The one gap left in **H2** of `qou-5gai`, and the reason every PR in the H4 tier
has to carry the caveat *"H2 remains partial — dilation ✅, translation ✅,
Möbius ✗, so 'hyperbolic volume' is a name backed by two generators."*

`Isom(H³)` acting on upper half-space is generated by horizontal translation,
dilation, rotation about the vertical axis, **and inversion in the unit
hemisphere**. The first two are proved. This bean is the fourth.

## The statement

    σ : ℝ³ → ℝ³,   σ(x) = x / ‖x‖²

    hypVolume (σ '' A)  =  hypVolume A

`σ` preserves the upper half-space — `(σ x)₃ = x₃/‖x‖²`, so `x₃ > 0 ↔ (σ x)₃ > 0`
— which is the easy half and needs no measure theory.

## The Jacobian is DERIVED, not to be re-derived — and it is certified

    Dσ(x) h  =  h/‖x‖²  −  2⟨x,h⟩x/‖x‖⁴  =  (1/‖x‖²)·(I − 2·xxᵀ/‖x‖²)

The bracket is `I − 2P` with `P = xxᵀ/‖x‖²` the rank-1 orthogonal projection onto
`ℝx` — i.e. a **Householder reflection**, whose determinant is `−1` in any
dimension. So in dimension 3

    det Dσ(x)  =  (1/‖x‖²)³ · (−1)  =  −‖x‖⁻⁶,      |det Dσ(x)| = ‖x‖⁻⁶

**Certified numerically (2026-08-10, mpmath 40 dps, central differences):** the
ratio `det Dσ / (−‖x‖⁻⁶)` is `1.0` to printed precision at four well-spread
points, and the density-weighted invariance

    (1/(σx)₃³) · |det Dσ(x)|  =  1/x₃³

holds to `≤ 3e-41`. So the cancellation is exact and the sign convention above is
the right one. Do not spend a session re-deriving this; spend it on the Lean.

**Why it cancels, in one line:** `(σx)₃ = x₃/‖x‖²`, so the density picks up
`‖x‖⁶` and the Jacobian contributes `‖x‖⁻⁶`.

## Route, and where the risk actually is

1. `σ` is `ContDiff` / differentiable off the origin — `fun_prop` territory once
   `‖x‖² ≠ 0` is in hand.
2. `HasFDerivAt σ (Dσ x) x` with `Dσ x` as above. Mechanical but fiddly.
3. **`det (I − 2P) = −1` for a rank-1 orthogonal projection `P`. THIS IS THE
   RISK.** Search Mathlib for the reflection determinant before hand-rolling it:
   `LinearIsometryEquiv.reflection`, `Module.Basis.det`,
   `Matrix.det_one_sub_smul`-shaped lemmas. If nothing fits, the concrete
   `Fin 3 → ℝ` route is a `Matrix.det_fin_three` computation on
   `δᵢⱼ − 2xᵢxⱼ/‖x‖²`, which is a `linear_combination` on `‖x‖² = x₀²+x₁²+x₂²`
   — ugly but certain, and the dimension is fixed at 3 anyway.
4. Change of variables:
   `MeasureTheory.lintegral_image_eq_lintegral_abs_det_fderiv_mul` (needs
   injectivity of `σ` on the domain — `σ` is an involution off the origin,
   `σ(σ x) = x`, which is the cheapest injectivity proof available).

## Carrier warning — read this before starting

`qou-5gai` records that **H1 was written on `ℝ × ℝ × ℝ`, and that carrier cannot
do H2**: `volume.IsAddHaarMeasure` fails to synthesize on `Prod`, and
`Mathlib.MeasureTheory.Measure.Haar.Prod` does not exist. The chimney/`hypVolume`
stack is on `Fin 3 → ℝ` (see `IdealTetrahedronRegion.chimney`), which **does**
have `IsAddHaarMeasure`, `addHaar_smul` and `finrank = 3`. Stay on `Fin 3 → ℝ`.
This is the same trap that made the dilation half hard.

## What landing this buys

Every H4-tier statement currently carries "H2 is partial, so *hyperbolic volume*
is a name backed by two generators." With translation + dilation + inversion the
name is earned (rotation about the vertical axis is the easy fourth, and is worth
doing in the same PR — it is `det = 1` on a `Fin 3 → ℝ` block matrix, the same
shape as `det_rotL` in `OrthoschemeRotation`).

It does **not** by itself close the ideal-tetrahedron identification — see
`qou-w3eg` — which is a separate and larger gap.
