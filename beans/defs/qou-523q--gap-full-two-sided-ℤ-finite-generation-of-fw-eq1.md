## Context

Follow-up to PR #4492 (branch `claude/fw-eq14-recursion-brick-2026-08-01`),
which formalized Fantini–Wheeler eq. (14) (arXiv:2410.20973) as the
hypothesis class `QOU.QBeta.StateIntegral.Recursion` and proved the
one-step lattice reductions sorry-free in
`folio/quantum-observable-universe/lean/QOU/QBeta/StateIntegralRecursionLattice.lean`.

## The open target

Prove the **full** "rank max{A,B}" statement FW state over Q(q): the
`R`-module generated by the whole row `{ I m 0 : m ∈ ℤ }` is generated by
a **single** size-`max{A,B}` window `{ I j 0 : j₀ ≤ j < j₀ + max{A,B} }`
— i.e. `Submodule.span R (Set.range (fun m : ℤ => I m 0))` is
finitely generated by ≤ `max{A,B}` elements (`Submodule.FG`, or an explicit
`span R (window) = span R (row)`).

## What already exists (PR #4492, sorry-free)

- `row_zero_recurrence`: the order-max{A,B} recurrence on row 0.
- `row_zero_solve_A`, `row_zero_top_reduction`: the **one-step** reductions
  (top index of the recurrence window ∈ span of the window below it).
- `ell_collapse` + `lattice_in_row_zero_span`: the ℓ-direction already
  collapses onto row 0, so the 2-D problem is genuinely reduced to the 1-D
  row-0 finite-generation.

## Why it wasn't closed here

The full statement needs a **two-sided induction over m ∈ ℤ**: use the
top-reduction to fold every `m ≥ j₀ + max{A,B}` down into the window, AND the
symmetric bottom-reduction (solve the recurrence for the *lowest* index —
its coefficient is `C(B,0)(−1)⁰ = 1`, a unit) to fold every `m < j₀` up.
Both extreme coefficients are units, so both directions work; the bookkeeping
(strong induction on `|m − j₀|` in ℤ, or two `Nat` inductions after splitting
at `j₀`) is the actual work. Left as a bean rather than rushed, to keep
PR #4492's sorry-free guarantee honest.

## Next honest step

Add `row_zero_solve_bottom` (mirror of `row_zero_solve_A`, isolating the k=0
term), then a strong-induction lemma `row_zero_in_window` over ℤ, then package
as `Submodule.FG` / a `span` equality. All still generic `[Field R]`,
§7c-clean. No new class fields — this is pure derivation from the existing
`Recursion` class.

-- Ref: [fantini-wheeler2024] arXiv:2410.20973 §1.2 ("max{A,B} independent integrals")
