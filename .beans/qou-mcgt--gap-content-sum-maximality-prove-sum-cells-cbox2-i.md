## The statement

For `λ ⊢ k` with `λ ∉ {(k), (1ᵏ)}` (i.e. at least 2 rows AND at least 2 columns):

    C₂(λ) := Σ_□ c(□)²  ≤  C₂((k−1,1)) = Σ_{j=0}^{k−2} j² + 1,

with equality exactly on the conjugate pair `{(k−1,1), (2,1^{k−2})}`.

Equivalently, in the form the downstream needs:

    ρ := max_{λ non-extremal} r(λ) = 1 − 3/(k−1),
    r(λ) = χ^λ(3-cycle)/f^λ = 3(C₂(λ) − C(k,2)) / (k(k−1)(k−2)).

The extremal split (`T3_lt_of_extremal_split`, `T3_le_explicit_c`) takes `ρ < 1`
as a hypothesis and delivers `T₃ ≤ c·T₁` with `c < 1`; that chains through
`ratio_bound_of_T3_le` (`ε = 2(1−c)/(1+2c) ≍ 4/(3(k−1))`) into
`cube_moment_le_of_ratio_bound`. **Only `ρ < 1` is missing**, and only
polynomially — a uniform constant is NOT needed, since `T₁` is
super-exponential.

## Verified, not proved

`computations/probes/wstd_extremal_split_probe.py` (k ≤ 13) and an extended check
to **k = 24**: the off-extremal maximiser is exactly `{(k−1,1), (2,1^{k−2})}` at
every k, and the gap `C₂((k)) − C₂((k−1,1)) = (k−1)² − 1` exactly (checked
k = 5,10,15,20,24).

## Proof strategy

1. **`C₂` is conjugation-invariant** (contents negate under `λ ↦ λ'`), so
   maximisers come in conjugate pairs — this *explains* the observed tie and
   halves the work: WLOG `λ₁ ≥ ℓ(λ)`.
2. **Exchange argument.** If `λ` is non-extremal with `λ₁ < k−1`, moving the last
   cell of the last row to the end of row 0 keeps it non-extremal and strictly
   increases `C₂` (the cell moves from content `λ_ℓ−1−(ℓ−1)` to content `λ₁`,
   and under the WLOG the latter has strictly larger square). Iterating drives
   any non-extremal `λ` to `(k−1,1)`.
3. The `(k−1)²−1` gap then follows by direct computation:
   `Σ_{j=0}^{k−1}j² − (Σ_{j=0}^{k−2}j² + 1) = (k−1)² − 1`.

Step 2 needs care where the WLOG is tight (tall-thin shapes), which is exactly
where the conjugate branch takes over. Elementary, but a real induction — needs
Mathlib partition API.

## Weaker sufficient version (if the sharp one is hard)

Any `ρ ≤ 1 − δ(k)` with `δ` decaying polynomially suffices. So a crude bound
`C₂(λ) ≤ C₂((k)) − c·k²` for non-extremal `λ`, any explicit `c > 0`, closes (D)
just as well. Do NOT spend effort on sharpness that the downstream discards.

## REFRAMED (2026-08-11) — this is the ALDOUS PROPERTY for the 3-cycle class

The content-sum conjecture is not an ad-hoc combinatorial statement. The audit's
own Jucys–Murphy identity gives

    C₂(λ) = C(k,2) + (eigenvalue of the 3-cycle class sum on V_λ),

so **maximising `C₂` is exactly maximising the normalized character**
`χ^λ(3-cycle)/f^λ`. And the value at the claimed second-place shape is
recognisable: for the **standard representation** `(k−1,1)`,
`χ(g) = fix(g) − 1 = k − 4` and `f = k − 1`, giving

    (k−4)/(k−1) = 1 − 3/(k−1) = ρ     — exactly the measured ρ.

Verified k=5..15: the JM/content route and the standard-rep character agree
identically (`wstd_extremal_split_probe.py` covers the C₂ side to k=13; the
character identification checked separately).

So the bean's statement is equivalent to:

> **The 3-cycle conjugacy class sum on `S_k` has its strictly second-largest
> normalized eigenvalue at the standard representation `(k−1,1)`** — i.e. the
> normal Cayley graph on `S_k` generated by the full 3-cycle class has the
> **Aldous property**.

(The two trivial-value shapes `(k)` and `(1ᵏ)` are the trivial and sign reps,
both giving `+1` since a 3-cycle is even — which is exactly why the extremal
split needs to remove *two* shapes, not one.)

## CLOSED BY CITATION (2026-08-11) — owner supplied the papers (commit 2a697a9b)

Read `library/arxiv-2607.29018v1/2607.29018v1.pdf` (Lv–Zhou, *The Aldous property for normal Cayley
graphs on symmetric groups*). The conjecture is a known theorem, twice over:

1. **Li–Xia–Zhou** (quoted in Lv–Zhou §1.1): for a **single conjugacy class** `S`,
   `Cay(S_n,S)` has the Aldous property **iff** `2 ≤ |supp(σ)| ≤ n−2` for each
   `σ ∈ S`. The 3-cycles are a single class with `|supp| = 3`, so this holds for
   `n ≥ 5`. This is our case exactly.
2. **Lv–Zhou Theorem 1.3(a)**: for a normal set `S` with `2 ≤ |supp(σ)| ≤ n−2`,
   if `E(S) = ∅` **or `O(S) = ∅`** then `Cay(S_n,S)` has the Aldous property.
   Every 3-cycle is **even**, so `O(S) = ∅`. Independent route, same conclusion.

**And the exact value falls out.** Lv–Zhou Corollary 1.5: for `S ⊆ A_n` with
`2 ≤ |supp| ≤ n−2`,

    λ₂ = ( Σ_{σ∈S} |fix(σ)| − |S| ) / (n−1).

For the 3-cycle class (`|S| = n(n−1)(n−2)/3`, `fix(σ) = n−3`):

    λ₂/λ₁ = (n−4)/(n−1) = 1 − 3/(n−1)  =  ρ.

Verified against the formula at n = 5,6,7,10,13,20,24,50 — exact match, and
against direct enumeration for n ≤ 24.

### Residual caveat (real, do not paper over)

Both results are stated for **sufficiently large n**; neither statement as read
gives `N` explicitly. Direct enumeration covers `k ≤ 24` with exact agreement, so
any gap is confined to a window above 24 — but the constant is **not pinned**.
Accordingly `hρ` stays an explicit hypothesis in
`QOU/Mass/CubeMomentLowerBound.lean` rather than being discharged. Someone
wanting it unconditional should extract `N` from the Lv–Zhou proof (§ following
Thm 1.3) or from Li–Xia–Zhou [22].
