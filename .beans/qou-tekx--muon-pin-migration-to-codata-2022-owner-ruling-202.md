## The ruling

Owner, 2026-08-30: **"C."** then **"CODATA 2022 for muon"**. Recorded in AGENTS.md
§"q₀ anchor convention" as `OWNER RULING 2026-08-30`.

Re-derived independently at `mp.dps = 60`, `Vol(4₁) = 2·Cl₂(π/3) =
2.02988321281930725004240510855`:

| | `m_μ/m_e` | `q₀` |
|---|---|---|
| **A** frozen pin | *(none)* | `1.1099785955573347…` |
| **B** CODATA 2018 | `206.7682830` | `1.10997859555418057528159407961` |
| **C** CODATA 2022 | `206.7682827` | `1.10997859564273904668179512938` ← **canonical** |

Inverting **A** gives `m_μ/m_e = 206.768282989315111`, matching neither published
figure — it sits strictly between them. A cannot share a dataset with CAL-1, which
is what decided it.

## Already true — no work needed

`constants.py` serves `MASS_RATIO_MU_E_STR = 206.7682827  # CODATA 2022`, and
`q_muon_at()` returns `1.10997859564274` = **C**. The live derivation path is
already correct. **Only the anchor-defining witness is frozen at A**:
`computations/q-pinning-50-digit.witness.json`.

## 🛑 This is NOT a sweep, and the reason is on the record

Re-pinning that witness took `main` red on 2026-08-19: both anchors collapsed to
one string, **262 correctly-stamped muon witnesses flipped to `Q0_FLIP`**
(`Q0_OK` 654 → 392), and every `ideal_muon` producer hard-failed — including,
circularly, the one that regenerates the anchor. `q0_repin_sweep.py` carries an
`ANCHOR_DEFINING` exclusion for exactly this. **Do not remove it. Do not re-pin
that file as a step in a bulk pass.** Read `2e4745448d` before touching this.

## Staging this needs, in order

1. **Establish what reads A.** `_q0_value_for_anchor("muon")` is the documented
   reader; measure the rest before moving anything.
2. **Decide what "muon-anchored" means for a witness stamped before the ruling.**
   A witness computed at A is not wrong about what it did — it is stamped with a
   value the corpus no longer calls canonical. Re-pinning the anchor *without*
   regenerating them is precisely the 262-flip failure.
3. **Order matters.** The anchor witness cannot be regenerated by a producer that
   hard-fails when the anchor is inconsistent. Whatever breaks that circle has to
   be built first.
4. **Only then** the consumer migration, producer by producer, never as one sweep.

## Live consequence today

The `q0-anchor flip` gate (one of the six reds in `qou-hah0`) fails on exactly
this: `hadron-knot-table.witness.json` is stamped `anchor=muon` with A while the
audit expects C. Under this ruling **the audit is right and the witness is
stale** — which settles the question `qou-hah0` recorded as unsettled. It does
not make the fix cheap: `hadron_knot_table` is the producer AGENTS.md measures at
**>50 min for one bound atom before its own timeout kills it**.

## Accepted cost

C is a **live** derivation over a CODATA input, so unlike A it moves whenever that
table is updated. That is the deliberate price of reproducibility from a published
source, and should not be re-litigated as a defect the next time it drifts.

## THREE ARE NOT INNOCENT — a straddle the flip audit structurally cannot see

`probes/he_nu_sdp_barfold_h9_test.py`, `he_nu_sdp_psd_count_test.py`,
`he_nu_sdp_saturation_obstruction.py` each carry, at module level:

    Q0 = 1.1099785955573347        # the RETIRED A pin, as a BARE float64 literal

They write it to the witness as top-level `"q0"`, then call the stamper with
`q0_anchor=None`, which resolves to proton and writes `q0Value` = the proton
pin. So each witness **declares an anchor it did not compute at**, and its own
`q0` and `q0Value` — siblings, not nested — disagree by ~11.5 ppb.

`q0_anchor_consistency_audit` compares `q0Anchor` against `q0Value`. Those two
AGREE, so all three pass. The disagreement is one field over.

Three defects in one: wrong pin, float64 literal where AGENTS.md permits
`float()` only inside an f-string, and a stamp that conceals both.
