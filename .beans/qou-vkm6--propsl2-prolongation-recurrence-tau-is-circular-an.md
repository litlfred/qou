1. CIRCULAR. That formula is the n=2 instance of the block's own recurrence

### Corrected: "CIRCULAR" is not right; the CHECK is vacuous, the VALUE is not

`a_D^(n) = S(n)/n` with `S(n) = Σ_{λ⊢n} dim_q λ` is a **closed form** — the
audit script's own R1 prints it and says so. So `a_D^(2)`, `a_D^(3)`, `a_D^(4)` are
each independently computable, and `τ = (a_D^(2)+a_D^(4))/a_D^(3)` therefore
evaluates to a **well-defined number** (2.642386309). It is not circular in the sense
of determining nothing.

What the `residual = 0 for every substituted a_D^(3)` measurement actually shows is
that the **n=4 consistency check is vacuous** — true by construction, since τ was
solved on it. That is a different (and correct) claim from "τ is undetermined".

### Strengthened: the PREMISE is false, which is worse

The block called θ "the last open number of the depth correspondence". Since
`a_D^(n)` is closed-form for **every** n, there was never an open number there at
all. τ is a summary of three terms of an already-determined sequence. So the sentence
fails on its premise, not merely on its method.

−14.31%, n=7 −32.17%, n=8 −52.21%. Scoped to an **n≤4 effective germ** per
AGENTS.md scope-(a), not deleted. The det B = 1 / Sp(2) argument stands.
