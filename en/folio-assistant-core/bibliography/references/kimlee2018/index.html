No DOI, ISSN or URL is printed on the article; venue read off the title page and running head, no lookup performed. Read in full 2026-08-09. The folio-relevant part is §3, the type A_{n-1} review: T(A_{n-1}) generated by E₁,…,E_{n-1} with E_i² = δE_i, E_iE_j = E_jE_i for i > j+1, E_iE_jE_i = E_i for j = i±1 (δ ∈ ℂ a free parameter, the E_iE_jE_i relation UN-rescaled — the convention this folio adopted, e_i := q − σ_i with e_i² = [2]_q e_i and δ = [2]_q). Prop. 3.1 gives a Gröbner–Shirshov basis whose standard monomials number C_n, i.e. dim TL_n = Catalan(n), and note that the basis needs two families BEYOND the defining relations (E_{i,j}E_i − E_{i−2,j}E_i and E_jE_{i,j} − E_jE_{i,j+2}) — the same completion phenomenon that makes def:hecke-normal-form's confluence claim false (bean qou-43co). Prop. 3.1 is QUOTED from Kang–Lee–Lee–Oh, J. Algebra 252 (2002) 258-292, Prop. 6.2, the primary, which is not yet in this file (bean qou-qspu). The paper's own theorem (dim T(B_n) = (n+2)C_n − 1) has no consumer here. A close sibling exists — the same authors' arXiv:1808.05026, 'GS bases for Temperley-Lieb algebras of types B and D', whose §3 is verbatim this same review — deliberately NOT registered separately; see the ledger row for library/arxiv-1808.05026v1/1808.05026v1.pdf.
