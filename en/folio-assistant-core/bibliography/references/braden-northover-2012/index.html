Note
Recovers Riera–Rodríguez's period matrix τ₀·C via the Hulek–Craig sextic model, and additionally (i) identifies the Vector of Riemann Constants and (ii) constructs the explicit anti-holomorphic involution (the real structure / complex conjugation on the plane model), whose fixed set is a union of Hilbert ovals. This explicit conjugation on Jac(Bring) is the concrete Hodge-side object of the α_EM per-loop fibre-level correspondence (docs/audits/2026-07-18-alpha-em-involution-type-nome-independent.md). Corrects the j-invariant labelling: j(τ₀) = −5·29³/2⁵, j(5τ₀) = −25/2, flagging the Riera–Rodríguez swap as a typo. Registered 2026-07-18 from library/ intake; metadata from the uploaded PDF.
