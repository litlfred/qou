Each $\check R_{i,i+1}$ acts on $\varepsilon_q$ by $-q^{-1}$, so $X_i(\varepsilon_q \otimes f) = \varepsilon_q \otimes (-q^{-1} B_i f)$. The $(0,1,2)$ component of $\varepsilon_q$ is $1$, so $\varepsilon_q \otimes g = \varepsilon_q \otimes h$ forces $g = h$. Hence $X_i(\varepsilon_q \otimes f) = -\varepsilon_q \otimes f$ if and only if $-q^{-1} B_i f = -f$, that is $B_i f = q f$. For item 2, substitute $B_1 f = -q^{-1} f$: if $q^{-2} = -1$, then $q^2 \cdot q^{-2} = 1$ gives $q^2 + 1 = 0$, contradicting $q^2 + 1 \neq 0$.
