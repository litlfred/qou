Each $\check R_{i,i+1}$ acts on $\varepsilon_q$ by $-q^{-1}$ (`R12_eps`, `R23_eps`), so $X_i(\varepsilon_q \otimes f) = \varepsilon_q \otimes (-q^{-1} B_i f)$ (`X12_singlet`, `X23_singlet`). The $(0,1,2)$ component of $\varepsilon_q$ is $1$, so $\varepsilon_q \otimes g = \varepsilon_q \otimes h$ forces $g = h$ (`pure_eps_inj`). Hence $X_i(\varepsilon_q \otimes f) = -\varepsilon_q \otimes f$ if and only if $-q^{-1} B_i f = -f$, that is $B_i f = q f$ (`singlet_exterior_iff`). For item 2, substitute $B_1 f = -q^{-1} f$ (`singlet_antisym_eigen`); if $q^{-2} = -1$ then $q^2 \cdot q^{-2} = 1$ gives $q^2 + 1 = 0$ (`inv_sq_ne_neg_one`).
