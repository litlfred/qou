The T-duality involution $\iota \colon (X, z) \mapsto (z, X)$ ([T-duality on elliptic fibres](#rem:t-duality-elliptic)) acts on color tube coordinates as follows. Writing $c = X - z$, the dual point has base coordinate $z' = X = c + z$ and color coordinate $X' = z$, yielding the dual color tube coordinate $c' = z - X = -c$. Hence

```tex
\begin{equation}\label{eq:t-duality-color-tube}
  \iota \colon (c, z)  \longmapsto  (-c, c + z).
\end{equation}
```

The symmetry $F(X,z) = F(z,X)$ ([T-duality on elliptic fibres](#rem:t-duality-elliptic)) translates to covariance of the color tube cubic. The involution $\iota$ carries the cubic at parameter $z$ with root $c$ to the cubic at parameter $c + z$ with root $-c$. This follows directly from $F(c+z, z) = F(z, c+z)$, as $F(z, c+z)$ is the color tube cubic at parameter $c+z$ evaluated at $-c$.
