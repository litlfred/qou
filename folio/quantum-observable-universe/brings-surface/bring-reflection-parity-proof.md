The relations for $T$, and its uniqueness, are checked over all of $S_5$. The isometry $(g, c)\colon x \mapsto gxT$ fixes the vertex $x\langle S\rangle$ if and only if $x^{-1}gxT \in \langle S \rangle$. It keeps the edge $\{x, xA\}$ with its direction if and only if $gxT = x$, and reverses it if and only if $gxT = xA$. It fixes the face through $x$ if and only if $x^{-1}gxTA \in \langle AS\rangle$. Counting over the $120$ darts gives fixed cells only for $g$ a transposition ($6$ vertices, $6$ edges kept) and for $g$ a double transposition ($4$ vertices, $4$ edges reversed, $8$ faces). For $g = 1$ there are none. A kept face has its orientation reversed. With $H^0 = [5]^+$ and $H^2 = [5]^-$, the Hopf trace formula gives $\operatorname{tr}((g,c) \mid H^1) = 1 - 1 - (C^0 - C^1 + C^2) = 0$ for every $g$, so $H^1$ is $[2,1^3]^+ \oplus [2,1^3]^-$. Since $c$ is central, a class function on $S_5 \times C_2$ is a pair $(f_0, f_1)$, and $m_\rho^\pm = \langle f_0 \pm f_1, \chi_\rho\rangle/240$. For item 4, $(\rho\otimes\varepsilon)^{H\times\langle c\rangle}$ is $\rho^H$ when $\varepsilon = +$ and $0$ when $\varepsilon = -$, so the recovery matrix of [the classification](#prop:bring-harmonic-types) applies to each parity. $\square$
