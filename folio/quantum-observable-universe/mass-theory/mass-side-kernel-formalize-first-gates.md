*The mass-side kernel specification bundles the mass-theory analogs of the four formalize-first invariants for any candidate linking-weight function $w(q)$. Satisfying this specification requires clearing all four mass-side gates simultaneously.*

The four parametric conditions implement the anchor-stable, bar-even, $q=1$ shadow (open categorical gap), and direction-sanity invariants for the mass side. The direction-sanity check uses an additive threshold, while the $q=1$ shadow accommodates optional hypothetical anchors. This specification evaluates candidate kernels through a unified four-gate criterion.
