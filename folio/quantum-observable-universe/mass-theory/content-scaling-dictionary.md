The mass model reads the content $c$ of a box as an isospin label and assigns to each
content class a Bethe--Weizsäcker scaling function. This assignment is a dictionary of the
model, not a consequence of the proposition it interprets: the proposition fixes $c$ as the
$q$-Jucys--Murphy eigenvalue exponent, a total-spin datum of the sub-tower, and the table
below is the model's choice of what that datum counts.

| Content $c$ | Isospin meaning | Scaling $f_c(Z,N)$ |
|:-----------:|:---------------:|:-------------------:|
| $+1$ | proton nearest-neighbor | $Z(Z{-}1)/A^{1/3}$ |
| $-1$ | neutron nearest-neighbor | $N(N{-}1)/A^{1/3}$ |
| $0$ | balanced (pn mixed) | $A^{2/3}$ or $\pm 1/\sqrt{A}$ |
| $\pm 2$ | next-nearest same-type | $Z^{4/3}/A^{1/3}$ |
| $\lvert c\rvert \geq 3$ | long-range | $T^p(T{+}1)^p/A^p$ |

Each scaling function counts the number of nucleon pairs the model places at content $c$ in
the nuclear ground state. The content is not a magnetic quantum number of the
$\mathrm{SU}_q(2)$ weight space $V_\lambda$: for a two-row shape $(a,b)$ the number of boxes
$a+b$ never equals the number of weights $a-b+1$, and for $a+b \geq 3$ the largest content
$a-1$ exceeds the largest weight $(a-b)/2$, so no box-to-weight assignment realises the older
reading of this table.
