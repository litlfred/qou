*Any candidate Habiro element $F(q)$ must satisfy the direction-sanity invariant: $|F(q_0)|$ must be in the same order of magnitude as the target ratio $\mathfrak{Q}_\beta^{\text{CODATA}} / [Q_A(q_0) \cdot \cos(\alpha_{\text{eff}}(q_0))]$. A candidate predicting a magnitude differing by more than $10\times$ is screened out.*

This implements the formalize-first magnitude check. This is an order-of-magnitude screen, not a structural exclusion: no proved invariant forbids a candidate outside the window, so a screened-out candidate is not refuted. The target is $\approx 1$ on the retired $z = 1$ base and $\approx 1.76$ on the ruled convention-D base $z_D$.

The screen is the predicate $\mathrm{Scr}_{10}(t,|F(q_0)|)$ of [order-of-magnitude-screen proposition](#prop:order-of-magnitude-screen), with the threshold $10$ (one decade each way) a convention and the target $t$ a comparison value. Everything provable about the gate is in that proposition. In particular a larger threshold only admits more candidates (item 1); a screen-out implies $F\ne F_{\mathrm{true}}$ only if the true kernel passes the screen (item 2), which is a comparison with data; and the obstruction behind the canonical precedent, a candidate of the form $B\,z(q_0)^m$ with $0\le z(q_0)\le1$, needs no threshold (item 4): if $B<t$ then $B\,z(q_0)^m<t$ for every $m$. Whether $B<t$ holds is again a comparison with data, and it fails on the retired $z=1$ base, where $t<1$. The additive band $|m-t|\le10t$ is not this window: on nonnegative magnitudes it is the one-sided bound $m\le11t$, so it rejects no too-small candidate (item 6).
