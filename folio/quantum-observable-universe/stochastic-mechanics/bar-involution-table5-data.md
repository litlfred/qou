| Combination | Result | Defining identity |
|---|---|---|
| sym + sym | sym | $\overline{x + y} = \overline x + \overline y = x + y$ |
| sym $\times$ sym | sym | $\overline{x y} = \overline y\,\overline x = x y$ (commutative subring) |
| anti + anti | anti | $\overline{x + y} = -x - y = -(x + y)$ |
| **anti $\times$ anti** | **sym** | $\overline{x y} = (-y)(-x) = x y$ (commutative subring) |
| sym $\times$ anti | anti | $\overline{x y} = (-y) x = -(x y)$ (commutative subring) |
| $-$sym | sym | $\overline{-x} = -\overline x = -x$ |
| $-$anti | anti | $\overline{-x} = -\overline x = x = -(-x)$ |
| $h^{2n}$ ($h$ anti) | sym | $\overline{h^{2n}} = (-h)^{2n} = h^{2n}$ |
| $h^{2n+1}$ ($h$ anti) | anti | $\overline{h^{2n+1}} = (-h)^{2n+1} = -h^{2n+1}$ |
| $\overline{-x} = -\overline{x}$ | identity | $\mathbb{Z}$-linearity of $\overline{\,\cdot\,}$ |
