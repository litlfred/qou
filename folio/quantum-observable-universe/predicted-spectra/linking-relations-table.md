Three operations construct every particle from the seven torus knot generators: Hopf linking ($\oplus$), Skein crossing change ($\sigma$), and color-tube linking ($[\cdot]_p$). This table records the result of each operation applied to pairs of building block knots.

## Table 1: Hopf linking $K_1 \oplus K_2$

The Hopf link $\mathcal{L}_H$ joins two knots into a two-component link. The linking number is always $\pm 1$.

See [Table 1](#tbl:linking-relations-table-table1-data).

## Table 2: Skein crossing change $K^{\sigma}$

The Skein crossing change reverses one crossing. Applied globally, it acts as the mirror operation mapping particle to antiparticle. Applied locally at one crossing, it transmutes quark flavour.

See [Table 2](#tbl:linking-relations-table-table2-data).

## Table 3: Color-tube linking $[K_1, K_2, K_3]_p$

Three knots threaded through the three color tubes of Bring's surface form a Borromean-linked baryon.

See [Table 3](#tbl:linking-relations-table-table3-data).

## Table 4: Connected sum $K_1 \# K_2$

The connected sum joins knots end-to-end. The Seifert genus is additive: $g(K_1 \# K_2) = g(K_1) + g(K_2)$. This operation does not produce a physical composite. It is a mathematical operation arising in the Skein resolution tree.

See [Table 4](#tbl:linking-relations-table-table4-data).

The volume is additive under connected sum: $\mathrm{Vol}(K_1 \# K_2) = \mathrm{Vol}(K_1) + \mathrm{Vol}(K_2)$. This follows from JSJ decomposition, where each knot contributes its hyperbolic piece.

## Table 5: $L_0^{\pm}$ smoothing

The $L_0^{\pm}$ smoothing at a crossing in a braid word replaces the crossing with parallel strands. This splits one component into two. The sign on $L_0$ matches the beta decay emission type ($\beta^{\pm}$).

See [Table 5](#tbl:linking-relations-table-table5-data).

In each case, the $L_0^{\pm}$ smoothing produces exactly one charged lepton ($e^-$ or $e^+$, closing to the positive or negative Hopf link) and one (anti)neutrino (unknot or mirror unknot). This construction ensures that lepton number is conserved.
