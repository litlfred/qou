Apply the Leibniz rule to $z = z^2$: $D(z) = D(z)z + zD(z) = 2zD(z)$, using that $z$ commutes with $D(z)$. Multiplying on the left by $z$ gives $zD(z) = 2z^2D(z) = 2zD(z)$, so $zD(z) = 0$, and then $D(z) = 2zD(z) = 0$. For any $a$, $D(za) = D(z)a + zD(a) = zD(a)$.

If $\varphi$ is an automorphism, then $\varphi(z)^2 = \varphi(z^2) = \varphi(z)$, and every element of $A$ is $\varphi(b)$ for some $b$, with $\varphi(z)\varphi(b) = \varphi(zb) = \varphi(bz) = \varphi(b)\varphi(z)$.

If $z$ is central and $u$ is a unit, then $uzu^{-1} = zuu^{-1} = z$. An automorphism of the form $x \mapsto uxu^{-1}$ therefore fixes $z$, so one that moves $z$ is not of that form. $\square$
