**Algebra without quasi-zeros.** Let $R$ be a commutative ring with unity and $A$ an $R$-algebra. An element $a \in A$ is a **quasi-zero** if

$$
  bac = 0 \qquad \text{for all } b, c \in A \text{ not both } 1.
$$

The algebra $A$ is :defterm[without quasi-zeros]{#no-quasi-zeros} if no such element exists. Assume that $R$ has no quasi-zeros. This ensures that leading-term decompositions are well-defined and the division algorithm terminates correctly. It guarantees that $R$-linear hom-spaces have no phantom morphisms annihilated by all compositions, making the Frobenius pairing non-degenerate.
