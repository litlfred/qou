# Explicit instance of canonical Markov weights

The canonical Markov-weight hypothesis (stated in [Per-block character closed forms for $\chi_\lambda(\Delta_{T_\beta})(q)$ over $H_3(q)$, antipode pairing, and vanishing at $q = 1$](qbeta-per-block-chi-closed-forms.md) §Extension #4) is satisfiable. An explicit $\sqrt q$-bearing choice of weights satisfying it is:

$$
  y_{(3)}(q) = z(q), \qquad
  y_{(2,1)}(q) = \tfrac{1}{2} - z(q), \qquad
  y_{(1,1,1)}(q) = z(q),
$$

where $z(q) = \sqrt q / (1 + q) = 1/(q^{1/2}+q^{-1/2})$ is the parameter *this instance* is built on. It is the **excised convention C** value, not the framework's production Markov parameter $z = q^3/(q^2+1)$; the choice is a formal witness, constructed to show the hypothesis is satisfiable, and nothing downstream reads its $z$ as the paper's.
