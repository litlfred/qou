# Explicit instance of canonical Markov weights

The canonical Markov-weight hypothesis (stated in [Per-block character closed forms for $\chi_\lambda(\Delta_{T_\beta})(q)$ over $H_3(q)$](qbeta-per-block-chi-closed-forms.md) §Extension #4) is satisfiable. An explicit $\sqrt q$-bearing instance is:

$$
  y_{(3)}(q) = z(q), \qquad
  y_{(2,1)}(q) = \tfrac{1}{2} - z(q), \qquad
  y_{(1,1,1)}(q) = z(q),
$$

where $z(q) = \sqrt q / (1 + q) = 1/(q^{1/2}+q^{-1/2})$ is an auxiliary algebraic function used solely to inhabit this hypothesis (distinct from the Markov parameter $q^3/(q^2+1)$); it witnesses that the normalisation condition is non-empty, and nothing downstream identifies this auxiliary $z(q)$ with the paper's Markov parameter.
