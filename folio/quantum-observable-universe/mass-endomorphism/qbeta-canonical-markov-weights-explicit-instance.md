# Explicit instance of canonical Markov weights

The canonical $H_3$ Markov-weights hypothesis (introduced in [the per-block character closed forms](qbeta-per-block-chi-closed-forms.md) §Extension #4) is satisfiable. An explicit $\sqrt q$-bearing inhabitant is given by:

$$
  y_{(3)}(q) = z(q), \qquad
  y_{(2,1)}(q) = \tfrac{1}{2} - z(q), \qquad
  y_{(1,1,1)}(q) = z(q),
$$

where $z(q) = \sqrt q / (1 + q) = 1/(q^{1/2}+q^{-1/2})$ is the parameter *this inhabitant* is built on. It is the **excised convention C** value, not the framework's production Markov parameter $z = q^3/(q^2+1)$; this inhabitant is constructed to show the dimension-normalisation hypothesis is non-empty, and nothing downstream reads its $z$ as the paper's.
