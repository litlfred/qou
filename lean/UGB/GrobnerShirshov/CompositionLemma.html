    Gröbner–Shirshov Composition Lemma (Diamond Lemma) #

    The Composition Lemma (also known as the Diamond Lemma for ring theory, Bergman 1978) is the central result of Gröbner–Shirshov theory:

    A rewriting system Σ is confluent (hence yields unique normal forms) if and only if every S-polynomial of Σ reduces to zero.

    This module states the lemma and its corollaries using the proper reduction relations defined in Basic.lean:

    1. Termination — well-founded induction on the admissible order.
    2. Local confluence — from S-polynomial resolution.
    3. Confluence — Newman's lemma (termination + local confluence).
    4. Uniqueness of normal forms — from confluence.
    5. Idempotency of reduce — the composition lemma itself.
    6. Retraction property — bridge to FormalGroups.lean.

    References #

    • Bergman, The diamond lemma for ring theory, Adv. Math. 29 (1978).
    • Bokut, Imbeddings into simple associative algebras, Algebra i Logika 15 (1976).
    • [fred2005, §3, Proposition 3.8].

    §2 Local Confluence from S-Polynomial Resolution #

    source
    axiom UGB.GrobnerShirshov.local_confluence {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) (hgs : IsGrobnerShirshovBasis G k ord sys) (hnqz : NoQuasiZerosFree G k) (f g₁ g₂ : AlgElement G k) (h₁ : SingleStepReduction ord sys f g₁) (h₂ : SingleStepReduction ord sys f g₂) :
    ∃ (h : AlgElement G k), MultiStepReduction ord sys g₁ h ∧ MultiStepReduction ord sys g₂ h

    Local confluence: if all S-polynomials reduce to zero (i.e., the system is a GS basis), then whenever f → g₁ and f → g₂ by single-step reductions, there exists h with g₁ →* h and g₂ →* h.

    Axiomatised because the three-case proof (disjoint / overlap / inclusion) requires AlgElement subtraction to form the S-polynomial g₁ - g₂, which is not available at the abstract level. The argument is:

    • Disjoint sites: both reductions commute; apply each to the other's result.
    • Overlap: g₁ - g₂ is an overlap S-polynomial, which reduces to zero by hgs.overlap_resolves.
    • Inclusion: g₁ - g₂ is an inclusion S-polynomial, which reduces to zero by hgs.inclusion_resolves.

    Reference: Bergman 1978, §3, proof of Theorem 1.2 (the Diamond Lemma).

    §3 Confluence (Newman's Lemma) #

    source
    theorem UGB.GrobnerShirshov.newman {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) (hlc : ∀ (f g₁ g₂ : AlgElement G k), SingleStepReduction ord sys f g₁ → SingleStepReduction ord sys f g₂ → ∃ (h : AlgElement G k), MultiStepReduction ord sys g₁ h ∧ MultiStepReduction ord sys g₂ h) (f : AlgElement G k) (hacc : Acc (fun (g h : AlgElement G k) => SingleStepReduction ord sys h g) f) (g₁ g₂ : AlgElement G k) :
    MultiStepReduction ord sys f g₁ → MultiStepReduction ord sys f g₂ → ∃ (h : AlgElement G k), MultiStepReduction ord sys g₁ h ∧ MultiStepReduction ord sys g₂ h

    Newman's lemma, in the form the induction actually needs: local confluence plus accessibility of f under reduction gives confluence at f.

    The hypothesis is taken as a plain function rather than as IsGrobnerShirshovBasis, because nothing in the argument looks at why the system is locally confluent — this is the abstract rewriting content, and keeping it separate is what makes confluence below a one-line instantiation.

    The proof is the standard tiling argument. Given x →* g₁ and x →* g₂, expose the first step of each (MultiStepReduction.cases_head); if either run is empty the other is the common reduct. Otherwise x → a →* g₁ and x → b →* g₂, and:

    • local confluence at the fork a ← x → b gives c with a →* c, b →* c;
    • the induction hypothesis at a — legitimate because x → a — applied to a →* g₁ and a →* c gives d with g₁ →* d and c →* d;
    • the induction hypothesis at b, applied to b →* g₂ and b →* c →* d, gives e with g₂ →* e and d →* e.

    Then e is the common reduct: g₁ →* d →* e and g₂ →* e. Note that the two induction steps are not symmetric — the second consumes the output of the first — which is why local confluence alone does not suffice and termination is doing real work.

    Reference: Newman (1942); Bergman 1978, Corollary to Theorem 1.2.

    §4 Uniqueness of Normal Forms #

    source
    theorem UGB.GrobnerShirshov.normal_form_unique {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) (hgs : IsGrobnerShirshovBasis G k ord sys) (hnqz : NoQuasiZerosFree G k) (f nf₁ nf₂ : AlgElement G k) (hred₁ : ReducesToNF ord sys f nf₁) (hred₂ : ReducesToNF ord sys f nf₂) :
    nf₁ = nf₂

    Uniqueness of normal forms: if f →* nf₁ and f →* nf₂ where both nf₁ and nf₂ are in normal form, then nf₁ = nf₂.

    Proof: by confluence, nf₁ and nf₂ have a common reduct h. Since both are in normal form (no reduction applies), h = nf₁ and h = nf₂, hence nf₁ = nf₂.

    Was an axiom. Its own docstring gave the two-line proof and then listed as the reason for axiomatising exactly the two things that are available: confluence (§3, now a theorem) and irreducibility of normal forms (MultiStepReduction.eq_of_isNormalForm, proved in Basic.lean since the reduction relation was repaired).

    Justified by Bergman 1978, Theorem 1.2.

    §5 The Composition Lemma (Main Theorem) #

    source
    theorem UGB.GrobnerShirshov.composition_lemma {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) (hgs : IsGrobnerShirshovBasis G k ord sys) (hnqz : NoQuasiZerosFree G k) (hlc : ∀ r ∈ sys.rules, IsUnit (r.lc ord)) (f : AlgElement G k) :
    reduce ord sys hlc (reduce ord sys hlc f) = reduce ord sys hlc f

    The Composition Lemma (Shirshov 1962, Bokut 1976, Bergman 1978):

    The reduction map is idempotent: reduce (reduce f) = reduce f.

    This encodes the forward direction of the diamond lemma: a GS basis (all S-polynomials reduce to zero) implies that normal-form monomials form a k-basis of the quotient k⟨G⟩ / (Σ).

    Proof: reduce f is in normal form (by reduce_is_normal), so it reduces to itself in zero steps. By normal_form_unique, the chosen normal form of reduce f must equal reduce f.

    Carries hlc (unit leading coefficients) since reduce does — see Basic.lean §6. Both hypotheses are load-bearing and for different reasons: hlc is what makes reduce defined at all, hgs is what makes its value canonical.

    The retraction property reduce ∘ embed ∘ reduce = reduce needed by FormalGroups.GrobnerShirshovBasis.composition_lemma.

    If embed is the identity on reduced elements, then the property follows from idempotency of reduce.
