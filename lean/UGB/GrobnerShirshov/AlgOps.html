    Generic admissible orders #

    The arithmetic on AlgElement G k (single, add, smul, sub, leftMulGen, ofTerms, contextMul, …) now lives in Elem.lean, which Basic.lean imports: stating a reduction step needs subtraction and two-sided multiplication by a monomial, so those operations have to be available before the reduction relations, not after them. Nothing was renamed and everything is still in the UGB.GrobnerShirshov namespace, so import UGB.GrobnerShirshov.AlgOps continues to bring all of it into scope.

    What remains here is the order-theoretic half: shortlex well-foundedness and the generic deg-lex AdmissibleOrder construction for any generator type with an injective rank function.

    §8 Generic Deg-Lex Order Construction #

    source
    theorem UGB.GrobnerShirshov.shortLex_wellFounded {α : Type u_1} {r : α → α → Prop} (hr : WellFounded r) :
    WellFounded fun (a b : List α) => a.length < b.length ∨ a.length = b.length ∧ List.Lex r a b

    Shortlex well-foundedness (Mathlib v4.24.0 gap). Pure List.Lex is not well-founded on unbounded-length lists (e.g. [1] ≻ [0,1] ≻ [0,0,1] ≻ …); the length-first refinement — "shorter word, or equal length and lexicographically smaller" — restores well-foundedness for any well-founded base relation r. This is the generic replacement for NormalForms.lexEncoding, whose fixed-base encoding into ℕ only works for the finite generator set SU2Gen; an arbitrary injective rank : G → ℕ has unbounded image, so no order-embedding of the length-n lex order (order type ω^n) into ℕ (order type ω) exists — the accessibility must be proved directly.

    noncomputable def UGB.GrobnerShirshov.mkDegLexOrder {G : Type u} [DecidableEq G] (rank : G → ℕ) (rank_inj : Function.Injective rank) :
    AdmissibleOrder G

    Construct a deg-lex AdmissibleOrder for any generator type G equipped with an injective rank function rank : G → ℕ.

    This generalises degLexOrder from NormalForms.lean (which is specific to SU2Gen). The proofs are identical in structure:

    • Well-foundedness: from List.Lex.wellFounded via rank
    • Trichotomy: case split on length, then on lex
    • Compatibility: length preserved by concatenation

    We delegate to the existing NormalForms infrastructure by mapping generators to SU2Gen (or more precisely, to ℕ via rank) and using List.Lex.wellFounded directly.
