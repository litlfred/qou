    Jet-Stratified Gröbner–Shirshov Reduction #

    This module formalises two results connecting jet prolongation to Gröbner–Shirshov (GS) computation:

    1. Ordering extension through the jet tower (moved from QOU.Torsion.ordering_jet_compatibility): the deg-lex admissible order at level n extends compatibly to level n+1 when jet prolongation introduces new generators.

    2. Jet-stratified reduction algorithm: given a GS basis Σₙ at level n, the GS property at level n+1 can be verified by checking only S-polynomials that involve at least one transient (new) relation — the descended–descended pairs are inherited.

    Complexity #

    Standard Buchberger at level n+1 checks O(|Σ_{n+1}|²) S-poly pairs. Jet-stratified reduction checks only O(|Σₙ| · k + k²) pairs, where k = |Σ_{n+1}^trans|.

    For SU(2) (k = O(1) new generators per level), this reduces the S-polynomial work from O(n²) to O(n) per jet level.

    References #

    • [fred2005, §3] — Gröbner–Shirshov basis for Dist(G)
    • [bergman1978] https://doi.org/10.1016/0001-8708(78)90010-5
    • [bokutchen2014] Bokut & Chen, Bull. Math. Sci. 4 (2014), §2.1.

                  theorem UGB.GrobnerShirshov.degLexNat_wf :
                  WellFounded degLexNat

                  degLexNat (deg-lex, length-first) is well-founded. It has order type ω^ω — so it is not order-embeddable into ℕ, and pure lex is not well-founded (cf. the removed lexLt_wf in NormalForms.lean, where [g₁] > [g₀,g₁] > … descends forever). The length-first guard rescues it: degLexNat = Prod.Lex (· < ·) (· < ·) pulled back along l ↦ (l.length, l), and the inner (· < ·) is well-founded on each length fiber (fixedLength_lex_wf), so WellFounded.prod_lex_of_wellFoundedOn_fiber applies.

                  Ordering extends through the jet tower #

                  source
                  theorem UGB.GrobnerShirshov.ordering_extends {φ : List ℕ → List ℕ} {a b : List ℕ} (hφa : φ a = a) (hφb : φ b = b) (hab : degLexNat a b) :
                  degLexNat (φ a) (φ b)

                  Jet-embedding order compatibility. The jet embedding sends each level-n generator to the same index among the first numGens indices at level n+1, so a descended monomial's ℕ-valued index list is left unchanged by the embedding φ (φ a = a). A deg-lex comparison of two descended monomials therefore carries over verbatim to their images.

                  Stated with the embedding φ and its fixed-point property on descended monomials (φ a = a, φ b = b) as explicit hypotheses, and the preserved comparison derived by rewriting — not the old self-assuming (hab : degLexNat a b) : degLexNat a b := hab, which named the embedding nowhere and asserted nothing about it.

                  Reference: [manuscript] §3/ordering-jet-compatibility.

                                §4 Jet-Stratified GS Verification #

                                source
                                axiom UGB.GrobnerShirshov.descended_gs_inherited {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (jss : JetStratifiedSystem G k) (h_desc_gs : IsGrobnerShirshovBasis G k ord jss.descended) (oc : OverlapComposition G k ord) (h₁ : oc.rule₁ ∈ jss.descended.rules) (h₂ : oc.rule₂ ∈ jss.descended.rules) :
                                ∃ (nf : AlgElement G k), ReducesToNF ord jss.full oc.spoly nf ∧ nf.isZero

                                Descended GS inheritance (axiom stub): if the descended subsystem is already a GS basis (verified at level n), then all descended × descended S-polynomials resolve to zero.

                                This is the key lemma that eliminates O(|Σₙ|²) checks.

                                Axiomatised because the proof requires constructing the reduction of each descended S-polynomial within the full system, showing that the extra transient rules do not interfere with the descended reduction (since transient leading monomials involve new generators that cannot appear in descended monomials).

                                source
                                axiom UGB.GrobnerShirshov.jet_stratified_gs_criterion {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (jss : JetStratifiedSystem G k) (h_desc_gs : IsGrobnerShirshovBasis G k ord jss.descended) (h_new_overlap : ∀ (oc : OverlapComposition G k ord), oc.rule₁ ∈ jss.full.rules → oc.rule₂ ∈ jss.full.rules → ¬(oc.rule₁ ∈ jss.descended.rules ∧ oc.rule₂ ∈ jss.descended.rules) → ∃ (nf : AlgElement G k), ReducesToNF ord jss.full oc.spoly nf ∧ nf.isZero) (h_new_inclusion : ∀ (ic : InclusionComposition G k ord), ic.inner ∈ jss.full.rules → ic.outer ∈ jss.full.rules → ¬(ic.inner ∈ jss.descended.rules ∧ ic.outer ∈ jss.descended.rules) → ∃ (nf : AlgElement G k), ReducesToNF ord jss.full ic.spoly nf ∧ nf.isZero) :
                                IsGrobnerShirshovBasis G k ord jss.full

                                Jet-stratified GS criterion (axiom stub): the full system at level n+1 is a GS basis if and only if:

                                1. The descended subsystem is a GS basis (from level n), AND
                                2. All desc×trans and trans×trans S-polynomials resolve to zero.

                                Condition (1) is inherited. Only condition (2) requires new computation: O(|Σₙ| · k + k²) S-poly checks instead of O(|Σ_{n+1}|²).

                                Axiomatised because the full proof requires showing that the descended subsystem's GS property lifts through the inclusion into the full system, using descended_gs_inherited plus the hypotheses on new S-polynomials.

                                Reference: [fred2005, §3], extended to jet towers.

So the axiom says nf_full = X for every X of the type, and the degree restriction it is named for ("restricting to rules with LM degree ≤ max degree of f's support") appears only in a comment beside the binder.

From the axiom alone, any single reduction makes every element of AlgElement G k equal to every other — proved below as degree_filtered_reduction_collapses_type, which needs no witness because it applies the axiom twice to the same nf_full.
