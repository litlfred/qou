    Elements of the free associative algebra, and their arithmetic #

    AlgElement G k is the raw carrier used throughout UGB.GrobnerShirshov: a coefficient function Monomial G → k together with a finite support that is only required to be a superset of the monomials carrying a non-zero coefficient.

    This module holds the type and all of its algebraic operations, so that Basic.lean — which needs subtraction, scalar multiplication and two-sided multiplication by monomials in order to state a reduction step — can use them without a cyclic import. (AlgOps.lean previously held them, but AlgOps imports Basic; the operations were moved here and Basic now imports this file. Nothing was renamed, and everything stays in the UGB.GrobnerShirshov namespace, so downstream references are unaffected.)

    The support field is not canonical #

    Because support may be strictly larger than {m | coeff m ≠ 0}, no mathematical statement about an element should be phrased in terms of it. Two AlgElements with the same coefficients but different supports denote the same element of k⟨G⟩. Hence:

    • AlgElement.isZero f means ∀ m, f.coeff m = 0, not f.support = ∅;
    • AlgElement.CoeffEq f g is the equality of elements that matters.

    support is retained only to keep sums over an element finite.

    Design notes #

    • Supports are supersets: add f g uses f.support ∪ g.support, which is valid but may overcount (cancellation). support_spec only requires zero coefficients outside the support.
    • DecidableEq on monomials: required for Finset.image and for the shape test in contextMul. Monomial G = List G, so DecidableEq G suffices.
    • No general multiplication: convolution on List G requires summing over all factorizations. What the rewriting theory actually needs is multiplication by a monomial on each side — contextMul a f b = a · f · b — and that is exact and cheap.

    References #

    • Bergman, The diamond lemma for ring theory, Adv. Math. 29 (1978), 178–218.

        structure UGB.GrobnerShirshov.AlgElement (G : Type u) (k : Type v) [Ring k] :
        Type (max u v)

        An element of the free associative algebra k⟨G⟩ over a ring k, represented as a finitely-supported linear combination of monomials.

        For the formalization we work abstractly: an element is a function from monomials to coefficients with finite support.

        • coeff : Monomial G → k

          Coefficient of each monomial.

        • support : Finset (Monomial G)

          The support is finite.

        • support_spec (m : Monomial G) : m ∉ self.support → self.coeff m = 0

          Coefficients outside the support are zero.

                              Context multiplication a · f · b: multiply f on the left by the monomial a and on the right by the monomial b.

                              This is the operation a rewriting step is built from — replacing an occurrence of a rule's leading monomial inside a larger word means subtracting c • (a · relation · b). It is exact (no convolution needed) because a and b are monomials: the coefficient of a ++ w ++ b is the coefficient of w, and every other monomial gets 0.

                                        A two-term relation in context is the same two terms, in context.

                                        Every rule in a two-term presentation — braid, far-commutation, Bokut–Shiao — has this shape, and an S-polynomial is built out of exactly two such context-multiplications. Computing one from the excise definition each time is the same case split every time; this does it once.

                                        The proof is the only place the shape condition has to be reasoned about: on the shape a ++ w ++ b both sides reduce to append-cancellation, and off it both sides are zero because a matching term would exhibit the missing w.
