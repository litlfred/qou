    normal_form_exists is false as stated #

    UGB.GrobnerShirshov.normal_form_exists (Basic.lean §6) asserts:

    given a Gröbner–Shirshov basis and any element f, there exists a normal form reachable from f.

    This is false. This file refutes it at a concrete instance: G = SU2Gen, k = ℤ, the deg-lex order, and the one-rule system whose single relation is 2·K.

    Why it fails #

    Two conditions that the framework treats as interchangeable are not:

    • isNormalForm is a condition on monomials — no rule's leading monomial occurs as an infix of a monomial carrying a non-zero coefficient;
    • taking a SingleStepReduction additionally requires solving c · lc(r) = f.coeff (a ++ lm(r) ++ b) for c — a condition on coefficients.

    When lc(r) is not invertible these come apart, and an element can be stuck: not in normal form, yet with no reduction available. Here lc = 2 is not a unit in ℤ, and f = K has coefficient 1, so a step would need c · 2 = 1.

    Nothing rules this system out. IsGrobnerShirshovBasis places no condition on leading coefficients, and this system satisfies it for a reason already in the tree: isGrobnerShirshovBasis_of_single_letter_rule — a one-rule system whose leading monomial is a single letter is a GS basis, because the length forces every composition to have empty contexts.

    What this costs #

    reduce is defined as (normal_form_exists …).choose, so it and everything through it — composition_lemma, retraction_property, buchberger, pbw_corollary, main_theorem_statement — currently rest on a false axiom, from which anything follows. The repair is normal_form_exists_of_unit_lc (CompositionLemma.lean): the same statement with IsUnit (r.lc ord) on every rule, proved from reduction_well_founded, and with the unused hgs dropped. Threading that hypothesis through reduce and its consumers is the migration this refutation motivates; it is not done here.

    Note the axiom's hgs argument is a red herring: this counterexample is a Gröbner–Shirshov basis. Strengthening the confluence hypothesis cannot rescue the statement, because the failure is about coefficients, not about overlaps.
