    Gröbner–Shirshov Bases — Foundational Definitions #

    This module provides the abstract algebraic framework for Gröbner–Shirshov (GS) bases in the context of non-commutative algebras presented by generators and relations. The key structures are:

    1. Monomial order — a well-order on monomials compatible with multiplication (admissible order).
    2. Rewriting system — oriented relations f ↦ f − lm(f) that reduce elements to normal form.
    3. Single-step and multi-step reduction — formalised as inductive relations, enabling proper termination and confluence statements.
    4. S-polynomial (composition) — the obstruction to confluence; the composition lemma asserts all S-polynomials reduce to zero.

    The elements themselves, and their arithmetic, live in Elem.lean.

    Three repairs (bean qou-auq3) #

    Earlier versions of this file were degenerate in three separate ways, and the predicate IsGrobnerShirshovBasis consequently held of everything:

    1. leadingMonomial (_ord) f hf := hf.choose ignored its order argument and returned an arbitrary element of the support. Every statement phrased with it — the composition decompositions, isNormalForm, SingleStepReduction — was therefore about an arbitrary monomial. It is now the ord-greatest support element (§2), with leadingMonomial_mem_support and le_leadingMonomial exported.
    2. SingleStepReduction did not relate f to g: its only field asked that some rule's leading monomial be an infix of some monomial of f and that no monomial of g exceed it — which g = 0 satisfies always. It now carries the equation g = f − c • (a · r.relation · b) (§3).
    3. OverlapComposition.spoly and InclusionComposition.spoly were free fields, never computed from the rules, so "the S-polynomial reduces to zero" constrained nothing. They are now definitions (§4). The composition structures also quantified their decomposition over every admissible order (lm₁_decomp : ∀ ord, …), which after repair (1) would have made them near-uninhabited and the GS predicate vacuous in the other direction; they now take the order as a parameter.

    The acceptance test for the repair is UGB.GrobnerShirshov.Hecke's one_does_not_reduce_to_zero: the unit is in normal form for the Hecke system and is not zero, so "everything reduces to zero" no longer holds.

    structure UGB.GrobnerShirshov.AdmissibleOrder (G : Type u) :
    Type u

    An admissible monomial order: a well-order on monomials that is compatible with left and right multiplication (concatenation).

    lt a b means a is strictly smaller than b in the ordering.

    Compatibility: if a < b then c ++ a ++ d < c ++ b ++ d for all monomials c, d.

    • lt : Monomial G → Monomial G → Prop

      The strict order relation on monomials.

    • trichotomy (a b : Monomial G) : self.lt a b ∨ a = b ∨ self.lt b a

      The order is a strict linear order (trichotomy).

    • wf : WellFounded self.lt

      The order is well-founded (every non-empty set has a minimum).

    • left_compat (a b c : Monomial G) : self.lt a b → self.lt (c ++ a) (c ++ b)

      Left compatibility: a < b → c ++ a < c ++ b.

    • right_compat (a b d : Monomial G) : self.lt a b → self.lt (a ++ d) (b ++ d)

      Right compatibility: a < b → a ++ d < b ++ d.

                  structure UGB.GrobnerShirshov.SingleStepReduction {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) (f g : AlgElement G k) :
                  Prop

                  Single-step reduction, repaired (repair 2).

                  f → g when some rule r ∈ sys has its leading monomial occurring inside a monomial of f — say f has a non-zero coefficient at a ++ lm(r) ++ b — and g is obtained by subtracting the corresponding multiple of the relation:

                  g = f − c • (a · r.relation · b), with c · lc(r) = f.coeff(a·lm(r)·b).

                  The coefficient condition is what makes the step eliminate the monomial it targets: g.coeff (a·lm(r)·b) = 0. Two degenerate readings are excluded by it. Without f.coeff (a·lm(r)·b) ≠ 0 and the equation on c, the choice c = 0, g = f would be a legal step, → would be reflexive, and CompositionLemma.reduction_well_founded would be a false axiom. And the previous version — which asked only that lm(r) be an infix of some monomial of f, with no relation between f and g at all — admitted g = 0 from any f whatsoever.

                  Everything is stated on coefficients rather than on the support field, because that field is only a superset of the true support (see Elem.lean) and carries no mathematical content.

                  • exists_witness : ∃ rule_used ∈ sys.rules, ∃ (a : Monomial G) (b : Monomial G) (c : k), f.coeff (a ++ rule_used.lm ord ++ b) ≠ 0 ∧ c * rule_used.lc ord = f.coeff (a ++ rule_used.lm ord ++ b) ∧ g.CoeffEq (f.sub (AlgElement.smul c (AlgElement.contextMul a rule_used.relation b)))

                    There exists a rule, an occurrence of its leading monomial inside a monomial of f, and a coefficient, witnessing the step.

                          Overlap composition (intersection S-polynomial): given two rules whose leading monomials overlap, the S-polynomial is the difference of the two ways to reduce the overlap.

                          If lm(f) = a·b and lm(g) = b·c with overlap b, then S(f,g) = lc(g)·f·c − lc(f)·a·g — for monic rules simply f·c − a·g.

                          The composition lemma states that the rewriting system is a Gröbner–Shirshov basis iff every S-polynomial reduces to zero.

                                      §6 Existence of Normal Forms #

                                      The normal_form_exists axiom that used to stand here was FALSE, and is gone (bean qou-lzoo). NormalFormExistsRefutation.normal_form_exists_false proves its negation at G = SU2Gen, k = ℤ, sorry-free and depending on no framework axiom. The counterexample is the one-rule system with relation 2·K: it is a Gröbner–Shirshov basis, and the element K is stuck — not in normal form, because isNormalForm is a condition on monomials and the rule's leading monomial occurs; yet admitting no step, because a step must also solve c · lc(r) = 1 with lc(r) = 2, and 2 is not a unit in ℤ.

                                      The error was to read termination as "the stuck element is in normal form". Termination gives only "no infinite reduction sequence"; the two coincide exactly when every rule has an invertible leading coefficient — the hypothesis Bergman 1978 Thm 1.2 carries and the axiom dropped. hgs was a red herring: the counterexample satisfies it, so no confluence hypothesis could have rescued it.

                                      normal_form_exists is now a theorem with that hypothesis, and reduce is built from it, so nothing in the development rests on the false statement.

                                            §6 Reduction respects CoeffEq, and negation #

                                            Two facts the family theorems keep needing, and one obstacle worth recording.

                                            AlgElement is a representation: CoeffEq is the equality that means anything. But MultiStepReduction.refl is syntactic, so a coefficientwise-equal source cannot simply be substituted into a chain — MultiStepReduction f' f does not follow from CoeffEq f' f. The way through is congr_source below, whose conclusion is a disjunction: either the chain restarts at f', or f' was already coefficientwise the chain's endpoint. The refl case lands in the second disjunct, which is exactly what the syntactic constructor costs.
