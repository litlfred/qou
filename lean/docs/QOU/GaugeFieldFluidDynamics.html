    §1 Brane Fluid Data #

    source
    structure QOU.GaugeFieldFluidDynamics.BraneFluidData (M : Type u_1) :
    Type u_1

    Brane fluid data: a fluid on the brane whose viscosity is determined by the substrate parameter q.

    LaTeX: \label{sec:brane-fluid}

    • substrate : SubstrateParameter M

      The substrate parameter field q : M → ℝ.

    • viscosity : M → ℝ

      Viscosity field ν : M → ℝ, determined by q.

    • viscosity_nonneg (p : M) : 0 ≤ self.viscosity p

      Viscosity is non-negative.

    • viscosity_monotone (p₁ p₂ : M) : self.substrate.field p₁ ≤ self.substrate.field p₂ → self.viscosity p₂ ≤ self.viscosity p₁

      Viscosity decreases as q increases (deeper quantum ⟹ less viscous).
