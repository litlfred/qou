    Gröbner–Shirshov Bases — Foundational Definitions #

    This module provides the abstract algebraic framework for Gröbner–Shirshov (GS) bases in the context of non-commutative algebras presented by generators and relations. The key structures are:

    1. Monomial order — a well-order on monomials compatible with multiplication (admissible order).
    2. Rewriting system — oriented relations f ↦ f − lm(f) that reduce elements to normal form.
    3. Single-step and multi-step reduction — formalised as inductive relations, enabling proper termination and confluence statements.
    4. S-polynomial (composition) — the obstruction to confluence; the composition lemma asserts all S-polynomials reduce to zero.

    These definitions are self-contained and do not depend on the specific choice of algebra (U_q, Dist(G), etc.). Specialisations are in NormalForms.lean and StrongMultiplicativity.lean.

      structure QOU.GrobnerShirshov.AdmissibleOrder (G : Type u) :
      Type u

      An admissible monomial order: a well-order on monomials that is compatible with left and right multiplication (concatenation).

      lt a b means a is strictly smaller than b in the ordering.

      Compatibility: if a < b then c ++ a ++ d < c ++ b ++ d for all monomials c, d.

      • lt : Monomial G → Monomial G → Prop

        The strict order relation on monomials.

      • trichotomy (a b : Monomial G) : self.lt a b ∨ a = b ∨ self.lt b a

        The order is a strict linear order (trichotomy).

      • wf : WellFounded self.lt

        The order is well-founded (every non-empty set has a minimum).

      • left_compat (a b c : Monomial G) : self.lt a b → self.lt (c ++ a) (c ++ b)

        Left compatibility: a < b → c ++ a < c ++ b.

      • right_compat (a b d : Monomial G) : self.lt a b → self.lt (a ++ d) (b ++ d)

        Right compatibility: a < b → a ++ d < b ++ d.

                    structure QOU.GrobnerShirshov.SingleStepReduction {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) (f g : AlgElement G k) :
                    Prop

                    Single-step reduction: f reduces to g in one step if there exists a rule r ∈ sys whose leading monomial appears as a subword of some monomial in supp(f), and g is obtained by replacing that occurrence with the tail of r.

                    Abstractly: g has a strictly smaller leading monomial than f under the admissible order, and f - g lies in the ideal generated by the rules.

                    • exists_witness : ∃ rule_used ∈ sys.rules, ∃ target_monomial ∈ f.support, leadingMonomial ord rule_used.relation ⋯ <:+: target_monomial ∧ ∀ m ∈ g.support, ¬ord.lt target_monomial m

                      There exists a rule and target monomial witnessing the reduction step.

                            §4 S-Polynomials (Compositions) #

                            source
                            structure QOU.GrobnerShirshov.OverlapComposition (G : Type u) (k : Type v) [Ring k] :
                            Type (max u v)

                            Overlap composition (inclusion/intersection S-polynomial): given two rules whose leading monomials overlap, the S-polynomial is the difference of the two ways to reduce the overlap.

                            If lm(f) = a·b and lm(g) = b·c with overlap b, then S(f,g) = f·c − a·g (after leading-coefficient normalisation).

                            The composition lemma states that the rewriting system is a Gröbner–Shirshov basis iff every S-polynomial reduces to zero.

                            • rule₁ : ReductionRule G k

                              The first rule.

                            • rule₂ : ReductionRule G k

                              The second rule.

                            • left : Monomial G

                              The left context (monomials before the overlap).

                            • overlap : Monomial G

                              The overlap subword.

                            • right : Monomial G

                              The right context (monomials after the overlap).

                            • lm₁_decomp (ord : AdmissibleOrder G) : leadingMonomial ord self.rule₁.relation ⋯ = self.left ++ self.overlap

                              The leading monomial of rule₁ decomposes as left ++ overlap.

                            • lm₂_decomp (ord : AdmissibleOrder G) : leadingMonomial ord self.rule₂.relation ⋯ = self.overlap ++ self.right

                              The leading monomial of rule₂ decomposes as overlap ++ right.

                            • overlap_nonempty : self.overlap ≠ []

                              The overlap is non-empty.

                            • spoly : AlgElement G k

                              The S-polynomial itself (the difference of the two reductions).

                              Type (max u v)

                              Inclusion composition: when the leading monomial of one rule entirely contains that of another as a subword.

                              If lm(g) = a ++ lm(f) ++ b, then S(f,g) = g − c · a·f·b where c is the ratio of leading coefficients.

                              • outer : ReductionRule G k

                              • right : Monomial G

                                Right context.

                                §5 Gröbner–Shirshov Basis (Abstract Definition) #

                                source
                                structure QOU.GrobnerShirshov.IsGrobnerShirshovBasis (G : Type u) (k : Type v) [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) :
                                Prop

                                A rewriting system is a Gröbner–Shirshov basis if every S-polynomial (both overlap and inclusion compositions) reduces to the zero element under the rewriting system.

                                This is the abstract formulation of the composition lemma (Shirshov 1962, Bokut 1976, Bergman 1978).

                                • overlap_resolves (oc : OverlapComposition G k) : oc.rule₁ ∈ sys.rules → oc.rule₂ ∈ sys.rules → ∃ (nf : AlgElement G k), ReducesToNF ord sys oc.spoly nf ∧ nf.isZero

                                  Every overlap S-polynomial reduces to zero.

                                • inclusion_resolves (ic : InclusionComposition G k) : ic.inner ∈ sys.rules → ic.outer ∈ sys.rules → ∃ (nf : AlgElement G k), ReducesToNF ord sys ic.spoly nf ∧ nf.isZero

                                  Every inclusion S-polynomial reduces to zero.

                                  §6 Existence of Normal Forms #

                                  source
                                  axiom QOU.GrobnerShirshov.normal_form_exists {G : Type u} {k : Type v} [Ring k] [DecidableEq G] (ord : AdmissibleOrder G) (sys : RewritingSystem G k) (hgs : IsGrobnerShirshovBasis G k ord sys) (f : AlgElement G k) :
                                  ∃ (nf : AlgElement G k), ReducesToNF ord sys f nf

                                  Existence of normal forms: given a GS basis and any element f, there exists a normal form reachable from f.

                                  Justification: the admissible order ord is well-founded, and each single-step reduction strictly decreases the leading monomial. By well-founded induction on the Dershowitz–Manna multiset ordering, iterated reduction terminates in a normal form.

                                  This is axiomatised at the abstract level because the constructive proof requires a concrete single-step reduction function with explicit algebra operations (subtraction, scalar multiplication). Each concrete instantiation (U_q in NormalForms.lean, Dist(G) in Flatness.lean) provides these operations.

                                  Reference: Bergman 1978, Theorem 1.2 (existence part).
