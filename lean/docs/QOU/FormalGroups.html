    Formal Groups — QOU Interface #

    Re-exports the formal-groups integration results from the Fred 2005 dissertation and provides the QOU-specific categorical interface (strong multiplicativity via FrobeniusHopfData).

    The core definitions and theorems live in Fred2005.FormalGroups; this module bridges them into the QOU namespace.

    Structure #

    1. Re-exports — CommutativeFormalGroup, SkewedPoissonStructure, etc.
    2. Strong multiplicativity (categorical) — Frobenius relation on FrobeniusHopfData
    3. Connection to QOU jet prolongation — unit-root ↔ integrability bridge
    4. Gröbner–Shirshov bridge — connection to QOU.GrobnerShirshov.*

    Status #

    The Gröbner–Shirshov core (composition lemma, normal forms, flatness, strong multiplicativity) is now formalized in QOU.GrobnerShirshov.*. Remaining sorrys in Fred2005.FormalGroups mark results that depend on domain-specific integration arguments beyond the GS framework.

    §1 Re-exports from Fred2005 #

    All core formal-group structures and theorems are defined in Fred2005.FormalGroups. We re-export the namespace here so that downstream QOU modules can use unqualified names.

    §2 Strong Multiplicativity (Categorical Form) #

    The categorical form of strong multiplicativity operates on FrobeniusHopfData — the monoidal-category structure used in the QOU. This wraps the algebraic condition from [fred2005, Theorem 4.12] into the language of monoidal categories.

    source
    structure QOU.FormalGroups.StrongMultiplicativity (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] :
    Type (max u v)

    Strong multiplicativity condition (categorical form): the Frobenius relation (Id ⊗ m) ∘ (Δ ⊗ Id) = Δ ∘ m = (m ⊗ Id) ∘ (Id ⊗ Δ) is preserved under the Gröbner–Shirshov deformation of the distribution algebra.
