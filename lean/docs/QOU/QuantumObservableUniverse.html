    Chapter 1 — Quantum Observable Universe #

    Formalization of the foundational definitions and results from Chapter 1 of the QOU manuscript.

    LaTeX source: chapters/quantum-observable-universe.tex

    Structure #

    1. Categorical foundations — QuantumUniverse, FrobeniusHopfData, observability conditions, fibre functor, Tannaka–Krein gauge group.
    2. ℂ realisation — CR manifold data, instanton connections, state bundle.
    3. Substrate parameter and gauge group — specialisation map, quantum Planck constant.
    4. Reeb decomposition and particles — fermions, bosons, q-harmonic forms.
    5. q-Deformed operators — exterior derivative, Lie bracket, connection, Reeb vector field, Reeb flow, torsion leaves.
    6. Lemmas and propositions — irreducibility, self-duality, main commutative diagram.

    • [lusztig1993] G. Lusztig, Introduction to Quantum Groups, Birkhäuser 1993.

    structure QOU.FrobeniusHopfData (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] :
    Type (max u v)

    Frobenius–Hopf data in a monoidal category.

    An object A equipped with a Hopf algebra structure (μ, η, Δ, ε, S) and a Frobenius form λ : A → 𝟙 such that the pairing A ⊗ A → μ → A → λ → 𝟙 is non-degenerate and the Frobenius relation holds.

    LaTeX: used in \label{def:quantum-universe}, item (ii). Ref: [kock2004]

    • obj : C

      The underlying object in C.

    • mul : CategoryTheory.MonoidalCategoryStruct.tensorObj self.obj self.obj ⟶ self.obj

      Multiplication morphism μ : A ⊗ A → A.

    • unit : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ self.obj

      Unit morphism η : 𝟙 → A.

    • comul : self.obj ⟶ CategoryTheory.MonoidalCategoryStruct.tensorObj self.obj self.obj

      Comultiplication morphism Δ : A → A ⊗ A.

    • counit : self.obj ⟶ CategoryTheory.MonoidalCategoryStruct.tensorUnit C

      Counit morphism ε : A → 𝟙.

    • antipode : self.obj ⟶ self.obj

      Antipode morphism S : A → A.

    • frobeniusForm : self.obj ⟶ CategoryTheory.MonoidalCategoryStruct.tensorUnit C

      Frobenius form λ : A → 𝟙.

    • coevaluation : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ CategoryTheory.MonoidalCategoryStruct.tensorObj self.obj self.obj

      Coevaluation morphism η̃ : 𝟙 → A ⊗ A, the dual datum to the evaluation ev = μ ≫ λ : A ⊗ A → 𝟙. Together with ev, this exhibits A as self-dual in the monoidal category C.

    • pairing_snake_left : CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.rightUnitor self.obj).inv (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.coevaluation) (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).inv (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight (CategoryTheory.CategoryStruct.comp self.mul self.frobeniusForm) self.obj) (CategoryTheory.MonoidalCategoryStruct.leftUnitor self.obj).hom))) = CategoryTheory.CategoryStruct.id self.obj

      Snake identity (left). The composite A →[ρ⁻¹] A ⊗ 𝟙 →[A ◁ coev] A ⊗ (A ⊗ A) →[α⁻¹] (A ⊗ A) ⊗ A →[ev ▷ A] 𝟙 ⊗ A →[λ_] A equals id_A, where ev = μ ≫ λ. This is one half of the exact self-pairing making A self-dual.

    • pairing_snake_right : CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.leftUnitor self.obj).inv (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.coevaluation self.obj) (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).hom (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj (CategoryTheory.CategoryStruct.comp self.mul self.frobeniusForm)) (CategoryTheory.MonoidalCategoryStruct.rightUnitor self.obj).hom))) = CategoryTheory.CategoryStruct.id self.obj

      Snake identity (right). The composite A →[λ_⁻¹] 𝟙 ⊗ A →[coev ▷ A] (A ⊗ A) ⊗ A →[α] A ⊗ (A ⊗ A) →[A ◁ ev] A ⊗ 𝟙 →[ρ_] A equals id_A.

    • frobenius_relation : CategoryTheory.CategoryStruct.comp self.mul self.comul = CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.comul self.obj) (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).hom (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.mul))

      Frobenius relation: μ ≫ Δ = (Δ ▷ A) ≫ α ≫ (A ◁ μ). Comultiplication is a bimodule map — the defining axiom of a Frobenius object in a monoidal category.

              Involutive structure (†-structure / *-structure) on a monoidal category.

              A contravariant endofunctor † : C^op → C that is the identity on objects, satisfies f†† = f, and is compatible with the monoidal structure.

                The involution on morphisms: f† : Y ⟶ X for f : X ⟶ Y.

              • dagger_dagger {X Y : C} (f : X ⟶ Y) : self.dagger (self.dagger f) = f

                Involutivity: f†† = f.

              • dagger_comp {X Y Z : C} (f : X ⟶ Y) (g : Y ⟶ Z) : self.dagger (CategoryTheory.CategoryStruct.comp f g) = CategoryTheory.CategoryStruct.comp (self.dagger g) (self.dagger f)

                Contravariance: (g ∘ f)† = f† ∘ g†.

              • dagger_id (X : C) : self.dagger (CategoryTheory.CategoryStruct.id X) = CategoryTheory.CategoryStruct.id X

                Identity: id† = id.
