    §1 Jet Prolongation #

    source
    structure QOU.Torsion.JetProlongation (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] :
    Type (max u v)

    Jet prolongation data: the categorical jet object J¹(A) = A ⊗ Ω¹(A), where Ω¹(A) = ker(μ : A ⊗ A → A) is the bimodule of Kähler differentials.

    Given a Frobenius–Hopf object A in a monoidal category, the jet object inherits a Frobenius–Hopf structure because Ω¹(A) is a direct summand of A ⊗ A (via the non-degenerate Frobenius pairing).

    LaTeX: \label{prop:jet-prolongation}, Steps 1–2.

    • base : FrobeniusHopfData C

      The base Frobenius–Hopf object A.

    • jet : FrobeniusHopfData C

      The jet Frobenius–Hopf object J¹(A).

    • ascent : self.base.obj ⟶ self.jet.obj

      The ascent embedding ℓ : A ↪ J¹(A) (direct summand inclusion).

    • restriction : self.jet.obj ⟶ self.base.obj

      The restriction map r : J¹(A) → A (retraction of the ascent).

    • retraction : CategoryTheory.CategoryStruct.comp self.ascent self.restriction = CategoryTheory.CategoryStruct.id self.base.obj

      The restriction is a left inverse of the ascent: r ∘ ℓ = id_A. This is the key identity used in the descent involution proof.

    • ascent_preserves_mul : CategoryTheory.CategoryStruct.comp self.base.mul self.ascent = CategoryTheory.CategoryStruct.comp (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.ascent self.base.obj) (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.jet.obj self.ascent)) self.jet.mul

      The ascent preserves multiplication: ℓ ≫ jet.mul = (ℓ ⊗ ℓ) ≫ base.mul (ascent is a coalgebra morphism).

    • restriction_preserves_comul : CategoryTheory.CategoryStruct.comp self.restriction self.base.comul = CategoryTheory.CategoryStruct.comp self.jet.comul (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.restriction self.jet.obj) (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.base.obj self.restriction))

      The restriction preserves comultiplication: r ≫ base.comul = jet.comul ≫ (r ⊗ r).
