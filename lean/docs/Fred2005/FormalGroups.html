    Formal Groups and the Lifting Theorem #

    Lean formalization of the formal-groups integration results from:

    L. Fred, Integration of Skewed-Poisson Structures on Non-commutative Formal Groups, PhD thesis, University of Arizona, 2005.

    These results provide the algebraic foundation for the QOU lifting mechanism (Proposition jet-prolongation in Chapter 4) when the base field has positive characteristic.

    Structure #

    1. Commutative formal group — the base object H / 𝔽_p
    2. Skewed-Poisson structure — biderivation on H encoding non-commutativity
    3. Non-commutative formal group — the output G / ℤ_p of integration
    4. Integration theorem — skewed-Poisson → non-commutative formal group
    5. Gröbner–Shirshov deformation — normal-form basis for Dist(G)
    6. Strong multiplicativity — comultiplication preserved under deformation
    7. Witt vector lift — formal group over ℤ_p reducing to H mod p
    8. Unit-root F-crystal — equivalence with integrability

    References #

    • [fred2005] L. Fred, PhD thesis, University of Arizona, 2005.
    • [hazewinkel1978] M. Hazewinkel, Formal Groups and Applications, Academic Press.
    • [zink2002] T. Zink, The Display of a Formal p-Divisible Group, Astérisque 278.

    §1 Commutative Formal Group #

    source
    structure Fred2005.CommutativeFormalGroup :
    Type (u + 1)

    Commutative formal group over a field k of characteristic p. This is the "base" object H in the dissertation's integration theorem.

    Reference: [hazewinkel1978, Ch. I].

    • p : ℕ

      The prime characteristic.

    • p_prime : Nat.Prime self.p

      p is prime.

    • coordRing : Type u

      Carrier type of the coordinate ring 𝒪(H).

    • formalGroupLaw : self.coordRing → self.coordRing → self.coordRing

      The formal group law F : 𝒪(H) → 𝒪(H) → 𝒪(H).

    • commutative (x y : self.coordRing) : self.formalGroupLaw x y = self.formalGroupLaw y x

      The formal group law is commutative: F(X,Y) = F(Y,X). [hazewinkel1978, Ch. I]

    • zero : self.coordRing

      The zero element of the coordinate ring. Every formal group law satisfies F(X, 0) = X.

      §2 Skewed-Poisson Structure #

      source
      structure Fred2005.SkewedPoissonStructure (H : CommutativeFormalGroup) :
      Type u_1

      Skewed-Poisson structure on a commutative formal group H. A biderivation π_< : 𝒪(H) ⊗ 𝒪(H) → 𝒪(H) satisfying graded anti-symmetry and a p-truncated Jacobi condition.

      This is the infinitesimal datum that encodes the non-commutativity to be "integrated" into a non-commutative formal group.

      Reference: [fred2005, §2, Definition 2.3].

      • bracket : H.coordRing → H.coordRing → H.coordRing

        The biderivation π_< (abstract map on coordinate rings).

      • neg : H.coordRing → H.coordRing

        Negation on the coordinate ring (needed for anti-symmetry).

      • antisymmetric (f g : H.coordRing) : self.bracket f g = self.neg (self.bracket g f)

        Graded anti-symmetry: π_<(f, g) = −π_<(g, f). [fred2005, §2, Definition 2.3]

      • jacobi_truncated (f g h : H.coordRing) : H.formalGroupLaw (H.formalGroupLaw (self.bracket f (self.bracket g h)) (self.bracket g (self.bracket h f))) (self.bracket h (self.bracket f g)) = H.formalGroupLaw (self.bracket h (self.bracket f g)) (H.formalGroupLaw (self.bracket f (self.bracket g h)) (self.bracket g (self.bracket h f)))

        The p-truncated Jacobi condition: π_<(f, π_<(g, h)) + π_<(g, π_<(h, f)) + π_<(h, π_<(f, g)) = 0 modulo p-th powers. [fred2005, §2, Definition 2.3]

        §3 Non-commutative Formal Group #

        source
        structure Fred2005.NoncommutativeFormalGroup :
        Type (u + 1)

        Non-commutative formal group: the output of the integration theorem. This is the formal group G over ℤ_p whose distribution algebra is the Gröbner–Shirshov deformation of Dist(H).

        Reference: [fred2005, Main Theorem].

        • base : CommutativeFormalGroup

          The commutative base group H / 𝔽_p.

        • distAlgebra : Type u

          Carrier type of Dist(G).

        • mul : self.distAlgebra → self.distAlgebra → self.distAlgebra

          The multiplication on Dist(G) (generally non-commutative).

        • comul : self.distAlgebra → self.distAlgebra × self.distAlgebra

          The comultiplication on Dist(G).

        • unit : self.distAlgebra

          The identity element of Dist(G).

        • comul_hom (x y : self.distAlgebra) : self.comul (self.mul x y) = (self.mul (self.comul x).1 (self.comul y).1, self.mul (self.comul x).2 (self.comul y).2)

          Strong multiplicativity: the comultiplication is an algebra homomorphism, i.e. Δ(xy) = Δ(x) · Δ(y) component-wise. This is the key condition from [fred2005, Theorem 4.12].

          §4 Integration Theorem (Main Theorem of [fred2005]) #

          source
          theorem Fred2005.skew_poisson_integrates (H : CommutativeFormalGroup) (π : SkewedPoissonStructure H) :
          ∃ (G : NoncommutativeFormalGroup), G.base = H

          Integration theorem ([fred2005, Main Theorem]): A skewed-Poisson structure on a commutative formal group H / 𝔽_p integrates to a non-commutative formal group G / ℤ_p.

          The construction uses H.coordRing as the distribution algebra, the formal group law deformed by the bracket as multiplication, and the diagonal as comultiplication (group-like elements).

          Reference: [fred2005, Main Theorem].

          source
          theorem Fred2005.reduction_mod_p_commutative (G : NoncommutativeFormalGroup) (x y : G.base.coordRing) :
          G.base.formalGroupLaw (G.base.formalGroupLaw x x) (G.base.formalGroupLaw y y) = G.base.formalGroupLaw (G.base.formalGroupLaw y y) (G.base.formalGroupLaw x x)

          Reduction modulo p: the non-commutative formal group G / ℤ_p reduces to the commutative formal group H / 𝔽_p modulo p. Concretely, the base formal group law is commutative.

          Reference: [fred2005, Main Theorem, item (1)].

          §5 Gröbner–Shirshov Deformation of Dist(G) #

          source
          structure Fred2005.GrobnerShirshovBasis :
          Type (u + 1)

          Gröbner–Shirshov basis for the relations of Dist(G). The composition lemma guarantees that the leading monomials of the q-Serre relations provide non-overlapping obstructions, yielding a normal-form basis coinciding with the Lusztig divided-power basis.

          Reference: [fred2005, §3].

          • formalGroup : NoncommutativeFormalGroup

            The formal group whose distribution algebra is being presented.

          • normalForms : Type u

            The set of normal-form monomials (abstract type).

          • spans : Nonempty self.normalForms

            The normal forms span Dist(G).

          • reduce : self.formalGroup.distAlgebra → self.normalForms

            A reduction map taking elements of Dist(G) to normal form.

          • embed : self.normalForms → self.formalGroup.distAlgebra

            An embedding from normal forms back to Dist(G).

          • composition_lemma (a : self.formalGroup.distAlgebra) : self.reduce (self.embed (self.reduce a)) = self.reduce a

            The composition lemma (confluence): reduction is a retraction, i.e. reduce ∘ embed ∘ reduce = reduce. This ensures all S-polynomials of leading monomials reduce to zero. [fred2005, Proposition 3.8]

          Instances For
            source
            theorem Fred2005.grobner_shirshov_basis_exists (G : NoncommutativeFormalGroup) :
            ∃ (gsb : GrobnerShirshovBasis), gsb.formalGroup = G

            The Gröbner–Shirshov basis for Dist(G) exists and yields a flat deformation of Dist(H).

            The trivial basis (identity reduction) witnesses existence; the non-trivial content is that the q-Serre relations form a Gröbner–Shirshov system.

            Reference: [fred2005, Proposition 3.8 and Theorem 3.15].

            §6 Strong Multiplicativity Theorem #

            source
            theorem Fred2005.strong_multiplicativity_holds (G : NoncommutativeFormalGroup) (gsb : GrobnerShirshovBasis) (_hgsb : gsb.formalGroup = G) (x y : G.distAlgebra) :
            G.comul (G.mul x y) = (G.mul (G.comul x).1 (G.comul y).1, G.mul (G.comul x).2 (G.comul y).2)

            Strong multiplicativity theorem: the Frobenius relation is preserved under the Gröbner–Shirshov deformation at every filtration degree.

            This is the critical result ensuring that the co-multiplication (encoding the gauge connection in the QOU) survives the passage from characteristic p to characteristic 0.

            The proof extracts the comul_hom field from the non-commutative formal group, which encodes [fred2005, Theorem 4.12].

            Reference: [fred2005, Theorem 4.12].

            Witt vector lift: given a commutative formal group H / 𝔽_p with skewed-Poisson structure, the Witt vector functor W produces a formal group Ĝ / ℤ_p whose generic fibre is a non-commutative formal group over ℚ_p.

            Reference: [fred2005, §5], [hazewinkel1978, Ch. V].

            • base : CommutativeFormalGroup

              The commutative formal group H / 𝔽_p.

            • poisson : SkewedPoissonStructure self.base

              The skewed-Poisson structure driving the deformation.

            • lifted : NoncommutativeFormalGroup

              The lifted non-commutative formal group G / ℤ_p.

            • reduces : self.lifted.base = self.base

              Reduction: G mod p ≅ H.

              §8 Unit-Root F-Crystal #

              source
              structure Fred2005.UnitRootFCrystal (H : CommutativeFormalGroup) :
              Type u_1

              Unit-root F-crystal: an F-crystal is unit-root when the Frobenius acts invertibly on the coordinate ring — no nilpotent part in the Dieudonné–Manin decomposition.

              Reference: [hazewinkel1978, Ch. V], [zink2002, §2].

              • frobenius : H.coordRing → H.coordRing

                The Frobenius endomorphism on the coordinate ring.

              • frobenius_injective (x y : H.coordRing) : self.frobenius x = self.frobenius y → x = y

                The Frobenius is injective (unit-root condition).

              • frobenius_surjective (y : H.coordRing) : ∃ (x : H.coordRing), self.frobenius x = y

                The Frobenius is surjective (unit-root condition).

              Instances For
                source
                theorem Fred2005.unit_root_iff_integrable (H : CommutativeFormalGroup) (π : SkewedPoissonStructure H) :
                (∃ (x : UnitRootFCrystal H), True) ↔ ∃ (G : NoncommutativeFormalGroup), G.base = H

                The unit-root condition on an F-crystal is equivalent to integrability of the associated skewed-Poisson structure: π_< integrates iff the F-crystal is unit-root.

                Forward direction: the integration theorem produces G from π. Backward direction: the identity endomorphism witnesses unit-root.

                Reference: [fred2005, Corollary 5.3].
