    class QOU.Appendix.DeltaMaxNumericalScale.DeltaMaxNumericalScaleContext :
    Type

    Context for the uniform Δ_max scale bound.

    Restated 2026-08-21 (vacuity ledger, proof-no-trivial-true / reflexive-tautology-ascribed-literal). The class previously carried the single field holds : (1 : ℝ) = 1 — provable by rfl, so it constrained no instance at all, and the theorem below projected it to conclude (1 : ℝ) = 1: vacuous with or without an instance.

    The fields now state the actual hypothesis the appendix block names — that Δ_max is uniformly bounded by a positive scale. The bound is carried as a parameter, not a numeral: the block's numerical value is not derived anywhere in the corpus, and inventing one here would be a fit. Supplying it is the open work (bean qou-7fyw).

    • bound : ℝ

      The uniform bound on the jet-filtration defect.

    • bound_pos : 0 < bound

      The bound is a genuine (positive) scale.

    • deltaMax : ℝ

      The quantity being bounded.

    • deltaMax_abs_le : |deltaMax| ≤ bound

      The uniform bound holds.

      -DeltaMaxNumericalScaleContext.bound ≤ DeltaMaxNumericalScaleContext.deltaMax ∧ DeltaMaxNumericalScaleContext.deltaMax ≤ DeltaMaxNumericalScaleContext.bound ∧ 0 < DeltaMaxNumericalScaleContext.bound

      Numerical scale of the uniform bound. From the uniform bound on |Δ_max|, the two-sided enclosure -bound ≤ Δ_max ≤ bound follows, and the bound is strictly positive so the enclosing interval is non-degenerate.

      §3b-conditional on DeltaMaxNumericalScaleContext: the bound itself is assumed, not established. The conclusion is derived from the hypothesis fields rather than projected from a conclusion field, so this is not a self-assuming projection.
