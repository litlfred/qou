    QOU.GaugeFieldFluidDynamics.QArithmetic — generic q-arithmetic #

    The algebraic half of the §7c split of QOU.GaugeFieldFluidDynamics (bean qou-q7cm). Everything here is stated over a generic {R : Type*} [Field R]: q-integers, the q-factorial and q-binomial, and the q-hook product with its small worked shapes. It names no real-number type, no order relation and no archimedean construct anywhere in its code.

    The archimedean material that used to sit interleaved with this — the sign lemmas about qInteger (which assume the substrate parameter exceeds one), the real-valued Markov parameter, and the whole brane-fluid / Navier–Stokes development — stays in QOU.GaugeFieldFluidDynamics, which imports this module. Per AGENTS.md §7c a block belongs to the algebraic substrate or the archimedean specialisation, never both; this file is the substrate side.

    (Those constructs are described in words rather than written out: the q-regime detector greps this file, so a worked example in a docstring would score the module archimedean — the very false positive this split exists to remove.)

    Known residual detector artefact. detectRegimes still tags this module real-positive, because syt3_squares_sum_eq_six closes a statement about natural numbers with norm_num, and that tactic name is on the archimedean marker list. The proof is 1² + 2² + 1² = 6 over ℕ — nothing archimedean is involved. The sibling checker q-usage-archimedean-in-categorical-chapter already guards this case (it only fires on a tactic when the file also carries a real-typed marker); detectRegimes does not. The authoritative gate, wall-side-correct, passes. Do not rewrite the proof to appease the tag.

    Same namespace as the parent, so every existing call site is unchanged.

      theorem QOU.GaugeFieldFluidDynamics.qInteger_succ {R : Type u_1} [Field R] (q : R) (n : ℕ) (hq : q - q⁻¹ ≠ 0) (_hq0 : q ≠ 0) :
      qInteger q (n + 1) = q * qInteger q n + q⁻¹ ^ n

      Recursion for q-integers: [n+1]_q = q · [n]_q + q⁻ⁿ for q ≠ q⁻¹. Equivalently expanded as a sum of monomials, [n]_q = q^(n-1) + q^(n-3) + … + q^(-(n-1)) (n terms).

      Algebraic proof: using qInteger q (n + 1) = (q^(n+1) − q⁻^(n+1))/(q − q⁻¹), one rearranges the numerator q^(n+1) − q⁻^(n+1) = q · (q^n − q⁻^n) + q⁻ⁿ · (q − q⁻¹) which yields the recursion after dividing by q − q⁻¹.

        q-binomial coefficient [n choose k]_q := [n]_q! / ([k]_q! · [n−k]_q!). Note: this is the ratio definition; when q − q⁻¹ ≠ 0 and the denominator is non-zero (always true at generic q) the result is a well-defined rational.
