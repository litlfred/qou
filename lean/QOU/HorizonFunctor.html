    QOU.HorizonFunctor #

    Canonical declaration for content block at quantum-observable-universe/information-theory/horizon-functor.ts.

    Formalises the manuscript horizon functor ∂ : π₀(Bun°(ℙ(V))) → 𝒫(Bun ∖ Bun°) sending each aeon 𝒜 to its boundary — the configurations that are limits of diagrams in 𝒜 but have A₀|_𝒮 = 0 (hence lie outside the observable subcategory Bun°).

    Naming note. The codomain is a power set 𝒫(…), so ∂ is encoded as the set-valued map boundary : Aeon → Set Config — an object-level map, not a CategoryTheory.Functor (no morphism-map/laws). This matches the manuscript, which writes the target as 𝒫(…) and observes ∂ degenerates to the identity on component inclusions. "Functor" is a naming convention here.

    structure QOU.HorizonFunctor :
    Type 1

    Data for the horizon functor.

    A definition carrier: the ambient configurations Config, the aeons Aeon = π₀(Bun°), the observability predicate, and the boundary map ∂, with the defining property that the boundary lands in the non-observable complement (A₀ = 0).

    • Config : Type

      Objects of the ambient bundle category Bun(ℙ(V)).

    • Aeon : Type

      Aeons π₀(Bun°) (connected components of the observable subcategory).

    • observable : self.Config → Prop

      Observability predicate (membership in Bun°).

    • boundary : self.Aeon → Set self.Config

      The horizon / boundary map ∂.

    • boundary_nonobservable (𝒜 : self.Aeon) (c : self.Config) : c ∈ self.boundary 𝒜 → ¬self.observable c

      The boundary of an aeon consists of non-observable configurations (A₀|_𝒮 = 0) — it lands in Bun ∖ Bun°.

      De-axiomatisation (bean bqfr): a genuine topological horizon. Over any topological space of configurations with a real degree-0 section A₀, an aeon is a region and its horizon is the topological frontier of the region intersected with the A₀ = 0 locus. frontier is Mathlib's real closure-minus-interior — the genuine "limits of diagrams in the aeon" operator — so boundary_nonobservable is a theorem (the boundary lies in {A₀ = 0} by construction), not an assumption.
