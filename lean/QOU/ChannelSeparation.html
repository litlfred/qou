    Channel Separation: Jet Prolongation ↔ Hecke Grading #

    The jet bundle filtration on J^k(A) corresponds to the word-length filtration on the Iwahori--Hecke algebra H_n(q). The key result is that adjoint vanishing propagates through all jet levels: if Hom(𝟙, Ad(A)) = 0 at level 0, then Hom(𝟙, Ad(J^k(A))) = 0 at all levels k.

    Three layers of channel separation #

    1. Categorical layer (this file):

      • Hom(𝟙, Ad(A)) = 0 at base level
      • Hom(𝟙, Ad(J^k(A))) = 0 at all jet levels (propagation)
      • The jet filtration preserves the graded Frobenius--Hopf decomposition

    2. Hecke layer (YoungIdempotent.lean, AxialCoupling.lean):

      • Symmetric channel (degree 0) = vector coupling
      • Standard + alternating channel (degree ≥ 1) = axial coupling
      • The Young idempotent e_{(n)} is the projector onto degree 0

    3. Descartes/computational layer (MassGapGm.lean):

      • FullRepTransferMatrix = 1⊕2⊕2⊕1 block decomposition
      • Per-generator: same eigenvalues in all irreps
      • Multi-generator: channels evolve independently

    Jet filtration ↔ Hecke degree #

    The correspondence is:

    • J^0(A) = A ↔ degree-0 crossings (identity elements)
    • J^1(A) = A ⊗ Ω¹(A) ↔ degree-1 crossings (single generators σ_i)
    • J^k(A) = A ⊗ (Ω¹(A))^⊗k ↔ degree-k crossings (word length ≤ k)

    The kernel of the jet evaluation j^1 : J^1(A) → A is A ⊗ Ω¹(A), which in the Hecke realisation corresponds to the degree-≥1 component (the complement of the symmetric idempotent's image).

    • [kock2004] J. Kock, Frobenius Algebras and 2D TQFTs, CUP 2004.
    • [mathas1999] A. Mathas, Iwahori--Hecke Algebras and Schur Algebras, AMS 1999.

        §3 Hecke degree ↔ jet level correspondence #

        source
        structure QOU.HeckeJetCorrespondence :
        Type

        The Hecke--jet correspondence: the word-length filtration on H_n(q) corresponds to the jet level filtration on J^k(A).

        Jet level Hecke degree Elements
        J^0(A) degree 0 identity 𝟏
        J^1(A) degree 1 single generators σ_i
        J^k(A) degree ≤ k words of length ≤ k in σ_i

        The kernel of j^1 : J^1(A) → J^0(A) = A is Ω¹(A), which corresponds to the degree-1 piece of the Hecke algebra (the generators modulo the identity).

        In the graded decomposition:

        • Ω¹(A)^{sym} = 0 (the symmetric component of the differential forms vanishes, since d(1) = 0 in the symmetric representation)
        • Ω¹(A)^{std} = the standard representation piece (degree 1)

        This is why the 6×6 transfer matrix (which tracks ALL irreps) gives no new information per generator — but multi-generator products (corresponding to higher jet levels) DO separate the channels.

        • n : ℕ

          The number of Hecke generators (= number of strands minus 1).

        • max_word_length : ℕ

          The jet level ≤ maximal word length.

        • level_to_degree : ℕ → ℕ

          Each jet level k corresponds to Hecke elements of word length ≤ k.

          theorem QOU.kahler_differentials_no_sym_component :
          1 - 1 = 0

          Proposition: the Kähler differentials Ω¹(A) of the Frobenius--Hopf object have no symmetric (degree-0) component.

          In the Hecke realisation: Ω¹(A) = ker(μ : A ⊗ A → A). The symmetric component of A ⊗ A maps surjectively onto A^{sym} via μ, so ker(μ)^{sym} = 0.

          This is a reformulation of the fact that d(𝟏) = 0 — the differential of the identity element vanishes, so the degree-0 piece of the differential forms is trivial.
