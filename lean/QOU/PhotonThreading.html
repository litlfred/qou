    Photon Threading = Gröbner Energy #

    The categorical mass of a hadron is defined as the Hecke cost of the augmented braid element in the GS framework. Gauge invariance (path-independence) is definitional: the energy depends on the hadron braid word, not on any choice of reduction path.

    Architecture #

    BraidWord.generators : List ℤ
  → augmentedBraidElement (HeckeGS)  → AlgElement (HeckeGen n) ℝ
  → heckeCost (HeckeGS)             → ℝ  (total |coefficient| sum)
  → crossingEnergy                   → ℝ  (× skein weight)
  → categoricalMass                  → ℝ  (× (q-1)²)

    The ThreadingReduction type is retained as a witness: it records the concrete Hecke steps for display/verification, but the energy is defined by the GS normal form, not by the witness.

            Gauge invariance (definitional) #

            source
            theorem QOU.PhotonThreading.crossing_energy_gauge_invariant {M : Type u_1} (sp : ArchimedeanSubstrateField M) (p : M) (hp : UGB.GrobnerShirshov.Hecke.HeckeParams) (β₁ β₂ : BraidWord) (hn : β₁.nStrands = β₂.nStrands) (hg : β₁.generators = β₂.generators) :
            crossingEnergy sp p hp β₁ = crossingEnergy sp p hp β₂

            Gauge invariance: the crossing energy depends only on the hadron braid word — concretely, on its strand count and its generator list. Two braid words that agree on nStrands and generators have equal crossing energy, regardless of any other (witness-only) data.

            This is the genuine content of "no reduction path to vary over": crossingEnergy is a function of (nStrands, generators) alone, so equality of those two fields forces equality of the energy. The proof rewrites along the two field equalities (the energy is not rfl-equal for distinct BraidWord records, only for ones agreeing on the data crossingEnergy reads).

            source
            theorem QOU.PhotonThreading.mass_gauge_invariant {M : Type u_1} (sp : ArchimedeanSubstrateField M) (p : M) (hp : UGB.GrobnerShirshov.Hecke.HeckeParams) (β₁ β₂ : BraidWord) (h : β₁.generators = β₂.generators) (hn : β₁.nStrands = β₂.nStrands) :
            categoricalMass sp p hp β₁ = categoricalMass sp p hp β₂

            Mass gauge invariance: same hadron → same mass. Same hadron means the same braid word: equal generator lists on the same number of strands (the strand count enters via the B_{n+1} photon-augmentation embedding).

            source
            theorem QOU.PhotonThreading.crossingEnergy_pos_of_nontrivial {M : Type u_1} (sp : ArchimedeanSubstrateField M) (p : M) (hp : UGB.GrobnerShirshov.Hecke.HeckeParams) (β : BraidWord) (hq : sp.field p > 1) (hcost : 0 < UGB.GrobnerShirshov.Hecke.heckeCost (UGB.GrobnerShirshov.Hecke.augmentedBraidElement hp β.generators)) :
            0 < crossingEnergy sp p hp β

            Key lemma: a non-trivial braid has strictly positive crossing energy when q > 1 and the Hecke cost of its augmented braid is non-zero.

            The Hecke cost being non-zero for a non-empty braid follows from the GS basis property: the augmented braid element has a unique normal form with at least one non-zero coefficient (since the identity element has cost 0 and the augmented braid of a non-trivial knot is not the identity in H_n(q)).

            We state this as a hypothesis hcost — the GS engine (Bokut–Shiao axiom) provides it for any specific braid word.
