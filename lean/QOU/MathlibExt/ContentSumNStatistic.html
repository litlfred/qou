    QOU.MathlibExt.ContentSumNStatistic — contentSum λ = n(λ') − n(λ) #

    The content-sum / n-statistic link that was, until now, only a prose comment in QPartitionCombinatorics (the note at def nLambda: "In terms of the conjugate, contentSum λ = n(λ') − n(λ)"). This is the algebraic half of the n-statistic identity κ_λ = Σ_x h_x − |λ| − 2·n(λ) that the telescope-closure convention bridge hconv turns on (audit docs/audits/2026-08-29-normalizedsum-closes-via-telescope.md): combined with the hook-sum identity Σ_x h_x = |λ| + n(λ) + n(λ') (Common.HookSumComplete.hookSum_eq) it gives κ_λ = Σ_x h_x − |λ| − 2·n(λ).

    contentSum λ = Σ_{(i,j)} (j − i) = Σ_{cells} j − Σ_{cells} i. The row part Σ_{cells} i = Σ_i i·λ_i is n(λ) = nLambda λ; the column part Σ_{cells} j, regrouped by column via the Fubini transpose IdentityI.cell_fubini, is Σ_j j·colLen(λ, j) = Σ_r r·(conj λ)_r = n(λ') = nLambda (conj λ).

    Purely combinatorial: List ℕ carrier, ℤ values, no ℝ, no analytic input.

    theorem QOU.MathlibExt.ContentSumNStatistic.contentSum_eq_nLambda_conj_sub (l : List ℕ) (hl : List.Sorted (fun (x1 x2 : ℕ) => x1 ≥ x2) l) :
    QPartitionCombinatorics.contentSum l = ↑(QPartitionCombinatorics.nLambda (BraidKnot.IdentityI.conj l)) - ↑(QPartitionCombinatorics.nLambda l)

    contentSum λ = n(λ') − n(λ) (the conjugate/n-statistic form of the content sum), for a weakly-decreasing partition λ. The content of a cell (i,j) is j − i; summing the j-part by columns gives n(λ') = nLambda (conj λ) and the i-part by rows gives n(λ) = nLambda λ.
