    The level-1 q-Borel (Jacobi-theta) kernel tₙ = q^{C(n,2)} = q^{n(n−1)/2}. This is the canonical kernel of the q-Borel transform B_{q,1} resolving an integral-slope singularity.

      theorem QOU.MathlibExt.QBorelKernel.qBorelKernel_succ {R : Type u_1} [Monoid R] (q : R) (n : ℕ) :
      qBorelKernel q (n + 1) = q ^ n * qBorelKernel q n

      The q-Borel kernel recurrence t_{n+1} = q^n · tₙ (the level-1 case tₙ = q^{n−1}·t_{n−1} of the RSZ family relation). Proof: C(n+1,2) = C(n,1) + C(n,2) = n + C(n,2) (Pascal), so q^{C(n+1,2)} = q^n · q^{C(n,2)}.
