    Full row rank ⇒ some r × r minor is nonzero #

    For M : Matrix (Fin r) (Fin n) K over a field, linearly independent rows force some r × r column selection to have nonzero determinant.

    Mathlib does not have this. It has the square characterisation (Matrix.linearIndependent_rows_iff_isUnit, m × m only) and the rank API (Matrix.rank, rank_eq_finrank_span_cols), but nothing connecting rank to minors of a rectangular matrix — there is no minor API outside Adjugate and PosDef.

    Why it is wanted here #

    This is the missing hypothesis of CauchyBinet.det_gram_map_ne_zero, which takes "one r × r minor of the integer matrix M is nonzero" and returns "det (N Nᵀ) ≠ 0 over every characteristic-zero field". Linear independence of the rows is what a caller actually has; a nonzero minor is what the Cauchy–Binet corollary wants. This file is the bridge, and det_gram_map_ne_zero_of_linearIndependent at the bottom is the composite:

    M : Matrix (Fin r) (Fin n) ℤ with ℚ-independent rows ⟹ det (N Nᵀ) ≠ 0 for N = M.map (Int.cast : ℤ → k), any [CharZero k].

    Proof route #

    Three moves, all at the level of column indices — never converting a set of column vectors back into a set of indices, which is where this argument usually gets painful in a proof assistant.

    1. Independent rows ⇒ M.rank = r (LinearIndependent.rank_matrix) ⇒ the columns span K^r, since rank is also the dimension of the column span.
    2. exists_linearIndepOn_extension extracts an index set b ⊆ Fin n whose columns are independent and still cover the rest. It is stated for LinearIndepOn, i.e. indexed by a set, so no vector-to-index step arises.
    3. Independent + spanning ⇒ b is a basis ⇒ b.card = r; enumerate b in increasing order with Finset.orderEmbOfFin to get the Selector, and the resulting square submatrix has independent columns, hence is a unit.

    The columns of a full-row-rank matrix span K^r. Row rank is column rank, so the column span has dimension r inside an r-dimensional space.

    Step 3 — the selector, and the minor it names #

    source
    theorem QOU.MathlibExt.RankMinor.exists_selector_det_ne_zero {K : Type u_1} [Field K] {r n : ℕ} (M : Matrix (Fin r) (Fin n) K) (hM : LinearIndependent K M.row) :
    ∃ (f : CauchyBinet.Selector r n), (CauchyBinet.minorA M f).det ≠ 0

    Full row rank ⇒ a nonzero maximal minor. Some strictly monotone selection of r columns has invertible square submatrix.

    This is the hypothesis CauchyBinet.det_gram_map_ne_zero asks for.

    Composite — the statement a caller actually has hypotheses for #

    An integer matrix with ℚ-independent rows has a nonsingular Gram matrix over every characteristic-zero field. Nothing here is ordered except ℤ, which is the whole point: the conclusion travels to ℂ without the form ever being positive definite there.

    The rank argument runs over ℚ (a field, so §1–3 apply), the sum of squares runs over ℤ (ordered, so Cauchy–Binet gives positivity), and only the final ≠ 0 crosses into k.

    The same, over arbitrary finite index types #

    Selector r n is Fin-indexed by construction (StrictMono needs an order), so everything above is stated for Matrix (Fin r) (Fin n). A caller's matrix is usually indexed by whatever its data is indexed by — a set of tableaux, a quotient — so it has to be reindexed through Fintype.equivFin first. That is pure bookkeeping and belongs here, not at each call site.
