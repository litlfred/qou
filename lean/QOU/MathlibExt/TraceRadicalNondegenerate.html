    The trace radical of a weighted block trace vanishes #

    Bean qou-cds1. Wedderburn-side infrastructure for the one open item left by QOU.MathlibExt.HeckeToTemperleyLieb:

    ⟨U_i U_j U_i − v²·U_i⟩ = traceRadical tr_M — the ⊇ half.

    That half says the Markov trace sees everything outside the ideal, i.e. the induced form on TL_n(δ) is nondegenerate. Once TL_n(δ) is known semisimple and its Markov trace is identified as a weighted sum of block traces, the nondegeneracy is pure algebra, and this file supplies it in the shape the application needs:

    A ≃ₐ[K] Π i, Matrix (d i) (d i) K      and      τ = Σ_i y_i · trace_i
with every  y_i ≠ 0                    ⟹        traceRadical τ = {0}.

    What was already in Mathlib, and what was not #

    The single-block case is in Mathlib and I nearly re-proved it. A first search for nondegenerate / trace.*eq_zero came back empty and I recorded the matrix trace form as a Mathlib gap; it is not one. Matrix.ext_iff_trace_mul_right (A = B ↔ ∀ x, (A * x).trace = (B * x).trace) is exactly nondegeneracy, phrased as an extensionality lemma, which is why a search on the word "nondegenerate" misses it. Recorded because the near-miss is the interesting part: the lemma you want may be in Mathlib under the shape it is used for rather than the name it is known by.

    The weighted-product case is genuinely absent, and it is the one the application needs — the Markov trace is not a block trace, it is a weighted sum of them, and the weights are what carry the physics.

    What this file does NOT do #

    It does not prove TL_n(δ) semisimple, and does not produce the AlgEquiv. That is the deep input, and it remains open. What is closed here is everything downstream of it: given the decomposition and nonzero weights, the radical is zero. The nonzero-weights hypothesis is already discharged in this corpus — QOU.QBeta.TemperleyLiebTower.yw_pos gives 0 < y_λ for 1 < q — so the decomposition is the sole remaining input.

    The weighted block trace τ(a) = Σ_i y_i · tr(a_i) on a finite product of matrix algebras.

    This is the shape of every Markov trace in this corpus: tr_M = Σ_λ y_λ χ_λ, with the y_λ the Wedderburn weights.

      The radical of a weighted block trace is zero exactly when no weight vanishes — the ← direction.

      If some y_j = 0 the j-th block is invisible to τ and lies in the radical; with every weight nonzero, testing against Pi.single j x isolates one block and matrix_eq_zero_of_forall_trace_mul finishes it.

      The weights are where the content is: this is the formal statement of "the trace sees every block".

      The nonzero-weight hypothesis cannot be dropped.

      If y j = 0 and the j-th block is not the zero algebra, then that whole block lies in the radical, so the radical is strictly bigger than {0}. The witness is the identity of the j-th block, sitting at j and zero elsewhere.

      Stated so that weightedBlockTrace_traceRadical_eq_zero's hypothesis is visibly load-bearing rather than decorative: with it the radical vanishes, without it — at any single index — it does not.

      The shape the Temperley–Lieb application needs.

      If A decomposes as a finite product of matrix algebras and τ is the weighted block trace pulled back along that decomposition, then τ has zero radical provided no weight vanishes.

      Applied to TL_n(δ): the two inputs are (i) the Wedderburn decomposition, still open, and (ii) y_λ ≠ 0, which QOU.QBeta.TemperleyLiebTower.yw_pos already supplies for 1 < q. So this reduces the ⊇ half of ⟨relators⟩ = traceRadical tr_M to the decomposition alone.
