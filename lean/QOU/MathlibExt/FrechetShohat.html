    QOU.MathlibExt.FrechetShohat #

    Moment-problem infrastructure for the balanced q-Borel kernel-convergence theorem (docs/audits/2026-07-25-kernel-convergence-mathlib-gap.md): the Stieltjes-moment predicate, moment-sequence determinacy, the Carleman condition, the unit Schwinger measure e^{−s}·ds with its factorial moments (PROVED), uniqueness of weak limits of probability measures (PROVED), and the two classical theorems Mathlib does not yet have — Fréchet–Shohat (moment convergence + determinate limit ⇒ weak convergence) and Carleman–Stieltjes determinacy — stated as content-bearing hypothesis classes (Mathlib-gap markers, §3b-tax; NO instance in this repo: an instance requires the genuine formalization, which would itself be an upstream Mathlib contribution).

    Mathlib-gap map (survey 2026-07-25, pin leanprover/lean4:v4.24.0) #

    EXISTS upstream (imported and used here):

    • weak-convergence topology on MeasureTheory.ProbabilityMeasure + ProbabilityMeasure.tendsto_iff_forall_integral_tendsto (Mathlib.MeasureTheory.Measure.ProbabilityMeasure); portmanteau characterizations (…Measure.Portmanteau); Lévy–Prokhorov metrizability (…Measure.LevyProkhorovMetric); tightness API (…Measure.Tight, TightNormed);
    • separation of finite measures by bounded continuous test functions: MeasureTheory.ext_of_forall_integral_eq_of_IsFiniteMeasure (Mathlib.MeasureTheory.Measure.FiniteMeasureExt); characteristic- function determinacy ext_of_charFun; complex-MGF determinacy ProbabilityTheory.ext_of_complexMGF_eq;
    • moments/mgf: ProbabilityTheory.moment, mgf, iteratedDeriv_mgf_zero (Mathlib.Probability.Moments.*);
    • the Gamma integral: Real.Gamma_eq_integral, Real.Gamma_nat_eq_factorial.

    MISSING upstream (the gap this module scaffolds around):

    • the Hamburger/Stieltjes moment problem as such (determinacy from moment-growth conditions);
    • Carleman's determinacy criterion (Σ M_k^{−1/(2k)} = ∞ ⇒ determinate) — class CarlemanDeterminacyStieltjes below;
    • Fréchet–Shohat / method of moments — class FrechetShohatStieltjes below;
    • Prokhorov's compactness theorem (tight ⇒ relatively compact) did not surface in the pinned olean survey; only the tightness definitions are present.

    The mgf-route determinacy that Mathlib DOES have (ext_of_complexMGF_eq) requires exponential integrability in a neighbourhood of 0 — strictly stronger than Carleman, and NOT satisfied uniformly by the q-Borel fibre kernels (the fibre problem is indeterminate, log-normal/Krein regime; see the audit §3.1), so it cannot replace the Carleman/Fréchet–Shohat package for the q→1 limit statement.

Billingsley, Probability and Measure, 3rd ed., Wiley 1995, Theorem 30.2; B. Simon, The classical moment problem as a self-adjoint finite difference operator, Adv. Math. 137 (1998) 82–203 (Carleman, Stieltjes case). q→1 confluence literature route: Di Vizio–Zhang, Ann. Inst. Fourier 59 (2009) 347–392 (divizio-zhang2009).

              class QOU.MathlibExt.FrechetShohat.CarlemanDeterminacyStieltjes :
              Prop

              Carleman–Stieltjes determinacy (classical theorem, Mathlib gap). If the moment sequence M (of genuine Stieltjes moment data, positive) satisfies the Carleman condition Σ_k M_k^{−1/(2k)} = ∞, the Stieltjes moment problem for M is determinate. Simon, Adv. Math. 137 (1998) 82–203, Cor. 4.5 / Thm. 5.14; Akhiezer, The Classical Moment Problem, 1965. QOU.Archimedean.BorelProperTimeMoment.carleman_divergence proves the hypothesis for M k = k!; this class carries the theorem itself.

                class QOU.MathlibExt.FrechetShohat.FrechetShohatStieltjes :
                Prop

                Fréchet–Shohat / method of moments (classical theorem, Mathlib gap), Stieltjes form with an explicit limit candidate. If probability measures μs n, all supported on [0,∞) with all moments finite, have k-th moments converging to M k for every k, and μ realizes the moment data M, and M is Stieltjes-determinate, then μs → μ in the topology of weak convergence. Fréchet–Shohat, Trans. AMS 33 (1931) 533–543; Billingsley, Probability and Measure, 3rd ed., Thm. 30.2. The uniqueness half is already provable (tendsto_probabilityMeasure_unique); the convergence half needs tightness-from-moments + Prokhorov/Helly selection, absent from the pinned Mathlib.
