    The bond rule reduces to its d = 0 case #

    QOU.MathlibExt.MarkovBondRule.BondRule carries the one trace-level input of the bond-product formula as an unproved hypothesis:

    tr (x * (σ_g + d • 1)) = (z + d) * tr x for g unused by x.

    This file removes the parameter d from that hypothesis, unconditionally. For any linear functional on any R-algebra,

    tr (x * (s + d • 1)) = tr (x * s) + d * tr x

    so the d-family holds for a given x, g iff its d = 0 member does (bondRule_iff_sigma_case). The whole (z + d) shape is a consequence of linearity; the mathematical content sits entirely in the single equation tr (x * σ_g) = z * tr x.

    This matters because it is exactly half of what qou-g8i1 has to prove, and it is the half that needs no Hecke-algebra machinery: a trace, an algebra, and linearity. The remaining half — the σ_g case — is where the Markov property and the unused-generator hypothesis actually do their work, and it stays open.

    Scope #

    Nothing here asserts the bond rule. bondRule_iff_sigma_case is an iff: it transports the hypothesis, it does not discharge it. MarkovLinear below is a plain bundling of "linear functional on an algebra" and is instantiated for the trivial example only, to show the structure is inhabited and therefore not vacuous.

    Base ring #

    Generic [CommRing R] and a generic R-algebra A. No ℝ, no q-specifics, no archimedean content — the statement is about linearity and nothing else.

      The bond rule holds for all d iff it holds at d = 0.

      The (z + d) family collapses to one equation. ↤ is the direction that matters: proving the single σ_g case yields the whole family.

      The structure is inhabited: the zero functional is a MarkovLinear.

      Present so MarkovLinear is demonstrably not an empty abstraction. It is a witness of inhabitation only — the zero functional satisfies the bond rule trivially for every z, so it is evidence about the definition's well-formedness and about nothing else.
