    QOU.MathlibExt.MatrixSemisimple — matrix rings over a division ring are semisimple #

    Fills (the division-ring case of) Mathlib's proof_wanted IsSemisimpleRing.matrix (RingTheory/SimpleModule/Basic.lean), the gap blocking the Prop-level semisimplicity corollaries of the QOU Wedderburn ladder (HeckeH2Wedderburn, HeckeH3Wedderburn).

    Route (bean qou-5mrn):

    1. Transitivity — over a division ring K, any nonzero vector reaches any vector under the Matrix.mulVec action (exists_smul_eq): the explicit matrix w ⬝ (eᵢ (v i)⁻¹)ᵀ does it.
    2. Column-module simplicity — hence n → K is a simple Matrix n n K-module (instIsSimpleModule_vec).
    3. Column decomposition — the regular module Matrix n n K decomposes Matrix-linearly into its columns (columnsEquiv : Matrix n n K ≃ₗ[Matrix n n K] (n → (n → K))).
    4. Assembly — the coordinate submodules of the Pi module are simple with join ⊤, so the Pi module is semisimple (sSup_simples_eq_top_iff_isSemisimpleModule), and the regular module inherits it along columnsEquiv (IsSemisimpleModule.congr): IsSemisimpleRing (Matrix n n K).

    The empty-index case is handled separately (the matrix ring is then a subsingleton, whose submodule lattice is trivially complemented).

    Upstream candidate: statements and names follow Mathlib conventions so the content can be PR'd against the proof_wanted upstream.

    -- Ref: [wenzl1988] https://doi.org/10.1007/BF01404457
