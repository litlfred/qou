    QOU.MathlibExt.Ribbon — balanced and ribbon monoidal categories #

    Mathlib supplies BraidedCategory, SymmetricCategory and Left/RightRigidCategory, but it has no balancing twist: measured against the pinned Mathlib, grep -rl "ribbon\|BalancedCategory" Mathlib/CategoryTheory/ returns a single unrelated file (Topos/Classifier.lean, where "balanced" means the epi-mono factorisation sense). There is no Mathlib/CategoryTheory/Monoidal/Ribbon.lean, and Monoidal/Rigid/ contains only Basic, Braided, FunctorCategory, OfEquivalence.

    This module is the candidate for upstream Mathlib/CategoryTheory/Monoidal/Ribbon.lean. It is stated over Mathlib's own BraidedCategory / RightRigidCategory and imports nothing from QOU, so it can be lifted verbatim.

    Main definitions #

    • BalancedCategory C — a braided monoidal category with a natural twist θ_X : X ⟶ X satisfying θ_{𝟙} = 𝟙 and the Joyal–Street balancing axiom θ_{X ⊗ Y} = β_{X,Y} ≫ β_{Y,X} ≫ (θ_X ⊗ θ_Y). Each θ_X is an isomorphism.
    • RibbonCategory C — a balanced right-rigid category whose twist is compatible with duality, θ_{Xᘁ} = (θ_X)ᘁ.

    Main statements #

    • BalancedCategory.ofSymmetric / RibbonCategory.ofSymmetric — non-vacuity: every symmetric monoidal category is balanced with the trivial twist θ = 𝟙, and every symmetric right-rigid category is ribbon. So neither class is conditional-on-False; both are inhabited across Mathlib's symmetric categories (ModuleCat R, …).
    • BalancedCategory.twistIso, twistNatIso — the twist packaged as an isomorphism and as a natural automorphism of 𝟭 C, which is the form the naturality axiom actually asserts.
    • BalancedCategory.inv_twist_naturality — the inverse twist is natural too.
    • BalancedCategory.twist_tensorUnit_right — the balancing axiom is consistent with θ_{𝟙} = 𝟙: at Y = 𝟙_C it reduces to naturality along the right unitor rather than to a new constraint. Derived, not assumed.
    • RibbonCategory.twist_dualDual — θ_{Xᘁᘁ} = (θ_X)ᘁᘁ.
    • RibbonCategory.rightAdjointMate_inv_twist — the mate of the inverse twist is the inverse of the dual's twist, (θ_X⁻¹)ᘁ = (θ_{Xᘁ})⁻¹.

    Scope #

    This is structure, not a theorem about any particular category: it names the datum the Reshetikhin–Turaev construction needs on top of braided-rigid. Nothing here is wired to compute and no numerical claim depends on it. Base ring (§7c): everything is stated over a generic Mathlib braided (right-rigid) category; no ℝ appears.

    References #

    • [joyal1993] Joyal, Street, Braided tensor categories, Adv. Math. 102 (1993) — the balancing axiom.
    • [turaev1994] Turaev, Quantum invariants of knots and 3-manifolds — ribbon categories and the ribbon trace.

          theorem QOU.MathlibExt.BalancedCategory.twist_tensor_three {C : Type u} [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] [BalancedCategory C] (X Y Z : C) :
          twist (CategoryTheory.MonoidalCategoryStruct.tensorObj X (CategoryTheory.MonoidalCategoryStruct.tensorObj Y Z)) = CategoryTheory.CategoryStruct.comp (β_ X (CategoryTheory.MonoidalCategoryStruct.tensorObj Y Z)).hom (CategoryTheory.CategoryStruct.comp (β_ (CategoryTheory.MonoidalCategoryStruct.tensorObj Y Z) X).hom (CategoryTheory.MonoidalCategoryStruct.tensorHom (twist X) (CategoryTheory.CategoryStruct.comp (β_ Y Z).hom (CategoryTheory.CategoryStruct.comp (β_ Z Y).hom (CategoryTheory.MonoidalCategoryStruct.tensorHom (twist Y) (twist Z))))))

          The twist on a three-fold tensor carries no irreducible three-body datum.

          Unfolding the balancing axiom twice: θ_{X ⊗ Y ⊗ Z} is built entirely from pairwise braidings (β_{X, Y⊗Z}, β_{Y⊗Z, X}, β_{Y,Z}, β_{Z,Y}) and single-object twists (θ_X, θ_Y, θ_Z). Nothing in it depends on the three objects jointly in a way that is not already a composite of two-object data. Three is the first arity at which a genuine many-body term could appear, and it does not.

          Scope of the resulting prune (read before citing this downstream) #

          This is a structural fact about the ribbon datum, in the sense of the "(b) structural exclusion" tier: the invariant is the balancing axiom itself, stated above and cited here. What it excludes is precise and narrow:

          • it does exclude any weight defined as a composite of twists and braidings on an A-fold tensor from carrying an irreducible three-or-more-body contribution — such a composite is always per-object data together with pairwise data;
          • it does not exclude the missing super-pairwise additive term in the many-body binding magnitude. That term is not claimed here to be ribbon-derived, and if it is not, this says nothing about it.

          The bridge between the two is a question about how the binding weight is defined, not a question about ribbon categories, and it is deliberately left open here. What the lemma does supply, if that bridge is made, is a reason of the right kind: the pairwise cap ρ_A ≤ C(A,2) recorded in the mass-theory development has exactly the shape this decomposition predicts — C(A,2) is the number of pairwise braidings the iterated balancing axiom produces.

            The twist commutes with double-dualisation: θ_{Xᘁᘁ} = (θ_X)ᘁᘁ. The ribbon axiom applied twice. The double dual is where the general quantum-dimension conjugation symmetry dim (Xᘁ) = dim X would live; that broader statement additionally needs a pivotal structure, which Mathlib does not provide either.
