    theorem QOU.MathlibExt.norm_jacobiTheta₂_sub_one_le (c a : ℝ) (ha : 0 < a) :
    ‖jacobiTheta₂ (-↑c) (Complex.I * ↑Real.pi / ↑a) - 1‖ ≤ 2 * Real.exp (-(Real.pi ^ 2 / a)) / (1 - Real.exp (-(Real.pi ^ 2 / a)))

    θ₂(−c, iπ/a) = 1 + O(e^{−π²/a}), uniformly in the real shift c.

    S = 0 in norm_jacobiTheta₂_term_le because (-c : ℂ) has zero imaginary part — that is what makes the bound uniform in c. n² ≥ |n| then converts the Gaussian tail into a geometric one.

    theorem QOU.MathlibExt.abs_tsum_gaussian_sub_sqrt_le (a c : ℝ) (ha : 0 < a) :
    |∑' (n : ℤ), Real.exp (-a * (↑n - c) ^ 2) - √(Real.pi / a)| ≤ √(Real.pi / a) * (2 * Real.exp (-(Real.pi ^ 2 / a)) / (1 - Real.exp (-(Real.pi ^ 2 / a))))

    The sharp Laplace sum. ∑_{n∈ℤ} e^{−a(n−c)²} is √(π/a) — the Gaussian integral — with a relative error that is exponentially small in 1/a and uniform in the shift c.
