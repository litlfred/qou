    Carrier bridge: List schurElement ↔ YoungDiagram schurPrincipal #

    The corpus carries two parallel Wenzl/Macdonald Schur-element developments on different carriers:

    • List carrier (X free) — QOU.MathlibExt.WenzlSchurElement.schurElement Q X lam on Partition = List ℕ, a nested fold over (i, j) with j < lam[i]. The Macdonald hook telescope is proved here only at n ≤ 3 (MacdonaldTelescope.telescope_one/two/three), with a general conditional M1 (jonesMarkov_normalisation_of_telescope).
    • YoungDiagram carrier (X = Q^r) — QOU.QBeta.WenzlWeight.schurPrincipal r Q μ on YoungDiagram, a Finset.prod over μ.cells. Here the general telescope is proved sorry-free (QOU.SchurWeyl.sum_dim_wenzlWeight_eq_one, general n, general level r).

    The two schurElement/schurPrincipal objects are the same hook–content formula Q^{n(λ)} · ∏_x (1 − X·Q^{c(x)})/(1 − Q^{h(x)}), but no Lean lemma connects them. This file builds that bridge, so the List-carrier low-rank results can be re-derived from — rather than duplicate — the already-proved general YoungDiagram telescope.

    Correspondence (at X = Q^r, μ = YoungDiagram.ofRowLens lam hl) #

    List side YoungDiagram side how they match
    cellContent i j = j − i content (i, j) = j − i definitional (this file, content_eq_cellContent)
    (lam[i]?).getD 0 (ofRowLens lam hl).rowLen i rowLen_ofRowLens
    Partition.hookLength lam i j hook (ofRowLens lam hl) (i, j) arm +1 / leg +1, needs hl sorted
    nLambda lam nPart (ofRowLens lam hl) ∑ i · row-length i
    nested fold over (i, j) ∏ x ∈ μ.cells cells = ⋃ᵢ {i} ×ˢ range(rowLen i)

    Status #

    Scaffold + the content-carrier match (content_eq_cellContent). The remaining bricks (hook-match, nPart = nLambda, product reindex, assembly) are the substantial part and land incrementally; the final target is

    schurElement Q (Q^r) lam = schurPrincipal r Q (YoungDiagram.ofRowLens lam hl).

    theorem QOU.MathlibExt.WenzlSchurElementBridge.schurElement_eq_schurPrincipal_of_hook (r : ℕ) (Q : ℝ) (hQ0 : Q ≠ 0) (lam : List ℕ) (hl : List.Sorted (fun (x1 x2 : ℕ) => x1 ≥ x2) lam) (hhook : ∀ (i j : ℕ), j < lam[i]?.getD 0 → QBeta.WenzlWeight.hook (YoungDiagram.ofRowLens lam hl) (i, j) = QPartitionCombinatorics.Partition.hookLength lam i j) :
    WenzlSchurElement.schurElement Q (Q ^ r) lam = QBeta.WenzlWeight.schurPrincipal r Q (YoungDiagram.ofRowLens lam hl)

    Assembly (B6), conditional on the hook match. Given that the YoungDiagram hook length agrees with the List hookLength on every cell of ofRowLens lam hl, the two Schur elements coincide at the principal specialisation X = Q^r:

    schurElement Q (Q^r) lam = schurPrincipal r Q (ofRowLens lam hl).

    The prefactors match by nPart_ofRowLens_eq_nLambda; the cell products match by prod_cells_ofRowLens, the content match (numerator, via Q^r · Q^{c} = Q^{r+c}, needs Q ≠ 0), and the hypothesis hhook (denominator). The single remaining ingredient for the unconditional bridge is hhook — i.e. hook_ofRowLens_eq_hookLength (B3, the sorted-list leg-length identity).

    theorem QOU.MathlibExt.WenzlSchurElementBridge.hook_ofRowLens_eq_hookLength (lam : List ℕ) (hl : List.Sorted (fun (x1 x2 : ℕ) => x1 ≥ x2) lam) (hpos : ∀ x ∈ lam, 0 < x) (i j : ℕ) (hj : j < lam[i]?.getD 0) :
    QBeta.WenzlWeight.hook (YoungDiagram.ofRowLens lam hl) (i, j) = QPartitionCombinatorics.Partition.hookLength lam i j

    Hook match (B3). For every cell (i, j) of ofRowLens lam hl (j < (lam[i]?).getD 0, lam weakly-decreasing and positive), the YoungDiagram hook length equals the List hookLength:

    hook (ofRowLens lam hl) (i, j) = Partition.hookLength lam i j.

    Both are (row_i − j) + leg, where the arm is row_i − j and the leg is the number of rows below i still reaching column j. The YoungDiagram column length is identified with the corpus list column length by QOU.Mathlib.colLen_rowLens (on rowLens_ofRowLens_eq_self), and the sorted-list leg identity colLen l j = (i+1) + cnt (l.drop (i+1)) j (QOU.Mathlib.SYTBeta.colLen_eq_succ_add_cnt_drop) supplies exactly the hookLength leg count ((lam.drop (i+1)).filter (· > j)).length.

    theorem QOU.MathlibExt.WenzlSchurElementBridge.schurElement_eq_schurPrincipal (r : ℕ) (Q : ℝ) (hQ0 : Q ≠ 0) (lam : List ℕ) (hl : List.Sorted (fun (x1 x2 : ℕ) => x1 ≥ x2) lam) (hpos : ∀ x ∈ lam, 0 < x) :
    WenzlSchurElement.schurElement Q (Q ^ r) lam = QBeta.WenzlWeight.schurPrincipal r Q (YoungDiagram.ofRowLens lam hl)

    The carrier bridge (unconditional). For a weakly-decreasing, strictly positive partition lam and Q ≠ 0, the List-carrier schurElement at the principal specialisation X = Q^r equals the YoungDiagram-carrier schurPrincipal:

    schurElement Q (Q^r) lam = schurPrincipal r Q (ofRowLens lam hl).

    This is schurElement_eq_schurPrincipal_of_hook with the hook match B3 supplying the hypothesis. It is the missing lemma connecting the two developments: the general Macdonald hook telescope is proved on the YoungDiagram carrier (QOU.SchurWeyl.sum_dim_wenzlWeight_eq_one), and this equality transports it to the List carrier.
