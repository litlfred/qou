    QOU.MathlibExt.SDP — Semidefinite-programming framework #

    A skeleton framework for semidefinite programming, built on top of Mathlib's Matrix.PosSemidef infrastructure. This is a candidate for upstream contribution to Mathlib/Analysis/Convex/SDP/Basic.lean or similar.

    What this module provides #

    • SDPPrimal — primal SDP problem data: cost operator T and a finitely-indexed family of equality-constraint operators A : ι → Matrix _ _ R with right-hand sides b : ι → R.
    • SDPPrimal.IsFeasible — predicate: Φ ⪰ 0 satisfies all constraints.
    • SDPPrimal.IsStrictlyFeasible (Slater) — Φ ≻ 0 with constraints met.
    • SDPDual — dual SDP: maximise Σ b_i y_i subject to T - Σ y_i A_i ⪰ 0.
    • HasStrongDuality — the headline (Boyd-Vandenberghe Thm 5.5) as a typeclass; concrete instances are the conjectural input.

    What this module does NOT yet prove #

    The full Boyd-Vandenberghe Theorem 5.5 requires Mathlib-side infrastructure (matrix-cone separation, KKT, value-function continuity) that is not yet available. We state strong duality as a typeclass; downstream uses bind to it without the proof.

    References #

    • [boyd-vandenberghe-2004] Boyd, Vandenberghe, Convex Optimization. https://doi.org/10.1017/CBO9780511804441
    • [todd2001] Todd, Semidefinite optimization, Acta Numerica 10 (2001). https://doi.org/10.1017/S0962492901000071

              §2 Strong duality (Boyd-Vandenberghe Theorem 5.5) #

              The headline result: if the primal SDP (P) is Slater-strictly feasible, then strong duality holds: inf{ ⟨T, Φ⟩ : Φ ⪰ 0, A_i Φ = b_i } = sup{ Σ b_i y_i : T - Σ y_i A_i ⪰ 0 }.

              The full proof requires convex-cone separation in Matrix.PosSemidef, KKT conditions for matrix-cone constraints, and value-function continuity. We package the conclusion as a typeclass; concrete instances are the conjectural input.

                  §2.1 Dual slack matrix #

                  The dual slack S(y) := T - Σ y_i A_i is the matrix whose positive-semidefiniteness encodes dual feasibility. For a dual- optimal y*, S(y*) is PSD and tr(S(y*) · Φ) = primal_obj(Φ) - Σ y*_i b_i = primal_obj(Φ) - dual_obj(y*). This is the core algebraic identity bridging primal/dual via complementary slackness.

                      §3 Strict complementarity → primal-optimum uniqueness #

                      The Boyd-Vandenberghe §5.5 strict-complementarity condition refines the strong-duality witness with active/inactive partition data. Under this strengthening, the primal optimum is unique (cf. Todd 2001 §3.4). We package both the certificate and the uniqueness conclusion so downstream consumers (QOU.BraidKnot.*) can apply them directly.

                      Strengthens StrongDualityPair with the active/inactive partition of the constraint indices. An index i is "active" iff its dual variable ystar i is strictly positive (constraint is binding); otherwise it is "inactive" with ystar i = 0.

                      Concrete fields:

                        Primal-optimum uniqueness — REMOVED (it was false) #

                        This module used to carry strict_complementarity_unique_axiom and two theorems consuming it: strict_complementarity_unique and strict_complementarity_optimum_subsingleton.

                        All three asserted false propositions and have been deleted. The refutation is QOU.MathlibExt.SDPUniquenessCounterexamples.not_strict_complementarity_unique (sorry-free, depending on no QOU axiom): take n = 1, no constraints and zero cost. Every PSD matrix is then feasible with the same objective, so Φ⋆ = 0 and Φ' = 1 both satisfy every hypothesis and the conclusion gives 1 = 0.

                        Alizadeh-Haeberly-Overton 1997 requires dual nondegeneracy for primal uniqueness, not strict complementarity alone; the deleted statement omitted it and was therefore strictly stronger than the theorem it cited.

                        Where uniqueness now lives. Uniqueness is an ordered-field fact and is not available over the generic R of this module, so it belongs downstream at ℝ:

                        • QOU.MathlibExt.SDPRealUniqueness.real_strict_complementarity_unique_of_dualSlack_posDef — the interior case, fully proved, hypothesis (sdp.dualSlack sc.ystar).PosDef.
                        • QOU.MathlibExt.SDPRealUniqueness.SDPSlaterUniqueness — the §3b-cond conditional class, with proven instances for the interior and active-empty-plus-cost-PosDef cases.

                        Every live QOU consumer has cost = 1 and no constraints, hence dualSlack = 1, which is positive-definite — so all of them satisfy the interior hypothesis and lose nothing by the change.
