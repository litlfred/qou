    QOU.MathlibExt.MonoidalCalcVar — Monoidal calculus of variations #

    A skeleton framework for variational equations of motion in monoidal categories. Candidate for upstream contribution to Mathlib/CategoryTheory/CalculusOfVariations/Basic.lean (the module does not yet exist; this is greenfield).

    What this module provides #

    • PairingSpace C X Y — the field space X ⊗ Y ⟶ 𝟙_ C: the pairings on an ordered pair of objects. Two tensor slots, so a member of it is a rank-2 object, and that is a fact about its type, not a claim about its name.
    • HasAction — a typeclass on a monoidal preadditive category C with a pair of objects X Y: an R-valued action functional on the field space.
    • contract η — the additive trace PairingSpace C X Y →+ End(𝟙_C) against a co-pairing η : 𝟙_ C ⟶ X ⊗ Y. This is the map that recovers the scalar.
    • VariationalData / ExternalCurrents — the Lagrangian decomposition and its sources, with the Einstein/stress/gravity triple rank-2 and the gauge/matter pair left scalar (see "What is and is not retyped" below).
    • HasMonoidalEOM typeclass — packaging the equations of motion.
    • einstein_contracted / einstein_contracted_comp — the bridge: the old scalar Einstein equation is the contraction of the rank-2 one.
    • subsingleton_of_contract_reflects — and the converse fails.

    Retyped 2026-09-15 (owner-authorised; bean qou-h0ou) #

    This module previously declared

    class HasAction (R : Type*) (C : Type u) … where
  action : ((𝟙_ C) ⟶ (𝟙_ C)) → R

    whose domain is End(𝟙_C) — the scalars. A variational derivative is an object on the field space, the thing being varied; an action whose field space is the scalars has a scalar derivative, and nothing in the type mentioned the objects being paired. Downstream, ExternalCurrents.einsteinTensor was typed (𝟙_ C) ⟶ (𝟙_ C): a scalar wearing a tensor's name. Einstein's equation is a rank-2 identity and a scalar cannot state one.

    The domain is now PairingSpace C X Y. The rank-2-ness is carried by what is varied, never by what the action's values are — see QOU.Variational.QuadraticAction.ofFunctional_variation (QOU/FrobeniusHopfData/PairingVariationalDerivative.lean), where an action built entirely out of a scalar reading still has a bilinear derivative.

    What is and is not retyped #

    gravity, einsteinTensor and stressTensor are rank-2. gauge, gaugeCurrent and matter are unchanged and remain scalars. That split is not a physical claim about which currents "are" tensors — it is forced by the equation gravity = einsteinTensor + stressTensor, whose three terms must inhabit one additive group. The Yang-Mills and transport equations relate different objects and are left exactly as they were, so the diff shows only what the Einstein identity requires.

    The bridge, and why this is a refactor rather than a replacement #

    contract η T = η ≫ T composes a rank-2 field with a co-pairing η : 𝟙_ C ⟶ X ⊗ Y and lands in End(𝟙_C) — the slot the module used to store. einstein_contracted derives the old scalar equation from the new rank-2 one, so nothing that was previously statable has been lost.

    subsingleton_of_contract_reflects is the other half: if equality of contractions implied equality of the rank-2 fields, uniformly in the co-pairing, the field space would have at most one element. The invariant is zero_comp — the degenerate co-pairing η = 0 contracts every field to the same scalar. So the scalar form is strictly weaker in any Preadditive monoidal category with two distinct pairings, and the retype is a strengthening rather than a rename.

    What the retype does NOT fix #

    hasMonoidalEOM_of_def still proves all three equations by rfl, because it defines vd as ⟨ec.einsteinTensor + ec.stressTensor, ec.gaugeCurrent, 0⟩. Retyping does not touch that: the tautology is orthogonal to rank, and an honest report of this change has to say so rather than imply the rfl was the defect being removed. einstein_split_iff states the residual problem exactly — the Einstein identity says only that the stress term is the residual gravity − einsteinTensor, and places no condition whatever on einsteinTensor. That is AGENTS.md §"Defined residual ≠ derived decomposition" in Lean, and it remains open.

    What is NOT claimed #

    No gravitational content: no metric, no curvature, no stress-energy realisation, no Newton constant, no 8π, no numerical constant of any kind. This module is about which types the equations of motion can be stated in. HasMonoidalEOM remains a typeclass — the equations are assumed at every use site, not derived, and retyping them does not make them proved.

    What this module does NOT yet prove #

    The classical calculus of variations (Wald, Bleecker, Kobayashi- Nomizu) lives in differential geometry. The categorical generalisation requires:

    • A categorical Lagrangian with respect to a connection
    • Internal variations as morphisms in C
    • An adjoint theory making the action functional varied with respect to a connection morphism

    The quadratic case is an exception and is now available: for a quadratic action the Gateaux derivative is algebraic, no limit is needed, and QOU.Variational.QuadraticAction supplies it sorry-free. Everything beyond quadratic remains open.

    Base ring (§7c) #

    Generic {R : Type*} throughout — nothing here performs an archimedean operation on the action value (no ordering, no Real.*, no numeric literal). A concrete instance at a real-analytic category supplies (R := ℝ).

                §3 Equations of motion (the headline conjecture) #

                The Wald-Bleecker-Kobayashi-Nomizu trio of EOMs in the categorical setting:

                • Einstein: gravity = G_λ + T_q — now an identity between pairings
                • Yang-Mills: gauge = J_ψ
                • Transport: matter = 0

                The full proof requires a categorical calculus of variations. The skeleton packages these three claims into a typeclass; concrete instances are the conjectural input.

                  §4 The bridge to the scalar form #

                  The point of the retype is that nothing previously statable is lost: the old scalar Einstein equation is a theorem about the new rank-2 one, obtained by contracting. The converse direction fails, which is what makes the rank-2 form strictly stronger.

                  source

                  The bridge. Contracting the rank-2 Einstein identity against any co-pairing η yields the scalar equation this module used to state directly.
