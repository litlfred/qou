    QOU.MathlibExt.PosSemidefTraceZero #

    The cone-self-polarity fact: for positive-semidefinite matrices A, B, tr(A · B) = 0 iff A · B = 0. This is the linear- algebraic core of SDP complementary slackness (Boyd-Vandenberghe §5.5) and the missing Mathlib piece for closing strict_complementarity_unique in QOU.MathlibExt.SDP.

    What this module proves #

    • Matrix.PosSemidef.trace_mul_eq_zero_iff_mul_eq_zero — the headline cone-self-polarity equivalence.
    • Matrix.PosSemidef.complementary_slackness — SDP-flavoured re-statement: if (T - Σy A) ⪰ 0, Φ ⪰ 0, and tr((T - Σy A) · Φ) = 0, then (T - Σy A) · Φ = 0.

    Mathematical content #

    Let A, B be n×n real (or complex) PSD matrices. Write A = U D U^* with U orthogonal, D diagonal with non-negative entries. Then tr(A B) = tr(U D U^* B) = tr(D U^* B U). Since U^* B U is congruent to B (hence still PSD), its diagonal entries are non-negative. So tr(A B) = Σ_i D_ii (U^* B U)_ii is a sum of non-negative terms, vanishing iff each term is zero. Tracing back: (U^* B U)_ii = 0 for all i with D_ii > 0, hence D · U^* B U = 0, hence A B = 0.

    This is the "self-polarity" of the PSD cone in matrix space (equipped with the Frobenius inner product ⟨A, B⟩ := tr(A^* B)).

    theorem QOU.MathlibExt.PosSemidefTraceZero.Matrix.PosSemidef.trace_mul_eq_zero_iff_mul_eq_zero {n : ℕ} {A B : Matrix (Fin n) (Fin n) ℝ} (hA : A.PosSemidef) (hB : B.PosSemidef) :
    (A * B).trace = 0 ↔ A * B = 0

    Cone self-polarity for PSD matrices (real case). For PSD matrices A, B : Matrix (Fin n) (Fin n) ℝ, tr(A · B) = 0 ↔ A · B = 0. The forward direction is the non-trivial half (the reverse is tr 0 = 0).

    PROOF SKETCH (forward):

    1. Diagonalise A = U D U^T with U orthogonal, D diagonal non-negative (via Matrix.PosSemidef.eigenvectorMatrix).
    2. tr(A B) = tr(U D U^T B) = tr(D U^T B U) (cyclic).
    3. U^T B U is PSD (orthogonal-similar to PSD B).
    4. tr(D U^T B U) = Σ_i D_ii · (U^T B U)_ii, each summand ≥ 0.
    5. Sum = 0 ⟹ each summand = 0 ⟹ on the support of D, the diagonal of U^T B U is zero ⟹ (PSD diagonal-zero ⟹ row+col zero) (U^T B U)_{ij} = 0 whenever D_ii > 0.
    6. Therefore D · U^T B U = 0, hence A · B = U D (U^T B U) U^T = 0.

    theorem QOU.MathlibExt.PosSemidefTraceZero.Matrix.PosSemidef.trace_mul_eq_zero_iff_mul_eq_zero_diagonal {n : ℕ} {a b : Fin n → ℝ} (ha : ∀ (i : Fin n), 0 ≤ a i) (hb : ∀ (i : Fin n), 0 ≤ b i) :
    (Matrix.diagonal a * Matrix.diagonal b).trace = 0 ↔ Matrix.diagonal a * Matrix.diagonal b = 0

    Diagonal sub-case of cone self-polarity.

    For diagonal PSD matrices A = diag(a), B = diag(b) with a, b : Fin n → ℝ non-negative, tr(A · B) = 0 ↔ A · B = 0.

    PROOF: A · B = diag(a_i * b_i), so tr(A · B) = Σ a_i b_i. Each summand is non-negative; sum zero ⟹ each summand zero ⟹ each a_i b_i = 0 ⟹ diagonal entries of A · B are zero ⟹ A · B = 0 (off-diagonal of a diagonal matrix is zero).

    This is the foundation for the general spectral argument: diagonalise A = U D Uᵀ, then the general case reduces to this diagonal case via cyclicity of trace.

    theorem QOU.MathlibExt.PosSemidefTraceZero.Matrix.PosSemidef.complementary_slackness {n : ℕ} {S Φ : Matrix (Fin n) (Fin n) ℝ} (hS : S.PosSemidef) (hΦ : Φ.PosSemidef) (h_gap : (S * Φ).trace = 0) :
    S * Φ = 0

    SDP complementary slackness (matrix form). If the dual slack S := T - Σ_i y_i A_i is PSD, the primal Φ is PSD, and the duality-gap measure tr(S · Φ) = 0, then S · Φ = 0. This is the bridge identity used in SDP-uniqueness arguments.

    theorem QOU.MathlibExt.PosSemidefTraceZero.Matrix.PosSemidef.kernel_containment_of_product_zero {n : ℕ} {S Φ : Matrix (Fin n) (Fin n) ℝ} (h_prod : S * Φ = 0) (j : Fin n) :
    (S.mulVec fun (i : Fin n) => Φ i j) = 0

    Kernel containment from complementary slackness. If S · Φ = 0, every column of Φ lies in the kernel of S. Combined with primal feasibility (Φ PSD with prescribed trace constraints) this pins Φ down to a low-dimensional subspace — the linear-algebraic core of SDP-optimum uniqueness.
