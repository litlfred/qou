    IsSemisimpleRing (Module.End R M)

    IsSemisimpleRing (Module.End R M) for any finite semisimple module — Mathlib's proof_wanted IsSemisimpleRing.module_end, in full.

    MathlibExt.EndSemisimple.isSemisimpleRing_end covers M a finite-dimensional vector space over a field. This is the general statement, with the same hypotheses the proof_wanted carries.

    Three steps, each already available:

    1. IsSemisimpleModule.exists_end_ringEquiv decomposes End R M ≃+* Π i, Matrix (Fin dᵢ) (Fin dᵢ) (End R Sᵢ) with each Sᵢ a simple submodule — this is the isotypic decomposition, and it is where Module.Finite is used;
    2. Schur's lemma (Module.End.instDivisionRing) makes each End R Sᵢ a division ring, so each block is semisimple by MatrixSemisimple.instIsSemisimpleRing_matrix;
    3. a finite product of semisimple rings is semisimple, and RingEquiv.isSemisimpleRing transports back.

    Note this does not need the general-base matrix result: the blocks land on division rings by Schur, which is precisely the case already proved.
