    QOU.MathlibExt.FrobeniusInnerProduct #

    The Frobenius inner product on matrices, ⟨A, B⟩_F := tr(A^T · B). This is the canonical inner-product structure for SDP analysis: the PSD cone is self-polar w.r.t. this inner product (PosSemidefTraceZero), the Frobenius norm ‖A‖_F := sqrt(⟨A, A⟩) is rotation-invariant, and the strict-convexity arguments needed for SDP uniqueness all live here.

    What this module provides #

    • Matrix.frobeniusInner — tr(A^T · B) as a real-valued inner product on Matrix (Fin n) (Fin n) ℝ.
    • Matrix.frobeniusInner_symm — symmetry.
    • Matrix.frobeniusInner_self_nonneg — non-negativity on the diagonal (Mathlib via Matrix.trace_transpose_mul_self_nonneg).
    • Matrix.frobeniusInner_self_eq_zero_iff — non-degeneracy.
    • Matrix.frobeniusNorm — sqrt of the diagonal value (extends to a Norm instance once paired with the metric topology).

    Categorical content #

    The Frobenius inner product makes Matrix (Fin n) (Fin n) ℝ into an inner-product space isomorphic to ℝ^(n²). This isomorphism transports Mathlib's Convex / StrictConvexOn machinery directly to the matrix setting — the key ingredient for closing strict_complementarity_unique in QOU.MathlibExt.SDP.
