    QOU.MathlibExt.TraceIsWeighted — every trace on a product of matrix algebras is weighted #

    QOU.MathlibExt.WeightedTraceGram computes the Gram determinant of weightedTrace c. It does not establish that the traces one cares about have that shape; its docstring asserted it as motivation. This file proves it.

    On A = ∏_i M_{d_i}(K), a linear functional t satisfying t(xy) = t(yx) is exactly weightedTrace c with

    c i = t (E^{(i)}_{aa}) (any diagonal matrix unit of block i).

    Two one-line matrix-unit identities do all the work, and both are consequences of the trace property, not extra hypotheses:

    • E_ab = E_aa · E_ab while E_ab · E_aa = 0 for b ≠ a — so a trace kills every off-diagonal unit;
    • E_aa = E_ab · E_ba and E_bb = E_ba · E_ab — so a trace is constant on the diagonal units of a block, which is what makes c i well defined independently of the chosen a.

    Why it is worth a file #

    It is the step that turns the Gram determinant into a statement about a named trace. In particular it is what lets the Wedderburn block weights of the canonical symmetrizing trace τ (QOU.Hecke.TauSymmetrizing, QOU.Hecke.TauStructureConstants) be defined rather than assumed — the abstract Schur element is 1 / c_λ, and without well-definedness of c_λ there is no such object.

    What is proved #

    • weightedTraceₗ — weightedTrace bundled as a LinearMap.
    • blockUnitBasis — the matrix units are a basis of the product; its elements are exactly blockUnit.
    • apply_blockUnit_of_ne / apply_blockUnit_diag_eq — the two identities.
    • eq_weightedTrace — the theorem.
    • blockWeight_eq — the weight read off any diagonal unit.

    Generic over [Field K] with no ordering and no archimedean structure, per the §7c base-ring convention.
