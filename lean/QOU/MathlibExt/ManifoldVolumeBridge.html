    §1 — Unconditional: relabelling a tetrahedron of a triangulation #

    No class, no hypothesis. This is the triangulation-level form of IdealTetrahedron.volume_rotate, and it is what makes "the volume of a triangulation" independent of how each tetrahedron happened to be labelled.

      §2 — The bridge, as a hypothesis #

      HyperbolicVolumeBridge M says: the type M has a real-valued volume, there is a notion of a triangulation realising an element of M, and a realising triangulation computes that volume.

      The third field is Thurston's theorem, not something proved here. That is exactly why this is a class with no instance rather than a definition.

      source
      class QOU.MathlibExt.HyperbolicVolumeBridge (M : Type u_1) :
      Type u_1

      The triangulation-to-manifold volume bridge, carried as an explicit hypothesis.

      No instance is provided, and providing one would be a defect unless it came with an actual theory of hyperbolic 3-manifolds. The point of the class is to make every downstream statement wear its dependence in its type.

      • vol : M → ℝ

        The volume of an element of M. Undefined in this corpus; supplied by the hypothesis.

      • Realises {n : ℕ} : IdealTriangulation n → M → Prop

        Realises T m : the ideal triangulation T realises the structure on m. Thurston's hyperbolisation is what would produce inhabitants of this.

      • vol_eq_of_realises {n : ℕ} (T : IdealTriangulation n) (m : M) : Realises T m → vol m = T.volume

        The bridge. A realising triangulation computes the volume. This is the hypothesis; the theorems below compose it rather than restate it.

      • realisable : ∃ (n : ℕ) (T : IdealTriangulation n) (m : M), Realises T m

        Non-triviality, and it is load-bearing. Without it the class admits the degenerate model Realises := fun _ _ => False, under which vol_eq_of_realises holds vacuously and the class asserts nothing about geometry -- the same failure the corpus records for the birthday axioms, where a two-valued function satisfies all six. That model was CONSTRUCTED and typechecked before this field was added; with the field it no longer elaborates. A carrier must assert something (AGENTS.md §3b-tax).

        Any two realising triangulations have the same volume.

        Derived, not projected: the bridge is applied to each triangulation and the two equations are composed. This is the statement that would make "the volume of the manifold" well defined, and it is the first thing one would want from the bridge.
