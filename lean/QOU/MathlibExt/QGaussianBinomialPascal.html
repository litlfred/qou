    QOU.MathlibExt.QGaussianBinomialPascal — q-Pascal + concrete Rogers–Szegő #

    Companion to QPartitionCombinatorics (bean 5ldf, epic 08a2). Supplies the q-Pascal recurrence for the Gaussian binomial qBinom, the primitive that #2807's qBinom shipped without, derived from the qBracket_add addition identity (#2817), and the concrete balanced Rogers–Szegő polynomial H_n(t;q) = Σ_k [n choose k]_q tᵏ.

    The q-Pascal rule is stated in the m-parametrised form (n = k+1+m) so every index is a sum, never a Nat subtraction — the cleanest shape for downstream rewriting.

    Normalization caveat — balanced H_n does NOT instantiate FollowsRogersSzego #

    QOU.Mass.BindingQHermiteOscillator.FollowsRogersSzego (#2800) encodes the standard three-term recurrence H_{m+2} = (1+t)H_{m+1} − (1−q^{m+1})·t·H_m. That holds for the standard (q;q)-normalized Rogers–Szegő (QOU.Machinery.QPochhammer.qBinomial). The qBinom here is the balanced (qⁿ−q⁻ⁿ)/(q−q⁻¹) binomial, whose q-Pascal carries q^{±} factors; feeding it through the same derivation gives a scaled-argument q-difference relation (mixing H_n(t) and H_n(t/q)), not the clean (1−qⁿ) 3-term. So the concrete balanced H_n below is a faithful object with verified low-order values, but instantiating the standard class needs the standard q-Pascal — a separate follow-on (bean 5ldf).

    theorem QOU.MathlibExt.QPartitionCombinatorics.qBinom_pascal {q : ℝ} (hq : 1 < q) (k m : ℕ) :
    qBinom q (k + m + 2) (k + 1) = q ^ (m + 1) * qBinom q (k + 1 + m) k + q ^ (-(↑k + 1)) * qBinom q (k + 1 + m) (k + 1)

    q-Pascal rule for the Gaussian binomial (q > 1, m-parametrised, n = k+1+m): [k+m+2 choose k+1]_q = q^{m+1}·[k+1+m choose k]_q + q^{-(k+1)}·[k+1+m choose k+1]_q. Derived from qBracket_add via the qFactorial ratio — the recurrence behind the Rogers–Szegő / continuous q-Hermite three-term relation.

      theorem QOU.MathlibExt.QPartitionCombinatorics.rogersSzego_two (q t : ℝ) (hq : 1 < q) (hq0 : q ≠ 0) :
      rogersSzego q t 2 = 1 + (q + q⁻¹) * t + t ^ 2

      H_2(t;q) = 1 + [2]_q·t + t² with [2]_q = q + q⁻¹ (balanced). The middle coefficient is the balanced quantum integer — the first place balanced vs standard normalization differ (q+q⁻¹ here, 1+q for the standard (q;q) Rogers–Szegő).
