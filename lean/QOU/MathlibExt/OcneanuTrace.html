    The Ocneanu / Markov trace as an abstract functional on a tower #

    Mathlib has no Markov trace and no Ocneanu trace. Measured, not assumed: a case-insensitive word-boundary grep over every .lean file of the vendored tree (commit f897ebcf72cd16f89ab4577d0c826cd14afaafc7) returns 0 hits for Ocneanu, Markov trace, Temperley, Kauffman, skein, Jones polynomial and BraidGroup, and 1 for Hecke — a paper title in the FLT bibliography comment. find -iname '*knot*' -o -iname '*braid*' -o -iname '*hecke*' returns only CategoryTheory files about the monoidal braiding. Two near-misses that a bare grep would report: Mathlib.CategoryTheory.MarkovCategory is categorical probability and Mathlib.MeasureTheory…Markov is Markov's inequality; neither is this. What Mathlib does supply, and what this file leans on, is Matrix.trace_mul_comm-style cyclicity as an idea and the Subalgebra / LinearMap / IsConj API.

    This file axiomatises the trace as a functional on a tower of subalgebras

    H 0 ⊆ H 1 ⊆ H 2 ⊆ ⋯ ⊆ A,

    with a distinguished new generator g n ∈ H (n+1) at each level, and derives the consequences that make such a functional useful.

    What is a HYPOTHESIS here #

    MarkovTrace itself. Its fields are the classical axioms

    • tr_mul_comm — the trace property tr (a * b) = tr (b * a);
    • tr_one — normalisation tr 1 = 1;
    • markov — Markov stabilisation tr (a * g n) = z * tr a for a ∈ H n;
    • markov_inv — the inverse-generator form tr (a * g⁻¹ n) = z' * tr a.

    Nothing in this file constructs such a functional on the Iwahori–Hecke tower, and no claim is made that the Hecke tower satisfies these axioms. That is the standard theorem of Jones and Ocneanu, cited below and not formalised here. What is supplied instead is a non-vacuity witness (unitMarkovTrace), so that the axioms are demonstrably satisfiable and none of the theorems below is empty.

    No topology is proved here. There is no braid group, no link diagram, no Hecke algebra, no Markov theorem, no Reidemeister move and no Jones polynomial anywhere in this file, and none is defined or imported. The tower is purely algebraic: a monotone family of Subalgebra R A with a distinguished element adjoined at each level. Where the names "Markov move I / II" occur below they are nomenclature for the algebraic statement being proved — they record which classical move that statement is the algebraic shadow of, and are not a claim that any topological invariance has been established.

    What is a THEOREM here #

    • MarkovTrace.tr_conj — conjugation invariance from a one-sided inverse: v * u = 1 → tr (u * x * v) = tr x. No unit, no group, no invertibility of x.
    • MarkovTrace.tr_eq_of_isConj — consequently tr is a class function: IsConj x y → tr x = tr y. This is Markov move I.
    • MarkovTrace.tr_gen, MarkovTrace.tr_gen_inv — the two Markov parameters are the trace values of the generators: tr (g n) = z, tr (g⁻¹ n) = z'. These are where tr_one earns its place.
    • MarkovTrace.tr_mul_stabWord — iterated stabilisation: appending the k successive new generators g n, g (n+1), …, g (n+k-1) to an element of H n multiplies the trace by z ^ k. This is Markov move II, iterated, and it is the statement whose specialisation at a = 1 reads tr (g n * g (n+1) * ⋯) = z ^ k.
    • MarkovTrace.gen_inv_eq_of_quadratic, MarkovTrace.markovParam_inv_eq_sub and MarkovTrace.tr_mul_ginv_of_quadratic — the inverse stabilisation is not independent once a quadratic relation is present: if g n * g n = h • g n + 1 then g⁻¹ n = g n - h • 1, the parameter is forced to z' = z - h, and — the substantive form — the stabilisation identity tr (a * g⁻¹ n) = (z - h) * tr a for a ∈ H n follows from tr_mul_comm, tr_one and markov alone, without using the field markov_inv at all. In the Hecke case h = q - q⁻¹. That last theorem is the precise sense in which the fourth Markov axiom is derived rather than assumed; markov_inv is nonetheless kept as a field because the derivation needs the quadratic relation, which is supplied at the call site and is not part of the tower data, so the structure would otherwise be unable to state T3' at all.

    stabWord is a plain definition (a word in a family of ring elements) and carries no trace content; stabWord_add is the concatenation identity for it.

    Relation to existing material in this repository #

    This is deliberately self-contained and Mathlib-only, per the convention for QOU.MathlibExt. Two neighbours are worth naming so this file is not mistaken for either:

    • QOU.MathlibExt.MarkovUnusedGenerator.MarkovTower axiomatises the same tower shape but for a different purpose — deriving the bond rule at an unused interior generator — and carries neither the normalisation tr 1 = 1, the inverse generator, nor conjugation invariance.
    • QOU.MathlibExt.MarkovTrace is a module namespace about the character / cyclicity layer on concrete Hecke matrix representations. The structure defined here is QOU.MathlibExt.OcneanuTrace.MarkovTrace; the two share a final name component and nothing else.

    Conventions #

    The Markov parameters z and z' are abstract ring elements throughout. Nothing here fixes them, so the file is convention-neutral: it is neither a convention-C nor a convention-D statement, and instantiating z at either specialises it without reproving anything.

    Base ring #

    Generic [CommRing R] acting on a generic ring A. No ℝ, no ordering, no square roots, no archimedean content. The single concrete witness exists_markovTrace_param_ne is stated over ℚ only because it needs a ring carrying a unit that differs from its own inverse.

    -- Ref: [jones1987] https://doi.org/10.2307/1971403 -- Ref: [wenzl1988] https://doi.org/10.1007/BF01393699

    The axioms #

    source
    structure QOU.MathlibExt.OcneanuTrace.MarkovTrace (R : Type u_3) [CommRing R] (A : Type u_4) [Ring A] [Algebra R A] :
    Type (max u_3 u_4)

    A Markov (Ocneanu) trace on a tower of subalgebras of A.

    H n is the n-th algebra of the tower and g n is the generator adjoined at step n, so g n ∈ H (n + 1) but in general g n ∉ H n. ginv n is a two-sided inverse for it, present so that the negative-crossing stabilisation axiom can be stated.

    Every field is used by a theorem below, and no field encodes any of the conclusions: conjugation invariance, the values tr (g n) and tr (ginv n), iterated stabilisation, and the relation between the two Markov parameters are all derived.

    • H : ℕ → Subalgebra R A

      The tower of subalgebras H 0 ⊆ H 1 ⊆ ⋯.

    • H_mono : Monotone self.H

      The tower is increasing.

    • g : ℕ → A

      The generator adjoined at step n.

    • g_mem (n : ℕ) : self.g n ∈ self.H (n + 1)

      g n lives one level up.

    • ginv : ℕ → A

      A two-sided inverse for g n (the negative crossing).

    • ginv_mem (n : ℕ) : self.ginv n ∈ self.H (n + 1)

      The inverse generator also lives one level up.

    • ginv_mul (n : ℕ) : self.ginv n * self.g n = 1

      ginv n is a left inverse of g n.

    • mul_ginv (n : ℕ) : self.g n * self.ginv n = 1

      ginv n is a right inverse of g n.

    • tr : A →ₗ[R] R

      The trace, as an R-linear functional on the whole algebra.

    • tr_mul_comm (a b : A) : self.tr (a * b) = self.tr (b * a)

      (T1) The trace property.

    • tr_one : self.tr 1 = 1

      (T2) Normalisation.

    • z : R

      The Markov parameter for a positive crossing.

    • zinv : R

      The Markov parameter for a negative crossing.

    • markov (n : ℕ) (a : A) : a ∈ self.H n → self.tr (a * self.g n) = self.z * self.tr a

      (T3) Markov stabilisation, at the top of the tower.

    • markov_inv (n : ℕ) (a : A) : a ∈ self.H n → self.tr (a * self.ginv n) = self.zinv * self.tr a

      (T3') Markov stabilisation by the inverse generator.

        theorem QOU.MathlibExt.OcneanuTrace.MarkovTrace.gen_inv_eq_of_quadratic {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : MarkovTrace R A) (n : ℕ) (h : R) (hq : T.g n * T.g n = h • T.g n + 1) :

        source
        theorem QOU.MathlibExt.OcneanuTrace.MarkovTrace.markovParam_inv_eq_sub {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : MarkovTrace R A) (n : ℕ) (h : R) (hq : T.g n * T.g n = h • T.g n + 1) :
        T.zinv = T.z - h

        The negative Markov parameter is determined by the positive one as soon as the generator satisfies a quadratic relation: z' = z - h.

        For the Iwahori–Hecke relation σ² = (q - q⁻¹) σ + 1 this reads z' = z - (q - q⁻¹), i.e. the fourth Markov axiom is a consequence of the other three rather than an independent assumption.

        source
        theorem QOU.MathlibExt.OcneanuTrace.MarkovTrace.tr_mul_ginv_of_quadratic {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : MarkovTrace R A) (n : ℕ) (h : R) (hq : T.g n * T.g n = h • T.g n + 1) (a : A) (ha : a ∈ T.H n) :
        T.tr (a * T.ginv n) = (T.z - h) * T.tr a

        The inverse-stabilisation axiom itself is derived, not merely its parameter. Given the quadratic relation, tr (a * ginv n) = (z - h) * tr a for every a ∈ H n.

        The proof uses only gen_inv_eq_of_quadratic (hence ginv_mul), linearity of tr, and markov — the field markov_inv is not used, which is what makes this the honest form of the claim that the fourth Markov axiom is a consequence of the other three rather than an independent assumption. markovParam_inv_eq_sub is the corresponding statement about the parameter, and does go through markov_inv.

        Non-vacuity #

        The axioms above are satisfiable, and they do not force the two Markov parameters to coincide. The witness is the one-dimensional tower A = R with every H n = ⊤, the generator a fixed unit u, and tr = id. It is commutative and says nothing about the Hecke tower — it is an inhabitation witness only — but it is faithful (tr 1 = 1 ≠ 0 in a nontrivial ring), so the axioms do not collapse the trace to zero.
