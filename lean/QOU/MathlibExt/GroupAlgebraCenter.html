    Counting: conjugacy classes of S_n, and the centre of a group algebra #

    Two bounds needed by the completeness half of the Specht classification (SpechtClassification.specht_exhausts_irreducibles), where the chain is

    #{simple k[Sₙ]-modules} ≤ dim_k Z(k[Sₙ]) ≤ #conj classes of Sₙ ≤ #partitions of n.

    This file supplies the two right-hand steps. Both are stated as inequalities, which is what the count needs and is markedly cheaper than the equalities:

    • #conj classes ≤ #partitions needs only that Equiv.Perm.partition separates conjugacy classes — not that every partition is realised as a cycle type, which Mathlib does not have.
    • dim_k Z(k[G]) ≤ #conj classes needs only that the class sums span the centre — not that they are independent.

    Mathlib coverage #

    Equiv.Perm.partition and partition_eq_of_isConj exist; the induced injection on ConjClasses does not. For group algebras Mathlib has no centre API at all at the pinned revision — no class sums, no dimension formula. Both are genuine gaps.

      2. The centre of a group algebra is spanned by class sums #

      An element of k[G] is central iff its coefficient function is constant on conjugacy classes, so it is a combination of the class sums. Only this direction — centre ⊆ span — is proved, since only the resulting dimension bound is used.

        theorem QOU.MathlibExt.GroupAlgebraCenter.center_le_span_classSum {k : Type u_1} {G : Type u_2} [CommRing k] [Group G] [Fintype G] [DecidableRel IsConj] :
        Subalgebra.toSubmodule (Subalgebra.center k (MonoidAlgebra k G)) ≤ Submodule.span k (Set.range classSum)

        The centre is contained in the span of the class sums.

        A central z is constant on classes, so z = Σ_c z(cᵒᵘᵗ) · classSum c; the carriers partition G, which turns the double sum back into Σ_g single g (z g) = z.

        Only this inclusion is proved — the class sums are in fact a basis, but the counting argument needs no more than the resulting dimension bound.

        3. Class functions #

        A function G → k constant on conjugacy classes is determined by its values on ConjClasses G, so the space of them has dimension at most the number of classes. This is the target the characters of pairwise non-isomorphic simple modules land in, and the reason #simples ≤ #conj classes.
