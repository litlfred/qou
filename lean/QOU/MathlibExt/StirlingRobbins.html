    theorem QOU.MathlibExt.log_factorial_le_stirling_robbins {n : ℕ} (hn : n ≠ 0) :
    Real.log ↑n.factorial ≤ ↑n * Real.log ↑n - ↑n + Real.log ↑n / 2 + Real.log (2 * Real.pi) / 2 + 1 / (12 * ↑n)

    Robbins' upper bound. For n ≠ 0,

    log n!  ≤  n·log n − n + ½·log n + ½·log(2π) + 1/(12n).

    The exact counterpart of Mathlib's Stirling.le_log_factorial_stirling, with the 1/(12n) term its docstring records as missing. Together the two pin log n! to within 1/(12n).

    The matching lower bound #

    Robbins' other half. Remarkably it needs no series estimate at all: the terms are all nonnegative, so the sum dominates its FIRST term ⅓·x, and that alone already beats the telescoping gap. The margin is exactly 24m+1:

    ⅓·x ≥ 1/(12(m+1)+1) − 1/(12(m+2)+1)
  ⟺  36(2m+3)² ≤ (12m+13)(12m+25)
  ⟺  0 ≤ 24m + 1

    true for every m ≥ 0, and tight at m = 0 where the two sides differ by 1.

    theorem QOU.MathlibExt.le_log_factorial_stirling_robbins {n : ℕ} (hn : n ≠ 0) :
    ↑n * Real.log ↑n - ↑n + Real.log ↑n / 2 + Real.log (2 * Real.pi) / 2 + 1 / (12 * ↑n + 1) ≤ Real.log ↑n.factorial

    Robbins' bounds, both sides. For n ≠ 0,

    n·log n − n + ½log n + ½log(2π) + 1/(12n+1)
  ≤ log n! ≤
n·log n − n + ½log n + ½log(2π) + 1/(12n).

    The lower bound strictly sharpens Mathlib's Stirling.le_log_factorial_stirling (which has no 1/(12n+1) term), and the upper bound has no Mathlib counterpart at all. Their gap is 1/(12n) − 1/(12n+1) = 1/(12n(12n+1)) = O(1/n²), which is what qou-mlgp (A) needs: the −(π/12N)cot θ refinement requires the 1/(12k) term to o(1/N) accuracy, and either bound alone leaves an O(1/N) hole.
