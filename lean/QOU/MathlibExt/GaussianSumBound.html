    theorem QOU.MathlibExt.sum_exp_neg_mul_sq_le {a : ℝ} (ha : 0 < a) (m : ℕ) :
    ∑ d ∈ Finset.range m, Real.exp (-a * ↑d ^ 2) ≤ 1 + √(Real.pi / a) / 2

    The discrete Gaussian sum, bounded uniformly in the number of terms. ∑_{d < m} e^{−a d²} ≤ 1 + ½√(π/a). The 1 is the d = 0 term, which the integral comparison cannot see.

    theorem QOU.MathlibExt.sum_exp_neg_mul_mul_pred_le {a : ℝ} (ha : 0 < a) (m : ℕ) :
    ∑ d ∈ Finset.range m, Real.exp (-(a * ↑d * (↑d - 1))) ≤ 2 + √(Real.pi / a) / 2

    The form a per-step tail bound produces: the penalty accumulated over d steps is 1 + 2 + … + (d−1) = d(d−1)/2, so the exponent carries d(d−1), not d². Costs one extra unit because d(d−1) ≥ (d−1)² fails at d = 0.
