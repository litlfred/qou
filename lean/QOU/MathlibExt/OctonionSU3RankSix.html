    QOU.MathlibExt.OctonionSU3RankSix — rank(ev_{e₁}) = 6, closing dim 𝔰𝔲(3) = 8 #

    The OctonionSU3Stabilizer gate reduces the colour SU(3) dimension to a rank: finrank (su3 e) = 8 ↔ rank(evOct e) = 6. This file supplies the missing rank(evOct e) = 6 at the concrete unit imaginary e = e₁ (Pi.single 1 1), turning finrank (su3 e₁) = 8 into an unconditional theorem — the S⁶ = G₂/SU(3) dimension count, fully in Lean.

    The value is exact-ℚ certified by the merged probe (octonion_su3_stabilizer_probe.py); here it is proved from the corpus's own explicit 𝔤₂ basis. Structure:

    • octDer_span_eq_top — the 14 explicit derivations octDer span Der𝕆 (14 independent elements, octDer_linearIndependent, in a 14-dim space, octonion_derivation_dim), so they are a basis.
    • range_evOct_eq_span_images — hence range(evOct e) = span { (octDerMat i)·e }, the span of the 14 concrete image vectors.
    • At e = e₁ those images are ±e₂, …, ±e₇ (columns of the octDerMat i), so the range is the 6-dim coordinate subspace {v : v₀ = v₁ = 0} — hence rank = 6.

    Base ring ℚ; nothing archimedean.

    rank(ev_{e₁}) = 6 at the concrete unit imaginary e₁ = Pi.single 1 1 #

    The 14 images evOct e₁ (octDer i) = (octDerMat i) ·ᵥ e₁ are the 1st columns of the octDerMat i; a direct evaluation gives ±e₂, …, ±e₇ for the nine non-stabilizer derivations and 0 for the five in su3 e₁. Hence range(evOct e₁) is exactly the span of {e₂, …, e₇} — the 6-dimensional coordinate subspace {v : v₀ = v₁ = 0}.
