    QOU.MathlibExt.TraceFormSemisimple — the abstract semisimplicity theorem #

    Brick B3d (epic qou-hnhg, track 3): the keystone of Wenzl's semisimplicity criterion, as a general Mathlib statement.

    Theorem. A finite-dimensional algebra A over a field K whose regular trace form regTraceForm K A x y = trace(L_{xy}) is nondegenerate is a semisimple ring.

    Proof (assembled from the TraceNilpotent core):

    1. A is Artinian (finite-dimensional over a field), so its Jacobson radical Ring.jacobson A = Ideal.jacobson ⊥ is a nilpotent ideal (IsArtinianRing.isNilpotent_jacobson_bot).
    2. For x in that radical and any y, y * x lies in the radical (a left ideal), hence is nilpotent, so regTraceForm K A y x = trace(L_{yx}) = 0 (regTraceForm_eq_zero_of_mul_isNilpotent). By trace cyclicity regTraceForm K A x y = regTraceForm K A y x = 0 — note we never need the radical to be two-sided.
    3. Nondegeneracy forces x = 0, so Ring.jacobson A = ⊥, i.e. A is semisimple (isSemisimpleRing_iff_jacobson).

    This discharges the abstract half of the criterion. Instantiating it at the Iwahori–Hecke algebra with its Markov trace, and identifying nondegeneracy with [n]_q! ≠ 0 (bricks qou-t2ot/qou-8irr), turns the cited WenzlCriterion class into a theorem.
