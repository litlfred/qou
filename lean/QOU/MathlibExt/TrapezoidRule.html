    theorem QOU.MathlibExt.integral_eq_trapezoid_sub {f f' f'' : ℝ → ℝ} {a b : ℝ} (hf : ∀ x ∈ Set.uIcc a b, HasDerivAt f (f' x) x) (hf' : ∀ x ∈ Set.uIcc a b, HasDerivAt f' (f'' x) x) (hcont : ContinuousOn f'' (Set.uIcc a b)) :
    ∫ (x : ℝ) in a..b, f x = (b - a) / 2 * (f a + f b) - 1 / 2 * ∫ (x : ℝ) in a..b, (x - a) * (b - x) * f'' x

    The trapezoid rule with its exact error term.

    ∫_a^b f = ((b−a)/2)·(f a + f b) − ½·∫_a^b (x−a)(b−x)·f″(x) dx

    for any f with a second derivative on [[a,b]] and f″ continuous there. Exact — an identity, not an estimate.

    |(b - a) / 2 * (f a + f b) - ∫ (x : ℝ) in a..b, f x| ≤ (b - a) ^ 3 * M / 12

    The trapezoid error bound. |trapezoid − ∫| ≤ (b−a)³·M/12 when |f″| ≤ M on [a,b].

    The classical O(h³) per-cell estimate — O(h²) after summing 1/h cells — and the reason a trapezoid rule sees one order more than a rectangle rule.
