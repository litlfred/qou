    cLiTwoExt's integrand is integrable at real x > 0 — qou-invr step (1), DONE #

    Bean qou-invr, step (1) complete:

    intervalIntegrable_clog_one_sub_div_ofReal {x : ℝ} (hx : 0 < x) :
  IntervalIntegrable (fun t => log (1 − x·t) / t) volume 0 1

    Both singularities handled — the logarithmic one at t = 1/x (in range exactly when x > 1, which is the whole difficulty) and the removable one at t = 0. Verified at x = 2.24698, i.e. at w₁ itself.

    Why step (1) exists #

    Route 35 showed the inversion leg is not a boundary-value problem: Re Li₂ is continuous across [1,∞) because Li₂'s jump 2πi·log x is purely imaginary. What that left is concrete: cLiTwoExt y = −∫₀¹ log(1 − y·t)/t dt, and every existing integrability lemma (intervalIntegrable_log_one_sub_div_of_slitPlane and its notCut corollary) assumes the integrand avoids log's cut on the whole of [0,1]. For real x > 1 that fails — 1 − x·t changes sign at t = 1/x ∈ (0,1).

    This is not a technicality. A Lean ∫ of a non-integrable function is the junk value 0, so until integrability is proved, every statement about cLiTwoExt x for x > 1 is a statement about 0: vacuously true and useless. Exactly the "true and about nothing" failure this lane has hit before.

    What IS proved #

    intervalIntegrable_clog_one_sub_mul (x a b : ℝ) — the full complex statement, on any interval. It is assembled from:

    • log_ofReal_eq — for real r, log r = log |r| + arg(r)·I. Separating the divergent real part from the bounded arg is the first line of the argument.
    • arg_one_sub_mul_ofReal — arg (1 − x·t) is an explicit two-valued step function, 0 before the sign change and π after. So the branch jump is not an obstacle at all; it is a bounded measurable function.
    • intervalIntegrable_real_log_one_sub_mul — the real half, unconditional. 1 − x·t is affine, hence analytic, hence meromorphic, so Mathlib's intervalIntegrable_log_norm_meromorphicOn applies directly; Real.log is even (Real.log_abs) so the ‖·‖ costs nothing.

    That last step is why this closed. The hard part — integrating log through its own singularity — was already in Mathlib, twice over (intervalIntegrable_log' unconditionally, and the meromorphic version used here). qou-invr had priced this leg as "new analytic infrastructure"; it was API archaeology.

    The 1/t assembly, as built #

    1/t is a second, independent singularity at t = 0 — removable (log(1 − x·t) ~ −x·t), and unrelated to the logarithmic one.

    1. Split at c = 1/(2x) (IntervalIntegrable.trans), so 1 − x·t ≥ 1/2 on [0,c].
    2. intervalIntegrable_integrand_right — on [c,1], 1/t is continuous (t ≥ c > 0), so it peels off with IntervalIntegrable.mul_continuousOn against the theorem above.
    3. intervalIntegrable_integrand_left — on [0,c], rescale to the existing intervalIntegrable_log_one_sub_div_of_slitPlane rather than reprove the removable singularity. The substitution t = c·u sends the integrand to log(1 − u/2)/u, whose slit hypothesis holds outright (Re(1 − u/2) ≥ 1/2), and comp_mul_left transports 0..1 to 0..c. The removable singularity at 0 is thereby handled by the proof that already existed.

    ⚠ A performance note worth keeping. Step 3 first appeared to be a mathematical obstruction: it timed out at 63s even with a 10× heartbeat budget. The cause was neither the analysis nor comp_mul_left's side conditions — it was a rw [one_div] in the goal that hcomp did not carry, so exact had to unify (2x)⁻¹ against 1/(2x) under a pile of casts. Deleting that one rewrite made it instant. An elaboration timeout is not evidence that a step is hard.

    How cLiTwoExt 1 = π²/6 was obtained #

    1 is the excluded point of both existing lemmas — cLiTwoExt_eq_cLiTwo needs ‖y‖ < 1, cLiTwoExt_eq_cLiTwo_of_norm_le_one needs y ∈ notCut. The route around:

    • cLiTwo 1 = π²/6 is immediate — the series converges at 1, so this is just hasSum_one_div_succ_sq. No boundary theory.
    • cLiTwoExt along the reals is a primitive (cLiTwoExt_ofReal_eq_primitive, from cLiTwoExt_ofReal_mul at y = 1), and primitives of integrable functions are continuous — integrability at x = 1 being step (1).
    • So both are continuous along [0,1] and agree on [0,1); the value at the branch point follows by uniqueness of limits.

    Step (1) is therefore not merely a prerequisite of step (2) — it is what makes the branch point reachable at all.

    The earlier framing, kept because the contrast still holds #

    G' = 0 gives the identity only up to a constant, and Route 35 G3 measures G ≡ π²/3. Pinning it needs one value, and the only available base point is x → 1⁺, where ½·log²x → 0 and both dilogarithm terms tend to Re cLiTwoExt(1). So the constant is 2·Re cLiTwoExt(1), and the identity is equivalent to

    Re cLiTwoExt(1) = π²/6.

    Contrast with the Landen leg, which is the instructive part. There the base point could be taken at z → 0⁻, where every term vanishes outright — so no special value was needed and the leg closed. Here the base point is forced to the branch point x = 1, where the value is π²/6 rather than 0. The two legs differ not in their derivative arguments, which are equally routine, but in whether the natural base point is a zero or a special value.

    Two things are needed, and neither is free:

    1. Re cLiTwoExt(1) = π²/6. cLiTwoExt_eq_cLiTwo needs ‖y‖ < 1 and cLiTwoExt_eq_cLiTwo_of_norm_le_one needs y ∈ notCut; 1 satisfies neither — it is exactly the excluded point of both. So this is an Abel / boundary-limit statement about the series, not a corollary of what exists.
    2. Continuity of x ↦ Re cLiTwoExt(x) at 1, to take the limit at all.

    Note (2) is plausible precisely because Route 35 G1 measured the Re jump across the cut to be zero — but measured is not proved, and x = 1 is the branch point rather than an interior point of the cut, so G1 does not cover it.

    The Li₂ integrand, approached from below — Route 36 G11 #

    hcont in the transport wants cLiTwoExt continuous at a point of the cut [1,∞), reached along a path with Im < 0. That splits into a pointwise part and a dominated-convergence part; this section closes the pointwise one, and it turns out to cost nothing.

    The reason is a Mathlib theorem that is exactly the right shape: Complex.continuousWithinAt_log_of_re_neg_of_im_zero gives log continuous at a negative real when restricted to the upper half plane {0 ≤ z.im}. And w ↦ 1 − w·t carries {Im w ≤ 0} into {0 ≤ Im z} for t > 0, because Im(1 − w·t) = −t·Im w. So approaching the cut from below in w is approaching log's cut from above in 1 − w·t — the two conventions agree, and Lean's principal branch already sits on that side (arg_one_sub_mul_ofReal).
