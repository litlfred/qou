    QOU.MathlibExt.RegTraceGramProduct — the Gram determinant of a product algebra #

    Bean qou-kwoa, the determinant's value: the assembly step.

    RegTraceMatrix derives the Gram determinant of a single matrix block, ± d^(d²). This file assembles the blocks: for a finite product of algebras, the Gram determinant in a product basis is the product of the block Gram determinants. Composed with the block computation it derives the integer constant ∏_λ d_λ^(d_λ²) that computations/hecke/tw_gram_determinant_probe.py measured by factoring exact symbolic determinants.

    A correction to the blocker I previously named #

    PR #6552 recorded the assembly as blocked on a named Mathlib gap: Matrix.det_blockDiagonal is uniform-block-size only, and there is no determinant lemma for Matrix.blockDiagonal'. The first half is true and the second half is true, and neither is the obstruction — Matrix.BlockTriangular.det_fintype (Mathlib/LinearAlgebra/Matrix/Block.lean:276) already gives

    M.det = ∏ k, (M.toSquareBlock b k).det

    for b : m → α whose fibres are the blocks — of arbitrary, differing sizes. A block-diagonal matrix is block-triangular for every b, so that lemma covers this case outright. The search that produced the wrong conclusion was det intersected with blockDiagonal'; the capability is present under a different name. Recorded because the shape of the error — reporting the absence of a spelling as the absence of a capability — is the one the corpus-grep discipline exists to catch.

    Contents #

    • det_eq_prod_of_offDiagonal_eq_zero — the general statement, for any square matrix over a sigma index whose off-diagonal blocks vanish. This is the reusable piece and it is where BlockTriangular.det_fintype is discharged; Matrix.det_blockDiagonal' would be an immediate corollary.
    • regTraceForm_pi_single_of_ne / regTraceGram_pi_offDiagonal — the regular trace form on a product pairs different factors to zero, so its Gram in Pi.basis is block diagonal.
    • regTraceGram_pi_det — the assembly: det = ∏ i, det (block Gram).
    • regTraceGram_pi_matrix_det — the two composed, for a product of matrix algebras: the integer constant ∏ i, ± d_i^(d_i²), derived.

    What is still NOT claimed #

    This computes the Gram determinant in the product basis Pi.basis. Transporting it to the T_w basis of a Hecke algebra changes it by (det P)² for the change-of-basis P, so this determines the constant only up to a square — and says nothing at all about the q-part, where the Schur elements live. This is not a proof of Geck–Pfeiffer 7.2.6.

    A block-diagonal matrix over a sigma index has determinant the product of its blocks, with the blocks allowed to have different sizes.

    This is the general form of what Matrix.det_blockDiagonal gives only for uniform blocks. The whole content is Matrix.BlockTriangular.det_fintype plus the identification of the fibre {p // p.1 = k} with κ k; the linear order on ι is an artifact of that lemma and does not appear in the conclusion.

    theorem QOU.MathlibExt.regTraceGram_pi_matrix_det {K : Type u_1} [Field K] {ι : Type u_2} [Fintype ι] [DecidableEq ι] {J : ι → Type u_5} [(i : ι) → Fintype (J i)] [(i : ι) → DecidableEq (J i)] :

    The Gram determinant of a product of matrix algebras, in the product of matrix-unit bases: the product over blocks of ± d_i^(d_i²).

    This is regTraceGram_pi_det' composed with regTraceGram_stdBasis_det, and it is the derivation of the integer constant that computations/hecke/tw_gram_determinant_probe.py measured by factoring exact symbolic determinants. Up to the signs it is ∏_i d_i^(d_i²); reading the block dimensions off the Wedderburn decomposition of H_{n+1} — the SYT counts of the partitions of n+1 — that is 1, 2⁴, 2⁴·3¹⁸ at n = 1, 2, 3, the probe's three measured constants.

    ((BilinForm.toMatrix (Pi.basis fun (i : ι) => Matrix.stdBasis K (J i) (J i))) (regTraceBilin K ((i : ι) → Matrix (J i) (J i) K))).det ≠ 0 ↔ ∀ (i : ι), ↑(Fintype.card (J i)) ≠ 0

    The product Gram determinant vanishes exactly when some block dimension dies in K.

    The sharp characteristic statement for a semisimple algebra in Wedderburn form: the regular trace form degenerates iff char K divides one of the block dimensions. Over a characteristic-zero field no block can die, which is the route RegTraceGramNondegenerate takes to det(twGram) ≠ 0 — this says the char-zero hypothesis there is not merely sufficient but exactly right.
