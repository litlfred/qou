    TL content stratification — the combinatorial characterisation (bean qou-lcgj) #

    WenzlSchurElement.schurElement_tl_eq_zero_iff (already on main) reduces Schur-element vanishing at the physical Markov parameter X = Q^{-N} to the existential predicate HasContentCell lam N. That is not yet a combinatorial description: it still quantifies over cells.

    This file eliminates the quantifier. For a genuine partition (weakly decreasing, positive parts) the content-N hyperplane meets the diagram in a condition on a single shape statistic:

    • N ≥ 0 : HasContentCell lam N ↔ N < lam₁ (more than N columns)
    • N < 0 : HasContentCell lam N ↔ -N < ℓ(lam) (more than -N rows)

    Hence at X = Q^{-N}, N ≥ 0, the surviving Wedderburn blocks are exactly the partitions with at most N columns.

    Conventions are fixed by WenzlSchurElement: rows/columns are 0-indexed and cellContent i j = j - i. Note the resulting statement is the conjugate of the textbook GL(N)/HOMFLY one ("at most N rows"), which corresponds to the other sign convention X = Q^{+N}; see the report for the discussion.

    Base ring: ℝ only in the Schur-element corollaries, which inherit it from schurElement (§7c). The combinatorial characterisation itself is ring-free.

      Corollary: the two conditions are jointly necessary #

      Combining the two forward directions, a content-N cell forces both more than N columns and more than -N rows — the diagram must reach the content-N anti-diagonal from both sides. This is the "hook" form of the stratification and needs no sign hypothesis at all.
