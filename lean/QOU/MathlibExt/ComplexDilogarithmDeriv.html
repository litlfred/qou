    cLiTwoExt is complex-differentiable on ℂ ∖ [1,∞) #

    Bean qou-clx8. ComplexDilogarithmSlit.lean gave the derivative along rays by moving the parameter into the limit of integration. That is not enough for analyticity, which needs every direction. This file gets it, by differentiating under the integral sign after all — which the bean called "not a Mathlib one-liner", correctly: Mathlib supplies the theorem (intervalIntegral.hasDerivAt_integral_of_dominated_loc_of_deriv_le, with 𝕜 = ℂ, so its conclusion is a genuine complex derivative) but not the one hypothesis that is actually work here.

    The missing infrastructure, and why it is the whole job #

    The dominating function has to bound ∂/∂w [log(1−wz)/z] = −(1−wz)⁻¹ uniformly for w in a ball and z ∈ [0,1]. So what is needed is

    ∃ ε > 0, ∃ δ > 0, ∀ w ∈ closedBall w₀ ε, ∀ z ∈ [0,1],  δ ≤ ‖1 − w·z‖

    and once that exists the dominating function is a constant, which is the easiest possible case of the theorem.

    exists_uniform_lower_bound below is that statement. It is proved by compactness rather than by explicit estimates: closedBall w₀ ε ×ˢ Icc 0 1 is compact, the map (w,z) ↦ ‖1 − w·z‖ is continuous on it, and it never vanishes there — because ℂ ∖ [1,∞) is open (isOpen_notCut), so a small enough ball stays inside it, and there mem_slitPlane_one_sub_mul puts 1 − wz in slitPlane, which excludes 0. A continuous positive function on a compact set has a positive minimum.

    Explicit estimates would work too, but they split into two cases with different shapes (m/√(M²+m²) off the real axis, 1 − max(Re w₀ + ε, 0) on it) and the compactness argument handles both at once.

    The result #

    hasDerivAt_cLiTwoExt : HasDerivAt cLiTwoExt (∫ z in 0..1, -(1 - w*z)⁻¹) w
hasDerivAt_cLiTwoExt' : w ≠ 0 → HasDerivAt cLiTwoExt (-(log (1-w)/w)) w
differentiableOn_cLiTwoExt, analyticOnNhd_cLiTwoExt

    so cLiTwoExt is analytic on ℂ ∖ [1,∞) and "the analytic continuation" is now a theorem, not a name — which is what qou-clx8 set out to establish.

    ⚠ Why the derivative is stated as an integral first #

    -(log (1−w)/w) is the wrong value at w = 0: Lean's x/0 = 0 makes it 0, while the true derivative there is 1 (from the series Σ wᵏ/k²). The integral form ∫₀¹ -(1−wz)⁻¹ dz is correct at every w including 0, where it is -1 — note that is the derivative of the integrand's integral, and the sign flips in cLiTwoExt's leading minus. So the closed form is a corollary with w ≠ 0, not the primary statement.

    This lane has already been bitten once by exactly this: hinv1/hlan1 were false because Lean's junk values (tsum of a non-summable family is 0) were read as if they were the mathematical values. Stating the closed form as primitive would have repeated it.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms. qou-clx8 is explicit that closing it does not move the sum rule; Route 5 is a restatement.

      theorem QOU.MathlibExt.exists_uniform_lower_bound {w₀ : ℂ} (hw₀ : w₀ ∈ notCut) :
      ∃ ε > 0, ∃ δ > 0, (∀ w ∈ Metric.closedBall w₀ ε, w ∈ notCut) ∧ ∀ w ∈ Metric.closedBall w₀ ε, ∀ z ∈ Set.Icc 0 1, δ ≤ ‖1 - w * ↑z‖

      ‖1 − w·z‖ is bounded below, uniformly for w near w₀ and z ∈ [0,1].

      This is the hypothesis hasDerivAt_integral_of_dominated_loc_of_deriv_le needs and the only real work in this file: with it the dominating function is a constant.
