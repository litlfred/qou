    QOU.MathlibExt.QStandardRogersSzego — standard q-Pascal + the FollowsRogersSzego instance #

    Closes the loop left open by #2823/#2829: the balanced qBinom satisfies a scaled-argument q-Pascal, so its Rogers–Szegő does NOT obey the standard (1−qⁿ) three-term recurrence of QOU.Mass.BindingQHermiteOscillator.FollowsRogersSzego. The standard (q;q)-normalized binomial QOU.Machinery.qBinomial does. This file proves the standard q-Pascal [n+1;k+1]_q = [n;k]_q + q^{k+1}[n;k+1]_q (from the clean (q;q) addition 1−q^{a+b} = (1−q^a) + q^a(1−q^b)) and uses it to exhibit a genuine FollowsRogersSzego instance — proving the §3b conjecture class is non-vacuous.

    Ground ring ℝ, q > 1 (so every (q;q)_n ≠ 0 — away from roots of unity).

    theorem QOU.Machinery.qBinomial_pascal {q : ℝ} (hq : 1 < q) (k m : ℕ) :
    qBinomial (k + m + 2) (k + 1) q = qBinomial (k + 1 + m) k q + q ^ (k + 1) * qBinomial (k + 1 + m) (k + 1) q

    Standard q-Pascal for the (q;q) Gaussian binomial (q > 1, m-parametrised, n = k+1+m): [k+m+2 choose k+1]_q = [k+1+m choose k]_q + q^{k+1}·[k+1+m choose k+1]_q. Clean (no q^{±} half-powers) — this is the form that drives the standard Rogers–Szegő three-term recurrence. From the (q;q) addition 1−q^{(k+1)+(m+1)} = (1−q^{k+1})+q^{k+1}(1−q^{m+1}).
