    BraidedTower instances — the class is inhabited, in both quadrants #

    Bean qou-301d. HeckeSandwichReduces proves SandwichReduces, hence TowerSpan, hence the disjoint-block trace law, from three equations (quad / far / braid) and nothing else. It closed with the caveat that it constructed no instance of that class, so the theorem was general but unwitnessed. This file removes that caveat.

    The two carriers were built independently, for different reasons. The table below once said that between them they cover the two ways a witness can be degenerate; the last column shows why that is not so — see the correction under "What the Hecke instance buys".

    carrier h filtration trace
    unitMarkovTrace u (HeckeSandwichReduces.braidedTower_unit) u - u⁻¹, can be ≠ 0 constant (H = ⊤) identity
    SymmetricGroupTowerWitness.symTrace 0 grows at every level not a homomorphism
    HeckeTowerWitness.heckeTowerMarkovTrace h z free parameter H 0 < H 1 🛑 IS a homomorphism — towerTrace_mul below

    What the Hecke instance buys #

    braidedTower_heckeTower is the one the caveat named: the presented infinite Iwahori-Hecke algebra H_∞, with h a free parameter of the construction, so h ≠ 0 — the Hecke case h = q - q⁻¹ — is available. That is a real gain for the filtration, and towerSpan_heckeTower is the first TowerSpan witness with both a provably growing filtration (twH_zero_lt_one) and h ≠ 0.

    🛑 CORRECTED 2026-09-13 — it buys nothing for the TRACE, and this is measured, not suspected. This paragraph continued: "Composing it with disjointBlock_of_braided gives disjointBlock_heckeTower: the disjoint-block trace law on a Hecke tower at h ≠ 0, which is the configuration every prior witness missed." The composition is valid and disjointBlock_heckeTower is true; what is wrong is reading it as exercising the disjoint-block content.

    ocneanuTrace_mul_of_markov below proves that the rank-2 Ocneanu trace is multiplicative on every pair exactly when z * z = h * z + 1 — and that equation is precisely the hypothesis heckeTowerMarkovTrace requires in order to be a MarkovTrace at all. Since towerTrace = ocneanuTrace ∘ collapse with collapse an algebra hom, towerTrace_mul makes the whole trace an algebra homomorphism, and heckeTower_tr_mul_unconditional states the trace law for arbitrary a, b with no level hypothesis whatsoever. So disjointBlock_heckeTower holds for reasons that have nothing to do with disjoint blocks.

    The table's third column said "not faithful". That is true and it is a different property: faithfulness is about separating elements, multiplicativity is about the law under test. Only the second answers whether the witness exercises DisjointBlockMultiplicative.

    Consequence: no witness has all three properties — growing filtration, h ≠ 0, and a non-multiplicative trace. SymmetricGroupTowerWitness has the first and third at h = 0; this one has the first and second. The trace content at q ≠ 1 remains unexercised by any inhabited witness.

    🛑 What that gap IS, corrected 2026-09-13 — it is NOT "Jones' theorem is open". This read "which is Jones' theorem on H_∞(q) and stays open (bean qou-g8i1)", and both halves are wrong. qou-g8i1 is completed and is titled "Prove the (z+d) bond rule" — a different result; the pointer comes from a scoping in qou-0fmb that qou-0fmb itself retracted on 2026-09-12. And the Ocneanu trace's existence and uniqueness are PROVED on main, sorry-free: SchurWeyl/MarkovTraceInstance.ocneanuMarkovTrace : MarkovTraceFamily ℝ q q⁻¹ (q³/(q²+1)) and SchurWeyl/MarkovTraceUnique.markovTrace_unique.

    The real gap is that those live in a different abstraction: HeckeCoset.MarkovTraceFamily is level-indexed with one trace per level, one Markov parameter and no ginv, while OcneanuTrace.MarkovTrace is a single algebra with a filtration, one trace, ginv, and both z and zinv. Nothing bridges them. The live carrier is bean qou-ejde (the colimit route), whose step 1 SchurWeyl/HeckeProductInjective.heckeProduct_injective landed on 2026-09-13.

    Note also that "faithful on H_∞(q)" is the wrong target at convention D — the weight vanishes for ℓ(λ) ≥ 3 (QBeta/WenzlWeightVanishing. conventionD_weight_eq_zero_iff_rowLens), so the radical is nonzero and the attainable statement is faithfulness on H_∞(q)/rad. That over-claim is bean qou-phlk, already adjudicated.

    The corpus already held HeckeRankTwoMarkov.ocneanuTrace_mul_defect, whose defect is literally h * z + 1 - z * z. What it had not recorded is that the MarkovTrace hypothesis kills that defect.

    It is a three-line instantiation because HeckeTowerWitness imposes exactly these three relations by RingQuot, so twGen_quad / twGen_far / twGen_braid are the class fields. That is a statement about how well the two halves fit, not about how much either one proves.

    What the symmetric-group instance buys #

    braidedTower_sym gives SymmetricGroupTowerWitness.sandwichReduces_sym a second, independent derivation. That file proves SandwichReduces in the permutation model, by support and point-pushing arguments through the double coset S_{k+1} = S_k ∪ S_k s_k S_k; sandwichReduces_all reproves it by rewriting with the relations, never mentioning a permutation. Two routes to the same conclusion in the same model is a check on both.

    The group-level inputs are the two classical facts about adjacent transpositions, proved here from Equiv.swap_apply_apply alone: distant swaps commute (s_far), and s (m+1) s m s (m+1) = s m s (m+1) s m because both sides are swap m (m+2) (s_braid).

    🛑 What is still NOT settled #

    Two limits, both inherited from the carriers and neither repaired here.

    • The Hecke trace is not faithful. HeckeTowerWitness's trace collapses every generator onto the single generator of the rank-2 algebra and composes with its Ocneanu trace, so disjointBlock_heckeTower is a statement about a coarse functional, not about the Ocneanu trace of H_∞(q). This does not weaken sandwichReduces_all itself, which uses no trace field — it bounds what the composition delivers.

      🛑 The gap is a BRIDGE, not Jones' theorem — corrected 2026-09-13. The first version of this paragraph said "constructing that trace is Jones' existence theorem and remains open (bean qou-g8i1)". Both halves are wrong. Jones' theorem is proved in this corpus, with uniqueness, both sorry-free on main: SchurWeyl.MarkovTraceInstance builds wtrace with the trace property, normalisation, Markov stabilisation and tower compatibility (wtrace_incl) at z = q³/(q²+1), plus eq_wtrace_of_markov; SchurWeyl.MarkovTraceUnique.markovTrace_unique gives uniqueness. What is missing is that all of it lives in HeckeCoset.MarkovTraceFamily, a different Markov-trace abstraction, and nothing bridges it to OcneanuTrace.MarkovTrace — which is the structure this file's theorems consume. And qou-g8i1 is not that item at all: it is the (z+d) bond rule, and it is completed. The live carrier is qou-0fmb's re-scope of 2026-09-12, which names qou-ejde (heckeIncl injective) as the keystone that discharges it.

    • Strict growth is proved only at the bottom. twH_zero_lt_one gives H 0 < H 1; H n < H (n+1) for n ≥ 1 does not follow from the collapse map, which sends every generator to the same element. The symmetric-group instance does grow at every level (t_not_mem_shiftedUpTo) but has h = 0. No single carrier yet has both h ≠ 0 and growth at every level.

      The bean is qou-p8yg, not qou-uoal (corrected 2026-09-13: qou-uoal is completed, and it is the ≤ n! upper half). qou-p8yg records that H 1 < H 2 is a wiring job rather than a build — the rank-6 separator already exists sorry-free (SchurWeyl.HeckeDim3Dim.finrank_hecke3, sixBasis, HeckeDim3.braid3) — while general n needs the (n+1)! lower bound. It also records the negative that closes the cheap route: scalar_tail_forces_central excludes the whole tail-to-scalars family.

    Nothing here derives the bond product. That reading of the atom word remains measured, per DisjointBlockTraceLaw's own statement of scope.

    theorem QOU.MathlibExt.BraidedTowerInstances.s_far (m k : ℕ) (hk : k + 1 < m) :
    SymmetricGroupTowerWitness.s m * SymmetricGroupTowerWitness.s k = SymmetricGroupTowerWitness.s k * SymmetricGroupTowerWitness.s m

    Distant adjacent transpositions commute. Conjugating swap m (m+1) by s k fixes both endpoints when k + 1 < m, so the conjugation is trivial.

    Measuring the Hecke instance's trace, rather than assuming it #

    The three theorems the correction above rests on. They are about HeckeTowerWitness's trace only; nothing here touches BraidedTower, sandwichReduces_all, or any conclusion drawn from them.

    source
    theorem QOU.MathlibExt.BraidedTowerInstances.ocneanuTrace_mul_of_markov {R : Type u_1} [CommRing R] {h : R} (z : R) (hz : z * z = h * z + 1) (x y : HeckeRankTwoMarkov.Hecke2 R h) :
    (HeckeRankTwoMarkov.Hecke2.ocneanuTrace z) (x * y) = (HeckeRankTwoMarkov.Hecke2.ocneanuTrace z) x * (HeckeRankTwoMarkov.Hecke2.ocneanuTrace z) y

    The Markov hypothesis makes the rank-2 Ocneanu trace multiplicative.

    HeckeRankTwoMarkov.ocneanuTrace_mul_defect computes the defect on σ · σ as h * z + 1 - z * z; this shows the defect vanishes on every pair precisely under z * z = h * z + 1, which is the Markov condition.

    source
    theorem QOU.MathlibExt.BraidedTowerInstances.towerTrace_mul {R : Type u_1} [CommRing R] (h z : R) (hz : z * z = h * z + 1) (x y : HeckeTowerWitness.HeckeTower R h) :
    (HeckeTowerWitness.towerTrace h z) (x * y) = (HeckeTowerWitness.towerTrace h z) x * (HeckeTowerWitness.towerTrace h z) y

    Hence the presented tower's trace is an algebra homomorphism, since collapse is one and towerTrace = ocneanuTrace ∘ collapse.

    source
    theorem QOU.MathlibExt.BraidedTowerInstances.heckeTower_tr_mul_unconditional {R : Type u_1} [CommRing R] (h z : R) (hz : z * z = h * z + 1) (a b : HeckeTowerWitness.HeckeTower R h) :
    (HeckeTowerWitness.heckeTowerMarkovTrace h z hz).tr (a * b) = (HeckeTowerWitness.heckeTowerMarkovTrace h z hz).tr a * (HeckeTowerWitness.heckeTowerMarkovTrace h z hz).tr b

    The same fact in the form that makes the degeneracy unmissable: for this witness the trace law holds for arbitrary a and b, with no hypothesis about levels, so disjointBlock_heckeTower is an instance of it and carries no disjoint-block information.
