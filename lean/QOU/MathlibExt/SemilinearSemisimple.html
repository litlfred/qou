    Semisimplicity along semilinear maps #

    Mathlib's RingTheory/SimpleModule/Basic.lean carries the linear statements (IsSemisimpleModule.of_injective, .of_surjective) and leaves the semilinear ones as proof_wanted:

    proof_wanted _root_.LinearMap.isSemisimpleModule_of_injective (_ : Function.Injective l)
    [IsSemisimpleModule S N'] : IsSemisimpleModule R M'
proof_wanted _root_.LinearMap.isSemisimpleModule_of_surjective (_ : Function.Surjective l)
    [IsSemisimpleModule R M'] : IsSemisimpleModule S N'

    Each carries a TODO naming an API generalisation it was thought to need — "generalize Submodule.equivMapOfInjective from InvPair to RingHomSurjective" and "generalize LinearMap.quotKerEquivOfSurjective to SemilinearMaps". Neither generalisation is required, because neither proof needs a semilinear equivalence:

    • LinearMap.isSemisimpleModule_iff_of_bijective — the theorem sitting directly above the two proof_wanteds — takes a bijective semilinear map, not a ≃ₛₗ. A ≃ₛₗ is what forces RingHomInvPair, i.e. an invertible σ; a plain map does not.
    • So the injective case uses l.rangeRestrict, and the surjective case a complement of ker l rather than the quotient by it.

    One hypothesis is added: [RingHomSurjective σ]. It is absent from the proof_wanteds, and appears to be an oversight rather than a strengthening — LinearMap.range and Submodule.map are only defined for a semilinear map under it, and isSemisimpleModule_iff_of_bijective itself carries it.

    Semilinear of_injective, avoiding any ≃ₛₗ (and so any RingHomInvPair): isSemisimpleModule_iff_of_bijective wants a bijective semilinear MAP, and the range restriction of an injective l is one.
