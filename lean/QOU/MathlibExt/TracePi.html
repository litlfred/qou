    QOU.MathlibExt.TracePi — the trace of a block-diagonal endomorphism of a product #

    Bean qou-kwoa.

    Mathlib has LinearMap.trace_prodMap' for a binary product M × N, and nothing for an arbitrary finite product ∀ i, M i. This file supplies the missing statement:

    trace (⨁ᵢ fᵢ) = ∑ᵢ trace fᵢ

    Everything here is about LinearMap.trace alone — no algebra structure, no Hecke input — so it is a pure Mathlib-gap file and belongs under MathlibExt.

    Why it is needed here #

    QOU.SchurWeyl.heckeWedderburn lands in ∀ lam : Partition (n + 1), Matrix (SYT lam) (SYT lam) K, an arbitrary finite product rather than an iterated binary one. The nondegeneracy converse in RegTraceGramNondegenerate proves its block statement for a simple ring, and a product of matrix algebras is not simple, so the block verdicts have to be reassembled — which is exactly this sum formula, applied to lmul.

    Proof #

    Via LinearMap.trace_eq_matrix_trace in the basis Pi.basis b indexed by Σ i, ι i: the diagonal entry at ⟨j, k⟩ is (b j).repr (f j (b j k)) k, because a block-diagonal map sends Pi.single j v to Pi.single j (f j v). Summing over the sigma type in two stages gives the per-block matrix traces.
