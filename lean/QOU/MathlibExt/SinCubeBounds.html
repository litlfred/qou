    theorem QOU.MathlibExt.sub_cube_div_six_lt_sin {x : ℝ} (hx : 0 < x) :
    x - x ^ 3 / 6 < Real.sin x

    sin x > x − x³/6 for every x > 0 — the tighter form of Real.sin_gt_sub_cube, which Mathlib states only as x − x³/4 on (0,1].

    f = sin x − x + x³/6 has f(0) = 0 and f′ = cos x − 1 + x²/2 > 0, the latter being exactly Real.one_sub_sq_div_two_lt_cos.

    theorem QOU.MathlibExt.cos_lt_one_sub_sq_div_two_add_pow_four_div_24 {x : ℝ} (hx : 0 < x) :
    Real.cos x < 1 - x ^ 2 / 2 + x ^ 4 / 24

    cos x < 1 − x²/2 + x⁴/24 for every x > 0.

    g = 1 − x²/2 + x⁴/24 − cos x has g(0) = 0 and g′ = sin x − x + x³/6, which is positive by the previous theorem — the two bounds bootstrap.

    theorem QOU.MathlibExt.mul_cube_cos_lt_sin_cube {x : ℝ} (hx : 0 < x) (hxpi : x < Real.pi) :
    x ^ 3 * Real.cos x < Real.sin x ^ 3

    x³·cos x < sin³x on (0, π).

    For x ≥ π/2 this is cos x ≤ 0 < sin³x. For x < π/2 it is the ladder: cos x < 1 − x²/2 + x⁴/24 ≤ (1 − x²/6)³ (the last step needing only x² ≤ 9), so x³cos x < (x − x³/6)³ < sin³x.

    This is logSinc‴ < 0, i.e. logSinc″ is monotone — see the file header.
