              The five refutations #

              Each theorem below negates the proposition asserted by one of the five SDP axioms. They are stated at ℝ; for the two axioms quantified over a general ordered *-ring, refuting the ℝ instance refutes the general statement a fortiori.

              source

              ¬∀ {n : ℕ} {ι : Type} {sdp : SDP.SDPPrimal n ℝ ι} [Fintype ι] (sc : SDP.StrictComplementarityPair sdp) {Φ' : Matrix (Fin n) (Fin n) ℝ}, sdp.IsFeasible Φ' → sdp.objAt Φ' = sdp.objAt sc.Φstar → Φ' = sc.Φstar

              strict_complementarity_unique_axiom is FALSE. (QOU/MathlibExt/SDP.lean)

              theorem QOU.MathlibExt.SDPUniquenessCounterexamples.not_slater_strict_complementarity_kernel :
              ¬∀ {n : ℕ} {ι : Type} [inst : Fintype ι] {sdp : SDP.SDPPrimal n ℝ ι} (sc : SDPRealUniqueness.RealStrictComplementarityPair sdp) {Φ' : Matrix (Fin n) (Fin n) ℝ}, sdp.IsFeasible Φ' → sdp.objAt Φ' = sdp.objAt sc.Φstar → (∀ (i : ι), (sdp.constraint i * (Φ' - sc.Φstar)).trace = 0) → sdp.dualSlack sc.ystar * (Φ' - sc.Φstar) = 0 → (Φ' - sc.Φstar) * sdp.dualSlack sc.ystar = 0 → Φ' = sc.Φstar

              slater_strict_complementarity_kernel_axiom is FALSE — the complementarity-difference hypotheses hold vacuously when S = 0. (QOU/MathlibExt/SDPRealUniqueness.lean)
