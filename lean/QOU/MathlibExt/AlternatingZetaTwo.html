    The alternating ζ(2) — a Mathlib gap, and the Landen base value #

    Mathlib has hasSum_zeta_two : Σ 1/n² = π²/6 but no alternating analogue. Route 33 named Li₂(−1) = −π²/12 as the one value standing between hasDerivAt_landenCombo (the Landen leg's analytic core, proved) and Landen itself. This file supplies it.

    The derivation #

    Split Σ 1/(n+1)² into even and odd index:

    • odd index gives Σ 1/(2k+2)² = ¼·Σ 1/(k+1)² = π²/24;
    • so even index gives Σ 1/(2k+1)² = π²/6 − π²/24 = π²/8.

    The alternating series has the same two pieces with the even one negated, so it sums to −π²/8 + π²/24 = −π²/12.

    The indexing is the corpus's: LiTwo x = Σ' x^{k+1}/(k+1)², so LiTwo(−1) is literally Σ' (−1)^{k+1}/(k+1)² and the statement below matches it termwise.

    This file imports only Mathlib, so it can go upstream unchanged — the same discipline ComplexDilogarithm.lean follows.
