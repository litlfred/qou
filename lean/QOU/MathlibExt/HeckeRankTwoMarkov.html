    The rank-two Hecke (Iwahori) algebra and its Ocneanu/Markov trace #

    This file constructs, concretely and sorry-free, the single-generator Hecke algebra H₂(q) = R[σ] / (σ² = h·σ + 1) (with h = q - q⁻¹ the substrate bandwidth) as a rank-two free R-algebra, and equips it with the Ocneanu/Markov trace tr(a·1 + b·σ) = a + z·b.

    Why this exists #

    QOU.MathlibExt.OcneanuTrace defines the abstract Markov-trace functional (the tower H, generators g/ginv, the parameters z/zinv, the trace and Markov axioms) and derives its general consequences. Two concrete instances of that structure already exist in the corpus:

    • unitMarkovTrace — A = R, generators are scalar units. Non-degenerate in z but degenerate in the algebra (no genuine crossing).
    • QOU.MathlibExt.SymmetricGroupTowerWitness — the genuine growing non-commutative tower MonoidAlgebra R (Equiv.Perm ℕ), but at q = 1, where every generator squares to 1 (h = 0) and the Markov parameter is forced to z = 0. It exercises the tower/filtration content but not the Hecke quadratic relation at q ≠ 1.

    The piece those two miss — and which this file supplies — is a concrete algebra in which the quadratic relation σ² = h·σ + 1 genuinely bites: h ≠ 0, the two Markov parameters differ (zinv = z - h ≠ z), and the trace is not multiplicative on σ. That is exactly the q ≠ 1 content, at the smallest level (one generator, H₂).

    Scope (what this does NOT do) #

    H₂ has a single generator, so it cannot instantiate the infinite tower of OcneanuTrace.MarkovTrace: the stabilisation axiom tr(a · g n) = z · tr a for every level n forces degeneracy once the tower stops growing. The genuine non-commutative Hecke tower H_∞(q) at q ≠ 1 — where the braid relation is written and SandwichReduces must be proved by rewriting rather than by a permutation-support argument — remains the hard-Mathlib-gap epic (bean qou-08a2 / qou-301d). This file is the q ≠ 1, single-generator witness, complementary to the q = 1, infinite-tower symmetric-group witness.

              Non-degeneracy — why this is a genuine q ≠ 1 Hecke functional #

              source
              theorem QOU.MathlibExt.HeckeRankTwoMarkov.Hecke2.markovParam_ne_iff {R : Type u_1} [CommRing R] {h : R} (z : R) :
              z ≠ z - h ↔ h ≠ 0

              The two Markov parameters differ iff the bandwidth is nonzero, i.e. iff q ≠ 1. (The symmetric-group witness has h = 0, so there z = zinv.)

              source
              theorem QOU.MathlibExt.HeckeRankTwoMarkov.Hecke2.ocneanuTrace_mul_defect {R : Type u_1} [CommRing R] {h : R} (z : R) :
              (ocneanuTrace z) (sigma * sigma) - (ocneanuTrace z) sigma * (ocneanuTrace z) sigma = h * z + 1 - z * z

              The multiplicativity defect equals the Hecke quadratic. The trace is multiplicative on σ (tr(σ²) = tr(σ)²) exactly when z is a root of the Hecke quadratic X² - h·X - 1. Generically it is not, so the trace is a genuinely non-multiplicative functional — the whole point of a Markov trace.

              source
              theorem QOU.MathlibExt.HeckeRankTwoMarkov.Hecke2.exists_nonmultiplicative :
              ∃ (h : ℚ) (z : ℚ), (ocneanuTrace z) (sigma * sigma) - (ocneanuTrace z) sigma * (ocneanuTrace z) sigma ≠ 0

              A concrete non-degenerate instance over ℚ: at h = 1, z = 0 the multiplicativity defect is 1 ≠ 0, so the Ocneanu trace on H₂(ℚ) is a genuinely non-multiplicative functional (witnessing non-vacuity of ocneanuTrace_mul_defect).
