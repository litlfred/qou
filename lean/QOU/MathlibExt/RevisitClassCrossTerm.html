    Which non-monotone words carry a cross term — the revisit-class prune #

    MonotoneWordTraceFactorizes proves that an ascending word factorizes. This file asks the converse question the formalize-first discipline requires before any probe is run: which departures from monotonicity produce a cross term, and which are cross-term-free? A word is non-monotone when some generator g m recurs after a higher generator has appeared. The class is stratified by what lies between the two occurrences, and the answer is sharp:

    revisit pattern (x ∈ H m) cross term declaration
    x · gₘ · gₘ₊₁ · gₘ — one step up and back none (cyclicity alone) oneStepRevisit_eq_monotone
    x · gₘ · gₘ₊₂ · gₘ — skip the neighbour none (far commutation) skipRevisit_eq_monotone
    x · gₘ · gₘ₊₁ · gₘ₊₂ · gₘ — climb two, come back none twoStepClimbRevisit_eq_monotone
    x · gₘ · gₘ₊₁ · gₘ · gₘ₊₁ — the cyclic square (gₘ gₘ₊₁)² z² − h z − 1 cyclicSquare_cross_term

    So a cross term is not produced by a bond re-crossing after its neighbour, nor by any single revisit that climbs and returns. It is produced exactly when two adjacent generators alternate — gₘ gₘ₊₁ gₘ gₘ₊₁ — which is the braid (σₘ σₘ₊₁)² whose closure on three strands is the torus knot T(3,2) (one component, the three strands cyclically permuted), against the monotone gₘ² gₘ₊₁² whose closure is the Hopf chain (three components). The n = 4 word of MarkovTraceInterleavedCrossTerm is this three-strand object stabilised once (interleaved_eq_stab_cyclicSquare); the cross term there is z · (z² − h z − 1).

    Correction of an earlier claim (2026-09-04). MarkovTraceInterleavedCrossTerm and the audit of 2026-09-03 describe n = 4 as "the smallest instance where the product formula fails". It is not: the smallest instance is n = 3, content (2, 2), the cyclic square against the Hopf chain, with cross term exactly the convention-D Markov defect z² − h z − 1 (no z prefactor). qou-ls86's n = 3 identity concerned content (2, 1) only, where the single interleaved word is a rotation of the monotone one.

    Reading for the nucleus #

    Three adjacent strands cyclically braided is the algebraic signature of a closed triple — (σₘ σₘ₊₁)², closure T(3,2) — against the pairwise chain the production word writes. In the production atom word the class has two realisations, and only the first is choice-free:

    • A cyclic-triple bond (any A ≥ 2). The bond letter B at generator 3k+2 is doubled and its two crossings alternate with the last two intra crossings of nucleon k at 3k+1 (or, mirror-wise, the first two of nucleon k+1 at 3k+3): … L₁L₂L₃ · B · L₄ · B …. The three strands are adjacent, no conjugation is needed, and the cross term against the same-content monotone word (a two-crossing Hopf-clasp bond) is exactly b(L₁L₂L₃) · (z² − hz − 1) · tr(prefix) · ∏ tr(suffix runs) by cyclicSquare_cross_term plus multilinearity in the affine letters. This is what computations/probes/cyclic_triple_bond_cross_term_probe.py measures.
    • A cyclic coordination graph (A ≥ 3): three nucleons each bonded to the other two. On the linear strand layout the closing bond joins non-adjacent strands and needs a band generator (a conjugated crossing passing over or under the middle nucleon), so this realisation carries a choice the algebra does not make for it. Not probed here.

    What is excluded either way: a bond that merely re-crosses its neighbour, reaches over it and returns, or is stacked as a clasp B² — none of these leaves the monotone trace.

    Base ring (§7c) #

    Generic CommRing R, Ring A, through MarkovTrace (T1–T3). The Hecke quadratic, the braid relation and far commutation are hypotheses on the generators where used; each theorem names exactly the ones it needs.

    Cross-term-free revisits #

    source
    theorem QOU.MathlibExt.RevisitClass.oneStepRevisit_eq_monotone {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : OcneanuTrace.MarkovTrace R A) (m : ℕ) (x : A) (hx : x ∈ T.H m) :
    T.tr (x * T.g m * T.g (m + 1) * T.g m) = T.tr (x * T.g m * T.g m * T.g (m + 1))

    One-step revisit carries no cross term. For any prefix x ∈ H m, tr(x gₘ gₘ₊₁ gₘ) = tr(x gₘ gₘ gₘ₊₁): rotate the trailing gₘ to the front, peel gₘ₊₁, rotate back. Cyclicity and one Markov move only — no braid relation, no quadratic. This is qou-ls86's n = 3 identity with an arbitrary prefix.

    theorem QOU.MathlibExt.RevisitClass.skipRevisit_eq_monotone {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : OcneanuTrace.MarkovTrace R A) (m : ℕ) (x : A) (hcomm : T.g (m + 2) * T.g m = T.g m * T.g (m + 2)) :
    T.tr (x * T.g m * T.g (m + 2) * T.g m) = T.tr (x * T.g m * T.g m * T.g (m + 2))

    Skipping the neighbour carries no cross term. If gₘ₊₂ commutes with gₘ, x gₘ gₘ₊₂ gₘ = x gₘ gₘ gₘ₊₂ outright.

    theorem QOU.MathlibExt.RevisitClass.twoStepClimbRevisit_eq_monotone {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : OcneanuTrace.MarkovTrace R A) (m : ℕ) (x : A) (hx : x ∈ T.H m) (hcomm : T.g (m + 2) * T.g m = T.g m * T.g (m + 2)) :
    T.tr (x * T.g m * T.g (m + 1) * T.g (m + 2) * T.g m) = T.tr (x * T.g m * T.g m * T.g (m + 1) * T.g (m + 2))

    Climbing two steps and returning carries no cross term. x gₘ gₘ₊₁ gₘ₊₂ gₘ: move gₘ past gₘ₊₂ (far commutation), peel gₘ₊₂ (Markov), then the one-step identity.

    The cross-term-bearing revisit: the cyclic square #

    source
    theorem QOU.MathlibExt.RevisitClass.tr_hopfChain {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : OcneanuTrace.MarkovTrace R A) (m : ℕ) (h : R) (x : A) (hx : x ∈ T.H m) (hq0 : T.g m * T.g m = h • T.g m + 1) (hq1 : T.g (m + 1) * T.g (m + 1) = h • T.g (m + 1) + 1) :
    T.tr (x * T.g m * T.g m * (T.g (m + 1) * T.g (m + 1))) = (h * T.z + 1) ^ 2 * T.tr x

    The Hopf-chain trace with prefix: tr(x gₘ² gₘ₊₁²) = (hz+1)² · tr x.

    theorem QOU.MathlibExt.RevisitClass.tr_cyclicSquare {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : OcneanuTrace.MarkovTrace R A) (m : ℕ) (h : R) (x : A) (hx : x ∈ T.H m) (hq0 : T.g m * T.g m = h • T.g m + 1) (hbraid : T.g m * T.g (m + 1) * T.g m = T.g (m + 1) * T.g m * T.g (m + 1)) (hxc : x * T.g (m + 1) = T.g (m + 1) * x) :
    T.tr (x * T.g m * T.g (m + 1) * T.g m * T.g (m + 1)) = (h * (T.z * (h * T.z + 1)) + T.z ^ 2) * T.tr x

    The cyclic-square trace with prefix: tr(x gₘ gₘ₊₁ gₘ gₘ₊₁) = (h z (h z + 1) + z²) · tr x, via the braid relation and the quadratic. Requires x to commute with gₘ₊₁ (far commutation of the prefix with the new generator).

    theorem QOU.MathlibExt.RevisitClass.cyclicSquare_cross_term {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : OcneanuTrace.MarkovTrace R A) (m : ℕ) (h : R) (x : A) (hx : x ∈ T.H m) (hq0 : T.g m * T.g m = h • T.g m + 1) (hq1 : T.g (m + 1) * T.g (m + 1) = h • T.g (m + 1) + 1) (hbraid : T.g m * T.g (m + 1) * T.g m = T.g (m + 1) * T.g m * T.g (m + 1)) (hxc : x * T.g (m + 1) = T.g (m + 1) * x) :
    T.tr (x * T.g m * T.g (m + 1) * T.g m * T.g (m + 1)) - T.tr (x * T.g m * T.g m * (T.g (m + 1) * T.g (m + 1))) = (T.z ^ 2 - h * T.z - 1) * T.tr x

    THE MINIMAL CROSS TERM — three strands. With the same content (2, 2), the cyclic square (gₘ gₘ₊₁)² and the Hopf chain gₘ² gₘ₊₁² differ by exactly the convention-D Markov defect: tr(x (gₘ gₘ₊₁)²) − tr(x gₘ² gₘ₊₁²) = (z² − h z − 1) · tr x. This is the smallest instance where the product formula fails — n = 3, not n = 4.

    source
    theorem QOU.MathlibExt.RevisitClass.interleaved_eq_stab_cyclicSquare {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (T : OcneanuTrace.MarkovTrace R A) :
    T.tr (T.g 0 * T.g 1 * T.g 0 * T.g 2 * T.g 1) = T.z * T.tr (T.g 1 * T.g 0 * T.g 1 * T.g 0)

    The n = 4 interleaved word is the stabilised cyclic square. tr(g₀ g₁ g₀ g₂ g₁) = z · tr((g₁ g₀)²): rotate g₁ to the front, peel g₂. So the n = 4 cross term z (z² − h z − 1) is the three-strand one times a Markov stabilisation — the object behind the cross term is the torus knot T(3,2) of the cyclically braided triple, not anything four-strand.

    Convention D: the three-strand cross term in closed form #

    source
    theorem QOU.MathlibExt.RevisitClass.cyclicSquare_cross_term_neg_convD (q : ℝ) (hq : 0 < q) :
    (q ^ 3 / (q ^ 2 + 1)) ^ 2 - (q - q⁻¹) * (q ^ 3 / (q ^ 2 + 1)) - 1 < 0

    At convention D the three-strand cross term is −(q⁴ + q² + 1)/(q² + 1)² — the Markov defect itself (markovDefect_convD) — and it is negative for every real q > 0: the cyclic square's trace is smaller than the Hopf chain's, so a cyclically braided triple carries extra log-suppression, i.e. extra binding.
