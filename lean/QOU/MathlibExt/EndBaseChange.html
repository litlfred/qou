    QOU.MathlibExt.EndBaseChange — the endomorphism algebra base-changes #

    For a finite free module M over a commutative ring R and an R-algebra A, extension of scalars carries the endomorphism algebra to the endomorphism algebra:

    A ⊗[R] Module.End R M ≃ₐ[R] Module.End A (A ⊗[R] M).

    Why this file exists #

    Mathlib carries the map but not its bijectivity. Module.End.baseChangeHom has type Module.End R M →ₐ[R] Module.End A (A ⊗[R] M), and Module.endTensorEndAlgHom is likewise an algebra hom; neither comes with a lemma saying the induced map out of A ⊗[R] Module.End R M is an equivalence. A name scan over all 6990 Mathlib modules in the workspace found no such lemma (bean qou-dr1c).

    The gap matters for the k[S_n] division-ring collapse — residual item 1 of SnWedderburnPartitionBridge.sn_isotypic_specht_split, scoped in docs/audits/2026-08-10-sn-division-ring-collapse-scoping.md. The collapse argument needs S^μ to stay simple after extending scalars to an algebraic closure, and the standard route to that runs End ⊗ K ≅ End_K(· ⊗ K) followed by Schur. This file supplies that step at the level of plain modules.

    Scope. This is the module-level statement only. The application needs the equivariant version, K ⊗_k End_{k[G]}(V) ≅ End_{K[G]}(K ⊗_k V), which does not follow formally from this one: it additionally needs that taking G-invariants commutes with the base change. For finite G in characteristic zero that is available through the averaging idempotent, since extension of scalars preserves the image of an idempotent, but it is not proved here. So this file is a rung, not the item.

    Construction #

    Through matrices, which keeps every step an existing Mathlib equivalence:

    A ⊗[R] End R M ≃ A ⊗[R] Matrix ι ι R ≃ Matrix ι ι A ≃ End A (A ⊗[R] M)

    using LinearMap.toMatrixAlgEquiv at both ends and matrixEquivTensor in the middle. endBaseChangeEquiv_tmul then identifies the result with the canonical map a ⊗ₜ f ↦ a • LinearMap.baseChange A f, which is what makes the equivalence usable rather than merely an existence statement — without it the definition would only say that some isomorphism exists.

    The equivalence is stated over R. It is in fact A-linear, but A-linearity is not needed by the intended consumer and matrixEquivTensor is itself only an R-algebra equivalence, so no attempt is made to strengthen it here.
