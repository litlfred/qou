    Landen's combination is locally constant — the analytic core the corpus lacks #

    ComplexDilogarithm.lean lists, among what it does not provide, "the inversion formula Li₂ z + Li₂ (1/z) = −π²/6 − ½·log(−z)²". That family — inversion and Landen — is what qou-rstq item 4 needs, because identifying the piecewise extend with Re of the analytic Rogers L is those two identities. Route 33 measures the identification at 1e-50 in all three regimes; this file supplies the analytic half of the Landen leg.

    What is proved #

    d/dz [ Li₂(z) + Li₂(z/(z−1)) + ½·log(1−z)² ] = 0

    (hasDerivAt_landenCombo), wherever the three arguments are legal. The three terms' derivatives are

    −log(1−z)/z ,   −log(1−z)/(z(z−1)) ,   log(1−z)/(z−1)

    and they cancel because −1/z − 1/(z(z−1)) + 1/(z−1) = 0 identically. The middle one is where the branch enters: it needs log(1 − z/(z−1)) = −log(1−z), i.e. log(1/(1−z)) = −log(1−z), which holds exactly when 1−z avoids the log cut — hence the slitPlane hypothesis, stated rather than assumed.

    The constant, and how it is pinned #

    A vanishing derivative gives Landen only up to a constant. That constant is pinned below (landenCombo_ofReal_eq_zero), on the negative real axis — the regime extend actually uses — closing what Route 33 G5 recorded as the one thing still missing from this leg.

    The base point is the limit z → 0⁻, not z = −1, and that is the whole trick. At z = −1 the combination is Li₂(−1) + Li₂(½) + ½·log 2²; those three cancel exactly, but pinning there would need Li₂(½) = π²/12 − ½·log 2², which Mathlib does not have. At 0 every term vanishes outright (cLiTwoExt_zero, log 1 = 0), so no special value is needed at all. The endpoint costs nothing because Ico t 0 already excludes the one point where hasDerivAt_landenCombo's hypotheses fail (z ≠ 0), and continuity there is supplied separately by continuousOn_landenCombo_ofReal.

    Route 34 G3 checks this is a real economy rather than a stylistic preference: each of the three pieces at z = −1 is individually nonzero.

    What is still not proved #

    The inversion leg (x > 1) is harder and is not attempted: x > 1 lies on cLiTwoExt's cut, so it needs a boundary value from off the cut, not just a constant of integration. Route 33 G5 records it as the sharper of the two, and Route 34 G5 checks adversarially that this file does not reach it — the combination is visibly nonzero at t = 2.24698, the one argument extended_sum uses in that regime.

    Nor does this close qou-rstq item 4. Identifying the corpus's piecewise extend with Re of the analytic Rogers L still needs the real-part bookkeeping on top of these identities. This closes one of the two analytic legs that item rests on.

    Closing the constant: Landen holds outright on the negative reals #

    The derivative above leaves the identity only up to a constant. Route 33 G5 recorded the connectedness step as the one thing still missing from the Landen leg. It is closed here, on the negative real axis — the regime extend actually uses.

    The constant is pinned at the limit z → 0⁻, not at z = −1. That choice is what makes this self-contained: at z = −1 the combination evaluates to Li₂(−1) + Li₂(½) + ½·log 2², so pinning there would need the special value Li₂(½) = π²/12 − ½·log 2², which is not in Mathlib. At 0 every term vanishes outright (cLiTwoExt_zero, and log 1 = 0), so no special value is needed at all. The exceptional point costs nothing because Ico t 0 already excludes it.
