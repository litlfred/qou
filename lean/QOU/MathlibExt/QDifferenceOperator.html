      def QOU.MathlibExt.QDifferenceOperator.qDiff {R : Type u_1} [CommRing R] (q : R) (f : R → R) :
      R → R

      The q-difference operator (numerator form) Δ_q f = x ↦ f(q·x) − f(x). Equals (q−1)·x · D_q f(x) for the Jackson derivative D_q; division-free, so total over any CommRing.

        theorem QOU.MathlibExt.QDifferenceOperator.qDiff_mul {R : Type u_1} [CommRing R] (q : R) (f g : R → R) (x : R) :
        qDiff q (fun (y : R) => f y * g y) x = qDiff q f x * g x + f (q * x) * qDiff q g x

        q-Leibniz (product) rule — the clean one: Δ_q(f·g)(x) = Δ_q(f)(x)·g(x) + f(q·x)·Δ_q(g)(x). This is the structural reason q-difference modules are well-behaved.

        Monomial action. Δ_q(·^n)(x) = (q^n − 1)·x^n. (Divide by (q−1)x to recover D_q(x^n) = [n]_q·x^{n−1}.)

        theorem QOU.MathlibExt.QDifferenceOperator.qDiff_comp_monomial {R : Type u_1} [CommRing R] (q x : R) (m : ℕ) (f : R → R) :
        qDiff q (fun (y : R) => f (y ^ m)) x = qDiff (q ^ m) f (x ^ m)

        The monomial q-chain rule — the only surviving composition rule, with q rescaled to q^m: Δ_q(f ∘ (·^m))(x) = Δ_{q^m}(f)(x^m), because (q·x)^m = q^m·x^m.

        theorem QOU.MathlibExt.QDifferenceOperator.qDiff_comp_no_naive_chain :
        qDiff 2 (fun (y : ℚ) => (y ^ 2) ^ 2) 1 ≠ qDiff 2 (fun (y : ℚ) => y ^ 2) (1 ^ 2) * qDiff 2 (fun (y : ℚ) => y ^ 2) 1

        No naive q-chain rule for a non-monomial inner function. Concrete counterexample over ℚ: with f = g = (·²) (so f ∘ g = (·⁴)), Δ₂((·²)∘(·²))(1) = 15, but the naive "product of q-derivatives" Δ₂(·²)(1²)·Δ₂(·²)(1) = 3·3 = 9. 15 ≠ 9 — implicit q-differentiation through a non-monomial branch does not close.
