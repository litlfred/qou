    Markov normalisation of the Jones–Markov weights (convention D, n = 3) #

    The Jones–Markov weights y_λ on H_n(q) are characterised by the normalisation

    ∑_{λ ⊢ n} y_λ · dim V_λ = 1

    This file proves that identity at n = 3 for the convention-D weights, as an identity of rational functions in q — not a numerical check at any particular q₀.

    Why this file exists #

    The convention-D weights were validated three ways before this: agreement with the Rust trace_weights_n engine (1.2e-15), the vanishing of every weight on a partition with three or more rows, and agreement between two independently generated numeric tables (~1e-50). Each of those compares the weights against another implementation or a shared convention. None tests the defining property.

    Eight hypotheses were raised and refuted chasing a residual in the Schur–Weyl identity before anyone checked whether ∑ y_λ · dim = 1 held at all. It does — symbolically, for n = 2, …, 6. This is the n = 3 case made machine-checkable.

    Convention D #

    z = q³/(q²+1), which forces r = 2 in the Wenzl bridge q·z = Q^r(1-Q)/(1-Q^r) with Q = q². Since r is the number of variables in the Schur principal specialisation, r = 2 is a two-dimensional fibre, and a Schur polynomial in two variables vanishes on any partition with a third row. Hence y_{(1,1,1)} = 0 below is forced, not imposed.

    Base ring #

    Stated over a generic [Field R] per the §7c base-ring convention: this is q-deformation combinatorics with no archimedean content, so specialising to ℝ would be gratuitous. The only hypothesis is q^2 + 1 ≠ 0, which is what makes the weights well-defined.

    -- Ref: [jones1987] https://doi.org/10.2307/1971403 -- Ref: [wenzl1988] https://doi.org/10.1007/BF01393695

              Why the sign weight vanishes #

              The canonical proof of this fact is upstream, not here. origin/main already carries it, sorry-free and for every level:

              • QOU.QBeta.TemperleyLiebTower.conventionD_kills_antisymmetriser — the base case n = 3, derived from the three Markov moment equations together with z·(q²+1) = q³ (which is convention D).
              • QOU.Mathlib.YoungDiagramThreeRowCorner.threeRow_vanishing_all_levels — the lift to every n > 3.

              Cite those when the fact is needed. The lemmas below are not an independent establishment of it and must not be read as one: they are the bridge-side mechanism, showing how the same vanishing falls out of the Schur principal specialisation at r = 2 rather than out of the trace axioms. Two routes to one conclusion, of which the upstream one is stronger (all levels, from the defining equations) and is the one to depend on.

              ySign := 0 above is a definition, so any lemma concluding ySign q = 0 by rfl would prove nothing about convention D — it would restate the definition. The content is that convention D forces that zero, and that is what the next lemma derives.

              In the Wenzl bridge the weight of λ carries the factor ∏_{x ∈ λ} (1 - X · Q^{c(x)}) with Q = q² and X = Q^r. Convention D pins r = 2, so X = Q². A partition with a third row has a cell at (i,j) = (2,0), whose content is c = j - i = -2, contributing the factor 1 - Q² · Q^{-2} = 0 and annihilating the whole product.

              ∏ x ∈ s, (1 - Q ^ 2 * Q ^ c x) = 0

              The vanishing, for any partition shape.

              The Wenzl-bridge weight of λ carries ∏_{x ∈ λ} (1 - X · Q^{c(x)}) over the cells of λ. Under convention D, X = Q². This says: if any cell has content -2, the whole product is zero — so the conclusion does not depend on the shape of λ beyond it having such a cell.

              Every partition with three or more rows has one, at (i,j) = (2,0) where c = j - i = -2. Cells are left abstract (s : Finset ι with contents c : ι → ℤ) precisely so the lemma is about the content, not about a particular encoding of Young diagrams.

Stated as the contrapositive so it is falsifiable rather than definitional.

              Convention D is the r = 2 solution of the Wenzl bridge #

              Everything above takes X = Q² (equivalently r = 2) as given. This section derives it from the bridge equation itself, which is what makes convention D a solution rather than a choice.

              The bridge is q·z = Q^r (1-Q)/(1-Q^r) with Q = q². The next two lemmas show that at r = 2 it collapses to q·z = Q²/(1+Q), and that this holds exactly for z = q³/(q²+1) — the definition of convention D.

              This was asserted in prose when the migration landed; it is now checked.

              Convention D is the r = 2 bridge solution.

              With Q = q², the r = 2 bridge q·z = Q²/(1+Q) holds for z = q³/(q²+1).

              So z = q³/(q²+1) is not a convention chosen over 1/(q^{1/2}+q^{-1/2}) — it is the value solving the bridge at an integer r = 2, and r is the number of variables in the Schur principal specialisation. Convention C solves the same equation at a non-integer r, which is why nothing vanishes there (wenzl_factor_nonzero_of_ne).
