    theorem QOU.MathlibExt.hasSum_gaussian_theta (a c : ℝ) (ha : 0 < a) :
    HasSum (fun (n : ℤ) => Complex.exp (-↑a * (↑n - ↑c) ^ 2)) (↑(Real.pi / a) ^ (1 / 2) * jacobiTheta₂ (-↑c) (Complex.I * ↑Real.pi / ↑a))

    ∑_{n∈ℤ} e^{−a(n−c)²} = √(π/a) · θ₂(−c, iπ/a), as a HasSum, for every a > 0 and every real shift c.

    Exact — no asymptotics. The n = 0 term of θ₂(−c, iπ/a) is 1 and the rest is O(e^{−π²/a}), while √(π/a) = ∫_ℝ e^{−a(x−c)²} dx; so this is the precise statement that replacing the Laplace sum by the Laplace integral costs only an exponentially small relative error, uniformly in the shift c.

    theorem QOU.MathlibExt.hasSum_gaussian_theta_tilt (a c t : ℝ) (ha : 0 < a) :
    HasSum (fun (n : ℤ) => Complex.exp (-↑a * (↑n - ↑c) ^ 2 + ↑t * (↑n - ↑c))) (Complex.exp (↑t ^ 2 / (4 * ↑a)) * ↑(Real.pi / a) ^ (1 / 2) * jacobiTheta₂ (-↑(c + t / (2 * a))) (Complex.I * ↑Real.pi / ↑a))

    The tilted sum — every Gaussian moment at once.

    ∑_{n∈ℤ} e^{−a(n−c)² + t(n−c)} = e^{t²/4a}·√(π/a)·θ₂(−(c + t/2a), iπ/a).

    Completing the square is a shift of c by t/2a, so this is hasSum_gaussian_theta with no new analytic input. It is the moment generating function of the discrete Gaussian: the m-th t-derivative at 0 is ∑_k (k−c)^m e^{−a(k−c)²}, and the e^{t²/4a}·√(π/a) prefactor is exactly the CONTINUUM generating function ∫_ℝ e^{−ax²+tx} dx. The entire discrete-vs-continuum discrepancy, at every moment, is therefore the single factor θ₂(−(c + t/2a), iπ/a) = 1 + O(e^{−π²/a}), uniformly in c and t.

    That is the sense in which the cubic-and-higher remainder of a Laplace potential cannot produce a polynomial correction: it enters only through moments, and the moments are exponentially faithful. (The differentiation step itself is not formalised here — see the file header.)
