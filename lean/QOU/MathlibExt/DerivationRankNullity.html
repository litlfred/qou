    QOU.MathlibExt.DerivationRankNullity #

    Rank–nullity reduction for the derivation space of a finite-dimensional (not necessarily associative) algebra, targeting the octonion case dim Der(𝕆) = 14 (the compact G₂).

    For a bilinear multiplication m on a finite-dimensional space V, the Leibniz-defect operator

    L : End(V) →ₗ Bil(V, V; V), L(D)(x, y) = D(m x y) − m (D x) y − m x (D y)

    has ker L = Der(V, m) by definition of a derivation. Rank–nullity then gives

    dim Der(V, m) + rank L = (dim V)²,

    so for an 8-dimensional algebra (dim End = 64, proved here as finrank_end) the G₂ dimension count reduces to a rank computation:

    dim Der = 14 ⟺ rank L = 50.

    What this file does NOT prove #

    dim Der(𝕆) = 14 itself. That requires the octonion multiplication and a rank-50 witness for its defect operator (the explicit-basis route); this file supplies the exact interface such a witness must plug into, for any 8-dimensional algebra. No claim is made that every 8-dimensional algebra has a 14-dimensional derivation space (false — e.g. the zero multiplication has Der = End, rank L = 0).

    Wall / base-ring note (§7c) #

    Everything here is linear algebra over a generic field K — no ordering, no Real.*, nothing archimedean. The octonion instantiation over ℝ (where the compact G₂ lives) specializes K := ℝ downstream; the reduction itself is field-agnostic.
