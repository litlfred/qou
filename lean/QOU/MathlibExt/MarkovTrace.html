    Markov Trace on Hecke-Algebra Representations #

    The Markov trace on H_n(q) is the linear functional that turns a braid word into its Jones–Markov invariant. On a fixed finite-dimensional matrix representation ρ : HeckeRep n d (over the ground ring R_t = ℤ[t, t⁻¹], see QOU.Archimedean.HeckeRep) the representation character

    tr_ρ(w) = (ρ.eval w).trace (= HeckeRep.character ρ w)

    is the un-normalised, single-irrep shadow of the Markov trace. This file proves the two structural properties every Markov-type trace inherits from the ordinary matrix trace, on the concrete HeckeRep framework:

    1. Trace property tr(AB) = tr(BA) — lifted to braid words as tr_ρ(v ++ w) = tr_ρ(w ++ v) (character_append_comm), i.e. the character is a class function / cyclic-word invariant.
    2. Conjugation invariance for the standard generators tr_ρ(σ_i · A · σ_i⁻¹) = tr_ρ(A) and the σ_i⁻¹-conjugate (trace_conj_gen / trace_conj_genInv), together with the word-level form character_conj_word.

    The enabling lemma is HeckeRep.eval_append: braid-word evaluation is a monoid homomorphism from list concatenation to matrix multiplication. It extends the HeckeRep API (it is declared here under QOU.Archimedean, its proper namespace, so ρ.eval_append dot-notation resolves) and is the structural bridge that lets the ordinary-matrix trace_mul_comm speak about braid words.

    Scope / honesty note #

    HeckeRep.character is the trace on one representation; the full Jones–Markov trace is the y_λ-weighted sum over the Wedderburn blocks λ ⊢ n (see QOU.Mathlib.HeckeAlgebra.MarkovTrace for the abstract uniqueness class, and QOU.Braiding.HnMarkovTrace.MarkovTraceTower for the tower axioms). What is proved here is the cyclic / conjugation structure those weighted traces inherit block-by-block — not the normalisation tr_M(1) = 1 nor the Markov peel axiom, which are representation-independent and live in those files.

    §1 Braid-word evaluation is a homomorphism #

    Declared under QOU.Archimedean so it extends the HeckeRep API alongside HeckeRep.eval / HeckeRep.character (fully-qualified QOU.Archimedean.HeckeRep.eval_append, supporting ρ.eval_append dot-notation).

    source
    theorem QOU.Archimedean.HeckeRep.eval_append {n d : ℕ} (ρ : HeckeRep n d) (v w : BraidWord n) :
    ρ.eval (v ++ w) = ρ.eval v * ρ.eval w

    Evaluation is a monoid homomorphism. Evaluating the concatenation of two braid words is the product of their evaluations: ρ.eval (v ++ w) = ρ.eval v * ρ.eval w.

    This is the structural fact that makes HeckeRep.character behave like a trace on the braid monoid. Proved by induction on the first word.

    §2 Conjugation invariance of the matrix trace (QOU-free) #

    A one-line consequence of cyclicity that Mathlib does not package under a convenient name. It is the algebraic core of the Markov trace's class-function property.

    source
    theorem QOU.MathlibExt.MarkovTrace.trace_conj_of_mul_eq_one {R : Type u_1} [CommRing R] {m : Type u_2} [Fintype m] [DecidableEq m] {M N A : Matrix m m R} (h : N * M = 1) :
    (M * A * N).trace = A.trace

    Trace of a two-sided conjugate. If N · M = 1 then tr(M · A · N) = tr(A) for any square matrix A.

    With N = M⁻¹ this is the usual similarity-invariance tr(M A M⁻¹) = tr(A); stated with a bare left-inverse hypothesis so it applies to the Hecke generator/inverse pair, which are two-sided inverses of each other but only a one-sided hypothesis is needed here.

      §4 Conjugation invariance for the standard generators #

      The Markov trace is invariant under conjugation by any braid generator: the Jones–Markov trace is a trace on H_n(q), so tr(σ_i x σ_i⁻¹) = tr(x). On a representation this reduces, via eval_append, to matrix similarity invariance (trace_conj_of_mul_eq_one) using the generator/inverse relations σ_i · σ_i⁻¹ = 1 = σ_i⁻¹ · σ_i (HeckeRep.gen_mul_genInv / HeckeRep.genInv_mul_gen).

      source
      theorem QOU.MathlibExt.MarkovTrace.trace_conj_gen {n d : ℕ} (ρ : Archimedean.HeckeRep n d) (i : Fin (n - 1)) (A : Matrix (Fin d) (Fin d) Archimedean.R_t) :
      (ρ.gen i * A * ρ.genInv i).trace = A.trace

      Conjugation by a generator σ_i preserves the trace at the matrix level: tr(σ_i · A · σ_i⁻¹) = tr(A).

      theorem QOU.MathlibExt.MarkovTrace.character_conj_word {n d : ℕ} (ρ : Archimedean.HeckeRep n d) (i : Fin (n - 1)) (w : Archimedean.BraidWord n) :

      Generator-conjugation invariance of the Markov trace on braid words. Prepending σ_i and appending σ_i⁻¹ to a word w leaves the representation character unchanged: tr_ρ((i,+) :: (w ++ [(i,−)])) = tr_ρ(w).

      This is the word-level statement of trace_conj_gen, obtained by evaluating the singleton generators via eval_append.

      §5 The Wedderburn-weighted Markov trace tr_M = Σ_λ y_λ · χ^λ #

      The full Jones–Markov trace is the y_λ-weighted sum of the per-block characters over the Wedderburn decomposition H_n(q) = ⊕_λ M_{d_λ}(R) (partitions λ ⊢ n). This is the shape used throughout the mass/binding compute (tr_M = Σ_λ y_λ χ_λ); the y_λ(q) closed forms are the compute-side input (schur_principal_mpmath, WenzlSchurElement).

      Bean qou-xq3f (T2), a first brick of the general braid-word trace: its Markov cyclicity (M2), derived block-by-block from character_append_comm, independent of the particular y_λ. This does not yet fix the y_λ values (the deep compute-side input) nor the normalisation (M1) / Markov peel (M3); it establishes that whatever weights are supplied, the Wedderburn-weighted sum is a class function.
