    noncomputable def QOU.MathlibExt.cRogersL (z : ℂ) :
    ℂ

    The Rogers dilogarithm on ℂ, built on the integral continuation cLiTwoExt so that it is defined off [1,∞) rather than only on the disc.

    Neumann writes R(z) = ½·log z·log(1−z) − ∫₀^z log(1−t)/t dt; the integral is −Li₂(z), so this is the same function.

      The derivative of the Rogers dilogarithm.

      L′(z) = −½·( log(1−z)/z + log z/(1−z) )

      The Li₂ term contributes −log(1−z)/z and the ½·log·log term contributes ½·log(1−z)/z − ½·log z/(1−z); the two log(1−z)/z pieces combine to halve it. This is exactly the rogersDeriv that QOU.QBeta.FiveTwo.pentagon_deriv_x_eq_zero takes as given.

        The pentagon's log expansions, on the positive real region #

        Assembling the five-term identity needs the three expansions

        log a₃ = log(1−x) − log(1−xy),   log(1−a₃) = log x + log(1−y) − log(1−xy)
log(1−a₄) = log x + log y

        and their a₅ companions. These are branch conditions, not identities: they are exactly where flattening enters, and Route 45 measured the pentagon sum drifting once one of them fails.

        On the positive real square 0 < x, y < 1 every pentagon argument is a positive real, so all logarithms are real and the expansions hold outright. That is the base region from which analytic continuation carries the identity outward — the same shape as the Landen proof already in the corpus, which pins its constant on a real interval and continues.

        ⚠ This does not give the expansions anywhere else. Off the real square they can and do fail, which is the whole content of Routes 45–46.

        Rogers inversion #

        The Li₂ inversion Li₂(z) + Li₂(1/z) + ½log(−z)² = −π²/6 is already proved in ComplexDilogarithmInversion. Adding the two Rogers half-log·log terms, the log z · log(1−z) pieces cancel against each other through log(1−1/z) + log(−z) = log(1−z), and what is left is quadratic in log(−z) but not in log z alone.

        That is why an inversion pair evaluates to π² plus π times an angle rather than to a log² — the shape Route 58's link G3 needs.

        Pinning a branch integer by a window #

        Route 58's remaining links all have the same shape: an algebraic identity such as a₃³·y₁ = −y₃ gives 3·log a₃ + log y₁ = log(−y₃) + 2πik, and the work is showing k = 0. The window that does it need not be tight — the arguments involved live in (0, π) and (0, π/2), so the sum lands in (0, 5π/2), and the only value there congruent to π mod 2π is π itself.

        Archimedean/BranchIntegerPinning.lean pins such an integer along a continuous family; this is the single-point version, and it is what the saddle needs.
