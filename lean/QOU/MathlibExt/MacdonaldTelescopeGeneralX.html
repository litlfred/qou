    QOU.MathlibExt.MacdonaldTelescopeGeneralX — the general-X hook telescope (research) #

    The Macdonald hook telescope

    Σ_{λ ⊢ n} f_λ · schurElement Q X λ = ((1 − X)/(1 − Q))^n

    is proved in the corpus only at the principal specialisation X = Q^r (QOU.SchurWeyl.sum_dim_wenzlWeight_eq_one, transported to the List carrier by WenzlJonesMarkovNormalisation.sum_dim_jonesMarkovCoeff_eq_one). The identity is in fact true for all X; this file develops that generalisation.

    The route (polynomial identity in X) #

    schurElement Q X λ = Q^{n(λ)} · ∏_x (1 − X·Q^{c(x)}) / (1 − Q^{h(x)}) has X only in the numerator, so it is a polynomial in X of degree |λ| = n (over the field ℝ, with Q fixed and generic). Hence:

    • LHS Σ_{λ⊢n} f_λ · schurElement Q X λ is a polynomial in X of degree ≤ n;
    • RHS ((1 − X)/(1 − Q))^n = (1 − Q)^{-n} · (1 − X)^n is a polynomial in X of degree n.

    Both polynomials agree at X = Q^r for every r ≥ n (the proved specialisation, summed over the f_λ-weighted shapes of size n). For the substrate regime Q > 1 the set {Q^r : r ∈ ℕ} is infinite, so Polynomial.eq_of_infinite_eval_eq forces the two polynomials equal — hence the telescope holds for all X.

    Plan / status #

    This is a research tranche, developed brick by brick:

    1. powers_infinite — {x : ℝ | ∃ n, Q^n = x} is infinite for Q > 1 (this file; the infinite agreement set). ✓
    2. schurElementPoly Q λ : ℝ[X] — lift schurElement to a formal polynomial in X with eval X (schurElementPoly Q λ) = schurElement Q X λ. [open]
    3. agreement at X = Q^r — from the merged carrier bridge + sum_dim_wenzlWeight_eq_one (summed, un-normalised: Σ f_λ s_λ(Q,Q^r) = Z_n). [open]
    4. assembly — eq_of_infinite_eval_eq on 2+3 over the infinite set of 1, then eval at an arbitrary X. [open]

    Bricks 2–4 are the substantial part (formal-polynomial reformulation of the nested product, degree bookkeeping); only brick 1 lands here so far.

            ∑ ν : { ν : YoungDiagram // ν.cells.card = n }, ↑(Mathlib.numStandardYoungTableaux ↑ν) * WenzlSchurElement.schurElement Q X0 (↑ν).rowLens = ((1 - X0) / (1 - Q)) ^ n

            Brick 4 / the general-X hook telescope. For the substrate regime Q > 1, the Macdonald hook telescope holds for all X:

            Σ_{|ν|=n} f^ν · schurElement Q X ν.rowLens = ((1 − X)/(1 − Q))^n.

            Both sides are eval X of polynomials in X (bricks 2, and the RHSPoly); they agree at every X = Q^r, r ≥ 1 (brick 3), and {Q^{r+1} : r} is infinite (brick 1's argument), so Polynomial.eq_of_infinite_eval_eq forces the two polynomials equal — hence they agree at the arbitrary X.
