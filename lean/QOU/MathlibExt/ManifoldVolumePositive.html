    theorem QOU.MathlibExt.ManifoldVolumePositive.triangulation_volume_pos {n : ℕ} (hn : 0 < n) (T : IdealTriangulation n) :
    0 < T.volume

    A nonempty ideal triangulation has strictly positive volume.

    Each tetrahedron contributes strictly positively (BlochWignerPositive.volume_pos), and 0 < n makes the index set nonempty — without which the sum is empty and the volume is 0.

    0 < HyperbolicVolumeBridge.vol m

    A manifold realised by a nonempty ideal triangulation has strictly positive volume.

    The general form of Encounter.FigureEightVolumeBridge.vol_pos_of_realises and Encounter.FiveTwoVolumeBridge.vol_pos_of_realises, which reached the same conclusion at their own two shapes through a Clausen special value and through a volume comparison respectively. Neither route generalised; this one does not need either.
