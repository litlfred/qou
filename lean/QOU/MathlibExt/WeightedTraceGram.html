    QOU.MathlibExt.WeightedTraceGram — the Gram determinant of a character-weighted trace #

    Bean qou-kwoa, the q-part: the determinant side of Geck–Pfeiffer 7.2.6.

    Ref: [geckpfeiffer2000] Geck–Pfeiffer, *Characters of Finite Coxeter Groups and
Iwahori–Hecke Algebras*, Thm 7.2.6.

    The citation stays, and its role changes. In QOU.MathlibExt.WenzlSchurElement the Geck–Pfeiffer criterion is carried as SchurElementCriterion, a hypothesis class with no instance — the theorem is assumed. What is proved below is the determinant half of that theorem, so for the split semisimple case the citation becomes an attribution rather than a load-bearing assumption. Geck and Pfeiffer proved it first; a Lean proof does not change that, and every declaration here says so.

    The observation this file is built on #

    On a split semisimple algebra A ≅ ∏_λ M_{d_λ}(K) every trace is a combination of the block characters, t = Σ_λ c_λ · χ_λ. Two such traces matter here and they differ only in the weight:

    trace c_λ Gram determinant
    regular, x ↦ tr(L_x) d_λ ∏_λ ± d_λ^(d_λ²)
    canonical symmetrizing τ, τ(T_w) = δ_{w,1} 1/s_λ ∏_λ ± s_λ^(−d_λ²)

    s_λ is the Schur element of the block, and the second row is Geck–Pfeiffer's identity. Proving the weighted statement therefore subsumes QOU.MathlibExt.regTraceGram_pi_matrix_det (the regular case, c_λ = d_λ) and supplies the determinant side of the symmetrizing case at the same time.

    What is proved #

    • weightedGram_det — the determinant, for any weights.
    • weightedGram_det_ne_zero_iff — it is nonzero iff every weight is nonzero. With c_λ = 1/s_λ this reads "the Gram of τ is nondegenerate iff every Schur element is nonzero", which is exactly the equivalence SchurElementCriterion currently assumes.
    • weightedGram_regular — the regular trace is the c_λ = d_λ case, so the merged result is recovered rather than duplicated.

    What is NOT proved, and what still stands between here and the criterion #

    Two algebra-specific facts, neither of which this file touches:

    1. That H_n(q) carries the canonical symmetrizing trace τ at all, with τ(T_w) = δ_{w,1}. Mathlib has no symmetric-algebra theory — there is no occurrence of the word symmetrizing anywhere in it — and the corpus has none either.
    2. That τ's weights are 1/s_λ for the Wenzl Schur element formalised in QOU.MathlibExt.WenzlSchurElement.schurElement. That identification is the content of the Schur element and is where the q-dependence enters.

    Until both land, SchurElementCriterion stays a cited class and must not be given an instance. In particular the shortcut of discharging it from heckeWedderburn — legal, since semisimplicity is separately available — is refused: the implication would hold with the Schur elements doing no work at all, which would misrepresent a Wedderburn result as a Schur-theoretic one.
