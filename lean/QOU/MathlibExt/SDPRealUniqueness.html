    QOU.MathlibExt.SDPRealUniqueness #

    ℝ-specialized strict-complementarity uniqueness for SDP, with the dual feasibility and strong-duality-identity content upgraded from True placeholders to actual mathematical claims.

    What this module provides #

    • RealStrongDualityPair — extends StrongDualityPair sdp (for sdp : SDPPrimal n ℝ ι) with concrete:

      • dualSlack_psd : (sdp.dualSlack ystar).PosSemidef
      • obj_eq_dualObj : sdp.objAt Φstar = sdp.dualObjAt ystar

    • RealStrictComplementarityPair — extends RealStrongDualityPair with the active/inactive partition + dual-positivity (mirrors StrictComplementarityPair but at ℝ).

    • real_strict_complementarity_unique — the closed uniqueness theorem at ℝ: given a RealStrictComplementarityPair, the primal optimum is unique among feasible matrices with matching objective value. Proof uses dualSlack_trace_eq + complementary_slackness + a kernel-uniqueness step.

    Categorical content #

    This module instantiates the abstract strict_complementarity_unique sorry from QOU.MathlibExt.SDP at R := ℝ with the upgraded dual-content. The kernel-uniqueness step uses Slater (strictly- feasible primal Φ ≻ 0 exists) + strict complementarity to pin the primal optimum.

    Open work #

    The kernel-uniqueness step (S6 in the Boyd-Vandenberghe §5.5 proof) requires showing that two PSD matrices Φ', Φstar both in ker(S) and satisfying the same affine constraints tr(A_i Φ) = b_i must coincide. This is typically proven via Slater + the specific structure of S (rank-deficient on the optimal face). Currently this last step remains a sorry; batches 1-10 closed everything else.

The class is the sharpest case: its single field was the false proposition, so the class was uninhabitable and any instance of it unsound. The axiom carried _h_S_diff, _h_diff_S and _h_constraint_diff on top of feasibility and objective-match, and that looks like a guard: it says Φ' - Φ⋆ lies in ker S.         §3.1 Interior-optimum closure (active set empty) #

        When the active set is empty (the optimum lies in the strict interior of the feasible region), the dual slack S(y*) = T - Σ y*_i A_i simplifies to T (since all y*_i = 0). If T is positive-DEFINITE, then S * Φ = 0 ⟹ Φ = 0 directly via invertibility. This closes the uniqueness theorem without needing the kernel-uniqueness machinery.

        This is exactly the situation for ³He per PR #608: all three Wedderburn-block min-eigs are positive (1.87, 0.53, 0.53), so the active set is empty and T is PosDef. The interior closure applies.

              §3.07 Multiplication-commutativity for PSD pairs at zero #

              Per Copilot review: the section originally claimed to provide the range-containment lemma range(Φ) ⊆ ker(S) from S * Φ = 0. In fact the proven Lean theorem only establishes the (weaker but related) commuted-multiplication identity Φ * S = 0. Range containment is an EQUIVALENT statement modulo the range/kernel encoding (A * v = 0 ⟺ v ∈ ker(A), and B * A = 0 ⟺ range(A) ⊆ ker(B)), but those equivalences require additional Lean infrastructure (Submodule.range, LinearMap.ker) not yet wired into our matrix types.

              The full range-containment lemma (sandwich-PSD route via square roots, sketched in the proof outline below) is genuine multi-week Mathlib work and remains open. The proven mul_zero_comm is the linear-algebraic stepping stone that actually compiles.

              PROOF SKETCH (closeable but bulky in Lean):

              1. M := S^{1/2} · Φ · S^{1/2} is PSD (sandwich preserves PSD).
              2. tr(M) = tr(S^{1/2} · S^{1/2} · Φ) = tr(S · Φ) = 0 (cyclic + S²=S).
              3. PSD with trace 0 ⟹ M = 0 (single-matrix Mathlib lemma).
              4. M = 0 ⟹ (S^{1/2} v)ᵀ Φ (S^{1/2} v) = 0 for all v.
              5. PSD Φ + zero quadratic form ⟹ Φ · (S^{1/2} v) = 0 for all v.
              6. ⟹ Φ · S^{1/2} = 0 ⟹ range(Φ) ⊆ ker(S^{1/2}) = ker(S).

              Once this lemma is closed, both Φ' and Φstar have their ranges in ker(S). The difference D := Φ' − Φstar then satisfies range(D) ⊆ ker(S), and combined with tr(A_i · D) = 0 and strict complementarity, the SDP rank-deficiency theorem closes uniqueness. The remaining gap is the rank-deficiency theorem itself (Slater-required), which is the multi-week Mathlib delivery.
