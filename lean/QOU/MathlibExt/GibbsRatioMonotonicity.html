    Damped-sum ratios: an exact criterion bounding the A-growth of a Gibbs family #

    Analytic infrastructure for per-block-weight exclusions.

    A recurring shape in the Δ_λ binding programme is a ratio of two exponentially damped finite sums,

    Z a C τ = ∑ i, a i * exp (-(C i) * τ) , R τ = Z b D τ / Z a C τ ,

    with a i ≥ 0 per-partition amplitudes and C i content-Casimir "energies". The physical question — can any damping time τ reproduce an observed A-growth ratio? — is a question about the range of R on [0, ∞), so answering it excludes a whole one-parameter family rather than a single point.

    The main result is an exact, calculus-free criterion (ratio_le_initial_iff):

    R τ ≤ R 0 ↔ ∑ᵢ ∑ⱼ aᵢ bⱼ e^{-Dⱼτ} ≤ ∑ᵢ ∑ⱼ aᵢ bⱼ e^{-Cᵢτ} ,

    i.e. damping shrinks the growth ratio exactly when the cross-weighted denominator energies beat the numerator ones. ratio_le_initial_of_energies_le gives the clean sufficient condition ∀ i j, C i ≤ D j, and target_unreachable_of_gt_initial packages the exclusion: a target strictly above the undamped value R 0 is then unreachable for every τ ≥ 0.

    This is the general form of the GAP-6 (bean qou-bcig) numerical finding, where the undamped supremum 3.658 fell short of the 12.72 A-growth target, so no damping time — canonical or fitted — could work.

    Two sufficient conditions, and which one applies. The termwise test ∀ i j, C i ≤ D j (crossSum_le_of_energies_le) is false for the Δ_λ data (C_max(D) = 75.4 > C_min(⁴He) = 20.3 — the energy ranges overlap), and so is the Jensen relaxation min D ≥ E_r[C] (20.28 < 23.11). The usable hypothesis is a coupling (crossSum_le_of_coupling): a non-negative matrix with the prescribed marginals, supported on pairs with C i ≤ D j. Such a coupling exists exactly when the numerator's energy distribution first-order stochastically dominates the denominator's — a finite CDF check, which for the Δ_λ data holds (0 violations across all 43 thresholds).

    So the GAP-6 family exclusion is proved here modulo exhibiting that coupling: target_unreachable_of_coupling is the closed chain, and the remaining input is a finite combinatorial certificate rather than an analytic gap.

    Base ring: archimedean (Real.exp, ordering) ⇒ ℝ, the correct §7c placement.

      Sufficient condition via a coupling (the usable one). The termwise test ∀ i j, C i ≤ D j is far too strong — it fails whenever the two energy ranges overlap, as they do for the Δ_λ data. The right hypothesis is a coupling: a non-negative matrix M with the prescribed row/column marginals, supported only on pairs where C i ≤ D j.
