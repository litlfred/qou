    QOU.MathlibExt.WenzlJonesMarkovNormalisation — the unconditional M1 on the List carrier #

    The Markov-trace normalisation tr_M(𝟙) = 1 for the concrete List-carrier Jones–Markov weights jonesMarkovCoeff, general n, unconditional — derived from (not assumed alongside) the general Macdonald hook telescope already proved on the YoungDiagram carrier.

    The general telescope is QOU.SchurWeyl.sum_dim_wenzlWeight_eq_one:

    ∑_{ν : |ν| = n} f^ν · wenzlWeight r Q ν = 1,

    sorry-free for every level r and rank n. The carrier bridge (WenzlSchurElementBridge.schurElement_eq_schurPrincipal) plus YoungDiagram.ofRowLens_to_rowLens_eq_self gives, per diagram,

    jonesMarkovCoeff Q (Q^r) ν.rowLens = wenzlWeight r Q ν,

    so the two sums are termwise equal and the List-carrier weights inherit the normalisation. This discharges — for the principal specialisation X = Q^r — the conditional jonesMarkov_normalisation_of_telescope, on the natural index set (the SYT-weighted diagrams of size n) rather than an ad-hoc partition list.

    References #

    • [wenzl1988] Wenzl, "Hecke algebras of type $A_n$ and subfactors," Invent. Math. 92.
    • [macdonald1995] Macdonald, Symmetric Functions and Hall Polynomials, §I.3.

    ∑ ν : { ν : YoungDiagram // ν.cells.card = n }, ↑(Mathlib.numStandardYoungTableaux ↑ν) * WenzlSchurElement.jonesMarkovCoeff Q (Q ^ r) (↑ν).rowLens = 1

    The unconditional M1 on the List carrier. For the principal specialisation X = Q^r, the concrete Jones–Markov weights, summed over the SYT-weighted diagrams of size n, normalise to one:

    ∑_{ν : |ν| = n} f^ν · jonesMarkovCoeff Q (Q^r) ν.rowLens = 1.

    Termwise equal (via jonesMarkovCoeff_rowLens_eq_wenzlWeight) to the proved QOU.SchurWeyl.sum_dim_wenzlWeight_eq_one; the normalisation is derived, not assumed.
