    QOU.MathlibExt.TraceNilpotent — the trace form kills nilpotents #

    Reusable building blocks for the abstract symmetric-algebra semisimplicity theorem (track 3 of the Hecke-semisimplicity attack, epic qou-hnhg; this file is bricks qou-ubz8 (B3c) core lemmas).

    The keystone of Wenzl's criterion is: a finite-dimensional algebra whose regular trace form is nondegenerate is semisimple. Its mathematical heart is that the trace form annihilates the (nilpotent) Jacobson radical, which rests on two facts proved here, sorry-free, over any field.

    Base-ring note. Mathlib's Algebra.trace / Algebra.traceForm are commutative-only (CommRing S), so they do not apply to the noncommutative Hecke algebra. We therefore use the regular representation trace regTrace x = LinearMap.trace K A (lmul K A x) directly (the trace of left-multiplication as a K-endomorphism), which is defined for any finite-dimensional algebra, commutative or not. This is exactly the object Wenzl's / Geck–Pfeiffer's criterion uses.

    The remaining assembly — threading these through the two-sided Jacobson ideal (Ring.jacobson / TwoSidedIdeal) and isSemisimpleRing_iff_jacobson — is the next brick (qou-u181, B3d); the noncommutative ideal API is the identified hard joint.

For an x in a nil two-sided ideal, x * y is always nilpotent, giving the radical-annihilation step of the semisimplicity theorem (the two-sided-ideal plumbing is brick B3d, qou-u181).
