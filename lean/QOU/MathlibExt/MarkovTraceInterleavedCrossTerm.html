    The Markov trace is NOT bond-multiplicative at n = 4: the interleaved cross term #

    computations/probes/markov_multiplicativity_interleaved_probe.py (bean qou-ls86, 2026-08-18) proved by exact algebra that on H₃ the interleaved word s₀ s₁ s₀ has the same Markov trace as the sequential s₀² s₁ — the single interleaved word of H₃ is a cyclic rotation of a sequential one — and concluded the per-bond product formula is exact there. It then flagged the general-n question as open, naming s₀ s₁ s₀ s₂ s₁ as an n = 4 word with no such rotation.

    This file settles that instance: the product formula fails at n = 4. From the Ocneanu axioms alone — tr 1 = 1, the trace property, Markov stabilisation tr(x gₙ) = z·tr x for x ∈ Hₙ — plus the Hecke quadratic g² = h·g + 1 and the braid relation, both taken as hypotheses on the generators,

    tr(s₀ s₁ s₀ s₂ s₁) = z (z² + h z + h² z²)
tr(s₀² s₁² s₂)     = z (h z + 1)²                  (the per-bond product)
difference         = z (z² − h z − 1)               (`interleaved_sub_sequential`)

    The factor z² − h z − 1 is the corpus's convention-D Markov defect (bean qou-19jc; by qou-xzrj it equals −(q⁴+q²+1)/q² · y₍₂,₁₎, the two-row Wedderburn weight). At convention D, z = q³/(q²+1), h = q − q⁻¹, it is −(q⁴+q²+1)/(q²+1)² (markovDefect_convD), strictly negative for real q > 0 (crossTerm_neg_convD): the interleaved trace is smaller, so an interleaved word class carries extra log-suppression — extra binding.

    What this is and is not #

    • Positive existence, exact. A multi-bond cross term exists in the framework's own trace, for interleaved word classes, with an exact closed form. Independently confirmed in the 16-dim spin-½ representation (markov_trace_n4_interleaved_cross_term_probe.py, 11/11).
    • No production number moves. atom_braid_word_3A is sequential (one inter-nucleon letter, no generator recurring after its neighbour), so the production trace's bare-product implementation is exact for the production word class. This is a candidate source for the multi-bond term qou-ls86 closed at n = 3, not a correction.
    • Which word class a nucleus is remains the carrier blocker (qou-5vhf). Nothing is wired and nothing is fitted.

    Base ring (§7c) #

    The abstract identity is over a generic CommRing R acting on a generic Ring A — the MarkovTrace structure of QOU.MathlibExt.OcneanuTrace, whose T1–T3 are exactly the axioms used. The convention-D closed form is over a generic Field; only the sign statement is over ℝ (an ordering claim, archimedean by nature).

    THE CROSS TERM. The interleaved word and the per-bond product differ by exactly z (z² − h z − 1). The product formula is not exact at n = 4.

    theorem QOU.MathlibExt.InterleavedCrossTerm.markovDefect_convD {K : Type u_1} [Field K] (q : K) (h2 : q ^ 2 + 1 ≠ 0) :
    (q ^ 3 / (q ^ 2 + 1)) ^ 2 - (q - q⁻¹) * (q ^ 3 / (q ^ 2 + 1)) - 1 = -(q ^ 4 + q ^ 2 + 1) / (q ^ 2 + 1) ^ 2

    The convention-D Markov defect z² − h z − 1 at z = q³/(q²+1), h = q − q⁻¹, in closed form: −(q⁴+q²+1)/(q²+1)².

    theorem QOU.MathlibExt.InterleavedCrossTerm.crossTerm_neg_convD (q : ℝ) (hq : 0 < q) :
    q ^ 3 / (q ^ 2 + 1) * ((q ^ 3 / (q ^ 2 + 1)) ^ 2 - (q - q⁻¹) * (q ^ 3 / (q ^ 2 + 1)) - 1) < 0

    The cross term is strictly negative at convention D for every real q > 0: the interleaved trace is smaller than the per-bond product, so an interleaved word class carries extra log-suppression (extra binding).
