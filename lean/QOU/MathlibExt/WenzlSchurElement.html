    QOU.MathlibExt.WenzlSchurElement #

    — Wenzl Schur element and Jones-Markov closed form

    The Wenzl Schur element at partition λ ⊢ n is the combinatorial coefficient

    s_{λ, X}(Q) = Q^{n(λ)} · ∏_{x ∈ λ} (1 − X · Q^{c(x)}) / (1 − Q^{h(x)}),

    where n(λ) = Σ_x c(x) (the content sum), c(x) = j − i is the content of cell (i, j), and h(x) is the hook length.

    The Jones-Markov coefficient y_λ(q) is the canonical scaling

    y_λ(q) = s_{λ, X}(Q) / Z_n(Q, X)

    with Z_n(Q, X) = Σ_{λ ⊢ n} f_λ · s_{λ, X}(Q) the Wenzl-bridge normalisation. Per prop:macdonald-hook-telescope, Z_n = ((1 − X) / (1 − Q))^n, giving the closed form

    y_λ(q) = Q^{n(λ)} · (1 − Q)^n / (1 − X)^n
          · ∏_{x ∈ λ} (1 − X · Q^{c(x)}) / (1 − Q^{h(x)}).

    Refs:

    • [wenzl1988] Hecke algebras of type A_n and subfactors, Invent. Math. 92 (1988).
    • [macdonald1995] Symmetric Functions and Hall Polynomials, I.3.
    • [stanley1999] Enumerative Combinatorics II, Cor. 7.12.5.

          Wenzl-bridge normalisation Z_n #

          By definition Z_n(Q, X) = Σ_{λ ⊢ n} f_λ · s_{λ, X}(Q), where f_λ is the number of standard Young tableaux of shape λ.

          Per the Macdonald hook telescope (macdonald-hook-telescope.lean), this sum equals ((1 − X) / (1 − Q))^n.

          We abstract Z_n rather than constructing the full SYT sum here since the SYT count f_λ is itself a deep Mathlib gap.

              Schur-element non-vanishing at the substrate regime #

               (Wenzl-bridge stage 2, bean `qou-vndn`)

              Semisimplicity of $H_n(q)$ with Markov parameter $X$ is governed by the Schur elements of the symmetrizing trace: the algebra is semisimple iff every $s_{\lambda}$ is nonzero (Geck--Pfeiffer [geckpfeiffer2000] Thm 7.2.6). Here we prove — sorry-free, on the concrete schurElement above — that in the substrate regime $Q > 1$, $X \leq 0$ every Schur element is nonzero, carry the Geck--Pfeiffer criterion as a cited hypothesis class (SchurElementCriterion, no instance — the symmetrizing-trace theory is not in Mathlib), and compose: semisimplicity at every rank.

              Scope note (honest regime bound). Physical Markov specialisations use $X > 0$ (e.g. $X = Q^{-N}$), where the numerator factors $1 - X\,Q^{c(x)}$ genuinely vanish at cells of content $c = N$ — that vanishing locus is the Temperley--Lieb / level-rank quotient structure, not a defect. The $X \leq 0$ bound proves the generic-parameter statement; the $X = Q^{-N}$ stratification is proved below (schurElement_tl_eq_zero_iff) — it is no longer outstanding work.

                The Temperley–Lieb stratification at the physical parameter #

                 $X = Q^{-N}$ (companion to the $X \leq 0$ regime bound)

                At the physical Markov specialisation $X = Q^{-N}$ the content numerator $1 - Q^{-N} Q^{c(x)}$ vanishes exactly at cells of content $c(x) = N$. So the vanishing locus of the Schur element is precisely the set of partitions containing a content-$N$ cell — the Temperley--Lieb / level-rank quotient stratification, proved here as a sorry-free iff on the concrete schurElement. Vanishing Schur elements are the structure at physical $X$, not a defect: they cut out the quotient category.

                ⚠ Convention: this gives COLUMNS, and a corpus block says rows. With cellContent i j = j - i and rows/columns 0-indexed, a partition has a content-N cell (for N ≥ 0) exactly when N < λ₁, so the blocks that survive at X = Q^{-N} are those with at most N columns. The textbook GL(N) / HOMFLY statement is the transpose — quantum dimension ∏ [N + c(x)]/[h(x)] vanishes at c(x) = -N, i.e. at X = Q^{+N}, giving at most N rows. So this file uses the conjugate convention.

                That collides with mass-theory/hecke-radical-is-temperley-lieb.md, which states the survivors are the two-row shapes (n-k,k) and tabulates them for n = 2..7. The Catalan dimension counts there are unaffected (dim λ = dim λ'), so nothing numerical is wrong — but the two blocks label different sets of partitions as the TL quotient. Anyone wiring schurElement_tl_eq_zero_iff to that block must transpose. The N < 0 mirror gives the textbook row form directly.

                Both forms are proved in QOU.MathlibExt.TLContentStratification, which eliminates the existential in HasContentCell and replaces it with a one-line shape statistic: at X = Q^{-N}, N ≥ 0, a block survives iff λ₁ ≤ N (schurElement_tl_ne_zero_iff_numCols_le); the N < 0 mirror is ℓ(λ) ≤ -N (schurElement_tl_ne_zero_iff_length_le).

                  Product form — what (P) has to manipulate #

                  schurElement is defined by a nested foldl so that it computes. Nothing cell-by-cell can be said about a fold, so before the Pieri step can compare two shapes the same value has to be exhibited as a product over cells.

                  That is a proof obligation, not a rewriting convenience. Both folds multiply into their accumulator and start at 1, and a * n / d = a * (n / d) holds in a field regardless of whether d vanishes — but the interleaved division is exactly what makes it non-obvious, so it is proved rather than assumed.

                      How a row factor responds to a box #

                      The per-cell update rule lifts to the row products. Three cases, and they are not symmetric:

                      • below the new box — nothing moves at all, so the factor is literally equal;
                      • the row itself — one cell longer, and every old cell's hook is +1;
                      • above — one cell of the row (the one in column λ_r) has its hook raised.

                      The first two are proved here. The third needs product surgery at a single index, which is the next piece.
