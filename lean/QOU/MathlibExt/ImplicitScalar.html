    Scalar implicit function theorem — solving f x y = 0 for y #

    Bean qou-trns. The envelope step dS/dφ = 2φ needs the roots yⱼ(x) of the GGM curve to be differentiable in x, and that is the implicit function theorem for one equation in one unknown with one parameter.

    Why this is a Mathlib gap #

    Mathlib has an implicit function theorem — Mathlib/Analysis/Calculus/Implicit.lean — but it is the general Banach-space version built on ImplicitFunctionData, which presents the solution set through a complemented-subspace splitting (leftFun/rightFun, and implicitFunction : F → G → E taking a point of ker f'). That is the right shape for a submanifold and the wrong shape for "solve for y as a function of x". It is also, as of this writing, imported by nothing else in Mathlib.

    What is missing is the scalar case in the form everyone actually uses:

    f x₀ y₀ = 0,  ∂f/∂y ≠ 0   ⟹   ∃ g,  g x₀ = y₀,  f x (g x) = 0 near x₀,
                                    g' x₀ = −(∂f/∂x)/(∂f/∂y)

    exists_hasDerivAt_implicit below is that statement, over any complete nontrivially-normed field — so ℂ for this application, and ℝ for free.

    The construction #

    The standard one, done concretely rather than through ImplicitFunctionData: straighten the graph with Φ(x,y) = (x, f x y), whose derivative

    L (a,b) = (a, A·a + B·b),      A = ∂f/∂x,  B = ∂f/∂y

    is invertible exactly when B ≠ 0, with L⁻¹(a,b) = (a, (b − A·a)/B) written down explicitly (ContinuousLinearEquiv.equivOfInverse). Then Mathlib's inverse function theorem applies to Φ, and

    g x := (Φ.localInverse (x, 0)).2

    is the branch. eventually_right_inverse gives Φ(Ψ(x,0)) = (x,0), whose first component says Ψ(x,0) = (x, g x) and whose second says f x (g x) = 0. The derivative falls out of to_localInverse composed with a ↦ (a,0), and L⁻¹(1,0) = (1, −A/B) is where the IFT formula comes from.

    ⚠ Where this does NOT apply on the transport arc, and why that is expected #

    ∂curve/∂y ≠ 0 is exactly "y is a simple root", i.e. the discriminant does not vanish. On the 5₂ transport arc the discriminant does vanish, at θ = 137.9206708879635° — that is exists_unit_circle_disc_zero, proved in QOU/QBeta/FiveTwoDiscriminant.lean. Two of the three branches collide there and no differentiable labelling of individual roots survives it.

    So this theorem gives the branches on [0,π] ∖ {φ₀} and cannot give them at φ₀. That is not a defect: it is why QOU/Archimedean/ConstantOffOnePoint.lean exists — constant_of_hasDerivWithinAt_zero_off_point glues a derivative identity that holds off one point into a statement on the whole interval, using continuity there. The two bricks are built for each other.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms. This is one hypothesis of the envelope step, not the envelope step, and certainly not the sum rule.

          The theorem #

          source
          theorem QOU.MathlibExt.exists_hasDerivAt_implicit {𝕜 : Type u_1} [NontriviallyNormedField 𝕜] [CompleteSpace 𝕜] {f : 𝕜 × 𝕜 → 𝕜} {f' : 𝕜 × 𝕜 →L[𝕜] 𝕜} {x₀ y₀ : 𝕜} (hf : HasStrictFDerivAt f f' (x₀, y₀)) (h0 : f (x₀, y₀) = 0) (hB : f' (0, 1) ≠ 0) :
          ∃ (g : 𝕜 → 𝕜), g x₀ = y₀ ∧ (∀ᶠ (x : 𝕜) in nhds x₀, f (x, g x) = 0) ∧ HasDerivAt g (-f' (1, 0) / f' (0, 1)) x₀

          Scalar implicit function theorem.

          If f : 𝕜 × 𝕜 → 𝕜 is strictly differentiable at (x₀, y₀), vanishes there, and its y-partial B := f' (0,1) is nonzero, then there is a function g with g x₀ = y₀, solving f (x, g x) = 0 near x₀, and

          g' x₀ = −A / B,     A := f' (1,0).

          Proved by straightening the graph with (x,y) ↦ (x, f (x,y)) and applying Mathlib's inverse function theorem, rather than through ImplicitFunctionData.

          Non-vacuity: the hypotheses are satisfiable and the formula is right #

          source
          theorem QOU.MathlibExt.exists_sqrt_branch :
          ∃ (g : ℂ → ℂ), g 1 = 1 ∧ (∀ᶠ (x : ℂ) in nhds 1, g x ^ 2 - x = 0) ∧ HasDerivAt g (1 / 2) 1

          Usability check. An existence theorem whose hypotheses nothing satisfies is worthless, so here it is instantiated end to end on f (x,y) = y² − x at (1,1): ∂f/∂y = 2 ≠ 0, ∂f/∂x = −1, and the theorem returns a branch of √x through 1 with g′(1) = −(−1)/2 = 1/2 — the derivative of √x at 1, as it must be.
