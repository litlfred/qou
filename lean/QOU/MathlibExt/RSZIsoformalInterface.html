    def QOU.MathlibExt.RSZ.rszLevel (μ₁ μ₂ : ℤ) :
    ℤ

    RSZ's level, p.38: d := μ₂ − μ₁, the difference between two consecutive slopes of the filtration.

    The arity is the point. This is a binary operation on slopes; there is no "level of a slope". A single slope cannot be supplied, so the misreading "slope ½ ⇒ level 2" is not expressible here.

          source
          theorem QOU.MathlibExt.RSZ.c1_infinity_isoformalDim_eq_zero :
          (rszIsoformalDim 1 (fun (x : Fin 1) => 2) fun (x : Fin 1) => 1) = 0

          C1's ∞ has NO Stokes data — the instance, not just the general lemma.

          L1's Newton polygon at ∞ has a single edge (r,d) = (2,1): slope ½ with multiplicity 2, pure isoclinic. After the ramified pullback ζ² = x — which QOU.QBeta.ramified_qBorel_budget showed is the only pairing with sub-quadratic leftover — the data is k = 1, rank 2, slope 1. The isoformal space is a point.

          So there is no local isoformal q-Stokes multiplier at C1's ∞ to compute. Independently: RSZ's Stokes matrices are unipotent automorphisms inducing the identity on gr M₀ (§4.4, Thm 5.5.7), and with one slope there is no strictly-upper-triangular part — the Stokes group is trivial.

          Do not read this as "C1 has no Stokes multipliers". Two different objects share the name, and only the first is zero-dimensional:

          • local isoformal moduli at ∞ — F(P₁,…,P_k) at a single point. This lemma. Dimension 0.
          • the connection-matrix Stokes multipliers — the data in P = Y₀⁻¹Y_∞ between the theta-normalised solutions at 0 and at ∞, functions of the invariant χ = P₀₀P₁₁/(P₀₁P₁₀). Global, live, and open (bean qou-wgnx; the connection matrix and χ are already built). A dimension count at one point says nothing about it.

          This instance exists because the general lemma above was not enough. rszIsoformalDim_one's docstring already said "no Stokes data to extract", and I still wrote "the Stokes multiplier is the remaining open item" three times across PRs #4771 and #4783. A lemma naming C1 is harder to walk past than a lemma about an abstract k = 1. Retraction: 2026-08-08-c1-infinity-has-no-stokes-multiplier.md.
