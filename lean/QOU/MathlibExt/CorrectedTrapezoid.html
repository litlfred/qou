    |(b - a) / 2 * (f a + f b) - (b - a) ^ 2 / 12 * (f' b - f' a) - ∫ (x : ℝ) in a..b, f x| ≤ (b - a) ^ 5 * M / 720

    The corrected trapezoid error bound. h⁵·M/720 for |f⁗| ≤ M.

    Two orders better per cell than the plain trapezoid rule — O(h⁴) rather than O(h²) once summed over 1/h cells.

    Reducing the remainder from g⁗ to g″ #

    The kernel w = (x−a)²(b−x)² has DOUBLE roots at both ends, so w(a) = w(b) = w′(a) = w′(b) = 0 and two integrations by parts leave no boundary terms at all:

    ∫_a^b w·g⁗ = ∫_a^b w″·g″,        w″ = 12(x−a)² − 12(b−a)(x−a) + 2(b−a)²

    (again one FTC application, against F := w·g‴ − w′·g″). Moreover w″ has ZERO MEAN, ∫_a^b w″ = 0, because w′ vanishes at both ends.

    WHY THIS MATTERS FOR qou-mlgp (A). The g⁗ form needs sup|logSinc⁗|, whose finiteness rests on an eighth-order cancellation (6/x⁴ − (4cos²+2)/sin⁴, two terms that individually blow up — at N = 100 the crude bound overshoots by 5·10⁷). The g″ form needs only logSinc″, which is already bounded here (QOU/Knot/LogSincNearZero.lean: |logSinc″| ≤ 1 on (0,1]).

    The zero mean is what makes it sharp enough. Writing the remainder as ∫ w″·(g″ − c) for any constant c and taking c = g″(a),

    |remainder| ≤ (∫|w″|)·osc_cell(g″) ≤ 2h³·osc_cell(g″),

    and if g″ is MONOTONE the per-cell oscillations telescope over the k cells to |g″(b) − g″(a)| ≤ 2·sup|g″| instead of accumulating as k·h·sup|g‴|. That turns the composite error on the sum into O(h²·sup|g″|) = O(1/N²) — below the O(1/N) term (A) is after.

    So the remaining analytic requirement drops from "bound logSinc⁗" (an eighth-order cancellation) to "logSinc″ is monotone", i.e. the SIGN condition logSinc‴ < 0, i.e. x³·cos x < sin³x on (0, π). That is a single clean inequality — an Adamović–Mitrinović-type statement — rather than a cancellation estimate. It is not proved here, and Mathlib's sin_gt_sub_cube (x − x³/4) is too weak for it; the sharper sin x > x − x³/6 would suffice.

    The g″-form error bound, driven by OSCILLATION rather than a sup #

    Combining the three previous results — the exact order-2 identity, the reduction ∫ w·g⁗ = ∫ w″·g″, and ∫ w″ = 0 — the per-cell error is controlled by the OSCILLATION of g″ on the cell, not by sup|g⁗|. That is what lets the cells telescope when g″ is monotone.

    theorem QOU.MathlibExt.integral_eq_corrected_trapezoid_sub_deriv2 {g g₁ g₂ : ℝ → ℝ} {a b : ℝ} (hg : ∀ x ∈ Set.uIcc a b, HasDerivAt g (g₁ x) x) (hg1 : ∀ x ∈ Set.uIcc a b, HasDerivAt g₁ (g₂ x) x) (hc2 : ContinuousOn g₂ (Set.uIcc a b)) :
    ∫ (x : ℝ) in a..b, g x = (b - a) / 2 * (g a + g b) - (b - a) ^ 2 / 12 * (g₁ b - g₁ a) + 1 / 24 * ∫ (x : ℝ) in a..b, (12 * (x - a) ^ 2 - 12 * (b - a) * (x - a) + 2 * (b - a) ^ 2) * g₂ x

    The order-2 identity from the order-1 one — only C² needed.

    ∫_a^b g = (h/2)(g a + g b) − (h²/12)(g₁ b − g₁ a)
            + (1/24)·∫_a^b w″·g₂,      h = b−a

    with NO g‴ or g⁗ hypotheses anywhere. The order-2 rule was originally derived from the quartic kernel, which forced four derivatives; but the kernel identity

    w″ = 12(x−a)² − 12(b−a)(x−a) + 2(b−a)² = −12·(x−a)(b−x) + 2(b−a)²

    expresses w″ in terms of the ORDER-1 kernel (x−a)(b−x), so

    (1/24)∫ w″ g₂ = −½∫ (x−a)(b−x) g₂ + ((b−a)²/12)·∫ g₂
              = −½∫ (x−a)(b−x) g₂ + ((b−a)²/12)(g₁ b − g₁ a)

    by the FTC on g₂. Substituting into integral_eq_trapezoid_sub the B₂ terms cancel exactly and the order-1 identity is recovered. So the order-2 rule is a REWRITING of the order-1 rule, not a deeper theorem — and it inherits the order-1 rule's C² hypotheses.
