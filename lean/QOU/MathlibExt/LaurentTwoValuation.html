    QOU.MathlibExt.LaurentTwoValuation — the [2]_q-adic valuation on ℤ[q^{±1}] #

    The corpus's [2]_q-adic valuation (QCollatz.qTwoValuation) is defined only on Polynomial ℤ (multiplicity of the root q = -1). This file fills the Mathlib-gap noted there (bean qou-4atn): the same valuation on the Laurent ring LaurentPolynomial ℤ = ℤ[q^{±1}], the Skein module where the q-Collatz fundamental cycle {q⁻¹, 1+q⁻¹} lives.

    The valuation is the (q+1) = [2]_q-adic multiplicity (emultiplicity). The key inputs, all sorry-free:

    • [2]_q = q+1 is not a unit (it vanishes at q = -1, via the eval₂ ring hom at the unit -1);
    • so the fundamental-cycle values are v_[2](q⁻¹) = 0 (a unit) and v_[2](1+q⁻¹) = 1 (1+q⁻¹ = q⁻¹·(q+1)).

    These are exactly the values the q-Collatz even-branch descent needs on the attractor cycle: C(1+q⁻¹) = q⁻¹ drops v_[2] from 1 to 0.

    Base ring is the fibre-level ℤ[q^{±1}] (§7c: no archimedean structure).
