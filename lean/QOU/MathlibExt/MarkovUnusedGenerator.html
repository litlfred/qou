    The bond rule at an unused generator, derived #

    QOU.MathlibExt.MarkovBondRule.BondRule carried, as an unproved hypothesis, the one trace-level input of the bond-product formula. MarkovBondLinear removed the parameter d from it, leaving exactly one open equation:

    tr (W * σ_g) = z * tr W for a monotone word W not using generator g.

    This file proves that equation from the Markov-trace axioms. Nothing here is assumed about q, about the Hecke relation, or about which convention fixes z: the argument uses only that tr is a linear trace on a tower of subalgebras, that generators far apart commute, and the Markov property at the top of the tower.

    Why it is not simply the Markov property #

    The Markov property is a statement about the last generator: tr (a * σ_n) = z * tr a for a ∈ H_n. The bond generators of an atom word are interior — there are strands above them — so the rule has the form of the Markov property without being an instance of it. What licenses it is that g is unused: the word splits across the gap into two commuting sub-towers.

    The proof #

    Induction on the word, peeling the top letter σ_m (available because the word is monotone: each generator occurs once, in increasing order). Three cases:

    • m < g — every letter is below g, so the whole word lies in H_g and the Markov property applies directly. No induction needed.
    • g + 2 ≤ m — σ_m and σ_g commute, so σ_g slides down past the top letter; Markov at m peels σ_m, and the induction hypothesis finishes.
    • m = g + 1 — the one case where neither move is available. Cyclicity of the trace rotates σ_g to the front, σ_g * W lands in H_{g+1}, Markov at g + 1 peels σ_{g+1}, cyclicity rotates back, and Markov at g finishes.

    The m = g + 1 case is the reason this needs the trace property and not merely linearity.

    Scope #

    MarkovTower axiomatises the Jones/Ocneanu trace on the H_n(q) tower; it does not construct it, and no claim is made here that the Hecke tower satisfies these axioms — that is the standard result cited below. What is new here is that the unused-generator rule is a consequence of those axioms rather than an extra assumption, which is what qou-g8i1 needed.

    z is an abstract ring element throughout. In particular this file is convention-neutral: it is neither a convention-C nor a convention-D statement, and instantiating z := q³/(q²+1) (convention D, per QOU.MathlibExt.MarkovNormalisation) specialises it without reproving anything.

    Base ring #

    Generic [CommRing R] and a generic R-algebra A. No ℝ, no ordering, no archimedean content.

    structure QOU.MathlibExt.MarkovUnusedGenerator.MarkovTower (R : Type u_3) [CommRing R] (A : Type u_4) [Ring A] [Algebra R A] :
    Type (max u_3 u_4)

    A Markov-trace tower: the axioms of the Jones/Ocneanu trace on H_1 ⊆ H_2 ⊆ ⋯, with an abstract Markov parameter z.

    Deliberately minimal — every field below is used by the theorem, and no field encodes the conclusion. In particular there is no hypothesis about interior generators; that is what gets derived.

    • H : ℕ → Subalgebra R A

      The tower of subalgebras. H n is generated by σ 0, …, σ (n-1).

    • H_mono : Monotone self.H

      The tower is increasing.

    • σ : ℕ → A

      The generators.

    • σ_mem (n : ℕ) : self.σ n ∈ self.H (n + 1)

      σ n is the new generator at level n + 1.

    • far_comm (i j : ℕ) : i + 2 ≤ j → self.σ i * self.σ j = self.σ j * self.σ i

      Generators at distance ≥ 2 commute (the far-commutation braid relation).

    • tr : A →ₗ[R] R

      The trace, as a linear functional.

    • tr_comm (a b : A) : self.tr (a * b) = self.tr (b * a)

      The trace property tr (a * b) = tr (b * a).

    • z : R

      The Markov parameter.

    • markov (n : ℕ) (a : A) : a ∈ self.H n → self.tr (a * self.σ n) = self.z * self.tr a

      The Markov property, at the top of the tower only.

        The bond rule at an unused generator.

        For a monotone word l (strictly increasing letters) that does not use g,

        tr (wordProd l * σ g) = z * tr (wordProd l).

        This is the single equation qou-g8i1 left open, and it is derived here from the Markov axioms — no extra hypothesis.

        def QOU.MathlibExt.MarkovUnusedGenerator.trivialMarkovTower {R : Type u_1} [CommRing R] :
        MarkovTower R R

        The axioms are consistent and admit a non-degenerate model: A = R, every H n = ⊤, every σ n = 1, tr = id, z = 1.

        Present so MarkovTower is demonstrably not an empty abstraction. It is a witness of inhabitation only — this model is commutative and says nothing about the Hecke tower. Unlike a zero-functional witness it is at least faithful (tr 1 = 1 ≠ 0 in a nontrivial R), so the axioms do not force degeneracy.

          Discharging BondRule #

          QOU.MathlibExt.MarkovBondRule.BondRule was introduced as an open primary: a content-bearing class carrying the bond rule as a hypothesis, with no instance provided. The theorem above supplies one.

          Reading Unused g x as "x is a monotone word that omits generator g" — the condition the numerics were measured under — every field of BondRule is now constructed, and its tr_mul_sigmaPlus is derived. What remains an assumption is only that the Hecke tower carries a Markov trace, which is the cited standard result rather than anything specific to this framework.

          Consequently MarkovBondRule.bond_pp_nn, stated there conditionally on BondRule, holds outright for any Markov tower whose parameter is markovZ q.
