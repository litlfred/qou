    Faddeev non-compact quantum dilogarithm Φ_b (modular double) — T3 scaffold #

    The decay / bar-odd face of the quantum dilogarithm, complementary to the compact Φ_q (mass / bar-even) backbone formalized in QOU.MathlibExt.QuantumDilogarithm{,Infinite} (T1). This is the object the open Q_β c₃ bar-odd S-leak lives in (S ≈ +0.00968 muon / −0.03946 proton; docs/audits/2026-07-11-qbeta-c3-barodd-sleak-phib-target.md).

    Φ_b is defined analytically by the contour integral $$\Phi_b(z) = \exp\!\int_{\mathbb{R}+i0} \frac{e^{-2izw}}{4\sinh(wb)\,\sinh(w/b)}\,\frac{dw}{w},$$ which needs contour integration not available in Mathlib. Per AGENTS.md §3b we therefore axiomatize Φ_b as a conjecture-class carrying its real defining functional equations (the existence of a function satisfying them is the open input) and derive consequences from those axioms — nothing here constructs Φ_b, and no numerical c_k value is produced or wired.

    class QOU.MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi (b : ℂ) (Φ : ℂ → ℂ) :
    Prop

    Faddeev Φ_b (conjecture-class, §3b). Φ : ℂ → ℂ satisfies the two modular-double q-difference equations of the non-compact quantum dilogarithm at modular parameter b > 0: $$\Phi_b(z - \tfrac{ib}{2}) = \bigl(1 + e^{2\pi b z}\bigr)\,\Phi_b(z + \tfrac{ib}{2}), \qquad \Phi_b(z - \tfrac{i}{2b}) = \bigl(1 + e^{2\pi z/b}\bigr)\,\Phi_b(z + \tfrac{i}{2b}).$$ The two relations are exchanged by b ↔ 1/b (with Re (1/b) > 0 following from Re b > 0), encoding the self-duality Φ_b = Φ_{1/b} — the structural feature the compact Φ_q (single relation) lacks.

    Total-function encoding caveat (why shift_binv carries a guard). The true Φ_b is meromorphic with poles on the 1/b-side (dual) lattice. At a dual-lattice point (e^{2πz/b} = −1) an unguarded relation would force Φ(z − i/(2b)) = 0 · Φ(z + i/(2b)) = 0 for ANY total Φ, while the intended object's value there is finite and non-zero — the meromorphic identity holds as 0 · ∞ (measured at the proton-anchor substrate b via the validated evaluator computations/qbeta/phi_b_evaluator.py: |Φ_b(z − i/(2b))| ≈ 1.11e−6 ≠ 0 while the k = 0 dual product factor at z + i/(2b) vanishes to 3e−34). An unguarded ∀ z axiom is therefore unsatisfiable by any total-function encoding of Φ_b; the guard excludes exactly the dual pole lattice. shift_b needs no guard: its prefactor-zero points are genuine zeros of Φ_b (numerator/compact half), where 0 = 0 · Φ(·) holds.

    The sorry-free consequences below hold for any Φ in this class; the open conjecture is that the integral Φ_b is such a Φ (on the Im b² > 0 substrate branch this is discharged by the modular-double product — see QOU.MathlibExt.PhiBProd; the |q| = 1 fibre regime, real b, remains open).

    • hb : 0 < b.re

      Re b > 0 (covers real b > 0 — the |q| = 1 fibre regime — and the product-supported substrate branch arg b = π/4).

    • shift_b (z : ℂ) : Φ (z - Complex.I * (b / 2)) = (1 + Complex.exp (2 * ↑Real.pi * b * z)) * Φ (z + Complex.I * (b / 2))

      b-shift relation (the "compact half", same shape as Φ_q's q-difference equation). Unguarded: its prefactor zeros are genuine zeros.

    • shift_binv (z : ℂ) : 1 + Complex.exp (2 * ↑Real.pi * z / b) ≠ 0 → Φ (z - Complex.I / (2 * b)) = (1 + Complex.exp (2 * ↑Real.pi * z / b)) * Φ (z + Complex.I / (2 * b))

      1/b-shift relation (the modular-dual half, absent from compact Φ_q), guarded away from the dual pole lattice (see class docstring).

      The bar-odd source: chiral knot operators (Hopf-led) — argument-identification target #

      The bar involution q ↦ q⁻¹ is the mirror/chirality operation (J_K(q⁻¹) = J_{mirror K}(q)), so an operator's bar-ODD part is non-zero iff it is chiral (parity ↔ chirality dictionary, docs/audits/2026-07-07-parity-chirality-dictionary-closed.md):

      • amphichiral operators (mirror-invariant, CS = 0) — e.g. the figure-8 4₁ — have zero bar-odd part; they are the compact Φ_q mass/bar-even face (T1, the −Vol(4₁) datum).
      • chiral operators — led by the Hopf link (2-crossing), and the torus knots T(2,3) = 3₁ (electron), T_{3,5} (writhe mediator) — carry the bar-ODD part; they are the Φ_b decay/bar-odd face formalized here (T3).

      The Hopf sector is the concrete carrier: the bar-odd datum collapses (in y = q² + q⁻²) to C_Hopf(y) = y³ − 6y² + 10y − 6, discriminant −76 < 0 (complex-conjugate root pair), with C_Hopf(2) = −2 = J_Hopf(q=1) = the empirical c₃ near-match (QOU.QBeta.HopfCubicOddCarrier, content/.../mass-theory/qbeta-odd-carrier-hopf-cubic.md).

      Caveat (Subgoal-2 boundary). The Hopf fibre cubic is anchor-invariant (cross-anchor swing ~10⁻⁸), so the chiral operators supply the bar-odd carrier but not the anchor-dependent c₃ S-leak (S(muon) ≈ +0.00968, S(proton) ≈ −0.03946; docs/audits/2026-07-11-qbeta-c3-barodd-sleak-phib-target.md). The remaining keystone is to identify the FaddeevPhi argument whose archimedean evaluation at each anchor reproduces S — i.e. to realize the chiral Hopf sector's anchor-dependent leak through the Φ_b axioms above. That argument-identification is not done here.

      Reconciliation with the landed algebraic/Gram results (2026-07-11) #

      A parallel line pins the same bar-odd carrier at the H₃(q) algebra level and sharpens "chiral operators" to a single algebraic mode (docs/audits/2026-07-11-qbeta-c3-barodd-nz-deformation-gap.md):

      • The σ-parity (mass/decay) split of e_k is proved sorry-free in QOU.QBeta.EkParitySplit (massProj / decayProj); S is the decayProj (bar-odd) half.
      • The Frobenius/Gram form G_{ij} = tr_M(b_i b_j) is indefinite (signature 5+, 1−); the bar-odd decayProj lands exactly on the unique negative-norm ghost mode (L₊ − L₋)/√2 (|cos| = 1), while the mass (bar-even) part sits in the positive/unitary cone. So decay ⊥ mass ⇒ decay = binding (Gram-norm sign is the mass/binding split): this Φ_b/bar-odd face is the binding channel, an LP/SDP dual shadow-price mode, not a mass contribution.

      So this analytic Φ_b axiomatization and the H₃ Gram-ghost picture are two faces of one object: Φ_b is the modular-double analytic carrier (with a numerical evaluator validated vs Hikami), and (L₊ − L₋) is its H₃-algebraic shadow. The open link remains the same z(q₀) → c_k evaluation map that would make either face reproduce the anchor-dependent S.
