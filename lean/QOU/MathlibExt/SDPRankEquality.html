    QOU.MathlibExt.SDPRankEquality #

    The Goldman-Tucker / Alizadeh-Haeberly-Overton 1997 rank-equality theorem for SDP under strict complementarity.

    ⚠ Archimedean wall #

    Per the QOU manuscript's archimedean-wall principle (categorical / pre-archimedean content vs archimedean / realified content), this entire module lives on the ARCHIMEDEAN side. Every statement and proof here uses real-valued (ℝ) PSD matrices, real spectral analysis, real inner products, and real invertibility — all post-realification machinery.

    The pre-archimedean content (categorical Hecke algebra, formal q-deformation in ℤ[q, q⁻¹], Markov-trace-as-symbolic-rational- function) lives in QOU.HeckeAlgebra.* and is not entangled with the SDP analysis here. The realification map Hecke_n(formal q) → HeckeElement n(q_0 ∈ ℝ) happens BEFORE the SDP machinery is invoked.

    Conclusions drawn here (e.g. helium3_uniqueness_closed) are archimedean statements about the realified SDP at q_0, not categorical statements about the pre-archimedean Hecke algebra. Pulling back to a categorical claim requires additional infrastructure (e.g. realification-map injectivity on the relevant Hecke sub-algebra) that this module does not attempt to bridge.

    This wall-respect is intentional: SDP uniqueness is naturally an archimedean statement (the PSD cone, eigenvalue analysis, Slater's interior-point hypothesis are all real-analytic notions); forcing it into the pre-archimedean side would require formal-power-series PSD machinery that's both heavier and not what the QOU paper actually claims.

    Headline statement #

    For PSD matrices Φ (primal optimum) and S (dual slack) of a Slater-feasible SDP at strict complementarity:

    rank(Φ) + rank(S) = n.

    This is the single missing categorical input isolated by the SDPRankUniqueness axiom in SDPRealUniqueness.lean. Proving the rank equality here is what eliminates that axiom; the SDPSlaterUniqueness pipeline then reduces to three atomic inputs — strict_complementarity_kernel_disjoint, affine_slater_rigidity, and rank_via_eigenvalues (a Mathlib API-shape axiom for the standard rank-equals-non-zero- eigenvalue-count fact for Hermitian matrices). All three are axioms (zero sorry). For the QOU practical (³He interior) case, the kernel-disjoint and affine-Slater inputs have proven sub-instances, and the rank-via-eigenvalues axiom is consumed only via Mathlib-standard reasoning; the chain is fully sorry-free.

    Decomposition of the proof into independent pieces #

    The standard textbook proof (Alizadeh-Haeberly-Overton 1997 §3; Boyd-Vandenberghe §5.5.2 for the definition of strict complementarity) factors into:

    • (R1) Range containment (proven in QOU.MathlibExt.SDPRealUniqueness.Matrix.PosSemidef.mul_zero_comm): PSD S * Φ = 0 ⟹ range(Φ) ⊆ ker(S), hence rank(Φ) ≤ n - rank(S) by rank-nullity.

    • (R2) Strict-complementarity rank equality — the categorical content: ker(S) ∩ ker(Φ) = {0} under strict complementarity, hence range(Φ) ⊕ range(S) = ℝ^n, hence rank(Φ) + rank(S) = n.

    • (R3) Uniqueness from rank equality + Slater: dim(ker(S)) = rank(Φ) + affine constraints + Slater ⟹ the optimal Φ is unique.

    R1 is proven (in PR #623 batch ~24 + the range-containment lemma). R2 is the categorical Mathlib gap. R3 reduces to finite-dimensional linear-algebra under Slater (proven from R2).

    What this module provides #

    • Matrix.PosSemidef.eigenvalues_pos_filter_eq_ne_zero_filter (theorem — fully proven): for PSD M, the filter {i : eigenvalues i > 0} equals {i : eigenvalues i ≠ 0}.

    • Matrix.PosSemidef.rank_via_eigenvalues (axiom — Mathlib API shape): for PSD M, rank M = #{i : eigenvalues_i > 0}. Standard fact (Boyd-Vandenberghe §A.5.5), supplied by Mathlib as Matrix.IsHermitian.rank_eq_card_non_zero_eigenvalues or equivalent; booked as an axiom here pending exact lemma- name verification at build time.

    • strict_complementarity_kernel_disjoint (axiom — R2): under strict complementarity, ker(Φ) ∩ ker(S) = {0}.

    • rank_equality_under_strict_complementarity (theorem — proven from the above + range containment): rank(Φ) + rank(S) = n.

    • SDPRankUniqueness_proven_via_rank_equality (theorem — closes the Slater uniqueness from rank equality): wires R1 + R2 + R3 into the SDPRankUniqueness axiom from SDPRealUniqueness.lean, replacing it with a theorem.

    §1 Rank for PSD matrices via eigenvalues #

    For Hermitian (and a fortiori PSD) matrices, rank equals the number of non-zero eigenvalues. Mathlib's Matrix.rank is defined via the column-image submodule; equivalence with the eigenvalue count for Hermitian matrices is a standard fact.

    source
    theorem QOU.MathlibExt.SDPRankEquality.PosSemidef.eigenvalues_pos_filter_eq_ne_zero_filter {n : ℕ} {M : Matrix (Fin n) (Fin n) ℝ} (hM : M.PosSemidef) :
    {i : Fin n | 0 < ⋯.eigenvalues i} = {i : Fin n | ⋯.eigenvalues i ≠ 0}

    PSD eigenvalue filter equivalence — for a PSD matrix, "strictly positive eigenvalue" coincides with "non-zero eigenvalue" (since PSD eigenvalues are non-negative). Fully proven; no Mathlib gap.

    source
    theorem QOU.MathlibExt.SDPRankEquality.PosSemidef.rank_via_eigenvalues {n : ℕ} {M : Matrix (Fin n) (Fin n) ℝ} (hM : M.PosSemidef) :
    M.rank = {i : Fin n | 0 < ⋯.eigenvalues i}.card

    PSD rank via eigenvalues — for a real PSD matrix, the rank equals the count of strictly-positive eigenvalues (PSD eigenvalues are non-negative, so equivalently: rank = #{i : eigenvalues i ≠ 0}).

    Status: PROVEN (de-axiomatised) — composes the proven helper eigenvalues_pos_filter_eq_ne_zero_filter (PSD eigenvalues are ≥ 0, so > 0 ⟺ ≠ 0) with Mathlib's Matrix.IsHermitian.rank_eq_card_non_zero_eigs (rank A = #{i // eigenvalues i ≠ 0}, immediate from the spectral theorem) and Fintype.card_subtype (bridging the subtype-card to the Finset.filter card).

    Ref: [boyd-vandenberghe-2004] Convex Optimization §A.5.5 (rank of a Hermitian matrix equals the number of non-zero eigenvalues; immediate from the spectral theorem).

    §2 Strict-complementarity kernel disjointness #

    The categorical content of strict complementarity: ker(Φ) ∩ ker(S) = {0} for the primal optimum Φ and dual slack S. This is the single Mathlib gap isolating the multi-week SDP rank-equality work.

    §2.9 Matrix rank via the toLin' range (missing-lemma shim) #

    Matrix.rank is defined as finrank R (range mulVecLin), and the proofs below phrase rank through range toLin'. Mathlib ships only the basis-general Matrix.rank_eq_finrank_range_toLin; the standard-basis specialisation (…toLin') the original proofs assumed is provided here.

    source
    theorem QOU.MathlibExt.SDPRankEquality.rank_eq_finrank_range_toLin' {m k : ℕ} (M : Matrix (Fin m) (Fin k) ℝ) :
    M.rank = Module.finrank ℝ ↥(LinearMap.range (Matrix.toLin' M))

    Standard-basis specialisation of Matrix.rank_eq_finrank_range_toLin: M.rank = finrank ℝ (range M.toLin'). Since toLin' = mulVecLin (both send v ↦ M *ᵥ v) and Matrix.rank is by definition the finrank of range mulVecLin, the two ranges coincide.

    §3 Rank equality from kernel disjointness #

    The proven half: kernel disjointness + range containment give the rank equality rank(Φ) + rank(S) = n. Pure finite-dimensional linear algebra.

    source
    theorem QOU.MathlibExt.SDPRankEquality.rank_sum_le_of_mul_zero {n : ℕ} {ι : Type u_1} [Fintype ι] {sdp : SDP.SDPPrimal n ℝ ι} (sc : SDPRealUniqueness.RealStrictComplementarityPair sdp) :
    sc.Φstar.rank + (sdp.dualSlack sc.ystar).rank ≤ n

    Rank inequality from range containment — proven half: rank(Φstar) + rank(S) ≤ n (the easy direction).

    Proof: range(Φstar) ⊆ ker(S) (R1) ⟹ rank(Φstar) ≤ dim(ker(S)) = n - rank(S). Pure linear algebra.

    source
    theorem QOU.MathlibExt.SDPRankEquality.rank_equality_under_strict_complementarity {n : ℕ} {ι : Type u_1} [Fintype ι] {sdp : SDP.SDPPrimal n ℝ ι} (sc : SDPRealUniqueness.RealStrictComplementarityPair sdp) (_h_slater : sdp.IsStrictlyFeasible) (h_S_posDef : (sdp.dualSlack sc.ystar).PosDef) :
    sc.Φstar.rank + (sdp.dualSlack sc.ystar).rank = n

    Rank equality from strict complementarity — proven from kernel disjointness (R2) + range containment (R1) + finite-dimensional rank-nullity.

    The proof composes:

    1. range(Φstar) ⊆ ker(S) (range_contained_in_kernel_of_mul_zero)
    2. ker(Φstar) ∩ ker(S) = {0} (strict_complementarity_kernel_disjoint)
    3. rank(Φstar) + rank(S) ≤ n (rank_sum_le_of_mul_zero, proven above)
    4. dim(ker(Φstar)) + dim(ker(S)) ≤ n (kernel-disjoint ⟹ direct sum)
    5. (n - rank(Φstar)) + (n - rank(S)) ≤ n (rank-nullity)
    6. ⟹ rank(Φstar) + rank(S) ≥ n
    7. Combined with (3): rank(Φstar) + rank(S) = n.

    §4 Slater uniqueness from rank equality (proven) #

    Once we have the rank equality, Slater + strict complementarity forces uniqueness via finite-dimensional argument:

    • Any feasible Φ' with same objective has range in ker(S).
    • dim(ker(S)) = n - rank(S) = rank(Φstar).
    • The affine constraints tr(A_i Φ) = b_i define a hyperplane intersection; under Slater, this hyperplane intersected with the rank-bounded PSD cone gives a unique point.

    This is proven (modulo §1, §2 axioms).

    §4.5 Affine-Slater rigidity axiom #

    The final composition SDPRankUniqueness_proven_via_rank_equality needs one more categorical input: affine-Slater rigidity — the statement that under Slater's strict feasibility + the rank-equality structure (range Φ ⊕ range S = ℝ^n), the affine constraint set restricted to symmetric matrices in ker(S) (where the difference D = Φ' − Φstar lives) is a SINGLE POINT.

    This is the "active face has dimension zero" content from Alizadeh-Haeberly-Overton 1997 §3. Genuinely multi-week categorical work (active-face dimension theory + Slater's interior-point hypothesis); axiomatised here as a NAMED single statement so the rest of the chain composes cleanly.

    affine_slater_rigidity — REMOVED (it was false) #

    This axiom asserted that under Slater plus the rank equality rank Φ⋆ + rank S = n, a Hermitian D with S · D = 0 and vanishing constraint traces must be zero. It is false and has been deleted. Refutation: QOU.MathlibExt.SDPUniquenessCounterexamples.not_affine_slater_rigidity — sorry-free, depending on no QOU axiom.

    Its rank guard is real but insufficient, which is why this one needs a two-dimensional counterexample rather than the one-dimensional one used for the other four: take n = 2, no constraints, cost = diag(1,0), Φ⋆ = diag(0,1) and D = diag(0,1). Then rank Φ⋆ + rank S = 1 + 1 = 2 = n — the guard is satisfied — and S · D = 0 with D ≠ 0.

    affine_slater_rigidity_of_dualSlack_posDef (below, proven) is the interior case and is what SDPRankUniqueness_proven_via_rank_equality now uses.
