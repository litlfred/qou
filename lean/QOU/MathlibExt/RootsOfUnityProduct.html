    theorem QOU.MathlibExt.prod_one_sub_nthRoots_erase_one {n : ℕ} (hn : n ≠ 0) :
    (Multiset.map (fun (a : ℂ) => 1 - a) ((Polynomial.nthRoots n 1).erase 1)).prod = ↑n

    ∏_{ζ ≠ 1}(1 - ζ) = n over the n-th roots of unity in ℂ.

    The product is over (nthRoots n 1).erase 1, i.e. every n-th root of unity except 1 itself, each counted once (the roots are distinct since n ≠ 0 in ℂ, which is what card_nthRoots_one encodes).

    theorem QOU.MathlibExt.prod_one_sub_zeta_pow {n : ℕ} (hn : n ≠ 0) {ζ : ℂ} (hζ : IsPrimitiveRoot ζ n) :
    ∏ j ∈ Finset.Ico 1 n, (1 - ζ ^ j) = ↑n

    ∏_{j=1}^{n-1}(1 - ζ^j) = n for a primitive n-th root of unity ζ.

    The index conversion needs no injectivity: Multiset.map_erase_of_mem holds for any f, because multiset erase removes a single occurrence.

    theorem QOU.MathlibExt.prod_two_sin_pi_div (n : ℕ) (hn : n ≠ 0) :
    ∏ j ∈ Finset.Ico 1 n, 2 * Real.sin (↑j * Real.pi / ↑n) = ↑n

    ∏_{j=1}^{n-1} 2 sin(jπ/n) = n.

    The real form, obtained from prod_one_sub_zeta_pow at ζ = e^{2πi/n} by taking norms, using ‖1 - e^{iθ}‖ = 2 sin(θ/2) on (0, 2π).

    At k = n-1 this is s_{n-1} = -log n for s_k = -∑_{j=1}^k log(2 sin(jπ/n)), the endpoint that pins the additive constant in the one-loop expansion of QOU.Knot.kashaev.
