    Faddeev Φ_b on the fibre saddle — genuine real-integral construction #

    The construction item of the Φ_b program (PR #3544 work item 2): on the fibre saddle (real b, real z) the Faddeev contour integral collapses to a real single integral, numerically pinned to 8e-29 against the validated contour evaluator (computations/qbeta/qbeta_phi_b_real_form_pin.py, P1–P4 gates):

    log Φ_b(z) = i·(−J/2 + πz²/2 + π(b² + b⁻²)/24), J(b, z) = ∫₀^∞ [ sin(2zt) / (t·sinh(bt)·sinh(t/b)) − 2z/t² ] dt.

    Unlike QOU.MathlibExt.FaddeevQuantumDilogarithm (which axiomatizes Φ_b as a conjecture-class because the contour integral is out of Mathlib's reach), this file gives a genuine noncomputable def — phiB is Mathlib's Bochner integral, no axiom, no class — and proves its structural laws sorry-free:

    • phiB_self_dual — Φ_{b⁻¹} = Φ_b (the modular-double self-duality), from the manifest b ↔ b⁻¹ symmetry of the kernel.
    • norm_phiB — unitarity ‖Φ_b(z)‖ = 1 (the phase is real).
    • phiB_inversion — Φ_b(z)·Φ_b(−z) = exp(i·(πz² + π(b²+b⁻²)/12)) (the inversion relation: J is odd in z, so it cancels).
    • phiB_zero — Φ_b(0) = exp(i·π(b²+b⁻²)/24) (J(b,0) = 0).

    Honest scope. These laws hold for the defined object unconditionally (Mathlib's integral is total; the symmetry/oddness proofs are pointwise kernel identities plus integral congruence, needing no integrability hypotheses). What is not proved here — and is the remaining analytic content — is the identification of phiB with the contour-integral Φ_b (the 8e-29 numerical pin, P1–P4); kernel integrability IS proved (near-0 outright, the tail modulo two standard majorant facts — see the integrability sections). No c_k value is produced or wired; the argument-identification is a separate item.

            The fibre branch is the |q| = 1 regime, and Φ_b is σ-unitary there #

            At real b the modular parameter q_b = e^{iπb²} sits ON the unit circle — the fibre / root-of-unity regime where the modular-double product diverges (QOU.MathlibExt.PhiBProd covers only Im b² > 0, where |q_b| < 1) and the real integral above is the construction. The defined phiB is a genuine phase there: Φ_b · conj(Φ_b) = 1. This is the archimedean instance of the σ-unitarity hypothesis of prop:phi-b-unitary-bar-odd (σ = complex conjugation): by that proposition's rigidity clause, any such phase with Φ² ≠ 1 carries a nontrivial bar-odd part — the fibre-branch Φ_b is an intrinsically bar-odd carrier.

              Integrability: the exponential-tail domination is a THEOREM #

              sin is bounded, the double-sinh denominator grows like e^{(b+1/b)t}, and the subtracted 2z/t² is a t^{-2} tail — so the kernel is dominated on [1, ∞) by C·e^{−bt} + 2|z|·t^{−2}, and integrable there. All the kernel-specific analysis (the sinh lower bound, the domination chain, continuity/measurability) is proved sorry-free below.

              Fully unconditional (2026-07-14). The two majorant integrability facts — e^{−bt} and t^{−2} are integrable on [1, ∞) — are the standard Mathlib theorems exp_neg_integrableOn_Ioi and integrableOn_Ioi_rpow_of_lt, proved here as the private lemmas majorant_exp / majorant_inv. (Their modules Mathlib.MeasureTheory.Integral.ExpDecay + Mathlib.Analysis.SpecialFunctions.ImproperIntegrals were built into the sandbox olean cone; an earlier revision carried them as explicit hexp/hinv hypotheses per the PhiBProd precedent — now discharged.) So the tail (integrableOn_kernel_Ioi_one), the near-0 piece (integrableOn_kernel_Ioc_zero_one — the −2z/t² subtraction cancels the pole), and hence the full (0, ∞) integrability (integrableOn_kernel_Ioi_zero) are all hypothesis-free theorems. The def↔contour identification of phiB with the Faddeev contour integral remains the 8e-29 numerical pin (module docstring) — it is NOT assumed anywhere in this file.

              The near-0 piece: the subtraction cancels the pole (THEOREM) #

              On (0, 1] the kernel is bounded, hence integrable: writing y = 2zt, p = bt, r = t/b (so p·r = t² exactly), the kernel splits as

              kernel = (sin y − y)/D + 2z·(t² − sinh p · sinh r)/(t² · sinh p · sinh r),

              and each piece is O(1): |sin y − y| ≤ 2|y|³ (globally) against D ≥ t³·e^{−(b+1/b)} (from sinh x ≥ x·e^{−x}), and |sinh p · sinh r − pr| ≤ pr·(p² + r²) on the box p, r ≤ 1 (from the two-sided cubic sinh estimates supplied by Real.exp_bound at order 3) against sinh p · sinh r ≥ (49/81)·pr. Away from 0 (on [δ, 1], δ = min(1, 1/b, b)) both raw terms are trivially bounded. All proved sorry-free below; integrableOn_kernel_Ioc_zero_one needs no hypotheses.
