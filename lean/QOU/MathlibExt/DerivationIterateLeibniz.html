    theorem QOU.MathlibExt.DerivationIterate.iterate_leibniz {R : Type u_1} {A : Type u_2} [CommSemiring R] [CommSemiring A] [Algebra R A] (D : Derivation R A A) (f g : A) (n : ℕ) :
    (⇑D)^[n] (f * g) = ∑ k ∈ Finset.range (n + 1), n.choose k • ((⇑D)^[k] f * (⇑D)^[n - k] g)

    Higher Leibniz rule. Iterating a derivation n times across a product distributes binomially:

    Dⁿ(f·g) = Σ_{k=0}^{n} C(n,k) · (Dᵏ f) · (D^{n−k} g).

    The n = 1 case is Derivation.leibniz; the general case is the algebraic shadow of the analytic Leibniz formula, and it is what makes exp(D) multiplicative.

    Stated with ℕ-smul rather than a cast, so the inductive step needs only additivity of D (map_nsmul) and never Derivation.map_natCast.

    theorem QOU.MathlibExt.DerivationIterate.exp_leibniz_iff_cross_vanishes {R : Type u_3} {A : Type u_4} [CommSemiring R] [CommRing A] [Algebra R A] (D : Derivation R A A) (f g : A) :
    f * g + D (f * g) = (f + D f) * (g + D g) ↔ D f * D g = 0

    exp(D) is multiplicative exactly when the cross-term vanishes, at one-instanton order. For D with D² = 0 the exponential truncates to 1 + D, and

    (1+D)(f·g) = (1+D)f · (1+D)g ↔ Df · Dg = 0.

    This is the honest one-instanton statement behind "the Stokes automorphism is exp of the alien derivative": at first order the automorphism property is equivalent to the vanishing of the two-instanton cross-term, which is what truncating at one instanton assumes. The unconditional exp(Δ) automorphism needs a completion or local nilpotency for the series to converge, and is not claimed here.

    Note the D² = 0 hypothesis is not needed for the equivalence itself — 1 + D is the truncation whether or not D squares to zero — so it is not taken as an argument. It is recorded in the name because that is the setting in which 1 + D is exp D.

    (⇑D)^[1] (f * g) = f * D g + g * D f

    The n = 1 case is Leibniz. Recorded as a consistency check that iterate_leibniz specialises correctly — a wrong binomial index would show up here.

    theorem QOU.MathlibExt.DerivationIterate.iterate_leibniz_two {R : Type u_1} {A : Type u_2} [CommSemiring R] [CommSemiring A] [Algebra R A] (D : Derivation R A A) (f g : A) :
    (⇑D)^[2] (f * g) = (⇑D)^[2] f * g + 2 • (D f * D g) + f * (⇑D)^[2] g

    The n = 2 case, written out. D²(fg) = D²f·g + 2·Df·Dg + f·D²g. The middle coefficient 2 is the first place the binomial content is visible, so this is the smallest genuine test of iterate_leibniz.
