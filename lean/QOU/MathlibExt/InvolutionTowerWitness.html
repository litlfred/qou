    A TowerSpan witness whose filtration actually GROWS #

    Bean qou-301d. This exists to answer a specific criticism made of DisjointBlockTraceLaw.towerSpan_unit, in that file's own docstring: it is a degenerate witness. Its algebra is R itself, so every submodule containing 1 is already ⊤; and its filtration is constant, so towerSpan_of_constant covers it for reasons unrelated to anything TowerSpan asserts.

    This file supplies a witness without that defect.

    The construction #

    A = MonoidAlgebra R G with G = Multiplicative (ℕ →₀ ZMod 2) — countably many commuting involutions t m. The tower is H n = adjoin {t m | m < n}, the generators are g m = ginv m = t m, and the trace is the augmentation, with z = z' = 1.

    • t_mul_t — t m * t m = 1, so the quadratic relation holds with h = 0.
    • sandwichReduces_involution — SandwichReduces holds, and non-trivially: t * c * t = c * (t * t) = c uses commutativity and the involution relation. This is the local rewriting rule of TowerSpanReduction doing real work.
    • towerSpan_involution — hence TowerSpan, via towerSpan_of_sandwichReduces.
    • t_not_mem_shiftedUpTo — the filtration genuinely grows: t N is not in shiftedUpTo n M for M < N. Proved by exhibiting an algebra endomorphism (killN, induced by the coordinate projection that kills index N) which fixes every generator of the stage but sends t N to 1; if t N were in the stage it would be fixed, forcing t N = 1, which t_ne_one refutes.

    🛑 What this witness still does NOT exercise #

    The trace is an algebra homomorphism. So DisjointBlockMultiplicative holds here for every pair a, b — disjointness plays no part — and the witness therefore tests the filtration content of TowerSpan while saying nothing about its trace content.

    That is a real limitation and it is stated here rather than left for a reader to discover: this file removes the constant-filtration objection to towerSpan_unit, and only that one. A witness with a growing filtration and a non-multiplicative trace would essentially be a Hecke or symmetric-group tower, which Mathlib does not supply.
