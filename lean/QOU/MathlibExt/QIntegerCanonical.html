    The canonical quantum integer [n]_q = (qⁿ − q⁻ⁿ)/(q − q⁻¹).

    Bar-even, the U_q(sl₂) quantum dimension, and the form matching AGENTS.md §7a's Hecke normalisation. Use this unless your variable means q² — see qIntGeo.

        The integer-index sibling #

        Six definitions in the corpus carry a ℤ index with a byte-identical body, under five different names: qNumberSym (twice), qIntZ, qIntSym, qInt, qBracket. They are not a separate convention — qIntBalZ_natCast below shows the ℤ form restricts to qIntBal on ℕ. What the ℤ index buys is the one structural fact ℕ cannot state: the q-integer is odd in its index (qIntBalZ_neg), which is what makes [k−3]_q-style shifted indices (volume_perturbation) and negative sl₂ weights expressible at all.

          The classical-extended (guarded) forms — policy #

          Eight further definitions guard the singularity, if q = 1 then n else …. They were previously lumped together as one bucket; they are two, because the guard is orthogonal to the convention: three are guarded-balanced (H3HeckeIdempotents, ZeqNRhoCorrection, FeynmanPathIntegrals) and three are guarded-geometric (jacksonInt in two chapters, quantum-dilogarithm, TopologicalMass).

          The policy is: keep the guard, but define it through the unguarded form. A guarded definition really is a different function — Lean's x / 0 = 0 makes the unguarded form take value 0 at q = 1, whereas the guarded one takes the removable-singularity value n. So a blanket guarded → unguarded sweep would silently change behaviour at q = 1, exactly the way a blanket geometric → balanced sweep would. But that difference is confined to a single point, and stating it as a theorem (qIntBalCl_of_ne_one) rather than a comment is what lets a site migrate and keep its q = 1 case.

          The substrate sits at q₀ ≈ 1.11 ≠ 1, so production evaluation never sees the guard; it exists for the classical limit q → 1, which several sites take deliberately (q-casimir-classical-limit, Hoefsmit.qBracket_at_one).

          The gap, and its closure. The balanced form is singular at q = −1 as well (q − q⁻¹ = 0 there too). This was first recorded here as an open gap — "the two-sided variant is left to whoever needs q = −1" — on the belief that the guarded-balanced sites all guard only q = 1. A closer census found that belief wrong: three sites guard the singular locus itself, writing if q − q⁻¹ = 0 (unified-iterative-correction, QSchurYLambdaClosedForm) or the equivalent if q = q⁻¹ (zeta8-witness-level2-su2), and a fourth (QOU.IwahoriHecke.Hoefsmit.qBracket) guards q ≠ 1 ∧ q ≠ −1 explicitly. So the two-sided variant had four users already. It is qIntBalClSing below, and the two guarded families are now separated by name rather than conflated:

          form guard value on the guard
          qIntBalCl q = 1 n
          qIntBalClSing q − q⁻¹ = 0 (i.e. q = ±1, and q = 0) n

          They are not interchangeable: away from characteristic 2, qIntBalCl (−1) n = 0 while qIntBalClSing (−1) n = n. qIntBalClSing_eq_qIntBalCl states exactly where they do agree, and qIntBalCl_neg_one_eq_zero carries the (-1 : R) ≠ 1 hypothesis that separates them — in characteristic 2 the locus {1, −1} is a single point and the two forms coincide, so the distinction this module draws is a characteristic-≠ 2 phenomenon.

              Singular-locus-guarded balanced q-integer: qIntBal away from the whole locus where the balanced denominator vanishes, and n on it.

              This is the two-sided companion to qIntBalCl, and the form four corpus sites actually use. Two honesty notes on the guard, since q − q⁻¹ = 0 is not the same set as q = ±1:

              • q = −1 is a genuine removable singularity and n is its correct value, which is why the guard is worth having: qIntBalCl returns 0 there.
              • q = 0 is caught too, because Lean's 0⁻¹ = 0 makes q − q⁻¹ = 0 hold at zero. The value n there is not a limit of anything — it is junk from a junk input. The guard is stated on the denominator rather than on q = ±1 because that is what the call sites wrote; nothing downstream evaluates at q = 0, and the substrate sits at q₀ ≈ 1.11.

                Small-index shorthands #

                Five corpus sites write [2]_q and [3]_q out longhand as q + q⁻¹ and q² + 1 + q⁻² under local names (qInt2, qBracket2, qInt3). They cannot be aliased — the longhand is their body and their proofs use it — but they can be tied to the canonical bracket by these two identities.

                Note both are conditional, and on more than the obvious: [2]_q needs only q − q⁻¹ ≠ 0, but [3]_q additionally needs q ≠ 0, because the middle term 1 is q · q⁻¹. A shorthand site is therefore equal to the canonical bracket away from the degenerate locus, not everywhere — which is exactly the kind of thing a body swap would have hidden.
