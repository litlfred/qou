    QOU.MathlibExt.PosSemidefDiagZero #

    The "PSD with zero diagonal entry has zero row/column" lemma — the key Mathlib piece needed by the general spectral-reduction proof of Matrix.PosSemidef.trace_mul_eq_zero_iff_mul_eq_zero.

    What this module provides #

    • Matrix.PosSemidef.entry_zero_of_diag_zero — if C.PosSemidef and C i i = 0, then C i j = 0 for all j.
    • Matrix.PosSemidef.row_zero_of_diag_zero — same conclusion packaged as "the i-th row is zero".

    Mathematical content #

    Let C be a real PSD matrix. Suppose C_ii = 0. Pick any j ≠ i. By PSD, (e_i + t · e_j)^T · C · (e_i + t · e_j) ≥ 0 for all t ∈ ℝ. Expanding:

    C_ii + 2 t · C_ij + t² · C_jj ≥ 0
= 0   + 2 t · C_ij + t² · C_jj   (by `C_ii = 0`)

    For this quadratic in t to be non-negative for all t, its discriminant must be ≤ 0:

    (2 · C_ij)² - 4 · 0 · C_jj ≤ 0
⟹  4 · C_ij² ≤ 0
⟹  C_ij² = 0
⟹  C_ij = 0.

    The PSD-symmetric companion C_ji = 0 follows from C_ji = C_ij (PSD implies Hermitian; for real matrices, symmetric).

    Categorical significance #

    This is the missing piece for closing the general case of trace_mul_eq_zero_iff_mul_eq_zero (in QOU.MathlibExt.PosSemidefTraceZero): the spectral reduction needs "PSD diagonal-zero ⟹ row-col-zero" to conclude that the diagonalised product D · C is zero when tr(D · C) = 0.

    References #

    • [horn-johnson-2013] Matrix Analysis, §7.7 (Schur complements + PSD det inequalities — the canonical authority for the PSD-has-nonneg-principal-minors lemma used here).
    • [boyd-vandenberghe-2004] §A.5.5 (Schur complement; PSD block structure). Note: §A.5.3 in Boyd is "Generalized eigenvalue decomposition" — that section was previously cited here in error.

    C i j ^ 2 ≤ C i i * C j j

    Cauchy–Schwarz inequality for PSD entries (Horn–Johnson 2013 §7.7): for any real PSD matrix C and indices i, j, (C_ij)² ≤ C_ii · C_jj.

    Proved directly from the test-vector quadratic form: for i ≠ j, v = x·e_i + e_j gives 0 ≤ C_ii x² + 2 C_ij x + C_jj for all x (PSD positivity + quadratic_form_two_index); a nonnegative real quadratic has nonpositive discriminant (discrim_le_zero), i.e. (2 C_ij)² − 4 C_ii C_jj ≤ 0, whence the bound. The i = j case is C_ii² ≤ C_ii². Previously an axiom pending the Mathlib principal-submatrix-PSD API; now discharged.

    theorem QOU.MathlibExt.PosSemidefDiagZero.Matrix.PosSemidef.entry_zero_of_diag_zero {n : ℕ} {C : Matrix (Fin n) (Fin n) ℝ} (hC : C.PosSemidef) {i : Fin n} (h_diag : C i i = 0) (j : Fin n) :
    C i j = 0

    PSD off-diagonal-zero from diagonal-zero.

    For a real PSD matrix C, if C i i = 0 for some index i, then C i j = 0 for all j.

    PROOF: Given C i i = 0, set v := single i 1 + t · single j 1 (canonical basis vectors). PSD implies v^T · C · v ≥ 0. Expanding gives 2 t · C i j + t² · C j j ≥ 0 for all t. Discriminant ≤ 0 ⟹ (C i j)² ≤ 0 · C j j = 0 ⟹ C i j = 0.
