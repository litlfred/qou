    QOU.MathlibExt.BraidGroup — Artin braid groups (a genuine Mathlib gap) #

    Mathlib has no braid groups. Verified by search: no file matching *braid* anywhere in Mathlib/, and Mathlib/GroupTheory/ carries Coxeter but not the braid group itself. This module supplies the minimum the MFW programme (QOU/Knot/MortonFranksWilliams.lean, bean qou-dr8m) actually needs, built on Mathlib's PresentedGroup.

    Indexing convention #

    BraidGroup n is the braid group on n + 1 strands, with n Artin generators indexed by Fin n. The offset is deliberate: the alternative (Fin (n-1) for n strands) uses truncated ℕ-subtraction, which poisons every downstream index proof. strandCount n = n + 1 is provided so callers never have to remember which convention is in force.

    Artin presentation #

    σᵢσⱼ = σⱼσᵢ                    for |i − j| ≥ 2      (far commutation)
σᵢσᵢ₊₁σᵢ = σᵢ₊₁σᵢσᵢ₊₁                                (braid relation)

    What is proved here #

    exponentSum — the writhe homomorphism BraidGroup n →* Multiplicative ℤ sending every generator to 1. This is the piece MFW needs: the e in

    e − n + 1 ≤ mindeg_v P  ≤  maxdeg_v P ≤ e + n − 1

    and it is a theorem, not a definition-by-fiat: it descends to the quotient precisely because every Artin relator has total exponent sum zero — the far commutator trivially (it is a commutator, and the target is abelian), and the braid relator because both sides are words of length three. Both obligations are discharged below, so exponentSum is well-defined on the presented group rather than only on the free group.

    That well-definedness is the whole content: the writhe of a braid word is obvious, the writhe of a braid group element is not, and MFW is a statement about the latter.
