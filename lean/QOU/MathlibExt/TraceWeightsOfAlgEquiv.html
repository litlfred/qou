    QOU.MathlibExt.TraceWeightsOfAlgEquiv — a trace's block weights, through a splitting #

    QOU.MathlibExt.TraceIsWeighted shows a trace on ∏_i M_{d_i}(K) is weightedTrace c. This file transports that along an algebra equivalence, so the weights become attached to a trace on an abstract split semisimple algebra A — which is where the abstract Schur element lives.

    What is proved #

    • traceWeight E t a i — the weight of block i, the value of t on the pullback of a diagonal matrix unit.
    • traceWeight_indep — it does not depend on which diagonal unit is chosen. (blockWeight_eq transported; this is what tau_mul_comm was needed for.)
    • eq_weightedTrace_of_algEquiv — t x = weightedTrace (traceWeight …) (E x).
    • exists_ne_zero_forall_mul_eq_zero_of_traceWeight_eq_zero — a vanishing weight puts a whole block in the radical: it exhibits z ≠ 0 with t (z y) = 0 for every y.

    That last one is the direction that matters downstream. Its contrapositive is: if the form (x, y) ↦ t(x y) is nondegenerate, then every block weight is nonzero — so every abstract Schur element 1 / c_λ exists. Applied to the canonical symmetrizing trace, whose Gram determinant QOU.Hecke.TwBasis.tauGram_det_ne_zero computes, that is the statement some s_λ = 0 ⟹ the algebra is not split semisimple.

    Nothing here is Hecke-specific and nothing is archimedean: [Field K], [Ring A], [Algebra K A], per §7c.
