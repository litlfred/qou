    QOU.MathlibExt.QPlancherel — q-Plancherel measure framework #

    A skeleton framework for the q-Plancherel measure on integer partitions and its asymptotic behaviour (CLT). This is a candidate for upstream contribution to Mathlib/Probability/QPlancherel.lean once the surrounding Hecke-character infrastructure is available.

    What this module provides #

    • QDimension typeclass — abstract d_q(λ) for a partition type.
    • QPlancherelMeasure — P_q(λ) = d_q(λ)² / Z_q(k) where Z_q(k) = Σ_{λ ⊢ k} d_q(λ)² is the q-deformed normalisation.
    • CharacterFluctuation — χ_λ - 𝔼[χ] over P_q.
    • HasQPlancherelCLT typeclass — Féray-Méliot 2010 Thm 1.1: the variance of CharacterFluctuation is O(1/k).

    What this module does NOT yet prove #

    The Féray-Méliot CLT requires:

    • A Mathlib formalisation of the Hecke algebra H_n(q) and Markov characters
    • The q-hook walk of Kerov 1996 (q-Plancherel sampling)
    • Asymptotic analysis of q-shifted factorials

    These are deep probability/representation-theory results. The typeclass packages the CLT conclusion; concrete instances are the conjectural input.

    References #

    • [feray2010] V. Féray, P.-L. Méliot, Asymptotics of q-Plancherel measures, Probability Theory and Related Fields 152 (2012), 589-624. https://doi.org/10.1007/s00440-010-0331-6
    • [kerov1996] S. Kerov, A q-analog of the hook walk algorithm, Algebra i Analiz 8 (1996).
    • [biane2001] P. Biane, Approximate factorization and concentration for characters of symmetric groups, IMRN 2001, no. 4, 179-192.

          §2 Féray-Méliot q-Plancherel CLT #

          The headline asymptotic result: as k → ∞, the character fluctuations χ_λ - 𝔼_q[χ] (over the q-Plancherel measure) have variance O(1/k).

          Statement-level form: for any partition type Λ carrying a q-dimension and a partition function, the q-Plancherel CLT provides a uniform C such that |f_k - f_∞| ≤ C / √(k - 3) for branching fractions f_k.

          Type

          q-Plancherel CLT typeclass: witnesses the Féray-Méliot O(1/√k) bound for q-Plancherel branching fractions.

          • Cq : ℝ

            The Féray-Méliot constant.

          • Cq_pos : 0 < Cq Λ R

            The constant is positive.

          • f : ℕ → ℝ

            The branching-fraction sequence the CLT is about.

          • f_inf : ℝ

            Its limit.

          • bound (k : ℕ) : k ≥ 4 → |f Λ R k - f_inf Λ R| ≤ Cq Λ R / √(↑k - 3)

            The Féray–Méliot O(1/√k) bound, for this sequence and its limit.

            f and f_inf are class data, not universally quantified. They were ∀-bound until 2026-08-29, which made the class uninhabitable: Cq is fixed by the instance while f_inf ranged over all of ℝ, so f := 0, f_inf := Cq + 1, k := 4 (where √(4-3) = 1) gave Cq + 1 ≤ Cq, and False followed — machine-checked, #print axioms clean, in docs/audits/2026-08-29-qplancherel-clt-uninhabitable-probe.lean.

            The defect was the general shape a sibling branch named on PR #6041: an external theorem asserted for every inhabitant of a structure that does not carry the theorem's hypotheses. [feray2010] Theorem 1.1 is a statement about the q-Plancherel branching fractions, not about arbitrary real sequences, and the type must say so.

          Instances

            §3 The partition function as a constructed sum, and total mass one #

            §1 states the measure as d_q(λ)² / Z k with Z an opaque class field of HasPartitionFunction, constrained only by Z_pos. That suffices for measure_nonneg and for measure_mul_partitionFunction — but note what the latter actually says once unfolded: Z · (d² / Z) = d², which holds for any nonzero Z and so says nothing about Z being a sum of squares.

            In particular §1 does not establish that measure is a probability measure. The class docstring documents Z_q(k) = Σ_{λ ⊢ k} d_q(λ)², and the module header repeats it, but that identity is prose: nothing in the type ties Z k to any sum, so no total-mass statement is available or even expressible.

            This section closes that gap the honest way — by constructing the partition function as a finite sum over an explicit Finset of blocks and proving total mass 1 for it — and then records the witness showing the opaque field cannot deliver the same conclusion, so the construction is not mistaken for bookkeeping.

            On triviality. sum_measureOn_eq_one is a one-line consequence of Finset.sum_div and div_self, and that is the point rather than a defect: normalising a family by its own sum gives total mass one by construction, so this theorem is evidence about the constructed object only. It is emphatically not evidence that Σ_λ d_q(λ)² is the canonical normaliser for the Ocneanu weights W_λ = d_q(λ)²/[n]_q! — that question is open, and the measured Σ_λ d_q(λ)² ≠ [n]_q! at q ≠ 1 (the Z(n) defect, with its sign change at n = 7) is exactly what makes it open. See docs/audits/2026-06-20-keystone-wlambda-Z-defect-n-scaling.md.

            def QOU.MathlibExt.QPlancherel.qPartitionFunctionOn {Λ' : Type u} {R' : Type v} [CommRing R'] [QDimension Λ' R'] (s : Finset Λ') :
            R'

            Constructed q-Plancherel partition function over an explicit finite set of Wedderburn blocks: Z_q(s) = Σ_{λ ∈ s} d_q(λ)².

            Unlike HasPartitionFunction.Z this is a definition, not an axiom: the summation the class docstring describes is carried out. The Finset is supplied by the caller because the universe of partitions of a given size is finite but not canonically presented here (the same reason §1 gave for leaving Z opaque).
