    QOU.MathlibExt.RegularHom — Hom_G(k[G], V) ≃ V #

    Third brick of W1+W3 of the Wedderburn epic (qou-bxw4).

    An equivariant map out of the regular representation is determined by where it sends the identity basis vector, and every target vector occurs. So

    Hom_G(k[G], V) ≃ₗ[k] V, hence dim_k Hom_G(k[G], V) = dim_k V.

    Combined with the Schur orthonormality of SpechtSchurDiagonal this is what reads the multiplicity of S^μ in the regular representation off as dim_k S^μ — the step that turns dim_k k[S_n] = n! into n! = Σ_μ (dim S^μ)². The point of doing it this way rather than by expanding characters is that it needs no completeness / spanning statement for the characters, which the corpus has only as an upper bound.

    This file is deliberately general: any group, any base field, any representation. Nothing about S_n or Specht modules enters.
