    def QOU.MathlibExt.QBorelKernel.qBorelExp (d n : ℕ) :
    ℕ

    The level-d q-Borel kernel exponent. With n = d·m + r (m = n / d, r = n % d), summing the chain n, n−d, …, r gives m·r + d·C(m,2).
