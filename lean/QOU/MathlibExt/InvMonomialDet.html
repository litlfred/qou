    QOU.MathlibExt.InvMonomialDet — determinant of a matrix supported on the graph of a permutation #

    A generalised permutation matrix — one whose support is the graph {(v, σ v)} of a permutation, carrying an arbitrary scalar f v there — has determinant sign σ · ∏ f. Mathlib has both halves separately (Matrix.det_diagonal, Matrix.det_permute') and not the composite, so this file is one lemma and its group-inversion specialisation.

    The specialisation is the one wanted downstream: on a finite group G, the matrix M v w = if w = v⁻¹ then f v else 0. That is the shape of the Gram matrix of a symmetrizing trace in a basis indexed by G — see QOU.Hecke.TauSymmetrizing — because such a trace pairs a basis element only with the basis element at its inverse.

    What is proved #

    • det_of_graph_monomial — det (fun v w => if w = σ v then f v else 0) = sign σ · ∏ f, for any σ : Equiv.Perm ι.
    • det_of_inv_monomial — the σ = inversion case on a finite group.
    • det_of_inv_monomial_ne_zero — nonzero over a field iff no f v vanishes.

    Nothing here is Hecke-specific and nothing is archimedean; everything is over a generic [CommRing K] ([Field K] only for the non-vanishing corollary), per the §7c base-ring convention.

    source
    theorem QOU.MathlibExt.det_of_graph_monomial {K : Type u_1} {ι : Type u_2} [Fintype ι] [DecidableEq ι] [CommRing K] (σ : Equiv.Perm ι) (f : ι → K) :
    (Matrix.of fun (v w : ι) => if w = σ v then f v else 0).det = ↑↑(Equiv.Perm.sign σ) * ∏ v : ι, f v

    A matrix supported on the graph of σ is sign σ times the product of its nonzero entries.

    M v w = f v when w = σ v and 0 otherwise; it is diagonal f with its columns permuted, which is why Matrix.det_permute' closes it.

    theorem QOU.MathlibExt.det_of_inv_monomial {K : Type u_1} [CommRing K] {G : Type u_3} [Group G] [Fintype G] [DecidableEq G] (f : G → K) :
    (Matrix.of fun (v w : G) => if w = v⁻¹ then f v else 0).det = ↑↑(Equiv.Perm.sign (Equiv.inv G)) * ∏ v : G, f v

    The inversion case. On a finite group, a matrix whose only nonzero entries sit at (v, v⁻¹) has determinant sign(inv) · ∏ f.

    source
    theorem QOU.MathlibExt.det_of_inv_monomial_ne_zero {K : Type u_1} [Field K] {G : Type u_3} [Group G] [Fintype G] [DecidableEq G] {f : G → K} (hf : ∀ (v : G), f v ≠ 0) :
    (Matrix.of fun (v w : G) => if w = v⁻¹ then f v else 0).det ≠ 0

    Over a field such a determinant vanishes exactly when one of the entries does — the sign is a unit and contributes nothing.
