    Quadratic surds are badly approximable — a Mathlib-gap lemma #

    Mathlib knows Irrational (Real.sqrt D) (for non-square D) but does not carry the classical badly-approximable lower bound: for α = √D there is c > 0 with ‖jα‖ ≥ c/j for every j ≥ 1, where ‖·‖ = |· − round ·| is the distance to the nearest integer. Equivalently, the continued-fraction partial quotients of a quadratic surd are bounded — but the bound here is proved elementarily, with no continued-fraction machinery, from the single arithmetic fact that D j² − p² is a nonzero integer (hence |D j² − p²| ≥ 1).

    This is the number-theoretic input the Dilog Part B W-P1 limit needs to make the no-resonance / wp1_tendsto_of_powerBound hypothesis unconditional for x = e^{−√D}: the maximal-cell branch-point gap is ≈ {j√D}·(q_j − 1) ≥ (c/j)·(q_j − 1) ≈ c·(q_j − 1)² (the quadratic bound K = 2).

    sqrt_badlyApproximable : ∃ c > 0, ∀ j ≥ 1, c/j ≤ ‖j√D‖.

    theorem QOU.MathlibExt.sqrt_badlyApproximable {D : ℕ} (hD : Irrational √↑D) :
    ∃ (c : ℝ), 0 < c ∧ ∀ (j : ℕ), 1 ≤ j → c / ↑j ≤ |↑j * √↑D - ↑(round (↑j * √↑D))|

    Quadratic surds are badly approximable. For α = √D irrational there is c > 0 with c/j ≤ |jα − round(jα)| for all j ≥ 1. Elementary: with p = round(jα), the integer D j² − p² is nonzero (else α = p/j is rational), so |D j² − p²| ≥ 1; factoring (jα − p)(jα + p) = D j² − p² and bounding |jα + p| ≤ (2α + 1)·j gives |jα − p| ≥ 1/((2α+1) j).

    theorem QOU.MathlibExt.sqrt_fract_badlyApproximable {D : ℕ} (hD : Irrational √↑D) :
    ∃ (c : ℝ), 0 < c ∧ ∀ (j : ℕ), 1 ≤ j → c / ↑j ≤ Int.fract (↑j * √↑D)

    Fractional-part form. For α = √D irrational, c/j ≤ {jα} for all j ≥ 1 ({·} = Int.fract). This is the shape the Dilog Part B maximal-cell branch-point gap needs (the gap is ≈ {j√D}·(q_j − 1)). Proved directly with p = ⌊jα⌋: since p ≤ jα, jα + p ≤ 2αj (no 1/2 slack), and D j² − p² is a positive integer ({jα} = 0 would make jα = p ∈ ℤ, contradicting irrationality), so {jα} = jα − p = (D j² − p²)/(jα + p) ≥ 1/(2αj).

    theorem QOU.MathlibExt.quadratic_irrational_fract_badlyApproximable {A B C : ℤ} {β : ℝ} (hA : A ≠ 0) (hβ : Irrational β) (hβ0 : 0 < β) (hroot : ↑A * β ^ 2 + ↑B * β + ↑C = 0) :
    ∃ (κ : ℝ), 0 < κ ∧ ∀ (j : ℕ), 1 ≤ j → κ / ↑j ≤ Int.fract (↑j * β)

    Every real quadratic irrational is badly approximable (fract form). If β > 0 is irrational and satisfies an integer quadratic Aβ² + Bβ + C = 0 (A ≠ 0), then ∃ κ > 0, ∀ j ≥ 1, κ/j ≤ {jβ} — the degree-2 Liouville bound. With p = ⌊jβ⌋, the integer N = A p² + B p j + C j² is nonzero (else p/j is a rational root, forcing β or its conjugate rational), so |N| ≥ 1; the identity N = −(jβ − p)·(A(p+jβ) + Bj) (using the root relation) with the bound |A(p+jβ)+Bj| ≤ j·(2|A|β + |B|) gives {jβ} = jβ − p ≥ 1/(j·(2|A|β+|B|)). Generalizes sqrt_fract_badlyApproximable (A=1, B=0, C=−D) to all quadratic surds, hence the unconditional Dilog Part B limit to x = e^{−β} for every quadratic-irrational β > 0.
