    The Iwahori–Hecke algebra of a Coxeter matrix #

    Mathlib-style local infrastructure. Mathlib has a CoxeterMatrix and a CoxeterSystem, but no Hecke algebra of any kind — measured against the built .olean tree (the source is not present in every container), with CoxeterSystem as a positive control: CoxeterSystem occurs in three modules, Hecke in one, and that one is Mathlib/NumberTheory/FLT/Basic, where it is a docstring mention of Hecke operators in the modularity story. So this file builds the object from FreeAlgebra and RingQuot rather than wrapping something upstream.

    What this is, and what QOU.IwahoriHecke is not #

    QOU.IwahoriHecke.Quotient.IwahoriHeckeQuot imposes the quadratic relation only; its braid relations were deferred. That makes it a free product of copies of R[x]/((x − q)(x + 1)), one per generator — a legitimate ring, but not a Hecke algebra, and every theorem stated about it is a theorem about that free product.

    HeckeAlgebra R q M below imposes both families, so it is the Iwahori–Hecke algebra of the Coxeter matrix M in the Iwahori normalisation

    (T_i − q)(T_i + 1) = 0, T_i T_j T_i ⋯ = T_j T_i T_j ⋯ (M i j factors each side).

    Design notes #

    • The relation is an inductive, not a Set of ideal generators. RingQuot quotients by the ring congruence generated by an arbitrary relation, so the two families can be listed as two constructors and no ideal-membership reasoning is needed anywhere downstream.
    • M is a bare B → B → ℕ, not a CoxeterMatrix B. Nothing in the construction or in the universal property needs symmetry, the diagonal condition, or any other Coxeter axiom; requiring CoxeterMatrix would buy nothing and would couple this file to an API that has drifted across Mathlib refactors. A caller holding a CoxeterMatrix B passes its coercion.
    • Base ring is a generic [CommRing R] (§7c). No ordering, no ℝ, no archimedean construct appears; q is a formal parameter.

            The generators are invertible #

            This is what makes the Hecke algebra a quotient of the braid group algebra rather than merely of the free algebra, which is how AGENTS.md §7a frames it: σ_i is a positive crossing and σ_i⁻¹ a negative one, and the skein relation comes from multiplying the quadratic relation through by σ_i⁻¹. That step needs the inverse to exist, and nothing above supplied it.

            source
            theorem QOU.MathlibExt.IwahoriHecke.T_mul_sub {R : Type v} [CommRing R] {q : R} {B : Type u} {M : B → B → ℕ} (i : B) :

            The quadratic relation, rearranged: T_i (T_i − (q−1)) = q.

            This is the whole content of invertibility — over any ring in which q is a unit it exhibits q⁻¹(T_i − (q−1)) as an inverse. The only step beyond expanding is that algebraMap is central.

              Non-vacuity #

              A quotient can collapse. HeckeAlgebra R q M is built by imposing relations on a free algebra, and nothing so far rules out those relations forcing 0 = 1 — in which case every theorem above would be true and empty. This section rules it out.

              The witness is the index representation T_i ↦ q, the one-dimensional representation sending every generator to the parameter. It needs M symmetric, which every Coxeter matrix is (and CoxeterMatrix carries as a field), but the construction above never required it, so it is taken as a hypothesis here rather than globally.
