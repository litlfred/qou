    The skein relation, derived from the Hecke quadratic relation #

    Mathlib has neither an Iwahori–Hecke algebra nor a skein relation: a case-insensitive word search over the vendored tree (leanprover/lean4:v4.24.0, Mathlib commit f897ebcf72cd16f89ab4577d0c826cd14afaafc7) returns 0 hits for skein, Temperley, Kauffman, Jones polynomial and Ocneanu, and exactly 1 for Hecke — a paper title in the NumberTheory/FLT/Basic bibliography comment. CoxeterMatrix and CoxeterSystem exist; no q-deformation of them does.

    This file supplies the purely algebraic half of the skein calculus, at the level of a single ring element. Nothing here is diagrammatic and nothing here is topological.

    The setting #

    R is any commutative ring, A any (possibly noncommutative) R-algebra, q qi : R a pair of scalars, and T : A an element satisfying the Hecke quadratic relation in this repository's symmetric normalisation (AGENTS.md §7a):

    T * T = (q - qi) * T + 1 (IsHeckeGenerator)

    Where the eigenvalue factorisation is used, q and qi are additionally required to be mutually inverse (q * qi = 1), so that qi is a legitimate stand-in for q⁻¹. Carrying qi as a separate scalar with an explicit hypothesis, rather than writing q⁻¹, is what keeps the base ring a bare CommRing: no Field, no Inv, no ordering, no archimedean structure appears anywhere in this file (AGENTS.md §7c).

    What is a THEOREM here #

    Everything below is proved; there is no sorry and no new axiom.

    • mul_negCrossing, negCrossing_mul — T is invertible, with the explicit two-sided inverse T - (q - qi). Only the quadratic relation is used; q need not be a unit for this.
    • isUnit_of_isHeckeGenerator, heckeUnit — the resulting unit of A.
    • sub_inv_eq, sub_inv_eq_smul_one — the skein relation. For any right inverse S of T, T - S = (q - qi) · 1. This is L₊ - L₋ = (q - q⁻¹) L₀ with L₊ = T, L₋ = T⁻¹, L₀ = 1. The content beyond mul_negCrossing is that a right inverse of T is forced to be T - (q - qi), so the relation does not depend on which inverse one names.
    • isHeckeGenerator_of_sub_inv, isHeckeGenerator_iff_sub_inv — the converse, and hence the equivalence. For an element that has a right inverse S, the skein relation T - S = (q - qi) implies the quadratic back again, so the two are equivalent. This is the precise sense in which "the skein relation is the Hecke relation"; note the standing hypothesis T * S = 1, without which the statement is not even well posed.
    • isHeckeGenerator_iff_factored — the eigenvalue factorisation, as an equivalence: given q * qi = 1, T * T = (q - qi) T + 1 ↔ (T - q)(T + qi) = 0. Both directions. This is what licenses the reading "T has eigenvalues q and -qi", and it is the step that turns the Hecke relation into the skein relation.
    • factored_swap — the factors commute past each other: (T + qi)(T - q) = 0 as well.
    • isHeckeGenerator_mirror — the mirror involution. (q - qi) - T, which is -T⁻¹, is again a Hecke generator with the same parameters. This is the algebraic shadow of reflecting a crossing: T and -T⁻¹ have the same eigenvalue pair {q, -qi}.

    What is a HYPOTHESIS or a DEFINITION here #

    • IsHeckeGenerator is a definition — the quadratic relation, named. No claim is made that any particular algebra of interest contains such an element; §Non-vacuity below exhibits some that do.
    • The knot-theoretic reading is an interpretation, not a proved correspondence. Calling T a positive crossing L₊, T - (q - qi) a negative crossing L₋, and 1 a smoothing L₀ is the standard dictionary (AGENTS.md §7a; Jones, Kassel–Turaev), and it is not formalised anywhere in this repository. There is no link diagram, no Reidemeister move and no braid closure in this file, so nothing here proves that these three elements are the three resolutions of a crossing in a diagram. The theorems are theorems about a ring element; the topology is a reading imposed on them from outside.

    Non-vacuity #

    A spec nothing satisfies proves nothing, so three witnesses are exhibited, in increasing strength:

    • isHeckeGenerator_left, isHeckeGenerator_right — the two eigenvalue scalars q and -qi, viewed in R itself. These are the one-dimensional representations.
    • isHeckeGenerator_witness2 — a non-scalar witness !![q, 1; 0, -qi] in 2 × 2 matrices over any R with q * qi = 1, together with witness2_ne_algebraMap: it is not in the image of algebraMap, so the theorems above are not secretly statements about scalars.
    • exists_isHeckeGenerator_ne_algebraMap — the same at the fully concrete parameters q = 2, qi = 1/2 over ℚ, where q ≠ -qi so the eigenvalue factorisation is a genuine factorisation into distinct linear factors.

    Relation to the rest of this repository #

    The invertibility half of this file exists elsewhere in QOU in four non-interchangeable forms, none of which subsumes this one: QOU.QBeta.JonesNormalisation.sigma_inv (needs Field R, and imports the Temperley–Lieb tower), QOU.Hecke.IwahoriHecke.σ_mul_σInv and QOU.SchurWeyl.HeckeAlgebra.σ_mul_σInv (statements about the generators of two particular RingQuot presentations, not about an arbitrary element), QOU.BraidsAndKnots.sigma_mul_sub_h (one side only, and with σ a scalar in a CommRing), and QOU.MathlibExt.OcneanuTrace.gen_inv_eq_of_quadratic (one side only, inside a trace structure).

    To be precise about what is not new: sigma_inv is already element-level and already two-sided, so the invertibility statement as such is not this file's contribution. What is new is (i) the base ring — carrying qi as a separate scalar with q * qi = 1 supplied only where needed drops Field R to a bare CommRing R, and drops the Temperley–Lieb import to nothing outside Mathlib; (ii) the factorisation stated as an iff rather than as a one-way consequence; (iii) the skein relation stated against an arbitrary inverse, together with its converse, so that the quadratic and the skein relation are proved equivalent; and (iv) the mirror involution. Imports are Mathlib-only.

    The scalar predicate QOU.BraidsAndKnots.IsHeckeGen (σ h : R) is the same quadratic with the parameter pair already contracted to h = q - qi and the element required to be a scalar; IsHeckeGenerator below is its algebra-element refinement, and isHeckeGenerator_left/isHeckeGenerator_right generalise that file's isHeckeGen_q from Field R with q ≠ 0 to CommRing R with q * qi = 1.

    The Hecke quadratic relation #

    source
    def QOU.MathlibExt.SkeinRelation.IsHeckeGenerator {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (q qi : R) (T : A) :
    Prop

    T satisfies the Hecke quadratic relation with parameters q, qi:

    T² = (q - qi) · T + 1.

    This is the symmetric (skein) normalisation of AGENTS.md §7a, in which qi plays the role of q⁻¹; the Iwahori normalisation (T - q)(T + 1) = 0 is a different, rescaled convention and is not what this predicate says.

    The parameter qi is deliberately unconstrained here — q * qi = 1 is required only where the eigenvalue factorisation is used, and stating the predicate without it keeps the invertibility results below free of that hypothesis.

      Invertibility, and the explicit inverse #

      q is not assumed to be a unit in this section. In the symmetric normalisation the constant term of the quadratic is already 1, so the inverse falls out with no division at all — which is exactly why this normalisation is the one the skein relation is stated in.

          From here on q and qi are mutually inverse, so that qi really is q⁻¹.

          source
          theorem QOU.MathlibExt.SkeinRelation.isHeckeGenerator_iff_factored {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] {q qi : R} (hqi : q * qi = 1) (T : A) :
          IsHeckeGenerator q qi T ↔ (T - (algebraMap R A) q) * (T + (algebraMap R A) qi) = 0

          The eigenvalue factorisation, as an equivalence.

          For mutually inverse scalars q, qi, the Hecke quadratic relation T² = (q - qi)T + 1 holds iff (T - q)(T + qi) = 0.

          The right-hand form is what licenses the phrase "T has eigenvalues q and -qi", and multiplying it through by T⁻¹ is the classical derivation of the skein relation. Stating it as an iff — rather than as a one-way consequence of the quadratic — records that the quadratic and the factored form carry the same information.

          This is an equivalence between the quadratic and the factored form; it is isHeckeGenerator_iff_sub_inv that states the equivalence between the quadratic and the skein relation itself.

          The mirror involution #

          source
          theorem QOU.MathlibExt.SkeinRelation.isHeckeGenerator_mirror {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] {q qi : R} {T : A} (hT : IsHeckeGenerator q qi T) :
          IsHeckeGenerator q qi ((algebraMap R A) (q - qi) - T)

          -T⁻¹ is again a Hecke generator, with the same parameters.

          Writing h = q - qi, the element h - T equals -(T - h) = -T⁻¹ (mirror_eq_neg_negCrossing), and it satisfies the same quadratic relation that T does. The eigenvalue reading explains why: T has eigenvalues {q, -qi}, so T⁻¹ has {qi, -q} and -T⁻¹ has {-qi, q} — the same pair back again.

          Two honesty notes on that paragraph. The eigenvalue reading is a heuristic and it silently assumes q * qi = 1 (it inverts q and -qi); the theorem does not, and carries no such hypothesis — the proof is the direct expansion (h - T)² = h² - 2hT + T² = h² - hT + 1 = h(h - T) + 1, valid for any qi. And "mirror image of a crossing" is an interpretation, not a formalised correspondence; the statement is about ring elements.
