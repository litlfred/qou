    Liouville for doubly-periodic entire functions #

    A holomorphic function on ℂ that is periodic under two ℝ-linearly independent complex periods is constant — the classical "an elliptic function with no poles is constant". This is the analytic content the Faddeev–Volkov pentagon rigidity buys (QOU.QBeta.CyclicDilogPentagon): the ratio of two FaddeevPhi solutions is invariant under both the compact ib-shift and the modular-dual i/b-shift, so where it is entire it is doubly-periodic, hence constant. That is exactly the step the L4 file carried as the open hypothesis PentagonRigidity.uniqueUpToScalar (the "doubly-periodic ⇒ constant" Liouville input said to be absent from Mathlib).

    This file supplies that step from Mathlib primitives, closing the analytic-Liouville half of the open input honestly:

    • periodic_zsmul — periodicity under a period propagates to its integer multiples;
    • const_of_doublyPeriodic — reducing each ℝ-coordinate b.repr z i modulo 1 (Int.fract) lands every z in the bounded half-open parallelepiped ∑ᵢ [0,1)·bᵢ up to an integer-lattice translation that f ignores; that parallelepiped sits in a closed ball, compact because ℂ is a ProperSpace, so the range of f is bounded and Liouville (Differentiable.exists_const_forall_eq_of_bounded) forces constancy. No measure theory / ZLattice machinery — only Basis.repr, Int.fract, and a closed ball.

    What this does not do: it does not prove the ratio is entire (the zeros of the two Φ_b solutions coincide) or that the two periods are ℝ-independent at the substrate b — those remain the genuine analytic-Φ_b inputs. It converts the bespoke uniqueUpToScalar hypothesis into two smaller, standard facts (entire ratio + independent periods), with the Liouville-elliptic step now a proved lemma.

    f (z + a • c) = f z

    Periodicity under a single period propagates to its integer multiples. If f (z + c) = f z for all z, then f (z + a • c) = f z for every a : ℤ.

    theorem QOU.MathlibExt.DoublyPeriodicLiouville.const_of_doublyPeriodic {f : ℂ → ℂ} {b : Module.Basis (Fin 2) ℝ ℂ} (hf : Differentiable ℂ f) (h : ∀ (i : Fin 2) (z : ℂ), f (z + b i) = f z) :
    ∃ (c : ℂ), ∀ (z : ℂ), f z = c

    Liouville for doubly-periodic entire functions. A differentiable f : ℂ → ℂ periodic under both vectors of an ℝ-basis b of ℂ is constant. Reducing the two ℝ-coordinates of z modulo 1 lands z, up to a lattice translation f ignores, in the closed ball of radius ‖b 0‖ + ‖b 1‖; that ball is compact (ℂ proper), so range f is bounded and Liouville forces a constant.

    theorem QOU.MathlibExt.DoublyPeriodicLiouville.ratio_const_of_doublyPeriodic {Φ Ψ : ℂ → ℂ} {b : Module.Basis (Fin 2) ℝ ℂ} (hΦ : Differentiable ℂ Φ) (hΨ : Differentiable ℂ Ψ) (hΦ0 : ∀ (z : ℂ), Φ z ≠ 0) (hper : ∀ (i : Fin 2) (z : ℂ), Ψ (z + b i) / Φ (z + b i) = Ψ z / Φ z) :
    ∃ (c : ℂ), ∀ (z : ℂ), Ψ z = c * Φ z

    Rigidity bridge — the reduced form of PentagonRigidity.uniqueUpToScalar. If two entire functions Φ, Ψ with Φ nowhere zero have a ratio that is genuinely periodic (prefactors cancelled) under both vectors of an ℝ-basis of ℂ, then Ψ = c · Φ for a constant c. This is exactly the Faddeev–Volkov rigidity content the L4 pentagon file (QOU.QBeta.CyclicDilogPentagon) carried as an open hypothesis: the two remaining inputs are now explicit and smaller — Ψ/Φ is entire (the zeros coincide) and the two quasi-period ratios cancel to genuine periods with independent periods (b a basis) — while the doubly-periodic ⇒ constant Liouville step is proved above.

    theorem QOU.MathlibExt.DoublyPeriodicLiouville.ratio_const_of_entire_ratio {Φ Ψ : ℂ → ℂ} {b : Module.Basis (Fin 2) ℝ ℂ} (hr : Differentiable ℂ fun (z : ℂ) => Ψ z / Φ z) (hper : ∀ (i : Fin 2) (z : ℂ), Ψ (z + b i) / Φ (z + b i) = Ψ z / Φ z) :
    ∃ (c : ℂ), ∀ (z : ℂ), Ψ z / Φ z = c

    Rigidity bridge, divisor form — the shape the Faddeev application actually has. ratio_const_of_doublyPeriodic above requires Φ to be nowhere zero. Faddeev's quantum dilogarithm Φ_b does not satisfy that: it is meromorphic with a genuine zero/pole lattice (poles at c_b + i(mb + nb⁻¹), zeros at the reflected lattice), so the bridge as stated does not apply to it directly — a hypothesis/application mismatch worth naming rather than working around.

    What the open input hratio (bean qou-cons) actually delivers is weaker and better matched: two FaddeevPhi solutions share their divisor, so the ratio is entire even though neither factor is zero-free. This variant takes exactly that as its hypothesis, and is therefore the form a discharged hratio plugs into. Together with hibinv (bean qou-rp5f, supplying hper off the dual pole lattice) it yields constancy of the ratio.

    Strictly weaker than ratio_const_of_doublyPeriodic: it assumes nothing about the zeros of Φ, and correspondingly concludes about the ratio rather than about Ψ pointwise (see eq_const_mul_of_entire_ratio for the pointwise form away from the divisor).

    theorem QOU.MathlibExt.DoublyPeriodicLiouville.eq_const_mul_of_entire_ratio {Φ Ψ : ℂ → ℂ} {b : Module.Basis (Fin 2) ℝ ℂ} (hr : Differentiable ℂ fun (z : ℂ) => Ψ z / Φ z) (hper : ∀ (i : Fin 2) (z : ℂ), Ψ (z + b i) / Φ (z + b i) = Ψ z / Φ z) :
    ∃ (c : ℂ), ∀ (z : ℂ), Φ z ≠ 0 → Ψ z = c * Φ z

    Pointwise form of ratio_const_of_entire_ratio, valid off the divisor: wherever Φ is nonzero, Ψ = c · Φ with the same constant. This is how the rigidity conclusion is consumed in practice — the identity is asserted on the complement of the pole/zero lattice, not on all of ℂ.
