    The α_EM form ladder: its integers are convention-free, and its residual is anchor-dominated #

    Bean qou-4jut follow-on, under epic qou-qia8. Formalises the two structural facts behind computations/alpha-em-form-ladder.witness.json:

    1/α  =  q[9]_q[10]_q  +  2g/(4π(g−1))  +  αH(1 − h²α)  +  Δ₂,   g = 4
      H = [2]_q/(8π),   h = q − q⁻¹ (Hecke structure constant),
      Δ₂ = uncomputed archimedean two-loop (weight-3; NOT the −h²Hα² above)

    with two recorded fixed points (proton- and muon-anchored). The recorded decimals live in the companion FormLadderAnchorDominanceChecks.lean, not here (bean qou-08zf, 2026-09-03): they are witness output and CODATA, i.e. empirical inputs, and the owner's standing preference is that formal mathematics carry none. This file is the mathematics; the companion is recorded-witness arithmetic that instantiates it.

    Part 1 — the ladder's integers need no minimal-strand convention #

    The witness calls its integers "structurally derived (Bring genus 4; crossing numbers of T(2,9), T(3,5))". What is proved here is the property that makes that phrase safe: the crossing number of a torus knot, c(T(p,q)) = min (p(q−1)) (q(p−1)), is symmetric under p ↔ q (crossingNumberTorus_symm), so it assigns one value to T(p,q) ≅ T(q,p) with no convention required.

    This is exactly what the writhe rule fails to do. w(T(m,p)) = (m−1)p is not symmetric — writheTorus_not_symm exhibits w(T(2,3)) = 3 ≠ 4 = w(T(3,2)) — which is why folio/quantum-observable-universe/mass-theory/torus-knot-delta-q-writhe.md had to be given the minimal-strand guard m ≤ p (Morton–Williams braid index) earlier in this same PR, and why computations/rosso_jones_three_strand_delta_q.py now raises on a swapped pair. The α_EM ladder inherits no such hazard: crossing_number_needs_no_convention states the contrast as a single proposition.

    This does not make the ladder correct — see the honest scope below. It removes one specific failure mode (a presentation-dependent integer) that the neighbouring δ_q rule genuinely had.

    Part 2 — the residual is anchor-dominated, and no anchor-blind term fixes it #

    • anchor_gap_eq_prediction_gap — the difference of the two anchors' residuals equals the difference of their raw predictions: the reference value cancels. So "which anchor" is independent of the CODATA vintage. Not idle: the witness scores against 137.035999084 while alpha-k-per-force-assembly.witness.json carries 137.035999177, and this says the anchor comparison survives that discrepancy untouched.
    • no_anchor_blind_affine_correction_closes_gap — appending any further term that does not itself depend on the anchor (any affine x ↦ s·x + c, s ≠ 0) leaves the two anchors distinct. So the residual spread cannot be absorbed by carrying the α-expansion further — not by the derived αH(1 − h²α) already in the form, and not by the uncomputed Δ₂, since neither depends on the anchor except through q itself. Only an anchor-dependent ingredient can move it.
    • degenerate_correction_is_vacuous — the one escape, s = 0, does equalise them, by discarding the prediction entirely. Named so the exclusion is not over-claimed.
    • The instantiation on the recorded values — predictions_differ, anchor_gap_dominates_proton_residual (gap more than 40× the proton-anchored residual), leading_term_residual_dwarfs_full_form (the leading term alone misses by more than 5·10⁵× the full form's proton-anchored residual; quoting q[9]_q[10]_q's residual as the framework's α_EM accuracy is a category error of about six orders of magnitude, and this file exists partly because that error was made in session and had to be retracted) — is in QOU.AlphaEM.FormLadder.Checks (FormLadderAnchorDominanceChecks.lean).

    Honest scope #

    Scope-(a) throughout, and this file proves nothing about α_EM itself. The witness's own caveats stand and are not discharged here: the derivation carries three unproved classes; the result is anchor-dependent (which is Part 2's subject, not its refutation); and no coefficient is fitted. What is proved is (i) an arithmetic property of the torus crossing number, and (ii) the structural consequence for any two anchor predictions — stated over a generic commutative ring / integral domain, per §7c; the recorded decimals enter only in the companion, as explicit defs of measured data, never as derived quantities.

    Part 1 is generic and convention-free (ℕ, min). The genus term is stated division-free over an arbitrary commutative ring — no π, no Real, and no characteristic hypothesis, per §7c and the standing "rewrite so there is no /2" steer. Part 2 mentions no ℝ at all.

    Tower status (owner ruling 2026-09-03): ORDER-ZERO-ONLY. The ladder is the leading term plus a one-loop self-coupling on the single force-carrier pair; the full H_n(q) tower is not used, and nothing here claims otherwise.

    Part 0 — the genus term, generically #

    source
    def QOU.AlphaEM.FormLadder.IsGenusTerm {R : Type u_1} [CommRing R] (g p T : R) :
    Prop

    T is the genus term at genus g (with p standing for π) exactly when it satisfies the ladder's defining relation, stated cleared of denominators: 4·p·(g−1)·T = 2·g.

    Writing it this way — rather than as T = 2g/(4p(g−1)) — costs nothing and buys everything: it needs no p ≠ 0, no g − 1 ≠ 0, and no characteristic hypothesis, so it holds over an arbitrary commutative ring. A quotient form would force 4 ≠ 0, i.e. would silently exclude characteristic 2.

          Part 2 — anchor dominance, generically #

          No recorded number appears here. P and M stand for the proton- and muon-anchored predictions, C for whatever reference value they are scored against; the three statements hold over any commutative ring (the third needs cancellation, so an integral domain).

          source
          theorem QOU.AlphaEM.FormLadder.anchor_gap_eq_prediction_gap {R : Type u_1} [CommRing R] (P M C : R) :
          M - C - (P - C) = M - P

          The anchor gap does not depend on the reference value.

          Subtracting the same reference from both predictions cancels: the difference of the residuals is the difference of the raw predictions. So the comparison between the two anchors is untouched by which CODATA vintage is used — relevant because the ladder witness scores against one CODATA vintage while alpha-k-per-force-assembly.witness.json carries another.

          theorem QOU.AlphaEM.FormLadder.no_anchor_blind_affine_correction_closes_gap {R : Type u_1} [CommRing R] [IsDomain R] (P M s c : R) (hne : P ≠ M) (hs : s ≠ 0) :
          s * P + c ≠ s * M + c

          No anchor-blind correction closes the gap.

          A further term appended to the ladder that does not itself depend on the anchor acts as one affine map x ↦ s·x + c on both predictions. For s ≠ 0 the two stay distinct. So the residual spread cannot be removed by carrying the α-expansion further, nor by any other anchor-independent ingredient; only an anchor-dependent one can move it. Cancellation of s needs an integral domain, which is carried as an instance rather than hidden in ℝ.
