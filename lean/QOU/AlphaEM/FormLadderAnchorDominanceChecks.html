    α_EM form ladder — recorded-witness arithmetic (NOT mathematics) #

    Companion to QOU.AlphaEM.FormLadderAnchorDominance. Everything in this file is a recorded decimal — witness output or a CODATA reference — and a norm_num check on it. Nothing here is derived; the mathematics (Part 0–2 of the companion) is stated there over generic rings with no empirical input, and this file only instantiates it on the numbers computations/alpha-em-form-ladder.witness.json recorded.

    Split out on 2026-09-03 (bean qou-08zf) so that the formal statements carry no empirical literal (owner preference, stricter than AGENTS.md §7c's "CODATA → ℝ" row). The names are unchanged from their previous location in the companion, under the Checks namespace.

    scripts/check-sidecars.sh flags this file as "ℝ in type but no archimedean construct". That is expected and not a defect: every declaration here is a recorded decimal, and a decimal literal is the §7c CODATA/experimental row — ℝ is the correct type for it, and generalising to {R} would only hide the fact that these are measured numbers.
