    1. Bar-parity selection (weak / Q_β sector) #

    source
    structure QOU.SelectionRules.BarInvolution (R : Type u_1) [CommRing R] :
    Type u_1

    A bar-involution: an additive, negation-compatible self-map of the ring (the arithmetic shadow of q ↦ q⁻¹ on the Laurent ring). Only additivity is needed for the eigenspace-orthogonality argument, so we ask for no more.

    • bar : R → R
    • bar_add (a b : R) : self.bar (a + b) = self.bar a + self.bar b
    • bar_neg (a : R) : self.bar (-a) = -self.bar a

      Applied: the bar-odd c₃ carrier ≠ the bar-even −Vol(4₁). This is the scope-(b) structural reason c₃ = −Vol(4₁) fails — wrong bar-parity eigenspace, not merely a wrong number.

        theorem QOU.SelectionRules.nonneg_sum_ne_neg_target {R : Type u_2} [CommRing R] [PartialOrder R] [IsOrderedRing R] {ι : Type u_3} (s : Finset ι) (n x : ι → R) (hn : ∀ i ∈ s, 0 ≤ n i) (hx : ∀ i ∈ s, 0 ≤ x i) (t : R) (ht : t < 0) :
        ∑ i ∈ s, n i * x i ≠ t

        Positivity exclusion (the common cause of Δ_λ rows B and E). A non-negative linear combination of non-negative operators is non-negative, hence cannot equal a strictly negative target.

        Applied to Δ_λ: on any partition where the mixed-sign target Δ_λ < 0, every positive ansatz — Frobenius co-Casimir (1/dim_q > 0) and the crystal/KL route (Σ_w n^w_λ · X_w, n^w_λ ≥ 0) — is excluded. One machine-checked selection rule unifies the co-Casimir wrong-sign refutation and the KL-positivity prune.
