    QOU.AppendixSurreals.BlowupCalculus #

    Canonical declaration for content block at quantum-observable-universe/appendix-surreals/surreal-blowup-calculus.ts.

    Formalises the manuscript blow-up calculus: write a divergent expression X(Λ) with Λ → ω a named infinite surreal, subtract a counterterm C(Λ) so that X(ω) − C(ω) is finite, and take the standard part to obtain the renormalised real X_ren := st(X(ω) − C(ω)) ∈ ℝ.

    Infrastructure — now with a real model (bean zkst) #

    The apparatus is the BlowupField typeclass: an ordered field with a designated positive infinite element ω, its infinitesimal ε = ω⁻¹, and a standard-part retraction st onto ℝ.

    De-axiomatisation (2026-07-06). This is no longer a free axiom: Mathlib's hyperreals ℝ* are a genuine BlowupField instance (instBlowupFieldHyperreal below), so the whole calculus is realisable, not merely conditional. Building this model also corrected a latent over-idealisation: the original st_add was stated unconditionally, but no real model satisfies that — the standard part is additive only on finite elements (st(ω + 1) = 0 ≠ st ω + st 1 = 1). st_add is now conditioned on an IsFinite predicate, matching Hyperreal.st_add; the renormalised value st(X(ω) − C(ω)) is meaningful exactly because the counterterm makes X(ω) − C(ω) finite.

    class QOU.AppendixSurreals.BlowupField (K : Type u_1) [Field K] [LinearOrder K] [IsStrictOrderedRing K] :
    Type u_1

    Blow-up infrastructure. An ordered field K with a named positive infinite element omega, a finiteness predicate IsFinite, and a standard-part map st : K → ℝ that is additive on finite elements, fixes the natural-number constants, and kills the infinitesimal ε = omega⁻¹.

    • omega : K

      The named infinite surreal ω.

    • omega_infinite (n : ℕ) : ↑n < omega

      ω exceeds every natural number — it is infinite.

    • st : K → ℝ

      The standard-part retraction onto ℝ.

    • IsFinite : K → Prop

      Finiteness predicate (an element with a well-defined standard part).

    • st_add (x y : K) : IsFinite x → IsFinite y → st (x + y) = st x + st y

      st is additive on finite elements (it is not globally additive; no real model of a non-archimedean field is).

    • st_natCast (n : ℕ) : st ↑n = ↑n

      st fixes the natural-number constants.

    • natCast_isFinite (n : ℕ) : IsFinite ↑n

      Natural-number constants are finite.

    • st_omega_inv : st omega⁻¹ = 0

      The infinitesimal ε = ω⁻¹ has standard part 0.

    • omega_inv_isFinite : IsFinite omega⁻¹

      The infinitesimal ε = ω⁻¹ is finite.

          De-axiomatisation (bean zkst): the hyperreals ℝ* are a genuine BlowupField. Every field is a Mathlib theorem — ω = Hyperreal.omega is infinite (infinitePos_omega), st = Hyperreal.st is additive on the finite (¬ Infinite) elements (Hyperreal.st_add), fixes real constants (st_id_real), and kills ε = ω⁻¹ (infinitesimal_epsilon). So the blow-up calculus is realisable, not merely axiomatic.
