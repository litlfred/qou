    QOU.AppendixSurreals.LocalInfinitesimalField — conjecture carrier #

    §3b-cond class axiomatisation for content block conj:local-infinitesimal-field: Substrate parameter as a local infinitesimal field ε(x).

    Primary conjecture carrier with no instance — the honest open state per AGENTS.md §3b-tax.

    What changed (bean qou-ffwk) #

    The previous field schema was a scalar plus a field asserting that it vanishes, inhabited by ⟨0, rfl⟩. The class chose its own witness, so it asserted nothing and a downstream [LocalInfinitesimalField] hypothesis was not a meaningful conditional.

    Why the scheme and sheaf are not modelled #

    The block sets the conjecture up over a scheme X — ε ∈ Γ(X, 𝔪_X), a section of the sheaf of infinitesimals, with X a functor CRing → Set evaluated at the valuation ring of finite surreals. Mathlib's AlgebraicGeometry.Scheme and Topology.Sheaves are both available in this tree, so that framing could be written down.

    It is deliberately not, because none of the three claims uses it. Read them back: ε(x) differs from ε(y) somewhere; st(ε(x)) = 0 everywhere; the leading coefficient is globally constant. Every one is an extensional statement about the family x ↦ ε(x). Restricting/gluing, the structure sheaf, and the X(𝒪) ↠ X(ℝ) standard-part map are all setting — they explain where the family comes from and why it is interesting, and the conjecture would be neither stronger nor weaker if X were a bare type.

    Wrapping the family in a Scheme would therefore assert structure the claims never consume, which is the same defect in the opposite direction from the schema this file used to carry: a placeholder asserts too little, decoration asserts too much. X stays an abstract index type, and the sheaf framing lives in this docstring where a reader can find it.

    If a later result actually needs locality — gluing local εs, or a stalkwise argument — that is the point to introduce the sheaf, and the class statement below will still be what it restricts to.

    What is encoded #

    • Part 1 — local variation. "ε(x) may differ from ε(y) for distinct x, y." Encoded as genuine non-constancy. This is the whole point of the conjecture: a global ε is exactly what the appendix already has, so a carrier that permitted a constant family would assert nothing new.
    • Part 2 — standard-part global constant. "st(ε(x)) = 0 for all x, so the classical substrate is q = 1 everywhere." Encoded as infinitesimality, which is the block's own framing (ε is a section of the sheaf of infinitesimals); standardPart_eq_zero below derives the st form from it using the corpus's own StandardPart API.
    • Part 3 — birthday-uniform at archimedean scale. "The leading surreal coefficient of ε(x) is globally constant and equals q₀ − 1." Encoded against a caller-supplied leadingCoeff, for the reason below.

    leadingCoeff is the coefficient of ω⁻¹ in Conway normal form. It does not exist in this tree, and it is not OmegaOrder.Ow, which is the leading exponent. Rather than invent it, it enters as a parameter — the same choice as the archimedean_agreement pipelines and DiophantineBirthday's trajectory. See Asymptotics.lean for why the Conway-normal-form machinery is not available from Mathlib.

    q₀ is a parameter too, not a literal. Writing 0.11 into a carrier would fix a substrate pin inside a conjecture and require re-editing whenever the pin moves.

    Base ring (§7c) #

    K is a generic [SurrealField K]. ℝ enters only through standardPart and leadingCoeff's codomain — the archimedean shadow the conjecture is about — and through SurrealField's own ofReal. No numerical substrate value appears.

    class QOU.AppendixSurreals.LocalInfinitesimalField (X : Type v) (K : Type u) [SurrealField K] (ε : X → K) (leadingCoeff : K → ℝ) (q₀ : ℝ) :
    Prop

    The substrate parameter is a local infinitesimal field.

    The conjecture of conj:local-infinitesimal-field: q(x) = 1 + ε(x) fluctuates from point to point, every fluctuation is infinitesimal, and the leading surreal coefficient is nevertheless globally constant.

    Parameters are the caller's data:

    • X — the index type of points (the block's scheme, taken extensionally; see the header);
    • ε x — the local infinitesimal at x;
    • leadingCoeff — the ω⁻¹ coefficient in Conway normal form, which this tree does not construct;
    • q₀ — the archimedean substrate value, a parameter rather than a literal.

    An instance is the conjecture, for that data. None is provided.

    • infinitesimal (x : X) : SurrealField.IsInfinitesimal (ε x)

      Part 2. Every local value is infinitesimal, so the classical substrate is q = 1 at every point.

    • local_variation : ∃ (x : X) (y : X), ε x ≠ ε y

      Part 1 — local variation. The family is genuinely non-constant. Without this the conjecture collapses to the global ε the appendix already has, so a carrier permitting a constant family would assert nothing new.

    • leadingCoeff_const (x : X) : leadingCoeff (ε x) = q₀ - 1

      Part 3. The leading ω⁻¹ coefficient is globally constant and equals the archimedean substrate deviation.

      Refuted over a one-point index — the property the old schema lacked entirely.

      local_variation cannot hold when there is nowhere to vary, so the conjecture is genuinely falsifiable by the shape of X alone. Under the previous schema ⟨0, rfl⟩ closed the class for every choice of everything, including a one-point scheme, so "the substrate fluctuates" had nothing to fail against.

      This is also the precise sense in which the conjecture says more than the appendix's existing global ε.
