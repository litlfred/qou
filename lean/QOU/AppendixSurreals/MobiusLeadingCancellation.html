    def QOU.AppendixSurreals.MobiusLeadingCancellation.IndependentOfFinite {R : Type u_1} [Ring R] {M : Type u_2} [AddCommGroup M] [Module R M] (F : Submodule R M) (Ω : M) :
    Prop

    The infinite unit Ω is independent of the finite part F: no nonzero scalar multiple of Ω is finite. In the surreal application Ω plays ω^{+1} and F the finite (ord_ω ≤ 0) elements.

      Leading-coefficient cancellation. For ord ≤ 1 elements a • Ω + f and b • Ω + g (with f, g finite), the difference is finite iff the leading coefficients agree: [Ω](I₁) = [Ω](I₂). This is the algebraic content of the Möbius surreal renormalization's finiteness bound.
