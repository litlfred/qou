    QOU.AppendixSurreals.SurrealLimitTransfer — limits as surreal equalities #

    Conjecture class packaging the analytic → surreal transfer: an ω-evaluation evalOmega assigning to every real sequence a surreal value, algebra-compatible, order-compatible on eventual domination, and computing limits through the standard-part map. A convergent limit statement aₙ → L becomes the surreal proximity equality IsClose (evalOmega a) (ofReal L) — equality up to an infinitesimal — and on the nose standardPart (evalOmega a) = L.

    Epistemic status (primary conjecture, class-axiomatised). For the concrete surreals such an evaluation exists model-theoretically (Robinson ultrapower; Berarducci–Mantova germ evaluation at ω), but it is not constructible from the abstract SurrealField interface alone, so it is carried as a content-bearing class with no instance — the honest open state per AGENTS.md §3b-tax. No instance is fabricated.

    The payoff is the two derived theorems (fully proved from the class fields):

    • standardPart_evalOmega_of_tendstoReal — limits are computed by st ∘ evalOmega;
    • tendstoReal_le_of_eventuallyLE — the limit-comparison inequality, derived purely through the surreal order and standardPart_le_of_le.

    The second shows the "inequality → surreal statement → real inequality" round trip promised by the alien-calculus ↔ surreal integration review (2026-07-13): the eventual pointwise inequality is transferred to a single surreal inequality at ω, and the archimedean inequality between the limits is recovered by the (proved) monotonicity of the standard part.

        class QOU.AppendixSurreals.SurrealLimitTransfer (K : Type u) [SurrealField K] :
        Type u

        Conjecture (surreal limit transfer). An ω-evaluation of real sequences into K: constants map to ofReal, algebra is respected pointwise, eventual domination transfers to the surreal order, and a convergent sequence evaluates infinitesimally close to its limit.

        The fields carry the conjecture's hypotheses (the existence of a structured evaluation); the theorems below derive consequences from them. @conjecture: primary — no other conjecture class is assumed.

        • evalOmega : (ℕ → ℝ) → K

          Evaluation of a real sequence at the surreal ω.

        • evalOmega_const (r : ℝ) : (evalOmega fun (x : ℕ) => r) = SurrealField.ofReal r

          Constant sequences evaluate to the embedded real.

        • evalOmega_add (a b : ℕ → ℝ) : (evalOmega fun (n : ℕ) => a n + b n) = evalOmega a + evalOmega b

          Additivity.

        • evalOmega_mul (a b : ℕ → ℝ) : (evalOmega fun (n : ℕ) => a n * b n) = evalOmega a * evalOmega b

          Multiplicativity.

        • evalOmega_le_of_eventuallyLE (a b : ℕ → ℝ) : EventuallyLE a b → evalOmega a ≤ evalOmega b

          Eventual pointwise domination transfers to the surreal order.

        • evalOmega_isClose_of_tendstoReal (a : ℕ → ℝ) (L : ℝ) : TendstoReal a L → IsClose (evalOmega a) (SurrealField.ofReal L)

          A convergent sequence evaluates infinitesimally close to its limit: the limit statement as a surreal equality-up-to-ε.
