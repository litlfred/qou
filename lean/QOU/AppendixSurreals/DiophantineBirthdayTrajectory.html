    §1 — the criterion is invariant under the trajectory's ambiguity, and still separates #

    Two reals whose sign expansions share a tail differ by a rational. A trajectory criterion must therefore be rational-shift invariant to be well defined; the question is whether that invariance forces the collapse no_birthday_only_separation exhibits for birthdays.

    source
    theorem QOU.AppendixSurreals.liouvilleWith_rat_shift_invariant (p x : ℝ) (r : ℚ) :
    LiouvilleWith p (x + ↑r) ↔ LiouvilleWith p x

    The Liouville exponent is a function of the trajectory tail.

    Changing finitely many signs of a sign expansion shifts the real by a rational, and LiouvilleWith p does not see that shift. So this criterion is well defined on tails — the precondition any trajectory criterion has to meet.

    source
    theorem QOU.AppendixSurreals.liouvilleWith_separates :
    ∃ (x : ℝ) (y : ℝ), LiouvilleWith 2 x ∧ ¬LiouvilleWith 2 y

    And it does not collapse. Unlike birthday ∘ ofReal, which is constant on the irrationals and therefore separates nothing, LiouvilleWith 2 takes both truth values: liouvilleNumber 2 satisfies it and 0 does not.

    This is the exact point where the trajectory version departs from the birthday version. no_birthday_only_separation says every predicate on the birthday agrees on √2 and π; no such collapse is available here, because the criterion is already non-constant.

    §2 — the fast-approximation direction is settled, in Mathlib #

    Liouville x is "approximable to every order p" (forall_liouvilleWith_iff), and Liouville's theorem turns that into transcendence.

    source
    theorem QOU.AppendixSurreals.liouville_trajectory_direction_settled (x : ℝ) (h : ∀ (p : ℝ), LiouvilleWith p x) :
    Transcendental ℤ x

    Liouville's theorem, as the trajectory conjecture's settled direction.

    If a real is approximable to every order — the strongest possible trajectory condition — it is transcendental. Discharged from Mathlib, not assumed.

    This is why labelling conj:diophantine-birthday as wholly open overstates it: one direction of the separation is a theorem in the corpus's own toolchain.

    source

    A concrete witness that the settled direction is not vacuous: liouvilleNumber 2 is approximable to every order, hence transcendental.

    §3 — the shape of what remains #

    Stated as a definition so the open content has a name, not as a class with a stipulated field.     source
    def QOU.AppendixSurreals.SlowApproximationImpliesAlgebraic (p : ℝ) :
    Prop

    The naive converse of liouville_trajectory_direction_settled: that slow rational approximation is enough for algebraicity.

    ⚠ This is FALSE at every p, and is named here only so the conjecture's wording is not mistaken for it. Almost every real is transcendental with approximation exponent exactly 2, so for any p > 2 there are transcendentals satisfying ¬ LiouvilleWith p x — the hypothesis holds and the conclusion fails. It is deliberately not asserted, instanced, or used as a hypothesis anywhere.

    Roth's theorem does not repair this direction, and it is worth being explicit because the conjecture's gloss cites Roth. Roth sharpens the settled direction — algebraic irrationals have exponent exactly 2, hence LiouvilleWith p x with p > 2 already forces x transcendental, improving on Liouville's degree-dependent bound. It says nothing about reals that approximate slowly. So citing Roth buys a better exponent on the direction that is already closed, not progress on the one that is open. (Roth is in any case not in Mathlib; Liouville is.)

    The genuinely open content of conj:diophantine-birthday is therefore neither this nor §2, but the surreal claim: that the sign-expansion trajectory computes the approximation exponent. That is the bridge §3 of the header says is unbuilt.

      ⚠ At p = 1 the statement above is not merely false but VACUOUSLY TRUE, which is the trap worth having in the corpus.

      liouvilleWith_one makes every real approximable to order 1, so the hypothesis ¬ LiouvilleWith 1 x is never satisfied and the implication holds with no content. A reader who instantiated the target at a convenient exponent would obtain a proved Lean theorem whose statement reads like the conjecture and which says nothing — worse than the false version, because it carries a proof.

      This is the same failure mode as birthday_avg_le in Basic.lean (satisfied vacuously under any bounded birthday) and as DiophantineBirthday's former stipulated field (since replaced upstream, bean qou-ffwk): a statement whose form suggests content it does not carry.

      §3b — the bridge, closed: runs give LiouvilleWith #

      GonshorConvergence proves that a run of k ≥ n·t signs in α's own expansion yields an explicit dyadic m/2ⁿ with error at most 1/(2ⁿ)ᵗ. That is the Diophantine shape in this development's vocabulary; the theorem below states it in Mathlib's, which is what makes the lane's claim checkable against the literature rather than only internally consistent.

      ⚠ The hypothesis quantifies over infinitely many n — that is LiouvilleWith's own ∃ᶠ and it cannot be removed. Whether a given α satisfies it is a fact about that α: bounded runs for an algebraic irrational (Thue–Siegel–Roth, §4), unbounded for a Liouville number. So this is a bridge, not a decision procedure.

      source
      theorem QOU.AppendixSurreals.liouvilleWith_of_frequent_runs (α : ℝ) (t : ℕ) (hirr : Irrational α) (hfreq : ∀ (N : ℕ), ∃ (n : ℕ), N ≤ n ∧ Bracketed (expandState α n) ∧ (expandState α n).gap ≤ 1 ∧ ∀ j < n * t, ↑(expandState α (n + j)).value < α) :
      LiouvilleWith (↑t) α

      Infinitely many runs of length n·t ⟹ LiouvilleWith t.

      The implication the trajectory picture always asserted, now proved: run structure in the sign expansion controls the Diophantine exponent.

      Irrational α is required by LiouvilleWith's own x ≠ m / n clause — a rational α eventually is one of its dyadic approximants, and the predicate excludes that case by definition rather than by accident.

      §4 — the remaining input is a THEOREM, not a conjecture #

      What stands between the pieces above and an actual separation is Thue–Siegel–Roth: an algebraic irrational has approximation exponent exactly 2, so it is not approximable to any order p > 2. Roth proved it in 1955 and it earned the Fields Medal.

      ⚠ So it must not be recorded as a conjecture. Doing so would label a settled theorem as open — the same class of error this arc already found three times in conj:diophantine-birthday (an "honest open state" that encoded nothing, a separation that was impossible as stated, and a direction already proved in Mathlib). It is stated here as an explicit hypothesis, and results that need it take it as an argument.

      ⚠ A name collision that will mislead a search. Mathlib does contain Mathlib/Combinatorics/Additive/Corner/Roth.lean, proving "Roth's theorem" — but that is the additive-combinatorics one about 3-term arithmetic progressions, an unrelated result that happens to share the name. Thue–Siegel–Roth appears in Mathlib only as a docstring aside in LiouvilleWith.lean. Checking "is Roth in Mathlib?" by name returns yes and the answer is no.

      Stated as a def of a Prop rather than a class, for the reason given in §3: a Prop taken as a hypothesis cannot be discharged by stipulating a field.

      def QOU.AppendixSurreals.RothExponent :
      Prop

      Thue–Siegel–Roth (Roth 1955): an algebraic irrational is not approximable to any order beyond 2.

      A known theorem, not formalised in Mathlib and not proved here. Anything below that needs it takes it as an explicit hypothesis.
