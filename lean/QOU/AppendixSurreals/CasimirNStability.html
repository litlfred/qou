    QOU.AppendixSurreals.CasimirNStability — n-stability selects the bare count #

    Formalises the selection principle of the N_⊙ construction for conj:casimir-epsilon-vacuum (audit docs/audits/2026-05-31-casimir-n-unknot-construction.md).

    The Casimir prefactor is a single physical number, so the mode-count functional evaluated on the n-component vacuum (n disjoint unknots) must have a cutoff-independent relative substrate deviation — "n-stability". Among the candidate trace functionals:

    • the bare disjoint-component count N(n) = n is q-independent — n-stable and mode-counting (admissible, and by nStable_unique the unique such functional once the single-mode value is fixed to 1 by the Hoefsmit normalisation Geom_ε(1·⊙) = ε/ℏ_q²);
    • the Jones value of the n-unlink δ^{n−1}, with quantum dimension δ = √q + (√q)⁻¹, fails n-stability for every q > 0, q ≠ 1 (its relative deviation grows with the cutoff);
    • the normalised Markov trace ≡ 1 is stable but content-free — it does not count modes.

    The fourth candidate of the audit (the unnormalised Wenzl sum Σ_λ y_λ) requires the partition-weight family and is covered numerically by casimir-n-unknot-construction.witness.json; it diverges in n and is inadmissible for the same reason as the Jones value.

    The file is archimedean (ℝ, Real.sqrt, ordering) per the §7c base-ring convention.

    def QOU.AppendixSurreals.NStable (F : ℕ → ℝ → ℝ) (q : ℝ) :
    Prop

    n-stability (cutoff admissibility) of a vacuum trace functional F : ℕ → ℝ → ℝ (value at mode-cutoff n, substrate parameter q): the relative substrate deviation is independent of the cutoff. In division-free form: F m q · F n 1 = F n q · F m 1 for all cutoffs. A single-number observable cannot depend on where the mode tower is truncated.
