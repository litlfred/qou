    The Skein-Collatz map descends from a QOU substrate parameter (Tier C, C8 brick 2) #

    Brick 1 (SkeinCollatzArith, in QCollatz.lean) showed the Skein-Collatz q-arithmetic is determined by a single ring element q. This file closes brick 2: that q is the QOU substrate parameter — the map's arithmetic is derived from an actual ArchimedeanSubstrateField of the framework, not posited.

    QOU.ArchimedeanSubstrateField M (def:substrate-parameter) furnishes, at each point p ∈ M, the substrate field q(p) : ℝ with q(p) ≥ 1 > 0 and never a root of unity. Feeding q(p) to SkeinCollatzArith realises the whole map arithmetic — [2]_q, [3]_q, the Skein divisibility identity, the contraction gap, the Bézout coprimality and the fundamental {q⁻¹, 1+q⁻¹} cycle — over ℝ, from the substrate value. The substrate's positivity axiom (field_pos) is exactly what makes the fundamental cycle honest (q(p) invertible).

    Honest scope: this links the Skein-Collatz q to the substrate parameter object (where q genuinely lives — QuantumUniverse deliberately has no q field; it "enters via the substrate parameter"). It derives the arithmetic; the dynamical conjecture (reaches_cycle) and its μ remain the open walls. No axiomatisation.

      C8 brick 3 — the arithmetic on the Reeb-bundle Skein module 𝒮(q) ≅ ℤ[q^±1] #

      The Reeb-bundle Skein module (prop:skein-generation) is 𝒮(q) ≅ ℤ[q^{±1}] = LaurentPolynomial ℤ — the ground ring R_q of the formal chain (GroundRingAnnotations) — with q the module indeterminate T. Instantiating SkeinCollatzArith there realises the map's whole q-arithmetic on the actual Skein module, and q = T is a unit (inverse T(-1), qcollatz_laurent_qunit), so the fundamental cycle lives in 𝒮(q).

      Together with brick 2 this exhibits the two levels of q: the fibre q = T in 𝒮(q) = ℤ[q^{±1}] (this brick) and its archimedean evaluation q = q(p) ∈ ℝ at a substrate point (brick 2) — the substrate→fibre picture of AGENTS.md §"Im(q) at fibre vs observable level".
