    Period-4 Skein-Collatz cycle exclusion (Front B, B1) #

    Extends the period-1/2/3 no-cycle results one period further. Each primitive length-4 parity word (EEEO, EEOO, EOEO, EOOO, up to rotation; EEEE is the all-even case handled uniformly elsewhere) pins the cycle value to a non-unit multiple in the Skein ring ℤ[q^{±1}] (whose only units are ±q^n), so there is no nontrivial period-4 cycle — except EOEO, which forces q·P₁ = 1 and hence degenerates to the fundamental 2-cycle {q⁻¹, 1+q⁻¹} (imprimitive), not a new period-4 orbit.

    Convention (as in the period-3 lemmas): a step Pᵢ → Pⱼ satisfies Pⱼ·(q+1) = Pᵢ (even) or Pⱼ·(q+1) = (q²+q+1)·Pᵢ + 1 (odd). All identities are proved by linear_combination over a generic [CommRing R] (§7c).

    q * (q ^ 3 + 4 * q ^ 2 + 5 * q + 3) * P3 = 1

    Period-4, word EEEO. Forces q·(q³+4q²+5q+3)·P₃ = 1; the coefficient is a non-unit in ℤ[q^{±1}], so no EEEO 4-cycle.

    q * (2 * q ^ 2 + 3 * q + 2) * P1 = 2 * q ^ 2 + 3 * q + 2

    Period-4, word EOEO. Forces q·(2q²+3q+2)·P₁ = 2q²+3q+2, i.e. (over an integral domain) q·P₁ = 1: P₁ = q⁻¹, the fundamental 2-cycle traversed twice. So EOEO is imprimitive — not a new period-4 cycle.

    q * (q ^ 5 + 3 * q ^ 4 + 5 * q ^ 3 + 3 * q ^ 2 - 1) * P1 = -(q ^ 4 + 3 * q ^ 3 + 6 * q ^ 2 + 6 * q + 3)

    Period-4, word EOOO. Forces q·(q⁵+3q⁴+5q³+3q²−1)·P₁ = −(q⁴+3q³+6q²+6q+3); non-unit coefficient, so no EOOO 4-cycle. With the other words (and their rotations) this excludes every nontrivial period-4 cycle.
