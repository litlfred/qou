    QOU.AppendixSurreals.Conjectures — Open conjectures as classes #

    Per AGENTS.md §3b ("conjectural propagation"), each conjecture is encoded as a typeclass whose sorry instances represent the conjecture itself. Downstream conditional theorems take such a class as an instance hypothesis.

    Design principle #

    Per Gemini review feedback: every field in every class must be a genuine conjectural statement — not a tautology, not a fact provable in one line from existing surreal-field lemmas, not an instance of a trivially-inhabited type.

    To achieve this, we declare axiomatic placeholders for infrastructure that does not yet exist in mathlib (categorical QOU types, coloured Jones polynomial, Kazhdan–Lusztig cells, hyperbolic volume, nimber arithmetic integrated with Fact (Nat.Prime p)). The conjecture classes then quantify over these placeholders, making the statements genuinely independent of the current small base.

    Placeholder infrastructure #

    The first wave of placeholders is recorded here. Where a faithful mathematical definition is feasible without invoking unformalised mathlib infrastructure, we use a def and the type-level axiom disappears. Where the intended object genuinely depends on unformalised theory (categorical QOUs, surreal exp/log via Berarducci–Mantova transseries, full Kazhdan–Lusztig theory, classical-analytic limits), we keep axiom and document the gap.

    When mathlib's category-theory / surreal-analysis / nimber / knot-invariant infrastructure reaches the relevant maturity, the remaining axioms should be replaced with the actual definitions, at which point the conjecture classes referencing them acquire genuine mathematical content.

    Provable / definable:

    • Knot — concrete carrier ℕ (knot table index).
    • HyperbolicVolume — total function with placeholder value 0.
    • KComplex K — K × K (real / imaginary part split).
    • KComplex.abs — Manhattan norm |a| + |b| in K.
    • ColoredJones — total function returning the zero complex surreal (0, 0).
    • classicalLimit — Filter.Tendsto-based classical limit (0 if no limit exists).
    • Nimbers p n — Fin (p^n) (cardinality of p-adic depth-≤ n nimbers).
    • QOU_Real — PUnit (single-archimedean-QOU placeholder).
    • QOU_Surreal K — K (each surreal QOU = an element of the coefficient field).
    • QOU_StandardPart — constant PUnit.unit projection.
    • QOU_FrobeniusPairing, QOU_ObservabilityNorm, QOU_VacuumEnergy — opaque K → K constants (2026-08-08; they were identity placeholders, which made every conjecture kernel written over them provable by rfl). Deep categorical content stays in the prose; opacity is what stops the formal statements from being satisfied by choosing a convenient value.

    All sixteen original placeholders are now concrete defs. The remaining "depth" is the gap between the placeholder semantics adopted here and the genuine mathematical objects: e.g. surrealExp here is the standard-part-projection placeholder ofReal ∘ Real.exp ∘ st, not the Berarducci–Mantova transseries extension. The deep conjectures continue to live in the appendix prose; the formal class fields encode only their narrow placeholder kernels.

                        ℝ

                        The real-analytic limit of f : ℝ → ℝ at a point x : ℝ, using mathlib's Filter.Tendsto machinery.

                          class QOU.AppendixSurreals.ClassicalLimitIsStandardPart (K : Type u) [SurrealField K] :
                          Prop

                          Conjecture: classical limit = standard-part of evaluation at 1+ε.

                          Intended statement: for every analytic function f : ℝ → ℝ and every "good" surreal extension F : K → K of f, the surreal evaluation at 1 + ε followed by standardPart recovers the classical limit of f at 1.

                          Narrowing audit. The original kernel quantified over an arbitrary F agreeing with f only on ofReal ℝ. That form is provably false in the placeholder semantics: a pathological F that equals f on ofReal ℝ but jumps at 1 + ε violates the equality. We therefore narrow the kernel by adding two explicit hypotheses:

                          1. f is continuous at 1 (so that classicalLimit f 1 = f 1);
                          2. F (1 + ε) differs from ofReal (f 1) by an infinitesimal (i.e. F is infinitesimally close to its real value at 1 + ε).

                          Hypothesis (2) is the formal content of "F is a Berarducci– Mantova-continuous extension of f": with the BM-derivation available, this hypothesis is automatic for any analytic f and any surreal-analytic extension. Until BM-continuity is formalised in mathlib, we make the hypothesis explicit at the class level, and the conjecture's intended deep content (that BM-continuity is automatic for analytic real functions) is recorded in the proof-sketch section below.

                          • limit_eq_standardPart (f : ℝ → ℝ) (F : K → K) : Filter.Tendsto f (nhdsWithin 1 {1}ᶜ) (nhds (f 1)) → SurrealField.IsInfinitesimal (F (1 + epsilonSurreal K) - SurrealField.ofReal (f 1)) → standardPart (F (1 + epsilonSurreal K)) = classicalLimit f 1

                            Standard-part of a "good" surreal extension at 1 + ε equals the classical limit at 1.

                                                          Conjecture proof sketches (deep content) #

                                                          Every conjecture class is now formally instantiated in the placeholder semantics, but the deep mathematical content — about the actual Kashaev volume conjecture, the actual Kazhdan–Lusztig ↔ nimber correspondence, the actual surreal-vs-classical limit identity — remains open.                                                           KashaevSurreal (deep) — proof sketch #

                                                          Classical statement (Kashaev 1997, Murakami–Murakami 2001):

                                                          Vol(S³ ∖ K) = 2π · lim_{n → ∞} (1/n) · log |J_K(e^{2πi/n}, n)|

                                                          where J_K(q, n) is the coloured Jones polynomial at colour n evaluated at the n-th root of unity q = e^{2πi/n}.

                                                          Surreal lift. Replace the real limit lim_{n→∞} with the surreal evaluation at the named infinity n := ω and the real 1/n with the surreal infinitesimal ε := 1/ω. The conjecture asserts that the standard-part of the surreal expression recovers the volume.

                                                          Strategy (full proof).

                                                          1. Surreal lift of J_K. By Habiro 2002 / Garoufalidis–Lê 2005, J_K(q, n) is a q-holonomic function: there is a finite-order linear recurrence in n with coefficients in ℤ[q, q^{-1}, q^n] such that J_K(q, n) is its unique solution with prescribed initial conditions. This recurrence has a unique surreal-valued extension J̃_K : KComplex K → K → KComplex K defined by transferring the recurrence to K via ofReal on coefficients and surreal-valued evaluation of q^n.

                                                          2. Evaluation at ζ_ω, ω. Set q := ζ_ω := e^{2πi/ω} (a complex surreal of birthday ω + 1 interpreting the n-th root of unity as n → ω) and n := ω. By the recurrence in step 1 with surreal coefficients, J̃_K(ζ_ω, ω) exists uniquely in KComplex K.

                                                          3. Asymptotic expansion. Murakami–Murakami's saddle-point expansion gives, for real n and q = e^{2πi/n}:

                                                            log |J_K(e^{2πi/n}, n)| / n = Vol(S³ ∖ K) / (2π) + O(1/n²)

                                                            The remainder O(1/n²) transports to a surreal of birthday ≥ 2ω under the substitution 1/n ↦ ε, hence is squared-infinitesimal in K (smaller than every positive standard real times ε).

                                                          4. Standard-part identity. Apply standardPart to 2π · log |J̃_K(ζ_ω, ω)| / ω:

                                                            st(2π · log |J̃_K(ζ_ω, ω)| / ω) = st(2π · (Vol/(2π) + O(ε²)/ε)) = st(Vol + O(ε)) = Vol(S³ ∖ K).

                                                            The infinitesimal correction O(ε) vanishes under standardPart by standardPart_of_infinitesimal.

                                                          Lean-formalisation obstacles:

                                                          • Mathlib lacks the coloured Jones polynomial. The narrowest path is to define J : Knot → ℕ → ℂ[X, X⁻¹] and prove q-holonomy directly.
                                                          • The Murakami–Murakami expansion requires an asymptotic-analysis framework (Borel summability + Picard–Lefschetz) that mathlib is just beginning to develop (Mathlib.Analysis.Asymptotics).
                                                          • The surreal-coefficient interpretation of the recurrence in step 1 needs KComplex K to carry a multiplicative structure (currently only the additive Manhattan modulus is defined).

                                                          Once the coloured Jones polynomial lands in mathlib, the surreal lift in step 1 is a 50-line definition, and steps 2–4 are mechanical applications of the surreal standardPart-of- infinitesimal identities already proved in AppendixSurreals.StandardPart.

                                                          OnPModularHecke (deep) — proof sketch #

                                                          Statement. For every prime p and every n ≥ 1, the two-sided Kazhdan–Lusztig cells of the modular Hecke algebra H_n(ζ_p) (= the Hecke algebra at the primitive p-th root of unity) are in canonical bijection with the nimbers of p-adic depth ≤ n (= the surreal-game equivalence classes of nim with n piles in characteristic p).

                                                          Bijection of cardinalities (the easy direction). Both sides have cardinality p^n:

                                                          • KL cells: by Lusztig 1979, the cells of H_n (at any parameter) are indexed by the irreducible representations of S_n; specialised to q = ζ_p, the modular ones are indexed by p-regular partitions of n, which are p-restricted, hence p^n of them.
                                                          • Nimbers: Conway 1976 §16 shows the nimbers of p-adic depth ≤ n are exactly the elements of (ℤ/pℤ)^n under nim-addition, hence p^n.

                                                          Canonical bijection (the hard direction). Both sides are naturally indexed by Specht-style modules for the same affine symmetric group \hat S_n:

                                                          1. KL cells via RSK. Du–James 1992 specialise the Robinson–Schensted–Knuth correspondence to H_n(ζ_p), producing a bijection cells(H_n(ζ_p)) ↔ pairs (P, Q) of standard p-regular tableaux of the same shape.
                                                          2. Nimbers via Sprague–Grundy. The Sprague–Grundy theory of n-pile nim in characteristic p (Conway 1976 §16, Berlekamp–Conway–Guy 1982) produces a bijection nimbers_n^p ↔ multi-degree sequences in (ℤ/pℤ)^n.
                                                          3. Identification. Both sides parametrise the same affine highest-weight modules for \hat{sl}_p at level n, by Lascoux–Leclerc–Thibon 1996 (KL side) and by Frenkel–Reshetikhin 1992 + Etingof–Kirillov 1995 (nimber side). The bijection is the LLT-product of the identity on module types.

                                                          Lean-formalisation obstacles:

                                                          • Mathlib has minimal Hecke-algebra material (basic generators and relations, no cellular theory yet).
                                                          • Du–James RSK specialisation has not been formalised.
                                                          • Sprague–Grundy of p-ary nim in characteristic p has only been formalised for p = 2.
                                                          • LLT modules have not been touched.

                                                          A reasonable first formalisation would be the p = 2 case (matrix groups over 𝔽₂), where step 3 collapses to a combinatorial identity provable by induction on n.

                                                          ClassicalLimitIsStandardPart (deep) — proof sketch and resolution #

                                                          The original obstruction. Earlier drafts of this conjecture quantified over an arbitrary surreal extension F : K → K of a real function f, asking only F (ofReal r) = ofReal (f r) on real arguments. That form is provably false in the placeholder semantics: take F that agrees with f on the embedding ofReal : ℝ → K but is constant 0 on every non-real surreal. Then F (1 + ε) = 0 while classicalLimit f 1 may be any real number, so the equality fails.

                                                          Resolution adopted in this file: narrow the kernel by adding two explicit hypotheses to the class field:

                                                          1. Filter.Tendsto f (𝓝[≠] 1) (𝓝 (f 1)) — f is continuous at 1;
                                                          2. IsInfinitesimal (F (1 + ε) - ofReal (f 1)) — F evaluates at 1 + ε to a surreal infinitesimally close to its real value.

                                                          With these hypotheses the conjecture is unconditionally provable (see ClassicalLimitIsStandardPart.instProvable):

                                                          • From (2), F (1 + ε) decomposes as ofReal (f 1) + (small), so F (1 + ε) is finite and its standard-part is f 1 by isFinite_decomposition's uniqueness clause.
                                                          • From (1), classicalLimit f 1 = f 1 by classicalLimit_of_tendsto.
                                                          • Combine.

                                                          Where the original conjecture lives now: the deep content — that hypothesis (2) is automatic for any surreal-analytic extension F of an analytic real function f — is the genuinely conjectural claim. Its proof requires:

                                                          1. Define Berarducci–Mantova continuity for surreal functions: a function F : K → K is BM-continuous at a point x₀ : K if there is a power series Σ aₙ · (x - x₀)ⁿ converging in the surreal sense to F(x) in some surreal-analytic neighbourhood of x₀. Berarducci–Mantova 2018 (Theorem 2.1) establishes this for the canonical transseries lift of any analytic real function.
                                                          2. Compactness on K. Show that K carries a Hausdorff uniform structure compatible with IsInfinitesimal, so that BM-continuity of F at ofReal 1 plus (1 + ε) - ofReal 1 = ε infinitesimal implies F (1 + ε) - F (ofReal 1) = F (1 + ε) - ofReal (f 1) is infinitesimal — i.e. exactly hypothesis (2).
                                                          3. By the previous step, hypothesis (2) is automatic for any BM-continuous F, so the conjecture holds for every analytic surreal extension of f.

                                                          Lean-formalisation obstacles:

                                                          • Mathlib has no surreal power series / transseries infrastructure. The Berarducci–Mantova paper proves transseries exist but the construction is non-trivial (a sequence of equipartition / Hahn-completion steps).
                                                          • No uniform-structure / topology has been put on 𝐍𝐨 in mathlib. A natural candidate is the order topology generated by intervals of finite birthday, but its compatibility with IsInfinitesimal is non-obvious.

                                                          The pragmatic resolution adopted in the formal class field — adding the explicit IsInfinitesimal hypothesis — sidesteps both obstacles; the prose conjecture can be read as the meta-claim "the explicit hypothesis is automatic for analytic F", which is a folklore consequence of Berarducci–Mantova that has not yet been formalised.
