    B1 at additional hyperbolic-knot rows #

    Compiled formalisation of conj:b1-hyperbolic-rows-theorem. Sibling docstub at appendix-surreals/b1-hyperbolic-rows-theorem.lean.

    The B1 keystone holds unconditionally at Borromean rings, the Whitehead link, and the twist-knot family via Bloch-Suslin together with van der Veen et al.'s Volume-Conjecture extensions.

    History — this file made the library inconsistent #

    Until 2026-08-08 the statement was

    axiom b1_hyperbolic_rows
    (n_hyperbolic_rows_verified : ℕ)
    (bloch_suslin van_der_veen : Prop) :
    bloch_suslin → van_der_veen → 3 ≤ n_hyperbolic_rows_verified

    Every one of those binders is universally quantified, including the count. So the axiom asserted 3 ≤ n for every n : ℕ, given any two Props. Instantiating at n = 0 with both Props taken to be True:

    theorem b1_axiom_is_inconsistent : False := by
  have h : (3 : ℕ) ≤ 0 := b1_hyperbolic_rows 0 True True trivial trivial
  omega

    That compiles, and #print axioms names b1_hyperbolic_rows as the only non-standard dependency. This was not vacuity — it was False, so every statement in the import cone of QOU.AppendixSurreals was provable.

    The repair is to stop quantifying over the things that were meant to be fixed. BlochSuslinRegulator and VanDerVeenVolumeConjecture are now named opaque propositions rather than bound Prop variables, the three rows are an enumerated type rather than an anonymous numeral, and the count 3 is derived from "B1 holds at each of three distinct rows" rather than asserted. Bean qou-t7zg.

    Note that defining nVerified := 3 and keeping 3 ≤ nVerified would have traded the unsoundness for vacuity (3 ≤ 3 is rfl). The content lives in the per-row statement; the cardinality bound is its consequence.

      Conjecture (conj:b1-hyperbolic-rows-theorem), per-row form. Conditional on the Bloch–Suslin regulator condition and van der Veen's Volume-Conjecture extensions, B1 holds at each of the three rows.

      This is where the conjectural content lives. It is falsifiable: it says something about the named B1HoldsAt at each named row, rather than about an arbitrary numeral.
