    QOU.AppendixSurreals.FigureEightCasimirWeight — the 3/4 is exact algebra #

    Supporting lemmas for the first Casimir q-correction discussion of conj:casimir-epsilon-vacuum (audit docs/audits/2026-06-01-casimir-first-qcorrection-figure8.md).

    The leading 1/d⁴ Casimir term is q-free (disjoint unknots, the n-stable bare count). The first q-correction is carried by the first hyperbolic braided mode — the figure-eight knot 4_1 — whose substrate weight is its Jones polynomial

    J_{4_1}(q) = q⁻² − q⁻¹ + 1 − q + q² (Lickorish; normalised J_{4_1}(1) = 1).

    The audit claims J_{4_1}(q) = 1 + (3/4) h² + O(h⁴) with h = q − q⁻¹. This file proves the 3/4 is exact algebra, not a fit:

    (4·(J−1) − 3·h²) · (h² + 8 + 4·(q+q⁻¹)) = h⁴ (exact field identity),

    with the remainder denominator h² + 8 + 4(q+q⁻¹) > 0 for q > 0. Hence 4(J−1) − 3h² = h⁴ / (positive), i.e. the h² coefficient of J−1 is exactly 3/4 with an explicit, sign-definite O(h⁴) remainder — no fitting, no free parameter.

    The identification of J_{4_1} as the first-correction weight is the structural (physical) input documented in the audit; the 3/4 that follows from that weight is the elementary algebra proved here.

    Ref: [lickorish1997] An Introduction to Knot Theory, Springer GTM 175 (Jones polynomial of the figure-eight knot).

      theorem QOU.AppendixSurreals.jones41_taylor (q : ℝ) (hq : 0 < q) :
      jones41 q = 1 + 3 / 4 * (q - q⁻¹) ^ 2 + (q - q⁻¹) ^ 4 / (4 * ((q - q⁻¹) ^ 2 + 8 + 4 * (q + q⁻¹)))

      The result, as a theorem. With h = q − q⁻¹, the figure-eight Jones weight expands as J_{4_1}(q) = 1 + (3/4)·h² + R(q), where the remainder R(q) = h⁴ / (4·(h² + 8 + 4(q+q⁻¹))) is exact, and for q > 0 is positive and of order h⁴ (its denominator → 64 as q → 1). The leading coefficient 3/4 is forced by ring; it is not a fitted constant. This is the precise sense in which "J_{4_1} = 1 + (3/4)h² + O(h⁴)" holds.

      class QOU.AppendixSurreals.FirstInteractingCasimirCorrection :

      Conjectural input (conj:casimir-first-q-correction, §3b-cond pattern). The conjecture: the first substrate-dependent correction to the plate-bounded vacuum mode-sum enters with the Markov-trace weight of the minimal hyperbolic braided mode — the figure-eight knot 4₁. This class axiomatises that identification; the theorems below are fully verified consequences, conditional on an instance. No instance is provided: constructing one (the interacting-mode mode-sum) is the open content of the conjecture.

        relative weight of the first substrate correction, per mode

        the carrier identification: the weight is the Jones polynomial (Markov trace) of the figure-eight knot
