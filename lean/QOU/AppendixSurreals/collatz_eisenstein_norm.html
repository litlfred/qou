    The Eisenstein norm on the q-Collatz backward tree #

    This file supplies the two arithmetic inputs that the unit-obstruction engine in QOU.AppendixSurreals.CollatzBlockDescent is applied to, and which that file records as argued, not formalized:

    • the branch norm formula N(Q_k(w)) = 1 + 6k + 12k², and
    • the tree-structure induction — every node of the backward tree from the attractor lies either on the main even chain or on a bare k ≥ 1 branch.

    Together with the engine (evenSubtree_no_oddPreimage) they give the tree-level conclusion: no two chained odd-preimages occur in the backward tree, i.e. no v = 0 block occurs there.

    What is proved here, and over what #

    Almost everything below is an identity over an arbitrary CommRing R carrying an element w with w² + w + 1 = 0; those lemmas carry no side hypotheses.

    The two statements that genuinely need ℤ[ω]-like arithmetic — that a norm-n element with n ≠ ±1 is a non-unit, and that the coordinates (x, y) of x + y·w are determined — are isolated behind the explicit hypothesis

    hindep : ∀ x y : ℤ, (x : R) + (y : R) * w = 0 → x = 0 ∧ y = 0

    ("1 and w are ℤ-independent in R"). That holds in ℤ[ω] and in ℂ; it fails in, say, ZMod 3. It is a hypothesis on the ambient ring, not a conjecture: nothing here is axiomatized, and no sorry appears in this file.

    Scope (per the repo's (a)/(b) refutation discipline) #

    The conclusion is a structural exclusion for the backward tree — the obstruction is a proved invariant (the Eisenstein norm), not a numerical near-miss. But its scope is the backward tree only. The step from "no v = 0 block in the backward tree" to "no v = 0 block in D∞" is the convergence conjecture itself (qcz7 A1) and is not claimed.

          The main chain and its k-th branch #

          Along the main even chain from the attractor 1 + q⁻¹ one has u₀ = v₀ = -w, so at n = 6k (where α^n = 1) the data is

          u_(6k) = -w,        v_(6k) = -6k - (6k+1)·w.

          Differentiating the odd-branch relation [3]_q·Q = [2]_q·P - 1 at w, where [3]_q vanishes, gives (2w + 1)·Q(w) = P(w) + (w+1)·P'(w).

                source
                theorem QOU.AppendixSurreals.CollatzEisenstein.branch_subtree_no_oddPreimage {R : Type u_1} [CommRing R] (w : R) (hw : w ^ 2 + w + 1 = 0) (hindep : ∀ (x y : ℤ), ↑x + ↑y * w = 0 → x = 0 ∧ y = 0) (hcoord : ∀ (z : R), ∃ (x : ℤ) (y : ℤ), z = eis w x y) (k : ℕ) (hk : 1 ≤ k) (n : ℕ) :
                ¬∃ (Q : R), (w + 1) * ((w + 1) ^ n * branchEval w k) = (w ^ 2 + w + 1) * Q + 1

                The tree-structure theorem. Let p = branchEval w k be the evaluation at the odd-preimage node of the k-th branch, k ≥ 1. Then no node of the even subtree above it admits an odd-preimage:

                ∀ n, ¬ ∃ Q, [2]_q·(αⁿ·p) = [3]_q·Q + 1.

                So each k ≥ 1 branch of the backward tree is a bare even chain — it carries no second odd step. Together with the main chain (k = 0, which returns to the attractor) this exhausts the tree: every node lies on the main chain or on a bare k ≥ 1 branch, and no two odd-preimages ever chain.

                Consequence for the arc: no v = 0 block occurs in the backward tree.
