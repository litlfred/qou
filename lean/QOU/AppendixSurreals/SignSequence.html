    QOU.AppendixSurreals.SignSequence — Gonshor sign sequences #

    A finite sign sequence s : List Sign determines a dyadic rational gonshor s ∈ ℚ via Conway's recursive {L | R} recipe.

    This module is fully constructive: gonshor is a left-fold over a state tuple (value, lo, hi, hasLo, hasHi) : ℚ × ℚ × ℚ × Bool × Bool, implementing the recipe:

    • Empty list ↦ (0, 0, 0, false, false) — value zero, no bounds yet.
    • Next sign +:
      • if no upper bound yet: new value = v + 1; bounds become (v, ∅) (lower = old v; upper still unbounded).
      • if upper bound hi exists: new value = (v + hi) / 2; bounds become (v, hi).
    • Next sign - is symmetric (swap roles of lo and hi).

    Then transport into any SurrealField via the canonical embedding ofReal ∘ ratCast.

    Convention #

    The list is processed left-to-right (List.foldl): the head is the first (outermost) sign, and subsequent signs refine. This matches Conway's convention that the leftmost sign is applied first.

    Examples (verified below):

    • [] ↦ 0
    • [+] ↦ 1
    • [-] ↦ -1
    • [+, +] ↦ 2
    • [+, -] ↦ 1/2
    • [-, +] ↦ -1/2
    • [-, -] ↦ -2

    References #

    • [gonshor1986] Gonshor, An Introduction to the Theory of Surreal Numbers, Cambridge University Press, Chapter 2.
    • [conway1976] Conway, On Numbers and Games, Academic Press.

                    theorem QOU.AppendixSurreals.birthday_gonshorIn_le_omega (K : Type u) [SurrealField K] (s : List Sign) :
                    SurrealField.birthday (gonshorIn K s) ≤ Ordinal.omega0

                    The birthday of gonshorIn K s is bounded by ω.

                    Proved from birthday_ofReal_le_omega: every real-image element has surreal birthday at most ω.

                    NOTE. The sharper bound birthday ≤ (s.length : Ordinal) (Gonshor 1986, Theorem 2.1) — proved unconditionally below for s.length ≤ 1 — is not derivable for general s from the abstract SurrealField axioms alone. The induction step would require a per-step bound on birthday (x / 2) (the halving move in GonshorState.step), which is not among the axioms in QOU.AppendixSurreals.Basic and is not implied by them. Adding such a bound would be an additional axiom on SurrealField, so we state and prove only the universally-supported ≤ ω form here.

                    Ref: [gonshor1986] Theorem 2.1 (sharper form, partial coverage below)

                        @[reducible, inline]
                        abbrev QOU.AppendixSurreals.HoefsmitChoice (n : ℕ) :
                        Type

                        The Hoefsmit eigenspace decomposition step: applying a Hecke generator T_i (resp. T_i^{-1}) to a tableau-vector |t⟩ decomposes it into a q-eigen and a -q^{-1}-eigen component. The which-channel choice at each step is a sign function on (tableau, generator) pairs.

                        The actual recipe (§2 of Gonshor 1986: sign assignment by ordering of options) is left as a parameter rather than fixed to a placeholder value. Callers requiring the canonical Hoefsmit recipe pass the appropriate term; downstream invariants are parameterised over the choice.
