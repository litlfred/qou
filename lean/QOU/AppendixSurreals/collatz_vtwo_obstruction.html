    The [2]_q-adic valuation is not a descent measure (Front A, A1) #

    reaches_cycle_of_descent reduces q-Collatz convergence to the existence of a measure μ : Skein → ℕ strictly decreasing off the attractor. The natural candidate is the [2]_q-adic valuation v_[2] = qTwoValuation (multiplicity of the root q = -1). It descends by exactly one on an even step (qTwoValuation_mul_qplus_one) — but on an odd step it can increase.

    This file machine-checks that failure with a concrete witness, turning the audit's prose wall into a theorem: P = -X - 2 is q-odd (v_[2] = 0), yet its odd branch ([3]_q P + 1)/[2]_q = -(X+1)² has v_[2] = 2. So no unconditional monotone descent measure can equal v_[2] alone.

    Scope (a), not (b). This rules out the obvious candidate μ = v_[2]; it does not exclude the existence of some descent measure (the convergence wall stays open). No fabricated μ.

    source
    theorem QOU.AppendixSurreals.qcollatz_vTwo_increases_on_odd_branch :
    ∃ (P : Polynomial ℤ) (Pnext : Polynomial ℤ), (Polynomial.X + 1) * Pnext = (Polynomial.X ^ 2 + Polynomial.X + 1) * P + 1 ∧ qTwoValuation P = 0 ∧ 2 ≤ qTwoValuation Pnext

    The [2]_q-adic valuation increases on an odd step — so it is not a descent measure. Witness P = -X-2 (q-odd, v_[2] = 0); the odd-branch relation [2]_q · Pnext = [3]_q · P + 1 gives Pnext = -(X+1)² with v_[2] = 2. Scope-(a): kills the natural μ candidate, not the conjecture.
