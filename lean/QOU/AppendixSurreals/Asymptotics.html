    QOU.AppendixSurreals.Asymptotics — ω-adic Big-O valuation #

    Axiomatises the surreal ω-adic order Ow : K → WithTop K (leading exponent in Conway normal form) and records the standard dictionary relating it to classical Big-O / little-o / Θ / ∼.

    The valuation signature is axiomatised as a typeclass OmegaOrder; the classical-Big-O bridge is stated as a conjectural class SurrealBigOBridge per AGENTS.md §3b (conjectural propagation).

    Mathlib does not yet expose Conway normal form on 𝐍𝐨, so the canonical surreal model is still not constructed here. OmegaOrder is nevertheless populated, by the Hahn model in HahnOmegaOrder.lean — see below.

    History: how this class came to be instantiable (2026-08-16) #

    OmegaOrder previously had no instance anywhere in this tree, which left every [OmegaOrder]-conditional result untested for satisfiability — a class that asserts a great deal but has never been shown consistent is not much better than one that asserts nothing, which is the defect bean qou-ffwk is about. A first attempt to supply a model from Mathlib's Hahn-series API found three obstructions. Recorded because two of them are still live for the surreal model, and because obstruction 2 is the one this class was changed to remove.

    1. No degenerate model is available — still true. SurrealField requires omegaSurreal : K with omegaSurreal_gt_natCast : ∀ n : ℕ, (n : K) < _. No real exceeds every natural, so SurrealField ℝ is impossible; the cheap witness that would settle non-emptiness cannot exist, and any SurrealField model must be genuinely non-archimedean. This is why SpectralNormalForm, which needs IsInfinitesimal/IsFinite and hence SurrealField, is still unwitnessed even though OmegaOrder now is.

    2. The exponent type was self-referential — FIXED. Ow was typed K → WithTop K, exponents in the field itself. That is right for 𝐍𝐨, closed under ω-exponentiation, but it has no counterpart in Mathlib, whose valuation is HahnSeries.orderTop : HahnSeries Γ R → WithTop Γ with Γ separate. The class now carries Γ as its own parameter (take Γ := K for the surreal reading) and weakens [SurrealField K] to [CommRing K] [Algebra ℝ K], which is all the scaling axiom ever used. Bean qou-x20w.

    3. orderTop multiplicativity — PROVED. Mathlib offers only the inequality orderTop_add_le_mul. The equality Ow_mul states is now derived in HahnOmegaOrder.lean from HahnSeries.order_mul over a domain, together with the two zero cases.

    Still open for the surreal carrier: the Lex order transfer, and a birthday function satisfying the nadd sub-additivity and midpoint bounds SurrealField demands.

    Notation: in LaTeX we write $O_\omega$ (Big-O register, via the \ordw macro). In Lean the identifier is Ow for ASCII usability.

    LaTeX label: rem:conway-normal-form.

    Type (max u w)

    A commutative ℝ-algebra K admits an ω-adic order with exponents in Γ: the leading exponent in Conway normal form, valued in WithTop Γ.

    Classical analogue is the p-adic order ord_p. Under the QOU notational convention, the symbol is typeset as $O_\omega$ (Big-O register) because the equivalence f = O(g) ⟺ Ow(f) ≤ Ow(g) makes Big-O the natural reading.

    Why the exponent group is a separate parameter #

    Until 2026-08-16 this class fixed Ow : K → WithTop K and required [SurrealField K]. Exponents-in-K is right for 𝐍𝐨, which is closed under ω-exponentiation — but it is a self-referential structure, and it made the class uninstantiable: it left Ow with no model anywhere in this tree, so every [OmegaOrder]- conditional result was untested for satisfiability. See bean qou-x20w, and qou-ffwk for the carrier-hygiene work that surfaced it.

    Two changes fix that, both conservative:

    • exponents move to their own Γ, matching the standard shape of a leading-exponent valuation (and Mathlib's HahnSeries.orderTop : HahnSeries Γ R → WithTop Γ); take Γ := K to recover the old reading for 𝐍𝐨;
    • the base weakens from [SurrealField K] to a commutative ring with an algebra over an arbitrary scalar ring S, which is all Ow_algebraMap_mul ever used. It was previously phrased with SurrealField.ofReal; nothing about a leading-exponent valuation needs the scalars to be the reals, and leaving them abstract also keeps this module clear of the §7c mixed-regime rule (a generic base ring beside a real-field type is exactly what that rule forbids). Surreal callers instantiate S := ℝ, since every SurrealField is canonically a real algebra via SurrealField.toAlgebra with algebraMap equal to ofReal.

    Together these admit the Hahn model in HahnOmegaOrder.lean.

    • Ow : K → WithTop Γ

      The ω-adic order, valued in WithTop Γ.

    • Ow_zero : Ow S 0 = ⊤

      Zero has order ⊤.

    • Ow_mul (x y : K) : Ow S (x * y) = Ow S x + Ow S y

      Multiplication is valuation-additive: Ow (x·y) = Ow x + Ow y.

    • Ow_algebraMap_mul (r : S) (x : K) : (algebraMap S K) r ≠ 0 → Ow S ((algebraMap S K) r * x) = Ow S x

      Rescaling by a nonzero real leaves the leading exponent unchanged (finite nonzero reals have Ow = 0).
