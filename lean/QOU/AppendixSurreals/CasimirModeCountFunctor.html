    QOU.AppendixSurreals.CasimirModeCountFunctor — Stage C scaffolding for N_⊙ #

    Stage C of the N_⊙-construction workplan (docs/workplans/2026-06-12-n-odot-construction-scoping.md) for conj:casimir-epsilon-vacuum.

    The genuine blocker of the Casimir conjecture is the categorical object N_⊙(A, d) — the plate-bounded, surreal-valued disjoint-unknot density whose archimedean image is the standard mode count. The selection principle (CasimirNStability.lean) and the prefactor arithmetic (CasimirZetaPrefactor.lean) pin down what N_⊙ must reduce to; they do not build it. This file scaffolds the construction: it gives N_⊙ a typed interface (the §3b-cond class pattern) and proves that any object meeting the interface discharges the downstream CasimirEpsilonVacuum energy class. N_⊙ thereby becomes a precise upstream target rather than prose.

    What is new here, beyond CasimirEpsilonVacuum. That class carries the archimedean energy density energyPerArea : ℝ → ℝ directly. The mode-count object is one level up: it depends on the plate area A as well as the gap d, and the physically essential property is extensivity in area (locality of the lift) — this is what makes "energy per unit area" well-defined and area-independent. The interface records that, plus the reduction (via n-stability) to the q-free disjoint-count scaling −π²/(720 d³).

    What remains open (no instance is provided). Constructing an instance is the Yekutieli-homotopy lift of the plate-bounded link-projection functor — a functor from plate-bounded ambient-isotopy classes to surreal-valued counts, functorial in (A, d), whose n-stable restriction is the bare disjoint-unknot count. The substrate-conformal boundary data this lift needs is not yet formalised anywhere in the corpus; see the workplan Stage C. This file is the target type, not the construction.

    class QOU.AppendixSurreals.PlateModeCountFunctor :
    Type

    Stage-C interface for N_⊙(A, d) (§3b-cond class). Carries the archimedean image of (N⊙^in − N⊙^out)·ε as a function of plate area A and gap d (units ℏc = 1), exactly as CasimirEpsilonVacuum sidesteps the surreal layer by recording the standard-part. The two axioms are the content the lift must deliver:

    • extensive_in_area — the count difference is proportional to the plate area (locality / functoriality of the lift), so the per-area energy is well-defined and area-independent;
    • per_area_scaling — the per-area count reduces to the q-free disjoint-unknot value −π²/(720 d³) selected by n-stability (CasimirNStability), with prefactor pinned by CasimirZetaPrefactor.

    No instance is provided: the construction is the open Yekutieli lift.

    • modeCountDiff : ℝ → ℝ → ℝ

      archimedean image of (N⊙^in − N⊙^out)·ε for plates of area A, gap d (units ℏc = 1).

    • extensive_in_area (A d : ℝ) : modeCountDiff A d = A * modeCountDiff 1 d

      extensivity in plate area: the count difference is proportional to area, so energy per unit area is well-defined and area-independent.

    • per_area_scaling (d : ℝ) : 0 < d → modeCountDiff 1 d = -Real.pi ^ 2 / (720 * d ^ 3)

      the per-area count reduces to the disjoint-unknot (bare-count, q-free) value selected by n-stability: the leading parallel-plate scaling −π²/(720 d³).

        Transported consistency witness — NOT a substrate derivation. This inhabits PlateModeCountFunctor with the textbook Casimir energy density hardcoded, f(A,d) = −A·π²/(720 d³). Its only purpose is to show the interface is consistent (the two axioms are jointly satisfiable, so the class is not vacuous) and that the downstream chain (CasimirEpsilonVacuum, and via energyPerArea_deriv the force law) runs end-to-end on a concrete object.

        It is transport, not derivation: the −π²/(720 d³) scaling is postulated here, copied from standard physics, not produced from substrate data. Providing it as an instance would let typeclass resolution silently discharge the conjecture, so it is deliberately a plain def (not an instance). The open conjecture (conj:casimir-epsilon-vacuum) is precisely that the categorical Yekutieli lift yields this function from the plate-bounded mode count — see docs/workplans/2026-06-12-n-odot-construction-scoping.md (Stage C).
