    QOU.AppendixSurreals.HoefsmitBridge — Hoefsmit ↔ Conway construction #

    The bridge proposition prop:hoefsmit-is-surreal-construction asserts a forest-isomorphism between standard tableaux of two-rowed shapes and finite-dyadic surreals of bounded birthday.

    Status #

    Mathlib's Combinatorics.YoungTableau does not yet expose the YJM (Young–Jucys–Murphy) extension as a rooted-tree structure, so the full bridge cannot be proved here. This file provides:

    1. an abstract TwoRowTableau type recording only the row sizes (row1, row2) of a two-rowed Young shape. This matches the set of two-rowed shapes (one shape per partition), which coincides with the set of two-rowed standard tableaux only for n ≤ 2; for n ≥ 3 distinct standard tableaux of the same shape (e.g. the two tableaux of shape (2, 1) at n = 3) are not distinguished by TwoRowTableau;
    2. an explicit injectivity proof at small sizes (n ≤ 2), the first non-trivial cases of the bridge proposition;
    3. a typeclass formulation of the bridge in general (per AGENTS.md §3b), with the witness deferred to a future entry-aware refactor of TwoRowTableau plus a YJM-tree formalisation.

    References #

    • [conway1976] Conway, On Numbers and Games, §0.
    • [gonshor1986] Gonshor, An Introduction to the Theory of Surreal Numbers, Chapter 2.
    • [hoefsmit1974] Hoefsmit, Representations of Hecke algebras of finite groups with BN-pairs of classical type, PhD Thesis, UBC.

              noncomputable def QOU.AppendixSurreals.hoefsmitDyadic {n : ℕ} (_h : n ≤ 2) :
              TwoRowTableau n → ℚ

              The Hoefsmit-to-surreal map sends a two-rowed tableau to its associated dyadic rational (= birthday-bounded surreal).

              Defined by case analysis on the tableau shape:

              • size 0: empty ↦ 0
              • size 1: singleton ↦ 0 (the single box has no left/right choice)
              • size 2: (2,0) ↦ 1 (rightmost extension: q-eigenchannel) (1,1) ↦ -1 (downward extension: -q⁻¹-eigenchannel)

              The function is restricted to n ≤ 2 at the type level: the TwoRowTableau n data records only the row sizes, which distinguishes standard tableaux exactly when n ≤ 2. For n ≥ 3 distinct standard tableaux of the same shape (e.g. the two tableaux of shape (2, 1) at n = 3) cannot be told apart from row sizes alone, so the map is not defined there — we discharge the impossible case via absurd on the n ≤ 2 hypothesis rather than returning a placeholder value.

              A general-n Hoefsmit-to-dyadic bijection requires an entry-aware tableau type plus a YJM-tree formalisation in Mathlib, neither of which is currently available.

                theorem QOU.AppendixSurreals.hoefsmit_is_surreal_construction {n : ℕ} (h : n ≤ 2) :
                Function.Injective (hoefsmitDyadic h)

                The Hoefsmit-is-surreal-construction proposition for tableau sizes n ≤ 2: the Hoefsmit-to-dyadic map hoefsmitDyadic is injective on TwoRowTableau n for every such n.

                This is the consolidated form of hoefsmit_bridge_zero, hoefsmit_bridge_one, hoefsmit_bridge_two, exposing the LaTeX-label-matching name hoefsmit_is_surreal_construction referenced by the content manifest (appendix-surreals/hoefsmit-is-surreal-construction.ts).

                The general-n extension requires an entry-aware tableau type plus a YJM-tree formalisation in Mathlib (see the file-level docstring); per AGENTS.md §3b we do not assert it as an axiom. The proposition here is the genuine n ≤ 2 statement, proved unconditionally.
