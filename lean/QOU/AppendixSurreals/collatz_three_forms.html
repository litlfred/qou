    The three faces of the q-Collatz conjecture (Tier C, C12) #

    rem:collatz-three-forms asserts that the contact-boundary condition — each tripling followed by at least two halvings on average — has three equivalent faces: categorical (Markov trace on H_n(q)), arithmetic (a contraction threshold on [2]_q, [3]_q), and residue (behaviour at the [2]_q-divisor q = -1). That remark carries no lean ref at all, making it the largest unformalized item in the q-Collatz arc. This file supplies the carrier.

    The three faces are formalized here at different epistemic tiers, and the tiers are the point — they are not interchangeable:

    face tier here
    arithmetic (threshold is exactly 2) proved integer_threshold_eq_two, contactThreshold_mem_Ioo
    residue (q = -1) proved qi2_at_divisor, odd_branch_at_divisor
    classical limit (E[v₂(3n+1)] = 2) proved expected_halvings_eq_two
    categorical (tr_M(𝒞_q^k(h)) → 1) open conjecture MarkovTraceConvergence, content-bearing, no instance

    What this file closes that was open #

    QOU.Substrate.contact_threshold_lt_two (in QOU/QCollatz.lean) is titled "The contact threshold 1 < v* < 2" — but its statement and proof establish only v* < 2. The lower half 1 < v* appears nowhere in the corpus (grepped), and it is the half that matters for the remark's claim "The integer threshold is exactly v = 2. Two halvings per tripling are required.": without it, one halving might have sufficed. one_lt_contactThreshold supplies it and contactThreshold_mem_Ioo states the two-sided result the docstring claims.

    integer_threshold_eq_two then gives the remark's sentence directly, without any transcendental quantity: v = 1 is never enough and v = 2 always is, for every q > 0.

    The categorical face stays open, and is carried honestly #

    MarkovTraceConvergence is a §3b-tax PRIMARY conjecture carrier: a class whose fields state the remark's display equation and its "identity braid is the unique attractor" clause, with no instance — the honest encoding of an open problem (AGENTS.md: axiomatization is not a proof; a fabricated instance would be an audit dodge). It is not an empty marker: both fields are parameter-quantified propositions with real content.

    What is proved about it is the bridge C12 asks for — no_nontrivial_periodic_trace derives, from the conjecture, that the step operator admits no periodic orbit whose trace differs from the unknot value. That is the categorical shadow of the arc's arithmetic cycle-exclusion results (qcollatz_no_adj_tail_cycle, qcollatz_no_front_loaded_cycle), so the two faces are now coupled by a theorem rather than by prose.

    Scope #

    Nothing here proves the q-Collatz conjecture or any part of it. The arithmetic and residue faces were always elementary — the remark presents them as such; what was missing was that they had no machine-checked carrier and that one of the two threshold inequalities was unproved anywhere.

    Base ring: the residue face is generic [CommRing R] (§7c); the threshold and classical-limit faces are genuinely archimedean (Real.log, an infinite series) and so are stated over ℝ, on the archimedean side of the wall.

    Face 1 — arithmetic: the contraction threshold is exactly two halvings #

    With [2]_q = q + 1 and [3]_q = q² + q + 1 (QOU.Substrate.qInt_two, qInt_three identify these with the q-integers). A cycle with one tripling and v halvings contracts exactly when [2]_q^v > [3]_q.

    source
    theorem QOU.AppendixSurreals.CollatzThreeForms.qi2_lt_qi3 (q : ℝ) (hq : 0 < q) :
    q + 1 < q ^ 2 + q + 1

    [2]_q < [3]_q: one halving never pays for a tripling. Their difference is q², so this is strict for every q ≠ 0.

    source
    theorem QOU.AppendixSurreals.CollatzThreeForms.qi3_lt_qi2_sq (q : ℝ) (hq : 0 < q) :
    q ^ 2 + q + 1 < (q + 1) ^ 2

    [3]_q < [2]_q²: two halvings always do. Their difference is exactly the substrate parameter q — the algebraic gap of QOU.Substrate.qInt_gap.

    source
    theorem QOU.AppendixSurreals.CollatzThreeForms.integer_threshold_eq_two (q : ℝ) (hq : 0 < q) :
    ¬q ^ 2 + q + 1 < (q + 1) ^ 1 ∧ q ^ 2 + q + 1 < (q + 1) ^ 2 ∧ ∀ (v : ℕ), q ^ 2 + q + 1 < (q + 1) ^ v → 2 ≤ v

    The integer contraction threshold is exactly v = 2, for every q > 0 — the remark's "Two halvings per tripling are required", with no transcendental quantity involved. Three claims: v = 1 never suffices, v = 2 always does, and no v below 2 can suffice.

    The transcendental form of the same statement #

    v* = log[3]_q / log[2]_q is the real threshold; the integer condition v ≥ 2 is what the remark uses.

      theorem QOU.AppendixSurreals.CollatzThreeForms.odd_branch_at_divisor {R : Type u_1} [CommRing R] (P : R) :
      ((-1) ^ 2 + -1 + 1) * P + 1 = P + 1

      The odd branch degenerates to a shift at the divisor. Since [3]_q ↦ 1, the numerator [3]_q·P + 1 of an odd step becomes P + 1. This is why the domain condition of the Skein-Collatz map is P|_{q=-1} ∈ {0, -1}: those are exactly the values at which one more halving is available.

      Face 3 — the classical limit q = 1: the margin is exactly zero #

      The remark's displayed identity. For uniformly distributed odd n, the 2-adic valuation of 3n + 1 is k with probability 2^{-k}, so its expectation is ∑ k·2^{-k}.

      source
      theorem QOU.AppendixSurreals.CollatzThreeForms.expected_halvings_eq_two :
      ∑' (n : ℕ), ↑n * (1 / 2) ^ n = 2

      E[v₂(3n+1)] = ∑_{k} k·2^{-k} = 2 — the remark's displayed identity, exactly. (The n = 0 term contributes 0, so summing over all of ℕ agrees with the remark's sum from k = 1.)

      source
      theorem QOU.AppendixSurreals.CollatzThreeForms.classical_limit_is_critical :
      ∑' (n : ℕ), ↑n * (1 / 2) ^ n = 2 ∧ ∀ (q : ℝ), 0 < q → ∀ (v : ℕ), q ^ 2 + q + 1 < (q + 1) ^ v → 2 ≤ v

      The classical case has no margin. The expected number of halvings per tripling at q = 1 equals the integer threshold 2 established in integer_threshold_eq_two — the remark's "There is no margin."

      Stated as a conjunction of two facts about two different kinds of object (an expectation and a sufficiency threshold), deliberately not as an equivalence between them: they are numerically equal, which is what "critical" means here, and nothing stronger is asserted.

      Face 4 — categorical: the Markov trace on H_n(q). OPEN. #

      source
      structure QOU.AppendixSurreals.CollatzThreeForms.HeckeCollatzSystem (H : Type u_2) (S : Type u_3) [One S] :
      Type (max u_2 u_3)

      The categorical setup: a carrier H (the Hecke algebra H_n(q) in the intended reading) with a Markov trace into the Skein ring S, a Collatz step operator, and a distinguished identity braid whose trace is the unknot value 1 and which the step fixes.

      This is setup, not conjecture — every field is a definitional property of the identity braid, discharged in any intended model.

      • trM : H → S

        The Markov trace tr_M : H_n(q) → 𝒮(q), sending braid words to Jones polynomials.

      • step : H → H

        One application of the Skein-Collatz operator 𝒞_q.

      • identity : H

        The identity braid.

      • trM_identity : self.trM self.identity = 1

        Its trace is the unknot value.

      • identity_fixed : self.step self.identity = self.identity

        The step fixes it.
