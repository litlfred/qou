    §1 — the upper bound is already a theorem #

    birthday (n : K) ≤ n follows from birthday_one and birthday_add_le alone. Stating it makes the asymmetry visible: the axioms give the ≤ and nothing gives the ≥.

    source
    theorem QOU.AppendixSurreals.birthday_natCast_le {K : Type u} [SurrealField K] (n : ℕ) :
    SurrealField.birthday ↑n ≤ ↑n

    birthday (n : K) ≤ n, from the existing axioms.

    Induction: birthday (n+1) ≤ birthday n ♯ birthday 1 = birthday n ♯ 1 = succ (birthday n), and succ is monotone. Nothing here needs a new axiom — which is the point.

    §2 — the missing lower bound, as an opt-in mixin #

    source
    class QOU.AppendixSurreals.BirthdayFaithful (K : Type u) [SurrealField K] :
    Prop

    BirthdayFaithful — the one equation the six SurrealField axioms cannot supply: the natural numbers are born on the day their value names.

    A mixin, deliberately. SurrealField is used across ~38 modules and most of them do not reason about birthdays; requiring this of all of them would be noise. Carrying it separately also makes the dependency legible — a result that needs genuine birthday content takes [BirthdayFaithful K], and one that does not, does not.

    Combined with birthday_natCast_le (§1, which needs no mixin) this pins birthday n exactly; the mixin supplies only the half that was missing.

    • birthday_natCast (n : ℕ) : SurrealField.birthday ↑n = ↑n

      Conway: the natural number n is born on day n.

      §3 — the mixin is a GENUINE strengthening #

      If BirthdayFaithful followed from the six existing axioms it would be satisfied by every model of them, including the flat one. It is not.

      source
      theorem QOU.AppendixSurreals.flatBirthday_not_faithful :
      ¬∀ (n : ℕ), HyperrealTransfer.flatBirthday ↑n = ↑n

      The flat model fails the mixin, at n = 2.

      flatBirthday assigns 1 to every nonzero element, so flatBirthday (2 : ℝ*) = 1 ≠ 2. Since flatBirthday does satisfy all six birthday axioms (HyperrealLimitTransfer.surrealFieldHyperreal), this shows BirthdayFaithful is not derivable from them.

      source
      theorem QOU.AppendixSurreals.birthdayFaithful_independent_of_surrealField_axioms :
      (∃ (x : SurrealField ℝ*), True) ∧ ¬∀ (n : ℕ), HyperrealTransfer.flatBirthday ↑n = ↑n

      Summary, as a single statement. The six birthday axioms are satisfiable together with the negation of the mixin — witnessed by flatBirthday on ℝ* — so the mixin adds strictly new content.

      source
      theorem QOU.AppendixSurreals.birthdayFaithful_independent_witnessed :
      ∃ (S : SurrealField ℝ*), ¬∀ (n : ℕ), SurrealField.birthday ↑n = ↑n

      Independence, with the two halves actually joined.

      ⚠ The conjunction above is weaker than its name, and the gap is easy to miss. Its first conjunct says some SurrealField structure exists on ℝ*; its second says flatBirthday fails the mixin. Nothing in the statement says these concern the same structure — read literally it would be satisfied by an unrelated witness for each half, which is not independence.

      This is the honest form: one structure, satisfying all six axioms, whose own birthday fails the mixin. It is what the earlier docstring already claimed ("witnessed by flatBirthday on ℝ*") and what the conjunction did not say.

      The proof is unchanged because surrealFieldHyperreal.birthday is flatBirthday by definition — so the content was always there, and only the statement was loose. That is precisely why it was worth tightening rather than leaving as a comment: a reader checking the theorem, not the field assignment, could not have known.
