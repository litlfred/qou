    QOU.AppendixSurreals.StandardPart — Robinson's standard-part map #

    The map st : No_fin → ℝ sending each finite surreal to the unique real with infinitesimal difference. Standard-part is a surjective ring homomorphism whose kernel is the infinitesimals.

    This module provides:

    • standardPart : K → ℝ (zero on non-finite inputs by convention)
    • ring-hom properties on the finite subring
    • the kernel characterisation

    References #

    • [robinson1966] Robinson, Non-standard Analysis, §3.2.
    • [alling1987] Alling, Foundations of Analysis over Surreal Number Fields, North-Holland.

        Subring packaging of the finite surreals #

        The set { x : K | IsFinite x } is a Subring K, and the standard-part map is a ring homomorphism out of it. This lets downstream development quote standardPart as a Mathlib RingHom without re-proving _add/_mul at every call site.

            Surreal proximity (IsClose) #

            Two surreals are close if their difference is infinitesimal. This is an equivalence relation on K, and standardPart is constant on its equivalence classes (over the finite subset).

            This is a baby pre-uniformity layer: the IsClose-equivalence-class of x is precisely the monad of x (in non-standard-analysis parlance), and the standard-part map factors uniquely through the quotient.

                Algebraic closure properties of IsClose #

                IsClose is preserved by negation, addition, and (under a finiteness assumption) multiplication. These lemmas mirror the arithmetic of the monad in non-standard analysis.
