    QOU.AppendixSurreals.Blowup — Named infinite/infinitesimal surreals #

    The first infinite surreal ω and the first positive infinitesimal ε = 1/ω live as members of the SurrealField typeclass (see Basic.lean). This module derives the basic relations.

    The full theory of named infinities (ω², ω^ω, hyperseries) is substantial [@conway1976; @ehrlich2012] and is left to mathlib's ordinal-arithmetic development. Here we only need the named endpoints used by the appendix's blow-up calculus.

    References #

    • [conway1976] Conway, On Numbers and Games, §0.
    • [ehrlich2012] Ehrlich, The absolute arithmetic continuum, Bull. Symbolic Logic 18 (2012) 1–45. https://doi.org/10.2178/bsl/1327328438

        The blow-up calculus #

        A small bundle exposing the named-surreal cutoff ω, the corresponding infinitesimal unit ε = 1/ω, and the renormalisation operator renormalise X C := st (X - C) that strips a counter-term and projects to the real numbers. This is the Lean form of def:surreal-blowup-calculus.

            ℝ

            Renormalisation: subtract a counter-term C from a surreal-valued divergent expression X, then project to ℝ via standardPart. The result is 0 whenever X - C is not finite — i.e. when the counter-term failed to absorb the divergence.
