    structure QOU.AppendixSurreals.Bracketed (st : GonshorState) :
    Prop

    The bisection regime: both bounds exist, the value lies strictly inside them, and — the clause that does the work — the value is the midpoint of its own bracket.

    GonshorState.step re-establishes this at every step, which is why the bracket halves.

    • hasLo : st.hasLo = true
    • hasHi : st.hasHi = true
    • mid : st.value = (st.lo + st.hi) / 2
    • lt : st.lo < st.hi

            The bridge, in one statement. For any real α, once its expansion has bracketed, k further signs approximate α to within gap / 2ᵏ.

            This is what conj:diophantine-birthday's "birthday trajectory" needs on the surreal side: prefix length controls approximation quality, the denominator is exponential in the prefix length, and the target is a genuine given real rather than the expansion's own bracket.

            Runs, and why they are where the Liouville exponent lives #

            expansion_approximates gives error gap / 2ᵏ at a state whose own denominator has also grown by 2ᵏ. That is error ≈ 1/q — approximation exponent 1, which LiouvilleWith.liouvilleWith_one gives for every real for free. So the bracket rate on its own certifies nothing, and it would be easy to mistake it for progress.

            The exponent lives in the run structure. A + step keeps hi and raises lo; a - step keeps lo and lowers hi. So a run of k identical signs freezes one endpoint while the bracket keeps halving — leaving a rational fixed at step n, with denominator from step n, that approximates α to accuracy 2⁻ᵏ better. Error 1/q^{(n+k)/n} rather than 1/q: the exponent is the run length relative to the prefix length, which is exactly the shape of a Liouville condition.

            The denominator invariant — what turns a run into an exponent #

            run_plus_approximates says α is within gap / 2ᵏ of st.hi. To read that as an approximation exponent one needs st.hi as m / q with q known, and GonshorState stores bare ℚ with no denominator information at all. This supplies it: every bound after n steps is a dyadic with denominator dividing 2ⁿ.

            Both regimes preserve it, for different reasons — the unbounded ±1 moves keep the denominator exactly, and the bisecting moves at worst double it.

                theorem QOU.AppendixSurreals.expansion_run_approximates (α : ℝ) (n k : ℕ) (hb : Bracketed (expandState α n)) (hrun : ∀ j < k, ↑(expandState α (n + j)).value < α) :

                From a run to an approximation exponent #

                expansion_run_approximates bounds the error by gapₙ / 2ᵏ against a denominator 2ⁿ. Reading that as an exponent means comparing it to 1 / (2ⁿ)ᵗ, which needs the run length k measured against n rather than absolutely: k ≥ n·t is exactly what buys exponent t.

                ⚠ gapₙ ≤ 1 is taken as a hypothesis rather than derived. It is always true at the first bracketed step — an unbounded + sets lo := value and value := value + 1, so the following - bisects an interval of width exactly 1, and every later gap is smaller — but proving "the first bracketed step" requires reasoning about when the bounds first appear, which is a separate induction and not needed for the statement below.
