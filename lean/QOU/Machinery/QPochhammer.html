    Finite q-Pochhammer (a;q)_n #

    Base ring is a generic [CommRing R] per AGENTS.md §7c: the q-Pochhammer symbol and its recursion are purely algebraic (q ^ k is Monoid.npow, k : ℕ), with no archimedean construct. The archimedean specialisation R := ℝ at the substrate q₀ happens at the consumer sites. Only the Gaussian q-binomial (which divides) needs [Field R].

    source

    Finite q-Pochhammer (a;q)_n = ∏_{k=0}^{n-1} (1 - a·q^k).

      Diagonal q-Pochhammer (q;q)_n, defined as qPochhammerFinite q q n = ∏_{k=0}^{n-1} (1 - q·q^k). Note this equals the textbook form ∏_{k=0}^{n-1} (1 - q^(k+1)) (provably, via q·q^k = q^(k+1)), but the two are not definitionally equal — we keep the q·q^k form so that qPochhammerDiag reuses qPochhammerFinite directly.

        Gaussian q-binomial [n choose k]_q #

        The standard form [n k]_q = (q;q)_n / ((q;q)_k · (q;q)_{n-k}). Currently a placeholder; promotion to derived requires the q-binomial theorem and Pascal-type recursion (q-deformed).

        Normalization note (bean 5ldf consolidation, 2026-06-26). This is the standard (q;q) q-binomial — a distinct object from the QOU-canonical balanced QOU.MathlibExt.QPartitionCombinatorics.qBinom ((qⁿ−q⁻ⁿ)/(q−q⁻¹) brackets): e.g. [2 choose 1] is 1+q here vs q+q⁻¹ there. The two are NOT interchangeable; pick by which bracket convention the caller needs. (The balanced one has the proved q-Pascal qBinom_pascal.)
