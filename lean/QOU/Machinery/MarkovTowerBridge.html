    Discharging the cyclicity bricks against the Ocneanu tower #

    QOU.Machinery.MarkovInductive.cyclic_two_g proves the two-generator Ocneanu cyclicity step from seven hypotheses about an abstract (memB, E, tr). Seven assumed hypotheses is a weak result: the more a conditional theorem assumes, the less its conclusion says, and nothing in that file forces the hypotheses to describe a Hecke tower rather than an arbitrary triple that happens to satisfy them.

    This file supplies the tower and derives four of the seven from the W2 interface (QOU.Machinery.HeckeTower.HeckeConditionalExpectation, bean qou-2017), leaving hIH — the induction hypothesis, which is what an induction is for — and hgwg, the Markov reduction of a two-generator word.

    The instantiation is the obvious one:

    brick tower
    A Hn1, the level-n+1 algebra
    memB x ∃ y, x = ι y — the image of Hn under the tower inclusion
    E ι ∘ ε — conditional expectation, viewed back inside Hn1
    tr trn ∘ ε — a level-n trace pulled up through ε
    memBlow memB (see the note below)

    What is actually derived, and what is not #

    hCE is the one with content. Everything else is bookkeeping about the image of an algebra map; hCE says the trace cannot distinguish a * x from a * E x for a in the subalgebra, which is the property that makes ε a conditional expectation rather than an arbitrary retraction. It follows from bimodule and retract together, and towerTrace_mul_eq_of_memB is the proof.

    Note that it is derived only because tr was defined as trn ∘ ε. For a trace not of that form hCE is a genuine assumption, and this file would not apply — which is the honest content of the reduction: it converts "assume the trace is compatible with ε" into "define the trace through ε".

    Scope — what this does NOT close #

    HeckeConditionalExpectation has no instance, and this file does not build one. It is a §3b dependent conjecture carrier, so every result here is conditional on it in exactly the way its own file says. Conditional-proved is not premise-established. What changed is the size of the conditional: four hypotheses that were free parameters are now consequences of one named, content-bearing class.

    memBlow is instantiated as memB, not as a genuinely lower level. That is sound — cyclic_two_g uses memBlow only through hElow/hlowB/hCE, and all three hold — but it means this file does not exercise the two-level structure the abstract statement allows. A tower with H_{n-1} ⊊ H_n would need a second ε; nothing here depends on the difference.

          Arbitrary w, via the spanning decomposition #

          cyclic_two_g's hgwg is stated for a w the caller has ALREADY put into coset-sum form. That is the weaker half of the assumption: it silently requires the caller to know a decomposition exists. HeckeCosetSpanning supplies exactly that, so the reduction below runs on an ARBITRARY w : Hn.

          What it yields is the hgwg equation with the expectation Ew exhibited, built from the decomposition, rather than assumed equal to ι (ε w). Closing that last gap — Ew = ι (ε w) — needs the Markov property of the conditional expectation, ε (b · σₙ · c) = z • (b·c), which is NOT a field of HeckeConditionalExpectation (it has exactly retract and bimodule). So this section does not close it, and says so rather than adding a field and calling the assumption discharged.

          The hgwg reduction for an arbitrary w. Given the spanning decomposition and the two grounding shape lemmas — one for the lower-coset summand, one for the middle — the two-generator Markov reduction holds for EVERY w : Hn.

          The conclusion pins the witness to the decomposition: it asserts both that w splits and that the reduction holds with the expectation built from that split. A bare ∃ Ew, … would have been weaker in a way that matters here — a degenerate trace (tr = 0, the case markov_axioms_vacuous_of_weight_zero already records upstream) satisfies ∃ Ew for any Ew at all, so the existential alone would carry no information about the coset structure. Tying the two conjuncts together is what stops the statement being satisfiable by a lucky witness.

          The grounding hypotheses are the genuine mathematical input; the decomposition is what lets them cover every w rather than only pre-decomposed ones.

          The conditional-expectation instance is load-bearing #

          A "reduction" that quietly assumed its conclusion would compile exactly as happily as this one, so the claim is checked rather than asserted. simp fails to close hCE with the instance removed, which is weak evidence; the section below is the decisive form — with a linear ε that is NOT a conditional expectation, the hCE identity is false, not merely unproved.

          Keep this section. It is what stops a later reader "simplifying" the theorem by dropping an instance that looks decorative in the statement.
