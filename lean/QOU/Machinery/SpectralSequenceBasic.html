    Abstract (p,q)-graded spectral-sequence page #

    source
    structure QOU.Machinery.SpectralSequencePage :
    Type (u_1 + 1)

    Spectral sequence page at level r: a (p, q)-graded object E r p q together with a differential d r : E r p q → E r (p+r) (q+1-r).

    Encoded type-level only; the actual Mathlib spectral-sequence infrastructure would land in Mathlib.Algebra.Homology.SpectralSequence when categorified upstream. (A base ring is intentionally NOT a parameter — the pages are bare graded types at this scaffold level; an R-linear refinement is future work.)

    • E : ℕ → ℤ → ℤ → Type u_1

      The page indexed by level r, position (p, q).

    • d (r : ℕ) (p q : ℤ) : self.E r p q → self.E r (p + ↑r) (q + 1 - ↑r)

      The differential at level r (positions are ℤ; the level shift r is cast to ℤ explicitly to avoid mixed ℕ/ℤ addition).
