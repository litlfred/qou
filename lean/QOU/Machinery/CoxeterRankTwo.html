    Rank-two words: reduced words over two letters are alternating #

    Matsumoto's theorem reduces, by the classical Tits argument, to one statement about a rank-two parabolic: if i and j are both right descents of w, then w has a reduced word whose tail is the alternating block of length M i j. This file develops the rank-two half of that.

    What is here #

    • not_isReduced_concat_self — a reduced word has no two adjacent equal letters, because s c s c = 1 deletes them.
    • isReduced_pair_eq_alternatingWord — hence a reduced word all of whose letters lie in {i, j} is one of the two alternating words of its length. This is what makes the rank-two case finite-dimensional: there are at most two reduced words of each length.
    • exists_word_of_mem_parabolic / exists_reducedWord_of_mem_parabolic — every element of W_J is the product of a J-word, and a J-word of minimal length is ambient-reduced. The second is where CoxeterDeletion.exists_deletion is spent: without it, a shorter J-word need not exist and the parabolic could a priori sit non-isometrically inside W.
    • pow_eq_one_of_alternatingWord_eq — if the two alternating words of length k have the same product then (s i s j)^k = 1. This is the bridge from words to the order of s i s j, which is the one genuinely missing input (see below).

    🛑 The input this file does NOT supply #

    QOU.Machinery.CoxeterGeometricRepresentationFull states its own honesty note: it proves simple-injectivity but not "the order of σᵢσⱼ being exactly mᵢⱼ". That is precisely the predicate DihedralExact isolated here, and it is left as an explicit hypothesis rather than assumed — it is discharged for M i j ≤ 3 in CoxeterDihedralDescent, which covers type A.

    Reduced two-letter words are alternating #

    source
    theorem QOU.Machinery.CoxeterRankTwo.isReduced_pair_eq_alternatingWord {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) {i j : B} (ω : List B) :
    cs.IsReduced ω → (∀ l ∈ ω, l = i ∨ l = j) → ω = CoxeterSystem.alternatingWord i j ω.length ∨ ω = CoxeterSystem.alternatingWord j i ω.length

    The rank-two structure theorem. A reduced word whose letters all lie in {i, j} is one of the two alternating words of its length — so a rank-two parabolic has at most two reduced words per length, which is what makes the dihedral analysis finite.

    theorem QOU.Machinery.CoxeterRankTwo.exists_reducedWord_of_mem_parabolic {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) {J : Set B} {v : W} (hv : v ∈ CoxeterParabolic.parabolic cs J) :
    ∃ (p : List B), (∀ l ∈ p, l ∈ J) ∧ cs.IsReduced p ∧ cs.wordProd p = v

    The parabolic embeds isometrically. An element of W_J has a J-word that is reduced in the ambient system — so its W_J-length and its W-length agree.

    This is where the deletion condition is spent: a J-word that is not ambient-reduced admits a two-letter deletion, and the result is again a J-word, so a minimal-length J-word is reduced.

    s j · s i is the inverse of s i · s j.

    source
    theorem QOU.Machinery.CoxeterRankTwo.pow_eq_one_of_alternatingWord_eq {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) {i j : B} {k : ℕ} (h : cs.wordProd (CoxeterSystem.alternatingWord i j k) = cs.wordProd (CoxeterSystem.alternatingWord j i k)) :
    (cs.simple i * cs.simple j) ^ k = 1

    The two spellings agree only at a power that is trivial. If the two alternating words of length k have the same product, then (s i s j)^k = 1.

    This is the step that converts the word-level ambiguity into a statement about the order of s i s j, and it is the reason DihedralExact below is exactly the input Matsumoto needs.

    The missing input, isolated #

    source
    def QOU.Machinery.CoxeterRankTwo.DihedralExact {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) :
    Prop

    s i · s j has order exactly M i j. One direction — (s i s j)^{M i j} = 1 — is the defining relation and holds always; what this predicate adds is that no smaller positive power is trivial.

    CoxeterGeometricRepresentationFull proves simple-injectivity and says in its own honesty note that it does not prove this. It is therefore carried as a hypothesis and discharged where it can be: M i j ≤ 3, which is every off-diagonal entry of type A.
