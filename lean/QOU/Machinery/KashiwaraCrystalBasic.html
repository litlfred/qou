    structure QOU.Machinery.CrystalGraph :
    Type (u_1 + 1)

    Kashiwara crystal graph structure: a type V of vertices, with partial endomorphisms f i : V → Option V and e i : V → Option V indexed by simple-root labels i : ℕ.

    • V : Type u_1

      The vertex set.

    • f : ℕ → self.V → Option self.V

      Lowering operator f i v (Option-valued for partiality).

    • e : ℕ → self.V → Option self.V

      Raising operator e i v (Option-valued for partiality).

          Crystal morphisms #

          source
          structure QOU.Machinery.CrystalHom (G : CrystalGraph) (G' : CrystalGraph) :
          Type (max u_1 u_2)

          A morphism of crystal graphs: a vertex map toFun commuting with both the lowering (f) and raising (e) operators. Bundling the two morphism laws as separate fields keeps downstream rewriting smooth.

          • toFun : G.V → G'.V

            The underlying vertex map.

          • map_f (i : ℕ) (v : G.V) : Option.map self.toFun (G.f i v) = G'.f i (self.toFun v)

            toFun commutes with lowering: f i then map = map then f i.

          • map_e (i : ℕ) (v : G.V) : Option.map self.toFun (G.e i v) = G'.e i (self.toFun v)

            toFun commutes with raising: e i then map = map then e i.

            Conditional classes for the Stembridge axioms + type-A specialisation #

            source
            class QOU.Machinery.StembridgeCrystal (G : CrystalGraph) :
            Prop

            Conditional class carrying the foundational crystal axiom. NEAR-MATCH tier. The reversibility field is inhabitable by a genuine crystal — see the standardSl2Crystal instance below; the full Stembridge S1–S8 instance still requires upstream Mathlib crystal-graph machinery.

            The single field encodes the Kashiwara reversibility law, not the full Stembridge S1–S8 (whose additional string-length / interplay conditions would further constrain an instance) — hence the field is named reversibility rather than stembridge_axioms.

            • reversibility (i : ℕ) (v w : G.V) : G.f i v = some w ↔ G.e i w = some v

              The foundational Kashiwara crystal axiom presupposed by the full Stembridge S1–S8: for every simple-root label i, the raising and lowering operators e i, f i are mutually inverse partial maps — f i v = some w ↔ e i w = some v. (No longer True.)

                class QOU.Machinery.DemazureSubcrystal (G : CrystalGraph) (level : ℕ) :
                Type u_1

                Conditional class for Demazure module identification: a Demazure sub-crystal at level level corresponds to a Weyl-group word. The sub-crystal is carried as a predicate member with a distinguished highest-weight generator (highest, pinned by highest_isHighest as an actual highest-weight vertex — annihilated by every raising operator); demazure_closure states the defining Demazure property (closed under the first level lowering operators — the Weyl-word support).

                • member : G.V → Prop

                  Membership predicate cutting out the Demazure sub-crystal.

                • highest : G.V

                  The distinguished highest-weight vertex generating the sub-crystal.

                • highest_mem : member level (highest level)

                  The generator lies in the sub-crystal.

                • highest_isHighest (i : ℕ) : G.e i (highest level) = none

                  highest really is highest-weight: every raising operator annihilates it (e i highest = none).

                • demazure_closure (i : ℕ) : i < level → ∀ (v w : G.V), member level v → G.f i v = some w → member level w

                  Demazure closure (was True): the sub-crystal is closed under lowering by the first level simple roots — exactly the operators in the support of the length-level Weyl word.

                  source
                  instance QOU.Machinery.instSl2DemazureSubcrystal :
                  DemazureSubcrystal standardSl2Crystal 1

                  B(Λ₁)'s level-1 Demazure sub-crystal — which happens to be everything.

                  sl₂ has one simple root, so W = {e, s₀} and B(Λ₁) has exactly two Demazure sub-crystals: B_e(Λ₁) = {u_Λ} at length 0, and B_{s₀}(Λ₁) = {u_Λ, f₀ u_Λ} at length 1 — and the second is the whole two-vertex crystal. So member := fun _ => True is the correct value here, not a shortcut: the level-1 sub-crystal of B(Λ₁) really is all of it.

                  What that costs, and why it was flagged (2026-08-24, bean qou-uno5). This docstring used to call the witness "a genuine DemazureSubcrystal … closed under lowering", which reads as though closure had been checked. It has not: with member ≡ True both the hypothesis and the conclusion of demazure_closure are trivially inhabited, so the field closes by trivial — exactly the strength it had when it was literally True, before someone strengthened it into the real closure condition. The strengthening bought nothing while this was the only inhabitant. It is not any more: sl3DemazureLevelOne below is a proper sub-crystal whose closure has to be verified, and sl3LevelOne_not_closed_at_level_two proves the field can fail.

                  highest_isHighest is the one field this witness does exercise — e i false = none for every i is checked, not assumed.

                  Still a global instance, and correctly so: DemazureSubcrystal standardSl2Crystal 1 is a fact about a concrete two-vertex crystal, not a conjecture, so resolution supplying it is sound. Read it as "the whole crystal at the longest Weyl word", never as evidence about Demazure closure in general.

                  A rank where the Demazure condition has teeth #

                  The two-vertex sl₂ crystal cannot separate a proper Demazure sub-crystal from the whole crystal at level = 1: with one simple root, the length-1 Weyl word already sweeps everything. Three vertices and two simple roots can, so the closure field is tested here rather than left untested (bean qou-uno5).

                  abbrev QOU.Machinery.standardSl3Crystal :
                  CrystalGraph

                  The standard sl₃ crystal B(Λ₁): three vertices in a string 0 -f₀→ 1 -f₁→ 2, with the matching e-inverses. Vertex 0 is the highest-weight vector; there are two simple roots, labelled 0 and 1.

                  An abbrev rather than a def (unlike standardSl2Crystal) so that standardSl3Crystal.V reduces to Fin 3 at reducible transparency and instance search finds OfNat / DecidableEq / Fintype on the vertices — which is what lets the closure obligations below be discharged by decide. The sl₂ crystal needs none of this: its vertices are Bool, whose two literals are constructors rather than numerals.

                      Conditional theorem: residue-A composite identification #

                      If a crystal G carries all three classes above, then the crystal operator f_1^2 acting on the trefoil-image vertex would produce the empirical c_2 = -1 Taylor coefficient (this is the proven content of QBetaCategoricalPrecisionLadder.lean). The composite operator f_1^2 · q-Pochhammer-evaluation is the path D candidate.
