      theorem QOU.Machinery.CoxeterParabolic.tauAssignment_swap_no_target_transition {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) {i j : B} (hm : M.M i j = 3) (hm' : M.M j i = 3) (hne : cs.simple i ≠ cs.simple j) :
      ¬∃ (T : (Fin 4 → ℂ) → Fin 4 → ℂ), ∀ (v : W → ℂ), (tauAssignmentAtRank cs j i hm' ⋯).toFun v = T ((tauAssignmentAtRank cs i j hm hne).toFun v)

      The swap edge admits NO transition map on the isotypic target: there is no function T — linear or otherwise — with τ_{(j,i)} = T ∘ τ_{(i,j)}. The witness state (coefficients −I at the identity and 1 at σᵢ) lies in the kernel of the (i,j)-assignment but not of the (j,i)-assignment, so the swap transition exists only at cell level (cellRestrict_swap) and provably does not descend.
