    structure QOU.Machinery.HeckeGeneral.DescentStructure (W : Type u_1) :
    Type u_1

    A descent structure on an index type W: an involutive step map (right multiplication by a fixed generator) together with a rank function the step never fixes. Every Coxeter system gives one on each simple reflection (t := (· * sᵢ), ℓ := length); the finite rungs n = 3, 4 give them by explicit tables (below).

    • t : W → W

      The step map u ↦ u·s (right multiplication by the generator).

    • len : W → ℕ

      The rank (length) function.

    • t_invol (u : W) : self.t (self.t u) = u

      The generator is an involution: u·s·s = u.

    • len_ne (u : W) : self.len (self.t u) ≠ self.len u

      The step never fixes the rank: ℓ(u·s) ≠ ℓ(u).
