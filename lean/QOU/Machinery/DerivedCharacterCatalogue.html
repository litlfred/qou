            source
            structure QOU.Machinery.KnotPartitionAtomCell :
            Type

            A catalogue cell identifies a (knot K, partition λ, atom A) triple and stores the derived character data plus provenance.

            This is the Lean schema mirror of the Python KnotPartitionAtomCell dataclass. Fields are kept as primitive types (strings, integer lists, etc.) so the schema can be ported across the Python/Lean boundary without bringing in heavy algebra.

            • knot : String

              Knot operator name (from the PR #1677 census or atom-braid prefix).

            • partition : List ℕ

              Partition λ ⊢ n_K as a non-increasing list of positive ints.

            • atom : String

              QOU atom / observable target (e.g. "borromean-baryon", "5Li").

            • braidWord : String

              Canonical braid word for K in B_{n_K}, as a pretty string.

            • strandCount : ℕ

              n_K, the strand count of the braid representative.

            • chiLambdaQLaurent : List (ℤ × String)

              χ^λ(β_K)(q) as a Laurent in q: list of (q_degree, coefficient_string) pairs. Negative q_degree allowed. Convention stored in qConvention.

            • qConvention : QConvention

              Variable convention for chiLambdaQLaurent.

            • kLambda : ℕ

              Per-partition truncation order k_λ per prop:per-partition-k-lambda-rule.

            • tier : Tier

              Provenance tier (see Tier).

            • derivationRef : String

              Citation: commit-sha or audit-doc path of the structural derivation.

              Conditional class — R-matrix derivation #

              §3b-cond pattern: cells whose χ^λ was computed via the R-matrix template (T17 / PR #1933) carry this class. The instance is the proof that the cell's stored data agrees with the R-matrix output. NEAR-MATCH tier; instance fully verified only once a complete parabolic-restriction proof is in place.

              source
              class QOU.Machinery.IsRMatrixDerived (R : Type u_1) [CommRing R] (cell : KnotPartitionAtomCell) :
              Type u_1

              A cell is R-matrix-derived when its stored χ^λ (as a genuine ℚ → ℚ Laurent evaluation, storedChi) agrees, away from q = 0, with the categorical R-matrix character rmatrixChi obtained from the T17 template (R-matrix on V⊗ⁿ + Schur-Weyl projection to the λ-block + trace).

              This is a genuine §3b-cond conditional class — its fields carry real R → R data (generic over a field R, §7c) and a real equality Prop, not an opaque True marker. The instance for borromeanTwoOneBaryon is fully discharged (no sorry): agrees is the proven theorem borromeanTwoOneBaryonChi_eq_t17, which reuses T17's chi21_borromean_qform_eq_hform.

              HONESTY (mirrors the BorromeanChiPerRep.lean scope note): the proven content is storedChi = rmatrixChi at the level of q-rational forms. That rmatrixChi is itself the categorical R-matrix trace (rather than just the published h-polynomial) is, at the time of writing, NARRATIVE-ONLY for the seminormal Hecke-representation step — it is independently confirmed numerically (≤ 4e-50) by borromean_chi_independent_crosscheck.py. The class therefore certifies the catalogue cell against the formalised T17 polynomial, not against an in-Lean construction of the seminormal representation.

              • storedChi : R → R

                A genuine R → R evaluation of the cell's stored Laurent chiLambdaQLaurent (in the Kauffman variable). Generic over a field R per §7c — no ordering / Real.* is involved, only the inverses the Laurent needs.

              • rmatrixChi : R → R

                The categorical R-matrix character χ^λ(β_K) this cell realises, as a q-rational function (T17 template).

              • agrees (q : R) : q ≠ 0 → storedChi cell q = rmatrixChi cell q

                The stored Laurent agrees with the R-matrix character at every nonzero q.

                      Phase-2 cells (B_2 + B_3) — monomial / palindromic instances #

                      The Phase-2 sympy build (derived_chi_catalogue_build.py) emits cells for Hopf, Trefoil, Cinquefoil (B_2) and Figure-eight (B_3) alongside the Borromean. Their χ^λ characters are either:

                      • monomial in q (B_2 trivial / sign reps, single-rep cells of 4₁)
                      • palindromic q-polynomial (Figure-eight (2,1) at (σ_1·σ_2⁻¹)^2)

                      For the monomial cases, the R-matrix derivation IS the closed form (the trivial / sign 1-dim Hecke rep evaluated at σ_1^k gives q^k / (−q⁻¹)^k directly). So storedChi = rmatrixChi is definitionally true, and the agrees field reduces to fun _ _ => rfl.

                      For Figure-eight (2,1) the chi is a polynomial; we record the stored Laurent and use the same self-referential identity (storedChi = rmatrixChi trivially), with a follow-up TODO to link to a separate published-form proof once the Figure-eight R-matrix derivation lands as a content block.

                                                          Kind-2 Laurent reframe — division-free unit forms over ℤ[q, q⁻¹] #

                                                          The five dividing characters above (/q^k) carry [Field R] because the class field IsRMatrixDerived.storedChi : R → R cannot express q⁻¹ without inversion.
