    The dihedral descent lemma — the heart of Matsumoto's theorem #

    If i and j are both right descents of w, then w has a reduced word whose tail is the alternating block of length M i j — in both spellings. One braid move at that tail therefore converts a reduced word for w ending in i into one ending in j, which is the step the Tits induction turns on.

    The argument #

    Cut w = u · v with u the minimal representative of w W_J, J = {i, j} (CoxeterParabolic.exists_minRep, length_minRep_mul_wordProd'). Length is additive across the cut, so both descents pass to v, and the whole question moves into the rank-two parabolic.

    There CoxeterRankTwo takes over. A reduced word for v over two letters is alternating, and a descent at c means some reduced word ends in c — so both alternating spellings of length k = ℓ(v) are reduced words for v. Two spellings with one product force (s_i s_j)^k = 1; the word is reduced so k ≤ M i j; the descents make k ≥ 1. Exactness of the dihedral order closes the interval and k = M i j.

    Both side conditions are now DERIVED, not assumed #

    These statements used to carry two hypotheses, DihedralExact cs and M i j ≠ 0. QOU.Machinery.CoxeterDihedralOrder discharges both from the geometric representation, and this file spends that input rather than propagating the hypotheses:

    • dihedralExact_full — the Chebyshev/cosine argument: ⟨αᵢ, (fᵢfⱼ)^k αᵢ⟩ = cos(2πk / m), which is 1 only at k = 0 in the range 0 < k < m.
    • bond_ne_zero_of_pow_eq_one — the infinite-bond half: at m = 0 the rotation is a shear whose αᵢ-coefficient is 1 + 2k, so (σᵢσⱼ)^k = 1 with k > 0 is impossible. That is exactly what refutes the M i j = 0 branch here, where the old hm hypothesis excluded it by fiat.

    Consequence: the whole Matsumoto/Bruhat arc downstream of this file is unconditional for every Coxeter system, not only type A and not only the finite-bond ones.

    dihedralExact_le_three is kept below. It is now superseded as an input — nothing in the arc needs it — but it is a genuinely different and much more elementary proof of the M i j ≤ 3 case, resting only on CoxeterGeometricRepresentationFull's two unconditional cell-faithfulness results with no trigonometry.

    The descent lemma proper #

    source
    theorem QOU.Machinery.CoxeterDihedralDescent.exists_reduced_alternating_tail {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) {i j : B} (hij : i ≠ j) {w : W} (hi : cs.IsRightDescent w i) (hj : cs.IsRightDescent w j) :
    0 < M.M i j ∧ ∃ (l₁ : List B), cs.IsReduced (l₁ ++ CoxeterSystem.alternatingWord i j (M.M i j)) ∧ cs.wordProd (l₁ ++ CoxeterSystem.alternatingWord i j (M.M i j)) = w ∧ cs.IsReduced (l₁ ++ CoxeterSystem.alternatingWord j i (M.M i j)) ∧ cs.wordProd (l₁ ++ CoxeterSystem.alternatingWord j i (M.M i j)) = w

    The dihedral descent lemma. If i and j are both right descents of w, then the bond order M i j is finite and positive, and w has a reduced word whose tail is the alternating block of length M i j — in both spellings, with the same prefix. A single braid move at that tail moves between them.

    The 0 < M i j conjunct is derived, not assumed: two distinct descents give (σᵢσⱼ)^k = 1 for k = ℓ(v) > 0, and CoxeterDihedralOrder.bond_ne_zero_of_pow_eq_one refutes that at an infinite bond. It is returned rather than left to the caller because the caller needs it to split off the tail's last letter.

    DihedralExact for M i j ≤ 3 — an elementary proof, no longer load-bearing #

    theorem QOU.Machinery.CoxeterDihedralDescent.dihedralExact_le_three {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) (hle : ∀ (i j : B), M.M i j ≤ 3) :
    CoxeterRankTwo.DihedralExact cs

    s_i s_j has order exactly M i j whenever M i j ≤ 3.

    Both cases come from CoxeterGeometricRepresentationFull's unconditional cell faithfulness: [i, j] reduced at M i j = 2 and [i, j, i] reduced at M i j = 3. If a smaller power were trivial the corresponding word would collapse to something of length ≤ 1.

    Superseded as an input by CoxeterDihedralOrder.dihedralExact_full, which proves the same predicate for every M i j. Kept because the argument is independent and elementary — no trigonometry, no Chebyshev recursion — so it is a cheap cross-check on the general result at the only bond orders type A ever uses.
