    QOU.Machinery.HeckeH4WedderburnInv — left/right inverse of the rank-4 coordinate map #

    Wedderburn tranche W3 (capstone) (bean qou-308a; design doc §4): the corollaries the assembly file HeckeH4Wedderburn consumes, derived from the Lean-verified matrix identities of HeckeH4WedderburnMul* through the mulVec glue of HeckeH4WedderburnCoord:

    • wedderburnInvV₄_left — the coordinate left inverse (injectivity input): the inverse formulas recover every NF coordinate from the character/block component tuple;
    • homVec_wedderburnInvV₄ + the five component right-inverse lemmas chiNF₄_wedderburnInvV₄_plus/_minus, blockOf22/31/211_wedderburnInvV₄ (surjectivity input).

    Genericity hypotheses (read off $\det A = -(q^2+1)^{24}(q^4+1)^{10} (q^2-q+1)^3(q^2+q+1)^3/q^{50}$): q ≠ 0, q ^ 2 + 1 ≠ 0, q ^ 4 + q ^ 2 + 1 ≠ 0, q ^ 4 + 1 ≠ 0 — note the new [4]-type condition q ^ 4 + 1 ≠ 0 absent at rank 3. Over $\mathbb{R}$ all four denominators are positive for q ≠ 0, so only q ≠ 0 survives.

    HONESTY (STRICT, §"Axiomatization is NOT a Proof"): every lemma is discharged by computation — no axiom, no sorry, no conditional class, no native_decide; the sympy cofactors are payloads, re-verified by Lean's linear_combination kernel check.

    Base ring (§7c): generic [Field K] — inverses are genuinely used; no archimedean construct.

    -- Ref: [wenzl1988] https://doi.org/10.1007/BF01239526 -- Ref: [jones1987] https://doi.org/10.2307/1971403
