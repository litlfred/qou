    Proved layer — the Jones projection from the quadratic alone #

    noncomputable def QOU.Machinery.HeckeTower.jonesIdempotent {R : Type u_1} [Field R] {H : Type u_2} [Ring H] [Algebra R H] (q : R) (s : H) :
    H

    The Jones projection attached to a Hecke generator: the normalized −q⁻¹-eigenchannel projector e = (q+q⁻¹)⁻¹ • (q•1 − s). Defined for any element of any R-algebra; its projection identities below need only the Hecke quadratic.

            §3b DEPENDENT conjecture — the Wenzl tower step (bean qou-2c4t, the A1 apex). GIVEN the presentations, the inclusion, and the Markov trace at level n+1, semisimplicity ASCENDS the tower wherever the trace is nondegenerate: if Hn is semisimple and trn1 has no nonzero left kernel, then Hn1 is semisimple. This is Wenzl's induction step [wenzl1988, Thm 2.2]; the proved rungs isSemisimpleRing_H3A (and the rank-2 HeckeH2Wedderburn) realize its conclusion concretely at n = 2, 3 without the tower machinery. Proving this class's field for symmetric-group Coxeter data at the Markov trace is the general-n target the explicit-Wedderburn route cannot reach; it is still open.

            Mathlib does not supply the prerequisite; the CORPUS already does (measured 2026-08-26, bean qou-kzjl). Mathlib's traceForm_nondegenerate is

            ∀ (K L) [Field K] [Field L] [Algebra K L] [FiniteDimensional K L]
  [Algebra.IsSeparable K L], (traceForm K L).Nondegenerate

            which is wrong here in two independent ways: it runs separable ⇒ nondegenerate where this field needs the converse, and both K and L are fields where H_n(q) is non-commutative. Mathlib's isSemisimpleRing_* family is structural (iff_jacobson, iff_isArtinianRing, …), none of it trace-form based.

            That Mathlib measurement is correct and is NOT a reason to prove anything new here. The result — a finite-dimensional algebra over a field with nondegenerate regular trace form is semisimple — has been in this corpus since brick B3d (epic qou-hnhg) as QOU.MathlibExt.isSemisimpleRing_of_regTraceForm_nondegenerate, with its nilpotent-trace core in QOU.MathlibExt.TraceNilpotent. Recorded because the two questions are easy to conflate and one of them was: an exhaustive search of Mathlib says nothing about what the corpus holds.

            What is instantiated, and what is not. QOU.Machinery.HeckeRank.wenzlTowerStep_regTrace discharges this class's field at general rank for the regular trace w ↦ trace (L_w), so the class is no longer instance-free. It contributes an adapter between two spellings of nondegeneracy, not a semisimplicity proof. Two things are worth reading off it rather than assuming. First, the ascent does not consume the Hn-semisimple hypothesis at all — nondegeneracy at level n+1 is the whole of it, which makes hypothesis 1 of the field redundant for this trace. Second: the general-n Hecke target needs the field at the Markov trace — and that is not merely unproved here, it is false on H_n at the canonical convention D, so no instance of this class at the Markov trace on H_n can exist. The convention-D pin z(q²+1) = q³ forces the antisymmetric Wedderburn weight y₍₁³₎ to 0, that block lies in the radical of the trace form, and det G = 0 exactly — QOU.QBeta.TemperleyLiebTower.conventionD_kills_antisymmetriser and QOU.QBeta.MarkovGramDegenerate.gram_det_eq_zero_of_radical_combination, both sorry-free. Independently: the closed-form n = 3 determinant in gram-matrix-h3-symbolic carries the factor (q²+1)z − q³, which is the convention-D pin rearranged, so det G vanishes identically in q there.

            The Frobenius structure is real but lives on the quotient H_n / rad τ ≅ TL_n(δ) (pairing_descends, mem_radical_of_pairing_zero), matching prop:markov-trace-frobenius-selection (iii). Discharging this class at the Markov trace over that quotient is bean qou-s7z2; it is genuine work, since both the braided presentation and the tower inclusion must be restated for the quotient. The nearest abstract statement remains QOU.MathlibExt.isSemisimpleRing_of_qGeneric, which reaches semisimplicity from q-genericity but takes the Gram–factorial equivalence as a hypothesis, and whose own open input — the general T_w-basis determinant, the classical Schur-element product formula — is unchanged by any of this.

              class QOU.Machinery.HeckeTower.HeckeCosetSpanning (R : Type u_3) [Field R] (q : R) (rank : ℕ) (Hlow : Type u_4) (Hn : Type u_5) [Ring Hlow] [Ring Hn] [Algebra R Hlow] [Algebra R Hn] (σn : ℕ → Hn) [HeckeBraidedPresentationOfRank q rank Hn σn] (ιlow : Hlow →ₐ[R] Hn) (k : ℕ) :
              Prop

              §3b DEPENDENT conjecture — the coset spanning decomposition (bean qou-zm8z). GIVEN the two Hecke braided presentations and the tower inclusion ιlow : Hlow →ₐ Hn, every element of the larger algebra splits as

              w = ιlow a + Σᵢ ιlow (b i) · σn n · ιlow (c i)

              i.e. Hn = Hlow + Hlow · σₙ · Hlow — the level-n algebra is spanned by the lower one together with its σₙ-double-coset. Classically this is Iwahori's basis theorem / the Coxeter length filtration: a reduced word either avoids the top generator (first summand) or factors through exactly one occurrence of it (the sum). Mathlib has neither at general rank, which is why this is a class.

              This is the brick Ocneanu cyclicity induction actually runs on. The inductive step reduces tr(w₁w₂) to words of the shape u·g·v, and reaching an ARBITRARY pair needs exactly this spanning statement to put a general w into that shape. Without it the induction is stated only for already-decomposed words. It was named as a deliverable of the W2 re-scope note (bean qou-2017) alongside HeckeConditionalExpectation and JonesBasicConstruction and, unlike those two, was never built.

              Independent of the conditional expectation: it mentions neither ε nor the Jones projection, so it can be discharged separately, and a proof of it does not need any trace at all. OPEN — no instance.

                Prop

                §3b DEPENDENT conjecture — the Markov property of the conditional expectation (bean qou-zm8z). GIVEN a conditional expectation, ε collapses the σₙ-coset with a single scalar:

                ε (ιlow b · σₙ · ιlow c) = z • (b · c).

                This is the defining property of the Markov trace's z (the Ocneanu parameter) at the level of ε rather than of tr.                 This class ASSUMES the Markov property; it does not derive it. Its value is that the assumption is now a named, content-bearing carrier with a stated dependency edge, instead of an anonymous hypothesis threaded through call sites — and that, combined with HeckeCosetSpanning, it is exactly enough to compute ε on an arbitrary element (see MarkovTowerBridge.towerE_eq_of_spanning). That computation is the new content; the assumption itself is relocated, not discharged. OPEN — no instance.

                  What HeckeBraidedPresentation does and does not force #

                  Recorded while trying to build a genuine HeckeCosetSpanning instance (bean qou-zm8z). The attempt failed, and it failed one level BELOW the spanning decomposition — which is worth knowing before anyone else tries.

                  At the time of writing HeckeBraidedPresentation has no instance anywhere in the corpus. The two results below say why that is harder than it looks, and they are the only two facts needed to see it.

                  It is satisfiable, but weakly. constant_generator_presentation gives an instance from a SINGLE element satisfying the quadratic, with σ constant. Both the braid relation and far-commutation are then rfl. So an instance of this class does not force two distinct generators, does not force the braid relation to have any content, and does not force anything to fail to commute. It is much weaker than "is a Hecke algebra".

                  And a finite Hecke algebra cannot satisfy it with its true generators. The fields quantify over ALL i : ℕ, so H_n must supply σ i beyond its rank. far_commute_zero is the obstruction: σ 0 must commute with σ j for every j ≥ 2. In H₃ with σ 0 = σ₁ and σ 1 = σ₂ that rules out padding with the last real generator, since σ₁ and σ₂ do not commute; and no eventually periodic padding works either, for the same reason at the next index. The class describes H_∞, not H_n.

                  So a genuine instance needs either the infinite tower, or the class re-stated with a rank bound (σ : Fin n → H, relations guarded by i + 1 < n). That is a change to a class three other classes bind, so it is not made here.
