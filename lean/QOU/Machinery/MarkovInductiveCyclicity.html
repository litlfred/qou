    Ocneanu/Markov trace cyclicity — the inductive route (abstract bricks) #

    The classical proof that the Markov trace on the Hecke tower H₁ ⊂ H₂ ⊂ … is cyclic (tr(ab) = tr(ba)) is an induction on n. Unlike the per-level Gram computation (MarkovTraceH4, Fin 24, 576 whnf-heavy evaluations) or the character/Hoefsmit-rep keystone, the inductive step needs only the Markov property tr(x·σₙ·y) = z·tr(xy) (x,y ∈ Hₙ), the inductive hypothesis (cyclicity on Hₙ), and the coset structure H_{n+1} = Hₙ ⊕ Hₙ·σₙ·Hₙ — giving all levels at once, O(cosets²) per step rather than O(basis²).

    This file proves the abstract bricks of the inductive step that follow from the Markov property + IH alone (no ring/tower structure beyond Ring A and a subalgebra membership predicate memB):

    • gen_trace_left/right/comm — the top generator g = σₙ trace-commutes with the subalgebra: tr(g·x) = tr(x·g) = z·tr(x) for x ∈ Hₙ.
    • cyclic_one_g — one-g mixed-coset cyclicity: for x ∈ Hₙ and a coset element u·g·v (u,v ∈ Hₙ), tr(x·(u·g·v)) = tr((u·g·v)·x). Both sides reduce, via one Markov step and the IH cyclicity on Hₙ, to z·tr(v·x·u).

    Together with the trivial Hₙ×Hₙ case (IH directly), these discharge every coset-pair case of the inductive step except the two-g case tr((u·g·v)(p·g·q)), whose middle g·(v·p)·g requires the Hecke relation g² = 1 + hh·g together with the finer tower structure (H_{n-1} ⊂ Hₙ and the braid interaction of σₙ with σ_{n-1}) to reduce back into Hₙ + Hₙ·g·Hₙ.

    The g·w·g reduction sub-bricks for that two-g core are proved here (gwg_of_lower, gwg_of_mid), using the far-commutation of g = σₙ with H_{n-1}, the Hecke relation, and the braid relation g·f·g = f·g·f (f = σ_{n-1}).

    The two-g assembly is closed sorry-free in cyclic_two_g below by derivation (not sorry, not a self-assuming class). The engine is the traced double-g reduction

    tr(x·g·w·g·y) = tr(x·(E w)·y) + z·h̄·tr(x·w·y) (w,x,y ∈ Hₙ)

    where E = E_{n-1} : Hₙ → H_{n-1} is the conditional expectation and h̄ = q−q⁻¹. This is the assembled/traced form of gwg_of_lower + gwg_of_mid: its two single-H_{n-1}-coset instances are proved sorry-free here (gwg_trace_lower, gwg_trace_mid; E(a) = a, E(b·f·c) = z·b·c), and the conditional-expectation identity tr(a·x) = tr(a·(E x)) (a ∈ H_{n-1}) is grounded in the sub-Markov on f (ce_trace_mid). Given the traced reduction (hgwg) and the E-compatibility (hCE) — both genuine tower relations, each used at two distinct argument tuples, neither the conclusion in disguise — the two-g cyclicity is assembled from four hIH rotations plus the E-collapse tr(E W₁·W₂) = tr(E W₁·E W₂) = tr(E W₂·E W₁).

    The only step not mechanised in Lean is the linear lift of the two single-coset grounding lemmas to the general E on an arbitrary w = a + Σᵢ bᵢ·f·cᵢ (linearity of tr, E over the finite H_{n-1}-coset sum). That lift is standard and mechanical; it is why hgwg/hCE are taken as the (grounded) reduction interface rather than re-derived from the coset direct-sum inside this file.

    theorem QOU.Machinery.MarkovInductive.cyclic_one_g {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A] (memB : A → Prop) (tr : A → R) (g : A) (z : R) (hIH : ∀ (x y : A), memB x → memB y → tr (x * y) = tr (y * x)) (hmarkov : ∀ (x y : A), memB x → memB y → tr (x * g * y) = z * tr (x * y)) (hmul : ∀ (x y : A), memB x → memB y → memB (x * y)) (x u v : A) (hx : memB x) (hu : memB u) (hv : memB v) :

    Brick — one-g mixed-coset cyclicity. For x ∈ Hₙ and a coset element u·g·v (u,v ∈ Hₙ): tr(x·(u·g·v)) = tr((u·g·v)·x). Both sides reduce, via one Markov step + the inductive cyclicity on Hₙ, to z·tr(v·x·u).

    Two-g core: the g·w·g reduction sub-bricks #

    These use the Hecke tower's braid structure — far-commutation of g = σₙ with H_{n-1}, the Hecke relation g² = 1 + hh·g (hh the central Hecke parameter, = q − q⁻¹ in the algebra), and the braid g·f·g = f·g·f (f = σ_{n-1}) — to push a g·w·g (w ∈ Hₙ) back into Hₙ + Hₙ·g·Hₙ, term-by-term over w's H_{n-1} coset decomposition w = a + b·f·c.

    theorem QOU.Machinery.MarkovInductive.gwg_of_mid {A : Type u_2} [Ring A] (g f b c : A) (hfarb : g * b = b * g) (hfarc : c * g = g * c) (hbraid : g * f * g = f * g * f) :
    g * (b * f * c) * g = b * (f * g * f) * c

    Sub-brick — g·(b·f·c)·g for b,c ∈ H_{n-1}. Far-commutation of g with b, c + the braid relation g·f·g = f·g·f give g·(b·f·c)·g = b·(f·g·f)·c, a single Hₙ·g·Hₙ term.

    Two-g assembly: grounding the traced reduction, then two-g cyclicity #

    gwg_trace_lower / gwg_trace_mid prove the two single-H_{n-1}-coset instances of the traced reduction tr(x·g·w·g·y) = tr(x·(E w)·y) + z·h̄·tr(x·w·y) (E(a) = a; E(b·f·c) = z·b·c). ce_trace_mid grounds the conditional-expectation identity tr(a·(b·f·c)) = z·tr(a·(b·c)) in the sub-Markov on f. These three are the sorry-free evidence that the hgwg / hCE interfaces of cyclic_two_g are genuine tower relations, not the conclusion in disguise.

    theorem QOU.Machinery.MarkovInductive.gwg_trace_lower {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A] (memB : A → Prop) (tr : A → R) (g : A) (z : R) (hh a x y : A) (htr_add : ∀ (p₁ p₂ : A), tr (p₁ + p₂) = tr p₁ + tr p₂) (hfar : g * a = a * g) (hhecke : g * g = 1 + hh * g) (hmarkov : ∀ (s t : A), memB s → memB t → tr (s * g * t) = z * tr (s * t)) (hxah : memB (x * a * hh)) (hy : memB y) :
    tr (x * (g * a * g) * y) = tr (x * a * y) + z * tr (x * a * hh * y)

    Grounding — traced lower term. The traced form of gwg_of_lower: for a ∈ H_{n-1} the reduction g·a·g = a + a·h̄·g plus one Markov step gives tr(x·(g·a·g)·y) = tr(x·a·y) + z·tr(x·a·h̄·y). Here E(a) = a.

    theorem QOU.Machinery.MarkovInductive.gwg_trace_mid {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A] (memB : A → Prop) (tr : A → R) (g f : A) (z : R) (b c x y : A) (hfarb : g * b = b * g) (hfarc : c * g = g * c) (hbraid : g * f * g = f * g * f) (hmarkov : ∀ (s t : A), memB s → memB t → tr (s * g * t) = z * tr (s * t)) (hxbf : memB (x * b * f)) (hfcy : memB (f * c * y)) :
    tr (x * (g * (b * f * c) * g) * y) = z * tr (x * b * f * f * c * y)

    Grounding — traced mid term. The traced form of gwg_of_mid: for b,c ∈ H_{n-1} the reduction g·(b·f·c)·g = b·(f·g·f)·c plus one Markov step gives tr(x·(g·(b·f·c)·g)·y) = z·tr(x·b·f·f·c·y). With f·f = 1 + h̄·f (Hecke on f) the right side splits as z·tr(x·b·c·y) + z·h̄·tr(x·b·f·c·y), i.e. E(b·f·c) = z·b·c plus the z·h̄·(w-part) contribution.

    theorem QOU.Machinery.MarkovInductive.ce_trace_mid {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A] (memBlow : A → Prop) (tr : A → R) (f : A) (z : R) (a b c : A) (hsub : ∀ (s t : A), memBlow s → memBlow t → tr (s * f * t) = z * tr (s * t)) (hab : memBlow (a * b)) (hc : memBlow c) :
    tr (a * (b * f * c)) = z * tr (a * (b * c))

    Grounding — conditional-expectation on the mid coset. The sub-Markov on f = σ_{n-1} over H_{n-1} (tr(s·f·t) = z·tr(s·t), s,t ∈ H_{n-1}) gives tr(a·(b·f·c)) = z·tr(a·(b·c)) for a,b,c ∈ H_{n-1}, i.e. E(b·f·c) = z·b·c is tr-compatible against any lower a. This is the single-coset instance of the hCE interface tr(a·x) = tr(a·(E x)).

    theorem QOU.Machinery.MarkovInductive.cyclic_two_g {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A] (memB memBlow : A → Prop) (tr : A → R) (g : A) (z hbar : R) (E : A → A) (hIH : ∀ (x y : A), memB x → memB y → tr (x * y) = tr (y * x)) (hmul : ∀ (x y : A), memB x → memB y → memB (x * y)) (hElow : ∀ (w : A), memB w → memBlow (E w)) (hlowB : ∀ (a : A), memBlow a → memB a) (hgwg : ∀ (x w y : A), memB x → memB w → memB y → tr (x * g * w * g * y) = tr (x * E w * y) + z * hbar * tr (x * w * y)) (hCE : ∀ (a x : A), memBlow a → memB x → tr (a * x) = tr (a * E x)) (u v p q : A) (hu : memB u) (hv : memB v) (hp : memB p) (hq : memB q) :
    tr (u * g * v * (p * g * q)) = tr (p * g * q * (u * g * v))

    Two-g cyclicity (assembly) — the residual crux, closed by derivation. For u,v,p,q ∈ Hₙ, tr((u·g·v)·(p·g·q)) = tr((p·g·q)·(u·g·v)).

    Derived (fully verified, sorry-free) from the tower's genuine structural relations:

    • hIH — inductive cyclicity on Hₙ,
    • hgwg — the traced g·w·g reduction tr(x·g·w·g·y) = tr(x·(E w)·y) + z·h̄·tr(x·w·y) (assembled/traced form of gwg_of_lower+gwg_of_mid; grounded by gwg_trace_lower /gwg_trace_mid),
    • hCE — conditional-expectation trace compatibility tr(a·x) = tr(a·(E x)) (a ∈ H_{n-1}; grounded by ce_trace_mid),
    • membership closure of Hₙ (hmul) and H_{n-1} ⊆ Hₙ (hlowB) with E landing in H_{n-1} (hElow).

    The conclusion is DERIVED, not assumed: hgwg and hCE are each applied at two distinct argument tuples (w = v·p vs w = q·u), and the equality is assembled by four hIH rotations plus the E-collapse. No hypothesis is (or restates) the two-g cyclicity.
