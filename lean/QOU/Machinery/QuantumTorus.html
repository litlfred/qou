    QOU.Machinery.QuantumTorus — the skew-Laurent q-Weyl ring (NT-T2 brick B1) #

    The quantum torus T = R⟨L^±,M^±⟩/(LM − q²ML) as a skew-Laurent ring.

    Brick B1 of the Nguyen–Tran strong-AJ decomposition (docs/workplans/2026-07-20-nguyen-tran-strong-aj-lean-workplan.md). The paper's quantum torus is the skew-Laurent presentation A[L^±; σ] with coefficient ring A = R[M^±] and σ(M) = q²·M (paper: t², corpus: q = t⁴). This file realises it on Mathlib's early-stage Mathlib.Algebra.SkewMonoidAlgebra with the L-degree group G = Multiplicative ℤ acting on A by the automorphism σ (the action of Multiplicative.ofAdd 1).

    SkewMonoidAlgebra A (Multiplicative ℤ) is exactly the skew-Laurent ring: finitely-supported ℤ → A with the twisted product single m a · single n b = single (m+n) (a · σᵐ b) (Mathlib single_mul_single). Its support : Finset (Multiplicative ℤ) is the L-degree structure that brick B3 (skew-Euclidean division) divides on.

    What is proved here (sorry-free) #

    • sigma — the σ-twist (action of ofAdd 1), a ring automorphism of A.
    • emb : A →+* QuantumTorus A — the coefficient (M-side) embedding.
    • Lgen, Linv — the L^{±1} generators, with Lgen * Linv = 1 = Linv * Lgen (Lgen is a unit: LUnit).
    • Lgen_mul_emb — the q-Weyl commutation L · a = σ(a) · L (and the L⁻¹ transpose). With a distinguished σ-eigenvector M (σ M = c·M) this specialises to the paper's L·M = c·M·L (qWeyl_eigen_commutation, c = q²).
    • Degree / basis basics: emb/Lgen/monomial coeff lemmas, Lgen ≠ 0, single-monomial support.
    • Evaluation to the function model (ℕ → K, the corpus QDifferenceOperator carrier of QOU.BraidKnot.AJFigureEight): the shift shiftFwd and scalar-power mulPow q operators satisfy the q-Weyl relation shiftFwd ∘ mulPow q = q • (mulPow q ∘ shiftFwd) (funcModel_qWeyl) — so the corpus tower operators are a genuine q-Weyl representation.
    • torusEval — the universal ring-hom evaluation of the torus into any semiring, from a coefficient ring-hom + an image unit for L satisfying the twist compatibility (a thin re-exposure of liftNCRingHom).

    Base ring (§7c) #

    Generic {A : Type*} [CommRing A] for the coefficient ring and generic {K : Type*} [Field K] for the function model. No ℝ, no ordering, no archimedean construct: the whole file is algebraic. Inverses in the function model use [Field K] only through scalar powers q^N.
