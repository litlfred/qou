    def QOU.Machinery.CoxeterParabolic.RightExchangeProp {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) :
    Prop

    The right exchange property (Bjorner–Brenti Thm 1.4.3, simple form; Bourbaki Lie IV §1): a right descent of a reduced word's product is realized by deleting a single letter. Textbook-true; not derivable from Mathlib's current Coxeter primitives (the audited upstream gap) — used below only as an explicit hypothesis.

            theorem QOU.Machinery.CoxeterParabolic.length_minRep_mul_wordProd {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) (J : Set B) (hexch : RightExchangeProp cs) {u : W} (hu : IsMinRep cs J u) {p : List B} (hp : ∀ l ∈ p, l ∈ J) (hred : cs.IsReduced p) :
            cs.length (u * cs.wordProd p) = cs.length u + p.length

            THE LIFTING LEMMA (Bourbaki Lie IV §1 / BB Prop 2.4.4, core form), conditional on the exchange property: a minimal coset representative u composes length-additively with every reduced J-word, ℓ(u · π p) = ℓ(u) + |p|. A failed ascent triggers exchange on the concatenated reduced word; deletion in the u-part contradicts the minimality of u, deletion in the p-part contradicts the reducedness of p. This is the fact the merged coset structures' len_add fields encode.
