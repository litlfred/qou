    QOU.Machinery.QuantumTorusAJ — GGM/AJ and the binding q-lift as co-resident quantum-torus elements #

    Infrastructure wiring connecting three previously-separate corpus objects:

    • the abstract quantum torus T = A[L^±; σ] (QOU.Machinery.QuantumTorus, brick B1 of the Nguyen–Tran strong-AJ decomposition),
    • the concrete, sorry-free order-2 GGM/AJ annihilator of the figure-eight colored Jones tower (QOU.BraidKnot.AJFigureEight.figureEightOperator), and
    • the proved binding q-lift kernel [m+2]_q b_{m+2} = b_{m+1} + b_m (QOU.Mass.QDifferenceConfluentObstruction.qlift_normalized_kernel_exists).

    What is established here (sorry-free) #

    The coefficient ring is realised as the diagonal M-operators A = ℤ → K (functions of the integer colour), carrying the σ-twist as translation σ(a)(N) = a(N+1) — the paper's σ(M) = c·M with M = q^N, c = q. On this A the quantum torus QuantumTorus (ℤ → K) is a genuine skew-Laurent ring and:

    1. act2 — the order-≤2 function-model action of a torus element on a colour tower J : ℤ → K: it reads the element's L^0, L^1, L^2 coefficients (QuantumTorus.coeffAt) and assembles the q-difference operator coeffAt f 0 · J + coeffAt f 1 · shift J + coeffAt f 2 · shift² J. This is the diagonal-M / shift-L representation whose q-Weyl relation is QuantumTorus.funcModel_qWeyl (L·M = q·M·L); act2 is additive (act2_add). (The bijective torusEval-into-AddMonoid.End ring homomorphism is mathematically the same object but is elaboration-intractable over AddMonoid.End (ℤ → K) — the concrete liftNCRingHom instance blows the isDefEq budget; act2 is the tractable equivalent for the order-2 elements at hand, and is faithful on them since they are supported in degrees {0,1,2}.)
    2. GGM lives in the torus (a theorem). The order-2 figure-eight annihilator is the torus element ggmElement, whose L^j coefficient is exactly figureEightOperator.coeff j (coeffAt_ggmElement), and under act2 it reproduces the exact concrete figureEightOperator action ∑_{j≤2} coeff_j(q, q^N)·J(N+j) (act2_ggmElement_matches_figureEight). So "the GGM/AJ operator is an element of the quantum torus" is machine-checked, not a slogan.
    3. The C1 binding kernel lives in the SAME torus. The proved q-lift kernel [m+2]_q σ² − σ − 1 is the torus element c1Element, acting as act2 (c1Element c) b m = c m · b(m+2) − b(m+1) − b(m) (act2_c1Element); with c m = [m+2]_q this is the operator form of qlift_normalized_kernel_exists.

    Both ggmElement and c1Element are elements of the one ring QuantumTorus (ℤ → K) (act2_ggm_add_c1, a non-vacuous witness: the algebraic sum only typechecks because they are co-resident, and its action is the explicit combined operator). The proved five-route module distinction — Newton-polygon slopes {½,½} (C1) vs {−1,+1} (GGM) — is therefore a statement about two concrete elements of a common q-difference ring. The inequivalence itself is not proved here (it needs Ramis–Sauloy–Zhang Newton-polygon theory, outside Mathlib); see docs/audits/2026-07-20-qlift-gauge-gap-synthesis.md. This file only makes the two kernels co-resident and pins the GGM action compatibility — pure infrastructure, no module-theoretic claim.

A torus element f acts on a colour tower J : ℤ → K as the q-difference operator whose L^j-coefficient is the diagonal coeffAt f j (j = 0,1,2): L shifts, coeffAt f j scales.             Co-residence: both kernels are elements of the one quantum torus #

            source
            theorem QOU.Machinery.QuantumTorusAJ.act2_ggm_add_c1 {K : Type u_1} [Field K] (a0 a1 a2 c J : ℤ → K) (N : ℤ) :
            act2 (ggmElement a0 a1 a2 + c1Element c) J N = (a0 N - 1) * J (N + 0) + (a1 N - 1) * J (N + 1) + (a2 N + c N) * J (N + 2)

            Co-residence (the point of this file), operationally. Because ggmElement … and c1Element … are elements of the same ring QuantumTorus (ℤ → K), their sum is again a torus element, and its act2 action is the concrete order-2 operator obtained by adding the two kernels coefficient-by-coefficient: ((a0−1) + (a1−1)L + (a2+c)L²). This is a non-vacuous witness that the two kernels live in one q-difference ring — the algebraic sum only typechecks because of co-residence, and the result is an explicit operator. The proved five-route module distinction (slopes {½,½} (C1) vs {−1,+1} (GGM), docs/audits/2026-07-20-qlift-gauge-gap-synthesis.md) is therefore a statement comparing these two concrete elements of the common ring; the inequivalence itself is not formalised here (Newton-polygon theory, outside Mathlib).
