    class QOU.Machinery.HeckeBraidedCategory.HeckeBraidedPresentation (R : Type u_1) [Field R] (q : R) (H : Type u_2) [Ring H] [Algebra R H] (σ : ℕ → H) :
    Prop

    §3b PRIMARY conjecture — general-n Hecke braided presentation. The braid generators σ : ℕ → H of the inductive-limit Hecke algebra H_∞(q) satisfy three relations: the Hecke quadratic (the R-matrix eigenvalue / Skein equation), the braid relation (the Yang–Baxter / braiding-hexagon shadow — the F2 datum), and far commutation (the monoidal-interchange F1 shadow). Over a field R (needs q⁻¹).

    Content-bearing (three real quantified equations, no True, no empty body). This is the algebraic presentation of the braided monoidal SOURCE category 𝐂 that τ's domain requires. No instance for general n — Mathlib has no H_n(q) for n≥3, so this is the OPEN source-category infrastructure (F1/F2). PRIMARY: its signature binds no other conjecture class. Concrete slices are proved at n=2 (heckeQuadratic_h2 below) and n=3 (QOU.Machinery.H3.mulσ₀_hecke).

    • hecke_quadratic (i : ℕ) : σ i * σ i = (q - q⁻¹) • σ i + 1

      Hecke quadratic relation σᵢ² = (q − q⁻¹)·σᵢ + 1 (Skein / R-matrix eigenvalue equation).

    • braid_adjacent (i : ℕ) : σ i * σ (i + 1) * σ i = σ (i + 1) * σ i * σ (i + 1)

      Braid relation σᵢ σᵢ₊₁ σᵢ = σᵢ₊₁ σᵢ σᵢ₊₁ — the Yang–Baxter / hexagon shadow (the braiding datum F2).

    • far_commute (i j : ℕ) : i + 1 < j → σ i * σ j = σ j * σ i

      Far commutation σᵢ σⱼ = σⱼ σᵢ for |i − j| ≥ 2 (monoidal interchange F1).
