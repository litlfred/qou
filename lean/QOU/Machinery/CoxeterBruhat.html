    The Bruhat (subword) order on a Coxeter system #

    Mathlib has no Bruhat order. That is measured rather than grepped — a source grep is worthless in this checkout, where .lake/packages/mathlib carries 6990 oleans and zero .lean files — by enumerating the environment (scripts/lean-probes/): of 439 reachable Coxeter constants, 0 contain ruhat and 0 contain ubword.

    It is wanted here for bean qou-phir. TwInverseLength.TwInv_mem_spanLe proves that T_w⁻¹ cannot escape upward in length; the sharper statement measured by tw_inverse_support_probe.py is that its support is the interval [e, w⁻¹] — and that cannot even be stated without this order.

    The definition, and the one thing to know about it #

    u ≤ w iff some reduced word for w has a subword whose product is u.

    The classical subword property says the choice of reduced word does not matter — for a reduced ω with wordProd ω = w, every u ≤ w appears as a subword of that ω. It is not proved here, and until it is, BruhatLe should be read as the existential it literally is. The ingredient it needs is the exchange condition, which this repo does have (QOU.Machinery.CoxeterParabolic.rightExchange, sorry-free for every Coxeter system) — so this is unfinished work, not a blocked route.

    What is proved, and what is deliberately not #

    Proved: reflexivity, 1 ≤ w, length monotonicity, and the two ascending-extension steps that an induction along a reduced word actually consumes.

    Not proved, and not to be assumed by a consumer: transitivity, antisymmetry, the subword property above, and the lifting property. Each needs the exchange condition. A downstream file that needs one of them should prove it from rightExchange rather than quietly assume BruhatLe is a partial order — it is not yet known here to be one.

    🟩 This file is on the Murphy-basis critical path — found 2026-09-06, after it was built #

    It was written as "the subword order Mathlib has none of", with transitivity, antisymmetry, the subword property and lifting deliberately left unproved. All four are consumed by Mathas' route to the Murphy basis, which was not known at the time:

    • Proposition 3.7 (Dipper–James) — for row standard λ-tableaux, s ⊵ t iff d(s) ⊵ d(t), the source noting that Bruhat–Chevalley "agrees with the dominance ordering on row standard λ-tableaux". Since dOf is a bijection (TableauPerm.equivPerm), DominanceWellFounded.domGtOn and the Bruhat order are the same order transported, so MurphyInductionMeasure.murphyLex is lex-on-shapes × Bruhat-on-permutations.
    • Corollary 3.8, which 3.14's induction closes on, opens by invoking Mathas' Theorem 1.1.11: T_{d(v)} T_w = Σ r_x T_x with r_x ≠ 0 only for x whose reduced expression is a subexpression of d(v)w. That is the subword property, i.e. exactly the lemma this file declines to prove. QOU.BraidKnot.TwInverseBruhat.TwInv_mem_spanBruhatLe is the corpus's nearest existing instance of that shape.

    🛑 Two inequivalent definitions of the Bruhat order are now in play in this corpus and only one is named. BruhatLe here is the subword definition. Mathas' is reflection-generated with length increase — w = v t₁⋯t_k with ℓ(v t₁⋯t_j) = ℓ(v) + j. Their equivalence is a theorem, not an unfolding. Do not let a second one accrete under this name; that is the dOf collision (#6899) one level up.

      theorem QOU.Machinery.CoxeterBruhat.bruhatLe_inv {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) {u w : W} (h : BruhatLe cs u w) :
      BruhatLe cs u⁻¹ w⁻¹

      The Bruhat order is inversion-invariant: u ≤ w ↔ u⁻¹ ≤ w⁻¹.

      This is the handedness bridge, and it is the reason this lemma is here rather than in a consumer. Three separate orders on this arc multiply on opposite sides:

      • Tw_mul_Tw : T_v · T_w = T_{w·v} — the Hecke product is anti-multiplicative in the index, forced by orbitMap, not a typo;
      • TableauPerm.dOf_smul : dOf (w • t) = w * dOf t — the tableau action puts the permutation on the left;
      • BruhatReflection.ReflStep v w := ∃ τ, IsReflection τ ∧ w = v * τ ∧ ℓ v < ℓ w — the reflection order steps on the right.

      A consumer that needs a left-handed statement of a right-handed lemma (or the reverse) transports through this lemma rather than restating the lemma with the sides swapped. The proof is the reversed word: wordProd ω.reverse = (wordProd ω)⁻¹, reversal preserves reducedness, and List.Sublist.reverse carries the subword across.

      theorem QOU.Machinery.CoxeterBruhat.bruhatLe_of_length_add {B : Type u_1} {W : Type u_2} [Group W] {M : CoxeterMatrix B} (cs : CoxeterSystem M W) {u w : W} (h : cs.length (u * w) = cs.length u + cs.length w) :
      BruhatLe cs u (u * w)

      Length additivity puts the left factor below the product: if ℓ(u·w) = ℓ(u) + ℓ(w) then u ≤ u·w.

      Concatenating reduced words for u and w gives a word of length ℓ(u) + ℓ(w) = ℓ(u·w), so it is reduced for u·w, and u's own word is a prefix — hence a subword.

      This is the coset-minimality bridge, and it is what makes the row-standard representative usable in Mathas' Prop. 3.7. A tableau's d is a distinguished (minimal length) coset representative, and CoxeterReflectionCocycle.length_minRep_mul_wordProd' — the unconditional Bourbaki lifting lemma — supplies exactly this hypothesis for it. So a step that leaves a tableau's rows unsorted is not lost: the sorted representative sits below the raw one in Bruhat, and transitivity closes the gap.

      Measured before it was proved: d(rowsort(τ·t)) ≤ d(τ·t) on every transposition of every row-standard tableau of every partition of n ≤ 6 — 2 134 710/2 134 710 at n = 6 (dipper_james_forward_step_probe.py).
