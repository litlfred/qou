      class QOU.Machinery.FaddeevQuantumDilogContext (q : ℝ) :
      Type

      Conditional class axiomatising the compact quantum dilogarithm context for the Habiro element. NEAR-MATCH tier; instance not constructed (requires upstream Bloch–Wigner machinery).

      Legacy name. FaddeevQuantumDilogContext (and the field prefix faddeev_) are retained for compatibility with existing lean.ref consumers, but the object here is the compact q-Pochhammer Φ_q ∏(1−q^{-k}z)^{-1} — not Faddeev's non-compact modular-double Φ_b (see QOU.QBeta.FaddeevModularDouble and the 2026-07-06 terminology ruling in docs/audits/2026-07-06-qbeta-faddeev-phi-b-modular-double-accuracy.md).

      • Phi : ℝ → ℝ

        The compact q-dilogarithm Φ_q(z) = ∏_{k≥0} (1 - q^{-k} z)^{-1} carried as an abstract real function of z (the concrete infinite product / its convergence is the open derivation).

      • faddeev_functional_equation (z : ℝ) : (1 - z) * Phi q z = Phi q (q⁻¹ * z)

        The Φ_q functional equation (1 - z)·Φ_q(z) = Φ_q(q⁻¹ z) (was True). Derivation for the k ≥ 0 product convention: the k = 0 factor of P(z) := ∏_{k≥0}(1 - q^{-k}z) peels off as P(z) = (1 - z)·P(q⁻¹ z), and Φ_q = P⁻¹ inverts this to the stated relation.
