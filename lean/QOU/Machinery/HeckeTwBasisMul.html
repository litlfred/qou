    QOU.Machinery.HeckeTwBasisMul — the T_w standard-basis structure constants, all ranks #

    HeckeGeneralRankQuadratic.mulSimple is the right action of the Hecke generator T_{sᵢ} on the function module W → R of an arbitrary Coxeter system, and mulSimple_quadratic proves σᵢ² = h·σᵢ + 1 at every rank. This file identifies that action, on the standard basis vectors e_w = Pi.single w 1, as the classical Iwahori–Hecke T_w-basis multiplication rule — the structure constants of H_n(q) for all n at once:

    T_w · T_{sᵢ} = T_{w·sᵢ} if ℓ(w·sᵢ) > ℓ(w) (ascent) T_w · T_{sᵢ} = T_{w·sᵢ} + h · T_w if ℓ(w·sᵢ) < ℓ(w) (descent)

    (the h normalization of σᵢ² = h·σᵢ + 1; at w = sᵢ the descent case is T_{sᵢ}² = T_1 + h·T_{sᵢ} = 1 + h·σᵢ, consistent).

    Contents (all sorry-free, rank-agnostic over any CoxeterSystem):

    • mulSimple_single — the combined length rule on e_w.
    • mulSimple_single_ascent / mulSimple_single_descent — the two cases.
    • mulSimple_single_one — T_1 · T_{sᵢ} = T_{sᵢ}: the generator is the basis vector at sᵢ (ℓ(sᵢ) = 1 > 0).

    This names the T_w basis's structure constants uniformly; it does not close the open all-ranks keystones (Gram symmetry / Tits faithfulness), which stay honest hypotheses elsewhere.
