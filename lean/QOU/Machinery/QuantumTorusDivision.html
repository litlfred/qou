    QOU.Machinery.QuantumTorusDivision — skew-Euclidean right-division (NT-T2 brick B3) #

    Right-division f = q·g + r (deg r < deg g) in the localized quantum torus.

    Brick B3 of the Nguyen–Tran strong-AJ decomposition (docs/workplans/2026-07-20-nguyen-tran-strong-aj-lean-workplan.md, class (c) — genuine Mathlib gap). In the localized torus T̃ = R(M)⟨L^±⟩ the coefficient ring is a field, so every nonzero element's leading L-coefficient is a unit and Euclidean right-division by L-degree terminates; this is what makes the recurrence ideal A_K principal (paper §1.2).

    Honest status of this file (§3b, anti-laundering STRICT) #

    The whole file is now sorry-free. The reduction engine (the real degree-drop content):

    • reductionQuotient — the quotient monomial that cancels the L^e term.
    • reduction_leading_coeff_match — its product with g matches f's L^e coefficient exactly (the algebraic heart: uses coeff_single_mul, the σ-image unit σ^{e-d}(u), and Ring.inverse_mul_cancel).
    • reduction_top_coeff_cancel — hence the one reduction step f - reductionQuotient·g kills the L^e coefficient.

    The induction/termination layer built on top (the pieces Mathlib does not provide as Ore-extension theory, discharged directly here):

    • topDeg_lt_of_forall_ge_eq_zero / topDeg_eq_bot_iff — the WithBot ℤ / Finset.max degree calculus.
    • skew_right_division_degree_drop — one reduction step strictly drops topDeg. The L^e coefficient vanishes (reduction_top_coeff_cancel) and every higher coefficient vanishes because topDeg f = e and the reduction monomial L^{e-d}·g has top degree ≤ e (computed directly via coeff_single_mul + coeffAt_eq_zero_of_topDeg_lt).
    • exists_skew_right_division_fuel / exists_skew_right_division — the division existence theorem ∃ q r, f = q·g + r ∧ (r = 0 ∨ topDeg r < topDeg g), by a ℕ-fuel induction: each step lowers topDeg by ≥ 1, so a fuel bound read off f's finite top degree terminates the recursion. This is the constructive replacement for the (absent) skew-Laurent Euclidean algorithm.
