    QOU.LiftingDescent — Arc spaces of the brane tower #

    Formalizes def:arc-space.

    The QOU recursive brane tower 𝓢₀ ↪ 𝓢₁ ↪ 𝓢₂ ↪ ⋯ is identified with a tower of jet schemes L_n(X), and its inverse limit is the arc space L(X) = lim_{←n} L_n(X).

    Design (per PR #403 review):

    • JetScheme X n packages just the carrier of L_n(X).
    • JetTower X carries the whole family L_n(X) together with the level-shifting truncation maps L_{n+1}(X) → L_n(X).
    • ArcSpace X tower is the inverse limit, exposing one projection Carrier → (tower.level n).Carrier per level.

    This avoids the type-vs-term confusion of trying to write (JetScheme X n).Carrier from inside another structure: the carrier is now extracted from a term of JetScheme, not from the type.

    References #

    • [denef-loeser2001] Denef, Loeser, Geometry on Arc Spaces of Algebraic Varieties. ECM Barcelona 2000, Birkhäuser, 327-348.

    structure QOU.LiftingDescent.JetScheme (X : Type u_1) (n : ℕ) :
    Type (u_2 + 1)

    The n-th jet scheme L_n(X) of a variety X.

    Represents the functor R ↦ Hom(Spec R[t]/(t^{n+1}), X). In QOU it is identified with the n-th level of the recursive brane tower 𝓢_n. The structure exposes only the carrier of L_n(X); the truncation map L_{n+1}(X) → L_n(X) lives on JetTower (it is inherently a level-shifting map).

    • Carrier : Type u_2

      Underlying scheme of the n-th jet space.

        structure QOU.LiftingDescent.ArcSpace (X : Type u_1) (tower : JetTower X) :
        Type (max (u_2 + 1) u_3)

        The arc space L(X) of a variety X over a chosen jet tower.

        L(X) = lim_{←n} L_n(X) is the inverse limit of the jet schemes. In QOU it equals the inverse limit of the recursive brane tower 𝓢_∞ := lim_n 𝓢_n. Carries the formal data needed for motivic integration even when X is singular.

        The compatible field is the inverse-system law: each projection equals the next, post-composed with truncation.

        • Carrier : Type u_2

          The carrier of the arc space (inverse limit of jet schemes).

        • projection (n : ℕ) : self.Carrier → (tower.level n).Carrier

          Projection to each finite jet level.

        • compatible (n : ℕ) (a : self.Carrier) : tower.truncation n (self.projection (n + 1) a) = self.projection n a

          Compatibility with truncation: trunc_n ∘ proj_{n+1} = proj_n.
