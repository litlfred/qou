    structure QOU.BraidKnot.Keystone.FoldedFibreBoundaryData :
    Type

    The folded fibre boundary datum of the candidate F_λ = [mark]²/D² at one fibre root. Content-bearing: the nine per-node squared characters [mark]²_ζ (charSq), the normalizer D² = Σ [mark]²_ζ (D2), and the Verlinde weights F with the two genuine content fields hF : F i = charSq i / D2 and the normalization hnorm : (F.map id).sum = 1. The normalization is the real (provable, non-trivial) claim — a bare marker : True would be a review failure.

    • charSq : List ℚ

      The nine per-node squared characters [mark μ]²_ζ (marks 1,2,3,4,5,6,4,2,3).

    • hlen : self.charSq.length = 9

      Exactly nine McKay nodes.

    • D2 : ℚ

      The normalizer D² = Σ_{9 nodes} [mark]²_ζ.

    • hD2 : self.charSq.sum = self.D2

      D² is the node-sum of the squared characters.

    • hD2ne : self.D2 ≠ 0

      D² ≠ 0 (the Verlinde weights are well-defined).

    • F : List ℚ

      The Verlinde weights F_λ = [mark λ]²_ζ / D².

    • hF : self.F = List.map (fun (x : ℚ) => x / self.D2) self.charSq

      F is the per-node quotient of the squared characters by D².

    • hnorm : self.F.sum = 1

      CONTENT — normalization. Σ_λ F_λ = 1.
