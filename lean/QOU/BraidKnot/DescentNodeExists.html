    A non-standard row-standard tableau has a descent node #

    This is the second half of Mathas' Lemma 3.13, and the last piece of it. QOU.BraidKnot.GarnirDescentAdditive proves that length is additive at any descent node; 3.13 also asserts that a row-standard non-standard tableau has one. That is what is proved here.

    The statement #

    exists_descentNode_of_not_standard : IsRowStandard t → ¬ IsStandard t → ∃ i j, IsDescentNode t i j

    Together with invSet_garnirPerm_subset_of_descent this closes the length half of 3.13: for a row-standard non-standard t there is a Garnir tableau g and a w with t = w • g and ℓ(d(t)) = ℓ(d(g)) + ℓ(w).

    The argument #

    Contrapositive. A descent node is a failure of column-strictness between adjacent rows, while IsColStandard quantifies over arbitrary row pairs, so the two are not immediately interchangeable: the content is that having no adjacent failure forces the whole column to increase. lt_of_noDescent is that induction, mirroring entry_lt_entry_of_lt_row (which proves the same shape for a StandardYoungTableau, where column-strictness is part of the structure rather than a hypothesis).

    Strictness at the induction step needs one extra step beyond "not a descent": ¬ IsDescentNode gives only ≤, and the labels are distinct because t is a bijection and the two cells differ.

    Both halves together #

    theorem QOU.BraidKnot.DescentNodeExists.exists_garnir_length_additive {μ : YoungDiagram} {t : Specht.Tableau μ} (hrs : RowStandardTableau.IsRowStandard t) (hns : ¬RowStandardTableau.IsStandard t) :
    ∃ (i : ℕ) (j : ℕ) (h : (i + 1, j) ∈ μ), Hecke.Inversions.invSet (GarnirTableau.garnirPerm i j h) ⊆ Hecke.Inversions.invSet (TableauPerm.dOf t)

    The length half of Mathas' Lemma 3.13, complete.

    For a row-standard tableau that is not standard there exists a Garnir tableau whose every inversion survives in d(t) — which by length_dOf_smul_eq_add_iff is ℓ(d(t)) = ℓ(d(g)) + ℓ(w) for the w with t = w • g.

    The existence half is this file; the additivity half is invSet_garnirPerm_subset_of_descent.

    Non-vacuity by cross-check #
