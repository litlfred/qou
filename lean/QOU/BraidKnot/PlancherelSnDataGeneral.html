    QOU.BraidKnot.PlancherelSnDataGeneral — Identity I's Plancherel data, at every n #

    IdentityI.PlancherelSnData n carries the two standard S_n facts Identity I is conditional on:

    • (i) Σ_λ dim(λ)² = n!, and
    • (ii) 2·Σ_λ dim(λ)²·(Σ_{c∈λ} c(c)²) = n(n−1)·n!, the cleared content-square Plancherel mean.

    Both were supplied only by hand-registered decide instances at n = 2 … 12, so the conditional Identity I results (IdentityI.two_sum_dim_sq_hooks, IdentityI.twoM_eq_plancherel_hook_sum) were usable only in that range. This file builds the datum for every n.

    What each half now rests on #

    • (i) is PartitionsOfBridge.sum_map_dimHLF_sq, i.e. the Robinson–Schensted correspondence (QOU.Mathlib.rskBurnsideHolds) transported to the list model.
    • (ii) is RegularRepBlockTrace.identityB_conditional applied to the assembled spectral datum OVTopAssembly.snSpectralData, whose class hypothesis is inhabited by SnIsotypicSpechtSplitInstance — reindexed off PartitionIndex n onto the list enumerator through SpechtWedderburnLe12.numSYT_partitionEquiv (dimensions) and ContentSqSumBridge.contentSqSum_ofRowLens (contents).

    The second bridge is the one that did not exist: the OV/JM layer states the eigenvalue as JucysMurphy.contentSqSum over a diagram's cells, and PlancherelSnData states it as IdentityI.sumSqContents over a row-length list. Identity (ii) held for all n in the first form since identityB_general; it could not be written in the second.

    Not an instance, on purpose #

    plancherelSnDataGeneral is a def, not an instance: IdentityIPlancherelInstances registers eleven per-n instances, and PlancherelSnData is a data-carrying class, so a competing general instance would make h.parts / h.dim depend on which one resolution picked. The per-n instances stay the resolvable ones (and stay cheaper) inside their range; the general-n payoff is stated directly by two_sum_dim_sq_hooks_general / twoM_eq_plancherel_hook_sum_general below, which carry no hypothesis at all.

    Pure combinatorics on ℕ/ℤ plus the assembled Wedderburn datum over ℚ; nothing archimedean; no fit.
