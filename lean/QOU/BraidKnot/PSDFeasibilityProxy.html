    QOU.BraidKnot.PSDFeasibilityProxy #

    Bridge between the decidable structural proxies on BraidWord (structurallyValidBinding, evenPower, length ≤ 4) used in the CanonicalKnotIdSDP placeholder instances, and the categorical PSD-feasibility statement on the abstract Hecke- algebra Wedderburn decomposition.

    What this module provides #

    • evenPower_necessary_for_blockPosSemidef — the proxy BraidWord.evenPower is a NECESSARY condition for every Wedderburn block of the corresponding Hecke element to be PSD. Axiomatised at the categorical-content level pending the algebra-evaluation map BraidWord → HeckeElement n.

    • withinLengthBound — the enumerator's search-space bound as a named decidable predicate.

    Not provided, despite an earlier version of this list saying so: a structurallyValidBinding_necessary_for_canonical — "the structural-validity proxy is necessary for the Hecke element to be a candidate canonical T_w". No such declaration exists or has ever existed in this file. What stood in its place was a tautology under the similar name structurallyValidBinding_necessary, removed on 2026-08-30 (see the note at the foot of this file). The predicate itself is BraidWord.structurallyValidBinding in mass-theory/conj-canonical-knot-id-sdp.lean; the necessity claim awaits the same algebra-evaluation map as its evenPower sibling.

    Mathematical content #

    The decidable Lean predicates evenPower, structurallyValidBinding, and length ≤ L_K_max are NECESSARY but NOT SUFFICIENT conditions for the categorical PSD-feasibility / minimal-length / canonical-Markov-trace claims. This module captures the arrow decidable proxy → categorical claim direction (the only direction that's relevant for falsification: violating the proxy disqualifies the candidate categorically).

    The reverse direction (sufficiency) requires the full SDP machinery: PSD eigenvalue check per Wedderburn block via QOU.HeckeAlgebra.Hoefsmit, Markov-trace evaluation via QOU.HeckeAlgebra.MarkovTrace. These are the open Lean ports.

    • binding-k-enumerator.witness.json — empirical justification that the placeholder bindingKWord [3, 3] satisfies the decidable predicates.
    • binding-k-solver.witness.json — empirical PSD-feasibility verification per Wedderburn block.

    axiom QOU.BraidKnot.PSDFeasibilityProxy.evenPower_necessary_for_blockPosSemidef (n : ℕ) (w : List ℤ) :
    (braidWordEval n w).PosSemidef → ∀ g ∈ w.eraseDups, (List.count g w + List.count (-g) w) % 2 = 0

    Even-power proxy is necessary for block PSD.

    If braidWordEval n w has every Wedderburn block PSD, then w.evenPower (the decidable proxy on BraidWord) holds.

    Contrapositive: a word violating evenPower cannot evaluate to a PSD-everywhere element. This is the half of "evenPower-iff-PSD" that's actually true at the σ_k^{2m} eigenvalue level.

    Axiomatised at the categorical-content level; concrete proof requires the Hoefsmit-eigenvalue computation per block.

    def QOU.BraidKnot.PSDFeasibilityProxy.withinLengthBound (w : List ℤ) (L_max : ℕ) :
    Prop

    The length-bound proxy for the canonical-T_w search: a candidate word is within the enumerator's search space only if w.length ≤ L_max (the R5-full SDP search bounds candidate length to L_K_max ≤ 4, per binding-k-enumerator's parameter).

    Named as a decidable predicate (§3b: naming, not asserting). The necessity is the enumerator's search-space restriction — a definitional bound, not a derived theorem. The previous (h : ¬P) : ¬P := h was a self-assuming tautology that asserted nothing about braid words.

      Hypothesis and conclusion are the same proposition and the proof is the hypothesis: (h : ¬P) : ¬P := h, which is id under a name that promises a necessity result. It asserted nothing about braid words, PSD blocks, or n_0.
