    QOU.BraidKnot.per_nucleon_shift_additive_linearity — shift(Z+1, N) − shift(Z, N) = 18 #

    Proposition (prop:per-nucleon-shift-additive-linearity).

    The atomic Markov-trace denominator D(u) = 2^{2A+1} · u^{shift} · (1 + u²)^{3A−1} of canonical pppnnn ordering has shift exponent satisfying the additive-linearity recurrence:

      shift(Z+1, N) − shift(Z, N) = 18,
  shift(Z, N+1) − shift(Z, N) = 21,    for Z, N ≥ 1 (A ≥ 2)

    Together with the base case shift(D) = shift(1, 1) = 40, this fixes the closed form shift(Z, N) = 18Z + 21N + 1 on the entire A ≥ 2 triangle.

    The per-direction increments (18, 21) and the base value 40 are the categorical/computed inputs — derived by Hoefsmit per-irrep pole-order analysis (witness per-irrep-pole-{proton-h3,deuteron-h6}.witness.json). The closed form shift(Z, N) = 18Z + 21N + 1 is derived here from those inputs by induction over (Z, N), exactly as in the manuscript proof — not projected from a stored field.

    class QOU.BraidKnot.PerNucleonShiftContext :
    Type

    Context carrying the inputs of the shift recurrence: the base value shift(1,1) = 40 and the constant per-direction increments 18 (per new proton) and 21 (per new neutron), valid for Z, N ≥ 1. The closed form is NOT a field — it is derived below.

    • shift : ℕ → ℕ → ℤ

      The shift exponent shift(Z, N) : ℤ.

    • shift_base : shift 1 1 = 40

      Input — base case: shift(1, 1) = 40 (Hoefsmit deuteron pole order).

    • shift_proton_step (Z N : ℕ) : 1 ≤ Z → 1 ≤ N → shift (Z + 1) N - shift Z N = 18

      Input — per-new-proton increment is constantly 18 for Z, N ≥ 1.

    • shift_neutron_step (Z N : ℕ) : 1 ≤ Z → 1 ≤ N → shift Z (N + 1) - shift Z N = 21

      Input — per-new-neutron increment is constantly 21 for Z, N ≥ 1.
