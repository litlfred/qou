    The adjacent commutator as ONE word identity #

    HeckeJucysMurphyReduction.lean showed that all JM commutativity reduces to the adjacent case, and that the adjacent case is proved only at i = 1. This file reduces the adjacent case itself to a single concrete identity between two braid words, at every index.

    The normal forms #

    Write u := σ_k, v := σ_{k+1}, N := L_k. Then L_{k+1} = uNu and L_{k+2} = vuNuv, and

    L_{k+1} L_{k+2} = (uv) N (uv) N (uv)          `jmRaw_adjacent_left`
L_{k+2} L_{k+1} = (uvu) N (uv) N u            `jmRaw_adjacent_right`

    Each is two rewrites: one braid relation uvu = vuv, and one use of N's commutation with v (jmRaw_comm_sigma_far, since k < k+1). The Hecke relation is not used.

    So adjacent commutativity at index k+1 is exactly the assertion that these two words agree.

    Why this is progress #

    The previous formulation, LᵢL_{i+1} = L_{i+1}Lᵢ, hides Lᵢ inside itself — every attempt unfolded the recursion again and reproduced a commutator of the same shape (recorded in qou-u9o1). In the normal forms N appears twice, opaquely, and the only structure left is braid-word bookkeeping around it. Both sides start with uv, so after cancelling that unit the question is

    N (uv) N (uv)  =?=  u N (uv) N u

    for the specific N = L_k.

    Do NOT read that as a question about an arbitrary N commuting with v — that reading is FALSE. Taking N = v, which certainly commutes with v, the two sides differ already in the 2-dimensional irrep of H₃(q) at q = 2 (jm_adjacent_generic_N_counterexample.py, exact rational arithmetic). So adjacent commutativity genuinely needs L_k's structure, not merely its commutation with v; an attack that only assumes the latter cannot work. (The N = 1 line in that script is a control — Lean proves that case, and a first version of the script that reported False there was measuring its own bug, not the mathematics.)

    Consistency at k = 0 #

    At k = 0, N = L₀ = 1 and the forms collapse to (uv)³ and (uvu)(uv)u (jmRaw_adjacent_left_zero, jmRaw_adjacent_right_zero). Those are exactly the two words jmRaw_prod_three and jmRaw_two_mul_one identify with (σ₀σ₁)³ and (σ₁σ₀)³, which fullTwist3_symm proves equal. So the i = 1 case is recovered as the N = 1 specialisation — the normal forms are consistent with the one case already known.

    Still open #

    The identity above for general N — i.e. adjacent commutativity at k ≥ 1. Nothing here proves it; what is gained is that it is now one word identity in one unknown rather than a recursion that regenerates itself. Consequently general ∏Lᵢ = Δ² and the general-λ twist remain open and conditional respectively.

    The open question, stated once. Adjacent commutativity at k+1 holds exactly when the two normal forms agree. This is a restatement, not a proof — but it isolates the problem as a single word identity in the one unknown N = L_k, with no recursion left to unfold.

    A proved SUFFICIENT condition #

    Measurement in the faithful regular representations of H₄ and H₅ (jm_adjacent_h4_structure_probe.py) showed the identity holds for some N and fails for others, with the pattern independent of q but dependent on k — s₀ fails at k = 1 and holds at k = 2. The explanation is that at k = 2 the element s₀ commutes with both u = σ₂ and v = σ₃, and that is enough.

    theorem QOU.BraidKnot.Hecke.braid_cube_eq {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} (H : HeckeGenerators R A q) (k : ℕ) :
    (HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1)) ^ 3 = HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1) * HeckeGenerators.σ q k * (HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1)) * HeckeGenerators.σ q k

    (uv)³ = (uvu)(uv)u at every index — both sides are (uvu)².

    The left side regroups as (uvu)(vuv) and one braid move turns the second factor into uvu; the right side is (uvu)(uvu) by associativity alone. This is the index-k form of the half-twist identity fullTwist3_symm.

    theorem QOU.BraidKnot.Hecke.jmRaw_adjacent_of_comm {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} (H : HeckeGenerators R A q) (k : ℕ) (N : A) (hu : N * HeckeGenerators.σ q k = HeckeGenerators.σ q k * N) (hv : N * HeckeGenerators.σ q (k + 1) = HeckeGenerators.σ q (k + 1) * N) :
    HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1) * N * (HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1)) * N * (HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1)) = HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1) * HeckeGenerators.σ q k * N * (HeckeGenerators.σ q k * HeckeGenerators.σ q (k + 1)) * N * HeckeGenerators.σ q k

    Sufficient condition: an N commuting with both u and v satisfies the identity.

    If N commutes with σ_k and σ_{k+1} it commutes with everything in sight, so both normal forms collapse to N² · (uv)³ and N² · (uvu)(uv)u respectively, and braid_cube_eq finishes.

    This is sufficient, NOT necessary — and the distinction is measured, not guessed. At k = 2 in H₅, N = σ₃² = v² satisfies the identity while not commuting with u = σ₂ (they are adjacent). So this condition explains part of the data and cannot be the characterisation.

    It also does not apply to the case that matters: N = L_k does not commute with σ_k — the hook word L_k ends in σ_{k-1}, adjacent to σ_k — which is exactly why adjacent commutativity is hard and why this lemma does not close it.
