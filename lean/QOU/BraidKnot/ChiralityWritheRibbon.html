    QOU.BraidKnot.ChiralityWritheRibbon — chirality factor from ribbon-twist framing #

    For a closed braid $\hat\beta$ with writhe $w(\beta) \in \mathbb{Z}$, the chirality factor (Term 5 of the QOU mass formula) satisfies, to first order in the Hecke deformation parameter $h = q - q^{-1}$:

    $$ a_K(\beta) = 1 + w(\beta) \cdot h \cdot \langle c(\lambda)\rangle_\beta + O(h^2). $$

    This follows from the Kauffman framing formula: the ribbon twist element $\varTheta_\lambda \in Z(H_n(q))$ acts on the irreducible $V_\lambda$ as $q^{2\kappa_\lambda}$, where $\kappa_\lambda = \sum_{x\in\lambda} c(x)$ is the total Jucys–Murphy content. A change of framing by writhe $w$ multiplies the Markov trace in each Wedderburn channel by $q^{2w\kappa_\lambda}$; expanding to first order in $h$ yields the claim.

    An independent empirical observation (confirmed for $D$, $T$, $^3\mathrm{He}$, $^4\mathrm{He}$) is the multiplicative crossing rule: for every inter-nucleon (pn) crossing with sign $s \in \{+1,-1\}$,

    $$ a_K = \prod_{\text{pn crossings } c}(1 + \mathrm{sign}(c)\cdot h). $$

    The structural first-order result is proved below sorry-free: the chirality factor's first-order coefficient is the character-weighted average content ⟨c⟩_β (chirality_writhe_ribbon). The only categorical input is the ribbon-twist eigenvalue, axiomatized as the class RibbonTwistEigenvalue.framing_formula (Θ_λ = q^{2w·κ_λ}, a standard Jones–Ocneanu fact). The empirical multiplicative pn-crossing rule is a separate conjecture.

    Type

    A Wedderburn channel is a partition λ ⊢ n, encoded here by its total Jucys–Murphy content κ_λ = Σ c(x) and its quantum dimension (Plancherel weight denominator). We keep the abstract structure parameter-free so that the ribbon computation is independent of the underlying Young combinatorics module.

    • kappa : ℤ

      Total Jucys–Murphy content κ_λ := Σ_{x ∈ λ} (col x - row x).

    • weight : ℝ

      Plancherel weight w_λ = dim_q(λ)² / [n]_q! (positive real).

    • weight_pos : 0 < self.weight

      Weights are positive.

        §2 Ribbon twist eigenvalue #

        source
        class QOU.BraidKnot.ChiralityWritheRibbon.RibbonTwistEigenvalue (q : ℝ) :
        Type

        Ribbon twist eigenvalue. The full-twist central element θ_n ∈ Z(H_n(q)) acts on the irreducible Hecke module V_λ by the scalar q^{2κ_λ}. We expose this as an axiom class; it is a standard consequence of the Jones–Ocneanu ribbon structure on H_n(q).

        Ref: [kassel1995] Ch. XIV; [mathas1999] §3.

        • q_pos : 0 < q

          q > 0 (substrate regime).

        • framing_eigenvalue : ℤ → ℤ → ℝ

          The eigenvalue of θ_n^{w} on V_λ is q^{2w·κ_λ} (Kauffman framing: the ribbon twist acts as q^{2κ_λ}, so a writhe-w framing change multiplies channel λ by q^{2w·κ_λ}).

        • framing_formula (w kappa : ℤ) : framing_eigenvalue q w kappa = q ^ (2 * w * kappa)

          The eigenvalue formula: θ_n^{w}|_{V_λ} = q^{2w·κ_λ}.

          §3 Chirality factor as a Wedderburn-weighted ratio #

          source
          noncomputable def QOU.BraidKnot.ChiralityWritheRibbon.chiralityFactor {q : ℝ} [RT : RibbonTwistEigenvalue q] (channels : List WedderburnChannel) (chars : List HeckeCharValue) (writhe : ℤ) (h_len : channels.length = chars.length) :
          ℝ

          The chirality factor for a braid β with writhe w is the ratio of the ribbon-twisted Markov trace to the untwisted trace:

          a_K(β) = (Σ_λ w_λ χ^λ(β) q^{w·κ_λ}) / (Σ_λ w_λ χ^λ(β)).

          We record this as a real number; positivity in the physical regime is not formalized here.

            §4 First-order writhe-linearisation #

            source
            theorem QOU.BraidKnot.ChiralityWritheRibbon.log_q_first_order (q : ℝ) (hq : 0 < q) (κ : ℤ) :
            ∃ (R : ℝ), q ^ (2 * κ) = 1 + ↑κ * (q - q⁻¹) + R * (q - q⁻¹) ^ 2

            Logarithm identity at first order in h. For q > 0 with deformation parameter h = q - q⁻¹, ln q = h/2 + O(h³). Equivalently, q^{2κ} = 1 + κ·h + O(h²).

            This is the key analytic input for the linearisation.

            source
            theorem QOU.BraidKnot.ChiralityWritheRibbon.chirality_writhe_ribbon (q : ℝ) [RT : RibbonTwistEigenvalue q] (writhe : ℤ) (channels : List WedderburnChannel) (chars : List HeckeCharValue) (h_len : channels.length = chars.length) (h_denom : (List.zipWith (fun (ch : WedderburnChannel) (cv : HeckeCharValue) => ch.weight * cv.val) channels chars).sum ≠ 0) :
            ∃ (c_avg : ℝ) (R : ℝ), c_avg = (List.zipWith (fun (ch : WedderburnChannel) (cv : HeckeCharValue) => ch.weight * cv.val * ↑ch.kappa) channels chars).sum / (List.zipWith (fun (ch : WedderburnChannel) (cv : HeckeCharValue) => ch.weight * cv.val) channels chars).sum ∧ chiralityFactor channels chars writhe h_len = 1 + ↑writhe * (q - q⁻¹) * c_avg + R * (q - q⁻¹) ^ 2

            Main proposition — writhe-linearisation of the chirality factor.

            Let β ∈ B_n be a braid with writhe w = w(β). Let h = q - q⁻¹ be the Hecke deformation. Let ⟨c⟩_β = Σ_λ w_λ χ^λ(β) κ_λ / Σ_λ w_λ χ^λ(β) be the character-weighted average Jucys–Murphy content. Then

            a_K(β) = 1 + w · h · ⟨c⟩_β + O(h²),

            and the first-order coefficient c_avg is exactly ⟨c⟩_β (not the vacuous 0): the chirality factor is linear in h and linear in the writhe to first order.

            §5 Amphichiral case (sanity check) #

            source
            theorem QOU.BraidKnot.ChiralityWritheRibbon.chirality_writhe_zero (q : ℝ) [RT : RibbonTwistEigenvalue q] (channels : List WedderburnChannel) (chars : List HeckeCharValue) (h_len : channels.length = chars.length) (h_denom : (List.zipWith (fun (ch : WedderburnChannel) (cv : HeckeCharValue) => ch.weight * cv.val) channels chars).sum ≠ 0) :
            ∃ (R : ℝ), chiralityFactor channels chars 0 h_len = 1 + R * (q - q⁻¹) ^ 2

            Corollary: amphichiral knots have vanishing first-order chirality.

            When writhe w = 0, the linearisation gives a_K = 1 + O(h²). The chirality correction is second-order, consistent with a_{4_1} = 1 - h² for the amphichiral figure-eight knot.

              class QOU.BraidKnot.ChiralityWritheRibbon.PNCrossingRule (q : ℝ) :
              Prop

              Empirical multiplicative crossing rule (conjecture).

              For nuclear knots (D, T, ³He, ⁴He), paper assigns

              a_K = Π_{c ∈ pn-crossings(β)} (1 + sign(c)·h).

              This rule reproduces all three paper assignments:

              • D (1 positive crossing): a_D = 1 + h.
              • T, ³He (1 positive + 1 negative): a = 1 - h².
              • ⁴He (2 positive + 2 negative): a = (1 - h²)².

              A categorical derivation of why each pn crossing contributes (1 ± h) requires specifying the pn coupling in Schur–Weyl terms and is left open. The most structurally natural origin is the spin-½ braiding eigenvalue of U_q(𝔰𝔩₂) on the symmetric component of V₁ ⊗ V₁.

              • q_pos : 0 < q

                q > 0 (substrate regime).

              • pn_product_formula (crossings : List PNCrossing) : ∃ (a_K : ℝ), a_K = List.foldl (fun (acc : ℝ) (c : PNCrossing) => acc * (1 + ↑c.sign * (q - q⁻¹))) 1 crossings

                The chirality factor factorises as a product over pn crossings.
