      theorem QOU.BraidKnot.IsotopeKnot.equivalence [ctx : EquivalenceContext] :
      Equivalence EquivalenceContext.isotope

      Manuscript statement (full body):

      Proposition. The isotope relation is an equivalence on $\{\text{atom-knots with fixed } Z\}$.

      Proof.

      • Reflexivity: $K \sim K$ trivially since $w_{q^Z}^{(1)} = w_{q^Z}^{(2)} = w_{q^Z}$ for $K_1 = K_2$.

      • Symmetry: $K_1 \sim K_2$ iff $w_{q^Z}^{(1)} = w_{q^Z}^{(2)}$, which is symmetric in $K_1, K_2$.

      • Transitivity: If $w_{q^Z}^{(1)} = w_{q^Z}^{(2)}$ and $w_{q^Z}^{(2)} = w_{q^Z}^{(3)}$, then $w_{q^Z}^{(1)} = w_{q^Z}^{(3)}$ by transitivity of equality in $S_{n(K)}$.

      The equivalence classes at fixed $Z$ are parametrised by the neutron-quark block $w_{\bar q^N}$ and inter-nucleon connector $w_{\mathrm{inter}}$, giving the standard isotope chart for element $Z$ (e.g. $Z = 6$: ${}^{12}\mathrm{C}, {}^{13}\mathrm{C}, {}^{14}\mathrm{C}, \ldots$). $\square$

      Quotient structure. The quotient $\{\text{atom-knots}\}/{\sim}$ at fixed $Z$ is the element class for $Z$. This recovers the chemical element concept categorically — element = isotope class.
