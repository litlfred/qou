        def QOU.BraidKnot.TwoRowStratum.enumerateTwoRow (n : ℕ) :
        List (List ℕ)

        The canonical enumeration of Λ²(n) as a list: for each k ∈ {0, 1, …, ⌊n/2⌋}, emit the pair (n - k, k) — but with the trivial-rep (n) written as [n] and the equal-pair case (n/2, n/2) as [n/2, n/2]. Excludes any zero-component partitions (so (n, 0) ↦ [n] rather than [n, 0]).

        Equations
        • QOU.BraidKnot.TwoRowStratum.enumerateTwoRow n = List.map (fun (k : ℕ) => if k = 0 then [n] else [n - k, k]) (List.range (n / 2 + 1))

              class QOU.BraidKnot.TwoRowStratum.HasTwoRowProjection (HeckeAlg : Type u_1) :
              Type u_1

              The two-row projection on the Wedderburn decomposition.

              Axiomatised here as a class encoding the splitting tr_M(β) = tr_M(π_{2-row} β) + tr_M((1 - π_{2-row}) β) for any Hecke element β. The concrete projection requires the full Wedderburn decomposition apparatus (per-partition irrep blocks Hoefsmit basis); the class allows downstream consumers to take its existence as a typeclass hypothesis.

              • pi : HeckeAlg → HeckeAlg

                The projection π_{2-row} : HeckeAlg → HeckeAlg as a function.

              • idempotent (β : HeckeAlg) : pi (pi β) = pi β

                Idempotency: π² = π.
