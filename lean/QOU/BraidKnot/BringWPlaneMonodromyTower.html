    The depth-2 SL₂ power-trace tower of the Bring W-plane monodromy #

    Follow-up to BringWPlaneMonodromy (the unimodular 2×2 monodromy M on the W-plane H¹(E), E = Bring/S₄, with M² = (tr M)·M − I, unimodular_two_recurrence).

    The full-Hecke geometric-index program's selection-rule period a_D^(n) = lw(n−1) (#1765) was empirically pinned this session (sibling bean z2bn, PRs #2795 / #2800 / #2808): the global a_D^(n) is super-exponential (a √-branch falling factorial (1/2)_n), and the depth-2 SL₂ trace τ is only the n ≤ 4 effective fit (it caps at the dominant eigenvalue λ₊ ≈ 2.18 while the lw ratio keeps growing 1.9 → 3.1, so SL₂ diverges from lw by n = 5/6).

    This file formalizes the structural reason that the depth-2 SL₂ side is a bounded-by-exponential object. From the Cayley–Hamilton relation M² = (tr M)·M − I, every power obeys the same depth-2 linear recurrence, and so does the power-trace tower t_n := tr(Mⁿ) (the quantity the sibling probe computes):

    t_{n+2} = (tr M)·t_{n+1} − t_n (the Chebyshev / Lucas recurrence, with τ = tr M).

    A solution of a depth-2 linear recurrence is t_n = A·λ₊ⁿ + B·λ₋ⁿ (λ_± the roots of x² − τ x + 1, λ₊λ₋ = 1), hence O(λ₊ⁿ) — exponential. It therefore cannot reproduce a super-exponential lw(n−1) for large n — the formalized counterpart of the sibling's numerical "SL₂ diverges by n = 5/6".

    Scope (a), per AGENTS.md "before declaring refuted". This is a scope-(a) statement: the depth-2 SL₂ trace tower, alone, is an exponential object and so is only the n ≤ 4 effective fit — it does not capture the global super-exponential a_D. It is not a scope-(b) structural exclusion of SL₂/monodromy data from the closure (the exponential-vs-super-exponential growth gap is cited from the sibling's empirical run #2795/#2808, not Lean-proved here; the global object plausibly composes the depth-2 tower with higher q-Bessel / Rogers–Szegő layers, per #2800's 3-layer map).

    Base ring ℝ; pure linear algebra. τ appears only as the symbol tr M. No fit.

    The first two rungs of the tower are the universal SL₂ trace seeds: t₀ = tr(I) = 2 and t₁ = tr M. With powTrace_recurrence these determine the whole tower t_n = tr(Mⁿ) — the depth-2 rigidity: two seeds fix every higher rung (so a depth-2 SL₂ tower has only two free parameters, the formalized sense in which fitting the low-n lw values over-determines it).
