    QOU.BraidKnot.CanonicalKnotIdSDPUniqueness #

    Wires QOU.MathlibExt.SDP.strict_complementarity_unique and QOU.HeckeAlgebra.Common into a concrete Subsingleton-style uniqueness statement for the canonical knot identification of light nuclei (²H, ³H, ³He).

    This is the "infra-backed" upgrade of the existence-only witness-conditioned theorems in folio/quantum-observable-universe/braids-and-knots/conj-canonical-knot-id-sdp.lean.

    What this module proves #

    canonical_T_w_unique_under_strict_complementarity — given an SDP sdp with a StrictComplementarityPair sc, the primal optimum (the canonical T_w element for the nucleus) is unique among all primal-feasible matrices achieving the same objective. This is QOU.MathlibExt.SDP.strict_complementarity_unique re-stated in the Hecke-algebra setting, with the Hecke-algebra HeckeElement n cast through the Matrix (Fin (heckeDim n)) (Fin (heckeDim n)) ℝ representation that SDPPrimal consumes.

    Open work #

    The casting HeckeElement n → Matrix _ _ ℝ is currently a stub (rank-1 outer-product representation; the full Wedderburn- block matrix representation is the open Lean port of the Hoefsmit machinery).

    References #

    • [boyd-vandenberghe-2004] Boyd, Vandenberghe, Convex Optimization.
    • [todd2001] Todd, Semidefinite optimization, Acta Numerica 10 (2001).

    def QOU.BraidKnot.heckeAsMatrix {n : ℕ} (x : HeckeAlgebra.HeckeElement n) :
    Matrix (Fin (HeckeAlgebra.heckeDim n)) (Fin (HeckeAlgebra.heckeDim n)) ℝ

    Hecke element → matrix representation stub. Casts an abstract HeckeElement n into a matrix in the dimension expected by SDPPrimal. Concrete representation: the rank-1 outer product x ⊗ x, which is positive-semidefinite for ALL x (including x = 0, where the result is the zero matrix; PSD by convention). The full Wedderburn-block representation is the open Lean port of Hoefsmit.

      Hecke-element-as-PSD-matrix is positive-semidefinite — rank-1 outer products always are.

      PROOF: write heckeAsMatrix x = (col x) · (col x)ᵀ. Then apply Mathlib's Matrix.posSemidef_self_mul_transpose (or similar — verify exact name). Direct unfolding works: ((col x) · (col x)ᵀ) i j = Σ_k (col x) i k · ((col x)ᵀ) k j = (col x) i 0 · (col x) j 0 = x i · x j.

      heckeAsMatrix T_w' = heckeAsMatrix T_w_star

      Canonical T_w uniqueness — Hecke-algebra-flavoured specialisation of strict_complementarity_unique. Given an SDP whose primal optimum is the cast of a Hecke element T_w_star, any other primal-feasible Hecke element with the same objective value casts to the same matrix — and (in the full theory) is therefore equal to T_w_star.

      This is the bridge theorem the conj-canonical-knot-id-sdp.lean helium3_canonical_uniqueness_via_strict_complementarity will consume once the per-nucleus SDP instance and certificate are constructed.
