    Standard Young tableaux, and the base case of the JM spectrum #

    This is the start of the spectral half — the half of JucysMurphySpectrum that says Lᵢ acts on the seminormal basis with eigenvalue q^{2·content}. It is the larger half and is not closed here; what this file does is make its indexing objects real.

    Why a bijection is not enough #

    KeystoneJucysMurphyTwist.lean models a tableau as a bijection Fin n ≃ cells λ. That is exactly right for sum_content_of_equiv — the content sum reindexes along any bijection — but it is too weak for the spectral statement, which holds for standard tableaux only. The seminormal representation is built on the standard ones; an arbitrary filling indexes nothing.

    So this file defines StandardTableau, carrying the increasing conditions, and records that the weaker results still apply to it (StandardTableau.sum_content).

    The base case is forced, and proved #

    Lᵢ's spectral rule must give eigenvalue q^{2·content} of the cell holding entry i. At i = 0 the JM recursion gives L₁ = 1, so the rule is only consistent if entry 0 sits at a cell of content 0. StandardTableau.zero_at_corner proves it sits at (0,0) exactly — hence content 0 − 0 = 0 and q⁰ = 1.

    That is a genuine consistency check on the assumed spectral rule, discharged rather than assumed: the rule's base case is forced by standardness plus the partition shape, not chosen to fit.

    What remains #

    Everything else. The seminormal representation, the diagonal action of Lᵢ, and the eigenvalue at general i are all still absent, and remain the content of JucysMurphySpectrum. Nothing here discharges it; this narrows what a future proof has to construct, and pins one endpoint.

    Refs:

    • [macdonald1995] Symmetric Functions and Hall Polynomials, I.1 (partitions, contents).
    • [wenzl1988] Hecke algebra representations (seminormal form).

    Young diagrams are closed upward in a column #

    (r - 1, c) ∈ cells l

    A Young diagram is closed upward within a column. If (r, c) is a cell and r > 0, then (r−1, c) is a cell too — because the partition's rows are weakly decreasing, so row r−1 is at least as long as row r.

    Standard Young tableaux #

    source
    structure QOU.BraidKnot.Keystone.StandardTableau (l : MathlibExt.QPartitionCombinatorics.Partition) (n : ℕ) :
    Type

    A standard Young tableau of shape λ with n entries: a bijection from entries to cells whose inverse is increasing along rows and down columns.

    The conditions are stated in the direction that is convenient to use: if two entries share a row (resp. column) and the first is further right (resp. down), then it is the larger entry.

    • toEquiv : Fin n ≃ { c : ℕ × ℕ // c ∈ cells l }

      The underlying entries-to-cells bijection.

    • row_incr (i j : Fin n) : (↑(self.toEquiv i)).1 = (↑(self.toEquiv j)).1 → (↑(self.toEquiv i)).2 < (↑(self.toEquiv j)).2 → i < j

      Entries increase along a row.

    • col_incr (i j : Fin n) : (↑(self.toEquiv i)).2 = (↑(self.toEquiv j)).2 → (↑(self.toEquiv i)).1 < (↑(self.toEquiv j)).1 → i < j

      Entries increase down a column.
