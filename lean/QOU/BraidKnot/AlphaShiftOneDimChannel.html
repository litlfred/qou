          theorem QOU.BraidKnot.charOf_eq_zpow {G : Type u_1} [CommGroup G] (s : G) (w : Word) :
          charOf s w = s ^ writhe w

          The closed form. On a one-dimensional channel the character of a word is s raised to its writhe — so such a channel sees the writhe and nothing else about the word. The all-row channel (s = q) and the all-column channel (s = −q⁻¹) are the two instances.

          theorem QOU.BraidKnot.abs_val_le_length {G : Type u_1} [CommGroup G] (val : G → ℤ) (hmul : ∀ (a b : G), val (a * b) = val a + val b) (hone : val 1 = 0) (s : G) (hs : (val s).natAbs = 1) (w : Word) :
          (val (charOf s w)).natAbs ≤ List.length w

          The derived bound. When the generator has valuation ±1 — which is what the seminormal entries give at ρ = ∓1 — the character's valuation is bounded by the word length. This is α_shift ≤ L, obtained from the algebra rather than fitted to measurements.

          theorem QOU.BraidKnot.writhe_conj (a w : Word) :
          writhe (a ++ w) = writhe a + writhe w

          The writhe is invariant under conjugating the word. Together with the Markov trace's own conjugation invariance, this is why the bound above is on the REDUCED length rather than the written one.

          theorem QOU.BraidKnot.abs_val_lt_length_of_cancel {G : Type u_1} [CommGroup G] (val : G → ℤ) (hmul : ∀ (a b : G), val (a * b) = val a + val b) (hone : val 1 = 0) (s : G) :
          (val (charOf s [1, -1])).natAbs < [1, -1].length

          Non-vacuity I. The bound is STRICT for a word containing a cancelling pair — a genuine inequality, not an equality in disguise.

          Note the (val s).natAbs = 1 hypothesis of abs_val_le_length is NOT needed here: the writhe of σ σ⁻¹ is zero, so the strictness holds for ANY generator valuation. Stated without it rather than carrying a decorative hypothesis.

          theorem QOU.BraidKnot.writhe_ne_length :
          writhe [1, -1] ≠ ↑[1, -1].length

          Non-vacuity II. The character is not s ^ length in general: the word σ σ⁻¹ has writhe 0 and length 2, so "α_shift = letter count" is a fact about POSITIVE words and does not generalise.
