    sortPerm is minimal-length in its coset #

    The intertwining T_d · x_μ = x_ν · T_d — Lemma 3.9's algebraic step — needs T_v T_d = T_{vd} for every v in the Young subgroup, which is

    ℓ(v · d) = ℓ(v) + ℓ(d)     for all `v ∈ S_μ`,

    i.e. Mathas' d ∈ D_μ. This file proves it for CompositionYoung.sortPerm.

    The argument, and why it needs no Coxeter theory #

    QOU.Hecke.LengthAdditive.length_mul_eq_add_iff (#6444) reduces the whole question to inversion sets — ℓ(u·v) = ℓ(u) + ℓ(v) ↔ invSet v ⊆ invSet (u·v) — unconditionally, so nothing here touches the exchange condition that Mathlib lacks.

    What remains is then two order facts about blocks:

    • Blocks are consecutive, so a smaller block index means a smaller position (lt_of_index_lt). This is assembled from Mathlib's sizeUpTo bounds.
    • A Young element preserves block indices, by definition of youngOfComp.

    Together: an inversion of d must straddle two different blocks (within one block d is increasing), the blocks are then ordered the same way as the positions, and v cannot move a label out of its block — so the inversion survives.

    Mathas' D_μ, and Proposition 3.3's length half in full generality #

    Everything above is stated for sortPerm, but its proof used only one property of that permutation: it never inverts two labels that land in the same block. Mathas calls the permutations with that property D_μ and defines them tableau-side —

    D_μ = { d ∈ S_n | t^μ d is row standard }. Then D_μ is a complete set of right coset representatives of S_μ in S_n. Moreover, if w ∈ S_μ and d ∈ D_μ then ℓ(wd) = ℓ(w) + ℓ(d) and T_{wd} = T_w T_d. (Proposition 3.3)

    — and "t^μ d is row standard" is exactly that condition, since the rows of t^μ are the blocks of μ in order. Defining D_μ by the condition rather than by the tableau keeps this file free of tableau machinery, and gives Prop 3.3's length half for every d, not just the block-sorting one.

      The mirror: ℓ(d · w) = ℓ(d) + ℓ(w) #

      Tw_mul_Tw is handed — T_v · T_w = T_{w·v} — so the two factors of Murphy's m_{st} = T_{d(s)}^* x_μ T_{d(t)} need the length hypothesis on both sides. The one above covers T_d · T_v; this covers T_v · T_d.

      The argument mirrors it and uses the same two block facts: an inversion of a Young element lies inside one block (across blocks it cannot invert, since blocks are ordered), and sortPerm is increasing inside a block, so it preserves that inversion.
