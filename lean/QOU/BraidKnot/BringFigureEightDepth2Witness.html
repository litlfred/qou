    QOU.BraidKnot.BringFigureEightDepth2Witness — conjecture carrier #

    §3b-cond class axiomatisation for content block conj:bring-figure-eight-depth-2-witness: Bring figure-8 volume as depth-2 grouplike value (50-digit numerical witness).

    Primary conjecture carrier with no instance — the honest open state per AGENTS.md §3b-tax.

    What changed (bean qou-ffwk) #

    The previous field schema was a scalar residual : ℝ plus a field asserting it vanishes, which is inhabited by ⟨0, rfl⟩. The class chose its own witness, so it asserted nothing and a downstream [BringFigureEightDepth2Witness] hypothesis was not a meaningful conditional. The compared quantities are now class parameters, so an instance must discharge the claim for the caller's data.

    Two stale statements in the old header are also corrected. It said "the noncomputable instance is the conjectural witness whose sorry represents the open conjecture" while the body two paragraphs later said no instance is provided — the axiom-and-instance pair had been removed without the header being updated. And what was removed was an axiom, not a sorry; the distinction matters, because a sorry at least surfaces as sorryAx.

    Which half is the conjecture #

    The block asserts a chain:

    Vol(S³ \ 4₁)  =  std(2 Im Li₂^q(e^{iπ/3}))  =  2 Cl₂(π/3)

    and its own status note splits it: "Numerically discharged at 50 digits via mpmath … Conjectural as a structural identification of the depth-2 grouplike value with Vol(4₁)." So the two equalities have different standing, and only the first is conjectural. The second is the evaluation, verified to 50 digits by computations/gb_depth_period_bring_fig8.py with a committed witness, and the block records that a partial-sum cross-check agrees to about 13 digits.

    The class therefore carries one field, the structural identification. Folding the evaluation in as a second field would mark verified work as conjectural, which is the mirror image of the defect this bean exists to fix. The evaluation enters instead as a hypothesis of evaluates_to below, so a caller composes the two and the provenance of each stays visible.

    Equality is stated exactly, not within a tolerance. The block writes = and the 50-digit figure is evidence for the identity rather than a claim that it holds only approximately — unlike conj:gs-archimedean-agreement-*, which writes ≈ and whose carriers are parameterised by a tolerance for that reason.

    Conditionality that cannot be expressed here, and why #

    The block states the conjecture is "conditional on conj:gb-depth-period-correspondence". That would naturally be an instance parameter — the §3b-cond shape — but it cannot be one: the corresponding class QOU.AlgebraicSubstrate.GBDepthPeriodCorrespondence exists only as a co-located stub (mass-theory/gb-depth-period-correspondence.lean), and per QOU.GroundRingAnnotations co-located stubs are documentation that lake does not compile. A library module cannot import one.

    So the dependency is documented here and not enforced by the elaborator. Making it enforceable requires promoting that carrier into lean/QOU/, which is its own piece of work and is not attempted here. Recorded rather than quietly dropped: an instance of this class does not discharge the correspondence it rests on.

    Base ring (§7c) #

    ℝ is required and not a gratuitous specialisation. The left side is a hyperbolic volume, the right is a standard part — the map out of the graded structure into the observable value. Both live on the observable side of the substrate wall by construction; that is what "archimedean" means in this block's own depth table.

    class QOU.BraidKnot.BringFigureEightDepth2Witness (figureEightVolume grouplikeStd : ℝ) :
    Prop

    Bring figure-8 volume as a depth-2 grouplike value.

    The conjecture of conj:bring-figure-eight-depth-2-witness: the hyperbolic volume of the figure-8 knot equals the standard part of the depth-2 grouplike value at the regular-ideal-tetrahedron shape parameter.

    Parameters are the caller's data:

    • figureEightVolume — Vol(S³ \ 4₁), the archimedean side;
    • grouplikeStd — std(2 Im Li₂^q(e^{iπ/3})), the algebraic side.

    Both sides carry Goncharov period-depth 2 and iterated-integral depth 2 respectively. That match is not a field: the block derives it "by construction of the Bloch–Wigner regulator", so it is a fact the conjecture is stated against, not part of what the conjecture asserts.

    An instance is the conjecture, for that data. None is provided, and an instance would still not discharge conj:gb-depth-period-correspondence — see the header.

    • identifies : figureEightVolume = grouplikeStd

      The conjecture: the structural identification of the volume with the depth-2 grouplike value.

      The class is satisfiable, and only at data that satisfies it #

      Two checks in opposite directions. Tightening a vacuous carrier can overshoot into one nobody can ever instantiate, which is a false claim rather than an open one. And the tightening is pointless unless inhabitation genuinely depends on the data. Neither is an instance, so typeclass resolution cannot pick either up and silently close a downstream hypothesis.
