    QOU.BraidKnot.RegularRepBlockTrace — side 2 (Wedderburn block trace) of Identity (B) #

    RegularRepTrace discharged side 1 of the Identity-(B) trace equation: tr_reg(C₂) = n!·binom(n,2) over any CommRing R, ℂ-free. This file discharges side 2 — tr_reg(C₂) = Σ_λ dim(λ)²·ω_λ — as a rigorous conditional result (§3b-cond), the only unproved input being a single hypothesis bundle that Mathlib does not yet provide.

    The Mathlib gap, isolated #

    Side 2 needs the Wedderburn block decomposition of R[S_n] together with the Jucys–Murphy eigenvalue theorem (the central C₂ = Σ_k X_k² acts on the λ-isotypic block by the scalar ω_λ = Σ_{c∈λ} c(c)²). Equivalently — and this is all the trace computation actually uses — the endomorphism mulLeft C₂ is diagonalisable with the block spectral decomposition mulLeft C₂ = Σ_λ ω_λ · π_λ, where π_λ projects onto the λ-isotypic block (R-dimension dim(λ)²) and Σ_λ π_λ = id.

    The existence of a block decomposition is semisimplicity, which is in the pinned Mathlib (Mathlib.RepresentationTheory.Maschke: R[G] is semisimple when |G| is invertible in R). What is not in Mathlib is the S_n-specific Okounkov–Vershik layer pinning down which blocks and which scalars: the partition ↔ irreducible classification, dim(λ) = #SYT(λ), and the JM-eigenvalue = contents theorem. That identification — not semisimplicity — is the irreducible content of the hypothesis below. (Mathlib.RepresentationTheory.* is merely missing from this sandbox's partial olean cache; it builds from the pinned commit, so the gap is genuinely the Okounkov–Vershik mathematics, not a toolchain artifact.)

    SnWedderburnSpectralData bundles exactly that hypothesis. Everything downstream of it is fully proved in pure linear algebra (trace is linear; trace of a projection is the rank of its range, LinearMap.IsProj.trace; finrank (R[S_n]) = n!), so the theorems are honest conditional results: if the spectral decomposition exists, then the conclusions hold — verified by Lean modulo the single named structural input.

    What is derived (non-degenerate — the conclusions are produced, not assumed) #

    • blockTrace_eq — tr_reg(C₂) = Σ_λ ω_λ·dim(λ)² (side 2). The quadratic dim(λ)² is produced by IsProj.trace (= finrank of the rank-dim(λ)² block), not carried as a field.
    • sumSq_dim_eq — Σ_λ dim(λ)² = n! (the RSK sum-of-squares, the "dim side" the gate note flagged as needing HLF/RSK). Produced from completeness Σ π_λ = id and tr(id) = finrank = n!.
    • identityB_conditional — Σ_λ dim(λ)²·ω_λ = n!·binom(n,2): Identity (B) itself, obtained by equating side 2 (blockTrace_eq) with side 1 (RegularRepTrace.trace_centralC2_…).

    To read ω_λ as the content-square sum Σ_{c∈λ} c(c)² (so identityB_conditional becomes the literal Plancherel content-square mean of the keystone) is the residual JM-eigenvalue identification; the sibling IdentityIContentDecomposition.idB_verified_le12 confirms the same equality numerically for all partitions of n ≤ 12.

    Base ring: Field R. Side 2 is genuinely a field phenomenon — semisimplicity / Wedderburn fails over a general CommRing — so Field is the weakest typeclass that admits the construction (§7c); the eigenvalues/contents are integers, hence live in any field. (Side 1 stays CommRing-generic and is reused here by specialisation.)

    structure QOU.BraidKnot.RegularRepBlockTrace.SnWedderburnSpectralData (R : Type u_1) [Field R] (n : ℕ) :
    Type (max 1 u_1)

    The isolated Mathlib gap for side 2. A Wedderburn / Jucys–Murphy block spectral decomposition of mulLeft C₂ on the regular representation R[S_n]: a finite family of projections proj i onto blocks p i of R-dimension d i ^ 2 (the λ-isotypic components, dim(λ)²), the central element acting as the scalar ω i on block i (mulLeft C₂ = Σ_i ω_i · proj_i), and the blocks exhausting the space (Σ_i proj_i = id).

    This bundles precisely the S_n Okounkov–Vershik content not in Mathlib (the partition ↔ irreducible classification, dim(λ) = #SYT(λ), and JM eigenvalues = contents) that pins the blocks and scalars; the existence of such a decomposition is semisimplicity (RepresentationTheory.Maschke, which is in Mathlib). Every theorem below is proved outright given such a datum.

    • Idx : Type

      Index of the irreducible blocks (the partitions of n).

    • fintypeIdx : Fintype self.Idx
    • d : self.Idx → ℕ

      d i = dim(λ_i), the dimension of the i-th irreducible.

    • ω : self.Idx → R

      ω i = the scalar by which C₂ acts on block i (the JM eigenvalue Σ_{c∈λ_i} c(c)²).

    • p : self.Idx → Submodule R (MonoidAlgebra R (Equiv.Perm (Fin n)))

      The i-th isotypic block (R-dimension d i ^ 2).

    • proj : self.Idx → Module.End R (MonoidAlgebra R (Equiv.Perm (Fin n)))

      The projection onto block i.

    • isProj (i : self.Idx) : LinearMap.IsProj (self.p i) (self.proj i)

      proj i is the projection onto p i.

    • rank (i : self.Idx) : Module.finrank R ↥(self.p i) = self.d i ^ 2

      The i-th isotypic block has R-dimension dim(λ_i)².

    • decomp : LinearMap.mulLeft R (RegularRepTrace.centralC2 n) = ∑ i : self.Idx, self.ω i • self.proj i

      Block spectral decomposition: C₂ acts as the scalar ω i on block i.

    • complete : ∑ i : self.Idx, self.proj i = LinearMap.id

      The blocks exhaust the regular representation.

      Non-vacuity — the hypothesis bundle is satisfiable #

      The conditional results above are vacuous if SnWedderburnSpectralData cannot be instantiated, so we exhibit the degenerate n = 0 witness. R[S_0] ≅ R is one-dimensional; the single (empty) partition has dim = 1, and C₂ = 0 (an empty Fin 0 sum) so its eigenvalue is ω = 0 and the lone block is the whole space. This sorry-free instance certifies that the structure is consistent / not over-constrained. (Non-degenerate instances, n ≥ 2, require the actual Wedderburn block decomposition — the isolated Mathlib gap this file is conditional on.)
