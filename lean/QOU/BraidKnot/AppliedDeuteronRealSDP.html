    QOU.BraidKnot.AppliedDeuteronRealSDP — ²H real per-nucleus SDP (Phase D) #

    Phase D of the [#1575] real-SDP workplan: replace the abstract empty-constraint SDP (deuteron_emptySDP, cost = identity, no constraints) with the real deuteron SDP whose cost and constraints come from the mass-formula assembly.

    The numeric assembly + dual certificate live in computations/deuteron_real_sdp.py → deuteron-real-sdp.witness.json (Phase A cost, Phase B branching constraints, Phase C strong-duality solve). This file is the Lean type-level wiring: it states the real SDP as an SDPPrimal over the 11 Wedderburn blocks λ ⊢ 6, and derives uniqueness from the generic ℝ-uniqueness bridge real_strict_complementarity_unique_of_dualSlack_posDef conditional on the dual-slack PosDef certificate the SDP solve emits.

    Status #

    This is a scaffold. The cost vector and the dual-slack PosDef certificate are abstracted as hypotheses (RealSDPCertificate), matching the §3b-cond conditional-class pattern: the Lean statement is fully verified modulo the single class instance that the numeric witness supplies. Discharging the instance from the witness JSON (the clarabel/cvxpy dual) is the final wiring step, tracked as a follow-up.

      structure QOU.BraidKnot.RealSDPCertificate (m : ℕ) :
      Type

      Real deuteron SDP certificate (§3b-cond conditional class).

      Bundles the data the numeric solve (deuteron_real_sdp.py → deuteron-real-sdp.witness.json) produces that Lean cannot yet recompute internally:

      • sdp — the real per-nucleus SDP (non-identity cost from the mass formula, branching constraints), at the block dimension m.
      • rs — a real strong-duality pair (primal optimum Φ⋆, dual y⋆) certified by the clarabel/cvxpy solve.
      • dualSlack_posDef — the dual slack S(y⋆) = T − Σ yᵢ⋆ Aᵢ is positive-definite (strong-duality / strict- complementarity certificate; the bounded positive-norm subspace solve in #1582 supplies this).

      A term of this class is exactly the witness's strong-duality certificate. Everything downstream is proved from it.

      • sdp : MathlibExt.SDP.SDPPrimal m ℝ (Fin 3)

        The real per-nucleus SDP at block dimension m.

      • rs : MathlibExt.SDPRealUniqueness.RealStrongDualityPair self.sdp

        The certified real strong-duality pair.

      • dualSlack_posDef : (self.sdp.dualSlack self.rs.ystar).PosDef

        The dual slack is PosDef (the solve's certificate).
