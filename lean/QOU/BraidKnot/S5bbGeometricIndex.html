    QOU.BraidKnot.S5bbGeometricIndex #

    Lean formalisation of the geometric index for the s5bb keystone.

    This file class-axiomatises the contact geometry properties of the 5-manifold, specifically the existence of a nowhere-zero U(1) ⊂ SU(3) colour Reeb vector field outside the SO(3) isotropy, and defines its equivariant index against the Ocneanu weights.

    Honesty note: the target value 4143/90 that S5bbClosure posits this index hits is fit-tier (no derivation trail; cited Reeb route refuted — see the class docstring). Everything here is an assumed hypothesis; nothing in this file derives c₄.
