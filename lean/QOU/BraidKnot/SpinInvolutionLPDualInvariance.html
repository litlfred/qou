    QOU.BraidKnot.SpinInvolutionLPDualInvariance #

    Canonical declaration for content block at quantum-observable-universe/mass-theory/spin-involution-lp-dual-invariance-proof.ts.

    Formalises the manuscript proof that the spin involution σ is an isometry of the Frobenius pairing ⟨a,b⟩ = τ(ab) and leaves the LP cost functional invariant (Steps 1 and 3). The apparatus — trace τ, anti-multiplicative involution σ with τ∘σ = τ and cyclic τ — is axiomatised as a context class (pure algebra over a generic ring; §7c-clean).

    Type u_1

    The spin-involution / Frobenius-trace apparatus.

    A definition carrier: a ring A, the Markov trace τ, the spin involution σ, and its structural properties — anti-multiplicativity σ(a)σ(b) = σ(ba), involutivity σ∘σ = id, trace-invariance τ∘σ = τ, the cyclic (Markov) property τ(ab) = τ(ba), and a σ-fixed cost c.

    • τ : A → ℝ

      The Markov trace τ : A → ℝ.

    • σ : A → A

      The spin involution σ.

    • sigma_antimul (a b : A) : self.σ a * self.σ b = self.σ (b * a)

      Anti-multiplicativity: σ(a)·σ(b) = σ(b·a).

    • sigma_involutive (a : A) : self.σ (self.σ a) = a

      σ is involutive.

    • trace_sigma (a : A) : self.τ (self.σ a) = self.τ a

      Trace-invariance τ ∘ σ = τ.

    • tau_cyclic (a b : A) : self.τ (a * b) = self.τ (b * a)

      Cyclic / Markov property τ(ab) = τ(ba).

    • c : A

      The LP cost element c, fixed by σ.

    • sigma_c : self.σ self.c = self.c

      σ fixes the cost: σ(c) = c.

        De-axiomatisation (concrete model, bean ovh1). The n×n real matrix algebra with the transpose σ = (·)ᵀ and the matrix trace τ is a genuine instance — every carrier axiom is a theorem, not an assumption: anti-multiplicativity is Matrix.transpose_mul, involutivity is Matrix.transpose_transpose, trace-invariance is Matrix.trace_transpose, the Markov/cyclic law is Matrix.trace_mul_comm, and the identity matrix is σ-fixed (Matrix.transpose_one). So the spin-involution apparatus — hence the LP-dual invariance results proved over it — is realisable.
