    Porting the Jucys–Murphy theory onto the bounded presentation #

    HeckeBoundedGenerators.lean introduced HeckeGeneratorsBelow R A q n — the H_n(q) relations, required only for the generator indices that occur there — because HeckeStableScalarCascade.stdTwo_no_stable_extension shows the unbounded HeckeGenerators cannot host an irreducible representation.

    This file ports the Jucys–Murphy theory onto it.

    The port GENERALIZES; it does not fork #

    HeckeGenerators.toBelow downcasts every unbounded presentation to a bounded one at every n, and jmRawB_toBelow / jmB_toBelow say the JM elements agree on the nose. So a theorem proved on HeckeGeneratorsBelow implies its unbounded counterpart immediately — the bounded statement is strictly stronger, and each ported result below is followed by the recovery of the original as a corollary rather than a copy.

    That is the whole reason to spend the bound bookkeeping: it buys a strictly larger class of models (now including the 2-dimensional stdTwoBelow3) at no loss of theorems.

    What the bounds cost #

    Each relation is now conditional, so every use carries an index side-condition:

    relation needs
    hecke i i + 1 < n
    braid i i + 2 < n
    far i j i + 1 < j and j + 1 < n

    The side-conditions are what the port has to thread; the algebra is unchanged.

    Refs:

    • [jones1987] V. Jones, Hecke algebra representations of braid groups and link polynomials.
    • [wenzl1988] H. Wenzl, Hecke algebras of type A_n and subfactors.
