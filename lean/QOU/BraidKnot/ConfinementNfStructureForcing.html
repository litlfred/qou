    QOU.BraidKnot.ConfinementNfStructureForcing — conjectural class (§3b), content-bearing #

    §3b class axiomatisation for content block conj:confinement-nf-structure-forcing: Confinement → NF-structure forcing.

    Given a compound braid β = β₁ ⋆ I ⋆ β₂ ∈ Bₙ across a basis interface I, assuming the confinement hypothesis |A| < n! (the active LP/SDP set A is a proper subset of all n! partition channels), the class carries the conjecture's two-part content:

    1. NF-support localisation — the Wedderburn maximiser λ⋆ = argmax_λ ord⁻_{q=0} χ_λ(T_β) resides strictly inside the active set (λ⋆ ∈ A).
    2. Duality-bounded shift — the structural NF shift decomposes as shift_NF(β) = α_shift(I) + Δ(β₁,β₂;A) with the deviation bounded by the LP duality gap, |Δ| ≤ duality_gap(β).

    Matured from a degenerate residual : ℝ / residual = 0 placeholder to the faithful two-part statement above (bean cj421). Two consequences are derived, sorry-free (shiftNF_mem_band, shiftNF_eq_of_zero_gap): the NF shift is trapped in the band α_shift ± duality_gap, and an exact zero gap forces shift_NF = α_shift — matching the benchmark's observed exact-zero-gap outcome.

    Per AGENTS.md §3b-cond we provide no global instance: supplying one means exhibiting the actual QOU objects (the NF shift, interface shift, and duality gap of a real compound braid) together with the localisation and shift-bound facts — which is exactly the open conjecture. The honest open state (§3b-tax) is a content-bearing class with no instance. Downstream theorems may take [ConfinementNfStructureForcing] as an explicit [Instance] hypothesis to derive rigorous-conditional results (§3b-cond).

    Type

    Confinement → NF-structure forcing — §3b conjecture class carrying the localisation + duality-bounded-shift content.

    Conjectural class — see conj:confinement-nf-structure-forcing.

    • activeSet : Finset ℕ

      The active LP/SDP set A ⊆ {λ ⊢ n} of partition labels with y_λ⋆ > 0, indexed as ℕ.

    • nFactorial : ℕ

      The confinement bound n! (the order of Sₙ).

    • confinement : activeSet.card < nFactorial

      Confinement hypothesis |A| < n!: the active set is a proper (confined) subset of all n! partition channels.

    • lambdaStar : ℕ

      The Wedderburn maximiser λ⋆ = argmax_λ ord⁻_{q=0} χ_λ(T_β).

    • localisation : lambdaStar ∈ activeSet

      Part 1 (NF-support localisation). The maximiser resides strictly inside the active set: λ⋆ ∈ A.

    • shiftNF : ℝ

      The structural NF shift shift_NF(β).

    • alphaShift : ℝ

      The interface base shift α_shift(I).

    • delta : ℝ

      The structural deviation Δ(β₁, β₂; A).

    • dualityGap : ℝ

      The LP/SDP duality gap duality_gap(β).

    • shift_decomp : shiftNF = alphaShift + delta

      Part 2a (shift decomposition). shift_NF(β) = α_shift(I) + Δ.

    • delta_bounded : |delta| ≤ dualityGap

      Part 2b (duality-bounded deviation). |Δ| ≤ duality_gap(β).
