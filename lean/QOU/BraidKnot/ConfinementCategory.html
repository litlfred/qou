    Confinement Category #

    The category Conf has confined particles as objects and {unfolding, folding, dressing} as morphisms. The Markov trace extends to a functor tr_M : Conf → R_q.

    Design — list-based morphisms (Pattern 4 / no axioms) #

    A morphism P → Q is a list of atomic moves (unfold, fold, dress) chained source-to-target. This representation makes composition a transparent cons/append operation, so the category laws (id_comp, comp_id, assoc) are proved by induction, not asserted as axioms.

    The earlier opaque ConfMorphism.comp + three category axioms have been removed: making comp transparent eliminates the underlying need for them.

    inductive QOU.BraidKnot.AtomicConfMove :
    ConfinedParticle → ConfinedParticle → Type

    Atomic confinement move. A single generator of the confinement category — unfolding, folding, or dressing. The full morphism P → Q is a list (chain) of these.

    • unfold (P P' : ConfinedParticle) : P.level = P'.level + 1 → AtomicConfMove P P'

      Unfold P to a finer representation P' (P.level = P'.level + 1).

    • fold (P P' : ConfinedParticle) : P'.level = P.level + 1 → AtomicConfMove P P'

      Fold P to a coarser representation P' (P'.level = P.level + 1).

    • dress (P_bare P_dressed : ConfinedParticle) (shellName : String) : AtomicConfMove P_bare P_dressed

      Dress P_bare with a named shell, producing P_dressed.

        Empty chain — identity morphism on P.

        Prepend an atomic move to an existing chain.
