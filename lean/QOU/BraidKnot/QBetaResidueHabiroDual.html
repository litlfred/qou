    Q_β residue-A Habiro element: the bar-ODD dual of α_EM #

    The α_EM next-order factor H = [2]_q·(1 − h²α) (alpha-em-habiro-bar-involution, PR #1511) is bar-EVEN — a fixed point of the bar involution — with a modular zero at ζ₄. The α_EM block records that the Q_β analogue "whose trace difference is not a bar fixed point … required a separate cancellation analysis", and that it carries a modular pole at ζ₄ — "the exact structural dual" of α_EM's zero.

    Two independent results this session pin the Q_β residue (the c_3 source) to the bar-ANTIsymmetric sector:

    • PR #1900: the c_k-recursion kernel's leading coefficient a_1 = −c_3 = √2·Φ₂ is bar-odd;
    • PR #1907: the on-main α_eff = (z−1)·h/2 is bar-odd (h = q − q⁻¹ bar-odd).

    What is (and is NOT) formalised here — the 2-variable picture #

    Exactly as in the α_EM file, the bar involution is modelled at the fibre level by treating q and its inverse qi as independent ring variables and taking "bar" to be the swap q ↔ qi (generic CommRing; no reality, no archimedean evaluation — per AGENTS.md "Im(q) fibre vs observable"). The genuine q ↦ q⁻¹ involution, the ζ₄ root of unity, and the literal q + q⁻¹ = 0 condition are all recovered only after specialising qi = q⁻¹ (a group-of-units / field structure). The lemmas below are therefore stated in the swap picture; the ζ₄/pole reading is the interpretation under that specialisation and is flagged as such, not proved as a complex-analytic pole (that would need a localisation / fraction field).

    The bar-EVEN generator is [2]_q = q + qi; the bar-ODD generator is h = q − qi. The residue numerator is N = h·(1 − h²α) (bar-odd); the residue element is F = N / [2]_q, singular at the [2]_q zero locus.

    This is a structural statement (parity + zero/non-vanishing at the bar-antifixed locus). It does NOT claim the full F, the archimedean evaluation τ(F) = c_3, or any c_3 value — those remain the KLR/SW-residue kernel frontier (docs/scope/2026-06-05-qbeta-residue-a-klr-crystal-kernel-scope.md).

          theorem QOU.BraidKnot.QBetaResidueDual.residue_vs_alphaEm_at_bar_antifixed {R : Type u_1} [CommRing R] (q α : R) :
          bracketTwo q (-q) = 0 ∧ residueNum q (-q) α = 2 * q * (1 - (2 * q) ^ 2 * α)

          Zero/non-vanishing duality at the bar-antifixed locus, packaged. At qi = −q: the α_EM factor [2]_q is zero, while the Q_β residue numerator N equals 2q(1 − 4q²α) (non-zero under residueNum_ne_zero_at_bar_antifixed's hypotheses). So [2]_q's vanishing is α_EM's zero in the bar-even sector and the pole of F = N/[2]_q in the bar-odd sector — two faces of the same factor. (Equalities only; non-vanishing/pole are the separate lemma + caveat.)
