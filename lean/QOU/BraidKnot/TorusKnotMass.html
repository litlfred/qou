    QOU.BraidKnot.TorusKnotMass — torus-knot mass class extending VolumeConjecture #

    Refinement scaffolding for the RT-route SM mass derivation, per docs/audits/2026-05-24-pr1122-retraction-and-existing-canonical-adaptation.md §3.B + docs/audits/2026-05-24-rt-binomial-cherry-pick-trace-evaluation.

    The hyperbolic-knot mass-derivation chain uses QOU.Kashaev.VolumeConjecture to identify $\\mathrm{Vol}(S^3 \\setminus K) = 2\\pi \\lim_N \\log|J_N(K)| / N$. For torus knots $T(p, q)$ this gives $\\mathrm{Vol} = 0$ (Seifert- fibered), so $|J_N|$ grows sub-exponentially — and the mass formula $m(K) = m_e \\cdot \\mathrm{Vol}(K) / \\hbar_q^2$ gives ZERO.

    The torus-knot mass derivation requires a DIFFERENT chain. This file scaffolds the class structure: TorusKnotMass extends VolumeConjecture with:

    • A polynomial growth-rate field for $|J_N(T(2, n))|$ in $N$
    • A mass-formula split between gauge bosons (W, Z) and the Higgs scalar
    • Cross-particle ratio fields tied to the Weinberg angle and Higgs self-coupling (via CategoricalHiggsIdempotent)

    This is a SCAFFOLD class (§3b conjecture carrier): the class fields encode the conjecture's content; no instance is provided — the open state per §3b-tax. Downstream theorems take [TorusKnotMass] as an explicit instance hypothesis.

    Empirical input (from probes, NOT proved):

    • From rt_binomial_trace_evaluation_probe.py:
      • mass / P_m(h_0) ≈ 143 for gauge bosons (W, Z)
      • mass / P_m(h_0) ≈ 171 for Higgs scalar (H)
      • W/Z ratio matches SM cos θ_W within 1% from binomial pattern alone
    • From sibling PR #1125:
      • $c_{2j}(T(2, 2m)) = \\binom{m+j}{2j}/2$ (sympy-proved, 54 cells)

    These empirical findings inform the structure of the class fields below but do NOT supply the proofs — supplying instances is the research-grade work.

    class QOU.BraidKnot.TorusKnotMass :
    Type

    Torus-knot mass class — extends VolumeConjecture with fields for the polynomial growth rate of $|J_N(T(2, n))|$ and the mass-formula split between gauge bosons and scalars.

    The empirical W/Z = cos θ_W result (probe rt_binomial_trace_evaluation_probe.py, PR #1128) is captured here as a TARGET that a complete instance would establish.

    Per AGENTS.md §3b-tax: the class fields encode the conjectural content; the absence of an instance is the open structural statement.

    • poly_growth_degree : ℕ → ℕ

      Polynomial growth rate of $|J_N(T(2, n))|$ in $N$. For torus knots, the Kashaev limit is zero (Vol = 0), so growth must be sub-exponential. The polynomial degree is n - 1 for T(2, n) (heuristic; confirmed by empirical probes for n = 4, 6, 8).

    • poly_growth_degree_eq (n : ℕ) : poly_growth_degree n = n - 1

      The degree formula: $\\deg = n - 1$ for $T(2, n)$.

    • gauge_mass_factor : ℝ

      Multiplicative factor in the mass formula for gauge bosons (W, Z). Empirically (probe rt_binomial_trace_evaluation_probe.py): gauge_mass_factor ≈ 143 (matches mass(W)/P_m(h_0) and mass(Z)/P_m(h_0) within 1%).

    • gauge_mass_factor_pos : 0 < gauge_mass_factor

      Gauge mass factor is positive.

    • scalar_mass_factor : ℝ

      Multiplicative factor in the mass formula for the Higgs scalar (H). Empirically (probe rt_binomial_trace_evaluation_probe.py): scalar_mass_factor ≈ 171 (matches mass(H)/P_m(h_0) within 1%).

    • scalar_mass_factor_pos : 0 < scalar_mass_factor

      Scalar mass factor is positive.

    • factors_distinct : gauge_mass_factor ≠ scalar_mass_factor

      The two mass factors are distinct: gauge bosons and scalars have structurally different categorical normalizations.

    • WZ_mass_ratio : ℝ

      The Weinberg-angle-equivalent ratio: $m_W / m_Z = $ cos θ_W. For torus knots W = T(2,4), Z = T(2,6), this should equal the ratio of their trace polynomials $P_2(h_0) / P_3(h_0)$ when both use the same gauge_mass_factor.

    • WZ_mass_ratio_in_unit : 0 < WZ_mass_ratio ∧ WZ_mass_ratio < 1

      The W/Z ratio is in (0, 1) (W is lighter than Z).
