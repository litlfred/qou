    QOU.BraidKnot.CrystalGraphRealization — crystal-graph realisation (conjecture) #

    Class axiomatisation of [conj:crystal-graph-realization]: under the Brundan–Kleshchev isomorphism, GS canonical basis elements T_w correspond to indecomposable graded projective KLR modules realising Kashiwara crystal highest-weight vectors of Cryst(𝔰𝔩_n).

    The class encodes the data needed by downstream blocks (the crystal node, the Kashiwara raising/lowering operators, the highest-weight predicate); the crystal_realises field is the conjectural input.

    class QOU.BraidKnot.CrystalGraphRealization (R : Type u) [CommRing R] (q : R) :
    Type (u + 1)

    Crystal-graph realisation (conjecture).

    A normal form T_w ∈ H_n(R, q) is realised by a Kashiwara crystal highest-weight vector via the Brundan–Kleshchev isomorphism. The class fields encode:

    • CrystalNode — the crystal node type;
    • nodeOf — the node attached to a normal form;
    • raising / lowering — Kashiwara ẽ_i and f̃_i operators;
    • crystal_realises — the conjecture itself: every node attached to a GS normal form is annihilated by every raising operator.
    • NormalForm : Type u

      Abstract type of Hecke normal forms.

    • CrystalNode : Type u

      Abstract type of crystal nodes of Cryst(𝔰𝔩_n).

    • nodeOf : NormalForm q → CrystalNode q

      Crystal node attached to a normal form.

    • raising : ℕ → CrystalNode q → Option (CrystalNode q)

      Kashiwara raising operator ẽ_i (partial — none when applied to a highest-weight vector).

    • lowering : ℕ → CrystalNode q → Option (CrystalNode q)

      Kashiwara lowering operator f̃_i.

    • crystal_realises (T : NormalForm q) (i : ℕ) : raising i (nodeOf T) = none

      The conjecture itself: every GS normal form's crystal node is a highest-weight vector. Plays the role of sorry.

        def QOU.BraidKnot.CrystalGraphRealization.canonical (R : Type u) [CommRing R] (q : R) :
        CrystalGraphRealization R q

        The degenerate model — a def, deliberately NOT an instance.

        Both carrier types collapse to PUnit and both crystal operators return none, so crystal_realises closes by rfl: it holds because there is nothing for it to say, not because the crystal structure was constructed.

        It was declared instance and documented as "Faithful instance. Carries the explicit research-grade conjecture as a sorry." Neither half held. There is no sorry term anywhere in this file — the two occurrences of the word are both in docstrings — so #print axioms on anything downstream reported no sorryAx, and nodeOf_isHighestWeight above read as an established result about GS normal forms whose only model in scope has exactly one normal form and one node.

        As an instance it satisfied every [CrystalGraphRealization R q] binder by synthesis. Demoting it changes nothing else: measured 2026-08-24, all twelve files that bind this class — eight library modules and four content-block siblings — build with zero errors afterwards, because every one of those binders is a hypothesis in a signature (the honest §3b-cond shape) rather than a synthesis site. The measurement is sensitive rather than vacuous: with this declaration a def, inferInstance for the class fails with "failed to synthesize QOU.BraidKnot.CrystalGraphRealization", and succeeds again when it is restored to an instance.

        The model stays available to anyone who wants it by name; it is simply no longer found by instance synthesis. Same disposition as triv_hecke / triv_wedderburn (PR #5581) and skeletonRealisation (PR #5621). QOU/MassEndomorphism/VolumeBridge.lean is the instance-free design this follows.
