            theorem QOU.BraidKnot.KeystoneWLambdaContinuation.wlambda_ratio_is_qi {R : Type u_1} [CommRing R] (t : R) :
            dq311 t - dq32 t = 1

            The continuation is evaluation. The four block quantum dimensions are fixed qi polynomials in t; therefore any W_λ ratio (in which the D² normaliser cancels) is a ratio of qi polynomials — the root value and the archimedean q₀ value are that one rational function at t = φ versus t = q₀ + q₀⁻¹. Stated for the electron/muon ratio numerator: d((3,1,1)) − d((3,2)) = 1 for all t, an identity of polynomials, hence continuation-stable.
