    QOU.BraidKnot.AJFigureEight #

    The AJ conjecture at the QOU anchor knot, stated concretely.

    Part of the "AJ in QOU, fully and honestly" tranche (docs/audits/2026-07-03-aj-conjecture-dialog-assessment.md). The corpus's existing AJ carrier (QuantumAPolynomial in stochastic-mechanics/phi-q-aj-machinery-identification.lean) is a degree-placeholder; with coloredJones41 now a concrete Lean object (QOU.BraidKnot.HabiroNewtonLadder, sorry-free), the AJ statement can be made content-bearing for the figure-eight: an explicit q-difference operator structure, the annihilation property against the actual colored Jones tower, and the strong-AJ q→1 specialization against the explicit classical A-polynomial A_{4₁}(L, M) = M⁴L² − (M⁸ − M⁶ − 2M⁴ − M² + 1)L + M⁴ (CCGLS tables).

    Honest status (§3b) #

    • The class StrongAJFigureEight carries the strong-AJ statement (Ref: [nguyen-tran-2021], strong AJ for 4₁) as content-bearing fields. Every field is now machine-checked sorry-free: the operator data, the q=1 specialization to the classical A-polynomial (meridian-squared convention), nontriviality (char 0), unit nondegeneracy, and the general-N annihilation — proved in QOU.BraidKnot.AJFigureEightAnnihilation by the division-free qZeilberger certificate telescope (valid at every q ≠ 0, roots of unity included), which also hosts the instance. This file holds the statement layer, the explicit operator, and the pointwise results.
    • The derived theorems genuinely derive (∃-packaging, bar transport via the proved coloredJones41_bar_symmetric) — they do not merely project a class field (§3b-cond non-degeneracy).
    • For the Borromean 𝓑₃ the AJ input stays OPEN, consistent with phi-q-aj-machinery-identification.lean (no instance there either).

    Base ring (§7c) #

    Generic {K : Type*} [Field K] throughout (inverses needed); no ℝ, no ordering, no archimedean constructs. The q→1 specialization is evaluation at 1 : K — algebraic, not a limit.

              class QOU.BraidKnot.AJFigureEight.StrongAJFigureEight (K : Type u_2) [Field K] :
              Type u_2

              Strong AJ for the figure-eight (§3b class; literature theorem, instance not fabricated). Carries, as content-bearing fields, the statement proved in the literature (Ref: [nguyen-tran-2021]): an explicit order-2 inhomogeneous q-difference operator annihilates the colored Jones tower of 4₁ for every q ≠ 0, and its homogeneous part evaluated at q = 1 equals the classical A-polynomial up to a nonzero unit factor unit m. The sorry-free instance (explicit operator, all fields proved — general-N annihilation included) lives in QOU.BraidKnot.AJFigureEightAnnihilation; the empirical reconstruction is computations/aj_figure_eight_operator_construct_verify.py.

              • op : QDifferenceOperator K

                The annihilating operator (explicit in the literature).

              • order_eq : op.order = 2

                The inhomogeneous presentation has order 2.

              • nontrivial (q : K) : q ≠ 0 → NontrivialAt op q

                Non-trivial at every q ≠ 0.

              • annihilates (q : K) : q ≠ 0 → Annihilates op q (HabiroNewtonLadder.coloredJones41 q)

                Annihilates the (concrete, Lean-defined) colored Jones tower of 4₁ at every q ≠ 0.

              • unit : K → K

                The strong-AJ unit factor relating the q = 1 specialization to the classical A-polynomial. For the actual operator it is (M²−1)²(M²+1)/M¹⁶ — an L-free factor in M, vanishing at the degenerate meridians M² = ±1, so nondegeneracy (below) is the honest condition, not pointwise nonvanishing.

              • unit_nondegenerate : ∃ (m : K), m ≠ 0 ∧ unit m ≠ 0

                The unit factor is not identically zero (the classical limit is not the zero polynomial).

              • specializes (L M : K) : M ≠ 0 → op.coeff 2 1 (M ^ 2) * L ^ 2 + op.coeff 1 1 (M ^ 2) * L + op.coeff 0 1 (M ^ 2) = unit M * aPolyFigureEight L M

                Specialization (the AJ content), meridian-squared convention: at q = 1, with m = M² (the multiplication variable is the square of the meridian eigenvalue — the convention the corpus-side verification aj_figure_eight_operator_construct_verify.py identified; the naive m = M map does not match), the homogeneous part equals unit M · A_{4₁}(L, M).
