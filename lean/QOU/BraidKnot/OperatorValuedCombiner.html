    The conjecture (prop:operator-valued-combiner-convergence) #

    For an A-nucleon atom with canonical braid β_atom at H_{3A}, the iterated application of prop:crystal-r-matrix-sub-lemma at each peeling level n_k = 3(A-k+1) assembles into a convergent representation of χ^λ(β_atom). Unwound, the χ-value at level A+1 is an LR-weighted combination of the level-A value with the new nucleon block. The recursion bottoms out at A=2 (deuteron), end-to-end verified at 0.72 ppb against markov_peel.tr_M_atomic per docs/audits/2026-06-02-subgoal-1-phase-a-baseline.md.

    §3b-cond pattern (mirrors CrystalRMatrixSubLemma) #

    The conjecture is axiomatised as a Lean class WenzlAOperator whose fields encode (a) the combiner value at each peel level, (b) the LR weight, and (c) the branching recursion constraint — the convergence content. No instance is provided here: the missing instance IS the conjecture (the H_9+ universal-extract problem is research-grade, owner-active). Downstream consumers take [WenzlAOperator R q] as an explicit instance hypothesis and derive conditional results that are fully Lean-verified modulo that instance.

    The remaining research-grade gap (per docs/audits/2026-06-02-subgoal-1-sdp-multiterm-and-tritium.md): the A^λ_{ξν}(I) extracts at H_9+ are least-squares fits over the H_3 inner-test family, NOT universal. A concrete WenzlAOperator instance requires universal extracts.

    class QOU.BraidKnot.OperatorValuedCombiner.WenzlAOperator (R : Type u) [CommRing R] (q : R) [CrystalGraphRealization R q] :
    Type u

    §3b-cond conjectural class: the operator-valued Wenzl branching combiner.

    combinerValue A is the χ-value the combiner produces for the canonical A-nucleon atomic braid (at H_{3A}). lrWeight A is the Littlewood–Richardson weight entering the peel from level A to level A+1. The branching_recursion field is the convergence content of prop:operator-valued-combiner-convergence: the value at each level ≥ 2 is determined from the previous by the LR-weighted combiner.

    No instance is provided — the missing instance is the conjecture (universal H_9+ extracts, research-grade).

    • combinerValue : ℕ → R

      χ-value of the operator-valued combiner at peel level A (= 3A strands).

    • lrWeight : ℕ → R

      Littlewood–Richardson weight for the peel level A → A+1.

    • branching_recursion (A : ℕ) : 2 ≤ A → combinerValue q (A + 1) = lrWeight q A * combinerValue q A

      The convergence recursion (the conjecture's content): for every atomic level A ≥ 2, the combiner value at A+1 equals the LR-weighted combiner.

      Gap Analysis: The in-repo RSK infrastructure (QOU.Mathlib.RSK_substrate_proved) provides the classical Burnside identity, but this convergence requires universal extracts for H_9+ which are not covered by standard RSK. This remains an open research-grade gap.

      Bottoms out at A=2 (deuteron), verified numerically at 0.72 ppb (Phase A).
