    All JM commutativity reduces to the ADJACENT case #

    HeckeJucysMurphyCommutation.lean proved the adjacent case at i = 1 only, and recorded that the exchange relations were exhausted and the half-twist argument did not extend. This file changes the shape of the remaining problem rather than attacking it head-on.

    The reduction #

    L_{j+1} = σⱼ Lⱼ σⱼ by definition, and Lᵢ commutes with σⱼ whenever j > i (jmRaw_comm_sigma_far). Sliding Lᵢ past both copies of σⱼ gives

    [Lᵢ, L_{j+1}] = σⱼ [Lᵢ, Lⱼ] σⱼ        (`jmRaw_commutator_step`, for j > i)

    so the commutator of a far pair is a conjugate of the commutator one step closer. Iterating down to j = i + 1:

    [Lᵢ, Lⱼ] = 0  for every j > i   ⟺   [Lᵢ, L_{i+1}] = 0

    (jmRaw_comm_of_adjacent). So the adjacent case is not merely the hard case — it is the only case. Everything else is conjugation.

    Consequence: the i = 1 row is complete #

    jmRaw_comm_adjacent_one proved L₂L₃ = L₃L₂. Feeding it to the reduction gives jmRaw_one_comm_all : L₂ commutes with every Lⱼ, j ≥ 1 — a whole row of the commutativity matrix, from what was a single instance.

    What this does and does not settle #

    It does not prove general commutativity: [Lᵢ, L_{i+1}] = 0 for i ≥ 2 is still open, and the reduction gives no purchase on it (it relates different j at fixed i, never different i). What it does is collapse a two-parameter problem to a one-parameter one, and make the i = 1 result worth more than an instance.

    Since general ∏Lᵢ = Δ² and the spectral half are also still open, the general-λ twist remains conditional — unchanged by this file.

    The reduction, stated as one hypothesis. If every adjacent pair commutes, the whole JM family is commutative.

    When this was written the hypothesis was the open residue for i ≥ 2. It is no longer open: HeckeTranspositionExpansion.jmRaw_comm_adjacent discharges it outright, via the additive family and Jucys's telescoping, so jmRaw_comm_all in that file is this conclusion with no hypothesis at all.
