    QOU.BraidKnot.SpechtStandardBasis — brick 4 of the Okounkov–Vershik tower (capstone) #

    The standard-basis theorem for Specht modules: dim_k S^μ = #SYT(μ) (Sagan, The Symmetric Group, Thm 2.5.2).

    This is the capstone half of brick 4. All of the objects (SYT→tableau conversion, standard polytabloids, the abstract Triangular lever, corestriction, spanning half) live one layer down in SpechtStandardBasisCore; the two independence cores (SpechtDominanceCore, SpechtTriangularCore) sit between them and this file. Everything is declared in the same QOU.BraidKnot.SpechtStandardBasis namespace across the three files, so external references are unchanged.

    The triangular core is now consumed, not stubbed #

    Historically standardPolytabloid_triangular was an honest sorry here (the dominance core, cited to Sagan Thm 2.5.2). That core has since been proved sorry-free in SpechtTriangularCore.standardPolytabloid_triangular' (independence, modulo only the relation-level dominance lemma SpechtDominanceCore.dominance_relation_exists). Because that proof lives in a module that imports the brick-4 definitions, it could not be consumed from the old single-file layout without a circular import; the definitions were therefore split into SpechtStandardBasisCore, and this file — now sitting above the cores — proves standardPolytabloid_triangular by directly consuming the already-proved standardPolytabloid_triangular'.

    Net effect: standardPolytabloid_triangular carries no independence sorry. Both former brick-4 stubs — the dominance core and the spanning / straightening core standardPolytabloid_straightening — have since been discharged, so the whole chain is now sorry-free outright.

      Carries [CharZero k], inherited from standardBasis. This declaration previously bore an omit [CharZero k] in, which made the file fail to compile: the proof applies standardBasis, which genuinely takes the instance, so the omitted binder left CharZero k unsynthesizable at the application. The generality the omit asserted was never established — dropping it is what the existing proof supports.
