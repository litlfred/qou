    def QOU.BraidKnot.BarTransport.IsBarSymmetric {K : Type u_1} [Field K] (J : K → ℕ → K) (q : K) :
    Prop

    A tower J (indexed by a parameter q : K and a color n : ℕ) is bar-symmetric at q if its values at q and q⁻¹ coincide pointwise. This holds for amphichiral knots (like 4₁) where the colored Jones polynomial is invariant under q ↦ q⁻¹.

      §2 m-free q-difference operators and bar duality #

      Many q-difference recurrences in knot theory have coefficients that
depend on `q` but NOT on the lattice variable `m`. For such operators
the bar involution `q ↦ q⁻¹` is a clean algebraic operation.
      source
      structure QOU.BraidKnot.BarTransport.MFreeQDiffOp (K : Type u_2) [Field K] :
      Type u_2

      An m-free q-difference operator: one whose coefficients depend on q alone, not on the lattice variable m. The Annihilates relation for such an operator uses q^N in the m-slot, but since the coefficients ignore m, the annihilation condition simplifies.

      • coeff : ℕ → K → K

        Coefficient of the j-th shift, depending only on q.

              §3 The specialization tower: q ↦ 1 and IsQHolonomic ↦ IsHolonomic #

              If `J` is q-holonomic and the operator coefficients have well-defined
q → 1 limits, the limiting sequence satisfies a classical recurrence
(D-finite / holonomic in the sense of Zeilberger). This is structural
— the q-holonomic category is a deformation of the holonomic one.
              source
              theorem QOU.BraidKnot.BarTransport.MFreeAnnihilates_at_one {K : Type u_1} [Field K] (op : MFreeQDiffOp K) (J : ℕ → K) (h : MFreeAnnihilates op 1 J) (N : ℕ) :
              ∑ j ∈ Finset.range (op.order + 1), op.coeff j 1 * J (N + j) = op.rhs 1

              If J satisfies the m-free annihilation at q for every q, it satisfies the q = 1 specialization. A trivial instantiation, but it anchors the conceptual bridge: the q → 1 limit of a q-holonomic sequence is holonomic.
