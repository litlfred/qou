    The r = 5 affine-Weyl fold of the Ê₈ mark vector — exact algebra behind the #

    Lawrence–Rozansky modulus identification on Σ(2,3,5) #

    Companion to computations/lr_modulus_identification_sigma235.py (PR #3822, the W_λ keystone's last open piece). That probe establishes the corrected exact identity

    |S_{0λ}^{(m)}(ζ)| = 2·|[mark λ]_{ζ^m}| / D_Ê₈(ζ^m), ζ = e^{iπ/5}, m = 1, 2,

    for the 9 affine-Ê₈ McKay nodes of 2I (marks 1,2,3,4,5,6,4,2,3), with the two flat connections of Σ(2,3,5) as the two Galois embeddings. This file proves the algebraic core of that identity — everything that is pure ring/field algebra — sorry-free:

    • the Chebyshev fold values of the quantum integers [m] at the two folds (2cos(π/5) = φ, 2cos(2π/5) = φ − 1, with φ² = φ + 1): [3] = φ, [4] = 1, [5] = 0, [6] = −1 (first fold) and the Galois-conjugate values (second fold);
    • the Ê₈-node normalizers D²(ζ) = 8 + 4φ and D²(ζ²) = 12 − 4φ (= 10 ± 2√5 under φ = (1+√5)/2);
    • the fold multiplicity D_Ê₈² = 2·D_MTC² (the 9-node set folds 2:1 onto the r = 5 alcove {1,2,3,4}, node 5 → 0) — the exact origin of the global factor 2 (resp. √2) correcting the conjectured modulus identification;
    • the core normalization identity (10−2s)(10+2s) = 80 for s² = 5, which is exactly ((2/√5)·sin(mπ/5))² · D²(ζ^m) = 4 — the factor-2-corrected modulus identity at the vacuum node, whence at every node by multiplying with [mark]².

    What is not in this file: the colored Lawrence–Rozansky flat-connection amplitudes A_m(α) = ±(2/√5)·sin(αmπ/5). Its bare (α = 1) case is now a Lean theorem — the real-trigonometric identity A_m(1)² = 4/D²(ζ^m) is proved in the archimedean companion KeystoneLRAmplitudeReal.lean (§7c: Real.sin lives in a separate file from this generic-field core), promoting the former ~1% machine-evidence to exact. The full colored α ≥ 2 amplitude and the q₀ archimedean continuation (the loc_matches gate) remain open.

    Base ring (§7c) #

    Generic: the fold lemmas need only [CommRing R] with a golden element φ² = φ + 1; the normalization identity needs only [Field K] with s² = 5 (rational literals, no ℝ, no Real.sqrt, no ordering).

        theorem QOU.BraidKnot.KeystoneLRModulusFold.core_normalization {K : Type u_1} [Field K] (s : K) (hs : s ^ 2 = 5) :
        (10 - 2 * s) * (10 + 2 * s) = 80

        Core normalization identity: for s² = 5 (a square root of 5 in any characteristic-zero field), (10 − 2s)(10 + 2s) = 80. Under s = √5 this is exactly ((2/√5)·sin(π/5))² · D_Ê₈(ζ)² = 4 — i.e. the vacuum-node case of the factor-2-corrected modulus identity |A_m(mark)|·D_Ê₈(ζ^m) = 2·|[mark]_{ζ^m}| — since sin²(π/5) = (10−2√5)/16 and D_Ê₈(ζ)² = 10+2√5 (and Galois-symmetrically for the second flat connection, sin²(2π/5) = (10+2√5)/16, D² = 10−2√5).
