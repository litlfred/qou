    jmRaw_comm on the bounded presentation — the last item on qou-t1kv #

    Tranche 3, assembling the transposition machinery into Jucys's telescoping argument and landing jmRawB_comm: the Jucys–Murphy elements of a bounded presentation commute.

    The final bound is the natural one #

    jmRawB_comm holds for i < n and k < n — exactly "both Lᵢ and L_k are elements of H_n(q)". Nothing stronger is needed, and nothing weaker suffices: L_i is a word in σ₀ … σ_{i−1}, so i < n is already forced for it to be well-formed.

    Bounds, and the four lemmas that need none #

    lemma bound
    sigma_comm_addJMB i < n
    sigma_comm_addJMB_small j + 1 < n
    sigma_comm_partialSumB m < n
    sigma_comm_partialSumB_above j + 1 < n
    sigma_comm_partialSumB_ne m < n and j + 1 < n
    comm_transpB_of_comm_sigma none
    comm_addJMB_of_comm_sigma none
    partialSumB_succ none
    addJMB_comm_of_le m + 1 < n
    addJMB_comm i < n, k < n

    sigma_comm_partialSumB_ne is the only place needing two bounds, and for a real reason: it splits on j < m versus j > m, and the two branches constrain different indices. A single hypothesis would have been wrong on one side.

    Why this route rather than the product half #

    Jucys's telescoping argument — A_{m+1} = S_{m+1} − S_m — never touches the product half of Mathas 3.24(iii), which addJMB_sigma_prod_swap shows only swaps the factors and is entangled with the conclusion it was meant to supply. The bounded port inherits that virtue unchanged.
