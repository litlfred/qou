    def QOU.BraidKnot.BindingConcentration.interfaceCount (A : ℕ) :
    ℕ

    The number of interface generators for an atom with A nucleons. Each nucleon occupies 3 strands; interfaces connect adjacent nucleon blocks at strand positions 3, 6, ..., 3(A-1). For A nucleons: k = A−1 interface generators.

        theorem QOU.BraidKnot.BindingConcentration.lp_binding_sparse (n : ℕ) (y_chi : Fin n → ℝ) (target : ℝ) (cost : Fin n → ℝ) (hcost : ∀ (i : Fin n), 0 < cost i) (htarget : target ≠ 0) (hfeas : ∃ (i : Fin n), y_chi i ≠ 0) :
        ∃ (Δ : Fin n → ℝ), ∑ i : Fin n, y_chi i * Δ i = target ∧ (∃ (i₀ : Fin n), ∀ (i : Fin n), i ≠ i₀ → Δ i = 0) ∧ ∀ (Δ' : Fin n → ℝ), ∑ i : Fin n, y_chi i * Δ' i = target → ∑ i : Fin n, cost i * |Δ i| ≤ ∑ i : Fin n, cost i * |Δ' i|

        LP duality theorem: the binding Δ_λ concentrates on the partition with the largest |y_λ × χ^λ(β_K)| product.

        Proof sketch: the LP has cost vector t_λ (Plancherel weight) and one equality constraint. The dual has one variable y₀*. Strong duality: the primal optimum concentrates on the partition where the cost-to-coefficient ratio is minimised, which (for Plancherel cost) is the largest |y×χ| partition.

        This is a THEOREM about LP structure, not about physics. It holds for ANY LP with one equality constraint and non-negative costs.

        theorem QOU.BraidKnot.BindingConcentration.interface_asymmetry_maximal (n k : ℕ) (hk : k ≤ n) :
        |↑n - 2 * ↑k| ≤ ↑n

        The interface eigenvalue asymmetry is maximal for the partition that separates interface strands from bulk strands.

        On V_λ with shape (n−k, k): σ₃ has n₊ = n−k eigenvalues at +q and n₋ = k at −q⁻¹ (from the SYT content-difference criterion). The asymmetry |n₊ − n₋| = |n − 2k| is maximised when k is minimal (k=1 for simple partitions) or maximal.

        noncomputable def QOU.BraidKnot.BindingConcentration.E₀ (m_e q : ℝ) :
        ℝ

        The binding energy scale E₀ = m_e / (q₀(q₀−1)). This is the single-Planck-tick energy scale from CAL-1 + CAL-2. The deuteron binds at +0.91% via E₀ × q⁻¹ (PR #1367).

        NOTE: the per-knot extension to A≥3 (B = E₀×q⁻ᴬ×δ_tr×A(A−1)/2, PR #1383) was RETRACTED as backhanded fitting (PR #1386): the pair-count A(A−1)/2 and q-power q⁻ᴬ were hand-chosen to match AME data. The real A≥3 binding must come from the SDP solutions and iterative knot building at H_{3A}.
