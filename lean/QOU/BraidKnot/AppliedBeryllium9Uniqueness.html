    QOU.BraidKnot.AppliedBeryllium9Uniqueness — concrete ⁹Be application #

    Thin wrapper specialising NucleusEmptySDPUniqueness to ⁹Be's strand count n = 3·A = 3·9 = 27 (Z=4, N=5, A=9).

    Status #

    Sorry-free closure for ⁹Be's empty-SDP uniqueness via the parameterised nucleus_uniqueness_closed at n := 27. No abstract-axiom dependency.

    ⁹Be was added as a verified atom-braid case in Sprint 2.
