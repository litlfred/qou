    QOU.BraidKnot.GSReductionOrder — the GS reduction order in the KLR calculus #

    Layer-0/1 formalisation scaffold for the order-match kernel of [conj:crystal-graph-realization], per the design doc docs/audits/2026-06-07-klr-gs-order-formalization-plan.md.

    The abstract CrystalGraphRealization R q class (sibling file) treats NormalForm as opaque and axiomatises the highest-weight condition. This module supplies the concrete GS combinatorics the conjecture is actually about — the Gröbner–Shirshov rewriting system of def:hecke-normal-form, with every rule oriented so each step strictly decreases the intended shortlex order (a standalone ≺ order relation is not yet defined here; see the plan doc Layer 0 L0.1–L0.2 for the Prod.Lex (length, lex) order this orientation targets) — and isolates the single open input as the order-match axiom order_match (the claim ★ that the shortlex GS irreducibles match the Brundan–Kleshchev canonical-basis labels on the nose, i.e. confinement level = crystal degree).

    Everything here is additive: the existing CrystalGraphRealization class and its importers are untouched.

    Build-verified 2026-06-07: lake build QOU.BraidKnot.GSReductionOrder exit 0 (2244/2244 targets), sorry-free (the single conjectural input is the order_match class field per AGENTS.md §3b).

      inductive QOU.BraidKnot.Step :
      GSWord → GSWord → Prop

      The Gröbner–Shirshov single-step rewrite relation of def:hecke-normal-form, on the reduced-word combinatorics:

      • hecke — the quadratic collision σ_i σ_i; the Hecke relation σ_i² = (q−q⁻¹)σ_i + 1 removes the σ_i σ_i factor from any reduced word (its linear tail is tracked separately in hecke-normal-form.lean);
      • farComm — far-commutativity oriented to move the smaller index left, σ_i σ_j → σ_j σ_i when j + 2 ≤ i; the single orientation (not the symmetric |i−j| ≥ 2) keeps the step strictly shortlex-decreasing, so the relation terminates instead of looping i::j ↔ j::i;
      • yangBaxter— the braid move oriented shortlex-decreasing, σ_{i+1} σ_i σ_{i+1} → σ_i σ_{i+1} σ_i (the rewrite lowers the leading generator index from i+1 to i).

      Confluence is the Diamond Lemma (Bergman 1978); the normal forms biject with Sₙ (n! of them).

      • hecke (pre post : GSWord) (i : ℕ) : Step (pre ++ i :: i :: post) (pre ++ post)
      • farComm (pre post : GSWord) (i j : ℕ) (h : j + 2 ≤ i) : Step (pre ++ i :: j :: post) (pre ++ j :: i :: post)
      • yangBaxter (pre post : GSWord) (i : ℕ) : Step (pre ++ (i + 1) :: i :: (i + 1) :: post) (pre ++ i :: (i + 1) :: i :: post)

          Layer 1 — the order-match axiom (★), the single open input #

          source
          class QOU.BraidKnot.GSOrderMatch (R : Type u) [CommRing R] (q : R) :
          Type (u + 1)

          GS ↔ KLR order-match (conjecture, axiomatised).

          Pairs the GS reduction order with the KLR ℤ-grading. The fields:

          • NormalForm — the GS normal forms (abstractly, the n! reduced words T_w);
          • confinementLevel — the LP shadow-price confinement level (def:confinement-level);
          • crystalDeg — the Brundan–Kleshchev KLR ℤ-grading degree;
          • order_match — the conjecture (★): on every GS normal form the two filtrations agree on the nose, crystalDeg = confinementLevel, rather than only up to a re-indexing of strata. This single field is the sorry-equivalent the whole crystal-graph-realization chain reduces to.
          • NormalForm : Type u

            Abstract type of GS normal forms T_w.

          • confinementLevel : NormalForm q → ℕ

            LP shadow-price confinement level of a normal form.

          • crystalDeg : NormalForm q → ℕ

            Brundan–Kleshchev KLR ℤ-grading degree of a normal form.

          • order_match (T : NormalForm q) : crystalDeg T = confinementLevel T

            The conjecture (★): the GS reduction order matches the KLR grading filtration on the nose.

            def QOU.BraidKnot.GSOrderMatch.canonical (R : Type u) [CommRing R] (q : R) :
            GSOrderMatch R q

            The trivial model — a def, not an instance, and not "faithful".

            Its docstring said "Faithful instance. Carries the explicit research-grade conjecture as a sorry." Neither half was true. There is no sorry: it sets NormalForm := PUnit and both confinementLevel _ := 0 and crystalDeg _ := 0, so the order-match (★) is discharged by rfl on 0 = 0. Two filtrations agree because both are identically zero on a one-element set of normal forms, not because the GS reduction order tracks the KLR grading. A sorry would at least be visible to #print axioms; this was not.

            The class docstring calls order_match "the sorry-equivalent the whole crystal-graph-realization chain reduces to". That is the right reading of the class; this model was what stopped it from being true of the corpus, because as an unconditional instance it discharged that field for every R and q and made confinement_eq_crystalDeg an unconditional theorem about the zero filtration.

            Same shape as ConfinementGradingCorrespondence.canonical, which states the same correspondence over [CrystalGraphRealization R q], and demoted the same way (bean qou-fngs). Nothing consumed it: the class has no users outside this file.

            Still open: (★) itself — that crystalDeg T = confinementLevel T on the n! genuine GS normal forms, on the nose rather than up to a re-indexing of strata.
