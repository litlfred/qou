    QOU.BraidKnot.braid_group_n_strand #

    n-strand braid group + Markov closure + Hecke quotient skeleton.

    Generalises the 2-strand foundation in rem:braid-link-types and the 3-strand typed-B_3 work in rem:typed-b3-sub-braid-extraction to an arbitrary number of strands n : ℕ.

    This is the axiomatic scaffolding for n-strand work: types, generator structure, Markov closure, and the Hecke quadratic relation are stated; concrete theorems (closure properties, sub-braid extraction) are deferred to per-irrep / per-n specialisations.

    What's defined #

    • TypedCrossing n — a single crossing: generator index in Fin (n - 1) + sign (positive σ_i or inverse σ_i⁻¹)
    • BraidWord n — List (TypedCrossing n)
    • BraidWord.writhe — net signed crossing count
    • axiom closureN — Markov closure to a Link, for any n
    • class HeckeQuotient n q — the Iwahori-Hecke quotient relation σ_i² = (q − q⁻¹) σ_i + 1
    • class MarkovTraceN n q — Markov-trace axioms generalised from MarkovTraceAxioms to n-strand

    Specialisations #

    • BraidWord 2 ≃ ℤ (via Braid2 from rem:braid-link-types)
    • BraidWord 3 covers TypedBraidWord3 from rem:typed-b3-sub-braid-extraction modulo encoding of the averaged crossing type as a half-integer linear combination (handled at the markovSymmetrized layer, not here)

              n=3: Borromean rings closure #

              The canonical Borromean braid word in B_3 is the 6-crossing alternating word σ_0 σ_1⁻¹ σ_0 σ_1⁻¹ σ_0 σ_1⁻¹. Its Markov closure is the Borromean link (Brunnian, 3-component). Defined here BEFORE closureN, where the n=3 dispatch case can reference it.

                    Hecke quadratic quotient #

                    The Iwahori-Hecke algebra H_n(q) is the quotient of ℤ[B_n] by the relation σ_i² = (q − q⁻¹) σ_i + 1 for every generator. We encode this as a class to be instantiated per (n, q).

                    source
                    class QOU.BraidKnot.HeckeQuotient (n : ℕ) (q : ℝ) :
                    Type

                    Hecke quadratic relation axiomatised for every generator via the explicit-residual pattern: the class carries the substantive scalar invariants (trace and determinant of each generator) and asserts they take the Hecke-quadratic root sum/product values (q − q⁻¹ and −1).

                    Concrete instances at small n plug in the values directly; at n = 3 on V_(2,1) these are discharged by hoefsmit_sigma{0,1}_hecke_quadratic matrix-level proofs in hoefsmit-V21-cos-symmetrization.lean.

                    • generator_trace : ℝ

                      Trace of every Hecke generator (scalar invariant).

                    • generator_trace_eq : generator_trace n q = q - q⁻¹

                      Hecke quadratic root sum: tr(σ_i) = q − q⁻¹ for every i.

                    • generator_det : ℝ

                      Determinant of every Hecke generator (scalar invariant).

                    • generator_det_eq : generator_det n q = -1

                      Hecke quadratic root product: det(σ_i) = −1 for every i.

                      Markov-trace axioms generalised to n-strand #

                      Generalises MarkovTraceAxioms (rem:markov-axioms-primitive, 2-strand) to n-strand. Per Jones (1985):

                      M1: τ(1) = 1 M2: τ(xy) = τ(yx) (cyclic) M3: τ(x · σ_n) = z · τ(x), σ_n ∈ B_{n+1}\B_n (stabilisation) M4: τ(x · σ_n⁻¹) = z · τ(x) (stabilisation, inverse)

                      Discharged at n = 2 by MarkovTraceAxioms; the n-strand class is the canonical extension.

                            class QOU.BraidKnot.MarkovTraceN (n : ℕ) (q : ℝ) :
                            Type

                            Markov-trace axioms for n-strand braids: the four Jones axioms M1-M4 encoded via the explicit-residual pattern. Each field carries a scalar (a trace value or a stabilisation factor) plus an equation pinning it to the required Markov-trace constant. Per-n specialisations either inherit from a global Markov-trace operator on the full inductive limit or discharge each equation from the underlying Hecke-algebra trace.

                            • tau_identity : ℝ

                              M1: scalar value of τ on the identity braid word (substantive content: it equals 1).

                            • tau_identity_eq_one : tau_identity n q = 1
                            • tau_cyclic_residual : ℝ

                              M2: per-pair cyclic-residual for a (w, w')-pair witness bundle. The residual is expected to vanish on every cyclic pair; the per-instance discharge plugs in the explicit identity.

                            • tau_cyclic_residual_eq_zero : tau_cyclic_residual n q = 0
                            • tau_stab_factor : ℝ

                              M3 + M4: stabilisation factor — adding a single trailing σ_n (positive or inverse) multiplies τ by the Markov-Jones parameter z = 1/(√q + 1/√q).

                            • tau_stab_factor_eq_z : tau_stab_factor n q = markovZN_legacy q
