    Keystone G2 — the falsifiable defect-gate for a geometric W_λ index #

    The full-Hecke geometric-index program's decisive gate (phase G2, see docs/scope/2026-06-24-keystone-fullhecke-geometric-index-program.md): an S¹-equivariant (Reeb) index on a geometric realization of the full-Hecke arena reproduces the q-Plancherel weight family W_λ only if its 2nd heat-kernel coefficient a₂(n) equals the proved defect cubic 144·C(n) = −n(n−1)(2n−13) (WLambdaDefectClosedForm) for every rank n — including the exact n = 7 sign flip.

    This file formalizes that gate as a machine-checkable specification with falsifiable teeth. It does not construct the index (that is G1, the owner-gated differential-geometric build); it states precisely what any candidate must satisfy, so a future geometric a₂ can be checked against it mechanically — the program's "decisive refute-or-confirm" step.

    On target (4), conjugation symmetry. The per-partition target W_λ = W_{λ′} (now proved on main: KeystoneC2QDimTranspose.qPlancherelWeight_conj, #2794) is an independent necessary condition: it constrains the per-λ weights, whereas this defect gate constrains only the summed coefficient Σ_λ-defect at each rank. A candidate could match a₂(n) without being per-λ transpose-symmetric, so the two gates are genuinely distinct — recorded here rather than conflated.

    Base ring ℤ (the coefficient is 144·-cleared exactly as n144C); nothing archimedean, no q₀, no fit.
