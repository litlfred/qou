    QOU.BraidKnot.QBetaHabiroGeneratorRigidity #

    Formalize-first structural narrowing for the Q_β precision-ladder flip-flop (the recurring c_k wire / un-wire saga; see docs/audits/2026-05-31-qbeta-ck-truncation-order-canonical-framing.md).

    The gap this addresses #

    QBetaCategoricalPrecisionLadder fixes each rung coefficient c_k of the Q_β precision ladder

    Q_β = Q_base · ∏_{k ≥ 2} (1 + c_k · b^k · ℏ_q^{2k})

    behind its own conditional class — QbetaC3StructuralFormClass (c_3 = J_Hopf), QbetaC4StructuralFormClass (c_4 = J·b⁴), QbetaC5StructuralFormClass (c_5 = -(b²+½)), … . Each rung is an independent degree of freedom: any one c_k can be re-fit without touching the others. That independence is the flip-flop — it is what lets c_3 be wired at N=3 and un-wired later (#1452 ↔ #1479) with no structural contradiction.

    What is proved here (and what is NOT) #

    The honest formalize-first move is to state the rigidity that a single fixed generator would impose, WITHOUT deriving any c_k value. If the whole tower is the u-expansion of ONE fixed simple ("single-pole", 1/(1 − ρu)) generator — the natural shape of a fixed categorical Habiro element rather than a per-rung menu — then its coefficients obey a rank-1 / Casoratian law: c_{k+1} = ρ · c_k, so every rung from k = 4 on is forced by c_2 and c_3 (c_2 · c_4 = c_3²). Fixing the generator collapses the per-rung freedom to two parameters.

    This file:

    1. defines SingleGeneratorLaw (the rank-1 recurrence on the c_k);
    2. proves it forces every higher rung from (ρ, c_2) (single_generator_forces) and hence makes the 2×2 Hankel / Casoratian minor vanish (hankel_minor_vanishes);
    3. proves the contrapositive flip-flop obstruction: a non-vanishing Hankel minor certifies that NO single generator fits (not_single_generator_of_hankel_ne), with a rational witness showing the corpus's independently-fitted menu (c_2 = -1, c_3 = -2, c_4 ≠ -4) is not rank-1;
    4. records the open conjecture — that the TRUE categorical tower is a single fixed bar-odd ("sinh partner") Habiro generator — as a content-bearing Prop class with no instance (QBetaSingleHabiroGenerator), and derives the conditional rigidity from it (qbeta_ladder_rigid_of_single_generator, §3b-cond).

    The two-pole (depth-2) complement (folded in from #4089) #

    The rank-1 single-pole law above is deliberately the tightest generator shape, and not_single_generator_of_hankel_ne shows the fitted menu is not rank-1 — a single pole is too rigid to match. The natural next shape is a two-pole rational generator P/Q with denominator degree ≤ 2 — exactly the bar-even [2]_q-denominator element of QBetaResidueHabiroDual. The second block below states its rigidity on the Taylor / convolution coefficients (P = Q · c, the sum-form dual of the product-form ladder above):

    1. convCoeff / conv_unique — the holonomic tower solving Q * c = Q * c' is unique once Q 0 is a unit;
    2. tail_recurrence / two_term_tail_recurrence — a two-pole generator forces the depth-2 linear recurrence Q₀·c_n + Q₁·c_{n-1} + Q₂·c_{n-2} = 0 for n ≥ 2 (the on-main recurrence ansatz is a consequence of rationality);
    3. c3_not_free — once (P,Q) is fixed, Q₀·c_3 + Q₁·c_2 + Q₂·c_1 = 0, so c_3 is a dependent quantity, not a free per-session fit;
    4. c2_eq_neg_one_of_anchor — the proved c_2 = -1 rung falls out of the anchor Q₂ = Q₀ + ladder seed;
    5. two_term_generator_rigid — two towers from the same fixed (P,Q) are equal; and FixedTwoTermGeneratorConjecture, the defined-not-asserted open existence input (the sole open premise, no instance).

    Where the rank-1 block certifies "one pole is too rigid", the depth-2 block supplies the recurrence the two-pole [2]_q residue element actually predicts, and proves uniqueness. Both derive no c_k value and wire nothing.

    DISCIPLINE. This derives NO c_k value (in particular says nothing about c_3 = -2 vs the empirical -2.0693); it wires NOTHING to production; the generator's existence is an OPEN class with no instance. It is the bar-odd mirror of the bar-even HabiroNewtonLadder.casoratian_eq_zero (4₁ Newton nodes) and is a scope-(a) structural statement about the fitted menu, not a scope-(b) exclusion of any Habiro construction — producing the generator is exactly the open target probe-qbeta-habiro-element-search.

    Everything is over a generic base ring/field (§7c) — no ℝ, no sorry, no axiom.

    def QOU.BraidKnot.SingleGeneratorLaw {K : Type u_1} [Mul K] (c : ℕ → K) (ρ : K) :
    Prop

    A single-generator (rank-1) coefficient law for a ladder coefficient sequence c : ℕ → K: from index 2 on, consecutive coefficients are in fixed ratio ρ,

    c (k+1) = ρ · c k for all k ≥ 2.

    This is the hallmark of ONE fixed simple generator 1/(1 − ρu) (a single pole), as opposed to independently chosen per-rung coefficients c_2, c_3, c_4, … — the current corpus situation, in which each c_k lives behind its own conditional class.

The class asserts NOTHING about the VALUE of any c_k (in particular nothing about c_3); it asserts only that fixing the generator removes the per-rung freedom.
