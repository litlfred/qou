    QOU.BraidKnot.NucleusEmptySDPUniqueness — generic empty-SDP uniqueness #

    Parameterised over the strand-count n : ℕ (= 3A where A = Z + N is the nucleon count). Provides ONCE the sorry-free closure of the strict-complementarity uniqueness theorem for the empty-constraint SDP at heckeDim n, then per-nucleus Applied*Uniqueness files specialise via abbrev.

    What this generalises #

    The previously-duplicated per-nucleus files (AppliedHelium3Uniqueness.lean, AppliedDeuteronUniqueness.lean, AppliedTritiumUniqueness.lean) repeated the same proof three times with only the dimension parameter n changing. This module collapses the duplication: each per-nucleus file becomes a thin wrapper supplying its n value.

    What's nucleus-specific (NOT in this module) #

    The real per-nucleus SDP — with its actual cost function from the mass formula and its actual non-empty constraints from the quark / sheet structure — IS nucleus-specific. This module covers only the abstract-framework demonstration via the empty-constraint SDP at the appropriate dimension. The "pending" qualifiers in the existing per-nucleus theorem names (_pending_multiterm for ²H, _pending_hoefsmit for ³H) refer to the multi-term cost wiring and Hoefsmit basis port — separate substantive work.

    What this gives #

    For any n : ℕ:

    • nucleusEmptySDP n — the SDP at dimension heckeDim n with identity cost and no constraints
    • nucleusEmptySDP_strictlyFeasible n — strictly-feasible witness
    • nucleusTrivialStrictCompPair n — trivial strict-complementarity pair (active set empty, Φ⋆ = 0)
    • nucleus_uniqueness_via_empty_sdp n — Subsingleton uniqueness via the abstract canonical_T_w_subsingleton (axiom-dependent path)
    • nucleusRealStrongDualityPair n — concrete real strong-duality pair (Φ⋆ = 0, identity dualSlack)
    • nucleus_dualSlack_posDef n — dualSlack = 1 is PosDef
    • nucleus_uniqueness_closed n — sorry-free uniqueness via real_strict_complementarity_unique_of_dualSlack_posDef, no axiom dependency
    • nucleus_optimum_is_zero n — Φ⋆ = 0 by rfl
    • nucleus_objAt_optimum_eq_zero n — obj at Φ⋆ = 0 by simp

    Usage #

    -- AppliedHelium3Uniqueness.lean
abbrev helium3_emptySDP := nucleusEmptySDP 9
abbrev helium3_uniqueness_closed := @nucleus_uniqueness_closed 9

    Adding a new nucleus (e.g. ⁴He at n = 12):

    -- AppliedHelium4Uniqueness.lean
abbrev helium4_emptySDP := nucleusEmptySDP 12
abbrev helium4_uniqueness_closed := @nucleus_uniqueness_closed 12

        Sorry-free closure via the ℝ-uniqueness layer #

        The empty-constraint SDP has cost matrix T = 1 (identity), no equality constraints, hence dual slack S(y) = T - Σ y_i A_i = 1 (identity, regardless of y since the sum is empty). The identity matrix is positive-DEFINITE, so real_strict_complementarity_unique_of_dualSlack_posDef applies and gives full sorry-free uniqueness.

        This closure is dimension-independent: the proof at n = 6 (²H), n = 9 (³H, ³He), n = 12 (⁴He), n = 18 (⁶Li), n = 27 (⁹Be), n = 33 (¹¹B), or any other n is identical. The previous per-nucleus files duplicated this proof three times.

          Active-empty closure route (matches the empirical-witness language) #

          nucleus_uniqueness_closed above closes uniqueness through the dual-slack-PosDef interior argument. The R5-full witnesses report the result in the active-set language ("all Wedderburn-block min-eigs > 0 ⟹ active set empty"), so we also expose the closure through the active-empty theorem real_strict_complementarity_unique_of_active_empty_and_cost_posDef. For the empty-constraint SDP (ι = Empty) the active set is empty by construction and the cost is the PosDef identity, so this route is also sorry-free and axiom-free — and its hypotheses match the R5-full witness's reported active = ∅ certificate directly (e.g. ³He at n = 9: the three Wedderburn-block min-eigs 1.87, 0.53, 0.53 are all

          0). This is the first BraidKnot-layer consumer of the active-empty closure (previously only SDPRealUniqueness referenced it).
