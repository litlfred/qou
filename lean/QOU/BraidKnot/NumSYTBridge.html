    QOU.BraidKnot.NumSYTBridge — encoding bridge numSYT = numSYTenum ∘ rowLens #

    The Frame–Robinson–Thrall wiring (numSYT_mul_hookProduct) and the Burnside identity (DeltaLambdaSignRule.burnside) both need the repo's two standard-Young-tableau counts to agree:

    • QOU.BraidKnot.numSYT μ = Nat.card (QOU.BraidKnot.StandardYoungTableau μ) — the 0-indexed tableau type (entry : ℕ → ℕ → ℕ, lt_card/zero_off/inj_on/row_strict/col_strict);
    • QOU.Mathlib.numStandardYoungTableaux μ = Nat.card (QOU.Mathlib.StandardYoungTableau μ) — the SSYT-wrapper type (a SemistandardYoungTableau whose entry map bijects the cells onto Set.Icc 1 μ.cells.card, i.e. 1-indexed).

    These are different structures; this file builds the explicit equivalence between them (an index shift by 1 on the cells, wrapping/unwrapping the semistandard tableau) and derives the count equality numSYT μ = numStandardYoungTableaux μ. Combined with the already-proved list bridge QOU.Mathlib.SYTEnum.numSYTenum_eq_numStandardYoungTableaux and the round-trip YoungDiagram.ofRowLens_to_rowLens_eq_self, this yields

    numSYT μ = numSYTenum μ.rowLens                        (`numSYT_eq_numSYTenum_rowLens`)

    — the encoding needed to feed the GNW hook-walk numSYTenum_mul_prodHooks into numSYT_mul_hookProduct.

    Pure combinatorics on ℕ; nothing archimedean; no fit. Verified standalone via lean-direct against the pinned v4.24.0 oleans; it carries no sorry.

    References #

    • [sagan2001] Sagan, The Symmetric Group, §3.1 (standard Young tableaux; the 0/1-indexing is a cosmetic normalisation of the same filling).
