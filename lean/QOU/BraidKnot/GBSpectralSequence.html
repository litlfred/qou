    QOU.BraidKnot.GBSpectralSequence — Gröbner–Shirshov spectral sequence #

    The unified knot mass formula has six structural terms which emerge as pages of a spectral sequence associated with the Gröbner– Shirshov filtration J^•(q) on H_n(R, q).

    Conditional-class axiomatisation (AGENTS.md §3b). The spectral-sequence existence statement is captured here as an abstract typeclass; full constructive formalisation requires the filtered-Hochschild-cochain machinery and is multi-week work (currently sketched in the .md). Downstream consumers take a [GBSpectralSequence R] instance and proceed.

    Formal-chain version. Lives under lean/QOU/ and is compiled by lake build.

    LaTeX label: prop:gb-spectral-sequence

    source
    class QOU.BraidKnot.GBSpectralSequence (R : Type u) [CommRing R] :
    Type (u + 1)

    GB spectral sequence on the GS-filtered Hecke algebra.

    A class instance carries:

    • filtration : ℕ → Type* — the filtered pieces J^ℓ(q) (or, strictly, the associated graded J^ℓ / J^{ℓ+1} at level ℓ).
    • differential : ∀ ℓ, filtration ℓ → filtration ℓ — the direct sum d = d_H + d_F + d_{YB} of the three GS rewriting rules, lifted to the Hochschild cochain complex.
    • d_squared_zero — the differential squares to zero (Cartan–Eilenberg).
    • e_infty_converges — the spectral sequence converges to the associated graded of the Hecke algebra.

    Each field encodes a substantial mathematical statement; the class is the conditional-class wrapper for the proposition prop:gb-spectral-sequence.

    • graded : ℕ → Type u

      The associated-graded piece at filtration level ℓ.

    • gradedAdd (ℓ : ℕ) : AddCommGroup (graded R ℓ)

      Each graded piece is an additive group.

    • differential (ℓ : ℕ) : graded R ℓ → graded R ℓ

      The differential d : J^ℓ / J^{ℓ+1} → J^ℓ / J^{ℓ+1}.

    • d_squared_zero (ℓ : ℕ) (x : graded R ℓ) : differential ℓ (differential ℓ x) = 0

      The differential squares to zero.

    • E_infty : ℕ → Type u

      Convergence target: at each level ℓ the E_∞ page identifies with the associated graded. The class records the target type and the convergence map, and asserts that the latter is surjective.

    • E_infty_add (ℓ : ℕ) : AddCommGroup (E_infty R ℓ)
    • convergeTo (ℓ : ℕ) : graded R ℓ →+ E_infty R ℓ

      Convergence map J^ℓ / J^{ℓ+1} → E_∞^ℓ.

    • e_infty_converges (ℓ : ℕ) : Function.Surjective ⇑(convergeTo ℓ)

      Convergence: the spectral sequence stabilises onto E_∞. Cf. gemini-code-assist review on PR #535.

      class QOU.BraidKnot.GBSpectralSequenceCollapsesAtE2 (R : Type u) [CommRing R] extends QOU.BraidKnot.GBSpectralSequence R :
      Type (u + 1)

      T4 scaffold: E_2 spectral-sequence collapse extension class.

      Per prop:spectral-sequence-collapse and the audit docs/audits/2026-05-24-derivation-chain-gb-jet-orders-and-pentagon.md §2 (Step 7 — GB filtration / spectral sequence): the GB spectral sequence collapses at $E_2$ because Pentagon coherence forces the higher differentials $d_k$ for $k \geq 2$ to vanish.

      Extends GBSpectralSequence with the explicit collapse-at-E_2 condition: the convergence map is iso (not just surjective) at every filtration level. Under this strengthening, every higher jet $h^{2k}$ for $k \geq 2$ is determined by the $E_2$ data (the $\ell = 0, 1, 2$ pieces).

        The convergence map is injective (combined with surjectivity from the parent class, this gives iso at E_2).

        E_2 collapse theorem. Under the E_2 collapse extension, the convergence map is bijective at every filtration level — i.e., the spectral sequence's $E_2$ page IS the $E_\infty$ page up to the iso. This is the formal statement of "no free parameters beyond E_2".
