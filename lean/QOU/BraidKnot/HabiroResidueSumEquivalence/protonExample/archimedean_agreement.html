    §3b-cond class axiomatisation for content block conj:gs-archimedean-agreement-residue: Archimedean agreement (proton instance): degree-48 Habiro trace at u₀.

    This is a conjecture: the class is a primary conjecture carrier with no instance — the honest open state per AGENTS.md §3b-tax.

    What changed (bean qou-ffwk) #

    The previous field schema — a scalar residual : ℝ plus a field asserting it vanishes — is inhabited by ⟨0, rfl⟩: the class chose its own witness, so it asserted nothing and a downstream [archimedean_agreement] hypothesis was not a meaningful conditional. The two compared quantities are now class parameters, so an instance must discharge the claim for the caller's data. Shape reviewed on PR #3793 (closed unmerged 2026-08-03); this lands its class body.

    Faithfulness #

    The block states one identity, at one braid: the degree-48 Markov-normalised Habiro trace of the proton, evaluated at u₀, against the proton Gröbner–Shirshov mass, agreeing "to machine precision". So this carrier is not quantified over braids — that is the generic sibling's job — and the tolerance is explicit rather than hidden inside an equality.

    The block's recorded value for the agreement is deliberately not written into the class. A carrier that fixes a decimal asserts more than the conjecture does and would have to be re-edited whenever the pin moves; the value belongs in the block and its witness, and the instance that eventually discharges this class is where it enters.

    specialises below derives this carrier from the generic one, so the two are ordered rather than independent: anyone establishing the generic conjecture gets the proton case, and nobody has to assert it twice.

    Base ring (§7c) #

    ℝ is required for the same reason as the generic sibling: the claim is about an archimedean evaluation compared against a mass, on the observable side of the substrate wall by construction.

    Prop

    Archimedean agreement (proton instance): the proton's degree-48 Markov-normalised Habiro trace, evaluated at u₀, agrees with the proton Gröbner–Shirshov mass within ε.

    Conjectural class — see conj:gs-archimedean-agreement-residue.

    Parameters are the caller's data: the two evaluated quantities and the certified tolerance. An instance is the conjecture, for that data. None is provided.

    • tolerance_nonneg : 0 ≤ ε

      The tolerance is a tolerance: a negative ε would make the class empty rather than open, which is a different and wrong claim.

    • agree : |habiroTraceEval - gbMass| ≤ ε

      The conjecture, at the proton braid.
