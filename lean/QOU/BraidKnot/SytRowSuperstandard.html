    QOU.BraidKnot.SytRowSuperstandard — the row-superstandard standard Young tableau #

    The row-superstandard (row-reading) tableau of shape μ: fill the cells with 1, 2, …, |μ| reading each row left-to-right, top row first. Its entry at (i, j) ∈ μ is

    rowPrefix μ i + j + 1, where rowPrefix μ i = ∑_{i' < i} μ.rowLen i'

    (the number of cells in the rows strictly above i, plus the position j within row i, plus 1).

    This file builds it in two stages:

    1. The underlying semistandard tableau rowSuperstandardSsyt μ — proved sorry-free. Rows are (weakly) increasing because j grows; columns are strictly increasing because rowPrefix strictly increases with the row index (each skipped row contributes at least one cell — rowLen is positive down to the bottom row by rowLen_anti).

    2. Nonemptiness of StandardYoungTableau μ (the BijOn onto {1, …, |μ|}) — the base-tableau existence brick the Okounkov–Vershik exchange argument (syt_all_connect_to_some) needs. (Stage 2 is developed incrementally; see the tracked cores.)

    Pure combinatorics on ℕ (§7c-clean: no ℝ, no ordering on a ring, no Real.*). Reusable independently of the seminormal machinery.

    Ref: [sagan2001] (The Symmetric Group, §3.9 — the superstandard / row-reading tableau).

          theorem QOU.BraidKnot.rowSuperstandard_injOn (μ : YoungDiagram) :
          Set.InjOn (fun (c : ℕ × ℕ) => (rowSuperstandardSsyt μ).entry c.1 c.2) ↑μ.cells

          InjOn: distinct cells get distinct row-reading labels. If the labels agree, the rows must agree (a later row's first label already exceeds any earlier row's last label, by rowPrefix_mono + j < rowLen), and then the columns agree by cancellation.

          theorem QOU.BraidKnot.rowSuperstandard_surjOn (μ : YoungDiagram) :

          SurjOn: the row-reading filling hits every label in {1, …, |μ|}. It is injective (rowSuperstandard_injOn) and maps the |μ| cells into {1, …, |μ|} (also |μ| elements), so it is onto by counting (Finset.surjOn_of_injOn_of_card_le).
