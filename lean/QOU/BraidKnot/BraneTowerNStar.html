        Substantive recovery predicate: at level nStar, the caller- supplied projection value phiProj recovers the empirical binding B_target to within relative error eps.

        phiProj is an explicit argument (not an ∃-bound witness) so the predicate has propositional content beyond satisfiability: a witness must produce a SPECIFIC numerical value derived from the cyclotomic projection π_{n_⋆}^{(z)}(Φ_q^trans(β)), not "there exists some real number close to the target."

        (Per #637 review: the ∃ Phi_proj form is satisfiable for any B_target, eps > 0 by picking Phi_proj = B_target. Taking phiProj as a concrete input is the strictly-stronger requirement.)
