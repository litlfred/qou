    W_λ partition-function defect — closed form (keystone C(n)) #

    Formalizes the closed-form result of docs/audits/2026-06-20-keystone-wlambda-C-n-closed-form.md (main commit ffcbcde3), which the audit explicitly left as a deferred Lean opportunity ("Identity I … is a clean candidate for a Lean lemma; deferred — the sandbox Lean toolchain is currently network-blocked").

    The q-Plancherel partition function Z(n) = Σ_{λ⊢n} d_q(λ)²/[n]_q! has leading defect 1 − Z(n) = C(n)·h² + O(h⁴) (h = q − q⁻¹). The perturbation expansion collapses the defect coefficient to

    24·C(n) = 2·M(n) − S_n − 2n,

    where S_n = Σ_{k=1}^n (k²−1) and M(n) = (1/n!) Σ_{λ⊢n} dim(λ)² Σ_{c∈λ} h_c² is the Plancherel-expected squared-hook sum. The representation-theoretic input is

    Identity I: M(n) = n(3n−1)/2.

    Identity I is now a sorry-free, general-n, unconditional Lean theorem (QOU.BraidKnot.PlancherelSnDataGeneral.two_sum_dim_sq_hooks_general, closed 2026-08-25 — docs/audits/2026-08-25-ov-general-n-chain-is-closed.md); the twoM def below is its cleared-denominator ℤ shadow, consumed by the algebraic collapse. Given Identity I and the elementary S_n formula, the defect coefficient is the cubic

    144·C(n) = −n(n−1)(2n−13),

    whose only sign-determining factor (2n−13) gives the exact n = 7 sign change (C(n) > 0 for 2 ≤ n ≤ 6, C(n) < 0 for n ≥ 7).

    Everything below is a pure ℤ statement (base ring stays ℤ; no archimedean input — q₀ and the 210 ppb target are never used, matching the audit's "no fit" discipline). The twoM def is the cleared-denominator ℤ form of the now-proved Identity I (general-n theorem, see above); the algebraic collapse and the sign change are proved outright here.
