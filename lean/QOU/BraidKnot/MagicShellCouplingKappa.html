    QOU.BraidKnot.MagicShellCouplingKappa #

    Canonical declaration for content block at quantum-observable-universe/particle-interactions/magic-shell-coupling-kappa-table-data.ts.

    Formalises the manuscript magic-shell coupling table: the shell scale E₀ = m_e/(q(q−1)), h = q − q⁻¹, and the q-integers [2]_q = q + q⁻¹, [3]_q = q² + 1 + q⁻², together with the identity [3]_q = [2]_q² − 1. Generic over any field (§7c: q⁻¹ needs Field; no ordering used).

    Type u_1

    Data for the magic-shell coupling table at q.

    A definition carrier: q ≠ 0, the electron scale m_e, the shell scale E₀, the deformation h, and the q-integers [2]_q, [3]_q, each pinned to its manuscript value.

    • q : R

      Substrate parameter q.

    • q_ne : self.q ≠ 0

      q ≠ 0.

    • m_e : R

      Electron scale m_e.

    • E0 : R

      Shell scale E₀ = m_e/(q(q−1)).

    • h : R

      Deformation h = q − q⁻¹.

    • br2 : R

      [2]_q = q + q⁻¹.

    • br3 : R

      [3]_q = q² + 1 + q⁻².

    • E0_def : self.E0 = self.m_e / (self.q * (self.q - 1))

      E₀ = m_e/(q(q−1)).

    • h_def : self.h = self.q - self.q⁻¹

      h = q − q⁻¹.

    • br2_def : self.br2 = self.q + self.q⁻¹

      [2]_q = q + q⁻¹.

    • br3_def : self.br3 = self.q ^ 2 + 1 + self.q⁻¹ ^ 2

      [3]_q = q² + 1 + q⁻².
