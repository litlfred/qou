    Centrality of the Jucys–Murphy power sum C₂, de-abstracted to one combinatorial core #

    IdentityBWedderburn.identityB_via_wedderburn_unconditional reduces Identity (B) for ℂ[Sₙ] to a single classical input: the centrality of the second Jucys–Murphy power sum

    C₂ = ∑ₖ Xₖ² ∈ Z(ℂ[Sₙ]), Xₖ = ∑_{i<k} (i k).

    This module proves that centrality outright — no sorry remains. The chain center ⟸ class-function coefficient ⟸ cycle-type case analysis is machine-checked end to end, including the combinatorial heart

    centralC2_apply_threecycle : for a 3-cycle σ, C₂ σ = 1

    (each 3-cycle arises from exactly one triple (k,i,j) with i,j<k and swap(i,k)·swap(j,k)=σ — namely k = max(supp σ), i = σ⁻¹(k), j = σ(k); the opposite ordering produces σ⁻¹).

    Everything below is sorry-free ([propext, Classical.choice, Quot.sound]):

    • centralC2_apply — coefficient of C₂ at σ as ∑ₖ #{(i,j) : i,j<k, swap(i,k)·swap(j,k)=σ}.
    • swap_prod_classify — swap(i,k)·swap(j,k) is 1 (if i=j) or a 3-cycle.
    • centralC2_apply_other — σ neither 1 nor a 3-cycle ⟹ C₂ σ = 0 (CharZero-free).
    • centralC2_apply_one — C₂ 1 = binom(n,2) (from RegularRepTrace.centralC2_coeff_one).
    • centralC2_apply_threecycle — C₂ σ = 1 for a 3-cycle σ (the k = max(supp σ) count: the pair set is empty unless k = max(supp σ), and there it is exactly {(σ⁻¹ k, σ k)}).
    • isThreeCycle_conj, conj_eq_one_iff — conjugation preserves cycle type / the identity.
    • commute_all_of_commute_single, mem_center_of_commute_single, commute_single_of_classFun, mem_center_of_classFun — general: a class-function coefficient ⟹ central in MonoidAlgebra.
    • centralC2_classFun — the coefficient of C₂ is a class function (three cycle-type cases).
    • centralC2_mem_center — C₂ ∈ Set.center ℂ[Sₙ], sorry-free: together with IdentityBWedderburn.identityB_via_wedderburn this closes Identity (B) for ℂ[Sₙ] outright.

    So C₂ = binom(n,2)·1 + (class-sum of all 3-cycles) at the coefficient level — Jucys' theorem for the p = 2 power sum — is fully formalised.

    Base ring: the coefficient/centrality machinery is generic ([CommRing R] / [CommSemiring S]); the final centralC2_mem_center is stated at ℂ (the ring IdentityBWedderburn consumes).

    Ref: [vershik-kerov1977] (Okounkov–Vershik / Jucys central elements).
