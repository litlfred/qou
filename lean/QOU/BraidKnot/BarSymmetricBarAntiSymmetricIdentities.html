    QOU.BraidKnot.BarSymmetricBarAntiSymmetricIdentities — P_m, Q_m + Pythagorean #

    Lean encoding of the four hyperbolic identities for the bar-symmetric $P_m$ and bar-anti-symmetric $Q_m$ Markov-trace components of the $T(2, 2m)$ torus link family.

    Origins #

    • P_m = cosh((2m+1)η) / (2 cosh η): sibling PR #1125 / PR #1165 binomial pattern
    • Q_m = sinh((2m+1)η) / (2 cosh η): sibling PR #1153 sinh partner
    • Four identities: PR #1181 sympy-verified for m = 0..6

    What this file PROVES #

    ✓ Pythagorean (I2): P_m² − Q_m² = 1/(2 cosh η)² ✓ tanh ratio (I1): Q_m / P_m = tanh((2m+1)η) ✓ sum (I3): P_m + Q_m = e^{(2m+1)η} / (2 cosh η) ✓ diff (I4): P_m − Q_m = e^{-(2m+1)η} / (2 cosh η)

    Plus the per-particle tanh ladder corollary (PR #1153 finding): At substrate η_0, Q_m(η_0)/P_m(η_0) = tanh((2m+1)·η_0) gives: m=2 (W): tanh(5 η_0) ≈ 0.478 m=3 (Z): tanh(7 η_0) ≈ 0.622 m=4 (H): tanh(9 η_0) ≈ 0.734

    These are claimed (in PR #1153) to be EM-channel-to-total ratios.

    What this file does NOT prove #

    • The CONNECTION to the Higgs mass formula (PR #1164) — that requires the bar-symmetric projection acts as the canonical mass channel; formal identification is research-grade open
    • The Borromean Q = 0 — depends on the Borromean Markov-trace closed form (PR #1081), which is in a separate file; cross-cited not encoded

    Honest framing #

    These identities are GENUINE DERIVATIONS from hyperbolic-function algebra. Unlike empirical pattern matches earlier in the session, each identity follows by direct algebra:

    • cosh² − sinh² = 1 → P² − Q² = 1/(2 cosh η)²
    • sinh/cosh = tanh → Q/P = tanh
    • cosh ± sinh = e^±x → P ± Q = e^{±(2m+1)η}/(2 cosh η)

    The proofs are mechanical via Mathlib's hyperbolic-function lemmas.

              Cross-reference: Borromean (NOT torus) Q = 0 #

              The Borromean rings 𝓑_3 are hyperbolic (not Seifert-fibered torus). Per BorromeanMarkovTrace.lean (PR #1081) the closed form is purely even in h: tr_M(β_Bor) = (4 + h² − 3h⁴ − h⁶) / (h² + 4)

              The bar-anti-symmetric companion of this trace would be the odd-h part divided by (h² + 4). Since the trace has NO odd-h terms, the companion is zero.

              This is encoded as a CONDITIONAL theorem here (depends on the Borromean closed form proved elsewhere in BorromeanMarkovTrace.lean).

                  source
                  theorem QOU.BraidKnot.Q_borromean_real_eq_zero (h : ℝ) :
                  Q_borromean_real h = 0

                  The Borromean Markov trace has zero bar-anti-symmetric companion, over ℝ.

                  The closed form (4 + h² − 3h⁴ − h⁶) / (h² + 4) has all-even-power numerator and denominator, so trM_borromean_real (−h) = trM_borromean_real h by ring. The bar-anti-symmetric projection Q_borromean_real h := (trM(h) − trM(−h)) / 2 therefore vanishes identically.

                  This is the ℝ-side lift of the ℚ proof in QOU.BraidsAndKnots.Q_borromean_eq_zero (PR #1211, commit 5329eb054). No Rat.cast lift is needed — the ring proof works uniformly over any CommRing of characteristic 0; the noncomputable qualifier is purely because of (_ : ℝ) / (_ : ℝ) division, not because of any irrational input.
