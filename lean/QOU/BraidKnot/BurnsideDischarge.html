    QOU.BraidKnot.BurnsideDischarge — Σ_λ (f^λ)² = n! over the custom Partition encoding #

    Discharges DeltaLambdaSignRule.burnside from its two roadmap bridges, both of which are now proved, plus the Wedderburn/dimension side.

    burnside was a self-assuming projection: BurnsideContext carried the burnside conclusion itself as a class field, and the "proof" was ctx.burnside_claim … — a P → P with no mathematical content (AGENTS.md §3b-cond rule 5). Nobody could supply the instance honestly, so every downstream use was gated on an assumption.

    This file supplies the instance from an actual derivation:

    (partitions.map fun Λ => Λ.dimIrrep ^ 2).sum

    = (partitions.map fun Λ => numSYT (partitionEquivIndex n Λ).diagram ^ 2).sum -- bridge (1): dimIrrep_eq_numSYT (PartitionHookProductBridge) + toYoungDiagram_eq below = ∑ i : PartitionIndex n, numSYT i.diagram ^ 2 -- bridge (2): PartitionReindex.sum_map_eq_sum_partitionIndex = n! -- OVTopAssembly.sum_numSYT_sq_eq_factorial

    Why a leaf module #

    burnside is stated in QOU.BraidKnot.DeltaLambdaSignRule, which is upstream of every ingredient — PartitionReindex → PartitionNatBridge → DeltaLambdaSignRule, and likewise for the hook-product bridge. The discharge therefore cannot live at the statement site without a cycle; it moves downstream to this leaf, exactly as the FRT hook-length formula did in QOU.BraidKnot.HookProductHLF.

    theorem QOU.BraidKnot.BurnsideDischarge.sort_coe_parts {n : ℕ} (Λ : DeltaLambdaSignRule.Partition n) :
    Multiset.sort (fun (x1 x2 : ℕ) => x1 ≥ x2) ↑Λ.parts = Λ.parts

    Coercing a weakly-decreasing list to a Multiset and sorting it back is the identity. This is the same round-trip PartitionNatBridge.partitionEquivNatPartition's left_inv performs; isolated here because the shape identity below needs it on its own.

    theorem QOU.BraidKnot.BurnsideDischarge.toYoungDiagram_eq {n : ℕ} (Λ : DeltaLambdaSignRule.Partition n) :
    toYoungDiagram Λ = ((PartitionReindex.partitionEquivIndex n) Λ).diagram

    The shape glue. The YoungDiagram a custom Partition n denotes is the diagram carried by its image under the reindexing equiv — i.e. bridge (1)'s toYoungDiagram and bridge (2)'s partitionEquivIndex agree on shapes.

    Both sides are YoungDiagram.ofRowLens of the same parts list; the right-hand side takes the scenic route through Nat.Partition's multiset, which sort_coe_parts undoes.
