    The ADDITIVE Jucys–Murphy elements, and where Prop 3.24 actually breaks #

    Every route tried on the multiplicative elements jmRaw failed (five refuted leads, bean qou-u9o1). Reading the classical source explained why: jmRaw is not the Jucys–Murphy element.

    Mathas (Iwahori–Hecke Algebras and Schur Algebras of the Symmetric Group, Prop. 3.24) defines them additively — a sum of transpositions, L₁ = 0, with recursion L_k = q⁻¹(T_{k−1} + T_{k−1} L_{k−1} T_{k−1}). Note the extra + T_{k−1}, absent from jmRaw (k+1) = σ_k · jmRaw k · σ_k.

    This file builds the additive family in this corpus's Hecke convention (σ² = (q − q⁻¹)σ + 1) rather than transcribing formulas across conventions — Mathas works with T² = (q−1)T + q, so his coefficients are not ours.

    What the recursion gives (proved) #

    Writing A_{k+1} := σ_k A_k σ_k + d·σ_k for a free scalar d and h := q − q⁻¹:

    • addJM_sigma_left : σ_k A_{k+1} = h·A_{k+1} + A_k σ_k + d
    • addJM_sigma_right : A_{k+1} σ_k = h·A_{k+1} + σ_k A_k + d
    • addJM_sigma_comm_add : σ_k commutes with A_k + A_{k+1} — for every d.

    The two exchange relations differ only by swapping A_k σ_k and σ_k A_k, which is exactly why those terms cancel in the sum. This is Mathas 3.24(iii)'s sum half, and it comes out cleaner here than the multiplicative analogue did: no constraint on d at all.

    Where 3.24 breaks — the product half does NOT follow from the recursion #

    Mathas 3.24(iii) also asserts T_i commutes with the product L_i L_{i+1}, and derives commutativity (iv) from it. From the recursion alone one gets only

    • addJM_sigma_prod_swap : σ_k (A_k A_{k+1}) = (A_{k+1} A_k) σ_k

    — with the operands swapped on the right, which is genuine commutation only if A_k and A_{k+1} already commute. So (iii)'s product half and (iv) are entangled, and the recursion does not separate them.

    This is the same obstruction found on the multiplicative side (sigma_mul_jm_prod), and it is now located precisely: it survives the change of convention. Mathas's "follows easily using the relations" must use the explicit sum-of-transpositions expansion, not just the recursion — which this file does not have, because an abstract presentation has no transposition elements.

    Honest scope #

    Nothing here proves commutativity, and JucysMurphySpectrum is untouched. What is established is that the additive convention does improve the sum half (unconditionally, for free d) and does not rescue the product half — so the next attempt needs the transposition expansion, not another convention change.

    Refs:

    • [macdonald1995] Symmetric Functions and Hall Polynomials, I.1.
    • [wenzl1988] Hecke algebra representations.
