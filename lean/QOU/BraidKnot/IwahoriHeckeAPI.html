    Iwahori--Hecke algebra API (scaffolding for QOU's graded-Mikusiński framework) #

    This file provides a Mathlib-style API for the Iwahori–Hecke algebra H_n(q) over a commutative ring R, structured to support QOU's graded-Mikusiński / Goncharov-period framework (conj:gb-depth-period-correspondence).

    The core IwahoriHeckeAlgebra structure is defined as a class with the standard relations + a bar involution + Markov trace. Specific results — Wedderburn decomposition at generic q, central idempotent formulas via Jucys–Murphy elements — are stated as theorems with sorry references to upstream sources (Kassel 1995, Hoefsmit, Murphy, Dipper–James), pending Mathlib's eventual formalisation.

    This scaffolding lets QOU's content blocks (hecke-baer-star-generic.lean, explicit-central-idempotent.lean, gb-depth-period-correspondence.lean, etc.) cite a concrete Lean API rather than True placeholders. When Mathlib upstreams an IwahoriHeckeAlgebra, these files migrate by re-binding the opaque definitions to Mathlib's official ones.

    structure QOU.BraidKnot.IwahoriHeckeAPI.IwahoriHeckeAlgebra (n : ℕ) (R : Type u_1) [CommRing R] (q : R) (h_unit : IsUnit q) :
    Type (max 1 u_1)

    The Iwahori–Hecke algebra H_n(q) of type A_{n-1} over a commutative ring R with invertible element q ∈ R^×. The algebra has braid generators σ_i (i = 1, …, n - 1) satisfying:

    1. Quadratic relation (σ_i - q)(σ_i + q⁻¹) = 0;
    2. Braid relation σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1};
    3. Far commutativity σ_i σ_j = σ_j σ_i for |i - j| ≥ 2.

    The bar involution * : H_n(q) → H_n(q) is the antilinear extension of σ_i ↦ σ_i⁻¹, q ↦ q⁻¹. The Markov trace is the unique linear functional tr_M : H_n(q) → R invariant under Markov moves (stabilisation + conjugation).

    This is a placeholder structure pending Mathlib's eventual formalisation. The opaque type carries enough hypotheses to state and prove the structural results we need, but concrete construction is deferred.

    • carrier : Type

      The underlying carrier type.

    • ring : Ring self.carrier

      Algebra structure on the carrier.

    • star_ring : StarRing self.carrier

      Star (bar involution) structure.

    • sigma : Fin (n - 1) → self.carrier

      The braid generators σ_i for i ∈ Fin (n - 1). Defined only when n ≥ 1; trivial otherwise.

    • markov_trace : self.carrier → R

      Markov trace as an R-linear map carrier → R. Linearity, Markov-trace cyclicity, and the stabilisation property are placed as separate axioms below.

                    Prop

                    Markov trace stabilisation: with the tower inclusion incl : H_n ↪ H_{n+1} (HeckeInclusion) and the new top generator σ_n of H_{n+1} (index n-1 of its Fin n generators), the Markov trace satisfies

                    tr_{M, n+1}(incl a · σ_n) = z · tr_{M, n}(a)

                    for the Markov parameter z : R (concretely z = 1 / (q^{1/2} + q^{-1/2}), carried here as an abstract R-parameter since q^{1/2} need not lie in a generic R). Together with MarkovTraceCyclic this is the defining pair of Markov moves characterising tr_M (Jones 1987 §3). hn : 0 < n makes the σ_n index ⟨n-1, _⟩ : Fin n well-formed (stabilisation adds σ_n to H_n, which requires n ≥ 1).

                    • stabilisation (a : H.carrier) : H_succ.markov_trace (HeckeInclusion.incl a * H_succ.sigma ⟨n - 1, ⋯⟩) = z * H.markov_trace a

                          def QOU.BraidKnot.IwahoriHeckeAPI.IwahoriHeckeAlgebra.partitionTranspose :
                          List ℕ → List ℕ

                          Transpose of a partition (Young-diagram conjugate). For each column index j (0-indexed up to the row length of the first row), the transposed partition's j-th entry is the number of original rows with at least j + 1 boxes. Examples:

                          transpose [3, 1] = [2, 1, 1] (Young diagram with 3 + 1 = 4 boxes) transpose [2, 2] = [2, 2] (self-conjugate) transpose [4] = [1, 1, 1, 1]

                          Per Gemini PR #634 review: replaces the previous incorrect List.reverse placeholder. Reversal does NOT yield the transpose (e.g. [3, 1].reverse = [1, 3] which is not even a valid partition; the correct transpose is [2, 1, 1]).
