    QOU.BraidKnot.HookProductHLF — the FRT hook-length formula in the BraidKnot register #

    This file discharges the brick-1 target numSYT μ * hookProduct μ = |μ|! — the Frame–Robinson–Thrall hook-length formula stated over QOU.BraidKnot's own StandardYoungTableau / hookLength definitions — sorry-free, by composing three already-proved pieces:

    1. QOU.BraidKnot.SYTEncodingBridge.numSYT_eq_numStandardYoungTableaux (proved in QOU.BraidKnot.SYTEncodingBridgeTwo) — the tableau-count bridge numSYT μ = numStandardYoungTableaux μ (BraidKnot SYT ≃ Mathlib-register SYT).
    2. hookProduct_eq_hookLengthProduct (proved below) — the hook bridge hookProduct μ = μ.hookLengthProduct, i.e. BraidKnot's Finset.filter-counted arm/leg equals the geometric rowLen/colLen arm/leg of QOU.Mathlib.
    3. QOU.Mathlib.numStandardYoungTableaux_mul_hookLengthProduct — the geometric HLF, itself proved from the list-form Novelli–Pak–Stoyanovskii identity SYTEnum.numSYTenum_mul_prodHooks.

    Only piece 2 was missing; it is the content of this file, and it reduces to the two Finset.card computations already proved in QOU.BraidKnot.PieceAGeneral (armZ_eq_card, legZ_eq_card), which identify the arm/leg filters with Finset.Ioo images.

    Why this file rather than an in-place proof #

    QOU.Mathlib.HookLengthFormula transitively imports QOU.BraidKnot.StandardYoungTableau (via QOU.BraidKnot.SpechtClassification → Specht → StandardYoungTableau), so the HLF is not available where numSYT_mul_hookProduct was originally stated. The statement therefore moves downstream to this leaf module, where the import is legal. Nothing consumed the original sorryed declaration (every other occurrence in the corpus was a docstring/roadmap mention), so the move costs no consumer updates.

    theorem QOU.BraidKnot.HookProductHLF.numSYT_mul_hookProduct (μ : YoungDiagram) :
    numSYT μ * hookProduct μ = μ.card.factorial

    Frame–Robinson–Thrall hook-length formula in the QOU.BraidKnot register, sorry-free:

    #SYT(μ) · ∏_{c ∈ μ} h(c) = |μ|!,

    equivalently f^μ = |μ|! / ∏ h(c). Stated multiplicatively so it lives over ℕ (hookProduct_pos makes the division form well-posed).
