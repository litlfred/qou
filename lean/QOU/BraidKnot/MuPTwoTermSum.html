    1. Window facts #

    Everything below runs off the two w-bounds already proved in the parent file, plus positivity of the relevant powers.

    source
    theorem QOU.BraidKnot.MuPTwoTermSum.wGen_pos (q : ℝ) (hq0 : 11099 / 10000 ≤ q) (hq1 : q ≤ 111 / 100) :
    0 < MuPCarrier.wGen q

    w > 0 on the pin window.

    2. The signs are forced #

    Neither sign is a hypothesis. c₃ > 0 because a non-positive leading coefficient of small height drives the whole sum negative, while t > 0; c₄ < 0 because a non-negative quartic term leaves the cubic term alone above the top of the residual window — the same (1/5)·w³ ≥ 2.5194e-7 > 2.4e-7 estimate that no_small_height_w_monomial uses at j = 3.

    source
    theorem QOU.BraidKnot.MuPTwoTermSum.sum_signs_forced (q c₃ c₄ t : ℝ) (hq0 : 11099 / 10000 ≤ q) (hq1 : q ≤ 111 / 100) (hc30 : 1 / 5 ≤ |c₃|) (_hc31 : |c₃| ≤ 5) (_hc40 : 1 / 5 ≤ |c₄|) (hc41 : |c₄| ≤ 5) (htlo : 18 / 10 ^ 8 ≤ t) (hthi : t ≤ 24 / 10 ^ 8) (hsum : c₃ * MuPCarrier.wGen q ^ 3 + c₄ * MuPCarrier.wGen q ^ 4 = t) :
    0 < c₃ ∧ c₄ < 0

    The two-term bar-even tail must alternate. If c₃·w³ + c₄·w⁴ = t with both coefficients of small height, q in the pin window and t in the residual window, then c₃ is positive and c₄ is negative.

    It is stronger than its signature. Only 1/5 ≤ |c₃| and |c₄| ≤ 5 are used — _hc31 and _hc40 are carried so the three theorems in this file take the same hypotheses and compose without plumbing. The check that establishes this is deleting both binders and fixing the two positional call sites: the proof closes unchanged. Do not reach for the unused-variable linter here; linter.unusedVariables does not fire on a binder prefixed with _, so its silence on this signature is the underscore doing its job and says nothing either way. (An earlier version of this docstring cited that silence as the evidence. The claim was true and the evidence was not: a reviewer who checked it as invited would have seen nothing and been unable to tell "unused" from "warning suppressed". Caught by an independent verification pass.)

    So the alternation holds for a quartic coefficient of arbitrarily small height and for a cubic coefficient of arbitrarily large height; small-heightness is needed only as a floor on |c₃| and a ceiling on |c₄|. Do not read the extra binders as required.

    3. The coefficients are pinned #

    With the signs fixed, both coefficients are bounded on both sides. The cubic rung is the sharp one: [1/5, 1/4] is 1 % of the small-height band.

    source
    theorem QOU.BraidKnot.MuPTwoTermSum.sum_c3_pinned (q c₃ c₄ t : ℝ) (hq0 : 11099 / 10000 ≤ q) (hq1 : q ≤ 111 / 100) (hc30 : 1 / 5 ≤ |c₃|) (hc31 : |c₃| ≤ 5) (hc40 : 1 / 5 ≤ |c₄|) (hc41 : |c₄| ≤ 5) (htlo : 18 / 10 ^ 8 ≤ t) (hthi : t ≤ 24 / 10 ^ 8) (hsum : c₃ * MuPCarrier.wGen q ^ 3 + c₄ * MuPCarrier.wGen q ^ 4 = t) :
    1 / 5 ≤ c₃ ∧ c₃ ≤ 1 / 4

    The cubic rung is pinned to [1/5, 1/4]. The lower bound is the small-height hypothesis once the sign is known; the upper bound is c₃·w³ = t − c₄·w⁴ ≤ 24/10⁸ + 5·(11/1000)⁴, against w³ ≥ (108/10000)³. The margin is genuine but thin — 313205/10¹² against 314928/10¹², 0.5471 % — so it is exact rational arithmetic, not a decimal estimate.

    1/4 is content, not slack. The sharp window-wide bound is 313205/1259712 = 0.2486322, so 1/4 leaves 0.00137; a mutation to 24/100 fails to close. Stated because a reader cannot otherwise tell a chosen round number from a forced one.

    theorem QOU.BraidKnot.MuPTwoTermSum.sum_c4_bounded (q c₃ c₄ t : ℝ) (hq0 : 11099 / 10000 ≤ q) (hq1 : q ≤ 111 / 100) (hc30 : 1 / 5 ≤ |c₃|) (hc31 : |c₃| ≤ 5) (hc40 : 1 / 5 ≤ |c₄|) (hc41 : |c₄| ≤ 5) (htlo : 18 / 10 ^ 8 ≤ t) (hthi : t ≤ 24 / 10 ^ 8) (hsum : c₃ * MuPCarrier.wGen q ^ 3 + c₄ * MuPCarrier.wGen q ^ 4 = t) :
    c₄ ≤ -(4 / 5)

    The quartic rung satisfies c₄ ≤ −4/5. From c₄·w⁴ = t − c₃·w³ ≤ 24/10⁸ − (1/5)·(108/10000)³ = −11942.4/10¹² against w⁴ ≤ (11/1000)⁴. So the small-height band available to c₄ is [−5, −4/5], not [−5, −1/5] ∪ [1/5, 5]. Margin 0.0956 %.

    −4/5 is content, not slack. The sharp window-wide bound is −0.8156820, so −4/5 leaves 0.01568; a mutation to −82/100 fails to close.

    4. What this does not say #

    sum_signs_forced is a statement about a specific two-term shape. Read the arity before citing it:

    • It is not an exclusion. The family is non-empty — at the proton pin, (c₃, c₄) = (0.2014, −3.5) reproduces t to 3.8e-4 relative. A future derivation may land in it.
    • It is not a statement about three-term or longer tails, whose sign structure it does not constrain.
    • It does not license reading the alternation as physical. An alternating cyclotomic tower is a familiar shape in quantum topology, and that is suggestive rather than evidential: the entropy bound still says a coefficient matched to t carries no information. The value of the alternation is that a derived pair now has a sharp prediction to fail.
