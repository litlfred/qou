    QOU.BraidKnot.CrystalRMatrixSubLemma — operator-valued Sub-lemma 2.1 (proposition, conditional on conj:crystal-graph-realization) #

    Encodes the operator-valued statement of Sub-lemma 2.1 for the Hecke branching block decomposition. Per the audit docs/audits/2026-05-08-crystal-r-matrix-sublemma-2-1.md (Step 2), the matrix-entry pole order at q = 0 of A^λ_{μ, ν}(σ_i) on any SYT T in the (μ, ν)-block is 1 iff ρ_T(i) ≤ -1, where ρ_T(i) is the axial distance c(cell of i+1) - c(cell of i).

    Conditional on conj:crystal-graph-realization (Brundan–Kleshchev iso + Kashiwara crystal limit), this gives a purely combinatorial pole-order indicator that bypasses the Hoefsmit matrix-entry computation. In particular, α_shift(T_{(p, k)}) = k(p - 1) recovered without computing seminormal eigenvalues.

    The class states that a given pole-order assignment agrees with the audit's Step 2 indicator. The assignment is carried as separate data (PoleOrderData) rather than as a class field, so no instance can pick the very function it is compared against — see the history note on combinatorialPoleOrder below. A HasBranchingBlockLemma instance can be derived from this class via the Step 4 composition (cycle → product over generators), closing the operator-valued residual of prop:confinement-nf-partial-proof Theorem T_2.

    structure QOU.BraidKnot.PoleOrderData :
    Type

    Matrix-entry pole orders as given data.

    poleOrder ρ is the pole order at q = 0 of the matrix entry of A^λ_{μ, ν}(σ_i) on an SYT whose axial distance at i is ρ, recorded as a Bool (true ↦ pole of order 1, false ↦ order 0; Step 1 of the audit rules out higher orders).

    Why a structure and not a class field (2026-08-24, bean qou-09mr). When the pole orders are a field of the class, an instance gets to choose the very function the propositional field compares it against, and the choice fun ρ => decide (ρ ≤ -1) satisfies the comparison by rfl. That is how the previous encoding was discharged for free — no sorry, and nothing established. Carried as data and taken as a class parameter below, the assignment must be named by whoever assumes something about it.

    • poleOrder : ℤ → Bool

      Pole order at q = 0 as a function of the axial distance ρ: true for a pole of order 1, false for order 0.

      Prop

      Crystal R-matrix Sub-lemma 2.1 (proposition, conditional), as a predicate ON a given pole-order assignment.

      Conditional on conj:crystal-graph-realization, the matrix-entry pole order of A^λ_{μ, ν}(σ_i) at q = 0 on any SYT T in the (μ, ν)-block is

      pole_order(σ_i, T) = 1 iff ρ_T(i) ≤ -1 = 0 otherwise

      where ρ_T(i) = c(cell of i+1 in T) - c(cell of i in T) is the axial distance and c(cell) = col - row.

      The single field asserts that identity about the supplied P; the class can no longer manufacture its own indicator.

      • pole_indicator_correct (rho : ℤ) : P.poleOrder rho = decide (rho ≤ -1)

        The proposition itself (Step 2 of the audit): the supplied pole order is exactly the indicator of ρ ≤ -1. This is the field a concrete model must discharge (not a sorry — the content is combinatorial, derived from the crystal R-matrix action at q = 0).

        def QOU.BraidKnot.CrystalRMatrixSubLemma.column_syt_pole_per_cycle (p : ℕ) :
        ℕ

        Pole-per-cycle on the column SYT of shape (1^p).

        By definition of a column, every adjacent pair (j, j+1) for j = 1, …, p - 1 has axial distance ρ_T(j) = -1 (cells stacked vertically; col fixed, row decreases by 1). By pole_indicator_correct, every generator contributes a pole of order 1, so the cycle pole is p - 1. Matches prop:alpha-shift-torus-knot (α_shift(T_{(p, 1)}) = p - 1).

          The residual vacuity, stated as theorems rather than left as a trap #

          Parameterising stops the class from choosing its pole orders, but it cannot stop a consumer from instantiating at the assignment that is literally the indicator. Rather than leave that as a latent trap — the shape that let the previous encoding pass every audit — it is recorded below as a pair. Read together they say exactly what an instance is worth: [CrystalRMatrixSubLemma R q P] carries no information until P is pinned down, and it carries real information as soon as it is.

            History (2026-08-24, bean qou-09mr). This replaces an instance canonical whose class field poleIndicator was set to fun ρ => decide (ρ ≤ -1) — the very function pole_indicator_correct compares against — so the propositional field closed by rfl. Its docstring conceded the point ("the indicator IS the witness function") and offered "no sorry" as reassurance; no sorry was exactly the problem, because nothing was left visible to #print axioms. It was also an instance, pinned by let C := CrystalGraphRealization.canonical R q to the one-point crystal — and since that def is the corpus's only realisation of CrystalGraphRealization, every way of instantiating this class's theorems at a concrete R, q got the free witness by resolution.

            Note what this witness does not depend on: R, q, and the realisation C are free. A consistency witness that holds for every crystal-graph realisation, including CrystalGraphRealization.canonical's one-point crystal, says nothing about any of them — it is a fact about the indicator function alone. The old instance hid that by pinning itself to CrystalGraphRealization.canonical R q, which read as though a crystal had been consulted.
