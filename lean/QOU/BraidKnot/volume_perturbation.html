    QOU.BraidKnot.volume_perturbation #

    Canonical Lean for content block prop:volume-perturbation-formula.

    Proposition. The vertex volume perturbation on going from H_k to H_{k+1} is δΦ_k = z² · Vol(4_1) · [k − 3]_q, where z = 1/(√q + 1/√q) is the Markov parameter and Vol(4_1) ≈ 2.030 is the figure-eight volume.

    Disposition (integrity) #

    The previous revision carried the perturbation identity as a class field claim_perturbation_formula and handed it back by projection (def := ctx.claim_perturbation_formula) — the self-assuming projection forbidden by AGENTS.md §3b-cond item 5. This is corrected:

    • The class VolumePerturbationContext now carries only genuine data — the substrate parameter q, the Markov parameter z, the volume Vol(4_1), and the actual vertex-volume-perturbation sequence δΦ — plus the definitional Markov-parameter link z = 1/(√q + 1/√q). It does not carry the perturbation identity as a field.
    • qIntSym is the concrete balanced q-integer and qIntSym_zero proves [0]_q = 0 (the unperturbed level k = 3 carries no perturbation) — genuine, sorry-free algebra.
    • volume_perturbation states the real manuscript identity over the concrete q-integer; it is unproved (sorry + manuscript citation per AGENTS.md §1a disposition 2 — the identity between the categorical vertex-volume perturbation δΦ and the closed form is the empirically verified content, not a Mathlib-derivable one).

      • Vol_41 : ℝ

        The figure-eight hyperbolic volume Vol(4_1) ≈ 2.030.

      • δΦ : ℕ → ℝ

        The actual vertex volume perturbation at level k: δΦ_k (the categorical quantity, to be compared with the closed form).

      • z_def : z = 1 / (√q + 1 / √q)

        Definitional link: the Markov parameter z = 1 / (√q + 1/√q).

        The perturbation identity: δΦ_k = z² · Vol(4_1) · [k − 3]_q for all k ≥ 4.
