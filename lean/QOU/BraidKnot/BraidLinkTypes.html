    QOU.BraidKnot.braid_link_types #

    Step A of the Track-C plan: define braid-group and link types in Lean from first principles, discharging the closure 2 = Hopf link atomic axiom from rem:markov-closure-map-axiomatic.

    Scope #

    This file builds the MINIMAL braid-link infrastructure needed for the Track-C application: the 2-strand braid group B_2, the Markov-closure map at 2 strands, and the Hopf link as a concrete inductive type.

    Full braid-group theory (Mathlib-class) is OUT OF SCOPE; here we focus on the 2-strand specialisation.

    What's defined #

    • inductive Link — small finitely-generated link type covering the unknot and the Hopf link (and a generic "torus link T(2, k)" case).
    • Braid2 : Type — the 2-strand braid group, generated by a single σ and its inverse.
    • closure2 : Braid2 → Link — the Markov closure of a 2-strand braid.
    • closure2_at_two_crossings_eq_hopf — the substantive theorem: the Markov closure of σ² is the Hopf link.

    This DISCHARGES Atom 1 of rem:markov-closure-map-axiomatic.

    LaTeX label: rem:braid-link-types (Track C Step A).

    The Link type (small concrete inductive) #

    For our purposes we need 3 link types: unknot, Hopf, generic torus T(2, k). This is sufficient for the 2-strand closure analysis.
