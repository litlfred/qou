    QOU.BraidKnot.JucysMurphyCoeff — the ℂ-free core of Identity (B) #

    Identity (B) — the Plancherel content-square mean, the second half of the keystone-carried Identity I — is classically proved via Z(ℂ[S_n]) + Jucys–Murphy elements. This file records the observation (owner question, 2026-06-24) that ℂ is not needed, and indeed neither is any representation theory or dim(λ)/SYT/RSK machinery (none of which is in the pinned Mathlib): the computational heart of (B) is a statement about the identity coefficient of (Σ involutions)² in the group algebra R[G] = MonoidAlgebra R G over a generic CommRing R (§7c base-ring discipline — start generic).

    coeff_one_sq_sum_single_involution: for any group G and any finite set s of involutions, the coefficient of 1 in (Σ_{g∈s} g)² is |s|. Reason: g·h = 1 ⟺ h = g⁻¹ = g for involutions, so only the |s| diagonal terms g·g = 1 contribute.

    Why this is the (B) core. Applied to the Jucys–Murphy element X_k = Σ_{i<k}(i k) (transpositions are involutions), it gives coeff_1(X_k²) = #{i<k} = k, hence coeff_1(C₂) = coeff_1(Σ_k X_k²) = Σ_k k = \binom{n}{2} — the same \binom{n}{2} as jm_identity_coeff_two (on main, IdentityIContentDecomposition.lean), now with the group-algebra coefficient itself identified over generic R, ℂ-free. The remaining bridge to the partition form Σ_λ dim(λ)²·Σ_{c∈λ} c(c)² is the standard regular-representation / Wedderburn step — over ℚ (S_n is a rational group), not ℂ — and needs the S_n block-decomposition infrastructure absent from the pinned Mathlib.

    theorem QOU.BraidKnot.JucysMurphyCoeff.coeff_one_sq_sum_single_involution {R : Type u_1} [CommRing R] {G : Type u_2} [Group G] [DecidableEq G] (s : Finset G) (hs : ∀ g ∈ s, g * g = 1) :
    ((∑ g ∈ s, MonoidAlgebra.single g 1) ^ 2) 1 = ↑s.card

    ℂ-free core of Identity (B). In R[G] = MonoidAlgebra R G over any CommRing R, the identity coefficient of (Σ_{g∈s} g)² is |s| whenever every g ∈ s is an involution (g·g = 1). Proof: expand the square to Σ_{g,h} single (g·h) 1; evaluating at 1 keeps the terms with g·h = 1, i.e. h = g⁻¹ = g (involution), so exactly the |s| diagonal terms survive, each contributing 1. No field, no representation theory — pure group-algebra combinatorics over generic R.

    theorem QOU.BraidKnot.JucysMurphyCoeff.jm_swap_sq_coeff_one {R : Type u_1} [CommRing R] {n : ℕ} (k : Fin n) (t : Finset (Fin n)) :
    ((∑ i ∈ t, MonoidAlgebra.single (Equiv.swap i k) 1) ^ 2) 1 = ↑t.card

    Jucys–Murphy building block. For any finite t ⊆ Fin n, the JM-style sum Σ_{i∈t} (i k) (transpositions all sharing the strand k) has squared identity coefficient |t|. The map i ↦ (i k) is globally injective ((i k) sends k ↦ i, so it determines i) and each (i k) is an involution, so the indexed lemma applies. With t = {i : i < k} this is coeff_1(X_k²) = #{i < k} = k; summing over k gives coeff_1(Σ_k X_k²) = \binom{n}{2}.

    Identity (B), ℂ-free computational core, fully discharged. The Jucys–Murphy central element C₂ = Σ_k X_k² with X_k = Σ_{i<k}(i k) has identity coefficient \binom{n}{2} in R[S_n] = MonoidAlgebra R (Perm (Fin n)), over any CommRing R — no ℂ, no representation theory, no dim(λ)/SYT/RSK. Per-k: coeff_1(X_k²) = #{i<k} = k (jm_swap_sq_coeff_one + Finset.Iio card); summing: Σ_{k} k = \binom{n}{2} (Gauss). This is the exact \binom{n}{2} of IdentityIContentDecomposition.jm_identity_coeff_two on main, now realised as the group-algebra coefficient itself. The remaining bridge to Σ_λ dim(λ)²·Σ_c c(c)² is the standard regular-rep/Wedderburn step over ℚ (S_n rational), not ℂ.
