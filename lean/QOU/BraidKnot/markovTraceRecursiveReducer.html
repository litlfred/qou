    QOU.BraidKnot.markovTraceRecursiveReducer — symbolic Markov-trace reducer #

    Proposition (prop:markov-trace-recursive-reducer).

    Let β ∈ B_n be any braid word. There is a terminating algorithm that returns a closed-form symbolic expression for tr_M(β) ∈ ℚ(q) using only:

    (1) The Hecke quadratic σᵢ² = h σᵢ + 1 (h = q − q⁻¹),

    (2) The Markov axiom tr_M(α σₙ) = z · tr_M(α),

    (3) Cyclicity tr_M(αβ) = tr_M(βα),

    (4) The braid relations.

    The algorithm terminates in O(ℓ(β) · n!) basis evaluations and verifies the disjoint-product property tr_M(α ⊗ β) = tr_M(α) · tr_M(β).
