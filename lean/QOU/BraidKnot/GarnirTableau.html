    The Garnir tableau g_{ij}, and descent nodes #

    Mathas' Lemma 3.13 says: for a row-standard non-standard t there are a Garnir tableau g and w with t = g · w and ℓ(d(t)) = ℓ(d(g)) + ℓ(w). This file supplies the two objects the statement names — g_{ij} and the descent nodes that index the (i,j) to use.

    g_{ij} is a rotation #

    refTab_symm_apply (QOU.BraidKnot.TableauPerm) puts the label rowPrefix μ i + j in cell (i,j) of the reference tableau, and the companion probe measures that g_{ij} rotates the label block [rowPrefix μ i + j, rowPrefix μ (i+1) + j] by j+1 — 108 Garnir tableaux over all partitions of n = 3..7, zero mismatches. So g_{ij} is defined here as garnirPerm • t^μ with garnirPerm an intervalRotate, and bijectivity is free: nothing has to be shown surjective.

    The block has width rowLen μ i + 1 — the tail of row i from column j, plus the head of row i+1 up to column j.

    Scope #

    Mathas 3.13 is not proved here. What this adds is that both of its objects are now definable, and length_garnir_eq_add_iff reduces its length condition to inversion containment against a concrete g. Which descent node to pick is still open — measured, the first always works (1789/1789 at n = 3..6), but that is evidence, not a proof.

        Non-vacuity: g_{ij} is never the reference tableau #

        The rotation amount is j + 1 and the block width is rowLen μ i + 1. Since (i+1, j) ∈ μ forces j < rowLen μ (i+1) ≤ rowLen μ i, the shift is strictly between 0 and the width — so it never reduces to the identity, for any μ, i, j. This is what stops every result below from being vacuous.

          The length half of Mathas 3.13, against the actual Garnir tableau.

          For t = w • g_{ij}, length is additive exactly when w undoes none of g_{ij}'s inversions. Both sides are now concrete: the right-hand side is a containment between inversion sets of explicit permutations, with no lengths and no reduced words in it.
