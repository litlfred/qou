    QOU.BraidKnot.DeuteronWitness — placeholder R5-full witness for ²H #

    PR #608's R5-full search at L_max=8 returned σ_2 σ_1^6 σ_2^{-1} as the deuteron winner — NOT the historical 6_2. This is the "single-term cost function" failure: B = m_e ρ |tr_M(T_w)| under-constrains the search and admits non-canonical PSD-feasible candidates.

    The full multi-term cost (T2-T6 of thm:knot-mass-formula-unified) re-run is open work (PR #608 followup #1). This module records a PLACEHOLDER witness for ²H so the R5FullWitness LightNucleus.deuterium typeclass resolves; concrete numerical values come from re-running the search with the fixed cost function.

    What this module provides #

    Categorical significance #

    The instance lets downstream theorems compile under [R5FullWitness LightNucleus.deuterium], but the values are provisional: closing the actual deuteron uniqueness (i.e. showing the canonical knot is 6_2) requires the multi-term cost re-run.
