    QOU.BraidKnot.hoefsmit_seminormal_form — explicit ρ_λ(σᵢ) matrix entries #

    Proposition (prop:hoefsmit-seminormal-form).

    For each partition λ ⊢ n and substrate parameter q > 1, the Hoefsmit seminormal form gives an explicit matrix representation ρ_λ : H_n(R, q) → M_{d_λ}(ℂ) where d_λ = |SYT(λ)| is the number of standard Young tableaux of shape λ. The generator σᵢ acts on the SYT basis by

      ρ_λ(σᵢ)_{s s'} = a_ρ      if s' = s
                 = b        if s' = sᵢ (the swap of i, i+1)
                 = 0        otherwise

    where

      a_ρ = (q − q⁻¹) / (1 − q^{-2ρ}),
  b   = √(1 − a_ρ²)

    and ρ = ρ(s, i) is the axial distance between cells i and i+1 in s.

    The Lean encoding records the matrix entries against an abstract HoefsmitSeminormalContext carrying the SYT data and the representation matrix.

    -- Ref: [manuscript] quantum-observable-universe/braids-and-knots/hoefsmit-seminormal-form.md -- Ref: [hoefsmit1974] P. Hoefsmit, Representations of Hecke algebras of finite groups with BN-pairs of classical type, PhD thesis 1974.

    class QOU.BraidKnot.HoefsmitSeminormalContext (n : ℕ) :
    Type 1

    Abstract context for the Hoefsmit seminormal form.

    • q : ℝ

      The substrate parameter q > 1.

    • q_gt_one : 1 < q n
    • Partition : Type

      Indexing type for partitions of n.

    • SYT : Partition n → Type

      Indexing type for standard Young tableaux.

    • axialDistance {lam : Partition n} : SYT lam → ℕ → ℤ

      The axial distance ρ(s, i) between cells i and i+1.

    • hoefsmitDiagonal : ℤ → ℝ

      The Hoefsmit diagonal entry a_ρ = (q − q⁻¹) / (1 − q^{-2ρ}).

    • hoefsmitOffDiagonal : ℤ → ℝ

      The Hoefsmit off-diagonal entry b = √(1 − a_ρ²).

    • repMatrix {lam : Partition n} (s s' : SYT lam) (i : ℕ) : ℝ

      The representation matrix entry ρ_λ(σᵢ)_{s s'}.

    • swapIResult {lam : Partition n} : SYT lam → ℕ → Option (SYT lam)

      The "swap-i-result" function, partial since it may not yield a valid SYT.

    • repMatrix_def {lam : Partition n} (s s' : SYT lam) (i : ℕ) : repMatrix s s' i = if s' = s then hoefsmitDiagonal n (axialDistance s i) else match swapIResult s i with | some t => if s' = t then hoefsmitOffDiagonal n (axialDistance s i) else 0 | none => 0

      Manuscript defining equation for the matrix entries (Hoefsmit 1974).
