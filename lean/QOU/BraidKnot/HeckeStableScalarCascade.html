    The stable Hecke algebra collapses irreducible representations to scalars #

    HeckeGenerators (HeckeJucysMurphyElements.lean) presents the stable algebra H_∞(q): its hecke, braid and far relations are quantified over all i : ℕ. This file proves that that arity is not a harmless over-generalisation. It carries a genuine obstruction:

    No representation on which σ₀ and σ₁ act irreducibly can be a HeckeGenerators instance.

    The mechanism is Schur, not dimension. far forces σ₃ to commute with both σ₀ and σ₁; if those two generate the full endomorphism algebra, Schur makes σ₃ a scalar, and then a downward cascade along the braid relation drags σ₂, σ₁, σ₀ down to that same scalar.

    What is proved here #

    • sigma_eq_of_succ_scalar — the cascade step, in any HeckeGenerators over a field with Nontrivial A: if σ (i+1) is a scalar s, then σ i is the same scalar s.
    • sigma_scalar_of_schur — the exclusion: under a Schur hypothesis on {σ₀, σ₁}, σ₁ is scalar.
    • stdTwo_hecke0 / stdTwo_hecke1 / stdTwo_braid — the explicit 2×2 Young seminormal matrices really do satisfy the H₃(q) relations, over any field with q ≠ 0.
    • stdTwo_centralizer_scalar — their joint centralizer is exactly the scalars.
    • stdTwo_no_stable_extension — hence no HeckeGenerators instance restricts to them.

    Why this matters (bean qou-t1kv) #

    QOU/Archimedean/HeckeH3.lean carries stdRep3, the 2-dimensional (2,1) representation of H₃(q), with its Hecke and braid relations already proved. It is the obvious multi-dimensional witness for IsJMWeight (HeckeSeminormalWeight.lean), which is currently non-vacuous only at the one-dimensional scalarGenerators. stdTwo_no_stable_extension shows that plugging it in is not merely awkward but impossible: the obstruction is real, and a bounded-index variant of the class (relations required only for i < n - 1) is the only route to a dim > 1 witness.

    This is a scope-(b) structural exclusion in the sense of AGENTS.md: the invariant that forbids the construction is proved here, not inferred from a failed search.

    Exactly what is excluded — the exclusion does NOT reach reducible representations #

    The hypothesis that does the work is the centralizer condition sigma_scalar_of_schur.schur, not "irreducible" and not "dim > 1". A reducible representation has a non-scalar idempotent in its centralizer, so it simply fails that hypothesis and the theorem says nothing about it.

    That is not a hedge — §5 proves the boundary is real: existsNonscalar_heckeGenerators exhibits a genuine HeckeGenerators instance on 2×2 matrices whose generators are not scalar, namely the constant diagonal σᵢ = diag(q, −q⁻¹) for every i. It is reducible (the two coordinate lines are invariant), so:

    • dim > 1 instances exist. Any reading of this file as "no multi-dimensional instance exists" is wrong, and constGenerators is the counterexample.
    • The Schur hypothesis is load-bearing, and the exclusion is sharp. What H_∞ cannot host is an irreducible action, not a big one.

    (Raised by the sibling Sym²-gate PR #5764, where an irrep-level exclusion was being read as covering arbitrary objects — V_{1/2} ⊕ V_0 has dimension 3, is not an irrep, and passes. Same shape of trap, so the boundary is proved here rather than asserted.)

    Refs:

    • [jones1987] V. Jones, Hecke algebra representations of braid groups and link polynomials.
    • [wenzl1988] H. Wenzl, Hecke algebras of type A_n and subfactors.

    §1 A scalar generator is a root of the Hecke quadratic #

    s * s = (q - q⁻¹) * s + 1

    If a generator is the scalar s, the Hecke relation forces s² = (q − q⁻¹)s + 1.

    Nontrivial A is what makes algebraMap from the field R injective; without it A is the zero ring and every relation holds vacuously.

    §2 The downward cascade #

    source
    theorem QOU.BraidKnot.Hecke.sigma_eq_of_succ_scalar {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} [Nontrivial A] (H : HeckeGenerators R A q) (i : ℕ) (s : R) (h : HeckeGenerators.σ q (i + 1) = (algebraMap R A) s) :
    HeckeGenerators.σ q i = (algebraMap R A) s

    Cascade step. In H_∞(q), if σ (i+1) is the scalar s then σ i is the same scalar s.

    Proof: the braid relation at i reads σᵢ · s · σᵢ = s · σᵢ · s. Scalars are central, so this is s · σᵢ² = s² · σᵢ. Substituting the Hecke relation σᵢ² = (q − q⁻¹)σᵢ + 1 and collecting gives s·(s − (q − q⁻¹)) · σᵢ = s, and the bracket is 1 by scalar_mul_sub_eq_one.

    source
    theorem QOU.BraidKnot.Hecke.sigma_eq_of_le_of_scalar {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} [Nontrivial A] (H : HeckeGenerators R A q) (s : R) (k j : ℕ) :

    Downward propagation. A scalar at index j forces the same scalar at every i ≤ j.

    §3 Schur forces every generator to be scalar #

    source
    theorem QOU.BraidKnot.Hecke.sigma_scalar_of_schur {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} [Nontrivial A] (H : HeckeGenerators R A q) (schur : ∀ (x : A), x * HeckeGenerators.σ q 0 = HeckeGenerators.σ q 0 * x → x * HeckeGenerators.σ q 1 = HeckeGenerators.σ q 1 * x → ∃ (c : R), x = (algebraMap R A) c) :
    ∃ (c : R), HeckeGenerators.σ q 1 = (algebraMap R A) c

    The exclusion. If the joint centralizer of σ₀ and σ₁ consists of scalars — the Schur condition satisfied by any irreducible representation — then σ₁ is itself a scalar.

    far places σ₃ in that centralizer (0 + 1 < 3 and 1 + 1 < 3), so σ₃ is a scalar s; the cascade of §2 then drags σ₂ and σ₁ down to s.
