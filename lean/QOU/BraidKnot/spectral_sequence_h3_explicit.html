    class QOU.BraidKnot.SpectralSequenceH3ExplicitContext (d1Explicit d2Explicit pagesConcretised : Prop) :
    Type 1

    Abstract context for the spectral_sequence_h3_explicit claim — manuscript-named typed fields below; sub-claims (i) the explicit d_1-differential, (ii) the explicit d_2-differential, and (iii) the concretised page-identifications for H_3(R, q) are the three Prop parameters.

    Parameterised 2026-09-13. The three sub-claims were Prop-valued fields with a _holds witness beside each — fields typed with the universe Prop, so the instance chose the proposition and ⟨True, trivial⟩ discharged all three. Any [SpectralSequenceH3ExplicitContext]-conditional result was unconditional. QOU.ProofHygiene.SelfAssumingContexts is the machine-checked statement of why this shape is a defect regardless of intent: the carrier asserts nothing even as a conjecture, so it cannot serve as a conjectural witness either.

    As parameters, the propositions are fixed by whoever writes the binder and appear in the type of every consumer, so a witness proves that proposition rather than one the instance picked. The carrier stays inhabitable — it is a conjecture carrier and Nonempty K ↔ C is the correct semantics for one — but the vacuity is now visible in the type instead of hidden in the instance.

    No mathematical judgement is made here, deliberately. An earlier attempt encoded sub-claim (i) as d₁ ∘ d₁ = 0; that is true of any differential and is not the manuscript's claim, which is the explicit formula. The same attempt encoded (iii) as page-stabilisation past r = 3, keying the index to 3 by association with H_3 — which is the Hecke strand count, not a spectral-sequence page index. Both were the author's call to make, not this file's; parameterising states the shape without pre-empting either. The conjectures are untouched and still open: no instance is supplied.
