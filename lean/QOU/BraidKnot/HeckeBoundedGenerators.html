    The bounded Hecke presentation, and the Jucys–Murphy spectral half at n = 3 #

    HeckeStableScalarCascade.lean proved that HeckeGenerators — whose relations are quantified over all i : ℕ, i.e. the stable algebra H_∞(q) — cannot host an irreducible representation, and that a bounded-index variant is therefore the only route to a dim > 1 witness for IsJMWeight.

    This file builds that variant and cashes it out at n = 3.

    What is here #

    • HeckeGeneratorsBelow R A q n — the relations required only for the generator indices that actually occur in H_n(q), namely σ₀ … σ_{n-2}. At n = 3 this is exactly two generators with one braid relation and no far-commutation at all.
    • hecke_mul_sub_eq_one / sub_mul_hecke_eq_one — the Hecke relation already supplies the inverse, σ⁻¹ = σ − (q − q⁻¹). So the σinv / mul_σinv / σinv_mul fields of the unbounded HeckeGenerators are redundant data, and the bounded class does not carry them.
    • stdTwoBelow3 — the 2-dimensional (2,1) representation as an instance. Its Hecke and braid relations are the ones already proved in HeckeStableScalarCascade.lean; nothing new is assumed.
    • stdTwoBelow3_jm_content — the payload. The Jucys–Murphy elements act on the seminormal vector e₀ = (1,0) by q^{2c} with c = 0, 1, −1.

    Why the payload matters #

    HeckeJucysMurphyElements.lean splits JucysMurphySpectrum into a structural half (the Lᵢ exist, commute, multiply to the full twist) and a spectral half, and says of the latter:

    The spectral half — that Lᵢ acts on the seminormal basis by q^{2·content}. Untouched here. It needs Young's seminormal form, which the corpus does not carry.

    This file gives that spectral half its first instance. The three eigenvalues q^0, q^2, q^{-2} are q^{2c} for the contents c = 0, 1, −1 of the cells (0,0), (0,1), (1,0) — i.e. of the standard Young tableau

    1 2
3

    on λ = (2,1), read in the order the JM elements index. It is one tableau at one n, not Young's theorem; what it establishes is that the content spectrum is realised, on a genuinely 2-dimensional module, rather than only conjectured.

    Refs:

    • [jones1987] V. Jones, Hecke algebra representations of braid groups and link polynomials.
    • [wenzl1988] H. Wenzl, Hecke algebras of type A_n and subfactors.

    §1 The Hecke relation supplies the inverse #

    source
    theorem QOU.BraidKnot.Hecke.hecke_mul_sub_eq_one {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} {X : A} (h : X * X = (algebraMap R A) (q - q⁻¹) * X + 1) :
    X * (X - (algebraMap R A) (q - q⁻¹)) = 1

    X · (X − (q − q⁻¹)) = 1 for any Hecke-quadratic X. Scalars are central, so this is pure rearrangement — no invertibility hypothesis is needed.

    §2 The bounded presentation #

    source
    class QOU.BraidKnot.Hecke.HeckeGeneratorsBelow (R : Type u_3) [Field R] (A : Type u_4) [Ring A] [Algebra R A] (q : R) (n : ℕ) :
    Type u_4

    Bounded Hecke presentation. The relations of H_n(q), required only for the generator indices that actually occur there: σ₀ … σ_{n-2}, i.e. i + 1 < n.

    Contrast HeckeGenerators, which quantifies over every i : ℕ and so presents H_∞(q). That difference is not cosmetic — stdTwo_no_stable_extension shows the unbounded version excludes the 2-dimensional representation outright.

    No σinv field: §1 derives the inverse from hecke.

    • σ : ℕ → A

      The braid generators; only σ i for i + 1 < n is constrained.

    • hecke (i : ℕ) : i + 1 < n → σ q n i * σ q n i = (algebraMap R A) (q - q⁻¹) * σ q n i + 1

      Hecke relation, for each generator of H_n(q).

    • braid (i : ℕ) : i + 2 < n → σ q n i * σ q n (i + 1) * σ q n i = σ q n (i + 1) * σ q n i * σ q n (i + 1)

      Braid relation, whenever both σ i and σ (i+1) are generators of H_n(q).

    • far (i j : ℕ) : i + 1 < j → j + 1 < n → σ q n i * σ q n j = σ q n j * σ q n i

      Far commutation, whenever both indices are generators of H_n(q).
