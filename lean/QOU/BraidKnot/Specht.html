    QOU.BraidKnot.Specht — brick 2 of the Okounkov–Vershik tower #

    The classical Specht-module construction S^μ for a YoungDiagram μ with n = μ.card, following Sagan, The Symmetric Group (§2.3–2.5) and James, The Representation Theory of the Symmetric Groups.

    This is "brick 2" of the QOU OV-tower; it builds on brick 1 (QOU.BraidKnot.StandardYoungTableau, the SYT count numSYT, imported above).

    What is sorry-free here #

    The whole definitional foundation is verified, sorry-free:

    • Tableau μ — general (bijective) Fin n-fillings of μ's cells.
    • the S_n-action on tableaux (Tableau.smul, a MulAction).
    • rowPattern / colPattern — the row/column membership data of a tableau, together with the S_n-action on them (MulAction (Perm (Fin n)) (Fin n → ℕ)).
    • rowStab / colStab — row/column stabilizers as honest Subgroups (literally MulAction.stabilizer of the patterns).
    • Tabloid μ — the row-equivalence quotient, with Fintype/DecidableEq.
    • Mtab μ — the permutation module Tabloid μ →₀ k, with its S_n representation Mtab.rep (a Representation k (Perm (Fin n)) (Mtab μ)).
    • polytabloid and SpechtSubmodule μ (the latter is a Submodule by construction, being a Submodule.span).

    The two deep theorems — proved, one layer up #

    This module used to carry specht_isSimple and specht_finrank_eq_numSYT as honest sorry stubs. Both are now proved and the stubs have been removed; see §6 for where each lives and why the proofs cannot be written here. This module is sorry-free.

    • S^μ is simple in char 0 → SpechtIrreducible.specht_isSimple
    • dim_k S^μ = #SYT(μ) → SpechtStandardBasis.specht_finrank_eq_numSYT (equivalently SpechtFinrankWired.specht_finrank_eq_numSYT_wired)

    Both report [propext, Classical.choice, Quot.sound] under #print axioms.

    Conventions #

    Following brick 1, μ : YoungDiagram and a cell is (i, j) : ℕ × ℕ with (i, j) ∈ μ. We work over a base type k that is a field where simplicity is discussed, and a generic [CommRing k] for the module-level construction (nothing archimedean — §7c: no ℝ, no ordering, no Real.*).

    References #

    • [sagan2001] Sagan, The Symmetric Group, §2.3–2.5 (tabloids, polytabloids, Specht modules, the standard basis Thm 2.5.2).
    • [james1984representation] James, The Representation Theory of the Symmetric Groups (Specht modules, irreducibility in char 0).
    • [fulton1997] Fulton, Young Tableaux (tableaux / tabloids).

      A (general) μ-tableau is a bijective filling of the cells of μ by the labels Fin n (n = μ.card). We carry it as an equivalence Fin n ≃ μ.cells: t l is the cell holding label l. Unlike StandardYoungTableau (brick 1) these fillings are arbitrary bijections — no monotonicity is imposed.

                                6. The deep theorems — proved, one layer up #

                                This section used to declare specht_finrank_eq_numSYT and specht_isSimple as brick-2 targets carrying a bare sorry. Both are now proved, and the two stubs have been removed rather than left in place.

                                Statement Proved as Axioms
                                dim_k S^μ = #SYT(μ) SpechtStandardBasis.specht_finrank_eq_numSYT (and SpechtFinrankWired.specht_finrank_eq_numSYT_wired) propext, Classical.choice, Quot.sound
                                S^μ is simple (char 0) SpechtIrreducible.specht_isSimple propext, Classical.choice, Quot.sound

                                Why the proofs cannot live here #

                                Both run through machinery that imports this file: the standard polytabloid basis (SpechtStandardBasisCore → SpechtTriangularCore → SpechtStandardBasis) and the M^μ bilinear form with James's submodule theorem (SpechtIrreducible). Brick 2 cannot import its own consumers. The repo's convention for that situation is the …Wired pattern — see SpechtFinrankWired, which restates and proves the dimension identity.

                                Why they were deleted rather than left as documented stubs #

                                A sorry-backed duplicate of a proved theorem is not merely noise: it typechecks and is usable. Anything that wrote exact Specht.specht_isSimple … would have obtained a sorryAx-tainted proof of a statement that is in fact available cleanly one module up — a silent downgrade with no error anywhere. Nothing consumed either stub (checked), so removing them costs nothing and closes that hole.

                                One genuine generalization left open #

                                The deleted specht_finrank_eq_numSYT was stated over [Field k] with no CharZero, whereas the proved version carries [Field k] [CharZero k]. That extra hypothesis is inherited from standardBasis and is very likely removable — the standard polytabloids are a basis over any field — but that needs the CharZero uses inside standardBasis's inputs traced and discharged, which is a real task and not an annotation change. Tracked as a bean; do not re-add a sorry here to represent it.
