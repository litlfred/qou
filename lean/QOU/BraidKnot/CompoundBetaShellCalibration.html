      De-axiomatisation (bean lqft). E₀ = 𝔔_β is not a free assumption: the shell scale is defined to be the H² calibration input 𝔔_β (the manuscript's "shell sector introduces no new calibration"). ofCalibration builds the record from the three calibration values with E0 := H2, so E0_eq is rfl — the "no fourth calibration" property is structural, not posited. (The numerical value of 𝔔_β itself is fixed by the β-decay Q-value compute; that is a producer-side fact, orthogonal to this identity.)
