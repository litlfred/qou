    Keystone s013 — the q-Bessel radial-part target (machine-checked obligation) #

    The keystone residual-(i) reduced to the single open field bwS0 λ = d_q(λ)/D (KeystoneVerlindeSMatrixBridge.BWVacuumRowIsHecke). The value-map screen (computations/probes/keystone_valuemap_screen_s013.py, merged #3197) sharpened what the weight must return at the four n = 5 conjugation classes. This file makes both machine-checked:

    2.     3.             class QOU.BraidKnot.Keystone.QBesselRadialPartRealization {R : Type u_1} [Field R] (q a : R) (h : VerlindeModularData R) :
            Type (max u_1 u_2)

            Conjecture carrier (OPEN — the s013 / precheck step-(a) obligation): the q-Bessel radial-part realization of the keystone vacuum row. A realization supplies:

            • latticePt — the partition → q-Bessel-lattice assignment. This map is the open geometric construction (the owner-gated DG object, #2503); it is NOT established anywhere in the corpus, and this class does not assert it exists.
            • weight — the radial weight family, constrained to the corpus-formalized Jackson second-kind q-Bessel contiguity (the hypothesis of QOU.QBeta.qbessel_second_kind_coeff_closed_form). This constraint is the content: a solution family is a single coefficient orbit, so all vacuum-row values must lie on ONE q-Bessel orbit (realization_on_orbit) — falsifiable, not an arbitrary table.
            • latticePt_conj — transpose-equivariance, the W_λ = W_{λ′} hallmark the measure must respect (precheck P2).
            • realizes — the weight at each partition's lattice point IS the vacuum row S0.

            No instance is provided: the open state is the honest state (§3b-tax). The discriminating numerical test a candidate must pass is realization_discriminating_block below.

            • latticePt : VerlindeModularData.Part R → ℕ

              Partition → q-Bessel-lattice point (the open DG construction).

            • weight : ℕ → R

              The radial weight family (second-kind radial part).

            • weight_qbessel (k : ℕ) : weight q a h (k + 1) * ((1 - q ^ (k + 1)) * (1 - a * q ^ (k + 1))) = -(a * q ^ (2 * k + 1)) * weight q a h k

              weight solves the Jackson second-kind q-Bessel contiguity — the corpus-formalized constraint (QBesselContiguityRecurrence) making this carrier content-bearing.

            • latticePt_conj (p : VerlindeModularData.Part R) : p ∈ VerlindeModularData.parts → latticePt q a (VerlindeModularData.conj p) = latticePt q a p

              Transpose-equivariance: λ and λ′ share a lattice point (precheck P2).

            • realizes (p : VerlindeModularData.Part R) : p ∈ VerlindeModularData.parts → weight q a h (latticePt q a p) = VerlindeModularData.S0 p

              The realization: the radial weight at the partition point is the vacuum row.
