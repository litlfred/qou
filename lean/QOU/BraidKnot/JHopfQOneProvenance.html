    QOU.BraidKnot.JHopfQOneProvenance — the provenance of J_Hopf(q=1) = −2 #

    The c_3 near-match in the Q_β truncation ladder is recorded (AGENTS.md §"Critical framing — Q_β c_k") as c_3 = -2 = J_Hopf(q=1). This file rigorizes the provenance of that −2 — it does not close a derivation gap (the c_3 value is proved measurement-limited; see SRigidity.no_anchor_invariant_realizes_swing), it only pins where the number −2 comes from knot-theoretically, so the constant is not free-floating.

    The convention gap (stated honestly) #

    The framework's reduced Markov trace of the Hopf-link closure σ₁² (JonesNuclearQuotient.jonesHopfLink q = h·z + 1, h = q − q⁻¹, z = 1/(√q+1/√q)) evaluates at q = 1 to 1, not −2 — proved below as jonesHopfLink_one. So −2 is not the raw reduced trace.

    The −2 is the standard (V-normalized) Jones polynomial of the Hopf link at t = 1, via the classical evaluation V_L(1) = (−2)^{c−1} (Jones 1985; c = number of link components). Both facts are captured:

    1. loopValue q = −(√q + 1/√q) is the Jones loop factor δ — the base of the (δ)^{n−1} prefactor in Jones's normalization V_{β̂}(t) = (−(√t+1/√t))^{n−1}(√t)^e · \barπ_t(β). At q = 1, δ = −2 (loopValue_one). The −2 lives entirely in this loop factor; the trace part \barπ_1(σ₁²) = 1 contributes nothing.

    2. classicalJonesAtOne c = δ(1)^{c−1} = (−2)^{c−1} is the classical value at t = 1 for a c-component link (classicalJonesAtOne_eq). The 2-component Hopf link gives (−2)^{2−1} = −2 (jonesHopf_atOne); the 1-component unknot gives (−2)^0 = 1 (unknot_atOne); a 1-component knot (trefoil) also gives 1.

    3. jonesHopfStd q = −√q − (√q)^5 is the tabulated standard normalized Jones polynomial of the (negative) Hopf link V(t) = −t^{1/2} − t^{5/2} (Jones 1987, standard link tables). Independently, jonesHopfStd 1 = −2 (jonesHopfStd_one), cross-checking the (−2)^{c−1} route.

    Numerical witness cross-reference #

    The corpus probe computations/qbeta/qbeta_c3_jhopf_q0_vs_q1_comparison.py (witness computations/qbeta/qbeta-c3-jhopf-q0-vs-q1-comparison.witness.json) records the same −2 from a third convention J_Hopf(q) = −(q² + q⁻²), also = −2 at q = 1, and confirms it is q_0-independent ("Rule A: c_3 = J_Hopf(q=1) = −2, passes the Taylor-coefficient stability test"; the q_0-evaluation J_Hopf(q_0) ≈ −2.044 is the near-match swing). That three distinct Jones normalizations — the loop factor δ^{c−1}, the tabulated V(t), and −(q²+q⁻²) — all agree at q = 1 is the convention-robustness of the −2 at the classical point: it is the loop/component-count invariant V_L(1) = (−2)^{c−1}, not an artifact of one normalization.

    Base ring (§7c): archimedean (Real.sqrt, Jones-variable evaluation), so ℝ.
