    QOU.BraidKnot.EigenbasisStructuralLemmas — content/twist eigenbasis lemmas #

    Lean formalization of the structural lemmas of the content/twist eigenbasis, verified exact-symbolic in computations/probes/eigenbasis_structural_lemmas_probe.py (PR #2502) and flagged there for Lean follow-up (lean_followup).

    The eigenbasis is organized by the ribbon-twist eigenvalue θ_λ = q^{2c(λ)}: the full twist Δ² ∈ Z(H_n(q)) acts on the Wedderburn channel V_λ by the scalar θ_λ, formalized as the class [QOU.BraidKnot.ChiralityWritheRibbon.RibbonTwistEigenvalue]. This file proves the lemmas sorry-free over ℝ importing only Mathlib; the connection of the abstract framing ratio θ to the categorical q^{2κ_λ} is framing_eigenvalue_pow below.

    Lemmas #

    • L3 — framing generating function (this file): the framing tower Σ_m t^m χ_λ(β·Δ^{2m}) is the single-pole rational χ_λ(β)/(1 − t·θ_λ).

    L3 — framing generating function #

    source
    theorem QOU.BraidKnot.EigenbasisStructuralLemmas.framing_eigenvalue_pow (q : ℝ) (κ : ℤ) (m : ℕ) :
    q ^ (2 * ↑m * κ) = (q ^ (2 * κ)) ^ m

    Ribbon power law. The eigenvalue of the m-fold full twist Δ^{2m} on the channel V_λ is the m-th power of the single-twist eigenvalue θ_λ = q^{2κ_λ}:

    q^{2mκ} = (q^{2κ})^m.

    This is the algebraic content linking the m-fold framing to the ribbon eigenvalue; it holds for every real base (the zpow identity is valid in a GroupWithZero).

    source
    theorem QOU.BraidKnot.EigenbasisStructuralLemmas.framing_gf_closed_form (θ t : ℝ) (c : ℕ → ℝ) (hstep : ∀ (m : ℕ), c (m + 1) = θ * c m) (N : ℕ) :
    (1 - t * θ) * ∑ m ∈ Finset.range N, t ^ m * c m = c 0 * (1 - (t * θ) ^ N)

    L3 — framing generating function (finite closed form).

    Let c m = χ_λ(β · Δ^{2m}) be the Hecke character of the braid β framed by m full twists, in Wedderburn channel λ. Centrality of the full twist Δ² ∈ Z(H_n(q)) together with the ribbon eigenvalue Δ²|_{V_λ} = θ (θ = q^{2c(λ)}, framing_eigenvalue_pow) gives the one-step scaling c (m+1) = θ · c m. Then the framing generating function is the single-pole rational c 0 / (1 − t·θ): the partial sums satisfy the finite geometric closed form

    (1 − t·θ) · Σ_{m<N} t^m · c m = c 0 · (1 − (t·θ)^N),

    so the only pole is at t = θ⁻¹ = q^{−2c(λ)}. The result is not vacuous: it pins the framing tower as geometric with ratio t·θ and leading coefficient c 0, which is the substance of the eigenbasis reframing (the framing tower separates orders by content).

    theorem QOU.BraidKnot.EigenbasisStructuralLemmas.framing_gf_ribbon (q t χ₀ : ℝ) (κ : ℤ) (N : ℕ) :
    (1 - t * q ^ (2 * κ)) * ∑ m ∈ Finset.range N, t ^ m * (q ^ (2 * ↑m * κ) * χ₀) = χ₀ * (1 - (t * q ^ (2 * κ)) ^ N)

    L3 discharged at the concrete ribbon eigenvalue θ_λ = q^{2κ}.

    Instantiating framing_gf_closed_form at the framed character c m = q^{2mκ}·χ₀ — the action of the m-fold full twist Δ^{2m} on V_λ through the ribbon eigenvalue θ_λ = q^{2κ} (QOU.BraidKnot.ChiralityWritheRibbon.RibbonTwistEigenvalue.framing_formula, here via framing_eigenvalue_pow). The hypothesis hstep is discharged (not assumed): the one-step scaling q^{2(m+1)κ} = q^{2κ}·q^{2mκ} is proved. The framing tower is then the single-pole rational with pole at t = q^{−2κ}:

    (1 − t·q^{2κ}) · Σ_{m<N} t^m · q^{2mκ} · χ₀ = χ₀ · (1 − (t·q^{2κ})^N).

    L1 — order-parity = word-length parity #

    source
    theorem QOU.BraidKnot.EigenbasisStructuralLemmas.character_qneg_parity {L : ℕ} {ι : Type u_1} (paths : Finset ι) (a : ι → Fin L → ℝ → ℝ) (q : ℝ) (hodd : ∀ (p : ι) (i : Fin L), a p i (-q) = -a p i q) :
    ∑ p ∈ paths, ∏ i : Fin L, a p i (-q) = (-1) ^ L * ∑ p ∈ paths, ∏ i : Fin L, a p i q

    L1 — order-parity = word-length parity.

    Model the Hecke character of a length-L braid word β in channel λ as a sum over the index paths of the seminormal matrix product, χ_λ(β)(q) = Σ_p Π_{i<L} a(p,i)(q), where each factor a(p,i) is an entry of one crossing matrix σ_j (or σ_j − h·I). Each such factor is an odd Laurent polynomial: its q ↦ −q image is its negation (the seminormal eigenvalues q, −q⁻¹ and the off-diagonal entries all have odd Laurent degree, since q ↦ −q sends q^k ↦ (−1)^k q^k). Then

    χ_λ(β)(−q) = (−1)^L · χ_λ(β)(q),

    equivalently every exponent of the Laurent character has parity ≡ L (mod 2). This makes the PR #2496 parity obstruction a theorem: a same-type-nucleon / winding tower flips parity because the nucleon word has odd length L = 11, so 11·k alternates parity in k.

    L1 — literal Laurent-support form #

    source
    def QOU.BraidKnot.EigenbasisStructuralLemmas.ParityHom (ε : ZMod 2) (p : AddMonoidAlgebra ℝ ℤ) :
    Prop

    A Laurent polynomial p ∈ ℝ[ℤ] = LaurentPolynomial ℝ is ε-parity- homogeneous when every exponent in its support has parity ε (the zero polynomial vacuously, for every ε). This is the literal "all exponents ≡ ε (mod 2)" content behind the q ↦ −q symmetry of character_qneg_parity.

      L2 — bar-involution ↔ conjugation duality #

      source
      theorem QOU.BraidKnot.EigenbasisStructuralLemmas.character_bar_conjugate {L : ℕ} {ι : Type u_1} {ι' : Type u_2} [Fintype ι] [Fintype ι'] (a : ι → Fin L → ℝ → ℝ) (a' : ι' → Fin L → ℝ → ℝ) (q s : ℝ) (φ : ι ≃ ι') (hfac : ∀ (p : ι) (i : Fin L), a p i q⁻¹ = s * a' (φ p) i q) :
      ∑ p : ι, ∏ i : Fin L, a p i q⁻¹ = s ^ L * ∑ p' : ι', ∏ i : Fin L, a' p' i q

      L2 — bar-involution ↔ conjugation duality (conditional on the seminormal bar–conjugate relation).

      The Hecke bar involution q ↦ q⁻¹ swaps the seminormal eigenvalues q ↔ −q⁻¹, which is exactly the intertwiner V_λ ≅ V_{λ'} to the conjugate Wedderburn channel λ' (transpose partition; dim V_λ = dim V_{λ'}, so the path index sets are in bijection φ). At the level of matrix entries this is a uniform sign s ∈ {±1} and a path bijection φ with

      a_λ(p,i)(q⁻¹) = s · a_{λ'}(φ p, i)(q) (the seminormal bar–conjugate input).

      From this factor-level categorical input the character-level duality follows by reindexing along φ and extracting the L signs:

      χ_λ(β)(q⁻¹) = s^L · χ_{λ'}(β)(q).

      This is the §3b-cond conditional-class shape: the bar–conjugate relation is the explicit hypothesis; the duality is derived, not assumed.
