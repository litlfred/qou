    QOU.BraidKnot.TritiumWitness — placeholder R5-full witness for ³H #

    PR #608's R5-full search does not yet support tritium because the Hoefsmit seminormal at H_5 is currently implemented only in Rust (tools/hecke-engine) — the Python pipeline that emits r5-full-canonical-knot-solver.witness.json doesn't run for tritium.

    This module records a PLACEHOLDER witness so the R5FullWitness LightNucleus.tritium typeclass resolves; concrete numerical values come from the Python H_5 Hoefsmit port (PR #608 deferred-Hoefsmit-H5).

    What this module provides #

    • instR5FullWitness_tritium_placeholder — placeholder witness marking the H_5 Hoefsmit dependency.

    Categorical significance #

    The instance lets downstream theorems compile under [R5FullWitness LightNucleus.tritium], but the values are provisional pending the Python port of the H_5 Hoefsmit seminormal representation.

    • tools/hecke-engine (Rust H_5 implementation)
    • computations/hecke/hecke_characters.py (Python H_3 / H_4 implementation; H_5 awaits port)
