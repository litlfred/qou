    QOU.BraidKnot.GramSeminormalBlock — per-block Hoefsmit-seminormal data #

    Option E Phase 1 deliverable (declaration stub). Provides the Lean-side signature for per-Wedderburn-block representation data of the Iwahori–Hecke algebra H_n(q), used by Option E's Δ_λ closure program.

    The Wedderburn isomorphism reduction #

    The full NF-basis Gram matrix on H_n(q) has size n! × n! (720 × 720 for H_6, 362880 × 362880 for H_9). Direct computation is intractable beyond H_3. The Wedderburn isomorphism

    H_n(q) ≅ ⊕_{λ ⊢ n} End(V_λ)

    reduces this to per-block data of size dim_λ × dim_λ per partition. Total entries across all blocks is Σ_λ dim_λ² = n! — the same data, exponentially smaller per-block view.

    For each λ ⊢ n, this module records:

    • dimLambda λ — the number of standard Young tableaux of shape λ (= the dimension of the irrep V_λ)
    • the Hoefsmit-seminormal representation rhoLambdaSigmaK λ k : Matrix (Fin (dimLambda λ)) (Fin (dimLambda λ)) R for k = 1, ..., n-1 (i.e., σ_k ∈ B_n acting on V_λ)
    • the longest-word matrix rhoLambdaW0 λ
    • the character value chiLambdaW0 λ := tr (rhoLambdaW0 λ)

    Per AGENTS.md §7c (Base ring convention) the structure is purely algebraic — no Real.sqrt / Real.rpow / order predicates — and is parameterised over a generic commutative ring R. Numerical specialisations live in archimedean-evaluation modules.

    The numerical instances at the substrate q_0 ∈ ℝ come from the Python witness option-e-phase1-gram-h6.witness.json (cross-checked at H_3 against the published NF-basis 6×6 Gram in option-e-phase1-h3-cross-check.witness.json: max residual 2.22e-16 over 21 unique NF Gram entries).

    Wedderburn-sum identity (the key cross-check) #

    For Hecke elements b, c ∈ H_n(q),

    tr_M(b · c) = Σ_{λ ⊢ n} y_λ · tr (ρ_λ b · ρ_λ c)

    where y_λ are the Jones–Markov weights. The Python witness verifies this for the H_3 NF basis: max residual 2.22e-16 across 21 unique pairs (b_i, b_j). The Lean side records the structural class of per-block representation data; numerical witnesses are pulled from the Python sidecar.

    Phase 1 scope (this file) #

    This file is a declaration stub (AGENTS.md §3b conditional class pattern): the class encapsulates the per-block data as a hypothesis, with the Python witness as the canonical instance. Full Lean proof of the Wedderburn reassembly is deferred to a Mathlib-bridging follow-up.

    Phase 2 use (downstream) #

    Option E Phase 2 (canonical-basis trace ρ_w(K) at crystal vertices) consumes rhoLambdaSigmaK λ k and rhoLambdaW0 λ to compute the canonical-basis trace per crystal vertex w. The crystal-weight formula

    Δ_λ(K) = Σ_w n^w_λ · ρ_w(K)

    then folds the per-block data with Kazhdan–Lusztig multiplicities n^w_λ to produce per-partition Δ_λ values for the binding-energy formula B(K) = m_e · Σ_λ y_λ · χ^λ(β_K) · (1 + Δ_λ(K)).

      structure QOU.BraidKnot.GramSeminormalBlock.SeminormalBlockData (R : Type u_1) [CommRing R] (n : ℕ) (lam : Partition n) (q : R) :
      Type u_1

      Per-block Hoefsmit-seminormal representation data for a partition λ ⊢ n of the Iwahori–Hecke algebra H_n(q), parameterised over a generic commutative ring R (AGENTS.md §7c).

      The fields encode the dimension dim_λ and the per-generator and longest-word matrices in the Hoefsmit-seminormal basis indexed by standard Young tableaux of shape λ.

      The Python witness option-e-phase1-gram-h6.witness.json carries the numerical instances at substrate q_0 ∈ ℝ for all 11 partitions λ ⊢ 6. A Mathlib-bridging follow-up will provide the symbolic construction at general q over a generic R.

      • dimLambda : ℕ

        Number of standard Young tableaux of shape λ.

      • rhoLambdaSigmaK : Fin (n - 1) → Matrix (Fin self.dimLambda) (Fin self.dimLambda) R

        ρ_λ(σ_k) for k = 1, …, n−1 (length n − 1).

      • rhoLambdaW0 : Matrix (Fin self.dimLambda) (Fin self.dimLambda) R

        ρ_λ(w_0) for the longest element w_0 ∈ S_n.

      • chiLambdaW0 : R

        The character value χ_λ(w_0) = tr(ρ_λ(w_0)).
