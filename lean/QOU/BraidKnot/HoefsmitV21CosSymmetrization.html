    QOU.BraidKnot.hoefsmit_V21_cos_symmetrization #

    Hoefsmit seminormal matrices for the 2-dimensional irrep V_(2,1) of H_3(q) + the Markov-symmetrized cos-resummation theorem.

    Per prop:hoefsmit-V21-cos-symmetrization:

    ρ_{(2,1)}(σ_0) = ⟨q, -q⁻¹⟩ (diagonal) ρ_{(2,1)}(σ_1) = ⟨d_1, d_2; b, b⟩ (off-diagonal coupling)

    with d_1 = q^3 / (q^2 + 1), d_2 = -q⁻¹ / (q^2 + 1), b^2 = d_1 d_2 + 1 (Hecke quadratic constraint on σ_1).

    The Markov-symmetrized character for a typed braid β ∈ B_n on V_(2,1) is Tr(ρ_(2,1)(β)) · cos((z-1) h / 2) at single-wrap order, where the cos factor comes from prop:q-beta-cos-resummation.

    LaTeX label: prop:hoefsmit-V21-cos-symmetrization

                  Hecke quadratic identity on σ_0 #

                  ρ_(2,1)(σ_0)^2 = (q - q⁻¹) · ρ_(2,1)(σ_0) + 1, since the diagonal entries are q and -q⁻¹, both eigenvalues of the Hecke quadratic.

                  source
                  theorem QOU.BraidKnot.hoefsmit_sigma0_hecke_quadratic (q : ℝ) (hq : q ≠ 0) :
                  hoefsmit_sigma0 q * hoefsmit_sigma0 q = (q - q⁻¹) • hoefsmit_sigma0 q + 1

                  σ_0's diagonal action squares to the Hecke quadratic identity at the matrix level: M^2 = (q - q⁻¹) M + I.

                  Hecke quadratic identity on σ_1 (off-diagonal Hoefsmit matrix) #

                  By Cayley-Hamilton on a 2×2 matrix M = !![a, b; c, d], M² = (a + d) · M + (b·c − a·d) · I = tr(M) · M − det(M) · I.

                  For σ_1 = !![d_1, b; b, d_2] with b² = d_1·d_2 + 1:

                  • tr(σ_1) = d_1 + d_2 = q − q⁻¹ (Hecke quadratic root sum)
                  • det(σ_1) = d_1·d_2 − b² = −1 (Hecke quadratic root product)
                  • hence σ_1² = (q − q⁻¹) · σ_1 + I (matrix Hecke quadratic)

                            class QOU.BraidKnot.V21Eigenphase (q : ℝ) :
                            Prop

                            Hoefsmit V_(2,1) eigenphase axiomatisation: the transfer-matrix spectrum on V_(2,1) is {e^{+i·eigenphase q}, e^{-i·eigenphase q}}.

                            Established at the combinatorial level in prop:beta-decay-transfer-matrix; we record it here as a class field since the underlying eigenvalue computation lives in the existing Python infrastructure (computations/hecke_characters.build_seminormal_matrices) and is not yet machine-proved.

                            • symmetrized_character_bounded : |2 * Real.cos (eigenphase q)| ≤ 2

                              The Markov-traced V_(2,1) character on a typed braid at single wrap equals 2 · cos(eigenphase q). Concrete consequence: the symmetrized character has magnitude bounded by 2.

                            • cos_bar_invariant : Real.cos (eigenphase q) = Real.cos (-eigenphase q)

                              Cos of the eigenphase is bar-invariant (q ↔ q⁻¹). This is the bar-symmetry constraint on the Markov-trace symmetrization, forced by the cyclic property τ(σ_i x) = τ(x σ_i).

                                Eigenphase forcing — the provable core of θ = arccos(χ^(2,1)/2) #

                                The Borromean braid 𝓑₃ has even writhe, so its V_(2,1) image is det = +1 — a genuine SU(2)-type rotation, unlike the single generator σ_1 (det = -1, hoefsmit_sigma1_det_eq). For any such real 2×2 rotation with |trace| ≤ 2 the eigenphase is forced: trace = 2 cos θ at θ = arccos(trace/2). This is the provable content behind the spectral phase θ = arccos(χ^(2,1)(𝓑₃)/2).

                                Not proved here (and provably non-generalising). Why the factor θ/(8ℏ_q²) is the correct mass correction is a top-down ansatz: the /8 is the Borromean octahedral count Vol(𝓑₃) = 8·G, but the second /ℏ_q² is unexplained, and it does not extend to binding — atoms A ≥ 2 live in the (3A−1, 1) irrep (dim 3A−1 > 2), whose H_{3A} eigenvalues are real reciprocal pairs (hyperbolic), with no single rotation angle (see docs/audits/2026-05-28-spectral-phase-correction-derived.md). The spectral mass correction therefore stays EXPLORATORY; this lemma records only its proved kinematic core, replacing a prior vacuous True := by trivial audit stub.

                                theorem QOU.BraidKnot.eigenphase_forced (t : ℝ) (ht : |t| ≤ 2) :
                                2 * Real.cos (Real.arccos (t / 2)) = t

                                Eigenphase forcing. A real 2×2 rotation (det = 1, |trace| ≤ 2) has its trace pinned to 2 cos θ at the forced angle θ = arccos(trace/2): concretely 2 · cos(arccos(t/2)) = t for |t| ≤ 2. The provable kinematic core of the Borromean spectral phase θ = arccos(χ^(2,1)(𝓑₃)/2).
