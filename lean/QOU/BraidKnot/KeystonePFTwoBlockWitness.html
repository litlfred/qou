    A concrete non-Unit Perron–Frobenius witness (2-block model) #

    Strengthens the Unit-block non-vacuity witness of KeystonePerronFrobeniusGroundState.lean to a genuine 2-block model with a non-constant quantum-dimension vector and Frobenius eigenvalue ≠ 1: N = [[1,1],[2,2]], rho = 3, d = (1,2). N is non-negative; d is a positive eigenvector at 3; and the eigen equation alone forces any eigenvector at 3 to have v 1 = 2 · v 0, hence to be v 0 • d — so pf_proportional holds. This shows the §3b-cond class admits non-trivial instances (not only the constant Unit block).

    Still a toy. A non-negative-matrix witness, not the physical Hecke fusion category; the instance whose N is the actual fusion operator and d the Hecke d_q remains the owner-gated open content (narrow Subgoal-2 reversal, #2503/#2524).
