    QOU.BraidKnot.BoxContent — box content, and what it is NOT #

    Former carrier for prop:content-scaling-correspondence (mass-theory/content-scaling-correspondence.md), and the record of why that block was re-worded.

    Until 2026-09-04 the block's mathematical sentence read: "by q-Schur–Weyl duality V^{⊗n} ≅ ⊕_λ V_λ ⊗ S_λ, the content c = j − i of a box at position (i,j) equals the magnetic quantum number m_j of the corresponding SU_q(2) weight space", and this file held only the definition boxContent, so the block's lean.ref resolved while the proposition itself had no Lean (bean qou-59x9, audit docs/audits/2026-09-04-lean-ref-resolution-count-mass-theory.md). The theorems below refute that sentence; on the owner's go (bean qou-kpx7) the block now states the true fact — content is the q-Jucys–Murphy eigenvalue exponent, QOU.SchurWeyl.SeminormalRep.seminormalRep_qJM — and its lean.ref names that theorem. The scaling table moved to rem:content-scaling-dictionary.

    Formalised here: the sentence is false in its literal reading, and the obstruction is structural, not numerical. For SU(2) the shapes are two-row, λ = (a, b) with b ≤ a, and V_λ has spin j = (a − b)/2, so its weights are m with 2m ∈ {−(a−b), −(a−b)+2, …, a−b} — a − b + 1 of them — while λ has a + b cells.

    • twoRow_card_cells_ne_card_weights — a + b ≠ a − b + 1 for every a b : ℕ (it would need 2b = 1). So no bijection "box ↔ weight space" exists for any shape at all; "the corresponding weight space" names nothing.
    • top_content_not_weight — for 3 ≤ a + b the cell (0, a−1) has content a − 1, and 2(a−1) > a − b, so that content is not a weight of V_λ under any assignment of boxes to weight spaces.
    • single_box_content_not_weight, column_content_not_weight — the two shapes with n ≤ 2 other than (2,0) fail as well ((1,0) by parity, (1,1) by range). row_two_contents_are_weights — (2,0) is the one shape where every content is a weight, and it is the only one.

    What is true, and is corpus infrastructure already: box contents are the (q-)Jucys–Murphy eigenvalues (QOU.SchurWeyl.QJucysMurphyEigen), i.e. they track the total-spin increments of the sub-tower V^{⊗k}, k ≤ n — a Casimir datum, not a weight. The consumer crystal-isospin-degeneracy-proof uses only c(·) as a cell statistic and content differences (axialDistance), which this refutation does not touch.

    boxContent is kept (it is what the manifest names) and bridged by rfl to the canonical QOU.MathlibExt.YoungDiagramCells.content, so nothing proved against the one copy is unreachable from the other (bean qou-cdup).

    Base ring: everything is over ℕ/ℤ; no archimedean construct (§7c).

                theorem QOU.BraidKnot.twoRow_card_cells_ne_card_weights (a b : ℕ) :
                ↑a + ↑b ≠ twoRowTwiceSpin a b + 1

                Number of cells of (a, b) versus number of weights of V_{(a,b)}: a + b ≠ (a − b) + 1, always. There is no bijection "box ↔ weight space" for any two-row shape, so "the corresponding weight space" of a box is not defined.

                source
                theorem QOU.BraidKnot.top_content_not_weight {a b : ℕ} (hab : b ≤ a) (h3 : 3 ≤ a + b) :
                ¬IsTwoRowWeight a b (2 * boxContent { row := 0, col := a - 1 })

                The rightmost cell of the first row, (0, a−1), has content a − 1; for 3 ≤ a + b twice that exceeds 2j = a − b, so it is not a weight of V_{(a,b)} — under any assignment of boxes to weight spaces.

                source
                theorem QOU.BraidKnot.single_box_content_not_weight :
                ¬IsTwoRowWeight 1 0 (2 * boxContent { row := 0, col := 0 })

                λ = (1): the single box has content 0, but V_{(1)} has spin 1/2 and its weights are ±1/2; 0 fails by parity.

                source
                theorem QOU.BraidKnot.column_content_not_weight :
                ¬IsTwoRowWeight 1 1 (2 * boxContent { row := 1, col := 0 })

                λ = (1,1): the lower box has content −1, but V_{(1,1)} is the trivial representation with the single weight 0.

                theorem QOU.BraidKnot.row_two_contents_are_weights :
