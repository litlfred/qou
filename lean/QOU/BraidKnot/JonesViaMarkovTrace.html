    QOU.BraidKnot.JonesViaMarkovTrace — Jones value of the Hopf link via the Markov trace #

    Tier-3 (bean 60iz, epic 08a2) first real layer of the Jones-polynomial / knot-invariant infrastructure behind jet_filtered_knot_factor.jonesQuotient. Per the framework convention (AGENTS.md §7a, thm:jones-markov-trace; Jones 1987, Wenzl 1988) the Jones polynomial is the Markov trace of a braid's Hecke image, J_L(q) = tr_M(ρ(β_L)).

    This builds on the real q-deformed Markov-trace abstraction QOU.Braiding.MarkovTraceTower — complementary to #2743's q = 1 k[S_n] Wedderburn build (this is the H_n(q) Markov trace, that is the symmetric-group algebra). The σ_1²-closure is the Hopf link (QOU.BraidKnot.BraidLinkTypes.closure2 σ_sq = Link.hopfLink), so the Markov trace trM_sigma1_sq is the Jones value of the Hopf link.

    The load-bearing content is jonesHopf_invariant: the Jones value is a link invariant because the Markov trace is stabilisation-invariant (strand-count-independent) — the proved reason the Markov trace descends to a knot/link invariant. Sorry-free.

      Braiding.MarkovTraceTower.trM_sigma1_sq q n = jonesHopf q

      The Jones value is a link invariant. The Markov trace of σ_1² computed in any H_n(q) with n ≥ 2 agrees with the base H_2 value jonesHopf, by Markov stabilisation (σ_1² uses only the first generator, so extra strands contribute z · z⁻¹ = 1). This is exactly the property that makes the Markov trace descend to a knot/link invariant (Jones 1987). Sorry-free.

      theorem QOU.BraidKnot.jonesHopf_pos (q : ℝ) (hq : 1 < q) :
      0 < jonesHopf q

      The Hopf-link Jones value is positive in the Wenzl regime (q > 1): under convention D the closed form is (q⁴ + 1)/(q² + 1), a ratio of manifestly positive reals, so positivity closes it outright.

      The convention-C proof needed q^{5/2} ≥ q^{1/2} via Real.rpow_le_rpow_of_exponent_le and then nlinarith, because the numerator was a difference of half-powers whose sign had to be argued. Convention D has no subtraction and no square roots. Sorry-free.
