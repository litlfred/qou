    d(t): the permutation carrying the reference tableau to t #

    Murphy's basis is m_{st} = T_{d(s)}^* · x_λ · T_{d(t)}, so every statement in that construction is indexed by a permutation attached to a tableau, and QOU.BraidKnot has had no such map. This file supplies it.

    Specht.Tableau μ is Fin n ≃ μ.cells with σ • t = t ∘ σ⁻¹, and the action is simply transitive: fixing the row-superstandard tableau t^μ as origin, every tableau is d • t^μ for exactly one d. That d is dOf t.

    Why this is the piece that was missing #

    Mathas' Lemma 3.13 — the one ingredient of the Murphy spanning argument with no q = 1 antecedent in the corpus — reads: for a row-standard non-standard t there are a Garnir tableau g and w with t = g · w and

    ℓ(d(t)) = ℓ(d(g)) + ℓ(w).

    dOf_smul below turns the tableau factorisation t = w • g into the permutation factorisation d(t) = w * d(g), which is exactly the input QOU.Hecke.Inversions.length_mul_eq_add_iff consumes. Composing the two (length_dOf_smul_eq_add_iff) reduces Mathas' length condition to a concrete, decidable combinatorial claim:

    no inversion of d(g) is undone by w.

    What is still absent, and is not attempted here: the Garnir tableau g_{ij} itself and the descent-node ordering. This file is the bridge, not the lemma — it makes the length half of 3.13 statable, and says nothing about which g realises it. Measured support for the target it feeds: computations/hecke/murphy_garnir_length_additivity_probe.py finds the first descent node sufficient in 1789/1789 row-standard non-standard tableaux for n = 3,4,5,6.

            Mathas' length condition, reduced to inversion containment #

            source
            theorem QOU.BraidKnot.TableauPerm.length_dOf_smul_eq_add_iff {μ : YoungDiagram} {n : ℕ} (hn : Specht.nOf μ = n + 1) (w : Equiv.Perm (Fin (Specht.nOf μ))) (g : Specht.Tableau μ) :
            (Hecke.SymmetricCoxeter.permCoxeterSystem n).length ((toFinSucc hn) (dOf (w • g))) = (Hecke.SymmetricCoxeter.permCoxeterSystem n).length ((toFinSucc hn) w) + (Hecke.SymmetricCoxeter.permCoxeterSystem n).length ((toFinSucc hn) (dOf g)) ↔ Hecke.Inversions.invSet ((toFinSucc hn) (dOf g)) ⊆ Hecke.Inversions.invSet ((toFinSucc hn) (dOf (w • g)))

            The length half of Mathas 3.13, as a combinatorial criterion.

            For a tableau factorisation t = w • g, the length is additive — ℓ(d(t)) = ℓ(w) + ℓ(d(g)) — exactly when w undoes none of d(g)'s inversions.

            The right-hand side is decidable and mentions no lengths and no reduced words, which is what makes it checkable for a proposed Garnir tableau.
