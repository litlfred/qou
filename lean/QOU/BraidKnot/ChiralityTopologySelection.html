    Chirality selects the binding topology (formalization of PR #2507) #

    PR #2507 (computations/probes/chirality_topology_binding_probe.py, audit docs/audits/2026-06-20-chirality-forces-complete-graph-topology.md) established empirically that the Pauli (alternating Hecke) channel — which makes identical-nucleon pairs (p-p, n-n) unbound and leaves only the proton–neutron pair bound via the std Jones–Markov channel — is incompatible with the production linear-chain topology and instead selects the complete graph restricted to p-n pairs.

    This file isolates the rigorous combinatorial core of that finding, with no archimedean input (pure ℕ bond counting; see AGENTS.md §7c — base ring stays generic, here ℕ, no ℝ):

    • On the chain topology the surviving p-n bond count is a single interface bond, independent of the mass number A = Z + N (chain_binding_A_independent).
    • On the complete graph the p-n bond count is Z · N, strictly increasing in each of Z, N (complete_pn_strictMono_N), hence genuinely A-dependent.
    • Therefore any A-dependent Pauli-restricted binding cannot be realized on the chain — it forces the complete graph (A_dependence_forces_complete).

    These are the two structural results of the #2507 audit, stated as theorems. The numerical accuracy comparison (RMS 6.19 MeV) lives in the probe witness; this file proves only the topology-selection logic, which is parameter-free.

        theorem QOU.BraidKnot.ChiralityTopologySelection.A_dependence_forces_complete {Z N Z' N' : ℕ} (h : 0 < Z ∧ 0 < N) (h' : 0 < Z' ∧ 0 < N') (hdiff : chainPnBonds Z N ≠ chainPnBonds Z' N') :
        False

        Topology selection (the #2507 thesis). A Pauli-restricted binding whose p-n bond count differs between two (Z,N)-nuclei (i.e. is genuinely A-dependent) cannot be realized on the chain topology: the chain forces equality. Contrapositive of chain_binding_A_independent; the only remaining parameter-free topology that supports the differing count is the complete graph (complete_pn_strictMono_N).
