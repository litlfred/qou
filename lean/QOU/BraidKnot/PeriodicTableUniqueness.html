    QOU.BraidKnot.PeriodicTableUniqueness — full periodic table coverage #

    Element-level wrappers for NucleusEmptySDPUniqueness covering all 118 elements of the periodic table (H through Og), using the AME2020 reference isotope per element as listed in AtomicMass.lean. Each wrapper specialises the parameterised nucleus_uniqueness_closed at n = 3A where A is the element's mass number per AME2020.

    Coverage matrix #

    For every element with (Z, N, A) per AtomicMass.lean:

    • <element>_emptySDP : SDPPrimal (heckeDim (3*A)) ℝ Empty
    • <element>_uniqueness_closed — sorry-free, axiom-free

    What this generalises #

    The existing per-isotope files (AppliedHelium3Uniqueness.lean, AppliedDeuteronUniqueness.lean, etc.) cover QOU-tracked specific isotopes (²H, ³H, ³He, ⁴He, ⁶Li, ⁹Be, ¹¹B, ¹²C, ¹⁴N, ¹⁶O). This file extends coverage to the full periodic table at the AME2020-reference-isotope level. Together they cover both:

    • QOU's R5-full-solver-tracked specific isotopes (per-isotope files)
    • Every chemical element's reference isotope (this file)

    Naming convention #

    <element_lowercase>_<theorem_name> where element_lowercase is the short lowercase symbol used in AtomicMass.lean. For H/He this collides with the per-isotope notation (e.g. helium3_emptySDP vs he_emptySDP); they refer to different isotopes (³He vs ⁴He) and the per-isotope versions take precedence in disambiguation.

    What this does NOT cover #

    Same caveat as NucleusEmptySDPUniqueness: this is the abstract-framework demonstration at the empty-SDP level. The real per-element / per-isotope SDP (with multi-term cost from the mass formula and non-empty constraints) is element-specific substantive open work.

    References #

    • QOU.BraidKnot.NucleusEmptySDPUniqueness (parameterised proof)
    • QOU.AtomicMass (element data source — AME2020)
