    Confined Particle #

    A confined particle is a tuple (name, level, Markov class, coarse strand count). Named via a registry; Markov class represented canonically by Gröbner–Shirshov normal form. Confinement at q is a separate SDP-feasibility predicate tied to QOU.Interactions.ConfinementSDP.

    structure QOU.BraidKnot.MarkovClass :
    Type

    Markov class. Equivalence class of closed braids under Markov moves, represented canonically by its Gröbner–Shirshov normal form as a BraidWord n.

    Two closed braids that are Markov-equivalent share the same canonical representative. The strandCount field is the n of the underlying BraidWord n.

    • strandCount : ℕ

      Number of strands of the canonical representative.

    • gsNormalForm : Archimedean.BraidWord self.strandCount

      The canonical GS-NF representative as a Hecke braid word.

      structure QOU.BraidKnot.ConfinedParticle :
      Type

      Confined particle. A named tuple at a confinement level with an underlying Markov class of closed braid. Stability predicates layer on top; confinement at q ∈ R_q is the SDP-feasibility predicate.

      Note: the coarse strand count is derived from the Markov class rather than stored separately, so well-formedness (coarseStrands = markovClass.strandCount) holds by definition.

      • name : String

        Symbol from the particle-shortcut registry (e.g. "proton", "\\He4", "electron").

      • level : ℕ

        Confinement level ℓ (quark = 0, nucleon = 1, atom = 2, compound = 3).

      • markovClass : MarkovClass

        Canonical Markov class of the underlying closed braid.
