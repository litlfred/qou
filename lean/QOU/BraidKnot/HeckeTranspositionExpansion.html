    The sum-of-transpositions expansion — the missing ingredient, and it needs no new axioms #

    HeckeAdditiveJucysMurphy established that the product half of Mathas 3.24(iii) does not follow from the JM recursion in either convention, and that the classical proofs reach it through the explicit expansion of L_k as a sum of transpositions. The probe jm_partial_sum_centrality_probe.py then found that Jucys's centrality argument avoids the product half entirely, but still needs that same expansion.

    So the expansion is the one missing ingredient. This file supplies it.

    No new axioms #

    It would be tempting to add transposition elements to HeckeGenerators as new fields with defining relations — and that would be an axiomatisation, exactly what the anti-laundering rule targets. It is unnecessary: in a braid presentation the transposition element is a conjugate of a generator,

    T_(i,k)  =  σ_{k−1} ⋯ σ_{i+1} · σ_i · σ_{i+1} ⋯ σ_{k−1}

    which recursively is T_(i,k+1) = σ_k T_(i,k) σ_k with T_(k,k+1) = σ_k. That is a definition built from the existing generators, so nothing is assumed.

    The expansion #

    addJM_eq_transp_sum : A_k = d · Σ_{i<k} T_(i,k).

    With this corpus's recursion A_{k+1} = σ_k A_k σ_k + d·σ_k the coefficients come out uniform — every transposition carries the same d. (Mathas's recursion puts q⁻¹ outside both terms and so yields geometric coefficients q^{-1}, q^{-2}, …; the two families differ, and this file proves the expansion for the one this corpus actually uses rather than transcribing his.)

    What this unlocks, and what it does not #

    It is the input Jucys's argument needs: conjugating a transposition by σ_j permutes the index pair, so σ_j fixes the sum Σ_{i<k} T_(i,k) whenever j and j+1 both miss k — which is 3.24(i), and in turn feeds the centrality of the partial sums and the telescoping.

    What the file grew into. Those steps are now all here, in order: the pair-swap law (sigma_comm_transp_pair), Mathas 3.24(i) (sigma_comm_addJM), Jucys's centrality (sigma_comm_partialSum_ne), the telescoping (addJM_comm), and — via the identification L_k = 1 + A_k at d = q − q⁻¹ — commutativity of the multiplicative family itself (jmRaw_comm). The paragraph above was written when only the expansion existed; it is kept because the sequence it lays out is the one that worked.

    Still not proved here: ∏Lᵢ = Δ² beyond n = 3, and the spectral half of JucysMurphySpectrum (the seminormal representation). The general-λ twist therefore remains conditional — commutativity was a necessary step toward it, not a sufficient one.

      The pair-swap law — σ_j fixes T_(j,i) + T_(j+1,i) #

      This is the mechanism behind Mathas 3.24(i)'s hard half. For i > j+1 the sum Σ_{l<i} T_(l,i) has exactly two terms σ_j can disturb — l = j and l = j+1 — and σ_j preserves their sum while fixing every other term individually.

      Measured first ([jm_partial_sum_centrality_probe.py] and a companion sweep at n = 6, q ∈ {2,3}, exact rationals): the pair commutes in every case, while each term alone does not. So this is a genuine pair phenomenon, not term-by-term commutation.

      theorem QOU.BraidKnot.Hecke.sigma_comm_transp_pair {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} (H : HeckeGenerators R A q) (j i : ℕ) :
      j + 1 < i → HeckeGenerators.σ q j * (transp H j i + transp H (j + 1) i) = (transp H j i + transp H (j + 1) i) * HeckeGenerators.σ q j

      Pair-swap law: for i > j+1, σ_j commutes with T_(j,i) + T_(j+1,i).

      Base case i = j+2, with u = σ_j, v = σ_{j+1}: the claim is u(vuv + v) = (vuv + v)u. One braid move turns uvu into vuv on each side, leaving vuv² + uv = v²uv + vu, and the Hecke relation v² = hv + 1 expands both to h·vuv + uv + vu. Braid alone is not enough — the Hecke relation is what makes the leftover terms cancel.

      Step i → i+1: both transpositions gain the same outer conjugation by σ_i, and σ_j commutes with σ_i because i > j+1.

      Disjoint transpositions commute with the generator #

      The remaining half of 3.24(i): σ_j commutes with T_(l,i) individually whenever l and i both miss {j, j+1} — the two transpositions are disjoint.

      This is not letter-wise obvious: for l < j < j+1 < i the word for T_(l,i) contains both σ_j and σ_{j+1}. Measured first (H₆, exact rationals): 24 disjoint pairs, all commuting, none failing.

      Partial-sum centrality — Jucys's route #

      S_m := Σ_{i ≤ m} A_i. Measured in jm_partial_sum_centrality_probe.py: S_m commutes with σ_j for every j ≠ m, at three values of q and three of d.

      The exception at j = m is not an accident: the summation cutoff splits the pair (A_m, A_{m+1}), and that pair is exactly what addJM_sigma_comm_add handles. Every other index commutes with σ_j on its own.

        Word lifting — from letters to the whole transposition #

        Centrality gives commutation with generators. To telescope we need commutation with A_i, which is a sum of words in the generators. The lift is an induction over transp's own recursion: T_(l,i) is built from σ_l … σ_{i−1}, so an element commuting with every σ_j for j < i commutes with the whole word.

        This is bookkeeping, not new mathematics — but it is what turns sigma_comm_partialSum_ne into a statement about A_i.

        Back to the multiplicative elements #

        The corpus's jmRaw and the additive family are the same object shifted by 1, once d is the Hecke parameter h = q − q⁻¹:

        L_k = 1 + A_k   with   d = q − q⁻¹.

        Checking the recursion is one line: σ_k(1 + A_k)σ_k = σ_kσ_k + σ_k A_k σ_k, and the Hecke relation turns the first term into h·σ_k + 1, which is exactly the 1 plus the d·σ_k that A_{k+1} adds. This is why the constant d had to be free: the value that identifies the two families is forced, not chosen.

        Consequence: jmRaw commutes, which is the property five direct attacks on jmRaw failed to reach (bean qou-u9o1). The adjacent case [L_k, L_{k+1}] = 0 — the one case HeckeJucysMurphyReduction could not close and the reason the whole reduction stayed conditional — falls out with the rest.
