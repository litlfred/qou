    Shell-Closure Stability #

    Along the dressing chain P_bare → P^(1) → ⋯ → P^(Z_max) in the confinement category, the Frobenius stability index σ_F := n_target · y₀*(P, q) is non-decreasing (claim 1). Its marginal increment Δσ_F(Z) = σ_F(P^(Z)) − σ_F(P^(Z-1)) — the ionisation gap I₁(Z) — attains strict local maxima at the shell closures (claim 2), where binding multiplicity μ(S_Z, q) ≥ 2; the monotone σ_F itself has no interior local maximum. Whether those closures fall at the noble-gas Z ∈ {2, 10, 18, 36, 54, 86} is conditional on the open shell-capacity (2n²/Madelung) derivation — the bare 2×2 T_γe gives closures every two electrons, not the noble gases (a high-precision categorical σ_F chain confirms σ_F does not by itself reproduce the noble-gas peaks). At a closure Z the dressed particle is a local terminal object of the dressing sub-diagram: any outgoing dressing requires breaking multiple tight dual blocks of the confinement SDP simultaneously, exceeding the EM coupling at generic q.

    (The two ShellClosureStability theorem groups formalise exactly the consistent content — claim 1 monotone and claim 2 μ ≥ 2 — and do not assert a local maximum of σ_F.)

    Claim (1) follows from SDP-relaxation monotonicity under the cabling-induced primal/dual lift — not Cauchy eigenvalue interlacing, which would run in the opposite direction on a raw principal-submatrix relationship.

    class QOU.BraidKnot.HasFrobeniusStability (D : DressedParticle) :
    Type

    Frobenius stability data — class-supplied evaluation of σ_F(D, q) = n_target · y₀*(D, q) (the optimal dual objective of the confinement SDP at (D, q); equivalently, by strong duality, the optimal primal ⟨T, Φ*⟩).

    The index is ℝ-valued, and that is the whole point (2026-09-02). It used to be R_q → R_q, and because R_q = ℤ[q, q⁻¹] carries no order, this file installed one:

    local instance : LE R_q := ⟨fun _ _ => True⟩

    Under that instance x ≤ y is True for every pair, so claim (1) below — "the stability index is non-decreasing along the dressing chain" — was True, and ShellClosureMonotone was inhabited by ⟨trivial⟩ for any pair of dressed particles, one-step or not. Measured lean-direct, exit 0, with the instance in scope:

    example (x y : R_q) : x ≤ y := trivial
example … : frobeniusStability D_prev q ≤ frobeniusStability D q := trivial
example … : ShellClosureMonotone D_prev D q h := ⟨trivial⟩

    An ordering is an archimedean construct (AGENTS.md §7c), so it belongs on the ℝ side of the substrate wall, not on the Laurent ring. σ_F is an SDP dual objective and is a real number; making that explicit removes the need for a fabricated order and makes claim (1) falsifiable. The argument stays R_q — the point of evaluation is still substrate-side.

    Claim (2) was never affected, and this is worth separating rather than sweeping in: bindingMultiplicity is ℕ-valued, so μ ≥ 2 is over ℕ's genuine order. The same probe rejects … ≥ 2 := trivial with a type mismatch. Only the σ_F comparisons collapsed.

      The stability index σ_F(D, q), real-valued: it is an SDP dual objective, and it is compared with ≤.

          Prop

          Shell-closure monotonicity — typeclass (Pattern 4).

          Witnesses non-decrease of the Frobenius stability index for a specific one-step dressing pair. The full SDP-relaxation monotonicity proof requires the cabling embedding ι : H_{A+Z-1}(q) ↪ H_{A+Z}(q) and the dual-feasible lift, which depend on Mathlib SDP infrastructure. By packaging the inequality as a class, the conjectural content is visible at every use site rather than asserted universally.
