    RT surgery data. The modular S-matrix vacuum row (VerlindeVacuumRow), together with the data of a surgery presentation of the 3-manifold: the finite set of fusion labels, and the framed colored-link invariant colInv λ = F(L, λ) — the value of the RT ribbon functor on the surgery link L with its component colored by λ. (The framing/signature normaliser is a global scalar that cancels in every per-label / ratio statement below, so it is not carried.)

    • D : R
    • vac : ι
    • d_vac : self.d self.vac = 1
    • D_ne : self.D ≠ 0
    • labels : Finset ι

      The fusion labels summed over in the surgery presentation.

    • colInv : ι → R

      The framed colored-link invariant F(L, λ) of the surgery link colored by λ.

      def QOU.BraidKnot.RTSurgery.RTSurgeryData.partitionSum {ι : Type u_1} {R : Type u_2} [Field R] (M : RTSurgeryData ι R) :
      R

      The Reshetikhin–Turaev surgery invariant of the presented 3-manifold: the color-sum of the framed colored-link invariant weighted by the S-matrix vacuum row S_{0λ}. This is the shape of Turaev's surgery formula τ(M) = Σ_λ S_{0λ} · F(L, λ) (global framing normaliser dropped). The sum is over the modular category's simple objects; the per-label weight is the vacuum row.

      -- Ref: [manuscript] Reshetikhin–Turaev surgery formula (Turaev 1994, ch. II).

      Equations
