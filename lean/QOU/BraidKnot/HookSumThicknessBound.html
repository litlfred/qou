    Thickness costs hook length: H(μ) ≥ r(μ)² #

    For a Young diagram μ write r(μ) := min (μ.rowLen 0) (μ.colLen 0) — the smaller of its first-row length and its first-column length, a crude "thickness". This module proves

    r(μ)^2  ≤  Σ_{c ∈ μ.cells} hookZ μ c                                      (`sq_min_le_sum_hookZ`)

    together with the per-row strict decrease of hook lengths

    hookZ μ (i, j+1) + 1  ≤  hookZ μ (i, j)                                   (`hookZ_succ_lt`)

    which is the reason each row can hold at most one cell of any given hook length.

    Why these two #

    They are the combinatorial content behind an analytic bound on the deuteron-wall quantity REV (bean qou-hok7). There R_λ ≤ C · r(λ) follows from the per-row decrease, and the upper bound REV = O(n^{3/4}) needs a converse coupling r back to the hook sum — exactly sq_min_le_sum_hookZ. The Python side (computations/deltalambda/rev_sublinearity_closed_probe.py) verifies both exhaustively for n ≤ 26; this module proves them for every diagram.

    The proof is one line of the closed form, and it replaces a WRONG argument #

    HookSumClosedForm.two_mul_sum_hookZ_eq_sum_sq gives 2H = Σ_i (rowLen i)² + Σ_j (colLen j)². Every summand is a square, hence non-negative, so each sum dominates its own 0-th term:

    2H  ≥  (rowLen 0)² + (colLen 0)²  ≥  2 · min(rowLen 0, colLen 0)² .

    That is the whole argument. It is recorded here because the first attempt at this bound, in computations/deltalambda/rev_sublinearity_proof_probe.py, claimed the stronger H ≥ 3r² - 3r + 1 from h(1,j) ≥ 2r - j — a step that silently assumes column j has ≥ r cells for every j ≤ r, when only column 1 does. It is false, with 1168 counterexamples at n ≤ 22; the sharpest is the hook shape (11, 1^10), where r = 11 and H = 131 against a claimed 331. The bound proved here assumes nothing about columns 2..r, and is stronger than the r² - r + 1 that a repaired row-plus-column count gives.

    Sharpness #

    sq_min_le_sum_hookZ is attained exactly at μ = (1): there r = 1 and H = 1. For every larger diagram it is strict (checked exhaustively to n = 26 on the Python side; not proved here, and not needed — only the inequality is used downstream).

    Base ring #

    ℤ throughout, matching PieceAGeneral and HookSumClosedForm: no ℝ, no ordering on a substrate parameter, no archimedean input. Per AGENTS.md §7c this is a purely combinatorial statement and must not be stated over ℝ.

    theorem QOU.BraidKnot.HookSum.hookZ_succ_lt (μ : YoungDiagram) (i j : ℕ) :
    PieceA.hookZ μ (i, j + 1) + 1 ≤ PieceA.hookZ μ (i, j)

    Hook lengths strictly decrease along a row: moving one cell to the right drops the arm by exactly one and cannot raise the leg, since colLen is antitone. Consequently a row contains at most one cell of any given hook length — the combinatorial fact behind N_m(λ) ≤ ℓ(λ).

    theorem QOU.BraidKnot.HookSum.hookZ_strictAnti_row (μ : YoungDiagram) (i : ℕ) {j j' : ℕ} :
    j < j' → PieceA.hookZ μ (i, j') < PieceA.hookZ μ (i, j)

    Hook lengths are strictly decreasing along a row: j < j' gives h(i,j') < h(i,j). Induction on the one-step lemma.

    theorem QOU.BraidKnot.HookSum.card_row_filter_hookZ_le_one (μ : YoungDiagram) (i : ℕ) (m : ℤ) :
    {c ∈ μ.row i | PieceA.hookZ μ c = m}.card ≤ 1

    L1. A row contains at most one cell of any given hook length. This is what bounds the hook-length multiplicity N_m(λ) by the number of rows, and (via the conjugate statement) by the number of columns — the input to R_λ ≤ C · r(λ) in the REV bound.
