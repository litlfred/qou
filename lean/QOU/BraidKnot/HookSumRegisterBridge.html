    Bridging the two hook-sum registers #

    The hook-sum identity is proved twice in this corpus, in registers that did not talk to each other:

    1. QOU.HookSumComplete.hookSum_eq (module QOU.Common.HookSumComplete) — over a sorted List ℕ, in ℕ with truncated subtraction, with its own colLen / bStat / colSum / hookSum, and an explicit sortedness hypothesis.
    2. QOU.BraidKnot.HookSum — over Mathlib's YoungDiagram, in ℤ, on PieceAGeneral's armZ / legZ / hookZ, with no sortedness hypothesis (YoungDiagram carries that structurally).

    HookSum's docstring asserted they were the same identity and stated (1)'s shape term-for-term so a reader could check. That is a human reading. This module makes it a proof: hookSum_rowLens identifies the two hook sums, and sum_hookZ_eq_bStat_via_list re-derives the YoungDiagram closed form from the list one, so the two are demonstrably one theorem rather than two that happen to agree.

    The four component bridges #

    rowLens_getD, colLen_rowLens, rowLens_sum_eq_card translate the data; rowLens_sorted' and rowLens_le_rowLen_zero discharge (1)'s two hypotheses from YoungDiagram.rowLen_anti alone. Note that rowLens_sorted' does not go through YoungDiagram.rowLens_sorted: rowLen_anti gives the statement in the form hookSum_eq wants directly, without unpacking List.Sorted.

    Where the work actually is #

    The ℕ-to-ℤ cast, as expected — but only because it is conditional. (1) writes an arm as l.getD i 0 - 1 - j in truncated ℕ subtraction, which agrees with armZ's ℤ subtraction only on a cell. So the cellwise step carries j < μ.rowLen i, and derives i < μ.colLen j from it through mem_iff_lt_rowLen / mem_iff_lt_colLen, before omega may equate the two. Off a cell the two registers genuinely disagree, and nothing here says otherwise.

    Index sets #

    hookSum_eq takes a column bound M; μ.rowLen 0 is the natural choice and rowLens_le_rowLen_zero supplies it. The row count is forced: List.length of μ.rowLens, which YoungDiagram.length_rowLens identifies with μ.colLen 0.

    The bridge #

    source
    theorem QOU.BraidKnot.HookSumBridge.hookSum_rowLens (μ : YoungDiagram) :
    ↑(HookSumComplete.hookSum μ.rowLens) = ∑ c ∈ μ.cells, PieceA.hookZ μ c

    The two hook sums are the same number. HookSumComplete.hookSum of μ.rowLens, cast to ℤ, is Σ_c hookZ μ c.

    The cellwise step is where the registers actually meet: the list side's truncated ℕ subtraction agrees with armZ/legZ only because j indexes a real cell of row i, which also forces i < μ.colLen j.

    source
    theorem QOU.BraidKnot.HookSumBridge.sum_hookZ_eq_bStat_via_list (μ : YoungDiagram) :
    ∑ c ∈ μ.cells, PieceA.hookZ μ c = ∑ j ∈ Finset.range (μ.rowLen 0), ↑j * ↑(μ.colLen j) + ∑ i ∈ Finset.range (μ.colLen 0), ↑i * ↑(μ.rowLen i) + ↑μ.cells.card

    The list-register closed form, transported. Σ_c hookZ = b(λ') + b(λ) + n derived from HookSumComplete.hookSum_eq through the bridge — a second, independent route to HookSum.sum_hookZ_eq_bStat, which proves the same proposition from the YoungDiagram arm/leg reflections instead.

    source
    theorem QOU.BraidKnot.HookSumBridge.sum_hookZ_eq_bStat_via_reflections (μ : YoungDiagram) :
    ∑ c ∈ μ.cells, PieceA.hookZ μ c = ∑ j ∈ Finset.range (μ.rowLen 0), ↑j * ↑(μ.colLen j) + ∑ i ∈ Finset.range (μ.colLen 0), ↑i * ↑(μ.rowLen i) + ↑μ.cells.card

    The reflection route proves the very same proposition — same statement, so the two derivations are not merely consistent, they are one theorem.
