    QOU.BraidKnot.KeystoneHeckeMTC — the Hecke/Temperley–Lieb side as a concrete MTC (the target of "BW = Hecke") #

    This file assembles the Hecke blocks into a single explicit HeckeMTC bundle carrying the two pieces of modular data a modular tensor category must have — the vacuum S-matrix row S₀ and the diagonal ribbon twist / modular T-matrix θ — together with the quantum dimension qDim = d_q, the global dimension D (D² = Σ d_q²), a distinguished vacuum object of quantum dimension 1, and the transpose (bar / charge-conjugation) involution conj. It then proves exactly the modular-data relations that are genuinely provable from the existing corpus, reusing the already-established lemmas rather than re-deriving them:

    • S0_ratio_eq_qDim — the vacuum-row ratio recovers the quantum dimension, S₀(λ)/S₀(vac) = d_q(λ), routed through the corpus-proved QOU.BraidKnot.VerlindeVacuumRow.S0_ratio (BWVacuumRowIsHecke.lean). This is the S₀ = d_q/D modular datum.
    • S0_conj — the vacuum row is transpose-invariant (chirality-blind), S₀(λ′) = S₀(λ), derived from the qDim_conj field (the corpus-proved QOU.BraidKnot.IdentityI.qDim_conj, KeystoneC2QDimTranspose.lean, d_q(λ′) = d_q(λ)).
    • theta_conj_mul — the twist's chirality law in product form, θ(λ′)·θ(λ) = 1, derived from the theta_conj field (the corpus-proved QOU.BraidKnot.Keystone.theta_conjugate (KeystoneModularTwist.lean), θ_{λ′} = θ_λ⁻¹).
    • verlindeMeasure_conj — the Verlinde measure μ(λ) = S₀(λ)² is transpose-invariant.

    The concrete Hecke instance heckeMTC discharges qDim_conj from IdentityI.qDim_conj and theta_conj from Keystone.theta_conjugate (not carried abstractly), and reuses KeystoneVerlindeSMatrixBridge's positivity (sum_qDimSq_pos) for D ≠ 0. A non-vacuity example (a genuine HeckeMTC ℝ over the block set {[]}) confirms the structure is inhabited, so the theorems above are not conditional-on-False.

    structure QOU.BraidKnot.Keystone.HeckeMTC (R : Type u_1) [Field R] :
    Type (max u_1 (u_2 + 1))

    The Hecke/Temperley–Lieb side as a concrete modular tensor category (the target of "BW = Hecke").

    Bundles both pieces of modular data on the Hecke partition blocks:

    • the vacuum S-matrix row S0 : Part → R with the published modular-data identity S₀(λ) = d_q(λ)/D (S0_eq), and a distinguished vacuum object vac of quantum dimension 1;
    • the ribbon twist / modular T-matrix theta : Part → R, diagonal, with the chirality law θ_{λ′} = θ_λ⁻¹ (theta_conj) and θ_vac = 1;

    together with the quantum dimension qDim = d_q (transpose-invariant, qDim_conj), the global dimension D (D² = Σ d_q², D_sq; D ≠ 0, D_ne), and the transpose (bar) involution conj closing the block set (conj_mem).

    The fields qDim_conj, theta_conj, S0_eq, D_sq are the modular-data inputs; the file's theorems derive the modular-data consequences from them. Constructing an instance whose qDim is the Hecke d_q and whose S0 is the BW gauge datum is the open physics content (bwse / bean bwhk), NOT supplied by this class.

    • Part : Type u_2

      Partition index for the Hecke block λ ⊢ n.

    • parts : Finset self.Part

      The finite set of Hecke partition blocks.

    • conj : self.Part → self.Part

      The transpose (bar / charge-conjugation) involution λ ↦ λ′.

    • conj_mem (p : self.Part) : p ∈ self.parts → self.conj p ∈ self.parts

      The blocks are closed under transpose.

    • vac : self.Part

      The monoidal unit / vacuum object.

    • vac_mem : self.vac ∈ self.parts

      The vacuum is one of the blocks.

    • qDim : self.Part → R

      The categorical quantum dimension d_q(λ) of the Hecke block.

    • qDim_vac : self.qDim self.vac = 1

      The vacuum object has quantum dimension 1.

    • qDim_conj (p : self.Part) : p ∈ self.parts → self.qDim (self.conj p) = self.qDim p

      Corpus-proved input d_q(λ′) = d_q(λ) (QOU.BraidKnot.IdentityI.qDim_conj).

    • theta : self.Part → R

      The ribbon twist / modular T-matrix eigenvalue θ_λ (diagonal modular datum).

    • theta_vac : self.theta self.vac = 1

      The twist is trivial on the vacuum: θ_vac = 1.

    • theta_conj (p : self.Part) : p ∈ self.parts → self.theta (self.conj p) = (self.theta p)⁻¹

      Corpus-proved input — the twist's chirality law θ_{λ′} = θ_λ⁻¹ (QOU.BraidKnot.Keystone.theta_conjugate).

    • D : R

      The global quantum dimension D (total dimension of the modular category).

    • D_ne : self.D ≠ 0

      D ≠ 0.

    • D_sq : self.D ^ 2 = ∑ p ∈ self.parts, self.qDim p ^ 2

      D² = Σ_λ d_q(λ)² — the defining global-dimension relation.

    • S0 : self.Part → R

      The vacuum S-matrix row S₀(λ).

    • S0_eq (p : self.Part) : p ∈ self.parts → self.S0 p = self.qDim p / self.D

      Published modular-data identity S₀(λ) = d_q(λ)/D (vacuum row of the S-matrix in any MTC).
