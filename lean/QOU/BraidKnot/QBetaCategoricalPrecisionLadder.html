    QOU.BraidKnot.q_beta_categorical_precision_ladder #

    The Q_β categorical-derivation precision ladder through depth N=3:

    Q_β^cat = Q_β^A · cos(α - b·ℏ_q²/2) ← N=1, Kashiwara f̃_1 · (1 - b² · ℏ_q^4) ← N=2, Kashiwara f̃_1² · (1 - 2 · b³ · ℏ_q^6) ← N=3, Hopf Jones J(q=1) = -2

    with α = (z-1)h/2, b = √(q⁴+q²+1)/(q²+1), and ℏ_q = (q-1)/q.

    Each rung's coefficient is BUILT from substrate-only data:

    • b: Hoefsmit off-diagonal coupling on V_(2,1) (Hecke seminormal form)
    • 2 = -J_Hopf(q=1): classical-limit Jones polynomial of the Hopf link

    DISCIPLINE (2026-05-30, supersedes earlier "derived" framing). Only the N=2 rung (c_2 = -1) is Taylor-EXACT and wired to production (per_observable_100x_status.py, Q_N2 = 1279 ppb honest floor). The N≥3 rungs (c_3 = J_Hopf, c_4, c_5, …) are STRUCTURAL NEAR-MATCHES at canonical q₀ (c_3 = J_Hopf is 3.35% off the empirical Taylor coefficient -2.0693), NOT Taylor-exact derivations — see docs/audits/2026-05-30-qbeta-ck-mp-dk-deep-audit.md and computations/qbeta/qbeta-delta-tr-vs-formA.witness.json. The c_3 identification is locked behind the conditional QbetaC3StructuralFormClass (§3b-cond) at the foot of this file; production wires nothing beyond c_2.

                              Bar-involution invariance #

                              The categorical formula is invariant under the bar involution q ↔ q⁻¹ because:

                              α(q⁻¹) = -α(q) by eigenphase_bar_involution b(q⁻¹) = b(q) (symmetric in (q² + q⁻²)) ℏ_q(q⁻¹) = -ℏ_q(q) but enters at even powers

                              The full product is even in (q - q⁻¹), consistent with the classical-limit decategorification principle.

                              source
                              theorem QOU.BraidKnot.hoefsmitB_bar_invariant (q : ℝ) (_hq : 0 < q) :
                              hoefsmitB q⁻¹ = hoefsmitB q

                              b is bar-symmetric: hoefsmitB q⁻¹ = hoefsmitB q for q > 0.

                              hoefsmitB q = √(q⁴+q²+1)/(q²+1). Dividing radicand and denominator by q²: q⁻⁴+q⁻²+1 = (q⁴+q²+1)/(q²)² and q⁻²+1 = (q²+1)/q², so √(·)/(·) telescopes to the q-form (Real.sqrt_div splits the quotient, Real.sqrt_sq evaluates √(q²)² = q²). Previously an axiom "pending a sqrt_div_eq lemma in Mathlib"; the existing Real.sqrt_div + Real.sqrt_sq API discharges it directly.

                              class QOU.BraidKnot.QBetaPrecisionLadderCoefficients :
                              Type

                              Categorical coefficient class for the Q_β precision ladder.

                              Holds the per-rung coefficients c_k for the factor (1 + c_k · b^k · ℏ_q^{2k}) at depth k ≥ 2. All rungs through N=5 are now pinned to closed forms derived from two primitives:

                              • b(q) — Hoefsmit off-diagonal coupling (Kashiwara source)
                              • c_3 = J_Hopf(q=1) = −2 — Hopf Jones polynomial at q=1 (categorical inter-block source)

                              The closed forms (per 2026-05-19-qbeta-all-ck-categorical-extension.md):

                              c_2(q) = −1 (pure Kashiwara, intra-block) c_3(q) = −2 = J_Hopf(q=1) (pure Jones, inter-block) c_4(q) = c_3(q) · b⁴(q) = −2·b⁴(q) (Jones × Kashiwara mixing) c_5(q) = −(b²(q) + 1/2) (Kashiwara b² + Hopf-half offset; doc's c_4 form, off by one rung)

                              Each instance may extend the class with c_6, c_7, ... once their closed forms are derived.

                              • c_k_at_q : ℕ → ℝ → ℝ

                                The k-th rung categorical coefficient c_k(q).

                              • c_2_eq (q : ℝ) : c_k_at_q 2 q = -1

                                N=2: pure Kashiwara, factor (1 - b²·ℏ_q^4).

                              • c_3_eq (q : ℝ) : c_k_at_q 3 q = jonesHopfClassicalLimit

                                N=3: pure Jones, c_3 = J_Hopf(q=1).

                              • c_4_eq (q : ℝ) : c_k_at_q 4 q = jonesHopfClassicalLimit * hoefsmitB q ^ 4

                                N=4: c_4 = c_3 · b⁴ (Jones × Kashiwara, 0.91% empirical residual).

                              • c_5_eq (q : ℝ) : c_k_at_q 5 q = -hoefsmitB q ^ 2 - 1 / 2

                                N=5: c_5 = −(b² + 1/2) (Kashiwara b² + Hopf-half offset; sub-ppt residual).

                              • c_6_eq (q : ℝ) : c_k_at_q 6 q = jonesHopfClassicalLimit ^ 2 * hoefsmitB q ^ 2

                                N=6: c_6 = c_3² · b² = 4·b² (Jones-squared × Kashiwara b²; closes 6.5× tighter than N=5). EMPIRICAL FIT — not derived.

                              • c_7_eq (q : ℝ) : c_k_at_q 7 q = jonesHopfClassicalLimit ^ 3

                                N=7: c_7 = c_3³ = −8 (Jones cubed). Residual leverage is so small at N=7 (10⁻¹⁵ scale) that many c_7 values give acceptable closure; this form is chosen for pattern aesthetics, not derivation.
