    Bar-parity invariant — the formalize-first filter on any μ-anchor correction #

    The surviving μ–p route, gated by its invariant. The μ–p tension attack (bean qou-ph2a, docs/audits/2026-08-01-mu-p-tension-attack-recon-floor-verdict.md) found the naive mechanism refuted: the q-deformed projector-weight shift on the H_5 Markov trace (#2584) is not only 6–7 orders too large but bar-mixed — its correction has a nonzero bar-odd part, and so fails the parity a genuine figure-8 (4₁) correction must have. The one un-refuted route (the colored Σ(2,3,5) WRT / Habiro q-series, s5-so3 keystone) must respect the same parity.

    This module states that parity invariant and proves its algebra, so the route is gated before any wide numerics (formalize-first, AGENTS.md §"Formalize-first probe discipline"). The invariant is the bar-involution q ↦ q⁻¹:

    • BarEven f — f(q⁻¹) = f(q): the parity the amphichiral figure-8 anchor has. Proved for the actual colored-Jones tower here (packaging the sorry-free coloredJones41_bar_symmetric), and for [2]_q = q + q⁻¹.
    • BarOdd f — f(q⁻¹) = −f(q): the parity ℏ = q − q⁻¹ has.
    • Exclusion (the filter): a function that is both bar-even and has a bar-odd part must have that part vanish (barEven_barOdd_forces_zero; over CharZero, forced to 0). So a candidate μ-correction with a nonzero bar-odd component (the refuted projector shift) cannot be a bar-even figure-8 correction. This is a structural exclusion (scope-(b)) justified by the proved parity invariant — not a numerical near-miss.

    Nothing here fits or uses q₀ / the 210 ppb target; it is the parity algebra + the anchor's proved bar-symmetry. Wiring a derived bar-even correction to production remains gated on the open Σ(2,3,5) WRT evaluation (bean s5bb).

    Base ring (§7c) #

    Generic {K : Type*} [Field K] throughout (the bar-involution needs q⁻¹); no ℝ, no ordering, no archimedean constructs. CharZero is assumed only for the two lemmas that must divide by 2 (the odd-part-forced-zero corollary and the even/odd reconstruction).

          Power parity — the Δ_λ chirality sign IS the bar-involution grading #

          The Δ_λ closure target (bean s5bb, Option-E) is mixed-sign: the chirality sign is deltaSign λ = (-1)^(principal grading λ) (QOU.BraidKnot.PrincipalGradingJetOrder.deltaSign, QOU.BraidsAndKnots.PartitionOf5.deltaSign). Since each principal-grading-1 generator is the bar-odd ℏ = q − q⁻¹, a degree-d monomial has bar-parity (-1)^d — so the Δ_λ chirality sign and the μ-correction bar-even requirement (#2584) are the same ℤ/2 bar-involution grading on the shared s5-so3 W_λ object. The two open routes are gated by one invariant.

          The exclusion filter — bar-even ∧ bar-odd part ⇒ that part vanishes #

          source
          theorem QOU.BraidKnot.BarParityInvariant.barEven_barOdd_forces_two_zero {K : Type u_1} [Field K] {f : K → K} (he : BarEven f) (ho : BarOdd f) (q : K) (hq : q ≠ 0) :

          Common-parity collapse. A function that is both bar-even and bar-odd satisfies f q + f q = 0 everywhere on the punctured line. Over any field: the even law gives f q⁻¹ = f q, the odd law gives f q⁻¹ = −f q, so f q = −f q.
