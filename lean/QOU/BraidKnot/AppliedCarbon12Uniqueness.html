    QOU.BraidKnot.AppliedCarbon12Uniqueness — concrete ¹²C application #

    Thin wrapper specialising NucleusEmptySDPUniqueness to ¹²C's strand count n = 3·A = 3·12 = 36 (Z=6, N=6, A=12).

    ¹²C is the third triple-α product (3·⁴He → ¹²C via the Hoyle state at 7.65 MeV), making it the gateway to all heavier nucleosynthesis in stellar interiors.

    Status #

    Sorry-free closure for ¹²C's empty-SDP uniqueness via the parameterised nucleus_uniqueness_closed at n := 36. No abstract-axiom dependency. The QOU framework does not yet have an R5-full witness for ¹²C; this module pre-provisions the uniqueness scaffolding for when that witness lands.
