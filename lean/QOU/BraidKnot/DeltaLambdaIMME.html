      theorem QOU.BraidKnot.imme_mirror_diff {R : Type u_1} [CommRing R] (a b c T3 : R) :
      imme a b c T3 - imme a b c (-T3) = 2 * b * T3

      Mirror difference isolates the linear coefficient. The bar-even a and c·T₃² cancel, leaving 2·b·T₃. This is the explicit-quadratic refinement of mirror_baseline_cancels (#3089): a mirror pair can only ever measure b, never c, no matter how large the quadratic.

      theorem QOU.BraidKnot.imme_triplet_2nd_diff {R : Type u_1} [CommRing R] (a b c : R) :
      imme a b c 1 + imme a b c (-1) - 2 * imme a b c 0 = 2 * c

      Triplet 2nd difference isolates the quadratic. For an isobaric triplet T₃ ∈ {−1, 0, +1}, the symmetric second difference f(1) + f(−1) − 2·f(0) cancels a and b·T₃, leaving 2·c. This is why measuring c requires three multiplet members, not a mirror pair.

      theorem QOU.BraidKnot.imme_third_diff_zero {R : Type u_1} [CommRing R] (a b c x : R) :
      imme a b c (x + 3) - 3 * imme a b c (x + 2) + 3 * imme a b c (x + 1) - imme a b c x = 0

      Askey–Racah / Wigner truncation, made falsifiable. A degree-2 IMME has a vanishing third finite difference Δ³f(x) = f(x+3) − 3 f(x+2) + 3 f(x+1) − f(x) = 0. Equivalently: no d·T₃³ term can hide in the residual — the "charge-dependent forces are rank-≤2 isotensors" statement (the Askey–Racah cutoff) is the testable identity that a fourth multiplet member must satisfy.
