    QOU.BraidKnot.Chi21GarsideZero #

    The α₃-break structural prune.

    This file derives — from the explicit 2 × 2 Hoefsmit seminormal representation of the two braid generators — the fact that the (2,1) Hecke character of the Garside (half-twist) element σ₁σ₂σ₁ ∈ B₃ vanishes:

    χ^{(2,1)}(σ₁σ₂σ₁) = tr ρ_{(2,1)}(σ₁σ₂σ₁) = 0.

    Contrast with ChiLambdaW0SignWeighting.lean, which records χ_{(2,1)}(w₀) = 0 as a constant imported from S₃ character theory. Here the value is obtained by forming the concrete seminormal matrices ρ_{(2,1)}(σ₁), ρ_{(2,1)}(σ₂), multiplying to get ρ_{(2,1)}(σ₁σ₂σ₁), and computing its trace.

    The (2,1) seminormal representation of H₃(q) #

    The irrep (2,1) ⊢ 3 is 2-dimensional, with basis the two standard Young tableaux of shape (2,1):

    t₁ = 1 2 / 3 ,   t₂ = 1 3 / 2 .

    Contents c = col − row: cell (1,1)↦0, (1,2)↦1, (2,1)↦−1. The Hoefsmit seminormal form (mass-theory/hoefsmit-seminormal-form.md, [hoefsmit1974], [wenzl1988]) sets, for a generator σ_i and tableau s with axial distance ρ = c(s,i+1) − c(s,i),

    ρ_λ(σ_i)_{s,s}  = a_ρ := (q − q⁻¹) / (1 − q^{−2ρ}),
ρ_λ(σ_i)_{s,sᵢ} = b   := √(a_ρ · a_{−ρ} + 1)   (when sᵢ is standard),
ρ_λ(σ_i)_{s,s'} = 0    otherwise.
    • σ₁ (swap entries 1,2) is diagonal on {t₁,t₂}: on t₁ the distance is c(2)−c(1)=1−0=1, on t₂ it is c(2)−c(1)=−1−0=−1, and neither swap is standard. Hence ρ(σ₁) = diag(a₁, a₋₁).
    • σ₂ (swap entries 2,3) mixes t₁ ↔ t₂: on t₁ the distance is c(3)−c(2)=−1−1=−2, on t₂ it is c(3)−c(2)=1−(−1)=2; the swap t₁ ↔ t₂ is standard. Hence ρ(σ₂) = !![a₋₂, b; b, a₂].

    The off-diagonal entry b is carried as a free parameter — it never enters the trace of ρ(σ₁)·ρ(σ₂)·ρ(σ₁), so the vanishing is independent of the seminormal square root:

    tr(D · M · D) = a₁²·a₋₂ + a₋₁²·a₂ ,   D = diag(a₁,a₋₁), M = !![a₋₂,b;b,a₂].

    With s := q², a₁²·a₋₂ = −s²/((s−1)³(s+1)) = −a₋₁²·a₂, so the two summands cancel exactly.

    α₃-break meaning #

    The z^k Markov marker (the z-graded piece detecting a full k-fold Garside twist) breaks at k = 3 structurally: the half-twist σ₁σ₂σ₁ is the (2,1)-blind element, so the (2,1) Wedderburn block contributes nothing to any observable built from the α₃ (three- strand Garside) marker. This is a structural prune of the α₃ channel, not a numerical near-cancellation. See computations/probes/probe_9b_alphak_structure.py.

                  α₃-break structural prune. The (2,1) Hecke character of the Garside half-twist σ₁σ₂σ₁ vanishes, derived from the explicit 2 × 2 Hoefsmit seminormal matrices:

                  χ^{(2,1)}(σ₁σ₂σ₁) = tr ρ_{(2,1)}(σ₁σ₂σ₁) = a₁²·a₋₂ + a₋₁²·a₂ = 0.

                  Over any field, with q ≠ 0, q² ≠ 1, and q⁴ ≠ 1 (the seminormal axial-distance denominators nonzero). The off-diagonal seminormal entry b is arbitrary — it does not enter the trace.
