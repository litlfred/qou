    class QOU.BraidKnot.Keystone.HabiroRigidity (H : Type u_1) (RootIndex : Type u_2) :
    Type (max u_1 u_2)

    Habiro rigidity (§3b class). An abstract Habiro-like element type H equipped with a root-of-unity evaluation evalRoot ζ : H → ℂ (value at each root of unity ζ, indexed by RootIndex) and an archimedean q₀-value evalQ0 : H → ℝ (the τ_∞ evaluation post-fibre-functor). The content is root_injective: an element of H is determined by its root-of-unity values — Habiro's injectivity miracle, carried here as the class hypothesis (not proved). Any instance supplies this rigidity; the actual z-Habiro ring realizing it is the open object.

    • evalRoot : RootIndex → H → ℂ

      Root-of-unity evaluation: value of a Habiro element at the root of unity indexed by ζ.

    • evalQ0 : H → ℝ

      Archimedean q₀-value (τ_∞ evaluation) of a Habiro element.

    • root_injective (a b : H) : (∀ (ζ : RootIndex), evalRoot ζ a = evalRoot ζ b) → a = b

      Content — Habiro injectivity (hypothesis). A Habiro element is determined by its root-of-unity values: if a and b agree at every root of unity, then a = b.
