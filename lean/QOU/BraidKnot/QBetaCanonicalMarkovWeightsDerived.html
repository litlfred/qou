    QOU.BraidKnot.QBetaCanonicalMarkovWeightsDerived — the H₃ instance IS the derived Markov weights #

    QBetaCanonicalMarkovWeightsInstance (PR #6487) makes canonicalInstance — the weights y₍₃₎ = (q⁴+1)/(q²+1)², y₍₂,₁₎ = q²/(q²+1)², y₍₁³₎ = 0 — the default inhabitant of CanonicalMarkovWeightsH3. That PR justified the three values by a probe (canonical_markov_weights_h3_are_sl2_dimensions.py, exact sympy) against the Ocneanu product at z_D. A probe is a check, not a derivation, and the corpus already holds the derivation: HeckeMarkov3.markovWeight0/1/2 are the n = 3 Markov weights solved from the defining conditions tr_M(1) = 1, tr_M(σ₁) = z, and the Markov relation (derive-then-check, SW-8), and OcneanuWeightMarkov3 proves the general-n closed form ocneanuWeight reproduces them.

    This file closes the loop: at convention D's z_D = q³/(q²+1) the instance's three values are markovWeight0, markovWeight2, markovWeight1 (in the block order (3), (2,1), (1³)), hence are the n = 3 slice of ocneanuWeight q z_D. So the default instance is now proved equal to the derived object, and nothing about it rests on the probe.

    The "Ocneanu family z_N = q^N/[N]_q, D is its N = 2 point, C is in no member" story told in rem:markov-z-reconciliation and PR #6370 was already in Lean, and that PR did not cite it. The record, so the next reader does not repeat the omission:

    • QOU.SchurWeyl.OcneanuWeight (PR #5575, 2026-08-23): the general-n cell product, the z_D row cap, and "z_D is the k = 2 member of z = q^{2k+1}/(1+q²+⋯+q^{2k}), C in no member" — that family is z_N with N = k, written with the geometric sum in place of [N]_q.
    • QOU.SchurWeyl.WenzlWeightLevelR.wenzlMarkovParam: the level-r family itself; the Toffoli file's markovZAt N q is wenzlMarkovParam N (q²) / q (Hecke normalisation).
    • QOU.SchurWeyl.OcneanuWeightWenzl.ocneanuWeight_conventionD_eq_schurPrincipal: the hook-content identification at every μ — the bridge #6370 presented as new.
    • QOU.MassTheory.TwoRowCapDerived.traceSum_eq_twoRow_of_wenzl: the mass channel's trace restricts exactly to two-row partitions, χ free — the "push into the mass channel" that motivated this file, closed before it was proposed.
