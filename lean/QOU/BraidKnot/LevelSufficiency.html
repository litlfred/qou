    Level Sufficiency #

    For a confined particle P admitting normal forms at strand counts n₀ ≤ n₁ related by confinement reduction, the Markov trace coincides on both representations whenever k_max(P, q) ≤ n₀.

    Justifies computing mass, binding, and Jones polynomial at the coarsest level (e.g. nucleon-level for atoms) and unfolding to a deeper level (quark-level) only when k_max > n forces it (magic shell / SDP).

    def QOU.BraidKnot.kMax (P : ConfinedParticle) (_q : Archimedean.R_q) :
    ℕ

    Witnessed partition truncation k_max(P, q) of the confinement SDP at (P, q) — the largest Wedderburn block λ ⊢ k with non-zero projection in the optimal Φ*.

    Coarse upper bound. The full SDP-derived value is bounded above by the Markov-class strand count: every Wedderburn block that supports non-zero Φ* weight indexes a partition of size ≤ strandCount. The bound is tight when every block carries weight; the slack is precisely the SDP active-support multiplicity. We adopt the upper bound here so kMax is a closed-form definition; per-instance refinements live in LevelSufficient witnesses.

          Prop

          Level sufficiency — typeclass (Pattern 4).

          Witnesses Markov-trace invariance under an unfolding morphism P → P' for a specific confined-particle pair satisfying the coverage hypothesis. The headline result is the Markov tower property (Jones), but its formalisation in Lean depends on the full HeckeRep.character machinery; until then, callers supply the witness for the pairs they actually use.

            markovTrace P q = markovTrace P' q

            Level sufficiency (headline) (per-instance form). Backed by LevelSufficient.

            Assumed, not derived here — the body projects LevelSufficient.trace_eq, so the trace equality is a hypothesis carried by the instance argument, not a result established below. Jones is cited for the Markov-trace theory the statement is about; it is not the source of a proof performed here. The statement is genuinely conditional (P, P', q are arbitrary), so it may not be strengthened to a global axiom.
