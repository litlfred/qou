    The concrete row (from #3652 vector 2 — no fit) #

    What this proves — and the honest disposition #

    • bwS0Concrete_eq_S0_iff (symbolic-exact): the de-opaqued gate holds ↔ (S0 = 0 ∨ θ^f = 1).
    • bwS0Concrete_conj_mul / bwS0Concrete_breaks_symmetry (scope-(b) structural exclusion, per AGENTS.md — cites a proved invariant): d_q (hence S0) is transpose-invariant (qDim_conj), but the twist θ is transpose-inverting (theta_conjugate). So the concrete row S0·θ^f breaks a conjugation symmetry that d_q/D has, and it cannot equal the transpose-symmetric d_q/D for f ≠ 0 unless θ^f = 1. This is a genuine invariant, not a magnitude probe.
    • bwS0Concrete_eq_hecke_forces_trivial_twist (capstone): if the concrete Hecke row equals the modular datum d_q/√(Σ d_q²) on all of P, then ∀ l ∈ P, (θ_λ)^f = 1 — the de-opaqued gate forces a twist-trivial framing.
