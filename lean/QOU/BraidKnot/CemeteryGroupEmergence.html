    QOU.BraidKnot.CemeteryGroupEmergence — cemetery group as ker τ (conjecture) #

    Class axiomatisation of [conj:cemetery-group-emergence]: monotonicity of the cemetery group Z_n = ker τ under crystal extensions. Once a crystal path enters Z_n it cannot escape, and the corresponding normal form vanishes under the observation functor τ.

    The class takes [CrystalGraphRealization R q] and [CemeteryGroup R] as upstream inputs. The monotone_under_extension field is the conjectural content.

    Type u

    Cemetery-group emergence (conjecture).

    Encodes monotonicity of the cemetery filter under crystal extensions: if a prefix lies in Z_n, every continuation also lies in Z_n, and τ annihilates the extended normal form.

    • inCemetery : CrystalGraphRealization.CrystalNode q → Prop

      Predicate: a crystal node lies in the cemetery group Z_n.

    • tauImage : CrystalGraphRealization.NormalForm q → R

      Image under the observation functor τ (graded character) of a normal form. Lives in R for definiteness; abstract instances may refine this.

    • monotone_under_extension (T : CrystalGraphRealization.NormalForm q) : inCemetery (CrystalGraphRealization.nodeOf T) → tauImage T = 0

      The conjecture (monotonicity): if nodeOf T lies in Z_n, then τ T = 0. Plays the role of sorry.

      def QOU.BraidKnot.CemeteryGroupEmergence.canonical (R : Type u) [CommRing R] (q : R) [C : CrystalGraphRealization R q] :
      CemeteryGroupEmergence R q

      The trivial model — a def, not an instance, and not "faithful".

      Its docstring said "Faithful instance. Carries the explicit research-grade conjecture as a sorry." Neither half was true. There is no sorry: it sets tauImage _ := 0, so monotone_under_extension is discharged by rfl on 0 = 0 and the inCemetery hypothesis is never used. The observation functor annihilates cemetery nodes here because it annihilates everything. A sorry would at least be visible to #print axioms; this was not.

      inCemetery v := ∃ T, nodeOf T = v is the one non-degenerate field, and it is the field the conjecture does not turn on: monotonicity is vacuous against a τ that is identically zero.

      As an unconditional instance it made tauImage_eq_zero_of_inCemetery and killSwitch_zero_mul — the kill-switch property the GS reduction engine is supposed to prune with — unconditional theorems about the zero map.

      Demoted the same way as ConfinementGradingCorrespondence.canonical (bean qou-fngs). Nothing consumed it: the class has no users outside this file.

      Still open: conj:cemetery-group-emergence — that Z_n = ker τ is monotone under crystal extension for a τ that is not identically zero.
