    The lex order on partitions of n is well-founded — 3.14's outer induction measure #

    Mathas' Lemma 3.14 is a double induction: lexicographic across shapes (case (i), ν >ₗ λ) and dominance within a fixed shape (case (ii), ν = λ with u ⊵ s). Neither half can even be stated as an induction until its measure is known to be well-founded.

    This file supplies the outer one.

    Why it is short, and where each piece came from #

    Both halves were already in the corpus and neither was built for this:

    • PartitionLex.partitionLexGt_irrefl and partitionLexGt_trans — the lex order is a strict order (proved when the order was introduced, to settle that Mathas' 3.12 step is lex and not dominance);
    • QOU.Mathlib.fintypeSizedDiagram — diagrams of a fixed size are a Fintype, transported from Nat.Partition n, built for the Young-lattice corner count.

    A strict order on a finite type is well-founded, so the two compose in one line. The point of the file is not the proof but that the composition exists: without a Fintype on shapes of fixed size, the outer induction of 3.14 would need a numeric measure and a monotonicity argument, and that is a real piece of work this corpus does not have to do.

    What is NOT here #

    The inner measure — dominance within a fixed shape — is a separate well-foundedness obligation and is not addressed in this file. Do not read this file alone as "3.14's induction is justified": it justifies one of its two axes.

    Both axes are now done, and the note above is scoped to this file rather than to the corpus. DominanceWellFounded.domGtOn_wellFounded supplies the inner axis (strict dominance on tabloids; domRel is a partial order and Specht.Tabloid does carry a Fintype — both questions this file left open), and MurphyInductionMeasure.murphyLex_wellFounded combines the two into the lexicographic product 3.14 actually runs on. The paragraph is kept because its file-local claim stays true; the open questions it names are answered next door.
