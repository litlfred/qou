    QOU.BraidKnot.SnWedderburnPartitionBridge — the partition-indexed isotypic projection family #

    The OV capstone (OVTopAssembly.snBlocks) needs a partition-indexed projection family of the symmetric-group algebra R[S_n] over a general characteristic-zero field R: a family of projections proj i (i : SpechtClassification.PartitionIndex n) onto blocks p i of R-dimension (dim Sᵘ)², summing to the identity. In OVTopAssembly this is a single opaque cited sorry (snBlocks). This file de-abstracts that gap: it isolates the one S_n-representation-theory fact genuinely absent from the pinned Mathlib, and discharges everything else — the entire passage from a Wedderburn ∏ Matrix algebra-equivalence to the projection bundle — by sorry-free linear algebra.

    This mirrors the merged SpechtDominanceCore / exists_linearOrder_of_partialOrder lever pattern: a precisely-named structural core, with all the surrounding plumbing proved.

    What is sorry-free here #

    • The mechanical extraction snBlocks_of_algEquiv (the payoff). Given any R-algebra isomorphism e : R[S_n] ≃ₐ[R] ∏ᵢ Matrix(Fin dᵢ) R, it produces the full snBlocks bundle: the coordinate idempotents pulled back along e are projections (IsProj) onto blocks of R-dimension dᵢ², and they sum to the identity. This is the bulk of the gap and it is pure linear algebra — transProj_* + coordProj_* + finrank_range_* below.
    • The assembled bridge snBridge — the snBlocks-shaped existence theorem, sorry-free modulo the single named core. This is exactly what OVTopAssembly.snBlocks consumes.

    The one named core (the genuine S_n-rep-theory gap) #

    • sn_isotypic_specht_split — over a characteristic-zero field R, the isotypic, rational, OV-labelled Wedderburn decomposition of R[S_n]: R[S_n] ≃ₐ[R] ∏_{i:PartitionIndex n} Matrix(Fin (dim S^{λ_i})) R, with block i the S^{λ_i}-isotypic component (matrix size = dim_R S^{λ_i}), carrying the central C₂ = Σₖ Xₖ² to the block-scalar family fun i => contentSqSum λᵢ • 1. The plain rational split sn_rational_specht_split is now a corollary of it (forget the C₂ clause), so the file has a single core, not two. This statement folds in the pieces of content absent from the pinned Mathlib:
      • (a) ℚ-rationality / absolute irreducibility. The division rings collapse to R itself — S_n-representations are defined over ℚ, so no genuine division-ring factors appear. This is the genuinely missing input: the char-0 (Maschke + rationality) descent. Correction (2026-08-09). An earlier wording of this bullet said Mathlib "has the matrix-product form only for an algebraically closed base". That is inaccurate, and it contradicted §"Whether Mathlib offers…" two paragraphs below, which correctly cites the general division-ring form. Mathlib's IsSemisimpleRing.exists_algEquiv_pi_matrix_divisionRing gives the ∏ Matrix decomposition as an algebra equivalence over any base — algebraic closure is needed only to collapse the 𝔇 i, which is exactly (and only) what is missing here. That rung is now wired as WedderburnSn.sn_wedderburnArtin_alg (sorry-free), so what this core still owes on the (a) front is the collapse 𝔇 i ≃ R alone, not the algebra-form split.
      • (b) the partition labelling of the block set (SpechtClassification.PartitionIndex n).
      • (c) the Okounkov–Vershik identification of block i with S^{λ_i} — matrix size = dim_R S^{λ_i} = #SYT(λ_i). -- Ref: [james1984representation], [sagan2001].

    Why one core, not two (over-generality note). An earlier shape split this into sn_absolutelyIrreducible_charZero (a partition-indexed split with abstract sizes d) plus sn_block_dim_eq_specht (d i = dim S^{λ_i}). The second is false as a ∀-over-splits claim: the index→block assignment of an arbitrary partition-indexed split is fixed only up to a permutation (Wedderburn determines the multiset of block sizes, not the labelling), so a relabeled split can have d i ≠ dim S^{λ_i} (e.g. at n = 6, swap the size-1 and size-5 blocks). Folding the alignment into the single existential core sn_isotypic_specht_split (from which the plain sn_rational_specht_split is derived) — which asserts the aligned split exists, a true statement — is the honest disposition; it avoids planting an over-general cited sorry (cf. the DominanceData.dom_colStab / seminormalVectors_span over-generality fixes).

    Whether Mathlib offers any S_n-rationality support #

    It does not. Mathlib (pinned v4.24.0) provides the abstract Wedderburn–Artin theorem in three forms — ring (IsSemisimpleRing.exists_ringEquiv_pi_matrix_divisionRing), algebra over an arbitrary base (…exists_algEquiv_pi_matrix_divisionRing), and the algebraically-closed specialisation (…_of_isAlgClosed, where the division rings collapse to the base field by Schur + algebraic closure) — but nothing about the rationality of the symmetric group's representations: no statement that S_n-irreducibles are defined over ℚ, no Specht module at all (a name search over the full import closure returns 0 hits for Specht), no Specht-module ↔ Wedderburn-block identification, no dim(λ) = #SYT(λ) at the block level. The core is therefore genuine.

    Measured residual (2026-08-09). With WedderburnSn.sn_wedderburnArtin_alg in place, the delta between what Mathlib + this corpus supply and what sn_isotypic_specht_split asserts is exactly four items, none of them the Wedderburn step itself:

    1. the division-ring collapse 𝔇 i ≃ R (ℚ is a splitting field for S_n);
    2. the reindexing Fin N ≃ SpechtClassification.PartitionIndex n;
    3. the size identification 𝔫 i = dim_R S^{λ_i};
    4. the C₂ = Σₖ Xₖ² block-scalar alignment ↦ contentSqSum λᵢ • 1 (the isotypic clause).

    Base ring (§7c) #

    variable {R : Type} [Field R] [CharZero R] for the rep-theory layer: Field is what the Wedderburn decomposition needs; CharZero is what the char-0 rationality (Maschke) and the brick-3 classification need. The mechanical §1 is over a generic [CommRing R] / [Field R] — pure linear algebra. No ℝ, no Real.*, no ordering on R: the construction is algebraic.

          5. The aligned bundle — isotypic projections + the C₂ block-decomposition #

          snBridge above gives the snBlocks bundle from a size-aligned split (block i has the right dimension (dim S^{λ_i})²). The capstone's decomp field needs strictly more: the central Jucys–Murphy element C₂ = Σ_k X_k² must be block-diagonal with eigenvalues contentSqSum λ_i,

          mulLeft C₂ = ∑ i, contentSqSum λ_i • proj i,

          and that holds only when block i is the S^{λ_i}-isotypic component — an isotypic-alignment, strictly stronger than size-alignment (distinct partitions can share dim S^λ, so a size-aligned split need not be isotypic-aligned). The decomp therefore cannot be layered on top of snBridge's size-aligned proj; the projection family and the eigen-decomposition must be produced together.
