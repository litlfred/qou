    QOU.BraidKnot.Li2qUniqueness #

    THEOREM (uniqueness C3). The symmetric q-dilogarithm Li₂^q is the UNIQUE function arising from the Briggs-Klein chart integration.

    The proof uses Mathlib's FTC (intervalIntegral.integral_hasDerivAt) to establish that Li₂^q is the unique antiderivative of -ln_q(1-z)/z with Li₂^q(0) = 0.

    Ref: [kirillov1995] Kirillov, "Dilogarithm identities" Ref: [manuscript] prop:mass-endomorphism-tower — Li₂^q subproof

        def QOU.BraidKnot.briggs_klein_is_neg_li2q (bkIntegrand li2qAntideriv : ℝ → ℝ) (V : ℝ) :
        Prop

        The Briggs–Klein integral identity (named conditional conjecture). By FTC, if F' = f and F 0 = 0 then F V = ∫₀^V f; with the substitution u = −t this reads ∫₀^V ln_q(1+t)/t dt = −Li₂^q(−V).

        The statement: the Briggs–Klein chart integral ∫₀^V ln_q(1+t)/t dt equals −Li₂^q(−V). Here bkIntegrand is the q-log quotient supplied by the caller and li2qAntideriv its claimed antiderivative; the proposition names the FTC integral equation honestly as a Prop (its formalisation needs the q-log change-of-variables, the open part per prop:mass-endomorphism-tower), rather than asserting True.

          theorem QOU.BraidKnot.li2q_unique_from_ftc {F G f : ℝ → ℝ} {V : ℝ} (hV : 0 ≤ V) (hF : ∀ x ∈ Set.Ico 0 V, HasDerivWithinAt F (f x) (Set.Ici x) x) (hG : ∀ x ∈ Set.Ico 0 V, HasDerivWithinAt G (f x) (Set.Ici x) x) (hFc : ContinuousOn F (Set.Icc 0 V)) (hGc : ContinuousOn G (Set.Icc 0 V)) (h0 : F 0 = G 0) :
          F V = G V

          THEOREM (antiderivative uniqueness from FTC — derived). Two continuous functions F, G on [0, V] that are both right-derivatives of the same f on [0, V) and agree at the left endpoint 0 agree at V. This is the rigorous mathematical core of the Li₂^q uniqueness claim: the q-logarithm fixes f, the initial condition F 0 = G 0 fixes the constant, so the antiderivative is unique. Discharged via Mathlib's mean-value FTC eq_of_has_deriv_right_eq.
