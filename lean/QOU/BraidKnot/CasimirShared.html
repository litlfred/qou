    QOU.BraidKnot.CasimirShared — promoted shared types for the braid/knot content blocks #

    Content-block .lean siblings cannot import one another, yet several blocks in content/.../braids-and-knots/ share a handful of carrier structures. This library module promotes those shared types into the QOU library so the deferred sibling files (q-casimir, q-casimir-exists, q-casimir-unique, knot-eigenbasis-complete-proof) can import QOU.BraidKnot.CasimirShared instead of re-declaring them.

    Two independent clusters live here, each over the ground ring its originating sibling used:

    • Casimir cluster (namespace QOU, ground ring R_q = ℚ(q) = RatFunc ℚ): QuantumSu2, QCasimirData, QCasimir. The quantum-group relation [E,F] = (K − K⁻¹)/(q − q⁻¹) divides by (q − q⁻¹), so the ground ring is the fraction field ℚ(q) (matching the canonical quantum-su2.lean).

    • Eigenbasis cluster (namespace QOU.Braiding, ground ring R_q = ℤ[q, q⁻¹] = LaurentPolynomial ℤ): HeckeAlgebra, BoundedPartition, SchurWeylDecomposition, AlexanderSurjectivity, MarkovTrace. These carry explicit q⁻¹ data fields (the Laurent ring has no native Inv).

              structure QOU.QCasimirData (qs : QuantumSu2) :
              Type u_1

              Parameter bundle for constructing the q-Casimir element.

              We carry explicit inverses of q and of (q − qInv) with two-sided witnesses, plus a central embedding ι : R_q →+* qs.Algebra, so that the construction never invokes a field-style ⁻¹ on an abstract coefficient.

              • qInv : R_q

                Explicit inverse of q in the ground ring.

              • qInv_left : self.qInv * qs.q = 1

                Left inverse witness for qInv.

              • qInv_right : qs.q * self.qInv = 1

                Witness that qInv is a right inverse.

              • ι : R_q →+* qs.Algebra

                Embedding of the ground ring into the algebra.

              • ι_central (r : R_q) (a : qs.Algebra) : self.ι r * a = a * self.ι r

                The image of ι lies in the centre of qs.Algebra.

              • invQm : qs.Algebra

                An algebra element that inverts ι (q - qInv).

              • invQm_left : self.invQm * self.ι (qs.q - self.qInv) = 1

                Left inverse witness for invQm.

              • invQm_right : self.ι (qs.q - self.qInv) * self.invQm = 1

                Witness that invQm is a right inverse.

              • invQm_central (a : qs.Algebra) : self.invQm * a = a * self.invQm

                invQm is central.
