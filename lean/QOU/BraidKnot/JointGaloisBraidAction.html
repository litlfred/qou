    class QOU.BraidKnot.JointGaloisBraidAction (n : ℕ) :
    Type 1

    Joint motivic-Galois $\times$ braid-group action on the bi-filtration $\mathcal{H}_q^{(n, K)}$, with the braid axis carried by the real symmetric group Equiv.Perm (Fin n).

    Conjectural class — see conj:joint-galois-braid-action.

    • BiFiltration : Type

      The knot-indexed bi-filtration $\mathcal{H}_q^{(n, K)}$.

    • GMot : Type

      The motivic Galois group $G_{\mathrm{mot}}$ (acts on the depth axis; no Mathlib/QOU infra — abstract, Tier 3).

    • galAct : GMot n → BiFiltration n → BiFiltration n

      The motivic-Galois action on the bi-filtration.

    • braidAct : Equiv.Perm (Fin n) → BiFiltration n → BiFiltration n

      The braid-group action on the bi-filtration, through the real symmetric group $S_n = $ Equiv.Perm (Fin n) (the braid image permuting Wedderburn cells).

    • equivariance (g : GMot n) (b : Equiv.Perm (Fin n)) (a : BiFiltration n) : galAct g (braidAct b a) = braidAct b (galAct g a)

      The conjecture (cross-axis equivariance, from the manuscript): the two actions commute, $g_{\mathrm{mot}}(\beta \cdot \alpha) = \beta \cdot g_{\mathrm{mot}}(\alpha)$ — equivalently the joint $G_{\mathrm{mot}} \rtimes S_n$ action stabilises each stratum.
