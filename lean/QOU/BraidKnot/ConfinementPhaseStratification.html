    Confinement Phase Stratification #

    The confinement locus Ω(P) = {q : confined(P, q)} is open in the generic q-locus; its complement is a real-algebraic stratification of codimension ≥ 1. Each connected component is a confinement phase on which active support, binding multiplicity μ, and σ_F are (locally) constant or real-analytic. Every confinement-framework theorem (level-sufficiency, shell-closure-stability, etc.) is implicitly scoped to a single phase; boundary crossings are deconfinement or regime switches.

    Real-axis stratification data (typeclass-supplied) #

    The phase-stratification analysis lives on the real q-axis, where the SDP constraint matrices are continuous in q. The underlying ground ring R_q = LaurentPolynomial ℤ is purely algebraic; the maps confinedReal, muReal, sigmaFReal are the analytic specialisations obtained by evaluating SDP-derived quantities at real q.

    These maps are not closed-form: they depend on the (numerical) SDP solution at each q. Rather than opaque-stubbing them, we package them as a typeclass HasRealAxisData so each particle's data is supplied by the caller (typically from a numerical SDP solver, e.g. CVXPY).

              §1 SDP regularity hypotheses #

              The three stratification claims (open locus, μ-constancy on components, σ_F-continuity) are all consequences of Slater-strict SDP feasibility plus continuity of the constraint matrices in q (Boyd–Vandenberghe §5.6). We therefore package the genuine analytic inputs — not the conclusions — as a typeclass, and derive the trio from them. This keeps the class honest: its fields are the hypotheses of the stratification theorem, and each theorem below performs a real inference (the SDP-sensitivity step is the residual sorry), rather than projecting an assumed conclusion.

              class QOU.BraidKnot.HasSDPRegularity (P : ConfinedParticle) [HasRealAxisData P] :
              Prop

              SDP regularity hypotheses — the genuine inputs of the phase-stratification theorem. An instance asserts that confinement on the real axis is Slater-strict SDP feasibility, and that this strict-feasibility set is open with the value/multiplicity data locally regular. These are hypotheses (the "IF" of the stratification claim), not the topological conclusions.

              • confined_iff_feasible (q : ℝ) : confinedReal P q ↔ StrictlyFeasible P q

                Confinement at real q is exactly Slater-strict SDP feasibility.

              • feasible_isOpen : IsOpen {q : ℝ | StrictlyFeasible P q}

                The strictly-feasible set is open (Slater strictness is an open condition when the SDP data is continuous in q).

              • mu_locally_constant (C : Set ℝ) : IsConnected C → (∀ q ∈ C, StrictlyFeasible P q) → ∀ (q₁ q₂ : ℝ), q₁ ∈ C → q₂ ∈ C → muReal P q₁ = muReal P q₂

                On a connected set of strictly-feasible points the active-support cardinality (hence μ) does not jump.

              • sigmaF_continuousOn : ContinuousOn (sigmaFReal P) {q : ℝ | StrictlyFeasible P q}

                The value data σ_F is continuous on the strictly-feasible set.
