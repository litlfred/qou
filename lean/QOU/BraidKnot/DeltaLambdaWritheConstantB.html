    theorem QOU.BraidKnot.constant_b_from_writhe_proportional {R : Type u_1} [CommRing R] (base : ℤ → R) (κ : R) (Z N : ℤ) :
    base (Z + N) + κ * (↑Z - ↑N) - (base (N + Z) + κ * (↑N - ↑Z)) = 2 * κ * (↑Z - ↑N)

    The constancy mechanism (proved; the proportionality is the hypothesis). Model the residual as r Z N = base(Z+N) + κ·(Z−N) — an isoscalar baseline plus an isovector term linear in Z−N with an A-independent coefficient κ (the structural ansatz suggested by the writhe's universal isospin slope). Then the mirror difference is 2κ·(Z−N), with κ the A-independent slope: this is exactly why the measured b (= the per-T₃ slope = 4κ) is constant in A.

    The file asserts nothing about the value of κ (the open per-writhe coefficient, κ = b/4 ≈ −0.437); only that if the odd part is writhe-proportional with A-independent κ, the mirror slope cannot depend on A.
