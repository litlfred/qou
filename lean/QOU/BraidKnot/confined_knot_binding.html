    QOU.BraidKnot.confined_knot_binding #

    Canonical Lean for content block prop:confined-knot-binding.

    The substantive, parameter-free content of the .md proof is the extremal cancellation of the symmetric crossing: for the proton–neutron symmetric mixing ½(σ + σ⁻¹), i.e. crossing parameters (c, d) = (1, −H_A/2) with H_A = q − q⁻¹, the symmetric and alternating one-dimensional Wedderburn channels cancel exactly, so the binding volume is carried entirely by the standard representation.

    This file derives that cancellation directly over a generic commutative ring (per AGENTS.md §7c). The previous encoding axiomatised a binding-energy tautology E_bind = |tr_M(β)|·m_e·ρ_K as a class field and projected it (:= ⟨ctx.claim_i, ctx.claim_ii⟩); that was a vacuous self-assuming projection and is removed.

    -- Ref: [manuscript] quantum-observable-universe/braids-and-knots/confined-knot-binding.md

    §7c: the cancellation below is exact in q — χ_sym + χ_alt = 0 at (c, d) = (1, −H_A/2) — and needs only a commutative ring in which q is a unit (carried as q : Rˣ, so ↑q⁻¹ is a Units coercion) and 2 is invertible (the H_A/2 halving, written ⅟(2 : R)). Invertibility of 2, not characteristic zero and not archimedean: no ordering, radical or Real.* construct appears, so the statements hold over ℤ[1/2][q, q⁻¹] and the archimedean evaluation at q_0 happens downstream.

          theorem QOU.BraidKnot.confined_knot_extremal_cancellation {R : Type u_1} [CommRing R] [Invertible 2] (q : Rˣ) :
          chiSym q 1 (-heckeHA q * ⅟2) + chiAlt q 1 (-heckeHA q * ⅟2) = 0

          Extremal cancellation of the symmetric crossing.

          For the symmetric mixing (c, d) = (1, −H_A/2), the symmetric and alternating one-dimensional channels are negatives of each other, so χ_sym + χ_alt = 0. Since the Wedderburn weights of the two one-dimensional irreps coincide (W_sym = W_alt, both = q²/(q⁴ + 4q² + 1)), the weighted contribution W_sym·χ_sym + W_alt·χ_alt vanishes — the binding volume is carried entirely by the standard representation.

          theorem QOU.BraidKnot.confined_knot_weighted_cancellation {R : Type u_1} [CommRing R] [Invertible 2] (q : Rˣ) (W : R) :
          W * chiSym q 1 (-heckeHA q * ⅟2) + W * chiAlt q 1 (-heckeHA q * ⅟2) = 0

          Weighted extremal cancellation with equal one-dimensional Wedderburn weights W_sym = W_alt = W.

          Because the two one-dimensional channels carry the same Plancherel weight, the weighted sum factors as W · (χ_sym + χ_alt), which vanishes by confined_knot_extremal_cancellation.
