    The twist scalar θ_λ² on the bounded presentation #

    The last piece of the Jucys–Murphy chain begun in HeckeBoundedJucysMurphy.lean: from the per-element content eigenvalues to the full twist acting by θ_λ² = q^{2c(λ)}.

    Nothing about prod_jmEigen needed porting #

    HeckeSeminormalWeight.prod_jmEigen — that the content eigenvalues multiply to θ_λ² — mentions no HeckeGenerators at all. It is a statement about the eigenvalue function and the combinatorics of cells, so the bounded versions below reuse it unchanged. Only the two theorems that actually touch a presentation had to move.

    The payoff, and an independent check #

    For λ = (2,1) the content sum is 0 + 1 + (−1) = 0, so θ_λ² = q⁰ = 1: the full twist of B₃ acts trivially on the seminormal vector. That is a falsifiable prediction, and stdTwo_fullTwist_eq_one confirms it by a completely different route — a direct matrix computation that (σ₀σ₁)³ = 1, with no Jucys–Murphy input.

    This mirrors the falsifiability check HeckeSeminormalWeight runs for the one-row block against theta_single_row_sq, but on a 2-dimensional module — which the unbounded presentation cannot host at all (stdTwo_no_stable_extension).

    §3 The independent check #

    source
    theorem QOU.BraidKnot.Hecke.stdTwo_fullTwist_eq_one {K : Type u_4} [Field K] (q : K) (hq : q ≠ 0) :
    (stdTwo0 q * stdTwo1 q) ^ 3 = 1

    The falsifiability check. (σ₀σ₁)³ = 1 for the explicit 2×2 seminormal pair, by direct matrix computation — no Jucys–Murphy input whatsoever.

    This is the same number θ_{(2,1)}² = 1 predicts, reached by a completely different route, so §1's conclusion is constrained by an independently-proved case rather than free.

    The two routes agree. The Jucys–Murphy product of the eigenvalues on e₀ is 1 · q² · q⁻² = 1, and the full twist really is the identity. Both sides are θ_{(2,1)}².
