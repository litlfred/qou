    structure QOU.BraidKnot.DistinguishedKnotIdeal (k : ℕ) (R : Type u_1) :
    Type u_1

    The depth-k distinguished knot ideal as a central projector.

    Fields:

    • central_projector_value: amplitude of the central projector e_K at a partition (proxy for the full Hecke-algebra projector in the abstract setting), valued in the generic base ring R.
    • knot_label: the name of the distinguished knot ("4_1" at k = 3 under the textbook weight dim_q²/[n]_q! — the label is family-relative, see the module docstring; pending for k = 1, k = 2).

    §7c: the FR-pullback weight algebra below is pure field arithmetic (a dim_q²·χ / ([n]_q!·Z) ratio), so it is stated over a generic {R : Type*} [Field R]. This module is now wholly on the algebraic side of the substrate→archimedean wall: the empirical decimal variance records (ordered ℝ literals) that used to sit further down have been split out into the sibling QOU.BraidKnot.DepthStratifiedFrobeniusReciprocityVariance.

    • central_projector_value : R
    • knot_label : String

          noncomputable def QOU.BraidKnot.frPulledBackWeight {R : Type u_1} [Field R] (dim_q_sq n_q_fact chi_lambda_eK z_normalization : R) :
          R

          The FR-pulled-back Wedderburn weight at depth k: dim_q²(λ) · χ^λ(e_{K_k*}) / ([n]_q! · Z_normalization)

          where Z_normalization is the partition-depth sum of dim_q²(μ) · χ^μ(e_{K_k*}).

          Verifiable identity: when χ^λ(e_K) = 1 (trivial projector, i.e. K is "transparent"), the FR weight reduces to the uniform weight times the depth-sum reciprocal.

          • QOU.BraidKnot.frPulledBackWeight dim_q_sq n_q_fact chi_lambda_eK z_normalization = dim_q_sq * chi_lambda_eK / (n_q_fact * z_normalization)

              noncomputable def QOU.BraidKnot.depthStratifiedFR_chiralityIdeal (R : Type u_1) [Field R] :
              DepthStratifiedFrobeniusReciprocity R

              Chirality-ideal model with the predicate read as its own witness. knot_ideal_at_k is real at k = 3 (chirality_ideal_4_1) and a "?"-labelled zero projector elsewhere. The conjectural field is not: fr_pullback_at_low_k is defined to be fun q _k => q = 1, so fr_pullback_classical : ∀ k, fr_pullback_at_low_k 1 k unfolds to 1 = 1 and closes by rfl, uniformly in k. No Frobenius reciprocity, induced representation or depth stratum is encoded; the field is satisfied by choosing the predicate to be the equation the field asserts.

              The classical-limit case genuinely is provable in principle, via Mathlib's Representation.induced plus the pending Specht-module API — that is what a real model would have to supply here.

              A def, not an instance, since 2026-08-24, and given a name: it was anonymous, so resolution supplied it for every field under the generated name instDepthStratifiedFrobeniusReciprocity.

              Callers name it: letI := depthStratifiedFR_chiralityIdeal R.
