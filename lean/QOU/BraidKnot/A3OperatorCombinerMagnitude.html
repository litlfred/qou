    QOU.BraidKnot.A3OperatorCombinerMagnitude — the operator-valued branching #

    combiner supplies zero additional magnitude over the scalar Markov trace

    The A=3 magnitude question (ROUTE 1) #

    The A=3 triton Δ_λ magnitude factor r* = μ₃/c₃ ≈ 1.585 (μ₃ = +0.4708 the target simplex moment; c₃ = 0.297 = E₀·(1 − τ_Borr) the derived single Markov-trace near-miss) is bracketed out of every single-Markov-trace ingredient. The surviving hypothesis (bean qou-tnvz) is that the missing 1.585× is a genuinely many-body / cross-channel object.

    ROUTE 1 proposed: replace the scalar Σ_λ y_λ χ_λ Frobenius pairing with the operator-valued branching combiner — the H₉ → H₆ → H₃ (peel one nucleon at a time) Wenzl branching, keeping the operator (matrix) structure instead of collapsing to a scalar trace at each level — on the premise that a single trace loses the cross-channel information the branching retains.

    What this file proves — the structural claim, formalized FIRST #

    The premise is false at the observable level, and this file proves why and by how much.

    The observable read off the operator-valued combiner is a cyclic, additive trace τ of the assembled operator, sliced by the isotypic projector family {P i} of the branching (i = (ξ,ν)). The invariant that governs it is the partition-of-unity trace collapse:

    τ X = Σ i, τ (P i · X · P i) (trace_partition_collapse)

    for any orthogonal resolution of unity (P i · P j = 0 for i ≠ j, Σ P i = 1) and any cyclic additive τ. Consequently the block-resolved readout of the operator combiner equals the scalar Markov trace exactly — the per-block weight is identically 1:

    operatorCombinerReadout = τ X (operatorCombiner_eq_scalarTrace)

    so retaining the operator structure supplies a factor of exactly 1.0 (0 % of the needed +58.5 %; gap identically 0).

    The only way a block decomposition can produce a value ≠ τ X is a non-uniform per-block weight w i ≠ 1 — and the deviation is exactly

    (Σ i, w i · τ (P i·X·P i)) − τ X = Σ i, (w i − 1) · τ (P i·X·P i) (weightedReadout_sub_trace)

    which vanishes when the weights are uniform (weightedReadout_eq_of_uniform) and, contrapositively, a magnitude change forces a non-uniform weight (magnitude_change_forces_nonuniform_weight).

    That non-uniform per-block weight is precisely the Δ_λ per-partition weight — a different functional than the trace, not something any trace-based operator combiner "retains". A Δ_λ fixed by inverting μ₃ is a fit (the standing Δ_λ gate), not supplied by ROUTE 1. Verdict: scope-(b) structural exclusion; cited invariant = the partition-of-unity trace collapse below.

    Scope and base ring (§7c) #

    Generic commutative ring R as the trace codomain, generic (noncommutative) ring A as the operator algebra. No archimedean structure, no ℝ, no fitted constant. Idempotency of P i is not assumed — only an orthogonal resolution of unity — so the identity holds for any resolution, the isotypic projectors being the intended case (mirrors InterfaceOperatorBlockDiagonal).

    theorem QOU.BraidKnot.A3OperatorCombinerMagnitude.trace_partition_collapse {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] {ι : Type u_3} [Fintype ι] (τ : A →+ R) (hcyc : ∀ (x y : A), τ (x * y) = τ (y * x)) (P : ι → A) (horth : ∀ (i j : ι), i ≠ j → P i * P j = 0) (hsum : ∑ i : ι, P i = 1) (X : A) :
    τ X = ∑ i : ι, τ (P i * X * P i)

    Partition-of-unity trace collapse (the cited invariant).

    Let {P i} be an orthogonal resolution of unity in A (P i · P j = 0 for i ≠ j, Σ i, P i = 1), and let τ : A →+ R be cyclic. Then the trace of any X equals the sum of its diagonal block compressions:

    τ X = Σ i, τ (P i · X · P i).

    Off-diagonal blocks vanish under the cyclic trace; the per-block weight is identically 1. This is the W = β = 1 specialisation of the interface-operator block-diagonality, isolated here as the magnitude invariant for ROUTE 1.

        Contrapositive — a magnitude change forces a non-uniform weight.
