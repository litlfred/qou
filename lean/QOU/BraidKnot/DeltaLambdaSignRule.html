                                        theorem QOU.BraidKnot.DeltaLambdaSignRule.hecke_character_diag_odd (q : ℝ) (n : ℕ) (hn : Odd n) :
                                        q ^ n + (-(1 / q)) ^ n = q ^ n - (1 / q) ^ n

                                        Standard-rep character identities — formalised in the Hecke compute #

                                        The following exact characters on the 2-dimensional standard block V_{(2,1)} require the Hecke/Hoefsmit representation as Lean infrastructure to state faithfully, which this file does not build:

                                        • χ^{(2,1)}((σ₁σ₂⁻¹)³) = 2 − 3h⁴ − h⁶ (Borromean; h = q − q⁻¹) • χ^{(2,1)}(σ₀σ₁) = −1 (Hopf link) • χ^{(2,1)}(σ₀σ₁σ₀) = 0 (trefoil element) • tr_M(atom_braid A, q) = p_A(u)/d_A(u), p_A, d_A ∈ ℤ[u] (Habiro rational) • interface multiplicity = dim(V_{(2,1)}) = 2 (confinement SDP)

The scalar arithmetic that does not need the representation is captured by hecke_character_diag_odd above. -- Ref: [ram1997] https://doi.org/10.1007/BF02677006
