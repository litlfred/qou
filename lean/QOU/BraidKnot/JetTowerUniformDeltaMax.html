    QOU.BraidKnot.JetTowerUniformDeltaMax — uniform per-level binding bound #

    The brane-tower mass series

    𝔪(ρ) = 𝔪⁽⁰⁾(ρ) + Σ_{n ≥ 1} ℏ_q^{2n} · Δ⁽ⁿ⁾(ρ)

    converges geometrically (per prop:jet-tower-convergence) under the uniform-boundedness hypothesis

    ∀ n ≥ 1, |Δ⁽ⁿ⁾(ρ)| ≤ Δ_max(ρ).

    This file axiomatizes the hypothesis as a class per AGENTS.md §3b. The conditional geometric-tail bound is then provable from the class instance plus standard real analysis.

    Formal-chain version. Lives under lean/QOU/ and is compiled by lake build. The co-located documentation stub at braids-and-knots/jet-tower-uniform-delta-max.lean mirrors this.

    class QOU.BraidKnot.JetTowerUniformDeltaMax (ρ : Type u_1) :
    Type

    The conjecture, encoded as a class.

    A JetTowerUniformDeltaMax ρ instance asserts the existence of a finite real delta_max bounding the per-level binding contributions delta n for all n ≥ 1. The unproved input is the existence of the instance; downstream conditional theorems (geometric-tail truncation bounds) are then fully verified parametrically.

    • delta : ℕ → ℝ

      The per-level binding contribution at level n.

    • delta_max : ℝ

      The asserted uniform bound.

    • delta_max_nonneg : 0 ≤ delta_max ρ

      Non-negativity of the bound.

    • uniform_bound (n : ℕ) : 1 ≤ n → |delta ρ n| ≤ delta_max ρ

      The uniform-bound hypothesis.

        Conditional theorem: under the uniform-bound conjecture, the geometric-tail bound holds.

        For a substrate parameter q with 0 < ℏ_q² < 1, the tail of the brane-tower mass series after the first N terms is bounded by delta_max · ℏ_q^{2(N+1)} / (1 - ℏ_q²).
