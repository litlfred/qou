    Bridging the two standard-Young-tableau encodings #

    The corpus carries two StandardYoungTableau structures, and the RSK sum-of-squares result is stated in one while the hook-length chain lands in the other:

    structure entries packaging counted by carries
    QOU.BraidKnot.StandardYoungTableau μ < μ.card (0-indexed) raw entry + inj_on / row_strict / col_strict / zero_off numSYT OVTopAssembly.sum_numSYT_sq_eq_factorial (RSK)
    QOU.Mathlib.StandardYoungTableau μ Set.Icc 1 μ.cells.card (1-indexed) SemistandardYoungTableau + Set.BijOn numStandardYoungTableaux numSYTenum_eq_numStandardYoungTableaux (hook-length / sytDim)

    Because the two are distinct types, neither result transfers to the other. This file builds the bridge, whose payoff is twofold:

    • RSKBurnsideTarget.RSKBurnsideHolds — ∑_{p ⊢ n} dimSYT p ² = n!, which the corpus records as "not yet a theorem … the multi-session next step", becomes a reindexing of the (already proved) OVTopAssembly.sum_numSYT_sq_eq_factorial;
    • the Plancherel normalisation Σ_λ (f^λ)² = k! in the sytDim/partsOf encoding, which is the single open premise of YoungDiagramTailFirstInstance.nuV_top_closed_form.

    This is not the burnside roadmap's bridge (1) (numSYT_mul_hookProduct, the hook-length formula inside the custom-Partition encoding) — that gap is orthogonal and stays open.

    This file #

    The ≤ direction: the 1-indexed encoding embeds into the 0-indexed one by entry ↦ entry − 1, so numStandardYoungTableaux μ ≤ numSYT μ. The reverse inequality needs the pigeonhole (inj_on + lt_card on an n-element cell set forces surjectivity onto {1,…,n}) together with weak-row monotonicity from adjacent strictness; it is the remaining half of the bridge.

    Corrections (2026-08-23) #

    Three statements above describe the state of the corpus when this file was written and no longer hold. The text is left in place; each is superseded as follows.

    • "which the corpus records as 'not yet a theorem … the multi-session next step'" — RSKBurnsideTarget no longer records that (it was corrected the same day), and RSKBurnsideHolds is a theorem for every n: QOU.Mathlib.rskBurnsideHolds, from the Robinson–Schensted correspondence.
    • "the single open premise of YoungDiagramTailFirstInstance.nuV_top_closed_form" — discharged by PlancherelNormalisation.nuV_top_closed_form_unconditional.
    • "that gap is orthogonal and stays open" — the orthogonality stands; the gap does not. QOU.BraidKnot.numSYT_mul_hookProduct_partition proves exactly the named bridge (1) (numSYT (toYoungDiagram Λ) * Λ.hookProduct = n!) and is axiom-clean, as is its payoff dimIrrep_eq_numSYT.

    And in This file below, "it is the remaining half of the bridge": the reverse inequality is proved, as the equality QOU.BraidKnot.numSYT_eq_numStandardYoungTableaux in NumSYTBridge. This file still carries only the ≤ direction, which is what makes the sentence easy to miss.
