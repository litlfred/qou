    Keystone value step, input (B): the Perron–Frobenius ground state is d_q (§3b-cond) #

    KeystoneSelfDualSpectralNarrowing.lean proved the (C) leg of the value-step reframe: a self-dual S (S² = C) has S⁴ = 1, eigenvalues are 4th roots of unity, and on the C = +1 self-dual sector they tighten to ±1 (eigenvalue_selfdual_sector_pm_one). What that leg leaves open — and what this file closes, conditionally — is input (B): why the +1 ground state of that sector is the quantum-dimension vector d_q and not some other positive eigenvector.

    The answer is the Perron–Frobenius / Ocneanu–Wenzl selection: the fusion (branching) operator N is entrywise non-negative, and a non-negative operator has, up to scale, a unique positive eigenvector at its Frobenius eigenvalue — the Markov-trace weights, i.e. d_q (Ocneanu; Wenzl). This is a cited theorem, not one this file re-proves; so it is axiomatised as a §3b-cond primary conjecture class PerronFrobeniusGroundState, following the repo's conditional-class convention: a Prop-valued hypothesis over the explicit data N, rho, d (as HeckeBraid (H : …) : Prop in IwahoriHeckeAPI.lean), whose content field pf_proportional carries the PF up-to-scale uniqueness as an explicit, parameter-quantified hypothesis (§3b-tax: a primary conjecture — it binds no other conjecture class — with real content, not True).

    What is derived (sorry-free, genuine work — not a self-assuming projection). Given the class, eq_d_of_normalized proves that a positive ground eigenvector normalised to agree with d at any one index is equal to d — sharpening the cited "proportional" input to a unique pin. The derivation is real: it exhibits the proportionality constant, evaluates at the normalising index, and cancels the (positive, hence nonzero) d-component to force c = 1. This is the §3b-cond non-degeneracy requirement (the class carries the hypothesis — PF up-to-scale uniqueness — and the theorem derives the strictly stronger normalised conclusion — the pin to d_q).

    Scope. Keystone value step (s013), input (B). Conditional on the class instance (the physical fusion category being the one whose PF eigenvector is the Hecke d_q), which is the owner-gated open content (narrow Subgoal-2 reversal, #2503/#2524). A Unit-block model instance over any ordered field witnesses non-vacuity (the conditional results are not conditional-on-False).

    Base ring: an ordered field [Field R] [LinearOrder R] [IsStrictOrderedRing R] — positivity of the quantum dimensions (0 < d i) is genuinely archimedean (§7c); the d_q numerical evaluation at q₀ lives downstream. (LinearOrderedField is deprecated as a class binder in Mathlib v4.24.0.)

    class QOU.BraidKnot.Keystone.PerronFrobeniusGroundState {ι : Type u_1} {R : Type u_2} [Fintype ι] [DecidableEq ι] [Field R] [LinearOrder R] [IsStrictOrderedRing R] (N : Matrix ι ι R) (rho : R) (d : ι → R) :
    Prop

    Perron–Frobenius / Ocneanu–Wenzl ground-state selection (§3b-cond primary conjecture, Prop).

    A Prop-valued hypothesis class over the explicit data N (fusion operator), rho (Frobenius eigenvalue), d (quantum-dimension vector) — the repo's conditional-class convention (HeckeBraid (H : …) : Prop), keeping the data explicit and the conjectural assumption proof-irrelevant. Content: N non-negative, d positive, d the Frobenius eigenvector, and — the conjectural field — that any positive eigenvector at rho is a scalar multiple of d (PF up-to-scale uniqueness). Primary conjecture (binds no other conjecture class); the content is the parameter-quantified pf_proportional, not a True/empty marker.

    • N_nonneg (i j : ι) : 0 ≤ N i j

      N is entrywise non-negative (the Markov / fusion structure).

    • d_pos (i : ι) : 0 < d i

      The quantum dimensions are positive.

    • d_eigen : N.mulVec d = rho • d

      d is the Frobenius eigenvector: N d = rho · d.

    • pf_proportional (v : ι → R) : (∀ (i : ι), 0 < v i) → N.mulVec v = rho • v → ∃ (c : R), v = c • d

      Cited PF / Ocneanu–Wenzl uniqueness (the conjectural input): every positive eigenvector at the Frobenius eigenvalue is a scalar multiple of d.
