    (fun (x : 𝕜) => h x * a x / (h x * b x)) = fun (x : 𝕜) => a x / b x

    Shared-factor cancellation (pure function identity). A ratio (h·a)/(h·b) equals a/b wherever the shared factor h is nonzero — the anchor cancels. Stated over any field, pointwise.

    theorem QOU.BraidKnot.Keystone.logDeriv_ratio_indep_of_shared_factor (h a b : ℝ → ℝ) (hh : ∀ (x : ℝ), h x ≠ 0) :
    (logDeriv fun (x : ℝ) => h x * a x / (h x * b x)) = logDeriv fun (x : ℝ) => a x / b x

    Pin-sensitivity of a ratio is anchor-independent. The logarithmic derivative of the ratio (h·a)/(h·b) equals that of a/b: the shared factor h — e.g. the absolute anchor ℏ_q⁻² — makes zero contribution to the ratio's pin-sensitivity. This is the generalized Habiro pin-robustness: W_λ and every mass ratio, sharing the anchor, are blind to it.
