    noncomputable def QOU.BraidKnot.qInteger (q : ℝ) (n : ℕ) :
    ℝ

    The symmetric q-integer [n]_q = (q^n - q^{-n})/(q - q^{-1}) as a real-valued function.

    • n = 0: returns 0
    • q = 1: returns n (classical limit)
    • otherwise: symmetric q-integer formula.

    Stated over ℝ; the same definition transports to any field where (q - q⁻¹) is invertible.

    Equations
    • QOU.BraidKnot.qInteger q n = if n = 0 then 0 else if q = 1 then ↑n else (q ^ n - q ^ (-↑n)) / (q - q⁻¹)

        class QOU.BraidKnot.Li2qPhiqBarSymmetrization :
        Type

        The bar-symmetrization conjecture as a Lean class.

        For each n ≥ 1 and each q ∈ R, the bar-symmetrized Faddeev coefficient equals the symmetric Li_2^q coefficient.

        Class fields:

        • bar_holds_at: predicate naming the (q, n) pairs where the identity is verified.
        • bar_holds_at_classical: discharges all n at q = 1 (the classical-limit case, verified via li2qCoeff_at_q_eq_one).

        Downstream theorems consume the class via [Instance] per AGENTS.md §3b-cond.

        • bar_holds_at : ℝ → ℕ → Prop

          The (q, n) pairs where the bar-symmetrization identity is established.

        • bar_holds_at_classical (n : ℕ) : bar_holds_at 1 n

          At q = 1, the identity holds for all n via the verified classical-limit chain.

          def QOU.BraidKnot.li2qPhiqBarSymmetrization_qEqOne :
          Li2qPhiqBarSymmetrization

          Model with the predicate read as its own witness. bar_holds_at is defined to be fun q _n => q = 1, so the conjectural field bar_holds_at_classical : ∀ n, bar_holds_at 1 n unfolds to 1 = 1 and closes by rfl, uniformly in n. Nothing about bar symmetrisation, the Faddeev coefficients or li2qCoeff is encoded; the field is satisfied by choosing the predicate to be the equation the field asserts.

          The classical-limit fact it gestures at is proved in this file, unconditionally and without the class: li2qCoeff_bar_invariant_at_q_eq_one. This model does not use it, and a real model would.

          A def, not an instance, since 2026-08-24, and given a name: it was anonymous, so resolution supplied it under the generated name instLi2qPhiqBarSymmetrization.
