    QOU.BraidKnot.GradedTraceResidueSplit — graded-trace residue split #

    The Markov trace on the filtered Hecke algebra H_n(q) decomposes canonically as

    tr_M(T_w) = tr_gr(σ(T_w)) + Res_GB(T_w)

    where σ is the symbol map to the associated graded algebra and Res_GB is the sum of rewriting-defect residues at root-of-unity poles. Filtered-algebra analogue of Strutinsky's smooth-plus- oscillating nuclear-energy decomposition.

    Pre-Archimedean. Polymorphic in the ground field R; the opaque trace declarations carry q : R and return values in R, not ℝ. Per QOU.GroundRingAnnotations, this stub is in the formal pre-Arch chain.

    Formal-chain version. Lives under lean/QOU/ and is compiled by lake build. The co-located documentation stub at braids-and-knots/graded-trace-residue-split.lean mirrors this.

            class QOU.BraidKnot.GradedTraceResidueSplit (R : Type u) [CommRing R] :
            Type u

            Graded-trace residue split. Polymorphic in the ground field R.

            The Markov trace decomposes as smooth (graded) + oscillating (residue), the categorical analogue of Strutinsky's macroscopic + shell-correction split.

            • q : R
            • element : Unit
            • smooth : R
            • oscillating : R
            • total : R
            • split_identity : total = smooth + oscillating
            • smooth_is_graded : smooth = gradedTrace q (element R)
            • oscillating_is_residue : oscillating = gbResidue q (element R)
