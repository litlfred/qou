    Three Calibration Inputs #

    Pins the QOU framework to exactly three external numerical inputs:

    • m_e (electron mass, leptonic scale)
    • m_μ / m_e (substrate parameter via Vol(4_1) / ℏ_q²)
    • Q_β(n) (free-neutron β-decay Q-value, hadronic scale)

    Beyond these three, no further empirical input is admissible. This file provides the placeholder declarations referenced by prop:three-calibration-inputs; the calibration constants themselves are CODATA values (axioms), not derived.

    Type

    The three calibration inputs as opaque real-valued constants. Each is a CODATA measurement; the framework axiomatises their existence and relation to the categorical action.

    The "axiom" here is that exactly three real-valued external inputs are admissible. Any predicate / observable in the framework must factor through these three plus q₀.

    • m_e : ℝ
    • m_mu_over_m_e : ℝ
    • Q_beta_n : ℝ
    • m_e_pos : 0 < self.m_e

      All three calibrations are positive.

    • m_mu_ratio_pos : 0 < self.m_mu_over_m_e
    • Q_beta_n_pos : 0 < self.Q_beta_n
    • q_zero : ℝ

      The substrate parameter is determined by the dimensionless ratio.

      Three-calibration-inputs proposition (pattern C — named, not asserted).

      Every numerical observable of the framework factors through the three calibration inputs (q₀, m_e, Q_β(n)): there is a function f : ℝ → ℝ → ℝ → ℝ of the three calibrations reproducing the observable's value obs. We name this factorization claim as a Prop over an abstract observable obs : ℝ — honestly stating the conditional conjecture rather than discharging it with a vacuous : True := trivial. The framework realises it case-by-case (every numerical comparison cites the calibration block); an inhabitant of this Prop for a given obs is the per-observable factorization witness.
