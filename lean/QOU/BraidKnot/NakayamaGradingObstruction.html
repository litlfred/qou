      def QOU.BraidKnot.NakayamaGradingObstruction.rowGradingSign (R : Type u_1) [CommRing R] (k : ℕ) :

        theorem QOU.BraidKnot.NakayamaGradingObstruction.rowGradingSign_eq_nakayama_iff_even (k : ℕ) :
        rowGradingSign ℤ k = nakayamaSymmetricValue ℤ ↔ Even k

        The row grading matches the symmetric-Nakayama value ONLY on even degree. Over any CommRing, (−1)^k = 1 ↔ Even k. So the sign carrier g_ρ agrees with a symmetric algebra's Nakayama automorphism (ν = id, value +1) precisely on the bar-even sector.

        theorem QOU.BraidKnot.NakayamaGradingObstruction.rowGradingSign_ne_nakayama_of_odd (k : ℕ) (hk : Odd k) :
        rowGradingSign ℤ k ≠ nakayamaSymmetricValue ℤ

        The obstruction (odd sector). On any partition with odd n(λ) = k, the row grading g_ρ takes the value −1, which differs from the symmetric-Nakayama value +1. Hence g_ρ is NOT the Nakayama automorphism of a symmetric algebra — this refutes Angle A on the algebras (R_n, ℂS_n, H_n(q)) that carry the partition-indexed simples.

        theorem QOU.BraidKnot.NakayamaGradingObstruction.rowGradingSign_nontrivial_at_three :
        rowGradingSign ℤ 3 ≠ nakayamaSymmetricValue ℤ

        g_ρ is a nontrivial ℤ/2 grading, so it is not the identity value +1 everywhere. Concretely n([1,1,1]) = 3 is odd (for λ = [1^3] ⊢ 3), witnessing a degree where the row grading is −1 ≠ +1. This is the smallest concrete obstruction.
