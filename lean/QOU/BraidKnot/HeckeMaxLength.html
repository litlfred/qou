    QOU.BraidKnot.HeckeMaxLength — a maximal-length element of a finite set of permutations #

    Murphy's leading term is d(s)⁻¹ · w_λ · d(t), where w_λ is the longest element of the Young subgroup S_λ. That object exists nowhere in this corpus and nowhere in the pinned Mathlib: measured against a positive control, CoxeterSystem is 3 oleans, IsReduced 58, and longestElement is 0. So the (C1) triangularity argument has a missing prerequisite, and this file supplies the part of it that is actually needed.

    Existence, not uniqueness — and why that is enough #

    The classical statement is that a finite Coxeter group has a unique longest element. Uniqueness is a real theorem and is not proved here.

    It is also not required. The consumer is Triangular (SpechtStandardBasis), whose three fields ask for some injective lead with a unit diagonal and support bounded above — not for a canonical one. So a choice of maximiser suffices, and existence of a maximiser in a nonempty finite set is elementary.

    Stating this explicitly because the gap between "exists" and "the" is exactly where a formalisation quietly acquires an unproved uniqueness assumption.

    What this does NOT settle #

    lead_inj — that distinct tableau pairs give distinct leading permutations — is not made easier by having a maximiser. It is the hard field of Triangular, and it is what forces something canonical in the classical treatment. This file removes one prerequisite; it does not touch that.
