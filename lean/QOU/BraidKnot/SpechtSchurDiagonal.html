    QOU.BraidKnot.SpechtSchurDiagonal — dim_k Hom_G(S^μ, S^μ) = 1 #

    First brick of W1+W3 of the Wedderburn epic (qou-bxw4), which the epic's own scouting merged into a single construction. It converts W2 (SpechtAbsolutelyIrreducible.specht_end_scalar) into the form the corpus' character machinery consumes.

    QOU.MathlibExt.RepresentationCharacter already carries the general identity

    ⅟|G| • Σ_g χ_V(g⁻¹)·χ_W(g) = dim_k Hom_G(V, W) (charPairing_eq_finrank_homG)

    together with one_le_finrank_homG_self (the identity is equivariant, so the diagonal is at least 1) and the vanishing off the diagonal. What it did not have is the diagonal exactly 1 — the normalisation Mathlib reaches only via FDRep.char_orthonormal, which carries [IsAlgClosed k]. For Specht modules that hypothesis is unnecessary: W2 says the commutant is the base field over any characteristic-zero field, which pins the diagonal at 1 outright.

    So the Specht characters are orthonormal over ℚ, not merely orthogonal — which is what turns the classification's counting bound into an expansion of χ_reg, and that is the route to n! = Σ_μ (dim S^μ)² recorded on bean qou-3c2j.

    Scope #

    This file is the bridge lemma only. It does not compute χ_reg, does not decompose the regular representation, and claims nothing about sn_isotypic_specht_split, which remains open.

    one_le_finrank_homG_self gives ≥ 1 for any nonzero representation; the content here is ≤ 1, which is W2 — the commutant is the base field, so there is nothing beyond the scalars. Mathlib obtains this normalisation only over an algebraically closed base (FDRep.char_orthonormal); no algebraic closure is used here.

    The off-diagonal, exported #

    The vanishing Hom_G(S^μ, S^ν) = 0 for μ ≠ ν is used inside SpechtClassification.specht_exhausts_irreducibles's counting proof but was never stated as a lemma of its own. Exported here, because orthonormality needs both entries and the diagonal alone is only half of it.

    theorem QOU.BraidKnot.SpechtSchurDiagonal.homG_specht_cross_eq_bot {k : Type} [Field k] [CharZero k] {μ ν : YoungDiagram} (h : Specht.nOf μ = Specht.nOf ν) (hne : μ ≠ ν) :
    MathlibExt.RepresentationCharacter.homG (SpechtClassification.spechtRep μ) (SpechtClassification.spechtRepOn h) = ⊥

    Schur, off the diagonal. For distinct diagrams of the same size there is no nonzero equivariant map S^μ → S^ν.

    Both simplicity hypotheses come from SpechtClassification.spechtRep_stable_eq_bot_or_top; on the ν side, stability under every spechtRepOn h g is the same condition as stability under every spechtRep ν σ, because transportPermHom h is surjective. The non-isomorphism is specht_pairwise_noniso.

    theorem QOU.BraidKnot.SpechtSchurDiagonal.finrank_homG_specht {k : Type} [Field k] [CharZero k] (μ ν : YoungDiagram) (h : Specht.nOf μ = Specht.nOf ν) :
    Module.finrank k ↥(MathlibExt.RepresentationCharacter.homG (SpechtClassification.spechtRep μ) (SpechtClassification.spechtRepOn h)) = if μ = ν then 1 else 0

    The Schur pairing is orthonormal on Specht modules, over any characteristic-zero field. dim_k Hom_G(S^μ, S^ν) = 1 if μ = ν and 0 otherwise.

    Mathlib's orthonormality (FDRep.char_orthonormal) carries [IsAlgClosed k]; neither half of this needs it. The 1 is W2 (SpechtAbsolutelyIrreducible.specht_end_scalar); the 0 is the classification's own Schur argument, exported above.
