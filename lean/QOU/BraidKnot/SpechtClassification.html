    QOU.BraidKnot.SpechtClassification — brick 3 of the Okounkov–Vershik tower #

    The classification of the irreducible k[S_n]-modules over a characteristic-zero field k: the family of Specht modules {S^μ : μ ⊢ n} is a complete, pairwise non-isomorphic family of the simple k[S_n]-modules. Consequently the number of iso-classes of irreducible S_n-representations equals the number of partitions of n — the count that pins the Wedderburn block count.

    This is "brick 3"; it builds on brick 1 (QOU.BraidKnot.StandardYoungTableau) and brick 2 (QOU.BraidKnot.Specht, the Specht-module construction S^μ ≤ M^μ).

    Design — "S^μ as an S_n-representation" and isomorphism #

    Brick 2's Specht.SpechtSubmodule μ is a Submodule k (Mtab μ), and crucially S^μ and S^ν for μ ≠ ν live in different ambient modules (Mtab μ vs Mtab ν). To compare them as S_n-representations we:

    1. View each S^μ as a genuine Representation — spechtRep μ is the restriction of Specht.Mtab.rep μ to the (S_n-stable) submodule S^μ, produced via LinearMap.restrict. Its well-formedness needs the stability lemma specht_smul_mem (S^μ is S_n-invariant), which is a genuine brick-2/brick-3 theorem and is honestly stubbed.

    2. State isomorphism via a hand-rolled intertwiner — IsRepIso ρ ρ' asserts a k-linear equiv e : V ≃ₗ[k] V' that intertwines the two actions (e (ρ g x) = ρ' g (e x)). This is the cleanest honest formulation: it composes directly with brick 2's Mtab.rep/SpechtSubmodule and avoids FDRep's finite-dimensionality plumbing (which would force Module.Finite side-goals before the classification content is even reachable). We chose this over FDRep k (Perm …) Iso for exactly that reason — the intertwiner predicate is a Prop-level statement over the Representation objects brick 2 already supplies.

    What is sorry-free here #

    • PartitionIndex n — the index type {μ : YoungDiagram // μ.card = n}, with DecidableEq (and a fresh sorry-free DecidableEq YoungDiagram instance the pinned Mathlib lacks).
    • IsRepIso — the intertwiner predicate, with refl/symm/trans (it is an equivalence relation on representations; all three sorry-free).
    • transportPermHom — the Perm (Fin a) →* Perm (Fin b) group transport along a = b (sorry-free), the device that lets S^μ, S^ν be compared over one group.
    • spechtRep / spechtRepOn — S^μ and the regrouped S^ν as Representations (sorry-free proof terms, but transitively sorryAx-dependent because they reference specht_smul_mem; see below).
    • partitionEquivYoungIndex — the bijection Nat.Partition n ≃ PartitionIndex n (sorry-free; built from YoungDiagram.ofRowLens / rowLens round-trips via the helper card_eq_rowLens_sum, since Mathlib has no packaged bridge at this pin).
    • the Fintype (PartitionIndex n) instance + card_partitionIndex / card_irreducibles_eq_card_partitions — sorry-free (they rest on partitionEquivYoungIndex, now closed); the latter is the punchline count #{irreducibles} = #{partitions of n} modulo the classification stubs below.

    What is stated with sorry + -- Ref: (the genuine theorems) #

    • specht_smul_mem — S^μ is S_n-stable (needed to form spechtRep). -- Ref: [sagan2001] §2.3.
    • specht_pairwise_noniso — μ ≠ ν → ¬ (S^μ ≅ S^ν). -- Ref: [james1984representation].
    • specht_exhausts_irreducibles — every simple k[S_n]-module is ≅ some S^μ. -- Ref: [sagan2001] §2.4.

    All textbook-famous theorems (Sagan §2.4, James 1984); their Lean proofs are out of scope for one brick and are honestly stubbed per AGENTS.md §1. This module is intentionally not imported by the QOU.BraidKnot umbrella (it carries honest sorry targets); it is verified to compile standalone via lean-direct against the pinned v4.24.0 oleans.

    References #

    • [sagan2001] Sagan, The Symmetric Group, §2.4 (classification of irreducibles; the Specht modules are a complete set of simple modules in char 0).
    • [james1984representation] James, The Representation Theory of the Symmetric Groups (Specht modules; pairwise non-isomorphism via the bilinear form / the James submodule theorem).
    • [fulton1997] Fulton, Young Tableaux (partitions and Young diagrams).

              3. Isomorphism of representations (the intertwiner predicate) #

              source
              structure QOU.BraidKnot.SpechtClassification.IsRepIso {k : Type} [Field k] {G V V' : Type} [Monoid G] [AddCommGroup V] [Module k V] [AddCommGroup V'] [Module k V'] (ρ : Representation k G V) (ρ' : Representation k G V') :
              Prop

              Two representations are isomorphic when there is a k-linear equivalence between their carriers that intertwines the group actions. This is the honest, plumbing-free notion of "V ≅ V' as G-representations": a k-linear isomorphism e with e (ρ g x) = ρ' g (e x) for all g, x.

              For Specht modules of different shapes the carriers S^μ and S^ν sit in different ambient modules, and the same abstract group Perm (Fin n) acts on both (here n = μ.card = ν.card), so this is exactly the statement that compares them.

                      4. The classification theorems #

                      • SpechtCrossDominance.dominance_of_tableau_noclash — Sagan Lemma 2.2.6.

                        Completeness. Every simple k[S_n]-module is isomorphic to some Specht module.                         Proved #

                        The Specht modules are #partitions many pairwise non-isomorphic simples (specht_isSimple + specht_pairwise_noniso), and there are no others. The "no others" half is a count, every step of it a bound:

                        #{pairwise non-isomorphic simples}
  ≤ dim_k {class functions on Sₙ}      characters are independent class functions
  ≤ #conj classes of Sₙ                a class function is its values on classes
  ≤ #partitions of n                   cycle type separates conjugacy classes

                        Assuming an extra simple W isomorphic to no S^μ gives #partitions + 1 pairwise non-isomorphic simples, contradicting the chain.

                        Independence of the characters comes from the pairing

                        ⅟|G| • Σ_g χ_V(g⁻¹)·χ_W(g) = dim_k Hom_G(V, W)

                        (RepresentationCharacter.charPairing_eq_finrank_homG), which is diagonal by Schur and has nonzero diagonal because the identity is equivariant. Note what is not needed: FDRep.char_orthonormal normalises that diagonal to 1 and carries [IsAlgClosed k] to do it, but a bound only needs the diagonal nonzero — so the whole argument runs over an arbitrary characteristic-zero field, ℚ included.

                        theorem QOU.BraidKnot.SpechtClassification.card_irreducibles_eq_card_partitions (n : ℕ) :
                        Fintype.card (PartitionIndex n) = Fintype.card n.Partition

                        The count corollary (the punchline). The number of iso-classes of irreducible k[S_n]-modules equals the number of partitions of n.

                        We phrase the left-hand side as Fintype.card (PartitionIndex n) — the number of Specht modules — which equals the number of irreducibles by specht_pairwise_noniso (they are distinct) + specht_exhausts_irreducibles (they are all of them). The right-hand side Fintype.card (Nat.Partition n) is the partition count. This is the identity that pins the Wedderburn block count of k[S_n] to #{λ ⊢ n}.
