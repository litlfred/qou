    Jucys–Murphy elements from the Hecke presentation #

    KeystoneJucysMurphyTwist.lean reduced the general-λ ribbon twist to one assumed input: that the full twist's scalar on V_λ is the product of the JM eigenvalues q^{2·content}. That packages two separate facts — a structural one (the JM elements exist, commute, and multiply to the full twist) and a spectral one (they act on the seminormal basis with eigenvalue q^{2·content}).

    This file attacks the structural half, from the Hecke presentation itself.

    The setting #

    HeckeGenerators is the type-A presentation: an R-algebra with invertible generators σᵢ satisfying the braid relations and the corpus's Hecke relation σᵢ² = (q − q⁻¹)σᵢ + 1 (§7a). Assuming it is "let A be a Hecke algebra" — a definition, not a claim about the world — so this is not the axiomatization the anti-laundering rule targets. Generators are indexed by ℕ with relations for all indices, i.e. the stable algebra H_∞(q); each H_n(q) sits inside it.

    What is PROVED here #

    • jmRaw — the unnormalized JM recursion L_{i+1} = σᵢ Lᵢ σᵢ, and jm, the q-normalized form L_{i+1} = q⁻¹ σᵢ Lᵢ σᵢ of the arc's statement of the problem.
    • jm_eq_smul_jmRaw_two — the two conventions differ by a power of q. Proved at i = 1 only; the general q^{−i(i−1)/2} is not proved here. What is pinned, at n = 3, is that the exponent in jm_prod_three is 3 = c([3]) (contentSum_three_eq) — the same one-row content sum two_mul_contentSum_single_row supplies to the twist, so the normalization is not free bookkeeping.
    • jmRaw_closed_two — L₂ = (q − q⁻¹)σ₀ + 1 in the generators, by the Hecke relation.
    • jmRaw_prod_three : L₁L₂L₃ = Δ² at n = 3, where Δ² = (σ₀σ₁)³. This is the ∏Lᵢ = Δ² identity, proved from the braid relation alone — a single braid application on the middle three letters of σ₀σ₀σ₁σ₀σ₀σ₁.
    • jm_prod_three — the same in the q-normalized convention: q^{-3}·Δ², and 3 = c([3]).
    • jmRaw_comm_far / sigma_comm_jmRaw_one — the far-commutation that drives general commutativity.

    What is NOT proved — stated plainly #

    • General ∏_{i<n} Lᵢ = Δ². Proved here at n = 2 and n = 3 only. The general case is an induction whose step needs the far-commutation of Lᵢ past the new generator; the n = 3 proof below is its first genuine instance, not a special case of a completed argument.
    • General commutativity LᵢLⱼ = LⱼLᵢ. jmRaw_comm_far gives the easy far case; the adjacent case is the hard one and is open.
    • The spectral half — that Lᵢ acts on the seminormal basis by q^{2·content}. Untouched here. It needs Young's seminormal form, which the corpus does not carry.

    So JucysMurphySpectrum is not discharged by this file. What is now separated is which half is which: the structural half has a proof route, demonstrated at n = 3; the spectral half does not yet exist in Lean.

    Refs:

    • [wenzl1988] Hecke algebra representations (seminormal form; JM spectrum).
    • [macdonald1995] Symmetric Functions and Hall Polynomials, I.1.

    class QOU.BraidKnot.Hecke.HeckeGenerators (R : Type u_1) [Field R] (A : Type u_2) [Ring A] [Algebra R A] (q : R) :
    Type u_2

    The type-A Hecke presentation. Generators indexed by ℕ (the stable algebra H_∞(q)), invertible, satisfying the braid relations and the corpus's Hecke relation (§7a).

    • σ : ℕ → A

      The braid generators.

    • σinv : ℕ → A

      Their inverses.

    • mul_σinv (i : ℕ) : σ q i * σinv q i = 1
    • σinv_mul (i : ℕ) : σinv q i * σ q i = 1
    • hecke (i : ℕ) : σ q i * σ q i = (algebraMap R A) (q - q⁻¹) * σ q i + 1

      The Hecke relation σᵢ² = (q − q⁻¹)σᵢ + 1 (§7a).

    • braid (i : ℕ) : σ q i * σ q (i + 1) * σ q i = σ q (i + 1) * σ q i * σ q (i + 1)

      Braid relation, adjacent generators.

    • far (i j : ℕ) : i + 1 < j → σ q i * σ q j = σ q j * σ q i

      Far commutation, |i − j| ≥ 2.
