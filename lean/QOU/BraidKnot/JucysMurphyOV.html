    X_s · e_t = #{j < s : (j s) ∈ colStab t} · (−e_t) + Σ_{j < s, (j s) ∉ colStab t} e_{(j s)·t}.

    For the column-superstandard T₀ with s at cell (i, j) the same-column count is i, so the first term is −i · e_{T₀}; since content(i,j) = j − i, the sole remaining obligation is the off-column (Garnir) collapse

    Σ_{j' < s, (j' s) ∉ colStab T₀} e_{(j' s)·T₀} = j · e_{T₀},

    i.e. the off-column sum contributes exactly the number of cells strictly left of s in its row. Numerically confirmed in docs/audits/2026-07-19-ov-base-vector-column-superstandard-verification.md.

          theorem QOU.BraidKnot.JucysMurphy.linearIndependent_of_joint_eigenvectors {k : Type} [Field k] {V : Type u_1} [AddCommGroup V] [Module k V] {ι : Type u_2} {S : Type u_3} (A : S → V →ₗ[k] V) (v : ι → V) (c : ι → S → k) (hnz : ∀ (i : ι), v i ≠ 0) (heig : ∀ (i : ι) (s : S), (A s) (v i) = c i s • v i) (hinj : Function.Injective c) :
          LinearIndependent k v

          (L1) Joint eigenvectors with pairwise-distinct eigenvalue tuples are linearly independent. Generic linear algebra (no tableau/Specht content, sorry-free): a family v : ι → V of nonzero vectors, each a simultaneous eigenvector of every operator A s with eigenvalue tuple c i : S → k; if the tuple map c is injective, the family is independent.

          Proof: linearIndependent_iff' + strong induction on the support t of a finite dependency. For j ∈ t: if t = {j}, then g j • v j = 0 forces g j = 0 (v j ≠ 0); otherwise pick i₀ ∈ t with i₀ ≠ j and a separator s₀ with c i₀ s₀ ≠ c j s₀ (tuple injectivity), apply A s₀ and subtract c i₀ s₀ · the original relation — the i₀ term dies, and the inductive hypothesis on t.erase i₀ gives g j · (c j s₀ − c i₀ s₀) = 0, whence g j = 0.

          Note the operators need not commute and no diagonalisability is assumed — only the given family's eigen-structure is used. This is the entire linear-algebra content of the OV "distinct content-tuples ⇒ independent" step, factored out of the citation.

          L2 helpers: entries strictly increase along diagonals; the row-count formula #

          The proof of L2 below avoids diagram-removal entirely. In a standard tableau the entries strictly increase along each diagonal (row_strict + col_strict + up-left-closedness), the diagonal-d cells of μ form a contiguous row range starting at row (−d)⁺, and therefore

          row(s) = (−content s)⁺ + #{s' < s with the same content}

          — the row of a label is determined by the content tuple alone. Two tableaux with the same content tuple then agree cell-by-cell (columns follow from rows + contents), hence are equal.
