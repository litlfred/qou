    The M₁ edge calculus: Fact A and the 1-Lipschitz diagonal lemma #

    Two pieces of the M₁ > 0 reduction (bean qou-k5r5) that were established by exact computation and flagged "Lean-formalizable", and are now proved.

    M₁ = Cov_Planch(Σ_h, ω₃) is written on the Fulman up-down chain as M₁ = P − N with

    P := Cov(Σ|c|, ω₃) ≥ 0        N := −Cov(ΣD², ω₃) ≥ 0

    and the whole remaining gap is the finite-n domination P > N. This module proves the P ≥ 0 half at the per-edge level, and the structural lemma that bounds the per-edge N/P ratio.

    Fact A is algebra, not combinatorics #

    An up-down move removes a box of content c_r and adds one of content c_a. The increments were measured exactly:

    Δω₃ = c_r² − c_a²          ΔΣ|c| = |c_r| − |c_a|

    Their product is (|c_r| − |c_a|)²(|c_r| + |c_a|) ≥ 0 — and that identity is true of any two integers, because c² = |c|². So the per-edge sign of P needs no property of Young diagrams at all: factA_nonneg below is stated for arbitrary cr ca : ℤ, which is the honest strength. What the combinatorics supplies is only the two increment formulas, and those are inputs here rather than theorems (they are per-move facts about the chain, not about a single diagram).

    The 1-Lipschitz lemma is where the diagrams enter #

    D c, the number of cells on diagonal c, satisfies D (c+1) ≤ D c ≤ D (c+1) + 1. The right-hand inequality is what caps the per-edge ratio N/P|ₑ at 4, via d_a − d_r ≤ r − a.

    Its proof is short and worth stating, because it is the only place antitonicity of the row lengths is used: the indices on diagonal c form a downward-closed set, hence an initial segment range (D c). If D c exceeded D (c+1) by two, the two indices k, k+1 in the gap would both satisfy rowLen i = i + c + 1, forcing rowLen (k+1) > rowLen k and contradicting rowLen_anti.

    Only the c ≥ 0 side is proved. The c < 0 side is the transpose statement, and YoungDiagram.rowLen_transpose turns one into the other; it is not restated here because nothing in the reduction needs both sides simultaneously.

    What this does NOT give #

    P ≥ 0 per-edge does not give P > N. The parent bean records that the per-edge ratio is unbounded above by any bound that helps — it reaches 4, so no per-edge or FKG argument can close the gap — and that weight-suppression is refuted, N/P < 1 being an averaging phenomenon. These lemmas are the floor under that analysis, not a route around it.

        Telescoping: the two-case per-edge bound #

        diagLen_lipschitz bounds ONE step. What the M₁ > 0 route needs is the SUM, and the sum telescopes exactly:

        ∑_{t=0}^{λ₁-1} (D t − D (t+1))  =  D 0 − D λ₁  =  D 0.

        So the profile's total fall is D 0 — no limit shape, no error term, no Berry–Esseen. Two consequences, one per edge type of the up-down chain, and between them they cover every edge:

        • Same-sign contents (u ≤ v on one side): D u − D v is the number of drop sites in [u, v), so it lies in [0, v − u] and the per-edge slope (D u − D v)/(v − u) is a density in [0, 1].
        • Opposite-sign contents: the two sides telescope to the same total D 0, which cancels, leaving a difference of two counts each in [0, D 0] — hence |D_μ u − D_μᵀ v| ≤ D 0. This is the case the slope is unbounded on (it grows like √(2n); see ..._edge_ratio_monotonicity.py), so a bound covering it at all is the point.

        Measured in computations/deltalambda/wlambda_covariance_epic_M1_telescoping_route.py: 0 violations of either bound over every edge at every n ≤ 46, and the second is sharp — max |slope| · g / D 0 = 1 exactly, attained. Neither closes M₁ > 0: the two bounds together still exceed 1, so averaging is still required. What they replace is an appeal to effective limit-shape asymptotics with elementary, deterministic, finite statements.

        The area constraint #

        Every bound above uses only D 0, λ₁ and 1-Lipschitz. The global constraint ∑_c D c = n was unused, and it is worth more than all of them: computed over the limiting edge measure (wlambda_covariance_epic_M1_limit_closed_form.py), adding it takes the budget's margin from 0.047 % to 7.54 % — about 160× more room. The reason is that min (D 0) (λ₁ - a) is nearly vacuous away from the origin: it permits D a = 0.637 √n at a = √n where the truth is 0.218 √n.

        Two elementary facts do it, and each is one step from something already proved:

        • monotonicity — a * D a ≤ ∑_{c < a} D c, since D is antitone;
        • 1-Lipschitz tail — D a * (D a + 1) / 2 ≤ ∑_{c ∈ [a, a + D a)} D c, since D (a + k) ≥ D a - k, which is diagLen_le_add_sub.

        The two ranges are disjoint and abut, so together they give diagLen_area_bound below. Solving that quadratic for D a gives the form the quadrature uses, D a ≤ √(a² + 2A) - a; it is stated here in the equivalent division-free way, which is both stronger as a Lean statement and free of Real.sqrt.

        What is NOT proved here. The bound is against the PARTIAL sum ∑_{c < a + D a} D c, which is what the argument needs and is stronger than bounding by the full area. Identifying that sum with a count of boxes — hence with n, and with A_σ → n/2 in the limit — is a separate step, and the A_σ → n/2 half is a limit-shape input rather than a theorem. The 7.54 % figure depends on it; with only A_σ ≤ n the margin is 0.094 %.

        Refining the opposite-sign bound #

        abs_diagLen_sub_transpose_le bounds the opposite-sign slope by D 0 / g, and that bound is SHARP per edge. But it is not sharp on AVERAGE, and the difference decides the route: computed over the limiting edge measure (wlambda_covariance_epic_M1_limit_closed_form.py), the crude bound puts the budget at 1.005709 — a miss — while the refinement below puts it at 0.999534.

        Two facts do it, and both are one step from what is already proved here.

        • D 0 ≤ D c + c (that is diagLen_le_add_sub at u = 0): the profile cannot have fallen by more than c after c steps, so at most c of the D 0 drop sites lie in [0, c).
        • D c + c ≤ λ₁ (diagLen_add_le_rowLen_zero, new below): the last box on diagonal c sits at row D c - 1, column D c - 1 + c, and that column is inside row D c - 1, hence inside row 0.

        The second is what bounds the drop sites from the other end: there are only λ₁ - D 0 non-drop sites in total on a side, so a long interval must contain drops. Together they give diagLen_sub_transpose_le_refined.

        The guard on the second lemma is real, not decorative. D c + c ≤ λ₁ fails when D c = 0 and c > λ₁ — the ℤ form would then assert 0 ≤ a negative. So it is stated over ℕ unconditionally (truncated subtraction makes it true), and over ℤ only under 0 < D c. Every actual corner satisfies that, a corner being a box on its own diagonal.

        The site distribution κ, and what the "inflation factor" actually is #

        The M₁ > 0 route needs E_ω[slope], and by the telescoping lemmas above a same-sign slope is the density of drop sites δ t := D t − D (t+1) ∈ {0,1} in the edge's content interval. The measured quantity that governs the route is

        infl := E_ω[density] / E_ω[D 0 / λ₁]

        — how much more the ω-chosen intervals drop than the diagram's own global average. It is measured at 0.494 at n = 46 and rising (wlambda_covariance_epic_M1_telescoping_route.py).

        This section says what that ratio is. Give each interval e weight w e and let it spread that weight uniformly over the sites it covers:

        κ t := ∑_{e ∋ t} w e / (hi e − lo e).

        Two facts, both elementary and both proved here:

        • kappa_sum — ∑_t κ t = ∑_e w e. Each interval contributes g · (1/g) = 1, so κ is (after normalising) a probability distribution on SITES.
        • weighted_density_eq_kappa_dot — the weighted sum of interval densities equals ∑_t κ t · δ t.

        Together: the ω-average interval density is exactly the κ-mass sitting on drop sites. Since there are D 0 drop sites among T (the telescoping identity), uniform κ gives exactly the global density D 0 / T, i.e. infl = 1. So the inflation factor is neither mysterious nor a fitted constant — it is precisely the departure of κ from uniform, and infl > 1 iff ω over-weights drop sites.

        What this does NOT do is bound it. κ is determined by the Plancherel up-down edge measure, not by any property of a Young diagram, so no theorem about diagLen can constrain it; that is measurement's job. Recorded because the identity is what makes the measured number mean something.

        Two consequences worth stating, since one of them corrects a claim I made before proving any of this:

        • E_ω[D 0 / λ₁] → 1/π, so asymptotically infl < π/2 is the same statement as E_ω[density] < 1/2 — the pointwise limit-shape bound already known to be exactly critical. I had reported "infl = 0.494 against π/2" as comfortable headroom. It is the constraint restated, not headroom.
        • 1/2 is the pointwise maximum of the VKLS local drop density, attained only at the main diagonal. So infl → π/2 would require κ to concentrate at the ORIGIN. Measured over n = 12..48, κ's mean site moves away from it and then plateaus near 0.853·√n — it is not heading for the origin, which is the failure mode that would sink the route. Evidence, not proof: the ceiling implied by that position has settled at ≈0.3545 (so infl → ≈1.11), but the measured density is still only ~54% of it and climbing.

          The diagonal decomposition — the area constraint as an EQUALITY #

          sum_diagLen_le_card bounds an initial run of diagonals by n. The bound is lossy by exactly the cells it never reaches, and the loss is nameable: run the diagonals both ways and every cell is hit exactly once.

          Cell (i, j) has content j - i. Split μ.cells on i ≤ j:

          • i ≤ j — the cell sits on diagonal c = j - i ≥ 0 of μ, at row i;
          • j < i — the cell sits on diagonal r = i - j ≥ 1 of μᵀ, at row j.

          Both maps are bijections onto their halves, so the two diagonal sums add to n exactly. Since diagLen μᵀ 0 = diagLen μ 0, the symmetric form double-counts the main diagonal and reads ∑ D + ∑ Dᵀ = n + D 0.

          Why this matters for the M₁ > 0 budget: the route needs the two one-sided areas A₊, A₋, and the inequality version can only ever give A_σ ≤ n.                 The diagonal form of the hook sum — where the |u| cancellation lives #

                sum_hookLen_eq_sum_coords says ∑ h = ∑ (i + j + 1). Resolving that down each diagonal is what makes the Kerov computation of κ work, so it is worth having exactly rather than asymptotically.

                A cell on diagonal c ≥ 0 at depth k is (k, k + c), so i + j + 1 = 2k + c + 1, and summing over k < D c gives D c ² + c · D c. Hence

                ∑_cells h  =  ∑_c D(c)²  +  ∑_c |c| · D(c)

                (both sums over all integer diagonals, the negative ones read off the transpose).

                Why it matters. In the continuum D(c) = (√n/2)(ν̂(u) − |u|) with u = c/√n, so the first sum is (n^{3/2}/4) ∫ (ν̂ − |u|)² and the second (n^{3/2}/2) ∫ |u| (ν̂ − |u|). Under Kerov's ν̂ = Ω + (2/√n) Δ the FIRST-ORDER parts are n ∫ (Ω − |u|) Δ and n ∫ |u| Δ, and the |u| CANCELS:

                ∑ h − E[∑ h]  ≈  n ∫ Ω(u) Δ(u) du.

                That cancellation is the whole reason ∑ h fluctuates at order n rather than n^{3/2}, and it is what reduces κ's sign to the single Fourier coefficient f₃ = ∫₀^π (cos t (π/2 − t) + sin t) sin t sin 3t dt = 16/75 > 0, giving κ = (8/3π²)(16/75) = 128/(225π²). See computations/deltalambda/wlambda_covariance_epic_M1_kappa_derivation.py.
