    Concrete #SYT counts for small self-conjugate shapes → tabulated c_λ #

    Toward the tabulated c_λ ∈ {1,3,8,10} of symbolic_character_table (bean qou-tqab). This file pins the smallest self-conjugate shape by direct enumeration: #SYT = 2, hence c_λ(σ₁) = #SYT/2 = 1, for the hook (2,1). Larger c_λ values need the hook-length formula (a genuine Mathlib gap; tracked separately).
