    def QOU.BraidKnot.SixTermPerDerivationWeights.binding_assembly (B E_0_β α m_e a_K T1_free T1_atom T23_free T23_atom T4_free T4_atom T6_free T6_atom : ℝ) :
    Prop

    The six-term binding-energy assembly (prop:six-term-per-derivation-weights), as a proposition over caller-supplied data:

      B = E_0_β · (T1_free − T1_atom)
    + α · (T23_atom − T23_free)
    + m_e · (T4_atom − T4_free)
    + E_0_β · (a_K − 1) · T1_atom
    + (T6_atom − T6_free)

    Named, not asserted. This is the declaration the block's lean.ref actually resolves to — see the note below on what it replaced.

    Nothing here constructs the descended Markov trace T1, the Φ_q vertex terms T2/T3, τ(C_dim_q) (T4), the cyclotomic residue sum T6, the chirality coefficient a_K, or the Borromean–Catalan scale α = m_e·8G; they are reals the caller supplies. So this states which quantities are combined and how, not why they are the ones that appear.

      B = 0

      No binding when free and bound agree — derived.

      If every per-term value coincides between the free and atomic configurations and the chirality coefficient is a_K = 1, the assembly gives B = 0. Each of the five terms is a difference that vanishes, the fourth through its (a_K − 1) factor.

      The sanity check the assembly must pass to be a binding energy at all, and the reason the shape is worth naming: it is a hypothesis something is proved from.

      2026-09-03 — what binding_assembly was, and the file it shadowed #

      Until this change binding_assembly was opaque binding_assembly (Z N : Nat) : Float — an opaque constant, asserting nothing, with a Float standing for a mass in MeV. The block's lean.ref resolved to it, so the proposition's formal handle carried no statement at all.

      It also shadowed a second declaration of the same fully-qualified name in SixTermPerDerivationWeights/binding_assembly.lean, which held BindingAssemblyContext and projected its own conclusion field. resolveCanonicalLean takes the direct module path first when that file declares the named decl, so this file always won and that one was never read. It is now a drained shell; the projection is gone.

      Neither module is imported anywhere, and nothing outside them names either declaration (measured across content/, 2026-09-03).
