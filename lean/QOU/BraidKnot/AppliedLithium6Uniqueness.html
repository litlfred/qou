    QOU.BraidKnot.AppliedLithium6Uniqueness — concrete ⁶Li application #

    Thin wrapper specialising NucleusEmptySDPUniqueness to ⁶Li's strand count n = 3·A = 3·6 = 18 (Z=3, N=3, A=6).

    Status #

    Sorry-free closure for ⁶Li's empty-SDP uniqueness via the parameterised nucleus_uniqueness_closed at n := 18. No abstract-axiom dependency.

    ⁶Li was added as a verified atom-braid case in Sprint 2 (commit 57783eebb); this file lifts the same to the SDP-uniqueness layer.
