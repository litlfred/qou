    QOU.BraidKnot.SnIsotypicSpechtSplitInstance — the keystone class, inhabited #

    SnWedderburnPartitionBridge.SnIsotypicSpechtSplit R axiomatises the isotypic Wedderburn split of R[S_n] in matrix form, together with the statement that it sends the Jucys–Murphy central element C₂ to the family of block scalars contentSqSum. A large part of the corpus is stated conditionally on it — OVTopAssembly, RSKBurnsideDischarge, BurnsideDischarge, PieceASpechtCharacter, PlancherelNormalisation — and until now nothing inhabited it.

    instance : SnIsotypicSpechtSplit k for any characteristic-zero field k. Everything it needs is proved:

    • the split itself, for every n, is SpechtWedderburnGeneral.spechtEquiv — which exists because QOU.Mathlib.rskBurnsideHolds (epic qou-nrex, brick 42) discharged the count;
    • the matrix form is algEquivMatrix (Module.finBasis …), a basis choice, applied blockwise;
    • the C₂ statement is SpechtCentralC2Scalar.spechtProduct_centralC2, and an algebra equivalence carries c • 1 to c • 1.

    What this discharges #

    Every [SnIsotypicSpechtSplit ℚ] hypothesis in the corpus is now satisfiable by instance resolution, so the results carrying it are unconditional.

    Note the direction of the dependency, because it is the reverse of the one the corpus previously had: RSKBurnsideDischarge.rskBurnsideHolds derives the RSK/Burnside identity from this class. This instance is built from QOU.Mathlib.rskBurnsideHolds, which is proved from the Robinson– Schensted correspondence with no hypothesis at all — so the identity is not being assumed anywhere in this chain.

    Base ring #

    Any characteristic-zero field. The class's use sites are all at ℚ, but the construction is generic — the split, the matrix form and the C₂ alignment never mention ℚ — so the instance is stated where it actually holds.
