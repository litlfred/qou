    theorem QOU.BraidKnot.KeystoneRootsToQ0Bridge.q0_value_arbitrary_on_gate {α : Type u_1} {β : Type u_2} (S : Set α) (q0 : α) (hq0 : q0 ∉ S) (f : α → β) (v : β) :
    ∃ (g : α → β), (∀ z ∈ S, g z = f z) ∧ g q0 = v

    The gate value at q₀ is arbitrary. If the substrate point q₀ is not itself in the gate set S, then for any target f and any prescribed value v there is a function agreeing with f at every gate point yet taking the value v at q₀.

    This is the formal price of leaving the analytic (rational) class: a candidate that is merely defined at q₀ — rather than analytically continued there — inherits no constraint from matching at roots of unity.

    theorem QOU.BraidKnot.KeystoneRootsToQ0Bridge.gate_does_not_determine_q0 {α : Type u_1} {β : Type u_2} (S : Set α) (q0 : α) (hq0 : q0 ∉ S) (f : α → β) {v₁ v₂ : β} (hv : v₁ ≠ v₂) :
    ∃ (g₁ : α → β) (g₂ : α → β), (∀ z ∈ S, g₁ z = f z) ∧ (∀ z ∈ S, g₂ z = f z) ∧ (∀ z ∈ S, g₁ z = g₂ z) ∧ g₁ q0 ≠ g₂ q0

    The gate does not determine the substrate value. For any gate set S with q₀ ∉ S and any two distinct values v₁ ≠ v₂, there exist two functions that agree with each other (and with the target f) at every point of S but disagree at q₀.

    So "matches the Hecke row at all roots of unity" is, by itself, consistent with any value at the substrate anchor. Determination requires an extra hypothesis tying q₀ to S — rationality (the sibling's route, which then forces f = 0) or an analytic bridge. Absent that, the root-of-unity gate is silent at q₀.

    Horn (i) — with an analytic bridge, the gate does reach q₀ #

    The converse half of the dichotomy, over ℂ (genuinely archimedean, §7c). If the candidate row and the Hecke row are both analytic on one preconnected open set U containing a point z₀ at which the gate set accumulates and containing q₀, then agreement on the gate forces agreement at q₀ — by the identity theorem (AnalyticOnNhd.eqOn_of_preconnected_of_frequently_eq).

    Since the roots of unity are dense in the unit circle, any candidate analytic on a neighbourhood of an arc of |q| = 1 together with the real point q₀ ≈ 1.10998 falls into this horn — and is therefore pinned to the (rational) Hecke row, which in the concrete monomial-twist case forces f = 0 (sibling #4973). Escaping that conclusion requires failing this hypothesis, which is exactly horn (iii).
