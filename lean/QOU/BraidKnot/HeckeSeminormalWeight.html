    The twist on a Jucys–Murphy weight vector #

    KeystoneJucysMurphyTwist carries the general-λ twist conditionally, on a class JucysMurphySpectrum whose one assumption is about the composite object:

    fullTwistScalar = ∏ i, q ^ (2 · content (e i))

    That is not the statement the seminormal-form literature proves. What it proves is a statement about the constituents — that each Lₖ acts on a standard-tableau basis vector by q^{2·content} — from which the product statement follows only because ∏Lᵢ = Δ².

    HeckeFullTwistProduct.jmProd_eq_delta_pow now supplies that step for every n, so this file makes the replacement:

    • assumed — IsJMWeight: Lₖ · v = cₖ · v for k < n. Per-element, the textbook hypothesis.
    • derived — fullTwist_smul_of_weight: Δ² · v = (∏ cₖ) · v.
    • derived — fullTwist_smul_eq_theta_sq: with cₖ = q^{2·content}, Δ² · v = θ_λ² · v.

    It also derives the class field itself: twist_scalar_eq_theta_sq says that if the twist acts on a nonzero weight vector by some scalar, that scalar is θ_λ².

    Non-vacuity #

    A conditional theorem is worth what its hypothesis is inhabited. scalar_isJMWeight exhibits an instance — the one-dimensional representation σᵢ ↦ q with the one-row tableau — and scalar_fullTwist_eq_single_row checks that the value the general theorem then returns is q^{n(n−1)}, which KeystoneHeckeRootsForceTwist.theta_single_row_sq obtains from the two roots of the Hecke relation with no Jucys–Murphy input at all. Two routes, same answer.

    What this does and does not change #

    It does not prove the seminormal form. The eigenvalue hypothesis is still an assumption for dim V_λ > 1 — the instance above is one-dimensional and demonstrates only that the hypothesis is satisfiable, not that it holds in general — and the general-λ twist is still conditional. What changes is which thing is assumed: an assumption about a product of n operators becomes an assumption about each operator separately, and the passage between them is now proved rather than bundled into the same class field.

    The scalar hypothesis is per-vector and carries no positivity, ordering, or archimedean content, so everything here stays over a generic [Field R] and [Ring A] per §7c — no ℝ.

          Non-vacuity, and a falsifiability check against an independent route #

          A conditional theorem is worth only as much as its hypothesis is inhabited. This section exhibits an instance and checks that the conclusion it delivers agrees with a result proved by a completely different argument.
