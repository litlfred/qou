    QOU.BraidKnot.StandardYoungTableau — brick 1 of the Identity-I S_n rep-theory program #

    First brick of the multi-session program scoped in [docs/scope/2026-06-24-identity-i-plancherel-snrep-infra-program.md]: the standard-Young-tableau count numSYT μ = #SYT(μ) and its Frame–Robinson–Thrall hook-length value — the "dimension side" dim(λ) = f^λ that program phase P2 needs for axiom (i) Σ_λ dim(λ)² = n!.

    Pinned Mathlib (rev f897ebcf) ships YoungDiagram and a semistandard-tableau type but not StandardYoungTableau, the SYT count, or the hook-length dimension (verified against the cached oleans). This file supplies the missing definitions over ℕ (nothing archimedean — §7c) and states the FRT identity. Its proof is the genuine formalisation target (a textbook-famous theorem) and is left as sorry + -- Ref: per AGENTS.md §1.

It is verified to compile standalone via lean-direct against the cached v4.24.0 oleans.

    structure QOU.BraidKnot.StandardYoungTableau (μ : YoungDiagram) :
    Type

    A standard Young tableau of shape μ: a filling of the cells of μ by the integers 0, …, |μ| − 1, each used once, strictly increasing along rows (left → right) and down columns (top → bottom). Entries are carried by entry : ℕ → ℕ → ℕ, constrained on the cells (i, j) ∈ μ and pinned to 0 off the diagram (zero_off) so the type is finite — an SYT is fully determined by its values on the finitely many cells of μ — which is what makes numSYT via Nat.card well-defined (without zero_off the entry field would be free off-cells, the type infinite, and Nat.card would collapse to 0). Surjectivity onto {0, …, |μ| − 1} is omitted: it is forced by inj_on together with μ.cells.card = μ.card, so stating it would be redundant.

    • entry : ℕ → ℕ → ℕ

      The entry at cell (i, j).

    • lt_card (i j : ℕ) : (i, j) ∈ μ → self.entry i j < μ.card

      Entries lie in {0, …, |μ| − 1}.

    • zero_off (i j : ℕ) : (i, j) ∉ μ → self.entry i j = 0

      Off the diagram the filling is pinned to 0, so the structure is finite (an SYT is determined by its values on the finitely many cells of μ).

    • inj_on (i j i' j' : ℕ) : (i, j) ∈ μ → (i', j') ∈ μ → self.entry i j = self.entry i' j' → i = i' ∧ j = j'

      Distinct cells carry distinct entries.

    • row_strict (i j : ℕ) : (i, j + 1) ∈ μ → self.entry i j < self.entry i (j + 1)

      Entries strictly increase along each row.

    • col_strict (i j : ℕ) : (i + 1, j) ∈ μ → self.entry i j < self.entry (i + 1) j

      Entries strictly increase down each column.

      def QOU.BraidKnot.StandardYoungTableau.encode {μ : YoungDiagram} (T : StandardYoungTableau μ) :
      { c : ℕ × ℕ // c ∈ μ.cells } → Fin μ.card

      Encode a standard tableau by its entries on the cells of μ: each on-cell entry lies in Fin μ.card (by lt_card), and zero_off pins the off-cell entries to 0, so a tableau is fully determined by this finite data. This injection into a finite function type witnesses finiteness of StandardYoungTableau μ.

        noncomputable def QOU.BraidKnot.numSYT (μ : YoungDiagram) :
        ℕ

        numSYT μ = #SYT(μ), the number of standard Young tableaux of shape μ. This is the dimension f^μ = dim V_μ of the irreducible S_{|μ|}-representation indexed by μ (program brick 1 / phase P2). Well-defined because StandardYoungTableau μ is finite (the zero_off normalisation pins entries off the diagram, so an SYT is determined by its finitely many on-cell values). Noncomputable: it counts an unbundled structure via Nat.card, which is a genuine count here because StandardYoungTableau.instFinite (above) proves the type finite.

        The brick-1 FRT identity is proved downstream as QOU.BraidKnot.HookProductHLF.numSYT_mul_hookProduct (see the note at the end of this file for why it cannot be stated here). The Finite instance and the base case numSYT ⊥ = 1 — numSYT_bot — are proved here.

              The FRT hook-length formula #

              The brick-1 target #SYT(μ) · ∏_{c ∈ μ} h(c) = |μ|! — i.e. f^μ = |μ|! / ∏ h(c) — is proved (sorry-free) as QOU.BraidKnot.HookProductHLF.numSYT_mul_hookProduct.

              It cannot be stated here: its proof needs QOU.Mathlib.HookLengthFormula, which transitively imports this module (via QOU.BraidKnot.SpechtClassification → Specht → StandardYoungTableau). The statement therefore lives one level downstream, in the leaf module QOU.BraidKnot.HookProductHLF, where the import is legal.
