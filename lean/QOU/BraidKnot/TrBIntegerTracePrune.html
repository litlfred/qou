    Integer-trace prune of the "SL₂(ℤ) monodromy" framing for the lever-1 tr B target #

    The lever-1 binding-kernel identification (audits docs/audits/2026-06-24-lever1-trB-geometric-target.md and docs/audits/2026-06-24-keystone-bring-jacobian-E4-elliptic-W-plane.md) targets the W-plane monodromy trace

    tr B = 3(3q⁴ + 8q² + 3) / (4q(q+1)²)  ≈ 2.6423863  at the substrate q₀ ≈ 1.10998,

    and the 2026-06-24 keystone audit framed the realizing matrix as "M ∈ SL₂(ℤ) acting on H¹(E) with char. poly x² − (tr M)x + 1". That framing is structurally excluded (scope-(b) per AGENTS.md §Before declaring "refuted"; the cited invariant is the integrality of traces of integer matrices): automorphisms and Gauss–Manin monodromies of algebraic families act on H₁(·, ℤ) by integer (symplectic) matrices, so their traces are integers — but tr B at the documented q₀ interval lies strictly between 2 and 3, hence is not an integer. No M ∈ SL₂(ℤ) (indeed no integer 2×2 matrix at all — det = 1 is never used) has char-poly x² − (tr B)x + 1.

    What survives (the re-scope, uploaded-papers idea A3 in docs/audits/2026-07-18-uploaded-papers-binding-mass-gap-ideas.md): the family realizing tr M(q₀) = 2.6424 must be a real-analytic SL₂(ℝ) transfer-matrix family, not the integral monodromy of an algebraic elliptic surface. This prunes the entire "search algebraic elliptic fibrations / modular monodromies for trace 2.6424" class before anyone runs it (formalize-first).

    Contents (all sorry-free; base ring ℚ per AGENTS.md §7c — the trace obstruction is pure arithmetic, no archimedean input):

    • trace_intMatrix_eq_intCast — the ℚ-trace of (the ℚ-cast of) an integer 2×2 matrix is the cast of its integer trace;
    • not_exists_intMatrix_trace_eq / not_exists_SL2Z_trace_eq — the reusable gate: a non-integer rational is not the trace of any integer 2×2 matrix / any M ∈ SL₂(ℤ);
    • trB + two_lt_trB / trB_lt_three — the closed-form trace target and the interval bound 2 < trB q < 3 for every q ∈ [1, 6/5] (which contains every documented q₀ pin, muon- or proton-anchored: q₀ ≈ 1.10998);
    • trB_not_intCast / no_SL2Z_realizes_trB — the concrete prune on the whole interval, and no_SL2Z_realizes_trB_q0_proxy at the 6-digit rational proxy q = 110998/100000 of the documented q₀.

    The exact q₀ (transcendental, pinned by m_μ/m_e = Vol(4₁)/ℏ_q²) is not a rational, so the archimedean statement "tr B(q₀) ∉ ℤ" is carried here by the interval form: trB maps the entire rational interval [1, 6/5] strictly between 2 and 3, and the same polynomial inequalities hold verbatim over ℝ (the proofs below use only ordered-field arithmetic). The prune therefore applies to any real q in that interval, q₀ included.

    theorem QOU.BraidKnot.TrBIntegerTracePrune.trace_intMatrix_eq_intCast (M : Matrix (Fin 2) (Fin 2) ℤ) :
    (M.map Int.cast).trace = ↑M.trace

    The trace of the ℚ-cast of an integer 2×2 matrix is the cast of its (integer) trace. This is the cast form of "an integer matrix has integer trace" — the invariant backing the scope-(b) exclusion.

    theorem QOU.BraidKnot.TrBIntegerTracePrune.not_exists_intMatrix_trace_eq {t : ℚ} (ht : ∀ (n : ℤ), ↑n ≠ t) :
    ¬∃ (M : Matrix (Fin 2) (Fin 2) ℤ), ↑M.trace = t

    The reusable integer-trace gate. If t : ℚ is not (the cast of) an integer, then no integer 2×2 matrix has trace t. Trivial contrapositive of integrality — but this is exactly the statement that prunes "find M over ℤ with char-poly x² − t·x + 1" searches for non-integer t.
