    QOU.BraidKnot.AdelicCriticalLinePersistence — conjectural class (§3b) #

    §3b class axiomatisation for content block conj:adelic-critical-line-persistence.

    This is the keystone step of the q-Riemann-hypothesis arc, and until now it had no carrier of any kind. The arc runs

    local q-zeta of Bring's curve  ->  Hasse-Weil  |α_i| = q^{1/2}
   ->  spectral half-line      Re(ρ_i) = 1/2 at each place
   ->  [ THIS STEP ]           ->  classical RH

    Steps 1-3 have blocks and Lean (QOU.AlgebraicSubstrate.hasse_weil_bound, spectral_half_line). Step 4 was stated only as a subordinate clause in the prose of conj:classical-riemann-hypothesis: "The Riemann hypothesis asserts that this alignment survives the adelic assembly into the global zeta function." Bean qou-qadl.

    Why this is the whole difficulty, not one gap among several #

    The Hasse-Weil bound holds at every place, unconditionally, for curves over finite fields — Weil proved it in 1948, and RH has stayed open for the 78 years since. So local critical-line alignment at every place cannot by itself be close to RH: this implication carries the entire distance between the two. Stating it is what makes that distance visible instead of eliding it, and any reading of the arc as "reducing RH to" the local statement is measuring the wrong leg.

    Vacuity hazard — read before providing an instance #

    The class is an implication, and an implication is vacuously true whenever its antecedent fails. So an instance on a family localSpectrum that is not critical-line aligned is worth exactly nothing, and would be the da-arity-conflation failure mode: a proposition of the right shape carrying none of the intended content.

    The content sits at families where the antecedent holds — for the arc, the Bring-curve local spectra, where spectral_half_line supplies alignment at each place. An instance is a genuine advance only when accompanied by a witness family satisfying the antecedent. No instance is provided here; that is the honest open state (§3b-tax: this is a primary conjecture, taking no other conjecture class as a hypothesis).

    class QOU.BraidKnot.AdelicCriticalLinePersistence {P : Type u_1} (localSpectrum : P → Fin 8 → ℂ) :
    Prop

    Conjecture (adelic critical-line persistence). If the local spectral exponents are critical-line aligned at every place, the global zeta function inherits the alignment: every non-trivial zero of riemannZeta has real part 1/2.

    P indexes the places; localSpectrum v is the family of eight spectral exponents at the place v, in the sense of QOU.AlgebraicSubstrate.spectral_half_line — whose conclusion Re(ρ_i) = 1/2 is exactly this class's antecedent, and is well-posed because spectral_coord_re_unique makes that real part branch-independent.

    Conjectural class — see conj:adelic-critical-line-persistence.

    • persistence : (∀ (v : P) (i : Fin 8), (localSpectrum v i).re = 1 / 2) → ∀ (s : ℂ), riemannZeta s = 0 → (∀ (n : ℕ), s ≠ -2 * (↑n + 1)) → s.re = 1 / 2

      Local alignment at every place implies the global critical-line property. Stated as an implication so that the local hypothesis is visible in the type: a proposition asserting only the conclusion would be RH, and one asserting only the antecedent would be a fact about the curve.

      The arc's claim, assembled. Local critical-line alignment at every place, together with adelic persistence, yields the classical Riemann hypothesis.

      This is a genuine composition rather than the projection of a single assumption: it consumes the persistence class and a separate proof of local alignment, and neither alone gives the conclusion. It is the precise sense in which the framework "reduces RH" to its local statement — and it makes plain that the reduction is only as strong as the persistence hypothesis, which is open.
