    QOU.BraidKnot.h3_hecke_idempotents #

    H_3(q) Hecke idempotents — explicit q-dimensions and Plancherel weights for the three Wedderburn blocks.

    The Iwahori-Hecke algebra H_3(q) has three irreducible representations indexed by partitions of 3:

    • V_(3) — symmetric (1-d): σ_i acts as q on the 1-d space
    • V_(2,1) — Hoefsmit (2-d): σ_0 diagonal q, -q⁻¹, σ_1 off-diagonal with b coupling
    • V_(1,1,1) — antisymmetric (1-d): σ_i acts as -q⁻¹

    The q-Hecke idempotents e_λ ∈ H_3(q) project onto each block. Their explicit construction (Gyoja-Uno) requires the full Hecke algebra type; this module records the SCALAR INVARIANTS associated to each idempotent (q-dimensions and Plancherel weights) and the substantive identities they satisfy.

    This DISCHARGES the q-YST scaffolding portion of prop:ck-extraction-from-algebraic-rules's Rule 2 at n=3: the three blocks listed above exhaust V = V_(3) ⊕ V_(2,1) ⊕ V_(1,1,1), with q-dimension sum matching the regular representation dim_q H_3(q) = [3]_q!.

    Base ring (§7c). All content here is algebraic in q: the scalar invariants are rational functions of q, so the file is stated over a generic field {R : Type*} [Field R] (e.g. ℚ(q)), never specialised to ℝ. There is no archimedean construct (no ordering, no Real.*); the substrate→archimedean evaluation at q₀ ∈ ℝ happens elsewhere.

            Sum-of-dim_q identity (Wedderburn completeness) #

            Σ_λ dim_q(V_λ) · [n!/dim_q(V_λ)] = dim_q H_n(q) = [n]_q!

            For n=3 the equivalent identity in dim_q² (squared dimensions) holds modulo the q-Plancherel weights y_λ. We record the simpler sum-of- dim_q identity:

            dim_q V_(3) + dim_q V_(2,1) + dim_q V_(1,1,1) = 2 + (q + q⁻¹) = q + q⁻¹ + 2

            This is a non-trivial substantive scalar identity in q.

            source
            theorem QOU.BraidKnot.dimQ_sum_H3 {R : Type u_1} [Field R] (q : R) :
            dimQ_V3 q + dimQ_V21 q + dimQ_V111 q = q + q⁻¹ + 2

            The sum of the three q-dimensions at H_3 equals q + q⁻¹ + 2.

            Eigenvalue table per Wedderburn block #

            For each block λ, the generators σ_i act with eigenvalues drawn from {q, -q⁻¹} (the Hecke quadratic roots). The eigenvalue assignment per block:

            V_(3): σ_0 = q, σ_1 = q V_(2,1): σ_0 = ⟨q, -q⁻¹⟩ (diagonal), σ_1 = ⟨d_1, d_2; b, b⟩ V_(1,1,1): σ_0 = -q⁻¹, σ_1 = -q⁻¹

            This is a concrete combinatorial assignment, not a vacuous Prop.
