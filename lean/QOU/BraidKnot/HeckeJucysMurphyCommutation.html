    JM commutation relations, and where the general-λ derivation actually stops #

    HeckeJucysMurphyElements.lean split the JucysMurphySpectrum assumption into a structural half and a spectral half, and proved the structural half at n = 2, 3. This file pushes the structural half further and — more importantly — locates precisely where the general-λ derivation stops, so the remaining gap is one statement rather than a vague "seminormal form".

    The two exchange relations (proved, from the Hecke relation alone) #

    With h := q − q⁻¹ and L_{i+1} = σᵢ Lᵢ σᵢ:

    • sigma_mul_jm_succ : σᵢ L_{i+1} = h L_{i+1} + Lᵢ σᵢ
    • jm_succ_mul_sigma : L_{i+1} σᵢ = h L_{i+1} + σᵢ Lᵢ

    Each is one application of σᵢ² = hσᵢ + 1. They are the engine for everything below.

    Consequences (proved) #

    • sigma_comm_add — σᵢ commutes with Lᵢ + L_{i+1}. The two exchange relations differ by exactly the term that cancels in the sum. This is the classical statement that σᵢ commutes with the symmetric functions of the adjacent JM pair, and it is the first genuinely general commutation fact in this corpus (the n = 3 results were single instances).
    • sigma_mul_jm_prod — σᵢ (Lᵢ L_{i+1}) = (L_{i+1} Lᵢ) σᵢ. Note the order swap on the right: this is not yet "σᵢ commutes with the product", and it becomes that exactly when Lᵢ and L_{i+1} commute — which is the open problem, not an input.
    • jmRaw_comm_sigma_far — σⱼ Lᵢ = Lᵢ σⱼ for j ≥ i + 1, at every i, by induction on the recursion. This is the far half of commutativity in general, superseding the single instance proved previously.

    Where the derivation stops — stated exactly #

    Adjacent commutativity Lᵢ L_{i+1} = L_{i+1} Lᵢ is NOT proved here, and I could not reduce it to the relations above. The obstruction is recorded honestly rather than papered over, because it is easy to think one has it:

    Writing u := Lᵢσᵢ and v := σᵢLᵢ, the exchange relations give u = (σᵢ − h)L_{i+1} and v = L_{i+1}(σᵢ − h), and then Lᵢ L_{i+1} = u² while L_{i+1} Lᵢ = v². So the goal becomes (σᵢ−h)w = w(σᵢ−h) with w := L_{i+1}(σᵢ−h)L_{i+1} — i.e. it reduces to another commutation of the same shape, not to anything already proved. sigma_comm_add gives the sum; the product needs strictly more.

    Consequently ∏Lᵢ = Δ² remains proved only at n = 2, 3, and the general-λ twist θ_λ = q^{c(λ)} remains conditional.

    What this changes for JucysMurphySpectrum #

    Nothing is discharged, but the residual assumption is now one identified statement — adjacent commutativity, plus the spectral eigenvalue property — rather than an opaque bundle. See bean qou-u9o1.

    Refs:

    • [wenzl1988] Hecke algebra representations (seminormal form; JM spectrum).

    σᵢ commutes with the adjacent SUM #

    source
    theorem QOU.BraidKnot.Hecke.sigma_comm_add {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} (H : HeckeGenerators R A q) (i : ℕ) :
    HeckeGenerators.σ q i * (jmRaw H i + jmRaw H (i + 1)) = (jmRaw H i + jmRaw H (i + 1)) * HeckeGenerators.σ q i

    σᵢ commutes with Lᵢ + L_{i+1}.

    The two exchange relations carry the same h·L_{i+1} term, so it cancels in the sum:

    σᵢ(Lᵢ + L_{i+1}) = σᵢLᵢ + (h·L_{i+1} + Lᵢσᵢ)
                 = (L_{i+1}σᵢ − h·L_{i+1}) + h·L_{i+1} + Lᵢσᵢ
                 = (Lᵢ + L_{i+1})σᵢ.

    This is the classical fact that σᵢ commutes with the symmetric functions of the adjacent JM pair. It holds at every i — the first general commutation statement in this corpus.

    theorem QOU.BraidKnot.Hecke.sigma_mul_jm_prod {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} (H : HeckeGenerators R A q) (i : ℕ) :
    HeckeGenerators.σ q i * (jmRaw H i * jmRaw H (i + 1)) = jmRaw H (i + 1) * jmRaw H i * HeckeGenerators.σ q i

    σᵢ (Lᵢ L_{i+1}) = (L_{i+1} Lᵢ) σᵢ.

    Note the order swap on the right: this is not yet "σᵢ commutes with the product". It becomes that precisely when Lᵢ and L_{i+1} commute — which is the open problem, so this identity must not be quoted as commutation.

    Far commutation, in general #

    source
    theorem QOU.BraidKnot.Hecke.jmRaw_comm_sigma_far {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] {q : R} (H : HeckeGenerators R A q) (i j : ℕ) :
    i < j → HeckeGenerators.σ q j * jmRaw H i = jmRaw H i * HeckeGenerators.σ q j

    σⱼ commutes with Lᵢ whenever j > i (strictly).

    jmRaw H i is a word in σ₀ … σ_{i−1}, so j > i puts σⱼ at distance ≥ 2 from every letter and the presentation's far relation applies at each one. Induction on i.

    The strictness is not a technicality. At j = i the generator σᵢ is adjacent to the outermost letter of L_{i+1}, far does not apply, and that boundary case is exactly the open adjacent-commutativity problem this file could not close. An earlier draft of this theorem stated i ≤ j and was mathematically wrong for that reason; the Lean caught it.

    The hook-word form of Lᵢ #

    The exchange relations above are exhausted for the adjacent case. The standard next tool is the explicit hook word

    L_k = (σ_{k−1} ⋯ σ₁) σ₀ σ₀ (σ₁ ⋯ σ_{k−1}),

    which exhibits L_k as a palindrome around σ₀² and makes the letters it contains visible — the fact jmRaw_comm_sigma_far uses implicitly and the fact any braid-relation attack on adjacent commutativity needs explicitly.

        The first genuine instance of ADJACENT commutativity #

        The exchange relations could not reach the adjacent case, but the half-twist does at i = 1. The route is worth recording because it is not the one the exchange relations suggest: it goes through Δ = σ₀σ₁σ₀ = σ₁σ₀σ₁ and the fact that Δ² is a palindrome-insensitive square.

        (σ₀σ₁)³ = (σ₁σ₀)³ — both are Δ·Δ for the half-twist Δ = σ₀σ₁σ₀ = σ₁σ₀σ₁.

        (σ₀σ₁)³ groups as (σ₀σ₁σ₀)(σ₁σ₀σ₁) and (σ₁σ₀)³ as (σ₁σ₀σ₁)(σ₀σ₁σ₀); the braid relation turns each factor into the other, so both collapse to the same square.

        Adjacent commutativity at i = 1: L₂L₃ = L₃L₂.

        The first genuine instance of the case the exchange relations could not reach. Both products are the full twist, approached from opposite sides — L₂L₃ = (σ₀σ₁)³ (jmRaw_prod_three) and L₃L₂ = (σ₁σ₀)³ (jmRaw_two_mul_one) — and fullTwist3_symm identifies those.

        This is one instance, not the general theorem. It works because at i = 1 both products are the whole full twist of B₃, so the half-twist symmetry closes it; for i ≥ 2 the products are proper sub-words and that argument does not apply. General adjacent commutativity remains open (bean qou-u9o1).
