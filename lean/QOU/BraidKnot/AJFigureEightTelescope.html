    QOU.BraidKnot.AJFigureEightTelescope #

    Division-free split-product bookkeeping for the 4₁ certificate telescope (bean udmw, foundational tranche).

    The one remaining sorry in QOU.BraidKnot.AJFigureEight (general-N annihilation) is discharged, corpus-side, by the qZeilberger certificate (computations/aj_figure_eight_certificate.py; content Lean-proved in QOU.BraidKnot.AJFigureEightCertificate). Assembling it in Lean requires telescoping values whose rational form has denominators (q^k − q^N)(q^k − q^{N+1}) — these vanish both at the tower boundary k ∈ {N, N+1} and at roots of unity, while the class field quantifies over ALL q ≠ 0. The assembly must therefore be division-free: this file provides the split-product layer it stands on.

    Contents (all sorry-free) #

    • risingA q x k = ∏_{j<k} (x − q^{j+1}), risingB q x k = ∏_{j<k} (x·q^{j+1} − 1) — the two halves of the Newton-ladder element after clearing.
    • ladder_factor_split — the per-factor identity (x + x⁻¹ − λ_{j+1}) · (x q^{j+1}) = (x − q^{j+1})(x q^{j+1} − 1).
    • newtonLadder_split — the cleared ladder: g_k(x + x⁻¹) · ∏_{j<k} (x q^{j+1}) = risingA · risingB, generic x ≠ 0.
    • newtonLadder_lam_split — the specialization x = q^N used by the colored Jones tower.
    • risingA_shift / risingB_shift — the color-shift (N → N+1, i.e. x → q·x) relations that produce the certificate ratios r₁, r₂ division-free.

    Base ring (§7c) #

    The split products and their shift relations are polynomial identities — generic {R : Type*} [CommRing R]. Only the split of the ladder at x + x⁻¹ (which touches the nodes λ_j = q^j + q^{−j}) needs {K : Type*} [Field K]. Everything is algebraic — no ℝ, no ordering, no archimedean constructs.
