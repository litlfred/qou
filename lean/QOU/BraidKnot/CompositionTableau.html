    Composition-shaped tableaux — and IsDistinguished IS row standardness #

    TableauPerm.dOf gives Mathas' d(t) for a partition shape (Specht.Tableau is indexed by a YoungDiagram). Mathas' Lemma 3.9 is about a composition μ, whose rows need not decrease, so that map does not apply to it as stated.

    This file supplies the missing shape, and the point of it is that almost nothing new has to be proved: the row-standardness condition on a composition tableau turns out to be CompositionMinimal.IsDistinguished, already proved to characterise the distinguished coset representatives D_μ.

    The dictionary #

    The cells of a composition c : Composition n are Fin n, linearly ordered, with cell x lying in row c.index x — because Composition.index is defined so that row i occupies the consecutive positions sizeUpTo i … sizeUpTo i + blocksFun i − 1. A tableau is a bijection between entries and cells, and following dOf's orientation we carry it as d : Perm (Fin n) read entry ↦ cell, so d.symm is cell ↦ entry.

    Row standardness is naturally stated on cells — "reading a row left to right, the entries increase" (IsRowStandard) — while IsDistinguished is stated on entries. isRowStandard_iff_isDistinguished is the (short) argument that a bijection is monotone within a block exactly when its inverse is.

    What this buys #

    existsUnique_rowStandard restates Proposition 3.3 in the vocabulary Mathas uses: every right coset of S_μ contains exactly one row-standard μ-tableau. Nothing is reproved — it is CompositionCosetExists.existsUnique_isDistinguished_mem_coset under the dictionary — which is precisely the claim worth making mechanical rather than asserting it in prose.
