    QOU.BraidKnot.chirality_frobenius_self_pairing #

    Canonical Lean for content block prop:chirality-from-frobenius-self-pairing.

    The .md derives the amphichiral case of the chirality factor from the Fricke trace relation in H_3(R, q): the figure-eight character evaluates to χ_{4_1}((2,1)) = 2 − [3]_q = −1 − h², from which the chirality factor is a_{4_1} = 1 − h² (h = q − q⁻¹ the Hecke deformation, [3]_q = q² + 1 + q⁻² the balanced quantum integer).

    This file derives those identities directly over a generic commutative ring {R : Type*} [CommRing R], with the substrate parameter carried as a unit q : Rˣ (§7c). Both [3]_q = q² + 1 + q⁻² and h = q − q⁻¹ are Laurent expressions in q: the only structure they need is that q be invertible, which a Units element supplies by construction. So no field is required, no field_simp, and no q ≠ 0 side condition — each identity is a linear_combination of the single defining unit relation q · q⁻¹ = 1. The substrate evaluation at q₀ ∈ ℝ happens elsewhere, past the wall.

    A previous encoding axiomatised the conclusion χ = 1 − h² as a class field and projected it (:= ctx.claim_chirality_factor); that was a vacuous self-assuming projection and is removed in favour of the genuine derivations below.

        theorem QOU.BraidKnot.ChiralityFrobenius.chirality_figure_eight_character {R : Type u_1} [CommRing R] (q : Rˣ) :
        2 - qInt3 q = -1 - heckeH q ^ 2

        Figure-eight Fricke identity (manuscript, amphichiral case).

        The figure-eight character in the standard (2,1) representation of H_3(R, q) is χ_{4_1}((2,1)) = 2 − [3]_q, and this equals −1 − h² with h = q − q⁻¹. The identity is exactly −2·(q·q⁻¹ − 1), i.e. a multiple of the unit relation.

        theorem QOU.BraidKnot.ChiralityFrobenius.chirality_amphichiral_via_qInt3 {R : Type u_1} [CommRing R] (q : Rˣ) :
        1 - heckeH q ^ 2 = 4 - qInt3 q

        Amphichiral chirality factor of the figure-eight as a quantum integer.

        The manuscript's amphichiral chirality factor is a_{4_1} = 1 − h². Writing it through the balanced quantum integer [3]_q, the closed form is 1 − h² = 4 − [3]_q (since [3]_q = q² + 1 + q⁻² and h² = q² − 2 + q⁻²). This is the normalisation-free algebraic face of the chirality factor; like the Fricke identity it is a multiple of the unit relation, here +2·(q·q⁻¹ − 1).
