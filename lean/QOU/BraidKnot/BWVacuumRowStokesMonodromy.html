    What this file states #

    The passage that #3677 pinned — the colored-WRT vacuum row bwS0Concrete = S_{0λ}·θ_λ^{f} realizing the Verlinde measure W_λ = ‖S_{0λ}‖² at the fibre root of unity ‖q‖=1, versus its value at the observable substrate q₀>1 — is naively read as analytic continuation of a q-series from ‖q‖=1 to q₀. That reading is wrong for this framework. The correct categorical framing (audit §1) is the Riemann–Hilbert / Stokes one: the analytic continuation of the solutions of a linear q-difference connection is its monodromy — "continue to q₀" becomes "apply the monodromy operator", a morphism in a category, with no limits taken.

    Concretely, the ribbon twist θ_λ = q^{c(λ)} (the framing datum that distinguishes fibre from observable; #3662/#3677 twist, KeystoneModularTwist.theta) is a monodromy eigenvalue of the Gauss–Manin connection whose unimodular 2×2 monodromy M is BringWPlaneMonodromy.M, with characteristic (Cayley–Hamilton) relation the depth-2 recurrence kernel x² − (tr M)·x + 1 (unimodular_two_recurrence, τ = tr M). This file axiomatizes that single structural residue as a content-bearing §3b class and derives its sorry-free consequences.

    Honest scope (§"Axiomatization is NOT a Proof"; §3b-tax) #

    This file reframes the fibre→observable passage in monodromy language and ties three corpus objects into one eigenvalue picture:

    class QOU.BraidKnot.Keystone.StokesMonodromyFraming (τ : ℝ) :
    Type

    The fibre↔observable passage as a Stokes / Gauss–Manin monodromy action (§3b class).

    CONTENT: the ribbon twist θ_λ — the framing that distinguishes the fibre value (‖q‖=1) from the observable value (q₀>1) — is an eigenvalue of the unimodular monodromy M, i.e. it satisfies M's characteristic (Cayley–Hamilton) relation x² − (tr M)·x + 1 = 0 with τ = tr M. This is the Riemann–Hilbert statement that "continuation to q₀" is "apply the monodromy", not an analytic limit.

    The single field eigen carries the residue as a parameter-quantified polynomial equation in the shape of the characteristic relation of unimodular_two_recurrence — genuine content, discharged for a concrete shape-witness but open for the actual Seifert M (BringWPlaneMonodromy).

    • theta : ℝ

      The λ-graded ribbon twist eigenvalue θ_λ carried on this block (the framing datum).

    • eigen : theta τ ^ 2 - τ * theta τ + 1 = 0

      CONTENT. θ solves the unimodular monodromy's characteristic polynomial x² − τ·x + 1 = 0 (τ = tr M) — i.e. θ is a monodromy eigenvalue. This is the Cayley–Hamilton residue of unimodular_two_recurrence, evaluated on the eigenvalue θ rather than the operator.
