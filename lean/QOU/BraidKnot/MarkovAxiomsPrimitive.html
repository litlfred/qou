    QOU.BraidKnot.markov_axioms_primitive #

    Primitive Lean axiomatisation of the four Markov axioms (Jones 1985 / Wenzl 1988) characterising the unique Markov trace τ_M on the Hecke algebra H_n(R, q):

    M1: τ(1) = 1 (normalisation) M2: τ(xy) = τ(yx) (cyclicity) M3: τ(x · σ_n) = z · τ(x) (stabilisation by σ_n) M4: τ(x · σ_n^{-1}) = z₋ · τ(x) (stabilisation by σ_n^{-1}; DERIVED, not independent)

    with z = 1/(√q + 1/√q) the Markov-trace loop value and z₋ = z − (q − q⁻¹) the negative-crossing loop value. M4 is forced by M1+M3 and the Hecke quadratic relation σ⁻¹ = σ − (q − q⁻¹); note z₋ ≠ z for q ≠ ±1. Per prop:markov-trace-frobenius-selection, M1-M3 uniquely pin τ_M as the Frobenius-non-degenerate trace.

    This file:

    1. Defines the 4 axioms as a Lean class MarkovTraceAxioms.
    2. Derives the disjoint-stabilisation factorisation τ(K_1 ⊔ K_2) = τ(K_1) · τ(K_2) · z^k from M3 alone (iterated k times), discharging MarkovDisjointStabilisation class hypothesis used in prop:categorical-chain-convergence-mechanisms.

    LaTeX label: rem:markov-axioms-primitive (helper Lean infrastructure).

    Primitive Markov-trace axiomatisation #

    Generic-R primary definition (Tier 2 formal adjoin) #

    The Markov-Jones parameter markovZax is naturally a function of the formal square root u = √q. Over any field R carrying an element u with u² = q (the formal adjoin R[X]/(X² − q) realises this universally), the parameter has the closed form z = u / (u² + 1) = 1 / (u + u⁻¹).

    The archimedean specialisation markovZax_real (q : ℝ) (hq : 0 < q) instantiates u := Real.sqrt q and recovers the original real-valued formula. See docs/audits/2026-06-01-hoefsmit-tier2-migration-plan.md for the migration roadmap and Policy B rationale.

    Markov-Jones parameter, generic-R Tier 2 form.

    Defined for the formal square root u (any element of a field with u² = q). The closed form u / (u² + 1) avoids Real.sqrt, works over any field, and matches the original 1 / (u + u⁻¹) formula (equivalent by clearing the denominator).

    The Markov KERNEL, not a Markov parameter — convention-C shaped, kept deliberately for comparison (bean qou-cxjq, 2026-08-26).

    The old line here read "Archimedean specialisation: markovZax (Real.sqrt q) = markovZax_real q hq when 0 < q". That is no longer true — markovZax_real is now convention D — and it is removed rather than left to rot.

    markovZax u = u/(u²+1) is convention-neutral as a function; the convention lives in how it is instantiated. Convention C is markovZax √q. Convention D is not markovZax u for any u at all (QOU.BraidKnot.no_kernel_instantiation_is_conventionD: the kernel's real range is [-1/2, 1/2] and z_D q > 1/2 for every q > 1) — it is the rescaling q² · markovZax q, which is what markovZax_real now computes.

    So: do not consume this as a Markov parameter. Use markovZax_real, which is convention D.

          class QOU.BraidKnot.MarkovTraceAxioms {R : Type u_1} [Field R] (u : R) :
          Type u_1

          Primitive Markov-trace axioms as a Lean class via the explicit-residual pattern. Captures the axioms M1 and M3 from Jones 1985 / Wenzl 1988 that (with cyclicity M2, implicit in the trace construction) uniquely characterise the Markov trace on H_n(R, q); M4 is derived from M3 via the Hecke quadratic relation, with the distinct loop value z₋ = z − (q − q⁻¹).

          Each axiom is encoded as a scalar invariant (residual / stab factor) plus an equation pinning it to the required value.

          Tier 2 generic-R form (Phase 2 of the q-usage Hoefsmit migration, PR #1640 / #1658). The class is parameterised by an abstract field R and an element u : R; the intended physical interpretation is that u is a formal square-root of the Hecke parameter q, but the class itself imposes no u² = q constraint — that hypothesis enters at the callsite for any concrete instantiation that needs it.

          Archimedean entry points: MarkovTraceAxioms_real q (an abbrev of MarkovTraceAxioms (Real.sqrt q)) and the _real wrappers markov_iterated_stab_real and disjoint_product_factorisation_real below carry an explicit (hq : 0 < q) hypothesis so they avoid the q-usage-positivity-implicit warning. There are no instances of this class on main at the time of this Phase 2 refactor, so no archimedean callers are broken.

          • tau_identity : R

            M1: scalar value of τ on the identity element.

          • tau_identity_eq_one : tau_identity u = 1

            M1: τ(1) = 1 (normalisation).

          • tau_stab_factor : R

            M3: stabilisation factor. Adding one disjoint strand multiplies a trace value by markovZax u.

          • tau_stab_factor_eq_z : tau_stab_factor u = markovZax u

            M3: the stabilisation factor equals z = u / (u² + 1).

              Disjoint-product factorisation (derived from M3): two braids K_1, K_2 acting on disjoint strands give the factorised joint trace.

              K_1 has trace τ_K1, K_2 has trace τ_K2; their joint trace after stabilising k disjoint strands is:

              τ_M(K_1 ⊔ K_2) = τ_K1 · τ_K2 · z^k

              This DISCHARGES the MarkovDisjointStabilisation axiomatic class used in prop:categorical-chain-convergence-mechanisms (Mechanism 2).
