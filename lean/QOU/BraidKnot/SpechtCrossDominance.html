    Sagan Lemma 2.2.6 — the cross-shape dominance criterion #

    If t is a μ-tableau and s a ν-tableau on the same label set, and no two labels sharing a column of t share a row of s, then μ dominates ν.

    This is the combinatorial core of Sagan's cross-shape theory (§2.2–2.4), and the missing ingredient of SpechtClassification.spechtIso_imp_dom_both.

    The argument #

    Fix r and count the labels in the first r rows of s, sorted by their column in t:

    • by rows of s, there are Σ_{j<r} ν_j of them;
    • in a fixed column c of t there are at most min r (μ.colLen c) — at most r because the no-clash hypothesis makes the row-in-s map injective on each column of t, and at most μ.colLen c because that is how long the column is;
    • summing over columns, Σ_c min r (μ.colLen c) counts the cells of μ in its first r rows, which is Σ_{j<r} μ_j.

    So Σ_{j<r} ν_j ≤ Σ_{j<r} μ_j for every r, which is dominance.

    Relation to SpechtIrreducible §4.x #

    The same-shape specialisation of this count already lives there, inside row_lt_colLen, where it feeds the Gale–Ryser matching noclash_match_exists. This module states the count in the cross-shape generality Sagan's §2.4 needs. Its two cell-counting ingredients were private there and are now public; they are imported rather than re-derived.

    What this does not finish #

    spechtIso_imp_dom_both also needs the module-theoretic half of Sagan 2.4.4 — the cross-shape κ_t acting on M^ν, the vanishing κ_t {s} = 0 under a clash, and the extension of a homomorphism S^μ → M^ν to M^μ along the decomposition SpechtIrreducible.isCompl_specht_perp. See the bean for the plan.

    1. Counting cells through a tableau bijection #

    filterCard_reindex and colCells_card are SpechtIrreducible's §4.x helpers, made public there rather than re-derived here — they are the same counts, and a second copy would be a second thing to keep true.

    source
    theorem QOU.BraidKnot.SpechtCrossDominance.card_cells_row_lt (μ : YoungDiagram) (r : ℕ) :
    {cell ∈ μ.cells | cell.1 < r}.card = ∑ j ∈ Finset.range r, μ.rowLen j

    The number of labels in the first r rows, read off the cells: it is the partial sum of row lengths.

    2. The dominance criterion, abstractly #

    Stated on a bare label type with the two pattern functions and their fiber counts as hypotheses, so it can be applied across two different shapes without transporting a tableau.

    source
    theorem QOU.BraidKnot.SpechtCrossDominance.dominance_of_noclash {n : ℕ} {μ ν : YoungDiagram} (ct rs : Fin n → ℕ) (hcolMem : ∀ (l : Fin n), ct l ∈ Finset.image Prod.snd μ.cells) (hcolCard : ∀ (c : ℕ), {l : Fin n | ct l = c}.card = μ.colLen c) (hrowCard : ∀ (r : ℕ), {l : Fin n | rs l < r}.card = ∑ j ∈ Finset.range r, ν.rowLen j) (hnoclash : ∀ (a b : Fin n), ct a = ct b → rs a = rs b → a = b) (i : ℕ) :
    ∑ j ∈ Finset.range i, ν.rowLen j ≤ ∑ j ∈ Finset.range i, μ.rowLen j

    Sagan Lemma 2.2.6 (abstract form).

    ct is the column pattern of a μ-tableau, rs the row pattern of a ν-tableau, both on the same n labels. If no two labels share both a column under ct and a row under rs, then μ ⊵ ν.

    The conclusion is stated as the raw partial-sum inequality, which is definitionally SpechtClassification.partitionDom μ ν.

    Sagan Lemma 2.2.6, for tableaux. t of shape μ and s of shape ν on the same labels (via h): if no column of t meets a row of s twice, then μ dominates ν.
