    QOU.BraidKnot.RowStandardTableau — the index set Murphy's straightening runs over #

    Mathas' Lemma 3.14, the one remaining input to the Murphy basis (HeckeMurphyYoung.basisOfSpanning), is a statement about row-standard tableaux: for s, t row-standard of shape λ, m_{st} is a combination of m_{uv} with u, v standard of shape ν, where either ν ⊳ λ, or ν = λ and u ⊵ s, v ⊵ t.

    The corpus had no row-standard notion, and that absence is what blocks the spanning leg rather than any difficulty in the argument. The gap is quantitative and it is large:

    shape row-standard μ-tableaux standard μ-tableaux
    general μ ⊢ n n! / ∏ᵢ μᵢ! f^μ
    one column (1ⁿ) n! 1

    HeckeMurphyYoung.span_murphySum_one_conjugates_eq_top (step 2 of spanning) is exactly the one-column row: every T_w is a Murphy element there, because x_{(1ⁿ)} = 1 and every filling of a single column is row-standard. Against the standard family that shape contributes a single element, so the statement cannot be made there at all — hence this file.

    Why a predicate and not a new structure #

    Specht.Tableau μ = Fin (nOf μ) ≃ μ.cells is already the arbitrary bijective filling, and it is what HeckeMurphyYoung.dOf, dAt and murphyM consume. Row-standardness is a condition on such a filling — labels increase along each row — so it is a predicate, and a row-standard tableau is a subtype. Nothing downstream has to be re-plumbed. (BraidKnot.StandardYoungTableau is a different, entry-based structure carrying both row_strict and col_strict; the row-standard condition is that structure minus the column half, but expressed on the filling type the Hecke side already speaks.)

    References #

    • [mathas1999] Mathas, Iwahori–Hecke Algebras and Schur Algebras of the Symmetric Group, §3 (the Murphy basis; Lemmas 3.9, 3.12, 3.13, 3.14).
    • [sagan2001] Sagan, The Symmetric Group, §2.6 (Garnir relations, the q = 1 template).

    Prop

    Row-standard: within any one row, label order agrees with column order.

    Stated as the single implication same row → earlier column → smaller label. The converse follows from it (both patterns are determined by the filling, which is a bijection), so this is the convenient form to use: a hypothesis about columns discharges a goal about labels.

        The one-column shape #

        A shape with no cell in column 1 has every row of length at most one, so no two distinct labels share a row and the row-standard condition is vacuous: every filling qualifies. YoungDiagram is closed under moving up and left, so (0,1) ∉ μ is the whole hypothesis.

          Standard ⟹ row-standard #

          Mathas' Lemma 3.14 rewrites a row-standard pair as a combination of standard pairs, so the two index sets have to be related in the obvious direction: a standard tableau, read as a filling, is row-standard. That is the forgetful map Std(μ) → RowStd(μ).

          It is not quite immediate. StandardYoungTableau.row_strict compares only adjacent cells (entry i j < entry i (j+1)), while row-standardness compares arbitrary pairs in a row, so the transitive form has to be proved first. entry_lt_entry_of_lt below does that by induction on the right-hand column, using the diagram's up-left closure to know the intermediate cells are present.

          entry_lt_entry_of_lt is a statement about StandardYoungTableau alone and belongs upstream in QOU.BraidKnot.StandardYoungTableau; it is here to keep this change to a single file, the same call as the Tw_mul_σ_* lemmas in HeckeMurphyYoung.

          The transitive closure of row_strict, by induction on the right-hand column. The up-left closure of a YoungDiagram supplies the intermediate cells: if (i, j') is in the diagram then so is every (i, k) with k ≤ j'.

          theorem QOU.BraidKnot.RowStandardTableau.isRowStandard_sytToTableau {μ : YoungDiagram} (T : StandardYoungTableau μ) :
          IsRowStandard (SpechtStandardBasis.sytToTableau T)

          A standard tableau, read as a filling, is row-standard — the forgetful map Std(μ) → RowStd(μ) that Lemma 3.14's target side needs.

          sytToTableau T is the inverse of cellLabel T, so a label l sits at the cell c with cellLabel T c = l, and cellLabel is literally T.entry on that cell. Two labels in the same row with the earlier column therefore compare exactly as their entries do, which is entry_lt_entry_of_lt.

          Column-standard, and standard, on the same filling type #

          Lemma 3.14's target side is a standard pair, so "standard" is needed as a predicate on Specht.Tableau μ too — the same type the row-standard predicate and the whole q = 1 Garnir apparatus (colWordNum, garnirA/garnirB/garnirG) already live on. With IsStandard here, all three index sets of Mathas' Lemma 3.14 — row-standard source, standard target, and the map between them — are expressed on one type, and the statement of 3.14 no longer has anything missing.

          Everything below mirrors the row case exactly, col_strict for row_strict throughout.
