    Graded Markov trace from the GS filtration #

    The graded Markov trace at level ℓ is the induced trace on the quotient J^ℓ / J^{ℓ+1} of the Gröbner–Shirshov filtration, and is purely algebraic over a generic commutative ring (no Archimedean function theory).

    Disposition (derived, sorry-free) #

    The proposition prop:graded-markov-trace-from-gs-filtration asserts that for each level ℓ there is a uniquely determined linear trace

    tr_{M,ℓ} : J^ℓ / J^{ℓ+1} → R

    characterised by quotient compatibility (tr_{M,ℓ} ∘ π_ℓ = tr_M|_{J^ℓ}), well-defined because tr_M is filtration-respecting.

    This is exactly the universal property of the quotient: given the filtration data and the filtration-respecting hypothesis (tr_M vanishes on J^{ℓ+1}) as the legitimate inputs, the induced trace exists (Submodule.liftQ) and is unique (a linear map out of a quotient is determined by its values on representatives). We therefore derive the existence-and-uniqueness statement sorry-free from those inputs (gradedTrace_exists_unique), rather than projecting it from a class field.

    This replaces the previous self-assuming class GradedMarkovTraceFromGSFiltration whose field descends_from_markov : gradedTrace 0 = markovValue was the conclusion, projected by theorem … := s.descends_from_markov (forbidden by AGENTS.md §1a / §3b-cond rule 5). The carried data here (filtration, trace, filtration_respecting) are genuine inputs; the descent map and its uniqueness are produced, not assumed.

    The construction is purely algebraic over [CommRing R] (AGENTS.md §7c) — no analytic continuation, complex evaluation, or roots of unity. The upstream fact that tr_M is filtration-respecting for the GS filtration (Cartan–Eilenberg + Jones' Markov-trace existence) is the hypothesis filtration_respecting, supplied by the GS-filtration theorem prop:gb-spectral-sequence.

    GS-filtration data for the graded Markov trace.

    Bundles the genuine inputs of prop:graded-markov-trace-from-gs-filtration:

    • M — the ambient R-module (the Hecke algebra H_n(R, q)),
    • filtration ℓ = J^ℓ — the descending two-sided GS-filtration,
    • filtration_mono — J^{ℓ+1} ⊆ J^ℓ,
    • trace = tr_M — the Markov trace as an R-linear functional,
    • filtration_respecting — tr_M vanishes on J^{ℓ+1} (the filtration-respecting property the descent needs).

    No field encodes the descent conclusion: the induced trace and its uniqueness are derived by gradedTrace_exists_unique below.

      The descending GS-filtration J^ℓ.

    • filtration_mono (ℓ : ℕ) : self.filtration (ℓ + 1) ≤ self.filtration ℓ

      J^{ℓ+1} ⊆ J^ℓ.

    • trace : self.M →ₗ[R] R

      The Markov trace tr_M : H_n(R, q) → R as a linear functional.

    • filtration_respecting (ℓ : ℕ) (x : self.M) : x ∈ self.filtration (ℓ + 1) → self.trace x = 0

      Filtration-respecting (the legitimate input, not the conclusion): tr_M vanishes on J^{ℓ+1}.
