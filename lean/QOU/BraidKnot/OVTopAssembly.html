    QOU.BraidKnot.OVTopAssembly — the TOP / capstone of the Okounkov–Vershik tower #

    This file is the keystone of the keystone: it assembles bricks 2 / 3 / 5 together with the Wedderburn–Artin decomposition of R[S_n] into a single RegularRepBlockTrace.SnWedderburnSpectralData R n, and thereby discharges the side-2 hypothesis of Identity (B). The §3b-cond conditional theorem RegularRepBlockTrace.identityB_conditional — if a Wedderburn / Jucys–Murphy block spectral decomposition exists, then Σ_λ ω_λ·dim(λ)² = n!·binom(n,2) — becomes, via this assembly, the unconditional general-n Identity (B) (modulo the bricks' own honest stubs).

    What this capstone does #

    sn_spectralData_exists n : Nonempty (SnWedderburnSpectralData R n) constructs the structure, wiring each field to the brick that supplies it. The construction is de-abstracted: the six projection-data fields no longer carry bare opaque sorrys — each is wired to the named brick theorem it cites, via the glue lemma snBlocks (the OV-reindexing residual, itself now discharged by SnWedderburnPartitionBridge.snBridge — no direct sorry) and per-field consumption of the proved/stubbed bricks.

    rank re-route (brick-4 finrank → proved independence) #

    The rank field formerly rewrote with the opaque brick-2 stub Specht.specht_finrank_eq_numSYT (a bare sorry : finrank Sᵘ = numSYT μ). It now rewrites with SpechtFinrankWired.specht_finrank_eq_numSYT_wired, which rebuilds the same dim Sᵘ = #SYT identity from the standard polytabloid basis but sources linear independence from the proved triangular core SpechtTriangularCore.standardPolytabloid_triangular' (sorry-free — its dominance core SpechtDominanceCore.dominance_relation_exists is discharged on the pinned oleans) instead of the independence stub. Consequently the rank sorry-path no longer contains the independence stub SpechtStandardBasis.standardPolytabloid_triangular nor the opaque brick-2 finrank stub; its only remaining sorry is the spanning / straightening stub SpechtStandardBasis.standardPolytabloid_straightening (via standardPolytabloid_span). The basis- building + finrank machinery itself is sorry-free (demonstrated: a Basis.mk whose independence and spanning are both supplied as hypotheses depends only on [propext, Classical.choice, Quot.sound]), so the spanning stub is genuinely the sole residual.

    identityB_general n is the payoff: it feeds (sn_spectralData_exists n).some into RegularRepBlockTrace.identityB_conditional, yielding the Identity-(B) trace equation Σ_i ω_i · dim(λ_i)² = n!·binom(n,2) for all n — modulo the tower's stubs.

    Base ring (§7c) #

    variable {R : Type} [Field R] [CharZero R]. This is algebraic: Field is what the structure and the Wedderburn decomposition need; CharZero is what the brick-3 classification needs. No ℝ, no Real.*, no ordering on R, no archimedean tactics — the eigenvalues / contents are integers cast into the field.

    This module carries honest sorry targets, so — like bricks 1–5 — it is intentionally not wired into the QOU.BraidKnot umbrella (that would taint the umbrella's sorry-free CI surface). Verified standalone via lean-direct against the pinned v4.24.0 oleans.

    The OV-reindexing residual + C₂ decomposition — from SnWedderburnPartitionBridge #

    The keystone's SnWedderburnSpectralData needs a partition-indexed isotypic projection family of R[S_n] that is simultaneously the snBlocks bundle (projections, ranks (dim Sᵘⁱ)², completeness) and block-diagonalises the central Jucys–Murphy element mulLeft C₂ with eigenvalues contentSqSum λ_i. These two halves are inseparable: mulLeft C₂ is block-diagonal only in the isotypic frame, which is strictly stronger than the size-aligned frame of snBridge (distinct partitions can share dim Sᵘ, so a size-aligned split need not be isotypic-aligned; see SnWedderburnPartitionBridge §5). Both are therefore supplied together by the single aligned core SnWedderburnPartitionBridge.snBlocks_c2_aligned.

    History / correction. Earlier revisions split this into a snBlocks (delegating to the size-aligned snBridge) plus a separate c2_eigen_on_blocks that took the projection family as a free argument. That free-proj decomp statement is false, machine-proved as SnWedderburnPartitionBridge.freeProjClaim_false (instantiate proj ≡ 0 ⇒ mulLeft C₂ = 0 ⇒ C₂ = 0, contradicting C₂(1) = binom(n,2) ≠ 0) — because mulLeft C₂ is block-diagonal only for the specific isotypic projections, not an arbitrary snBlocks/snBridge family. The over-general c2_eigen_on_blocks is removed in favour of the aligned core.

    TOP of the OV tower — the Wedderburn / Jucys–Murphy block spectral decomposition exists.

    We construct the keystone's SnWedderburnSpectralData R n by wiring each field to its brick:

    • Idx := SpechtClassification.PartitionIndex n (brick 3) — sorry-free, with its Fintype.
    • d i := numSYT i.diagram (bricks 1/2, dim Sᵘ = #SYT) — sorry-free definition.
    • ω i := ((contentSqSum i.diagram : ℤ) : R) (brick 5, the JM content-square eigenvalue) — sorry-free definition.
    • p / proj / isProj / complete / decomp are all drawn from the single aligned core SnWedderburnPartitionBridge.snBlocks_c2_aligned (the isotypic projection family and the C₂ block-decomposition, produced together; Ref sn_rational_specht_split strengthened to isotypic alignment + JucysMurphy.centralC2_acts_by_contentSqSum).
    • rank i additionally consumes the brick-4 wired finrank SpechtFinrankWired.specht_finrank_eq_numSYT_wired load-bearingly (a rw turning the aligned core's block-size (dim Sᵘⁱ)² into the field's (numSYT λ_i)²). This wired finrank sources independence from the proved core SpechtTriangularCore.standardPolytabloid_triangular', so the rank sorry-path is the spanning / straightening stub only — not the independence stub and not the opaque brick-2 finrank stub Specht.specht_finrank_eq_numSYT.
