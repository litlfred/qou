    Length additivity holds at every descent node #

    This closes the length half of Mathas' Lemma 3.13.

    What is proved #

    For a row-standard tableau t and any descent node (i,j) of it,

    invSet (garnirPerm i j) ⊆ invSet (dOf t)

    which by length_dOf_smul_eq_add_iff (QOU.BraidKnot.TableauPerm, from QOU.Hecke.Inversions.length_mul_eq_add_iff) is exactly

    ℓ(d(t)) = ℓ(d(g_{ij})) + ℓ(w) where t = w • g_{ij}.

    No minimality hypothesis #

    Mathas' statement, and the corpus probe built from it, ask only that some descent node work, and the probe reports that the first one always does. The proof below shows the condition holds at every descent node, so no minimality, ordering, or choice is needed anywhere.

    That is visible once the containment is unfolded. The rotation's inversions are exactly the pairs (label in row i from column j on, label in row i+1 up to column j), and dOf t sends a reference label to t's entry in that cell, so the containment says precisely

    t(i,c) > t(i+1,c') for all c ≥ j, c' ≤ j,

    and row-standardness chains it out of the single descent inequality:

    t(i,c) ≥ t(i,j) > t(i+1,j) ≥ t(i+1,c').

    Corroborated before it was proved: computations/hecke/garnir_all_descent_nodes_probe.py finds additivity at 3685 of 3685 descent nodes over the 1789 row-standard non-standard tableaux with n = 3..6.

    What is still open #

    Mathas 3.13 also asserts that a non-standard row-standard tableau has a descent node. That is a separate statement (a failure of column-standardness produces one) and is not proved here.

    Length additivity holds at every descent node.

    For a row-standard t and any descent node (i,j), every inversion of the Garnir permutation is an inversion of d(t) — which by length_dOf_smul_eq_add_iff is exactly ℓ(d(t)) = ℓ(d(g_{ij})) + ℓ(w).

    No minimality hypothesis: the argument never compares (i,j) with any other descent node.
