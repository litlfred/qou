    The Garnir shape has the same size — the connector 3.14's outer induction needs #

    GarnirShape.garnirShape_lexGt gives garnirShape μ i j >ₗ μ, and PartitionLexWellFounded.lexGtOn is the well-founded order 3.14's case (i) inducts along. They do not compose as they stand: lexGtOn n lives on PartOf n, shapes of a fixed size, so feeding the Garnir shape into it needs

    `(garnirShape μ i j).cells.card = μ.cells.card`

    This file supplies it, and with it lexGtOn_garnirPartOf: the Garnir step drops the shape in the very order 3.14's outer induction runs on.

    **🛑 CORRECTION. An earlier version of this file recorded the last step as blocked by a missing lemma — (ofRowLens w hw).rowLens.sum = w.sum with no positivity hypothesis — and said so in its docstring and commit message. That was wrong. QOU.Mathlib.card_cells_ofRowLens proves exactly (ofRowLens L hsort).cells.card = L.sum, with no positivity hypothesis, and it sits one screen above card_cells_eq_rowLens_sum in SchenstedPartitionShape.lean — the file this one was already importing and citing. The Mathlib half of that claim was right and was measured by environment enumeration; the corpus half was never checked at all. card_garnirShape below is now three rewrites.

    Why the count works out #

    garnirComp μ i j replaces rows i, i+1 of μ — of lengths rowLen i and rowLen (i+1) — by the three entries

    `j`,  `rowLen i + 1`,  `rowLen (i+1) - j - 1`

    whose sum is rowLen i + rowLen (i+1) provided j + 1 ≤ rowLen (i+1), which is exactly what (i+1, j) ∈ μ gives. The subtraction is truncated ℕ subtraction, so that hypothesis is doing real work rather than bookkeeping: without it the third entry clamps at 0 and the count is wrong.

    Everything else is take/drop reassembly, and sorting is invisible to a sum because sortDesc is a permutation.

    The bridge lemma exists three times over #

    cells.card = rowLens.sum is in the corpus as SchenstedPartitionShape.card_cells_eq_rowLens_sum, again as WenzlJonesMarkovNormalisation.rowLens_sum_eq_card, and a third time as SpechtClassification.card_eq_rowLens_sum. Three independent proofs of one lemma is worth recording, not fixing here.
