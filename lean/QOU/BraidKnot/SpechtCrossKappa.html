    The cross-shape column antisymmetriser κ_t acting on M^ν #

    SpechtIrreducible builds κ_t = Σ_{π ∈ C_t} sgn(π) · π acting on M^μ, where t is a μ-tableau. Sagan's cross-shape theory (§2.4) needs the same operator acting on M^ν for a different shape ν with the same number of cells: the column group C_t ≤ S_n does not care which diagram the module came from.

    This module supplies that, and the one fact about it Sagan 2.4.4 consumes:

    κ_t {s} ≠ 0 forces no column of t to meet a row of s twice,

    whose contrapositive is the sign-reversing involution already used same-shape in SpechtIrreducible.kap_of_mem_line_clash. Composed with SpechtCrossDominance.dominance_of_tableau_noclash (Sagan 2.2.6) it gives the headline of this file:

    κ_t {s} ≠ 0 ⟹ μ ⊵ ν.

    The transport #

    C_t ≤ Perm (Fin (nOf μ)) while Mtab.rep ν takes Perm (Fin (nOf ν)), so everything is threaded through transportPerm h, the multiplicative transport along h : nOf μ = nOf ν. It is definitionally SpechtClassification.transportPermHom h — the same term — so the two agree by rfl where they meet; that module is downstream and cannot be imported here.

    Nothing else in the argument depends on μ ≠ ν; taking ν = μ and h = rfl recovers the same-shape statements.

    Outcome #

    SpechtClassification.spechtIso_imp_dom_both is proved from this file plus SpechtCrossDominance, and with it specht_pairwise_noniso. The assembly is SpechtClassification.dom_of_intertwiner.

    The extension of a homomorphism S^μ → M^ν to all of M^μ — the step the textbook proof needs M^μ = S^μ ⊕ (S^μ)ᗮ for — turned out to be avoidable; see §3-bis.

        3. A clash kills it #

        The same sign-reversing involution as SpechtIrreducible.kap_of_mem_line_clash: if two labels share a column of t and a row of s, the transposition swapping them lies in C_t, fixes the tabloid {s}, and pairs the C_t-sum off against itself with opposite signs.

        (kapCross h t) (Specht.Mtab.of s) = 0

        Clash ⇒ vanishing. If a ≠ b share a column of t and (after transport) a row of s, then κ_t {s} = 0.

        3-bis. κ_t is idempotent up to |C_t| #

        κ_t κ_t = |C_t| · κ_t, because for fixed π the map ρ ↦ πρ is a bijection of C_t and sgn(π)sgn(ρ) = sgn(πρ).

        This is what lets the assembly of Sagan 2.4.4 skip the extension of a homomorphism S^μ → M^ν to all of M^μ. The textbook argument writes θ(e_t) = θ(κ_t {t}) = κ_t θ({t}), which needs θ defined on the tabloid {t} ∉ S^μ, hence needs M^μ = S^μ ⊕ (S^μ)ᗮ. But κ_t e_t = |C_t| e_t stays inside S^μ, so equivariance of θ on S^μ alone already gives κ_t θ(e_t) = |C_t| θ(e_t) ≠ 0, which is all the dominance argument needs.

        SpechtIrreducible.isCompl_specht_perp is therefore not on the critical path for spechtIso_imp_dom_both; it remains as the honest orthogonal decomposition.

        4. Non-vanishing forces dominance #

        The contrapositive of §3 is exactly the hypothesis of Sagan Lemma 2.2.6.
