    QOU.BraidKnot.plancherel_weight_boundedness #

    Plancherel weights w_λ = (dim V_λ)² / n! (with dim V_λ the classical, q-independent Hecke irrep dimension) form a probability distribution on partitions of n: each w_λ ∈ [0, 1] and Σ_λ w_λ = 1 exactly.

    Remark: the q-deformed alternative dim_q²/[n]_q! does NOT sum to 1 at finite q ≠ 1 (empirical: ~1.51 at q₀ ≈ 1.1097, n = 12); it is recorded alongside but is not the probability measure.

    This formalises the convergence guarantee for the curvature-rank strata Φ_k and the universal Frobenius co-Casimir tail.

    Base ring (AGENTS.md §7c) #

    Pre-archimedean: the statements below hold over any linearly ordered commutative ring R — [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] — and use no completeness, no Real.* function and no archimedean axiom. Only the order is needed (for 0 ≤ w_λ, |·| and Finset.single_le_sum). This matches the narrative, which asserts Σ_λ w_λ = 1 exactly in ℚ: the classical weights (dim V_λ)²/n! are rational, so R := ℚ is already an instance and the previous ℝ specialisation was gratuitous. R := ℝ remains an instance for archimedean evaluation downstream.

      Proposition (Plancherel-weight boundedness).

      The Plancherel distribution on partitions of n satisfies:

      1. Each weight is in [0, 1].
      2. Sum of weights is 1.

      Hence any bounded function f : Partition → R has a Plancherel average bounded by ‖f‖_∞.

      Stated over any linearly ordered commutative ring (§7c).
