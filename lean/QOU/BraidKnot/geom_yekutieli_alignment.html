    class QOU.BraidKnot.GeomYekutieliAlignmentContext (R : Type u_1) [CommRing R] :
    Type u_1

    Abstract context for the geom_yekutieli_alignment claim — manuscript-themed typed fields below; sub-claims encode the piecewise geometric-invariant formula for Geom(K) (three cases: hyperbolic / torus / unknot). Over a generic substrate ring R per §7c.

    • hbar_q : R

      The quantum Planck constant ℏ_q = 1 − 1/q.

    • hbar_q_inv : R

      The inverse of the quantum Planck constant.

    • hbar_inv_mul : hbar_q * hbar_q_inv = 1

      hbar_q is a unit, witnessing hbar_q * hbar_q_inv = 1.

    • Vol_q : R

      The algebraic quantum volume Vol_q(K) of the knot complement.

    • CS_q : R

      The algebraic Chern–Simons invariant CS_q(K) of the knot.

    • Geom : R

      The piecewise geometric invariant Geom(K) : R.

    • geom_identity : Geom = Vol_q * hbar_q_inv ^ 2 + CS_q * hbar_q ^ 2

      Master algebraic relation. The evaluation of the rigid dualizing complex admits a single closed-form expression Geom = Vol_q / hbar_q² + CS_q · hbar_q².

    • is_hyperbolic : Prop

      Predicate: the knot is hyperbolic.

    • is_torus : Prop

      Predicate: the knot is a torus knot.

    • is_trivial : Prop

      Predicate: the knot is the unknot.

    • hyperbolic_implies_cs_zero : is_hyperbolic R → CS_q = 0

      Regime consequences: in the algebraic-hyperbolic regime, CS_q = 0.

    • torus_implies_vol_zero : is_torus R → Vol_q = 0

      Regime consequences: in the algebraic-torus regime, Vol_q = 0.

    • trivial_implies_both_zero : is_trivial R → Vol_q = 0 ∧ CS_q = 0

      Regime consequences: in the algebraic-trivial regime, both vanish.

    • trM : R

      The per-block Markov-trace factor of the knot's own Hecke level: trM = Σ_λ w_λ χ_λ(β_K)/dim λ (prop:hoefsmit-scattering-pipeline Stage 2/4), evaluated over the partitions of the KNOT'S OWN strand count (H₃ for the 3-strand Borromean baryons — NOT a fixed global level).

    • boundaryHolonomy : R

      The boundary holonomy of the categorical connection: the surface-ordered exponential Hol_∂Σ A of the gauge field A over the boundary of the Seifert surface Σ of β_K (Yekutieli non-abelian Stokes, surface-ordered integral).

    • massFactor : R

      The physical mass factor (prop:hoefsmit-scattering-pipeline Stage 4, before scaling by m_e): Geom(K) · trM.

    • claim_iv_holonomy_equals_trM : boundaryHolonomy = trM

      Manuscript sub-claim (iv) — Yekutieli alignment (CONJECTURAL). The boundary holonomy of the categorical connection equals the Hecke Markov trace: Hol_∂Σ A = trM. This is the non-abelian Stokes identification of Stage 3 — surface curvature integrates to the boundary trace. It is the conjectural join conj:geom-yekutieli-alignment; the class instance is the §3b-cond axiomatisation (the only sorry in the chain).

    • mass_factor_def : massFactor = Geom * boundaryHolonomy

      Definition — Stage-4 per-block mass factor. The mass factor is defined as Geom(K) times the boundary holonomy.
