    The C8 lower bound (arithmetic core, proved) #

    source
    theorem QOU.BraidKnot.KeystoneC8SuperExpBound.c8_lower_bound {ι : Type u_1} (s : Finset ι) (f g : ι → ℝ) (kfac Ik : ℝ) (hg : ∀ i ∈ s, 0 ≤ g i) (hkfac : 0 < kfac) (hIk : 0 < Ik) (hA : ∑ i ∈ s, f i * g i = kfac / 3) (hC : ∑ i ∈ s, g i ≤ Ik) :
    kfac / (9 * Ik) ≤ (∑ i ∈ s, f i ^ 2 * g i) / kfac

    C8 super-exponential lower bound. With w_std := (Σ f² g)/kfac, the identity Σ f g = kfac/3 (input A), and Σ g ≤ Ik (input C, Ik = I(k)), the Plancherel-weighted branched sum obeys w_std ≥ kfac/(9·Ik). Cauchy–Schwarz is weighted_cs (proved); only (A)/(C) are SYT-supplied.

    Involution numbers (concrete; I(k) = Σ_{λ⊢k} f^λ at q=1) #

    This file used to define its own involutionNumber. It was a second, independent definition of the sequence QOU.Mass.involutionNumber already carried — same two base cases, same recurrence, no shared code. The duplication was harmless only by luck: the two constants were distinct, so a lemma proved about one said nothing about the other, and bridging them needed an explicit induction (involutionNumber_eq_keystone, now deleted as redundant).

    The single definition now lives in QOU/Mass/InvolutionNumbers.lean, where the substantive content also sits — card_involutions_eq_involutionNumber, that I(n) counts the involutions in S_n. The export below keeps KeystoneC8SuperExpBound.involutionNumber resolving, so every existing reference and the fully-qualified name both still work.

    I(k) = Σ_{λ⊢k} f^λ — the q=1 value of the QOU na-Stokes period S(n) = Σ_λ dim_q(λ) — is proved in QOU.Mass.sum_numSYT_eq_involutionNumber.

    Genuinely super-exponential lower bound (square form, no √) #

    source
    theorem QOU.BraidKnot.KeystoneC8SuperExpBound.c8_superexp_sq_lower_bound {ι : Type u_1} (s : Finset ι) (f g : ι → ℝ) (kfac Ik : ℝ) (K : ℕ) (hg : ∀ i ∈ s, 0 ≤ g i) (hkfac : 0 < kfac) (hIk : 0 < Ik) (hA : ∑ i ∈ s, f i * g i = kfac / 3) (hC : ∑ i ∈ s, g i ≤ Ik) (hIsq : Ik ^ 2 ≤ 2 ^ K * kfac) :
    kfac / (81 * 2 ^ K) ≤ ((∑ i ∈ s, f i ^ 2 * g i) / kfac) ^ 2

    C8 super-exponential lower bound — square form. The bare c8_lower_bound combined with the crude Ik ≤ kfac (involution_le_factorial) only yields the constant w_std ≥ 1/9. Feeding the sharper Gevrey-1/2 involution bound Ik² ≤ 2^K·kfac instead gives a genuinely super-exponential lower bound on the square:

    w_std² ≥ kfac / (81 · 2^K) ( = k!/(81·2^k) at kfac = k!, K = k ),

    and k!/2^k → ∞ super-exponentially — so w_std itself leaves every geometric class. Squaring sidesteps Real.sqrt entirely: pure algebra over the two proved inputs. This is the arithmetic core the C8 audit's "super-exponential" claim actually needs (the 1/9 constant did not deliver it).
