    QOU.BraidKnot.AJTrefoil #

    The AJ conjecture at the QOU electron knot (trefoil), stated concretely.

    Companion to QOU.BraidKnot.AJFigureEight, completing the AJ statement layer for the QOU knot set ("do the same for the trefoil", bean 3eeq; audit: docs/audits/2026-07-03-aj-conjecture-dialog-assessment.md §"Prove AJ in QOU, fully"). AJ for the trefoil is literature-established (two-bridge knots — Lê 2006; Ref: [garoufalidis2004] for the statement); the corpus-side reconstruction + verification is computations/aj_trefoil_operator_construct_verify.py (witness aj-trefoil-operator-construct-verify.witness.json): the tower is the Rosso–Jones twist-eigenvalue sum for the closure of σ₁³ in B₂ with the convention self-anchored against the Jones polynomial (left-handed V(3₁) = −q⁻⁴ + q⁻³ + q⁻¹); the annihilator is inhomogeneous order 1 (the trefoil A-polynomial is linear in L), verified exactly for N = 1..10, with q → 1 specialization (1−M²)/M¹⁰ · (1 + L·M⁶) under the meridian-squared convention.

    Encoding #

    The braiding eigenvalues live at quarter-powers of q, so the tower is parameterized by w with q = w⁴: T_j = (−1)^{n−j} w^{2j(j+1) − n(n+2)} (integer ℤ-powers of w), J_N = w^{−3n(n+2)} · (∑_{j≤n} T_j³ [2j+1]_v) / [N]_v, v = w², n = N−1.

    Honest status (§3b) #

    Machine-checked sorry-free: the operator transcription, the q = 1 specialization to the classical trefoil A-polynomial 1 + L·M⁶, nontriviality (char 0, single witness — no case split needed), unit nondegeneracy, and — since the root-of-unity evaluation cores were discharged in QOU.BraidKnot.AJTrefoilRootEval — the general-N annihilation assembled in QOU.BraidKnot.AJTrefoilAnnihilation. No sorry remains anywhere in the trefoil strong-AJ chain. Unlike 4₁ there is no bar-transport theorem: the trefoil is chiral, its tower is not bar-symmetric — the operator-level face of chirality.

    Base ring (§7c) #

    Generic {K : Type*} [Field K] (+ [CharZero K] where stated); ℤ-powers via zpow; no ℝ, no ordering, no archimedean constructs.
