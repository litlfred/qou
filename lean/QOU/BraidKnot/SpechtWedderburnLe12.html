    QOU.BraidKnot.SpechtWedderburnLe12 — the Wedderburn split, unconditionally, for n ≤ 12 #

    Brick 6 of W1+W3 of the Wedderburn epic (qou-bxw4), and the first unconditional result of the arc.

    SpechtWedderburnCriterion reduced the split to one number: spechtProduct is an algebra isomorphism as soon as Σ_{μ ⊢ n} (#SYT μ)² = n!. That number is not open at every n — the corpus already proves it for n ≤ 12, by a route with no RSK correspondence in it at all (PartitionsOfBridge.rskBurnsideHolds_le12: decide-verified list-model data fed through the hook-length bridge). Measured, not assumed: #print axioms on that theorem reports only propext, Classical.choice, Quot.sound.

    So for n ≤ 12,

    k[S_n] ≃ₐ[k] ∏_{μ ⊢ n} End_k(S^μ)

    over any characteristic-zero field, sorry-free and axiom-free.

    What the bridge costs #

    Two index changes, both already available:

    • SpechtClassification.partitionEquivYoungIndex : Nat.Partition n ≃ PartitionIndex n — and the diagram it produces is definitionally RSKBurnsideTarget.partitionShape, since both are YoungDiagram.ofRowLens of the weakly-decreasingly sorted parts;
    • SYTEncodingBridge.numSYT_eq_numStandardYoungTableaux — the two SYT encodings in this corpus (0-indexed BraidKnot, 1-indexed Mathlib) have the same count.

    Honest scope #

    n ≤ 12 only in this file. The general case is exactly RSKBurnsideHolds n for general n, which is the RSK correspondence — and the Schensted programme this paragraph pointed at has since landed it (QOU.Mathlib.rskBurnsideHolds). The unconditional split is SpechtWedderburnGeneral.spechtEquiv; this file is retained as the small-n route, which needs no RSK at all.

    Corrected 2026-08-23. This paragraph used to continue: "Nothing here proves it, and sn_isotypic_specht_split — stated for all n — remains open, as do the two keystones that inherit sorryAx from it." That is no longer the state of the world: sn_isotypic_specht_split's sorry became the class SnIsotypicSpechtSplit, which is now inhabited (SnIsotypicSpechtSplitInstance). Likewise RSKBridge.RSK_substrate_axiom is no longer an axiom — it is a theorem, proved from the same result. Check with #print axioms rather than by reading imports, as before.

    MonoidAlgebra k (Equiv.Perm (Fin n)) ≃ₐ[k] (i : SpechtClassification.PartitionIndex n) → Module.End k ↥(Specht.SpechtSubmodule i.diagram)

    The Wedderburn split of k[S_n], unconditionally, for n ≤ 12.

    k[S_n] ≃ₐ[k] ∏_{μ ⊢ n} End_k(S^μ) over any characteristic-zero field: partition-indexed, block μ acting on the Specht module S^μ.

    Everything the split needs is proved — the commutant is the base field (W2), the map is partition-indexed and block-sized by construction, and it is injective — leaving only the count Σ_μ (#SYT μ)² = n!, which the corpus proves for n ≤ 12 with no RSK correspondence (PartitionsOfBridge.rskBurnsideHolds_le12).

    -- Ref: [sagan2001] §1.10, §2.4; [james1984representation].
