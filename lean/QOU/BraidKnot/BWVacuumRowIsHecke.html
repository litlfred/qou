    S_{0λ} / S_{00} = d_q(λ).

    structure QOU.BraidKnot.VerlindeVacuumRow (ι : Type u_1) (R : Type u_2) [Field R] :
    Type (max u_1 u_2)

    A modular S-matrix vacuum row over a fusion-label type ι: the entries are the quantum dimensions d normalised by the total quantum dimension D, with a distinguished vacuum label vac of quantum dimension 1. D is carried abstractly (its value √(Σ_λ d_λ²) is archimedean and lives downstream); only D ≠ 0 is used here.

    • d : ι → R

      Quantum dimension of each fusion block.

    • D : R

      Total quantum dimension (√(Σ d_λ²) downstream; abstract here).

    • vac : ι

      The vacuum (trivial object) label.

    • d_vac : self.d self.vac = 1

      The vacuum object has quantum dimension 1.

    • D_ne : self.D ≠ 0

      The total quantum dimension is nonzero.
