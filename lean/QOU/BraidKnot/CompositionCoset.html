    Mathas' D_μ is a transversal — the uniqueness half of Proposition 3.3 #

    D_μ = { d ∈ S_n | t^μ d is row standard }. Then D_μ is a complete set of right coset representatives of S_μ in S_n. Moreover, if w ∈ S_μ and d ∈ D_μ then ℓ(wd) = ℓ(w) + ℓ(d) and T_{wd} = T_w T_d. (Mathas, Proposition 3.3)

    CompositionMinimal.length_mul_eq_add_of_isDistinguished is the length half. This file is the uniqueness half: a right coset of S_μ contains at most one distinguished element.

    The proof is the length half, applied twice #

    If d₁ and d₂ are both distinguished and lie in one coset, then d₂ = v · d₁ with v ∈ S_μ, and also d₁ = v⁻¹ · d₂ with v⁻¹ ∈ S_μ. Length additivity applies to each, so

    ℓ(d₂) = ℓ(v) + ℓ(d₁)   and   ℓ(d₁) = ℓ(v⁻¹) + ℓ(d₂),

    and adding them forces ℓ(v) + ℓ(v⁻¹) = 0. Since ℓ(v⁻¹) = ℓ(v), that gives ℓ(v) = 0, hence v = 1.

    No exchange condition, no reflection cocycle, no IsReduced residue — it is two applications of a lemma this arc already proved by inversion sets.

    What is still open #

    Existence — that every coset contains a distinguished element. That is the other half of Prop 3.3 and is not proved here; the natural route is that the minimal-length element of a coset must be distinguished (a non-distinguished d admits a same-block transposition v ∈ S_μ with ℓ(v·d) < ℓ(d)), which is an inversion-count argument rather than a corollary of the above.
