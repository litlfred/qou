    Entry monotonicity and consecutive-label geometry for standard Young tableaux #

    Public, sorry-free geometric facts about QOU.BraidKnot.StandardYoungTableau used by the Okounkov–Vershik exchange argument (JucysMurphy.lean). The two entry-monotonicity lemmas mirror the private copies in JucysMurphy.lean (entry_lt_diag_succ, entry_lt_of_diag_row_lt), lifted here as reusable public lemmas; the payoff is:

    • content_ne_of_succ — the cells of two consecutive labels never lie on the same diagonal (their contents differ). This is the d ≠ 0 half of the admissibility of an AdjacentSwapStep: for a genuine standard tableau, consecutive labels can never share a content, because a shared content would force a cell carrying a label strictly between them (impossible).

    Scope: pure combinatorics on ℕ/ℤ cell coordinates; §7c-clean (no ℝ); no fit.

    Entries strictly increase along the immediate diagonal step (i,j) → (i+1,j+1).

    theorem QOU.BraidKnot.entryLtOfDiagRowLt {μ : YoungDiagram} (T : StandardYoungTableau μ) (r : ℕ) {x y : ℕ × ℕ} :
    x ∈ μ → y ∈ μ → y.1 = r → ↑x.2 - ↑x.1 = ↑y.2 - ↑y.1 → x.1 < y.1 → T.entry x.1 x.2 < T.entry y.1 y.2

    Entries strictly increase along a diagonal: same content, strictly smaller row ⇒ strictly smaller entry.

    theorem QOU.BraidKnot.content_ne_of_succ {μ : YoungDiagram} (T : StandardYoungTableau μ) {p q : ℕ × ℕ} (hp : p ∈ μ) (hq : q ∈ μ) (hval : T.entry q.1 q.2 = T.entry p.1 p.2 + 1) :
    ↑p.2 - ↑p.1 ≠ ↑q.2 - ↑q.1

    Consecutive labels never share a diagonal. If cell q carries the label one greater than cell p (entry q = entry p + 1), then p and q have different content (col − row). A shared content would place a cell carrying a label strictly between the two consecutive labels — impossible.

    theorem QOU.BraidKnot.sameRow_of_content_succ {μ : YoungDiagram} (T : StandardYoungTableau μ) {p q : ℕ × ℕ} (hp : p ∈ μ) (hq : q ∈ μ) (hval : T.entry q.1 q.2 = T.entry p.1 p.2 + 1) (hgap : ↑q.2 - ↑q.1 = ↑p.2 - ↑p.1 + 1) :

    Content gap +1 ⇒ same row (for consecutive labels). If q carries the successor label of p and content q = content p + 1, then p and q are in the same row.

    theorem QOU.BraidKnot.sq_content_gap_ne_one {μ : YoungDiagram} (T : StandardYoungTableau μ) {p q : ℕ × ℕ} (hp : p ∈ μ) (hq : q ∈ μ) (hval : T.entry q.1 q.2 = T.entry p.1 p.2 + 1) (hrow : p.1 ≠ q.1) (hcol : p.2 ≠ q.2) :
    (↑q.2 - ↑q.1 - (↑p.2 - ↑p.1)) ^ 2 ≠ 1

    d² ≠ 1 for consecutive labels in different rows and columns. Together with content_ne_of_succ (d ≠ 0), this is the full admissibility of an AdjacentSwapStep between the two cells: |d| ≥ 2.
