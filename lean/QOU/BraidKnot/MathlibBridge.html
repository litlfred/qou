    QOU.BraidKnot.MathlibBridge — concrete bridge to Mathlib YoungDiagrams #

    Wires Mathlib.Combinatorics.Young.YoungDiagram into the abstract QOU.BraidKnot.ShellNeutrality.YoungDiagram (a Multiset ℤ shadow) used by the categorical-neutrality conjecture.

    Given a Mathlib Young diagram Y (a downward-closed finset of cells in ℕ × ℕ), the bridge fromMathlib Y packages the multiset of Jucys–Murphy contents { c.2 - c.1 : c ∈ Y.cells } together with the cardinality witness, producing an instance of our abstract YoungDiagram. All abstract theorems (kappa_conjugate, kappa_zero_of_self_conjugate, kappa_unionDiagram, etc.) then apply to images of fromMathlib.

    The remaining open lemma is the bridge fact

    Y.transpose = Y → isSelfConjugate (fromMathlib Y)

    i.e. that the Mathlib-level transposition predicate transports to the abstract Multiset-symmetry predicate. This is provable from the definition of YoungDiagram.transpose (which swaps each cell (i, j) ↔ (j, i)) and Multiset.map symmetry, but the full proof needs the Mathlib lemma YoungDiagram.transpose_cells (or equivalent). It is recorded as a typeclass-axiom field below for downstream use, with the Lean proof deferred.

      §2 Bridge axiom — Mathlib transpose ↔ abstract self-conjugacy #

      source
      class QOU.BraidKnot.MathlibBridge.TransposeBridge :
      Prop

      Bridge axiom (typeclass field). If a Mathlib Young diagram is fixed by transpose, then its bridge image is self-conjugate in the abstract Multiset model.

      Provable from YoungDiagram.transpose_cells (Mathlib): the cell set of the transpose is the swap-image of the original cell set, so the multiset of contents under c ↦ c.2 - c.1 is invariant under negation. Exposed here as a typeclass field so downstream applications can use it without depending on the proof construction.

        §3 Reverse direction — discharged via Mathlib #

        The reverse direction kappa (fromMathlib Y) = 0 → Y.transpose = Y is the genuinely Young-lattice claim. In the abstract Multiset model it is FALSE (counter-example {1, 2, -3}), so the bridge to a concrete Mathlib YoungDiagram is essential. The full proof reduces to the Frobenius-coordinate bijection:

        • self-conjugate Young diagrams of n ↔ partitions of n into distinct odd parts (standard Mathlib bijection),
        • combined with the fact that for non-self-conjugate λ ⊢ n, the content multiset is necessarily distinguishable from its negation (provable by ranging over the longest first column of λ vs λ').

        Recorded as a typeclass axiom field; the proof is the open Phase 3 deliverable referenced in the workplan.
