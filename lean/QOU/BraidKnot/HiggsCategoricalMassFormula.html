    QOU.BraidKnot.HiggsCategoricalMassFormula — Lean encoding of the constructed Higgs mass formula #

    Encodes the categorical Higgs mass formula constructed in computations/higgs_categorical_mass_formula_attempt.py (PR #1159):

    m_H = m_W · (P_4(h_0) / P_2(h_0)) · (6/5) · (1 - h_0^4 · Vol(B_3)/4)

    Empirical match: -0.67% from m_W anchor; +0.44% from m_Z anchor.

    What this file proves #

    ✓ Structural identity: 6/5 = |S_3| / |partitions(4)| ✓ Structural identity: Vol(B_3)/4 = 2G (Catalan) ✓ Algebraic shape: m_H_formula(m_W, h_0, etc.) is well-defined ✓ The formula's components are computable from substrate + W anchor

    What this file does NOT prove (sorry) #

    ✗ That m_H_formula actually EQUALS m_H (requires categorical derivation of the 6/5 leading term + h^4 correction; both currently have ~1% empirical residuals) ✗ Derivation of m_W from substrate (still external SM anchor) ✗ The 6/5 leading term itself (PR #1154 NEGATIVE on direct match)

    Honest status #

    Per AGENTS.md §3b-cond: this is a class-conditional encoding of the empirically-validated formula. The sorry represents the OPEN categorical derivation, NOT a missing Lean tactic. The 0.5% residual deviation is consistent with higher-order corrections (h^6, h^8) not captured.

    This is the FIRST Lean encoding of a constructed categorical mass formula for a torus-knot particle in the framework's RT-route chain. Empirical validation lives in the witness JSON; this file makes the structure type-level.

    The trace polynomial $P_m(h)$ for $T(2, 2m)$ torus link.

    Closed form: $P_m(h) = \sum_{j=0}^m \binom{m+j}{2j} / 2 \cdot h^{2j}$.

    Provenance (cited):

    • Sibling PR #1125 — sympy-verified the pattern for 54 cells (m=1..9, j=0..5)
    • Sibling PR #1165 — PROVED IN GENERAL via the Fibonacci-polynomial / Chebyshev-of-second-kind identity (Graham–Knuth–Patashnik Concrete Mathematics §6.6, Riordan Combinatorial Identities Ch 4 Eq 41a, Vajda Fibonacci and Lucas Numbers §III.16)
    • PR #1174 (mine, merged, SUPERSEDED by #1165) — verified the load-bearing Chebyshev identity $T_{2m+1}(x)/x = \sum C(m+j, 2j) (4(x^2-1))^j$ symbolically for m = 0..6; that's now subsumed by #1165's general proof
    • PR #1185 — Lean encoding of the bar-symmetric/anti-symmetric structure

    This noncomputable definition encodes the closed-form sum; actual evaluation requires the Real-arithmetic chain. The general-m proof lives in PR #1165's audit; this file consumes the closed form.

      Catalan's constant G — referenced via the existing framework convention (Vol(B_3) = 8G; Adams 1985). Real-valued, transcendental.

      Implementation note: encoded as a Real here for use in the mass formula; in production, this connects to mpmath G ≈ 0.91596.

      ⚠ NAME COLLISION + truncated-literal trap (flagged 2026-08-19).

      1. This is a decimal literal, i.e. a rational — so the docstring's "transcendental" describes the intended constant, not this definition. Nothing in this file is false as a result: the only consequence drawn from it, volBorromean / 4 = 2 * catalanG, is a ring identity that holds for any value. But it is a live trap. The moment anyone asserts volBorromean = Vol(𝓑₃), or links it to QOU.Knot.BorromeanVolume's 8·Cl₂(π/2), that statement becomes false — by ~1e-52 — in exactly the way VOL_4_1 was before bean qou-yf47 replaced its truncated decimal with 2·Cl₂(π/3).
      2. A second, different catalanG exists in this corpus: QOU.Knot.WhiteheadVC.catalanG := ∑' n, (-1)^n/(2n+1)^2 — the exact series. Two objects under one name is what the AGENTS.md notation register forbids.

      The exact form is already available: QOU.Knot.clausen (π/2), with certified rational bounds in QOU/Knot/CatalanValueBounds.lean. Switching to it is the qou-yf47 repair applied here; left to this file's owner because it may move numerics downstream. Audit: docs/audits/2026-08-19-volume-conjecture-work-overlap-sweep.md.

                What's CONJECTURED (open categorical derivations — documented, not Lean-claimed) #

                The categorical Higgs mass formula is an empirically-validated hypothesis, not a proved theorem. At the external anchor m_W = 80.379 it gives higgsMassFormula ≈ 124.26 GeV against the measured m_H = 125.10 GeV (−0.67 %; PR #1159, witness higgs-categorical-mass-formula-attempt.witness.json, 50 dps). The open categorical derivations are:

                (a) scalar_mass_factor / gauge_mass_factor = (6/5)·(1 − h⁴·2G) exactly (not merely empirically within 1 %); (b) the categorical formulas for scalar_mass_factor / gauge_mass_factor in terms of P_m and SM data; (c) higher-order h⁶/h⁸ corrections for the residual 0.5 %.

                These are recorded as prose, not as a True / trivial Lean stub: the empirical match lives in the witness JSON and the structural conjecture is carried by the §3b-cond class scaffolding — no proved Lean theorem asserts the match. (The prior theorem … := by trivial and def … : True := trivial audit-only placeholders were removed — they had no downstream consumers.)
