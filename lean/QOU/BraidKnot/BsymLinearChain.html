    B_sym is a linear-chain (additive) binding — formalization #

    Formalizes the provable structural content of the B_sym linear-chain result (docs/audits/2026-06-16-b-sym-linear-chain-closed-form.md, PR #2343), per bean 6z40: B_sym = α·ln(tr_free/tr_atom) is itself a definition + empirical claim (only rfl-trivial in Lean), but its additive linear-chain decomposition is a theorem once the per-bond factorization is taken as the structural input.

    The bound atom braid orders strands as ['p']·Z ++ ['n']·N and places an inter-nucleon crossing only between adjacent nucleons, so the chain carries exactly

    (Z−1) p-p bonds · 1 p-n interface bond · (N−1) n-n bonds = (A−1) total.

    Because each crossing sits on a distinct Hecke generator, the per-knot trace factorizes over bond positions and the log-binding is exactly additive:

    B_sym(Z,N) = α·[ (Z−1)·L_pp + L_pn + (N−1)·L_nn ],   L_X = ln(tr_free/tr_(1 X-bond)).

    This file proves (i) the bond-count combinatorics (pure ℕ) and (ii) the additivity closed form as a List.sum identity over the chain's bond multiset. The per-bond values L_X : Bond → R are abstract parameters (base ring generic R, per AGENTS.md §7c — the additivity is algebra, no archimedean input); the empirical claim that this matches the actual 50-dps trace stays in the audit, not asserted here. Complements QOU.BraidKnot.ChiralityTopologySelection (which fixed the p-n bond counts chainPnBonds = 1, completePnBonds = Z·N); this file gives the full (pp, pn, nn) chain decomposition and its additivity.

    Naming note (2026-09-05, bean qou-qnqf) #

    "Binding" and "log-binding" above are NAMES for a definitionally introduced quantity, not a derived identification, exactly as line 8 already says. That caution is now backed by a result rather than left as a hedge: the free-energy reading which motivated calling α·ln(tr_free/tr_atom) a binding energy cannot supply the identification, because the underlying state sum has a negative summand for every bond and every q > 0, so it has no energy spectrum and no Legendre structure (QOU.Mass.FreeEnergyReadingIsSigned, sorry-free; the_free_energy_reading_has_no_energy_spectrum_probe.py).

    Nothing in this file is affected. L : Bond → R is an abstract parameter over a generic ring and every theorem here is a statement about sums of whatever L is — the bond-count combinatorics and the additivity closed form are algebra, and they hold under any reading of L. Only the word "binding" is on loan.
