    The arc's theorems, instantiated on the actual Hecke algebra #

    HeckeGenerators and HeckeGeneratorsBelow axiomatise the Hecke, braid and far relations on an ambient ring; they do not construct H_n(q). Every theorem in the Jucys–Murphy / full-twist / seminormal arc is therefore of the form "in any ring carrying such elements, …" — conditional on being handed one.

    This file hands it one. QOU.MathlibExt.IwahoriHecke.HeckeAlgebra imposes both defining families, and the type-A Coxeter matrix on ℕ gives the braid graph of the infinite strand family, so every index satisfies the relations and the unbounded HeckeGenerators class — not merely HeckeGeneratorsBelow n for one n — is inhabited.

    The parameter bookkeeping is the convention bridge: the corpus writes σ² = (q − q⁻¹)σ + 1, the Iwahori normalisation writes (T − Q)(T + 1) = 0, and the two agree at Q = q² with σ = q⁻¹T. So the algebra instantiated here is HeckeAlgebra R (q * q) typeAMatrix and the generators are its T rescaled. No square root is adjoined anywhere; the parameter moves, not the generator.

    The type-A Coxeter matrix #

    source
    def QOU.BraidKnot.Hecke.typeAMatrix :
    ℕ → ℕ → ℕ

    The Coxeter matrix of type A_∞, on the index set ℕ of strand positions: adjacent generators braid (m = 3), non-adjacent ones commute (m = 2), and the diagonal is 1.

    Indexing by ℕ rather than Fin (n-1) is deliberate. The relations then hold at every index, so this single object serves every n at once: HeckeGenerators (unbounded) is inhabited, and each HeckeGeneratorsBelow n follows by restriction.

      Mathlib does have Aₙ : (n : ℕ) → CoxeterMatrix (Fin n); the reason this file does not simply use it is the indexing.             What this closes #

            The arc's results now hold of the Hecke algebra, not merely of any ring that happens to carry the relations. Two representative consequences; the rest of the arc composes the same way.
