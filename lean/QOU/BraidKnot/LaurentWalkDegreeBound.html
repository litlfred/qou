    Degree growth of the Gröbner–Shirshov normal-form walk #

    This file formalises the structural claims behind computations/probes/symbolic_nf_q_degree_magic_probe.py, which walks the atom braid word carrying each normal-form coefficient as an exact Laurent polynomial in q rather than as a floating-point number at q₀.

    What is and is not proved here #

    The probe makes claims of two different kinds and only one kind is a theorem.

    Formalised here — the algebraic facts that justify the representation:

    • hQ_mul_T — multiplying a monomial by h = q - q⁻¹ is a shift and subtract, h · qᵉ = qᵉ⁺¹ - qᵉ⁻¹. This is the load-bearing claim: it is why no general polynomial multiplication occurs anywhere in the walk.
    • hQ_mul_mem — multiplying by h widens the exponent range by exactly one on each side, and no more.
    • step_mem — one normal-form step, whose multipliers are 1 and h scaled by ring elements, widens the range by at most one on each side.
    • walk_mem_spanRange — after n such steps from the identity the state lies in [-n, n]. The degree span grows linearly in the number of crossings, at most 2 per crossing, which is the formal content of "the state does not grow with the nucleon number; only the polynomial degree does".

    NOT formalised, because they are not theorems. That the atom path's multipliers are exactly 1, 0, -h, -h/2 is a fact about a particular Python function, not about mathematics; it enters here as the hypothesis hstep of walk_mem_spanRange, which is the honest encoding — the theorem says what follows if a walk has that shape, and a walk using a general polynomial multiplier falsifies it. Likewise the measured degrees (proton 10, 11, 9, 8, 10, 5; neutron 9, 10, 2, 5, 7, 8) and the timings are witness data, not propositions.

    Base ring #

    Everything is stated over a generic CommRing R (§7c): the walk is pure ℚ[q^{±1}] algebra with no archimedean content, and the rational multiplier -1/2 appears only as some ring element d, so no division is needed in any statement.

        theorem QOU.BraidKnot.LaurentWalk.walk_mem_spanRange {R : Type u_1} [CommRing R] (f : ℕ → LaurentPolynomial R) (h0 : f 0 = LaurentPolynomial.T 0) (hstep : ∀ (k : ℕ), ∃ (c : R) (d : R), f (k + 1) = LaurentPolynomial.C c * f k + LaurentPolynomial.C d * (hQ * f k)) (n : ℕ) :
        f n ∈ spanRange (-↑n) ↑n

        The walk's degree span grows linearly in the number of steps.

        After n steps from the identity q⁰, every exponent lies in [-n, n]. So a walk of n crossings carries at most 2n + 1 distinct monomials per coefficient: the state does not grow with the nucleon number, only the polynomial degree does, and only linearly in the crossing count.

        The hypothesis hstep is where the atom path's restricted multipliers enter. A walk that multiplied by a general polynomial would not satisfy it, and the conclusion would genuinely fail — the bound is not an artifact of the statement.
