    QOU.BraidKnot.SymmetricCrystalPairProduction — type B folding (conjecture) #

    Class axiomatisation of [conj:symmetric-crystal-pair-production]: folding the 𝔰𝔩_n Cartan datum into Type B forces every Kashiwara descent step to occur as a pair (f̃_i, f̃_{ī}) whose two descendants are bar-conjugate. Single chiral excitations are unreachable; matter and antimatter are produced together as bar-conjugate pairs.

    Takes [CrystalGraphRealization R q] as upstream input.

    LaTeX: \label{conj:symmetric-crystal-pair-production}

    • Lecouvey, C. (2007).

    Type u

    Symmetric-crystal pair production (conjecture).

    Encodes Type-B folding of the 𝔰𝔩_n crystal: every transition v_0 → v_- ⊔ v_+ from a bar-invariant source produces a bar-conjugate pair, and every normal form generated by the GS engine is bar-invariant.

    • barInvolution : CrystalGraphRealization.NormalForm q → CrystalGraphRealization.NormalForm q

      Bar-involution on normal forms T_w ↦ T̄_w (sends q ↦ q⁻¹ and reverses crossings).

    • bar_involutive (T : CrystalGraphRealization.NormalForm q) : barInvolution (barInvolution T) = T

      Bar-involution is involutive.

    • bar_invariant (T : CrystalGraphRealization.NormalForm q) : barInvolution T = T

      The conjecture itself: every GS normal form is bar-invariant. Plays the role of sorry.

      def QOU.BraidKnot.SymmetricCrystalPairProduction.canonical (R : Type u) [CommRing R] (q : R) [C : CrystalGraphRealization R q] :
      SymmetricCrystalPairProduction R q

      The trivial model — a def, not an instance, and not "faithful".

      Its docstring said "Faithful instance. Carries the explicit research-grade conjecture as a sorry." Neither half was true. There is no sorry: it sets barInvolution T := T, so bar_invariant is discharged by rfl on T = T. Every normal form is bar-invariant because the bar involution is the identity map — nothing here sends q ↦ q⁻¹ or reverses a crossing, and bar_involutive is rfl for the same reason. A sorry would at least be visible to #print axioms; this was not.

      As an unconditional instance it made barInvolution_eq_self and nodeOf_barInvolution_highest_weight unconditional theorems about the identity map, so conj:symmetric-crystal-pair-production asserted nothing.

      Demoted the same way as ConfinementGradingCorrespondence.canonical (bean qou-fngs). Nothing consumed it: the class has no users outside this file.

      Still open: that the GS-generated normal forms are fixed by the genuine bar involution, and the Type-B folding statement that a transition v₀ → v₋ ⊔ v₊ out of a bar-invariant source produces a bar-conjugate pair — which no field of this class states.
