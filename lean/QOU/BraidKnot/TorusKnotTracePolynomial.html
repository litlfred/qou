    QOU.BraidKnot.TorusKnotTracePolynomial — the T(2,2m) trace polynomial, proved #

    docs/canonical-derivation-cheat-sheet.md §5 records, for the T(2, 2m) torus-knot Markov trace (PR #1125, torus-knot-h-expansion-pattern.md):

    `P_m(h) = Σ_{j=0}^{m} C(m+j, 2j)/2 · h^{2j} = (q^{2m+1} + q^{−(2m+1)}) / (2·[2]_q)`,
`h = q − q⁻¹`,

    and marks it "sympy-exact across m = 1..6" — that is, verified on six cases. It is the identity the categorical Weinberg-angle statement is built on, via P_m(h₀) = cosh((2m+1)η₀) / (2 cosh η₀) at a real substrate q₀ = e^{η₀}.

    This file proves it, for all m, over any field.

    How, and why the recursion comes first #

    Both sides satisfy the same Chebyshev-type recurrence, because q² + q⁻² = h² + 2:

    `S_{m+1} = (h² + 2)·S_m − S_{m−1}`,   `S_0 = 1`,  `S_1 = h² + 1`.

    So the work splits cleanly:

    • chebS_q_form — the recursion equals the q-form. Pure field algebra; this is the half the cosh statement needs, and it is proved first because it is the load-bearing one.
    • chebS_eq_sum — the recursion equals the binomial sum. This is where the combinatorial content sits, and it reduces to one Pascal identity (choose_shift_identity), applied twice.

    Composing them gives traceIdentity, the cheat-sheet statement.

    Doing it in this order matters: the recursion is the object that makes both sides computable, and neither side is naturally defined in terms of the other. A direct sum-to-q-form induction would have to carry the binomial manipulation and the field algebra simultaneously.

    What this does and does not settle #

    It settles that the closed form is an identity rather than a coincidence checked on six cases. It says nothing about the +1.07 % residual in the Weinberg-angle comparison — that is a question about which of cosh and cos the physics selects, and QOU.MathlibExt.CoshCosSeparation shows the two are not near each other.

      Half one — the q-form #

      h² + 2 = q² + q⁻², which is exactly the multiplier in the recurrence satisfied by q^{2m+1} + q^{−(2m+1)}.

      source
      theorem QOU.BraidKnot.chebS_q_form {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (m : ℕ) :
      chebS (q - q⁻¹) m * (q + q⁻¹) = q ^ (2 * m + 1) + (q ^ (2 * m + 1))⁻¹

      The q-form. S_m(q − q⁻¹)·(q + q⁻¹) = q^{2m+1} + q^{−(2m+1)}.

      At a real substrate q = e^η this reads S_m·2cosh η = 2cosh((2m+1)η), i.e. the cheat sheet's P_m(h₀) = cosh((2m+1)η₀)/(2 cosh η₀).

      Half two — the binomial sum #

      The combinatorial content is one Pascal identity, used twice.

      source
      theorem QOU.BraidKnot.choose_shift_identity (m i : ℕ) :
      (m + i + 2).choose (2 * i + 2) + (m + i).choose (2 * i + 2) = (m + i).choose (2 * i) + 2 * (m + i + 1).choose (2 * i + 2)

      The Pascal identity behind the recurrence.

      C(m+i+2, 2i+2) + C(m+i, 2i+2) = C(m+i, 2i) + 2·C(m+i+1, 2i+2).

      Indexed by i rather than by j = i+1 so that every argument is a genuine natural number and no truncated subtraction appears. Three applications of Pascal's rule and omega on the resulting linear combination.

        theorem QOU.BraidKnot.chebSum_succ_succ_add {K : Type u_2} [CommRing K] (h : K) (m : ℕ) :
        chebSum h (m + 2) + chebSum h m = (h ^ 2 + 2) * chebSum h (m + 1)

        chebSum satisfies the recursion, in additive form.

        Stated as S_{m+2} + S_m = (h²+2)·S_{m+1} rather than with a subtraction on purpose: the termwise fact underneath is choose_shift_identity, which is an identity between sums of binomial coefficients in ℕ, and keeping it additive means no truncated subtraction ever has to be reasoned about.

        All three sums are first put over the common range range (m+3) — legitimate by chebSum_eq_range, since the extra terms vanish — after which peeling index 0 aligns the h² shift with the rest.

        theorem QOU.BraidKnot.chebSum_eq_chebS {K : Type u_2} [CommRing K] (h : K) (m : ℕ) :
        chebSum h m = chebS h m

        The binomial sum is the recursion. Two-step induction; the step is chebSum_succ_succ_add rearranged, so the additive form is used exactly once and the subtraction only ever appears on the chebS side, where it is over a ring.

        The cheat-sheet statement #

        source
        theorem QOU.BraidKnot.traceIdentity {K : Type u_2} [Field K] [CharZero K] (q : K) (hq : q ≠ 0) (hq2 : q + q⁻¹ ≠ 0) (m : ℕ) :
        ∑ j ∈ Finset.range (m + 1), ↑((m + j).choose (2 * j)) / 2 * (q - q⁻¹) ^ (2 * j) = (q ^ (2 * m + 1) + (q ^ (2 * m + 1))⁻¹) / (2 * (q + q⁻¹))

        P_m(h) = (q^{2m+1} + q^{−(2m+1)}) / (2·[2]_q), for every m.

        This is docs/canonical-derivation-cheat-sheet.md §5's identity, recorded there as "sympy-exact across m = 1..6". It is now a theorem over any field of characteristic zero, with no bound on m.

        At a real substrate q = e^η the right-hand side is cosh((2m+1)η) / (2 cosh η), which is the form the categorical Weinberg-angle statement uses.
