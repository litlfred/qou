    Bridge QOU.Mathlib.StandardYoungTableau μ → QOU.BraidKnot.StandardYoungTableau μ #

    Two standard-Young-tableau types live in this development:

    • QOU.Mathlib.StandardYoungTableau μ — a refinement of Mathlib's SemistandardYoungTableau, whose entry map is a Set.BijOn onto {1, …, |μ|} (entries 1..|μ|). The row-superstandard witness rowSuperstandardStd and the Nonempty instance built in SytRowSuperstandard.lean are of this type.
    • QOU.BraidKnot.StandardYoungTableau μ — the bespoke entry-based structure (entry, lt_card, zero_off, inj_on, row_strict, col_strict) with entries 0..|μ|-1, used by the Jucys–Murphy / Okounkov–Vershik seminormal machinery (JucysMurphy.lean: tableauCellEquiv, AdjacentSwapStep, syt_all_connect_to_some).

    This file is the one-line-down conversion toBraidKnot between them: shift every entry down by one (entry i j - 1). Off the diagram Mathlib's SSYT is pinned to 0 (zeros'), and 0 - 1 = 0 in ℕ, so zero_off holds for free; on the diagram the Set.BijOn bound 1 ≤ entry ≤ |μ| makes the truncated subtraction faithful (omega). Consequently the JM/OV code has a concrete Nonempty (QOU.BraidKnot.StandardYoungTableau μ) (rowSuperstandardBraidKnot), supplying the base tableau T₀ its exchange argument needs.

    Scope: pure combinatorics on ℕ; §7c-clean (no ℝ, no ordering on q); no fit.
