    W_λ keystone, residual (i): the MTC-matching obligation as a §3b-cond class #

    The s5-so3 keystone reduces the lever-1 binding kernel R(q,x) = x² − τx + 1 to a single geometric trace τ = tr B, whose geometric face is the W_λ index — the Beasley–Witten / Reshetikhin–Turaev localization weight on the Hecke partition blocks. Residual (i) (the single owner-gated open object, opened 2026-06-29) is:

    pin the Beasley–Witten gauge datum on S³/2I to the Hecke Rep U_q(sl_N) blocks so the localization W_λ = d_q²/D² is provably our Hecke category's Plancherel measure, not "some MTC's".

    This file does not construct that gauge datum (that is the deep, owner-gated differential geometry — the Chern–Simons group + level on the Poincaré sphere whose equivariant index produces exactly the Hecke q-dimensions d_q(λ)). It does the formalize-first complement: it states the matching as a single named hypothesis and derives the keystone's two necessary conditions from it, turning "pin the gauge datum" from prose into a precise, auditable Lean obligation.

    The class (BeasleyWittenLocalization) carries, as its only unproved field, the matching obligation loc p = d_q(p)² / D² — what the gauge datum must deliver. Everything else is a derived consequence, so the theorems are non-degenerate (AGENTS.md §3b-cond / §3b-tax — the class axiomatises the input, the theorems derive the conclusions and never assume them):

    • C1 — normalization (loc_isProbabilityMeasure): any localization matching d_q²/D² is a probability measure, Σ_λ loc λ = 1. (D² cancels by construction — this is the C1 normalization the 2026-06-20 audit pinned: the genuine Plancherel D² = Σ d_q² normaliser, not [n]_q!.)
    • C2 — chirality-blindness (loc_conj_eq): any such localization is transpose-invariant, loc λ′ = loc λ. This transports the corpus-proved categorical fact qDim_conj / qPlancherelWeight_conj (KeystoneC2QDimTranspose.lean, sorry-free) onto the gauge-theory weight loc via the matching.

    So C1 + C2 are necessary conditions any gauge datum must satisfy — a falsifiable constraint on residual (i)'s owner-gated search (a localization whose weight is not normalized, or not transpose-invariant, cannot be the Hecke Plancherel measure). Two of these (C2 here; the W_λ defect cubic 144·C(n) = −n(n−1)(2n−13) in WLambdaDefectClosedForm.lean) are already Lean-proved, so they are genuine consistency obligations, not vacuous.

    Base ring. Generic {R : Type*} [Field R] (§7c): the measure identity d_q²/D² and both necessary conditions are pure field algebra — no ordering, no Real.sqrt, no q₀.     class QOU.BraidKnot.Keystone.BeasleyWittenLocalization (R : Type u_1) [Field R] :
    Type (max u_1 (u_2 + 1))

    Residual (i): the Beasley–Witten / RT localization, matched to the Hecke Plancherel measure.

    Carries the Hecke partition blocks parts for λ ⊢ n, the transpose involution conj (λ ↦ λ′), the categorical q-dimension qDim = d_q, and — as its single unproved field — the MTC-matching obligation loc_matches: the gauge-theory localization weight loc equals the categorical Plancherel measure d_q(λ)² / D², D² = Σ_λ d_q(λ)². This is exactly what the owner-gated gauge datum on S³/2I must deliver; it is not constructed here.

    The two structural inputs conj_mem (blocks closed under transpose) and qDim_conj (the corpus-proved d_q(λ′) = d_q(λ)) are established facts, not the conclusions; globalDim_ne is D² ≠ 0.

    • Part : Type u_2

      Partition index for λ ⊢ n.

    • parts : Finset (Part R)

      The finite set of Hecke partition blocks λ ⊢ n.

    • conj : Part R → Part R

      The transpose involution λ ↦ λ′.

    • conj_mem (p : Part R) : p ∈ parts → conj p ∈ parts

      The blocks are closed under transpose (λ ⊢ n ⇒ λ′ ⊢ n).

    • qDim : Part R → R

      The categorical q-dimension d_q(λ) of the Hecke block.

    • qDim_conj (p : Part R) : p ∈ parts → qDim (conj p) = qDim p

      Corpus-proved input d_q(λ′) = d_q(λ) (KeystoneC2QDimTranspose.qDim_conj, sorry-free) — carried abstractly here (Mathlib-only module).

    • globalDim_ne : ∑ p ∈ parts, qDim p ^ 2 ≠ 0

      The global quantum dimension D² = Σ_λ d_q(λ)² is nonzero.

    • loc : Part R → R

      The Beasley–Witten / RT localization weight on the blocks (the gauge-theory side).

    • loc_matches (p : Part R) : p ∈ parts → loc p = qDim p ^ 2 / ∑ m ∈ parts, qDim m ^ 2

      THE MTC-MATCHING OBLIGATION (residual i). The localization equals our category's Plancherel measure d_q(λ)² / D². The single unproved field — what the owner-gated gauge datum must deliver.
