    structure QOU.BraidKnot.JucysMurphyData :
    Type (u_1 + 1)

    Placeholder Jucys–Murphy data: a commutative ring (the Iwahori–Hecke algebra H_n(q)) together with its Jucys–Murphy elements and the symmetric-polynomial evaluations. The full Hecke model is pending; the ring instance is what makes the multiplicative statements below type-check.

    • algebra : Type u_1

      The underlying algebra.

    • commRing : CommRing self.algebra

      The algebra's commutative ring structure.

    • jm : ℕ → self.algebra

      Jucys–Murphy elements J_1, J_2, ….

    • esymmJM : ℕ → self.algebra

      The elementary symmetric polynomial e_ℓ(J_1,…,J_n) evaluated in the algebra.
