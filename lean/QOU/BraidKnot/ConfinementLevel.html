    QOU.BraidKnot.ConfinementLevel — confinement level via shadow-price filtration #

    ℓ(K, q) := min { ℓ : T_w ∈ J^ℓ(q) } where J^ℓ(q) is generated by the ℓ cheapest knot operators at q.

    Formal-chain version. Lives under lean/QOU/ and is compiled by lake build.

    Why valid is a parameter and not a field (bean qou-i6u4) #

    Until 2026-09-06 this was a plain structure carrying level : ℕ as a free field, with an axiom ConfinementLevel.level_canonical asserting that two records agreeing on braidIndex, nStrands and q have the same level. That axiom was false — the fields are independent, so ⟨0,0,0,0⟩ and ⟨0,0,0,1⟩ refute it — and the axiom's own docstring said why: "a constraint the current plain-structure encoding does not enforce at the type level."

    Carrying the filtration predicate valid as a parameter indexed by the braid datum, together with level_valid and level_min as proof fields, is the repair. It makes level genuinely the minimum rather than free data, so uniqueness becomes a one-line theorem and existence becomes a real construction rather than a junk witness. Nothing here depends on any axiom — #print axioms reports none at all, not even propext.

    Note that uniqueness needs only antisymmetry. The narrative block prop:confinement-level-unique gives three reasons — monotone filtration, upward-closed level set, nonempty level set — but the first two do no work in the uniqueness argument; nonemptiness is what existence needs.

      Type

      Confinement level of a closed braid at substrate parameter q.

      valid is the filtration predicate fun d ℓ => T_w(d) ∈ J^ℓ(d.q), carried as a parameter — a function of the datum — so that level is determined by the braid rather than chosen freely alongside it.

      • level : ℕ

        Confinement level ℓ ∈ ℕ.

      • level_valid : valid d self.level

        level sits in the filtration.

      • level_min (ℓ : ℕ) : valid d ℓ → self.level ≤ ℓ

        and no smaller index does — this is what makes it the minimum.
