    QOU.BraidKnot.DeltaLambdaRefutation — formalize-the-refutation of Δ_λ closure ansätze #

    The per-isotope binding formula B(K) = m_e · Σ_λ y_λ χ^λ Δ_λ requires per-partition Δ_λ values. The per-partition VALUE is now PROVED (2026-08-02, sorry-free, general-n): Δ_λ = (-1)^{n(λ)}·dim V_λ (QOU.BraidsAndKnots.dtEuler_eq_deltaLambda_unconditional). The six ansätze refuted below (Frobenius co-Casimir, Demazure-fibre, LP-Plancherel, LP-Frobenius, crystal-graph, augmented Markov) did not fail on the value — they failed to derive the many-body MAGNITUDE r* ≈ 1.585 (which no per-block Δ_λ can supply; the missing term is super-pairwise, pairwise cap ρ_A ≤ C(A,2) proved in QOU.MassTheory.exchangeDet_pow_two_le_four). So the gate rule — "do not propose a seventh fit-based ansatz for the magnitude" — still stands, and this file operationalises the magnitude-refutations (the value is now Lean-proved, not merely enforced by reviewer vigilance).

    This file operationalises that rule per the formalize-the-refutation discipline (.claude/skills/local/compute-author.md §3.4): a refuted ansatz becomes a machine-checked inequality tol < |prediction − target|, not a prose warning, so the dead ansatz cannot be silently re-proposed and slip past review.

    The numbers are 12-figure truncations of the 50-dps witness computations/rho-k-h3a-co-casimir.witness.json (allPassed: true); the refutation holds with enormous margin (gap ≈ 4.498 m_e units vs tol 1), so 12 figures is far more than the inequality needs. Statements are decidable rational (in)equalities — sorry-free, norm_num-discharged over ℚ.
