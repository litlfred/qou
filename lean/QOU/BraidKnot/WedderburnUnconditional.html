    QOU.BraidKnot.WedderburnUnconditional — the discharged cone, stated without hypotheses #

    SnIsotypicSpechtSplitInstance inhabits SnWedderburnPartitionBridge.SnIsotypicSpechtSplit ℚ, so every result carrying that class as a hypothesis is satisfiable by instance resolution. This file makes that concrete rather than leaving it as a claim about instance resolution: each theorem below restates a conditional result with no hypothesis, and its proof is the conditional result applied. If the instance ever stopped resolving, this file would stop compiling.

    The hypotheses are left in place upstream on purpose — removing them would churn every signature, and the class form is what lets instance resolution fill them at use sites downstream of the instance. What this file adds is a checked record of which results are now unconditional.

    Stale docstrings this exposed — both now corrected (2026-08-23) #

    Two upstream comments described the state of the world before the instance existed. This section originally flagged them rather than rewriting them, on the grounds that they were someone else's files. Both have since been corrected in place:

    • BurnsideDischarge said OVTopAssembly.sum_numSYT_sq_eq_factorial "carries the residual sorryAx". It does not — it carries a class hypothesis, and the class is now inhabited.
    • RSKBurnsideDischarge said of its class-conditional result "It is now a theorem". That overclaimed a conditional proof; the unconditional one is QOU.Mathlib.rskBurnsideHolds.

    The flags are kept as a record of what was wrong and when.
