    Keystone value step, structural reframe: self-duality narrows the eigenfunction class #

    Context (owner reframe, 2026-07-05). The keystone value map needs the vector bwS0(λ) = d_q(λ)/D (BWVacuumRowIsHecke.lean). The geometric-realisation program tried to reproduce it by screening an off-the-shelf q-special-function family (Σ(2,3,5) WRT, colored Lawrence–Rozansky, and the E_q(2) q-Bessel — Hahn–Exton/q-Hankel via Koornwinder–Swarttouw arXiv:1208.2521, and the big q-Bessel / q-Laguerre of Ciccoli–Koelink–Koornwinder arXiv:math/9805023). Every node-value screen was a scope-(a) refutation, and the big q-Bessel route is not even a 0-dof test: its discrete orthogonality is supported on {c·q^k : k∈ℤ} for any c > 0 (math/9805023 §4), so its "nodes" carry a free scale.

    The reframe inverts the search: instead of importing an orthogonal family and testing its values, read off the orthogonality/eigen constraints the framework's own structure imposes, and let them narrow the class. Three ingredients:

    • (A) Frobenius pairing. The Markov trace tr_M = Σ_λ y_λ χ_λ is a Frobenius form; under it the characters χ_λ are orthogonal with the quantum-dimension (Plancherel) weight μ(λ)=d_q(λ)²/D² (KeystoneVerlindeSMatrixBridge.verlindeMeasure_eq_plancherel), and d_q(λ)/D = χ_λ(1)/D is the vacuum overlap. The orthogonal system is supplied, not imported.
    • (B) Categorical 𝐂-action / Verlinde. S simultaneously diagonalises the fusion operators; d_q is the unique Perron–Frobenius-positive common eigenvector (Ocneanu; Wenzl — the corpus y-lambda-closed-form-wenzl-bridge).
    • (C) Self-duality. The modular S is symmetric and squares to charge conjugation, S² = C (C² = 1). That is the categorical avatar of a self-reciprocal transform — the spectral duality the geometric program was not using.

    What this file proves (the (C) leg, sorry-free). For any symmetric S with S² = C and C² = 1 (charge conjugation an involution):

    • sTransform_pow_four : S ^ 4 = 1 — S has order dividing 4: the categorical self-reciprocality (𝓗_q⁴ = id), matching the self-reciprocal q-Hankel transform of arXiv:1208.2521.
    • eigenvector_pow_four_fixed — an eigenvector v with S v = ζ v satisfies ζ⁴ • v = v (any CommRing); and eigenvalue_pow_four_eq_one — over a field, on a nonzero v, this gives ζ⁴ = 1: every eigenvalue is a 4th root of unity. The eigenfunction class is narrowed to the four charge-conjugation phases (as ordinary Fourier self-duality forces iⁿ on the Hermite eigenfunctions). On the self-dual (C-fixed) sector C = +1, so S² = +1 there and the real symmetric S has eigenvalues ±1; the vacuum row lives in this sector (vacuumRow_conj_invariant) and is the +1 / PF-positive ground state — this is where d_q is pinned by (A)+(B).

    Honest scope. This is the keystone value step (s013), not Step-9b binding. The value step already has its non-geometric answer (redirect iii = Markov/PF uniqueness); this leg supplies the narrowing — the constraint any geometric realisation must satisfy, and the reason a free-scale q-Bessel family cannot be it — not a new closure. The PF-selection (B) step that pins the specific +1-eigenvector to d_q is cited (Ocneanu/Wenzl), not re-proved here.

    Base ring (§7c): generic {R : Type*} [CommRing R] — the order-4 identity is pure matrix algebra; the ζ⁴=1 eigenvalue corollary needs only a nonzero test vector, no ordering or Real.sqrt.

    Type (max u_3 u_4)

    A self-dual S-transform on a finite fusion-label type. Bundles the modular data used by the narrowing: a symmetric matrix S, a charge-conjugation matrix C that is an involution, and the self-duality relation S² = C. (In a modular tensor category S is symmetric and S² = C is the standard modular relation; C is the charge-conjugation permutation, C² = 1.)

    • S : Matrix ι ι R

      The modular S-matrix.

    • C : Matrix ι ι R

      The charge-conjugation matrix.

    • S_symm : self.S.transpose = self.S

      S is symmetric (Frobenius self-duality of the pairing).

    • S_sq : self.S * self.S = self.C

      Self-duality S² = C.

    • C_invol : self.C * self.C = 1

      Charge conjugation is an involution C² = 1.
