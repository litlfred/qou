    QOU.BraidKnot.BringTrilogDepth3Witness — conjectural class (§3b), content-bearing #

    §3b class axiomatisation for content block conj:bring-trilog-depth-3-witness: Bring trilog at $\zeta_5$ as depth-3 grouplike value (50-digit functional-equation cross-validated witness).

    The class carries the conjecture's actual content:

    • the four archimedean components of $\tau_{\mathrm{arch}}(\mathrm{Li}_3^q(\zeta_5^k)) = \mathrm{Cl}_3(2\pi k/5) + i\,S_3(2\pi k/5)$ for the two $\mathbb{Q}$-independent orbit representatives $k = 1, 2$ (Clausen Cl₃ is even and $2\pi$-periodic, so $k = 4, 3$ repeat them);
    • the K = 5 distribution relation, real part — the 50-dps cross-validated falsifiable content (bring-trilog-zeta5-depth-3.witness.json, residual $5.5\times10^{-51}$): $2\,(\mathrm{Cl}_3(2\pi/5) + \mathrm{Cl}_3(4\pi/5)) = (5^{-2} - 1)\,\zeta(3) = -(24/25)\,\zeta(3)$, tied to the PROVED arithmetic core Cl3Zeta5OrbitSum.orbit_sum_identity via cl3OrbitSumPredicted;
    • the witness-pinned sign non-degeneracies ($\mathrm{Cl}_3(2\pi/5) \approx +0.18937 > 0$, $S_3(2\pi/5) \approx +0.99220 > 0$) that make the depth-3 value genuinely nontrivial (rule out the zero realisation).

    Sorry-free consequences are DERIVED below (pair_sum_eq, cl3_4pi5_neg): the pair sum is $-(12/25)\,\zeta(3)$ — half the full 4-term orbit sum, since each Clausen value appears twice in the orbit — and $\mathrm{Cl}_3(4\pi/5) < 0$.

    The sorry instance is the open conjecture per §3b (that the q-side depth-3 grouplike exists and archimedean-realises to these components), NOT a missing proof.
