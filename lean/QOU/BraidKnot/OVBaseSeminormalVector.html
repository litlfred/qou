    OV base seminormal vector — the polytabloid JM computation (toward seminormalVector_base_exists) #

    The single remaining sorry in the Okounkov–Vershik seminormal cone, seminormalVector_base_exists ([JucysMurphy.lean]), reduces (numerically confirmed, audit 2026-07-19) to the eigen-equation on the column-superstandard polytabloid:

    X_s · e_{T₀} = content(cell of s) · e_{T₀}.

    This file builds that computation from the sorry-free Specht foundation. First brick: the reduction of the abstract JM action (rep μ).asAlgebraHom (jucysMurphy n s) applied to a polytabloid into the concrete signed-cell polytabloid sum ∑_{j<s} e_{(j\,s)·t} — general in the tableau t, from Representation.asAlgebraHom_single + rep_polytabloid.

    JM action on a polytabloid = a polytabloid sum. The Jucys–Murphy element X_s = ∑_{j<s} (j\,s) acts on the polytabloid e_t by ∑_{j<s} e_{(j\,s)·t} — each transposition permutes the polytabloid (rep_polytabloid), and asAlgebraHom sends the single sum to the endomorphism sum. General in t; the eigen-equation is what this sum collapses to for the column-superstandard T₀.

    Column antisymmetry. For σ in the column stabilizer of t, permuting the columns signs the polytabloid: rep σ (e_t) = sgn(σ) · e_t. Reindex the column-stabilizer sum by left-multiplication by σ (a bijection of colStab t, as σ ∈ colStab t); sgn(σ·π) = sgn(σ)·sgn(π) and sgn(σ)² = 1 collapse the signs.

    C-antisymmetry sum collapse (the coset-inner-sum). For any finite set H of permutations all lying in the column stabilizer of t, the signed representation sum collapses to |H| · e_t: each term is sgn(σ) · (sgn(σ) · e_t) = sgn(σ)² · e_t = e_t by brick 2 (rep_colStab_polytabloid) and sgn(σ)² = 1. This is the inner sum over a full-column subgroup S_C ⊆ colStab t in the coset decomposition of the single-column Garnir relation (brick 3b): it turns ∑_{π ∈ S_C} sgn(π)·π·e_t into |C|! · e_t. Collision-independent — pure column antisymmetry.

    The outer star-sum evaluation. This is the RHS of the single-column Garnir cancellation 0 = |C|!·(e_t − ∑_{j∈C} e_{(j\,s)·t}); collision-independent.

      Toward the row collision (brick 3b, item (i)) #

      The one remaining debt for seminormalVector_base_exists is the full-group annihilation ∑_{σ ∈ S_{C∪{s}}} sgn σ · σ·e_t = 0, which colGarnir_single_column_of_annihilation turns into the single-column relation. By sum_sign_rep_polytabloid_eq_zero_of_family + mtab_sum_sign_smul_of_eq_zero that reduces to a row collision: for every ρ ∈ colStab t, two distinct labels of C ∪ {s} share a row in ρ • t.

      The argument is generic in t — it needs only c < c_s, not column-superstandardness:

      • ρ ∈ colStab t preserves the column pattern (colPattern_smul_of_mem_colStab below), so in ρ • t the column-c labels are still exactly C, filling column c entirely — i.e. occupying rows 0, …, colLen c − 1.
      • s stays in column c_s, hence sits at some row r < colLen c_s.
      • colLen is antitone and c < c_s, so r < colLen c_s ≤ colLen c = |C|.
      • Therefore the column-c label in row r shares that row with s, and the two are distinct (different columns) — the antisymmetriser kills the tabloid.

      This block lands the first step; the remaining steps (column-c labels occupy exactly rows 0…colLen c − 1; the colLen comparison; assembling the collision) are tracked on bean sv8b.

      The bean's plan routed this through "the column-c labels occupy exactly rows 0 … colLen c − 1". That intermediate is unnecessary: a tableau is an Equiv onto μ.cells, so it suffices to show the cell (row s, c) is in μ and then pull it back. Concretely, with r = row s:

      • (r, c') ∈ μ gives r < colLen c' (mem_iff_lt_colLen);
      • colLen c' ≤ colLen c since c ≤ c' (colLen_anti) — columns weakly shorten;
      • so r < colLen c, i.e. (r, c) ∈ μ;
      • t.symm on that cell is the required x.

      No column-superstandardness, no counting — this is generic in t.
