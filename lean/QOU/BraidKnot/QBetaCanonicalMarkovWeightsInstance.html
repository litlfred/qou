    QOU.BraidKnot — Explicit instance of CanonicalMarkovWeightsH3 #

    An explicit √q-bearing inhabitant of the CanonicalMarkovWeightsH3 class (from prop:qbeta-per-block-chi-closed-forms §Extension #4, PR #1764). The instance is built from the Markov parameter markov_parameter q = √q / (1 + q):

    y_(3)(q) = z(q) y_(2,1)(q) = 1/2 - z(q) y_(1,1,1)(q) = z(q)

    The dimension-normalisation axiom holds for any q > 0: y_(3) + 2·y_(2,1) + y_(1,1,1) = z + (1 - 2z) + z = 1. ✓

    Honest scope. This proves the class is INHABITABLE — making the §3b-cond conditional theorems (delta_tau_M_canonical_has_q2_minus_1_factor etc.) non-vacuous — but is NOT a claim that this is THE canonical Wenzl–Markov instance. The canonical Wenzl weights have a different closed form derived from the Bratteli-diagram structure of H_3(q); see the accompanying .md for the numerical comparison.

    CanonicalMarkovWeightsH3

    Explicit √q-bearing instance of CanonicalMarkovWeightsH3.

    Constructed from the Markov parameter z(q) = √q / (1 + q). The sum-of-dimensions normalisation y_(3) + 2·y_(2,1) + y_(1,1,1) = 1 follows from z + (1 - 2z) + z = 1 for any real-valued z.

    Not canonical. This is one valid inhabitant of the class — it satisfies the normalisation because z + 2(1/2 - z) + z = 1 holds for any z, which is precisely why it inhabits the class without being the production weights. identifying THE canonical inhabitant is open math — that is now canonicalInstance below (2026-09-03).

    ⚠ Demoted from instance to def (2026-09-03). It remains a first-class inhabitant and every use of it below is unchanged: they all name it explicitly with @, and is_inhabited names it too. What changes is only that it is no longer a candidate for implicit resolution, so a bare delta_tau_M_canonical q now unambiguously means the canonical weights rather than whichever instance was declared last.

      The CANONICAL inhabitant #

      The instance above is a valid inhabitant and was never claimed to be the canonical one — the accompanying .md says so, and records that "identifying the canonical inhabitant remains open". It is no longer open.

      The canonical Wenzl–Markov weights of the production trace (convention D) are the U_q(𝔰𝔩₂) quantum dimensions normalised by [2]_q³:

      y_(3) = [4]_q/[2]_q³ = (q⁴+1)/(q²+1)² y_(2,1) = 1/[2]_q² = q²/(q²+1)² y_(1³) = 0

      Why these and not others. Convention D is the N = 2 member of the Ocneanu family z_N = q^N/[N]_q: its framing ratio a² = z/z₋ is the monomial q⁴, which collapses every Ocneanu numerator into quantum integers and turns the weight product into the hook-content formula w_λ = dim_q(V_λ^{𝔰𝔩_N})/[N]_q^n. So these three values are derived from the trace, not fitted to it (computations/probes/ocneanu_weights_are_sl_n_quantum_dimensions.py, 13/13; QOU.Information.markov_framing_ratio_eq and markovZ_eq_qsq_div_qDimTwo, sorry-free).

      The y_(1³) = 0 is not a coincidence either: it is the 𝔰𝔩₂ row bound. A partition with more than N rows contains a cell of content -N, whose Ocneanu numerator factor vanishes identically (QOU.Information.ocneanu_numerator_vanishes_at_content_neg). Three rows, N = 2.

      The numerical values at the substrate q₀ ≈ 1.10998 are 0.5054042, 0.2472979, 0 — exactly what the accompanying .md records as the canonical convention-D weights.

          noncomputable instance QOU.BraidKnot.CanonicalMarkovWeightsH3.canonicalInstance :
          CanonicalMarkovWeightsH3

          The canonical inhabitant of CanonicalMarkovWeightsH3.

          The 𝔰𝔩₂ quantum dimensions of the production trace. Unlike explicitInstance, this is not merely an inhabitant: it is the one the convention-D Markov trace actually carries, derived from the framing ratio rather than chosen to satisfy the normalisation.

          The normalisation is an identity rather than a constraint that had to be arranged: (q⁴+1) + 2q² = (q²+1)².

          This is the class's default instance (owner decision, 2026-09-03, bean qou-6u92). Bare delta_tau_M_canonical q therefore means the production trace's Δτ_M, not the √q-bearing toy.

          The promotion was made as a PAIR with demoting explicitInstance to a def below, and the pairing is the point: two global instances of one class is a silent hazard, because resolution takes the later declaration and nothing in the source says so. With exactly one instance, what a bare use means is stated rather than inferred. Verified by lean-direct on all five files that mention the class, against a green baseline taken before the change.

          Evaluation of delta_tau_M_canonical at the explicit instance #

          The three lemmas below make the §3b-cond conditional theorems concrete at the one in-repo instance (explicitInstance), closing the loop between the class hypothesis and a downstream computation. They feed the numerical companion qbeta_delta_tau_M_canonical_explicit_instance.py (witness qbeta-delta-tau-m-canonical-explicit-instance.witness.json), which evaluates the SAME object at substrate q₀ and reports the cross-anchor swing against the rational surrogate.

          theorem QOU.BraidKnot.delta_tau_M_canonical_explicit_eq (q : ℝ) :
          delta_tau_M_canonical q = markov_parameter q * chi_block_3 q + (1 / 2 - markov_parameter q) * chi_block_21 q + markov_parameter q * chi_block_111 q

          Lemma (explicit-instance unfolding). With the explicit √q-bearing instance, the canonical Δτ_M is the concrete z-weighted block sum, where z = markov_parameter q = √q / (1 + q):

          Δτ_M^can(q) = z · χ_(3) + (1/2 − z) · χ_(2,1) + z · χ_(1,1,1).

          Pure definitional unfolding (the instance projections β/ι-reduce).

          theorem QOU.BraidKnot.delta_tau_M_canonical_explicit_has_q2_minus_1_factor (q : ℝ) (hq : 0 < q) :

          Theorem (explicit-instance (q²−1) factor). For q > 0, the canonical Δτ_M at the explicit instance factors through (q² − 1), so it vanishes at the classical point q = 1 for the structural reason (the (q²−1) factor in every per-block character), independently of the √q-bearing weights.

          Proof: unfold to the z-weighted block sum (delta_tau_M_canonical_explicit_eq), substitute the per-block factorisations from chi_blocks_have_q2_minus_1_factor, and pull out the common (q²−1); the cofactor carries the weights z = markov_parameter q as an opaque atom under ring.
