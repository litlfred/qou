    QOU.BraidKnot.F3_eps6_leading_eq_neg_2b_cubed #

    Symbolic exact match: the leading ε^6 coefficient of (F_3 - 1) at q = 1+ε equals exactly -2 · b³(q=1) = -3·√3/4.

    This is the formal-Lean port of the result proved symbolically in probe_q_beta_cat_per_factor_decomposition.py:

    F_3 - 1 = -2 · b³ · ℏ_q^6 At q = 1: b² = (q⁴+q²+1)/(q²+1)² = 3/4, so b = √3/2, b³ = (3·√3)/8. ℏ_q at q = 1: ℏ_q = (q-1)/q = 0, but leading term is ℏ_q ≈ ε at q = 1+ε. So ℏ_q^6 leading is ε^6. Hence (F_3 - 1)'s ε^6 coefficient is -2 · (3√3/8) = -3√3/4.

    The result is CLOSED in Lean by elementary arithmetic.
