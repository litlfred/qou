    QOU.BraidKnot.WitnessR5Full #

    The R5-full SDP-search numerical certificate (PR #608) for a light nucleus. Mirrors the R5FullWitness class declared in the content-block file folio/quantum-observable-universe/braids-and-knots/conj-canonical-knot-id-sdp.lean into the Lake-tracked tree.

    What this module provides #

    • R5FullWitness n — typeclass with the empirical SDP-search data: α-gap, primal/dual objectives, optimal multiplicity ρ⋆.
    • StrictComplementarityCert n — companion certificate (also mirroring the content-block declaration).

    Concrete instances #

    The Helium3Witness module (separate file) registers the hardcoded numerical instance for ³He with the values from r5-full-canonical-knot-solver.witness.json (PR #608):

    • alpha_gap := 0
    • rho_star := 3
    • min_block_eigs := [1.87, 0.53, 0.53] (all positive, active set empty)

    class QOU.BraidKnot.R5FullWitness (n : LightNucleus) :
    Type

    R5-full numerical witness for nucleus n. Records the empirical SDP-search outputs that PR #608's r5_full_canonical_knot_solver.py produces.

    • alpha_gap : ℝ

      α-gap from the SDP search (PSD-feasible iff = 0).

    • alpha_gap_nonneg : 0 ≤ alpha_gap n

      α-gap is non-negative (PSD-feasibility direction).

    • primal_obj : ℝ

      Primal objective at the search winner.

    • dual_obj : ℝ

      Dual objective at the search winner.

    • duality_gap_le : |primal_obj n - dual_obj n| ≤ 10⁻¹ ^ 6

      Strong duality at the working precision (10⁻⁶ ≈ ε of double-precision SDP solver).

    • rho_star : ℕ

      The optimal multiplicity ρ⋆ (≥ 1).

    • rho_star_pos : 0 < rho_star n

      ρ⋆ is positive.

      structure QOU.BraidKnot.StrictComplementarityCert (n : LightNucleus) [_w : R5FullWitness n] :
      Type

      Strict-complementarity certificate for nucleus n. Records the dual-side data from the SDP search that distinguishes active vs inactive constraints. Mirrors the StrictComplementarity structure in the content-block file.

      • min_block_eig : ℝ

        Minimum eigenvalue across all Wedderburn blocks in the witness's per_block_summary.

      • min_dual_y_on_active : ℝ

        Minimum dual variable on the active set.

      • max_inactive_dual : ℝ

        Maximum dual variable on the inactive set.

      • active_dual_pos_or_empty : 0 < self.min_dual_y_on_active ∨ 0 < self.min_block_eig

        Either the active set is non-empty with positive duals, or the optimum lies in the strict interior.

      • inactive_dual_zero : self.max_inactive_dual = 0

        Inactive duals are exactly zero.
