    QOU.BraidKnot.SpechtIrreducible — reduction of specht_isSimple to two named cores #

    Reduces the brick-2 irreducibility obligation QOU.BraidKnot.Specht.specht_isSimple to its two genuine deep cores via the M^μ bilinear form (James's submodule theorem).

    It builds the S_n-invariant symmetric bilinear form ⟨f, g⟩ = Σ_d f d · g d on M^μ (tabloids orthonormal) sorry-free, builds the column antisymmetrizer κ_t and its structural theory sorry-free (§3.5), and thereby proves James's submodule theorem (specht_submodule_dichotomy, §4.5) fully sorry-free: the former pure-combinatorial residual noclash_match_exists (the Gale–Ryser / conjugate-partition matching) is now discharged (§4.x) from four elementary YoungDiagram counting helpers.

    The module is now sorry-free end to end. specht_form_nondegenerate — long the single remaining core — is proved for every characteristic-zero field (§4.4), so specht_isSimple is proved outright. #print axioms reports [propext, Classical.choice, Quot.sound] for both.

    The route is not the standard-basis theorem. §4.4 thins the polytabloids over ℚ to an independent sub-family that still spans, observes that their coordinate matrix Mz is an integer matrix, and pushes det (Mz Mzᵀ) ≠ 0 into k by Cauchy–Binet: the Gram determinant is a sum of squares of minors, so positivity is an assertion about ℤ and never about k. The sub-family comes from generic linear algebra (exists_linearIndepOn_extension), so no Garnir straightening, no dominance core, and no standard tableau appears anywhere in the proof — the argument does not know what a standard tableau is.

    (Those cores are in fact themselves proved — standardBasis, standardPolytabloid_span and specht_finrank_eq_numSYT in SpechtStandardBasis all report [propext, Classical.choice, Quot.sound], and the "STUB" rows in that module's docstring table are stale as of 2026-08-08. Independence from them is a robustness property of this proof, not a way around an open problem.)

    §4.3-bis remains as the ordered-field Stage 1 (positive definiteness over ℚ, ℝ) feeding specht_isSimple_ordered; it is now a lighter special case rather than the only complete story.

    The column-clash lemma kap_of_mem_line (κ_t {s} ∈ span {e_t}) is now fully sorry-free: its two legs — the clash cancellation (kap_of_mem_line_clash, a sign-reversing involution ⇒ κ_t{s} = 0) and the no-clash reindexing (kap_of_mem_line_match, {π₀•s} = {t} for π₀ ∈ C_t ⇒ κ_t{s} = sgn(π₀)·e_t) — are both sorry-free, and the matching existence noclash_match_exists they consume is now proved (§4.x), so the lemma carries no residual sorry.

        3.5. The column antisymmetrizer κ_t (sorry-free) #

        The classical James submodule theorem is driven by the column antisymmetrizer κ_t = Σ_{π ∈ C_t} sgn(π) · rep(π) acting on M^μ. This section builds κ_t and its structural properties sorry-free:

        • kapL (a genuine M^μ →ₗ M^μ), kapL_apply, kapL_of, kapL_of_self (κ_t {t} = e_t);
        • kapL_mem_U — κ_t preserves any S_n-stable submodule (it is an integer combination of the group action);
        • kapL_selfadjoint — ⟨κ_t x, y⟩ = ⟨x, κ_t y⟩ for the form (sgn is inversion- invariant and the form is S_n-invariant);
        • polytabloid_rep_equivariant — rep σ e_s = e_{σ•s} (via the conjugation bijection conjEquiv : C_s ≃ C_{σ•s}), and tableau_transitive — the S_n- action on tableaux is transitive.

        These reduce specht_submodule_dichotomy (§4.5) to a single combinatorial core, kap_of_mem_line (§4), exactly as SpechtDominanceCore reduced brick 4.

            4.x. Pure-combinatorial core of noclash_match_exists (sorry-free) #

            The residual matching lemma below is discharged from four combinatorial helpers over Mathlib's YoungDiagram, with no representation theory: a cardinality reindexer through a tableau bijection (filterCard_reindex), the column-cell count min r (colLen c) (colCells_card), the per-column label count colLen c (Col_card), and the Gale–Ryser saturation rowPattern s l < colLen (colPattern t l) (row_lt_colLen). From saturation the label map l ↦ (rowPattern s l, colPattern t l) is a bijection onto μ.cells; matching it against t produces the column permutation π₀ ∈ C_t with {π₀ • s} = {t}.

            4.2. Gram-matrix helper lemmas for non-degeneracy #

            These two lemmas, together with standardBasis, drive the proof of specht_form_nondegenerate (§4.3). They give the diagonal and off-diagonal entries of the Gram matrix of bilinM restricted to the standard-polytabloid basis.

            • specht_gram_diag — ⟨e_T, e_T⟩ = |C_T| (the size of the column stabilizer). Proved by expanding the polytabloid double-sum and observing that cross-terms ⟨{π•t}, {σ•t}⟩ = δ_{π,σ} (two column-permuted tabloids are row-equivalent iff π⁻¹σ fixes the row pattern, i.e. π⁻¹σ ∈ rowStab ∩ colStab = {1}), so the only surviving terms are the diagonal ones where each contributes sgn(π)^2 = 1. Reference: [sagan2001] §2.4.
            • specht_gram_orthogonal — ⟨e_S, e_T⟩ = 0 for distinct standard Young tableaux S ≠ T. This is Lemma 2.4.7 of [sagan2001]: if S ≠ T are standard, then some pair of entries that are in the same row of one lies in the same column of the other, producing a sign-canceling transposition in C_T that kills the inner product.

            ⚠ REFUTED: the standard-polytabloid Gram matrix is NOT diagonal #

            A lemma specht_gram_orthogonal asserting ⟨e_S, e_T⟩ = 0 for distinct standard Young tableaux S ≠ T stood here across several commits, carrying a sorry and a comment attributing the failure to "missing double-coset machinery". The statement is false, which is why every elementary route failed. Do not restate it.

            Counterexample, μ = (2,1), n = 3 — the two SYT are

            S = 1 2      T = 1 3
    3            2

            with column stabilisers C_S = {id, (13)}, C_T = {id, (12)}, so

            e_S = {12|3} − {23|1},      e_T = {13|2} − {23|1}.

            Tabloids are orthonormal for bilinM, and the two polytabloids share exactly the tabloid {23|1} with coefficient −1 on each side, giving

            ⟨e_S, e_T⟩ = (−1)·(−1) = 1 ≠ 0.

            The full Gram matrix is [[2,1],[1,2]] (determinant 3). Machine-checked by direct enumeration for every μ ⊢ n, n ≤ 5: the off-diagonal is nonzero in every partition with ≥ 2 standard tableaux (e.g. μ = (2,1,1) gives [[6,2,−2],[2,6,2],[−2,2,6]]). Only the diagonal claim survives, and it is exactly specht_gram_diag above (⟨e_T, e_T⟩ = |C_T|), which is proved sorry-free and independently confirmed by the same enumeration.

            What Sagan §2.4 actually supplies is the triangularity of the standard polytabloids with respect to the dominance order — already available here as SpechtTriangularCore.standardPolytabloid_triangular' — not orthogonality.

            Consequence for specht_form_nondegenerate below: the "off-diagonal entries vanish, so ⟨e_T, x⟩ = c_T·|C_T|" proof plan is invalid as stated and has been replaced. See the corrected plan in that theorem's docstring.

            4.3-ter. The diagonal Gram entry, and what it does not buy #

            ⟨e_t, e_t⟩ = |C_t| is genuine characteristic-zero content — it is the reason the form is not identically zero on S^μ. It is restored here (see the provenance note on the lemma) because every route to Stage 2 needs it and it was lost as collateral damage when a different, false, lemma was refuted.

            It does not, however, close Stage 2, and the reason is worth recording so the route is not re-attempted. One might hope to feed R := S^μ ⊓ (S^μ)ᗮ — which is S_n-stable — into the already-proved specht_submodule_dichotomy, getting S^μ ≤ R or R ≤ (S^μ)ᗮ:

            • the first branch is killed by the lemma below (it would force ⟨e_t, e_t⟩ = 0, i.e. |C_t| = 0, false in char 0);
            • but the second branch is vacuous — R ≤ (S^μ)ᗮ holds by construction, so it yields nothing.

            And the vacuity is not an artifact of how the dichotomy is stated. Unfolding the κ side: by kapL_mem_line, κ_t x = λ_t(x) · e_t for a scalar λ_t(x), and by kapL_selfadjoint together with ⟨{t}, e_t⟩ = 1, ⟨e_t, x⟩ = ⟨κ_t {t}, x⟩ = ⟨{t}, κ_t x⟩ = λ_t(x). So the dichotomy's "κ_t x = 0 for all t" branch says exactly x ∈ (S^μ)ᗮ — literally the hypothesis one already has. The dichotomy therefore cannot separate R = ⊥ from R ≠ ⊥, in any characteristic. Stage 2 needs the rank/base-change input described at the sorry, not another pass through James's theorem.

            The proof, in five moves.

            1. Thin the polytabloids over ℚ. exists_linearIndepOn_extension picks a subset of tableaux b whose polytabloids are ℚ-independent and still cover the rest. It is stated for LinearIndepOn over a Set ι, so what comes back is a set of tableaux, not of vectors — which is why this step needs no standard-basis theorem, no Garnir straightening, and no dominance core.

            2. Their coordinate matrix is an integer matrix. A polytabloid is a signed sum of basis tabloids, so every coefficient is a sum of ±1 (SpechtBaseChange.polytabloid_apply_eq_intCast). Call it Mz.

            3. det (Mz Mzᵀ) ≠ 0 over k. RankMinor.exists_selector_det_ne_zero turns the ℚ-independence of Mz's rows into a nonzero maximal minor, and CauchyBinet.det_gram_map_ne_zero turns that into the Gram determinant being nonzero in k. This is the step that reaches ℂ: Cauchy–Binet writes det (Mz Mzᵀ) = Σ_f (det Mz_f)², a sum of squares of integers, so the positivity argument happens entirely in ℤ and k is never ordered.

            4. That determinant is the Gram determinant of the form. The tabloid basis is orthonormal for bilinM (bilinM_apply), so the Gram matrix of any family is exactly (coordinate matrix) · (coordinate matrix)ᵀ.

            5. Invertible Gram ⇒ trivial radical. GramNondegenerate.span_inf_orthogonalBilin_eq_bot.

            The family spans over k and not merely over ℚ because the coordinates are integers, so the ℚ-relations found in step 1 survive base change (SpechtBaseChange.spechtSubmodule_eq_span_of_rat).

            Relation to Stage 1. specht_form_nondegenerate_ordered (§4.3-bis) proves the same statement over an ordered field by positive definiteness, in three lines. It remains as the cheap special case; it provably cannot reach ℂ, where the form is bilinear rather than sesquilinear and has isotropic vectors (x = (1, i) gives ⟨x, x⟩ = 0 with x ≠ 0).

            4.5. James's submodule theorem — proved from the single core #

            source
            theorem QOU.BraidKnot.SpechtIrreducible.specht_submodule_dichotomy {k : Type} [Field k] (μ : YoungDiagram) (U : Submodule k (Specht.Mtab μ)) (hU : ∀ (σ : Equiv.Perm (Fin (Specht.nOf μ))), ∀ x ∈ U, ((Specht.Mtab.rep μ) σ) x ∈ U) :

            James's submodule theorem (the dichotomy) — now proved sorry-free modulo the single core kap_of_mem_line. For any S_n-stable k-submodule U ≤ M^μ, either S^μ ≤ U or U ≤ (S^μ)ᗮ.

            Proof. Split on whether κ_s annihilates all of U.

            • If κ_s x = 0 for every x ∈ U, s: then for each x ∈ U, ⟨e_s, x⟩ = ⟨κ_s {s}, x⟩ = ⟨{s}, κ_s x⟩ = 0 (kapL_selfadjoint), so x ⊥ S^μ, i.e. U ≤ (S^μ)ᗮ.
            • Otherwise some κ_s x ≠ 0 with x ∈ U. Then κ_s x ∈ U (kapL_mem_U) and κ_s x ∈ span{e_s} (kapL_mem_line), so κ_s x = c·e_s with c ≠ 0, whence e_s ∈ U. By S_n-equivariance (polytabloid_rep_equivariant) and transitivity (tableau_transitive) every polytabloid lies in U, so S^μ ≤ U.
