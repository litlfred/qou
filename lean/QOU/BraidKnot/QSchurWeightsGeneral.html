    QOU.BraidKnot.QSchurWeightsGeneral #

    THEOREM (uniqueness C4). The Markov-trace weights y_λ(q) on H_n(q) are uniquely determined by Frobenius positivity + Wenzl normalisation:

    y_λ(q) = q^{c(λ)} / [n]_q!

    Proof: induction on n using Wenzl's branching rule (Theorem 5 of [wenzl1988]). Base case n=2 proved sorry-free in PR #1298.

    Ref: [wenzl1988] Wenzl, "Hecke algebras of type A_n and subfactors" Ref: [ram1991] Ram, "A Frobenius formula for the characters" Ref: [manuscript] prop:q-schur-y-lambda-closed-form

    class QOU.BraidKnot.WenzlBranching (q : ℝ) :
    Type

    Wenzl branching rule (axiomatized).

    The Markov weight of λ ⊢ n under the inclusion H_{n-1} ↪ H_n satisfies: y_λ^{(n)} = y_μ^{(n-1)} · q^{content(cell)} / [n]_q

    where μ = λ with one removable cell deleted, and content(cell) is the content (j-i) of that cell.

    This is [wenzl1988] Theorem 5. The class axiomatizes it so that the inductive proof can proceed formally.

    • weight : MathlibExt.QPartitionCombinatorics.Partition → ℝ
    • branching (lam μ : MathlibExt.QPartitionCombinatorics.Partition) (i j : ℕ) : weight q lam = weight q μ * q ^ MathlibExt.QPartitionCombinatorics.cellContent i j / MathlibExt.QPartitionCombinatorics.qBracket q lam.size
    • base_one : weight q [1] = 1
    • normalised (n : ℕ) : True

      theorem QOU.BraidKnot.qSchur_weight_base (q : ℝ) (hq : 1 < q) [W : WenzlBranching q] :
      WenzlBranching.weight q [1] = q ^ MathlibExt.QPartitionCombinatorics.contentSum [1] / MathlibExt.QPartitionCombinatorics.qFactorial q 1

      THEOREM (q-Schur weight — base case, derived). Conditional on the WenzlBranching data, the closed form y_λ = q^{c(λ)} / [n]_q! holds at the induction base λ = (1) (n = 1):

      weight [1] = q^{contentSum [1]} / qFactorial q 1 = q^0 / [1]_q! = 1.

      This is a genuine derivation, not a tautology: it combines the class field WenzlBranching.base_one (weight [1] = 1) with the computed facts contentSum [1] = 0 (contentSum_one), q^(0:ℤ) = 1, and qFactorial q 1 = [1]_q = 1 for q > 1. The general inductive step is the open part carried by qSchur_weight_closed_form below.

      def QOU.BraidKnot.qSchur_weight_closed_form (q : ℝ) [W : WenzlBranching q] :
      Prop

      Conditional q-Schur weight closed form (the §3b-cond conjecture, named honestly as a Prop). Conditional on WenzlBranching q, for every partition λ the Markov weight equals q^{c(λ)} / [|λ|]_q!.

      The base case qSchur_weight_base is derived above; the full statement (the inductive step across all λ) is the open part of prop:q-schur-y-lambda-closed-form and is named, not asserted, here.

        def QOU.BraidKnot.qSchur_normalisation (q : ℝ) [W : WenzlBranching q] (parts : List MathlibExt.QPartitionCombinatorics.Partition) :
        Prop

        Wenzl normalisation (named conditional conjecture). Conditional on WenzlBranching q, the Markov weights sum to one against the q-dimensions:

        Σ_{λ ⊢ n} dim_q(λ) · y_λ = 1.

        Stated honestly as a Prop over a supplied list parts of the partitions of n (the §3b-cond carrier; not asserted). Follows from the q-analog of Burnside's identity Σ_λ (f^λ)² q^{c(λ)} = [n]_q!.
