    QOU.BraidKnot.PerNucleusMassDerivation #

    Per-nucleus instantiation of the categorical mass formula M = ρ · m_e · |tr_M(T_w)| for {²H, ³H, ³He}. Combines the R5FullWitness data (which fixes ρ⋆) with the abstract MassFormulaCategorical to produce concrete Lean-typed mass predictions.

    Mathematical content #

    For each light nucleus n:

    • ρ(n) := w.rho_star (from the registered R5FullWitness n)
    • T_w(n) is the canonical Hecke element (currently a placeholder element of HeckeElement n.n₀ pending the algebra-evaluation port)
    • M_pred(n) := ρ(n) · m_e · |tr_M(T_w(n))|

    The numerical conversion to MeV uses m_e_MeV_codata := 0.51099895069 from MassFormulaCategorical.

    What this module provides #

    • nucleusMass n — the categorical mass prediction at the Hecke-element level (placeholder T_w)
    • nucleusMassMeV n — the MeV-converted prediction
    • nucleusMass_nonneg n — non-negativity proof

    Open Lean port #

    The placeholder T_w(n) := 0 ensures the mass is zero — the real values come from the Hoefsmit-evaluated braid words once that port lands. This module captures the schematic structure; concrete values follow.

    noncomputable def QOU.BraidKnot.PerNucleusMassDerivation.m_e_cat :
    ℝ

    Cat-units electron mass placeholder. Real value comes from the proton chain's m_e_Hecke ≈ 0.0007783 (per derivation_chain.M_HECKE_PIPELINE_AT_Q0).

    def form (was previously an axiom). Discharged 2026-06-07 by binding to the witness's approximate value 0.0007783. The axiom previously committed to no value (only existence) and let downstream proofs use it opaquely; the only theorem that depended on m_e_cat semantically was m_e_cat_pos, which now follows by norm_num from the literal. Other consumers (nucleusMass, nucleusMassMeV) treat m_e_cat as a scalar and do not care about its exact value. A future refactor will rebind this def to the Hecke-port output once the categorical pipeline returns a Lean-typed real; every downstream proof continues to type-check unchanged.

    Until then, the literal acts as a placeholder witness (same role as the axiom, but with positivity provable).
