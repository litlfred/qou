    QOU.BraidKnot.symbolic_character_table — χ_λ(σ₁) = c_λ · h (concrete, sorry-free) #

    Proposition (prop:symbolic-character-table).

    For each self-conjugate partition λ ∈ {[2,1], [3,1,1], [3,2,1], [4,1,1,1]}, the single-generator seminormal character χ_λ(σ₁) is c_λ · h where h = q − q⁻¹ and c_λ = #SYT(λ)/2 ∈ {1, 3, 8, 10}.

    Disposition (integrity) — the sorry is now discharged #

    Earlier revisions carried an opaque chiSigma class field and left the proposition as sorry + citation: the seminormal-form summation a_ρ = h/(1 − q^{−2ρ}) over standard Young tableaux was not in Mathlib, so χ_λ(σ) could not be computed. That apparatus now exists in-repo:

    • SeminormalCharacterConnector.sigmaOneCharacter_eq_card_mul proves χ_λ(σ₁) = |R_row| · h for every self-conjugate μ (the off-diagonal class is empty for a single generator; |R_row| = |R_col| by the conjugate-transpose bijection);
    • the per-shape counts card_rowClass_mu{21,311,321,4111} (via the hook-length / enumeration count #SYT) give |R_row| = c_λ ∈ {1, 3, 8, 10}.

    So chiSigma below is now a concrete def (the σ₁ seminormal character of the shape), not an opaque field, and symbolic_character_table is proved outright — no sorry, no class conclusion field. The manuscript's [3,1,1] pair/triple character polynomials are retained as sorry-free algebraic identities.

    -- Ref: [manuscript] quantum-observable-universe/mass-theory/symbolic-character-table.md -- Ref: [sagan2001] The Symmetric Group, §3.3 (Young's seminormal form)

    §7c base ring. The whole table is Hecke seminormal-form algebra: sigmaOneCharacter is already generic over [Field R], and sigmaOneCharacter_eq_card_mul additionally wants (2 : R) ≠ 0 — the same characteristic condition the meson-em-sinh-closed-form port needed.
