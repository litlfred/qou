    The hook-sum closed form #

    For every Young diagram μ with n = |μ| cells, row lengths λ and column lengths λ',

    Σ_{c∈μ} hook(c) = Σ_i C(λ_i, 2) + Σ_j C(λ'_j, 2) + n,

    equivalently, doubling to stay in ℤ and folding n into the squares,

    2 · Σ_{c∈μ} hook(c) = p₂(λ) + p₂(λ'),      p₂(λ) := Σ_i λ_i².

    The second form is the one the Plancherel analysis uses: it exhibits Σ_h as a conjugation-symmetric functional of the diagram, half the sum of p₂ on λ and on its transpose. That symmetry is what forces Σ_h outside the algebra Λ* of shifted symmetric functions — the free cumulants R_k have conjugation parity R_k(λ') = (−1)^k R_k(λ), so a Λ* element invariant under conjugation can carry no odd-degree part, while Σ_h grows like n^{3/2}.

    This module supplies only the identity. It is proved from the reflection lemmas already established for Piece A (sum_armZ_generic, sum_legZ_generic, sum_swap_transpose in PieceAGeneral) plus a cells-to-rows decomposition, so it carries no new combinatorial input.

    Prior art — the same identity in the List ℕ register #

    QOU.Common.HookSumComplete.hookSum_eq already proves this identity, sorry-free, as Σ_c h(c) = b(λ') + b(λ) + n over a sorted List ℕ, with its own colLen / bStat / armPart / legPart / hookSum definitions in ℕ (truncated subtraction) and an explicit sortedness hypothesis. This module is that identity restated where the rest of the corpus lives: on Mathlib's YoungDiagram, over ℤ, on the armZ / legZ / hookZ of PieceAGeneral — so it composes with pieceA and the rest of QOU.BraidKnot, which the List ℕ version cannot, and needs no sortedness hypothesis, YoungDiagram carrying that structurally.

    sum_hookZ_eq_bStat below states the result in HookSumComplete's own b(λ') + b(λ) + n shape, term for term, so the correspondence is visible rather than asserted. The two are not bridged: that needs YoungDiagram.rowLens lemmas relating l.getD i 0 to μ.rowLen i and the ℕ/ℤ cast, and is tracked separately. The three QOU.Common.HookSum* modules are pre-existing import orphans (bean qou-kljb, owner-scoped); this one is wired into QOU.BraidKnot.

    Index sets #

    The row and column sums are taken over range N / range M for any N, M large enough to cover the diagram (μ.colLen 0 ≤ N rows, μ.rowLen 0 ≤ M columns). Outside that range rowLen/colLen vanish, so every admissible choice gives the same value; taking a hypothesis rather than a canonical N keeps the statement usable against whatever bound a caller already has.

    Base ring #

    All sums over ℤ, matching PieceAGeneral — no ℝ, no archimedean input.
