    Central primitive idempotents e_λ — carrier and open conjecture #

    The vocabulary shared by prop:explicit-central-idempotent and conj:explicit-central-idempotent: the standard-Young-tableau type, the q-content of a box, the idempotent element itself, and the open conjecture asserting that the four Murphy–Lagrange cross-checks hold.

    Why this is a library module and not a content-block sibling #

    ExplicitCentralIdempotentConjecture is stated by one block (the conj:) and consumed as an instance hypothesis by another (the prop:). A content-block sibling .lean cannot import another sibling, so keeping the class in a sibling would force the two blocks to declare it twice, independently — the divergence shape recorded in docs/audits/2026-09-03-sibling-lean-compile-sweep.md §"A cost of this sweep", where two declarations sharing a name drift apart and the lean.ref (which resolves sibling-first, by file) silently picks the stale one. Declaring it once here is what makes both blocks able to name the same object.

    §3b-tax status #

    ExplicitCentralIdempotentConjecture is a primary conjecture: its signature binds no other conjecture class. Per §3b-tax an unproved primary is a content-bearing class with no instance, and there is deliberately none — supplying one would assert the conjecture rather than prove it (§"Axiomatization is NOT a Proof").

    def QOU.BraidKnot.ExplicitCentralIdempotent.qContent {R : Type u_2} [CommRing R] (i j : ℤ) (q : Rˣ) :
    R

    The q-content of a box at position (i, j) in a Young diagram: c(i, j; q) = q^(2(j - i)).

    This is the integer (signed) power, so for boxes below the main diagonal (j < i) the content is q⁻²ᵏ for some k > 0, i.e. q ^ (n : ℤ) must be total.

    §7c: that is supplied by carrying q as a unit q : Rˣ of a bare CommRing R — Rˣ is a group, so zpow is total there — rather than by strengthening the base ring to a GroupWithZero/Field. The generic Hecke ground ring ℤ[q, q⁻¹] is exactly this situation: q is a unit and the ring is not a field.

    Per Gemini PR #634 review: previous (2 * (j - i)).toNat was mathematically incorrect — it forced q^0 = 1 for all boxes below the diagonal, which contradicts the standard q-content definition (Hoefsmit, prop:hoefsmit-seminormal-form).

      class QOU.BraidKnot.ExplicitCentralIdempotent.ExplicitCentralIdempotentConjecture {R : Type u_2} [CommRing R] (q : R) :
      Type (max 1 u_2)

      CONJECTURE (OPEN) — conj:explicit-central-idempotent.

      The Murphy–Lagrange element e_λ decomposes as a sum, over the standard Young tableaux of shape λ, of pairwise-orthogonal idempotents — the per-tableau Lagrange projectors

      π_T = ∏_k ∏_{□ ≠ T(k)} (J_k - c(□;q)) / (c(T(k);q) - c(□;q))

      onto the joint (c(T(1);q), …, c(T(n);q))-eigenspace of the commuting Jucys–Murphy elements.

      This is the interpolation-theoretic INPUT, not the conclusion. Earlier this class had a single field whose type was centralIdempotent lam q * centralIdempotent lam q = centralIdempotent lam q — the downstream theorem's conclusion verbatim — and that theorem discharged it by exact hi.idempotent lam h, a bare projection. AGENTS.md §3b-cond item 5 forbids exactly that: a class must axiomatise the hypotheses and the theorem must derive its conclusion from them. Caught 2026-09-04 by the --item5 mode of scripts/conditional-on-class-hypothesis-audit.ts.

      The three fields below are what Lagrange interpolation in commuting variables actually supplies, and idempotency, orthogonality and sum-to-identity are all consequences of them rather than restatements. explicit_central_idempotent_via_murphy now composes them.

      • Tab : List ℕ → Type

        The standard Young tableaux of shape λ, as an index type.

      • fintypeTab (lam : List ℕ) : Fintype (Tab q lam)

        Finitely many of them, so the decomposition is a finite sum.

      • proj (lam : List ℕ) : Tab q lam → R

        The Lagrange projector attached to one tableau.

      • proj_idem (lam : List ℕ) (T : Tab q lam) : proj lam T * proj lam T = proj lam T

        Each projector is idempotent — Lagrange interpolation at a simple joint eigenvalue.

      • proj_orth (lam : List ℕ) (T T' : Tab q lam) : T ≠ T' → proj lam T * proj lam T' = 0

        Distinct tableaux carry distinct joint eigenvalue tuples, so their projectors are orthogonal.

      • centralIdempotent_eq_sum (lam : List ℕ) : centralIdempotent lam q = ∑ T : Tab q lam, proj lam T

        e_λ is the sum of the per-tableau projectors.
