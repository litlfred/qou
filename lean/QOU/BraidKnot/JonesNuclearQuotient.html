              theorem QOU.BraidKnot.JonesNuclearQuotient.jonesHopfLink_eq_jonesHopf (q : ℝ) (hq : 1 < q) :
              jonesHopfLink q = jonesHopf q

              The Hopf-value bridge: the (h·z + 1) Hopf value here equals the canonical closed form jonesHopf of [JonesViaMarkovTrace].

              Under convention D this stopped needing an rpow normalisation at all (2026-08-26, bean qou-cxjq). It used to be "the rpow-normalisation bridge, previously deferred pending the LSP": both sides reduced to √q − 1/√q + 1, and the proof had to convert Real.sqrt q ↔ q ^ (1/2 : ℝ), establish q ^ (5/2) = q² · √q, and clear denominators around a square root.

              Under D both sides are the same rational function (q⁴ + 1)/(q² + 1) — the Markov axiom fixes tr_M(σ₁²) = h·z + 1, and at z = q³/(q²+1) that is exactly the tower's migrated trM_sigma1_sq. The square roots are gone from both, so the bridge is field_simp; ring.

              Worth noting against the general expectation that a convention migration costs proof effort: here it removed a proof obligation that had been deferred.

                    noncomputable def QOU.BraidKnot.JonesNuclearQuotient.nuclearQuotientJones (q : ℝ) (Z N : ℕ) :
                    ℝ

                    The nuclear quotient braid Jones value — the RHS of the (open) Part-4 conjecture a(Z,N) = J_β̄(q). Selects the (2,k) torus-link Jones value by the shell-structure crossing power k = nuclearCrossingPower Z N. This is the concrete construction of jet_filtered_knot_factor.jonesQuotient; it does not assert equality with the BW knot factor a(Z,N) (the open conjecture).
