    The covering monodromy t ↦ −t and the classical prolongation d/dz #

    source
    def QOU.Brings.RamificationParityMonodromy.mono {R : Type u_1} [CommRing R] (f : ℤ → R) :
    ℤ → R

    Ramification covering monodromy t ↦ −t. On the coefficient model Σ_e f(e) t^e, substituting t ↦ −t sends the coefficient at exponent e to (−1)^e · f(e): it fixes even-t-degree terms and negates odd ones. This is the ℤ/2 grading whose +1/−1 eigenspaces are the bar-even (cosh) and bar-odd (sinh) sectors.

      def QOU.Brings.RamificationParityMonodromy.shift2 {R : Type u_1} [CommRing R] (c f : ℤ → R) :
      ℤ → R

      A degree-(−2) exponent shift with arbitrary coefficient weight c: the coefficient of t^e is read from t^{e+2}. The classical geometric prolongation d/dz = (1/(2t)) d/dt is the member with weight c(e) = (e+2)/2 (ddz below); the parity structure proved here is weight-independent, which is exactly why the immaterial ½ scalar can be dropped.

              No-identity (the geometric core of S1). A classical jet tower grown from a fixed-t-parity seed (mono X = ε • X) cannot reproduce a target tower whose monodromy eigenvalue σ n genuinely differs from ε at some jet n where the target is nonzero. Over an integral domain the constant character ε of the classical tower and any nonconstant character σ are incompatible.

              theorem QOU.Brings.RamificationParityMonodromy.classical_jet_not_door_v {R : Type u_1} [CommRing R] [NoZeroDivisors R] (hchar : 1 ≠ -1) (X : ℤ → R) (target : ℕ → ℤ → R) (hX : mono X = 1 • X) (htar : ∀ (n : ℕ), mono (target n) = (-1) ^ n • target n) (hid : ∀ (n : ℕ), jet X n = target n) (e : ℤ) (hnz : target 1 e ≠ 0) :
              False

              Door-v specialization. The Door-v residual is exactly a bar-even (cosh) seed X (mono X = 1 • X) confronting a target whose n-th jet carries the (−1)^n bar-parity character — the measured (−1)^m alternation. No classical jet tower realizes it: already at n = 1 the classical character 1 disagrees with (−1)^1 = −1 (using 1 ≠ −1, i.e. characteristic ≠ 2). The (−1)^m residual is therefore the ramification covering monodromy, not a classical jet.
