    def QOU.Brings.sylvesterMatrix {R : Type u_1} [CommRing R] {m n : ℕ} (p : Fin (m + 1) → R) (q : Fin (n + 1) → R) :
    Matrix (Fin (n + m)) (Fin (n + m)) R

    The Sylvester matrix of p (degree m; p 0 leading, …, p m constant) and q (degree n, same convention). Rows 0 … n−1 are the coefficients of p shifted right by the row index; rows n … n+m−1 are those of q, shifted by row − n.
