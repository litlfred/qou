    QOU.Brings.ColourCubicBranchLocus — the branch locus is bar-symmetric, and no residue survives #

    Two exact facts about the colour cubic

    f(X, z) = X³ + (z+1)X² + (z²+z+1)X + (z³+z²+z+1)

    whose branch locus is the zero set of

    Δ(z) = −(16z⁶ + 24z⁵ + 35z⁴ + 50z³ + 35z² + 24z + 16)

    (bring_cubic_monodromy_probe.py A1: degree 6, gcd(Δ, Δ′) = 1, so six distinct simple branch points). Both facts bear on the enclosed pole set E that prop:sw-period-residue-sum leaves open — see bean qou-qx7j.

    1. The locus is invariant under the bar involution z ↦ 1/z #

    Δ's coefficient list [16, 24, 35, 50, 35, 24, 16] is palindromic. Hence z⁶ Δ(1/z) = Δ(z), so the branch locus is closed under z ↦ 1/z (branchLocus_inv_mem). That is the Hecke bar-involution acting on the pole locus — the corpus had the polynomial written out exactly and had not noticed that it is self-reciprocal.

    Consequences, all exact:

    • The substitution w = z + 1/z sends Δ/z³ to the cubic 16w³ + 24w² − 13w + 2 (w_cubic_of_palindromic, verified by field_simp; ring).
    • That cubic has discriminant −80000 < 0, so exactly one real root and one conjugate pair; and C(−2) = −4 < 0 < 23 = C(−1) puts the real root in (−2, −1) ⊂ (−2, 2) (w_real_root_mem_Ioo, integer evaluations only).
    • A real w with w² < 4 gives roots of z² − wz + 1 of modulus exactly one (normSq_root_eq_one). So two branch points lie exactly on the unit circle, and they are the bar-fixed ones.
    • The remaining four form a single bar-orbit {a, ā, 1/a, 1/ā} — two strictly inside, two strictly outside.

    The unit circle is therefore not an admissible contour: it passes through two branch points. That rules out the one candidate the corpus's own ∮_{S_c} notation suggests.

    2. No residue survives, at any branch point, at any jet level #

    At a simple (square-root) branch point put z = z_k + t², so t is a local coordinate on the curve and d/dz = (1/(2t)) d/dt. On a Laurent term a_j t^j that operator acts by a_j t^j ↦ (j/2) a_j t^{j−2}, so after n applications

    a_j t^j ↦ a_j · 2^{−n} · (∏_{i<n} (j − 2i)) · t^{j−2n}.

    Since λ_SW^(n) = X^(n) dz = X^(n) · 2t dt, the residue is 2 · the coefficient of t^{−2} in X^(n), which can only come from j = 2n − 2. But that chain product contains a zero factor at i = n − 1 (chain_factor_eq_zero): the term has become a constant after n − 1 applications, and the n-th differentiates it away.

    So every residue vanishes identically — for every branch point and every n ≥ 1, independent of the Puiseux coefficients. Hence every subset E gives period zero, and E is not identifiable because there is nothing to enclose.

    This is a third route to a conclusion the corpus already holds. prop:sw-classical-jet-exactness gets period = 0 from global exactness (λ_SW^(n) = d(X^(n−1))) and scopes it as a scope-(b) exclusion of the classical-jet reading; QOU.Brings.period_eq_zero_of_total_residue_vanishes gets it from the ambient compact surface. This one is local and per-point: it needs neither a global primitive nor the surface, only the parity of (1/2t) d/dt. The q-difference prolongation is untouched by all three.

    Ground ring: ℤ for the chain product (a parity fact), ℂ/ℝ for the modulus computations, which are genuinely archimedean (§7c).

        2. No residue survives — stated in the corpus's own local model #

        QOU.Brings.RamificationParityMonodromy already carries exactly the setting this needs: at a simple ramification point z = z_c + t² it models a local Laurent expansion by its coefficient function f : ℤ → R and defines the classical prolongation as

        ddz f = fun e => ((e + 2 : ℤ) : R) • f (e + 2),

        the coefficient form of d/dz = (1/(2t)) d/dt with its exponent shift of exactly −2. That file uses the shift's evenness (to show ddz commutes with the covering monodromy t ↦ −t). What follows uses the multiplier instead, and it is the one exponent where that multiplier vanishes.

        Nothing here rebuilds ddz; the results below are about the corpus's operator.

        §7c: this half is pure algebra over a generic [CommRing R] — no ordering, no ℝ. Only §1's modulus computations are archimedean.

        source
        theorem QOU.Brings.ColourCubicBranchLocus.ddz_residue_slot_eq_zero {R : Type u_1} [CommRing R] (f : ℤ → R) :
        RamificationParityMonodromy.ddz f (-2) = 0

        The residue slot is annihilated by a single application of d/dz.

        (ddz f)(−2) = ((−2) + 2) • f 0 = 0 • f 0 = 0, for every f. The t^{−2} coefficient of a z-derivative is always zero, because the only input that could reach it is the constant term f 0, and differentiating a constant kills it.

        Since λ_SW^(n) = X^(n) dz = X^(n) · 2t dt, the residue at a simple branch point is (up to the nonzero factor 2) exactly this coefficient. So every residue of λ_SW^(n) vanishes, at every branch point, for every n ≥ 1, whatever the Puiseux data — the conclusion needs no global primitive and no compact surface, only the multiplier e + 2 at e = −2.

        theorem QOU.Brings.ColourCubicBranchLocus.chain_factor_eq_zero (m : ℕ) :
        ∏ i ∈ Finset.range (m + 1), (2 * ↑m - 2 * ↑i) = 0

        The same fact as a chain product, for the general-n bookkeeping. n applications of (1/(2t)) d/dt multiply the term a_j t^j by ∏_{i<n} (j − 2i); at the critical j = 2n − 2 (writing n = m+1) the factor at i = m is zero. Kept because the probe reports this product across n.

        Hence no enclosed set E can produce a nonzero period. A sum of zeros over any finite index set is zero, so the choice of E is immaterial: the question "which branch points does the contour enclose" has no content under the classical-jet prolongation λ_SW^(n) = X^(n) dz.
