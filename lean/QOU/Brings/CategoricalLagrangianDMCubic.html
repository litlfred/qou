    QOU.Brings.CategoricalLagrangianDMCubic — the Donagi–Markman cubic-condition route to an INDEPENDENT geometric origin for the binding kernel C1 #

    Scope (read this first). This file is a FORMALIZE-FIRST STRUCTURAL SCAFFOLD for an open research route, not a proof of anything about the keystone binding kernel. It states — honestly, as content-bearing conjecture carriers with no instances — the structural chain by which the Donagi–Markman "cubic condition" ([donagi-markman1996cubics] §1; [donagi1997swintegrable]) would give the keystone binding kernel C1 an independent geometric origin, de-tautologizing the QDM-3 result.

    Why de-tautologize. QOU.Machinery.QProlongation.symbol_eq_recurrence_kernel proves symbol D_q = recurrenceKernelLead κ by construction: the recurrence operator D_q is defined from the C1 recurrence and recurrenceKernelLead is defined as the leading term of that same recurrence. That is an honest tautological re-encoding (its own file says so), not a geometric origin for C1. The genuine wall is to build the cubic / period datum independently from the Bring hyperkähler geometry and only then match it to the kernel. This file scaffolds that independent side.

    The 4-form → 2-form correction (documented, load-bearing). The Bring cone C(𝓑) ⊂ ℂ⁵ is a real-4-dimensional manifold (def:bring-cone-tetraplectic-structure; QOU.Tetraplectic.BringCone). A tetraplectic 4-form on a 4m-manifold needs Ω^m non-degenerate; at m = 1 the 4-form degenerates to a mere volume form and carries no Lagrangian-fibration data. The structure that actually supports a Donagi–Markman ACIHS / Lagrangian fibration is the hyperkähler holomorphic-symplectic 2-form Ω_ℂ (signalled by the 3-Sasakian link + the Reeb quaternionic twist [M_i,M_j] = 2M_k, proved sorry-free in QOU.Tetraplectic.BringCone). So the load-bearing object below is the holomorphic-symplectic 2-form, NOT the 4-form.

    The structural chain (each item stated honestly) #

    1. QDonagiMarkmanCubicCondition — primary conjecture class (§3b-tax). The q-analogue of DM's cubic condition on a q-Lagrangian fibration: there is a field of totally-symmetric cubics c ∈ Sym³ T*B whose contraction is the differential of the (q-)period map. Content-bearing: the field asserts the period differential is totally symmetric (the integrability that is equivalent to the fibration being Lagrangian / the period matrix being a Hessian), which is FALSE for a generic fibration. No instance (open).

    2. BringHolomorphicSymplectic — primary conjecture class (§3b-tax). The Bring hyperkähler cone carries a non-degenerate holomorphic-symplectic 2-form Ω_ℂ, and the on-shell categorical-Lagrangian wavefront 𝒟_∇ψ = 0 (def:categorical-lagrangian, rem:wavefront-propagation) is Lagrangian (isotropic + half-dimensional) w.r.t. it. Content-bearing; no instance.

    3. categorical_lagrangian_dm_cubic — conditional theorem (§3b-cond), proved sorry-free modulo classes (1)+(2) taken as explicit [Instance] hypotheses (the binders ARE the dependency edges, §3b-tax). It composes the two class fields: it extracts the DM q-cubic of the Bring fibration, derives its full S₃/3-cycle symmetry from the two transposition symmetries (a genuine composition, not a self-assuming projection), and carries through the Lagrangian isotropy of the wavefront from class (2).

    4. QCubicEqBindingKernel — THE TARGET, dependent conjecture class (§3b-tax; depends on class (1) via an [Instance] binder). It asserts the open identity: the DM q-cubic of the Bring fibration equals the binding kernel C1 — concretely, the q-cubic's leading self-contraction is the nonzero recurrence-kernel weight κ = QOU.Machinery.QProlongation.recurrenceKernelLead (the leading term of the depth-2 C1 kernel [n+2]_q b_{n+2} = b_{n+1} + b_n, QOU.Mass.QDifferenceConfluentObstruction). This is the genuine open wall. It has no instance. Deriving it (NOT fitting it) is what would give C1 an independent geometric origin and de-tautologize QDM-3; it is NOT proved here.

    structure QOU.Brings.CategoricalLagrangianDMCubic.QLagrangianFibration (R : Type u_1) [CommRing R] :
    Type u_1

    q-Lagrangian fibration data. A base of dimension dim together with the differential of the (q-)period map dPeriod i j k = ∂_k τ_{ij}, where τ_{ij} is the (symmetric) q-period matrix. We record only the symmetry the period matrix carries a priori — symmetry in the first two slots (τ_{ij} = τ_{ji}). The third-slot symmetry is exactly the Donagi–Markman cubic condition and is therefore NOT recorded here — it is the content of the conjecture class QDonagiMarkmanCubicCondition.

    • dim : ℕ

      Complex dimension of the fibration base B.

    • dPeriod : Fin self.dim → Fin self.dim → Fin self.dim → R

      Differential of the q-period map: dPeriod i j k = ∂_k τ_{ij}.

    • dPeriod_symm_ij (i j k : Fin self.dim) : self.dPeriod i j k = self.dPeriod j i k

      The q-period matrix is symmetric: ∂_k τ_{ij} = ∂_k τ_{ji}.

        class QOU.Brings.CategoricalLagrangianDMCubic.QDonagiMarkmanCubicCondition {R : Type u_1} [CommRing R] (F : QLagrangianFibration R) :
        Prop

        §3b primary conjecture class — the q-Donagi–Markman cubic condition.

        @conjecture: primary

        The q-analogue of the Donagi–Markman cubic condition ([donagi-markman1996cubics] §1): for the q-Lagrangian fibration F, there is a field of totally-symmetric cubics c ∈ Sym³ T*B — symmetric under every transposition of its three slots — whose contraction reproduces the differential of the q-period map, dPeriod = ⟨c, ·⟩ (i.e. ∂_k τ_{ij} = c_{ijk}).

        Content (not a marker). F records only that dPeriod is symmetric in its first two slots (the period matrix is symmetric). The class asserts the STRONGER, non-automatic fact that dPeriod is totally symmetric — the integrability equivalent to τ being a Hessian ∂²F and the fibration being Lagrangian (an ACIHS). This is FALSE for a generic dPeriod, so the class genuinely constrains F; it is not dischargeable for an arbitrary fibration.

        No instance is supplied — the honest open state of the cubic-condition conjecture.

        • exists_cubic : ∃ (c : Fin F.dim → Fin F.dim → Fin F.dim → R), (∀ (i j k : Fin F.dim), c i j k = c j i k) ∧ (∀ (i j k : Fin F.dim), c i j k = c i k j) ∧ ∀ (i j k : Fin F.dim), F.dPeriod i j k = c i j k

          There is a totally-symmetric cubic c realising the period differential: c is symmetric under the (1 2) and (2 3) transpositions (which generate S₃), and ∂_k τ_{ij} = c_{ijk}.
