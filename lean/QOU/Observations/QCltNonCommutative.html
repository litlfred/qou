    QOU.Observations.QCltNonCommutative #

    Conditional q-Central Limit Theorem for Hecke transfer matrices, encoded as a typeclass per AGENTS.md §3b-cond. The class fields carry concrete mathematical content (a real variance, a q-Gaussian measure, quantitative convergence statements) so that providing an instance requires actual mathematical input rather than four free propositions.

    The conjecture states that the centred braid-generator sum S_n = n^{-1/2} Σ (σ_i - tr_M(σ_i)) converges, in joint moments under tr_M, to a non-commutative q-Gaussian process at parameter q ∈ (0, ∞) in the Wenzl positivity regime.

    Resolves issue #649 §1 (q-CLT proof / derivation).

    class QOU.Observations.QCltNonCommutative.QCltNonCommutative (R : Type u) [Field R] [LinearOrder R] [IsStrictOrderedRing R] [TopologicalSpace R] :
    Type u

    Conditional q-CLT class. Asserts the existence of a quantitative q-CLT limit for a sequence of Hecke transfer matrices under the Markov trace.

    Each field carries content; the class is satisfied only with actual mathematical witnesses, not by any pair of propositions.

    • secondCumulant — the limit variance κ₂ of S_n under tr_M.
    • qGaussianMeasure — the limit measure G_q(t, x) parametrised by a level-index.
    • momentConvergence — for each fixed degree k, tr_M(S_n^k) converges to the k-th moment of qGaussianMeasure.
    • characteristicLimit — the moment-generating-function form of the convergence: tr_M(exp_q(i ξ S_n)) converges to exp_q(-ξ²/2 · κ₂).
    • secondCumulant : R

      Limit variance (second free q-cumulant).

    • secondCumulant_pos : 0 < secondCumulant

      Positivity of the limit variance.

    • qGaussianMeasure : ℕ → R

      The q-Gaussian limit measure as a function level → R.

    • qGaussianMeasure_nonneg (n : ℕ) : 0 ≤ qGaussianMeasure n

      The q-Gaussian measure is non-negative at every level.

    • momentSequence : ℕ → ℕ → R

      Concrete moment sequence: for each fixed degree k, the $k$-th joint moment of the rescaled centred sum S_n under tr_M as a function of n. Carrying this as a class field forces an instance to supply the actual moment data.

    • limitMoment : ℕ → R

      Limit moments: the limiting value of the $k$-th moment. Also a class field, so the instance supplies the actual limit.

    • momentConvergence (k : ℕ) : Filter.Tendsto (fun (n : ℕ) => momentSequence n k) Filter.atTop (nhds (limitMoment k))

      Moment convergence: for every fixed degree k, the sequence n ↦ momentSequence n k converges to limitMoment k. Encoded via Filter.Tendsto, the standard Mathlib convergence predicate.

    • characteristicSequence : ℕ → R → R

      Concrete characteristic-function sequence: for each ξ, the moment-generating-function value tr_M(exp_q(i ξ · S_n)) as a function of n.

    • characteristicLimitValue : R → R

      Characteristic-function limit: at each ξ, the limit of the characteristic-function sequence.

    • characteristicConvergence (ξ : R) : Filter.Tendsto (fun (n : ℕ) => characteristicSequence n ξ) Filter.atTop (nhds (characteristicLimitValue ξ))

      Characteristic-function convergence: pointwise in ξ.
