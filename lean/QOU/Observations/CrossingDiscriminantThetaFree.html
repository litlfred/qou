    noncomputable def QOU.Observations.CrossingDiscriminantThetaFree.crossingDisc (a b : ℝ) :
    ℝ

    The discriminant the block forms, as a function of the two moduli. This is the whole point: it is a function of ‖·‖ alone, so it is blind to every phase by construction.

      theorem QOU.Observations.CrossingDiscriminantThetaFree.crossingDisc_self (a : ℝ) :
      crossingDisc a a = 0

      Item 1's reading, carried to its conclusion. conj:complex-chirality- rotation item 1 says the mirror multiplies S_c by e^{-i n_c θ} where the particle carries e^{+i n_c θ}. A phase has modulus one, so the two moduli coincide and the discriminant is identically zero — to all orders, not to first. The block's own item 1 therefore contradicts its own O(θ²).

      theorem QOU.Observations.CrossingDiscriminantThetaFree.crossingDisc_norm_theta_free {n r : ℝ} (hn : 0 < n) (hr : 0 < r) (θ : ℝ) :
      crossingDisc ‖↑n * (↑r * Complex.exp (↑θ * Complex.I))‖ ‖-↑n / (↑r * Complex.exp (↑θ * Complex.I))‖ = (r ^ 2 - 1) / (r ^ 2 + 1)

      The θ-free statement, with the phase present and explicit. Write the particle's crossing energy as n·q and the mirror's as −n/q with q = r·e^{iθ} — which is def:crossing-energy on an all-positive braid together with prop:antiparticle-crossing-reversal item 2. Then the discriminant of their norms equals (r² − 1)/(r² + 1) for every θ.

      θ is bound on the left and absent on the right: that is the refutation of the O(θ²) claim, and it is not an approximation.

      theorem QOU.Observations.CrossingDiscriminantThetaFree.crossingDisc_pos_of_one_lt {r : ℝ} (hr : 1 < r) :
      0 < (r ^ 2 - 1) / (r ^ 2 + 1)

      For a substrate with |q| > 1 the discriminant is strictly positive — so the q ↔ q⁻¹ asymmetry the mirror introduces is not merely nonzero at some orders, it never vanishes. This is the direction that does work: no choice of phase can make the two crossing energies agree in magnitude.
