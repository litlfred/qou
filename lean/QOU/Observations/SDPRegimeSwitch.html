    QOU.Observations.SDPRegimeSwitch — SDP dual block is positive semidefinite #

    Proposition (prop:sdp-regime-switch).

    The SDP extension of the LP-dual operator-selection framework introduces matrix-valued cross-block couplings c_{λλ'} between conjugate-partition pairs in the Wedderburn decomposition of H_n(q). The SDP dual carries a 2×2 PSD block per conjugate pair (λ, λ'):

      ⎛ μ_λ − y₀ − y_λ        c_{λλ'}      ⎞
  ⎝ c_{λλ'}          μ_{λ'} − y₀ − y_{λ'} ⎠  ⪰  0

    Disposition (derived, not projected) #

    The previous encoding carried a holds-style restatement: the class fields diag_nonneg / det_cond already are the scalar Sylvester conditions, and the "theorem" merely re-emitted them. Here those two conditions are the genuine dual-feasibility inputs (the SDP solution's slack), and the theorem derives the actual positive-semidefiniteness of the block — its quadratic form is non-negative for every test vector (x₀, x₁):

    (μ_λ − y₀ − y_λ)·x₀² + 2·c_{λλ'}·x₀x₁ + (μ_{λ'} − y₀ − y_{λ'})·x₁² ≥ 0.

    This is Sylvester's criterion for a symmetric 2×2 matrix (d ≥ 0, d' ≥ 0, dd' ≥ c² ⇒ PSD), proved over any linearly ordered commutative ring (§7c: nothing archimedean is used) via the identity d·Q = (d·x₀ + c·x₁)² + (dd' − c²)·x₁² (case d > 0) and the degenerate d = 0 ⇒ c = 0 collapse. The "regime switch" of the manuscript — the isolated (Z, N) values where c_{λλ'} = 0 — is exactly where the block diagonalises; the PSD feasibility derived here holds throughout.

    class QOU.Observations.SDPRegimeSwitchContext (R : Type u_2) [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] :
    Type u_2

    Dual-feasibility data for the SDP regime-switch block. All fields are inputs (the SDP solution and its slack); the block's positive-semidefiniteness is derived in SDPRegimeSwitch.

    • q : R

      The substrate parameter q.

    • Z : ℕ

      Proton number Z.

    • N : ℕ

      Neutron number N.

    • μ : ℕ → R

      Per-partition q-Laplacian eigenvalue μ_λ.

    • y_0 : R

      LP-dual variable y_0.

    • y : ℕ → R

      Per-partition LP-dual variables y_λ.

    • c_couple : ℕ → ℕ → R

      Per-conjugate-pair coupling c_{λλ'}.

    • diag_nonneg (l l' : ℕ) : 0 ≤ μ l - y_0 - y l ∧ 0 ≤ μ l' - y_0 - y l'

      Dual feasibility (diagonal slack ≥ 0): the 2×2 block diagonal entries μ − y₀ − y are non-negative.

    • det_cond (l l' : ℕ) : c_couple l l' ^ 2 ≤ (μ l - y_0 - y l) * (μ l' - y_0 - y l')

      Dual feasibility (determinant slack ≥ 0): the product of diagonals dominates the squared coupling.

      SDP dual block is positive semidefinite ([prop:sdp-regime-switch]).

      For every conjugate pair (l, l') the 2×2 dual block is PSD: its quadratic form is non-negative for every test vector (x₀, x₁),

      d·x₀² + 2c·x₀x₁ + d'·x₁² ≥ 0, d := μ_l − y₀ − y_l, etc.

      Derived (Sylvester) from the dual-feasibility inputs diag_nonneg (d, d' ≥ 0) and det_cond (c² ≤ dd') — the genuine semidefiniteness of the block, not a restatement of the scalar slacks. Proof: for d > 0, d·Q = (d·x₀ + c·x₁)² + (dd' − c²)·x₁² ≥ 0; for d = 0, c² ≤ 0 forces c = 0 and Q = d'·x₁² ≥ 0.
