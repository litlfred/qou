    QOU.Observations.AlgebraicGnsEmbedding #

    The Markov-trace GNS embedding H_∞(q) ↪ L(H), encoded as a typeclass packaging the four ingredients of the construction.

    Unlike MuArchContinuumLimit, the GNS construction is not conjectural: it is the Jones–Wenzl subfactor machinery ([jones1985], [wenzl1988]). Under convention D the trace factors through Temperley–Lieb with loop value [2]_q = q + q⁻¹ ≥ 2, so positivity holds for every real q > 0 (Jones), including the QOU substrate q_0 ≈ 1.11. The old "regime q^{1/2} + q^{-1/2} > 2" only excluded q = 1. The per-block weights are proved positive in QOU.SchurWeyl.ocneanuWeight_conventionD_pos_of_two_rows.

    The class fields are the data of the construction (positive tracial state on the inductive system, trace ideal, Hilbert-space completion, faithful representation). Provided an instance, the embedding π_GNS : H_∞(q) → L(H) is exhibited.

    References #

    • [jones1985] V. F. R. Jones, A polynomial invariant for knots via von Neumann algebras, Bull. AMS 12 (1985) 103-111.
    • [wenzl1988] H. Wenzl, Hecke algebras of type A_n and subfactors, Invent. Math. 92 (1988) 349-383.

    Type (max u v)

    Markov-trace GNS embedding data.

    A class witnessing the Jones–Wenzl GNS embedding of the inductive limit Hecke algebra H_∞(q) into bounded operators on a Hilbert space. Each field carries concrete content; no True placeholders.

    The carrier A represents H_∞(q), the carrier H represents the GNS Hilbert space, and repr is the faithful representation.

    • trM : A → ℝ

      The (real-valued) Markov trace.

    • trM_add (x y : A) : trM H (x + y) = trM H x + trM H y

      Linearity of trM.

    • trM_cyclic (x y : A) : trM H (x * y) = trM H (y * x)

      Traciality (cyclicity): tr_M(x · y) = tr_M(y · x).

    • trM_pos (x : A) : 0 ≤ trM H (star x * x)

      Positivity (every real q > 0 under convention D): tr_M(x* x) ≥ 0.

    • traceIdeal : A → Prop

      Faithfulness on the GNS quotient: tr_M(x* x) = 0 → x ∈ trace ideal. Encoded via an explicit ideal predicate.

    • trM_faithful (x : A) : trM H (star x * x) = 0 ↔ traceIdeal H x
    • repr : A → H → H

      The GNS representation as a function A → (H → H) (left multiplication on the GNS quotient, extended to H by continuity).

    • repr_add (x y : A) (h : H) : repr (x + y) h = repr x h + repr y h

      Linearity of repr in its first argument (so repr (x + y) = repr x + repr y pointwise).

    • repr_mul (x y : A) (h : H) : repr (x * y) h = repr x (repr y h)

      Multiplicativity of repr (a *-homomorphism on the algebra-action side).

    • repr_faithful (x : A) : (∀ (h : H), repr x h = 0) → traceIdeal H x

      Faithfulness of repr: zero representation only for ideal elements.
