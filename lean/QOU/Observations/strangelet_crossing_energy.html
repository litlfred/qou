    Base ring (§7c) — ℝ here is correct #

    StrangeletCrossingEnergyContext inherits a generic coefficient ring R from QOU.Shared.MarkovTraceContext, but this block's fields stay at ℝ: the binding-energy formulae are hypothesised under 0 < q_real, and the conclusion E_bind_udd < E_bind_uds is derived by inv_pos + linarith. Ordering hypotheses and linarith are archimedean, so the block sits after the substrate→archimedean wall. Reviewed under bean qou-mtcx; do not "port" it to R to reduce an ℝ count.

    q_real is genuinely used and is now tied to the inherited q : R (bean qou-mt7r): the class extends QOU.Shared.ArchimedeanEval, which carries an assumed evaluation eval : R →+* ℝ and derives q_real := eval q. It used to be an independent field, so 0 < q_real constrained a free real rather than the image of this universe's substrate parameter. The evaluation is assumed, not constructed: it is not the archimedean τ-functor, and ArchimedeanEval.ofRingHom machine-checks how little it takes to inhabit.
