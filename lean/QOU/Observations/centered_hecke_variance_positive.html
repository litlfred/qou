    QOU.Observations.centered_hecke_variance_positive #

    Canonical declaration for content block prop:centered-hecke-variance-positive: the centred Hecke generator has strictly positive variance.

    Base ring (§7c) #

    Under convention D (z = q³/(q²+1), owner ruling 2026-08-09) the Markov parameter is a rational function of q: no radical is taken anywhere in this file, so every statement below is ordered-field algebra and the scalars are a generic R with [Field R] [LinearOrder R] [IsStrictOrderedRing R]. The substrate evaluation Var(σ_i) ≈ 0.75270211325196540159 at q₀ ≈ 1.10998 is the instantiation R := ℝ and lives on the archimedean side of the wall.

    Convention-D rewrite (2026-08-29) #

    This module previously stated the block's convention-C form z = 1/(q^{1/2} + q^{-1/2}) and quoted Var ≈ 0.855 at q₀ — a figure the .md explicitly withdrew on 2026-08-09 when the block was corrected to convention D. The module is not imported by QOU.lean, so it was never compiled and the drift was never surfaced.

    The rewrite is also a strengthening, and the reason is worth recording. The old encoding was §3b-conditional: it carried

    term1_pos : 0 < (q - q⁻¹) * z
term2_pos : 0 < 1 - z ^ 2

    as context-class axioms and obtained positivity by linarith from them. Under convention D those two hypotheses are not jointly satisfiable on the domain the .md claims. term1_pos forces q > 1; term2_pos is z < 1, i.e. q³ < q² + 1, forcing q < ψ where ψ = 1.465571231876768… is the supergolden ratio. So the class was inhabited only on q ∈ (1, ψ) — a fact stated nowhere — while the .md claims positivity for every q > 0. The substrate q₀ ≈ 1.10998 sits inside that window, which is why the restriction went unnoticed.

    Worse for the block's two headline claims: q = 1 is excluded (there q - q⁻¹ = 0, so term1_pos fails), and q = 1 is exactly where the .md now says the minimum 3/4 is attained. The old encoding could not express the strengthening its own .md had just made.

    Splitting Var into two separately-positive pieces is therefore the wrong decomposition under D. The closed form (q⁴ + q² + 1)/(q² + 1)² is a ratio of manifestly positive polynomials, so positivity needs no hypothesis beyond q ≠ 0, and the minimum falls out of the exact identity Var - 3/4 = (q² - 1)²/(4(q² + 1)²). Everything below is unconditional and sorry-free; there is no context class and no axiom.
