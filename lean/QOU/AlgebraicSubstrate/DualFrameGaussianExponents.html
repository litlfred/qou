    theorem QOU.AlgebraicSubstrate.DualFrameGaussianExponents.lattice_gaussian_complete_square {K : Type u_1} [Field K] (L uln j : K) (hL : L ≠ 0) (h2 : 2 ≠ 0) :
    -(uln + j * L - -(L / 2)) ^ 2 / (2 * L) = -(L * (j * (j + 1))) / 2 - j * uln + -(uln + L / 2) ^ 2 / (2 * L)

    M1 — lattice-Gaussian completion of the square. The Gaussian exponent at the lattice point t_j = uln + j·L, with center μ̂ = −L/2 and variance σ² = L, equals the atomic B-factor mass exponent −L·j(j+1)/2 − j·uln plus the j-independent translate constant −(uln + L/2)²/(2L). This is the exact statement that the whole u-translate atomic continuum samples ONE Gaussian — the a.c. log-normal member.

    theorem QOU.AlgebraicSubstrate.DualFrameGaussianExponents.dual_mode_moment_shift {K : Type u_1} [Field K] (L k d : K) (h2 : 2 ≠ 0) :
    (k + d) * -(L / 2) + (k + d) ^ 2 * L / 2 = L * (k * (k - 1)) / 2 + (d * -(L / 2) + d ^ 2 * L / 2) + k * (d * L)

    M2 — dual-mode moment shift. For the complex shift z = k + d (d the dual-mode shift, d·L = 2πi m in the wall-side reading), the Gaussian exponential-moment exponent with μ̂ = −L/2, σ² = L splits exactly into (i) the mode-independent moment ladder L·k(k−1)/2, (ii) the k-independent mode mass d·μ̂ + d²L/2, and (iii) the cross term k·(d·L) — an integer multiple of 2πi in the wall-side reading, invisible to the exponential. The algebraic mechanism is variance = lattice step.
