    Metallic-ratio hierarchy of the Hecke scalar #

    The Iwahori–Hecke generator satisfies σ² = (q − q⁻¹)·σ + 1, so the structural scalar of the braiding is q − q⁻¹. This file proves the owner's assertion (2026-06-08): the real values q > 0 at which this scalar is a non-negative integer n are exactly the metallic ratios δ_n = (n + √(n²+4))/2 — golden (n = 1), silver (n = 2), bronze (n = 3), … (n = 0 gives the trivial δ_0 = 1, i.e. q = 1) — and the bar involution q ↦ q⁻¹ sends δ_n to δ_n − n = 1/δ_n.

    Ref: docs/audits/2026-06-08-q-regime-map-coordination.md §3b and docs/audits/2026-06-08-metallic-q-hierarchy-proof.md (rigorous hand proof).

    Machine-verified 2026-06-08 (lean v4.24.0): clean compile, and #print axioms on every theorem here = [propext, Classical.choice, Quot.sound] (the standard Mathlib axioms — no sorryAx).

      theorem QOU.AlgebraicSubstrate.metallic_two_q (n : ℕ) :
      metallic n + (metallic n)⁻¹ = √(↑n ^ 2 + 4)

      Quantum dimension at a metallic ratio. The Temperley–Lieb loop / quantum dimension [2]_q = q + q⁻¹ evaluates to √(n²+4) at q = δ_n (golden → √5, silver → √8 = 2√2). On the unit circle this scalar is 2cos θ ∈ [−2,2]; here on the real-metallic ladder it is √(n²+4) ≥ 2, so only n = 0 (δ_0 = 1, value 2) meets the root-of-unity range — the algebraic reason golden is the unique metallic ratio that is also a root-of-unity quantum dimension (φ = 2cos(π/5)).
