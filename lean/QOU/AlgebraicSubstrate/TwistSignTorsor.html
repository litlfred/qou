      Type (max u_3 u_4)

      A twist sign: the monoidal character by which two ribbon structures over one braiding differ.

      Modelling it as a homomorphism is the whole content. The ribbon axiom θ (V ⊗ W) = (θ V ⊗ θ W) ∘ c ∘ c forces ε (V ⊗ W) = ε V * ε W, so a sign assignment that is not multiplicative does not define a twist at all.
