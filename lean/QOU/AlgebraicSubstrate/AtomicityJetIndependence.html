    The abstract jet-compatibility shape #

    source
    structure QOU.AlgebraicSubstrate.SubstrateClock.JetCompatibleOrder (M : Type u_1) [AddCommMonoid M] :
    Type u_1

    Abstract extraction of the prop:ordering-jet-compatibility axiom set for an additive computation monoid M — the strongest structural reading under which the jet-tower ordering could bear on PlanckStepAtomicity at all:

    • lt — the braiding-induced ordering (one GLOBAL relation, exactly as the block Lean's degLex; per-level orderings are its restrictions, which is why the block's axiom ordering_extends is tautological there and the extension leg is the derived ltAt_extends here);
    • level — the jet filtration A₀ ⊆ A₁ ⊆ …: an increasing exhaustive tower of submonoids (zero_mem/add_mem = subalgebra closure, level_mono = the prolongation embeddings ℓ_n, level_exhausts = the direct-limit leg);
    • compat — leg 2, translation invariance (ordering_compatible);
    • wf — leg 3, well-foundedness (wellfounded_at_level, globally).

    This is a structure, not a class: an ordering is a CHOICE of data, and a monoid may carry several.

    • lt : M → M → Prop

      The braiding-induced ordering (global; levels restrict it).

    • level : ℕ → M → Prop

      The jet filtration: membership in the level-n subalgebra.

    • zero_mem (n : ℕ) : self.level n 0

      Each level contains the empty computation.

    • add_mem (n : ℕ) (a b : M) : self.level n a → self.level n b → self.level n (a + b)

      Each level is closed under composition (subalgebra closure).

    • level_mono {m n : ℕ} : m ≤ n → ∀ (a : M), self.level m a → self.level n a

      The tower is increasing: the prolongation ℓ_n embeds level m into every later level.

    • level_exhausts (a : M) : ∃ (n : ℕ), self.level n a

      Direct-limit leg: every element lives at some finite level.

    • compat (a b c d : M) : self.lt a b → self.lt (c + a + d) (c + b + d)

      Leg 2 (ordering_compatible): two-sided translation invariance.

    • wf : WellFounded self.lt

      Leg 3 (wellfounded_at_level, globally): no infinite descent.

        The rank-2 model: ℕ × ℕ with degree-lexicographic order #

        def QOU.AlgebraicSubstrate.SubstrateClock.degLexPair (a b : ℕ × ℕ) :
        Prop

        Degree-lexicographic order on the rank-two step monoid ℕ × ℕ — the exact analogue of the block's degLex (length first, then lex): compare total degree first, then the second ("jet-direction") coordinate. At fixed degree the pair is determined by its second coordinate, so this IS the full lex tie-break. Note the new generator (0,1) is ordered AFTER the old one (1,0), exactly as the jet prolongation orders new Ω¹ directions after all old generators.

              The independence theorems #

              source
              theorem QOU.AlgebraicSubstrate.SubstrateClock.planckStepAtomicity_not_forced_by_jet_order :
              ¬∀ (M : Type) [inst : AddCommMonoid M] (a : JetCompatibleOrder M), ∃ (g : M), (∀ (a : M), ∃ (n : ℕ), a = n • g) ∧ ∀ (n m : ℕ), n • g = m • g → n = m

              Route 1 closes negative (proved, sorry-free, unconditional). The jet-compatibility axiom set does NOT force atomicity: it is refutable to claim that every additive monoid carrying a jet-compatible order is atomic. Witness: rankTwoJetOrder on ℕ × ℕ satisfies every leg, yet ℕ × ℕ has no single generating step (atomicity_fails_for_two_generators). Consequently there is no theorem JetCompatibleOrder M → PlanckStepAtomicity M, and prop:ordering-jet-compatibility's order structure cannot upgrade PlanckStepAtomicity from premise to theorem.

              Full independence (proved, sorry-free, unconditional). The jet-compatibility axiom set neither proves nor refutes atomicity: ℕ × ℕ carries a jet-compatible order and is not atomic (planckStepAtomicity_not_forced_by_jet_order), while ℕ carries a jet-compatible order and is atomic (rankOneJetOrder, nat_is_atomic). Atomicity is genuinely NEW content beyond the jet-tower ordering structure — which is exactly the situation the §3b-tax primary-conjecture-class representation of PlanckStepAtomicity is designed for.

              ∃ (J : JetCompatibleOrder (ℕ × ℕ)), (∀ (a b : ℕ × ℕ), J.lt a b ∨ a = b ∨ J.lt b a) ∧ (∃ (g₀ : ℕ × ℕ), g₀ ≠ 0 ∧ (∀ (a : ℕ × ℕ), a ≠ 0 → a = g₀ ∨ J.lt g₀ a) ∧ ∀ (a : ℕ × ℕ), ∃ (n : ℕ), J.lt a (n • g₀)) ∧ ¬∃ (g : ℕ × ℕ), ∀ (a : ℕ × ℕ), ∃ (n : ℕ), a = n • g

              The strengthened axiom set is STILL insufficient (proved, sorry-free, unconditional). One and the same rank-2 model satisfies the full jet-compatibility axiom set PLUS totality PLUS the existence of a least nonzero step PLUS cofinality of that step's iterates — and is still not atomic. So no order-theoretic strengthening of prop:ordering-jet-compatibility along these natural axes can close route 1: what atomicity adds is precisely the generates clause (every segment IS an iterate of the step, not merely comparable to iterates), and any jet-tower formalization strong enough to imply it would have to carry that clause as an assumption — i.e. assume the conclusion.
