    QOU.AlgebraicSubstrate.DominationSqueeze — the squeeze as an algebraic object #

    The move. Every surreal bound in appendix-surreals — RH, BSD, q-Collatz, P-vs-NP, q-NS blowup — runs one shared step: put a cost and a budget at different ordω grades and read off cost > budget. That step is stated in an ordered field (ℝ(ε) ⊂ No), which is exactly why QOU.Archimedean.SurrealGradingPrune can prove it blind to anything happening inside ℝ.

    This file replaces it with its algebraic content. The step is not an order fact. It is the strict-triangle equality of a valuation:

    if val a < val b then val (a + b) = val a — a strictly dominant term survives, and the sub-dominant one cannot cancel it.

    Everything the squeeze is used for follows from that, and it needs no ordered field, no ℝ, no surreals, no transfer principle — only an abelian group with a filtration. So the argument moves to the substrate side of the archimedean wall, where the framework's GB / jet filtration already lives.

    What this buys #

    Ordered-field form Algebraic form
    ordω(A) > ordω(B) ⟹ A > B val A < val B ⟹ val (A + B) = val A
    needs an ordered field needs an abelian group + filtration
    lives past the substrate wall lives on the substrate side
    blind on ℝ (SurrealGradingPrune) informative on any graded object
    lem:surreal-squeeze's Lean is a tautology add_ne_zero_of_val_lt is a theorem

    Sign convention. val is a valuation: smaller means more dominant (order of vanishing), with val 0 = ⊤. The corpus's ordω runs the other way (ordω(ε⁻¹) = 1 > −3 = ordω(ε³)), so ordω = −val. A squeeze written ordω(cost) > ordω(budget) reads here as val cost < val budget.

    Where it instantiates #

    • jetDomination below — the jet / GB filtration on coefficient sequences, i.e. order of vanishing at q = 1. This is the grading QOU.Archimedean.TowerHeightAttack §3 requires and the bare VolumeTowerDecomposition (a plain HasSum) does not supply.
    • Any ℕ-filtered ring, via val x = sup {n | x ∈ Fⁿ}.
    • The Ohtsuki tower 𝔙_b = 𝔙₀ + Σ κₙ (2πb²)ⁿ — val = leading ℏ-order.

    Scope #

    This makes the inference step of the surreal bounds rigorous and reusable. It establishes none of their premises — the Reeb-period budget accounting, the non-compressibility conjecture, the std-of-the-skein assumption are untouched, and no millennium bound becomes a proof of anything because of this file.

    Type (max u_3 u_4)

    Domination structure — a filtration / valuation on an abelian group, carrying exactly the data the squeeze arguments use and nothing else.

    val a is the grade / filtration depth / order of vanishing of a, with ⊤ for 0. The only axiom is the ultrametric bound; strict domination is derived (val_add_eq_of_lt), not assumed.

    • val : A → WithTop Γ

      Grade / filtration depth. Smaller = more dominant.

    • val_zero : self.val 0 = ⊤

      Zero is infinitely deep.

    • val_neg (a : A) : self.val (-a) = self.val a

      Negation preserves depth.

    • le_val_add (a b : A) : min (self.val a) (self.val b) ≤ self.val (a + b)

      Ultrametric bound: a sum is at least as deep as its shallowest summand.

          §3 Bridge back to the ordered-field form #

          The algebraic core implies the ordered-field squeeze whenever the domination is order-compatible, so nothing is lost by working algebraically. And SurrealGradingPrune says the converse direction is where the information was never there: on ℝ the grading is constant, so the ordered-field form has no premise to fire on. Together: use the algebraic form; the ordered-field form is the special case that happens to be blind.

          Order-compatibility: a strictly dominant term is strictly larger. This is the extra hypothesis the ordered-field reading needs, and the one that has no content on ℝ.

          • lt_of_val_lt {a b : A} : 0 < a → 0 < b → self.val a < self.val b → b < a

            Strictly dominant (smaller val) and positive ⟹ strictly larger.
