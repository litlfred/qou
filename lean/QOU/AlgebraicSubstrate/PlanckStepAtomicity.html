    class QOU.AlgebraicSubstrate.SubstrateClock.PlanckStepAtomicity (M : Type u_3) [AddCommMonoid M] :
    Prop

    Primary conjecture (open — NO instance; §3b-tax). ATOMICITY of the substrate's computation monoid — the formal content of rem:discrete-planck-step's "there is no sub-step resolution": there is a single step g (one full Reeb circuit, the Planck step) such that

    • every computation segment is an iterate n • g of it (generates — nothing exists between the iterates, no sub-step), and
    • distinct iterate counts give distinct segments (free — "the count of Planck steps measures dynamical distance": counting is well defined).

    Equivalently n ↦ n • g is an additive bijection ℕ ≃ M (stepIterate_bijective): the computation monoid is a copy of ℕ generated by one indivisible step (indivisibility is DERIVED: atomic_generator_indivisible). This is a genuine structural restriction — FALSE for the rank-two step monoid ℕ × ℕ (atomicity_fails_for_two_generators). The corpus's ℕ-valued InformationTheoreticTime.stepCount is a chart reading OF this conjecture (a modeling choice), not a proof of it; an instance may only be created from a genuine derivation of the computation order's rank-one/ℕ-shape (open).

    • atomic : ∃ (g : M), (∀ (a : M), ∃ (n : ℕ), a = n • g) ∧ ∀ (n m : ℕ), n • g = m • g → n = m

      There is one Planck step generating every computation segment, with pairwise-distinct iterates: no sub-step resolution, well-defined step count.
