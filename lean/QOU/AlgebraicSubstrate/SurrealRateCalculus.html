    QOU.AlgebraicSubstrate.SurrealRateCalculus — rate table #

    Records the four classical-limit scaling laws of the QOU framework as surreal-order inequalities:

    • Mass gap Δ_q ≍ ε^3 — positive infinitesimal of order 3.
    • Reeb period Ω_q ≍ ε⁻¹ — positive transfinite of order 1.
    • Enstrophy ceiling Z_q ≍ ε^(-4/3) — transfinite of order 4/3.
    • Rogue-zero cost E(δ) ≍ δ² · ε⁻¹ — transfinite scaled by δ².

    Each is stated as a leading-coefficient equation on an abstract field carrier F; downstream instances discharge by specialising to 𝐍𝐨 via QOU.AppendixSurreals.StandardPart. The class requires only [CommRing F] — no ordering or positivity hypothesis; those are added by downstream interpretations that need them (e.g.\ to compare Ow-orders).

    LaTeX label: prop:surreal-rate-calculus.

    References #

    • [conway1976] Conway, On Numbers and Games.
    • [gonshor1986] Gonshor, Introduction to the Theory of Surreal Numbers. DOI:10.1017/CBO9780511629143.

    class QOU.AlgebraicSubstrate.SurrealRateCalculus (F : Type u) [CommRing F] :
    Type u

    The rate-table shape: a class recording the four classical-limit rates as data over an abstract field carrier F.

    An instance of this class fixes the leading-coefficient equations Δ = ε³, Ω·ε = 1, Z³·ε⁴ = 1, E(δ)·ε = δ² (each up to a positive scalar absorbed into the named quantity) and entails the rate table [prop:surreal-rate-calculus]. Under the surreal embedding ε ↦ 1/ω, these equations specialise to the Ow-valuations Ow(Δ) = -3, Ow(Ω) = 1, Ow(Z) = 4/3, Ow(E(δ)) = 1 whenever δ ≠ 0 (the rogue-zero equation E(δ)·ε = δ² holds for every δ : F; the Ow = 1 interpretation requires δ ≠ 0).

    • epsilon : F

      The Reeb infinitesimal embedded in F. Non-zero (forced by reebPeriod_order : reebPeriod · epsilon = 1 below).

    • massGap : F

      The mass gap.

    • reebPeriod : F

      The Reeb period.

    • enstrophyCeiling : F

      The enstrophy ceiling.

    • roguePartCost : F → F

      Rogue-zero energy cost, parametrised by a standard-real drift.

    • massGap_order : massGap = epsilon ^ 3

      Mass-gap leading-coefficient equation: Δ = ε³.

    • reebPeriod_order : reebPeriod * epsilon = 1

      Reeb-period leading-coefficient equation: Ω · ε = 1.

    • enstrophy_order : enstrophyCeiling ^ 3 * epsilon ^ 4 = 1

      Enstrophy leading-coefficient equation: Z³ · ε⁴ = 1 (the cubic form of Z = ε^(-4/3), avoiding fractional exponents at the type level).

    • rogueZero_order (δ : F) : roguePartCost δ * epsilon = δ ^ 2

      Rogue-zero leading-coefficient equation: E(δ) · ε = δ² for every drift δ.

      def QOU.AlgebraicSubstrate.surrealRateCalculus_classicalLimit (F : Type u) [CommRing F] :
      SurrealRateCalculus F

      Classical-limit model (ε = 1). Every rate quantity is 1, so three of the four rate equations degenerate to 1 = 1:

      • Δ = 1 = 1³
      • Ω · 1 = 1 · 1 = 1
      • Z³ · 1⁴ = 1 · 1 = 1
      • E(δ) · 1 = δ² · 1 = δ² — the only field that still varies with its argument, and only because roguePartCost is defined as fun δ => δ ^ 2.

      This is the "no infinitesimal" baseline: it fixes no rate ratio, because with Δ = Ω = Z = 1 there are no ratios to fix. The substantive content arises when ε is genuinely infinitesimal in 𝐍𝐨 via the standard-part embedding.

      A def, not an instance, since 2026-08-24. The carrier was universally quantified ((F : Type u) [CommRing F]), so typeclass resolution supplied ε = 1 for every commutative ring. surreal_rate_calculus_conditional below is stated over [S : SurrealRateCalculus F] and reads as conditional on the rate table; with this instance in scope the class binder cost a caller nothing and the table it named was the all-ones one.

      Worth stating precisely, because it is not a vacuity claim about that theorem: at ε = 1 its other hypothesis hε_inf (ε^(n+1) below every positive λ) is unsatisfiable in an ordered field, so the theorem cannot actually be applied at this model. The defect is that the model is supplied silently — a reader of the signature could not see which rate data the conclusion was about.

      Callers name it: letI := surrealRateCalculus_classicalLimit F.

        theorem QOU.AlgebraicSubstrate.surreal_rate_calculus_conditional {F : Type u} [Field F] [LinearOrder F] [IsStrictOrderedRing F] [S : SurrealRateCalculus F] (hε_pos : 0 < SurrealRateCalculus.epsilon) (hε_inf : ∀ (n : ℕ) (lam : F), 0 < lam → SurrealRateCalculus.epsilon ^ (n + 1) < lam) :
        (0 < SurrealRateCalculus.massGap ∧ 0 < SurrealRateCalculus.reebPeriod) ∧ (∀ (lam : F), 0 < lam → SurrealRateCalculus.massGap < lam) ∧ (∀ (lam : F), 0 < lam → lam < SurrealRateCalculus.reebPeriod) ∧ ∀ (δ : F), 0 < δ → SurrealRateCalculus.massGap < δ ^ 2 * SurrealRateCalculus.reebPeriod

        Surreal rate calculus — the four strict inequalities ([prop:surreal-rate-calculus]).

        Working in an ordered field F carrying the rate data [SurrealRateCalculus F] (so the leading-coefficient equations Δ = ε³, Ω · ε = 1, … hold) and treating ε as a strictly positive infinitesimal — 0 < ε together with hε_inf: every positive power ε^(n+1) lies below every standard real λ > 0 — the four claims of the proposition are derived, not assumed:

        1. Positivity — 0 < Δ and 0 < Ω.
        2. Infinitesimal gap — Δ < λ for every standard real λ > 0.
        3. Transfinite period — λ < Ω for every standard real λ > 0.
        4. Squeeze — Δ < δ² · Ω for every standard real δ > 0 (the mechanism underlying every millennium-problem squeeze: a standard-scale cost δ² · ε⁻¹ strictly exceeds the infinitesimal dissipation ε³).

        The proof is purely order-theoretic — items (1)–(3) follow from the rate equations and the positivity/archimedean-smallness of ε; item (4) reduces, after multiplying by ε > 0, to ε⁴ < δ², which is the n = 3 instance of hε_inf. No cancellation in an ordered field is possible because the cost is transfinite and the dissipation infinitesimal.

        The nine conjecture-cone binders were removed 2026-08-30. They were {α : ℝ} {K ω : ℝ → ℝ} {Sbrk : Set ℝ} together with [QAubinLions K] … [RegularityBreakdown Sbrk], and the paragraph they replaced said plainly what they did: they "record the conditional dependency of the rate table on the q-NS conjecture cone … the inequalities themselves are unconditional given the rate data and the infinitesimality of ε."

        That is an honest description of a dishonest signature. A binder the proof never consumes does not record a dependency — it reads as one to anyone scanning the statement, while discharging nothing. The proof below uses S, hε_pos and hε_inf and nothing else; four of the nine binders existed only to supply parameters to the other five.

        The dependency of the rate table on the cone is a manuscript-level claim (conj:q-aubin-lions, …, conj:regularity-breakdown) and belongs in the .md banner, which states it. What is proved here is what the proof actually uses: the rate equations and the archimedean smallness of ε.
