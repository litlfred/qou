    theorem QOU.AlgebraicSubstrate.isQGeneric_real {q : ℝ} (hq : 1 < q) :
    IsQGeneric ℝ q

    The archimedean instance. Every real q > 1 is q-generic — the substrate anchor q₀ ≈ 1.10998 included.

    ℝ here is not a §7c violation but the point of the exercise: this is the specialisation past the archimedean wall, and it genuinely needs the ordering (cyclotomic_pos' holds because every root of Φ_d lies on the unit circle, so Φ_d cannot vanish to the right of 1).

    It also settles non-vacuity where it matters. The class is not merely inhabitable by some toy ring; it is satisfied at the value the framework actually evaluates at, so a definition stated over IsQGeneric reaches the substrate.
