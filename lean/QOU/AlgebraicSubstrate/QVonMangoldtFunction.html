    structure QOU.AlgebraicSubstrate.QVonMangoldtFunction :
    Type 1

    Data for the q-von Mangoldt function Λ_q.

    A definition carrier: Idx indexes the maximal ideals 𝔪, N 𝔪 is the norm (residue-field cardinality), isFundamentalDefect marks the ideals lying over a prime of the centre, and Lambda_q is pinned by its defining piecewise value — the q-deformation (N 𝔪 ^ ℏ_q − 1)/ℏ_q of log N(𝔪) on defects, 0 otherwise.

    • Idx : Type

      Index type for the maximal ideals 𝔪 of 𝒪_q(𝓑).

    • N : self.Idx → ℝ

      Norm N(𝔪) — the residue-field cardinality.

    • hbar_q : ℝ

      Substrate q-Planck constant ℏ_q.

    • isFundamentalDefect : self.Idx → Prop

      Whether 𝔪 is a fundamental defect (lies over a prime of the centre).

    • decidableDefect : DecidablePred self.isFundamentalDefect

      Decidability of the defect predicate (so the piecewise value is a term).

    • Lambda_q : self.Idx → ℝ

      The q-von Mangoldt function.

    • lambda_def (m : self.Idx) : self.Lambda_q m = if self.isFundamentalDefect m then (self.N m ^ self.hbar_q - 1) / self.hbar_q else 0

      Defining identity: Λ_q(𝔪) = (N 𝔪 ^ ℏ_q − 1)/ℏ_q on defects, else 0.
