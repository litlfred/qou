    q-Collatz Kummer removability via the universal χ(A) obstruction (Tier C, C9) #

    The q-Collatz map's even branch divides by [2]_q; the obstruction to that division being globally removable is the level-2 residue κ_C of the universal χ(A) class (thm:qou-obstruction-reduction, QOU.AlgebraicSubstrate.QouObstructionReductionContext). This file supplies the C9 Lean-link: conditional on the obstruction context, the even-branch [2]_q Kummer obstruction vanishes — the divisor is removable — iff 2 ∣ χ(A), specialising the universal kappa_vanishes_iff_chi to the q-Collatz-relevant level n = 2.

    Honest scope (anti-laundering) #

    This is the Kummer-removability leg only, not the full q-Collatz conjecture. Removability of the [2]_q divisor is necessary for the map to be well-behaved on its even branch, but convergence (reaches_cycle) additionally requires the descent measure μ — the open wall documented in the 2026-07-18 audit. So this file links κ_C = 0 to a divisibility fact about χ(A), and does not claim κ_C = 0 ⟺ [q-Collatz holds].

    χ(A) = −6 is Descartes-universe-specific (Bring's surface Σ₄, genus 4), not a general-QOU fact; the _of_chi_neg_six corollary is therefore stated with χ(A) = −6 as an explicit hypothesis, matching the scoping of the q-Collatz contact-boundary block (prop:collatz-contact-boundary, scoped to "QOU with 2 ∣ χ(A)").
