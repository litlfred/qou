    QOU.AlgebraicSubstrate.SurrealSqueeze — the squeeze lemma #

    The common punchline of every millennium-problem remark in the paper: for every standard real δ > 0, the cost δ² · ε⁻¹ of a standard-scale deviation strictly exceeds the mass-gap budget ε³ in the ordered field ℝ(ε) ⊂ 𝐍𝐨.

    Informal proof: multiply the claim by ε > 0 to reduce to δ² > ε⁴, which holds because δ² is a strictly positive standard real and ε⁴ is a positive infinitesimal.

    Two formalisations are provided:

    1. surreal_squeeze — the surreal-field version with the intended hypotheses (ε infinitesimal in some SurrealField K, δ a positive standard real). Proved using the IsInfinitesimal infrastructure from QOU.AppendixSurreals.Basic.

    2. surreal_squeeze_of_pow_lt — the abstract pure-algebra form over any linearly ordered field, taking the substantive size separation ε^4 < δ^2 directly as a hypothesis. Used internally by surreal_squeeze and available to callers who already control the ε^4 < δ^2 bound by other means.

    LaTeX label: lem:surreal-squeeze.

    References #

    • [conway1976] Conway, On Numbers and Games, §0.
    • [gonshor1986] Gonshor, An Introduction to the Theory of Surreal Numbers. DOI:10.1017/CBO9780511629143.

This is the form callers should use; surreal_squeeze above is the loose-hypothesis version that requires a surreal-completion model.

    theorem QOU.AlgebraicSubstrate.surreal_squeeze {K : Type u} [AppendixSurreals.SurrealField K] (ε : K) (δ : ℝ) (hε : 0 < ε) (hε_inf : AppendixSurreals.SurrealField.IsInfinitesimal ε) (hδ : 0 < δ) :
    AppendixSurreals.SurrealField.ofReal δ ^ 2 * ε⁻¹ > ε ^ 3

    surreal_squeeze: in any SurrealField K, for every strictly positive infinitesimal ε ∈ K and every strictly positive standard real δ, the cost (ofReal δ)² · ε⁻¹ of a standard-scale deviation strictly exceeds the mass-gap budget ε³.

    This is the surreal-coefficient version intended by the paper (lem:surreal-squeeze). The proof reduces — via surreal_squeeze_of_pow_lt — to the size separation ε⁴ < (ofReal δ)², which holds because ε⁴ is infinitesimal (closure of infinitesimals under multiplication by finite elements, applied iteratively) and (ofReal δ)² is a strictly positive standard real.
