    theorem QOU.AlgebraicSubstrate.critical_exponent_enstrophy_unbounded (enstrophy : ℝ → ℝ) (α : ℝ) [h : CriticalExponent enstrophy α] (M : ℝ) :
    ∃ (q : ℝ), 1 < q ∧ M < enstrophy q

    The enstrophy is unbounded near q = 1 — a consequence of the critical-exponent conjecture.

    Three states on one day, and the middle one is the instructive failure.

    1. It concluded (3 * 4 : ℕ) = 12 — true by rfl with or without the hypothesis, so the [CriticalExponent] binder was decorative (qou-93hu).
    2. It concluded 3 * α = 4, from a class field typed α = 4/3. That cleared the shape defect and inherited a worse one from the class: 4/3 is not a result the corpus holds. p2-critical-exponent.md offers it as one of two heuristic values under two named turbulence closures and says the true exponent is open. So this theorem derived an arithmetic identity from a fabricated premise — the derivation was sound and the premise was not (qou-4670).
    3. Now: the class asserts divergence, and what follows from it is unboundedness. M is arbitrary, so this is not satisfiable by any bounded enstrophy, and it uses the hypothesis at ε = 1.

    Note the conclusion drops the neighbourhood. That is deliberate: the localisation is what makes the hypothesis strong, and a consequence is free to be weaker. The 1 < q conjunct is kept so the statement stays in the q-NS regime.

    theorem QOU.AlgebraicSubstrate.qNS_cone_full_composition (α : ℝ) (K ω enstrophy : ℝ → ℝ) (S : Set ℝ) (obstruction : ℕ → ℕ) (smooth : Prop) [QAubinLions K] [NSCounterexample ω] [CriticalExponent enstrophy α] [BlowupYekutieli obstruction smooth] [RegularityBreakdown S] :
    K 0 = 0 ∧ (∀ (M : ℝ), ∃ (t : ℝ), M < ω t) ∧ (∀ (M : ℝ), ∃ (q : ℝ), 1 < q ∧ M < enstrophy q) ∧ (¬smooth ↔ ∃ (n : ℕ), obstruction n ≠ 0) ∧ MeasureTheory.volume S = 0

    Full q-NS-cone composition (all 5 classes).

    Until 2026-08-30 this concluded that "every conjectural existential field admits a witness simultaneously" — five existentials, all witnessed by zero, so the conjunction was provable with none of the hypotheses. Four of the five conjuncts now say something the corresponding class is needed for: a determined zero-energy compactness, an unbounded vorticity, the exponent's value, a null breakdown locus.

    The fourth conjunct WAS the exception and no longer is. On 2026-08-30 that carrier was replaced by the upstream obstruction statement (qou-88nf), so all five conjuncts now need their class. Note the replacement is not a strengthening of the old leg: a blow-up rate and obstruction-class vanishing are different propositions that shared a name.

    The third conjunct read α = 4/3 until 2026-08-30. That was a projection of a class field asserting a value the corpus calls open; both the field and this conjunct are gone (qou-4670). What replaces it is the divergence consequence, which is derived rather than returned.

    theorem QOU.AlgebraicSubstrate.qNS_enstrophy_cube_bound (Z : ℝ) (h_Z : 0 ≤ Z) :
    0 ≤ Z ^ 3

    Enstrophy cube bound: every non-negative enstrophy Z ≥ 0 satisfies Z³ ≥ 0.

    This is UNCONDITIONAL and used to pretend otherwise. It carried all five q-NS class hypotheses while its proof is pow_nonneg h_Z 3, which uses none of them — 0 ≤ Z ^ 3 follows from 0 ≤ Z alone. I flagged that in a note here and left the binders; a reviewer then flagged the same thing on PR #6122, observing that it makes dependency tracking noisy and reads later as a genuine conditional consequence. Two independent reads agreeing is enough: the binders are gone.

    Verified safe to drop: these corollaries have no external callers, so removing hypotheses breaks nothing.
