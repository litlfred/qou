    QOU.AlgebraicSubstrate.qou_obstruction_reduction #

    Canonical declaration for content block thm:qou-obstruction-reduction.

    The lean.ref URI qou:QOU.AlgebraicSubstrate.qou_obstruction_reduction resolves to this declaration in the qou Lake package.

    §3b-cond conditional class (honest). The class QouObstructionReductionContext carries the two genuine mathematical inputs of the obstruction reduction as hypothesis fields —

    • vdb_duality : Van den Bergh / Calabi–Yau duality of dimension 3 for U_q(su₂), HH^i(U_q,Ad) ≅ HH_{3-i}(U_q,Ad) (equal dimensions);
    • drinfeld_rigidity : Drinfeld rigidity of the quasi-triangular deformation, dim HH_1(U_q,Ad) = 1;

    — together with the raw dimension data, χ(A), the primitive Kummer obstruction integer κ₀, and the definitional Kummer-vanishing field. Conclusion (a), dim HH²(U_q,Ad) = 1, is derived below by composing the two inputs (HH² ≅ HH_{3-2} = HH_1 = 1); it is NOT a class field. The χ(A)-identification of the generator (conclusions (b),(c)) rests on the single honest domain gap obstruction_trace_gap (the explicit Euler/trace pairing).

    That gap is carried as class hypotheses, NOT as a sorry (corrected 2026-08-25). This paragraph read "left as sorry" and was contradicted by the file it describes: there is no sorry token anywhere here, and obstruction_trace_gap is proved from the hattori_stallings, trace_pairing_cast and chern_character fields — as the docstring on kappa_vanishes_iff_chi below has said all along. The domain gap is real; what was wrong is where it lives. Recorded rather than silently deleted because the stale wording is the kind a sorry audit reads as a hit and a human reader reads as an open item, so it manufactures a false gap in both directions at once.

    class QOU.AlgebraicSubstrate.QouObstructionReductionContext :
    Type

    §3b-cond context for thm:qou-obstruction-reduction.

    Fields are the genuine hypotheses / data of the reduction — the downstream conclusion dim HH² = 1 is derived from them, never carried as a field.

    • hhCohDim : ℕ → ℕ

      dim_k HH^i(U_q, Ad), the Hochschild cohomology dimensions.

    • hhHomDim : ℕ → ℕ

      dim_k HH_i(U_q, Ad), the Hochschild homology dimensions.

    • vdb_duality (i : ℕ) : i ≤ 3 → hhCohDim i = hhHomDim (3 - i)

      INPUT — Van den Bergh / Calabi–Yau duality of dimension 3 for U_q(su₂): HH^i(U_q,Ad) ≅ HH_{3-i}(U_q,Ad), hence equal dimension. (A literature theorem; the class instance is the §3b-cond conditional hypothesis.)

    • drinfeld_rigidity : hhHomDim 1 = 1

      INPUT — Drinfeld rigidity of the quasi-triangular deformation: the degree-1 Hochschild homology (the deformation module) is one-dimensional.

    • chi_A : ℤ

      Euler characteristic χ(A).

    • phi_1_image : ℝ

      Trace image of the HH² generator (observation-frame value).

    • kappa0 : ℤ

      The primitive Kummer obstruction integer κ₀ (distinct datum; its equality with χ(A) is the residual gap, not assumed here).

    • kappa_vanishes : ℕ → Prop

      Kummer level-n vanishing predicate κ₀ ≡ 0 (mod n).

    • kappa_vanishes_def (n : ℕ) : kappa_vanishes n ↔ ↑n ∣ kappa0

      DEFINITIONAL — Kummer level-n vanishing is n ∣ κ₀ (definition of the predicate, in terms of κ₀, NOT χ(A)).

    • trace_pairing : ℤ → ℝ

      Structural trace evaluation map from algebraic K-theory K₀(A) to Hochschild homology HH₀(A)

    • hattori_stallings : trace_pairing chi_A = ↑kappa0

      Hattori-Stallings trace property relating the primitive Kummer obstruction κ₀ to the Euler characteristic χ(A)

    • trace_pairing_cast (z : ℤ) : trace_pairing z = ↑z

      The trace pairing on Z acts as casting to Reals

    • chern_character : phi_1_image = trace_pairing chi_A

      Chern character map property identifying the trace image of the HH² generator with χ(A) via trace pairing

      The universal obstruction class χ(A) ∈ HH²(U_q, Ad) ≅ ℤ, under the name its consumers use.

      A pure accessor for the existing chi_A field — it introduces no new datum and no new hypothesis. SkeinResolutionObstruction is documented as being "cross-wired to the same QouObstructionReductionContext … via obstruction_class_eq", i.e. deliberately reading the one canonical class rather than carrying a free field of its own; that wiring just had no name on this side. Adding it here keeps the single-source-of-truth property the de-axiomatisation (bean 7kzn) was for.

        QouObstructionReductionContext.kappa0 = QouObstructionReductionContext.chi_A ∧ QouObstructionReductionContext.phi_1_image = ↑QouObstructionReductionContext.chi_A

        Residual cohomology gap. The Euler/trace pairing on the generator of the one-dimensional HH²(U_q, Ad) evaluates to χ(A), so κ₀ = χ(A) and the trace image is χ(A). This is the explicit Connes / Hattori–Stallings pairing computation — the disjoint tensor decomposition of the adjoint bimodule together with the commutation of the Markov trace with the coproduct — which is NOT derivable from the two structural inputs (vdb_duality, drinfeld_rigidity) and is left as the honest domain gap.

        theorem QOU.AlgebraicSubstrate.qou_obstruction_reduction [ctx : QouObstructionReductionContext] :
        QouObstructionReductionContext.hhCohDim 2 = 1 ∧ QouObstructionReductionContext.phi_1_image = ↑QouObstructionReductionContext.chi_A ∧ ∀ (n : ℕ), 1 ≤ n → (QouObstructionReductionContext.kappa_vanishes n ↔ ↑n ∣ QouObstructionReductionContext.chi_A)

        Content statement (from manuscript), §3b-conditional on QouObstructionReductionContext:

        Theorem. Let (𝐂, A, τ) be a quantum observable universe. Then (a) the classical-limit obstruction is one-dimensional dim HH²(U_q,Ad) = 1; (b) its unique class is the trace image of the Euler characteristic; (c) the level-n obstruction vanishes iff n ∣ χ(A).

        Part (a) is derived from the two inputs (Van den Bergh CY-3 duality composed with Drinfeld rigidity). Parts (b),(c) reduce to the single honest trace gap obstruction_trace_gap.
