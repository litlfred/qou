    QOU.AlgebraicSubstrate.MetallicLPIdentities #

    Sorry-free Lean proofs of the closed-form identities surfaced by the metallic-q LP probe series (2026-06-09 session, PR #2047). Builds on the metallic hierarchy theorems in QOU.AlgebraicSubstrate.MetallicHierarchy (proved 2026-06-08, PR #1999).

    Theorems proved (all sorry-free) #

    Silver metallic ratio basics #

    • delta_silver_satisfies_minpoly: δ_silver² − 2·δ_silver − 1 = 0
    • delta_silver_pos, delta_silver_gt_one: 0 < 1 < δ_silver
    • delta_silver_inv: δ_silver⁻¹ = δ_silver − 2 = √2 − 1
    • delta_silver_hecke_scalar: δ_silver − δ_silver⁻¹ = 2

    n=2 LP silver coincidence #

    • silver_lp_coincidence: for q > 0, t_1(q) = t_2(q) ↔ q = δ_silver where t_1(q) = 2(q + q⁻¹), t_2(q) = q² − q⁻² are the n=2 LP Markov-trace cost coefficients on basis {γ, σ_0} of H_2(q).
    • cost_coincidence_iff_hecke_scalar_two: intermediate algebraic step
    • cost_coincidence_unique: the coincidence holds at exactly one q > 0

    Bar involution and metallic-pair relations #

    • delta_silver_inv_eq_bar: 1/δ_silver = δ_silver − 2, i.e. the bar involution sends δ_silver ↦ √2 − 1 ≈ 0.414
    • phi_squared_value: φ² = φ + 1 = (3 + √5)/2
    • q_gold_bar_image: the deconfinement boundary q_gold = 1/φ² maps under bar to φ² ≈ 2.618, between silver and bronze
    • q_gold_def: q_gold = 1/φ² = (3 − √5)/2

    Mahler-height drop characterisation #

    • hecke_scalar_integer_iff_metallic: for q > 0, q − q⁻¹ ∈ ℤ_{≥0} ↔ q = δ_n for some n ∈ ℕ (re-statement of MetallicHierarchy Theorem 1 in terms of integers)

    §3b-cond conditional content #

    • class GaloisPairCharacterSum: χ^λ + χ^{λ'} = dim λ · (q − q⁻¹)
    • class CSCSilverIsCFLTransition: silver IS the CFL transition density
    • class BarMirrorPhi2CFLgCFLTransition: φ² IS the CFL → gCFL boundary

                The Hecke character χ^λ evaluated at a braid generator, as a function of q. Carried as a field rather than referenced: the Hoefsmit-Wenzl character machinery is not in this framework, and that absence is exactly what makes this class conditional.

              • conj {n : ℕ} : n.Partition → n.Partition

              • dim {n : ℕ} : n.Partition → ℕ

                The conjecture: for every q > 0 and every partition λ, χ^λ(σ_i) + χ^{λ'}(σ_i) = dim(λ) · (q − q⁻¹).

                Empirically verified for partitions of n ∈ {3, 4}; a direct consequence of A_λ + A_{λ'} = dim λ, from SYT right-of / below counts being swapped under transpose.

                Was holds : Prop — a field typed with the UNIVERSE Prop, so the instance supplied the proposition and ⟨True⟩ inhabited the class. Encoded 2026-09-07 per §3b-tax: an unproved primary is a content-bearing class with no instance.

                    SDP degeneracy at cost-coincidence points #

                    When cost coefficients coincide (t_i(q) = t_j(q) at some q), the LP/SDP becomes degenerate: strict complementarity FAILS, and the optimal face has positive dimension instead of being a vertex. This is what an "undetermined SDP" looks like algorithmically.

                    For the n=2 LP at q = δ_silver: t_1(δ_silver) = t_2(δ_silver) (by silver_lp_coincidence) ⇒ both x_1 and x_2 are optimal with the same cost ⇒ active set is degenerate (neither row strictly active) ⇒ Slater's strict complementarity condition FAILS

                    The empirical n=2 LP active-set sweep observed exactly this: AT δ_silver the active set was empty (neither Frobenius row tight); on either side the active set was a single row. This IS the SDP-degeneracy signature.

                    source
                    theorem QOU.AlgebraicSubstrate.MetallicLPIdentities.n2_lp_degenerate_at_silver (n_target : ℝ) :
                    have x_a := (n_target, 0); have x_b := (0, n_target); t1_n2 delta_silver * x_a.1 + t2_n2 delta_silver * x_a.2 = t1_n2 delta_silver * x_b.1 + t2_n2 delta_silver * x_b.2

                    Helper: the n=2 LP is degenerate at q = δ_silver.

                    Stated as: any feasible x with x_1 + x_2 = n_target achieves the same cost. In SDP language, the optimal face has dimension ≥ 1 instead of being a vertex.
