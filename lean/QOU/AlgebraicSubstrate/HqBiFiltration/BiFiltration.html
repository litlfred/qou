    QOU.AlgebraicSubstrate.HqBiFiltration.BiFiltration #

    Canonical declaration for content block at quantum-observable-universe/mass-theory/hq-bi-filtration.ts.

    Formalises the manuscript definition of the knot-indexed bi-filtration: for a depth filtration G^(0) ⊆ G^(1) ⊆ ⋯ on the substrate convolution algebra and a central primitive idempotent e = e_{λ_K}, the knot-K-localised depth-n stratum is H_q^{(n,K)} = { α ∈ G^(n) : e·α·e = α }. Pure algebra over a generic ring (§7c-clean).

    Type u_1

    Data for the bi-filtration on a ring A.

    A definition carrier: the idempotent e = e_{λ_K} (e² = e), and the depth filtration G : ℕ → Set A (monotone, the horizontal Goncharov axis).

    • e : A

      The central primitive idempotent e_{λ_K}.

    • e_idem : self.e * self.e = self.e

      e is idempotent.

    • G : ℕ → Set A

      The iterated-integral depth filtration G^(n).

    • G_mono (n : ℕ) : self.G n ⊆ self.G (n + 1)

      The filtration is monotone: G^(n) ⊆ G^(n+1).
