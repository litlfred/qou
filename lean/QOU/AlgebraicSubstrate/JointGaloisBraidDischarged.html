    Joint Galois × braid action — general discharge (conditional class form) #

    Compiled formalisation of prop:joint-galois-braid-discharged. Sibling narrative at stochastic-mechanics/joint-galois-braid-discharged.md.

    The manuscript argues the joint motivic-Galois × braid action commutes on every bi-filtration cell structurally: "the two actions touch disjoint factors of the bi-filtration's underlying tensor structure."

    This file encodes that argument honestly (§3b-cond). The genuine hypothesis — the disjoint tensor decomposition Cell ≅ A ⊗ B on which the Galois action moves only the A factor and the braid action moves only the B factor — is carried as the fields of a content-bearing class. Commutation is then derived, not assumed, from those hypotheses by the bifunctorial interchange law (galoisA ⊗ id and id ⊗ braidB act on disjoint coordinates).

    The genuinely-unwritten domain math — that the concrete 𝓗_q^{(n,K)} with its actual motivic-Galois and braid actions realises this disjoint split — is the instance for the concrete cell, which is left unbuilt (open primary, §3b-tax): the general theorem below is fully verified modulo that single named categorical input.

    class QOU.AlgebraicSubstrate.JointGaloisBraidDischarged.JointGaloisBraidDecomposition :
    Type 1

    Conditional-class hypotheses for prop:joint-galois-braid-discharged.

    Encodes the manuscript's structural input (not its conclusion): the bi-filtration cell splits as a disjoint tensor product Cell ≅ A ⊗ B (here modeled at the underlying-set level as an injection decomp : Cell → A × B), the motivic-Galois action moves only the A factor (galois = galoisA ⊗ id), and the braid action moves only the B factor (braid = id ⊗ braidB).

    The fields are genuine hypotheses — the disjoint-factor intertwining equations — from which commutation is derived in joint_action_discharged, never assumed. In particular there is no field asserting "galois commutes with every function"; that would be the conclusion in disguise.

    • Cell : Type

      The bi-filtration cell carrier.

    • A : Type

      Left tensor factor — the motivic-Galois action sees only this.

    • B : Type

      Right tensor factor — the braid action sees only this.

    • GaloisAction : Type

      Motivic-Galois group elements.

    • BraidAction : Type

      Braid group elements.

    • decomp : Cell → A × B

      The disjoint tensor decomposition Cell ↪ A ⊗ B (underlying-set image of the categorical iso).

    • decomp_inj : Function.Injective decomp

      A tensor iso is injective on underlying sets: the decomposition separates points of the cell.

    • galois : GaloisAction → Cell → Cell

      The motivic-Galois action on the whole cell.

    • braid : BraidAction → Cell → Cell

      The braid action on the whole cell.

    • galoisA : GaloisAction → A → A

      The motivic-Galois action restricted to the left factor A.

    • braidB : BraidAction → B → B

      The braid action restricted to the right factor B.

    • galois_on_A (g : GaloisAction) (x : Cell) : decomp (galois g x) = (galoisA g (decomp x).1, (decomp x).2)

      Disjointness hypothesis (Galois ↦ A-factor). Under the decomposition the Galois action is galoisA ⊗ id: it moves the A-coordinate and fixes the B-coordinate.

    • braid_on_B (b : BraidAction) (x : Cell) : decomp (braid b x) = ((decomp x).1, braidB b (decomp x).2)

      Disjointness hypothesis (braid ↦ B-factor). Under the decomposition the braid action is id ⊗ braidB: it moves the B-coordinate and fixes the A-coordinate.

      Proposition (prop:joint-galois-braid-discharged, conditional on [JointGaloisBraidDecomposition]).

      The joint motivic-Galois × braid action commutes on every bi-filtration cell: galois g (braid b x) = braid b (galois g x).

      Derived — not assumed. Applying decomp to both sides, the disjoint-factor hypotheses galois_on_A and braid_on_B send each composite to the single pair (galoisA g a, braidB b b') — the interchange law for galoisA ⊗ id and id ⊗ braidB acting on disjoint coordinates — and injectivity of decomp transports the equality back to Cell. The only unproved input in the chain is the class instance for the concrete 𝓗_q^{(n,K)} (left unbuilt).
