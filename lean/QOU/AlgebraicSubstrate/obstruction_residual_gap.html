    Localising the residual gap of thm:qou-obstruction-reduction (Tier C, C11) #

    collatz_contact_boundary is §3b-conditional, and its docstring names the residual as "the κ₀ = χ(A) trace-gap input inherited from QouObstructionReductionContext", with "a full derivation of the remaining substrate primitives remains pending". That is accurate but imprecise: it says a gap remains without saying how large it is or what would close it.

    This file measures it. Two results, both sorry-free:

    1. The gap is exactly one integer equation. The context carries the gap across three fields — trace_pairing, hattori_stallings, trace_pairing_cast. residual_gap_iff shows that in the presence of trace_pairing_cast the Hattori–Stallings field is logically equivalent to the bare equation κ₀ = χ(A). So the trace-pairing apparatus contributes nothing: the residual is one equation between two integers, not a body of analytic input.

    2. The structural inputs cannot close it. The context's docstring asserts the gap "is NOT derivable from the two structural inputs (vdb_duality, drinfeld_rigidity)". That was prose. structuralCore_not_force_gap proves it: an explicit assignment satisfies both inputs while κ₀ ≠ χ(A). And structuralCore_hhCohDim_two shows the same two inputs do still force conclusion (a), dim HH² = 1 — so the separation is sharp. Conclusion (a) is derived; conclusions (b),(c) are not, and no strengthening of the two literature inputs will change that.

    Is the context a self-assuming projection? No — but the margin is thin #

    AGENTS.md §3b-cond rule 5 forbids a class that carries a block's own conclusion as a field with a "theorem" that merely projects it. Result 1 shows obstruction_trace_gap is close to that shape: strip trace_pairing and its _cast and the remaining field says κ₀ = χ(A) outright.

    It is nevertheless not a rule-5 violation, and the distinction is worth stating because it is the whole justification for the current encoding. The block's conclusion (c) is κ₀ ≡ 0 (mod n) ↔ n ∣ χ(A). The assumed equation κ₀ = χ(A) is not that conclusion; it is a named literature input (the Hattori–Stallings / Chern-character trace computation) which, composed with the definitional kappa_vanishes_def, yields the conclusion. Assuming a cited theorem and deriving from it is the §3b-cond pattern working as intended.

    What a reader should take away is narrower and more useful: the three trace fields are one hypothesis wearing three names, so anyone auditing the residual should audit hattori_stallings alone, and anyone closing it must supply an actual Hochschild computation — no rearrangement of the existing fields will do it.

    Base ring: ℤ and ℝ only where the context already uses them; nothing new is specialised (§7c).

    1 — the residual is exactly κ₀ = χ(A) #

    source
    theorem QOU.AlgebraicSubstrate.ObstructionResidualGap.residual_gap_iff (tp : ℤ → ℝ) (chi kappa : ℤ) (hcast : ∀ (z : ℤ), tp z = ↑z) :
    tp chi = ↑kappa ↔ kappa = chi

    The trace-pairing apparatus is decorative. Given that the pairing is the canonical cast (trace_pairing_cast), the Hattori–Stallings hypothesis trace_pairing χ(A) = κ₀ says precisely κ₀ = χ(A) and nothing more.

    Stated over free data rather than over the class, so that it characterises the shape of the hypothesis rather than merely re-deriving what an instance already grants.

    phi = tp chi ↔ phi = ↑chi

    2 — the structural inputs do not reach the gap #

    The two literature inputs constrain only the Hochschild dimensions. Isolating them from the trace data shows exactly what they can and cannot do.

    structure QOU.AlgebraicSubstrate.ObstructionResidualGap.StructuralCore :
    Type

    The context's structural core: the two literature inputs (vdb_duality, drinfeld_rigidity) together with the raw dimension data and the two integers, but without any trace field.

    • hhCohDim : ℕ → ℕ

      dim_k HH^i(U_q, Ad).

    • hhHomDim : ℕ → ℕ

      dim_k HH_i(U_q, Ad).

    • chi_A : ℤ

      Euler characteristic χ(A).

    • kappa0 : ℤ

      The primitive Kummer obstruction integer κ₀.

    • vdb_duality (i : ℕ) : i ≤ 3 → self.hhCohDim i = self.hhHomDim (3 - i)

      Van den Bergh / Calabi–Yau duality in dimension 3.

    • drinfeld_rigidity : self.hhHomDim 1 = 1

      Drinfeld rigidity.
