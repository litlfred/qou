    QOU.AlgebraicSubstrate.PolyhedralDomination — the squeeze as a face test #

    Bean qou-filh. Domination values in a linearly ordered Γ. The natural invariant of a q-difference equation is not a number but its Newton polygon, valued in a lattice-ordered group (ℤⁿ/ℚⁿ): a linear order appears only after choosing a supporting functional, i.e. selecting a face.

    This file makes that precise, and the payoff is the translation asked for:

    an archimedean inequality "cost exceeds budget" becomes "some supporting functional strictly separates the two valuation points" — an LP-feasibility / face-membership question on the polyhedron.

    squeeze_of_face_separation is that statement. Face.toDomination is why it works: every face specialises a polyhedral valuation to an ordinary Domination, so the whole DominationSqueeze toolkit applies face-by-face.

    Reading it as Newton polygons #

    For a linear q-difference equation the Newton polygon's slopes are the q-Gevrey orders of its formal solutions (Ramis–Sauloy–Zhang). The corpus already carries the one-dimensional shadow — QOU.Mathlib.QGevreyOrder's IsQGevreyOrder q s a, with the same reference — and that file's own docstring lists the Newton-polygon convolution law as out of scope. That law is exactly le_val_add here, now stated in the polyhedral (⊓) form it wants.

    • a point of Γ = a Newton-polygon exponent/slope datum;
    • ⊓ = the polyhedral meet (the lower hull of a sum contains the meet);
    • a Face = a supporting functional; picking one picks a face;
    • Face.toDomination = restricting attention to that face;
    • face separation = the LP feasibility test that replaces the inequality.

    Honesty about the trivial face #

    Face is satisfiable by the constant-⊤ functional, which separates nothing. So a Face alone asserts nothing — exactly the situation trivialError_bound records for SurrealParallelTransportBound. That is stated here as trivialFace + trivialFace_separates_nothing rather than left as a trap: a face carries information only once it is exhibited to separate something, which is what Separates and squeeze_of_face_separation require.

    Scope #

    This is the structural translation. It does not construct the Newton polygon of any particular QOU q-difference equation, and it does not decide any inequality on its own — it says which question to hand to an LP solver. Building an actual PolyDomination from the framework's q-difference data is the remaining work under qou-filh.

    structure QOU.AlgebraicSubstrate.PolyDomination (A : Type u_2) [AddCommGroup A] (Γ : Type u_3) [SemilatticeInf Γ] :
    Type (max u_2 u_3)

    Polyhedral domination — a valuation into a lattice-ordered value object, with the ultrametric bound stated via the meet ⊓ rather than min.

    Domination is the special case where Γ is linearly ordered (then ⊓ = min), so nothing is lost; what is gained is that the value of an element can be a polygon datum rather than a single grade.

    • val : A → WithTop Γ

      Polyhedral grade — a Newton-polygon datum, not necessarily a number.

    • val_zero : self.val 0 = ⊤

      Zero is infinitely deep.

    • val_neg (a : A) : self.val (-a) = self.val a

      Negation preserves the polygon.

    • le_val_add (a b : A) : self.val a ⊓ self.val b ≤ self.val (a + b)

      Newton-polygon / ultrametric law in polyhedral form.

      Type (max u_2 u_4)

      A supporting functional — a choice of face.

      φ sends polygon data to a linearly ordered scale, carrying the polyhedral meet to min. Choosing such a φ is choosing the direction in which the polygon is read, i.e. selecting a face.

      • φ : WithTop Γ → WithTop Δ

        The functional, already lifted to the ⊤-adjoined value object.

      • map_top : self.φ ⊤ = ⊤

        Depth is preserved.

      • map_inf (x y : WithTop Γ) : self.φ (x ⊓ y) = min (self.φ x) (self.φ y)

        The polyhedral meet becomes the linear min — this is what makes the face a legitimate reading of the polygon.

      • mono {x y : WithTop Γ} : x ≤ y → self.φ x ≤ self.φ y

        The functional is monotone (implied by map_inf, kept as a field so the specialisation below needs no lattice lemmas).

            theorem QOU.AlgebraicSubstrate.squeeze_of_face_separation {A : Type u_1} [AddCommGroup A] {Γ : Type u_2} [SemilatticeInf Γ] {Δ : Type u_3} [LinearOrder Δ] {P : PolyDomination A Γ} (F : Face P Δ) {cost budget : A} (h : F.Separates cost budget) :
            cost + budget ≠ 0

            The face-membership test — the translation.

            An archimedean inequality "the cost strictly exceeds the budget, so the budget cannot absorb it" is replaced by a question about the Newton polygon: does some supporting functional strictly separate the two valuation points? If one does, the conclusion follows with no ordered field, no ℝ, and no surreals.

            That question — is this point strictly below that one along some admissible direction — is exactly an LP feasibility test on the polyhedron.
