    QOU.AlgebraicSubstrate.ReebSpectrum #

    The shape a Reeb spectrum must have, and the named — unproved — hypothesis tying it to the Frobenius eigenvalues of LocalQZetaFunction.

    What this is for (bean qou-qspc) #

    cor:spectral-half-line concludes Re(ρᵢ) = 1/2 for exponents satisfying αᵢ = q^{ρᵢ}, and exists_spectral_coord shows such exponents always exist. But the arc wants to say something stronger — that the Reeb spectrum lies on the critical line — and nothing in the corpus related the two. Measured: the identifier ReebEigenvalue occurred in exactly one file, a content-block sibling no module can import, and the library's Reeb infrastructure (ReebEpsilon, QReebFlow, ReebDecomposition) carries no spectrum with complex eigenvalues.

    What this does NOT claim #

    It does not say what ξ_q is. The operator is data, supplied by whoever instantiates the structure; this file fixes only the shape any Reeb spectrum must have — eight modes, each a genuine eigenvector with a complex eigenvalue — and names the identification as a hypothesis.

    That distinction is the whole design. An opaque carrier (holds : Prop, or a structure whose fields promise properties they do not encode) would assert nothing and could be discharged by ⟨True⟩; is_eigen is a real equation, so an instance has to produce an operator and vectors that actually satisfy it. reebSpectrumExample below witnesses that the shape is inhabited, so it is not an empty interface either.

    HasReebSpectralCoords carries no instance. That is the honest open state (§3b-tax): the identification of the Frobenius exponents with the Reeb spectrum is precisely what is unproved, and it is now stated where it can be cited and attacked rather than absent.

    structure QOU.AlgebraicSubstrate.ReebSpectrum (H : Type u_1) [AddCommGroup H] [Module ℂ H] :
    Type u_1

    The shape of a Reeb spectrum. An operator on a ℂ-module together with eight nonzero eigenvectors and their complex eigenvalues.

    H and op are parameters, not claims: this says what it means to be a spectrum of eight modes, not which operator the framework's ξ_q is.

    • op : H →ₗ[ℂ] H

      The operator whose spectrum this is (the Reeb derivation, when instantiated at it).

    • mode : Fin 8 → H

      The eight fundamental modes.

    • spec : Fin 8 → ℂ

      Their eigenvalues, complex — the critical line is a line in ℂ, so a real spectrum could not carry the claim Re(ρ) = 1/2 non-trivially.

    • mode_ne_zero (i : Fin 8) : self.mode i ≠ 0

      A mode is a genuine eigenvector, not the zero vector.

    • is_eigen (i : Fin 8) : self.op (self.mode i) = self.spec i • self.mode i

      The eigenvalue equation. This is what makes the structure content-bearing: an instance must exhibit an operator and vectors satisfying it.

        Non-vacuity #

        The interface is inhabited: H = ℂ, the identity operator, every mode 1 with eigenvalue 1. Trivial as a spectrum, but it establishes that ReebSpectrum is a shape something can have — unlike a carrier whose fields cannot be satisfied, and unlike one any ⟨True⟩ discharges.
