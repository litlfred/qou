    QOU.AlgebraicSubstrate.WeilZeta #

    The two classical Weil inputs as a hypothesis class, and the Hasse–Weil magnitude derived from them.

    Why this is a library module and not a content-block sibling #

    It was both, in hasse-weil-bound.lean, until the material below had a second consumer. cor:spectral-half-line concludes Re(ρᵢ) = 1/2 from the magnitude ‖αᵢ‖ = q^{1/2}, and took that magnitude as its own hypothesis — because content-block siblings are outside the package globs (§0a) and cannot import one another, so it had no way to reach hasse_weil_bound where the magnitude is derived. The same hypothesis being assumed in one file and proved in the file next to it is not a division of labour; it is a gap that happens to close by coincidence of wording.

    So the class and the four-step chain that ends at hasse_weil_bound live here, importable by both. hasse-weil-bound.lean keeps everything downstream of the magnitude — conjugation-closure, the characteristic-polynomial facts, Vieta — which is the block's actual content.

    What is assumed and what is derived #

    Assumed, as the two fields of IsWeilZeta: the functional equation (as a permutation) and Castelnuovo–Severi. Both are cited classical results, and weilZetaExample witnesses that they are jointly satisfiable, so the class is not an empty carrier.

    Derived: that the two together force ‖αᵢ‖² = q exactly rather than ≤ — the step Weil's argument turns on, and the one piece of the Hasse–Weil argument the corpus proves itself.

    Ground ring: ℝ (geometric/analytic realisation) — real powers and norms.

    class QOU.AlgebraicSubstrate.IsWeilZeta (Z : LocalQZetaFunction) :
    Prop

    Weil datum. The hypothesis that Z is the zeta function of a smooth projective geometrically irreducible curve over 𝔽_q, recorded through the two consequences the Hasse–Weil argument consumes.

    Both fields are classical theorems about such curves, not properties of an arbitrary LocalQZetaFunction — see the module docstring for the False derivations that follow from asserting them universally.

    • functional_equation — the functional equation of the zeta function of a curve pairs each eigenvalue αᵢ with q/αᵢ. See [weil1948] §IV, or [rosen2002] Ch 5, Thm 5.9.
    • castelnuovo_severi — the Castelnuovo–Severi inequality on B × B (Hodge index theorem) bounds the self-intersection of the Frobenius correspondence, giving |αᵢ|² ≤ q. See [weil1948] §V; [milne2013] §27; [rosen2002] Ch 5, Thm 5.10.
    • functional_equation : ∃ (σ : Equiv.Perm (Fin 8)), ∀ (i : Fin 8), Z.eigenvalues (σ i) = ↑Z.q / Z.eigenvalues i

      Functional-equation pairing: αᵢ ↦ q/αᵢ permutes the eigenvalues.

      Stated as a permutation rather than as ∀ i, ∃ j. The existential form is strictly weaker and loses multiplicities — it is satisfied by families in which two eigenvalues share a partner and a third has none — so nothing about the root multiset follows from it, and charPoly_map_conj below is exactly such a multiset statement. Weil's functional equation does supply the bijection, so this is the faithful form, not a strengthening of the cited result.

    • castelnuovo_severi (i : Fin 8) : ‖Z.eigenvalues i‖ ^ 2 ≤ Z.q

      Castelnuovo–Severi: |αᵢ|² ≤ q.

      theorem QOU.AlgebraicSubstrate.eigenvalue_norm_sq (Z : LocalQZetaFunction) [IsWeilZeta Z] (i : Fin 8) (h_cs : ‖Z.eigenvalues i‖ ^ 2 ≤ Z.q) (h_fe : ∃ (j : Fin 8), Z.eigenvalues j = ↑Z.q / Z.eigenvalues i) :
      ‖Z.eigenvalues i‖ ^ 2 = Z.q

      The functional equation + Castelnuovo–Severi together force |αᵢ|² = q (not just ≤).

      The functional equation gives |αᵢ| · |q/αᵢ| = q for paired eigenvalues, so |αᵢ|² ≥ q. Combined with CS, equality holds. See [rosen2002] Ch 5, proof of Thm 5.12.

      This step is derived, not assumed: it is the one piece of the Hasse–Weil argument the corpus proves itself.

      theorem QOU.AlgebraicSubstrate.hasse_weil_bound (Z : LocalQZetaFunction) [IsWeilZeta Z] (i : Fin 8) :
      ‖Z.eigenvalues i‖ = Z.q ^ (1 / 2)

      Hasse–Weil bound: every fundamental Frobenius eigenvalue αᵢ of Bring's curve satisfies |αᵢ| = q^{1/2}.

      This is the Riemann hypothesis for curves over finite fields, proved by Weil via the Castelnuovo–Severi inequality on the self-product B × B.

      Stated conditionally on [IsWeilZeta Z] (§3b-cond): the two Weil inputs are hypotheses, and everything else is derived. The proof combines:

      • eigenvalue_functional_equation (symmetry of the zeta function)
      • castelnuovo_severi_bound (Hodge index theorem on B × B)
      • eigenvalue_norm_sq (combining the two forces equality)

      Non-vacuity #

      IsWeilZeta is a hypothesis class, so it is worth nothing unless it is inhabited: an empty carrier would make hasse_weil_bound conditional on a proposition no datum satisfies, which is the failure mode proof-no-empty-prop-carrier exists to catch. The witness below is the supersingular shape q = 4, αᵢ = 2 for all i — a genuine Weil datum, with |αᵢ|² = 4 = q and q/αᵢ = 2 = αⱼ.
