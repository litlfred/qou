    QOU.AlgebraicSubstrate.AdelicSubstrate — adelic substrate interface #

    Formalizes def:adelic-substrate.

    The QOU framework's macroscopic substrate is the rational adele ring 𝔸_ℚ = ℝ × ∏'_p ℚ_p: an archimedean place ℝ (the laboratory continuum) together with one non-archimedean local ring per rational prime p, restricted-product compatible.

    The interface below is abstract: a carrier type with an archimedean projection and per-prime non-archimedean projections. The QOU instance (not constructed here) identifies each Loc p with the localized quantum-geometric state at the p-th cyclotomic / Kummer level of the Habiro completion, and the archimedean projection with the classical-limit functor.

    References #

    • [tate1967] Tate, Fourier Analysis in Number Fields and Hecke's Zeta-Functions. In Algebraic Number Theory (Cassels-Fröhlich, eds.), Academic Press, 1967.

    structure QOU.AlgebraicSubstrate.AdelicSubstrate :
    Type (max (u_1 + 1) (u_2 + 1))

    The adelic substrate of the QOU framework.

    Abstract interface: a ring Carrier carrying an archimedean place (projection to ℝ) and one non-archimedean place per rational prime p (projection to a local quantum-state ring Loc p).

    Encodes the rational adele ring 𝔸_ℚ = ℝ × ∏'_p ℚ_p as used by Tate's adelic Fourier analysis.

    • Carrier : Type u_1

      The carrier ring of the substrate.

    • Loc : ℕ → Type u_2

      Local non-archimedean rings, indexed by rational primes.

    • archimedean : self.Carrier → ℝ

      Archimedean projection π_∞ : A → ℝ (the laboratory continuum).

    • nonArchimedean (p : ℕ) : self.Carrier → self.Loc p

      Non-archimedean projection π_p : A → Loc p at each prime p.
