    def QOU.AlgebraicSubstrate.SubstrateClock.IsClock {M : Type u_1} [AddCommMonoid M] {K : Type u_2} [Field K] (T : M → K) :
    Prop

    A clock on the substrate's computation monoid M: a K-valued step-counter that (i) is additive under composition of computation segments — the algebraic core of "functorial under the substrate's composition of computation steps" — and (ii) is not identically zero — the algebraic shadow of cofinality (a counter that never registers any computation counts nothing). The order-theoretic clauses (strict monotonicity for the braiding-induced ordering ≺_∞, cofinality in the well-founded computation order of prop:ordering-jet-compatibility) are archimedean-side refinements recorded in the audit; the downstream algebra uses only (i)+(ii).

      class QOU.AlgebraicSubstrate.SubstrateClock.SubstrateClockUniqueness (M : Type u_3) [AddCommMonoid M] (K : Type u_4) [Field K] [CharZero K] :
      Prop

      Primary conjecture (open — NO instance; §3b-tax). THE SUBSTRATE HAS ONE CLOCK: any two clocks of the substrate's computation monoid differ by a single nonzero scale — the scale freedom that owner premise P1 (substrate scale-freedom) already quotients out. The field is parameter-quantified over all clock pairs; it is a genuine structural restriction on M (rank-one-ness of the computation monoid), FALSE for a two-generator step monoid (uniqueness_fails_for_two_generators) and discharged by atomicity of the step monoid (unique_up_to_scale_of_atomic — the "no sub-step resolution" of the Planck step, rem:discrete-planck-step, currently prose-only). An unproved primary conjecture is honestly represented by this content-bearing class with no instance; creating an instance without proving the substrate monoid's rank-one structure would be laundering.
