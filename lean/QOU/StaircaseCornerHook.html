    Staircase EW-residual conjecture #

    The staircase partition ρ k = (k, k-1, …, 1) carries a distinguished corner hook at cell (0,0):

    h_corner(ρ k) = arm(0,0) + leg(0,0) + 1 = (k-1) + (k-1) + 1 = 2k - 1.

    This file:

    • Proves staircase_corner_hook_eq_two_k_sub_one : h_corner k = 2*k - 1 rigorously (combinatorial; no sorry).
    • Axiomatises as a Lean class the spectral conjecture that the scale q^(1/(2k-1)) appears as a pairwise eigenvalue ratio of the staircase β_EW operator on V_{ρ k} — the conjecture verified empirically for k=3 (cot θ_W gap closure to 0.13%) and k=4 (rel.err 0.14%) in staircase_ew_residual_conjecture.py.

    Per AGENTS.md §3b, an unproved staircase EW-residual claim must be either kind conjecture or a provable kind under the conditional-class exception (a class instance whose sorry axiomatises the claim). We choose the latter so downstream results may state conditional theorems "if StaircaseEWResidual holds, then …".

    References #

    • Hoefsmit (1974), Representations of Hecke algebras of finite groups with BN-pairs of classical type, PhD thesis, UBC.
    • Mathas (1999), Iwahori–Hecke algebras and Schur algebras of the symmetric group, AMS, §3.31.
    • Stanley (1999), Enumerative Combinatorics II, Cambridge UP, §7.21 (hook-content formula).

    def QOU.StaircaseCornerHook.hCorner (k : ℕ) :
    ℕ

    The corner hook of the staircase ρ k = (k, k-1, …, 1) at cell (0, 0). Defined directly as the combinatorial quantity:

    h_corner k := arm(0,0) + leg(0,0) + 1

    For the staircase ρ k:

    • arm(0,0) = (length of row 0) - 1 = k - 1
    • leg(0,0) = (number of rows with ρ k r ≥ 1) - 1 = k - 1

    so h_corner k = (k - 1) + (k - 1) + 1.

    Equations
    • QOU.StaircaseCornerHook.hCorner k = k - 1 + (k - 1) + 1

      theorem QOU.StaircaseCornerHook.staircase_corner_hook_eq_two_k_sub_one (k : ℕ) (hk : 1 ≤ k) :
      hCorner k = 2 * k - 1

      Provable lemma. The corner hook of the staircase ρ k equals 2*k - 1 for every k ≥ 1.

      This is purely combinatorial: it follows from the definition of the staircase shape and the hook-length formula, with no appeal to representation theory or any spectral data.

      Ref: [stanley1999] Enumerative Combinatorics II, §7.21

      The staircase EW-residual conjecture (axiomatised as a class) #

      For the empirical content and 7/7 witness assertions, see:

      • computations/staircase_ew_residual_conjecture.py
      • computations/staircase-ew-residual-conjecture.witness.json
      • docs/audits/2026-05-06-staircase-ew-residual-conjecture.md

      Per AGENTS.md §3b-cond, the conjecture is encoded as

      • an opaque Prop-valued declaration StaircaseEWSpectralContent k (one axiom; cannot be discharged by trivial); and
      • a class StaircaseEWResidual whose single field bundles the family ∀ k ≥ 2, StaircaseEWSpectralContent k.

      Per AGENTS.md §3b-tax an open primary conjecture is represented by a content-bearing class with no instance. This file therefore provides no global instance (see the "Open conjecture — hypothesis-only" section below); the illustrative snippet

      axiom conj_staircase_ew_residual : StaircaseEWResidual
instance : StaircaseEWResidual := conj_staircase_ew_residual   -- illustrative only; NOT provided

      shows what a sorry-record instance would look like, but a fabricated sorry/trivial instance is exactly what §3b-tax forbids on an open carrier. Downstream theorems instead take [StaircaseEWResidual] as an explicit instance hypothesis and carry the §3b-cond "conditional on conj:staircase-ew-residual" banner; once a real proof lands, a genuine instance is added here and every downstream conditional becomes unconditional automatically.

      Ref: [manuscript] §EW-residual, observed at q_0 to relative error 1.30e-3 (k=3, top-two ratio against cot θ_W) and 1.42e-3 (k=4, pairwise-ratio search in dim-768 spectrum).

      def QOU.StaircaseCornerHook.StaircaseEWSpectralContent {R A : Type u} [CommRing R] [Inv R] [Ring A] [Algebra R A] (q s : R) (k : ℕ) [Hecke.HeckeAlgebra R (k * (k + 1) / 2) q A] [HR : Hecke.HoefsmitRepresentation (k * (k + 1) / 2) q A (Hecke.staircasePartition k)] :
      Prop

      Concrete spectral statement: in any Hoefsmit representation HR of H_{n_k}(q) on the staircase Specht module V_{ρ k}, the matrix image of the canonical β_EW Δ_I^minimal word has two nonzero eigenvalues whose ratio is q ^ (1 / (2k - 1)).

      The exponent 1 / (2k - 1) lives in the real / rpow world; we state the predicate over an arbitrary R together with a designated scale element s : R standing for the would-be q ^ (1 / (2k - 1)). Downstream callers supply s either by working over ℝ with Real.rpow, or by adjoining a (2k−1)-th root of q to the base ring.

      This replaces the previous opaque axiom StaircaseEWSpectralContent (k : ℕ) : Prop with a predicate that actually mentions the Hoefsmit-matrix spectrum.

            Open conjecture — hypothesis-only (no global instance) #

            The staircase EW-residual conjecture is the existence of an instance StaircaseEWResidual q (canonicalScale q): that for every k ≥ 2 the scale q^(1/(2k-1)) is realised as a β_EW eigenvalue ratio on V_{ρ k} (empirically verified at k=3 rel.err 0.13 %, k=4 rel.err 0.14 % in staircase_ew_residual_conjecture.py).

            Per AGENTS.md §3b-cond we provide no global instance (which would require a sorry): downstream theorems take [StaircaseEWResidual q (canonicalScale q)] as an explicit instance hypothesis and carry the "conditional on conj:staircase-ew-residual" banner. Closing the conjecture means constructing StaircaseEWSpectralContent q (canonicalScale q k) k for every k ≥ 2 — a substantive Hoefsmit-matrix spectral analysis — after which an instance can be added and every downstream conditional becomes unconditional automatically.

            Ref: [manuscript] docs/audits/2026-05-06-staircase-ew-residual-conjecture.md
