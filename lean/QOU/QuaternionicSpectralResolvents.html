    QOU.QuaternionicSpectralResolvents #

    Canonical declaration for content block at quantum-observable-universe/brings-surface/quaternionic-spectral-resolvents.ts.

    Formalises the manuscript definition of the quaternionic spectral resolvents ω₀,…,ω₃ : 𝒮 → J^∞E on Bring's surface: with q ∈ ℂ, 0 < |q| ≤ 1 and r = −ln|q| (so |q| = e^{−r}), the resolvent ω₀ is the uncertainty component and ω₁,ω₂,ω₃ are the space-like and time-like components carried by the quaternion units 𝐢,𝐣,𝐤. The abstract quaternion algebra is axiomatised (H with the Hamilton relations) since the Mathlib quaternion cone is outside the available olean set; the scale r = −ln|q| is over ℝ (§7c archimedean).

    structure QOU.QuaternionicSpectralResolvents :
    Type 1

    Data for the quaternionic spectral resolvents at a substrate value q.

    A definition carrier: the modulus |q| with 0 < |q| ≤ 1, the scale r = −ln|q|, the quaternion carrier H with its imaginary units 𝐢,𝐣,𝐤, and the four resolvents.

    • qAbs : ℝ

      The modulus |q|.

    • qAbs_pos : 0 < self.qAbs

      |q| > 0.

    • qAbs_le_one : self.qAbs ≤ 1

      |q| ≤ 1 (inside the closed unit disc).

    • r : ℝ

      The scale r.

    • r_def : self.r = -Real.log self.qAbs

      r = −ln|q|.

    • H : Type

      The quaternion carrier.

    • instH : Ring self.H

      H is a ring.

    • i : self.H

      The imaginary units.

    • j : self.H
    • k : self.H
    • ω : Fin 4 → self.H

      The four spectral resolvents ω₀,…,ω₃ (as elements of H).
