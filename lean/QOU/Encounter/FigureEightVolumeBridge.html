    theorem QOU.Encounter.FigureEightVolumeBridge.vol_pos_of_realises {M : Type u_1} [MathlibExt.HyperbolicVolumeBridge M] (m : M) (h : MathlibExt.HyperbolicVolumeBridge.Realises Knot.FigureEightTri.figureEightTriangulation m) :
    0 < MathlibExt.HyperbolicVolumeBridge.vol m

    Positivity — derived, not assumed.

    ManifoldVolumeBridge deliberately declines to carry positivity as a class field, because 0 < D(z) on the upper half plane is not in the corpus. At the figure-eight it does not need to be assumed: Cl_2_pi_div_three_pos supplies it.

    theorem QOU.Encounter.FigureEightVolumeBridge.vol_ne_zero_of_realises {M : Type u_1} [MathlibExt.HyperbolicVolumeBridge M] (m : M) (h : MathlibExt.HyperbolicVolumeBridge.Realises Knot.FigureEightTri.figureEightTriangulation m) :

    The 4₁ volume is not zero, hence the triangulation is not degenerate. A corollary worth naming because a bridge whose vol collapsed to 0 would satisfy every transport statement vacuously — the degenerate-model check, applied to the value rather than to the relation.
