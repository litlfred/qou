    Palindromicity and Orbital Type #

    The word-length histogram of the quotient atom NF is palindromic through the s sub-shells (Z ≤ 4) and breaks at the first p electron.

    This file defines the palindromicity predicate and proves it for the helium case (Z=2), which has histogram {1:1, 2:1} — trivially palindromic.

        theorem QOU.Molecular.helium_histogram_palindromic :
        IsPalindromic [0, 1, 1, 0]

        The helium histogram is [0, 1, 1, 0] — zero terms at length 0, one at length 1 (σ₁), one at length 2 (σ₀σ₁), zero at length 3. This is palindromic (Poincaré dual).

        §3 General palindromicity conjecture #

        source
        class QOU.Molecular.PalindromicityOrbitalType (Z : ℕ) :
        Type

        Conjecture. For the quotient atom model in H_{Z+1}(q), the word-length histogram is palindromic for Z ≤ 4 (pure s-shells) and non-palindromic for Z ≥ 5 (p-shell occupied).

        This is the Poincaré duality statement: palindromicity holds when the NF occupies a self-dual sub-lattice of the Bruhat order on S_{Z+1}, which happens precisely for s-type orbitals.

        • histogram : List ℕ

          The NF histogram at atomic number Z.

        • palindromic_iff_s_type : IsPalindromic (histogram Z) ↔ Z ≤ 4

          The histogram is palindromic iff all occupied sub-shells are s-type.
