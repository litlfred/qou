    Shell Closure from NF Term Count #

    Formalization of the quotient atom model: the nuclear core is quotiented to a single strand, and electrons are added one at a time. We prove the Z=2 (helium) case: after adding 2 electrons to the nuclear strand, the NF has exactly 2 terms — the same as after 1 electron. This is the first shell closure (1s²).

    The quotient atom model #

    In H_{Z+1}(q), strand 0 is the nuclear core 𝒩 and strands 1..Z are electrons. The crossing types are:

    𝒩-e : Z · σ⁻¹ = Z · (σ − HA) (EM attraction) e-e : σ (EM repulsion)

    References #

    • [iwahori1964] https://doi.org/10.1515/crll.1964.215.167
    • [jones1987] https://doi.org/10.2307/1971403

                  §4 Helium: NF(𝒩 + 2e⁻) in H₃(q) #

                  The helium atom: strand 0 = nucleus (Z=2), strands 1,2 = electrons.

                  Step 1: Add e₁ (strand 1). Crossings: 𝒩-e at σ₀ with Z_eff=2. After reduction: NF₁ = (−2·HA)·𝟏 + 2·σ₀ (in H₂, 2 terms)

                  Step 2: Add e₂ (strand 2). New crossings:

                  • 𝒩-e at σ₀ with Z_eff=2: multiply by 2·σ₀⁻¹ = 2·σ₀ − 2·HA
                  • e-e at σ₁: multiply by σ₁ (repulsive)

                  After GS reduction in H₃(q), the NF has exactly 2 terms.

                  KEY RESULT: n(2) = n(1) = 2. The second electron is absorbed without creating new basis words. This is the 1s² shell closure.

                                    theorem QOU.Molecular.helium_shell_closure :
                                    helium_nf 0 = 0 ∧ helium_nf 1 = 0 ∧ helium_nf 2 ≠ 0 ∧ helium_nf 3 ≠ 0 ∧ helium_nf 4 = 0 ∧ helium_nf 5 = 0

                                    Shell closure theorem for helium (Z=2).

                                    The helium quotient atom NF in H₃(q) has exactly 2 nonzero terms (slots 2 and 3), while hydrogen in H₂(q) also has 2 nonzero terms.

                                    n(He) = n(H) = 2.

                                    The second electron is absorbed into the existing NF basis without creating new reduced words. This is the 1s² shell closure.

                                      class QOU.Molecular.ShellClosureNFTermCount :
                                      Type

                                      Conjecture class. An instance asserts that the quotient-atom NF term count nf_term_count : ℕ → ℕ (electrons → number of nonzero NF basis coefficients) is constant on each magic- number plateau:

                                      n(Z+1) = n(Z) for Z, Z+1 ∈ same shell

                                      or equivalently, n changes only when Z crosses a magic number.

                                      The Z=2 (helium) case is proved unconditionally as helium_shell_closure above (n(2) = n(1) = 2). The general case for Z ∈ {8, 20, 28, 50, 82, 126} requires Hecke-tower computations at H_{Z+1} which are intractable beyond Z ≈ 8; the conjecture asserts the pattern persists.

                                      sorry in any concrete instance is understood as conjecture, not missing proof. Downstream blocks may take [ShellClosureNFTermCount] as an explicit hypothesis to remain theorem/proposition per AGENTS.md §3b-cond.

                                      Ref: [manuscript] §Shell closure NF term count, conj:shell-closure-nf-term-count

                                      • nf_term_count : ℕ → ℕ

                                        The NF term count after Z electrons (in H_{Z+1}(q)).

                                      • helium_base : nf_term_count 2 = nf_term_count 1

                                        Helium base case (proved unconditionally above): n(2) = n(1) = 2.

                                      • shell_constant_between_magics (Z : ℕ) : Z + 1 ∉ magic_numbers ∧ Z ∉ magic_numbers → nf_term_count (Z + 1) = nf_term_count Z

                                        Conjectural shell-closure rule. For every magic number m and every Z, Z+1 in the same shell (between consecutive magic numbers), the term count is constant. Equivalently: term count changes ONLY at Z transitions across magic numbers.

                                        def QOU.Molecular.canonical :
                                        ShellClosureNFTermCount

                                        Constant-count skeleton. Sets nf_term_count ≡ 0, so both helium_base and shell_constant_between_magics close by rfl (every shell-step is 0 = 0). It encodes none of the NF-term-count content.

                                        It also disagrees with the one case this file proves: helium_nf has two nonzero slots (helium_palindromic_histogram), i.e. n(2) = n(1) = 2, which is what helium_base is documented to record. The skeleton satisfies helium_base by setting both sides to 0 instead. A constant function makes "the count is constant across a shell" true for the same reason it makes it true across a magic-number boundary — the claim's whole content is where the count changes.
