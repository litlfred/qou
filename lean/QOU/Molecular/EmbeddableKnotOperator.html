    structure QOU.Molecular.EmbeddableKnotOperator :
    Type

    A knot operator embedded into the ambient 3-manifold with a geometric overlap weight w ∈ (0, 1]. Axial (σ-type) channels have overlapWeight = 1; transverse (π-type) channels have overlapWeight < 1.

    • baseBinding : ℝ

      Un-embedded channel binding (energy units).

    • overlapWeight : ℝ

      Geometric overlap weight set by the embedding direction.

    • weight_pos : 0 < self.overlapWeight

      The overlap weight is positive: the channel binds.

    • weight_le_one : self.overlapWeight ≤ 1

      The overlap weight does not exceed the axial (head-on) maximum.

                theorem QOU.Molecular.orthogonal_channels_le_dim {ι : Type u_1} [Fintype ι] (v : ι → EuclideanSpace ℝ (Fin 3)) (hne : ∀ (i : ι), v i ≠ 0) (horth : Pairwise fun (i j : ι) => inner ℝ (v i) (v j) = 0) :
                Fintype.card ι ≤ 3

                Spatial-dimension bound. In ℝ³ a family of pairwise-orthogonal nonzero vectors has at most three members: orthogonal nonzero vectors are linearly independent, and a linearly independent family in a space of finrank 3 has cardinality ≤ 3. Embedding bond channels as mutually orthogonal directions, the number of channels — the bond order — is capped by the spatial dimension, so no bond exceeds order three.
