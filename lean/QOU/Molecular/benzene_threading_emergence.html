    QOU.Molecular.benzene_threading_emergence #

    Proposition (conditional on [conj:q-integer-mass-formula]) (prop:benzene-threading-emergence): The LP dual of the benzene molecular braid in H₁₂₀(q) selects the threading link T(2,6) = (σ₁σ₂⋯σ₅)² as the optimal π-electron configuration.

    Disposition (integrity) #

    All four conjuncts of the resolving declaration are now derived; none is a projected conclusion field:

    • (i) More shared crossings. The threading link T(2,6) has 6 × 2 = 12 attractive σ⁻¹ crossings; the localised Kekulé configuration has 3 × 2 = 6. So n_shared_localised < n_shared_threading is the literal arithmetic fact 6 < 12. The crossing counts are defined by the molecular geometry (n_shared_threading_def, n_shared_localised_def), not handed back as a conclusion field.
    • (ii) D₆ symmetry. The threading configuration's symmetry group is the dihedral group D₆, whose order |D₆| = 2·6 = 12 is the genuine Mathlib computation Fintype.card (DihedralGroup 6) = 12 (DihedralGroup.card). The symmetry_order field is defined to be this cardinality.
    • (iii) Alexander weight non-vanishing. The .md gives the value Δ_{T(2,6)}(q) = (q³ − q⁻³)/(q − q⁻¹) = [3]_{q²} = q² + 1 + q⁻². The context carries that evaluation as a definitional input (alexander_weight_def), and alexander_weight ≠ 0 is derived by positivity of q² + 1 + (q²)⁻¹ over ℝ (benzene_alexander_weight_pos). A previous revision carried the non-vanishing itself as the §3b-cond class field and returned it verbatim in the conjunction — a residual self-assuming projection (AGENTS.md §3b-cond item 5); it is now a derived conjunct.
    • (iv) Resonance stabilisation is non-negative. The .md's LP-dual shadow price E_res ∝ Φ₁^{Kekulé} − Φ₁^{T(2,6)} is non-negative: derived by instantiating the §3b-cond ground-state hypothesis (threading_minimises, the LP-dual selection of T(2,6)) at the Kekulé configuration and rearranging (benzene_resonance_nonneg) — the same use-the-hypothesis-at-one-point shape as h2_binding_nonneg in h2_lp_dual_binding.lean.

    The single irreducibly-conjectural input is the LP-dual ground-state selection — the threading link minimises Φ₁ over the candidate π-electron configurations (Φ₁^{T(2,6)} < Φ₁^{Kekulé} < Φ₁^{Dewar} in the .md). It is carried by the §3b-cond class BenzeneThreadingSelection as a quantified hypothesis the theorem instantiates, never restated verbatim in the conclusion.

    Base ring (§7c) #

    q is the Hecke deformation parameter, alexander_weight its Alexander evaluation [3]_{q²} = q² + 1 + q⁻², and Φ₁ the LP objective. The proofs need division, an order and positivity/linarith -- an ordered field -- but nothing archimedean, so the scalars are a generic R and the substrate evaluation is R := ℝ.

      class QOU.Molecular.BenzeneThreadingEmergenceContext (R : Type u_2) [Field R] [LinearOrder R] [IsStrictOrderedRing R] :
      Type u_2

      Data of the benzene threading-emergence claim. All fields are inputs (geometry counts, the substrate parameter, the Alexander evaluation, and the Φ₁-functional); none is a conclusion.

      • n_shared_threading : ℕ

        Number of shared σ⁻¹ crossings in the threading-link configuration T(2,6) (6 × 2 = 12).

      • n_shared_threading_def : n_shared_threading R = 12

        The threading crossing count is 12 (6 π-electrons × 2 adjacent protons), definitional input.

      • n_shared_localised : ℕ

        Number of shared crossings in the competing localised (Kekulé) configuration (3 × 2 = 6).

      • n_shared_localised_def : n_shared_localised R = 6

        The localised crossing count is 6 (3 localised π pairs × 2), definitional input.

      • symmetry_order : ℕ

        Order of the symmetry group acting on the π-electron configuration.

      • symmetry_order_def : symmetry_order R = Fintype.card (DihedralGroup 6)

        The symmetry group of the threading configuration is D₆, so its order is Fintype.card (DihedralGroup 6) (definitional input).

      • q : R

        The (real) deformation parameter at which the Alexander weight is evaluated (the substrate q₀ in the physical reading).

      • alexander_weight : R

        Alexander polynomial weight of the threading configuration at q.

      • alexander_weight_def : alexander_weight = q ^ 2 + 1 + (q ^ 2)⁻¹

        The Alexander evaluation (definitional input, from the .md): Δ_{T(2,6)}(q) = (q³ − q⁻³)/(q − q⁻¹) = [3]_{q²} = q² + 1 + q⁻².

      • Phi1_config : BenzeneConfig → R

        Φ₁ of each candidate π-electron configuration.

          • (i) n_shared_localised < n_shared_threading — derived from the definitional counts as 6 < 12;
          • (ii) symmetry_order = 12 — derived via DihedralGroup.card, |D₆| = 2·6 = 12;
          • (iii) alexander_weight ≠ 0 — derived from the definitional Alexander evaluation [3]_{q²} = q² + 1 + q⁻² by positivity (benzene_alexander_weight_pos);
          • (iv) 0 ≤ Φ₁^{Kekulé} − Φ₁^{T(2,6)} — derived by instantiating the §3b-cond LP-dual selection hypothesis at Kekulé (benzene_resonance_nonneg).

          Every conjunct is derived; the conjectural LP-dual selection enters only as the quantified threading_minimises hypothesis.
