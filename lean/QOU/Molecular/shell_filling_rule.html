    QOU.Molecular.shell_filling_rule #

    Canonical Lean for content block prop:shell-filling-rule: Shell filling minimises $\Phi_1$ (aufbau from LP dual).

    Disposition (2026-07-03, bean qsb2 — restructured from a projection stub) #

    The previous encoding was the exact holds : Prop + impl_* anti-pattern: the class carried an opaque aufbau_holds : Prop, an instance aufbau_active : aufbau_holds, and three impl_* fields handing back each conclusion, which the "theorem" merely projected — the self-assuming projection forbidden by AGENTS.md §3b-cond item 5. Restructured per §1a honest dispositions:

    • The class now carries only genuine data: the ground-state shell occupancy, the shell capacity with its defining formula capacity n = 2n² ([def:electron-shell-braid-capacity]), the Pauli bound occupancy ≤ capacity (a structural hypothesis), the type of admissible valence configurations with the ground state and the singly-occupied-site count, and the LP primal/dual data (primal_obj, y_0). The aufbau_holds / aufbau_active / impl_* fields are gone.
    • Derived sorry-free (shell_filling_pauli_bound): the concrete occupancy bound occupancy n ≤ 2n², from the Pauli hypothesis and the capacity formula — genuine (if small) algebra, not a projection.
    • Stated with honest sorry + citation (stated, not yet proved):
      • claim (i) shell_filling_inner_shells — inner shells n < n_val fill completely (needs the Φ₁-monotonicity argument: an inner vacancy reduces Φ₁ more than any valence electron);
      • claim (ii) shell_filling_hund_rule — the ground state maximises singly-occupied valence sites (needs the ee-crossing Φ₁ comparison for parallel vs antiparallel trefoil pairs);
      • claim (iii) shell_filling_lp_strong_duality — the optimal LP primal objective equals the dual objective Z·y₀ (LP strong duality for the electron assignment problem).

    Base ring (§7c) #

    Everything counted here -- occupancies, capacities, singly-occupied sites -- is ℕ, and the only scalars are the LP dual variable y_0 and the primal objective, related by primal_obj = Z * y_0. That needs a natural-number cast and a product, nothing ordered and nothing archimedean, so the LP scalars are a generic [Semiring R]; the substrate evaluation is R := ℝ.

    The module is now entirely pre-archimedean: the three *_unconstrained_false refutation witnesses below were formerly stated at ShellFillingRuleContext ℝ, but their counterexamples live in the ℕ-valued occupancy / capacity / singly fields (and, for the LP conjunct, in 1 ≠ 0), so they are stated over the same generic [Semiring R] — with [Nontrivial R] where 1 ≠ 0 is needed. Each is strictly stronger than its former ℝ form, which it recovers by instantiating R := ℝ. No ℝ remains in the file.

    class QOU.Molecular.ShellFillingRuleContext (R : Type u_2) [Semiring R] :
    Type (max 1 u_2)

    Data of the shell-filling claim for atom (Z, N). All fields are inputs (model data, defining formulas, and the Pauli structural hypothesis); none carries a conclusion of the proposition.

    • Z : ℕ

      Proton number Z.

    • N : ℕ

      Neutron number N.

    • n_val : ℕ

      The valence shell index n_val.

    • occupancy : ℕ → ℕ

      Ground-state occupation count at shell n (the Φ₁-minimising assignment of the Z electron trefoils).

    • capacity : ℕ → ℕ

      Maximum capacity of shell n.

    • capacity_def (n : ℕ) : capacity R n = 2 * n ^ 2

      Defining formula capacity n = 2n² ([def:electron-shell-braid-capacity]).

    • occupancy_le_capacity (n : ℕ) : occupancy R n ≤ capacity R n

      Pauli constraint (structural hypothesis): no shell is occupied beyond its braid capacity.

    • inner_shells_maximised (n : ℕ) : n < n_val R → capacity R n ≤ occupancy R n

      Inner shells are fully occupied due to Φ₁ monotonicity.

    • ValenceConfig : Type

      Admissible valence-shell configurations of the atom.

    • ground : ValenceConfig R

      The ground-state valence configuration.

    • singly : ValenceConfig R → ℕ

      Number of singly-occupied sites of a valence configuration.

    • max_singly : ℕ

      Maximum singly-occupied sites bound.

    • ground_singly_eq_max : singly ground = max_singly R

      Ground state achieves the maximum singly-occupied sites.

    • singly_le_max (c : ValenceConfig R) : singly c ≤ max_singly R

      All configurations respect the maximum singly-occupied sites.

    • y_0 : R

      LP dual variable y₀ (electron chemical potential).

    • primal_obj : R

      Optimal primal objective of the electron assignment LP (the minimal total Φ₁).

    • dual_obj : R

      The dual objective without coefficients.

    • dual_obj_def : dual_obj = ↑(Z R) * y_0

      Definition of dual objective.

    • strong_duality : primal_obj = dual_obj

      Strong duality equates primal and dual objectives. (Needs abstract LP duality infrastructure that does not exist in Mathlib; kept as an honest assumption for models without certificates)

      class QOU.Molecular.ShellFillingLPDuality (R : Type u_2) [CommSemiring R] extends QOU.Molecular.ShellFillingRuleContext R :
      Type (max 1 u_2)

      LP optimality certificate for the electron-assignment LP (§3b-cond model class over ShellFillingRuleContext, bean qou-kkja).

      Claim (iii) — primal_obj = Z·y₀ — is not derivable from ShellFillingRuleContext alone, and that is machine-checked below by shell_filling_lp_strong_duality_unconstrained_false: the base class carries y_0 and primal_obj as unrelated scalars, so a context with Z = 0, y_0 = 0, primal_obj = 1 refutes it.

      This class supplies the LP structure the base class lacks — the assignment variables, the per-site cost, and a dual optimality certificate (stationarity + complementary slackness). Claim (iii) is then derived from those hypotheses by shell_filling_lp_strong_duality_of_certificate, not carried as a field. Nothing here asserts the conclusion: the fields constrain x, cost, slack, y_0 and primal_obj jointly, and the equality falls out of the algebra.

      Generic [CommSemiring R] (§7c) — commutativity is used only to match the Z·y₀ orientation of the existing statement; no ordering and no archimedean structure is required. Note this is the certificate, not a proof that one exists: exhibiting x and slack for a given atom is the separate (open) optimisation problem.
