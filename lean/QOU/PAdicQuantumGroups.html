    Chapter 7 — p-Adic Quantum Observable Universe #

    Formalization of the p-adic and finite-field realisations of the QOU from Chapter 7 of the manuscript.

    LaTeX source: chapters/p-adic-quantum-groups.tex

    Structure #

    1. F-Isocrystal realisation — QOU over ℚ_p via F-isocrystals
    2. Finite-field realisation — QOU over 𝔽_p via fusion categories
    3. Enveloping algebra — Lusztig integral form of U_q(su(2))
    4. Witt vector lifting — from 𝔽_p to ℚ_p via [fred2005]

    References #

    • [lusztig1993] G. Lusztig, Introduction to Quantum Groups, Birkhäuser 1993.
    • [fred2005] L. Fred, PhD thesis, University of Arizona, 2005.

    §1 F-Isocrystal Realisation #

    source
    structure QOU.PAdicQuantumGroups.FIsocrystalData :
    Type (u_1 + 1)

    F-Isocrystal data: the categorical data for a ℚ_p realisation of the QOU. The category C is the category of F-isocrystals (modules over the Dieudonné ring ℚ_p⟨F, V⟩ / (FV − p)); the Frobenius endomorphism plays the role of Levi-form contraction.

    LaTeX: \label{ex:p-adic-realisation}

    • p : ℕ

      The prime p.

    • p_prime : Nat.Prime self.p

      p is prime.

    • carrier : Type u_1

      The carrier type of the F-isocrystal.

    • frobenius : self.carrier → self.carrier

      Frobenius endomorphism φ.

    • verschiebung : self.carrier → self.carrier

      Verschiebung endomorphism V, satisfying F ∘ V = p.

      Type (u_1 + 1)

      ℚ_p Quantum Observable Universe: a QOU realised over a p-adic field, where the substrate parameter is q = p^{−v_p(det φ)}.

      LaTeX: \label{ex:p-adic-realisation}

      • p : ℕ
      • p_prime : Nat.Prime self.p
      • carrier : Type u_1
      • frobenius : self.carrier → self.carrier
      • verschiebung : self.carrier → self.carrier
      • substrate_q : ℝ

        The substrate parameter derived from the Frobenius.

      • q_ge_one : 1 ≤ self.substrate_q

        q ≥ 1 (classicality bound).

      • frobenius_irreducible (x y : self.carrier) : self.frobenius x = x → self.frobenius y = y → x = y

        Irreducibility of the associated F-crystal: the Frobenius endomorphism has at most one fixed point (the zero element).

      • frobenius_surjective (y : self.carrier) : ∃ (x : self.carrier), self.frobenius x = y

        Surjectivity of Frobenius (unit-root condition): every element has a Frobenius pre-image. This encodes [fred2005, Corollary 5.3].

      • fv_comm (x : self.carrier) : self.frobenius (self.verschiebung (self.frobenius x)) = self.frobenius (self.frobenius (self.verschiebung x))

        Frobenius–Verschiebung commutativity under Frobenius: F(V(F(x))) = F(F(V(x))) on the carrier. This is the F-crystal form of strong multiplicativity from [fred2005, Theorem 4.12].

            §4 Witt Vector Lifting (from [fred2005]) #

            source
            theorem QOU.PAdicQuantumGroups.padic_qou_lifts_from_finite_field (ff : FiniteFieldQOU) (_hq : ff.root_order ≠ 1) :
            ∃ (pq : PAdicQOU), pq.p = ff.p

            Witt vector lift of the p-adic QOU: given the 𝔽_p realisation, the formal-groups integration theorem produces a ℚ_p realisation whose Frobenius–Hopf structure is a deformation of the finite-field one.

            The construction uses PUnit as the carrier (witnessing existence) with identity Frobenius/Verschiebung.

            LaTeX: \label{sec:witt-vector-lifting}, \label{def:witt-vector-lift}. Reference: [fred2005, Main Theorem].
