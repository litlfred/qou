    Type u_1

    Context for the Markov-trace (Plancherel) normalization of H_n(q).

    Restated 2026-08-22 (vacuity ledger, proof-no-trivial-true / proof-no-self-assuming-projection). The class previously carried the single field holds : (1 : ℝ) = 1 — provable by rfl, so it constrained no instance, and the theorem below projected it to conclude (1 : ℝ) = 1: vacuous with or without an instance.

    The fields now state the actual categorical input the block names — the Wedderburn block dimensions d_λ, the Plancherel weights y_λ(q), and the normalization identity ∑_λ d_λ · y_λ = 1. The normalization is the lone conditional hypothesis (the Markov-trace normalization of H_n(q), assumed here, not derived).

    • d : ι → ℝ

      The Wedderburn block dimensions d_λ.

    • y : ι → ℝ

      The Plancherel weights y_λ(q).

    • normalization : ∑ i : ι, d i * y i = 1

      Markov-trace normalization for H_n(q): ∑_λ d_λ · y_λ(q) = 1.
