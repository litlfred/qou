    QOU.BraidsAndKnots.YoungDiagramTransposeBridge — the sorted-List ↔ cell-model transpose bridge #

    YoungDiagramKernel states the Δ_λ covariance kernel on the weakly-decreasing List ℕ encoding and proves conjugation-invariance of the content square only by bounded decide (contentSq_conj_invariant_of_le_six, k ≤ 6), noting: "the general (∀ sorted l) statement follows from the sorted-List transpose bijection … that infra is not yet built here." YoungDiagramTranspose proves the transpose parity facts (csq_transpose, csum_transpose) on the abstract cell model Finset (ℕ × ℕ), asserting in prose that the coordinate swap "is realized by YoungDiagramKernel.conj".

    This file builds that missing bridge, sorry-free and for all k:

    • cells l — the cell set {(i,j) : j < l_i} of a list diagram, as a disjoint row biUnion (mem_cells, no sortedness needed);
    • contentSq_eq_csq — the kernel file's contentSq is the cell-model csq (row-by-row re-summation);
    • lt_countP_iff — the staircase equivalence c < #{x ∈ l : r < x} ↔ r < l_c for sorted l (single induction on l);
    • conj_getD — (conj l)_c = #{x ∈ l : c < x} for sorted l (both in- and out-of-range);
    • cells_conj — the bridge: cells (conj l) = transpose (cells l) for sorted l;
    • contentSq_conj / omega3_conj — conjugation-invariance of the content square and of the 3-cycle eigenvalue ω₃ for all sorted l (upgrading the decide-bounded k ≤ 6 lemmas to the general statement the kernel file called for), by transport through csq_transpose.

    Scope (honest): infrastructure only — the kernel sign covariance_kernel_conjecture stays OPEN; indeed YoungDiagramTranspose proves the transpose route cannot sign T₃ (the summand is transpose-even). What this file adds is the exact pairing structure for every k (previously k ≤ 6): the kernel summand is invariant under the genuine list-level conjugation, so summands pair off along λ ↔ λ' with self-conjugate diagrams as fixed points.

    Base ring: ℤ (contents are integers); everything else is ℕ-combinatorics. Standalone library file (no .ts/.md sibling), verified per-file by lean-direct, like its two parents.
