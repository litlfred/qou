    Braid-closure component count is a crossing-sign invariant #

    The number of components of a braid closure is determined by the permutation the braid induces on its strands, and σᵢ and σᵢ⁻¹ induce the same transposition. So the component count cannot see a crossing's sign, and is therefore invariant under every resolution of an unsigned or averaged crossing.

    Why this is worth proving #

    This is the invariant that adjudicates the deuteron's knot assignment (bean qou-e5jf, docs/audits/2026-08-21-deuteron-knot-assignment-adjudication.md). The canonical deuteron mass word atom_braid_word_3A(1,1) is a 23-letter element of H₆(q) whose five averaged crossings σ − h/2 and σ − h(½ − δ/4) are ℂ-linear combinations, not braid-group elements, so the word has no single closure — it has one closure per resolution, and there are 2⁵ = 32 of them.

    Enumeration found all 32 resolutions give a 3-component link while 6₂ and the trefoil are knots (1 component) and the Hopf link has 2. This file replaces that enumeration with a proof: the count is the same for every resolution because it never depended on the signs, so no knot and no 2-component link can be the closure of that word under any crossing convention. That is a scope-(b) structural exclusion in the sense of AGENTS.md §"Before declaring refuted" — the invariant is named and proved here rather than asserted.

    It is also the formalize-first prune of docs/audits/…-adjudication.md §5 step 2: it rules out the entire knot-valued hypothesis class before any census search is run, so a search that does run can be pointed at the right slice.

    What is proved #

    • wordPerm_eq_of_indices_eq — the induced permutation depends only on the sequence of crossing indices, never on their signs. This is the whole content; everything else is a specialisation of it.
    • wordPerm_resolve — consequently, resolving each unsigned crossing by an arbitrary rule f (a function of the letter's position, so distinct crossings may resolve differently) leaves the permutation unchanged.
    • closureComponents_resolve — hence the component count of the closure, defined as the number of orbits of the induced permutation acting on the strands, is likewise unchanged.
    • closureComponents_ne_of_perm_ne — the contrapositive, which is the form the adjudication uses: differing component counts exclude a candidate outright.

    Scope — what is proved, and what is cited #

    The new content is the sign-invariance. What is not proved here, and must not be read as proved, is the identification underneath it:

    • that wordPerm adjacentPerm is the image of the braid word under the standard surjection Bₙ ↠ Sₙ, and
    • that the closure's components correspond to that permutation's orbits.

    Both are standard (Birman §1.2 and §2.2) and are cited, not derived — deriving them needs a formalisation of Bₙ with its relations, which this file deliberately does not build. So wordPerm adjacentPerm is defined to send each crossing to the adjacent transposition regardless of sign, rather than being shown to do so from the braid relations.

    That definitional choice is where a reader should aim their scepticism, so it is worth being explicit about why it is not circular. The claim being formalised is "the map Bₙ → Sₙ cannot see a crossing's sign", and the reason it cannot is that σᵢ and σᵢ⁻¹ have the same image there. wordPerm encodes exactly that by giving g the index and withholding the Bool. Had the definition instead read if letter.2 then g letter.1 else (g letter.1)⁻¹, every theorem below would be false — which is what makes them falsifiable statements about the definition rather than restatements of it.

    Purely combinatorial otherwise: Equiv.Perm (Fin n) and lists. No ring, no ℝ, no archimedean construct, so §7c's base-ring wall is not approached. The statements are generic in the index type where possible.

    Braid words are modelled exactly as the corpus already models them — QOU.Archimedean.BraidWord n is by definition List (Fin (n - 1) × Bool) with the Bool recording the sign — so these lemmas apply to it without a conversion. That type is not imported here, to keep the import cone off the matrix/Hecke machinery this argument does not use.

      §2 Resolving unsigned crossings #

      An unsigned word is a bare list of indices; a resolution chooses a sign for each crossing. The rule f : ℕ → Bool is indexed by position, so different crossings may be resolved differently — the 2⁵ resolutions of the deuteron mass word are exactly the fs on its five averaged letters.
