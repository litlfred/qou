    The canonical class-angle bijection: A₅ irreps → icosahedral conjugacy-class angles #

    The s5-so3 keystone's angle half asks for the map from the five A₅ irreps {A, T₁, T₂, G, H} to the five icosahedral rotation conjugacy-class angles {0°, 72°, 120°, 144°, 180°} (the orders of I ⊂ SO(3): identity, 5-fold, 3-fold, 5-fold, 2-fold). The merged geometric build (BringFiberActionInstance.lean, PR #3093) discharges BringFiberAction.five_distinct_classes with the continuous Reeb phases θ_λ = arccos(χ_λ(C₅)/dim_λ) ∈ {0°, 57.4°, 90°, 101.9°, 104.5°} — distinct, but not the icosahedral class angles. This file pins the canonical class-angle bijection and proves it is uniquely forced by three structural properties of the A₅ character table.

    The A₅ character table (rows = irrep, cols = class [e, 2A, 3A, 5A, 5B]) #

    irrep e 2A (180°) 3A (120°) 5A (72°) 5B (144°)
    A 1 1 1 1 1
    T₁ 3 −1 0 φ −1/φ
    T₂ 3 −1 0 −1/φ φ
    G 4 0 1 −1 −1
    H 5 1 −1 0 0

    with φ = (1+√5)/2, −1/φ = (1−√5)/2. The zero pattern (the only character datum used here — no √5, so the determination is pure finite combinatorics): T₁,T₂ vanish on 3A; G vanishes on 2A; H vanishes on 5A and 5B; A never vanishes.

    The three properties that force the map (uniqueness) #

    1. (P1) Character-nonvanishing. An irrep is never assigned the angle of a class on which its character is zero (the realizing rotation must act nontrivially on the irrep). This alone cuts the 5! = 120 bijections to 40.
    2. (P2) Galois 5-fold chirality. The outer automorphism √5 ↦ −√5 simultaneously swaps the chirality pair T₁ ↔ T₂ and the two 5-cycle classes 5A ↔ 5B (72° ↔ 144°). χ_{T₁} takes the golden value φ (the larger root) on 5A, pinning T₁ ↦ 5A (72°) and its partner T₂ ↦ 5B (144°). This is the chirality pair of the keystone five-fold 1+1+1+2 = 5 (KeystoneFiveFoldStructure.lean). Cuts 40 → 4.
    3. (P3) Trivial-to-identity. The trivial rep A maps to the identity class e (0°). Cuts 4 → 1.

    The unique survivor is A ↦ 0°, T₁ ↦ 72°, G ↦ 120°, T₂ ↦ 144°, H ↦ 180°. The historic G-vs-T₂ tie is resolved structurally: G ↦ 120° is forced (after A,T₁,T₂ are placed, G must avoid 2A where χ_G = 0, leaving only 3A); T₂ ↦ 144° by the Galois twist. This is not the SO(3)-tower appearance order (T₂ ↦ 180°, G ↦ 144°) — appearance order and the canonical class map genuinely disagree, and the character table picks the latter.

    Anti-tautology #

    The angles here come only from the classical A₅ character table (zero pattern + Galois action) — they carry no q₀ dependence. The MTC weights W_λ = d_q²/D² (residual (i)) are the separate q₀-Plancherel data. So this bijection is not a re-naming of W_λ: angles and weights are independent inputs, exactly the structure a genuine geometric realization should have.

    Scope (honest) #

    This pins and proves-unique the class-angle half of the keystone (conj:s5-so3-fiber-action), upgrading the Reeb-phase #3093 instance to the actual icosahedral class angles and making the owner-gated geometric derivation falsifiable (any Bring-quintic automorphism derivation must reproduce {0,72,120,144,180}). It does not close residual (i) (the W_λ = d_q²/D² Plancherel/MTC obligation), and it does not re-derive Bring's quintic automorphism from scratch — P1–P3 are read off the published A₅ character table.

    Base ring (§7c): the determination is pure finite combinatorics over the inductive A5Irrep / IcoClass (decide-verifiable); the only ℝ appears in the optional BringFiberAction-shaped furnishing at the end, where the SO(3) rotation angle is intrinsically real.

                    Uniqueness — the three structural properties force the canonical map. Any class assignment f that is character-nonvanishing (P1), Galois 5-fold chiral (T₁ ↦ c5a, T₂ ↦ c5b, P2), trivial-to-identity (A ↦ e, P3), and injective, equals canonicalClassMap. In particular the G ↦ c3 / H ↦ c2 split (the G-vs-T₂ tie) is forced: with A, T₁, T₂ placed, G must avoid c2 (χ_G = 0 there, by P1) and e, c5a, c5b (already taken, by injectivity), leaving only c3; then H lands on the last free class c2.
