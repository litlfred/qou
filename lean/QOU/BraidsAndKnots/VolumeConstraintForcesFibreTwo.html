    The volume constraint as a dimension statement #

    source
    def QOU.BraidsAndKnots.exteriorSquareDim (N : ℕ) :
    ℕ

    dim Λ²V for a fibre V of dimension N.

    Stated combinatorially, exactly as RowCapObstruction states dim V_λ for the three λ ⊢ 3 channels (weylDimSym, weylDimMixed, weylDimAlt) — the same N, the same idiom, so the two constraints on it compose without a translation step.

      theorem QOU.BraidsAndKnots.exteriorSquareDim_ne_zero_iff (N : ℕ) :
      exteriorSquareDim N ≠ 0 ↔ 2 ≤ N

      Weak reading of condition (v): ε is onto.

      If Λ²V → 𝟙 hits its target then Λ²V is nonzero, which says only N ≥ 2. Recorded to make precise how much of the volume constraint is not enough: this reading admits every fibre of rank at least two, the colour fibre N = 3 included.

      theorem QOU.BraidsAndKnots.exteriorSquareDim_eq_one_iff (N : ℕ) :
      exteriorSquareDim N = 1 ↔ N = 2

      Strong reading of condition (v): ε is an isomorphism Λ²V ≅ 𝟙.

      C(N,2) = 1 has the unique solution N = 2: below it the exterior square vanishes, above it the exterior square is at least three-dimensional and can carry no non-degenerate map to a one-dimensional unit.

      This is the rank statement the D-forcing chain needs, and it comes from the framework's own definition rather than from thm:su2-emergence.

      theorem QOU.BraidsAndKnots.exteriorSquareDim_three_ne_one :
      exteriorSquareDim 3 ≠ 1

      The volume constraint excludes the colour fibre.

      At N = 3 the exterior square is three-dimensional, so condition (v) under the strong reading fails. This is the formal counterpart of the observation in bean qou-n1dj that the mass chain does not inherit the eightfold chapter's N = 3 construction: the two channels are constrained by the same axiom to different ranks, so no re-tuning connects them.

      theorem QOU.BraidsAndKnots.weak_volume_reading_admits_three :
      exteriorSquareDim 3 ≠ 0 ∧ exteriorSquareDim 3 ≠ 1

      The weak reading does not suffice — stated, not assumed.

      exteriorSquareDim_ne_zero_iff gives 2 ≤ N, and N = 3 satisfies it. The class MassTraceIsFibreCategorical admits an instance at N = 3 with a nonzero alternating weight (weightAlt_ne_zero_at_three, proved in the sibling file), so under the weak reading the alternating channel need not vanish and nothing forces convention D.

      This is the anti-vacuity check for the distinction this file draws: the two readings of condition (v) are genuinely different in consequence, not two phrasings of one thing.
