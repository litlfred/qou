    QOU.BraidsAndKnots.M1DescentDPPConvergence — the cited external inputs to M₁ > 0, as a Lean class #

    M₁ = Cov_Planch(Σ_□ h, Σ_□ c²) > 0 for all n is the sole open input of the Δ_λ super-exponential growth bound (bean qou-k5r5, epic qou-x631). The Cauchy–Schwarz reduction (YoungDiagramKernelCSMargin.lean, PR #5896) makes it sufficient that the (CS) margin m(n) = ρ_P(n) − σ_D(n)/σ_A(n) is positive, and the leading order is settled:

    • ρ_P(n) → ρ_P∞ = 2√6/5 (CSMarginCorrelationConstant.csMargin_rho_eq, sorry-free),
    • σ_D(n)/σ_A(n) → √(V_D/V_A) = 0.67961…, V_A = 8/(9π²), V_D = 0.041597… (audit 2026-08-29-covariance-kernel-M1-po72-leading-constants.md, PR #5969),
    • leading margin m∞ = 0.300186 > 0, and m(n) > 0 exactly for 4 ≤ n ≤ 40 (finite_n_cs_margin.py).

    What remains is an effective finite-n statement turning these limits into positivity for every n. This file formalizes the external analytic inputs that supply it, as a §3b-cond conditional class — content-bearing (Filter.Tendsto to the exact limits plus the strict leading gap), cited, and deliberately without an instance: the class is the honest carrier of the open input, and the theorems below derive the eventual (CS) margin — hence eventual M₁ > 0 — from it by a sorry-free Filter.Tendsto argument.

    The cited results (see folio/schema/references.ts, all in library/):

    • [ivanov-olshanski2003] — Kerov's CLT for the Plancherel measure: the limiting (co)variances are Σ_k f̂_k ĝ_k / k. Gives the limits ρ_P∞, √(V_D/V_A).
    • [borodin-okounkov-olshanski2000] — the descent set is a determinantal point process with the discrete Bessel kernel; the content statistics are its linear statistics. Bulk sine-kernel limit (Thm 3, rate-free); Toeplitz structure (Rem 1.6).
    • [johansson2001] — Lemma 3.9: explicit super-exponential Bessel tail bound past the edge (the Olver-free tail half, tail_bulk_split.py); Lemma 3.8: de-Poissonization with explicit C/N².
    • [gorbunov2024] — Berry–Esseen rate for linear statistics of the Bessel-kernel DPP (Kac–Akhiezer + Borodin–Okounkov Toeplitz): the machinery for the bulk rate, i.e. what upgrades the qualitative Tendsto below to an explicit crossover N₀. That N₀, with the exact table for n < N₀, closes all-n via YoungDiagramKernelCSMargin.m1_pos_all_of_base_and_tail.

    This is NOT a proof of M₁ > 0. Per the anti-laundering discipline, axiomatizing a cited result as a class is assuming it, not proving it — the class has no instance, and the bulk-rate step (discrete Plancherel descent variance) remains genuinely open. What is sorry-free here is the derivation of eventual positivity from the assumed convergence, which is real Mathlib topology.

    §7c: this is the archimedean layer (ℝ, √, ordered limits), so ℝ is warranted.

    class QOU.BraidsAndKnots.M1DescentDPPConvergence.DescentDPPMarginConvergence (rhoP sigRatio : ℕ → ℝ) (rhoInf sigRatioInf : ℝ) :
    Prop

    Conditional class (cited external input): the descent-DPP (CS)-margin ingredients converge to their exact leading limits, with a strictly positive leading gap.

    Parameterized by the finite-n correlation rhoP = Corr(Σ|c|, ω₃)(n), the finite-n ratio sigRatio = σ_D(n)/σ_A(n), and their limits. The three fields carry genuine content:

    • rhoP_tendsto — ρ_P(n) → ρ_P∞. Ref: [ivanov-olshanski2003] (limit) · [borodin-okounkov-olshanski2000] (descent DPP / bulk kernel).
    • sigRatio_tendsto — σ_D(n)/σ_A(n) → √(V_D/V_A). Ref: [johansson2001] (tail Lemma 3.9 + de-Poisson Lemma 3.8) · [gorbunov2024] (bulk rate machinery).
    • leading_margin_pos — √(V_D/V_A) < 2√6/5, i.e. m∞ > 0 (CSMarginCorrelationConstant.csMargin_rho_eq; V_D < 64/(75π²)).

    No instance is provided: an instance would assert the open bulk-rate result.

Because π cancels in the square, this is exactly V_D < 64/(75π²) — and that bound is proved rigorously (certified interval partial sum + explicit analytic tail majorant, wlambda_covariance_epic_M1_VD_ceiling_rigorous.py: V_D < 0.0415975 < 0.0864607). This lemma is the Lean reduction: given V_A = 8/(9π²), sigRatioInf² = V_D/V_A, rhoInf² = 24/25 (CSMarginCorrelationConstant.csMargin_rhoSq_eq), 0 ≤ rhoInf, and the ceiling V_D < 64/(75π²), the strict inequality follows by π-cancellation in the square. Unlike the two Tendsto fields, this one is NOT gated on the open bulk kernel rate — it is a fact about the exact limit constants, now discharged modulo the certified numeric ceiling.
