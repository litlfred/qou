    QOU.BraidsAndKnots.YoungDiagramKernel — elementary Lean infrastructure for the Δ_λ covariance kernel #

    The Δ_λ growth bound (#3939) reduces (via #3959) to the covariance kernel Cov_Planch(f^λ, Σ_□ c(□)²) ≤ 0, equivalently the elementary content form

    ∀ k,  Σ_{λ ⊢ k} (f^λ)³ · (Σ_□ c(□)² − C(k,2))  ≤  0,

    with f^λ = number of standard Young tableaux (hook-length dimension) and c(□) = content. Stating this in Lean does not need S_k-character theory or free probability (which Mathlib lacks) — only the hook-length dimension and the content sum, which this file defines self-contained on List ℕ (weakly-decreasing parts). The full character / free-cumulant framing (Σ̂₃ = R₄ + R₂, E_Planch[R₄] = −k) that situates the kernel in Biane–Śniady / Kerov-CLT theory is verified computationally in computations/deltalambda/wlambda_covariance_kernel_frontier.py.

    The kernel itself is OPEN (a Biane–Śniady / Kerov-CLT character-ratio anti-correlation), carried here as an honest sorry-conjecture (§3b) with the elementary statement machine-checkable as well-typed. Verified k ≤ 30. The sorry is a conjecture, not a proof gap.

                                    theorem QOU.BraidsAndKnots.YoungDiagramKernel.secondMomentKernel_eq_zero_of_le_seven (k : ℕ) (hk : 3 ≤ k) (hk' : k ≤ 7) :
                                    secondMomentKernel k = 0

                                    The dim²-weighted 3-cycle content-spread total VANISHES (Lean-verified, 3 ≤ k ≤ 7): Σ_{λ⊢k} (f^λ)² ω₃(λ) = 0. This is k!·E_Planch[ω₃] = 0 (the Plancherel content mean is C(k,2)) — an exact identity, not conjectural. It isolates the open kernel as the first-order response to the extra dimension factor: cov(k) = Σ (f^λ)³ ω₃ = k!·Cov_Planch(f^λ, ω₃), a genuine dimension-tilt covariance (Ivanov–Olshanski Prop 5.1; the dim³ weight has one surplus dim beyond column orthogonality, so — unlike this dim² total — it lies outside the polynomial-function algebra A).

                                    Why 3 ≤ k ≤ 7 is a Lean artifact, and exactly what would remove it. The identity holds for every k, and the shortest route is Jucys–Murphy rather than Prop 5.1. Writing X_i = Σ_{j<i} (i j), the JM theorem gives that Σ_i X_i² is central, acting on the irrep λ by the eigenvalue Σ_□ c(□)² (each standard-tableau basis vector picks up c(□)² box by box). Expanding the square, (i j)² = 1 contributes C(k,2)·1, and every cross term (i j)(i l) with j ≠ l is a 3-cycle:

                                    Σ_i X_i² = C(k,2)·1 + (3-cycle class sum).

                                    Reading off eigenvalues, Σ_□ c(□)² = C(k,2) + const·ω^λ_{(3)}, so Σ_λ (f^λ)² ω₃(λ) ∝ Σ_λ f^λ χ^λ(3-cyc) = 0 by column orthogonality — the whole identity is that one vanishing, with no asymptotics anywhere.

                                    Lifting interval_cases … decide to a general-k proof therefore needs exactly three imports from the Specht/S_n epic (sp00), and nothing else: (i) the JM elements with their content eigenvalues, (ii) centrality of Σ_i X_i^m, (iii) column orthogonality Σ_λ f^λ χ^λ(σ) = 0 for σ ≠ 1. That is the concrete sp00 dependency for this lemma; the k ≤ 7 bound is a decide budget, not a mathematical frontier. (Recorded 2026-08-15 while attacking qou-v8t7; the reduction is standard, the point here is naming the three inputs so sp00 can be aimed at them.)

                                    theorem QOU.BraidsAndKnots.YoungDiagramKernel.contentSq_conj_invariant_of_le_six (k : ℕ) (hk : k ≤ 6) (l : List ℕ) :
                                    l ∈ partsOf k → contentSq (conj l) = contentSq l

                                    Content-square is conjugation-invariant — verified for all λ ⊢ k, k ≤ 6 (decide): contentSq (conj λ) = contentSq λ. Reason: the transpose bijection on cells (i,j) ↦ (j,i) sends the content j−i to i−j, and (i−j)² = (j−i)². Consequence: ω₃ is conjugation-symmetric, hence U-shaped (large at both the row and column extremes, small in the balanced middle) — which is exactly why no monotone / FKG / comonotone certificate for the kernel can work. The general (∀ sorted l) statement follows from the sorted-List transpose bijection cellSum (conj l) f = cellSum l (fun i j => f j i) (via len (conj l) = l.headD 0, conj l |>.getD r 0 = #{i : l.getD i 0 > r}, and the staircase equivalence c < (conj l).getD r 0 ↔ r < l.getD c 0); that infra is not yet built here.
