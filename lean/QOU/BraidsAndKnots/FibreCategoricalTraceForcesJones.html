    class QOU.BraidsAndKnots.MassTraceIsFibreCategorical (R : Type u_2) [CommRing R] (N : ℕ) :
    Type u_2

    The one open premise, axiomatised: the mass-channel trace is the categorical trace of the fibre action on V^{⊗3}.

    An instance records the three Frobenius weights (y_(3), y_(2,1), y_(1³)) of the mass-channel trace on H₃(q), together with the two support properties that follow from its being the categorical trace of the action of a fibre of dimension N:

    • weight*_eq_zero_of_dim_eq_zero — row-cap support. Quantum Schur–Weyl duality decomposes V^{⊗3} = ⊕_{λ ⊢ 3} S^λ ⊗ V_λ with the row cap ℓ(λ) ≤ N; a partition violating the cap has dim V_λ = 0 and therefore contributes no summand at all. A trace computed from the fibre action can put no weight on a channel that is absent from the module it acts on.

    • weightMixed_ne_zero_of_dim_ne_zero — non-degeneracy / faithfulness. Conversely a channel the fibre genuinely supplies is genuinely seen: its weight is nonzero. This is faithfulness on the surviving (Temperley–Lieb) part, and it is what excludes the degenerate root z = q of the Temperley–Lieb condition (markovWeights_degenerate_root).

    Both properties are independent of the deformation parameter, because the row cap constrains dim V and quantisation does not change dimensions.

    What is not asserted. The weight magnitudes. At q ≠ 1 these are quantum dimensions rather than the classical Weyl dimensions weylDim*, so pinning them to the classical values would be false. Nothing here mentions q, the Ocneanu parameter, or the Jones weight vector — those appear only in the conclusions of the theorems below.

    An instance of this class is not a proof of the premise; it is the premise, named. Bean qou-n1dj is open on whether the mass channel admits one.

    • weightSym : R

      Frobenius weight of the symmetric channel λ = (3).

    • weightMixed : R

      Frobenius weight of the mixed channel λ = (2,1); this is the Temperley–Lieb / two-row block.

    • weightAlt : R

      Frobenius weight of the alternating channel λ = (1³); this is the block the row cap kills at N = 2.

    • weightSym_eq_zero_of_dim_eq_zero : Eightfold.RowCapObstruction.weylDimSym N = 0 → weightSym N = 0

      Row-cap support in the symmetric channel.

    • weightMixed_eq_zero_of_dim_eq_zero : Eightfold.RowCapObstruction.weylDimMixed N = 0 → weightMixed N = 0

      Row-cap support in the mixed channel.

    • weightAlt_eq_zero_of_dim_eq_zero : Eightfold.RowCapObstruction.weylDimAlt N = 0 → weightAlt N = 0

      Row-cap support in the alternating channel — the field that, at N = 2, supplies the Temperley–Lieb condition y_(1³) = 0.

    • weightMixed_ne_zero_of_dim_ne_zero : Eightfold.RowCapObstruction.weylDimMixed N ≠ 0 → weightMixed N ≠ 0

      Non-degeneracy: a mixed channel the fibre supplies is genuinely carried. Equivalently, faithfulness on TL₃.

      (q + qi) ^ 2 * MassTraceIsFibreCategorical.weightMixed N = 1 ∧ MassTraceIsFibreCategorical.weightSym N = 1 - 2 * MassTraceIsFibreCategorical.weightMixed N ∧ z * (q + qi) = q ^ 2

      Conditional theorem — the fibre-categorical premise plus dim V = 2 forces convention D.

      Let the mass-channel trace satisfy the premise MassTraceIsFibreCategorical (the categorical trace of the fibre action on V^{⊗3}; the one open input), let the fibre be two-dimensional (hN : N = 2, supplied by thm:su2-emergence), and let the three Markov equations hold against the H₃(q) q-character table on the class representatives 1, σ₀, σ₀σ₁,

      tr 1 = 1, tr σ₀ = z, tr σ₀σ₁ = z²

      (hypotheses hnorm, hsigma, hsigmasigma; qi is q⁻¹, constrained by hqi : q * qi = 1, so the statement is division-free).

      Then the weight vector and the Ocneanu parameter are completely determined:

      [2]_q² · y_(2,1) = 1, y_(3) = 1 − 2 y_(2,1), z · [2]_q = q²,

      with [2]_q = q + qi. Solving the first gives y = ([4]_q/[2]_q³, 1/[2]_q², 0) — the Jones / Temperley–Lieb closure, convention D. Convention C, whose Ocneanu parameter satisfies z·[2]_q ≠ q², is thereby excluded.

      This is an implication, not a resolution. The conclusion is derived — from the class fields (which mention neither q nor z nor D), the proved row-cap obstruction, and the proved Markov-trace uniqueness theorem. What it buys is that the D-vs-C question now rests on exactly one named, unproved premise instead of on a numerical coincidence with CODATA. Whether the mass channel satisfies that premise is bean qou-n1dj, and it is open.

        The conditional is not vacuous — convention D is a model #

        A conditional theorem whose antecedent is unsatisfiable proves nothing. The next two declarations rule that out: at N = 2 the premise is satisfiable together with all three Markov equations, and the model realising it is convention D itself. t plays the role of [2]_q⁻¹ = 1/(q + q⁻¹), carried as an element constrained by h2 : (q + qi) * t = 1 so the construction stays division-free (§7c).
