    Jet-order valuation of a graded object #

    The valuation = the LOWEST degree carrying nonzero dimension = the number of
leading zeros.  This is exactly what the GS jet-order structure reads off a
graded object: the bottom grade `n(λ)` at which the block enters.  It is
manifestly degree-BLIND above the bottom (any rearrangement of the nonzero
tail leaves it fixed).

      THE SHARP MECHANISM: at the valuation grade the honest object reads 1, not dim #

      The single-degree object puts `dim V_λ` at degree `n(λ)`; the honest
fake-degree object puts `1` (the monic leading coefficient of `f_λ(q)`) there.
So the valuation cannot be "read off × dim" to recover the concentrated object:
at its own grade the natural object has magnitude `1`, and the missing
`dim − 1` sits spread across higher grades.  This is WHY a valuation cannot
force concentration.

      theorem QOU.BraidsAndKnots.jetorder_valuation_cannot_force_single_degree :
      ∃ (single : PartitionOf5 → List ℕ) (fake : PartitionOf5 → List ℕ), (∀ (p : PartitionOf5), valuation (single p) = valuation (fake p)) ∧ (∀ (p : PartitionOf5), (single p).sum = (fake p).sum) ∧ (∀ (p : PartitionOf5), p.dim ≠ 1 → gradedEuler (single p) ≠ gradedEuler (fake p)) ∧ ∀ (p : PartitionOf5), gradedEuler (single p) = p.deltaLambda

      THE CRUX (limitative — bean qou-71ma). There exist two graded assignments single = G_λ and fake = H_λ such that:

      • they carry the SAME jet-order VALUATION n(λ) at every block (val) — the bottom grade the GS jet-order structure supplies; • they carry the SAME ungraded Wedderburn dimension dim V_λ at every block (dim) — the datum the confinement SDP / T_w / tr_M read (#4570); • yet their signed Euler characteristics DIFFER on every non-trivial block (differ), with only the concentrated object equal to Δ_λ (is_delta).

      Since the promoted a-function supplies exactly (valuation, ungraded dim) and both objects share BOTH, no functional of that data — in particular the GS jet-order valuation — can distinguish, hence cannot FORCE, the single-degree (top-cohomology) concentration. The concentration H^{top}(𝓑_λ) = V_λ is a genuinely INDEPENDENT input. This is the NEGATIVE answer to qou-71ma: the jet-order valuation supplies the grade VALUE, never the single-degree SELECTION. Companion (ungraded side): #4570 sdp_cannot_force_top_degree.

      Degree-blindness is generic (not an n = 5 artifact) #

      A valuation reads only the bottom grade; knowing it, together with the total
(ungraded) dimension, never pins the signed Euler characteristic.  Witnesses:
`[d+2]` vs `[d+1, 1]` — same valuation `0`, same total `d+2`, Euler chars
`d+2` vs `d` differ, for every `d`.
