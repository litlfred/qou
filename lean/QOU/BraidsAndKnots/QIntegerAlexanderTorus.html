    QOU.BraidsAndKnots.QIntegerAlexanderTorus — q-integer differences are torus-knot Alexander polynomials #

    Bean qou-rftd (T8), epic qou-8lxd.

    The symmetric quantum integer difference [n]_q − [n−1]_q equals the Alexander polynomial of the (2, 2n−1) torus knot. This is the cheapest genuine bridge between the framework's q-side (quantum integers, which appear throughout the Hecke machinery — quantum dimensions, [3]_q! in the Borromean factor, Wenzl genericity) and its knot side.

    Observed phenomenologically by Gavrilik in the U_q(su_n) hadron mass-sum-rule programme, where it is used to label hadron flavours by knot invariants -- Ref: [gavrilik2001] https://arxiv.org/abs/hep-ph/0103325

    The identity itself is pure algebra over ℤ[q^{±1}] and is proved here sorry-free and unconditionally, independent of any phenomenological use. Nothing about hadron masses, flavour labelling, or the Cabibbo angle is asserted or assumed; those claims carry their own (separately assessed) epistemic status and are not imported by this file.

    Statement #

    Write everything in framed (Laurent-free) form so the file lives over a generic CommRing R with no inverses and no archimedean input (§7c). The symmetric quantum integer

    [n]_q = q^{n−1} + q^{n−3} + ⋯ + q^{−(n−1)}

    satisfies q^{n−1} · [n]_q = ∑_{i<n} q^{2i} =: framedQInt q n, and

    q^{n−1} · ([n]_q − [n−1]_q) = framedQInt q (n+1) − q · framedQInt q n (with the index shift n ↦ n+1).

    The two results are:

    • framedQInt_sub_eq_alexanderTorus2 — the difference is the normalized Alexander polynomial Δ_{T(2,2n+1)}(q) = ∑_{j < 2n+1} (−q)^j;
    • one_add_mul_alexanderTorus2_odd — the division-free closed form (1 + q) · Δ_{T(2,2n+1)}(q) = 1 + q^{2n+1}, i.e. Δ_{T(2,m)}(q) = (1 + q^m)/(1 + q), the classical Alexander polynomial of the (2,m) torus knot for odd m.

    Why this matters to the framework #

    n = 1 gives T(2,3) — the trefoil, which is the framework's electron knot — with Δ = 1 − q + q². So the very first instance of the identity lands on the knot the framework already uses, with no tuning. Note this is a structural observation, not a derivation of anything: the identity holds over any commutative ring and says nothing on its own about masses.

    Two adjacent facts are recorded as separate results rather than folded in, because each is a genuinely different claim:

    • framedQInt_sub_eq_zero_iff_alexander_root — the vanishing locus [n]_q = [n−1]_q is exactly the root set of Δ_{T(2,2n+1)}.
    • alexanderTorus2_bar_symm — Δ is bar-symmetric, Δ(q) = q^{m−1} Δ(q⁻¹) in framed form, matching the bar-involution the framework uses elsewhere.

        theorem QOU.BraidsAndKnots.QIntegerAlexanderTorus.alexanderTorus2_bar_symm {R : Type u_1} [CommRing R] (q : R) (n : ℕ) :
        ∑ j ∈ Finset.range (2 * n + 1), (-1) ^ j * q ^ (2 * n - j) = alexanderTorus2 q (2 * n + 1)

        Bar symmetry in framed form. Δ_{T(2,m)} is palindromic up to sign: q^{m−1} · Δ(q⁻¹) = Δ(q) unframes to the bar-involution symmetry Δ(q) = Δ(q⁻¹) for odd m. Stated here framed, as ∑_{j<m} (−1)^j q^{m−1−j} = ∑_{j<m} (−1)^j q^j for odd m.
