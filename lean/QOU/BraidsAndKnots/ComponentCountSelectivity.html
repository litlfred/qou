    def QOU.BraidsAndKnots.ComponentCountSelectivity.jonesAtOne {R : Type u_1} [Ring R] (c : ℕ) :
    R

    The q = 1 value of the Jones polynomial, as a function of the component count c ≥ 1. This is a DEFINITION of the quantity whose behaviour we study, not a claim that the Jones polynomial equals it; that is Jones' theorem and is cited, not reproved.

      theorem QOU.BraidsAndKnots.ComponentCountSelectivity.jonesAtOne_eq_one_iff {R : Type u_1} [Ring R] [LinearOrder R] [IsStrictOrderedRing R] {c : ℕ} (hc : 1 ≤ c) :
      jonesAtOne c = 1 ↔ c = 1

      The selectivity theorem. Among links, the q = 1 invariant reaches the unknot's value 1 exactly when the link has a single component.

      This is the mathematical content of "the q = 1 layer is transparent to c = 1 objects and to nothing else". The forward direction is the one that does work: it says no multi-component link can hide at the interface.

      theorem QOU.BraidsAndKnots.ComponentCountSelectivity.no_separation_of_equal_component_count {R : Type u_1} [Ring R] [LinearOrder R] [IsStrictOrderedRing R] (f : ℕ → R) {c c' : ℕ} (h : c = c') :
      f c = f c'

      The negative result, and it is the load-bearing one. A quantity that is a function of the component count alone cannot separate two species that share a component count.

      In the framework's own assignments the proton and the neutron are both the Borromean linking of three quarks, so c = 3 for each. Hence no invariant of this shape distinguishes them, and in particular the q = 1 collapse cannot be a charge-separation mechanism: it does not see charge. Measured statement of the same fact, with the corpus citations for the assignments, in the probe named above.
