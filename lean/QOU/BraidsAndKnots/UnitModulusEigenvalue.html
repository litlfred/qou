    Unit-modulus eigenvalues on V_{(2,1)} and Borromean fixed point #

    Main results #

    1. Hecke determinant: det(σ) = q·(−q⁻¹) = −1 on every 2-dim Wedderburn block (the eigenvalues of σ are q, −q⁻¹).
    2. Even-length determinant: a product of 2k generators has det = (−1)^{2k} = 1, so its eigenvalues satisfy λ₁λ₂ = 1 (the unit-circle condition together with |tr| ≤ 2).
    3. Borromean fixed point: the Borromean braid β_Bor = (σ₁σ₂⁻¹)³ has the degenerate eigenvalue λ = −1 on V_{(2,1)}.

    Disposition (integrity) #

    The previous version carried two def … : True := trivial placeholders (borromean_trace_21_eq_neg_two, all_positive_trace_positive) — vacuous, and forbidden by AGENTS.md §1a. They are removed. The genuine algebraic content is proved: hecke_generator_det_neg_one (generic field), even_braid_det_one, and borromean_eigenvalue_neg_one (now concludes λ = −1, not merely the discriminant). The rep-theory inputs those placeholders gestured at — that tr_{(2,1)}(β_Bor) = −2 (Hoefsmit seminormal rep / BorromeanMarkovTrace.lean closed form) and that all-positive braids have 0 < tr < 2 — are not formalised here (they need the Hoefsmit matrix infrastructure); they enter borromean_eigenvalue_neg_one as the explicit hypotheses tr = −2, det = 1, so the eigenvalue conclusion is a genuine conditional on those inputs, not a vacuous assertion.

    Base ring (§7c) #

    Neither result needs a field; both are stated over the weakest class that admits them, and the previous [Field R] is gone.

    • hecke_generator_det_neg_one is a units identity: the eigenvalue −q⁻¹ only makes sense when q is invertible, so q is carried as a unit q : Rˣ over a CommRing and the inverse is Units.inv, not field division. Over a field this is exactly the old q ≠ 0 hypothesis, so no generality is lost and ℤ[q, q⁻¹] (where q is a unit) is now in scope.
    • borromean_eigenvalue_neg_one needs only that (λ+1)² = 0 ⇒ λ+1 = 0, i.e. no zero divisors — [CommRing R] [NoZeroDivisors R]. A field is one such ring, but so is ℤ[q, q⁻¹]. The hypothesis is genuinely required: over ZMod 4, λ = 1 satisfies (λ+1)² = 0 yet λ ≠ −1.

    Only the integer determinant (−1)^{2k} uses ℤ. No archimedean structure is needed — |λ| = 1 is the narrative reading of λ₁λ₂ = 1 with |tr| ≤ 2, not a Lean hypothesis here.

    Hecke generator determinant #

    source
    theorem QOU.BraidsAndKnots.hecke_generator_det_neg_one {R : Type u_1} [CommRing R] (q : Rˣ) :
    ↑q * -↑q⁻¹ = -1

    The Hecke relation σ² = h·σ + 1 forces det(σ) = −1 on every 2-dimensional Wedderburn block: the eigenvalues of σ are q and −q⁻¹ (roots of x² − h·x − 1), with product q·(−q⁻¹) = −1.

    §7c: a units identity over a plain CommRing — the second eigenvalue is only defined when q is invertible, so q is carried as q : Rˣ and the inverse is Units.inv. Over a field this is exactly the old q ≠ 0; unlike the field version it also applies over ℤ[q, q⁻¹], where q is a unit but no division is available.

    Unit modulus for even-length braids #

    source
    theorem QOU.BraidsAndKnots.even_braid_det_one (n : ℕ) :
    (-1) ^ (2 * n) = 1

    A product of an even number 2k of Hecke generators on V_{(2,1)} has determinant (−1)^{2k} = 1 (each generator contributes −1). Together with |tr| ≤ 2 this is the unit-circle condition λ₁λ₂ = 1.

    Borromean eigenvalue #

    source
    theorem QOU.BraidsAndKnots.borromean_eigenvalue_neg_one {R : Type u_1} [CommRing R] [NoZeroDivisors R] (lam tr det : R) (h_tr : tr = -2) (h_det : det = 1) (h_root : lam ^ 2 - tr * lam + det = 0) :
    lam = -1

    Borromean eigenvalue is −1. If λ is an eigenvalue of ρ_{(2,1)}(β_Bor) — a root of the 2×2 characteristic polynomial λ² − tr·λ + det with the Borromean data tr = −2, det = 1 — then λ = −1 (the degenerate fixed point).

    The characteristic polynomial is (λ + 1)², so the only structure the argument uses is the absence of zero divisors: (λ + 1)² = 0 ⇒ λ + 1 = 0 ⇒ λ = −1. §7c: stated over [CommRing R] [NoZeroDivisors R] rather than [Field R] — the weakest class that admits it. NoZeroDivisors is not removable: over ZMod 4, λ = 1 satisfies λ² + 2λ + 1 = 0 but λ ≠ −1. The data tr = −2 is the Hoefsmit / Markov-trace input (carried as a hypothesis, not asserted here); det = 1 is even_braid_det_one for the 6-generator word.
