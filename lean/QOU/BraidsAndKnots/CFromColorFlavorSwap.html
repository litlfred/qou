    QOU.BraidsAndKnots.CFromColorFlavorSwap — D6 charge conjugation as color-sheet flavor swap #

    §3b-cond class axiomatisation for content block conj:c-from-color-flavor-swap (D6 charge-conjugation closure), replacing the former sibling stub's vacuous holds : Prop placeholder.

    Honest split — proved vs conjectural. The block's three claims separate cleanly:

    1. C is an involution — PROVED sorry-free below (NucleonColorContent.conj_involutive; proton ↦ antiproton, neutron ↦ antineutron by rfl).
    2. C commutes with the chirality sign ε — PROVED sorry-free below (chiralitySign_conj_invariant): the ε rule of conj:inter-nucleon-channel-color-tube is flavor-conjugation invariant because conj is an involution (match ↦ match, conjugate-pair ↦ conjugate-pair).
    3. C commutes with the weight tensor W — the genuinely CONJECTURAL content, carried as the class field weight_conj_invariant of CFromColorFlavorSwap (sorry = conjecture per AGENTS.md §3b; no global instance is provided). It cannot be derived today because the closed form of W is itself open (open question 1 of the upstream block).

    Given (3), the refined generator data (W, ε) per color pair — and hence the color-weighted generator σ^(F₁,F₂) = Σ W σ^ε and its scalar shadow Σ W·ε — is C-invariant: refined_generator_data_conj_invariant and signedWeightSum_conj_invariant DERIVE this by composing the class field with the proved ε-invariance (a genuine derivation, not a projection).
