    def QOU.BraidsAndKnots.stepf :
    ℕ × ℕ → ℕ → ℕ × ℕ

    The (index, running-sum) fold step defining n(λ): on reading part part at current index acc.1, advance the index and add acc.1 · part. This is the same step used inline by PartitionOf5.nStat and DeltaLambdaDTIndexGeneralN.nStatList; naming it keeps foldl rewrites clean. (Unfolds to their inline lambda, so aStat stays defeq to both.)

        def QOU.BraidsAndKnots.addRow :

            (†) — n(λ) = Σ_i C(λ'_i, 2) for every partition #

            source
            theorem QOU.BraidsAndKnots.aStat_eq_sumChoose2_conjugate (l : List ℕ) (hl : List.Sorted (fun (x1 x2 : ℕ) => x1 ≥ x2) l) :
            aStat l = sumChoose2 (conjugate l)

            (†), general n (sorry-free). For any partition λ given by a weakly-decreasing list of parts, the a-function statistic equals the sum of C(·,2) over the conjugate partition's parts:

            `aStat l = sumChoose2 (conjugate l)`.

            Proof: induction on l (largest-row peeling). Both sides drop by the same increment Σ (tail) when the largest row is removed — aStat by aStat_cons, sumChoose2 ∘ conjugate by sumChoose2_addRow_ge (its c.length ≤ a hypothesis furnished by length_conjugate_le from decreasingness) together with sum_conjugate.
