    QOU.BraidsAndKnots.YoungDiagramKernelDimPos — sytDim positivity via the HLF chain #

    The pincer scaffold (YoungDiagramKernelPincer) carries the dimension-positivity hypothesis ∀ l ∈ partsOf k, 0 < sytDim l on its bridge theorems. It is true — f^λ = #SYT(λ) ≥ 1 — but its list-level proof needs the Frame–Robinson–Thrall divisibility, which the corpus carries in a different list formalization (QOU.BraidKnot.IdentityI.prodHooks / the machine-checked QOU.Mathlib.SYTEnum.numSYTenum_mul_prodHooks). This file bridges the two hook products and discharges the hypothesis:

    • hookProd_eq_prodHooks — the kernel's hookProd (per-cell λ_i + λ'_j − j − i − 1) equals IdentityI.prodHooks (per-cell (λ_i − j) + (colLen_j − i) − 1) for sorted l. The two ℕ-truncated expressions agree exactly because on genuine cells both subtractions are non-truncating: j < λ_i (the cell bound) and i < λ'_j (its staircase mirror, YoungDiagramTransposeBridge.lt_countP_iff).
    • sytDim_eq_numSYTenum / sytDim_pos — hence sytDim l = numSYTenum l and 0 < sytDim l from numSYTenum · prodHooks = n! (n! > 0 forces both factors positive; no separate #SYT-nonemptiness argument needed).
    • sytDim_pos_of_mem_partsOf — the hypothesis in exactly the form the pincer consumes, with the sortedness/positivity supplied by the enumeration soundness (partsOf_facts).

    Pure ℕ combinatorics; no fit; kernel conjecture untouched. Standalone library file (no .ts/.md sibling), verified per-file by lean-direct, like its parents.
