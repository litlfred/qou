    def QOU.BraidsAndKnots.contentsFrom :
    ℕ → List ℕ → List ℤ

    Contents c(i,j) = j - i of the cells of the rows lam, where the first row of lam is row index i. A row of length len contributes len cells with contents 0 - i, 1 - i, …, (len-1) - i.

        theorem QOU.BraidsAndKnots.neg_mem_partitionContents_of_lt_length (lam : List ℕ) (hpos : ∀ (x : ℕ), x ∈ lam → 0 < x) (k : ℕ) (hk : k < lam.length) :
        -↑k ∈ partitionContents lam

        Level-integer vanishing law, combinatorial half. A partition with strictly more than k rows — all rows nonempty — has a cell of content -k, namely the first cell of row k.

        The positivity hypothesis is essential, not decorative: for lam = [3, 0] and k = 1, row 1 is empty and -1 is not a content (checked below).

        theorem QOU.BraidsAndKnots.principalSpec_numerator_eq_zero_of_lt_length {K : Type u_1} [Field K] (Q : K) (lam : List ℕ) (hpos : ∀ (x : ℕ), x ∈ lam → 0 < x) (k : ℕ) (hk : k < lam.length) :
        (List.map (fun (c : ℤ) => 1 - Q ^ (↑k + c)) (partitionContents lam)).prod = 0

        Level-integer vanishing law, algebraic half. At integer level k, the principal-specialisation numerator ∏_{x ∈ λ} (1 - Q^(k + c(x))) vanishes for every partition with strictly more than k rows — for any Q in any field, including Q = 0.

        This is the exact statement that generates the level-integer ladder: raising the level past k is what re-admits the (k+1)-row stratum.

        Machine-checked evidence that the positivity hypothesis is load-bearing rather than decorative: dropping it makes the statement FALSE.
