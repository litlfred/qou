    The Plancherel normalisation Σ_λ (f^λ)² = k! in the sytDim / partsOf encoding #

    Discharges the last premise of YoungDiagramTailFirstInstance.nuV_top_closed_form: tiltNorm k 0 = k!, i.e. Σ_{λ ∈ partsOf k} (sytDim λ)² = k!.

    Why the reindexing is rebuilt here #

    The corpus already has a reindexing of exactly this shape, PartitionReindex.sum_map_eq_sum_partitionIndex, but it is stated over the custom DeltaLambdaSignRule.Partition type — and DeltaLambdaSignRule.lean does not compile at present (its Partition.armLength / legLength / hookLength / hookProduct / nStat / conjugate dot-notation does not resolve; it is one of the known red files targeted by main's content-sibling compile-repair tranche). Building on it would make this keystone rest on a red import. So the transport is redone here directly over Mathlib's Nat.Partition k, whose dependency cone is green: partsOf k ↔ Nat.Partition k ↔ PartitionIndex k.

    The chain #

    Σ_{l ∈ partsOf k} (sytDim l)² → Σ_{p : Nat.Partition k} (sytDim (p.parts.sort ·≥·))² (Finset.sum_bij, this file) → Σ_{i : PartitionIndex k} (numSYT i.diagram)² (partitionEquivYoungIndex) → k! (OVTopAssembly)

    with the summand matched by the SYT-encoding bridge (SYTEncodingBridge.numSYT_eq_numStandardYoungTableaux) composed with the hook-length side (numSYTenum_eq_numStandardYoungTableaux, sytDim_eq_numSYTenum).
