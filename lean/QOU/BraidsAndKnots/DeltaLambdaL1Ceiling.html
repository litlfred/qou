    ℓ¹ ceiling. For per-block magnitude carriers a : ι → R and any per-block weight s : ι → R bounded by 1 in absolute value (in particular any chirality sign s i = ±1), the weighted sum is bounded in absolute value by the ℓ¹ norm ∑ |a i|, for every s.

    theorem QOU.BraidsAndKnots.weighted_sum_below_target {ι : Type u_1} {R : Type u_2} [Field R] [LinearOrder R] [IsStrictOrderedRing R] (S : Finset ι) (a s : ι → R) (T : R) (hs : ∀ i ∈ S, |s i| ≤ 1) (hceil : ∑ i ∈ S, |a i| < T) :
    |∑ i ∈ S, s i * a i| < T

    Sign-only prune. If the ℓ¹ ceiling ∑ |a i| is strictly below the target magnitude T, then NO bounded weight reassignment reaches T: |∑ s i * a i| < T for every s with |s i| ≤ 1. With a := y_λ χ^λ dim_λ and s the chirality sign, this is the structural exclusion behind the Δ_λ prune (the witness measures ∑ |a i| / T ∈ [0.36, 0.59] < 1).
