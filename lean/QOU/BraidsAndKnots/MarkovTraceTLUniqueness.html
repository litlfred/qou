    The Temperley–Lieb condition pins the H₃(q) Markov trace uniquely #

    What this settles. Two normalised Markov traces on H₃(q) circulate in the corpus and give different values on the Borromean braid β_Bor (they differ by 1.9554e-4 at the substrate — the "convention D vs convention C" split of [docs/audits/2026-06-09-binding-trace-convention-split.md]):

    • convention D — the Jones / Temperley–Lieb closure, weight vector y = ([4]_q/[2]_q³, 1/[2]_q², 0); this is what the production absolute-mass facade consumes (m_p_substrate_identity_50dps.trM_borromean → F_Bor → canonical_mass.py);
    • convention C — the full-Hecke Ocneanu / Wenzl z-trace at z = 1/(q^{1/2} + q^{-1/2}), whose three-row weight is nonzero.

    Since the two agree to 195 ppm and D is the one that lands on CODATA, the question (bean qou-3qrv) is whether D is forced or selected. This file answers the mathematical half: given that the trace factors through Temperley–Lieb and is faithful there, D is forced — uniquely, with no residual freedom and no experimental input.

    The setup #

    A normalised Markov trace on H₃(q) is determined by its Ocneanu parameter z through its values on the three class representatives,

    tr 1 = 1, tr σ₀ = z, tr σ₀σ₁ = z²,

    expanded in the Frobenius basis tr = Σ_λ y_λ χ^λ over λ ⊢ 3. The H₃(q) q-character table on those representatives is

    λ χ^λ(1) χ^λ(σ₀) χ^λ(σ₀σ₁)
    (3) 1 q q²
    (2,1) 2 q − q⁻¹ −1
    (1³) 1 −q⁻¹ q⁻²

    (computed by hecke_character_symbolic.q_character_on_braid_word; the three hypotheses hnorm, hsigma, hsigmasigma below are exactly these three equations). q⁻¹ is carried as a separate element qi with q * qi = 1, so every statement here is division-free and lives over a generic commutative domain — the fibre (formal q) side of the substrate/archimedean wall, per AGENTS §7c. Nothing below mentions ℝ, an ordering, or a numerical q₀.

    The result #

    markovWeights_eq_jones_of_threeRow_eq_zero: the Temperley–Lieb condition y_(1³) = 0 together with faithfulness on TL₃ (y_(2,1) ≠ 0) forces

    [2]_q² · y_(2,1) = 1, y_(3) = 1 − 2·y_(2,1), z · [2]_q = q²

    where [2]_q = q + q⁻¹. Both hypotheses are load-bearing: markovWeights_degenerate_root exhibits the other solution of y_(1³) = 0, namely z = q with y = (1, 0, 0) — the trivial character, which annihilates the two-row block as well and so is not a faithful trace on TL₃. Dropping y_(2,1) ≠ 0 therefore makes the conclusion false, not merely unprovable.

    threeRow_ne_zero_of_ocneanu_ne: the contrapositive that matters in practice — any faithful normalised Markov trace whose parameter satisfies z·[2]_q ≠ q² has y_(1³) ≠ 0, i.e. does not factor through Temperley–Lieb. This is the structural separation of convention C from convention D.

    The Temperley–Lieb condition pins the H₃(q) Markov trace uniquely.

    Let y₃, y₂₁, y₁₃ be the Frobenius weights of a normalised Markov trace on H₃(q) with Ocneanu parameter z, i.e. tr = Σ_λ y_λ χ^λ satisfying tr 1 = 1, tr σ₀ = z, tr σ₀σ₁ = z² against the H₃(q) character table (the three hypotheses hnorm, hsigma, hsigmasigma).

    If the trace factors through Temperley–Lieb (hTL : y₁₃ = 0, the three-row block is annihilated) and is faithful on TL₃ (hfaith : y₂₁ ≠ 0), then the weight vector and the Ocneanu parameter are completely determined:

    [2]_q² · y₂₁ = 1, y₃ = 1 − 2 y₂₁, z · [2]_q = q²,

    with [2]_q = q + qi. Solving the first for y₂₁ recovers the Jones-closure vector ([4]_q/[2]_q³, 1/[2]_q², 0) — convention D.

    theorem QOU.BraidsAndKnots.markovWeights_degenerate_root {R : Type u_1} [CommRing R] (q qi : R) (hqi : q * qi = 1) :
    1 + 2 * 0 + 0 = 1 ∧ q * 1 + (q - qi) * 0 + -qi * 0 = q ∧ q ^ 2 * 1 + -1 * 0 + qi ^ 2 * 0 = q ^ 2 ∧ q * (q + qi) = q ^ 2 + 1

    The faithfulness hypothesis is not decorative.

    The Temperley–Lieb condition y₁₃ = 0 alone has a second solution: the trivial character y = (1, 0, 0) at z = q. It satisfies all three Markov equations, so markovWeights_eq_jones_of_threeRow_eq_zero genuinely needs y₂₁ ≠ 0 — without it the conclusion z·[2]_q = q² is false (here z·[2]_q = q² + 1 ≠ q²). This solution annihilates the two-row block too, so it is not a faithful trace on TL₃; that is what rules it out.

    y₁₃ ≠ 0

    Convention C does not factor through Temperley–Lieb.

    Contrapositive of the uniqueness theorem, in the form that separates the two production conventions: a faithful normalised Markov trace whose Ocneanu parameter fails z·[2]_q = q² necessarily has a nonzero three-row weight. Applied to the Wenzl z-trace (convention C, z = 1/(q^{1/2}+q^{-1/2})), this says C carries the (1³) block and so is not the Jones/TL trace.
