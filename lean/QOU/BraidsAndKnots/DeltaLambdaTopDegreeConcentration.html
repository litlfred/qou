    Graded Euler characteristic of a coefficient vector #

    A graded finite-dimensional object is encoded by its coefficient list
`l : List ℕ`, where `l[i]` is the dimension in cohomological degree `i`
(degree `0` first).  Its signed (DT / Behrend) Euler characteristic is
`Σ_i (-1)^i · l[i]`.  This is exactly the decategorified `∑ (-1)^i dim H^i`.
Defined by structural recursion on the list (degree accumulator `d`) so it
reduces cleanly under `decide` at the `n = 5` anchor.

            THE CRUX: the confinement SDP / canonical T_w cannot force top-degree #

            source
            theorem QOU.BraidsAndKnots.sdp_cannot_force_top_degree :
            ∃ (single : PartitionOf5 → List ℕ) (fake : PartitionOf5 → List ℕ), (∀ (p : PartitionOf5), (single p).sum = (fake p).sum) ∧ (∀ (p : PartitionOf5), p.dim ≠ 1 → gradedEuler (single p) ≠ gradedEuler (fake p)) ∧ ∀ (p : PartitionOf5), gradedEuler (single p) = p.deltaLambda

            THE CRUX (limitative). There exist two graded assignments — the single-degree Springer object G_λ = singleCoeffs and the full fake-degree coinvariant object H_λ = fakeCoeffs — such that:

            • they carry the SAME ungraded Wedderburn dimension dim V_λ at every block (same), i.e. they are INDISTINGUISHABLE to any functional of the ungraded block data — which is exactly what the confinement SDP (ρ_λ(T(c)) ⪰ 0), the canonical T_w selection, and the Markov trace tr_M = Σ_λ w_λ χ_λ are (they factor through ⊕_λ End(V_λ));

            • yet their signed (DT/Behrend) Euler characteristics DIFFER on every non-trivial block (differ), with only the single-degree object equal to Δ_λ (single_is_delta).

            Consequently the ungraded datum does NOT pin the graded Euler characteristic, so NO functional of it — in particular the confinement SDP / canonical T_w — can FORCE the top-degree (single-degree) concentration. The top-cohomology projection H^{top}(𝓑_λ) = V_λ is a genuinely INDEPENDENT input. This is the precise NEGATIVE answer to bean qou-nmpr: the confinement SDP / canonical T_w, as constructed, does not reach top degree.
