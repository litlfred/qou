    QOU.BraidsAndKnots.YoungDiagramTranspose — the transpose-parity no-go for the Δ_λ kernel sign #

    The Δ_λ super-exponential growth bound (#3939) reduces (#3959) to the covariance kernel

    T₃ = Σ_{λ⊢k} (f^λ)² χ^λ(3-cycle) ≤ 0
   ⇔ cov(k) := Σ_{λ⊢k} (f^λ)³ (Σ_□ c(□)² − C(k,2)) ≤ 0,   c(i,j) = j − i.

    The kernel is OPEN (YoungDiagramKernel.covariance_kernel_conjecture, an honest §3b sorry). A tempting scope-(b) route is the conjugation involution λ ↔ λ' (transpose), which the reduction already exploits to prove the linear content moment vanishes (T₂ = 0). This file formalizes the precise statement that this route cannot sign T₃: the transpose involution kills the odd content moment T₂ but is a pointwise symmetry of the even content-square moment, so it contributes zero information about the sign of T₃.

    The content parities are realized on a cell model of a Young diagram as a Finset (ℕ × ℕ) of cells (i,j), with transpose = coordinate swap (i,j) ↦ (j,i):

    • csum (linear content Σ (j − i)) is transpose-odd (csum_transpose) ⇒ kills T₂;
    • csq (content square Σ (j − i)²) is transpose-even (csq_transpose) — squares kill the sign ⇒ the whole cov summand is transpose-invariant (kernel_summand_transpose_invariant).

    The coordinate-swap cell model is the representation-free heart of the classical conjugation bijection; on the weakly-decreasing List ℕ encoding of YoungDiagramKernel the swap is realized by YoungDiagramKernel.conj (the cell-level bijection there is the standard transpose correspondence).

    Together with the FKG-on-dominance no-go (fl_kernel_sign_structure.py, NARROWING A) this pins the kernel sign as an order-blind, parity-blind concentration effect: no correlation inequality on the dominance lattice and no parity/involution argument can produce it — a large-deviation / tilted-limit-shape bound is required. This file does not close the kernel.

    Base ring: ℤ for the concrete content (contents are integers); the abstract summand-parity lemmas are generic over {R : Type*} [CommRing R]. This is a standalone library file (no .ts/.md sibling), imported by no QOU module — like YoungDiagramKernel / DeltaLambdaDReduction, it is verified per-file by lean-direct.     Abstract summand parity (generic commutative ring) #

    An involution on the index set fixes each summand of an even quantity but flips the sign of each summand of an odd one. This is the abstract reason the transpose route can only close T₂ (odd content moment), never T₃ (even content-square moment).

    source
    theorem QOU.BraidsAndKnots.YoungDiagramTranspose.even_summand_involution_invariant {ι : Type u_1} {R : Type u_2} [CommRing R] (g a : ι → R) (σ : ι → ι) (i : ι) (hg : g (σ i) = g i) (ha : a (σ i) = a i) :
    g (σ i) * a (σ i) = g i * a i

    Even moment is fixed pointwise. If the weight g and the quantity a are both invariant under σ at i, the weighted summand g · a is fixed by σ. So an involution gives no sign information about an even moment — the crux of the transpose no-go for T₃.

    source
    theorem QOU.BraidsAndKnots.YoungDiagramTranspose.odd_summand_involution_cancels {ι : Type u_1} {R : Type u_2} [CommRing R] (g a : ι → R) (σ : ι → ι) (i : ι) (hg : g (σ i) = g i) (ha : a (σ i) = -a i) :
    g i * a i + g (σ i) * a (σ i) = 0

    Odd summands cancel in pairs. If the weight is invariant (g (σ i) = g i) and the quantity is odd (a (σ i) = − a i), the paired summands g i · a i and g (σ i) · a (σ i) cancel. Summing this pairing over the transpose involution is exactly why the odd content moment vanishes: T₂ = Σ_λ (f^λ)³ Σ_□ c(□) = 0.

    Concrete cell model: contents under coordinate swap (transpose) #

    A Young diagram is modeled by its set of cells D : Finset (ℕ × ℕ); the content of a cell (i,j) is c = j − i ∈ ℤ. Transpose is the coordinate swap (i,j) ↦ (j,i), realized as a Finset.map along the injective Prod.swap.

          theorem QOU.BraidsAndKnots.YoungDiagramTranspose.csq_transpose (D : Finset (ℕ × ℕ)) :

          Content square is transpose-EVEN. (j − i)² = (i − j)², so Σ_□ c(□)² is fixed by transpose. This is the fact that makes the transpose involution a symmetry of the cov summand — it cannot sign T₃.

          Linear content is transpose-ODD. (j − i) + (i − j) = 0, so Σ_□ c(□) negates under transpose. This is the mechanism behind T₂ = 0.
