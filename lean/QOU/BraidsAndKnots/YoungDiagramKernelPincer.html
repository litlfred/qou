    QOU.BraidsAndKnots.YoungDiagramKernelPincer — the two-leg pincer scaffold for the kernel sign #

    The covariance kernel covariance_kernel_conjecture (kernelValue k ≤ 0, OPEN) has exactly one live full-proof route after the recorded eliminations (holonomic, FKG, peeling, transpose-parity, genus, complete monotonicity): the tilt-interpolation pincer. Tilt the Plancherel-squared weight (f^λ)² by exp(θ·ln f^λ) and set g(θ) := E_{2+θ}[ω₃]; then g(0) = 0 exactly, the kernel sign is g(1) ≤ 0, and the pincer closes it from two legs:

    • [A2] g′(0) = Cov₂(ln f^λ, ω₃) ≤ 0 (the log-dimension/content-spread anti-correlation), and
    • [A3] the interpolation remainder is dominated: |g(1) − Cov₂(ln f, ω₃)| ≤ −Cov₂(ln f, ω₃).

    This file formalizes the scaffold (formalize-first): the tilted objects as finite real sums over the partsOf enumeration, the explicit finite-sum covariance covLnF, the pure-arithmetic pincer lemma, and the conditional derivation

    `KernelPincerLegs k`  (mean-zero + A2 + A3, a §3b-cond content-bearing class, NO instance)
  ⟹  `tiltedMean k 1 ≤ 0`  ⟹  `kernelValue k ≤ 0`

    so the two legs become the pinned Lean targets. All theorems here are sorry-free; the open content is carried honestly by the instance-less class (§3b-tax: fields are the conjecture's inputs; the kernel bound is genuinely derived from them through the positivity/cast bridge — not a self-assuming projection).

    What is and is not asserted #

    • The identification g′(0) = covLnF k (real differentiation of the finite tilted sums) is the next analytic tranche and is not asserted here; [A3] is therefore stated directly as the remainder-vs-covLnF bound, which is the exact inequality the pincer consumes. Arithmetic makes [A2] a consequence of [A3] (pincer_arith_forces_A2); both are kept as named fields because the attack proves them separately (A2 via the hook/Frullani reduction, A3 via uniform mixed-cumulant bounds).
    • mean_zero (E₂[ω₃] = 0) is an exact identity (regular-character orthogonality), decide-verified k ≤ 7 in ℤ-form (secondMomentKernel_eq_zero_of_le_seven); its general real-form proof rides the same character bridge and is kept as a field until that lands.
    • The dimension-positivity hypothesis ∀ l ∈ partsOf k, 0 < sytDim l is true (f^λ = #SYT ≥ 1) but its list-level proof needs the HLF divisibility bridge (hookProd ∣ (sum l)!); it is taken as an explicit hypothesis on the bridge theorems and discharged when that bridge lands.

    Base ring (§7c): genuinely archimedean (Real.exp, Real.log), so ℝ. Standalone library file (no .ts/.md sibling), verified per-file by lean-direct, like its parents.

                    The hook form of leg [A2] #

                    The FRT quotient turns the log-dimension into log-factorial-minus-log-hooks, ln f = ln k! − ln ∏h, and covariance kills the constant, so

                    `covLnF k = − Cov₂(ln ∏h, ω₃)`.
