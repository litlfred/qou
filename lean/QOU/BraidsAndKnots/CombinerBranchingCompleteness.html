    QOU.BraidsAndKnots.CombinerBranchingCompleteness #

    — the operator-valued combiner reaches every Wedderburn block

    The operator-valued combiner (a_operator_recursive.py :: interface_blocks, narrative hecke-branching-trace-decomposition.md) decomposes a per-block character along H_{n_inner}(q) ⊗ H_{n_block}(q) ↪ H_n(q):

      χ^λ(β₁ · I · β₂) = Σ_{ξ⊢n_inner, ν⊢n_block} c^λ_{ξν} · Tr(A^λ_{ξν}(I) · …).

    The per-λ completeness (the sum captures all of Res(V_λ)) is already established in the corpus: the trace is the sum over the orthogonal (ξ,ν)- isotypic components, and H_n(q) ≅ ⊕_{λ⊢n} End(V_λ) (Wenzl 1988; QOU/Hecke/Wedderburn.lean).

    This file formalizes the dual guarantee — that the enumeration is non-degenerate: interface_blocks returns at least one child for every λ ⊢ n, so the production trace tr_M = Σ_λ y_λ χ^λ drops no block. By Frobenius reciprocity V_λ ⊆ Ind(V_ξ ⊠ V_ν) ⟺ c^λ_{ξν} > 0, and any skew shape admits an LR filling, so non-degeneracy reduces to the purely combinatorial fact

      every λ ⊢ n with n ≥ k has a SUB-PARTITION of size n − k  (ξ ⊆ λ).

    Proved here sorry-free (exists_subpartition_of_size) by removing one Young box at a time from the last row. The empirical completeness over the actual combiner splits (6, 9, 12) is verified in combiner_branching_completeness.py.

    Refs:

    • [wenzl1988] Hecke algebras of type A_n and subfactors, Invent. Math. 92
    • [halverson-ram1998] Murnaghan–Nakayama rule for the Hecke algebra
    • [manuscript] content/.../mass-endomorphism/hecke-branching-trace-decomposition.md

        theorem QOU.BraidsAndKnots.CombinerBranchingCompleteness.exists_subpartition_of_size (k : ℕ) (lam : MathlibExt.QPartitionCombinatorics.Partition) :
        (∀ x ∈ lam, 1 ≤ x) → k ≤ List.sum lam → ∃ (mu : MathlibExt.QPartitionCombinatorics.Partition), List.sum mu + k = List.sum lam ∧ IsSubPartition mu lam

        Combiner non-degeneracy (Frobenius reciprocity completeness). Every canonical positive partition λ of size ≥ k has a sub-partition μ ⊆ λ of size |λ| − k — so the branching H_{|λ|−k}(q) ⊗ H_k(q) ↪ H_{|λ|}(q) reaches λ (its interface_blocks enumeration is non-empty), and the operator-valued combiner drops no Wedderburn block.
