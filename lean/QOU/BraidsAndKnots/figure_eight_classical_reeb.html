    Classical q-Reeb angle θ(1) = 2π/3 (proved). At q = 1 the trace is t = −1 with t² = 1 < 4, so every eigenvalue λ (root of the characteristic polynomial x² + x + 1) has unit modulus (via unit_modulus_of_det_one_small_trace) and is a primitive cube root of unity (λ³ = 1, λ ≠ 1). A primitive cube root has argument ±2π/3, so the classical q-Reeb rotation angle is exactly 2π/3 — the amphichiral anchor from which the q-deformation θ(q₀) ≈ 117.087° departs (Δθ ≈ −2.913°, the derived symmetry-breaking seed of the c₃ bar-odd S).
