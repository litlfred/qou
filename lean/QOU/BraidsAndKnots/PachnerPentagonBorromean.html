    class QOU.BraidsAndKnots.PachnerPentagonBorromean (R : Type u_1) [CommRing R] :
    Type (max 1 u_1)

    conj:pachner-pentagon-borromean (D15) as a §3b conjecture-class over a generic value ring R (the state-sum / coefficient ring).

    An instance is a CONJECTURAL WITNESS — the categorical (u,v) specialisation that makes the Pachner-invariant Φ_q state-sum h⁴ coefficient equal the Borromean Markov-trace −3/4. The natural- specialisation probe currently exhibits NO such witness (see header), so no instance is provided.

    • Tri : Type

      Abstract ideal triangulations of S³ ∖ 𝓑₃.

    • stateSum : Tri R → R

      The Turaev–Viro / Reshetikhin–Turaev Φ_q state sum on a triangulation.

    • PachnerRelated : Tri R → Tri R → Prop

      Pachner 2–3 relatedness of two triangulations.

    • pachner_invariant {T T' : Tri R} : PachnerRelated T T' → stateSum T = stateSum T'

      Pachner 2–3 invariance — STANDARD given the Φ_q pentagon: the state sum is constant on 2–3-related triangulations.

    • borOctahedral : Tri R

      The 8-ideal-octahedron decomposition of S³ ∖ 𝓑₃ (Thurston).

    • borTetrahedral : Tri R

      Its 16-ideal-tetrahedron refinement, one 2–3 move away.

    • borromean_pachner_related : PachnerRelated borOctahedral borTetrahedral

      The two canonical Borromean decompositions are 2–3-related.

    • h4_stateSum_coeff : R

      The h⁴ coefficient extracted from the Pachner-invariant state sum.

    • four_h4_eq_neg_three : 4 * h4_stateSum_coeff = -3

      CONJECTURAL identification with the Borromean Markov-trace coefficient (tr_M(β_Bor) = 1 − (3/4)·h⁴ − …, BorromeanMarkovTrace), written division-free as 4·coeff = −3. UN-EXHIBITED — this field is the §3b conjectural content.
