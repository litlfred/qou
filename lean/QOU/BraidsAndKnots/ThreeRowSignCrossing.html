    theorem QOU.BraidsAndKnots.sign_crossing_of_block_dominance_exchange {a b : ℝ} (hab : a ≤ b) {F T₁ T₂ R : ℝ → ℝ} (hsplit : ∀ (q : ℝ), F q = T₁ q + T₂ q + R q) (hcont : ContinuousOn F (Set.Icc a b)) (ha_dom : |T₂ a + R a| < T₁ a) (hb_dom : |T₁ b + R b| < -T₂ b) :
    ∃ c ∈ Set.Ioo a b, F c = 0

    Block dominance exchange forces a zero.

    Let F = T₁ + T₂ + R be a continuous function split into two distinguished blocks and a remainder. Suppose that

    • at the left endpoint a the first block is positive and dominates everything else: |T₂ a + R a| < T₁ a;
    • at the right endpoint b the second block is negative and dominates everything else: |T₁ b + R b| < -T₂ b.

    Then F vanishes somewhere strictly between a and b.

    This is the exact shape of the measured deuteron data: T₁ is the (4,1,1) term, T₂ the (3,2,1) term, and R the remaining ≥3-row blocks. The hypotheses are falsifiable statements about those numbers — dropping either dominance hypothesis makes the conclusion fail (a positive F with a merely larger negative block elsewhere need not vanish).

    theorem QOU.BraidsAndKnots.crossing_unique_of_strictMonoOn_ratio {a b : ℝ} {T₁ T₂ : ℝ → ℝ} (hT₁ : ∀ q ∈ Set.Icc a b, 0 < T₁ q) (hmono : StrictMonoOn (fun (q : ℝ) => -T₂ q / T₁ q) (Set.Icc a b)) (c : ℝ) :
    c ∈ Set.Icc a b → ∀ d ∈ Set.Icc a b, T₁ c + T₂ c = 0 → T₁ d + T₂ d = 0 → c = d

    The crossing is unique when the block ratio is strictly monotone.

    In the two-block regime (F = T₁ + T₂ with T₁ > 0 and T₂ < 0 throughout), write the overtake ratio r = (-T₂)/T₁. Then F q = 0 exactly when r q = 1, so if r is strictly monotone on [a, b] the crossing is unique.

    This is the formal content of the word "overtake": the second block does not merely become large, it grows relative to the first, and it does so monotonically, so it crosses the first exactly once.

    theorem QOU.BraidsAndKnots.two_block_neg_iff_ratio_gt_one {t₁ t₂ : ℝ} (ht₁ : 0 < t₁) :
    t₁ + t₂ < 0 ↔ 1 < -t₂ / t₁

    Sign of a two-block sum is the sign of 1 − r.

    The companion readout used by the probe: with T₁ > 0, the sum T₁ + T₂ is negative precisely when the overtake ratio r = (-T₂)/T₁ exceeds 1. This is what makes "the (3,2,1) block has overtaken (4,1,1)" and "the total has gone negative" the same statement rather than two correlated observations.
