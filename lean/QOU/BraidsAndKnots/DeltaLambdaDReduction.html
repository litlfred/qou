    QOU.BraidsAndKnots.DeltaLambdaDReduction — the character reduction of the Δ_λ sub-lemma (D) #

    The Δ_λ growth bound (#3939, WstdSuperExpBound.lean) had one open input, the sub-lemma (D) w_std = E_Planch[f^{λ/(2,1)}] ≥ E_Planch[f^{λ/(3)}]. PR #3959 reduced it, via exact S_k character identities, to the covariance kernel T₃ = Σ_λ (f^λ)² χ^λ(3-cycle) ≤ 0 (equivalently Cov_Planch(f^λ, Σ_□ c(□)²) ≤ 0), using:

    • the exact identity 6·(W − E) = T₁ − 4·T₃ − 3·T₂ (W = Σ(f^λ)²f^{λ/(2,1)}, E = Σ(f^λ)²f^{λ/(3)}, Tⱼ = Σ(f^λ)²·χ^λ(class), from f^{λ/(2,1)} = (f^λ − χ₃)/3, f^{λ/(3)} = (f^λ + 3χ₂ + 2χ₃)/6);
    • T₂ = 0 exactly (conjugation χ^{λ'} = sgn·χ^λ);
    • T₁ = Σ(f^λ)³ ≥ 0.

    This file formalizes the algebraic reduction step: from those three facts, (D) E ≤ W follows from T₃ ≤ 0. Combined with WstdSuperExpBound.wstd_ge_quarter_lower_bound (#3939), the entire chain from the covariance kernel T₃ ≤ 0 to the super-exponential growth bound on w_std is now Lean-proved — leaving only T₃ ≤ 0 (the Biane–Śniady / Kerov-CLT anti-correlation, open) as the single unproved input.

    The character identities themselves (f^{λ/(2,1)}=(f^λ−χ₃)/3, T₂=0, the Jucys–Murphy content formula) are verified computationally (computations/deltalambda/wlambda_D_reduction_content_covariance.py) and are Lean-targets pending Mathlib S_k-character machinery; the covariance kernel itself is open.

    Base ring: ℝ. Sorry-free.
