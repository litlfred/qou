    QOU.BraidsAndKnots.recursive_atom_knot_atlas — concrete consumer #

    Real consumer of the parameterised SDP-uniqueness infrastructure from PR #1537 (NucleusEmptySDPUniqueness) and its per-isotope / per-element / per-stable-isotope wrappers. Replaces the prior placeholder sorry stub.

    What this consumes #

    For every atom/isotope catalogued in the recursive atom-knot atlas content block (recursive-atom-knot-atlas.md), the corresponding SDP-uniqueness theorem from one of the four wrapper layers:

    Layer Module Wrapper naming
    QOU R5-full nuclei Applied<Nucleus>Uniqueness (10 files) helium4_uniqueness_closed, etc.
    Per-element (AME2020) PeriodicTableUniqueness he_uniqueness_closed, etc.
    Per-stable-isotope StableIsotopeUniqueness (PR #1542) c12_uniqueness_closed, etc.
    Generic NucleusEmptySDPUniqueness @nucleus_uniqueness_closed (3*A)

    Atlas-entry uniqueness theorem #

    For each atlas entry at mass number A, the canonical T_w knot operator's uniqueness at the empty-constraint SDP demonstration level is certified by:

    @QOU.BraidKnot.nucleus_uniqueness_closed (3 * A)

    Per-atom convenience wrappers below provide the named theorem each atlas entry can cite.

    What this does NOT cover #

    This module wires the abstract framework demonstration — the empty-constraint SDP at heckeDim (3A) with dualSlack = 1 is PosDef, so the trivial strict-complementarity pair gives sorry-free uniqueness. The real per-nucleus SDP with multi-term cost from the mass formula and non-empty constraints is per-nucleus substantive open work; see docs/coordination/2026-05-30-sdp-uniqueness-status.md.

    Atlas SDP-uniqueness theorem statement.

    For every atlas entry characterised by nucleon count A, the canonical T_w knot operator at the empty-constraint SDP is unique among feasible matrices achieving the same objective.

    Proved by direct delegation to the parameterised nucleus_uniqueness_closed (3 * A).
