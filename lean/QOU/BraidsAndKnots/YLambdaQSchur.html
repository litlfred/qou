    QOU.BraidsAndKnots.YLambdaQSchur #

    Closed-form q-Schur Markov-trace weights and their structural properties.

    The q-Schur convention #

    Per PR #1259 (Markov-trace convention audit), the q-Schur convention has a closed-form expression for the central coefficients y_λ in the Markov-trace expansion tr_M = Σ_λ y_λ · χ_λ on H_n(q):

    y_λ(q) := q^{c(λ)} / [n]_q!

    where:

    • c(λ) = Σ_{(i,j) ∈ λ} (j - i) is the content sum of the partition λ ⊢ n
    • [n]_q! = [n]_q · [n−1]_q · … · [1]_q is the q-factorial
    • [k]_q = (q^k - q^{-k}) / (q - q^{-1}) is the balanced q-integer

    This is the principal specialisation of the Schur polynomial at (1, q, q², …, q^{n-1}), divided by the q-factorial.

    What this file proves #

    The y_λ formula has a clean transpose-pair identity that does not depend on the full Young-diagram structure — only on the fact that transposing a partition negates the content of every cell, hence the content sum c(λ^T) = −c(λ).

    Theorem yLambdaQSchur_transpose_pair:

    y_λ(q) · y_{λ^T}(q) = 1 / [n]_q!²

    PROVED in Lean via field_simp + ring (no sorry, no placeholder, no class hypothesis). Uses only the structural fact q^c · q^{-c} = 1 for any integer c at non-zero q.

    Why this matters #

    This is the first Lean theorem on y_λ that carries real mathematical content — earlier Lean files (y-lambda-closed-form-wenzl-bridge.lean) use placeholder structures that reduce to 0 · _. This file's yLambdaQSchur_transpose_pair is an honest identity provable from the closed-form definition.

    The transpose-pair identity is structurally informative:

    • For self-conjugate partitions (λ = λ^T, c = 0), it specialises to y_λ² = 1 / [n]_q!², i.e. |y_λ| = 1/[n]_q!.
    • For transpose-paired partitions, the product is q-independent (apart from the [n]_q!² scaling), which is the categorical signature of bar-pairing on the y_λ space.

          theorem QOU.BraidsAndKnots.yLambdaQSchur_transpose_pair {R : Type u_1} [Field R] (q : R) (_hq : q ≠ 0) (n : ℕ) (c : ℤ) :
          yLambdaQSchur q n c * yLambdaQSchur q n (-c) = 1 / qFactorial q n ^ 2

          Transpose-pair identity. For a partition λ ⊢ n with content sum c, and its transpose λ^T (which has content sum −c):

          y_λ(q) · y_{λ^T}(q) = 1 / [n]_q!².

          The proof uses the fact that transposing a Young diagram negates the content of every cell, so the content sums are negatives of each other. Combined with qPow_mul_qPow_neg the q-dependence in the numerator cancels.

          This is the cleanest non-trivial identity satisfied by the closed-form y_λ.

          Self-conjugate specialisation (c = 0) #

          Bar-involution and Mullineux symmetry #

          The substrate has a bar-involution q ↔ q⁻¹ which acts on partition combinatorics via the Mullineux involution (column-row swap / transpose λ ↔ λᵀ). This section proves the bar-symmetry of q-integers and q-factorials, then lifts to y_λ.

          source
          theorem QOU.BraidsAndKnots.qInt_bar_inv {R : Type u_1} [Field R] (q : R) (_hq : q ≠ 0) (_h_neq : q - q⁻¹ ≠ 0) (n : ℤ) :
          qInt q⁻¹ n = qInt q n

          q-integer bar-symmetry: [n]_{q⁻¹} = [n]_q.

          Under bar (q ↔ q⁻¹), both numerator q^n − q^{−n} and denominator q − q⁻¹ flip sign in the same way, so the ratio is invariant.

          This is the fundamental bar-symmetry that makes [n]_q a "balanced" q-integer (vs the asymmetric (q^n − 1)/(q − 1)).

          source
          theorem QOU.BraidsAndKnots.qFactorial_bar_inv {R : Type u_1} [Field R] (q : R) (_hq : q ≠ 0) (_h_neq : q - q⁻¹ ≠ 0) (n : ℕ) :

          y_λ bar-Mullineux involution #

          The y_λ in q-Schur convention satisfies the bar-Mullineux identity: substituting q ↔ q⁻¹ on the substrate sends y_λ to y_{λᵀ} (the y_λ of the transpose partition). Proof: q^c → q^{-c} under bar (negates content sum), and [n]_q! is bar-symmetric.

          These theorems combine the bar-involution q ↔ q⁻¹ with the Mullineux involution λ ↔ λᵀ to produce structural identities that exploit BOTH symmetries simultaneously.

          F_Bor as |tr_M(β_Bor)| normalised by y_(3) Markov weight #

          The substrate identity for the proton mass uses the categorical observable

          F_Bor(q) := |tr_M(β_Bor, q)| · [3]_q! / q^3

          This file proves the CLEAN identification:

          F_Bor(q) = |tr_M(β_Bor, q)| / y_(3)(q)

          since y_(3)(q) := q^(c((3))) / [3]_q! = q^3 / [3]_q! (content sum of the trivial partition (3) is c((3)) = 0+1+2 = 3).

          This gives F_Bor a natural categorical interpretation: it is the Markov trace of β_Bor DIVIDED by the q-Schur Markov weight of the trivial / symmetric partition (3) — equivalently, the trace NORMALISED to remove the trivial-partition's content shift.

          The proton substrate identity then reads in cleaner form:

          m_p = 2 · m_μ · |tr_M(β_Bor)| / y_(3)(q_0) - 12 · m_e

          or equivalently (clearing y_(3)):

          y_(3)(q_0) · (m_p + 12 · m_e) = 2 · m_μ · |tr_M(β_Bor, q_0)|

          This section provides the categorical identity for dim V_(2,1) via the hook-length formula.

          The hook-length identity #

          For the partition λ = (2, 1) of n = 3, the Young diagram has cells (1,1), (1,2), (2,1) with hook lengths:

          • (1,1): arm = 1, leg = 1 → hook = 3
          • (1,2): arm = 0, leg = 0 → hook = 1
          • (2,1): arm = 0, leg = 0 → hook = 1

          Hook-length formula: dim V_λ = n! / ∏ hook(c) = 6 / (3 · 1 · 1) = 2.

          This is the elementary categorical content of the "2" appearing in the substrate proton-mass identity.
