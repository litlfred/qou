    QOU.BraidsAndKnots.BorromeanPairwiseLinking — pairwise linking cannot see the proton braid #

    Bean qou-bhfg (front 4-B). Formalize-first prune, per AGENTS.md §"Formalize-first probe discipline": a structural fact that removes an entire ansatz class before any numerical search over it.

    The problem this prunes #

    Front 4-B needs the intra-nucleon EM self-energy E_EM — the open "two-like-charge EM-linking invariant" that blocks both m_d − m_u and 69 % of the ³He mirror residual. The extraction is δ_QCD = Δ_pn + E_EM with Δ_pn = 1.2933 MeV framework-derived (computations/quark-mass-extraction-stage1.witness.json); the lattice comparator for E_EM is ≈ 0.8 MeV.

    The obvious first ansatz for a two-charge linking energy is a functional of the pairwise linking numbers of the constituent strands. This file shows that class is empty on the proton.

    The computation #

    The proton braid is the Borromean link, presented in the corpus as the closed braid (σ₀σ₁⁻¹)³ ∈ B₃ (knots-particles-confinement/brunnian-property-of-borromean.md). Simulating that word — each letter exchanges the strands currently at positions i, i+1 and contributes a crossing of its sign between those two strands — gives signed crossing sums of 0 for all three pairs, hence all three linking numbers lk = 0.

    So a functional of pairwise linking data alone assigns the Borromean braid exactly what it assigns the 3-component unlink, and a self-energy that vanishes on the unlink therefore vanishes on the proton. It cannot produce 0.8 MeV. This is a scope-(b) exclusion of the ansatz class, with the invariant named and computed rather than asserted.

    Why this is not vacuous #

    hopf_crossSum_ne_zero is the control: the same simulator returns 2 (i.e. lk = 1) on the Hopf link σ₀². So the machinery detects nonzero linking when it is there, and the Borromean zeros are a fact about the Borromean word rather than about the simulator. borromean_perm_id additionally confirms the word closes to a genuine 3-component link, so the zeros are not an artifact of components having been merged.

    Scope — read before citing #

    • This is about pairwise linking only. It says nothing against the Milnor triple linking number μ̄₁₂₃, which is precisely the first invariant that is nonzero on Borromean rings, and which the corpus already carries for the sin²θ_W front. If anything this file points at it.
    • It does not prove the corpus's conj:brunnian-property-of-borromean (that every 2-component sublink is the unlink). That is strictly stronger — vanishing linking number is necessary, not sufficient — and remains a conjecture. Nothing here should be read as closing it.
    • It assumes the corpus's presentation of the proton braid as (σ₀σ₁⁻¹)³, consumed as given.

    -- Ref: [kawauchi1996] (Brunnian links; linking number of a closed braid as the -- signed count of crossings between two components).

                Why the meson EM mechanism does not transport to the nucleon #

                The framework does have a derived electromagnetic correction in the meson sector (braids-and-knots/meson-em-sinh-closed-form.md: the m_K²/m_π² ratio carries an (α_em/π)·(1 + log(1 + ℏ_q)) term). The obvious move for 4-B is to carry it over to the nucleon. It does not carry.

                The two carriers differ in exactly the invariant at issue. A meson is a Hopf-bound q q̄ pair — two components, and the corpus's own evenTwistLinkingNumber records lk(T(2,2k)) = k ≠ 0. A nucleon is the Borromean braid — three components with every pairwise linking 0. So any mechanism carried by pairwise linking is active on the meson and inactive on the nucleon, identically.

                There is a second, independent reason, which needs no interpretation of what the meson term is carried by: as written it is a function of q alone. Two carriers evaluated at the same substrate q receive the same value, so transporting it as-is contributes equally to the proton and the neutron and therefore nothing to their splitting. That one is immediate and is recorded in the audit rather than here, having no mathematical content to prove.

                source
                theorem QOU.BraidsAndKnots.BorromeanPairwiseLinking.meson_mechanism_vanishes_on_nucleon {α : Type u_1} [Zero α] (F : ℤ → α) (hF0 : F 0 = 0) (_hmeson : F (crossSum 0 1 hopfWord [0, 1]) ≠ 0) :
                F (crossSum 0 1 borWord [0, 1, 2]) = 0 ∧ F (crossSum 0 2 borWord [0, 1, 2]) = 0 ∧ F (crossSum 1 2 borWord [0, 1, 2]) = 0

                The meson mechanism cannot be the intra-nucleon one. For any F that vanishes on zero linking, if F is nonzero on the meson carrier (the Hopf link, lk ≠ 0) then it is zero on every pair of the nucleon carrier.

                So an E_EM transported from the meson sector along pairwise linking is identically zero inside the nucleon — it cannot reach the ≈ 0.8 MeV comparator, and it cannot distinguish the proton from the neutron.

                The "pion inside the nucleon" bridge is a braid-word artifact #

                There is a tempting second route from the meson sector, and the corpus material invites it. brunnian-property-of-borromean.md records that deleting the 0-th strand of (σ₀σ₁⁻¹)³ leaves (σ₀⁻¹)³ ∈ B₂, whose closure is the negative trefoil — and the trefoil is T(2,3), which the lepton–meson dictionary assigns to the generation-1 meson, the pion. Read naively that says a pion sits inside the nucleon, ready to carry its electromagnetic self-energy.

                It does not survive a component count. Deleting one component from a 3-component link must leave 2 components. The naively deleted braid word closes to 1. So naive braid-word deletion is not sublink deletion, and the trefoil it produces is an artifact of the word rather than a feature of the link — which is exactly why the corpus block says topological equivalence to U₂ "requires an explicit sequence of Reidemeister moves". The true sublink is the unlink, and the unlink carries no pion.

                This is proved rather than argued so that the inference cannot be re-derived from the same material later.
