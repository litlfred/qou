    QOU.BraidsAndKnots.InterNucleonChannelColorTube — the D6-upstream color-tube channel class #

    §3b-cond class axiomatisation for content block conj:inter-nucleon-channel-color-tube (color-tube weighted inter-nucleon Hecke channel assignment), replacing the former sibling stub's vacuous holds : Prop placeholder with the content-bearing structure sketched in the block's "Lean axiomatisation (sketch)" section.

    What is encoded here (statable today):

    • the color-sheet / quark-flavor ground types (ColorSheet, QuarkFlavor, NucleonColorContent, proton/neutron content);
    • the chirality-sign rule ε(c₁, c₂, F₁, F₂) ∈ {+1, −1, 0} exactly as stated in the block (+1 matter–matter match, −1 flavor-conjugate, 0 mixed) — a definition, with its value-range proved;
    • the class InterNucleonChannelColorTube carrying the weight tensor W_{c₁c₂}(F₁, F₂) ∈ ℚ≥0 with its normalisation Σ_{c₁c₂} W = 1 (ℚ is used, not a generic ring, because the block's nonnegativity constraint genuinely requires an order — §7c);
    • the uniform-flavor projection W = 1/9 as a named witness of satisfiability (uniformColorTubeData) — deliberately NOT registered as an instance, because the conjecture's content is that the true weights derive from the Bring SO(3)-fiber tensor, and the uniform projection is exactly the flavor-only collapse the block identifies as missing structure;
    • the fiber-action wiring facts that are already derivable from the discharged BringFiberAction instance: the color sheets are the T₁ irrep's basis (dim T₁ = 3 = #sheets, T₁ = the ℓ = 1 Hopf selection), and the color-sheet fiber rotation is pinned to the icosahedral Reeb phase arccos(φ/3).

    What remains OPEN (the conjecture, per the block's §Open questions): the closed form of W_{c₁c₂} as a tensor in the SO(3)-fiber data over Bring (open question 1) and the derivation of the ε rule from the S₅-orbit / CPT structure (open question 2). No global instance is provided; downstream results consume [InterNucleonChannelColorTube] as a genuine hypothesis.

    The substrate-pure realisation of the flavor-only projection is implemented in computations/closed_form_tau_M.py under pn_convention="bring_color_weighted" (PROVED, PR #690/#942).

                            class QOU.BraidsAndKnots.InterNucleonChannelColorTube [BringFiberAction] :
                            Type

                            CONJECTURE (§3b-cond class). Inter-nucleon Hecke channel assignment from Bring color-tube weighting: the canonical color-pair weight tensor W_{c₁c₂}(F₁, F₂) ∈ ℚ≥0, normalised to Σ_{c₁c₂} W = 1 per flavor pair, so the refined generator σ^(F₁,F₂) = Σ W_{c₁c₂} σ^{ε(c₁,c₂,F₁,F₂)} is a categorical average over the 9 color-sheet pairs.

                            The [BringFiberAction] binder records the conditional structure of the block ("conditional on conj:s5-so3-fiber-action"); that supplier class is now discharged by the icosahedral Reeb instance (bringFiberAction_icosahedral). The remaining open content — the closed form of W as a tensor in the SO(3)-fiber data over Bring, with no residual degrees of freedom — is exactly what an instance of this class must supply. No global instance is provided: the uniform-flavor projection uniformColorTubeData below witnesses satisfiability but is deliberately not registered, because it is the flavor-only collapse the conjecture identifies as missing the per-arc structure.
