      Manuscript sub-claim (ii) — the border-strip recursion: the recursive value is the signed sum over border strips of size ρ_1,

      χ^λ_ρ = Σ_{ξ ∈ BS(λ, ρ_1)} (-1)^{ht(ξ)} · χ^{λ∖ξ}_{ρ∖ρ_1}.

      This is the Murnaghan–Nakayama rule, written out. It was claim_ii_miss_computes_via : Prop with a _holds witness beside it — a field typed with the universe Prop, so the instance chose the proposition and ⟨True, trivial⟩ discharged it. The docstring said the recursion "stays abstract because it requires enumeration of border strips"; the enumeration is now a field, so it does not.

      Proposition statement (from manuscript):

      The classical Murnaghan-Nakayama rule expresses $\chi_\rho^\lambda$ recursively via border-strip removal:*

      $$ \chi_\rho^\lambda \;=\; \sum_{\xi \in BS(\lambda, \rho_1)} (-1)^{\mathrm{ht}(\xi)} \, \chi_{\rho \setminus \rho_1}^{\lambda \setminus \xi} $$

      where $BS(\lambda, \rho_1)$ is the set of border strips of size $\rho_1$ in $\lambda$, $\mathrm{ht}(\xi)$ is the height of strip $\xi$, and $\rho \setminus \rho_1$ is $\rho$ with its first part removed.
