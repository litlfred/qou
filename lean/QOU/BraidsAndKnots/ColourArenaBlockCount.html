    QOU.BraidsAndKnots.ColourArenaBlockCount #

    — the block-count backbone of "no finite colour arena"

    The production nuclear-mass trace is the full Hecke / Wenzl principal specialization s_λ(1, q, q², …), which is nonzero for every partition λ. A finite colour arena ℂ^N realizes the N-variable specialization s_λ(1, q, …, q^{N-1}), which by the Schur row-bound

      s_λ(x₁, …, x_N) = 0   ⟺   rows(λ) > N

    is zero for every λ with more than N rows. So a finite ℂ^N "misses" the trace content carried by the >N-row Wedderburn blocks. The empirical weighted miss-share grows with the mass number A (3.4% @⁴He → 6.0% @⁵He, audit 2026-06-16-keystone-arena-is-full-hecke-not-su3.md).

    This file formalizes the part that is a theorem: the block-count backbone. The Schur row-bound itself is a classical symmetric-function fact (verified numerically for n = 5, 6 in keystone_full_hecke_not_su3_arena.py and colour_arena_missed_block_count.py); here it is the premise defining missedByColourArena, and the counting consequence is proved sorry-free:

    • appendUnitRows N injects every partition of size m into the colour-ℂ^N-MISSED partitions of size m + (N+1) (missedEmbedding, missedEmbedding_injective);
    • hence the missed-block family is unbounded as the size n ∝ A grows — no finite N captures the trace for all A (no_finite_colour_arena).

    The witness appends N+1 unit rows (μ ↦ μ ++ (1^{N+1})), extending the first column downward by N+1 boxes; it is canonical (weakly-decreasing) whenever μ is, since every part of μ is ≥ 1. Rows = List.length (the corpus Partition := List ℕ imposes no order at the type level, but the witness stays in canonical form).

    The weighted miss-share monotonicity (3.4% → 6.0%) is not formalized: it is q₀- and braid-dependent (principal-spec weights × oscillating χ_λ(β_A)), and is the weighted face of this count backbone, not a corollary.

    Refs:

    • [macdonald1995] Symmetric Functions and Hall Polynomials, I.3 (Schur row-bound)
    • [wenzl1988] Hecke algebras of type A_n and subfactors, Invent. Math. 92
    • [manuscript] docs/audits/2026-06-19-colour-arena-block-count-theorem.md

            theorem QOU.BraidsAndKnots.ColourArenaBlockCount.no_finite_colour_arena (N : ℕ) (mu : MathlibExt.QPartitionCombinatorics.Partition) :
            ∃ (lam : MathlibExt.QPartitionCombinatorics.Partition), List.sum lam = List.sum mu + (N + 1) ∧ missedByColourArena N lam

            No finite colour arena. For every fixed colour dimension N and every shape μ, there is a partition of size |μ| + (N+1) that the colour-ℂ^N arena misses; ranging μ over all partitions of m = n-(N+1) gives (via the injection missedEmbedding) at least p(n-N-1) distinct missed blocks at size n — unbounded in A.

            This is the structural upgrade of "no finite colour arena" from the empirical 3.4% → 6.0% data points to a block-count theorem: a finite ℂ^N cannot capture the full-Hecke trace for all mass numbers A.
