    QOU.BraidsAndKnots.QSchurYLambdaClosedForm #

    q-Schur Plancherel weights y_λ(q) closed-form via q-content principal specialization:

    y_λ(q) = q^{c(λ)} / [n]_q!
  where c(λ) = Σ_{(i,j) ∈ λ} (j − i) is the content sum
        [n]_q! = Π_{k=1}^n (q^k − q^{-k})/(q − q^{-1})

    This file is the qou Lake package canonical Lean for content block prop:q-schur-y-lambda-closed-form introduced in PR #1259.

    Why this matters for 1ppb: per the 1ppb status dashboard, q-Schur Plancherel is the convention used by Q_β at N=3 categorical, which is the only observable currently meeting Subgoal-1 (6.02 ppb pred vs 7.80 ppb target). Formalising the closed-form identity establishes the structural backbone for the Q_β derivation chain at Lean level.

    What's defined (Lean-typed, sorry-free) #

    • contentSum λ — Σ_{cells (i,j) ∈ λ} (j − i)
    • qBracket k q — [k]_q = (q^k − q^{-k}) / (q − q^{-1})
    • qFactorial n q — [n]_q! = Π_{k=1}^n [k]_q
    • ySchurClosedForm λ q — q^{c(λ)} / [n]_q!

    What's conjectural (axiomatised as class — §3b-cond) #

    • QSchurYLambdaClosedFormClaim: the closed form ACTUALLY IS the q-Schur Markov-trace Plancherel weight at every n and every q. Axiomatised as a class with an abstract qSchurWeight field (the categorical weight, awaiting Mathlib's q-Schur algebra formalisation) and an extensional identity closed_form_holds : ∀ λ q, ySchurClosedForm λ q = qSchurWeight λ q. This is a known theorem in q-Schur duality (Lusztig 1990, Beilinson-Lusztig-MacPherson); the class deviates from the repo's vacuous-True §3b-cond convention because PR #1720 review (Gemini) flagged the placeholder as semantically degenerate.

    • qSchur_H2_top, qSchur_H2_bottom, qSchur_H2_normalization: the H_2 case explicit identities, sorry-free via unfold + decide + qFactorial + qBracket + field_simp + ring. These are concrete q-bracket identities — the class QSchurYLambdaClosedFormClaim above carries the categorical content extensionally (∀ λ q, ySchurClosedForm λ q = qSchurWeight λ q); see the class docstring.

    • qSchur_H3_top, qSchur_H3_mid, qSchur_H3_bottom: the H_3 case explicit identities for partitions (3), (2,1), (1,1,1), sorry-free via the same H_2 pattern. Helper lemmas q_add_inv_ne_zero and q_sq_add_one_add_inv_sq_ne_zero factor the non-vanishing side-conditions. Unlike H_2 there is no clean "normalization" theorem at H_3 because the unweighted partition sum is not 1 — Plancherel weighting by dim_q(λ)² would be required, deferred to the q-Schur algebra formalisation that discharges QSchurYLambdaClosedFormClaim.

    H_2 cross-check (numerically verified in PR #1259 audit) #

    y_(2)(q) = q · q^0 / ([1]_q · [2]_q) = q / (q + q⁻¹) (since [1]_q = 1, [2]_q = q + q⁻¹)

    y_{(1,1)}(q) = q^{-1} / [2]_q! = q⁻¹ / (q + q⁻¹)

    Sum: (q + q⁻¹) / (q + q⁻¹) = 1 ✓ Plancherel normalization

    The audit's H_2 cross-check (docs/audits/2026-05-25-markov-trace-convention-audit.md) confirms this numerically against pn.trace_weights_n_q_schur(2, q).

                class QOU.BraidsAndKnots.QSchurYLambdaClosedForm.QSchurYLambdaClosedFormClaim :
                Type

                Conjecture (axiomatised as class per AGENTS.md §3b-cond).

                For every partition λ and every valid q : ℝ, the q-Schur Markov-trace Plancherel weight y_λ^{qSchur}(q) equals the closed form ySchurClosedForm λ q = q^{c(λ)} / [n]_q!.

                This is a known theorem in q-Schur duality (Lusztig 1990, Beilinson–Lusztig–MacPherson) but its Lean formalisation from Mathlib axioms requires the q-Schur algebra structure not currently in Mathlib. The class axiomatises this via an abstract qSchurWeight field (the categorical weight, awaiting the Mathlib formalisation) and an extensional closed_form_holds identity asserting equality with ySchurClosedForm everywhere. Downstream theorems depending on this closed form take this class as an [Instance] hypothesis per §3b-cond.

                Convention deviation note: most §3b-cond classes in the repository (~80-100, registered under lean-section-3b-cond-classes-permanent) use a vacuous True placeholder field. This class uses the stronger extensional form per PR #1720 review (Gemini, 2026-06-03); the repo-wide convention is unchanged.

                • qSchurWeight : List ℕ → ℝ → ℝ

                  The categorical q-Schur Markov-trace Plancherel weight, awaiting Mathlib's q-Schur algebra formalisation. Until then this field is provided abstractly by any instance of the class; the conjecture is closed_form_holds below.

                • closed_form_holds (lam : List ℕ) (q : ℝ) : ySchurClosedForm lam q = qSchurWeight lam q

                  The conjecture: the closed form ySchurClosedForm agrees with the q-Schur weight qSchurWeight at every partition and every valid q, i.e. y_λ^{qSchur}(q) = q^{c(λ)} / [n]_q!. Any instance of this class commits to that extensional identification.

                  H_3 explicit identities #

                  For partitions of n = 3:

                  c((3)) = 3 ⇒ y_(3)(q) = q^3 / [3]q! c((2,1)) = 0 ⇒ y{(2,1)}(q) = 1 / [3]q! c((1,1,1)) = -3 ⇒ y{(1,1,1)}(q) = q⁻³ / [3]_q!

                  with [3]_q! = [3]_q · [2]_q · 1 = (q² + 1 + q⁻²)(q + q⁻¹).

                  Unlike H_2, the analogue of qSchur_H2_normalization requires weighting by dim_q(λ)² (q-Schur Plancherel measure on the dual chain) — dim((2,1)) = 2 makes the un-weighted sum y_(3) + y_{(2,1)} + y_{(1,1,1)} not equal to 1. We therefore state the three identities only; a full Plancherel statement is left to the future q-Schur algebra development that will discharge QSchurYLambdaClosedFormClaim.
