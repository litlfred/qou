    The DT-realization predicate #

    `(md, vc)` assigns to each block a moduli complex-dimension `md λ` and a
Behrend-weighted virtual count `vc λ`; it *realizes* `Δ_λ` when the resulting
Behrend-signed DT count `(-1)^{md λ}·vc λ` reproduces the corpus binding
factor `deltaLambda` for every block.  The Springer/toy reading is
`(md, vc) = (nStat, dim)`.

      theorem QOU.BraidsAndKnots.dt_moduliDim_underdetermined :
      ∃ (md₁ : PartitionOf5 → ℕ) (md₂ : PartitionOf5 → ℕ), IsDTRealization md₁ PartitionOf5.dim ∧ IsDTRealization md₂ PartitionOf5.dim ∧ ∀ (p : PartitionOf5), md₁ p ≠ md₂ p

      THE CRUX (limitative). The Δ_λ = Behrend-signed DT-count target UNDER-DETERMINES the moduli dimension: two DISTINCT moduli-dimension assignments — the Springer value n(λ) and n(λ)+2 — both realize Δ_λ with the substrate count dim V_λ. So matching Δ_λ constrains the moduli dimension only mod 2 (its Behrend-sign parity), never the actual Springer value n(λ) = dim_ℂ 𝓑_λ. The Δ_λ = DT-count identification therefore does NOT force the Springer fibre 𝓑_λ; the dimension n(λ) must come from an independent substrate map (the a-function / GS jet-order valuation). This is the precise sense in which the toy moduliDim := nStat merely READS the answer — the open internal derivation (DeltaLambdaDTRealization, bean qou-ylot) is not closed by the DT identity.
