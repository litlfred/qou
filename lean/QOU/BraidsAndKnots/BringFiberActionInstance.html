    The geometric build: the forced BringFiberAction instance #

    The s5-so3 keystone's conditional class BringFiberAction (S5SO3FiberAction.lean) carries the geometric fibre map irrepToRotation : A5Irrep → IcosahedralRotation and its substantive injectivity field five_distinct_classes (the five A₅ irreps realize five DISTINCT icosahedral rotation angles). Every downstream keystone result (s5_so3_fiber_action_scaffold, reeb_eq_restriction_scaffold) was conditional on [BringFiberAction]. This file discharges it with the forced icosahedral data.

    The map is determined. A₅ ≅ the icosahedral rotation group I ⊂ SO(3) (Klein 1884). The per-irrep icosahedral Reeb phase is θ_λ = arccos(χ_λ(C₅)/dim_λ), where χ_λ(C₅) is the A₅ character on the 5-fold conjugacy class. The five cosines are exact (A₅ character table; PR #2591 validated the angle assignment to 5×10⁻⁴¹, with the golden-ratio fingerprint χ_{ℓ=1}(72°)=1+2cos72°=φ):

    irrep dim χ(C₅)/dim
    A 1 1
    T₁ 3 (1+√5)/6 = φ/3
    T₂ 3 (1−√5)/6 = −φ⁻¹/3
    G 4 −1/4
    H 5 0

    These five reals are distinct, so the five Reeb phases are distinct (arccos is injective on [−1,1]), and five_distinct_classes holds. The instance is therefore content-bearing, not the falsified vacuous : True map (AGENTS.md §3b): irrepToRotation is the genuine icosahedral Reeb map and its injectivity is proved from the character data.

    Scope (honest). This discharges conj:s5-so3-fiber-action — the fibre-map existence + the distinct-angles half — with the validated icosahedral angles, making s5_so3_fiber_action_scaffold (and the conjugation-identification it derives) unconditional.
