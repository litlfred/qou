    The discriminant of the colour cubic — generic identities #

    Chip on conj:hecke-monodromy-step-two (QOU.Mass.HeckeMonodromy). The probe computations/probes/colour_cubic_branch_monodromy_probe.py computes, exactly in sympy, the X-discriminant of the colour cubic P(X, z) = X³ + (z+1)X² + (z²+z+1)X + (z³+z²+z+1):

    disc_X P = −(16z⁶ + 24z⁵ + 35z⁴ + 50z³ + 35z² + 24z + 16),

    and records two facts about the sextic D(z) in that bracket that this file makes theorems over a generic field:

    • colourDiscriminant_reciprocal — D is reciprocal: z⁶ · D(z⁻¹) = D(z) for z ≠ 0. This is the structural reason the six branch points come in pairs z ↔ 1/z on a common ray, which is what forced the probe's lasso paths to detour (its lasso(...) docstring).
    • colourDiscriminant_sos — the sum-of-squares identity D(z) = (4z³ + 3z² + 3z + 4)² + 2z²(z² + 1), a pure ring identity. Over an ordered field it gives D > 0 everywhere, i.e. no real branch point — that archimedean consequence lives in QOU/Mass/ColourCubicDiscriminantReal.lean per §7c.

    The discriminant is −D, so its sign is opposite; only the vanishing locus matters for the branch points, and D and −D share it.

    Base ring §7c: CommRing R for the sum of squares, Field K for the reciprocity (needs z⁻¹).
