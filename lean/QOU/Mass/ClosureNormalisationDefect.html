    Juxtaposition carries one loop factor, so the free energy is not additive #

    QOU.MathlibExt.MarkovTraceMultiplicative.markovTrace_juxtapose proves the matrix identity tr(A ⊗ₖ B) = tr A · tr B, and QOU.Mass.ArchimedeanTraceBridge.freeEnergy_juxtapose reads it as free-energy additivity. Both are correct about matrices.

    The reading as knots is off by exactly one loop factor, and this file makes the defect machine-checked rather than leaving it as a caveat.

    The measurement that forces this #

    computations/_li_2_q_util.py:777-783 records that the Markov closure of an n-strand braid is normalised by the loop value raised to n − 1. Juxtaposing an m-strand braid with an n-strand braid produces an m + n-strand braid, so the normaliser goes

    δ^{m−1} · δ^{n−1} = δ^{m+n−2}    ⟼    δ^{m+n−1}

    — one factor of δ that the unnormalised matrix identity does not see. At the proton-pinned q₀ = 1.1099785827513808 the canonical (Wenzl) loop value is δ = [2]_q = q + q⁻¹ = 2.01089686671, so log δ = 0.6985808249 per juxtaposition, and ⁴He (four components, three juxtapositions) is short by ≈ 2.096 in free energy.

    Do not read q + 2 + q⁻¹ = 4.0109 as δ. That figure, which appears in the source line above, is δ_C² — a loop value already raised to n − 1 = 2 for a three-strand closure. Mistaking it for δ doubles log δ to 1.389.

    What is proved here #

    closureNorm δ k t = t / δ^k is the closure-normalised trace of a (k+1)-strand braid whose unnormalised trace is t (indexing by k = n − 1 keeps the exponent a natural number).

    • closureNorm_juxtapose — the normalised traces multiply only after paying δ: closureNorm δ a A * closureNorm δ b B = δ * closureNorm δ (a+b+1) (A*B).
    • freeEnergy_closureNorm_juxtapose — hence the free energy is additive up to log δ, not additive.
    • freeEnergy_closureNorm_additive_iff — and it is genuinely additive iff δ = 1, which the substrate does not satisfy: [2]_q = 1 forces q = 1, excluded at q₀ > 1.
    • loopValue_ne_one — [2]_q ≠ 1 for q > 1, so the exception never applies here.

    What this does NOT say #

    The matrix-level results it corrects are true and stay true; nothing in MarkovTraceMultiplicative is refuted. What is corrected is the identification of that identity with the knot-theoretic statement, and specifically the claim that a disjoint trivial component costs no free energy. It costs log δ.

    This also does not settle which normalisation the framework's mass observable uses. If the amplitude is already closure-normalised, the defect below applies; if it is the raw matrix trace, markovTrace_juxtapose applies unchanged and the connected-sum reading is the one to drop. One of the two must give — the commit that introduced them claimed both. Bean qou-bsfg.

      theorem QOU.Mass.ClosureNormalisationDefect.closureNorm_juxtapose {R : Type u_1} [Field R] {δ : R} (hδ : δ ≠ 0) (a b : ℕ) (A B : R) :
      closureNorm δ a A * closureNorm δ b B = δ * closureNorm δ (a + b + 1) (A * B)

      Juxtaposition costs one loop factor. Normalised traces do not simply multiply: combining a (a+1)-strand and a (b+1)-strand closure into an (a+b+2)-strand one loses one power of δ relative to the product. This is the precise sense in which the unnormalised identity tr(A ⊗ₖ B) = tr A · tr B over-counts.

        The substrate never sits at the exceptional point. For q > 1 the loop value exceeds one — q + q⁻¹ > 1 — so freeEnergy_closureNorm_additive_iff's escape hatch is closed and the log δ term is always present. At q₀ it is log 2.01089686671 = 0.6985808249 per juxtaposition.

        A components, not two #

        The section this corrects (MarkovTraceMultiplicative, "Extensivity: n disjoint components multiply") states the two-fold case and cites an induction that is not there. With the loop factor in hand the A-fold statement is worth having, because the deficit grows with A rather than being a one-off constant.

        Joining A components with strand counts n_i = k_i + 1 gives ∑ n_i strands, so the normaliser goes from ∏ δ^{n_i − 1} = δ^{∑ k_i} to δ^{∑ k_i + (A − 1)} — the composite is short by δ^{A−1}, and the free energy by (A − 1)·log δ. Writing A = m + 1 keeps the exponent a natural number. At q₀, ⁴He (m = 3) is short by 3 · 0.6985808249 = 2.0957424747.
