    inductive QOU.Mass.BondChannelClassSelection.CalClass :
    Type

    The three calibration classes of the canonical triple (the ideal mathematical calibrations; AGENTS.md cheat-sheet table).

    • cal1 : CalClass

      CAL-1: the leptonic mass scale m_e — the W-plane scale.

    • cal2 : CalClass

      CAL-2: the β-decay width P_skew^β, numerically pinned via m_μ/m_e — the W-plane modulus q₀, a dimensionless quantity.

    • cal3 : CalClass

      CAL-3: the pion-sector bar-even channel P_avg^π / meson scale m_π — the cohomologically orthogonal Vol(Hopf) = 0 class.

      structure QOU.Mass.BondChannelClassSelection.BondChannelModel (R : Type u_2) [CommRing R] :
      Type u_2

      Small algebraic model of the three calibration classes and their length-scale support on the inter-nucleon bond channel. The field volBond_eq_zero records the geometric input: the bond channel is the 2-body Hopf class, whose complement is non-hyperbolic, Vol(Hopf) = 0 (SnapPy-verified; ledger docs/coordination/binding-scale-is-hyperbolic-volume.md).

      • me : R

        CAL-1 scale m_e (the W-plane scale / dimensional unit).

      • mpi : R

        CAL-3 scale m_π (the orthogonal meson scale).

      • qFactor : CalClass → R

        Dimensionless q₀-rational factor attached to each class — CAL-2's entire contribution enters through such factors (q₀ is dimensionless, so CAL-2 carries no length scale of its own).

      • volBond : R

        Hyperbolic volume of the bond (Hopf, 2-body) channel.

      • support : CalClass → R

        Dimensionful support of each calibration class on the bond channel.

      • volBond_eq_zero : self.volBond = 0

        Geometric input: Vol(Hopf) = 0 (the Hopf complement is non-hyperbolic).
