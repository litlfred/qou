    def QOU.Mass.KindDependentBondBreaksIntegrality.bRatioKind (ρ₁ ρ₂ ρ₃ m₁ m₂ m₃ : ℚ) :
    ℚ

    b₃/b₂ when the bond weight may depend on the kind of pair the interface joins. ρᵢ is pair i's weight in units of the reference pair's — and the reference is the pn pair, because b₂ is measured on the deuteron, which is pn. Setting every ρᵢ = 1 recovers the uniform case.

      And it is not the same function — the generalisation has content. A single kind whose weight differs moves the ratio by exactly that difference, so bRatioKind is not constant in ρ. Without this the extension could be vacuous.

      The forced kind-ratio for the minimal ³He carrier.

      ³He is ppn: one pp pair and two pn pairs. With the minimal Brunnian counts mᵢ = 1 and the pn weight as the reference, the measured ratio is reproduced iff

      ρ_pp  =  1 + rMeasured  =  2433859 / 1483044  ≈  1.64112 .

      Read RIGHT-TO-LEFT only: this is the number qou-qqm4's derived z + d_kind at the pp interface must independently produce. Computing ρ_pp from the left is a one-parameter fit — see the banner above.

      theorem QOU.Mass.KindDependentBondBreaksIntegrality.kind_ratio_not_determined_by_sum :
      ∃ (ρ : ℚ) (m₁ : ℚ) (m₂ : ℚ) (m₃ : ℚ) (m₁' : ℚ) (m₂' : ℚ) (m₃' : ℚ), m₁ + m₂ + m₃ = m₁' + m₂' + m₃' ∧ bRatioKind ρ 1 1 m₁ m₂ m₃ ≠ bRatioKind ρ 1 1 m₁' m₂' m₃'

      Why the exhaustion cannot see this. Its ratio depends only on the sum of the counts (bRatio_depends_only_on_sum); the kind-dependent ratio does not, because two carriers with the same total can distribute their crossings over pairs of different kinds. So the collapse that makes the exhaustion exhaustive is exactly what a kind-dependent weight breaks.
