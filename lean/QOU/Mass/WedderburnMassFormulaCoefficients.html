    theorem QOU.Mass.WedderburnMassFormulaCoefficients.haSq_eq_qIntBal_three_sub_three {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) (hqq : q - q⁻¹ ≠ 0) :
    (q - q⁻¹) ^ 2 = QInteger.qIntBal q 3 - 3

    The identity. The Hecke–Skein parameter squared is the third balanced q-integer, shifted by 3: h_A² = [3]_q − 3.

    Needs q ≠ q⁻¹ only because qIntBal divides by q − q⁻¹; at q = ±1 the quantum integer degenerates and the statement is vacuous rather than false.

    theorem QOU.Mass.WedderburnMassFormulaCoefficients.beta3_of_beta2 {R : Type u_1} [Field R] (q b₂ b₃ : R) (hq : q ≠ 0) (hqq : q - q⁻¹ ≠ 0) (h₂ : b₂ = -2 * QInteger.qIntBal q 3) (h₃ : b₃ = (q - q⁻¹) ^ 2) :
    2 * b₃ + b₂ + 6 = 0

    The dependency. Given the published shapes β₂ = −2[3]_q and β₃ = h_A², the two coefficients satisfy one linear relation with no q in it at all:

    2·β₃ + β₂ + 6 = 0        (equivalently `β₃ = −β₂/2 − 3` wherever `2` is a unit)

    So the correction term carries one q-integer degree of freedom, not two. Stated multiplicatively to stay valid in every characteristic — dividing by 2 would need (2 : R) ≠ 0, a hypothesis the content does not require.

    Falsifiable, and it is exactly what the recorded pair (β₂, β₃) = (−6.087415, 0.0499) violates: it evaluates to 2(0.0499) − 6.087415 + 6 = +0.012385, not 0. The same β₂ forces β₃ = 0.0437073.
