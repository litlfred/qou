    theorem QOU.Mass.CostOrderSensitivity.minimal_transfers_along_fibre {W : Type u} {Q : Type v} {R : Type w} [Preorder R] {Feasible : W → Prop} {cands : Set W} (π : W → Q) (f : Q → R) {w₁ w₂ : W} (hfib : π w₂ = π w₁) (h₁min : ∀ (w' : W), w' ∈ cands → Feasible w' → f (π w₁) ≤ f (π w')) (w' : W) :
    w' ∈ cands → Feasible w' → f (π w₂) ≤ f (π w')

    Minimality transfers along the fibre. If the cost is f ∘ π and w₂ lies in the same fibre of π as a cost-minimal w₁, then w₂ is cost-minimal too. Nothing about words is used: this is a statement about minimising a function that is constant on fibres.

    theorem QOU.Mass.CostOrderSensitivity.selected_not_determined_of_cost_factors {W : Type u} {Q : Type v} {R : Type w} [Preorder R] {Feasible : W → Prop} {cands : Set W} (π : W → Q) (f : Q → R) {w₁ w₂ : W} (hne : w₁ ≠ w₂) (hfib : π w₂ = π w₁) (h₁mem : w₁ ∈ cands) (h₁feas : Feasible w₁) (h₁min : ∀ (w' : W), w' ∈ cands → Feasible w' → f (π w₁) ≤ f (π w')) (h₂mem : w₂ ∈ cands) (h₂feas : Feasible w₂) :
    ∃ (a : W), ∃ (b : W), a ≠ b ∧ (a ∈ cands ∧ Feasible a ∧ ∀ (w' : W), w' ∈ cands → Feasible w' → f (π a) ≤ f (π w')) ∧ b ∈ cands ∧ Feasible b ∧ ∀ (w' : W), w' ∈ cands → Feasible w' → f (π b) ≤ f (π w')

    The step FrobeniusSelected.cost_eq stops short of. If two distinct feasible candidates lie in the same fibre of a quotient the cost factors through, then the minimal-cost selection predicate holds of both, so it does not determine the word.

    The three conjuncts are exactly FrobeniusSelected's mem, feasible and minimal, spelled out rather than by re-declaring that structure — this is a statement about the corpus's selection rule, not a second copy of it.

    A letter-sum cost: the cost of a word is the sum of a per-letter weight. Crossing count is weight ≡ 1; writhe is weight = ±1; the crossing energy E_cross measured in qou-99qc is weight = ±h.

      Non-vacuity #

      The fibre hypothesis with w₁ ≠ w₂ is satisfiable, so the theorems above are not about an empty case. This is the abstract shape of the pair the sibling probe measured: σ₁σ₀ and σ₀σ₁ tie at 2q under E_cross while the Q_β they produce differ by roughly a factor of two.
