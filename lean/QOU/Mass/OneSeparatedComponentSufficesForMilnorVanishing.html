    structure QOU.Mass.OneSeparatedComponentSufficesForMilnorVanishing.Summands :
    Type

    Two components are joined when some summand of the connected-sum decomposition touches both. On a monotone closure a summand is one generator's run, so it touches only the components containing strands g and g+1 — measured at most two. The single hypothesis joins_linked is what the topology supplies: a shared (2, k) torus summand links the two components it joins.

    • joins : ℕ → ℕ → Prop

      some summand of the connected sum touches both components

    • lk : ℕ → ℕ → ℤ

      linking numbers of the closure

    • joins_linked (i j : ℕ) : self.joins i j → self.lk i j ≠ 0

      sharing a summand makes two components linked

      def QOU.Mass.OneSeparatedComponentSufficesForMilnorVanishing.SplitsOff (S : Summands) (k i j : ℕ) :
      Prop

      Component k splits off from the pair i, j when it shares a summand with neither. This is what makes μ̄ vanish on {i, j, k}: λ_k is then trivial in the quotient generated by the meridians of i and j, so the h_i h_j coefficient is zero. Note it says nothing about whether i and j are linked to each other.

          structure QOU.Mass.OneSeparatedComponentSufficesForMilnorVanishing.PathCarrierextends QOU.Mass.OneSeparatedComponentSufficesForMilnorVanishing.Summands :
          Type

          The path carrier: lk vanishes off consecutive pairs. Stated in the direction actually used — non-adjacent implies unlinked — so nothing below silently requires more than the measurement supports.

          This hypothesis is no longer a measurement (2026-09-05). MonotoneWordComponentStructure.linking_only_between_adjacent proves it for every monotone word: a run crossing two distinct components puts them at compIdx g and compIdx g + 1, so only consecutive components can be linked. The P_μ shape was carried as a measured fact across this whole arc — 7 isotopes, both crossing-resolution branches — and it is a theorem. Kept as a structure field because the consumers below take a carrier as given; it is now an instantiable hypothesis rather than an assumed one.

            theorem QOU.Mass.OneSeparatedComponentSufficesForMilnorVanishing.not_adjacent_of_lt_lt {a b c : ℕ} (hab : a < b) (hbc : b < c) :
            ¬Adjacent a c

            The two outer members of an ordered triple are never adjacent — a < b < c forces c ≥ a + 2. Small, but it is what makes the trichotomy below a trichotomy: the pair (a, c) is unlinked in every case, so only (a,b) and (b,c) can vary.

            theorem QOU.Mass.OneSeparatedComponentSufficesForMilnorVanishing.splitsOff_or_consecutive (P : PathCarrier) {a b c : ℕ} (hab : a < b) (hbc : b < c) :
            (SplitsOff P.toSummands a b c ∨ SplitsOff P.toSummands c a b) ∨ b = a + 1 ∧ c = a + 2

            The residual is exactly the consecutive triple. On the path carrier an ordered triple either has a component that splits off — putting it inside splitsOff_of_unlinked's reach — or it is {a, a+1, a+2}. There is no third case.

            So the 31 triples the carrier leaves uncovered are not a ragged remainder to be chipped at with more linking-number bookkeeping; they are one shape, and closing them needs a genuinely different invariant (see the header).
