          noncomputable def QOU.Mass.SelfMutualPartition.binding {C : Type u_1} (E : Finset C) (energy : C → ℝ) (isInter : C → Prop) [DecidablePred isInter] :
          ℝ

          Binding energy, by the standard mass-deficit definition: the sum of the isolated component masses (each = that component's self energy, since an isolated component has no inter-component crossings) minus the assembled mass. Here the sum of isolated masses is selfEnergy (the self crossings are exactly those present in isolation).

            theorem QOU.Mass.SelfMutualPartition.binding_eq_neg_mutualEnergy {C : Type u_1} (E : Finset C) (energy : C → ℝ) (isInter : C → Prop) [DecidablePred isInter] :
            binding E energy isInter = -mutualEnergy E energy isInter

            R2 — binding is exactly the (negative of the) mutual pairing. The self energies cancel: rest mass is the self part, binding is the inter-component mutual part. The assignment mass ↔ self, binding ↔ mutual is a theorem of the crossing partition plus the mass-deficit definition, not a modelling postulate.

              noncomputable def QOU.Mass.SelfMutualPartition.coordinationUnits {C : Type u_1} (E : Finset C) (isInter : C → Prop) [DecidablePred isInter] :
              ℝ

              Coordination units = ½ · (inter-component crossing count). One coordination unit per clasp; a clasp is two inter-component crossings (a minimal Brunnian bond, n₊ = n₋ = 1). This is the general crossing-count → coordination coefficient — no minimal-bond restriction.
