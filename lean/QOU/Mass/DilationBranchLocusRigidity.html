    QOU.Mass.DilationBranchLocusRigidity — no nontrivial dilation preserves the branch locus #

    The colour spectral curve Σ : P(X,z) = 0 of the Lever-1 binding kernel is a 3-sheeted cover of the z-line whose branch locus is the zero set of the branch sextic

    D(z) = 16z⁶ + 24z⁵ + 35z⁴ + 50z³ + 35z² + 24z + 16

    (= −disc_X P, QOU.Mass.ColorSpectralCubicGeometry.color_cubic_discriminant).

    This file proves that D is rigid under scaling: if precomposing D with a dilation z ↦ l·z returns a constant multiple of D, then l = 1 (and the constant is 1). Two coefficients do all the work — the constant term forces c = 1, and the linear term then forces l = 1.

    Why this closes a route (bean qou-lmnq; wall W1, qou-d8de) #

    The W1 wall asks for a q-difference prolongation D_q built from Σ, and its first named route is a q-shift on the base, z ↦ q²z. Two prior tranches excluded that route by the coefficient field: no rational q-connection on the z-line has the sheets as flat sections (QOU.Mass.ColorCubicIrreducible, PR #6695), and the same exclusion survives passage to the ramified local chart (QOU.Mass.IrreducibleCubicNoQuadraticRoot, PR #6738). What those left open was an operator living on Σ itself rather than on a coordinate.

    This file closes that, and it needs no rationality theorem. The geometric step is stated here in prose and is not formalised: an automorphism σ : Σ → Σ covering z ↦ l·z is an isomorphism of coverings up to the base automorphism, so it carries ramification points to ramification points and therefore permutes the finite branch locus B. Because D is squarefree (exactly checked in the companion probe) and D(0) = 16 ≠ 0, "l·B = B" says precisely that D(l·z) and D(z) have the same root multiset, i.e. D ∘ (l·) = c·D for a constant c. That hypothesis is where this file starts, and from it l = 1 — so the only dilation admitting a lift to Σ is the identity, for every l, root of unity or not, at every q.

    The complementary half — that Σ → P¹ has full S₃ monodromy, hence no single-valued algebraic branch — is already held in the corpus and is cited rather than re-derived: computations/qbeta/c3_w1_cover_monodromy.py.

    Currency note (2026-09-12). The paragraph above says "the geometric step is stated here in prose and is not formalised". That step is two halves, and only one is still prose. An automorphism of Σ permutes B remains prose — genuinely geometric, about coverings and ramification. A map sending a finite set of nonzero points into itself has finite order is now proved: QOU.Mass.BranchLocusFiniteOrder.exists_pow_eq_one_of_stabilizes, with the substrate corollaries not_stabilizes_of_one_lt_real / ..._complex ruling out every real l > 1. The general-Möbius determinacy behind Stab(B) ↪ Sym(B) is also proved, in QOU.Mass.MoebiusThreePointRigidity. So the prose chain from here to the conclusion is one link long, not two.

    Ground ring: [Field K] [CharZero K] (§7c). Characteristic zero is used exactly to invert 16 and 24; nothing archimedean appears.

      l = 1 ∧ c = 1

      Scaling rigidity of the branch locus. If the branch sextic precomposed with a dilation z ↦ l·z is a constant multiple of itself, then l = 1 and the constant is 1.

      The constant term gives 16 = c·16, hence c = 1; the linear term then gives 24·l = 24, hence l = 1. Characteristic zero is used only to invert those two integers.

      No nontrivial dilation preserves the branch locus. Contrapositive form: a dilation by l ≠ 1 cannot send the branch sextic to a multiple of itself, so (by the covering argument in this file's header) it admits no lift to Σ.
