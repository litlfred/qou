    Involution (telephone) numbers — the q = 1 shadow of S(n) = ∑_{λ⊢n} dim_q(λ) #

    The binding q-deformation period S(n) = ∑_{λ ⊢ n} dim_q(λ) (see mass-theory/cyclotomic-boundary-at-keystone) has q = 1 value S(n)|_{q=1} = ∑_{λ ⊢ n} f^λ = I(n), the involution / telephone numbers (OEIS A000085: 1, 1, 2, 4, 10, 26, 76, …), by the Frobenius–Schur identity (RSK: involutions ↔ standard Young tableaux). I(n) is the number of self-inverse permutations of n elements and satisfies

    I(n) = I(n-1) + (n-1)·I(n-2)

    (split an involution of {1,…,n} on the image of n: fixed — I(n-1); or swapped with one of the n-1 others — (n-1)·I(n-2)).

    This file defines involutionNumber by that recurrence and proves (card_involutions_eq_involutionNumber) that it equals the actual count of involutions {σ ∈ Sₙ : σ² = 1} for all n, grounding the q = 1 shadow. The proof is a clean bijective argument: strong (two-step) induction on n, reduced to the count recurrence card(inv Sₙ₊₂) = card(inv Sₙ₊₁) + (n+1)·card(inv Sₙ), which is proved by splitting an involution σ on p := σ 0 (fixed-point vs transposition) via the point-restriction bijection involSubtypeEquiv. Sorry-free (axioms: propext, Classical.choice, Quot.sound).

    The full F1 target (the q-lift S(n) and its cyclotomic-boundary recurrence) sits above this on the Mathlib-absent q-hook-length / RSK machinery.

      The general count identity card(involutions of Fin n) = involutionNumber n #

      We prove the identity for all n by two-step induction, the inductive step being the count recurrence card(inv Fin (n+2)) = card(inv Fin (n+1)) + (n+1)·card(inv Fin n).

      theorem QOU.Mass.card_involutions_eq_involutionNumber (n : ℕ) :
      Fintype.card { σ : Equiv.Perm (Fin n) // σ * σ = 1 } = involutionNumber n

      General count identity. The number of involutions (self-inverse permutations) of Fin n equals involutionNumber n, for every n. Equivalently, involutionNumber counts ∑_{λ ⊢ n} f^λ by the Frobenius–Schur / RSK correspondence.
