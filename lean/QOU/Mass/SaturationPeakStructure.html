    noncomputable def QOU.Mass.SaturationPeakStructure.perNucleon (aV aS aC u : ℝ) :
    ℝ

    Per-nucleon binding in the volume−surface−Coulomb shape, in the variable u = A^(1/3) > 0: f(u) = a_V − a_S/u − a_C·u².

      theorem QOU.Mass.SaturationPeakStructure.perNucleon_lt_volume (aV aS aC u : ℝ) (haS : 0 < aS) (haC : 0 ≤ aC) (hu : 0 < u) :
      perNucleon aV aS aC u < aV

      The curve never attains the bulk coefficient. For a positive surface cost and a non-negative Coulomb cost, f(u) < a_V at every u > 0 — so the observed maximum of the per-nucleon binding lies STRICTLY BELOW a_V. This is the structural reason the empirical B/A peak is not the bulk coefficient, and hence why matching a constant to that peak says nothing about the bulk.

      Falling branch. Once the Coulomb cost dominates the surface cost (a_C(u₁+u₂)u₁u₂ > a_S), the per-nucleon binding DECREASES with mass number. Together with perNucleon_increasing this gives an interior maximum: the curve peaks and then declines, exactly as the AME data do beyond A≈60.

      theorem QOU.Mass.SaturationPeakStructure.peak_is_not_bulk (aV aS aC uPeak : ℝ) (haS : 0 < aS) (haC : 0 ≤ aC) (hu : 0 < uPeak) :
      perNucleon aV aS aC uPeak < aV ∧ aV - perNucleon aV aS aC uPeak = aS / uPeak + aC * uPeak ^ 2

      The peak is not a bulk quantity — the interpretive punchline. Whatever mass number maximises the per-nucleon binding, its value is strictly below a_V, and the shortfall is precisely the surface-plus-Coulomb cost at that point. Therefore a constant matching the observed peak matches an interior maximum of a surface/Coulomb competition, not the bulk coefficient — the two differ by a parameter-dependent amount with no fundamental significance.
