    The Milnor indeterminacy Δ(ijs) #

    source
    def QOU.Mass.MilnorIndeterminacyGate.indeterminacy (l12 l13 l23 : ℤ) :
    ℕ

    The Milnor indeterminacy Δ(ijs) of a 3-component sub-link with pairwise linking numbers l12, l13, l23: the gcd of the three pairwise linking numbers. Milnor 1954: μ̄(ijs) is a well-defined residue only modulo this gcd (the lower-order invariants of the proper sub-links of a 3-component link are exactly the pairwise linking numbers). Computed on ℤ.natAbs since the gcd of integers is a natural number and ZMod is indexed by ℕ; this agrees with Int.gcd.

      The physical gate: cluster triples #

      source
      structure QOU.Mass.MilnorIndeterminacyGate.ClusterTriple :
      Type

      A 3-component sub-link of a cluster arrangement, carried abstractly by its pairwise linking data l12 = lk(i,j), l13 = lk(i,s), l23 = lk(j,s). Modeling input (Milnor 1954, carried here as the type of the residue, not as an axiom): the triple invariant μ̄(ijs) of the sub-link is a well-defined element of ZMod (indeterminacy l12 l13 l23) only — any integer representative is meaningful only through its residue class modulo the gcd of the pairwise linkings.

      • l12 : ℤ

        Pairwise linking number of components i, j.

      • l13 : ℤ

        Pairwise linking number of components i, s.

      • l23 : ℤ

        Pairwise linking number of components j, s.

              def QOU.Mass.MilnorIndeterminacyGate.ClusterTriple.Brunnian (t : ClusterTriple) :
              Prop

              All pairwise linkings vanish: the Brunnian/Borromean pattern (a pure-α triple).

              This is TIER 2 — strictly weaker than true Brunnian-ness (every proper sub-link is the unlink), which it does not imply: the Whitehead link has linking number 0 and is not the unlink. Tier table for the four things this corpus calls Brunnian, and which implications hold: QOU.Mass.BrunnianTierDisambiguation.
