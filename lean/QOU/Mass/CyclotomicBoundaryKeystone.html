    QOU.Mass.CyclotomicBoundaryKeystone — the Habiro-tail cyclotomic boundary at n = 5 #

    Formalizes the finite forward direction of conj:cyclotomic-boundary-at-keystone (cyclotomic-boundary-at-keystone.md) and the n = 6 non-cyclotomicity certificate, as far as is honestly provable.

    The binding q-deformation of the na-Stokes period S(n) = Σ_{λ⊢n} dim_q(λ) (the q-involution / telephone numbers, S(n)|_{q=1} = I(n), OEIS A000085) obeys S(n) = S(n-1) + [n-1]_q S(n-2) + D(n). The Habiro tail D(n), cleared of its q-monomial to an ordinary integer polynomial, is (compute: computations/lever1_cyclotomic_boundary_keystone_conjecture.py):

    • D(4) = Φ₁² · Φ₃ — cyclotomic
    • D(5) = 2 · Φ₁² · Φ₂² · Φ₃ · Φ₆ — cyclotomic
    • D(6) = Φ₁² · Φ₅ · C₆, C₆ deg-8 — non-cyclotomic

    What is proved here (sorry-free) #

    • D4_eq, D5_eq — the base-case factorizations into explicit palindromic factors.
    • Phi1_cyclotomic, Phi2_cyclotomic, Phi3_cyclotomic, Phi5_cyclotomic, Phi6_cyclotomic — those factors ARE the Mathlib cyclotomic polynomials, so D4_cyclotomic, D5_cyclotomic exhibit D(4), D(5) as genuine products of cyclotomics (Tier 1 of the conjecture, fully closed).
    • C6_reciprocal — the palindrome identity C₆(z) = z⁴·C̃(z + z⁻¹), C̃(y) = y⁴+4y³+2y²−10y−8, for every z ≠ 0.
    • C6ℂ_eq — C6ℂ is C6core evaluated over ℂ.
    • unit_circle_sum_real — if ‖z‖ = 1 then z + z⁻¹ is real.
    • Ctil_disc — the discriminant datum Δ(C̃) = −44208 < 0.
    • Ctil_no_four_real_roots, Ctil_has_nonreal_root — C̃ has a non-real root, proved from scratch via the explicit 16-term discriminant identity (see the section below); no sorry, no axiom.
    • C6core_offcircle_root — C₆ has a root off the unit circle (derived, via the reciprocal transform, from Ctil_has_nonreal_root alone).
    • C6core_non_cyclotomic — C₆ is not a product of cyclotomic polynomials (derived from C6core_offcircle_root). Crucially this uses only the easy direction of Kronecker's dichotomy — every root of a product of cyclotomics is a root of unity, hence norm 1 (cyclotomic.dvd_X_pow_sub_one + Complex.norm_eq_one_of_pow_eq_one, both in Mathlib) — and does not need the hard Kronecker converse.

    The former residual gap — now closed (fully sorry-free) #

    Ctil_has_nonreal_root (C̃ has a non-real root) was previously the file's single sorry. It is now proved with no sorry and no axiom. Mathlib has no quartic-discriminant = ∏_{i<j}(rᵢ−rⱼ)² bridge, so the fact is derived from scratch:

    • Ctil_no_four_real_roots — for reals a,b,c,d with the Vieta data of C̃ (Σ = −4, Σ₂ = 2, Σ₃ = 10, Π = −8), the Vandermonde square ∏_{i<j}(rᵢ−rⱼ)² equals the explicit 16-term discriminant polynomial in the elementary symmetric functions (a pure ring identity), which at those Vieta values is Δ(C̃) = −44208 < 0; a Vandermonde square of reals is ≥ 0, so no four reals are the roots of C̃.
    • Ctil_has_nonreal_root — C̃ is monic of degree 4, hence over ℂ it splits into four roots a,b,c,d (IsAlgClosed.splits_codomain, eq_prod_roots_of_monic_of_splits_id, Multiset.card_eq_four). Were all four real, Vieta feeds Ctil_no_four_real_roots to a contradiction; so some root has nonzero imaginary part.

    Consequently the entire Tier-2, n = 6 non-cyclotomicity chain is sorry-free. The full Tier-2 claim — D(n) non-cyclotomic for all n ≥ 6 — is verified through n = 11 and remains not proved (out of scope here).

                          theorem QOU.Mass.CyclotomicBoundaryKeystone.Ctil_no_four_real_roots (a b c d : ℝ) (h1 : a + b + c + d = -4) (h2 : a * b + a * c + a * d + b * c + b * d + c * d = 2) (h3 : a * b * c + a * b * d + a * c * d + b * c * d = 10) (h4 : a * b * c * d = -8) :
                          False

                          Quartic discriminant identity ∏_{i<j}(rᵢ−rⱼ)² = Δ(C̃) written in the elementary symmetric functions of a,b,c,d (16 terms; a pure ring identity), evaluated at the Vieta values of C̃: if four reals are the roots of C̃ (Σ = −4, Σ₂ = 2, Σ₃ = 10, Π = −8) then their Vandermonde square equals Δ(C̃) = −44208 < 0 (Ctil_disc) — impossible, since a Vandermonde square of reals is ≥ 0. Hence C̃ has no four real roots.

                          source
                          theorem QOU.Mass.CyclotomicBoundaryKeystone.Ctil_has_nonreal_root :
                          ∃ (y : ℂ), Ctilℂ y = 0 ∧ y.im ≠ 0

                          C̃ has a non-real root (sorry-free). C̃ = X⁴+4X³+2X²−10X−8 is monic of degree 4, so over ℂ it splits into four roots a,b,c,d (IsAlgClosed.splits_codomain + eq_prod_roots_of_monic_of_splits_id). If all four were real, Vieta gives Σ = −4, Σ₂ = 2, Σ₃ = 10, Π = −8, whence Ctil_no_four_real_roots derives False from Δ(C̃) = −44208 < 0. So some root has nonzero imaginary part. This is the classical fact Δ < 0 ⇒ non-real root, here proved from scratch (Mathlib has no quartic discriminant bridge) via the explicit 16-term symmetric identity.

                          source
                          theorem QOU.Mass.CyclotomicBoundaryKeystone.C6core_offcircle_root :
                          ∃ (z : ℂ), C6ℂ z = 0 ∧ ‖z‖ ≠ 1

                          Reduction (sorry-free) — there is a root of C₆ off the unit circle, reduced to Ctil_has_nonreal_root alone. A non-real root y of C̃ lifts, via z = (y + w)/2 with w² = y² − 4, to a nonzero z with z + z⁻¹ = y and C6ℂ z = z⁴·C̃(y) = 0 (C6_reciprocal); and ‖z‖ ≠ 1, else unit_circle_sum_real forces y = z + z⁻¹ real, contradicting y.im ≠ 0.

                          theorem QOU.Mass.CyclotomicBoundaryKeystone.C6core_non_cyclotomic :
                          ¬∃ (s : Multiset ℕ), C6core = (Multiset.map (fun (k : ℕ) => Polynomial.cyclotomic k ℤ) s).prod

                          Conclusion (sorry-free modulo Ctil_has_nonreal_root) — C₆ is not a product of cyclotomic polynomials. This needs only the easy direction of Kronecker's dichotomy: every root of a product of cyclotomics is a root of unity (cyclotomic k ∣ Xᵏ − 1), hence has norm 1 — contradicting the off-circle root from C6core_offcircle_root. (The hard Kronecker converse, absent from Mathlib, is not used.)
