    def QOU.Mass.CoordinationWeightDifferences.bind {R : Type u_1} [CommRing R] (w : ℕ → R) (A : ℕ) :
    R

    The coordination weight assembly: a nucleus of mass number A carries C(A,2) pairs, each contributing the mean weight w (A-1) of a nucleon at coordination z = A-1. Every binding map is of this form for exactly one w; this is a change of variables, not a hypothesis.

            theorem QOU.Mass.CoordinationWeightDifferences.b3_nonpos_of_le {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {w : ℕ → R} (h : w 2 ≤ w 1) :
            b3 w ≤ 0

            A non-increasing coordination weight forces b₃ ≤ 0.

            This is the wall, and it subsumes the Mayer result rather than sitting beside it: any assembly whose mean binding per pair does not rise with coordination gives a non-positive connected three-body cumulant. A saturating assembly is non-increasing, so it lands here — the multiplicative form's b₃ < 0 is an instance, not a coincidence.

            theorem QOU.Mass.CoordinationWeightDifferences.lt_of_b3_pos {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {w : ℕ → R} (h : 0 < b3 w) :
            w 1 < w 2

            The falsifiable form, and the one measurement instantiates.

            AME2020 gives b₃ = +1.426222 MeV > 0 (Ursell inversion of the deuteron and the isospin-averaged A = 3 binding). So the physical coordination weight rises from coordination 1 to coordination 2: w 1 < w 2. That single inequality is the entire content of "nature's b₃ is positive", and it is what a derivation of the magnitude has to produce.
