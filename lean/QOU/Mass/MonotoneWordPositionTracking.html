      def QOU.Mass.MonotoneWordPositionTracking.posAfter (e : ℕ → ℕ) :
      ℕ → ℕ → ℕ

      The position→strand map after runs 0, …, g-1 have executed.

      e_g crossings of one adjacent pair compose to the identity when e_g is even and to a single swap when it is odd, so only the parity of the exponent survives — which is why this is a one-step recursion rather than an iteration.

        theorem QOU.Mass.MonotoneWordPositionTracking.posAfter_self (e : ℕ → ℕ) (g : ℕ) :
        posAfter e g g = MonotoneWordComponentStructure.pStart e g

        pStart is the correct recursion. Position g holds pStart e g when run R_g begins — an even run restores the pair so the next run's left strand is g+1, an odd run swaps them so the left strand is carried over unchanged.

        This is what MonotoneWordComponentStructure assumed about its own definition.
