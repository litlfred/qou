    1. The recursion behind χ_k = 2 cos(k·θ) #

    source
    theorem QOU.Mass.ThreeDividesKBreaks.two_cos_recursion (θ : ℝ) (k : ℕ) :
    2 * Real.cos ((↑k + 2) * θ) = 2 * Real.cos θ * (2 * Real.cos ((↑k + 1) * θ)) - 2 * Real.cos (↑k * θ)

    The Chebyshev recursion for 2 cos(k·θ).

    V is 2×2 with det V = 1 and tr V = −1 − x, so Cayley–Hamilton gives χ_{k+2} = (tr V)·χ_{k+1} − χ_k. The trace sequence 2 cos(k·θ) satisfies the same recursion with 2 cos θ = tr V, which is what identifies the two — and it is why one cosine can replace the ten separate polynomial identities that GammaGammaSelectionTen carries.

    2. The residue split — where the 3 ∣ k pattern comes from, and what #

    becomes of it once δ > 0

    source
    theorem QOU.Mass.ThreeDividesKBreaks.cos_of_three_mul (m : ℕ) (δ : ℝ) :
    Real.cos (↑(3 * m) * (2 * Real.pi / 3 + δ)) = Real.cos (↑(3 * m) * δ)

    k = 3m: the 2π/3 part is whole turns, so only the accumulated phase survives.

    This is why the multiples of 3 are the feasible ones at δ = 0 (cos 0 = 1), and equally why they STOP being feasible once k·δ passes π/2.

    source
    theorem QOU.Mass.ThreeDividesKBreaks.cos_of_three_mul_add_two (m : ℕ) (δ : ℝ) :
    Real.cos (↑(3 * m + 2) * (2 * Real.pi / 3 + δ)) = Real.cos (4 * Real.pi / 3 + ↑(3 * m + 2) * δ)

    k = 3m+2: a fixed 4π/3 offset plus the accumulated phase.

    At δ = 0 this is cos (4π/3) = −1/2 < 0, which is the infeasibility of the non-multiples. The offset is fixed; the phase is not — and §3 is what happens when the phase catches up.

    theorem QOU.Mass.ThreeDividesKBreaks.cos_of_three_mul_add_one (m : ℕ) (δ : ℝ) :
    Real.cos (↑(3 * m + 1) * (2 * Real.pi / 3 + δ)) = Real.cos (2 * Real.pi / 3 + ↑(3 * m + 1) * δ)

    k = 3m+1: offset 2π/3. Included so the three classes are visibly a partition and a reader is not left wondering whether this one behaves differently. It does not — it has the largest threshold, 5π/6, which is why the probe finds its first feasible member at k = 103 rather than 23.

    3. The refutation #

    source
    theorem QOU.Mass.ThreeDividesKBreaks.cos_four_pi_thirds_add_nonneg {φ : ℝ} (h1 : Real.pi / 6 ≤ φ) (h2 : φ ≤ 5 * Real.pi / 6) :
    0 ≤ Real.cos (4 * Real.pi / 3 + φ)

    The feasibility window for the 2 mod 3 class.

    cos (4π/3 + φ) ≥ 0 exactly when the total angle has come round to the fourth quadrant, i.e. φ ∈ [π/6, 5π/6]: at φ = π/6 the angle is 3π/2 and the cosine is 0, at φ = 5π/6 it is 2π + π/6. So a 2 mod 3 candidate becomes FEASIBLE once its accumulated phase reaches π/6 — it does not need to reach a half turn. That small threshold is why the pattern breaks in this class first.

    source
    theorem QOU.Mass.ThreeDividesKBreaks.pattern_fails_at_residue_two (m : ℕ) (δ : ℝ) (h1 : Real.pi / 6 ≤ ↑(3 * m + 2) * δ) (h2 : ↑(3 * m + 2) * δ ≤ 5 * Real.pi / 6) :
    ¬3 ∣ 3 * m + 2 ∧ 0 ≤ 2 * Real.cos (↑(3 * m + 2) * (2 * Real.pi / 3 + δ))

    The pattern fails: a k ≡ 2 (mod 3) whose phase has reached the window is feasible.

    3 ∤ k and χ_k ≥ 0 together contradict χ_k ≥ 0 ↔ 3 ∣ k. So this exhibits the failure from the hypothesis that such a k exists; the companion probe supplies k = 23 at the proton pin, where δ = 0.0254231… puts k·δ = 0.5847 inside [π/6, 5π/6] = [0.5236, 2.6180].

    Note what the hypothesis costs: only that the accumulated phase has entered a window of width 2π/3. Since consecutive members of this residue class step the phase by 3δ, any δ ≤ 2π/9 cannot step over the window — so such a k exists for every small positive δ. That existence argument is NOT formalised here (see the file header); this theorem is the implication it feeds.

    theorem QOU.Mass.ThreeDividesKBreaks.not_forall_feasible_iff_three_dvd (m : ℕ) (δ : ℝ) (h1 : Real.pi / 6 ≤ ↑(3 * m + 2) * δ) (h2 : ↑(3 * m + 2) * δ ≤ 5 * Real.pi / 6) :

    So no θ with δ > 0 can satisfy χ_k ≥ 0 ↔ 3 ∣ k for all k, once one such k is in the window. Stated as the refutation of the universal claim, which is the form the open item was posed in.
