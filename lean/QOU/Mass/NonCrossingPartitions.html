    Decidable encoding of (non-crossing) partitions #

    source
    def QOU.Mass.IsCanon {n : ℕ} (f : Fin n → Fin n) :
    Prop

    f : Fin n → Fin n is a canonical partition labelling: f i is the minimum of the block containing i. Characterised by f i ≤ i (representative is the block minimum) and f (f i) = f i (representatives are fixed points). These two conditions cut the finite function type Fin n → Fin n down to the partition lattice of Fin n.

    Equations
    • QOU.Mass.IsCanon f = ((∀ (i : Fin n), f i ≤ i) ∧ ∀ (i : Fin n), f (f i) = f i)

      def QOU.Mass.NonCross {n : ℕ} (f : Fin n → Fin n) :
      Prop

      f is non-crossing: no i < j < k < l has f i = f k, f j = f l, f i ≠ f j (two blocks interleaving as …i…j…k…l…).

      Equations
      • QOU.Mass.NonCross f = ∀ (i j k l : Fin n), i < j → j < k → k < l → f i = f k → f j = f l → f i = f j

          The counts |NC(n)| = C_n, by decide #

          Each Fintype.card (NCPart n) enumerates the ≤ n^n functions Fin n → Fin n, keeps the canonical non-crossing ones, and counts them. The results are the Catalan numbers 1, 1, 2, 5, 14.

          source

          Fintype.card (NCPart 0) = 1

          |NC(0)| = 1 = C₀ (the empty partition).

          theorem QOU.Mass.card_ncpart_four :
          Fintype.card (NCPart 4) = 14

          |NC(4)| = 14 = C₄. The 15th partition of {0,1,2,3} — the crossing {{0,2},{1,3}} — is the one NonCross rejects (see below).

          The excluded crossing partition #

          {{0,2},{1,3}} — canonical label f = (0,1,0,1) — is a genuine partition labelling (IsCanon) that crosses (¬ NonCross), so it is the one partition dropped from B₄ = 15 to reach C₄ = 14. This is the set-theoretic content behind FreeCumulants.classical_sub_free_moment4 (classical − free = κ₂², the crossing pair-partition's contribution).

            Catalan bridge #

            C_n = Nat.centralBinom n / (n + 1) (= Nat.catalan n, unredefined), matching the primitive used in FreeCumulants.lean.

            source
            theorem QOU.Mass.catalan_via_centralBinom :
            Nat.centralBinom 0 / 1 = 1 ∧ Nat.centralBinom 1 / 2 = 1 ∧ Nat.centralBinom 2 / 3 = 2 ∧ Nat.centralBinom 3 / 4 = 5 ∧ Nat.centralBinom 4 / 5 = 14

            The Catalan values C₀..C₄ = 1,1,2,5,14, via Mathlib's Nat.centralBinom (C_n = centralBinom n / (n+1)).

            source
            theorem QOU.Mass.card_ncpart_eq_catalan :
            Fintype.card (NCPart 0) = Nat.centralBinom 0 / 1 ∧ Fintype.card (NCPart 1) = Nat.centralBinom 1 / 2 ∧ Fintype.card (NCPart 2) = Nat.centralBinom 2 / 3 ∧ Fintype.card (NCPart 3) = Nat.centralBinom 3 / 4 ∧ Fintype.card (NCPart 4) = Nat.centralBinom 4 / 5

            The count is the Catalan number. |NC(n)| = Fintype.card (NCPart n) = Nat.centralBinom n / (n+1) = C_n for n = 0,1,2,3,4. This is the bijective upgrade of FreeCumulants.freeMoment_eval_one_eq_catalanCount: there the all-ones moment evaluated to C_n; here the non-crossing partitions are counted and the count is C_n.
