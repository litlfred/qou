    def QOU.Mass.BrunnianTripleExhaustion.bRatioOfTriple (m₁ m₂ m₃ : ℚ) :
    ℚ

    b₃/b₂ for a Brunnian A = 3 carrier with per-pair crossing counts n₊ = n₋ = mᵢ, against the owner-ruled Hopf pair carrier c₂ = 2. The total crossing count is c₃ = 2(m₁+m₂+m₃), so this is c₃/2 − 3.

          2. The exhaustion #

          theorem QOU.Mass.BrunnianTripleExhaustion.no_carrier_reproduces_b3 (M : ℤ) :
          ↑M - 3 ≠ CarrierCrossingQuantisation.rMeasured

          No carrier reproduces the measured b₃ — and the Brunnian hypothesis is not even needed. b₃/b₂ = M − 3 is an integer for any integer M, while rMeasured lies strictly between 0 and 1, so no integer works at all. Stated without 3 ≤ M because the proof does not use it; brunnian_sum_ge_three is what makes the gap bound below sharp, not what makes this true.
