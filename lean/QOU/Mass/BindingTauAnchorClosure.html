    QOU.Mass.BindingTauAnchorClosure — wired anchors force τ > 2 ⇒ binding kernel extensive #

    Companion to QOU.Mass.Lever1Tau.tau_kernel_closed_form, which proves the wired-anchor seed τ = (a_D^(2) + a_D^(4)) / a_D^(3) equals the closed form 3(3q⁴ + 8q² + 3)/(4q(q+1)²) (the three production-wired prolonged Seiberg–Witten period anchors a_D^(2)=1, a_D^(3)=(q+1)²/(3q), a_D^(4)=(3q²+4+3q⁻²)/4). This file does not re-prove that identity — it cites it — and adds the two facts that file does not:

    • tauAnchor_gt_two — 0 < q ⇒ 2 < τ throughout the substrate regime, via the sum-of-squares positivity 504·(τ·den − 2·den) = 56(9q²−4q)² + (56q−36)² + 3240 > 0;
    • binding_extensive_at_substrate — composing with QOU.Mass.lambdaPlus_gt_one (the abstract τ>2 ⇒ λ₊>1 spectral bridge), the depth-2 binding kernel R = x²−τx+1 is extensive (λ₊ > 1) given the anchors — the property the saturating |χ| joint trace (τ=2, λ=1) lacks.

    Plus the bar-antisymmetric odd partner a_D^(5) = τ·a_D^(4) − a_D^(3) and its closed form.

    Scope (honest) #

    Algebraic half only: the wired anchor values force this τ, τ > 2, hence extensivity. It does not derive the geometric residual a_D^(n) = ∮ λ_SW^(n) = lw(n−1) (this τ = abelianised λ_SW Gauss–Manin holonomy on color E_q) — the owner-gated keystone (conj:qdifference-kernel-prolongation-symbol). The Step-1 geometry probe computations/substrate/lever1_color_sigma_geometry_probe.py shows the bare differential carries zero residue at the finite branch points, so that identification needs the prolongation operator λ_SW^(n) → a_D^(n), left "by induction" (the construction gap).
