    Color spectral cubic — color-root power sums are q-free #

    The lever-1 binding Seiberg–Witten differential is λ_SW = X dz, with the color coordinate X cut out by the color spectral cubic

    X³ + (z+1)X² + (z²+z+1)X + (z³+z²+z+1) = 0

    (color-tube-fibers.lean, mi-sw-abelianisation-cartan.md). This cubic — and hence every classical jet/period built from it — is q-free: no quantum-deformation parameter appears. This file records the color-root power sums p_n = Σ Xᵢⁿ for n = 1,2,3, computed by Newton's identities from the cubic's elementary symmetric functions, all equal to the clean q-free polynomials −(zⁿ+1).

    Why this matters (z2bn second probe). Because the spectral data is q-free, a classical (d/dz) jet prolongation of λ_SW yields q-independent periods ∮λ_SW^(n), which cannot equal the q-dependent binding anchors a_D^(3) = (q+1)²/(3q) etc. That q-type-consistency mismatch (b)-excludes the classical-jet identification and forces the binding-kernel prolongation to be a q-difference operator (the bean's "fibre q-difference kernel R(q,x)"). See computations/substrate/z2bn_prolongation_qdifference_constraint.py and the audit docs/audits/2026-06-25-z2bn-prolongation-qdifference-constraint.md. Generic base ring R — the absence of any quantum parameter in the statement is the point.
