    theorem QOU.Mass.QDifferenceGaugeMatrix.scalar_gauge_eq {K : Type u_1} [Field K] {n : Type u_2} [Fintype n] [DecidableEq n] (s t : K) (hs : s ≠ 0) (A B : Matrix n n K) (h : s • 1 * B = A * t • 1) :
    B = (t / s) • A

    The q-difference gauge law for a scalar gauge — DVRSZ eq. (2.4.1), B = (σ_q F)⁻¹ A F, with F = c·1 and cleared of the inverse.

    Read s = σ_q(c) and t = c: the hypothesis is (σ_q F) · B = A · F, and the conclusion is B = (c / σ_q c) · A. Taking c = z^k and σ_q : z ↦ q·z gives c / σ_q c = q^{-k}, so a monomial gauge multiplies the system matrix by a power of q — which is the step #7208 needs and cites rather than proves.

    The action is not conjugation: the two sides carry different scalars, σ_q c on the left and c on the right, and they fail to cancel exactly when σ_q c ≠ c.

    theorem QOU.Mass.QDifferenceGaugeMatrix.det_charMatrix_smul {K : Type u_1} [Field K] {n : Type u_2} [Fintype n] [DecidableEq n] (t X : K) (ht : t ≠ 0) (A : Matrix n n K) :
    (X • 1 - t • A).det = t ^ Fintype.card n * ((X / t) • 1 - A).det

    Scaling the system matrix moves the characteristic polynomial by a substitution.

    det(X·1 − t·A) = t^n · det((X/t)·1 − A) for t ≠ 0, where n is the size. So the spectral locus of t·A is that of A pulled back along X ↦ X/t — it moves, unless the locus happens to be invariant under that substitution.

    Combined with scalar_gauge_eq, this is the dictionary #7208 assumed: a gauge transformation of the q-difference system and a change of the X coordinate over the base are the same move. QGaugeSpectralRigidity.weight_relations then measures what surviving it would cost a monic cubic — every non-leading coefficient.

    theorem QOU.Mass.QDifferenceGaugeMatrix.det_charMatrix_conj {K : Type u_1} [Field K] {n : Type u_2} [Fintype n] [DecidableEq n] (X : K) (A F : Matrix n n K) (hF : IsUnit F.det) :
    (X • 1 - F * A * F⁻¹).det = (X • 1 - A).det

    The contrast: conjugation leaves the characteristic polynomial alone.

    det(X·1 − F A F⁻¹) = det(X·1 − A) for invertible F. This is why the Seiberg–Witten spectral curve of a Higgs field is well defined — gauge acts there by conjugation — and its failure for the twisted q-difference action (σ_q F)⁻¹ A F is precisely the finding of #7208. The probe checks this numerically over ℚ (T3); this is the statement it is a sample of.
