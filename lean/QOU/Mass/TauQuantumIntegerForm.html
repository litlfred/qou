    Lever-1 kernel trace τ — quantum-integer (bar-even) form + SL₂ transfer structure #

    The lever-1 binding kernel trace has the proved closed form (Lever1Tau.tau_kernel_closed_form, PRs #2767/#2755)

    τ(q) = 3(3q⁴ + 8q² + 3) / (4q(q+1)²).

    This file records three structural facts about the prolongation operator M (a_D^(n+2) = τ a_D^(n+1) − a_D^(n)) — the z2bn third probe (PF-monodromy synthesis).

    Base-ring discipline (§7c) — M is NOT inherently over ℝ. Each statement is given over the weakest ring that admits it, matching the substrate→archimedean wall:

    1. transfer_det_one — over any CommRing R: the depth-2 transfer matrix !![τ,-1;1,0] has det = 1, so M ∈ SL₂(R). Trace-agnostic, no ordering, no division — M ∈ SL₂ is ring-universal.
    2. tau_quantum_integer_form / tau_bar_even — over any field K with q,(q+1),2 invertible (e.g. K = ℚ(q), the Hecke fraction field): τ is a rational function of the quantum integer [2]_q = q+q⁻¹ alone, τ = 3(3[2]²+2)/(4([2]+2)), hence bar-even τ(q⁻¹)=τ(q). Here q is a formal variable and q ↦ q⁻¹ is the bar-involution of the Hecke base ring ℤ[q,q⁻¹] — this is the fibre / categorical level, no ℝ needed. A classical-jet trace has no reason to collapse onto [2]_q, so the [2]_q-form is the Hecke / q-difference fingerprint.
    3. Hyperbolicity is the only archimedean piece. With τ > 2 (Lever1Tau.tauAnchor_gt_two, an order statement living over ℝ) the archimedean evaluation M(q₀) ∈ SL₂(ℝ) is hyperbolic (λ₊ > 1 — the seed kernel's extensivity; the physical lw grows super-geometrically past λ₊, #2752). So M ∈ SL₂(ℤ[q,q⁻¹]) at the fibre level (bar-even, q formal); SL₂(ℝ) is only the evaluation at the substrate q₀ where the ordering τ>2 lives. The topological Picard–Fuchs monodromy is SL₂(ℤ) (integer trace, parabolic trace = 2 at the I₁ nodal fibres of the squarefree-Δ color curve); since τ ∉ ℤ (even τ(1)=21/8), M is not that arithmetic monodromy.

    See computations/substrate/z2bn_pf_monodromy_synthesis.py and the audit docs/audits/2026-06-25-z2bn-pf-monodromy-synthesis.md.

    theorem QOU.Mass.TauQuantumInteger.tau_quantum_integer_form {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hq1 : q + 1 ≠ 0) (h2 : 2 ≠ 0) :
    3 * (3 * q ^ 4 + 8 * q ^ 2 + 3) / (4 * q * (q + 1) ^ 2) = 3 * (3 * (q + q⁻¹) ^ 2 + 2) / (4 * (q + q⁻¹ + 2))

    τ is a rational function of the quantum integer [2]_q = q + q⁻¹ alone: τ(q) = 3(3[2]² + 2)/(4([2]+2)). Stated over any field K with q, q+1, 2 invertible (e.g. K = ℚ(q), the Hecke fraction field) — not ℝ. The proved closed form 3(3q⁴+8q²+3)/(4q(q+1)²) collapses onto [2]_q, the Hecke / q-difference fingerprint.

    theorem QOU.Mass.TauQuantumInteger.tau_bar_even {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hq1 : q + 1 ≠ 0) (h2 : 2 ≠ 0) :
    3 * (3 * q⁻¹ ^ 4 + 8 * q⁻¹ ^ 2 + 3) / (4 * q⁻¹ * (q⁻¹ + 1) ^ 2) = 3 * (3 * q ^ 4 + 8 * q ^ 2 + 3) / (4 * q * (q + 1) ^ 2)

    τ is bar-even: τ(q⁻¹) = τ(q) (invariant under the Hecke bar-involution q ↦ q⁻¹), over any field K with q, q+1, 2 invertible. Immediate consequence of the [2]_q form.
