    QOU.Mass.AdditiveCorrectionConfinement — new energy terms are confined to the binding sector #

    The formalize-first invariant behind the zero-point channel-energy exploration (2026-07-04 audit docs/audits/2026-07-04-zero-point-channel-energy-and-information.md): the canonical absolute nucleon masses (muon-anchored facade, canonical_mass.py) already reproduce observation. Therefore any proposed additional energy term — a q-Casimir zero-point shift, a channel-information term, any D_ν-interpolation energy — is quantitatively confined: at the free-particle level its magnitude is bounded by twice the existing match tolerance (additive_correction_confined), and if the match is taken as exact the term vanishes there outright (additive_correction_zero_of_exact). New energy can only live where predictions do not already saturate observation — the binding / convolution-defect sector.

    Both statements are elementary order-field algebra, stated over a generic linearly ordered field ([Field K] [LinearOrder K] [IsStrictOrderedRing K]; §7c: the ordering is the entire content; no ℝ-specific construct is used).

    source
    theorem QOU.Mass.AdditiveCorrectionConfinement.additive_correction_confined {K : Type u_1} [Field K] [LinearOrder K] [IsStrictOrderedRing K] (m_pred m_obs δ ε : K) (h1 : |m_pred - m_obs| ≤ ε) (h2 : |m_pred + δ - m_obs| ≤ ε) :
    |δ| ≤ 2 * ε

    Confinement bound. If a predicted mass already matches observation within ε, then any modified prediction m_pred + δ that also matches within ε has |δ| ≤ 2ε: a proposed new energy term cannot exceed twice the existing agreement tolerance at the level where that agreement holds.

    source
    theorem QOU.Mass.AdditiveCorrectionConfinement.additive_correction_zero_of_exact {K : Type u_1} [Field K] [LinearOrder K] [IsStrictOrderedRing K] (m_pred m_obs δ : K) (h1 : m_pred = m_obs) (h2 : m_pred + δ = m_obs) :
    δ = 0

    Exact-match corollary. If the prediction matches observation exactly both with and without the additional term, the term is zero — an exact absolute-mass match leaves no room for a new free-particle energy contribution.
