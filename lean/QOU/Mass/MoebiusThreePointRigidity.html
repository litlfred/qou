    A = 0 ∧ B = 0 ∧ C = 0

    A quadratic with three distinct roots is the zero quadratic.

    A·x² + B·x + C vanishing at three pairwise-distinct points forces A = B = C = 0.

    Proof: subtracting the equations at x and y and cancelling x − y gives A·(x+y) + B = 0; the same at x and z gives A·(x+z) + B = 0; subtracting those and cancelling y − z gives A = 0, and the rest follows.

    c = 0 ∧ d = a ∧ b = 0

    Three-point rigidity. If the Möbius data (a, b; c, d) fixes three distinct points — in the cleared sense a·w + b = w·(c·w + d), which needs no chart and no cw + d ≠ 0 — then c = 0, d = a and b = 0: the data of the identity map.

    This is the content #7185 deferred as "Möbius machinery"; the fixed-point condition is a quadratic c·w² + (d−a)·w − b = 0, so quadratic_zero_of_three_roots does all of it.

    theorem QOU.Mass.MoebiusThreePointRigidity.moebius_proportional_of_three_agree {K : Type u_1} [Field K] (a b c d a' b' c' d' x y z : K) (hxy : x ≠ y) (hxz : x ≠ z) (hyz : y ≠ z) (hx : (a * x + b) * (c' * x + d') = (a' * x + b') * (c * x + d)) (hy : (a * y + b) * (c' * y + d') = (a' * y + b') * (c * y + d)) (hz : (a * z + b) * (c' * z + d') = (a' * z + b') * (c * z + d)) :
    a * c' = a' * c ∧ a * d' + b * c' = a' * d + b' * c ∧ b * d' = b' * d

    The injectivity Stab(B) ↪ Sym(B), in cleared coordinates.

    If two Möbius data agree at three distinct points — cleared, (a·x + b)·(c'·x + d') = (a'·x + b')·(c·x + d) — then every 2×2 minor of the stacked data vanishes:

    a·c' = a'·c, a·d' + b·c' = a'·d + b'·c, b·d' = b'·d

    i.e. the two data are proportional and induce the same map. This is the statement the Stab(B) ↪ Sym(B) = S₆ embedding rests on: a base automorphism preserving the six-point branch locus is pinned by where it sends three of those points, so the stabiliser is finite of order at most 6·5·4.

    Same lemma again — the difference of the two cleared forms is a quadratic in the evaluation point.
