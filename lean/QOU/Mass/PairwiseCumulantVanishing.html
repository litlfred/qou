    structure QOU.Mass.PairwiseCumulantVanishing.BindingMap (R : Type u_2) [CommRing R] :
    Type u_2

    A binding map on a four-body system, recorded by its values on every sub-cluster independently. Nothing here assumes the values are related; IsPairwise below is what asserts a relation, and it is a hypothesis.

    • pair : Fin 4 → Fin 4 → R

      the binding of the pair {i, j}

    • triple : Fin 4 → Fin 4 → Fin 4 → R

      the binding of the triple {i, j, k} — an independent datum

    • quad : R

      the binding of the whole four-body cluster — an independent datum

      def QOU.Mass.PairwiseCumulantVanishing.BindingMap.b3 {R : Type u_1} [CommRing R] (M : BindingMap R) (i j k : Fin 4) :
      R

      The connected three-body cumulant of a triple: its binding, less the three pair bindings inside it. This is the Ursell/Möbius definition, and it is the quantity the AME inversion measures as b₃ = +1.426222 MeV.

      That figure is the ISOSPIN AVERAGE of the two A = 3 nuclei — say so when you quote it (provenance recorded 2026-08-30). With the uniform pair value e₂ = B(²H) = 2.224566:

      • b₃(³H) = 8.481798 − 3e₂ = 1.808100
      • b₃(³He) = 7.718058 − 3e₂ = 1.044360
      • mean = 1.426230, matching the quoted 1.426222 to 8·10⁻⁶ MeV — the residual is AME input precision (it implies B(²H) = 2.2245687 against 2.2245660, a 2.7 eV difference). Each single-nucleus alternative is 26.8 % away, so the identification is not a coincidence.

      Why the average is the right object here: this file's binding model carries one uniform pair value, with no pp/pn/nn distinction — the regime ChainBondOrderDependence.orderIndependent_iff identifies as the physical one. The entire ³H–³He splitting (0.763740 MeV, dominantly the Coulomb repulsion of ³He's second proton) therefore has nowhere to live but b₃, and averaging is what keeps it from being charged to one nucleus.

      Do not compare it directly against a triton-pinned e₃. The body-order tower pins e₃ = (B(³H) − 3e₂)/M₃(³H) = 1.808100 on the triton alone, because that is the nucleus whose single triple is genuinely Borromean (lk = 0, μ̄₁₂₃ = +1). The two numbers differ by 27 % for that reason and not because either is wrong; they are different conventions for the same order.

      No theorem here depends on which convention is used: not_isPairwise_of_b3_ne_zero needs only b₃ ≠ 0, and 1.426222 and 1.808100 are both nonzero.

      Prior art — this re-derives a result the corpus already held. Bean qou-9v7t (2026-08-29, PR #5990, computations/b3-charge-decomposition-a3.witness.json) had already split the A = 3 doublet into its charge-symmetric and charge-antisymmetric parts and named them: b3_sym = 1.4262225 — "the strong channel's obligation", the figure above — against b3_asym = 0.3818775, half the mirror splitting, "the EM channel's". The identification here is that result reached again from the other end; it is recorded because the docstring carried the number without it, not because the number was unknown.

      One question that bean leaves open, and this docstring should not paper over. The symmetric/antisymmetric split is exact bookkeeping, but it is not the same as a Coulomb correction: ³H has a single proton and so no pp pair at all, while ³He has one. So the Coulomb energy is not charge-antisymmetric about the mean — removing it moves the mean, not only the difference, and it moves it toward the triton value. Whether the strong-channel obligation is 1.426 or nearer 1.81 is therefore a live 27 % question on the very quantity the magnitude gate is short by 6–14×, and the bean's own "live successor" note says the EM channel at A = 3 is unaddressed. External precedent points the same way: Platter, Hammer and Meißner fix their SU(4)-symmetric three-nucleon parameter from B(³H) = 8.48 MeV — the triton alone (platter2005tjon, and mba-remark-tjon-universality-external). Nothing here settles it; it is flagged so the average is not read as adjudicated.

              def QOU.Mass.PairwiseCumulantVanishing.BindingMap.IsPairwise {R : Type u_1} [CommRing R] (M : BindingMap R) :
              Prop

              M is pairwise-additive: every cluster's binding is the sum of the pair bindings it contains. This is the shape §10a's assembly produces — the bond functional f is applied per bond and the results are summed.
