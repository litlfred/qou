    theorem QOU.Mass.MirrorSplitIsASmallFractionOfTheEnergy.split_fraction_bound {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] (Φp Φn r : R) (Z N : ℕ) (hn : 0 < Φn) (hle : Φn ≤ Φp) (hr : Φp ≤ r * Φn) :
    (↑Z + ↑N) * (Φp - Φn) ≤ (r - 1) * (↑Z * Φp + ↑N * Φn)

    The observable is a 1/A sliver of the bounded quantity.

    With Φn ≤ Φp ≤ r·Φn and Φn > 0, the mirror split Φp − Φn scaled by the nucleon count A = Z + N is dominated by (r − 1) times the total Z·Φp + N·Φn. Read as a fraction: ΔE / E ≤ (r − 1)/A.

    Stated multiplicatively so no division — and hence no field — is needed.

    theorem QOU.Mass.MirrorSplitIsASmallFractionOfTheEnergy.interval_narrower_than_split_iff {R : Type u_1} [CommRing R] [LinearOrder R] {B₁ U₁ B₂ U₂ split : R} :
    U₁ - B₂ - (B₁ - U₂) < split ↔ U₁ - B₁ + (U₂ - B₂) < split

    The obligation a two-sided bound would have to meet. The interval is narrower than the split it is meant to explain exactly when the combined slack is — and by split_fraction_bound the split is itself at most (r − 1)/A of the energy. So the requirement is a joint relative tightness below (r − 1)/A.

    An iff, not an implication: both directions are wanted, since the point is that narrowing the interval is equivalent to tightening the bounds, with no slack elsewhere to trade against.

    theorem QOU.Mass.MirrorSplitIsASmallFractionOfTheEnergy.zero_neutron_flux_is_the_r_eq_three_case {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] (Φp Φn : R) (Z N : ℕ) (hzero : Φn = 0) (hp : 0 ≤ Φp) (hNZ : ↑N ≤ ↑Z) :
    (↑Z + ↑N) * (Φp - Φn) ≤ (3 - 1) * (↑Z * Φp + ↑N * Φn)

    The Φn = 0 case satisfies the same bound at r = 3.

    The main bound needs Φn > 0 to define a ratio, so a vanishing neutron flux formally escapes its hypotheses. It does not escape its conclusion: with Φn = 0 and N ≤ Z (true on the whole A = 2Z − 1 mirror ladder, where N = Z − 1), the same inequality holds with r = 3.

    So the limit that looked like an escape sits inside the excluded regime.

    theorem QOU.Mass.MirrorSplitIsASmallFractionOfTheEnergy.zero_neutron_flux_fraction_is_exactly_one_over_Z {R : Type u_1} [CommRing R] (Φp Φn : R) (Z N : ℕ) (hzero : Φn = 0) :
    ↑Z * (Φp - Φn) = ↑Z * Φp + ↑N * Φn

    And the fraction is exactly 1/Z, not merely bounded.

    With Φn = 0 the energy is c·Z·Φp and the split is c·Φp, so Z times the split is the energy. On the A = 2Z − 1 ladder that is 2/(A + 1) — the same 1/A order the general bound gives, reached exactly rather than as an estimate.
