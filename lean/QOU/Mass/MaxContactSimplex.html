    and notes that the tempting fit-free light-nucleus match — ⁴He weighted 6·a_D² + 4·a_D³ + 1·a_D⁴ — is exactly that A≤4 simplex bond count, i.e. the binomials C(4,2), C(4,3), C(4,4).

    That assertion was prose. It is also a theorem, and it is load-bearing, so it is proved here.

    What is actually being claimed #

    Equal spheres of radius r are mutually tangent exactly when their centres are pairwise at distance 2r. So "A spheres in max contact, all pairs touching" is "A points pairwise equidistant", and the claim A ≤ 4 in three dimensions is:

    at most finrank + 1 points of a real inner-product space can be pairwise equidistant.

    Hence the contact graph is complete — C(A,2) bonds — precisely for A ≤ 4, and for A ≥ 5 it must have strictly fewer, which is the "saturates below".

    The proof #

    Base at p 0 and set vᵢ = pᵢ - p₀. All ‖vᵢ‖ = c, and for i ≠ j

    ‖vᵢ - vⱼ‖ = ‖pᵢ - pⱼ‖ = c   ⟹   ⟪vᵢ, vⱼ⟫ = c²/2,

    so the Gram matrix is c²/2 off the diagonal and c² on it, giving

    ‖∑ aᵢ vᵢ‖² = (c²/2) [ (∑ aᵢ)² + ∑ aᵢ² ].

    Both bracketed terms are non-negative, so the norm vanishes only when every aᵢ = 0: the vᵢ are linearly independent, and there are A - 1 of them.

    Verified numerically before formalising, with a control: replacing the off-diagonal c²/2 by 3c²/4 breaks the identity on 967 of 1000 random integer vectors, so the check is not vacuous.

    Bridge to QOU.Mass.CoordinationSaturation #

    CoordinationSaturation.lean refutes complete-graph coordination by its CONSEQUENCE: complete_graph_no_saturation shows perNucleonComplete ε A — the C(A,2)-bond model — exceeds every bound, so no B/A plateau exists. It then takes bounded degree as a modelling assumption (perNucleonBounded).

    no_complete_contact_of_five_le refutes the same model a second and independent way: in three dimensions the complete contact graph does not EXIST for A ≥ 5, whatever it would predict. So the C(A,2) bond count is not merely phenomenologically wrong for heavy A; it is geometrically unavailable, which is the t7qv frontier's "A≥5 saturates below" as a theorem rather than a premise.

    What this does NOT supply, stated so nobody mistakes the bridge for the whole span. bounded_degree_saturates needs a bound on the DEGREE, and that is the three-dimensional kissing number (12, Schütte–van der Waerden) — not proved here and not a modest formalisation. -- Ref: [bezdek-reid2013] — held source stating the kissing-number-12 rigidity it uses (Thms 4/5, via Hales' 2.52 separation of a 13th ball); the Schütte–van der Waerden 1953 proof itself is not held.

    And a trap, verified numerically, for whoever tries the easy route. The standard spherical-code argument — ∑ᵢⱼ ⟪uᵢ,uⱼ⟫² ≥ m²/d against ∑_{i≠j} ⟪uᵢ,uⱼ⟫² ≤ m(m-1)/4 — would give m ≤ 9 in d = 3. That is FALSE: the icosahedral configuration realises m = 12. The argument needs |⟪uᵢ,uⱼ⟫| ≤ 1/2, whereas tangency bounds the inner product only from ABOVE. Measured on that configuration: the inner products run over [-1, 0.4472], so ⟪uᵢ,uⱼ⟫ ≤ 1/2 holds while |⟪uᵢ,uⱼ⟫| ≤ 1/2 fails at the antipodal pairs, and ∑ᵢⱼ ⟪uᵢ,uⱼ⟫² = 48 exactly — meeting the Frobenius bound m²/d = 48 with equality, and exceeding the naive ceiling m + m(m-1)/4 = 45.
