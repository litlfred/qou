    theorem QOU.Mass.BrunnianTierDisambiguation.linkingVanishes_iff_forall_at (lk : Fin 3 → Fin 3 → ℤ) (hsymm : ∀ (i j : Fin 3), lk i j = lk j i) :
    lk 0 1 = 0 ∧ lk 0 2 = 0 ∧ lk 1 2 = 0 ↔ ∀ (k : Fin 3), FreedmanHeGenusHandleNeedsVanishingLinking.BrunnianAt lk k

    T2 ⟺ T3, on a three-component cluster.

    All three pairwise linking numbers vanish exactly when every component is unlinked from the other two. Symmetry of the linking matrix is a hypothesis because BrunnianAt reads the matrix in one direction only; the Gauss linking number is symmetric, so this is not a restriction in practice.

    This is the bridge MilnorIndeterminacyGate and FreedmanHeGenusHandleNeedsVanishingLinking never had between them — they state the same condition, one globally and one pointwise, and nothing related them.

    theorem QOU.Mass.BrunnianTierDisambiguation.noIsolatedPairEnergy_fails_for_crossing_pair (m : ℕ) (hm : 0 < m) (q : ℝ) (hq : 1 < q) :
    BrunnianBindingChannel.pairEnergy m m q ≠ 0

    T4 fails for every crossing pair — the statement that was walked past.

    A pair with n₊ = n₋ = m and 0 < m has vanishing linking number (so T2 and T3 hold of it) and strictly positive mutual energy, so NoIsolatedPairEnergy (w₂ = 0) is false of it. Vanishing linking does not empty the energy; it empties only the signed channel, and the unsigned count channel survives.

    Restated from brunnian_binding_survives under the name of the property it refutes, because the failure mode this file exists to prevent was reading a theorem about linking as a theorem about energy.
