    Disambiguation (qInt) #

    QOU.Mass.qInt (QHookDimension) is the balanced q-integer ∑_{i<n} q^{2i-(n-1)}; the geometric ∑_{i<n} q^i this file means is QOU.MathlibExt.qInt. Lean resolves a bare name against the enclosing namespace before an opened one, so inside namespace QOU.Mass.* a bare qInt is the balanced one however this file opens QOU.MathlibExt. Every reference below is therefore fully qualified: the bare form compiled against the wrong convention from 1646b5d6d3 until this was fixed, and a bare form reintroduced here would silently mean different mathematics again. Bean qou-lksc.
