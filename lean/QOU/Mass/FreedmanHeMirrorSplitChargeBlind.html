    def QOU.Mass.FreedmanHeMirrorSplitChargeBlind.fhBound {R : Type u_1} [CommRing R] (C a φp φn m : R) (Z N : ℕ) :
    R

    The right-hand side of the Freedman–He link bound (Komendarczyk eq. (43)) specialised to a vertex-transitive carrier and a charge-only flux.

    C is the pure constant (π/16)^{1/4}, a the common component value ac(L_k, L), m the factor min_k |Flux(X_k)|, and the Z proton components carry flux φp while the N neutron components carry φn. The sum Σ_k ac(L_k,L)|Flux(X_k)| collapses to a · (Z·φp + N·φn).

      The mirror split: the bound's value on (Z, N) minus its value on the mirror partner (N, Z). Mirror partners share A = Z + N, share the carrier link, and share m — the swap only relabels which components are charged, so every ingredient except the charge assignment is held fixed.

        theorem QOU.Mass.FreedmanHeMirrorSplitChargeBlind.mirrorSplit_eq {R : Type u_1} [CommRing R] (C a φp φn m : R) (Z N : ℕ) :
        mirrorSplit C a φp φn m Z N = C * a * m * ((↑Z - ↑N) * (φp - φn))

        The split factorises: all dependence on the nucleus enters through the single integer Z − N, multiplying the flux difference.

        This is the charge-blindness of eq. (43) made explicit: the topology (a), the constant (C) and the minimum (m) survive the subtraction untouched, and the component counts survive only in the combination Z − N.

        Stated as the falsifiable claim: two different nuclei on the d = 1 ladder have equal splits. The AME ladder disagrees by a factor of 13.63 across A = 3…63, so the hypotheses of this theorem — a vertex-transitive carrier, a flux depending only on charge, and a saturated bound — cannot all hold.

        theorem QOU.Mass.FreedmanHeMirrorSplitChargeBlind.mirrorSplit_eq_zero_of_flux_eq {R : Type u_1} [CommRing R] (C a φ m : R) (Z N : ℕ) :
        mirrorSplit C a φ φ m Z N = 0

        The split vanishes identically when the two fluxes agree. So a charge-blind flux assignment predicts no mirror splitting at all — the bound cannot even produce the effect, let alone its A-dependence. This is the degenerate case that forces φp ≠ φn before any fitting begins.
