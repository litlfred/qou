    def QOU.Mass.QbetaFmapPowerClassPrune.IsEigen {X : Type u_1} {R : Type u_2} [CommRing R] (rot : X → X) (ζ : R) (A : X → R) :
    Prop

    A function A : X → R is an eigenfunction of a self-map rot : X → X with eigenvalue ζ iff A (rot z) = ζ · A z for all z. This abstracts the ζ₄ = i rotation z ↦ z + iπ/2 of the fibre argument (whose exp-eigenfunction is exp_zeta4_eigen in ComplexVolumeZeta4Partner).

      Pincer Arm-2 core. For a ζ₄ eigenfunction (ζ² = −1) and an even power m, ζ₄-faithfulness of the monomial power Aᵐ (both non-faithful orbit sums vanish) forces 4·Aᵐ ≡ 0. Because m is even, μ = ζᵐ has μ² = ζ²ᵐ = (ζ²)ᵐ = (−1)ᵐ = 1, so the isotype collapse fires. Generic [CommRing R].

      ℂ bridge to bean 5nx8 (IsZeta4Faithful, zeta4Rot) #

      The generic core specialises to the concrete ζ₄ fibre model. Over ℂ, 4 ≠ 0, so four_mul_eq_zero upgrades to Aᵐ ≡ 0: an even-degree monomial in a ζ₄-faithful carrier vanishes identically. The carrier exp (the +i eigenvector, exp_zeta4_eigen) then gives the non-vacuous refutation.
