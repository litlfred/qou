    theorem QOU.Mass.LowerBoundCannotConstrainADifference.diff_unconstrained {R : Type u_1} [AddCommGroup R] [LinearOrder R] [IsOrderedAddMonoid R] (B₁ B₂ t : R) :
    ∃ (E₁ : R), ∃ (E₂ : R), B₁ ≤ E₁ ∧ B₂ ≤ E₂ ∧ E₁ - E₂ = t

    The result. A lower bound on each of two quantities places no constraint on their difference: for any target t, energies satisfying both bounds exist whose difference is exactly t.

    The witness is explicit — push E₂ up until E₁ = E₂ + t clears B₁ as well. Since E₂ may be taken arbitrarily large, t may be arbitrarily negative; since E₁ may be, t may be arbitrarily positive.

    theorem QOU.Mass.LowerBoundCannotConstrainADifference.diff_bounded_of_upper {R : Type u_1} [AddCommGroup R] [LinearOrder R] [IsOrderedAddMonoid R] {E₁ E₂ B₁ B₂ U₁ U₂ : R} (h₁ : B₁ ≤ E₁) (h₁' : E₁ ≤ U₁) (h₂ : B₂ ≤ E₂) (h₂' : E₂ ≤ U₂) :
    B₁ - U₂ ≤ E₁ - E₂ ∧ E₁ - E₂ ≤ U₁ - B₂

    What would restore a constraint without saturation: an UPPER bound. Given two-sided bounds the difference is pinned to an interval. Eq. (43) supplies only the lower half, so this names the missing ingredient exactly — not more topology, but an upper bound on the energy of a knotted flux configuration.

    The interval of diff_bounded_of_upper collapses to a point exactly when both bounds are tight, recovering diff_of_saturated. So saturation is the extreme case of the two-sided situation, not a mild simplification of it: it assumes the upper bound coincides with the lower one.
