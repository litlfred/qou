          theorem QOU.Mass.EnumeratorSelectionDegeneracy.selfCrossing_countChannel_eq_zero (q : ℝ) :
          countChannel 0 0 q = 0

          A carrier built only from intra-nucleon generators contributes no binding. It has no inter-component crossings, so both counts are zero and the channel vanishes identically — for every q, so no anchor or convention rescues it. This is what the enumerator's rank-1 candidate σ₈⁻² is.

          source
          theorem QOU.Mass.EnumeratorSelectionDegeneracy.carrier_underdetermined_by_binding (np nn : ℕ) (q : ℝ) :
          countChannel np nn q = countChannel (np + nn) 0 q

          So the carrier is underdetermined by the binding itself. In B₉ there are nine band generators joining any given pair of nucleons (3 × 3 strand choices), and countChannel assigns all nine the same value. Combined with QOU.Mass.SelfMutualPartition, which makes the binding a sum over inter-component crossings, the binding-relevant content of a carrier is just the per-pair crossing counts — a triple (m₁, m₂, m₃), not a braid word.

          Measured, for a Brunnian carrier (n₊ = n₋ = mᵢ on each pair) with total crossings c ≤ 12: 20 triples, against 382,637,520 structured band words — a collapse of about 1.9 × 10⁷.

          This is why a trace criterion cannot select the carrier, and it subsumes Defect 3. The residual is being asked to make a distinction the binding does not use. Defect 3 (the exact 1|2-vs-2|3 tie) is the two-generator shadow of this: the trace ties them because the binding has no opinion either.

          3. The minimal interface set cannot carry a Brunnian link #

          source
          def QOU.Mass.EnumeratorSelectionDegeneracy.twoLk (a b : ℤ) :
          ℤ × ℤ × ℤ

          Pairwise linking numbers of a carrier σ₃^a σ₆^b in B₉, doubled to stay in ℤ: the 1|2 pair sees only the σ₃ letters, the 2|3 pair only the σ₆ letters, and the 1|3 pair sees neither.

          The third component being 0 is an ENCODING of a reachability fact, not something proved here. σ₃ transposes positions 3,4 and σ₆ transposes 6,7, so no strand starting in block 1 (1…3) can ever occupy a position adjacent to a strand of block 3 (7…9): the two blocks never cross, at any word length. Formalising that would need a braid-word model this file deliberately does not carry; it is stated in the header and taken as the definition of twoLk. Everything below is honest given that reading and vacuous without it.

            theorem QOU.Mass.EnumeratorSelectionDegeneracy.commuting_interfaces_brunnian_trivial (a b : ℤ) (h : twoLk a b = (0, 0, 0)) :
            a = 0 ∧ b = 0

            On the minimal interface set the only Brunnian carrier is trivial. σ₃ and σ₆ are distant (|3 - 6| ≥ 2) hence commute, so ⟨σ₃, σ₆⟩ is free abelian and every word reduces to σ₃^a σ₆^b. Brunnian means every pairwise linking number vanishes, which forces a = b = 0.

            So no amount of extra word length produces a Brunnian carrier here — the obstruction is the generator set, not the length bound. The corpus's own canonical A = 3 carrier, the Borromean (σ₁σ₂⁻¹)³, needs adjacent generators and is therefore outside this subgroup entirely.
