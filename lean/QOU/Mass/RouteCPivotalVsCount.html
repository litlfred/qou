    Route C step 2 — the pivotal Markov parameter against the count-shaped one #

    Bean qou-8uxw (route C of the binding-gap survey, docs/audits/2026-09-05-binding-gap-groupoids-derived-categories-full-tower.md §7d). Route C step 1 showed the order-zero cross term is a Burnside fixed-point count. Step 2 asks whether the framework's q-deformation of that count is itself an unweighted count (a groupoid cardinality in the Baez–Hoffnung–Walker sense).

    On the spin-½ tensor space V^{⊗n} with the §7a R-matrix (eigenvalues q on Sym², −q⁻¹ on Λ²) there are two natural normalised traces of a single crossing:

    • the pivotal one, K = diag(q, q⁻¹) inserted on every strand — the framework's convention D, zD q = q³ / (q² + 1);
    • the ordinary one, no weight — the count-shaped reading, zJ q = (3q − q⁻¹) / 4.

    This file carries the three algebraic facts the probe computations/probes/route_c_step2_pivotal_vs_count_probe.py measures, stated over a generic field so nothing archimedean enters:

    1. zJ_sub_zD — the exact difference zJ − zD = −(q² − 1)² / (4q(q² + 1)), so the two agree at q = 1 and to first order (double root) and split at second order;
    2. zJ_eq_zD_iff — they coincide iff q² = 1;
    3. ordinary_partial_trace_scalar_iff — the mechanism: the unweighted partial trace of the R-matrix over the closed strand is diag(2q − q⁻¹, q), and that is scalar iff q² = 1. A trace on V^{⊗n} is a Markov trace iff that partial trace is scalar, so the ordinary trace is not a Markov trace away from q = ±1 — the framework's q-count is the K-weighted count.

    The partial-trace matrix itself is computed in the probe (it is a 2×2 calculation); what is proved here is the scalar-iff-q² = 1 step, which is the step a numerical evaluation at one q cannot establish.

    Base ring: a generic Field K with (4 : K) ≠ 0; the two hypotheses q ≠ 0 and q² + 1 ≠ 0 are exactly the denominators. No ℝ.
