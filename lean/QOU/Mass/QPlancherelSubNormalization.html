    QOU.Mass.QPlancherelSubNormalization — the q-Plancherel completeness defect #

    Formalize-first Lean record of the normalization leg of the W_λ keystone wall (2026-07-17 audit docs/audits/.../keystone-wlambda-unitarity-normalization-gate.md, Python probe keystone_wlambda_unitarity_normalization_gate_probe.py). The q-deformed Plancherel weight of an irrep λ ⊢ n is W_λ(q) = d_q(λ)² / [n]_q!, and its total mass is the partition function

    Z_n(q) := (Σ_{λ ⊢ n} d_q(λ)²) / [n]_q!,

    where d_q(λ) = [n]_q! / ∏_{cells}[hook]_q is the quantum hook-length dimension and [k]_q = (q^k − q^{−k})/(q − q^{−1}) is the balanced quantum integer. At q = 1 this is the classical Plancherel measure and Z_n(1) = 1 (RSK / Burnside: Σ_λ (f^λ)² = n!). The audit's finding — the content of this file — is that for q ≠ 1 the total mass is a rational function of q that is strictly less than 1: W_λ is sub-normalized, so it is not the vacuum-row probability measure of any unitary modular category at real q ≠ 1. The "fibre → archimedean continuation" of the normalization is therefore trivial (a rational function continues everywhere bar poles); the genuine wall is the non-rational amplitude leg (the Lawrence–Rozansky front), not the normalization.

    This file proves the two smallest cases explicitly, which is all that is needed to witness both phenomena (rationality + strict sub-normalization at q ≠ 1):

    • n = 2 — Z₂(q) = 2q/(q²+1) (rational), Z₂(1) = 1, and Z₂(q) < 1 for every real q > 0, q ≠ 1 (the archimedean completeness defect);
    • n = 3 — Z₃(q) = q(q⁴+4q²+1) / ((q²+1)(q⁴+q²+1)) (rational), Z₃(1) = 1.

    Base ring: ℝ throughout (§7c). This is deliberate and justified — the load-bearing result is the archimedean strict inequality Z₂(q) < 1 (a 0 < (q−1)² fact), which lives past the substrate→archimedean wall; the companion rational-closed-form identities are stated over ℝ so that positivity discharges the (positive) denominators without threading nonvanishing hypotheses.

    The small-n quantum dimensions are the hook-length values, computed by hand: d_q((2)) = d_q((1,1)) = 1, d_q((2,1)) = [2]_q, d_q((3)) = d_q((1,1,1)) = 1 (hook multisets {2,1}, {3,1,1}, {3,2,1}), and [2]_q! = [2]_q, [3]_q! = [3]_q[2]_q.

    Ref: [macdonald1995] (symmetric functions; hook-length formula) — folio/schema/references.ts.
