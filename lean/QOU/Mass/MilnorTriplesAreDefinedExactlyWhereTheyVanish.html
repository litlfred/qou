    structure QOU.Mass.MilnorTriplesAreDefinedExactlyWhereTheyVanish.Summands :
    Type

    Two components are joined when some summand of the connected-sum decomposition touches both.

    On the derived carrier a summand is one generator's run, so it touches only the components containing strands g and g+1 — measured at most two, on A = 2, 4, 6, 8, 10. The single hypothesis joins_linked is what the topology supplies: a shared (2, k) torus summand links the two components it joins.

    • joins : ℕ → ℕ → Prop

      some summand of the connected sum touches both components

    • lk : ℕ → ℕ → ℤ

      linking numbers of the closure

    • joins_linked (i j : ℕ) : self.joins i j → self.lk i j ≠ 0

      sharing a summand makes two components linked

      theorem QOU.Mass.MilnorTriplesAreDefinedExactlyWhereTheyVanish.separated_of_delta_zero (S : Summands) {a b c : ℕ} (hab : S.lk a b = 0) (hbc : S.lk b c = 0) (hca : S.lk c a = 0) :
      ¬S.joins a b ∧ ¬S.joins b c ∧ ¬S.joins c a

      The result, and it is the whole file. A triple on which μ̄ is a genuine integer — Δ = gcd(lk_ij, lk_jk, lk_ki) = 0, i.e. all three pairwise linking numbers vanish — shares no summand between any two of its members.

      Its sublink is therefore split, and every Milnor invariant of length ≥ 2 vanishes on a split link — whatever the individual components are knotted as (measured: they are (2, odd)-torus knots, not unknots; local knotting changes no Milnor invariant). So on this carrier the condition that makes μ̄ defined is the condition that makes it zero.

      Needs no path structure, no minimality, and no Δ-arithmetic: it is exactly the contrapositive of joins_linked, which is why the result is as general as the connected-sum decomposition itself.
