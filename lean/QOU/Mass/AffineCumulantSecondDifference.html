          theorem QOU.Mass.AffineCumulantSecondDifference.secondDiff_signedCumulant_eq_zero {R : Type u_1} [CommRing R] (α β : R) (k : ℕ) :
          signedCumulant α β (k + 2) - 2 * signedCumulant α β (k + 1) + signedCumulant α β k = 0

          The second difference vanishes identically, for every (α, β).

          This is the invariant the exclusion rests on, and it is why the test is parameter-free: α and β have cancelled before any measured value is used.
