        theorem QOU.Mass.PairEnergyRewardsShort.pairEnergy_singleton_le {α : Type u_1} {K : α → α → ℕ → ℝ} (hK : ∀ (a b : α) (d : ℕ), 0 ≤ K a b d) (x : α) (w : List α) :
        pairEnergy K [x] ≤ pairEnergy K w

        "Rewards short operators", proved.

        Under a non-negative kernel, a one-letter word is a GLOBAL minimiser of the pair energy — it attains 0 and nothing can go below 0. So minimising a pair energy over a catalogue of mixed lengths selects a shortest operator for a reason that has nothing to do with the operator: the sum is empty.

        source
        theorem QOU.Mass.PairEnergyRewardsShort.exists_singleton_minimiser {α : Type u_1} {K : α → α → ℕ → ℝ} (hK : ∀ (a b : α) (d : ℕ), 0 ≤ K a b d) (cat : List (List α)) (x : α) (hmem : [x] ∈ cat) :
        ∃ w₀ ∈ cat, pairEnergy K w₀ = 0 ∧ ∀ w ∈ cat, pairEnergy K w₀ ≤ pairEnergy K w

        The form that bites on a selection program: if the catalogue contains ANY one-letter word, the program's optimum is 0 and is attained there, whatever else the catalogue holds.

        This is why the measured degeneracy is structural. It is also exactly why the honest comparison is at FIXED length, where every candidate has the same number of pairs and the kernel's separation-dependence is what decides.
