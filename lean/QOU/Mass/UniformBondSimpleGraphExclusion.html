    def QOU.Mass.UniformBondSimpleGraphExclusion.b3Uniform {R : Type u_1} [CommRing R] (ε : R) (e2 e3 : ℕ) :

    The connected three-body cumulant of a uniform-bond assembly, written in terms of the edge counts alone: b₃ = ε·(e₃ − 3·e₂).

      theorem QOU.Mass.UniformBondSimpleGraphExclusion.b3Uniform_nonpos {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {ε : R} (hε : 0 ≤ ε) {e2 e3 : ℕ} (h3 : e3 ≤ 3) (h2 : 1 ≤ e2) :
      b3Uniform ε e2 e3 ≤ 0

      The exclusion. A simple graph on three vertices has at most three edges, and a bonded pair has at least one. Hence every uniform-bond simple-graph assembly has b₃ ≤ 0.

      No monotonicity, no degree cap, no relation between mass numbers is assumed. The hypotheses are exactly "the triple's graph is simple" and "the pair is bonded".

      The equality case is the complete triple. b₃ = 0 exactly when the triple carries all three bonds and the pair carries one — the pairwise-additive assembly. Every sparser graph is strictly negative.

      The falsifiable form. A measured b₃ > 0 refutes the conjunction "uniform bond weight" ∧ "simple graph" — for every graph family at once, so no choice of which pairs bind can rescue it.

      AME2020 gives b₃ = +1.426220 MeV, so the physical binding is not of this shape.
