    QOU.Mass.BindingQBesselKernel — Layer 2: the super-exponential q-Bessel kernel #

    The genuine global layer of the binding prolongation a_D^(n). Sibling PR #2795 settled, via the √-branch of the color spectral curve (X^(n) ~ (z−z_k)^{1/2−n}, falling-factorial coefficient (1/2)_n), that a_D^(n) = lw(n−1) (#1765) grows super-exponentially — and that its natural fast kernel is the q-Bessel class (jackson-q-bessel-contiguity). This file wires that verdict to the existing q-Bessel infrastructure (QOU.QBeta.QBesselContiguityRecurrence) at the level of the binding period sequence.

    The two layers are one recurrence with two ratio regimes #

    Both layers are first_order_solution (c_n = c_0 · ∏_{j<n} r_j) with different ratio r:

    Layer ratio r_k sequence regime
    1 (BindingHyperbolicRecurrence) constant ρ = λ₊ = e^{θ_binding} a_D^(n) = a_D^(0)·ρⁿ (geometric, C-finite) depth-2 SL₂, n ≤ 4 fit
    2 (this file) q^k-dependent qbesselRatio q a k a_D^(n) = a_D^(0)·∏ qbesselRatio (q-holonomic) super-exp, true global

    Layer 1 is exactly the constant-ratio degeneration (q → 1) of Layer 2 (geometric_of_constant_ratio in the imported file) — which is precisely why the SL₂ trace τ is an effective fit that breaks at n = 6: a q^k-dependent ratio admits no low-order constant-coefficient (C-finite) recurrence (#1839).
