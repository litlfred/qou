    The Hecke relation for a generator σ with parameter q: σ² = (q − q⁻¹) σ + 1 (the convention (σ − q)(σ + q⁻¹) = 0 of §7a).

      def QOU.Mass.MixedSpectrumCharacterNotLetterMultiplicative.RightLetterMultiplicative {R : Type u_1} {H : Type u_2} [Field R] [Ring H] [Algebra R H] (χ : H →ₗ[R] R) (σ : H) (q' : R) :
      Prop

      χ is right-multiplicative for the letter σ with scalar q': χ(x σ) = q' χ(x) for every x. This is what makes a letter contribute a fixed factor to the character of any word it is appended to.

        ¬∃ (q' : R), RightLetterMultiplicative χ σ q'

        Mixed spectrum excludes letter-multiplicativity. If χ(1) = d₊ + d₋ and χ(σ) = d₊ q − d₋ q⁻¹ with both multiplicities non-zero (the trace of a representation in which σ has both eigenvalues q and −q⁻¹), then no scalar q' makes χ(x σ) = q' χ(x) for all x.
