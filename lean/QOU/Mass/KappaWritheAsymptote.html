    Gap-9b, κ leg: the isovector-slope asymptote is the trace ratio, not the interface factor #

    The bar-odd writhe coefficient κ of the per-isotope binding residual decomposes as κ = κ_FW + κ_AME, and its framework part is carried by the isovector (mirror) slope b_pred(A) = d(log_{q₀} B_pred)/dT₃. The Phase-5q closed form (computations/probes/b_pred_mirror_slope_closed_form.py, audit 2026-06-29-delta-lambda-z-correction-writhe) gives, for a mirror pair (Z,N) ↔ (N,Z),

    B_pred(Z,N) = E₀ · τ_p^Z τ_n^N · (1 − ε(Z,N)),   ε(Z,N) = z^{Z−1}(z − h/2)(z − h)^{N−1}
b_pred(A)   = log_{q₀}(τ_p/τ_n) + log[(1 − ε(N,Z))/(1 − ε(Z,N))] / ((N − Z)·ln q₀)

    with the measured substrate values z ≈ 0.4994 and z − h ≈ 0.2903, both < 1 in absolute value. The derived claim (this file, sorry-free):

    • epsilon_tendsto_zero — since |z| < 1, the interface term ε vanishes geometrically as the strand count grows. This is why the interface correction dies at large A.
    • correction_zero_of_eps_eq — when the two mirror interface terms coincide (the ε → 0 limit), the correction term is exactly 0, so b_pred = log_{q₀}(τ_p/τ_n) — the plateau.

    Consequence (the refutation, scope (a)). The asymptote of b_pred is the p/n trace ratio log_{q₀}(τ_p/τ_n) ≈ 1.37181 (hence κ_FW = −b_pred(∞)/4 ≈ −0.34295), not the earlier interface-only near-match log_{q₀}(z/(z−h)) ≈ 1.2998: interfaces enter only through the vanishing ε term (epsilon_tendsto_zero), never the plateau. The κ_AME ≈ −0.094 remainder is experimental (Coulomb isovector), outside the trace — so κ overall stays near-match, not derived.

    Base ring ℝ (§7c): genuinely archimedean — Real.log, |z| < 1, geometric decay.
