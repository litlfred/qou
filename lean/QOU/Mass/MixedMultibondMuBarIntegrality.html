    Mixed-multibond μ̄-idempotent: the common-weight integer count is refuted #

    Lean face of the integrality obstruction measured in computations/deltalambda/mixed_multibond_mubar_integrality_probe.py (audit docs/audits/2026-07-18-mixed-multibond-mubar-idempotent-integrality.md).

    The audit's next-step-#1 hypothesis is that the mixed-multibond shared channel is "one |μ̄|-idempotent per light cluster" — a common scalar weight w times the (signed) integer Milnor triple count S m ∈ ℤ:

    channel m = w · (S m), S m ∈ ℤ.

    Milnor invariants are integers (Magnus expansion; binding_mn_milnor_linking.py), so this file proves the purely-algebraic consequence: such a model forces the channel values into integer proportion, and — normalised so the single triple at m = 2 is the unit — every channel m is an integer multiple of channel 2. The measured t-series is not (¹⁵N / ¹¹B = 1.22, ¹⁹F / ¹¹B = 0.35), so no such model exists. What survives is a q-weighted per-triple magnitude (the SDP per-block weight), where w is not common — this file rules out only the common-weight form.

    Base ring is a generic [CommRing R] (§7c): the statement is pure algebra in R with integer casts (· : ℤ) → R; no ordering, no ℝ. The archimedean channel values (MeV) instantiate R := ℝ at the consumer, supplying the empirical channel m ≠ (k : R) · channel 2 hypothesis from the probe.

    Common-weight models put the channel into integer proportion. If channel m = w · (S m) with an integer count S, then for all m, k

    channel m · (S k) = channel k · (S m)

    (cross-multiplication) — the values are in the integer ratio S m : S k, independent of the common weight w.

    theorem QOU.Mass.MixedMultibondMuBarIntegrality.mubar_common_weight_refuted {R : Type u_1} [CommRing R] (channel : ℕ → R) (w : R) (S : ℕ → ℤ) (hmodel : ∀ (m : ℕ), channel m = w * ↑(S m)) (hunit : S 2 = 1) (m : ℕ) (hnonmult : ∀ (k : ℤ), channel m ≠ ↑k * channel 2) :
    False

    Refutation. If some measured channel m is not an integer multiple of channel 2, no common-weight integer-count μ̄-idempotent model (normalised at the m = 2 unit) can reproduce it. The hypothesis hnonmult is the empirical input (the probe: ¹⁵N/¹¹B = 1.22, ¹⁹F/¹¹B = 0.35 are not integers).

    The surviving q-weighted form is under-determined per level (anti-laundering) #

    The refutation above kills the common-weight form (one scalar w, over- determined by the several channel m). What survives is a per-triple weighted sum channel m = Σ_{i ∈ triples m} w_i · μ̄_i with the weights w_i not common. This lemma states the honest epistemic status of that survivor: at a single level with N ≥ 1 triples and a nonzero μ̄, the N free weights can reproduce any target channel value — so the q-weighted form is unfalsifiable from the channel value alone. It is therefore a fit unless the weights are supplied by an independent derivation (the confinement-SDP per-block LP duals, #3802) rather than read off the observable. This is the anti-laundering companion to the refutation: "q-weighted survives" is not a free closure. Base ring [Field R] (division).
