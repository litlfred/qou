        theorem QOU.Mass.SelfCrossingInvarianceGate.gate_has_content :
        (SelfMutualPartition.mutualEnergy Finset.univ (fun (x : Fin 2) => 1) fun (c : Fin 2) => c = 0) = 1 ∧ bindingOfIsolated Finset.univ (fun (x : Fin 2) => 1) 1 = -1 ∧ bindingOfIsolated Finset.univ (fun (x : Fin 2) => 1) 0 = -2 ∧ bindingOfIsolated Finset.univ (fun (x : Fin 2) => 1) 1 ≠ bindingOfIsolated Finset.univ (fun (x : Fin 2) => 1) 0

        The gate has falsifiable content: drop it and binding is no longer a function of the mutual part. One fixed assembly — a single inter-component crossing and a single self-crossing, each of unit energy — read two ways: the self-crossing was already present in isolation (isolatedMassTotal = 1, the gate holds) or it was created by the assembly (isolatedMassTotal = 0, a type-I move, the gate fails). The mutual energy is 1 in both readings, and the two bindings differ. So binding_indep_of_self is a consequence of the gate, not of the partition.

        §2 — the Călugăreanu reason the gate is not automatic #

        SL = Wr + Tw (Călugăreanu 1961 (1.3); Pohl (1.4), stated for regular isotopy). Passage through an inflexional configuration moves writhe and twist by equal and opposite amounts, so only the sum survives; and a type-I Reidemeister move — the creation or removal of a self-crossing — forces such a passage, which Moffatt & Ricca note general ambient isotopies typically involve.

        Generic over [AddCommGroup R]: the exchange is pure algebra (§7c — no ordering, no archimedean construct is needed to state or prove it).

              Carrying §2 into the gate of §1 #

              A self-energy functional on framed components is a map Framed R → ℝ. Whether the §1 gate holds for it is decided by which invariant it factors through.
