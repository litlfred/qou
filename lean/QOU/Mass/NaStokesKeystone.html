    QOU.Mass.NaStokesKeystone — the prolongation-period keystone (§3b conjecture) and the conditional τ #

    This file formalises the neighbourhood of the Lever-1 keystone identity

    a_D^(n) = ∮_{S_c} λ_SW^(n) = lw(n−1) (conj #1765)

    — stating the keystone as a §3b conjecture class and proving, conditional on it, that the depth-2 SL₂ binding trace τ assembles (sorry-free) to its bar-even closed form.

    The non-abelian-Stokes utilisation (the bridge made explicit) #

    The keystone is the last link of the categorical derivation chain. The non-abelian Stokes step supplies what the period integrates to:

    1. Yekutieli non-abelian Stokes (prop:hecke-spectral-sequence) — CONJECTURAL, see QOU.Mass.HeckeMonodromy (2026-09-06). The abelianised Cartan connection on the exceptional divisor S_c is conjectured to have curvature 2-form F(σ) = σ² − (q − q⁻¹)σ − 1; the corpus does not construct it (cheat-sheet §2a). Its q = 1 shadow — a reflection — IS derived (Picard–Lefschetz monodromy of the colour cubic, HeckeQuadraticClassicalShadow.lean); only the deformation 1 ↦ q is the hypothesis. Granting it, flatness F = 0 gives the Hecke quadratic, whose two roots are the Stokes/Hecke eigenvalues λ₊ = q (symmetric L₊), λ₋ = −q⁻¹ (antisymmetric L₋) — QOU.Mass.HeckeStokes.stokes_curvature_factors.
    2. Holonomy = multiplicative surface integral. The loop holonomy Hol(∂S_c) = ∮_{S_c} F (Yekutieli's MI∫) is therefore a Hecke element.
    3. Markov trace (QOU.Hecke.MarkovTrace). Closing the loop applies the canonical trace tr_M, which Wedderburn-decomposes as tr_M(x) = Σ_λ y_λ χ^λ(x) (QOU.Hecke.Wedderburn.trace_decomposition, derived from complete + block_scaling since PR #5710; it was a projected class field before that).
    4. Mean quantum dimension. Averaging the selection-rule character sum over the partitions λ ⊢ c+1 is precisely lw(c) = (1/(c+1)) Σ_{λ⊢c+1} dim_q V_λ. The keystone asserts the n-jet prolongation period equals this categorical average.

    So the open core is only the geometric step 1→4 equality (period = lw); everything downstream of it — the τ assembly here — is unconditional Lean algebra. The bar-evenness of τ is inherited from the eigenvalue gap [2]_q = λ₊ − λ₋ = q − (−q⁻¹) (QOU.Mass.HeckeStokes.quantum_dim_is_eigenvalue_gap), which this file uses directly.

    Scope honesty — the depth-2 SL₂ τ is the n ≤ 4 effective reading #

    Sibling PR #2795 (sw_period_growth_probe.py, fork verdict [docs/audits/2026-06-25-sw-jet-prolongation-explicit-and-fork.md]) settles, structurally, that γ encircles a disc_X = 0 branch point ⇒ a √-branch ⇒ X^(n) ~ (z−z_k)^{1/2−n} ⇒ the period coefficient is the falling factorial (1/2)_n, so the true global a_D^(n) grows super-exponentially (= the mean quantum dimension lw; the q-Bessel class is its fast kernel). The depth-2 SL₂ recurrence a_D^(n+2) = τ a_D^(n+1) − a_D^(n) is geometric (ratio → λ₊ ≈ 2.18), so τ is an effective fit to the three binding anchors n = 2, 3, 4 (deuteron n=2, ⁴He magic-shell n=4). They agree through n = 5 and split at n = 6. Accordingly the theorem below consumes the keystone only at c = 1, 2, 3 — it is the honest finite n ≤ 4 assembly, not a claim that the global prolongation is SL₂.

    The three selection-rule values fed as hypotheses are proved unconditionally on main: selection_rule_c1_eq_one, selection_rule_c2_eq_closed_form, selection_rule_c3_eq_family_a_q_form (climax-volume-mass/selection-rule-*.lean).

    The prolongation-period keystone — conj:sw-prolongation-period-eq-mean-qdim (#1765), axiomatised as a §3b conjecture class.

    aD n is the n-th jet-prolongation period a_D^(n) = ∮_{S_c} λ_SW^(n) of the Seiberg–Witten differential; lw c is the selection-rule mean quantum dimension (1/(c+1)) Σ_{λ⊢c+1} dim_q V_λ. The conjecture asserts the period equals the non-abelian-Stokes / Markov-trace average lw at every level:

    a_D^(n) = lw(n−1) i.e. aD (c+1) = lw c.

    This sorry-free class is the only unproved input of the conditional results below; an instance is the geometric content (step 1→4 of the docstring bridge), not a missing proof.

    • keystone (c : ℕ) : aD (c + 1) = lw c

        The even/odd (cosh/sinh) hyperbolic structure #

        Writing q = e^ξ (ξ = log q), the two Stokes/Hecke eigenvalue combinations are the two hyperbolic functions of ξ:

        [2]_q = q + q⁻¹ = 2 cosh ξ (the gap λ₊ − λ₋; bar-even, q ↦ q⁻¹ invariant) q − q⁻¹ = 2 sinh ξ (the curvature coefficient λ₊ + λ₋; bar-odd)

        The Hecke bar-involution q ↦ q⁻¹ is ξ ↦ −ξ, under which cosh is even and sinh is odd. This is exactly the "even/odd" split: τ is a rational function of the even gap alone (tau_in_stokes_eigenvalue_gap), hence bar-even — it is the algebraic face of τ = 2 cosh θ_binding. The lemmas below pin the even/odd dichotomy without leaving the substrate-algebra regime (no Real.cosh/exp needed; the bar-involution carries the parity). The bar-odd q − q⁻¹ is the sinh-partner whose physical face is the bar-odd Q_β scale (canonical cheat sheet: Q_β = the sinh partner of the bar-even cosh meson scale m_π).
