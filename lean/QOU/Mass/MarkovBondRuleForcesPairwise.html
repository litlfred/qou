    structure QOU.Mass.MarkovBondRuleForcesPairwise.ClusterTrace (R : Type u_3) [CommMonoid R] :
    Type u_3

    The Markov-trace ratios of the clusters of up to four nucleons: one scalar per cluster. Only the ratio tr_free / tr_atom matters, so this carries no units and no anchor.

    • pair : Fin 4 → Fin 4 → R

      the two-body cluster {i, j}.

    • triple : Fin 4 → Fin 4 → Fin 4 → R

      the three-body cluster {i, j, k}.

    • quad : R

      the four-body cluster.
