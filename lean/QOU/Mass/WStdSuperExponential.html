    QOU.Mass.WStdSuperExponential — w_std defined, and its growth made unconditional #

    w_std(k) = ∑_{λ ⊢ k} W_λ · f^{λ/(2,1)} (Plancherel weights W_λ = (f^λ)²/k!) is the branched tower weight the level-selection argument turns on. Three files reason about it — QOU/Mass/LevelSelectionLogarithmic.lean, QOU/Mass/CubeMomentLowerBound.lean, QOU/Mass/BindingGevreyHalf.lean — and until now it had no Lean definition at all: it lived in docstrings, and every statement about it was either abstract in a function parameter w : ℕ → ℝ or carried its two inputs as hypotheses. wStd below is that definition.

    What is now unconditional #

    BindingGevreyHalf.wstd_superexp_sq proves k!/(81·2^k) ≤ w_std(k)² from two hypotheses it explicitly declines to discharge — its docstring calls them "the open combinatorial core":

    • (A) ∑_λ f^λ · f^{λ/(2,1)} = k!/3 — this is branching_two_one, proved in QOU.Mathlib.SkewBranchingTwoOne (bean qou-b21r).
    • (C) ∑_λ f^{λ/(2,1)} ≤ I(k) — skew_le_straight composed with sum_dimSYT_eq_involution, both already unconditional.

    Both are now theorems, so wStd_sq_lower states the bound with no hypotheses but k ≥ 3.

    The class was unsatisfiable as stated; it now carries a threshold, and is inhabited #

    LevelSelectionLogarithmic.TowerGeometricLowerBound used to demand c · r^k ≤ w k for every k. At the real w_std that is false, and not marginally: w_std(k) = 0 for k < 3, because no diagram of fewer than three cells contains (2,1) and fDimSkew guards on containment. not_towerGeometricLowerBound_wStd_of_lt_three proves the refutation outright, for every r and c — a structural exclusion with an invariant, not a failed search, so no choice of constants could have repaired it.

    The class therefore carries a threshold k₀, and towerGeometricLowerBound_wStd inhabits it at k₀ = 3. With that instance the level-selection exclusions apply to the actual w_std rather than to an abstract w: no_linear_selection_wStd and no_superlinear_selection_wStd below are those two theorems with nothing left conditional.

    The honest positive statement is a threshold bound, and wStd_geometric_from_three supplies one: (1/30)·(√2)^k ≤ w_std(k) for k ≥ 3, which is the class's lower_bound field with r = √2 > 1 and c = 1/30 > 0 on that tail. k ≥ 3 is not an artifact — it is exactly where w_std stops vanishing, so the bound covers the whole range on which any bound is possible. Everything downstream (no_linear_selection, no_superlinear_selection) already works on a tail — they pick an A from an atTop filter — so the threshold class serves them unchanged.

    A correction to my own first attempt, kept because the reasoning is the point. The first version of this file proved the bound only from k ≥ 9, and its header said the threshold was "an artifact of the crude step 4^k ≤ k!" which could be lowered only by computing the six values w_std(3) … w_std(8) — "a finite computation this file does not do". That was wrong about the remedy. No value of w_std is needed: the threshold is set by the constant, and weakening c from 1/9 to 1/30 moves the integer step from 4^k ≤ k! (first true at k = 9) to 9·4^k ≤ 100·k! (first true at k = 3, and tight there: 576 ≤ 600). The optimum over k ≥ 3 of k!/(81·4^k) is attained at k = 3 and equals 1/864, so any c ≤ 1/√864 ≈ 0.0340 works; 1/30 is the round number under it.

    Base ring ℝ (archimedean: √2, real order) — the wall is crossed only in the last two results; everything above wStd_sq_lower is ℕ-combinatorial.
