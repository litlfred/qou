    QOU.Mass.C1KernelLevelReading — L_K is a recurrence on the residue tower, level by level #

    conj:qdifference-kernel-prolongation-symbol writes its carrier as [m+2]_q b_{m+2} = b_{m+1} + b_m with x = q^m, and m there is the body order, which prop:sw-period-residue-sum identifies with the jet degree (prop:binding-genfun-qdifference: G(x;q) = Σ_n B_n x^n in body order n). So the operator L_K = (q²x − 1)σ² − (q−1)σ − (q−1) is a second-order recurrence in the level — the relation that the level-indexed sequence of residues of the jet tower,

    r_n := (Dⁿ X)(−2) (the period of the n-th prolonged differential at the pole),

    must satisfy. D : Jⁿ → Jⁿ⁺¹ is first-order in the level, so L_K is never D itself.

    C1KernelAsShiftSum (#6582) and C1KernelDictionaryParity (#6610) read σ instead as a shift in the t-exponent of a single jet. That is the pure-shift-1 special case — for a tower X ↦ c·X(· + 1) the level index and the t-exponent lock together, r_n = cⁿ a_{n−2} (shiftOne_const_residueSeq) — not the conjecture's reading. Their theorems stand as mathematics about those t-operators; this module re-derives what the conjecture actually asks on the correct axis.

    What is proved #

    • residueSeq_zero_of_powerSeries: on a power-series seed the level-0 residue is 0, for every operator. So the residue tower can never equal a carrier with b_0 ≠ 0 (the involution-number carrier has b_0 = b_1 = 1) — the body-order index and the jet level are offset, or the recurrence is demanded only from a level on.
    • c1RecFrom_ext: a level-n₀ C1 sequence is fixed by its two values at n₀, n₀+1 (rank 2), for q not a root of unity — the conjecture's own "needs two base cases".
    • c1Rec_zero_of_init_zero: two zero initial values force the zero sequence.
    • twoOp_residueSeq_one: for the admissible two-term operator the level-1 residue is c₂(−2) · a₀ — it reads the branch value with the shift-2 weight at the residue slot.
    • derivativeLike_twoOp_c1Rec_zero: a derivative-like shift-2 term (c₂(−2) = 0) therefore has r_0 = r_1 = 0, and if its residues satisfy C1 from level 0 they are all zero. That is #6582's conclusion — the prolongation needs a non-derivative component — re-derived on the level axis, with the invariant named: the first two residues of a derivative-like tower vanish and C1 is homogeneous of order 2.
    • twoOp_c1RecFrom_two_iff: for the derivative-only two-term operator, C1 from level 2 on the residues is equivalent to the index-shifted C1 recurrence [m+4]_q s_{m+2} = s_{m+1} + s_m on the tower's t¹-coefficients s_m := (Dᵐ X)(1) (via #6498's twoOp_iterate_residue, r_{m+2} = κ s_m, κ = c₁(−2) c₂(−1) ≠ 0). So on the level axis the symbol identification is a concrete constraint on the tower, not on D's shape: which (c₁, c₂, X) make the t¹-coefficient sequence C1.

    Nothing here constructs D_q or decides the conjecture.
