    The order-zero cross term is a fixed-point count (Burnside), read as a groupoid cardinality #

    Route C, step 1, of the 2026-09-05 binding-gap survey (bean qou-8uxw). The T1 probe (interleaving_cross_term_q_adic_order_probe.py, bean qou-212w) measured that at q = 1, z = 1/2, the Markov trace on ℚS₄ is tr(w) = 2^{c(w) − 4} with c(w) the number of cycles, so the unnormalised cross term at q = 1 is 2^{c(interleaved)} − 2^{c(sequential)} = 2 − 8 = −6.

    Groupoidification (Baez–Hoffnung–Walker) reads a character of a permutation representation as a count of fixed points — the cardinality of the fixed-point set of w acting on colourings Fin 4 → Fin 2, i.e. the degroupoidified span X ← X^w → X. That is exactly 2^{c(w)}: a colouring is w-invariant iff it is constant on each cycle. This file pins the two instances by finite computation — the one place decide is the honest tool (a 16-element search, twice):

    interleaved  w = s₀ s₁ s₀ s₂ s₁   — a 4-cycle — fixes  2 colourings
sequential   w = s₀² s₁² s₂ = s₂  — a transposition — fixes 8 colourings

    so the q = 1 cross term is 2 − 8 = −6 fixed colourings, matching [2]_q⁴·Δ |_{q=1} = −6.

    The q-deformation of this count is the μ-weighted quantum trace on V^{⊗4} (the 16-dim spin-½ route of markov_trace_n4_interleaved_cross_term_probe.py), which degenerates to the ordinary trace of the permutation matrix — the fixed-point count — at q = 1. That degeneration is checked exactly in the probe; here only the classical counts are formalised.
