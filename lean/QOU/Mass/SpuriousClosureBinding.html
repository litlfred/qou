    ∑ i ∈ s, ArchimedeanTraceBridge.freeEnergy (ClosureNormalisationDefect.closureNorm δ (k i) (t i)) - ArchimedeanTraceBridge.freeEnergy (ClosureNormalisationDefect.closureNorm δ (∑ i ∈ s, k i + m) (∏ i ∈ s, t i)) = ↑m * Real.log δ

    A non-interacting assembly registers binding m · log δ. The left-hand side is the mass-deficit binding — sum over isolated components minus the assembled value — for an assembly whose only difference from its parts is the closure normalisation. It is not zero.

    The artefact always has the sign of binding. For δ > 1 and at least one joining, the spurious term is strictly positive — it can never present as anti-binding, so a sign check cannot detect it.

    theorem QOU.Mass.SpuriousClosureBinding.spuriousPerNucleon_lt_log {δ : ℝ} (hδ : 1 < δ) (m : ℕ) :
    ↑m * Real.log δ / (↑m + 1) < Real.log δ

    source
    theorem QOU.Mass.SpuriousClosureBinding.spuriousPerNucleon_mono {δ : ℝ} (hδ : 1 < δ) (m : ℕ) :
    ↑m * Real.log δ / (↑m + 1) ≤ (↑m + 1) * Real.log δ / (↑m + 1 + 1)

    It does not vanish in the large-assembly limit — it saturates. The per-component artefact is monotone increasing in the component count, so it approaches the constant log δ from below rather than washing out. A constant per-nucleon offset is exactly the shape of a plateau, which is why this is worth stating rather than dismissing as small.

    The artefact is removable — and the standard normalisation is exactly what removes it #

    QOU.MathlibExt.MarkovMoves.normFactor is c^{writhe} · d^{level}. The writhe slot c is what makes the invariant survive stabilisation (normFactor_stab); the level slot d is what absorbs the closure normalisation, since closureNorm δ k t = t / δ^k is precisely a factor δ^{-level}. Choosing d = δ cancels it exactly, and the spurious binding above drops to zero.

    That is worth stating for two reasons. It explains why a Jones-style normalisation carries a level factor at all — it is not decoration, it is the closure bookkeeping — and it shows the artefact is a convention defect rather than an obstruction: it is removable, by a normalisation the corpus already has. What it does NOT say is that any particular corpus computation makes that choice; the artefact is present in any binding read off closureNorm without the δ^{level} factor restored.

    theorem QOU.Mass.SpuriousClosureBinding.spuriousBinding_absorbed_eq_zero {ι : Type u_1} {δ : ℝ} (hδ : δ ≠ 0) (s : Finset ι) (k : ι → ℕ) {t : ι → ℝ} (ht : ∀ i ∈ s, 0 < t i) (m : ℕ) :
    ∑ i ∈ s, ArchimedeanTraceBridge.freeEnergy (δ ^ k i * ClosureNormalisationDefect.closureNorm δ (k i) (t i)) - ArchimedeanTraceBridge.freeEnergy (δ ^ (∑ i ∈ s, k i + m) * ClosureNormalisationDefect.closureNorm δ (∑ i ∈ s, k i + m) (∏ i ∈ s, t i)) = 0

    With the level factor restored, the spurious binding is exactly zero. The same non-interacting assembly that registered m · log δ in spuriousBinding_eq registers nothing once the δ^{level} normalisation is applied. So the artefact is a defect of the unnormalised convention, not of the physics — and the fix is the normalisation the framework already uses for the writhe.
