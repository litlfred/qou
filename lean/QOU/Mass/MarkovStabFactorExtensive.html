    The Markov/Jones stabilisation factor is EXTENSIVE (linear in strand count) #

    L2-closure attack option A1 (docs/audits/2026-08-07-l2-closure-attack-options-non-em-terms.md §3), formalised at the level at which it is actually algebraic — and not one step further.

    The raw Ocneanu/Markov trace on the braid group B_n becomes a link invariant only after multiplying by the Jones/HOMFLY stabilisation factor N(q)^{n-1} — the power of the loop value N(q) that the Markov moves force so that a stabilisation move (adding a strand closed up with a single crossing) does not change the invariant. That factor is exactly what makes the invariant intensive: independent of how many strands the braid happens to be written on.

    Its logarithm is therefore (n-1)·log N(q) — linear in the strand count n, i.e. extensive. This file proves the ring-level content of that statement: the factor accrues exactly one constant factor of N(q) per added strand (markovStabFactor_succ), and merging an m-strand with an n-strand system multiplies the two factors and one extra N(q) (markovStabFactor_merge) — the signature of a volume-like (extensive) accumulation, in contrast to an intensive isotopy invariant whose per-strand ratio is 1 (markovStabFactor_not_intensive).

    SCOPE — this is the STRUCTURE only; the magnitude is deliberately left open. Whether the coefficient log N(q) (times the electron scale) matches the nuclear volume term a_V is a prediction, free to fail — and at the Jones specialisation N = 2 the audit measures it 5.4× short (§3 caveat). Nothing here identifies strand count with mass number, wires a value, or fits: it proves only that the discarded normalisation is extensive, which is precisely the object both proved constraints — the intensive/extensive split and the pairwise cap ρ_A ≤ C(A,2) — say is the missing (non-2-body, volume) term. Sorry-free.

    def QOU.Mass.MarkovStabFactor.markovStabFactor {R : Type u_1} [CommRing R] (Nq : R) (n : ℕ) :
    R

    The Jones/HOMFLY stabilisation factor on n strands: the power N(q)^{n-1} of the loop value N(q) that the Markov moves force in order to turn the raw Ocneanu trace into a link invariant. Parameterised by the loop value Nq alone — the extensivity structure below is independent of its exact form (-(q^{1/2}+q^{-1/2}), [N]_q, …).

      theorem QOU.Mass.MarkovStabFactor.markovStabFactor_succ {R : Type u_1} [CommRing R] (Nq : R) {n : ℕ} (hn : 1 ≤ n) :
      markovStabFactor Nq (n + 1) = markovStabFactor Nq n * Nq

      One constant factor of N(q) per added strand. For n ≥ 1, stab(n+1) = stab(n)·N(q). The per-strand ratio is the constant N(q), independent of n — the defining property of an extensive accumulation (an intensive isotopy invariant would have ratio 1).

      theorem QOU.Mass.MarkovStabFactor.markovStabFactor_merge {R : Type u_1} [CommRing R] (Nq : R) {m n : ℕ} (hm : 1 ≤ m) (hn : 1 ≤ n) :
      markovStabFactor Nq m * markovStabFactor Nq n * Nq = markovStabFactor Nq (m + n)

      Merge law (extensivity). Combining an m-strand with an n-strand system multiplies their stabilisation factors and one extra N(q): stab(m)·stab(n)·N(q) = stab(m+n). Equivalently the exponents satisfy (m-1)+(n-1)+1 = (m+n)-1, so log stab accumulates +log N(q) per merge — the volume-like (extensive) growth that a link-invariant normalisation is designed to cancel.

      theorem QOU.Mass.MarkovStabFactor.markovStabFactor_not_intensive {R : Type u_1} [Field R] (Nq : R) (hNq1 : Nq ≠ 1) (hNq0 : Nq ≠ 0) {n : ℕ} (hn : 1 ≤ n) :
      markovStabFactor Nq (n + 1) ≠ markovStabFactor Nq n

      Extensive, not intensive. For a nontrivial loop value N(q) ≠ 1 the factor genuinely depends on strand count: stab(n+1) ≠ stab(n) (n ≥ 1). An intensive isotopy invariant is by definition n-independent; the stabilisation factor is not, so normalising it away removes exactly this n-dependent (extensive) piece — the term the corpus has been hunting.

      theorem QOU.Mass.MarkovStabFactor.markovStabFactor_exponent_affine {A : ℕ} (hA : 1 ≤ A) :
      A + 1 - 1 - (A - 1) = 1

      Closed form of the accumulated log-exponent. Over A strands the stabilisation exponent is A - 1, an affine function of A with unit slope: exponent(A+1) - exponent(A) = 1 for A ≥ 1. This is the arithmetic core of "extensive" — a constant nonzero increment per strand, versus the 0 increment of an intensive invariant.

      theorem QOU.Mass.MarkovStabFactor.markovStabFactor_merge_parts {R : Type u_1} [CommRing R] (Nq : R) (ns : List ℕ) :
      ns ≠ [] → (∀ n ∈ ns, 1 ≤ n) → markovStabFactor Nq ns.sum = (List.map (markovStabFactor Nq) ns).prod * Nq ^ (ns.length - 1)

      Binding accrues N(q)^{A-1} of the discarded normalisation — extensive in the constituent count A. Writing an A-constituent system as the strand-merge of A parts with strand counts ns (each ≥ 1), the total stabilisation factor is the product of the parts' factors times N(q)^{|ns|-1}:

      stab(Σ nᵢ) = (∏ stab nᵢ) · N(q)^{A-1}, A = |ns|.

      So the normalisation that does not cancel in a binding difference (bound system minus its free constituents) is exactly N(q)^{A-1} — extensive in the constituent count A, independent of the individual strand counts. This is the precise sense in which the discarded Markov normalisation is the volume term ∝ A: it is the residue of A-1 strand-merges, one factor of N(q) each (markovStabFactor_merge). Magnitude still open: whether (A-1)·log N(q) (times the electron scale) equals a_V·(A-1) is the prediction, not proved here — the audit measures the N = 2 reading 5.4× short.
