    QOU.Mass.BindingRecurrenceSpectral — the depth-2 binding kernel is extensive #

    The fibre q-difference kernel for the binding generating function is depth-2, R(q,x) = x² − τ·x + 1 with det = 1 (constant term 1), and τ is fixed without fit by the selection-rule anchors a_D^(n) = lw(n−1) (binding_selection_rule_tau_closure.py, PR #2612); τ(q₀) = 2.6424.

    The body-order recurrence a_{n+2} = τ·a_{n+1} − a_n (QOU.Mass.BindingQDifferenceRecurrence, depth 2, kernel [−1, τ]) has characteristic roots λ_± = (τ ± √(τ²−4))/2. This file proves the three structural facts that make the kernel extensive (its solutions grow), which is exactly the property the saturating |χ| joint trace lacks (productModel_3body_nonpos; PR #2703: B_joint is A-independent, λ_eff ≈ 1):

    • lambdaPlus_isRoot — λ₊ solves x² − τx + 1 = 0;
    • lambda_product_eq_one — λ₊ · λ₋ = 1 (the det = 1 / reciprocal-roots fact);
    • lambdaPlus_gt_one — for τ > 2, the dominant root λ₊ > 1 (extensive growth), whence λ₋ = 1/λ₊ < 1.

    The τ > 2 hypothesis is discharged for every substrate 0 < q (no fit, no geometric input) in QOU.Mass.BindingTauAnchorClosure: the selection-rule trace τ = (a_D^(2)+a_D^(4))/a_D^(3) = 3(3[2]_q²+2)/(4([2]_q+2)) satisfies 0 < q ⇒ 2 < τ (tauAnchor_gt_two, sum-of-squares), and binding_extensive_at_substrate composes it with lambdaPlus_gt_one below to give λ₊ > 1 for the whole substrate family.

    So τ > 2 ⇒ λ₊ > 1: the kernel encodes the extensive (A-scaling) binding the saturating multiplicative trace (sitting at the degenerate τ = 2, λ = 1 no-growth boundary) cannot source. τ(q₀) = 2.6424 > 2 satisfies the hypothesis.

    Scope (PR #2752). These are unconditional facts about the roots of x² − τx + 1; read as a claim about binding they are a conditional — IF the binding generating function had this fixed-τ depth-2 kernel, THEN it is extensive. The physical body-order coefficients a_D^(n) = lw(n−1) in fact grow super-geometrically (#2708; ratios → 2.76, past λ₊), so λ₊ > 1 witnesses that the seed kernel is extensive — correct but weaker than "the binding grows at rate λ₊". The qualitative "extensive, not saturating" conclusion is thereby reinforced, not weakened. See docs/audits/2026-06-25-spectral-bridge-tautology-recurrence-vs-lw.md.

    LaTeX label: prop:binding-recurrence-extensive (interprets prop:binding-genfun-qdifference).
