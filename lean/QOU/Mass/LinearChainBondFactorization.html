    def QOU.Mass.LinearChainBond.bondFactor {M : Type u_1} (Z : ℕ) (fpp fpn fnn : M) (i : ℕ) :
    M

    The factor carried by 0-indexed bond i (joining nucleons i+1 and i+2 in the p^Z · n^N order): pp while both endpoints are protons (i + 2 ≤ Z), pn at the single interface (i + 1 = Z), nn after.

        theorem QOU.Mass.LinearChainBond.chainRatio_succ_neutron {M : Type u_1} [CommMonoid M] (Z N : ℕ) (hZ : 1 ≤ Z) (hN : 1 ≤ N) (fpp fpn fnn : M) :
        chainRatio Z (N + 1) fpp fpn fnn = chainRatio Z N fpp fpn fnn * fnn

        Per-neutron multiplicativity (the bean-2o66 lemma). For Z, N ≥ 1, adding one neutron appends exactly one nn bond: the trace ratio is multiplied by f_nn, so it is exactly geometric in N — and the multiplier does not mention Z.

        chainRatio Z 1 fpp fpn fnn = fpp ^ (Z - 1) * fpn

        Base of the tower: one neutron. The Z bonds are Z − 1 pp's and the single pn interface: ratio(Z, 1) = f_pp^(Z−1) · f_pn.

        theorem QOU.Mass.LinearChainBond.chainRatio_closed_form {M : Type u_1} [CommMonoid M] (Z N : ℕ) (hZ : 1 ≤ Z) (hN : 1 ≤ N) (fpp fpn fnn : M) :
        chainRatio Z N fpp fpn fnn = fpp ^ (Z - 1) * fpn * fnn ^ (N - 1)

        Closed form (the audit's exact additive chain, multiplicatively): ratio(Z, N) = f_pp^(Z−1) · f_pn · f_nn^(N−1) for Z, N ≥ 1.

        theorem QOU.Mass.LinearChainBond.chainRatio_neutron_slope_indep {M : Type u_1} [CommMonoid M] (Z Z' N : ℕ) (hZ : 1 ≤ Z) (hZ' : 1 ≤ Z') (hN : 1 ≤ N) (fpp fpn fnn : M) :
        chainRatio Z (N + 1) fpp fpn fnn * chainRatio Z' N fpp fpn fnn = chainRatio Z' (N + 1) fpp fpn fnn * chainRatio Z N fpp fpn fnn

        Z-independence of the per-neutron multiplier (division-free cross-multiplied form): the step ratio(·, N) → ratio(·, N+1) is the same for every proton count.

        Archimedean corollary — the log-binding is affine in N #

        At the substrate anchor the per-bond factors are positive reals and B_sym = α · ln(ratio); the per-neutron log increment is ln f_nn = l(q₀) (≈ 1.23698, i.e. b_nn = α·l ≈ 5.178 MeV), independent of Z.
