        theorem QOU.Mass.FlavourSplitNormalisation.tPN_mean_normalised {R : Type u_1} [Field R] [CharZero R] (mp mn : R) (h : mp + mn ≠ 0) :
        1 / 2 - deltaMean mp mn / 4 = mp / (mp + mn)

        The production pn weight is the proton's mass fraction — and the 1/4 is what the mean-normalisation costs.

        t_pn = 1/2 − δ/4 = m_p/(m_p+m_n) identically, for δ normalised by the mean. This is BondLetterIdentification.tPN_eq_proton_mass_fraction restated with the normalisation made explicit, which is the point: the 4 is 2 × 2, one factor from M_N being a mean and one from Δm being a full difference.

        theorem QOU.Mass.FlavourSplitNormalisation.tPN_sum_normalised {R : Type u_1} [Field R] [CharZero R] (mp mn : R) (h : mp + mn ≠ 0) :
        1 / 2 - deltaSum mp mn / 2 = mp / (mp + mn)

        Under sum-normalisation the coefficient is 1/2, not 1/4.

        The same physical weight — the proton's mass fraction — reads 1/2 − δ/2 when δ is normalised by m_p + m_n. So the numeral is carried by the convention, not by the physics.

        source
        theorem QOU.Mass.FlavourSplitNormalisation.quarter_is_wrong_under_sum_normalisation {R : Type u_1} [Field R] [CharZero R] (mp mn : R) (h : mp + mn ≠ 0) :
        1 / 2 - deltaSum mp mn / 4 - mp / (mp + mn) = (mn - mp) / (4 * (mp + mn))

        And 1/4 is positively WRONG under sum-normalisation, by a residual that vanishes only when the two masses agree.

        This is what makes the two theorems above a statement rather than a re-labelling: the coefficient is not free to be either, it is determined by which mass normalises δ, and picking the wrong pairing is detectable.

        theorem QOU.Mass.FlavourSplitNormalisation.wPP_mean_normalised {R : Type u_1} [Field R] [CharZero R] (mp mn : R) (h : mp + mn ≠ 0) :
        1 / 2 + deltaMean mp mn / 4 = mn / (mp + mn)

        And the weight on the pp letter is the NEUTRON's mass fraction.

        pn_interface_bar_structure_probe fact 3 writes the canonical interface as f_pn = w_p·f_pp + w_n·f_nn with w_p = 1/2 + δ/4. Together with tPN_mean_normalised (w_n = 1/2 − δ/4 = m_p/(m_p+m_n)) this says each like-pair letter is carried by the mass fraction of the other nucleon:

        σ_pn = (m_n·σ + m_p·σ⁻¹)/(m_p + m_n) .

        An identity, not a derivation — see the docstring.

        noncomputable def QOU.Mass.FlavourSplitNormalisation.directInterp {R : Type u_1} [Field R] (ma mb ta tb : R) :

            theorem QOU.Mass.FlavourSplitNormalisation.crossInterp_like_pair {R : Type u_1} [Field R] [CharZero R] (m t : R) (hm : m ≠ 0) :
            crossInterp m m t t = t

            Both interpolations fix a like pair, for any masses and any endpoint value — because a like pair averages a letter with itself. This is the theorem form of pn_interface_bar_structure_probe's "a like-flavour bond has no mean to tilt", and it is what retires the "mass fraction fails at the like pairs" objection recorded in an earlier version of this file's docstring: the three letters are one rule, not two.

            theorem QOU.Mass.FlavourSplitNormalisation.normalisations_distinguishable {R : Type u_1} [Field R] [CharZero R] (mp mn : R) (h : mp + mn ≠ 0) (hne : mn ≠ mp) :
