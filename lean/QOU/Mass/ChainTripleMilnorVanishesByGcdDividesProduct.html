    structure QOU.Mass.ChainTripleMilnorVanishesByGcdDividesProduct.ChainTriple :
    Type

    A chain triple on a monotone closure: a hub linked to two ends x, y that are unlinked from each other, together with the degree-2 Magnus coefficient of the hub's longitude.

    eps_eq is the measured structural input and the only place monotonicity enters: one run per generator puts the two far meridians in contiguous, non-interleaved blocks of λ_hub, so the coefficient is a product of block sums. Verified on 596/596 monotone chain triples; it fails off monotone.

    • u : ℤ

      lk(hub, x) — nonzero by the chain hypothesis, though nothing below needs that

    • v : ℤ

      lk(hub, y)

    • eps : ℤ

      the degree-2 Magnus coefficient ε_{x,y}(λ_hub)

    • eps_eq : self.eps = self.u * self.v

      MEASURED (596/596 monotone): the far meridians are non-interleaved, so the coefficient is the product of the two linking numbers

        theorem QOU.Mass.ChainTripleMilnorVanishesByGcdDividesProduct.chain_mubar_vanishes (C : ChainTriple) :
        delta C ∣ C.eps

        The result, and it is the whole file. μ̄ is defined modulo Δ, and Δ divides the chain triple's coefficient — so μ̄ = 0 there.

        The proof is gcd u v ∣ u ∣ u * v. It is unconditional in u and v: no positivity, no primality, no bound on the linking numbers. All the content sits in eps_eq, which is where monotonicity was used.

        theorem QOU.Mass.ChainTripleMilnorVanishesByGcdDividesProduct.both_orderings_vanish (C : ChainTriple) (epsRev : ℤ) (hrev : epsRev = 0) :
        delta C ∣ C.eps ∧ delta C ∣ epsRev

        The reverse ordering ε_{y,x}(λ_hub) is measured to be 0 (596/596), and Δ divides that too — trivially.

        Stated because the raw coefficient is order-DEPENDENT (u·v one way, 0 the other), which is alarming until one notices that this is exactly what the mod-Δ indeterminacy absorbs: the invariant is well defined and zero under both orderings, so nothing about the vanishing depends on a convention.
