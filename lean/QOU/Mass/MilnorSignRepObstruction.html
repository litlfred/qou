        def QOU.Mass.MilnorSignRepObstruction.pairAct {R : Type u_1} (g : Equiv.Perm (Fin 3)) (w : Fin 3 → R) :
        Fin 3 → R

        The S₃ action on pair-channel functions. Channels (unordered pairs {i,j} ⊂ Fin 3) are indexed by the omitted component k; the action of a relabeling g sends the function w to w ∘ g⁻¹. As a representation this is the permutation module on 3 points = trivial ⊕ standard.

            The Schur obstruction (finding D2) #

            source
            theorem QOU.Mass.MilnorSignRepObstruction.sign_equivariant_pairVector_eq_zero {R : Type u_1} [CommRing R] (h2 : ∀ (x : R), x + x = 0 → x = 0) (v : Fin 3 → R) (hequiv : ∀ (g : Equiv.Perm (Fin 3)) (k : Fin 3), signR g * v k = v (g⁻¹ k)) :
            v = 0

            Core computation: a pair-channel vector v that transforms in the SIGN representation — sgn(g)·v k = v (g⁻¹ k) for all g — vanishes, provided R has no 2-torsion. Proof: each channel k is fixed by the transposition of the two other indices, which has sign −1, so −v k = v k. This is the "sign rep does not occur in trivial ⊕ standard" Schur statement, by direct computation.

Any S₃-equivariant R-linear map from the sign representation (the line spanned by μ̄(123)) to the pair-channel representation (charge bilinears; trivial ⊕ standard) is ZERO — the concrete Schur-lemma obstruction, over any commutative ring without 2-torsion (weakest hypothesis stated explicitly).

            The D2 obstruction, audit-shaped corollary.
