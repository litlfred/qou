          theorem QOU.Mass.SU4CasimirIsAffineInPairCount.casimirX8_eq {R : Type u_1} [CommRing R] (n : R) :
          casimirX8 n = 15 * n - 5 * pairCountX2 n

          The Casimir is affine in the pair count. 8·C₂ = 15n − 5·n(n−1), i.e. C₂([1^n]) = (15/8)·n − (5/4)·C(n,2). Every apparent dependence of the Casimir on the many-body structure is carried by n and the pair count alone.

          theorem QOU.Mass.SU4CasimirIsAffineInPairCount.pairSum_eq {R : Type u_1} [CommRing R] (n : R) :
          pairSumX16 n = -5 * pairCountX2 n

          The two-body sum is exactly proportional to the pair count. 16·S = −5·n(n−1), i.e. S(n) = −(5/8)·C(n,2) for every n.

          This is the load-bearing statement: a two-body SU(4)-invariant interaction summed over the fully antisymmetric A-body state contributes a constant per pair, so it gives a constant coordination weight and b₃ = 0. The SU(4) Casimir cannot produce a three-body cumulant.
