      c1FormalDeg n = n ^ 2

      Gaussian growth: deg_q(cₙ) = n². The C1 formal solution at ∞ has coefficients of q-degree n², i.e. growth q^{n²} — the divergent (q-Gevrey) behaviour that forces Stokes summation. Under QOU.Mathlib.QGevreyOrder.IsQGevreyOrder that is order 2, equivalently RSZ level ½; see the level/order note in the module docstring. Proof: the sum of the first n odd numbers is n².

      theorem QOU.Mass.C1FormalSolutionGrowth.c1FormalDeg_step (n : ℕ) :
      c1FormalDeg (n + 1) = c1FormalDeg n + (2 * n + 1)

      The growth is strictly super-linear for n ≥ 2 (n² > c·n eventually) — a divergent formal series, confirming the ∞ singularity is irregular (not Fuchsian). Stated as the per-step increment d_{n+1} − d_n = 2n+1, which is unbounded.

      The ratio degree, derived #

      c1FormalDeg_eq_sq above assumes deg_q(c_{m+1}/c_m) = 2m+1. That assumption is discharged here: reading the multiplier as a polynomial in q over ℤ makes the degree a theorem, and natDegree_mul chains it to n² directly from the recursion — so the n² no longer rests on the docstring.

      The m = 0 case is the only wrinkle: there (q−1)qᵐ and (q−1)q^{2m} coincide, so the leading coefficient is 2 rather than 1. The degree is still 2m+1 = 1, but the argument has to branch.

          The recursion, derived from L1 #

          Added 2026-08-08 (bean qou-slpd item 4, remainder). Everything above took the recursion c_{m+1} = c_m(1 + (q−1)qᵐ + (q−1)q^{2m}) from c3-w2-inf-formal-solution.witness.json. It is now derived from the operator.

          Applying L1 = (q²x − 1)σ² − (q−1)σ − (q−1) (with σ : x ↦ qx, so σ(x^{-k}) = q^{-k}x^{-k}) to the ∞-side ansatz f = ∑_{k≥0} c_k x^{-k}, the coefficient of x^{-n} collects exactly four terms — one per summand of L1, with an index shift k = n+1 on the q²x·σ² piece:

          q²·q^{-2(n+1)}·c_{n+1}   −   q^{-2n}·c_n   −   (q−1)q^{-n}·c_n   −   (q−1)·c_n

          That collection is l1CoeffAt. That it really is the coefficient is checked symbolically, with symbolic c_k, in computations/qbeta/c3_w2_c1_inf_recursion_derivation.py (4/4) — so the term-by-term reading is machine-verified rather than eyeballed. l1CoeffAt_eq_zero_iff below then proves, in general, that it vanishes iff the recursion holds.

          The ansatz does not satisfy L1 f = 0 outright, and that is recorded rather than dropped. Multiplying by x shifts the k = 0 term of σ²f up to x^{+1}, leaving l1Obstruction = q²·c₀, nonzero for the corpus's c₀ = 1 (every power above x^{+1} does vanish — checked in the script). So the honest statement is: the recursion is equivalent to L1 f having no x^{-n} term for any n ≥ 0, with one leftover at x^{+1}. That leftover is what a nonzero Newton slope forces — a pure power series in 1/x cannot solve an irregular operator — and it does not touch the growth chain, which only ever used the recursion.
