    QOU.Mass.FibreMonodromyOrderTwo — the fibre root of unity is -1, and C1 dies there #

    Wall W1 (qou-d8de) asks for a q-difference prolongation D_q built from the colour spectral curve Σ : P(X,z) = 0. Its route 2 reads, verbatim:

    Root-of-unity fibre monodromy. The fibre singularity is a root of unity; a q-difference connection may arise naturally from its local monodromy.

    Route 1 (a q-shift on the base, z ↦ q²z) is closed in all three charts it could have lived in — the base coordinate (QOU.Mass.ColorCubicIrreducible, PR #6695), the ramified local coordinate (QOU.Mass.IrreducibleCubicNoQuadraticRoot, PR #6738), and Σ itself (QOU.Mass.DilationBranchLocusRigidity, PR #6769). So route 2 is the live one, and this file asks the question that comes before any construction: which root of unity can that datum actually supply?

    The two halves #

    (1) No total branch point — colorCubic_no_triple_root. Over any field of characteristic zero the colour cubic X³ + (z+1)X² + (z²+z+1)X + (z³+z²+z+1) has no triple root, for any z. Matching against (X − r)³ gives three coefficient equations; eliminating r from the first two forces 2z² + z + 2 = 0, and from the first and third 26z³ + 24z² + 24z + 26 = 0, and those two have no common solution (they reduce to 15z = 30 and then 12 = 0).

    Geometrically: a branch point of the 3-sheeted cover is where sheets collide, and "three sheets collide" is exactly "the fibre cubic has a triple root". Since that never happens, every branch point is simple — precisely two sheets meet — so the local monodromy is a transposition, of order exactly 2. The only root of unity the fibre datum supplies is therefore -1: never a primitive cube root, never anything higher.

    The covering-space step is stated here in prose and is NOT formalised — Mathlib has no monodromy of a branched cover of Riemann surfaces in usable form. What is formalised is the algebraic fact it rests on (no triple root), exactly as DilationBranchLocusRigidity formalises the coefficient identity under its own unformalised "σ permutes the branch locus" step.

    (2) C1 is unavailable at q = -1 — c1_hypothesis_fails_at_neg_one. The quantum integers collapse: qint (-1) (2k) = 0 and qint (-1) (2k+1) = 1. The C1 carrier QDifferenceConfluentObstruction.qlift_normalized_kernel_exists carries the standing hypothesis ∀ k, 1 ≤ k → qint q k ≠ 0, and qint (-1) 2 = 0 falsifies it. So the carrier theorem is not merely degenerate at q = -1; it does not apply at all.

    c1_undetermined_of_qint_eq_zero says what goes wrong independently of that hypothesis: when the leading coefficient vanishes, [m+2]_q · b_{m+2} = b_{m+1} + b_m holds for one value of b_{m+2} iff it holds for every value, so it is a constraint on b_{m+1}, b_m rather than a recurrence determining b_{m+2}.

    Scope (fixed before the argument was run) #

    Scope (b), with the invariants cited above, applies to exactly one identification: q = the eigenvalue of the local fibre monodromy. Every looser reading of route 2 stays open at scope (a) at most — in particular a q-difference structure that uses the monodromy representation without setting q to an eigenvalue, one built at z = ∞, or one from the global S₃ rather than a local generator. Route 3 (Ramis–Sauloy–Zhang / Sauloy) is untouched.

    Nothing here constructs D_q; this removes a reading of a route. No fit, nothing wired.

    Ground ring: [Field K] [CharZero K] (§7c). Characteristic zero is used only to know 15 ≠ 0 and 12 ≠ 0; nothing archimedean appears.

    Part 1 — the colour cubic never has a triple root #

    source
    theorem QOU.Mass.FibreMonodromyOrderTwo.colorCubic_no_triple_root {K : Type u_1} [Field K] [CharZero K] (z r : K) (hc2 : z + 1 = -3 * r) (hc1 : z ^ 2 + z + 1 = 3 * r ^ 2) (hc0 : z ^ 3 + z ^ 2 + z + 1 = -r ^ 3) :
    False

    No total branch point. If the colour cubic X³ + (z+1)X² + (z²+z+1)X + (z³+z²+z+1) equalled (X − r)³ — i.e. if all three sheets collided over z — its coefficients would satisfy the three hypotheses below. They are inconsistent, for every z and every r.

    Consequently every branch point of the 3-sheeted cover is simple: exactly two sheets meet, so the local monodromy is a transposition of order 2.

    ¬∀ (k : ℕ), 1 ≤ k → QDifferenceConfluentObstruction.qint (-1) k ≠ 0

    The C1 carrier's standing hypothesis is FALSE at q = -1.

    QDifferenceConfluentObstruction.qlift_normalized_kernel_exists — the proved binding q-difference carrier [n+2]_q·b_{n+2} = b_{n+1} + b_n — assumes ∀ k, 1 ≤ k → qint q k ≠ 0. At the value route 2's fibre monodromy supplies, that assumption does not hold, so the carrier theorem does not apply.

    theorem QOU.Mass.FibreMonodromyOrderTwo.c1_undetermined_of_qint_eq_zero {K : Type u_1} [Field K] (q : K) (n : ℕ) (hz : QDifferenceConfluentObstruction.qint q (n + 2) = 0) (rhs c c' : K) :
    QDifferenceConfluentObstruction.qint q (n + 2) * c = rhs ↔ QDifferenceConfluentObstruction.qint q (n + 2) * c' = rhs

    A vanishing leading coefficient makes C1 a constraint, not a recurrence.

    If [n+2]_q = 0 then the C1 equation holds for one candidate value of b_{n+2} iff it holds for every candidate value — so it carries no information about b_{n+2}. This is independent of the carrier theorem's hypothesis; it is what that hypothesis exists to prevent.
