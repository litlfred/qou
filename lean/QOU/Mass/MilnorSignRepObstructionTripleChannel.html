    theorem QOU.Mass.MilnorSignRepObstructionTripleChannel.sign_equivariant_scalar_eq_zero {R : Type u_1} [CommRing R] (h2 : ∀ (x : R), x + x = 0 → x = 0) (c : R) (hequiv : ∀ (g : Equiv.Perm (Fin 3)), MilnorSignRepObstruction.signR g * c = c) :
    c = 0

    Core computation. A ring element c that transforms in the SIGN representation while its target carries the trivial action — signR g * c = c for every g — vanishes, provided R has no 2-torsion.

    Proof: a transposition has signR = -1, so -c = c, hence c + c = 0.

    theorem QOU.Mass.MilnorSignRepObstructionTripleChannel.muBar_cannot_carry_symmetric_channel {R : Type u_1} [CommRing R] (h2 : ∀ (x : R), x + x = 0 → x = 0) (T : R →ₗ[R] R) (hT : ∀ (g : Equiv.Perm (Fin 3)) (x : R), T (MilnorSignRepObstruction.signR g * x) = T x) (μbar channel : R) (hchannel : T μbar = channel) (hne : channel ≠ 0) :
    False

    A nonzero symmetric three-body channel cannot be linear in μ̄.

    If T is an S₃-equivariant linear functional of the antisymmetric invariant whose value on μ̄ is the required channel, and that channel is nonzero, contradiction.

    The corpus's measured cumulants require tripleMutual = -(b₃ + 3b₂) = -8.09991876 MeV ≠ 0 (probe b3_brunnian_count_channel_probe.py), so the hypothesis hne is discharged by data and the conclusion bites.

    The "distinguishable components" escape does NOT exist for a nucleon triple #

    The scope note above named one live escape: the obstruction assumes full S₃-equivariance, while a physical triple has distinguishable components (a triton is (p,n,n), ³He is (p,p,n)), so the symmetry available is smaller than S₃.

    That escape is empty, and the reason is pigeonhole. Inspect the proof of sign_equivariant_scalar_eq_zero: it invokes hequiv at exactly one transposition. Full S₃-equivariance was never needed — a single transposition under which the channel is invariant and μ̄ flips is enough. And a nucleon triple always has one, because there are only two species: any three nucleons include two of the same kind.

    So the obstruction reaches every nucleon triple in every nucleus, (p,n,n), (p,p,n), (p,p,p) and (n,n,n) alike — not only a hypothetical S₃-symmetric one. In particular it closes the form qou-lq6k actually proposes: an antisymmetry-breaking charge weighting cannot work, because charge is a function of species and therefore assigns the two like nucleons the same weight, leaving the swap a symmetry of the weighted channel.

    🛑 What this does NOT close, stated because the pigeonhole argument invites over-reading. The hypothesis is hflip — there exists a swap under which μ̄ flips and the channel does not — and species is not the only label a nucleon carries. Two neutrons agree in species but may differ in spin (or any other quantum number), and two components in different states need not leave the channel invariant when exchanged. For such a triple hflip fails and nothing here applies.

    So the honest statement is: a weighting that is a function of SPECIES alone cannot break the antisymmetry; a weighting that distinguishes the two like nucleons by some further quantum number is untouched, and spin is the obvious candidate. That is a narrower and more specific open question than qou-lq6k had before, not a closed one. Nothing here proposes such a weighting — proposing one because it would fit is the anti-fit violation.

    theorem QOU.Mass.MilnorSignRepObstructionTripleChannel.linear_in_muBar_vanishes_of_identical_pair {R : Type u_1} [CommRing R] (h2 : ∀ (x : R), x + x = 0 → x = 0) (T : R →ₗ[R] R) (μbar : R) (hflip : T (-μbar) = T μbar) :
    T μbar = 0

    The obstruction needs only ONE transposition — the minimal form.

    If a channel is a linear functional T of the antisymmetric invariant, and there is a single component swap under which μ̄ flips sign while the channel does not, then the channel vanishes. No group action, no S₃, no representation theory: linearity gives T(−μ̄) = −T(μ̄), the invariance gives T(−μ̄) = T(μ̄), and the two force T(μ̄) + T(μ̄) = 0.

    hflip is the physical content: swapping two identical nucleons flips μ̄ (it is totally antisymmetric) and leaves the mutual energy of the triple unchanged (they are identical particles, so the state is the same).

    A nucleon triple's channel cannot be linear in μ̄ — the escape closed.

    Anti-vacuity #

    theorem QOU.Mass.MilnorSignRepObstructionTripleChannel.sq_functional_is_equivariant_and_nonzero :
    (∀ (g : Equiv.Perm (Fin 3)) (x : ℤ), (MilnorSignRepObstruction.signR g * x) ^ 2 = x ^ 2) ∧ ∃ (x : ℤ), x ^ 2 ≠ 0

    The linearity hypothesis is load-bearing. The QUADRATIC functional x ↦ x² is S₃-equivariant into the trivial representation — (signR g * x)² = x² — and is not identically zero. So the theorem above genuinely needs linearity, and the surviving coupling is through μ̄² (equivalently |μ̄|), matching MilnorSignRepObstruction.muBarFamily_sq_invariant.

    Stated over ℤ so that "not identically zero" is a concrete, checkable claim.
