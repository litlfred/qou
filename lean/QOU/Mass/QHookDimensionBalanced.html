                dimQ_bal q n hooks = dimQ (q ^ 2) n hooks

                Balanced ↔ Gaussian hook-dimension cancellation (exact condition). When the accumulated hook-denominator twist matches the numerator (factorial) twist — ∏_{h ∈ hooks} q^{−(h−1)} = q^{−Σ_{i<n} i} — the overall balanced twist cancels and dim_bal(λ) = dim_{q^2}(λ). The hypothesis holds exactly when Σ_{h ∈ hooks} (h−1) = Σ_{i<n} i (for a genuine partition λ ⊢ n, hooks.card = n, this is Σ h = n(n+1)/2 — true for hook / row / column shapes, false in general, e.g. λ = (2,1); see the module docstring). Given q ≠ 0, q^2 ≠ 1.
