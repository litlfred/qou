    Part 1 — the counting bound #

    MultiplicityCountingBound.abs_sum_le_card_mul supplies |Σ a| ≤ card · M over a generic linearly ordered ring: the whole multiplicity channel, for arbitrary signs. Everything in this file turns that into an archimedean statement about growth in A.

    Part 2 — the log form: the multiplicity surplus #

    source
    noncomputable def QOU.Mass.MultiplicityNotExtensive.multiplicitySurplus (T M : ℝ) :
    ℝ

    The multiplicity surplus: how much the sum's log-amplitude exceeds the log-amplitude of its own largest summand. Under the archimedean bridge (ArchimedeanTraceBridge) binding is E₀ times a log-amplitude, so this is the part of the binding that multiplicity — as opposed to any single partition's weight — could be responsible for.

      Part 3 — a √ law is not a linear law, with an explicit threshold #

      source
      theorem QOU.Mass.MultiplicityNotExtensive.sqrt_lt_linear_of_sq_lt {a c A : ℝ} (ha : 0 < a) (hc : 0 ≤ c) (hA : (c / a) ^ 2 < A) :
      c * √A < a * A

      A c√A law falls strictly below any positive linear rate once A > (c/a)². No limits: the threshold is exhibited. With c = π√2 from Hardy–Ramanujan and a the required per-nucleon rate in units of E₀, this is what makes the exclusion quantitative at every physical mass number rather than merely asymptotic.

      source
      theorem QOU.Mass.MultiplicityNotExtensive.card_ge_exp_of_linear_le_log_card {m a A : ℝ} (hm : 0 < m) (h : a * A ≤ Real.log m) :
      Real.exp (a * A) ≤ m

      The contrapositive with teeth. If the multiplicity channel is to supply a term linear in A at rate a, the number of summands must be at least exp (a·A) — exponential in the nucleon count. The partitions of 3A number exp(O(√A)), so this is not a bound that a larger search could meet; it is a bound on the index set itself.

      Part 4 — the scale-free shape statement #

      E₀ is undetermined (BindingScaleCandidates, bean qou-v8ct), so the exclusion must not turn on its value. Normalise instead: let the √ law agree with the measured binding at one mass number, and read off what it does everywhere else.

      source
      theorem QOU.Mass.MultiplicityNotExtensive.sqrt_law_shortfall (r B₁ : ℝ) (hr : 0 ≤ r) :
      B₁ * r = √r * (B₁ * √r)

      The shortfall of a √ law against saturation is exactly √(A₂/A₁), independent of the scale and of the constant. Normalise any c√A law to reproduce the binding B₁ at mass number A₁; it then predicts B₁·√(A₂/A₁) at A₂, while a saturating (constant B/A) law gives B₁·(A₂/A₁). The identity below says the second is √(A₂/A₁) times the first, exactly — an equality, so no tolerance and no fit is involved.

      source
      theorem QOU.Mass.MultiplicityNotExtensive.sqrt_law_undershoots {r B₁ : ℝ} (hr : 1 < r) (hB : 0 < B₁) :
      B₁ * √r < B₁ * r

      The shortfall is a genuine one — strict — as soon as the mass ratio exceeds one. This is the falsifiable edge of sqrt_law_shortfall: matching at A₁ forces an undershoot at every larger A₂, for every positive scale.

      theorem QOU.Mass.MultiplicityNotExtensive.sqrt_per_nucleon_antitone {c A₁ A₂ : ℝ} (hc : 0 ≤ c) (h1 : 0 < A₁) (h12 : A₁ ≤ A₂) :

      Per nucleon, a √ law decays. c√A / A = c/√A is non-increasing in A. The measured B/A is flat across the mass table — that is what nuclear saturation means — so the two have different shapes, again with no scale in the statement.

      Part 5 — the applied corollary, with Hardy–Ramanujan named #

      The growth bound on the partition function is classical and is not proved here. It is carried as an explicit hypothesis so that the conditional is visibly a conditional, per AGENTS.md §"Conditional-proved ≠ premise-established".

      source
      theorem QOU.Mass.MultiplicityNotExtensive.hardyRamanujan_gives_sqrt_law {T M m c A : ℝ} (hT : 0 < T) (hM : 0 < M) (hm : 0 < m) (h : T ≤ m * M) (hHR : Real.log m ≤ c * √A) :
      multiplicitySurplus T M ≤ c * √A

      Hardy–Ramanujan gives the √ law. If the number of summands m of the A-nucleon trace sum obeys log m ≤ c·√A — which the partition count p(3A) does, with c = π√2, by Hardy–Ramanujan — then the multiplicity surplus obeys the same bound, and hence (sqrt_lt_linear_of_sq_lt) is strictly below any positive linear rate beyond an explicit threshold.

      source
      theorem QOU.Mass.MultiplicityNotExtensive.multiplicity_not_extensive {T M m a c A : ℝ} (hT : 0 < T) (hM : 0 < M) (hm : 0 < m) (h : T ≤ m * M) (hHR : Real.log m ≤ c * √A) (ha : 0 < a) (hc : 0 ≤ c) (hA : (c / a) ^ 2 < A) :
      multiplicitySurplus T M < a * A

      The exclusion, assembled. Under a Hardy–Ramanujan-type bound on the number of summands, the multiplicity surplus is strictly less than the extensive term a·A for every A past the exhibited threshold (c/a)². So the multiplicity channel of a trace-sum binding law cannot be the extensive term — on any graph, at any scale, with any signs, for any braid word.
