    theorem QOU.Mass.QIntegerBarParity.qIntBal_bar_even {R : Type u_1} [Field R] (q : R) (n : ℕ) :
    QHookDimensionBalanced.qIntBal q⁻¹ n = QHookDimensionBalanced.qIntBal q n

    The balanced quantum integer is BAR-EVEN.

    [n]_{q⁻¹} = [n]_q — the bar involution σ : q ↦ q⁻¹ fixes it.

    Both the numerator and the denominator change sign under σ, and the two signs cancel. This is the property that makes the balanced form the one compatible with the corpus's bar-even / bar-odd channel decomposition.

    No hypothesis at all: inv_inv holds unconditionally in a field, so this is an identity of the definition, not a statement about a regular q.

    theorem QOU.Mass.QIntegerBarParity.qIntPoly_bar_covariant {R : Type u_1} [Field R] (q : R) (n : ℕ) (hq : q ≠ 0) :
    QHookDimensionBalanced.qIntPoly q⁻¹ n = q⁻¹ ^ (n - 1) * QHookDimensionBalanced.qIntPoly q n

    The geometric quantum integer is NOT bar-even — it is bar-COVARIANT, transforming with weight −(n−1):

    qIntPoly q⁻¹ n = q⁻¹^(n−1) · qIntPoly q n.

    Proof: ∑_{i<n} q^{−i} is the same sum read backwards (Finset.sum_range_reflect), and backwards it is ∑_{i<n} q^{i−(n−1)}, i.e. the forward sum scaled by q^{−(n−1)}. Only q ≠ 0 is needed — no q ≠ 1, and nothing archimedean.

    theorem QOU.Mass.QIntegerBarParity.qIntPoly_bar_even_forces_degenerate {R : Type u_1} [Field R] (q : R) (n : ℕ) (hq : q ≠ 0) (hbar : QHookDimensionBalanced.qIntPoly q⁻¹ n = QHookDimensionBalanced.qIntPoly q n) :
    (q⁻¹ ^ (n - 1) - 1) * QHookDimensionBalanced.qIntPoly q n = 0

    The separating statement, in usable contrapositive form.

    If the geometric form were bar-even at n — i.e. qIntPoly q⁻¹ n = qIntPoly q n — then the covariance factor q⁻¹^(n−1) must act trivially on it. Combined with qIntPoly_bar_covariant, bar-evenness of the geometric form forces

    `(q⁻¹^(n−1) − 1) · qIntPoly q n = 0`,

    so it holds only in the degenerate cases: n ≤ 1 (where the sum is 0 or 1), q^(n−1) = 1, or qIntPoly q n = 0. Away from those, the geometric form is genuinely not bar-even, so it cannot carry a bar-even quantity.

    theorem QOU.Mass.QIntegerBarParity.bar_distinguishes_at_two {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) :
    QHookDimensionBalanced.qIntBal q⁻¹ 2 = QHookDimensionBalanced.qIntBal q 2 ∧ QHookDimensionBalanced.qIntPoly q⁻¹ 2 = q⁻¹ * QHookDimensionBalanced.qIntPoly q 2

    The two forms are not interchangeable under bar. Concretely at n = 2: balanced is fixed by σ, geometric is scaled by q⁻¹. Recorded as the smallest witness that the distinction is real rather than formal.
