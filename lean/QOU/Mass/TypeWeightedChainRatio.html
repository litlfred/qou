          theorem QOU.Mass.TypeWeightedChainRatio.avgTriple_order_independent_iff {R : Type u_1} [Field R] [CharZero R] (wpp wpn wnn : R) :
          muTripleMiddleHeavy wpp wpn wnn = muTripleMiddleLight wpn ↔ wpp + wnn = 2 * wpn

          The isospin average is arrangement-independent exactly on the arithmetic-mean locus. Per isotope the chain does depend on which nucleon is in the middle; averaging ³H against ³He cancels that iff w_pp + w_nn = 2w_pn. Production satisfies it exactly (0, -h/2, -h).

          theorem QOU.Mass.TypeWeightedChainRatio.allPn_ratio_eq_two {R : Type u_1} [Field R] [CharZero R] {wpn : R} (hne : wpn ≠ 0) :
          muTripleMiddleLight wpn / muPair wpn = 2

          An all-pn chain gives ratio 2 for ANY pn weight, with no locus condition at all. The middle-light arrangement (n-p-n and p-n-p) has only pn bonds, so the weight cancels entirely between numerator and denominator.

          This is the sharpest form of the obstruction: on that arrangement b₃/b₂ = -1 whatever the pn interface is — colour-weighted, δ-dependent, anything.
