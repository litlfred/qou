    class QOU.Mass.LevelSelection.TowerGeometricLowerBound (w : ℕ → ℝ) (r c : ℝ) (k₀ : ℕ) :
    Prop

    The tower growth lower bound, above a threshold. A geometric lower bound c · r^k ≤ w k on the branched tower weight w = w_std, holding for k ≥ k₀, with base r, constant c and threshold k₀ carried as parameters.

    Why the threshold is not cosmetic. This class previously demanded the bound for every k, and in that form it is false at the real w_std: at k = 0 it reads c ≤ w_std 0 = 0, against c_pos. QOU.Mass.WStd.not_towerGeometricLowerBound_wStd proves that refutation for every r and c, so no choice of constants repaired it — the threshold is the fix. The vanishing is structural: no diagram of fewer than three cells contains (2,1), and fDimSkew guards on containment.

    Its intended instance is k₀ = 3 — exactly where w_std stops vanishing, so the class covers the entire range on which any lower bound is possible. See QOU.Mass.WStd.towerGeometricLowerBound_wStd.

    The measured growth is strictly stronger than geometric — successive ratios strictly increasing, 1.38 → 2.88 for k ≤ 10 (wlambda_wstd_growth_bound_probe.py), and the proved square bound k!/(81·2^k) ≤ w_std(k)² is genuinely super-exponential. The geometric form here is the weaker shadow of that, and is all the logarithmic conclusion below needs.

    • one_lt_r : 1 < r

      r > 1 — the bound is genuinely growing (the verified growth is super-exponential, with r effectively unbounded; any fixed r > 1 is a valid — weaker — lower-bound base).

    • c_pos : 0 < c

      c > 0 — positive leading constant.

    • lower_bound (k : ℕ) : k₀ ≤ k → c * r ^ k ≤ w k

      The lower bound: c · r^k ≤ w k for every jet level k ≥ k₀.

      theorem QOU.Mass.LevelSelection.level_geometric_bound (w : ℕ → ℝ) (r c : ℝ) (k₀ : ℕ) [T : TowerGeometricLowerBound w r c k₀] (M : ℝ) (kA : ℕ → ℕ) (A : ℕ) (hk : k₀ ≤ kA A) (hext : w (kA A) ≤ M * ↑A) :
      c * r ^ kA A ≤ M * ↑A

      Conditional theorem — the level's exponential is at most linear in A. Given the tower lower bound (TowerGeometricLowerBound w r c) and extensive binding w (kA A) ≤ M · A at the selected level kA A, we get

      c · r^(kA A) ≤ M · A.

      Dividing by c > 0 gives r^(kA A) ≤ (M/c)·A; since r > 1, taking log_r (monotone) then gives kA A ≤ log_r((M/c)·A) — the level grows at most logarithmically in A. A linear rule kA A = A would force c · r^A ≤ M · A (exponential ≤ linear), impossible for large A; bond-count A(A−1)/2 is worse. Both are excluded — matching the scale-free probe (k∝A R²=0.67, k∝bonds R²=0.49 vs log-type R²≈0.88). Proved outright from the class hypothesis.

      theorem QOU.Mass.LevelSelection.linear_selection_bound (w : ℕ → ℝ) (r c : ℝ) (k₀ : ℕ) [T : TowerGeometricLowerBound w r c k₀] (M : ℝ) (A : ℕ) (hk : k₀ ≤ A) (hext : w A ≤ M * ↑A) :
      c * r ^ A ≤ M * ↑A

      Linear selection is excluded. The kA A = A (linear) instance of the bound: extensivity forces c · r^A ≤ M · A for every A — the exponential-vs-linear inequality that fails for large A when r > 1 (r^A outgrows any linear M·A). So no linear level-selection rule is consistent with extensive binding; bond-count k = A(A−1)/2 is a fortiori excluded.

      theorem QOU.Mass.LevelSelection.no_linear_selection (w : ℕ → ℝ) (r c : ℝ) (k₀ : ℕ) [T : TowerGeometricLowerBound w r c k₀] (M : ℝ) (hext : ∀ (A : ℕ), 1 ≤ A → w A ≤ M * ↑A) :
      False

      Linear selection is genuinely impossible (exponential beats linear). The linear_selection_bound inequality c·r^A ≤ M·A cannot hold for all A ≥ 1: since r > 1, the geometric c·r^A eventually outgrows any linear M·A (Mathlib's isLittleO_coe_const_pow_of_one_lt: (A : ℝ) =o[atTop] r^A). So no extensive (linear-in-A) binding law is consistent with the tower lower bound — the level-selection rule cannot be linear (nor bond-count A(A−1)/2, a fortiori). This converts the file's "linear excluded" argument into an actual theorem.

      Extensivity is required only for A ≥ 1 (the physical regime); the A = 0 case is deliberately excluded — there it would collapse to a boundary artifact (w 0 ≥ c > 0 vs M·0 = 0) that does not capture the exponential-vs-linear content. The proof genuinely uses the growth lemma, not the boundary.

      theorem QOU.Mass.LevelSelection.no_superlinear_selection (w : ℕ → ℝ) (r c : ℝ) (k₀ : ℕ) [T : TowerGeometricLowerBound w r c k₀] (M : ℝ) (kA : ℕ → ℕ) (A₀ : ℕ) (hsuper : ∀ (A : ℕ), A₀ ≤ A → A ≤ kA A) (hext : ∀ (A : ℕ), A₀ ≤ A → w (kA A) ≤ M * ↑A) :
      False

      Super-linear (incl. bond-count) selection is excluded too. Generalises no_linear_selection: for any level rule kA that is eventually at least linear (A ≤ kA A for A ≥ A₀), extensive binding w (kA A) ≤ M·A on the same tail is impossible — because c·r^A ≤ c·r^{kA A} (monotonicity, r > 1) reduces it to the same geometric-beats-linear contradiction. In particular the bond-count rule kA A = A(A−1)/2 satisfies A ≤ kA A for A ≥ 3, so it is excluded (with A₀ = 3, its physical deuteron-and-up regime) — discharging the "A(A−1)/2 a fortiori excluded" claim that no_linear_selection's docstring only asserted in prose. The threshold A₀ plays the same honest role as the A ≥ 1 restriction: it is the physical domain, not a boundary artifact.
