          The Ursell three-body cumulant of a chain-additive model is -b₂, identically. B(3) - 3B(2) = 2b - 3b = -b. No choice of bond value, weighting or scale changes it — the -1 is the inversion's three pair terms meeting the chain's two bonds.

          Hence b₃/b₂ = -1 for every chain-additive model. This is what the three bond-additive channels were measuring; it is an identity, not three findings.

          So a chain-additive model can never produce a positive b₃. Asking it for one is asking the wrong object — which is the reframing, and the reason this is a question about the comparison rather than about the physics.

          3. The generalisation: NO uniform pairwise-bond model can be positive #

          The chain is one bond set. The -1 above is what that bond set gives, but the argument does not need it: for a binding that is additive over a bond set with a uniform bond value b (uniform meaning the bond value does not depend on A), only the bond counts survive into the cumulant ratio —

          b₂ = n(2)·b ,  b₃ = n(3)·b - 3·n(2)·b ,  b₃/b₂ = n(3)/n(2) - 3 .

          Two nucleons that are bound have exactly one bond, so n(2) = 1; and a simple bond set on three nucleons has at most C(3,2) = 3 of them. Hence b₃/b₂ = n(3) - 3 ≤ 0 for every such model — the chain (n(3) = 2) gives -1, all-pairs (n(3) = 3) gives exactly 0, and nothing reaches the measured +0.641.

          Scope (b), invariant named: the bond count on three nodes is capped at three while the Ursell inversion subtracts three pair terms. The escape is non-uniformity — a model whose A = 3 bonds are stronger than the deuteron bond is not covered, since then b₃/b₂ = 3w/w_d - 3 > 0 whenever w > w_d. That is the surviving direction, and it is the one to take next.
