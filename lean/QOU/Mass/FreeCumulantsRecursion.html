    Explicit order-5 and order-6 free moments #

    freeMoment5 / freeMoment6 are the non-crossing-partition polynomials ∑_{π ∈ NC(n)} ∏_{V ∈ π} κ_{|V|} for n = 5, 6, grouped by block-type (the κ-monomial). The block-type multiplicities are the number of non-crossing partitions of the given shape; they total C₅ = 42 and C₆ = 132.

        Speicher's first-block recursion at n = 5, 6 #

        Each inner factor is the gap sum h_{s,n-s} = ∑_{i₁+…+i_s = n-s} ∏_j m_{i_j} of the table in the module docstring, written in the merged free moments freeMoment₀,…,freeMoment₄ (and freeMoment5 for n = 6). Each is a ring identity — the polynomial content of the non-crossing first-block decomposition.

        Catalan bridge at orders 5 and 6 #

        At all cumulants = 1 each non-crossing partition contributes 1, so freeMomentₙ(1,1,…) = |NC(n)| = C_n. This extends FreeCumulants.freeMoment_eval_one_eq_catalanCount (n ≤ 4) to C₅ = 42 and C₆ = 132, expressed via Mathlib's Nat.centralBinom (C_n = centralBinom n / (n+1) = Nat.catalan n).
