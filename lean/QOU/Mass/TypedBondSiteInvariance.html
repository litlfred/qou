                  The mean condition is forced. On a regular graph carrying both a bond and a non-bond between distinct sites, site invariance forces L_pp + L_nn = 2·L_pn — the p–n scalar is the arithmetic mean of the like-pair scalars. Strictly weaker than L_pp = L_pn = L_nn, which is what the chain forces; the chain's extra strength comes from its irregularity.

                  theorem QOU.Mass.TypedBondSiteInvariance.complete_A2_coefficient (Lpp Lpn Lnn A d : ℚ) :
                  Lpp * ((A - d) * (A - d - 2)) + Lnn * ((A + d) * (A + d - 2)) + 2 * Lpn * ((A - d) * (A + d)) = (Lpp + Lnn + 2 * Lpn) * A ^ 2 + (2 * d * (Lnn - Lpp) - 2 * (Lpp + Lnn)) * A + (d ^ 2 * (Lpp + Lnn - 2 * Lpn) + 2 * d * (Lpp - Lnn))

                  The complete-graph branch saturates only under an exact sign cancellation. For the complete graph on A sites the typed sum is B = L_pp·C(Z,2) + L_pn·Z·N + L_nn·C(N,2); along the isobaric line Z = (A−d)/2, N = (A+d)/2 the coefficient of A² is (L_pp + L_nn + 2·L_pn)/8. Written without division, as the doubled form: the A² coefficient of 8·B is L_pp + L_nn + 2·L_pn.

                  QOU.Mass.CoordinationSaturation.complete_graph_no_saturation assumes a single ε > 0, so it does not cover the mixed-sign case; this identity is what shows the case exists.

                  theorem QOU.Mass.TypedBondSiteInvariance.complete_b3_eq (Lpp Lpn Lnn : ℚ) (hsat : Lpp + Lnn + 2 * Lpn = 0) :
                  (Lpp + Lnn) / 2 + 2 * Lpn - 3 * Lpn = -2 * Lpn
