    theorem QOU.Mass.BranchLocusFiniteOrder.exists_pow_eq_one_of_stabilizes {K : Type u_1} [Field K] (S : Finset K) (hS : 0 ∉ S) (l : K) (hmap : ∀ r ∈ S, l * r ∈ S) {r : K} (hr : r ∈ S) :
    ∃ (n : ℕ), 0 < n ∧ n ≤ S.card ∧ l ^ n = 1

    The pigeonhole step. If a finite set S of a field contains no zero and is mapped into itself by multiplication by l, then l has finite multiplicative order, bounded by S.card.

    This is the half of the W1 tranches' prose step that is not geometric. The S.card + 1 orbit points l^0·r, …, l^{S.card}·r all lie in S, which has S.card elements, so two coincide; the common factor l^i·r is nonzero, so cancelling it gives l^n = 1.
