        Discharging the positivity hypothesis for the framework's amplitude class #

        The bridge above carries 0 < T as a hypothesis because log needs a nonzero (here positive) argument. That hypothesis is not a genuine assumption for the amplitudes the framework actually uses: the categorical amplitudes are quantum dimensions, built from quantum integers [n]_q, and at the substrate modulus q > 1 every quantum integer is strictly positive (QOU.MathlibExt.qInt_pos). So for the quantum-integer amplitude class the positivity follows from the substrate constraint q > 1 and is discharged, not assumed. (The multiplicativity input — that the assembly amplitude factorises as (∏ Tᵢ)·I — is the separate, still-open item: the Jones trace is multiplicative under connected sum, J(K₁#K₂)=J(K₁)·J(K₂). That is now PROVED algebraically in QOU.MathlibExt.MarkovTraceMultiplicative and consumed in the capstone section at the end of this file; bean qou-301d.)

          Capstone — BOTH hypotheses discharged on juxtaposed matrix amplitudes (bean qou-301d) #

          The lemmas above take T₁ * T₂ (multiplicativity) and 0 < T (positivity) as hypotheses. On the framework's actual amplitudes — Markov traces of Hecke-representation matrices — both are theorems:

          • multiplicativity is MarkovTraceMultiplicative.markovTrace_juxtapose (the trace of a disjoint-strand juxtaposition is the product of the block traces, from Matrix.trace_kronecker) — the algebraic form of J(K₁#K₂)=J(K₁)·J(K₂);
          • positivity is preserved by juxtaposition (markovTrace_juxtapose_pos) and, for the quantum-integer amplitude class, holds outright at q > 1 (qIntR_pos above).

          So the bridge below assumes only that the composite amplitude IS the juxtaposition (IsJuxtaposition, the algebraic statement that the two sub-braids share no strand) and that each component amplitude is positive. Nothing about log-additivity is postulated.

          theorem QOU.Mass.ArchimedeanTraceBridge.binding_juxtapose_eq_zero {m : Type u_1} {n : Type u_2} [Fintype m] [Fintype n] {A : Matrix m m ℝ} {B : Matrix n n ℝ} {C : Matrix (m × n) (m × n) ℝ} (h : MathlibExt.MarkovTraceMultiplicative.IsJuxtaposition A B C) (hA : 0 < A.trace) (hB : 0 < B.trace) :
          freeEnergy A.trace + freeEnergy B.trace - freeEnergy C.trace = 0

          Binding of a juxtaposed pair vanishes. If the assembly is a genuine disjoint union (no linking), the mass-deficit binding is zero — the components are independent. Binding is therefore carried entirely by the FAILURE of juxtaposition, i.e. by the linking, which is what bindingFreeEnergy measures. This is the falsifiable content of the whole bridge.
