    def QOU.Mass.FreedmanHeGenusHandleNeedsVanishingLinking.BrunnianAt {ι : Type u_1} (lk : ι → ι → ℤ) (k : ι) :
    Prop

    The hypothesis the genus handle needs at component k: every pairwise linking number of k with the other components vanishes.

    This is the Brunnian condition localised at one component, and it is exactly what makes a surface bounded by L_k in the complement of the rest exist at all.

    TIER 3. It is the pointwise form of MilnorIndeterminacyGate's tier-2 condition — BrunnianTierDisambiguation.linkingVanishes_iff_forall_at proves the two agree on a symmetric three-component matrix — and, like it, is strictly weaker than true Brunnian-ness. Tier table for the four things this corpus calls Brunnian, and which implications hold: QOU.Mass.BrunnianTierDisambiguation.

      structure QOU.Mass.FreedmanHeGenusHandleNeedsVanishingLinking.PathLinking (m : ℕ) :
      Type

      The measured shape of the derived carrier: m components whose linking graph is the path P_m — consecutive components linked, and (as recorded in lk_symm) linking is symmetric.

      Only the two facts the theorem uses are demanded. In particular nothing here says the non-consecutive pairs vanish; the conclusion does not need it, and demanding it would make the structure harder to instantiate than the result requires.

      • lk : Fin m → Fin m → ℤ

        the pairwise linking numbers

      • lk_symm (i j : Fin m) : self.lk i j = self.lk j i

        linking is symmetric in its two components

      • consecutive_ne (i : Fin m) (h : ↑i + 1 < m) : self.lk i ⟨↑i + 1, h⟩ ≠ 0

        consecutive components are genuinely linked

        The result. On a path of at least two components, no component has all its linking numbers vanishing — so the Borromean hypothesis of the complement-genus estimate fails at every single one.

        The endpoint is the case worth stating: the last component has no successor, and the argument closes it by walking backwards through lk_symm.
