    class QOU.Mass.ComplexVolumeFibreDescent.ComplexVolumeFibre (V : ℝ → ℂ) :
    Prop

    conj:binding-qbeta-complex-volume (fibre descent), §3b class. A complex-volume fibre object is a map V : ℝ → ℂ whose real part is bar-even (binding / cosh channel: even under η ↦ −η) and imaginary part is bar-odd (Q_β / sinh channel: odd under η ↦ −η). The framework's binding and Q_β observables descending from one such V is the open conjecture.

    • re_bar_even (η : ℝ) : (V (-η)).re = (V η).re

      Re V is bar-even — the binding (cosh) channel.

    • im_bar_odd (η : ℝ) : (V (-η)).im = -(V η).im

      Im V is bar-odd — the Q_β (sinh) channel.

        The self-dual locus constraint (from prop:self-dual-higgs-real-volume) #

        The keystone QOU.Knot.SelfDuality.higgs_complex_volume_real proves, over a generic (CommRing R, σ), that a bar-fixed element has zero bar-odd part. Here is its fibre-map instance, wired into the descent class: an amphichiral source (J_N(q) = J_N(q⁻¹), the Higgs 4₁) gives a bar-fixed fibre object, and for a bar-fixed ComplexVolumeFibre the Q_β channel vanishes identically — 𝔙 is purely real (binding only, CS = 0).

        This is a falsifiability constraint on the open descent: any candidate assembly of the actual trace object 𝔙 = E₀·tr_M((Π_free−1)∘ℳ) into a ComplexVolumeFibre must send amphichiral composites to real 𝔙 (zero Q_β). A proposed assembly producing a nonzero Q_β for a self-dual composite is refuted by barFixed_qbeta_zero below — structure narrowing the search, per formalize-first.

        def QOU.Mass.ComplexVolumeFibreDescent.BarFixed (V : ℝ → ℂ) :

        A fibre object is bar-fixed (self-dual / amphichiral source): V(−η) = V(η). This is the fibre-map form of J_N(q) = J_N(q⁻¹) (the Higgs 4₁ self-duality).
