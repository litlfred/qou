    QOU.Mass.WignerSU4RowBoundInactive — the doubly-magic SU(4) route cannot SIZE the #

    ⁴He enhancement

    prop:bk-coordination-multiplicity reads the jet-filtration body-order multiplicity off AME2020 as M_need(A) = B_AME/(m_e·Vol_A), matches the non-magic A = 3 pair with the coordination number z = A − 1, and attributes doubly-magic ⁴He an extra factor M_need/z ≈ 2.52, identified with the Schur–Weyl period a_D^(4) = Σ_{λ⊢4} dim_q λ / 4.

    The standing structural motivation for singling out A = 4 is Wigner's SU(4) supermultiplet scheme: the nucleon spin–isospin space is 4-dimensional, ⁴He is the [1⁴] singlet, and dim [1ⁿ] = C(4,n) vanishes for n ≥ 5. The corpus is careful to say this locates the A = 4 turnover without sizing it.

    This file proves that "without sizing" is not a caution but a theorem.

    The invariant #

    A partition of n has at most n parts, because every part is ≥ 1 (rows_le). Hence for every n ≤ 4 the SU(4) admissibility constraint "at most 4 rows" is satisfied by every partition of n (su4_inactive_of_le_four), so the admissible set is the full set (su4_filter_eq_univ) and, for every weight function w into every AddCommMonoid, the SU(4)-restricted Schur–Weyl sum equals the unrestricted one (su4_restricted_sum_eq).

    A constraint that is satisfied vacuously at both n = 3 and n = 4 takes the same value on both, so no functional built by imposing it can distinguish them — in particular it cannot produce a factor present at A = 4 and absent at A = 3. su4_no_magic_enhancement states exactly that: the restricted-to-unrestricted ratio is 1 at both, for any weight.

    The bound is not vacuous in general — it first bites at n = 5, witnessed by the all-ones partition (su4_active_at_five), which is precisely the dim [1⁵] = 0 fact the corpus already uses. So the SU(4) row bound is a genuine constraint that happens to be inactive exactly on the range where the enhancement lives.

    Scope #

    This is a scope-(b) structural exclusion in the sense of AGENTS.md §"Before declaring refuted / ruled out / dead end": it cites a proved invariant (rows_le, below) rather than a failed numerical probe. Its scope is narrow and deliberate — it excludes the Wigner-SU(4)-row-restriction route to sizing the enhancement, and nothing else. It says nothing about:

    • whether some other Schur–Weyl functional sizes it (the a_D^(4) identification is tested numerically, and found wanting, in computations/magic_shell_enhancement_derive_or_refute.py — that is scope (a));
    • whether ⁴He's closed shell has some non-representation-theoretic consequence;
    • the A = 3 z = A − 1 match, which is untouched.

    Base ring: ℕ for the combinatorial core; the summation lemma is stated over a generic [AddCommMonoid R] (AGENTS.md §7c — nothing archimedean is used or needed).
