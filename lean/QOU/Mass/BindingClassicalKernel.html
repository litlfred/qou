      theorem QOU.Mass.BindingClassicalKernel.aDClassical_variable_coeff (n : ℕ) :
      (↑n + 3) * aDClassical (n + 3) = (↑n + 2) * aDClassical (n + 2) + (↑n + 2) * (↑n + 1) * aDClassical (n + 1)

      The exact classical binding kernel is variable-coefficient (derived, not fitted).

      For every n, the classical binding period a_D^(n) = I(n)/n satisfies the variable-coefficient depth-2 recurrence

      (n+3)·a_D^(n+3) = (n+2)·a_D^(n+2) + (n+2)(n+1)·a_D^(n+1).

      The coefficients depend on n (they grow), so this is not a fixed-τ recurrence; the constant-τ depth-2 model (BindingRecurrenceSpectral) is the n≤4 shadow of this kernel. Proved from the telephone recurrence — no fit, no sorry.
