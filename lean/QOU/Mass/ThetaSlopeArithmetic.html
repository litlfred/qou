              theorem QOU.Mass.ThetaSlopeArithmetic.sinhcosh_reaches_ggm :
              (prodSlope c1Slope c1Slope, prodSlope (bar c1Slope) (bar c1Slope)) = (1, -1)

              The sinh/cosh twist reaches the GGM slope pair. The symmetric square of a slope-½ solution f sits at slope 2·½ = 1 (f²) and its bar-conjugate (f̄)² at slope 2·(−½) = −1. The pair equals (1, −1).

              theorem QOU.Mass.ThetaSlopeArithmetic.gs_cumulative_degree (m : ℕ) :
              (∑ k ∈ Finset.range m, k) * 2 = m * (m - 1)

              GS-filtration cumulative q-degree = C(m,2). The Hecke reducer's Gröbner–Shirshov normal forms are graded by Coxeter/word length; level k contributes degree k, so the cumulative degree through level m is ∑_{k<m} k = m(m−1)/2 = C(m,2) — the top degree ℓ(w₀) of the longest element (corpus witness gb-filtration-jet-order). Pure ℕ combinatorics (Finset.sum_range_id_mul_two). This is the categorical grading the theta Gaussian is (numerically) half of.

              The Newton polygons, computed — c1Slope and ggmSlopes are no longer stipulated #

              Added 2026-08-08 (bean qou-slpd item 4). Everything above took the two slope values as definitions. This section derives them from the operators, so the Door-i obstruction rests on a computation rather than on two hand-entered rationals.

              Operators in x = q^m with σ : x ↦ qx (docs/audits/2026-07-20-qlift-routeA-rsz-invariants.md §1), then pushed to ∞ in the RSZ frame w = 1/x, σ̃ : w ↦ qw, denominators cleared:

              • C1 L1 = (q²x − 1)σ² − (q−1)σ − (q−1) ⟶ −(q−1)w·σ̃² − (q−1)w·σ̃ + (1−w), valuations (0, 1, 1).
              • GGM eq-49 L2 = σ² − (2 − qx)σ + 1 ⟶ qw·σ̃² + (1−2qw)·σ̃ + qw, valuations (1, 0, 1).

              The valuations are proved from the coefficient polynomials (c1_valuations, ggm_valuations) via natTrailingDegree, not read off by eye; RSZ §2.2.1's lower hull is then newtonSlopes. C1's middle point (1,1) sits strictly above the segment (0,0) → (2,1) (mid-height ½ < 1), giving one edge (r,d) = (2,1) — slope ½ with multiplicity 2, pure isoclinic and non-integral. GGM's (1,0) is a vertex, giving two edges of slopes −1, +1.

              The audit called this "exact hand algebra" and asked for formalize-first. This is that.

              Sign convention. RSZ changed terminology so that module slopes are the negatives of the older operator convention (Astérisque 355, footnote 2 p. 16, Example 2.2.2, r_{M∨}(µ) = r_M(−µ)); the change negates every slope uniformly, so newtonSlopes_c1_ne_ggm — the only thing Door-i needs — is unaffected.

              Still not settled by this: whether the Newton slope is the q-Gevrey order or level of a given solution sequence. See the order/level note in the module docstring. Computing the polygon pins the number ½; it does not by itself say which growth quantity that number is.

                def QOU.Mass.ThetaSlopeArithmetic.newtonSlopes (d : Order2Valuations) :
                Multiset ℚ

                RSZ §2.2.1 Newton slopes, order 2. Lower convex hull of {(0,v₀), (1,v₁), (2,v₂)}. The middle point lies strictly above the segment (0,v₀) → (2,v₂) exactly when v₀ + v₂ < 2v₁; then the hull is one edge of horizontal length 2 and the slope (v₂−v₀)/2 occurs with multiplicity 2. Otherwise the hull breaks at (1,v₁) into two edges of length 1.
