        2b. The hypothesis is μ ∝ c, NOT μ = c/2 #

        source
        theorem QOU.Mass.CarrierCrossingQuantisation.bRatio_scale_invariant {R : Type u_1} [Field R] (κ c₂ c₃ : R) (hκ : κ ≠ 0) :
        bRatio (κ * c₂) (κ * c₃) = bRatio c₂ c₃

        Rescaling the multiplicity changes nothing. b₃/b₂ is invariant under μ ↦ κμ for any κ ≠ 0, so every result below holds for any multiplicity proportional to the crossing count — the ½ of countChannel is not load-bearing.

        This matters for how the obstruction can be escaped, and it corrects the obvious guess. The ½ looks like a free convention one could simply drop; it is not, and dropping it would not help anyway. It is the unique solution of BrunnianBindingChannel.pairEnergy_decomp, the ring identity splitting n₊q − n₋q⁻¹ into its bar-even and bar-odd parts — and by this lemma any other constant gives the same b₃/b₂.

        So the hypothesis actually in force is linearity: μ = κ·c. Escaping the lattice needs a nonlinear μ(c), and that contradicts pairEnergy_decomp being linear in (n₊, n₋), which it is by construction. The escape route therefore runs through def:crossing-energy itself, not through a convention.

          3b. A Brunnian carrier has an EVEN crossing count, which widens the gap #

          source
          theorem QOU.Mass.CarrierCrossingQuantisation.brunnian_crossings_even (np nn : ℕ) (h : np = nn) :
          Even (np + nn)

          Brunnian ⇒ even. BrunnianBindingChannel.brunnian_signedChannel_zero empties the signed channel exactly when n₊ = n₋; then c = n₊ + n₋ = 2n₊ is even. The A = 2 Hopf carrier is not Brunnian (lk = 1, n₊ = 2, n₋ = 0) — it is the boundary case where lk = z = 1 — so this constrains the A ≥ 3 carriers only, which is where b₃ lives.

          source
          theorem QOU.Mass.CarrierCrossingQuantisation.even_lattice_gap (k : ℤ) :
          209293 / 1483044 ≤ |↑k / 2 - 3 - rMeasured|

          Under parity the grid coarsens to the half-integers, and the gap widens. With c(³H) and c(³He) both even their sum is even, so μ_triple = (c_H + c_He)/4 is a half-integer, not a quarter-integer: the lattice is k/2 - 3. Every point stays at least 209293/1483044 ≈ 0.14112 from the measured ratio — 22.01 % of it, up from the 16.98 % that ignoring parity allows.

          This is what excludes the two nearest points of quarter_lattice_gap: c₃ = 7 and c(³H)+c(³He) = 15 are both odd, hence unreachable by Brunnian carriers.
