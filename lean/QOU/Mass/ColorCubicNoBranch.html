    theorem QOU.Mass.ColorCubicNoBranch.no_root_of_irreducible {K : Type u_1} [Field K] {p : Polynomial K} (hp : Irreducible p) (hdeg : 1 < p.natDegree) (a : K) :
    Polynomial.eval a p ≠ 0

    An irreducible polynomial of degree > 1 over a field has no root. A root a gives (X − C a) ∣ p; since X − C a is not a unit and p is irreducible, p is associate to X − C a, forcing natDegree p = 1 — contradicting 1 < natDegree p.

    theorem QOU.Mass.ColorCubicNoBranch.no_branch_section {K : Type u_1} [Field K] {C : Polynomial K} (hirr : Irreducible C) (hdeg : 1 < C.natDegree) :
    ¬∃ (a : K), Polynomial.eval a C = 0

    No single-valued algebraic branch of the color cubic (conditional on its computed irreducibility over the base field). If the cubic C is irreducible and has degree > 1, no element of the field is a root — i.e. there is no single-valued branch section. This is the permanent consequence of the witness's monodromy = S₃.
