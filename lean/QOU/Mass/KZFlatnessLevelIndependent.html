    The infinitesimal braid relations are homogeneous — KZ flatness is level-independent #

    Bean qou-d0qq, prune P3 of docs/audits/2026-09-07-route-c-step3-and-kz-level-plans.md §B.

    Kohno's theorem: the Knizhnik–Zamolodchikov connection ∇ = d − ħ Σ_{i<j} t_ij d log(z_i − z_j) on the configuration space Conf_n(ℂ) is flat iff the coefficients t_ij satisfy the infinitesimal braid relations — symmetry t_ij = t_ji, the commutator relation [t_ij, t_ik + t_jk] = 0 for distinct i, j, k, and [t_ij, t_kl] = 0 for disjoint pairs. Those relations are homogeneous in t: if t satisfies them, so does c • t for every scalar c. Since the level enters the connection only through the overall scalar ħ (ħ = 1/(k+2) up to normalisation), flatness cannot depend on the level — real, imaginary, or otherwise. What does depend on the level is the monodromy's target: the Hecke algebra H_n(q) with q = e^{iπħ} is semisimple iff q is not a root of unity.

    This file proves the homogeneity (the only step with content); the equivalence "flat ⟺ infinitesimal braid relations" is Kohno's theorem and is cited, not formalised. Consequence for the corpus: two content blocks (mass-theory/lifted-crossing-locality, nuclear-interactions/q-holonomy-locality-derivation) said the KZ connection is "flat at q₀" as though flatness singled out q₀; it does not. What singles out q₀ there is semisimplicity, and the blocks are reworded to say so.

    -- Ref: [kohno1987] Kohno, Ann. Inst. Fourier 37 (1987) — flatness ⟺ infinitesimal braid relations.

    Base ring: A any (non-commutative) R-algebra over a commutative ring R; no ℝ.

    structure QOU.Mass.KZFlatnessLevelIndependent.InfinitesimalBraidRelations {A : Type u_2} [Ring A] {n : ℕ} (t : Fin n → Fin n → A) :
    Prop

    The infinitesimal braid (Kohno–Drinfeld) relations on a family t : Fin n → Fin n → A.

    • symm (i j : Fin n) : t i j = t j i
    • comm_three (i j k : Fin n) : i ≠ j → i ≠ k → j ≠ k → Commute (t i j) (t i k + t j k)

      [t_ij, t_ik + t_jk] = 0 for pairwise distinct i, j, k.

    • comm_disjoint (i j k l : Fin n) : i ≠ k → i ≠ l → j ≠ k → j ≠ l → Commute (t i j) (t k l)

      [t_ij, t_kl] = 0 for disjoint pairs.
