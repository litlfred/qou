      theorem QOU.Mass.PairingParityForcesPositiveB3.pairing_forces_b3_pos {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {δ : R} (hδ : 0 < δ) :
      0 < b3Contrib (-δ) 0

      The pairing term forces b₃ > 0. The deuteron is odd-odd, so pairing enters it as −δ; A = 3 is odd-A, so pairing vanishes there. The resulting contribution is 3δ, positive for every δ > 0 — the sign comes from the parities, not from the coefficient.
