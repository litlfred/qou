    def QOU.Mass.MonotoneWordComponentStructure.pStart (e : ℕ → ℕ) :
    ℕ → ℕ

    The strand sitting at position g when run R_g begins.

    pStart e 0 = 0 (nothing has moved yet). After run g: if e g is even the pair is restored, so position g+1 holds strand g+1 and the next run's left strand is g+1; if e g is odd they are swapped, so the left strand is carried over unchanged.

      def QOU.Mass.MonotoneWordComponentStructure.compIdx (e : ℕ → ℕ) :
      ℕ → ℕ

      Which component of the closure strand i belongs to: the number of even-exponent generators strictly below it.

      Odd runs fuse consecutive strands into one cycle; an even run is where one component ends and the next begins. Written as a count rather than as a cycle decomposition because that is the only property anything below needs.

        theorem QOU.Mass.MonotoneWordComponentStructure.components_differ_iff_even (e : ℕ → ℕ) (g : ℕ) :
        (compIdx e (pStart e g) ≠ compIdx e (g + 1) ↔ e g % 2 = 0) ∧ (e g % 2 = 0 → compIdx e (g + 1) = compIdx e (pStart e g) + 1)

        The result, and it is the whole file. The two strands crossing in run g lie in different components exactly when e g is even — and when they do, the components are adjacent, compIdx g and compIdx g + 1.

        Everything tier 1 asserts is a reading of this one statement.
