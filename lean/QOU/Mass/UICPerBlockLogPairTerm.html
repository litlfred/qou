    1. The non-multiplicativity defect of a two-branch block trace #

    source
    def QOU.Mass.UICPerBlockLogPairTerm.oneCrossing {R : Type u_1} [CommRing R] (wP wM x y d : R) :
    R

    The trace of one crossing with offset d in a two-branch block: the two eigenvalues x, y are shifted by d and weighted by wP, wM.

    At x = q, y = −q⁻¹ this is ChainTraceFactor.twoStrandTrace, which equals z + d for the convention-D Markov parameter z = q³/(q²+1).

      The trace of two crossings on the same generator, offsets d₁, d₂. Within each branch the eigenvalues multiply, so the two branches are summed after multiplying, not before — which is exactly why this is not the product of the two one-crossing traces.

        theorem QOU.Mass.UICPerBlockLogPairTerm.twoCrossing_defect {R : Type u_1} [CommRing R] (wP wM x y d₁ d₂ : R) (hw : wP + wM = 1) :
        twoCrossing wP wM x y d₁ d₂ - oneCrossing wP wM x y d₁ * oneCrossing wP wM x y d₂ = wP * wM * (x - y) ^ 2

        The exact non-multiplicativity defect. For branch weights summing to one,

        twoCrossing − oneCrossing(d₁)·oneCrossing(d₂) = wP · wM · (x − y)².

        The right-hand side mentions neither offset: the failure of multiplicativity is the same for every pair of bonds. This is the mechanism by which a per-block logarithm leaves the additive class of GradedBindingFunctionalPairTerm.additive_census.

        theorem QOU.Mass.UICPerBlockLogPairTerm.twoCrossing_mul_iff {R : Type u_1} [CommRing R] (wP wM x y d₁ d₂ : R) (hw : wP + wM = 1) (hnorm : wM * (x - y) ^ 2 = 1) :
        twoCrossing wP wM x y d₁ d₂ = oneCrossing wP wM x y d₁ * oneCrossing wP wM x y d₂ ↔ wP = 0

        The block trace is multiplicative over two bonds iff the defect vanishes; under the wM·(x−y)² = 1 normalisation that happens exactly when wP = 0, i.e. when the block has only one live branch. So a genuinely two-branch block is never multiplicative.

          def QOU.Mass.UICPerBlockLogPairTerm.census {R : Type u_1} [CommRing R] (c fpp fpn fnn A Z : R) :
          R

          Twice the all-pairs bond census functional, doubled so that C(Z,2) = Z(Z−1)/2 needs no division and the statement holds over any commutative ring:

          2·F(Z) = f_pp·Z(Z−1) + 2·f_pn·Z(A−Z) + f_nn·(A−Z)(A−Z−1) + c.

          c absorbs everything constant in Z (in the UIC that is the per-nucleon intra-nucleon part, which is A letters regardless of how many are protons).

            theorem QOU.Mass.UICPerBlockLogPairTerm.census_secondDiff {R : Type u_1} [CommRing R] (c fpp fpn fnn A Z : R) :
