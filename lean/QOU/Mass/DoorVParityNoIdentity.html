    theorem QOU.Mass.DoorVParityNoIdentity.nonneg_not_signalternating (s : ℕ → ℝ) (hs : ∀ (n : ℕ), 0 ≤ s n) (n : ℕ) :
    ¬s n * s (n + 1) < 0

    The core parity fact. A pointwise non-negative real sequence is never sign-alternating: for every n, the product of consecutive terms is non-negative, so it cannot be < 0. This is the exact invariant behind the Door-v residual — the tensor-square solutions f₊², f₋² are non-negative squares, hence carry no consecutive sign flip.

    theorem QOU.Mass.DoorVParityNoIdentity.doorV_parity_no_identity (p q y : ℕ → ℝ) (hp : ∀ (n : ℕ), 0 ≤ p n) (hq : ∀ (n : ℕ), 0 ≤ q n) (α β : ℝ) (hα : 0 ≤ α) (hβ : 0 ≤ β) (m : ℕ) (hy : y m * y (m + 1) < 0) :
    ¬∀ (n : ℕ), α * p n + β * q n = y n

    Door-v parity NO-IDENTITY (scope-(b) structural exclusion).

    Model of the Door-v situation. p, q are the non-negative tensor-square sequences f₊², f₋² (0 ≤ p n, 0 ≤ q n). y is the genuinely sign-alternating GGM target (y n · y (n+1) < 0, i.e. every consecutive pair flips sign — the (−1)^m character). α, β ≥ 0 are the sign-preserving coefficients the tensor-square positivity forces.

    Conclusion: NO such (α, β) reproduces the target — α·p + β·q = y is impossible. Proof: the left side lies in the non-negative positive cone (posCone_nonneg), so an identity would force y ≥ 0 everywhere, contradicting a single sign flip (nonneg_not_signalternating). One consecutive pair suffices, so genuine alternation anywhere already excludes the identity.

    This is a scope-(b) exclusion: the cited invariant is the proved non-negativity of a real square, not a numerical near-match.

    The bar-parity twist — what it does and does not do #

    Added 2026-08-08 for conj:c1-ggm-bar-parity-faces. The obstruction above says no non-negative-cone combination can equal a target with a consecutive sign flip. The conjecture's open half asks whether the diagonal ℤ/2 character (−1)^m is the whole difference. These lemmas settle the scalar-combination reading of that question, in the negative, and say why the module-level reading is untouched.

    The twist inverts every consecutive-pair sign, not only the alternating ones. So it can clear the obstruction only for a target that alternates at every pair — and the Stokes carrier's solution does not, since 2 − q^{m+1} is positive below m + 1 = log 2 / log q. Measured in computations/qbeta/c3_w2_bar_parity_twist_probe.py (4/4): the twisted sequence still flips, at exactly the indices where the untwisted one did not.

    Consequence. "The diagonal ℤ/2 character is the sole residual" cannot mean that applying the character makes the target a non-negative combination of the squares — that reading is excluded by the same non-negativity invariant that produced the obstruction. It must be read at the module level, up to a genuine gauge. Nothing here bears on that, and nothing here refutes the conjecture; one reading of it is removed.
