    theorem QOU.Mass.MonotoneWordCycleStructure.posAfter_stab (e : ℕ → ℕ) {j g N : ℕ} (hjg : j < g) (hgN : g ≤ N) :
    MonotoneWordPositionTracking.posAfter e N j = MonotoneWordPositionTracking.posAfter e g j

    Runs above j leave j alone. Run g moves only positions g and g+1, so a position strictly below g is untouched — the other half of posAfter_of_le, which handled positions strictly above.

    theorem QOU.Mass.MonotoneWordCycleStructure.posAfter_of_odd (e : ℕ → ℕ) {i N : ℕ} (hodd : ¬e i % 2 = 0) (hiN : i + 1 ≤ N) :
    MonotoneWordPositionTracking.posAfter e N i = i + 1

    An odd run fuses i with i+1. The closure permutation sends i to i + 1: runs above i cannot touch it (posAfter_stab), run i swaps it up, and runs below cannot reach i+1 (posAfter_of_le).

    theorem QOU.Mass.MonotoneWordCycleStructure.posAfter_of_even (e : ℕ → ℕ) {i N : ℕ} (heven : e i % 2 = 0) (hiN : i + 1 ≤ N) :
    MonotoneWordPositionTracking.posAfter e N i = MonotoneWordComponentStructure.pStart e i

    An even run wraps i back to pStart e i. Runs above i leave it alone and run i does not move it, so the closure permutation returns the strand that was sitting at position i when run R_i began — which posAfter_self identifies as pStart e i.

    theorem QOU.Mass.MonotoneWordCycleStructure.compIdx_posAfter (e : ℕ → ℕ) {i N : ℕ} (hiN : i + 1 ≤ N) :
    MonotoneWordComponentStructure.compIdx e (MonotoneWordPositionTracking.posAfter e N i) = MonotoneWordComponentStructure.compIdx e i

    The closure permutation preserves the class. Both branches land in compIdx e i: the odd one because an odd run contributes nothing to the count, the even one by compIdx_pStart.

    Hence every cycle of the closure lies inside a single compIdx class.

    theorem QOU.Mass.MonotoneWordCycleStructure.lt_compIdx_of_lt_pStart (e : ℕ → ℕ) {i j : ℕ} (hj : j < MonotoneWordComponentStructure.pStart e i) :
    MonotoneWordComponentStructure.compIdx e j < MonotoneWordComponentStructure.compIdx e i

    pStart e i is the least element of i's class: everything strictly below it sits in a strictly earlier class.

    With compIdx_pStart (same class) this pins pStart e i as the class minimum, which is what makes posAfter_of_even close the cycle rather than merely stay inside it.

    theorem QOU.Mass.MonotoneWordCycleStructure.step_within_class (e : ℕ → ℕ) {i N : ℕ} (hsame : MonotoneWordComponentStructure.compIdx e (i + 1) = MonotoneWordComponentStructure.compIdx e i) (hiN : i + 1 ≤ N) :
    MonotoneWordPositionTracking.posAfter e N i = i + 1

    The class is traversed upward. Consecutive strands in the same class are joined by an odd run, and the closure permutation sends one to the next — so a class is connected inside a single cycle.

    Together with compIdx_posAfter (cycle ⊆ class) this gives cycles = classes.
