          theorem QOU.Mass.ConstantKernelGrowthBound.exists_exponential_bound {d : ℕ} {c : Fin d → ℝ} {a : ℕ → ℝ} (hd : 0 < d) (h : IsConstKernelRec d c a) :
          ∃ (M : ℝ), 0 ≤ M ∧ ∀ (n : ℕ), |a n| ≤ M * kernelBound c ^ n

          The bound. Every solution of a depth-d constant-kernel recurrence is dominated by a geometric sequence whose base is the kernel's ℓ¹ norm (or 1, whichever is larger) and whose constant depends only on the d initial values.

          This is the elementary form of "constant-coefficient recurrences have solutions Σ p_i n * λ_i ^ n" — stated as a bound so that it can be contradicted by a growth hypothesis without needing the characteristic-root decomposition.

          The contradiction. No super-exponentially growing sequence satisfies a depth-d recurrence with a constant kernel, for any depth and any kernel.

          Applied to the corpus: prop:prolonged-periods-fixed-depth (constant kernel, d ≤ 8) and classical_period_ratio_unbounded (super-exponential) cannot both hold of a_D^(n). Which one gives is not decided here — see the file header.
