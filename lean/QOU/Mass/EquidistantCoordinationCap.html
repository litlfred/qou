    theorem QOU.Mass.inner_self_sum_of_equidistant_gram {V : Type u_1} [NormedAddCommGroup V] [InnerProductSpace ℝ V] {n : ℕ} (v : Fin n → V) (d : ℝ) (hg : ∀ (i j : Fin n), inner ℝ (v i) (v j) = d ^ 2 / 2 * (1 + if i = j then 1 else 0)) (c : Fin n → ℝ) :
    inner ℝ (∑ i : Fin n, c i • v i) (∑ i : Fin n, c i • v i) = d ^ 2 / 2 * ((∑ i : Fin n, c i) ^ 2 + ∑ i : Fin n, c i ^ 2)

    The Gram identity for an equidistant family.

    If v : Fin n → V has ⟪v i, v j⟫ = (d²/2)·(1 + δᵢⱼ) — which is exactly the Gram matrix of the difference vectors pᵢ − p₀ of a pairwise-equidistant point family at common distance d — then for any coefficients c,

    ‖Σ cᵢ vᵢ‖²  =  (d²/2) · ( (Σ cᵢ)² + Σ cᵢ² ).

    Both bracketed terms are squares, which is what forces independence below.

    LinearIndependent ℝ v

    Equidistant ⇒ linearly independent.

    The difference vectors of a pairwise-equidistant point family (common distance d ≠ 0) are linearly independent: ‖Σ cᵢ vᵢ‖² is (d²/2) times a sum of two squares, so it vanishes only when every cᵢ does.

    n ≤ Module.finrank ℝ V

    The cap. A pairwise-equidistant family of difference vectors in a space of finite rank r has at most r members — so a max-contact cluster of A nucleons (whose A − 1 difference vectors are such a family) satisfies A - 1 ≤ r. In r = 3 this is A ≤ 4: the tetrahedron is the largest all-mutually-adjacent point set in ℝ³, and the complete contact graph K_A is not 3D-realizable for A ≥ 5.
