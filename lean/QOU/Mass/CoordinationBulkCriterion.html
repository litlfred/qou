    QOU.Mass.CoordinationBulkCriterion — an edge set can supply a surface term only if it has a bulk #

    QOU.Mass.SurfaceExponentIsDimension rejected the production braid word's chain against the AME chart: its coordination graph is a path, so its bond count is A − 1 and its per-nucleon law is the p = 1 member of B/A = a − b·A^(−p), which the data exclude. It left the sharpened question — what edge set could supply a surface term at all?

    This file answers the general form of that question, and the answer is not about amplitudes.

    Part 1 — every affine bond count is p = 1, so none of them is ever a surface term #

    An edge set whose bond count is affine in A,

    M(A) = α·A + β,

    has per-nucleon binding ε·M(A)/A = εα + εβ/A exactly (affine_perNucleon) — the p = 1 member of the family, whatever α and β are (affine_eq_perNucleonExp). By perNucleonExp_exponent_inj it therefore differs from every p ≠ 1 law at some A (affine_ne_surfaceLaw), provided β ≠ 0 — i.e. provided the count is not exactly proportional to A, in which case there is no correction at all.

    Both coordination objects derived anywhere on main are affine, and this one theorem covers both:

    • the production word's chain, A − 1 bonds (chain_is_affine, at α = 1, β = −1);
    • the deltahedron contact graph, E = 3A − 6 by Euler (deltahedron_is_affine, at α = 3, β = −6).

    So the obstruction is not that the chain is one-dimensional in particular. Affineness alone is enough, and it is a property both derived candidates share.

    Part 2 — the criterion an edge set must satisfy, and why both candidates fail it #

    CoordinationSurfaceDeficit.perNucleon_split puts the whole A-dependence of the correction in the surface fraction A_surf/A. Two things must hold at once for that fraction to carry a genuine surface term:

    HasBulk A_surf  ↔  A_surf → ∞      (there IS a surface, and it grows)
                ∧  A_surf/A → 0    (there IS an interior — a bulk)

    Each clause alone is cheap; the conjunction is what has content. The two derived candidates fail one clause each, for opposite reasons:

    • The chain has A_surf = 2, a constant. It has an interior, but its surface does not grow, so the deficit is a fixed number of missing bonds spread over A nucleons — 1/A, exponent 1 (boundedSurface_not_hasBulk).
    • A convex deltahedron has A_surf = A: every nucleon is a vertex of the hull, so it is three-dimensional and yet has no interior at all. Its surface fraction is constant, so the deficit renormalises the volume term and contributes no A-dependence whatever (linearSurface_not_hasBulk). Two caveats, both measured by the companion probe and both weakening what this row can be taken to show: convex deltahedra exist only for A ∈ {4,…,10,12}, and the corpus records them only up to A = 7 — so HasBulk, an A → ∞ criterion, is applied here to the idealisation A_surf = A and never to the corpus's actual data, which does not reach far enough to have an asymptotic regime at all.

    The satisfying case is exactly the one CoordinationSurfaceDeficit assumed: A_surf = c·A^θ with 0 < θ < 1 (powerSurface_hasBulk), which is where the compact-packing hypothesis θ = 2/3 lives.

    This is why the question is prior to the amplitude. #6761 asked what fixes the fractional degree loss 1 − k'/k and measured its answer generic (67.9 % of the plausible window). No value of that ratio matters until an edge set satisfies HasBulk.

    What is new here, and what the corpus already had #

    A corpus-grep (six paths; path 0 unavailable, so grep-open not graph-open) puts four prior results between this file and a claim of novelty. Each is cited so a reader does not have to find it.

    • The general affine object already has a Lean def. QOU.Mass.AffineCountMultiplicityWindow.mu (α β A : R) : R := α * A + β is the same object over a generic field, used there for cumulants, never for a surface exponent. affineBondCount is therefore a second definition of it, and the two should be reconciled if either grows consumers. That file's own scope note — "the window below is stated for a general affine multiplicity and is instantiated at nothing" — describes exactly the step this file takes.
    • The chain half of Part 2 is already closed in prose, twice. computations/qbeta/qbeta_chain_cannot_carry_coulomb_or_surface_probe.py §2 states it verbatim: "In a path every interior vertex has degree exactly 2 and the two endpoints have degree 1 — a deficit of 2, independent of A. No A^(2/3) piece can arise from the edge count of a path, for any letters." Restated in docs/audits/2026-09-05-binding-law-arc-synthesis.md. So boundedSurface_not_hasBulk formalises an argument the corpus already carries; it does not discover it. Neither prior site has Lean.
    • The deltahedron half is my own prose from #6780, whose header already said a convex deltahedron "is d = 3 geometrically while having no bulk at all". linearSurface_not_hasBulk promotes that objection to a decidable Prop. That is worth doing and it is not a new finding.
    • AffineCountIsNotASurfaceTerm is a one-instance result, and its generalisation over invariants was already made informally: computations/probes/every_seifert_invariant_is_affine_probe.py records scope-(b) for any Seifert invariant of the canonical closure "via QOU.Mass.AffineCountIsNotASurfaceTerm's strictly-monotone ratio, which applies verbatim to each affine invariant" — measured on six nuclei, target fixed at A^(2/3), never written as a theorem.

    What is new is accordingly narrow and worth stating precisely: arbitrary (α, β) against every p ≠ 1 rather than one count against one target; the deltahedron instantiation in Lean; and HasBulk itself, which a full grep finds nowhere in the corpus in any wording — neither the conjunction, nor Tendsto (A_surf A / A) atTop (nhds 0) in any Lean file.

    Scope #

    • Proved: the affine identity and its exclusion of every p ≠ 1; both derived edge sets are affine; the three HasBulk verdicts (constant fails, linear fails, sublinear power succeeds).
    • NOT proved, and this is the open item: that the substrate cannot emit a non-affine coordination object. Reaching a scope-(b) exclusion would need an argument that every edge set the braid word can express is affine, which is not attempted here — and the corpus already carries two scope-(a) negatives pointing the same way, which must be cited rather than re-derived: every_seifert_invariant_is_affine_probe.py ("the framework's nuclear encoding has no surface … a surface term must come from geometry the encoding does not currently carry", measured at six A) and computations/substrate/nf_inter_nucleon_is_a_count_not_a_graph_probe.py (a stronger negative on one layer: the NF encoding expresses a bond count by type and no graph at all, since two different graphs with the same type counts give a bit-identical vector).
    • 🛑 The enumeration of derived edge sets is EMPIRICAL, so "no derived edge set has a bulk" is scope-(a) and is stated here only for the AFFINE ones. The corpus keeps its own list at QOU.Hecke.BoundedDegreeCoulomb, and it is longer than two. Beyond the chain and the deltahedron there is at least max-contact sphere packing (computations/binding_edge_set_selection.py), whose contact numbers for A ≥ 5 are case-by-case geometry, are not the deltahedron family in general, and are not known to be affine — so this file does not cover it, and says so rather than letting the conclusion overreach. There is also the degree-capped count f_k(A) = A·min(A−1,k)/2 (QOU.Mass.SaturationInvisibleToCumulants), which is piecewise and so not affine on ℝ, though Part 2 does reach it. The honest claim is about affine edge sets, not about every edge set the corpus derives.
    • Relation to QOU.Mass.AffineCountIsNotASurfaceTerm: that file excludes one specific affine count (12A − 1, a crossing count) against one specific target (c·A^(2/3)), by monotonicity of the ratio. This is the same conclusion reached in the exponent variable and for an arbitrary affine count against every p ≠ 1 — a generalisation of it, not a re-derivation, and the two are proved by different routes.
    • Not a fit. Nothing here is measured against data; the companion probe checks the corpus's edge sets against the criterion.

    Ground ring ℝ (§7c: archimedean — real powers and limits).

      Part 2 — the bulk criterion #

      source
      def QOU.Mass.CoordinationBulkCriterion.HasBulk (Asurf : ℝ → ℝ) :
      Prop

      An edge set has a bulk when its surface count grows without bound — there is a surface — while the surface fraction vanishes — there is an interior. Each clause alone is cheap; the conjunction is the content.
