    def QOU.Mass.BraneTowerIsospinBlind.braneTowerW {R : Type u_1} [CommRing R] {ι : Type u_2} (β : ι) (n : ℕ) (z : R) (w : ι → ℕ → R) :
    R

    The R-side brane-tower term of a braid word β (drawn from an index type ι) on n strands: a sum over subsets S of the n − 1 adjacent generators of z^{|S|} times a per-subset weight w β |S|. The Markov-trace structure makes the weight depend on the subset size only (within a fixed word); w β lets it a-priori still depend on the word β.

      braneTowerW β₁ (3 * A) z w = braneTowerW β₂ (3 * A) z w

      (b)-structural exclusion — isospin-blindness of the trace-invariant tower. If the per-subset weight is Markov-invariant, i.e. reduced-word independent (w β₁ = w β₂ — the cited invariant tr_M(σ_i) = z is reduced-word independent), then two isobars β₁, β₂ on the same n = 3A strands receive an identical brane-tower term. Hence the contribution of the trace-invariant brane tower to the mirror-pair binding difference is exactly 0: any mirror split must be carried by T₁ (descended tr_M) and T₅ (chirality), not the brane tower.         theorem QOU.Mass.BraneTowerIsospinBlind.braneTowerR_eq_binom_sum {R : Type u_1} [CommRing R] (n : ℕ) (z : R) (f : ℕ → R) :
        braneTowerR n z f = ∑ k ∈ Finset.range (n - 1 + 1), ↑((n - 1).choose k) * z ^ k * f k

        The trace-invariant tower collapses to a function of (n, z, f) only: braneTowerR n z f = ∑_{k ≤ n−1} C(n−1, k) z^k f k. There is no braid-word input — this is the algebraic content behind isospin-blindness (the value is fixed by the strand count n = 3A, so two isobars of the same A get the same tower).
