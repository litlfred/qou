    Lever-1 binding kernel — (b)-exclusion of the constant-coefficient depth-2 recurrence #

    The lever-1 binding generating function uses the selection-rule weights lw(c) = (1/(c+1)) · Σ_{λ ⊢ c+1} dim_q(λ) (mean quantum dimension; a_D^(n) = lw(n−1)). A natural hypothesis — the depth-2, det = 1 kernel R = x² − τx + 1 — would make the lw sequence satisfy a constant-coefficient depth-2 linear recurrence lw(c) = τ·lw(c−1) − lw(c−2) for a single fixed τ. The numerical probe (lever1_lw_depth2_recurrence_test.py, audit 2026-06-24-lever1-lw-depth2-recurrence-falsified.md) found this fails beyond the 3-point seed: τ fit to c = 2,3 (i.e. the n = 3,4 checks) does not satisfy the next (c = 4) check.

    This file is the (b)-structural-exclusion of that constant-coefficient depth-2 model, proved at the classical limit q = 1 (mean classical irrep dimension), where it is a pure-ℚ fact — and it implies the q-general failure: the recurrence residual is a rational function of q that is already nonzero at q = 1 (value −7/240), hence not the zero function. The carried invariant is the standard S_n irreducible dimension via the hook-length formula — computed from the partition structure, not tabulated (dodge-proof), reusing the pattern of WLambdaDefectClosedForm.

    Scope ((a)/(b) discipline, AGENTS.md). This is the (b) exclusion of the constant-coefficient depth-2 model (a window-independent τ). It does not exclude a q-family / variable-τ monodromy B — that object (the abelianised λ_SW holonomy on the color E_q) is the open, owner-gated keystone target and is untouched here. The file formalizes the audit's finding that "θ_binding = 0.7815 is a 3-point seed-fit artifact, not a derived constant-τ rate." Ref: [manuscript] docs/audits/2026-06-24-lever1-lw-depth2-recurrence-falsified.md

              theorem QOU.Mass.Lever1Depth2.depth2_no_fixed_tau (τ : ℚ) :
              ¬(lwCl 3 = τ * lwCl 2 - lwCl 1 ∧ lwCl 4 = τ * lwCl 3 - lwCl 2)

              (b)-exclusion of the constant-coefficient depth-2 recurrence. There is no fixed τ : ℚ for which the det = 1 depth-2 recurrence lw(c) = τ·lw(c−1) − lw(c−2) holds on the classical lever-1 weights at both c = 3 and c = 4: the c = 3 (seed) equation forces τ = 21/8, and then the c = 4 equation requires 26/5 = 251/48, false (residual −7/240). Hence the lever-1 lw sequence is not the orbit φ(Mⁿ v₀) of any window-independent depth-2 kernel — θ_binding is a seed-fit artifact, not a derived constant-τ rate. (q-deformation only worsens this: the residual rational function is already nonzero at q = 1.)
