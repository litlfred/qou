    Type (u_1 + 1)

    Frobenius-Hopf Object: An object A in a rigid monoidal category equipped with a Hopf algebra structure (μ, η, Δ, ε, S) and a Frobenius form λ : A → 𝟙 satisfying non-degeneracy.

    LaTeX: \label{def:frobenius-hopf} Mathlib: No direct equivalent — builds on Mathlib.CategoryTheory.Monoidal.Category Universes: objects in u, morphisms in v

    • carrier : Type u_1

      The carrier type of the underlying object.

    • mul : self.carrier → self.carrier → self.carrier

      Multiplication μ : A ⊗ A → A.

    • unit : self.carrier

      Unit element η : 𝟙 → A.

    • comul : self.carrier → self.carrier × self.carrier

      Comultiplication Δ : A → A × A.

    • counit : self.carrier → Unit

      Counit ε : A → unit.

    • antipode : self.carrier → self.carrier

      Antipode S : A → A.

    • frobeniusForm : self.carrier → ℝ

      Frobenius form λ : A → ℝ (non-degenerate).
