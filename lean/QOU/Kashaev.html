    QOU.Kashaev — Kashaev volume conjecture as a typeclass #

    The Kashaev volume conjecture (KVC) is axiomatised here as a Lean typeclass. Any downstream theorem that depends on KVC takes [VolumeConjecture q] as a typeclass argument and is then fully verified by Lean — the only unproved input is the class instance.

    Formal-chain version. This file lives under lean/QOU/ and is compiled by lake build. The co-located documentation stub at folio/quantum-observable-universe/braids-and-knots/kashaev-volume-conjecture.lean mirrors this content for .md-rendering / sibling-resolution purposes (per QOU.GroundRingAnnotations).

    LaTeX label: conj:kashaev-volume-conjecture

    The conjecture remains open in general; instances are constructed by hand for specific knot families (figure-eight knot, torus knots, etc.) where the conjecture is actually proved.

    class QOU.Kashaev.VolumeConjecture (q : ℝ) :
    Type

    Kashaev Volume Conjecture (axiomatised).

    Encodes the assertion that the hyperbolic volume of S³ \ K equals the Kashaev limit 2π · lim_N log|J_N(K)| / N of the colored Jones polynomial.

    Any instance of this class supplies:

    • hypVolume β — the hyperbolic volume of the complement of the closure of β (zero when the complement is not hyperbolic).
    • kashaevLimit β — the asymptotic limit of the colored Jones polynomial.
    • kvc_holds β — the conjecture itself, identifying the two.

    The kvc_holds field is the conjectural input: providing it is the role of mathematicians (not Lean). Downstream theorems consuming [VolumeConjecture q] are conditional on it.

    • hypVolume : PhiQPiece.Braid → ℝ

      Hyperbolic volume of S³ \ K_β, with the convention that non-hyperbolic complements contribute zero.

    • kashaevLimit : PhiQPiece.Braid → ℝ

      The Kashaev asymptotic limit 2π · lim_N log|J_N(K)| / N.

    • hypVolume_nonneg (β : PhiQPiece.Braid) : 0 ≤ hypVolume q β

      Hyperbolic volume is non-negative.

    • kvc_holds (β : PhiQPiece.Braid) : hypVolume q β = kashaevLimit q β

      The conjecture itself: the Kashaev limit equals the hyperbolic volume. This is the field that plays the role of sorry for KVC.

    • pieceVol (β : PhiQPiece.Braid) : Finset (Fin (β.n - 1)) → ℝ

      The hyperbolic volume of a Φ_q-piece K_S (the sub-link selected by the smoothing set S). Supplied by the instance (the SnapPy bridge layer for concrete knot families); abstract here so callers never see a placeholder masquerading as a genuine S-dependent value.

    • pieceVol_nonneg (β : PhiQPiece.Braid) (S : Finset (Fin (β.n - 1))) : 0 ≤ pieceVol q β S

      Piece volumes are non-negative (each is a genuine hyperbolic volume).
