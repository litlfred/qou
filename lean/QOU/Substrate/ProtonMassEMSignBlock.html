    QOU.Substrate.ProtonMassEMSignBlock #

    Conditional-class formalization of the proton-mass identity EM correction hypothesis from PR #1645 item 1 (the m_p Yekutieli substrate-derivation).

    Conjecture (provisional, NOT a proved theorem) #

    Per mp_yekutieli_plancherel_scaffold.py + mp_yekutieli_sign_block_discrimination.py (PR #1645), the (α_em/π)/dim H_3 correction in the proton-mass identity

    m_p = 2·m_μ·F_Bor(q_0) − (12 − (α_em/π)/dim H_3) · m_e

    is hypothesized to arise from EM coupling at the SIGN rep V_(1,1,1) of H_3 (the Wedderburn block carrying the proton's color-antisymmetric wave function), with Plancherel weight P_(1,1,1) = d²/|S_3| = 1/6.

    This file states the conjecture as a Lean class per AGENTS.md §3b-cond (conditional-class exception), so that downstream theorems can carry it as an explicit hypothesis until the structural derivation lands.

    What's IN this file #

    • EmSignBlockCorrection class encoding the conjecture
    • Trivial axiomatization (no proof — the class is a placeholder for the future Bring zero-mode + Plancherel-channel derivation)

    What's NOT in this file #

    • The derivation itself (open — see audit + coord docs)
    • The cross-anchor invariance proof (Probe A in PR #1629 verifies numerically)
    • The m_μ over-determination handling (separate concern, formalized in QOU.Substrate.MuOverDetermination)

    Cross-references #

    • merged PR #1581, #1617, #1629
    • mp_yekutieli_plancherel_scaffold.py (numerical match)
    • mp_yekutieli_sign_block_discrimination.py (Fermi-stat argument)
    • QOU.Substrate.MuOverDetermination (related substrate structure)

              Open work — current status (post-PR #1645 follow-up) #

              This module does NOT prove that m_p_residual = (α_em/π)/6 — that would require:

              1. Categorical derivation of the bare per-block (α_em/π) EM coupling (Bring zero-mode analog of m_K/m_π's (3q²-1)/(2q²) from PR #1442). Status: open, multi-session.

              2. Categorical proof that the proton's mass identity residual lives at the sign Wedderburn block (color antisymmetry via Fermi statistics). Status: open; physical argument identified (color singlet → sign rep) but not formalized.

              3. Reconciliation with the residual 54 ppb after the (α_em/π)/6 correction. Status: RESOLVED as CODATA precision floor. PR #1645 follow-up mp_residual_exotic_basis_pslq.py ran PSLQ over the exotic basis (Bloch-Wigner D(z), Mahler measures including Bring quintic z⁵-z-1, hyperbolic volumes, elliptic K) at 120 dps maxcoeff 10⁶ — NULL. CODATA propagation analysis:

                • δk from m_p: 44.4 ppb
                • δk from m_e: 44.9 ppb
                • δk from m_μ: 33.5 ppb
                • Quadrature sum: ~71 ppb CODATA floor

                Observed 54 ppb sub-residual = 76% of CODATA floor. The proton-mass identity is exact within experimental uncertainty; the residual cannot be discriminated from "exact closure" at current input-anchor precision.

              Items (1)–(2) remain multi-session open work; item (3) is closed empirically. The class above lets downstream Lean theorems carry the conjecture as an explicit hypothesis pending (1)–(2).
