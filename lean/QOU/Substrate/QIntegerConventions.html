    def QOU.Substrate.QIntegerConventions.qClas {K : Type u_1} [Field K] (n : ℕ) (q : K) :
    K

    The classical (Gaussian) q-integer, written as the geometric sum 1 + q + ⋯ + qⁿ⁻¹. Division-free, so it is total: defined at every q, including q = 1 where it equals n.

        The bridge. The symmetric bracket at q is the classical bracket at q², normalised by q^(n-1). Stated at n = 2 and n = 3, where it is a one-line field computation; the general n statement is the same identity on geometric sums.

        theorem QOU.Substrate.QIntegerConventions.conventions_never_agree {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (h : q - q⁻¹ ≠ 0) :
        qSymm 2 q ≠ qClas 2 q

        They never agree where both are defined. q - q⁻¹ ≠ 0 already forces q ≠ 1, and the difference (1 − q)/q is then nonzero. So "the conventions coincide at q = 1" is a statement about limits: at q = 1 the symmetric bracket is 0/0 and has no value to coincide with.
