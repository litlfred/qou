    QOU.Substrate.MuOverDetermination #

    Lean formalisation of the substrate over-determination finding: the canonical q₀ (anchored from m_p via PR #1422) and the "μ-anchored q₀" (the value that would make m_μ_pred = m_μ_CODATA exactly) are GENERICALLY DIFFERENT. Therefore m_p and m_μ cannot simultaneously match CODATA at sub-ppb precision via this two- calibration substrate.

    This is the Lean-level structure behind PR #1581's Probe A: the 211 ppb m_μ residual IS the propagated q₀ shift, NOT a missing categorical correction.

    What's PROVED (sorry-free) #

    The muon-mass-ratio formula ratio(q) := Vol(4_1) / (1 - 1/q)² is STRICTLY MONOTONIC on q > 1, hence INJECTIVE.

    Therefore for distinct positive constants m_μ_target_a and m_μ_target_b (e.g. one from m_p anchor, one from CODATA m_μ), the unique inverses q_a := ratio⁻¹(m_μ_target_a / m_e) and q_b := ratio⁻¹(m_μ_target_b / m_e) are also distinct.

    Why this matters for 1ppb #

    The L2 dashboard reports m_μ at 210 ppb miss. PR #1581 Probe A showed numerically that this 211 ppb EQUALS the propagated Δq₀ shift via ∂ ln(m_μ)/∂q = -2/(ℏ_q·q²). This Lean theorem encodes the STRUCTURE behind that numerical fact: the substrate is over-determined when one fixes q₀ from a single physical mass.

          theorem QOU.Substrate.MuOverDetermination.substrate_over_determination (vol_4_1 : ℝ) (hvol : 0 < vol_4_1) (q_a q_b ratio_a ratio_b : ℝ) (hq_a : 1 < q_a) (hq_b : 1 < q_b) (h_a : muRatio vol_4_1 q_a = ratio_a) (h_b : muRatio vol_4_1 q_b = ratio_b) (h_eq : q_a = q_b) :
          ratio_a = ratio_b

          Substrate over-determination corollary.

          For two distinct target mass ratios ratio_a ≠ ratio_b (e.g. one from inverting the m_p anchor, one from the CODATA m_μ target), the unique q values that make muRatio vol_4_1 q = ratio_* for each are DIFFERENT.

          Contrapositive: q_a = q_b ⇒ ratio_a = ratio_b. This is the negation of "one q anchor matches both physical masses."

          What this Lean module does NOT do #

          • Does NOT prove the m_μ residual EQUALS the propagated Δq₀ shift exactly — that requires real-derivative analysis (Mean Value Theorem on Mathlib's deriv), which is heavier setup. The numerical fact is verified in Probe A (mu_substrate_tension_audit_100dps.py) at 100 dps with 12-significant-figure match.

          • Does NOT prove the framework's choice of q₀ anchor. The class ReadingAValidAtH2 pattern (AGENTS.md §3b-cond) is the right way to formalise such structural choices; this module only proves the INJECTIVITY structure that makes the choice consequential.

          • Does NOT provide a Lean-side dashboard wiring (the dashboard lives in per_observable_100x_status.py).
