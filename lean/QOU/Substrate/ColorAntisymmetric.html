    QOU.Substrate.ColorAntisymmetric #

    Substrate-level implementation of QCD color-singlet → sign rep of S_3 on color labels. Per PR #1654 Item B reframing of the m_p sign-block hypothesis open work:

    (a) Substrate-level implementation of QCD color-singlet (Fermi statistics → sign rep of S_3 on color labels).

    This module lands the first Lean scaffold for this multi-session categorical work. It encodes the structural facts that can be formalized now without the full categorical machinery:

    1. Sign rep of S_3 is 1-dimensional (mirroring trivial rep, both have Plancherel weight 1/6).
    2. Sign rep is the unique 1-dim block antisymmetric under the transposition action of S_3.
    3. A "color singlet" structure on 3 strands is conjecturally a Fermi-statistics-correct categorification of QCD color antisymmetry.

    def QOU.Substrate.ColorAntisymmetric.signPlancherelWeight (n : ℕ) :
    ℚ

    The Plancherel weight of the sign rep of S_n equals 1/n!. Since the sign rep is 1-dimensional, P_(sign) = 1²/n! = 1/n!.

      class QOU.Substrate.ColorAntisymmetric.FermiColorSinglet (Baryon : Type u_1) :
      Type u_1

      Conjectural placeholder class: substrate-level QCD color singlet.

      Per AGENTS.md §3b-cond: this class axiomatizes the conjecture that the proton (uud baryon) wave function on 3 color strands is fully antisymmetric (Fermi statistics), making the COLOR action lie in the sign rep V_(1,1,1) of S_3.

      NO INSTANCE is provided — the class IS the conjecture. The full categorical derivation requires multi-session substrate-level work that does not yet exist (PR #1654 Item B reframing).

      Future agents pursuing the derivation should:

      1. Define the substrate analog of a "color strand"
      2. Define the substrate analog of "anti-symmetric under S_n action"
      3. Prove the proton's substrate representation is in this class

      None of these are formalized yet.

      • colorAction : Equiv.Perm (Fin 3) → Baryon → Baryon

        The baryon's color action: a permutation of the three color labels acts on the (one-dimensional) color amplitude.

      • color_in_sign_rep (b : Baryon) (i j : Fin 3) : i ≠ j → amplitude (colorAction (Equiv.swap i j) b) = -amplitude b

        Conjectural content (V_(1,1,1) sign rep). The color action is antisymmetric — every transposition Equiv.swap i j (i ≠ j) negates the color amplitude, i.e. the action carries the sign character of S_3, placing the color state in the sign rep V_(1,1,1). This is the substrate analogue of QCD color antisymmetry (Fermi statistics); the full categorical derivation is multi-session open work, so no instance is provided here.

        theorem QOU.Substrate.ColorAntisymmetric.sign_transposition_eq_neg_one {i j : Fin 3} (h : i ≠ j) :
        Equiv.Perm.sign (Equiv.swap i j) = -1

        Open-work item (2), formalized. Every transposition of three color labels acts on the sign representation of S_3 as multiplication by -1: the sign of Equiv.swap i j (for i ≠ j, i j : Fin 3) is -1. This is the representation-theoretic generator of the color antisymmetry posited by the FermiColorSinglet conjecture — proved directly from Mathlib's sign homomorphism, sorry-free.
