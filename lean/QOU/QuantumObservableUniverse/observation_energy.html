    QOU.QuantumObservableUniverse.observation_energy #

    Canonical Lean for content block prop:observation-energy: Observation increases quantum energy and deforms the action.

    Disposition (2026-07-03, bean qsb2 — restructured from a projection stub) #

    The previous encoding was a noncomputable def whose Prop-conjunction merely projected conclusion-carrying class fields (hbar_diff, hbar_diff_pos, S_deform) — the self-assuming projection forbidden by AGENTS.md §3b-cond item 5. Restructured per §1a honest dispositions:

    • Claim (i), derived sorry-free (observation_energy_hbar_diff, observation_energy_hbar_diff_pos): from the defining equation ℏ_x = 1 - x⁻¹ (field hbar_eq) and the positivity hypotheses 1 < q, 0 < δq, the difference identity ℏ_{q+δq} - ℏ_q = δq / (q(q+δq)) and its strict positivity are genuine field_simp / positivity algebra — the former conclusion fields are gone.
    • Claim (ii), split: the remainder R₂ is now defined by the class field R_2_def as the exact first-order Taylor remainder, so the deformation equation S_{q+δq} = S_q + δq·∂S/∂q + R₂(δq) is derived (trivial rearrangement, observation_energy_action_deformation). The substantive analytic content — R₂ = O(δq²), which needs second-order regularity of the categorical action 𝔖_q — is observation_energy_remainder_quadratic, now derived sorry-free conditional on that regularity: the class carries it as the C^{1,1} fields (S_hasDeriv, S'_lipschitz, L), and the O(δq²) bound then follows via the mean-value inequality.
    • Claim (iii), derived by ∃-packaging (observation_energy_classical_sign): the class carries witness data q_inc, q_dec where the classical energy respectively increases / decreases (the MassGap-style ∃-repackaging of AGENTS.md §7d U4); the theorem derives the .md claim — the classical energy is unconstrained in sign — as the existential over those witnesses.

    class QOU.QuantumObservableUniverse.ObservationEnergyContext :
    Type

    Model data for [prop:observation-energy]. All fields are inputs (defining equations, positivity hypotheses, opaque model data, sign-witness points); none carries a conclusion of the proposition.

    • q : ℝ

      Substrate parameter q : ℝ.

    • q_gt_one : 1 < q

      Substrate regime q > 1.

    • δq : ℝ

      Substrate perturbation δq.

    • δq_pos : 0 < δq

      The perturbation is positive.

    • hbar : ℝ → ℝ

      Quantum Planck constant as a function of the substrate parameter.

    • hbar_eq (x : ℝ) : hbar x = 1 - x⁻¹

      Defining equation ℏ_x = 1 - x⁻¹ ([def:quantum-planck-constant]).

    • S : ℝ → ℝ

      Categorical action q ↦ 𝔖_q ([def:categorical-action]), opaque model data.

    • dS_dq : ℝ

      First-order observation cost ∂𝔖_q/∂q, opaque model data.

    • R_2 : ℝ → ℝ

      Second-order remainder R₂.

    • R_2_def (δ : ℝ) : R_2 δ = S (q + δ) - S q - δ * dS_dq

      Defining equation: R₂(δ) is the first-order Taylor remainder of the action at q (definitional input, not a conclusion).

    • E_classical : ℝ → ℝ

      Classical energy q ↦ E_classical(q) (the q → 1 shadow of the action), opaque model data.

    • q_inc : ℝ

      Witness point where the classical energy increases under the perturbation (sign-witness data for claim (iii)).

    • q_dec : ℝ

      Witness point where the classical energy decreases under the perturbation (sign-witness data for claim (iii)).

    • E_inc : E_classical (q_inc + δq) > E_classical q_inc

      The classical energy increases at q_inc.

    • E_dec : E_classical (q_dec + δq) < E_classical q_dec

      The classical energy decreases at q_dec.

    • S' : ℝ → ℝ

      Derivative function S' = ∂𝔖/∂q of the categorical action.

    • S_hasDeriv (x : ℝ) : HasDerivAt S (S' x) x

      The action S is differentiable everywhere with derivative S'.

    • L : ℝ

      Second-order regularity constant (a Lipschitz bound on S').

    • L_nonneg : 0 ≤ L

      The regularity constant is non-negative.

    • S'_lipschitz (x : ℝ) : |x - q| ≤ δq → |S' x - dS_dq| ≤ L * |x - q|

      Second-order regularity of the action (the C^{1,1} input the O(δ²) remainder needs): S' is L-Lipschitz measured from q on the window. At x = q this forces S' q = dS_dq; away from q it bounds how fast the slope may change. This is the honest analytic hypothesis the manuscript's O((δq)²) claim rests on — an input, not the conclusion.

      Proposition ([prop:observation-energy]) — resolving declaration for the lean.ref URI qou:QOU.QuantumObservableUniverse.observation_energy.

      Conjoins the three claims: (i) the quantum Planck constant strictly increases, ℏ_{q+δq} - ℏ_q = δq/(q(q+δq)) > 0 (derived sorry-free); (ii) the action deforms as 𝔖_{q+δq} = 𝔖_q + δq·∂𝔖_q/∂q + R₂(δq) with R₂ = O(δq²) (equation derived; the quadratic bound carries the one honest sorry, see observation_energy_remainder_quadratic); (iii) the classical energy is unconstrained in sign (derived from the witnesses).
