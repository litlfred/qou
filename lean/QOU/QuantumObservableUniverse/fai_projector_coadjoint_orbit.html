    QOU.QuantumObservableUniverse.fai_projector_coadjoint_orbit #

    Canonical Lean for content block lem:fai-projector-coadjoint-orbit: Rank-1 projectors embed $\mathbb{P}(V)$ as a coadjoint orbit in $\mathrm{Ad}(A)$.

    Disposition (2026-07-03, bean qsb2 — restructured from a projection stub) #

    The previous encoding carried the entire lemma as a context-class field (twice_sigma_eq_id_of_projector) and the "theorem" merely applied that field to another field — the self-assuming projection forbidden by AGENTS.md §3b-cond item 5. The involution identity is genuinely provable, so the class is gone and the claim is now proved outright, sorry-free:

    • Formalised and proved: for an idempotent ρ (ρ * ρ = ρ) in any ring, (2ρ - 1)² = 1. Over a ℚ-algebra 2(ρ - ½·id) = 2ρ - 1, so this is exactly the manuscript's involution claim (2σ(ρ))² = id_V for the traceless component σ(ρ) = ρ - ½·id_V of a projector. The identity needs only idempotency, so per AGENTS.md §7c it is stated over a generic (noncommutative) [Ring R]; the 2-dimensional standard-representation instance is the Matrix (Fin 2) (Fin 2) ℝ corollary below.
    • Proved sorry-free (2026-07-11): the second half of the .md lemma — that σ identifies ℙ(V) ≅ G/T with a closed coadjoint orbit in Ad(A) — is proved at the archimedean matrix level as fai_projector_coadjoint_orbit_orbit: the traceless component σ(ρ) of every rank-1 projector (Hermitian idempotent of trace 1) on τ(V) = ℂ² is unitarily conjugate to the single base point σ₀ = ½·diag(1, −1), so the σ-image of ℙ(V) is one U(2)-adjoint orbit. The proof runs Mathlib's spectral theorem (Matrix.IsHermitian.spectral_theorem) and pins the two eigenvalues via the proved char-poly invariants fai_projector_sigma_trace (tr σ = 0) and fai_projector_sigma_det (det σ = −¼); the eigenvalue ordering is resolved by a u = U / u = U·swap case split. The full differential-geometric content (orbit topology, the G/T identification as a smooth homogeneous space) remains in the narrative proof block prf:fai-projector-coadjoint-orbit.

    theorem QOU.QuantumObservableUniverse.fai_projector_det_eq_zero {R : Type u_1} [CommRing R] (ρ : Matrix (Fin 2) (Fin 2) R) (hidem : ρ * ρ = ρ) (htr : ρ.trace = 1) :
    ρ.det = 0

    Orbit invariant — determinant. A rank-1 projector ρ on τ(V) = ℂ² (idempotent ρ² = ρ with tr ρ = 1, so its eigenvalues are 1, 0) has det ρ = 0. Pure Fin 2 entry algebra: the (0,0) entry of ρ² = ρ gives ρ₀₀² + ρ₀₁ρ₁₀ = ρ₀₀, and the trace gives ρ₀₀ + ρ₁₁ = 1; then det ρ = ρ₀₀ρ₁₁ − ρ₀₁ρ₁₀ = 0 by linear_combination. (This is the archimedean shadow of "a rank-1 projector is singular"; it fixes one of the two char-poly invariants that pin the coadjoint orbit.)

      theorem QOU.QuantumObservableUniverse.fai_projector_sigma_det {R : Type u_1} [Field R] [CharZero R] (ρ : Matrix (Fin 2) (Fin 2) R) (hidem : ρ * ρ = ρ) (htr : ρ.trace = 1) :
      (ρ - 2⁻¹ • 1).det = -4⁻¹

      Orbit invariant — determinant of the traceless component. For a rank-1 projector ρ on ℂ², det σ(ρ) = −¼, matching det σ₀ = −¼. Together with tr σ(ρ) = 0 this fixes both coefficients of the characteristic polynomial t² − (tr)·t + det = t² − ¼, so every σ(ρ) has the same char poly as σ₀ (eigenvalues ±½). Since a Hermitian matrix is unitarily diagonalisable and its char poly determines its spectrum, this is exactly the statement that the σ-image of ℙ(V) is a single U(2)-adjoint orbit — the conjugacy step below.

      theorem QOU.QuantumObservableUniverse.fai_projector_coadjoint_orbit_orbit (ρ : Matrix (Fin 2) (Fin 2) ℂ) (hidem : ρ * ρ = ρ) (hherm : ρ.conjTranspose = ρ) (htr : ρ.trace = 1) :
      ∃ u ∈ Matrix.unitaryGroup (Fin 2) ℂ, ρ - 2⁻¹ • 1 = u * sigmaBasePoint * star u

      Lemma ([lem:fai-projector-coadjoint-orbit], coadjoint-orbit half) — proved sorry-free.

      The traceless component σ(ρ) = ρ − ½·id_V of every rank-1 projector on the categorical-dimension-2 standard representation — archimedean realisation: a Hermitian idempotent of trace 1 on τ(V) = ℂ² — is unitarily conjugate to the single base point σ₀ = ½·diag(1, −1). Hence the σ-image of ℙ(V) is one U(2)-adjoint orbit, and σ identifies ℙ(V) ≅ G/T = U(2)/(U(1) × U(1)) with a closed coadjoint orbit in Ad(A) (the .md lemma's second half).

      Proof (spectral theorem, no sorry). By Matrix.IsHermitian.spectral_theorem, ρ = U · diagonal(eigenvalues) · U⋆ with U unitary, so σ(ρ) = U · diagonal(μ) · U⋆ for μ = eigenvalues − ½ (using U U⋆ = 1). Conjugation preserves trace and determinant, so the two proved invariants fai_projector_sigma_trace (tr σ(ρ) = 0) and fai_projector_sigma_det (det σ(ρ) = −¼) give μ₀ + μ₁ = 0 and μ₀ μ₁ = −¼; hence {μ₀, μ₁} = {½, −½}. In the case μ = (½, −½), diagonal μ = σ₀ and u = U; in the case μ = (−½, ½), diagonal μ = P σ₀ P for the swap permutation P = !![0,1;1,0] (unitary), and u = U · P. Either way σ(ρ) = u · σ₀ · star u.
