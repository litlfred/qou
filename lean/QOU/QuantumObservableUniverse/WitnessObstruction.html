    Why a QOU witness cannot be a module category #

    QOU.TrivialWitness builds a QuantumUniverse on ModuleCat R with A = 𝟙. The obvious next question is whether the same category can carry a QuantumObservableUniverse. It cannot, and this file proves why.

    The obstruction is a shape argument about two of the QOU fields, not about R or the choice of A:

    • adjoint_vanishing : Subsingleton (𝟙 ⟶ Ad(A)) — the observability axiom, "no hidden global symmetries".
    • adjoint_nontrivial : adjointIncl ≠ 0 — the field added under bean qou-fav8 to stop adjointObj := 0 satisfying the previous one vacuously.

    In a category where Hom(𝟙, −) reflects zero objects, the first forces Ad(A) to be a zero object, which forces every morphism out of it to be zero, which contradicts the second. ModuleCat R is such a category: Hom(R, W) ≅ W, so a subsingleton hom-set means W = 0 on the nose.

    What this buys #

    It is a necessary condition on any QOU witness, obtained without attempting the construction: the unit must not generate. That is exactly the property separating a representation category from a plain module category — in Rep(G), Hom(𝟙, W) = W^G can vanish for W ≠ 0, and it is what brings-qou-axiom-map.md relies on when it says Ad(A) decomposes "with no spin-0 summand".

    So [kassel1995] §IX naming Rep(SU_q(2)) is not an arbitrary choice of convenience — no module category could have worked. The formalize-first discipline applies: this prunes the search before running it.

    Scope #

    This is scope (a): it rules out module categories as QOU witnesses. It does not show a QOU exists anywhere, and it is not progress toward discharging QuantumObservableUniverse.exists_instance, whose sorry is untouched.
