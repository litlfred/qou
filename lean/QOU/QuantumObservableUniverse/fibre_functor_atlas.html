    QOU.QuantumObservableUniverse.fibre_functor_atlas #

    Canonical Lean for content block prop:fibre-functor-atlas: the transition data of a fibre-functor atlas is a G-cocycle, so its charts are identity-diagonal, its transitions are torsor inverses, and the atlas is connected.

    §3b-cond rule 5 (non-degenerate). The context class carries the single structural hypothesis — the cocycle condition g(i,k) = g(j,k)·g(i,j) — and the theorem derives the remaining three manuscript sub-claims (chart identity, torsor inverse, connectedness) from it. The class does not carry the conclusion; the proof is a genuine derivation, not a projection.

    class QOU.QuantumObservableUniverse.FibreFunctorAtlasContext (G : Type) [Group G] :
    Type 1

    Context for fibre_functor_atlas: the transition data g of a fibre-functor atlas over the Tannaka group G = Aut⊗(τ), together with the cocycle hypothesis, the single structural input from which the chart/torsor/connectedness conclusions follow.

    • FFIdx : Type

      Fibre-functor index set (indexes the chart cover).

    • g : FFIdx G → FFIdx G → G

      Transition isomorphisms g(i,j) : G for each pair of fibre functors.

    • cocycle (i j k : FFIdx G) : g i k = g j k * g i j

      Cocycle condition g(i,k) = g(j,k) · g(i,j) for every triple — the lone structural hypothesis.

      theorem QOU.QuantumObservableUniverse.fibre_functor_atlas {G : Type} [Group G] [ctx : FibreFunctorAtlasContext G] :
      (∀ (i : FibreFunctorAtlasContext.FFIdx G), FibreFunctorAtlasContext.g i i = 1) ∧ (∀ (i j : FibreFunctorAtlasContext.FFIdx G), FibreFunctorAtlasContext.g j i = (FibreFunctorAtlasContext.g i j)⁻¹) ∧ (∀ (i j k : FibreFunctorAtlasContext.FFIdx G), FibreFunctorAtlasContext.g i k = FibreFunctorAtlasContext.g j k * FibreFunctorAtlasContext.g i j) ∧ ∀ (i j : FibreFunctorAtlasContext.FFIdx G), ∃ (x : G), FibreFunctorAtlasContext.g i j = x

      Proposition (fibre-functor atlas). Let (C, A, τ) be a quantum observable universe with G = Aut⊗(τ) and fibre-functor transition data g satisfying the cocycle condition. Then the four manuscript sub-claims hold: (i) chart identity g(i,i) = 1; (ii) torsor inverse g(j,i) = g(i,j)⁻¹; (iii) the cocycle condition; (iv) connectedness.

      Claims (i), (ii), (iv) are derived from the cocycle hypothesis ctx.cocycle; only (iii) restates it.
