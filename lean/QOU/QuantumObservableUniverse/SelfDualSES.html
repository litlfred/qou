    QOU.QuantumObservableUniverse.SelfDualSES — rem:self-dual-ses, formalised #

    Bean qou-fngs. The content block rem:self-dual-ses states

    0 → Ω⁻(A) → Ω²(A) → Ω⁺(A) → 0,   Ω^± = ker(id ∓ ⋆_q)

    and had no Lean behind it — the corpus contained no exact sequence of any kind before QOU/Mathlib/LongExactSequence.lean. This file supplies the algebra: the ±1 eigenspace decomposition of an involution, and the exact sequence it produces.

    What is actually true, and where it costs something #

    Three statements, in increasing strength, because they need different hypotheses and the corpus works over a ring where the strongest one fails.

    1. Exactness is free. 0 → M⁻ → M → M ⧸ M⁻ → 0 is exact for any submodule, involution or not (minus_ses_exact). Writing the sequence down proves nothing.
    2. Disjointness needs 2-torsion-freeness. An element both self-dual and anti-self-dual satisfies x = −x, so it vanishes only if M has no 2-torsion (disjoint_plus_minus). Carried as a hypothesis, not assumed via a field — the same discipline as BarGradedCollapse.
    3. The splitting needs 2 to be invertible (isCompl_plus_minus), because it is literally x = ½(x + ⋆x) + ½(x − ⋆x). Only then is the quotient M ⧸ M⁻ identified with M⁺ (quotMinusEquivPlus), which is what the block's arrow Ω²(A) → Ω⁺(A) means.

    Point 3 fails over R_q = ℤ[q, q⁻¹]. 2 is not invertible there: R_q is ℤ[ℤ], its units are ± q^n, and 2 is none of them. So the self-dual splitting is not available over the ground ring — it is available after inverting 2, or in the archimedean realisation over ℝ that the block's second sentence describes. The block reads as though the splitting were unconditional; it is not, and the condition is exactly the one that separates its two sentences.

    The same structure as the bar involution #

    BarGradedCollapse.IsEven/IsOdd for q ↦ q⁻¹ and IsSelfDual/IsAntiSelfDual for ⋆_q are the same definition — the ±1 eigenspaces of an involution — and eq_zero_of_even_and_odd is disjoint_plus_minus under another name. isSelfDual_iff_fixed and isAntiSelfDual_iff_negated record the identification as checkable statements rather than leaving it as prose: it means a parity-collapse argument and a self-duality argument are one argument, and either file's hypotheses can be discharged by the other's.
