    structure QOU.FrobeniusHopfData (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] :
    Type (max u v)

    Frobenius–Hopf data in a monoidal category.

    An object A equipped with a Hopf algebra structure (μ, η, Δ, ε, S) and a Frobenius form λ : A → 𝟙 such that the pairing A ⊗ A → μ → A → λ → 𝟙 is non-degenerate and the Frobenius relation holds.

    LaTeX: used in \label{def:quantum-universe}, item (ii). Ref: [kock2004]

    • obj : C

      The underlying object in C.

    • mul : CategoryTheory.MonoidalCategoryStruct.tensorObj self.obj self.obj ⟶ self.obj

      Multiplication morphism μ : A ⊗ A → A.

    • unit : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ self.obj

      Unit morphism η : 𝟙 → A.

    • comul : self.obj ⟶ CategoryTheory.MonoidalCategoryStruct.tensorObj self.obj self.obj

      Comultiplication morphism Δ : A → A ⊗ A.

    • counit : self.obj ⟶ CategoryTheory.MonoidalCategoryStruct.tensorUnit C

      Counit morphism ε : A → 𝟙.

    • antipode : self.obj ⟶ self.obj

      Antipode morphism S : A → A.

    • frobeniusForm : self.obj ⟶ CategoryTheory.MonoidalCategoryStruct.tensorUnit C

      Frobenius form λ : A → 𝟙.

    • coevaluation : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ CategoryTheory.MonoidalCategoryStruct.tensorObj self.obj self.obj

      Coevaluation morphism η̃ : 𝟙 → A ⊗ A, the dual datum to the evaluation ev = μ ≫ λ : A ⊗ A → 𝟙. Together with ev, this exhibits A as self-dual in the monoidal category C.

    • pairing_snake_left : CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.rightUnitor self.obj).inv (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.coevaluation) (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).inv (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight (CategoryTheory.CategoryStruct.comp self.mul self.frobeniusForm) self.obj) (CategoryTheory.MonoidalCategoryStruct.leftUnitor self.obj).hom))) = CategoryTheory.CategoryStruct.id self.obj

      Snake identity (left). The composite A →[ρ⁻¹] A ⊗ 𝟙 →[A ◁ coev] A ⊗ (A ⊗ A) →[α⁻¹] (A ⊗ A) ⊗ A →[ev ▷ A] 𝟙 ⊗ A →[λ_] A equals id_A, where ev = μ ≫ λ. This is one half of the exact self-pairing making A self-dual.

    • pairing_snake_right : CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.leftUnitor self.obj).inv (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.coevaluation self.obj) (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).hom (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj (CategoryTheory.CategoryStruct.comp self.mul self.frobeniusForm)) (CategoryTheory.MonoidalCategoryStruct.rightUnitor self.obj).hom))) = CategoryTheory.CategoryStruct.id self.obj

      Snake identity (right). The composite A →[λ_⁻¹] 𝟙 ⊗ A →[coev ▷ A] (A ⊗ A) ⊗ A →[α] A ⊗ (A ⊗ A) →[A ◁ ev] A ⊗ 𝟙 →[ρ_] A equals id_A.

    • frobenius_relation : CategoryTheory.CategoryStruct.comp self.mul self.comul = CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.comul self.obj) (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).hom (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.mul))

      Frobenius relation: μ ≫ Δ = (Δ ▷ A) ≫ α ≫ (A ◁ μ). Comultiplication is a bimodule map — the defining axiom of a Frobenius object in a monoidal category.

    • one_mul : CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.unit self.obj) self.mul = (CategoryTheory.MonoidalCategoryStruct.leftUnitor self.obj).hom

      Left unit law. η ▷ A ≫ μ = λ_A. Axiom 1 of def:frobenius-hopf-substrate says (μ, η) make A an associative unital algebra object; this is half of "unital".

      Field shape matches CategoryTheory.MonObj.one_mul exactly, so toMonObj is a field-for-field transport.

    • mul_one : CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.unit) self.mul = (CategoryTheory.MonoidalCategoryStruct.rightUnitor self.obj).hom

      Right unit law. A ◁ η ≫ μ = ρ_A. The other half of "unital".

    • mul_assoc : CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.mul self.obj) self.mul = CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).hom (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.mul) self.mul)

      Associativity. (μ ▷ A) ≫ μ = α ≫ (A ◁ μ) ≫ μ — the "associative" of axiom 1. Matches CategoryTheory.MonObj.mul_assoc.

    • counit_comul : CategoryTheory.CategoryStruct.comp self.comul (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.counit self.obj) = (CategoryTheory.MonoidalCategoryStruct.leftUnitor self.obj).inv

      Left counit law. Δ ≫ ε ▷ A = λ_A⁻¹. Axiom 2 says (Δ, ε) make A a coassociative counital coalgebra object; this is half of "counital". Matches CategoryTheory.ComonObj.counit_comul.

    • comul_counit : CategoryTheory.CategoryStruct.comp self.comul (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.counit) = (CategoryTheory.MonoidalCategoryStruct.rightUnitor self.obj).inv

      Right counit law. Δ ≫ A ◁ ε = ρ_A⁻¹.

    • comul_assoc : CategoryTheory.CategoryStruct.comp self.comul (CategoryTheory.MonoidalCategoryStruct.whiskerLeft self.obj self.comul) = CategoryTheory.CategoryStruct.comp self.comul (CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.whiskerRight self.comul self.obj) (CategoryTheory.MonoidalCategoryStruct.associator self.obj self.obj self.obj).hom)

      Coassociativity. The "coassociative" of axiom 2. Matches CategoryTheory.ComonObj.comul_assoc.

    • antipode_anti_mul : CategoryTheory.CategoryStruct.comp self.mul self.antipode = CategoryTheory.CategoryStruct.comp (CategoryTheory.MonoidalCategoryStruct.tensorHom self.antipode self.antipode) (CategoryTheory.CategoryStruct.comp (β_ self.obj self.obj).hom self.mul)

      Antipode axiom 1 — S reverses multiplication. μ ≫ S = (S ⊗ S) ≫ β ≫ μ, in elements S(ab) = S(b)S(a).

      This is the braiding-carrying half of the antipode package and is why the structure now requires [BraidedCategory C]: "reverses" is not statable without a way to exchange the two tensor factors. That is no new demand on the framework — def:frobenius-hopf-substrate already says the substrate is available at the level of a quantum universe, and def:quantum-universe is braided monoidal.

      This axiom family REPLACED the convolution condition on 2026-09-15 (owner decision, beans qou-c64q / qou-aawz). See the module docstring of QOU.QuantumObservableUniverse.FrobeniusHopfModelDichotomy for why: the convolution condition Δ ≫ (S ▷ A) ≫ μ = ε ≫ η — which is Mathlib's HopfObj.antipode_left, and which this structure carried from 2026-09-14 to 2026-09-15 — has no non-trivial model over a field. It is not merely unsatisfied by the natural candidates; it forces dim A ≤ 1.

      The three theorems recording that are not deleted. They are restated to take the convolution condition as an explicit hypothesis rather than to read it off a field, which is strictly stronger: they now constrain any morphism satisfying it, not only a structure that declares it.

    • antipode_anti_comul : CategoryTheory.CategoryStruct.comp self.antipode self.comul = CategoryTheory.CategoryStruct.comp self.comul (CategoryTheory.CategoryStruct.comp (β_ self.obj self.obj).hom (CategoryTheory.MonoidalCategoryStruct.tensorHom self.antipode self.antipode))

      Antipode axiom 2 — S reverses comultiplication. S ≫ Δ = Δ ≫ β ≫ (S ⊗ S), in elements Δ(S x) = Σ S(x₂) ⊗ S(x₁).

    • antipode_unit : CategoryTheory.CategoryStruct.comp self.unit self.antipode = self.unit

      Antipode axiom 3 — S fixes the unit. η ≫ S = η.

    • antipode_counit : CategoryTheory.CategoryStruct.comp self.antipode self.counit = self.counit

      Antipode axiom 4 — S preserves the counit. S ≫ ε = ε.

    • antipode_involutive : CategoryTheory.CategoryStruct.comp self.antipode self.antipode = CategoryTheory.CategoryStruct.id self.obj

      Antipode axiom 5 — S is involutive. S ≫ S = 𝟙_A.

      On its own this pins nothing: S = 𝟙_A satisfies it, measured on S₃ and D₄ as well as on every abelian group tested (computations/probes/frobenius_hopf_intermediate_axioms_probe.py). It earns its place only alongside antipode_anti_mul, which 𝟙_A fails whenever A is non-commutative.

    • antipode_frobeniusForm : CategoryTheory.CategoryStruct.comp self.antipode self.frobeniusForm = self.frobeniusForm

      Antipode axiom 6 — S preserves the Frobenius form. S ≫ λ = λ, so the pairing ⟨a, b⟩ = λ(ab) is S-invariant.

            structure QOU.QuantumUniverse (R : Type u_1) [CommRing R] :
            Type (max (max (max (max (u + 1) u_1) (u_2 + 1)) (u_3 + 1)) (v + 1))

            Quantum Universe over a commutative ring R.

            A triple (C, A, ω) where C is a k-linear braided monoidal category, A is a Frobenius–Hopf object in C, and ω is a fibre functor. The deformation parameter q is not part of the base definition; it enters via the substrate parameter (Definition 1.x, ArchimedeanSubstrateField).

            Rigidity is deliberately absent here. A quantum universe is braided but need not have duals; duals are imposed one level up, on QuantumObservableUniverse, where they carry the antiparticles and permit a strand to close into a knot. Do not add a RigidCategory instance to this structure.

            LaTeX: \label{def:quantum-universe}

            • C : Type u

              The monoidal category C. Represented as an opaque type with Category and MonoidalCategory instances.

            • catInst : CategoryTheory.Category.{v, u} self.C
            • monInst : CategoryTheory.MonoidalCategory self.C
            • preInst : CategoryTheory.Preadditive self.C

              Hom-sets are abelian groups. Carried because the paper's R-linearity (below) presupposes it, and because two axiom-4 fields need it: the zero morphism for block orthogonality, and a finite sum for block completeness.

              Note this REPLACES a bare HasZeroMorphisms field. Preadditive supplies zero morphisms already, so carrying both would put two HasZeroMorphisms instances on C and make p_b ≫ p_b' = 0 ambiguous.

            • linInst : CategoryTheory.Linear R self.C

              C is R-linear. Every hom-set is an R-module and composition is R-bilinear — verbatim def:rigid-monoidal-category, and what def:quantum-universe means by "an R-linear braided monoidal category".

              This is CategoryTheory.Linear, which takes Preadditive as a prerequisite; the two are a stack, not alternatives.

            • braidedInst : CategoryTheory.BraidedCategory self.C

              Temporal braiding. The exchange of two adjacent systems is a process with a direction: c_{V,W} : V ⊗ W ≅ W ⊗ V, not required to be symmetric. The hexagon identities are part of the class, and are what make an interaction independent of the order in which its pairwise crossings are written.

            • balancedInst : MathlibExt.BalancedCategory self.C

              The balancing twist θ_X : X ⟶ X (axiom 1, categorical half).

              This is what makes the substrate parameter q derivable rather than carried. On the defining representation the twist axiom forces θ_V = q^{1/2} · id_V (rem:sqrt-q-ribbon-structure), so q is read off the structure; there is deliberately no q field, since a distinguished element would smuggle in as data the thing the framework claims to derive.

              Three further things it supplies, none of which the previous [BraidedCategory] alone gave:

              1. Framing. Without a twist a braid closure is only a framed link invariant — tr_M(β) depends on the writhe of the braid word rather than on the knot. Since masses are read off knots, that dependence would be fatal.
              2. Sphericality on all of C. Axiom 3 gives left-trace = right-trace on End(A) only, but the Markov trace closes strands of V^{⊗n}, not of A. Ribbon = braided + spherical extends it to the objects the knot theory actually uses.
              3. A legible classical boundary. BalancedCategory.ofSymmetric proves every symmetric category is balanced with θ = 𝟙, so the classical case is θ = 𝟙, i.e. q = 1 — a describable member, not an excluded one. This is why the fix is "add the twist", not "forbid symmetric": q → 1 must stay inside the category it is a limit of.

              Uses the in-repo BalancedCategory (bean rtrb, sorry-free) since Mathlib has no ribbon layer.

            • frobHopf : FrobeniusHopfData self.C

              The Frobenius–Hopf object A in C.

            • fibreFunctor : CategoryTheory.Functor self.C (Type u_2)

              The fibre functor τ : C → Type* (abstracting Vect_R / R-Mod). The paper asks for it to be exact, faithful, R-linear and monoidal; NONE of those four is carried by this type, which is a bare functor to Type. Recorded rather than silently implied — the gap is real and separate from the R-linearity of C now carried above.

            • frobenius_symmetric (f : self.frobHopf.obj ⟶ self.frobHopf.obj) : self.frobHopf.leftTrace f = self.frobHopf.rightTrace f

              Symmetric Frobenius (axiom 3). A closed loop has one amplitude: closing a worldline on the left and closing it on the right compute the same endomorphism of the unit. Equivalently, the Frobenius form ∫_A is symmetric and the Nakayama automorphism is trivial.

              This is a genuine restriction, not a consequence of axiom 2: a Frobenius algebra whose form is non-symmetric has leftTrace ≠ rightTrace, and then "the trace of a process" — hence any mass read off a trace — would depend on a drawing convention.

            • unitEndEquiv : R ≃+* CategoryTheory.End (CategoryTheory.MonoidalCategoryStruct.tensorUnit self.C)

              The ground ring is End(𝟙_C). The block data below lands in R rather than in End(𝟙_C), which presumes the two agree. That is a genuine extra assumption, NOT a consequence of R-linearity: Linear R C supplies only a ring map R → End(𝟙_C), r ↦ r • 𝟙, and its being bijective needs 𝟙 simple. Carried explicitly so the assumption is visible instead of hiding in a docstring.

              Surfaced on the paper side in def:quantum-universe.

            • blocks : Type v

              Wedderburn semisimplicity (axiom 4). The substrate has channels: A decomposes into finitely many blocks that do not mix, and no block is degenerate.

              Encoded here: a Fintype of blocks, an idempotent endomorphism of A per block, their mutual orthogonality, their completeness, and invertibility of each block's Frobenius weight and quantum dimension.

              blocks indexes the NON-NEGLIGIBLE blocks, and vanishing elsewhere is permitted. dimQ_isUnit below is therefore a specification of what blocks ranges over, NOT a prohibition on the ambient category. This matters at a root of unity (and in char p), where some dim_q(λ) really does vanish: those λ are negligible — they form a tensor ideal, the categorical trace kills anything factoring through them, and the standard construction quotients by that ideal (semisimplification) before reading off blocks. Read as a prohibition, the field would exclude the root-of-unity categories outright; read as an index specification, it says the decomposition is that of the semisimplified quotient.

              The corpus already relies on this shape elsewhere: y_(1^3) ≡ 0 in h3-markov-wenzl-weights (the Temperley-Lieb quotient kills the 3-row partition), and tr_M = Σ_λ y_λ χ^λ sums over all λ with zero weights on some. That vanishing is a DIFFERENT mechanism from negligibility — a row cap at generic q, not a root-of-unity phenomenon — but it is the same pattern, and it is why no sum over blocks needs re-indexing here.

              Orthogonality needs a zero morphism and completeness needs a finite sum; both come from the Preadditive instance field above.

              frobWeight and dimQ land in R via unitEndEquiv, which is carried as a field rather than left to a docstring — see its comment for why R-linearity alone does not supply it (bean qou-w1g8).

              Given this axiom, the co-Casimir trace identity tr_M(C_dimQ) = Σ_λ 1/dim_q(λ) is a consequence, proved as QOU.BraidKnot.frobenius_codim_universal by linearity of the trace over the central idempotents. It is deliberately NOT an axiom here: asserting it would assert something already proved, and would collide with the unrelated def:mass-identity (the vortex integral).

            • blocksFintype : Fintype self.blocks
            • centralIdem : self.blocks → (self.frobHopf.obj ⟶ self.frobHopf.obj)

              The central idempotent p_λ of each block.

            • centralIdem_idem (b : self.blocks) : CategoryTheory.CategoryStruct.comp (self.centralIdem b) (self.centralIdem b) = self.centralIdem b

              Each p_λ is idempotent.

            • centralIdem_orthogonal (b b' : self.blocks) : b ≠ b' → CategoryTheory.CategoryStruct.comp (self.centralIdem b) (self.centralIdem b') = 0

              Blocks do not mix. Distinct central idempotents are orthogonal, so a state resolving into one channel has no component in another. This is the half of semisimplicity that costs only a zero morphism.

            • centralIdem_complete : ∑ b : self.blocks, self.centralIdem b = CategoryTheory.CategoryStruct.id self.frobHopf.obj

              The blocks span. Σ_λ p_λ = 𝟙_A: every state resolves into the channels, with nothing left over. Together with orthogonality this is what "Wedderburn decomposition" means; without it the blocks could sit inside A without exhausting it.

              This is the field the axiom's NAME promised and its TYPE did not deliver. It needs the finite sum that Preadditive supplies.

            • frobWeight : self.blocks → R

              The Frobenius weight ∫_A p_λ of each block.

            • frobWeight_isUnit (b : self.blocks) : IsUnit (self.frobWeight b)

              Every block's Frobenius weight is a unit: none is invisible to the trace. IsUnit, not ≠ 0 — the paper says "invertible in R", and over a ring those differ (2 ≠ 0 in ℤ, and 2 is not a unit). The two coincide only over a field, which is why ≠ 0 survived while the base ring was one.

            • dimQ : self.blocks → R

              The quantum dimension dim_q(λ) of each block.

            • dimQ_isUnit (b : self.blocks) : IsUnit (self.dimQ b)

              Every block's quantum dimension is a unit: each can be normalised against. IsUnit for the same reason as frobWeight_isUnit.

            • differentialForms : Type u_3

              A admits a differential calculus: the module of Kähler differentials Ω¹(A) exists in C. Represented abstractly as a type (the carrier of Ω¹(A)).

              structure QOU.QuantumObservableUniverse (R : Type u_1) [CommRing R] extends QOU.QuantumUniverse R :
              Type (max (max (max (max (u + 1) u_1) (u_2 + 1)) (u_3 + 1)) (v + 1))

              Quantum Observable Universe over a commutative ring R.

              A quantum universe that is rigid and satisfies three observability conditions: (0) rigidity: every object has a dual. This is the antiparticle condition — a dual is a worldline read backwards, ev and coev are pair annihilation and creation — and it is what lets a strand bend back on itself, hence what lets a braid close into a knot. It is imposed here rather than on QuantumUniverse. (i) the Frobenius form on A is non-degenerate — an exact self-pairing, already enforced structurally by the snake identities in FrobeniusHopfData. (ii) Hom_C(𝟙, Ad(A)) is trivial — no non-trivial invariant adjoint morphisms. (iii) categorical volume constraint: the fundamental object V of categorical dimension 2 admits a non-degenerate epimorphism ε : Λ²V → 𝟙 preserved by the rigid dualities. Formalised below under the strong (iso) reading — see the fields.

              • rigidInst : CategoryTheory.RigidCategory self.C

                Rigidity (condition 0): every object of C has left and right duals, with ev/coev satisfying the snake identities.

              • adjointObj : self.C

                The adjoint object Ad(A) in C, carrying the adjoint action of the Hopf algebra A on itself. In a braided monoidal category it is constructed from (A, μ, Δ, S) and the braiding; that construction is not available here, so the object is provided together with the three fields below, which pin down enough of its relationship to A that a degenerate choice cannot satisfy them.

                This was previously a free field, with nothing linking it to frobHopf. That made adjoint_vanishing satisfiable by taking adjointObj := 0 — the zero object has Hom(𝟙, 0) = 0 trivially — so an instance could satisfy "no hidden global symmetries" by having no adjoint object at all. See bean qou-fav8.

              • adjointIncl : self.adjointObj ⟶ self.frobHopf.obj

                Ad(A) sits inside A. The adjoint action is an action of A on itself, so its carrier is part of A rather than an unrelated object.

              • adjoint_mono : CategoryTheory.Mono self.adjointIncl

                The inclusion is a subobject inclusion.

              • adjoint_augmented : CategoryTheory.CategoryStruct.comp self.adjointIncl self.frobHopf.counit = 0

                Ad(A) carries no trivial summand: it lands in ker ε.

                This is what makes condition (ii) a statement with content. The full A always contains the unit η : 𝟙 → A, so Hom(𝟙, A) = 0 is false for any nontrivial A and cannot be what the axiom means. The corpus is explicit that the trivial part is excluded: Ad(A) decomposes "with no spin-0 summand" (brings-qou-axiom-map.md) and is ≅ V₂, the 3-dimensional traceless part, for SU_q(2) (brings-is-qou.lean). That reduced adjoint is the augmentation ideal ker ε, which the adjoint action preserves because ε is an algebra map.

              • adjoint_nontrivial : self.adjointIncl ≠ 0

                Ad(A) is not the zero object. Together with the two fields above this is what adjointObj := 0 fails: the only morphism out of the zero object is zero.

              • adjoint_vanishing : Subsingleton (CategoryTheory.MonoidalCategoryStruct.tensorUnit self.C ⟶ self.adjointObj)

                Adjoint vanishing (condition ii): all morphisms 𝟙 → Ad(A) in C are equal. In an R-linear category this is equivalent to Hom_C(𝟙, Ad(A)) = 0, since the zero morphism is always present and all others must equal it.

                Read with the three fields above, this now says what the paper says: the reduced adjoint has no invariants.

              • fundamentalObj : self.C

                The fundamental object V of categorical dimension 2.

              • exteriorSquare : self.C

                The exterior square Λ²V as an object of C.

                This was previously a free field, with nothing tying it to fundamentalObj — so condition (iii) said nothing about V at all. The two fields below present it as a quotient of V ⊗ V, which is the weakest true statement that makes it Λ² of something rather than an arbitrary object. Same defect and same repair as adjointObj above; see bean qou-n1dj item 3.

              • exteriorSquareProj : CategoryTheory.MonoidalCategoryStruct.tensorObj self.fundamentalObj self.fundamentalObj ⟶ self.exteriorSquare

                The antisymmetrisation π : V ⊗ V ↠ Λ²V. The corpus writes this arrow with a two-headed ↠ in VolumeFromRigidity.projection and in lem:volume-from-rigidity; the next field is that ↠.

              • exteriorSquare_epi : CategoryTheory.Epi self.exteriorSquareProj

                Λ²V is a quotient of V ⊗ V.

                Deliberately no eigenvalue condition on the braiding. In a braided category the braiding acts on the q-exterior square by -q⁻¹, not by -1, so demanding β ≫ π = -π would silently impose q = 1 and rule out the quantum group the framework is about.

              • volumeIso : self.exteriorSquare ≅ CategoryTheory.MonoidalCategoryStruct.tensorUnit self.C

                Volume constraint (condition iii), under the strong (iso) reading: ε : Λ²V ≅ 𝟙.

                def:quantum-observable-universe writes "non-degenerate epimorphism", which admits two readings of unequal strength (VolumeConstraintForcesFibreTwo.lean):

                reading dimension statement forces
                epi onto 𝟙 C(N,2) ≠ 0 N ≥ 2 — admits the colour fibre N = 3
                iso Λ²V ≅ 𝟙 C(N,2) = 1 N = 2

                The iso is taken because it is the reading under which the axiom does the job the corpus proof asks of it: det(g) is the scalar by which g acts on the top exterior power, so a constraint on Λ²V is a determinant constraint exactly when 2 = N. Under the weak reading ε constrains the second elementary symmetric function of the eigenvalues and the step to det(g_V) = 1 does not go through.

                This also removes the vacuity: the previous field was a bare morphism, and QuantumUniverse supplies Preadditive C, so volumeForm := 0 inhabited it for any exteriorSquare. An iso cannot be zero unless the base ring is trivial — volumeForm_ne_zero below.
