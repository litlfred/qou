    Every model of FrobeniusHopfData is trivial, in the linear setting #

    QOU.FrobeniusBialgebraCollapse proves ε(1)·x = ε(x)·1 (scalar_id_eq_counit_unit) and reads off one consequence: if ε(1) = 1 then A ≅ 𝟙_C. This file pushes the same identity the other way and finds that the escape it seemed to leave open is not one.

    The dichotomy #

    Write σ = η ≫ ε : 𝟙_C ⟶ 𝟙_C for the scalar ε(1).

    • id_factors_through_unitCounit — the identity on A factors through a morphism carrying σ in the middle. No hypothesis.
    • retract_of_unit_of_isIso — if σ is invertible, A is a retract of the tensor unit.
    • id_eq_zero_of_unitCounit_eq_zero — if σ = 0, then 𝟙_A = 0, so A is a zero object. Needs MonoidalPreadditive, and nothing else.

    In a preadditive monoidal category whose scalars End (𝟙_C) form a field — ModuleCat k, FdRep k G, any k-linear abelian monoidal category with simple unit — every σ is either 0 or invertible, so every FrobeniusHopfData has A a zero object or a retract of 𝟙_C.

    dichotomy_of_scalars_field states exactly that, taking the field property as the hypothesis ∀ σ, σ = 0 ∨ IsIso σ rather than importing a field structure, so it applies wherever that disjunction holds.

    What this answers, and what it does not #

    Bean qou-aawz asked for one of two outcomes: exhibit a non-trivial FrobeniusHopfData, or prove the current axioms already force A = 𝟙. This is the second outcome, restricted to the linear setting, and it supersedes the narrower reading recorded on 2026-09-15 — that a non-trivial model merely needs a non-unital counit. It needs more than that: it needs ε(1) to be neither invertible nor zero, which no field permits.

    Two limits, both real:

    1. The zero case needs MonoidalPreadditive. Over a bare monoidal category σ = 0 is not even statable, and this file proves nothing there. Whether a non-linear monoidal category admits a non-trivial model is open.
    2. A retract of 𝟙_C need not be 𝟙_C. It is when the unit is indecomposable, which holds in ModuleCat k and in every category with simple unit, but "retract of the unit" is the honest general conclusion and is what is stated.

    Why this is not a defect to be repaired #

    It is the classical fact, made exact. A finite-dimensional Hopf algebra is Frobenius, but its Frobenius comultiplication is not its Hopf comultiplication. def:frobenius-hopf-substrate axiom 3 fixes Δ as the Frobenius one and axiom 2 now demands an antipode against that Δ — so the two are being forced to coincide, and the collapse is what that costs.

    The group algebra is the worked case. k[G] with the dual-basis Frobenius comultiplication has Δ(1) = Σ_h h ⊗ h⁻¹, so the convolution of S(g) = g⁻¹ with the identity sends 1 ↦ Σ_h h⁻², which equals 1 only for the trivial group. It is a Frobenius algebra and a Hopf algebra and satisfies neither antipode axiom here, for exactly the reason this file records.

    References #

    • [kock2004] J. Kock, Frobenius Algebras and 2D TQFTs, CUP 2004.
    • [kassel1995] C. Kassel, Quantum Groups, Springer 1995, Ch. III.

    The dichotomy #

    source
    theorem QOU.FrobeniusHopfData.dichotomy_of_scalars_field {C : Type u} [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] (F : FrobeniusHopfData C) [CategoryTheory.Preadditive C] [CategoryTheory.MonoidalPreadditive C] (hconv : F.ConvolutionLeft) (hscal : ∀ (σ : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ CategoryTheory.MonoidalCategoryStruct.tensorUnit C), σ = 0 ∨ CategoryTheory.IsIso σ) :
    CategoryTheory.CategoryStruct.id F.obj = 0 ∨ ∃ (i : F.obj ⟶ CategoryTheory.MonoidalCategoryStruct.tensorUnit C) (r : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ F.obj), CategoryTheory.CategoryStruct.comp i r = CategoryTheory.CategoryStruct.id F.obj

    No non-trivial model, when the scalars form a field.

    The hypothesis hscal is exactly "End (𝟙_C) has no non-zero non-invertible element", which holds in ModuleCat k for k a field and in any k-linear category with simple unit. It is taken as a hypothesis rather than derived from a field instance so that the statement applies wherever the disjunction does.

    The conclusion: A is a zero object, or a retract of 𝟙_C. There is no third case, and in particular no non-trivial substrate.

    This is the negative answer to bean qou-aawz in the linear setting. It is silent about a bare monoidal category, where σ = 0 is not statable.
