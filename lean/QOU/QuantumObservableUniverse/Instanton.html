    structure QOU.CategoricalQExtDeriv (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] :
    Type (max u v)

    Categorical q-deformed exterior derivative.

    On a quantum observable universe with weight decomposition π_H, π_V and substrate parameter q, the q-deformed exterior derivative is d_q = q⁻¹ d + (1 − q⁻¹) π_V ∘ d.

    LaTeX: \label{def:categorical-q-ext-deriv}

    • frobHopf : FrobeniusHopfData C

      The Frobenius–Hopf object A in C.

    • d_classical : self.frobHopf.obj ⟶ self.frobHopf.obj

      The classical differential d : Ωᵏ(A) → Ωᵏ⁺¹(A).

    • proj_V : self.frobHopf.obj ⟶ self.frobHopf.obj

      The vertical projection π_V.

    • q : GroundRing.R_q

      The deformation parameter q, over the formal ground ring.

      Was q : ℝ. def:substrate-parameter puts the deformation parameter in End(𝟙) ≅ R_q, not in ℝ, and the co-located sibling had already made the move (bean qou-u87j); this copy is the one that had not.

    • qinv : GroundRing.R_q

      A two-sided inverse for q, carried as data.

      R_q = ℤ[q, q⁻¹] is a ring, not a field: it has no Inv instance, so q⁻¹ cannot be written even though the indeterminate is invertible in it. Carrying the inverse explicitly, with its defining relation below, is strictly stronger than the q_ne_zero it replaces — over a ring, invertible is not implied by nonzero. And the block needs the stronger form: d_q = q⁻¹ d + (1 − q⁻¹) π_V ∘ d requires q⁻¹ to exist, which q ≠ 0 does not give.

    • q_mul_qinv : self.q * self.qinv = 1

      qinv is the inverse of q. Replaces the former q_ne_zero.

    • proj_V_idem : CategoryTheory.CategoryStruct.comp self.proj_V self.proj_V = self.proj_V

      Idempotency of the vertical projection: π_V ∘ π_V = π_V.

          structure QOU.CategoricalInstanton {C : Type u} [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] (fh : FrobeniusHopfData C) :
          Type v

          Categorical instanton: a connection whose curvature is self-dual with respect to the q-Hodge star ⋆_q.

          LaTeX: \label{def:categorical-instanton}

          • connection : fh.obj ⟶ fh.obj

            The connection morphism ∇ : A → A ⊗ Ω¹(A) (represented as endo).

          • curvature : fh.obj ⟶ fh.obj

            The curvature F_∇ = ∇² : A → Ω²(A) (represented as endo).

          • hodge : CatHodgeInvolution fh.obj

            The q-Hodge star involution on Ω²(A).

          • self_dual : self.hodge.IsSelfDual self.curvature

            Self-duality: ⋆_q(F_∇) = F_∇.

          Instances For

            Lemma (Irreducibility from observability). LaTeX: \label{lem:categorical-irreducible}

            A categorical instanton forces the adjoint hom-space Hom(𝟙, Ad(A)) = 0: any anti-self-dual connection must be the zero connection, so there are no non-trivial adjoint-valued observables.

            Axiom justification: requires encoding the adjoint representation Ad(A) = A ⊗ A^∨ as a categorical construction and deriving Hom(𝟙, Ad(A)) = 0 from self-duality of the curvature. The adjoint-rep functor (internal End) is not yet in Mathlib for general monoidal categories.

            Classical counterpart: Donaldson–Kronheimer, The Geometry of Four-Manifolds, §4.2 (irreducibility of anti-self-dual connections).

            References:

            • [manuscript] §1-quantum-observable-universe
            • [donaldson1990] https://doi.org/10.1093/oso/9780198535539.001.0001

            class QOU.HasCategoricalIrreducibility {C : Type u} [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] {frobHopf : FrobeniusHopfData C} (adjointObj : C) (adjointInclusion : adjointObj ⟶ frobHopf.obj) (_inst : CategoricalInstanton frobHopf) :
            Prop

            Categorical irreducibility — hypotheses of the manuscript proof.

            Carries the two inputs of the argument in [prf:categorical-irreducible], parameterised by the inclusion ι : Ad(A) ↪ A of the adjoint object (A is self-dual, so A ⊗ A^∨ ≃ A ⊗ A; ι is the trace-free part sitting inside it):

            • trace-freeness — ∫_A vanishes on Ad(A), so it cannot separate two morphisms 𝟙 → Ad(A);
            • non-degeneracy — the observability axiom, stated as Mono (ι ≫ ∫_A).

            Neither field is the conclusion Subsingleton (𝟙 ⟶ Ad(A)); the conclusion is derived from them in categorical_irreducible by cancelling the mono. They are of course jointly equivalent to it — that is what it means for the manuscript proof to be correct — but the equivalence runs through the cancellation step, which is the argument. Compare the field this class used to carry, which was the conclusion verbatim (see the removal note below).

            Stated in zero-free form (s ≫ f = t ≫ f rather than s ≫ f = 0) because C is not assumed to have zero morphisms.

            • form_indistinguishes (s t : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ adjointObj) : CategoryTheory.CategoryStruct.comp s (CategoryTheory.CategoryStruct.comp adjointInclusion frobHopf.frobeniusForm) = CategoryTheory.CategoryStruct.comp t (CategoryTheory.CategoryStruct.comp adjointInclusion frobHopf.frobeniusForm)

              Trace-freeness of Ad(A). Ad(A) is the trace-free part of A ⊗ A^∨, so the Frobenius form ∫_A restricted along ι does not distinguish morphisms out of the unit: ∫_A ∘ ι ∘ s = ∫_A ∘ ι ∘ t for all s, t : 𝟙 → Ad(A).

            • form_mono : CategoryTheory.Mono (CategoryTheory.CategoryStruct.comp adjointInclusion frobHopf.frobeniusForm)

              Non-degeneracy of ∫_A (observability axiom). The restricted form ι ≫ ∫_A is a monomorphism.

              theorem QOU.categorical_dq_squared_classical_limit {C : Type u} [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] [CategoryTheory.Preadditive C] [CategoryTheory.Linear GroundRing.R_q C] (cqd : CategoricalQExtDeriv C) (hq : cqd.q = 1) (hd_sq : CategoryTheory.CategoryStruct.comp cqd.d_classical cqd.d_classical = 0) :
              CategoryTheory.CategoryStruct.comp cqd.dq cqd.dq = 0

              Classical limit of d_q². LaTeX: \label{prop:categorical-dq-squared}

              When q = 1, d_q² vanishes whenever the classical d² vanishes. This is the classical-limit direction; for the non-vanishing direction (d_q² ≠ 0 when q ≠ 1) see categorical_dq_squared_nonvanishing.

              Non-vanishing of d_q² (the quantum correction). LaTeX: \label{prop:categorical-dq-squared-nonvanishing}

              When q ≠ 1 and the classical d² = 0, the q-deformed d_q² is non-zero: the deformation introduces a genuine curvature term.

              Axiom justification: requires analysis of the scalar coefficient qinv²(1 − q)² ≠ 0 for the cross-term π_V ∘ d ∘ π_V ∘ d. The proof is a direct computation once Linear R_q C provides scalar expansion, but the cross-term non-vanishing hypothesis hcross is already hoisted.

              The coefficient is written with the carried qinv, not q⁻¹: over R_q = ℤ[q, q⁻¹] the notation q⁻¹ does not exist (no Inv instance), so the argument has to run off q_mul_qinv (bean qou-u87j). R_q is an integral domain and qinv is a unit, so qinv² (1 − q)² ≠ 0 reduces to 1 − q ≠ 0 — exactly the q ≠ 1 hypothesis. The former ℝ version additionally needed q ≠ 0 to write q⁻¹ at all.

              The hypothesis hcross represents the geometric content: the vertical projection π_V does not commute with the classical differential d, so the cross-term is generically non-zero.

              Ref: Connes, Noncommutative Geometry, Ch IV (spectral deformations).

              References:

              • [manuscript] §1-quantum-observable-universe
              • [connes1994] https://doi.org/10.1016/0022-4049(94)90126-0
