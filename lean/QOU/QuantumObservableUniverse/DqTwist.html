    QOU.QuantumObservableUniverse.DqTwist — d_q is d twisted, and d_q² ≠ 0 is the twist failing to commute #

    Bean qou-fngs, LES/spectral arc. Answers a structural question the corpus poses but never states as a theorem: is the non-vanishing of d_q² related to the twist? It is not merely related — it is the twist.

    d_q factors as a twist of d #

    Instanton.lean defines

    d_q = qinv • d + (1 − qinv) • (π_V ≫ d)

    and composition is bilinear, so this factors:

    d_q = T_q ≫ d,      T_q := qinv • 𝟙 + (1 − qinv) • π_V

    dq_eq_twist_comp below. T_q interpolates between the identity (at qinv = 1, i.e. q = 1) and the vertical projector (at qinv = 0) — a deformation of the identity by an idempotent, which is what "twist" means here. twist_classical records that q = 1 collapses it to 𝟙, which is why dq_classical holds.

    The obstruction is non-commutation, not q ≠ 1 #

    dq_sq_eq_zero_of_twist_comm is the theorem this file exists for:

    T_q ≫ d = d ≫ T_q   and   d ≫ d = 0   ⟹   d_q ≫ d_q = 0

    because d_q ≫ d_q = T d T d = T T d d = 0. No hypothesis on q at all.

    That strictly generalises CategoricalQExtDeriv.dq_classical, which reaches the same conclusion only at q = 1, and it relocates the obstruction: d_q² fails to vanish not because the deformation parameter is non-classical, but because the twist does not commute with the differential. q = 1 is sufficient only because it makes T_q = 𝟙, which commutes with everything — dq_sq_eq_zero_of_classical_via_twist derives the classical case that way, from commutation rather than by unfolding.

    The corpus already says this in prose, in Instanton.lean's axiom justification: "the vertical projection π_V does not commute with the classical differential d, so the cross-term is generically non-zero." Its hcross hypothesis is exactly that cross-term. This file promotes that sentence to a theorem and shows the cross-term is the commutator obstruction.

    The curvature, exactly #

    dq_sq_eq_curvature computes d_q² rather than giving a condition for it to vanish. Writing κ := d ≫ π_V − π_V ≫ d for the projector commutator, and assuming only d² = 0:

    d_q ≫ d_q = (1 − q⁻¹) • (T_q ≫ κ ≫ d)

    Three things follow, and the third is the one the arc needs.

    • q = 1 kills it through the scalar (1 − q⁻¹), recovering dq_classical from the formula rather than from a commutation hypothesis.
    • κ = 0 kills it for every q. So the sharp condition is that π_V commutes with d — twist_comm_iff shows the twist-commutation hypothesis above is exactly (1 − q⁻¹) • κ = 0, i.e. the curvature vanishing.
    • The curvature is first order in (1 − q⁻¹). d_q has a degree-zero leading term and its failure to square to zero is entirely in degree ≥ 1. That is not a remark — it is the filtration statement the arc has been reaching for: filter by powers of (1 − q⁻¹) and the associated graded satisfies d² = 0, with the curvature reappearing as a higher differential.

    The standing name for an object with d² ≠ 0 is a curved complex, and the established apparatus for taming one is a Maurer–Cartan element / bounding cochain — which is what the Floer literature in library/ (Smith's twisted complexes and formality, Chanda's invariance up to a change of local systems) supplies as method rather than as content. See docs/curved-dq-and-the-floer-cluster.md.

    Why this matters for the spectral-sequence arc #

    QOU/Mathlib/PagedSpectralSequence.lean requires d ∘ d = 0. So d_q is not a valid differential for a PagedSS — a curved object has no cohomology, because ker ⧸ im is not defined when im ⊄ ker.

    That is not a gap in the API; it is the actual mathematical situation, and it says where the filtration has to do its work. The standard resolution is to filter so the curvature sits in higher filtration degree, so that the associated graded satisfies d² = 0 and the curvature reappears as a higher differential d_r. In this corpus the filtration on offer is the jet order / Gröbner degree — which is precisely the filtration S-GB-spectral-collapse is about.

    So the two threads are one problem seen twice: the curvature d_q² ≠ 0 is the obstruction to a naive spectral sequence, and the filtration is what tames it.
