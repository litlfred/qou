    structure QOU.HigherForms (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] :
    Type (max u v)

    Higher differential forms Ωᵏ(A) = ⋀ᵏ_A Ω¹(A).

    The graded A-bimodule of exterior powers of Kähler differentials, with Ω⁰(A) = A and d : Ωᵏ → Ωᵏ⁺¹ satisfying d² = 0.

    LaTeX: \label{def:higher-forms}

    • frobHopf : FrobeniusHopfData C

      The underlying Frobenius–Hopf object A.

    • formObj : ℕ → C

      The degree-k form object Ωᵏ(A) in C.

    • degree_zero : self.formObj 0 = self.frobHopf.obj

      Ω⁰(A) = A.

    • d (k : ℕ) : self.formObj k ⟶ self.formObj (k + 1)

      The differential d : Ωᵏ(A) → Ωᵏ⁺¹(A).

      structure QOU.InvolutiveStructure (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] :
      Type (max u v)

      Involutive structure (†-structure / *-structure) on a monoidal category.

      A contravariant endofunctor † : C^op → C that is the identity on objects, satisfies f†† = f, and is compatible with the monoidal structure.

      LaTeX: \label{def:involutive-structure}

      • dagger {X Y : C} : (X ⟶ Y) → (Y ⟶ X)

        The involution on morphisms: f† : Y ⟶ X for f : X ⟶ Y.

      • dagger_dagger {X Y : C} (f : X ⟶ Y) : self.dagger (self.dagger f) = f

        Involutivity: f†† = f.

      • dagger_comp {X Y Z : C} (f : X ⟶ Y) (g : Y ⟶ Z) : self.dagger (CategoryTheory.CategoryStruct.comp f g) = CategoryTheory.CategoryStruct.comp (self.dagger g) (self.dagger f)

        Contravariance: (g ∘ f)† = f† ∘ g†.

      • dagger_id (X : C) : self.dagger (CategoryTheory.CategoryStruct.id X) = CategoryTheory.CategoryStruct.id X

        Identity: id† = id.

        structure QOU.PositiveDefiniteStructure (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.Preadditive C] extends QOU.InvolutiveStructure C :
        Type (max u v)

        Positive-definite structure on an involutive monoidal category.

        The involution is positive-definite if for every non-zero f : 𝟙 → X, the composite f ≫ f† : 𝟙 → 𝟙 is positive in End(𝟙) ≅ R.

        LaTeX: \label{def:positive-definite-dagger}

        • dagger {X Y : C} : (X ⟶ Y) → (Y ⟶ X)
        • dagger_dagger {X Y : C} (f : X ⟶ Y) : self.dagger (self.dagger f) = f
        • dagger_comp {X Y Z : C} (f : X ⟶ Y) (g : Y ⟶ Z) : self.dagger (CategoryTheory.CategoryStruct.comp f g) = CategoryTheory.CategoryStruct.comp (self.dagger g) (self.dagger f)
        • dagger_id (X : C) : self.dagger (CategoryTheory.CategoryStruct.id X) = CategoryTheory.CategoryStruct.id X
        • positive_definite {X : C} (f : CategoryTheory.MonoidalCategoryStruct.tensorUnit C ⟶ X) : f ≠ 0 → CategoryTheory.CategoryStruct.comp f (self.dagger f) ≠ 0

          Positive-definiteness: for non-zero f : 𝟙 → X, f ≫ f† ≠ 0. (In an ℝ-linear category, this encodes positivity.)

          structure QOU.CatHodgeInvolution {C : Type u} [CategoryTheory.Category.{v, u} C] (X : C) :
          Type v

          An involutive endomorphism in a category, modeling the Hodge star operator ⋆. When ⋆² = id, the eigenvalue decomposition V = V⁺ ⊕ V⁻ (self-dual ⊕ anti-self-dual) follows from the spectral theory of involutions.

          • star : X ⟶ X

            The Hodge star operator ⋆ : X ⟶ X.

          • star_sq : CategoryTheory.CategoryStruct.comp self.star self.star = CategoryTheory.CategoryStruct.id X

            Involutivity: ⋆ ≫ ⋆ = id_X.

                    structure QOU.SpinLabels :
                    Type

                    Spin labels: the simple objects of a quantum observable universe are indexed by half-integer spin labels j ∈ {0, 1/2, 1, 3/2, ...}, with V_j having categorical dimension 2j + 1.

                    LaTeX: \label{def:spin-labels}

                    • twice_j : ℕ

                      The spin label j, represented as twice the spin (so j = 0, 1, 2, 3, ... corresponds to spin 0, 1/2, 1, 3/2, ...).

                    • cat_dim : ℕ

                      The categorical dimension of V_j is 2j + 1 = twice_j + 1.
