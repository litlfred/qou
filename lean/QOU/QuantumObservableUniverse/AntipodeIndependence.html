    Historical record: the antipode WAS free data, and S² = id WAS independent #

    This file is a record of a state the corpus has left. On 2026-09-14 the owner decided to add the Hopf antipode axiom to def:frobenius-hopf-substrate (beans qou-c64q, qou-qjhc). QOU.FrobeniusHopfData now carries antipode_left / antipode_right, and QOU.FrobeniusHopfData.antipode_unique (in QOU.QuantumObservableUniverse.AntipodeDetermined) shows the antipode is determined by the rest of the data. The hole described below is closed.

    What is kept here is the machine-checked statement of what was wrong, over a structure FrobeniusHopfDataPreAxiom reproducing the pre-2026-09-14 shape of FrobeniusHopfData exactly: eight data fields and three laws (pairing_snake_left, pairing_snake_right, frobenius_relation).

    The point it records: unit, counit and antipode were mentioned by no law. A field constrained by nothing is free data — no property of it is derivable, and none is refutable — so S² = id was neither open nor false but independent of the definition. That is a third epistemic state, and it was being filed as the first.

    The prose said otherwise, which is how it survived: axiom 2 of the block read "with antipode S : A → A satisfying the Hopf compatibility ε ∘ μ = u ∘ (ε ⊗ ε)" — a condition in which S appears on neither side. A QA reviewer had already flagged it in the block's own sidecar (frobenius-hopf-substrate.qa.json, criterion trap-nonspeakable); this file is the machine-checked form of that reading, and scripts/lean-structure-field-law-audit.py is its mechanical detector.

            The cost, part two. With zero morphisms available, S ≫ S = 𝟙 as a theorem would have forced 𝟙_A = 0 — every such object a zero object. Take g = 0: 0 ≫ 0 = 0, so 0 = 𝟙.

            🛑 Scope. This argument substitutes 0 for the antipode and therefore needs antipode to be free data. It applies to FrobeniusHopfDataPreAxiom and not to the current QOU.FrobeniusHopfData, whose antipode is determined (QOU.FrobeniusHopfData.antipode_unique) and so cannot be chosen.
