    structure QOU.CRManifoldData :
    Type (u_1 + 1)

    CR manifold data for the ℂ realisation.

    Canonical 4-tuple (C, θ, G, S): C = Rep(SU_q(2)) is the monoidal category; θ is the contact form (pseudo-Hermitian structure) on a CR manifold M (implicit as domain of θ); G = SU(2); S = P ×_G CP¹ is the state bundle (principal bundle P implicit).

    LaTeX: \label{def:c-quantum-universe}

    • M : Type u_1

      The underlying smooth manifold carrier.

    • topM : TopologicalSpace self.M
    • n : ℕ

      CR dimension n ≥ 1; real dimension of M is 2n + 1.

    • n_pos : 0 < self.n
    • r : ℕ

      Levi form signature (r, s) with r + s = n.

    • s : ℕ
    • rs_sum : self.r + self.s = self.n
    • contactForm : self.M → ℝ

      The contact form θ represented abstractly as a continuous 1-form.

    • contact_nondeg : ∃ (p : self.M), self.contactForm p ≠ 0

      Non-degeneracy: θ does not vanish identically.

      Taken from the two co-located siblings, which had it where this copy did not (bean qou-u87j). Without it a "CR manifold" with θ ≡ 0 satisfies the structure, and contactForm is a contact form in name only.

    • reebField : C(self.M, self.M)

      The Reeb vector field ξ, characterised by ι_ξ dθ = 0 and θ(ξ) = 1.

      Continuous, as C(M, M) — also from the siblings. This copy had the bare function M → M, weaker than a vector field on a manifold should be, and the TopologicalSpace M instance above was already present to support it. Nothing in the tree reads this field, so the strengthening breaks no caller.

    • reeb_preserves_contact (p : self.M) : self.contactForm (self.reebField p) = self.contactForm p

      The Reeb field preserves the contact form: θ(ξ(p)) = θ(p).
