    QOU.FluidDynamics.p1_spectral_sobolev — discrete spectrum and Sobolev embedding #

    Lemma (prop:p1-spectral-sobolev).

    For the q-Laplacian Δ_q with q > 1: (a) the eigenvalues μ_k form a non-negative increasing sequence; (b) μ_k = [k]_q²; (c) the Sobolev embedding H¹_q ↪ L^∞ holds with constant C_S.

    Formalisation notes #

    • Base ring (§7c). Generic {R : Type*} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] — the weakest class admitting the ordering claims; not ℝ. No archimedean construct beyond order is used. The setup 1 < q and the zpow growth bound (b′) are archimedean refinements not used by the statement and are deferred to a post-wall specialisation.
    • Non-degenerate conditional (§3b-cond cond. 5) — (a) is derived. The genuine inputs are the eigenvalue formula (b) (the spectral computation) and monotonicity/non-negativity of the q-integers; from these the theorem derives (a): 0 ≤ μ 0 = [0]_q² and μ k = [k]_q² ≤ [k+1]_q² = μ (k+1). (c) is the Sobolev analytic input, carried as a named hypothesis. Previously all three were bare class fields projected into the conclusion.

    class QOU.FluidDynamics.P1SpectralSobolevContext (R : Type u_1) [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] :
    Type u_1

    Hypotheses for the discrete spectrum + Sobolev embedding (§7c: generic linearly ordered CommRing (IsStrictOrderedRing), no ℝ). (b) and the q-integer monotonicity are the genuine inputs; the spectrum ordering (a) is derived in p1_spectral_sobolev.

    • q_int : ℕ → R

      The q-integer [k]_q = (q^k − q^{−k})/(q − q^{−1}).

    • q_int_nonneg (k : ℕ) : 0 ≤ q_int k

      The q-integers are non-negative (holds for q > 1).

    • q_int_mono (k : ℕ) : q_int k ≤ q_int (k + 1)

      The q-integers increase in k (holds for q > 1).

    • μ : ℕ → R

      The discrete q-Laplacian eigenvalues μ_k.

    • eigenvalue_formula (k : ℕ) : μ k = q_int k ^ 2

      (b) — the spectral computation: eigenvalue closed form μ_k = [k]_q².

    • C_S : R

      Sobolev embedding constant C_S for H¹_q ↪ L^∞.

    • H1_norm : R

      H¹_q- and L^∞-norms of an arbitrary test function.

    • Linf_norm : R
    • sobolev_embedding : Linf_norm ≤ C_S * H1_norm

      (c) — the analytic input: Sobolev embedding bound ‖f‖_{L^∞} ≤ C_S · ‖f‖_{H¹_q}.
