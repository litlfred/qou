    QOU.FluidDynamics.burgers_core_strain_cap #

    The finite-core strain cap — deriving the two-regime model's phase-2 saturation value α = Γ/(πV₁) from the Gaussian vortex profile (bean qou-zuz0, sub-item U4 of the model-to-PDE decomposition, 2026-08-14-qns-model-to-pde-uniformity-decomposition.md).

    A singular point vortex of circulation Γ exerts co-rotation strain Γ/(2πr²) at distance r — unbounded as r → 0 (pointStrain_unbounded). A finite Gaussian core of variance a² (the profile of both the Lamb–Oseen and the steady Burgers vortex, both exact NS solutions) exerts

    coreStrain = Γ/(2πr²) · (1 − exp(−r²/(2a²))),

    and the elementary inequality 1 − e^{−x} ≤ x gives the uniform cap

    coreStrain ≤ Γ/(4πa²) for every r > 0 (coreStrain_le_cap),

    attained in the limit r → 0. This is the regularization mechanism of the overlap regime, derived: however close the approach, a finite core cannot exert more than Γ/(4πa²) strain. Under the model's stretching normalization V₁ = 4a² the cap reads Γ/(π·V₁) — the phase-2 saturation value of rem:hyperbolic-overlap-saturation, now derived from the exact-solution profile up to the V₁ normalization convention (cap_eq_model_saturation).

    Scope (honest). Derived: the cap inequality for the Gaussian profile, and its identity with the model's saturation under the stated V₁ convention. Named conventions/hypotheses, not derived here: the choice V₁ = 4a² (the model's stretching coordinate is pinned to core variance by this dictionary); applying the single-vortex profile to the two-vortex hyperbolic overlap geometry (the same per-core localization hypothesis as the rest of the two-regime model). The steady Burgers balance γ = 4ν/a² (strain that holds the core steady) is noted in the audit; not needed for the cap. This file is archimedean (ℝ) by §7c necessity: Real.exp and Real.pi are the statement.
