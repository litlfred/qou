    QOU.FluidDynamics.yekutieli_obstruction_level — obstruction level = ⌊s⌋+1 #

    The Yekutieli obstruction level and its identification with the terminal Sobolev regularity, sharpening the categorical→classical bridge (Bridge B, B2) of the q-NS classical-gap program (docs/audits/2026-07-18-q-ns-classical-gap-decomposition.md).

    Scope discipline (owner directive 2026-07-24). Given a QOU, s(t) is the Sobolev regularity of the QOU's own internal q = 1 flow, not of a classical ℝ³ Navier–Stokes solution. This file fixes the QOU-internal obstruction↔Sobolev bookkeeping; it makes no claim about the external PDE.

    What this adds #

    p3-blowup-yekutieli (blowup_yekutieli) reformulates smoothness as lifting through the whole brane tower: v smooth ⟺ κ_n(v) = 0 ∀ n, and blow-up as the existence of a finite obstruction level n*. That block also records the mechanism connecting the categorical obstruction to the Sobolev regularity s(t) of the QOU-internal q = 1 flow:

    at q = 1 the n-th brane-tower class κ_n(v) is nonzero iff the n-th jet of v is undefined, i.e. iff n > s(t); a finite-time singularity has terminal regularity s* < ∞, and the obstruction level is n* = ⌊s*⌋ + 1.

    This file formalises that correspondence and proves n* = ⌊s⌋ + 1 is exactly the least level at which lifting fails:

    • yekutieli_obstruction_at_level — the class κ_{n*} does not vanish;
    • yekutieli_no_obstruction_below — every level below n* lifts cleanly;
    • yekutieli_obstruction_level_least — n* is the minimal failing level.

    This is the concrete realisation of Bridge (B)'s B2 identification (the categorical lift ⟺ classical Hⁿ-smoothness dictionary). It is still on the categorical/definitional side of the wall — it does not prove that a classical NS solution attains a finite s* (that existence statement is the open Clay content, conj:regularity-breakdown R1/R2). It fixes the bookkeeping between the two sides once a terminal s is given.

    Base ring (§7c) #

    Genuinely archimedean: s : ℝ is the (real) Sobolev exponent and the argument uses the order structure and Nat.floor. ℝ is correct here — this block lives on the archimedean side of the substrate wall.

    class QOU.FluidDynamics.YekutieliObstructionLevel :
    Type

    Yekutieli obstruction–Sobolev correspondence at a fixed time.

    sobolev is the terminal Sobolev regularity s = s(t) of the QOU-internal q = 1 flow's velocity (0 ≤ s, finite — the finite-time-blow-up regime); obstruction n is the proposition "κ_n(v) ≠ 0", i.e. lifting fails at brane-tower level n. The single field obstruction_iff_exceeds is the manuscript's mechanism (p3-blowup-yekutieli): the level-n class is nonzero exactly when n exceeds the Sobolev regularity, so the n-th jet is undefined.

    • sobolev : ℝ

      Terminal Sobolev regularity s(t) of the velocity field.

    • sobolev_nonneg : 0 ≤ sobolev

      Regularity is non-negative.

    • obstruction : ℕ → Prop

      "κ_n(v) ≠ 0": lifting fails at brane-tower level n.

    • obstruction_iff_exceeds (n : ℕ) : obstruction n ↔ sobolev < ↑n

      Mechanism (p3-blowup-yekutieli): the level-n obstruction class is nonzero iff n exceeds the Sobolev regularity.
