    QOU.FluidDynamics.q_turbulence_spectrum #

    Proposition for content block prop:q-turbulence-spectrum: $q$-deformed energy cascade and modified Kolmogorov spectrum.

    Four sub-claims: (i) the q-deformed Kolmogorov spectrum E_q(k) = C_q ε^{2/3} [k]_q^{−5/3} / ([k]_q / k); (ii) the discrete cascade transfer rate T_{k→k+1} = ε ([k+1]_q^{2/3} − [k]_q^{2/3}) / ([k+1]_q − [k]_q); (iii) the finite cascade depth N_modes ≤ ¾ ln Re_q / ln q; (iv) the spectral gap ΔE_gap = C_q ε^{2/3} ([1]_q^{−5/3} − [2]_q^{−5/3}) > 0.

    Disposition (integrity) #

    The previous encoding was a self-assuming projection (forbidden by AGENTS.md §3b-cond item 5): four claim_* class fields carried the four sub-claims verbatim and the "theorem" tupled them back.

    Now:

    • Claims (i) and (ii) are formulas, so E_q and transferRate are honest defs (with the symmetric q-integer [k]_q = (q^k − q^{−k})/(q − q^{−1}) also a def); the theorem records them as definitional equalities.
    • Claim (iv) 0 < ΔE_gap is derived sorry-free from the genuine inputs 1 < q, 0 < ε, 0 < C_q: [1]_q = 1 < q + q⁻¹ = [2]_q, and x ↦ x^{−5/3} is strictly antitone on positives, so [1]_q^{−5/3} − [2]_q^{−5/3} > 0.
    • Claim (iii), the cascade-depth bound on the (opaque) active-mode count N_modes, is derived conditionally (bean qou-octr fix, 2026-08-14): the unconditional form is refutable (finite_cascade_depth_unconstrained_false — the base class never relates N_modes to Re_q), so the flat sorry it once carried could never be discharged and was removed. The physical input is now the explicit QTurbulenceCascadeModel.cutoff hypothesis q^N_modes ≤ Re_q^{3/4} (all active modes below the Kolmogorov dissipation scale), from which the depth bound follows by log algebra (finite_cascade_depth_of_cutoff, sorry-free).

    The base class carries only data + genuine physical inputs (1 < q, Re_q = 2/(q−1), 0 < ε, 0 < C_q, the opaque mode count); no field is any of the four conclusions. The cascade-model class adds the one named modeling hypothesis; the file is now sorry-free.

              class QOU.FluidDynamics.QTurbulenceCascadeModelextends QOU.FluidDynamics.QTurbulenceSpectrumContext :
              Type

              Cascade model for claim (iii) (the fix demanded by finite_cascade_depth_unconstrained_false below, bean qou-octr): the single physical input of the Kolmogorov dissipation-cutoff argument, as an explicit hypothesis. On the geometric mode ladder the N-th active mode sits at wavenumber scale q^N, and the classical cutoff argument places every active mode below the dissipation scale Re^{3/4} — the multiplicative bound q^N_modes ≤ Re_q^{3/4}.

              The field is a hypothesis in the shape of the physical model, not the conclusion: the depth bound N ≤ ¾·log Re_q / log q is derived from it by the log/division algebra in QTurbulence.finite_cascade_depth_of_cutoff (§3b-cond item 5: the class carries the input, the theorem does the derivation).
