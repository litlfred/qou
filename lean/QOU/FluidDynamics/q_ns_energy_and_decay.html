    QOU.FluidDynamics.q_ns_energy_and_decay #

    Infrastructure for [thm:q-ns-wellposedness]: the two derivable halves of the block's claim.

    Why this file exists #

    q_ns_wellposedness.lean carried the block's whole conclusion — existence, uniqueness, smoothness, the energy inequality and the spectral-decay bound — as a single class field, and projected it. That is the self-assuming shape AGENTS.md §3b-cond item 5 forbids, and it is also imprecise about what is actually open: it puts the energy inequality and the spectral decay, which are consequences of the equations, on the same footing as global existence, which is not.

    Two of the three properties do not need any q-NS-specific infrastructure. Given the evolution's own differential inequalities, they are Grönwall comparisons and are proved here, unconditionally:

    block property status here
    (i) existence + uniqueness open — stays a hypothesis (Millennium-adjacent)
    (ii) energy inequality derived — energy_inequality_of_balance
    (iii) Δ_q-spectral decay derived — modal_decay_of_deriv_le

    Both are stated for a generic scalar trajectory, so they carry no q-NS commitments of their own and cannot smuggle the conclusion back in: they say if the flow satisfies the pointwise balance / modal inequality, then the integrated bound holds, which is the honest content.

    theorem QOU.FluidDynamics.modal_decay_of_deriv_le {a a' : ℝ → ℝ} {c T : ℝ} (hcont : ContinuousOn a (Set.Icc 0 T)) (hderiv : ∀ t ∈ Set.Ico 0 T, HasDerivWithinAt a (a' t) (Set.Ici t) t) (hineq : ∀ t ∈ Set.Ico 0 T, a' t ≤ -c * a t) (t : ℝ) :
    t ∈ Set.Icc 0 T → a t ≤ a 0 * Real.exp (-c * t)

    Modal exponential decay from the modal differential inequality.

    If a real trajectory a satisfies a' t ≤ -c · a t on [0, T), then a t ≤ a 0 · exp (-c t) on [0, T].

    Applied to the Δ_q-eigencomponent a = |v̂_k| with c = ν_q [k]_q², this is property (iii) of [thm:q-ns-wellposedness]. The eigenvalue enters only as the constant c; nothing here knows about q, which is the point — the decay is a consequence of the modal inequality, not an extra assumption about solutions.

    theorem QOU.FluidDynamics.energy_inequality_of_balance {E Dcum E' D : ℝ → ℝ} {ν T : ℝ} (hcont : ContinuousOn (fun (t : ℝ) => E t + 2 * ν * Dcum t) (Set.Icc 0 T)) (hderiv : ∀ t ∈ Set.Ico 0 T, HasDerivWithinAt (fun (s : ℝ) => E s + 2 * ν * Dcum s) (E' t + 2 * ν * D t) (Set.Ici t) t) (hbal : ∀ t ∈ Set.Ico 0 T, E' t + 2 * ν * D t ≤ 0) (hD0 : Dcum 0 = 0) (t : ℝ) :
    t ∈ Set.Icc 0 T → E t + 2 * ν * Dcum t ≤ E 0

    Energy inequality from the pointwise energy balance.

    Let E be the squared norm ‖v(t)‖²_A and Dcum the cumulative dissipation t ↦ ∫₀ᵗ ‖d_q v(s)‖²_A ds. If the balance E' t + 2 ν_q · D t ≤ 0 holds pointwise — the differential form of the energy identity — then the integrated inequality

    E t + 2 ν_q · Dcum t ≤ E 0

    holds on [0, T]. This is property (ii) of [thm:q-ns-wellposedness].

    Note what is and is not assumed: the hypothesis is the pointwise balance (a statement about the equations), and the conclusion is the integrated bound (the statement the block makes). Assuming the latter directly, as the previous encoding did, assumes the theorem.
