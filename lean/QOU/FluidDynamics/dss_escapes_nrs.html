    QOU.FluidDynamics.dss_escapes_nrs — why discretely self-similar escapes NRŠ #

    Structural backing for the Finding-1 re-scope of the Leray profile (prop:leray-profile, conj:regularity-breakdown) from continuous backward-self-similar to discretely self-similar (DSS), per the q-NS gap audit (docs/audits/2026-07-18-q-ns-classical-gap-decomposition.md).

    Scope discipline (owner directive 2026-07-24). The profile U(s) is the QOU's own internal blow-up profile in similarity time. This file is a structural fact about the steady-vs-periodic profile classes; it explains why scoping the QOU-internal profile to discretely self-similar is consistent with the NRŠ no-go. It is a statement about QOUs / profile classes, not about the classical ℝ³ PDE.

    The point #

    In Leray's similarity variables the profile is a function U = U(s) of s = -log(T* - t). Two regularity classes:

    • continuous self-similar — U is s-independent (steady);
    • discretely self-similar (DSS) — U is s-periodic with some period P (set by the root-of-unity scaling λ_κ, P = 2 log λ_κ).

    Nečas–Růžička–Šverák (Acta Math. 176, 1996) exclude the steady finite-energy profile. This file records the clean structural reason the DSS class survives that no-go:

    selfSimilar_iff_all_periods — a profile is steady iff it is periodic for every period. So the NRŠ-excluded (steady) class is exactly the intersection of all the periodic classes; a genuinely single-period DSS profile (dss_not_selfSimilar_of_nonconstant) is not steady, hence not touched by the no-go.

    Honest scope #

    This is a structural fact about the profile classes — it explains why the DSS re-scope is consistent with NRŠ. It does not construct a nontrivial DSS profile (that existence — the finite-dimensional Leray shooting problem — is the open content of prop:leray-profile / conj:regularity-breakdown). The NRŠ no-go itself is a cited literature theorem, not re-proved here.

    Base ring (§7c) #

    Archimedean: U : ℝ → ℝ on the similarity time s ∈ ℝ. ℝ is correct.

      def QOU.FluidDynamics.DSSPeriodic (U : ℝ → ℝ) (P : ℝ) :
      Prop

      The similarity profile U(s) is discretely self-similar with period P if it is P-periodic in s (P = 2 log λ_κ for the root-of-unity scaling λ_κ).

        theorem QOU.FluidDynamics.selfSimilar_iff_all_periods (U : ℝ → ℝ) :
        SelfSimilar U ↔ ∀ (P : ℝ), DSSPeriodic U P

        Steady = periodic for every period. A similarity profile is (continuously) self-similar iff it is discretely self-similar for every period P. Hence the NRŠ-excluded steady class is precisely the intersection of all the DSS classes.

        theorem QOU.FluidDynamics.dss_not_selfSimilar_of_nonconstant {U : ℝ → ℝ} (hwit : ∃ (s : ℝ), U s ≠ U 0) :

        Single-period DSS is not steady (given a non-constant value). A DSS profile that takes some value ≠ U 0 is not self-similar — so it lies in the complement of the NRŠ-excluded steady class and is not touched by the no-go. This is the class the discretely-self-similar re-scope lives in.

        theorem QOU.FluidDynamics.selfSimilar_isDSS {U : ℝ → ℝ} (h : SelfSimilar U) (P : ℝ) :
        DSSPeriodic U P

        The steady class is the strict floor. Any self-similar profile is DSS for every period (its s-independence is the degenerate case of periodicity); the content of the re-scope is that the converse fails — non-steady single-period profiles exist in principle and are what NRŠ leaves open.
