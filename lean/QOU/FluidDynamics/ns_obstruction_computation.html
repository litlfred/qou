    QOU.FluidDynamics.ns_obstruction_computation — obstruction computation at the collision locus #

    Proposition (prop:ns-obstruction-computation).

    For the Descartes universe with an anti-parallel vortex pair of linking number lk: (i) the topological obstruction lk · e(ξ)|_p is non-zero iff the Reeb field has a zero at p; (ii) for n ≥ 1 the per-jet obstruction δ_n|_Σ is non-zero iff the n-th velocity jet diverges on Σ.

    Formalisation notes #

    • Base ring (§7c). Generic {R : Type*} [CommRing R] — no ℝ. The Euler-class value and jet obstructions take values in R; the linking number is genuinely ℤ (cast into R); all claims are (in)equalities-with-zero, no order or analysis.
    • Non-degenerate conditional (§3b-cond cond. 5). Each iff's two implication directions are carried as explicit hypotheses; the theorem derives both iffs (Iff.intro) and conjoins them — it does not carry either iff as a bare class field.

    class QOU.FluidDynamics.NsObstructionComputationContext (R : Type u_1) [CommRing R] :
    Type u_1

    Hypotheses for the NS obstruction computation (§7c: generic CommRing, ℤ linking number, no ℝ). The four implication directions are explicit; ns_obstruction_computation derives the two iffs.

    • lk : ℤ

      Linking number lk of the colliding vortex pair.

    • e_xi_at_p : R

      Euler class value e(ξ)|_p at the collision point.

    • reeb_zero_at_p : Prop

      Predicate: the Reeb field has a zero at p.

    • reeb_zero_of_obstruction : ↑(lk R) * e_xi_at_p ≠ 0 → reeb_zero_at_p R

      (i) ⇒: a non-vanishing topological obstruction forces a Reeb zero.

    • obstruction_of_reeb_zero : reeb_zero_at_p R → ↑(lk R) * e_xi_at_p ≠ 0

      (i) ⇐: a Reeb zero at p forces the obstruction lk · e(ξ)|_p ≠ 0.

    • delta_n : ℕ → R

      Per-jet-level obstruction δ_n restricted to the collision surface Σ.

    • jet_diverges : ℕ → Prop

      Predicate: the n-th jet of the velocity diverges on Σ.

    • jet_diverges_of_delta (n : ℕ) : 1 ≤ n → delta_n n ≠ 0 → jet_diverges R n

      (ii) ⇒: a non-vanishing jet obstruction forces jet divergence.

    • delta_of_jet_diverges (n : ℕ) : 1 ≤ n → jet_diverges R n → delta_n n ≠ 0

      (ii) ⇐: jet divergence exhibits a non-vanishing jet obstruction.
