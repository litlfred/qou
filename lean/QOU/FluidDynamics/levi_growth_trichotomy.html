    QOU.FluidDynamics.levi_growth_trichotomy — Levi condition-number trichotomy #

    Refines the conj:levi-degeneracy dichotomy into an exhaustive trichotomy on the growth exponent of the Levi condition number, per the q-NS gap audit Finding 3 (docs/audits/2026-07-18-q-ns-classical-gap-decomposition.md).

    Scope discipline (owner directive 2026-07-24). Given a QOU, C_L(κ) is the Levi condition number of the QOU's own vortex-core geometry along its root-of-unity ladder, and "NS-singular / NS-regular" below mean the QOU's internal q = 1 flow. This is a statement about QOUs; it does not decide the classical ℝ³ Navier–Stokes problem.

    The problem with the dichotomy #

    conj:levi-degeneracy states "exactly one of (A) C_L(κ) = O(1) / (B) C_L(κ) ~ κ". These are not complementary: an intermediate rate C_L(κ) ~ κ^β with 0 < β < 1 satisfies neither, so as written the conjecture could be vacuously false. The LeviDegeneracy class in fluid-dynamics/levi-degeneracy-conjecture.lean encodes the degeneracy set, not the growth rate, so it does not capture the dichotomy at all.

    The fix #

    Introduce the growth exponent β = limsup_κ (log C_L(κ) / log κ) ∈ [0, 1] and state the exhaustive trichotomy:

    • β = 0 — C_L = O(1), Levi non-degenerate ⇒ (categorically) NS-singular (branch A);
    • β = 1 — C_L ~ κ, Levi degenerates / core → sheet ⇒ NS-regular (branch B);
    • 0 < β < 1 — marginal C_L ~ κ^β, undetermined (the window the dichotomy silently dropped).

    Rewritten 2026-08-30 — the structure did not tie beta to condNumber #

    The previous LeviGrowthTrichotomy carried condNumber : ℕ → ℝ and beta : ℝ with no field relating them, and leviNonDegenerate : Prop as a free field the instance chose for itself. Two instances were built against the old definition to measure what it asserted, and both type-check:

    • condNumber = fun _ => 0, beta = 1/2, leviNonDegenerate = True — a "condition number" that is identically zero, an exponent unrelated to it, and both branch fields vacuous because 1/2 is neither 0 nor 1;
    • condNumber = fun _ => 1 (so C_L = O(1), true exponent 0) with beta = 1 — the opposite branch of the conjecture, accepted without complaint.

    So condNumber was decoration and beta was a free real: assuming LeviGrowthTrichotomy bought nothing about a Levi condition number. And the three theorems below used only beta_mem, which made them facts about a real in [0,1] dressed as facts about a Levi trichotomy — the inversion AGENTS.md §"Conditional-proved ≠ premise-established" warns about, and the same defect appendix-surreals/surreal-squeeze.lean records in its own history.

    Both are fixed:

    • beta is pinned to condNumber by a two-sided limsup characterisation stated without Filter — for every ε > 0, condNumber κ ≤ κ^(β+ε) eventually, and κ^(β-ε) ≤ condNumber κ infinitely often. Together these say exactly limsup_κ log C_L(κ) / log κ = β.
    • leviNonDegenerate is a parameter, not a field, so an instance can no longer choose the proposition its own branch fields are about.
    • The elementary trichotomy facts are restated on a bare real β, where their unconditional character is visible; the structure-level corollaries are kept for consumers.

    The tie has a payoff beyond hygiene: bounded_condNumber_forces_beta_zero derives the .md's identification of branch A with C_L = O(1), which was previously an unstated coincidence between two unrelated fields.

    Honest scope #

    This formalises the classification structure — that the correct statement is a trichotomy and that the marginal window is a genuine third case. It does not compute the actual β (which branch the real C_L(κ) growth falls into): that value is the open content of conj:levi-degeneracy and, via Bridge B, the Clay problem.

    Base ring (§7c) #

    Archimedean: β and C_L are real (a limsup of real log-ratios, an order comparison). ℝ is correct — this block is on the archimedean side of the wall.

    The elementary facts, stated where they live #

    conj:levi-degeneracy asserts that the three regimes are mutually exclusive and exhaustive on β ∈ [0,1]. That assertion is true and unconditional — it is ordered-field trichotomy — and it is stated here on a bare real so that nothing about it looks conjectural. The structure-level corollaries follow.

    source
    theorem QOU.FluidDynamics.beta_trichotomy {β : ℝ} (h0 : 0 ≤ β) (h1 : β ≤ 1) :
    β = 0 ∨ 0 < β ∧ β < 1 ∨ β = 1

    The trichotomy is exhaustive on [0, 1]. Every bounded-rate exponent falls into one of β = 0, 0 < β < 1, β = 1 — so the original two-branch dichotomy (β = 0 xor β = 1) is not a valid partition; the marginal window 0 < β < 1 is the missing third case.

    source
    theorem QOU.FluidDynamics.beta_marginal_undetermined {β : ℝ} (h : 0 < β ∧ β < 1) :
    β ≠ 0 ∧ β ≠ 1

    The marginal window is a genuine third case. When 0 < β < 1, neither β = 0 nor β = 1 holds, so neither branch is triggered.

    The conjectural structure #

    Everything below is conditional. Assuming LeviGrowthTrichotomy is assuming an open conjecture, and the fields are chosen so that the assumption has content.

    source
    structure QOU.FluidDynamics.LeviGrowthTrichotomy (leviNonDegenerate : Prop) :
    Type

    Growth-rate data for the Levi condition number C_L(κ) along the root-of-unity ladder q_κ = e^{iπ/κ}, refining conj:levi-degeneracy.

    The proposition leviNonDegenerate — "the Levi form is non-degenerate along the ladder", both eigenvalues positive — is a parameter: the branch fields are claims about a given non-degeneracy predicate, not about one the instance is free to invent.

    beta is the growth exponent limsup_κ log C_L(κ) / log κ, and beta_upper / beta_lower are that limsup written out without Filter. They are what makes condNumber load-bearing rather than decorative; see the file docstring for the two instances that satisfied the previous definition with no content at all.

    • condNumber : ℕ → ℝ

      The Levi condition number C_L(κ) at ladder step κ.

    • condNumber_pos (κ : ℕ) : 0 < self.condNumber κ

      A condition number is positive — without this log C_L is meaningless and the exponent below is not about anything.

    • beta : ℝ

      Growth exponent β = limsup_κ log C_L(κ) / log κ.

    • beta_mem : 0 ≤ self.beta ∧ self.beta ≤ 1

      Bounded-rate regime: 0 ≤ β ≤ 1 (C_L grows no faster than κ).

    • beta_upper (ε : ℝ) : 0 < ε → ∃ (N : ℕ), ∀ (κ : ℕ), N ≤ κ → self.condNumber κ ≤ ↑κ ^ (self.beta + ε)

      beta is an upper exponent for condNumber: for every ε > 0, C_L(κ) ≤ κ^(β+ε) for all large κ.

    • beta_lower (ε : ℝ) : 0 < ε → ∀ (N : ℕ), ∃ (κ : ℕ), N ≤ κ ∧ ↑κ ^ (self.beta - ε) ≤ self.condNumber κ

      …and it is attained: for every ε > 0, κ^(β-ε) ≤ C_L(κ) for infinitely many κ. Upper and lower together say exactly limsup_κ log C_L(κ) / log κ = β; the upper bound alone would be satisfied by any exponent at least the true one.

    • branchA : self.beta = 0 → leviNonDegenerate

      Branch A: β = 0 (C_L = O(1)) ⇒ Levi non-degenerate (NS-singular).

    • branchB : self.beta = 1 → ¬leviNonDegenerate

      Branch B: β = 1 (C_L ~ κ) ⇒ Levi degenerates (NS-regular).

      False

      Branches A and B are mutually exclusive. Stated honestly: the content is (0 : ℝ) ≠ 1, so the hypotheses are jointly unsatisfiable and no instance is consulted. It is kept because the .md asserts exclusivity, not because the structure supplies it.

      The tie earns its keep #

      conj:levi-degeneracy branch (A) reads "β = 0: bounded growth, C_L(κ) = O(1)" — it treats the exponent and the boundedness as the same condition. Under the previous definition that identification was unstated and unprovable, since nothing connected beta to condNumber; the file docstring's second measurement is a counterexample to it. With beta_lower in place one direction is a theorem.

      source
      theorem QOU.FluidDynamics.bounded_condNumber_forces_beta_zero {P : Prop} (T : LeviGrowthTrichotomy P) (hb : ∃ (M : ℝ), ∀ (κ : ℕ), T.condNumber κ ≤ M) :
      T.beta = 0

      A bounded condition number forces β = 0. If C_L is bounded then no positive exponent survives beta_lower, because κ^(β/2) → ∞ overtakes any bound. This is the .md's branch-(A) identification, derived rather than assumed.

      Consistency and refutability #

      The carrier is inhabited, so assuming it is not assuming a contradiction; and the tie is refutable, which is what the previous definition lacked.
