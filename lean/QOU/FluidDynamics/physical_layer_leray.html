    QOU.FluidDynamics.physical_layer_leray #

    ε-uniform Leray control in the physical layer — the time-averaged no-pile-up bound, proved (bean qou-6xv8, epic qou-a3n3; the physical-layer face of the uniformity question after Option C, def:qns-unit-layers).

    In the physical (c_q-rescaled) layer the viscosity is ν_phys = 1/(2q) exactly (qns_unit_layers), so for 1 < q ≤ 2 it satisfies ν_phys ≥ 1/4 — bounded below uniformly in ε. The discrete Leray inequality of low_mode_block_global therefore yields ε-uniform constants in this layer:

    • physical_leray_uniform — (δ/4)·∑_{i<n} Ω_phys(i) ≤ E₀ for every n, every datum, every 1 < q ≤ 2: the cumulative physical enstrophy is bounded by fixed, ε-free constants.
    • physical_tail_leray_uniform — the same bound for the above-band tail: the tail can spike at an instant, but its time integral is ε-uniformly bounded. This is the time-averaged form of the physical-layer no-pile-up hypothesis, proved.

    What remains, honestly. The SF5-supported open hypothesis is the sup-in-time tail bound. Time-integrated control does not imply sup-in-time control — that implication gap is precisely the classical weak-vs-strong (Leray-to-regularity) gap of the fixed-ν Navier–Stokes problem. After this file, the in-QOU millennium remainder in the physical layer has exactly the classical shape: energy bound uniform (trivial), Leray/time-averaged enstrophy uniform (this file), sup-in-time enstrophy open — no more and no less. Nothing here closes that gap; it localizes it.

    Hypothesis-carrying discrete style over a generic ordered field (§7c); the physical-layer dissipation step and the layer conversion are the consumer's obligations, tagged per the never-straddle rule of def:qns-unit-layers.

    Discrete epochs of regularity (bean qou-8wjo) #

    Markov's counting inequality applied to the ε-uniform Leray bound: for any exceedance level λ, the bad-step count satisfies the product inequality (card bad)·λ ≤ (4/δ)·E₀ — with constants independent of ε, of the horizon n, and of everything about the data except E₀. For λ > 0 this reads card bad ≤ 4E₀/(δλ): the tail exceeds λ on at most boundedly many steps, and outside that set it is ≤ λ — the discrete image of Leray's epochs of regularity.

    What this does not give, honestly: the bad set is bounded in count, not located — it may concentrate at a single time, and a sup-in-time blow-up hiding inside boundedly many steps is exactly the configuration the classical weak-vs-strong gap permits. The open item is unchanged; this theorem fences it into an ε-uniformly small set of times.

    Discrete eventual regularity (bean qou-tfbx) #

    Leray's second classical theorem, in the discrete physical layer. Two pieces:

    1. Pigeonhole entry (exists_small_step): the ε-uniform Leray bound forces the enstrophy below any threshold θ within an explicit, ε-uniform number of steps — if (4/δ)·E₀ < m·θ, some step i < m has Ωp i ≤ θ. Entry time ≤ 4E₀/(δθ) + 1, independent of ε and of everything but E₀.

    Together: every solution is eventually regular, with an ε-uniform bound on the irregular window — blow-up, if any, is confined to [0, 4E₀/(δθ*)] where θ* is the basin threshold. The basin-invariance hypothesis is named, not smuggled: GP4 (global_persistence_subthreshold, substrate layer) proves exactly this shape; instantiating it in the physical layer (converting its threshold through def:qns-unit-layers without straddling) is the recorded follow-up, not assumed here.

    Inside the initial window: good-step chaining (bean qou-g1kj) #

    The one place blow-up could still live is the ε-uniform initial window. This section closes it for a larger data class than GP4's basin by combining the two uniform controls already proved:

    • epochs bound the total number of bad steps (Ω > lam) by an ε-free count Nbad;
    • the bootstrap (GP3's shape: from any good step, Ω ≤ 2·lam for the next H steps — taken as a named hypothesis here, exactly as the basin was before qou-f5o6) covers H steps after each good step.

    If every bad run is shorter than the bootstrap horizon (Nbad + 1 ≤ H), the good steps chain: the latest good step before any time n is at most Nbad steps back (else the interval in between would contain more bad steps than exist in total), so the bootstrap from it covers n — and Ω ≤ 2·lam everywhere (sup_bound_of_chaining). No induction is needed; the latest-good- step argument is a single pigeonhole.

    Reading of the arithmetic side condition (docstring only, not formalized): with Nbad ≈ 4E₀/(δ·lam) and H ≈ 1/(2δc·lam) the condition Nbad + 1 ≤ H is 8cE₀ ≲ 1 — an energy-smallness condition, ε-uniform, strictly weaker than GP4's enstrophy-smallness c·Ω₀ ≤ νμ. In-model, scope (a): the model's transfer constant c is fixed, whereas the classical supercriticality lives exactly in c growing with resolution — that distinction is the honest boundary of this result, stated, not blurred. Large data with 8cE₀ > 1 remains the open core.

    The energy-drain route and the infrared localization (bean qou-qy5l) #

    For large data (8cE₀ > 1) one natural route remains: energy is not merely monotone — it drains at a rate proportional to the enstrophy, and the discrete Poincaré bound k²ₘᵢₙ·E ≤ Ω (the lowest rung dominates: Ω = Σk²e ≥ k²ₘᵢₙ·Σe) turns the drain into geometric decay (energy_geometric_decay): E_n ≤ (1 − δν·k²ₘᵢₙ)ⁿ·E₀. Wait long enough and any datum enters the energy-small class, where energy_small_global takes over.

    The honest scaling — and why this does NOT close the core. The decay rate is δν·k²ₘᵢₙ, and in the physical layer the lowest wavenumber is k_phys,1 = (q−1)·[1]_q = ε (def:qns-unit-layers): the spectral gap vanishes in the continuum limit, so the decay rate is ~ δε²/4 — ε-NON-uniform, and the entry time into the small-energy class diverges as q → 1⁺. This is the correct discrete image of the classical situation (no Poincaré inequality on an unbounded domain; the physical-layer domain grows like c_q).

    Localization achieved: the ultraviolet side of the uniformity question was tamed (tail Leray, epochs, chaining — all ε-uniform); the energy-drain route shows the surviving large-data obstruction is infrared — the vanishing spectral gap of the continuum limit. The open core of epic qou-a3n3, sharpest form: large data, ε-uniformly in time, against a spectral gap that closes like ε. Nothing here resolves it; the theorem quantifies exactly where it lives.

    The damped-forced tail bound (bean qou-80p8) #

    The synthesis of the whole arc. Seen from above the fixed band, the tail is a strongly damped system forced through a fixed boundary:

    • every tail mode has k ≥ kB, so the tail's own dissipation rate is ν·kB² — ε-free, because the band is fixed;
    • the only input crosses the band boundary, where the banded bound (banded_enstrophy_le, ε-uniform) controls the amplitudes.

    If the boundary flux is bounded by a uniform Φ — the one named hypothesis — then the standard damped-forced invariant (tail_damped_forced_bound) gives

    Ω_tail(n) ≤ max(Ω_tail(0), Φ/(ν·kB²)) for every n,

    all data, ε-uniform: the sup-in-time tail bound that has been the open item since the uniformity reduction — closed in-model, conditional on Φ.
