    QOU.FluidDynamics.q_ns_classical_bridge — the categorical→classical NS bridge (Bridge B) #

    Formalize-first scaffolding for the classical (q → 1) side of the q-NS program, per the gap-decomposition audit docs/audits/2026-07-18-q-ns-classical-gap-decomposition.md.

    Scope discipline (owner directive 2026-07-24). Everything here is given a QOU. globallyRegular / blowsUp denote the states of the QOU's own internal q = 1 flow (ns-obstruction-tower), NOT the classical incompressible Navier–Stokes flow on ℝ³. Identifying the QOU-internal q = 1 limit with the external PDE is a separate hypothesis (B2), and that identification — hence any claim about the actual Clay problem — is the open wall, deliberately not asserted.

    This file does two honest things and closes nothing famous:

    1. Names Bridge B as a primary-conjecture class with no instance. The categorical obstruction NS(A) = e(ξ)|_Σ ≠ 0 is proved unconditionally on the categorical side (ns_singularity_descartes.lean, generic CommRing). The class CategoricalClassicalNSBridge carries the bridge hypotheses — B1, that the obstruction is a faithful regularity criterion for the QOU's internal flow; B2, the (open) identification of that internal flow with the external PDE — and derives the internal blow-up implication from them. The q → 1 limit inside a QOU is well-defined categorically; whether it is the classical ℝ³ PDE (B2) is the Clay-sized open wall. Per AGENTS.md §3b-tax an unproved primary is honestly an open class with no instance — none is provided.

    2. Records the critical-exponent closure α = 1 as a conditional identity. Under the standard dissipation closure ε = ν_q · Ω the enstrophy order parameter has a simple (q−1)^{−1} pole (α = 1). This is one of two conflicting heuristic values in the corpus (the other, α = 4/3, follows from a Kolmogorov-spectrum closure); the lemma makes the α = 1 branch an explicit consequence of its named closure, not a boxed absolute.

    Anti-laundering (AGENTS.md §"Axiomatization is NOT a Proof") #

    CategoricalClassicalNSBridge is the open wall, not a proof of it. It has no instance. classical_blowup_of_obstruction proves only "categorical side transfers given the bridge"; it does not resolve Clay, and must never be cited as if it did.

    • α-closure identity: generic {K : Type*} [Field K]; the archimedean reading (q → 1⁺, ε > 0) lives in the prose, not the statement. No ℝ.

    class QOU.FluidDynamics.CategoricalClassicalNSBridge {R : Type u_1} [CommRing R] (NS_A : R) :
    Type

    Bridge (B): the obstruction ↔ internal-flow transfer, given a QOU. @conjecture: primary — an open conjecture, axiomatised as a content-bearing class with no instance.

    Fields are the bridge hypotheses, never its conclusion (§3b-cond cond. 5, non-degenerate):

    • globallyRegular / blowsUp — the two states of the QOU's own internal q = 1 flow (ns-obstruction-tower), NOT the classical ℝ³ PDE. The identification of this internal flow with the external PDE is the separate open hypothesis B2 (see the module docstring) and is not encoded here.
    • blowup_iff_not_regular — internal blow-up is exactly the failure of internal global regularity (a BKM-type dichotomy for the internal flow).
    • obstruction_is_regularity_criterion — B1, the transfer statement: the categorical obstruction is a faithful regularity criterion for the QOU-internal flow, i.e. it vanishes iff that flow is globally regular.
    • globallyRegular : Prop

      Global regularity of the QOU's internal q = 1 NS flow.

    • blowsUp : Prop

      Finite-time singularity of the QOU's internal q = 1 NS flow.

    • blowup_iff_not_regular : blowsUp NS_A ↔ ¬globallyRegular NS_A

      Internal blow-up ⟺ failure of internal global regularity.

    • obstruction_is_regularity_criterion : NS_A = 0 ↔ globallyRegular NS_A

      B1 (the bridge criterion). The categorical obstruction is a faithful regularity criterion for the QOU-internal flow.

      theorem QOU.FluidDynamics.enstrophy_alpha_one_of_dissipation_closure {K : Type u_1} [Field K] (q ε Ω ν : K) (h2q : 2 * q ≠ 0) (hν : ν = (q - 1) / (2 * q)) (hclosure : ε = ν * Ω) :
      Ω * (q - 1) = 2 * q * ε

      Critical-exponent closure α = 1 (dissipation closure).

      Under the standard turbulence closure ε = ν_q · Ω (mean dissipation = q-viscosity × enstrophy) with ν_q = (q − 1)/(2q), the enstrophy order parameter satisfies the exact identity

      Ω · (q − 1) = 2 q ε.

      As q → 1⁺ with ε bounded away from 0, the right side tends to 2ε > 0 while q − 1 → 0, so Ω ~ (q − 1)^{−1}: the critical exponent is α = 1, conditional on this closure and on ε ↛ 0. The corpus's competing α = 4/3 follows from a different closure (a Kolmogorov k^{−5/3} spectrum truncated at N_eff); the two are not reconciled — see the audit, Finding 2. The 2q ≠ 0 hypothesis is the only ring condition the identity needs.
