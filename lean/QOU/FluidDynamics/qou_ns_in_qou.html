    QOU.FluidDynamics.qou_ns_in_qou — q-NS singularity inside a QOU (conditional) #

    Scope discipline (owner directive 2026-07-24). Every statement here is conditional on being given a Quantum Observable Universe (𝐂, A, τ) (def:quantum-observable-universe). We make no claim about the general classical Navier–Stokes problem on ℝ³ (the Clay Millennium problem). The conclusion internalBlowup is the QOU's own internal q-NS observable at q = 1, defined categorically from the substrate — not a finite-time singularity of the physical PDE. Bridging the two (identifying Object 1 = the internal flow with Object 2 = the ℝ³ PDE) is the open wall (bean qou-innq); it is deliberately not asserted.

    The in-QOU chain #

    Given a QOU, its defining observability axiom Hom_𝐂(𝟙, Ad(A)) = 0 forces irreducibility of the adjoint, hence a nonzero Euler characteristic χ(A) (qou-obstruction-reduction), hence — via Kummer non-divisibility — a nonzero NS obstruction NS(A) = e(ξ)|_Σ (ns-obstruction, ns-kummer-specialisation), which is by definition the QOU's internal q-NS singularity at q = 1 (ns-obstruction-tower, blowup-yekutieli). The capstone qou_internal_ns_singular composes these QOU-structural steps.

    Every QOU is internally singular — from the axiom, not from χ = -6. The chain starts at the definitional observability field, so qou_internal_ns_singular holds for every QOUFluidUniverse (∀ U); the Descartes χ = -6 instance below only witnesses non-vacuity. There is no NS-regular QOU: a χ = 0 (regular) object has NS(A) = 0, which violates observability, so it is a quantum universe but not a quantum observable universe. Regularity and QOU-hood are mutually exclusive.

    Clay recasting (in-QOU boundary). Consequently the open bridge is not "which QOU?" but "is the physical fluid a QOU at all?": classical NS blows up ⟺ the fluid is the internal q = 1 flow of a QOU (satisfies observability); classical NS is globally regular ⟺ the fluid is not a QOU (fails observability, χ = 0). That embedding question is the open wall (bean qou-innq, qou_ns_surreal_bridge), deliberately not asserted.

    Non-vacuity. descartesQOU is a concrete instance (χ(A) = -6, Bring's surface) for which the whole base chain discharges sorry-free: the arithmetic -6 ≠ 0 is decidable and internalBlowup is definitionally NS(A) ≠ 0 (ns-obstruction). So descartes_internal_ns_singular is an unconditional proof that this QOU's internal q-NS is singular — the capstone is not an empty conditional.

    Two layers, honestly separated #

    • base QOUFluidUniverse — the definitional/arithmetic chain (observability → χ → obstruction → internal blow-up). Fully instantiable (descartesQOU).
    • QOUFluidUniverseLevi — adds the geometric Yekutieli–Levi equivalence (obstruction ≠ 0 ↔ Levi non-degenerate, the T8 result), which is a genuine categorical theorem, not a definition; it is kept as a conditional extension and is not collapsed to rfl in descartesQOU.

    Base ring (§7c) #

    Generic {k : Type*} [CommRing k] for the obstruction; χ(A) : ℤ; other data are Props. The concrete instance uses k = ℤ. No ℝ.

      Step 3 (ns-obstruction): a nonzero NS obstruction is, by definition, the QOU's internal q-NS singularity (NS-singular ⟺ NS(A)≠0).
