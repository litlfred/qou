    QOU.FluidDynamics.levi_pair_channel_branch_b — the linear branch, and the pair channel #

    The dual of bounded_condNumber_forces_beta_zero (levi_growth_trichotomy.lean): a linearly growing Levi condition number forces β = 1, which is branch B of conj:levi-degeneracy.

    Scope discipline. Everything here is given a QOU, and everything about the anti-parallel-pair channel is conditional on the lock formula C_L = Γ/(π ν_q) — a model input, not derived. This is a per-channel statement in the sense of the 2026-07-25 caveat on conj:levi-degeneracy: it assigns a branch to one channel under a named hypothesis. It does not decide the conjecture, and it says nothing about channels the lock does not cover.

    Why this file exists #

    conj:levi-degeneracy is a trichotomy on β = limsup_κ log C_L(κ)/log κ: β = 0 is branch A (blow-up), β = 1 is branch B (regular), and 0 < β < 1 is the marginal window C, where the regularity verdict is undetermined. The corpus records a fitted β ≈ 0.9963 for the pair channel (qns-levi-lock-scaling-probe.witness.json, field beta_fit).

    A fitted 0.9963 is exactly the shape that would put this channel in the undetermined window C. It does not: the fit is a finite-ε artifact and the true exponent is 1 on the nose. Under the lock, with ν_q = (q-1)/(2q) and ε := q - 1,

    κ²_lock = π ν_q / Γ = (π/(2Γ)) · ε/(1+ε), so C_L = 1/κ²_lock ∼ (2Γ/π)/ε,

    which is exactly linear in 1/ε; the (1+ε) is the whole discrepancy. Measured at 50 dps (qns_levi_lock_beta_exact_probe.py): the secant exponent is 0.96293 over [10⁻¹,10⁻²], 0.99999996 over [10⁻⁷,10⁻⁸], and 1.0 over [10⁻¹⁹,10⁻²⁰]. The recorded 0.9963 is a fit over a finite window, not evidence of a marginal exponent.

    linear_condNumber_forces_beta_one below is the statement that removes the ambiguity: it does not measure β, it derives β = 1 from linear growth, so no fit precision is involved and window C is excluded for any channel whose condition number is eventually linear.

    What is proved, and what is assumed #

    Proved here: linear growth ⟹ β = 1 ⟹ branch B fires (¬ leviNonDegenerate); and the linear case is realizable, so the theorem is not vacuous (linearTrichotomy).

    Assumed, and named: the lock formula itself, the identification of C_L with 1/κ²_lock, and that the ladder's ε_κ is ∼ c/κ. Those are the model inputs; this file is what follows from them.

    Base ring (§7c) #

    Archimedean: β is a limsup of real log-ratios and Real.rpow is the statement. ℝ is correct — this is on the archimedean side of the wall.

    theorem QOU.FluidDynamics.linear_condNumber_forces_beta_one {P : Prop} (T : LeviGrowthTrichotomy P) (A : ℝ) (hA : 0 < A) (N₀ : ℕ) (hlin : ∀ (κ : ℕ), N₀ ≤ κ → A * ↑κ ≤ T.condNumber κ) :
    T.beta = 1

    A linearly growing condition number forces β = 1 — branch B.

    The dual of bounded_condNumber_forces_beta_zero, and the reason the marginal window C is not where this channel lives. If C_L(κ) = A·κ eventually with A > 0, then no exponent below 1 can be an upper exponent: beta_upper at ε = (1 - β)/2 would give A·κ ≤ κ^s with s = (1+β)/2 < 1, i.e. A·κ^(1-s) ≤ 1 — but κ^(1-s) is unbounded.

    Note what is not needed: no lower bound on β, no fit, and no precision claim. beta_mem supplies β ≤ 1 and this supplies β ≥ 1.

    theorem QOU.FluidDynamics.eventually_lt_rpow (c : ℝ) (hc : 0 ≤ c) (e : ℝ) (he : 0 < e) :
    ∃ (N : ℕ), 1 ≤ N ∧ ∀ (κ : ℕ), N ≤ κ → c < ↑κ ^ e

    Eventually c < κ^e, in the "for all large κ" form beta_upper needs — exists_large_rpow gives one index, monotonicity of x ↦ x^e in the base extends it.

    The linear case is realizable #

    Without this the theorem above could be about an empty class. The witness is C_L(κ) = A·(κ+1) — linear, and positive at every index including κ = 0, which A·κ is not.
