    QOU.FluidDynamics.ns_obstruction_tower — Yekutieli obstruction tower #

    Theorem (thm:ns-obstruction-tower).

    Let (C, A, τ) be a QOU with Yekutieli obstruction classes κ_n and let Σ be the collision locus of two anti-parallel vortex filaments. Then the QOU is NS-singular iff some restricted obstruction res_Σ(κ_n) is non-zero.

    Formalisation notes #

    • Base ring (§7c). Generic {R : Type*} [CommRing R] — no ℝ. The obstruction classes take values in R; res_Σ n ≠ 0 is inequality with zero (not archimedean), so no real structure is needed.
    • Non-degenerate conditional (§3b-cond cond. 5). The two directions of the iff are carried as explicit hypotheses; ns_obstruction_tower derives the iff (Iff.intro) rather than projecting it.

    class QOU.FluidDynamics.NsObstructionTowerContext (R : Type u_1) [CommRing R] :
    Type u_1

    Hypotheses for the Yekutieli obstruction-tower criterion (§7c: generic CommRing, no ℝ). The sufficiency and necessity directions are explicit; the theorem derives the iff.

    • kappa : ℕ → R

      Yekutieli obstruction classes κ_n indexed by n : ℕ.

    • res_sigma : ℕ → R

      Restriction res_Σ(κ_n) of κ_n to the collision locus Σ.

    • is_NS_singular : Prop

      Predicate: the QOU is NS-singular (blowup occurs).

    • obstruction_forces_singular : (∃ (n : ℕ), res_sigma n ≠ 0) → is_NS_singular R

      Sufficiency (deep): a non-vanishing restricted obstruction forces blowup.

    • singular_exhibits_obstruction : is_NS_singular R → ∃ (n : ℕ), res_sigma n ≠ 0

      Necessity: blowup exhibits a non-vanishing restricted obstruction.
