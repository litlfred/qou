        class QOU.FlavorDressing.FlavorDressingFunctor :
        Type

        Flavor dressing functor. Assigns a dressed-mass scale μ q ∈ ℝ to each quark flavor with the positivity hypothesis 0 < μ q.

        The discrete-category framing makes the assignment compatible with the chapter's other categorical constructions (Markov trace, Hoefsmit functor, Wedderburn block decomposition): flavor-sums in hadronic mass formulas are then intended to read as natural transformations rather than ad-hoc weighted sums.

        Naming note (functor vs. object-map). A functor out of a discrete category is exactly an object-map (every morphism is an identity), so calling μ a "functor" is defensible — but note this class encodes only the object-map μ : Flavor → ℝ (+ positivity); it is not a CategoryTheory.Functor, and no natural transformation is formalised here. The "natural transformations" remark above is the intended categorical reading, not encoded structure.

        Instances at specific substrate parameter values (e.g. q = q₀) live in sibling files; this class carries only the structural signature + positivity.

        • μ : Flavor → ℝ

          Dressed-mass scale at each flavor, in physical units (MeV).

        • μ_pos (q : Flavor) : 0 < μ q

          Positivity: every dressed quark mass is strictly positive.
