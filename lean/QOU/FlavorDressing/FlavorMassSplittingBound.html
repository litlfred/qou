    QOU.FlavorDressing.flavor_mass_splitting_bound #

    Two-sided substrate bound on the down–up dressed-quark splitting:

    0 < μ_d − μ_u < M_N · ℏ_q² · h_q · [2]_q

    with ℏ_q = (q − 1)/q, h_q = q − q⁻¹, [2]_q = q + q⁻¹.

    The lower bound is positivity; the upper bound follows from the algebraic identity

    (q − 1)²(1 − q⁻⁴)/3 = (1/3) · ℏ_q² · h_q · [2]_q

    at non-zero q (no spurious q² factor — see direct expansion in the lemma substrate_to_bound_ratio below).

    LaTeX: \label{thm:flavor-mass-splitting-bound}

    source
    theorem QOU.FlavorDressing.substrate_to_bound_ratio {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) (hq4 : q ^ 4 ≠ 1) (h3 : 3 ≠ 0) :
    (q - 1) ^ 2 * (1 - q ^ (-4)) / 3 / (((q - 1) / q) ^ 2 * (q - q⁻¹) * (q + q⁻¹)) = 1 / 3

    The substrate ratio (q − 1)²(1 − q⁻⁴)/3 over the bound factor ℏ_q² · h_q · [2]_q equals exactly 1/3 for any non-zero q. This algebraic identity is the engine of the upper bound; stated over a generic Field R per the repository's base-ring convention (AGENTS.md §7c) — the identity is a rational-function fact with no archimedean content. The downstream inequality flavor_mass_splitting_bound keeps its ℝ specialisation because it uses ordering.

    The hypothesis (3 : R) ≠ 0 rules out characteristic 3, where 1/3 itself is undefined; in ℝ, ℚ, or any char-0 field this is automatic.

    Positivity and inequality helpers (at q > 1) #

    source
    theorem QOU.FlavorDressing.flavor_mass_splitting_bound (F : FlavorDressingFunctor) (M_N q : ℝ) (hM : 0 < M_N) (hq : 1 < q) (h_derive : FlavorDressingFunctor.μ Flavor.down - FlavorDressingFunctor.μ Flavor.up = M_N * substrate_split_factor q) :
    0 < FlavorDressingFunctor.μ Flavor.down - FlavorDressingFunctor.μ Flavor.up ∧ FlavorDressingFunctor.μ Flavor.down - FlavorDressingFunctor.μ Flavor.up < M_N * (((q - 1) / q) ^ 2 * (q - q⁻¹) * (q + q⁻¹))

    Substrate bound on the dressed-quark splitting. For substrate parameter q > 1, nucleon average mass M_N > 0, and any FlavorDressingFunctor F satisfying the derivation identity of prop:flavor-dressed-mass-from-substrate-split, the down–up splitting satisfies the two-sided substrate bound

    0 < μ_d − μ_u < M_N · ℏ_q² · h_q · [2]_q

    where ℏ_q = (q − 1)/q, h_q = q − q⁻¹, [2]_q = q + q⁻¹.

    The strict lower bound expresses positivity of the substrate factor at q > 1; the strict upper bound uses the algebraic identity substrate_to_bound_ratio plus the Skein-side adjustment factor (q^{1/2}+q⁻^{1/2})/(q+q⁻¹) < 1 at q > 1.

    Conditional content: the realised value of μ_d − μ_u sits at about 1/3 of the upper bound at q = q₀; the theorem does NOT claim tightness. Tightness would require a finer substrate factor incorporating the Skein adjustment explicitly.
