    QOU.FlavorDressing.dressed_mass_from_substrate_split #

    The substrate-pure derivation of the down–up dressed-quark mass splitting:

    μ_d − μ_u = M_N · (q-1)²·(1 − q⁻⁴)/3 · (q^{1/2} + q⁻^{1/2})/(q + q⁻¹)
            + O((Δm/M_N)²)

    This is the categorical lift of prop:flavor-split-substrate to the level of the flavor-dressing functor.

    LaTeX: \label{prop:flavor-dressed-mass-from-substrate-split}

    source
    noncomputable def QOU.FlavorDressing.substrate_split_factor (q : ℝ) :
    ℝ

    The leading-order substrate factor

    s(q) = (q − 1)² · (1 − q⁻⁴) / 3 · (√q + 1/√q) / (q + 1/q)

    that multiplies M_N to give the dressed-quark splitting at substrate parameter q ∈ ℝ, 0 < q. Defined as a function on ℝ (we are at the archimedean / numerical layer here per AGENTS.md §7c).

      source
      class QOU.FlavorDressing.DressedMassSubstrateSplit (F : FlavorDressingFunctor) (M_N q : ℝ) :
      Prop

      External Skein-side hypothesis (axiomatised). The pair-Skein mass formula of lem:pair-skein-mass-formula applied to the Borromean baryon braids of the proton and neutron gives

      m_n − m_p = (q + q⁻¹)/(q^{1/2} + q⁻^{1/2}) · (μ_d − μ_u).

      Combined with the substrate identity (m_n − m_p)/M_N = (q-1)² · (1 − q⁻⁴) / 3 (from prop:flavor-split-substrate), this rearranges to μ_d − μ_u = M_N · substrate_split_factor q. The closed-form statement is recorded as this axiom; promoting it to a theorem requires Lean formalisations of both upstream lemmas. This was an axiom until 2026-08-08, and it made the library inconsistent. It read

      axiom dressed_mass_split_substrate_closed_form
    (F : FlavorDressingFunctor) (M_N q : ℝ) (_hM : 0 < M_N) (_hq : 1 < q) :
    F.μ Flavor.down - F.μ Flavor.up = M_N * substrate_split_factor q

      F, M_N and q are all universally quantified and mutually unrelated: nothing ties M_N to F. The left side is fixed by F alone, the right side varies freely with M_N. Take the constant dressing μ ≡ 1 (the class is trivially inhabited, μ_pos is one_pos), so the left side is 1 − 1 = 0, and instantiate at M_N = 1, q = 2:

      theorem dressed_mass_axiom_is_inconsistent : False := by
  have h := dressed_mass_split_substrate_closed_form flatF 1 2 one_pos (by norm_num)
  simp [flatF, substrate_split_factor] at h
  …  -- √2 + (√2)⁻¹ = 0, false since √2 > 0

      That compiled, with #print axioms naming this axiom. Because substrate_split_factor is a concrete strictly-positive expression rather than an opaque symbol, the forced factor = 0 is refutable, so the defect is False rather than mere collapse.

      Worth noting how it got here: the docstring below records that a review (Gemini #696) flagged the downstream theorem as a tautology, and the repair was to introduce this axiom. The tautology fix over-corrected into unsoundness — the statement stopped being empty by starting to be false.

      The repair is the §3b-cond hypothesis class below, with no instance: the relation holds for a particular (F, M_N, q) — the nucleon-mass scale belonging to that dressing — not for arbitrary triples.

      • M_N_pos : 0 < M_N

        The nucleon-mass scale is positive.

      • q_gt_one : 1 < q

        The substrate parameter is above the classical point.

      • split : FlavorDressingFunctor.μ Flavor.down - FlavorDressingFunctor.μ Flavor.up = M_N * substrate_split_factor q

        The closed form itself: μ_d − μ_u = M_N · s(q), for this M_N (the nucleon-mass scale of this dressing F) — the content of prop:flavor-split-substrate combined with lem:pair-skein-mass-formula, pending Lean formalisations of both.
