    QOU.TopologicalMass.cat_transient_localises_blowup #

    Lemma (lem:topological-mass-cat-transient).

    The transient component α − τ̂ₙ(α) ∈ 𝓐_{n+1}^{trans} has support contained in the union of the kernels of 𝔡_{n+1} at the blow-up centres p₁, …, p_N, and the transient trace decomposes as a sum of disjoint local contributions:

    tr(α − τ̂ₙ(α)) = Σ_{i=1}^{N} tr_trans(ϱ, p_i).

    Structure (hypothesis vs. derivation) #

    Everything is a parameter; nothing is a named constant.

    • The observation algebra 𝓐_{n+1} is an arbitrary R-module A over a generic commutative ring R (§7c: the statement is linear algebra, so no archimedean structure is needed). The descent projector τ̂ₙ is an arbitrary map A → A, the Frobenius trace an arbitrary R-linear functional A →ₗ[R] R, and the jet differential at the i-th centre an arbitrary R-linear map 𝔡ᵢ : A →ₗ[R] B.
    • Hypothesis (the .md's first clause, the open geometric input). hsupp: the transient component lies in the span of the local kernels, α − τ̂ₙ(α) ∈ ⨆_{i<N} ker 𝔡ᵢ. This is the jet-filtration support statement, which is not derived here; it is carried as an explicit hypothesis of the theorem rather than as a class field projected back.
    • Hypothesis (disjointness). hindep: the local kernels are independent (iSupIndep), the formal content of the proof block's "mutually disjoint submodules".
    • Derived. From hsupp the transient component splits into local pieces cᵢ ∈ ker 𝔡ᵢ (Submodule.mem_iSup_finset_iff_exists_sum), the linear trace distributes over the split (map_sum), and under hindep the local pieces — hence the local traces tr_trans(ϱ, pᵢ) := tr(cᵢ) — are unique, so tr_trans(ϱ, pᵢ) is well defined (localPiece_unique).

    The conclusion is not assumed anywhere: no hypothesis mentions the trace.

    An earlier revision modelled every input as a named opaque real and carried the decomposition itself as a Prop-class field projected back by transient_decomposition (a self-assuming projection); an earlier one still defined the inputs as 0 / the identity. Bean tmvac.

      theorem QOU.TopologicalMass.cat_transient_localises_blowup {R : Type u_1} {A : Type u_2} {B : Type u_3} [CommRing R] [AddCommGroup A] [Module R A] [AddCommGroup B] [Module R B] (alpha : A) (tauHat : A → A) (trFrob : A →ₗ[R] R) (d : ℕ → A →ₗ[R] B) (N : ℕ) (hsupp : alpha - tauHat alpha ∈ ⨆ i ∈ Finset.range N, CatTransient.localKer d i) :
      ∃ (c : ℕ → A), (∀ (i : ℕ), c i ∈ CatTransient.localKer d i) ∧ ∑ i ∈ Finset.range N, c i = alpha - tauHat alpha ∧ trFrob (alpha - tauHat alpha) = ∑ i ∈ Finset.range N, trFrob (c i)

      Transient trace localises to the blow-up centres ([lem:topological-mass-cat-transient]).

      Given the support hypothesis hsupp (the transient component α − τ̂ₙ(α) lies in the span of the local kernels ker 𝔡ᵢ, i < N), there are local pieces cᵢ ∈ ker 𝔡ᵢ such that tr(α − τ̂ₙ(α)) = Σ_{i<N} tr(cᵢ), i.e. the trace is a sum of local contributions tr_trans(ϱ, pᵢ) := tr(cᵢ). Derived: split by the support hypothesis, then distribute the linear trace (map_sum). When the kernels are disjoint (hindep), the pieces are unique (CatTransient.localPiece_unique), so the local contributions are well defined.
