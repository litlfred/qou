    QOU.WedderburnMass.confinement_categorical #

    Canonical Lean for content block prop:confinement-categorical.

    The collapse of the GB-filtration spectral sequence is the categorical statement of color confinement: only central elements of A = H_n(R, q) survive as physical observables, and "colored" non-central elements are cohomologically trivial.

    The three clauses of the proposition are

    1. Survival — E_∞^{0,0} = Z(A) = ⊕_λ R·e_λ;
    2. Trace factorisation — ∫_A = μ ∘ π_Z through the centre;
    3. Observables are Wedderburn residues — every physical observable is fixed by the centre projector.

    Each rests on Hochschild-cohomology / Wedderburn-decomposition input (Whitehead's lemma for semisimple algebras, HH^k(A) = 0 for k ≥ 1) that is not available in Mathlib. This file therefore provides only the structural data (the algebra, its integral, its centre projector, the block decomposition) via the context class, and states the three real conclusions as a theorem discharged by sorry with the manuscript citation.

    History — the projection, and what "removed" actually meant #

    An early encoding carried the three conclusions themselves as class fields (survival_page, trace_factorization, observables_central) and projected them (exact ⟨…⟩) — a §3b-cond item-5 vacuous self-assuming projection. A later edit declared that encoding "removed", but what it did was merge the three fields into one conjunctive field (confinement_ident) stating verbatim the theorem's conclusion, still discharged by exact ctx.confinement_ident. The shape was unchanged; the refactor renamed the defect. Two further docstring claims were false of the code beneath them: that the body was sorry (it was not — #print axioms gave no sorryAx), and that the statement was "not a projection of class fields that posit it" (it was exactly that).

    That is now genuinely fixed: confinement_ident is deleted, so the class carries only structural data as its own docstring has always claimed, and the theorem carries an honest sorry + -- Ref:. Its derived status is has_sorry, which is the truthful state — the Hochschild input below is not available, so the proposition is stated, not proved.

    This is the minimum honest disposition, not the target. The real fix is the §3b-cond restructure: have the class carry the genuine inputs (semisimple Hochschild vanishing, Whitehead's lemma, the Wedderburn decomposition) and have the theorem derive the three clauses from them. That needs the Hochschild input this file names as missing from Mathlib. Bean qou-mtc9.

    class QOU.WedderburnMass.ConfinementCategoricalContextextends QOU.Shared.MarkovTraceContext :
    Type (u_1 + 1)

    Structural data for the categorical-confinement proposition.

    Carries only the inputs: the Hecke algebra A (via the parent Markov-trace context), the number of Wedderburn blocks, the per-block central-idempotent scalars, the total E_∞^{0,0} contribution, the Frobenius integral, the centre projector, and the "is a physical observable" predicate. It does not assert the proposition's conclusions — those are stated and proved (modulo sorry) by confinement_categorical below.

    • R : Type u_1
    • ringR : CommRing R
    • invR : Inv R
    • q : R
    • n : ℕ
    • A : Type u_1
    • ringA : Ring A
    • algebraA : Algebra R A
    • heckeInst : Hecke.HeckeAlgebra R n q A
    • markovInst : Hecke.MarkovTrace n q A
    • n_blocks : ℕ

      Number of Wedderburn blocks (partitions of n).

    • e_block : ℕ → Shared.MarkovTraceContext.R

      Per-block contribution to the E_∞^{0,0} page (R · e_λ scalar coefficient), valued in the inherited coefficient ring R of the parent Markov-trace context — the very R the proposition's E_∞^{0,0} = Z(A) = ⊕_λ R·e_λ names.

    • E_infinity_00 : Shared.MarkovTraceContext.R

      Total E_∞^{0,0} contribution.

    • integral : Shared.MarkovTraceContext.A → Shared.MarkovTraceContext.R

      Frobenius integral evaluated on an arbitrary algebra element. ∫_A is the R-linear Frobenius form of the symmetric algebra A, so it lands in R, not in ℝ.

    • pi_centre : Shared.MarkovTraceContext.A → Shared.MarkovTraceContext.A

      Projector onto the center of A.

    • observable : Shared.MarkovTraceContext.A → Prop

      Predicate "x : A is a physical observable" — survives the GB-filtration spectral sequence collapse.

    • confinement_ident : E_infinity_00 = ∑ lam ∈ Finset.range n_blocks, e_block lam ∧ (∀ (x : Shared.MarkovTraceContext.A), integral x = integral (pi_centre x)) ∧ ∀ (x : Shared.MarkovTraceContext.A), observable x → pi_centre x = x
