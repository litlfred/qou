        theorem Polynomial.genWronskian_eq_zero_of_dependent {R : Type u_1} [CommRing R] {m : ℕ} [IsDomain R] (f : Fin m → Polynomial R) (c : Fin m → R) (hc : c ≠ 0) (h : ∑ j : Fin m, C (c j) * f j = 0) :
        genWronskian f = 0

        A linear dependence kills the generalized Wronskian.

        If ∑ⱼ cⱼ · fⱼ = 0 with the constants c not all zero, then differentiating i times gives ∑ⱼ cⱼ · fⱼ⁽ⁱ⁾ = 0 for every i — that is exactly the statement that the constant vector c is in the kernel of the Wronskian matrix, so the determinant vanishes.

        The contrapositive is what Roth's lemma consumes: a non-zero generalized Wronskian certifies linear independence.

        source
        theorem Polynomial.genWronskian_one_X :

        ⚠ Non-vacuity: a non-zero generalized Wronskian occurs.

        genWronskian_eq_zero_of_dependent is used through its contrapositive — non-zero Wronskian ⟹ linearly independent — which certifies nothing if the Wronskian is always zero. It is not: 1 and X give the identity matrix and Wronskian 1.

        Worth pinning because the vanishing theorem alone is consistent with a definition that returns 0 identically, and every downstream use would still typecheck.

        The converse at m = 2, in characteristic zero #

        The base case of the induction the general statement needs. Mathlib already supplies the two facts that make it short — IsCoprime.wronskian_eq_zero_iff (for coprime arguments the Wronskian vanishes exactly when both derivatives do) and eq_C_of_derivative_eq_zero (in characteristic zero a polynomial with zero derivative is constant). What is missing is the reduction to the coprime case, which is the scaling identity below.

        The Wronskian scales quadratically under a common factor: W(ga, gb) = g² W(a, b).

        This is what reduces the general case to the coprime one — divide out the gcd.

        theorem Polynomial.exists_dependence_of_wronskian_eq_zero {K : Type u_2} [Field K] [CharZero K] [DecidableEq K] {a b : Polynomial K} (ha : a ≠ 0) (hw : a.wronskian b = 0) :
        ∃ (c : K) (d : K), c ≠ 0 ∧ C c * b + C d * a = 0

        The converse at m = 2 in characteristic zero: a vanishing Wronskian forces a linear dependence with constant coefficients.

        Divide by the gcd to reach coprime a₁, b₁; the scaling identity kills g², so W(a₁, b₁) = 0; coprimality turns that into a₁' = b₁' = 0; characteristic zero makes both constant; and b₁ · a − a₁ · b = 0 is then the dependence.

        ⚠ Stated for a field because the gcd step needs one. The general-m statement, which Roth's lemma actually consumes, is an induction with this as its base; it is proved below as exists_dependence_of_genWronskian_eq_zero, and consumes this lemma directly.

        The crux of the general-m induction: derivative descent #

        The general converse (a vanishing Wronskian forces a constant dependence, any m) goes classically like this: the vanishing determinant gives a kernel vector c over the function field, so ∑ⱼ cⱼ · fⱼ⁽ⁱ⁾ = 0 for i = 0, …, m−1; one then shows the cⱼ are constants, which is what upgrades a K(X)-dependence to the K-dependence wanted.

        That upgrade is the mathematical content, and it is the lemma below. Everything else in the induction is rank and minor bookkeeping over RatFunc K.

        Stated over a plain commutative ring — no field, no characteristic hypothesis — because the argument is only the product rule plus re-indexing.

        source
        theorem Polynomial.sum_derivative_of_forall_sum_eq_zero {R : Type u_1} [CommRing R] {m : ℕ} (f c : Fin m → Polynomial R) (k : ℕ) (h : ∀ i ≤ k, ∑ j : Fin m, c j * (⇑derivative)^[i] (f j) = 0) (i : ℕ) :
        i < k → ∑ j : Fin m, derivative (c j) * (⇑derivative)^[i] (f j) = 0

        Derivative descent. If a coefficient vector annihilates the first k + 1 derivative rows, its own derivative annihilates the first k.

        Differentiating the i-th relation gives ∑ⱼ cⱼ′ fⱼ⁽ⁱ⁾ + ∑ⱼ cⱼ fⱼ⁽ⁱ⁺¹⁾ = 0, and the second sum is the (i+1)-st relation, hence zero — which is exactly why the hypothesis must reach one row further than the conclusion.

        Iterating this is what forces every cⱼ to be constant in the classical proof.

        source
        theorem Polynomial.sum_derivative_descent_witness (i : ℕ) :
        i < 3 → ∑ j : Fin (Nat.succ 1), derivative (![X, -X] j) * (⇑derivative)^[i] (![X, X] j) = 0

        ⚠ The hypothesis is satisfiable with a non-constant c, so the lemma is not about an empty range.

        At k = 0 the conclusion quantifies over i < 0 and says nothing, so the content lives entirely at k ≥ 1 — and a reader could reasonably wonder whether the hypothesis can hold that far with c non-constant, since for independent f it cannot. It can when the f are dependent, which is exactly the situation the induction is in: f = ![X, X] with c = ![X, −X] annihilates every derivative row.

        theorem Polynomial.sum_wronskian_combo_eq_zero {R : Type u_1} [CommRing R] {m : ℕ} (f c : Fin m → Polynomial R) (k : ℕ) (l : Fin m) (h : ∀ i ≤ k, ∑ j : Fin m, c j * (⇑derivative)^[i] (f j) = 0) (i : ℕ) :
        i < k → ∑ j : Fin m, (c l).wronskian (c j) * (⇑derivative)^[i] (f j) = 0

        The Wronskian combination of a kernel vector is again a kernel vector (one row shorter), and its l-th entry is zero.

        ∑ⱼ W(c_l, cⱼ) · fⱼ⁽ⁱ⁾ = c_l · (∑ⱼ cⱼ′ fⱼ⁽ⁱ⁾) − c_l′ · (∑ⱼ cⱼ fⱼ⁽ⁱ⁾), and both brackets vanish — the first by derivative descent, the second by hypothesis.

        ⚠ This is what removes the need for the function field. The classical proof normalises the kernel vector so that its last entry is 1, which requires dividing and so forces the argument into RatFunc K. Multiplying by c_l instead of dividing achieves the same cancellation inside R[X], and the resulting entries are literally wronskian (c l) (c j) — so exists_dependence_of_wronskian_eq_zero above applies to them directly.

        theorem Polynomial.exists_constant_dependence_of_wronskians_vanish {K : Type u_2} [Field K] [CharZero K] {m : ℕ} (f c : Fin m → Polynomial K) (l : Fin m) (hl : c l ≠ 0) (hw : ∀ (j : Fin m), (c l).wronskian (c j) = 0) (h0 : ∑ j : Fin m, c j * f j = 0) :
        ∃ (lam : Fin m → K), lam ≠ 0 ∧ ∑ j : Fin m, C (lam j) * f j = 0

        Steps 4–5. Once every wronskian (c l) (c j) vanishes and c l ≠ 0, the polynomial kernel vector collapses to a constant one — and that constant vector is non-zero.

        ⚠ The non-triviality is the part that is easy to lose. Cancelling c l gives ∑ⱼ C λⱼ · fⱼ = 0 whatever λ is, and λ = 0 satisfies that vacuously — so a proof that stops at cancellation has proved nothing. What rules it out is the relation at j = l: c l = C (λ l) * c l with c l ≠ 0 in a domain forces λ l = 1. Hence λ ≠ 0.

        0 < m → ∀ (f : Fin m → Polynomial K), genWronskian f = 0 → ∃ (lam : Fin m → K), lam ≠ 0 ∧ ∑ j : Fin m, C (lam j) * f j = 0

        The converse: a vanishing generalized Wronskian forces a constant linear dependence.

        Induction on m. Either the leading minor already degenerates — and the inductive hypothesis finishes, extending by zero — or it does not, and then the kernel vector's last entry is non-zero, sum_wronskian_combo_eq_zero produces a kernel vector of the non-degenerate minor, which is therefore zero, which is exactly the hypothesis of exists_constant_dependence_of_wronskians_vanish.

        theorem Polynomial.genWronskian_eq_zero_iff {K : Type u_2} [Field K] [CharZero K] {m : ℕ} (f : Fin m → Polynomial K) (hm : 0 < m) :
        genWronskian f = 0 ↔ ∃ (lam : Fin m → K), lam ≠ 0 ∧ ∑ j : Fin m, C (lam j) * f j = 0

        Linear dependence over the constants is exactly a vanishing generalized Wronskian, in characteristic zero.

        This is the form Roth's lemma consumes: a non-zero generalized Wronskian is a certificate of linear independence.

        The general-m converse is proved — genWronskian_eq_zero_iff above. The route recorded here earlier (kernel vector, induction, Wronskian combination, the m = 2 converse, substitution) went through as stated, and stayed inside K[X]: the RatFunc K ratio argument the first draft of this file called for was never needed.

        ⚠ One step of that recorded route was wrong, and worth keeping visible. Step 5 read "substituting, c_m · (∑ⱼ λⱼ fⱼ) = 0, and c_m ≠ 0 in a domain gives the constant dependence". That produces ∑ⱼ λⱼ fⱼ = 0 and says nothing about λ ≠ 0 — but λ = 0 satisfies the conclusion vacuously, so as written the step would have licensed a proof of nothing. The repair comes from a step already proved: applying the m = 2 converse at j = l forces λ_l = 1. See the ⚠ on exists_constant_dependence_of_wronskians_vanish.

        The estimate that steps 1, 2 and 5 were "matrix bookkeeping" did hold: they needed no new mathematics, only Fin.lastCases/Fin.snoc surgery and two structural helpers.

        Still open, and materially harder:

        • it is false in characteristic p for the naive derivative (xᵖ has every derivative zero, so 1, xᵖ are independent with vanishing Wronskian), so it needs characteristic zero or a restatement over Hasse derivatives;
        • in several variables it needs generalized operators — products of partials of bounded total order — not just the iterated single derivative used here, and a choice of which m of them to take.

        Stated rather than assumed, so nothing downstream can quietly consume it.
