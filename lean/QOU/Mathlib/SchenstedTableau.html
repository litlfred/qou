    Schensted insertion tableaux as Mathlib SemistandardYoungTableau #

    Brick 7 — SSYT-object realization. Bricks 1–6b built the row-insertion map insertWord / insertWordRec and proved the list-form invariants (RowsSorted, ColStrict) together with the general-index monotonicity lemmas (rowsSorted_getD_le, colStrict_getD_lt) and the shape lemmas (colShapeYoung_iff_shape, colStrict_len_le).

    Here we package any list tableau T : List (List ℕ) whose rows are weakly increasing (RowsSorted) and whose columns are strictly increasing (ColStrict) as an honest Mathlib SemistandardYoungTableau (YoungDiagram.ofRowLens (tableauShape T) _), with

    entry i j := (T.getD i []).getD j 0.

    The three structure obligations discharge directly:

    • row_weak' ← rowsSorted_getD_le,
    • col_strict' ← colStrict_getD_lt,
    • zeros' ← List.getElem?_eq_none past the row length.

    The row-length shape tableauShape T is a valid ofRowLens argument because column-strictness forces the row lengths to weakly decrease (colShapeYoung_iff_shape + IsChain.pairwise).

    Specialising to T = insertWord w gives the semistandard insertion tableau P(w) of a word as a Mathlib object (insertWordSSYT), the first bridge from the QOU RSK program into Mathlib's numStandardYoungTableaux world.

    (tableauShape T).getD i 0 = (T.getD i []).length

    Row-length lookup of the shape is the length of that row (out-of-range rows are empty on both sides, so this holds unconditionally).

    (i, j) ∈ YoungDiagram.ofRowLens (tableauShape T) hw ↔ j < (T.getD i []).length

    Membership in the row-length Young diagram, expressed via getD on T. Routed through the unconditional shape_getD and Mathlib's own getElem? lemmas, so it does not depend on the getD_row_* case split.
