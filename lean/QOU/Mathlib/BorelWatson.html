    theorem QOU.Mathlib.Borel.factorialPow_succ_le_iff {K : Type u_1} [Field K] [LinearOrder K] [IsStrictOrderedRing K] {x : K} (hx : 0 < x) (N : ℕ) :
    ↑(N + 1).factorial * x ^ (N + 1) ≤ ↑N.factorial * x ^ N ↔ (↑N + 1) * x ≤ 1

    Least-term index (pre-archimedean). For 0 < x in any linearly ordered field, the truncation term t_N = N!·xᴺ stops decreasing exactly when (N+1)·x > 1: t_{N+1} ≤ t_N ↔ (N+1)·x ≤ 1. No exp, no completeness — pure order theory; the least term therefore sits at N ≈ 1/x.

    Archimedean: the least-term value is e^{−1/x} (ℝ, Stirling) #

    source
    theorem QOU.Mathlib.Borel.gevrey1_remainder_expDecay {C x a : ℝ} (hC : 0 ≤ C) (hx0 : 0 < x) (hx1 : x ≤ 1) (_ha : 0 ≤ a) (hbound : ∀ (N : ℕ), a ≤ C * ↑N.factorial * x ^ N) :
    a ≤ C * Real.exp 2 / √x * Real.exp (-1 / x)

    Gevrey-1 remainder ⇒ exponential decay (archimedean). If a nonnegative real a is dominated by the Gevrey-1 truncation bound a ≤ C·N!·xᴺ for every N, then a is exponentially small: a ≤ C·e²·x^{-1/2}·e^{−1/x} for 0 < x ≤ 1. Evaluating the bound at the least-term index N = ⌊1/x⌋ and applying brick 1 (factorial_le_stirling_upper, N! ≤ e√N(N/e)ᴺ) collapses (Nx/e)ᴺ to e^{−N} ≤ e·e^{−1/x}. This is the analytic heart of Watson uniqueness — exponential (super-polynomial) smallness that a >π-sector Phragmén–Lindelöf argument (brick 3) turns into a = 0.
