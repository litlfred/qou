            §3 The oper condition #

            structure QOU.Mathlib.QOper.QOper2 (K : Type u_1) [Field K] extends QOU.Mathlib.QOper.QConnection2 K :
            Type u_1

            A rank-2 q-connection is a q-oper when its (2,1) entry is identically 1 (the oper gauge). In this gauge, A takes the form:

            A(x) = [ t(x)   -Δ(x) ]
       [  1      0     ]

            where t is the trace and Δ is the quantum Wronskian (determinant).

            • a₁₁ : K → K

              The oper gauge: a₂₂ = 0.

                  def QOU.Mathlib.QOper.satisfiesEq (K : Type u_1) [Field K] (A : QOper2 K) (q : K) (y : K → K) :
                  Prop

                  The q-oper equation. A q-oper A determines the second-order q-difference equation on a function y : K → K: y(q²x) − t(x) · y(qx) + Δ(x) · y(x) = 0. This is the q-analogue of the differential equation on P¹ that the oper connection encodes.
