    QOU.Mathlib.PartitionsOfBridge — partitionsOf n enumerates Nat.Partition n; RSK/Burnside n ≤ 12 #

    The Identity I combinatorics run decide over the fuel-based list enumerator QOU.BraidKnot.IdentityI.partitionsOf n (all weakly-decreasing positive List ℕ summing to n), while the abstract Plancherel/RSK statements range over Mathlib's Nat.Partition n. PartitionListBridge supplies the pointwise dictionary (toList / ofList); what was missing is the enumeration bridge: that partitionsOf n lists exactly the image of toList, each partition once. This file proves it and cashes it out:

    • mem_partsFuel_sound / mem_partsFuel_complete / partsFuel_nodup — soundness, completeness, and duplicate-freeness of the fuel-based enumerator, by induction on the fuel;
    • mem_partitionsOf / partitionsOf_nodup — the corollaries at fuel = target = cap = n;
    • toFinset_partitionsOf — (partitionsOf n).toFinset = Finset.univ.image toList;
    • sum_map_partitionsOf — sum transport: ((partitionsOf n).map g).sum = Σ_{p ⊢ n} g (toList p);
    • rskBurnsideHolds_le12 — the RSK/Burnside identity Σ_{p ⊢ n} dimSYT(p)² = n! for all n ≤ 12, by feeding the decide-verified list-model data dim_validated_le12 through rskBurnsideHolds_iff_dimHLF (which rests on the now-proved hook-length bridge dimSYT_eq_dimHLF). This grounds the n ≤ 12 Plancherel instances in the genuine #SYT count with no RSK correspondence and no SYT structure theory.

    (A direct kernel decide on the Nat.Partition n-indexed sum is not possible: the Fintype instance for Nat.Partition n does not reduce in the kernel — verified empirically. The list enumerator is the computable face; this bridge is what connects it to the abstract index.)

    Pure combinatorics on ℕ; nothing archimedean; no fit.

    Σ_{λ ⊢ n} dimHLF(λ)² = n! for every n — the list-model dimension certificate that dim_validated_le12 establishes by decide at n ≤ 12, now available at every n.

    This is rskBurnsideHolds_le12 run backwards: that theorem transports the decide-verified list identity up to the abstract Nat.Partition index; this one transports the Robinson–Schensted theorem (QOU.Mathlib.rskBurnsideHolds) down to the list index, through the same two bridges — rskBurnsideHolds_iff_dimHLF for the hook-length identification and sum_map_partitionsOf for the enumeration.

    Consumers that were capped at n ≤ 12 only because dim_validated_le12 was a finite check can use this instead; dim_validated_le12 remains the cheaper route inside its range.
