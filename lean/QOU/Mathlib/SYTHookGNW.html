    QOU.Mathlib.SYTHookGNW — corner-recursion route for the general HLF (GNW) #

    The general dimension hook-length formula numSYTenum l = dimHLF l was once isolated to the single Aitken/Frobenius determinant identity (ii), blocked by the pinned Mathlib (no Combinatorics.RSK / Specht / Frobenius-determinant infrastructure). This file closes it sorry-free via the Greene–Nijenhuis–Wilf corner-recursion route, which needs none of that infrastructure — pure ℕ/ℚ combinatorics — from two identities, both now proved:

    • corner recursion of the count (cornerRecursion): numSYTenum λ = Σ_{removable corners c} numSYTenum (λ ∖ c) — sorry-free in SYTCornerListConnection.cornerRecursion_proof, via the structural branching rule on StandardYoungTableau (SYTBranchingRule) and the diagram↔list corner correspondence;
    • GNW hook-summation identity (gnwHookIdentity, over ℚ): Σ_{corners c} ∏h_λ / ∏h_{λ∖c} = n — the partial-fractions / telescoping identity on hook products, sorry-free in SYTHookGNWRatio.gnwHookIdentity_proof (per-corner hook ratio + the β-Lagrange Vandermonde keystone in SYTBetaLagrange).

    A strong induction on n = sz l combines the two into the divisor-free HLF #SYT(λ)·∏h_λ = n!, whence the Aitken identity and the general HLF. Because the corner-removal infrastructure (SYTListCorner) sits downstream of SYTHookFormulaGeneral, the canonical sorry-free names dimAitkenIdentity and numSYTenum_eq_dimHLF live here (the former SYTHookFormulaGeneral versions carried the now-retired cited sorry).

    Pure combinatorics on ℕ/ℚ; nothing archimedean; no fit.

    theorem QOU.Mathlib.SYTEnum.gnwHookIdentity (l : List ℕ) (hl : List.Sorted (fun (x1 x2 : ℕ) => x1 ≥ x2) l) (hpos : ∀ a ∈ l, 0 < a) (hne : l ≠ []) :
    (List.map (fun (c : ℕ) => ↑(BraidKnot.IdentityI.prodHooks l) / ↑(BraidKnot.IdentityI.prodHooks (removeCorner l c))) (corners l)).sum = ↑(BraidKnot.IdentityI.sz l)

    (GNW hook) hook-summation identity — the sole remaining gap of the GNW route. Summing the hook-product ratios over the removable corners gives the cell count: ∑_{corners c} ∏h_λ / ∏h_{λ∖c} = n. This is the partial-fractions / telescoping core of the Greene–Nijenhuis–Wilf proof — the rational identity that turns the count recursion into the hook-length formula.

    Closure (PROVED, sorry-free). Via the already-proved β-number identity (i) (SYTHookFormulaGeneral.prodHooks_mul_betaProdGap: ∏h_λ · betaProdGap = betaFactProd, β_i = λ_i + (k−1−i)), each ratio rewrites as a β-ratio, reducing this to the β-Lagrange identity

    ∑_i β_i · ∏_{j≠i} (β_i − 1 − β_j) / (β_i − β_j) = (∑_i β_i) − C(k,2)   ( = sz l ),

    a self-contained ℚ partial-fractions identity over the distinct β_i (non-corner i drop out because β_i − 1 = β_{i+1} there). The β-Lagrange identity is proved in SYTBetaLagrange.betaLagrange via the Vandermonde/det_vandermonde keystone (SYTVandermonde.interp_leadingCoeff); the per-corner hook ratio (SYTHookGNWRatio.prodHooks_ratio/prodHooks_removeCorner, incl. the row-drop corner) and the assembly over corners (SYTHookGNWRatio.gnwHookIdentity_proof) discharge this identity outright.
