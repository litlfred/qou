    QOU.Mathlib.ColLenRowLensBridge — the list↔diagram column-length bridge #

    The corpus carries two column-length notions that the geometric hook-length formula must identify:

    • the diagram YoungDiagram.colLen μ j (Mathlib) — the length of column j of μ;
    • the list QOU.BraidKnot.IdentityI.colLen l j := (l.filter (j < ·)).length — used by the corpus prodHooks.

    This file proves they agree on l = μ.rowLens:

    IdentityI.colLen μ.rowLens j = μ.colLen j.

    This is the missing bridge for identifying the geometric cell-hook product ∏_{c∈μ} h(c) (QOU.Mathlib.HookLengthFormula.hookLengthProduct) with the corpus list product prodHooks μ.rowLens, and hence for discharging the geometric Frame–Robinson–Thrall HLF against the already-proved list-form HLF (QOU.Mathlib.SYTEnum.numSYTenum_mul_prodHooks).

    Proof: μ.rowLens = (range (colLen 0)).map μ.rowLen (Mathlib rowLens), so the filtered length counts {i < colLen 0 : j < rowLen i}; j < rowLen i ↔ (i,j) ∈ μ ↔ i < colLen j (Mathlib mem_iff_lt_rowLen / mem_iff_lt_colLen), and colLen j ≤ colLen 0 (colLen_anti) collapses the count to colLen j.

    Pure combinatorics on ℕ; nothing archimedean; no fit.
