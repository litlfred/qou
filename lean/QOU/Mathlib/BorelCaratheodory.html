    theorem QOU.Mathlib.BorelCaratheodory.norm_le_norm_two_mul_sub {M : ℝ} (hM : 0 < M) {w : ℂ} (hw : w.re ≤ M) :
    ‖w‖ ≤ ‖2 * ↑M - w‖

    If Re w ≤ M and 0 < M then ‖w‖ ≤ ‖2M - w‖.

    This is the engine: it converts a ONE-SIDED bound on the real part into a TWO-SIDED bound on the modulus of the Möbius transform. Geometrically, the half-plane Re w ≤ M is exactly the set of points at least as close to 0 as to 2M.

    theorem QOU.Mathlib.BorelCaratheodory.norm_le_of_re_le {R M r : ℝ} {f : ℂ → ℂ} (hR : 0 < R) (hM : 0 < M) (hrR : r < R) (hd : DifferentiableOn ℂ f (Metric.ball 0 R)) (h0 : f 0 = 0) (hre : ∀ w ∈ Metric.ball 0 R, (f w).re ≤ M) {z : ℂ} (hz : ‖z‖ ≤ r) :
    ‖f z‖ ≤ 2 * M * r / (R - r)

    Borel-Carathéodory inequality. A one-sided bound on the real part of a holomorphic f with f 0 = 0 yields a two-sided bound on its modulus strictly inside the disc.

    No 0 ≤ r hypothesis is needed: for r < 0 the hypothesis ‖z‖ ≤ r is unsatisfiable, and the proof never case-splits on the sign.
