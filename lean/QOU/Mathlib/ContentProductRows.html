    QOU.Mathlib.ContentProductRows — the content side of the level-r specialisation, by rows #

    HookProductMonoidBridge reindexes the hook product of a YoungDiagram by rows. This file does the same for the content product — the numerator of QBeta.WenzlWeight.schurPrincipal.
    rowLen_eq_zero_of_colLen_le rows past colLen 0 are empty
    prodContentF_rows ∏_{c ∈ μ} f(r − c₁ + c₂) = ∏_{i<r} ∏_{j<rowLen i} f(r − i + j)
    schurNumExponent on a cell of an ≤ r-row diagram, r + content c is the natural r − c₁ + c₂
    prodContentF_rows_one_sub_pow the q-instance, in schurPrincipal's own zpow form
    prodContentF_mul_descFactF the content side in descFactF form, division-free

    Row i's inner product is a contiguous block f(r−i), f(r−i+1), …, f(r−i+μ_i−1), so SYTBeta.prod_block_mul_descFactF turns it into descFactF f β_i / descFactF f (r−1−i) — the top index r − i + μ_i − 1 is β_i at r rows. That is the cancellation the hook side is waiting for.

    The outer range is r, not colLen 0: rows past the last nonzero one contribute an empty product, which is exactly the zero-padding convention SYTBetaZeroPadding fixes for the hook side.

    The content side in descFactF form #

    source
    theorem QOU.Mathlib.SYTBeta.prodContentF_mul_descFactF {M : Type u_1} [CommMonoid M] (f : ℕ → M) (r : ℕ) (μ : YoungDiagram) (hr : μ.colLen 0 ≤ r) :
    (∏ c ∈ μ.cells, f (r - c.1 + c.2)) * ∏ i ∈ Finset.range r, descFactF f (r - 1 - i) = ∏ i ∈ Finset.range r, descFactF f (r - i + μ.rowLen i - 1)

    The content side, division-free.

    ∏_{c ∈ μ} f(r − c₁ + c₂) · ∏_{i<r} descFactF f (r−1−i) = ∏_{i<r} descFactF f (r − i + μ_i − 1).

    The right-hand product is ∏_i descFactF f β_i at r rows — the same object the hook side produces (SYTBetaGapVandermonde.prodHooksF_mul_pair_prod). Dividing the two therefore cancels it, leaving the Vandermonde over a μ-independent constant: exactly the shape the branching ratio needs.

    The left-hand correction ∏_{i<r} descFactF f (r−1−i) is μ-independent, so it cancels too when the ratio of two diagrams is taken.
