    QOU.Mathlib.YoungDiagramCornerReindex — the corner/addable exchange as a sum reindexing #

    YoungDiagramAddCell builds the bijection

    cornerAddEquiv n : CornerPair n ≃ AddPair n,

    (λ, removable corner of λ) ↔ (λ ∖ c, that corner as an addable one), for |λ| = n + 1. An equivalence is not yet usable under a ∑: both sides must be Fintypes. This file supplies those instances and the resulting reindexing lemma.
    fintypeDiagramsOfCard diagrams of a fixed size are finite, transported from Nat.Partition
    fintypeCornerPair, fintypeAddPair the two pair types are finite
    sum_cornerPair_eq_sum_addPair ∑ over removable corners at n + 1 = ∑ over addable ones at n
    fintypeAddableCells a diagram has finitely many addable cells
    sum_cornerPair_flat, sum_addPair_flat each pair sum as a double sum
    sum_corner_eq_sum_addable the exchange as a double-sum reindexing — the usable form

    Why the imports differ from YoungDiagramAddCell #

    Finiteness is the one part of this story that is not pure ℕ × ℕ combinatorics: it comes from partitionShapeEquiv (a diagram of size n is a partition of n), which sits on the RSK/Schensted cone; the finiteness of a diagram's corner set comes from SYTBranchingRule. Keeping it in a separate file leaves YoungDiagramAddCell importable by anything that only wants addCell and the round-trips.

    AddPair's instance costs nothing extra: transporting along cornerAddEquiv avoids ever having to bound the addable cells of a diagram directly — the removable side already did that work.

    Nothing archimedean; no ring; no fit.

      The outer branching exchange as a sum reindexing. Summing a function of (diagram of size n, addable corner) over all such pairs is the same as summing it, pulled back along the exchange, over (diagram of size n + 1, removable corner).

        theorem QOU.Mathlib.sum_corner_eq_sum_addable {M : Type u_1} [AddCommMonoid M] (n : ℕ) (f : { ν : YoungDiagram // ν.cells.card = n } → ℕ × ℕ → M) :
        ∑ L : { ρ : YoungDiagram // ρ.cells.card = n + 1 }, ∑ c : { c : ℕ × ℕ // IsCornerCell (↑L) c }, f ⟨eraseCorner ↑L ↑c ⋯, ⋯⟩ ↑c = ∑ ν : { ν : YoungDiagram // ν.cells.card = n }, ∑ s : { s : ℕ × ℕ // IsAddableCell (↑ν) s }, f ν ↑s

        The exchange as a double-sum reindexing. Summing over (λ, removable corner) at size n + 1 — with the summand read on the erased diagram — is summing over (ν, addable corner) at size n.
