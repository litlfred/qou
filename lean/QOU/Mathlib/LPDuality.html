    LP Duality — finite-dimensional weak and strong duality #

    Weak and strong duality for finite-dimensional linear programs, stated over Fin k → ℝ without any Matrix dependency.

    source
    theorem QOU.Mathlib.LPDuality.weak_duality {n m : ℕ} (A : Fin m → Fin n → ℝ) (b : Fin m → ℝ) (c x : Fin n → ℝ) (y : Fin m → ℝ) (hx_pos : ∀ (j : Fin n), 0 ≤ x j) (hx_feas : ∀ (i : Fin m), b i ≤ ∑ j : Fin n, A i j * x j) (hy_pos : ∀ (i : Fin m), 0 ≤ y i) (hy_feas : ∀ (j : Fin n), ∑ i : Fin m, y i * A i j ≤ c j) :
    ∑ i : Fin m, b i * y i ≤ ∑ j : Fin n, c j * x j

    Weak LP duality. ∑ b_i y_i ≤ ∑ c_j x_j for primal-feasible x and dual-feasible y.

    source
    theorem QOU.Mathlib.LPDuality.strong_duality {n m : ℕ} (A : Fin m → Fin n → ℝ) (b : Fin m → ℝ) (c x : Fin n → ℝ) (y : Fin m → ℝ) (hx_slack : ∀ (j : Fin n), x j = 0 ∨ ∑ i : Fin m, y i * A i j = c j) (hy_slack : ∀ (i : Fin m), y i = 0 ∨ ∑ j : Fin n, A i j * x j = b i) :
    ∑ j : Fin n, c j * x j = ∑ i : Fin m, b i * y i

    Strong LP duality (certificate form). Given complementary slackness, ∑ c_j x_j = ∑ b_i y_i.

    theorem QOU.Mathlib.LPDuality.duality_gap_decomposition {n m : ℕ} (A : Fin m → Fin n → ℝ) (b : Fin m → ℝ) (c x : Fin n → ℝ) (y : Fin m → ℝ) :
    ∑ j : Fin n, c j * x j - ∑ i : Fin m, b i * y i = ∑ j : Fin n, (c j - ∑ i : Fin m, y i * A i j) * x j + ∑ i : Fin m, y i * (∑ j : Fin n, A i j * x j - b i)

    Duality-gap decomposition. An unconditional identity: the primal-dual gap is exactly the sum of the primal complementary-slackness residuals (c_j - (Aᵀy)_j) · x_j and the dual ones y_i · ((Ax)_i - b_i).

    No feasibility hypothesis is needed — this is algebra, and that is the point. A solver reports a duality_gap scalar; this identity lets a consumer recompute that gap from the emitted x, y, A, b, c alone, so the reported number becomes checkable rather than trusted. weak_duality above says the gap is non-negative under feasibility; this says where it lives.

    theorem QOU.Mathlib.LPDuality.duality_gap_le_of_residual_bounds {n m : ℕ} (A : Fin m → Fin n → ℝ) (b : Fin m → ℝ) (c x : Fin n → ℝ) (y : Fin m → ℝ) (ε : ℝ) (hp : ∀ (j : Fin n), (c j - ∑ i : Fin m, y i * A i j) * x j ≤ ε) (hd : ∀ (i : Fin m), y i * (∑ j : Fin n, A i j * x j - b i) ≤ ε) :
    ∑ j : Fin n, c j * x j - ∑ i : Fin m, b i * y i ≤ ↑n * ε + ↑m * ε

    Certified gap bound. If every primal slack residual and every dual slack residual is at most ε ≥ 0 in the (signed) sense below, the gap is at most (n + m) · ε.

    This is the form a numerical consumer can discharge: it bounds the true gap by quantities it computes itself from the emitted certificate, with no appeal to the solver's own duality_gap field.
