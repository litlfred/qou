    theorem MvPolynomial.abs_coeff_mul_le {σ : Type u_1} {f g : MvPolynomial σ ℤ} {Bf Bg : ℤ} (hf : ∀ (a : σ →₀ ℕ), |coeff a f| ≤ Bf) (hg : ∀ (b : σ →₀ ℕ), |coeff b g| ≤ Bg) (n : σ →₀ ℕ) :
    |coeff n (f * g)| ≤ ↑f.support.card * (Bf * Bg)

    H(f·g) ≤ #supp(f) · H(f) · H(g).

    In coeff n (f·g) = ∑ coeff a f · coeff b g over the antidiagonal of n, a summand survives only when a ∈ supp f, and b = n − a is then determined — so at most #supp f terms survive, each bounded by H(f)·H(g).

    ⚠ The easy direction. See the module header.

    theorem MvPolynomial.abs_coeff_multiset_prod_le {σ : Type u_1} {S B : ℤ} (hS1 : 1 ≤ S) (hB0 : 0 ≤ B) (t : Multiset (MvPolynomial σ ℤ)) (hS : ∀ f ∈ t, ↑f.support.card ≤ S) (hB : ∀ f ∈ t, ∀ (n : σ →₀ ℕ), |coeff n f| ≤ B) (n : σ →₀ ℕ) :
    |coeff n t.prod| ≤ (S * B) ^ t.card

    H(∏ t) ≤ (S·B)^{card t} for a multiset of factors, each of support size at most S and height at most B.

    1 ≤ S is what lets the bound be stated as a clean k-th power. The sharp form shaves one S — the recursion only ever applies abs_coeff_mul_le with an original factor in the first slot, never a partial product, so the last factor contributes no support cost — but carrying S^{k-1} through the induction costs more than it buys.

    |coeff n (∏ i ∈ s, F i)| ≤ (S * B) ^ s.card

    H(∏_{i ∈ s} Fᵢ) ≤ (S·B)^{#s} — the Finset form of the previous theorem.

    theorem MvPolynomial.abs_coeff_det_le {σ : Type u_1} {ι : Type u_2} [Fintype ι] [DecidableEq ι] {S B : ℤ} (hS1 : 1 ≤ S) (hB0 : 0 ≤ B) (M : Matrix ι ι (MvPolynomial σ ℤ)) (hS : ∀ (i j : ι), ↑(M i j).support.card ≤ S) (hB : ∀ (i j : ι) (n : σ →₀ ℕ), |coeff n (M i j)| ≤ B) (n : σ →₀ ℕ) :
    |coeff n M.det| ≤ ↑(Fintype.card ι).factorial * (S * B) ^ Fintype.card ι

    H(det M) ≤ m! · (S·B)^m for an m × m matrix of integer multivariate polynomials with entries of support size at most S and height at most B.

    Leibniz expands the determinant into m! signed products of m entries. The sign is a unit of ℤ, so it does not move the absolute value at all; each product is bounded by abs_coeff_prod_le; and the m! is just the number of permutations.

    This is what turns a height bound on an auxiliary polynomial into one on a generalized Wronskian. ⚠ It needs S — a support-size bound on the entries — not only a height bound; supplying that for iterated pderivs is card_support_pderiv_le in QOU/Mathlib/MvGenWronskian.lean.
