    QOU.Mathlib.SchenstedPartitionShape — partitions of n are the Young diagrams with n cells #

    Brick 41 of epic qou-nrex (RSK inverse).

    Brick 40 gives the correspondence as an Equiv onto {X : Σ μ, SYT μ × SYT μ // X.1.cells.card = n}. RSKBurnsideHolds n is indexed by Nat.Partition n, not by YoungDiagram, so the two do not meet until that index is identified:

    partitionShapeEquiv n : Nat.Partition n ≃ {μ : YoungDiagram // μ.cells.card = n}

    The cells.card side needs a lemma the corpus did not have and Mathlib does not either — a Young diagram has as many cells as its row lengths sum to. card_cells_ofRowLens proves it from the pieces SchenstedCellsBridge already built for the content bridge: the cells are the disjoint union of the rows (cells_biUnion, rows_pairwiseDisjoint) and a row is a product with a range (row_eq_prod). The content bridge itself is stated only for a tableauShape; these pieces are general, and this is the general consequence.

    The rest is the sorted-list round trip. A partition's shape remembers its parts because rowLens_ofRowLens_eq_self returns the sorted list, and sorting is injective on multisets; a diagram is a partition's shape because its own rowLens is already sorted, and sorting a sorted list returns it (sort_coe_of_sorted, via List.eq_of_perm_of_sorted).

    Scope #

    The index bridge. RSKBurnsideHolds for general n needs one more step past it — the Σ-card decomposition Nat.card {X // X.1.cells.card = n} = ∑ p, (dimSYT p)^2 — and is not proved here. It remains proved only for n ≤ 12, by rskBurnsideHolds_le12, a route with no RSK correspondence in it.

    Pure combinatorics on ℕ; nothing archimedean; no fit.

    Scope note superseded (2026-08-23). The scope paragraph above records the state of the arc when this brick landed. RSKBurnsideHolds is now proved for every n (QOU.Mathlib.rskBurnsideHolds, brick 42), and SnIsotypicSpechtSplit is inhabited, so any statement here that they "remain open" or hold "only for n ≤ 12" describes history rather than the corpus. The per-brick scope is otherwise unchanged and still accurate.
