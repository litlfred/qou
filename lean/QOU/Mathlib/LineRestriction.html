        theorem MvPolynomial.derivative_lineRestrict {σ : Type u_1} {K : Type u_2} [CommRing K] [Fintype σ] [DecidableEq σ] (a c : σ → K) (f : MvPolynomial σ K) :
        Polynomial.derivative ((lineRestrict a c) f) = (lineRestrict a c) (dirDeriv c f)

        Chain rule for restriction to a line: d/dt (f(a + tc)) = (Dᶜf)(a + tc).

        Mathlib has no chain rule for aeval, so this goes by induction on f; the multiplicative step is the only one with content.

        source
        theorem MvPolynomial.iterate_derivative_lineRestrict {σ : Type u_1} {K : Type u_2} [CommRing K] [Fintype σ] [DecidableEq σ] (a c : σ → K) (k : ℕ) (f : MvPolynomial σ K) :
        (⇑Polynomial.derivative)^[k] ((lineRestrict a c) f) = (lineRestrict a c) ((dirDeriv c)^[k] f)

        The iterated chain rule. dⁱ/dtⁱ on the restriction is (Dᶜ)ⁱ upstairs — and (Dᶜ)ⁱ has order exactly i, which is the order bound the univariate Wronskian needs.

        source
        theorem MvPolynomial.exists_lineRestrict_ne_zero {σ : Type u_1} {K : Type u_3} [Field K] [Infinite K] {P : MvPolynomial σ K} (hP : P ≠ 0) (c : σ → K) :
        ∃ (a : σ → K), (lineRestrict a c) P ≠ 0

        A non-zero polynomial survives restriction to some line, in every direction.

        Note the quantifiers: the direction c is arbitrary — only the base point has to be chosen. That is because the constant term of the restriction is P(a), so any a off the zero set of P already works, and MvPolynomial.funext supplies one over an infinite field.

        Next #

        With the bridge in place, qou-sq3h needs:

        1. Genericity — for a suitable (a, c) the restrictions t ↦ fⱼ(a + tc) of a K-independent family stay K-independent. MvPolynomial.funext (infinite integral domain) supplies the input; the work is applying it to the finitely many combinations that must survive.
        2. The pullback — lineRestrict is an AlgHom, so it commutes with det, giving genWronskian (lineRestrict ∘ f) = lineRestrict (det ((Dᶜ)ⁱ fⱼ)). With (1) and the univariate criterion, the right-hand side is non-zero.
        3. Multilinear expansion — (Dᶜ)ⁱ is a linear combination of monomial operators of order i; expanding det over those exhibits a non-zero bounded-order mvGenWronskian.

        Step 2 is the only one that needs both this file and QOU.Mathlib.GenWronskian, so it belongs in a file importing both rather than here.
