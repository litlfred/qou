      theorem QOU.Mathlib.SDPDuality.traceInner_nonneg_of_posSemidef {n : ℕ} (S X : Matrix (Fin n) (Fin n) ℝ) (hS : S.PosSemidef) (hX : X.PosSemidef) :
      0 ≤ traceInner S X

      tr(SX) ≥ 0 for PSD S and X. Proof: spectral decomposition S = U diag(λ) U* with λᵢ ≥ 0, trace cyclicity gives tr(SX) = tr(diag(λ) · U*XU), U*XU is PSD (by conjTranspose_mul_mul_same), then Σ λᵢ (U*XU)ᵢᵢ ≥ 0 since both factors are nonneg.
