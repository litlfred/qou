    QOU.Mathlib.RSKBurnsideTarget — Identity-I axiom (i) stated with the genuine #SYT count #

    This glue file connects the session's two merged infra pieces — the Nat.Partition/sorted-list bridge (PartitionListBridge) and the standard-tableau primitive (StandardYoungTableau, numStandardYoungTableaux) — into the precise statement of Identity-I axiom (i), the RSK / Burnside identity

    ∑_{p ⊢ n} dim(p)² = n!,   dim(p) := #SYT(shape p).

    Mathlib's abstract partition index Nat.Partition n maps to a YoungDiagram via YoungDiagram.ofRowLens applied to the parts sorted weakly-decreasing (the same sorted-list the PartitionListBridge builds), and numStandardYoungTableaux of that diagram is the genuine SYT count (a Finite-backed Nat.card). So RSKBurnsideHolds n is a faithful, fully-defined Prop. It is now a theorem for every n (QOU.Mathlib.rskBurnsideHolds, epic qou-nrex): its proof is exactly the RSK correspondence S_n ≃ Σ_λ SYT(λ)², which the pinned Mathlib lacks and which was built in-repo (SchenstedRSKEquiv.rskEquiv). This file supplies the concrete dimSYT for the abstract dim field of RSKBridge.RSKBijection.

    rskBurnside_imp_substrate makes the connection explicit: a proof of RSKBurnsideHolds n discharges RSKBridge.RSK_substrate_axiom n (instantiate its existential witness with dimSYT). Discharge paths (status):

    • dimSYT_eq_dimHLF — dimSYT p = dimHLF (toList p), the Frame–Robinson–Thrall hook-length formula (#SYT(λ) = n!/∏h_c). Now proved in IdentityIHLFBridge (counting bridge SYTEnum.dimSYT_eq_numSYTenum ∘ the GNW general HLF SYTEnum.numSYTenum_eq_dimHLF), making RSKBurnsideHolds n equivalent to a computable dimHLF sum (IdentityIHLFBridge.rskBurnsideHolds_iff_dimHLF).
    • a proof of RSKBurnsideHolds n: done for every n (QOU.Mathlib.rskBurnsideHolds, from the Robinson–Schensted correspondence). Previously this line read "done for n ≤ 12 … general n still awaits RSK", citing PartitionsOfBridge.rskBurnsideHolds_le12 — the decide-verified enumeration bridge, which remains valid and is still the cheapest route at small n, but is no longer the only one. Corrected 2026-08-23.

          theorem QOU.Mathlib.rskBurnside_imp_substrate {n : ℕ} (h : RSKBurnsideHolds n) :
          ∃ (dimFn : n.Partition → ℕ), ∑ p : n.Partition, dimFn p ^ 2 = n.factorial

          A proof of RSKBurnsideHolds n discharges the (deliberately weak) RSK_substrate_axiom. RSKBridge.RSK_substrate_axiom n only asserts the existence of some dimFn with ∑ dimFn² = n! (satisfiable trivially, hence not the real identity). This theorem exhibits the genuine witness: once RSKBurnsideHolds n is proved, dimSYT is exactly such a dimFn. So the concrete identity is at least as strong as the abstract existential — the honest direction of the bridge.
