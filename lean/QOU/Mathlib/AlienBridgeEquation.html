    structure QOU.Mathlib.AlienBridge.BridgeSystem (R : Type u_4) (A : Type u_5) (Ω : Type u_6) [CommSemiring R] [CommRing A] [Algebra R A] :
    Type (max (max u_4 u_5) u_6)

    An alien derivation system carrying Écalle's bridge equation: an ordinary derivation ∂, a family of alien derivations Δ_ω indexed by Ω, a weight ω ↦ weight ω ∈ R recording each singularity's location, and the relation

    ∂(Δ_ω f) − Δ_ω(∂ f) = weight ω • Δ_ω f.

    The relation is a field, i.e. a hypothesis on the system. It is not derived from the other data and is not claimed of any particular analytic construction.

    • ord : Derivation R A A

      The ordinary derivation ∂.

    • alien : Ω → Derivation R A A

      The alien derivation at the singularity ω.

    • weight : Ω → R

      The location of the singularity ω, as a scalar weight.

    • bridge (ω : Ω) (f : A) : self.ord ((self.alien ω) f) - (self.alien ω) (self.ord f) = self.weight ω • (self.alien ω) f

      Écalle's bridge equation. ⁅∂, Δ_ω⁆ = ω · Δ_ω.

      The hypothesis has teeth. If ∂ commutes with Δ_ω and the weight acts injectively (in particular, if weight ω is a non-zero-divisor and nonzero), then Δ_ω = 0.

      So the bridge equation is a genuine constraint, not bookkeeping: a system can satisfy it with Δ_ω ≠ 0 only by failing to commute, and by exactly the amount ω. Recorded because a structure field that any system satisfies would make the theorems below vacuous.

      theorem QOU.Mathlib.AlienBridge.BridgeSystem.ord_dotted_comm {R : Type u_1} {A : Type u_2} {Ω : Type u_3} [CommSemiring R] [CommRing A] [Algebra R A] (S : BridgeSystem R A Ω) (ω : Ω) {e : A} (he : S.ord e = -(S.weight ω • e)) (f : A) :
      S.ord (e * (S.alien ω) f) = e * (S.alien ω) (S.ord f)

      The bridge proper: the dotted alien derivative commutes with ∂.

      Let e_ω be a formal exponential of weight −ω, i.e. ∂ e_ω = −ω · e_ω (think e^{−ωz}), and set Δ̇_ω f := e_ω · Δ_ω f. Then

      ∂ ∘ Δ̇_ω = Δ̇_ω ∘ ∂.

      The ω produced by the bridge equation is cancelled exactly by the −ω from differentiating e_ω — which is what the relation is for. This is the step that lets the Δ_ω be transported to the analytic side as ordinary commuting operators.

      Scope note. Unlike the other results here, this hypothesis is not witnessed by polyEulerSystem below: R[X] has no element of ∂-eigenvalue −n, since the Euler operator's eigenvalues on R[X] are the degrees ≥ 0. A witness needs negative weights, i.e. Laurent polynomials R[t, t⁻¹] with e = t^{−n}. That model is not built here, so the theorem is proved but its hypothesis is so far only exhibited abstractly.

      theorem QOU.Mathlib.AlienBridge.BridgeSystem.ord_comm_of_weight_zero {R : Type u_1} {A : Type u_2} {Ω : Type u_3} [CommSemiring R] [CommRing A] [Algebra R A] (S : BridgeSystem R A Ω) (ω : Ω) (hw : S.weight ω = 0) (f : A) :

      Weight zero is the degenerate case. At weight ω = 0 the bridge equation says precisely that Δ_ω commutes with ∂ — the converse direction of alien_eq_zero_of_ord_comm, and a check that the sign and placement of the weight in the field are right.

      A concrete non-trivial model — the Euler system #

      Everything above is conditional on `BridgeSystem` being inhabited by
something other than the zero family: a structure whose only model has
`Δ_ω = 0` would make `weight_shift`, `weight_add_of_comp` and
`ord_dotted_comm` true but empty.

This section removes that doubt.  Any `(A, D, t)` with `D t = t` — an
"Euler coordinate" — carries a bridge system on `Ω = ℕ` with `Δ_n := tⁿ · D`
and weight `n`, and `Δ₁ t = t²` is nonzero whenever `t² ≠ 0`.  A concrete
witness is `R[X]` with the Euler operator `X·d/dX` and `t = X`, where
`t² = X² ≠ 0` for any nontrivial `R`.

So the structure is inhabited at **nonzero** weight by a **nonzero** alien
family — exactly the regime `alien_eq_zero_of_ord_comm` says commutation
forbids.
