      Is hbound circular? No — and this is the lemma that says why #

      Γ_m's last clause is b ^ (m q) ≤ H₀ ^ (r₀ p) where b is the auxiliary polynomial's height bound, ⌈siegelHeight r α μ⌉. It reads as circular: b depends on r, r = rothDegrees H N depends on H₀, and H₀ is what the clause constrains.

      It is not, and the reason is a cancellation. Note first, from the types, that siegelHeight r α μ depends on H only through r — so raising H₀ while holding r fixed leaves b alone and raises the right-hand side, which is hbound_mono below. That is the move the informal proof makes when it says "choose q₁ large".

      Holding r fixed while raising H₀ means raising N too, and the asymptotics are what make it work. Writing log for real logarithms: r₀·log H₀ ≈ log N, so the right side is ≈ p·log N. On the left, log b ≈ ρ·log(#box · ‖A‖) with ρ = #E/(#box − #E), and both #box and ‖A‖ grow like exp(c·∑_h r_h) while ∑_h r_h ≈ log N · ∑_h 1/log H_h. So the left side is ≈ m q ρ c · log N · ∑_h 1/log H_h, log N cancels, and since the growth clause makes H₀ the smallest height, ∑_h 1/log H_h ≤ m/log H₀. The clause reduces to a condition on H₀ alone: log H₀ ≳ m² q ρ c / p.

      ⚠ That cancellation is an asymptotic argument, not yet formalised. hbound_mono is the part that is, and it is the part the non-circularity actually rests on; the rest is an estimate on #box and ‖A‖ that this arc has not written down. Recorded so the gap is visible rather than implied by the surrounding lemmas being proved.

      Γ_m from the supply, modulo the height clause. There are heights in the supply and a threshold N such that if the auxiliary polynomial's height bound b satisfies Γ_m's last clause for them, then all seven clauses hold.

      The implication is the honest shape. hbound is a statement about the produced data, so it cannot be a hypothesis of the existential — and quantifying it over all possible H, N would demand far more than the argument needs. hbound_mono is what makes the implication dischargeable: the clause improves as H₀ grows, and the supply is unbounded.

      ⚠ b is a function of the produced data, not a constant. It was a constant in the first draft, and that version cannot be used: the b this is actually applied at is ⌈siegelHeight (rothDegrees H N) α μ⌉, which depends on the H and N the theorem itself produces. A constant b cannot be instantiated with it, so the "honest shape" was still the wrong one — honest about hbound and wrong about b.

      theorem MvPolynomial.sum_rothDegrees_le {m : ℕ} (H : Fin m → ℕ) (N b : ℕ) (hb : 1 < b) (hle : ∀ (h : Fin m), b ≤ H h) :
      ∑ h : Fin m, rothDegrees H N h ≤ m * (Nat.log b N + 1)

      Σ r_h in terms of the smallest height. Σ_h rothDegrees H N h ≤ m·(log_b N + 1) for any b below every height — because Nat.log is antitone in its base, so the smallest height gives the largest degree.

      This is the concrete form of the asymptotic Σ r_h ≈ log N · Σ_h 1/log H_h ≤ m·log N/log H₀ that hbound's cancellation runs on: it puts Σ r_h under m·log_{H₀} N, so the left side of the height clause grows like N^{c·m/log H₀} against a right side of N^p.
