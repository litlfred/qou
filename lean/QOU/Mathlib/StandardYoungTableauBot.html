    #SYT(⊥) = 1 — the empty-diagram standard-tableau count #

    A single small, sorry-free lemma: the empty Young diagram ⊥ has exactly one standard Young tableau, numStandardYoungTableaux ⊥ = 1.

    It is proved directly, via Subsingleton + Nonempty on QOU.Mathlib.StandardYoungTableau ⊥ — it does not route through the Frame–Robinson–Thrall hook-length bridge (IdentityIHLFBridge.dimSYT_eq_dimHLF) or the n ≤ 12 decide certificate (PartitionsOfBridge.rskBurnsideHolds_le12) that the sibling RSK build uses. So it is an independent, elementary computation of a numStandardYoungTableaux (a noncomputable Nat.card, so decide is impossible on it) of a concrete shape. The technique — Nat.card_eq_one_iff_unique with the Set.BijOn onto Set.Icc 1 0 = ∅ discharged by Set.bijOn_empty — is the reusable pattern for any single-cell / small concrete shape.

    Scope: pure combinatorics on ℕ; §7c-clean; no fit. The general RSK / Burnside identity is developed elsewhere (QOU.Mathlib.RSKBurnsideTarget, PartitionsOfBridge, the P1–P5 program).
