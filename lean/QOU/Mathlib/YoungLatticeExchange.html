    QOU.Mathlib.YoungLatticeExchange — the corner/addable exchange, on the YoungDiagramAddable API #

    The (λ, removable corner) ≃ (λ ∖ c, that corner, now addable) exchange, built on QOU.Mathlib.YoungDiagramAddable so that it can sit in QOU.lean's import cone.

    Why this file exists rather than reusing YoungDiagramAddCell #

    QOU.Mathlib.YoungDiagramAddCell already has this exchange (cornerAddEquiv). It cannot be used here: YoungDiagramAddCell and YoungDiagramAddable both declare QOU.Mathlib.IsAddableCell and QOU.Mathlib.addCell, so no module can import both —

    error: import QOU.Mathlib.YoungDiagramAddable failed, environment already contains
       'QOU.Mathlib.mem_addCell._simp_1' from QOU.Mathlib.YoungDiagramAddCell

    and QOU.lean imports YoungDiagramAddable. Since the two addCell definitions are character-identical (insert c μ.cells, same IsAddableCell hypothesis), the four round-trip lemmas port verbatim; they are re-proved here against YoungDiagramAddable's copy. The duplication is main's (bean qou-dup1), not introduced here — this file simply picks the side QOU.lean already uses.

    Names are deliberately distinct from YoungDiagramAddCell's (SizedCornerPair vs CornerPair, etc.) so that this module does not re-create the very collision it works around.

    Pure combinatorics; nothing archimedean (§7c).
