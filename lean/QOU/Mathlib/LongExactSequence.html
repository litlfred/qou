    QOU.Mathlib.LongExactSequence — the LES, and the three things it is used for #

    Bean qou-fngs. Until now the corpus had no long exact sequence: an audit on 2026-08-24 found the phrase in exactly two prose lines and zero declarations, while rem:self-dual-ses states a short exact sequence in Markdown with nothing formal behind it.

    That was not for want of Mathlib. Function.Exact and LinearMap.exact_iff are there, and this file does not re-derive them. What is missing upstream is the packaged ℤ-indexed sequence and, more to the point, the three consequences an obstruction argument actually reaches for. Those are the content here.

    Exactness is a computation rule, not a decoration #

    An LES is worth having because it converts vanishing into isomorphism. Each theorem below is one direction of that trade:

    • surjective_iff_next_eq_zero — f_n is onto exactly when f_{n+1} = 0. Surjectivity is not evidence about f_n; it is evidence about its successor.
    • injective_iff_prev_eq_zero — dually, injectivity of f_{n+1} is a fact about f_n.
    • equivOfNeighboursZero — both neighbours vanish ⟹ the middle map is an isomorphism. This is the one that closes a computation: an unknown module is pinned to a known one by two vanishing statements, neither of which mentions it.

    map_eq_zero_of_subsingleton then feeds the machine: a term that is zero makes both maps touching it zero, so a single vanishing group propagates outward as injectivity and surjectivity of its neighbours. That is how a long exact sequence is used to compute, and it is why the vanishing results this corpus keeps assuming are worth proving rather than positing.

    Relation to the spectral-sequence files #

    PagedSpectralSequence.turn is E_{r+1} ≅ ker d ⧸ im d — a subquotient. An LES is the degenerate case where the subquotient vanishes, so exactness holds on the nose. The two are the same bookkeeping at different resolution, and Collapses is what makes a spectral sequence behave like this file.

    Base ring #

    Ring R, generic. Nothing here is archimedean and nothing needs a field: the statements are about kernels and ranges, which exist over any ring — including R_q = ℤ[q, q⁻¹], where the corpus actually works.

    structure QOU.Mathlib.LongExactSequence.LES (R : Type u) [Ring R] (M : ℤ → Type v) [(n : ℤ) → AddCommGroup (M n)] [(n : ℤ) → Module R (M n)] :
    Type v

    A long exact sequence: a ℤ-indexed family of modules with maps f_n : M n → M (n+1), exact at every spot.

    Indexed by ℤ rather than ℕ because the sequences this corpus produces are two-sided — a connecting map runs down in degree — and truncating at zero would put a spurious boundary where the mathematics has none. A bounded sequence is expressed by making the outlying terms subsingletons, which map_eq_zero_of_subsingleton turns into exactly the vanishing hypotheses the theorems below want.

    • map (n : ℤ) : M n →ₗ[R] M (n + 1)

      The map out of degree n.

    • exact (n : ℤ) : Function.Exact ⇑(self.map n) ⇑(self.map (n + 1))

      Exact at every degree: ker f_{n+1} = range f_n.

      theorem QOU.Mathlib.LongExactSequence.surjective_of_subsingleton_target {R : Type u} [Ring R] {M : ℤ → Type v} [(n : ℤ) → AddCommGroup (M n)] [(n : ℤ) → Module R (M n)] (L : LES R M) {n p : ℤ} (hp : n + 1 + 1 = p) [Subsingleton (M p)] :
      Function.Surjective ⇑(L.map n)

      A vanishing term two steps along makes f_n surjective.

      The target, not the source: f_n is onto when f_{n+1} is zero (surjective_iff_next_eq_zero), and what makes f_{n+1} zero without also collapsing f_n's own target is M_{n+2} vanishing. Deriving it from Subsingleton (M (n+1)) instead would be true and useless — that hypothesis makes f_n's codomain trivial, so surjectivity says nothing.

      The theorem that closes a computation.

      If the maps on both sides vanish, f_n is an isomorphism — so an unknown module is pinned to a known one by two vanishing statements, neither of which mentions it. This is what an LES is for, and it is the shape every "the obstruction vanishes, therefore the two agree" argument in the corpus wants underneath it.

      The predecessor index is carried as an equation rather than written n-1, because n - 1 + 1 is only propositionally n in ℤ and the difference is a type mismatch on M. subst then discharges the transport.
