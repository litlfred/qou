    QOU.Mathlib.SpectralCollapseCriteria — collapse you can check, and a legacy bridge #

    Bean qou-fngs. The spectral-sequence arc had reached an honest impasse worth naming: the machinery is proved and nothing instantiates it. An audit on 2026-08-24 found fifteen classes across the corpus asserting a spectral or collapse property with zero instances between them, and PagedSS itself deliberately shipped without a witness.

    Zero instances is better than a trivial one — nothing false is proved — but it also means nothing is proved. Two things are missing, and this file supplies both.

    1. Parity checked on one side instead of two #

    BarGradedCollapse.collapses_of_parity_mismatch proves collapse from a grading, but demands the source be purely even and the target purely odd — two independent claims about every element of every page.

    The content here is isAntiSelfDual_image_of_selfDual: if the differential anticommutes with an involution, ⋆ ∘ d = − d ∘ ⋆, then evenness of the source implies oddness of the image. Anticommutation is a property of a map, testable on generators; so the parity obligation drops from two sides to one side plus a map identity.

    Be clear about what that is and is not. It is bookkeeping, not a weakening of the mathematics: collapses_of_anticommuting_involution still needs a parity hypothesis on the target, and with both sides even the statement reduces to d = −d, which is 2-torsion-freeness doing the work. The gain is that one of the two page-wide hypotheses is replaced by a check on d.

    The involution the corpus already has is the bar involution q ↦ q⁻¹, and SelfDualSES records that its even/odd parts are the ±1 eigenspaces of an involution — the same structure as ⋆_q. So this is applicable, in principle, to the object the substrate axiom is about.

    2. A bridge, so the legacy hypothesis can be discharged honestly #

    SpectralSequence.GBFiltrationCollapsesAtE2 was an instance until it was demoted (collapse_is_definitional), because a PUnit model satisfied it and made every downstream theorem unconditional. Demoting it stopped the laundering but left canonicalTrivial as the only way to supply it — so a real filtration had no route in.

    legacyOfPaged is that route: a PagedSS with Collapses yields the legacy class. Downstream consumers of [GBFiltrationCollapsesAtE2 R] are unchanged, and a reader can now tell a genuine discharge from a decorative one by which constructor was used.

    What this still does not do #

    It does not construct the Gröbner-filtration spectral sequence, and it does not verify the anticommutation hypothesis for it. It converts "assume it collapses" into "exhibit an anticommuting involution", which is a smaller and checkable obligation — not a discharged one. Saying otherwise would repeat the defect this file exists downstream of.

    d = 0

    The vanishing criterion.

    A differential that anticommutes with an involution, from a purely self-dual page to a purely self-dual page, is zero.

    No sleight of hand: with both sides fixed the two facts are d x = ⋆(d x) and ⋆(d x) = −d x, so d x = −d x and 2-torsion-freeness finishes. The honest description is that anticommutation supplies the second of the two parity facts BarGradedCollapse.map_eq_zero_of_parity_mismatch demands as a hypothesis.

    A PagedSS whose pages carry involutions, whose differentials anticommute with them, and whose pages from r₀ on are pointwise fixed, collapses at r₀.

    The "pointwise fixed" hypothesis is what remains to be verified for the Gröbner filtration; it is stated as a hypothesis rather than assumed, which is the whole difference between this and GBFiltrationCollapsesAtE2.

    Collapse from bounded support — no Gröbner input required #

    theorem QOU.Mathlib.SpectralCollapseCriteria.collapses_of_bounded_support {R : Type u} [CommRing R] {page : SpectralSequence.CellIndex → Type v} [(c : SpectralSequence.CellIndex) → AddCommGroup (page c)] [(c : SpectralSequence.CellIndex) → Module R (page c)] (S : PagedSpectralSequence.PagedSS R page) (N : ℕ) (hzero : ∀ (c : SpectralSequence.CellIndex), c.p < 0 ∨ ↑N < c.p → Subsingleton (page c)) :
    PagedSpectralSequence.Collapses S (N + 1)

    Bounded support forces collapse.

    If every page vanishes outside the filtration window 0 ≤ p ≤ N, the spectral sequence collapses at N + 1.

    The argument is the standard one and it uses no property of the filtration beyond its width. d_r shifts p by r, so once r > N the differential out of any surviving cell lands at p + r > N, outside the window, where the target is zero. Cells already outside the window have zero source. Either way the map is zero.

    This is the theorem the corpus's mass formula actually needs. prop:phi-q-categorical-truncation states that the brane-tower sum truncates at k⋆, the maximum GB-depth among the support partitions, and that "truncation at any deeper level yields the identical categorical value" — a boundedness claim. Boundedness is weaker than S-GB-spectral-collapse and, as this shows, it is provable rather than assumed.

    What it does not give is collapse at E_2 specifically: it yields collapse at N + 1, where N is the window width. The mass formula needs k⋆ to be the max GB-depth rather than something larger, so the strong form is still an assertion. Do not read this as discharging it.

    The legacy bridge #

    Restricted to `page : CellIndex → Type u`: the old `SpectralSequence R`
declares `cell : CellIndex → Type u` in `R`'s own universe, so a page
family at an independent level `v` cannot be presented in it at all.
