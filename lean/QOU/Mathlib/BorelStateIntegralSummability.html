    class QOU.Mathlib.BorelStateIntegral.BorelSummableToStateIntegral (R : Type u_1) [CommRing R] (M : Type u_2) [AddCommGroup M] [Module R M] (D : Type u_3) :
    Type (max (max u_1 u_2) u_3)

    Hypotheses / inputs of Fantini–Wheeler Theorem 1.4 ([fantini-wheeler2024], arXiv:2410.20973), axiomatized as a Lean class over a generic base ring R (standing for ℤ[q^±]).

    Type parameters:

    • R — the base ring (ℤ[q^±]).
    • M — the R-module spanned by the state integrals I_{m,ℓ}.
    • D — the admissible resummation directions ϑ (args avoiding Stokes rays); left abstract.

    The rank r = max{A,B} is the number of critical points (FW: "there are max{A,B} critical points"). The fields carry the inputs FW proves exist; the downstream theorems derive consequences.

    The cocycle field is stated in groupoid-completed form (all triples), the standard resurgent-structure encoding of FW eq. (27), which holds for ordered ϑ₁ < ϑ₂ < ϑ₃ and extends by S_{ϑ,ϑ} := 1, S_{ϑ',ϑ} := S_{ϑ,ϑ'}⁻¹.

    §3b-cond non-degeneracy: no field carries a downstream theorem's own conclusion. stokes_refl / stokes_inv are derived from stokes_cocycle via the group structure of GL (Fin rank) R; frame_transport_trans is derived from frame_transport + the cocycle.

    • rank : ℕ

      The rank r = max{A,B} — the number of critical points / the size of the Stokes matrices.

    • stateIntegral : ℤ × ℤ → M

      The Andersen–Kashaev state integrals I_{m,ℓ} ∈ M, indexed by (m, ℓ) ∈ ℤ × ℤ. The (0,0) member is the AK integral.

    • resummation : D → M

      The Borel–Laplace resummation of Φ_Ξ in admissible direction ϑ; a single distinguished element of the state-integral module.

    • resummation_mem_span (d : D) : resummation R d ∈ Submodule.span R (Set.range (stateIntegral R D))

      FW combination relation. Away from Stokes rays the resummation is a ℤ[q^±]-linear combination of state integrals: it lies in the R-span of the I_{m,ℓ}.

    • frame : D → Fin (rank R M D) → M

      The frame Î_{j,ϑ}: the r-tuple of independent resummed series collected in FW eq. (25), as a map D → (Fin rank → M).

    • stokes : D → D → GL (Fin (rank R M D)) R

      The Stokes matrices S_{ϑ₁,ϑ₂}(q) ∈ GL_{max{A,B}}(ℤ[q^±]) (FW eq. 26). Valued in the general linear group over R.

    • frame_transport (a b : D) (i : Fin (rank R M D)) : frame b i = ∑ j : Fin (rank R M D), ↑(stokes a b) j i • frame a j

      FW transport (eq. 26). Changing the resummation direction acts on the frame by right-multiplication by the Stokes matrix: Î_{j,ϑ₂} = Î_{j,ϑ₁} · S_{ϑ₁,ϑ₂}, i.e. componentwise frame b i = ∑ⱼ (S_{a,b})ⱼᵢ • frame a j.

    • stokes_cocycle (a b c : D) : stokes a b * stokes b c = stokes a c

      FW Stokes cocycle (eq. 27, groupoid form). S_{ϑ₁,ϑ₂} · S_{ϑ₂,ϑ₃} = S_{ϑ₁,ϑ₃}.
