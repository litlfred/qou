    QOU.Mathlib.RSKSubstrateInstances — the RSK substrate, proved (not assumed) for n ≤ 12 #

    RSKBridge carries the substrate assumption as a Lean axiom: RSK_substrate_axiom (n : ℕ) : RSKBurnsideHolds n — the RSK/Burnside identity Σ_{p ⊢ n} dimSYT(p)² = n! on the genuine #SYT count, for every n, pending Mathlib's RSK cardinality theorem. With the hook-length bridge (IdentityIHLFBridge.dimSYT_eq_dimHLF) and the enumeration bridge (PartitionsOfBridge.rskBurnsideHolds_le12) both proved, the identity is now a theorem for every n ≤ 12. This file wires that in:

    • RSK_substrate_proved_le12 — the n ≤ 12 route, via the enumeration bridge. Corrected 2026-08-23: this bullet used to call it "the axiom-free counterpart of RSK_substrate_axiom" and say "the axiom's live range is now n ≥ 13 only". There is no live range, because there is no axiom: RSKBridge.RSK_substrate_proved proves the identity for every n from the Robinson–Schensted correspondence. This bullet's route is retained as the cheaper one at small n, not as the only one.
    • rskBijection_of_lt13 — the first genuine RSKBijection n construction (the class had no non-vacuous instance): dim := dimSYT with the proved Burnside field, at n ≤ 12.
    • instRSKBijection — and now at every n (2026-08-23), from QOU.Mathlib.rskBurnsideHolds. This replaced the four hand-registered instances at the physically-used n = 3, 5, 7, 12; see its docstring for why they are removed rather than kept alongside.
    • cohortWitness_of_lt13 — a concrete CohortRSKWitness n from the partitionsOf enumerator and dim_validated_le12.

    Pure combinatorics on ℕ; nothing archimedean; no fit; no new axioms (and no use of RSK_substrate_axiom anywhere in this file).

      RSKBijection n for every n — dim := dimSYT with the Burnside field supplied by QOU.Mathlib.rskBurnsideHolds, the Robinson–Schensted proof.

      This supersedes the four hand-registered instances that stood here (n = 3 the deuteron pn channel, n = 5 the s5-so3 keystone, n = 7 the defect-cubic sign flip, n = 12 the top of the decide-verified coverage), each built from rskBijection_of_lt13. They are removed rather than kept alongside this one: the class carries data (dim), so two instances at the same n would be an ambiguity even though both supply dimSYT.

      rskBijection_of_lt13 itself is retained — at small n the enumeration route is cheaper and needs no RSK.
