    theorem MvPolynomial.exists_bounded_order_mvGenWronskian_two {σ : Type u_1} {K : Type u_3} [Field K] [CharZero K] [DecidableEq σ] {f g : MvPolynomial σ K} (h : LinearIndependent K ![f, g]) :
    ∃ (k : σ), mvGenWronskian ![[], [k]] ![f, g] ≠ 0

    The m = 2 bounded-order criterion, in the committed shape.

    The family (id, ∂ₖ) has orders 0 and 1, which is exactly ord (Δᵢ) ≤ i. So for two polynomials the bounded-order generalized Wronskian criterion holds outright.

    General m: the criterion Roth's lemma consumes #

    The m = 2 case above is exactly the base case that the univariate general-m converse in QOU.Mathlib.GenWronskian is built on, and the rest of that proof transposes: kernel vector, derivative descent, Wronskian combination, the m = 2 case, substitution.

    ⚠ The earlier note here recorded this as a plan and warned the analogy might fail where the univariate proof uses the canonical operator dⁱ/dxⁱ while the multivariate family is chosen. It does not fail, and the reason is worth stating: the hypothesis is that every bounded-order Wronskian vanishes, so the cofactor expansion is available for an arbitrary last operator Δ with ord Δ ≤ m−1. Being able to vary that operator freely is exactly what replaces canonicity. Descent then goes through because ord (∂ₖ ∘ Δ_l) = |l| + 1 ≤ m−1 whenever |l| ≤ m−2.

    No genericity is used anywhere — no generic direction, no generic point, no infinite-field argument. The generic-direction machinery in QOU.Mathlib.DirectionalWronskian is therefore not needed for this result; it remains as an independently meaningful reduction.

    l.length < n → ∑ j : Fin m, (pderiv k) (c j) * (pderivList l) (f j) = 0

    Derivative descent for bounded-order operators.

    If c annihilates every operator of order ≤ n, then ∂ₖc annihilates every operator of order < n. Mirrors Polynomial.sum_derivative_of_forall_sum_eq_zero; the reason it works is that ∂ₖ ∘ Δ_l = Δ_{k::l} has order |l| + 1 ≤ n, so the cross term is already zero.
