    QOU.Mathlib.BarGradedCollapse — collapse proved from a parity grading #

    Bean qou-fngs, continuing the arc. PagedSpectralSequence.lean made Collapses mean something; this file gives the first way to prove it instead of assuming it.

    The argument the corpus already has, one level up #

    QOU/QBeta/ZBarParity.lean works at the scalar level. Under the fibre bar involution q ↦ q⁻¹ it proves z is exactly bar-even, κ_{(2,1)} exactly bar-odd, and — the load-bearing step — bar_even_ne_bar_odd_of_ne_zero: an even scalar cannot equal a nonzero odd one, in characteristic ≠ 2. That is the c₃-odd exclusion (ck_a1_bar_odd_of_c3_odd).

    Read structurally, that is a ℤ/2 grading, and the exclusion is the most classical reason a spectral sequence degenerates: a differential that must shift parity, landing where the parity is wrong, is zero because of the grading — no computation, no filtration analysis.

    What was missing is the lift from scalars to maps between modules. That is this file:

    • eq_zero_of_even_and_odd — an element both even and odd is zero, given 2-torsion-freeness (the module form of bar_even_and_odd_two_mul_eq_zero);
    • map_eq_zero_of_parity_mismatch — a bar-equivariant map from a purely even module to a purely odd one is the zero map;
    • collapses_of_parity_mismatch — hence a PagedSS whose differentials run even → odd from page r₀ on collapses at r₀.

    The third is a collapse theorem with a proof. GBFiltrationCollapsesAtE2 asserted the same shape and was discharged by PUnit.

    What is assumed, and it is not hidden #

    The parity data is a hypothesis: someone must exhibit the involution and show the pages are purely even / purely odd. That is real mathematical work and this file does not do it for the Gröbner filtration. What it removes is the step where collapse itself was assumed — given the grading, collapse now follows.

    2-torsion-freeness is carried explicitly rather than assumed via a field, so the result is available over R_q = ℤ[q, q⁻¹], where the corpus actually works, and not only after specialising to ℝ.

          theorem QOU.Mathlib.BarGradedCollapse.map_eq_zero_of_parity_mismatch {R : Type u} [CommRing R] {M N : Type v} [AddCommGroup M] [Module R M] [AddCommGroup N] [Module R N] (bM : BarInvolution M) (bN : BarInvolution N) (f : M →ₗ[R] N) (hequiv : ∀ (x : M), bN.bar (f x) = f (bM.bar x)) (heven : ∀ (x : M), IsEven bM x) (hodd : ∀ (y : N), IsOdd bN y) (htors : ∀ (y : N), y + y = 0 → y = 0) :
          f = 0

          A parity-mismatched equivariant map is zero.

          If f intertwines the two involutions, the source is purely even and the target purely odd, then every f x is both even (transported from the source) and odd (by the target's grading) — hence zero.

          This is ZBarParity's exclusion applied to a map rather than a scalar, and it is what makes a grading force a differential to vanish.
