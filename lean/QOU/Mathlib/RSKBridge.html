    QOU.Mathlib.RSKBridge — Robinson–Schensted–Knuth bridge to Burnside #

    The classical Robinson–Schensted–Knuth correspondence gives a bijection RSK : S_n ≃ Σ_{λ ⊢ n} (SYT(λ) × SYT(λ)) which by counting yields the Burnside / RSK identity n! = Σ_{λ ⊢ n} (#SYT(λ))².

    Mathlib's Mathlib.Combinatorics.RSK is partial — the bijection is formalised in part but the cardinality consequence above has not yet landed. This file:

    1. States RSKBijection (n : ℕ) as a class wrapping the bijection's existence with the cardinality identity as a field.

    2. Provides a BurnsideFromRSK derivation: [RSKBijection n] → BurnsideIdentity n numStandardYoungTableaux.

    3. Documents the upstream Mathlib path:

      • Mathlib.Combinatorics.Young.SYT supplies SYT(λ) (the finite type of standard Young tableaux of shape λ).
      • Mathlib.Combinatorics.RSK.bijection (when complete) supplies the equiv S_n ≃ Σ_λ SYT(λ) × SYT(λ).
      • Burnside follows from Fintype.card_congr RSK.bijection, Fintype.card_sigma, and Fintype.card_prod.

    The class shape is the §3b-cond pattern from AGENTS.md: the upstream Mathlib theorem is the only sorry/instance the downstream chain depends on; once it lands, the whole chain becomes fully verified.

    File status: upstreamable scaffolding. The class fields are concrete (not Prop := True), so the audit-level §3b-cond hypothesis is content-bearing.

    References:

    • Robinson (1938), Schensted (1961), Knuth (1970) — original RSK papers.
    • Stanley, Enumerative Combinatorics Vol 2, Ch. 7.
    • Mathlib partial: Mathlib.Combinatorics.RSK.

    class QOU.Mathlib.RSKBridge.RSKBijection (n : ℕ) :
    Type

    RSKBijection class — the conjectural Mathlib upstream: the cardinality consequence of the RSK correspondence.

    Field n_factorial_eq_sum_squares asserts the Burnside identity directly; field dim is the supplied SYT-count function. The class instance acts as the §3b-cond hook for discharging downstream BurnsideIdentity claims.

    • dim : n.Partition → ℕ

      The supplied SYT-count function (concrete instances use Mathlib.Combinatorics.Young.SYT.card).

    • n_factorial_eq_sum_squares : ∑ Λ : n.Partition, dim Λ ^ 2 = n.factorial

      The Burnside identity: n! = Σ_λ (dim λ)².

      Cohort-based RSKBijection (concrete via explicit cohort lists) #

      Bypass `Nat.Partition n` (whose `Fintype.card` API is
upstream-dependent) by working over a `List`-based cohort.
The classical Burnside identity `Σ d_λ² = n!` is then
discharged directly from the cohort's `n*_squares_sum_eq`
theorem — no upstream Mathlib gap.
