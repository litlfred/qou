    QOU.Mathlib.SYTListCorner — list-level corner-removal infrastructure for the GNW route #

    The low-level combinatorics of removable corners of a weakly-decreasing shape l : List ℕ and the corner-deletion operation removeCorner l i, shared by the GNW reduction (SYTHookGNW) and the structural-branching connection (SYTCornerListConnection). Splitting it into its own file lets both consumers import it without an import cycle.

    removeCorner preserves weak decrease and positivity and drops the size by one; the hook product is positive on a positive shape. Pure combinatorics on ℕ/ℚ; nothing archimedean; no fit.

    Corner-removal infrastructure #

    source
    def QOU.Mathlib.SYTEnum.IsCorner (l : List ℕ) (i : ℕ) :
    Prop

    Row index i is a removable corner of shape l: a genuine row whose last cell is an outer corner, i.e. the next row is strictly shorter (treating "beyond the last row" as length 0). For a weakly-decreasing positive shape this is exactly the set of cells whose deletion leaves a shape.

      def QOU.Mathlib.SYTEnum.removeCorner (l : List ℕ) (i : ℕ) :
      List ℕ

      Remove one cell from the end of row i: decrement that row's length, then drop the row entirely if it has shrunk to 0 (which, for a removable corner of a weakly-decreasing positive shape, happens only when i is the final length-1 row).
