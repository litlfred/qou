    QOU.Mathlib.HeckeAlgebra — Iwahori–Hecke algebra at generic q #

    A minimal upstreamable shape for H_n(q), the Iwahori–Hecke algebra of type A_{n-1} at a generic Hecke parameter q. Mathlib has symmetric-group representation theory in Mathlib.RepresentationTheory.SymmetricGroup but not the q-deformation H_n(q). This file fills the gap with the smallest API the QOU substrate consumes:

    1. IwahoriHeckeAlgebra n q (a class) — abstract carrier with the braid + Hecke relations as fields.
    2. MarkovTrace (a class) — the unique trace satisfying the Markov-axiom tr_M(x · σ_n) = z · tr_M(x) plus tr_M(1) = 1.
    3. WedderburnDecomposition (a class) — at generic q, H_n(q) ≅ ⊕_{λ ⊢ n} M_{d_λ}(R).
    4. WenzlBridge (a class) — the central-character expansion tr_M(σ_w) = Σ_λ y_λ · χ_λ(σ_w) with closed-form y_λ = dim_q(λ) · d_λ / [n]_q!.

    Class structure: each is a class in AGENTS.md §3b-cond form so downstream theorems take [Instance] hypotheses and remain fully verified by Lean modulo the substrate-supplied class instances.

    File status: this is upstreamable scaffolding. The genuine Mathlib implementation would supply concrete instances over ℤ[q, q⁻¹] / ℚ(q) ground rings, with the relations realised as quotients of FreeAlgebra.

    References: Kassel, Quantum Groups (Springer 1995) Ch. III. Wenzl, Hecke algebras of type A_n and subfactors, Invent. Math. 92 (1988) 349-383. Jones, Hecke algebra representations of braid groups and link polynomials, Annals (1987).

    class QOU.Mathlib.HeckeAlgebra.IwahoriHeckeAlgebra (R : Type u) [CommRing R] (n : ℕ) (q : R) :
    Type (u + 1)

    Iwahori–Hecke algebra H_n(q) of type A_{n-1} — abstract carrier as a §3b-cond class. The class fields encode the standard presentation: n - 1 braid generators σ_i satisfying the Hecke relation, the braid relation, and far-commutativity, plus a unit.

    • carrier : Type u

      Carrier set of H_n(q).

    • carrier_addCommGroup : AddCommGroup (carrier n q)

      Module structure (additive group). Instance-implicit so the three relation fields below can be written with +; it was a plain field while the relations were Prop variables and nothing needed to add.

    • one : carrier n q

      The unit element 1 ∈ H_n(q).

    • mul : carrier n q → carrier n q → carrier n q

      Multiplication.

    • smul : R → carrier n q → carrier n q

      Scalar action of the ground ring. Added with the relations: the Hecke relation has a coefficient, so it cannot be stated without one.

    • sigma : Fin (n - 1) → carrier n q

      The n - 1 braid generators σ_1, …, σ_{n-1}.

    • hecke (i : Fin (n - 1)) : mul (sigma i) (sigma i) = smul (q - Ring.inverse q) (sigma i) + one

      Hecke relation: (σ_i - q)(σ_i + q⁻¹) = 0, equivalently σ_i² = (q - q⁻¹) σ_i + 1 (AGENTS.md §7a, balanced convention).

      q⁻¹ is Ring.inverse q, not q⁻¹ — the class is over a CommRing, which has no Inv. Ring.inverse agrees with the field inverse wherever q is a unit (Ring.inverse_eq_inv'), which it is at every Hecke parameter this corpus evaluates at.

    • braid (i j : Fin (n - 1)) : ↑j = ↑i + 1 → mul (mul (sigma i) (sigma j)) (sigma i) = mul (mul (sigma j) (sigma i)) (sigma j)

      Braid relation: σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1}.

      Adjacency is a hypothesis on the underlying naturals rather than Fin arithmetic: n - 1 is truncated subtraction, so i + 1 on the nose would wrap at the top index and quietly assert the wrong equation.

    • far_commute (i j : Fin (n - 1)) : ↑i + 2 ≤ ↑j → mul (sigma i) (sigma j) = mul (sigma j) (sigma i)

      Far commutativity: σ_i σ_j = σ_j σ_i for |i − j| ≥ 2. Stated one-sided (i + 2 ≤ j); the other side follows by symmetry of the conclusion.

      class QOU.Mathlib.HeckeAlgebra.MarkovTrace (R : Type u) [CommRing R] (n : ℕ) (q z : R) [H : IwahoriHeckeAlgebra R n q] :
      Type u

      Abstract Markov trace on H_n(q). The class wraps the Jones–Wenzl uniqueness theorem: at generic q, the unique trace tr_M : H_n(q) → R satisfying (i) tr_M(1) = 1, and (ii) tr_M(x · σ_n) = z · tr_M(x) (Markov axiom) is the Jones–Markov trace. The class field markov_axiom_holds packages both.

      • trace : IwahoriHeckeAlgebra.carrier n q → R

        The trace map.

      • trace_one : trace z IwahoriHeckeAlgebra.one = 1

        Normalisation: tr_M(1) = 1.

      • markov_axiom (x : IwahoriHeckeAlgebra.carrier n q) (i : Fin (n - 1)) : ↑i + 2 = n → trace z (IwahoriHeckeAlgebra.mul x (IwahoriHeckeAlgebra.sigma i)) = z * trace z x

        The Markov axiom: tr_M(x · σ_{n-1}) = z · tr_M(x), for the LAST generator.

        "Last" is a hypothesis on the underlying naturals (i + 2 = n) rather than Fin arithmetic, for the reason recorded at IwahoriHeckeAlgebra.braid: n - 1 is truncated subtraction and an on-the-nose top index wraps. At n ≤ 1 there is no generator and Fin (n - 1) is empty, so the field is vacuously true there — correctly, since H_0 and H_1 have no Markov peel to perform.

        Was markov_axiom : Prop with a sibling markov_axiom_holds, i.e. a proposition the instance CHOSE. Its own docstring called itself a "placeholder shape".

          class QOU.Mathlib.HeckeAlgebra.WedderburnDecomposition (R : Type u) [CommRing R] (n : ℕ) (q : R) [H : IwahoriHeckeAlgebra R n q] :
          Type u

          Wedderburn decomposition at generic q: H_n(q) ≅ ⊕_{λ ⊢ n} M_{d_λ}(R). Encoded as a class hypothesis asserting the existence of block-projection idempotents p_λ summing to 1 and pairwise orthogonal.

          • block_proj : n.Partition → IwahoriHeckeAlgebra.carrier n q

            The block-projection idempotents p_λ ∈ H_n(q).

            Indexed by Nat.Partition n, not ℕ. The change is forced by writing the real blocks_sum below — a sum over blocks needs a finite index, and ℕ → H.carrier cannot express one. This is the same move the StandardYoungCount docstring above records for its own repair; the index is the partition set in both cases because that is what indexes the Wedderburn blocks of H_n(q).

          • blocks_sum : ∑ lam : n.Partition, block_proj lam = IwahoriHeckeAlgebra.one

            Completeness: Σ_λ p_λ = 1.

          • blocks_orthogonal (lam mu : n.Partition) : lam ≠ mu → IwahoriHeckeAlgebra.mul (block_proj lam) (block_proj mu) = 0

            Pairwise orthogonality: p_λ · p_μ = 0 for λ ≠ μ.

          • blocks_idem (lam : n.Partition) : IwahoriHeckeAlgebra.mul (block_proj lam) (block_proj lam) = block_proj lam

            Idempotence: p_λ² = p_λ. The class docstring called these "idempotents" and nothing said so; now something does.

              def QOU.Mathlib.HeckeAlgebra.triv_hecke (R : Type u) [CommRing R] (n : ℕ) (q : R) :

              Trivial model of the Hecke class — every field is filled with the structurally-trivial value (carrier := PUnit, all three relations := True). Genuine models at R = ℚ(q) arrive when Mathlib's Iwahori–Hecke library lands.

              A def, not an instance, since 2026-08-23. It was declared instance, and its docstring said so plainly: "Discharges the §3b-cond hypothesis at the audit level." That is what §3b-tax forbids — "an unproved primary is honestly represented by a content-bearing class with no instance; do not fabricate a trivial instance to 'close' it."

              The defect was not the placeholder but its globality. Being an instance, typeclass resolution supplied it for every R, n, q, so every downstream [IwahoriHeckeAlgebra R n q] was discharged silently with carrier = PUnit and the author of that theorem never learned the hypothesis was free. Measured before the change:

              #synth IwahoriHeckeAlgebra ℤ 3 1                     -- triv_hecke ℤ 3 1
(inferInstance : IwahoriHeckeAlgebra ℤ 3 1).carrier = PUnit  -- rfl

              As a def the trivial model stays available to anyone who deliberately wants it (letI := triv_hecke R n q), and nothing is discharged behind a caller's back. Blast radius of the demotion, measured: one error, triv_wedderburn below, fixed in place. Nothing else in the corpus depended on the global resolution.

                                                                      H_3 Wedderburn block decomposition (3 blocks) #

                                                                      `H_3(q)` decomposes as `M_1(R) ⊕ M_2(R) ⊕ M_1(R)` at generic
q, indexed by the partitions of 3:
- λ = [3]:    1-dim symmetric block,
              projector `e_[3]` is the "q-symmetrizer".
- λ = [2,1]:  2-dim mixed block,
              projector `e_[2,1] = 1 - e_[3] - e_[1,1,1]`.
- λ = [1,1,1]: 1-dim antisymmetric block,
              projector `e_[1,1,1]` is the "q-antisymmetrizer".

Block dimensions: 1² + 2² + 1² = 6 = |S_3| ✓.

Standard projector formulas (Hoefsmit / Wenzl normalisation),
written with the S_3 Poincaré polynomial in the Hecke
parameter, `P(q) = Σ_{w ∈ S_3} q^{2ℓ(w)} = 1 + 2q² + 2q⁴ + q⁶
= (1+q²)(1+q²+q⁴)`:
- `e_[3]     = (1 / P(q))   Σ_{w ∈ S_3} q^{ℓ(w)} T_w`.
- `e_[1,1,1] = (1 / P(q⁻¹)) Σ_{w ∈ S_3} (-q⁻¹)^{ℓ(w)} T_w`.
- `e_[2,1]   = 1 - e_[3] - e_[1,1,1]`.

Why `P(q)` and not the balanced `[3]_q!`: the trivial block
satisfies `T_w e_[3] = q^{ℓ(w)} e_[3]`, so squaring the sum
multiplies it by `Σ_w q^{2ℓ(w)}` — idempotency forces the
normalizer `P(q)` exactly.  The sign block has
`T_w e_[1³] = (-q⁻¹)^{ℓ(w)} e_[1³]`, forcing `P(q⁻¹)`.
The earlier balanced-`[3]_q!` normalizer made both
projectors non-idempotent; see
`docs/audits/2026-06-09-heckealgebra-idempotency-diagnosis.md`.

                                                                                                                            Recursive H_n structure #

                                                                                                                            The Hecke tower `H_0 ⊂ H_1 ⊂ H_2 ⊂ ...` admits a clean
recursion at each level:

1. **Cardinality recursion**: `|H_{n+1}(q)| = (n+1) · |H_n(q)|`
   (basis size grows as `n.factorial`, with `(n+1)! = (n+1) · n!`).

2. **Coset decomposition**: as a left `H_n(q)`-module,
   `H_{n+1}(q) ≅ H_n(q) ⊕ H_n(q) · σ_n ⊕ H_n(q) · σ_n σ_{n-1}
   ⊕ ... ⊕ H_n(q) · σ_n ... σ_1` (`n+1` summands).

3. **Markov-trace recursion**: `tr_M^{(n+1)}(x · σ_n) = z ·
   tr_M^{(n)}(x)` for `x ∈ H_n(q)` (Jones–Markov axiom).

4. **Wedderburn-block recursion**: `Σ_{λ ⊢ n+1} d_λ² = (n+1)!
   = (n+1) · Σ_{μ ⊢ n} d_μ²` (Burnside / branching rules).

Each is captured as a theorem below.

                                                                                                                                        Per-generator action via H_{n-1} ⊂ H_n embedding (item #1) #

                                                                                                                                        The Hecke tower has the property that for each `n`, `H_n(q)`
contains `H_{n-1}(q)` as the subalgebra generated by `σ_1,
…, σ_{n-2}`.  The "new" generator `σ_{n-1}` at level `n`
acts on `H_{n-1} ⊂ H_n` by:
- **Far commutativity**: `σ_{n-1} · σ_i = σ_i · σ_{n-1}` for
  `i ≤ n-3`.
- **Braid relation**: `σ_{n-1} · σ_{n-2} · σ_{n-1} = σ_{n-2}
  · σ_{n-1} · σ_{n-2}`.
- **Hecke relation**: `σ_{n-1}² = (q − q⁻¹) σ_{n-1} + 1`.

This gives a **recursive build** of the per-generator action
table at level `n` from the level-`n-1` action.  Encoded
abstractly below as a class hypothesis.
