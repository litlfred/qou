    theorem MvPolynomial.abs_coeff_mvGenWronskian_le {σ : Type u_1} [DecidableEq σ] {m L : ℕ} {S d B : ℤ} (hS1 : 1 ≤ S) (hd1 : 1 ≤ d) (hB0 : 0 ≤ B) (D : Fin m → List σ) (f : Fin m → MvPolynomial σ ℤ) (hS : ∀ (j : Fin m), ↑(f j).support.card ≤ S) (hd : ∀ (i : σ) (j : Fin m), ↑(degreeOf i (f j)) ≤ d) (hB : ∀ (j : Fin m) (n : σ →₀ ℕ), |coeff n (f j)| ≤ B) (hL : ∀ (i : Fin m), (D i).length ≤ L) (n : σ →₀ ℕ) :
    |coeff n (mvGenWronskian D f)| ≤ ↑m.factorial * (S * (d ^ L * B)) ^ m

    The height of a generalized Wronskian:

    H(mvGenWronskian D f)  ≤  m! · (S · (d^L · B))^m

    for f : Fin m → MvPolynomial σ ℤ whose supports have size at most S, whose degrees in every variable are at most d, and whose heights are at most B, with each operator list D i of length at most L.

    This is the composite the arc had been assembling in pieces. Each matrix entry is pderivList (D i) (f j), so abs_coeff_pderivList_le bounds its height by d^{|D i|}·B ≤ d^L·B and card_support_pderivList_le keeps its support at S; abs_coeff_det_le then does the Leibniz expansion.

    The hypotheses 1 ≤ S, 1 ≤ d, 0 ≤ B are not restrictive — any bound can be raised to meet them — and they are what let the result be stated as a clean power rather than a product of per-index factors.

    Non-vacuity guard #

    abs_coeff_mvGenWronskian_le carries eight hypotheses. This instantiates all of them at once — m = 1, f = X, D = ![[]], S = d = B = 1, L = 0 — so the theorem cannot be true merely because its premises are unsatisfiable.

    The D i j shape — the height side's missing composite #

    ⚠ This is correction 5's pattern again, on the other chain. There the index side had no counterpart to a height composite; here the height side has none to an index composite.

    abs_coeff_mvGenWronskian_le above is for D : Fin m → List σ — one operator list per row, applied to a different function per column. Mahler §13's determinant is a different shape: D : Fin r → Fin r → List σ, a different operator for each entry, all applied to the same P. The index side has that composite (sum_max_le_index_det, QOU/Mathlib/WronskianIndex.lean); the height side did not, and the gap went unnoticed for the same reason as last time — each side looked complete from its own end.

    The composite itself is short: abs_coeff_det_le for the determinant, and card_support_pderivList_le / abs_coeff_pderivList_le for the entries.

    ⚠⚠ Correction twenty-one — this file bounds the wrong operator #

    §7 (doc pp. 85–86) bounds the auxiliary polynomial by a majorant, A ≪ a(1+x₁)^{r₁}…(1+x_m)^{r_m}, differentiates it, and reads off

    A_{j₁…j_m} ≪ a·binom(r₁,j₁)…binom(r_m,j_m)·(1+x₁)^{r₁−j₁}…(1+x_m)^{r_m−j_m}
binom(r,j) ≤ 2^r,   so   Δ_{μν}A ≪ 2^{r₁+…+r_m}·a·∏(1+x_h)^{r_h}
W ≪ n!·{2^{Σ r_h}·a·∏(1+x_h)^{r_h}}^n

    The binomial with no j! is the tell. For an ordinary derivative the coefficient factor is j!·binom(i,j) (see coeff_pderiv_iterate below); Mahler's is binom(r_h,j_h) alone. So his Δ is the divided (Hasse) derivative, and mvGenWronskian — a fold of MvPolynomial.pderiv — is not it.

    The two determinants differ by the scalar (∏_i (Dx i)!)·(∏_j (Dy j)!), because the operator on entry (i,j) splits as a row part and a column part. That is free for the index (index_C_mul) and free for the dependence criterion. It is not free for the height, and §12 spends its budget 2^{(2m+1)ρ₁} exactly — clause 3 is calibrated to equality at the floor — so there is nothing to absorb it with.

    That is why abs_coeff_det_sepFamily_le's d^{2n²} does not fit §12's 2^{2nΣr_h}: the d^{2n²} is the factorials, not a loose estimate.

    The lemma below is the first stone of the repair: the exact coefficient formula for iterated pderiv, from which the factorial separates cleanly and §7's 2^{d} appears.

    ⚠ It rests on MvGenWronskian.coeff_pderiv, which this arc already had. A first draft of this section re-proved that lemma from scratch — the second self-duplication in this session (the first was map_pUnitAlgEquiv, already present as pUnitAlgEquiv_map). The beans discipline's "check before you create" applies to lemmas too, and a duplicate type-checks.

    theorem MvPolynomial.coeff_pderiv_iterate {σ : Type u_1} {R : Type u_2} [CommRing R] [DecidableEq σ] (j : σ) (k : ℕ) (g : MvPolynomial σ R) (n : σ →₀ ℕ) :
    coeff n ((⇑(pderiv j))^[k] g) = (∏ i ∈ Finset.range k, ↑(n j + 1 + i)) * coeff (n + Finsupp.single j k) g

    The coefficient of an iterated partial derivative, exactly:

    coeff n (∂ⱼ^k g) = (n_j + 1)(n_j + 2)⋯(n_j + k) · coeff (n + k·eⱼ) g

    The product is k!·binom(n_j + k, k). The k! is exactly what separates ∂^k from the divided derivative, and binom(n_j+k, k) ≤ 2^{n_j+k} is §7's 2^r.
