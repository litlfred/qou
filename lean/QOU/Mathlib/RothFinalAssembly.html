    theorem MvPolynomial.height_le_mul_den {κ : ℚ} {B : ℝ} (hB : 1 ≤ B) (hκ : |↑κ| ≤ B) :
    ↑(max κ.num.natAbs κ.den) ≤ B * ↑κ.den

    A bounded rational's height is at most B times its denominator. H = max(|num|, den), and |num| ≤ B·den is just |κ| ≤ B cleared of its denominator; den ≤ B·den needs B ≥ 1.

    This is the lemma that lets a floor on the heights — which is all the selection can impose, since S is a set of heights — serve as a floor on the denominators, which is what hpt actually constrains. Without it the two floors are unrelated: a rational of height 10^9 can have denominator 1.

    False

    Steps 1 → 2 → 3 → 4, with the parameters chosen rather than assumed.

    roth_contradiction_int needed nine facts about data it did not produce — the degrees r, the heights H, the auxiliary polynomial's height bound, the approximations. Here every one of them is produced, and what is left is a list of conditions on constants alone:

    • hfloorExp, hgap, hpq — the ladder's own arithmetic, unchanged from Γ_m;
    • hm2 : 2·[K:ℚ] < 4ε²m — unknowns beat conditions, with the factor 2 that keeps Siegel's exponent at most 1;
    • hT — one floor on the heights, discharging both the height clause (hTsiegel) and the polynomial's share of the denominators (hTtheta);
    • hfin — Roth's inequality, with log N already divided out.

    hfin is the interesting one. In (1+θ)·m·(1+η) < (2+δ)(1−η)·(m(½−ε) − ν) the normalisation slack η = 1/k appears on both sides with opposite signs: it inflates the denominators' total size and deflates the approximation exponent. Writing 2 + δ' := (2+δ)(1−η) turns it into exactly exists_m_of_slack's shape at δ', so the excess the slack budget is paid from is not δ but δ − η(2+δ) — the approximation quality net of the normalisation. That is the honest statement of "choose N large compared with the heights", and it is why k had to become a parameter of the selection.

    The supply app is the negation of Roth's theorem in the form the proof consumes: for every height in an unbounded set S there is a rational of exactly that height approximating ψ α₀ to within H^{-(2+δ)}.

    The slack budget, in the product form this chain actually produces #

    RothNormalisation.slack_pos balances the budget for the additive shape K = (2+δ)L, L' = (1+η)L. The chain built here produces something slightly different: the two-sided normalisation gives K = (2+δ)(1−η)·log N and L' = (1+η)·log N, so η appears twice, with opposite signs — it inflates the denominators' total size and deflates the approximation exponent. slack_pos's form sees only the first.

    The budget is correspondingly tighter, and the threshold below is what it comes to: with all four slacks below a common t,

    t·(16 + 5δ) < δ

    is enough, and the derivation is tight to it — the surplus works out to t + t²(3+2δ). In particular t < δ/(16+5δ) < 1/5, which is where the 1/2 − 2t > 0 that the whole estimate rests on comes from.

    ∃ (m : ℕ) (p : ℕ) (q : ℕ) (F : ℕ) (k : ℕ) (T : ℕ) (ε : ℚ) (ν : ℚ) (θ : ℝ), 1 ≤ m ∧ 0 < p ∧ p ≤ q ∧ 0 < q ∧ 1 ≤ F ∧ 1 ≤ k ∧ q * ((m - 1) * m * (2 * m + 1)) ≤ F * p ∧ 0 < ε ∧ ε ≤ 1 / 2 ∧ 2 * ↑(Module.finrank ℚ K) < 4 * ε ^ 2 * ↑m ∧ 0 ≤ θ ∧ 1 ≤ T ∧ C₀ ^ (m * q) * W ^ (2 * m * m * q) ≤ ↑T ∧ 2 + (Real.log ↑C₀ + Real.log ↑W) + Real.log (2 * B) + Real.log 2 + θ * Real.log B ≤ θ * Real.log ↑T ∧ 0 ≤ ν ∧ ↑(rothConstant m) ^ 2 ^ (m - 1) * (↑p / ↑q) < ν ^ 2 ^ (m - 1) ∧ (1 + θ) * (↑m * (1 + 1 / ↑k)) < (2 + δ) * (1 - 1 / ↑k) * (↑(↑m / 2 - ε * ↑m) - ↑ν)

    The parameters exist. Every hypothesis of roth_contradiction_selected except the supply app is satisfiable, simultaneously, for any δ > 0 and any K, B, C₀, W.

    This is the non-vacuity check, and it is not optional. roth_contradiction_selected derives False from a list of conditions; a contradictory list would prove it just as well and would look exactly the same from outside. app is deliberately excluded — it is the negation of Roth's theorem, so no witness for it can exist and asking for one would be asking to refute the result.

    The order of choice is forced, and every step is Archimedean:

    1. t from exists_slack_bound — the common bound on all four slacks.
    2. s : ℚ below both t and 1/2; it serves as ε, as θ, and as ν/m.
    3. k past 1/s, so the normalisation slack 1/k is below s.
    4. m past [K:ℚ]/(2s²) — the doubled unknowns-beat-conditions threshold.
    5. ν := s·m.
    6. q past rothConstant(m)^(2^{m−1}) / ν^(2^{m−1}) at p = 1, then F from hfloorExp.
    7. T past exp((2 + log C₀W + log 4B + s·log B)/s) and past C₀^{mq}·W^{2m²q}.

    ν is the step worth naming. hgap bounds it below and hfin bounds it above, so ν cannot be made small; only ν/m can, which is why hfin_of_slack's division by m is not cosmetic. Taking ν = s·m pins ν/m at s while hgap's lower bound falls away as q grows — the two constraints are compatible only in that order.

    theorem MvPolynomial.not_approximable_of_algebraic {K : Type u_1} [Field K] [NumberField K] (α₀ : NumberField.RingOfIntegers K) (ψ : K →+* ℝ) {δ : ℝ} (hδ : 0 < δ) :
    ¬∀ (N : ℕ), ∃ (κ : ℚ), N ≤ max κ.num.natAbs κ.den ∧ |↑κ - ψ ((algebraMap (NumberField.RingOfIntegers K) K) α₀)| ≤ ↑(max κ.num.natAbs κ.den) ^ (-(2 + δ))

    Step 5 — Roth's theorem, in the "not approximable to order 2 + δ" form.

    For a real embedding ψ of a number field and an algebraic integer α₀, there is no sequence of rationals of unbounded height approximating ψ α₀ to within H^{-(2+δ)}.

    Everything the contradiction needs is now manufactured here rather than assumed:

    • the constants — B above the house of α₀ and above |ψ α₀| + 1, C₀ above c K, W above 4B — are ceilings, and exist because those are three real numbers;
    • the parameters come from exists_roth_parameters, which is where the non-vacuity lives;
    • the supply S is defined as the set of heights that admit a good approximation, so app holds by unfolding and hS is exactly the hypothesis being refuted.

    ⚠ Scope. This is Roth for ψ α₀ with α₀ an algebraic integer of K. Extending to every real algebraic number needs one more step — clearing denominators, so that an arbitrary algebraic x is ψ α₀ / n for some α₀ ∈ 𝓞 K — and the approximation exponent has to be carried across that scaling. That step is not done here, and the statement below says only what it proves.

    Clearing denominators: what the height does under an integer multiple #

    not_approximable_of_algebraic is stated for ψ α₀ with α₀ an algebraic integer. Reaching an arbitrary real algebraic number goes through IsAlgebraic.exists_integral_multiple: some n·x is integral. So the approximation hypothesis has to be transported along κ ↦ n·κ, and these lemmas are what that costs.

    The scaling is two-sided and lossy in the same factor: H(nκ) ≤ n·H(κ) and H(κ) ≤ n·H(nκ). The first bounds the new height from above; the second is what keeps the transported heights unbounded, and it does not follow from the first — without it every nκ could have height 1. Both come from one fact about an unreduced fraction, read in opposite directions.

    ⚠ The factor n is why this argument cannot preserve the exponent. |nx − nκ| = n|x − κ| ≤ n·H(κ)^{-(2+δ)}, and n·H^{-(2+δ)} ≤ H^{-(2+δ')} only once H^{δ−δ'} ≥ n, which fails for every H when δ' = δ.

    An earlier draft of this comment said the transported statement holds "at no δ' = δ". That was an overclaim and is corrected here: what fails at δ' = δ is the elementary transport, not the statement. Whether n·x is approximable to order exactly 2 + δ is not settled by anything in this file — and appealing to Roth to settle it would be circular, since Roth is what this transport feeds.

    theorem MvPolynomial.approximable_nsmul {x : ℝ} {n : ℕ} (hn : 0 < n) {δ δ' : ℝ} (hδ'0 : 0 < δ') (hlt : δ' < δ) (h : ∀ (N : ℕ), ∃ (κ : ℚ), N ≤ max κ.num.natAbs κ.den ∧ |↑κ - x| ≤ ↑(max κ.num.natAbs κ.den) ^ (-(2 + δ))) (N : ℕ) :
    ∃ (κ : ℚ), N ≤ max κ.num.natAbs κ.den ∧ |↑κ - ↑n * x| ≤ ↑(max κ.num.natAbs κ.den) ^ (-(2 + δ'))

    Approximability transports along an integer multiple, at a strictly smaller exponent. If x admits rational approximations of unbounded height to order 2 + δ, then n·x admits them to order 2 + δ' for every δ' < δ.

    The whole argument is linear once written in logarithms, which is why it is written that way here: the condition is (3 + δ')·log n ≤ (δ − δ')·log H, so the threshold fed to the hypothesis is exp((3+δ')·log n / (δ−δ')), and both height bounds enter as log H(nκ) ≤ log n + log H(κ) and H(κ) ≤ n·H(nκ). Nothing here needs the monotonicity of x ↦ x^c for negative c.

    theorem MvPolynomial.approximable_height_of_den {x B : ℝ} (hB0 : 0 ≤ B) (hBx : |x| ≤ B) {ε δ : ℝ} (hδ0 : 0 < δ) (hlt : δ < ε) (h : ∀ (N : ℕ), ∃ (κ : ℚ), N ≤ κ.den ∧ |↑κ - x| ≤ ↑κ.den ^ (-(2 + ε))) (N : ℕ) :
    ∃ (κ : ℚ), N ≤ max κ.num.natAbs κ.den ∧ |↑κ - x| ≤ ↑(max κ.num.natAbs κ.den) ^ (-(2 + δ))

    Height form from denominator form. The classical statement bounds |x − p/q| by a power of the denominator; everything above is stated in terms of the height max(|p|, q). The two differ, and the difference costs a slice of the exponent.

    H ≥ q always, so q^{-(2+ε)} ≥ H^{-(2+ε)} — the height form is the stronger hypothesis, and it does not follow from the denominator form for free. What makes it follow is that a rational close to a bounded x has a bounded numerator: |p| ≤ (B+1)q, hence H ≤ (B+1)q, and then q^{-(2+ε)} ≤ H^{-(2+δ)} once (B+1)^{2+δ} ≤ q^{ε−δ}. True for large q, and the hypothesis supplies unboundedly many.

    This is flagged as R0 in docs/audits/2026-08-30-roth-arc-ROAST.md: the gap is benign but it had never been written down, and "benign and unwritten" is what this repo's taxonomy exists to catch.

    theorem MvPolynomial.not_approximable_of_isAlgebraic {x : ℝ} (hx : IsAlgebraic ℚ x) {ε : ℝ} (hε : 0 < ε) :
    ¬∀ (N : ℕ), ∃ (κ : ℚ), N ≤ κ.den ∧ |↑κ - x| ≤ ↑κ.den ^ (-(2 + ε))

    Roth's theorem, for every real algebraic number.

    |x − p/q| ≤ q^{−(2+ε)} has no solutions of unbounded denominator, for any real algebraic x and any ε > 0.

    Everything analytic is already done — not_approximable_den_of_nsmul_eq handles both exponent conversions. What is left is construction, and it is the last step of the arc:

    • IsFractionRing.isAlgebraic_iff ℤ ℚ ℝ turns IsAlgebraic ℚ x into IsAlgebraic ℤ x by clearing denominators, and exists_integral_multiple then produces a non-zero c : ℤ with c • x integral. The sign is discarded by passing to c.natAbs, since integrality survives negation.
    • ℚ⟮y⟯ ⊆ ℝ for y = |c|·x is a number field: finite-dimensional because y is integral over ℚ, and of characteristic zero because it sits inside ℝ.
    • The real embedding is the inclusion, and it is injective because it is a ring map out of a field — which is also what lets IsIntegral.tower_bot carry integrality down from ℝ to ℚ⟮y⟯, the one step that does not go the obvious way.

    Note that y need not be primitive for anything: ℚ⟮y⟯ is used only as some number field containing y, never as ℚ(x).

    theorem MvPolynomial.finite_den_le (x : ℝ) (D : ℕ) :
    {κ : ℚ | κ.den ≤ D ∧ |↑κ - x| ≤ 1}.Finite

    Rationals of bounded denominator near a fixed real are finitely many. The num/den pair determines the rational, the denominator is bounded by hypothesis, and the numerator is bounded because |κ| ≤ |x| + 1 forces |num| ≤ (|x|+1)·den.

    This is the discreteness of ℚ, and it is exactly what separates "no family of unbounded denominator" from "finitely many solutions". Nothing earlier in the arc supplies it — every estimate so far is about how good an approximation is, none about how many there are.

    theorem MvPolynomial.finite_approximations_of_isAlgebraic {x : ℝ} (hx : IsAlgebraic ℚ x) {ε : ℝ} (hε : 0 < ε) :
    {κ : ℚ | |↑κ - x| ≤ ↑κ.den ^ (-(2 + ε))}.Finite

    Roth's theorem, classical form. For a real algebraic x and any ε > 0, the inequality |x − p/q| ≤ q^{−(2+ε)} has only finitely many rational solutions.

    The step from not_approximable_of_isAlgebraic is not bookkeeping: "no family of unbounded denominator" and "finitely many solutions" differ by the discreteness of ℚ, which is finite_den_le. What makes them meet is that a solution is automatically within 1 of x, because q^{−(2+ε)} ≤ 1 — so an infinite solution set with bounded denominators would sit inside a finite set.
