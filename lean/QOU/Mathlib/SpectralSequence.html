    QOU.Mathlib.SpectralSequence — abstract spectral-sequence API #

    A minimal, upstreamable shape for the E_r-page library that QOU's GB-filtration spectral sequence and Wedderburn-block arguments need. Mathlib has homological-algebra primitives (HomotopyCategory, DerivedCategory, ChainComplex) but no E_r-page abstraction with collapse criteria. This file fills that gap with the smallest API the QOU substrate consumes:

    1. SpectralSequence R — pages indexed by ℕ × ℤ × ℤ (page, bidegree (p, q)), valued in R-modules that are abstractly Type*.
    2. differential of bidegree (r, 1 - r) (cohomological convention).
    3. CollapsesAt r₀ predicate — d_r = 0 for all r ≥ r₀.
    4. convergesTo placeholder relating the r₀ page to the E_∞-target.

    The QOU GB-filtration claim is CollapsesAt 2, i.e. the spectral sequence collapses at the E_2 page (Wedderburn block decomposition coincides with E_2).

    This file is namespaced QOU.Mathlib.SpectralSequence to mark it as an upstreamable candidate. Migration to Mathlib proper would keep the same shape with R-modules replaced by Mathlib.CategoryTheory.GradedObject machinery.

    LaTeX label: substrate axiom S-spectral-sequence-collapse (AGENTS.md §3b — class axiomatisation).

          structure QOU.Mathlib.SpectralSequence.SpectralSequence (R : Type u) :
          Type (u + 1)

          A spectral sequence over a coefficient type R: an abstract family of cell groups, indexed by the page + bidegree, equipped with differentials d_r and the requirement d_r ∘ d_r = 0.

          • cell : CellIndex → Type u

            Cell at index c = (r, p, q). Abstract carrier; a concrete instance picks R-modules / vector spaces / abelian groups.

          • cell_inhab (c : CellIndex) : Inhabited (self.cell c)

            Each cell is inhabited (every cell is at least the zero element). Concrete instances supply the full module structure.

          • differential (c : CellIndex) : self.cell c → self.cell c.next

            The differential d_r : E_r^{p,q} → E_r^{p+r,q-r+1}.

          • zero (c : CellIndex) : self.cell c

            The zero element of each cell (used to state "differential vanishes" without a full module structure).

                      What inhabiting these classes does and does not show #

                      In the manner of
`QOU/Archimedean/TauFunctorTargetSpec.lean`'s
`interface_alone_is_trivially_inhabitable`: the classes above are
inhabitable, cheaply, and a reader should be able to check how cheaply.

**Every spectral sequence constructed in this file has
`differential _ _ := default` — the constant map.** So `CollapsesAt` holds
of them by `rfl`, definitionally, for every page. Collapse is built into
the models rather than proved of anything.

That is not a defect of the models — an abstract API needs witnesses — but
it does bound what they establish. `collapse_is_definitional` below records
it so no downstream reader mistakes "the API has a collapsing instance" for
"the GB filtration collapses".

The open obligation is unchanged and is the whole content of
`S-GB-spectral-collapse`: exhibit the spectral sequence of the *actual*
Gröbner filtration on `H_n(q)`, with differentials that are what the
filtration makes them, and show `d_r = 0` for `r ≥ 2`. Nothing here does
that, and nothing here is evidence about it.

                      theorem QOU.Mathlib.SpectralSequence.collapse_is_definitional (R : Type u) (r₀ : ℕ) :
                      CollapsesAt (trivial R) r₀

                      The trivial model collapses definitionally, not substantively. Its differential is the constant map, so d_r = 0 is rfl at every page — there is no filtration behind it and no computation performed.

                      Convergence + E_∞ page #

                      A spectral sequence **converges** to a target if its
`E_∞` page (the colimit of the `E_r` pages, equivalently
the `r`-stable cells once `d_r = 0` for all `r ≥ r₀`)
matches the target.  At collapse, `E_∞ = E_{r₀}` directly.

                        Two further defects in the API itself, demonstrated #

                        Beyond the vacuity of the *instances* (`qou-fngs`), the **predicate** is
weaker than its name. Both facts below are exhibited rather than asserted.

**(i) `zero` is a marked element, not an additive zero.** `SpectralSequence`
carries `zero : ∀ c, cell c` with no additive structure on `cell` and no law
relating `zero` to anything. So `CollapsesAt` says "the differential equals
whatever the model nominated", which *any* constant differential satisfies —
see `constTrue_collapses` together with `constTrue_differential_is_true`.

**(ii) There is no page-turning, so collapse relates no two pages.** A real
spectral sequence requires `E_{r+1} ≅ ker d_r ⧸ im d_r`; this structure has
no such field, so `cell {r := 2, …}` and `cell {r := 3, …}` are unrelated
types. `EInfinityCell` then *defines* `E_∞` to be the `r₀` page, and
`eInfinity_eq_page_is_rfl` shows that equation is `rfl` — a definition, not
a consequence of collapsing. The docstring claim that collapse "immediately
implies `E_{r₀} = E_{r₀+1} = … = E_∞`" holds only in that circular sense.

**How to resolve.** Value the cells in `ModuleCat R` (Mathlib has it), make
`differential` `R`-linear, and add the two missing laws — `d ∘ d = 0` and
the page-turning isomorphism. Then `CollapsesAt r₀ → E_{r₀} ≅ E_∞` becomes a
theorem instead of a definition. Everything that needs is already in
Mathlib (`LinearMap.ker`, `LinearMap.range`, quotients): it is the *general*
spectral-sequence theory that is missing (`qou-pan0`), not this.
