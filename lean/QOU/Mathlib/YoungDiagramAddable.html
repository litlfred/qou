    QOU.Mathlib.YoungDiagramAddable — addable cells, and #addable = #removable + 1 #

    QOU/Mathlib/YoungDiagramCorner.lean supplies removable corners (IsCornerCell, eraseCorner) — the cells whose deletion leaves a Young diagram. This file supplies the mirror notion, the addable cells whose insertion leaves a Young diagram, and proves the counting relation between the two:

    #{addable cells of μ} = #{removable corners of μ} + 1

    for every Young diagram μ, the empty one included.

    Why this identity #

    It is the diagonal of the DU − UD = I relation of Stanley's differential-poset formulation of the Young lattice, and DU − UD = I is what QOU/Mathlib/BurnsideViaBranching.lean needs in order to discharge its remaining hypothesis hup (Σ_{λ ⊐ μ} f^λ = n · f^μ), the last obligation on the RSK-free route to

    Σ_{λ ⊢ n} (f^λ)² = n!    (bean `qou-wtny`, SW-3).

    That file's companion hypothesis hdown is already discharged in the corpus by QOU.Mathlib.numStandardYoungTableaux_branching. This file does not close hup — see §"What this does not do" below, which states precisely what is still missing.

    The proof #

    Both sets are reindexed by their row, after which the identity is a shift by one. Writing r i := μ.rowLen i:

    • (i, j) is a removable corner ⟺ r i = j + 1 and r (i+1) < r i (corner_iff);
    • (i, j) is an addable cell ⟺ j = r i and (i = 0 or r i < r (i-1)) (addable_iff).

    So removable corners biject with R = {i | r (i+1) < r i} and addable cells with A = {0} ∪ {i+1 | i ∈ R} — the disjoint union of a single extra element with a shifted copy of R (addableRows_eq). Hence #A = #R + 1. Row 0 is always addable (one may always start a new first row); every other addable row is the row directly below a removable corner, and conversely.

    Both index sets are cut out of a Finset because r i = 0 once i ≥ μ.colLen 0 (rowLen_pos_iff), so only finitely many rows can carry either kind of cell.

    IsAddableCell is proved to be the right notion, not asserted #

    IsAddableCell is stated as a concrete condition on neighbours (c ∉ μ, and each of c's up/left neighbours is in μ or off the board). On its own that is a definition, and a definition cannot be wrong — so it is backed by addCell, which constructs the Young diagram μ ∪ {c} from it, discharging the IsLowerSet obligation. That is what makes IsAddableCell mean "can actually be added" rather than merely naming a predicate. card_addCell records that the construction does add exactly one cell.

    What this does not do #

    hup needs the full DU − UD = I, i.e. also the off-diagonal: for μ ≠ ν of the same size, #{λ | λ ⊐ μ, λ ⊐ ν} = #{κ | κ ↗ μ, κ ↗ ν} (both are 1 when μ and ν differ by moving a single cell, and 0 otherwise). That is a statement about pairs of diagrams and is untouched here. The induction assembling diagonal + off-diagonal + hdown into hup is also not done. Per AGENTS.md §"Axiomatization is NOT a Proof", this file proves one lemma; it does not license treating hup as established.

    Sanity check #

    On μ = (3,2,2) the file's own definitions evaluate to #cornerCells = 2 and #addableCells = 3, matching the hand count — corners (0,2) and (2,1); addable cells (0,3), (1,2) and (3,0). Both sides are non-empty, so the identity here is not the vacuous 0 = 0 + 1-style statement an unguarded cardinality equation can degenerate into.

    Recorded honestly: that is an #eval (compiler) check, not a kernel-checked theorem. decide does not close it — reduction gets stuck on YoungDiagram.ofRowLens — and native_decide is banned by AGENTS.md §"Strict Lean Discipline" item 6, so no concrete instance is pinned as a regression test. What is kernel-checked is stronger in the direction that matters: mem_addableCells and mem_cornerCells prove the two Finsets are exactly the addable cells and the removable corners, so the identity is a statement about the genuine sets rather than about two conveniently-chosen images.

    Base ring #

    None — the whole file is ℕ-valued counting on Finsets. Nothing archimedean, no fit.

    0 < μ.rowLen i ↔ i < μ.colLen 0

    Row i is non-empty exactly when i is below the height of the first column. In particular μ.rowLen i = 0 for every i ≥ μ.colLen 0, which is what makes the row-index sets below finite.

    Addable cells #

    source
    def QOU.Mathlib.IsAddableCell (μ : YoungDiagram) (c : ℕ × ℕ) :
    Prop

    An addable cell of μ: a cell outside μ whose upper neighbour (i-1, j) and left neighbour (i, j-1) each either lie in μ or fall off the board. These are exactly the cells that may be adjoined to μ with the result still a Young diagram — see addCell.
