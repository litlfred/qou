      theorem MvPolynomial.exists_integral_separated_factors {σ : Type u_1} {τ : Type u_2} (U : MvPolynomial σ ℚ) (V : MvPolynomial τ ℚ) (hU : U ≠ 0) (W : MvPolynomial (σ ⊕ τ) ℤ) (hW : (map (Int.castRingHom ℚ)) W = (rename Sum.inl) U * (rename Sum.inr) V) :
      ∃ (l : ℚ) (U' : MvPolynomial σ ℤ) (V' : MvPolynomial τ ℤ), l ≠ 0 ∧ (map (Int.castRingHom ℚ)) U' = C l * U ∧ (map (Int.castRingHom ℚ)) V' = C l⁻¹ * V

      Gauss's lemma for disjoint variable groups.

      If W has integer coefficients and, over ℚ, factors as a product of a polynomial in the x-variables and one in the y-variables, then the two factors can be rescaled by a single rational l to become integral.

      ⚠ The proof needs neither unique factorisation nor Bézout, and that is a consequence of the groups being disjoint: coeff (i ⊞ j) (U·V) = uᵢ·vⱼ exactly, so once U is scaled to be primitive and integral, the denominator of each vⱼ divides every coefficient of U', hence divides their gcd, hence is 1. In shared variables the coefficients mix and none of this is available.
