    QOU.Mathlib.PagedSpectralSequence — collapse that actually says something #

    Bean qou-fngs. QOU/Mathlib/SpectralSequence.lean has an E_r-page API whose CollapsesAt predicate is weaker than its name, in two ways that file now exhibits rather than asserts:

    • zero : ∀ c, cell c is a marked element, not an additive zero, so CollapsesAt is satisfied by any constant differential — constTrue_collapses with constTrue_differential_is_true;
    • there is no page-turning law, so pages at different r are unrelated types and EInfinityCell defines E_∞ to be the r₀ page — eInfinity_eq_page_is_rfl proves that equation by rfl, for any spectral sequence and any collapse proof.

    This module supplies the missing structure. The three things the old API lacks are exactly the three things a spectral sequence is:

    1. pages are R-modules, so "the differential is zero" means the zero map rather than "equals a nominated element";
    2. d ∘ d = 0, without which ker ⊇ im fails and the page quotient is not even well-posed;
    3. page-turning, E_{r+1} ≅ ker d_r ⧸ im d_r, which is what makes the pages a sequence rather than an indexed family of unrelated objects.

    With those, page_stabilises_of_collapse is a theorem: if every differential from page r₀ on is zero, the next page is isomorphic to this one. In the old API the corresponding statement was rfl.

    Nothing here needed missing infrastructure #

    LinearMap.ker, LinearMap.range, Submodule.comap and module quotients are all in Mathlib. It is the general spectral-sequence theory that is absent (bean qou-pan0) — the minimal honest version is not. An earlier assessment on this branch called this blocked on Mathlib; that was too pessimistic and is corrected here.

    What this still does not do #

    It does not construct the Gröbner-filtration spectral sequence, which is the whole content of the substrate axiom S-GB-spectral-collapse. It makes the claim expressible: a real instance must supply modules, a differential squaring to zero, and the page-turning isomorphism, none of which a PUnit model can fake.

                The theorem the old API could not state.

                If S collapses at r₀ then at every cell of page r ≥ r₀ the next page is isomorphic to this one. In QOU/Mathlib/SpectralSequence.lean the corresponding claim was eInfinity_eq_page_is_rfl — true by definition, for every spectral sequence, collapsing or not.

                The proof is the content of collapse: d_c = 0 makes the kernel everything, and d_{prev c} = 0 makes the incoming image nothing, so the quotient is the page itself.

                No trivial witness is shipped, deliberately #

                The structure is inhabitable — take every page to be the zero module, `d`
the zero map, and `turn` the unique isomorphism between zero modules. That
is *not* provided as a named `def` here.

The reason is the defect this file exists to repair. In
`QOU/Mathlib/SpectralSequence.lean` a trivial witness was reachable, first
by `inferInstance` and then by name, and it was cited as though the
substrate axiom had been discharged. A named trivial model is a thing
downstream code reaches for; leaving it unnamed costs a genuine instance
nothing (it supplies its own modules) and costs a decorative one the two
lines it would have leaned on.

What a real instance must supply, and what no `PUnit` model can fake:
module structure on every page, an `R`-**linear** differential squaring to
zero, and an isomorphism onto the actual subquotient.
