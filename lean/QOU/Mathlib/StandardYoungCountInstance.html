    QOU.Mathlib.StandardYoungCountInstance — the carrier, inhabited #

    QOU.Mathlib.HeckeAlgebra.StandardYoungCount used to carry its identity as a Prop-valued field, which let an instance choose the proposition as well as prove it. With the field restated as the Burnside/RSK identity itself the class asserts something, and this module supplies the canonical inhabitant.

    Both halves come from the corpus and neither is conditional:

    • QOU.Mathlib.dimSYT — the genuine SYT count, a Finite-backed Nat.card over Nat.Partition n (RSKBurnsideTarget.lean);
    • QOU.Mathlib.RSKBridge.RSK_substrate_proved — ∑_{λ ⊢ n} dimSYT λ ² = n!, delegating to QOU.Mathlib.rskBurnsideHolds in SchenstedRSKBurnside.lean, which takes no instance argument.

    Two same-named theorems, and only one of them is unconditional #

    Worth recording, because the names collide and the wrong reading makes this instance look conditional. There are two rskBurnsideHolds:

    declaration hypotheses
    QOU.Mathlib.rskBurnsideHolds (SchenstedRSKBurnside.lean) none — this is the one used here
    …RSKBurnsideDischarge.rskBurnsideHolds [SnWedderburnPartitionBridge.SnIsotypicSpechtSplit ℚ]

    RSKBridge.RSK_substrate_proved delegates to the first. (The second is not open either — that class has an instance for every characteristic-zero field, SnIsotypicSpechtSplitInstance.lean — but it is a different route and its binder is what makes the two look different.)
