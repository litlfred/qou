    §10's estimate, with H rather than q #

    §10 bounds Θ₁(a; r; H) ≤ log a / (r log H) for H ≥ 2, where H = max(|P|, |Q|) is the height of the point κ = P/Q. Its proof:

    A(x) = (Qx − P)^j·B(x) with B integral, hence the lowest and the highest non-zero coefficients of A are divisible by P^j and Q^j respectively. It follows that H^j ≤ |A| ≤ a.

    ⚠⚠ This block previously read "this module proves only the Q^j half … ⚠ Not attempted". Both halves are now proved (QOU.Mathlib.RothHeightBound), and index_le_of_abs_coeff_le below is §10's estimate itself, stated against index with no logarithm in it: a ≤ H^e gives index ≤ e/d.

    ⚠ The recorded plan was wrong about the method, and cheaply so. It proposed reversing the polynomial (x ↦ x^{deg}·A(1/x)) to swap lowest with highest and κ with 1/κ, reusing the leading-coefficient theorem at the reciprocal point. That works, but it is unnecessary: Polynomial.trailingCoeff is multiplicative in a domain for exactly the reason leadingCoeff is, so the trailing half proves directly, in the same four lines, with no reversal and no reciprocal. The reversal plan came from thinking about the page — where "lowest and highest … respectively" invites a symmetry argument — rather than about the available API.

    ⚠ What the reversal plan did get right is that the halves are not symmetric: q > 0 is free but p ≠ 0 is not, and κ = 0 has to be discharged separately. See RothHeightBound.max_abs_pow_le_max_abs_trailingCoeff_leadingCoeff.

    theorem MvPolynomial.index_le_of_abs_leadingCoeff_le {p q : ℤ} (hq : 2 ≤ q) (hco : IsCoprime p q) {d : ℕ} (hd : d ≠ 0) {P : Polynomial ℤ} (hP : P ≠ 0) (e : ℕ) (hB : |P.leadingCoeff| ≤ q ^ e) :
    index (fun (x : Unit) => d) (fun (x : Unit) => ↑p / ↑q) ((pUnitAlgEquiv ℚ).symm (Polynomial.map (algebraMap ℤ ℚ) P)) ≤ ↑(↑e / ↑d)

    The m = 1 case of Roth's lemma.

    `|lead P| ≤ q^e`,  `q ≥ 2`,  `gcd(p,q) = 1`,  `P ≠ 0`,  `d ≠ 0`
  ⟹  `index_d(P; p/q) ≤ e/d`.

    With Roth's hypothesis H(P) ≤ q^{εd} — so e = εd — this reads index ≤ ε, which is what the induction on the number of variables consumes.

    The proof is by contradiction on the realised index. Because index is an infimum over a finite support, and in one variable every support element is Finsupp.single () n, the index is literally n₀/d for some natural n₀. So e/d < index forces e < n₀, hence (e+1)/d ≤ index, hence q^{e+1} ≤ |lead P| ≤ q^e — impossible for q ≥ 2.

    ⚠ That integrality step is why q ≥ 2 rather than q > 0: with q = 1 the powers do not separate and the argument gives nothing.

    Validation #

    The theorem has six hypotheses; this instantiates all of them and extracts a non-trivial conclusion rather than merely showing they are satisfiable.

    Take P = 1, p/q = 1/2, d = 1, e = 0: then |lead P| = 1 ≤ 2⁰, and the theorem gives index ≤ 0. With index_nonneg that pins the index of a non-zero constant to exactly 0 — the right answer, since a non-zero constant vanishes to order zero everywhere.

    Validation of the H-form — a case the q-form cannot reach #

    index_le_of_abs_leadingCoeff_le needs q ≥ 2; index_le_of_abs_coeff_le needs only max(|p|, |q|) ≥ 2. The gap is exactly the points whose height sits in the numerator, and κ = 3 is the smallest of them: q = 1, so the q-form does not apply at all.

    Take P = X − 3, κ = 3/1, d = 1, e = 1. Then H = 3, every coefficient is at most 3 in absolute value, and 3 ≤ 3¹, so the theorem gives index ≤ 1. That is the true value — X − 3 vanishes to order exactly 1 at 3 — so the bound is attained, not slack.
