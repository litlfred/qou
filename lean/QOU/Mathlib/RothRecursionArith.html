    theorem RothArith.sum_max_sub_ge (θ r : ℚ) (n K : ℕ) (hK : K ≤ n) :
    ↑K * θ - ↑K * (↑K - 1) / (2 * r) ≤ ∑ ν ∈ Finset.range n, max 0 (θ - ↑ν / r)

    The truncated sum bound. For any cut-off K ≤ n, the sum of max 0 (θ − ν/r) over ν < n is at least the untruncated arithmetic progression over ν < K.

    Two slacknesses, both free: the tail K ≤ ν < n is dropped because every term is non-negative, and max 0 x ≥ x is used on the retained terms. No hypothesis relating K to θ or r is needed — the caller chooses K to make the bound sharp.

    theorem RothArith.sq_mul_le_two_mul_of_sum_le {θ r S : ℚ} (hr : 0 < r) (hθ : 0 ≤ θ) {n : ℕ} (hn : θ * r ≤ ↑n) (hS : ∑ ν ∈ Finset.range n, max 0 (θ - ↑ν / r) ≤ S) :
    θ ^ 2 * r ≤ 2 * S

    The quadratic bound — Mahler §13's second case.

    If the truncated sum ∑_{ν<n} max(0, θ − ν/r) is at most S, and there are enough terms (θ·r ≤ n), then

    θ² · r ≤ 2 · S,

    i.e. θ ≤ √(2S/r). Stated squared so that no Real.sqrt is needed and everything stays in ℚ.

    The cut-off is K = ⌈θ·r⌉: it is at most n by hypothesis, at least θ·r by the ceiling property, and at most θ·r + 1 — which is exactly what makes the arithmetic progression's correction term K(K−1)/(2r) at most half of K·θ, leaving K·θ/2 ≥ θ²r/2.

    ⚠ This is the shape a linear combination cannot produce, and its absence is what the sixth correction was detecting.

    theorem RothArith.le_two_mul_div_of_sum_le {θ r S : ℚ} (hr : 0 < r) {n : ℕ} (hn : 0 < n) (hge : (↑n - 1) / r ≤ θ) (hS : ∑ ν ∈ Finset.range n, max 0 (θ - ↑ν / r) ≤ S) :
    θ ≤ 2 * S / ↑n

    Mahler §13, case (1) — the SHARP form.

    When the cut-off falls outside the range ((n−1)/r ≤ θ, so every one of the n terms is unclipped), Gauss's sum eats half of them and the conclusion carries a factor 2/n:

    θ ≤ 2S/n.

    ⚠ The 2/n is the entire content. Dropping it — keeping only the ν = 0 term, which gives θ ≤ S unconditionally — is true but useless in the application, where S is of size n·Φ. 2S/n is then of size Φ, and S is of size n·Φ; the factor separating them is the matrix size. See the ninth correction in QOU/Mathlib/RothInductionStep.lean.

    The sharp form: case 2 kept squared, with no √2 lost.

    le_two_mul_max_of_sum_le below turns case 2's θ²·r ≤ 2S into θ ≤ 2q via S ≤ q²·r, and that step costs a factor √2: what θ² ≤ 2q² gives is θ ≤ √2·q, not θ ≤ 2q.

This arc's module header had recorded "the weakening of √2 to 2" as confirmed against the source; it is the arc's own, and it is avoidable.

The proof is the same as le_two_mul_max_of_sum_le's, stopping one step earlier in each branch.

    theorem RothArith.sq_branch_strictly_sharper :
    ¬(3 / 2) ^ 2 * 1 ≤ 2 * 1 ∧ 3 / 2 ≤ 2 * 1

    ⚠ The sharpening bites. At r = S = 1 the squared branch bounds θ by √2 and the rounded one by 2q = 2. θ = 3/2 lies between them: the rounded branch admits it, the squared branch does not.

    So sq_le_two_mul_max_of_sum_le is strictly stronger than le_two_mul_max_of_sum_le's second case rather than a restatement of it — which is the whole point, since the factor recovered here is the one that separates this arc's constant from §14's.

    theorem RothArith.le_two_mul_max_of_sum_le {θ r S q : ℚ} (hr : 0 < r) (hθ : 0 ≤ θ) (hq0 : 0 ≤ q) (hq : S ≤ q ^ 2 * r) {n : ℕ} (hn : 0 < n) (hS : ∑ ν ∈ Finset.range n, max 0 (θ - ↑ν / r) ≤ S) :
    θ ≤ 2 * max (S / ↑n) q

    Mahler §13, combined — and it needs no side condition.

    θ ≤ 2 · max (S/n, q)        for any `q` with `S ≤ q²·r`.

    The case split is on whether the cut-off θ·r falls inside the range of columns:

    • (n−1)/r ≤ θ — it does not, every column contributes, and le_two_mul_div_of_sum_le gives θ ≤ 2S/n;
    • otherwise θ·r < n−1 ≤ n, which is exactly sq_mul_le_two_mul_of_sum_le's hypothesis, and that gives θ² ≤ 2q² ≤ (2q)², hence θ ≤ 2q.

    ⚠ Note what is absent: no hypothesis relating S, r and n. The two branches are complementary by construction, so the combination is unconditional. An earlier form of this demanded S·r ≤ n in order to force the second branch — see the ninth correction; that condition is both unnecessary and false in the intended regime.

    Non-vacuity #

    Two guards. The first shows the max 0 is load-bearing rather than decorative; the second shows the hypothesis stack of sq_mul_le_two_mul_of_sum_le is satisfiable at a point where the truncation is active.

    source
    theorem RothArith.sum_max_truncation_active :
    ∑ ν ∈ Finset.range 3, max 0 (1 - ↑ν / 1) = 1 ∧ ∑ ν ∈ Finset.range 3, (1 - ↑ν / 1) = 0

    The truncation is doing work. At θ = 1, r = 1, n = 3 the truncated sum is 1 (terms 1, 0, 0) while the untruncated sum ∑ (θ − ν/r) is 0 (terms 1, 0, −1).

    They differ, so no reading of the theorem in which max 0 is dropped is the same theorem — and the untruncated version is the smaller quantity, which is the wrong direction for a lower bound on a sum being estimated from above.
