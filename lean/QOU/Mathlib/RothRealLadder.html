    Roth's Lemma, stated on the index directly #

    RothLemmaTheta speaks of Θ_m; this says what that means for a polynomial and a point.

    source
    theorem MvPolynomial.index_le_rothBound {σ : Type u_1} {m : ℕ} (hm : 1 ≤ m) {p q F : ℕ} (hp : 0 < p) (hpq : p ≤ q) (o : σ ≃ Fin m) {a : ℤ} {r H : σ → ℕ} (hg : RothGammaFull o p q F r (fun (j : σ) => ↑(H j)) a) {A : MvPolynomial σ ℤ} {κ : σ → ℚ} (hA : InRothPolySet a r A) (hκ : InRothFracSet H κ) :
    ∃ (Θ : ℚ), 0 ≤ Θ ∧ Θ ^ 2 ^ (m - 1) ≤ ↑(rothConstant m) ^ 2 ^ (m - 1) * (↑p / ↑q) ∧ index r κ ((map (algebraMap ℤ ℚ)) A) ≤ ↑Θ

    Roth's Lemma (§14). If a; r₁,…,r_m; H₁,…,H_m has property Γ_m with t = p/q, then every A ∈ R(a;r) has index at most c_m·t^{2^{−(m−1)}} at every κ ∈ Q(H), where c_m = 2^{m+1} − 3.

    The conclusion is root-free: Θ^{2^{m−1}} ≤ c_m^{2^{m−1}}·t. ⚠ Θ is existential because it is Θ_m — the bound is uniform over R(a;r) × Q(H), which is stronger than a bound depending on A and κ, and is what §12 invokes when it recurses.

    source
    theorem MvPolynomial.index_le_rothBound_witness :
    ∃ (Θ : ℚ), 0 ≤ Θ ∧ Θ ^ 2 ^ (2 - 1) ≤ ↑(rothConstant 2) ^ 2 ^ (2 - 1) * (1 / 1) ∧ index (fun (x : Fin 2) => 1) (fun (x : Fin 2) => 1024) ((map (algebraMap ℤ ℚ)) 1) ≤ ↑Θ

    Non-vacuity of Roth's Lemma at m = 2 — the arity §13 actually needs (m ≥ 2).

    p = q = 1 (so t = 1), F = 10, d ≡ 1, H ≡ 1024, a = 1, A = 1, κ ≡ 1024.

    ⚠ The heights cannot be small. Clause 3 forces 2^F ≤ K₁ with q·(m−1)m(2m+1) ≤ F·p, so at m = 2 the floor is 2^{10} = 1024. Every other witness in this arc got away with H = 2; this is the one place where clause 3 bites, and exhibiting it is the point — a satisfiability claim about Γ_m that quietly used H = 2 would be about a different hypothesis.

    ⚠ t = 1 makes the bound itself weak (Θ ≤ c₂ = 5). That is a limitation of this witness, not of the theorem: what it establishes is that the hypothesis stack is satisfiable at m ≥ 2, so the theorem is not vacuous where §13 lives.
