    Weierstrass primary factor #

    source
    noncomputable def QOU.Mathlib.HadamardFactorization.weierstrassFactor (p : ℕ) (z : ℂ) :
    ℂ

    The Weierstrass primary factor (elementary factor) of genus p: Eₚ(z) = (1 - z)·exp(∑_{k=1}^{p} z^k / k). Reindexed with k = 0 … p-1 so the summand is z^{k+1}/(k+1). E₀(z) = 1 - z; higher p add the exponential convergence-accelerating factor that makes the canonical product converge.

          The hard analytic core (stated-open, cited sorry) #

          source
          theorem QOU.Mathlib.HadamardFactorization.norm_one_sub_weierstrassFactor_le (p : ℕ) {z : ℂ} (hz : ‖z‖ ≤ 1) :
          ‖1 - weierstrassFactor p z‖ ≤ ‖z‖ ^ (p + 1)

          Weierstrass estimate (convergence-critical, PI-2). For ‖z‖ ≤ 1, ‖1 - Eₚ(z)‖ ≤ ‖z‖^{p+1}. This is the bound that makes the canonical product converge.

          PROVED (2026-08-07), sorry-free, in QOU.Mathlib.WeierstrassFactorEstimate.

          Not by the textbook route. Ahlfors/Conway argue from the nonneg-coefficient power series Eₚ(z) = 1 - ∑_{k>p} a_k z^k, which needs real power-series machinery. The proof used instead runs through the derivative identity Eₚ'(z) = -z^p·exp(Sₚ(z)) — the telescoping (1-z)∑_{k<p} z^k = 1 - z^p kills the -1 — giving 1 - Eₚ(z) = ∫₀¹ z^{p+1} t^p exp(Sₚ(tz)) dt. The constant is exactly 1 because that integral's real total mass is 1 - Eₚ(1) = 1 on the nose; the crude bound exp(H_p)/(p+1) exceeds 1 for every p ≥ 1 and would not suffice.

          The ℕ-indexed statement was FALSE — refuted, then repaired #

          An earlier version of hadamard_factorization enumerated the zeros as a : ℕ → ℂ with ∀ n, f (a n) = 0. That is not merely hard to prove; it is false, and the two theorems below are a sorry-free refutation.

          Complex.exp has order 1 and exp 0 = 1 ≠ 0, so it satisfies every hypothesis — but it has NO zeros at all, so no a : ℕ → ℂ can satisfy ∀ n, f (a n) = 0. A ℕ-indexed enumeration cannot express "finitely many zeros", let alone none. The sorry on that statement could never have been closed; it could only ever have been used to derive anything at all.

          The repair existentially quantifies the index type, so ι = Empty covers the zero-free case. hadamard_factorization_statement_satisfiable_for_exp checks that the repaired statement really is satisfiable in exactly the case that refuted the old one — a regression test, not a restatement.

          theorem QOU.Mathlib.HadamardFactorization.hadamard_factorization_needs_nonneg_order :
          ¬∀ (f : ℂ → ℂ) (ρ : ℝ), IsEntireOfOrderLE f ρ → f 0 ≠ 0 → ∃ (p : ℕ) (g : Polynomial ℂ) (ι : Type) (_ : Countable ι) (a : ι → ℂ), ↑p ≤ ρ ∧ ↑g.natDegree ≤ ρ ∧ (∀ (i : ι), a i ≠ 0) ∧ (∀ (i : ι), f (a i) = 0) ∧ ∀ (z : ℂ), (Multipliable fun (i : ι) => weierstrassFactor p (z / a i)) ∧ f z = Complex.exp (Polynomial.eval z g) * ∏' (i : ι), weierstrassFactor p (z / a i)

          The 0 ≤ ρ hypothesis of hadamard_factorization is necessary — without it the statement is FALSE (machine-proved, no sorry).

          IsEntireOfOrderLE f ρ is satisfiable at negative ρ: for ρ < 0 the exponent ‖z‖^ρ is bounded above on ‖z‖ ≥ 1 and Mathlib's rpow sends 0 ^ ρ to 0, so the constant function 1 satisfies it with A = C = 1. But the conclusion demands (p : ℝ) ≤ ρ for a natural number p, and (p : ℝ) ≥ 0 > ρ. So the existential cannot be met.

          Classically the order of a nonzero entire function is ≥ 0 by construction, which is why the hypothesis is invisible in the textbooks; here the predicate takes ρ as an input, so it has to be said. Same for (g.natDegree : ℝ) ≤ ρ. Axioms [propext, Classical.choice, Quot.sound].

          class QOU.Mathlib.HadamardFactorization.HasHadamardFactorization :
          Prop

          Hadamard factorization theorem (the stated-open core, PI-5). An entire function f of finite order ρ with f(0) ≠ 0 factors as f(z) = exp(g(z)) · ∏ₙ Eₚ(z/aₙ), where (aₙ) enumerates the zeros of f (with multiplicity), the genus p ≤ ρ, and g is a polynomial of degree ≤ ρ. The canonical product converges. This is the theorem that pins the minimal Faddeev solution phiBProd among all phiBProd·(elliptic) multiples (epic qou-lbth). Mathlib v4.24.0 lacks it; the proof needs Jensen's formula, zero-counting, and the Weierstrass/Borel–Carathéodory growth machinery.

          NOTE (honest, non-vacuous): the product equation f z = exp(g z)·∏ₙ Eₚ(z/aₙ) already forces each aₙ to be a zero of f (via weierstrassFactor_eq_zero_iff) and forces completeness of the zero enumeration (no other zeros on either side), so the theorem is stated in full strength, not weakened.

          NOTE (0 ≤ ρ): IsEntireOfOrderLE takes ρ as an input and is satisfiable at negative ρ (the constant 1), where (p : ℝ) ≤ ρ is unsatisfiable for p : ℕ. Without the hypothesis the statement is false — hadamard_factorization_needs_nonneg_order proves it. The classical theorem hides this because the order of a nonzero entire function is ≥ 0 by construction.
