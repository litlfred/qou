    theorem MvPolynomial.le_index_rational_of_taylor_witness :
    ↑(1 / 2) ≤ index (fun (x : Fin 1) => 1) (fun (x : Fin 1) => ↑0 / ↑1) ((map (Int.castRingHom ℚ)) (X 0))

    The hypothesis bundle is satisfiable and the conclusion is not vacuous.

    Twelve hypotheses, several of them inequalities between constructed quantities, is exactly the shape in which a theorem can be true because nothing satisfies it. This discharges every one of them at m = 1, r = (1), P = x, α = 0, p/q = 0/1, K = 8, μ = 1, ν = ½, where hfinal comes down to 16·e^{−4} < 1.

    ⚠ What it does not show: γ = β − α is 0 here, so the Taylor machinery is not exercised. A witness with γ ≠ 0 is not available at small m: the constants (box)²·H·(2B)^{Σr}·2^{Σr} only fall below ∏ q_h^{−r_h} when m is large and the approximation exceptionally good, which is Roth's inequality itself and hence step 4's business. Recorded rather than papered over.
