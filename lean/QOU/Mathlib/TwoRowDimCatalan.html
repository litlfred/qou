    QOU.Mathlib.TwoRowDimCatalan — two-row Specht dimensions square-sum to catalan n #

    This file joins the two halves of the general-n corank statement, which were already in the corpus but had never been put together:

    • SYTHookRows.dimHLF_pair — the two-row hook-length dimension is the ballot number, dimHLF [a,b] = C(a+b,b) − C(a+b,b−1), sorry-free.
    • BallotNumbers.ballot_sq_sum_catalan — the ballot numbers square-sum to catalan n, sorry-free, general n.

    Composing them gives

    Σ_{k ≤ ⌊n/2⌋} (dim S^{(n−k,k)})² = catalan n                (`dimHLF_two_row_sq_sum`)

    a statement about actual standard-Young-tableau counts, not about binomial coefficients. That is the form the Wedderburn accounting needs.

    Why this is the load-bearing step for corank(n) = n! − catalan n #

    The Markov-trace Gram form is diagonal in the Wedderburn basis with entries proportional to y_λ, so its corank is n! minus the sum of (dim V_λ)² over the blocks the trace can see. Under convention D the visible blocks are exactly the partitions with ℓ(λ) ≤ 2 (Wenzl level r = 2), whose dimensions are the two-row Specht dimensions counted above. So

    dim radical = n! − Σ_{ℓ(λ) ≤ 2} (dim V_λ)² = n! − catalan n

    for every n, superseding the four measured values n = 3,4,5,6 → 1, 10, 78, 588 (computations/probes/tl_n6_discriminator.py).

    What is and is not proved here — read before citing #

    Everything in this file is unconditional: #print axioms gives [propext, Classical.choice, Quot.sound] on every declaration, with no sorryAx.

    The arithmetic — that the two-row square-sum is catalan n — is therefore settled for all n. What is not settled here, and is not claimed, is the identification of the visible blocks with ℓ(λ) ≤ 2: that rests on the Wenzl weight system, which the corpus carries as a Lean class rather than a proof (QOU.QBeta.WenzlWeight.IsOcneanuWeightSystem, the _of_wenzl naming convention). Per bean qou-fpjy a class hypothesis is a binder, not an axiom, so #print axioms cannot see that dependency — a conditional declaration and an unconditional one produce identical axiom reports. Do not read a clean axiom report on a _of_wenzl declaration as evidence that Wenzl is proved.

    Numerical cross-check of the whole reduction (hook length formula against full partition enumeration, n ≤ 14): computations/probes/two_row_ballot_catalan_reduction.py.

    theorem QOU.Mathlib.dimHLF_two_row_eq_ballot (n k : ℕ) (hk : 2 * k ≤ n) :
    ↑(BraidKnot.IdentityI.dimHLF [n - k, k]) = ballot n k

    The two-row hook-length dimension is the ballot number, in ballot's indexing: dim S^{(n−k,k)} = m_k(n) whenever 2k ≤ n.

    dimHLF_pair already says this as a ℕ difference of binomials; the work here is the cast to ℤ, which needs C(n,k−1) ≤ C(n,k) so that the truncated ℕ subtraction agrees with the honest ℤ one. That monotonicity holds precisely below the centre of the row, i.e. exactly under the hypothesis 2k ≤ n that makes (n−k, k) a partition — so the side condition is not an artefact, it is the same condition twice.

    The k = 0 case is separate because m_0 is pinned rather than computed (see ballot); there the shape is (n) with an empty second row and dimHLF_zero_row gives 1.

    theorem QOU.Mathlib.dimHLF_two_row_sq_sum (n : ℕ) :
    ∑ k ∈ Finset.range (n / 2 + 1), ↑(BraidKnot.IdentityI.dimHLF [n - k, k]) ^ 2 = ↑(catalan n)

    Σ_{k ≤ ⌊n/2⌋} (dim S^{(n−k,k)})² = catalan n.

    The sum of squared dimensions over all partitions of n with at most two rows is the n-th Catalan number — for every n, with the dimensions given by the Frame–Robinson–Thrall hook length formula rather than by a closed form assumed in advance.

    Equivalently, by RSK, 321-avoiding permutations of n are counted by C_n; but the proof goes nowhere near RSK — see BallotNumbers.ballot_sq_sum_catalan for the reflection-plus-Vandermonde argument that replaces it.

    theorem QOU.Mathlib.factorial_sub_two_row_sq_sum (n : ℕ) :
    ↑n.factorial - ∑ k ∈ Finset.range (n / 2 + 1), ↑(BraidKnot.IdentityI.dimHLF [n - k, k]) ^ 2 = ↑n.factorial - ↑(catalan n)

    The general-n rank accounting: n! minus the visible-block dimension count is n! − catalan n.

    This is the arithmetic identity that QOU.QBeta.MarkovGramDegenerate.corank_three / _four / _five were three hand-computed instances of. Those wrote the two-row dimensions out by hand (1, 2 / 1, 3, 2 / 1, 4, 5); this derives the whole count from catalan n with nothing listed by hand.

    The measured values, as instances of the general theorem #

    n = 3, 4, 5, 6 are the values computations/probes/tl_n6_discriminator.py measured as Gram coranks (1, 10, 78, 588). n = 7, 8 are stated here as arithmetic predictions — the numbers a rank measurement at those levels would have to produce. They are not themselves rank measurements, and nothing below claims otherwise.
