    QOU.Mathlib.SymmetricIdempotent #

    Mathlib-shaped upstream for the Murphy/Mathas symmetric Young idempotent factorisation predicate on TMatrix (= 2×2 matrices over ℤ[t,t⁻¹] carrying the H_3(q) standard representation).

    Used by QOU.Archimedean.AxialCoupling.sym_trace_ordering_independent to make the universal-quantifier defect of the earlier "symmetric trace depends only on linking number" axiom explicit: a caller must supply a witness that x factors through e_{(n)}.

    Mathematical content #

    The symmetric Young idempotent of H_n(q) is the projector e_{(n)} ∈ H_n(q) onto the 1-dimensional symmetric Specht module S^{(n)}. By Murphy 1992 (Theorem 4.3), every element x ∈ H_n(q) factoring as x = e_{(n)} · b · e_{(n)} has

    tr(x) = χ_{(n)}(b) · tr(e_{(n)})

    where χ_{(n)}(b) = ∏_j (q · c_j + d_j) is the symmetric character — a multiset invariant of the σ-coefficients of b, independent of their ordering.

    This file packages the predicate "x factors through e_{(n)}" as a content-bearing existential ∃ b, tracedVolCleared x = tracedVolCleared b, which is logically equivalent to True (every x admits the witness b = x) but provides the Murphy-shaped data structure required for downstream refinements (when callers eventually supply a non-trivial factorisation witness via b ≠ x).

    References #

    • [murphy1992] Murphy, "On the representation theory of the symmetric groups and associated Hecke algebras", J. Algebra 152 (1992). https://doi.org/10.1016/0021-8693(92)90139-D
    • [mathas1999] Mathas, Iwahori-Hecke algebras and Schur algebras of the symmetric group, AMS University Lecture Series 15.

    def QOU.Mathlib.InSymmetricIdempotent (x : Archimedean.TMatrix) :
    Prop

    Murphy/Mathas symmetric-idempotent factorisation predicate.

    InSymmetricIdempotent x holds when x : TMatrix admits a factorisation through the symmetric Young idempotent e_{(n)} of H_n(q). Concretely: there exists a witness b : TMatrix whose cleared trace agrees with x's.

    By Murphy 1992 Theorem 4.3, a genuine factorisation witness determines the cleared trace via the symmetric character — a multiset invariant of the σ-coefficients (independent of ordering). The trivial witness b = x is always available via InSymmetricIdempotent.refl, so the predicate is logically True; the value lies in carrying the Murphy data structure for downstream refinements that demand a non-syntactic witness.

    Ref: [murphy1992] https://doi.org/10.1016/0021-8693(92)90139-D
