    QOU.Mathlib.SYTBranchingBijection — the deletion/insertion maps are mutually inverse #

    eraseMax (delete the max-value corner) and insertMax (re-insert |μ| at a corner) are mutually inverse. Together with the structural counting bridge this is the Greene–Nijenhuis–Wilf branching bijection StandardYoungTableau μ ≃ ⨆_{corners c} StandardYoungTableau (μ ∖ c).

    Pure combinatorics; nothing archimedean; no fit.

    source
    theorem QOU.Mathlib.syt_ext {μ : YoungDiagram} {T1 T2 : StandardYoungTableau μ} (h : ∀ (i j : ℕ), T1.entry i j = T2.entry i j) :
    T1 = T2

    Two standard tableaux of the same shape are equal when their entry maps agree (bijOn is a Prop, hence proof-irrelevant).

    source
    theorem QOU.Mathlib.insertMax_eraseMax {μ : YoungDiagram} (T : StandardYoungTableau μ) (c : ℕ × ℕ) (hc : IsCornerCell μ c) (hmax : T.entry c.1 c.2 = μ.cells.card) :
    insertMax c hc (eraseMax T c hc hmax) = T

    Roundtrip 1. Deleting the max corner and re-inserting |μ| recovers T.

    theorem QOU.Mathlib.entry_insertMax_corner {μ : YoungDiagram} (c : ℕ × ℕ) (hc : IsCornerCell μ c) (S : StandardYoungTableau (eraseCorner μ c hc)) :
    (insertMax c hc S).entry c.1 c.2 = μ.cells.card

    The re-inserted tableau carries |μ| at the corner (so it has a max corner there).

    theorem QOU.Mathlib.eraseMax_insertMax {μ : YoungDiagram} (c : ℕ × ℕ) (hc : IsCornerCell μ c) (S : StandardYoungTableau (eraseCorner μ c hc)) :
    eraseMax (insertMax c hc S) c hc ⋯ = S

    Roundtrip 2. Re-inserting |μ| at c and deleting that corner recovers S.
