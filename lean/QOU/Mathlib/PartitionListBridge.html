    QOU.Mathlib.PartitionListBridge — Nat.Partition n ↔ the weakly-decreasing List ℕ model #

    The Identity I combinatorics (QOU.BraidKnot.IdentityI, the keystone W_λ defect input) is developed over a computable model of a partition: a weakly-decreasing List ℕ of positive parts summing to n (so decide can run over allPartsLE9 etc.). Mathlib's abstract index for the same object is Nat.Partition n (a Multiset ℕ of positive parts with parts_sum = n).

    The general-n discharge of Identity I's two PlancherelSnData axioms (the docs/scope/2026-06-24-identity-i-plancherel-snrep-infra-program.md program, phase P5) must bridge these two indices — e.g. to push the RSKBridge/regular-representation ∑_{Λ : Nat.Partition n} dim(Λ)² = n! (axiom (i)) onto the List ℕ-model dimHLF the per-n instances use, and to range an abstract ∑_{Λ} over the concrete sorted lists.

    P5 landed 2026-08-23. Both axioms are now discharged at every n by QOU.BraidKnot.PlancherelSnDataGeneral.plancherelSnDataGeneral, which uses this file's sum transport for axiom (i) and ContentSqSumBridge.contentSqSum_ofRowLens for axiom (ii). The paragraph above describes what the bridge is for; it is no longer a statement of open work.

    This file builds that bridge sorry-free, over core Mathlib only (no representation theory, no hook-length formula — those are the genuinely Mathlib-absent pieces of the program):

    • toList — Nat.Partition n → List ℕ, the parts sorted weakly-decreasing;
    • toList_sorted / toList_pos / toList_sum / toList_coe — it lands in the model;
    • ofList — the inverse on a valid (sorted-or-not, positive, size-n) list;
    • equivSortedList — the resulting Equiv Nat.Partition n ≃ {l // weakly-decreasing ∧ pos ∧ sum = n}.

    Base ring is irrelevant (pure combinatorics on ℕ); nothing archimedean.

          Sum transport — the operation a general-n PlancherelSnData instance needs #

          To discharge the Identity I axiom (i) ∑_λ dim(λ)² = n! for general n from a single shared abstract source (the RSKBridge Burnside identity over Nat.Partition n), one needs to move a sum between the two indices. toList is injective, so a sum over the sorted-list model Finset.univ.image toList equals the abstract sum ∑_{Λ : Nat.Partition n}. Setting g l = (dim l)² then turns a model-side sum_dim_sq into the abstract Burnside sum, and vice versa — exactly the bridge step P5 calls for.
