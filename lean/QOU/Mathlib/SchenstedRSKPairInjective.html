    QOU.Mathlib.SchenstedRSKPairInjective — rskPair is injective #

    Brick 39 of epic qou-nrex (RSK inverse).

    SchenstedRSKInjective proves the RSK map injective on words: the pair (P(w), Q(w)) of list tableaux determines w. rskPair is stated on permutations, and its value is a Σ of Mathlib standard Young tableaux. This file bridges that mismatch, which is the whole distance between the two statements.

    The bridge needs no HEq and no subst, and that is the point worth recording. Extracting the second component of a Σ-equality normally needs a transport, because its type depends on the first. But fun X => X.2.1.entry i j is a perfectly good non-dependent function on the Σ type — a dependent projection followed by an ℕ-valued field — so congrArg hands over entry equalities directly.

    From there it is ordinary list combinatorics: eq_of_shape_and_entries turns "same shape, same entries" into equality of list tableaux, shiftT_injective strips the 0→1 relabel, and word_eq_of_insertWordRec_eq (the existing word-level injectivity) finishes. wordOfPerm_injective takes the last step back to permutations.

    Scope #

    Injectivity. Together with brick 38 this is a bijection in substance, but the Equiv itself — and RSKBurnsideHolds for general n past it — is not assembled here. RSKBurnsideHolds remains proved only for n ≤ 12, by a route with no RSK correspondence in it.

    Pure combinatorics on ℕ; nothing archimedean; no fit.

    Scope note superseded (2026-08-23). The scope paragraph above records the state of the arc when this brick landed. RSKBurnsideHolds is now proved for every n (QOU.Mathlib.rskBurnsideHolds, brick 42), and SnIsotypicSpechtSplit is inhabited, so any statement here that they "remain open" or hold "only for n ≤ 12" describes history rather than the corpus.
