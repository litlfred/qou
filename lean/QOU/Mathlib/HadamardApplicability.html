    theorem QOU.Mathlib.HadamardApplicability.denFactor_eq_zero {b : ℂ} (hb : b ≠ 0) :
    MathlibExt.PhiBProd.denFactor b (Complex.I * b / 2 * (1 + 1 / b ^ 2)) 0 = 0

    The k = 0 denominator factor of the modular-double product vanishes at an explicit point, for every b ≠ 0.

    phiBProd is defined as a quotient by ∏' k, denFactor b z k, so this is the obstruction to phiBProd being entire — see the module docstring for exactly what is and is not concluded from it.

    theorem QOU.Mathlib.HadamardApplicability.denFactor_eq_zero_shift {b : ℂ} (hb : b ≠ 0) (m : ℤ) :
    MathlibExt.PhiBProd.denFactor b (Complex.I * b / 2 * (1 + 1 / b ^ 2) + ↑m * Complex.I * b) 0 = 0

    The vanishing point is not a single accident: shifting z by any multiple of i b along the dual period keeps the k = 0 factor at zero, so the obstruction recurs.

    The repair: each HALF is entire, so Hadamard applies to the halves #

    The obstruction above is to phiBProd — the quotient. It is not an obstruction to the numerator or the denominator, each of which is a product of entire factors. This section proves that, so the reformulation is available rather than merely asserted.

    theorem QOU.Mathlib.HadamardApplicability.differentiable_tprod_one_add {f : ℕ → ℂ → ℂ} (hf : ∀ (n : ℕ), Differentiable ℂ (f n)) (hdom : ∀ (R : ℝ), 0 < R → ∃ (u : ℕ → ℝ), Summable u ∧ ∀ᶠ (n : ℕ) in Filter.atTop, ∀ z ∈ Metric.ball 0 R, ‖f n z‖ ≤ u n) :
    Differentiable ℂ fun (z : ℂ) => ∏' (n : ℕ), (1 + f n z)

    If every f n is entire and the family is dominated by a summable sequence on every ball, then z ↦ ∏' n, (1 + f n z) is entire.

    The general fact behind the repair. Mathlib supplies locally uniform multipliability from a summable dominant (Summable.hasProdLocallyUniformlyOn_nat_one_add) and holomorphy of locally uniform limits (TendstoLocallyUniformlyOn.differentiableOn); this stitches them and passes from "on every ball" to entire, differentiability being local.

    Differentiable ℂ fun (z : ℂ) => ∏' (k : ℕ), MathlibExt.PhiBProd.numFactor b z k

    The numerator half of the modular-double product is entire.

    The domination hypothesis is carried EXPLICITLY, matching PhiBProd's own stated discipline: that file carries its Multipliable inputs as named hypotheses rather than discharging them, because they are the analytic convergence facts (geometric bounds for Im b² > 0). Same input, same treatment — the point here is the STRUCTURAL claim that the numerator is entire GIVEN convergence, which is what the ratio is not.
