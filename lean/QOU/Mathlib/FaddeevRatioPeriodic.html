    1. The prefactor cancels: hper is algebra off the prefactor zeros #

    source
    theorem QOU.Mathlib.FaddeevRatioPeriodic.ratio_shift_b {b : ℂ} {Φ Ψ : ℂ → ℂ} (hΦ : MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi b Φ) (hΨ : MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi b Ψ) (z : ℂ) (hA : 1 + Complex.exp (2 * ↑Real.pi * b * z) ≠ 0) :
    Ψ (z - Complex.I * (b / 2)) / Φ (z - Complex.I * (b / 2)) = Ψ (z + Complex.I * (b / 2)) / Φ (z + Complex.I * (b / 2))

    The ratio of two FaddeevPhi b solutions is invariant under the compact ib-shift wherever the shared prefactor is nonzero.

    The whole content is that both shift equations carry the SAME prefactor, so it cancels from the ratio. Note this needs nothing about the zeros of Φ: at a point where Φ vanishes both sides are 0, and mul_div_mul_left covers it.

    2. The prefactor zero sets are nowhere dense #

    source
    theorem QOU.Mathlib.FaddeevRatioPeriodic.dense_compl_zeros {g : ℂ → ℂ} (hg : Differentiable ℂ g) {z₀ : ℂ} (hz₀ : g z₀ ≠ 0) :
    Dense {z : ℂ | g z = 0}ᶜ

    An entire g that is nonzero somewhere has a zero set with DENSE COMPLEMENT.

    Identity theorem: if the zero set had interior, g would vanish on a neighbourhood, hence identically on the (preconnected) plane.

    3. hibinv follows from hratio #

    source
    theorem QOU.Mathlib.FaddeevRatioPeriodic.periodic_b_of_continuous {b : ℂ} {Φ Ψ : ℂ → ℂ} (hΦ : MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi b Φ) (hΨ : MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi b Ψ) (hcont : Continuous fun (z : ℂ) => Ψ z / Φ z) (w : ℂ) :
    Ψ (w - Complex.I * b) / Φ (w - Complex.I * b) = Ψ w / Φ w

    Given that the ratio is entire, ib-periodicity holds EVERYWHERE.

    The algebra gives it off the prefactor zeros; those are nowhere dense; a continuous function is determined by its values on a dense set. So the open input hibinv (bean qou-rp5f) is not independent of hratio (bean qou-cons) — it follows from it.
