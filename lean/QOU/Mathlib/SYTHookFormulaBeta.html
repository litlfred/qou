    QOU.Mathlib.SYTHookFormulaBeta — the per-row Frame–Robinson–Thrall hook product #

    This file proves, in full generality and sorry-free, the per-row hook-product identity that the beta-number form of the Frame–Robinson–Thrall hook-length formula rests on. It is self-contained combinatorics on ℕ — it does not import the heavy IdentityIContentDecomposition substrate; the wiring of these lemmas to the corpus prodHooks lives in a companion file.

    The per-row hook product #

    For a weakly-decreasing partition l, the hook of cell (i,j) (0-indexed, j < l[i]) is h(i,j) = (l[i] − j) + (colLen j − i) − 1. Because every row 0,…,i is at least as long as row i (l[r] ≥ l[i] > j), the leg simplifies to colLen j − 1 − i = #{r > i : l[r] > j} — it depends only on the tail t = l[i+1:] (with every part ≤ l[i]). So row i's hook product is

    rowHookProd a t = ∏_{j < a} ((a − j) + #{p ∈ t : p > j}),   a = l[i], t = l[i+1:].

    rowHookProd satisfies the divisor-free recursion

    • rowHookProd a [] = a! (rowHookProd_nil)
    • rowHookProd a (c :: r) · (a + 1 − c) = rowHookProd (a+1) r (rowHookProd_cons_mul)

    (for c ≤ a and r weakly-decreasing with max r ≤ c). Iterating gives the closed form

    rowHookProd a t · D a t = (a + |t|)!,    D a [] = 1,  D a (c::r) = (a+1−c) · D (a+1) r,

    which is the per-row Frame–Robinson–Thrall hook product ∏_c h(i,c) = β_i! / ∏_{j>i}(β_i − β_j) in divisor-free form (β_i = l[i] + (k−1−i); D a t = ∏_{j>i}(β_i − β_j)). Pure ℕ combinatorics; nothing archimedean; no fit.
