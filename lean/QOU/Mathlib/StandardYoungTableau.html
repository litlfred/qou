    QOU.Mathlib.StandardYoungTableau — the standard Young tableau type Mathlib lacks #

    Mathlib's Combinatorics.Young provides YoungDiagram and SemistandardYoungTableau (weakly increasing along rows, strictly increasing down columns, zero off the diagram) but no standard Young tableau type and no #SYT(λ) count — and no Combinatorics.RSK at the pinned toolchain (recon 2026-06-26, see docs/scope/2026-06-24-identity-i-plancherel-snrep-infra-program.md).

    Both the Identity I axiom (i) ∑_λ #SYT(λ)² = n! (RSK / Burnside) and the hook-length formula dim(λ) = n!/∏h_c need an honest #SYT(λ). This file builds the minimal standard-tableau type those need, as a refinement of Mathlib's SemistandardYoungTableau:

    A standard Young tableau of shape μ (with n = |μ| cells) is a semistandard tableau whose entry map is a bijection from the cells of μ onto {1, …, n}.

    Weak rows (SSYT) + the bijection's injectivity give the usual strict rows (row_strict). The count is numStandardYoungTableaux μ := Nat.card (StandardYoungTableau μ) (Nat.card is total — no Fintype instance is needed to define the count; finiteness + the closed-form value are the tracked next steps toward RSK/HLF).

    Scope (per the program's Decision 1). This is a minimal in-repo SYT, deliberately built only as far as the Identity I axioms need; Specht modules / RSK / HLF are natural Mathlib-upstream contributions and are flagged as such. Pure combinatorics on ℕ; nothing archimedean.

        theorem QOU.Mathlib.StandardYoungTableau.row_strict {μ : YoungDiagram} (T : StandardYoungTableau μ) {i j1 j2 : ℕ} (hlt : j1 < j2) (hcell : (i, j2) ∈ μ) :

        Rows are strictly increasing — not merely weakly, as for a general semistandard tableau. On a row, the SSYT weak-row inequality together with injectivity of the (bijective) filling forces strictness. This certifies the type is the genuine standard-tableau notion, not a vacuous wrapper.
