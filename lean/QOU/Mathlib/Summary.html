    QOU.Mathlib.Summary — capstone import + master discharge #

    Capstone file importing the full upstream QOU.Mathlib.* infrastructure and providing a master discharge theorem packaging everything into a single downstream-consumable handle.

    Use case: Downstream files needing the upstream substrate-axiom layer discharged need only

    import QOU.Mathlib.Summary open QOU.Mathlib.Summary

    and then consume MasterUpstream.complete to get the aggregate result.

The declaration at QOU/Mathlib/SpectralSequence.lean is a def, not an instance, and its docstring says so in terms — "that is exactly why this is a def and not an instance … it must now be supplied by hand, so a reader of a downstream theorem can see whether the hypothesis was discharged by a real filtration or by PUnit." The proof term below is the demonstration: the GBFiltrationCollapsesAtE2 conjunct is discharged by ⟨canonicalTrivial R⟩, applied explicitly, while the WedderburnIsomorphism conjunct beside it still uses inferInstance because that one has a genuine instance.

    So [GBFiltrationCollapsesAtE2 R] is not free, and a downstream theorem taking it is a real §3b-cond conditional. The stale reading is worse than merely out of date: it tells a reader that live conditional results are unconditional-and-vacuous, which invites deleting or weakening them.
