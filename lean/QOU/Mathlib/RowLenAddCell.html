    QOU.Mathlib.RowLenAddCell — row lengths under addCell, and rowLens past its end #

    Two small facts the general-r branching assembly needs, both about shape rather than about weights.
    eq_of_lt_iff_lt two naturals with the same <-downset are equal
    rowLen_addCell rowLen (addCell μ s) i = rowLen μ i + [i = s₁]
    getD_rowLens μ.rowLens.getD i 0 = μ.rowLen i for every i, not only i < |rowLens|

    getD_rowLens is the one that is easy to get wrong: past the end of the list getD returns the default 0, and rowLen returns 0 too, so the identity holds unconditionally — but only because rowLens has exactly colLen 0 entries, which is what rowLen_eq_zero_of_colLen_le supplies. It is what lets the List-indexed hook side and the range r-indexed content side be compared without a side condition on i.

    rowLen_addCell is the β ↦ β + e_a step: adding a box at s raises row s₁'s length by one and leaves every other row alone, hence raises β_{s₁} by one and fixes the rest — which is exactly the single-node update VandermondeUpdateRatio is about.
