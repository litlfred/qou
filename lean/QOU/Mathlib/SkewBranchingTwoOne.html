    QOU.Mathlib.SkewBranchingTwoOne — RSKIdentitiesContext is inhabited #

    QOU/BraidKnot/YoungTableauStandard.lean states

    3 · ∑_{λ ⊢ k}  f^λ · f^{λ/(2,1)}  =  k!        (k ≥ 3)

    as branching_two_one, conditional on the [RSKIdentitiesContext] class, and records that no instance of that class exists in this corpus — so neither it nor c8_superexp, which inherits the same hypothesis, could be applied at any concrete k.

    This file supplies the instance. It is the general branching sum factorial_mul_skewPair_of_le at μ = (2,1), where |μ| = 3 and f^{(2,1)} = 2:

    3! · G((2,1), k) = k! · 2     ⟹     3 · G((2,1), k) = k!.

    Not RSK #

    The file header of YoungTableauStandard says this identity "requires massive infrastructure (the RSK correspondence and hook-length formula)". The route taken here uses neither. It is the same lesson its sibling sum_dimSYT_eq_involution already recorded: Young's lattice is a 1-differential poset, and the up-operator identity (QOU.Mathlib.upSum_eq) plus the skew branching rule (fDimSkew_branching) give the whole family by finite combinatorics on YoungDiagram — no insertion, no bumping, no permutation ↔ tableau-pair bijection.

    The one ingredient taken off the shelf is the single number f^{(2,1)} = 2, via the decide-verified small-n hook-length bridge numStandardYoungTableaux_eq_dimHLF_le4. That is a computation on one three-cell shape, not the hook-length formula as a general theorem.

    Pure combinatorics; nothing archimedean (§7c); no fit.
