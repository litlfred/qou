    QOU.Mathlib.SchenstedRSKEquiv — the Robinson–Schensted correspondence as an Equiv #

    Brick 40 of epic qou-nrex (RSK inverse).

    Bricks 38 and 39 give surjectivity and injectivity of rskPair. This packages them:

    rskEquiv n : Equiv.Perm (Fin n) ≃ {X : Σ μ, SYT μ × SYT μ // X.1.cells.card = n}

    The subtype is forced. rskPair lands in the Σ over all Young diagrams, but its image is exactly the diagrams with n cells — rskPair_card, which reads off recordingCells_card through recordingShape_eq_pShape. Cutting the codomain down to that subtype is what makes the map a bijection rather than merely injective.

    Surjectivity needs one small restatement: brick 38 produces a permutation of Fin |μ|, and the subtype's index is n. exists_rskPair_eq_of_card substitutes the cardinality hypothesis, which is legitimate here precisely because n is a variable — the same move that was unavailable in brick 35, where the diagram equality had no variable side and ofRowLens_congr had to be proved instead.

    Scope #

    The correspondence, as a bijection. Not RSKBurnsideHolds. That identity is indexed by Nat.Partition n, so getting to it from here needs a further count: Nat.card {X // X.1.cells.card = n} = ∑ p : Nat.Partition n, (dimSYT p)^2, which in turn needs partitionShape to be a bijection onto the Young diagrams with n cells. None of that is done here, and RSKBurnsideHolds for general n remains proved only for n ≤ 12, by rskBurnsideHolds_le12 — a route with no RSK correspondence in it.

    Pure combinatorics on ℕ; nothing archimedean; no fit.

    Scope note superseded (2026-08-23). The scope paragraph above records the state of the arc when this brick landed. RSKBurnsideHolds is now proved for every n (QOU.Mathlib.rskBurnsideHolds, brick 42), and SnIsotypicSpechtSplit is inhabited, so any statement here that they "remain open" or hold "only for n ≤ 12" describes history rather than the corpus. The per-brick scope is otherwise unchanged and still accurate.
