    State of the beta-number route (this PR) #

    The classical beta-number proof factors HLF as two identities (β_i = l[i] + (k−1−i)):

    • (i) hook side — ∏_c h_λ(c) = (∏_i β_i!) / ∏_{i<j}(β_i − β_j). CLOSED, sorry-free, general n in SYTHookFormulaBetaProd (prodHooks_mul_betaGapProd): in divisor-free form

      prodHooks l · betaProdGap l = betaFactProd l,

      where betaProdGap l = ∏_i betaGapProd (l[i]) (l.drop (i+1)) = ∏_{i<j}(β_i − β_j) (the Vandermonde) and betaFactProd l = ∏_i (l[i] + (l.drop (i+1)).length)! = ∏_i β_i!.

    • (ii) dimension side — #SYT(λ) = n! · ∏_{i<j}(β_i − β_j) / ∏_i β_i! (Aitken / Frobenius determinant = Vandermonde / ∏β_i!). In divisor-free form

      numSYTenum l · betaFactProd l = (sz l)! · betaProdGap l.        (`dimAitkenIdentity`)

      Once the residual gap — the Aitken/Frobenius determinant evaluation, for which the pinned Mathlib has no Combinatorics.RSK/Specht/Frobenius-determinant infrastructure — it is now proved sorry-free via the Greene–Nijenhuis–Wilf corner recursion (no determinant infrastructure at all).
