    QOU.Mathlib.SchenstedReverseRow — reverse row insertion (the RSK inverse, brick 1) #

    The Schensted programme has built the forward map as far as SchenstedPairingMap.rskPair : Equiv.Perm (Fin n) → Σ_λ SYT(λ) × SYT(λ). What its own roadmap names next is the inverse — reverse bumping — and that is what this file starts, mirroring SchenstedInsertion's brick 1 on the other side.

    Why the inverse and not injectivity of the forward map. Injectivity of rskPair would give n! ≤ Σ_λ (f^λ)², and that inequality is already available by a completely different route: BraidKnot.SpechtActionInjective.factorial_le_sum_sq, from injectivity of the Specht action map. The two programmes deliver the same direction. What neither has is the reverse, and on the RSK side the reverse is exactly the inverse map. So reverse bumping is the non-redundant next step.

    rowUninsert r y undoes rowInsert: it replaces the rightmost entry of r strictly less than y by y, and returns that entry. If no entry is < y it reports none — the signal that this row was not the one bumped into.

    Proved here, sorry-free:

    • rowUninsert_of_forall_le — a row all of whose entries are ≥ y is untouched (none);
    • rowUninsert_rowInsert — the inversion law: if inserting x into a weakly-increasing r bumps y, then reverse-inserting y into the result returns r and reports x;
    • rowUninsert_length / rowUninsert_sorted — the two structural invariants, mirroring rowInsert_length / rowInsert_sorted.

    Scope #

    One row. The cascade across rows (undoing insertRec), the recovery of the word, and the resulting bijection are later bricks; nothing here claims them, and RSKBurnsideHolds for general n remains open. (It is proved for n ≤ 12 by a different route entirely — PartitionsOfBridge.rskBurnsideHolds_le12, no RSK involved.)

    Pure combinatorics on ℕ; nothing archimedean.

    source
    def QOU.Mathlib.Schensted.rowUninsert :
    List ℕ → ℕ → List ℕ × Option ℕ

    Reverse row insertion. Undo a bump: replace the rightmost entry of r strictly less than y by y, returning (newRow, some removed). If every entry is ≥ y there is nothing to undo, and the row is returned unchanged with none.

    The recursion descends to the end of the list first, so the rightmost eligible entry is the one replaced — the mirror of rowInsert, which stops at the leftmost entry strictly greater than the inserted value.

      theorem QOU.Mathlib.Schensted.rowUninsert_of_forall_le (r : List ℕ) (y : ℕ) :
      (∀ a ∈ r, y ≤ a) → rowUninsert r y = (r, none)

      Nothing to undo. If every entry of r is at least y, reverse insertion leaves r alone and reports none. This is what makes the inversion law's base case go through: past the insertion point a Schensted row is entirely ≥ the bumped value.

      theorem QOU.Mathlib.Schensted.rowUninsert_rowInsert (r : List ℕ) :
      List.Sorted (fun (x1 x2 : ℕ) => x1 ≤ x2) r → ∀ (x y : ℕ), (rowInsert r x).2 = some y → rowUninsert (rowInsert r x).1 y = (r, some x)

      The inversion law. If inserting x into a weakly-increasing row r bumps y, then reverse-inserting y into the resulting row recovers r and reports the inserted x.

      rowInsert and rowUninsert are therefore mutually inverse on the bumping branch, which is the branch the RSK cascade runs on.

      theorem QOU.Mathlib.Schensted.rowUninsert_sorted (r : List ℕ) :
      List.Sorted (fun (x1 x2 : ℕ) => x1 ≤ x2) r → ∀ (y : ℕ), List.Sorted (fun (x1 x2 : ℕ) => x1 ≤ x2) (rowUninsert r y).1

      Reverse insertion keeps the row weakly increasing.
