    The session's two dimension notions for a partition λ ⊢ n are:

    • dimSYT p := numStandardYoungTableaux (partitionShape p) — the genuine SYT count, a Finite-backed Nat.card over the StandardYoungTableau type (RSKBurnsideTarget); and
    • QOU.BraidKnot.IdentityI.dimHLF l := (sz l).factorial / ∏_c h_c — the Frame–Robinson–Thrall hook-length dimension over the weakly-decreasing List ℕ model (IdentityIContentDecomposition), already decide-validated Σ_λ dimHLF(λ)² = n! for n ≤ 12 (dim_validated_le12) and wired into the PlancherelSnData {3..12} instances.

    The hook-length formula asserts these agree: #SYT(λ) = n!/∏_c h_c. Stated on the partition index (p.parts sorted weakly-decreasing is exactly the row-length list both partitionShape and PartitionListBridge.toList build):
