    QOU.Mathlib.SYTHookGNWRatio — the per-corner hook ratio (toward gnwHookIdentity) #

    SYTHookGNWWiring proved the Vandermonde/factorial casts of betaProdGap/betaFactProd. This file builds the per-corner hook ratio prodHooks(l)/prodHooks(l∖c) = β_c·∏_{j≠c}(β_c−1−β_j)/(β_c−β_j) that, summed over corners (non-corners vanish) against betaLagrange, closes gnwHookIdentity.

    First piece: the factorial side. For a non-row-drop corner removeCorner l c = l.set c (l[c]−1) (no length change); betaFactProd factors depend only on l[i] and the drop length, so only factor c changes (β_c!/(β_c−1)! = β_c).

    Pure ℕ/ℚ combinatorics; nothing archimedean; no fit.

    Remaining design — the gap ratio, row-drop, and assembly (DONE) #

    All scaffolding above is sorry-free. The remaining route to gnwHookIdentity:

    (R1) Gap ratio (non-row-drop) — DONE (betaProdGap_ratio). betaProdGap (l.set c (l[c]−1)) = betaProdGap l · ∏_{j∈(range k).erase c} (β_c−1−β_j)/(β_c−β_j). Via the pairs form: factor each term β'ᵢ−β'ⱼ = (βᵢ−βⱼ)·rᵢⱼ (mul_div_cancel₀, gaps nonzero by betaNat_ne), so betaProdGap(l∖c) = betaProdGap(l)·∏ᵢ∏ⱼ rᵢⱼ (prod_mul_distrib). Evaluate the inner ratio product: inner_i = 1 for i>c; inner_c = ∏_{j∈Ioo c k}(β_c−1−β_j)/(β_c−β_j); inner_i = r_{i,c} = (βᵢ−β_c+1)/(βᵢ−β_c) for i<c (prod_eq_single c, others =1). Pull out i=c (mul_prod_erase), restrict the rest to range c (prod_subset, i>c terms =1), and use the sign flip (βᵢ−β_c+1)/(βᵢ−β_c) = (β_c−1−βᵢ)/(β_c−βᵢ) (ring). Split erase c = range c ∪ Ioo c k.

    (R2) Factorial × gap ⇒ per-corner ratio — DONE (prodHooks_ratio). Combines betaFactProd_ratio (= β_c) with (R1) through identity (i) prodHooks·betaProdGap = betaFactProd (prodHooks_mul_betaProdGap, betaProdGap_pos): prodHooks(l)/prodHooks(l∖c) = β_c·∏_{j≠c}(β_c−1−β_j)/(β_c−β_j).

    (R3) Row-drop corner (l[c]=1, last row, k→k−1) — DONE (prodHooks_removeCorner). removeCorner l c = (l.set c (l[c]−1)).filter (·≠0); the filtered list is sorted (sorted_set_corner), and filtering zeros from a sorted list is prodHooks-invariant (prodHooks_filter_zero_sorted, via the trailing-zero lemma prodHooks_append_zero), so prodHooks(removeCorner l c) = prodHooks(l.set c (l[c]−1)) and (R2) applies directly.

    (R4) Assembly — DONE (gnwHookIdentity_proof). Sum over corners l; non-corner rows vanish (β_c−1 = β_{c+1}, gnw_noncorner_vanish); bridge the corner list-sum to a range Finset sum (filter_map_sum + list_range_sum + prod_betaNat_erase) and apply betaLagrange (betaVec l) + sum_betaVec_sub (= sz l) via betaLagrange_range. This discharges SYTHookGNW.gnwHookIdentity.
