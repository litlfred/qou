        theorem QOU.Mathlib.Borel.stokesJump_beyondAllOrders {E : Type u_1} [NormedAddCommGroup E] {jump : ℝ → E} (h : StokesJumpBound jump) (N : ℝ) :
        Filter.Tendsto (fun (x : ℝ) => x ^ N * ‖jump x‖) Filter.atTop (nhds 0)

        A Stokes jump is beyond all orders. If ‖jump x‖ ≤ C·exp(−b·x^s) with b > 0, s > 1, then x^N·‖jump x‖ → 0 for every real N — the jump decays faster than any power of x.

        This is the reason alien calculus exists. A formal asymptotic series in x^{-1} sees only the powers; a term killed by every power is invisible to it. So two functions with the same asymptotic expansion can differ by a Stokes jump, the expansion cannot distinguish them, and the alien derivative is the invariant that can. gevrey_difference_stokesJumpBound above supplies the hypothesis from a Gevrey-1 remainder bound; this consumes it.

        Note C ≥ 0 is not assumed — it follows, since ‖jump x‖ ≥ 0 and the exponential is positive wherever the bound holds.
