    QOU.Mathlib.Bialternant — the alternant branching rule #

    For exponents α₀ < α₁ < ⋯ < α_N and variables x₀, …, x_N in a commutative ring, the alternant a_α(x) = det (x_i ^ α_j) splits off the variable x₀:

    a_α(x) = x₀^{α₀} · ∏_{i ≥ 1} (x_i − x₀) ·
         Σ_{k_j < α_{j+1} − α_j} x₀^{Σ_j (α_{j+1} − 1 − α_j − k_j)} · a_{(α_j + k_j)_j}(x₁, …, x_N).

    The new exponents γ_j = α_j + k_j range over α_j ≤ γ_j < α_{j+1}, so they interlace the old ones. This is the determinant half of the bialternant formula a_{λ+δ} = a_δ · s_λ.

    Proof: subtract x₀^{α_j − α_{j−1}} times column j − 1 from column j. Row 0 becomes (x₀^{α₀}, 0, …, 0); each remaining entry is x_i^{α_j}(x_i^d − x₀^d), which carries the factor x_i − x₀ times a geometric sum, and the determinant is multilinear in those sums.
