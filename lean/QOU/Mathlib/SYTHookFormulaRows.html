    QOU.Mathlib.SYTHookFormulaRows — Frame–Robinson–Thrall hook-length formula, closed #

    in full generality for one- and two-row shapes (sorry-free).

    The general HLF numSYTenum l = dimHLF l is PROVED, sorry-free, in QOU.Mathlib.SYTEnum.numSYTenum_eq_dimHLF (SYTHookGNW.lean) via the Greene–Nijenhuis–Wilf route — corner recursion plus the hook-summation identity, combined by strong induction. This header said "remains open in this corpus" until 2026-08-30, long after that proof landed; it is a source-file status note that went stale, and it misled a downstream consumer into writing the same false claim into QOU.Hecke.blockDim, a PR body and a bean. Cite the theorem, not this file, for the general case. This file proves the closed-form sub-cases that HLF specialises to on small shapes — worth having independently of the general theorem, since they are explicit closed forms rather than an existence result — genuine ∀-quantified theorems (not bounded decide):

    • One row [a] (a ≥ 1): prodHooks [a] = a!, hence dimHLF [a] = 1 (prodHooks_single, dimHLF_single). This is HLF for λ = (a): there is exactly one standard tableau of a single row.

    • Two rows [a, b] (a ≥ b ≥ 1): the divisor-free closed product prodHooks [a,b] · (a − b + 1) = (a+1) · a! · b! (prodHooks_pair_mul), the classical two-row hook product giving the ballot-number dimension dimHLF [a,b] = (a+b)! · (a−b+1) / ((a+1)·a!·b!).

    All arithmetic is over ℕ; nothing archimedean; no fit. The hook used is exactly the one in QOU.BraidKnot.IdentityI (h(i,j) = (λ_i − j) + (colLen j − i) − 1), so these closed forms certify prodHooks/dimHLF on the row families directly.

    Two-row HLF: closed-form hook product prodHooks [a,b] #

    theorem QOU.Mathlib.SYTHookRows.prodHooks_pair_row1 (a b : ℕ) (hab : b ≤ a) :
    (List.map (fun (j : ℕ) => b - j + (BraidKnot.IdentityI.colLen [a, b] j - 1) - 1) (List.range b)).prod = b.factorial

    Row-1 hook product of [a,b] (a ≥ b): cell j < b of the second row has hook (b − j) + (colLen j − 1) − 1 = b − j (since j < b ⟹ colLen = 2), so the product is b!.

    theorem QOU.Mathlib.SYTHookRows.prodHooks_pair_row0_mul (a b : ℕ) (hab : b ≤ a) :
    (List.map (fun (j : ℕ) => a - j + (BraidKnot.IdentityI.colLen [a, b] j - 0) - 1) (List.range a)).prod * (a + 1 - b).factorial = (a + 1).factorial * (a - b).factorial

    Row-0 hook product of [a,b] (a ≥ b) in divisor-free form: (∏_{j} h(0,j)) · (a + 1 − b)! = (a+1)! · (a − b)!. The row-0 hooks split as a + 1 − j for j < b and a − j for b ≤ j < a; the first block contributes the descending product (a+1)!/(a+1−b)!, the second (a − b)!.

    theorem QOU.Mathlib.SYTHookRows.prodHooks_pair_mul (a b : ℕ) (hab : b ≤ a) (_hb : 1 ≤ b) :
    BraidKnot.IdentityI.prodHooks [a, b] * (a + 1 - b).factorial = (a + 1).factorial * (a - b).factorial * b.factorial

    Two-row hook product, divisor-free closed form (sorry-free). For a ≥ b ≥ 1, prodHooks [a,b] · (a + 1 − b)! = (a+1)! · (a − b)! · b!. This is the Frame–Robinson–Thrall hook product on a two-row shape, the denominator of the ballot-number dimension dimHLF [a,b] = (a+b)! · (a+1−b)! / ((a+1)! · (a−b)! · b!) (equivalently the standard (a+b)!·(a−b+1)/((a+1)·a!·b!)).

    The single-column hook product is n!. The column [1,1,…,1] has one cell per row, and the hook at row i is (1 - 0) + (n - i) - 1 = n - i, so the product over i < n is the descending product n · (n-1) ⋯ 1.
