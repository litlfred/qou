    QOU.Mathlib.SYTBetaZeroPadding — padding a partition with empty rows #

    The trap this file exists for. SYTBeta.betaNum l i = l[i] + (|l| − 1 − i) measures the β-numbers against |l|, the number of nonzero rows. The β-numbers of the level-r principal specialisation are measured against r, the number of variables: the partition is padded with r − |l| empty rows first. The two disagree by the constant r − |l| on every row, and — worse — the padded version has extra rows β = r−1−|l|, …, 0 that the unpadded one does not have at all.

    Differences β_i − β_j between real rows are unaffected, so the Vandermonde is the same up to the new rows; but nothing else transfers for free, and a proof that quietly uses |l| where r belongs is wrong in a way no type error catches.

    What does transfer for free is the hook side, and that is what this file proves: empty rows contribute no cells and are counted by no column, so

    prodHooksF f (l ++ replicate m 0) = prodHooksF f l.

    Pad first, then apply the β-number machinery at r.
