    QOU.Mathlib.RamifiedShiftCalculus — shift-operator symbol calculus at a ramified pole #

    Infrastructure for walls W1/W2 of docs/audits/2026-07-20-zgeometric-prolongation-symbol-scoping.md: the q-D-module symbol calculus at a simple ramification point z = z_c + t², in the coefficient model f : ℤ → R of a local Laurent expansion Σ_e f(e) tᵉ that QOU.Brings.RamificationParityMonodromy already uses.

    The object #

    A shift operator is a pair (shift k : ℤ, multiplier c : ℤ → R):

    shiftOp k c f = fun e => c e * f (e + k)

    — the coefficient at tᵉ is read from t^{e+k} with weight c e. Every derivative-like operator on the chart is one of these:

    operator shift k multiplier c e annihilates constants?
    classical d/dz = (1/2t) d/dt (ddz) 2 e + 2 yes, c(−2) = 0
    naive q-deformation of d/dz 2 [e+2]_q yes, [0]_q = 0
    Jackson D_{q,t} in the local coordinate 1 [e+1]_q yes, [0]_q = 0
    a zeroth-order / connection term 0 or 1 arbitrary no when c(−k) ≠ 0

    The pair (k, c) is the operator's symbol on the punctured t-disk, and symbols compose: shiftOp k c ∘ shiftOp l d = shiftOp (k+l) (c · d(· + k)) (shiftOp_comp). That composition law, with its iterate shiftOp_iterate, is the calculus W2 asks for at the level of leading Laurent data.

    What it proves — the W1 prune #

    The keystone needs the jet tower to produce a nonzero period (residue at the t^{−2} slot, since λ = X^{(n)}·2t dt) and to carry the (−1)^n bar-parity residual (Door-v). Two exact necessary conditions on any single-shift prolongation follow, with no reference to the C1 kernel coefficients (W3):

    1. Residue. For a seed supported in t-degrees ≥ 0 (a power series — the colour-cubic branch is one), a shift-1 or shift-2 operator that annihilates constants (c(−k) = 0) has vanishing residue slot at every jet level (residue_slot_zero_shift_two, residue_slot_zero_shift_one). Every derivative — classical, or q-deformed in either q-integer convention, in z or in t — annihilates constants. So no derivative-like prolongation of shift 1 or 2 can produce the binding period; only a term with c(−k) ≠ 0, i.e. a genuine zeroth-order (connection-matrix) component, can.
    2. Parity. An even shift commutes with the covering monodromy t ↦ −t; an odd shift anti-commutes (shiftOp_anticomm_mono_of_odd), so its jet tower's monodromy eigenvalue alternates as (−1)^n (odd_shift_jet_monodromy_alternates) — the positive counterpart to classical_jet_monodromy_constant. The (−1)^n residual therefore needs an odd shift component.

    Together: the sought D_q must have an odd shift and a non-derivative component that does not annihilate constants. Both are derived from the local geometry of Σ (square-root branch ⇒ the coefficient model) and the two measured target properties — never from the binding terms.

    This does not construct D_q (W1 stays a wall) and does not identify its symbol with C1 (W3 stays). It narrows the class exactly.

    Ground ring: generic [CommRing R] throughout (§7c); [Field R] only where a q-integer is instantiated.

          The W1 prune: derivative-like shift-1 / shift-2 operators cannot produce a residue #

          Shift 2. If c(−2) = 0 the residue slot is dead at every jet level n ≥ 1, for every seed: the i = 0 factor of the iterate product is c(−2). This is the classical d/dz and every q-deformation of its multiplier.

              Non-vacuity: an operator that does NOT annihilate constants does produce a residue #

              source
              theorem QOU.Mathlib.RamifiedShiftCalculus.constant_weight_shift_one_residue {R : Type u_1} [CommRing R] (f : ℤ → R) :
              (shiftOp 1 fun (x : ℤ) => 1)^[2] f (-2) = f 0

              A shift-1 operator with a nonzero zeroth-order weight reaches the residue slot from the constant term in two steps with weight c(−2)·c(−1); with c ≡ 1 that is 1. So the prune is a statement about derivative-like operators, not about all of them — which is the whole point.
