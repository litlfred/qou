    QOU.Mathlib.SYTCornerListConnection — discharging cornerRecursion via the structural branching rule #

    Connects the list-level corner combinatorics (corners l, removeCorner l i) to the structural GNW branching count (numStandardYoungTableaux_branching), through the counting bridge numSYTenum l = numStandardYoungTableaux (ofRowLens l hl).

    The geometric heart is eraseCorner_ofRowLens: deleting the corner cell (i, λ_i − 1) from the diagram of λ gives the diagram of removeCorner λ i.

    Pure combinatorics; nothing archimedean; no fit.

    theorem QOU.Mathlib.SYTEnum.filter_ne_zero_getD (m : List ℕ) :
    List.Sorted (fun (x1 x2 : ℕ) => x1 ≥ x2) m → ∀ (r : ℕ), (List.filter (fun (x : ℕ) => x != 0) m).getD r 0 = m.getD r 0

    Filtering trailing zeros preserves getD at every index, for a descending-sorted list. In a list sorted ≥, the nonzero entries are a prefix, so filter (· ≠ 0) drops only trailing zeros and the indexed lookup is unchanged (out-of-range lookups are 0 on both sides).
