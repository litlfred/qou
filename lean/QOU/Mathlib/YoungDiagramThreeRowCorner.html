    A removable corner that preserves "at least three rows" #

    Bean qou-7gei. Discharges the combinatorial hypothesis hpred of QOU.QBeta.TemperleyLiebTower.vanishing_step, which until now was stated as a hypothesis and justified only by exhaustion at n + 1 = 4, 5, 6, 7.

    The statement, and why it is the right one #

    vanishing_step needs: every shape at level n+1 with ≥ 3 rows covers some shape at level n with ≥ 3 rows. Dually — and this is the form that is actually convenient — every Young diagram with ≥ 3 rows and at least 4 cells has a removable corner whose removal still leaves ≥ 3 rows.

    Two encoding facts make it tractable:

    • "at least three rows" is (2,0) ∈ μ. The row count is μ.colLen 0, and mem_iff_lt_colLen turns 3 ≤ μ.colLen 0 into 2 < μ.colLen 0 into (2,0) ∈ μ. So the goal 3 ≤ (eraseCorner μ c hc).colLen 0 unfolds, via mem_eraseCorner, to (2,0) ∈ μ ∧ (2,0) ≠ c — and the first conjunct is the hypothesis. The whole theorem is therefore "there is a corner other than (2,0)."
    • The last cell of the last row is always a corner (isCorner_lastRow), in closed form, with no search: (μ.colLen 0 − 1, μ.rowLen (μ.colLen 0 − 1) − 1).

    So the proof is: take that corner; if it is not (2,0) we are done; if it is, then μ has exactly three rows with a single cell in the third, and a corner in row 0 or row 1 serves instead.

    Where the cardinality hypothesis is used #

    Exactly once, and it is the content rather than an edge case. With three rows, a one-cell third row, and rowLen 0 = 1, the diagram is forced to be (1,1,1) — three cells. That single shape is the only obstruction, and it is precisely why n = 3 is the base case of the induction in vanishing_all_levels rather than a step: (1³) covers only (1²), which has two rows. Do not "simplify" the 4 ≤ card hypothesis away; it is carrying that fact.

    Machinery is the repo's own (QOU.Mathlib.YoungDiagramCorner): Mathlib supplies YoungDiagram, rowLen, colLen and their monotonicity, but has no corner API.

    THE THEOREM. A diagram with at least three rows and at least four cells has a removable corner whose removal still leaves at least three rows.

    This is hpred of QOU.QBeta.TemperleyLiebTower.vanishing_step, no longer a hypothesis. Three cases, each exhibiting an explicit corner:

    1. the last-row corner is not (2,0) — use it;
    2. it is (2,0), and row 1 is shorter than row 0 — use the row-0 corner;
    3. it is (2,0) and rows 0 and 1 are equal — then they have length ≥ 2 (else μ = (1,1,1), ruled out by the cardinality hypothesis) and the row-1 corner serves.

    Instantiating the propagation — bean qou-7gei item 2 #

    QOU.QBeta.TemperleyLiebTower.vanishing_all_levels_dom is stated on abstract Shape, Cov and rows, with the combinatorial predecessor fact as a hypothesis. Here that hypothesis is discharged on real Young diagrams, so the propagation is no longer conditional on it.

    Shapes are {μ : YoungDiagram // μ.cells.card = n} — written inline rather than behind a def, so subtype projections stay definitionally transparent and no unfolding lemmas are needed. Cov is the converse of corner removal: l covers m when deleting some removable corner of l gives m. rows is colLen 0.

    Note what this deliberately avoids. Phrasing covers as a Finset (Shape (n+1)) would need Fintype {μ : YoungDiagram // μ.cells.card = n}, which Mathlib does not provide and which is real work to build. The domination form of the induction never sums, so Cov can be a bare Prop and the finiteness question never arises.

    ∃ (m : { μ : YoungDiagram // μ.cells.card = n }), 3 ≤ (↑m).colLen 0 ∧ ∃ (c : ℕ × ℕ) (hc : IsCornerCell (↑l) c), eraseCorner (↑l) c hc = ↑m

    The predecessor fact, on Young diagrams of a given size.

    Every shape of size n+1 with at least three rows covers a shape of size n with at least three rows, provided 3 ≤ n. This is hpred of vanishing_all_levels_dom, discharged.

    The 3 ≤ n guard is exactly the 4 ≤ card of exists_threeRow_corner, and it is load-bearing: at n = 2 the shape (1³) of size 3 covers only (1²), which has two rows. That is the base case of the induction, not a step.

    theorem QOU.Mathlib.card_three_threeRow_unique (μ : YoungDiagram) (hcard : μ.cells.card = 3) (hrows : 3 ≤ μ.colLen 0) :
    μ.cells = {(0, 0), (1, 0), (2, 0)}

    At three cells there is exactly one shape with three rows, namely (1³).

    Three rows forces (0,0), (1,0), (2,0) ∈ μ — that is already three cells — and card = 3 leaves no room for a fourth. So the base case of the induction is a statement about a single diagram, which is what lets the scalar pinning TemperleyLiebTower.conventionD_kills_antisymmetriser discharge it: there is nothing to quantify over.

    This is the glue between the scalar layer (which knows y₍₁³₎ = 0) and the diagram layer (which needs ∀ m of size 3 with ≥ 3 rows, y m = 0).

    The propagation, with every combinatorial hypothesis discharged.

    If the weights are nonnegative, each cover is dominated by its parent, and all ≥ 3-row weights vanish at three strands, then they vanish at every level above. Nothing here is assumed about Young diagrams — youngPred supplies it.

    The two remaining hypotheses are the analytic ones and both are proved elsewhere on this branch for the actual Markov weights: hnn from TemperleyLiebTower.yw_nonneg, and hdom from TemperleyLiebTower.dominates_of_branching applied to yw_branching. The base case is conventionD_kills_antisymmetriser.

    So the ≥ 3-row vanishing at all n ≥ 3 now rests on the n = 3 pinning plus proved facts, with no appeal to Wenzl's theorem.

    3 ≤ (↑l).colLen 0 → y (3 + k) l = 0

    The composed statement: one scalar in, vanishing at every level out.

    threeRow_vanishing_all_levels still asks for a base case quantified over shapes. threeRow_size_three_subsingleton collapses that quantifier, so the input becomes a single scalar fact — the weight of the one three-row shape of size 3 is zero — which is exactly what TemperleyLiebTower.conventionD_kills_antisymmetriser delivers.

    That is as far as this layer can honestly go, and the boundary is worth naming. Going further means saying that the framework's y_λ is the Wedderburn weight of the Markov trace, i.e. tr_M = Σ_λ y_λ χ_λ. That is a statement about characters and the Wedderburn decomposition — the representation theory this module deliberately does not carry, and which the Hecke-instance layer (QOU.Hecke, PR #4857) is building. Until it lands, y here is any function satisfying the hypotheses, and the theorem is a genuine implication rather than a tautology: nothing below defines y to be zero anywhere.

    The one place a reader could be misled is hpin. It is an input, not a conclusion. What is proved is that a single zero at n = 3 propagates to every level — not that the zero is there.
