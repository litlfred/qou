    QOU.Mathlib.SYTEnumerationN7 — brute-force #SYT = dimHLF at n = 7 (isolated, expensive) #

    The per-shape hook-length validation numSYTenum l = dimHLF l is decide-checked for n ≤ 6 in SYTEnumeration. This file pushes it one step further, to every partition of 7.

    Why a separate leaf file. The n = 7 check enumerates 7! = 5040 fillings per shape across 15 shapes; the kernel decide takes ≈ 3.5 min wall and needs both maxHeartbeats 0 (elaborator) and a raised maxRecDepth (the 5040-deep structural allPerms recursion). Isolating it here — nothing imports this module — keeps that cost off the build path of SYTEnumeration's dependents (SYTHookFormula{,General}), which stay fast.

    Axiom-free, not native_decide. This is a genuine kernel decide, so it adds no axioms (#print axioms numSYTenum_eq_dimHLF_7 shows only the propositional-extensionality/quotient core, no Lean.ofReduceBool / Lean.trustCompiler). This deliberately avoids the compiled-evaluator trust that the mpi9 cleanup is removing elsewhere (AGENTS.md §1a). n = 8 (40320 fillings/shape) is the practical kernel ceiling and is left to the aggregate dim_validated_le12; recorded, not silently dropped.

    Pure combinatorics on ℕ; nothing archimedean; no fit.
