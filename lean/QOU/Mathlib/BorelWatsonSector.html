    theorem QOU.Mathlib.Borel.re_cpow_ofReal {z : ℂ} {t : ℝ} (hz : z ≠ 0) :
    (z ^ ↑t).re = Real.exp (Real.log ‖z‖ * t) * Real.cos (z.arg * t)

    Re(z^t) = ‖z‖^t · cos(t · arg z) for z ≠ 0 and real t: the real part of a fractional power, computed via z^t = exp(log z · t) and Complex.exp_re. No branch-cut arg-of-cpow identity needed.

    theorem QOU.Mathlib.Borel.re_cpow_pos_of_abs_arg_lt {z : ℂ} {t : ℝ} (hz : z ≠ 0) (ht : 0 < t) (harg : |z.arg| < Real.pi / (2 * t)) :
    0 < (z ^ ↑t).re

    The fractional-power sector map (brick 4b-i). For 0 < t and z ≠ 0 in the sector |arg z| < π/(2t), the fractional power z^t lands in the open right half-plane. Since the source sector has opening π/t (which is > π precisely when t < 1), this is the opening->π → half-plane contraction the Watson transport needs.

    theorem QOU.Mathlib.Borel.analyticAt_cpow_const {t : ℝ} {z : ℂ} (hz : z ∈ Complex.slitPlane) :
    AnalyticAt ℂ (fun (w : ℂ) => w ^ ↑t) z

    Holomorphy of the fractional power z ↦ z^t on the slit plane (ℂ ∖ ℝ_{≤0}), which contains every sector of opening < 2π about the positive axis. A direct instance of AnalyticAt.cpow (z^t = exp(t log z), log analytic off the slit). The second geometric ingredient of the Watson carrier, alongside sector_cpow_mapsTo.
