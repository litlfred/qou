    The elliptic divisor-degree theorem — scaffold (PI-2, bean qou-toqt) #

    For a nonconstant elliptic function f (doubly-periodic meromorphic on ℂ, with ℝ-independent periods ω₁, ω₂), the sum of the local orders over one fundamental parallelogram is zero:

    $$\sum_{p \in P} \operatorname{ord}_p f \;=\; 0 \qquad\Longleftrightarrow\qquad \#\{\text{zeros}\} = \#\{\text{poles}\} \text{ (with multiplicity).}$$

    This is Liouville's third theorem (the "degree-zero" theorem). It is the missing analytic input in the PentagonRigidity Φ₁/Φ₂-entire leg (docs/audits/2026-07-20-pentagon-entire-leg.md): the difference equations make the divisor of the ratio Ψ/Φ doubly-periodic (QOU.QBeta.MeromorphicSameOrder.meromorphicOrderAt_orderDiff_periodic), but degree-zero + a sign input is what forces that periodic divisor to vanish identically, killing the elliptic-freedom obstruction.

    What is proved here (sorry-free) vs. open #

    Proved now (elementary bricks, Mathlib-only cone):

    • periodic_deriv / periodic_logDeriv — the derivative and logarithmic derivative f'/f of a periodic function are periodic. This is the boundary-integral cancellation ingredient: on opposite edges of the parallelogram (which differ by a period) the integrand logDeriv f agrees, while the orientations oppose, so the two edge contributions cancel.
    • isElliptic_logDeriv — the logarithmic derivative of an elliptic function is itself elliptic (periodic under both ω₁ and ω₂).
    • meromorphicOrderAt_translate / divisor_translate — the divisor is lattice-periodic: ord_p f and hence (divisor f).p are invariant under each period, so the divisor is determined by its restriction to one cell. (The translation brick meromorphicOrderAt_comp_add is reproved locally, namespaced, to keep this file's dependency cone Mathlib-only and lean-direct verifiable; the un-namespaced original lives in QOU.QBeta.MeromorphicSameOrder.)

    Stated open (the deep analytic core — a genuine Mathlib gap):

    • elliptic_divisor_degree_zero — the degree-zero theorem itself, carried as a cited sorry. Mathlib v4.24.0 has Liouville, Cauchy estimates, meromorphicOrderAt, MeromorphicOn.divisor, Complex.CauchyIntegral and circleIntegral, but it has no elliptic-function theory, no argument principle / residue theorem (Σ ord = (1/2πi)∮ f'/f), and no Hadamard-factorization. The proof route Σ ord = (1/2πi)∮_{∂P} f'/f = 0 (boundary integrals cancel by the periodicity of logDeriv f proved above) needs the argument principle to identify the sum of orders with the contour integral of logDeriv f; that identification is the absent theorem. The boundary cancellation half is formalizable now (it is isElliptic_logDeriv); the argument principle half is not.

    This is honest scaffolding of a known gap: not vacuous True, not axiomatized-as-proved. See docs/audits/2026-07-20-pi2-elliptic-divisor-scaffold.md.

    Boundary-cancellation bricks: f'/f of a periodic function is periodic #

    source
    theorem QOU.Mathlib.EllipticDivisorDegree.periodic_deriv {f : ℂ → ℂ} {c : ℂ} (hf : Function.Periodic f c) :
    Function.Periodic (deriv f) c

    The derivative of a periodic function is periodic. If f (·+c) = f, then deriv f (·+c) = deriv f. This is the pointwise statement that makes the two horizontal (resp. vertical) edges of a fundamental parallelogram carry the same f'/f integrand up to the period shift.

    source
    theorem QOU.Mathlib.EllipticDivisorDegree.periodic_logDeriv {f : ℂ → ℂ} {c : ℂ} (hf : Function.Periodic f c) :
    Function.Periodic (logDeriv f) c

    The logarithmic derivative f'/f of a periodic function is periodic. Since logDeriv f = deriv f / f and both deriv f and f are periodic, so is their quotient. On the two edges of ∂P that differ by the period c, the logDeriv f integrand agrees; with opposite orientation the contributions cancel — the boundary-integral cancellation that drives the degree-zero proof.

    An elliptic function: meromorphic on all of ℂ and doubly periodic under ω₁, ω₂. (ℝ-independence of the periods — so the lattice is genuinely rank-2 — is carried as a separate hypothesis where needed, matching QOU.MathlibExt.DoublyPeriodicLiouville.)

    • periodic₁ : Function.Periodic f ω₁

    • periodic₂ : Function.Periodic f ω₂

      f is periodic under the second period.

      def QOU.Mathlib.EllipticDivisorDegree.fundamentalParallelogram (ω₁ ω₂ : ℂ) :
      Set ℂ

      The half-open fundamental parallelogram { s·ω₁ + t·ω₂ : s, t ∈ [0,1) } of the lattice ⟨ω₁, ω₂⟩. A single such cell contains exactly one representative of each lattice coset (the Int.fract reduction of QOU.MathlibExt.DoublyPeriodicLiouville.const_of_doublyPeriodic), so summing a lattice-periodic divisor over it is the "degree over a fundamental domain".

        The divisor is lattice-periodic (a provable structural brick) #

        meromorphicOrderAt_comp_add is the translation invariance of the meromorphic order, reproved locally (namespaced) so this file needs only the Mathlib cone.

        source
        theorem QOU.Mathlib.EllipticDivisorDegree.meromorphicOrderAt_translate {f : ℂ → ℂ} {c : ℂ} (hf : Function.Periodic f c) (z : ℂ) :
        meromorphicOrderAt f (z + c) = meromorphicOrderAt f z

        The meromorphic order is invariant under a period. If f is periodic under c, then ord_{z+c} f = ord_z f. Hence the order — the local zero/pole multiplicity — is a lattice-periodic function of the base point.

          ∑ z ∈ S, (MeromorphicOn.divisor f Set.univ) z = 0

          Liouville's third theorem: the degree of an elliptic divisor is zero. For a nonconstant elliptic function f with ℝ-independent periods, the sum of the local orders (zeros minus poles, with multiplicity) over one fundamental parallelogram vanishes. S enumerates the finitely many divisor points inside the cell (the finiteness — support locally finite ∩ compact cell — is a separate, tractable brick; it is passed as hS so that the analytic core is isolated).

          OPEN. The classical proof is Σ_{p∈P} ord_p f = (1/2πi) ∮_{∂P} logDeriv f = 0, where the contour integral vanishes because logDeriv f is elliptic (isElliptic_logDeriv, proved above) so opposite edges cancel. The first equality is the argument principle, which is absent from Mathlib v4.24.0 (no elliptic-function theory, no residue theorem). The boundary-cancellation half is formalized here; the argument-principle half is the genuine gap.
