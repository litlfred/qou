    Σ_λ (f^λ)² = n! without RSK — the branching induction #

    QOU/Mathlib/RSKBurnsideTarget.lean states the Burnside identity ∑_{λ ⊢ n} dim(λ)² = n! and records its proof as

    "the RSK correspondence S_n ≃ Σ_λ SYT(λ)² (absent from pinned Mathlib; the multi-session next step)"

    with the general-n case open (the decide-verified range reaches n ≤ 12).

    RSK is not needed. The identity follows by induction from the two branching rules on the Young lattice, and this file supplies the inductive step in the form that consumes them:

    • down — f^λ = Σ_{μ ↗ λ} f^μ: an SYT of λ puts its largest entry in some corner, so removing that corner is a bijection onto ⨆_μ SYT(μ). This is essentially the defining recursion of the SYT count, not a theorem about representations.
    • up — Σ_{λ ⊐ μ} f^λ = n · f^μ for μ ⊢ n−1. The one with content; it is the DU − UD = I relation of Stanley's differential-poset formulation.

    Given both, Σ_{λ ⊢ n} (f^λ)² = n · Σ_{μ ⊢ n−1} (f^μ)², and induction from Σ_{λ ⊢ 0} = 1 gives n!.

    Verified numerically for n ≤ 10 (both branching rules at every μ, and the resulting recursion) before formalising.

    What this file proves #

    sum_sq_step, stated for an abstract bipartite incidence so it depends on no Young-diagram infrastructure: two finite levels A, B, an incidence I ⊆ A ×ˢ B, a weight f, and the two branching hypotheses give

    ∑_{l ∈ B} (f l)² = c · ∑_{m ∈ A} (f m)².

    The proof is a Fubini exchange over I. sum_sq_factorial_of_step then iterates it to n!.

    What is hypothesis, and what is left #

    hdown and hup are hypotheses. Instantiating them for the Young lattice — A = shapes (n−1), B = shapes n, I the covering relation, f = #SYT — is the remaining work, and hup is the only mathematically substantial part. That is a much smaller target than constructing the RSK bijection: it is one identity about corner-addition counts, where RSK is a bijection between S_n and pairs of tableaux.

    Per AGENTS.md §"Axiomatization is NOT a Proof", carrying hup as a hypothesis does not establish it; the contribution here is that the route avoids RSK.

    hdown is no longer open — it is proved elsewhere in the corpus #

    Measured 2026-08-21 (bean qou-wtny). The text above lists hdown and hup together as the remaining work. That is stale for hdown: QOU.Mathlib.numStandardYoungTableaux_branching (QOU/Mathlib/SYTBranchingRule.lean) already proves, sorry-free and at general n,

    numStandardYoungTableaux μ = ∑_{removable corners c} numStandardYoungTableaux (μ ∖ c)

    via a genuine Equiv.ofBijective on corner deletion / max re-insertion — exactly the hdown shape. So of this file's two hypotheses one is discharged in the corpus already, and hup is the single remaining mathematical obligation, as the header's own next paragraph says.

    What is not yet done for hdown is its instantiation: sum_sq_step wants the sum indexed by a Finset of shapes cut out by an incidence relation, whereas numStandardYoungTableaux_branching indexes by the corner subtype {c // IsCornerCell μ c}. Bridging the two needs corner-erasure to be a bijection onto {μ ∈ shapes (n−1) : μ ⋖ λ}. That is bookkeeping, not mathematics, but it is not free.

    Mathlib v4.24.0 does not contain RSK — how that was established #

    The pinned toolchain's olean tree carries exactly two Young modules, Mathlib/Combinatorics/Young/YoungDiagram and .../SemistandardTableau. There is no StandardYoungTableau, no hookLength, and no RSK / Schensted module anywhere in it.

    Method note, because it is reusable: enumerate the olean tree, do not ask an index. lean_leansearch / lean_loogle are frequently unreachable from a sandbox (403 through the agent proxy), and — more importantly — they index a current Mathlib, not the version this repo pins. A negative from them is therefore not evidence about v4.24.0. Enumerating .lake/packages/mathlib/.lake/build/lib/lean/Mathlib/** answers the question for the version actually being built against, and needs no network at all.

    A second route is further along — read this before investing here #

    Bean qou-3c2j (sibling, landing through PRs #5139 / #5151 / #5156) is building the same identity by the representation-theoretic route, and is closer: the regular module decomposes into isotypic components, each of type S^μ, with multiplicity m_μ = dim Hom_G(k[G], S^μ) = dim S^μ — the first equality from Schur orthonormality (SpechtSchurDiagonal.finrank_homG_specht, landed sorry-free), the second from MathlibExt.RegularHom.homGRegularEquiv (landed sorry-free). Then n! = dim_k k[S_n] = Σ_μ m_μ · dim S^μ = Σ_μ (dim S^μ)². As that bean records, the identity comes out as a conclusion, so it would retire the sorryAx in OVTopAssembly.sum_numSYT_sq_eq_factorial rather than route around it. One brick remains there: turning sSup_isotypicComponents into a finrank sum indexed by PartitionIndex n.

    This file is therefore kept as an independent second route, not as the primary attack, and its remaining obligation (hup) is the larger of the two. Its standing value is that it is representation-theory-free: the branching induction needs no Specht module, no semisimplicity, and no character theory — only two counting rules on the Young lattice. If the isotypic route closes first, the honest use of this file is to verify that result from the combinatorial side, per AGENTS.md §"converge on landing".

    Base ring #

    ℕ throughout — the identity is about counts, and no subtraction or ordering beyond Finset sums is used.

    source
    theorem QOU.Mathlib.sum_sq_step {σ : Type u_1} [DecidableEq σ] (A B : Finset σ) (I : Finset (σ × σ)) (f : σ → ℕ) (c : ℕ) (hdown : ∀ l ∈ B, ∑ m ∈ A with (m, l) ∈ I, f m = f l) (hup : ∀ m ∈ A, ∑ l ∈ B with (m, l) ∈ I, f l = c * f m) :
    ∑ l ∈ B, f l ^ 2 = c * ∑ m ∈ A, f m ^ 2

    The inductive step, abstractly. Two finite levels A and B joined by an incidence I, with

    • hdown — each l ∈ B has weight equal to the total weight of its I-predecessors in A;
    • hup — each m ∈ A has I-successors in B of total weight c · f m;

    then the weighted square-sums are related by the same factor c.

    Instantiated on the Young lattice with f = #SYT and c = n, this is Σ_{λ ⊢ n} (f^λ)² = n · Σ_{μ ⊢ n−1} (f^μ)².

    source
    theorem QOU.Mathlib.sum_sq_factorial_of_step (S : ℕ → ℕ) (h0 : S 0 = 1) (hstep : ∀ (n : ℕ), S (n + 1) = (n + 1) * S n) (n : ℕ) :
    S n = n.factorial

    Iterating the step gives the factorial. A level-indexed family whose square-sums satisfy S (n+1) = (n+1) · S n with S 0 = 1 is n!. Combined with sum_sq_step at each level, this is the Burnside identity.
