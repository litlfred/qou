    QOU.OptionE.DeltaLambda — Δ_λ derivation framework #

    Option E infrastructure file 3/4 — derives the per-partition binding-energy density Δ_λ(K) from crystal-graph + rung-selection data, producing the input to Path-D mass prediction.

    Δ_λ from crystal data (framework) #

    For a partition λ ⊢ 3A (Wedderburn block for atom of mass number A), the canonical Δ_λ derived from Option E is:

    $$ \Delta_\lambda(K) \;=\; \sum_{v \in \mathrm{Vertices}(\Gamma_\lambda)} \mathrm{weight}_k(v) \cdot \mathrm{value}(v) $$

    where:

    • Γ_λ is the crystal graph at partition λ
    • weight_k(v) is a k-dependent weight from the canonical rung-selection rule (RungSelection.RungRule)
    • value(v) is a real-valued contribution from the vertex's position in the crystal

    The substantive content of Option E is the specific choice of weight_k and value for which the resulting Δ_λ is intended to close the AME binding energies. Closure is an open target, not an achieved result: the per-λ weighted sum B_pred currently undershoots the deuteron by ≈ −82.9 % under the canonical Option E weights (see the 2026-06-16 Option-E deuteron correction). This file states the framework signature only; it makes no claim that any concrete weight function closes the AME data. DeuteronVerification.lean carries the closure predicate closes_within_10pct as a hypothesis, with no proved closure instance.

    Path-D mass prediction #

    Given Δ_λ values for all λ ⊢ 3A, the predicted binding energy is:

    $$ B_{\mathrm{pred}}(K) \;=\; m_e \cdot \sum_{\lambda \vdash 3A} y_\lambda(q_0) \cdot \chi^\lambda(\beta_K) \cdot \Delta_\lambda(K) $$

    where y_λ(q_0), χ^λ(β_K) are computable from existing QOU infrastructure.

    This file provides the framework signature; concrete weight functions + per-atom predictions live in DeuteronVerification.lean.

    • weight : ℕ → ℝ

      The k-dependent weight function (input: rung index, output: ℝ).

      The per-vertex value function.

        Path-D mass prediction signature #

        Given an atom (Z, N) with partitions λ ⊢ 3A and per-partition Δ_λ values, Path-D predicts the binding energy:

        B_pred = m_e · Σ_λ y_λ · χ^λ(β) · Δ_λ

        We provide the signature; concrete numerical evaluation requires y_λ + χ^λ caches (existing QOU infrastructure).
