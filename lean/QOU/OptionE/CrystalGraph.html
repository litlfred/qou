    QOU.OptionE.CrystalGraph — Kashiwara crystal graph structure #

    Option E infrastructure file 1/4 — basic crystal-graph data structures.

    The Kashiwara crystal of sl_n at level 1 is a directed graph with vertex set = semistandard Young tableaux + edge set encoding the action of the Chevalley generators e_i, f_i at the q → 0 limit ([kashiwara1991]).

    For QOU's purposes:

    • Vertex set: standard Young tableaux of shape λ ⊢ n (we restrict to SYT for the seminormal basis correspondence).
    • Crystal arrows: per-strand f_i operations on the tableau.
    • Crystal weight: a function wt : V → ℤ^r encoding the height in each i-string.

    This file provides the abstract structure; concrete crystal graphs for specific partitions live in DeuteronVerification.lean.

    Refs:

    • [kashiwara1991] DOI 10.1215/S0012-7094-91-06321-0
    • [lecouvey2007] DOI 10.1016/j.jalgebra.2007.07.002
