    Context #

    The current L2 100× dashboard has 3 failures (Q_β, m_n, Δ_pn) all sharing one structural root: the τ_M Kashiwara derivation is truncated at k = 2, with k ≥ 3 rungs dropped as non-canonical (see L2_100x_SharedRoot.lean).

    The Δ_λ binding-energy density (per docs/audits/2026-05-18-delta-lambda-gating-context.md) is what's needed for Path-D mass prediction:

    $$ B(K) \;=\; m_e \cdot \sum_{\lambda \vdash 3A} y_\lambda(q_0)\, \chi^\lambda(\beta_K)\, \Delta_\lambda(K) $$

    Six closure ansätze have failed (Frobenius co-Casimir, Demazure- fibre, LP-Plancherel, LP-Frobenius, crystal-graph, augmented Markov). Option E is the surviving research direction:

    Demazure / KLR canonical basis with explicit q→1 limit. Option E (Kashiwara crystal) is in flight; its expected output is a closed- form Δ_λ from the crystal graph.

    Scope of this scaffold #

    This file does not close Option E. It establishes the structural framework:

    1. class OptionECrystalDeltaLambda — the §3b-cond class axiomatising Option E's content. An instance encodes:

      • The crystal graph structure on partitions λ ⊢ 3A
      • A rung-selection rule extending τ_M to k ≥ 3
      • The resulting Δ_λ values closing Path-D mass prediction

    2. OptionEFramework — a struct collecting the open research questions Option E must answer to land:

      • Closed-form derivation of Δ_λ from crystal vertices
      • Canonical rung-selection at k ≥ 3 (not fitted)
      • q → 1 limit compatibility

    3. Verification framework — a sorry-free record that the 3 failing L2 observables would advance jointly under Option E closure (the shared-root finding from L2_100x_SharedRoot.lean).
