          theorem QOU.Eightfold.RowCapObstruction.weyl_dim_alt_eq_zero_iff (N : ℕ) :
          weylDimAlt N = 0 ↔ N < 3

          The row-cap obstruction. The alternating channel λ = (1³) is empty exactly when N < 3.

          ℓ((1³)) = 3, so Schur–Weyl's row cap ℓ(λ) ≤ N admits this partition only for N ≥ 3; arithmetically that is C(N,3) = 0 ↔ N < 3.

          3. The channels account for all of V^{⊗3} #

          The Specht multiplicities 1, 2, 1 times the Weyl dimensions above reproduce N³ at the two values the chapter compares — confirming these are the right three channels and nothing is missing.

          source
          theorem QOU.Eightfold.RowCapObstruction.schur_weyl_cube_split_two_three :
          2 ^ 3 = weylDimSym 2 + 2 * weylDimMixed 2 + weylDimAlt 2 ∧ 3 ^ 3 = weylDimSym 3 + 2 * weylDimMixed 3 + weylDimAlt 3

          Dimension count at the two decisive values. The Specht multiplicities 1, 2, 1 times the Weyl dimensions account for all of V^{⊗3} at N = 2 and at N = 3:

          N = 2 :   4 + 2·2 + 0  =  8  = 2³
N = 3 :  10 + 2·8 + 1  = 27  = 3³

          so nothing is missing from the three channels, and the N = 2 deficit is located precisely in the vanishing alternating channel rather than in some unaccounted-for piece.

          The general identity N³ = C(N+2,3) + 4·C(N+1,3) + C(N,3) for all N is Worpitzky's identity with Eulerian numbers ⟨3,k⟩ = 1, 4, 1; it is not formalised here (it is standard, and the chapter compares only N = 2 against N = 3).

          4. The two instances that decide the chapter #

          source
          theorem QOU.Eightfold.RowCapObstruction.eightfold_channels_at_two :
          weylDimSym 2 = 4 ∧ weylDimMixed 2 = 2 ∧ weylDimAlt 2 = 0 ∧ 2 ^ 3 = weylDimSym 2 + 2 * weylDimMixed 2 + weylDimAlt 2

          At N = 2: symmetric 4, mixed contributes 4, alternating 0; total 8 = 2³.

          The symmetric channel is a 4-dimensional spin-3/2 quadruplet, not a decuplet, and there is no singlet at all.

          source
          theorem QOU.Eightfold.RowCapObstruction.eightfold_channels_at_three :
          weylDimSym 3 = 10 ∧ weylDimMixed 3 = 8 ∧ weylDimAlt 3 = 1 ∧ 3 ^ 3 = weylDimSym 3 + 2 * weylDimMixed 3 + weylDimAlt 3

          At N = 3: symmetric 10 (decuplet), mixed 8 (octet, with multiplicity 2), alternating 1 (singlet); total 27 = 3³ — the eightfold way.

          theorem QOU.Eightfold.RowCapObstruction.decuplet_forces_three {N : ℕ} (h : weylDimSym N = 10) :
          N = 3

          The decuplet determines the flavour dimension. If the symmetric channel has dimension 10 then N = 3 — so the decuplet is not merely consistent with three flavours, it forces them.
