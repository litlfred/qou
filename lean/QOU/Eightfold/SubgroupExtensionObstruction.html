    QOU.Eightfold.SubgroupExtensionObstruction — the obstruction to extending a character #

    off a subgroup is a well-defined class

    Issue #7092's answer (main f7fee734c3) records that, on the exact L6a4 class-1 Ptolemy point over K = ℚ[T]/(f), the ratio r = σ_b(x)/D(x) is a coboundary for the GGZ decoration torus — a homomorphism r : L → Kˣ on the row lattice L = {e ∈ ℤ⁶ : ∑ e ≡ 0 mod 3} — but does not lift to a diagonal SL(3) matrix over K, because w := r(3e₀) is not a cube in K.

    w is the value at one lattice vector, and a claim about maps cannot rest on that: a different choice of e₀ gives a different w. This file supplies the invariant.

    What is proved #

    For a subgroup L ≤ M of abelian groups, an element e₀ : M with e₀ ^ n ∈ L, and a character r : L →* A:

    • liftObstruction_mul_mem — replacing e₀ by e₀ * ℓ with ℓ ∈ L multiplies the obstruction by r ℓ ^ n. So its class in A / Aⁿ does not depend on the choice, and whether that class is trivial is an invariant of r and of L ≤ M — not of the lattice vector picked to witness it.
    • pow_eq_of_extends — if r extends to a character R : M →* A, the obstruction is (R e₀) ^ n, an n-th power.
    • not_extends_of_not_isPow — the contrapositive, and the form the computation uses: a non-trivial obstruction class forbids every extension. So w failing to be a cube is not a fact about e₀; it rules out the SL(3) lift outright.

    Scope, stated precisely because the converse is the half that is missing #

    This is the direction that refutes. The converse — a trivial class implies an extension exists — needs M / L to be cyclic of order n generated by e₀, and is not proved here; nothing below should be read as asserting it. The refuting direction is the one the #7092 computation invokes, and it needs no hypothesis on the index at all.

    None of this says the obstruction is evidence about the open conjecture. Whether ρ ↦ ρ⁻ᵀ induces σ_b as a map on the variety is bean qou-qjhc, and is open. Since K contains ζ₃, Kummer theory identifies Kˣ/(Kˣ)³ ≅ H¹(K, μ₃), so this obstruction is μ₃-cohomological exactly as the representation-level class in H²(M, ∂M; ℤ/3) is — which is why the class, and not merely its non-triviality, is the object to look at.

    A

    The obstruction to extending r : L →* A across e₀, namely r (e₀ ^ n).

    Its class in A / Aⁿ is the invariant; the bare value depends on e₀, and liftObstruction_mul_mem says exactly how.

      liftObstruction L r hn' = liftObstruction L r hn * r ⟨ℓ, hℓ⟩ ^ n

      The obstruction is well defined modulo n-th powers. Moving the witness e₀ by an element of L multiplies it by an n-th power, so its class in A / Aⁿ — and in particular whether that class is trivial — is independent of the choice.
