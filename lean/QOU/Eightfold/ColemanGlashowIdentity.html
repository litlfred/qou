    def QOU.Eightfold.ColemanGlashowIdentity.mass {R : Type u_1} [CommRing R] (strong em : R) :
    R

    Octet baryon mass under first-order breaking: an isospin-multiplet strong part plus a U-spin-multiplet electromagnetic part.

    strong is the strong contribution shared by an isospin multiplet (P1); em is the electromagnetic shift shared by a U-spin multiplet (P2).

                    theorem QOU.Eightfold.ColemanGlashowIdentity.coleman_glashow_identity {R : Type u_1} [CommRing R] (N S X a b c : R) :
                    cgCombination N S X a b c = 0

                    Coleman–Glashow is an identity of the first-order ansatz. The combination vanishes for every choice of the three strong and three electromagnetic parameters, over any commutative ring.

                    The alternating structure is exactly what cancels the U-spin shifts: a appears in p and Σ⁺ with opposite sign, b in n and Ξ⁰, c in Σ⁻ and Ξ⁻.

                    theorem QOU.Eightfold.ColemanGlashowIdentity.cg_cannot_discriminate {R : Type u_1} [CommRing R] (N S X a b c N' S' X' a' b' c' : R) :
                    cgCombination N S X a b c = cgCombination N' S' X' a' b' c'

                    The discriminating-power statement. Two arbitrarily different breaking patterns — hence arbitrarily different physics — give the same value of the Coleman–Glashow combination, namely zero. The relation cannot tell them apart.

                    This is the analogue of GellMannOkuboIdentity.gmo_cannot_discriminate and DecupletEqualSpacing.equal_spacing_cannot_discriminate, with the same consequence: reproducing the relation is not evidence for any mechanism.

                    theorem QOU.Eightfold.ColemanGlashowIdentity.strong_only_all_splittings_vanish {R : Type u_1} [CommRing R] (N S X : R) :
                    m_p N S X 0 0 0 - m_n N S X 0 0 0 = 0 ∧ m_SigPlus N S X 0 0 0 - m_SigMinus N S X 0 0 0 = 0 ∧ m_XiZero N S X 0 0 0 - m_XiMinus N S X 0 0 0 = 0

                    With the electromagnetic shifts switched off, every splitting in the combination vanishes separately — so the relation is not a statement about the strong sector, and is empty without electromagnetism.

                    theorem QOU.Eightfold.ColemanGlashowIdentity.splittings_not_identically_zero :
                    ∃ (N : ℤ) (S : ℤ) (X : ℤ) (a : ℤ) (b : ℤ) (c : ℤ), m_p N S X a b c - m_n N S X a b c ≠ 0

                    The individual splittings are not identically zero, so coleman_glashow_identity is a genuine cancellation among nonzero terms rather than the trivial statement that nothing varies. Witnessed over ℤ.

                    theorem QOU.Eightfold.ColemanGlashowIdentity.cg_needs_both_premises {R : Type u_1} [CommRing R] (N S X a a' b c : R) :
                    m_p N S X a b c - m_n N S X a b c - (mass S a' - m_SigMinus N S X a b c) + (m_XiZero N S X a b c - m_XiMinus N S X a b c) = a - a'

                    Both premises are load-bearing. Drop (P2) — let the electromagnetic shift differ between the two members of a U-spin multiplet, so that p and Σ⁺ carry a and a' — and the combination no longer vanishes.

                    Stated by exhibiting the failure: with the Σ⁺ shift changed from a to a', the combination becomes a' − a, which is nonzero whenever the U-spin premise is genuinely violated. So Coleman–Glashow does test (P1) ∧ (P2); what it cannot do is discriminate among mechanisms that satisfy both.

                    theorem QOU.Eightfold.ColemanGlashowIdentity.cg_premise_violation_is_detectable :
                    ∃ (a : ℤ) (a' : ℤ), a - a' ≠ 0

                    And that failure is realisable: some choice makes it nonzero over ℤ.
