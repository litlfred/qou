    def QOU.Eightfold.GellMannOkuboIdentity.massSqQuadrupled {R : Type u_1} [CommRing R] (a b c fourCasimir Y : R) :
    R

    The first-order SU(3)-breaking mass operator, evaluated on a state of isospin Casimir I(I+1) and hypercharge Y:

    m²(I, Y)  =  a  +  b·Y  +  c·( I(I+1) − Y²/4 ).

    Multiplied through by 4 to stay division-free over a general CommRing, and parametrised by fourCasimir = 4·I(I+1) (an integer on every octet state), so this returns 4 m². GMO is homogeneous, so the overall factor is immaterial.

                theorem QOU.Eightfold.GellMannOkuboIdentity.gmo_identity {R : Type u_1} [CommRing R] (a b c : R) :
                2 * kaonAvgMassSqDoubled a b c = 3 * etaMassSq a b c + pionMassSq a b c

                Gell-Mann–Okubo is an identity of the first-order octet ansatz.

                4 m²_K  =  3 m²_η  +  m²_π

                holds for every choice of the breaking parameters a, b, c, over any commutative ring. (In the normalisation above: 2 · kaonAvgMassSqDoubled is 4 · (4 m²_K), matching 3 · (4 m²_η) + (4 m²_π) on the right.)

                The parameters cancel identically — b, the entire hypercharge dependence and hence the whole content of an SU(3)-breaking mechanism, does not survive. Consequently GMO constrains only the form of the breaking (octet, first order) and has no power to discriminate between mechanisms sharing that form. Reproducing GMO is therefore not evidence for any particular dynamics, QOU's included.

                theorem QOU.Eightfold.GellMannOkuboIdentity.gmo_cannot_discriminate {R : Type u_1} [CommRing R] (a b c a' b' c' : R) :
                2 * kaonAvgMassSqDoubled a b c - (3 * etaMassSq a b c + pionMassSq a b c) = 2 * kaonAvgMassSqDoubled a' b' c' - (3 * etaMassSq a' b' c' + pionMassSq a' b' c')

                The parameters are invisible to GMO. Two entirely different breaking patterns (a,b,c) and (a',b',c') — arbitrarily far apart, hence arbitrarily different physics — give the same value of the GMO combination, namely zero.

                This is the discriminating-power statement: GMO cannot tell them apart.
