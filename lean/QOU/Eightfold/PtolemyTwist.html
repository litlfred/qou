      Ptolemy equations with a μ₃ twist #

      source
      structure QOU.Eightfold.Ptolemy.TwistedEq (V : Type u_2) :
      Type u_2

      One equation of a Ptolemy variety carrying a μ₃-twist: a signed sum of monomials in the Ptolemy coordinates V, each term weighted by a power of the primitive cube root of unity. The twist field is the obstruction cocycle's contribution.

      This is a description of the shape snappy's equations were measured to have — see the file header. Nothing here claims that description is complete or canonical; it is the hypothesis under which the transport theorem below applies.

      • card : ℕ

        number of terms

      • sign : Fin self.card → ℤ

        the integer coefficient of each term (in practice ±1)

      • twist : Fin self.card → ZMod 3

        the exponent of u on each term — the obstruction cocycle

      • mono : Fin self.card → V → ℕ

        the monomial of each term, as exponents on the Ptolemy coordinates

                Non-emptiness is invariant. P^c has an R-point iff P^{−c} does.

                This is what retires the compute question for the Sym² gate: whatever is true of one twist is true of its negative, so the thirteen nontrivial L6a4 classes cannot be separated from each other by emptiness alone.

                theorem QOU.Eightfold.Ptolemy.eval_negTwist_one {R : Type u_1} [CommRing R] {V : Type u_2} [Fintype V] (E : TwistedEq V) (x : V → R) :
                E.negTwist.eval 1 x = E.eval 1 x

                The trivial cocycle is its own negative. At u = 1 — the trivial obstruction class — the twisted and negatively-twisted systems are literally the same equations, so transport is the identity and no σ is needed.

                This is the Lean counterpart of the one fixed point of c ↦ -c measured in computations/ptolemy/obstruction_gerbe_involution.py: H²(M, ∂M; ℤ/3) ≅ (ℤ/3)³ has order 27 and exactly one element with c = -c, the trivial one. It is also why the argument concludes what it does — the only class a self-dual representation could carry is the one this lemma is about.
