    QOU.Eightfold.OcneanuRankFamily — convention D is the rank-2 member of a #

    one-parameter family, and the rank is recoverable from the Markov parameter

    Bean qou-j3w6 (the condition-5 decision), epic qou-8lxd. Companion to QOU.QuantumObservableUniverse.VolumeFormDegree, which is the same N on the categorical side.

    The question this answers #

    Does the corpus's canonical Markov parameter z = q³/(q²+1) (convention D, owner ruling 2026-08-15 R1) correspond to a rank, and if the rank is left free is there a natural member at every N?

    Yes to both, and the two are the same N as the volume-form degree. computations/y_lambda_su_n.py already carries the N-parametrised weights — the principal specialisation s_λ(1, q, …, q^{N-1}) by hook-content — and every call site in the corpus passes N = 2. Evaluating the Markov parameter z = tr_M(σ) = y_{(2)}·q − y_{(1,1)}·q⁻¹ on those weights gives, symbolically and exactly,

    z_N = (q − q⁻¹) · q^{2N} / (q^{2N} − 1)

    which is markovParam below. Verified exact in sympy for N = 1 … 6 against that producer; z_2 = q³/(q²+1) on the nose, and numerically z_2(q₀) = 0.6126880371464652516 against the trace-convention registry's REG_ZD = 0.61268803714646524.

    The three facts, and why each matters #

    (1) z_2 IS convention D (markovParam_two). So the production trace is an SU(N) quantum-group trace, at N = 2. The corpus's canonical Markov parameter is not a free normalisation choice that happened to land somewhere — it is a rank commitment.

    (2) The rank is recoverable from the parameter (markovParam_strictAnti, markovParam_injective). For 1 < q the family is strictly decreasing in N, hence injective, so z determines N. This is what makes (1) a commitment rather than a coincidence: no other rank produces q³/(q²+1). It is also the Lean form of what ocneanu_N_lockin_probe.py measures numerically — the mass channel cannot be retuned to N = 3, because moving N moves z, and z is the trace the mass pipeline already evaluates. Flavour therefore needs a second trace on the same H_n(q), not a modified first one; QOU.Braiding.HnMarkovTrace.MarkovTraceTower already types the Markov parameter as a free class field, so two instances are typeable today.

    (3) The whole family sits between two limits (markovParam_gt_hecke, markovParam_one). z_1 = q is the gl(1) corner where only the fully symmetric block survives; z_N decreases strictly to q − q⁻¹, the coefficient of the Hecke relation itself σ² = (q − q⁻¹)σ + 1, which is the N → ∞ (uncapped, full-Hecke) value and is never attained. Every rank-N trace is (q − q⁻¹) plus the strictly positive excess (q − q⁻¹)/(q^{2N} − 1) (markovParam_sub_hecke), and that excess is exactly the row cap.

    The row cap, and its identity with the volume-form degree #

    RowCapObstruction.lean proves dim V_{(1^3)} = C(N,3) vanishes iff N < 3, i.e. Λ³ of a rank-N object needs N ≥ 3. Here the same cap arrives as arithmetic, from the hook-content numerator: a partition with more than N rows has a cell at position (N+1, 1), whose content is 1 − (N+1) = −N, so the numerator picks up the balanced quantum integer [N + (−N)]_q = [0]_q = 0 and the whole weight dies (cap_content, qIntBalanced_zero, rowCapFactor_eq_zero). Measured on the producer at n = 4: N = 1 survives only (4), N = 2 only ℓ(λ) ≤ 2, N = 3 only ℓ(λ) ≤ 3, N = 4 everything.

    That cap is the volume form. The last partition surviving at rank N is the single column (1^N), which is Λ^N of the fundamental — the determinant, Λ^N W ≅ 𝟙; the first to die is (1^{N+1}), i.e. Λ^{N+1}W = 0. So the N of VolumeFormDegree.rank_eq_of_volumeForm and the N of this trace are one number, approached from the categorical and the trace side respectively. In particular condition 5 of def:quantum-observable-universe (Λ²V ≅ 𝟙) and convention D (z = q³/(q²+1)) are the same commitment, stated twice.

    What is proved here, and what is not #

    Proved, sorry-free: every statement about markovParam and the row-cap arithmetic below — the closed form's specialisations, strict antitonicity and injectivity in N, the two-sided bracket, and the content computation that makes the cap automatic.

    Not proved, and asserted nowhere below:

    • that markovParam N is the Markov parameter of the SU(N) trace for general n. The n = 2 instance — which is where the Markov parameter is defined, z = tr_M(σ) on the two blocks of H_2(q) — is now proved sorry-free in QOU.Eightfold.HookContentMarkovParam.hookContent_markovParam, from the hook-content product over the four cells, for every N ≥ 1. The general hook-content principal-specialisation identity for arbitrary λ remains verified symbolically in sympy against the corpus producer for N = 1 … 6, and is cited rather than proved. (This bullet previously said the whole identity was uncited-and-unproved because "Mathlib has no hook-content API to state it against". That turned out not to be an obstruction: the n = 2 instance needs no such API — only [m]_q and one algebraic identity.)
    • that a rank-3 trace exists on the substrate's H_n(q) as a second structure compatible with axioms 1–4. Nothing here constructs one. This file says what its parameter would have to be — z_3 = q⁵/(q⁴+q²+1), ≈ 0.4493048091 at q₀ (markovParam_three) — which is a specification, not a construction.
    • anything about which rank the axioms supply. That is bean qou-j3w6.

    Base ring: ℝ, and the archimedean specialisation is genuine rather than gratuitous (§7c) — the ordering 1 < q is used essentially, both for q^{2N} ≠ 1 and for the strict monotonicity that carries the whole injectivity argument.
