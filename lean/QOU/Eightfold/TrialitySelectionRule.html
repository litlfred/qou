    QOU.Eightfold.TrialitySelectionRule — colour neutrality is a ℤ/3 grading #

    Bean qou-d7h1 (flavour SU(3) vs colour SU(3)), under epic qou-8lxd.

    What this is, and what it is NOT #

    The corpus carries triality in one sense already — the ζ₃ rotation of the three-strand Hecke datum, QOU.BraidsAndKnots threeStrand_cubes_to_one in three-strand-color-winding-rigidity.lean. That is a statement about a rotation having order three. It is not the selection rule, which is a statement about which composites can contain a singlet at all, and which the corpus does not carry: all five corpus-grep paths come back empty on the claim shape (singlet iff, contains a singlet, a mod-3 condition on a tensor product), as opposed to on the word "triality".

    The grading #

    For SU(N) the fundamental V and its conjugate V* generate a ℤ/N-graded monoid of tensor products: N-ality is +1 on V, −1 on V*, additive under ⊗, and an SU(N) singlet occurs in a product exactly when the total N-ality vanishes. At N = 3 this is triality. Written for an object built from a copies of 𝟑 and b copies of 𝟑̄:

    triality a b = a − b   in ℤ/3,      contains a singlet  ↔  triality a b = 0

    The equivalence is the model, cited from standard SU(3) representation theory, exactly as Sym2GateMultiplicity.sym2SingletCount is the model there — Mathlib has no SU(3) type, so the count is stated as a definition and labelled as one. Everything below the definition is derived.

    What is proved #

    • neutral_iff_mod — the grading in arithmetic form, a % 3 = b % 3.
    • The hadron table, each a consequence and not an assumption: meson_neutral (1,1), baryon_neutral (3,0), antibaryon_neutral (0,3), and the exclusions single_quark_not_neutral (1,0), diquark_not_neutral (2,0), four_quark_not_neutral (4,0). The observed exotics come out neutral: tetraquark_neutral (2,2), pentaquark_neutral (4,1).
    • triality_add / neutral_add — it really is a grading: additive under composition, and neutrality is closed under it.
    • identification_invisible_to_selection_rule — the proved negative: weighting the grading by a unit (2, the identified-groups case) changes no verdict.
    • neutral_decomposition and its converse decomposition_neutral — the content theorem. Every colour-neutral combination is m mesons together with n baryons and n' antibaryons, and every such combination is neutral. So the neutral monoid is generated by (1,1), (3,0), (0,3): mesons and baryons are not merely examples of neutral states, they exhaust them.

    diquark_not_neutral is the confinement statement in this language — a two-quark object cannot contain a colour singlet, at any q, for grading reasons alone.

    Relationship to the Sym² gate — DIFFERENT QUESTIONS, do not conflate #

    Sym2GateMultiplicity and Sym2GateComplexType count singlets in Sym²(W). This file counts singlets in W itself. Those are not the same question and the two criteria must not be read as one:

    • W = 𝟑: no singlet in W (triality 1 0 ≠ 0), and none in Sym²(W) = 𝟔 either. The two agree here, but by different routes.
    • W = 𝟑 ⊗ 𝟑 ⊗ 𝟑 (a baryon): a singlet is present in W (triality 3 0 = 0 — it is the ε tensor, totally antisymmetric), while the Sym²-gate machinery says nothing about it, because Λ³ is not Sym².

    Conflating them would be the arity slip AGENTS.md §"Grep the claim SHAPE" describes: two singlet-counting statements about different objects, sharing a word. They are complementary tools, not one tool.

    Bearing on the open question — a PROVED NEGATIVE, not a test #

    eightfold-open-problems.md lists as open whether the flavour and colour SU(3) are the same, different, or groupoid-dual. The obvious hope is that triality discriminates: if the groups are distinct a quark carries one fundamental index of each, while if they are identified it carries two indices of the one group, so its triality is 2 rather than 1, and the neutrality condition becomes 2(a − b) = 0 instead of a − b = 0.

    Those are the same condition, and identification_invisible_to_selection_rule proves it. 2 is a unit in ℤ/3, so multiplying the grading by it permutes the non-zero classes and fixes zero. Every composite gets the same verdict either way — meson, baryon, diquark, tetraquark, pentaquark alike.

    So the selection rule cannot distinguish the two cases, and any argument that reaches for it is dead on arrival. That is worth knowing precisely because it is the first thing one tries: the invariant proved above is real, but it is blind to the identification, and a search for the discriminator has to look somewhere the ℤ/3 grading does not reach. The question stays open; this file closes one route to it.

        3. The content theorem: mesons and baryons EXHAUST the neutral states #

        theorem QOU.Eightfold.TrialitySelectionRule.decomposition_neutral (m n n' : ℕ) :
        Neutral (m + 3 * n) (m + 3 * n')

        Anything built from m mesons, n baryons and n' antibaryons is neutral.

        source
        theorem QOU.Eightfold.TrialitySelectionRule.neutral_decomposition {a b : ℕ} (h : Neutral a b) :
        ∃ (m : ℕ) (n : ℕ) (n' : ℕ), a = m + 3 * n ∧ b = m + 3 * n'

        The converse, and the point of the file. Every colour-neutral combination is m mesons together with n baryons and n' antibaryons.

        So mesons and baryons are not merely examples of neutral states — the neutral monoid is generated by (1,1), (3,0) and (0,3), and there is no third kind of colour-neutral composite to look for.

        4. The grading is blind to the flavour/colour identification #

        source
        def QOU.Eightfold.TrialitySelectionRule.trialityWeighted (k a b : ℕ) :
        ZMod 3

        Weighted triality. If each quark carries k fundamental indices of the group, its triality is k and a composite of a quarks and b antiquarks has grading k·(a − b).

        k = 1 is the case where colour and flavour are distinct groups (one colour index per quark); k = 2 is the case where they are identified (the colour and flavour indices become two indices of the same group).

          5. Triality certifies COMPLEX TYPE — the input Sym2GateFSTrichotomy needs #

          Sym2GateFSTrichotomy.gate_forces_complex_of_dim_three says a three-dimensional object passing the Sym² gate must be complex type, and leaves complex type as an input. The grading supplies it: duality negates triality, and in ℤ/3 an element equals its own negation only when it is zero.

          The same unit fact — 2 invertible in ℤ/3 — that makes the grading blind to the flavour/colour identification also makes it sharp about self-duality. One arithmetic fact, a negative result and a positive one.

          source
          theorem QOU.Eightfold.TrialitySelectionRule.triality_dual (a b : ℕ) :
          triality b a = -triality a b

          Duality exchanges fundamentals and antifundamentals, hence negates triality.

          theorem QOU.Eightfold.TrialitySelectionRule.triality_eq_zero_of_selfDual {a b : ℕ} (h : triality b a = triality a b) :
          triality a b = 0

          Self-duality forces vanishing triality. In ℤ/3, −x = x gives 2x = 0, and 2 is a unit.

          The certificate. An object of non-vanishing triality is not self-dual — so it is complex type, not real and not quaternionic.

          source
          theorem QOU.Eightfold.TrialitySelectionRule.fundamental_not_selfDual :
          triality 0 1 ≠ triality 1 0

          The fundamental 𝟑 is complex type. Its triality is 1 ≠ 0, so it is not isomorphic to its dual.

          This is the fact Sym2GateFSTrichotomy leaves as an input, obtained here from the grading rather than cited. What remains cited for the octonionic route is the other half: that the Günaydin–Gürsey decomposition Im(𝕆) ≅ ℝ ⊕ ℂ³ puts SU(3) on that ℂ³ in its standard fundamental representation. Given that, complex type is no longer an assumption.
