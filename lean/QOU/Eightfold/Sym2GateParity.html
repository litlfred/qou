    QOU.Eightfold.Sym2GateParity — the Sym² gate is decided by PARITY, not self-duality #

    Companion to QOU.Eightfold.Sym2Gate, and the formal record of a correction.

    What this file is for #

    The Sym² gate is the requirement that Sym²(W) contain no singlet — the condition an SU(3)-triplet candidate W must satisfy, since Sym²(𝟑) = 𝟔 is irreducible precisely because 𝟑̄ ≠ 𝟑.

    The compute probe computations/state_space_natural_three_sym2_gate.py originally argued: every SU(2) representation is self-dual, therefore no summand of any V^⊗n can pass the gate. That inference is invalid. Self-duality splits by the Frobenius–Schur indicator:

    dim d = 2j+1 spin FS invariant form singlet lives in gate
    odd integer +1 symmetric (orthogonal) Sym² fails
    even half-integer −1 antisymmetric (symplectic) Λ² passes

    so the 2-dimensional fundamental — self-dual, but symplectically — passes the gate. This file formalises the criterion that actually decides it.

    The combinatorial content #

    Clebsch–Gordan gives V_j ⊗ V_j = ⨁_{k=0}^{2j} V_k, and the summands split between Sym² and Λ² by the parity of 2j − k: Sym²(V_j) collects exactly those k ≤ 2j with k ≡ 2j (mod 2). The gate therefore fails precisely when the singlet index k = 0 survives that filter, i.e. precisely when 2j is even, i.e. precisely when d = 2j + 1 is odd.

    Everything below is stated over 2j (twoJ) rather than d to keep the arithmetic subtraction-free.

    Why the correction leaves the physics conclusion intact #

    Colour needs dim W = 3, which is odd, hence orthogonal, hence fails the gate (adjoint_fails_gate). So a triplet still cannot be found among the summands of V^⊗n for a 2-dimensional fibre, and the downstream collapse argument in docs/audits/2026-08-07-eightfold-live-surface-collapse.md stands. What was wrong was only the stated generality — even-dimensional summands do pass, and they are simply the wrong dimension.

    self_duality_does_not_decide_gate records the counterexample pair formally, so the invalid inference cannot be re-derived from this file.

    -- Ref: [fulton-harris1991] §11 (Clebsch–Gordan for sl₂); Frobenius–Schur -- indicator (-1)^{2j} for the spin-j irrep of SU(2).

    def QOU.Eightfold.Sym2GateParity.sym2Indices (twoJ : ℕ) :
    Finset ℕ

    Indices k of the SU(2) irreps V_k occurring in Sym²(V_j), where twoJ = 2j. Clebsch–Gordan supplies k ≤ 2j; the symmetric square keeps exactly those k congruent to 2j mod 2.
