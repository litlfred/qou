    QOU.Eightfold.WeylInvarianceQDeformation — A₂ root datum is q-independent #

    Bean qou-d9wj (T1), epic qou-8lxd.

    The Drinfeld–Jimbo quantisation replaces the binomial coefficient 2 = C(2,1) in the classical Serre relation with the Gaussian binomial [2]_q = q + q⁻¹. The Cartan matrix entry a₁₂ = -1 (which determines the root angle cos θ = -1/2, hence θ = 120°) is not touched by the q-deformation.

    This file proves:

    1. gaussianBinomial2_classical: at q = 1, [2]_q = 2 (the classical limit).
    2. cartanMatrixAt_const: the A₂ Cartan datum is constant in q — true by construction, no content on its own (see its docstring).
    3. qSerre_not_constant: the Serre coefficient genuinely moves with q (witness at q = 2). This is the half with content.
    4. cartan_fixed_while_qSerre_moves: the conjunction of 2 and 3 — the "two 2s" separation, which is the file's actual claim.
    5. qSerre_neq_cartan_diag: for (q-1)² ≠ 0, the Gaussian binomial [2]_q differs from the diagonal Cartan entry 2.
    6. root_angle_ratio_A2: the root angle ratio a₁₂/a₁₁ = -1/2 is q-independent, stated division-free over ℤ as the cross-multiplied 2·a₁₂ = -a₁₁.

    Scope — what this file does NOT establish #

    It does not prove that Drinfeld–Jimbo quantisation leaves the root datum invariant. That is a theorem of Lusztig/Kashiwara, cited by the chapter and not formalised here. What is formalised is the arithmetic of the "two 2s" separation on the A₂ datum. Anything citing this file as machine-checked evidence for q-independence of the eightfold classification is over-reading it.

          theorem QOU.Eightfold.WeylInvarianceQDeformation.qSerre_neq_cartan_diag (R : Type u_1) [CommRing R] (q : R) (hq : (q - 1) ^ 2 ≠ 0) :
          gaussianBinomial2Framed R q ≠ 2 * q

          For q ≠ 1 — stated as (q - 1)² ≠ 0, the honest upstream hypothesis — the framed Gaussian binomial differs from the framed Cartan diagonal. The Cartan entry stays 2; the Serre coefficient moves. They are different mathematical objects.

          The hypothesis is genuinely upstream of the conclusion: the proof supplies the identity (q² + 1) - 2q = (q - 1)². (An earlier version took q² + 1 ≠ 2q as the hypothesis, which is definitionally the conclusion — it assumed what it claimed to prove.)

          theorem QOU.Eightfold.WeylInvarianceQDeformation.qSerre_not_constant :
          ∃ (q : ℤ), gaussianBinomial2Framed ℤ q ≠ 2 * q

          The Serre coefficient genuinely moves with q: it is not a constant function, witnessed at q = 2 where the framed binomial is 5 and the framed Cartan diagonal is 4.

          This is the half of the "two 2s" separation that has content — without it, cartanMatrixAt_const is compatible with both sides being constant, which is precisely the confusion the file exists to dispel.

          theorem QOU.Eightfold.WeylInvarianceQDeformation.root_angle_ratio_A2 :
          2 * cartanMatrix_A2 0 1 = -cartanMatrix_A2 0 0

          The root angle cos θ = a₁₂/a₁₁ = -1/2, hence θ = 120°. Both entries are fixed integers, so the ratio is q-independent.

          §7c: stated division-free over the Cartan datum's own ring ℤ, as the cross-multiplied identity 2·a₁₂ = -a₁₁. This is the R[h] pattern — the ratio claim a₁₂/a₁₁ = -1/2 is recovered from it in any ℚ-algebra by dividing through by the unit a₁₁ = 2, so nothing is lost by not passing to ℚ, and the integrality of the Cartan entries stays visible.
