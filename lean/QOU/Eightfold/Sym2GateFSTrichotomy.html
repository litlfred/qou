    QOU.Eightfold.Sym2GateFSTrichotomy — a dimension-3 gate pass FORCES complex type #

    Unifies QOU.Eightfold.Sym2GateMultiplicity (the self-dual sector) and QOU.Eightfold.Sym2GateComplexType (the complex sector) into one count over the full Frobenius–Schur trichotomy, and derives the statement neither file can make alone.

    The question this answers #

    Bean qou-8pl3 Route B records the chapter's argument that the octonionic SU(3) and the icosahedral colour triple cannot both come from one construction, "since the Sym² gate excludes the icosahedral colour triple T₁ while the G₂ route passes it". That is a case analysis over two examples. What is actually at work is a property of Frobenius–Schur type: T₁ is a rotation representation of A₅ ⊂ SO(3) and hence real, while the Günaydin–Gürsey triple in Im(𝕆) ≅ ℝ ⊕ ℂ³ is complex.

    Neither companion file can say so. Sym2GateMultiplicity models FS = ±1 only; Sym2GateComplexType models FS = 0 only. The statement needs one count over all three types, which is what this file supplies.

    The theorem #

    gate_forces_complex_of_dim_three — any object of dimension 3 that passes the Sym² gate must contain a complex-type irrep.

    So the exclusion of T₁ is not a fact about the icosahedron and the pass of the G₂ triple is not a fact about octonions: both are consequences of Frobenius–Schur type, and no real or quaternionic construction whatever can supply a three-dimensional object through this gate. The chapter's two-example comparison becomes a corollary (real_triple_fails_gate).

    The count #

    For W ≅ ⨁ mᵢ Vᵢ, the singlets of Sym²(W) are counted per type:

    FS(Vᵢ) invariant form multiplicity-space contribution
    +1 real (orthogonal) symmetric Sym², C(mᵢ+1, 2)
    −1 quaternionic (symplectic) antisymmetric Λ², C(mᵢ, 2)
    0 complex none on Vᵢ itself mᵢ · m_{dual i}, from Vᵢ ⊗ Vᵢ*

    As in both companions, the count is the model — cited standard representation theory, not derived, since Mathlib has no representation-type machinery. Two further standard facts are carried explicitly as hypotheses rather than smuggled in:

    • QuaternionicEvenDim — a quaternionic irrep has even dimension (it is an ℍ-module). This is what the parity argument actually runs on, and Sym2GateMultiplicity obtained it from the SU(2) formula dim = 2j + 1; here there is no such formula, so it is a hypothesis.
    • ComplexNotSelfDual — a complex-type irrep is not its own dual.

    Making them hypotheses is the point: the theorem then says exactly which standard inputs the conclusion needs, and a reader can see that no fact about octonions or icosahedra is among them.

    The complex-type input, and how much of it is now derived #

    This file leaves complex type as an input. TrialitySelectionRule supplies half of it: duality negates triality, and in ℤ/3 an element equals its own negation only when it is zero, so an object of non-vanishing triality is not self-dual (not_selfDual_of_triality_ne_zero). The fundamental has triality 1, hence fundamental_not_selfDual — complex type, derived rather than cited.

    What remains cited is the other half, and it is genuinely about octonions: that the Günaydin–Gürsey decomposition Im(𝕆) ≅ ℝ ⊕ ℂ³ puts SU(3) on that ℂ³ in its standard fundamental representation. Given that, complex type is no longer an assumption anywhere in the chain.

    So bean qou-8pl3 Route B gap (i) narrows rather than closes: it was "the Sym² pass is a literature decomposition", and what is left is the smaller claim that the triple carries the fundamental. This file says what complex type buys once you have it and what real type costs; TrialitySelectionRule says what certifies it.

    Nor does it bear on the flavour/colour identification: TrialitySelectionRule shows the ℤ/3 grading is blind to that, and nothing here changes it.

    Base ring (§7c) #

    Pure combinatorics over ℕ. No ring, no ordering, no archimedean content.

    -- Ref: [fulton-harris1991] §3.5, §11 (the Frobenius–Schur trichotomy; the -- invariant bilinear form is symmetric for FS = +1, antisymmetric for -- FS = −1, absent for FS = 0; quaternionic irreps carry an ℍ-module -- structure and so have even dimension). -- Ref: [gunaydin-gursey1973] (the Im(𝕆) ≅ ℝ ⊕ ℂ³ decomposition under -- SU(3) ⊂ G₂, cited for the complex type of the triple, not derived here).

                  The theorem. A three-dimensional object that passes the Sym² gate must contain a complex-type irrep.

                  Real and quaternionic constructions are excluded as a class: the real multiplicities are forced to zero and the quaternionic dimensions are even, so the total is even and cannot be 3. Complex type is not one way among several to reach dimension three through this gate — it is the only way.

                  6. The gate CANNOT separate flavour from colour #

                  eightfold-open-problems.md item 4 concludes that flavour and colour SU(3) "cannot both come from the same construction: the Sym² gate excludes the icosahedral colour triple T₁, while the G₂ route passes it."

                  The premise concerns two different objects receiving different verdicts, which establishes that those two objects differ. The conclusion is about one construction supplying two roles, which does not follow from it.

                  gate_forces_complex_of_dim_three makes the failure structural rather than merely a gap in the inference: at dimension three, passing is equivalent to carrying a complex-type irrep. So any two three-dimensional objects that both pass are both complex type, and the gate has returned the same verdict for both. A flavour triple and a colour triple that each pass are, to this gate, indistinguishable.

                  The witnesses below exhibit exactly that: two genuinely distinct three-dimensional objects, both passing. The gate is not merely silent on the flavour/colour question — it is provably blind to it, in the same way TrialitySelectionRule.identification_invisible_to_selection_rule shows the ℤ/3 grading is.
