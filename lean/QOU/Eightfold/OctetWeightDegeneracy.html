    Weights #

    A weight is the pair (2I₃, Y). Isospin is doubled so that every entry is an integer; the doubling is a relabelling and changes no statement below.

          The consequence for mass formulae #

          source
          theorem QOU.Eightfold.OctetWeightDegeneracy.weight_function_cannot_separate_lambda_sigma0 {S : Type u_2} (f : Weight → S) (wLam wSig : Weight) :
          wLam = (0, 0) → wSig = (0, 0) → f wLam = f wSig

          No function of the weight can separate Λ from Σ⁰. There is no cleverness available, because the two states hand f the same argument — so the statement needs no structure on the target at all, not even a ring — hence the local {S : Type*} rather than the file's [CommRing R]. Weakening the hypothesis is the point: no target structure can rescue the class.

          A mass formula depending only on (2I₃, Y) therefore predicts m_Λ = m_Σ⁰. Experiment gives 1115.7 against 1192.6 MeV, so the entire class is excluded.

            Isospin is not a function of the weight. Two octet states share the weight (0, 0) while carrying I = 1 and I = 0, so no map Weight → ℤ reproduces the isospin column. This is what the octet needs and the weight cannot give.

            Channel arithmetic — keeping the two "twos" apart #

            source
            theorem QOU.Eightfold.OctetWeightDegeneracy.schur_weyl_cube_arithmetic :
            10 * 1 + 8 * 2 + 1 * 1 = 3 ^ 3

            The Schur–Weyl channel count at N = 3, n = 3: 27 = 10·1 + 8·2 + 1·1.

            The 2 here is dim S^{(2,1)}, the Hecke-module multiplicity of the octet inside V^{⊗3}. It is not the Λ/Σ⁰ degeneracy of lambda_sigma0_same_weight, which is a count of states over one lattice point within a single octet. The two facts are stated in the same file so that the distinction is visible, not so that they can be merged.

            theorem QOU.Eightfold.OctetWeightDegeneracy.octet_deficit_is_one :
            octetWeights.length - octetWeights.dedup.length = 1 ∧ decupletWeights.length - decupletWeights.dedup.length = 0
