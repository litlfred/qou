    def QOU.Eightfold.NonetMixingUnconstrained.charPoly {R : Type u_1} [CommRing R] (d₁ d₂ e x : R) :
    R

    The characteristic polynomial of the symmetric 2 × 2 nonet mass matrix

        ⎡ d₁  e ⎤
    ⎣ e   d₂ ⎦

    written out as x² − (trace)·x + (determinant). Stated as a plain polynomial expression rather than via Matrix.charpoly so that the statement stays elementary and division-free.

      theorem QOU.Eightfold.NonetMixingUnconstrained.charPoly_factors_of_trace_det_match {R : Type u_1} [CommRing R] (d₁ l₁ l₂ x : R) {d₂ esq : R} (hd : d₂ = l₁ + l₂ - d₁) (he : esq = (d₁ - l₁) * (l₂ - d₁)) :
      x ^ 2 - (d₁ + d₂) * x + (d₁ * d₂ - esq) = (x - l₁) * (x - l₂)

      The key identity. With the octet entry d₁ held fixed — it is what Gell-Mann–Okubo determines — the singlet entry d₂ and the mixing e can be chosen so that the characteristic polynomial is exactly (x − l₁)(x − l₂), for any targets l₁, l₂.

      Both choices are forced and explicit: d₂ = l₁ + l₂ − d₁ (matching the trace) and e² = (d₁ − l₁)(l₂ − d₁) (matching the determinant).

      theorem QOU.Eightfold.NonetMixingUnconstrained.mixing_unconstrained {R : Type u_1} [CommRing R] (d₁ l₁ l₂ : R) :
      ∃ (d₂ : R) (esq : R), ∀ (x : R), x ^ 2 - (d₁ + d₂) * x + (d₁ * d₂ - esq) = (x - l₁) * (x - l₂)

      The nonet mixing is unconstrained by the octet-breaking ansatz.

      Given the octet member d₁ that GMO fixes, every pair of physical masses (l₁, l₂) is realised by some singlet entry d₂ and some squared mixing esq. The ansatz therefore says nothing about where the physical states sit or how strongly they mix.

      Contrast GellMannOkuboIdentity.gmo_cannot_discriminate and DecupletEqualSpacing.equal_spacing_cannot_discriminate, where the ansatz forces the answer and the relation is consequently content-free. Here it forces nothing, so the measured mixing is information — and deriving it would be a real prediction.

      theorem QOU.Eightfold.NonetMixingUnconstrained.charPoly_zero_mixing_eq_linear_factors {R : Type u_1} [CommRing R] (d₁ d₂ x : R) :
      charPoly d₁ d₂ 0 x = (x - d₁) * (x - d₂)

      Zero mixing is exactly the unmixed case. When e = 0 the characteristic polynomial factors as (x − d₁)(x − d₂), i.e. the physical masses are the octet and singlet entries and no mixing occurs.

      The mixing is therefore carried entirely by e: it is the single parameter the symmetry leaves free, and the one whose observed value the vector and pseudoscalar nonets disagree about.

      Non-degeneracy controls #

      Without these, mixing_unconstrained could be satisfied vacuously by targets that force esq = 0, i.e. by no mixing at all.

      ∃ (d₁ : ℤ) (l₁ : ℤ) (l₂ : ℤ), (d₁ - l₁) * (l₂ - d₁) ≠ 0

      The construction genuinely requires nonzero mixing whenever the octet member lies strictly between the two physical masses — which is the observed situation in both nonets. Witnessed over ℤ at d₁ = 1, l₁ = 0, l₂ = 2: esq = (1 − 0)(2 − 1) = 1 ≠ 0.
