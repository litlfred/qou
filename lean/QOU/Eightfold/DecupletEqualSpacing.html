    def QOU.Eightfold.DecupletEqualSpacing.massQuadrupled {R : Type u_1} [CommRing R] (a b c fourCasimir Y : R) :
    R

    The first-order SU(3)-breaking mass operator, quadrupled to stay division-free:

    4 m(I, Y)  =  4a  +  4b·Y  +  c·( 4I(I+1) − Y² ).

    Identical in form to GellMannOkuboIdentity.massSqQuadrupled; the decuplet is conventionally fitted with masses rather than masses-squared, but the identity below is insensitive to that choice — it uses only the shape of the operator.

              The structural cause #

              theorem QOU.Eightfold.DecupletEqualSpacing.casimir_collapses_of_isospin_affine {R : Type u_1} [CommRing R] (Y fourCasimir : R) (h : fourCasimir = (Y + 2) * (Y + 4)) :
              fourCasimir - Y ^ 2 = 6 * Y + 8

              The decuplet's Casimir term is affine in Y. Whenever the isospin is affine in the hypercharge in the decuplet's pattern — encoded division-free as fourCasimir = (Y + 2)(Y + 4), which is 4·I(I+1) at 2I = Y + 2 — the quadratic combination 4I(I+1) − Y² collapses to 6Y + 8.

              This is the whole mechanism: the Y² cancels, so the breaking operator becomes affine in Y and equal steps in Y give equal steps in mass.

              theorem QOU.Eightfold.DecupletEqualSpacing.equal_spacing {R : Type u_1} [CommRing R] (a b c : R) :
              sigmaStarMass a b c - deltaMass a b c = xiStarMass a b c - sigmaStarMass a b c ∧ xiStarMass a b c - sigmaStarMass a b c = omegaMass a b c - xiStarMass a b c

              The decuplet equal-spacing rule is an identity of the first-order octet ansatz. All three consecutive spacings coincide for every a, b, c, over any commutative ring.

              a drops out (it is the common centroid) and the pattern of the breaking survives only as the single number −4b − 6c. Two mechanisms with different (b, c) but the same 4b + 6c are indistinguishable here, and every mechanism whatsoever satisfies the equality of the three spacings.

              theorem QOU.Eightfold.DecupletEqualSpacing.omega_eq_two_xi_minus_sigma {R : Type u_1} [CommRing R] (a b c : R) :

              theorem QOU.Eightfold.DecupletEqualSpacing.equal_spacing_cannot_discriminate {R : Type u_1} [CommRing R] (a b c a' b' c' : R) :
              omegaMass a b c - xiStarMass a b c - (xiStarMass a b c - sigmaStarMass a b c) = omegaMass a' b' c' - xiStarMass a' b' c' - (xiStarMass a' b' c' - sigmaStarMass a' b' c')

              The discriminating-power statement. Two arbitrarily different breaking patterns (a,b,c) and (a',b',c') — hence arbitrarily different physics — give the same value of the equal-spacing combination, namely zero. Equal spacing cannot tell them apart.

              This is the decuplet analogue of GellMannOkuboIdentity.gmo_cannot_discriminate, and it carries the same consequence: reproducing the rule is not evidence for any mechanism.

                  theorem QOU.Eightfold.DecupletEqualSpacing.octet_casimir_not_function_of_hypercharge :
                  ∃ (Y : ℤ) (k₁ : ℤ) (k₂ : ℤ), k₁ ≠ k₂ ∧ (Y, k₁) ∈ octetStates ∧ (Y, k₂) ∈ octetStates

                  On the baryon octet the Casimir is not a function of the hypercharge. Two distinct octet states share Y = 0 while carrying different 4·I(I+1) — Σ at 8 and Λ at 0. Hence no substitution fourCasimir = g(Y) exists for the octet, and casimir_collapses_of_isospin_affine has nothing to act on: the decuplet's collapse to an affine mass operator has no octet counterpart.

                  This is what stops the equal-spacing argument from being read as a generic fact about SU(3) multiplets. The claim is derived from octetStates, not asserted.
