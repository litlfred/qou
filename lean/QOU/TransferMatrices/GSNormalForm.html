    The Hecke-only Gröbner–Shirshov reduction: the two steps the appendix argues #

    prop:tm-gs-normal-form claims that reducing the block-ordered nucleus element Ξ_A uses only the Hecke rule σᵢ² → (q − q⁻¹)σᵢ + 1 — zero Yang–Baxter and zero far-commutativity steps — that it terminates in the chain form ∏ᵢ (aᵢσᵢ + bᵢ) whose coefficients follow the transfer-matrix recurrence, and that the subset expansion of that chain is the exact Gröbner–Shirshov normal form.

    What is formalised here, and why these pieces #

    The appendix's proof rests on exactly two things it argues rather than cites, and both are formalised below. Everything it cites — confluence of the rewriting system, via Bergman's Diamond Lemma — is left cited.

    1. The block computation (hecke_linear_mul, heckeStep_eq_transferMatrix). Multiplying two linear forms in a single generator and applying the Hecke rule once yields a linear form again, with coefficients

    a' = a·c·qq + a·d + b·c ,      b' = a·c + b·d ,

    and that pair is exactly T(c,d) ⬝ᵥ (a,b). This is the inductive step's entire algebraic content, and it is falsifiable in the strong sense: it is derived from the Hecke relation via linear_combination (a*c) • hσ, so perturbing the relation — a sign on the +1, a different scalar — changes the matrix and breaks the theorem. transferMatrix_scalar_crossing records the degenerate case the prose flags parenthetically: at c = 0 the transfer matrix is d • 1, so a purely scalar crossing costs no Hecke step at all.

    2. Normality of the chain expansion (no_hecke_pattern, no_farComm_pattern, no_yangBaxter_pattern). The proof's "Normality of the expansion" paragraph argues that a monomial σ_S — each generator at most once, indices strictly increasing — contains none of the three leading words, hence is irreducible. That is a purely combinatorial claim about strictly increasing lists, and it is proved here for all three rule families. This is what makes "the expansion is the normal form" a theorem rather than an assertion.

    heckeStepBound records the appendix's step accounting C(A,2) − (A−1) = C(A−1,2) as a derived consequence, via Pascal — not as a substitute for the above.

    Honest scope #

    This does not formalise the proposition. Three things are missing, and none should be read in.

    1. No Hecke algebra. There is no construction of H_A(q) here, and no Gröbner–Shirshov basis for it. The block computation is stated for an arbitrary commutative ring containing an element σ satisfying the Hecke relation. That is legitimate for the block step — the computation happens inside the subalgebra generated by a single σᵢ, which is commutative — but it means the noncommutativity of H_A(q) is nowhere exercised.
    2. No confluence. Uniqueness of the normal form rests on the Diamond Lemma, cited to Bergman. Nothing here proves it, and the normality theorems below establish only that chain monomials are irreducible, not that reduction is confluent.
    3. No global induction. The proposition's headline — that the whole reduction of Ξ_A incurs zero Yang–Baxter and zero far-commutativity steps — needs the appendix's block-locality argument (that no such pattern ever arises across block boundaries during reduction). That argument is prose here; what is proved is the block-local step and the irreducibility of the final words.

    So this discharges the two load-bearing computations and leaves the structural claim narrative.

    The Hecke scalar #

    Carried as a unit q : Rˣ over a CommRing rather than as an element of a field: the only inverse the rewriting rule needs is q⁻¹, and a Units inverse realises it without assuming division (CLAUDE.md §7c base-ring minimality).

      1. The block computation #

      source
      theorem QOU.TransferMatrices.GSNormalForm.hecke_linear_mul {R : Type u_1} [CommRing R] (σ qq c d a b : R) (hσ : σ ^ 2 = qq * σ + 1) :
      (c * σ + d) * (a * σ + b) = (a * c * qq + a * d + b * c) * σ + (a * c + b * d)

      The block step. In any commutative ring containing σ with σ² = qq·σ + 1, the product of two linear forms in σ is again linear, with the stated coefficients.

      This is the inductive step of the appendix's proof. It is derived from the Hecke relation, not asserted alongside it: the linear_combination certificate is (a*c) * hσ, so the relation is genuinely load-bearing and a perturbed relation gives a different — false — statement.

        2. Normality of the chain expansion #

        A chain monomial σ_S is recorded by its list of generator indices, which is strictly increasing. The three theorems below say it contains no leading word of any of the three rule families, i.e. it is irreducible.

        source
        theorem QOU.TransferMatrices.GSNormalForm.no_hecke_pattern {w : List ℕ} (h : List.IsChain (fun (x1 x2 : ℕ) => x1 < x2) w) (i : ℕ) :
        ¬[i, i] <:+: w

        No Hecke pattern. A strictly increasing index word has no repeated adjacent letter, so no subword σᵢσᵢ — the leading word of the Hecke rule.

        source
        theorem QOU.TransferMatrices.GSNormalForm.no_farComm_pattern {w : List ℕ} (h : List.IsChain (fun (x1 x2 : ℕ) => x1 < x2) w) (i j : ℕ) (hij : i + 2 ≤ j) :
        ¬[j, i] <:+: w

        No far-commutativity pattern. Its leading word is σⱼσᵢ with j ≥ i + 2; adjacent letters in a strictly increasing word satisfy j < i instead.

        source
        theorem QOU.TransferMatrices.GSNormalForm.no_yangBaxter_pattern {w : List ℕ} (h : List.IsChain (fun (x1 x2 : ℕ) => x1 < x2) w) (i j : ℕ) :
        ¬[j, i, j] <:+: w

        No Yang–Baxter pattern. Its leading word is σⱼσᵢσⱼ, which repeats the letter σⱼ; a strictly increasing word is injective along adjacencies, so j < i < j is impossible.

        3. The step accounting, as a consequence #

        source
        theorem QOU.TransferMatrices.GSNormalForm.heckeStepBound {A : ℕ} (hA : 1 ≤ A) :
        A.choose 2 - (A - 1) = (A - 1).choose 2

        C(A,2) − (A−1) = C(A−1,2) — the appendix's Hecke-step budget: one reduction per crossing after the first at each generator. Stated after the computations above and proved via Pascal, so the arithmetic reads as bookkeeping rather than as the content.
