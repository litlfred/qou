    abbrev QOU.HeckeAlgebra.Wedderburn.RegIndex (n : ℕ) :
    Type

    The regular-representation index. Each partition λ ⊢ n contributes f^λ copies of an f^λ-dimensional space, so the cardinality is Σ_λ (f^λ)² — the number RSK identifies with n!.

      noncomputable def QOU.HeckeAlgebra.Wedderburn.blockDiagonal {n : ℕ} (x : WedderburnDecomposition n) :
      Matrix (RegIndex n) (RegIndex n) ℝ

      Block-diagonal assembly, constructed. The entry at (λ, m, i), (μ, m', j) is x_λ i j when the partitions and the multiplicity indices agree, and 0 otherwise. No axiom, and no dimension identity: the target index type is the one the decomposition naturally lives on.

        The assembly is injective — it is an embedding. Two decompositions with the same block-diagonal matrix agree block by block, read off at multiplicity index 0, which exists because 0 < f^λ.

        The positivity is taken as an explicit argument rather than invoked, and that is deliberate — though the reason first given for it was about the container, and that part is now wrong. Discharge it with

        source
        theorem QOU.HeckeAlgebra.Wedderburn.blockDiagonal_trace {n : ℕ} (x : WedderburnDecomposition n) :
        (blockDiagonal x).trace = ∑ lam : n.Partition, ↑(Hoefsmit.seminormalDim lam) * Matrix.trace (x lam)

        The regular-representation trace formula. blockDiagonal places block λ along the diagonal once for each multiplicity index m : Fin (f^λ), so its trace weights each block trace by f^λ:

        trace (blockDiagonal x) = Σ_λ f^λ · trace (x λ)

        Unconditional — no RSK, no positivity. This is the identity QOU/HeckeAlgebra/MarkovTrace.lean's module doc used to advertise for wenzlBridge and which nothing proved, because until blockDiagonal existed there was no embedding to state it over.

        It is also a check on the construction rather than only a lemma about it: had the multiplicity been mis-indexed in blockDiagonal, the coefficient here would come out 1 or (f^λ)² and the proof would not close.

        The one missing ingredient, written down instead of assumed: the Robinson–Schensted–Knuth dimension identity Σ_λ (f^λ)² = n!. Everything above is independent of it; everything below is explicitly conditional on it.
