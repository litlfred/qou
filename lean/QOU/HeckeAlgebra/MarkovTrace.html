    QOU.HeckeAlgebra.MarkovTrace — extended Markov-trace structure #

    Builds on the abstract markovTrace axiom in QOU.HeckeAlgebra.Common to expose the categorical structure needed by the QOU mass formula M = ρ · m_e · |tr_M(T_w)|:

    • The Markov property (cyclic invariance under conjugation)
    • The Wenzl bridge: tr_M(β) = Σ_{λ ⊢ n} y_λ(q) · χ^λ(β) where y_λ are the Jones-Markov central coefficients and χ^λ is the trace of β in the irrep V_λ (Hoefsmit seminormal rep).

    What this module provides #

    • MarkovProperty — axiomatised cyclicity / Markov-axiom property

    • JonesMarkovCoefficient λ q — y_λ(q) central coefficients

    • wenzlBridge — markovTraceOnWedderburn x = Σ_λ y_λ(q_0) · trace (x λ).

      This list used to advertise that identity as markovTrace n (wedderburnEmbed x) = Σ_λ y_λ(q_0) · trace (x λ), which overstates it in two ways and is corrected here (2026-09-05, bean qou-kp2z). The theorem's left-hand side is markovTraceOnWedderburn, whose definition is that very sum, so wenzlBridge is proved by rfl — it unfolds a definition rather than connecting two independently-given quantities. And it never mentioned wedderburnEmbed: nothing in this module did, outside this sentence. Relating a trace on the assembled matrix algebra to the block sum is genuine content, and it is now proved — in QOU/HeckeAlgebra/WedderburnTrace.lean, over the constructed blockDiagonal. What is still not proved is that identity with markovTrace itself on the left: markovTrace is opaque in QOU/HeckeAlgebra/Common.lean, so connecting it to either sum remains open.

    Categorical content #

    The Markov trace satisfies:

    • Cyclicity: tr_M(x · y) = tr_M(y · x) (inherited from ordinary matrix trace via the Wedderburn block decomposition)
    • Markov axiom: tr_M(x · σ_n) = z · tr_M(x) for x ∈ H_n(q), where z = 1 / (q^{1/2} + q^{-1/2}) is the Markov parameter (per prop:markov-trace-axioms in the manuscript)
    • Wenzl bridge: tr_M = Σ_λ y_λ · χ^λ is the partition-sum decomposition that powers the Python compute layer (tr_m_q_hecke_seminormal.py, wedderburn_jones_markov.py)

    Open Lean port #

    The full Markov-trace formalisation requires:

    • A concrete markovTrace definition (currently axiomatic)
    • The y_λ(q) formula (Wenzl 1988 §3) as a polynomial/Laurent expression in q
    • The Hoefsmit seminormal representation matrices for χ^λ (started in QOU.HeckeAlgebra.Hoefsmit)

    This module captures the type-level interface and the categorical axioms; concrete formulas are deferred to the next round.

    References #

    • [wenzl1988] Wenzl, Hecke algebras of type A_n and subfactors, Inventiones Math. 92 (1988), 349-383.
    • [jones1985] Jones, A polynomial invariant for knots via von Neumann algebras, Bull. AMS 12 (1985).
    • [kassel2008] Kassel-Turaev, Braid Groups, §13.6.

          Cyclicity — removed from this layer, because it lives in two others #

          This module used to declare, alongside heckeMul above,

          axiom MarkovTrace_cyclic :
  ∀ {n} (x y : HeckeElement n),
    markovTrace n (heckeMul x y) = markovTrace n (heckeMul y x)

          That axiom is gone as of 2026-08-26 (bean qou-k5jt). Measured corpus-wide first: it had zero consumers. heckeMul is kept, since it is an opaque datum rather than an axiom and the degeneracy lemma below needs it.

          So it was assumed mathematics that bought nothing, and by markov_axioms_vacuous_of_weight_zero below it did not even constrain the trace: under a zero Riesz weight it reads 0 = 0.

          Cyclicity itself is not lost — it is proved twice already, and neither proof was reachable from here:

          • QOU.MathlibExt.MarkovTrace.character_append_comm — for the concrete Markov trace on a Hecke representation, tr_ρ(v ++ w) = tr_ρ(w ++ v), by ρ.eval_append and Matrix.trace_mul_comm. Sorry-free.
          • QOU.Machinery.MarkovInductiveCyclicity — the inductive Ocneanu route over a generic algebra: cyclic_one_g, cyclic_two_g and the gwg_* bricks, all sorry-free and axiom-free, stated conditionally on named hypotheses (hIH, hgwg, hCE) in the §3b-cond style.

          Restoring an abstract cyclicity statement here should therefore not reintroduce an opaque multiplication. MarkovInductiveCyclicity already works over a generic algebra A with a membership predicate, which is the shape that composes; an opaque binary operation is the shape that cannot.

          ⚠ Note what is NOT claimed. MarkovInductiveCyclicity is currently an orphan — nothing imports it and nothing consumes cyclic_two_g — and its hypotheses are not discharged anywhere. Conditional-proved is not premise-established (AGENTS.md §"Conditional-proved ≠ premise-established"). The bricks exist; the assembly into an unconditional statement about a specific algebra does not.

          axiom QOU.HeckeAlgebra.MarkovTrace.MarkovTrace_markov_axiom {n : ℕ} (x : HeckeElement n) :
          markovTrace (n + 1) (heckeStab x) = QSubstrate.markovParameter * markovTrace n x

          Markov axiom for the Markov trace: stabilisation scales the trace by the Markov parameter z = 1 / (q_0^{1/2} + q_0^{-1/2}) — the single constant QSubstrate.markovParameter, not an arbitrary real:

          tr_M(stab_n x) = z · tr_M(x).

          The z used to be a ∀-bound variable, which made this axiom collapse the Markov trace to zero. With ∀ (z : ℝ) in front, instantiating at z = 0 and z = 1 gives

          markovTrace (n+1) (heckeStab x) = 0        (z := 0)
markovTrace (n+1) (heckeStab x) = markovTrace n x   (z := 1)

          hence markovTrace n x = 0 for every n and every x. The corpus stayed consistent — the zero map satisfies markovTrace_linear, the only other constraint on markovTrace — but tr_M, the central object of the mass chain M = ρ · m_e · |tr_M(T_w)|, was pinned to the zero function, so every downstream statement about it was vacuously about 0. The docstring already said "z := QSubstrate.markovParameter"; only the binder was wrong. Bean qou-ck1f.

          The degeneracy is not excluded — checked, not asserted #

          QOU.HeckeAlgebra.markovTrace's docstring observes that a zero weight satisfies every axiom stated about the trace. That was an observation made by reading the axioms; the two lemmas here make it a checked fact.

          What this does and does not establish. It shows the stated axioms do not exclude tr_M ≡ 0: under a zero weight each of them holds, so none of them can be used to derive a contradiction from degeneracy. It is NOT a consistency proof of the axiom set, which is a statement about models and is not the kind of thing a theorem inside that same set can settle. Read it as "nothing here forces tr_M ≠ 0", which is the claim being made, and not as more.

            @[simp]
            theorem QOU.HeckeAlgebra.MarkovTrace.wenzlBridge {n : ℕ} (x : Wedderburn.WedderburnDecomposition n) :
            markovTraceOnWedderburn x = ∑ lam ∈ partitions_as_finset n, JonesMarkovCoefficient lam QSubstrate.q_0 * Matrix.trace (x lam)

            Wenzl bridge (categorical identity): the Markov trace of an element via its Wedderburn decomposition equals the weighted sum of block traces.

            tr_M(x) = Σ_{λ ⊢ n} y_λ(q) · tr(x λ)

            where tr is the ordinary matrix trace per block. This is the categorical content that the Python compute layer implements in wedderburn_jones_markov.py.

            The q is QSubstrate.q_0, not a ∀-bound variable. It used to be universally quantified, which is the same defect as in MarkovTrace_markov_axiom above and equally corrosive here: markovTraceOnWedderburn x does not mention q, so a ∀ q on the right makes the weighted block-sum provably independent of q (wenzlBridge_q_independent_defect below, which no longer typechecks against this corrected statement). The q-dependence of y_λ(q) is the entire content of the Wenzl bridge, so the old form asserted the negation of what it was for. WedderburnDecomposition is defined as the decomposition of H_n(q_0) (see Wedderburn.lean), so q_0 is the only q the statement can honestly mean. Bean qou-ck1f.
