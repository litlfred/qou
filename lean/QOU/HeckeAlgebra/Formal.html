    QOU.HeckeAlgebra.Formal — pre-archimedean Hecke layer over ℤ[q, q⁻¹] #

    The pre-archimedean Hecke algebra layer, parameterised over a commutative ring R so that:

    • R := ℤ gives ℤ[q, q⁻¹] — the canonical integer-coefficient formal Hecke algebra. This is the preferred ground ring because it admits clean reduction to F_p for every prime p (via ZMod.castRingHom), making categorical statements about character / trace / structure constants hold in finite characteristic.

    • R := ℚ gives ℚ[q, q⁻¹] — needed when denominators force rationality (e.g. some Hoefsmit seminormal matrix entries). Loses clean F_p reduction at primes dividing the denominators.

    • R := ZMod p gives F_p[q, q⁻¹] — direct F_p formal Hecke, obtained from R := ℤ by reduction mod p.

    • R := ℝ recovers the archimedean form via realification at the QOU substrate value q_0 (see QOU.HeckeAlgebra.Realification).

    Design philosophy: F_p compatibility #

    Per user direction "we want as many stmts to hold in F_p": state every statement we can over ℤ[q, q⁻¹], falling back to ℚ[q, q⁻¹] only when denominators are unavoidable. Statements over ℤ[q, q⁻¹] reduce automatically to F_p for every prime; statements with rational denominators only reduce at primes coprime to those denominators.

    What this module provides #

    • HeckeFormalElement R n — a formal Hecke element as a function-space vector over LaurentPolynomial R.

    • HeckeFormalAlgebra R n — abstract formal algebra (axiomatised multiplication; concrete construction deferred to a future Mathlib port of the Iwahori-Hecke generators).

    • Reduction maps to F_p via LaurentPolynomial.map.

    ⚠ Archimedean wall #

    This module lives ENTIRELY on the pre-archimedean side. No real-valued analysis, no PSD machinery, no inner products. The realification Hecke_formal R → Hecke_archimedean ℝ lives in QOU.HeckeAlgebra.Realification and is what crosses the wall.

    References #

    • [kazhdan-lusztig-1979] Representations of Coxeter groups and Hecke algebras, Invent. Math. 53 — KL basis with integer structure constants over ℤ[q, q⁻¹].
    • [hoefsmit1974] Hoefsmit's seminormal form — denominators introduce ℚ.
    • [wenzl1988] Wenzl's y_λ Jones-Markov coefficients — rational-in-q.

                  Integer-coefficient when R = ℤ: q − 1, q ∈ ℤ[q, q⁻¹]. Reducing mod p (when R = ℤ then R = ZMod p) preserves the relation since coefficients are integers — making the Hecke relation hold uniformly across all primes.

                  F_p validity of the T-relation #

                  The T-form Hecke relation has INTEGER coefficients in q (T_i² = (q − 1) T_i + q · 1). Reducing mod p preserves the relation since the coefficients q − 1, q ∈ ℤ[q, q⁻¹] map to (q − 1), q ∈ F_p[q, q⁻¹] via the canonical reduction.

                  This is the central F_p-compatibility consequence of choosing T-form over σ-form.
