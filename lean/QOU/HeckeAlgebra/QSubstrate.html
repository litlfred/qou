    QOU.HeckeAlgebra.QSubstrate — q_0 specialisation #

    The QOU substrate parameter q_0 ≈ 1.10998 is the unique positive real root of the equation m_μ / m_e = 206.7682830 under the categorical mass-ratio formula (per def:m-mu-over-m-e-calibration).

    What this module provides #

    • q_0 : ℝ — the QOU substrate parameter, axiomatised at this abstraction level (Mathlib doesn't have the categorical- derivation Lean infra to compute it from first principles yet; the Python compute layer derives the 50-dps value).
    • c_q : ℝ — speed of light in cat units, c_q = 1 / (q_0 - 1).
    • hbarQ : ℝ — Planck constant in cat units, (q_0 - 1) / q_0.
    • markovParameter : ℝ — z = 1 / (q_0^{1/2} + q_0^{-1/2}).
    • eta_q : ℝ — operational entropy, (2q_0 - 1) / q_0³.

    Categorical content #

    These are the derived constants that appear throughout the QOU manuscript and feed downstream computations. They are axiomatised here at the Lean level (concrete value derivation lives in computations/substrate/q_parameter.py).

    The 50-dps decimal expansion q_0 ≈ 1.1099785955541805… is checked-in as a witness; the Lean axiom is just a positive-real- number existence claim.
