    QOU.HeckeAlgebra.Realification — wall crossing at q = q_0 #

    The archimedean wall crossing: the canonical map from the pre-archimedean formal Hecke algebra Hecke_formal R := R[q, q⁻¹]^{Fin (heckeDim n)} to the archimedean form HeckeElement n := EuclideanSpace ℝ (Fin (heckeDim n)) via evaluation at the QOU substrate parameter q := q_0 ∈ ℝ.

    ⚠ Architectural role of this module #

    This module is the wall. Every other module in QOU.HeckeAlgebra.* lives entirely on one side or the other:

    • Pre-archimedean side (Hecke_formal, Hoefsmit_formal, JonesMarkov_formal, etc.): formal q over ℤ[q, q⁻¹] (or ℚ[q, q⁻¹] where denominators force it). Categorical content; reduces to F_p uniformly when over ℤ.

    • Archimedean side (HeckeElement over ℝ, SDP machinery, PosSemidef analysis, kernel-disjointness): real-valued spectral analysis at q = q_0. Required for SDP-uniqueness conclusions but does NOT pull back to categorical claims.

    The realification map below is the ONE place these meet: it specialises a formal Hecke element at q := q_0 to obtain its archimedean realification.

    Consequences:

    • Statements proven on the pre-archimedean side can be realified at q_0 to give archimedean specialisations.
    • Statements proven on the archimedean side via realification (e.g. SDP uniqueness) DO NOT lift back to categorical pre-archimedean claims.

    What this module provides #

    • realifyAt q_0 : LaurentPolynomial ℝ → ℝ — evaluation of a formal real Laurent polynomial at q = q_0.

    • realifyHeckeElement q_0 — element-wise realification.

    • realifyHoefsmitMatrix q_0 — entry-wise realification of formal Hoefsmit matrices.

    • Composition lemmas: realification commutes with addition, scalar multiplication, and (axiomatically) Hecke multiplication.

    References #

    • QOU manuscript §"Archimedean realization functor" — the formal categorical-to-real map.

    noncomputable def QOU.HeckeAlgebra.Realification.realifyAtRealQ0 :
    LaurentPolynomial ℝ →+* ℝ

    Realification of a formal Laurent polynomial at q_0.

    For f ∈ ℝ[q, q⁻¹], realifyAt q_0 f = f(q_0) ∈ ℝ.

    Uses Mathlib's LaurentPolynomial.eval₂RingHom with the identity coefficient embedding and q_0 as the evaluation value (must be a unit; here q_0 ≠ 0 from q_0 > 1 gives IsUnit q_0 in the field ℝ).

      §2 Realification at q_0 via embedded ℤ → ℝ #

      For the ℤ[q, q⁻¹] formal layer (the F_p-friendly choice), we compose: ℤ[q, q⁻¹] → ℝ[q, q⁻¹] (coefficient embedding) → ℝ (eval at q_0). This is the canonical realification used by the QOU pipeline.

            §4 Compatibility with F_p reduction #

            For statements proven over ℤ[q, q⁻¹] and reduced to F_p[q, q⁻¹], we have a parallel realification path through F_p (when q_0 has a meaningful F_p analogue). This compatibility is mostly bookkeeping; concrete uses come from comparing identity-statement validity in F_p vs ℝ.

            source
            theorem QOU.HeckeAlgebra.Realification.identity_holds_in_realification {n : ℕ} (x y : Formal.HeckeFormalElement ℤ n) (h_eq : x = y) :
            realifyHeckeElement x = realifyHeckeElement y

            Statement-level F_p reduction commutes with realification in the sense that any polynomial identity holding in ℤ[q, q⁻¹] (and hence in every F_p[q, q⁻¹]) realifies to the same identity in ℝ.
