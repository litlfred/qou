          The edge rows are degenerate at every cusp number #

          source
          theorem QOU.OneLoopEdgeLattice.edge_rows_sum_zero {m n : ℕ} (G G' G'' : Fin m → Fin n → ℤ) (z : Fin n → ℂ) (hz0 : ∀ (j : Fin n), z j ≠ 0) (hz1 : ∀ (j : Fin n), z j ≠ 1) (hG : ∀ (j : Fin n), ∑ I : Fin m, G I j = 2) (hG' : ∀ (j : Fin n), ∑ I : Fin m, G' I j = 2) (hG'' : ∀ (j : Fin n), ∑ I : Fin m, G'' I j = 2) (j : Fin n) :
          ∑ I : Fin m, (↑(G I j) * zeta (z j) + ↑(G' I j) * zetaP (z j) + ↑(G'' I j) * zetaPP (z j)) = 0

          The structural fact behind the multi-cusp extension.

          If every column of the edge matrices sums to 2 — which holds at every cusp number, because each tetrahedron has six edges in three opposite pairs, one pair per shape type, and each is glued into exactly one edge class — then the specialised edge rows sum to zero, hence have rank at most N - 1.

          Note what is absent: there is no cusp number in this statement, and none in the proof. DG state the column-sum identity for one cusp ("every edge begins and ends at the cusp"), and PR #4708 read that as a hypothesis and concluded the c ≥ 2 extension was blocked. It is not a hypothesis.

          The per-cusp factor is a reparametrization #

          source
          theorem QOU.OneLoopEdgeLattice.percusp_factor_absorbs {t c : ℝ} (ht : 0 < t) :
          2 ^ ((c - 1) / 2) * (2 ^ c * t) ^ (-1 / 2) = 2 ^ (-1 / 2) * t ^ (-1 / 2)

          The per-cusp factor 2^{(c-1)/2} cancels identically.

          If the superseded determinant satisfies |τ_old| = 2^c |τ| — which holds on the default triangulations of 4_1, L5a1 and L6a4, the three cases the factor was fitted to — then

          2^{(c-1)/2} · |τ_old|^{-1/2} = 2^{-1/2} · |τ|^{-1/2}

          for every c. So the law carrying a per-cusp factor and the law carrying none are the same function on such data, and agreement at c = 1, 2, 3 distinguishes nothing. This is the precise sense in which the "standard per-cusp Gaussian-integration factor" was a reparametrization: it is exactly the c-dependence needed to undo the 2^c.

          Stated for real c and any t > 0; the geometric content is t = |τ|.
