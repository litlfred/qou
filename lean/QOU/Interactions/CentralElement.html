    B₃ character theory (corrected) #

    B₃ = (σ₀σ₁⁻¹)³ is NOT central in H₃(q) and is NOT a scalar matrix in the standard representation. However:

    • net(B₃) = 1 exactly (trivial character)
    • χ_alt(B₃) = 1 exactly (alternating character)
    • The e⁻ NF coefficient of B₃ is zero (observed computationally, consistent with character constraints but not yet proved from characters alone)

    RETRACTED claims (from earlier version) #

    The following claims were INCORRECT and have been removed:

    • borromean3_comm_gen0/gen1 — B₃ does NOT commute with generators
    • borromean3_central — B₃ is NOT central in H₃(q)
    • borromean3_is_scalar — B₃ is NOT scalar in the standard rep
    • borromean3_entry_01 = 0 — FALSE (B₃(0,1) ≠ 0 in the std rep)
    • borromean3_eq_fullTwist — B₃ ≠ Δ² (different braid group elements)

    The error: these were stated with by simp; ring but never compiled. The ring tactic would have failed because the matrix entries are nonzero Laurent polynomials.

    What IS true #

    The trivial and alternating characters ARE exactly 1, because in 1-dimensional representations the generator inverse σ₁⁻¹ ↦ q⁻¹ (trivial) or −q (alternating), and the product σ₀σ₁⁻¹ evaluates to 1 in both cases. This is a 1D computation, not a 2×2 matrix computation, so ring works.

    Archimedean.stdRep3_gen0 * Archimedean.stdRep3_gen1 * Archimedean.stdRep3_gen0 * (Archimedean.stdRep3_gen0 * Archimedean.stdRep3_gen1 * Archimedean.stdRep3_gen0) = 1

    The full twist Δ = σ₀σ₁σ₀ squares to the identity in the standard (2,1) representation of H₃(q).

    This is because Δ² is central with character q^{n(λ)} on irrep V_λ, and for λ = (2,1) the content is 0, so Δ² ↦ I.

    Numerically verified: (σ₀σ₁σ₀)² = I at all tested q values.

    §3 B₃ and Δ² are DIFFERENT #

    theorem QOU.Interactions.borromean3_ne_fullTwist :
    borromean3 ≠ Archimedean.stdRep3_gen0 * Archimedean.stdRep3_gen1 * Archimedean.stdRep3_gen0 * (Archimedean.stdRep3_gen0 * Archimedean.stdRep3_gen1 * Archimedean.stdRep3_gen0)

    B₃ = (σ₀σ₁⁻¹)³ ≠ Δ² = (σ₀σ₁σ₀)² in the standard rep. Δ² = I (proved above), but B₃ ≠ I (proved above). Therefore B₃ ≠ Δ².

    §5 The remaining open question: center of B₃ #

    source
    theorem QOU.Interactions.borromean3_not_central :
    borromean3 ≠ Archimedean.stdRep3_gen0 * Archimedean.stdRep3_gen1 * Archimedean.stdRep3_gen0 * (Archimedean.stdRep3_gen0 * Archimedean.stdRep3_gen1 * Archimedean.stdRep3_gen0)

    The center of the 3-strand braid group B₃ is infinite cyclic, generated by the full twist Δ² = (σ₀σ₁σ₀)².

    This is a classical result in braid theory:

    • Chow (1948): Z(B_n) = ⟨Δ²⟩ for n ≥ 3
    • Birman (1974): "Braids, Links, and Mapping Class Groups", Thm 1.24

    In our context: Δ² = I in the standard (2,1) representation (proved: fullTwist_sq_eq_one), and B₃ = (σ₀σ₁⁻¹)³ ≠ Δ² = I (proved: borromean3_ne_fullTwist). Therefore B₃ is NOT in the center of B₃.

    The confinement uniqueness does NOT require B₃ to be central. Instead, B₃ is the unique element with: (a) e⁻ = 0 in NF (proved by Hecke engine) (b) χ_triv = 1 (proved) (c) Confined net matching both proton and neutron targets (proved computationally in confinement-operator-selection.py) (d) Minimal braid word length among (a)-(c) satisfying elements
