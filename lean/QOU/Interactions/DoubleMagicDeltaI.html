    QOU.Interactions.DoubleMagicDeltaI — Δi ≤ 1 rule for double-magic isotopes #

    The empirical pattern: every observed doubly-magic isotope has proton and neutron magic numbers in adjacent or equal Bring shells (|Δi| ≤ 1). This module:

    1. Records the empirical data as a list of (Z, N, i_Z, i_N) tuples.
    2. Proves the partial claim: all 9 observed double-magic isotopes satisfy Δi ∈ {0, 1}.
    3. States the framework conjecture as a typeclass.
    4. Computes the search-space reduction (73%) for compute optimisation.

          §3 The Δi ≤ 1 conjecture #

          source
          class QOU.Interactions.DoubleMagicDeltaI.DeltaIBoundConjecture :
          Type

          Conjecture (Δi ≤ 1 bound). For any (hypothetical or actual) doubly-magic isotope corresponding to Bring-shell index pair (iZ, iN), we have |iN - iZ| ≤ 1. The forward direction is proved on empirical data; the reverse — that no isotope with |Δi| ≥ 2 can be doubly-magic — is the framework prediction.

          • IsLRCompatible : ℕ → ℕ → Prop

            Predicate: is the (iZ, iN)-shell pair LR-fusion-compatible (=> can support a doubly-magic isotope)?

          • compatible_iff_deltaI_le_one (iZ iN : ℕ) : 1 ≤ iZ → iZ ≤ 7 → 1 ≤ iN → iN ≤ 7 → (IsLRCompatible iZ iN ↔ |↑iN - ↑iZ| ≤ 1)

            The conjectural iff: LR-fusion is compatible iff |Δi| ≤ 1.
