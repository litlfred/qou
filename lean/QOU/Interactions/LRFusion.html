    QOU.Interactions.LRFusion — double-magic LR-fusion rigidity #

    A composite nuclear configuration A = Z + N is double-magic iff the Littlewood–Richardson fusion of the proton representation V_{ydZ} and the neutron representation V_{ydN} yields a dominant composite V_{ydA} whose Jucys–Murphy multiset is gapless and globally neutral: κ_{ydA} = 0.

    Conjectural-propagation (AGENTS.md §3b): downstream of SaturatedShellConjecture and ShellCondensationConjecture, so the LR-rigidity claim is also axiomatised here.

    LaTeX label: conj:diagrammatic-double-magic-lr-fusion

      §2 Provable algebraic ingredient — content additivity #

      source
      class QOU.Interactions.LRFusion.ContentAdditive (C : Composite) :
      Prop

      Content additivity (provable from the LR rule, axiomatised here at the abstract framework level): the Jucys–Murphy charge of the dominant composite equals the sum of the constituent charges. This is the standard fact that contents add under tensor induction.

      A concrete non-vacuous instance is the disjoint-union composite Composite.fromUnion, where ydA := ydZ ⊔ ydN is the multiset disjoint union; in that case content additivity is proved directly from kappa_unionDiagram (see instance contentAdditive_fromUnion). The full LR-fusion ydA is conjecturally also content-additive but requires the LR rule to verify.

      • kappa_add : BraidKnot.ShellNeutrality.kappa C.ydA = BraidKnot.ShellNeutrality.kappa C.ydZ + BraidKnot.ShellNeutrality.kappa C.ydN

            §4 The LR-fusion rigidity conjecture #

            source
            class QOU.Interactions.LRFusion.DoubleMagicConjecture :
            Prop

            Conjecture 3 — Diagrammatic double-magic and LR-fusion rigidity.

            For saturated, self-conjugate constituents λ_Z ⊢ Z and μ_N ⊢ N (Z, N ∈ 𝔐), the LR-fusion at level A = Z + N is rigid: the dominant composite ν_{ZN} ⊢ A is itself self-conjugate. That is the .md's claim and it is what lr_rigidity states.

            🛑 The second field is gone (2026-08-31), and it was FALSE #

            Until 2026-08-31 this class carried a second field:

            magic_iff_double_magic : ∀ (C : Composite),
  (kappa C.ydA = 0 ∧ isSelfConjugate C.ydA ∧ C.ydA.n ∈ magicLadder)
  ↔ IsDoubleMagic C

            It is removed for two independent reasons, both measured.

            (1) The A ∈ magicLadder conjunct is not in the .md, and is false at every physically intended instance. The source block claims that the dominant ν_{ZN} is self-conjugate with c(ν) = 0 and LR multiplicity one; it never claims the composite strand count A = Z + N is a magic number. Magic numbers are shell closures for a proton or neutron count separately, and the sum of two of them is essentially never one: of the seven observed double-magic nuclei — ⁴He (A=4), ¹⁶O (16), ⁴⁰Ca (40), ⁴⁸Ca (48), ⁵⁶Ni (56), ¹³²Sn (132), ²⁰⁸Pb (208) — not one has A ∈ {2, 8, 20, 28, 50, 82, 126}. Exhaustively, the only magic pair whose sum is magic at all is 8 + 20 = 28.

            (2) The ↔ was refutable, and the repair to IsDoubleMagic moves the falsity rather than removing it. With the old definition the ← direction failed at the empty composite (double-magic by triviality, A = 0 ∉ magicLadder). Adding the missing saturation makes ← safe and breaks → at the same point: κ(∅) = 0 and ∅ is self-conjugate, but 0 ∉ magicLadder so ∅ is not saturated. A converse of this shape cannot be rescued by a non-degeneracy guard alone.

            The converse was in any case a Lean addition: the removed docstring said "The reverse direction asserts that only double-magic compositions reach the magic ladder", a claim the .md does not make.

            Still not encoded: the .md also claims the LR multiplicity is one (c^{ν}_{λ,μ} = 1, all others vanishing). That needs Littlewood–Richardson coefficients, which this file does not carry, so it is stated in the narrative and absent here. Recorded so the gap is visible rather than implied.

            Bean qou-z9ws; refutation of the old form in docs/audits/2026-08-31-double-magic-conjecture-is-false.lean.

              §5 Downstream — double-magic ⇒ homological condensation #

              🛑 The "capstone" is gone (2026-08-31) — it never made the connection #

              Until 2026-08-31 this section ended with

              theorem doubleMagic_implies_condensation
    [D : DoubleMagicConjecture] [ShellCondensationConjecture]
    (C : Composite) [ContentAdditive C]
    (hM : IsDoubleMagic C) (hL : C.ydA.n ∈ magicLadder) :
    InfinityVanishesAtPositiveQ C.ydA.n :=
  condensation_at_magic hL

              described as "the algebraic-geometry capstone connecting" three conjectures. Its body is condensation_at_magic hL, which needs hL and [ShellCondensationConjecture] and nothing else: D, [ContentAdditive C] and hM are all unused. The theorem is condensation_at_magic under another name, with three decoy binders making it look like a chain.

              The link it appeared to supply — from "C is double-magic" to "C.ydA.n ∈ magicLadder" — is exactly what the removed magic_iff_double_magic asserted, and that assertion is false: no observed double-magic nucleus has a magic mass number (see the class docstring above). So the chain cannot be closed by repairing the binders; the step it needs does not hold.

              Removed rather than re-stated. A caller wanting the real content applies condensation_at_magic directly, which says what it does. Whether some other route leads from double-magic constituents to shell condensation is open, and naming a theorem after that route does not create it.
