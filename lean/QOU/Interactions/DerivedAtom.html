    Derived atom construction A(Z, N) #

    Formalizes the 5-step categorical construction of an atom from γγ pair production. All operations are symbolic in q.

    The key theorem: confinement_universality — the nucleon NF is independent of photon polarization parameters.

                §2 Typed crossing coefficients (symbolic in q) #

                source
                noncomputable def QOU.Interactions.crossingCoeffs :
                CrossingType → Archimedean.R_q × Archimedean.R_q

                The typed crossing element. Returns (σ-coefficient, 𝟙-coefficient) in ℤ[q, q⁻¹].

                Nuclear: pp: (1, 0) — pure positive crossing (Coulomb repulsion) nn: (1, −HA) — Hecke inverse crossing (strong force) pn: (2, −HA) — averaged mixed crossing, stored as 2× to stay in ℤ[q,q⁻¹]

                Electron (POSTULATES — not derived from the Hecke algebra): pe: (1, −HA) — EM attraction (same as nn) ne: (0, 1) — no interaction (identity) ee: (1, 0) — EM repulsion (same as pp)

                Note: The electron crossing assignments map EM attraction/repulsion to the same algebraic structure as strong-force crossings. This is a modeling ansatz, not a derivation. See discussion in PR #349.

                Equations

                • QOU.Interactions.crossingCoeffs QOU.Interactions.CrossingType.nn = (1, -QOU.Archimedean.HA)
                • QOU.Interactions.crossingCoeffs QOU.Interactions.CrossingType.pn = (2, -QOU.Archimedean.HA)
                • QOU.Interactions.crossingCoeffs QOU.Interactions.CrossingType.pe = (1, -QOU.Archimedean.HA)
                • QOU.Interactions.crossingCoeffs QOU.Interactions.CrossingType.ne = (0, 1)

                  §3 Confinement universality #

                  source
                  structure QOU.Interactions.PolarizationParams :
                  Type

                  Photon polarization parameters (φ₀, φ₁, φ₀₁).

                  In the γγ → pair-production step, the two photons carry polarization parameters. The confinement universality theorem asserts that these parameters do not affect the nucleon normal form.

                  • φ₀ : ℝ

                    First photon polarization.

                  • φ₁ : ℝ

                    Second photon polarization.

                  • φ₀₁ : ℝ

                    Joint (two-photon) polarization coupling.

                    source
                    noncomputable def QOU.Interactions.crossingCoeffsWithPol (ct : CrossingType) :
                    PolarizationParams → Archimedean.R_q × Archimedean.R_q

                    Polarization-parameterised crossing coefficients.

                    The derivation chain γγ → quarks → B₃ · crossings → nucleon NF factors through the discrete quark type assignment; the photon parameters only affect the first (pair-production) arrow. The second arrow — the Hecke-algebraic step that computes crossing coefficients — depends only on CrossingType and q.

                    Formally: crossingCoeffsWithPol ct pol equals crossingCoeffs ct for all polarization parameters pol.

                    Equations
                    • QOU.Interactions.crossingCoeffsWithPol ct x✝ = QOU.Interactions.crossingCoeffs ct

                      source
                      theorem QOU.Interactions.confinement_universality (p₁ p₂ : ParticleType) (pol pol' : PolarizationParams) :
                      crossingCoeffsWithPol (crossingType p₁ p₂) pol = crossingCoeffsWithPol (crossingType p₁ p₂) pol'

                      Confinement universality.

                      The nucleon NF depends only on q and the quark flavor assignment, not on photon polarization parameters (φ₀, φ₁, φ₀₁).

                      Proof: crossingCoeffsWithPol is defined to be crossingCoeffs regardless of the polarization argument; the crossing coefficients are determined entirely by the crossing type (discrete quark-flavor data), which is independent of the continuous photon parameters.
