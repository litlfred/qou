    Wedderburn Mass Formula — three-invariant atomic mass #

    For a neutral atom (Z, N) with n_gen Hecke-NF generators, the mass decomposes as the sum of nucleon and electron rest masses plus a Wedderburn-weighted binding term:

    M(Z, N) = Z · m_p + N · m_n + Z · m_e + α · Σᵢ ln |V̂ᵢ^full|

    where the full traced volume per generator is the Wedderburn sum

    V̂ᵢ^full = w_sym · λᵢ^sym + w_std · V̂ᵢ^std + w_alt · λᵢ^alt

    and the Wedderburn–Markov weights at the baryon level n = 3 are

    w_sym = w_alt = 1 / [3]_q!, w_std = [2]_q² / [3]_q!, where [3]_q! = (1+q+q²)(1+q).

    The binding scale α = m_e · 8G (Catalan, Vol(B_3) = 8G).

    LaTeX: \label{prop:wedderburn-mass-formula}

    This file encodes the formula structurally:

    • All q-dependent quantities (q_int_2, q_int_3, q_fact_3, w_sym, w_std, w_alt) are real noncomputable defs.
    • All physical constants (m_p, m_n, m_e, catalan_G, alpha_bind) are noncomputable defs with explicit numerical values from CODATA / standard tables.
    • Only the Hoefsmit eigenvalues (V_std, lambda_sym, lambda_alt) and the integer numGenerators remain opaque — they depend on the seminormal-form construction which is not yet formalised.
    • Theorems include both the structural mass split and several positivity/closed-form facts about the weights, all proved.

              Hoefsmit-derived data (typeclass-supplied per (Z, N)) #

              The Hoefsmit seminormal form of H_k(q) is not yet formalised in Lean / Mathlib. Rather than opaque-stubbing the per-(Z, N) coefficients, we package them as a typeclass HasHoefsmitData (Z N) so each nucleus's data is supplied by the caller (typically from the Hoefsmit-tabulation Python pipeline; see hoefsmit-seminormal.witness.json).

                        source
                        instance QOU.Interactions.hasHoefsmitData_vacuum :
                        HasHoefsmitData 0 0

                        Vacuum Hoefsmit data: at (Z, N) = (0, 0) (no nucleons, no Hecke generators), the seminormal data collapses to the trivial identity:

                        • numGenerators = 0 (empty set)
                        • V_std = 0 (no generators contribute)
                        • lambda_sym = lambda_alt = 1 (empty product) The bindingTerm is then α · Σ_{i ∈ ∅} … = 0, so vacuum has zero binding contribution.
                        Equations
                        • QOU.Interactions.hasHoefsmitData_vacuum = { numGenerators := 0, V_std := fun (x : ℕ) (x : ℝ) => 0, lambda_sym := fun (x : ℕ) (x : ℝ) => 1, lambda_alt := fun (x : ℕ) (x : ℝ) => 1 }

                                          theorem QOU.Interactions.wedderburnMass_succ_Z (Z N : ℕ) [HasHoefsmitData Z N] [HasHoefsmitData (Z + 1) N] (q : ℝ) :
                                          wedderburnMass (Z + 1) N q - wedderburnMass Z N q = m_p + m_e + (bindingTerm (Z + 1) N q - bindingTerm Z N q)

                                          Mass is monotone in Z along the proton-rich axis. Adding one proton (with neutron number fixed) increases the leading rest-mass term by m_p + m_e. The binding term is Z-dependent via V_std, λ^sym, λ^alt (opaque), so we can only state the rest-mass part as an algebraic identity.
