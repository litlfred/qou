    Demand stability: the demand profile determines nuclear stability #

    The demand profile (set of negative NF coefficients) is the categorical diagnostic of stability. Beta-stable nuclei minimize demand magnitude at fixed mass number A.

    References #

    • [prop:demand-stability]
    • [conj:periodic-table-demand]

    §1 Demand magnitude #

    The demand magnitude: sum of absolute values of negative NF coefficients, over ℤ[q, q⁻¹].

    For formal proofs we work with the negative part directly
since absolute value requires an ordering on R_q.

    The negative part of a coefficient requires an ordering on R_q. Since R_q = ℤ[q,q⁻¹] has no canonical total order, the demand profile is defined over ℝ-valued evaluations (at specific q₀), not over R_q directly.

    For formal proofs, we use the sign of specific Laurent polynomials
evaluated at q > 1 (see ProtonTrefoilSign.lean).

    §2 Beta stability criterion #

    A configuration (Z, N) is beta-stable at fixed A = Z + N if no single nucleon exchange p ↔ n reduces the demand.

    Formally: (Z, N) is beta-stable iff for Z' = Z ± 1, N' = A - Z':
  demandMag(A(Z,N)) ≤ demandMag(A(Z',N'))

This is a finite condition: at fixed A, there are only A+1
configurations to check.

    §3 The e⁻ coefficient as beta decay receptivity #

    Beta decay receptivity.

    The e⁻ coefficient (index 5 in the NF basis) of a nucleon
is the trefoil demand. If c₅ < 0, the nucleon is receptive
to beta decay: it can emit an electron (trefoil) to reduce
its demand.

The sign of the e⁻ coefficient for the proton and neutron is
proved negative in ProtonTrefoilSign.lean:
- `proton_trefoil_neg_on_interval`: c₅(p) < 0 for q ∈ (1, 3/2]
- `neutron_trefoil_neg`: c₅(n) < 0 for all q > 1
- `neutron_more_negative`: |c₅(n)| > |c₅(p)| for q > 1

    §4 Magic numbers from demand closure #

    A magic number is a value of Z (or N) at which the nucleus achieves demand closure (all NF coefficients nonneg) for at least one value of the complementary quantum number.

    Conjecture: the magic numbers are exactly {2, 8, 20, 28, 50, 82, 126}.

Verified computationally for Z = 2 (He-3: demand = ∅).

    §5 Hecke square identity for typed crossings #

    source
    theorem QOU.Interactions.typed_crossing_square_pp (ρ : Archimedean.HeckeRep 3 2) (i : Fin 2) :
    ρ.gen i * ρ.gen i = Archimedean.HA_t • ρ.gen i + 1

    The typed crossing squares reduce via the Hecke relation. This is the key identity for polynomial scaling of the inductive GB reduction.

    C_pp² = HA · C_pp + 1 C_nn² = HA · C_nn + 1 (after expanding σ⁻¹ = σ - HA)

    Both are instances of σ² = HA·σ + 1.

    The mixed crossing square identity. C_pn² = HA · C_pn + 1 − ¼HA²

    (In ℤ[q, q⁻¹], we state: 4·C_pn² = 4·HA·C_pn + 4 − HA².)

This requires expanding (σ - ½HA)² and using the Hecke relation.
Since ½ ∉ ℤ[t,t⁻¹], we multiply through by 4.
    source
    theorem QOU.Interactions.mixed_crossing_square_identity (ρ : Archimedean.HeckeRep 3 2) (i : Fin 2) :
    (2 • ρ.gen i - Archimedean.HA_t • 1) * (2 • ρ.gen i - Archimedean.HA_t • 1) = (4 + Archimedean.HA_t * Archimedean.HA_t) • 1

    The mixed crossing square: (2σ - HA)² = 4 + HA². Uses the Hecke relation σ² = HA·σ + 1.
