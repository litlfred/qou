      Prop

      Universal ILP Algorithm (pattern C — named, not asserted).

      Content statement (from manuscript): a single integer linear program selects the operator at every level of the QOU construction; the same Gram matrix $G$, the same Frobenius check $Gx \geq 0$, and the same ILP are applied to quarks, nucleons, atoms, and molecules.

      The structural reading is that there are exactly four construction levels and the ILP Gram dimension is constant across them. We name this as a Prop over the context's primitive data, rather than projecting it from self-assuming h_* fields — an instance of this proposition is the open structural claim.
