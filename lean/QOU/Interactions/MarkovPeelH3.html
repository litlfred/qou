    Concrete Markov trace on the H₃(q) NF basis #

    H₃-specialised companion to QOU.Interactions.MarkovPeel. Provides the explicit canonical Jones–Markov trace on the 6-element NF basis of H₃(q) (HeckeNF := Fin 6 → R_q, basis {γ, σ₀, σ₁, L₊ = σ₀σ₁, L₋ = σ₁σ₀, e⁻ = σ₀σ₁σ₀}; see QOU.Interactions.HeckeEngine).

    The canonical trace values on this basis are (per markov_trace_canonical.py lines 13-17 and the Python production witness markov-peel-atomic-tr-m.witness.json):

    tr_M(γ) = 1 tr_M(σ₀) = z tr_M(σ₁) = z tr_M(L₊) = z² tr_M(L₋) = z² tr_M(e⁻) = h·z² + z where h = q − q⁻¹

    Direct numerical cross-check at q₀: proton = b₀·γ + b₁·σ₀ + b₂·σ₁ + b₃·L₊ + b₄·L₋ + b₅·e⁻ tr_M(proton)|q₀ = +1.14575978231523894039…

    Scope vs the abstract MarkovTrace typeclass #

    MarkovTrace H R from MarkovPeel.lean is a tower-flavoured typeclass — it expects top : Nat → H for arbitrarily large strand counts. HeckeNF is fixed at 6 elements (only H₃), so a direct MarkovTrace HeckeNF R_q instance would need to interpret top n for n > 3 as a degenerate / dummy value, which would sacrifice the algebraic content of the (M2) Markov-peel axiom.

    This file therefore provides a specialised MarkovTraceH3 record that captures the H₃-specific trace + axioms, and a one-line derivation of tr_M(proton) matching the Python production witness. A full MarkovTrace instance for the whole tower requires a generic family HeckeNF (n : Nat) := Fin (Nat.factorial n) → R (or a Garside / Iwahori normal form), which is out of scope here.

    structure QOU.Interactions.MarkovTraceH3 (R : Type u_1) [CommRing R] :
    Type u_1

    An H₃-specific Markov-trace structure parameterised on the target ring R (typically a √q-extended Laurent ring or a formal symbolic ring). Captures the canonical trace on the six NF basis elements of H₃(q): {γ, σ₀, σ₁, L₊, L₋, e⁻}.

    • z : R

      The Markov parameter z = q³/(q²+1) = q²/[2]_q — convention D, the production trace (trace-convention registry). Corrected 2026-09-05 (qou-46ab): this read z = 1/(q^{1/2} + q^{-1/2}), which is convention C, excised by the owner ruling of 2026-08-09. The two are not variant normalisations of one quantity — see rem:markov-z-reconciliation.

    • h : R

      The Hecke parameter h = q − q⁻¹.

    • tr : HeckeNF → R

      The trace map. Linear in the NF basis.

      noncomputable def QOU.Interactions.trH3 {R : Type u_1} [CommRing R] (φ : Archimedean.R_q →+* R) (z h : R) (a : HeckeNF) :
      R

      The canonical Markov-trace function on H₃ NF basis elements.

      Given Markov parameter z and Hecke parameter h = q − q⁻¹, a basis-linear element a : HeckeNF (6 coefficients in R_q) has Markov trace

      tr (a) = a₀ · 1 + a₁ · z (σ₀) + a₂ · z (σ₁) + a₃ · z² (L₊ = σ₀σ₁) + a₄ · z² (L₋ = σ₁σ₀) + a₅ · (h·z² + z) (e⁻ = σ₀σ₁σ₀)

      The values come from the Markov axioms applied to each basis element individually: • tr(γ) = 1 by (M3) • tr(σ_i) = z by (M2) with x = γ • tr(σ_iσ_j) = z² by two (M2) peels (prop:markov-pair-z2) • tr(σ_iσ_jσ_i) = h·z² + z (Hecke quadratic + Markov peel)

      Corrected 2026-09-05 (qou-46ab): this claimed the Python production witnesses cross-check the formula at q = q₀ to ≤ 4·10⁻¹⁶ against the Hoefsmit + Wenzl bridge. That tolerance was measured in convention C and does not hold as stated; the bridge witness is 7·10⁻² from the C-frame value. The formula itself is convention-independent — it is the Markov axioms applied basis element by basis element — so nothing above depends on z's value. The numeric claim is dropped rather than restated with a new tolerance, because it has not been re-measured under D.

      The signature takes an explicit ring hom φ : R_q →+* R (the "lift" of the algebra coefficients into the trace ring) so the canonical instance with R = R_q and φ = RingHom.id drops out trivially, while the symbolic instance with R = R_q[z, z⁻¹] / (z⁻¹ − (q² + 1)/q³) is also expressible via the inclusion hom. (Corrected 2026-09-05, qou-46ab: the defining relation read z⁻¹ − q^{1/2} − q^{-1/2}, i.e. convention C. Under production convention D, z = q³/(q²+1), so the relation is z⁻¹ = (q²+1)/q³ — and note it needs no √q, which is one of the structural reasons D is the production trace.)
