    Proton e⁻ coefficient is negative for 1 < q < q* #

    The e⁻ NF coefficient of the proton (B₃ · typed crossings for u,u,d) is:

    c_{e⁻}(𝔭) = (q−1)²(q+1)²(q⁸ − 3q⁶ − 3q² + 1) / (4q⁶)

    The sign is determined by p(q) = q⁸ − 3q⁶ − 3q² + 1:

    • p(1) = −4 < 0
    • p has a unique real root q* ≈ 1.804 in (1, ∞)
    • For 1 < q < q*: p(q) < 0, hence c_{e⁻} < 0

    Since q₀ ≈ 1.110 < 1.804 = q*, the proton has negative e⁻ coefficient — it demands a trefoil (electron), which is the categorical origin of beta decay.

          theorem QOU.Interactions.derivFactor_neg_on_interval (q : ℝ) (hq1 : 1 ≤ q) (hq2 : q ≤ 3 / 2) :
          derivFactor q < 0

          r(q) = 4q⁶ − 9q⁴ − 3 < 0 for all q ∈ [1, 3/2].

          Proof: write r(q) = q⁴(4q² − 9) − 3. For q ≤ 3/2: 4q² ≤ 4·(9/4) = 9, so 4q² − 9 ≤ 0. Since q⁴ ≥ 0, we get q⁴(4q² − 9) ≤ 0. Therefore r(q) ≤ 0 − 3 = −3 < 0.

          source
          theorem QOU.Interactions.signPoly_deriv_neg (q : ℝ) (hq1 : 1 ≤ q) (hq2 : q ≤ 3 / 2) :
          2 * q * derivFactor q < 0

          p'(q) = 2q · r(q) < 0 for q ∈ (1, 3/2]. Since r(q) < 0 (proved above) and q > 0, the product is negative. Therefore p is strictly decreasing on [1, 3/2].

          source
          theorem QOU.Interactions.signPoly_neg_on_interval (q : ℝ) (hq1 : 1 ≤ q) (hq2 : q ≤ 3 / 2) :
          signPoly q < 0

          THE KEY RESULT: p(q) < 0 for all q ∈ [1, 3/2].

          Direct algebraic proof — no monotonicity or IVT needed!

          Write −p(q) = 3q⁶ − q⁸ + 3q² − 1 = q⁶(3 − q²) + (3q² − 1).

          For q ∈ [1, 3/2]: • 3 − q² ≥ 3 − 9/4 = 3/4 > 0 (since q ≤ 3/2) • q⁶ ≥ 1 (since q ≥ 1) • 3q² − 1 ≥ 2 > 0 (since q ≥ 1)

          Therefore −p(q) ≥ 1 · 3/4 + 2 = 11/4 > 0, so p(q) < 0.

          §5 The neutron e⁻ coefficient #

          source
          noncomputable def QOU.Interactions.neutronTrefoilCoeff (q : ℝ) :
          ℝ

          The neutron e⁻ coefficient is ALWAYS NEGATIVE for q > 1. No sign polynomial analysis needed — the formula is a perfect negative square:

          c_{e⁻}(𝔫) = −(q−1)²(q+1)²(q²+1)² / (4q⁴)

          All factors in the numerator are perfect squares (≥ 0), the denominator is positive, and the overall sign is −. Therefore c_{e⁻}(𝔫) ≤ 0 for all q, with equality only at q = 1.

            §6 Neutron e⁻ more negative than proton e⁻ #

            source
            noncomputable def QOU.Interactions.trefoilDiff (q : ℝ) :
            ℝ

            The neutron has MORE trefoil demand than the proton:

            c_{e⁻}(𝔫) − c_{e⁻}(𝔭) = −(q−1)⁴(q+1)⁴(q⁴+1) / (4q⁶)

            This difference is always negative for q > 1, meaning the neutron's e⁻ coefficient is more negative than the proton's. This is why the FREE NEUTRON beta-decays but the free proton does not (at our q₀).
