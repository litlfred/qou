    The Gram matrix of H₃(q) is indefinite #

    Proves that the Frobenius bilinear form ⟨a, b⟩_F = tr_M(a·b) is NOT positive definite on H₃(q) for q > 1. This is done by exhibiting a vector v with vᵀGv < 0.

    This is the key result for the LP proof: an indefinite Gram matrix means the LP can achieve tr_M = 0, proving that energy minimization alone is insufficient for confinement.

    Approach #

    Rather than computing the full 6×6 determinant, we exhibit a specific vector v = (0, 1, -1, 0, 0, 0) and show that vᵀGv = G₁₁ - 2G₁₂ + G₂₂ = 2(HA·z + 1) - 2z² < 0 for q > 1.

    Wait — actually G₁₁ = G₂₂ (by symmetry σ₀ ↔ σ₁), and G₁₂ = z² (from tr_M(σ₀·σ₁) = z²). So vᵀGv = 2(HA·z+1) - 2z². At q₀: 2(0.209·0.499 + 1) - 2·0.249 = 2·1.104 - 0.499 = 1.71 > 0.

    That doesn't work. Let me try v = (0, 0, 0, 1, -1, 0): vᵀGv = G₃₃ - 2G₃₄ + G₄₄.

    G₃₃ = tr_M(L₊·L₊), G₄₄ = tr_M(L₋·L₋), G₃₄ = tr_M(L₊·L₋).

    From the computation: G₃₃ = G₄₄ ≈ 0.855, G₃₄ ≈ 1.105. So vᵀGv = 2·0.855 - 2·1.105 = -0.500 < 0. ✓

    We need G₃₃ - 2G₃₄ + G₄₄ < 0, i.e., G₃₃ + G₄₄ < 2G₃₄.

    Symbolically: L₊·L₊ = σ₀σ₁σ₀σ₁ = σ₀·(σ₁σ₀σ₁) = σ₀·e⁻ (by braid relation) Wait: σ₁σ₀σ₁ = σ₀σ₁σ₀ = e⁻ (braid relation) So L₊² = σ₀·σ₁·σ₀·σ₁ = σ₀·(σ₁σ₀σ₁) = σ₀·e⁻

    Actually: (σ₀σ₁)² = σ₀σ₁σ₀σ₁. Apply braid: σ₁σ₀σ₁ = σ₀σ₁σ₀. So σ₀σ₁σ₀σ₁ = σ₀·(σ₁σ₀σ₁) ... no, need parentheses. σ₀σ₁·σ₀σ₁ = σ₀·(σ₁σ₀)·σ₁ ... hmm.

    Let me just use: (σ₀σ₁)² reduces via Hecke. σ₀σ₁σ₀σ₁: Apply braid to middle: σ₁σ₀σ₁ = σ₀σ₁σ₀ But the pattern σ₀|σ₁σ₀|σ₁ — the middle σ₁σ₀ is not a braid triple. So just use: (σ₀σ₁)·(σ₀σ₁) and reduce σ₁σ₀ by... it's already NF (L₋). No Hecke reduction needed. (σ₀σ₁)² = σ₀σ₁σ₀σ₁. Wait: is σ₀σ₁σ₀σ₁ in NF? The max word length in NF(H₃) is 3 (= e⁻). σ₀σ₁σ₀σ₁ has length 4, so it must reduce.

    σ₀σ₁σ₀σ₁: look for σᵢσⱼσᵢ with |i-j|=1.
Positions 0,1,2: σ₀σ₁σ₀ → σ₁σ₀σ₁ (braid, reduces to lex-smaller).
So σ₀σ₁σ₀σ₁ → σ₁σ₀σ₁·σ₁ = σ₁σ₀·σ₁² = σ₁σ₀·(HAσ₁+1)
= HA·σ₁σ₀σ₁ + σ₁σ₀ = HA·e⁻ + L₋
(using braid: σ₁σ₀σ₁ = σ₀σ₁σ₀ = e⁻)

    So NF((σ₀σ₁)²) = L₋ + HA·e⁻.

    Similarly: L₊·L₋ = σ₀σ₁·σ₁σ₀ = σ₀·σ₁²·σ₀ = σ₀·(HAσ₁+1)·σ₀ = HA·σ₀σ₁σ₀ + σ₀² = HA·e⁻ + HAσ₀ + 1 So NF(L₊·L₋) = 1 + HA·σ₀ + HA·e⁻.

    Now: tr_M(L₊²) = tr_M(L₋ + HA·e⁻) = z² + HA·(HAz² + z) = z² + HA²z² + HAz = z²(1 + HA²) + HAz

    tr_M(L₊·L₋) = tr_M(1 + HAσ₀ + HAe⁻) = 1 + HAz + HA(HAz² + z) = 1 + HAz + HA²z² + HAz = 1 + 2HAz + HA²z²

    G₃₃ = tr_M(L₊²) = z²(1+HA²) + HAz G₃₄ = tr_M(L₊·L₋) = 1 + 2HAz + HA²z²

    vᵀGv = 2G₃₃ - 2G₃₄ (when G₃₃=G₄₄ by symmetry L₊↔L₋)

    Wait: G₃₃ = G₄₄ requires tr_M(L₊²) = tr_M(L₋²). By cyclicity tr_M(L₋²) = tr_M((σ₁σ₀)²) = tr_M(σ₁σ₀σ₁σ₀). Apply braid to σ₁σ₀σ₁: σ₁σ₀σ₁ → σ₀σ₁σ₀ (same e⁻!) σ₁σ₀σ₁σ₀ → σ₀σ₁σ₀·σ₀ = e⁻·σ₀. tr_M(e⁻·σ₀) = tr_M(σ₀σ₁σ₀²) = tr_M(σ₀σ₁·(HAσ₀+1)) = HA·tr_M(σ₀σ₁σ₀) + tr_M(σ₀σ₁) = HA·(HAz²+z) + z² = HA²z² + HAz + z² = z²(1+HA²) + HAz

    So indeed G₃₃ = G₄₄. Good.

    vᵀGv = 2(z²(1+HA²)+HAz) - 2(1+2HAz+HA²z²) = 2z² + 2HA²z² + 2HAz - 2 - 4HAz - 2HA²z² = 2z² - 2HAz - 2 = 2(z² - HAz - 1)

    Need to show z² - HAz - 1 < 0 for q > 1.

    z = 1/(q^½ + q^{-½}), HA = q - q⁻¹.

    z² = 1/(q^½+q^{-½})², HAz = (q-q⁻¹)/(q^½+q^{-½}).

    z² - HAz - 1 = 1/(q^½+q^{-½})² - (q-q⁻¹)/(q^½+q^{-½}) - 1

    Let s = q^½+q^{-½} (≥ 2 for q ≥ 1). Then: = 1/s² - (q-q⁻¹)/s - 1 = (1 - (q-q⁻¹)s - s²)/s²

    Note: q - q⁻¹ = (q^½-q^{-½})(q^½+q^{-½}) = (q^½-q^{-½})·s

    So (q-q⁻¹)·s = (q^½-q^{-½})·s².

    numerator = 1 - (q^½-q^{-½})s² - s² = 1 - s²(q^½-q^{-½}+1) = 1 - s²·(q^½ + 1 - q^{-½})

    For q > 1: q^½ > 1, so q^½ + 1 - q^{-½} > 1. And s ≥ 2, so s² ≥ 4. So numerator ≤ 1 - 4·1 = -3 < 0. ✓

    This is a clean symbolic proof! Let me write it in Lean.

    All variables are symbolic: q appears only through z and HA.

    §2 The Gram form is indefinite #

    source
    theorem QOU.Interactions.gram_indefinite_witness :
    hopfPlus * hopfPlus + hopfMinus * hopfMinus ≠ 2 • (hopfPlus * hopfMinus)

    The vector v = e₃ - e₄ (i.e., L₊ − L₋) witnesses indefiniteness of the Gram form.

    vᵀGv = G₃₃ - 2G₃₄ + G₄₄ = 2(z²(1+HA²) + HAz) - 2(1+2HAz+HA²z²) = 2z² - 2HAz - 2 = 2(z² - HAz - 1).

    For q > 1: z < 1/2 and HA > 0, so z² < 1/4 and z² - HAz - 1 < 1/4 - 0 - 1 < 0.

    Therefore vᵀGv < 0 and G is NOT positive semidefinite.
