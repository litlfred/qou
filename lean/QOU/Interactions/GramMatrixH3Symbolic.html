    QOU.Interactions.GramMatrixH3Symbolic #

    Symbolic categorical Gram matrix gramMatrix u for the H_3(q) Hoefsmit-seminormal basis (6-element NF) — direct-use form (no typeclass indirection per main commit 91cb2671b's revert of the Phase 1a typeclass).

    Phase 1b deliverable (PR follow-up to PR #1255 Option E Phase 1a).

    What this file does #

    Replaces the deferred "rational-encode 36 decimal entries" plan with explicit categorical closed-form entries (sympy-computed, verified to 1e-16 against gram-matrix-dual.witness.json at q_0).

    Each of the 21 upper-triangle entries is a Laurent polynomial in u = √q, where q > 0 (substrate hypothesis). The entries with ONLY even powers of u are equivalent to rational functions in q; the entries with ODD powers carry an explicit √q factor.

    NF basis (6 elements) #

      b_0 = 1            (empty word)
  b_1 = σ_0
  b_2 = σ_1
  b_3 = σ_0σ_1
  b_4 = σ_1σ_0
  b_5 = σ_0σ_1σ_0    (canonical of σ_0σ_1σ_0 = σ_1σ_0σ_1)

    Markov trace TR_M — and WHICH CONVENTION each half of this file is in #

    TR_M = [1, z, z, z², z², h·z² + z], h = q − q⁻¹

    with z the Markov weight. Everything in this file follows from that one line, and which z you put in it decides the answer. Two are in play:

    convention C z = √q/(q+1) excised 2026-08-09, re-affirmed 2026-08-15 convention D z = q³/(q²+1) CANONICAL (owner ruling 2026-08-15)

    gramEntry / gramMatrix and everything proved about them are convention C. They are correct — every one of the 21 closed forms below equals the generic Gram at z = z_C exactly — but C is not the canonical frame. The gramEntryD / gramMatrixD section further down is the canonical one.

    Why this is not a matter of substituting one z for the other #

    Over ℚ(q, z), with z free, the determinant factors as

    det G(q,z) = −(z − q)⁵ (qz + 1)⁵ ((q²+1)z − q³) (q³z + qz + 1) / q⁸

    and the third factor is (q²+1)z − q³. It vanishes identically in q exactly at z = q³/(q²+1) — convention D. So D is not a frame in which this Gram happens to be singular at the substrate anchor: D is a root of the H_3 Gram determinant as a polynomial in z. Under D the form has rank 5, a one-dimensional radical spanned by the three-strand q-antisymmetriser, and a negative eigenvalue at q₀ besides.

    Consequently gramMatrix_det_ne_zero below — the file's headline theorem, sorry-free and true — is FALSE in the canonical convention, and so is the positive-definiteness reading of it. Both are stated for C and must be cited as C results. markovWeightD_root records the vanishing factor in Lean so that the scoping is machine-checkable rather than a comment someone can tidy away; gramEntryD_zero_one pins which z the D entries were built from, for the same reason.

    Derivation and the six cross-checks (including that this file's own gram_det_eq is reproduced factor for factor from the generic form): computations/probes/gram_h3_convention_frame_probe.py.

    Symbolic Gram (upper triangle, in u = √q) #

      G[0,0] = 1
  G[0,1] = G[0,2] = u/(u²+1) = √q/(q+1)
  G[0,3] = G[0,4] = u²/(u²+1)² = q/(q+1)²
  G[0,5] = (u² + u - 1)/(u²+1)
  G[1,1] = G[2,2] = (u² + u - 1)/u
  G[1,2] = u²/(u²+1)² = q/(q+1)²
  G[1,3] = G[1,4] = G[2,3] = G[2,4] = (u² + u - 1)/(u²+1)
  G[1,5] = G[2,5] = G[3,3] = G[4,4] = (u⁴ + u - 1)(u⁴ + u³ - 1)/[u²(u²+1)²]
  G[3,4] = ((u² + u - 1)/u)² = G[1,1]²
  G[3,5] = G[4,5] = (u¹⁰ + u⁹ − u⁸ − u⁵ + u² + u − 1)/[u⁴(u²+1)]
  G[5,5] = (u¹² + u¹¹ − 2u¹⁰ − u⁹ + 2u⁸ + u⁷ − u⁶ − u⁵ + 2u⁴ + u³ − 2u² − u + 1)/u⁶

        **Why `u > 1` rather than `u ≠ 1`** (correctness fix, 2026-05-25):
sympy factorization of det numerator yields

  ```
  det(G(u)) = -(u-1)(u+1)(u³+u-1)⁵(u³+u²+1)⁵·p(u)·r(u) / (u¹⁰(u²+1)¹²)
    p(u) = u⁶-u⁵+u⁴-u³+2u²-u+1                 (no real roots)
    r(u) = u⁶+u⁵+2u⁴+u³+u²+u+1                 (no positive roots)
  ```

revealing a SECOND positive real root at `u ≈ 0.6823278` (the
real root of `u³+u-1 = 0`) — the older hypothesis `u ≠ 1` was
insufficient. The framework substrate has `q_0 ≈ 1.110 > 1`,
so `u_0 > 1` is the natural domain.

**Proof strategy** (factor-by-factor positivity for `u > 1`):
- `u - 1 > 0`                  by `u > 1`
- `u + 1 > 0`                  by `u > 0`
- `u³ + u - 1 > 1`             by `u > 1` (so `u³ > 1, u > 1`)
- `u³ + u² + 1 > 0`            by `u > 0` (positive monomials)
- `p(u) > 0`                   unconditionally on ℝ (no real roots;
                                numerical minimum on `[0, ∞)` ≈ 0.86)
- `r(u) > 0` for `u > 0`       (all-positive coefficient polynomial)
- denominator `u¹⁰(u²+1)¹² > 0` for `u > 0`

Therefore `det(G(u)) = -(strictly positive) ≠ 0` for `u > 1`.

**Numerical evidence** (sympy + Mathlib's `Matrix.det`):
- `det(gramMatrix 1) = 0`                    (classical limit)
- `det(gramMatrix 0.6823278) = 0`            (newly-found root)
- `det(gramMatrix u_0) ≈ −0.189` at `u_0 ≈ 1.054`
- `rank(gramMatrix u_0) = 6`                 (full rank at substrate)

        Symbolic factorization of det(gramMatrix u) — Phase 1b-2 #

        Per gram-h3-det-factorization.witness.json (sympy at 50-dps), the 6×6 Hoefsmit Gram determinant factors as:

        det(G(u)) = − [ (u−1)·(u+1)·(u³+u−1)⁵·(u³+u²+1)⁵·p(u)·r(u) ] / [ u¹⁰·(u²+1)¹² ]

        where

        • p(u) = u⁶ − u⁵ + u⁴ − u³ + 2u² − u + 1
        • r(u) = u⁶ + u⁵ + 2u⁴ + u³ + u² + u + 1

        The numerator has degree 44 in u; the only positive real roots are u = 1 (classical limit) and u ≈ 0.6823 (root of u³+u−1). For the framework's substrate domain u > 1, all six factors are strictly positive, so the determinant is non-zero.

        This section proves the six positivity lemmas + the main theorem conditional on the symbolic factorization (which is recorded in the witness as a sympy-verified identity).

                          Convention D — the canonical frame #

                          Everything above is convention C. This section is the canonical one (z = q³/(q²+1), owner ruling 2026-08-15).

                          Three things change and one does not:

                          • The entries become rational in q. No √q, hence no Real.sqrt, so nothing here needs ℝ for its statement — only the positivity calls on q² + 1 use the order, and those hold in any LinearOrderedField. Per AGENTS.md §7c that is a strictly better base-ring position than the C section, which cannot escape ℝ.
                          • The determinant is identically zero, not merely small: z_D is a root of the determinant factor (q²+1)z − q³ (markovWeightD_root), so the vanishing is an identity in q, not a numerical coincidence at the substrate anchor. Proved here by exhibiting the radical rather than by a det_fin_six expansion — cheaper, and it produces the null direction instead of merely asserting one exists.
                          • Positive-definiteness fails. It fails already from the radical, before any spectral computation; at q₀ the D-frame spectrum additionally carries a negative eigenvalue (gram-matrix-dual.witness.json), so the form is indefinite, not positive-semi-definite.
                          • Symmetry and G[0,0] = 1 are unchanged, because they hold for every z whatever. They are the part of the C section that transfers.

                          The null direction (−q³, q², q², −q, −q, 1) is −q³ · Σ_w (−1/q)^ℓ(w) T_w, the three-strand q-antisymmetriser — the same object computations/probes/gram_radical_exact_probe.py reaches exactly over ℚ at three rational q, and the same one the qou-u2jg keystone names from the trace side. Here it arrives from the determinant, as an identity in q.

                                  Direct-use pattern #

                                  HasH3GramMatrix was reverted from universal-ilp-algorithm.lean (main commit 91cb2671b, 2026-05-25, "Phase 1a typeclass infrastructure is superseded by the symbolic Gram entries — the typeclass-driven approach added an unnecessary layer of indirection when the categorical entries are directly definable").
