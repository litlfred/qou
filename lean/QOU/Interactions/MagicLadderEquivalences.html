    QOU.Interactions.MagicLadderEquivalences — magic-ladder predicate equivalences #

    After the cleanup of redundant conjectures, the framework has exactly four primary conjectural characterisations of the magic ladder {2, 8, 20, 28, 50, 82, 126}:

    (A) MagicEqualsEmpirical — algebraic primality at q_0 ([conj:algebraic-primality-equals-empirical-at-q0]). (C) ShellCondensationConjecture — homological shell condensation (E_∞^{p, q>0} = 0) ([conj:homological-shell-condensation]). (F) BringShellBindingConjecture — Bring six-torus-knot cumulative shell binding ([prop:torus-knot-shell-binding]). (G) DeltaIBoundConjecture — Δi ≤ 1 LR-fusion compatibility ([conj:double-magic-delta-i-bound]).

    This module records the structural fact that any two of A, C share the same per-n iff with n ∈ magicLadder, and are therefore pairwise equivalent.

    §1 Meta-theorem: iff-with-magicLadder predicates are pairwise equivalent #

    theorem QOU.Interactions.MagicLadderEquivalences.predicate_equivalence_via_magic {P Q : ℕ → Prop} (hP : ∀ (n : ℕ), P n ↔ n ∈ LiftingDescent.HomologicalCondensation.magicLadder) (hQ : ∀ (n : ℕ), Q n ↔ n ∈ LiftingDescent.HomologicalCondensation.magicLadder) (n : ℕ) :
    P n ↔ Q n

    Meta-theorem (transitivity through the magic ladder). Given two predicates P, Q : ℕ → Prop that each satisfy the iff P n ↔ n ∈ magicLadder and Q n ↔ n ∈ magicLadder, they are pairwise equivalent: P n ↔ Q n for every n.

    Proof: chain the two iffs through the middle term.
