    QOU.Interactions.TrefoilCanonicalMassUnit #

    The trefoil T(2,3) is the canonical mass unit for the electron.

    Mathematical content #

    The QOU calibration triangle identifies three inputs (AGENTS.md §"Canonical derivation chain"):

    CAL-1 : m_e — the electron mass (sets the MeV scale) CAL-2 : P_skew^β — the neutron β-sector bar-skew channel (fixes q₀) CAL-3 : P_avg^π — the pion-sector bar-even channel (the meson scale)

    The electron itself is identified with the trefoil knot T(2,3): it is the only closed 3-braid whose Hecke NF coefficient for the antisymmetric (bar-odd) basis element e⁻ is zero at every q (TrefoilVanishing), making it the unique positive-topological-mass knot in the n=2 Hecke sector. Its CAL-1 role asserts:

    m_topological(trefoil) = m_e_MeV_codata

    where m_e_MeV_codata = 0.51099895069 MeV is the CODATA value.

    Lean encoding (§3b-cond) #

    The mass identification is a primary conjecture (no Lean proof from substrate primitives yet — the full derivation chain from the Hecke algebra to a specific MeV value awaits the Markov-trace port). It is axiomatised as a content-bearing class TrefoilElectronMassConj, whose single field states the identification for a given Hecke element, multiplicity and cat-unit scale — the three quantities are class parameters, not class fields, so no instance can be produced without exhibiting an element whose Markov trace actually normalises to one.

    Downstream theorems conditioned on [TrefoilElectronMassConj …] are fully Lean-proved once the class instance is fixed.

    Restated 2026-08-23 (bean qou-lo1t) — the class was inhabited. Its previous form carried the quantities as fields beside equations naming their values:

    trefoil_strand_count : ℕ ; trefoil_strand_eq : trefoil_strand_count = 2
trefoil_crossing_count : ℕ ; trefoil_crossing_eq : … = 3
trefoil_topological_mass : ℝ ; trefoil_mass_eq_m_e : … = m_e_MeV_codata

    so ⟨2, 3, rfl, rfl, m_e_MeV_codata, rfl⟩ discharged it — verified to elaborate. Every "conditional on TrefoilElectronMassConj" theorem in this file was therefore unconditional, and the "open physical identification trefoil ↔ electron" the docstring claimed to encode appeared nowhere in the type: trefoil_strand_count was a free ℕ merely named for the trefoil, with no braid word behind it.

    Two consequences, both applied below. The strand and crossing counts are not conjectural — they are computed from the actual braid word QOU.KnotTheory.trefoil (strands := 2, three positive letters), so they are now unconditional rfl facts rather than assumed fields; this is how QOU.KnotRegistry.trefoil_crossing_count already states the crossing count. The mass identification is the genuinely open part, and is now stated about given data.

    This is an improvement, not a closure: see the residual-weakness note on the class itself. The class remains dischargeable by solving for m_e_cat, because the corpus does not define a cat-unit electron scale to pin it against.

    Already-proved algebraic facts (sorry-free, no class needed) #

    • trefoil_mass_unit_pos: m_e_MeV_codata > 0 (from norm_num)
    • trefoil_coloring_flat_deviation: the coloring deviation is a bar-even square (import from TrefoilColoringBarEven)
    • trefoil_nf_coeff_zero_implies_no_mass_pole: vanishing e⁻ NF coefficient ↔ the knot does not couple to the antisymmetric channel — a purely algebraic consequence

    §2 Primary conjecture class (§3b-tax: primary, no upstream class) #

    source
    class QOU.Interactions.TrefoilCanonicalMassUnit.TrefoilElectronMassConj (T : HeckeAlgebra.HeckeElement 2) (rho : ℕ) (m_e_cat : ℝ) :
    Prop

    Primary conjecture: the trefoil is the canonical mass unit for the electron.

    Stated for given data — a Hecke element T of the n = 2 sector, a multiplicity ρ, and a cat-unit electron scale m_e_cat — all three of which are parameters, so an instance must be supplied against a specific element rather than manufactured alongside one. The single field is the CAL-1 identification: the trefoil's categorical mass in MeV is the CODATA electron mass, i.e. the trefoil is the mass unit.

    This is the open physical identification trefoil ↔ electron, not derived from substrate primitives. A trivial instance is FORBIDDEN per AGENTS.md §3b-tax — and, since m_e_MeV_codata > 0, the field is equivalent to ρ · m_e_cat · |tr_M T| = 1, a constraint relating the three parameters (see trefoil_cat_mass_normalised below).

    Residual weakness, stated rather than papered over (bean qou-lo1t). Parameterising blocks the discharge the old form admitted — ⟨rfl⟩ no longer typechecks, verified — but it does not close the class. Given any T with tr_M T ≠ 0 one may still take ρ := 1 and m_e_cat := 1 / |tr_M T| and prove the field; this was checked and elaborates. What that costs an author is real (a specific element, and a proof its Markov trace is nonzero) and it is now visible — the numbers appear at the instance site — but it is a cheat that remains available. Closing it needs m_e_cat fixed by a definition rather than left free; the corpus has no cat-unit electron scale to point at, only the MeV one (m_e_MeV_codata), so that is the actual gap.

    Status: PRIMARY CONJECTURE (open, no Lean proof from substrate). The class is left without an instance until a derivation is available. @conjecture: primary
