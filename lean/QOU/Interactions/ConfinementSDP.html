    Confinement SDP: matrix Frobenius positivity #

    The confinement SDP is the full matrix-valued problem whose scalar diagonal projection is QOU.Interactions.ConfinementLP. It selects the confined operator via a primal-dual pair of semidefinite programs over End(H_n(q)), with matrix complementary slackness capturing multi-operator binding.

    The scalar LP obtains only when every Wedderburn block decouples; in general the multi-operator regime (binding multiplicity μ ≥ 2) is structural, not exceptional.

    §1 SDP data on H_n(q) (typeclass-supplied per n) #

    The full confinement-SDP solution (Φ*, y₀*, …) requires solving a semidefinite program at strand count n, which depends on Mathlib SDP infrastructure not yet available. Rather than opaque-stubbing each datum, we package them as a typeclass HasConfinementSDPData (n) so callers supply (typically from a numerical SDP solver, e.g. CVXPY/SCS) the cost matrix, primal optimum, target, dual shadow price, and Slater-feasibility predicate.

                §2 The SDP primal–dual theorem #

                Strong duality as a typeclass (Pattern 4) #

                The full SDP strong-duality result requires Mathlib SDP duality, which is not yet available. Rather than asserting strong duality universally as a top-level axiom, we package it as a typeclass HasConfinementSDPStrongDuality. Callers must supply an instance to use the primal–dual identity, making the conjectural content visible at every use site.

                A concrete construction would discharge strong_duality for the specific n of interest (e.g. n = 4 for the proton/neutron Wedderburn blocks).

                source
                class QOU.Interactions.HasConfinementSDPStrongDuality (n : ℕ) [HasConfinementSDPData n] (h : slaterStrict n) :
                Prop

                Confinement SDP — strong-duality typeclass. Holds for (n, h) when the primal SDP min ⟨T, Φ⟩ s.t. Φ ⪰ 0, ⟨π_λ, Φ⟩ ≥ 0, 2×2 pair-PSD, tr(Φ) = n_target and its dual max n_target · y₀ s.t. y₀ I + Σ y_λ π_λ − T ⪯ 0, y_λ ≥ 0 satisfy strong duality ⟨T, Φ*⟩ = n_target · y₀*. By Slater + Boyd–Vandenberghe Thm 5.5, this follows from the Slater-strict hypothesis once Mathlib SDP duality lands.

                • strong_duality : primalOpt n = nTarget n * y0Star n

                  Strong duality. (Needs abstract LP/SDP duality infrastructure that does not exist in Mathlib; kept as an honest assumption for models without certificates)

                  theorem QOU.Interactions.slaterStrict_is_freely_dischargeable (n : ℕ) :
                  ∃ (inst : HasConfinementSDPData n), slaterStrict n

                  The Slater hypothesis of ConfinementSDP is still freely dischargeable — by a different route since 2026-09-07.

                  It used to be free because slaterStrict was a Prop-universe FIELD: the instance supplied a proposition and True was legal. It is now the real condition ∃ Φ, PosDef Φ ∧ Feasible Φ, and the instance below discharges it by choosing a trivial CONE instead — PosDef and Feasible both fun _ => True, witnessed at Φ = 0.

                  Keeping this theorem is the point. The encoding narrowed the freedom without eliminating it, and a theorem that still proves the hypothesis free is the honest record of exactly how much was bought: the shape of Slater's condition, not its content.

                  Note the statement is ∃ inst, slaterStrict and not ∃ _inst, True: the latter says only that the class is inhabited, which is the weak discriminator this corpus already has an audit about (2026-08-09-inhabitation-is-a-weak-discriminator). What is claimed here is stronger and is the point — an instance whose Slater condition holds, by trivial.

                  Kept in the file deliberately, in the idiom of TransferMatrixEigenphase: a demonstration that a field asserts nothing is the honest record while the field cannot yet be encoded.
