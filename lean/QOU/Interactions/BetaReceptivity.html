    Beta decay receptivity: character theory of B₃ #

    Proves exact character values for B₃ = (σ₀σ₁⁻¹)³:

    • Trivial character = 1 (net = 1 exactly)
    • Alternating character = 1

    These are EXACT results in ℤ[t,t⁻¹] (not numerical). The proofs use 1-dimensional representation evaluations, not 2×2 matrix computations.

    References #

    • [prop:demand-stability]
    • [jones1987] https://doi.org/10.2307/1971403

            §2 Character values of σ₀σ₁⁻¹ #

            source
            theorem QOU.Interactions.borromean_unit_trivial_char :
            Archimedean.q_from_t * Archimedean.q_inv_from_t = 1

            In the TRIVIAL representation: σ₀ ↦ q, σ₁⁻¹ ↦ q⁻¹. Therefore σ₀σ₁⁻¹ ↦ q·q⁻¹ = 1.

            This is a computation in R_t (scalars), not in 2×2 matrices.

            source
            theorem QOU.Interactions.borromean_unit_alt_char :
            -Archimedean.q_inv_from_t * -Archimedean.q_from_t = 1

            In the ALTERNATING representation: σ₀ ↦ −q⁻¹, σ₁⁻¹ ↦ −q. (σ₁ ↦ −q⁻¹, and σ₁⁻¹ = σ₁ − HA ↦ −q⁻¹ − (q−q⁻¹) = −q.) Therefore σ₀σ₁⁻¹ ↦ (−q⁻¹)(−q) = 1.

            §3 Character values of B₃ = (σ₀σ₁⁻¹)³ #

            source
            theorem QOU.Interactions.borromean3_net_exact :
            (Archimedean.q_from_t * Archimedean.q_inv_from_t) ^ 3 = 1

            net(B₃) = χ_triv(B₃) = 1 EXACTLY for all q.

            Proof: χ_triv is multiplicative on the group algebra. χ_triv(σ₀σ₁⁻¹) = 1 (proved above). χ_triv(B₃) = χ_triv((σ₀σ₁⁻¹)³) = 1³ = 1.
