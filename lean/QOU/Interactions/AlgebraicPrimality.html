    QOU.Interactions.AlgebraicPrimality — magic via tensor-product irreducibility #

    A pure-math definition of "magic" without empirical input. For each strand count n and substrate q, the confinement SDP gives a canonical state ψ_n(q). We say n is magic at q iff ψ_n(q) is algebraically prime: not in the closed span of any non-trivial tensor product ψ_{n_1}(q) ⊗ ... ⊗ ψ_{n_k}(q) with k ≥ 2 and n_i ≥ 1.

    This file:

    • defines the magic predicate as an axiom-class (the SDP machinery is not formalised here; only the structural primality logic);
    • proves the base case n = 1 is vacuously prime;
    • exposes the conjectural empirical-match claim as a typeclass.

        Prop

        The "is in the closed span of tensor products of canonical states indexed by a decomposition" predicate. opaque since 2026-08-24; the genuine span predicate is still the upgrade target.

        It was def … : Prop := False, ignoring all four of its arguments. Its own docstring drew the consequence — "every n ≥ 1 is therefore algebraically prime" — and stopped there. That consequence is not a harmless simplification; it is the negation of what this file exists to state. IsAlgebraicallyPrime n q unfolded to n ≥ 1 ∧ ∀ decomp, … → ¬False, i.e. definitionally to n ≥ 1. So IsKnownMagic n q was provable in one line for every n ≥ 1, magic or not, and IsKnownNotMagic n q was unprovable for every n ≥ 1 — while MagicEqualsEmpirical asserts primality holds exactly on {2, 8, 20, 28, 50, 82, 126} and magicEqualsEmpirical_of_perNAxioms needs both halves. The model did not under-specify the conjecture; it contradicted it.

        Sealing the body keeps the type and every structural result that quantifies over the predicate (IsAlgebraicallyPrime, not_prime_of_inTensorSpan, two_isAlgebraicallyPrime) while removing the ability to discharge a primality claim by unfolding. Same remedy, and the same reason, as the three opaque surreal placeholders in QOU/AppendixSurreals/Conjectures.lean.

          §3 The algebraic-primality definition #

          source
          def QOU.Interactions.AlgebraicPrimality.IsAlgebraicallyPrime (n : ℕ) (q : ℝ) :
          Prop

          Definition (algebraic primality). A natural number n ≥ 1 is algebraically prime at substrate q if and only if canonicalState n q is not in the closed span of any non-trivial tensor-product decomposition.

          Conventions:

          • n = 0 is not prime (vacuum).
          • n = 1 is prime vacuously — no non-trivial decomposition exists.
          • For n ≥ 2, primality is non-trivial.

            §5 Vacuous primality at n = 1 #

            source
            theorem QOU.Interactions.AlgebraicPrimality.one_isAlgebraicallyPrime (q : ℝ) :
            IsAlgebraicallyPrime 1 q

            Theorem (prop:n-equals-1-vacuous-magic). For every q : ℝ, the integer n = 1 is algebraically prime — vacuously, because no decomposition into k ≥ 2 parts each ≥ 1 can sum to 1.

            The proof needs only elementary arithmetic: a list of length ≥ 2 with all entries ≥ 1 has sum ≥ 2 > 1, contradicting sum = 1. No SDP / Hecke / tensor-product analysis is invoked.

                    §9 Partial proof — assembling the conjecture from per-n facts #

                    source
                    def QOU.Interactions.AlgebraicPrimality.magicEqualsEmpirical_of_perNAxioms {q : ℝ} (h_q : 1 < q) (h_in : ∀ n ∈ empiricalMagicLadder, IsKnownMagic n q) (h_out : ∀ n ∉ empiricalMagicLadder, IsKnownNotMagic n q) :
                    MagicEqualsEmpirical

                    Theorem (assembly). Suppose we have, at substrate q:

                    • For every n ∈ empiricalMagicLadder, an IsKnownMagic n q instance.
                    • For every n ∉ empiricalMagicLadder, an IsKnownNotMagic n q instance.

                    Then the conjecture MagicEqualsEmpirical holds at q.

                    This is the structural conjecture: it factors the iff into per-n axioms. The n = 1 axiom is discharged by the proved one_isKnownMagic instance; the others (n in {2, 8, 20, 28, 50, 82, 126} and n outside the ladder) remain conjectural, waiting for the SDP machinery.

                      class QOU.Interactions.AlgebraicPrimality.NonTrivialBindingAtTwo (q : ℝ) :
                      Prop

                      Typeclass (n = 2 binding axiom). The single non-trivial axiom needed to discharge IsKnownMagic 2 q: at substrate q, the canonical state ψ_2(q) is not in the closed tensor span of ψ_1 ⊗ ψ_1 (the unique non-trivial decomposition of 2).

                      This is the minimal axiom — by decomp_two_eq_oneOne, proving primality at n = 2 reduces to this single check.

                      In framework language: the SDP at n = 2 produces a non-trivial bound state, distinct from two free single-strands. Empirically expected at any reasonable substrate q > 1.

                      • not_in_oneOne_span : ¬InTensorSpan 2 q (canonicalState 2 q) [1, 1]

                        ψ_2(q) is not in the tensor span via decomposition [1, 1].

                        §11 The n = 2 binding axiom has no model — and that is the point #

                        Until 2026-08-24 this section read:

                        /-- **Trivial-model instance.**  On the concrete `InTensorSpan ≡ False`
    model, `not_in_oneOne_span` reduces to `¬ False`, which is `True`.
    Provides a Lean-verified discharge of the n = 2 axiom on every
    substrate `q`. -/
instance trivialBindingAtTwo (q : ℝ) : NonTrivialBindingAtTwo q where
  not_in_oneOne_span := not_false

                        The description was accurate and the instance was worthless: ¬ False is not evidence that ψ_2(q) fails to decompose, it is evidence that InTensorSpan had been defined to hold of nothing. Being an instance, it discharged [NonTrivialBindingAtTwo q] at every real q, and two_isKnownMagic_of_nonTrivialBinding chained off it, so IsKnownMagic 2 q — the first non-trivial magic shell, the one the whole per-n factorisation is aimed at — resolved for free.

                        With InTensorSpan now opaque the witness no longer typechecks, and no instance is provided. That is the honest open state (AGENTS.md §3b-tax: "an unproved primary is honestly represented by a content-bearing class with no instance; do not fabricate a trivial instance to 'close' it"). Demoting the instance to a def would not have been enough on its own: with InTensorSpan ≡ False still unfolding, anyone could rebuild the witness inline without naming anything, so the root had to go first and the instance then went with it.

                        Nothing else in this file depended on it — one_isKnownMagic and zero_isKnownNotMagic are real proofs (vacuous quantification at n = 1; the n ≥ 1 clause at n = 0) that never consult InTensorSpan's body, and this module has no importers.

                        What is now genuinely open, and was previously masked: a model of InTensorSpan in which IsKnownNotMagic n q is provable for n ∉ empiricalMagicLadder. magicEqualsEmpirical_of_perNAxioms needs that half too, and the ≡ False model made it unprovable for every n ≥ 1.
