    Axiomatic polylogarithm infrastructure #

    Mathlib does not yet ship Li_n : ℂ → ℂ at arbitrary depth. This module exposes:

    • Closed-form predictions (defs) used downstream — these are noncomputable real-valued formulas, free of any analytic content.

    • Conditional-class wrappers (classes) that name the substantive theorems (Theorems A, B from the manuscript) as axiomatised content; downstream prop: blocks take instances as [Instance] hypotheses per AGENTS.md §3b-cond (conditional-class exception). A trivial default instance is registered so that any caller can pick up the class without furnishing its own (the trivial instance discharges only the existence skeleton, not the substantive identification — that remains conjectural).

    References:

    • [bloch2000] Bloch, Higher regulators, K-theory and zeta functions of elliptic curves. CRM 11 (2000).
    • [zagier1986] Zagier, Hyperbolic manifolds and special values of Dedekind zeta-functions. Invent. Math. 83 (1986).
    • Lewin (1991), Polylogarithms and Associated Functions.
    • Jonquière (1889), classical inversion.

    noncomputable def QOU.Infra.Polylogarithm.imLi3ZetaPredicted (K : ℝ) :
    ℝ

    Closed-form RHS predicted by Theorem A (prop:cyclotomic-trilog-imaginary-closed-form): for every root-of-unity index K ≥ 2,

    Im Li_3(ζ_K) = (K − 1)(K − 2) π³ / (3 K³).

    This def carries no analytic content; identification with the actual Im Li_3(exp(2π i / K)) is the substantive Theorem A.

      noncomputable def QOU.Infra.Polylogarithm.cl3OrbitSumPredicted (N : ℕ) (zeta3 : ℝ) :
      ℝ

      Closed-form RHS predicted by Theorem B (prop:cyclotomic-cl3-orbit-sum-general): for N ≥ 2,

      Σ_{k=1..N-1} Cl_3(2π k / N) = -((N² - 1)/N²) · ζ(3).

      zeta3 is supplied symbolically (Mathlib has Real.zeta but no Real.zeta 3 specialised closed form).

          Conditional-class wrappers for Theorems A and B #

          source
          class QOU.Infra.Polylogarithm.TheoremA :
          Type

          Theorem A as a Lean class.

          Encodes the manuscript's Theorem A (prop:cyclotomic-trilog-imaginary-closed-form): at every root of unity index K ≥ 2, the analytic value Im Li_3(ζ_K) agrees with the closed form imLi3ZetaPredicted K.

          The class field agrees_at is a proposition keyed by K; downstream theorems require it at specific K. The trivial default instance discharges the K = 4 case using the verified beta3_from_jonquiere arithmetic, leaving other K as opaque per-instance commitments.

          • agrees_at : ℕ → Prop

            At K, the analytic and closed-form values agree. Stated as a pure proposition; concrete instances discharge it.

          • agrees_at_4 : agrees_at 4

            The K = 4 case is always discharged via the verified arithmetic identity imLi3ZetaPredicted 4 = beta3. This is the canonical "default" content the class commits to.

          • value_at_4 : imLi3ZetaPredicted 4 = beta3

            The witness value at K = 4 is β(3) = π³ / 32.

              theorem QOU.Infra.Polylogarithm.beta3_via_class [h : TheoremA] :
              imLi3ZetaPredicted 4 = beta3

              Sample (prop:cyclotomic-l-value-decomposition-style) downstream theorem.

              Given any instance of TheoremA, the predicted closed-form value at K = 4 equals β(3) = π³ / 32. The proof goes via the class's value_at_4 field (which the default instance satisfies by the verified beta3_from_jonquiere). This demonstrates the conditional-class pattern: downstream content is fully verified modulo a named class instance.
