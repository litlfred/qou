    Axiomatic Clausen function infrastructure #

    The Glaisher–Clausen function

    Cl_n(θ) :=  Im Li_n(e^{iθ})   if n is even
         :=  Re Li_n(e^{iθ})   if n is odd

    is not yet in Mathlib. This file packages the closed-form predictions used downstream as axiomatic functions, with the substantive series-identification deferred to the TheoremA / TheoremB / JonquiereGeneral classes in QOU.Infra.Polylogarithm.

    References:

    • [zagier1986] Zagier, polylogarithms and L-values.
    • Lewin (1991), Polylogarithms and Associated Functions, Ch. 4.

    noncomputable def QOU.Infra.Clausen.clNAtZetaPredicted (n K : ℕ) (zetaN : ℝ) :
    ℝ

    Closed form for Cl_n at every depth and root of unity index, predicted by Theorems E + F + G (the all-depths generalisation of Theorems A + B). For n odd this is the orbit-sum multiplier; for n even it vanishes (parity case-split).

    Equations
    • QOU.Infra.Clausen.clNAtZetaPredicted n K zetaN = if n % 2 = 1 then (↑K ^ (1 - ↑n) - 1) * zetaN else 0

      noncomputable def QOU.Infra.Clausen.jonquiereWrongParity (n K : ℕ) (bernoulliAtOneOverK : ℝ) :
      ℝ

      Jonquière inversion (closed-form RHS) at depth n. The "wrong-parity" part of Li_n(ζ_K) equals -(2π i)^n / n! · B_n(1/K).

      Right now we encode the real-part magnitude using a Bernoulli polynomial value supplied symbolically (Mathlib has Polynomial.bernoulli but partial evaluation infrastructure). Concrete instances of JonquiereGeneral plug in the actual Bernoulli value.

      Equations
      • QOU.Infra.Clausen.jonquiereWrongParity n K bernoulliAtOneOverK = -((2 * Real.pi) ^ n / ↑n.factorial) * bernoulliAtOneOverK
