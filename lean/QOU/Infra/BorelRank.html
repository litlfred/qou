    Axiomatic Borel rank infrastructure #

    Borel's theorem on the ranks of K_{2n-1}^{ind}(F) ⊗ ℚ for a number field F is not in Mathlib. This file packages the rank formula as a typeclass BorelRank together with the explicit dimension constants used in prop:borel-partial-resolution and prop:depth-2-identification-bloch-suslin.

    References:

    • Borel (1977), Cohomologie réelle stable de groupes S-arithmétiques classiques. Publ. Math. IHÉS 64 (1977), 185-202.
    • [bloch2000] Bloch, Higher regulators.
    • [suslin1991] Suslin, K_3 of a field, and the Bloch group.

    def QOU.Infra.BorelRank.borelRankPredicted (n r1 r2 : ℕ) :
    ℕ

    Borel rank of K_{2n-1}^{ind}(F) ⊗ ℚ for a number field with (r_1, r_2) real-and-complex embeddings. For n ≥ 2:

    n even: r_1 + r_2 n odd: r_2

    Formula expressed on naturals.

      class QOU.Infra.BorelRank.BorelRank (F : Type u_1) :
      Type

      Borel rank as a class. Records the rank of the indecomposable K-theory at every depth n ≥ 2 for the relevant field. Concrete instances (e.g. cyclotomic fields ℚ(ζ_K)) instantiate (r_1, r_2) and supply a rank_witness predicate identifying borelRankPredicted with the actual dim_ℚ K_{2n-1}^{ind}(F) ⊗ ℚ.

      Per Gemini review: the previous existence-only field ∃ d, d = borelRankPredicted n r1 r2 was vacuous (always satisfiable by ⟨borelRankPredicted n r1 r2, rfl⟩). Mirrors the meaningful pattern used in QOU.Infra.Polylogarithm.TheoremA: a rank_witness : ℕ → Prop predicate that concrete instances sharpen plus a verified arithmetic identity at depth 2 (where Bloch-Suslin discharges unconditionally) and 3 (where the rank formula reduces to elementary arithmetic).

      • r1 : ℕ

        Number of real embeddings of F.

      • r2 : ℕ

        Number of pairs of complex embeddings of F.

      • rank_witness : ℕ → Prop

        At depth n, the predicted Borel rank agrees with the actual dim_ℚ K_{2n-1}^{ind}(F) ⊗ ℚ. Stated as an opaque predicate that concrete instances may discharge.

      • rank_witness_2 : rank_witness F 2

        At depth 2 (Bloch-Suslin), the witness is discharged. This is the canonical "depth-2 unconditional" content.

      • rank_formula_arith (n : ℕ) : 2 ≤ n → borelRankPredicted n (r1 F) (r2 F) = if n % 2 = 0 then r1 F + r2 F else r2 F

        Verified arithmetic: the predicted rank at depth n is determined by parity of n and the embedding pair (r_1, r_2). This is the closed-form Borel formula stripped of K-theoretic content — pure case-split.

        def QOU.Infra.BorelRank.cyclotomicBorelRank (K n : ℕ) :
        ℕ

        Cyclotomic field embeddings: for ℚ(ζ_K) with K prime ≥ 3, (r_1, r_2) = (0, (K-1)/2). Borel rank at depth n:

        n even: (K-1)/2 n odd: (K-1)/2

        (same formula in this case since r_1 = 0).
