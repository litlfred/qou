    Axiomatic Dirichlet L-value infrastructure #

    L(χ, n) for a Dirichlet character χ mod K and integer n ≥ 2 is not yet in Mathlib as a first-class function (Mathlib has DirichletCharacter but not the L-series evaluation at integer arguments). This file packages the L-value as an axiomatic function and records the Hurwitz-Lerch decomposition used in prop:cyclotomic-l-value-decomposition.

    References:

    • [bloch2000] Bloch, Higher regulators, K-theory and L-values.
    • [zagier1986] Zagier, polylogarithms and L-value identities.

      class QOU.Infra.DirichletL.DirichletLClass (K : ℕ) (chi : ℕ → ℝ) :
      Prop

      Hurwitz-Lerch decomposition (axiomatic form).

      Encodes the manuscript identity

      L(χ, n) = N^{-n} Σ_{a=1..N-1} χ(a) · ζ_H(n, a/N)

      via the relation between L(χ, n) and the Hurwitz zeta values ζ_H(n, a/N). The full statement is conditional on Polylogarithm.TheoremA (which identifies the cyclotomic polylog values) plus the Gauss-sum identity on χ.

      • hurwitz_lerch (n : ℕ) : 2 ≤ n → ∃ (y : ℝ), y = lValueAxiomatic K chi n

        The Hurwitz-Lerch decomposition holds at every depth n ≥ 2.

          Placeholder, not the identity. Intended: the classical β(3) = L(χ_4, 3), whose proof from Theorem A (via Im Li_3(i) = β(3)) is in prop:cyclotomic-l-value-decomposition.

          Actually True, so it is inhabited by trivial and asserts nothing — the identity is named here, not stated. Nothing in the corpus references this declaration, so it is inert rather than harmful, but do not read a use of it as a use of the identity. Stating it properly needs β and L(χ, s) as Mathlib objects; neither is in scope in this file, which is why the placeholder exists. Tracked as qou-35zi.
