    theorem QOU.Knot.FigureEightVolume.log_cell_telescope {h : ℝ} (hh : 0 < h) (n : ℕ) :
    ∑ j ∈ Finset.Icc 1 n, ((∫ (u : ℝ) in (↑j - 1) * h..↑j * h, Real.log u) - h * Real.log (↑j * h)) = h * (↑n * Real.log ↑n - ↑n - Real.log ↑n.factorial)

    L4-1c(i) — the singular part telescopes exactly (sorry-free). For every grid spacing h > 0 and every n,

    Σ_{j=1}^{n} ( ∫_{(j−1)h}^{jh} log u du − h·log(jh) )
  = h · ( n·log n − n − log(n!) ).

    The log h pieces cancel identically and the log j pieces telescope; the right-hand side is exactly the combination the Stirling brick (tendsto_log_factorial_stirling) evaluates.
