    noncomputable def QOU.Knot.GradedGeneratingFunction.gf {ι : Type u_1} {R : Type u_2} [CommSemiring R] (s : Finset ι) (c : ι → R) (deg : ι → ℕ) :
    Polynomial R

    The grade generating function ∑_{i ∈ s} c i · X^(deg i).

    Over ℤ[q,q⁻¹] with deg the Coxeter length and c the normal-form coefficients, this is the G_E(x) the arc measures.

      (gf (Fintype.piFinset S) (fun (f : (a : κ) → α a) => ∏ i : κ, c i (f i)) fun (f : (a : κ) → α a) => ∑ i : κ, deg i (f i)) = ∏ i : κ, gf (S i) (c i) (deg i)

      Multiplicativity over a dependent product index set.

      When the index set is ∏ᵢ S i, the coefficient multiplicative across factors and the degree additive, the generating function is the product of the factors' generating functions.

      This is the form the block factorisation needs: nucleon blocks are not identical to one another -- block i is supported on strands [bᵢ, bᵢ₊₁) -- so the family S i must be allowed to vary with i. The constant-family case is QOU.Knot.BodyOrderExpansion.gf_pow.

      theorem QOU.Knot.GradedGeneratingFunction.gf_shift {ι : Type u_1} {R : Type u_2} [CommSemiring R] (s : Finset ι) (c : ι → R) (deg : ι → ℕ) :
      (gf s c fun (i : ι) => deg i + 1) = Polynomial.X * gf s c deg

      A degree shift is multiplication by X.

      This is the promotion theorem's image in the generating function: raising every degree by one, with coefficients untouched, multiplies G by X.

      theorem QOU.Knot.GradedGeneratingFunction.gf_interface {ι : Type u_1} {R : Type u_2} [CommSemiring R] (s : Finset ι) (c : ι → R) (deg : ι → ℕ) (d : R) :
      (gf s c fun (i : ι) => deg i + 1) + Polynomial.C d * gf s c deg = (Polynomial.X + Polynomial.C d) * gf s c deg

      The canonical interface is multiplication by X + C d.

      The interface σ_g + d·I acts as (promotion) + (d times the original), and the generating function turns that into (X + C d) · G. With d = 0 it degenerates to gf_shift, which is the bare-word bridge.
