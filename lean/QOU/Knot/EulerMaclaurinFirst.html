    theorem QOU.Knot.grid_defect_bracket {f f' : ℝ → ℝ} {h : ℝ} (hh : 0 < h) {n : ℕ} (hderiv : ∀ x ∈ Set.Icc 0 (↑n * h), HasDerivAt f (f' x) x) (hanti : AntitoneOn f' (Set.Icc 0 (↑n * h))) :
    h ^ 2 / 2 * ∑ i ∈ Finset.range n, f' ((↑i + 1) * h) ≤ ∑ i ∈ Finset.range n, ∫ (u : ℝ) in ↑i * h..(↑i + 1) * h, f ((↑i + 1) * h) - f u ∧ ∑ i ∈ Finset.range n, ∫ (u : ℝ) in ↑i * h..(↑i + 1) * h, f ((↑i + 1) * h) - f u ≤ h ^ 2 / 2 * ∑ i ∈ Finset.range n, f' (↑i * h)

    First Euler–Maclaurin correction on a uniform grid. For f with antitone derivative on [0, nh], the right-endpoint Riemann defect is bracketed by h²/2 times the two endpoint Riemann sums of f′:

    (h²/2)·Σ_{i<n} f′(x_{i+1})  ≤  Σ_{i<n} ∫_{cell_i} (f(x_{i+1}) − f(u)) du
                            ≤  (h²/2)·Σ_{i<n} f′(x_i).

    Both envelopes are (h/2) times a Riemann sum of f′ over [0, nh], so both converge to (h/2)·(f(nh) − f(0)) — the first Euler–Maclaurin term.
