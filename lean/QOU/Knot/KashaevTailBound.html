    Part 1 — cot is antitone on (0, π) #

    source
    theorem QOU.Knot.FigureEightVolume.cot_antitoneOn {c d : ℝ} (hc : 0 < c) (hd : d < Real.pi) :
    AntitoneOn (fun (θ : ℝ) => Real.cos θ / Real.sin θ) (Set.Icc c d)

    cot is antitone on any [c,d] ⊂ (0, π): its derivative is −csc² < 0.

    Part 2 — the tangent and secant bounds at θ* = 5π/6 #

    source
    theorem QOU.Knot.FigureEightVolume.log_two_sin_le_tangent {θ : ℝ} (h0 : 0 < θ) (hπ : θ < Real.pi) :
    Real.log (2 * Real.sin θ) ≤ -√3 * (θ - 5 * Real.pi / 6)

    Tangent bound (concavity). log(2 sin θ) ≤ −√3 (θ − 5π/6) on (0, π). Equality exactly at θ*; this is the whole source of the right tail's Gaussian decay.

    Part 3 — the right tail is Gaussian #

    source
    theorem QOU.Knot.FigureEightVolume.kashaevProd_succ_le_exp {N k : ℕ} (hN : N ≠ 0) (hkN : k + 1 < N) :
    kashaevProd N (k + 1) ≤ kashaevProd N k * Real.exp (-(2 * √3) * ((↑k + 1) * Real.pi / ↑N - 5 * Real.pi / 6))

    One step of the right tail: past the saddle the ratio is at most exp(−2√3 (θ − θ*)).

    source
    theorem QOU.Knot.FigureEightVolume.kashaevProd_right_tail {N : ℕ} (hN : 6 ≤ N) (d : ℕ) (hd : 5 * N / 6 + d < N) :
    kashaevProd N (5 * N / 6 + d) ≤ kashaevProd N (5 * N / 6) * Real.exp (-(√3 * Real.pi * ↑d * (↑d - 1) / ↑N))

    The right tail is Gaussian. kashaevProd N (k*+d) ≤ kashaevProd N k* · exp(−√3 π d(d−1)/N).

    The exponent is quadratic in d because the tangent bound at θ* makes the per-step penalty grow LINEARLY: summing an arithmetic progression is where the d² comes from. Bounding every factor by the first would give only e^{−cd/N} and would not confine the sum to a √N-window.

    Part 4 — the left tail, from a SECANT bound #

    Concavity is the wrong way round on the left: the terms are rising towards the saddle, so what is needed is a LOWER bound on f = log(2 sin), and the tangent gives an upper one. A secant does the job on a bounded window — cot is antitone, so cot ≤ cot(2π/3) = −1/√3 on [2π/3, θ*], and integrating that back from θ* (where f vanishes) gives f(θ) ≥ (θ* − θ)/√3 there.

    theorem QOU.Knot.FigureEightVolume.kashaevProd_left_tail {N b : ℕ} (hN : N ≠ 0) (hb : 6 * b ≤ 5 * N) (d : ℕ) (hd : d ≤ b) (hlo : 2 * N ≤ 3 * (b - d)) :
    kashaevProd N (b - d) ≤ kashaevProd N b * Real.exp (-(Real.pi * ↑d * (↑d - 1) / (√3 * ↑N)))

    The left tail is Gaussian too. For b ≤ 5N/6 and d steps back that stay above 2π/3,

    kashaevProd N (b−d) ≤ kashaevProd N b · exp(−π d(d−1)/(√3 N)).

    The step-d gain is θ* − θ_{b−d}, which is at least d·h precisely because b ≤ 5N/6 — the same arithmetic progression as the right tail, run backwards, with 1/√3 in place of √3 because a secant is shallower than the tangent.

    Part 5 — the upper half-sum is O(√N) times its largest term #

    This is where the N^{3/2} comes from. log_kashaev_le_log_add already gives ⟨4₁⟩_N ≤ N · g_{k*} — enough for the exponential growth RATE and nothing finer. Feeding the Gaussian tail into sum_exp_neg_mul_mul_pred_le replaces that N by 2 + ½√(N/√3), and √(N/√3) is exactly the Laplace factor the tetrahedral probe measures.

    ∑ k ∈ Finset.Ico (5 * N / 6) N, kashaevProd N k ≤ kashaevProd N (5 * N / 6) * (2 + √(↑N / √3) / 2)

    The sum from the saddle upward is O(√N) times its largest term.

    source
    theorem QOU.Knot.FigureEightVolume.sum_kashaevProd_left_window_le {N : ℕ} (hN : 6 ≤ N) (m : ℕ) (hm : m ≤ 5 * N / 6) (hw : 2 * N ≤ 3 * (5 * N / 6 - m)) :
    ∑ d ∈ Finset.range m, kashaevProd N (5 * N / 6 - d) ≤ kashaevProd N (5 * N / 6) * (2 + √(√3 * ↑N) / 2)

    The window below the saddle is O(√N) times its largest term too.

    Stated by DISTANCE d from the saddle rather than by index k, which is how kashaevProd_left_tail is indexed — so no reindexing is needed and the Gaussian sum bound applies directly. The set {k* − d : d < m} is Ico (k*−m+1) (k*+1); saying so is not needed to state or use the bound.

    The window hypothesis 2N ≤ 3(k*−m) is the secant's domain θ ≥ 2π/3, so m reaches about N/6 — far wider than the √N that matters.

    Part 6 — the region below the secant window #

    sum_kashaevProd_left_window_le reaches down only to θ = 2π/3; below that the secant is no longer valid. What is there instead is the DOWN–UP–DOWN shape: the sequence falls on [0, ⌊N/6⌋] and rises on [⌈N/6⌉, w], so every term is dominated by one of the two ENDS of that stretch. No analysis is needed, only the monotonicity runs from KashaevArgmax.

    theorem QOU.Knot.FigureEightVolume.kashaevProd_le_max_of_le {N k w : ℕ} (hN : N ≠ 0) (hkw : k ≤ w) (hw : 6 * w ≤ 5 * N) :
    kashaevProd N k ≤ max 1 (kashaevProd N w)

    Below the window, every term is dominated by an endpoint: g_k ≤ max 1 g_w for k ≤ w ≤ 5N/6. 1 = kashaevProd N 0 covers the falling stretch and g_w the rising one.

    theorem QOU.Knot.FigureEightVolume.sum_kashaevProd_below_window_le {N w : ℕ} (hN : N ≠ 0) (hw : 6 * w ≤ 5 * N) :
    ∑ k ∈ Finset.range w, kashaevProd N k ≤ ↑w * max 1 (kashaevProd N w)

    The whole region below the secant window is at most w · max 1 g_w.

    That is O(N) times an endpoint value, not O(√N) times the peak — but the endpoint g_w is itself exponentially below the peak (kashaevProd_left_tail at distance k* − w ≈ N/6), so the region contributes O(1) relative to g_{k*} rather than O(√N). Turning that into a single numeric constant is arithmetic over e^{−x} ≤ 1/x and N² ≤ g_{k*}; it is NOT done here, and this lemma alone does not bound ⟨4₁⟩_N.

    theorem QOU.Knot.FigureEightVolume.sq_le_kashaevProd_argmax {N : ℕ} (hN : 6 ≤ N) :
    ↑N ^ 2 ≤ kashaevProd N (5 * N / 6)

    N² ≤ kashaevProd N ⌊5N/6⌋ — the peak dominates the exact endpoint value kashaevProd N (N−1) = N². Sharper than one_le_kashaevProd_argmax, and it is what makes the k ≤ N/6 terms (each ≤ 1) negligible against the peak.

    Part 7 — the first LOWER bound: the peak is not a spike #

    Everything above bounds the terms from ABOVE, which gives an upper bound on ⟨4₁⟩_N and therefore an inequality, not a value. Laplace needs the other side: the terms near the peak must stay LARGE over a √N-wide stretch, or the sum could be g_{k*} and nothing more.

    The bound needed is the mirror image, and the surprise is that it needs no new analysis. Below θ* the terms are rising, so a LOWER bound on g_{k*−d} needs an UPPER bound on the accumulated log(2 sin) — and that is exactly what the TANGENT gives. Concavity, which pointed the wrong way for the upper bound on the left, points the right way here. In particular there is NO WINDOW: the tangent bound is global on (0, π), so this holds for every d ≤ k*.

    theorem QOU.Knot.FigureEightVolume.kashaevProd_ge_left {N : ℕ} (hN : 6 ≤ N) (d : ℕ) (hd : d ≤ 5 * N / 6) :
    kashaevProd N (5 * N / 6) * Real.exp (-(√3 * Real.pi * ↑d * (↑d + 1) / ↑N)) ≤ kashaevProd N (5 * N / 6 - d)

    Lower bound below the saddle. g_{k*−d} ≥ g_{k*}·exp(−√3π d(d+1)/N), for every d ≤ k*.

    Note d(d+1), not d(d−1): bounding from below costs one step more than bounding from above, because the d-th step back is at most (d+1)h from θ* rather than at least (d−1)h.

    Part 8 — the sum below the saddle is at least m terms' worth #

    The mirror of Part 5/6's upper bounds. It needs no integral comparison and no Gaussian integral: the exponent d(d+1) is monotone in d, so every term of ∑_{d<m} is at least the LAST one, and the sum is at least m copies of it. Choosing m ≈ √(N/(√3π)) makes that last term ≥ e^{−1}, so the sum is ≥ e^{−1}·m·g_{k*} — the √N from below.

    theorem QOU.Knot.FigureEightVolume.le_sum_kashaevProd_left {N : ℕ} (hN : 6 ≤ N) (m : ℕ) (hm : m ≤ 5 * N / 6) :

    Lower bound for the window sum, the mirror of sum_kashaevProd_left_window_le. Every term is at least the last.

    theorem QOU.Knot.FigureEightVolume.le_sum_kashaevProd_left_of_sq {N m : ℕ} (hN : 6 ≤ N) (hm : m ≤ 5 * N / 6) (hsq : √3 * Real.pi * ↑m ^ 2 ≤ ↑N) :

    The √N from below. When √3·π·m² ≤ N the last term is ≥ e^{−1}, so the window sum is at least e^{−1}·m·g_{k*}. Taking m ≈ √(N/(√3π)) makes that ≥ c√N·g_{k*} — the matching side of sum_kashaevProd_right_le.

    Part 9 — recombination #

    The window sums are indexed by DISTANCE from the saddle (which is what made the Gaussian bounds apply with no reindexing); ⟨4₁⟩_N is indexed by k. Moving between them is one order-reversing reindex, and then the three regions are an exact three-way split of Finset.range N.

    source
    theorem QOU.Knot.FigureEightVolume.sum_kashaevProd_Icc_eq {N w : ℕ} (hw : w ≤ 5 * N / 6) :
    ∑ k ∈ Finset.Icc w (5 * N / 6), kashaevProd N k = ∑ d ∈ Finset.range (5 * N / 6 - w + 1), kashaevProd N (5 * N / 6 - d)

    The distance-indexed window sum IS the interval sum, reflected.

    source
    theorem QOU.Knot.FigureEightVolume.sum_kashaevProd_le_split {N w : ℕ} (hN : 6 ≤ N) (hw1 : 6 * w ≤ 5 * N) (hw2 : 2 * N + 3 ≤ 3 * w) (hwk : w ≤ 5 * N / 6) :
    ∑ k ∈ Finset.range N, kashaevProd N k ≤ ↑w * max 1 (kashaevProd N w) + kashaevProd N (5 * N / 6) * (2 + √(√3 * ↑N) / 2) + kashaevProd N (5 * N / 6) * (2 + √(↑N / √3) / 2)

    The three regions, recombined. An exact split of Finset.range N into [0, w), [w, k*] and (k*, N), each bounded by the corresponding lemma.

    Every piece here is sorry-free, but the first summand is O(N)·max 1 g_w, NOT O(√N)·g_{k*} — collapsing it needs the numeric constant recorded in the bean (e^{−x} ≤ 1/x against D = k*−w ≈ N/6, threshold N ≥ 62). So this is a bound on ⟨4₁⟩_N in three named pieces, not the C√N·g_{k*} statement.

    hw2 is 2N + 3 ≤ 3w, one step stricter than the secant window's 2N ≤ 3w: the middle region here is the CLOSED [w, k*], so the distance-indexed sum runs to d = k*−w, which lands at w — and the window has to hold there too.

    Part 10 — collapsing the below-window region against the peak #

    sum_kashaevProd_below_window_le bounds that region by w·max 1 g_w, which is O(N) times an ENDPOINT value. Two facts turn it into O(1) times the PEAK:

    • N² ≤ g_{k*} (sq_le_kashaevProd_argmax), so the 1 costs g_{k*}/N²;
    • g_w ≤ g_{k*}·e^{−x} with x = πD(D−1)/(√3N), D = k*−w (kashaevProd_left_tail), and e^{−x} ≤ 1/x.

    e^{−x} ≤ 1/x rather than a threshold on N is deliberate: it is x ≤ e^x, one line from Real.add_one_le_exp, and it keeps the statement free of any "for N large enough".

    theorem QOU.Knot.FigureEightVolume.sum_kashaevProd_below_window_le_argmax {N w : ℕ} (hN : 6 ≤ N) (hw1 : 6 * w ≤ 5 * N) (hw2 : 2 * N ≤ 3 * w) (hwk : w ≤ 5 * N / 6) (hD : 2 ≤ 5 * N / 6 - w) :
    ∑ k ∈ Finset.range w, kashaevProd N k ≤ kashaevProd N (5 * N / 6) * (↑w / ↑N ^ 2 + ↑w * (√3 * ↑N) / (Real.pi * ↑(5 * N / 6 - w) * (↑(5 * N / 6 - w) - 1)))

    Both summands are O(1): w ≤ N makes the first ≤ 1/N, and D ≈ N/6 makes the second ≈ 36√3/π ≈ 20. Stated with D explicit rather than collapsed to a numeral, so no threshold on N is smuggled in.

    Part 11 — ⟨4₁⟩_N against its own largest term, both sides #

    source
    theorem QOU.Knot.FigureEightVolume.kashaev_le_argmax_mul {N w : ℕ} (hN : 6 ≤ N) (hw1 : 6 * w ≤ 5 * N) (hw2 : 2 * N + 3 ≤ 3 * w) (hwk : w ≤ 5 * N / 6) (hD : 2 ≤ 5 * N / 6 - w) :
    kashaev N ≤ kashaevProd N (5 * N / 6) * (↑w / ↑N ^ 2 + ↑w * (√3 * ↑N) / (Real.pi * ↑(5 * N / 6 - w) * (↑(5 * N / 6 - w) - 1)) + (2 + √(√3 * ↑N) / 2) + (2 + √(↑N / √3) / 2))

    ⟨4₁⟩_N ≤ g_{k*}·C(N,w), with C an explicit expression and no threshold on N.

    Every summand of C is O(√N) or better: w/N² ≤ 1/N; the D-term is ≈ 36√3/π ≈ 20 at D ≈ N/6; the two window terms are the √N. Collapsing C to a single numeral needs √3 ≤ 1.8, π ≥ 3.14 and a threshold — which is exactly what this statement avoids, at the cost of being longer to read.
