    §1 — a flat tetrahedron has zero volume, for every real shape #

    QOU/Archimedean/BlochWignerLobachevsky.lean has BlochWigner_lob_real_eq_zero, but only for 0 < x < 1. The trefoil's shapes are −1 and 2, both outside that range, so the restricted form cannot see them. The vanishing in fact needs no hypothesis at all.

    source
    theorem QOU.Knot.FlatTet.arg_ofReal_zero_or_pi (r : ℝ) :
    (↑r).arg = 0 ∨ (↑r).arg = Real.pi

    The argument of a real number is 0 or π — never anything else. This is the whole reason a flat tetrahedron has zero volume: Λ vanishes at both.

    source
    theorem QOU.Knot.FlatTet.BlochWigner_lob_ofReal (x : ℝ) :
    Archimedean.BlochWigner_lob ↑x = 0

    A real shape parameter gives zero volume — unconditionally.

    Generalises BlochWigner_lob_real_eq_zero, which assumed 0 < x < 1. No hypothesis is needed, and that includes the two junk-value cases: at x = 1 Lean's 1/0 = 0 makes 1/(1−x) = 0, and at x = 0 it makes 1 − 1/x = 1; both give arg = 0, so the formula still returns 0.

    source
    theorem QOU.Knot.FlatTet.BlochWigner_lob_eq_zero_of_im_eq_zero {z : ℂ} (hz : z.im = 0) :
    Archimedean.BlochWigner_lob z = 0

    Flat ⇒ zero volume, in the form the geometry layer wants: a shape with vanishing imaginary part contributes nothing.

                          The headline, stated as one theorem: the edge equations do not detect hyperbolicity.

                          The trefoil complement is Seifert fibred, not hyperbolic, yet its shapes satisfy the edge equations and have volume 0. So satisfying the gluing equations is not sufficient for a geometric solution — positivity of the imaginary parts is the missing condition, and it is exactly what IdealTetrahedron.im_pos supplies.
