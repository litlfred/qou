          VOL_5_2, exactly — three ideal tetrahedra of shape y₁, in the Lobachevsky (angle) form.

            The 5₂ triangulation, as a defined object #

            QOU/MathlibExt/IdealTriangulation.lean supplies the layer that was missing: an IdealTetrahedron (a shape in the upper half plane) and an IdealTriangulation (finitely many of them) with a volume. Against that, the statements below are theorems about a defined object, not sentences with no subject.

            ⚠ Still nothing about S³ ∖ 5₂. Connecting an IdealTriangulation to a knot complement is Thurston hyperbolisation plus Mostow rigidity, and needs hyperbolic 3-manifolds, which neither Mathlib nor QOU has. See that file's header.

              The 5₂ ideal triangulation, with SnapPy's actual shapes.

              ⚠ CORRECTION (2026-08-09). An earlier version of this file defined the triangulation as const 3 fiveTwoTet — three tetrahedra all of shape y₁. That is wrong, and SnapPy says so: Manifold('5_2').tetrahedra_shapes gives

              tet 0 : 0.78492014550 + 1.30714127868i   = y₁
tet 1 : 0.12256116688 + 0.74486176662i   = 1/(1 − y₁)   ← NOT y₁
tet 2 : 0.78492014550 + 1.30714127868i   = y₁

              The middle tetrahedron carries the second edge parameter of y₁, not y₁.

              The volume claim survives — but as a theorem now, not an assumption: the relabelling z ↦ 1/(1−z) cyclically permutes the three dihedral angles (IdealTetrahedron.rotate_angles), so Λ(θ₁)+Λ(θ₂)+Λ(θ₃) is unchanged (volume_rotate). That is why Vol = 3·D(y₁) despite the shapes differing.

              Recorded because the earlier version was a guess that happened to give the right number for a reason it did not state.

                The edge gluing equations ARE the saddle cubic #

                SnapPy's three 5₂ edge equations (Manifold('5_2').gluing_equations(), the first N = 3 rows; the remaining two are cusp equations and carry negative exponents, so they need ℤ-valued data this API does not model):

                [1,0,1, 1,2,0, 1,0,1]
[0,1,1, 0,0,2, 0,1,1]
[1,1,0, 1,0,0, 1,1,0]

                Reducing each ∏ z^a (z′)^b (z″)^c − 1 over ℚ(y):

                • edges 0 and 2 have numerator −(y³ − 2y² + 3y − 1) — exactly the saddle cubic;
                • edge 1 is (z·z′·z″)² = (−1)² = 1, identically, needing no cubic at all.

                So the geometric gluing condition and the algebraic branch equation y² = (1−y)³ that this entire lane is built on are the same equation. That is not a coincidence noticed numerically — it is what the reduction below proves.
