    theorem QOU.Knot.FigureEightVolume.log_kashaevProd_asymptotic {N k : ℕ} (hk : 1 ≤ k) (hkN : k < N) (hN : 4 ≤ N) :
    |Real.log (kashaevProd N k) - (-(2 * ↑N / Real.pi) * Archimedean.Lob (↑k * Real.pi / ↑N) + Real.log (2 * ↑N * Real.sin (↑k * Real.pi / ↑N)) + Real.pi / (6 * ↑N) * (Real.cos (↑k * Real.pi / ↑N) / Real.sin (↑k * Real.pi / ↑N)))| ≤ 2 * (1 / (144 * ↑k ^ 2) + 7 / 12 * (Real.pi / ↑N) ^ 2 + (Real.pi / ↑N) ^ 2 / (12 * Real.sin (↑k * Real.pi / ↑N) ^ 2))

    The join. log(kashaevProd N k) is twice the log-sine sum, so the Euler–Maclaurin expansion of the latter doubles into an expansion of the former — with the same O(1/N²) error, doubled.

    This is the first statement in the development that expands the Kashaev term itself rather than a ratio of Kashaev terms.

    |Real.log (kashaevProd N k) - (-(2 * ↑N / Real.pi) * Archimedean.Lob (5 * Real.pi / 6) + Real.log (2 * ↑N * Real.sin (↑k * Real.pi / ↑N)) + Real.pi / (6 * ↑N) * (Real.cos (↑k * Real.pi / ↑N) / Real.sin (↑k * Real.pi / ↑N)))| ≤ 2 * (1 / (144 * ↑k ^ 2) + 7 / 12 * (Real.pi / ↑N) ^ 2 + (Real.pi / ↑N) ^ 2 / (12 * Real.sin (↑k * Real.pi / ↑N) ^ 2)) + 2 * ↑N / Real.pi * (√3 * (Real.pi / ↑N) ^ 2 / 2 + M * (Real.pi / ↑N) ^ 3 / 6)

    At the saddle. For k within one step of 5N/6 — which ⌊5N/6⌋ is — the expansion above can be re-centred on the exact saddle angle 5π/6, paying O(1/N) for the offset.

    The hypothesis is stated as a bound on |θ_k − 5π/6| rather than as k = ⌊5N/6⌋, because that is what the proof uses and because both ⌊5N/6⌋ and ⌈5N/6⌉ satisfy it.
