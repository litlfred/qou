    theorem QOU.Knot.FigureEightVolume.abs_Lob_taylor_saddle {θ M : ℝ} (hmem : ∀ x ∈ Set.uIcc (5 * Real.pi / 6) θ, 0 < x ∧ x < Real.pi) (hM : ∀ x ∈ Set.uIcc (5 * Real.pi / 6) θ, 1 / Real.sin x ^ 2 ≤ M) :
    |Archimedean.Lob θ - (Archimedean.Lob (5 * Real.pi / 6) + √3 * ((θ - 5 * Real.pi / 6) ^ 2 / 2))| ≤ M * |θ - 5 * Real.pi / 6| ^ 3 / 6

    Λ at the saddle. The linear term is absent because Λ′(θ*) = 0; the quadratic coefficient is √3/2 = |cot θ*|/2.
