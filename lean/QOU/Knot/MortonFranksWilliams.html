    QOU.Knot.MortonFranksWilliams — the MFW pair, and what it bounds #

    Bean qou-dr8m. The Morton–Franks–Williams inequalities bound the braid index of a link below, from the v-degrees of its HOMFLY polynomial. HOMFLY is the Ocneanu/Markov trace on the Iwahori–Hecke tower — the corpus's own object — so this is the natural route to a derived braid index, replacing the literature-recalled value braid index(6₁) = 4 that qou-xpgq flagged as unverified and load-bearing. (qou-xpgq lives on the unmerged branch of PR #5294, so beans show qou-xpgq returns nothing until that lands — its PR body carries the flag verbatim: "6₁'s braid index is not verified against any in-repo source".)

    The statement being formalised #

    With the HOMFLY skein v⁻¹P(L₊) − vP(L₋) = zP(L₀), P(unknot) = 1, and β ∈ B_n a braid with exponent sum (writhe) e whose closure is L:

    (1)   e − n + 1  ≤  mindeg_v P_L
(2)                 maxdeg_v P_L  ≤  e + n − 1

    These two are the HYPOTHESES here, carried by MFWWitness, and they are NOT proved. Proving them requires HOMFLY's well-definedness, i.e. Markov invariance of the Ocneanu trace on the Hₙ tower, plus a degree argument — research-scale, and tracked separately. Everything below is derived from the pair, sorry-free, and the file asserts nothing about any actual knot.

    This is the §3b-cond conditional pattern used honestly: the structure carries the inputs, the theorems derive the conclusions. It is deliberately NOT a class carrying braid index ≥ … as a field, which would be the "axiomatisation is not a proof" failure — the bound is computed here, not assumed.

    What is derived #

    • spread_le_two_mul_sub_two — subtracting (1) from (2) cancels the writhe e, which is the crux: e is not a link invariant, the degrees are.
    • braid_bound — hence spread + 2 ≤ 2n, the MFW lower bound on the braid index, in a division-free form.
    • no_representative_of_spread_gt — the contrapositive, which is the form that actually rules a strand number out.
    • selfLinking_le — reading (1) ALONE bounds the self-linking number sl = e − n above: sl ≤ mindeg_v P − 1. The HOMFLY sharpening of Bennequin. So one trace bounds a minimum below and a maximum above.
    • writhe_bounds — adding (1) and (2) instead constrains the writhe at fixed n (stated as two inequalities to avoid an abs import).

    And why the braid index is a MINIMUM and never a maximum #

    Markov.stab (stabilisation β ↦ βσₙ^{±1}, closure unchanged) makes the set of representable strand numbers upward closed, hence unbounded above: rep_unbounded. So max is ∞ for every link and carries no information — the minimum is the only invariant of the two. That asymmetry is structural, and it is proved here rather than asserted.

    References #

    • [morton1988] H. R. Morton, Seifert circles and knot polynomials. https://doi.org/10.1017/S0305004100064057
    • [franks-williams1987] J. Franks, R. F. Williams, Braids and the Jones polynomial. https://doi.org/10.1090/S0002-9947-1987-0896009-2
    • [manuscript] QOU/KnotTheory/JonesPolynomial.lean (the Markov-trace idiom this follows).

    structure QOU.Knot.MortonFranksWilliams.MFWWitness :
    Type

    The MFW input for one braid representative: n strands, writhe e, and the v-degree window [dmin, dmax] of the link's HOMFLY polynomial, together with the two MFW inequalities as hypotheses. Nothing here is proved; see the module docstring.

    • n : ℤ

      number of strands of the braid representative

    • e : ℤ

      exponent sum (writhe) of the braid word

    • dmin : ℤ

      mindeg_v of the HOMFLY polynomial of the closure

    • dmax : ℤ

      maxdeg_v of the HOMFLY polynomial of the closure

    • one_le_n : 1 ≤ self.n

      a braid has at least one strand

    • mfw_lower : self.e - self.n + 1 ≤ self.dmin

      MFW (1)

    • mfw_upper : self.dmax ≤ self.e + self.n - 1

      MFW (2)

    • dmin_le_dmax : self.dmin ≤ self.dmax

      the degree window is non-empty (mindeg ≤ maxdeg for a nonzero HOMFLY). Needed for writhe_bounds; NOT derivable from the MFW pair alone, so it is carried explicitly rather than quietly assumed.

      theorem QOU.Knot.MortonFranksWilliams.no_representative_of_spread_gt (n dmin dmax : ℤ) (h : 2 * n < dmax - dmin + 2) :
      ¬∃ (w : MFWWitness), w.n = n ∧ w.dmin = dmin ∧ w.dmax = dmax

      The contrapositive — the form that actually rules a strand number out. If the HOMFLY degree spread is too wide for n strands, then no braid on n strands closes to that link. This is how MFW is used in practice.

      class QOU.Knot.MortonFranksWilliams.Markov (Rep : ℕ → Prop) :
      Prop

      Markov stabilisation β ↦ β·σₙ^{±1} leaves the closure unchanged while adding a strand. Carried as a hypothesis on an abstract representability predicate: Rep n reads "some braid on n strands closes to this link".

      • stab (n : ℕ) : Rep n → Rep (n + 1)

        stabilisation adds a strand without changing the closure

        theorem QOU.Knot.MortonFranksWilliams.rep_unbounded {Rep : ℕ → Prop} [Markov Rep] {n : ℕ} (hn : Rep n) :
        ¬∃ (M : ℕ), ∀ (m : ℕ), Rep m → m ≤ M

        Hence there is no maximal braid index: the representable strand numbers are unbounded above, so max is ∞ for every link and carries no information. The braid index is a MINIMUM precisely because this maximum is degenerate.

        Worked instance: the knot 6₁ #

        The four numbers below are measured, not recalled: computations/homfly_braid_index_mfw.py computes the exact two-variable HOMFLY of a braid closure by descending-diagram skein recursion in integer Laurent arithmetic, and reads dmin/dmax off it. The producer is gated on textbook HOMFLY for five links, on the Conway specialisation P(v=1, z) = ∇(z) for seven knots, and on agreement with the tabulated braid index for the six knots other than 6₁.

        e = 1 is the writhe of the 4-strand word [1,1,2,-1,-3,2,-3], whose closure SnapPy identifies as 6₁/m032. That word is what supplies the upper bound; it is a computed fact about a diagram, so it is cited here rather than proved. What Lean adds is the lower bound and its consequence — and note that with spread = 6 and n = 4 both MFW inequalities are equalities, so the witness is tight on both sides. This replaces the literature-recalled braid index(6₁) = 4 that qou-xpgq flagged as unverified and load-bearing.

          An independent knot at braid index 4 #

          6₁ is the knot under test, so a separation theorem stated only about it cannot show that the machinery can separate 4 from 3 — it could be reading its own input back. T(4,5), the closure of (σ₁σ₂σ₃)⁵, supplies that independently: its braid index is min(p, q) = 4 by a theorem (MFW is sharp on torus knots), not by a knot table, and the measured HOMFLY window is [12, 18], again spread 6.
