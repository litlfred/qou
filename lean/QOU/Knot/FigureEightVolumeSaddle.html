    theorem QOU.Knot.FigureEightVolume.kashaevProd_eq_sin (N k : ℕ) :
    kashaevProd N k = 4 ^ k * (∏ j ∈ Finset.Icc 1 k, Real.sin (Real.pi * ↑j / ↑N)) ^ 2

    theorem QOU.Knot.FigureEightVolume.saddle_critical_point {θ : ℝ} (h0 : 0 < θ) (hπ : θ < Real.pi) :
    2 * Real.sin (θ / 2) = 1 ↔ θ = Real.pi / 3

    The saddle critical point (dual-purpose). On (0, π), 2 sin(θ/2) = 1 ↔ θ = π/3. This is the location of the Kashaev saddle — the factors 4 sin²(πj/N) of kashaevProd_eq_sin cross 1 here — and it is simultaneously the critical point of the QOU dilog-saddle potential V(θ) = Im Li₂(e^{iθ}), whose derivative is −log(2 sin(θ/2)) (content block rem:dilog-saddle-regime): V'(θ) = 0 ⟺ 2 sin(θ/2) = 1 ⟺ θ = π/3, giving Vol(4₁) = 2 Cl₂(π/3). The block states this narratively; this is its Lean proof, needing no Clausen function — only sin(π/6) = 1/2 and injectivity of sin on [−π/2, π/2].

    theorem QOU.Knot.FigureEightVolume.log_kashaev_le_log_add (N : ℕ) (hN : 1 ≤ N) :
    Real.log (kashaev N) ≤ Real.log ↑N + Real.log ((Finset.range N).sup' ⋯ (kashaevProd N))

    Saddle brick E1, upper half (sorry-free). log kashaev exceeds the max log-term by at most log N: the sum of N terms is at most N · max.     theorem QOU.Knot.FigureEightVolume.neg_Cl_2_pi_div_three_le {θ : ℝ} (hθ : θ ∈ Set.Icc 0 (2 * Real.pi)) :
    -Archimedean.Cl_2 (Real.pi / 3) ≤ Archimedean.Cl_2 θ

    Saddle brick E3c — the global minimum of Cl₂ (sorry-free). On [0, 2π], Cl₂(θ) ≥ −Cl₂(π/3). Compactness gives a minimiser; it is interior (the endpoints give 0, but Cl₂(5π/3) = −Cl₂(π/3) < 0 by E2+E3b); interior minimisers are critical (IsLocalMin.deriv_eq_zero + hasDerivAt_cl_2), so by E3a the minimiser is π/3 or 5π/3; positivity (E3b) rules out π/3. Hence the minimum is Cl₂(5π/3) = −Cl₂(π/3). (bean qou-yzs2)
