    Part 1 — Cl₂ and Λ are continuous #

    The corpus defines Cl_2 as a tsum and proves summability, but never continuity, which the ε → 0 limit below needs. The Weierstrass M-test applies verbatim: |sin(nθ)/n²| ≤ 1/n² uniformly in θ.

    Part 2 — splitting the integrand at its own singularity #

    theorem QOU.Knot.FigureEightVolume.log_two_sin_eq_logSinc_add {t : ℝ} (ht : 0 < t) (htpi : t < Real.pi) :
    Real.log (2 * Real.sin t) = logSinc t + Real.log (2 * t)

    log(2 sin t) = logSinc t + log(2t) on (0, π). Both logs split because sin t > 0 and t > 0 there.

    theorem QOU.Knot.FigureEightVolume.integral_logSinc_eq {a b : ℝ} (ha : 0 < a) (hb : b < Real.pi) (hab : a ≤ b) :
    ∫ (t : ℝ) in a..b, logSinc t = Archimedean.Lob a - Archimedean.Lob b - (b * Real.log (2 * b) - b - (a * Real.log (2 * a) - a))

    ∫_a^b logSinc = (Λ(a) − Λ(b)) − (b log 2b − b − (a log 2a − a)) for 0 < a ≤ b < π. This is the FTC step with the singular part removed.

    Part 3 — the constant #

    source
    theorem QOU.Knot.FigureEightVolume.abs_Lob_sub_near_zero {b : ℝ} (hb0 : 0 < b) (hb1 : b ≤ 1) :
    |Archimedean.Lob b - (b - b * Real.log (2 * b))| ≤ b ^ 3 / 3

    Λ near zero, with its constant: |Λ(b) − (b − b·log(2b))| ≤ b³/3 for 0 < b ≤ 1.

    This is the ingredient gap (A) was missing. Everything else in the Kashaev expansion is bookkeeping over Euler–Maclaurin and Stirling; this is where the −½log(2N sin θ) constant comes from.
