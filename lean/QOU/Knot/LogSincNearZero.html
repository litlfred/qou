    The second derivative, and an honest note on the higher ones #

    The composite Euler–Maclaurin rule's error over k cells is k·h⁵·sup|g⁗|/720, which on the SUM is k·h⁴·sup|g⁗|/720 ≈ sup|g⁗|/N³. So the assembly needs sup|logSinc⁗| on [h, θ] to be o(N²). It is in fact O(1):

    logSinc″   = 1/x² − 1/sin²x                    →  −1/3   as x → 0
logSinc‴   = 2cos x/sin³x − 2/x³               →   0
logSinc⁗   = 6/x⁴ − (4cos²x + 2)/sin⁴x         →  −2/15

    (all three verified against numerical differentiation). But each is a DIFFERENCE OF TWO TERMS THAT INDIVIDUALLY BLOW UP, and the bound depends on the cancellation: at N = 100 the crude 6/h⁴ is 6.2·10⁶ while the true value is 0.1335 — a factor of 5·10⁷. Feeding the crude bound into the composite rule gives an error of O(N), i.e. no theorem at all.

    So proving sup|logSinc⁗| = O(1) is NOT bookkeeping; it needs sin and cos expansions carried to eighth order with explicit remainders, and an earlier note in this corpus that called the interior bound "unglamorous work" understated it. What IS elementary is the second derivative, which is what the trapezoid-remainder form of the argument needs, and it is proved below from the same two sin bounds used above.

    The composite rule, instantiated at logSinc #

    Every hypothesis is now in hand, so this is a direct application. The grid is h, 2h, …, (m+1)h — it starts at h, never touching 0, which is the whole reason no regularity at 0 is needed.

    theorem QOU.Knot.FigureEightVolume.abs_sum_logSinc_sub_euler_maclaurin {h : ℝ} (hh : 0 < h) (m : ℕ) (hlt : h + ↑m * h < Real.pi) :
    |∑ j ∈ Finset.range (m + 1), logSinc (h + ↑j * h) - ((1 / h * ∫ (x : ℝ) in h..h + ↑m * h, logSinc x) + (logSinc h + logSinc (h + ↑m * h)) / 2 + h / 12 * (Real.cos (h + ↑m * h) / Real.sin (h + ↑m * h) - 1 / (h + ↑m * h) - (Real.cos h / Real.sin h - 1 / h)))| ≤ h ^ 2 / 12 * (1 / h ^ 2 - 1 / Real.sin h ^ 2 - (1 / (h + ↑m * h) ^ 2 - 1 / Real.sin (h + ↑m * h) ^ 2))

    The Euler–Maclaurin expansion of ∑_{j=1}^{m+1} logSinc(jh).

    | ∑_{j=0}^{m} logSinc(h+jh)
    − [ (1/h)∫_h^{h+mh} logSinc + ½(logSinc h + logSinc(h+mh))
        + (h/12)(logSinc′(h+mh) − logSinc′(h)) ] |
  ≤ (h²/12)·(logSinc″(h) − logSinc″(h+mh))

    i.e. the B₂ term appears once and the error is O(h²) — an order below the O(1/N) term qou-mlgp (A) extracts.

    This is QOU.MathlibExt.abs_integral_sub_composite_le_osc at g = logSinc, a = h, divided through by h. The four hypotheses it needs are hasDerivAt_logSinc, hasDerivAt_logSinc_deriv, continuity of logSinc″ (from hasDerivAt_logSinc_deriv2), and antitoneOn_logSinc_deriv.
