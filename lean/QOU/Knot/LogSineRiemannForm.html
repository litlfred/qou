    theorem QOU.Knot.FigureEightVolume.smooth_defect_eq_riemann_defect {h : ℝ} (hh : 0 < h) (n : ℕ) :
    ∑ i ∈ Finset.range n, ∫ (u : ℝ) in ↑i * h..(↑i + 1) * h, phi ((↑i + 1) * h) - phi u = h * ∑ i ∈ Finset.range n, phi ((↑i + 1) * h) - ∫ (u : ℝ) in 0..↑n * h, phi u

    The smooth half is a right-endpoint Riemann defect (sorry-free, exact). Each cell contributes h·φ(x_{i+1}) − ∫_{cell} φ, so the sum is the Riemann sum minus the integral over [0, nh]. No hypotheses beyond integrability, which φ has everywhere.
