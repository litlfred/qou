    QOU.Knot.FigureEightQuarticCoefficient — a₄ = i·√3/24 from the NZ longitude #

    The order-u⁴ extension of FigureEightComplexVolume (bean qou-x88s): the E1/E1b probes measured the quartic coefficient of the deformed 4₁ complex volume as a₄ = i·0.0721687836487… = i·√3/24 (4-point Richardson on the NZ longitude integral; a₂ cross-validated to 3×10⁻²⁰, a₄ stable to 4×10⁻¹⁵). This file DERIVES that value from the Neumann–Zagier integration

    𝔙(u) = 𝔙₀ − ½ ∫₀ᵘ v(t) dt,     v(u) = τ·u + v₃·u³ + O(u⁵),

    whose term-wise integration gives a₂ = −τ/4 and a₄ = −v₃/8 (a_{2k} = −v_{2k−1}/(4k)). With the CCGLS-recognized coefficients τ = −i√3 and v₃ = −i√3/3 the exact values follow by algebra.

    Provenance tiers (machinery-proved ≠ values-derived) #

    • The integration algebra (a₂_eq_neg_tau_div_four, a₄_eq_neg_v₃_div_eight) is proved here, sorry-free.
    • The coefficient inputs τ = −i√3, v₃ = −i√3/3 are the CCGLS A-polynomial recognition — probe-certified (computations/probes/qbeta_nz_even_series_fourone_probe.py, the τ = (0,∓1,1), v₃ = (0,∓1,3) ℚ(√−3) recognition), NOT Lean-derived. They enter as definitions whose provenance is this docstring.
    • The log-cos closed form −(√3/2)i·log cos u (which would predict a₆ = i√3/90) is REFUTED by the E1b measurement (a₆ = i·0.0184431195 ≠ i·0.0192450, witness qbeta-ohtsuki-nz-bridge-b6.witness.json) — this file deliberately stops at u⁴ and claims no closed form for the series.
