    §2 — The shape's real and imaginary parts #

    Both are projections of the explicit ofRealRoot witness, so they are definitional.

    §3 — Numeric brackets #

    Everything below follows from §1 and §2 by monotonicity. The margins are deliberately loose: the consumer (VOL_4_1 < VOL_5_2) has 34 % headroom, so there is no reason to chase digits — and chasing them is what made item 2 of qou-f8lit infeasible.

    source
    theorem QOU.Knot.FiveTwoShapeBounds.fiveTwoShape_re_bounds :
    31 / 40 < FiveTwoVolume.fiveTwoShape.re ∧ FiveTwoVolume.fiveTwoShape.re < 4 / 5

    31/40 < Re(y₁) < 4/5.

    source
    theorem QOU.Knot.FiveTwoShapeBounds.radicand_bounds :

    The radicand is bracketed, which is what the Im bound needs.

    theorem QOU.Knot.FiveTwoShapeBounds.fiveTwoShape_im_bounds :
    13 / 10 < FiveTwoVolume.fiveTwoShape.im ∧ FiveTwoVolume.fiveTwoShape.im < 33 / 25

    13/10 < Im(y₁) < 132/100. Strictly positive, and bounded away from 0 by an explicit rational — which fiveTwoShape_im_pos alone does not give.

    source
    theorem QOU.Knot.FiveTwoShapeBounds.fiveTwoShape_normSq_gt_one :
    1 < Complex.normSq FiveTwoVolume.fiveTwoShape

    normSq y₁ > 1, i.e. |y₁| > 1 — recorded because it closes the obvious shortcut: the Li₂ power series does not converge at y₁, which is why the corpus uses the extended cLiTwoExt, and why a naive dilogarithm partial sum cannot be used to bound VOL_5_2. Anyone reaching for one will find it diverges.
