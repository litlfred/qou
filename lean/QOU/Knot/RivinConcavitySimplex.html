    QOU.Knot.RivinConcavitySimplex — Rivin concavity on the angle simplex, not just on a line #

    Bean qou-mlgp Gap 3, completed.

    QOU.Knot.RivinConcavity.strictConcaveOn_tetVolLine proves that Λ(α) + Λ(β) + Λ(γ) is strictly concave along a line in the angle simplex, and its docstring then says

    Since strict concavity on a convex set is exactly strict concavity along every segment, this is Rivin's theorem for a single tetrahedron.

    That sentence is true and was not proved. It is the difference between a one-variable statement and Rivin's theorem, and the corpus had no way to cross it: Mathlib's concavity-from-second-derivative results are all one-dimensional (see QOU.MathlibExt.StrictConcaveOnSegments for the measured gap).

    With strictConcaveOn_of_segments in hand the crossing is direct, and this file makes it. strictConcaveOn_tetVol below is Rivin's theorem for one ideal tetrahedron, as a statement about a set in ℝ³ rather than about a parametrised line.

    What makes the promotion work #

    The tangency condition is free. RivinConcavity needs u + v + w = 0 — otherwise cot_quadratic_pos does not apply and the angles do not stay summing to π along the line. Here (u, v, w) is not chosen: it is y − x for two points of the simplex, and both sum to π, so it sums to 0 automatically.

    The non-degeneracy is nearly free too: ¬(u = 0 ∧ v = 0) would fail only if the first two coordinates agreed, and then w = −u − v = 0 forces y = x, which the strict hypothesis already excludes.

    So the geometry that the line version had to be given is exactly what "two distinct points of the simplex" already supplies.

          theorem QOU.Knot.Rivin.strictConcaveOn_totalVol {n : ℕ} {P : Set (Fin n → ℝ × ℝ × ℝ)} (hP : Convex ℝ P) (hsub : ∀ θ ∈ P, ∀ (i : Fin n), θ i ∈ tetAngleSimplex) :
          StrictConcaveOn ℝ P totalVol

          RIVIN CONCAVITY FOR AN IDEAL TRIANGULATION.

          The total volume is strictly concave on any convex set of angle assignments whose points are tetrahedron-wise admissible.

          The gluing equations never appear. That is the point: they are linear, so whatever polytope they cut out is convex, and P may be taken to be it. Concavity does not care which convex set — only that it is one, and that each of its points gives every tetrahedron a genuine angle triple. So this covers Rivin's angle-structure polytope, any face of it, and any further linear restriction, without proving anything about the gluing equations themselves.

          Where strictness comes from. Each summand tetVol ∘ (eval i) is constant in every other tetrahedron's angles, so as a function on P it is concave and not strictly so. But two distinct angle assignments must differ at some tetrahedron j, and there the summand is strictly concave by strictConcaveOn_tetVol. StrictConcaveOn.sum_of_mem is shaped for exactly this: one strict summand carries the sum.

          This is the variational statement the hyperbolic structure is characterised by — the complete structure is the unique critical point — and hence what the volume-conjecture work rests on downstream.
