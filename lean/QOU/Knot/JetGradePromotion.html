            theorem QOU.Knot.JetGradePromotion.lt_top_of_fixes_top {n : ℕ} {w : Equiv.Perm (Fin (n + 2))} (hw : w top = top) {x : Fin (n + 2)} (hx : x ≠ top) :
            w x < top

            The key step. A permutation fixing the top point must send every other point strictly below the top -- by injectivity, since the top is already taken, and it is the maximum. This is what makes the fresh generator length-increasing rather than length-decreasing.

            In particular the second-from-top point lands strictly below the top, so the pair (sub, top) is not an inversion of w.
