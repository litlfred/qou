      theorem QOU.Knot.MFWSkeinInduction.shifts_preserve_width {n e : ℤ} :
      e + n - 1 - (e - n + 1) = 2 * n - 2

      Consequence of the two above, and the reason MFW is sharp: neither skein branch loses any room at either edge, so the window the recursion delivers is the window the base case starts with, shifted — never wider, never narrower. Any slack in a computed spread therefore comes from the base case, not from the recursion.

      The base case, stated precisely #

      The recursion bottoms out at a totally descending word — every crossing first met from above (first_bad returns none in the engine). Its closure is the c-component unlink, so P = δ^{c-1} with δ = (v⁻¹ − v)/z, whose v-degrees are exactly {-(c-1), -(c-3), …, c-1}, i.e. spanned by [-(c-1), c-1].

      For that to sit inside window n e one needs precisely

      |e| ≤ n − c

      Measured, not assumed (2026-08-22): over every braid word of length ≤ 6 on 2–4 strands, 1227 are totally descending and all 1227 satisfy it — and it is tight, max |e| = n − c exactly for all nine (n, c) pairs reached. n − c is the reflection length of the word's permutation, which is where a proof should come from.

      It is not proved here, and it is not free: for arbitrary (non-descending) words the analogous bound fails — the longest element of S₃ has Coxeter length 3 against n − c = 1 — so the content lies in what "descending" supplies.

      What it supplies, measured: in a descending word no two strands cross more than once net — the maximum |net signed crossings| over any strand pair is exactly 1, across all 1227 words. That is the cancellation which keeps |e| small while the letter count stays large, and it is the natural next lemma.

      The bound decomposes over closure components. Two facts, each measured clean over 2592 descending words:

      • (A) any two closure components have linking number zero, so their signed crossings cancel exactly. This is provable, not a coincidence: a descending traversal totally orders the components, and every crossing between two of them is first met while traversing the earlier one — so the earlier component passes entirely over the later, lifts off it, and the crossing signs between them sum to 0.
      • (C) consequently each component satisfies |Σ inner nets| ≤ L - 1 separately (0 violations, tight in 1220 components).

      Since Σ (Lᵢ - 1) = n - c, the bound reduces to the single-component (c = 1) case.

      That reduction is not needed, because the hypothesis is a corollary of a classical theorem. Two standard facts close it outright:

      1. A descending diagram is an unlink (lickorish1997) — here the closure is the c-component unlink. Verified in this codebase's own conventions: over every descending word tested the HOMFLY depends only on c, taking the value ((v⁻¹ - v)/z)^{c-1} — the unlink polynomial — with zero disagreements.
      2. Bennequin's inequality (bennequin1983): sl(L) ≤ -χ(L). For a closed braid on n strands with exponent sum e the self-linking number is sl = e - n, and the c-component unlink has maximal Euler characteristic χ = c (c disjoint disks). Hence e - n ≤ -c, i.e. e ≤ n - c.

      Mirroring the diagram sends e ↦ -e and fixes the unlink, giving -e ≤ n - c; together |e| ≤ n - c, which is exactly DescendingWrithe. Tightness observed in the measurement is the standard closed braid realising sl = -c.

      Not circular: Bennequin (1983) predates HOMFLY (1985) and MFW (1987), and its proof is contact-geometric — it does not use the skein induction it is invoked in here.

      The hypothesis therefore remains a sorry-free threaded assumption in Lean only because Mathlib has neither HOMFLY nor the Bennequin inequality; its status is classical-and-cited, not open.

      Two self-contained decompositions were refuted before the classical route was found (scope-(a), recorded so they are not re-walked): the per-pair bound is necessary but not sufficient. In 298 of the 1227 words the number of pairs with nonzero net exceeds n − c — e.g. n = 3, w = σ₁σ₂σ₁⁻¹ has all three pairs nonzero against n − c = 1 — so |e| ≤ #nonzero pairs does not yield the bound. Second, "both the positive- and negative-net graphs are forests" is false: G⁻ always is, but G⁺ carries a cycle in 30 words — n = 4, w = σ₁σ₂σ₁σ₃σ₂⁻¹ has the positive triangle {1,2}, {1,3}, {2,3}. Both were attempts to prove from scratch what bennequin1983 already gives.

      qou-9ttb is closed: the mathematics of MFW is settled (propagation proved here, base case classical). What remains is that no Lean file in this repo touches an actual knot — there is no HOMFLY in Lean, so nothing can produce an MFWWitness from a real link. That is infrastructure on the scale of a Mathlib contribution and is tracked separately as qou-e6db.

      def QOU.Knot.MFWSkeinInduction.DescendingWrithe (n c e : ℤ) :
      Prop

      The base-case hypothesis, named so it can be discharged later rather than re-invented: a totally descending n-strand word with c closure components has |e| ≤ n − c. Classical — see the module docstring: descending ⇒ unlink (lickorish1997) plus Bennequin's inequality (bennequin1983).

        Wiring to MortonFranksWilliams #

        Until now this module was orphaned: nothing imported it, so its window arithmetic fed nothing. MortonFranksWilliams.MFWWitness carries the two MFW inequalities as the fields mfw_lower / mfw_upper, and those are exactly window membership for dmin and dmax. So the induction's output type and that file's input type are the same object, and the bridge below is definitional rather than a re-proof.
