        Reversibility passes to powers. Conjugation by a fixed x is a group homomorphism, so a single witness x reverses every power of g at once. This is what makes the result uniform in n, where the compute could only check finitely many.

        The vanishing lemma. Any conjugation-invariant, inversion-antisymmetric real-valued function vanishes on a reversible element. Two lines: invariance moves Φ g to Φ g⁻¹, antisymmetry turns that into -Φ g.

                      theorem QOU.Knot.RademacherReversible.Sm_not_conj_Rm :
                      Sm * Rm * Sm⁻¹ ≠ Rm⁻¹

                      Control: the same conjugation FAILS for the parabolic R. S · R · S⁻¹ ≠ R⁻¹, decided.

                      This is what makes Sm_conj_RL a fact about RL rather than a formality that any matrix would satisfy — the identity is special to the hyperbolic RL, and the vanishing it forces is correspondingly special.

                      Note the honest limit of this statement: it says THIS conjugator fails for R, not that R is non-reversible. The latter is true in SL(2, ℤ) (the parabolic classes !![1,n;0,1] for n > 0 and n < 0 are distinct, though they fuse in GL(2, ℤ)), but proving it needs an argument over ALL conjugators and is not attempted here.

                      3. The conclusion qou-aspz asked for #

                      source
                      theorem QOU.Knot.RademacherReversible.rademacher_eq_zero_of_reversible (Φ : SL2Z → ℝ) (hconj : ∀ (g x : SL2Z), Φ (x * g * x⁻¹) = Φ g) (hinv : ∀ (g : SL2Z), Φ g⁻¹ = -Φ g) (n : ℕ) :
                      Φ (RL ^ n) = 0

                      Φ((RL)ⁿ) = 0, for every n, from structure rather than computation.

                      Φ is any conjugation-invariant, inversion-antisymmetric real function on SL(2,ℤ) — Rademacher's function is one, as is every homogeneous quasimorphism. No Dedekind sum, no word count, no reciprocity law.

                      This is the Lean form of the scope-(a) refutation in qbeta_rdmr_rademacher_winding_probe.py: the Rademacher route cannot supply ϑ_K, because it is pinned to 0 on the canonical closures.
