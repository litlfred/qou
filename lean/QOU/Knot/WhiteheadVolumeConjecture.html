          theorem QOU.Knot.WhiteheadVC.whiteheadInnerSum_saddle {N n : ℕ} (hN : 2 ≤ N) (hn : n < N) :
          ∃ kmax < N - n, whiteheadS N n kmax ≤ whiteheadInnerSum N n ∧ whiteheadInnerSum N n ≤ (N - n) • whiteheadS N n kmax

          Saddle-packaging brick (E1 at the saddle). There is a maximizing index k* in the summation range whose single term brackets the whole inner sum within the term-count factor: S_{n,k*} ≤ Σ_k S_{n,k} ≤ (N−n)·S_{n,k*}. Taking (2π/N)·log, the two sides differ by (2π/N)·log(N−n) → 0, so the volume limit is governed by the single saddle term S_{n,k*} — the exact reduction the Clausen max-value analysis then evaluates.
