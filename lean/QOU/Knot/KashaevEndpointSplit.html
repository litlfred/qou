    noncomputable def QOU.Knot.FigureEightVolume.logSinc (x : ℝ) :
    ℝ

    logSinc x = log(sin x) − log x, i.e. log(sin x / x) where that is defined. The regular part of log(2 sin) after the log(2x) singularity is subtracted.

      @[simp]
      theorem QOU.Knot.FigureEightVolume.logSinc_zero :
      logSinc 0 = 0

      logSinc 0 = 0 — the singularity really is gone (Real.log 0 = 0 in Mathlib's convention, and sin 0 = 0, so both terms vanish). The analytic content is that log(sin x / x) → 0 as x → 0; this is the value the continuous extension takes.

      theorem QOU.Knot.FigureEightVolume.logSinc_neg (x : ℝ) :
      logSinc (-x) = logSinc x

      logSinc is even. Hence every odd derivative vanishes at 0, which is why the Euler–Maclaurin expansion of ∑ logSinc(jh) has no h-order endpoint contribution at the left end — the reason the split works.

      theorem QOU.Knot.FigureEightVolume.sum_log_two_sin_split {N k : ℕ} (hN : N ≠ 0) (hk : k < N) :
      ∑ j ∈ Finset.Ico 1 (k + 1), Real.log (2 * Real.sin (↑j * Real.pi / ↑N)) = ↑k * Real.log (2 * Real.pi / ↑N) + Real.log ↑k.factorial + ∑ j ∈ Finset.Ico 1 (k + 1), logSinc (↑j * Real.pi / ↑N)

      The endpoint split.

      ∑_{j=1}^{k} log(2 sin(jπ/N)) = k·log(2π/N) + log(k!) + ∑_{j=1}^{k} logSinc(jπ/N)

      exact, for every N ≠ 0 and every k < N. Each term is log(2 sin x) = log(2π/N) + log j + logSinc x at x = jπ/N; summing the log j gives log(k!).

      This is the step that removes the j = 0 singularity from (A): the left side is singular termwise as j/N → 0, the right side is a closed form plus a factorial plus a sum of a function continuous at 0.
