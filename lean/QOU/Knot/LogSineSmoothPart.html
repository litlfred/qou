        theorem QOU.Knot.FigureEightVolume.smooth_defect_squeeze {h : ℝ} (hh : 0 < h) {n : ℕ} (hnπ : ↑n * h < Real.pi) :
        h * (phiExt h n - Real.log 2) ≤ ∑ i ∈ Finset.range n, ∫ (u : ℝ) in ↑i * h..(↑i + 1) * h, phi ((↑i + 1) * h) - phi u ∧ ∑ i ∈ Finset.range n, ∫ (u : ℝ) in ↑i * h..(↑i + 1) * h, phi ((↑i + 1) * h) - phi u ≤ 0

        L4-1c(ii) — the smooth half is squeezed (sorry-free). Telescoping the per-cell bounds:

        h·( φ_ext(n) − log 2 )  ≤  Σ_{i<n} ∫_{cell_i} (φ(x_{i+1}) − φ(u)) du  ≤  0,

        an O(h) two-sided bound obtained with no derivative estimate — only antitonicity of φ and the sin u ≤ u ceiling. Together with the exact singular telescope (L4-1c(i)) and Stirling (L4-1b) this closes the ingredient list for the second-order log-sine expansion.
