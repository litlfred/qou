    structure QOU.Knot.M004AngleStructure.GA (α₁ β₁ γ₁ α₂ β₂ γ₂ : ℝ) :
    Prop

    The m004 generalised angle structure, in π-units, on the six tetrahedron angles (α₁, β₁, γ₁, α₂, β₂, γ₂).

    tet₁/tet₂ are the per-tetrahedron sums; edge₁/edge₂ are SnapPy's two edge equations for m004. The four are rank 3 (the edge sum is twice the tet sum), matching the 3-dimensional solution space the LP was solved over.

    • tet₁ : α₁ + β₁ + γ₁ = 1
    • tet₂ : α₂ + β₂ + γ₂ = 1
    • edge₁ : 2 * α₁ + β₁ + α₂ + 2 * γ₂ = 2
    • edge₂ : β₁ + 2 * γ₁ + α₂ + 2 * β₂ = 2

          theorem QOU.Knot.M004AngleStructure.fixed_iff_line {α₁ β₁ γ₁ α₂ β₂ γ₂ : ℝ} (h : GA α₁ β₁ γ₁ α₂ β₂ γ₂) :
          Fixed α₁ β₁ γ₁ α₂ β₂ γ₂ ↔ β₁ = 1 - 2 * α₁ ∧ γ₁ = α₁ ∧ α₂ = 1 - 2 * α₁ ∧ β₂ = α₁ ∧ γ₂ = α₁

          The exact fixed locus of the symmetry group, as an iff.

          A feasible point is fixed by both generators iff it lies on the line (t, 1 − 2t, t, 1 − 2t, t, t). Because this is an iff, it settles the bean's hypothesis (ii) NEGATIVELY: the fixed set is one-dimensional, so the symmetric point is not unique and symmetry alone cannot pin the optimum.

            theorem QOU.Knot.M004AngleStructure.minAngleOnLine_lt_of_ne {t : ℝ} (ht : t ≠ 1 / 3) :
            minAngleOnLine t < 1 / 3

            The Casson–Rivin objective is uniquely maximised at the regular point. Off t = 1/3 the minimum angle is strictly smaller — below it because t itself is, above it because 1 - 2t is.

            This is what replaces the bean's false hypothesis (ii): the symmetry cuts the feasible set to a line, and the objective — not the symmetry — picks the point on it.
