    Body order = filtration grade. Regrouping the expansion by how many bonds contribute an X, the coefficient of X ^ k is the sum over all (|s| - k)-subsets of bonds of the product of their scalars -- i.e. the (|s| - k)-body term.

    Discharging the assumed field of QOU.Mass.BodyOrderJetGrading #

    The content block lem:bond-order-eq-jet-degree carries a structure QOU.Mass.BodyOrderJetGrading whose theorem bodyorder_eq_jet_total sums a hypothesis field, body_eq_graded : ∀ n, bodyTerm n = gradedTerm n. The interesting claim -- that the n-body term IS the degree-n graded component -- is assumed there, not derived. What follows derives it, in the bond-product model.

    The structure lives in a content-block sibling under mass-theory/, not in the Lake library, so it cannot be imported here; BondGrading below mirrors its fields verbatim and is checked against them by hand. That is a limitation of the content-sibling layout, not a modelling choice.

    The index runs backwards, and saying so is the whole point. An m-body term sits at grade |s| - m, so a witness must re-index; matching bodyTerm n to gradedTerm n by defining them the same way would be the vacuous instance §3b-tax warns about. Here body_eq_graded is discharged by esymm_eq_compl_sum, a genuine complement bijection.

    theorem QOU.Knot.BodyOrderExpansion.esymm_eq_compl_sum {ι : Type u_1} {R : Type u_2} [CommRing R] [DecidableEq ι] (s : Finset ι) (d : ι → R) {n : ℕ} (hn : n ≤ s.card) :
    ∑ t ∈ Finset.powersetCard n s, ∏ e ∈ t, d e = ∑ u ∈ Finset.powersetCard (s.card - n) s, ∏ e ∈ s \ u, d e

    The complement bijection. Summing each n-subset's product equals summing, over (|s| - n)-subsets, the product over the complement. This is what makes the body index and the grade index two readings of one grading.

    theorem QOU.Knot.BodyOrderExpansion.body_eq_graded_of_bond_product {ι : Type u_1} {R : Type u_2} [CommRing R] [DecidableEq ι] (s : Finset ι) (d : ι → R) {n : ℕ} (hn : n ≤ s.card) :
    ∑ t ∈ Finset.powersetCard n s, ∏ e ∈ t, d e = ∑ u ∈ Finset.powersetCard (s.card - n) s, ∏ e ∈ s \ u, d e

    The field, discharged. QOU.Mass.BodyOrderJetGrading.body_eq_graded asserts bodyTerm n = gradedTerm n. In the bond-product model bodyTerm n = Σ_{|t| = n} ∏_{e ∈ t} d_e (the n-body cluster sum) and gradedTerm n is the coefficient at grade |s| - n, given by prod_bonds_graded. esymm_eq_compl_sum is exactly the equation between them.

    So the assumed field is a theorem here, and it is not definitional: the two sides are different expressions over different index sets, related by the complement bijection.

    Block factorisation, abstract half #

    The measured composition law is G_A(x) = [∏_bonds (x + d)] · G_1(x)^A. The bracket is gf_bonds and its factors are derived (gfOf_bridge). This section supplies the G_1(x)^A half abstractly: a generating function over a product index set, with additive degree and multiplicative coefficients, factorises.

    Applying this to the atomic braid needs the index set of H_{3A}'s normal forms to BE such a product -- i.e. that Coxeter length is additive over the Young subgroup S_3 × ⋯ × S_3, ℓ(w) = Σᵢ ℓ(wᵢ). That is the parabolic length formula, and it is proved in QOU.Knot.BlockLengthAdditive (length_blockProd, and length_blockProd_of_supportedIn for the two-sided support condition a nucleon block actually satisfies). QOU.Knot.BlockGeneratingFunction joins the two halves, using the dependent-family form gf_pi (in QOU.Knot.GradedGeneratingFunction, since it needs only a CommSemiring) rather than gf_pow below -- nucleon blocks are not identical to one another.

    (An earlier version of this note said the parabolic formula was "not proved here" and called this section bookkeeping rather than content. That was true when written and is no longer; the missing half was the reason the note existed.)

    The generating function is multiplicative over a product index set, when the degree is additive and the coefficient multiplicative across the factors.

    theorem QOU.Knot.BodyOrderExpansion.gf_pow {R : Type u_2} [CommRing R] {ι : Type u_3} [DecidableEq ι] (s : Finset ι) (c : ι → R) (deg : ι → ℕ) (A : ℕ) :
    (GradedGeneratingFunction.gf (Fintype.piFinset fun (x : Fin A) => s) (fun (f : Fin A → ι) => ∏ i : Fin A, c (f i)) fun (f : Fin A → ι) => ∑ i : Fin A, deg (f i)) = GradedGeneratingFunction.gf s c deg ^ A

    The A-fold form: G_1(x)^A. Over A independent copies of one block, with the total degree the sum of the blocks' degrees and the coefficient their product, the generating function is the single block's raised to the A.
