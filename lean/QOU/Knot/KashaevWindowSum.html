    theorem QOU.Knot.FigureEightVolume.sum_kashaevProd_window_sandwich {N k : ℕ} (hkN : k < N) (s : Finset ℕ) {T : ℕ → ℝ} {B : ℝ} (hs : ∀ k' ∈ s, k' < N) (h : ∀ k' ∈ s, |Real.log (kashaevProd N k') - Real.log (kashaevProd N k) - T k'| ≤ B) :
    |∑ k' ∈ s, kashaevProd N k' - kashaevProd N k * ∑ k' ∈ s, Real.exp (T k')| ≤ kashaevProd N k * (Real.exp B - 1) * ∑ k' ∈ s, Real.exp (T k')

    The sandwich, as a ratio. The window sum is within e^{±B} of the model — the form the Laplace step consumes, since e^{B} → 1 exactly when the expansion's error does.

    No sign hypothesis on B. A first draft carried 0 ≤ B, on the reasoning that e^{B} − 1 had better be nonnegative; it is not needed, because the step the lower half actually rests on is e^{B} + e^{−B} ≥ 2, which holds for EVERY real B. (And a negative B forces s empty, since h would bound an absolute value below zero — so both sides are 0 and the statement is true there too.)
