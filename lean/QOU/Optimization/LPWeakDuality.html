    Linear-programming weak duality (proved backing for the QOU LP/SDP dual witnesses) #

    Every QOU operator-selection / shadow-price compute emits a primal–dual pair in its *.witness.json and asserts duality_gap ≥ 0 (equivalently dual_obj ≤ primal_obj) as a numerical check (see the LP/SDP-dual infra in AGENTS.md and computations/lp_dual_solver.py). This file replaces that numeric check with a proved statement: for any primal-feasible x and any dual-feasible λ, the dual objective is a lower bound on the primal objective, so the duality gap is non-negative. This is the weak duality half; it holds for any feasible pair, requires no optimality, and needs only ordered-ring structure — no analysis, no archimedean input.

    Formulation #

    For a constraint matrix A : Fin m → Fin n → R, right-hand side a : Fin m → R and cost vector c : Fin n → R, over an ordered commutative ring R:

    • Primal feasibility (PrimalFeasible A a x): A x = a (row-wise, ∀ i, ∑ j, A i j * x j = a i) together with x ≥ 0 (∀ j, 0 ≤ x j).
    • Dual feasibility (DualFeasible A c l): λᵀ A ≤ c (∀ j, ∑ i, l i * A i j ≤ c j).

    The primal is min ∑ⱼ cⱼ xⱼ s.t. A x = a, x ≥ 0; its Lagrangian dual is max ∑ᵢ aᵢ λᵢ s.t. λᵀ A ≤ c. Weak duality is the inequality between the two objectives at any feasible pair.

    Contents #

    • lp_weak_duality — ∑ᵢ aᵢ λᵢ ≤ ∑ⱼ cⱼ xⱼ for feasible x, λ.
    • lp_duality_gap_nonneg — the gap primalObj − dualObj is non-negative.

    The base ring is a generic {R : Type*} with [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] — the substrate-side (§7c) statement of an inequality that later specialises to ℝ at the numerical witnesses without any change to the proof.

    -- Ref: [rivin2003] Igor Rivin, "Combinatorial optimization in geometry", -- Adv. Appl. Math. 31 (2003) 242–271, §3 (LP duality for the angle-structure -- / metric programs); the abstract LP weak-duality inequality proved here.

              theorem QOU.Optimization.lp_weak_duality {m n : ℕ} {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {A : Fin m → Fin n → R} {a : Fin m → R} {c x : Fin n → R} {l : Fin m → R} (hp : PrimalFeasible A a x) (hd : DualFeasible A c l) :
              ∑ i : Fin m, a i * l i ≤ ∑ j : Fin n, c j * x j

              LP weak duality. For any primal-feasible x and dual-feasible λ, the dual objective bounds the primal objective from below: ∑ᵢ aᵢ λᵢ ≤ ∑ⱼ cⱼ xⱼ.

              Proof: substitute aᵢ = ∑ⱼ Aᵢⱼ xⱼ, swap the order of summation, factor out xⱼ to reach ∑ⱼ (∑ᵢ λᵢ Aᵢⱼ) xⱼ, then bound each term using the dual inequality ∑ᵢ λᵢ Aᵢⱼ ≤ cⱼ and xⱼ ≥ 0.

              theorem QOU.Optimization.lp_duality_gap_nonneg {m n : ℕ} {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {A : Fin m → Fin n → R} {a : Fin m → R} {c x : Fin n → R} {l : Fin m → R} (hp : PrimalFeasible A a x) (hd : DualFeasible A c l) :
              0 ≤ dualityGap c x a l

              The LP duality gap is non-negative. For any primal-feasible x and dual-feasible λ, 0 ≤ dualityGap c x a l = primalObj c x − dualObj a l. This is the proved statement standing behind the duality_gap ≥ 0 assertion in every QOU LP/SDP-dual witness.
