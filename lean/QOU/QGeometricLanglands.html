    Chapter 11 — $q$-Geometric Langlands Correspondence #

    Formalization of the q-deformed Geometric Langlands correspondence within the QOU framework. The substrate parameter q ∈ 𝔾_m^{nt} defines a 𝔾_m-family of deformations; the Yekutieli obstruction classes κ_n and their Kummer filtration control q-flatness; the Hecke algebra H_n(q) provides q-Hecke operators; and the fibre functor τ mediates the automorphic–spectral equivalence.

    LaTeX source: chapters/q-geometric-langlands.tex

    Structure #

    1. q-Local system — functor Π₁(X) → Rep(G_q) with q-monodromy
    2. q-Flat connection — ∇_q² = (q−1)·F_q
    3. q-Hecke operator — integral transform on Bun_{G_q}
    4. q-Hecke eigensheaf — eigenvalue under Hecke operators
    5. q-Langlands dual — Ǧ_q = G_{q⁻¹}^∨
    6. q-Oper — transverse Borel reduction of q-flat connection

    References #

    • [frenkel2007] E. Frenkel, Lectures on the Langlands Program and Conformal Field Theory, 2007.
    • [aganagic2018] M. Aganagic, E. Frenkel, A. Okounkov, Quantum q-Langlands Correspondence, 2018.

    Universe pinning (repair 2026-06-11): the structures below carry Type* fields (fibreAt, groupAt, dualGroupAt), so each occurrence of QLocalSystem M / QHeckeEigensheaf M / QOper M in a different binder of the same theorem header auto-bound a fresh rigid universe — and the proof bodies then failed with QLocalSystem.{u_1, u_4} ≠ QLocalSystem.{u_1, u_2} mismatches. We pin the universes once and tie every use site explicitly: u = base type M, v = local-system fibres, w = quantum gauge group carrier, x = Langlands-dual group carrier.

    §1 q-Local Systems #

    source
    structure QOU.QGeometricLanglands.QLocalSystem (M : Type u) :
    Type (max u (v + 1))

    q-Local system: a functor from the fundamental groupoid of the brane curve X to representations of the quantum group G_q, satisfying the q-monodromy condition.

    For every contractible loop ρ, the monodromy is: L_q(ρ) = id + (q − 1) · Ω_q(ρ) where Ω_q(ρ) is the q-holonomy residue.

    The q-monodromy arises from d_q² ≠ 0 and the Kummer reduction of the Yekutieli class κ₀ controls brane tower lifting: L_q lifts from level n to n+1 iff n ∣ χ(A).

    LaTeX: \label{def:q-local-system} uses: def:categorical-q-connection, def:substrate-parameter, def:q-flat-connection, prop:categorical-dq-squared, prop:kummer-filtration-obstruction

    • sp : ArchimedeanSubstrateField M

      The underlying substrate parameter family.

    • fibreAt : M → Type v

      The representation type at each point (fibre of the local system).

    • monodromy (p : M) : self.fibreAt p → self.fibreAt p

      The monodromy endomorphism acting on the fibre at each point.

    • holonomyResidue : M → ℝ

      q-monodromy residue: the Ω_q(ρ) term.

    • q_monodromy (p : M) : self.holonomyResidue p = 0 → ∀ (x : self.fibreAt p), self.monodromy p x = x

      The q-monodromy condition: when the residue vanishes, monodromy acts as the identity on the fibre.

    • classical_limit (p : M) : self.sp.field p = 1 → self.holonomyResidue p = 0

      Classical limit: at q = 1 the residue vanishes.

      §2 q-Flat Connections #

      source
      structure QOU.QGeometricLanglands.QFlatConnection (M : Type u) :
      Type u

      q-Flat connection: a q-connection satisfying the q-flatness equation ∇_q² = (q − 1) · F_q.

      The q-curvature is determined by the Yekutieli class via the Hochschild–Kostant–Rosenberg comparison: F_q = HKR⁻¹(κ₀) ∈ HH²(U_q, Ad)

      A q-flat connection has F_q = 0.

      LaTeX: \label{def:q-flat-connection} uses: def:q-local-system, def:categorical-q-connection, prop:categorical-dq-squared

      • sp : ArchimedeanSubstrateField M

        The substrate parameter.

      • curvature : M → ℝ

        The intrinsic q-curvature F_q at each point, determined by the Yekutieli class: F_q = HKR⁻¹(κ₀). This is the minimal curvature compatible with d_q² ≠ 0.

      • connectionCurvature : M → ℝ

        The connection's total curvature ∇_q² decomposes as ∇_q² = (q − 1) · F_q + F_conn where F_conn is the connection-dependent part. A q-connection is q-flat when F_conn = 0, i.e. all curvature comes from the intrinsic obstruction (q − 1) · F_q.

      • total_curvature (p : M) : self.connectionCurvature p = (self.sp.field p - 1) * self.curvature p + self.connectionCurvature p - (self.sp.field p - 1) * self.curvature p

        The total curvature is the sum of intrinsic and connection parts.

      • is_q_flat : Prop

        q-flat means the connection-dependent curvature vanishes: all curvature is intrinsic (from the Yekutieli obstruction).

          §4 q-Hecke Eigensheaves #

          source
          structure QOU.QGeometricLanglands.QHeckeEigensheaf (M : Type u) :
          Type (max (max u (u_1 + 1)) (v + 1))

          q-Hecke eigensheaf: a q-D-module M on Bun_{G_q}(X) such that for every q-Hecke operator T_{x,λ}, there is an isomorphism: T_{x,λ}(M) ≃ M ⊗ V_λ(L_q)_x compatible with tensor products and factorisation.

          LaTeX: \label{def:q-hecke-eigensheaf} uses: def:q-hecke-operator, def:q-local-system

          • heckeOp : QHeckeOperator M

            The q-Hecke operator data.

          • eigenvalue : QLocalSystem M

            The eigenvalue q-local system.

          • tensor_compatible : self.eigenvalue.sp = self.heckeOp.sp

            Tensor compatibility (encoded as the consistency condition on eigenvalue data that the structure can express): the eigenvalue q-local system is defined over the same substrate parameter as the q-Hecke operator. This is the eigensheaf compatibility — the T_{x,λ}(M) ≃ M ⊗ V_λ(L_q)_x isomorphisms can only compose under tensor product (λ + μ = composite for λ and μ, twisted by the braiding σ_q) when L_q and the Hecke action share the substrate q. Replaces the former : True placeholder.

          • factorisation (p : M) : self.eigenvalue.sp.field p = 1 → self.eigenvalue.holonomyResidue p = 0

            Factorisation: Hecke operators at distinct points commute up to the O(q − 1) correction. At the classical point q = 1 the correction is screened — the eigenvalue local system's q-holonomy residue vanishes wherever the substrate is classical, so the Hecke operators commute on the nose. This is the q → 1 content of the O(q − 1) factorisation (replacing the former : True).

            §5 q-Langlands Dual Group #

            source
            structure QOU.QGeometricLanglands.QLanglandsDual (M : Type u) :
            Type (max (max u (w + 1)) (x + 1))

            q-Langlands dual group: Ǧ_q = G_{q⁻¹}^∨.

            Root system duality composed with substrate inversion q ↦ q⁻¹. For G_q = SU_q(2): Ǧ_q = SU_{q⁻¹}(2) ≅ SO_{q⁻¹}(3).

            The inversion q ↦ q⁻¹ interchanges the braiding eigenvalues q ↔ −q⁻¹, exchanging symmetric and antisymmetric channels. In the 𝔾_m-family picture this is the inversion automorphism ι : 𝔾_m → 𝔾_m, preserving torsion subgroups μ_n.

            LaTeX: \label{def:q-langlands-dual} uses: def:quantum-gauge-group, def:quantum-su2

              The substrate inversion: dual parameter is q⁻¹.

            • dualGroupAt : M → Type x

              The dual group at each point.

                class QOU.QGeometricLanglands.FibreFunctorRigidity (M : Type u) :
                Prop

                Fibre-functor rigidity (axiomatized): in a QOU the fibre functor τ is unique up to unique isomorphism (Tannaka–Krein). Any two q-local systems with the same holonomy residues are equal.

                This is the deep categorical input; the full proof requires Tannaka–Krein reconstruction for quantum groups, which is not in Mathlib.

                  Two q-local systems with the same substrate and the same holonomy residues at every point are equal.

                  theorem QOU.QGeometricLanglands.kummer_divisibility_criterion (χ : ℤ) (n : ℕ) (_hn : n ≥ 1) :

                  §7a The q-Geometric Langlands Conjecture (Lean axiom) #

                  The conjecture asserts an equivalence of ∞-categories:
  𝕃_q : 𝒟_q-mod(Bun_{G_q}(X)) ≃ QCoh(LocSys_{Ǧ_q}(X))
parametrised by q ∈ 𝔾_m^{nt}, satisfying Hecke compatibility,
fibre-functor factorisation, q-oper locus, Kummer constraint,
and classical limit.

Since ∞-categories, moduli stacks, and q-D-modules are not in
Mathlib, the conjecture is axiomatized as a class.  The `sorry`
in each instance is understood as **conjecture**, not missing proof.
Downstream theorems depend on this class explicitly, making the
logical dependency chain visible.

                  class QOU.QGeometricLanglands.QGeometricLanglandsConjecture (M : Type u) :
                  Type (max (max u (u_1 + 1)) (v + 1))

                  q-Geometric Langlands conjecture (axiomatized).

                  Asserts the existence of a functor 𝕃_q from q-Hecke eigensheaves to q-local systems that is:

                  1. Compatible with Hecke operators
                  2. Determined by the fibre functor
                  3. Injective on q-opers

                  LaTeX: \label{conj:q-geometric-langlands} uses: def:q-local-system, def:q-hecke-eigensheaf, def:q-langlands-dual, def:q-flat-connection

                  • langlandsFunctor : QHeckeEigensheaf M → QLocalSystem M

                    The Langlands functor: eigensheaves ↦ local systems.

                  • hecke_compatible (es : QHeckeEigensheaf M) : (langlandsFunctor es).sp = es.heckeOp.sp

                    Hecke compatibility: the functor intertwines Hecke operators with the local system action.

                  • recovers_eigenvalue (es : QHeckeEigensheaf M) : langlandsFunctor es = es.eigenvalue

                    The functor recovers the eigenvalue local system.

                  • oper_injective (_op _op' : QOper M) (es es' : QHeckeEigensheaf M) : langlandsFunctor es = langlandsFunctor es' → es.eigenvalue = es'.eigenvalue

                    Injectivity on q-opers: distinct q-opers produce distinct eigensheaves.
