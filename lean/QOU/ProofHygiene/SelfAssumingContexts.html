    The criterion #

    All four of the ledger's self-assuming patterns — proof-decoy-hypothesis, field-projection (22), exact-field-projection (2), tuple-projection (11), 48 live genuine entries between them — are instances of one property, and it is worth naming because it is checkable rather than aesthetic.

    source
    def QOU.ProofHygiene.Contentless (K : Sort u_1) (C : Prop) :
    Prop

    A context class is contentless for C when it is inhabited exactly when C holds.

    Instantiating such a class is then logically identical to assuming C, whatever the class's fields are named and however the conclusion is extracted from them — by a projection, by an application, or by a chain of either.

    The negation is the practical test, and it is the one a reviewer can actually run: exhibit an instance without already having the conclusion (not_contentless_of_witness).

      🛑 Contentless is not automatically a defect — read this before applying it.

      A conjecture carrier is supposed to be contentless for its conjecture. That is what AGENTS.md §3b means by "the class instance is the conjectural witness (sorry = conjecture), not a missing proof": assuming the class is meant to be exactly assuming the conjecture, and Nonempty K ↔ C is the correct semantics, not a finding.

      The defect is a theorem that extracts C from such a carrier and is then presented, named, or cited as though C had been derived. The ledger's own wording for the field-projection entries makes the same distinction: "a projection like this is the legitimate Mathlib accessor idiom ONLY when something builds the bundle" — i.e. when the carrier is inhabited by real mathematics somewhere, rather than never inhabited at all.

      So the criterion below answers "does this class carry content?". It does not by itself answer "is this declaration wrong?". For that, ask the two questions the ledger asks: is anything ever going to inhabit the carrier, and is a downstream declaration presenting the projection as a derivation?

      The one case that is unconditionally a defect regardless of intent is the bare-Prop-field carrier (closing section) — there, the carrier asserts nothing even as a conjecture, so it cannot serve as a conjectural witness either.

      source
      theorem QOU.ProofHygiene.not_contentless_of_witness {K : Sort u_1} {C : Prop} (hK : Nonempty K) (hC : ¬C) :
      ¬Contentless K C

      The reviewer's test. If the class can be instantiated while the conclusion fails, it is not contentless — it carries something. Contrapositively, a class you can only instantiate by already having C proves nothing about C.

              theorem QOU.ProofHygiene.conditional_not_contentless :
              ¬Contentless (ConditionalContext False False) False

              A genuine conditional class is NOT contentless for the conclusion, witnessed at H = C = False — it is inhabited there while the conclusion fails. This is the reviewer's test (not_contentless_of_witness) run on the shape that should pass it.

              source
              theorem QOU.ProofHygiene.separation :
              Nonempty (ConditionalContext False False) ∧ ¬Nonempty (DecoyContext False)

              The separation. At H = C = False the conditional class is inhabited and the decoy class is not. Same conclusion, opposite inhabitedness — so the two shapes are genuinely different objects, and "carries the implication" versus "carries the implication and asserts its antecedent" is a real distinction rather than a stylistic preference.

              This is what makes proof-decoy-hypothesis a criterion: a reviewer can ask whether the class supplies its own antecedent, and that question has a definite answer.

              The bare-Prop-field carrier — worse than self-assuming, and demonstrated elsewhere #

              proof-claims-unencoded / prop-universe-field. The ledger states the defect the same way in every instance:

              "Every field of this carrier is typed bare : Prop — the UNIVERSE of propositions, not a proposition. An instance therefore supplies a proposition rather than a proof of one, so instance := ⟨True⟩ type-checks and discharges the class, and every [C]-conditional theorem downstream is conditional on nothing."

              It is a type-level error rather than a judgement about intent, and it is strictly worse than the self-assuming shapes above — those at least assert their conclusion; this one asserts nothing even as a conjecture, so it cannot serve as a §3b conjectural witness either.

              It is demonstrated in docs/audits/, deliberately, and not here.

              • 2026-08-23-free-prop-field-triviality-probe.lean — the original, which has priority: three real carriers reproduced verbatim, each discharged with ⟨True, …⟩, and a conditional theorem shown unconditional.
              • 2026-09-12-prop-universe-carrier-shape.lean — the same for the abstract shape, plus the conjunction case (a field conjoining Prop-typed fields changes nothing, since True ∧ True discharges it) and the discriminator: claim : Prop is always inhabited, claim : C at C = False never is.

              Why not in this file. scripts/free-prop-field-audit.py globs content/**/*.lean, so a demonstration carrier placed here is by construction an instance of the very defect that audit counts — a permanent false positive in an active drain queue (bean qou-tsnp). It was here briefly and did exactly that, reported as PropUniverseWithConjunction, 2 fields. The docs/audits/ convention exists for this reason and the 2026-08-23 probe already followed it.

              The criterion above still covers the pattern: such a carrier is Contentless for True, which is the degenerate case of Contentless K C.
