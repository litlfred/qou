    QOU.MassEndomorphism.VolumeBridge — the Volume-Conjecture bridge (§3b-cond) #

    A non-degenerate conditional-class carrier (AGENTS.md §3b-cond) for the mass-endomorphism conjecture, reducing its open surface to exactly the one genuinely-open ingredient: the Volume-Conjecture bridge (Step 3 of conj:mass-endomorphism).

    The three steps of the conjecture #

    Per [mass-endomorphism-conjecture.md §"Established results"]:

    • Step 1 (proved, prop:categorical-mass-markov). The single-level categorical mass is the descended Markov trace |tr_M(ρ(β))| (Nakayama S² = id).
    • Step 2 (proved, prop:topological-mass-formula). The full brane tower sums to Vol(K_β)/ℏ_q².
    • Step 3 (OPEN — the Volume Conjecture). The Jones–Markov trace tr_M(ρ(β)) = J(K;q) (a Laurent polynomial) and the hyperbolic volume Vol(K) (transcendental) are different knot invariants; the only known bridge is the Volume Conjecture \cite{kashaev1997, murakami-murakami2001}. The transient brane tower Σ Φ_q(z_i) is conjectured to close this gap at the substrate q_0.

    What this carrier does (§3b-cond non-degenerate) #

    The class VolumeBridge axiomatises only the open input — the archimedean bridge equality volTerm = descTrace + transient (the Volume-Conjecture content at q_0) — and derives the manuscript's stated identities:

    • transient_identity : transient = volTerm − descTrace (the conjecture's displayed transient identity), and
    • fullMass_eq_volTerm : descTrace + transient = volTerm (Step 2, the full categorical mass).

    This is non-degenerate per §3b-cond item 5: the class field is the hypothesis (the VC bridge, the open Step 3), and the theorems derive the conclusions — the class does not carry a block's own conclusion behind a trivial projection.

    Honest open primary — NO instance #

    Unlike QOU.MassEndomorphism.MassEndomorphism ([MassEndomorphismConjecture.lean]), this class deliberately carries no instance. Per AGENTS.md §3b-tax ("an unproved primary is honestly represented by a content-bearing class with no instance; do not fabricate a trivial instance to 'close' it"), the absence of an instance is the honest representation of the open state: any [VolumeBridge R β]-conditional result is genuinely modulo the Volume Conjecture.

    Follow-up, now actioned (2026-08-24): the sibling class MassEndomorphism in MassEndomorphismConjecture.lean shipped a global instance canonical (all-zeros) and MassEndomorphismTrivial.lean shipped trivial_int_zero; both made [MassEndomorphism R β] synthesizable, so conditionality against that class was vacuous. Both are now defs, so the class is no longer globally inhabited and a caller who wants the zero model must name it. The mathematical gap the models stand in for is unchanged and still governed by the GAP-18a scoping audits (docs/audits/2026-05-04-gap-6a-18a-scoping.md): there is still no deterministic recipe Braid n → MassEndomorphism R β. VolumeBridge remains the instance-free carrier for the open Volume-Conjecture bridge.

    class QOU.MassEndomorphism.VolumeBridge (R : Type u_1) [CommRing R] (β : Type u_2) :
    Type u_1

    The Volume-Conjecture bridge (open input of conj:mass-endomorphism).

    Over a commutative ring R ⊇ ℤ[q^±1] and a braid type β:

    • descTrace : R — the descended Markov trace |tr_M(ρ(β))| (Step 1, proved; at the archimedean realisation R = ℝ it is the absolute value);
    • transient : R — the brane-tower transient sum Σ Φ_q(z_i);
    • volTerm : R — the volume term Vol(K_β)/ℏ_q² (Step 2, proved);
    • archimedean_bridge — the sole open field: the Volume-Conjecture equality at q_0, volTerm = descTrace + transient, asserting the transient tower closes the Jones→Volume gap.

    Carries no instance: this is an honest open primary (§3b-tax).

    • descTrace : R

      Descended Markov trace |tr_M(ρ(β))| (Step 1, proved).

    • transient : R

      Brane-tower transient sum Σ Φ_q(z_i).

    • volTerm : R

      Volume term Vol(K_β)/ℏ_q² (Step 2, proved).

    • archimedean_bridge : volTerm β = descTrace β + transient β

      The open Volume-Conjecture bridge at q_0: the descended trace plus the transient tower realises the volume term.
