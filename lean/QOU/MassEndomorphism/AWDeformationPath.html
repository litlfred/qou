    class QOU.MassEndomorphism.AWDeformationPath {R : Type u_1} [CommRing R] (σ : R →+* R) :
    Type u_1

    AW deformation-path conjecture (§3b class; conjecture — no instance is provided). One AW tridiagonal family (a t, b t, c t) joins the free endpoint (t = 0, q-Hermite bottom: diagonal off) to the bound endpoint (t = 1); a potential Φ on the path has the complex-volume defect 𝔙 as its endpoint difference (the categorical Neumann–Zagier path integral); and the 𝔙-ladder satisfies ONE three-term recurrence whose multiplier is bar-even. All fields are inputs; the two-channel (binding + 𝔔_β) descent is derived below.

    • a : R → ℕ → Rˣ

      deformation family: super-diagonal at parameter t (units, matching overlapColumn/IsEigencolumn, so each t-slice plugs into the overlap machinery without extra plumbing).

    • b : R → ℕ → R

      deformation family: diagonal at parameter t.

    • c : R → ℕ → R

      deformation family: sub-diagonal at parameter t.

    • free_qHermite_bottom (n : ℕ) : b σ 0 n = 0

      the free endpoint is the q-Hermite bottom of the scheme: the diagonal term vanishes at t = 0.

    • potential : R → R

      Neumann–Zagier-type potential on the deformation path.

    • defect : R

      the complex-volume defect 𝔙 (the fibre object of this block).

    • path_integral : defect σ = potential σ 1 - potential σ 0

      𝔙 is the potential's endpoint difference: bound (t=1) − free (t=0) — the categorical path integral over the character-variety path (abelian → discrete faithful).

    • ladder : ℕ → R

      the ladder of defects along body order, headed by 𝔙.

    • ladder_head : ladder σ 0 = defect σ
    • multiplier : R

      the shared three-term multiplier (the 2cosh-type coefficient).

    • multiplier_bar_even : σ (multiplier σ) = multiplier σ

      the multiplier is bar-even — the load-bearing hypothesis.

    • ladder_recurrence (n : ℕ) : ladder σ (n + 2) = multiplier σ * ladder σ (n + 1) - ladder σ n

      ONE recurrence on the full complex ladder.
