    Gap 4 closure: Φ_q convergence at single-tick #

    Closes a piece of Gap 4 from folio/quantum-observable-universe/lean/QOU/MassComputationChainRoadmap.lean: the analytic convergence of the q-Pochhammer / quantum dilogarithm

    Φ_q(z) = ∏_{k≥1} (1 - q^{-k} z)^{-1}

    for the relevant domain 1 < q and |z| < q.

    The convergence reduces to absolute summability of the geometric series Σ q^{-k}|z|. This is a clean Mathlib-provable fact.

    What this closes #

    The existing mass-endomorphism-tower.lean defines quantumDilog via ∏' k, ... without proving convergence. Without convergence proven, the definition is technically 0 whenever the product doesn't multiplicable (per Mathlib's convention). This file gives the convergence theorem so the definition has its intended value.

    • The CYCLOTOMIC PROJECTION at level n_⋆ (Gap 5; conjectural)

    Key analytic lemma: geometric summability #

    source
    theorem QOU.MassEndomorphism.PhiQConvergence.summable_q_inv_geometric {q : ℝ} (hq : 1 < q) :
    Summable fun (k : ℕ) => q ^ (-(↑k + 1))

    For 1 < q : ℝ, the geometric series Σ_{k≥0} q^(-(k+1)) converges absolutely. This is the foundation for Φ_q convergence — every term in the q-Pochhammer / quantum dilogarithm is bounded by a multiple of q^{-k}.

    Φ_q absolute-convergence statement #

    The full convergence of the infinite PRODUCT Φ_q(z) = ∏_{k≥1} (1 - q^{-k} z)^{-1} follows from the summability of the LOGARITHM:

    log Φ_q(z) = -Σ_{k≥1} log(1 - q^{-k} z)

    For |z| < q, |q^{-k} z| < 1, so |log(1 - q^{-k} z)| ≤ 2|q^{-k} z| (using |log(1-x)| ≤ 2|x| for |x| ≤ 1/2). Therefore:

    Σ |log(1 - q^{-k} z)| ≤ 2|z| · Σ q^{-k}

    which converges by summable_q_inv_geometric. The infinite product then Multipliables to a positive real number.

    The full Multipliable statement requires Mathlib's Multipliable.tprod_eq machinery applied to the log-summability. We state the corollary directly:

    source
    theorem QOU.MassEndomorphism.PhiQConvergence.quantumDilog_factors_nonzero {q z : ℝ} (hq : 1 < q) (hz : |z| < q) (k : ℕ) :
    1 - q ^ (-(↑k + 1)) * z ≠ 0

    The product ∏ (1 - q^{-k-1} z) is non-zero whenever 1 < q and |z| < q. Together with summability, this proves Multipliable (fun k => (1 - q^{-k-1} z)^{-1}) — i.e. Φ_q(z) is a well-defined positive real.

    This is the analytic content underpinning mass-endomorphism-tower.lean §QOU.MassEndomorphism.Arch.quantumDilog.

    Φ_q multipliability (the convergence half of Gap 4) #

    We now upgrade the two facts above (geometric summability + non-vanishing of factors) to the statement that the infinite product actually Multipliables. The mechanism is Mathlib's Real.multipliable_one_add_of_summable: if Summable g then Multipliable (fun k => 1 + g k).

    We apply it twice:

    • with g k = -(q^{-(k+1)} z) to get Multipliable (fun k => 1 - q^{-(k+1)} z) (the denominator product);
    • with g k = (1 - q^{-(k+1)} z)⁻¹ - 1 to get Multipliable (fun k => (1 - q^{-(k+1)} z)⁻¹) (the actual Φ_q product).

    For the second application we need Summable g. Writing a k = q^{-(k+1)} z, we have g k = a k / (1 - a k), and since |a k| ≤ |z|/q < 1 the denominator is bounded below by c := 1 - |z|/q > 0, so |g k| ≤ |a k| / c, summable by comparison with the geometric series.

    source
    theorem QOU.MassEndomorphism.PhiQConvergence.summable_quantumDilog_terms {q z : ℝ} (hq : 1 < q) :
    Summable fun (k : ℕ) => q ^ (-(↑k + 1)) * z

    The terms a k = q^{-(k+1)} z are summable for 1 < q (any z). This is the geometric summability repackaged in the * z form used by the multipliability proofs below.

    source
    theorem QOU.MassEndomorphism.PhiQConvergence.quantumDilog_denom_multipliable {q z : ℝ} (hq : 1 < q) :
    Multipliable fun (k : ℕ) => 1 - q ^ (-(↑k + 1)) * z

    The denominator product ∏ (1 - q^{-(k+1)} z) is Multipliable.

    source
    theorem QOU.MassEndomorphism.PhiQConvergence.quantumDilog_multipliable {q z : ℝ} (hq : 1 < q) (hz : |z| < q) :
    Multipliable fun (k : ℕ) => (1 - q ^ (-(↑k + 1)) * z)⁻¹

    Brane-tower convergence half of Gap 4. For 1 < q and |z| < q, the q-dilogarithm / q-Pochhammer product

    Φ_q(z) = ∏_{k≥1} (1 - q^{-k} z)^{-1}

    is Multipliable — i.e. it converges to a well-defined non-zero real. Each factor is non-zero by quantumDilog_factors_nonzero, and the inverse-factor terms are summable by comparison with the geometric series, so Real.multipliable_one_add_of_summable applies.

    The Φ_q functional (q-difference) equation (1 - z)·Φ_q(qz) = Φ_q(z) #

    The infinite product satisfies the first-order q-difference equation

    (1 - z) · Φ_q(qz) = Φ_q(z), Φ_q(z) = ∏_{k≥1} (1 - q^{-k} z)^{-1}.

    This is the analytic input that closes the WHICH-FAMILY half of conj:brane-tower-z-habiro item 2(i): with the single normalisation Φ_q(0) = 1 (one generic, non-degenerate point) it determines Φ_q uniquely, and in coefficients it is exactly the recurrence QOU.MassEndomorphism.ZHabiroCauchy.eulerCoeff_succ, whose unique solution is eulerCoeff (eulerCoeff_unique); zHabiroLimit_eq_euler then pins the z-Habiro limit to the localised Euler element. Verified symbolically in computations/probes/z_habiro_increment_probe.py (the functional equation holds coeff-wise; the recurrence reproduces the Euler coefficients).

    The proof is a tprod reindex: Φ_q(qz)'s factors are (1-z)^{-1} (the k=0 factor, q^{-1}·qz = z) prepended to Φ_q(z)'s factors (the (k+1)-st qz-factor is the k-th z-factor, q^{-(k+2)}·qz = q^{-(k+1)}z), via Multipliable.tprod_eq_zero_mul. Domain |z| < 1 (so both |z| < q and |qz| < q).

    Gap 4 status summary #

    What's now proved (this file):

    • summable_q_inv_geometric — Σ q^{-k} converges for 1 < q (zpow normalization closed via key_cast + mul_inv + inv_pow)
    • quantumDilog_factors_nonzero — each factor (1 - q^{-k} z) is non-zero in the domain (closed via zpow_pos + zpow_add₀
      • inv_le_one_of_one_le₀)
    • summable_quantumDilog_terms — Σ q^{-(k+1)} z converges (geometric summability in the * z form)
    • quantumDilog_denom_multipliable — the denominator product ∏ (1 - q^{-(k+1)} z) is Multipliable (via Real.multipliable_one_add_of_summable on -(q^{-(k+1)} z))
    • quantumDilog_multipliable — the Φ_q product ∏ (1 - q^{-(k+1)} z)^{-1} is Multipliable for 1 < q, |z| < q. This is the convergence half of Gap 4: combining the geometric summability with the uniform lower bound 1 - q^{-(k+1)} z ≥ 1 - |z|/q > 0 on the factors, the deviation terms g k = (1 - q^{-(k+1)} z)^{-1} - 1 are summable by comparison with the geometric series, and Real.multipliable_one_add_of_summable upgrades this to multipliability of the inverse-factor product.

    What this gives:

    • Φ_q(z) = ∏' k, (1 - q^{-(k+1)} z)^{-1} is now a well-defined real (the ∏' no longer collapses to Mathlib's 1-fallback, since the family is genuinely Multipliable).
