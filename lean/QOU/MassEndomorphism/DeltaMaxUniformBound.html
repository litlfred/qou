    QOU.MassEndomorphism.DeltaMaxUniformBound — uniform Δ_max in the rank-1 regime #

    The proposition prop:delta-max-uniform-bound closes the archimedean / rank-1 SDP regime of the convergence conjecture conj:jet-tower-uniform-delta-max:

    |Δ⁽ⁿ⁾(ρ)| ≤ 2 · L(β) · ‖ρ(β)‖_op² · 𝔪⁽⁰⁾(ρ_free), independent of n.

    The proof uses operator-norm boundedness of the Markov trace ([thm:markov-trace-factorization]), the recursive brane tower ([def:recursive-brane-tower]), and Kassel–Turaev's bound on the Jones–Wenzl module dimension ([kassel1995] §4.4.3).

    Archimedean tier. This proposition lives on the τ-image side: the operator norm ‖·‖_op is real-valued, the substrate parameter q > 0 is real, and the numerical evaluation at q₀ ≈ 1.1100 appears in the narrative. Per QOU.GroundRingAnnotations, this file is in the Archimedean realisation tier — it is not part of the formal pre-Arch chain.

    The conditional-class structure is supplied by OperatorNormBound below; an instance witnesses the four ingredients of the proof (operator-norm bound, Markov-trace boundedness, level-0 free mass, JW-module dimension bound).

    structure QOU.MassEndomorphism.OperatorNormBound (ρ : Type u_1) :
    Type

    Operator-norm bound data for a vortex ρ with braid representative β ∈ B_n.

    Captures the four quantities needed for the Δ_max uniform bound:

    • braidLength = L(β),
    • opNorm = ‖ρ(β)‖_op on the Jones–Wenzl module,
    • freeMassLevel0 = 𝔪⁽⁰⁾(ρ_free),
    • delta = the per-level residual, along with their non-negativity.

    All quantities are real-valued (Archimedean tier).

    • braidLength : ℕ
    • opNorm : ℝ
    • opNorm_nonneg : 0 ≤ self.opNorm
    • freeMassLevel0 : ℝ
    • freeMassLevel0_nonneg : 0 ≤ self.freeMassLevel0
    • delta : ℕ → ℝ
    • per_level_bound (n : ℕ) : 1 ≤ n → |self.delta n| ≤ 2 * ↑self.braidLength * self.opNorm ^ 2 * self.freeMassLevel0

      The proven per-level bound (Steps 1–4 of the .md proof).
