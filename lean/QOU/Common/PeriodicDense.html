    A continuous function periodic on a dense set is periodic everywhere #

    The identity-theorem-free core of the hibinv input of QOU.QBeta.FaddeevRigidityReduction (bean qou-q95i). The dual-shift periodicity of the Φ_b ratio (CyclicDilogPentagon.ratio_ibinv_periodic) is proved only off the discrete dual pole lattice (the shift_binv guard). To promote it to the everywhere-periodicity the reduction consumes, one does not need the full complex-analytic identity theorem: the dual pole lattice is discrete, so its complement is dense, and a continuous function agreeing with its shift on a dense set agrees everywhere. This isolates the remaining two inputs cleanly: the ratio is continuous (from the entireness endowment, qou-2cvs) and the dual-lattice complement is dense (a discreteness fact).

    Verified lean-direct against pinned Mathlib (exit 0).

    r (z + c) = r z

    A continuous r : ℂ → ℂ that is c-periodic on a dense set is c-periodic everywhere: r(·+c) and r are continuous and agree on a dense set, so they agree.

    theorem QOU.Common.dense_compl_of_countable {s : Set ℂ} (hs : s.Countable) :
    Dense sᶜ

    A countable subset of ℂ has dense complement. sᶜ = ⋂_{x ∈ s} {x}ᶜ, a countable intersection of dense open sets, so it is dense by Baire (ℂ is a complete metric — hence Baire — perfect space).

    theorem QOU.Common.dense_dualPole_compl {b : ℂ} (hb : b ≠ 0) :
    Dense {z : ℂ | 1 + Complex.exp (2 * ↑Real.pi * (z + Complex.I / (2 * b)) / b) ≠ 0}

    The dual pole lattice complement is dense (the hibinv discreteness input, bean qou-q95i). The zero set of the dual quasi-period prefactor 1 + exp(2π(z + i/2b)/b) is exactly where exp(2π(z + i/2b)/b) = -1; by Complex.exp_eq_exp_iff_exists_int this pins z to the discrete lattice { (πi + n·2πi)·b/(2π) − i/2b : n ∈ ℤ }, so the zero set is countable and its complement — the set on which CyclicDilogPentagon.ratio_ibinv_periodic's guard hpre holds — is dense in ℂ. Combined with periodic_of_continuous_of_eqOn_dense (and the qou-2cvs continuity endowment) this discharges the hibinv input of FaddeevRigidityReduction from the everywhere-periodicity side.
