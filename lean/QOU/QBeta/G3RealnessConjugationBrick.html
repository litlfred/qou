    Abstract brick: shared conjugation law ⇒ ratio fixed by conjugation #

    Pure algebra over a generic field with a star ring structure. The physical content ("real") is deferred to the ℂ corollary; here the content is that the ratio is a fixed point of the star automorphism, which needs no ordering and no ℂ.

    source
    theorem QOU.QBeta.G3RealnessConjugationBrick.ratio_star_fixed_of_shared_law {K : Type u_1} [Field K] [StarRing K] {a b u : K} (hu : u ≠ 0) (ha : star a = u * a) (hb : star b = u * b) :
    star (a / b) = a / b

    Shared conjugation law ⇒ the ratio is a fixed point of the star map.

    If star a = u * a and star b = u * b for a common NONZERO u, then the unit u cancels in a / b, so star (a / b) = a / b.

    This is genuine algebraic content, not a tautology: it is FALSE without the shared-u hypothesis (e.g. star a = u * a, star b = v * b with u ≠ v gives star (a/b) = (u/v)·(a/b) ≠ a/b in general). Holds in any field with a star ring structure; ℂ is not required.

    ℂ reading: fixed-by-conjugation ⇒ real #

    ℂ and .im appear only from here on (§7c).

    (a / b).im = 0

    Shared conjugation law ⇒ the ratio is real ((a / b).im = 0).

    The ℂ specialisation of ratio_star_fixed_of_shared_law: a complex number fixed by conjugation has zero imaginary part. This is the honest content of the numerical Im(I_FW/Z_GGM) ≈ 1e-32 — realness follows from the SYMMETRY, not from the float bound.

    Conditional 5₂ instantiation (§3b-cond) #

    The conjugation-covariance of the two 5₂ integrals is NOT proved. It is carried as an explicit hypothesis; the theorem DERIVES realness from it. The class is content-bearing (§3b-tax): its field is a parameter-quantified equation in the SHAPE of the claim (the shared-law covariance), carrying the hypothesis, not the conclusion (ratio).im = 0.

    source
    class QOU.QBeta.G3RealnessConjugationBrick.SharedConjugationCovariance (I_FW Z_GGM : ℂ → ℂ) :
    Prop

    OPEN hypothesis (conditional class). The Fantini–Wheeler combination I_FW and the Garoufalidis–Gu–Mariño assembly Z_GGM of the 5₂ state integral are conjugation-covariant with a common law: for each τ there is a nonzero u (a phase, rooted in the saddle conjugate-pairing V₂ = conj V₁) with conj (I_FW τ) = u * I_FW τ and conj (Z_GGM τ) = u * Z_GGM τ.

    NOT proved. The 5₂ AK-integral probe (PR #4475) found Im(I_FW/Z_GGM) ≈ 1e-32 — that numeric is EVIDENCE for this covariance, not a proof of it. A proof would follow from FW Thm 1.4 (bean qou-h7yk) plus the established saddle conjugate-pairing. Held as a [SharedConjugationCovariance] hypothesis so the downstream realness result is an honest §3b-cond conditional theorem.

    • shared (τ : ℂ) : ∃ (u : ℂ), u ≠ 0 ∧ star (I_FW τ) = u * I_FW τ ∧ star (Z_GGM τ) = u * Z_GGM τ

      For each τ, a common nonzero conjugation factor u covariates both integrals. The existential packages the (data) phase u inside a Prop.
