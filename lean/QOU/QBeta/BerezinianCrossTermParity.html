    theorem QOU.QBeta.BerezinianCrossTermParity.crossTerm_bar_even_of_adjoint_scaled {R : Type u_1} [CommRing R] (σ : R →+* R) (B Dinv k : R) (hinv : ∀ (x : R), σ (σ x) = x) (hk : σ k = k) (hDinv : σ Dinv = Dinv) :
    σ (B * Dinv * (k * σ B)) = B * Dinv * (k * σ B)

    The adjoint-scaled cross-term is bar-EVEN, for any bar-even scaling. If the odd off-diagonal blocks are adjoint-scaled C = k·σB with k bar-even (σk = k) and the even inverse-block Dinv bar-even (σ Dinv = Dinv), then the cross-term t = B·Dinv·C satisfies σ t = t — bar-EVEN — for any ring involution σ. The graded-self-adjoint case C = −σB of #4421 is the k = −1 instance; this shows the obstruction is not special to that sign but holds across the whole bar-even-scaled family.

    σ (B * Dinv * C) = -(B * Dinv * C)

    The non-self-adjoint route is realizable — and it is the g·γ model. A bar-even block B (σB = B) times a bar-odd block C (σC = −C), dressed by a bar-even Dinv, gives a genuinely bar-ODD cross-term: σ t = −t. The dressing g = B·Dinv is bar-even and the weight γ = C bar-odd — exactly the OddDecayWeightParity factorization, here derived as the generic bar-odd carrier from independent (non-adjoint) blocks.

So the realizable bar-odd carrier of crossTerm_bar_odd_of_barEven_barOdd_blocks evades the adjoint-scaled obstruction crossTerm_bar_even_of_adjoint_scaled exactly off 2-torsion — the two families are disjoint outside the degenerate 2-torsion locus.
