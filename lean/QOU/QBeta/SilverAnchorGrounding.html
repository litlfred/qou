    QOU.QBeta.SilverAnchorGrounding #

    Categorical grounding of the Q_β silver-ratio anchor. From the single defining relation of the silver ratio q² − 2q − 1 = 0 (q = 1 + √2) this file proves the two structural facts the existing silver-anchored c_k work assumed but never derived:

    1. The silver locus is the Q_A decay-prefactor zero. The substrate-branch Q_A numerator factor 2q + 1 − q² equals −(q² − 2q − 1), so it vanishes exactly on the silver locus. The true Q_β = |Δ(net)|·E₀ uses the GB-reduced trefoil coefficient, and Δ(net)(1+√2) = 82216 + 58136·√2 ≠ 0 ((q²−2q−1) ∤ Δ(net); verified in computations/qbeta/qbeta_silver_pole_subdominant_probe.py), so the Q_A zero is not cancelled and F = Q_β / [Q_A · cos α_eff] has a genuine pole there — the "categorical derivation of Q_A·cos α_eff's zero" direction flagged as productive in QOU.QBeta.RationalCoeffRecurrence. This pole is subdominant, not the dominant root. In the substrate variable it sits at u_silver = u(1+√2) ≈ 0.321, giving characteristic root 1/u_silver ≈ 3.12 (RationalCoeffRecurrence.pole_reciprocal_is_char_root), not the dominant tail ratio 1/u_substrate ≈ 117.4 (prop:q-beta-radius-of-convergence-gate, PR #1727; u_substrate ≈ 0.0085 < u_silver). The dominant pole is closer to 0 and comes from a non-Q_A source — so the silver/Q_A zero pins one subdominant root of the kernel's minimal denominator, and prunes the search for the dominant root (it is not the Q_A zero).

    2. Hoefsmit b² = 7/8 at that same locus. With the Hoefsmit value b² = (q⁴ + q² + 1)/(q² + 1)², the silver relation forces 8·(q⁴ + q² + 1) = 7·(q² + 1)², i.e. b² = 7/8. The c_8/c_9/c_10 silver rationals in QOU.QBeta.Cn_at_silver (PR #1793) take b² = 7/8 as a premise; this file derives it from the silver definition.

    So the silver ratio is one locus playing two roles: a Q_A zero giving a subdominant F-pole (char root ≈ 3.12, not the dominant ≈ 117.4) and the b² = 7/8 point grounding the silver rungs. The algebraic content is the factorisation q⁴ − 6q² + 1 = (q² − 2q − 1)(q² + 2q − 1) — the silver factor and its bar-conjugate.

    Pure algebra from q² = 2q + 1; stated over a generic CommRing per AGENTS.md §7c (no ℝ, no √2 needed). The field form is added only for the literal b² = 7/8 ratio. This grounds — it does not make any c_k ≥ 3 canonical (the Pell–Lucas pattern still breaks at the free rungs; registry §8); no c_k value is claimed here.

    theorem QOU.QBeta.qA_numerator_zero_at_silver {R : Type u_1} [CommRing R] (q : R) (hsilver : q ^ 2 - 2 * q - 1 = 0) :
    2 * q + 1 - q ^ 2 = 0

    The silver locus is the Q_A decay-prefactor zero. The substrate-branch Q_A numerator factor 2q + 1 − q² equals −(q² − 2q − 1), so it vanishes exactly when q satisfies the silver relation q² − 2q − 1 = 0. This is where F = Q_β/[Q_A·cos α_eff] has its pole — the dominant 1/u_substrate characteristic root of the c_k recurrence.

    theorem QOU.QBeta.silver_quartic_factor {R : Type u_1} [CommRing R] (q : R) :
    q ^ 4 - 6 * q ^ 2 + 1 = (q ^ 2 - 2 * q - 1) * (q ^ 2 + 2 * q - 1)

    The defining factorisation q⁴ − 6q² + 1 = (q² − 2q − 1)(q² + 2q − 1): the silver factor q² − 2q − 1 and its bar-conjugate q² + 2q − 1. This is the algebraic content behind the Hoefsmit b² identity below (it is the linear_combination cofactor).

    theorem QOU.QBeta.hoefsmit_bSq_numerator_silver {R : Type u_1} [CommRing R] (q : R) (hsilver : q ^ 2 - 2 * q - 1 = 0) :
    8 * (q ^ 4 + q ^ 2 + 1) = 7 * (q ^ 2 + 1) ^ 2

    Hoefsmit b² numerator identity at the silver locus (division-free, generic CommRing). With b² = (q⁴ + q² + 1)/(q² + 1)² (Hoefsmit), the relation q² − 2q − 1 = 0 forces 8·(q⁴ + q² + 1) = 7·(q² + 1)² — i.e. b² = 7/8. The linear_combination certificate is the cofactor (q² + 2q − 1) of silver_quartic_factor.

    theorem QOU.QBeta.hoefsmit_bSq_eq_at_silver {K : Type u_2} [Field K] [CharZero K] (q : K) (hsilver : q ^ 2 - 2 * q - 1 = 0) (hden : q ^ 2 + 1 ≠ 0) :
    (q ^ 4 + q ^ 2 + 1) / (q ^ 2 + 1) ^ 2 = 7 / 8

    Hoefsmit b² = 7/8 at the silver locus (field form). Dividing the division-free identity hoefsmit_bSq_numerator_silver by the nonzero (q²+1)² gives the literal Hoefsmit ratio used by the silver-rung values. The denominator nonvanishing holds at q = 1+√2 (there q²+1 = 2+2√2 ≠ 0).
