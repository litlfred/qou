    def QOU.QBeta.HabiroEvaluationTrichotomy.qPoch {R : Type u_1} [CommRing R] (q : R) :
    ℕ → R

    The q-Pochhammer symbol (q;q)ₙ = ∏_{k=1}^{n} (1 - q^k).

    Generic in the base ring: this is pure CommRing data, with no ordering and no archimedean input, per the §7c base-ring convention.

      theorem QOU.QBeta.HabiroEvaluationTrichotomy.qPoch_reflection {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (n : ℕ) :
      (q ^ ∑ k ∈ Finset.range n, (k + 1)) * qPoch q⁻¹ n = (-1) ^ n * qPoch q n

      The reflection identity. (q⁻¹;q⁻¹)ₙ = (-1)^n · q^(-(n(n+1)/2)) · (q;q)ₙ, written multiplicatively as

      q ^ (∑ k in range n, (k+1)) * (q⁻¹;q⁻¹)ₙ = (-1)^n * (q;q)ₙ

      to stay inside the ring (no negative exponents). The exponent ∑_{k<n} (k+1) = n(n+1)/2 is the blow-up factor: for |q| > 1 it is exactly what separates the divergent branch from the convergent one.

      Generic — any field, q ≠ 0. No ordering, no ℝ.

      Roots of unity: the evaluation exists #

      source
      theorem QOU.QBeta.HabiroEvaluationTrichotomy.qPoch_eq_zero_of_pow_eq_one {R : Type u_1} [CommRing R] (q : R) (N : ℕ) (hN : 1 ≤ N) (hq : q ^ N = 1) (n : ℕ) :
      N ≤ n → qPoch q n = 0

      At a root of unity of order N ≥ 1, (q;q)ₙ vanishes for every n ≥ N: the k = N factor is 1 - q^N = 0. Generic (CommRing).

      This is the positive half of the trichotomy — it is exactly why the cyclotomic completion is built at roots of unity, and why a Habiro element has honest values there.

      theorem QOU.QBeta.HabiroEvaluationTrichotomy.qPoch_abs_le_succ_of_one_lt {q : ℝ} {n : ℕ} (hn : 2 ≤ q ^ (n + 1)) :
      |qPoch q n| ≤ |qPoch q (n + 1)|

      The modulus is eventually non-decreasing. Once q ^ (n+1) ≥ 2 — which for real q > 1 holds from some index on — the step from n to n+1 cannot shrink |(q;q)ₙ|. The q > 1 hypothesis is not needed separately: it is already carried by 2 ≤ q ^ (n+1).

      theorem QOU.QBeta.HabiroEvaluationTrichotomy.qPoch_not_tendsto_zero_of_one_lt {q : ℝ} (hq : 1 < q) (N : ℕ) (hN : ∀ (n : ℕ), N ≤ n → 2 ≤ q ^ (n + 1)) :
      ¬Filter.Tendsto (fun (n : ℕ) => qPoch q n) Filter.atTop (nhds 0)

      No archimedean evaluation at real q > 1.

      A continuous evaluation of the cyclotomic completion at a point q requires (q;q)ₙ → 0, since (q;q)ₙ → 0 holds in the completion itself. For real q > 1 that limit fails: the moduli are eventually non-decreasing and bounded below by the (nonzero) modulus at the index where q ^ (n+1) ≥ 2 first holds.

      Stated with that index as an explicit hypothesis N, so the proof is elementary and the statement is exactly what is used downstream.
