    1. The per-block decomposition is a consequence of LINEARITY #

    source
    theorem QOU.QBeta.ECatBlockDecomposition.blockDecomposition_of_linear {ι : Type u_1} {R : Type u_2} {V : Type u_3} [Fintype ι] [CommRing R] [AddCommGroup V] [Module R V] (I : V →ₗ[R] R) (y : ι → R) (f : ι → V) :
    I (∑ i : ι, y i • f i) = ∑ i : ι, y i * I (f i)

    The block decomposition of E_cat, derived rather than assumed.

    I is the integral, presented as an arbitrary linear functional; y are the Wedderburn block weights y_λ; f λ is the per-block integrand χ_λ[(Δ(γ(s)) ⊗ Δ(γ(t))) ⋆_q ‖…‖]. The conclusion

    I (Σ_λ y_λ • f λ)  =  Σ_λ y_λ * I (f λ)

    says the total energy is the y-weighted sum of per-block integrals, so the per-block vector t_λ := y_λ * I (f λ) is a REFINEMENT of E_cat and not a different quantity.

    Stated over a generic commutative ring with I an arbitrary linear map: the decomposition is a fact about linearity, so it cannot be an artefact of the measure, of the q-deformation, or of the particular blocks.

    source
    theorem QOU.QBeta.ECatBlockDecomposition.total_eq_sum_blockCosts {ι : Type u_1} {R : Type u_2} {V : Type u_3} [Fintype ι] [CommRing R] [AddCommGroup V] [Module R V] (I : V →ₗ[R] R) (y : ι → R) (f : ι → V) :
    I (∑ i : ι, y i • f i) = ∑ i : ι, (fun (j : ι) => y j * I (f j)) i

    The total is exactly the sum of the per-block costs: with t_λ := y_λ * I (f λ), we get E_cat = Σ_λ t_λ. This is the Lean form of the assembly identity tr_M = Σ_λ t_λ that computations/nucleus_sdp_assembly.py asserts numerically, and it makes the per-block vector and the scalar total two views of one object.

    source
    theorem QOU.QBeta.ECatBlockDecomposition.blockVector_strictly_finer_than_total :
    ∃ (t : Fin 2 → ℤ) (t' : Fin 2 → ℤ), ∑ i : Fin 2, t i = ∑ i : Fin 2, t' i ∧ t ≠ t'

    A per-block VECTOR is strictly finer than its total. Two block decompositions can have the same total and different components, so a cost built from the vector can separate cases the scalar cannot.

    This is the precise sense in which decomposing E_cat over partitions buys something: it is not merely a re-writing. Exhibited concretely rather than asserted.

    2. The same statement at Mathlib's integral, so it is about the real #

    double integral and not only about an abstraction

    source
    theorem QOU.QBeta.ECatBlockDecomposition.integral_blockDecomposition {ι : Type u_1} {α : Type u_2} [Fintype ι] [MeasurableSpace α] (μ : MeasureTheory.Measure α) (y : ι → ℝ) (f : ι → α → ℝ) (hf : ∀ (i : ι), MeasureTheory.Integrable (f i) μ) :
    ∫ (x : α), ∑ i : ι, y i * f i x ∂μ = ∑ i : ι, y i * ∫ (x : α), f i x ∂μ

    The block decomposition at the Bochner integral.

    The integrand is a finite y-weighted sum of per-block integrands, each integrable; the integral of the sum is the weighted sum of the integrals. With α := S¹ × S¹ ∖ diag and μ the product measure this is exactly the E_cat decomposition, with no hypothesis beyond integrability of each block's integrand.

    Integrability is a genuine hypothesis and is stated, not assumed away: the O'Hara integrand is regularised precisely so that it is integrable across the diagonal, and on the flat-torus geodesic realisation it is identically zero there (qbeta_bring_ohara_bridge_probe, check [C2]).

        theorem QOU.QBeta.ECatBlockDecomposition.pairSum_not_perm_invariant :
        ∃ (K : ℕ → ℕ → ℕ → ℕ) (l : List ℕ) (l' : List ℕ), l.Perm l' ∧ pairSum K l ≠ pairSum K l'

        A separation-dependent pair sum is NOT permutation-invariant.

        This is the escape, and it is the whole reason a double integral can do what a letter sum provably cannot. LetterSumBlindness.letterSum_perm_invariant shows any Σ_letters f(letter) is constant on the permutation orbit; here a concrete kernel and a concrete transposition give different values.

        The mechanism is worth stating because it is the design constraint on any replacement cost: permuting the letters does not change the multiset, but it DOES change which pairs sit at which separation, so a kernel that reads the separation sees the reordering. A pair kernel that ignored d and was symmetric in its two letters would be permutation-invariant again and would buy nothing.
