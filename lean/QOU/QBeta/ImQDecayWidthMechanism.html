    theorem QOU.QBeta.hecke_second_eigenvalue_reality_locus {y s : ℝ} (hs : s ≠ 0) :
    y / s = 0 ↔ y = 0

    The second Hecke eigenvalue adds no reality locus. For q = x + iy with |q|² = s ≠ 0, the generator's spectrum is {q, −q⁻¹} and Im(−q⁻¹) = y/s. That vanishes exactly where y does — so requiring the whole spectrum real is requiring Im q = 0, no more and no less.

    This is candidate (iii)'s unitarity premise, and it is correct.

    theorem QOU.QBeta.hecke_spectrum_real_iff {x y : ℝ} (hq : x ^ 2 + y ^ 2 ≠ 0) :
    y = 0 ∧ y / (x ^ 2 + y ^ 2) = 0 ↔ y = 0

    The Hecke spectrum is real iff Im q = 0. Both eigenvalue imaginary parts — y and y/s — vanish together, by the lemma above.

    theorem QOU.QBeta.imaginary_width_zero_of_real_spectrum {imE : ℝ} (h : imE = 0) :
    -2 * imE = 0

    Mechanism B on a real spectrum gives exactly zero. With E = E₀ − iΓ/2 the width is Γ = −2·Im E, so a real spectrum forces Γ = 0 — not approximately, identically.

    theorem QOU.QBeta.imaginary_mechanism_does_produce_a_width {imE : ℝ} (h : imE ≠ 0) :
    -2 * imE ≠ 0

    Mechanism B is not broken — it simply is not what the framework uses. Included so the scope of this file is legible from the Lean alone: when Im E ≠ 0 mechanism B produces a perfectly good width. Nothing here excludes Im q from encoding one.

    theorem QOU.QBeta.two_width_mechanisms_are_independent {hbar Q imE : ℝ} (hh : hbar ≠ 0) (hQ : Q ≠ 0) (hreal : imE = 0) :
    hbar / Q ≠ 0 ∧ -2 * imE = 0

    The finding. On a real spectrum the two mechanisms disagree completely: A is nonzero, B is identically zero. So they are independent, and the framework's decay width — obtained at real q₀ — is a reciprocal real energy rather than an imaginary one.

    Scope (a): this relocates candidate (iii)'s burden onto exhibiting a Γ that mechanism A fails to produce; it does not exclude Im q.
