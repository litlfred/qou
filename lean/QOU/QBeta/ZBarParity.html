    §1. Convention C (z_C = √q/(1+q)) — EXCISED, kept as the record #

    🛑 This section is convention C, which the owner excised (2026-08-09, re-affirmed 2026-08-15 and 2026-08-26). The canonical Markov parameter is convention D, z_D = q³/(q²+1) — see §1b. The C results below are correct as statements about z_C and are retained because registry row KC13 and the ea56 class-Z2 exclusion cite them, and because MarkovZFullBarCondition / LadderPhaseMirrorCovariance consume z_bar_invariant_field as a proof term. They are not statements about the canonical parameter, and §1b shows the key one does not transfer.

    The defining constants now carry the convention in their names, so no reader can pick up an unlabelled z from this file and assume it is canonical.

            §2. The ladder variable's parity: ℏ_q bar-odd (twist −q), ℏ_q² bar-even (twist q²) #

            ℏ_q = 1 − q⁻¹ is bar-ODD up to the monomial twist −q. In the (q, qi) encoding (q·qi = 1, ℏ = 1 − qi, bar(ℏ) = 1 − q): bar(ℏ) = −q·ℏ.

                §5. Parity/shadow bookkeeping for the T3-2 tension (investigation infra) #

                The T3-2 tension (ledger §4-ter): "a₁ exactly bar-odd" and "a₁ q=1-regular with nonzero shadow" are jointly impossible. The two lemmas below are the generic, reading-agnostic certificates of the impossibility direction: a bar-compatible ring homomorphism (e.g. the q=1 evaluation) annihilates bar-odd elements, hence any evaluation of a bar-decomposed a = e + o factors through the bar-even part. Which horn resolves the tension for the kernel coefficient a₁ = −c₃ (odd-part reading vs q=1-singular reading vs symbol overloading between distinct a₁ objects) is an open investigation item — see the 2026-07-07 investigation audit.

                §6. The 4₁ cyclotomic (Habiro) basis is bar-invariant #

                The 4₁ colored Jones has the cyclotomic expansion J_N = Σ_k ω_k with ω_k = ∏_{j=1}^k (x + x⁻¹ − q^j − q^{−j}), x = q^N, and coefficients C_k ≡ 1 (Habiro; the certificate's Habiro–Le summand, termwise). Each factor — in the pair encoding (q, qi, x, xi) — is literally symmetric under the bar swap (q, x) ↦ (qi, xi), so every ω_k is exactly bar-invariant: the cyclotomic basis diagonalizes the bar involution for 4₁ (probe qbeta_b1_fourone_cyclotomic_rebasing_probe.py, B2-K2).

                  §7. The one-sided Habiro basis has index-alternating bar-parity #

                  (q;q)_k = ∏_{j=1}^k (1 − q^j) satisfies (q⁻¹;q⁻¹)_k · q^{1+2+…+k} = (−1)^k · (q;q)_k: bar-EVEN for even k, bar-ODD for odd k, up to a monomial twist. Hence a bar-even element expanded in the one-sided Habiro basis sources bar-odd content through the odd-index basis vectors — the parity re-mix lives in the basis (probe qbeta_b3_ladder_basis_parity_probe.py, B3-K2; the exponent ∑_{j<k}(j+1) = k(k+1)/2 is the Gauss sum).

                    §8. The u-side ladder variable: u^k carries a degree-dependent twist #

                    The observable ladder lives in u = b·ℏ_q², which is bar-EVEN up to the monomial twist q² (hbar_sq_bar_even_twist: bar(u) = q²·u). Hence the u-monomial u^k transforms with the degree-dependent twist q^{2k} — a scaling, not the KC16 index-inversion. This is the structural obstruction found by probe qbeta_b3u_uside_transfer_probe.py (B3-U1): the (u;u)_m Habiro basis carries no clean monomial bar-twist, so the fibre index-parity (KC16) does not descend to a clean per-rung parity of the c_k; the odd channel enters through the archimedean evaluation map, not a fibre basis change.

                    §9. The genuinely bar-even ladder variable ũ = q·u (twist 1) #

                    §8 shows the corpus ladder variable u = b·ℏ_q² is not bar-even: bar(u) = q²·u (twist q², hbar_sq_bar_even_twist). So u was mis-normalized for the bar decomposition — an exact re-expansion in u scrambles the per-rung parity (the B3-U obstruction, registry KC17).

                    The fix (measured exactly, ai81/08ds, 2026-07-03, 9fnm audit §"Follow-up"): the genuinely bar-EVEN ladder variable is ũ = q·u, i.e. ũ = q·b·ℏ_q². In that variable the bar-even part E of log R is an exact over-determined ũ-ladder (margin 9 through s¹⁷, ORD-17 probe 08ds). This lemma is the Lean certificate of bar(ũ) = ũ, grounding that corpus-wide re-normalization; it derives no c_k value, changes no registry tier, wires nothing (flip-flop guard §8).

                    Encoding: u = b·(1 − qi)² (ℏ_q = 1 − q⁻¹ = 1 − qi); the bar image swaps qi ↔ q, so bar(u) = b·(1 − q)² and bar(ũ) = bar(q)·bar(u) = qi·b·(1 − q)². Bar-evenness bar(ũ) = ũ is the cross-multiplied identity below; b is a bar-fixed (Hoefsmit) constant, carried inert.

                    source
