    phiBProd's zeros are isolated (G5 specialization: discharges hΦ₂_iso) #

    Discharges the hΦ₂_iso input of FaddeevStripGrowthUniqueness.faddeevPhi_proportional_of_stripGrowth for the concrete substrate phiBProd: ∀ z, ∀ᶠ w in 𝓝[≠] z, phiBProd b w ≠ 0.

    The chain, all on the branch Im b² > 0:

    1. Non-vanishing witness at z = 0. Each numFactor b 0 k / denFactor b 0 k is nonzero: the exponent's real part is < 0 (Re(πi b²(2k+1)) = −π·Im(b²)·(2k+1) for the numerator; the modular-dual sign for the denominator), so ‖exp‖ < 1 = ‖−1‖, hence 1 + exp ≠ 0. By tprod_{num,den}Factor_ne_zero (PR #4304), the two products are nonzero at 0.
    2. Products have order ≠ ⊤. Each product is entire (analyticOnNhd_{num,den}_tprod, #4296) and not identically zero (step 1), so by the identity theorem it is not locally zero at any z; meromorphicOrderAt_ne_top_iff_eventually_ne_zero gives order ≠ ⊤ everywhere.
    3. phiBProd order ≠ ⊤ via phiBProd_order_ne_top_of_products (#4225).
    4. Zeros isolated via meromorphicOrderAt_ne_top_iff_eventually_ne_zero again, now for phiBProd.

    Verified lean-direct against the pinned Mathlib cones + the merged phiBProd chain. Sorry-free.
