    §1. The shifted phase and its bar defect #

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.shiftedPhase_bar_defect {R : Type u_1} [CommRing R] (z zbar hk hkbar t : R) (hfull : zbar = z - hk) (hh : hkbar = -hk) :
    (zbar + t * hkbar - 1) * hkbar + (z + t * hk - 1) * hk = (2 * t + 1) * hk ^ 2

    The bar defect of the shifted eigenphase is (2t + 1)·h².

    With the parameter shifted to z + t·h (t bar-even), the doubled phase is 2α_t = (z + t·h − 1)·h, whose bar-image is (bar z + t·bar h − 1)·bar h. Feeding the full-bar condition bar z = z − h and bar h = −h:

    bar(2α_t) + 2α_t = (2t + 1)·h².

    Two things about the right-hand side carry the content. It does not mention z — so the defect is a property of the whole full-bar family, and no choice of parameter within that family can change it. And it is not identically zero — so bar-oddness is a genuine constraint on t.

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.naivePhase_not_barOdd {F : Type u_2} [Field F] (z zbar hk hkbar : F) (hfull : zbar = z - hk) (hh : hkbar = -hk) (hk0 : hk ≠ 0) :
    (zbar - 1) * hkbar + (z - 1) * hk ≠ 0

    The bare substitution is never bar-odd. At t = 0 — that is, using z_D itself in the C-frame formula — the defect is h², which is nonzero away from the classical point. Together with QOU.QBeta.decayLadder_zC_threeRow_ne_zero (which blocks the same move from the Temperley–Lieb side) this is why the convention change is a re-derivation and not a z-swap.

    §2. Uniqueness of the bar-odd shift #

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.barOdd_shift_unique {F : Type u_2} [Field F] (z zbar hk hkbar t : F) (hfull : zbar = z - hk) (hh : hkbar = -hk) (hk0 : hk ≠ 0) (h2 : 2 ≠ 0) :
    (zbar + t * hkbar - 1) * hkbar + (z + t * hk - 1) * hk = 0 ↔ t = -(1 / 2)

    Bar-oddness holds iff t = −1/2. The shift that restores the parity every downstream consumer assumes is unique, and it is a pure number: no dependence on q, on the anchor, or on which full-bar parameter one started from. This is the pruning step — the hypothesis class of D-frame eigenphases α_t collapses to a single member before any number is computed.

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.barOdd_parameter_eq {F : Type u_2} [Field F] (z zbar hk hkbar : F) (hfull : zbar = z - hk) (hh : hkbar = -hk) (h2 : 2 ≠ 0) :
    (zbar + -(1 / 2) * hkbar - 1) * hkbar + (z + -(1 / 2) * hk - 1) * hk = 0

    The unique bar-odd parameter is z − h/2. Restating barOdd_shift_unique in terms of the parameter rather than the shift: the surviving member of the family is the bar-EVEN projection of z.

    §2b. General shifts: the bar-even part cancels, the bar-odd part is forced #

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.generalShift_bar_defect {R : Type u_1} [CommRing R] (z zbar hk hkbar ce co cebar cobar : R) (hfull : zbar = z - hk) (hh : hkbar = -hk) (hce : cebar = ce) (hco : cobar = -co) :
    (zbar + cebar + cobar - 1) * hkbar + (z + ce + co - 1) * hk = hk * (hk + 2 * co)

    The defect of a general shift depends only on the shift's bar-ODD part.

    Split the shift as c = ce + co with bar ce = ce and bar co = −co. Then

    bar(2α_c) + 2α_c = h·(h + 2·co),

    with ce absent — and z absent too. So the bar-even half of the shift is invisible to the involution and parity constrains only co.

    This is the statement that makes barOdd_shift_unique a narrower result than it looks: within h-proportional shifts the answer is a single t, but among all shifts the answer is an affine family.

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.barOdd_forces_oddPart {F : Type u_2} [Field F] (z zbar hk hkbar ce co cebar cobar : F) (hfull : zbar = z - hk) (hh : hkbar = -hk) (hce : cebar = ce) (hco : cobar = -co) (hk0 : hk ≠ 0) (h2 : 2 ≠ 0) :
    (zbar + cebar + cobar - 1) * hkbar + (z + ce + co - 1) * hk = 0 ↔ co = -(hk / 2)

    Bar-oddness forces the shift's bar-odd part to be −h/2, and nothing else. The forward direction is the pruning; the reverse direction shows it holds for EVERY bar-even ce, which is the non-uniqueness.

    §3. The convention-D parameter's bar-even projection, in closed form #

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.zD_sub_halfH_eq {F : Type u_2} [Field F] (q : F) (hq : q ≠ 0) (hq2 : q ^ 2 + 1 ≠ 0) (h2 : 2 ≠ 0) :
    q ^ 3 / (q ^ 2 + 1) - (q - q⁻¹) / 2 = (q ^ 4 + 1) / (2 * q * (q ^ 2 + 1))

    z_D − h/2 = (q⁴ + 1) / (2q(q² + 1)). The closed form of the unique bar-odd parameter under convention D. Stated over a field with the two nonvanishing hypotheses made explicit.

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.zD_even_barEven {R : Type u_1} [CommRing R] (q qi : R) (h : q * qi = 1) :
    (qi ^ 4 + 1) * (2 * q * (q ^ 2 + 1)) = (q ^ 4 + 1) * (2 * qi * (qi ^ 2 + 1))

    z_D − h/2 is bar-EVEN, division-free: with q⁻¹ carried as qi (q·qi = 1), the cross-multiplied form of (qi⁴+1)/(2·qi·(qi²+1)) = (q⁴+1)/(2·q·(q²+1)).

    This is what makes the shifted parameter a legitimate eigenphase source: a bar-even parameter yields a bar-odd phase by QOU.QBeta.eigenphase_barOdd_of_barEven, which is exactly the property the C frame had for free and the naive D substitution loses.

    §4. The bar-odd phase in terms of the Wedderburn weights #

    source
    theorem QOU.QBeta.DFrameEigenphaseBarOdd.barOddPhase_eq_moment_form {R : Type u_1} [CommRing R] (z hk twoQ Xi : R) (hmom : 2 * z - hk = twoQ * Xi) :
    (2 * z - hk - 2) * hk = (twoQ * Xi - 2) * hk

    The unique bar-odd eigenphase is ([2]_q·Ξ − 2)·h/2.

    QOU.QBeta.loopMean_eq_twoQ_mul_moment gives 2z − h = [2]_q·Ξ in ANY convention, with Ξ = Σ_λ χ^λ(τ)·y_λ the transposition moment of the Wedderburn weights (n-independent, and bar-even under D because every convention-D weight is — markovWeightsD_y21_barEven).

    Combining with §2: the bar-even half of the Markov parameter is [2]_q·Ξ/2 and its bar-odd half is the universal h/2. So the bar-odd projection of the eigenphase is determined by the weights, even though — per no_weight_function_gives_phase — the full phase is not.

    Stated division-free in the doubled phase: 2·α^odd = (2z − h − 2)·h/2 · 2, i.e. (2z − h − 2)·h, so no inverse of 2 is needed and the identity holds over any CommRing.

    This is the sense in which the D-frame eigenphase is RE-DERIVED rather than substituted: its bar-even multiplier comes from the D weights, and its bar-odd factor is the h those weights cannot supply.
