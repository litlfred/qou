    The Ohtsuki κ-tower cannot be the Q_β c_k ladder — the sign invariant #

    The "prize" question of the S-channel saddle-point tranche: is the Q_β truncation ladder c_k the figure-eight (4₁) Chern–Simons perturbative (Ohtsuki) series κ_n? The probe computations/qbeta/qbeta_ohtsuki_kappa_vs_ck_direct_comparison.py answers no, with four independent obstructions. This file formalizes the crispest of them — the sign / even-rung positivity invariant — sorry-free.

    The invariant. The DERIVED Ohtsuki coefficients of 4₁ are all positive closed forms (from the Kashaev sum log J_N, PSLQ-exact, corpus #3606/#3628):

    κ₁ = 11√3π/108, κ₂ = 2π²/27, κ₃ = 1081√3π³/21870, κ₄ = 98π⁴/729 (all > 0).

    The Q_β ladder coefficients are negative: c₂ = −1 (Lean-proved Taylor-exact) and the q₀-extract c₃ ≈ −2.07 < 0. A positive number is never a negative number, so c_k ≠ κ_n for every pair — no rescaling of the ladder variable u can align them either, because the obstruction is the even-power sign, not a magnitude.

    Why this is not superficial. The natural "defence" of an identification is a reparametrization u ↦ λ·u of the ladder variable. even_rung_positive_ne_neg shows a single even rung already blocks it: κ₂·λ² ≥ 0 (κ₂ > 0, λ² ≥ 0) can never equal c₃ < 0, for ANY real λ. So no real rescaling maps the all-positive κ-tower onto the negative c_k pair (no_real_rescaling_aligns). This is the Lean root of obstruction (B1)/(B2) of the probe's honest negative.

    This is a genuine scope-(a)/(b) exclusion of the raw identification, NOT a claim that the deeper 4₁-resurgence ↔ Q_β-action bridge is closed: that bridge remains the standing open keystone (corpus 2026-07-12-ohtsuki-higher-rungs-exact.md, 2026-07-18-phib-a1-mis-identified-not-ohtsuki-kappa1.md). The κ_n are topological invariants of the figure-eight; the c_k are the Q_β observable ladder. No c_k is wired; no channel instance is fabricated; u(q₀) stays OPEN.

    Base ring is ℝ (archimedean §7c: Real.sqrt, Real.pi, ordering).

            The sign obstruction #

            source
            theorem QOU.QBeta.OhtsukiKappaVsCkSign.even_rung_positive_ne_neg {κ c : ℝ} (hκ : 0 < κ) (hc : c < 0) (lam : ℝ) :
            κ * lam ^ 2 ≠ c

            Even-rung positivity kills any real rescaling (the core invariant). A positive even Ohtsuki rung κ scaled by ANY real λ gives κ·λ² ≥ 0, so it can never equal a negative Q_β coefficient c < 0. This is why no reparametrization u ↦ λ·u of the ladder variable can turn the all-positive κ-tower into the negative c_k — the even-power sign is reparametrization- invariant.

            source
            theorem QOU.QBeta.OhtsukiKappaVsCkSign.no_real_rescaling_aligns {κ₁' κ₂' c₂ c₃ : ℝ} (hκ₂ : 0 < κ₂') (hc₃ : c₃ < 0) :
            ¬∃ (lam : ℝ), κ₁' * lam = c₂ ∧ κ₂' * lam ^ 2 = c₃

            No real rescaling aligns the tower with the ladder. There is no real λ simultaneously matching an odd rung to c₂ < 0 and the next even rung to c₃ < 0: the even constraint κ₂·λ² = c₃ alone is impossible for κ₂ > 0, c₃ < 0. (The first component is stated for faithfulness to the index-shifted pairing κ₁↔c₂, κ₂↔c₃; the contradiction comes from the second.)

            Concrete: c₂ = −1 ≠ κ₁ (sign). The Lean-proved Q_β Taylor coefficient c₂ = −1 is negative; the derived Ohtsuki κ₁ = 11√3π/108 is positive; they are unequal.
