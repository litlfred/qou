    The vanishing set does not determine the Ocneanu weights #

    WenzlWeightVanishing axiomatises Wenzl (1988) as IsOcneanuWeightSystem Q z r y, whose second field is a weight identity y μ = schurPrincipal r Q μ / Z. A proposed cheaper discharge route (2026-08-16-ocneanu-weight-axiomatisation.md §"Is there a cheaper route?") would replace that field by the vanishing set y μ = 0 ↔ r < μ.colLen 0, on the stated grounds that the vanishing set is all the corpus consumes.

    This file measures the gap between those two hypotheses, so that the trade is made against a proved statement rather than against an impression.

    Results #

    • ocneanuWeight_eq_bot_smul_schurPrincipal — rigidity: the class pins y completely, up to the single scalar y ⊥. Two weight systems agreeing at the empty diagram are equal everywhere.
    • vanishingSet_not_determines_weights — the gap is real: rescaling a genuine weight system at one surviving diagram preserves the vanishing set exactly and destroys the class. So the vanishing-set hypothesis is strictly weaker, and a consumer of weight values is not served by it.

    Neither result discharges Wenzl's theorem, and neither is a step toward discharging it; both are measurements of what a proposed weaker hypothesis would and would not supply. The route's viability is assessed in docs/audits/2026-08-21-wenzl-discharge-tln-route-scoping.md.

    Base ring: generic {R : Type*} [Field R] throughout — no ordering, no ℝ, no archimedean construct (AGENTS.md §7c).

    theorem QOU.QBeta.WenzlWeight.ocneanuWeight_eq_bot_smul_schurPrincipal {R : Type u_1} [Field R] {Q z : R} {r : ℕ} {y : YoungDiagram → R} [hw : IsOcneanuWeightSystem Q z r y] (μ : YoungDiagram) :
    y μ = y ⊥ * schurPrincipal r Q μ

    Rigidity — the class determines y up to the single scalar y ⊥.

    y μ = y ⊥ · s_μ. The normaliser Z of the class is not a free parameter once y ⊥ is known: it is 1 / y ⊥.

    This is what IsOcneanuWeightSystem supplies beyond a vanishing set, and it is the whole of the difference — a weight system carries one scalar's worth of freedom, whereas the vanishing set leaves a nonzero scalar free at every surviving diagram independently (vanishingSet_not_determines_weights).

      theorem QOU.QBeta.WenzlWeight.vanishingSet_not_determines_weights {R : Type u_1} [Field R] {Q : R} (z : R) {r : ℕ} {y : YoungDiagram → R} [hy : IsOcneanuWeightSystem Q z r y] {μ₀ : YoungDiagram} (hμ₀ : μ₀ ≠ ⊥) (hy₀ : y μ₀ ≠ 0) {c : R} (hc0 : c ≠ 0) (hc1 : c ≠ 1) :
      (∀ (μ : YoungDiagram), rescaleAt μ₀ c y μ = 0 ↔ y μ = 0) ∧ ∀ (z' : R), ¬IsOcneanuWeightSystem Q z' r (rescaleAt μ₀ c y)

      The vanishing set does not determine the weights.

      Given any genuine Ocneanu weight system y, and any diagram μ₀ ≠ ⊥ that y does not annihilate, the one-point rescaling rescaleAt μ₀ c y (with c ≠ 0, c ≠ 1):

      • has exactly the same vanishing set as y — so it satisfies every vanishing-set hypothesis that y does; and
      • is not an Ocneanu weight system at (Q, z', r) for any z'.

      Hence replacing weight_eq_schurPrincipal by a vanishing-set field yields a strictly weaker hypothesis. A downstream consumer of weight values — as opposed to the vanishing set alone — is not served by the weaker class.

      The proof is rigidity: rescaleAt μ₀ c y still agrees with y at ⊥ (since μ₀ ≠ ⊥), so if it were a weight system it would have to equal y everywhere by ocneanuWeight_unique_of_bot_eq; but it differs at μ₀ because c ≠ 1 and y μ₀ ≠ 0. Delete ocneanuWeight_eq_bot_smul_schurPrincipal and the argument does not go through: nothing else forces the value at μ₀.

      z is explicit: it appears in the hypothesis but not in the conclusion, so typeclass resolution cannot recover it (the same convention as ocneanuWeight_eq_zero_iff_of_wenzl).

      The gap is inhabited, not merely stated #

      vanishingSet_not_determines_weights carries three side conditions (μ₀ ≠ ⊥, y μ₀ ≠ 0, and a scalar c ∉ {0, 1}) on top of the class. A theorem whose hypotheses are never jointly met proves nothing, so they are met here concretely rather than argued for.
