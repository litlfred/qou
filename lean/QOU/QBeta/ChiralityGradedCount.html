    QOU.QBeta.ChiralityGradedCount — a fully proved, input-independent obstruction: no symmetric scalar recovers a chirality-split count #

    Why this file exists (the transcription problem) #

    FiveTwoDTSpectrumSplit and RouteANewtonPolygonDT prove sharp statements, but each takes hand-transcribed literature data as defs (the GGM eq-(96)/(97) Stokes matrices; the A_{4₁} monomials; the 5₂ boundary slopes). Lean cannot verify a transcription from a PDF, so those results are conditional on the transcription being faithful — the sorry-free ≠ derived boundary. Their inputs are cross-validated (det S± = 1, S⁺ᵀS⁻ = 1, the reciprocal symmetry of the Newton polygon), which is strong evidence, but evidence is not proof.

    This file isolates the part of the argument that needs no input at all. Every theorem below is a statement about arbitrary integers, proved outright. The knot-specific numbers (4, 3) then appear only as an instance, never as a hypothesis of the general result.

    The mathematical content #

    A chirality-split count is an ordered pair (a, b) (the S⁺ and S⁻ constants). The mirror involution τ swaps them. Then:

    • barGrading_faithful_general — the ℤ/2 decomposition into even = a + b (τ-fixed) and odd = a − b (τ-negated) loses no information: 2a = even + odd, 2b = even − odd.
    • symmetric_scalar_cannot_separate — the obstruction. Any symmetric function g : ℤ → ℤ → ℤ takes the same value on (a,b) and on its mirror (b,a). So if a count is genuinely chiral (a ≠ b, equivalently odd ≠ 0), no symmetric scalar reading distinguishes the two chiralities: the scalar is precisely the τ-trivial shadow of the graded object.
    • chiral_iff_odd_ne_zero — "genuinely chiral" and "nonzero bar-odd part" are the same condition.
    • amphichiral_collapse — when a = b (the amphichiral case) the bar-odd part vanishes and the pair degenerates to a single number, which is exactly why a single knot with a = b can never exhibit the obstruction.

    The last point is the methodological payload: it is a proof that testing on an amphichiral knot alone (e.g. 4₁) is structurally incapable of separating "scalar" from "graded" — the cross-knot gate is not a stylistic preference but a logical necessity.

    None of this derives A_ω, and none of it depends on any literature value.

              theorem QOU.QBeta.ChiralityGradedCount.symmetric_scalar_cannot_separate (g : Int → Int → Int) (hsym : ∀ (a b : Int), g a b = g b a) (p : Split) :

              The obstruction, in full generality. Any symmetric integer reading g assigns the same value to a split and to its mirror. Hence for a genuinely chiral split, g cannot depend on the chirality at all: every symmetric scalar is blind to the −1 eigenspace, which for a chiral count is nonzero.

              theorem QOU.QBeta.ChiralityGradedCount.symmetric_scalar_loses_chirality (g : Int → Int → Int) (hsym : ∀ (a b : Int), g a b = g b a) (p : Split) (hchi : IsChiral p) :

              theorem QOU.QBeta.ChiralityGradedCount.amphichiral_cannot_witness_obstruction (f : Int → Int → Int) (p : Split) (h : p.fst = p.snd) :
              f p.fst p.snd = f (mirror p).fst (mirror p).snd

              A single amphichiral knot cannot exhibit the obstruction. If the split is amphichiral, it equals its own mirror, so every reading — symmetric or not — agrees on it and on its mirror. The cross-knot (chiral) test is therefore a logical necessity, not a methodological preference.

              The knot instance — literature values enter ONLY here #

              The 5₂ DT constants (S⁺, S⁻) = (4, 3) (GGM eq 96/97, transcribed in FiveTwoDTSpectrumSplit) and the amphichiral 4₁ value (3, 3). Everything above is independent of these; they are supplied as an instance to show the general theorems are non-vacuous and correctly aimed.
