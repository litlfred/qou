    theorem QOU.QBeta.greedy_rung_exact {R : Type u_1} [Field R] (Qtarget Qprev x : R) (hQ : Qprev ≠ 0) (hx : x ≠ 0) :
    Qprev * (1 + (Qtarget / Qprev - 1) / x * x) = Qtarget

    The extracted rung reproduces the target exactly.

    rung is the coefficient the producer extracts at scale x (there x = uᵏ): it is defined as the relative shortfall divided by x. Applying it to Qprev therefore lands on Qtarget identically, for every nonzero Qprev and x.

    This is the algebraic content of the runtime line c_4: residual below compute precision (0.00e+00).

    theorem QOU.QBeta.greedy_next_residual_zero {R : Type u_1} [Field R] (Qtarget Qprev x : R) (hQ : Qprev ≠ 0) (hx : x ≠ 0) (hT : Qtarget ≠ 0) :
    Qtarget / (Qprev * (1 + (Qtarget / Qprev - 1) / x * x)) - 1 = 0

    The residual after the extracted rung is exactly zero.

    Consequently the producer's abs(ratio_m1) < EPS_RESIDUAL guard fires at the very next k, whatever EPS_RESIDUAL is — the ladder stops after one extracted rung, not because it converged but because it was solved.

    theorem QOU.QBeta.greedy_later_rungs_vanish {R : Type u_1} [Field R] (Qtarget Qprev x y : R) (hQ : Qprev ≠ 0) (hx : x ≠ 0) (hT : Qtarget ≠ 0) :
    (Qtarget / (Qprev * (1 + (Qtarget / Qprev - 1) / x * x)) - 1) / y = 0

    Any further extracted rung is zero.

    Whatever scale y a later rung is extracted at, its coefficient is the residual over y, and the residual is zero — so every rung beyond the first extracted one vanishes identically. c_4 … c_7 carry no information; they are not small, they are 0.

    theorem QOU.QBeta.exists_rung_hitting_target {R : Type u_1} [Field R] (Qtarget Qbase x : R) (hQ : Qbase ≠ 0) (hx : x ≠ 0) :
    ∃ (c : R), Qbase * (1 + c * x) = Qtarget

    The one-rung model is an exact interpolant, not an approximation.

    Stated without reference to the extraction: for any Qbase and any nonzero scale, there is a coefficient making the model hit the target exactly. So "the ladder reproduces CODATA" is a property of having one free coefficient, carrying no information about the model that coefficient multiplies.
