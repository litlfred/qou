    α_D is bar-MIXED — the obstruction to porting the C bar-split to D (qou-qb8g / qou-cds1) #

    Convention C pins the c₃ bar-even channel because the C rung phase α_C = (z_C − 1)·h/2 is pure bar-odd (α_C(1/q) = −α_C(q), already proved sorry-free as QOU.Interactions.eigenphase_bar_involution, since z_C is bar-even). This file supplies the contrasting D fact: the convention-D rung phase α_D = (z_D − 1)·h/2, with the sqrt-free canonical z_D = q³/(q²+1), is bar-MIXED — its bar-even part is nonzero — because z_D is not bar-homogeneous. So the pure-odd-phase mechanism that pinned the C split has no D analog, which is the exact structural obstruction recorded in the 2026-08-29 convention-D front audit (bean qou-qb8g).

    h = q − q⁻¹ is bar-odd; the bar involution is q ↦ q⁻¹. Archimedean by the ordering/positivity used for nonvanishing, so ℝ per AGENTS.md §7c.

    Verified symbolically (sympy) before formalising: 2α_D(1/q) + 2α_D(q) = (q²−1)²/q², nonzero for q ∉ {0, ±1}.
