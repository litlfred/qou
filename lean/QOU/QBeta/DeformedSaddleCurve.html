    def QOU.QBeta.DeformedSaddleCurve.curve {R : Type u_1} [CommRing R] (x y : R) :
    R

    The deformed 4₁ saddle curve x·y² + (x²−x−1)·y + 1 (as an element of R, vanishing exactly on the curve). Re-derived from the state-integral saddle equation; reduces to y² − y + 1 at x = 1.

      theorem QOU.QBeta.DeformedSaddleCurve.curve_root_product {R : Type u_1} [CommRing R] (x y₁ y₂ : R) :
      (y₁ - y₂) * (x * (y₁ * y₂) - 1) = y₂ * curve x y₁ - y₁ * curve x y₂

      Vieta, product form: two on-curve points at the same x satisfy (y₁ − y₂)·(x·y₁·y₂ − 1) = 0; in particular distinct saddles (with y₁ − y₂ a nonzerodivisor) force x·y₁·y₂ = 1. Stated divisor-free so it holds over any commutative ring.

      theorem QOU.QBeta.DeformedSaddleCurve.saddle_separation {R : Type u_1} [CommRing R] (x y₁ y₂ : R) (hs : x * (y₁ + y₂) = 1 + x - x ^ 2) (hp : x * (y₁ * y₂) = 1) :
      x ^ 2 * (y₁ - y₂) ^ 2 = (x ^ 2 - 3 * x + 1) * (x ^ 2 + x + 1)

      Saddle separation: under the Vieta relations of two on-curve saddles, x²·(y₁−y₂)² = (x²−3x+1)(x²+x+1) — the squared saddle separation IS the (119) discriminant product, so the branch locus of the Borel-singularity datum ι̃ ∝ V(σ₁) − V(σ₂) is exactly the (119) zero set. This is the algebraic core of the substrate-meridian-genericity argument.
