    QOU.QBeta.AfreeThetaConstraint — the one falsifiable statement the channel carries, #

    and the shape of candidate that cannot be tested against it

    ThetaRealityBound showed that the T4 checks are worth less than they read: the diagonal crossing is an identity in A, and reality is a one-sided bound. Read together with the circularity note that leaves the channel

    S_K = A · κ · (ln²q₀ − ϑ_K²)

    looking contentless — two anchor equations in three unknowns (A, ϑ₁, ϑ₂).

    It is not contentless. Underdetermined is not contentless. This file proves the two facts that matter for the search:

    • afree_invariant — eliminating A between the two anchors leaves (ln²q₀ − ϑ₁²) · S₂ = (ln²q₀ − ϑ₂²) · S₁, a relation containing no A and no κ. Any route supplying both ϑ values is testable against it with nothing inherited from the A-conditioned corpus values.
    • A_determined_of_theta — a route that lands on that relation determines A = S/(κ(ln²q₀ − ϑ²)), rather than importing it from the literature.

    and then the negative design result:

    • ratio_attained — for every target ratio y > 1 there is an explicit, admissible A realising ϑ₂² = y · ϑ₁², with ϑ₁² > 0. Hence a route that supplies only the ratio of the two ϑ is unfalsifiable: it cannot fail, it can only name an A. Only a route supplying both ϑ values absolutely over-determines the system and can produce a failing residual.

    The counting behind the last point: two equations, three unknowns; one extra scalar closes the system exactly (no residual), two over-determine it by one.

    Nothing here derives A_ω or proposes a value of ϑ; these are structural facts about what the channel can and cannot be asked.

    theorem QOU.QBeta.AfreeThetaConstraint.A_determined_of_theta {A κ lnq S : ℝ} (hA : A ≠ 0) (hκ : κ ≠ 0) (h : lnq ^ 2 - ThetaRealityBound.thetaSq A κ lnq S ≠ 0) :

    theorem QOU.QBeta.AfreeThetaConstraint.ratio_attained {κ lnq S₁ S₂ y : ℝ} (hκ : 0 < κ) (hlnq : 0 < lnq ^ 2) (hS₁ : 0 < S₁) (hS₂ : S₂ < 0) (hy : 1 < y) :
    ∃ (A : ℝ), 0 < A ∧ 0 < ThetaRealityBound.thetaSq A κ lnq S₁ ∧ ThetaRealityBound.thetaSq A κ lnq S₂ = y * ThetaRealityBound.thetaSq A κ lnq S₁

    Every ratio is attainable — the unfalsifiability of ratio-shaped candidates.

    Given a positive leak S₁ > 0, a negative leak S₂ < 0, and any target ratio y > 1, the explicit value

    A = (y·S₁ − S₂) / (κ · ln²q₀ · (y − 1))

    is positive and satisfies ϑ₂² = y · ϑ₁² with ϑ₁² > 0 — i.e. it is an admissible point of the family, with both ϑ real.

    Consequence: a route supplying only the ratio ϑ₂/ϑ₁ can never be refuted by the channel. Whatever ratio it produces, some A realises it exactly, with zero residual. Such a route does not test A_ω; it merely renames it. A genuine test requires both ϑ absolutely.

    theorem QOU.QBeta.AfreeThetaConstraint.exists_angle_assignment {n : ℕ} (S : Fin n → ℝ) (κ lnq A : ℝ) (hadm : ∀ (i : Fin n), S i / (A * κ) ≤ lnq ^ 2) :
    ∃ (θ : Fin n → ℝ), ∀ (i : Fin n), θ i ^ 2 = ThetaRealityBound.thetaSq A κ lnq (S i)

    Adding anchors never helps: the system is underdetermined by exactly one at EVERY anchor count.

    Each new anchor contributes one equation S_i = A·κ·(ln²q₀ − ϑ_i²) and one new unknown ϑ_i. So n anchors give n equations in n + 1 unknowns (A together with the n angles) — a deficit of one, independent of n.

    This states the consequence constructively: for every admissible A there is a complete angle assignment solving all n equations simultaneously. A is therefore never pinned, no matter how many anchors are collected. The underdetermination is STRUCTURAL, not a shortage of data.

    The only escape is an anchor whose ϑ is fixed independently — an equation carrying no new unknown. The corpus's one candidate, the electron/trefoil 3₁ with Vol = 0, is closed on its own terms: a torus knot's Kashaev invariant grows polynomially rather than exponentially, so it has no Stokes constant to supply an S at all.

    theorem QOU.QBeta.AfreeThetaConstraint.admissible_of_le {n : ℕ} {S : Fin n → ℝ} {κ lnq A : ℝ} (hκ : 0 < κ) (hA : 0 < A) (h : ∀ (i : Fin n), S i ≤ A * κ * lnq ^ 2) (i : Fin n) :
    S i / (A * κ) ≤ lnq ^ 2

    The admissibility hypothesis holds for every sufficiently large A, so the family of solutions above is a genuine continuum rather than an isolated point: raising A only ever makes more assignments available (thetaSq_nonneg_mono is the two-anchor form of the same monotonicity).
