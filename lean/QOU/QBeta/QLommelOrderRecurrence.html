    def QOU.QBeta.IsOrderThreeTermRec {K : Type u_1} [Field K] (b a : ℕ → K) :
    Prop

    The order three-term recurrence a (n+2) = b n · a (n+1) − a n (the q-Lommel / q-Bessel order contiguity (◇), as a relation on any sequence a : ℕ → K with coefficient sequence b : ℕ → K).

      theorem QOU.QBeta.two_root_geometric {K : Type u_1} [Field K] (r s α β : K) (hrs : r * s = 1) :
      IsOrderThreeTermRec (fun (x : ℕ) => r + s) fun (n : ℕ) => α * r ^ n + β * s ^ n

      Two-root (second-kind) geometric solution ⟹ DERIVED coefficient. If r · s = 1, the two-sided geometric sequence a n = α·rⁿ + β·sⁿ solves the order recurrence with the constant coefficient b = r + s — derived, not fitted (r, s are the two roots of t² − b·t + 1).

      This is the formal bridge for the binding Δ_λ ladder: the canonical residual Δ_λ(K) ≈ q₀^(10A−5) (docs/audits/2026-06-09-delta-lambda-canonical-residual.md) is geometric with ratio r = q₀¹⁰, so s = r⁻¹ = q₀⁻¹⁰ and the derived recurrence coefficient is b = q₀¹⁰ + q₀⁻¹⁰ = 2cosh(10·log q₀). The +β·sⁿ term is the second-kind admixture (Y_ν / K_ν branch) that carries the per-isotope deviations from the pure first-kind geometric law. The open keystone is a categorical derivation of the exponent 10A−5 = 5(2A−1) — the 5 is the Bring quintic — from the W_free vs W_atom crossing/jet bookkeeping; this lemma is the recurrence half that the exponent derivation feeds.

      theorem QOU.QBeta.first_kind_geometric_b {K : Type u_1} [Field K] (r C : K) (hr : r ≠ 0) :
      IsOrderThreeTermRec (fun (x : ℕ) => r + r⁻¹) fun (A : ℕ) => C * r ^ A

Hence the b ladder is derivable from the (derived) slope even while the offset remains open.

      theorem QOU.QBeta.double_root_linear {K : Type u_1} [Field K] (α β : K) :
      IsOrderThreeTermRec (fun (x : ℕ) => 2) fun (n : ℕ) => α + β * ↑n

      Double-root / C-finite linear expansion. The special case r = s = 1, corresponding to the recurrence coefficient b = 2. The general solution is the linear sequence a n = α + β * n. This formalises the decisive C-finite recurrence found in the extended alpha-cluster tower where b_ν ≈ 2 and ρ ≈ 1 (constant binding fractions).
