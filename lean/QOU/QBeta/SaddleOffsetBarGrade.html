    QOU.QBeta.SaddleOffsetBarGrade — chirality-grade ≠ q↔q⁻¹ Laurent bar-grade #

    Formalize-first honest negative for the qou-q86o "origin-centred only at q = 1" leg of the owner's saddle-vector picture.

    The sibling gate IotaOddSaddleOffsetAmphichiral (#4577) proves the certified saddle offset o = c⁺ − c⁻ vanishes iff the knot is (ι-fixed) amphichiral, by modelling the chirality swap (a,b) ↦ (b,a) as the bar involution q ↔ q⁻¹. The numerical probe saddle_offset_zero_location_probe.py (qou-q86o, #4583) shows those two involutions are genuinely different at the q-series level: the certified offset is odd under the chirality swap, but its q-dependence is not odd under q ↔ q⁻¹ — its q → 0 constant coefficient is the certified datum chiralityOdd 4 3 = 1 ≠ 0, whereas any object that is genuinely antisymmetric under q ↔ q⁻¹ has a zero constant coefficient.

    This file states that structural fact honestly. It is the reason the "the offset is origin-centred only at q = 1" leg is not delivered by the bar-fixed-point argument: that argument makes any genuinely q ↔ q⁻¹-odd object vanish at the fixed point q = q⁻¹ = 1 for free, but the certified DT offset is not such an object — it is a cross-chirality difference whose non-trivial content lives at q → 0, with its own zero-crossing at a small finite q ≈ 0.089 (the root of the DT expansion 1 − 9q − 28q² + …, a substrate-free convergence-region root — see the probe/audit).

    The two gradings #

    Write a Laurent-coefficient sequence as g : ℤ → R, where g n is the coefficient of qⁿ. The bar involution q ↦ q⁻¹ sends qⁿ ↦ q⁻ⁿ, i.e. acts on coefficients by n ↦ -n. Thus:

    • q↔q⁻¹ bar-grade. g is bar-odd in the modulus — BarAntisym g — when g (-n) = - g n for all n.
    • chirality-grade. The certified offset is odd under the chirality swap c⁺ ↔ c⁻ (the #4577 gate); this is a different involution on a different index set (the two chirality labels), not on the q-degree.

    What is proved (non-vacuous, sorry-free, falsifiable) #

    • barAntisym_const_zero — the bar-fixed-point vanishing, generic {R} [Ring R] [Invertible 2]: a q↔q⁻¹-odd object has zero constant coefficient. (This is exactly the mechanism the "q = 1" leg would need.)
    • barAntisym_const_zero_int — the same over ℤ (a domain), no Invertible 2.
    • offsetConst_eq_one — the certified offset's q → 0 constant coefficient is chiralityOdd (Splus0 0 1) (Sminus0 0 2) = 1 (reused from FiveTwoDTSpectrumSplit, not a fresh number).
    • certified_offset_not_barAntisym — the headline: no Laurent object whose constant coefficient equals the certified offset datum can be q↔q⁻¹-odd. Hence the certified offset's q = 1 vanishing is not delivered by the bar-fixed-point argument.
    • barAntisym_nontrivial — anti-vacuity: a genuinely q↔q⁻¹-odd object exists (g n = n), and it does have zero constant coefficient — so the hypothesis of barAntisym_const_zero is satisfiable, and the headline is a real distinction, not a vacuous one.

    Discipline #

    §7c: generic {R} theory; concrete grounding over ℤ (no archimedean construct). No sorry, no True := trivial, no native_decide, no axiom substituting for a proof. Scope-(a): a structural narrowing of the picture (the offset's q = 1 vanishing is only the trivial fixed-point one, distinct from the DT datum) — it invokes no proved invariant to exclude an ingredient, derives no physical number, wires no c_k, inverts no Q_β/CODATA. Standalone library file (like its dependency FiveTwoDTSpectrumSplit), verified lean-direct; not added to the QBeta aggregator.
