          The Wenzl hook–content weight #

          source
          noncomputable def QOU.QBeta.WenzlWeight.schurPrincipal {R : Type u_1} [Field R] (r : ℕ) (Q : R) (μ : YoungDiagram) :
          R

          The level-r principal specialisation of the Schur function, in the hook-content product form used throughout the corpus:

          s_λ(1, Q, …, Q^{r−1}) = Q^{n(λ)} · ∏_{x ∈ λ} (1 − Q^{r + c(x)}) / (1 − Q^{h(x)})

          This is markov_weights_symbolic.schur_principal_symbolic and schur_principal_mpmath._schur_principal_with, transcribed verbatim.

          Wenzl's theorem — the external input, and the only one — is that these are the Ocneanu/Markov trace weights on H_n(Q) at Markov parameter z_W = Q^r(1−Q)/(1−Q^r), up to the normalisation Σ_λ f^λ y_λ = 1. -- Ref: [wenzl1988] https://doi.org/10.1007/BF01404457 Wenzl, "Hecke algebras of type $A_n$ and subfactors", Invent. Math. 92 (1988) 349–383 — the source of the weight formula. -- Ref: [orellana1998] https://arxiv.org/abs/math/9806163 Orellana, "Weights of Markov Traces on Hecke Algebras", p. 17, restates Wenzl's type-A result in exactly this form: "In [W1] Wenzl showed that the weights of the Markov trace (with parameter z = q^r(1−q)/(1−q^r)) on the Hecke algebra of type A are given by the symmetric Schur functions s_{λ,r}(q)." Caution: Orellana's "type D" is the Coxeter type D_n and has nothing to do with this repo's trace convention D. Only the type-A statement above is used.

            theorem QOU.QBeta.WenzlWeight.wenzlLevel_conventionD {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) (hq2 : q ^ 2 + 1 ≠ 0) :
            q * (q ^ 3 / (q ^ 2 + 1)) / (1 - q ^ 2 + q * (q ^ 3 / (q ^ 2 + 1))) = (q ^ 2) ^ 2

            Convention D is Wenzl level r = 2.

            Wenzl's parameter relation z_W = Q^r(1−Q)/(1−Q^r) inverts to Q^r = z_W/(1 − Q + z_W). Convention D sits at Q = q² and z_W = q·z_D (the factor q is the Hecke-normalisation shift between g² = (Q−1)g + Q and σ² = (q − q⁻¹)σ + 1, under which σ = g/q and Q = q²). Substituting z_D = q³/(q²+1) gives Q^r = q⁴ = Q², so r = 2 on the nose — the SU(2) level, whose row cap is the Temperley–Lieb one.

            Not cited: this is an algebraic identity in q, so it is proved.

            theorem QOU.QBeta.WenzlWeight.schurPrincipal_eq_zero_iff {R : Type u_1} [Field R] {Q : R} (hQ0 : Q ≠ 0) (hQ : ∀ (k : ℤ), k ≠ 0 → Q ^ k ≠ 1) (r : ℕ) (μ : YoungDiagram) :
            schurPrincipal r Q μ = 0 ↔ r < μ.colLen 0

            The vanishing criterion, for every n, every λ and every level r.

            The level-r principal specialisation vanishes exactly when λ has more than r rows:

            s_λ(1, Q, …, Q^{r−1}) = 0 ⟺ ℓ(λ) > r.

            Q is assumed not to be a root of unity — precisely the genericity under which H_n(Q) is semisimple and the weights are defined. Without it the statement is false, so the hypothesis is doing real work rather than decorating the signature: at a root of unity a hook length can also kill a denominator and further numerator factors can vanish off content −r.

            The hypothesis is satisfiable, and the criterion is not vacuous #

The two results below rule that out: the first exhibits a broad class of Q meeting the root-of-unity hypothesis — including the substrate value Q = q₀² ≈ 1.232 — and the second evaluates the criterion on the smallest diagram that discriminates, checking that it returns different answers on the two sides.

            Wenzl's theorem as a hypothesis #

            Everything above is about schurPrincipal, a function this file defines. To say anything about the actual Ocneanu/Markov-trace weights one needs the external input — Wenzl (1988) — that those weights are this function. Below, that input stops being a comment and becomes a class threaded through the signature of every statement that depends on it (AGENTS.md §3b-cond).

            This proves nothing new. Per AGENTS.md §"Axiomatization is NOT a Proof", axiomatising an input does not discharge it: a class is an assumption wearing infrastructure. The statements below are proved conditional on Wenzl 1988 and must be cited that way. What the change buys is that the dependency is machine-tracked — a downstream declaration cannot use the weight-vanishing fact without IsOcneanuWeightSystem appearing in its type, where #check and code review will both see it.

            Why a class and not an axiom. An axiom would assert Wenzl's theorem globally and irrevocably; it could never be discharged, and it would have to be stated at some fixed (Q, z, r) or else quantified over a Hecke-algebra formalisation this repo does not have. The class form is parameterised, is satisfiable and falsifiable (both proved below), and — the deciding property — can one day be discharged: whoever formalises H_n(Q) and its Markov trace supplies the instance, and every conditional statement below becomes unconditional with no edit to this file. The cost is that the dependency does not appear in #print axioms; it appears in the type instead, which is why the conditional lemmas wear _of_wenzl in their names.

            No instance is provided, and none should be except by proving Wenzl's theorem. The satisfiability witness below is deliberately not registered as an instance, so typeclass search can never silently discharge the hypothesis.

            source
            class QOU.QBeta.WenzlWeight.IsOcneanuWeightSystem {R : Type u_1} [Field R] (Q z : R) (r : ℕ) (y : YoungDiagram → R) :
            Prop

            Wenzl (1988), as an explicit hypothesis: y is the Ocneanu weight system at level r.

            The class carries Wenzl's hypothesis, not the vanishing conclusion. Its two fields say:

            1. markovParameter_eq — the trace's Markov parameter z is Wenzl's at level r, i.e. z = Q^r(1−Q)/(1−Q^r), cleared of denominators.
            2. weight_eq_schurPrincipal — the external input. At that parameter the weights are the level-r principal specialisations, up to the normaliser Z fixed by Σ_λ f^λ y_λ = tr(1) = 1. Only Z ≠ 0 is used, so the statement does not depend on which normalisation convention is in force.

            Nothing about vanishing appears here. The conclusion y μ = 0 ↔ ℓ(λ) > r is derived — from this class plus the unconditional schurPrincipal_eq_zero_iff — rather than projected out of a field. That is the §3b-cond non-degeneracy requirement, and it is the whole point: the mathematical content of the vanishing lemma stays where it was proved, and the class supplies only the bridge.

            y is opaque. Lean cannot yet see the Hecke algebra or its trace, so the class cannot quantify over the actual Ocneanu weight — it can only name the property a candidate y would have to have. Producing an instance for the real trace weights is exactly Wenzl's theorem, and is exactly what remains unformalised. -- Ref: [wenzl1988] https://doi.org/10.1007/BF01404457 Wenzl, "Hecke algebras of type $A_n$ and subfactors", Invent. Math. 92 (1988) 349–383.

              The class is satisfiable, and it is not vacuous #

              A conditional theorem behind an unsatisfiable hypothesis proves nothing, and one behind a hypothesis satisfied by everything constrains nothing. Both are ruled out below: some y meet the class, and some y demonstrably do not.

              This does not discharge Wenzl's theorem, and must not be read as doing so.               The class is not vacuous: it rules things out.
