    The elimination #

    source
    theorem QOU.QBeta.FiveTwo.Ohtsuki.ohtsuki_elim {R : Type u_1} [CommRing R] {x y : R} (h1 : (1 - x) * y = 1) (h2 : x * (y - 1) ^ 2 = 1) :
    x ^ 3 = (1 - x) ^ 2

    Ohtsuki's critical-point system eliminates to x³ = (1−x)².

    From (1−x)·y = 1 and x·(y−1)² = 1. Over any commutative ring, and with no non-vanishing hypothesis: the identity

    `x³ − (1−x)² = (1−x)²·(x(y−1)² − 1) − x·(x + (1−x)(y−1))·((1−x)y − 1)`

    does the elimination directly. The mechanism is (1−x)(y−1) = x, which is h1 rearranged.

    source
    theorem QOU.QBeta.FiveTwo.Ohtsuki.one_sub_mul_sub_one {R : Type u_1} [CommRing R] {x y : R} (h1 : (1 - x) * y = 1) :
    (1 - x) * (y - 1) = x

    The step the elimination turns on: (1−x)(y−1) = x is exactly (1−x)y = 1 rearranged. Recorded separately because it is the whole content.

    The identification with the corpus's saddle cubic #

    source
    theorem QOU.QBeta.FiveTwo.Ohtsuki.saddle_poly_of_ohtsuki_poly {R : Type u_1} [CommRing R] (x : R) :
    (1 - x) ^ 3 - 2 * (1 - x) ^ 2 + 3 * (1 - x) - 1 = -(x ^ 3 - x ^ 2 + 2 * x - 1)

    The two cubics are negatives of each other under x = 1 − y.

    (1−x)³ − 2(1−x)² + 3(1−x) − 1 = −(x³ − x² + 2x − 1). One ring.

    theorem QOU.QBeta.FiveTwo.Ohtsuki.ohtsuki_cubic_iff_saddle_cubic {R : Type u_1} [CommRing R] (x : R) :
    x ^ 3 = (1 - x) ^ 2 ↔ (1 - x) ^ 3 - 2 * (1 - x) ^ 2 + 3 * (1 - x) - 1 = 0

    THE IDENTIFICATION. x is an Ohtsuki critical point iff 1 − x is a root of the corpus's 5₂ saddle cubic.

    FiveTwoSaddleSumRule.cubic_iff_sq_eq_cube already gives y³ − 2y² + 3y − 1 = 0 ↔ y² = (1−y)³, so this says the two branch equations — Ohtsuki's x³ = (1−x)² and the corpus's y² = (1−y)³ — are the same equation in coordinates differing by z ↦ 1 − z.

    source
    theorem QOU.QBeta.FiveTwo.Ohtsuki.ohtsuki_cubic_iff_sq_eq_cube {R : Type u_1} [CommRing R] (x : R) :
    x ^ 3 = (1 - x) ^ 2 ↔ (1 - x) ^ 2 = (1 - (1 - x)) ^ 3

    The same, phrased in the y² = (1−y)³ form the corpus carries: setting y = 1 − x, Ohtsuki's equation is the corpus's branch equation verbatim.

    source
    theorem QOU.QBeta.FiveTwo.Ohtsuki.saddle_cubic_of_ohtsuki_system {R : Type u_1} [CommRing R] {x y : R} (h1 : (1 - x) * y = 1) (h2 : x * (y - 1) ^ 2 = 1) :
    (1 - x) ^ 3 - 2 * (1 - x) ^ 2 + 3 * (1 - x) - 1 = 0

    End to end: a solution of Ohtsuki's critical-point system hands you a root of the corpus's saddle cubic, namely 1 − x.

    This is the bridge from Ohtsuki's volume-conjecture saddle to the data SaddleRoots bundles — with the caveat, stated in the module header and gated as G4 of Route 71, that which root is the geometric one is analytic input that no algebraic statement here supplies.
