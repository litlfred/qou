      theorem QOU.QBeta.TetraplecticProductRecurrence.tetraProd_funcEq {R : Type u_1} [CommRing R] (q x : R) (N : ℕ) :
      (1 + q * x) * tetraProd q (q ^ 2 * x) N = (1 + q ^ (2 * N + 1) * x) * tetraProd q x N

      The q²-dilation functional equation of the tetraplectic product. (1 + q x) · P_N(q² x) = (1 + q^{2N+1} x) · P_N(x). Both sides equal P_{N+1}(x): the left factors (1+qx) back in as the n=0 term after the q²-dilation reindexes n ↦ n+1; the right appends the n=N term. This is the recurrence that pins the q^{k²}/(q²;q²)_k coefficients of the reduction.

      theorem QOU.QBeta.TetraplecticProductRecurrence.e1_lattice_sum {R : Type u_1} [CommRing R] (q : R) (N : ℕ) :
      (q ^ 2 - 1) * ∑ n ∈ Finset.range N, q ^ (2 * n + 1) = q ^ (2 * N + 1) - q

      Explicit x¹-coefficient (the e_1 telescope). The first tetraplectic symmetric function e_1 over the finite lattice is the geometric sum ∑_{n<N} q^{2n+1}; here in cleared form (q² − 1)·∑_{n<N} q^{2n+1} = q^{2N+1} − q, the N→∞ limit of which is q/(1−q²) = q^{1²}/(q²;q²)_1, the k=1 closed form. Proved by induction on N.
