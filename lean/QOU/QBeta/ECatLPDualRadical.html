    1. Pairing the dual equality with a radical vector #

    source
    theorem QOU.QBeta.ECatLPDualRadical.radical_pairing {ι : Type u_1} {R : Type u_2} [Fintype ι] [Field R] (t one v Gy : ι → R) (y₀ : R) (hdual : ∀ (j : ι), y₀ * one j + Gy j = t j) (hGy : ∑ i : ι, Gy i * v i = 0) :
    ∑ i : ι, t i * v i = y₀ * ∑ i : ι, one i * v i

    The radical pairing.

    Gy is the image G y of the dual variables; v spans the radical of G, so ⟨Gy, v⟩ = ⟨y, Gv⟩ = 0 -- carried here as the hypothesis hGy, since it is a fact about G and v and not about the LP. Pairing the dual equality y₀·1 + Gy = t with v leaves one scalar equation.

    Everything below is a corollary of this line.

    2. The shadow price is DETERMINED before any solver runs #

    source
    theorem QOU.QBeta.ECatLPDualRadical.dual_price_determined_by_radical {ι : Type u_1} {R : Type u_2} [Fintype ι] [Field R] (t one v Gy : ι → R) (y₀ : R) (hdual : ∀ (j : ι), y₀ * one j + Gy j = t j) (hGy : ∑ i : ι, Gy i * v i = 0) (hone : ∑ i : ι, one i * v i ≠ 0) :
    y₀ = (∑ i : ι, t i * v i) / ∑ i : ι, one i * v i

    y₀ = ⟨t, v⟩ / ⟨1, v⟩.

    The shadow price of the net constraint is fixed by two inner products against the radical vector. No feasible point, no n_target, no solver, no ordering.

    This is the formalize-first payoff: whether the geometric cost gives a live dual is decided by ONE number, ⟨t, v⟩, and the probe that follows has to compute that and nothing else to know whether the LP is worth running.

    theorem QOU.QBeta.ECatLPDualRadical.dual_price_zero_of_cost_orthogonal_to_radical {ι : Type u_1} {R : Type u_2} [Fintype ι] [Field R] (t one v Gy : ι → R) (y₀ : R) (hdual : ∀ (j : ι), y₀ * one j + Gy j = t j) (hGy : ∑ i : ι, Gy i * v i = 0) (hone : ∑ i : ι, one i * v i ≠ 0) (ht : ∑ i : ι, t i * v i = 0) :
    y₀ = 0

    The recorded Hecke collapse, as a special case.

    A cost orthogonal to the radical forces y₀ = 0. This is y_0_eq_zero_of_radical's conclusion reached from the same pairing, and it holds with no hypothesis about feasibility, symmetry, or signs -- which is why the collapse cannot be escaped by adjusting the constraints.

    theorem QOU.QBeta.ECatLPDualRadical.dual_price_ne_zero_of_cost_not_orthogonal {ι : Type u_1} {R : Type u_2} [Fintype ι] [Field R] (t one v Gy : ι → R) (y₀ : R) (hdual : ∀ (j : ι), y₀ * one j + Gy j = t j) (hGy : ∑ i : ι, Gy i * v i = 0) (hone : ∑ i : ι, one i * v i ≠ 0) (ht : ∑ i : ι, t i * v i ≠ 0) :
    y₀ ≠ 0

    THE ESCAPE. A cost NOT orthogonal to the radical forces a nonzero shadow price.

    So the geometric cost's fate is settled by ⟨t, v⟩ alone. This is the statement that makes running the LP on t_λ a decidable question rather than a hopeful one — and note the direction: this does not say the geometric cost clears the bar, only that clearing it is exactly ⟨t, v⟩ ≠ 0.

    theorem QOU.QBeta.ECatLPDualRadical.dual_price_is_solver_independent {ι : Type u_1} {R : Type u_2} [Fintype ι] [Field R] (t one v Gy Gy' : ι → R) (y₀ y₀' : R) (hdual : ∀ (j : ι), y₀ * one j + Gy j = t j) (hdual' : ∀ (j : ι), y₀' * one j + Gy' j = t j) (hGy : ∑ i : ι, Gy i * v i = 0) (hGy' : ∑ i : ι, Gy' i * v i = 0) (hone : ∑ i : ι, one i * v i ≠ 0) :
    y₀ = y₀'

    The price is solver-independent: any two dual-feasible shadow prices agree. So the ratio above is a CHECK the eventual compute must satisfy, not a prediction the compute confirms — a solver returning anything else is wrong.

    3. The primal side: exactly which costs make the objective vacuous #

    source
    theorem QOU.QBeta.ECatLPDualRadical.cost_from_gram_makes_objective_a_constraint_readout {ι : Type u_1} {R : Type u_2} [Fintype ι] [Field R] (x u : ι → R) (Grow : ι → ι → R) (t : ι → R) (ht : ∀ (j : ι), t j = ∑ i : ι, Grow j i * u i) :
    ∑ j : ι, t j * x j = ∑ j : ι, (∑ i : ι, Grow j i * u i) * x j

    A cost drawn from the Gram makes the objective a read-out of the constraints.

    If the cost is obtained by pairing each basis vector against a fixed u through the Gram — tⱼ = ⟨G eⱼ, u⟩ — then

    ⟨t, x⟩ = ⟨G x, u⟩

    so the objective reports a linear functional OF THE CONSTRAINT DATA G x and carries no information the constraints do not already fix. Taking u = eₖ recovers the recorded Hecke defect exactly: tⱼ = G_{kj} gives ⟨t, x⟩ = (Gx)ₖ, which is t·x = u₀ at k = 0 — constant on a feasible set that pins that coordinate.

    Read with §2 this says precisely what a replacement objective must avoid, and it is two independent conditions, both checkable before solving: not drawn from the Gram it is paired with, and not orthogonal to that Gram's radical. Being merely "different from the Hecke cost" is neither.

    theorem QOU.QBeta.ECatLPDualRadical.diagonal_gram_kills_every_cost_on_its_diagonal {ι : Type u_1} {R : Type u_2} [Fintype ι] [Field R] (g u v t : ι → R) (hrad : ∀ (j : ι), g j * v j = 0) (ht : ∀ (j : ι), t j = g j * u j) :
    ∑ j : ι, t j * v j = 0

    A DIAGONAL Gram kills every cost built on its own diagonal.

    This is the general form of the negative measured in qbeta_ecat_lp_radical_pairing_probe (5/5), and it is stated for the diagonal case because that is the case measured -- the dense-Gram version needs a sum swap this file does not carry, and claiming it would be asserting more than is proved.

    Setting: G = diag g, so t_j = g_j * u_j for a cost built from the diagonal, and v is in the radical, i.e. g_j * v_j = 0 for every j. Then ⟨t, v⟩ = 0 — so by §2 the shadow price collapses.

    The block-basis instance. There g_λ = y_λ * dim_λ and the cost is t_λ = y_λ * f(λ), which is g_λ * u_λ with u_λ = f(λ)/dim_λ wherever dim_λ ≠ 0. So the measured collapse was an instance of this and not a coincidence of convention D: the SAME y_λ that makes the Gram entry vanish makes the cost component vanish, for every f.

    The design constraint for whoever builds the next cost: against a diagonal Gram, no cost proportional to that diagonal escapes. Escaping requires a component where the Gram has none — on the six-operator basis, a component along the q-antisymmetriser (-q³, q², q², -q, -q, 1). Being geometric is not sufficient and being non-Hecke is not sufficient.
