        theorem QOU.QBeta.Fig8CyclotomicBarInvariance.fig8Factor_bar_invariant {K : Type u_1} [Field K] (q : K) (j : ℕ) :
        fig8Factor q⁻¹ j = fig8Factor q j

        Each factor is fixed by the bar involution. The involution q ↦ q⁻¹ swaps the two brackets of (1 − qʲ)(1 − q⁻ʲ), and multiplication commutes.

        Generic per §7c — any field, and no q ≠ 0 hypothesis is needed: Lean's 0⁻¹ = 0 makes it hold at q = 0 too.

        source
        theorem QOU.QBeta.Fig8CyclotomicBarInvariance.fig8Term_bar_invariant {K : Type u_1} [Field K] (q : K) (n : ℕ) :
        fig8Term q⁻¹ n = fig8Term q n

        The whole term is fixed by the bar involution, exactly — not merely in modulus. T_n(q⁻¹) = T_n(q) for every n.

        This is the front-(a) result: for J(4₁) the two members of a bar-pair are interchangeable, so moving the evaluation from q₀ to q₀⁻¹ changes nothing.
