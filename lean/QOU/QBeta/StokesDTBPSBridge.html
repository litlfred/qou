    QOU.QBeta.StokesDTBPSBridge — resurgent-Stokes = DT/BPS bridge (adopted conjecture) #

    Vol-conjecture-style conditional adoption (bean qou-ujmw/qou-qnnq). The G3 Stokes integer A_ω = 3 of the figure-eight 4₁ is here made a conditional result downstream of a citeable published conjecture, exactly as conj:kashaev-volume-conjecture is adopted for the volume side.

    Which published bridge — and the honest non-degeneracy result #

    The mandated non-degeneracy gate asks whether the BPS count of 4₁ reproduces the GGM resurgent-Stokes / DT spectrum {3, 4} (reduced-Stokes 3) through the bridge. The answer depends on which BPS sector:

    • Gukov–Stošić 1112.0030 (OPEN sector) — FAILS. There "knot homology = space of open BPS states" (M5-brane on the conormal Lagrangian L_K ⊂ T*S³; colored HOMFLY homology). The knots–quivers correspondence (1707.02991) makes the 4₁ open-BPS count det(4₁) = 5 (five HOMFLY generators = five quiver nodes; calibrated against that paper's trefoil = 3 = det 3₁). 5 ∉ {3, 4}. So the open-HOMFLY Gukov–Stošić bridge does not license A_ω = 3; it is a different BPS sector.

    • GPPV 1701.06567 + GGM peacock 2012.00062 Conjecture 3(d) (CLOSED sector) — PASSES. GGM peacock Conjecture 3(d): "the Stokes constants are integers corresponding to the Donaldson–Thomas invariants … and the BPS degeneracies." GPPV realise that DT/BPS count as the graded dimension of the BPS Hilbert space of T[M₃] (the state-integral / Ẑ / 3d–3d sector). This reproduces {3, 4} (reduced-Stokes 3); the q → 0 anchor is machine-checked unconditionally in StokesQZeroDTCount (S⁺(0)₀₁ = 3).

    This file therefore axiomatises the closed-sector bridge and derives A_ω(4₁) = 3 conditional on it — a theorem for 4₁ (GGM proved Conjecture 3 for 4₁), conjectural in general. It is not the open-HOMFLY Gukov–Stošić bridge, which the check excludes.

    §3b-cond non-degeneracy (anti-laundering) #

    StokesDTBPSBridge carries the conjecture's inputs — the two identifications stokes = dt (GGM Conj 3(d)) and dt = bps (GPPV) — as class fields. It does not carry the conclusion A_ω = 3 as a field. aomega_fourOne_dt_count derives the BPS count of 4₁ by composing the two bridge identifications with the bridge-independent, certified 4₁ Stokes datum = 3 (from StokesQZeroDTCount). So the theorem proves something the class does not assume: the observable A_ω of 4₁ is the BPS/DT degeneracy, and it equals 3.

    Base ring (§7c) #

    Counts are ℤ (Donaldson–Thomas / BPS degeneracies are integers; a -3 DT entry occurs at 4₁, so a signed ring is correct). No archimedean construct (Real.*, ordering) appears; ℤ is the substrate-side ring here.

    class QOU.QBeta.StokesDTBPSBridge (Knot : Type u_1) :
    Type u_1

    Adopted conjecture — the closed-sector resurgent-Stokes = DT/BPS bridge.

    For a hyperbolic knot K, three integer invariants of S³ ∖ K / T[K] are conjecturally identified (GGM peacock Conjecture 3(d) + GPPV):

    • stokesConstant K — the resurgent Stokes constant of the state integral Z(S³ ∖ K) on the distinguished (geometric Borel) ray;
    • dtInvariant K — the Donaldson–Thomas / Kontsevich–Soibelman invariant of the associated q-difference / stability structure;
    • bpsDim K — the graded dimension of the GPPV BPS Hilbert space of T[K] in the geometric sector.

    The two class fields are the conjecture's content (its inputs). There is no field asserting any particular value of any of these integers — in particular no A_ω = 3 field; that value is derived downstream, only for 4₁, from the bridge-independent certified Stokes datum. An instance of this class is the conjecture holding; none is provided (the general conjecture is open — it is a theorem for 4₁).

    • stokesConstant : Knot → ℤ

      Resurgent Stokes constant of the state integral, geometric Borel ray.

    • dtInvariant : Knot → ℤ

      Donaldson–Thomas / motivic invariant of the q-difference structure.

    • bpsDim : Knot → ℤ

      Graded dimension of the GPPV BPS Hilbert space of T[K], geometric sector.

    • stokes_eq_dt (K : Knot) : stokesConstant K = dtInvariant K

      GGM peacock 2012.00062 Conjecture 3(d): the resurgent Stokes constant is the Donaldson–Thomas invariant.

    • dt_eq_bps (K : Knot) : dtInvariant K = bpsDim K

      GPPV 1701.06567 (with Gaiotto–Moore–Neitzke): the Donaldson–Thomas invariant is a BPS degeneracy — the dimension of the BPS Hilbert space.
