    The cyclic five-term relation has period 5: z₆ = z₁.

    The survey states this as "implies by a short calculation that they have period 5" (library/arxiv-2304.12545v1/2304.12545v1.pdf §3). This is that calculation.

    The five-term element lies in ker d #

    d[x] = x ∧ (1−x), and the five arguments of the five-term relation satisfy Σᵢ (zᵢ) ∧ (1−zᵢ) = 0. That vanishing is what makes the Bloch group well-defined.

    The survey's proof is a two-line reindexing: with 1 − zᵢ = zᵢ₋₁zᵢ₊₁,

    Σᵢ (zᵢ) ∧ (1−zᵢ) = Σᵢ (zᵢ) ∧ (zᵢ₋₁zᵢ₊₁)
                  = Σᵢ ((zᵢ)∧(zᵢ₋₁) + (zᵢ₋₁)∧(zᵢ)) = 0.

    Stated below for an arbitrary alternating biadditive pairing w, written additively — the multiplicative group F^× in additive notation, which is how Λ²(F^×) is used. This keeps the result independent of any particular Λ² encoding.

    source
    theorem QOU.QBeta.Bloch.wedge_five_term_vanishes {A : Type u_1} {M : Type u_2} [AddCommGroup A] [AddCommGroup M] (w : A → A → M) (hadd : ∀ (x y z : A), w x (y + z) = w x y + w x z) (halt : ∀ (x y : A), w x y + w y x = 0) (a₁ a₂ a₃ a₄ a₅ : A) :
    w a₁ (a₅ + a₂) + w a₂ (a₁ + a₃) + w a₃ (a₂ + a₄) + w a₄ (a₃ + a₅) + w a₅ (a₄ + a₁) = 0

    Σᵢ (zᵢ) ∧ (1−zᵢ) = 0 for the five-term relation.

    w is any biadditive alternating pairing; aᵢ are the (additively written) arguments, and the hypothesis w x (y + z) = w x y + w x z together with w x y + w y x = 0 is exactly what Λ² supplies. The five y-arguments are the sums aᵢ₋₁ + aᵢ₊₁, the additive form of 1 − zᵢ = zᵢ₋₁·zᵢ₊₁.

    The 5₂ saddle element lies in ker d — because y and 1−y are #

    multiplicatively dependent

    This one is specific to 5₂ rather than generic Bloch-group infrastructure.

    The saddle cubic says y² = (1−y)³, i.e. y and 1−y are multiplicatively dependent. In F^× written additively that reads 2·(y) = 3·(1−y), and then

    3·w(y, 1−y) = w(y, 3·(1−y)) = w(y, 2·(y)) = 2·w(y, y) = 0.

    So d[yⱼ] = (yⱼ) ∧ (1−yⱼ) is 3-torsion, hence zero rationally: the 5₂ saddle element defines a class in B(F) ⊗ ℚ.

    Note the conclusion is torsion, not zero on the nose — which is exactly the "delicate 2- and 3-torsion issues" the survey flags in the definition of B(F) (library/arxiv-2304.12545v1/2304.12545v1.pdf §3). Stating it as 3·w = 0 keeps that honest rather than quietly working ⊗ ℚ.

    source
    theorem QOU.QBeta.Bloch.three_smul_wedge_eq_zero {A : Type u_1} {M : Type u_2} [AddCommGroup A] [AddCommGroup M] (w : A → A → M) (hadd : ∀ (x y z : A), w x (y + z) = w x y + w x z) (hself : ∀ (x : A), w x x = 0) {u v : A} (h : u + u = v + v + v) :
    w u v + w u v + w u v = 0

    A multiplicative dependence 2·u = 3·v forces w u v to be 3-torsion.

    Applied with u = (y), v = (1−y) in F^× (additively), this says the d-image of a 5₂ saddle root is 3-torsion in Λ²(F^×).
