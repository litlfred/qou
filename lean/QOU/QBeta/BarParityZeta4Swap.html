    The ζ₄ bar-parity swap: translating bar-even ↔ bar-odd #

    The explicit translator between the mass (bar-even, cosh-like) and the decay/binding (bar-odd, sinh-like) faces. Complements the σ-parity split (QOU.QBeta.EkParitySplit, which projects onto the two faces) and the ζ₄ f-map constraints — this file states the swap map they both use implicitly.

    For any x in a field, put the two bar-parity shapes $$\mathrm{barEven}(x) = x + x^{-1}\ (\cosh\text{-like}),\qquad \mathrm{barOdd}(x) = x - x^{-1}\ (\sinh\text{-like}),$$ symmetric / antisymmetric under the bar involution x ↦ x⁻¹. A quarter-turn x ↦ ζx by a primitive fourth root of unity (ζ² = -1) exchanges them: $$\mathrm{barEven}(\zeta x) = \zeta\,\mathrm{barOdd}(x),\qquad \mathrm{barOdd}(\zeta x) = \zeta\,\mathrm{barEven}(x).$$

    This is the algebraic cosh ↔ sinh realization cosh(t) = -i\,\sinh(t+i\pi/2) (x = eᵗ, ζ = e^{iπ/2} = i): even ↔ odd is Re ↔ Im of the complex volume CVol = Vol + i·CS (mass = Re/bar-even, decay=binding = Im/bar-odd), and the translator is multiplication by ζ₄ = i.

    The swap is an algebraic / geometric-side operation, not an off-axis continuation of the evaluation. Here ζ multiplies the (already complex) shape / coefficient variable x — the geometric tetrahedron shape (z = e^{iπ/3} for 4₁) or the cyclotomic/Habiro coefficient — not the real substrate evaluation point q₀. So the bar-odd (decay/binding) object is obtained by ζ₄-transporting the solved bar-even (geometric) object algebraically, and then evaluating at the same real q₀. No analytic continuation of the q₀ evaluation off the real axis is needed: the ζ = i lives in the fibre/coefficient (where c_k legitimately live), while the archimedean constraint Im q₀ = 0 binds only the evaluation point. This is why the c₃ bar-odd S is "complex" (a ζ₄ coefficient factor) yet observed at real q₀ — the transport happens on the algebraic/geometric side, the evaluation stays real.

    Not a ζ₄-residue claim (coordination, §8 flip-flop guard). This is a functional-argument swap x ↦ ζx, orthogonal to the residue question already settled by QOU.QBeta.Zeta4Residue (QBetaZeta4ResidueRefutation): there Φ₄ = q²+1 is proved not to divide the odd carrier, so the odd channel has no ζ₄-residue / no pole at q = i. Nothing here reopens that — the swap barEven(ζx) = ζ·barOdd(x) is a parity-grading identity in the argument, not a pole/divisibility statement in q, and it wires no c_k.

    Generic field, no archimedean structure (§7c). No c_k wired.
