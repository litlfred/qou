    The deformed saddle condition is the GGM curve #

    Bean qou-trns. QOU/QBeta/FiveTwoSaddleSumRule.lean proves this at the base point x = 1:

    theorem cubic_iff_sq_eq_cube (y : R) : y³ - 2y² + 3y - 1 = 0 ↔ y² = (1 - y)³
theorem branch_data_of_cubic … : ∃ k : ℤ, 2 log y - 3 log (1 - y) = k·(2πi)

    and calls the branch data "the sole source of the π² in the sum rule". The deformed statements — the ones the transport travels along — were missing. This file supplies them.

    The saddle condition #

    The transport's integrand is V(x,y) = Li₂(y) + Li₂(xy) + Li₂(y/x) + log(−y)², and

    ∂V/∂y = (1/y)·[ 2 log(−y) − log(1−y) − log(1−xy) − log(1−y/x) ]

    using d/dz Li₂(z) = −log(1−z)/z three times. Exponentiating kills every logarithm, and ∂V/∂y = 0 becomes

    y² = (1−y)(1−xy)(1−y/x)

    deformed_saddle_iff_curve shows this is identically GGM's deformed 5₂ curve — over any commutative ring, denominators cleared. At x = 1 it collapses to y² = (1−y)³, recovering the corpus statement (saddle_at_one).

    That matters for scope. The envelope argument needs the saddle condition, and the saddle condition is often the part one worries about; here it is free, because it is the curve the roots were defined by. What the envelope still needs is the analysis — dyⱼ/dx and d/dz Li₂ along a path — not this.

    The branch data, deformed #

    branch_data_of_curve: every point of the curve satisfies

    2 log(−y) − log(1−y) − log(1−xy) − log(1−y/x) = k·(2πi),  k ∈ ℤ

    derived from the curve alone, no dilogarithm and no analysis — exactly as branch_data_of_cubic does at x = 1.

    And the sum over the three roots is pinnable #

    exp_branchSum_eq_one proves exp (Σⱼ branchTerm x yⱼ) = 1 from Vieta alone — the saddle condition is not needed for the sum, only for the individual terms. It rests on three products, of which one is new here:

    product source
    ∏ⱼ (1 − x·yⱼ) = x prod_one_sub_x_mul (#4658)
    ∏ⱼ (x − yⱼ) = x² prod_x_sub (#4658)
    ∏ⱼ (1 − yⱼ) = 1 prod_one_sub, new here

    That is precisely the hexp hypothesis of QOU/Archimedean/BranchIntegerPinning.lean. So along the transport arc the sum of the deformed branch integers is pinned to its base-point value by the same lemma that pins the transport's own branch integer — given continuity, which remains the open hypothesis there. At x = 1 the corpus records k = (+1, −1, 0), whose sum is 0.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.
