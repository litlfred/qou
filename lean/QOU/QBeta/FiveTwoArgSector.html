    Pinning the branch integer by a SECTOR — Route 27's obligations, proved #

    Bean qou-trns. FiveTwoBranchByArgument traded hcont for three real-algebraic inequalities measured along the arc (Route 27), with margins of 10% and 17% and no proof. This file discharges that trade: the obligations turn out not to be needed in the measured form at all, because the bound they were approximating is φ-dependent, and what is left is one inequality which is proved here.

    Why the measured margins were an artefact #

    Route 27 confined Σⱼ arg(1 − x·yⱼ) to the uniform window (−π, 2π), which forces tight control on every individual argument — hence the tight margins. But the window only has to exclude φ ± 2π, and it is free to depend on φ. With φ ∈ [0, π) the window (φ − 2π, φ + 2π) suffices, and it is loose enough to be reached from:

    input source
    arg(1 − x·y₁) ∈ (−π/2, 0), y₁ the positive real root ‖x·y₁‖ = y₁ < 1, so Re(1 − x·y₁) > 0
    arg(1 − x·y₃) ≥ 0 when Im(x·y₃) ≤ 0 Complex.arg_nonneg_iff
    arg(1 − x·y₂) ∈ (−π, π] free — Complex.neg_pi_lt_arg, Complex.arg_le_pi
    and, only when φ > π/2, arg(1 − x·y₂) ≥ 0 too same as y₃

    sum_window turns those into Σ ∈ (φ − 2π, φ + 2π), and branchInt_eq_zero_of_window into k = 0. Two of the four inputs are free, and the first needs only 0 < y₁ < 1 — which is p(0) = −1 < 0 < 1 = p(1) for the monic cubic Y³ − 2cY² + (2c+1)Y − 1.

    The one real fact, and its proof #

    What is left is: some root has Im(x·yⱼ) ≤ 0, and when φ > π/2, two do. On |x| = 1 the cubic is real, so the roots are a real one plus either two reals or a conjugate pair. Two reals: they are both negative (product 1, sum 2c < 0), so Im(x·y) = y·sin φ < 0 outright, and both qualify. A conjugate pair a ± b i: the statement is

    s·a < c·b        (`sa_lt_cb`),   `c = cos φ`, `s = sin φ > 0`, `b > 0`

    for the lower member, and when c < 0 the upper member follows from it since c·b < 0 < −c·b. That single inequality is Route 27's obligation — measured there with max(s·a − c·b) = −0.3365 and left open. It is proved here from two Vieta consequences, 2cR = 1 + 2aR and 2a(R−1) = R² − R − 1 with R = a² + b² = ‖y₂‖², by three sign certificates:

    • 1 < R (one_lt_normSq) — equivalently the real root is < 1. Otherwise b² > 0 would force 4R(R−1)² > (R²−R−1)², impossible on (0,1] where the left side is at most 16/27 (certificate (3R−1)²(4−3R) ≥ 0) and the right side is at least 1.
    • a > 0: then c > a > 0, and E := 1 + 4aR + 4a²R(R−1) > 0 termwise, giving a² < c²R.
    • a < 0 < −c: then E·(R−1) = R³(R−1)² − 1, and R³(R−1)² = (R³ − R²)·(R² − R) is a product of two factors in (0,1) — the first below 1 because c < 0, the second because a < 0 — so E < 0 and a² > c²R.

    sq_gap is the bridge: (s·a)² − (c·b)² = a² − c²R on the constraint set, so the sign of a² − c²R decides the goal once the signs of s·a and c·b are known.

    Status #

    This turns Route 27's three measured obligations into theorems, and removes the margins from the argument entirely.

    The remaining inputs — a real root in (0,1), and the sign of Im(x·yⱼ) for the other two — are stated as hypotheses here rather than assumed silently. They are proved in FiveTwoRootStructure (exists_pinning_data), by IVT plus real algebra; this file does not depend on that one, so the factoring stays honest.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.

    5. Non-vacuity #

    source
    theorem QOU.QBeta.FiveTwoDeformedSaddle.sa_lt_cb_nonvacuous :
    ∃ (a : ℝ) (b : ℝ) (c : ℝ) (s : ℝ) (R : ℝ), 0 < b ∧ 0 < s ∧ R = a ^ 2 + b ^ 2 ∧ 2 * c * R = 1 + 2 * a * R ∧ 2 * a * (R - 1) = R ^ 2 - R - 1 ∧ c ^ 2 + s ^ 2 = 1 ∧ s * a < c * b

    Non-vacuity for sa_lt_cb. The hypotheses are satisfiable, and by a point that is genuinely on the arc: R = 2 lies inside the measured range [1.2821, 2.3247] of ‖y₂‖² over the complex-pair arc (Route 28). Solving the two Vieta relations at R = 2 gives a = 1/2, then c = 3/4, then b = √7/2, s = √7/4, and the conclusion reads √7/8 < 3√7/8.

    The check with real content is Route 28, which verifies both Vieta relations, 1 < R, and the conclusion at 700 points of the arc at 40 dps.
