    Φ_b uniqueness — conditional on strip-growth + meromorphic normal form #

    Composes PhiBProdLociDensity.phiBProd_uniqueUpToScalar_of_normalForm into a single-class interface: FaddeevPhiPhysical packages the three requirements (shift equations + strip-growth + normal form) that the uniqueness chain needs.

    Honest accounting of what this file does and does not do.

    • What it does: reduces Faddeev uniqueness to a single typeclass with three families of axioms (shift equations, growth bound, regularity). No further hypotheses appear as explicit arguments — they are all class fields.

    • What it does NOT do: the two added fields (instStripGrowth, hNF) are carried axioms, not proved theorems. They are the QOU §3b conjecture-class pattern: open inputs packaged as class fields so downstream composition is clean. The class is non-vacuous (the concrete phiBProd satisfies all three), but instantiating it for a second solution IS the remaining analytic content.

    • instStripGrowth (physical content): the strip-growth bound ‖Φ₁ z‖ ≤ C · ‖phiBProd b z‖ is the physical asymptotic condition that Faddeev and Kashaev use to single out Φ_b among solutions of the shift equations. It excludes elliptic multipliers (which grow in the strip). This is a standard and physically motivated uniqueness input.

    • hNF (Lean technicality): MeromorphicNFOn Φ₁ Set.univ says the total-function encoding of Φ₁ has value 0 at poles (Mathlib's convention for meromorphic functions as total functions). This is NOT a mathematical hypothesis — any meromorphic function can be put in normal form. It is a Lean formalization regularity condition needed because FaddeevPhi works with raw ℂ → ℂ (which could have arbitrary junk values at poles). For the concrete Φ_b = num/den (quotient of entire functions), MeromorphicNFOn holds by construction.

    • Scope: the uniqueness is conditional on the class axioms. Saying "A_ω is uniquely determined" means: uniquely determined for any Φ₁ that is a FaddeevPhi + strip-growth + NF solution. The class axioms are the honest open inputs.

    Prop

    Φ_b with strip-growth + normal form (conjecture-class, §3b). Extends FaddeevPhi with the two regularity conditions that the uniqueness chain needs. Both are carried axioms (open inputs packaged as class fields):

    • strip-growth comparability to phiBProd — the physical asymptotic condition (Faddeev–Kashaev) excluding elliptic multipliers.
    • meromorphic normal form on ℂ — a Lean technicality (total-function values at poles are 0); holds by construction for quotients of entire functions.

    The class is non-vacuous: phiBProd itself satisfies all fields. But instantiating it for a second solution IS the remaining analytic content (the open input that the shift equations alone do not provide).

    • hb : 0 < (PhiBProd.substrateB t).re
    • shift_b (z : ℂ) : Φ (z - Complex.I * (PhiBProd.substrateB t / 2)) = (1 + Complex.exp (2 * ↑Real.pi * PhiBProd.substrateB t * z)) * Φ (z + Complex.I * (PhiBProd.substrateB t / 2))
    • shift_binv (z : ℂ) : 1 + Complex.exp (2 * ↑Real.pi * z / PhiBProd.substrateB t) ≠ 0 → Φ (z - Complex.I / (2 * PhiBProd.substrateB t)) = (1 + Complex.exp (2 * ↑Real.pi * z / PhiBProd.substrateB t)) * Φ (z + Complex.I / (2 * PhiBProd.substrateB t))
    • instStripGrowth : FaddeevPhiStripGrowth (MathlibExt.PhiBProd.substrateB t) Φ

      Φ is comparable in modulus to phiBProd (physical strip-growth bound).

    • hNF : MeromorphicNFOn Φ Set.univ

      Φ is in meromorphic normal form on ℂ (Lean regularity, not a math hypothesis — any meromorphic function can be represented this way).
