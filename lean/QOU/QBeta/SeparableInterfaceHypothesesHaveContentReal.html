    The Pauli-lock release survives positivity — the archimedean half #

    Sibling of QOU.QBeta.SeparableInterfaceHypothesesHaveContent, which carries the generic statements. Split per AGENTS.md §7c: the ordering (0 < μ) and the measured asymmetry as a real numeral are archimedean, so they live here and consume the generic results at R := ℝ rather than specialising them in place.

    What the split buys. The generic file's three results hold over any commutative ring, monoid or field — so the finding that separable_interface_degenerate's conclusion is unconstrained once its antecedent is dropped is not an artefact of the real numbers. This file adds the two things that genuinely need ℝ: that the escape stays inside the physically admissible positive-weight regime, and that the specific measured ratio is one of the values it reaches.

    The generic content theorem specialised to the reals; the non-degeneracy hypothesis (5 : ℝ) ≠ 6 is discharged by norm_num. Recorded so that the ring the corpus actually reasons over is on the record as an instance of the generic result, not a separate claim.

    Written in the named-argument form (R := ℝ) that AGENTS.md §7c prescribes for the archimedean sibling. An earlier revision used @f ℝ _ to dodge check-sidecars.sh, which counted the literal (R := as evidence a file declares a generic result and so reported this correctly-split file as "§7c MIXED". That detector bug is fixed (scripts/check-sidecars.sh, fourth false-positive class), so the workaround is gone and the prescribed spelling is back.

    The escape survives positivity.

    Over ℝ with all four weights strictly positive — the physically admissible regime, since the interface projector scalars satisfy μ₊ + μ₋ = 1 with both positive for q > 0 (InterfaceScalar.proj_add_eq_one and its ordering companions) — every positive ratio is still attainable. So the release of the conclusion is not an artefact of admitting negative or zero projector weights, which is the first objection it would meet.
