    The phiBProd partial products converge locally uniformly (input-1 closure) #

    This is the last infrastructure brick of input 1 of the Faddeev–Volkov uniqueness keystone (qou-7xvy). LocalUniformLimitEntire (merged) reduces analyticity of the infinite products ∏' k, numFactor b · k, ∏' k, denFactor b · k to a single local-uniform convergence fact about their Finset.range partial products. This file supplies that fact from Mathlib's uniform-product API and thereby closes input 1 unconditionally on the product-supported branch Im b² > 0 — in particular at the physical substrate b-map.

    The estimate #

    Each factor is 1 + exp(E(z) + k·c) with E an affine (hence entire, continuous) function of z and c = 2πi b² (numerator) / −2πi/b² (denominator). On the branch Im b² > 0, Re c < 0, so on any compact K ⊆ ℂ the factor norms are dominated by the summable geometric u_K(k) = e^{M_K}·(e^{Re c})^k, where M_K = sup_{z∈K} Re(E z) (finite by compactness). Mathlib's Summable.hasProdUniformlyOn_one_add then gives uniform convergence on each compact K, and hasProdLocallyUniformlyOn_of_forall_compact assembles these into HasProdLocallyUniformlyOn on ℂ; its tendstoLocallyUniformlyOn_finsetRange accessor is exactly the hypothesis LocalUniformLimitEntire needs.

    The bound is local (per-compact), not global: Re(E z) is unbounded on ℂ, so no single u dominates on all of ℂ — which is precisely why the local-uniform (not uniform) API is the right tool.

    Composing with PhiBProdMeromorphic.phiBProd_meromorphicOn_of_analytic, this discharges MeromorphicOn (phiBProd b) with no remaining analytic hypothesis on the branch: phiBProd_meromorphicOn / phiBProd_meromorphicOn_substrate.

    Verified lean-direct against the pinned Mathlib MultipliableUniformlyOn + LocallyUniformLimit cones (built from source) + PhiBProd. Sorry-free.

    Local-uniform convergence of ∏(1 + exp(affine + k·c)) for Re c < 0. The generic engine: for any continuous E : ℂ → ℂ and constant c with Re c < 0, the Finset.range partial products of 1 + exp(E z + k c) converge locally uniformly on ℂ to the tprod. On each compact K the factor norms are dominated by the summable geometric e^{M_K}·(e^{Re c})^k; hasProdLocallyUniformlyOn_of_forall_compact glues the compacts.
