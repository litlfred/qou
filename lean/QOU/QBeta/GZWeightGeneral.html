    Knot-independent Garoufalidis–Zagier weight rule, and its 5₂ instance #

    The merged QOU.QBeta.GZWeightSelection proved the weight-difference selection rule for the 4₁ connections. This file abstracts that rule to its knot-independent form — GZ eq. 3.7's automorphy weight κ(σ) = 3/2·[σ trivial] is universal (the 3/2 is the Kashaev N^{3/2}-prefactor exponent for any knot, ⟨K⟩_N ∼ N^{3/2}e^{vN}Φ, GZ eq. 1.1) — and instantiates it at 5₂, the non-amphichiral knot where the bar-odd A_ω actually lives.

    Why this matters for A_ω. The 5₂ GGM Stokes automorphisms S±(q) are assembled and the integer index Ind^{rot}_{5₂}(q) = 2·H⁺_{1,0}·H⁻_{1,0} = 1−12q+3q²+74q³+90q⁴ is extracted (probe qbeta_5two_stokes_barodd_index_probe.py, GGM 2007.10190 eq. 102, the (σ₁,σ₁) diagonal entry of S⁺). This file certifies — via the knot-independent weight rule — that this index is a genuine integer-exponent (b = 0) Stokes datum: the 5₂ geometric and conjugate saddles are both non-trivial, so any ray between them (the A_ω ray) has weight difference 0 ∈ ℤ, and b = ±3/2 would require the trivial connection as an endpoint — a different ray. It is the 5₂ analogue of the merged 4₁ weightDiff_aomega_zero, closing the "5₂ is the follow-up" note of PR #4213.

    Discipline: no fit; the weight values are the cited GZ definition, the selection rules are their algebraic consequences; the only 5₂-specific input is that the geometric/conjugate/real saddles are non-trivial (true — they are the non-abelian character-variety saddles, distinct from the trivial connection). Nothing wired; conj:algebraic-geometric-dilog-equivalence stays open. Verified lean-direct (exit 0).
