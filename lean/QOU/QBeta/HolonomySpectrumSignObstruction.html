    theorem QOU.QBeta.two_le_add_inv {x : ℝ} (hx : 0 < x) :
    2 ≤ x + x⁻¹

    x + x⁻¹ ≥ 2 for positive x — the whole obstruction in one line, and the reason it cannot be evaded by choosing residues: it holds for every positive x, so every real generator eigenvalue is caught.

    theorem QOU.QBeta.real_spectrum_character_ge_one (a : ℝ) :
    1 ≤ (Real.exp a + Real.exp (-a)) / 2

    A holonomy with real spectrum has character at least 1. If the generator's eigenvalues are ±a with a real, the normalised character tr M / 2 is cosh a ≥ 1.

    This is the residue-independent step: it is quantified over all real a, so a q-dependent residue only changes which a occurs and the bound is unmoved.

    theorem QOU.QBeta.correction_below_one_excludes_real_spectrum {κ a : ℝ} (hκ : κ < 1) :
    κ ≠ (Real.exp a + Real.exp (-a)) / 2

    Hence a sub-unit correction excludes every real-spectrum holonomy. The measured correction is 0.998…< 1, so no real a reproduces it.

    theorem QOU.QBeta.kd_character_sub_one {q : ℝ} (hq : 0 < q) :
    (q + q⁻¹) / 2 - 1 = (q - 1) ^ 2 / (2 * q)

    The Kohno–Drinfeld character at the substrate's real q, elementarily: (q + q⁻¹)/2 − 1 = (q−1)²/(2q). A square over a positive, so the character never drops below 1 — no analysis, no transcendence, no appeal to cosh.

    theorem QOU.QBeta.kd_holonomy_cannot_realise_subunit_correction {q κ : ℝ} (hq : 0 < q) (hκ : κ < 1) :
    κ ≠ (q + q⁻¹) / 2

    The punchline. With ħ = 2 ln q at real q > 0, the holonomy character is (q + q⁻¹)/2 ≥ 1, so it cannot equal a correction strictly below 1.
