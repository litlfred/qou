    QOU.QBeta.MarkovFrobeniusCollapse.General #

    Min-Frobenius-norm collapse over a general unital R-algebra.

    Base ring (§7c) #

    The statement is S² ≤ τ(X·X): a square and an order comparison, nothing archimedean. The file's own docstring already said "general unital R-algebra" while the code read ℝ, so the scalars are now a generic ordered ring. The same bound is proved sorry-free over [Field R] [LinearOrder R] [IsStrictOrderedRing R] in the sibling mass-theory/t-beta-markov-collapse-general-lift.lean (markov_frobenius_min_norm_lift, via completing-the-square + PSDTrace), which is the generality this file records.
