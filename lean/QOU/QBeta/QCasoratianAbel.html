    theorem QOU.QBeta.casoratian_abel {R : Type u_1} [CommRing R] (a b c f₀ f₁ f₂ g₀ g₁ g₂ : R) (hf : a * f₂ + b * f₁ + c * f₀ = 0) (hg : a * g₂ + b * g₁ + c * g₀ = 0) :
    a * (f₁ * g₂ - f₂ * g₁) = c * (f₀ * g₁ - f₁ * g₀)

    q-Casoratian (Abel) law — pointwise form.

    For a second-order linear q-difference equation a·h₂ + b·h₁ + c·h₀ = 0 (values of h at q²w, qw, w), two solutions f, g have Casoratian values C₀ = f₀ g₁ − f₁ g₀ at w and C₁ = f₁ g₂ − f₂ g₁ at qw satisfying

    a · C₁ = c · C₀.

    The middle coefficient b drops out — only the outer coefficients a (at q²w) and c (at w) survive, which is what makes the Casoratian a first-order q-recurrence. Proof is the elimination of the q²w values via the two equations, then ring.

    theorem QOU.QBeta.qbessel_casoratian_qabel {R : Type u_1} [CommRing R] (w qpow f₀ f₁ f₂ g₀ g₁ g₂ : R) (hf : qpow * f₂ - (1 + qpow - w) * f₁ + f₀ = 0) (hg : qpow * g₂ - (1 + qpow - w) * g₁ + g₀ = 0) :
    qpow * (f₁ * g₂ - f₂ * g₁) = f₀ * g₁ - f₁ * g₀

    Specialisation to the Hahn–Exton q-Bessel equation (☆).

    With a = q^ν (here the abstract parameter qpow := q^ν), b = −(1 + q^ν − w), c = 1, the Casoratian satisfies qpow · C₁ = C₀, i.e. C(qw) = qpow⁻¹ · C(w). Iterating this first-order q-recurrence yields the monomial form C(w) = const · w^{-ν} that the coincidence propagator G_q = g₁ g₂ / D and the reduction-of-order second solution rely on.
