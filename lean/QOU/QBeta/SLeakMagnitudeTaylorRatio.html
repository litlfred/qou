    theorem QOU.QBeta.SLeakMagnitudeTaylorRatio.cofactor_is_normalized_deviation {S g : ℝ → ℝ} {L qstar qp : ℝ} (hS : ∀ (q : ℝ), S q = L * (q - qstar) * g q) (hL : L ≠ 0) (hqp : qp - qstar ≠ 0) :
    S qp / (L * (qp - qstar)) = g qp

    The cofactor is the forced deviation from the linear model. Given the factorization S(q) = L·(q − q*)·g(q) of a function with a simple zero at q* (slope L ≠ 0), the cofactor g at any qp ≠ q* equals the multiplicative deviation S(qp) / (L·(qp − q*)) of S from its leading linear model. So g is not a free ansatz — it is pinned by the factorization, and the normalization g(q*) = 1 (used below) is the statement that this deviation is 1 at the zero.

    theorem QOU.QBeta.SLeakMagnitudeTaylorRatio.exact_ratio_factorization {S g : ℝ → ℝ} {L qstar qm qp : ℝ} (hS : ∀ (q : ℝ), S q = L * (q - qstar) * g q) (hL : L ≠ 0) (hqm : qm - qstar ≠ 0) (hgm : g qm ≠ 0) :
    S qp / S qm = (qp - qstar) / (qm - qstar) * (g qp / g qm)

    Exact ratio factorization (slope cancels, cofactor exact). For a function with the simple-zero factorization S(q) = L·(q − q*)·g(q) (L ≠ 0), and anchors qm ≠ q* with g(qm) ≠ 0, the exact ratio of two evaluations factors as the product of the anchor-offset ratio and the cofactor ratio:

    S(qp)/S(qm) = (qp − q*)/(qm − q*) · g(qp)/g(qm).

    The slope L drops out entirely — sharpening linear_ratio_slope_independent from the leading-order (g ≡ 1) case to the full cofactor. This is the identity the Route-A probe evaluates order-by-order in the Taylor truncation of g.

    theorem QOU.QBeta.SLeakMagnitudeTaylorRatio.offset_ratio_error_is_cofactor {S g : ℝ → ℝ} {L qstar qm qp : ℝ} (hS : ∀ (q : ℝ), S q = L * (q - qstar) * g q) (hL : L ≠ 0) (hqm : qm - qstar ≠ 0) (hgm : g qm ≠ 0) :
    S qp / S qm - (qp - qstar) / (qm - qstar) = (qp - qstar) / (qm - qstar) * (g qp / g qm - 1)

    The leading offset-ratio error is exactly the cofactor deviation. The error of approximating the exact ratio S(qp)/S(qm) by the leading anchor-offset ratio (qp − q*)/(qm − q*) equals (qp − q*)/(qm − q*) · (g(qp)/g(qm) − 1). This is the closed form of the probe's order-0 residual (≈ 6.18e-7): the leading offset ratio matches the exact magnitude only to the extent the cofactor ratio g(qp)/g(qm) departs from 1, so each Taylor order restored to g shrinks the miss.

    theorem QOU.QBeta.SLeakMagnitudeTaylorRatio.linear_model_relative_error {S g : ℝ → ℝ} {L qstar qp : ℝ} (hS : ∀ (q : ℝ), S q = L * (q - qstar) * g q) (hL : L ≠ 0) (hqp : qp - qstar ≠ 0) (hg1 : g qstar = 1) :
    (S qp - L * (qp - qstar)) / (L * (qp - qstar)) = g qp - g qstar

    Linear-model relative error under the normalization g(q*) = 1. With the cofactor normalized so that g(q*) = 1, the relative error of the leading linear model L·(qp − q*) against the exact S(qp) is exactly g(qp) − g(q*), the cofactor's increment away from its value at the zero. This quantifies why one Taylor order in g buys several digits: the linear model's miss is the cofactor's own departure from the normalized 1 at q*.
