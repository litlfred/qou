    Route 33 measured this identification at 1e-50 and named what Lean was missing per regime. All of it is now proved. The three regimes needed three different things:

    regime what it needed
    0 < x < 1 nothing — the series converges, cLiTwo_ofReal bridges
    x < 0 Landen's identity, landenCombo_ofReal_eq_zero

    The statement, per regime #

    The left side is the corpus's piecewise extension, built on the real LiTwo (a tsum, hence the junk value 0 outside its disc of convergence). The right side is Re of the analytic Rogers L, principal branches throughout. extended_sum is stated for the left; the level-7 bridge computes with the right. Identifying them is what item 4 asks for.

    Why Landen is exactly the input #

    Write u = x/(x−1). For x < 0 that lands in (0,1), where the series converges and cLiTwo_ofReal bridges LiTwo to cLiTwo. Two log identities then do all the bookkeeping:

    log(1−u) = −log(1−x)          because `1 − u = 1/(1−x)`
log u    = log(−x) − log(1−x) because `u = (−x)/(1−x)`

    so that

    rogersL u = Li₂ u − ½·log(−x)·log(1−x) + ½·log(1−x)²

    and Landen — Li₂ x + Li₂ u + ½·log(1−x)² = 0 — replaces Li₂ u, leaving

    rogersL u = −Li₂ x − ½·log(−x)·log(1−x) = −Re L(x)

    since Re log x = log(−x) for x < 0 (the iπ in log x meets a real log(1−x), so it contributes nothing to the real part). Then extend x = −rogersL u = Re L(x).

    The iπ not contributing is worth stating rather than passing over: it is the same −t-on-log's-cut phenomenon that produced corrections 5 and 6 in the transport lane. Here it is harmless, and because the partner factor is real — not because the cut was avoided.

    Scope — what this closes, and what it does NOT #

    Closed: qou-rstq item 4. extended_sum is stated for the piecewise extend; the level-7 bridge computes with the analytic Re L. This is the identification that lets them talk to each other, and it now covers every argument either of them uses.

    NOT closed, and unchanged by this file:

    • the 5₂ sum rule itself — item 4 was one input to the level-7 bridge, not the sum rule;
    • Gap A, the globally differentiable root labelling (qou-glbl), still the one open hypothesis in the transport;
    • assembling S(π) and wiring corr_sum_eq_neg_pi_sq to extended_sum (qou-asem) — that composition is now unblocked but is not written.

    An earlier draft of this file said the inversion regime "needs a genuine boundary value rather than a constant of integration". That was wrong — Route 35 showed Re L is continuous across the cut, so there was no limit to take. The correction is recorded in qou-invr rather than quietly deleted.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.
