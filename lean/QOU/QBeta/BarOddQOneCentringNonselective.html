    QOU.QBeta.BarOddQOneCentringNonselective — "centred at q=1" selects no fibre element #

    Formalize-first honest negative for the fibre-level survivor of the owner's saddle-vector picture (qou-q86o).

    After the sibling gates:

    • IotaOddSaddleOffsetAmphichiral (#4577) — the certified saddle offset o = c⁺ − c⁻ vanishes iff the knot is (ι-fixed) amphichiral, modelling the chirality swap (a,b) ↦ (b,a) as the involution;
    • SaddleOffsetBarGrade (#4583) — that certified offset is not a q ↔ q⁻¹ bar-odd Laurent object (its q→0 constant coefficient is the certified datum chiralityOdd 4 3 = 1 ≠ 0, whereas a genuinely q↔q⁻¹-odd object has zero constant coefficient),

    the picture is refuted as an archimedean / DT claim but is said to survive at the fibre level: a Habiro-ring / cyclotomic-completion element F(q) whose q ↔ q⁻¹ bar-odd part has forced-zero bar-fixed coefficient degree (n = 0 / constant term — the fibre reading of "centred at q = 1"; evaluation at the involution's fixed points q = ±1 is a distinct statement) by construction, whose root-of-unity / substrate evaluations would reproduce the certified {3,4} / DT data.

    This file states, sorry-free, the structural reason there is no DERIVED such element — only a vacuous-or-fit dichotomy. The q ↔ q⁻¹ involution acts on a Laurent-coefficient sequence g : ℤ → R by n ↦ -n; its only fixed degree is n = 0 (the q→0 / semiclassical datum). Consequently:

    • Vacuous horn. "vanishes at the bar-fixed degree" is implied by bar-oddness for the entire class (q1_centring_nonselective): adding the "centred at q=1" constraint to bar-oddness selects no element, so it cannot single out the knot's saddle vector — the centring is content-free. And the fixed datum does not even pin the element (centring_underdetermined): distinct bar-odd sequences share it.
    • Fit horn. The certified {3,4} DT datum is chiralityOdd 4 3 = 1 ≠ 0, which cannot be the bar-fixed-degree coefficient of any bar-odd object (certified_datum_not_barOdd_fixedDegree) — so recovering it must come from the non-fixed degrees (root-of-unity evaluations), which bar-oddness leaves free. That freedom is the Habiro-ring flexibility the anti-fit discipline forbids passing off as a derivation.

    Neither horn is a derivation: a bar-odd element realising only q=1 centring is content-free (vacuous horn); one additionally reproducing the {3,4} datum is a fit (fit horn). See the audit doc for the four-pillar synthesis (this file is pillar 1; #4583, HabiroMagnitudeA3 substrate-wall, and the q-exact StokesSymmetryConstant no-resurgent-tail keystone are pillars 2–4).

      Bar-fixed-degree vanishing (generic). A q↔q⁻¹-odd Laurent object has zero coefficient at the unique bar-fixed degree n = 0 (its constant term). (Evaluation of the Laurent object at the involution's fixed points q = ±1 is a distinct statement — not what is proved here — so the docstring claims only the n = 0 coefficient fact.)

      Non-selectivity: "centred at q=1" adds nothing to bar-oddness #

      source
      theorem QOU.QBeta.BarOddQOneCentringNonselective.q1_centring_nonselective {R : Type u_1} [CommRing R] [Invertible 2] (g : ℤ → R) :
      BarAntisym g ↔ BarAntisym g ∧ g 0 = 0

      The centring is non-selective. For any bar-odd g, the constraint "vanishes at the bar-fixed degree" (g 0 = 0, the q = 1 centring) is already implied — so BarAntisym g and BarAntisym g ∧ g 0 = 0 are equivalent. Imposing the owner's "origin-centred at q = 1" on a bar-odd fibre element selects no element: the property is content-free, hence cannot pick out the knot's saddle vector.

      theorem QOU.QBeta.BarOddQOneCentringNonselective.centring_underdetermined :
      ∃ (g₁ : ℤ → ℤ) (g₂ : ℤ → ℤ), BarAntisym g₁ ∧ BarAntisym g₂ ∧ g₁ 0 = g₂ 0 ∧ g₁ ≠ g₂

      Under-determination. The bar-fixed datum does not pin the element: two distinct bar-odd sequences (n ↦ n and n ↦ 2n) share the same bar-fixed coefficient g 0 = 0. A fortiori the centring cannot determine the saddle vector; the discriminating content must come from the non-fixed (root-of-unity) degrees, which bar-oddness leaves free.
