    phiBProd denominator lower bound ⇒ unconditional strip bound (growth epic, brick G2 + G3) #

    Route-B brick G2 of the Faddeev growth-estimate epic (qou-mz4f): the denominator product's lower bound, the one genuine estimate the scoping doc flagged. Combined with G1 (PhiBProdStripBound, merged) it discharges the δ hypothesis of the conditional G3, giving the unconditional phiBProd strip bound.

    • norm_tprod_one_add_ge (general): exp(∑' log(1 − ‖gₖ‖)) ≤ ‖∏' (1 + gₖ)‖ when every ‖gₖ‖ < 1 — from ‖1 + g‖ ≥ 1 − ‖g‖ > 0, log monotone, and ∏‖·‖ = exp(∑ log‖·‖).
    • G2 — norm_tprod_denFactor_ge: the denominator lower bound, valid where every ‖denFactorₖ − 1‖ < 1 (deep-strip regime, e.g. large Im z in the dual direction).
    • G3 unconditional — norm_phiBProd_le: ‖phiBProd b z‖ ≤ exp(∑' ‖numFactorₖ − 1‖) · exp(−∑' log(1 − ‖denFactorₖ − 1‖)), with no carried δ hypothesis — the denominator lower bound supplies it internally.

    Verified lean-direct against the pinned Mathlib Log.Summable + InfiniteSum.Field cones + PhiBProd. Sorry-free.

    theorem QOU.QBeta.PhiBProdStripLowerBound.norm_tprod_one_add_ge {g : ℕ → ℂ} (hg : Summable fun (k : ℕ) => ‖g k‖) (hsmall : ∀ (k : ℕ), ‖g k‖ < 1) :
    Real.exp (∑' (k : ℕ), Real.log (1 - ‖g k‖)) ≤ ‖∏' (k : ℕ), (1 + g k)‖

    General product-norm lower bound. For a norm-summable complex family g with every ‖gₖ‖ < 1, exp(∑' k, log(1 − ‖gₖ‖)) ≤ ‖∏' k, (1 + gₖ)‖. Proof: ‖∏‖ = ∏‖·‖; each ‖1 + gₖ‖ ≥ 1 − ‖gₖ‖ > 0; log monotone; ∏‖1+gₖ‖ = exp(∑ log‖1+gₖ‖).
