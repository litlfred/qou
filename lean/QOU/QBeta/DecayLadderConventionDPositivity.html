        noncomputable def QOU.QBeta.DecayLadderConventionDPositivity.ladderPhaseCoeff (z : ℝ) :
        ℝ

        The Q_β ladder's affine phase coefficient, 1/2 − z.

        The ladder's phase satisfies α = (z−1)h/2 = −h/4 − (h/2)·(1/2 − z), pure algebra, so this is the single quantity through which the Markov parameter z reaches the ladder.

        This is not a Wedderburn weight. It was previously named threeRowMiddleWeight and identified with the standard-block weight y_(2,1) of H₃(q); that identification is retracted — see the module docstring. The vector (z, 1/2 − z, z) satisfies only the normalisation condition of CanonicalMarkovWeightsH3 and fails the other two, and the actual y_(2,1) under convention D is q²/(q²+1)² > 0. No positivity claim about any Markov trace follows from the sign of this coefficient.

          theorem QOU.QBeta.DecayLadderConventionDPositivity.zD_gt_half (q : ℝ) (hq : 1 < q) :
          1 / 2 < zD q

          z_D(q) > 1/2 on the whole substrate regime q > 1.

          The cubic 2q³ − q² − 1 factors as (q − 1)(2q² + q + 1), whose second factor is positive for all real q; so the inequality is strict and holds for every q > 1, degenerating to equality only at the classical point q = 1.

          The two conventions sit on opposite sides of z = 1/2.

          Capstone: for every substrate value q > 1 the ladder's affine phase coefficient is positive at z_C and negative at z_D. There is no q > 1 at which the two agree in sign, so the C ladder's phase formula cannot be transported to D by substituting the parameter.

          This is a statement about one ansatz's phase, not about either trace. The earlier reading — that it separates the conventions by positivity of a Wedderburn weight — is retracted (module docstring): under convention D the H₃(q) weights are positive semidefinite, signature (5, 0, 1), per S2 (PR #5185).

          z_D in Temperley–Lieb form #

          The Markov parameter of convention D is q² divided by the quantum integer [2]_q = q + q⁻¹ — the loop parameter δ of the Temperley–Lieb algebra. The identity is purely algebraic: q + q⁻¹ = (q² + 1)/q, so q²/(q + q⁻¹) = q³/(q² + 1) = z_D.

          This is recorded because it is the shape of z_D, not evidence for a mechanism. Whether the D-frame trace actually factors through TL_n is a hypothesis under test (S2's front, PR #5185, corank data at n = 3, 4, 5 only); this lemma is one algebraic input to that question and settles none of it. See the audit doc §6.

          Stated over a generic field per AGENTS.md §7c — no ordering, no Real.sqrt, nothing archimedean is involved. The ℝ corollary is the specialisation. (The convention-C mirror z_C = 1/[2]_{√q} is not stated generically: it needs Real.sqrt, so it lives on the archimedean side of the wall.)
