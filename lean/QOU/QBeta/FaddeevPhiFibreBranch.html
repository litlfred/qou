    class QOU.QBeta.FaddeevPhiFibreBranch.CyclicFaddeevPhi {K : Type u_1} [Field K] (ζ : K) (N : ℕ) (D : K → K) :
    Prop

    Fibre-branch Faddeev-Φ shift structure (the root-of-unity / |q| = 1 analog of QOU.MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi).

    A carrier D : K → K (think D x = (x;ζ)_N, the finite q-Pochhammer denominator) at a primitive N-th root of unity ζ satisfies the two multiplicative shift laws that genuinely hold on the cyclic branch:

    • shift_factor — the finite boundary-trade law, the honest finite analog of the Faddeev shift Φ(q²x) = (1 + qx)Φ(x): scaling the argument by ζ trades the bottom boundary factor (1 − x) for the top factor (1 − x·ζ^N).
    • periodic — the exact N-periodicity D(ζ·x) = D(x), in which the (1 + qx)-type multiplier of the infinite Faddeev shift is absorbed by the cyclic wrap-around (ζ^N = 1 makes the top and bottom boundary factors cancel).

    Both fields carry genuine content (neither is True or an empty marker), per the §3b-tax "carrier must assert something" rule. The class is discharged unconditionally by cyclicFaddeevPhi_cyclic below.

    • hN : 0 < N

      N > 0 (the cyclic order is positive — the fibre analog of FaddeevPhi's 0 < b.re, i.e. a nondegenerate modular parameter).

    • hζ : IsPrimitiveRoot ζ N

      ζ is a primitive N-th root of unity — the |q| = 1 fibre datum.

    • shift_factor (x : K) : (1 - x) * D (ζ * x) = (1 - x * ζ ^ N) * D x

      Finite boundary-trade shift law (finite analog of the Faddeev Φ(q²x) = (1 + qx)Φ(x) shift).

    • periodic (x : K) : D (ζ * x) = D x

      Exact N-periodicity at the root of unity: the infinite-shift multiplier is absorbed by the cyclic wrap-around.
