    Garoufalidis–Zagier weight-difference selection rule for the 4₁ Stokes rays #

    Formalize-first resolution of the β = 3/2 failure in the A_ω odd-channel attack. The corpus probe qbeta_modular_resurgence_stokes_probe.py tested a Borel loggamma exponent β = 3/2 against the geometric–conjugate κ-ladder and it failed (β_inf ≈ 0.2–0.26, docs/audits/2026-07-18-g3-stokes-keystone-evidence-base.md). The literature says why: 3/2 is a type error here.

    The 3/2 is the Garoufalidis–Zagier modular weight κ(σ₀) of the trivial connection — the automorphy-factor exponent of the Kashaev N^{3/2} prefactor (⟨K⟩_N ∼ N^{3/2} e^{v N} Φ(2πi/N), GZ eq. 1.1; the weight κ(σ) = 3/2 iff σ = σ₀, else 0, GZ eq. 3.7). It is not the characteristic exponent of a single Borel singularity. The Borel exponent of a Stokes ray joining connections σ, σ′ is the weight difference b = κ(σ) − κ(σ′).

    The A_ω singularity sits at ω = Vol(4₁)/π, the geometric ↔ conjugate ray (σ₁ ↔ σ̄₁, GGM 2007.10190) — both non-trivial, both weight 0 — so its Borel exponent is the integer b = 0, and its Stokes constant is the integer DT/BPS 3d-index count [q⁰] Ind^{rot}_{4₁} = 3 (GGM Conj. 2), not a half-integer-weight modular datum. A value b = ±3/2 can occur only on a σ₀ ↔ (non-trivial) ray — a different singularity than A_ω. So testing β = 3/2 against the geometric–conjugate ladder was a category error.

    This file encodes GZ eq. 3.7's weight function on the three relevant 4₁ connections and derives the selection consequences over the finite connection type. No fit; the weight values are the cited GZ definition, the selection rules are their algebraic consequences. Verified lean-direct (exit 0).

          theorem QOU.QBeta.GZWeightSelection.weightDiff_eq_zero_iff (σ σ' : FlatConn) :
          weightDiff σ σ' = 0 ↔ (σ = FlatConn.sigma0 ↔ σ' = FlatConn.sigma0)

          Integer-exponent selection rule. The Borel exponent b = κ(σ) − κ(σ′) is 0 (the only integer value it takes) iff the two connections lie on the same side of triviality — both trivial or both non-trivial. The A_ω ray (both non-trivial) is on the integer branch; every σ₀-ray is on the half-integer branch.
