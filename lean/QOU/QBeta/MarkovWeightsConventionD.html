    The weights, denominator-cleared #

    Writing W = (q²+1)² for the common denominator, the convention-D weights are carried as their numerators: Y₃ = q⁴+1, Y₂₁ = q², Y₁₃ = 0, with the Markov parameter as Z = q³ over q²+1. Every statement below is the cross-multiplied form, so it holds over any CommRing.

    source
    theorem QOU.QBeta.markovWeightsD_norm {R : Type u_1} [CommRing R] (q : R) :
    q ^ 4 + 1 + 2 * q ^ 2 + 0 = (q ^ 2 + 1) ^ 2

    Normalisation. y_(3) + 2·y_(2,1) + y_(1³) = 1, cleared: the three numerators sum to W = (q²+1)². Note y_(1³) contributes nothing — the two-row weights alone already saturate the normalisation.

    source
    theorem QOU.QBeta.markovWeightsD_sigma {R : Type u_1} [CommRing R] (q : R) :
    q * (q ^ 4 + 1) + (q ^ 3 - q) + 0 = q ^ 3 * (q ^ 2 + 1)

    First Markov equation (tr(σ) = z), cleared by W. With h = q − q⁻¹ the q⁻¹ cancels: (q − q⁻¹)·q² = q³ − q, so the identity is polynomial. Right-hand side is z_D·W = q³(q²+1).

    source
    theorem QOU.QBeta.markovWeightsD_sigmasq {R : Type u_1} [CommRing R] (q : R) :
    q ^ 2 * (q ^ 4 + 1) - q ^ 2 + 0 = q ^ 6

    Second Markov equation (tr(σ²) = z²), cleared by W. The y_(2,1) eigenvalue is −1 and y_(1³) drops, leaving q⁶ = (z_D·W)²/W.

    source
    theorem QOU.QBeta.markovWeightsD_zsq {R : Type u_1} [CommRing R] (q z : R) (hz : z * (q ^ 2 + 1) = q ^ 3) :
    z ^ 2 * (q ^ 2 + 1) ^ 2 = q ^ 6

    z_D squared is consistent with the cleared right-hand side above. (z·(q²+1))² = (q³)² expands to z²·W = q⁶, matching markovWeightsD_sigmasq.

    Bar parity of the surviving weights #

    bar sends q ↦ q⁻¹. Carrying q⁻¹ as qi with q·qi = 1, a weight Y/W is bar-even iff bar(Y)·W = Y·bar(W), which is the form proved below. Both surviving weights are bar-EVEN — there is no bar-odd part anywhere in the D-frame weight data.

    source
    theorem QOU.QBeta.markovWeightsD_y21_barEven {R : Type u_1} [CommRing R] (q qi : R) (h : q * qi = 1) :
    qi ^ 2 * (q ^ 2 + 1) ^ 2 = q ^ 2 * (qi ^ 2 + 1) ^ 2

    y_(2,1) is bar-EVEN. bar(q²/(q²+1)²) = q²/(q²+1)², in the cross-multiplied form qi²·(qi²+1)⁻¹-free: qi² · (q²+1)² = q² · (qi²+1)².

    source
    theorem QOU.QBeta.markovWeightsD_y3_barEven {R : Type u_1} [CommRing R] (q qi : R) (h : q * qi = 1) :
    (qi ^ 4 + 1) * (q ^ 2 + 1) ^ 2 = (q ^ 4 + 1) * (qi ^ 2 + 1) ^ 2

    y_(3) is bar-EVEN. bar((q⁴+1)/(q²+1)²) = (q⁴+1)/(q²+1)², i.e. (qi⁴+1)·(q²+1)² = (q⁴+1)·(qi²+1)².

    source
    theorem QOU.QBeta.markovWeightsD_barEven_combination {R : Type u_1} [CommRing R] (a b abar bbar Y₃ Y₂₁ Y₃bar Y₂₁bar : R) (ha : abar = a) (hb : bbar = b) (h3 : Y₃bar = Y₃) (h21 : Y₂₁bar = Y₂₁) :
    abar * Y₃bar + bbar * Y₂₁bar = a * Y₃ + b * Y₂₁

    The prune, as a statement about what is available. Every D-frame weight is bar-even (the two above; the third is 0, which is bar-even trivially). So any R-linear combination of the D-frame weights is bar-even, and in particular no such combination supplies the bar-ODD eigenphase the C-frame ladder uses.

    Stated as: if f is built from the weights by a map that commutes with bar — here, any linear combination with bar-even coefficients — then f is bar-even. The content is the two lemmas above; this records the conclusion they are for.
