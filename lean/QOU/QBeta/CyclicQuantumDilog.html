    Finite q-Pochhammer denominator (x;ζ)_N = ∏_{k=0}^{N-1}(1 - x·ζ^k). This is the finite root-of-unity truncation of the analytic q-Pochhammer denominator; by cyclicDenom_eq it collapses to the polynomial 1 - x^N.

        theorem QOU.QBeta.CyclicQuantumDilog.cyclicDenom_shift_factor {K : Type u_1} [Field K] (ζ x : K) (m : ℕ) :
        (1 - x) * cyclicDenom ζ (ζ * x) m = (1 - x * ζ ^ m) * cyclicDenom ζ x m

        Finite shift factor law (the honest finite analog of the Faddeev shift Φ(q²x) = (1 + qx)Φ(x)). For every truncation length m — no root-of-unity hypothesis — scaling the argument by ζ trades the bottom boundary factor (1 - x) for the top boundary factor (1 - x·ζ^m):

        (1 - x) · cyclicDenom ζ (ζ·x) m  =  (1 - x·ζ^m) · cyclicDenom ζ x m .

        Both sides equal the length-(m+1) product ∏_{k=0}^{m}(1 - x·ζ^k): the left side reconstructs it by prepending the k = 0 factor to the shifted family, the right side by appending the k = m factor to the unshifted family.

        theorem QOU.QBeta.CyclicQuantumDilog.cyclicDenom_shift {K : Type u_1} [Field K] {ζ : K} {N : ℕ} (hN : 0 < N) (hζ : IsPrimitiveRoot ζ N) (x : K) :
        cyclicDenom ζ (ζ * x) N = cyclicDenom ζ x N

        Exact N-periodicity of the denominator at the root of unity: scaling the argument by ζ (a full rotation of the cyclic factor family) leaves the finite denominator invariant. Equivalently, the reindex

        ∏_{k<N}(1 - x·ζ^{k+1}) = ∏_{k<N}(1 - x·ζ^k)

        holds because ζ^N = 1. Proved via the collapse cyclicDenom = 1 - x^N: (ζ·x)^N = ζ^N·x^N = x^N.

        theorem QOU.QBeta.CyclicQuantumDilog.cyclicDilog_periodic {K : Type u_1} [Field K] {ζ : K} {N : ℕ} (hN : 0 < N) (hζ : IsPrimitiveRoot ζ N) (x : K) (j : ℕ) :
        cyclicDilog ζ (ζ ^ j * x) N = cyclicDilog ζ x N

        Full periodicity under scaling by any power ζ^j: Φ(ζ^j·x) = Φ(x). This is the "closes as a finite N-step recursion" statement — iterating the single ζ-shift cyclicDilog_shift j times leaves Φ unchanged, so the shift recursion is N-periodic (indeed period 1 in the ζ-scaling).
