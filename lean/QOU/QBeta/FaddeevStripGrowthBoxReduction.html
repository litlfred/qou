    theorem QOU.QBeta.FaddeevStripGrowthBoxReduction.norm_le_of_periodic_ballBound {r : ℂ → ℂ} {bas : Module.Basis (Fin 2) ℝ ℂ} {C : ℝ} (hper : ∀ (i : Fin 2) (z : ℂ), r (z + bas i) = r z) (hball : ∀ (w : ℂ), ‖w‖ ≤ ‖bas 0‖ + ‖bas 1‖ → ‖r w‖ ≤ C) (z : ℂ) :
    ‖r z‖ ≤ C

    A doubly-periodic function bounded on the fundamental ball is bounded everywhere. If r : ℂ → ℂ is periodic under both vectors of an ℝ-basis bas of ℂ, and ‖r w‖ ≤ C for every w in the closed ball of radius ‖bas 0‖ + ‖bas 1‖, then ‖r z‖ ≤ C for all z. Reducing the two ℝ-coordinates of z modulo 1 (Int.fract) lands z, up to a lattice translation r ignores, in that ball. The non-holomorphic modulus-bound analogue of const_of_doublyPeriodic.

    ‖r z‖ ≤ C ∧ 1 / C ≤ ‖r z‖

    Two-sided (comparability) form. If the ratio r is doubly-periodic and both ‖r‖ ≤ C and 1/C ≤ ‖r‖ hold on the fundamental ball, they hold globally. This is the FaddeevPhiStripGrowth.comparable shape (upper + lower modulus bound) reduced to the compact fundamental domain — the local Faddeev-asymptotic input that discharges the global strip-growth axiom (off phiBProd's zeros; divisor matching there is the separate same-divisor input).
