    The Jones normalisation under convention D #

    What markov-pair-z2 got wrong, and what the right statement is.

    That block asserts

    The value $z^2$ is the Jones polynomial of the Hopf link: $J_{\mathrm{Hopf}}(q) = -(q^{1/2} + q^{-1/2})\cdot z^2$

    and it is wrong three times over, only one of which is about the convention:

    1. Wrong link. z² = tr_M(σᵢσⱼ) for i < j. The closure of σ₁σ₂ in B₃ is the unknot, and the closure of σ₁σ₃ in B₄ is the two-component unlink. Neither is the Hopf link. The Hopf link is the closure of σ₁² in B₂, whose trace is tr_M(σ₁²) = hz + 1, not z².
    2. Wrong kind of object. A raw Markov-trace value is not a Jones polynomial. The invariant needs the loop factor δ^{n-1} and a framing correction q^{-2e}; without them the "value" is not even an invariant of the closure, since it changes under Markov stabilisation.
    3. Wrong loop parameter. The prefactor q^{1/2} + q^{-1/2} is [2]_{√q}, the loop value at half argument. The Temperley–Lieb loop value of the production trace is δ = [2]_q = q + q⁻¹. At q₀ these are 2.0027… and 2.010896866707122… — the same conflation as 1/δ = 0.4972905456… against the excised z_C = 0.4993203342….

    The theorem #

    For a braid β ∈ B_n with exponent sum e, the Jones polynomial of its closure is

    V(β̂)(t) = q^{-2e} · [2]_q^{n-1} · tr_M(β),        t = q^{-2}

    with no square roots anywhere. This file proves the algebraic core and checks it on four closures whose answers are known independently.

    Why convention D is exactly the right trace for this #

    The derivation turns on one identity, and it is the definition of convention D in disguise.

    Put eᵢ := q − σᵢ. From the Hecke quadratic relation σ² = hσ + 1 with h = q − q⁻¹,

    eᵢ² = q² − 2qσ + σ² = (q²+1) − (q+q⁻¹)σ = [2]_q · eᵢ

    so eᵢ is a Temperley–Lieb generator with loop parameter δ = [2]_q (tl_generator_sq). Its trace is tr_M(eᵢ) = q − z, and convention D says precisely

    (q − z) · [2]_q = 1        (`TemperleyLiebTower.loop_reciprocal`)

    i.e. tr_M(eᵢ) = 1/δ — the standard Temperley–Lieb Markov normalisation. The peel follows: tr_M(x eₙ) = (q − z) tr_M(x) = δ⁻¹ tr_M(x).

    So convention D is not compatible with the Jones/Temperley–Lieb trace; under eᵢ = q − σᵢ it is that trace. This is the content of the registry naming D "SU(2)/Temperley-Lieb (Jones) decomposition", made into an identity.

    The Kauffman dictionary #

    δ = −A² − A⁻² with A² = −q (kauffman_loop), hence t = A⁻⁴ = q⁻². The Hecke generator and the Kauffman bracket generator differ by a scalar: ρ(σᵢ) = (A/q)·σᵢ, since both have eigenvalue ratio −q² = −A⁴. That scalar, run against the writhe correction (−A³)^{-e}, collapses to q^{-2e} — every odd power of A cancels, which is why the final formula has no square roots even though the Kauffman variable does.

    Why this is a link invariant at all — and why D is forced #

    An earlier version of this file checked the formula on four closures and noted that the closure identifications (cl(σ₁σ₂) ⊂ B₃ is the unknot, and so on) were taken from standard theory rather than derived. That caveat is now unnecessary, and the reason is better than a formalisation of knot topology would have been.

    By Markov's theorem, two braids have the same closure exactly when they are related by conjugation and by stabilisation β ∈ B_n ↦ βσ_n^{±1} ∈ B_{n+1}. So a function of (β, e, n) that is invariant under those moves is a link invariant — no knots required. All three checks are algebra:

    • Conjugation. e and n do not change, and tr_M is cyclic (jonesV_conj). Free, for any Markov parameter.
    • Positive stabilisation. e ↦ e+1, n ↦ n+1, tr_M(βσ_n) = z·tr_M(β). Invariance is exactly q⁻²·[2]_q·z = 1 (jonesV_stabilise_pos).
    • Negative stabilisation. e ↦ e−1, n ↦ n+1. From the quadratic relation σ⁻¹ = σ − h (sigma_inv), so tr_M(βσ_n⁻¹) = (z−h)·tr_M(β), and invariance is exactly q²·[2]_q·(z−h) = 1 (jonesV_stabilise_neg).

    Both stabilisation conditions are not merely satisfied by convention D — each one, on its own, forces it (stab_pos_iff_conventionD, stab_neg_iff_conventionD, needing only q ≠ 0). That is the theorem this file is really about:

    Convention D is the unique Markov parameter for which q^{-2e}[2]_q^{n-1}tr_M is a link invariant.

    markov-pair-z2's prefactor q^{1/2}+q^{-1/2} is not a near-miss under this statement; with it the quantity is not an invariant of anything, because it fails to survive a stabilisation move.

    The four closure values are then corollaries worth keeping as sanity checks — they confirm the invariant is normalised so that the unknot is 1 — but they are no longer load-bearing, and nothing here assumes which link a given braid closes to.

    eᵢ := q − σᵢ is a Temperley–Lieb generator with loop parameter [2]_q.

    From the Hecke quadratic relation σ² = (q − q⁻¹)σ + 1 alone — no trace, no convention. This is what makes [2]_q the loop value and hence what makes q^{1/2} + q^{-1/2} the wrong prefactor in markov-pair-z2.

    Stated in an arbitrary R-algebra rather than a commutative ring: σᵢ does not commute with σⱼ, and the point is that this identity needs no such assumption, only that scalars are central (Algebra.commutes).

    theorem QOU.QBeta.JonesNormalisation.sigma_inv {R : Type u_1} [Field R] {A : Type u_2} [Ring A] [Algebra R A] (q : R) (s : A) (hs : s * s = (algebraMap R A) (q - q⁻¹) * s + 1) :
    s * (s - (algebraMap R A) (q - q⁻¹)) = 1 ∧ (s - (algebraMap R A) (q - q⁻¹)) * s = 1

    The inverse braid generator is σ − h. From the quadratic relation alone: σ(σ − h) = σ² − σh = (hσ + 1) − hσ = 1, and symmetrically on the left.

    This is what makes negative stabilisation computable without ever inverting anything: tr_M(σ⁻¹) = z − h.

    The normalisation, as scalar identities #

    V(β̂) = q^{-2e} · [2]_q^{n-1} · tr_M(β) evaluated on four closures whose Jones polynomials are known independently. Each is stated under IsConventionD and under nothing else, so each is a check that convention D — and not merely some Markov parameter — is what makes the normalisation land.

    source
    noncomputable def QOU.QBeta.JonesNormalisation.jonesFactor {R : Type u_1} [Field R] (q : R) (e m : ℕ) :
    R

    The Jones normalisation factor q^{-2e} · [2]_q^{m}, where m = n − 1 is the strand count less one.

    Carrying m rather than n is deliberate: n - 1 in ℕ is truncated subtraction, which would silently do the wrong thing at n = 0 and force a side condition on every lemma. With m the stabilisation moves are m ↦ m + 1 and nothing is ever subtracted.

        Markov invariance — the reason this is a link invariant #

        Markov's theorem: braid closures coincide exactly under conjugation and stabilisation. So invariance under those two moves makes jonesV a link invariant, with no knot theory in the statement. Each move turns out to force convention D.

        source
        theorem QOU.QBeta.JonesNormalisation.stab_pos_iff_conventionD {R : Type u_1} [Field R] (q z : R) (hq : q ≠ 0) :
        q⁻¹ ^ 2 * (q + q⁻¹) * z = 1 ↔ TemperleyLiebTower.IsConventionD q z

        Positive stabilisation ⟺ convention D. The move β ∈ B_n ↦ βσ_n ∈ B_{n+1} sends e ↦ e+1, m ↦ m+1 and multiplies the trace by z. Invariance is the single identity q⁻²·[2]_q·z = 1 — and that identity is equivalent to z(q²+1) = q³.

        Only q ≠ 0 is needed in either direction; no q² + 1 ≠ 0 side condition, because if q² + 1 = 0 then [2]_q = 0 and both sides are false.

        source
        theorem QOU.QBeta.JonesNormalisation.stab_neg_iff_conventionD {R : Type u_1} [Field R] (q z : R) (hq : q ≠ 0) :
        q ^ 2 * (q + q⁻¹) * (z - (q - q⁻¹)) = 1 ↔ TemperleyLiebTower.IsConventionD q z

        Negative stabilisation ⟺ convention D. The move β ↦ βσ_n⁻¹ sends e ↦ e−1, m ↦ m+1, and by sigma_inv multiplies the trace by z − h. Invariance is q²·[2]_q·(z−h) = 1, again equivalent to convention D.

        That the two stabilisations force the same z is not automatic — it is a consistency check on the whole normalisation, and it passes.

        The interface factorisation z^{p₊}(z−h)^{p₋} #

        prf:interface-knot-markov-z claims

        tr_M^FULL / tr_M^CONSTIT  =  z^{p₊} · (z − h)^{p₋}

        for an atom with p₊ positive and p₋ negative interface crossings. That claim is convention-independent — it is iterated Markov peel and holds for any Markov parameter — which is why regenerating its table under convention D should reproduce agreement to the same precision rather than break it. The two per-crossing factors are tr_M(σ) = z and tr_M(σ⁻¹) = z − h, the latter from sigma_inv (σ⁻¹ = σ − h, from the quadratic relation alone).
