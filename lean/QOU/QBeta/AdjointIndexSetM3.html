    QOU.QBeta.AdjointIndexSetM3 — the knot-INDEPENDENT core of the DT index set, and what it forces #

    Where this sits (Route C, milestone M3) #

    M2 (AomegaM2BPSCohomology) established — conditional on the DT/BPS bridge — that the closed-sector BPS spectrum would be abelian: every Borel ray distinct, trivial Davison–Meinhardt plethystic log, dim BPS_d = |Ω_d|, all multiplicities 1. That has a consequence worth stating plainly:

    If the spectrum is abelian with unit multiplicities, "categorifying" it is nearly content-free. A direct sum of one-dimensional spaces carries no information beyond which rays exist. So M3's real target is not "build a cohomological Hall algebra" — it is derive the index set Ω.

    That is a much sharper target than the CoHA framing, and it is what this file attacks.

    The observation that constrains any answer #

    M2 records the 4₁ index set as the meridian-charge polynomial s(x) = x + 1 + x⁻¹ (three unit-multiplicity states, charges e ∈ {−1,0,+1}), and the corpus records that the same s(x) governs 5₂ (GGM eqs 239/277/307: the 5₂ q→0 Stokes entries are s(x), s(x), s(x)+1). Knot-independence is the single hardest fact for any explanation to meet: it is exactly why every knot-specific invariant tried so far failed (Driver14CharacterVarietyDTMenu tests eight of them; Route A's R1 was the ninth).

    The hypothesis this file makes precise (NOT proved here) #

    H_Ad — the knot-independent core of the index set is the weight set of the adjoint representation of sl₂. For a meridian holonomy with eigenvalues (m, m⁻¹) and x = m², the adjoint (3-dimensional) representation has eigenvalues (x, 1, x⁻¹), so its character is exactly s(x) = x + 1 + x⁻¹, and at the parabolic point x = 1 its value is 3 = dim 𝔰𝔩₂.

    Why this is a mechanism and not a numerical coincidence:

    • In complex Chern–Simons theory the Borel singularities are differences of complex volumes of flat connections, and the deformation theory of a flat connection is governed by H¹(M, Ad ρ) — the adjoint local system is the canonical coefficient object, not a chosen one.
    • Ad(𝔰𝔩₂) is multiplicity-free with weights {2, 0, −2}, matching M2's sMultiplicities = [1,1,1] without adjustment.
    • It predicts knot-independence, which is the observed fact no knot-specific invariant could produce.
    • In QOU-native terms Ad ≅ Sym²V = S^{(2)}(ℂ²), the Schur–Weyl partner of the partition-(2) Wedderburn block of H₂(q) — so the hypothesis is expressible in Hecke language. (Partner, not the block: the block itself is 1-dimensional. See Part 3, where both dimensions are derived and this file's own earlier conflation of the two is corrected.)

    H_Ad is a hypothesis, not a derivation. Identifying the index set with a rep-theoretic object that is standard in the deformation theory is a structural reading; it does not derive the DT spectrum from Hecke data, and this file claims no such derivation.

    What IS proved here (decidable, no literature input in the general results) #

    The adjoint weight combinatorics, and — the load-bearing part — a forcing theorem: any knot-independent core, H_Ad included, cannot by itself produce the chirality-split (4₁, 5₂) ↦ (3, 4); it necessarily requires a knot-dependent remainder, and that remainder is forced to differ by exactly one between the two knots. This converts the otherwise-unfalsifiable move "add one more state for 5₂" into a structural requirement with a definite value, which any completion of H_Ad must independently derive.

    Part 2 then answers the obvious adversarial objection — "isn't H_Ad just Route A's R1 again?" — and the answer cuts both ways. It is not: R1 is the dtMax projection of the chirality-split datum and H_Ad's core is dtMin, so they read different halves, and the pair reconstructs the 2-element set {3,4} that no_scalar_matches_chirality_split_datum forbids any single scalar from naming. But the evidence is thinner than that makes it sound: 4₁'s amphichirality collapses dtMin onto dtMax, so the entire support for a knot-independent core is one observation (S⁻(5₂) = 3); and a rival hypothesis with no 𝔰𝔩₂ in it at all — the core is the {0, g, ḡ} triple every hyperbolic knot carries, i.e. R1's own universal floor — reproduces every H_Ad prediction, including a palindromic 3-element grading. Both are proved below. H_Ad stays a hypothesis, and it is not the only one standing.

                    Part 3 — the meridian grading, derived from Young-tableau combinatorics #

                    Part 2 left exactly one discriminator between H_Ad and its rival H_floor: the grading variable. H_floor grades by Chern–Simons value; H_Ad grades by meridian eigenvalue x = m². If the meridian grading falls out of QOU-native Hecke/Schur–Weyl data, H_Ad has a route H_floor does not.

                    It does — and getting there corrects an imprecision in this file's own earlier prose.

                    CORRECTION. Part 1's docstring said "Ad ≅ Sym²V, the partition-(2) Wedderburn block of H₂(q)". That conflates the two sides of Schur–Weyl duality. The partition-(2) block of H₂(q) has dimension #SYT((2)) = 1; it is one-dimensional, not three. What is three-dimensional is its Schur–Weyl partner S^{(2)}(ℂ²) = Sym²V on the quantum-group side of V^{⊗2} ≅ ⨁_λ S^λ(V) ⊗ M_λ. The 3 therefore lives on the U_q(𝔰𝔩₂) factor paired with the (2) block — not in the block itself. Both dimensions are derived below so the distinction cannot be lost again.

                    The payoff: the weight basis of S^{(2)}(ℂ²) is the set of semistandard Young tableaux of shape (2) on the alphabet {1,2}, and each tableau's weight is read off directly in the meridian variable — entry 1 contributes m, entry 2 contributes m⁻¹. So the meridian grading is combinatorial, not assumed.

                            Part 4 — the remainder is DERIVED from the trace field, and it is H_floor's win #

                            Part 1 proved that a knot-independent core forces a knot-dependent remainder, and said any completion "must derive that remainder independently". Part 2 named the rival H_floor. This part reports that H_floor does derive it — from the arithmetic of the trace field — which is a point against H_Ad, not for it.

                            Source (glyph-verified, corpus library/arxiv-2111.06645v3/2111.06645v3.pdf §2.1). Garoufalidis–Zagier describe P_K, the set of boundary-parabolic SL₂(ℂ) representations, for their three standard knots:

                            • 4₁ — P_K = {σ₀, σ₁, σ₂}; trace field ℚ(√−3), signature (0,1).
                            • 5₂ — P_K = {σ₀, σ₁, σ₂, σ₃}; trace field the cubic of discriminant −23, signature (1,1); σ₃ is the root with zero imaginary part.
                            • (−2,3,7) — P_K has seven elements: σ₀, the three from ℚ(ξ) (the same cubic as 5₂), and three more from ℚ(η), η³+η²−2η−1 = 0, the totally real abelian cubic of discriminant 49, signature (3,0).

                            So |P_K| = 3, 4, 7 — which reproduces R1's 4₁ ↦ 3, 5₂ ↦ 4 from a source independent of the A-polynomial, and extends it to a third knot.

                            The structural read that follows. H_floor's core is {σ₀, g, ḡ} = the trivial representation plus one complex-conjugate pair (the geometric one). Everything else in P_K is remainder. Counting embeddings by signature:

                            K reduced trace algebra real pairs \|P_K\| core remainder
                            4₁ ℚ(√−3) 0 1 3 3 0
                            5₂ cubic, disc −23 1 1 4 3 1
                            (−2,3,7) ℚ(ξ) × ℚ(η) 1+3 1+0 7 3 4

                            The 5₂ remainder of exactly 1 is therefore not an unexplained extra state: it is the single real embedding of the discriminant −23 cubic trace field, and 4₁'s remainder vanishes because its trace field is imaginary quadratic and has none. That is a derivation, from arithmetic, of the quantity Part 1 could only force.

                            Honest scoring. This strengthens H_floor and weakens the case for H_Ad on the count: H_floor now explains the number 3, predicts the remainder, and does so with no 𝔰𝔩₂ anywhere. H_Ad's remaining distinct content is what Part 3 established — the meridian grading s(x) = x + 1 + x⁻¹, which H_floor says nothing about. The two are best read as answering different questions (H_floor: why that many; H_Ad: why that polynomial) rather than as rivals for one.

                            Nothing here is a Hecke-internal derivation, so M3's actual target is untouched.
