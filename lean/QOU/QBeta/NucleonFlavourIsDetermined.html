    def QOU.QBeta.NucleonFlavour.pairCounts (nu nd : ℕ) :
    ℕ × ℕ × ℕ

    Pair-type counts for a three-quark content with n_u up and n_d down: (#uu, #ud, #dd). Each unordered pair of quarks is one crossing, typed by the two orientations.

      theorem QOU.QBeta.NucleonFlavour.flip_retypes_pairs (m n : ℕ) :
      (pairCounts m (n + 1)).1 + m = (pairCounts (m + 1) n).1 ∧ (pairCounts m (n + 1)).2.1 + n = (pairCounts (m + 1) n).2.1 + m ∧ (pairCounts (m + 1) n).2.2 + n = (pairCounts m (n + 1)).2.2

      β-decay retypes TWO pairs.

      A nucleon of m+1 ups and n downs becomes one of m ups and n+1 downs when a single up flips. The flipped quark belonged to m same-flavour pairs and n mixed pairs, so:

      • m pairs move uu → ud;
      • n pairs move ud → dd;
      • the C(m,2) + C(n,2) pairs not containing it are untouched.

      Stated additively to avoid truncated ℕ subtraction. At m = n = 1 — the proton — this is 1 + 1 = 2 retyped crossings out of three, which is what the census chains show.

      theorem QOU.QBeta.NucleonFlavour.two_shift_expansion {A : Type u_1} [Ring A] (X a Y b Z c : A) (hc : ∀ (x : A), c * x = x * c) :
      X * (a + c) * Y * (b + c) * Z - X * a * Y * b * Z = c * (X * Y * b * Z) + c * (X * a * Y * Z) + c * c * (X * Y * Z)

      The two-slot shift expansion.

      If two letters of a word each pick up the same central scalar c, the difference of the shifted and unshifted words is a three-term combination of words with one and both of those letters deleted:

      X(a+c)Y(b+c)Z − XaYbZ = c·(XYbZ) + c·(XaYZ) + c²·(XYZ)

      Stated over a noncommutative Ring — the braid algebra is not commutative — with centrality of c as an explicit hypothesis. Applied to the nucleons, c is the scalar −h/2 and the three right-hand words are the proton word with one or both flavour crossings smoothed.
