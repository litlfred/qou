      Continuing the branch conditions #

      The branch conditions are the delicate input, and the reason is that they are not identities — log a₃ = log(1−x) − log(1−xy) compares two sheets and Route 45 measured the pentagon drifting when they disagree. But the defect

      d₃(w) = log a₃(w) − log(1−w) + log(1−wy)

      is holomorphic wherever all three logarithms are, and its derivative vanishes identically: a₃′/a₃ + 1/(1−w) − y/(1−wy) = 0 as a rational function. So d₃ is locally constant, hence constant on any open connected region, hence 0 throughout a region containing one point where it vanishes.

      All five defects behave the same way, so the whole branch bookkeeping reduces to one geometric question: is there an open connected set of x on which the pentagon's arguments stay off both cuts and which reaches a base point? That is the honest residue of Routes 45–46 — not bookkeeping any more, but a statement about a region, and for the 5₂ saddle it is exactly where flattening can fail.

      ⚠ No such region is exhibited here for the 5₂ saddle values. What is proved is the propagation principle and the base point.
