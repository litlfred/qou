    §1. Convention D satisfies the full-bar condition bar(z) = z − h #

    source
    theorem QOU.QBeta.zD_full_bar_covariant {R : Type u_1} [CommRing R] (q qi : R) (h : q * qi = 1) :
    qi ^ 3 * (q ^ 2 + 1) = (q ^ 3 - (q - qi) * (q ^ 2 + 1)) * (qi ^ 2 + 1)

    bar(z_D) = z_D − h, division-free. With q⁻¹ carried as qi (q·qi = 1), the cross-multiplied form of qi³/(qi²+1) = q³/(q²+1) − (q − qi): both sides equal 1/(q³+q) as fractions, and the identity below is their denominator-cleared form. This is the z-level content of "convention D's Markov trace commutes with the full bar involution at the stabilisation step" — the trace-level premise (tr∘bar = bar∘tr) is NOT proved here.

    theorem QOU.QBeta.barEven_fullBar_forces_classical {R : Type u_1} [CommRing R] (q qi z zbar : R) (hqi : q * qi = 1) (heven : zbar = z) (hfull : zbar = z - (q - qi)) :
    q ^ 2 = 1

    A bar-EVEN Markov parameter satisfies the full-bar condition only at the classical point. If bar(z) = z (convention C's property, proved for z_C = √q/(1+q) in ZBarParity.z_bar_invariant) and bar(z) = z − (q − qi) (the full-bar condition), then q² = 1. Contrapositive: away from q² = 1, convention C fails the full-bar condition — the exact reverse of the coefficient-half verdict that had been read as favouring C.

    §1b. The ladder eigenphase inherits the parameter's bar parity #

    The Q_β precision ladder's N = 1 factor is cos(α − b·ℏ_q²/2) with the single-wrap eigenphase α = (z − 1)·h/2 (QOU.BraidKnot.QBetaCategoricalPrecisionLadder.alpha). Every bar-parity statement in the c_k record — (H1) c₃^even = −Vol(4₁), the S_leak program, q*_S, the KC13 prune — rests downstream of eigenphase_bar_involution, i.e. on α being bar-ODD.

    The two results below say that bar-oddness of α is exactly bar-evenness of z, and compute the defect when it fails. They are stated in the doubled variable 2α = (z − 1)·h so they stay division-free over any CommRing.

    Consequence for the convention ruling (bean qou-cds1). z_C is bar-even (ZBarParity.z_bar_invariant), so α is bar-odd and eigenphase_bar_involution holds — as a convention-C statement. z_D satisfies the full-bar condition instead (zD_full_bar_covariant), so under convention D the eigenphase is not bar-odd: its defect is exactly h², i.e. h²/2 on the undoubled α. This is a structural reason the C→D move cannot be a z-substitution: swapping z into the C-frame α keeps the formula while breaking the bar parity the formula's downstream consumers assume.

    theorem QOU.QBeta.eigenphase_barOdd_of_barEven {R : Type u_1} [CommRing R] (hk z zbar hbar : R) (heven : zbar = z) (hh : hbar = -hk) :
    (zbar - 1) * hbar + (z - 1) * hk = 0

    Bar-even parameter ⟹ bar-ODD eigenphase. With bar(h) = −h (immediate from h = q − q⁻¹), a bar-even z makes 2α = (z−1)h bar-odd: bar(2α) + 2α = 0. This is the convention-C case, and it is the hypothesis eigenphase_bar_involution encodes.

    source
    theorem QOU.QBeta.eigenphase_bar_defect_of_fullBar {R : Type u_1} [CommRing R] (hk z zbar hbar : R) (hfull : zbar = z - hk) (hh : hbar = -hk) :
    (zbar - 1) * hbar + (z - 1) * hk = hk ^ 2

    Full-bar parameter ⟹ eigenphase bar defect exactly h². If instead bar(z) = z − h (the full-bar condition, which z_D satisfies and a bar-even z cannot away from q² = 1 — barEven_fullBar_forces_classical), then bar(2α) + 2α = h² rather than 0.

    So the failure is not a perturbation to be estimated: it is an exact, z-independent remainder. Every parameter satisfying the full-bar condition has the SAME defect, so no choice within that family restores bar-oddness. The bar-odd projection of the D-frame eigenphase is therefore α − h²/4 (undoubled), which is a derived correction carrying no free parameter.

    theorem QOU.QBeta.zC_fails_fullBar {F : Type u_2} [Field F] [LinearOrder F] [IsStrictOrderedRing F] (s : F) (hs : 1 < s) :
    s⁻¹ / (1 + s⁻¹ ^ 2) ≠ s / (1 + s ^ 2) - (s ^ 2 - s⁻¹ ^ 2)

    z_C fails the full-bar condition on the substrate side. In the half-power coordinate s = √q with s > 1 (every substrate anchor has q > 1): bar(z_C) ≠ z_C − h, written out with bar acting as s ↦ s⁻¹ and h = q − q⁻¹ = s² − s⁻². Uses z_bar_invariant_field (bar-evenness of z_C); the failure is then exactly h ≠ 0.
