    Binding is a difference, and the trace is linear #

    source
    theorem QOU.QBeta.markov_trace_binding {ι : Type u_1} (s : Finset ι) (w chiAtom chiFree : ι → ℝ) :
    ∑ i ∈ s, w i * chiAtom i - ∑ i ∈ s, w i * chiFree i = ∑ i ∈ s, w i * (chiAtom i - chiFree i)

    The binding number is the trace of the binding operator. Trivial as algebra, and the whole point of the construction: because tr_M is linear, the subtraction can be done on the operators instead of on the numbers, and what comes out is an operator whose spectrum the numbers never saw.

    The blind sector #

    source
    theorem QOU.QBeta.blind_sector {ι : Type u_1} [DecidableEq ι] (s S : Finset ι) (w f g : ι → ℝ) (hw : ∀ i ∈ S, w i = 0) (hfg : ∀ i ∈ s, i ∉ S → f i = g i) :
    ∑ i ∈ s, w i * f i = ∑ i ∈ s, w i * g i

    The observable cannot see a zero-weight block. If the weights vanish on S, the weighted sum is identical for any two summands agreeing off S — whatever they do on S. At n = 6 under convention D, S is the seven partitions with more than two rows, and Δ_bind's character there is large (χ_{(3,2,1)} = −9.598, the biggest of any block) and contributes nothing.

        Why the blind sector is not merely unmeasured but unconstrained #

        source
        theorem QOU.QBeta.spectrum_not_determined_by_trace :
        IsElliptic 0 1 ∧ ¬IsElliptic 0 (-1)

        A weighted trace does not determine a spectrum. Two operators sharing every trace the corpus computes can differ in discriminant — one elliptic, one hyperbolic. So the eigenphases of a zero-weight block are not constrained by any measurement, which is what makes the blind sector a place a phase could live without contradicting anything.

        Witness on the invariants: tr = 0 with det = 1 (elliptic, disc = −4) and tr = 0 with det = −1 (hyperbolic, disc = +4).

        source
        theorem QOU.QBeta.zero_weight_admits_both_spectra (w : ℝ) (hw : w = 0) (trA trB : ℝ) :
        w * trA = w * trB ∧ IsElliptic 0 1 ∧ ¬IsElliptic 0 (-1)

        The same statement in the form the blind sector uses it: a block carrying weight zero contributes 0 to the observable for either operator, so the observable is consistent with both the elliptic and the hyperbolic one.
