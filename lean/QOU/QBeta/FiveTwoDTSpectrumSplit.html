    QOU.QBeta.FiveTwoDTSpectrumSplit — the 5₂ cross-knot {3,4} distinguisher #

    The structural resolution lever for the scalar-symmetry-constant vs DT-spectrum fork of the c₃-odd / A_ω question (keystone ledger docs/coordination/2026-08-02-c3-odd-aomega-unification.md; audit docs/audits/2026-08-02-fivetwo-crossknot-34-resolution.md).

    For the figure-eight knot 4₁ the GGM Stokes matrix is 2×2 and its q→0 form is S⁺(0) = [[1,3],[0,1]] (StokesQZeroDTCount), carrying the single off-diagonal integer 3; the q-exact symmetry constant is (S₁₂+S₂₁)/S₁₁ = 3 (StokesSymmetryConstant). Because 4₁ is amphichiral, its two Stokes matrices S⁺, S⁻ are related by the amphichiral involution ι, and the scalar 3 is unambiguous — the scalar and the DT spectrum cannot be separated in the 2×2 block.

    5₂ is chiral and its Stokes block is 3×3. The certified sandwich compute (computations/probes/qbeta_g3_5two_stokes_sandwich.py, K1/K2/K3 ✓; the same integer matrices are promoted to Mathlib-Matrix form in FiveTwoStokesMatrixIdentities) gives

    S⁺(0) = [[1,4,0],[0,1,0],[-3,-9,1]]   (the (96) factorization, constant 4)
S⁻(0) = [[1,0,3],[-4,1,-3],[0,0,1]]   (the (97) factorization, constant 3)

    so the DT spectrum {3,4} is split across chirality: the 4 lives in S⁺, the 3 in S⁻. The companion probe computations/probes/fivetwo_crossknot_34_distinguisher.py further finds that the literal 4₁ symmetry constant (S₁₂+S₂₁)/S₁₁ is not a q-exact constant for either 5₂ block (unlike 4₁), reinforcing that no single scalar clones across the two knots.

    This file proves — by decidable integer arithmetic on the certified matrix entries — the facts that make 5₂ a distinguisher:

    • dt_spectrum_two_element — the spectrum genuinely has two distinct members (4 ≠ 3); unlike 4₁, no single integer serves the leading Stokes data.
    • chirality_odd_datum_ne_zero — the ι-odd (antisymmetric) datum of the two chirality constants, chiralityOdd 4 3 = 1 ≠ 0, is nonzero, whereas on the amphichiral (degenerate) locus chiralityOdd a a = 0.
    • readings_all_distinct — the ι-even sum (7), the two members (4, 3), and the ι-odd difference (1) are pairwise distinct.

    Why this settles the fork (scope, honest — no derivation, no fit). The bar-odd observable ω = β·p − β⁻¹·q is ι-odd and vanishes on the amphichiral ι-fixed locus (BarOddAntisymOffDiagonal.omega_iota_odd, omega_zero_on_iotaFixed). An ι-odd observable cannot be carried by an ι-even symmetric-sum constant (the object that yields the scalar 3 at 4₁). 5₂ exhibits, as decidable data, that the relevant Stokes constants for a chiral knot form a genuine 2-element spectrum split by chirality, and that their ι-odd datum is the difference — sourced only by chirality, exactly 0 at the amphichiral degeneracy. Hence the observable's normalization integer is not a knot-independent scalar A_ω = 3; it is a member/combination of the chirality-split spectrum, degenerating to the single 3 at 4₁ only because the two chiralities coincide there. This is a scope-(a) structural refutation of the single-scalar reading (it neither confirms A=2/κ_shape nor A=3/A_ω·κ_pot as a universal scalar); which spectrum member the observable inherits is the residual normalization fork (qou-yh67), now sharpened to a choice among {3,4}, not scalar vs spectrum.

    Base ring / imports (honest). This file uses only core Lean (no import Mathlib.*): the certified Stokes matrices are integer matrices, so their entries and the DT constants live natively in Int; the ι-odd datum lemmas are stated over Int and discharged by decide/omega (both core). No ℝ, no ordering, no Real.* (§7c satisfied — the substrate→archimedean wall is not crossed). The Mathlib-Matrix promotion of the same data lives in FiveTwoStokesMatrixIdentities; this file is deliberately core-only so it verifies with the toolchain alone (no Mathlib olean set required). It does not derive the number from the 13 categorical drivers, does not bridge to c₃, and does not pick a normalization.

            The scalar reading fails: sum ≠ member ≠ difference #
