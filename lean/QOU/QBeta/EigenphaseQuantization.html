    theorem QOU.QBeta.EigenphaseQuantization.cos_rung_lt_of_base_short {Qbase d Qtarget α : ℝ} (hQ : 0 < Qbase) (hd : 0 < d) (hshort : Qbase * d < Qtarget) :
    Qbase * Real.cos α * d < Qtarget

    A bounded multiplicative rung cannot lift a base that already falls short.

    If the base Qbase, already damped by the positive N = 2 factor d, sits below the target, then no choice of phase α rescues it: the N = 1 rung is a cosine, and cos α ≤ 1.

    Instantiated on the ruled z_D base this is the statement that deriving the eigenphase cannot close the Q_β gap — the gap is in the base.

    theorem QOU.QBeta.EigenphaseQuantization.two_cos_eq_int_cases {α : ℝ} {c : ℤ} (h : 2 * Real.cos α = ↑c) :
    Real.cos α = -1 ∨ Real.cos α = -1 / 2 ∨ Real.cos α = 0 ∨ Real.cos α = 1 / 2 ∨ Real.cos α = 1

    Quantization of a q-uniform braid-image eigenphase on V_(2,1).

    A character of the braid image lies in ℤ[q,q⁻¹]; if it is additionally bounded on (0,∞) it is a constant integer, and on the two-dimensional irrep the bound is 2. So 2 cos α is an integer in [-2,2], leaving five possible cosines.

    A real strictly between two consecutive integers is not an integer.

    theorem QOU.QBeta.EigenphaseQuantization.not_braid_eigenphase_of_two_cos_mem_Ioo {α : ℝ} (h1 : 1 < 2 * Real.cos α) (h2 : 2 * Real.cos α < 2) :
    ¬∃ (c : ℤ), 2 * Real.cos α = ↑c

    The required ladder phase is not a q-uniform braid-image eigenphase.

    Given only that 2 cos α lies strictly between 1 and 2 — which is what the measured α_req satisfies, 2 cos α_req = 1.99725… — the phase cannot be the eigenphase of any braid-image matrix on V_(2,1) that is elliptic uniformly in q, because such a character is a constant integer.

    Note this covers a constant α as well as a q-varying one, which is exactly the case the boundedness-only argument leaves open.

    The five-element PHASE set, and why Kronecker is not load-bearing #

    two_cos_eq_int_cases above quantises the cosine — five values. The corpus's stated conclusion is about the phase: "a q-uniform braid-image eigenphase on V_(2,1) lies in the five-element set {0, π/3, π/2, 2π/3, π}". Those are different statements, and the bridge between them was prose arithmetic until now. phase_quantized is that bridge, via Real.injOn_cos.

    🟩 This closes the load-bearing half of qbeta_eigenphase_...'s assertion 8, and shows the unformalised half is DECORATIVE. That assertion reads "Kronecker: q-uniform ellipticity ⟹ integer char poly ⟹ eigenvalues are roots of unity ⟹ α ∈ 2πℚ", marked general-d, with a note that its Lean twin is unwritten. Two things follow from the chain below, and the second is the useful one:

    • V_(2,1) is 2-dimensional, so the corpus's conclusion is the d = 2 case — and at d = 2 the argument is elementary: an integer trace with |tr| ≤ 2 has five values, full stop. No Kronecker.
    • Therefore the unformalised general-d step is not on the path to anything the corpus asserts. It generalises a conclusion already had. Leaving it open costs nothing; that is a different situation from a gap that blocks.

    Worth recording because the cost of closing it is not small: Mathlib has no Kronecker's theorem (measured — Mathlib/ contains only kroneckerTMul*, the matrix product, unrelated), so formalising it means proving from scratch that an algebraic integer with all conjugates on the unit circle is a root of unity: bounded roots ⟹ bounded elementary symmetric functions ⟹ finitely many monic integer polynomials of that degree and height ⟹ pigeonhole on powers ⟹ finite order. Days, not hours — and for a generalisation nothing downstream consumes.

    theorem QOU.QBeta.EigenphaseQuantization.phase_quantized {α : ℝ} (hmem : α ∈ Set.Icc 0 Real.pi) (h : Real.cos α = -1 ∨ Real.cos α = -1 / 2 ∨ Real.cos α = 0 ∨ Real.cos α = 1 / 2 ∨ Real.cos α = 1) :
    α = 0 ∨ α = Real.pi / 3 ∨ α = Real.pi / 2 ∨ α = 2 * Real.pi / 3 ∨ α = Real.pi

    The five-element phase set. On [0, π], the five quantised cosine values pin α to exactly {0, π/3, π/2, 2π/3, π}.

    Real.injOn_cos is what makes this an equality rather than a containment.
