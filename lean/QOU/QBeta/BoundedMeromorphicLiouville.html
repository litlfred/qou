    Bounded meromorphic ⇒ entire (the state-integral / growth-bound route) #

    A boundedness companion to brick (c) (QOU.QBeta.RatioEntire.entire_toMeromorphicNFOn_div_of_same_order) for the Faddeev–Volkov uniqueness leg of the A_ω monodromy datum (qou-2cvs / route 2, bean qou-aanp).

    Brick (c) makes the ratio Φ₁/Φ₂ entire by matching divisors (the PhiBProd route). This file supplies the other honest route the elliptic-freedom obstruction (FaddeevPhiEllipticFreedom.faddeevPhi_mul_elliptic) leaves open: a nonconstant elliptic factor ℘ has poles, so it is unbounded; conversely a bounded meromorphic ratio has no poles and is therefore entire. The boundedness is exactly the endowment the state-integral / Écalle–Borel resurgent representation of Φ_b supplies — Φ_b is analytic with controlled growth in a fundamental strip, so the prefactor-cancelled ratio of two genuine solutions is bounded on ℂ.

    The mechanism reuses the Mathlib Meromorphic cone (built from pinned source, see scripts/build-meromorphic-cone.sh): a pole forces ‖f‖ → ∞ (tendsto_cobounded_of_meromorphicOrderAt_neg), which a uniform bound contradicts, so meromorphicOrderAt ≥ 0 everywhere; a normal-form function of nonnegative order is analytic (MeromorphicNFAt.meromorphicOrderAt_nonneg_iff_analyticAt), hence entire.

    Discipline: this is a conditional brick (§3b-cond). Boundedness is a named, non-axiomatised hypothesis — a growth statement that does not assume the conclusion (constancy/proportionality is far stronger, and there are bounded non-constant functions). It excludes the elliptic freedom honestly, on the merits. Verified lean-direct against the Meromorphic cone (exit 0).

    0 ≤ meromorphicOrderAt f z

    Bounded ⇒ meromorphic order ≥ 0 everywhere. If ‖f z‖ ≤ C for all z, then f has no pole: a negative-order point would force f → ∞ (tendsto_cobounded_of_meromorphicOrderAt_neg), impossible under a uniform bound (the punctured neighbourhood 𝓝[≠] z is NeBot in ℂ, so the empty preimage of the unbounded target cannot lie in it).

    theorem QOU.QBeta.BoundedMeromorphicLiouville.entire_of_meromorphicNFOn_bounded {g : ℂ → ℂ} {C : ℝ} (hg : MeromorphicNFOn g Set.univ) (hbdd : ∀ (z : ℂ), ‖g z‖ ≤ C) :
    Differentiable ℂ g

    Bounded meromorphic-normal-form ⇒ entire. A function in meromorphic normal form on ℂ that is bounded has nonnegative order everywhere (no poles), and a normal-form function of nonnegative order is analytic — so it is entire.

    Bounded ⇒ the normal-form representative is entire. For any f, if its normal-form representative g = toMeromorphicNFOn f univ is bounded, then g is entire. This is the boundedness analogue of brick (c) (RatioEntire.entire_toMeromorphicNFOn_div_of_same_order): there the ratio is made entire by matching divisors; here, by a uniform growth bound (the state-integral endowment).
