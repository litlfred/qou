    The lever derivative decomposition (machine-checked calculus for the m(q₀) gate) #

    The Q_β precision-ladder relation S(q) − Vol(4₁) = A(q)/u(q)³ differentiates (quotient rule) into

    $$\frac{dS}{dq} \;=\; \frac{A'}{u^3} \;-\; 3\,\frac{u'}{u}\,\bigl(S - \mathrm{Vol}(4_1)\bigr),$$

    which underlies the one-anchor derivative gate on any meridian-holonomy assignment m(q₀) for the c₃ bar-odd S (computations/qbeta/qbeta_c3_phib_mq_logderivative_constraint.py: the static term A′/u³ carries > 99.99 % of the 3.84×10⁶ slope, A′ ≈ +2.37; the log-derivative term is only ~10²). This file machine-checks the algebraic form of that decomposition so the gate is not re-derived by hand. No numerical value is used or wired; the statement is generic real calculus.

    -- Ref: [manuscript] computations/qbeta/qbeta-c3-phib-mq-logderivative-constraint.witness.json

    Quotient-rule decomposition for a cube-lever ratio. If f and u are differentiable at q with u q ≠ 0, then f/u³ is differentiable at q with derivative f′/u³ − 3(u′/u)(f/u³) — the exact algebraic shape of the c₃ S-slope decomposition (f = A, S − Vol(4₁) = A/u³).

    The decomposition rewritten in gate form: the un-levered derivative of the ratio recovers f′ up to the log-derivative correction — u³·(d/dq)(f/u³) = f′ − 3(u′/u)·f. This is the identity behind "u³·d[Im 𝔙(m(q))]/dq ≈ A′ at an anchor".
