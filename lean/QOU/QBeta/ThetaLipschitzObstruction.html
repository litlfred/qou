    theorem QOU.QBeta.ThetaLipschitzObstruction.s_variation_le_of_lipschitz {A κ L₁ L₂ S₁ S₂ ϑ₁ ϑ₂ Δq K : ℝ} (hAκ : 0 ≤ A * κ) (h₁ : S₁ = A * κ * (L₁ - ϑ₁ ^ 2)) (h₂ : S₂ = A * κ * (L₂ - ϑ₂ ^ 2)) (hlip : |ϑ₁ - ϑ₂| ≤ K * |Δq|) :
    |S₁ - S₂| ≤ A * κ * (|L₁ - L₂| + K * |Δq| * (|ϑ₁| + |ϑ₂|))

    A Lipschitz ϑ bounds the S-variation.

    If the channel S = A·κ·(L − ϑ²) holds at two substrate points, and ϑ is K-Lipschitz between them, then S cannot move further than the bound.

    No division, no differentiability: Lipschitz is all that is assumed, and every smooth geometric quantity is Lipschitz on a compact interval.

    theorem QOU.QBeta.ThetaLipschitzObstruction.not_lipschitz_of_s_variation_gt {A κ L₁ L₂ S₁ S₂ ϑ₁ ϑ₂ Δq K : ℝ} (hAκ : 0 ≤ A * κ) (h₁ : S₁ = A * κ * (L₁ - ϑ₁ ^ 2)) (h₂ : S₂ = A * κ * (L₂ - ϑ₂ ^ 2)) (hbig : A * κ * (|L₁ - L₂| + K * |Δq| * (|ϑ₁| + |ϑ₂|)) < |S₁ - S₂|) :
    ¬|ϑ₁ - ϑ₂| ≤ K * |Δq|

    The exclusion, contrapositive. If the measured S-variation EXCEEDS the Lipschitz bound, no such K works — the candidate ϑ is excluded.

    This is the form to apply as an up-front filter: compute the bound for the candidate's Lipschitz constant, compare against the measured |S₁ − S₂|, and discard on failure without ever evaluating the candidate's value.

    theorem QOU.QBeta.ThetaLipschitzObstruction.lipschitz_constant_ge {A κ L₁ L₂ S₁ S₂ ϑ₁ ϑ₂ Δq K : ℝ} (hAκ : 0 ≤ A * κ) (h₁ : S₁ = A * κ * (L₁ - ϑ₁ ^ 2)) (h₂ : S₂ = A * κ * (L₂ - ϑ₂ ^ 2)) (hlip : |ϑ₁ - ϑ₂| ≤ K * |Δq|) :
    |S₁ - S₂| - A * κ * |L₁ - L₂| ≤ A * κ * (K * (|Δq| * (|ϑ₁| + |ϑ₂|)))

    The Lipschitz constant is bounded below. Rearranged division-free: given the measured variation, any valid K satisfies this. With |Δq| ≈ 1.3e-8 and |S₁ − S₂| ≈ 4.9e-2 it is what forces K ~ 10⁷.

    The numeric bite, at the measured anchor values #

    Rounded-outward inputs, so each inequality is a genuine bound on the real case: A·κ = 3·√3/4 ≈ 1.2990381, |ΔL| ≤ 1e-8, |Δq| = 1.3e-8 (the 11.54 ppb pin separation), |ϑ₁| + |ϑ₂| ≤ 0.27, and the measured |S₁ − S₂| = 0.049.

    These are norm_num facts about the BOUND, not about ϑ — no ϑ value is asserted.
