    ∂V/∂y = 0 at the pair — pinning k = 0 by an argument bound #

    Bean qou-glbl, obligation (1), the last one open in Gap A.

    exists_int_dVdy_mul says ∂V/∂y · y = −k·2πi at every point of the curve, with k an integer nobody has pinned. At the positive real root k = ∓1 and it does not matter (re_dVdy_mul_eq_zero_of_real: a real Y′ sees only the real part). At the pair arg y moves, so heⱼ needs k = 0 outright.

    dVdy_eq_zero_of_argSum_bound … (hb : |argSum x y| < 2π) : dVdy x y = 0

    where argSum x y = arg(1−y) + arg(1−xy) + arg(1−y/x) − 2·arg(−y). Taking imaginary parts in exists_int_dVdy_mul turns it into argSum = k·2π, so any bound under 2π forces k = 0. This file supplies that bound in four regimes.

    ⚠ The obvious route is FALSE, not merely insufficient #

    argSum = 0 is equivalent to three Complex.log_mul splits holding at once:

    (i)   log(1−xy) + log(1−y/x) = log((1−xy)(1−y/x))
(ii)  log(1−y)  + log(that)  = log(y²)
(iii) 2·log(−y)              = log(y²)

    and (iii) needs Re y ≤ 0, which fails at the pair — Re y reaches +0.7848 (Route 38 G2, at 320 of 800 checks, all with the pair genuinely complex). Route 38 measures each wrap integer separately: n₁ ≡ 0, and n₂ = n₃ ∈ {−1,0,1}. So argSum = 0 holds by wrap cancellation, and a proof that performs the three splits unconditionally is proving something false. The bound below never needs them.

    The four regimes, and what supplies the missing π/2 in each #

    Write A = arg(1−y), a₁ = arg(1−xy), a₂ = arg(1−y/x), C = 2·arg(−y). Two components are free everywhere: A ∈ (−π/2, 0) from Re y < 1 and Im y > 0, and a₂ ∈ (−π, 0) from Im(y/x) > 0. The regimes differ only in a₁ and C.

    regime supplies the bound interval Route 38
    Re y > 0 forces cos φ > 0, so every term of Im(xy) carries the sign of Im y (−3π/2, 2π) G9, 160 checks
    Re y ≤ 0, cos φ ≤ 0 both terms of Im(xy) flip (−3π/2, 2π) G10, 107
    Re y ≤ 0, cos φ > 0 an identity, not a sign: Re(xy) + Re(y/x) = 2cos φ·Re y ≤ 0 (−2π, 2π) G11, 40
    the real pair both roots negative, so A = C = 0 (−π, π) G12, 186

    Every regime is non-empty. Regime 3 is the smallest and the only one no sign argument reaches — it is where a proof that assumed the signs were uniform would silently be assuming something false.

    ⚠ The tree's four sign facts are really two inequalities. With y = p+qi, x = c+si: cq − sp > 0 (unconditional) is both im_div_Ypair_fst_pos and im_mul_Ypair_snd_neg; cq + sp < 0 (needs c < 0) is both im_mul_Ypair_fst_neg and im_div_Ypair_snd_pos. Route 38's first draft of the regime gates mirrored each inequality branch-by-branch with a sign factor and failed: Im(x·y) for one branch pairs with Im(y/x) for the other, not with itself. Conjugation is the only correct symmetry, and it is why only Im y > 0 is treated here.

    ⚠ im_mul_Ypair_fst_neg's cos φ < 0 is not a gap to be filled. Route 38 G3 measures that it genuinely fails at 181 of 400 arc points, all at cos φ > 0 — and that failure region is regime 1, where the opposite sign supplies the bound.

    ⚠⚠ This is FALSE at φ = π, on the branch reaching −2.2469796: there argSum = 2π and k = ±1 (Route 38 G15). The cause is identical to VSide's endpoint failure — x·y = 2.2469796 lands ON Li₂'s cut, so a₁ = a₂ = π instead of cancelling. Benign because envelopeS_total needs HasDerivAt only on Ico 0 π, but every statement here must carry a hypothesis that excludes it.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.

      The conjugate branch, for free #

      Ypair.2 = conj Ypair.1, and on |x| = 1 conjugation swaps x·y with y/x — because conj x = x⁻¹ there. So argSum x (conj y) = −argSum x y: the two middle terms exchange places and every term flips sign.

      ⚠ This is the ONLY correct symmetry between the branches. Route 38's first draft of the regime gates tried to mirror each inequality separately with a sign factor and failed: Im(x·y) for one branch pairs with Im(y/x) for the other, not with itself.

      ⚠ And the four arg ≠ π side conditions are not decoration. arg_conj is if arg x = π then π else -arg x, so a term sitting on log's cut does not flip — it would break the identity by 2π, which is exactly the size of the error that matters here. Each is discharged from notCut at the call site: w ∈ notCut with Im w = 0 forces Re w < 1, hence Re (1 − w) > 0, hence arg (1 − w) = 0.
