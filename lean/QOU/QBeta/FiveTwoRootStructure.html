    The root structure — the last open input to the branch pinning, closed #

    Bean qou-trns. FiveTwoArgSector reduced the branch pinning to two facts about the roots of the deformed curve on |x| = 1, and stated them as hypotheses:

    • there is a real root t with 0 < t < 1;
    • of the other two, one has Im(x·y) ≤ 0, and when φ > π/2 both do.

    This file proves them. On |x| = 1 the y-cubic is real,

    p(Y) = Y³ − 2c·Y² + (2c+1)·Y − 1,     c = cos φ,

    so everything below is real algebra plus one application of the intermediate value theorem. No continuity in φ, no root tracking, no base point.

    The three steps #

    1. t ∈ (0,1) exists. p(0) = −1 < 0 < 1 = p(1), so IVT (exists_root_mem_Ioo). That p(1) = 1 identically in c is what makes this free — the 2c terms cancel.

    2. Factor out (Y − t). The remaining quadratic is Y² + βY + γ with β = t − 2c and γ = t² − 2ct + 2c + 1, and t·γ = 1 (that is p(t) = 0). Two consequences carry the whole argument:

    (t − 2c)·t(1−t) = t² + t − 1 =: W       (`beta_rel`)
c ≤ 1  ⟹  t > 2/5                       (`two_fifths_lt`)

    3. Split on the quadratic's discriminant.

    Real roots (β² ≥ 4γ). Then W ≥ 0 — W_nonneg_of_disc_nonneg, the one step with content. Suppose not; β² ≥ 4γ rearranges to W² ≥ 4t(1−t)², while W < 0 bounds t above by the golden section and c ≤ 1 bounds it below by 2/5, and on that interval 4t(1−t)² − W² is positive. With W ≥ 0 we get β ≥ 0, and γ = 1/t > 0, so both roots are negative and Im(x·y) = y·sin φ < 0 for each — the conjugate-pair inequality is not needed here at all.

    Conjugate pair (β² < 4γ). Then y = a ± b i with a = −β/2, b > 0, and a² + b² = γ. The hypotheses of sa_lt_cb hold — h1 is an identity given t·γ = 1, and h2 is beta_rel — so Im(x·ȳ) = s·a − c·b < 0. When c < 0 the other member follows, since c·b < 0 < −c·b.

    What this closes #

    The hypotheses ht0, ht1, h3 and hbig of branchInt_eq_zero_of_roots are now theorems, assembled in exists_pinning_data, which also returns the factorisation p(Y) = (Y − t)(Y − y₂)(Y − y₃) so that a consumer holding Vieta data can match its roots against these.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.
