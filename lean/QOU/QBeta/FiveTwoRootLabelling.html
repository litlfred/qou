    The real root as a differentiable function of c — bean qou-glbl #

    Gap A's last piece. hasDerivAt_envelopeS takes the root labelling Y₁ Y₂ Y₃ : ℝ → ℂ as given, differentiable functions; this file builds the one that carries the real root.

    Why this labelling and no other — Route 36 G9 #

    Y₁ φ = ((realRoot (cos φ) : ℝ) : ℂ)
(Y₂ φ, Y₃ φ) = otherRoots (t − 2c) (t² − 2ct + 2c + 1)

    is forced, not chosen. Every fact it needs was already proved:

    need supplied by
    the root exists exists_root_mem_Ioo
    it is unique in (0,1) real_root_neg_of_ne — every other real root is negative
    the IFT applies unitCubic_deriv_ne_zero, and ∂p/∂y ≥ 7/4 is tight
    the other two are continuous through the collision continuous_otherRoots

    and Y₁ comes out real-valued by construction, which is exactly the shape hasDerivAt_log_neg_ofReal needs. That was the one residue log_neg_route left open: route 2's lemma wants Y real-valued near φ, not merely real at φ, and no pointwise fact about roots can supply it. The construction does.

    What uniqueness is for #

    exists_hasDerivAt_implicit is local: it produces some g solving the equation near c, with no claim that g is the root anyone else means. Uniqueness in (0,1) is what turns that into a statement about realRoot — g is continuous and lands in the open interval (0,1), so it is realRoot near c, and the derivative transfers.

    The bound has to be strict because uniqueness is quoted at nearby parameters, not merely at c itself.

    The bound is c < 3/2, and getting past c = 1 was the point #

    A first version carried hc : c < 1. That excludes c = 1, which is φ = 0, an endpoint of the transport — so it would have cost an exceptional point, and envelopeS_total tolerates exactly one, already spent on the collision φ₀ = 137.9206708879635°. Two exceptions would have meant Gap A does not close by assembling what is already proved.

    It costs nothing, because uniqueness has a second and independent proof near c = 1. ∂p/∂t = 3t² − 4ct + (2c+1) has discriminant-in-t equal to 16c² − 24c − 12, negative on c ∈ (−0.3956…, 1.8956…); so on [1/2, 3/2] the cubic is strictly increasing, hence injective, hence has at most one real root anywhere (strictMono_unitCubic). No root structure enters.

    The two regimes overlap on [1/2, 1]: real_root_neg_of_ne covers c ≤ 1, monotonicity covers [1/2, 3/2]. Together (eq_realRoot') they give uniqueness for every c < 3/2 — which contains the entire arc range [−1,1] plus a two-sided neighbourhood of the endpoint. So c = 1 is interior, and φ = 0 needs no exception.

    VSide separately is false at φ = π (Route 36 G7) and needs x.im ≠ 0, so it lives on the open arc; this file covers all of [0,π].

    The derivative #

    dt/dc = −2t(1−t) / (3t² − 4ct + 2c + 1)

    Checked against a numerical derivative at seven values of c spanning the arc, agreeing to 5.7e-42 (Route 36). At c = 3/4 it is exactly −2/7, the point where unitCubic_deriv_ge's bound 7/4 is attained.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.

                          5b'. Toward heⱼ at the pair — the first tight bound #

                          Route 36 G13. heⱼ for the pair needs k = 0 in dVdy·y ∈ 2πi·ℤ (exists_int_dVdy_mul), because Re(dVdy·Y′) = k·2π·Im(Y′/y). The real root does not need it — there dVdy is purely imaginary and Y′ is real, which is re_dVdy_mul_eq_zero_of_real.

                          The pinning quantity is

                          S = arg(1−y) + [arg(1−xy) + arg(1−y/x) − 2·arg(−y)] = 2πk

                          and k = 0 follows from |S| < 2π. Bounding the four terms separately does not work — G13 measures their ranges as 1.4076 + 3.1133 + 3.1133 + 2·2.1115 = 11.857 > 2π. That route is closed; the correlations are what carry it.

                          Two groupings are tight instead, each measured under π/2, and their bounds sum to 2.8152 < 2π. This section proves the first, which is the elementary one: |arg(1−y)| < π/2 iff Re(1−y) > 0 iff Re y < 1, and at the pair Re y = cos φ − t/2 with cos φ ≤ 1 and t > 0. The second grouping remains open.
