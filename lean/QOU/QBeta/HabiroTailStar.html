      gaussBinom q (n + 1) (k + 1) = q ^ (n - k) * gaussBinom q n k + gaussBinom q n (k + 1)

      The dual Pascal rule [n+1,k+1]_q = q^{n−k}·[n,k]_q + [n,k+1]_q, unconditional (for k > n every term vanishes and truncated subtraction is harmless) — proved by induction from the primary recurrence alone.

      theorem QOU.QBeta.HabiroTailStar.gaussBinom_inv' {R : Type u_1} [CommRing R] (q qi : R) (hq : q * qi = 1) (n k : ℕ) :
      gaussBinom q n k = q ^ (k * (n - k)) * gaussBinom qi n k

      Bar-inversion (the heart of (★)), division-free over a generic CommRing: whenever qi is a two-sided inverse of q (hq : q * qi = 1), [n,k]_q = q^{k(n−k)}·[n,k]_{qi}, unconditional (both sides vanish for k > n). This is the lemma that collapses the quadratic exponents of the Masbaum transform, and it needs no field — only the unit witness, so it holds verbatim over ℤ[q, q⁻¹]. The literal q⁻¹ form is gaussBinom_inv below.
