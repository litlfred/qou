    def QOU.QBeta.LevelMixing.qPochC {S : Type u_1} [CommRing S] (q : S) (m : ℕ) :
    S

    (q;q)_m = ∏_{j=1..m} (1 − q^j) over a generic commutative ring — the same formula as HabiroTailStar.qPoch, at the weaker typeclass the divisibility statements need (see the header: over a field they would be vacuous).

      (1 - q) ^ (3 * m) ∣ c

      The derived constraint. If a single GGM block level m carries the whole bridge — mas · (q;q)_m³ = c · num with the block numerator num a unit (as it is on the j = 0 row, a monomial) — then the coefficient is forced to carry 3m factors of (1 − q).

      This is what pole cancellation costs: the block's order-3m pole at q = 1 must be paid for by the coefficient, since the Masbaum side is regular there.

      The sharpened constraint. Both sides contribute: the block's order-3m pole must be paid for, and the Masbaum level term already vanishes to order 2n. So the forced coefficient carries (1 − q)^{2n + 3m}, not merely (1 − q)^{3m}.

      theorem QOU.QBeta.LevelMixing.qPoch_prod_dvd_coeff {S : Type u_1} [CommRing S] (q : S) {Cn c num : S} (hu : IsUnit num) (n m : ℕ) (h : Cn * qPochC q n ^ 2 * qPochC q m ^ 3 = c * num) :
      qPochC q n ^ 2 * qPochC q m ^ 3 ∣ c

      The full-product constraint — strictly stronger than the (1 − q)-adic one. The (1 − q)^{2n+3m} bound above only reads off the vanishing at q = 1; but the entire Pochhammer product divides the coefficient. Since (q;q)_k = ∏_d Φ_d^{⌊k/d⌋} ranges over every cyclotomic factor, this captures the constraint at every root of unity at once, not just at q = 1.

      Its degree consequence is quadratic rather than linear (natDegree_ge_quadratic), which shrinks the reachable region from O(D²) pairs to O(D).

      The sharpened degree bound. A nonzero coefficient joining Masbaum level n to block level m has degree at least 2n + 3m.

      ∃ (n : ℕ), D < (c n).natDegree

      No bounded-degree level map bridges the tail. If a level map intertwines at every Masbaum level with nonzero coefficients, then its coefficient degrees are unbounded: for any budget D some level needs a coefficient of degree exceeding D.

      So there is no "small" universal bridge. Any level-mixing map valid at all orders has coefficients whose complexity grows without bound — which is a structural fact about the surviving family, obtained without searching it.

      theorem QOU.QBeta.LevelMixing.natDegree_ge_quadratic {Cn c num : Polynomial ℤ} (hu : IsUnit num) (n m : ℕ) (hc : c ≠ 0) (h : Cn * qPochC Polynomial.X n ^ 2 * qPochC Polynomial.X m ^ 3 = c * num) :
      2 * (n * (n + 1)) + 3 * (m * (m + 1)) ≤ 2 * c.natDegree

      The quadratic degree bound. A nonzero coefficient joining Masbaum level n to block level m satisfies

      2·deg c ≥ 2n(n+1) + 3m(m+1),

      i.e. deg c ≥ n(n+1) + 3m(m+1)/2 — quadratic in both indices, not linear. This supersedes natDegree_ge_of_bridge_combined (whose 2n+3m reads only the q = 1 vanishing); the full Pochhammer product carries every cyclotomic factor.

      Consequence: the reachable region under a degree budget D shrinks from O(D²) pairs to O(D) — n ≲ √D and m ≲ √(2D/3).
