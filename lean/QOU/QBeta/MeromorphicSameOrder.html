    Route-B step 2: order-difference periodicity for the Faddeev rigidity #

    The meromorphic reformulation of PentagonRigidity.uniqueUpToScalar (bean qou-2cvs, route B). The true Φ_b is meromorphic (zeros on the b-lattice, poles on the dual lattice), so the idealized entire-nowhere-zero scaffold does not apply; rigidity must be restated over MeromorphicOn/divisors. The keystone is that two solutions of the same first-order q-difference equation f(·+c) = P·f have the same divisor, so their ratio is entire and nowhere zero.

    This file proves route-B step 2 in full (sorry-free):

    • meromorphicOrderAt_comp_add — brick (a), translation invariance of the meromorphic order: ord (g∘(·+c)) x = ord g (x+c). Proved from the eq_top_iff / eq_int_iff characterizations, transporting the local representation across the z ↦ z+c homeomorphism (AnalyticAt.comp, punctured-nhds Tendsto). No longer a Mathlib gap.
    • meromorphicOrderAt_sharedPrefactor_balance — the prefactor P's order cancels: ord(P·Ψ) + ord Φ = ord(P·Φ) + ord Ψ.
    • meromorphicOrderAt_orderDiff_periodic — the step-2 conclusion, unconditional: two solutions of the same equation f(·+c)=P·f have ord Ψ − ord Φ preserved by one c-shift. Brick (a) discharges the translation input; nothing is assumed.

    Applied to both quasi-periods ib, i/b, this makes the order-difference ord Ψ − ord Φ doubly periodic — equivalently, the divisor of the ratio r = Ψ/Φ is ⟨ib, i/b⟩-periodic (r is c-periodic for each c, so r is an elliptic function).

    Honest scope correction (2026-07-19). Double periodicity does not force ord Φ = ord Ψ. A doubly-periodic meromorphic ratio can be a nonconstant elliptic function (Weierstrass ℘), so the two solutions need not share a divisor from the equations alone — there is genuine elliptic freedom. Hence "same divisor ⇒ ratio entire" is an independent analytic input (the Φ_b-specific characterization pinning the ratio to have no elliptic freedom), NOT a consequence of steps 1–2. Route B closes uniqueUpToScalar only with that extra input (≡ brick (c)'s premise); step 2 supplies the periodicity, not the constancy.
