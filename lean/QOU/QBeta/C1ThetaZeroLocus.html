    The converse q-theta zero locus #

    QOU/QBeta/C1ConnectionPoles.lean proves that θ_P vanishes on −P^{2ℤ} and that the winding difference across one fundamental annulus is exactly 2πi (qTheta_winding_step). Read through the argument principle, that says the annulus ρ < ‖z‖ < P²ρ contains exactly one zero, counted with multiplicity — which is the converse of the vanishing theorem, and what upgrades the C1 pole divisor from ⊇ to =.

    This file takes that last step. Everything general it needs is already proved:
    the annulus argument principle, factors off the contours argumentPrinciple_annulus_filter
    analytic functions factorise over their zeros QOU.Mathlib.exists_finset_factorisation
    the contour identity for θ_P qTheta_winding_step
    θ_P(−P^{2k}) = 0 qTheta_neg_zpow_eq_zero

    What is θ-specific, and is done here:

    • isPreconnected_openAnnulus — the factorisation needs a connected open set, and an open annulus is exp of a convex strip.
    • qThetaC_ne_zero_outer — non-vanishing on ‖z‖ = ρ propagates to ‖z‖ = P²ρ through the functional equation, so both contours are clean from the single hypothesis qTheta_winding_step already asks for.
    • qThetaC_zero_count_annulus — the count is 1.
    • qThetaC_zero_locus_annulus — hence a single simple zero, and if a lattice point −P^{2k} lies in the annulus it is that zero.

    theorem QOU.QBeta.C1Poles.isPreconnected_openAnnulus {r R : ℝ} (hr : 0 < r) (hrR : r < R) :
    IsPreconnected {z : ℂ | r < ‖z‖ ∧ ‖z‖ < R}

    An open annulus in ℂ is preconnected.

    It is the image under Complex.exp of the strip log r < re z < log R, which is a preimage of an interval under an ℝ-linear map, hence convex.

    Needed because exists_finset_factorisation runs the identity theorem, which wants a connected domain: an annulus is the smallest such domain containing the two contour circles of qTheta_winding_step.

    theorem QOU.QBeta.C1Poles.qThetaC_ne_zero_outer (P : ℝ) (hP : 1 < P) (ρ : ℝ) (hρ : 0 < ρ) (hne : ∀ (z : ℂ), ‖z‖ = ρ → qThetaC P z ≠ 0) (z : ℂ) :
    ‖z‖ = P ^ 2 * ρ → qThetaC P z ≠ 0

    Non-vanishing propagates outward across one fundamental annulus.

    θ_P(P²w) = w·θ_P(w) with w ≠ 0, so a zero on ‖z‖ = P²ρ would force one on ‖z‖ = ρ. This is why qTheta_winding_step's single hypothesis — no zero on the inner circle — is enough to make both contours legitimate.

    theorem QOU.QBeta.C1Poles.qTheta_pos_of_pos (P w : ℝ) (hP : 1 < P) (hw : 0 < w) :
    0 < qTheta P w

    θ_P is strictly positive on the positive real axis.

    Every term of ∑ P^{−n(n+1)} wⁿ is positive when w > 0, so the sum is. This is the cheapest proof that θ_P is not identically zero — which is what the identity theorem needs before it will produce a divisor at all, and what the hne hypotheses below ultimately rest on.

    ∃ (S : Finset ℂ) (m : ℂ → ℕ) (g : ℂ → ℂ), AnalyticOnNhd ℂ g {z : ℂ | c < ‖z‖ ∧ ‖z‖ < d} ∧ (∀ (z : ℂ), c < ‖z‖ → ‖z‖ < d → g z ≠ 0) ∧ (∀ a ∈ S, 0 < m a) ∧ (∀ a ∈ S, c < ‖a‖ ∧ ‖a‖ < d) ∧ Set.EqOn (qThetaC P) (fun (z : ℂ) => (∏ a ∈ S, (z - a) ^ m a) * g z) {z : ℂ | c < ‖z‖ ∧ ‖z‖ < d}

    theorem QOU.QBeta.C1Poles.qThetaC_zeros_iff_annulus (P : ℝ) (hP : 1 < P) (c d : ℝ) (hc : 0 < c) (hcd : c < d) :
    ∃ (S : Finset ℂ), (∀ a ∈ S, c < ‖a‖ ∧ ‖a‖ < d) ∧ ∀ (z : ℂ), c < ‖z‖ → ‖z‖ < d → (qThetaC P z = 0 ↔ z ∈ S)

    The zeros of θ_P in an open annulus are a finite set — and the factorisation names it: a ∈ S and θ_P a = 0 are the same statement there, because the multiplicities are positive and the cofactor never vanishes.

    theorem QOU.QBeta.C1Poles.exists_clean_radius (P : ℝ) (hP : 1 < P) (c d : ℝ) (hc : 0 < c) (hcd : c < d) :
    ∃ (ρ : ℝ), c < ρ ∧ ρ < d ∧ ∀ (z : ℂ), ‖z‖ = ρ → qThetaC P z ≠ 0

    Every open interval of radii contains one on which θ_P does not vanish.

    Only finitely many radii carry a zero — the zeros in an annulus are finite — and an interval of reals is infinite.

    This is what makes the "no zero on ‖z‖ = ρ" hypothesis of qTheta_winding_step and everything downstream a choice rather than a restriction: given any point one wants to reason about, a clean contour can always be placed on either side of it.

    theorem QOU.QBeta.C1Poles.qThetaC_zeros_annulus (P : ℝ) (hP : 1 < P) (r R : ℝ) (hr : 0 < r) (hrR : r < R) (hnr : ∀ (z : ℂ), ‖z‖ = r → qThetaC P z ≠ 0) (hnR : ∀ (z : ℂ), ‖z‖ = R → qThetaC P z ≠ 0) :
    ∃ (S : Finset ℂ) (m : ℂ → ℕ), (∀ a ∈ S, r < ‖a‖ ∧ ‖a‖ < R) ∧ (∀ a ∈ S, 0 < m a) ∧ (∀ a ∈ S, analyticOrderAt (qThetaC P) a = ↑(m a)) ∧ (∀ (z : ℂ), r < ‖z‖ → ‖z‖ < R → (qThetaC P z = 0 ↔ z ∈ S)) ∧ ((∮ (z : ℂ) in C(0, R), deriv (qThetaC P) z / qThetaC P z) - ∮ (z : ℂ) in C(0, r), deriv (qThetaC P) z / qThetaC P z) = (∑ a ∈ S, ↑(m a)) * (2 * ↑Real.pi * Complex.I)

    The zeros of θ_P between two clean circles, and the winding number that counts them.

    If θ_P vanishes nowhere on ‖z‖ = r or on ‖z‖ = R, its zeros in the open annulus form a finite set S with strictly positive multiplicities m, and

    ∮_{|z|=R} θ'/θ  −  ∮_{|z|=r} θ'/θ  =  (∑ a ∈ S, m a) · 2πi.

    The factorisation is taken on an annulus strictly larger than the contours — it must be, since the argument principle needs the non-vanishing cofactor on a neighbourhood of the closed contour annulus — and argumentPrinciple_annulus_filter counts only the factors in between.

    Nothing here mentions −P^{2ℤ}: which points the zeros are is arithmetic, and is the caller's job.

    theorem QOU.QBeta.C1Poles.qThetaC_unique_zero_fundamental_annulus (P : ℝ) (hP : 1 < P) (ρ : ℝ) (hρ : 0 < ρ) (hne : ∀ (z : ℂ), ‖z‖ = ρ → qThetaC P z ≠ 0) :
    ∃ (a : ℂ), ρ < ‖a‖ ∧ ‖a‖ < P ^ 2 * ρ ∧ analyticOrderAt (qThetaC P) a = 1 ∧ ∀ (z : ℂ), ρ < ‖z‖ → ‖z‖ < P ^ 2 * ρ → (qThetaC P z = 0 ↔ z = a)

    θ_P has exactly one zero in each fundamental annulus.

    The converse of qTheta_neg_zpow_eq_zero, and the statement that makes the C1 pole divisor exact rather than ⊇.

    qTheta_winding_step puts the winding difference across ρ < ‖z‖ < P²ρ at exactly 2πi; qThetaC_zeros_annulus reads that difference as (∑ m)·2πi, so ∑ m = 1; every multiplicity is at least 1, so the index set is a single point.

    The one hypothesis — no zero on the inner circle — is qTheta_winding_step's own, and is unavoidable rather than restrictive: the integrand θ'/θ is not defined on a circle through a zero, and the radius is ours to choose.

    theorem QOU.QBeta.C1Poles.qThetaC_zero_locus_fundamental_annulus (P : ℝ) (hP : 1 < P) (ρ : ℝ) (hρ : 0 < ρ) (hne : ∀ (z : ℂ), ‖z‖ = ρ → qThetaC P z ≠ 0) (k : ℤ) (hk1 : ρ < P ^ (2 * k)) (hk2 : P ^ (2 * k) < P ^ 2 * ρ) :
    analyticOrderAt (qThetaC P) (-↑(P ^ (2 * k))) = 1 ∧ ∀ (z : ℂ), ρ < ‖z‖ → ‖z‖ < P ^ 2 * ρ → (qThetaC P z = 0 ↔ z = -↑(P ^ (2 * k)))

    The converse zero locus on a fundamental annulus.

    If a lattice point −P^{2k} lies in the annulus, it is the unique zero — so on that annulus the zero set of θ_P is exactly {−P^{2k}}, which is the converse the C1 pole divisor needs.

    Choosing the k is arithmetic on Real.log, not analysis, and is left to the caller: the annulus has ratio P² and the lattice spacing is P², so an open fundamental annulus carries one lattice point or none, depending on where ρ falls.

    theorem QOU.QBeta.C1Poles.qThetaC_eq_zero_iff (P : ℝ) (hP : 1 < P) (w : ℂ) (hw : w ≠ 0) :
    qThetaC P w = 0 ↔ ∃ (k : ℤ), w = -↑(P ^ (2 * k))

    The zero locus of θ_P, in full: θ_P(w) = 0 ↔ w ∈ −P^{2ℤ}.

    The converse of qTheta_neg_zpow_eq_zero, with no hypothesis beyond w ≠ 0 — and 0 is excluded only because it is an essential singularity, where θ_P is not an analytic object at all. With p = P² this is the classical statement that the zero set of θ_p is exactly −p^ℤ, each zero simple.

    The argument is the fundamental-annulus result plus arithmetic: ⌊logb (P²) ‖w‖⌋ names the annulus P^{2k} ≤ ‖w‖ < P^{2k+2} holding w; exists_clean_radius places a clean contour ρ in (‖w‖/P², P^{2k}), an interval that is nonempty because ‖w‖ < P^{2k+2}; and (ρ, P²ρ) then contains both w and −P^{2k}, which qThetaC_zero_locus_fundamental_annulus identifies.

    This is what makes the C1 pole divisor exact rather than a containment: every locus in the table at the top of C1ConnectionPoles.lean is a single p-orbit of this set, with nothing else in it.

    theorem QOU.QBeta.C1Poles.qThetaC_analyticOrderAt_neg_zpow (P : ℝ) (hP : 1 < P) (k : ℤ) :
    analyticOrderAt (qThetaC P) (-↑(P ^ (2 * k))) = 1

    Every zero of θ_P is simple.

    Together with qThetaC_eq_zero_iff this is the entire divisor of θ_P on ℂ*: the orbit −P^{2ℤ}, reduced. It is what makes the C1 pole divisor determined rather than merely supported — a containment of zero sets fixes where the poles can be, but not with what multiplicity.
