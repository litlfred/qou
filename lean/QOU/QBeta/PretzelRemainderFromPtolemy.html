    QOU.QBeta.PretzelRemainderFromPtolemy — the third knot's H_floor inputs, from the solved Ptolemy varieties #

    Where this sits (Route C, M3, bean qou-m3ad Part 6) #

    AdjointIndexSetM3 carries the (−2,3,7) row of Garoufalidis–Zagier's table as a transcription: realEmbeddings pretzel237 = 4, complexPairs pretzel237 = 1, |P_K| = 7. Part 4 called the count 7 a prediction, not a check, because the Ptolemy database is firewalled. The variety itself is small enough to solve here (aomega_m3_pretzel_remainder_from_ptolemy_probe.py, 10/10): SnapPy's census m016 (= K12n242 = (−2,3,7) = Culler's K3_1, 3 tetrahedra) has two N = 2 obstruction classes, and a lex Gröbner basis reduces each to one cubic in one Ptolemy coordinate:

    • class 1: c³ − c − 1 = 0 — discriminant −23, the 5₂ shape cubic in −c (c = −θ, θ³ − θ + 1 = 0): one real root;
    • class 0: c³ + 4c² + 3c − 1 = 0 — discriminant 49, splits over ℚ(η), η³ + η² − 2η − 1 = 0: three real roots.

    Boundary-unipotent representations are the nontrivial elements of P_K, one per Ptolemy solution over all obstruction classes, so |P_K| = 1 + 3 + 3 = 7, the real embeddings number 1 + 3 = 4, and H_floor's remainder is 4. This file proves the two real-root counts over ℝ and links them to the transcribed values, as FloorRemainderFromDerivedShapeFields does for 4₁ and 5₂.

    Scope. The triangulation is SnapPy's census one (a held tool), not a Farey-word derivation — the pretzel is not two-bridge. Nothing here separates H_Ad from H_floor (core 3 under both), and the pretzel's q → 0 Stokes matrix is still not held (GGM record its level as 2), so the one-sided H_Ad test stays open.
