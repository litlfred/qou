    Vieta: the reciprocal cubic is the product over the roots #

    source
    theorem QOU.QBeta.FiveTwo.prod_one_sub_mul_eq {R : Type u_1} [CommRing R] {y₁ y₂ y₃ : R} (e1 : y₁ + y₂ + y₃ = 2) (e2 : y₁ * y₂ + y₁ * y₃ + y₂ * y₃ = 3) (e3 : y₁ * y₂ * y₃ = 1) (z : R) :
    (1 - y₁ * z) * (1 - y₂ * z) * (1 - y₃ * z) = 1 - 2 * z + 3 * z ^ 2 - z ^ 3

    ∏ⱼ (1 − yⱼ z) = 1 − 2z + 3z² − z³ for any three ring elements with the 5₂ cubic's elementary symmetric functions e₁ = 2, e₂ = 3, e₃ = 1.

    This is the generating-function step: it is what makes the power sums pₙ = Σⱼ yⱼⁿ integers and identifies Σₙ pₙzⁿ/n with −log of this cubic.

    The crux: the reciprocal cubic is (1−z)³ + z #

    source
    theorem QOU.QBeta.FiveTwo.recipCubic_eq {R : Type u_1} [CommRing R] (z : R) :
    1 - 2 * z + 3 * z ^ 2 - z ^ 3 = (1 - z) ^ 3 + z

    1 − 2z + 3z² − z³ = (1 − z)³ + z, over any commutative ring.

    A one-line ring identity, but it is the load-bearing one: it exhibits the integrand as a sum of two pieces that are separately non-negative on [0,1].

    source
    theorem QOU.QBeta.FiveTwo.recipCubic_pos {z : ℝ} (h0 : 0 ≤ z) (h1 : z ≤ 1) :
    0 < 1 - 2 * z + 3 * z ^ 2 - z ^ 3

    The integrand never vanishes on [0,1].

    Immediate from recipCubic_eq: on [0,1] both (1−z)³ and z are non-negative, and at z = 0 the first is 1.

    This is what makes ∫₀¹ log(1 − 2z + 3z² − z³)/z dz a convergent real integral, even though the series defining Σⱼ Li₂(yⱼ) diverges because |y₁| = 1.52 > 1. It is the technical content behind "Route 5 bypasses the complex-Li₂ continuation".

    The power-sum recurrence #

    Each root satisfies the cubic, so its powers obey the associated linear recurrence; summing over the roots gives the recurrence for pₙ = Σⱼ yⱼⁿ, which is why those power sums are integers (3, 2, −2, −7, −6, 7, 25, …).

    source
    theorem QOU.QBeta.FiveTwo.pow_succ_rec {R : Type u_1} [CommRing R] {y : R} (hy : y ^ 3 = 2 * y ^ 2 - 3 * y + 1) (n : ℕ) :
    y ^ (n + 3) = 2 * y ^ (n + 2) - 3 * y ^ (n + 1) + y ^ n

    A single root's powers obey the cubic's recurrence.

    theorem QOU.QBeta.FiveTwo.powerSum_rec {R : Type u_1} [CommRing R] {y₁ y₂ y₃ : R} (h1 : y₁ ^ 3 = 2 * y₁ ^ 2 - 3 * y₁ + 1) (h2 : y₂ ^ 3 = 2 * y₂ ^ 2 - 3 * y₂ + 1) (h3 : y₃ ^ 3 = 2 * y₃ ^ 2 - 3 * y₃ + 1) (n : ℕ) :
    y₁ ^ (n + 3) + y₂ ^ (n + 3) + y₃ ^ (n + 3) = 2 * (y₁ ^ (n + 2) + y₂ ^ (n + 2) + y₃ ^ (n + 2)) - 3 * (y₁ ^ (n + 1) + y₂ ^ (n + 1) + y₃ ^ (n + 1)) + (y₁ ^ n + y₂ ^ n + y₃ ^ n)

    The power sums pₙ = y₁ⁿ + y₂ⁿ + y₃ⁿ obey pₙ₊₃ = 2pₙ₊₂ − 3pₙ₊₁ + pₙ.

    Eliminating the complex roots #

    The restatement's final step drops y₁, y₂ entirely in favour of the real root. Both ingredients are Vieta consequences, given that the two non-real roots are a conjugate pair.

    source
    theorem QOU.QBeta.FiveTwo.real_root_mul_normSq {y₁ y₃ : ℂ} (e3 : y₁ * (starRingEnd ℂ) y₁ * y₃ = 1) :
    y₃ * ↑(Complex.normSq y₁) = 1

    y₃·‖y₁‖² = 1. With y₂ = conj y₁, the product relation e₃ = 1 says the real root is the reciprocal of ‖y₁‖².

    This is what turns log r into −½·log y₃ in the restatement, removing the modulus of the complex root as independent data.

    source
    theorem QOU.QBeta.FiveTwo.two_mul_re_eq {y₁ y₃ : ℂ} (e1 : y₁ + (starRingEnd ℂ) y₁ + y₃ = 2) :
    2 * ↑y₁.re = 2 - y₃

    The angle is determined by the real root. With y₂ = conj y₁, Vieta's e₁ = 2 gives 2·Re y₁ = 2 − y₃.

    Together with real_root_mul_normSq (‖y₁‖² = 1/y₃) this yields cos θ = (2 − y₃)·√y₃ / 2, the closed form used in the restatement — so the whole sum rule depends on the single real algebraic number y₃.

    Route 3, formalized: the Landen image cubic #

    Numerically (bean qou-0yqu, Route 3) the Landen substitution z = y/(y−1) maps the three 5₂ roots exactly onto the roots of z³ − z² + 1 — residual 0.0 at all three. That is pure algebra, so it is proved here rather than left as an observation.

    The route is still a dead end for the sum rule: it relates Σ Li₂(yⱼ) to a sum over a different algebraic set, giving one new equation and one new unknown. Proving where Landen lands is not proving that it helps.

    source
    theorem QOU.QBeta.FiveTwo.landen_image_cubic {R : Type u_1} [Field R] {y : R} (hy : y - 1 ≠ 0) (h : y ^ 2 = (1 - y) ^ 3) :
    (y / (y - 1)) ^ 3 - (y / (y - 1)) ^ 2 + 1 = 0

    The Landen image of a 5₂ saddle root is a root of z³ − z² + 1.

    From y² = (1−y)³ one gets z² = 1−y and z³ = −y for z = y/(y−1), whence z³ = z² − 1.

      The field: discriminant −23 #

      The 2026-08-07 finding (bean qou-0yqu) is that the 5₂ saddle cubic has discriminant −23, the smallest |discriminant| among complex cubic fields — which places the whole problem in the classical Zagier / dilogarithm-ladder setting. That was established with sympy; it is pure algebra, so it is machine-checked here instead.

      Note what this does and does not settle. The field identification is exact and now proved. But the classical −23 literature (Broadhurst hep-th/9811173 eq (73): vol(5₂) = 3·Z₂₃,₃) computes the volume / Bloch–Wigner side, which Route 2 showed carries no information about the sum rule. Knowing the field is not knowing the identity.

      The integrand is bounded: |log P(z)/z| ≤ 4 on (0,1] #

      Route 5's integral −∫₀¹ log P(z)/z dz is over an interval containing the apparent singularity at z = 0. It is only apparent: P(z) = 1 − 2z + O(z²), so log P(z) ∼ −2z and the quotient extends continuously with value −2.

      The quantitative form is |log P(z)| ≤ 4z, proved below from two elementary bounds sandwiching log:

      log P ≤ P − 1        (`Real.log_le_sub_one_of_pos`)
log P ≥ 1 − 1/P      (`Real.one_sub_inv_le_log_of_pos`)

      together with P ≥ 1/2 on [0,1], which converts the second into a linear bound. 4 is not tight — the true sup of |log P(z)/z| is 2, attained in the limit z → 0 — but a non-tight constant is all an integrability argument needs, and the slack keeps the polynomial certificates small.

      The integrand identity: Σⱼ Re Log(1 − yⱼz) = log P(z) on [0,1] #

      This is the pointwise half of the one link still separating Route 5 from the sum rule, namely

      Σⱼ Re Li₂(yⱼ) = −∫₀¹ log P(z)/z dz.

      The other half is the complex integral representation Li₂(y) = −∫₀¹ Log(1 − yz)/z dz, which for |y| > 1 is the analytic continuation (the integral converges for any y ∉ [1,∞) regardless of |y|, unlike the series). That half is still open — see bean qou-gkco.

      The pointwise identity below needs no dilogarithm and no continuation. It works because the real part of a complex log is a genuine norm-log, and norms multiply:

      Σⱼ Re Log(1 − yⱼz) = Σⱼ log‖1 − yⱼz‖ = log ∏ⱼ‖1 − yⱼz‖
                   = log‖∏ⱼ(1 − yⱼz)‖ = log|P(z)| = log P(z)

      the last step by recipCubic_pos. No 2πik correction appears anywhere — taking real parts discards exactly the branch ambiguity. (Probe qbeta_5two_route5_branch_data_probe gate G1 saw this numerically: the correction is identically zero, 3.1e-61 over 40 sample points. It is not a numerical accident; it is what this proof says.)

      theorem QOU.QBeta.FiveTwo.sum_re_log_one_sub_eq_log_recipCubic {y₁ y₂ y₃ : ℂ} (e1 : y₁ + y₂ + y₃ = 2) (e2 : y₁ * y₂ + y₁ * y₃ + y₂ * y₃ = 3) (e3 : y₁ * y₂ * y₃ = 1) {z : ℝ} (hz0 : 0 ≤ z) (hz1 : z ≤ 1) :
      (Complex.log (1 - y₁ * ↑z)).re + (Complex.log (1 - y₂ * ↑z)).re + (Complex.log (1 - y₃ * ↑z)).re = Real.log (1 - 2 * z + 3 * z ^ 2 - z ^ 3)

      Σⱼ Re Log(1 − yⱼz) = log P(z) for z ∈ [0,1].

      Real parts, so no branch data enters. y₁, y₂, y₃ are any three complex numbers with the 5₂ cubic's elementary symmetric functions.

      The three-root sum collapses to ONE real integral #

      The assembly step. With the pointwise identity above, plus linearity of the integral and the fact that Re commutes with it, the three separate dilogarithm-integrals over the roots become a single integral of a real polynomial's logarithm:

      Σⱼ Re Li₂(yⱼ) = −∫₀¹ log(1 − 2z + 3z² − z³)/z dz

      with Li₂ the integral-defined QOU.MathlibExt.cLiTwoExt, which is the object that makes sense at ‖y₁‖ = 1.52 where the series does not.

      One integrability hypothesis per root, and only for the complex-valued integrand — the real-part versions are derived (Integrable.re). For the 5₂ roots the three hypotheses are discharged by QOU.MathlibExt.intervalIntegrable_log_one_sub_div, which needs Re(1 − yz) > 0 on [0,1] — true for all three.

      This does not prove the sum rule. It makes Route 5's identity a theorem about cLiTwoExt; what remains is (i) identifying cLiTwoExt with the Li₂ of the sum rule off the disc — i.e. proving it is the analytic continuation, still open — and (ii) evaluating the resulting real integral in closed form, which is untouched. Bean qou-0yqu.
