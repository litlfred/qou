    theorem QOU.QBeta.abs_sq_gt_one {x y : ℝ} (hx : 1 < x) :
    1 < x ^ 2 + y ^ 2

    With x > 1, the modulus-squared s = x² + y² exceeds 1 whatever y is. Hence ln q is never purely imaginary on the substrate branch, and a purely elliptic Kohno–Drinfeld generator is impossible outright.

    theorem QOU.QBeta.character_im_zero_iff {x y : ℝ} (hx : 1 < x) :
    y / 2 * (1 - 1 / (x ^ 2 + y ^ 2)) = 0 ↔ y = 0

    The character's imaginary part vanishes only for real q. Writing q = x + iy, Im[(q + q⁻¹)/2] = (y/2)(1 − 1/s) with s = x² + y²; for x > 1 we have s > 1, so the factor 1 − 1/s is strictly positive and the product is zero exactly when y = 0.

    theorem QOU.QBeta.no_complex_q_gives_real_subunit_character {x y κ : ℝ} (hx : 1 < x) (hreal : y / 2 * (1 - 1 / (x ^ 2 + y ^ 2)) = 0) (hκ : κ < 1) :
    κ ≠ x / 2 * (1 + 1 / (x ^ 2 + y ^ 2))

    No complex q gives a real character below 1. If the character is real — which Q_β being real forces — then q is real, and the character is then (x + x⁻¹)/2 ≥ 1. So allowing Im q ≠ 0 and keeping the real part does not rescue the holonomy reading; it only trades a wrong-sided real number for a complex one.

    theorem QOU.QBeta.hecke_eigenvalues_not_unit_modulus {q : ℝ} (hq : 1 < q) :
    q ≠ 1 ∧ |(-q⁻¹)| ≠ 1

    Route B dissolves the scale-fixing. An elliptic generator forces unit-modulus braiding eigenvalues, but Kohno–Drinfeld fixes ħ = 2 ln q by matching the Hecke pair {q, −q⁻¹}, and for q > 1 neither member has modulus one. So a non-Hermitian deformation buys ellipticity at the cost of the matching that made the construction Kohno–Drinfeld in the first place.
