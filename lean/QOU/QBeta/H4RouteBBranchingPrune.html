    def QOU.QBeta.branchToH4 {R : Type u_1} [Add R] (a b c : R) :
    R × R × R × R × R

    The five λ ⊢ 4 block readings of an element of H₃ ⊂ H₄, as functions of its three λ ⊢ 3 readings (a, b, c) = (χ₍₃₎, χ₍₂,₁₎, χ₍₁,₁,₁₎), by the branching rule S₄ ↓ S₃. Order: (χ₍₄₎, χ₍₃,₁₎, χ₍₂,₂₎, χ₍₂,₁,₁₎, χ₍₁,₁,₁,₁₎).

      (branchToH4 a b c).snd.fst = (branchToH4 a b c).fst + (branchToH4 a b c).snd.snd.fst ∧ (branchToH4 a b c).snd.snd.snd.fst = (branchToH4 a b c).snd.snd.fst + (branchToH4 a b c).snd.snd.snd.snd

      Route-B prune (no independent N=4 rung). The five λ ⊢ 4 block readings of any element of H₃ ⊂ H₄ satisfy two fixed branching relations, so they are determined by the three λ ⊢ 3 readings — re-decomposing the unchanged H₃ element at λ ⊢ 4 cannot produce a genuine c₄^even rung.

      theorem QOU.QBeta.branchToH4_injective {R : Type u_1} [Add R] :
      Function.Injective fun (t : R × R × R) => branchToH4 t.fst t.snd.fst t.snd.snd

      H₃ data is the independent content. The λ ⊢ 3 readings are recovered from the λ ⊢ 4 readings (a = χ₍₄₎, b = χ₍₂,₂₎, c = χ₍₁,₁,₁,₁₎), so branchToH4 is injective: it adds no information beyond the three H₃ numbers.
