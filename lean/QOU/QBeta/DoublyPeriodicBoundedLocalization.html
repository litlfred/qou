    Global boundedness of a doubly-periodic function localizes to a fundamental domain #

    The Faddeev–Volkov uniqueness capstone (FaddeevUniquenessBoundedCapstone.faddeevPhi_proportional_of_bounded_ratio, wired to the concrete Φ_b in PhiBProdUniquenessAssembly) leaves one analytic input open: the global strip-boundedness hbdd : ∀ z, ‖r z‖ ≤ C of the prefactor-cancelled ratio r. That ratio is doubly periodic (elliptic) under the substrate lattice ⟨ib, i/b⟩ (route-B step 2, MeromorphicSameOrder + FaddeevRigidityMeromorphic).

    This file supplies the periodicity half of hbdd: a doubly-periodic function bounded on the closed fundamental parallelepiped (a compact set) is bounded on all of ℂ. So the global hbdd reduces to a local, compact-domain bound — ‖r‖ ≤ C on one fundamental domain — a strictly weaker analytic obligation than the global one. The ℘-freedom that would violate boundedness lives entirely inside the fundamental domain (its poles), so this is the honest localization of the remaining input, not a cosmetic restatement.

    The reduction uses only periodicity (no differentiability): reducing each ℝ-coordinate of z modulo 1 (Int.fract) lands z, up to a lattice translation f ignores, in the closed ball of radius ‖b 0‖ + ‖b 1‖ — the same Int.fract/⌊·⌋ construction as DoublyPeriodicLiouville.const_of_doublyPeriodic, but ending in the supplied compact-domain bound instead of Liouville. Verified lean-direct against the pinned Mathlib. Sorry-free.

    ‖f z‖ ≤ C

    Boundedness localizes to the fundamental domain. A function f periodic under both vectors of an ℝ-basis b of ℂ and bounded by C on the closed ball of radius ‖b 0‖ + ‖b 1‖ (which contains a fundamental parallelepiped) is bounded by C everywhere: every z is, up to a lattice translation f ignores, congruent to a point of that ball.
