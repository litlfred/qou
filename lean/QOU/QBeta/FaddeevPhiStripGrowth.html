    The strip-growth characterization class (growth epic, brick G4) #

    Route-B brick G4 of the Faddeev growth-estimate epic (qou-mz4f). The shift equations (the FaddeevPhi class) do not pin Φ_b — the elliptic-freedom obstruction. The physical Φ_b is singled out by a growth condition (Faddeev–Kashaev): among all shift-solutions it is the one with controlled growth. This file formalizes that condition as a §3b characterization class and discharges its non-vacuity by exhibiting phiBProd as an instance.

    • FaddeevPhiStripGrowth b Φ — Φ is comparable to phiBProd: ∃ C > 0, ‖Φ z‖ ≤ C‖phiBProd b z‖ and ‖phiBProd b z‖ ≤ C‖Φ z‖ for all z. This is the honest §3b axiomatization of the physical characterization — it carries the growth hypothesis (comparability), not the uniqueness conclusion.
    • instPhiBProd — phiBProd is an instance (C = 1), so the class is non-vacuous by construction (anti-laundering §3b-tax: the carrier asserts real content and is realized).
    • ratio_bounded_of_stripGrowth — the payoff toward G5: two strip-growth solutions have a bounded ratio off the denominator's zeros (‖Φ₁/Φ₂‖ ≤ C₁C₂), the raw-ratio input the boundedness capstone consumes.

    The strip bound that witnesses comparability for a concrete solution is supplied by the G1–G3 product estimates (PhiBProdStripBound, PhiBProdStripLowerBound); wiring the raw ratio bound here into the meromorphic-normal-form hbdd of FaddeevUniquenessBoundedCapstone is the remaining G5 step.

    Verified lean-direct against PhiBProd. Sorry-free.

    class QOU.QBeta.FaddeevPhiStripGrowth (b : ℂ) (Φ : ℂ → ℂ) :
    Prop

    Strip-growth characterization class. Φ is comparable in modulus to the canonical product phiBProd b: some C > 0 bounds each by C times the other, everywhere. This is the growth condition that singles out the physical Φ_b among the shift-solutions; it carries the comparability hypothesis, not the uniqueness conclusion.

    • comparable : ∃ (C : ℝ), 0 < C ∧ ∀ (z : ℂ), ‖Φ z‖ ≤ C * ‖MathlibExt.PhiBProd.phiBProd b z‖ ∧ ‖MathlibExt.PhiBProd.phiBProd b z‖ ≤ C * ‖Φ z‖
