    theorem QOU.QBeta.SLeakMagnitudeOffsetRatio.linear_ratio_slope_independent {L qstar qm qp : ℝ} (hL : L ≠ 0) :
    L * (qp - qstar) / (L * (qm - qstar)) = (qp - qstar) / (qm - qstar)

    Slope cancellation. For the leading-order linearization of a function at a simple zero q*, S(q) = L·(q − q*), the ratio of two evaluations equals the ratio of their offsets from q*, independently of the slope L ≠ 0. Applied to the bar-odd residual S_leak, the observed |S_leak(proton)/S_leak(muon)| therefore carries information about anchor placement relative to q* — not about the local slope, so no "period value" can be extracted from it.

    theorem QOU.QBeta.SLeakMagnitudeOffsetRatio.smooth_period_excluded_as_magnitude {P : ℝ → ℝ} {qm qp K r : ℝ} (hlip : |P qp - P qm| ≤ K * |qp - qm|) (hPm : P qm ≠ 0) (hsmall : K * |qp - qm| / |P qm| < 1) (hr : P qp / P qm = r) (hrbig : 2 ≤ |r|) :
    False

    Scope-(b): a smooth period cannot supply the factor-≈4 magnitude ratio. If a Lipschitz P on the anchor interval has variation budget K·|qp − qm|/|P(qm)| < 1 — the regime of any O(1) geometric period over the Δq ≈ 1.3e-8 anchor gap — then its ratio r = P(qp)/P(qm) satisfies |r − 1| < 1, so |r| < 2 and it cannot equal the observed |S_leak(proton)/S_leak(muon)| ≈ 4.075 (which has |r| ≥ 2). This is the SP1 smoothness wall for Bring-intrinsic periods: a smooth q₀-evaluated period is nearly constant across the two anchors, so the factor-≈4 magnitude asymmetry cannot be a period ratio.
