    §1. The character collapse: where the bar-odd h cancels #

    σ₁ satisfies the Hecke relation, so on any irreducible V_λ it acts with the two eigenvalues q and -q⁻¹, with multiplicities mp and mm summing to f^λ = dim V_λ. Hence χ_λ(σ₁) = q*mp - q⁻¹*mm.

    The combination 2*χ_λ(σ₁) - h*f^λ then loses every trace of h:

    source

    F

    The quantum integer [2]_q = q + q⁻¹. Bar-EVEN, unlike h = q - q⁻¹.

      theorem QOU.QBeta.chi_sigma_collapse {F : Type u_1} [Field F] (q mp mm : F) (hq : q ≠ 0) :
      2 * (q * mp - q⁻¹ * mm) - (q - q⁻¹) * (mp + mm) = twoQ q * (mp - mm)

      2·χ_λ(σ₁) - h·f^λ = [2]_q·(mp - mm).

      With χ_λ(σ₁) = q·mp - q⁻¹·mm and f^λ = mp + mm, the h = q - q⁻¹ multiplying the dimension exactly cancels the bar-odd half of the character, leaving the bar-EVEN [2]_q against the eigenvalue-multiplicity difference. That difference is the ordinary symmetric-group character χ^λ(τ) at a transposition — it is the q → 1 value of χ_λ(σ₁), where σ₁ ↦ τ, q ↦ 1 and -q⁻¹ ↦ -1.

      This one identity is the reason a bar-even weight vector can nonetheless pin the bar-odd phase: the phase's h is not supplied by the weights, and everything the weights DO supply enters through [2]_q.

      §2. The loop-mean identity, and the collapse of the n-dependence #

      source
      theorem QOU.QBeta.loopMean_eq_twoQ_mul_moment {F : Type u_1} [Field F] {ι : Type u_2} (s : Finset ι) (q z : F) (hq : q ≠ 0) (y mp mm : ι → F) (hnorm : ∑ i ∈ s, (mp i + mm i) * y i = 1) (hsigma : ∑ i ∈ s, (q * mp i - q⁻¹ * mm i) * y i = z) :
      2 * z - (q - q⁻¹) = twoQ q * ∑ i ∈ s, (mp i - mm i) * y i

      2z - h = [2]_q · Ξ, where Ξ = Σ_λ χ^λ(τ)·y_λ.

      Hypotheses are exactly the two Markov conditions the weight vector is defined by — the normalisation Σ f^λ y_λ = 1 and the stabilisation Σ χ_λ(σ₁) y_λ = z — plus the per-block eigenvalue decomposition, which is §1's input. No convention is fixed: z is arbitrary, so this holds in C, in D, and in any other frame.

      Stated over an arbitrary Finset ι so it covers every n at once; the caller supplies mp/mm as the two σ₁-eigenvalue multiplicities and the conclusion's moment is Σ (mp - mm)·y.

      theorem QOU.QBeta.moment_independent_of_index {F : Type u_1} [Field F] (q z Ξ₁ Ξ₂ : F) (h2 : twoQ q ≠ 0) (h₁ : 2 * z - (q - q⁻¹) = twoQ q * Ξ₁) (h₂ : 2 * z - (q - q⁻¹) = twoQ q * Ξ₂) :
      Ξ₁ = Ξ₂

      The transposition moment does not depend on n.

      2z - h mentions no index set, so if two different n both satisfy §2 against the same q and z, their moments agree. The n-independence of Ξ is therefore forced by the loop-mean identity rather than observed across a table — the probe's n = 2..9 sweep confirms the premise but is not what establishes the conclusion.

      (Only [2]_q ≠ 0 is needed, i.e. q² + 1 ≠ 0; over ℝ that is automatic.)

      theorem QOU.QBeta.phaseTwice_eq_moment_form {F : Type u_1} [Field F] (q z Ξ : F) (hmom : 2 * z - (q - q⁻¹) = twoQ q * Ξ) :
      2 * phaseTwice z (q - q⁻¹) - (q - q⁻¹) ^ 2 = (twoQ q * Ξ - 2) * (q - q⁻¹)

      The phase in moment form: 4α = [2]_q·Ξ·h + h² - 2h.

      Written on the doubled phase, 2·phaseTwice z h - h² = ([2]_q·Ξ - 2)·h, which is phaseTwice_projected_eq_loopMean with the loop mean rewritten by §2. Equivalently α = (h/4)·([2]_q·Ξ + h - 2).

      The bar-odd content sits entirely in the outer h; [2]_q and Ξ are both bar-even, so this exhibits the phase as h × (bar-even, and pinned by the weights) — the shape MarkovWeightsConventionD predicted without pinning.

      §3. The negative half: alpha is NOT a function of the weights #

      This is the scope-(b) structural exclusion, and the invariant it cites is bar-parity, proved in QOU.QBeta.MarkovWeightsConventionD.

      source
      theorem QOU.QBeta.phaseTwice_not_bar_fixed {F : Type u_1} [Field F] (z h : F) (hh : h ≠ 0) (hne : 2 * z - h ≠ 2) :
      phaseTwice (z - h) (-h) ≠ phaseTwice z h

      The core clash: the phase is not bar-fixed.

      Under D bar sends z ↦ z - h (zD_bar_eq_negative_loop: it exchanges the two stabilisation loop values), so phaseTwice (z-h) (-h) is the phase's bar image. It equals the phase itself only when h*(2z - h - 2) = 0.

      This is the whole mathematical content of the exclusion below; the wrapper that follows adds only the reading. Note it is a genuine restriction: without hne the two sides DO coincide, so the hypothesis is not decorative.

      source
      theorem QOU.QBeta.no_weight_function_gives_phase {F : Type u_1} [Field F] {Y : Type u_2} (G : Y → F) (y ybar : Y) (z zb h : F) (hh : h ≠ 0) (hne : 2 * z - h ≠ 2) (hbar : zb = z - h) (hy : ybar = y) (hF : phaseTwice z h = G y) (hFbar : phaseTwice zb (-h) = G ybar) :
      False

      No function of the weight vector reproduces the ladder phase.

      The hypotheses are the real ones and none is decorative:

      • hbar : zb = z - h — how bar acts on the Markov parameter under D (zD_bar_eq_negative_loop: bar exchanges the two stabilisation loop values);
      • hy : ybar = y — the weight vector is bar-EVEN. Proved for the D-frame weights as markovWeightsD_y21_barEven / markovWeightsD_y3_barEven, hence so is any F of them;
      • hF, hFbar — the supposed function F reproduces the phase at q and, because its argument is bar-fixed, returns the SAME value at q⁻¹;
      • hh : h ≠ 0, hne : 2z - h ≠ 2 — non-degeneracy.

      The conclusion is False: no such G exists.

      Honesty about what G and Y contribute: nothing logical. Once hy is substituted, hF and hFbar say only that the phase equals its own bar image, and the contradiction is phaseTwice_not_bar_fixed above. G and Y are carried because they are what makes the statement read as the exclusion it is — "some function of the weight vector returns the phase" — and because the bar-evenness of the weights is what supplies hFbar in any real application. The mathematics is entirely in the core lemma; this is its interpretation, not additional strength.

      Note what this does and does not exclude. It excludes the weights alone determining alpha; it does not touch §2, where alpha is recovered from the weights together with h. The two are consistent precisely because h is exactly the bar-odd datum the weights cannot see — h distinguishes q from q⁻¹, and the weights do not.

      theorem QOU.QBeta.zD_loopMean_sub_two_num {F : Type u_1} [Field F] (q : F) (hq : q ≠ 0) (hd : q ^ 2 + 1 ≠ 0) :
      (2 * zD q - (q - q⁻¹) - 2) * (q * (q ^ 2 + 1)) = q ^ 4 - 2 * q ^ 3 - 2 * q + 1

      2·z_D - h - 2 has numerator q⁴ - 2q³ - 2q + 1.

      2q³/(q²+1) - (q - q⁻¹) - 2 = (q⁴ - 2q³ - 2q + 1)/(q(q²+1)), so the §3 hypothesis 2z - h ≠ 2 is exactly the non-vanishing of that quartic. Stated denominator-cleared.

      theorem QOU.QBeta.zD_loopMean_eq_twoQ_mul_xi {F : Type u_1} [Field F] (q : F) (hq : q ≠ 0) (hd : q ^ 2 + 1 ≠ 0) :
      2 * zD q - (q - q⁻¹) = twoQ q * ((q ^ 4 + 1) / (q ^ 2 + 1) ^ 2)

      The D-frame loop mean, in closed form.

      2·z_D - h = [2]_q · (q⁴+1)/(q²+1)², i.e. the moment Ξ of §2 takes the value (1+Q²)/(1+Q)² with Q = q² — for every n, by moment_independent_of_index. Stated denominator-cleared so it is a polynomial identity.

      At n = 3 this value coincides with the single weight y_(3), because χ^(2,1)(τ) = 0, y_(1³) = 0 and [4]_Q = (1+Q)(1+Q²). That coincidence is special to n = 3 and should not be read as Ξ = y_(n) in general.
