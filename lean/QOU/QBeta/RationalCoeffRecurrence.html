    Rational fibre object ⇒ C-finite ladder coefficients (residue-A kernel grounding) #

    Residue-A unblock kernel work (docs/audits/2026-06-04-residue-a-unblock-kernel-scope.md + docs/audits/2026-06-04-residue-a-kernel-deepening-plan.md). The fibre object F(u) = Q_β/[Q_A·cos α_eff] satisfies a q-difference equation F(qξ) = R(q,ξ)·F(ξ); if F is a rational function P/Q, its ladder coefficients c_k are C-finite — they satisfy a constant-coefficient linear recurrence whose characteristic polynomial is the reverse of the denominator Q, and the poles of F (in particular the simple pole at u_substrate) are the reciprocals of the characteristic roots.

    This grounds the search "find the kernel R" ≡ "find the minimal denominator Q". Its contrapositive is the pruning used by computations/qbeta/qbeta_ck_recurrence_first_cut.py: the canonical c_2..c_10 admit no constant-coefficient recurrence of order ≤ 4, so F is not a low-degree rational function — the kernel is genuinely higher-order, and the productive direction is the canonical c_11+ extraction (or a categorical derivation of Q_A·cos α_eff's zero), not more real-q / root-of-unity forms.

    • pole_reciprocal_is_char_root — a denominator root u₀ gives a root u₀⁻¹ of the reversed (characteristic) polynomial.
    • CFinite — the order-d recurrence itself.
    • CFinite.recurrence_step — the recurrence solves for the leading term: the "kernel produces c_k from the seed" engine in math form.

    All verified sorry-free against mathlib (pinned f897ebcf, lean v4.24.0).

    theorem QOU.QBeta.pole_reciprocal_is_char_root {K : Type u_1} [Field K] (d : ℕ) (q : ℕ → K) (u₀ : K) (hu : u₀ ≠ 0) (hroot : ∑ j ∈ Finset.range (d + 1), q j * u₀ ^ j = 0) :
    ∑ j ∈ Finset.range (d + 1), q j * u₀⁻¹ ^ (d - j) = 0

    Pole ⇒ reciprocal is a characteristic root. If u₀ ≠ 0 is a root of the denominator polynomial ∑_{j≤d} q j · X^j, then u₀⁻¹ is a root of the reversed (characteristic) polynomial ∑_{j≤d} q j · X^(d-j).

    This is the find R ≡ find minimal Q grounding for the c_k recurrence: the pole u_substrate of F is exactly such a u₀, so 1/u_substrate is the dominant characteristic root of the ladder recurrence — matching the empirical tail ratio c_{k+1}/c_k → 1/u_substrate ≈ 117.4.

    def QOU.QBeta.CFinite {K : Type u_1} [Field K] (d : ℕ) (q c : ℕ → K) :
    Prop

    c is C-finite of order d with denominator coefficients q (q 0 ≠ 0): the defining constant-coefficient linear recurrence of the coefficients of a proper rational P/Q.

      theorem QOU.QBeta.recurrence_step {K : Type u_1} [Field K] {d : ℕ} {q c : ℕ → K} (h : CFinite d q c) {n : ℕ} (hn : d ≤ n) :
      c n = -(q 0)⁻¹ * ∑ j ∈ Finset.range d, q (j + 1) * c (n - (j + 1))

      The C-finite recurrence solves for the leading term: for n ≥ d, the coefficient c n is determined by the previous d values via the kernel -(q 0)⁻¹ · q (j+1). This is the "kernel produces c_k from the seed" engine — it makes rigorous the Step-2 statement that the kernel fixes c_{n} from the last d coefficients.
