    §1. The general identity: the phase anomaly is h times the z anomaly #

    source
    def QOU.QBeta.phaseTwice {R : Type u_1} [CommRing R] (z h : R) :
    R

    The doubled ladder phase 2·alpha = (z - 1)·h, carrying no division so the parity bookkeeping is available in any CommRing (including characteristic 2, where alpha itself would not be defined).

      theorem QOU.QBeta.phaseTwice_bar_anomaly {R : Type u_1} [CommRing R] (z zb h : R) :
      phaseTwice zb (-h) + phaseTwice z h = h * (z - zb)

      The bar-anomaly of the phase is h times the bar-anomaly of z.

      h is bar-ODD (bar h = -h, immediate for h = q - q⁻¹), so applying bar to 2 alpha = (z - 1) h sends z ↦ zb and h ↦ -h. The sum with the unbarred phase is then

      phaseTwice zb (-h) + phaseTwice z h = h * (z - zb).

      Everything downstream in this file is a specialisation of this one ring identity: the phase's failure to be mirror-covariant is exactly the Markov parameter's failure to be bar-invariant, amplified by h.

      source
      theorem QOU.QBeta.phaseTwice_bar_odd_iff_z_bar_fixed {D : Type u_2} [CommRing D] [IsDomain D] (z zb h : D) (hh : h ≠ 0) :
      phaseTwice zb (-h) = -phaseTwice z h ↔ z = zb

      Mirror-covariance of the phase characterises bar-invariance of z. Over a domain with h ≠ 0, the doubled phase is bar-ODD (its bar image is its negative) iff z is exactly bar-fixed. The forward direction is the structural exclusion this file exists to state: a convention whose Markov parameter moves under bar cannot carry a mirror-covariant framing phase, whatever the size of the movement.

          The bar-odd part of the D-frame phase is 2 alpha_D - h²/2, i.e. alpha_D - h²/4.

          Subtracting half the anomaly is the unique shift that makes the phase mirror-covariant, so this projection is forced by §1 + zD_sub_bar_eq_h rather than chosen. Note bar(h²) = h² (h bar-odd ⇒ h² bar-even), so the same constant is subtracted on both sides — that is what makes the shift consistent, and it is why no freedom remains.

          §4. What the D-frame anomaly actually is: bar exchanges the two loop values #

          §3 says z_D - bar(z_D) = h. Read with the Markov axioms that is a much sharper statement than "D fails a parity test", and it reverses the naive reading of §2-§3.

          The two stabilisation loop values are tr(x sigma_n) = z tr(x) and tr(x sigma_n⁻¹) = (z - h) tr(x) (block prop:jones-markov-trace-stabilisation). So z_D - bar(z_D) = h says exactly

          bar(z_D) = z_D - h = the NEGATIVE-stabilisation loop value.

          Under convention D the bar involution exchanges the two loop values — which is precisely what mirror symmetry must do, since mirroring a link exchanges positive and negative crossings, hence exchanges the two stabilisation moves. Convention C's parameter is bar-FIXED (§2), i.e. mirror-blind: it does not see the crossing-sign exchange at all.

          So D is the convention in which z transforms correctly under mirror, and the h²/2 phase anomaly is not a defect of D — it is the signature that D implements mirror ↔ crossing-sign exchange while the phase formula alpha = (z-1)h/2, which was written in the bar-fixed C frame, was carried over unchanged. It is the phase formula that needed re-deriving under D, not the convention.

          And the re-derivation is forced: phaseTwice_projected_eq_loopMean below shows the §3 projection is not a shift at all but the same phase evaluated at the mean of the two loop values (z + (z-h))/2, which under D (zD_bar_mean_eq_loop_mean) is the same thing as the bar-mean. Symmetrising over the mirror and symmetrising over the crossing sign are one operation in this frame.

            theorem QOU.QBeta.phaseTwice_eq_counit_sub_trace {F : Type u_2} [Field F] (z h : F) :
            phaseTwice z h = CrossingWeightAffine.evalMap h 1 - CrossingWeightAffine.evalMap h z

            The ladder's doubled phase IS the counit-minus-trace gap. With the Q_β evaluation map E(w) = h²/2 − h·w of CrossingWeightAffine (w = 1 the Frobenius counit ε, w = z the Markov trace tr_M):

            2·α = phaseTwice z h = E(1) − E(z) = ε(Δ) − tr_M(Δ).

            So the ladder eigenphase α = (z−1)h/2 is not an arbitrary parameterisation: it is exactly half the counit-minus-trace gap, i.e. the infinitesimal generator of the counit→trace transport. This locates the one unjustified step of the Q_β ladder — the exponentiation of this gap into cos(α − u/2), axiomatised as QOU.Interactions.QBetaCosResummation — as the target a convention-D re-derivation must actually supply (the transport), rather than a new phase formula. The identity holds for any z, so it is convention-blind; it locates, it closes nothing numerical — the c_k rung values remain anti-fit-fenced (bean qou-cds1). One ring line over CrossingWeightAffine.evalMap_affine.
