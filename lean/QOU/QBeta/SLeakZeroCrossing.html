    theorem QOU.QBeta.SLeakZeroCrossing.sleak_zero_between_anchors {Sleak : ℝ → ℝ} {a b : ℝ} (hab : a ≤ b) (hcont : ContinuousOn Sleak (Set.Icc a b)) (ha : Sleak a < 0) (hb : 0 < Sleak b) :
    ∃ q ∈ Set.Ioo a b, Sleak q = 0

    Sign-flip ⇒ zero-crossing. A continuous S_leak on the closed anchor interval [a, b] with S_leak a < 0 < S_leak b vanishes at some q* strictly inside (a, b). Applied to the c₃ bar-odd residual (with a = proton anchor, b = muon anchor, per the documented signs), this is the substrate q* where c₃ = −Vol(4₁) exactly — the residual is purely bar-even.

    theorem QOU.QBeta.SLeakZeroCrossing.sign_definite_carrier_excluded {g : ℝ → ℝ} {a b : ℝ} (hab : a ≤ b) (hcont : ContinuousOn g (Set.Icc a b)) (hnz : ∀ q ∈ Set.Icc a b, g q ≠ 0) (ha : g a < 0) (hb : 0 < g b) :
    False

    Scope-(b) exclusion of any sign-definite carrier. No continuous, nowhere-zero function g on the anchor interval [a, b] can agree with a carrier that changes sign across the anchors (g a < 0 < g b): its intermediate zero contradicts nonvanishing. This sharpens SRigidityPrune's "not anchor-invariant" to "must cross zero", excluding every sign-definite form (exp∘·, |·|, sum-of-squares) regardless of magnitude.
