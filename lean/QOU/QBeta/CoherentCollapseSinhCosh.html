    theorem QOU.QBeta.coherent_vs_observe_last (y y' s : ℝ) (hs : 0 ≤ s) :
    y * s + y' * -s = (y - y') * s ∧ y * |s| + y' * |(-s)| = (y + y') * s

    Coherent collapse vs observe-last. For two blocks whose bar-odd parts have opposite chirality (+s, -s — the rotation/growth split, PR #1742), the coherent sum (extract after summing) is (y - y')·s, which nulls at equal weights; the observe-last sum (|·| per block, then sum) is (y + y')·s, which survives. This is the algebraic core of the owner-confirmed coherent-collapse cancellation (the c_3-carrying sinh is exactly what the coherent sum can null while the incoherent sum keeps).
