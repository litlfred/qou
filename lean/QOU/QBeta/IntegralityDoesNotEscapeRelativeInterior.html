    1. The face argument without convexity #

    source
    theorem QOU.QBeta.IntegralityDoesNotEscapeRelativeInterior.linear_min_two_sided_kills_direction {V : Type u_1} [AddCommGroup V] [Module ℝ V] (f : V →ₗ[ℝ] ℝ) (S : Set V) (x d : V) (a b : ℝ) (ha : 0 < a) (hb : 0 < b) (hxa : x + a • d ∈ S) (hxb : x - b • d ∈ S) (hmin : ∀ y ∈ S, f x ≤ f y) :
    f d = 0

    A linear functional minimised at a two-sided-reachable point vanishes on that direction.

    This is the S4 face argument with the convexity removed, and removing it is the whole point: S here is an ARBITRARY set, so the statement applies to a polyhedron and to a set of lattice points alike. What does the work is not that S is convex but that it contains a point on each side of x along d.

    Consequence for the ILP question: an integer program cannot escape S4 by non-convexity, because non-convexity was never what the argument used. It can only escape by failing to reach both sides — i.e. by the lattice being COARSE enough near x to have no feasible point on one side. A dense coefficient ring does not do that.

    theorem QOU.QBeta.IntegralityDoesNotEscapeRelativeInterior.not_minimal_of_descent_direction {V : Type u_1} [AddCommGroup V] [Module ℝ V] (f : V →ₗ[ℝ] ℝ) (S : Set V) (x d : V) (a : ℝ) (ha : 0 < a) (hxa : x + a • d ∈ S) (hfd : f d < 0) :
    ¬∀ y ∈ S, f x ≤ f y

    The one-sided constructive form: a single better feasible point refutes minimality.

    This is what the probe exhibits at [A6] — it does not need a two-sided argument, only one feasible lattice point whose objective is strictly lower. Stated separately because a constructive refutation is a different (and cheaper) obligation than the structural one above, and conflating them is how a measurement gets reported as a theorem.

    theorem QOU.QBeta.IntegralityDoesNotEscapeRelativeInterior.min_iff_blind_on_two_sided_direction {V : Type u_1} [AddCommGroup V] [Module ℝ V] (f : V →ₗ[ℝ] ℝ) (S : Set V) (x d : V) (a b : ℝ) (ha : 0 < a) (hb : 0 < b) (hxa : x + a • d ∈ S) (hxb : x - b • d ∈ S) (hmin : ∀ y ∈ S, f x ≤ f y) :
    f (a • d) = 0 ∧ f (b • d) = 0

    Nothing but a functional vanishing on d can have x optimal, which is the S4 conclusion stated as a dichotomy: either the objective is blind to the direction, or x is not the optimum.

    2. Reading 1 — a non-integer coordinate is not in the integer lattice #

    source
    theorem QOU.QBeta.IntegralityDoesNotEscapeRelativeInterior.not_mem_integer_lattice_of_coord_not_integral {ι : Type u_1} (x : ι → ℝ) (i : ι) (hi : ∀ (n : ℤ), x i ≠ ↑n) :
    ¬∃ (y : ι → ℤ), ∀ (j : ι), x j = ↑(y j)

    B_3 is not in ℤ⁶, so an ILP over ℤ⁶ excludes it rather than failing to select it.

    Stated generally: a point one of whose coordinates is not the image of an integer is not in the integer lattice. Trivial, and worth having explicitly because it is a different kind of negative from §1 — §1 says a linear objective cannot pick B_3 out of the feasible set, this says B_3 is not in the feasible set. An agent reading only the first could reasonably think a cleverer objective might help.

    3. The exact Pisot sign test #

    source
    theorem QOU.QBeta.IntegralityDoesNotEscapeRelativeInterior.cube_sub_self_strictMono (x y : ℝ) (hx : 1 ≤ x) (hxy : x < y) :
    x ^ 3 - x < y ^ 3 - y

    x³ - x is strictly increasing on [1, ∞).

    The cubic x³ - x - 1 has derivative 3x² - 1 > 0 there; this is the order-theoretic form of that, proved directly so no calculus is needed.

    source
    theorem QOU.QBeta.IntegralityDoesNotEscapeRelativeInterior.lt_root_of_cubic_neg (q θ : ℝ) (_hq : 1 ≤ q) (hθ : 1 ≤ θ) (hroot : θ ^ 3 - θ - 1 = 0) (hneg : q ^ 3 - q - 1 < 0) :
    q < θ

    q < θ is EXACTLY the sign of q³ - q - 1, given that θ is the root.

    This is what lets the probe test "is q₀ below the smallest Pisot number" with a single exact rational comparison, and make no floating-point claim about θ = 1.324717957... at all. The hypothesis is only that θ is a root of x³ - x - 1 with θ ≥ 1 — Siegel's theorem that this particular root is the smallest Pisot number is CITED by the probe, not proved here.
