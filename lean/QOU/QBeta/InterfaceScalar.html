    The nucleon–nucleon interface is a single scalar #

    The interface collapses to one number, and that number is bounded.

    The title and subtitle here used to read "…and it has a floor" / "Why no crossing convention can bind the deuteron". Both are withdrawn (2026-08-09): the floor is convention-C specific and the deuteron IS reachable under the production convention D. See the retraction below.

    In the H_{3A} atom word (computations/mass_at_3A_proper.atom_braid_word_3A) the generator σ₂ is the only one joining strand 2 — nucleon k's last quark — to strand 3, nucleon k+1's first. So "the inter-nucleon sector" is literally the word placed at that one generator, and the binding functional B = α·ln(tr_free/tr_atom) reads it through the Markov trace alone.

    Two facts collapse that sector to a single number.

    • The Hecke quadratic σ² = h·σ + 1 closes span{1, σ} under multiplication (interface_mul), so every word at σ₂, of any length, is a•σ + b•1.
    • The Markov property tr(W·σ) = z·tr(W) plus linearity then gives tr(W·(a•σ + b•1)) = (a·z + b)·tr(W) (interface_scalar).

    Hence the whole interface enters through μ = a·z + b, and the per-bond log-suppression is L = −ln μ. The framework's four whitelisted crossings are the a = 1 cases at d ∈ {0, −h(½−δ/4), −h/2, −h}, i.e. μ ∈ [z−h, z].

    Four consequences are recorded here.

    mu_mem_Icc — the admissible μ lies in [z−h, z], so with −ln decreasing the binding is confined to [α·ln(1/z), α·ln(1/(z−h))]. mu_unreachable is the formal statement that a target above z is not attained by any admissible offset. Both are conditional theorems and remain true as stated.

    RETRACTION 2026-08-09 — the deuteron IS reachable, and the impossibility narrative that used to stand here is withdrawn. This paragraph read "Numerically that is [2.907195, 5.177967] MeV, while B_AME(²H) = 2.2245662: below the floor by 30.69 % … no crossing sign, colour weight, or multiplicity reaches the deuteron." Those numbers are convention C (z = 1/(√q+1/√q) = 0.4993), which was excised. Under the production convention D (z = q³/(q²+1) = 0.6127) the admissible band is [2.0507, 3.7978] MeV and contains B_AME(²H) = 2.224566. Solving for the required offset gives d = −0.024973 = −0.11945·h, inside the Hecke range [−h, 0], where under C it was +0.4230·h and outside. The theorems are untouched; only the claim that they bind here was wrong. What remains open is that the derived colour weight t = ½ − δ/4 = 0.499656 does not equal the required t = 0.119453 — a derivation gap, not an impossibility. Audit: docs/audits/2026-08-09-two-nucleon-channels-isospin-not-crossing-count.md; bean qou-kj4v.

    bond_energy_floor — a z-form-specific bound. z = 1/(q^{1/2} + q^{-1/2}) is convention C and is NO LONGER the production Markov parameter (production is D, z = q³/(q²+1)); this paragraph used to call it "the production Markov parameter" and to bill this as "the stronger, q-independent form, which supersedes mu_unreachable as the headline". Both withdrawn. For a z of the C form, AM-GM (two_le_add_inv, markov_param_le_half) gives z ≤ 1/2 for every q. With d ≤ 0 that forces μ ≤ 1/2 (mu_le_half) and hence

    B_bond = −α·log μ  ≥  α·log 2  =  2.90150117984 MeV,

    against B_AME(²H) = 2.224566 — 30.43 % below. This holds for every q, every crossing convention, and every multiplicity — but only for a z of the form 1/(x + x⁻¹), which is where AM-GM bites.

    SCOPE CORRECTION 2026-08-09. This paragraph previously added "and every N in an SU(N) choice of z (larger N shrinks z and increases the floor)". That is false, and it mattered. It assumed the SU(N) family is z = 1/[N], which it is not — the SU(N) weights are quantum dimensions (hook-content), and the SU(2) member is registry convention D at z = q³/(q²+1) = 0.6126880 > 1/2. markov_param_le_half does not apply to it, so neither does the floor. Measured under D the admissible band is [2.0507, 3.7978] MeV and B_AME(²H) = 2.224566 lies inside it, with the required offset d = −0.1192·h admissible. The impossibility below is therefore specific to convention C, the production binding trace, not a statement about Markov traces in general. See computations/y_lambda_su_n.py and docs/coordination/trace-convention-registry.md.

    Within convention C it stands — and only there. Contrapositively (alpha_upper_bound), under C the deuteron would be reachable only if

    α  ≤  B_AME(²H)/log 2  =  3.2093703 MeV,

    while the derived α = m_e/(q₀(q₀−1)) = 4.1859814 exceeds that by 30.43 %. Pursued in bean qou-qlma.

    charge_independence_iff — the strong force is charge independent, so a bond model must give L_pp = L_nn. With d_pp = 0 (σ) and d_nn = −h (σ⁻¹) that demands z = z − h, i.e. h = 0, i.e. q = 1: the classical limit, where the Hecke structure is gone. Measured under C, α(L_nn − L_pp) = 2.27077 MeV; under D with the derived writhe term wired it is 0.76532 MeV (the writhe factor (1−h)^(Δe/2) shifts pp and nn equally and oppositely, removing 56.19 % of the asymmetry). Either way the splitting is an artifact of the σ/σ⁻¹ charge assignment, not an isospin effect — charge symmetry demands the strong mirror split be small, and the flavour parameter δ cancels out of it entirely by mirror_split_eq_L_diff. Nature's 0.7638 MeV is mostly Coulomb (uniform-sphere E_C alone gives 0.9984), so the strong sector should supply only the small Nolen–Schiffer residual, not the whole split. Beans qou-4waf, qou-usft.

    proj_add_eq_one / proj_mul_eq_zero — the same quadratic supplies the isospin decomposition for free. P₊ = (σ + q⁻¹)/(q + q⁻¹) and P₋ = (q − σ)/(q + q⁻¹) are complementary orthogonal idempotents, and for two nucleons T=1 is the isospin-symmetric channel, T=0 the antisymmetric one. Their interface scalars are μ₊ = (z + q⁻¹)/(q + q⁻¹) and μ₋ = (q − z)/(q + q⁻¹), with μ₊ + μ₋ = 1.

    Base ring: generic (§7c). The algebra A is a plain [Ring A] over a commutative [CommRing R] of scalars, so nothing here assumes the Hecke algebra is commutative; the ordered results take [Field R] [LinearOrder R] [IsStrictOrderedRing R]because they are about the *scalar*μ, never about A`.

    Companion audit: docs/audits/2026-08-08-binding-functional-attack-vectors-and-li2q-guard.md. Beans qou-c6gx, qou-h7mh.

    Scope. This is a structural result about the interface — it collapses to one scalar, and that scalar is bounded by the Hecke range. It is not an impossibility result for the deuteron; that reading was C-specific and is retracted above. It is conditional in one place: interface_scalar takes the Markov property as a hypothesis, because in this corpus that property is an axiom carrying a sorry (jones-markov-trace.lean, standing in for Jones 1987) rather than a theorem. Nothing here proves the trace exists.

    It also does not claim the interface is where the ²H error lives. Note the premise of that argument has itself been retracted: an admissible μ does reach AME under convention D (see the retraction above). The per-bond sign-change evidence (audit §4) was also computed under C and needs re-running before it is cited. The two positive routes suggested by proj_* — a derived Clebsch weighting, and charge independence imposed with Coulomb carrying the mirror split — are neither formalised nor wired here.

    The Li₂^q product form of audit §8 is not in this file; it needs a Fubini argument on a doubly-indexed sum and is tracked separately (bean qou-cw27).

This is what forbids "adding more knot operations" at the interface: there is nowhere for them to go.

    theorem QOU.QBeta.InterfaceScalar.interface_scalar {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A] [Algebra R A] (tr : A → R) (W σ : A) (z a b : R) (hadd : ∀ (x y : A), tr (x + y) = tr x + tr y) (hsmul : ∀ (c : R) (x : A), tr (c • x) = c * tr x) (hmarkov : tr (W * σ) = z * tr W) :

    theorem QOU.QBeta.InterfaceScalar.bond_energy_floor (a mu : ℝ) (ha : 0 < a) (hmu : 0 < mu) (h : mu ≤ 1 / 2) :
    a * Real.log 2 ≤ -a * Real.log mu

    The universal binding floor. Combining mu_le_half with the fact that -log is decreasing: for any admissible interface scalar,

    B_bond = -α·log μ  ≥  α·log 2.

    Numerically α·log 2 = 2.90150117984 MeV while B_AME(²H) = 2.224566, which is 30.43% below the floor.     Which functional carries a multiplicative trace to an additive energy #

    docs/audits/2026-08-08-binding-functional-attack-vectors-and-li2q-guard.md §10a argues the binding functional is derived rather than chosen: tr_M is multiplicative over independent subsystems (tr_atom = tr_free * Prod_bonds mu_k, measured there to 1.2e-31) and energy is extensive, so the map from trace to energy satisfies Cauchy's f(xy) = f(x) + f(y) and the log form is forced.

    That argument lived only in audit prose. The five-path grep in docs/audits/2026-08-25-deuteron-attack-c-convergence.md recorded "Lean: nothing", and that part was correct. This section supplies the half that is mechanically checkable.

    What is proved here, and what is not. The comparison the corpus actually runs — log versus linear, the two candidates §10a weighs — is proved: the log form is extensive, the linear form is not, its failure has an exact closed form, and it carries a ceiling that kills it above A = 2 independently of extensivity. The uniqueness step ("the only continuous solutions of Cauchy's equation on (R_+, x) are c log x") is a classical theorem that is not formalised here, so "forced" still rests on it. Do not cite this section as a formalisation of §10a's uniqueness claim.

    theorem QOU.QBeta.InterfaceScalar.logForm_extensive (a x y : ℝ) (hx : 0 < x) (hy : 0 < y) :

    The log form is extensive. A product of bond scalars becomes a sum of bond energies — the property §10a requires of the trace-to-energy map.

    theorem QOU.QBeta.InterfaceScalar.linearForm_extensivity_defect (a x y : ℝ) :

convention D   z = q^3/(q^2+1)     defect = 0.966887

    The conclusion is unaffected in either convention — the closed form vanishes only when x = 1 or y = 1 — but the quoted figure needs the scope.

    theorem QOU.QBeta.InterfaceScalar.markov_param_determined {R : Type u_1} [Field R] (q y₂ y₁₁ z : R) (hnorm : y₂ + y₁₁ = 1) (htr : y₂ * q + y₁₁ * -q⁻¹ = z) :
    z = y₂ * (q + q⁻¹) - q⁻¹

    The Markov parameter is not a free choice — the weights fix it.

    At n = 2 the two irreps are (2) and (1,1), both one-dimensional, with χ^{(2)}(σ) = q and χ^{(1,1)}(σ) = −q⁻¹. Given only the Markov normalisation Σ_λ y_λ d_λ = 1 (here y₂ + y₁₁ = 1) and the pairing tr_M(σ) = Σ_λ y_λ χ^λ(σ), the parameter z := tr_M(σ) is a function of the weights:

    z = y₂·(q + q⁻¹) − q⁻¹.

    y_lambda_at(n, q) takes only q — there is no z argument — so z is a consequence of the Jones–Markov hook-length weights, not an input beside them. Checked numerically at q₀: tr_M(σ) from y_λ equals 1/(√q + 1/√q) to 7.3e-31 (the 30-digit y_λ cap). Consequently z cannot be retuned to close ²H without contradicting y_λ.

    theorem QOU.QBeta.InterfaceScalar.mirror_split_eq_L_diff {R : Type u_1} [CommRing R] (a L_pp L_pn L_nn : R) :
    a * (L_pn + L_nn) - a * (L_pp + L_pn) = a * (L_nn - L_pp)

    The mirror splitting sees only L_nn − L_pp; the p–n bond cancels.

    On the chain topology ³H = pnn carries bonds {pn, nn} and ³He = ppn carries {pp, pn}, so the predicted splitting is α(L_nn − L_pp) regardless of what the p–n bond is. Combined with charge_independence_iff (L_pp = L_nn ⟺ h = 0) this says the model's mirror splitting is nonzero precisely because the σ/σ⁻¹ templates are charge-assigned — it is an artifact, not isospin physics. Measured: α(L_nn − L_pp) = 2.27077 MeV against nature's 0.7638, which is mostly Coulomb. Giving all three bonds the same template sends it to zero.

    theorem QOU.QBeta.InterfaceScalar.binding_indep_of_free_trace (a trf mu : ℝ) (hf : 0 < trf) (hm : 0 < mu) :
    -a * Real.log (trf * mu) - -a * Real.log trf = -a * Real.log mu

    The nucleon identity cancels out of the binding. Since tr_atom = tr_free · μ, the binding −α·log tr_atom − (−α·log tr_free) is −α·log μ: tr_free, and with it tr_M(p) and tr_M(n), drops out entirely.

    This is why all isospin physics must live in the interface — nothing else survives the difference. In particular any assignment with d_pp = d_nn gives identically zero mirror splitting no matter how the proton and neutron words differ, which is what mirror_split_eq_L_diff sees from the other side.

    Can a space index break the pn degeneracy? #

    Bean qou-vbyi proposes a space index on the interface as "the only route past the proved flavour-only degeneracy", on the strength of qou-kj4v's observation that in the Standard Model the ³S₁/¹S₀ split is the tensor force — a spin-space coupling — and that "the Hecke interface has one index (the strand) and no space index to carry it."

    The reading of that as "add a space factor" does not survive a check, and the reason is in qou-kj4v's own sentence: "In S-wave Pauli LOCKS spin to isospin (space symmetric ⇒ spin and isospin symmetry opposite)." Both pn channels are S-wave, L = 0 — ³S₁ and ¹S₀ are both S in ²ᴹ⁺¹L_J. So a factor keyed on L takes the same value on both, and a common factor cannot separate what was already equal.

    The theorem below states this for an arbitrary separable interface, so it covers any space index entering multiplicatively, keyed on anything constant across the two channels — not merely L.

    source
    theorem QOU.QBeta.InterfaceScalar.separable_interface_degenerate {R : Type u_1} [CommMonoid R] {Sp : Type u_2} {Is : Type u_3} {Sp3 : Type u_4} (fSpin : Sp → R) (fIso : Is → R) (fSpace : Sp3 → R) (s1 s0 : Sp) (t1 t0 : Is) (ell : Sp3) (hplus : fSpin s1 = fIso t1) (hminus : fSpin s0 = fIso t0) :
    fSpin s1 * fIso t0 * fSpace ell = fSpin s0 * fIso t1 * fSpace ell

    A separable interface stays degenerate on the two pn channels, whatever space index it carries.

    The hypotheses encode the Pauli lock exactly as qou-kj4v states it: the triplet is (S = 1, T = 0) and the singlet (S = 0, T = 1), and the same two projector scalars μ₊, μ₋ appear in each SU(2) with the roles exchanged. The space factor is applied at one and the same ell, which is the physical input — both channels are S-wave.

    The conclusion holds for every fSpace, so no choice of space index rescues a separable interface. What the tensor force does in the Standard Model is couple spin to space; a product of a spin function and a space function is precisely what a coupling is not.

    interface_scalar above takes tr (W * σ) = z * tr W as a hypothesis — its own docstring flags this as an axiom standing in for Jones (1987), not a theorem. The question this answers is when that hypothesis may be assumed, which the corpus had not pinned down.
