      🛑 RESOLVED 2026-09-12: the hypothesis of towerSum_of_const is FALSE #

      qou-y3bm left one gap — is Δ^{(n)} level-independent? It is not, and the corpus already said so. prop:brane-tower-q-laplacian-decay's Step 3 states an equality, not a bound:

      |⟨e_k, Δ^{(n)} e_k⟩| = (λ_k^{(q)})^n ,      λ_k^{(q)} = [k]_q² ℏ_q / L_q²

      so Δ^{(n)} is the n-th iterate of the q-Laplacian and its eigenvalue grows (or decays) geometrically in n. towerSum_of_const is a true theorem whose hypothesis this object does not satisfy.

      The true sum is therefore geometric in ℏ_q² · λ_k, not in ℏ_q² (towerSum_iterated below), and it coincides with 1/(1 - ℏ_q²) exactly when λ_k = 1 (towerSum_iterated_eq_simple_iff). At the leading mode k = 1, [1]_q = 1, so λ_1 = ℏ_q / L_q² and λ_1 = 1 iff

      L_q = √ℏ_q .

      So qbeta_e0.tower_summed does carry a hidden parameter after all, and it is now named: it fixes the q-deformed filament length to √ℏ_q. That is a choice, not a derivation — L_q is a free geometric scale (fluid-dynamics/discrete-vortex-spectrum calls it "the q-deformed filament length"; the Kelvin-dispersion derivation takes L_q = L, the period). The honest statement is that the tower factor is a one-parameter family in L_q and the implemented value selects one member.
