    The spin–space (tensor) coupling cannot fix the two-nucleon sign defect #

    computations/probes/two_nucleon_sector_sign_probe.py measures that the framework binds the diproton and the dineutron (+2.5416, +3.3069 MeV) where nature has no bound state, and over-binds the deuteron by 27.3 % (+2.8328 vs +2.2246). Every interface-scalar mechanism is already excluded in Lean — single_crossing_binds, t3_grading_cannot_unbind_pp, the projector floor μ₊ + μ₋ = 1, the T-odd total floor (TwoChannelTotalBindingFloor), and any separable space factor (InterfaceScalar.separable_interface_degenerate). Bean qou-vbyi names the one surviving shape: a non-separable (S, L) coupling — the ³S₁–³D₁ tensor force, "the only route past the proved flavour-only degeneracy".

    This file shows that route cannot fix the sign defect, and cannot fix the deuteron either. Two invariants, each proved sorry-free.

    (A) The tensor operator acts as a scalar on the spin singlet — and that scalar is 0 #

    By Pauli, in a relative S-wave the two-nucleon spin and isospin symmetries are opposite: pp and nn (T = 1) are pure spin singlets (S = 0). The tensor operator is S₁₂(n̂) = 3 (σ₁·n̂)(σ₂·n̂) − σ₁·σ₂. On the singlet |s⟩ = |↑↓⟩ − |↓↑⟩:

    • σ₁·σ₂ |s⟩ = −3 |s⟩ (sigmaDot_mulVec_singlet)
    • (σ₁·n)(σ₂·n) |s⟩ = −|n|² |s⟩ for every n (nDotProd_mulVec_singlet)
    • hence S₁₂(n) |s⟩ = 3(1 − |n|²) |s⟩, which is 0 on the unit sphere (tensorOp_mulVec_singlet, tensorOp_annihilates_singlet).

    The singlet is an eigenvector of both generators, so any coupling built from them has no off-diagonal element out of S = 0 — there is nothing for the tensor force to mix the singlet with (equivalently: at J = 0, S = 0 has no L = 2 partner). The channel where the sign defect lives is untouched, for every direction n̂.

    (B) Off-diagonal coupling only LOWERS the ground state #

    Where the tensor force does act — the triplet, mixing ³S₁ with ³D₁ — the coupled 2×2 block [[E_S, t], [t, E_D]] has lower eigenvalue λ₋ = (E_S+E_D)/2 − √(((E_S−E_D)/2)² + t²), and

    • λ₋ ≤ E_S always, λ₋ < E_S whenever t ≠ 0 (lowerEigen_lt_left_of_ne).

    So tensor mixing makes the deuteron strictly more bound than the uncoupled ³S₁. The uncoupled channel is already 27.3 % over-bound; coupling moves it the wrong way.

    Verdict (scope-(b), invariants named above) #

    The non-separable (S, L) tensor coupling of qou-vbyi route 1 is a dead end for both A = 2 defects: it is identically zero on the singlet where pp/nn live, and it can only deepen the triplet where the deuteron is already over-bound. This closes the "live shape" that bean leaves open. It does not exclude unbinding as such — the writhe- normalised even-negative stacked words σ^{−2k} do unbind (SingleCrossingAlwaysBinds §scope), at 6–9× nature's magnitude — nor a change to the binding law itself.

    Base ring (§7c) #

    Part (A) is over ℂ because σ_y needs √−1; no ordering, no Real.* — it is exact matrix algebra. Part (B) is over ℝ by nature (an ordering statement with Real.sqrt).
