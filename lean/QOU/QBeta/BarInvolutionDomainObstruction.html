    theorem QOU.QBeta.BarInvolutionDomainObstruction.bar_pair_not_formable_of_subset_ball {K : Type u_1} [Field K] [LinearOrder K] [IsStrictOrderedRing K] (S : Set K) (hS : ∀ x ∈ S, |x| < 1) {q : K} (hq : q ≠ 0) :
    ¬(q ∈ S ∧ q⁻¹ ∈ S)

    The obstruction, as used. If a carrier's domain S is contained in the open unit ball, then for every nonzero q at most one of q, q⁻¹ lies in S.

    Consequently F(q) + F(q⁻¹) — hence the bar-even and bar-odd projections — is not formable anywhere on S. Not divergent: undefined.

    The positive half: the modulus-fixed locus is the unit circle #

    source
    theorem QOU.QBeta.BarInvolutionDomainObstruction.bar_modulus_stable_iff_abs_eq_one {K : Type u_1} [Field K] [LinearOrder K] [IsStrictOrderedRing K] {q : K} (hq : q ≠ 0) :
    |q⁻¹| = |q| ↔ |q| = 1

    A nonzero point is modulus-stable under the bar involution iff it lies on the unit circle.

    This is the structural reason the Habiro ring is built at roots of unity and not at an archimedean anchor: |q| = 1 is exactly the locus where q and q⁻¹ have the same modulus, so a domain can contain both. Pairs with HabiroEvaluationTrichotomy.qPoch_eq_zero_of_pow_eq_one, which says the evaluation exists there.

    Instantiated at the substrate #

    theorem QOU.QBeta.BarInvolutionDomainObstruction.substrate_pair_straddles_unit_circle {q : ℝ} (hq : 1 < q) :
    1 < |q| ∧ |q⁻¹| < 1

    The substrate bar-pair straddles the unit circle. For real q > 1 the anchor is outside the closed unit ball and its bar-partner is strictly inside.

    So neither member sits on the modulus-fixed locus of bar_modulus_stable_iff_abs_eq_one, and by not_mem_ball_and_inv_mem_ball no ball-shaped domain holds both.
