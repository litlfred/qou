    class QOU.QBeta.StateIntegral.Recursion (R : Type u_3) (M : Type u_4) [Field R] [AddCommGroup M] [Module R M] (A B : ℕ) (q : R) (I : ℤ → ℤ → M) :
    Prop

    §3b-cond hypothesis class carrying Fantini–Wheeler eq. (14).

    Recursion R M A B q I asserts that the family I : ℤ → ℤ → M, I m ℓ = I_{m,ℓ}, satisfies the two FW relations for the positive integers A ≠ B and the deformation parameter q. Each field is the recursion itself (a parameter-quantified equation in M), NOT a conclusion — this is the FW INPUT, to be assumed; the theorems below DERIVE the algebraic lattice structure from it.

    This is the analytic content FW prove for the actual integrals; here it is axiomatized so the downstream algebra can be checked by Lean.

    • hA : 0 < A

      FW setup: A is a positive integer.

    • hB : 0 < B

      FW setup: B is a positive integer.

    • hAB : A ≠ B

      FW setup: A ≠ B (so max{A,B} is a strict maximum).

    • relation_l (m ℓ : ℤ) : I m (ℓ + 1) = ∑ k ∈ Finset.range (B + 1), (↑(B.choose k) * (-1) ^ k * q ^ (-(ℓ * ↑k))) • I (m + ↑k) ℓ

      Left equality of (FW 14): the raising-in-ℓ relation. I_{m,ℓ+1} = ∑_{k=0}^{B} C(B,k)(−1)^k q^{−ℓk} I_{m+k,ℓ}.

    • relation_r (m ℓ : ℤ) : I m (ℓ + 1) = ((-1) ^ A * q ^ (↑A + m)) • I (m + ↑A) ℓ

      Right equality of (FW 14): the single-shift relation. I_{m,ℓ+1} = (−1)^A q^{A+m} I_{m+A,ℓ}.

      theorem QOU.QBeta.StateIntegral.row_zero_top_reduction {R : Type u_1} {M : Type u_2} [Field R] [AddCommGroup M] [Module R M] {A B : ℕ} {q : R} {I : ℤ → ℤ → M} [inst : Recursion R M A B q I] (hq : q ≠ 0) (m : ℤ) :
      I (m + ↑(max A B)) 0 ∈ Submodule.span R {y : M | ∃ j < max A B, y = I (m + ↑j) 0}

      Top-of-window reduction (m-direction one step). The top index of the order-max{A,B} recurrence, I_{m+max{A,B},0}, lies in the span of the fundamental window {I_{m,0}, …, I_{m+max{A,B}−1,0}}.

      This is the single-step reduction that shifts any row-0 index toward a size-max{A,B} fundamental domain — the algebraic core of FW's "max{A,B} independent integrals". Two cases on A ≠ B: if B < A the top is the A-shift (row_zero_solve_A + span monotonicity); if A < B the top is the B-term, isolated from the recurrence (its coefficient (−1)^B is a unit).

      theorem QOU.QBeta.StateIntegral.row_zero_bot_reduction {R : Type u_1} {M : Type u_2} [Field R] [AddCommGroup M] [Module R M] {A B : ℕ} {q : R} {I : ℤ → ℤ → M} [inst : Recursion R M A B q I] (m : ℤ) :
      I m 0 ∈ Submodule.span R {y : M | ∃ (j : ℕ), 1 ≤ j ∧ j ≤ max A B ∧ y = I (m + ↑j) 0}

      Bottom-of-window reduction (m-direction one step, mirror image). The bottom index of the order-max{A,B} recurrence, I_{m,0}, lies in the span of the window above it, {I_{m+1,0}, …, I_{m+max{A,B},0}}.

      This is the mirror of row_zero_top_reduction: it shifts any row-0 index up toward a size-max{A,B} fundamental domain. Unlike the top reduction, no case split on A ≠ B is needed — the k = 0 term of row_zero_recurrence always carries the unit coefficient C(B,0)·(−1)^0 = 1, so I_{m,0} is isolated directly:

      I_{m,0} = (−1)^A q^{A+m}·I_{m+A,0} − ∑_{k=1}^{B} C(B,k)(−1)^k I_{m+k,0},

      and every index on the right (m+A with 1 ≤ A ≤ max{A,B}, and m+k with 1 ≤ k ≤ B ≤ max{A,B}) lies in the up-window. (No hq hypothesis: the isolated coefficient is 1, so no inverse is taken.)

      theorem QOU.QBeta.StateIntegral.row_zero_in_window {R : Type u_1} {M : Type u_2} [Field R] [AddCommGroup M] [Module R M] {A B : ℕ} {q : R} {I : ℤ → ℤ → M} [inst : Recursion R M A B q I] (hq : q ≠ 0) (m : ℤ) :
      I m 0 ∈ Submodule.span R {y : M | ∃ j < max A B, y = I (↑j) 0}

      Two-sided ℤ reduction of row 0 into a fixed size-max{A,B} window. Every row-0 integral I_{m,0}, for any m ∈ ℤ, lies in the R-span of the single fundamental window {I_{0,0}, I_{1,0}, …, I_{max{A,B}−1,0}}.

      This is the full finite-generation core FW's "max{A,B} independent integrals" corollary rests on: the entire two-sided row ℓ = 0 reduces into one size-max{A,B} window. The proof is two ℕ-indexed strong inductions:

      • upward (hUp, ∀ n : ℕ, I_{n,0} ∈ W): indices < max{A,B} are window generators; an index n ≥ max{A,B} is pushed down by row_zero_top_reduction (base n − max{A,B}) into {I_{n−max,0}, …, I_{n−1,0}}, every element of which is a strictly-smaller natural index — strong IH.
      • downward (hDown, ∀ n : ℕ, I_{−n−1,0} ∈ W): row_zero_bot_reduction pushes I_{−n−1,0} up into {I_{−n,0}, …, I_{−n−1+max,0}}; each element is either a nonnegative index (covered by hUp) or a strictly-smaller negative index — strong IH.

      This is the literal "max{A,B} independent integrals" bound of FW: ≥ is row_zero_in_window (every generator reduces into the window), ≤ is that each window element is itself a row-0 integral.
