    theorem QOU.QBeta.det_sub_traceless (a b c d e f : ℝ) :
    -(a - d) ^ 2 - (b - e) * (c - f) = -a ^ 2 - b * c + (-d ^ 2 - e * f) + (2 * a * d + b * f + c * e)

    The mechanism. For traceless 2 × 2 matrices written out by entries, det (A₀ − B₀) = det A₀ + det B₀ + tr (A₀ B₀), where a traceless (x, y; z, −x) has det = −x² − yz and tr (A₀ B₀) = 2ad + bf + ce.

    theorem QOU.QBeta.sub_elliptic_iff_pairing_large (a b c d e f : ℝ) :
    0 < -(a - d) ^ 2 - (b - e) * (c - f) ↔ -(-a ^ 2 - b * c + (-d ^ 2 - e * f)) < 2 * a * d + b * f + c * e

    The ellipticity criterion in Killing-pairing form: the difference of two traceless directions is elliptic (det > 0) exactly when their pairing exceeds minus the sum of their determinants. For two hyperbolic directions (det A₀, det B₀ < 0) that threshold is positive, so alignment is required.

    0 < -(dA + dB)

    Two hyperbolic directions force a strictly positive alignment threshold, so the difference cannot be elliptic "for free" — the pairing has to be large. This is what makes the measured 2.107175 > 2.098162 a statement about the nucleons rather than a generic fact.
