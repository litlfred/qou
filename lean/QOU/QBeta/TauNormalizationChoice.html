    QOU.QBeta.TauNormalizationChoice — the A=1-vs-A=2 binary, machine-tracked #

    The qou-pzzl convention split, stated as mathematics instead of prose: the bar-odd observable S is normalized two ways in the corpus —

    • full-potential (ArgUPhaseBranchSelection / NZBarEvenVolumeFace): S = Im Φ(u) = κ_shape·(Re²u − Im²u), κ_shape = √3/2;
    • complex-volume, integer-dressed (SDeformedVolumeChannel): S = A_ω · Im 𝔙(u) = A_ω·κ_pot·(Re²u − Im²u), κ_pot = √3/4.

    Since Φ = 2𝔙 exactly (kappaFull_eq_two_mul_kappaCV, sorry-free), the full-potential convention IS the complex-volume convention with the integer forced to 2 (usesFullPotential_iff_A_two below), so the split is a single integer variable with candidate values {2, A_ω}. The exclusivity theorem makes the pzzl statement "one is wrong" precise: two integer dressings of the same nonvanishing channel force equal integers — so A = 2 and A = 3 cannot both hold anywhere Im 𝔙(u q) ≠ 0.

    Honesty (§3b; anti-laundering) #

    Nothing here decides the binary. Which normalization the fibre→observable (τ/archimedean) functor applies is the OPEN content of bean qou-yh67 (blocked on the A_ω internal derivation); no instance of either predicate is fabricated, and no numerical S is wired. This file only replaces the prose-tracked convention split with definitions the corpus can state conditional theorems against.
