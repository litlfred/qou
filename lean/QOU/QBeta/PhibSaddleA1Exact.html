    QOU.QBeta.PhibSaddleA1Exact — the saddle 2-loop A₁ = 1/3 + (17√3/108)·i (exact) #

    The 2-loop coefficient of the potential V(z) = Li₂(z) − Li₂(1/z) at the geometric saddle z* = e^{iπ/3} is

    A₁ = V⁗(z*)/(8·V''(z*)²) − 5·V'''(z*)²/(24·V''(z*)³).

    The saddle derivatives are algebraic (all in ℚ(√3, i)), pinned to 50+ dps by the probe computations/qbeta/qbeta_phib_a1_vs_ohtsuki_kappa1.py and confirmed symbolically (sympy):

    V''(z*)  = 3/2 − (√3/2)·i,
V'''(z*) = 2 + 3√3·i,
V''''(z*) = −39/2 + (3√3/2)·i.

    This file certifies the arithmetic: given these algebraic derivative values, the 2-loop coefficient is exactly 1/3 + (17√3/108)·i. The derivative values themselves are the numerically-established physical inputs (Li₂-derivative evaluation, outside Mathlib's current reach); this theorem discharges the field computation on top of them, division-free.

    Scope note (self-review, PR #3874). A₁ is the exact 2-loop of this potential; it is not the 4₁ Ohtsuki 2-loop invariant κ₁ = 11√3π/108 (they disagree — A₁ is π-free, κ₁ real/π-bearing). So V = Li₂(z) − Li₂(1/z) is a Vol+torsion reconstruction, not the 4₁ state integral. This lemma records the exact value; it makes no physical b-dictionary claim.

    Base ring: ℂ (the saddle values are genuinely complex — archimedean, post-wall).
