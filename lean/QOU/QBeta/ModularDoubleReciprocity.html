        theorem QOU.QBeta.ModularDoubleReciprocity.modular_reciprocity {K : Type u_1} [Field K] (c y : K) (hy : y ≠ 0) :
        logQ c y * logQDual c y = c ^ 2

        The modular-double reciprocity. log q * log q~ = c^2, for every y ≠ 0 — the y cancels.

        Generic per §7c: any field, and no pi, no ordering, no ℝ.

        This is a statement about the two defs above, which are stipulated. It is (c y)(c / y) = c^2 and nothing more. That it is algebraic is the Option-B point — an algebraic identity leaves no convention to re-choose — but the step from Faddeev's q, q~ to these definitions is imported, not proved. See the module docstring.

        theorem QOU.QBeta.ModularDoubleReciprocity.self_dual_iff_y_eq_one {c y : ℝ} (hc : 0 < c) (hy : 0 < y) :
        logQ c y = logQDual c y ↔ y = 1

        The balanced point. The two sides agree exactly at y = 1 — at c = 2pi that is q = exp(-2pi) ≈ 0.00187.

        Archimedean: the ↔ needs y > 0 to rule out y = -1, so this one takes ℝ.

        logQDual c y < logQ c y

        Near 1 is the worst place to sit. For 0 < y < 1 the dual's log is strictly the more negative, so |q~| < |q|; by logQDual_eq_div the gap widens reciprocally as y → 0.

        The substrate has y = ln q0 / (2pi) ≈ 0.0166, which is this case — and the resulting |log q~| ≈ 378 is the 4.8e-165.
