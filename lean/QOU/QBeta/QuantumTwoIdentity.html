    Quantum-2 algebraic identities #

    Proves the key identity connecting the quantum integer [2]_q to q · ℏ_q²:

    -(q + q⁻¹) = -2 - (q-1)²/q

    i.e. -[2]_q = -2 - q·ℏ_q².

    Corrected 2026-08-30 (bean qou-6bla): this file said ℏ_q² = (q-1)²/q, and that is false. ℏ_q = 1 - q⁻¹, so ℏ_q² = (q-1)²/q² — a factor of q smaller. At q₀ = 1.1099785827513808, (hbarQ q)^2 = 0.0098171865 against (q-1)²/q = 0.0108968667, a ratio of 1.1100. The identity itself is correct and untouched; only its reading was wrong.

    What this does NOT settle. The old text went on to say the gap from the classical value -2 is "exactly ℏ_q² = the expansion parameter of the precision ladder". The gap is (q-1)²/q, so it is q·ℏ_q², not ℏ_q² — but whether the ladder's parameter u = b·ℏ_q² ≈ 0.00852 is the one or the other cannot be read off here, since b is not fixed in this file. That is a question for the c_k ladder owner (qou-cds1), not something this correction resolves; the claim is withdrawn rather than replaced.

    Sorry-free. The identity is pure algebra (field_simp; ring).
