    The GGM curve's roots are locally differentiable in x #

    Bean qou-trns. QOU/MathlibExt/ImplicitScalar.lean supplies the scalar implicit function theorem; this file plugs it into the curve, which is the only thing standing between that brick and the envelope step.

    Two pieces:

    • hasStrictFDerivAt_curve — the curve, as a function of (x,y) : ℂ × ℂ, is strictly differentiable everywhere, with derivative ∂ₓc • fst + ∂_yc • snd. Mechanical (it is a polynomial), but the partials have to be written down and matched against what the mul/pow/sub combinators produce.

    • exists_hasDerivAt_root — the payoff. Off the discriminant locus, a root of the curve is locally a differentiable function of x, with the IFT value.

    The partials #

    curve x y = x·y³ − (x²+1)·y² + (x²+x+1)·y − x

∂ₓcurve = y³ − 2x·y² + (2x+1)·y − 1
∂_ycurve = 3x·y² − 2(x²+1)·y + (x²+x+1)

    ∂_ycurve ≠ 0 is exactly "y is a simple root of the cubic", which is what the IFT needs and what fails on the discriminant locus.

    ⚠ It does not hold on all of the transport arc, and that is expected #

    exists_unit_circle_disc_zero (FiveTwoDiscriminant.lean) proves the discriminant vanishes on |x| = 1, at θ = 137.9206708879635°. There two of the three branches collide, ∂_ycurve = 0, and no differentiable labelling of individual roots exists. So this gives branches on [0,π] ∖ {φ₀} only — and QOU/Archimedean/ConstantOffOnePoint.lean is the brick that glues such a statement into one on the whole interval.

    What the envelope still needs after this #

    The chain rule for d/dφ Σⱼ V(x, yⱼ(φ)), where the dyⱼ/dx terms vanish because ∂V/∂y = 0 — and that is already free, since deformed_saddle_iff_curve says the saddle condition is the curve. Note the envelope never needs the value of dyⱼ/dx, only that it exists; this file supplies the value anyway because the IFT gives it for nothing.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms. This is one hypothesis of the envelope step, not the envelope step.

        theorem QOU.QBeta.FiveTwoDeformedSaddle.exists_hasDerivAt_root_nonvacuous :
        ∃ (g : ℂ → ℂ), g 0 = 0 ∧ (∀ᶠ (x : ℂ) in nhds 0, curve x (g x) = 0) ∧ HasDerivAt g (-curveDx 0 0 / curveDy 0 0) 0

        Non-vacuity. exists_hasDerivAt_root is an existence theorem, and one whose hypotheses nothing satisfies proves nothing. They are satisfiable: (x, y) = (0, 0) lies on the curve, and curveDy 0 0 = 1 ≠ 0.

        The check with real content is numerical and lives in Route 26: along the transport arc |curveDy| is bounded away from zero except at the branch point φ₀, where it vanishes — so the IFT applies on [0,π] ∖ {φ₀} and nowhere fails except exactly where exists_unit_circle_disc_zero says it must.
