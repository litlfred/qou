    theorem QOU.QBeta.e2_branch_pos {x : ℝ} (hx : 1 / 2 < x) :
    0 < 2 * x - 1

    E2's non-real branch is empty for 1/2 < x. Im[1/(q(q−1))] has numerator −y(2x−1) (up to the positive denominator |q|²·|q−1|²), and 2x − 1 > 0 on the substrate branch.

    theorem QOU.QBeta.e1_branch_pos {x y : ℝ} (hx : 1 / 2 < x) :
    0 < 2 * x ^ 3 + 3 * x ^ 2 + 2 * x * y ^ 2 - y ^ 2

    E1's non-real branch is empty for 1/2 < x. Im[(q+1)/(2q³)] has numerator −y(2x³ + 3x² + 2xy² − y²), and that cubic-in-x factor regroups as 2x³ + 3x² + y²(2x − 1): a sum of three terms each positive once x > 1/2. Note this holds for every y, which is what makes the branch empty rather than merely small.

    theorem QOU.QBeta.im_e2_locus_is_nonempty :
    ∃ (x : ℝ) (y : ℝ), y ≠ 0 ∧ y * (2 * x - 1) = 0

    The 1/2 < x hypothesis is load-bearing for E2: at x = 1/2 the equation holds with y = 1 ≠ 0, so a real Q_β at complex q is admissible off the substrate branch.

    theorem QOU.QBeta.im_e1_locus_is_nonempty :
    ∃ (x : ℝ) (y : ℝ), y ≠ 0 ∧ y * (2 * x ^ 3 + 3 * x ^ 2 + 2 * x * y ^ 2 - y ^ 2) = 0

    The 1/2 < x hypothesis is load-bearing for E1 too. The branch solves to y² = −x²(2x+3)/(2x−1), positive exactly on −3/2 < x < 1/2; at x = −1/2 that gives y² = 1/4, so (x, y) = (−1/2, 1/2) sits on it with y ≠ 0. Hence neither theorem above may be restated without its hypothesis.

    The first draft of this witness offered (−1, 1), where the factor is −2, not 0. It is recorded because the failure mode is the point: an existence claim whose witness does not satisfy the equation would have passed a reader and been caught only by the kernel.

    theorem QOU.QBeta.branches_disjoint (y : ℝ) :
    2 * (1 / 2) ^ 3 + 3 * (1 / 2) ^ 2 + 2 * (1 / 2) * y ^ 2 - y ^ 2 = 1

    The two non-real branches are disjoint, so the extensions disagree about where imaginarity is admissible everywhere except on the substrate. At E2's locus x = 1/2 the E1 factor is 2(1/8) + 3(1/4) + y²(0) = 1, never zero — so no q off the real axis makes both readings real at once.

    theorem QOU.QBeta.cal2_circle_lies_in_substrate_half_plane {c r x y : ℝ} (hr0 : 0 ≤ r) (hc : 9 / 10 < c) (hr : r < 2 / 5) (hon : (x - c) ^ 2 + y ^ 2 = r ^ 2) :
    1 / 2 < x

    Candidate (ii)'s whole admissible set sits in the half-plane, not just q₀. The conjecture posits that CAL-2 alone leaves an Apollonius circle of admissible complex q, with Im q as "the arc coordinate parametrizing the other admissible q values". Reading CAL-2 with a modulus — which is what produces a circle at all — gives |q − 1| = √k·|q| with k = Vol(4₁)/(m_μ/m_e), hence centre 1/(1−k) and radius √k/(1−k). The probe derives centre 1.0099145, radius 0.1000641 from the live CODATA-2022 ratio, reproducing the conjecture's own stated ≈1.010 / ≈0.100.

    Any circle with centre above 9/10 and radius below 2/5 lies strictly right of 1/2, with room to spare: the measured pair clears both bounds by an order of magnitude. So im_qbeta_zero_iff_e1 and im_qbeta_zero_iff_e2 apply at every point of the arc, and Im Q_β = 0 leaves only its two real intersections. That is candidate (ii)'s test answered on its entire admissible set rather than at one point.
