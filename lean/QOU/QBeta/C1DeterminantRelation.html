        theorem QOU.QBeta.edge_roots_mul {K : Type u_1} [Field K] {q t s : K} (hq : q ≠ 0) (ht : q ^ 2 * t ^ 2 = q - 1) (hs : q ^ 2 * s ^ 2 = q - 1) (hne : t ≠ s) :
        q ^ 2 * (t * s) = -(q - 1)

        The ∞-end product. The two edge roots multiply to −(q−1)/q², i.e. q²·(t·s) = −(q−1). Note this is strictly more than the edge equation, which only constrains each root's square.

        theorem QOU.QBeta.irregular_end_consistent {K : Type u_1} [Field K] {q t s : K} (hq : q ≠ 0) (ht : q ^ 2 * t ^ 2 = q - 1) (hs : q ^ 2 * s ^ 2 = q - 1) (hne : t ≠ s) :

        The ∞-end check. After factoring out the simple zero, det A's leading coefficient at ∞ is −(q−1)/q²; scaled by q² that is −(q−1), exactly edge_roots_mul. The Newton polygon at ∞ and a₀/a₂ agree.
