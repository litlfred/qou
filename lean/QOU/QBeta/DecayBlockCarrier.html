                            theorem QOU.QBeta.DecayBlockCarrier.decay_carried_by_single_block {R : Type u_1} [Field R] [CharZero R] {q a : R} (hq0 : q ≠ 0) (hq2 : q ^ 2 + 1 ≠ 0) :
                            y3 q (zD q) * chi3 q (deltaS q a) + 2 * (y21 q (zD q) * chi21 q (deltaS q a)) + y111 q (zD q) * chi111 q (deltaS q a) = y3 q (zD q) * chi3 q (deltaS q a)

                            (CAPSTONE) Under convention D the decay element is carried by a SINGLE one-dimensional block.

                            Combining the two halves: χ^(2,1)(Δ_S) = 0 kills the 2-dimensional block for every Markov parameter, and y_(1³)(z_D) = 0 kills the 3-row block at z_D. What remains is one term. The trace of the decay element at z_D is therefore y_(3)(z_D) · χ^(3)(Δ_S) — one weight, one character.

                            The consequence recorded in qou-cds1: block re-weighting cannot source the convention-D correction, because after the cap there is only one weight left and it is fixed by the trace axioms. An anchor can rescale it and nothing more.
