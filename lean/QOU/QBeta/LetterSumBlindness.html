    1. A letter-sum is permutation-invariant #

    source
    theorem QOU.QBeta.LetterSumBlindness.letterSum_perm_invariant {α : Type u_1} {β : Type u_2} [AddCommMonoid β] (f : α → β) {l l' : List α} (h : l.Perm l') :
    (List.map f l).sum = (List.map f l').sum

    Any sum over letters is invariant under reordering them.

    f is an arbitrary per-letter weight into an arbitrary commutative monoid: the crossing count (f ≡ 1), the crossing energy (f = +q or -1/q by sign), the writhe (f = ±1), a q-dependent weight, anything. The conclusion is the same for all of them.

    source
    theorem QOU.QBeta.LetterSumBlindness.no_letterSum_separates {α : Type u_1} {β : Type u_2} {γ : Type u_3} [AddCommMonoid β] (f : α → β) (g : β → γ) {l l' : List α} (h : l.Perm l') :
    g (List.map f l).sum = g (List.map f l').sum

    No letter-sum functional separates two words that are reorderings of each other. The contrapositive form, which is how the exclusion is used: if a selector is defined by summing a weight over the letters, then it takes the same value on σ₁σ₀ and σ₀σ₁, whose closures are measurably different links.

    Crossing ENERGY is a letter-sum (with f the per-crossing weight +q or -1/q), hence permutation-blind by the same invariant. Stated over a generic commutative ring so it is a fact about the SHAPE of the functional, not about the particular values q and -1/q.

    3. The general form: a selector that factors through a class map is #

    blind to whatever the class forgets

    source
    theorem QOU.QBeta.LetterSumBlindness.factorsThrough_blind {W : Type u_1} {C : Type u_2} {E : Type u_3} (cls : W → C) (energy : C → E) {w w' : W} (h : cls w = cls w') :
    energy (cls w) = energy (cls w')

    Factoring through a class map is blindness.

    cls is the lossy step (for the Bring→O'Hara bridge: word ↦ lattice class (m, ℓ) = (writhe, strands)); energy is anything computed downstream of it. Two words with the same class get the same value.

    source
    theorem QOU.QBeta.LetterSumBlindness.factorsThrough_blind_forall {W : Type u_1} {C : Type u_2} {E : Type u_3} (cls : W → C) {w w' : W} (h : cls w = cls w') (energy : C → E) :
    energy (cls w) = energy (cls w')

    No choice of downstream function repairs it — in particular, no modulus.

    In the bridge, the cusp modulus τ enters only when the lattice class is turned into a geodesic and the geodesic into an energy, i.e. entirely inside energy. Universally quantifying over energy therefore says: deforming τ — to the Neumann-Zagier deformed cusp shape, or to anything else, inside that family or outside it — cannot separate two words that already share a class.

    This is the Lean form of the probe's no_modulus_can_fix_the_bridge_order_blindness, and it is strictly stronger than the numerical statement: it quantifies over all moduli rather than sampling three.

    theorem QOU.QBeta.LetterSumBlindness.bridgeClass_perm_blind {α : Type u_1} (exponent : α → ℤ) (strands : ℕ) {l l' : List α} (h : l.Perm l') :
    ((List.map exponent l).sum, strands) = ((List.map exponent l').sum, strands)

    The lattice class used by the bridge is itself letter-sum-type in its first coordinate (m = exponent sum) and constant in its second (ℓ = strand count), so it is permutation-blind — which is what puts the bridge in the scope of §3 in the first place.

    4. 🛑 THE SCOPE. A class-blind OBJECTIVE over a word-dependent #

    FEASIBLE SET is not blind

    source
    theorem QOU.QBeta.LetterSumBlindness.objective_blindness_does_not_transfer_to_constrained_optimum :
    ∃ (W : Type) (X : Type) (cls : W → Unit) (feasible : W → X → Prop) (obj : X → ℕ) (w : W) (w' : W) (a : X) (a' : X), cls w = cls w' ∧ feasible w a ∧ feasible w' a' ∧ (∀ (x : X), feasible w x → obj a ≤ obj x) ∧ (∀ (x : X), feasible w' x → obj a' ≤ obj x) ∧ obj a ≠ obj a'

    The exclusion does not reach a constrained optimum whose constraints see the word.

    Exhibited concretely: an objective that cannot see the word at all (obj takes only a point of X), two words in the SAME class (cls is constant), and yet two different optimal values — because the feasible sets differ.

    This is why §1–§3 do not rule out using an embedding energy as the COST VECTOR t of the operator-selection LP/SDP while the Hecke Gram matrix G supplies the constraints. The four gluon candidates have different Markov traces, hence different G, hence different feasible sets; minimising even a completely class-blind objective over four different feasible sets can give four different answers.

    Read this as a prune that does NOT fire, not as a positive result. It says the route is not excluded. It does not say the route works, and it does not supply the per-block geometric cost t_λ that the route would need.
