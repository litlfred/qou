    theorem QOU.QBeta.MeasurementFloor.miss_factor_ge_100 (σ err : ℝ) (hσ : 0 < σ) (h : σ ≤ err) :
    100 ≤ err / (σ / 100)

    Gate arithmetic. If a prediction's error is at least one experimental sigma (sigma <= err), the miss factor against the 100x target sigma/100 is at least 100. This is the arithmetic backbone of the measurement-limited ceiling: the anchor-dependence theorems supply sigma <= err for the c_3-routed observables; this lemma converts it into the L2-dashboard statement "misses 100x by >= 100x".
