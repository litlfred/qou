    §1 — the abstract core #

    No Laurent polynomial in s agrees with 2 cos (α s) on [1,∞) when α attains every non-positive value there. Nothing below mentions a Markov parameter; this is the convention-independence.

    source
    theorem QOU.QBeta.BraidImageEigenphase.no_laurent_of_surjective_nonpos (α : ℝ → ℝ) (hsurj : ∀ y ≤ 0, ∃ (s : ℝ), 1 ≤ s ∧ α s = y) (P : Polynomial ℝ) (N : ℕ) (heq : ∀ (s : ℝ), 1 ≤ s → 2 * Real.cos (α s) = Polynomial.eval s P / s ^ N) :
    False

    The core exclusion. If α attains every non-positive real on [1,∞), then 2 cos (α ·) is not a Laurent polynomial P(s)/s^N there.

            §3 — the exclusion, in each convention #

            The hypothesis heq is the branch-1 assumption of the EigenphaseCarrierVacuity trichotomy, written out: the transfer matrix lies in the braid image, so its character is a Laurent polynomial P(s)/s^N in the substrate variable, and it equals 2 cos α because the spectrum is {e^{±iα}}. Laurent polynomials in √q are allowed, so this covers ℤ[q^{±1}] and ℤ[q^{±1/2}] alike.
