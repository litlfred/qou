    theorem QOU.QBeta.zC_spelling_eq {K : Type u_1} [Field K] {s q : K} (hs : s ≠ 0) (hq : s ^ 2 = q) (hq1 : q + 1 ≠ 0) :
    (s + s⁻¹)⁻¹ = s / (q + 1)

    The detector-blind convention-C spelling.

    1/(s + s⁻¹) = s/(q+1) whenever s² = q. Writing s for √q, the left-hand side is d_u_closed_form_proof.py:18's z = 1/(q^(1/2) + q^(-1/2)) and the right-hand side is √q/(q+1) = z_C.

    This is the identity that makes a grep for the convention-C form miss the landed proof, and it is the load-bearing step of the qou-iayk adjudication.

    theorem QOU.QBeta.clearedDenom_C_ne_D {K : Type u_1} [Field K] (u : K) (hu : u ≠ 0) (hu1 : u ^ 2 ≠ 1) :
    u ^ 2 + 1 ≠ u ^ 4 + 1

    The two frames clear genuinely different denominators.

    At q = u² convention C's z is u/(1+u²) and convention D's is u⁶/(1+u⁴). The landed law's cyclotomic factor is the first denominator cleared once per Markov peel, so the only way it survives the convention change is if the two denominators coincide — and they do not, for any u outside {0, ±1}.

    An earlier draft of this file stated the C form as u/(u²+1) = u/(u²+1), which is rfl and says nothing. This is the non-vacuous statement it was reaching for.

            theorem QOU.QBeta.cycloExp_agree_iff (Z N : ℤ) :
            cycloExpC Z N = cycloExpD Z N ↔ N = 0

            Convention C is blind to the proton/neutron distinction, and this says exactly how.

            The two cyclotomic exponents agree iff N = 0 — i.e. only on pure-proton configurations. Under C every nucleon contributes 3; under D a proton contributes 3 and a neutron 1, so the frames coincide precisely when there are no neutrons.

            source
            theorem QOU.QBeta.uExp_agree_iff (Z N : ℤ) :
            uExpC Z N = uExpD Z N ↔ 6 * Z + N = 13

            The two u-exponents agree iff 6Z + N = 13 (equivalently A + 5Z = 13).

            This is a codimension-1 line in (Z,N), not a coincidence — see helium3_unique_uExp_agreement for why one atom appeared to satisfy the C-frame law exactly while its mass-3 partner did not.

            theorem QOU.QBeta.helium3_unique_uExp_agreement (Z N : ℕ) (hN : N ≤ 2) :
            6 * Z + N = 13 ↔ Z = 2 ∧ N = 1

            ³He is the unique light atom where the two u-exponents agree.

            qou-iayk recorded that ³He matched the convention-C exponent exactly (58 = 58) while its mass-3 partner tritium was off by 5, and read the irregularity as evidence the fresh values were incoherent. They are not: (Z,N) = (2,1) is simply the one point with N ≤ 2 lying on the agreement line 6Z + N = 13.

            The bound on Z is not needed: N ≤ 2 alone forces 6Z ∈ {11,12,13}, hence Z = 2. Stated without it, since carrying a hypothesis the proof does not use would overstate what the result requires.
