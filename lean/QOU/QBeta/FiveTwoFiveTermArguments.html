    hA, hB, hC are genuine five-term instances — the argument matching, proved #

    Bean qou-rhyp; roast item 1 of qou-rstq, which set this as the first thing to attack:

    "If any of hA, hB, hC is not a genuine five-term instance — wrong argument, wrong branch — the whole derivation collapses. They were checked numerically to 1e-40; check the algebra of the arguments independently."

    This file is that check, in Lean. Probe qbeta_5two_route14_fiveterm_arguments_exact_probe.py does it in exact arithmetic in ℚ(w); the two agree.

    The point #

    The five-term (Abel) relation

    L x + L y - L (x·y) - L (x(1-y)/(1-x·y)) - L (y(1-x)/(1-x·y)) = 0

    determines its last three arguments as rational functions of (x, y). So "hA is a five-term instance" is not a numerical claim — it is the claim that those rational functions evaluate to the arguments hA actually names. A check to 1e-40 cannot distinguish that from "some other identity that happens to hold at these points". Matching the arguments identically can.

    The generator #

    Everything is written in terms of x = w₂, which is itself a root of the same cubic (σ z = (z-1)/z is an order-3 automorphism of ℚ(w), and w₂ = σ w₁). In that generator the argument dictionary is as simple as it ever gets:

    q = 1/(2-x)        r = x/(x+1)        s = (1-x)/x

    and it is worth seeing which identities need the cubic and which do not:

    identity needs
    arg_A2, arg_B1, arg_C1 nothing — true for every x
    arg_A1, arg_B2 the minimal polynomial
    arg_C2 the minimal polynomial, in the form (1-x)²(1+x) = x² — i.e. bloch_key

    arg_C2 is FiveTwoCyclotomicBloch.bloch_key at a different point: the same identity that made the Bloch-group element 2[w] + [-w] work turns up again as the reason hC's last argument is 1 - r. That is not a coincidence worth hiding in a comment, so it is stated as a theorem.

    Two collapses that make the instances legible #

    arg_B1 says (1-x)·q = 1-q, so hB's denominator 1 - x·y collapses to q — which is why its fifth argument comes out as exactly x, with no denominator left. arg_C1 says x·s = 1-x, so hC's denominator collapses to x, and its fourth argument is exactly 1-s. Both are division-free facts.

    Scope — what is and is not proved here #

    Proved: the argument matching, over any Field, with the non-vanishing hypotheses stated rather than assumed.

    One of them turned out not to be needed. arg_B2 and arg_C2 were first stated with x ≠ 1, on the reasoning that s = (1-x)/x needs x invertible. But the relation s·x = 1-x already forces it: at x = 0 it reads 0 = 1. So ne_zero_of_hs assumes nothing beyond hs, and the two theorems lost a hypothesis. Worth recording as a small instance of a general point — a multiplicative defining relation often carries its own non-degeneracy, and adding the side condition by reflex hides that.

    Also proved, at the end of the file: the implication. hA_of_five_term, hB_of_five_term, hC_of_five_term each take the five-term relation with its own arguments spelled out — no identification smuggled into the statement — and deliver the ladder's hypothesis verbatim. With those, the twelve hypotheses of FiveTwoLevelSevenLadder.numerators_original_form rest on exactly one unproved input.

    Not proved: the five-term relation itself. That is classical (Abel) and is now the sole open analytic input to the level-7 numerators. This file shows the three hypotheses are instances of it, and that they follow from it; it does not show it holds.

    Wiring: the five-term relation implies hA, hB, hC #

    Capstone: Abel's relation ⟹ the level-7 numerators #

    Everything in this lane composes into one statement. Its hypotheses are exactly two things — the five-term relation at three points, and reflection at four — and its conclusion is the three numerators (17, 5, -1).

    Read the hypothesis list as the honest bill: that is all that is still assumed about L. The inversion and Landen hypotheses the ladder used to take are gone, discharged by construction in FiveTwoRogersExtend; the argument identifications are gone, proved above; the hsw3 renaming is gone. What remains is Abel, and reflection — and reflection is itself proved for the corpus's real LiTwo in FiveTwoRogersReflection.

    So on this branch of the chain there is one open input, and it is classical. That is not the sum rule: the transport x = 1 → x = -1 is still unformalized (qou-trns), and extend is still not identified with the analytic continuation in Lean (qou-rstq item 4).

    source
    theorem QOU.QBeta.FiveTwoFiveTermArguments.numerators_of_abel {K : Type u_1} [Field K] {x q r s : K} (L : K → K) (L1 : K) (hx : x ^ 3 - 2 * x ^ 2 - x + 1 = 0) (hq : q * (2 - x) = 1) (hr : r * (x + 1) = x) (hs : s * x = 1 - x) (hne : 1 - x * x ≠ 0) (hrw : L (1 - x) = L1 - L x) (hrq : L (1 - q) = L1 - L q) (hrr : L (1 - r) = L1 - L r) (hrs : L (1 - s) = L1 - L s) (fiveA : L x + L x - L (x * x) - L (x * (1 - x) / (1 - x * x)) - L (x * (1 - x) / (1 - x * x)) = 0) (fiveB : L (1 - x) + L q - L ((1 - x) * q) - L ((1 - x) * (1 - q) / (1 - (1 - x) * q)) - L (q * (1 - (1 - x)) / (1 - (1 - x) * q)) = 0) (fiveC : L x + L s - L (x * s) - L (x * (1 - s) / (1 - x * s)) - L (s * (1 - x) / (1 - x * s)) = 0) :
    7 * (2 * L1 + 2 * L x - L q) = 17 * L1 ∧ 7 * (2 * L x - L r) = 5 * L1 ∧ 7 * (-(2 * L1) + 2 * L x + L s) = -L1

    Abel's five-term relation at three points, plus reflection at four, gives the level-7 numerators (17, 5, -1).

    The five-term hypotheses carry their own arguments — x * (1 - y) / (1 - x * y) and the rest — so nothing about which instance is which is assumed here; that is what arg_A1 … arg_C2 prove.
