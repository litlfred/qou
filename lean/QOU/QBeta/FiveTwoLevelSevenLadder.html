    The level-7 ladder: the three numerators follow from three five-term instances #

    Bean qou-fivt (Route 11). Companion to FiveTwoCyclotomicBloch.lean.

    Route 8 transports the 5₂ saddle sum rule to the totally real cyclotomic field ℚ(ζ₇)⁺; Route 9 reduces it to three explicit values

    Re[2·L(wₖ) + L(−wₖ)] = mₖ·π²/42,   m = (17, 5, −1),   wₖ = 1 + 2cos(2πk/7).

    Reducing to (0,1) by reflection / inversion / Landen and writing q = w₁/(1+w₁), r = w₂/(1+w₂), s = −w₃ (with 1/w₁ = w₃/(w₃−1) = 1 − w₂), the three targets become linear statements in L 1, L w₂, L q, L r, L s.

    This file proves them from three instances of the five-term relation, taken as hypotheses, with L an abstract function — matching the corpus's existing style in FiveTwoSaddleSumRule.lean (where Li is abstract and the reflection identity is an explicit hypothesis). So nothing here depends on a dilogarithm implementation, on qou-clx8, or on the Bloch group.

    The three instances, all with arguments in (0,1):

    • hA — five-term at x = y = w₂
    • hB — five-term at x = 1 − w₂, y = q
    • hC — five-term at x = w₂, y = s

    and the certificate is

    7·T₁ =   hA − 4·hB + 2·hC
7·T₂ = 4·hA − 2·hB +   hC
7·T₃ = 2·hA −   hB + 4·hC

    The coefficient triples are cyclic shifts of (1, 2, 4) — the quadratic residues mod 7 — which is where the /7 in mₖ/7 comes from.

    Scope. This derives the three numerators given the five-term instances and reflection. It does not prove the five-term relation, the inversion/Landen extensions, or Route 8's transport. The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.

    7 * (2 * L1 + 2 * L w2 - L q) = 17 * L1 ∧ 7 * (2 * L w2 - L r) = 5 * L1 ∧ 7 * (-(2 * L1) + 2 * L w2 + L s) = -L1

    The three level-7 numerators, from three five-term instances plus reflection.

    L1 stands for L 1; it is kept abstract so the statement needs no evaluation.

    The targets are stated with the 7 cleared, as 7·Tₖ = mₖ·L1. Dividing by 7 would need Field R and CharZero R — in characteristic 7 the divided form is false, and ring correctly refuses it. Cleared, the certificate has integer coefficients and the result holds over any CommRing.

    7 * (2 * L1 + 2 * L w2 - L q + (2 * L w2 - L r) + (-(2 * L1) + 2 * L w2 + L s)) = 21 * L1

    Summing the three numerators: 17 + 5 − 1 = 21, and 21/7 = 3.

    In the π² normalisation this is Σₖ Re[2L(wₖ)+L(−wₖ)] = π²/2 = 3·L(1), which is Route 8's target and hence the 5₂ sum rule.

    The reduction step, and the full chain #

    numerators_of_five_term starts from the (0,1) form. This connects it to the original quantities 2·L wₖ + L (−wₖ), so the Lean covers all of Route 11 and not merely its last linear step.

    The reduction inputs are the three extension formulas, instantiated at the points used (each is a hypothesis here; none is proved in this file):

    • inversion at w₁ > 1, together with 1/w₁ = 1 − w₂;
    • Landen at −w₁ < 0, −w₂ < 0, and w₃ < 0, whose images are q, r, and 1 − w₂ respectively;
    • s = −w₃, which already lies in (0,1), so needs no transformation.

    What happens in characteristic 7 #

    The cleared statements above hold over any CommRing, characteristic 7 included — but there they are degenerate, and it is worth proving that rather than leaving it implicit.

    With (7 : R) = 0 the certificate combination hA − 4·hB + 2·hC, which equals −3·L1 + 14·L w₂ − 7·L q identically, collapses to −3·L1 = 0. So the hypotheses force 3·L1 = 0; over a field of characteristic 7 that gives L1 = 0 (as 3 is invertible mod 7), and every target reads 0 = 0.

    So the answer to "can the divided form be made true in characteristic 7" is no, and for a sharper reason than "7⁻¹ does not exist": the hypotheses themselves are inconsistent with L1 ≠ 0 there. The cleared form is the honest statement — true everywhere, with content exactly where 7 is invertible.
