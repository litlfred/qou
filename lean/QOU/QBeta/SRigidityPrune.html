    ¬∀ (x : A), S x = g (datum x)

    Anchor-invariant input cannot reproduce an anchor-varying target. If a candidate g : D → R is fed a datum datum : A → D that is constant across two anchors (datum a = datum a'), then g ∘ datum is constant across those anchors; so a target S : A → R with S a ≠ S a' is not realized by g ∘ datum at every anchor. Applied to S = Q_β/E₀ (which swings: proton vs muon) and any fixed CAL datum 𝔇 (P_skew^β, P_avg^π, m_π, all anchor-invariant): S is not a pure function of a single anchor-invariant calibration datum.
