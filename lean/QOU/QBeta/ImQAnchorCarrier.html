    — a single global Im(q₀) cannot carry the swing; per-anchor Im(q) fits anything

    The owner's reframe (capstone #4297). q₀ is not a universal real constant but our local, measured substrate value — a field that VARIES and generically carries Im(q) ≠ 0. #4293 (ArgUPhaseBranchSelection, sorry-free) proved the bar-odd phase channel S(r,φ) = (√3/2) r² sin(2φ), φ = arg(u), u = 2 log q₀, is a maximal-leverage DOF (∂S/∂φ|₀ = √3 r² ≠ 0, nzImVolume_phase_hasDerivAt) that is frozen at strictly real q₀ (arg(u)=0, substrate_meridian_arg_zero). Allow Im(q₀) ≠ 0 ⇒ arg(u) ≠ 0 ⇒ the phase unfreezes. This file makes the falsifiable test of that reframe a typed object.

    The arg(u) ↔ Im(q₀) relation (probe, exact — qbeta_imq_anchor_carrier_probe.py). For q₀ = q_r + i ε, u = 2 log q₀, the phase's leading response is linear in ε:

    d arg(u)/dε |₀ = 1/(q_r log q_r) (numeric = analytic = 8.63427 at q_r=1.10998),

    so, composing with ∂S/∂φ|₀ = √3 r² (r = 2 log q_r), the phase-channel linear response is S ≈ k·ε with

    k = √3 r² / (q_r log q_r) = 4√3 log(q_r)/q_r = 0.651275 (exact = numeric).

    The falsifiable test. The proton-pin and muon-pin anchors are two pins of the SAME q₀, differing only ~22 ppb in q_r; the slope k is therefore anchor-invariant to 1.9×10⁻⁷, so the model MEASURES Im(q₀) faithfully. But that same near-equality is the problem: a single global Im(q₀)=ε produces the SAME S at both anchors up to the 22 ppb q_r difference — a swing of 7.4×10⁻⁹ for the fitted |ε|≈0.06, versus the observed |S_p − S_m| = 0.0492: an order-mismatch of 6.63×10⁶ (the registry dc₃/dq ≈ 3.84×10⁶ obstruction reappearing through arg(u); corrected 2026-08-29 from 4.6×10⁶, the superseded-c₃ secant — bean qou-kt8o; and the amplitude ceiling (√3/2)r² = 0.0377 at fixed r is already below |S_p|=0.0395). Reproducing the swing therefore demands a different Im(q) per anchor: ε_p = −0.061 (−5.5% of q_r), ε_m = +0.015 (+1.3%), opposite sign (forced by the merged fig8Trace_im_odd: sign S = sign ε) and 4.07× in magnitude — a free O(10⁻²) knob with no derived scale.

    Verdict — NOT a lead (scope-(a)). Both guardrail failures fire together:

    • order-mismatch wall — any anchor-invariant Im(q₀), at any physical magnitude, is ~10⁶–10⁷ too small (global_imq_cannot_realize_swing + the probe's quantitative gap);
    • unfalsifiable knob — per-anchor Im(q) fits ANY residual pair (peranchor_imq_fits_anything), with the required values sign-flipping between a mere pinning choice (required_imq_opposite_sign) and no independent predictor.

    This is exactly the honesty guardrail's purpose: it keeps "q₀ varies" from being laundered into a c₃ closure.
