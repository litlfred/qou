    The phase arg(u) channel at the real substrate ray — corrected quadrature #

    (sin → cos), and what survives of the "wall"

    CONVENTION CORRECTION (2026-07-27, bean qou-u14x). The original version of this file defined the bar-odd / Chern–Simons face as nzImVolume r φ = (√3/2)·r²·sin(2φ). The A-polynomial ground-truth computation ([docs/audits/2026-07-27-nzImVolume-sincos-convention-bug.md]) shows the correct quadrature is cos: from 𝔙(u) = Vol + i·κ·u² (the proved QOU.Knot.FigureEightComplexVolume.imV₄₁, half-potential κ = √3/4; this file keeps the full-potential normalisation √3/2),

    Im 𝔙 − 0 = (√3/2)·r²·cos(2φ), Re 𝔙 − Vol = −(√3/2)·r²·sin(2φ).

    The original file's sin-form was the Re-face (up to sign), not the Im-face. Consequences, stated plainly rather than patched around:

    • nzImVolume_real_ray inverts. On the real ray φ = 0 the bar-odd face is (√3/2)·r² — positive and maximal, not 0. The old "S = 0 on the real ray" wall theorem was false; the amphichirality statement Im 𝔙(0) = 0 holds at the complete point u = 0, not along the whole real ray.
    • The phase is stationary, not maximal-leverage. ∂S/∂φ|₀ = 0 (cos is even); the old √3·r² slope belonged to the Re-face. Phase perturbations move the bar-odd face only at second order — the phase channel is doubly frozen: never displaced (arg u = 0 at every real anchor, unchanged below) and stationary even if displaced infinitesimally.
    • What survives of the wall: the anchor-swing of the bar-odd face is carried entirely by the magnitude channel (anchor_swing_is_magnitude_only), which #4288 proved anchor-smooth. The sign flip S(muon) > 0 > S(proton) therefore cannot come from smooth phase or magnitude perturbations at the real ray at all: reaching S < 0 requires cos(2φ) < 0, i.e. crossing the diagonal φ = π/4 by a finite rotation — a discrete branch/winding datum (the cusp-lattice slope of QOU.QBeta.WindingLatticeNormForm), not an infinitesimal q₀-sensitivity. nzImVolume_quarter_turn marks the diagonal: the quarter turn lands exactly on the zero.

    The substrate-reality facts (substrate_meridian_arg_zero, anchor_phase_difference_zero) are independent of the quadrature and unchanged. No c_k value is produced; nothing inverts Q_β/CODATA; nothing is wired.

    Base ring: archimedean (Real.cos, Complex.arg, ordering) ⇒ ℝ (§7c).
