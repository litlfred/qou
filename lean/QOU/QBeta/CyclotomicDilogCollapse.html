    theorem QOU.QBeta.CyclotomicDilogCollapse.cyclotomic_collapse {K : Type u_1} [Field K] {ζ : K} {N : ℕ} (hN : 0 < N) (hζ : IsPrimitiveRoot ζ N) (x : K) :
    ∏ k ∈ Finset.range N, (1 - x * ζ ^ k) = 1 - x ^ N

    Cyclotomic collapse. Over a field K, if ζ is a primitive N-th root of unity (N > 0), then for every x : K, ∏_{k=0}^{N-1} (1 - x·ζ^k) = 1 - x^N.

    This is the finite root-of-unity reduction of the q-Pochhammer denominator (x; q)_N at q = ζ_N.
