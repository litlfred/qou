    Notation (§7aa) #

    We write χ_eu for an Euler characteristic (chiEuTotal for the whole moduli, chiEuS for a single stratum). The glyph χ alone is a notation violation: in QOU it is shared by the characters — χ_λ in the Frobenius pairing tr_M = Σ_λ y_λ χ_λ, and χ_ζ(c) — and by the Lyapunov exponent χ_q. The Euler characteristic keeps the standard glyph but always carries the roman subscript (notation/notation-collisions.md). Write χ_eu, never an uppercase \Chi: there is no such KaTeX/LaTeX macro (uppercase Greek chi is glyph-identical to Latin X), so it would fail the render gate. The orbifold Euler number of Σ(2,3,5) keeps its own conventional symbol e = −1/30.

    Which number is "the Euler characteristic"? (−2, not −6) #

    Two integers circulate and must not be conflated:

    object value source
    QOU Wedderburn/Springer Euler characteristic Σ_{λ ⊢ 3} Δ_λ −2 StokesDTCountExceedsRecursionOrder.partitionEuler3_eq
    GGM sandwich (0,1) entry −6 = (−2)·3 StokesQZeroDTCount.sandwich_offdiagonal_qzero
    Stokes/DT/BPS count S⁺(0)₀₁ 3 StokesQZeroDTCount.stokes_qzero_offdiagonal

    The −6 is the product of the sandwich prefactor −2 and the count 3, not an Euler characteristic — though the original G3 directive hinted "Euler = −6", which is exactly the ambiguity this table removes.

    The obstruction does not depend on resolving it. chiEu_even_blocks_three below rules out every even total, so both −2 and −6 are excluded, and the result is immune to which object is meant.

          theorem QOU.QBeta.DTBehrendParityObstruction.no_constant_weight_yields_three (c : Int) :
          c * -2 ≠ 3

          Constant Behrend weight cannot yield the count 3 over χ_eu = −2. If the Behrend function is constant with value c, the count is c · χ_eu = c · (−2), which is even for every integer c; the target 3 is odd. This is the parity obstruction, stated at its source.

          source
          theorem QOU.QBeta.DTBehrendParityObstruction.chiEu_even_blocks_three (E c : Int) (hE : E % 2 = 0) :
          c * E ≠ 3

          The obstruction in full generality: every even total is excluded. For any even Euler characteristic E and any constant Behrend value c, the weighted count c · E is even and so cannot equal the odd target 3.

          This is why the −2 vs −6 ambiguity is harmless: both are even, so the constant-weight class is excluded either way. Only an odd total could be rescued by a constant weight — and the QOU machinery produces even ones.

          theorem QOU.QBeta.DTBehrendParityObstruction.at_least_two_strata (S : Strata) (hE : chiEuTotal S = -2) (hD : dtCount S = 3) :
          2 ≤ List.length S

          At least two Behrend strata. A stratification with total Euler characteristic −2 and Behrend-weighted count 3 cannot have fewer than two strata: the empty one has χ_eu = 0 ≠ −2, and a single stratum forces the even n · (−2) = 3. Hence the supplier of the knot DT count is genuinely singular (a smooth moduli has the constant Behrend function (−1)^dim).

          theorem QOU.QBeta.DTBehrendParityObstruction.odd_count_needs_odd_stratum (S : Strata) (hall : ∀ (p : Int × Int), p ∈ S → p.fst * p.snd % 2 = 0) :

          Some stratum must be odd·odd. Sharpening the parity obstruction, in contrapositive (constructive) form: if every stratum contributes an even weighted term n_i · χ_eu,i, the count cannot be 3. Equivalently, any construction supplying the knot DT count must exhibit a stratum carrying both an odd Behrend value and an odd Euler characteristic.
