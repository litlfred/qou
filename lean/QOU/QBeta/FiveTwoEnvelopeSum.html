    Σⱼ ∂V/∂x = −2·log x / x — the envelope's second ingredient #

    Bean qou-trns. FiveTwoCurveDeriv.lean supplies the first ingredient (the roots are differentiable, so the chain rule applies and the dyⱼ/dx terms die against ∂V/∂y = 0). This file supplies the second: what the surviving ∂V/∂x terms sum to.

    The computation #

    V(x,y) = Li₂(y) + Li₂(xy) + Li₂(y/x) + log(−y)²
∂V/∂x  = [ −log(1 − x·y) + log(1 − y/x) ] / x

    so summing over the three roots needs the two log-sums, and each is pinned by a Vieta product already proved in FiveTwoCyclotomicBloch (#4658):

    product exponentiates to gives
    ∏ⱼ(1 − x·yⱼ) = x exp(Σⱼ log(1−x·yⱼ)) = x Σⱼ log(1−x·yⱼ) = log x + 2πi·k₁
    ∏ⱼ(x − yⱼ) = x² exp(Σⱼ log(1−yⱼ/x)) = x⁻¹ Σⱼ log(1−yⱼ/x) = −log x + 2πi·k₂

    and then

    Σⱼ ∂V/∂x = (1/x)·[ −2·log x + 2πi·(k₂ − k₁) ] .

    With the branch integers pinned to 0 — which is what QOU/Archimedean/BranchIntegerPinning.lean does, given continuity and the base point — this is −2·log x / x. On x = e^{iφ} that is −2iφ/x, and against dx/dφ = i·x it gives dS/dφ = Re(−2iφ·i) = 2φ.

    What is proved here, and what is assumed #

    exp_sum_log_one_sub_x_mul and exp_sum_log_one_sub_div are proved from Vieta alone — they are the hexp inputs the pinning lemma consumes, and they need no analysis.

    sum_dVdx_of_pinned then takes the pinned sums as hypotheses and does the algebra. It does not prove the pinning: that needs hcont, which remains open (see this bean's earlier entries). Stating it with the pinned sums as hypotheses is the honest factoring — the algebra is separable from the analysis, and only the algebra is done here.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.

    theorem QOU.QBeta.FiveTwoDeformedSaddle.envelope_value {x : ℂ} (φ : ℝ) (hx : x ≠ 0) (hlog : Complex.log x = ↑φ * Complex.I) :
    -2 * Complex.log x / x * (Complex.I * x) = ↑(2 * φ)

    On the unit circle, against dx/dφ = i·x, that is 2φ.

    Σⱼ ∂V/∂x · (i·x) = −2·log x · i, and with log(e^{iφ}) = iφ this is −2·iφ·i = 2φ — real, which is why S is real and its derivative is 2φ.
