    The q-dimension normalisation [2]_qⁿ = Σ_j m_j(n) [n − 2j + 1]_q #

    Bean qou-0cyu item G2. The q-dimension of V^⊗n for the 2-dimensional V, decomposed over its two-row isotypic pieces. It is what makes the closed form y₍ₙ₋ₖ,ₖ₎ = [n−2k+1]_q / [2]_qⁿ normalise — i.e. what makes tr_M(1) = 1 hold — at every strand count rather than at the two that were checked by hand.

    Two things to take from it, neither about q-integers. A ## Status note is a dated measurement, not a standing fact — AGENTS.md says exactly this ("the source file's ## Status … notes are not authoritative: the corpus is the source of truth"), and this file is a worked instance of the cost. And the reason it went unnoticed is a naming split: one identity, called levelSum there and qdim_normalisation here, so a grep for either name finds neither the other nor the overlap.

    So the general statement below is a derivation from prior art, not a new result. What it adds is that the identity now exists in the [2]_qⁿ = Σ … form this file is named for, and that the ℤ-valued Mathlib.BallotNumbers.ballot is tied to the R-valued TwoRowNormalisation.ballot — two definitions of the same numbers that nothing previously connected, so no lemma about either transferred to the other.

    The route proposed here, and not the one taken #

    Kept, because it is correct and may be wanted at a different index. Writing the summand with natural subtraction as qint q (n + 1 - 2*j) makes the tail vanish on its own:

    • 2j ≤ n — the index is n − 2j + 1, the intended one;
    • 2j = n + 1 — the index truncates to 0, and qint q 0 = 0 (qint_zero); the coefficient m_j(n) is also zero here, by ballot_boundary_zero;
    • 2j > n + 1 — the index truncates to 0 again.

    So the sum may run over all of Finset.range (n+1) with no guard and no ⌊n/2⌋. TwoRowNormalisation.levelSum uses exactly this indexing, for exactly this reason, arrived at independently — and the three ingredients named here are the ones levelSum_succ in fact consumes:

    • TemperleyLiebTower.qint_three_term — [m+2] + [m] = [2]·[m+1];
    • the Pascal step m_{j+1}(n+1) = m_{j+1}(n) + m_j(n), as Mathlib.BallotNumbers.ballot_succ_succ in ℤ and ballot_pascal in R;
    • the boundary vanishing, as ballot_eq_zero_of_two_mul_eq_succ.

    The general-n normalisation, in the form this file is named for #

    Both statements below are one rewrite away from TwoRowNormalisation.levelSum_eq_one; neither is new mathematics. They exist because levelSum_eq_one is stated as Σ_λ dim_λ · y_λ = 1 — the weights already divided by [2]_qⁿ — and the q-dimension count is the same identity with the denominator cleared. A reader looking for [2]_qⁿ = Σ … did not find it, which is how this file came to declare it open.

    source
    theorem QOU.QBeta.QDimNormalisation.ballot_cast {R : Type u_1} [Field R] (n k : ℕ) :
    ↑(Mathlib.ballot n k) = TwoRowNormalisation.ballot n k

    The two ballot definitions agree, ((m_k(n) : ℤ) : R) = m_k(n).

    QOU.Mathlib.ballot is ℤ-valued, because it is squared and compared against catalan. QOU.QBeta.TwoRowNormalisation.ballot is R-valued, because it is multiplied by q-integers and carrying it in ℕ breaks Pascal at the boundary (see that file's header for the worked failure). The two bodies are syntactically the same recursion in different rings — and nothing connected them, so every lemma proved about one said nothing whatever about the other.

    theorem QOU.QBeta.QDimNormalisation.qdim_normalisation_general {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) (hq' : q - q⁻¹ ≠ 0) (hs : q + q⁻¹ ≠ 0) (n : ℕ) :
    ∑ k ∈ Finset.range (n + 1), TwoRowNormalisation.ballot n k * TemperleyLiebTower.qint q (n + 1 - 2 * k) = (q + q⁻¹) ^ n

    [2]_qⁿ = Σ_k m_k(n) · [n+1−2k]_q, at every n.

    The q-dimension of V^⊗n for the two-dimensional V, split over its two-row isotypic pieces: the left side is (dim_q V)ⁿ and each right-hand term is the multiplicity m_k(n) of the shape (n−k, k) times that block's q-dimension [n−2k+1]_q.

    The sum runs over all of range (n+1) with no ⌊n/2⌋ guard: past the last real shape the ℕ subtraction truncates the index to 0 and qint q 0 = 0, and at the single boundary index 2k = n+1 the multiplicity vanishes instead. Two different reasons, one uniform range — see the header.

    Hypotheses are the standing q-integer non-degeneracies: q ≠ 0, q ≠ q⁻¹ (else [m]_q is 0/0), q ≠ −q⁻¹ (else [2]_q = 0). All three hold at the proton pin q₀ ≈ 1.10998 with room.
