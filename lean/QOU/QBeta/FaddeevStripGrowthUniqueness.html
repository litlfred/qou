    Brick G5 of the Faddeev growth-estimate epic (qou-mz4f). It removes the analytic hbdd input of FaddeevUniquenessBoundedCapstone.faddeevPhi_proportional_of_bounded_ratio, deriving it from the strip-growth class (G4) via the removable-singularity extension (G5 crux, MeromorphicPuncturedBounded).

    faddeevPhi_proportional_of_stripGrowth — two FaddeevPhi solutions that are both FaddeevPhiStripGrowth (comparable to phiBProd), with Φ₂'s zeros isolated (hΦ₂_iso) and the normal-form identity off Φ₂'s zeros (hr_ratio), and the two dense periodicity loci, are proportional. The hbdd bound the capstone needed is now a theorem: ratio_bounded_of_stripGrowth (G4) bounds the raw ratio on {Φ₂ ≠ 0}; Φ₂'s zeros being isolated makes that a punctured-neighborhood bound at every point; and norm_le_of_bounded_on_punctured (G5 crux) promotes it to the global bound.

    So the boundedness capstone's three analytic inputs (hbdd, hr_ratio, loci) reduce to two (hr_ratio, loci) plus the structural strip-growth class — hbdd is derived, no longer an endowment. What remains to fully close qou-7xvy for the concrete phiBProd (assembly, no Mathlib gap): discharge hΦ₂_iso from meromorphicOrderAt (phiBProd b) ≠ ⊤ (PR #4225), and hr_ratio from the meromorphic normal-form identity on the analytic locus.

    theorem QOU.QBeta.FaddeevStripGrowthUniqueness.faddeevPhi_proportional_of_stripGrowth {b : ℂ} (hb2 : (b ^ 2).im ≠ 0) {Φ₁ Φ₂ : ℂ → ℂ} [MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi b Φ₁] [MathlibExt.FaddeevQuantumDilogarithm.FaddeevPhi b Φ₂] [FaddeevPhiStripGrowth b Φ₁] [FaddeevPhiStripGrowth b Φ₂] (hr_ratio : ∀ (z : ℂ), Φ₂ z ≠ 0 → toMeromorphicNFOn (Φ₁ / Φ₂) Set.univ z = Φ₁ z / Φ₂ z) (hΦ₂_iso : ∀ (z : ℂ), ∀ᶠ (w : ℂ) in nhdsWithin z {z}ᶜ, Φ₂ w ≠ 0) {S₀ S₁ : Set ℂ} (hS₀ : Dense S₀) (hS₁ : Dense S₁) (hmem₀ : ∀ z ∈ S₀, 1 + Complex.exp (Complex.I * ↑Real.pi * b ^ 2) * Complex.exp (2 * ↑Real.pi * b * z) ≠ 0 ∧ Φ₂ z ≠ 0 ∧ Φ₂ (z + Complex.I * b) ≠ 0) (hmem₁ : ∀ z ∈ S₁, 1 + Complex.exp (2 * ↑Real.pi * (z + Complex.I / (2 * b)) / b) ≠ 0 ∧ Φ₂ z ≠ 0 ∧ Φ₂ (z + Complex.I / b) ≠ 0) :
