    x = q + 1/q ≥ 2 for every q > 0. This is why disc_S = x² − 4 ≥ 0 is an inequality about the whole real branch rather than a fact about q₀.

    The short model: disc = h², hyperbolic at every real q #

    source
    noncomputable def QOU.QBeta.shortTr (q : ℝ) :
    ℝ

    The (2,1) block of the short-model decay operator Δ_S = (h²/2)·γ − (h/2)·σ₀ − (h/2)·σ₁, written out entry by entry.

    T₀ = diag(q, −1/q) and T₁ = !![a, b; b, h − a] with a = −1/(q³ + q); the off-diagonal b enters only through b², so it is carried as a hypothesis and no square root appears.

                  The classical limit q → 1 is exactly 2π/3 #

                  source
                  def QOU.QBeta.classicalTr :
                  ℝ

                  The leading direction of Δ_L as q → 1. Every NF coordinate carries a factor (q−1)(q+1); the coordinates vanishing to first order are γ and L₋, so the direction is −(1 + T₁T₀), and at q = 1 that is the concrete matrix !![−1/2, √3/2; −√3/2, −1/2] — rotation by 2π/3, negated.

                  Carried through its invariants rather than as a matrix, since only tr and det enter the eigenphase.
