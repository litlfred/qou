    theorem QOU.QBeta.FaddeevStripGrowthFKV.comparable_shape_of_periodic_ballBound {Φ Ψ : ℂ → ℂ} {bas : Module.Basis (Fin 2) ℝ ℂ} {C : ℝ} (hC : 0 < C) (hper : ∀ (i : Fin 2) (z : ℂ), Φ (z + bas i) / Ψ (z + bas i) = Φ z / Ψ z) (hballU : ∀ (w : ℂ), ‖w‖ ≤ ‖bas 0‖ + ‖bas 1‖ → ‖Φ w / Ψ w‖ ≤ C) (hballL : ∀ (w : ℂ), ‖w‖ ≤ ‖bas 0‖ + ‖bas 1‖ → 1 / C ≤ ‖Φ w / Ψ w‖) {z : ℂ} (hΨ : Ψ z ≠ 0) :
    ‖Φ z‖ ≤ C * ‖Ψ z‖ ∧ ‖Ψ z‖ ≤ C * ‖Φ z‖

    Comparability shape from the compact ratio bound. Let the ratio Φ/Ψ be periodic under an ℝ-basis bas of ℂ and satisfy the two-sided bound ‖Φ/Ψ‖ ≤ C, 1/C ≤ ‖Φ/Ψ‖ on the closed fundamental ball (the FKV eq-22 input). Then, wherever Ψ z ≠ 0, the FaddeevPhiStripGrowth.comparable shape holds: ‖Φ z‖ ≤ C‖Ψ z‖ and ‖Ψ z‖ ≤ C‖Φ z‖. The two-sided global ratio bound comes from FaddeevStripGrowthBoxReduction.comparable_of_periodic_ballBound; this file adds the norm_div conversion to the Φ/Ψ modulus inequalities.
