    No single-crossing interface can unbind at the substrate anchor #

    computations/probes/two_nucleon_sector_sign_probe.py measures that the framework binds the diproton (+2.5416 MeV) and the dineutron (+3.3069 MeV), where nature has no bound state in either channel. This file identifies the cause, and shows it is structural rather than a bad parameter choice.

    The mechanism #

    The interface scalar of a single crossing is μ = z + d, with the Markov parameter z = q³/(q²+1) (convention D) and the admissible interface offset d running over [-h, 0] — d = 0 at σ, d = -h at σ⁻¹, h = q - q⁻¹. The binding is B = -α·log μ, so

    B > 0  ⟺  μ < 1.

    Since the family is increasing in d, its maximum is μ = z. So every single-crossing interface binds as soon as z < 1, and

    z < 1  ⟺  q³ < q² + 1.

    At the substrate anchor q₀ ≈ 1.10998 that reads 1.3676 < 2.2321 — satisfied with a wide margin. Unbinding through a single crossing would need q > 1.46557…, the real root of q³ = q² + 1; the substrate sits 24 % below it, so this is not a near-miss that a small correction could flip.

    What the file proves (sorry-free) #

    • markov_z_lt_one — z < 1 from q³ < q² + 1.
    • h_lt_markov_z — h < z for every q > 0, unconditionally (it reduces to q⁴ - 1 < q⁴). This is what keeps the whole family positive, so log μ is defined throughout.
    • interface_mem_Ioo — for d ∈ [-h, 0], 0 < z + d < 1.
    • single_crossing_binds — hence -α · log (z + d) > 0 for α > 0: every admissible single-crossing interface binds.
    • writhe_normalisation_binds_harder — the writhe grading multiplies μ by a factor in (0,1) when 0 < h < 1, so the normalised scalar is smaller and the channel binds more. The normalisation cannot rescue the sign.
    • unbinding_needs_large_q — contrapositive: an unbinding single crossing forces q² + 1 ≤ q³.

    Scope — this is a scope-(b) exclusion, and a narrow one #

    Excluded: any single-crossing interface, at any admissible d, with or without the writhe normalisation, produces a bound channel whenever q³ < q² + 1. No choice of d — no colour weighting, no isospin projector, no crossing-sign assignment — can give an unbound two-nucleon channel at the substrate anchor. The invariant is μ ≤ z < 1 and it is proved here.

    NOT excluded: unbinding as such. computations/probes/stacked_interface_writhe_normalised_probe.py shows the writhe-normalised even negative stacked powers σ^{-2}, σ^{-4}, … have μ_eff > 1 and do unbind — those are not single crossings, so they lie outside this theorem. Their magnitudes are 6–9× nature's, so this is a repair direction, not a repair.

    Also not excluded: a different z convention, a construction where binding is not -α·log μ, or an interface built from something other than the 2-dimensional span{1, σ} subalgebra.

    Why this is worth a theorem rather than a remark #

    The corpus already records that the Hecke spectral projectors cannot unbind (InterfaceScalar.mu_sum_eq_one: μ₊ + μ₋ = 1 forces both < 1). That is the same conclusion for a two-element sub-family. This generalises it to the whole admissible interval and, more importantly, identifies the reason — z < 1 — which is a statement about the substrate anchor rather than about projectors. It converts "the two-nucleon signs come out wrong" from a measurement into an invariant, which is what tells a later agent not to look for a better d.

    Base ring (§7c) #

    ℝ throughout: the content is an ordering statement (0 < μ, μ < 1) plus Real.log, i.e. archimedean by nature.

        theorem QOU.QBeta.markovZ_sub_heckeH {q : ℝ} (hq : 0 < q) :
        markovZ q - heckeH q = 1 / (q * (q ^ 2 + 1))

        The gap between z and h is exactly 1/(q(q²+1)). The q⁴ terms cancel identically:

        z - h = q³/(q²+1) - (q²-1)/q = [q⁴ - (q⁴ - 1)] / [q(q²+1)] = 1/[q(q²+1)].

        So the bottom of the admissible family sits a computable distance above 0, for every q > 0 — there is no q at which the family degenerates.

        theorem QOU.QBeta.t3_grading_cannot_unbind_pp {q e : ℝ} (hq : 0 < q) (hz : q ^ 3 < q ^ 2 + 1) (hh0 : 0 ≤ 1 - heckeH q) (hh1 : 1 - heckeH q ≤ 1) (hT3 : 0 ≤ e) :

        The T₃ grading provably cannot unbind the pp channel.

        The corpus grades the strong-isospin interface by crossing sign — σ (positive writhe) for pp, σ⁻¹ (negative) for nn — i.e. by T₃ (QOU.ParticleInteractions.WeakIsospinT3Grading).         The nn side is not excluded by this (its T₃ writhe is negative, the helpful direction) — but it is quantitatively far off: unbinding nn needs e ≤ −7.74 at the substrate anchor against the T₃ assignment's e = −1.

        T-blind vs T-odd gradings #

        The two-nucleon sector needs the symmetric channel (T = 1) unbound and the antisymmetric one (T = 0) bound. Whether a grading can express that at all is decided by how it acts on the two channels' ratio.

        source
        theorem QOU.QBeta.common_factor_cancels_in_ratio {a b c : ℝ} (hc : c ≠ 0) (hb : b ≠ 0) :
        a * c / (b * c) = a / b

        A T-blind grading cannot discriminate the channels. If both channels are scaled by the same factor c ≠ 0, their ratio is unchanged — so no common grading can change which channel is closer to the unbinding threshold.

        This is the writhe: the normalisation (1-h)^(e/2) depends on the exponent sum, which is a property of the word, not of the Wedderburn block, so both channels receive it identically and it cancels here.

        theorem QOU.QBeta.reciprocal_factors_scale_ratio {a b t : ℝ} (ht : t ≠ 0) (hb : b ≠ 0) :
        a * t / (b * t⁻¹) = a / b * t ^ 2

        A reciprocal (T-odd) grading does move the ratio. If the two channels receive t and t⁻¹, the ratio is multiplied by t² — strictly monotone in t, so the channels can be reordered.

        This is the ribbon twist: θ_λ = q^{c(λ)} with c(λ') = -c(λ) (QOU.BraidKnot.KeystoneModularTwist), so at n = 2 the symmetric block gets q^{f} and the antisymmetric block q^{-f}.
