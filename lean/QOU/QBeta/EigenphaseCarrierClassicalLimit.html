    theorem QOU.QBeta.delta_L_is_not_a_carrier :
    2 * Real.cos (2 * Real.pi / 3) ≠ 2 * Real.cos 0

    Δ_L is not a carrier, and fails at order zero. A carrier needs tr M(1) = 2; the corpus's only elliptic operator — the only one clearing TIER-0 D0 — gives −1.

    theorem QOU.QBeta.carrier_gap_is_three :
    2 * Real.cos 0 - 2 * Real.cos (2 * Real.pi / 3) = 3

    The gap is exactly 3, the distance between the identity's character and a three-cycle's in χ^{(2,1)} — so the exclusion is a character-table fact.
