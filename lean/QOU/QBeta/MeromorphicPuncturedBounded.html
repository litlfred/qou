    Punctured-neighborhood boundedness ⇒ global boundedness of a meromorphic normal form (G5 crux) #

    The analytic heart of brick G5 of the Faddeev growth-estimate epic (qou-mz4f). The boundedness capstone FaddeevUniquenessBoundedCapstone.faddeevPhi_proportional_of_bounded_ratio consumes hbdd : ∀ z, ‖toMeromorphicNFOn (Φ₁/Φ₂) univ z‖ ≤ C — a bound on the normal form at every point. The strip-growth class (FaddeevPhiStripGrowth, G4) only bounds the raw ratio on the dense non-vanishing locus {Φ₂ ≠ 0}. This file bridges the gap: a bound on a punctured neighborhood of every point promotes to a global bound.

    • meromorphicOrderAt_nonneg_of_bounded_punctured — the local form of BoundedMeromorphicLiouville.meromorphicOrderAt_nonneg_of_bounded: boundedness on 𝓝[≠] z alone forces meromorphicOrderAt f z ≥ 0 (a pole would push f → ∞ on that very punctured filter, contradicting the bound). No global hypothesis.
    • norm_le_of_bounded_on_punctured — for a normal-form function bounded on a punctured neighborhood of every point: each point is a removable singularity (order ≥ 0 ⇒ analytic ⇒ continuous), so the value equals the limit and inherits the bound. This yields the global hbdd from a codiscrete (dense-complement) bound.

    Together these discharge the removable-singularity extension of G5. What remains to call the capstone (assembly-level, no Mathlib gap): (i) ∀ᶠ w in 𝓝[≠] z, Φ₂ w ≠ 0 — Φ₂'s zeros isolated (for phiBProd, from meromorphicOrderAt ≠ ⊤, PR #4225); (ii) hr_ratio (toMeromorphicNFOn (Φ₁/Φ₂) = Φ₁/Φ₂ off poles, from the meromorphic normal-form API); (iii) the honest physical hypothesis MeromorphicOn Φ₁ for the arbitrary second solution.

    Verified lean-direct against the pinned Mathlib Meromorphic cone. Sorry-free.

    theorem QOU.QBeta.MeromorphicPuncturedBounded.meromorphicOrderAt_nonneg_of_bounded_punctured {f : ℂ → ℂ} {C : ℝ} {z : ℂ} (hbdd : ∀ᶠ (w : ℂ) in nhdsWithin z {z}ᶜ, ‖f w‖ ≤ C) :
    0 ≤ meromorphicOrderAt f z

    Local bounded ⇒ order ≥ 0. A bound on a punctured neighborhood 𝓝[≠] z alone forces meromorphicOrderAt f z ≥ 0: a negative-order point would send f → ∞ on 𝓝[≠] z (tendsto_cobounded_of_meromorphicOrderAt_neg), but the bound keeps f inside a ball there — and 𝓝[≠] z is NeBot, so it cannot simultaneously be eventually-in and eventually-out. This is the punctured-neighborhood strengthening of BoundedMeromorphicLiouville.meromorphicOrderAt_nonneg_of_bounded (which assumes a global bound).

    theorem QOU.QBeta.MeromorphicPuncturedBounded.norm_le_of_bounded_on_punctured {g : ℂ → ℂ} {C : ℝ} (hg : MeromorphicNFOn g Set.univ) (hpunc : ∀ (z : ℂ), ∀ᶠ (w : ℂ) in nhdsWithin z {z}ᶜ, ‖g w‖ ≤ C) (z : ℂ) :
    ‖g z‖ ≤ C

    Punctured-bounded everywhere ⇒ globally bounded (normal form). If a meromorphic normal-form function g on ℂ is bounded by C on a punctured neighborhood of every point, then ‖g z‖ ≤ C for every z: order ≥ 0 (previous lemma) makes each point a removable singularity, so g is analytic — hence continuous — at z, and its value is the limit of the (bounded) nearby values. This turns a codiscrete (dense-complement) bound into the global hbdd the boundedness capstone requires.
