          theorem QOU.QBeta.N1FactorUniqueness.barMidpoint_eq (δ a : ℝ) :
          (Real.cos a + Real.cos (barPhase δ a)) / 2 = Real.cos (a - δ / 2) * Real.cos (δ / 2)

          The bar-midpoint identity — the step sympy.simplify would not do.

          (cos a + cos(δ - a))/2 = cos(a - δ/2) · cos(δ/2), exactly, for all real a and δ. Entry 10 verified this at 60 dps after the CAS returned a non-zero residual; it is an identity, and this is the proof.

          theorem QOU.QBeta.N1FactorUniqueness.const_free (δ K : ℝ) :
          BarInvariant δ (δ / 2) K

          The constant is FREE. For every K, re-centring by δ/2 gives a bar-invariant factor. So conditions (i)–(iii) leave K unconstrained — a proved negative, not an unfound constraint.

          theorem QOU.QBeta.N1FactorUniqueness.phase_forced {δ c K : ℝ} (hK : K ≠ 0) :
          BarInvariant δ c K ↔ ∃ (k : ℤ), c = δ / 2 - ↑k * Real.pi

          The phase re-centring is FORCED, modulo π.

          Bar-invariance for a nonzero K holds iff c = δ/2 - kπ for some integer k. The arc's continuity argument (c(0) = 0, c continuous) selects k = 0, giving c = δ/2; that selection is outside this statement.

          theorem QOU.QBeta.N1FactorUniqueness.c_limit (a : ℝ) :
          (Real.cos a + Real.cos (barPhase 0 a)) / 2 = Real.cos a

          The convention-C limit. At δ = 0 the factor is a bare cosine, which is condition (iii); and there the bar action is a ↦ -a, under which cos is already invariant. This is why C could use a bare cosine and D cannot — the bar-midpoint rule is vacuous in C, not satisfied by accident.

          theorem QOU.QBeta.N1FactorUniqueness.uncentred_fails {δ : ℝ} (hδ : ∀ (k : ℤ), δ ≠ 2 * ↑k * Real.pi) :
          ¬BarInvariant δ 0 1

          CONTROL — the forcing has teeth.

          If bar-invariance held for every c, everything above would be vacuous. It does not: the un-recentred cosine (c = 0, the convention-C form) is bar-invariant only in the degenerate case δ = 2kπ. Stated for arbitrary δ rather than at one sample point, and proved from phase_forced itself.

          theorem QOU.QBeta.N1FactorUniqueness.c_rule_is_vacuous (a : ℝ) :
          Real.cos (barPhase 0 a) = Real.cos a

          CONTROL — the C limit is not an accident of δ = 0 arithmetic.

          Under convention C the bar action is a ↦ -a and cos is even, so the bar-midpoint rule returns its input unchanged: the rule is vacuous in C. That is why C could carry a bare cosine, and the reason its unavailability under D is structural rather than a gap in the search.
