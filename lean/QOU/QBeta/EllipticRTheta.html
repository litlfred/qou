    Elliptic-R / θ-degeneration structure for the bar-even/bar-odd channels #

    Formalize-first brick for the hypothesis (owner intuition, 2026-07-25): the bar-even (cosh, mass/geometric) and bar-odd (sinh, Q_β/c₃) channels are not independent — the R-matrix / transfer matrix mixes them — because they are the two degeneration sectors of a single elliptic (Jacobi-θ) object, the q-heat kernel.

    The tier structure (Belavin–Drinfeld) #

    R-matrices form three tiers: rational → trigonometric (sinh/cosh) → elliptic (θ-functions). QOU's Hecke/braid R is the trigonometric one: its eigenvalues q, −q⁻¹ give the symmetric combination q + q⁻¹ = 2 cosh u (bar-even) and the antisymmetric q − q⁻¹ = 2 sinh u (bar-odd, the skein relation), for q = eᵘ. And sinh, cosh are exactly the τ → i∞ (nome → 0) degenerations of the odd/even Jacobi theta: θ₁ → sinh, θ₃,θ₄ → cosh. Jacobi θ is the heat kernel on the torus (∂_τ θ = (4πi)⁻¹ ∂_z² θ) — the q-heat kernel.

    This file proves the trigonometric-level parity structure (cheap, exact) and states the single-τ non-independence conjecture (§3b): the bar-odd and bar-even channels both factor through one elliptic modular parameter τ(anchor), so the c₃ cross-anchor swing (which no real sinh/cosh truncation captures — a trigonometric object has no free parameter to produce a swing) is the signature of the modular parameter of the elliptic uplift.

    class QOU.QBeta.EllipticRTheta.SingleTauChannelClosure (barOdd barEven τ : ℝ → ℝ) :
    Prop

    Single-τ non-independence (conjecture, §3b). The bar-odd channel barOdd(a) (the c₃/Q_β swing across substrate anchors a) and the bar-even channel barEven(a) (the mass/binding correction) both factor through one elliptic modular parameter τ(a): there are fixed profiles f, g (the θ-even/θ-odd quotients of the elliptic R) with barOdd = f ∘ τ and barEven = g ∘ τ. The content is the shared τ: the (barOdd, barEven) trajectory is a 1-parameter curve, not a 2-D independent pair — the non-independence the transfer matrix encodes. tau_nonconstant records that the swing is real (the parameter genuinely varies across anchors), so the closure is non-degenerate. No instance is provided: this is the open hypothesis to test.

    • odd_factors : ∃ (f : ℝ → ℝ), ∀ (a : ℝ), barOdd a = f (τ a)

      the bar-odd channel factors through the single modular parameter τ.

    • even_factors : ∃ (g : ℝ → ℝ), ∀ (a : ℝ), barEven a = g (τ a)

      the bar-even channel factors through the same τ (the non-independence).

    • tau_nonconstant : ∃ (a : ℝ) (a' : ℝ), τ a ≠ τ a'

      τ genuinely varies across anchors (the c₃ swing is not degenerate).

      theorem QOU.QBeta.EllipticRTheta.faddeev_modular_parameter {b : ℂ} (hb : b ≠ 0) :
      Complex.I / b / (Complex.I * b) = 1 / b ^ 2

      The Faddeev elliptic modular parameter is τ = 1/b². The elliptic freedom (FaddeevPhiEllipticFreedom.faddeevPhi_mul_elliptic) lives on the period lattice ⟨ib, i/b⟩; the modular parameter of that lattice is the period ratio τ = ω₂/ω₁ = (i/b)/(ib) = 1/b². So the single modular parameter of SingleTauChannelClosure is substrate-derived — a fixed function τ = 1/b² of the Faddeev modulus b, not a free fit. This is the concrete object whose (archimedean) evaluation the c₃ cross-anchor swing would have to track; it turns the "single τ" from an abstract hypothesis into a computable prediction. The modular double b ↔ 1/b sends τ = 1/b² ↦ b² = 1/τ — the S-transform, the theta-modular symmetry that mixes the θ-even/θ-odd (bar-even/bar-odd) sectors.
