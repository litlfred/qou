    The other branch integer: Σⱼ log(1 − yⱼ/x) = −log x #

    Bean qou-trns. sum_dVdx_of_pinned takes two pinned log-sums, and only one of them was proved. FiveTwoBranchPinned gave Σⱼ log(1 − x·yⱼ) = log x; this file gives the companion. It became visible only once the first was written — which is the point of writing joins out rather than calling them assembly.

    It is the same argument, mirrored #

    On |x| = 1 we have x⁻¹ = conj x, so

    (y/x).im = y.im·x.re − y.re·x.im ,

    and comparing with (x·y).im = x.re·y.im + x.im·y.re shows the two differ by conjugating y. Since the extra roots are either both real or a conjugate pair, the same two facts that gave Im(x·y₃) < 0 and Im(x·y₂) < 0 give Im(y₂/x) > 0 and Im(y₃/x) > 0. Nothing new is measured or assumed: im_div_otherRoots_fst_pos re-runs the sa_lt_cb case split against the mirrored quantity.

    The window mirrors too. Σⱼ arg(1 − yⱼ/x) = −φ + 2π·k₂, and

    input source
    arg(1 − t/x) ∈ (0, π/2) (t/x).im = −t·x.im < 0 and (t/x).re = t·x.re < 1
    arg(1 − y₂/x) ≤ 0 Im(y₂/x) > 0
    when φ > π/2, also arg(1 − y₃/x) ≤ 0 Im(y₃/x) > 0 once c < 0

    giving Σ ∈ (−φ − 2π, −φ + 2π) and k₂ = 0.

    Route 27 G5 observed numerically that k₂ = −k₁ because the two sums are complex conjugates on the open arc. That is true and is why one expects this to work — but it is not what is proved here. Formalising it would need the root multiset to be conjugation-closed as a permutation; mirroring the sector argument needs no such thing, so that is what is done.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.
