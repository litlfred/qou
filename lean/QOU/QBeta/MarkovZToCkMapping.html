    QOU.QBeta.MarkovZToCkMapping #

    The formal bridge (f-map) between the Markov parameter $z$ (and its Taylor coefficients $a_n$) and the Q_β precision ladder coefficients $c_k$.

    Context #

    As proved in ToroidalHarmonicsBasis.lean, the toroidal Legendre operator in the half-integer degree maps under x = 1/(2w) - 1 to a second-order differential equation in w = z^2. However, the Markov parameter recursion (markovParamCoeff, giving $a_n$) is written in the variable w = q - 1 and comes from the first-order ODE for z = sqrt(q)/(1+q).

    Bridging the $w = z^2$ toroidal domain and the $w = q-1$ Markov recursion domain, and ultimately evaluating the knot operator trace, requires a map (the "f-map") that sends the bare $z$-recursion sequence $a_n$ to the precision-ladder sequence $c_k$. This file formalises the existence and structural requirements of this f-map as a conditional class (ZToCkMappingClass).

    Claims #

    1. This does NOT claim a derived closed form for the f-map.
    2. This asserts the algebraic type signature of the f-map: it is an operator that takes the a_n sequence and returns the c_k sequence.
    3. It anchors the fact that no $c_k$ is made exact by the bare Toroidal mapping alone.

    Z to C_k Mapping Class (§3b-cond open f-map)

    Axiomatises the structure of the map from the pre-archimedean $z$-recursion coefficients ($a_n$) to the Q_β precision ladder categorical coefficients $c_k(q)$.

    The mapping evaluates the formal sequence against the specific substrate anchor $q$, producing the rung parameters $c_k(q)$ defined in QBetaPrecisionLadderCoefficients.

    • f_map_bridges_to_ck (q : ℝ) (_hq : 0 < q) : (qBetaFMap q fun (n : ℕ) => ↑(BraidKnot.markovParamCoeff n)) = fun (k : ℕ) => BraidKnot.QBetaPrecisionLadderCoefficients.c_k_at_q k q

      The f-map maps the real-embedded $a_n$ Markov coefficients to the $c_k(q)$ sequence at every evaluated $q > 0$.
