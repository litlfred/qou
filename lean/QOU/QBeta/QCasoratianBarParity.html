        theorem QOU.QBeta.casNum_reciprocal {R : Type u_1} [CommRing R] (q x qi xi : R) (hq : q * qi = 1) (hx : x * xi = 1) :
        casNum qi xi * (q ^ 3 * x ^ 3) = casNum q x

        Numerator reciprocity (division-free, over any CommRing). If q, x are units — witnessed by q·qi = 1, x·xi = 1 — then the bar-involved numerator, scaled by the monomial q³x³, returns the numerator:

        casNum qi xi · (q³x³) = casNum q x.

        (Exact linear_combination certificate; no field, no field_simp.)

        theorem QOU.QBeta.casoratian_ratio_bar_invariant {R : Type u_1} [CommRing R] (q x qi xi : R) (hq : q * qi = 1) (hx : x * xi = 1) :
        casNum qi xi * casDen q x = casNum q x * casDen qi xi

        P-C15 (Lean certificate, division-free CommRing form). The 4₁ order-2 Casoratian ratio a₀/a₂ = casNum/casDen is invariant under the fibre bar involution q ↦ q⁻¹, x ↦ x⁻¹, expressed without division as the cross-multiplied identity

        casNum qi xi · casDen q x = casNum q x · casDen qi xi.

        Both numerator and denominator scale by the same monomial q³x³ under the involution (casNum_reciprocal, casDen_reciprocal), so the shared factor cancels. Holds over any commutative ring with q, x units. Sorry-free.

        theorem QOU.QBeta.casoratian_ratio_bar_self_reciprocal {K : Type u_2} [Field K] (q x : K) (hq : q ≠ 0) (hx : x ≠ 0) (hd : casDen q x ≠ 0) (hd' : casDen q⁻¹ x⁻¹ ≠ 0) :
        casNum q⁻¹ x⁻¹ / casDen q⁻¹ x⁻¹ = casNum q x / casDen q x

        Field corollary (literal ratio form). Over a field, with q, x ≠ 0, the bar-involution q ↦ q⁻¹, x ↦ x⁻¹ fixes the ratio casNum/casDen. Derived from the division-free casoratian_ratio_bar_invariant above; a convenience restatement, not the primary result.
