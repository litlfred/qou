    Extending Rogers L off [0,1] — and why two ladder hypotheses were false #

    Bean qou-rhyp, item 2. This file discharges the inversion and Landen hypotheses of QOU/QBeta/FiveTwoLevelSevenLadder.lean, and corrects the reason they were open.

    The correction #

    qou-rhyp graded hinv1 and hlan1/2/3 as "real analysis, not yet in the corpus — each is a one-variable identity provable the same way LiTwo_reflection' is, so the corpus's existing proof is the template."

    That grading was wrong, in both directions.

    The corpus's dilogarithm is a bare power series,

    LiTwo x = ∑' k, x ^ (k + 1) / (k + 1) ^ 2      (`QOU/Archimedean/DilogarithmArchimedeanLimit.lean`)

    which is summable exactly on [-1, 1]. Off that interval Lean's tsum returns its junk value 0 (tsum_eq_zero_of_not_summable), and Real.log is even (Real.log_neg_eq_log), so a Rogers L built directly on LiTwo is, for |x| > 1, the function log|x| · log|1 - x| / 2 — not the dilogarithm.

    Two of the ladder's arguments sit exactly there. The ladder's w₁ is the root 2.2469796… of w³ - 2w² - w + 1, so hinv1 is evaluated at w₁ > 1 and hlan1 at -w₁ < -1. Numerically (probe qbeta_5two_route13_rogers_extension_probe.py, 60 dps) the two hypotheses fail by

    hinv1 : residual  -2.4543…        hlan1 : residual  +1.5692…

    while the other seven hold to 1e-61. They were not hard; they were false.

    The repair, and what it costs #

    The fix is definitional, not analytic. The extended real Rogers dilogarithm (Zagier, The dilogarithm function, §I.3) is defined off [0,1] by

    L x  :=  2·L 1 - L (1/x)        for x > 1
L x  :=  -L (x/(x-1))           for x < 0

    so inversion and Landen hold by construction. That is what extend below does, and the four hypotheses become one-line consequences of if-unfolding plus the two membership facts 1/x ∈ [0,1] and x/(x-1) ∈ [0,1].

    The cost is honest and worth stating: the Lean object is then a piecewise function, not proved equal to the analytic continuation of Li₂. It agrees with it — the same probe confirms the extension reproduces the three level-7 numerators (17, 5, -1)/7 · π²/6 to 1e-61 — but "agrees numerically" is not "is". Anyone wanting the analytic identification must prove it separately.

    Net effect on qou-rhyp #

    Of the twelve hypotheses numerators_original_form takes, this file discharges the four reduction ones (hinv1, hlan1, hlan2, hlan3) for any f whatever, and extend_reflection transports reflection through the extension. The genuinely open input is now exactly the three five-term instances hA, hB, hC.

    Everything here is generic in f and c: no dilogarithm is involved, so this file builds off basic Mathlib order/field lemmas alone and does not wait on the DilogReflection cone.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.
