    The σ-parity (mass / decay) split of the compact q-Pochhammer coefficient #

    The Faddeev residue expansion lands the elementary-symmetric coefficient e_k(q, q³, q⁵, …) = [x^k] ∏(1 + q^{2n+1} x) on the framework's Hecke / λ⊢n spine (tetraplectic → Bruhat → Young → partitions; see docs/scope/2026-07-11-qbeta-c3-barodd-tetraplectic-combinatorial-reduction.md).

    Two distinct involutions act on it and must not be conflated:

    • the transpose λ ↔ λ' (self-conjugate diagrams) is the modular self-duality Φ_b = Φ_{1/b};
    • the bar σ : q ↦ q⁻¹ (on |q| = 1, complex conjugation) is the sinh/cosh = bar-odd/bar-even split.

    e_k is transpose-symmetric but not σ-even. This file formalises the σ-parity split as named projections and proves — sorry-free — that

    • massProj (cosh / mass / −Vol(4₁) face) is σ-fixed,
    • decayProj (sinh / decay / the Q_β c₃ bar-odd S face) is σ-negated,
    • the two reconstruct f (and σ f),
    • decayProj f = 0 ↔ σ f = f, and — non-vacuously — decayProj f ≠ 0 exactly when f is not bar-even (σ f ≠ f); for the compact e_k(q,q³,…) this holds (e_k is not palindromic under q ↦ q⁻¹, verified in the probe), so the sinh/decay/S face genuinely carries content.

    This is the algebraic core (FaddeevModularDouble.bar_parity_decomposition promoted to named projections + the elementary-symmetric application). It does not derive the S-values: pinning the argument z(q₀) (the CS phase / complex volume, at the root-of-unity accumulation) is the open z→c_k evaluation map — this file closes the structure, not the observable.

    Base ring: [CommRing R] [Invertible (2 : R)] — the natural home is LaurentPolynomial ℚ (where 2 is a unit but the ring is not a field), so Field would over-specialise. No ℝ/ℂ (§7c): purely categorical/algebraic; the archimedean instance (σ = conj on ℂ, where decayProj = i·Im) lives post-archimedean-wall, not here.

        Mass ⊥ decay under any σ-invariant form — the Gram signature splits #

        The algebraic reason the bar-odd carrier sits in its own block of the Frobenius/Gram form (numerically the unique negative-norm ghost direction of the indefinite G_{ij}=tr_M(b_i b_j) in H₃(q), witnessed by qbeta_c3_barodd_knot_operator_gram_probe.py): a bar-even vector and a bar-odd vector are orthogonal under any σ-invariant bilinear form. Hence the mass (σ-even) and decay (σ-odd) projections never mix under the Gram pairing, and the signature splits cleanly along the parity — the ghost mode is Gram-orthogonal to the mass cone. Generic (no ℝ/ℂ, §7c): B is an abstract pairing, additive in its second argument and σ-invariant.
