    Abel's five-term relation for the Rogers dilogarithm on (0,1) #

    Bean qou-abel — the twelfth and last hypothesis of FiveTwoLevelSevenLadder.numerators_original_form, and the one input FiveTwoFiveTermArguments.numerators_of_abel still takes on faith.

    L x + L y - L (x·y) - L (x(1-y)/(1-x·y)) - L (y(1-x)/(1-x·y)) = 0

    for x, y ∈ (0,1).

    Shape of the proof #

    The same shape QOU/Archimedean/DilogReflection.lean uses for LiTwo_reflection': fix y, show the left-hand side has vanishing derivative in x on (0,1), hence is constant there, then evaluate the constant by letting x → 0⁺, where three of the five terms go to 0 and the other two cancel.

    Why the derivative vanishes — the cancellation is linear #

    Write A = log x, B = log (1-x), C = log y, D = log (1-y), E = log (1-xy). The two inner arguments satisfy

    1 - x(1-y)/(1-xy) = (1-x)/(1-xy)        1 - y(1-x)/(1-xy) = (1-y)/(1-xy)

    so every log appearing after the chain rule splits into A,…,E — this is log_inner_left, log_inner_right and friends below. Once it does, -2·F'(x) is a linear form in A,…,E with rational-function coefficients, and each of the five coefficients vanishes identically. For instance the A coefficient is

    1/(1-x) - y/(1-xy) - (1-y)/((1-x)(1-xy))
  = [(1-xy) - y(1-x) - (1-y)] / ((1-x)(1-xy)) = 0,

    and the other four go the same way. That is why the final step is field_simp and ring rather than an argument: all the content is in the log splittings, which is where the positivity side conditions live and where a wrong branch would hide.

    Status #

    This closes qou-abel. With it, numerators_of_abel becomes unconditional for the corpus's rogersL given only reflection, which FiveTwoRogersReflection.rogersL_reflection already proves.

    It does not close the 5₂ sum rule. The transport x = 1 → x = -1 is still unformalized (qou-trns), and extend is still not identified with the analytic continuation in Lean (qou-rstq item 4 — closed on paper by Route 15, not in Lean). The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.
