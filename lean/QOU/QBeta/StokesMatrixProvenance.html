    QOU.QBeta.StokesMatrixProvenance — the 5₂ Stokes matrices are DERIVED from the eq-(98) DT constants, not transcribed #

    The problem this closes #

    FiveTwoDTSpectrumSplit and FiveTwoStokesMatrixIdentities carry the 5₂ leading Stokes matrices as hand-typed defs ("glyph-decoded" from GGM 2012.00062 eqs (96)/(97)). Lean cannot check a transcription, so every downstream result was conditional on that typing being faithful — the sorry-free ≠ derived boundary, raised directly by the author: "do we have proof these are correct?"

    This file removes most of that exposure. Rather than re-typing the matrices, it reconstructs them from a much smaller and cleaner input: the GGM eq-(98) matrix of Stokes constants (= Donaldson–Thomas invariants),

            ⎛  0   4   3 ⎞
  DT =  ⎜ −4   0  −3 ⎟          (GGM 2012.00062 eq (98))
        ⎝ −3   3   0 ⎠

    whose (i,j) entry is the Stokes constant attached to the Borel singularity ι_{i,j}. GGM state that each S_{σᵢ,σⱼ} is the elementary matrix I + DT(i,j)·E_{ij}, and that the leading Stokes matrices are the products (eqs (96)/(97))

      S⁺(0) = S_{σ₃σ₁} · S_{σ₃σ₂} · S_{σ₁σ₂},
  S⁻(0) = S_{σ₁σ₃} · S_{σ₂σ₃} · S_{σ₂σ₁}.

    Computing those products reproduces the typed matrices exactly.

    Why this is a strong check, not a circular one #

    • The only input is the eq-(98) integer matrix — a small, unambiguous array of {0, ±3, ±4}, far less error-prone than two 3×3 matrices.
    • The typed entries are outputs: in particular S⁺(0)₃₂ = −9, the least guessable number in either matrix, is a product artifact (−3·4 + 3 = −9), never a transcribed digit. A transcription slip would have had to conspire with the product structure to survive.
    • The reconstruction is cross-checked against the independent structural identity GGM eq (17), S⁺(0)ᵀ · S⁻(0) = 1, proved here from the reconstructed matrices.

    What remains outside Lean's reach: that the eq-(98) array itself is faithfully read from the paper. That is now a single small matrix rather than the whole Stokes data — the residual exposure is minimized, not eliminated.

                        The chirality split, now on reconstructed data #

                        The DT constants carried by the two chiralities — 4 in S⁺, 3 in S⁻ — read off the reconstruction rather than the transcription.

                        source
                        theorem QOU.QBeta.StokesMatrixProvenance.chirality_split_from_reconstruction :
                        SplusRecon 0 1 = 4 ∧ SminusRecon 0 2 = 3 ∧ SplusRecon 0 1 ≠ SminusRecon 0 2

                        S⁺(0) carries the DT constant 4; S⁻(0) carries 3; they differ, so the 5₂ datum is a genuine two-element chirality-split spectrum.
