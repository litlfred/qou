            §2 — a content-bearing replacement #

            A 2×2 real matrix has spectrum {e^{+iα}, e^{−iα}} exactly when its trace is 2 cos α and its determinant is 1 (the characteristic polynomial is then t² − 2cos(α)t + 1, whose roots are e^{±iα}). Stating that is what the docstring of the existing class describes and its fields omit.

            Unlike the original, this carrier is falsifiable: it constrains the matrix. It is deliberately left with no instance — per AGENTS.md §3b-tax an unproved primary is honestly represented by a content-bearing class with no instance, and supplying a trivial one would reintroduce exactly the defect §1 documents.

              §3 — the obligation is a trichotomy, and §2 alone is not enough #

              Self-correction. §2's TransferMatrixSpectrum is a genuine improvement on the vacuous original — it constrains a given M (replacement_excludes_some_matrix). But it is still not the right obligation, because it does not force M to come from the Hecke data. Exhibited below: for every α there is a matrix with trace = 2 cos α and det = 1, namely the rotation exp(αJ) — built from α itself. So TransferMatrixSpectrum can be "discharged" circularly.

              Putting that next to the route-3 exclusion (QOU.QBeta.Seminormal, and qbeta_eigenphase_seminormal_exclusion_probe.py) gives a three-way split with only one contentful branch:

              1. M in the braid image — excluded. Every character lies in ℤ[q,q⁻¹] ⊂ ℚ(q,z), and 2cos((z−1)h/2) is transcendental over ℚ(q,z), so no such M exists as a functional identity. 🛑 The reason given here is the WRONG ONE — added 2026-09-04. The exclusion is real, but transcendence over ℚ(q,z) is an unproved docstring assertion: BraidImageEigenphaseExclusion calls it "the transcendence assertion", and PhaseFailsLogFunctionalEquation records it as "correct but needs transcendence theory". What actually closes branch 1 is BraidImageEigenphaseAlgebraic.coeffs_zero_of_surjective_nonpos — sorry-free, by zero-counting, and per its own docstring closing the character case and the eigenvalue-pair case. Cite that. Note its hypothesis: α surjective onto the non-positive reals, which the unbounded (z−1)h/2 family supplies and a bounded arccos does not — "algebraic, therefore excluded" is not the statement.
              2. M arbitrary — circular. rotationOfPhase below satisfies the obligation for any α whatsoever, so it says nothing about the substrate.
              3. M an exponential/holonomy of an independently-defined connection whose monodromy reproduces the Hecke braiding — the only remaining option, and the only one that could be contentful. It escapes (1) because a holonomy is transcendental, and (2) because the connection is defined without reference to α, which is then derived as its holonomy angle rather than assumed.

              Branch 3 is the Kohno–Drinfeld / KZ picture, and the corpus's canonical chain already invokes exactly that shape ("Yekutieli non-abelian Stokes"). This file does not carry out that construction; it establishes that it is the only place a derivation of α can live.

              🛑 §3 IS SUPERSEDED IN ITS KOHNO–DRINFELD FORM — added 2026-09-04 (bean qou-xjh4). The paragraph above is the text as written, kept because the trichotomy's structure still stands and branches 1 and 2 are unaffected. What is no longer true is "branch 3 is the only place a derivation can live" read as an endorsement of the Kohno–Drinfeld route: QOU.QBeta.HolonomySpectrumSignObstruction (2026-08-31, 4471ee72ce, 6 theorems, sorry-free, beans qou-pdix / qou-cds1) excludes every holonomy whose generator has real spectrum, Kohno–Drinfeld included.

              The step is residue-independent, which is why it reaches the whole class rather than one candidate: a real generator eigenvalue a gives character (eᵃ + e⁻ᵃ)/2 = cosh a ≥ 1 for every real a, so a q-dependent residue only changes which a occurs. The required correction factor is 0.998399 — below 1, hence unreachable. At the Kohno–Drinfeld value itself, matching the braiding P exp(ħt/2) to the Hecke eigenvalues {q, −q⁻¹} forces ħ = 2 ln q; q₀ > 1 is real, so that generator is hyperbolic (det A = −(ln q₀)² < 0) and gives 1.005448 against the required 0.998399. The whole obstruction is (x−1)² ≥ 0.

              Surviving ask, materially narrower: not "find a connection" but "find one whose generator is elliptic at real q" — det A > 0, spectrum ±iθ, θ = 0.0565947 — so the imaginarity has to be sourced, and the corpus names conj:im-q-physical-role as the candidate. Recorded as tier-0 condition D0 on qou-pdix's D1–D6 acceptance test.

              Two things this does not say, matching the audit's own scope: it does not show that no connection exists, and it does not derive α.

              Recorded here because this file is cited as the authority on the trichotomy — nuclear-interactions/q-beta-cos-resummation.lean quoted §3 on 2026-09-04 and propagated "branch 3 is where a derivation must live" into three further places before the obstruction was noticed. A file that others cite has to carry its own supersessions.
