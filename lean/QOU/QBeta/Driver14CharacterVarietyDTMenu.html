    The question this file answers (formalize-first, honest negative) #

    The arc ledger (docs/coordination/2026-08-02-c3-odd-aomega-unification.md, "How to resolve — routes") names the tractable, decidable, still-UNCHECKED Route 1: does a categorical q→0 DT count from Hecke/Bring data (drivers 11/13) reproduce the character-variety DT datum 4₁ ↦ 3, 5₂ ↦ {3,4}? Deciding it is the concrete test for whether the missing "driver-14" — a Behrend-weighted DT moduli of the character variety / T[K] BPS Hilbert space (#4599) — is constructible from the drivers, even as a fragment.

    StokesDTCountExceedsRecursionOrder (#4599) already showed the two specific QOU integers it examined miss the 4₁ count (partitionEuler₃ = −2 ≠ 3; recursionOrder 4₁ = 2 < 3). FiveTwoDTSpectrumSplit (#4593) showed the 5₂ datum is a genuine chirality-split 2-element spectrum (4 in S⁺, 3 in S⁻), not a knot-independent scalar. This file consolidates Route 1: it runs the whole menu of QOU-derivable (and, for good measure, classical) knot integers against the cross-knot DT datum and proves

    1. no menu invariant reproduces the DT count vector (4₁,5₂) ↦ (3,4) (no_menu_invariant_hits_dt_vector), and
    2. the deeper obstruction is a cardinality / chirality-refinement mismatch: the 5₂ DT datum is a 2-element set, while every QOU scalar driver invariant is single-valued per knot, so no scalar invariant can equal the DT datum (no_scalar_matches_chirality_split_datum). The missing driver-14 count is therefore inherently a chirality-refined (set-valued) moduli count — an object no scalar Wedderburn Euler characteristic / recursion order / block count supplies.

    This is a scope-(a) structural negative. It derives NO count, axiomatizes NO DT moduli, and — crucially — it does NOT assert the 2-point coincidence dtMax K = recursionOrder K + 1 (4₁: 2+1=3; 5₂: 3+1=4) as a law: two knots always admit a linear fit, the +1 reads as the abelian branch of the character variety (imported exponential-network geometry, not a QOU driver), and it is recorded in the audit as an unclaimed probe needing a third-knot (3₁/6₁) check, never a Lean theorem. Nothing fitted, nothing wired. Core-Lean only (no Mathlib olean); every fact is decide/omega-checkable.

No integer in the QOU driver menu (nor in the classical control set) has value-vector (3,4) over (4₁, 5₂): every menu vector differs from dtVector. So no single natural scalar knot-integer — Hecke block count, Wedderburn Euler total, AJ recursion order, crossing, determinant, tetrahedra, braid index, genus — reproduces the character-variety DT count.

                              theorem QOU.QBeta.Driver14CharacterVarietyDTMenu.no_scalar_matches_chirality_split_datum (f : KKnot → Int) :
                              ¬∀ (x : Int), x ∈ dtDatum KKnot.fiveTwo ↔ x ∈ [f KKnot.fiveTwo]

                              The chirality-refinement obstruction (the precise missing driver-14 input). No scalar knot invariant f : KKnot → Int has its one-element datum [f 5₂] equal (as a set) to the 5₂ DT datum {3,4}: matching would force f 5₂ = 4 and f 5₂ = 3, i.e. 4 = 3. Hence the character-variety DT count is not any scalar Euler characteristic / recursion order / block count; supplying it requires a chirality-refined, set-valued moduli count — an object outside the scalar-integer range of the 13 drivers. This is the sharpened, formalized name of the missing "driver-14".

                              Part 3 — packaged verdict #

                              source
                              theorem QOU.QBeta.Driver14CharacterVarietyDTMenu.driver14_dt_count_not_a_qou_scalar :
                              (∀ (v : Int × Int), v ∈ menuVectors → v ≠ dtVector) ∧ ¬∀ (x : Int), x ∈ dtDatum KKnot.fiveTwo ↔ x ∈ [(fun (x : KKnot) => 3) KKnot.fiveTwo]

                              Formalize-first honest verdict (Route 1). Neither reading of "driver-14 supplies the DT count" holds from the QOU scalar drivers: (1) no menu invariant hits the count vector (3,4), and (2) — the deeper obstruction — the 5₂ count is a chirality-split 2-set, which no single-valued scalar invariant can equal. The Behrend-weighted character-variety DT count is therefore not constructible as a scalar QOU invariant; it is an inherently chirality-refined geometric count of the spectral curve — external input, exactly as #4599's per-knot negative and the Rossmann-CC partition-level verdict independently found.
