    phiBProd is not locally zero ⇐ its two products are not locally zero (input 2 of 3) #

    The divisor route to the Faddeev–Volkov uniqueness hr_entire input (QOU.QBeta.RatioEntireOfSameDivisor.entire_toMeromorphicNFOn_div_of_same_order, and the capstone FaddeevUniquenessCapstone.faddeevPhi_proportional_of_same_divisor) needs, for the concrete reference Φ_b = phiBProd, the hypothesis ∀ z, meromorphicOrderAt (phiBProd b) z ≠ ⊤ — i.e. phiBProd is not locally identically zero at any point (ord = ⊤ ⇔ eventually zero).

    Since phiBProd b = num / den and meromorphicOrderAt is additive under products/inverses,

    ord (phiBProd b) = ord num − ord den,

    which is ≠ ⊤ exactly when both products have finite order — i.e. neither the numerator nor the denominator product is locally identically zero. This file reduces input 2 to that single honest fact, WithTop-arithmetic closing the ≠ ⊤ from WithTop.add_ne_top + LinearOrderedAddCommGroupWithTop.neg_eq_top.

    Companion to PhiBProdMeromorphic.phiBProd_meromorphicOn_of_analytic (input 1). The two together leave only input 3 (same divisor) + the shared open analytic input (infinite-product analyticity / non-vanishing of the products) for the concrete Φ_b.

    Verified lean-direct against the pinned Meromorphic cone + PhiBProd. Sorry-free.
