    class QOU.QBeta.RouteCM3CategoryIdentification.IdentifiesClosedSector (C : Type u) :
    Type

    M3 (primary conjecture). The closed-sector categorical datum C carries a chirality-graded DT output (true = the S⁺ sector, false = S⁻) that reproduces the certified M2 spectrum. Content-bearing: the two equations are the conjecture's falsifiable claims about C; an instance exists iff the identification holds for C. (Carries the dtOutput data field, so it is a data-class, not a Prop marker — deliberately: an instance must SUPPLY the output, not merely assert one exists.)

    • dtOutput : Bool → Int

      C has a well-defined chirality-graded integer DT output (Int — the ℤ notation is outside this import cone).

    • dt_plus_eq : dtOutput C true = AomegaM2BPSCohomology.dimBPSplus

      The S⁺-sector output equals the certified dimBPSplus.

    • dt_minus_eq : dtOutput C false = AomegaM2BPSCohomology.dimBPSminus

      The S⁻-sector output equals the certified dimBPSminus.
