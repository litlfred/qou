        §2 — the exclusion for an arbitrary algebraic relation #

        j ≤ d → p j = 0

        No non-trivial algebraic relation. If 2 cos (α ·) satisfies a polynomial relation over ℝ[X] on [1,∞), and α attains every non-positive real there, then every coefficient polynomial vanishes.

        This strengthens no_laurent_of_surjective_nonpos from Laurent relations to algebraic ones; see the module docstring.

        The Laurent case really is a special case #

        The module docstring claims this statement subsumes no_laurent_of_surjective_nonpos. That is a claim about the two theorems, so it is checked here rather than asserted: the Laurent relation is the case d = 1, p₀ = −P, p₁ = X^N, and re-deriving the predecessor from the new statement is a two-line proof.
