    theorem QOU.QBeta.conj_eq_inv_iff_modulus_one {x y s : ℝ} (hs : s = x ^ 2 + y ^ 2) (hne : x ≠ 0 ∨ y ≠ 0) :
    x * (s - 1) = 0 ∧ y * (s - 1) = 0 ↔ s = 1

    q̄ = q⁻¹ exactly on the unit circle. In real coordinates q = x + iy, q⁻¹ = (x − iy)/s with s = x² + y², so q̄ − q⁻¹ = (x − iy)(1 − 1/s) and both components carry the same factor s − 1. For q ≠ 0 the two operations agree iff s = 1.

    This is the whole first leg: candidate (i)'s identification of chirality with conjugation is the corpus's identification of it with the bar involution precisely on |q| = 1, which is the regime candidate (i) names, and it is not the regime the substrate is in.
