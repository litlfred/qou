    QOU.QBeta.QuiverMirrorAutomorphismExcluded — M1 search-space pruning (D1, first rung) #

    Formalize-first for the qou-q9ih (Q,W) construction: before scanning quivers, prune the implementation class. The target datum is the 5₂ chirality split (S⁺, S⁻) = (4, 3) read as a pair of DT counts exchanged by the mirror. The candidate implementations split into two classes:

    • count-invariant symmetries — the mirror acts by a structure map that preserves the DT count: a quiver automorphism, the opposite-quiver duality Q ↦ Q^op (DT-invariant), or any DT-preserving equivalence of the sector category;
    • sector-moving actions — the mirror moves the stability datum to a genuinely different ray (the M2 finding: distinct Borel rays in the abelian spectrum, RouteCM3CategoryIdentification).

    The theorems below exclude the whole first class: if the count Ω is invariant under the mirror implementation σ, every readable pair is amphichiral (bar-odd 0), so the (4, 3) datum is unreachable — and conversely the datum forces Ω(σd) ≠ Ω(d), i.e. any faithful M1 construction must break count-invariance, which a quiver (anti)automorphism cannot. The M1 search space is therefore (quiver, potential, TWO stability rays) — never (quiver + automorphism). This extends Driver14CharacterVarietyDTMenu.no_scalar_matches_chirality_split_datum (no scalar reading works) one level up: no count-preserving symmetry implementation works either.

    Same species as ChiralityGradedCount: input-free statements about arbitrary count functions — the knot numbers enter only through the existing literature defs (dtSplit52), quoted in the exclusion corollary. Nothing here constructs a (Q,W) or derives a DT integer (anti-laundering: the search remains open; this only says where not to search).
