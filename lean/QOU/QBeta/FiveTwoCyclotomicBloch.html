    The 5₂ sum rule: the algebraic core of Routes 8 and 9 #

    Bean qou-8v3k (Route 8) and qou-b7cy (Route 9), PR #4658.

    Everything here is pure commutative-ring algebra — no dilogarithm, no analysis, no Mathlib gap. These are exactly the steps of Routes 8 and 9 that do not depend on the complex Li₂ blocker (qou-clx8), isolated so that they are provable independently of it.

    Route 8 — the two Vieta products #

    Along GGM's deformed 5₂ curve x·y³ − (x²+1)·y² + (x²+x+1)·y − x = 0 the roots satisfy e₁ = (x²+1)/x, e₂ = (x²+x+1)/x, e₃ = 1. Stated with the denominators cleared, so the results hold over any CommRing:

    • prod_one_sub_x_mul : ∏ⱼ (1 − x·yⱼ) = x
    • prod_x_sub : ∏ⱼ (x − yⱼ) = x² (the cleared form of ∏ⱼ(1 − yⱼ/x) = 1/x)

    These are the step that makes the envelope computation collapse: S'(x) = (1/x)·log[(1/x)/x] = −2·log x / x.

    Route 9 — the Bloch-group condition #

    At the cyclotomic point x = −1, with w = 1 + 2cos(2πk/7) a root of w³ − 2w² − w + 1:

    • bloch_poly : (1 − w)²(1 + w) − w² = w³ − 2w² − w + 1 as polynomials
    • bloch_key : hence (1 − w)²(1 + w) = w² at any root

    bloch_poly is the sharp form: the Bloch-group condition δ(2[w] + [−w]) = 0 is not merely implied by the minimal polynomial — it is the minimal polynomial. That is why bloch_key is a one-line linear_combination.

    Consequence (not formalized here — it needs the Bloch group and Borel's theorem, neither of which is in Mathlib): δ(2[w] + [−w]) = w ∧ [(1−w)²(1+w)] = w ∧ w² = 0, so 2[w] + [−w] lies in the Bloch group of ℚ(ζ₇)⁺, which is totally real, hence the element is torsion and its Rogers dilogarithm lies in π²ℚ.

    Nothing here proves the sum rule. The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms. These are its formalizable algebraic components.

    Route 8: the Vieta products along the deformed curve #

    theorem QOU.QBeta.FiveTwoCyclotomicBloch.prod_one_sub_x_mul {R : Type u_1} [CommRing R] (x y₁ y₂ y₃ : R) (h₁ : x * (y₁ + y₂ + y₃) = x ^ 2 + 1) (h₂ : x * (y₁ * y₂ + y₁ * y₃ + y₂ * y₃) = x ^ 2 + x + 1) (h₃ : y₁ * y₂ * y₃ = 1) :
    (1 - x * y₁) * (1 - x * y₂) * (1 - x * y₃) = x

    ∏ⱼ (1 − x·yⱼ) = x for the roots of GGM's deformed 5₂ curve.

    Hypotheses are Vieta for x·y³ − (x²+1)·y² + (x²+x+1)·y − x = 0, with the denominators cleared so the statement lives over any CommRing.

    theorem QOU.QBeta.FiveTwoCyclotomicBloch.prod_x_sub {R : Type u_1} [CommRing R] (x y₁ y₂ y₃ : R) (h₁ : x * (y₁ + y₂ + y₃) = x ^ 2 + 1) (h₂ : x * (y₁ * y₂ + y₁ * y₃ + y₂ * y₃) = x ^ 2 + x + 1) (h₃ : y₁ * y₂ * y₃ = 1) :
    (x - y₁) * (x - y₂) * (x - y₃) = x ^ 2

    ∏ⱼ (x − yⱼ) = x² — the cleared form of ∏ⱼ (1 − yⱼ/x) = 1/x.

    Together with prod_one_sub_x_mul this gives ∏ⱼ [(1 − yⱼ/x)/(1 − x·yⱼ)] = 1/x², which is what turns the envelope derivative into −2·log x / x.

    Route 9: the Bloch-group condition at the cyclotomic point #

    source
    theorem QOU.QBeta.FiveTwoCyclotomicBloch.bloch_poly {R : Type u_1} [CommRing R] (w : R) :
    (1 - w) ^ 2 * (1 + w) - w ^ 2 = w ^ 3 - 2 * w ^ 2 - w + 1

    The sharp form. (1 − w)²(1 + w) − w² is identically the minimal polynomial w³ − 2w² − w + 1 of w = 1 + 2cos(2πk/7).

    So the Bloch-group condition is not a consequence of the minimal polynomial — it is the same polynomial.

    source
    theorem QOU.QBeta.FiveTwoCyclotomicBloch.bloch_key {R : Type u_1} [CommRing R] (w : R) (hw : w ^ 3 - 2 * w ^ 2 - w + 1 = 0) :
    (1 - w) ^ 2 * (1 + w) = w ^ 2

    At any root of w³ − 2w² − w + 1 one has (1 − w)²(1 + w) = w².

    This is the identity behind δ(2[w] + [−w]) = w ∧ w² = 0, i.e. behind 2[w] + [−w] lying in the Bloch group of ℚ(ζ₇)⁺.

    theorem QOU.QBeta.FiveTwoCyclotomicBloch.minpoly_one_sub {R : Type u_1} [CommRing R] (w : R) (hw : w ^ 3 - 2 * w ^ 2 - w + 1 = 0) :

    The minimal polynomial of 1 − w (namely −2cos(2πk/7)) is u³ − u² − 2u + 1.
