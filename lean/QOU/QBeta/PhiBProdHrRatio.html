    The normal-form identity hr_ratio for phiBProd (G5 specialization) #

    Discharges the hr_ratio input of PhiBProdUniquenessFinal.phiBProd_uniqueUpToScalar_of_stripGrowth for a physical (normal-form) second solution: where phiBProd b z ≠ 0, toMeromorphicNFOn (Φ₁ / phiBProd b) univ z = Φ₁ z / phiBProd b z.

    The identity holds because the ratio is analytic at such z:

    • phiBProd is analytic where it is nonzero (phiBProd = num/den, both entire, and phiBProd z ≠ 0 ⇒ den z ≠ 0) — phiBProd_analyticAt_of_ne_zero.
    • Φ₁ is analytic there: strip-growth comparability ‖Φ₁ w‖ ≤ C‖phiBProd w‖ plus phiBProd bounded near z gives a punctured-neighborhood bound, so meromorphicOrderAt Φ₁ z ≥ 0 (meromorphicOrderAt_nonneg_of_bounded_punctured, G5 crux), which for a normal-form Φ₁ means analytic (MeromorphicNFAt.meromorphicOrderAt_nonneg_iff_analyticAt).

    An analytic function is in meromorphic normal form, so toMeromorphicNFOn (Φ₁/phiBProd) univ z equals (Φ₁/phiBProd) z (toMeromorphicNFOn_eq_toMeromorphicNFAt + toMeromorphicNFAt_eq_self).

    The honest regularity hypothesis on the second solution is MeromorphicNFOn Φ₁ univ — the physical Φ_b is a genuine meromorphic function in normal form; the shift equations alone do not impose it.

    Verified lean-direct against the Mathlib Meromorphic.NormalForm cone + merged phiBProd. Sorry-free.
