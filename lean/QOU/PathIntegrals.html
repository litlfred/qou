    Chapter 3 — Path Integrals and Braiding #

    Formalization of the braid-group framework, SU(2)/SO(3) generators, and quantum group structures from Chapter 3 of the QOU manuscript.

    LaTeX source: chapters/path-integrals-and-braiding.tex

    Structure #

    1. Braid group — B₃ presentation and symmetric group S₃
    2. SU(2)/SO(3) — basis, generators, binary dihedral group Dic₃
    3. Braid involutions — twist, flip, and holonomy
    4. Quantum group — U_q(su(2)) and R-matrix braiding

    References #

    • [turaev2010] V. Turaev, Quantum Invariants of Knots and 3-Manifolds, de Gruyter 2010.
    • [lusztig1993] G. Lusztig, Introduction to Quantum Groups, Birkhäuser 1993.

                              structure QOU.PathIntegrals.HeckeAlgebra :
                              Type (u_1 + 1)

                              Hecke algebra H_n(q): the quotient of the group algebra k[B_n] by the quadratic relation (σᵢ − q)(σᵢ + q⁻¹) = 0.

                              When q is not a root of unity, H_n(q) is semisimple and isomorphic to k[S_n] as an abstract algebra (Jimbo's theorem).

                              LaTeX: \label{prop:knot-eigenbasis-complete} (part 1)

                                Number of strands.

                              • carrier : Type u_1

                                Carrier type.

                              • q : ℝ

                                The deformation parameter q.

                              • q_ne_zero : self.q ≠ 0

                                q ≠ 0.

                              • q_not_root_of_unity (k : ℕ) : k ≥ 1 → self.q ^ k ≠ 1

                                q is not a root of unity (for semisimplicity). Encoded as: q^k ≠ 1 for all k ≥ 1.

                              • mul : self.carrier → self.carrier → self.carrier

                                Multiplication in the algebra.

                              • one : self.carrier

                                Unit element.

                              • T : Fin (self.n - 1) → self.carrier

                                Generators T₁, …, Tₙ₋₁ (images of Artin generators).

                              • braid_relation (i : Fin (self.n - 2)) : let i' := ⟨↑i, ⋯⟩; let j := ⟨↑i + 1, ⋯⟩; self.mul (self.mul (self.T i') (self.T j)) (self.T i') = self.mul (self.mul (self.T j) (self.T i')) (self.T j)

                                Braid relation: TᵢTᵢ₊₁Tᵢ = Tᵢ₊₁TᵢTᵢ₊₁ for adjacent generators.

                              • sub : self.carrier → self.carrier → self.carrier

                                Subtraction in the algebra.

                              • smul : ℝ → self.carrier → self.carrier

                                Scalar multiplication by ℝ.

                              • quadratic (i : Fin (self.n - 1)) : self.sub (self.sub (self.mul (self.T i) (self.T i)) (self.smul (self.q - self.q⁻¹) (self.T i))) self.one = self.smul 0 self.one

                                Quadratic relation: Tᵢ² − (q − q⁻¹)·Tᵢ − 1 = 0, equivalently (Tᵢ − q)(Tᵢ + q⁻¹) = 0. The eigenvalues of each generator are q and −q⁻¹.

                                              structure QOU.PathIntegrals.KnotEigenbasisComplete :
                                              Type (max (max (max (max (max (max (u_1 + 1) (u_2 + 1)) (u_3 + 1)) (u_4 + 1)) (u_5 + 1)) (u_6 + 1)) (u_7 + 1))

                                              Completeness of the knot-type eigenbasis (Proposition 4.x).

                                              Combines semisimplicity of H_n(q), Alexander surjectivity, and density in the physical Hilbert space to establish that knot types form a complete eigenbasis replacing the Feynman path integral.

                                              Three parts:

                                              1. H_n(q) is semisimple at generic q, giving the complete q-Schur–Weyl decomposition of V^{⊗n}.
