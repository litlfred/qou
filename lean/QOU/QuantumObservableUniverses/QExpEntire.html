    QOU.QExpEntire — the q-exponential is entire (the Wick-rotation licence) #

    The categorical Wick rotation identifies the q-Laplace pairing s ↦ exp_q(s ·) with the q-Fourier pairing ξ ↦ exp_q(i ξ ·) as a single grouplike element evaluated on the real vs. imaginary axis (def:categorical-fourier, intro-q-resolvent-wick, i-as-braiding-orientation). The identity F(ξ) = L(iξ) is definitional once a single grouplike function is used; its falsifiable content is that this function is defined on all of ℂ, i.e. the q-exponential series converges everywhere (is entire).

    This file proves exactly that, in the substrate regime q > 1 (q₀ ≈ 1.11): the series ∑ xⁿ / [n]_q! is summable for every x : ℂ. If it had a finite radius of convergence the Wick rotation would not be globally valid, so summability-everywhere — not the tautological F = L ∘ (i·) — is the honest mathematical core.

    Base ring: genuinely archimedean (ℝ growth bounds, ℂ series, tendsto_pow_atTop), so ℝ/ℂ is correct here per §7c, not gratuitous.
