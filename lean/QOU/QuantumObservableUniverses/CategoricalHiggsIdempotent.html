    Refinement note (2026-05-24). The original class had a single residual : ℝ placeholder field. Per docs/audits/2026-05-24-pr1122-retraction-and-existing-canonical-adaptation.md §3.A, this file refines the class to explicitly encode:

    • The Higgs doublet $\Phi \in V_{1/2, 1/2}$ structure
    • The VEV $\langle\Phi\rangle = (0, v/\sqrt{2})^\top$ with the $\sqrt{2}$ in the doublet decomposition (SM convention)
    • The gauge couplings $g, g'$ for $\mathrm{SU}(2)_L \times \mathrm{U}(1)_Y$
    • The Higgs self-coupling $\lambda$
    • The mass-generation rules: $m_W = gv/2$, $m_Z = \sqrt{g^2 + g'^2}\,v/2$, $m_H = \sqrt{2\lambda}\,v$

    These fields make the categorical origin of the $\sqrt{2}$ factor (which appeared in the empirical PR #1122 W-correction probe and was retracted in PR #1126) explicit at the class level — the $\sqrt{2}$ is the SM Higgs-VEV doublet convention, encoded structurally here.

    The class remains conjectural (§3b): the noncomputable instance carries a sorry representing the open conjecture itself, not a missing proof. Downstream theorems may take [CategoricalHiggsIdempotent] as an explicit [Instance] hypothesis to derive unconditional Lean theorems modulo this single conjectural input (per §3b-cond).

    class QOU.QuantumObservableUniverses.CategoricalHiggsIdempotent :
    Type

    Categorical Higgs idempotent $e_H \\colon A \\to A$ projecting onto unbroken $\\mathrm{U}(1)_{em}$, with explicit doublet structure

    • VEV decomposition + gauge couplings + mass-generation rules.

    Refined version (2026-05-24): encodes the structural origin of the $\sqrt{2}$ in $m_W = gv/2 = g \cdot (v/\sqrt{2})/\sqrt{2}$.

    • vev_v_GeV : ℝ

      The vacuum expectation value scalar $v$ in GeV. SM measured value: $v \approx 246\;\text{GeV}$.

    • vev_v_pos : 0 < vev_v_GeV

      The VEV is positive.

    • vev_lower_component_GeV : ℝ

      The Higgs doublet's lower-component VEV value: $v/\sqrt{2}$. This is the SM convention where the doublet is parametrised as $\Phi = (\phi^+, \phi^0)^\top$ with $\langle \phi^0 \rangle = v/\sqrt{2}$.

    • vev_lower_component_eq_v_over_sqrt2 : vev_lower_component_GeV = vev_v_GeV / √2

      The doublet decomposition: $\\langle \\Phi \\rangle_{\\text{lower}} = v / \\sqrt{2}$. This is the SM CONVENTION for the Higgs-doublet VEV; the $\sqrt{2}$ comes from the doublet's component structure ($\Phi \in V_{1/2, 1/2}$), not from a deeper categorical fact.

    • gauge_coupling_g : ℝ

      The $\mathrm{SU}(2)_L$ gauge coupling $g$. SM measured value: $g \approx 0.6520$ at the $Z$ scale.

    • gauge_coupling_g_prime : ℝ

      The $\mathrm{U}(1)_Y$ gauge coupling $g'$. SM measured value: $g' \approx 0.3574$ at the $Z$ scale.

    • gauge_couplings_pos : 0 < gauge_coupling_g ∧ 0 < gauge_coupling_g_prime

      Both gauge couplings are positive.

    • higgs_self_coupling : ℝ

      The Higgs self-coupling $\lambda$. SM measured value: $\lambda \approx 0.129$ at the EW scale.

    • higgs_self_coupling_pos : 0 < higgs_self_coupling

      The Higgs self-coupling is positive (vacuum stability).

    • cos_theta_W : ℝ

      The Weinberg angle $\theta_W$ derived from gauge couplings: $\\cos\\theta_W = g / \\sqrt{g^2 + g'^2}$.

      The SM W/Z mass ratio is $m_W/m_Z = \\cos\\theta_W$.

    • cos_theta_W_def : cos_theta_W = gauge_coupling_g / √(gauge_coupling_g ^ 2 + gauge_coupling_g_prime ^ 2)

      Definition: $\\cos\\theta_W = g/\\sqrt{g^2 + g'^2}$.
