    QOU.Virtual — off-shell non-observability of virtual particles #

    A level-n virtual excitation lives in the recursive brane tower and is a base state f ∈ A_0 dressed by n internal 1-forms ω_1, …, ω_n ∈ Ω^1. The canonical projection π_0 : A_n → A_0 back to the observable base level acts through the counit ε : Ω^1 → K:

    π_0(f ⊗ ω_1 ⊗ ⋯ ⊗ ω_n) = f · ε(ω_1) ⋯ ε(ω_n)

    (virtual-particles-exceptional-divisor, prop:vertex-is-exceptional-divisor). A form with no constant part (ε(ω) = 0) is off-shell; the physical content is that off-shell excitations "project no shadow" onto the base level — they are non-observable — while on-shell excitations survive.

    This file proves that dichotomy exactly, as a biconditional (not merely the one-way "a product with a zero factor is zero"): the projection vanishes iff the base state is zero or some dressing form is off-shell.

    Base ring: a generic commutative domain K (§7c — algebraic, counit and scalar action only; no archimedean input).

      theorem QOU.Virtual.pi0_offshell {K : Type u_1} [CommRing K] {A : Type u_2} [AddCommGroup A] [Module K A] {n : ℕ} {e : Fin n → K} (f : A) (h : ∃ (i : Fin n), e i = 0) :

      Off-shell ⇒ no shadow. If some dressing form is off-shell (e i = 0), the excitation projects to zero at the base level — it is non-observable.

      theorem QOU.Virtual.pi0_eq_zero_iff {K : Type u_1} [CommRing K] {A : Type u_2} [AddCommGroup A] [Module K A] {n : ℕ} [IsDomain K] [NoZeroSMulDivisors K A] (e : Fin n → K) (f : A) :
      pi0 e f = 0 ↔ (∃ (i : Fin n), e i = 0) ∨ f = 0

      On-shell survives; off-shell vanishes — exactly. Over a domain with no zero smul-divisors, the base-level projection vanishes iff the base state is zero or some dressing form is off-shell. Equivalently, the excitation is observable (π_0 ≠ 0) iff f ≠ 0 and every form has a nonzero constant part.
