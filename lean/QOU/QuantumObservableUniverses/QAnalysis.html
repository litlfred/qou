    QOU.QuantumObservableUniverses.QAnalysis — q-analysis display structures #

    Authoritative library home for three q-analysis structures previously defined only inside content-object display snippets (quantum-observable-universes/q-resolvent.lean, q-heat-equation.lean, q-dilogarithm.lean). Relocated here (2026-06-09 axiom audit) so the companion *-unique.lean display files can import the real structures and carry genuinely type-checked uniqueness statements rather than referencing auto-bound type variables.

    Ground ring R_q = ℤ[q, q⁻¹] is taken from QOU.Archimedean.GroundRing.

    Type u_1

    q-Resolvent data. Packages the q-Laplacian delta_q, the spectral parameter s, and an inverse witness for s + delta_q in the convolution algebra 𝓗_q.

    • delta_q : H → H

      The q-Laplacian endomorphism.

    • s : H

      The spectral parameter.

    • R : H → H

      The resolvent R_q(s).

    • inverse_witness (x : H) : self.R (self.delta_q x) = x

      Inverse witness: R ∘ delta_q = id.

      structure QOU.QHeatEquation (S : Type u_1) :
      Type u_1

      q-Heat equation data: a one-parameter family with q-Laplacian, satisfying ∂ₜ u = -Δ_q u pointwise (algebraic shadow of the PDE).

      • u : ℝ → S → Archimedean.R_q

        Time-dependent section u : ℝ → S → Archimedean.R_q.

      • dt_u : ℝ → S → Archimedean.R_q

        Time-derivative ∂ₜ u.

      • dq_u : ℝ → S → Archimedean.R_q

        q-Laplacian applied to u.

      • evolves (t : ℝ) (x : S) : self.dt_u t x = -self.dq_u t x

        The evolution equation ∂ₜ u(t,x) = -Δ_q u(t,x).

        structure QOU.QDilogarithm (H : Type u_1) [Add H] :
        Type u_1

        q-Dilogarithm data: a level-2 iterated primitive of H_q characterised by the pentagon identity. The pentagon relation is additive, so the carrier H is required to support +.

        • Li2 : H × H

          The level-2 primitive Li₂_q ∈ H × H.

        • log_q : H

          The level-1 primitive log_q ∈ H.

        • Li2_eval : H → H

          Evaluation map.

        • mul : H → H → H

          Binary composition for pentagon arguments.

        • compl : H → H

          Complement x ↦ 1 - x.

        • div : H → H → H

          Division (x,y) ↦ x/y.

        • pentagon (x y : H) : self.Li2_eval y + self.Li2_eval x = self.Li2_eval (self.mul x y) + self.Li2_eval (self.div (self.mul x (self.compl y)) (self.compl (self.mul x y))) + self.Li2_eval (self.div (self.mul y (self.compl x)) (self.compl (self.mul x y)))

          Pentagon identity (5-term relation).

            Type u_1

            q-Logarithm data: an abstract primitive element of the q-shuffle Hopf algebra, characterised by primitivity Δ_q(log_q) = log_q ⊗ 1 + 1 ⊗ log_q and vanishing counit ε(log_q) = 0.

              The primitive element log_q ∈ H.

            • coprod : H → H × H

            • counit : H → Archimedean.R_q

              Counit on H.

            • one : H

              The unit / grouplike 1 ∈ H against which primitivity is taken.

            • primitive_left : (self.coprod self.log_q).1 = self.log_q

              Primitivity (right component).

            • counit_eq_zero : self.counit self.log_q = 0
