    structure QOU.CategoricalFourier (A : Type u_1) (Irreps : Type u_2) :
    Type (max u_1 u_2)

    Categorical Fourier transform data: a monoidal functor intertwining q-convolution with pointwise product, given as the family of Peter–Weyl projections.

    • project : Irreps → (A → A) → A → A

      The Fourier-image family: one projection per irreducible.

    • monoidal (j : Irreps) (f g : A → A) (q_conv : (A → A) → (A → A) → A → A) : self.project j (q_conv f g) = fun (x : A) => self.project j f (self.project j g x)

      Monoidal property: convolution becomes pointwise product on each irreducible component.

      structure QOU.CategoricalLaplace (A : Type u_1) :
      Type u_1

      Categorical Laplace transform data: a monoidal functor from q-convolution to pointwise product (Hopf pairing with the real-exponential grouplike).

      • transform : (A → A) → Archimedean.R_q → A → A

        Pairing: f ↦ (s ↦ ⟨exp_q(-s·), f⟩).

      • monoidal_mul (f g : A → A) (s : Archimedean.R_q) (q_conv : (A → A) → (A → A) → A → A) : self.transform (q_conv f g) s = fun (x : A) => self.transform f s (self.transform g s x)

        Monoidal: L[f ∗_q g] = L[f] · L[g].

      • monoidal_unit (s : Archimedean.R_q) : self.transform id s = id

        Unit preservation: L[𝟙] = 𝟙, with the monoidal unit of A → A under composition pinned to id. Quantifying one over all functions (the previous form) together with monoidal_mul makes the structure uninhabitable for |A| ≥ 2; the unit is a specific object, so it is id.
