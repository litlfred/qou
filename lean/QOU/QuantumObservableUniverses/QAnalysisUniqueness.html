    QOU.QuantumObservableUniverses.QAnalysisUniqueness #

    The three q-analysis uniqueness statements, conditional on the one rigidity step their narrative proofs assert, and proved from it.

    Why they are conditional #

    Until 2026-09-06 each was an unconditional axiom, and all three were false -- see QAnalysisUniquenessCounterexamples. The structures carry their ambient maps as free function fields, so agreement of those maps does not pin the distinguished element.

    The repair is not a new hypothesis invented to rescue the claim. Each *_rigid hypothesis below is a verbatim restatement of a sentence the block's own narrative proof already asserts:

    • prf:q-exponential-unique -- "The flow equation on primitives has only the trivial solution" -> flow_rigid.
    • prf:q-logarithm-unique -- "a primitive fixed by D_q with trivial counit vanishes" -> prim_rigid.
    • prf:q-dilogarithm-unique -- "The solution space of the level-2 shuffle recursion is one-dimensional modulo lower-level primitives" -> pentagon_rigid.

    Each is a kernel-triviality statement about a single element, from which two-element uniqueness is derived by subtraction. That is what keeps these off the self-assuming projection §3b-cond item 5 forbids: a hypothesis of the form "any two agree" would be the conclusion; a hypothesis of the form "the difference vanishes" is a strictly weaker input the proof has to work with.

    The narrative proofs also silently need the ambient maps to be additive -- they subtract two grouplikes and apply Δ, ε, D_q to the difference. A bare carrier type supports none of that, which is the deeper reason the original encodings could not be the narrative proofs. Additivity is therefore also explicit, over AddCommGroup.

    What is still open #

    Discharging any *_rigid hypothesis needs a graded q-shuffle Hopf algebra -- the degree bound is what makes the narrative's "iterating D_q forces all coefficients to vanish" work -- and the corpus does not have one. That gap is now visible in the type instead of hidden in an axiom.

    References #

    • [kassel1995] Quantum Groups (Springer GTM 155), §III.3, §IV.3

    e₁.e_q = e₂.e_q

    Uniqueness of the q-exponential grouplike, conditional on flow rigidity.

    flow_rigid is the narrative proof's own step: an element fixed by the Jackson derivative with vanishing counit is zero. Given it, the difference of two grouplikes sharing counit and D_q is such an element.

    theorem QOU.QDilogarithm.eval_unique_of_pentagon_rigid {H : Type u_1} [AddCommGroup H] (L₁ L₂ : QDilogarithm H) (h_mul : L₁.mul = L₂.mul) (h_compl : L₁.compl = L₂.compl) (h_div : L₁.div = L₂.div) (pentagon_rigid : ∀ (f : H → H), (∀ (x y : H), f y + f x = f (L₁.mul x y) + f (L₁.div (L₁.mul x (L₁.compl y)) (L₁.compl (L₁.mul x y))) + f (L₁.div (L₁.mul y (L₁.compl x)) (L₁.compl (L₁.mul x y)))) → f = 0) :
    L₁.Li2_eval = L₂.Li2_eval

    Uniqueness of the q-dilogarithm evaluation, conditional on pentagon rigidity.

    The conclusion is about Li2_eval, not Li2, and that is a correction rather than a weakening: Li2 is not mentioned by the pentagon field, so no hypothesis about the pentagon can reach it. The refuted axioms concluded Li2.1 = Li2.1, which the pentagon never constrained.

    The pentagon relation is additive in Li2_eval, so the difference of two solutions is again a solution; pentagon_rigid -- the narrative proof's one-dimensionality step -- then forces it to vanish.
