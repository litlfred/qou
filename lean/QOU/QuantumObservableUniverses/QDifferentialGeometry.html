    QOU.QuantumObservableUniverses.QDifferentialGeometry — q-differential-geometry display structures #

    Authoritative, importable library home for the categorical Dirac operator, Lagrangian, and q-connection data, so the companion *-unique.lean display files can import the real structures and carry genuinely type-checked uniqueness statements (the content-object snippets that define these structures live outside the QOU Lake library and are not importable on their own).

    These match the strengthened statements introduced on main by the proof-integrity(dirac|lagrangian) sweep (commits 2864d683, e0c6bb38): over an R-linear monoidal category the defining morphism is pinned by a *_formula law field rather than left free, so uniqueness is a genuine determination (not mere extensionality on free fields). CategoricalQConnection is strengthened here the same way (qinv + q_unit + nabla_q + nabla_q_formula).

    FrobeniusHopfData / CategoricalConnection from QOU.QuantumObservableUniverse.GaugeTheory; R_q from QOU.Archimedean.GroundRing.
