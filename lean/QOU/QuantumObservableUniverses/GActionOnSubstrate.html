    §3b-cond class axiomatisation for content block conj:g-action-on-substrate: Categorical $G = \\mathrm{SU}(2)_L \\times \\mathrm{U}(1)_Y$ action on the Frobenius–Hopf substrate.

    This is a conjecture, and the honest open state is a content-bearing class with no instance (AGENTS.md §3b-tax). GActionOnSubstrate carries the four axioms below — the conjecture's content, not a placeholder.

    No instance is provided anywhere in this file. An instance is the conjecture; fabricating one would be the audit-dodge §1a forbids. A downstream result takes [GActionOnSubstrate] as an explicit [Instance] hypothesis and is thereby conditional on it — rigorous modulo this single named input, per §3b-cond. It is not unconditional, and calling it so would be the "conditional-proved ≠ premise-established" confusion AGENTS.md warns about.
