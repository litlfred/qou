    QOU.KnotTheory — Braid-word knot representations #

    Knots and links are encoded as braid words in the Artin braid group B_n — sequences of generator letters σ_i^ε with index i ∈ {0, …, n-2} and exponent sign ε ∈ {+1, -1}. Markov closure turns a braid word into a link; every knot or link arises this way (Alexander's theorem).

    The braid-word encoding is O(n) in storage and O(n) for writhe / crossing-count, matching the older PD/Gauss-code encoding's complexity while staying in the canonical Hecke-algebra register that the QOU mass derivation uses throughout (AGENTS.md Canonical derivation chain). Multigraph encodings (PD code, Gauss code, chord diagrams) are equivalent up to a basis change but are not used elsewhere in the paper, so we drop them here.

    This file's targets — Jones polynomials, Khovanov homology, hyperbolic volumes — are computable from the braid word directly via the Markov trace on H_n(q) and via SnapPy lookups for hyperbolic data.

                        source
                        def QOU.KnotTheory.BraidWord.writhe (β : BraidWord) :
                        ℤ

                        Writhe of a braid word: the exponent sum w(β) = Σ_j ε_j over its letters σ_{i_j}^{ε_j}.

                        This is the writhe of the Markov closure diagram, and is the O(n) computation this file's header promises alongside crossingCount. Unlike the crossing count it is signed, so it is not a knot invariant on its own — it changes under Markov stabilisation — but it is exactly the framing correction that turns the Ocneanu trace into a link invariant.

                        Equations
                        • β.writhe = (List.map QOU.KnotTheory.BraidLetter.signValue β.letters).sum

                          theorem QOU.KnotTheory.BraidWord.abs_writhe_le_crossingCount (β : BraidWord) :
                          β.writhe.natAbs ≤ β.crossingCount

                          |w(β)| ≤ c(β): the writhe is bounded by the crossing count, with equality iff every letter has the same sign. Each summand contributes ±1.

                                          Writhe and Crossing Number #

                                          source
                                          def QOU.KnotTheory.writhe (β : BraidWord) :
                                          ℤ

                                          The writhe of a braid word (signed sum of exponents). For a braid word σ_{i_1}^{ε_1} ⋯ σ_{i_k}^{ε_k}, this returns ε_1 + ⋯ + ε_k. Note: this is the braid-projection writhe; it counts crossings between strands with signs. Per-component self-writhe (counted only within a single component of the closure) is zero in the standard braid projection — strands do not self-cross.
