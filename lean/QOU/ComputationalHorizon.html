    QOU.ComputationalHorizon #

    Canonical declaration for content block at quantum-observable-universe/information-theory/computational-horizon.ts.

    Formalises the manuscript definition of a computational horizon for the braid closure L = β̂ of a computation with c = 3N crossings (N Toffoli gates): the Skein resolution tree has 3^c leaves, and bandwidth saturation forces the time bound t ≥ (c·log 3 / 𝔅(q))·3^{c−c₀} (§7c: archimedean over ℝ — log, rpow).

    source
    structure QOU.ComputationalHorizon :
    Type

    Data for a computational horizon of L = β̂.

    A definition carrier: N Toffoli gates give c = 3N crossings; the resolution tree has numLeaves = 3^c leaves; the information bandwidth bandwidth = 𝔅(q) > 0 bounds the sampling rate; and minTime is pinned to the bandwidth-saturation lower bound.

    • N : ℕ

      Number of Toffoli gates N.

    • c : ℕ

      Number of crossings c.

    • c_eq : self.c = 3 * self.N

      c = 3N.

    • numLeaves : ℕ

      Number of leaves of the Skein resolution tree.

    • numLeaves_eq : self.numLeaves = 3 ^ self.c

      The resolution tree has 3^c leaves — one per discrete history.

    • bandwidth : ℝ

      Information bandwidth 𝔅(q) per Planck time.

    • bandwidth_pos : 0 < self.bandwidth

      Bandwidth is strictly positive.

    • c0 : ℝ

      Reference crossing count c₀ in the exponent.

    • minTime : ℝ

      Minimum Planck-step time to extract the degree-0 answer.

    • minTime_eq : self.minTime = ↑self.c * Real.log 3 / self.bandwidth * 3 ^ (↑self.c - self.c0)

      Bandwidth-saturation bound: t ≥ (c·log 3 / 𝔅(q))·3^{c−c₀}.
