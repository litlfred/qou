    QOU.q_gl_obstruction_calc #

    Canonical declaration for content block prop:q-gl-obstruction-calc: Obstruction to $q$-flatness.

    The four-part claim is now asserted as a theorem (no longer a bare def : Prop). Its arithmetic core is composed from the proved results in QOU.QGeometricLanglands:

    • part 3 (Kummer divisibility, κ₀ mod n = 0 ↔ n ∣ χ(A)) composes the proved kummer_divisibility_criterion with the geometric bridge (κ₀ mod n = 0 ↔ χ(A) ≡ 0 (mod n), the Kummer exact-sequence computation), which is now carried as the explicit conditional-class hypothesis QOU.QGlObstructionCalcContext.kappa_kummer_bridge (AGENTS.md §3b-cond) rather than an internal sorry — the geometric input is thereby visible in the theorem's signature and part 3 is a genuine conditional derivation;
    • part 4 (perpetual obstruction at arbitrarily large Kummer levels) is derived from the proved obstruction_cofinite_persistence together with part 3 — no additional geometric input.

    Parts 1 (intrinsic curvature nonzero when κ₀ ≠ 0, via HKR) and 2 (q-flatness ↔ vanishing connection-dependent curvature) are genuinely geometric and are not covered by the arithmetic core. They are assumed, as the class fields intrinsic_curvature_nonzero and q_flatness_equiv, and the theorem discharges each by returning the field — exact ctx.intrinsic_curvature_nonzero / exact ctx.q_flatness_equiv.

    Read the two halves differently, because they are not the same kind of thing. Part 3's kappa_kummer_bridge is an input: the theorem composes it with the proved kummer_divisibility_criterion to reach a conclusion neither one states, which is the §3b-cond pattern working as intended. Parts 1 and 2 have no such composition — each field's type is its conjunct of the conclusion verbatim, so for those two the theorem asserts exactly what it assumes. The mathematical content of this declaration is parts 3 and 4.

    Docstring corrected 2026-08-24. Until now this paragraph, and the per-part list below, said parts 1 and 2 "carry honest sorrys with the manuscript citation per AGENTS.md §1". That stopped being true at b67ee924e84, which replaced both sorrys with the class fields above and left the prose describing the previous state. The change is a legitimate move — a sorry and a hypothesis-carrying field are both honest ways to record an unproved input, and QGlObstructionCalcContext has no instance anywhere, so nothing is silently discharged — but a reader trusting the docstring would have looked for two sorrys that are not there and missed that two of the four parts are now assumptions.

    Base ring (§7c) #

    The arithmetic core runs in ℤ (χ(A), Kummer levels, divisibility). The two curvature values F^{intr}_q and R(∇) are only ever tested against zero (≠ 0, = 0) -- they are never ordered, normed or approximated -- so they take values in a generic commutative ring rather than ℝ. The archimedean realisation is the instantiation R := ℝ.

    • kappa_zero : Prop

      Predicate: the obstruction class κ₀ = e(ξ) ∈ H²(𝒮, 𝔾_m) vanishes.

    • kappa_kummer_bridge (n : ℕ) : 1 ≤ n → (kappa_vanishes R n ↔ chi_A R % ↑n = 0)

      Geometric Kummer bridge (class-axiomatised geometric input, per AGENTS.md §3b-cond). At Kummer level n ≥ 1, the mod-n reduction of the obstruction class κ₀ ∈ H²(𝒮, 𝔾_m) — the connecting map of the Kummer exact sequence 0 → μ_n → 𝔾_m --(·)ⁿ--> 𝔾_m → 0 in sheaf cohomology — vanishes iff the Euler characteristic satisfies χ(A) ≡ 0 (mod n). This is the genuinely geometric half of part 3: it computes κ₀ mod n by χ(A) mod n (the Yekutieli central-extension computation H²(𝒮, 𝔾_m) ≅ ℤ with κ₀ ↔ χ(A)), a fact not derivable from Mathlib. It is an input to the theorem — not part 3's conclusion (κ₀ mod n = 0 ↔ n ∣ χ(A)), which is derived by composing this bridge with the proved arithmetic QGeometricLanglands.kummer_divisibility_criterion. Encoding it as a named field (rather than an internal sorry) makes the conditional dependency explicit in the theorem's signature and auditable from the context.

    • intrinsic_curvature_nonzero : ¬kappa_zero R → F_intr ≠ 0

      External theorem / missing input: intrinsic curvature is nonzero when κ₀ ≠ 0

    • q_flatness_equiv : q_flat R ↔ R_connection = 0

      External theorem / missing input: q-flatness is equivalent to vanishing connection-dependent curvature

      theorem QOU.q_gl_obstruction_calc {R : Type u_1} [CommRing R] (ctx : QGlObstructionCalcContext R) :
      (¬QGlObstructionCalcContext.kappa_zero R → QGlObstructionCalcContext.F_intr ≠ 0) ∧ (QGlObstructionCalcContext.q_flat R ↔ QGlObstructionCalcContext.R_connection = 0) ∧ (∀ (n : ℕ), 1 ≤ n → (QGlObstructionCalcContext.kappa_vanishes R n ↔ ↑n ∣ QGlObstructionCalcContext.chi_A R)) ∧ ∀ (N : ℕ), ∃ (n : ℕ), N < n ∧ ¬↑n ∣ QGlObstructionCalcContext.chi_A R ∧ ¬QGlObstructionCalcContext.kappa_vanishes R n

      Obstruction to q-flatness (prop:q-gl-obstruction-calc).

      Let $(\mathbf{C}, A, \tau)$ be a quantum observable universe with $\chi(A) \neq 0$ and obstruction class $\kappa_0 = e(\xi) \in H^2(\mathcal{S}, \mathbb{G}_m)$. Then:

      1. the intrinsic q-curvature F^{intr}_q = HKR⁻¹(κ₀) is nonzero whenever κ₀ ≠ 0 — assumed, as ctx.intrinsic_curvature_nonzero (geometric, manuscript);
      2. ∇_q is q-flat iff its connection-dependent curvature vanishes — assumed, as ctx.q_flatness_equiv (geometric, manuscript);
      3. at Kummer level n ≥ 1, κ₀ mod n = 0 iff n ∣ χ(A) — derived by composing the geometric bridge to χ(A) mod n (the explicit conditional-class hypothesis kappa_kummer_bridge) with the proved arithmetic half kummer_divisibility_criterion;
      4. for χ(A) ≠ 0 the obstruction persists at arbitrarily large Kummer levels — proved from obstruction_cofinite_persistence + (3).
