    QOU.RepresentationTheory — Vectors in Rep(SU(2)) #

    Formalizes the representation-theoretic foundations of vectors in the QOU framework:

    1. Simple objects — definition of simplicity, tensor generation by V
    2. Categorical hadrons — morphisms 𝟙 → V^⊗n as composite particles
    3. Adjoint trace — categorical inner product on endomorphisms
    4. Pawlowski–Leitner basis — canonical basis for intertwiner spaces
    5. Pawlowski–Leitner inner product — orthogonality of the PL basis

    References #

    • [leitnerpawloski2004] arXiv:math/0409565 — "Unital Gröbner Bases over Arbitrary Commutative Ground Rings" (Leitner & Pawloski); the single Pawloski–Leitner paper
    • [kock2004] https://doi.org/10.1017/CBO9780511615443
    • [manuscript] §1, Vectors, hadrons, and the Pawlowski–Leitner basis

    §1 Simple Objects and Tensor Generation #

    source
    structure QOU.SimpleObject (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] :
    Type u

    An object X in a monoidal category C is simple if every monomorphism into X is either zero or an isomorphism.

    When the fibre functor τ is faithful and exact, X is simple in C iff τ(X) is a simple (irreducible) module.

    LaTeX: \label{rem:simple-objects-V}

      The underlying object in C.

    • catDim : ℕ

      The categorical dimension (rank of τ(obj) as a free R-module).

    • catDim_pos : self.catDim > 0

      The categorical dimension is positive.

            §2 Categorical Hadron #

            source
            structure QOU.CategoricalHadron (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] :
            Type

            A categorical hadron is a morphism 𝟙 → V^⊗n for some n ≥ 2, representing a composite particle as a tensor product of fundamental objects. The morphism factors through the Frobenius comultiplication and projections to simple summands.

            This is the purely categorical predecessor of the localized hadron (def:hadron) which adds a base point on the projective line.

            LaTeX: \label{def:categorical-hadron}

            • valence : ℕ

              The valence: number of constituent simple objects.

            • valence_ge : self.valence ≥ 2

              Valence is at least 2 (at least two constituents).

            • constituent_spins : Fin self.valence → ℕ

              The spin labels of the constituents (each as twice_j).

                    §3 Adjoint Trace #

                    source
                    structure QOU.AdjointTrace (C : Type u) [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] [CategoryTheory.BraidedCategory C] :
                    Type (max u v)

                    The adjoint trace on endomorphisms of V.

                    Given a Frobenius–Hopf data (A, μ, η, Δ, ε, λ), the adjoint trace of an endomorphism f : V → V is defined as tr_Ad(f) = λ ∘ μ ∘ (f ⊗ id_{V∨}) ∘ coev_V.

                    Properties:

                    • Cyclicity: tr_Ad(f ∘ g) = tr_Ad(g ∘ f)
                    • Non-degeneracy: ⟨f, g⟩_Ad = tr_Ad(f† ∘ g) is non-degenerate

                    In the archimedean realisation with G = SU(2), this recovers the Killing form: tr_Ad(f) = -2 tr_{ℂ²}(f).

                    LaTeX: \label{rem:adjoint-trace}

                    • frobHopf : FrobeniusHopfData C

                      The Frobenius–Hopf data providing the trace infrastructure.

                    • fundamentalObj : C

                      The fundamental object V on which endomorphisms are traced.

                        §4 Pawlowski–Leitner Basis #

                        source
                        noncomputable def QOU.pawLeiDim (twice_j n : ℕ) :
                        ℕ

                        The dimension of the intertwiner space Hom_{SU(2)}(V_j, V_{1/2}^⊗n).

                        Given by the hook-length formula: dim = (2j+1) · n! / ((n/2 + j + 1)! · (n/2 - j)!) when n ≡ 2j (mod 2) and n ≥ 2j, and zero otherwise.

                            §5 Pawlowski–Leitner Inner Product #

                            source
                            structure QOU.PawLeiInnerProduct :
                            Type

                            The Pawlowski–Leitner inner product on intertwiner spaces.

                            Defined via the adjoint trace: ⟨φ, ψ⟩_PL = tr_Ad(φ† ∘ ψ) = λ ∘ μ ∘ (φ† ∘ ψ ⊗ id) ∘ coev_{V_j}

                            The Pawlowski–Leitner basis {T_λ} is orthogonal with respect to this pairing: ⟨T_λ, T_μ⟩_PL = δ_{λμ} ‖T_λ‖².

                            LaTeX: \label{prop:pawlowski-leitner-inner-product} Ref: [leitnerpawloski2004] PL inner product / intertwiner basis (arXiv:math/0409565)

                            • basis : PawLeiBasis

                              The underlying basis data.

                            • normSq : Fin self.basis.num_basis → ℝ

                              The norm-squared of each basis vector (positive rational).

                            • normSq_pos (i : Fin self.basis.num_basis) : self.normSq i > 0

                              All norms are positive.

                                §6 Knot Factorization through Tensor Powers of V #

                                source
                                theorem QOU.hadron_tensor_factorization {C : Type u} [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] (h : CategoricalHadron C) (spins_pos : ∀ (i : Fin h.valence), h.constituent_spins i ≥ 1) :
                                h.totalTensorPower ≥ 2 * h.valence

                                A categorical hadron factors through tensor powers of V via the PawLei embedding. Each constituent V_{j_i} embeds into V_{1/2}^⊗(2j_i), so the full hadron embeds into V_{1/2}^⊗(2(j_1 + ⋯ + j_n)).

                                The hypothesis spins_pos ensures all constituents have nonzero spin (spin-0 is the trivial representation, which contributes nothing to the tensor embedding).

                                LaTeX: \label{rem:knot-factorization}

                                source
                                theorem QOU.clebsch_gordan_fundamental {C : Type u} [CategoryTheory.Category.{v, u} C] [CategoryTheory.MonoidalCategory C] :
                                (spinSimpleObject C 1).catDim * (spinSimpleObject C 1).catDim = (spinSimpleObject C 0).catDim + (spinSimpleObject C 2).catDim

                                The Clebsch–Gordan decomposition: V_{1/2} ⊗ V_{1/2} ≅ V_0 ⊕ V_1. In terms of categorical dimensions: dim(V_{1/2})² = dim(V_0) + dim(V_1), i.e. 2 · 2 = 1 + 3. Generic over any monoidal category C.
