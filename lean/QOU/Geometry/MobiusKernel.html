    QOU.Geometry.MobiusKernel — the classical Möbius-energy integrand #

    The classical Möbius energy of a curve γ (Freedman–He–Wang) is

    E(γ) = ∫∫ ( 1/‖γ s - γ t‖² − 1/d(s,t)² ) ds dt

    where d(s,t) is the arc-length distance. For an arc-length parametrised curve d(s,t) = |s − t|, and arc-length parametrisation is exactly LipschitzWith 1 γ.

    The point of this file is that the integrand's non-negativity is derived here, not assumed. It follows from the elementary chord-≤-arc inequality, which for a 1-Lipschitz curve is immediate.

    This matters because climax-volume-mass/mobius-energy.lean currently carries

    energy_classical_nonneg : 0 ≤ energy_classical

    as a structure field on CategoricalMobiusEnergy, with a theorem projecting it straight back out. That theorem is a self-assuming projection (AGENTS.md §3b-cond item 5) and it is unprovable there, because energy_classical is an opaque real with no definition — there is nothing to derive it from. This file supplies the missing subject.

    Deliberately independent of the q-side. Nothing here mentions q, the Frobenius–Hopf kernel, or the categorical connection; see beans vta3 / ne0m for why the q → 1 identification is blocked (the framework's transport runs along the q-deformation path, not along the filament, so it carries no two-point Euclidean data).

    Base ring: ℝ is forced (§7c) — ‖·‖, the ordering, and division are all archimedean. E stays a generic NormedAddCommGroup.

      ℝ

      The Möbius energy of an arc-length parametrised curve: the double integral of the integrand.

      Two honest caveats, both about what this does not say.

      1. It does not assert finiteness. Mathlib defines ∫ f = 0 for a non-integrable f, so mobiusEnergy is junk-valued rather than meaningless when the integral diverges. mobiusEnergy_nonneg below is correspondingly weak on such curves — it says 0 ≤ 0. Integrability (equivalently, finite Möbius energy) is a real hypothesis that has to be added before this carries analytic content.
      2. It is the whole-line, arc-length-parametrised form, not the S¹ version of Freedman–He–Wang. Closing up the parameter domain is a separate step.
