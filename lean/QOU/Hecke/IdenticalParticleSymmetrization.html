    QOU.Hecke.IdenticalParticleSymmetrization — Schur–Weyl decomposition of the #

    identical-nucleon constituent power

    The canonical mass-tower constituent factorization (Step 5l, closed_form_tau_M.py:302) is tr_M(𝓑_K) = tr_M³(𝓑_p)^Z · tr_M³(𝓑_n)^N · ∏ fᵢ, where the ^Z/^N are plain powers — Wenzl disjoint multiplicativity, i.e. the trace of the distinguishable tensor power V^{⊗Z} (the power sum p₁^Z = (tr V)^Z).

    For identical nucleons that is the wrong object: the physical trace must project onto a definite symmetry sector under the block-permutation group S_Z. By Schur–Weyl duality the distinguishable power decomposes as

    p₁^Z = Σ_{λ ⊢ Z} f^λ · s_λ (f^λ = #SYT(λ) = dim of the S_Z irrep)

    so the naive tr_M³(𝓑_p)^Z is the FULL sum over symmetry sectors; an identical-particle (e.g. doubly-magic, Pauli-closed) state lives in ONE sector s_λ. The missing-symmetrization gap (docs/audits/2026-06-10-missing- identical-nucleon-symmetrization.md) is precisely that the tower keeps the full power instead of the physical sector.

    This module proves the decomposition for the two smallest occupations, machine-checked (axioms propext/Classical.choice/Quot.sound only — no sorry):

    • Z = 2 (⁴He: the proton pair, the neutron pair). p₁² = s₍₂₎ + s₍₁,₁₎ = h₂ + e₂, multiplicities f^(2)=1, f^(1,1)=1. The square splits into symmetric (h₂) + antisymmetric (e₂); the doubly-magic pp/nn pairing is the S₂-sector projection the plain power omits.
    • Z = 3 (Li: ppp / nnn). p₁³ = s₍₃₎ + 2·s₍₂,₁₎ + s₍₁,₁,₁₎, multiplicities f^(3)=1, f^(2,1)=2, f^(1,1,1)=1 — the standard rep enters with multiplicity 2.
    • Z = 4 (⁸Be / first composite Z: the pp-pp, nn-nn double shells). p₁⁴ = s₍₄₎ + 3·s₍₃,₁₎ + 2·s₍₂,₂₎ + 3·s₍₂,₁,₁₎ + s₍₁,₁,₁,₁₎, multiplicities f^(4)=1, f^(3,1)=3, f^(2,2)=2, f^(2,1,1)=3, f^(1,1,1,1)=1 (Σ (f^λ)² = 1+9+4+9+1 = 24 = 4!). The (2,2) sector (multiplicity 2) and the Klein V₄ ◁ S₄ with S₄/V₄ ≅ S₃ carry the double-pair (pp × nn) exchange and recover the 6 = |S₃| = χ(Bring) Bring symmetry (Step 4).

    General theme (composite Z ≥ 6): S_Z has a non-trivial Young-subgroup lattice (S_6 ⊃ S₂×S₃; S_8 ⊃ S₂≀S₄ …), giving the sub-shell structure whose closures are the nuclear magic numbers.

    Self-contained (CommRing identities, import Mathlib.Tactic.Ring only) — does NOT depend on the rest of QOU.Hecke, so it builds independently.

    Newton–Frobenius power-sum form (the bosonic/fermionic constituents) #

    The symmetrized constituent of symmetrized_constituent_general.py is computed by the Frobenius formula h_Z = Σ_{μ⊢Z} p_μ/z_μ, e_Z = Σ_{μ⊢Z} ε_μ p_μ/z_μ, with power sums p_k = tr_M(B_p^k) and centralizer orders z_μ. The lemmas below are that formula in closed ring-verified form for Z = 2, 3, 4: the complete- homogeneous h_Z (bosonic sector) and elementary e_Z (fermionic / Pauli sector) written against the power sums p_k = Σ xᵢ^k. Multiplying through by Z! clears the 1/z_μ denominators so the statement holds over any CommRing (no division). For Z = 2 this is two_h2 / two_e2 above.

    Orbit identity ≠ Young symmetrizer (relabeling vs. composition) #

    A recurring confusion (block_swap_binding.py, symmetrized_binding_probe.py): the orbit identity tr_M(β_{Z,N}) = tr_M(rep) (atom_orbit_reduction.py) is relabeling — a same-species permutation leaves the canonical word p…pn…n fixed, so it acts by CONJUGATION β_σ W β_σ⁻¹, and any cyclic trace is conjugation-invariant (Markov M1). The identical-particle Young symmetrizer is a DIFFERENT object: the COMPOSITION average |G|⁻¹ Σ_σ tr_M(W·β_σ) (not conjugation), which the inter-nucleon bonds make ≠ tr_M(W) — measured as S_atom ≠ S_free in block_swap_binding.py. The lemma isolates exactly the part the orbit identity proves (conjugation), so the gap to the symmetrizer is explicit.

    source
    theorem QOU.Hecke.IdenticalParticle.orbit_relabel_invariant {R : Type u_1} [CommRing R] {G : Type u_2} [Group G] (τ : G → R) (hcyc : ∀ (x y : G), τ (x * y) = τ (y * x)) (g a : G) :
    τ (g * a * g⁻¹) = τ a

    Relabeling = conjugation is trace-invariant (the orbit identity). For any cyclic trace τ (τ(xy)=τ(yx)) on a group, conjugation by g preserves it: τ(g a g⁻¹) = τ a. This is atom_orbit_reduction's tr_M(β_σ W β_σ⁻¹)=tr_M(W). It does not give τ(a g) = τ(a) — the Young symmetrizer composes β_σ rather than conjugating, so that (generally false) equality is exactly the binding signal log(S_free/S_atom).
