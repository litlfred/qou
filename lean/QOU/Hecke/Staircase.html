    Staircase partitions and the canonical β_EW Δ_I^minimal word #

    This file specialises the abstract HoefsmitRepresentation infrastructure of QOU.Hecke.Hoefsmit to the staircase partitions ρ k = (k, k-1, …, 1), and records the canonical β_EW Δ_I^minimal braid word used by the Python pipeline (computations/staircase_ew_predictions.py).

    The pieces here are the Lean-side counterparts of the Python helpers beta_ew_word and the staircase shape used by hoefsmit_build. The actual matrix construction is part of the (still-research-grade) HoefsmitRepresentation instance and is not duplicated here; this file only fixes the inputs (partition + word) so a downstream theorem can talk about

    HoefsmitRepresentation.HasEigenvalueRatio
    (HoefsmitRepresentation.wordImage (betaEWWord n))
    (q ^ (1 / (2 * k - 1)))

    without committing to a particular construction strategy.

              def QOU.Hecke.betaEWWord (n : ℕ) :
              List (Generator n)

              Concrete realisation of the canonical β_EW Δ_I^minimal word on n strands.

              The Python reference (verbatim from staircase_ew_predictions.py):

              def beta_ew_word(n_strands: int) -> list[int]:
    if n_strands < 4: return [0, 1, 0]
    delta_I = [1, 3, 1]
    word = []
    for k in range(0, n_strands - 1, 2):
        word.extend([k] * 4 + delta_I)
    return word

              For n ≥ 5 we emit the [2j] * 4 ++ [1, 3, 1] block for every j ∈ {0, 1, …, n/2 − 1} whose anchor index 2j fits in Fin (n − 1); the in-range check is discharged by omega per block. For 3 ≤ n < 5 we emit the Python fallback [σ₀, σ₁, σ₀]. For n < 3 no generators exist and the word is empty.

              Intentional deviation from the verbatim Python at n = 4. The Python reference applies the < 4 fallback (so n = 4 enters the loop body), but the loop's delta_I = [1, 3, 1] writes index 3, which is out of bounds in Fin (n − 1) = Fin 3 for n = 4 and would not type-check on the Lean side. We therefore extend the fallback to 3 ≤ n < 5 so the construction stays well-typed. The n = 4 case is not part of the staircase conjecture's testable regime (staircaseStrands k = k(k+1)/2 ∈ {3, 6, 10, 15, …}), so this deviation does not weaken any downstream theorem.

              Replaces the previous opaque declaration so downstream wordImage calls see a concrete list rather than an unevaluable black box.
