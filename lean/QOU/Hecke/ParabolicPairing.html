    The w ↔ w·sᵢ pairing, and its length dichotomy #

    QOU.BraidKnot.HeckeCellular builds the Murphy element x_λ = Σ_{w ∈ S_λ} T_w only in the rank-one case S_λ = ⟨sᵢ⟩, and says why:

    the eigenvector property is proved by pairing each w with w sᵢ — one of the two has length going up, the other down … that pairing argument over Equiv.Perm (Fin (n+1)) is the open work. The T_w basis it needs is now available, so the blocker is the combinatorics, not the algebra.

    This file supplies that combinatorics.

    What is here #

    • length_swap_dichotomy — for every w and every simple reflection sᵢ, exactly one of ℓ(w·sᵢ) = ℓ(w) + 1 and ℓ(w) = ℓ(w·sᵢ) + 1 holds. This is the fact the two rsFun branches are selected by.
    • mulSwap — right multiplication by sᵢ, as an involution of Perm (Fin (n+1)) with no fixed points, so it pairs the group up.
    • mulSwap_pairs on a Finset closed under it: the set splits into the length-ascending half and its image, which is what turns Σ_{w ∈ S} T_w into a sum over pairs.

    Nothing here mentions the Hecke algebra: it is a statement about permutations and Coxeter length, which is exactly why it was the blocker.

      Pairing a closed Finset #

      A Young subgroup containing sᵢ is closed under mulSwap i. On such a set the involution is a fixed-point-free pairing, which is what lets a sum over the set be reorganised into a sum over pairs.

      source
      theorem QOU.Hecke.ParabolicPairing.mulSwap_bij {n : ℕ} {S : Finset (Equiv.Perm (Fin (n + 1)))} {i : Fin n} (hS : ∀ w ∈ S, mulSwap i w ∈ S) (w : Equiv.Perm (Fin (n + 1))) :

      On a set closed under mulSwap i, the map is a bijection of the set onto itself.

      theorem QOU.Hecke.ParabolicPairing.mem_ascending_or_image {n : ℕ} {S : Finset (Equiv.Perm (Fin (n + 1)))} {i : Fin n} (hS : ∀ w ∈ S, mulSwap i w ∈ S) (w : Equiv.Perm (Fin (n + 1))) (hw : w ∈ S) :
      (SymmetricCoxeter.permCoxeterSystem n).length (mulSwap i w) = (SymmetricCoxeter.permCoxeterSystem n).length w + 1 ∨ ∃ v ∈ S, mulSwap i v = w ∧ (SymmetricCoxeter.permCoxeterSystem n).length (mulSwap i v) = (SymmetricCoxeter.permCoxeterSystem n).length v + 1

      The ascending half determines the set. Every element of a closed S is either length-ascending under mulSwap i or the image of one that is — the split the Murphy pairing sums over.

      For a subgroup, closure is free #

      The hS hypothesis above is an assumption about an arbitrary Finset. For the case it exists to serve it is not an assumption at all: a Young subgroup containing sᵢ is closed under right multiplication by sᵢ because it is a subgroup. So the pairing applies to x_λ's index set with nothing to check.
