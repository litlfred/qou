    A uniform energy shift is a total-bond-count term (generic ring) #

    source
    theorem QOU.Hecke.BondCutSymmetryNoSignDefinite.bondSum_energyShift {R : Type u_1} [CommRing R] (epp epn enn npp npn nnn s : R) :
    BondCutSymmetry.bondSum (epp + s) (epn + s) (enn + s) npp npn nnn = BondCutSymmetry.bondSum epp epn enn npp npn nnn + s * (npp + npn + nnn)

    A uniform shift of all three bond energies adds the shift times the total bond count. In bond-factor letters e = -ln b, a shift by s is the common rescaling b_t ↦ e^{-s}·b_t; taking s negative enough drives every energy below zero, which is exactly class B. What it buys is a term proportional to n_pp + n_pn + n_nn, and nothing else.

    Class B's escape has a price: a repulsive neutron–neutron bond. If a pair-additive bond count reproduces the SEMF at pure neutron matter — where the SEMF with a_A > a_V is negative, i.e. unbound — then the n–n energy is strictly negative. In bond-factor letters e_nn = -ln b_nn < 0 means b_nn > 1.

    This is the honest statement of what dropping bondSum_nonneg costs: the escape is real, and it converts a structural exclusion into a falsifiable condition on a derived quantity. The hypothesis a_V < a_A is what AME2020 measures; it enters here as a hypothesis, never as a fit. Conditional-lemma naming per AGENTS.md §Conditional-proved ≠ premise-established.

    theorem QOU.Hecke.BondCutSymmetryNoSignDefinite.energySlope_gt_convexCap_iff {K : Type u_1} [Field K] [LinearOrder K] [IsStrictOrderedRing K] (epp epn enn : K) :
    (enn - epp) / 2 < BondCutSymmetry.energySlope epp epn enn ↔ enn < epn

    The dichotomy: beating the convex cap is exactly leaving the convex hull. δ > (e_nn - e_pp)/2 iff e_pn > e_nn, i.e. iff the p–n bond is weaker than both like-species bonds. In bond-factor letters (e = -ln b, monotone decreasing) that is b_pn < b_nn ≤ b_pp: strictly below the convex hull the corpus derives the interface in.

    No sign hypothesis appears, so class B changes nothing about it. The content is that class B does not open a route to the magnitude: an interface outside the hull is a chosen number, not a derived one, and choosing it to hit a_A is a one-parameter fit (AGENTS.md §NO FITTING, "selection against the target").
