        theorem QOU.Hecke.PauliChannelBinding.pauli_channel_unbound {q : ℝ} (hq : 0 < q) :
        ¬Binds (pauliEigenvalue q)

        Pauli channel is unbound. For positive substrate q, the antisymmetric (Pauli) channel value -q⁻¹ fails the binding criterion 0 < f < 1 because it is negative. Hence identical-nucleon (p-p, n-n) bonds — forced by Pauli antisymmetry into this channel — do not contribute binding. This is the categorical backbone of the chirality→complete-graph result: only the p-n bonds survive. (The Z·N pair count and the deuteron magnitude are NOT claimed here — see the scope note in the file header.)
