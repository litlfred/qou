    Hoefsmit seminormal-form representation of H_n(q) #

    For each partition λ ⊢ n, the Hoefsmit seminormal form gives an explicit matrix representation

    `ρ_λ : H_n(q) → Mat_{f^λ × f^λ}(ℚ(q))`

    where the basis is indexed by standard Young tableaux of shape λ and the matrix entries are determined by the Jucys–Murphy axial distance:

    `(ρ_λ(σ_i))_{T,T'}` is non-zero only when `T'` differs from `T`
by a swap of the entries `i` and `i+1`, and the non-zero values
are rational functions of the axial distance
`d := c(i+1) − c(i)` (where `c(k)` is the content of the cell
holding `k`):

  ρ_λ(σ_i)_{T,T} = (q − q⁻¹) / (1 − q^{−2d}) − q⁻¹    (diagonal)
  ρ_λ(σ_i)_{T,T'} = √(...)                            (off-diagonal swap)

    (See Hoefsmit (1974), Mathas (1999) §3.31, or Murphy (1981) for the precise formulae.)

    The Hoefsmit forms are the word-sensitive Hecke trace path: unlike Murnaghan–Nakayama characters (the q = 1 limit), they carry the full q-deformation of the Hecke algebra, distinguishing braids whose underlying permutation cycle types coincide. This is how ³He (Z=2, N=1) and ³H (Z=1, N=2) get different Markov traces even though their atomic-braid permutations have the same cycle type at H_{3A}.

    This file lays out the structural framework. The Python-side implementation is computations/hecke_seminormal.py (landed in PR #502, R1.b commits) which carries the full arithmetic at q-rational precision.

    structure QOU.Hecke.StandardYoungTableau {n : ℕ} (lam : Partition n) :
    Type

    Standard Young tableau of shape λ ⊢ n. Carries an explicit filling cells : Fin n → ℕ × ℕ mapping integers 1 ≤ k ≤ n to (row, column) cell coordinates; standard-ness is the increasing property along rows and down columns.

    • cells : Fin n → ℕ × ℕ

      Filling: which cell each integer 1..n occupies.

    • in_diagram (k : Fin n) : (self.cells k).1 < lam.parts.length ∧ (self.cells k).2 < lam.parts[(self.cells k).1]?.getD 0

      The cell at position k lies in the diagram of lam (= λ).

    • distinct (k k' : Fin n) : k ≠ k' → self.cells k ≠ self.cells k'

      Cells are pairwise distinct (every position filled exactly once).

    • rows_increasing (k k' : Fin n) : (self.cells k).1 = (self.cells k').1 → (self.cells k).2 < (self.cells k').2 → ↑k < ↑k'

      Rows increase: in the same row, cells with larger column have larger filled integer.

    • cols_increasing (k k' : Fin n) : (self.cells k).2 = (self.cells k').2 → (self.cells k).1 < (self.cells k').1 → ↑k < ↑k'

      Columns increase: in the same column, cells in lower rows have larger filled integer.

          class QOU.Hecke.HoefsmitRepresentation {R : Type u} (n : ℕ) (q : R) (A : Type u) [CommRing R] [Inv R] [Ring A] [Algebra R A] [HeckeAlgebra R n q A] (lam : Partition n) :
          Type u

          Hoefsmit seminormal representation of H_n(q) on the Specht module indexed by partition λ. An instance asserts:

          • A basis indexed by standard Young tableaux of shape λ (size equal to f^λ = the hook-length number of SYT(λ)).
          • For each generator σ_i ∈ H_n(q), an explicit matrix seminormal_matrix i : Mat_{f^λ × f^λ}(R) whose entries are rational functions of the axial distances of the basis tableaux.
          • The matrix family satisfies the three Hecke relations (quadratic, braid, far-commutativity) — captured by the conjunction of the matrix-level identities.

          The .lean file lays out the structural typeclass; substantive construction of the matrix entries lives downstream and is a research-grade follow-up. The Python-side implementation in computations/hecke_seminormal.py carries the arithmetic.

          • dim : ℕ

            Specht-module dimension f^λ. Stored as a field rather than computed because Mathlib's hook-length API is heavy and not always available.

          • dim_pos : 0 < dim q A lam

            Specht-module dimension is positive (every partition has at least the trivial SYT).

          • syt_basis : Fin (dim q A lam) → StandardYoungTableau lam

            Standard Young tableau enumeration. Size equal to dim.

          • seminormal_matrix : Generator n → Matrix (Fin (dim q A lam)) (Fin (dim q A lam)) R

            Hoefsmit matrix for generator σ_i.

          • quadratic_holds (i : Generator n) : seminormal_matrix i * seminormal_matrix i = (q - q⁻¹) • seminormal_matrix i + 1

            Hoefsmit matrices satisfy the Hecke quadratic relation.

          • braid_holds (i j : Generator n) : i.adjacent j → seminormal_matrix i * seminormal_matrix j * seminormal_matrix i = seminormal_matrix j * seminormal_matrix i * seminormal_matrix j

            Hoefsmit matrices satisfy the braid relation.

          • far_commute_holds (i j : Generator n) : i.farCommuting j → seminormal_matrix i * seminormal_matrix j = seminormal_matrix j * seminormal_matrix i

            Hoefsmit matrices satisfy far-commutativity.

              def QOU.Hecke.HoefsmitRepresentation.HasEigenvalueRatio {R : Type u} [CommRing R] {d : ℕ} [DecidableEq (Fin d)] (M : Matrix (Fin d) (Fin d) R) (r : R) :
              Prop

              HasEigenvalueRatio M r asserts that the matrix M has two nonzero eigenvalues μ₁, μ₂ (counted with algebraic multiplicity) whose ratio is r — that is, there exists μ ≠ 0 such that the characteristic polynomial of M is divisible by (X − μ) · (X − r·μ).

              When r ≠ 1 the two factors are coprime, so the divisibility is equivalent to μ and r·μ each appearing as roots (each with algebraic multiplicity ≥ 1). When r = 1 the product collapses to (X − μ)², so divisibility correctly forces μ to have algebraic multiplicity ≥ 2 — the multiplicity case the docstring demands. (A weaker formulation in terms of two separate det (M − λ • 1) = 0 conditions would be trivially satisfied at r = 1 by any single nonzero eigenvalue, which is not the intended meaning.)

                def QOU.Hecke.HoefsmitRepresentation.HoefsmitDistinguishesWordSensitivity {R : Type u} {n : ℕ} {q : R} {A : Type u} [CommRing R] [Inv R] [Ring A] [Algebra R A] [HA : HeckeAlgebra R n q A] (lamZ1N2 lamZ2N1 : Partition n) [HR_Z1N2 : HoefsmitRepresentation n q A lamZ1N2] [HR_Z2N1 : HoefsmitRepresentation n q A lamZ2N1] :
                Prop

                The block-trace of the Hoefsmit representation at partition λ restricted to a Hecke generator gives the (q = 1 limit of) the Murnaghan–Nakayama character; the q-deformation enters via the axial-distance ratios in the matrix entries.

                The Markov trace tr_M decomposes through the Hoefsmit forms via the Wedderburn–Artin sum tr_M(x) = Σ_λ y_λ · χ_λ(x) where χ_λ(x) = Tr(ρ_λ(x)) is the Hoefsmit-matrix trace. For atomic braids the per-partition character χ_λ(β_atom) is what distinguishes ³He from ³H even when their permutation cycle types agree: in the q=1 limit (MN) they are equal, but at finite q the axial-distance dependence of the Hoefsmit matrices produces different traces.

                Word-sensitivity, named as a Prop. The substantive content — that the Hoefsmit forms separate mirror nuclei (e.g. ³He vs ³H) even when their atomic-braid permutations share a cycle type — is that there is an atomic braid word w whose Hoefsmit-matrix trace at the two partitions differs: trace (wordImage w at λ_{Z1N2}) ≠ trace (wordImage w at λ_{Z2N1}). A constructive witness requires the explicit HoefsmitRepresentation matrix entries (which live in the Python implementation hecke_seminormal.py); a Lean-side instance is a research-grade follow-up. Per pattern C of the vacuity-fix playbook we therefore name the conditional conjecture as a def : Prop rather than asserting a vacuous True. The open state is honestly represented by the absence of a proof — there is no self-assuming projection and no : True := trivial.
