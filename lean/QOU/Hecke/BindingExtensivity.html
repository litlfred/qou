    1. A multiplicative observable is not bounded by any line #

    The one lemma with content is Bernoulli applied twice: once to get t^m above a line, once more by squaring to get t^(2m) above a parabola. A parabola beats a line, and that is the entire obstruction.

    source
    theorem QOU.Hecke.BindingExtensivity.sq_mul_sub_one_le_pow_two_mul {t : ℝ} (ht : 1 ≤ t) (m : ℕ) :
    (↑m * (t - 1)) ^ 2 ≤ t ^ (2 * m)

    Bernoulli, squared: for 1 ≤ t and any m, t^(2m) ≥ (m(t-1))².

    One application of one_add_mul_le_pow gives 1 + m(t-1) ≤ t^m; squaring turns the linear lower bound into a quadratic one, which is what outruns C·n.

    source
    theorem QOU.Hecke.BindingExtensivity.exists_pow_gt_linear {t : ℝ} (ht : 1 < t) {s : ℝ} (hs : 0 < s) (C : ℝ) :
    ∃ (n : ℕ), C * ↑n < s * t ^ n

    No constant scale makes an exponential linear.

    For any base t > 1, any scale s > 0 and any linear coefficient C, there is an n with C·n < s·t^n.

    This is the refutation of B = s·Δtr in its entirety: Δtr carries t_p^Z with t_p > 1 (measured 1.1458), binding energy is Θ(A), and no choice of s closes that gap. Measured counterpart: at the law's own optimal scale the residual still spans 4.21 decades over the AME2020 table.

    2. The additive observable is extensive by construction #

    log(tr_free / tr_atom) is the bond sum of the canonical A−1 chain. Its growth class is settled by nothing more than the bond energies being bounded.

    source
    def QOU.Hecke.BindingExtensivity.bondSum (epp epn enn : ℝ) (p q : ℕ) :
    ℝ

    The bond-energy sum of the canonical A−1 chain, for Z = p+1 protons and N = q+1 neutrons: p proton-proton bonds, one proton-neutron interface, and q neutron-neutron bonds. Equals log(tr_M(β_free) / tr_M(β_atom)) with epp = -ln b_pp, epn = -ln b_pn, enn = -ln b_nn.

      theorem QOU.Hecke.BindingExtensivity.additive_is_linear_multiplicative_is_not {epp epn enn m M t s : ℝ} (hmpp : m ≤ epp) (hmpn : m ≤ epn) (hmnn : m ≤ enn) (hMpp : epp ≤ M) (hMpn : epn ≤ M) (hMnn : enn ≤ M) (ht : 1 < t) (hs : 0 < s) (C : ℝ) :
      (∀ (p q : ℕ), m * (↑p + ↑q + 1) ≤ bondSum epp epn enn p q ∧ bondSum epp epn enn p q ≤ M * (↑p + ↑q + 1)) ∧ ∃ (n : ℕ), C * ↑n < s * t ^ n

      The two observables sit in different growth classes.

      With A = p + q + 2 nucleons the additive observable is pinned between two lines through the origin, for every (p, q) — that is what "extensive" means. The multiplicative one is bounded by no line at all, at any scale.

      This is §1.2 and §2 of the decision frame, with no nuclear data in it. The two sides are not competing fits of the same shape; they are different shapes, and only one of them can be a binding energy.
