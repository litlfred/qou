    WedderburnDecomp does not characterise H_n(q) — an instance would prove nothing #

    Bean qou-luq7, answered in the negative. Re-verified against the repaired class 2026-08-30 (bean qou-0cyu); see "The repair ... does not close the hole" below.

    The question this module settles #

    QOU.Hecke.WedderburnDecomp has no instance anywhere in the tree, so its consequences are conditional on an uninhabited class — and #print axioms cannot see that. The natural repair is to build an instance, joining Mathlib's Artin–Wedderburn (IsSemisimpleRing.exists_algEquiv_pi_matrix_divisionRing) to the Hecke dimension count.

    That repair would not work, and this module proves why. The class is satisfiable by a one-dimensional algebra at every n. Constructing an instance would therefore establish nothing about H_n(q), whose dimension is n!; it would only silence the audit.

    The mechanism #

    WedderburnDecomp takes [HeckeAlgebra R n q A] as a hypothesis, and QOU.Hecke.InstanceH2.rankOneModel inhabits that class at every n with A = R = ℚ, q = 1, embed := fun _ => 1. PR #4857 found this degeneracy and repaired it for HeckeAlgebra by adding the companion predicate IsHeckeOfFullRank (QOU/Hecke/FullRank.lean), whose whole purpose is to exclude the rank-one model. WedderburnDecomp never picked that companion up, so it inherits the hole through its own hypothesis.

    Every remaining field then goes through on ℚ for structural reasons, not by any dodge: central because ℚ is commutative; idempotent and orthogonal because the family π_λ = if λ = λ₀ then 1 else 0 is supported at one partition; complete because that one value is 1; and block_scaling because the block character χ^λ is itself a free field of the class, so tr_M(x · π_λ) = y_λ · χ^λ(x) constrains only the product y_λ · χ^λ — choose χ^λ to absorb whatever y_λ you picked.

    The repair this module originally asked for has landed, and does not close #

    the hole

    The first version of this file (2026-08-21) named a specific repair: replace the old trace_decomp field — which asserted the summation identity outright — with the block-scaling sentence tr_M(x · π_λ) = y_λ · χ^λ(x), "so that y_λ is pinned and trace_decomp can be deleted rather than assumed".

    That repair landed in PR #5710 (commit 30e5df8938), and it is a real improvement: trace_decomposition is now derived from complete + block_scaling rather than projected out of an axiom, and the pair of theorems weights_inert / weight_one_or_block_trace_zero that the old field forced are gone with it.

    It did not pin y_λ either — and the second repair, in this PR, now does. The #5710 class stored its blocks abstractly, so χ^λ had to come in as a field alongside y_λ, and an equation on their product pins neither factor: rankOneWedderburnScaled realised every nonzero rational as the weight at every partition. That was this module's finding, and the reason it held was the reason the first repair was needed — what the class stored was not enough to compute the block character from, so the character was assumed, and an assumed character absorbs an assumed weight.

    So χ^λ is no longer assumed. The free field is replaced by a block representation ρ_λ : A →ₐ[R] M_{f^λ}(R), with χ^λ := Matrix.trace ∘ ρ_λ defined from it. Being an algebra map, ρ_λ 1 = 1, hence χ^λ(1) = f^λ is forced — and block_scaling at x = 1 then reads tr_M(π_λ) = y_λ · f^λ (WedderburnDecomp.yLambda_determined). The rescaling trick is dead: yLambda_two_not_realisable below shows y_λ = 2 is now impossible at π_λ = 1, where before every nonzero rational was available.

    And the last free field is now gone too (2026-08-30, second tranche). blockDim was an untied natural, so the weight could be any 1/d — a one-parameter family, not all of ℚ, but still not determined. It is no longer a field: QOU.Hecke.blockDim λ = dimHLF λ.parts, the Frame–Robinson–Thrall hook-length dimension, computed from the partition alone. rankOneWedderburnDim cannot be written any more — a witness has no d to choose — and the family collapses onto its d = 1 member. On this carrier the weight is determined: yLambda_forced_one gives y_λ = 1 at the supported partition, for an arbitrary decomposition rather than for a witness.

    And there is no residue: dimHLF λ = #SYT(λ) is Frame–Robinson–Thrall, which this corpus proves sorry-free at general n (QOU.Mathlib.SYTEnum.numSYTenum_eq_dimHLF, the GNW route). blockDim is therefore f^λ as a theorem (QOU.Hecke.blockDim_eq_numSYT), not as an assumed formula. An earlier version of this paragraph called the general theorem open — that was false, taken from a stale header in SYTHookFormulaRows.lean, and both are corrected in the same commit.

    What this module does and does not claim #

    It does not claim WedderburnDecomp is false, or that its fields are wrong. Each field is a true and meaningful sentence about a genuine Wedderburn decomposition. The claim is the weaker, sharper one: the fields do not together pin down the algebra, so inhabiting them is not evidence.

    Scope, per AGENTS.md §"Before declaring refuted": this is a structural exclusion (b), and the invariant cited is a dimension count — Module.finrank ℚ ℚ = 1 against n! ≥ 2 for n ≥ 2. It excludes "an instance of the class as it stands is worth building", not the Wedderburn decomposition itself.

    What would have to change (revised 2026-08-30) #

    Pairing the class with the rank predicate is still necessary:

    variable [HeckeAlgebra R n q A] [IsHeckeOfFullRank R n A] [WedderburnDecomp n q A]

    It is no longer sufficient, and the block-scaling half of the original prescription has been tried. Two things would additionally have to hold:

    1. χ^λ must stop being a free field. It has to be computed — as the trace of a matrix representation ρ_λ : A → M_{f^λ}(R), which is the content the header docstring promises ("the matrix-algebra isomorphisms are captured abstractly") and the class does not carry. Only a χ^λ that is determined by the algebra makes block_scaling an equation about one unknown.
    2. f^λ must be tied to the partition. SpechtDimension is a class with a free dim field and no link to lam; the hook-length formula is stated in its docstring and encoded nowhere. Without it there is no dimension count to contradict, which is why the exclusion below has to be argued from Module.finrank ℚ ℚ rather than from anything the class says.

    Both are Mathas (1999) Theorem 3.43 — the seminormal form and its indexing by Partition n — and neither is in Mathlib.

          This is what closes qou-luq7. The morning's version of this file exhibited rankOneWedderburnDim n d, an instance with y_λ = 1/d for every d ≥ 1, and recorded that one-parameter family as the freedom surviving item 1. That definition can no longer be written: blockDim is not a field, so a witness cannot choose d, and rho must land in M_{f^λ}(ℚ) with f^λ computed from λ. The family collapses to its d = 1 member, which is rankOneWedderburn.

          So on this carrier y_λ is not merely constrained, it is determined.
