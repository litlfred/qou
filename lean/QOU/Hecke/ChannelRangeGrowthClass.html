    theorem QOU.Hecke.ChannelRangeGrowthClass.geometric_partial_sum_le {c x : ℝ} (hc : 0 ≤ c) (hx0 : 0 ≤ x) (hx1 : x < 1) (K : ℕ) :
    ∑ k ∈ Finset.range K, c * x ^ k ≤ c / (1 - x)

    A geometric shell sum is bounded independently of how many shells are taken, exactly when the decay beats the growth ratio. This is what "extensive" means here: a per-site bound that does not grow with the system.

    theorem QOU.Hecke.ChannelRangeGrowthClass.tree_threshold_iff {d μ : ℝ} (hd : 1 < d) :
    (d - 1) * Real.exp (-μ) < 1 ↔ Real.log (d - 1) < μ

    The tree criterion. For a bounded-degree graph the shell at distance k holds at most d(d-1)^{k-1} sites, so a Yukawa weight exp(-μk) gives a bounded per-site sum exactly when μ > log(d-1).

    This is the WORST case (a tree). A nuclear packing has polynomial shell growth and needs no such threshold — see the module docstring.

    theorem QOU.Hecke.ChannelRangeGrowthClass.massless_pair_sum (n : ℕ) :
    ↑n * (↑n - 1) / 2 * Real.exp (-0) = ↑n * (↑n - 1) / 2

    At zero decay every pair contributes fully. A massless mediator weights all n(n-1)/2 pairs by exp(0) = 1.

    theorem QOU.Hecke.ChannelRangeGrowthClass.no_linear_bound_on_pairs (C : ℝ) :
    ∃ (n : ℝ), 2 < n ∧ C * n < n * (n - 1) / 2

    And that is a different growth class from any extensive law. No constant multiple of n bounds the pair count, so a massless channel cannot be represented by a bounded per-site sum however the bond letters are chosen.

    theorem QOU.Hecke.ChannelRangeGrowthClass.rate_sum_pinned {bpp bnn t : ℝ} (hpp : 0 < bpp) (hnn : 0 < bnn) (ht : 0 < t) (h : bpp * bnn = 1 / t ^ 2) :
    -Real.log bpp + -Real.log bnn = 2 * Real.log t

    The p-p and n-n decay rates sum to a constant. Given the pinned product b_pp·b_nn = 1/t² (here t = [2]_q), the two rates L = -log b satisfy L_pp + L_nn = 2 log t. Three rates, one constraint, one free parameter.
