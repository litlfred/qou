      noncomputable def QOU.Hecke.MarkovCrossingReversal.markovReversal {R : Type u_1} [Field R] (h z : R) :
      R

      The Markov trace of the k = 2 crossing reversal, at Markov parameter z.

      Derivation, using nothing but tr(1) = 1 and tr(σ) = z: σ² - σ⁻² = h·(σ + σ⁻¹) (CrossingReversalParity.reversal_two) and σ + σ⁻¹ = 2σ - h (inv_eq), so the element is 2hσ - h² and its trace is 2hz - h².
