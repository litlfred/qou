      theorem QOU.Hecke.LayoutConflict.adjacent_pair_unique {p q C D x y : ℕ} (hgap : p + C ≤ q) (hx : x ∈ block p C) (hy : y ∈ block q D) (hadj : y = x + 1) :
      x = p + C - 1 ∧ y = q

      The whole obstruction. If a block ends strictly below where the next one starts, the only way a member of the first is adjacent to a member of the second is at the single boundary pair: the top of the lower block and the bottom of the upper one.

      Two disjoint intervals on a line touch once. Everything else in this file is a specialisation.

      The canonical 3k layout #

      atom_braid_word_3A puts nucleon k at {3k, 3k+1, 3k+2}. Consecutive nucleons are then consecutive blocks with no gap, so the lemma applies with p = 3k, C = 3, q = 3(k+1).

      A coupling across an interface is determined by its LOWER endpoint — the upper one is forced to be +1 — so everything below is stated in terms of that single natural number, which keeps Fin numerals and Prod out of the proofs.

          theorem QOU.Hecke.LayoutConflict.contiguous_layout_cannot_carry_a_colour_tube {C : ℕ} (hC : 2 ≤ C) {k : ℕ} (x : Fin C → ℕ) (hx : ∀ (i : Fin C), IsCoupling k (x i)) (hinj : Function.Injective x) :
          False

          A colour tube needs C distinct couplings across one interface. For C ≥ 2 that is strictly more than the layout admits, so no contiguous layout carries a colour tube — for any number of colours above one, hence in particular for three.
