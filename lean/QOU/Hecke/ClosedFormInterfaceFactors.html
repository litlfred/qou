    §1. The primary parameters in the square-root variable s (q = s²) #

    source
    def QOU.Hecke.ClosedForm.markovZ {R : Type u} [Field R] (s : R) :
    R

    Markov parameter in convention D, z_D = q³/(q²+1), written in the square-root variable s (q = s²) as s⁶/(s⁴+1).

    Migrated from convention C 2026-08-26 (bean qou-cxjq). This read s/(s²+1), which at q = s² is √q/(q+1) — convention C. This file's docstring is where the whole bean started: it states the s-substitution in plain English, and every detector missed it because the convention was hidden by a change of variable rather than a change of form.

    The s apparatus is now VESTIGIAL, and that is the follow-up this commit does not do. The entire reason for s was to express √q without Real.sqrt, so the file could stay on the substrate side of the AGENTS.md §7c wall. Convention D has no square root in it at all — q³/(q²+1) is rational in q directly — so the substitution buys nothing here any more, and s⁶/(s⁴+1) is strictly uglier than the q form it encodes. Rewriting the file in q is the right cleanup and is a separate, larger change across 22 theorems; doing it in the same commit as the convention migration would make both unreviewable.

    Migrated in place because this module has zero importers — verified by module import, not by name grep — so no recorded statement outside it changes meaning.

                    §3a. Under convention D the bar weight is a shift, and the strict #

                    average is bar-invariant

                    source
                    theorem QOU.Hecke.ClosedForm.markovZ_weight_eq_shift {R : Type u} [Field R] (s : R) (hs : s ≠ 0) (h4 : s ^ 4 + 1 ≠ 0) :
                    markovZ s / (s ^ 2) ^ 4 = markovZ s - heckeH s

                    The weight-−4 scaling and the −h shift are the same map.

                    z/q⁴ = z − h is an identity of convention D, not a coincidence at one point:

                    z/q⁴ = q³/(q⁴(q²+1)) = 1/(q(q²+1)), z − h = q³/(q²+1) − (q²−1)/q = (q⁴ − (q⁴−1))/(q(q²+1)) = 1/(q(q²+1)).

                    This is the fact that reconciles markovZ_bar_weight ("bar scales z by q⁻⁴") with QOU.MassTheory.barZ ("bar sends z to z − h"): the two statements are the same statement. Reading the weight as a mere rescaling — one that leaves an h uncancelled — is what makes the strict average look bar-broken under D when it is not.
