    When is Coxeter length additive? #

    QOU.Hecke.PermLength proves that the Coxeter length of a permutation is its inversion count (length_eq_invCount). This file turns that into an exact criterion for when length is additive along a product.

    Mathlib has subadditivity (CoxeterSystem.length_mul_le) but no equality criterion, so length_mul_eq_add_iff below fills a genuine gap.

    The counting identity #

    Write Inv w for the inversion set. For a pair p = (a, b) with a < b put

    • A — "v inverts p", i.e. v b < v a;
    • B — "u * v inverts p", i.e. u (v b) < u (v a).

    Sorting the pair (v a, v b) gives a bijection vPair v of the strictly ordered pairs, and the point of the whole file is that

    vPair v p ∈ Inv u ↔ A xor B.

    Counting the four classes A ∧ B, A ∧ ¬B, ¬A ∧ B, ¬A ∧ ¬B then gives

    ℓ(u) + ℓ(v) = ℓ(u * v) + 2 · #{p ∈ Inv v : p ∉ Inv (u * v)},

    so length is additive exactly when u undoes none of v's inversions — that is, exactly when Inv v ⊆ Inv (u * v).

          The criterion #

          source
          theorem QOU.Hecke.Inversions.length_mul_eq_add_iff {n : ℕ} (u v : Equiv.Perm (Fin (n + 1))) :
          (SymmetricCoxeter.permCoxeterSystem n).length (u * v) = (SymmetricCoxeter.permCoxeterSystem n).length u + (SymmetricCoxeter.permCoxeterSystem n).length v ↔ invSet v ⊆ invSet (u * v)

          Length is additive exactly when no inversion is undone.

          ℓ(u * v) = ℓ(u) + ℓ(v) holds iff every pair inverted by v is still inverted by u * v.

          Non-vacuity #

          The criterion is an honest iff: both sides genuinely occur. s₀ * s₀ = 1 collapses, so additivity fails and the subset criterion is false; s₀ * s₁ is reduced, so it holds.
