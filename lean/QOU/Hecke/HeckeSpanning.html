    QOU.Hecke.HeckeSpanning — H_{n+1}(q) = Σ_k incl(H_n(q)) · c_k #

    Third brick of the type-A spanning argument (bean qou-twwf). QOU.Hecke.HeckeStaircase proved the four ways a generator interacts with a descending run; this file assembles them into the tower decomposition.

    What is proved #

    • towerSpan — the submodule Σ_{k ≤ n+1} incl(H_n(q)) · c_k.
    • towerSpan_mul_gen — it is closed under right multiplication by every generator.
    • towerSpan_eq_top — hence it is everything.

    The case analysis #

    The foot of c_k = σ_n ⋯ σ_{n+1-k} is σ_{n+1-k}, and the four cases are decided by where i sits relative to it. Order matters: the fold case is tested first, because at the full run k = n+1 truncated subtraction collapses "one below the foot" onto the foot itself, and reading that as the extend case would ask for c_{n+2}, which is off the end of the tower.
