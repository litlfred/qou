    Hecke generators and braid / Hecke relations #

    For n ≥ 1, the Iwahori–Hecke algebra H_n(q) is generated over a base ring R by σ_1, ..., σ_{n-1} subject to:

    (H1) Hecke quadratic: σ_i² = (q - q⁻¹) σ_i + 1 (H2) Braid: σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1} (H3) Far-commutativity: σ_i σ_j = σ_j σ_i if |i - j| ≥ 2

    This file provides the abstract generator type and relation predicates. The full algebra (quotient of free algebra by these relations) lives in Algebra.lean.

    References #

    • [prop:braiding-eigenvalue-extraction]
    • Kassel (1995), Quantum Groups, §XII.1

    structure QOU.Hecke.Generator (n : ℕ) :
    Type

    A Hecke generator at index i for an algebra of strand count n. The condition 1 ≤ i ≤ n - 1 is encoded via Fin (n - 1).

    • idx : Fin (n - 1)

      Generator index, 0-based; corresponds to σ_{idx+1} in the literature's 1-based convention.

            def QOU.Hecke.HeckeQuadratic {R : Type u} {n : ℕ} (q : R) [CommRing R] [Inv R] {A : Type u} [Ring A] [Algebra R A] (embed : Generator n → A) :
            Prop

            Hecke relation predicate (H1): σ_i² = (q - q⁻¹) σ_i + 1 in any algebra A over R with σ_i interpreted via embed.

            We require [Inv R] so that q⁻¹ elaborates; mathematical well-posedness additionally needs q to be a unit, which downstream HeckeAlgebra instances enforce by working over a field or by providing a unit witness.

            Equations
