    QOU.Hecke.IwahoriHecke — the Iwahori–Hecke algebra H_n(q) #

    Mathlib has Coxeter groups but no Hecke algebra; this file supplies the construction (track 2 of the Hecke-semisimplicity attack, epic qou-hnhg, bean qou-w8hn).

    The type-A_n Iwahori–Hecke algebra H_{n+1}(q) is the free K-algebra on n generators σ₀, …, σ_{n-1} modulo the standard relations (Kassel–Turaev; the QOU Hecke–skein convention, AGENTS.md §7a):

    • quadratic σ_i² = (q - 1)·σ_i + q (i.e. (σ_i - q)(σ_i + 1) = 0);
    • braid σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1};
    • commutation σ_i σ_j = σ_j σ_i for |i - j| ≥ 2.

    It is realised as a RingQuot of FreeAlgebra K (Fin n), so it is an associative unital K-algebra by construction, and the generator relations hold in it (proved below). The standard n!-dimensional T_w-basis theorem (Bott–Samelson) is deliberately not claimed here — it is a separate, deep brick (qou-lrz1).

    inductive QOU.Hecke.HeckeRel (K : Type u_1) [CommRing K] (q : K) (n : ℕ) :
    FreeAlgebra K (Fin n) → FreeAlgebra K (Fin n) → Prop

    The defining relations of the type-A Iwahori–Hecke algebra on n generators, as a RingQuot relation on FreeAlgebra K (Fin n).

    • quadratic {K : Type u_1} [CommRing K] {q : K} {n : ℕ} (i : Fin n) : HeckeRel K q n (FreeAlgebra.ι K i * FreeAlgebra.ι K i) ((q - 1) • FreeAlgebra.ι K i + q • 1)

      σ_i² = (q - 1)·σ_i + q.

    • braid {K : Type u_1} [CommRing K] {q : K} {n : ℕ} (i : Fin n) (hi : ↑i + 1 < n) : HeckeRel K q n (FreeAlgebra.ι K i * FreeAlgebra.ι K ⟨↑i + 1, hi⟩ * FreeAlgebra.ι K i) (FreeAlgebra.ι K ⟨↑i + 1, hi⟩ * FreeAlgebra.ι K i * FreeAlgebra.ι K ⟨↑i + 1, hi⟩)

      σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1}.

    • commute {K : Type u_1} [CommRing K] {q : K} {n : ℕ} (i j : Fin n) (h : ↑j + 2 ≤ ↑i) : HeckeRel K q n (FreeAlgebra.ι K i * FreeAlgebra.ι K j) (FreeAlgebra.ι K j * FreeAlgebra.ι K i)

      σ_i σ_j = σ_j σ_i for |i - j| ≥ 2 (stated for j + 2 ≤ i; the generated congruence is symmetric).
