    QOU.Hecke.H2GramArithmetic — the n=2 Gram determinant, arithmetic core #

    The smallest Iwahori–Hecke algebra H_2(q) (one generator σ, σ² = (q-1)σ + q) is 2-dimensional with basis {1, σ} — it is AdjoinRoot(X² - (q-1)X - q), the monogenic algebra on the quadratic Hecke relation. Its regular trace form Gram determinant equals the discriminant of that quadratic, and this file proves — sorry-free over a field — the arithmetic identity behind the Wenzl criterion at n = 2:

    disc = (q-1)² + 4q = (q+1)² = [2]_q², and H_2(q) semisimple ⟺ disc ≠ 0 ⟺ q ≠ -1 ⟺ [2]_q! ≠ 0.

    So det(Gram) = [2]_q² ≠ 0 ⟺ [2]_q! ≠ 0 — the n = 2 instance of the Schur/Poincaré identity det(Gram) = [n]_q! (up to a unit). The Gram entries here (tr(1) = 2, tr(σ) = q-1, tr(σ²) = q²+1) are asserted as the companion-matrix traces; the companion sibling QOU.Hecke.H2CompanionRep (brick qou-eedq) derives them from the regular representation σ ↦ !![0, q; 1, q-1], proving that matrix satisfies the Hecke relation and that its trace-form Gram equals h2GramMatrix below — so det = [2]_q² rests on the representation, not on hand-read traces.

    def QOU.Hecke.h2GramMatrix {K : Type u_1} [Field K] (q : K) :
    Matrix (Fin 2) (Fin 2) K

    The H_2(q) regular-trace Gram matrix in the basis {1, σ}. Entries are the observable traces tr(L_{eᵢ eⱼ}): tr(1) = 2, tr(σ) = q-1 (companion-matrix trace of σ² = (q-1)σ + q), tr(σ²) = tr((q-1)σ + q·1) = (q-1)² + 2q = q²+1. Taking the trace is the observation step — the Gram is a matrix of observable results.
