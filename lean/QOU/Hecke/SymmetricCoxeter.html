    QOU.Hecke.SymmetricCoxeter — S_{n+1} and the type-Aₙ Coxeter group #

    The first brick of the T_w basis programme (beans qou-lrz1 / qou-twwf). The T_w basis of H_n(q) is what det(Gram) must be stated against, and it is the standing Mathlib gap behind the WenzlCriterion / SchurElementCriterion discharge.

    What the standing audits say, and what is actually true #

    The 2026-08-21 TL_n scoping audit lists as build item 1 "S_n as a Coxeter group of type A — absent", and AGENTS.md records "Equiv.Perm has no length/inversions". Measured against current Mathlib, that is stale in one direction and accurate in the other:

    • Present. CoxeterMatrix.Aₙ, the whole CoxeterSystem API (Mathlib/GroupTheory/Coxeter/{Basic,Length,Inversion,Matrix}.lean) including length, and — decisively for surjectivity — Equiv.Perm.mclosure_swap_castSucc_succ.
    • Absent. Any connection between Equiv.Perm and CoxeterMatrix.Aₙ. A grep for Equiv.Perm across GroupTheory/Coxeter/ returns nothing.

    So the gap is not the Coxeter theory; it is the bridge. This file builds the surjective half of that bridge.

    What is proved here (sorry-free, all general n) #

    • swap_braid_pow_three / swap_disjoint_pow_two — the two transposition identities, over any DecidableEq type.
    • s n i — the i-th adjacent transposition of S_{n+1}.
    • s_rel — the adjacent transpositions satisfy every type-Aₙ Coxeter relation, all three cases (i = j, adjacent, distant) against the actual CoxeterMatrix.Aₙ entries.
    • toPerm : (Aₙ n).Group →* Equiv.Perm (Fin (n+1)) — the induced map, with toPerm_simple.
    • toPerm_surjective — surjective, via Mathlib's Equiv.Perm.mclosure_swap_castSucc_succ.
    • incl — the parabolic inclusion W(Aₙ) →* W(A_{n+1}).
    • An ℕ-indexed generator layer (gen) with all three relation families restated arithmetically: gen_mul_self, gen_comm, gen_braid. These are the working form for the order-bound induction, whose index side conditions are arithmetic rather than Fin-shaped.

    The bridge is COMPLETE #

    permCoxeterSystem n : CoxeterSystem (Aₙ n) (Equiv.Perm (Fin (n+1))), together with the IsCoxeterGroup (Equiv.Perm (Fin (n+1))) instance. S_{n+1} is the Coxeter group of type Aₙ, formalized.

    The route, in order:

    1. s_rel — the adjacent transpositions satisfy every type-Aₙ relation, so toPerm : (Aₙ n).Group →* S_{n+1} exists.
    2. toPerm_surjective — via Equiv.Perm.mclosure_swap_castSucc_succ.
    3. inCosets_all — every element of W(Aₙ (n+1)) lies in one of n+2 parabolic cosets H · t_k, by simple_induction_right over the four closure cases.
    4. cover_surjective, finiteAn, card_An_le — the cover becomes a surjection W(Aₙ n) × Fin (n+2) ↠ W(Aₙ (n+1)), giving finiteness from the trivial W(Aₙ 0) and the bound |W(Aₙ n)| ≤ (n+1)!.
    5. toPerm_bijective — (n+1)! ≥ |W(Aₙ n)| ≥ |S_{n+1}| = (n+1)! squeezes, so the surjection is a bijection.

    Mathlib does not have this. Measured before starting: the only CoxeterSystem values in all of Mathlib are the tautological CoxeterMatrix.toCoxeterSystem (the system on the presented group itself) and CoxeterSystem.map (transport along an existing MulEquiv), and there are zero IsCoxeterGroup instances — the whole theory (length, inversions, exchange) with no concrete group ever plugged in. This file plugs the first one in, which means cs.length and all of Coxeter/Length.lean and Coxeter/Inversion.lean now apply to Equiv.Perm. That is exactly the length theory AGENTS.md records as missing, and it is what T_w well-definedness rests on (beans qou-lrz1 / qou-twwf).

            Descending runs and the four coset-closure cases #

            The order bound is |W(Aₙ N)| ≤ (N+1)·|W(Aₙ (N-1))|, obtained by showing that the union of the N+1 cosets H · t_k — where H is the parabolic incl image and t_k = σ_{N-1} ⋯ σ_k — is closed under right multiplication by every generator, hence is all of W.

            Closure splits into exactly four cases by the position of i relative to k, all four of which are proved below:

            case lemma mechanism
            i = k t_mul_gen_self σ_k² = 1
            i = k-1 t_mul_gen_pred the run extends: it is t_{k-1}
            i + 1 < k t_comm distant generators commute past every factor
            k < i t_push t_k σ_i = σ_{i-1} t_k, by induction on i - k with a braid base

            t_push is the only one with real content: the base case i = k+1 peels the run twice and combines the braid relation with t_comm, and the step case commutes σ_k past σ_i and applies the inductive hypothesis one rung up.

              The parabolic coset cover #

              inCosets_all is the structural heart of the order bound: every element of W(Aₙ (n+1)) lies in one of the n+2 cosets H · t_k, where H is the incl-image parabolic. It is proved by CoxeterSystem.simple_induction_right, whose inductive step is exactly inCosets_mul_gen — which in turn is where the four closure cases above are consumed, one per branch of a trichotomy on i vs k.

              What this does not yet do is turn the cover into a cardinality statement. That needs the surjection (Aₙ n).Group × Fin (n+2) → (Aₙ (n+1)).Group, a finiteness induction anchored at the trivial W(Aₙ 0), and then the comparison against |S_{n+1}| = (n+1)!.

                The order bound, and the Coxeter system #
