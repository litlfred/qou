    theorem QOU.Hecke.CrossingReversalParity.inv_quad {R : Type u_1} [Ring R] (σ σinv h : R) (hcen : ∀ (x : R), h * x = x * h) (hq : σ ^ 2 = h * σ + 1) (hl : σinv * σ = 1) :
    σinv ^ 2 = 1 - h * σinv

    The conjugate quadratic: the mirror generator satisfies σ⁻² = 1 - hσ⁻¹. This is what lets every power of σ⁻¹ be reduced without any binomial expansion, and it is where the alternating sign that produces the parity comes from.

    theorem QOU.Hecke.CrossingReversalParity.resolvent_sq {R : Type u_1} [Ring R] (σ σinv h : R) (hcen : ∀ (x : R), h * x = x * h) (hq : σ ^ 2 = h * σ + 1) (hl : σinv * σ = 1) :
    (σ + σinv) ^ 2 = h ^ 2 + 4

    The invariant. The resolvent u = σ + σ⁻¹ squares to the central scalar h² + 4. This is what makes the parity work: every even power of u is central, every odd one carries σ.

    theorem QOU.Hecke.CrossingReversalParity.reversal_two {R : Type u_1} [Ring R] (σ σinv h : R) (hcen : ∀ (x : R), h * x = x * h) (hq : σ ^ 2 = h * σ + 1) (hl : σinv * σ = 1) :
    σ ^ 2 - σinv ^ 2 = h * (σ + σinv)

    k = 2 is NOT central: the square reversal is h·u, and u = σ + σ⁻¹ carries σ. Contrast σ³ − σ⁻³ = h(h² + 3).

    theorem QOU.Hecke.CrossingReversalParity.reversal_two_forces_resolvent_central {R : Type u_1} [Ring R] (σ σinv h : R) (hcen : ∀ (x : R), h * x = x * h) (hq : σ ^ 2 = h * σ + 1) (hl : σinv * σ = 1) (hinv : R) (hhinv : hinv * h = 1) (z : R) (hz : σ ^ 2 - σinv ^ 2 = z) :
    σ + σinv = hinv * z

    The obstruction. If the k = 2 reversal equals an element z, then h·u = z. So when h is invertible, a central value at k = 2 forces the resolvent u = σ + σ⁻¹ — hence σ itself — to be central. In H_n(q) with n ≥ 3 the generators do not commute, so σ is not central and the square reversal is not a scalar. This is what the k = 2 route into δ has to get past, and it is the step conj:flavor-split-habiro-derivation does not supply.

    theorem QOU.Hecke.CrossingReversalParity.reversal_four {R : Type u_1} [Ring R] (σ σinv h : R) (hcen : ∀ (x : R), h * x = x * h) (hq : σ ^ 2 = h * σ + 1) (hl : σinv * σ = 1) :

    k = 4 has the same shape — h(h²+2)·u, still carrying σ. So the failure at k = 2 is parity, not a small-exponent accident.

    The recursion the parity rides on #

    theorem QOU.Hecke.CrossingReversalParity.reversal_rec {R : Type u_1} [Ring R] (σ σinv h : R) (hcen : ∀ (x : R), h * x = x * h) (hq : σ ^ 2 = h * σ + 1) (hl : σinv * σ = 1) (k : ℕ) :
    σ ^ (k + 2) - σinv ^ (k + 2) = (σ + σinv) * (σ ^ (k + 1) - σinv ^ (k + 1)) - (σ ^ k - σinv ^ k)

    D_{k+2} = u·D_{k+1} − D_k with u = σ + σ⁻¹. Together with resolvent_sq (u² = h² + 4 central) this is the general mechanism: D_k is h times a Chebyshev polynomial in u of degree k−1, carrying only powers of u congruent to k−1 mod 2. The general-k conclusion is not formalised here — see the probe named in the header.

    The archimedean specialisation: the two channel values, and their signs #

    §7c: this section — and only this section — is over ℝ, because it uses the ordering (1 < q). Everything above is generic.

    The point — corrected 2026-09-13; see the 🛑 retraction in the file header. These are statements about the two one-dimensional representations of the Hecke algebra, σ ↦ q (symmetric, trivial) and σ ↦ −q⁻¹ (alternating, sign), and that is all they have ever been. The k = 2 reversal evaluates on them to exact negatives (alternating_eq_neg_symmetric), so the symmetric one is positive and the alternating one negative for every q > 1.

    They are not a claim about what conj:flavor-split-habiro-derivation asserts. An earlier version of this paragraph read the block's "the weak interaction is strictly left-handed, so it projects onto the fully alternating channel of H₄" as its channel choice for the flavour split. It is the block's channel choice for the residual, the 0.128 % refinement, not for the baseline. Retracted in full in the header.

    Where these two theorems are actually used. splits_sum_zero is what makes the equal-weight symmetric/alternating channel average vanish identically, given the corpus's own w_sym = w_alt = q²/(q⁴+4q²+1) (docs/audits/2026-06-17-hecke-channel-chirality-binding.md). That excludes the averaged reading of the split — scope (b), invariant = the weight equality plus the exact negation — and is stated as MarkovCrossingReversal.channelAverage_eq_zero'.

    The identification is still mine, not the block's. That δ's numerator is the k = 2 crossing reversal is a reading; the block calls (q−1)²(1−q⁻⁴)/3 "a structured near-match, not a derived closed form". What changed is that the reading now has a trace behind it rather than a channel: tr_z(σ²−σ⁻²) = 2hz − h² reproduces that expression exactly at the augmentation z = q (MarkovCrossingReversal.baselineX_eq_augmentation_trace).
