    QOU.Hecke.H3Wedderburn — dim H_3(q) = 3! via the Wedderburn/hook route #

    Bricks qou-lrz1 + qou-0y6h at n = 3 (the Wedderburn side, companion to H2AlgebraDimension's monogenic n=2 route).

    At a Wenzl-generic parameter the Iwahori–Hecke algebra H_3(q) is semisimple, so it Wedderburn-decomposes as a product of matrix algebras indexed by the partitions λ ⊢ 3:

    H_3(q) ≅ M_{f^{(3)}} ⊕ M_{f^{(21)}} ⊕ M_{f^{(111)}},

    where f^λ is the number of standard Young tableaux of shape λ — given by the Frame–Robinson–Thrall hook-length formula f^λ = |λ|! / ∏_x h(x), computed here on the concrete Partition.hookLength (QPartitionCombinatorics, the same hook data WenzlSchurElement.schurElement uses). Its dimension is therefore Σ_λ (f^λ)², and this file proves — sorry-free by decide on the concrete hook lengths — that this equals 3! = 6, the n = 3 instance of dim H_n(q) = n! (qou-lrz1).

    General n (RSK bijection Σ_λ (f^λ)² = n!) is a genuine Mathlib gap: there is no StandardYoungTableau count and no Robinson–Schensted correspondence in Mathlib. The concrete small cases are the honest anchors.
