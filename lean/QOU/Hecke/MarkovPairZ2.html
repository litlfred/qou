    QOU.Hecke.MarkovPairZ2 — All-pairs Markov-trace identity #

    For adjacent generators σ_i, σ_j with |i - j| = 1, the Markov trace satisfies

    tr_M(σ_i · σ_j) = z²

    where z is the Markov parameter 1/(v + v⁻¹) (with v² = q the formal square root of the substrate parameter). This follows from two applications of the Markov property:

    tr_M(σ_i σ_j) = z · tr_M(σ_i) (peel σ_j) = z · z = z².

    The identity is the depth-2 cap of the all-pairs jet-tower formula in prop:mass-endomorphism-tower — pairs are the largest |S| at which the Markov property preserves closure (forward-derivation §A Step 17).

    Pre-Archimedean (formal-chain) version. Polymorphic in the ground ring R_q = ℤ[q^±1]. Conditional on a MarkovTraceAxioms instance.

    Parallel formalisations. This chain-list version coexists with the algebra-level version in Hecke/MarkovTrace.lean (theorem QOU.Hecke.MarkovTrace.trace_pair, currently a sorry) and the heavier Interactions/MarkovPeel.lean (class MarkovTrace with peeling axioms). The chain-list version is the lightweight form used by the audit's downstream consumers; the algebra-level version is the full-Hecke-algebra statement.

    theorem QOU.Hecke.markov_pair_z2 {z : R_q} [inst : MarkovTraceAxioms z] (i j : ℕ) (hi : { index := i, a := 1, b := 0 }.a = 1) (hi₀ : { index := i, a := 1, b := 0 }.b = 0) (hj : { index := j, a := 1, b := 0 }.a = 1) (hj₀ : { index := j, a := 1, b := 0 }.b = 0) :
    MarkovTraceAxioms.trace z [{ index := i, a := 1, b := 0 }, { index := j, a := 1, b := 0 }] = z * z

    All-pairs Markov-trace identity (depth-2 cap).

    For an adjacent pair of "trivial" generator chains (each chain is σ_i · 1 + 0, i.e. the bare braid generator at index i), each vertexVolume equals z, so the pair's trace is z².
