    The general-A bond product, in the shape the binding arc quotes #

    QOU/Hecke/MarkovBondFactor.lean proves the one-bond factor tr_M(c·σ_i + d) = c·z + d and the two-bond (A = 3) case, and records the general-A case as an open gap: "the general A-bond factorization tr_M(∏_k (c_k • σ_{i_k} + d_k)) = ∏_k (c_k·z + d_k) for pairwise-distant generators needs the cross-level Markov axiom (or a word-induction principle) that the class does not yet carry."

    QOU/Hecke/MarkovInteriorBond.lean supplies that word-induction principle (tr_bondWord_of_interiorMarkov) conditionally on InteriorMarkov, and QOU/Hecke/InteriorMarkovOfBraidedTower.lean discharges InteriorMarkov on every BraidedTower. What is missing between the two is only a shape: the bond-word theorem is stated for a chain carrying blocks between the bonds, and the gap above is quoted for the bare product of bond letters. This file closes that shape gap:

    • pureChain — the chain of bonds g₀ < g₁ < ⋯ with every intervening block equal to 1;
    • tr_pureBondChain_of_interiorMarkov — tr (∏_k (σ_{g_k} + d_k)) = ∏_k (z + d_k) conditionally on InteriorMarkov;
    • tr_pureBondChain_of_braided — the same on every braided tower, with no hypothesis beyond the Iwahori–Hecke relations and the Markov axioms.

    Scope — read before quoting this as "the gap is closed" #

    Three limits, each of which matters and none of which this file removes.

    1. The coefficient is 1, not a general c_k. The letter here is σ_g + d • 1, so this proves ∏_k (z + d_k), not ∏_k (c_k·z + d_k). c_k • σ + d_k is c_k • (σ + (d_k/c_k) • 1) only when c_k is invertible, and the ambient ring is a bare CommRing. This is not a restriction on the corpus's bonds: all three production bond types carry c = 1 (f_pp = z at (c,d) = (1,0), f_nn = z − h at (1,−h), f_pn = z − h(½ − δ/4) at (1, −h(½−δ/4))), as MarkovBondFactor's own docstring lists them.

    2. This is a different class from MarkovBondFactor's. That module's QOU.Hecke.MarkovTrace n q A is a fixed-level, single-algebra class: one n, one A, one trace, no filtration. It cannot state the interior hypothesis — "a below the bond and b above it" has no meaning without a filtration — which is exactly why its header calls the axiom one "the class does not yet carry". The theorem below lives in the tower vocabulary (MarkovTower / OcneanuTrace.MarkovTrace), which has the filtration. So the mathematics of the general-A gap is settled; transporting it into MarkovBondFactor's own class is a separate bridge and is not done here.

    3. A braided tower is not yet the production trace. The production Ocneanu trace of H_n(q) at z = q³/(q²+1) is constructed and proved unique as a SchurWeyl.HeckeCoset.MarkovTraceFamily; nothing in the tree packages that family as an OcneanuTrace.MarkovTrace carrying a BraidedTower instance (bean qou-gr3t, remaining item; qou-0fmb). The two BraidedTower instances the corpus does carry are the presented Hecke tower heckeTowerMarkovTrace (which factors through the rank-2 quotient and is not faithful) and the symmetric-group tower.

    Generic R, A; no ℝ.
