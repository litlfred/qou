    QOU.Hecke.IwahoriHeckeRankOne — the uniform family, identified at its smallest rank #

    QOU.Hecke.IwahoriHecke builds H_{n+1}(q) for general n as a RingQuot of a free algebra. Until this file it was orphaned: no other module in the tree imported it, nothing consumed it, and no declaration anywhere related it to the concrete rank objects (H2 R q, H3A, H4A) on which the corpus's actual semisimplicity theorems live. Those three are three unrelated carrier types, so the proved rank ladder and the uniform family had no point of contact at all.

    This file supplies the first one, at the smallest rank. At n = 1 the braid and commutation relations are vacuous (braid needs i + 1 < 1 and commute needs j + 2 ≤ i, both uninhabited over Fin 1), so only the quadratic survives and the algebra should be K[X]/(X² - (q-1)X - q). We prove the forward half of that identification.

    What is proved here (sorry-free, generic [CommRing K] per §7c) #

    • root_quad — the AdjoinRoot generator satisfies the Hecke quadratic in the exact smul form the HeckeRel constructor uses.
    • fwd — the algebra map IwahoriHecke K q 1 →ₐ[K] AdjoinRoot (X²-(q-1)X-q).
    • fwd_sigma — it sends the Hecke generator σ₀ to root, so it is not the zero-information map.

    The rank-1 identification, proved #

    rankOneEquiv : IwahoriHecke K q 1 ≃ₐ[K] AdjoinRoot (X² - (q-1)X - q), together with commute_rankOne — so the rank-1 member of the uniform family is H₂(q), and it is commutative. Semisimplicity now transports along rankOneEquiv from any AdjoinRoot-side statement.

    A retraction worth reading before you trust an API-level "blocked" #

    The first version of this file stopped at the forward map and recorded the inverse as blocked on a Mathlib gap: AdjoinRoot.liftHom requires a commutative target, IwahoriHecke K q 1 carries only Ring, RingQuot inherits CommRing solely from a CommRing base, and Mathlib has no CommRing (FreeAlgebra K (Fin 1)). Every one of those statements is true, and the conclusion drawn from them was wrong.

    AdjoinRoot.liftHom is not the only way out of an AdjoinRoot. Mathlib carries Polynomial.eval₂AlgHom', which evaluates into a noncommutative algebra given only that the scalars commute with the chosen element — supplied here by Algebra.commutes — and Ideal.Quotient.liftₐ, which descends it through the quotient. Composing the two builds the inverse with no commutativity hypothesis anywhere. Commutativity of IwahoriHecke K q 1 then falls out as a corollary of the isomorphism rather than being a prerequisite for it.

    The lesson is the one AGENTS.md states for durable refutations: "this construction, via this API, does not go through" is a scope-(a) negative about a route. It is not a structural exclusion, and it must not be written down as one. No invariant forbade the inverse; only the obvious lemma did not apply.

    What this still does NOT do #

    This file does not, and cannot, discharge WenzlCriterion. The consumer QOU.Information.PNeqNpEquivalence.counting_faithfulness_of_one_lt instantiates the cited layer's semisimple parameter at (∀ n, ss n) — every rank — and Jaeger–Vertigan–Welsh genuinely needs unbounded rank, since the #P-hard link family has unboundedly many strands. No finite collection of proved ranks entails a ∀ n statement. See docs/audits/2026-08-29-pneqnp-gap-inventory-refresh.md.
