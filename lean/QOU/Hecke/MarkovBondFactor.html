    An inter-nucleon bond in the atom braid is a bridge crossing c • σ_i + d • 1 (p-p: (1, 0); n-n: (1, −h); p-n: (1, −h(½−δ/4))). Its Markov-trace value is the conditional expectation of the crossing:

    tr_M(c • σ_i + d • 1) = c · z + d (one bond)

    and for two bridge crossings at generators i < j the trace factorizes over bonds:

    tr_M((c₁ • σ_i + d₁) · (c₂ • σ_j + d₂)) = (c₁·z + d₁) · (c₂·z + d₂)

    This is the fibre-level (generic CommRing R, formal q — per AGENTS.md §7c no archimedean structure) backbone of the per-bond binding factor f_bond(q) = c·z + d derived on the compute side: f_pp = z, f_nn = z − h, f_pn = z − h(½ − δ/4), validated against the measured tr_atom/tr_free to 1.1e-15 on D/T/³He/⁴He. See docs/audits/2026-06-10-binding-bond-graph-compute-audit-and-derivation.md and the depth-1 Z_q heat-kernel framing (the bridge is the depth-1 link kernel on the Wedderburn eigenbasis).

    Both lemmas are sorry-free consequences of the MarkovTrace class fields (trace_gen, trace_prod_gen, normalised, linearity). The general A-bond factorization tr_M(∏_k (c_k • σ_{i_k} + d_k)) = ∏_k (c_k·z + d_k) for pairwise-distant generators needs the cross-level Markov axiom (or a word-induction principle) that the class does not yet carry — same gap documented at markov_trace_unique; the pair case below is the A = 3 (two-bond) instance and the compute witness covers the general case numerically.

    Status of the general case (2026-09-07, bean qou-gr3t). The gap named above is now a named hypothesis with a counter-model: QOU.Hecke.MarkovInteriorBond.InteriorMarkov states the interior-generator Markov property (tr(a·σ_g·b) = z·tr(a·b) for a below and b above the bond), tr_bondWord_of_interiorMarkov proves the general-A bond product from it for arbitrary (non-monotone) block words, interiorMarkov_ascending proves it unconditionally in the monotone case, and not_interiorMarkov_cmTower exhibits a MarkovTower satisfying every field and violating it — so the property is independent of the abstract tower axioms.

    PROVED for the Hecke tower (2026-09-13, PR #7265 + #7337). The clause that stood here — "is a theorem of the Hecke tower (quadratic + braid + word-spanning), still to be proved there" — named the right target and is now out of date on its own conclusion. QOU.Hecke.InteriorMarkovOfBraidedTower.interiorMarkov_of_braided discharges InteriorMarkov on every BraidedTower (the three Iwahori–Hecke relations: quadratic, far-commutation, braid), through HeckeSandwichReduces.disjointBlock_of_braided; composing with tr_bondWord_of_interiorMarkov gives the general-A bond product unconditionally there, and QOU.Hecke.PureBondChainProduct.tr_pureBondChain_of_braided states it in the bare-product shape this docstring quotes. Both sorry-free.

    Three limits, or this gets over-quoted. (i) The coefficient is 1: the proved shape is ∏_k (z + d_k), not ∏_k (c_k·z + d_k), because c • σ + d factors only over a field — no restriction on the corpus, since all three bond types listed above carry c = 1. (ii) It is proved in a different class. MarkovTrace n q A below is fixed-level and single-algebra with no filtration, so it cannot state "a below the bond, b above it" — which is exactly what "the class does not yet carry" recorded, and remains true of this class; the proof lives in the tower vocabulary and transporting it here is a separate bridge. (iii) A braided tower is not yet the production trace: the Ocneanu trace of H_n(q) at z = q³/(q²+1) is proved unique as a HeckeCoset.MarkovTraceFamily and is not packaged as an OcneanuTrace.MarkovTrace (bean qou-gr3t, remaining item).

    The n = 9 exact identity (route_c_step3_bond_factorisation_exact_probe.py, 76/76) remains the independent scope-(b) evidence at fixed A, on the canonical non-monotone word.

    theorem QOU.Hecke.MarkovTrace.trace_bond_crossing {R : Type u} {n : ℕ} {q : R} {A : Type u} [CommRing R] [Inv R] [Ring A] [Algebra R A] [HA : HeckeAlgebra R n q A] [MT : MarkovTrace n q A] (i : Generator n) (c d : R) :
    (trace n q) (c • HeckeAlgebra.embed q i + d • 1) = c * z_param n q A + d

    Per-bond trace factor (one bond). The Markov trace of a bridge crossing c • σ_i + d • 1 is its conditional expectation c · z + d — the fibre-level form of the per-bond binding factor f_bond(q): f_pp = z ((c,d) = (1,0)), f_nn = z − h ((1, −h)), f_pn = z − h(½ − δ/4).

    theorem QOU.Hecke.MarkovTrace.trace_bond_pair_factorizes {R : Type u} {n : ℕ} {q : R} {A : Type u} [CommRing R] [Inv R] [Ring A] [Algebra R A] [HA : HeckeAlgebra R n q A] [MT : MarkovTrace n q A] (i j : Generator n) (h : ↑i.idx < ↑j.idx) (c₁ d₁ c₂ d₂ : R) :
    (trace n q) ((c₁ • HeckeAlgebra.embed q i + d₁ • 1) * (c₂ • HeckeAlgebra.embed q j + d₂ • 1)) = (c₁ * z_param n q A + d₁) * (c₂ * z_param n q A + d₂)

    Two-bond factorization. For bridge crossings at generators i < j the Markov trace factorizes over the bonds: tr_M((c₁σ_i + d₁)(c₂σ_j + d₂)) = (c₁z + d₁)(c₂z + d₂). This is the A = 3 (two-bond chain) instance of tr_atom = tr_free · ∏ f_bond; uses trace_prod_gen (tr_M(σ_iσ_j) = z², two Markov peels).
