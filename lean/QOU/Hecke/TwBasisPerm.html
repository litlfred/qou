    QOU.Hecke.TwBasisPerm — the Rs branch, made concrete for type Aₙ #

    The bridge between the two halves of the T_w programme (bean qou-twwf).

    QOU.Hecke.TwBasis defines Rs i for an arbitrary Coxeter system, with its branch condition stated in terms of cs.length. QOU.Hecke.PermLength proves that for the type-Aₙ system that condition is a comparison of w at two adjacent points. This file joins them.

    What is proved #

    • rsFun_perm — Rs i acts on T_w by T_{w sᵢ} when w(i) < w(i+1) and by (q-1)T_w + q T_{w sᵢ} otherwise.

    Why it matters #

    Every branch in the braid relation Rs i ∘ Rs j ∘ Rs i = Rs j ∘ Rs i ∘ Rs j is now decidable by the relative order of w(i), w(i+1), w(i+2) — a finite case analysis, rather than the parabolic-coset argument the abstract route would need (and which Mathlib has no machinery for: its GroupTheory/Coxeter/ directory has no strong exchange property, no parabolic subgroups and no minimal coset representatives).

    The case analysis itself is not done here, nor the distant-generator commuting case, nor the algebra map H_n(q) → End (W →₀ R) and the T_w independence that would follow from both.

    theorem QOU.Hecke.TwBasis.rsFun_perm {n : ℕ} {R : Type u_1} [CommRing R] (q : R) (i : Fin n) (w : Equiv.Perm (Fin (n + 1))) :
    rsFun (SymmetricCoxeter.permCoxeterSystem n) q i w = if w i.castSucc < w i.succ then Finsupp.single (w * Equiv.swap i.castSucc i.succ) 1 else (q - 1) • Finsupp.single w 1 + q • Finsupp.single (w * Equiv.swap i.castSucc i.succ) 1

    The branch condition, made concrete. For the type-Aₙ system the Rs branch is decided by comparing w at two adjacent points.
