    theorem QOU.Hecke.BoundedDegreeCoulomb.two_mul_card_edge_le {V : Type u_1} [Fintype V] (G : SimpleGraph V) [DecidableRel G.Adj] {d : ℕ} (hd : ∀ (v : V), G.degree v ≤ d) :
    2 * G.edgeFinset.card ≤ Fintype.card V * d

    The degree-sum formula as a bond-count bound. A graph in which no vertex has more than d neighbours has at most dn/2 edges, whatever else is true of it. This is the whole content of "a chain cannot carry Coulomb", with the chain replaced by its only relevant property.

    theorem QOU.Hecke.BoundedDegreeCoulomb.edge_share_le {n E d : ℝ} (hn : 1 < n) (hE : 2 * E ≤ n * d) :
    E / (n * (n - 1) / 2) ≤ d / (n - 1)

    The fraction of PAIRS that a degree-bounded graph's edges cover is at most d/(n-1). At d = 2 (a chain) this is the measured 2/(Z-1); at d = 12 (close packing) it is 12/(Z-1). Bounded either way, and vanishing.

    theorem QOU.Hecke.BoundedDegreeCoulomb.exists_gt_bounded_degree_bond_sum {ε c d : ℝ} (hε : 0 ≤ ε) (hc : 0 < c) (hd : 0 ≤ d) :
    ∃ (N : ℝ), 1 < N ∧ ∀ (n E : ℝ), N ≤ n → 0 ≤ E → 2 * E ≤ n * d → ε * E < c * (n * (n - 1) / 2)

    No constant per-bond energy makes a degree-bounded bond sum quadratic.

    Given any per-bond energy ε ≥ 0, any degree bound d ≥ 0 and any Coulomb coefficient c > 0, past a computable size EVERY graph with that degree bound has ε · (its bond count) strictly below c · (its pair count). The bond sum is linear; the pair count is not; and no choice of the letters closes the gap.

    Compare BindingExtensivity.exists_pow_gt_linear, which separates a different pair of growth classes (exponential vs linear) for a different purpose.
