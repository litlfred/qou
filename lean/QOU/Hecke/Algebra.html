    Hecke algebra H_n(q) — class-based formulation #

    The Iwahori–Hecke algebra of type A_{n-1} is presented as a typeclass over a commutative ring R and parameter q : R:

    class HeckeAlgebra (R : Type u) (n : ℕ) (q : R) (A : Type u)
    [CommRing R] [Inv R] [Ring A] [Algebra R A] where
  embed      : Generator n → A
  quadratic  : HeckeQuadratic q embed
  braid      : BraidRelation embed
  farCommute : FarCommutativity embed
  spans      : Algebra.adjoin R (Set.range embed) = ⊤

    Provability of statements about H_n(q) takes the algebra as an instance hypothesis.

    class QOU.Hecke.HeckeAlgebra (R : Type u) (n : ℕ) (q : R) (A : Type u) [CommRing R] [Inv R] [Ring A] [Algebra R A] :
    Type u

    The Iwahori–Hecke algebra H_n(q) over R, axiomatised as a typeclass. An instance asserts: an R-algebra A with a chosen generator embedding embed : Generator n → A satisfying the three Hecke relations.

    The spans field captures that A is generated as an R-algebra by embed's image (every element is a finite R-linear combination of monomials in the generators). Stated existentially to keep the class lightweight.

    • embed : Generator n → A

      The generator embedding σ_i ↦ embed i.

    • quadratic : HeckeQuadratic q (embed q)

      Hecke quadratic relation: σ_i² = (q - q⁻¹)σ_i + 1.

    • braid : BraidRelation (embed q)

      Braid relation: σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1}.

    • farCommute : FarCommutativity (embed q)

      Far-commutativity: σ_i σ_j = σ_j σ_i for |i - j| ≥ 2.

    • spans : Algebra.adjoin R (Set.range (embed q)) = ⊤

      Spanning property: A is generated as an R-algebra by the image of embed. Captured via Algebra.adjoin for compatibility with Mathlib's subalgebra API. Without this field the typeclass would admit any algebra containing the generators rather than the Hecke quotient itself.
