    QOU.Hecke.Inversions — an ℕ-valued inversion count for Perm (Fin n) #

    Toward the braid half of the T_w basis (bean qou-twwf).

    Why this exists #

    QOU.Hecke.TwBasis proves the Hecke quadratic relation for the right multiplication operators Rs i, using only Mathlib's length_mul_simple dichotomy. The braid relation needs to know which branch each length comparison takes, and the textbook route to that (dihedral reduction through parabolic cosets) needs machinery Mathlib does not have — measured: the whole Mathlib/GroupTheory/Coxeter/ directory is four files (Basic, Inversion, Length, Matrix), with no strong exchange property, no parabolic subgroups, and no minimal coset representatives.

    For type A there is a concrete alternative: a descent is just a comparison of two values, ℓ(w sᵢ) > ℓ(w) ↔ w(i) < w(i+1). Getting there needs ℓ = invCount, and Mathlib has only signAux — the inversion parity, as a ℤˣ-valued product — with no ℕ-valued count and no comparison to ℓ. So the count is built here.

    What is proved (sorry-free) #

    • eq_one_of_strictMono — a strictly monotone permutation of Fin n is the identity. Via StrictMono.orderIsoOfSurjective and the subsingleton of Fin n ≃o Fin n.

    • invSet / invCount — the inversion set and its cardinality.

    • invCount_one.

    • eq_one_of_invCount_eq_zero — no inversions implies the identity. This is the base case of the ℓ = invCount induction.

    • swap_pair_lt — swapping two adjacent positions preserves the order of every pair except the swapped pair itself. This is the crux: it is exactly what fails for a non-adjacent transposition.

    • card_erase_invSet_swap — the pair-matching bijection. Pairs meeting {i, i+1} in one element swap with each other, so every pair except (i, i+1) contributes identically to both inversion sets.

    • invCount_mul_swap — the step lemma: invCount (w · sᵢ) differs from invCount w by exactly one, upward exactly when w(i) < w(i+1).

    What is NOT proved yet #

    ℓ = invCount, and hence the descent characterisation ℓ(w sᵢ) > ℓ(w) ↔ w(i) < w(i+1). Both directions now follow from the step lemma by induction — invCount ≤ ℓ because each generator moves the count by one, and ℓ ≤ invCount by descending induction using eq_one_of_invCount_eq_zero as the base — but neither is written yet.
