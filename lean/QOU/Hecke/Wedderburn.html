    Wedderburn–Artin decomposition of H_n(q) #

    Over a "generic" base ring R (containing ℚ and the q-integers), the Hecke algebra splits as a direct sum of matrix algebras indexed by partitions of n:

    H_n(q) ≅ ⊕_{λ ⊢ n} M_{f^λ}(R)

    where f^λ = #SYT(λ) is the dimension of the Specht module (equal to the hook-length formula n! / Π hook(c) for c in λ).

    For each partition λ, the corresponding matrix block carries:

    • A central idempotent π_λ ∈ Z(H_n(q));
    • A faithful matrix representation ρ_λ : H_n(q) → M_{f^λ}(R).

    The Markov trace decomposes as tr_M(x) = Σ_λ y_λ · χ^λ(x) where y_λ = tr_M(π_λ) / f^λ is the central coefficient, and χ^λ(x) = tr(ρ_λ(x)) is the partition character.

          class QOU.Hecke.WedderburnDecomp {R : Type u} (n : ℕ) (q : R) (A : Type u) [CommRing R] [Inv R] [Ring A] [Algebra R A] [HeckeAlgebra R n q A] [MT : MarkovTrace n q A] :
          Type u

          Wedderburn–Artin decomposition of H_n(q). An instance asserts:

          • For each partition λ ⊢ n, a central idempotent pi_lambda λ;
          • The idempotents are mutually orthogonal and sum to 1;
          • Each block pi_lambda λ · A · pi_lambda λ is isomorphic to M_{f^λ}(R) (matrix algebra of size f^λ);
          • The Markov trace's restriction to each block is the matrix trace scaled by the central coefficient y_λ.

          For brevity we store only the central idempotents + scalar coefficients here; the matrix-algebra isomorphisms are captured abstractly via a representation rho_lambda.

          • pi_lambda : Partition n → A

            Central idempotent for partition λ.

          • idempotent (lam : Partition n) : pi_lambda q lam * pi_lambda q lam = pi_lambda q lam

            Each pi_lambda is idempotent.

          • orthogonal (lam mu : Partition n) : lam.parts ≠ mu.parts → pi_lambda q lam * pi_lambda q mu = 0

            Distinct idempotents are orthogonal.

          • central (lam : Partition n) (a : A) : pi_lambda q lam * a = a * pi_lambda q lam

            Each π_λ is central: π_λ ∈ Z(H_n(q)). This was always the claim of this class (see the docstring above: "central idempotent π_λ ∈ Z(H_n(q))") and of the §9.1 partition-respecting table ("Central idempotents π_λ (orthogonal, central) — asserted (class axiom)"); encoding it as a field closes the docstring-vs-fields gap (the proof-claims-unencoded pattern) and unlocks the L-3 per-λ Frobenius block-orthogonality below as derived theorems. Its discharge from the Hecke structure is the same Mathas (1999) §3.43 debt as orthogonal (§9.4 L-2).

          • y_lambda : Partition n → R

            Markov-trace central coefficient y_λ. By prop:y-lambda-recipe-from-partition this is a rational function in q given by s_λ(1, Q, ..., Q^{r-1}) / Σ d_μ s_μ(...).

          • all_parts : Finset (Partition n)

            The complete set of partitions (all irreducible representations of H_n(q), one for each partition λ ⊢ n). This equals the full set {λ | λ ⊢ n} of Young diagrams of n; by the Wedderburn–Artin theorem there are no other irreducibles over a generic base ring.

          • complete : ∑ lam ∈ all_parts q A, pi_lambda q lam = 1

            Resolution of identity (completeness). The central idempotents sum to 1: Σ_{λ ∈ all_parts} π_λ = 1. This is the machine-checked "we account for everything" — by Wedderburn–Artin the partitions of n index ALL irreducibles (Mathas 1999 §3.43), so the blocks exhaust the algebra with no residue. trace_exhaustive below is the derived unweighted decomposition that rests on this partition of unity; the y_λ enter one level down, through block_scaling.

          • rho (lam : Partition n) : A →ₐ[R] Matrix (Fin (blockDim lam)) (Fin (blockDim lam)) R

            The λ-block representation ρ_λ : A → M_{f^λ}(R), as an algebra homomorphism.

            This replaces a free field chi_lambda : Partition n → A → R, and the upgrade is the point: an AlgHom satisfies ρ_λ 1 = 1, so the block character has χ^λ(1) = f^λ forced. With χ^λ free, block_scaling was an equation on a product of two unknowns and pinned neither factor; with ρ_λ an algebra map it pins y_λ against blockDim (yLambda_determined).

          • block_scaling (x : A) (lam : Partition n) : (MarkovTrace.trace n q) (x * pi_lambda q lam) = y_lambda q A lam * ((rho q lam) x).trace

            Block scaling. The Markov trace restricted to block λ is the block character scaled by the central coefficient: tr_M(x · π_λ) = y_λ · χ^λ(x).

            This is the sentence in this class's header docstring — "The Markov trace's restriction to each block is the matrix trace scaled by the central coefficient y_λ" — which was prose and is now a field. It is where the y_λ actually enter, and it is a hypothesis, not the conclusion: trace_decomposition derives tr_M(x) = Σ_λ y_λ · χ^λ(x) from it together with complete, and neither input is that identity.

            It replaces a field trace_decomp that asserted the conclusion directly, over the terms tr_M(x · π_λ) rather than χ^λ(x) — applying y_λ on top of a quantity that already carries it. That field was not merely redundant with the derived trace_exhaustive: the two together forced (1 − y_μ) · tr_M(π_μ) = 0 for every block, i.e. every weight trivial or its block trace zero. Machine-checked as weights_inert / weight_one_or_block_trace_zero in commit 9e8b712fa2, which is where those two theorems can still be run; they are deleted here along with the field they were about.

              theorem QOU.Hecke.WedderburnDecomp.pi_mul_pi {R : Type u} {n : ℕ} {q : R} {A : Type u} [CommRing R] [Inv R] [Ring A] [Algebra R A] [HA : HeckeAlgebra R n q A] [MT : MarkovTrace n q A] [WD : WedderburnDecomp n q A] (lam mu : Partition n) :
              pi_lambda q lam * pi_lambda q mu = if lam = mu then pi_lambda q lam else 0

              (§9.4 L-2) Kronecker orthogonality of the central idempotents — π_λ · π_μ = δ_{λ,μ} · π_λ. Packages the idempotent and orthogonal axioms into one relation. The statement is keyed on lam = mu (matching the Kronecker δ_{λ,μ} and independent of Partition's internal representation); the @[ext] proof-irrelevance step (equal parts ⇒ equal Partition) is used only internally to bridge to the parts-keyed orthogonal axiom. Makes the block algebra directly usable.

              The standing §9.4 debt is to discharge the orthogonal axiom itself (and y_lambda uniqueness, L-1) from the Hecke structure via Schur character-orthogonality — Mathas (1999) §3.43, not yet in Mathlib. This lemma is the immediate consequence of the current axioms, not that discharge.

              theorem QOU.Hecke.WedderburnDecomp.trace_exhaustive {R : Type u} {n : ℕ} {q : R} {A : Type u} [CommRing R] [Inv R] [Ring A] [Algebra R A] [HA : HeckeAlgebra R n q A] [MT : MarkovTrace n q A] [WD : WedderburnDecomp n q A] (x : A) :
              (MarkovTrace.trace n q) x = ∑ lam ∈ all_parts q A, (MarkovTrace.trace n q) (x * pi_lambda q lam)

              Exhaustiveness of the Markov trace over the Wedderburn blocks — tr_M(x) = Σ_λ tr_M(x · π_λ), with NO residue. The machine-checked "we account for everything": derived from the resolution of identity Σ_λ π_λ = 1 (WD.complete) via left-distributivity and R-linearity of the trace — it does NOT re-assume a decomposition. The sum runs over the complete set WD.all_parts (the p(n) partitions of n); there are no other blocks. This lemma needs only complete; trace_decomposition below adds block_scaling to it and gets the y_λ-weighted form.
