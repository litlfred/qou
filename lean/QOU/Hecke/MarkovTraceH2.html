    QOU.Hecke.MarkovTraceH2 — a Markov trace on H₂(q), and a real #

    MarkovTraceContext

    Before this file the only inhabitant of QOU.Shared.MarkovTraceContext was the n = 0 witness, where Generator 0 is empty and every axiom holds because there is nothing to check. That is useful for refuting over-general statements and worth nothing as mathematics: any result quantified over MarkovTraceContext was being tested against a structure with no generators.

    This file supplies a witness with content. H₂(q) = R[X]/(X² − (q − q⁻¹)X − 1) is free of rank 2 on the power basis {1, σ} (QOU.Hecke.InstanceH2 + QOU.Hecke.instIsHeckeOfFullRankH2), so the trace is just "read the two coordinates and weight the second by z":

    tr_M(a·1 + b·σ) = a + b·z .

    What each axiom costs #

    axiom why it holds here
    trace is R-linear it is a combination of two Basis.coords
    normalised 1 is the 0-th power-basis vector, so its coordinates are (1, 0)
    cyclic H₂(q) is commutative — AdjoinRoot of a commutative ring — so x*y = y*x outright
    trace_gen σ is the 1-st power-basis vector, coordinates (0, 1), so the trace is z by construction
    trace_prod_gen quantifies over i.idx < j.idx in Fin 1 — vacuous

    Two of the five are therefore free at n = 2 (cyclic by commutativity, trace_prod_gen by emptiness). That is a real fact about the two-strand algebra, not a gap: H₂(q) is genuinely commutative and genuinely has one generator. It also means, exactly as InstanceH2 says of itself, that this is not evidence for n ≥ 3, where cyclicity is a theorem with content.

    z is a parameter, not a choice made here #

    The mathematical Markov parameter is z = 1/(q^{1/2} + q^{-1/2}), which needs a square root of q in R. QOU.Hecke.MarkovTrace stores z as a class field and constrains it only through trace_gen, so the construction below is stated for an arbitrary z : R and does not pretend to pin it. markovTraceH2 is a def rather than an instance for that reason — an instance would have to invent a value.

            The witness is not the degenerate one. Its generator set is inhabited; the n = 0 witness's is Generator 0, which is empty. That is the single fact separating a MarkovTraceContext that carries content from one which discharges every axiom by having nothing to quantify over.

            What this does not establish #

            cyclic and trace_prod_gen are free here — the first because H₂(q) is commutative, the second because there is only one generator index. At n ≥ 3 neither is free. Noncommutativity is already visible at n = 3 (QOU.Machinery.H3: σ₀σ₁ = e₄ ≠ e₃ = σ₁σ₀) and at n = 4 (QOU.Machinery.H4.mulσ0_mulσ1_ne), so cyclic becomes a theorem rather than a consequence of commutativity — QOU.Hecke.MarkovTraceOnH3A.markovTraceH3A is the first witness where it does, and where trace_prod_gen is satisfiable at all. Cyclicity at n = 4 is QOU.Machinery.H4.trM_cyclic, sorry-free via the 576-entry gram_symm closure, and correspondingly expensive: it is the tree's build pole.

            So this witness makes MarkovTraceContext-quantified results non-vacuous. It does not make them evidence about the general Markov trace.
