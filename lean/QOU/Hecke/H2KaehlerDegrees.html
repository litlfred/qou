    QOU.Hecke.H2KaehlerDegrees — the fibre has no degrees, the tower does (the honest HH_1 example) #

    prop:spectral-sequence-collapse asserts HH^k(H_n(q)) = 0 for k ≥ 1 at generic q (Whitehead's lemma for a semisimple algebra). Its Lean carrier QOU.WedderburnMass.centralIdempotent_idem proves idempotence of central idempotents and never uses its [WhiteheadHH] instance — recorded twice as a defect (docs/audits/2026-08-25-spectral-sequence-is-a-no-go-not-a-tool.md §2a). Mathlib has no Hochschild (co)homology, so the collapse cannot be stated there yet.

    This file does the one thing that CAN be stated and proved today, at n = 2, and it is the statement the research doc (docs/audits/2026-09-05-binding-gap-groupoids-derived-categories-full-tower.md §7 item 2) asks for: the semisimple fibre has no first Hochschild degree, and the same algebra over the tower ring does.

    The mathematics, and what is cited rather than proved #

    For the commutative algebra A_h := R[X]/(X² − h·X − 1) (this is H₂ with h = q − q⁻¹, QOU.Hecke.InstanceH2.H2), the first Hochschild homology is the module of Kähler differentials, HH_1(A_h/R) ≅ Ω¹_{A_h/R} (Hochschild–Kostant–Rosenberg degree one; for a commutative algebra this is the elementary identification HH_1 = Ω¹, Weibel An Introduction to Homological Algebra Prop. 9.4.3 / Loday Cyclic Homology 1.1.10), and for a monogenic algebra R[X]/(f)

    Ω¹_{A_h/R} ≅ A_h · dX / (f'(X) · dX) ≅ A_h / (f'(x))        with  f'(x) = 2x − h .

    Those two identifications are cited, not proved here — Mathlib's KaehlerDifferential API for a quotient of a polynomial ring was not exercised in this session, and no Hochschild framework exists. What IS proved is everything about the module A_h / (2x − h) that the identification turns into a statement about HH_1:

    • two_x_sub_h_sq — the discriminant identity (2x − h)² = h² + 4 in A_h. At h = q − q⁻¹ this is (q + q⁻¹)² = [2]_q² (two_x_sub_h_sq_hecke): the Hochschild degree-one module is killed by the square of the quantum integer [2]_q.
    • kaehlerIdeal_eq_top_of_isUnit — the fibre has no degree: if h² + 4 (i.e. [2]_q²) is a unit of R, then (2x − h) = A_h, so A_h/(2x − h) = 0. This is the n = 2 case of the collapse, over any ring in which [2]_q is invertible — in particular at every generic q, and at the substrate q₀.
    • kaehlerIdeal_ne_top_of_hom — the tower has one: if some ring homomorphism φ : R →+* K to a field (with 2 ≠ 0 in K) sends h² + 4 ↦ 0, then (2x − h) ≠ A_h and the module is non-zero. For R = ℤ[q, q⁻¹] and φ : q ↦ i (a primitive fourth root of unity, [2]_i = 0) this says exactly that HH_1(H₂ / ℤ[q^{±1}]) ≠ 0 — the algebra over the ring of the tower is not formal, and inverting [2]_q (passing to the fibre) is what kills the degree.

    So the two theorems are the two halves of one sentence: the degree the derived route needs exists over ℤ[q^{±1}] and is destroyed by specialising to a generic fibre. That is the structural content of the research doc's §2, at the one n where the corpus has a genuine HeckeAlgebra instance.

    What this does NOT claim #

    • Nothing about n ≥ 3 (H_n is non-commutative there; HH_1 ≠ Ω¹ and the corpus has no instance).
    • Nothing about the value of a binding term. A non-zero HH_1 is a place a many-body term could live; it is not a many-body term.
    • Nothing about the GB filtration or the spectral sequence — see the GAP note in mass-theory/spectral-sequence-collapse.lean, which stands.

    Ground ring: generic [CommRing R] throughout (§7c); the non-vanishing witness needs a field target only for IsUnit 0 → False. Bean qou-onte §7 item 2.
