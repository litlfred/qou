    theorem QOU.Hecke.WedderburnWeightDegeneracy.y21_at_zD_pos (q : ℝ) (hq : q ≠ 0) :
    0 < y21 q (zD q)

    THE RESULT. The (2,1) Wedderburn weight is strictly positive at the canonical loop value, for every nonzero real q.

    y_(2,1)(z_D) = q²/(q²+1)² is a manifestly positive rational function, so the block never degenerates: there is no convention-D analogue of the convention-C hadronic melt at any real q. A scope-(b) exclusion of the Wedderburn / Gram-degeneracy route with the invariant exhibited — it says nothing about a transition produced by some other mechanism.

    The convention-C loop value never reaches 1, for any u > 0: z_C ≤ 1/2.

    The corpus (qbeta-counit-closed-form.md) says the trivial loop value "is never attained on the substrate", which is a statement about q_0. This is the stronger fact: under convention C the Frobenius counit ε = tr_M|_{z=1} is unreachable as a Markov trace at EVERY q, not merely at the anchor.
