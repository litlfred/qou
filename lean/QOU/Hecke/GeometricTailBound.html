    theorem QOU.Hecke.GeometricTailBound.tail_eq {x : ℝ} (hx : x ≠ 1) :
    (1 - x)⁻¹ - (1 + x) = x ^ 2 / (1 - x)

    The whole tail of a geometric series past its second term. (1-x)⁻¹ - (1+x) = x²/(1-x), for any x ≠ 1.

    The tail is positive when 0 < x < 1, so summing always moves in the same direction — it just cannot move far.

    theorem QOU.Hecke.GeometricTailBound.tail_le {x : ℝ} (_h0 : 0 ≤ x) (h1 : x ≤ 1 / 2) :
    (1 - x)⁻¹ - (1 + x) ≤ 2 * x ^ 2

    A crude but useful bound: for 0 ≤ x ≤ 1/2 the entire tail is at most 2x². So "all the terms" is second order in a quantity already small.

    theorem QOU.Hecke.GeometricTailBound.summing_cannot_close {x C K : ℝ} (h0 : 0 < x) (h1 : x < 1) (hK : 1 < K) (hgap : C - (1 + x) = K * (x ^ 2 / (1 - x))) :
    (1 - x)⁻¹ < C

    Summing every remaining term cannot reach a target that the tail undershoots.

    If the outstanding gap C - (1+x) is K times the entire tail with K > 1, then even the full geometric sum (1-x)⁻¹ falls short of C.

    This is the honest content of "we should use all the terms": one may, and it is still not enough. At x = ℏ_q³ the measured K is 323.
