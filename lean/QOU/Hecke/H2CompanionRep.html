    QOU.Hecke.H2CompanionRep — the H_2 Gram from the regular representation #

    Brick qou-eedq: upgrade h2GramMatrix from asserted trace literals to the regular representation of H_2(q).

    H_2(q) = K⟨1, σ⟩ with σ² = (q-1)σ + q is 2-dimensional; left multiplication by σ in the ordered basis {1, σ} is the companion matrix of the Hecke quadratic X² - (q-1)X - q,

    C = !![0, q; 1, q-1] (σ·1 = σ, σ·σ = q·1 + (q-1)·σ).

    We prove:

    • h2Companion_hecke — C² = (q-1)·C + q·I, so σ ↦ C respects the Hecke relation: C is a faithful matrix image of σ, the left regular representation, not an ad-hoc matrix.
    • h2GramFromRep_eq — the regular-trace Gram matrix Gᵢⱼ = tr(ρ(eᵢ)·ρ(eⱼ)) built from ρ = {1 ↦ I, σ ↦ C} equals the h2GramMatrix whose entries H2GramArithmetic had merely asserted.

    Consequently det(Gram) = [2]_q² (h2GramFromRep_det) now rests on the representation-computed traces, closing the "traces asserted, not derived" gap flagged in H2GramArithmetic. Taking tr is the observation step; the Gram is a matrix of observable results of the regular action.
