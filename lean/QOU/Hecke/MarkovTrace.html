    Markov trace on H_n(q) #

    A Markov trace on the family {H_n(q)}_{n ≥ 1} is an R-linear functional tr_M : H_n(q) → R satisfying:

    (M1) Normalisation: tr_M(1) = 1 (M2) Cyclicity: tr_M(x · y) = tr_M(y · x) for all x, y (M3) Markov axiom: tr_M^{H_n}(x · σ_{n-1}) = z · tr_M^{H_{n-1}}(x) for x ∈ H_{n-1}(q) ⊂ H_n(q)

    with Markov parameter z = 1 / (q^{1/2} + q^{-1/2}).

    Existence + uniqueness up to scalar normalisation: Jones (1987), Ocneanu (1986).

    Markov trace structure on H_n(q). Encodes the three Markov axioms plus the connection to the Markov parameter z.

    For the chain H_1 ⊂ H_2 ⊂ ... the Markov axiom relates traces at adjacent levels; we capture this via a parameterised family of traces and a coherence condition.

    • trace : A →ₗ[R] R

      The trace as an R-linear map A → R.

    • normalised : (trace n q) 1 = 1

      (M1) Normalisation: tr_M(1) = 1.

    • cyclic (x y : A) : (trace n q) (x * y) = (trace n q) (y * x)

      (M2) Cyclicity: trace(x · y) = trace(y · x).

    • z_param : R

      The Markov parameter z = 1/(q^{1/2} + q^{-1/2}). Stored as a field rather than a definition because q^{1/2} requires choosing a square root extension of R.

    • trace_gen (i : Generator n) : (trace n q) (HeckeAlgebra.embed q i) = z_param n q A

      (M3 / generator value) tr_M(σ_i) = z for every generator. This is the key consequence of the full Markov axiom tr_M^{H_n}(x · σ_{n-1}) = z · tr_M^{H_{n-1}}(x) applied at level n with x = 1 ∈ H_{n-1}.

    • trace_prod_gen (i j : Generator n) : ↑i.idx < ↑j.idx → (trace n q) (HeckeAlgebra.embed q i * HeckeAlgebra.embed q j) = z_param n q A * z_param n q A

      (M3 / pair product) tr_M(σ_i · σ_j) = z² when i < j. Follows from two consecutive Markov peels: σ_j is top-indexed, one peel gives z · tr_{n-1}(σ_i); σ_i lives in H_{n-1} so the second peel gives z · z.

      (trace n q) (HeckeAlgebra.embed q i * (HeckeAlgebra.embed q j - (q - q⁻¹) • 1)) = z_param n q A * z_param n q A - (q - q⁻¹) * z_param n q A

      Trace of a generator times an inverse generator: tr_M(σ_i · σ_j⁻¹) = z² − (q − q⁻¹)·z for i < j.

      The Hecke quadratic relation gives σ_j⁻¹ = σ_j − (q − q⁻¹)·1 (HeckeAlgebra.inv_formula), so writing σ_j⁻¹ in that form and using R-linearity of the trace:

      tr_M(σ_i · (σ_j − (q−q⁻¹)·1)) = tr_M(σ_i·σ_j) − (q−q⁻¹)·tr_M(σ_i) = z² − (q−q⁻¹)·z

      by trace_prod_gen (i < j) and trace_gen. This is the denominator tr_M(T_β) of the Pauli-full-shell knot operator F(τ,N) in cor:spectral-decomposition-qvalue, whose decay operator is T_β = σ_0 · σ_1⁻¹ (i = 0, j = 1). Bean qou-xq3f.

      Uniqueness of the Markov trace #

      The class MarkovTrace alone does NOT determine the trace. Until 2026-10-10 this file carried axiom markov_trace_unique_axiom, asserting that two MarkovTrace instances with equal z_param have equal trace. That statement is false, and since it was an axiom it made the environment inconsistent. The class only pins tr(1), tr(σᵢ), tr(σᵢσⱼ) (i < j) and cyclicity; on H₄(q) the cyclic traces form a 5-dimensional space (one per partition of 4) and those conditions cut out only four of the five directions. Explicit counterexample, on the tree's own H₄(q): QOU.Hecke.MarkovTraceClassNotUnique.markov_trace_unique_axiom_false (the trace 4·tr_Z − 3·tr_{Z+1} − tr_{Z−1} + tr_{Z+2} satisfies every field with z_param = Z but gives Z³ + 6 on σ₀σ₁σ₂, against Z³ for the Ocneanu trace).

      What IS true is uniqueness under the cross-level Markov property (M3), tr(x · σ_k) = z · tr(x) for x in the subalgebra generated by σ₀, …, σ_{k-1}. MarkovTrace.IsMarkov states it, and markov_trace_unique below proves uniqueness from it, sorry-free, via the Jones normal form (QOU.IwahoriHecke.JonesNormalForm.markov_unique_of_adjoin_eq_top).

          theorem QOU.Hecke.markov_trace_unique {R : Type u} {n : ℕ} {q : R} {A : Type u} [CommRing R] [Inv R] [Ring A] [Algebra R A] [HA : HeckeAlgebra R n q A] (MT₁ MT₂ : MarkovTrace n q A) (hz : MarkovTrace.z_param n q A = MarkovTrace.z_param n q A) (h₁ : MT₁.IsMarkov) (h₂ : MT₂.IsMarkov) :
          MarkovTrace.trace n q = MarkovTrace.trace n q

          Uniqueness of the Markov trace (Ocneanu 1985; Jones 1987), sorry-free. Two MarkovTraces on the same HeckeAlgebra with the same Markov parameter that both satisfy the cross-level Markov property (M3) have the same trace.

          The (M3) hypotheses are necessary, not decorative: without them the conclusion is false (QOU.Hecke.MarkovTraceClassNotUnique.markov_trace_unique_axiom_false).
