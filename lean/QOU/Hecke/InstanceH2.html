    QOU.Hecke.InstanceH2 — a genuine HeckeAlgebra instance at n = 2 #

    Until now no concrete instance of QOU.Hecke.HeckeAlgebra existed anywhere in the tree (nor of QOU.Hecke.MarkovTrace, nor of QOU.Shared.MarkovTraceContext). Both appeared only in hypothesis position, [HeckeAlgebra R n q A], so every result quantified over them was conditional on infrastructure that had never been shown to exist.

    This file supplies the n = 2 case, and only that case, honestly.

    What is here #

    H2 R q := R[X] / (X² − (q − q⁻¹)·X − 1), via AdjoinRoot. The single Hecke generator is the image of X, and the defining relation is the Hecke quadratic relation σ² = (q − q⁻¹)·σ + 1 (AGENTS.md §7a convention).

    Why n = 2 is the honest stopping point, not a shortcut #

    Generator n carries idx : Fin (n - 1), so Generator 2 has exactly one index. BraidRelation quantifies over adjacent pairs and FarCommutativity over pairs differing by ≥ 2; with a single index neither predicate is ever satisfiable, so both hold vacuously. That is a real fact about n = 2, not a gap being papered over — the two-strand Hecke algebra genuinely has no braid relation to satisfy.

    It also means this instance is not evidence for n ≥ 3. At n = 3 the braid relation becomes non-vacuous and is the actual open infrastructure work the manuscript keeps citing. Nothing here touches it.

    Contrast with the degenerate witness #

    A MarkovTraceContext can also be built at n = 0, where Generator 0 is empty and every axiom holds because there is nothing to check. That witness is useful for refuting over-general statements (bean qou-octr) and is worth nothing as mathematics. This one is different in kind: the generator exists, the quadratic relation is genuinely imposed, and spans genuinely holds because AdjoinRoot is generated by its root.

            What this instance does NOT establish #

            HeckeAlgebra as stated asks for a generator map, the three relations, and spanning. It does not ask that A be free of rank n! over R, and without that it does not characterise H_n(q) — it is satisfied by algebras far too small.

            Concretely, at q = 1 the parameter h = q - q⁻¹ is 0, so x = 1 solves x² = h·x + 1; braid and far-commutativity are automatic in a commutative ring; and spans holds because Subalgebra ℚ ℚ is a subsingleton. Hence:

            instance QOU.Hecke.InstanceH2.rankOneModel (n : ℕ) :
            HeckeAlgebra ℚ n 1 ℚ

            The class admits a rank-1 model at every n. ℚ itself is a HeckeAlgebra ℚ n 1 ℚ for all n — including n where H_n(1) has dimension n! = 6, 24, 120, ….

            So a hypothesis [HeckeAlgebra R n q A] is much weaker than "A is the Hecke algebra": anything proved from it also holds of ℚ at q = 1. The missing axiom is the Iwahori basis — A free of rank n! over R on {T_w}_{w ∈ S_n}. See bean qou-ghak / the H3–H4 roadmap.
