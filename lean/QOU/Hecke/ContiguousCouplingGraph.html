        def QOU.Hecke.ContiguousCouplingGraph.IsCoupling (i j x : ℕ) :
        Prop

        x is the lower endpoint of a single-generator coupling between nucleons i and j: the generator σ_x crosses strands x and x+1, so a coupling puts x in nucleon i and x+1 in nucleon j.

        This is LayoutConflict.IsCoupling with the second nucleon left FREE rather than fixed to i+1 — which is the whole point, since the binding word needs couplings between nucleons that are not neighbours.

            theorem QOU.Hecke.ContiguousCouplingGraph.complete_coupling_forces_A_le_two {A : ℕ} (h : ∀ (i j : ℕ), i < A → j < A → i ≠ j → Coupled i j) :
            A ≤ 2

            The binding producer's coupling is unreachable. If every pair of the A nucleons is coupled — which is exactly what _step_chain_generic emits, one inter-nucleon letter per (new nucleon, earlier nucleon) pair — then A ≤ 2.

            So the deuteron re-embeds and nothing above it does: at A = 2 the single pair {0,1} IS the one adjacency, while from A = 3 the pair {0,2} has no generator to sit on.

            2 * (3 * A - 1) < A * (A - 1)

            The layout-free bound, which survives dropping contiguity. A linear arrangement of 3A strands has only 3A-1 adjacent position pairs, and each can carry at most one nucleon pair, so no layout whatever realises the complete coupling once C(A,2) > 3A-1 — that is, from A = 7, which is ⁷Li.

            Stated without division as 2·(3A-1) < A·(A-1). At A = 7 this is 40 < 42; the exhaustive search in the probe agrees, finding witnesses for A = 2 … 6 and none at A = 7.
