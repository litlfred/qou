    Class B in bond-factor letters #

    source
    theorem QOU.Hecke.BondCutSymmetryNoSignDefiniteLogBound.energy_neg_iff_one_lt_bond {b : ℝ} (hb : 0 < b) :
    -Real.log b < 0 ↔ 1 < b

    Class B is b > 1. A bond energy e = -ln b is negative — repulsive — exactly when its bond factor exceeds one. This is the definition the enumeration in bean qou-brng gives, made checkable against a derived number.

    A uniform bond rescaling leaves δ fixed #

    source
    theorem QOU.Hecke.BondCutSymmetryNoSignDefiniteLogBound.energySlope_bondRescale {bpp bpn bnn c : ℝ} (hpp : 0 < bpp) (hpn : 0 < bpn) (hnn : 0 < bnn) (hc : 0 < c) :
    BondCutSymmetry.energySlope (-Real.log (c * bpp)) (-Real.log (c * bpn)) (-Real.log (c * bnn)) = BondCutSymmetry.energySlope (-Real.log bpp) (-Real.log bpn) (-Real.log bnn)

    Rescaling all three bond factors by a common c > 0 leaves δ unchanged. ln (c·b) = ln c + ln b, so every energy shifts by -ln c and the generic energySlope_energyShift applies.

    theorem QOU.Hecke.BondCutSymmetryNoSignDefiniteLogBound.exists_bondRescale_all_energies_neg {bpp bpn bnn : ℝ} (hpp : 0 < bpp) (hpn : 0 < bpn) (hnn : 0 < bnn) :
    ∃ (c : ℝ), 0 < c ∧ -Real.log (c * bpp) < 0 ∧ -Real.log (c * bpn) < 0 ∧ -Real.log (c * bnn) < 0 ∧ BondCutSymmetry.energySlope (-Real.log (c * bpp)) (-Real.log (c * bpn)) (-Real.log (c * bnn)) = BondCutSymmetry.energySlope (-Real.log bpp) (-Real.log bpn) (-Real.log bnn)

    Class B is reachable from any positive law, at zero cost in δ. For any positive bond factors there is a common scale c > 0 making all three energies strictly negative — every bond repulsive, bondSum_nonneg fully escaped — while the p–n slope, and hence the whole symmetry coefficient, is identically the one before the rescaling.

    So the cheapest and most natural way into class B changes nothing the symmetry term sees. Whatever class B can do, it cannot do it uniformly.

    The dichotomy in bond-factor letters #

    source
    theorem QOU.Hecke.BondCutSymmetryNoSignDefiniteLogBound.interface_below_of_gt_convexCap {bpp bpn bnn : ℝ} (hnn : 0 < bnn) (h : (Real.log bpp - Real.log bnn) / 2 < BondCutSymmetry.energySlope (-Real.log bpp) (-Real.log bpn) (-Real.log bnn)) :
    bpn < bnn

    Beating the convex cap forces the interface below both like-species bonds. If δ exceeds (ln b_pp - ln b_nn)/2 then b_pn < b_nn: the p–n bond factor is strictly smaller than the smaller like-species factor, so it is not a convex combination of them and is not derived by SymmetrySignAmGm.weight_of_convention. No sign hypothesis is used, so class B does not change this.
