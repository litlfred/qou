              theorem QOU.Hecke.WedderburnWeightDegeneracy.y21_eq_zero_iff {K : Type u_1} [Field K] (q z : K) (hq : q ≠ 0) (h2 : q ^ 2 - q + 1 ≠ 0) (h3 : q ^ 2 + q + 1 ≠ 0) :

              The (2,1) block degenerates at exactly two loop values. y_(2,1)(z) = 0 iff z = q or z = -1/q. Both roots are needed below: under convention C they are the corpus detFactor3 and detFactor4.

              theorem QOU.Hecke.WedderburnWeightDegeneracy.y111_at_zD {K : Type u_1} [Field K] (q : K) (h1 : q ^ 2 + 1 ≠ 0) :

              y_(1^3) vanishes identically at the canonical loop value. This is the same fact as gramMatrixD_det_eq_zero: convention D annihilates the sign block, which is why the D determinant is identically singular and cannot be used to locate a transition — the question has to be put to the block weight instead.

              theorem QOU.Hecke.WedderburnWeightDegeneracy.zD_eq_one_iff {K : Type u_1} [Field K] (q : K) (h1 : q ^ 2 + 1 ≠ 0) :
              zD q = 1 ↔ q ^ 3 = q ^ 2 + 1

              z_D = 1 iff q³ = q²+1 — the supergolden equation. This is a DIFFERENT point from the convention-C Gram degeneracy u³+u−1 = 0 (there u = √q, so q = 1/ψ²); here it is q = ψ itself. It is where the Markov trace collapses onto the Frobenius counit.

              theorem QOU.Hecke.WedderburnWeightDegeneracy.zC_eq_qsq_iff {K : Type u_1} [Field K] (u : K) (hu : u ≠ 0) (h1 : u ^ 2 + 1 ≠ 0) :
