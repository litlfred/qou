    The bond products at the PRODUCTION Ocneanu trace #

    QOU.Hecke.InteriorMarkovOfBraidedTower, QOU.Hecke.PureBondChainProduct and QOU.Mass.ProductionChainBondProduct each prove a bond-product factorisation for every OcneanuTrace.MarkovTrace carrying a BraidedTower instance. Until the colimit bridge (QOU.SchurWeyl.HeckeColimitMarkovTrace) the only such instance in the tree was heckeTowerMarkovTrace, whose trace factors through a rank-2 quotient — so all three were statements about a class, with no production carrier.

    braidedTower_heckeColimit supplies the carrier. This file is the instantiation, and its content is not the re-statement but the concrete Markov parameter: at the production Ocneanu trace z = q³/(q²+1) (convention D, inherited from MarkovTraceInstance.wtrace_markov rather than chosen), so each abstract ∏ (z + d k) becomes a product in q.

    What is proved here #

    • prodZ_eq — (toTowerB prodTrace).z = q³/(q²+1), the substitution that makes everything below a formula in q.
    • tr_bondWord_ocneanu — the general bond word, at the production trace.
    • tr_pureBondChain_ocneanu — the strictly-increasing pure chain: tr((σ_{g₀}+d₀)(σ_{g₁}+d₁)⋯) = ∏ₖ (q³/(q²+1) + d k).
    • tr_productionChain_ocneanu — the production strand layout, whose bonds sit at σ_{3k+2}.

    What is NOT proved here #

    Nothing about the d k. Every statement below quantifies over arbitrary scalars d : ℕ → ℝ; the letter identification (pp ↦ 0, nn ↦ −h, pn ↦ d_averaged_weighted) is a separate, measured question and is assumed nowhere. So none of this is a binding-energy claim — it is the factorisation, with the framework's own z substituted in.

    No faithfulness, and no injectivity of ofLim n (bean qou-ejde): these are statements about trLim and about the image filtration exactly as the bridge leaves them.

    The hypotheses are those MarkovTraceInstance.wtrace already carries (hq0 : q ≠ 0, hq2 : NotRootOfUnity q, hq21 : q² + 1 ≠ 0, hgen : ∀ i > 0, (q²)^i ≠ 1) and none is added.
