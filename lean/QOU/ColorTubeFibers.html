    QOU.ColorTubeFibers #

    Canonical declaration for content block at quantum-observable-universe/brings-surface/color-tube-fibers.ts.

    Formalises the manuscript definition of the color tube R_z at z ∈ ℙ¹(ℂ) — the affine curve cut out by the color-tube cubic

    𝐫³ + (4z+1)𝐫² + (6z²+3z+1)𝐫 + (4z³+3z²+2z+1) = 0

    — and the shift 𝐫 = X − z realising the isomorphism R_z ≅ 𝓔_z with the color elliptic fiber. Pure algebra — generic over any CommRing (§7c-clean).

    structure QOU.ColorTubeFibers (R : Type u_1) [CommRing R] :
    Type u_1

    Data for the color tube R_z at a point z (the same cubic defines the G_z, B_z tubes with the other resolvent coordinates).

    A definition carrier: the base point z, and the color-tube cubic cubic pinned to its manuscript polynomial. Membership 𝐫 ∈ R_z is cubic 𝐫 = 0.

    • z : R

      The base point z ∈ ℙ¹.

    • cubic : R → R

      The color-tube cubic P_z.

    • cubic_def (r : R) : self.cubic r = r ^ 3 + (4 * self.z + 1) * r ^ 2 + (6 * self.z ^ 2 + 3 * self.z + 1) * r + (4 * self.z ^ 3 + 3 * self.z ^ 2 + 2 * self.z + 1)

      Defining polynomial of the color tube.
