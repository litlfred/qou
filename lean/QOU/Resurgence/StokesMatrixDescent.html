    QOU.Resurgence.StokesMatrixDescent #

    Categorical descent of the resurgent Stokes data, proved sorry-free over a generic base ring (see the sibling .md for the full narrative):

    • stokes_trace_conj_invariant (A.ii): trace conjugacy-invariance tr (g S g_inv) = tr S, the gauge-invariant Markov trace.
    • stokes_block_diagonal (A.i): Wedderburn equivariance implies block-diagonal S = sum e_i S e_i.
    • stokes_trace_block_sum: the trace splits into per-partition block traces.

    Ref: manuscript, mass-theory/stokes-matrix-descent.

    (A.ii) Gauge-invariance of the Markov trace tr_M(S) #

    source
    theorem QOU.Resurgence.stokes_trace_conj_invariant {n : Type u_1} {R : Type u_2} [Fintype n] [DecidableEq n] [CommRing R] (g : (Matrix n n R)ˣ) (S : Matrix n n R) :
    (↑g * S * ↑g⁻¹).trace = S.trace

    Stokes-trace descent (A.ii). A gauge / basis change acts on the Stokes matrix by conjugation S ↦ g S g⁻¹; the bar-invariant, gauge-invariant observable is the trace, a conjugacy invariant: tr(g S g⁻¹) = tr(S). This is the matrix-level Markov trace tr_M(S), and it is independent of the gauge g — proved from trace cyclicity. (The independence of the archimedean summation choice, median vs lateral, is a separate ℝ-level statement and is not part of this generic-ring scaffold.)

    (A.i) Wedderburn equivariance ⇒ block-diagonalisation #

    Stated over a general ring A (which the matrix algebra Mat_n(R) is an instance of), with e : ι → A the family of central idempotents indexed by partitions ι.

    source
    structure QOU.Resurgence.IdempotentFamily {ι : Type u_1} {A : Type u_2} [Fintype ι] [Ring A] (e : ι → A) :
    Prop

    A complete orthogonal idempotent family — the central Wedderburn / Young idempotents e_λ of H_n(q), one per partition λ : ι.

    • idem (i : ι) : e i * e i = e i

      Each e_i is idempotent.

    • ortho (i j : ι) : i ≠ j → e i * e j = 0

      Distinct idempotents are orthogonal.

    • complete : ∑ i : ι, e i = 1

      The family is complete: ∑_i e_i = 1.

        theorem QOU.Resurgence.stokes_block_diagonal {ι : Type u_1} {A : Type u_2} [Fintype ι] [Ring A] {e : ι → A} (hf : IdempotentFamily e) {S : A} (hS : CommutesFamily e S) :
        S = ∑ i : ι, e i * S * e i

        Block-diagonalisation (A.i). An Sₙ/Wedderburn-equivariant Stokes matrix S is block-diagonal in the Young/Hecke idempotent decomposition: S = ∑_λ e_λ S e_λ. Fully proved from completeness + off-block vanishing; no sorry, no axiom.

        Consequence: the invariant trace is the sum of per-partition block traces #

        source
        theorem QOU.Resurgence.stokes_trace_block_sum {n : Type u_1} {ι : Type u_2} {R : Type u_3} [Fintype n] [DecidableEq n] [Fintype ι] [DecidableEq ι] [CommRing R] {e : ι → Matrix n n R} (hf : IdempotentFamily e) {S : Matrix n n R} (hS : CommutesFamily e S) :
        S.trace = ∑ i : ι, (e i * S * e i).trace

        tr_M(S) = ∑_λ tr(e_λ S e_λ). Combining block-diagonalisation with additivity of the matrix trace: the gauge-invariant Markov trace of an equivariant Stokes matrix decomposes as the sum of its per-partition block traces. Proved sorry-free.
