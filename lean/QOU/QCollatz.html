    The q-deformed Collatz conjecture — Skein module formulation #

    Overview #

    The classical Collatz map divides by 2 (even) or applies 3n+1 (odd). In the q-deformed setting, 2 and 3 lift to quantum integers [2]_q and [3]_q, and the map operates on the Skein module S(q) ≅ ℤ[q±1].

    Three algebraic identities control the dynamics:

    1. Skein divisibility: [3]_q = q · [2]_q + 1 The q-analog of 3 = 1·2 + 1. Ensures the odd branch is well-defined.

    2. Contraction gap: [2]_q² - [3]_q = q Two halvings overpower one tripling. The margin is q itself.

    3. Uniqueness: Among all critical pairs (p₁^k₁, p₂^k₂) with p₁^k₁ = p₂^k₂ + 1, Collatz (2², 3¹) is the unique case where the q-gap is a monomial — and therefore positive for all q > 0.

    The (p₁^k₁, p₂^k₂) family #

    A generalized Collatz map (p₁, p₂) divides by p₁ when divisible and applies p₂·n + 1 otherwise. The contraction condition is [p₁]_q^k₁ > [p₂]_q^k₂, requiring k₁ halvings to beat k₂ triplings.

    The gap polynomial [p₁]^k₁ - [p₂]^k₂ ∈ ℤ[q±1] determines whether contraction holds for all q > 0 (all coefficients non-negative) or only for q near 1 (some negative high-degree coefficients).

      theorem QOU.Substrate.skein_divisibility (q : ℝ) (hq : q ≠ 1) :
      qInt q 3 = q * qInt q 2 + 1

      Skein divisibility: [3]_q = q · [2]_q + 1.

      At q = 1 this is 3 = 1·2 + 1. In the Skein-Collatz map, this identity ensures the odd branch is well-defined: for q-odd P (meaning [2]_q ∣ P+1), the numerator [3]_q·P + 1 = q·[2]_q·P + (P+1) is divisible by [2]_q.

      theorem QOU.Substrate.qInt_gap (q : ℝ) (hq : q ≠ 1) :
      qInt q 2 ^ 2 - qInt q 3 = q

      Contraction gap: [2]_q² - [3]_q = q.

      Two halvings (each dividing by [2]_q) more than compensate one tripling (multiplying by [3]_q). The margin between [2]_q² and [3]_q is exactly q — the substrate parameter.

      At q = 1: 2² - 3 = 1. At q₀ ≈ 1.1097: 2.11² - 3.34 ≈ 1.11.

      theorem QOU.Substrate.qInt_coprime (q : ℝ) (hq : q ≠ 1) :
      qInt q 3 - q * qInt q 2 = 1

      Coprimality of [2]_q and [3]_q.

      The Skein divisibility identity [3] = q·[2] + 1 is a Bézout relation: [3] - q·[2] = 1, so gcd([2], [3]) = 1.

      Consequence: [3]^a ≡ 1 (mod [2]) for all a ≥ 0, while [2]^b ≡ 0 (mod [2]) for b ≥ 1. These can never be equal, so the equation [3]^a = [2]^b has no solution for a, b > 0.

      This proves: the Skein-Collatz map has no periodic cycles other than the fixed point P = 1. A cycle with k_odd odd steps would require [3]^{k_odd} = [2]^k, which is impossible.

      The (3,8) gap is NOT always positive: [3]² - [8] has negative coefficients. For large q, [8] > [3]².

      theorem QOU.Substrate.contact_threshold_lt_two (q : ℝ) (hq : q > 0) (hq1 : q ≠ 1) :
      Real.log (qInt q 3) / Real.log (qInt q 2) < 2

      One-sided: v* < 2 (equivalently [3] < [2]²).

      This docstring previously announced the two-sided 1 < v* < 2, which the statement and proof below never established. The lower half 1 < v* (equivalently [2] < [3]) is proved in QOU.AppendixSurreals.CollatzThreeForms.one_lt_contactThreshold, and the two-sided form is contactThreshold_mem_Ioo there. The lower half is what rules out a single halving per tripling, so it is load-bearing for the claim that the integer threshold is exactly two.

      Since v* < 2 is proved algebraically ([3] < [2]²), the integer condition ⟨v⟩ ≥ 2 (two halvings per tripling) suffices — and avoids transcendental quantities entirely.
