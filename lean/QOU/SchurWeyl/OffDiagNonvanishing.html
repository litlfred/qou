    QOU.SchurWeyl.OffDiagNonvanishing — offDiag vanishes only at the scalar distances #

    The second of the two lemmas the irreducibility half of SW-5 needs (bean qou-jfr8).

    offDiag q (-1) = 0 is a @[simp] lemma, so the generator matrix genuinely has vanishing off-diagonal entries — that is what makes the size-1 orbits coherent. The question the matrix-unit chain asks is whether it can vanish anywhere else, because a chain step whose entry is 0 cannot be promoted by single_mem_range_of_entry_ne_zero.

    It cannot. offDiag q d = 0 forces d = ±1, so with TableauCells.two_le_natAbs_axialDist every admissible swap has a nonzero entry in at least the direction its sign allows.

    The identity that does it #

    On the negative branch offDiag q d = 1 + a(d)·a(−d), and clearing denominators turns offDiag q d = 0 into q^{2d} + q^{−2d} = q^2 + q^{−2} — the statement that q^{2d} and q^2 have the same value under x ↦ x + x⁻¹. That map is two-to-one, and the two preimages are visible as a factorisation:

    A(q²−1)² − q²(A−1)² = −(A − q²)(A·q² − 1), where A = q^{2d}.

    So either q^{2d} = q^2 or q^{2d+2} = 1, and zpow_ne_one turns each into a statement about the exponent: d = 1 or d = −1. Nothing about the size of d is used — the bound |d| ≥ 2 is only how the caller rules both out — and no d ≠ 0 hypothesis is needed either: at d = 0 the else branch gives offDiag q 0 = 1, so the implication is vacuous there.

    §7c note: ℝ here is genuine — offDiag and seminormalParam are archimedean by construction.

    theorem QOU.SchurWeyl.SeminormalRep.eq_one_or_neg_one_of_offDiag_eq_zero {K : Type u_1} [Field K] (q : K) (hq0 : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) {d : ℤ} :
    offDiag q d = 0 → d = 1 ∨ d = -1

    offDiag vanishes only at d = ±1. Equivalently: away from the scalar (same-row / same-column) distances the off-diagonal entry of the generator matrix is nonzero.

    theorem QOU.SchurWeyl.SeminormalRep.offDiag_eq_zero_iff_eq_neg_one {K : Type u_1} [Field K] (q : K) (hq0 : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) {d : ℤ} :
    offDiag q d = 0 ↔ d = -1

    offDiag vanishes exactly at d = -1 — the biconditional, and it is stronger than the disjunction eq_one_or_neg_one_of_offDiag_eq_zero concludes.

    The d = 1 disjunct is never realised: offDiag takes the plain branch for every d ≥ 0 (offDiag_of_not_neg), so offDiag q 1 = 1 ≠ 0 in any field. Only the negative branch can vanish, and there the two-to-one argument leaves d = -1 alone.

    This is the honest _iff_ for this entry, and it is not the one the declaration's old name offDiag_eq_zero_iff promised. That name suggested offDiag q d = 0 ↔ d = 1 ∨ d = -1, whose reverse direction is false at d = 1 — so no amount of work could have produced it. Bean qou-y4ca asked whether that converse was true; it is not, and this is what the corpus licenses instead.

    theorem QOU.SchurWeyl.SeminormalRep.offDiag_axialDist_ne_zero {K : Type u_1} [Field K] (q : K) {μ : YoungDiagram} (hq0 : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) (T : Mathlib.StandardYoungTableau μ) {k : ℕ} (hk : k ∈ Set.Icc 1 μ.cells.card) (hk' : k + 1 ∈ Set.Icc 1 μ.cells.card) (hadm : TableauCells.SwapAdmissible T k) :
    offDiag q (TableauCells.axialDist T k) ≠ 0

    Admissible swaps carry a nonzero off-diagonal entry. Combines TableauCells.two_le_natAbs_axialDist with offDiag_eq_zero_iff_eq_neg_one: an admissible swap is at distance |d| ≥ 2, and offDiag vanishes only at d = -1.

    Retargeted from eq_one_or_neg_one_of_offDiag_eq_zero (bean qou-y4ca). The disjunction obliged this proof to dispatch a d = 1 case that cannot occur — offDiag q 1 = 1 ≠ 0 — so the rcases … <;> omega discharged one real case and one vacuous one. The biconditional supplies d = -1 directly.
