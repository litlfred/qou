    QOU.SchurWeyl.MarkovConventionD — the Markov condition, unconditionally, at every n #

    MarkovAssembly reduced the Markov condition for the weighted seminormal trace to a per-corner identity, taken there as a hypothesis. This file discharges that hypothesis at convention D, for every Young diagram and every removable corner — so the Markov condition itself holds unconditionally:

    ∑_{|λ| = m+2} W_λ · tr(ρ_λ(ι y) · σ_{m+1}) = z_D · ∑_{|ν| = m+1} W_ν · tr(ρ_ν(y))

    for every y ∈ H_{m+1}(q), with W = ocneanuWeight q z_D and z_D = q³/(q²+1).

    Why this needs no general-n arithmetic #

    The per-corner identity quantifies over every diagram, and OcneanuWeightMarkovCorner proves it only for the ≤2-row ones. The gap is closed by the convention-D vanishing rather than by more arithmetic, and the split is clean:

    • ≥3 rows — W_ν = 0, and adding a cell cannot reduce the row count, so every W_{ν+s} = 0 as well. Both sides are 0; no corner arithmetic is involved at all (corner_identity_of_three_rows).
    • ≤2 rows — the diagram is a twoRow (eq_twoRow_of_rowLen_two_eq_zero), it has at most three addable cells, and the third — (2,0) — produces a 3-row diagram of weight 0. What survives is exactly the two-term statement OcneanuWeightMarkovCorner proves (corner_identity_twoRow).

    So the two-term shape of that file, which looks like a restriction, is the general statement once the vanishing is applied.

    What this closes #

    OcneanuWeightWenzl's docstring names the remaining external input as "ocneanuWeight satisfies tr(x·σ_n) = z·tr(x) at general n". At convention D — the canonical one per the 2026-08-15 owner ruling — that is this file's markov_conventionD, and it is sorry-free. For arbitrary z the per-corner identity is still open; ocneanu_markov_corner_reduction.py tests it exactly at symbolic z through n = 6.

    Base ring (§7c) #

    Generic [Field K], matching seminormalParam and seminormalRep. The genericity hypothesis hgen : ∀ i, 0 < i → (q²)^i ≠ 1 is the standard not-a-root-of-unity condition. No ordering, no ℝ.
