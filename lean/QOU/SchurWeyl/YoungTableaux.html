    QOU.SchurWeyl.YoungTableaux — partitions and standard Young tableaux (bean SW-2) #

    The combinatorial index set of the quantum Schur–Weyl program: for n : ℕ,

    • the partitions λ ⊢ n as a Fintype (so one can ∑/⊕ over them), and
    • the standard Young tableaux (SYT) of shape λ, together with the Specht dimension dLambda λ := #SYT(λ) presented as a Fintype.card.

    What is reused vs. built here #

    Mathlib.Combinatorics.Young supplies YoungDiagram and SemistandardYoungTableau, and Mathlib.Combinatorics.Enumerative.Partition supplies Nat.Partition with a Fintype instance — but Mathlib (at the pinned toolchain v4.24.0) has no standard-tableau type, no #SYT(λ) count, and no Combinatorics.RSK.

    The in-repo QOU.Mathlib layer already fills the first two gaps: QOU.Mathlib.StandardYoungTableau is a genuine SYT (a SemistandardYoungTableau whose entry map bijects the cells onto {1,…,|μ|}; strict rows are derived, StandardYoungTableau.row_strict) carrying a Finite instance, and QOU.Mathlib.RSKBurnsideTarget provides partitionShape and dimSYT p = numStandardYoungTableaux (partitionShape p) (a Nat.card).

    This SW-2 file does not duplicate that machinery. It provides the Schur–Weyl-facing API and its one genuinely new piece: upgrading the existing Finite (StandardYoungTableau μ) to a Fintype, so dLambda can be presented as Fintype.card as the program requires, and proving that this Fintype.card agrees with the pre-existing Nat.card count (hence with dimSYT).

    Pure combinatorics on ℕ; nothing archimedean; no fit.

                theorem QOU.SchurWeyl.dLambda_eq_dimSYT {n : ℕ} (lam : Partition n) :
                dLambda lam = Mathlib.dimSYT lam

                dLambda λ (this file's Fintype.card) equals QOU.Mathlib.dimSYT λ (its Nat.card), so the Schur–Weyl-facing dimension is definitionally the same combinatorial number that the RSK/Burnside target ∑_{λ ⊢ n} dimSYT(λ)² = n! ranges over.

                source
                theorem QOU.SchurWeyl.sum_dLambda_sq_eq_iff (n : ℕ) :
                ∑ lam : Partition n, dLambda lam ^ 2 = n.factorial ↔ Mathlib.RSKBurnsideHolds n

                The RSK / Burnside target restated with this file's dLambda: ∑_{λ ⊢ n} dLambda(λ)² = n! is equivalent to QOU.Mathlib.RSKBurnsideHolds n. (This is a restatement, not a proof — the identity itself needs the RSK correspondence, absent from the pinned Mathlib; it is the target of bean SW-3.)
