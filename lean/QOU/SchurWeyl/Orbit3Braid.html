    QOU.SchurWeyl.Orbit3Braid — the size-3 S₃-orbit braid identity (bean qou-gjg6) #

    The braid relation for the general-λ seminormal representation reduces to one identity per ⟨s_k, s_{k+1}⟩-orbit of SYT λ. Orbits come in sizes 1, 2, 3 and 6; the generic size-6 case is Orbit6Braid, the size-1 and size-2 cases reduce to the scalar eigenvalues and the 2 × 2 template, and this file covers size 3.

    What a size-3 orbit is #

    The standard fillings of a domino together with a disjoint cell. The domino's two cells are adjacent, which forces their relative order, so only 3!/2! = 3 of the six assignments are standard. Writing the domino as A, B and the disjoint cell as C, the three fillings of {k, k+1, k+2} with entry A < entry B are

    0 : A=k, B=k+1, C=k+2 1 : A=k, B=k+2, C=k+1 2 : A=k+1, B=k+2, C=k

    and the two generators act as

    • σ_k — fixes filling 0 with the scalar sc, and a 2 × 2 block on {1,2};
    • σ_{k+1} — a 2 × 2 block on {0,1}, and fixes filling 2 with the same scalar sc.

    Each generator is therefore (scalar) ⊕ (2 × 2 block) — but on different summands, which is exactly why the orbit is 3-dimensional and not reducible to the 2 × 2 case, the same phenomenon as at size 6.

    The scalar is the size-1 eigenvalue of the domino: q when the domino lies in a row (axial distance +1) and -q⁻¹ when it lies in a column (-1), per axialDist_of_sameRow / axialDist_of_sameCol and seminormalParam_one / _neg_one.

    The two hypotheses, and why both are needed #

    hsc : sc * sc = c * sc + 1 — the scalar must itself satisfy the Hecke quadratic, i.e. sc is a root of X² - cX - 1, which for c = q - q⁻¹ means exactly sc ∈ {q, -q⁻¹}. Without it even the quadratic relation fails, since the scalar block would not satisfy σ² = cσ + 1.

    hrel : a₂ * (sc * (sc - a₁)) = a₁ — the two block parameters are not independent. They are a(d) and a(d ∓ 1) for the same underlying axial distance d (the domino shifts the distance by one), and eliminating d leaves exactly this relation. It is uniform across both domino orientations once written in terms of sc.

    Both were found by exact-rational search, and both are derived at the foot of this file (hsc_row / hsc_col, hrel_row / hrel_col) for the actual seminormal parameters — the role seminormalParam_mul_rel plays for Orbit6Braid. So the identity is a statement about the Hoefsmit matrices, not about abstract 3 × 3 arrays.

    Scope #

    This is the identity for one orbit, in an explicit basis ordering, exactly as Orbit6Braid is. Assembling the orbits of SYT λ into the representation — the enumeration, the orbit-size classification, and the per-orbit basis correspondence — is step (ii) of the general construction and remains open under bean qou-gjg6.

    Refs:

    • [hoefsmit1974] Hoefsmit, PhD thesis (UBC 1974) — the seminormal form.
    • [ram1997] Ram, Seminormal representations of Weyl groups and Iwahori–Hecke algebras, https://doi.org/10.1112/S0024611597000373 — the axial-distance formulas.

        The hypotheses, derived from seminormalParam #

        genA_genB_braid takes hsc and hrel as hypotheses. This section discharges both for the actual seminormal parameters, so the identity is a statement about the Hoefsmit matrices rather than about abstract arrays — the same role seminormalParam_mul_rel plays for Orbit6Braid.

        Multiplicative coordinates: x = q^{-2d} for the axial distance d of the 2 × 2 block, so a₁ = a(d) = (q - q⁻¹)/(1 - x). The domino shifts the second generator's distance by one, giving a₂ = a(d-1) at q²x for a row-domino and a₂ = a(d+1) at x/q² for a column one.
