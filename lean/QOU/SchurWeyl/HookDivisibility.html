    QOU.SchurWeyl.HookDivisibility — the Schur element divides the q-factorial #

    For a Young diagram μ with n cells, the Schur element of H_n(Q) is c_λ = Q^{−n(λ)} ∏_{x ∈ μ} [h(x)]_Q (HeckeSchurElements.schurElt_eq). This file proves, sorry-free, that [n]_Q! / c_λ is Q^{n(λ)} times an integer polynomial in Q:

    • hookProd_dvd_qFactorial — ∏_{x ∈ μ} [h(x)] ∣ ∏_{m=1}^{n} [m] in R[X], any commutative ring R.
    • exists_qFactorial_eq_schurElt_mul — [n]_Q! = c_λ(Q) · Q^{n(λ)} · P(Q) with P ∈ ℤ[X], in every field, for Q ≠ 0, 1.

    Route #

    [m] = ∏_{d ∣ m, d ≥ 2} Φ_d (Mathlib prod_cyclotomic_eq_geom_sum), so Φ_d occurs #{x : d ∣ h(x)} times in the hook product and ⌊n/d⌋ times in [n]!. The divisibility therefore reduces to the classical hook inequality

      d · #{x ∈ μ : d ∣ h(x)}  ≤  |μ|        (every d ≥ 1)          -- mul_card_filter_dvd_hook_le

    proved here with beta-sets (James's abacus). Row i gets the bead β_i = λ_i + (r − 1 − i); the column positions j + r − λ'_j are exactly the gaps below β_i (image_cval_row), and the hook of cell (i, j) is β_i − (j + r − λ'_j) (hook_eq). So #{x : d ∣ h(x)} = W_d(B), the number of (bead, lower gap) pairs on a common d-runner (card_filter_dvd_hook), and |μ| = W_1(B). The inequality d · W_d(B) ≤ W_1(B) (mul_weight_le) is elementary: W_d + P_d = Σ_b ⌊b/d⌋ (P_d = bead pairs on a runner), and b ↦ (b mod d) + d · (rank of b on its runner) is injective (abacus_injOn), so Σ (b mod d) + d · P_d ≥ C(|B|, 2) ≥ P_1.

    Nonnegativity (proved elsewhere) #

    That P has nonnegative coefficients — the fake-degree / maj formula [n]_Q!/∏[h] = Σ_{T ∈ SYT(λ)} Q^{maj(T) − n(λ)} — is not established by this route. It is proved in QOU.Mathlib.MajFormula (qFactorial_eq_schurElt_mul_fmaj, coeff_fmaj_nonneg; bean qou-q3q2). The integrality proved here is the polynomiality half.

    Base ring (§7c): the polynomial statements are over a generic [CommRing R]; the evaluation statement is over a generic [Field F]. No ordering or archimedean input.
