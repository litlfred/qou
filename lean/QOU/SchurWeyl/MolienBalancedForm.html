    QOU.SchurWeyl.MolienBalancedForm — M_μ(q²) = q^{−κ(μ)} / ∏_x [h(x)]_q #

    MolienSymmetrisingTrace defines the Molien weight in the geometric variable Q = q²,

    M_μ(Q) = Q^{n(μ)} · ∏_{x ∈ μ} (1 − Q) / (1 − Q^{h(x)}),

    and proves it is the weight of the symmetrising trace. This file proves the balanced form quoted in that module's docstring:

    M_μ(q²) = q^{−κ(μ)} / ∏_{x ∈ μ} [h(x)]_q,      [h]_q = (q^h − q^{−h}) / (q − q^{−1}),

    with κ(μ) = Σ_x c(x) the content sum.

    Proof #

    • One cell. (1 − q²)/(1 − q^{2h}) = q^{1−h} / [h]_q (molien_cell). When q^{2h} = 1 both sides are 0 in Lean's division convention, so no genericity on the hooks is needed.
    • Exponents. Multiplying out gives q^{2 n(μ) + |μ| − Σ_x h(x)}. The hook-sum identity Σ_x h(x) = Σ_x j + Σ_x i + |μ| (BraidKnot.HookSum.sum_hookZ_eq, with n(μ) = Σ_x i and κ(μ) = Σ_x j − Σ_x i) makes the exponent −κ(μ) (sum_hook_eq).

    Base ring (§7c) #

    Generic [Field F]; the only hypotheses are q ≠ 0 and q² ≠ 1 (so that [h]_q is defined by the usual quotient). Nothing archimedean.
