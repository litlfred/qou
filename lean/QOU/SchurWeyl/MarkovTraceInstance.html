    QOU.SchurWeyl.MarkovTraceInstance — the Ocneanu weight is the Markov trace #

    This is where the tranche closes. MarkovConventionD and MarkovNormalisation proved the two defining properties of the weight; MarkovTraceUnique proved that a Markov trace is determined by its parameter, but about an abstract structure with no instance. This file builds the instance and draws the conclusion:

    ocneanuMarkovTrace : MarkovTraceFamily K q q⁻¹ (q³/(q²+1))
eq_wtrace_of_markov : ∀ T : MarkovTraceFamily K q q⁻¹ (q³/(q²+1)), ∀ n x, T.tr n x = wtrace … n x

    Every Markov trace on the Hecke tower with parameter z_D is the Ocneanu-weighted seminormal trace. That is the statement QOU/QBeta/WenzlWeightVanishing.lean cites Wenzl for, and at convention D it is now proved rather than cited.

    The two properties this file adds #

    wtrace is x ↦ ∑_{|ν| = n+1} W_ν · tr(ρ_ν x), as a bundled →ₗ[K]. Two of the four MarkovTraceFamily fields were already proved elsewhere (markov_conventionD, sum_dim_weight_eq_one); the other two are here:

    • cyclicity — seminormalRep is an AlgHom, so this is Matrix.trace_mul_comm blockwise.
    • consistency tr_{n+1}(ι x) = tr_n x — the corner decomposition once more, without the σ factor. trace_eq_sum_compress splits the diagonal sum over the corners (no block hypothesis needed — the trace is a sum over SYT μ and branchEquiv is a bijection onto it), compress_seminormalRep_heckeIncl identifies each block with the downstairs matrix, and ocneanuWeight_addable_sum closes the reindexed weight sum.

    Scope — read before quoting this #

    • Convention D only. z = q³/(q²+1). Nothing here says anything about other z.
    • Hypotheses: q ≠ 0, q² ≠ 1, q² + 1 ≠ 0, and the genericity condition ∀ i > 0, (q²)^i ≠ 1 — i.e. q² is not a root of unity. At a root of unity H_n(q) is not semisimple and partitions stop indexing the irreducibles, so the statement would need a different formulation, not a better proof.
    • The uniqueness half is generic [CommRing K]; the instance is over any field K.

    Base ring (§7c) #

    Generic [Field K], matching seminormalRep and seminormalParam; q² + 1 ≠ 0 and the genericity of q² are explicit hypotheses. No ordering, no ℝ.
