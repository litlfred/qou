    QOU.SchurWeyl.QJucysMurphyEigen — the q-Jucys–Murphy eigenvalue (bean qou-t8qh) #

    Ram (1997) Thm 4.1: on the seminormal representation the Jucys–Murphy element L_k acts diagonally, with eigenvalue q^{2·cellContent} at the cell holding the corresponding value.

    This is the one input still missing from QJucysMurphy.barSymJMSum_block_eigenvalue — the last real sorry in the SchurWeyl tree. (Its other blocker, hoefsmit_seminormal_rep, is proved.)

    The crux, and why the theorem is true #

    The recursion is pure conjugation, L_{k+1} = σ_k L_k σ_k, so the inductive step conjugates a diagonal matrix D by S = genMat q (k+1). For that to stay diagonal the off-diagonal of S · D · S must vanish, and on a size-2 orbit it is

    offDiag(-d) · (a(d)·q^{2c} + a(-d)·q^{2(c+d)}),

    with a = seminormalParam and d the axial distance. The bracket is identically zero:

    1/(1 - q^{-2d}) = -q^{2d}/(1 - q^{2d}),

    which is seminormalParam_weighted_cancel below. On a size-1 orbit S is already diagonal with entry a(±1), and a(1) = q, a(-1) = -q⁻¹, so a(d)² = q^{2d} — exactly the content shift.

    Base ring ℝ (the seminormal parameters are archimedean, §7c).

    seminormalParam q d * q ^ (2 * c) + seminormalParam q (-d) * q ^ (2 * (c + d)) = 0

    The weighted cancellation behind the JM eigenvalue. Weighting the two seminormal parameters of a size-2 orbit by the q^{2·content} of their own cells makes them cancel:

    a(d)·q^{2c} + a(-d)·q^{2(c+d)} = 0.

    This is exactly the off-diagonal of S · D · S on that orbit, so it is what keeps the conjugate of a diagonal matrix diagonal — the inductive step of Ram's Theorem 4.1.

    The full entry-level inductive step #

    Both entries of S · D · S on a size-2 orbit reduce to the same cancellation. Writing c for the content seen by D at T and c + d for the one at s·T:

    • the off-diagonal is offDiag(d) · (a(d)q^{2c} + a(-d)q^{2(c+d)}), which is 0;
    • the diagonal is a(d)²q^{2c} + offDiag(-d)offDiag(d)·q^{2(c+d)}, and using offDiag_mul_neg (offDiag(d)offDiag(-d) = 1 + a(d)a(-d)) it collapses to a(d)·(a(d)q^{2c} + a(-d)q^{2(c+d)}) + q^{2(c+d)} = q^{2(c+d)}.

    So one identity governs the whole step — which is why the induction closes.

        From the per-element eigenvalues to the block scalar #

        Ram 4.1 gives one diagonal matrix per k. What makes Θ = Σ_k (L_k + L_k⁻¹) a scalar is that summing over k = 0,…,n sweeps every cell of μ exactly once, in an order that depends on T but whose total does not.

        source
        theorem QOU.SchurWeyl.SeminormalRep.sum_cellOf_range {μ : YoungDiagram} {M : Type u_1} [AddCommMonoid M] (T : Mathlib.StandardYoungTableau μ) {n : ℕ} (hN : μ.cells.card = n + 1) (f : ℕ × ℕ → M) :
        ∑ k ∈ Finset.range (n + 1), f (TableauCells.cellOf T (k + 1)) = ∑ c ∈ μ.cells, f c

        Reindexing over a tableau's values. k ↦ cellOf T (k+1) is a bijection range (n+1) → μ.cells — its inverse is c ↦ T.entry c − 1 — because the entry map of a standard tableau is a bijection from the cells onto {1,…,|μ|}. So a sum indexed by the values is a sum over the cells, and in particular is independent of T.

        The block eigenvalue, packaged on Fin (dLambda lam) #

        This is the statement QJucysMurphy carried as a sorry, discharged — with one hypothesis it was missing. See barSymJMSum_block_eigenvalue_zero_false below: at N = 0 the statement is not merely unproved, it is false, so 0 < N is not bookkeeping.

        source
        theorem QOU.SchurWeyl.barSymJMSum_block_eigenvalue_of_pos {N : ℕ} {K : Type u_1} [Field K] (q : K) (hq0 : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) (hNpos : 0 < N) (lam : Partition N) :
        ∃ (ρ : Hecke K q q⁻¹ (N - 1) →ₐ[K] Matrix (Fin (dLambda lam)) (Fin (dLambda lam)) K), ρ (barSymJMSum K q q⁻¹ (N - 1)) = cellContentCoshSum lam q • 1

        Block eigenvalue of Θ on the irreducible ρ_λ — PROVED, for 0 < N.

        For every λ ⊢ N with N ≥ 1 the seminormal representation ρ_λ : H_{N-1}(q) →ₐ M_{d_λ}(ℝ) sends the central bar-symmetrised Murphy sum Θ = Σ_k (L_k + L_k⁻¹) to the scalar matrix (Σ_{c∈λ} (q^{2c} + q^{−2c}))·1 = cellContentCoshSum λ q · 1.

        The two ingredients: seminormalRep_qJM (Ram (1997) Thm 4.1 — L_k is diagonal with entry q^{2·content} at the cell holding k+1) and sum_cellOf_range (summing over k sweeps every cell once, so the diagonal is constant).

        q ≠ 0 with q ^ 2 ≠ 1 says over ℝ exactly that q is not a root of unity — the genericity [ram1997] presupposes, and what seminormalRep takes. It is weaker than the 0 < q ∧ q ≠ 1 the sorry'd version asked for: negative q is admitted here.

        Refs: [ram1997] Theorem 4.1; [hoefsmit1974]; [murphy1992].

        The N = 0 case is false — recorded, not silently excluded.

        Θ at n = 0 is L_0 + L_0⁻¹ = 1 + 1, which every algebra map sends to 2 · 1, while the empty partition's cellContentCoshSum is the empty sum 0. Since d_λ ≥ 1 always (instNonemptyStandardYoungTableau), the matrix algebra is nontrivial and 2 · 1 ≠ 0.

        Hence the 0 < N hypothesis on barSymJMSum_block_eigenvalue_of_pos is not an artefact of the proof route: the statement without it is refutable.

        (2 : K) ≠ 0 is a real hypothesis, not bookkeeping. Over ℝ the contradiction was 1 + 1 = 0 in the block algebra, closed by simp on a diagonal entry. In characteristic two that equation holds, so this statement is false there and the refutation needs the characteristic assumption. It is the one place in the general-field tranche (bean qou-j377) where the migration is not a pure retyping. The mismatch is a normalisation one — Θ counts k = 0,…,n (that is n+1 = N Murphy elements, one per cell, correct for N ≥ 1), and at N = 0 the ℕ-truncated N - 1 = 0 makes the range one term long against zero cells.
