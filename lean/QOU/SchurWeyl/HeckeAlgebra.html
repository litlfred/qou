    QOU.SchurWeyl.HeckeAlgebra — the Iwahori–Hecke algebra H_n(q) (bean SW-1) #

    Self-contained definition of the type-A_{n-1} Iwahori–Hecke algebra H_n(q) for the quantum-Schur–Weyl program (epic bean SW, this file is bean SW-1). Mathlib has Coxeter groups but no Hecke algebra, so we build it directly as a RingQuot of a free algebra.

    Convention #

    We follow the QOU Hecke–skein convention (AGENTS.md §7a):

    • quadratic (σ_i - q)(σ_i + q⁻¹) = 0, equivalently σ_i² = (q - q⁻¹)·σ_i + 1;
    • braid σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1};
    • far commutation σ_i σ_j = σ_j σ_i for |i - j| ≥ 2.

    To stay over a generic CommRing K (AGENTS.md §7c — start generic; specialise only when forced) we carry the inverse of q as an explicit scalar qi : K intended as q⁻¹. The quadratic relation is then stated in the inverse-free polynomial form

    σ_i² = (q - qi)·σ_i + (q·qi)·1,

    which specialises to the QOU form σ_i² = (q - q⁻¹)·σ_i + 1 the moment qi = q⁻¹ (q * qi = 1). No inverses appear in the defining ideal, so K need only be a commutative ring; a Field K or [Invertible q] is required only for the skein / units statements at the end.

    What is delivered here #

    • Hecke K q qi n — the algebra, as RingQuot (HeckeRel …); carries the canonical (non-commutative) Ring and Algebra K structure.
    • σ i — the generators; σ_quadratic, σ_braid, σ_commute, σ_quadratic_factored — the defining relations hold (sorry-free).
    • Universal property (Hecke.lift, lift_σ, hom_ext): an algebra map H_n(q) →ₐ[K] A is given by any family g : Fin (n-1) → A satisfying the three relations, and is uniquely determined by the images of the generators. This is the interface downstream reps (Hoefsmit, bean SW-4) consume: to build a representation it suffices to give matrices satisfying the Hecke relations.

    The n!-dimensional T_w-basis (Matsumoto / Bott–Samelson) is not claimed here — it is a separate, deep result.

    Refs:

    • [kassel1995] Ch. XII (Hecke algebras, Jones polynomial), https://doi.org/10.1007/978-1-4612-0783-2

    inductive QOU.SchurWeyl.HeckeRel (K : Type u_1) [CommRing K] (q qi : K) (n : ℕ) :
    FreeAlgebra K (Fin n) → FreeAlgebra K (Fin n) → Prop

    The defining relations of the type-A_{n-1} Iwahori–Hecke algebra on n generators σ_0, …, σ_{n-1}, as a RingQuot relation on FreeAlgebra K (Fin n). qi is the intended inverse of q.

    • quadratic {K : Type u_1} [CommRing K] {q qi : K} {n : ℕ} (i : Fin n) : HeckeRel K q qi n (FreeAlgebra.ι K i * FreeAlgebra.ι K i) ((q - qi) • FreeAlgebra.ι K i + (q * qi) • 1)

      σ_i² = (q - qi)·σ_i + (q·qi)·1 (⇔ (σ_i - q)(σ_i + qi) = 0).

    • braid {K : Type u_1} [CommRing K] {q qi : K} {n : ℕ} (i : Fin n) (hi : ↑i + 1 < n) : HeckeRel K q qi n (FreeAlgebra.ι K i * FreeAlgebra.ι K ⟨↑i + 1, hi⟩ * FreeAlgebra.ι K i) (FreeAlgebra.ι K ⟨↑i + 1, hi⟩ * FreeAlgebra.ι K i * FreeAlgebra.ι K ⟨↑i + 1, hi⟩)

      σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1}.

    • commute {K : Type u_1} [CommRing K] {q qi : K} {n : ℕ} (i j : Fin n) (h : ↑j + 2 ≤ ↑i) : HeckeRel K q qi n (FreeAlgebra.ι K i * FreeAlgebra.ι K j) (FreeAlgebra.ι K j * FreeAlgebra.ι K i)

      σ_i σ_j = σ_j σ_i for |i - j| ≥ 2 (stated for j + 2 ≤ i; the generated congruence is symmetric).

            Universal property #

            H_n(q) is the free K-algebra on generators satisfying the Hecke relations. Concretely: any target algebra map is built from a family of images that satisfy the relations (lift), and two algebra maps out of H_n(q) agreeing on the generators are equal (hom_ext).

              Skein form and units (require q invertible) #

              With qi a genuine inverse of q the quadratic relation becomes the QOU canonical form σ_i² = (q - q⁻¹)·σ_i + 1, and each generator is a unit — so the braid group maps into H_n(q)ˣ (the Hecke representation of braids). This is the only place inverses of q are used.
