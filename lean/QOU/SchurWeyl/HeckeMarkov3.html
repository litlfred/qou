    QOU.SchurWeyl.HeckeMarkov3 — the weighted-character (Markov) trace on H_3(q) (SW-8, n=3) #

    Under the Wedderburn iso H_3(q) ≅ ℝ × ℝ × M₂(ℝ) (HeckeWedderburn3), any Markov trace is a weighted character sum tr_M = Σ_λ w_λ χ_λ — the QOU Frobenius pairing and the partition-function reading of the trace (R1). Here we build that functional concretely at n = 3,

    markovTrace3 w₀ w₁ w₂ (x) = w₀·χ_{(3)}(x) + w₁·χ_{(1³)}(x) + w₂·χ_{(2,1)}(x),

    with χ_{(3)} = rhoTriv, χ_{(1³)} = rhoSign, and χ_{(2,1)} = trace ∘ seminormalRep21, and prove the two structural facts a Markov trace must have:

    • trace property markovTrace3 (x·y) = markovTrace3 (y·x) (markovTrace3_mul_comm) — each summand is the character of a representation, and characters are class functions (Matrix.trace_mul_comm for the (2,1) block);
    • value at 1 markovTrace3 1 = w₀ + w₁ + 2 w₂ = Σ_λ w_λ d_λ (markovTrace3_one) — the degeneracy-weighted block count (d_{(2,1)} = 2).

    Plus the concrete H_3(q) character values on the generators (char21_σ, char21_σ0σ1): χ_{(2,1)}(σ_i) = q - q⁻¹ and χ_{(2,1)}(σ₀σ₁) = -1.

    The canonical Ocneanu/HOMFLY normalisation of the weights w_λ (the choice of Markov parameter fixing the 1-parameter family, giving the Jones polynomial) is a separate normalisation step, tracked under qou-tpl5.

    Base ring ℝ (the (2,1) seminormal rep is archimedean, §7c).

    LaTeX label: prop:hecke3-markov-weighted-character References: Jones (1987) [jones1987], Wenzl (1988) [wenzl1988].

      Canonical Ocneanu/HOMFLY Markov weights for H_3(q) (bean qou-tpl5) #

      The three n = 3 character constraints leave the weight vector (w₀, w₁, w₂) free along a one-parameter family; the canonical (Ocneanu/Jones–HOMFLY) trace fixes the family by the recursive Markov property

      tr_M(x · σ_{n-1}) = z · tr_M(x) for x ∈ H_{n-1},

      with z the Markov parameter, together with the normalisation tr_M(1) = 1.

      Derivation. H_2 = ⟨σ₀⟩ ⊂ H_3 has basis {1, σ₀}. The Markov property applied one level down (x = 1, generator σ₀) gives tr_M(σ₀) = z·tr_M(1) = z; applied at the top level to x ∈ {1, σ₀} (generator σ₁) gives tr_M(σ₁) = z and tr_M(σ₀σ₁) = z·tr_M(σ₀) = z². Writing each of the three values tr_M(1) = 1, tr_M(σ₀) = z, tr_M(σ₀σ₁) = z² as the weighted character sum and solving the resulting 3×3 linear system

        w₀ + w₁ + 2 w₂           = 1
  w₀ q - w₁ q⁻¹ + w₂(q-q⁻¹) = z
  w₀ q² + w₁ q⁻² - w₂       = z²

      yields the closed forms below. All denominators — q²+1 and q⁴+q²+1 — are strictly positive for real q, so the weights are defined for every q ≠ 0; z remains the free Ocneanu parameter.

      These are derived, then checked: the normalisation markovWeights_one, the one-level markovWeights_σ0, and the two top-level Markov relations markovWeights_markov_σ1, markovWeights_markov_σ0σ1 are all proved below as concrete field identities, so a wrong weight would fail the check.

      References: Jones (1987) [jones1987], Wenzl (1988) [wenzl1988].
