    QOU.SchurWeyl.WenzlWeightLevelR — the normalised Wenzl weight at a general level r #

    The convention-D chain proved in PR #5575 — vanishing, branching, normalisation, uniqueness — is stated at Wenzl level r = 2, because that is where convention D sits (wenzlLevel_conventionD). Nothing in the vanishing half needs r = 2: QBeta.WenzlWeight.schurPrincipal_eq_zero_iff is already general in r, and it was only the downstream specialisation that fixed the level. This file removes that specialisation.
    levelBracket r Q 1 + Q + ⋯ + Q^{r−1}, the level-r principal specialisation of the one-box Schur function
    wenzlWeight r Q μ s_μ(1, Q, …, Q^{r−1}) / [r]_Q^{|μ|} — the normalised weight at level r
    wenzlWeight_eq_zero_iff w_μ = 0 ⟺ ℓ(μ) > r, for every n, every μ and every level r
    wenzlMarkovParam_eq Wenzl's z_W = Q^r(1−Q)/(1−Q^r) is Q^r / [r]_Q
    wenzlWeight_two_eq_ocneanuWeight at r = 2, Q = q² this is the convention-D Ocneanu weight
    wenzlMarkovParam_conventionD and its Markov parameter is q · z_D

    Why the last two rows matter #

    A generalisation that does not contain its own special case is a different object wearing the same name. The two convention-D theorems are the evidence that this one does: at r = 2, Q = q² the normalised level-r weight is definitionally the weight the merged chain works with, and its level-r Markov parameter is definitionally q · z_D. So every statement proved here at general r specialises back to a statement about the object PR #5575 proved things about, rather than to a lookalike.

    Branching at general r — proved downstream, not here #

    Status corrected 2026-08-24 (bean qou-4a68). This section previously recorded general-r branching as an open item on bean qou-j7ln. It is proved, sorry-free, in the files that import this one:

    • BranchingGenericity.sum_schurPrincipal_addCellOrSelf — the identity itself, ∑_{s addable to μ} s_{μ+s}(1, …, Q^{r−1}) = [r]_Q · s_μ(1, …, Q^{r−1});
    • AddableCellIndexing.sum_addable_wenzlWeight — the same for the normalised weight, in the addable-cell subtype indexing the corner exchange hands over;
    • WenzlNormalisation.sum_addable_wenzlWeight_all — with the row-count hypothesis removed.

    The pessimism this section used to record was about a route, and the route was avoidable. That identity is Pieri's rule at the principal specialisation — Orellana's Lemma 5.1 [orellana1998], proved there by the Littlewood–Richardson rule on the integer-level lattice Q = −q^{r₁+m} followed by rational continuation — and neither half is in Mathlib. The proof that landed does not go through either: it works directly from schurPrincipal_addCell_eq's per-row β-factor form, with the four non-vanishing side conditions all derived from the single hgen. So "not in Mathlib" was true and "therefore open here" did not follow.

    What remains true is the reading of the two-row case: OcneanuWeightBranching rests on schurPrincipal_twoRow, a closed form that exists because the hook-content product telescopes for a two-row diagram, and there is no such telescoping at general r. The general-r proof replaces the telescoping with the β-factor identity rather than recovering it.

    Base ring (§7c) #

    Generic [Field R] throughout — a rational function of Q. No ordering, no Real.sqrt, no ℝ.

    The level bracket #

    source
    noncomputable def QOU.SchurWeyl.levelBracket {R : Type u_1} [Field R] (r : ℕ) (Q : R) :
    R

    [r]_Q = 1 + Q + ⋯ + Q^{r−1}.

    This is s_{[1]}(1, Q, …, Q^{r−1}), the principal specialisation of the one-box Schur function — the factor Wenzl's normalisation divides by, once per cell.

      The normalised weight #

      source
      noncomputable def QOU.SchurWeyl.wenzlWeight {R : Type u_1} [Field R] (r : ℕ) (Q : R) (mu : YoungDiagram) :
      R

      The normalised Wenzl weight at level r.

      w_μ^{(r)}(Q) = s_μ(1, Q, …, Q^{r−1}) / [r]_Q^{|μ|}.

      The normalisation is the one that makes ∑_{μ ⊢ n} f^μ w_μ = tr(1) = 1: each of the n cells contributes one factor of [r]_Q, which is exactly what the branching identity consumes.

        Wenzl's Markov parameter at level r #

        source
        theorem QOU.SchurWeyl.wenzlMarkovParam_eq {R : Type u_1} [Field R] (r : ℕ) (Q : R) (hbr : levelBracket r Q ≠ 0) (hQ1 : 1 - Q ≠ 0) :
        Q ^ r * (1 - Q) / (1 - Q ^ r) = Q ^ r / levelBracket r Q

        Wenzl's level-r Markov parameter, in bracket form.

        z_W = Q^r(1−Q)/(1−Q^r) = Q^r / [r]_Q.

        The (1−Q)/(1−Q^r) of the literature is 1/[r]_Q once the geometric factor is cancelled; the bracket form is the one that survives Q = 1, and the one the normalisation of wenzlWeight is stated in.
