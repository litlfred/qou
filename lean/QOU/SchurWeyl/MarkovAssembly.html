    QOU.SchurWeyl.MarkovAssembly — the λ-sum, and the Markov condition modulo one identity #

    SeminormalCornerTrace decomposed the block trace over the removable corners of a single λ. YoungDiagramCornerReindex supplied the exchange (λ, removable corner) ↔ (λ ∖ c, addable corner) as a double-sum reindexing. This file runs the two together and consumes OcneanuWeightMarkovCorner's per-corner identity, giving the Markov condition itself:

    ∑_{|λ| = m+2} w_λ · tr(ρ_λ(ι y) · σ_{m+1}) = z · ∑_{|ν| = m+1} w_ν · tr(ρ_ν(y))

    for every y ∈ H_{m+1}(q).

    What it is conditional on, and what that is worth #

    The corner identity is a hypothesis of markov_of_corner_identity, not an axiom and not a sorry:

    ∀ ν with |ν| = m+1, ∀ removable corner r of ν: ∑_{s addable to ν} w_{ν+s} · a(c(s) − c(r)) = z · w_ν.

    So what is proved here is the reduction: the Markov condition for the weighted seminormal trace is that finite arithmetic identity, for any weight function whatever. Everything representation-theoretic — the branching decomposition, the block structure of σ_{m+1}, the Hoefsmit entry, the reindexing — is discharged. OcneanuWeightMarkovCorner proves the hypothesis at convention D for the ≤2-row diagrams the trace lives on; the general-n statement is what computations/schurweyl/ocneanu_markov_corner_reduction.py tests exactly at symbolic z for every partition of n ≤ 6.

    This closes step 3 of bean qou-uer7 — and with it the assembly the file docstrings of OcneanuWeightMarkovCorner and SeminormalBlockEquality both flag as missing. Those flags are now stale in one direction: the reduction is formalised; the corner identity at general n is not.

    theorem QOU.SchurWeyl.SeminormalRep.markov_of_corner_identity {K : Type u_1} [Field K] {q z : K} (hq0 : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) {m : ℕ} (w : YoungDiagram → K) (hcorner : ∀ (ν : YoungDiagram), ν.cells.card = m + 1 → ∀ (r : ℕ × ℕ), Mathlib.IsCornerCell ν r → ∑ s : { s : ℕ × ℕ // Mathlib.IsAddableCell ν s }, w (Mathlib.addCell ν ↑s ⋯) * Seminormal.seminormalParam q (axialDistance r ↑s) = z * w ν) (y : Hecke K q q⁻¹ m) :
    ∑ L : { ρ : YoungDiagram // ρ.cells.card = m + 2 }, w ↑L * ((seminormalRep q hq0 hq2 (m + 1) ⋯) ((HeckeInclusion.heckeIncl K q q⁻¹ m) y) * genMat q (m + 1) ⋯ ⋯).trace = z * ∑ ν : { ν : YoungDiagram // ν.cells.card = m + 1 }, w ↑ν * ((seminormalRep q hq0 hq2 m ⋯) y).trace

    The Markov condition, modulo the corner identity. For any weight function w satisfying the per-corner identity, the w-weighted seminormal trace of ι y · σ_{m+1} over the diagrams of size m + 2 is z times the w-weighted trace of y over those of size m + 1.

    The proof is the three steps the bean names: decompose each block trace over corners (trace_heckeIncl_mul_lastGen_corner), reindex the resulting double sum (sum_corner_eq_sum_addable), then swap the inner sums so the corner identity applies at r = the cell carrying each downstairs tableau's top entry.
