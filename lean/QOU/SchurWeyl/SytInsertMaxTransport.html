    QOU.SchurWeyl.SytInsertMaxTransport — the tableau side of the branching compatibility #

    SeminormalBlockTrace reduced the Markov condition, for a single V_λ, to a sum of diagonal entries. Turning that into the Markov condition itself needs one more structural fact:

    the seminormal representation of λ, restricted to the block of an addable corner s, is the seminormal representation of μ = λ ∖ s.

    genMat's entry rules read exactly four things about a tableau — cellOf, axialDist, SwapAdmissible, and swapTableau — so that fact reduces to their compatibility with QOU.Mathlib.insertMax, the corner-insertion map whose bijectivity SYTBranchingRule already proves. This file supplies all four, plus injectivity of insertMax at a fixed corner.

    lemma content
    cellOf_insertMax inserting the max does not move any smaller entry's cell
    axialDist_insertMax hence axial distances at smaller entries are unchanged
    swapAdmissible_insertMax_iff SwapAdmissible is defined from cellOf, so it transfers
    swapTableau_insertMax insertMax intertwines the partial s_k-action
    insertMax_injective at a fixed corner, insertMax changes only the cell c

    What is still missing #

    These are the ingredients, not the conclusion. The block equality itself — genMat_λ q k (insertMax S'') (insertMax S') = genMat_μ q k S'' S' — is a case analysis over genMat's three branches using the five lemmas above, and is not written here. Nor is the outer reindexing {(λ, corner)} ↔ {(μ, addable corner)} that the λ-sum needs, though SYTBranchingRule.branchInv (bijective) supplies the inner half of it.

    theorem QOU.SchurWeyl.TableauCells.cellOf_insertMax {μ : YoungDiagram} (c : ℕ × ℕ) (hc : Mathlib.IsCornerCell μ c) (S : Mathlib.StandardYoungTableau (Mathlib.eraseCorner μ c hc)) {k : ℕ} (hk : k ∈ Set.Icc 1 (Mathlib.eraseCorner μ c hc).cells.card) :
    cellOf (Mathlib.insertMax c hc S) k = cellOf S k

    insertMax does not move the cell of any smaller entry.

    theorem QOU.SchurWeyl.TableauCells.axialDist_insertMax {μ : YoungDiagram} (c : ℕ × ℕ) (hc : Mathlib.IsCornerCell μ c) (S : Mathlib.StandardYoungTableau (Mathlib.eraseCorner μ c hc)) {k : ℕ} (hk : k ∈ Set.Icc 1 (Mathlib.eraseCorner μ c hc).cells.card) (hk1 : k + 1 ∈ Set.Icc 1 (Mathlib.eraseCorner μ c hc).cells.card) :
    axialDist (Mathlib.insertMax c hc S) k = axialDist S k

    Hence insertMax preserves the axial distance at any pair of smaller entries.

    theorem QOU.SchurWeyl.TableauCells.swapAdmissible_insertMax_iff {μ : YoungDiagram} (c : ℕ × ℕ) (hc : Mathlib.IsCornerCell μ c) (S : Mathlib.StandardYoungTableau (Mathlib.eraseCorner μ c hc)) {k : ℕ} (hk : k ∈ Set.Icc 1 (Mathlib.eraseCorner μ c hc).cells.card) (hk1 : k + 1 ∈ Set.Icc 1 (Mathlib.eraseCorner μ c hc).cells.card) :
    SwapAdmissible (Mathlib.insertMax c hc S) k ↔ SwapAdmissible S k

    SwapAdmissible is defined from cellOf, so it too transfers.

    source
    theorem QOU.SchurWeyl.TableauCells.swapTableau_insertMax {μ : YoungDiagram} (c : ℕ × ℕ) (hc : Mathlib.IsCornerCell μ c) (S : Mathlib.StandardYoungTableau (Mathlib.eraseCorner μ c hc)) {k : ℕ} (hk : 1 ≤ k) (hkn : k + 1 ≤ (Mathlib.eraseCorner μ c hc).cells.card) (hadm : SwapAdmissible S k) (hadm' : SwapAdmissible (Mathlib.insertMax c hc S) k) :
    swapTableau (Mathlib.insertMax c hc S) k hk ⋯ hadm' = Mathlib.insertMax c hc (swapTableau S k hk hkn hadm)

    insertMax intertwines the partial s_k-action: swapping then inserting is inserting then swapping. With axialDist_insertMax and swapAdmissible_insertMax_iff this is everything genMat's entry rules read, so the seminormal matrix of a generator that avoids the top entry has the same entries on the block as it does downstairs.
