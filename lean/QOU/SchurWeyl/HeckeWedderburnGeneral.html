    QOU.SchurWeyl.HeckeWedderburnGeneral — the Wedderburn split of H_{n+1}(q), for every n #

    SW-7 (qou-0h5k). Counting turns the surjection of HeckeProductSurjective into an isomorphism:

    H_{n+1}(q)  ≃ₐ[ℝ]  ∏_{λ ⊢ n+1} M_{#SYT λ}(ℝ)

    for every real q that is not a root of unity.

    The direction of the count is what makes this work #

    The q = 1 file BraidKnot.SpechtWedderburnGeneral goes injective + equal finrank. That route is unavailable here: the corpus has HeckeCoset.finrank_le_factorial (dim H ≤ (n+1)!) but not the matching lower bound, which is the open Gröbner–Shirshov item qou-auq3 — and injectivity together with dim source ≤ dim target gives nothing.

    Running it through surjectivity inverts the dependency. A surjection forces dim target ≤ dim source; the corpus supplies dim source ≤ (n+1)!; and SW-3 — now available at every n (QOU.Mathlib.rskBurnsideHolds) — makes dim target = Σ_λ d_λ² = (n+1)!. The two inequalities close, so the map is bijective and

    `finrank ℝ (H_{n+1}(q)) = (n+1)!`

    falls out (finrank_hecke_eq_factorial) — the Iwahori–Hecke basis theorem's lower bound, obtained without the Gröbner–Shirshov route rather than waiting on it.

    theorem QOU.SchurWeyl.finrank_hecke_eq_factorial {K : Type u_1} [Field K] [CharZero K] (q : K) (hq0 : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) (n : ℕ) :
    Module.finrank K (Hecke K q q⁻¹ n) = (n + 1).factorial

    dim H_{n+1}(q) = (n+1)! — the Iwahori–Hecke basis theorem, both bounds.

    The upper bound is HeckeCoset.finrank_le_factorial. The lower bound is not proved by hand here: it is forced by the surjection onto a space of dimension (n+1)!. So the Gröbner–Shirshov route (qou-auq3) is not on the critical path for this statement.
