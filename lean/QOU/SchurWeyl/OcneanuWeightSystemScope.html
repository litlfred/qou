    QOU.SchurWeyl.OcneanuWeightSystemScope — why the identification does not discharge IsOcneanuWeightSystem #

    MarkovTraceInstance proves that ocneanuWeight at convention D is the Markov trace. The natural next thought is that this discharges the corpus's conditional-class carrier of Wenzl's theorem, QBeta.WenzlWeight.IsOcneanuWeightSystem, letting downstream statements drop their [IsOcneanuWeightSystem …] hypothesis. It does not, and this file proves why, so that nobody spends a session trying.

    The mismatch #

    The class asks for a single normaliser:

    weight_eq_schurPrincipal : ∃ Z, Z ≠ 0 ∧ ∀ μ, y μ = schurPrincipal r Q μ / Z

    Z is quantified outside ∀ μ. The true relation, ocneanuWeight_conventionD_eq_schurPrincipal, carries a normaliser that depends on the size of μ:

    ocneanuWeight q z_D μ = schurPrincipal 2 (q²) μ / (q² + 1)^{|μ|}

    and those are incompatible unless q² + 1 = 1. not_isOcneanuWeightSystem is that argument: evaluate at ⊥ (where |μ| = 0 and the weight is 1) to force Z = 1, then at a single cell (where |μ| = 1 and the weight is nonzero) to force q² + 1 = 1, hence q = 0.

    Scope of this negative result — read before quoting it #

    This is a structural exclusion in the sense of AGENTS.md §"Before declaring refuted": it rests on a proved invariant (the bridge, plus ocneanuWeight_bot and the one-cell non-vanishing), not on a failed search. But it is narrow, and two things it does not say:

    • It does not say the class is wrong. For an unnormalised y a single Z is exactly right — take Z = 1 and y = schurPrincipal r Q. The class is inhabitable; it is just not inhabited by a per-size-normalised weight family.
    • It does not say the corpus is inconsistent. What it shows is a gap between the class's prose — the file header describes the weights as "normalised so that Σ_λ f^λ y_λ = 1" — and its fields, which encode no normalisation and whose Z cannot vary with |μ|. Per-size normalisation is proved for ocneanuWeight (sum_dim_weight_eq_one), so the two cannot both hold of one weight family.

    The resolution is an authoring decision for whoever owns that class — index Z by the size, or drop the normalisation from the prose — and is deliberately not made here.

    Base ring (§7c) #

    ℝ, inherited; q ≠ 0, q² + 1 ≠ 0, and the root-of-unity exclusion ∀ k ≠ 0, (q²)^k ≠ 1.
