    QOU.SchurWeyl.PairProductSplit — splitting ∏_{i<j<r} at one index #

    The β-pair product P(β) = ∏_{i<j<r} f(β_i − β_j) changes, under β ↦ β + e_a, only in the pairs that involve a. To compare P(β') with P(β) one therefore wants the product split into

    • row a — the pairs (a, j) with j > a,
    • column a — the pairs (i, a) with i < a,
    • the rest, which is untouched.

    This file is that split, stated division-free for an arbitrary g : ℕ → ℕ → M so it applies to P(β) and P(β') alike.

    prod_pairs_split_ne is the form actually used: two families agreeing off the pairs involving a have the same "rest", so their products differ exactly by the row-a and column-a factors.
