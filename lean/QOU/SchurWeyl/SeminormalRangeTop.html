    QOU.SchurWeyl.SeminormalRangeTop — the seminormal representation is onto #

    The irreducibility half of SW-5 (bean qou-jfr8), in the range form AlgHom.range (seminormalRep …) = ⊤ that the Wedderburn assembly consumes. Surjectivity onto the full matrix block is irreducibility here, and stating it this way avoids standing up a module-over-the-algebra structure only to say "no proper submodule".

    The assembly #

    Five facts, each already proved, compose along a chain:

    fact supplies
    single_self_mem_range the diagonal units, via the simple q-Jucys–Murphy spectrum
    syt_swapStep_connected a chain of admissible swaps between any two tableaux
    offDiag_axialDist_ne_zero each step's off-diagonal entry is nonzero
    single_mem_range_of_entry_ne_zero a nonzero entry promotes to a matrix unit
    eq_top_of_single_mem the units generate everything

    The third is the one that was missing until now, and its absence was not visible from the plan: offDiag q (-1) = 0, so an admissible swap at distance −1 would contribute a vanishing entry and the promotion step would have nothing to consume. TableauCells.two_le_natAbs_axialDist rules that out by showing ±1 happens only in the same-row / same-column cases, which admissibility excludes.

    Note the induction composes units as a three-factor sandwich single c b 1 * single b T 1 * single T T 1, which Matrix.single_mul_mul_single evaluates directly. The two-factor identity single a b 1 * single b c 1 = single a c 1 is not in Mathlib at this pin and is not needed.
