    QOU.SchurWeyl.MarkovNormalisation — the second defining property, at every n #

    MarkovConventionD proves the Markov property tr(x·σ_n) = z·tr(x). "These are the Ocneanu weights" is two properties; this file proves the other one, the normalisation tr(1) = 1:

    ∑_{|λ| = n} f^λ · W_λ = 1        for every n,  W = ocneanuWeight q z_D

    (tr(1) = ∑_λ W_λ · tr(ρ_λ(1)) = ∑_λ W_λ · dim V_λ, and dim V_λ = f^λ is the number of standard tableaux.)

    The proof is the same exchange, run without the Hoefsmit factor #

    MarkovAssembly's reindexing does all the work again:

    • ocneanuWeight_addable_sum — for every diagram, ∑_{s addable} W_{ν+s} = W_ν. Same case split as the corner identity: ≥3 rows makes both sides 0, and on a twoRow the (2,0) cell drops out, leaving ocneanuWeight_twoRow_branching.
    • sum_dim_weight_succ — ∑_{|λ|=n+1} f^λ W_λ = ∑_{|ν|=n} f^ν W_ν, by expanding f^λ through numStandardYoungTableaux_branching and reindexing (λ, corner) ↔ (ν, addable).
    • sum_dim_weight_zero — the base case: the only diagram of size 0 is ⊥, with f = 1 (numStandardYoungTableaux_bot, already in the corpus) and W = 1 (an empty product over an empty product).

    So the sum is constant in n, and equal to its value at n = 0.

    Relation to the existing normalisation lemmas #

    OcneanuWeightMarkov3.ocneanuWeight_normalisation_three / _four prove the same identity at n = 3, 4 for arbitrary z. This file is the complement, not a replacement: all n, but convention D only. Neither subsumes the other.

    What is now proved, and what is not #

    Both defining properties of the Ocneanu/Markov weight hold, at convention D, at every n, in Lean. Uniqueness is not proved — that a Markov trace with a given z is the only one — so "these are the Ocneanu weights" still rests on that standard argument. For the downstream mass channel, which needs a Markov trace rather than the uniqueness of one, the two properties are what is used; but the uniqueness step should not be described as discharged.

    Base ring (§7c) #

    Generic [Field K], like the rest of the convention-D chain. No ordering, no ℝ.

    Weight branching, for every diagram. The weights of the diagrams obtained by adding one addable cell sum to the weight of the diagram itself.

    theorem QOU.SchurWeyl.sum_dim_weight_succ {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hq21 : q ^ 2 + 1 ≠ 0) (hgen : ∀ (i : ℕ), 0 < i → (q ^ 2) ^ i ≠ 1) (n : ℕ) :
    ∑ L : { ρ : YoungDiagram // ρ.cells.card = n + 1 }, ↑(Mathlib.numStandardYoungTableaux ↑L) * ocneanuWeight q (q ^ 3 / (q ^ 2 + 1)) ↑L = ∑ ν : { ν : YoungDiagram // ν.cells.card = n }, ↑(Mathlib.numStandardYoungTableaux ↑ν) * ocneanuWeight q (q ^ 3 / (q ^ 2 + 1)) ↑ν

    The weighted dimension sum does not depend on n.
