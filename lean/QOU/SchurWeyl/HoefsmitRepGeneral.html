    hoefsmit_seminormal_rep, proved #

    The general-λ seminormal representation, with the non-degeneracy that distinguishes it from the trivial q·1 matrix rep. This statement carried a -- Ref:-cited sorry in HoefsmitRep.lean from the file's creation; it is discharged here, and removed there rather than left standing beside a proved twin.

    It lives in its own file for an import reason, not a stylistic one: the proof consumes SeminormalRep.seminormalRepFin, and SeminormalRep imports TableauCells, which imports HoefsmitRep. Stating it where it was would be circular.

    What closed it, and in what order #

    Three things had to land, and only the middle one was ever the hard part:

    1. The braid relation for arbitrary λ — SeminormalRep.genMat_braid, unconditional on all of SYT μ, dispatching over every ⟨s_k, s_{k+1}⟩-orbit shape (PR #5076). This is what bean qou-im9l called "the hard core, NOT a plumbing task, multi-session".
    2. Non-scalarity's missing half — TableauCells.exists_swapAdmissible_of_one_lt_card (bean SW-5, PR #5266). genMat_ne_scalar already gave non-scalarity for a generator that moves a tableau; what was absent is that #SYT μ ≥ 2 produces such a tableau at all.
    3. |shape λ| = N — seminormalRepFin takes μ.cells.card = m + 1 as a hypothesis, and nothing said a partition's shape has N cells. card_shape below supplies it in six lines from QOU.BraidKnot.SpechtClassification.card_eq_rowLens_sum.

    Step 3 is worth flagging twice over. First, the reindexing was described (in the bean, and in #5076's body) as "mechanical": the reindex itself is — seminormalRepFin is four lines — but it was blocked on this hypothesis, and calling the step mechanical hid that.

    Second, I then over-corrected. I probed Mathlib, found card_ofRowLens / rowLens_sum_eq_card and five other spellings genuinely absent upstream, and wrote a ~100-line YoungDiagramCard.lean proving cells.card = rowLens.sum from scratch — without grepping the repo, where SpechtClassification.card_eq_rowLens_sum had been all along, its own docstring noting "Mathlib has no packaged bridge at this pin". That is the corpus-grep step AGENTS.md mandates before declaring something missing, and skipping it cost a duplicate file. The duplicate is deleted; card_shape below is the sibling PR #5282's formulation, adopted wholesale.

    The N = 0 branch is not a formality #

    Fin (N - 1) is Fin 0 there, so the conclusion's ∃ i cannot be produced and the hypothesis 2 ≤ dLambda lam has to be refuted instead. It is: the empty shape has no cells, so syt_ext_on_cells makes StandardYoungTableau a subsingleton vacuously, giving dLambda ≤ 1. The representation itself is still supplied — via Hecke.lift over the empty generator family.

    Refs:

    • [hoefsmit1974] P. N. Hoefsmit, PhD thesis, UBC (1974) — the seminormal form.
    • [ram1997] A. Ram, Proc. LMS (1997), https://doi.org/10.1112/S0024611597000282 — axial distances.

    theorem QOU.SchurWeyl.hoefsmit_seminormal_rep {N : ℕ} (q : ℝ) (hq : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) (lam : Partition N) :
    ∃ (ρ : Hecke ℝ q q⁻¹ (N - 1) →ₐ[ℝ] Matrix (Fin (dLambda lam)) (Fin (dLambda lam)) ℝ), 2 ≤ dLambda lam → ∃ (i : Fin (N - 1)), ∀ (s : ℝ), ρ (Hecke.σ ℝ q q⁻¹ (N - 1) i) ≠ s • 1

    Hoefsmit seminormal representation, general shape λ — PROVED.

    For every partition λ ⊢ N there is a d_λ-dimensional representation ρ_λ : H_N(q) →ₐ[ℝ] M_{d_λ}(ℝ) which, when d_λ ≥ 2, sends at least one generator to a non-scalar matrix — so it is not the reducible σ_i ↦ q·1 rep, and the statement is non-vacuous.

    q ≠ 0 together with q ^ 2 ≠ 1 says exactly that q is not a root of unity over ℝ, which is the genericity [ram1997]'s axial-distance formulas presuppose. Note this admits negative q: it is strictly weaker than 0 < q ∧ q ≠ 1.
