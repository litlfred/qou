    The arc's chain, closed. Every link was proved separately; this file is the composition.

    finrank R (H_n(q)/rad(wtrace))
  = Σ_{λ ⊢ n+1, ℓ(λ) ≤ 2} (f^λ)²          WtraceRadicalSemisimple.finrank_traceQuot
  = Σ_{k ≤ ⌊(n+1)/2⌋} (#SYT (n+1−k, k))²   TwoRowIdxReindex.finrank_traceQuot_eq_range_sum
  = Σ_{k ≤ ⌊(n+1)/2⌋} (ballot (n+1) k)²    TwoRowSYTBallot.numSYT_twoRow_eq_ballot
  = Σ_{k ≤ ⌊(n+1)/2⌋} (dimHLF [n+1−k, k])²  Mathlib.dimHLF_two_row_eq_ballot
  = catalan (n+1)                           Mathlib.dimHLF_two_row_sq_sum

    The third step is the one that was missing until now: it is the two-row hook length formula, and it is what lets a genuine tableau count meet a hook-length-formula value. The general Frame–Robinson–Thrall theorem is still absent from Mathlib and still proved in this corpus only for n ≤ 4 plus n = 5; it is not needed here.

    🛑 This is a DIMENSION, not an isomorphism with TL_n(δ) #

    catalan (n+1) is the dimension of TL_n(δ), so this says the quotient has exactly the right dimension to be the Temperley–Lieb algebra — and, with WtraceRadicalSemisimple.traceQuotEquiv, exactly the right Wedderburn block structure too.

    It does not say the two algebras are isomorphic. That needs ⟨U_i U_j U_i − v²·U_i⟩ = rad(tr_M), the open item QOU.MathlibExt.HeckeToTemperleyLieb records, and nothing here closes it. The content block hecke-radical-is-temperley-lieb's sentence — "a count of blocks and a count of dimensions are not an isomorphism of algebras" — remains true, and this file is precisely a count of dimensions. Do not cite it otherwise.

    What it does buy: the dimension obstruction to that identification is gone. Previously the two sides were a count and a formula with no bridge; now they agree, for every n.
