    The colimit of the Iwahori–Hecke tower, and its range filtration #

    Step 2 of the bridge from QOU.SchurWeyl's level-indexed Hecke algebras to the single-algebra OcneanuTrace.MarkovTrace interface, which wants one ring A carrying a monotone family of subalgebras H : ℕ → Subalgebra R A. Step 1 (QOU.SchurWeyl.HeckeDirectedSystem) supplied the DirectedSystem instance; this file takes the colimit and builds the filtration.

    What is proved here #

    • HeckeLim — the colimit lim_n Hecke K q qi n, via Mathlib's unified DirectLimit. No injectivity of heckeIncl is needed: measured against the live Mathlib, DirectLimit carries no injectivity hypothesis, so the carrier exists unconditionally and the bridge is not gated on bean qou-ejde (whether heckeIncl is injective). That question governs whether the ofLim n are embeddings, which is a separate statement.
    • instAlgebraHeckeLim — the K-algebra structure. Mathlib supplies no Algebra R (DirectLimit …) instance (measured: the DirectLimit namespace has instModule and instRing-family instances and nothing algebra-valued), so it is built here with Algebra.ofModule over the existing Module K instance — deliberately not with RingHom.toAlgebra', which would mint a second SMul K (HeckeLim …) and put a diamond against DirectLimit.instModule.
    • ofLimₐ — level n as an AlgHom into the colimit, and ofLimₐ_comp, the statement that it is compatible with the tower maps.
    • H and H_mono — the range filtration and its monotonicity. This is the MarkovTrace.H / MarkovTrace.H_mono pair.
    • gLim / ginvLim and gLim_mem / ginvLim_mem — the generator adjoined at step n (the image of σ_n, which first exists at level n+1) and its candidate inverse. These are the MarkovTrace.g / ginv / g_mem / ginv_mem fields.
    • gLim_eq / ginvLim_eq — each generator read at any level above the one it first appears in. This is the workhorse: two generators of different index live in different Hecke algebras, and the only way to multiply them is to push both into a common level, where the relation already holds.
    • gLim_quadratic, gLim_braid, gLim_far — the three defining relations, transported. Together these are exactly the MathlibExt.BraidedTower fields, so the colimit is a braided tower and TowerSpan / DisjointBlockTraceLaw apply to it once the trace is in place.
    • ginvLim_mul_gLim / gLim_mul_ginvLim — the two inverse laws, each carrying hqi : q * qi = 1 as an explicit hypothesis. σInv is defined unconditionally as σ - (q - qi)·1; it inverts σ only at qi = q⁻¹. This is a hypothesis of the Hecke algebra, not a gap: the braid group maps into Hecke K q qi n only when the generators are units.

    What is NOT proved here #

    Nothing about a trace. The MarkovTrace fields tr, tr_mul_comm, tr_one, markov and markov_inv are steps 4–6 and are not in this file, so no MarkovTrace instance is constructed here and none is claimed.

    H n is the image of level n. It coincides with a copy of Hecke K q qi n only when ofLim n is injective — exactly the open question of bean qou-ejde — and that is not assumed anywhere below. Every statement here is about the image.

                The generators #

                The generator adjoined at step n is σ_n, which first exists at level n+1. gLim_eq reads it at any level above that, which is what lets two generators of different index be compared: push both up to a common level and use the relation that already holds in Hecke K q qi j.
