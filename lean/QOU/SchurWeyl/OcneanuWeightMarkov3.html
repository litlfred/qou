    QOU.SchurWeyl.OcneanuWeightMarkov3 — the general-n weight reproduces the proved n = 3 weights #

    OcneanuWeight defines the closed form ocneanuWeight q z μ over a generic [Field R]. This file evaluates it on the three Young diagrams of size 3 and checks it against HeckeMarkov3's markovWeight0/1/2 — the weights that file proves satisfy the normalisation and both Markov relations. It also records the normalisation Σ_λ d_λ w_λ = 1 at n = 3 and at n = 4.

    This is the derive-then-check step for the general-n formula: a wrong closed form fails here. It is not a proof of the Markov property at general n — see OcneanuWeight's docstring for what is and is not claimed, and computations/schurweyl/ocneanu_weight_general_n.py for the exact-arithmetic derivation and its out-of-sample validation through n = 6.

    Base ring (§7c) #

    Genuinely archimedean, and deliberately separated from the generic definition: markovWeight0/1/2 are ℝ-valued, and the denominator non-vanishing facts (q² + 1 ≠ 0, q⁴ + q² + 1 ≠ 0, q⁴ + 1 ≠ 0) are discharged by positivity, which needs the ordering. Over a general field those would have to become hypotheses; nothing else here would change.

    Normalisation Σ_λ d_λ w_λ = 1 #

    The identity tr_M(1) = 1, since the identity's character in block λ is d_λ. At n = 3 this is markovWeights_one transported along the three theorems above; at n = 4 it is an out-of-sample check on the closed form — the n = 4 data pinned the framing monomial by a different route (the branching identity plus the q-Jucys–Murphy Markov relations), and no n = 4 weight is asserted anywhere in this repository's Lean.

    Normalisation at n = 3: w_{(3)} + 2 w_{(2,1)} + w_{(1³)} = 1.

    Cross-check: the general two-row formula against the proved n = 3 weight #

    OcneanuWeightBranching.schurPrincipal_twoRow gives the two-row weight at every (m,k) by a telescoping of the hook-content product. At (m,k) = (2,1) that general formula must reproduce markovWeight2, which was proved independently against the Markov relations. The chain below runs through both — markovWeight2 = ocneanuWeight (ofRowLens [2,1]) (the n = 3 theorem), then the bridge, then the general two-row closed form — so an off-by-one anywhere in the telescoping would fail here.
