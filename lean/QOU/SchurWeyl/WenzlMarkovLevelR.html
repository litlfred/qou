    QOU.SchurWeyl.WenzlMarkovLevelR — the Markov condition at every integer level #

    MarkovAssembly.markov_of_corner_identity reduces the Markov condition to the per-corner identity; WenzlMarkovCorner.wenzlWeight_markov_corner proves that identity at every level r. This file is the composition, and it is the statement bean qou-j7ln set out to reach:

    ∑_{|L| = m+2} w_L · tr(ι y · σ_{m+1})|_L = z_r · ∑_{|ν| = m+1} w_ν · tr(y)|_ν,

    for w = wenzlWeight r (q²) and z_r = Q^r/(q·[r]_Q).
    markov_wenzlWeight the Markov condition at every integer level r
    markov_wenzlWeight_two conservativity: r = 2 reproduces markov_conventionD

    The merged convention-D chain (#5575) is the r = 2 case: z_2 = q⁴/(q(1+q²)) = q³/(q²+1) = z_D, and markov_wenzlWeight_two derives that statement from this one rather than restating it.

    Scope #

    r is the Wenzl level — the number of variables in the principal specialisation — and is a positive integer by construction. This is a statement about every point of the Wenzl lattice, not about arbitrary z, which is off it.

    Base ring (§7c) #

    Generic [Field K]. The one step that used order, q² + 1 ≠ 0, now follows from q not being a root of unity (q⁴ ≠ 1).

    theorem QOU.SchurWeyl.SeminormalRep.markov_wenzlWeight {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) (hgen : ∀ (k : ℤ), k ≠ 0 → (q ^ 2) ^ k ≠ 1) {r : ℕ} (hr : r ≠ 0) {m : ℕ} (y : Hecke K q q⁻¹ m) :
    ∑ L : { ρ : YoungDiagram // ρ.cells.card = m + 2 }, wenzlWeight r (q ^ 2) ↑L * ((seminormalRep q hq hq2 (m + 1) ⋯) ((HeckeInclusion.heckeIncl K q q⁻¹ m) y) * genMat q (m + 1) ⋯ ⋯).trace = (q ^ 2) ^ r / (q * levelBracket r (q ^ 2)) * ∑ ν : { ν : YoungDiagram // ν.cells.card = m + 1 }, wenzlWeight r (q ^ 2) ↑ν * ((seminormalRep q hq hq2 m ⋯) y).trace

    The Markov condition for wenzlWeight r (q²), at every integer level r.

    The w-weighted seminormal trace of ι y · σ_{m+1} over the diagrams of size m + 2 is z_r times the w-weighted trace of y over those of size m + 1, with

    z_r = Q^r / (q · [r]_Q), Q = q².

    hgen — Q is not a root of unity — is the single genericity hypothesis the whole level-r chain runs on; hq2 is what seminormalRep itself needs, and is implied by hgen but has to be named because it appears in the statement.

    theorem QOU.SchurWeyl.SeminormalRep.markov_wenzlWeight_two {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) (hgen : ∀ (k : ℤ), k ≠ 0 → (q ^ 2) ^ k ≠ 1) {m : ℕ} (y : Hecke K q q⁻¹ m) :
    ∑ L : { ρ : YoungDiagram // ρ.cells.card = m + 2 }, ocneanuWeight q (q ^ 3 / (q ^ 2 + 1)) ↑L * ((seminormalRep q hq hq2 (m + 1) ⋯) ((HeckeInclusion.heckeIncl K q q⁻¹ m) y) * genMat q (m + 1) ⋯ ⋯).trace = q ^ 3 / (q ^ 2 + 1) * ∑ ν : { ν : YoungDiagram // ν.cells.card = m + 1 }, ocneanuWeight q (q ^ 3 / (q ^ 2 + 1)) ↑ν * ((seminormalRep q hq hq2 m ⋯) y).trace

    Conservativity: at r = 2 this is the merged convention-D statement.

    z_2 = (q²)²/(q·[2]_{q²}) = q³/(q²+1) = z_D and wenzlWeight 2 (q²) = ocneanuWeight q z_D, so markov_wenzlWeight at r = 2 reproduces MarkovConventionD.markov_conventionD on the nose — the general-level theorem specialises back to what #5575 proved, rather than merely resembling it.
