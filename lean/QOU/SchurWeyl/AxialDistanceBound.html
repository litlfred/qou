    QOU.SchurWeyl.AxialDistanceBound — admissible swaps are at axial distance ≥ 2 #

    A prerequisite of the irreducibility half of SW-5 (bean qou-jfr8), and the reason it is needed is not obvious from the statement.

    axialDist_trichotomy says same row ⟹ +1 and same column ⟹ −1. It does not say the converse, and the converse is what the matrix-unit argument needs. The off-diagonal entry of the generator matrix is offDiag, and offDiag q (-1) = 0 — a @[simp] lemma, not an edge case. So if an admissible swap could sit at distance −1, the entry the chain argument wants to promote to a matrix unit would vanish, and single_mem_range_of_entry_ne_zero would have nothing to consume. (genMat_ne_scalar sidesteps this by reading the partner column, which it can afford because it needs only one nonzero entry anywhere; a chain needs a direction, which is strictly stronger.)

    This file closes that: an admissible swap has |axialDist| ≥ 2, so the scalar distances ±1 are exactly the row/column cases and nothing else.

    The proof is one squeeze, run four ways #

    If k and k+1 sit at distance ±1 in different rows and different columns, then either

    • they are ordered strictly up-left, so the entry order is reversed — k + 1 < k; or
    • the rectangle they span has a corner cell that up-left closure puts in μ, and that cell's entry is squeezed strictly between k and k+1, of which there is none.

    Which corner works depends only on the sign of the distance: (i₂, j₁) when d = −1, and (i₁, j₂) when d = +1. Everything else is arithmetic.

    Pure tableau combinatorics: no ℝ, no q, nothing archimedean (§7c-clean).

    theorem QOU.SchurWeyl.TableauCells.entry_lt_of_le_of_ne {μ : YoungDiagram} (T : Mathlib.StandardYoungTableau μ) {i₁ j₁ i₂ j₂ : ℕ} (hi : i₁ ≤ i₂) (hj : j₁ ≤ j₂) (hne : i₁ ≠ i₂ ∨ j₁ ≠ j₂) (hcell : (i₂, j₂) ∈ μ) :
    T.entry i₁ j₁ < T.entry i₂ j₂

    Entries increase strictly along the up-left order. Weakly up-left and not equal gives a strict inequality, by one row step and one column step.

    theorem QOU.SchurWeyl.TableauCells.two_le_natAbs_axialDist {μ : YoungDiagram} (T : Mathlib.StandardYoungTableau μ) {k : ℕ} (hk : k ∈ Set.Icc 1 μ.cells.card) (hk' : k + 1 ∈ Set.Icc 1 μ.cells.card) (hadm : SwapAdmissible T k) :
    2 ≤ (axialDist T k).natAbs

    An admissible swap has axial distance at least 2 in absolute value.

    Equivalently: the scalar distances ±1 occur exactly in the same-row and same-column cases — the converse of axialDist_trichotomy, which that theorem does not provide.

    This is what keeps offDiag away from its zero: offDiag q (-1) = 0, so without this bound an admissible swap could carry a vanishing off-diagonal entry.
