    QOU.SchurWeyl.SytContentTuple — the content tuple determines the tableau, in the cellOf API #

    The separation input for general irreducibility (SW-5, bean qou-jfr8). Ram's Theorem 4.1 (SeminormalRep.seminormalRep_qJM) makes each q-Jucys–Murphy element act diagonally on the SYT basis, with entry q^{2·cellContent (cellOf T k)} at T. That alone does not separate the basis: it separates it only if distinct tableaux of one shape have distinct content tuples.

    That combinatorial fact is already proved in the corpus, sorry-free, as QOU.BraidKnot.JucysMurphy.syt_content_tuple_injective — the Okounkov–Vershik stack under BraidKnot/. What is missing is only the translation, because the two halves of the repo use two different StandardYoungTableau types:

    type cell-of-a-label
    SchurWeyl (TableauCells) QOU.Mathlib.StandardYoungTableau cellOf T k, labels 1 … |μ|
    BraidKnot (Okounkov–Vershik) QOU.BraidKnot.StandardYoungTableau tableauCellEquiv μ T s, labels 0 … |μ|−1

    BraidKnot/SytMathlibBridge.lean already carries the type conversion with both round trips (toBraidKnot, toMathlib, toBraidKnot_toMathlib, toMathlib_toBraidKnot). This file adds the missing label correspondence — cellOf T (s+1) is tableauCellEquiv μ T.toBraidKnot s, the one-down entry shift read on cells — and transports the separation statement across it.

    Two cellContents. QOU.SchurWeyl.cellContent (SchurWeyl/HoefsmitRep.lean) and QOU.BraidKnot.JucysMurphy.cellContent (BraidKnot/JucysMurphy.lean) are distinct declarations with the same body c.2 − c.1. They are definitionally equal, so the transport is free, but they are not the same symbol and this file is explicit about which is which — per AGENTS.md §"attributes do not transfer across overloaded symbols". (The corpus carries five cellContent definitions in total; consolidating them is a separate cleanup, not attempted here.)

    Refs:

    • [okounkov1996] Okounkov–Vershik, A new approach to the representation theory of the symmetric groups — the content-tuple/Gelfand–Tsetlin separation.
    • [ram1997] Ram, Seminormal representations … — the q-deformed eigenvalues.

    theorem QOU.SchurWeyl.cellOf_eq_tableauCellEquiv {μ : YoungDiagram} (T : Mathlib.StandardYoungTableau μ) (s : Fin (BraidKnot.Specht.nOf μ)) :
    TableauCells.cellOf T (↑s + 1) = ↑((BraidKnot.JucysMurphy.tableauCellEquiv μ T.toBraidKnot) s)

    The label correspondence across the SYT bridge. tableauCellEquiv finds the cell of T.toBraidKnot carrying label s; since toBraidKnot shifts every on-cell entry down by one, that is the cell of T carrying s + 1, i.e. cellOf T (s + 1).

    theorem QOU.SchurWeyl.syt_eq_of_cellContent_eq {μ : YoungDiagram} (T T' : Mathlib.StandardYoungTableau μ) (h : ∀ (k : ℕ), 1 ≤ k → k ≤ μ.cells.card → cellContent (TableauCells.cellOf T k) = cellContent (TableauCells.cellOf T' k)) :
    T = T'

    Separation — the content tuple determines the tableau (cellOf form). Two standard tableaux of the same shape that assign the same content to every label 1 ≤ k ≤ |μ| are equal.

    This is QOU.BraidKnot.JucysMurphy.syt_content_tuple_injective transported across the bridge. The mathematical content is entirely there: entries increase strictly along diagonals, so the row of the cell holding k is a function of the content tuple alone, and row + content gives the column.
