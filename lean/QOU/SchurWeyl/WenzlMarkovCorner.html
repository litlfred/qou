    QOU.SchurWeyl.WenzlMarkovCorner — the corner identity at general level r #

    MarkovAssembly.markov_of_corner_identity reduces the Markov condition to a per-corner identity on the weights,

    ∑_{s addable} w_{ν + s} · a(axialDistance c s) = z · w_ν for every removable corner c of ν,

    and OcneanuWeightMarkovCorner proves that identity at r = 2 one row at a time. This file proves it at every level r, for wenzlWeight r Q with Q = q², with

    z_r = Q^r / (q · [r]_Q).

    At r = 2 that is q⁴/(q(1+q²)) = q³/(q²+1) = z_D, the convention-D parameter — so the general statement specialises back to the merged chain's, and wenzlMarkovParam_conventionD is the q-shifted form of the same number (z_W = q·z_D, z_r = z_W/q).
    pow_ne_pow_of_ne distinct exponents, distinct powers, at a non-root-of-unity Q
    levelBracket_ne_zero [r]_Q ≠ 0 for r ≠ 0
    betaR_succ_ne_of_corner no β is one above a corner's β — the mirror of betaR_ne_succ_of_addable
    sum_wenzlWeight_node_weighted the algebraic core, over any field
    wenzlWeight_markov_corner the corner identity, over ℝ at Q = q²

    Why two theorems. The arithmetic is field-generic and has nothing to do with ℝ; only the translation of seminormalParam into the node weight Q·x_a/(Q·x_a − x_b) is ℝ-bound, because seminormalParam is. sum_wenzlWeight_node_weighted carries the former, wenzlWeight_markov_corner the latter.

    What the corner hypothesis buys. sum_prod_qratio_weighted needs Q·x_i ≠ x_b for every i ≠ b, i.e. β_i + 1 ≠ β_b — otherwise a summand is 0/0. Strict decrease of β does not give this: it permits β_{b−1} = β_b + 1. What rules it out is that c is a removable corner, so ν_{b+1} < ν_b, which pushes β_{b+1} a full two below β_b. That is betaR_succ_ne_of_corner, and it is the exact mirror of what addability buys in betaR_ne_succ_of_addable.

    Scope #

    r is the Wenzl level — the number of variables in the principal specialisation — and is an integer by construction; Q^r = z/(1−Q+z) pins the lattice. General integer r is on that lattice. Nothing here bears on arbitrary z, which is off it.

    Base ring (§7c) #

    Generic [Field F] / [Field K] throughout. No ordering, no ℝ.

    No β sits one above a corner's β.

    If c is a removable corner in row b then ν_{b+1} < ν_b, so β_{b+1} ≤ β_b − 2; rows further down are lower still, and rows above have β > β_b outright. Hence β_i + 1 = β_b for no i ≠ b.

    This is the mirror of betaR_ne_succ_of_addable, and it is what discharges the hne hypothesis of QOU.Mathlib.sum_prod_qratio_weighted at the corner node.

    theorem QOU.SchurWeyl.sum_wenzlWeight_node_weighted {F : Type u_2} [Field F] (Q : F) (hQ0 : Q ≠ 0) (hQ1 : Q ≠ 1) (hgen : ∀ (k : ℤ), k ≠ 0 → Q ^ k ≠ 1) {r b : ℕ} {ν : YoungDiagram} (hrν : ν.colLen 0 ≤ r) (hb : b < r) (hgap : ∀ i < r, i ≠ b → betaR r ν i + 1 ≠ betaR r ν b) :
    (∑ a ∈ Finset.range r, if Mathlib.IsAddableCell ν (a, ν.rowLen a) then wenzlWeight r Q (Mathlib.addCellOrSelf ν (a, ν.rowLen a)) * (Q * Q ^ betaR r ν a / (Q * Q ^ betaR r ν a - Q ^ betaR r ν b)) else 0) = Q ^ r / (Q - 1) / levelBracket r Q * wenzlWeight r Q ν

    The algebraic core of the corner identity.

    Summing the branching ratio against the node weight Q·x_a/(Q·x_a − x_b) collapses by sum_prod_qratio_weighted — the Lagrange residue sum — to Q^r/(Q−1), and the branching itself contributes w_ν/[r]_Q. Non-addable rows drop out on their own: the q-ratio numerator already vanishes there.

    hgap is the 0/0 guard, supplied at the corner node by betaR_succ_ne_of_corner.

    axialDistance c d = BraidKnot.TableauContent.axialDistance c d

    Bridge between the corpus's two axialDistances.

    QOU.SchurWeyl.axialDistance (HoefsmitRep, via cellContent) and QOU.BraidKnot.TableauContent.axialDistance (via content) are the same function under two names — both are (content of the second) − (content of the first). They are rfl-equal, but they are different constants, so a bare axialDistance inside namespace QOU.SchurWeyl resolves to the first even under open QOU.BraidKnot.TableauContent, and a rw with a lemma stated in the second will not fire. markov_of_corner_identity uses the first; axialDistance_corner_addable the second. This lemma is what lets one consume the other.

    (The duplication itself is a notation collision worth draining corpus-wide; that is not this file's scope.)

    theorem QOU.SchurWeyl.wenzlWeight_markov_corner {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hgen : ∀ (k : ℤ), k ≠ 0 → (q ^ 2) ^ k ≠ 1) {r : ℕ} (hr : r ≠ 0) (ν : YoungDiagram) {c : ℕ × ℕ} (hc : Mathlib.IsCornerCell ν c) :
    ∑ s : { s : ℕ × ℕ // Mathlib.IsAddableCell ν s }, wenzlWeight r (q ^ 2) (Mathlib.addCell ν ↑s ⋯) * Seminormal.seminormalParam q (axialDistance c ↑s) = (q ^ 2) ^ r / (q * levelBracket r (q ^ 2)) * wenzlWeight r (q ^ 2) ν

    The corner identity at general level r.

    For every removable corner c of ν,

    ∑_{s addable} w_{ν+s} · a(axialDistance c s) = z_r · w_ν, z_r = Q^r/(q·[r]_Q), Q = q².

    This is the hypothesis MarkovAssembly.markov_of_corner_identity consumes, so with it the Markov condition holds for wenzlWeight r (q²) at every integer level — OcneanuWeightMarkovCorner's row-by-row r = 2 argument, replaced by one uniform proof.

    At r = 2 the parameter is q⁴/(q(1+q²)) = q³/(q²+1) = z_D.

    The proof: the subtype sum becomes a guarded row sum (sum_addable_eq_sum_range), which is trimmed to range r (rows past colLen 0 are not addable; rows past r give a diagram with too many rows, which wenzlWeight_addCell_beyond_eq_zero kills), and each surviving seminormalParam becomes the node weight by axialDistance_corner_addable + seminormalParam_node_form. Then sum_wenzlWeight_node_weighted does the arithmetic.

    Note there is no a = b special case: at s.1 = c.1 the axial distance is 1 and the node form gives (q − q⁻¹)·Q/(Q−1) = q on its own.
