    QOU.SchurWeyl.HeckeSchurElements — τ = Σ_λ χ_λ / c_λ #

    The symmetrising trace τ = symTrace of H_{m+1}(q) (the T_1-coefficient, defined over any commutative ring in HeckeSymmetricAlgebra) decomposes over the irreducible seminormal characters χ_λ with weights 1 / c_λ, where the Schur element is

    c_λ(Q) = Q^{−n(λ)} · ∏_{x ∈ λ} (1 − Q^{h(x)}) / (1 − Q),      Q = q²,

    i.e. c_λ = 1 / M_λ for the Molien weight M_λ.

    Main results #

    • schurElt_eq — the closed form of c_λ (generic field, no hypotheses).
    • schurElt_ne_zero — c_λ ≠ 0 when Q ≠ 0 is not a root of unity.
    • molien_eq_symTrace — the Molien-weighted seminormal trace is τ (any field, generic q).
    • symTrace_eq_sum_schur — τ(x) = Σ_{|λ| = m+1} χ_λ(x) / c_λ.

    Proof #

    MolienSymmetrisingTrace shows the Molien-weighted seminormal trace is a Markov trace with z = 0; HeckeSymmetricAlgebra.MarkovTraceFamily.tr_eq_symTrace shows every such trace is τ. The rest is c_λ⁻¹ = M_λ.

    Scope #

    Everything is over a field K with q ≠ 0 not a root of unity (so qi = q⁻¹); τ itself, and its product formula, cyclicity and nondegeneracy, are over any commutative ring (HeckeSymmetricAlgebra).

    Base ring (§7c) #

    Generic [Field F] / [Field K] throughout. No ordering, no ℝ.
