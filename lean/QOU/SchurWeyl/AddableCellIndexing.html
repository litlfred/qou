    QOU.SchurWeyl.AddableCellIndexing — the addable-cell sum as a sum over rows #

    sum_wenzlWeight_addCellOrSelf sums over range r with a decidable guard. The branching exchange (YoungDiagramCornerReindex.sum_corner_eq_sum_addable) hands its inner sum over the addable-cell subtype. This file identifies the two.
    isAddableCell_row_le an addable cell sits in row ≤ colLen 0
    isCornerCell_row_lt a corner cell sits in row < colLen 0
    addableRowSet μ the addable cells, as an explicit Finset indexed by row
    sum_addable_eq_sum_range the subtype sum is the guarded range (colLen 0 + 1) sum
    sum_addable_wenzlWeight ∑_{s addable} w_{μ+s} = w_μ — branching in the exchange's own indexing

    Why the row bound is colLen 0 + 1 and not colLen 0. A diagram with k nonzero rows has an addable cell at row k — start a new row — so the rows carrying an addable cell run 0 … k, not 0 … k−1. Reconciling that with a range r sum is what wenzlWeight_addCell_beyond_eq_zero handles: at colLen 0 = r the row-r cell is real but its weight is 0.

    An addable cell sits in row ≤ colLen 0: either it is in row 0, or the cell above it is in μ, which bounds its row by the column height.

    A corner cell sits strictly inside the column height. The corner analogue of isAddableCell_row_le: a corner is a cell of ν, so its row is occupied, hence < colLen 0. (The addable bound is ≤, not <, because an addable cell may start a brand-new row.)

      Branching over the addable cells.

      ∑_{s addable to μ} w_{μ+s} = w_μ.

      Same content as sum_wenzlWeight_addCellOrSelf, in the indexing YoungDiagramCornerReindex.sum_corner_eq_sum_addable produces — which is what the normalisation induction consumes.

      The two row ranges are reconciled by cases, and both directions carry a real fact:

      • colLen 0 < r — rows colLen 0 < a < r are empty and so is the row above them, so isAddableCell_rowEnd_iff refuses them and the guard is 0;
      • colLen 0 = r — row r is addable, and its term vanishes only because the resulting diagram has r+1 rows (wenzlWeight_addCell_beyond_eq_zero).
