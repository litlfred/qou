    The sharp dimension of the tower image #

    Bean qou-p8yg, sharp half. HeckeTowerStrict.heckeIncl_range_lt_top shows the tower inclusion is never onto using a dimension inequality and no injectivity — see that file, whose import list is the evidence. This file consumes heckeIncl_injective to upgrade the inequality to the exact value: the image of H_m(q) in H_{m+1}(q) has dimension exactly (m+1)!.

    Split from HeckeTowerStrict deliberately. Keeping the two in one file would put heckeIncl_injective in the import cone of the strictness statement and make the independence claim unverifiable from the source; separating them lets the compiler carry it.

    Scope #

    ℝ, q ≠ 0, NotRootOfUnity q — inherited from heckeIncl_injective, whose step 2 (compress_seminormalRep_heckeIncl) is stated over ℝ with qi = q⁻¹. The strictness statement is not confined to ℝ; only this sharpening is.
