    QOU.SchurWeyl.QRatioBetaFactors — the q-ratio factor at a β-pair #

    schurPrincipal_mul_const reduces branching to comparing P(β') / P(β) against the q-ratio, where P(β) = ∏_{i<j<r}(1 − Q^{β_i−β_j}) and β' = β + e_a. Only pairs involving a differ, so the comparison is per-pair, and this file does those two cases.
    betaR_addCell β_i(μ + □ at row a) = β_i(μ) + [i = a]
    qratio_factor_lower pairs j > a — an exact match, no leftover factor
    qratio_factor_upper pairs j < a — the same match, times one Q

    Both are the same cancellation seen from the two sides: writing x_i = Q^{β_i}, divide numerator and denominator by whichever of Q^{β_a}, Q^{β_j} is the smaller power. The asymmetry is entirely in which is smaller, and it is what produces the Q^{#\{j < a\}} = Q^a that nPart_addCell supplies from the other side.

    No non-vanishing hypothesis. Both statements are equalities of quotients, and at a root of unity where a denominator vanishes both sides are _/0 = 0. The Q ≠ 0 hypothesis is only needed to cancel the common power.

    theorem QOU.SchurWeyl.qratio_factor_lower {F : Type u_1} [Field F] (Q : F) (hQ : Q ≠ 0) (b c : ℕ) (h : c ≤ b) :
    (Q * Q ^ b - Q ^ c) / (Q ^ b - Q ^ c) = (1 - Q ^ (b + 1 - c)) / (1 - Q ^ (b - c))

    The q-ratio factor at a pair below a (j > a, so β_j ≤ β_a).

    (Q·Q^{β_a} − Q^{β_j})/(Q^{β_a} − Q^{β_j}) = (1 − Q^{β_a+1−β_j})/(1 − Q^{β_a−β_j})

    — the right-hand side is exactly the P(β')-factor over the P(β)-factor, with no leftover power of Q.

    source
    theorem QOU.SchurWeyl.qratio_factor_upper {F : Type u_1} [Field F] (Q : F) (hQ : Q ≠ 0) (b c : ℕ) (h : b + 1 ≤ c) :
    (Q * Q ^ b - Q ^ c) / (Q ^ b - Q ^ c) = Q * ((1 - Q ^ (c - b - 1)) / (1 - Q ^ (c - b)))

    The q-ratio factor at a pair above a (j < a, so β_a < β_j).

    (Q·Q^{β_a} − Q^{β_j})/(Q^{β_a} − Q^{β_j}) = Q · (1 − Q^{β_j−β_a−1})/(1 − Q^{β_j−β_a})

    — the same P(β')-over-P(β) factor, times one Q. Summed over the a rows above, those Qs are the Q^a that nPart_addCell accounts for.
