    trLim is NOT faithful — the question four docstrings flag as untouched #

    HeckeColimit, HeckeColimitMarkovTrace, HeckeTowerStrict and HeckeInclInjective each record that trLim faithfulness is a separate question that nothing bears on. It is settled here, and the answer is no.

    The shape of the argument #

    Three ingredients, each already proved:

    1. One level is enough. OcneanuTraceNotFaithful exhibits a nonzero x ∈ Hecke ℝ q q⁻¹ 2 invisible to wtrace — supported on the column shape (1,1,1), whose Ocneanu weight vanishes at convention D.
    2. It stays nonzero upstairs. HeckeColimitFaithful.ofLimₐ_injective (the tower inclusions are injective — the opposite answer to the opposite question) sends it to a nonzero element of the colimit.
    3. Orthogonality propagates. MarkovTraceRadical.mem_rad_of_exhausted lifts orthogonality from one filtration stage to all of them: cyclicity turns each sandwich v · g · w inside out, Markov strips the generator, and v · w lands back in the stage below. TowerSpan supplies the step and the Hecke colimit has it (towerSpan_heckeColimit).

    The exhaustion ⋃_M shiftedUpTo 0 M = ⊤ is the one piece with no prior carrier; it is adjoin_range_σ_eq_top transported along gLim_eq, which reads the level-m generator σ_i as the colimit generator g i.

    Why this is not a defect in the framework #

    The radical is the Temperley–Lieb ideal and the form is nondegenerate on H_∞/rad ≅ TL_∞ (QBeta.MarkovTraceQuotient.quot_pairing_nondegenerate). What is refuted is faithfulness on the Hecke tower itself, which is the over-claim already adjudicated as bean qou-phlk. This file is the statement about the trLim carrier that adjudication did not reach.

    Scope #

    Convention D (z = q³/(q²+1)), ℝ, and the four genericity hypotheses that wtrace already carries — none is added. Under the excised convention C the three-row weight is nonzero and the verdict inverts; this is a statement about D.
