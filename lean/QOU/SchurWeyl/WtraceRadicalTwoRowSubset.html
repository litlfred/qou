    The radical of wtrace is EXACTLY the three-row part #

    WtraceRadicalTwoRow has the ⊇ half — anything killed by every at-most-two-row block is invisible to the Ocneanu trace form. This file adds ⊆ and so turns an inclusion into an identification.

    The statement #

    notMem_rad_of_twoRow_block_ne_zero — if some at-most-two-row block does not kill x, then some b pairs with it: wtrace (x * b) ≠ 0. Contrapositive of ⊆.

    mem_rad_iff_twoRow_blocks_vanish — the two halves together, as an iff.

    Why this is not blocked (a retraction) #

    WtraceRadicalTwoRow's docstring, bean qou-s7z2 and PR #7460's body all recorded ⊆ as blocked on Wenzl's theorem: it needs the ≤2-row Ocneanu weights nonzero, and the corpus's only statement of that was conditional on QBeta.IsOcneanuWeightSystem, a class with no instance.

    That reasoning went through the wrong object. IsOcneanuWeightSystem relates an opaque weight family to schurPrincipal; ocneanuWeight is a closed form, so the non-vanishing is provable directly — OcneanuWeightTwoRowNonzero, from the genericity wtrace already carries. See that file's docstring.

    The two remaining ingredients, and they are cheap #

    1. exists_trace_mul_ne_zero — a nonzero matrix is seen by some matrix under the trace form. Pick an entry M i j ≠ 0 and pair with the single-entry matrix at (j, i); the product's diagonal is supported at i and reads off M i j.
    2. Block isolation — heckeProduct_surjective realises the tuple Function.update 0 lam₀ N, so every block but lam₀ contributes 0 to the Frobenius sum. The surviving term is w_{d} · (M · N).trace, a product of two nonzero reals.

    The sum is indexed by {ν : YoungDiagram // ν.cells.card = n+1} while heckeProduct is indexed by Partition (n+1); partitionShapeEquiv reindexes one to the other, which is what lets Finset.sum_eq_single see a single surviving block.

    Scope #

    Convention D (z = q³/(q²+1)), ℝ, and the genericity wtrace carries — the same scope as the ⊇ half. Under the excised convention C the three-row weight is nonzero and the whole statement is empty rather than false.

    The radical of wtrace is EXACTLY the three-row part.

    The two halves together: x is invisible to the Ocneanu trace form precisely when every at-most-two-row block kills it. Equivalently, the radical is the span of the blocks with ℓ(λ) ≥ 3 — which at convention D is the Temperley–Lieb ideal.

    The tower comparison, unconditionally, at the concrete carrier #

    QBeta.TLTowerRadicalDescent compares the radicals at consecutive ranks and proves both directions — but every statement there is conditional, in the §3b-cond sense, on HeckeConditionalExpectation, an OPEN class with no instance. Its docstring explains why: a bare inclusion says nothing, because membership in the upper radical quantifies over the whole upper algebra, not over the image.

    At the concrete wtrace carrier the reflection direction needs none of that, because wtrace_incl is already unconditional: restricting a test element to the image is enough, and heckeIncl being an AlgHom supplies the rest. Two rewrites.

    This is the direction that carries the weight there — it is what makes the quotients a tower (TL_n ↪ TL_{n+1}) rather than a sequence of algebras with maps between them. The forward direction genuinely does need more than the inclusion, and is not claimed here; via mem_rad_iff_twoRow_blocks_vanish it reduces to the branching statement that erasing a corner from an at-most-two-row diagram leaves at most two rows, which is a separate piece of work.

    theorem QOU.SchurWeyl.WtraceRadicalTwoRow.mem_rad_of_incl_mem_rad {q : ℝ} (hq0 : q ≠ 0) (hq2 : GenericParameter.NotRootOfUnity q) (hq21 : q ^ 2 + 1 ≠ 0) (hgen : ∀ (k : ℕ), 0 < k → (q ^ 2) ^ k ≠ 1) (m : ℕ) (a : Hecke ℝ q q⁻¹ m) (ha : ∀ (x : Hecke ℝ q q⁻¹ (m + 1)), (SeminormalRep.wtrace q hq0 hq2 (m + 1)) ((HeckeInclusion.heckeIncl ℝ q q⁻¹ m) a * x) = 0) (b : Hecke ℝ q q⁻¹ m) :
    (SeminormalRep.wtrace q hq0 hq2 m) (a * b) = 0

    Reflection along the tower inclusion, unconditionally.

    If heckeIncl a is invisible to wtrace at level m+1, then a is invisible at level m. Test elements are restricted to the image: wtrace (heckeIncl a * heckeIncl b) = wtrace (heckeIncl (a * b)) = wtrace (a * b).

    No conditional expectation, and no instance of any open class — only the genericity wtrace already carries.
