    QOU.SchurWeyl.MatRepEquiv — equivalence of matrix representations, over any commutative ring #

    Extracted from QOU/SchurWeyl/SeminormalInequivalence.lean (bean qou-j377).

    Nothing here mentions ℝ, a Hecke algebra, or a Young diagram: it is the general statement that two matrix representations of one algebra are equivalent when an invertible change of basis intertwines them, plus what that forces on scalars, conjugates, traces and dimensions.

    It was living in the file with the largest ℝ surface in the Wedderburn cone, which scripts/check-sidecars.sh flagged as a §7c mixed generic/archimedean file. The flag predates the general-field work — MatRepEquiv has been generic since it was written — but it is exactly the shape §7c asks to be split, and moving it makes the remaining ℝ in SeminormalInequivalence the only thing in that file.

    MatRepEquiv had no consumers outside its original file, so this move breaks nothing; the sixteen uses inside it now resolve through this import.

    Equivalence of matrix representations #

    source
    def QOU.SchurWeyl.MatRepEquiv {R : Type u_1} {A : Type u_2} {ι : Type u_3} {κ : Type u_4} [CommRing R] [Semiring A] [Algebra R A] [Fintype ι] [DecidableEq ι] [Fintype κ] [DecidableEq κ] (ρ : A →ₐ[R] Matrix ι ι R) (ρ' : A →ₐ[R] Matrix κ κ R) :
    Prop

    Two matrix representations of one algebra are equivalent when an invertible change of basis intertwines them.

    Stated with an explicit inverse pair S, T rather than IsUnit S, because the index types ι and κ differ: S : Matrix κ ι R is not square, so IsUnit does not apply and the two one-sided identities are separate data. Both are needed — S * T = 1 is what forces the scalar comparison below, and T * S = 1 is what makes this a symmetric notion.

      theorem QOU.SchurWeyl.MatRepEquiv.scalar_eq {R : Type u_1} {A : Type u_2} {ι : Type u_3} {κ : Type u_4} [CommRing R] [Semiring A] [Algebra R A] [Fintype ι] [DecidableEq ι] [Fintype κ] [DecidableEq κ] [Nonempty κ] {ρ : A →ₐ[R] Matrix ι ι R} {ρ' : A →ₐ[R] Matrix κ κ R} (h : MatRepEquiv ρ ρ') {x : A} {c c' : R} (hc : ρ x = c • 1) (hc' : ρ' x = c' • 1) :
      c' = c

      A scalar value is an equivalence invariant. If x is sent to a scalar matrix by both representations, the two scalars agree.

      This is the whole force of centrality: a central element goes to a scalar in every irreducible block, and equivalent blocks cannot disagree about which scalar. Nonempty κ is needed and is not a formality — over the empty index type every matrix is 1, so any two scalars would be indistinguishable.

      ρ' x = S * ρ x * T

      An equivalence conjugates one representation into the other. The intertwining identity ρ' x * S = S * ρ x becomes ρ' x = S * ρ x * T once S * T = 1 is used on the right.

      theorem QOU.SchurWeyl.MatRepEquiv.trace_eq {R : Type u_1} {A : Type u_2} {ι : Type u_3} {κ : Type u_4} [CommRing R] [Semiring A] [Algebra R A] [Fintype ι] [DecidableEq ι] [Fintype κ] [DecidableEq κ] {ρ : A →ₐ[R] Matrix ι ι R} {ρ' : A →ₐ[R] Matrix κ κ R} (h : MatRepEquiv ρ ρ') (x : A) :
      (ρ' x).trace = (ρ x).trace

      The character is an equivalence invariant. tr ρ'(x) = tr ρ(x) for every x.

      This is the workhorse for unconditional separation, and it is strictly stronger than scalar_eq: it applies to every algebra element, not only those landing on scalars, so it can compare whole spectra rather than one number. Note it needs only S * T = 1 and T * S = 1 — no genericity, no algebra structure beyond the intertwining.
