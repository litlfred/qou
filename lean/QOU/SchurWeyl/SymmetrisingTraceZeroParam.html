    QOU.SchurWeyl.SymmetrisingTraceZeroParam — a Markov trace with z = 0 is the symmetrising trace #

    The symmetrising (regular) trace on the Iwahori–Hecke algebra is the functional τ(T_w) = δ_{w,1}: it takes the value 1 on the identity and 0 on every other element of the standard basis. This file proves that a Markov trace with parameter z = 0 is exactly that functional, on every H_n(q) of the tower.

    The basis used #

    Hecke K q qi n is presented as a quotient of the free algebra, so it carries no built-in T_w basis. The basis used is the coset family of HeckeCoset:

    cosetFam 0 () = 1,      cosetFam (m+1) (b, j) = ι(cosetFam m b) · r_j,
r_j = σ_m σ_{m−1} ⋯ σ_{m−j+1}   (r_0 = 1),

    which spans (HeckeCoset.span_cosetFam_eq_top) and has (m+1)! = |S_{m+1}| elements (HeckeCoset.card_cosetIndex). Each element is a product of distinguished coset representatives r_j, i.e. the T_w for the permutation w read off from the factorisation, of length cosetLen p = Σ j. The identity is the unique index of length 0.

    The statement #

    MarkovTraceFamily.tr_cosetFam_of_zero: if T is a Markov trace with z = 0, then

    T.tr m (cosetFam m p) = if cosetLen p = 0 then 1 else 0.

    Combined with HeckeCoset.markovTrace_unique (a Markov trace is determined by its parameter), this says: every z = 0 Markov trace is the symmetrising trace, and there is at most one.

    Proof #

    Induction on m, exactly the shape of markovTrace_unique. For p = (b, j):

    • j = 0: r_0 = 1, so tr(ι(cosetFam b)) = tr(cosetFam b) by consistency, and cosetLen (b, 0) = cosetLen b.
    • j ≥ 1: r_j = σ_m · ι(t) (descProd_eq_last_mul_incl), so cyclicity and the Markov axiom give tr = z · tr(t · cosetFam b) = 0; and cosetLen (b, j) ≥ j ≥ 1.

    Base ring (§7c) #

    Generic [CommRing K]; nothing archimedean.
