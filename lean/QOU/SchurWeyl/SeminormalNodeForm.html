    QOU.SchurWeyl.SeminormalNodeForm — the seminormal entry in node coordinates #

    sum_prod_qratio_weighted proves the arithmetic the Markov property needs, with the seminormal (Hoefsmit) entry appearing as the weight Q·x_a/(Q·x_a − x_b). This file is the translation: that weight is seminormalParam, once the axial distance is written in terms of the nodes x_i = Q^{β_i}.
    seminormalParam_node_form a(d) = (q − q⁻¹)·Q·x_a/(Q·x_a − x_b) when Q^d·x_b = Q·x_a
    seminormalParam_one' the d = 1 value q, in the form the a = b term uses
    rowLen_of_isCornerCell a removable corner sits at (b, μ_b − 1)
    axialDistance_corner_addable axialDistance = β_a − β_b + 1 — the content-to-β dictionary
    zpow_node_dictionary and hence Q^d · x_b = Q · x_a

    The hypothesis Q^d·x_b = Q·x_a is the content-to-β dictionary, and it is where d = β_a − β_b + 1 enters: an addable cell in row a has content β_a − (r−1), a removable corner in row b has content β_b − r, and their difference is β_a − β_b + 1.

    Base ring (§7c) #

    Generic [Field K]. Nothing archimedean: the proof is a field_simp.

    LaTeX label: lem:seminormal-node-form

    source
    theorem QOU.SchurWeyl.seminormalParam_node_form {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (xa xb : K) (hxb : xb ≠ 0) (d : ℤ) (hd : (q ^ 2) ^ d * xb = q ^ 2 * xa) (hden : q ^ 2 * xa - xb ≠ 0) :
    Seminormal.seminormalParam q d = (q - q⁻¹) * (q ^ 2 * xa) / (q ^ 2 * xa - xb)

    The seminormal entry, in node coordinates.

    With x_a, x_b the nodes and d the axial distance, Q^d·x_b = Q·x_a turns

    a(d) = (q − q⁻¹)/(1 − q^{−2d}) into (q − q⁻¹)·Q·x_a/(Q·x_a − x_b),

    which is exactly the weight in QOU.Mathlib.sum_prod_qratio_weighted.

    source
    theorem QOU.SchurWeyl.seminormalParam_one' {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hq2 : q ^ 2 - 1 ≠ 0) :
    (q - q⁻¹) * q ^ 2 / (q ^ 2 - 1) = q

    The d = 1 value in the shape the a = b term of the corner identity produces: (q − q⁻¹)·Q/(Q − 1) = q.

    The content-to-β dictionary #

    seminormalParam_node_form's hypothesis Q^d · x_b = Q · x_a is a statement about the axial distance between the addable cell and the removable corner. These three lemmas supply it.

    source
    theorem QOU.SchurWeyl.rowLen_of_isCornerCell {ν : YoungDiagram} {c : ℕ × ℕ} (hc : Mathlib.IsCornerCell ν c) :
    c.2 + 1 = ν.rowLen c.1

    A removable corner sits at the end of its row: c = (b, μ_b − 1).

    source
    theorem QOU.SchurWeyl.axialDistance_corner_addable (r : ℕ) (ν : YoungDiagram) {s c : ℕ × ℕ} (hs : Mathlib.IsAddableCell ν s) (hc : Mathlib.IsCornerCell ν c) (hsr : s.1 < r) (hcr : c.1 < r) :
    BraidKnot.TableauContent.axialDistance c s = ↑(betaR r ν s.1) - ↑(betaR r ν c.1) + 1

    The content-to-β dictionary.

    For an addable cell in row a and a removable corner in row b of the same diagram, both rows below r,

    axialDistance corner cell = β_a − β_b + 1.

    An addable cell has content β_a − (r−1); a removable corner has content β_b − r.
