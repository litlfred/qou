    QOU.SchurWeyl.SeminormalParam — the axial-distance parameter of the seminormal block #

    (bean qou-gjg6, step (i)/(ii) infrastructure)

    HoefsmitRep.lean provides seminormalBlock q a, the 2 × 2 building block of every size-2 s_i-orbit of Young's seminormal form, with one free parameter a. The general-λ construction needs that parameter as an explicit function of the axial distance d = axialDistance (cell of i) (cell of i+1). This file supplies it:

    seminormalParam q d = (q - q⁻¹) / (1 - q ^ (-2 * d))

    and proves the three facts that make it the right function.

    Why this is the correct parameter #

    It is fixed, not fitted. The concrete (2,1) matrix S1 was built by hand in HoefsmitRep.lean to satisfy the braid relation with S0, and its (0,0) entry is -1 / (q³ + q). In the tableau [[1,2],[3]] the entry 2 sits in cell (0,1) (content 1) and 3 in cell (1,0) (content -1), so σ_1 acts with axial distance d = -1 - 1 = -2, and

    seminormalParam q (-2) = (q - q⁻¹) / (1 - q⁴) = -1 / (q³ + q).

    S1_eq_seminormalParam below records that agreement, so the general formula is anchored on an independently-verified instance rather than asserted.

    What is delivered #

    • seminormalParam — the axial-distance rational function.
    • seminormalParam_one / seminormalParam_neg_one — a(1) = q, a(-1) = -q⁻¹. These are the size-1 orbit eigenvalues: when i and i+1 share a row the axial distance is +1 and the generator acts by q; when they share a column it is -1 and the generator acts by -q⁻¹. So the single formula covers the scalar orbits and the 2 × 2 orbits uniformly — there is no case split in the parameter, only in the block size.
    • seminormalParam_add_neg — a(d) + a(-d) = q - q⁻¹, i.e. the two diagonal entries of a size-2 block are a(d) and a(-d), matching seminormalBlock's trace. This is what makes the block symmetric under exchanging the two tableaux of the orbit.
    • S1_eq_seminormalParam — the anchor: S1 q = seminormalBlock q (seminormalParam q (-2)).

    Scope #

    This is infrastructure for the general-λ seminormal representation hoefsmit_seminormal_rep, which is proved — sorry-free, for every λ ⊢ N at any real q ≠ 0 that is not a root of unity — in HoefsmitRepGeneral.lean, off SeminormalRep.seminormalRepFin. It supplies the parameter function of steps (i)–(ii) of that construction. Step (iii) — the generic size-6 S₃-orbit braid identity — is proved in Orbit6Braid.lean (genA_genB_braid), which consumes this parameter.

    K

    The axial-distance parameter of the seminormal block. For an s_i-orbit whose axial distance is d, the (0,0) entry of the seminormal matrix of σ_i is

    a(d) = (q - q⁻¹) / (1 - q^{-2d}).

    At d = 1 (entries in the same row) this is q; at d = -1 (same column) it is -q⁻¹; at d = -2 it is the (0,0) entry of the hand-built (2,1) matrix S1.

      theorem QOU.SchurWeyl.Seminormal.seminormalParam_mul_neg_one {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (hq2 : q ^ 2 ≠ 1) :
      seminormalParam q 1 * seminormalParam q (-1) = -1

      At a scalar distance the block degenerates: a(1)·a(-1) = -1.

      The two size-1 eigenvalues q and -q⁻¹ multiply to -1, so 1 + a(d)a(-d) — the off-diagonal factor of seminormalBlock, and the d < 0 branch of SeminormalRep.offDiag — vanishes exactly at d = ±1.

      This is what makes the smaller orbits consistent. A size-1 orbit is a 1 × 1 block sitting inside the same uniform entry rule as every other; the rule would supply an off-diagonal entry 1 + a(d)a(-d) for it, and the whole construction only coheres because that entry is zero. Equivalently: seminormalBlock at a = q has determinant -1 and trace q - q⁻¹, and is already diagonal.

      theorem QOU.SchurWeyl.Seminormal.seminormalParam_rel {K : Type u_1} [Field K] (q : K) (p r : ℤ) (hq : q ≠ 0) (hp : q ^ (-2 * p) ≠ 1) (hr : q ^ (-2 * r) ≠ 1) (hpr : q ^ (-2 * (p + r)) ≠ 1) :
      seminormalParam q (p + r) * (seminormalParam q p + seminormalParam q r - (q - q⁻¹)) = seminormalParam q p * seminormalParam q r

      The three parameters of a ⟨s_k, s_{k+1}⟩-orbit satisfy one relation.

      At distances p, r and their sum — the only distances that occur across such an orbit (TableauCells.axialDist_succ_swapTableau, axialDist_swapTableau_word_left) — the three values are not independent:

      a(p+r)·(a(p) + a(r) - (q - q⁻¹)) = a(p)·a(r)

      This is Orbit6.seminormalParam_mul_rel stated directly on seminormalParam rather than on the multiplicative coordinates x = q^{-2p}, y = q^{-2r}, so it can be used where the distances are read off tableaux rather than chosen. It is the sole algebraic input the braid relation needs beyond seminormalParam_add_neg.
