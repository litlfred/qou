    QOU.SchurWeyl.OcneanuWeightWenzl — the derived weight IS schurPrincipal at level 2 #

    Why this file exists #

    QOU/QBeta/WenzlWeightVanishing.lean says of its own central definition:

    Wenzl's theorem — the external input, and the only one — is that these are the Ocneanu/Markov trace weights on H_n(Q) at Markov parameter z_W = Q^r(1−Q)/(1−Q^r).

    and docs/audits/2026-08-16-two-row-cap-proved-and-deltalambda-magnitude.md records the consequence: the two-row cap and everything built on it are proved about schurPrincipal 2 Q μ, a named rational expression, and reading them as statements about the mass channel's Ocneanu weight is that citation. #print axioms cannot see the dependency, because it is carried by the choice of object rather than by an axiom.

    OcneanuWeight.ocneanuWeight is a different object with a different provenance: it was derived from the Markov defining conditions in exact ℚ(q,z) (computations/schurweyl/ocneanu_weight_general_n.py) and is Lean-proved to reproduce this repository's own proved n = 3 Markov weights (OcneanuWeightMarkov3). This file proves the two coincide at convention D:

    ocneanuWeight q (q³/(q²+1)) μ = schurPrincipal 2 (q²) μ / (q²+1)^{|μ|}

    for every Young diagram, no genericity hypothesis, no sorry.

    What that does and does not achieve #

    It does not discharge the Wenzl citation. It relocates it. Before, the citation attached to a formula recalled from the literature. After, it attaches to the single statement

    ocneanuWeight satisfies the Markov property tr(x·σ_n) = z·tr(x) at general n

    about a formula that was derived from those very conditions and is checked against the proved n = 3 case. That statement is open — see OcneanuWeight's docstring and bean qou-uer7 — but it is now a well-posed Lean goal rather than a bibliography entry, and proving it would discharge the corpus's only external input here outright.

    The immediate payoff is smaller and concrete: the vanishing result ocneanuWeight_conventionD_eq_zero_of_three_rows, proved standalone in OcneanuWeight, is a duplicate of schurPrincipal_eq_zero_iff and is re-derived here from it, with the sharper iff.

    Base ring (§7c) #

    Generic [Field R] throughout — no ℝ, no ordering. hookLength_eq_hook is pure ℕ combinatorics.

    theorem QOU.SchurWeyl.hookLength_eq_hook {mu : YoungDiagram} {x : ℕ × ℕ} (hx : x ∈ mu.cells) :
    hookLength mu x = QBeta.WenzlWeight.hook mu x

    OcneanuWeight.hookLength (a Finset.card, hence decide-evaluable on concrete diagrams) agrees on cells with QOU.QBeta.WenzlWeight.hook (arm + leg via rowLen/colLen).

    Two definitions of one notion is a duplication; this lemma is the price of the computable one, and is stated so that no other file has to choose between them.

    theorem QOU.SchurWeyl.ocneanuNumFactor_conventionD {R : Type u_1} [Field R] (q : R) (hq2 : q ^ 2 + 1 ≠ 0) (i j : ℕ) :
    q ^ (2 * i) * (q ^ 2 - 1 - q * (q ^ 3 / (q ^ 2 + 1))) + q ^ (2 * j + 1) * (q ^ 3 / (q ^ 2 + 1)) = (q ^ (2 * j + 4) - q ^ (2 * i)) / (q ^ 2 + 1)

    The per-cell identity. At z = q³/(q²+1) the numerator factor of the cell (i,j) collapses to (q^{2j+4} − q^{2i})/(q²+1) — a difference of two monomials over the fixed denominator q²+1. This is the whole content of the bridge; everything else is bookkeeping.

    theorem QOU.SchurWeyl.schurPrincipalNumFactor {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) (i j : ℕ) :
    (q ^ 2) ^ i * (1 - (q ^ 2) ^ (2 + QBeta.WenzlWeight.content (i, j))) = q ^ (2 * i) - q ^ (2 * j + 4)

    The schurPrincipal numerator factor of the cell (i,j), with the Q^{n(λ)} prefactor distributed one power per cell: Q^i · (1 − Q^{2 + c}) = q^{2i} − q^{2j+4}.

    theorem QOU.SchurWeyl.ocneanuWeight_conventionD_eq_schurPrincipal {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) (hq21 : q ^ 2 + 1 ≠ 0) (mu : YoungDiagram) :
    ocneanuWeight q (q ^ 3 / (q ^ 2 + 1)) mu = QBeta.WenzlWeight.schurPrincipal 2 (q ^ 2) mu / (q ^ 2 + 1) ^ mu.cells.card

    The bridge. The derived general-n Ocneanu weight, evaluated at convention D's Markov parameter, is the level-2 principal Schur specialisation up to the normalisation [2]_{q²}^{|μ|}:

    ocneanuWeight q (q³/(q²+1)) μ = schurPrincipal 2 (q²) μ / (q²+1)^{|μ|}

    for every Young diagram — no genericity hypothesis on q beyond q ≠ 0 and q² + 1 ≠ 0.

    See the module docstring for what this settles (the two objects are the same) and what it does not (the Markov property of either at general n).

    theorem QOU.SchurWeyl.ocneanuWeight_conventionD_eq_zero_iff {R : Type u_1} [Field R] (q : R) (hq : q ≠ 0) (hq21 : q ^ 2 + 1 ≠ 0) (hgen : ∀ (k : ℤ), k ≠ 0 → (q ^ 2) ^ k ≠ 1) (mu : YoungDiagram) :
    ocneanuWeight q (q ^ 3 / (q ^ 2 + 1)) mu = 0 ↔ 2 < mu.colLen 0

    The two-row cap for the derived weight, as an iff.

    ocneanuWeight q (q³/(q²+1)) μ = 0 ↔ μ has more than two rows.

    Not proved here: it is QBeta.WenzlWeight.schurPrincipal_eq_zero_iff transported along the bridge. OcneanuWeight.ocneanuWeight_conventionD_eq_zero_of_three_rows proves the forward direction directly and needs no root-of-unity hypothesis; this is the sharper statement and needs hgen, exactly as the corpus theorem does — at a root of unity a hook length can kill a denominator and the iff is false.
