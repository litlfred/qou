    QOU.SchurWeyl.HeckeSchurOrthogonality — Schur orthogonality for H_{m+1}(q) #

    Over a field K of characteristic 0, with q ≠ 0 not a root of unity, write ρ_λ for the seminormal representation of H_{m+1}(q) on shape λ ⊢ m+1 and c_λ = c_λ(q²) for its Schur element. Then for all partitions λ, μ and tableau indices,

    Σ_w ρ_μ(T_{w⁻¹})_{a d} · ρ_λ(T_w)_{b c} = c_μ · δ_{λ μ} δ_{b d} δ_{c a},
Σ_w χ_μ(T_{w⁻¹}) · χ_λ(T_w)             = δ_{λ μ} · c_μ · f^μ,

    where f^μ is the number of standard tableaux of shape μ.

    Main results #

    • repr_eq_symTrace — the T_w-coefficient of x is τ(x T_{w⁻¹}) (dual basis at qi = q⁻¹).
    • symTrace_eq_sum_schur_partition — τ = Σ_λ χ_λ / c_λ, indexed by partitions.
    • schur_orthogonality — the matrix-coefficient form.
    • schur_orthogonality_char — the character form.
    • heckeChar_linearIndependent — the irreducible characters χ_λ are linearly independent linear forms on H_{m+1}(q).

    Proof #

    Take x with ρ_ν(x) = 0 for ν ≠ μ and ρ_μ(x) = E_{d a} (Wedderburn surjectivity). The dual-basis expansion x = Σ_w τ(x T_{w⁻¹}) T_w, read in block λ at entry (b, c), is the claim, because τ(x T_{w⁻¹}) = tr(E_{d a} ρ_μ(T_{w⁻¹})) / c_μ = ρ_μ(T_{w⁻¹})_{a d} / c_μ.

    Base ring (§7c) #

    Generic [Field K] [CharZero K]; characteristic 0 is what the Wedderburn split (heckeProduct_surjective) uses. No ordering, no ℝ.
