    class QOU.MagicShell.DeltaCouplingSubstrateForm :
    Type

    Magic-shell stabilization energy as a substrate-derived closed form.

    The class encodes the conjecture that Δ_coupling at finite-A magic shells equals (A - 2) · E_0 · log(1/h(q_0)) — the thermodynamic free- energy correction per excess nucleon pair at the QOU Hecke-thermal scale, in the skein-convention normalisation.

    Fields are concrete propositional equalities asserting the closed form. When promoted to a theorem (post cross-anchor verification + LP-active-set derivation of (A-2)), the class instance becomes the genuine substrate derivation. Until then it is axiomatised as a conjecture class per AGENTS.md §3b.

    • q0 : ℝ

      The substrate parameter q_0 (Wenzl positivity regime).

    • q0_gt_one : 1 < q0

      q_0 > 1 — required for h(q_0) > 0 and log positivity.

    • m_e : ℝ

      Electron mass m_e (CAL-1 calibration anchor).

    • E_0 : ℝ

      The Hecke energy unit E_0 = m_e / (q_0 (q_0 - 1)).

    • E_0_def : E_0 = m_e / (q0 * (q0 - 1))

      E_0 definition holds.

    • delta_coupling : ℕ → ℕ → ℝ

      The Δ_coupling value at magic shell (Z, N) with mass number A.

    • closed_form (Z N : ℕ) : delta_coupling Z N = (↑(Z + N) - 2) * E_0 * Real.log (1 / (q0 - q0⁻¹))

      The closed-form claim: Δ_coupling(Z, N) = (A-2) · E_0 · log(1/h(q_0)).

For every (Z, N) at the magic- shell anchor, the skein-form expression (A - 2) · E_0 · log(1/(q_0 - q_0⁻¹)) equals the thermodynamic-form expression (A - 2) · E_0 · [log(1/((q_0-1)/q_0)) - log(1 + q_0)].

      noncomputable instance QOU.MagicShell.deltaCouplingSubstrateForm_canonical (q : ℝ) (hq : 1 < q) (m_e : ℝ) :
      DeltaCouplingSubstrateForm

      Canonical concrete instance of DeltaCouplingSubstrateForm for any Wenzl-regime (q, m_e).

      The instance discharges the class abstraction by defining delta_coupling Z N to be the closed-form expression (A - 2) · E_0 · log(1/(q - q⁻¹)). The closed_form field is then satisfied by rfl. The empirical claim — that this closed form matches the AME-extracted magic-shell stabilisation — remains the conjectural content (verified at the (Z,N)=(2,2) anchor with 0.71% gap).

      Construction: q0 := q (substrate parameter, q > 1) m_e := m_e (any positive value) E_0 := m_e / (q (q - 1)) (Hecke energy unit) delta_coupling Z N := ((Z+N) - 2) · E_0 · log(1/(q - q⁻¹)) closed_form := rfl (definitional)

      Ref: probe_delta_coupling_leading_form.py (numerical witness at q_0, ⁴He). Ref: docs/audits/2026-05-17-delta-coupling-substrate-derivation.md
