    QOU.Information.GeometryOfIncompleteness — the capstone #

    The corpus unification (incompleteness-implies-horizon-proof.md): Turing completeness, Gödel incompleteness, and physical intractability are three witnesses of one phenomenon — the vanishing of degree-0 sections Γ(𝓗, A₀) = 0. A degree-0 datum (a decision answer, a particle identity, a Gödel sentence's truth value) is behind the jet horizon when it is inaccessible, and there are two independent routes to inaccessibility:

    • formal — the datum is unprovable (Gödel, forced by Turing-completeness);
    • physical — extracting it is super-polynomial (the bandwidth bound, qou_physical_intractability_unconditional, derived from the 3^{3n} resolution tree).

    The capstone below assembles both into: a Turing-complete substrate has a nonempty horizon — degree-0 truth is inaccessible. Honest scope: the formal witness is Gödel incompleteness (standard, taken as the hypothesis ¬ formallyProvable); the physical witness is derived here; the identity "horizon = this inaccessibility" is the framework's degree-0 reading. This is an existence/necessity statement about substrate structure — it does not assert P ≠ NP (which needs the separate, open counting→decision transfer).

    structure QOU.Information.DegreeZeroDatum (Datum : Type u) :
    Type u

    A degree-0 datum: a decision answer / particle identity / truth value, carried as an element of a caller-supplied Datum type, together with the step-count needed to physically extract it.

    formallyProvable : Prop was a field until 2026-09-14 and is now a caller-supplied predicate (FormallyProvable : Datum → Prop, a parameter of Inaccessible below). As a field it was typed with the universe Prop, so the CONSTRUCTOR chose the proposition — and that made the capstone dischargeable with no mathematical content. Verified before the change, not asserted:

    example : ∃ d : DegreeZeroDatum, Inaccessible d :=
  horizon_nonempty { formallyProvable := False, extractSteps := fun n => n }
    not_false          -- compiled, exit 0

    "There exists a datum that is not formally provable" was proved by defining one whose provability proposition is literally False. The structure also had no datum in it — only a Prop and a step-count — so there was nothing for provability to be about.

    With Datum and FormallyProvable supplied by the caller, applying the capstone now requires exhibiting a real carrier and a real failure of provability on it — which is Gödel's theorem, i.e. content. And it is refutable: see not_inaccessible_of_all_provable.

    • datum : Datum

      The datum itself — the thing whose provability is at issue.

    • extractSteps : ℕ → ℕ

      The step-count of a physical extractor (as a function of instance size).

        The geometry of incompleteness (capstone, sorry-free). Given (i) a Gödel datum that is formally unprovable — the incompleteness witness, forced in any Turing-complete substrate — and (ii) a boundary datum whose bandwidth-B extractor must read the full 3^{3n} surviving resolution tree — the physical witness — the jet horizon is nonempty: some degree-0 truth is inaccessible. The boundary datum is inaccessible physically (derived via qou_physical_intractability_unconditional), and the Gödel datum is inaccessible formally. Incompleteness and physical intractability are the two faces of the vanishing of degree-0 sections.
