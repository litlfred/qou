    QOU.Information.SkeinGradeConnective — the surreal grade meets the three-wall bridge #

    SkeinObservationBridge packages q-Collatz (Halts), q-NS (Regular/BlowsUp), and P-vs-NP (PolyObservable) as three questions about one len-filtered Skein orbit read through obs = tr_M. Its P-vs-NP separation (not_polyObservable_id_of_horizon_cost) is proved only for the identity (linear) budget — lt_three_pow discharges the single gap len P < 3^{len P}.

    This file upgrades that separation to every polynomial budget by routing it through the surreal ω-grade squeeze (SurrealBudgetGrade): the horizon cost 3^{len} is genuinely super-polynomial, so no PolyBounded budget — not just the linear one — observes a whole size-indexed family. This is the exact statement "the P-vs-NP leg's 3^c resolution-tree cost out-grades every polynomial," now as a grade fact rather than a per-instance omega.

    Placement on the two axes (honest, per the categorical-dialogue roast): q-NS is bounded-vs-unbounded in time (magnitude axis); q-Collatz / P-vs-NP are reachability / reachability-at-polynomial-rate (quantifier axis). Sharing the len filtration does not reduce one to another — this file connects only the P-vs-NP leg to the grade, which is where the grade legitimately lives. All sorry-free; ℕ-valued (base ring N/A).
