    QOU.Information.ChiMinusSix — "Given a QOU, χ(A) = -6" #

    The non-vanishing leg of conj:qou-p-neq-np is an axiom consequence, not a conjecture: the corpus derives the scalar value of the universal obstruction class as χ(A) = -6 (ex:chi-minus-six-derivation, prf:qou-obstruction-reduction). This file formalises that derivation conditionally on the QOU (§3b-cond), so the statement is "given a QOU, χ(A) = -6" — never an unconditional numerology.

    The value is the topological Euler characteristic of Bring's curve, the genus-4 Riemann surface cut out by the icosahedral (A₅) geometry of the substrate:

    χ(A) = χ_top(Bring) = 2 - 2·g = 2 - 2·4 = -6.

    The class QOUObstruction carries the two genuine inputs — the Bring genus (g = 4, a classical fact about Bring's curve) and the obstruction-reduction identification χ(A) = χ_top(Bring) (the conjectural bridge, prf:qou-obstruction-reduction) — and the theorem derives -6 from them by Euler-characteristic arithmetic. It is non-degenerate (§3b-tax): the class holds the sub-hypotheses, the theorem composes them; it never carries -6 as a bare field.

      The cohomological assumptions a QOU is built from. A QOU's obstruction context is fixed by two Hochschild-cohomology facts of the categorical substrate A:

      • observability — the observability axiom kills degree-0 obstructions, HH⁰(A) = 0; and
      • Frobenius–Hopf self-duality — Yekutieli–Van den Bergh Poincaré duality is invoked for HH²(A) ≅ (HH¹)^∨ ≅ k, so HH² is rank one. (Corrected 2026-09-15: this line read (HH⁰)^∨, which with hh0 = 0 would give HH² = 0. The rank-one claim itself is now the Wigner axiom, conj:wigner-axiom, not a consequence of the QOU axioms: at q = 1 Whitehead's lemma gives HH²(U(𝔤), M) = 0; see docs/audits/2026-09-15-chi-as-a-component-of-the-chern-character.md §2.4.)

      Encoded by their ranks (hh0 = 0, hh2 = 1); the rank-one HH² is exactly why the universal obstruction is a single scalar.
