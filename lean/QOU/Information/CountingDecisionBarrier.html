    QOU.Information.CountingDecisionBarrier — the Toda barrier to the counting→decision transfer #

    A machine-checked record of why the framework's counting→decision transfer is not a chippable conjecture. The transfer is the open hypothesis (exact-Jones ∉ FP) ⟹ (P ≠ NP) — the transfer argument of faithfulness_of_transfer on main, and the entire remaining content of conj:qou-p-neq-np (see qou-p-neq-np.md, PR #4866).

    What this is — and is NOT #

    This does not formalize Toda's theorem, construct an oracle, or make the P≠NP conjecture any less open (Mathlib has no oracle / counting complexity). It records the propositional skeleton of the barrier: the one implication relating counting and decision that is a theorem —

    Toda: FP = #P ⟹ P = NP (#P ⊆ FP ⟹ PH ⊆ P^{#P} = P ⟹ P = NP)

    — and the sorry-free fact that the framework's transfer is its converse, which is not entailed by it. A concrete abstract world satisfies Toda yet has counting-hardness (¬ FP=#P) coexisting with P = NP; so #P-hardness alone cannot be the source of a P–NP separation. The actual barrier strengthening (an oracle with FP ≠ #P ∧ P = NP) is Toda's relativization, cited [toda1991]/[arora2009], not formalized here.

    Purpose: anti-flip-flop infrastructure — stop future agents from "deriving" the transfer from counting hardness; it is logically independent of the one true counting↔decision implication.

    structure QOU.Information.CountingDecisionWorld :
    Type

    An abstract world carrying the two separation propositions and the ONE implication between them that is a theorem: Toda's FP = #P ⟹ P = NP.

    • pEqNp : Prop

      P = NP holds in this world.

    • fpEqSharpP : Prop

      FP = #P (exact counting collapses to poly-time function computation) holds in this world.

    • toda : self.fpEqSharpP → self.pEqNp

      Toda's implication (#P ⊆ FP ⟹ PH ⊆ P^{#P} = P ⟹ P = NP): if exact counting collapses to FP, so does the decision hierarchy.

        ∃ (W : CountingDecisionWorld), ¬W.Transfer

        Toda barrier (sorry-free): the transfer is NOT entailed by Toda. A concrete world satisfies Toda (fpEqSharpP → pEqNp) yet falsifies the transfer — it has P = NP together with counting-hardness ¬(FP=#P). So no argument that uses only the counting↔decision implication which is actually a theorem can establish the transfer: #P-hardness alone cannot separate P from NP. This is the propositional skeleton of Toda's relativization barrier; the oracle strengthening is cited, not formalized.
