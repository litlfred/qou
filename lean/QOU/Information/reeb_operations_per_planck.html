    QOU.Information.reeb_operations_per_planck — discrete iterations per Reeb circuit #

    Proposition (prop:reeb-operations-per-planck).

    Let q ∈ k^× ∖ {1} and t_P(q) = q/(q − 1) the Planck time. The number of discrete f_q-iterations composing one Reeb circuit is

    n_R(q) = t_P(q) = q/(q − 1) = 1/ℏ_q, with ℏ_q = (q − 1)/q.

    Each iteration is one braiding evaluation (one R-matrix application) and one jet-prolongation step, advancing the phase by ℏ_q of a full circuit.

    Formalisation notes #

    • Derived arithmetic, not assumed. The headline chain n_R = t_P = q/(q−1) = 1/ℏ_q is derived from the definitions ℏ_q = (q − 1)/q, t_P = q/(q − 1), and n_R = t_P (the iteration count equals the Planck time, from the Reeb-time coordinate t = ℏ_q · 𝒯). The non-trivial step t_P = 1/ℏ_q is field_simp
      • ring. The phase-increment bound 0 < ℏ_q < 1 is likewise derived from ℏ_q = (q − 1)/q with q > 1.
    • The per-iteration counts (n_connection_apps = 1, n_R_matrix_evals = 1) are structural definitions of the discrete dynamics (one ∇_q application, one R-matrix evaluation per f_q-iteration), carried as honest data fields — not self-assumed conclusions.
    • Base ring (§7c) — ℝ here is correct. The class inherits a generic coefficient ring R from MarkovTraceContext, but the substrate parameter is deliberately specialised: the whole proposition rests on the ordering hypothesis 1 < q_real, and the proof runs through lt_trans, div_pos, div_lt_one and linarith. Ordering and linarith are archimedean, so this block sits after the substrate→archimedean wall. Reviewed under bean qou-mtcx; do not "port" it to R to reduce an ℝ count.
    • q_real is now tied to the inherited q : R (bean qou-mt7r). The class extends QOU.Shared.ArchimedeanEval, which carries an assumed evaluation eval : R →+* ℝ and derives q_real := eval q. It used to be an independent field, so a context could set q_real := 37 alongside an unrelated q and this proposition still held — it was a statement about a real number, not about this universe's substrate parameter. The evaluation is assumed, not constructed: it is not the archimedean τ-functor, and ArchimedeanEval.ofRingHom machine-checks how little it takes to inhabit.

    Inputs for the Reeb-operations-per-Planck identity.

    The substrate definitions (ℏ_q = (q−1)/q, t_P = q/(q−1), n_R = t_P) are carried as fields; the arithmetic identities t_P = 1/ℏ_q and 0 < ℏ_q < 1 are derived in the theorem, not assumed. The per-iteration operation counts are modelling data.
