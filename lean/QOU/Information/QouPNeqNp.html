    QOU.Information.QouPNeqNp — conjectural class + concrete decision-cost target #

    §3b-cond class axiomatisation for content block conj:qou-p-neq-np: $\mathrm{P} \neq \mathrm{NP}$ at non-torsion $q \in \mathbb{G}_m$.

    Two layers, mirroring the block's chippable/conjectural split:

    1. The conjecture — class QouPNeqNp, whose faithful field carries the open counting→decision transfer. No instance is provided (the honest §3b-cond form): downstream results take [QouPNeqNp decisionCost chiResidual] as an explicit hypothesis, so the assumption is visible in every signature. History: earlier revisions carried a fabricated ⟨0, rfl⟩ instance (bean cj2b6, sign-backwards) and then a named axiom discharging the instance (conj_qou_p_neq_np_faithful). The axiom + global instance made qou_implies_p_neq_np_at_chi look unconditional (its axiom-dependence hidden from the signature, visible only via #print axioms) — the "Axiomatization is NOT a Proof" pattern (AGENTS.md). Both are removed here. The transfer is a class hypothesis, never an axiom, never an instance.

    2. The chippable kernel — two sorry-free lemmas in the sibling module ObstructionGenericity formalising why a concrete non-vanishing $\chi(A) \neq 0$ cannot by itself discharge the conjecture.

    Concrete target (no longer opaque). Earlier PNeqNPInQOU was an opaque nullary Prop — a token disconnected from the framework's own content-bearing cost predicates. It is now the concrete statement the QOU decision-cost family is not polynomially bounded, ¬ FamilyPolyBounded decisionCost (CountingModuliGrade): "no uniform c·nᵏ bounds the decision cost at every moduli point." This is not an axiomatisation of literature $\mathrm{P}$/ $\mathrm{NP}$ (Mathlib has none, and asserting one would launder — AGENTS.md); it is the framework's own, falsifiable, QOU-scoped separation, wired to the same FamilyPolyBounded infrastructure the counting axis proves super-poly (CountingModuliGrade.physical_point_hard). The counting→decision transfer from res ≠ 0 to this remains the open conjecture (faithful).

        class QOU.Information.QouPNeqNp {M : Type u_1} (decisionCost : M → ℕ → ℕ) (residual : ℝ) :
        Prop

        Conjecture (P ≠ NP in the QOU), §3b-cond carrier.

        Given a QOU with substrate parameter $q_0 \in \mathbb{G}_m^{\mathrm{nt}}(\mathbb{R})$, the QOU decision-cost family is not polynomially bounded ([PNeqNPInQOU decisionCost]). The statement is conditional on the QOU: an instance of this class is the hypothesis "the QOU's obstruction faithfulness holds", and only from it is the separation derived — never a bare $\mathrm{P} \neq \mathrm{NP}$.

        Non-degenerate (§3b-tax): the class carries the faithfulness implication (a genuine sub-hypothesis — the counting→decision transfer), not the conclusion directly. residual is a parameter (a Prop-class cannot hold ℝ data); the QOU application fixes it to the derived chiResidual.

        No instance is provided — faithful is the open conjecture (the transfer no known result supplies), so downstream results carry [QouPNeqNp …] explicitly.
