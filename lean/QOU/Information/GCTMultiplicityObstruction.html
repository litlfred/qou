    QOU.Information.GCTMultiplicityObstruction — a formalize-first GCT scaffold #

    Geometric Complexity Theory (Mulmuley–Sohoni) separates complexity classes by representation-theoretic multiplicity obstructions: an irreducible (indexed by a partition λ) whose multiplicity in the coordinate ring of one orbit closure differs from its multiplicity in another. The QOU is structurally aligned — its Hecke algebra H_n(q) Wedderburn-decomposes by partitions λ ⊢ n with multiplicities (the SYT counts f^λ), and the Temperley–Lieb stratification (WenzlSchurElement.schurElement_tl_eq_zero_iff: at physical X = Q^{-N} the Schur elements of content-N cells vanish) is exactly a multiplicity drop distinguishing regimes.

    This file lays the formalize-first foundation:

    • the sorry-free separation logic — a multiplicity obstruction is a genuine separator, and a class invariant turns it into a class separation;
    • the QOU–GCT bridge as a §3b conditional class with no instance — GCT is an open program, so this scaffold contributes to it, it does not close it (§anti-laundering: axiomatization is not proof).

    Honest scope. Separating P from NP via GCT needs multiplicity obstructions for VP vs VNP, which is open — occurrence obstructions alone provably cannot do it (Bürgisser–Ikenmeyer–Panova, 2016). This file gives the QOU's version of the target and the foundational logic, not a separation.

        class QOU.Information.QouGCTObstruction (hard easy : ℕ → MultData) :
        Prop

        The QOU–GCT bridge (conjecture; NO instance — GCT is open). Conjectures that for each n the resolution-tree obstruction is realised as a multiplicity obstruction at some partition λ_n separating the counting-hard object hard n from every poly-time object easy n. The class field carries the per-n obstruction as genuine content; no instance is provided — a fabricated one would be a P-vs-NP (indeed VP-vs-VNP) separation. The QOU's concrete candidate for the multiplicity drop is the Temperley–Lieb stratification (WenzlSchurElement.schurElement_tl_eq_zero_iff): at physical X = Q^{-N} the content-N Schur elements vanish, dropping those λ-multiplicities.
