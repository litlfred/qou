    This module states the manuscript claim over a context class so the lean.ref URI resolves to a real, compiling declaration in the qou Lake package (§3b-conditional). See the declaration docstring below for what the term discharges versus what is carried as a context-class axiom.

    Base ring (§7c) — ℝ here is correct #

    ToffoliTransferMatrixContext inherits a generic coefficient ring R from QOU.Shared.MarkovTraceContext, but this block's amplitudes stay at ℝ: sub-claim (vi) is the closed form P_{7,7} = (q + Real.sqrt q − 1) / (q + 1), and a square root is an archimedean construct with no counterpart over a generic CommRing. The whole family of amplitudes is stated at the same specialisation for coherence, so the block sits after the substrate→archimedean wall. Reviewed under bean qou-mtcx; do not "port" it to R to reduce an ℝ count.

    q_real is genuinely used (it is the argument of Real.sqrt) and is now tied to the inherited q : R (bean qou-mt7r): the class extends QOU.Shared.ArchimedeanEval, which carries an assumed evaluation eval : R →+* ℝ and derives q_real := eval q. It used to be an independent field, so sub-claim (v) — the classical limit q_real = 1 → P_flip k = 0 — could hold at q_real = 1 while the substrate parameter sat anywhere at all. The evaluation is assumed, not constructed: it is not the archimedean τ-functor, and ArchimedeanEval.ofRingHom machine-checks how little it takes to inhabit.

      Manuscript sub-claim (ii) — σ₁ control-crossing transfer: V̂₁(k) = z·c(k) + d(k), which is type-dependent (NOT = z; the d offset distinguishes the control types). A target-flip fixes the control pair k, so the target-flip difference Δ₁ = 0 — the control crossing is unchanged, not type-blind.

    • claim_v_classical_limit (k : ℕ × ℕ) : self.q_real = 1 → P_flip k = 0

      Manuscript sub-claim (v) — Classical limit: every target-flip amplitude vanishes at q = 1 because the core carries (q − 1).

      The Toffoli-diagonal amplitude P_{7,7}(q) = (q + q^{1/2} − 1) / (q + 1).

      Manuscript sub-claim (vi) — Toffoli diagonal closed form: P_{7,7}(q) = (q + √q − 1) / (q + 1).
