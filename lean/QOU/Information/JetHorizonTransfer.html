    class QOU.Information.JetHorizonTransfer {M : Type u_1} (decisionCost : M → ℕ → ℕ) (chi : ℤ) :
    Type

    The jet-horizon transfer (§3b-cond conjectural class). Encodes the corpus's degree-graded horizon mechanism for a QOU obstruction of scalar value chi.

    • degreeZeroBlocked — the proposition Γ(𝓗, A₀) = 0 (degree-0 sections vanish on the horizon: the P-answer is inaccessible);
    • opacity_of_obstruction — a nonzero obstruction induces that opacity (res ≠ 0 ⇒ Γ(𝓗,A₀)=0);
    • transfer — the conjectural counting→decision bridge: with the degree-0 answer blocked and degree-≥1 witnesses leaking, P ≠ NP holds in the QOU.

    No instance is provided — transfer is the open identification. The decisionCost parameter names the QOU decision-cost family whose non-poly-boundedness (PNeqNPInQOU decisionCost) the transfer targets.

    • degreeZeroBlocked : Prop

      Γ(𝓗, A₀) = 0: degree-0 sections vanish on the jet horizon.

    • opacity_of_obstruction : chi ≠ 0 → degreeZeroBlocked decisionCost chi

      A nonzero universal obstruction forces degree-0 horizon opacity.

    • transfer : degreeZeroBlocked decisionCost chi → PNeqNPInQOU decisionCost

      The conjectural bridge: a blocked degree-0 answer (with degree-≥1 witnesses leaking) yields the QOU decision separation.
