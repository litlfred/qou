    QOU.Information.SkeinNPEncoding — the NP → Jones (Markov-trace) encoding #

    The hardness / reduction leg of the Skein-observation bridge (SkeinObservationBridge). That file supplied the lower-bound side — the 3^c resolution horizon (not_polyObservable_of_horizon_cost) and the residue obstruction. This file supplies the complementary encoding side: a polynomial-size many-one reduction of a decision problem into the skein (Markov-trace) observation, so the observation is at least as hard as the encoded language. When that language is NP-complete, the skein observation is NP-hard — the QOU-internal shadow of the classical fact that evaluating the Jones polynomial / Markov trace is #P-hard (Jaeger–Vertigan–Welsh).

    Contents (all sorry-free over the abstract SkeinObservationSystem):

    • NPSkeinReduction — a poly-size reduction: an encoding enc : I → S of instances as skein words, a Polynomial ℕ size budget encBudget with len (enc i) ≤ encBudget (size i), and correctness accepts i ↔ HaltsObserved (enc i).
    • eval_mono — Polynomial ℕ evaluation is monotone (nonneg coeffs).
    • decisionBudget — poly-time transfer: if the encoding's image is poly-observable under a single Polynomial ℕ budget obsBudget, then every accepted instance is decided within the genuine polynomial obsBudget.comp encBudget — poly∘poly is poly. A poly-observable skein observation collapses the encoded language into P.
    • not_uniform_polyObservable_of_superpoly — the contrapositive: a super-polynomial decision lower bound on the encoded language transfers to the skein observation (it is not poly-observable). The honest shadow of "the skein / Markov-trace observation is NP-hard".
    • accepts_of_observed — soundness of the observation as an acceptor, from the reduction's correct field.

    Honesty (STRICT). Nothing here proves P ≠ NP or constructs a concrete NP-complete braid encoding. The existence of the encoding for a specific NP-complete problem is carried as the structure's fields (an honest open input); what is proved is that any such reduction transfers polynomiality both ways. Nothing is wired to production. This composes with — does not replace — PNeqNpEquivalence.JonesComplexityCitations (the #P counting inclusion) and the instance-free QouPNeqNp carrier.

    structure QOU.Information.NPSkeinReduction {S : Type u_1} {V : Type u_2} (sys : SkeinObservationSystem S V) {I : Type u_3} (size : I → ℕ) (accepts : I → Prop) :
    Type (max u_1 u_3)

    A polynomial-size many-one reduction of a decision problem into the skein (Markov-trace) observation of sys. Each instance i : I of size size i is encoded as a skein word enc i whose observation decides membership, at a skein length polynomial in the instance size. This is the NP→Jones encoding: it witnesses that the skein observation is at least as hard as accepts.

    • enc : I → S

      Encoding of instances as skein words.

    • encBudget : Polynomial ℕ

      The polynomial size budget of the encoding.

    • enc_len_le (i : I) : sys.len (self.enc i) ≤ Polynomial.eval (size i) self.encBudget

      The encoding is polynomial-size in the instance.

    • correct (i : I) : accepts i ↔ sys.HaltsObserved (self.enc i)

      Correctness: the instance is accepted iff the encoded word is observed-halting (its Markov trace matches the normal form's).

      ∃ (i : I), accepts i ∧ ¬sys.PolyObservable (fun (x : ℕ) => Polynomial.eval x obsBudget) (red.enc i)

      NP-hardness lower bound transfers to the skein observation. If the encoded language admits no polynomial decision budget — for every candidate polynomial budget some accepted instance escapes it (its super-polynomial lower bound) — then the skein observation is not poly-observable under any single polynomial budget on the encoding's image. The honest QOU-internal shadow of "the skein / Markov-trace observation is NP-hard".
