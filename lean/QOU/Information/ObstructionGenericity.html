    QOU.Information.ObstructionGenericity — chippable genericity kernel (sorry-free) #

    Generic-R companion to QouPNeqNp / content block conj:qou-p-neq-np, split into its own file per §7c (these lemmas need no archimedean construct; the conjecture carrier's residual : ℝ stays in QouPNeqNp.lean).

    The two lemmas formalise why a concrete non-vanishing $\chi(A) \neq 0$ at a generic point cannot by itself discharge the conjecture: a nonzero polynomial obstruction vanishes at only finitely many parameter values, so its non-vanishing locus over an infinite domain is cofinite, hence infinite — a generic (Zariski-open) condition, never equivalent to a uniform hardness statement (the "case-(a) leak" in conj:qou-p-neq-np).

    theorem QOU.Information.obstruction_nonvanishing_locus_infinite {R : Type u_1} [CommRing R] [IsDomain R] [Infinite R] {f : Polynomial R} (hf : f ≠ 0) :
    {q : R | Polynomial.eval q f ≠ 0}.Infinite

    Chippable kernel (sorry-free). The non-vanishing locus of a nonzero polynomial obstruction is infinite (indeed cofinite): over an infinite domain, f.eval q ≠ 0 holds at all but finitely many q. Exhibiting a concrete χ(A) ≠ 0 at a generic q₀ is therefore an easy, generic condition — it cannot by itself be equivalent to the uniform hardness statement P ≠ NP without collapsing the claimed equivalence.
