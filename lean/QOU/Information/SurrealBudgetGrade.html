    QOU.Information.SurrealBudgetGrade — the ω-grade cost/budget squeeze #

    The surreal / Hardy-field ω-grading is a rigorous ordered home for the P-vs-NP cost/budget comparison: a growth function's ω-grade orders it against the polynomials. In these terms SuperPolynomial (from PhysicalIntractability) is exactly

    ord_ω(cost) > ord_ω(every polynomial budget),

    and a polynomial budget is a function whose ω-grade is ≤ that of some c·n^k. This file formalizes the grade algebra — the content of "surreal grading is bound management, not bookkeeping": the poly-budget grade is closed under the operations one performs while bounding (monotone domination), the super-poly grade is stable under adding or multiplying sub-dominant terms, and the super-poly grade strictly dominates the poly-budget grade (not_polyBounded_of_superPoly, the squeeze). Applied to the derived physical cost this gives, sorry-free, ¬ PolyBounded steps — the surreal squeeze ord_ω(steps) > ord_ω(budget) underlying the P ⊊ (bandwidth-limited) separation.

    All sorry-free; the nontrivial facts route through SuperPolynomial.of_le (the grade is monotone), so there are no n = 0 boundary artifacts.

    def QOU.Information.PolyBounded (f : ℕ → ℕ) :
    Prop

    Polynomially bounded — the budget grade: f is dominated by some polynomial c·nᵏ. In ω-grade terms ord_ω(f) ≤ ord_ω(nᵏ). This is the exact De Morgan dual of SuperPolynomial.
