    QOU.Information.p_bandwidth_bound — P-time iff bandwidth-bounded Skein #

    Proposition (prop:p-bandwidth-bound).

    A decision problem encoded by a link L = β̂ with c = 3N crossings is in P if and only if its Skein polynomial P_L(q) can be evaluated — degree-0 answer extracted — within

      t(c) ≤ 𝓑(q)⁻¹ · poly(c)

    Planck steps, where 𝓑(q) = q·η_q / (q − 1)² is the information bandwidth per Planck time.

    The Lean encoding records the iff as a Prop-valued claim against an abstract PBandwidthContext carrying the link / Skein / computational data, plus the bandwidth function 𝓑(q).

    -- Ref: [manuscript] quantum-observable-universe/information-theory/p-bandwidth-bound.md

    noncomputable def QOU.Information.informationBandwidth (q η_q : ℝ) :
    ℝ

    The information bandwidth per Planck time: 𝓑(q) = q · η_q / (q − 1)² (where η_q is the entropy function, abstracted here as a parameter).

    Unguarded signature. q is a bare ℝ here, so informationBandwidth 1 η is a legal call and returns 0 (Lean's x/0 = 0) at exactly the classical limit where the bandwidth is meant to blow up — see informationBandwidth_junk_at_one. Every intended use goes through PBandwidthContext, which carries q_gt_one : 1 < q and so excludes the point; the exposure is in the signature, not in any current consumer. Noted rather than fixed because tightening the signature would change a public declaration's type for a defect nothing currently reaches.

      class QOU.Information.PBandwidthContext :
      Type

      Abstract context for the P-time-iff-bandwidth claim.

      The two implication directions of the characterisation are carried as explicit hypotheses (§3b-cond non-degenerate pattern), matching the two halves of the manuscript proof:

      • p_to_bandwidth — the forward simulation: a polynomial-time Turing machine deciding the problem encodes as a braid with c = O(poly(N)) crossings, and the transfer-matrix product evaluates P_L(q) in O(c) matrix multiplications, i.e. within the bandwidth budget.
      • bandwidth_to_p — the converse funnel: if the factored Skein form has O(poly(c)) factors then each is computed in O(1) steps from the local transfer matrix, so the total cost is polynomial and the problem is in P.

      Neither field is the iff; p_bandwidth_bound derives it (Iff.intro), so the projection-vacuity test is not triggered.

      • q : ℝ

        The substrate parameter q > 1.

      • q_gt_one : 1 < q
      • η_q : ℝ

        The entropy parameter η_q > 0.

      • η_q_pos : 0 < η_q
      • c : ℕ

        Number of crossings c (typically c = 3N for a braid on N strands).

      • inP : Prop

        Predicate "the decision problem is in P".

      • bandwidthBounded : Prop

        Predicate "the Skein polynomial is evaluable within 𝓑(q)⁻¹ · poly(c) Planck steps".

      • p_to_bandwidth : inP → bandwidthBounded

        Forward direction (TM → braid simulation): a P-time decision problem admits a bandwidth-bounded Skein evaluation.

      • bandwidth_to_p : bandwidthBounded → inP

        Converse direction (interference funnel): a bandwidth-bounded Skein evaluation decides the problem in polynomial time.
