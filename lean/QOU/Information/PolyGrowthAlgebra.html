    QOU.Information.PolyGrowthAlgebra — the budget grade is a bound-management algebra #

    The surreal ω-grade is bound management, not bookkeeping (owner directive): the polynomial-budget grade must be closed under the operations one performs while bounding — dominate, add overhead, multiply a dressing factor. This file makes that precise.

    SurrealBudgetGrade.PolyBounded (∃ c k, ∀ n, f n ≤ c·nᵏ) is the right negation target for the squeeze, but the bare nᵏ shape has an n = 0 artifact — 0ᵏ = 0 for k ≥ 1, so e.g. n ↦ n + 5 is not PolyBounded — and hence is not closed under +. The constant-safe class

    PolyGrowth f  :=  ∃ c k, ∀ n, f n ≤ c · (n+1)ᵏ

    is the genuine polynomial-growth ideal: it contains the constants and the identity, and is closed under +, ×, and monotone domination — the algebra of bound management. PolyBounded ⊆ PolyGrowth (a PolyBounded witness is a PolyGrowth witness), so nothing about the squeeze is lost.

    All sorry-free. The bridge in the other direction — not_superPolynomial_of_polyGrowth : PolyGrowth ⟹ ¬ SuperPolynomial (polynomial growth genuinely undercuts the super-polynomial grade) — is proved below via the (n+1)ᵏ ≤ (2n)ᵏ = 2ᵏnᵏ domination for n ≥ 1. This is exactly the squeeze the grade wants: nothing polynomial-growth is super-polynomial. It works only because SuperPolynomial's witness is guarded n ≥ 1 — the earlier unguarded definition was satisfied by the plain polynomial (n+1)² via the n = 0 escape (c·0ᵏ = 0 < f 0), confirmed in Lean; repairing that (bean qou-qgyw) is what made this direction true. Base ring not applicable (ℕ-valued).

      The reverse squeeze: polynomial growth is never super-polynomial #

      source
      theorem QOU.Information.not_superPolynomial_of_polyGrowth {f : ℕ → ℕ} (h : PolyGrowth f) :
      ¬SuperPolynomial f

      PolyGrowth ⟹ ¬ SuperPolynomial (sorry-free). Polynomial growth strictly undercuts the super-polynomial grade — the reverse of the PolyBounded-side squeeze, on the constant-safe class. Given f ≤ c·(n+1)ᵏ and a super-polynomial witness n ≥ 1 for the scaled budget (c·2ᵏ, k), the domination (n+1)ᵏ ≤ (2n)ᵏ = 2ᵏnᵏ (valid exactly because n ≥ 1) forces f n ≤ c·2ᵏ·nᵏ, contradicting c·2ᵏ·nᵏ < f n. The n ≥ 1 guard on SuperPolynomial is what closes the n = 0 escape that made this false before (bean qou-qgyw).
