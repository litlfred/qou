    QOU.Information.GCTPerRankObstruction — the TL multiplicity drop at every rank #

    GCTSchurMultiplicity exhibits a single proved GCT multiplicity obstruction (the block [2] present at the substrate, dropped at the TL locus X = Q^{-1}). This file extends it to every rank: for each n ≥ 2 there is a size-n partition — the single row [n], whose cell (0,1) has content 1 — on which the substrate and TL-locus multiplicity data are SeparatedAt. So the Temperley–Lieb multiplicity drop is not an isolated coincidence; it occurs at all scales, giving the ∀ n, ∃ λ structural shape the GCT program needs.

    STRICT honest scope. This is the shape of a per-rank obstruction for the substrate-vs-TL-locus regime separation. It is deliberately not packaged as a QouGCTObstruction instance: that class carries the counting-hard object vs every poly-time object (VP-vs-VNP) content, which is the open program; instantiating it from this regime separation would be laundering a proved (but different) statement into the open one. The class stays instance-free; this file provides the structural precedent (obstructions exist at every rank), not the VP/VNP obstruction. All sorry-free; base ring ℝ (schurElement archimedean, §7c).
