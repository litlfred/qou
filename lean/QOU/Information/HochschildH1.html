    QOU.Information.HochschildH1 — first Hochschild cohomology HH¹(A) = Der(A)/Inn(A) #

    Mathlib's Derivation R A M is built for a commutative base algebra A acting on a one-sided module M; it does not cover the noncommutative associative A-bimodule derivations whose quotient by inner derivations is HH¹(A). This file supplies that infrastructure for any associative R-algebra A:

    • IsDerivation D — the Leibniz predicate on D : A →ₗ[R] A;
    • derivationSubmodule — the R-submodule Der(A) ⊆ A →ₗ[R] A of all derivations;
    • innerMap / innerDerivationSubmodule — the inner derivations Inn(A) as the R-linear range of x ↦ ad_x;
    • inner_le_der : Inn(A) ≤ Der(A);
    • HH1 R A := Der(A) ⧸ Inn(A) — the first Hochschild cohomology, as an R-module.

    This makes precise the objects the P-vs-NP residue lives among (OuterDerivationResidue): the decision residue is a nonzero class in HH1, and PROBE A's computation dim HH1(H₃(ζ)) = 1 (root of unity) vs = 0 (generic) is a statement about this very quotient. Generic {R : CommRing} {A : Ring} [Algebra R A]. NOT sorry-free: the file carries sorry (8 as of 2026-09-15), each with its -- Ref:; the header claimed otherwise until then.
