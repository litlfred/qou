    QOU.Information.OuterDerivationResidue — the residue is an OUTER derivation #

    HH₁(A) = Der(A) / Inn(A) — the first Hochschild cohomology is derivations modulo inner ones. The merged CocenterTraceFactor localized the magnitude axis at HH₀ = A/[A,A] and proved any decision separator is a non-trace. This file takes the next structural step on the decision axis: it identifies what an HH₁ class concretely is and shows the inner part is trace-blind, so the residue res — if nonzero — is carried by an outer derivation.

    The bridge to the merged cocenter #

    An inner derivation ad_x : a ↦ x·a − a·x has image inside the commutator submodule [A,A] (innerDerivation_mem_commutator). Since a cyclic functional (BilinearTrace.IsCyclic) kills [A,A] (commutatorSubmodule_le_ker_of_trace, merged), every inner derivation is trace-blind (trace_comp_innerDerivation_eq_zero). So the inner part of HH₁ is exactly the part the magnitude/trace tower already sees and discards; a decision class must be the complementary outer part Der(A)/Inn(A).

    Where this sits in the P-vs-NP wall #

    At generic q the Hecke algebra H_n(q) is semisimple, and a semisimple algebra has no outer derivations (first Whitehead lemma / separability: every derivation is inner), so HH₁(H_n(q)) = 0 — no residue can live there. The residue can therefore only appear at the root-of-unity / fibre level, where H_n(ζ) is non-semisimple and outer derivations can exist. IsInnerDerivation and the outer-residue question are stated honestly here as the definition of the search target; no instance is fabricated (whether the Bring-level H_n(ζ) carries the required outer derivation is exactly the open res ≠ 0 — PROBE A).

      The residue is the OUTER part — the open search target #

      def QOU.Information.IsInnerDerivation {R : Type u_1} [CommRing R] {A : Type u_2} [Ring A] [Algebra R A] (D : A →ₗ[R] A) :

      D is an inner derivation iff it equals ad_x for some x. The complement — an R-linear derivation not of this form — is an outer derivation, i.e. a nonzero class in HH₁ = Der/Inn. The decision residue, if nonzero, is such an outer class.

A decision functional must therefore be sensitive to an outer derivation — it cannot be a trace (not_trace_of_separates_commutator, merged), and the derivation it sees cannot be inner. That conjunction — a non-trace functional detecting an outer derivation at the fibre level H_n(ζ) — is the precise open content of res ≠ 0. No instance is asserted here.
