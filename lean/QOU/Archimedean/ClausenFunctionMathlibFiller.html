    Clausen function Cl_2 — repo-internal Mathlib filler #

    Mathlib does not currently expose the Clausen function

    Cl_2(θ) := Σ_{k=1}^∞ sin(kθ) / k² = Im(Li_2(e^{iθ})) = -∫_0^θ ln(2 sin(t/2)) dt (for 0 < θ < 2π)

    which is the imaginary part of the dilogarithm on the unit circle and the standard ingredient in hyperbolic-volume formulas:

    Vol(figure-8 knot 4_1) = 2 · Cl_2(π/3) ≈ 2.029883 Vol(Borromean rings B_3) = 8 · Cl_2(π/2) = 8G ≈ 7.327724

    Both volumes are needed in:

    • prop:em-coupling-bring-zero-mode (additive Bring zero-mode for 1/α_EM)
    • rem:figure-8-archimedean-illustration (algebraic / archimedean dichotomy)
    • binding-scale-catalan (Borromean = 8G nuclear binding scale)
    • conj:bring-hyperbolic-knot-bloch-decomposition (K-theoretic ID search)

    noncomputable def QOU.Archimedean.Cl_2 (θ : ℝ) :
    ℝ

    The Clausen function Cl_2 : ℝ → ℝ defined by the Fourier series

    Cl_2(θ) := Σ_{k≥1} sin(k θ) / k²

    via Mathlib's tsum. The series converges absolutely and uniformly on all of ℝ (since |sin(k θ) / k²| ≤ 1 / k²), The tsum is well-defined and continuous. Outside the standard fundamental domain [0, 2π] the function extends by periodicity (Cl_2(θ + 2π) = Cl_2(θ)).

          noncomputable def QOU.Archimedean.Vol_Borromean :
          ℝ

          Borromean rings hyperbolic volume carrier. By the 2-octahedron decomposition, each ideal regular octahedron decomposes into 4 ideal tetrahedra of shape parameter i = e^{iπ/2}, each contributing Cl_2(π/2) = G (Catalan). Per octahedron = 4G = 4·Cl_2(π/2); total Borromean volume = 8G = 8·Cl_2(π/2).
