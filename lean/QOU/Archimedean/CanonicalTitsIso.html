    theorem QOU.Archimedean.CanonicalTitsIso.canonical_frame_c_eq_one {n : Type u_1} [Fintype n] {k : Type u_2} [Field k] {T G_Markov G_Hodge : Matrix n n k} {c : k} (hprop : T.transpose * G_Markov * T = c • G_Hodge) (hiso : T.transpose * G_Markov * T = G_Hodge) (hGH : G_Hodge ≠ 0) :
    c = 1

    The canonical (*-isometric) frame pins c = 1. If the τ-intertwiner T realises both the Schur proportionality Tᵀ·G_Markov·T = c•G_Hodge and the exact *-isometry Tᵀ·G_Markov·T = G_Hodge (the defining property of the canonical Tits *-iso, both forms canonically normalised), then c = 1. This is the sense in which the canonical Tits iso removes the μ²-gauge freedom of #4192: it is the c = 1 frame.
