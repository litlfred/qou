    Capstone — the conditional W-P1 Tendsto (dilog Part B, V3) #

    This file fuses the three W-P1 ingredients into a single joint-(q,n) convergence statement:

    • riemann_error_bound_up (brick 3c) — the two-sided going-up Riemann-sum error bound 0 ≤ ∫_1^{qⁿ} h − S_n ≤ qⁿ(q−1)(h(qⁿ)−h(1));
    • integral_one_to_c_eq_LiTwo_sub (brick 3e) + tendsto_LiTwo_nhdsWithin_lt_one (brick 2's Abel limit) — the target integral ∫_1^{qⁿ} h = Li₂(xqⁿ) − Li₂(x) with limit π²/6 − Li₂(x) as xqⁿ → 1⁻;
    • boundary_term_vanishes (the analytic seed) — the boundary term (q−1)·(−log(1−xqⁿ)) → 0 under the Diophantine no-resonance bound.

    The conclusion is the honest conditional result: along any filter on which q → 1, the going-up geometric partition reaches the branch point (x·qⁿ → 1⁻) and the no-resonance bound 1 − x·qⁿ ≥ c·(q − 1) holds, the positive-factor W-P1 sum (q − 1)·Σ_{k<n} log(1 − x·qᵏ) converges to Li₂(x) − π²/6. No fit; the unconditional (all-x, Faddeev-scaling) case — where 1 − x·qⁿ ≥ c(q − 1) can fail along the resonant n = ⌊log_q(1/x)⌋ sequence — remains the research residual (bean qou-jplv).

    Capstone — conditional W-P1 convergence (joint (q,n) filter).

    Let l be any filter on an index type ι carrying substrate data q : ι → ℝ, n : ι → ℕ and a fixed target 0 < x. Suppose along l:

    • q → 1 (the substrate limit, hq) with 1 < q eventually (hq1);
    • x·qⁿ → 1⁻ (the going-up partition reaches the branch point, hxqn);
    • 1 − x·qⁿ ≥ c·(q − 1) eventually, c > 0 (the Diophantine no-resonance bound keeping the endpoint gap above the cell width, hc + hbound).

    Then the positive-factor W-P1 sum (q − 1)·Σ_{k<n} log(1 − x·qᵏ) converges to Li₂(x) − π²/6.

    Proof. Write S i for the going-up Riemann sum Σ_{k<n} h(qᵏ)(qᵏ⁺¹−qᵏ) and I i for ∫_1^{qⁿ} h. Brick 3e turns I = Li₂(xqⁿ) − Li₂(x), whose limit is π²/6 − Li₂(x) (brick 2's Abel limit composed with hxqn). Brick 3c bounds E := I − S by 0 ≤ E ≤ qⁿ(q−1)(h(qⁿ)−h(1)); the upper bound splits as (q−1)(−log(1−xqⁿ)) − qⁿ(q−1)(−log(1−x)), the first factor → 0 by boundary_term_vanishes (no-resonance) and the second → 0 since qⁿ → 1/x is bounded and q − 1 → 0. A squeeze gives E → 0, hence S = I − E → π²/6 − Li₂(x), and the W-P1 sum = −S (brick 3d) tends to Li₂(x) − π²/6.
