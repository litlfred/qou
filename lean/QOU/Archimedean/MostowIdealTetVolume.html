    Type

    The ideal-tetrahedron region + its dihedral angles, as a §3b conditional class.

    A datum supplies, for every acute admissible dihedral-angle triple (α, β, γ), the region tetRegion α β γ that a genuine ideal tetrahedron of those dihedral angles occupies in Milnor's normalized position, together with:

    • region_eq_chimney: the region IS a vertical chimney over the inscribed triangle (Milnor's normalization — the cited geometric input); and
    • tetDihedralAngles: the region's three ∞-edge dihedral angles are (α, β, γ) — the real geometric content, PROVED in File 4 for the chimney (chimney_infedge_dihedral_eq_vertexAngle). This field carries the dihedral angles, not the volume conclusion, and cannot be met by an arbitrary chimney over the wrong triangle.
    • tetRegion : ℝ → ℝ → ℝ → Set (Fin 3 → ℝ)

      The region an ideal tetrahedron of dihedral angles (α, β, γ) occupies in the upper half-space H³, in Milnor's normalized position.

    • region_eq_chimney {α β γ : ℝ} : 0 < α → 0 < β → 0 < γ → α < Real.pi / 2 → β < Real.pi / 2 → γ < Real.pi / 2 → α + β + γ = Real.pi → ∃ (t : ℝ), tetRegion α β γ = HyperbolicVolume.chimney (HyperbolicVolume.inscribedTriangle 1 t α β γ) 1

      Milnor's normalization (cited geometric input). For an acute admissible triple, the region equals the vertical chimney over the inscribed triangle.

    • tetDihedralAngles {α β γ : ℝ} : 0 < α → 0 < β → 0 < γ → α < Real.pi / 2 → β < Real.pi / 2 → γ < Real.pi / 2 → α + β + γ = Real.pi → ∃ (t : ℝ), tetRegion α β γ = HyperbolicVolume.chimney (HyperbolicVolume.inscribedTriangle 1 t α β γ) 1 ∧ dihedralAngle 1 (edgePerp (chordNormal (t + γ)) 1) (edgePerp (chordNormal (t + 2 * γ + 2 * α + β)) (-1)) = α ∧ dihedralAngle 1 (edgePerp (chordNormal (t + γ)) (-1)) (edgePerp (chordNormal (t + 2 * γ + α)) 1) = β ∧ dihedralAngle 1 (edgePerp (chordNormal (t + 2 * γ + α)) (-1)) (edgePerp (chordNormal (t + 2 * γ + 2 * α + β)) 1) = γ

      The dihedral-angle content (PROVED in File 4 for the realizing chimney). There is a normalized position t in which the region is the chimney over the inscribed triangle AND the three ∞-edge dihedral angles — the hyperbolic angles between the interior edge-perpendicular in-face vectors of the pairs of vertical faces — are exactly (α, β, γ). This is the real geometric content the class requires of an instance; it is discharged by chimney_infedge_dihedral_eq_vertexAngle.
