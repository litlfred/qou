    theorem QOU.Archimedean.analyticAt_real_sin (x : ℝ) :
    AnalyticAt ℝ Real.sin x

    Real.sin is real-analytic at every point. The complex sin is entire (Complex.analyticAt_sin); its restriction to the reals along ofReal, read off by the real part, is Real.sin (Complex.sin_ofReal_re). Mathlib proves the ℂ side but names no ℝ-side lemma, so this fills the gap.

    theorem QOU.Archimedean.analyticAt_neg_log_two_sin {t : ℝ} (h0 : 0 < t) (hπ : t < Real.pi) :
    AnalyticAt ℝ (fun (s : ℝ) => -Real.log (2 * Real.sin s)) t

    Λ'(t) = −log(2 sin t) is real-analytic on (0, π). On (0, π), sin t > 0, so 2 sin t > 0 and Real.log is analytic there (AnalyticAt.log); precompose with the analytic Real.sin and negate.

    This is the analytic input the obtuse ideal-tetrahedron volume identity's analytic-continuation route consumes for its derivative; it does not by itself make Λ analytic (see the file header).
