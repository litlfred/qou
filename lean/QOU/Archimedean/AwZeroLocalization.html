    1. Recentring: why index n owns the point z = w^{1−2n} #

    source
    theorem QOU.Archimedean.AwZeroLocalization.recentring_exponent (m n : ℤ) :
    m ^ 2 + (1 - 2 * n) * m = n - n ^ 2 + (m - n) * (m - n + 1)

    The Gaussian exponent of A_w recentres at index n under the substitution z = w^{1−2n} u: m² + (1−2n)m = (n − n²) + (m−n)(m−n+1). The right-hand side is a constant plus a Gaussian in m − n, so the term of index m = n is the extremal one at that argument.

        theorem QOU.Archimedean.AwZeroLocalization.tropRoot_lt_succ {w : ℝ} (hw0 : 0 < w) (hw1 : w < 1) (n : ℕ) :
        tropRoot w n < tropRoot w (n + 1)

        The tropical roots are strictly increasing for 0 < w < 1: the Newton polygon of A_w is strictly convex, so every corner is a genuine corner and distinct indices give distinct tropical roots. The whole statement reduces to w^{n+2} < 1 + w.

        5. The antitone Ω-factor (archimedean) — the grid-free majorant #

        source
        theorem QOU.Archimedean.AwZeroLocalization.omega_factor_key (w x : ℝ) :
        w * (1 - x) ^ 2 - (1 - w * x) ^ 2 = -((1 - w) * (1 - w * x ^ 2))

        The algebraic heart of the counting-circle majorant: w(1−x)² − (1−wx)² = −(1−w)(1 − wx²).

        source
        theorem QOU.Archimedean.AwZeroLocalization.omegaFactor_antitone {w x S T : ℝ} (hw0 : 0 < w) (hw1 : w < 1) (hx0 : 0 < x) (hx1 : x < 1) (hS : 0 ≤ S) (hST : S ≤ T) :
        ((1 - w * x) ^ 2 + 4 * (w * x) * T) / ((1 - x) ^ 2 + 4 * x * T) ≤ ((1 - w * x) ^ 2 + 4 * (w * x) * S) / ((1 - x) ^ 2 + 4 * x * S)

        Each factor of the Ω-quotient on the counting circle |u| = w⁻¹ is antitone in S = sin²(θ/2). With x = w^{2i+1} the factor is ((1 − wx)² + 4wx·S) / ((1 − x)² + 4x·S); monotonicity follows from omega_factor_key, whose right-hand side is negative for 0 < w < 1, 0 < x < 1. Evaluating at S = 0 therefore majorises the whole circle, which is what turns the Rouché threshold n₀(w) into a closed-form, grid-free quantity.
