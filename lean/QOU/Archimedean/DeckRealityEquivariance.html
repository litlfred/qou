    theorem QOU.Archimedean.DeckRealityEquivariance.conj_eigenvector_of_real {n : Type u_1} [Fintype n] {U : Matrix n n ℂ} (hU : U.map ⇑(starRingEnd ℂ) = U) {μ : ℂ} {v : n → ℂ} (hv : U.mulVec v = μ • v) :
    U.mulVec (star v) = (starRingEnd ℂ) μ • star v

    Conjugate eigenvectors of a real operator. If U is real (U.map star = U) and U·v = μ·v, then U·(star v) = (conj μ)·(star v): the complex eigenspaces of a real operator come in conjugate pairs.

    theorem QOU.Archimedean.DeckRealityEquivariance.deck_eigenspace_exchange {n : Type u_1} [Fintype n] {U : Matrix n n ℂ} (hU : U.map ⇑(starRingEnd ℂ) = U) {v w : n → ℂ} (hv : U.mulVec v = Complex.I • v) (hw : U.mulVec w = -Complex.I • w) :
    U.mulVec (star v) = -Complex.I • star v ∧ U.mulVec (star w) = Complex.I • star w

    Deck eigenspace exchange (the ρ-equivariance, proved). For a real deck matrix U, conjugation carries the i-eigenspace to the (−i)-eigenspace and back — F∘ρ = conj∘F at the eigenspace level for the T1 cover's deck action (multipliers ±i, derived in T1).
