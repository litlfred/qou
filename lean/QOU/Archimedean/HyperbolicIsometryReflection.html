    The vertical coordinate plane {x = 0}, as the subspace orthogonal to the first basis vector e₀ = single 0 1. Reflection across it negates x and fixes (y, z) — a vertical-plane reflection (it contains the height axis e₂).

      The conformal height-scaling data of the vertical reflection (lam ≡ 1). The reflection is a Euclidean isometry, so its derivative — itself, as a linear map — scales every norm by 1; and it fixes the height coordinate, so the height scales by 1 too.
