    Dilog Part-B W-P1 — the a.e. route, deterministic bricks (Borel–Cantelli programme) #

    The scope-(b) refutation (DilogPartBWP1Refutation) shows the unconditional pointwise branch-index limit is false; the only attainable positive over all x is the measure-theoretic one — for a.e. x ∈ (0,1), the branch-index boundary term → 0 — via a Borel–Cantelli argument on resonance windows (ledger docs/coordination/dilog-part-b-cusp-attack.md, bean qou-jplv/qou-zuuz; Mathlib has measure_limsup_eq_zero, lacks Weyl equidistribution).

    This file lands the deterministic heart of that programme — the two x-pointwise bricks that reduce a.e. convergence to a pure measure estimate (the one genuine research residual):

    • branch_endpoint_eq — the branch-index endpoint identity x·q^{⌊s⌋} = exp((⌊s⌋−s)·log q) with s := log(1/x)/log q (so the gap is governed by the resonance frac s = s − ⌊s⌋).
    • branch_gap_lower_of_fract — the no-resonance ⇒ gap bound: if frac s ≥ θ (θ>0) and q ∈ (1,2], then 1 − x·q^{⌊s⌋} ≥ (θ/4)(q−1). This is exactly the hypothesis boundary_term_vanishes (#4270) consumes, so frac s bounded below ⇒ the boundary term → 0. The remaining open brick is: the set {x : frac s_m < ε_m} has summable measure (the resonance-window Lebesgue estimate), then Borel–Cantelli gives a.e. frac bounded below.

    noncomputable def QOU.Archimedean.brS (x q : ℝ) :
    ℝ

    The resonance parameter s := log(1/x)/log q (> 0 for x ∈ (0,1), q > 1). The branch index is ⌊s⌋; the endpoint gap is governed by the fractional part s − ⌊s⌋.

      theorem QOU.Archimedean.branch_endpoint_eq {x q : ℝ} (hx0 : 0 < x) (hq1 : 1 < q) :
      x * q ^ ⌊brS x q⌋₊ = Real.exp ((↑⌊brS x q⌋₊ - brS x q) * Real.log q)

      Branch-index endpoint identity x·q^{⌊s⌋} = exp((⌊s⌋ − s)·log q). Since s·log q = log(1/x) = −log x, we get x·q^{⌊s⌋} = exp(−s·log q + ⌊s⌋·log q).

      theorem QOU.Archimedean.branch_gap_lower_of_fract {x q : ℝ} (hx0 : 0 < x) (hq1 : 1 < q) (hq2 : q ≤ 2) {θ : ℝ} (hθ0 : 0 < θ) (hfract : θ ≤ brS x q - ↑⌊brS x q⌋₊) :
      θ / 4 * (q - 1) ≤ 1 - x * q ^ ⌊brS x q⌋₊

      No-resonance ⇒ gap lower bound. If the resonance frac s = s − ⌊s⌋ ≥ θ (θ > 0) and q ∈ (1,2], then 1 − x·q^{⌊s⌋} ≥ (θ/4)(q−1). Feeds boundary_term_vanishes (#4270) with c = θ/4, closing the boundary term → 0 on the no-resonance set.

      Proof: 1 − x·q^{⌊s⌋} = 1 − e^{−a} with a = (s−⌊s⌋)·log q ≥ 0; 1 − e^{−a} ≥ a·e^{−a} (add_one_le_exp); a ≥ θ·log q ≥ θ(q−1)/2 (log q ≥ (q−1)/q ≥ (q−1)/2 on q≤2); and e^{−a} = q^{−frac} ≥ q^{−1} ≥ 1/2. Product ≥ (θ(q−1)/2)(1/2) = (θ/4)(q−1).
