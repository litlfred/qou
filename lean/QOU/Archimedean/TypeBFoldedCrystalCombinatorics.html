    Type-B folded crystal combinatorics #

    Following AGENTS.md §7b "Type B folding for chirality / CPT", this file gives concrete Lean infrastructure for the Type-B folded $\mathfrak{sl}_n$ crystal used in prop:crystal-basis-resolves-mass-tower-open-problems:

    • PartitionWithContent — a list-of-cells representation of a partition together with each cell's content c(x) = column - row.
    • transpose_partition — the involution λ ↔ λ^T that pairs cells with c(λ) + c(λ^T) = 0 summand-by-summand.
    • Cell.content_neg_under_transpose — the unconditional cancellation lemma: each cell (r, c) and its transpose (c, r) satisfy content (r, c) + content (c, r) = 0.

    These are the combinatorial primitives needed to encode the chirality factor's $\langle c \rangle_\beta$ Wedderburn-weighted sum as a Type-B-folded crystal computation. The folding pairs λ ↔ λ^T, and the cell-level content cancellation makes the self-paired part of $\langle c \rangle_\beta$ vanish; the non-trivial part is the imbalance between $\chi^\lambda(\beta)$ and $\chi^{\lambda^T}(\beta)$ along the Demazure components.

              theorem QOU.Archimedean.TypeBCrystal.content_plus_transpose_content_eq_zero (x : Cell) :
              x.content + x.transpose.content = 0

              Key lemma: the content of a cell and the content of its transpose sum to zero. This is the unconditional cancellation identity that makes Type-B folding "work":

              c(λ) + c(λ^T) = 0 cell-by-cell.

              The proof is direct integer arithmetic.

                      theorem QOU.Archimedean.TypeBCrystal.PartitionWithCells.content_sum_plus_transpose_content_sum_eq_zero (P : PartitionWithCells) :
                      P.content_sum + P.transpose.content_sum = 0

                      Folding cancellation theorem (sorry-free). The content sum of a partition plus the content sum of its transpose is zero.

                      This is the partition-level lift of Cell.content_plus_transpose_content_eq_zero: every cell's content cancels with the transpose-image cell's content, so the two list-sums sum to zero.

                      source
                      theorem QOU.Archimedean.TypeBCrystal.self_transpose_content_sum_zero (P : PartitionWithCells) (h : P = P.transpose) :
                      P.content_sum = 0

                      Self-pair fixed-point property. A partition equal to its own transpose has content sum zero. This is the "self-dual" partition case (e.g. (2, 2), (3, 1), (4, 1, 1, 1) etc.): folding pairs each cell with its transpose, and the fixed-point partition sits at the symmetric centre.
