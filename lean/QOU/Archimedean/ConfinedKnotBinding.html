    Confined Knot Binding: Extremal Cancellation and Crossing Balance #

    Formalises prop:confined-knot-binding:

    1. Wedderburn weight equality: W_sym = W_alt for H₃(q), because d_q((3)) = d_q((1,1,1)) = 1.

    2. Extremal cancellation: For the pn crossing (d = -HA/2), the symmetric and alternating channel contributions cancel: W_sym · χ_sym + W_alt · χ_alt = 0.

    3. Crossing balance: V_pp + V_nn = 2 · V_pn exactly.

    4. δV = HA/2: The deviation V_pp - V_pn = HA/2.

    All proofs are over the generic ground ring R_q = ℤ[q, q⁻¹], symbolic in q (§7c: no archimedean structure is used — these are algebraic identities, so we do not specialise to ℝ or a field).

    Base-ring note (2026-07-11). R_q is a CommRing, not a field, so the pn-crossing "half" d = -HA/2 cannot be written as a literal division. It is instead carried as an explicit hypothesis dh + dh = -HA (equivalently 2·dh = -HA), which is exactly the defining property of the midpoint and keeps every identity provable by ring / linear_combination over CommRing. This replaces an earlier draft that used / and linarith/nlinarith on ℤ[q,q⁻¹] — operations that LaurentPolynomial ℤ does not support (it is neither a field nor ordered), so that draft did not compile.

    §1 Wedderburn weights of H₃(q) #

    The symmetric (3) and alternating (1,1,1) reps of H₃(q) are the two one-dimensional reps. Both partitions have hook-length multiset {3,2,1} (they are transposes, and the hook multiset is transpose-invariant), so their hook-length q-dimensions d_q(λ) = [3]_q!/∏_{cells}[h]_q both equal 1. Over the CommRing R_q (no division) we record this as the numerator/denominator identity ∏hooks = [3]_q!.

                      §3 Extremal cancellation for pn crossings #

                      The pn crossing has d = -HA/2, carried as the hypothesis d + d = -(c · HA) (the defining property of the half).

                      source
                      theorem QOU.Archimedean.ConfinedKnotBinding.extremal_cancellation (c d : R_q) (hd : d + d = -(c * HA)) :
                      chi_sym c d + chi_alt c d = 0

                      For the pn crossing with d + d = -(c · HA) (i.e. d = -c·HA/2), the sum χ_sym + χ_alt = 0.

                      Proof: χ_sym + χ_alt = (c·q + d) + (-c·q⁻¹ + d) = c·(q - q⁻¹) + 2d = c·HA + 2d = 0.

                      source
                      theorem QOU.Archimedean.ConfinedKnotBinding.weighted_extremal_cancellation (w c d : R_q) (hd : d + d = -(c * HA)) :
                      w * chi_sym c d + w * chi_alt c d = 0

                      Since W_sym = W_alt, the weighted sum also vanishes: W_sym · χ_sym + W_alt · χ_alt = W_sym · (χ_sym + χ_alt) = 0.

                        For pp crossings the extremal contribution is +2w·HA and for nn it is -2w·HA; the SUM pp + nn cancels exactly. This is why Z=N nuclei preserve Frobenius stability.
