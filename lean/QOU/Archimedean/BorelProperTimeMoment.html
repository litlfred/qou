    class QOU.Archimedean.BorelProperTimeMoment.BindingKernelSchwingerRepresentation (Kb : ℝ → ℝ) :
    Prop

    Conjecture carrier (primary; no instance exists or may be created). The binding Borel resummation kernel — the weight K_b(s)·ds realizing the keystone-forced normalizer as N(n+1) = n! = ∫ s^{n+1}·K_b(s)·ds/s — is a positive measure on (0,∞) with exactly the factorial ds/s-moments. These fields are the two OPEN hypotheses that Attack A reduces the conjecture "binding Borel variable = loop proper time" to:

    • positive + integrable — the substrate resummation weight is a genuine positive measure (open: no corpus result establishes it; the C1 carrier coefficients I(n)/n! are NOT themselves a Stieltjes moment sequence — log-convexity fails at m = 2 — so this is a statement about the kernel, not the coefficients);
    • moments — its moments are the keystone-forced factorials (open: the keystone forces the NORMALIZER values (n−1)!, not that they arise as the moments of the substrate's own kernel).

    Given both, kernel_moments_eq_schwinger below (proved) plus classical Carleman–Stieltjes determinacy (carleman_divergence proves its hypothesis; the theorem itself is classical, unformalized) force K_b(s)·ds = e^{−s}·ds — the identification. Creating an instance of this class would launder the conjecture (§Axiomatization is NOT a Proof); none exists.
