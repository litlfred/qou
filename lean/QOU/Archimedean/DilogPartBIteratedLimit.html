    Part B of conj:dilogarithm-archimedean-limit — the INNER bulk-closure limit (W-P1) #

    The wp1_riemann_bound of DilogPartBBranchPointSum (PR #4262, sorry-free) sandwiches the positive-factor rescaled log-sum (1−q)·Σ_{k<n} log(1−xqᵏ) against the dilog difference Li₂(xqⁿ) − Li₂(x) with an explicit boundary-decomposition error, for any 1 < q and x qⁿ < 1:

    0 ≤ (Li₂(xqⁿ) − Li₂(x)) − (1−q)Σ log(1−xqᵏ) ≤ (q−1)·(−log(1−xqⁿ)) − (q−1)·qⁿ·(−log(1−x)).

    The iterated-limit reading of W-P1 (coordination ledger docs/coordination/dilog-part-b-cusp-attack.md, PR #4299, numerical probe computations/probes/dilog_partb_iterated_limit_probe.py, exit 0) closes the residual without any Diophantine / no-resonance hypothesis by taking the two limits in order:

    • INNER (this file, bulk): fix x ∈ (0,1) and a target ρ ∈ (x,1) interior, and choose n(q) = ⌊log(ρ/x)/log q⌋ — the largest n with x qⁿ ≤ ρ. Because ρ stays bounded away from the branch point u = 1/x, the endpoint converges cleanly: ρ/q < x q^{n(q)} ≤ ρ, so x q^{n(q)} → ρ⁻ as q → 1⁺ (the floor error frac·log q is absorbed by the 1/q → 1 factor — no oscillation, which is exactly what the interior ρ buys over the branch-point n = ⌊log_q(1/x)⌋). Then Li₂(x q^{n(q)}) → Li₂(ρ) by continuity of Li₂ on (0,1), and the wp1_riemann_bound majorant → 0 because −log(1 − x q^{n(q)}) ≤ −log(1 − ρ) is bounded (the Diophantine subtlety is sidestepped). Hence

      `−(1−q)·Σ_{k<n(q)} log(1−xqᵏ)  ⟶  Li₂(x) − Li₂(ρ)`   as `q → 1⁺`.

    • OUTER (sibling / follow-up): Li₂(x) − Li₂(ρ) → Li₂(x) − π²/6 as ρ → 1⁻, by the Abel / left-continuity brick tendsto_LiTwo_nhdsWithin_lt_one (sorry-free, DilogReflection.lean). The composite iterated limit is the W-P1 target Li₂(x) − π²/6 with no Diophantine input — the honest closeable route.

    This file provides the INNER brick, sorry-free:

    • nOfQ — the bulk floor index n(q) = ⌊log(ρ/x)/log q⌋₊.
    • nOfQ_mul_pow_le / nOfQ_mul_pow_gt — the two-sided endpoint bracket ρ/q < x q^{n(q)} ≤ ρ for 1 < q.
    • tendsto_nOfQ_mul_pow — the clean endpoint limit x q^{n(q)} → ρ in 𝓝[>] 1.
    • wp1_bulk_tendsto — the INNER bulk closure −(1−q)·Σ → Li₂(x) − Li₂(ρ).

    Everything is over ℝ (archimedean — LiTwo, Real.log, Real.exp, and the ordering 1 < q live past the substrate→archimedean wall).

      x * q ^ nOfQ x q ρ ≤ ρ

      Upper endpoint bound. For 0 < x, x < ρ, 1 < q: x · q^{n(q)} ≤ ρ. Floor gives n(q) ≤ log(ρ/x)/log q, so n(q)·log q ≤ log(ρ/x), hence q^{n(q)} = exp(n(q)·log q) ≤ exp(log(ρ/x)) = ρ/x.

      Lower endpoint bound. For 0 < x, x < ρ, 1 < q: ρ/q < x · q^{n(q)}. Floor gives log(ρ/x)/log q < n(q) + 1, so log(ρ/x) − log q < n(q)·log q, hence q^{n(q)} = exp(n(q)·log q) > exp(log(ρ/x) − log q) = (ρ/x)·(1/q) = ρ/(x q), so x q^{n(q)} > ρ/q.

      theorem QOU.Archimedean.wp1_bulk_tendsto {x ρ : ℝ} (hx0 : 0 < x) (hxρ : x < ρ) (hρ1 : ρ < 1) :
      Filter.Tendsto (fun (q : ℝ) => -((1 - q) * ∑ k ∈ Finset.range (nOfQ x q ρ), Real.log (1 - x * q ^ k))) (nhdsWithin 1 (Set.Ioi 1)) (nhds (QPochhammer.LiTwo x - QPochhammer.LiTwo ρ))

      INNER bulk closure of Dilog Part B W-P1. For fixed x ∈ (0,1) and a fixed interior target ρ ∈ (x,1), with the bulk floor index n(q) = ⌊log(ρ/x)/log q⌋, the positive-factor rescaled log-sum converges to the interior dilog difference

      −(1−q)·Σ_{k<n(q)} log(1−xqᵏ) ⟶ Li₂(x) − Li₂(ρ) as q → 1⁺.

      Proof: wp1_riemann_bound gives 0 ≤ (Li₂(xq^{n}) − Li₂ x) − (1−q)Σ ≤ E(q). The dilog difference → Li₂(ρ) − Li₂ x (endpoint x q^{n(q)} → ρ by tendsto_nOfQ_mul_pow, then continuity of Li₂ at the interior ρ). The majorant E(q) = (q−1)(−log(1−xq^{n})) − (q−1)q^{n}(−log(1−x)) → 0 because both boundary factors stay bounded away from the branch point (x q^{n} ≤ ρ < 1 and q^{n} ≤ ρ/x), so the width q−1 → 0 kills them — no Diophantine input. Hence (1−q)Σ = (Li₂(xq^{n}) − Li₂ x) − [error ∈ [0,E]] → Li₂(ρ) − Li₂ x, and negating gives Li₂(x) − Li₂(ρ). This is the INNER limit of the iterated-limit route; the OUTER ρ → 1⁻ limit (Li₂ x − Li₂ ρ → Li₂ x − π²/6) is the Abel brick tendsto_LiTwo_nhdsWithin_lt_one.
