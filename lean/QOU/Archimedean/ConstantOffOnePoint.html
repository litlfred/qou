    A continuous function with vanishing derivative off one point is constant #

    Bean qou-trns. This is the last gap in the 5₂ transport, isolated as a statement about real functions with no dilogarithm in it.

    Why the 5₂ lane needs exactly this #

    The transport S(e^{iφ}) − S(1) = φ² is proved by an envelope argument giving dS/dφ = 2φ. That argument needs the implicit function theorem, hence a non-vanishing discriminant — and QOU/QBeta/FiveTwoDiscriminant.lean proves the discriminant vanishes at one point of the arc. So the derivative identity is available on [0,π] minus a point, and S is continuous throughout.

    That is precisely the hypothesis set below.

    Why it is not immediate from Mathlib #

    constant_of_has_deriv_right_zero requires the right derivative at every point of Ico a b. Splitting at the bad point c works on [a,c] — where Ico a c excludes c — but fails on [c,b], whose Ico c b contains c. The fix is to apply it on [t,b] for each t > c and then let t → c⁺, using continuity. That is what constant_of_hasDerivWithinAt_zero_off_point does.

    The exceptional point may be an endpoint or lie outside [a,b] entirely; those cases are subsumed, since then the hypothesis simply holds everywhere needed.

    Continuous, and zero derivative off a single point, implies constant.

    f is continuous on [a,b] and has vanishing right derivative at every point of [a,b) except possibly one. Then f is constant.

    The excepted point costs nothing: on [a,c] the hypothesis already covers [a,c), and to the right of c one applies the standard result on [t,b] for each t > c and passes to the limit.
