    class QOU.Archimedean.ReidemeisterActionTableContext :
    Type 1

    Abstract context for the reidemeister_action_table claim — manuscript-themed typed fields below; sub-claims map to the rows of the manuscript table (each Reidemeister / Markov move's behaviour on the three action sectors plus volume and trace).

    • Z : ℕ

      Proton number Z.

    • N : ℕ

      Neutron number N.

    • q : ℝ

      Substrate parameter q : ℝ.

    • z : ℝ

      Markov parameter z = 1/(q^{1/2} + q^{-1/2}).

    • Braid : Type

      Braid representative type.

    • trM : Braid → ℝ

      Markov-trace function on braids tr_M : Braid → ℝ.

    • β : Braid

      The base braid β whose moves we're tracking.

    • β_R1 : Braid

      The braid after applying an R1 self-twist β ↦ β · σ_n.

    • claim_r1_self_twist : trM β_R1 = z * trM β

      Manuscript sub-claim (R1) — self-twist β ↦ β · σ_n scales the Markov trace by z.

    • β_R2q_split_one : Braid

      The two braids resulting from the q-deformed R2 split σ_i² = (q − q⁻¹)σ_i + 1: one with single crossing, one trivial.

    • β_R2q_split_two : Braid
    • claim_r2_q_deformed : trM β_R2q_split_one + trM β_R2q_split_two = (q - q⁻¹) * trM β_R2q_split_one + trM β

      Manuscript sub-claim (R2-q) — q-deformed second Reidemeister move splits the trace as tr(σ²β) = (q − q⁻¹)·tr(σβ) + tr(β).

    • β_R2c : Braid

      The braid after applying R2-classical σ_i σ_i⁻¹ = 1 (= original).

    • claim_r2_classical : trM β_R2c = trM β

      Manuscript sub-claim (R2-classical) — σ_i σ_i⁻¹ = 1 is the identity move; trace is preserved exactly.

    • β_R3 : Braid

      The braid after applying R3 Yang-Baxter.

    • claim_r3_yang_baxter : trM β_R3 = trM β

      Manuscript sub-claim (R3) — Yang-Baxter σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1} preserves the trace.

    • β_FC : Braid

      The braid after applying a far-commute swap.

    • claim_far_commute : trM β_FC = trM β

      Manuscript sub-claim (FarComm) — σ_i σ_j = σ_j σ_i (|i − j| ≥ 2) preserves the trace.

    • β_MI : Braid

      The Markov-I conjugate γ β γ⁻¹.

    • claim_markov_I_conjugation : trM β_MI = trM β

      Manuscript sub-claim (M-I) — Markov-I conjugation preserves the trace (cyclicity).

    • β_MII : Braid

      The Markov-II stabilised braid β · σ_n (positive case).

    • claim_markov_II_stabilisation : trM β_MII = z * trM β

      Manuscript sub-claim (M-II) — Markov-II stabilisation β ↦ β · σ_n multiplies the trace by z.

      Manuscript statement (full body):

      Every braid move acts on the three sectors of the categorical action $\mathfrak{S}_q = \mathfrak{S}_q^{\mathrm{grav}} + \mathfrak{S}_q^{\mathrm{gauge}} + \mathfrak{S}_q^{\mathrm{matter}}$ (canonical action). This table gives the complete accounting: what each move preserves, what it changes, and what must be tracked for mass and energy calculations.

      The categorical action on a nuclear link. For a nucleus $\mathcal{N}(Z, N)$ evaluated at the braid representative $\beta \in B_A$:

      $$ \mathfrak{S}_q[\beta] #

      \underbrace{E_0}_{\text{gravity}}

      \underbrace{\sum_{\text{crossings}} \mathcal{S}{ij}(q)}{\text{gauge}}

      \underbrace{\mathfrak{S}q^{\mathrm{matter}}}{\text{matter (Pauli + pairing)}} $$

      The gauge sector decomposes via the Iwahori--Hecke algebra: each crossing $\sigma_i$ contributes weight $q$ (positive), $q^{-1}$ (negative), or $(q + q^{-1})/2$ (mixed).
