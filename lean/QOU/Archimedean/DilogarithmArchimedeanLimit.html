    Dilogarithm Archimedean-limit primitives (QOU.QPochhammer) #

    Importable lib-module home for the sorry-free concrete primitives of the Faddeev–Kashaev / Archimedean-limit construction:

    • denomPolyLocal / partialProductLocal — the q-Pochhammer partial product Φ_n(x; q);
    • LiTwo — the classical dilogarithm series Σ_{k≥1} x^k / k²;
    • the boundary lemmas LiTwo_zero, denomPoly_zero, partialProduct_zero, faddeev_limit_at_zero;
    • the open conjecture class ArchimedeanLimit, its stated form partialProduct_to_LiTwo, and the unconditional boundary instance archimedeanLimit_zero.

    These were previously defined only in the content-block sibling mass-theory/dilogarithm-archimedean-limit.lean, which — being a content sibling, not a Lake module — is not importable. Downstream blocks that need the concrete primitives (predicted-spectra/cl2-pentagon-and-faddeev-partial, and the dilogarithm-archimedean-limit block itself) now import this module, giving the definitions a single source of truth. The conjecture class ArchimedeanLimit and its boundary instance were promoted here too (2026-06-29) so that the sibling phi-q-wkb-greens-function.lean, whose WKBGreensFunction class extends ArchimedeanLimit, can import the class rather than depend on a non-importable content sibling.

          class QOU.QPochhammer.ArchimedeanLimit (x : ℝ) :
          Prop

          The Archimedean-limit conjecture, packaged as a typeclass. A concrete instance asserts the convergence (1 - q) · log Φ_n(x; q) → Li₂(x) along Faddeev's scaling.

          • faddeev_limit (ε : ℝ) : ε > 0 → ∃ δ > 0, ∀ (q : ℝ) (n : ℕ), 1 - δ < q ∧ q < 1 ∧ ↑n * (1 - q) > δ⁻¹ → ‖(1 - q) * Real.log (partialProductLocal q x n) - LiTwo x‖ < ε

            The Faddeev limit of the rescaled log partial product equals the classical dilogarithm. The hypotheses on (q, n) capture the joint scaling q → 1, n → ∞, n(1-q) → ∞.

            instance QOU.QPochhammer.archimedeanLimit_zero :
            ArchimedeanLimit 0

            Unconditional instance at x = 0. The Faddeev limit holds trivially at the boundary point x = 0 because both sides of the asserted convergence are identically zero, so the limit is the constant zero sequence. This is the only point at which the ArchimedeanLimit class can be inhabited without further Mathlib infrastructure; for every x ∈ (0, 1) the instance requires the full Tauberian argument from Faddeev 1994 / Kashaev 1997.

            Part B primitives — the substrate q → 1⁺ continuation #

            Sorry-free primitives for the Part-B derivation (docs/audits/2026-07-17-dilog-archimedean-limit-partB-pole-cancellation.md, computations/dilog_archimedean_partB_probe.py): the substrate continuation crosses the cusp x = 1, where the factors 1 − x qᵏ with k > k* turn negative. The two facts formalizable within this module's imports (Log.Basic, InfiniteSum.Basic) are the algebraic pole-subtraction and the reduction of the cusp value LiTwo 1 to the Basel series.

            source
            theorem QOU.QPochhammer.log_neg_factor_split (w : ℝ) (hw : 1 < w) :
            Real.log (w - 1) = Real.log w + Real.log (1 - w⁻¹)

            Pole-subtraction (algebraic core of Part B). For a negative factor 1 − w < 0 (i.e. w > 1), the principal log|1 − w| = log(w − 1) splits as the algebraic pole log w plus the convergent remainder log(1 − w⁻¹):

            log(w − 1) = log w + log(1 − w⁻¹).

            This is exactly the subtraction that regularizes each k > k* factor in the Part-B continuation (the +iπ branch phase lives on the complex side and is the Faddeev modular anomaly; here we isolate the real magnitude).

            source
            theorem QOU.QPochhammer.LiTwo_one_eq_tsum :
            LiTwo 1 = ∑' (k : ℕ), 1 / (↑k + 1) ^ 2

            The cusp value LiTwo 1 is the Basel series ∑' 1/(k+1)² (definitional: 1^(k+1) = 1). This isolates the entire remaining analytic input of Part B to a single named Mathlib result: LiTwo 1 = π²/6 follows from hasSum_zeta_two (Mathlib.NumberTheory.ZetaValues, the Basel problem — ∑' n:ℕ, 1/n² = π²/6, whose n=0 term is 0), the extended-Bloch / Rogers regulator constant ζ(2) = Li₂(1) that Part B derives as the quantum-dilog inversion constant.

            source
            theorem QOU.QPochhammer.LiTwo_one :
            LiTwo 1 = Real.pi ^ 2 / 6

            The cusp value is ζ(2) = π²/6. Closes the last analytic input of the Part-B derivation: the residual LiTwo 1 left after the pole-subtraction and the T_w Frobenius truncation is the Basel constant, obtained here from Mathlib's hasSum_zeta_two (Basel problem, ∑' n:ℕ, 1/n² = π²/6) by splitting off the vanishing n = 0 term. This is the extended-Bloch / Rogers regulator constant ζ(2) = Li₂(1) that Part B identifies as the (quantum-)dilogarithm inversion constant.

            source
            theorem QOU.QPochhammer.LiTwo_neg_one :
            LiTwo (-1) = -Real.pi ^ 2 / 12

            Bar-odd cusp partner LiTwo (-1) = -π²/12. The alternating Basel value -η(2) = -ζ(2)/2, the natural sinh/bar-odd companion of the bar-even LiTwo 1 = π²/6. Proved by the duplication LiTwo 1 + LiTwo (-1) = π²/12: the combined summand g n = ((-1)^{n+1} + 1)/(n+1)² vanishes on even n, and its odd reindex n = 2k+1 is ½·(k+1)⁻², so ∑ g = ½·ζ(2) = π²/12 (the even/odd Function.Injective.hasSum_iff reindex, as in Mathlib's hasSum_log_sub_log_of_abs_lt_one). Subtracting ∑ (n+1)⁻² = ζ(2) leaves LiTwo (-1) = π²/12 - π²/6 = -π²/12.

            Part A primitives — the sub-unity reduction (x ∈ (0,1), q ∈ (0,1)) #

            The elementary (sub-unity) direction of conj:dilogarithm-archimedean-limit. These are the sorry-free algebraic steps that turn log Φ_n(x; q) into the per-factor -log(1 - x qᵏ) series; each factor then expands via the classical -log(1 - y) = Σ_{m≥1} yᵐ/m power series (Mathlib hasSum_pow_div_log). The remaining input of Part A — the uniform / Tauberian exchange of the q → 1⁻, n → ∞ limit with the m-sum that produces Li₂(x) = Σ x^m/m² — is the analytic core, still carried by the ArchimedeanLimit class (not discharged here). These primitives are the scaffolding that a proof of that exchange builds on.

            source
            theorem QOU.QPochhammer.neg_log_one_sub_hasSum {y : ℝ} (hy : |y| < 1) :
            HasSum (fun (m : ℕ) => y ^ (m + 1) / (↑m + 1)) (-Real.log (1 - y))

            Per-factor log expansion. Each Faddeev factor contributes the classical series -log(1 - y) = Σ_{m≥1} yᵐ/m for |y| < 1 (Mathlib hasSum_pow_div_log_of_abs_lt_one). Applied with y = x qᵏ this is the per-crossing term of the archimedean limit.

            theorem QOU.QPochhammer.partialProduct_log_eq (q x : ℝ) (n : ℕ) (hpos : ∀ k ∈ Finset.range n, 0 < 1 - x * q ^ k) :
            Real.log (partialProductLocal q x n) = ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k)

            First Part-A reduction: the log of the partial product is the finite sum of the per-factor logs, log Φ_n(x; q) = Σ_{k<n} -log(1 - x qᵏ), whenever every factor is positive (guaranteed for x ∈ [0,1), q ∈ [0,1]).

            source
            theorem QOU.QPochhammer.partialProduct_log_eq_tsum (q x : ℝ) (n : ℕ) (hpos : ∀ k ∈ Finset.range n, 0 < 1 - x * q ^ k) (hlt : ∀ k ∈ Finset.range n, |x * q ^ k| < 1) :
            Real.log (partialProductLocal q x n) = ∑ k ∈ Finset.range n, ∑' (m : ℕ), (x * q ^ k) ^ (m + 1) / (↑m + 1)

            Second Part-A reduction: each per-factor log becomes the Li-type power series, so log Φ_n(x; q) = Σ_{k<n} Σ'_{m} (x qᵏ)^{m+1}/(m+1). Requires each Faddeev factor to be both positive and inside the radius of convergence (|x qᵏ| < 1), automatic for x ∈ [0,1), q ∈ [0,1]. This is the exact, finite-n reduction of the log partial product to the double (k, m) series whose q → 1⁻ limit is Li₂; the outstanding Part-A input is the uniform (Tauberian) exchange of that limit with the m-sum, still carried by ArchimedeanLimit.

            source
            theorem QOU.QPochhammer.partialProduct_log_eq_mseries (q x : ℝ) (n : ℕ) (hpos : ∀ k ∈ Finset.range n, 0 < 1 - x * q ^ k) (hlt : ∀ k ∈ Finset.range n, |x * q ^ k| < 1) (hq1 : ∀ (m : ℕ), q ^ (m + 1) ≠ 1) :
            Real.log (partialProductLocal q x n) = ∑' (m : ℕ), x ^ (m + 1) / (↑m + 1) * ((q ^ ((m + 1) * n) - 1) / (q ^ (m + 1) - 1))

            Third Part-A reduction (the m-series): interchanging the finite k-sum with the m-tsum (Summable.tsum_finsetSum) and summing the geometric k-series (geom_sum_eq) puts log Φ_n(x; q) in closed m-series form

            log Φ_n(x; q) = Σ'_m x^{m+1}/(m+1) · (q^{(m+1)n} − 1)/(q^{m+1} − 1).

            This is the exact, finite-n object whose q → 1⁻ limit is Li₂(x): each (q^{(m+1)n} − 1)/(q^{m+1} − 1) → n → ∞-regularised factor tends to 1/(m+1) as q → 1⁻, turning the summand into x^{m+1}/(m+1)². The termwise limit + dominated-convergence exchange with the m-sum is the remaining analytic core (the ArchimedeanLimit class), NOT discharged here.

            Dilogarithm functional equations #

            The duplication (Landen) identity Li₂(x) + Li₂(-x) = ½ Li₂(x²) is a pure power-series identity — provable, like LiTwo_neg_one (its x = 1 special case), by the even/odd Function.Injective.hasSum_iff reindex. The Euler reflection Li₂(x) + Li₂(1-x) = π²/6 - ln x·ln(1-x) is a different kind of identity: it mixes the series with logarithms, so its proof needs the derivative d/dx Li₂(x) = -ln(1-x)/x (a HasDerivAt of the LiTwo tsum) + FTC — machinery Mathlib lacks a Real.dilog for. It is stated below as a queued formalization (honest sorry, not discharged).

            source
            theorem QOU.QPochhammer.liTwo_summand_summable {y : ℝ} (hy : |y| < 1) :
            Summable fun (k : ℕ) => y ^ (k + 1) / (↑k + 1) ^ 2

            Absolute summability of the LiTwo summand on the open unit disc: dominated, term by term, by the geometric series Σ |y|^{k+1} (each (k+1)⁻² ≤ 1).

            source
            theorem QOU.QPochhammer.LiTwo_duplication (x : ℝ) (hx : |x| < 1) :
            LiTwo x + LiTwo (-x) = 1 / 2 * LiTwo (x ^ 2)

            Duplication (Landen) identity Li₂(x) + Li₂(-x) = ½ Li₂(x²) for |x| < 1. Generalises LiTwo_neg_one (the x = 1 boundary case). The combined summand vanishes on even indices; its odd reindex k = 2j+1 collapses x^{2j+2} to (x²)^{j+1} and halves the weight, via the even/odd Function.Injective.hasSum_iff reindex + HasSum.unique.
