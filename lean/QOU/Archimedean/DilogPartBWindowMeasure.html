    Dilog Part-B W-P1 — the resonance-window measure estimate (a.e. Borel–Cantelli brick) #

    The deterministic bricks (DilogPartBBorelCantelli) reduce a.e. convergence to bounding the Lebesgue measure of the resonance window W(q,ε) := {x ∈ (0,1) : s − ⌊s⌋ < ε}, s := log(1/x)/log q.

    This file lands the geometric structure of that window — the single hard step of the measure estimate that avoids any change-of-variables: W is contained in a union of explicit x-intervals (q^{−(n+ε)}, q^{−n}], n ∈ ℕ (window_subset_iUnion). Each such interval has length q^{−n}(1 − q^{−ε}), so volume(W) ≤ (1−q^{−ε})·Σ_n q^{−n} = (1−q^{−ε})·q/(q−1) ≤ ε·log q·q/(q−1) — the bound that, with Mathlib's measure_limsup_eq_zero (first Borel–Cantelli) and the deterministic branch_gap_lower_of_fract, closes a.e. convergence. The remaining ENNReal geometric-sum arithmetic is bean qou-a0li.

    theorem QOU.Archimedean.window_subset_iUnion {q : ℝ} (hq1 : 1 < q) (ε : ℝ) :
    {x : ℝ | x ∈ Set.Ioo 0 1 ∧ brS x q - ↑⌊brS x q⌋₊ < ε} ⊆ ⋃ (n : ℕ), Set.Ioc (q ^ (-(↑n + ε))) (q ^ (-↑n))

    The resonance window is contained in a countable union of explicit intervals. W(q,ε) := {x ∈ (0,1) : s − ⌊s⌋ < ε} ⊆ ⋃ n, (q^{−(n+ε)}, q^{−n}]. This is the geometric heart of the measure estimate: each interval has length q^{−n}(1−q^{−ε}), summing to (1−q^{−ε})·q/(q−1) ≤ ε·log q·q/(q−1).

    theorem QOU.Archimedean.volume_window_le {q : ℝ} (hq1 : 1 < q) (ε : ℝ) :
    MeasureTheory.volume {x : ℝ | x ∈ Set.Ioo 0 1 ∧ brS x q - ↑⌊brS x q⌋₊ < ε} ≤ ∑' (n : ℕ), ENNReal.ofReal (q ^ (-↑n) - q ^ (-(↑n + ε)))

    Measure reduction. volume(W) ≤ Σ' n, (q^{−n} − q^{−(n+ε)}) — the window measure is bounded by the total length of the covering intervals (monotonicity + countable subadditivity + volume(Ioc a b) = b − a). The remaining geometric evaluation Σ' n, q^{−n}(1−q^{−ε}) = (1−q^{−ε})·q/(q−1) is bean qou-a0li.

    theorem QOU.Archimedean.volume_window_le_geom {q ε : ℝ} (hq1 : 1 < q) (hε0 : 0 ≤ ε) :
    MeasureTheory.volume {x : ℝ | x ∈ Set.Ioo 0 1 ∧ brS x q - ↑⌊brS x q⌋₊ < ε} ≤ ENNReal.ofReal ((1 - q ^ (-ε)) * (q / (q - 1)))

    Resonance-window measure bound (complete). For 1 < q and 0 ≤ ε, volume(W(q,ε)) ≤ (1 − q^{−ε})·q/(q−1) — the exact geometric bound. Evaluates volume_window_le's tsum: each term is q^{−n}(1−q^{−ε}) = (q⁻¹)ⁿ(1−q^{−ε}), a geometric series summing to (1−q^{−ε})·(1−q⁻¹)⁻¹ = (1−q^{−ε})·q/(q−1). With 1 − q^{−ε} ≤ ε·log q, this is ≤ ε·log q·q/(q−1), the summable resonance-window bound Borel–Cantelli consumes.
