    The chord P₁P₃ in chord-3 form. Its subtended half-angle γ + α = π − β exceeds π/2, so sarea_circlePoint_unit produces the perpendicular-bisector direction t + γ + α, which is θ₃ − π for the chord-3 direction θ₃ = t+2γ+2α+β. Rewriting with α + β + γ = π gives sarea P₁P₃ w = 2 sin β · (w·nθ₃ − cos β) — the same functional chord 3 tests, up to the sign carried by the − π shift.

    theorem QOU.Archimedean.idealTet_eq_chimney {t α β γ : ℝ} (hα0 : 0 < α) (hβ0 : 0 < β) (hγ0 : 0 < γ) (hsum : α + β + γ = Real.pi) :
    idealTetrahedron (HyperbolicVolume.circlePoint 1 t) (HyperbolicVolume.circlePoint 1 (t + 2 * γ)) (HyperbolicVolume.circlePoint 1 (t + 2 * γ + 2 * α)) = HyperbolicVolume.chimney (HyperbolicVolume.inscribedTriangle 1 t α β γ) 1

    THE THEOREM. The Milnor-normalized ideal tetrahedron with far vertex ∞ and three finite vertices on the unit circle at angles t, t + 2γ, t + 2γ + 2α (defined from those vertices in File A2, independently of any chord data) EQUALS the chimney over the inscribed triangle of angles (α, β, γ).

    This replaces region_eq_chimney := rfl with a genuine set-equality: the region is now an independent object, and its coincidence with the chimney is a proved theorem, not an adopted convention. Sorry-free; the only cited input is the totally-geodesic classification adopted as a definition in File A1.
