    Three substantive Mathlib gaps — partial fillings #

    This file attempts the three substantive remaining tasks from mass-tower-deeper-fillers.md:

    (1) BlochGroup F quotient. Free abelian group on (F \ {0,1}) × (F \ {0,1}) modulo the 5-term pentagon relation, plus the antisymmetry [x] + [1/x] = 0. (2) Pentagon identity for Cl_2. The 5-term identity in sine-form, derivable from the standard Li_2 pentagon via imaginary-part extraction. (3) Faddeev-Kashaev quasi-classical limit. Convergence of (1-q) · log Φ_n(x; q) → Li_2(x) along the joint scaling q → 1, n → ∞, n(1-q) → ∞.

    Each piece is partially formalised: enough Lean structure to encode the statement and produce a sorry-free conditional theorem, not enough to close the substantive content unconditionally (which requires either upstream Mathlib contributions or ~hundreds of additional lines of Lean infrastructure). The class hooks below are the §3b-cond surrogates downstream blocks already use.

            (2) Pentagon identity for Cl_2 #

            source
            class QOU.Archimedean.SubstantiveFillers.Cl_2_PentagonHolds :
            Type

            The 5-term pentagon identity for Cl_2 (sine-form). For five real arguments α, β, γ, δ, ε lying in the standard fundamental domain (0, 2π) and satisfying the pentagon closure relation, the alternating sum

            Cl_2(α) - Cl_2(β) + Cl_2(γ) - Cl_2(δ) + Cl_2(ε) = 0.

            This is the imaginary-part projection of the standard 5-term identity for Im(Li_2). Full proof requires Mathlib's Fourier infrastructure (sine-series rearrangements). We axiomatise the identity as a class hypothesis.

            • closure : (Fin 5 → ℝ) → Prop

              The pentagon-closure predicate on 5-tuples of angles: the imaginary-part projection of the standard Li_2 5-term relation. Its concrete defining equation is the open Fourier-rearrangement input Mathlib lacks; the class carries it abstractly as a hypothesis datum.

            • pentagon_holds_general (c : Fin 5 → ℝ) : closure c → (∀ (i : Fin 5), 0 < c i ∧ c i < 2 * Real.pi) → Cl_2 (c 0) - Cl_2 (c 1) + Cl_2 (c 2) - Cl_2 (c 3) + Cl_2 (c 4) = 0

              The 5-term sine pentagon for Cl_2: every closure-related 5-tuple c lying in the fundamental domain (0, 2π) makes the alternating Cl_2 sum vanish. This is the genuine vanishing content (not a tautology), conditional on the abstract closure datum above — the §3b-tax "shape of the claim".

              (3) Faddeev-Kashaev quasi-classical limit #

              source
              class QOU.Archimedean.SubstantiveFillers.FaddeevKashaevQuasiClassicalLimit (x : ℝ) :
              Type

              Faddeev-Kashaev quasi-classical limit class. A concrete instance encodes the convergence

              (1 - q) · log Φ_n(x; q) → Li_2(x)

              along the joint scaling q → 1, n → ∞, n(1-q) → ∞. The Φ_n(x; q) here is the q-Pochhammer partial product partialProductLocal q x n from QOU.QPochhammer (dilogarithm-archimedean-limit.lean), and the limit is in the strong (uniform-on-compact) sense.

              This is parallel to the existing ArchimedeanLimit class in dilogarithm-archimedean-limit.lean; we record it here as a typeclass to make the interface explicit at the substantive-fillers level.

              • q : ℕ → ℝ

                The joint-scaling sequence q_n → 1 realising the Faddeev-Kashaev limit (the n → ∞, n(1-q_n) → ∞ regime).

              • q_tendsto_one : Filter.Tendsto (q x) Filter.atTop (nhds 1)

                The scaling is admissible: q_n → 1. (The companion n(1-q_n) → ∞ divergence is the open analytic input; carried abstractly with the convergence field below.)

              • convergence_holds : Filter.Tendsto (fun (n : ℕ) => (1 - q x n) * Real.log (QPochhammer.partialProductLocal (q x n) x n)) Filter.atTop (nhds (QPochhammer.LiTwo x))

                The Faddeev-Kashaev quasi-classical limit, stated. Along the admissible scaling, (1 - q_n) · log Φ_n(x; q_n) → Li_2(x), where Φ_n = partialProductLocal q x n. This is the genuine Tendsto content of the convergence (not a True placeholder) — the §3b-tax "shape of the claim"; the analytic Tauberian estimate closing it is the open Mathlib input.
