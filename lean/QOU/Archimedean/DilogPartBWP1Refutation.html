    Dilog Part-B W-P1 — refutation of the UNCONDITIONAL joint boundary limit (scope-(b)) #

    The joint W-P1 capstone (tendsto_wp1_sum_of_no_resonance, #4270) proves W-P1 convergence conditionally on a Diophantine no-resonance bound c(q−1) ≤ 1−x·qⁿ. This file proves that hypothesis is necessary: the unconditional joint boundary limit (q−1)·log(1−x·qⁿ) → 0 is false, by exhibiting an explicit counter-sequence along which the boundary term converges to a nonzero value (log x ≠ 0). A scope-(b) refutation (AGENTS.md §"Before declaring refuted"): a proved obstruction with a named witness.

    The counter-sequence #

    For fixed x ∈ (0,1), L := log(1/x) > 0,

    q_m := exp(L / (m + e^{−m})), n_m := m.

    Then 1 < q_m, q_m → 1⁺, and x·q_m^m = exp(−β_m) → 1⁻ with β_m := L·e^{−m}/(m+e^{−m}) → 0, yet the boundary term does not vanish:

    (q_m − 1)·log(1 − x·q_m^m) ⟶ log x ≠ 0.

    The proof factors the term as A_m · B_m with

    • (A) A_m := m·(q_m − 1) → L (squeeze: t ≤ eᵗ − 1 ≤ t·eᵗ at t = L/(m+e^{−m}), both ends ·m → L);
    • (B) B_m := log(1 − x·q_m^m)/m → −1 (δ_m = 1 − e^{−β_m} ∈ [β_m e^{−β_m}, β_m], so log β_m − β_m ≤ log δ_m ≤ log β_m, and log β_m/m = log L/m − 1 − log(m+e^{−m})/m → −1).

    Then A_m · B_m → L·(−1) = −L = log x, and uniqueness of limits gives ↛ 0.

    Base ring (§7c) #

    Archimedean throughout (ℝ): Real.exp, Real.log, atTop limits.
