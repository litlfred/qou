    theorem QOU.Archimedean.dH_eq_of_leftInverse {φ ψ : HyperbolicMetric.E → HyperbolicMetric.E} (hφ : HyperbolicMetric.IsDHIsometry φ) (hψ : HyperbolicMetric.IsDHIsometry ψ) (hlinv : Function.LeftInverse ψ φ) (x y : HyperbolicMetric.E) :
    HyperbolicMetric.dH (φ x) (φ y) = HyperbolicMetric.dH x y

    dH is preserved by a pair of mutually-inverse dH-isometries. Neither generator here is involutive, so IsDHIsometry.dH_eq (which needs an involution) does not apply; instead we sandwich dH (φ x) (φ y) between dH x y (from φ) and itself (from a left inverse ψ). If ψ is also a dH-isometry and ψ ∘ φ = id, then dH (φ x) (φ y) = dH x y.

    Horizontal rotations — height-fixing linear isometries #

    source
    noncomputable def QOU.Archimedean.heightFixingLinearIsom (L : HyperbolicMetric.E ≃ₗᵢ[ℝ] HyperbolicMetric.E) (hL : ∀ (p : HyperbolicMetric.E), L p 2 = p 2) :
    HyperbolicMetric.IsDHIsometry ⇑L

    The conformal height-scaling data of a height-fixing linear isometry (lam ≡ 1). Any linear isometry L whose action fixes the height coordinate ((L p)_z = p_z) scales every tangent norm by 1 (it is an isometry) and scales the height by 1 (it fixes it), so it preserves the line element ‖v‖/z. Horizontal rotations of the (x,y)-plane are exactly this.

      The conformal height-scaling data of a dilation p ↦ s·p (s > 0). The derivative is the scalar map v ↦ s·v, scaling every norm by s; and the height scales by the SAME s: (s·p)_z = s·p_z.
