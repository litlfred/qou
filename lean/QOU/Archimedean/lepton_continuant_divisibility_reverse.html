    QOU.Archimedean.lepton_continuant_divisibility_reverse — reverse continuant divisibility #

    Proposition (prop:lepton-continuant-recurrence).

    Let b_n = morganVoyceB n be the Morgan–Voyce continuant over Polynomial ℤ (b_0 = 0, b_1 = 1, b_{n+2} = X·b_{n+1} + b_n), i.e. the Fibonacci-polynomial sequence with indeterminate X playing the Hecke parameter h = q − q⁻¹. Then for every a ≥ 1,

      b_a ∣ b_n  →  a ∣ n .

    Together with the forward law a ∣ n → b_a ∣ b_n (morganVoyceB_dvd_of_dvd, re-proved locally here), this establishes the strong-divisibility equivalence b_a ∣ b_n ⟺ a ∣ n (morganVoyceB_dvd_iff) — the polynomial Fibonacci divisibility law, closing the mathematical half of the three-generation continuant residual.

    Route #

    The Polynomial ℤ gcd-monoid infrastructure is thin, so we avoid the gcd(b_m, b_n) = b_{gcd(m,n)} identity and argue by a direct mod-reduction + degree bound:

    1. Addition law b_{m+n+1} = b_{m+1} b_{n+1} + b_m b_n (morganVoyceB_add, re-proved locally: the sibling forward-law branch is not on main).
    2. Consecutive coprimality IsCoprime b_n b_{n+1} (morganVoyceB_coprime_succ), from which IsCoprime b_a b_{a·q+1} (since b_a ∣ b_{a·q}).
    3. Mod reduction: writing n = a·q + r, the addition law + coprime cancellation give b_a ∣ b_n → b_a ∣ b_r.
    4. Degree bound: b_k is monic with natDegree = k − 1 for k ≥ 1 (morganVoyceB_monic_natDegree). For 0 < r < a, b_r ≠ 0 and natDegree b_r = r − 1 < a − 1 = natDegree b_a, so b_a ∣ b_r (with b_r ≠ 0) forces natDegree b_a ≤ natDegree b_r (natDegree_le_of_dvd) — a contradiction. Hence r = 0, i.e. a ∣ n.

    Kept over generic Polynomial ℤ (§7c: no archimedean specialisation required — this is pure q-deformation combinatorics).

    Addition law and forward strong divisibility (local re-proofs) #

    theorem QOU.Archimedean.morganVoyceB_add (m n : ℕ) :
    morganVoyceB (m + n + 1) = morganVoyceB (m + 1) * morganVoyceB (n + 1) + morganVoyceB m * morganVoyceB n

    Addition law for the Morgan–Voyce continuant: b_{m+n+1} = b_{m+1} b_{n+1} + b_m b_n.

    The polynomial Fibonacci addition identity, specialised to b_1 = 1, b_2 = X. Two-step induction on m from morganVoyceB_recurrence.

    theorem QOU.Archimedean.morganVoyceB_dvd_mul (n k : ℕ) :
    morganVoyceB n ∣ morganVoyceB (n * k)

    b_n ∣ b_{n·k}: the continuant of every multiple winding is divisible by that of the base winding. Induction on k from the addition law.

    Consecutive coprimality #

    source
    theorem QOU.Archimedean.morganVoyceB_coprime_succ (n : ℕ) :
    IsCoprime (morganVoyceB n) (morganVoyceB (n + 1))

    Consecutive continuants are coprime: IsCoprime b_n b_{n+1}.

    Induction on n. Base IsCoprime b_0 b_1 = IsCoprime 0 1; step b_{n+2} = X·b_{n+1} + b_n, so coprimality with b_{n+1} is inherited from IsCoprime b_{n+1} b_n by adding a multiple of b_{n+1} (IsCoprime.add_mul_right_right).

    Monicity and degree #

    theorem QOU.Archimedean.morganVoyceB_monic_natDegree (n : ℕ) :
    (morganVoyceB (n + 1)).Monic ∧ (morganVoyceB (n + 1)).natDegree = n

    b_{n+1} is monic with natDegree = n. Joint two-step induction; the sum X·b_{n+1} + b_n has its leading term supplied by the strictly-higher-degree first summand.

    Reverse divisibility and the equivalence #

    source
    theorem QOU.Archimedean.morganVoyceB_dvd_reverse {a n : ℕ} (ha : 1 ≤ a) (hdvd : morganVoyceB a ∣ morganVoyceB n) :
    a ∣ n

    Reverse strong divisibility of the Morgan–Voyce continuant. For a ≥ 1, b_a ∣ b_n → a ∣ n.

    Mod-reduction: with r = n % a, if r ≥ 1 then the addition law + coprime cancellation give b_a ∣ b_r, contradicting the strict degree bound natDegree b_r = r − 1 < a − 1 = natDegree b_a. Hence r = 0, i.e. a ∣ n.

    theorem QOU.Archimedean.morganVoyceB_dvd_iff {a n : ℕ} (ha : 1 ≤ a) :
    morganVoyceB a ∣ morganVoyceB n ↔ a ∣ n

    Strong-divisibility equivalence (polynomial Fibonacci divisibility). For a ≥ 1, b_a ∣ b_n ⟺ a ∣ n.

    Forward: morganVoyceB_dvd_of_dvd; reverse: morganVoyceB_dvd_reverse.
