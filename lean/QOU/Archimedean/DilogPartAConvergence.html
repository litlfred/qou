    Part A of conj:dilogarithm-archimedean-limit — the convergence core (Brick 3) #

    The remaining analytic core of Part A: the geometric-partition Riemann sum (1-q)·Σ_{k<n} −log(1 - x qᵏ) (= log Φ_n, Brick 1; = a left-Riemann sum, Brick 2) converges to ∫₀¹ −log(1 - x u)/u du = Li₂(x) as q → 1⁻, n(1-q) → ∞.

    Sub-bricks:

    • B3.1 integral_zero_one_eq_LiTwo — ∫₀¹ −log(1 - x u)/u du = Li₂(x), the change of variables t = x u from LiTwo_eq_integral (Brick A / PR #4088). This is the integral the Riemann sum targets.

    Further sub-bricks (B3.2 Lipschitz bound on the integrand, B3.3 Riemann-sum error, B3.4 tail control, B3.5 the ArchimedeanLimit instance) build on B3.1. No ArchimedeanLimit instance is fabricated — the convergence is proved, not axiomatised.

    theorem QOU.Archimedean.convexOn_neg_log_one_sub_mul {x : ℝ} (hx0 : 0 < x) (hx1 : x < 1) :
    ConvexOn ℝ (Set.Icc 0 1) fun (u : ℝ) => -Real.log (1 - x * u)

    Convexity of g(u) = −log(1 - x u) on [0,1] — log is concave on (0,∞), u ↦ 1 - x u is affine mapping [0,1] into (0,∞) (since x u ≤ x < 1), and negation flips concave to convex.

    B3.3b — the telescoping Riemann-sum error bound #

    source
    theorem QOU.Archimedean.riemann_error_bound {x q : ℝ} (hx0 : 0 < x) (hx1 : x < 1) (hq0 : 0 < q) (hq1 : q < 1) (n : ℕ) :
    0 ≤ ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k) / q ^ k * (q ^ k - q ^ (k + 1)) - ∫ (u : ℝ) in q ^ n..1, -Real.log (1 - x * u) / u ∧ ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k) / q ^ k * (q ^ k - q ^ (k + 1)) - ∫ (u : ℝ) in q ^ n..1, -Real.log (1 - x * u) / u ≤ (1 - q) * (-Real.log (1 - x * 1) / 1 - -Real.log (1 - x * q ^ n) / q ^ n)

    B3.3b — the Riemann-sum error bound. The left-Riemann sum S_n = Σ_{k<n} h(qᵏ)·(qᵏ − qᵏ⁺¹) over-estimates ∫_{qⁿ}^1 h by at most (1-q)·(h(1) − h(qⁿ)): 0 ≤ S_n − ∫_{qⁿ}^1 h ≤ (1-q)·(h(1) − h(qⁿ)). Proof by induction: each step adds a cell whose error is squeezed by the per-cell bounds (B3.3a) and telescopes.

    ∃ δ > 0, ∀ (q : ℝ) (n : ℕ), 1 - δ < q ∧ q < 1 ∧ ↑n * (1 - q) > δ⁻¹ → ‖(1 - q) * Real.log (QPochhammer.partialProductLocal q x n) - QPochhammer.LiTwo x‖ < ε

    Unconditional Part-A limit on (0,1). With archimedeanLimit_Ioo the [ArchimedeanLimit x] typeclass gate on the conditional consumer partialProduct_to_LiTwo is discharged for every x ∈ (0,1): the Faddeev- scaling convergence (1-q)·log Φ_n(x;q) → Li₂(x) holds outright, no instance hypothesis required.
