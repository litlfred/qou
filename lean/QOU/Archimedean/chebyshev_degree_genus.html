    QOU.Archimedean.chebyshev_degree_genus — Chebyshev degree equals Seifert genus #

    Lemma (lem:chebyshev-degree-genus).

    Let a : ℕ → Polynomial ℤ be the Hecke recurrence

      a 0       = 0
  a 1       = 1
  a (n + 2) = s · a (n+1) + a n          (s = Polynomial.X)

    Substituting u = s², for every odd positive p, the polynomial a p is a polynomial in u of degree (p − 1) / 2 = g(T_{2,p}) with leading coefficient 1.

    Lean structure — derived, not axiomatised #

    This file proves the lemma by strong induction on the recurrence depth; there is no §3b-cond axiom projecting the conclusion. The key lemma hecke_deg_monic shows the stronger unconditional fact that for every n ≥ 1 the polynomial a n is monic of natDegree n − 1 (the odd-p restriction in the .md is only the genus interpretation g(T_{2,p}) = (p − 1)/2; the degree / leading-coeff statement holds for all n ≥ 1). The inductive step uses that X · a(n+1) is monic of degree (n+1) while a n has strictly smaller degree (hecke_deg_le), so the sum is monic of degree n+1.

    The exported chebyshev_degree_genus then specialises to odd positive p, matching the manuscript statement, and leadingCoeff = 1 follows from monicity. Working in natDegree, natDegree(a p) = p − 1 = 2g, i.e. the u = s² re-expression has degree (p − 1)/2 = g.

    noncomputable def QOU.Archimedean.heckeRecurrence :
    ℕ → Polynomial ℤ

    The Hecke recurrence a over Polynomial ℤ, indexed by ℕ.

    a 0 = 0, a 1 = 1, a (n+2) = X · a (n+1) + a n. These are the Chebyshev-like polynomials whose specialisation at s = q^{1/2} + q^{-1/2} recovers the Markov-trace evaluations of the torus-knot family T_{2,n} in the Iwahori–Hecke algebra.
