    Dilog Part-B W-P1 — the a.e. Borel–Cantelli assembly, analytic + schedule bricks #

    The two hard endpoints of the a.e. positive are proved on main: the deterministic branch_gap_lower_of_fract (no-resonance ⇒ gap, DilogPartBBorelCantelli) and the volume_window_le_geom measure bound (DilogPartBWindowMeasure). This file provides the analytic + schedule inputs to the Borel–Cantelli assembly, for the canonical Faddeev schedule

    q_m := 1 + 1/(m+1) → 1⁺, ε_m := 1/(m+1)² = (q_m − 1)² (summable).

    The key analytic fact is that the boundary-term majorant vanishes:

    (q_m − 1)·(−log((ε_m/4)(q_m−1))) → 0.

    Because ε_m = (q_m−1)², the majorant argument is (q_m−1)³/4, so with w := q_m−1 → 0⁺, (q_m−1)·(−log(w³/4)) = w·log 4 − 3·(w·log w) → 0 — reusing the t·log t → 0 seed tendsto_mul_log_nhdsWithin_zero (#4270). With branch_gap_lower_of_fract (which gives δ_m ≥ (ε_m/4)(q_m−1)) this majorant squeezes the boundary term (q_m−1)·(−log δ_m) → 0 on the a.e. no-resonance set; the remaining measure-side plumbing (ENNReal summability of Σ volume(W_m), measure_limsup_eq_zero, ae threading) is bean qou-a0li.
