    class QOU.Archimedean.RealisationVolumeCompatibility.RealisationVolumeCompatibility (Braid : Type u_1) :
    Type u_1

    conj:archimedean-realisation-volume-compatibility (§3b class). A QOU volume datum on a type of braids carries two distinct realizations — the local archimedean realization tauInfty (the Habiro-ring q₀-evaluation τ_∞) and the topological / motivic realization Rtop — together with the hyperbolic volume Vhyp. The content (compat) is the motivic coincidence: both realizations agree with Vhyp on every braid. That the framework's actual τ_∞ and R_top realize one motive this way is the open conjecture; the class only names the shape.

    • tauInfty : Braid → ℝ

      Local archimedean realization τ_∞: the Habiro-ring q₀-evaluation of the volume class.

    • Rtop : Braid → ℝ

      Topological / motivic realization R_top of the volume class.

    • Vhyp : Braid → ℝ

      Hyperbolic volume of the braid.

    • compat (β : Braid) : tauInfty β = Vhyp β ∧ Rtop β = Vhyp β

      Content — the motivic coincidence. Both realizations agree with the hyperbolic volume on every braid: τ_∞ β = V_hyp β and R_top β = V_hyp β.

      The class is non-vacuous (shape-witness). Taking all three realizations to be the identity on ℝ gives a triple satisfying compat — the structural shape is inhabited. This witnesses the shape is realizable; it does not assert that the framework's genuine τ_∞ / R_top coincide (there is no instance for the actual realization functors).

      Conditional consequence (motivic content), derived from the class — name-compat with the old lean.ref. Given the coincidence compat, the two realizations agree: τ_∞ β = R_top β. The archimedean and the topological/motivic realizations of the one volume motive produce the same value.
