    The general Bloch–Wigner D via Lobachevsky — reaching 5₂ #

    BlochWignerMathlibFiller covers the two QOU knots whose ideal-tetrahedron shape parameters lie on the unit circle: the figure-8 (e^{iπ/3}) and the Borromean rings (i). There the boundary correction log|z|·arg(1−z) vanishes identically and D collapses to Cl₂. That file names the general case as an open gap:

    General D : ℂ \ {0,1} → ℝ for non-unit-circle shape parameters — needs Complex.log and Complex.arg infrastructure with branch-cut handling.

    5₂ is the first QOU knot that falls in that gap: its shape parameter has |y| = 1.52…, so the correction term does not vanish and Cl₂ alone does not express D.

    The route, and why it does not need a complex Li₂ #

    For z in the upper half plane the three dihedral angles of the ideal tetrahedron of shape z are

    α = arg z,    β = arg(1/(1−z)),    γ = arg(1 − 1/z),

    and the classical formula for its volume is Λ(α) + Λ(β) + Λ(γ) with the Lobachevsky function Λ(t) = Cl₂(2t)/2. So the general D is expressible in Cl₂ after all — through the angles rather than through z directly. No complex dilogarithm is required for D.

    (A complex Li₂ is still needed elsewhere, for Re Li₂(y₁) in the 5₂ saddle sum rule — that is bean qou-ph1k, and it is a genuinely different problem. This file does not close it and does not claim to.)

    What is proved here #

    • summable_clausen — the Clausen series is summable. Missing from the filler, and everything below needs it.
    • Cl_2_neg, Cl_2_add_two_pi — oddness and 2π-periodicity, from the series.
    • Cl_2_duplication — Cl₂(2θ) = 2Cl₂(θ) − 2Cl₂(π−θ), from the Fourier series by a parity split. sin(nπ − nθ) = −(−1)ⁿ sin(nθ) puts a factor 1 + (−1)ⁿ on each term, killing the odd n and doubling the even; the surviving half reindexes to Cl₂(2θ).
    • Cl_2_two_pi_div_three, three_Lob_pi_div_three — the consistency check. Duplication at θ = π/3 forces Cl₂(2π/3) = (2/3)Cl₂(π/3), so the general formula's value at the regular ideal tetrahedron, 3·Λ(π/3) = 3·Cl₂(2π/3)/2, collapses to exactly Cl₂(π/3) — the per-tetrahedron value behind the corpus's Vol(4₁) = 2·Cl₂(π/3). This is not rfl: it validates the non-unit-circle definition against a case the corpus already trusts.
    • tetAngles_sum_eq_pi — the substantive theorem: for Im z > 0, arg z + arg(1/(1−z)) + arg(1 − 1/z) = π. The three quantities really are the angles of a tetrahedron. The proof is that the three factors multiply to −1 while each lies in the open upper half plane, so the arg-sum is π mod 2π and confined to (0, 3π).
    • the 5₂ shape algebra: the saddle cubic, the Landen image, and the fact that the real root contributes nothing to D.

    What is NOT proved here — read before citing #

    The numerical identity behind this file is

    D(y₊) = Vol(5₂)/3,   y₊ = 0.7849201454990266… + 1.3071412786820454…i

    and it is published: Broadhurst [hep-th/9811173] eq (73) records vol(5₂) = 3·Z₂₃,₃, with Z₂₃,₃ the Zagier value of the discriminant −23 cubic field — the smallest |disc| among complex cubic fields, which is why that particular constant appears.

    Checked at 80 dps against a Vol(5₂) computed from the saddle roots (computations/probes/fivetwo_saddle_values.py::volume()), so no hardcoded constant enters and there is no precision ceiling. Three routes agree:

    Vol(5₂)/3                              0.9427073627769277209212996030922116…
Im Li₂(y₊) + arg(1−y₊)·log|y₊|         (same, |Δ| = 1.1e-81)
Λ(α) + Λ(β) + Λ(γ)   ← this file       (same, |Δ| = 2.1e-81)

    i.e. exact to working precision, and the dihedral-angle route agrees with the naive complex-Li₂ form it is meant to replace. It is recorded below as a conjecture carrier with no instance — the honest representation of a statement that is numerically settled and published but not formally derived here.

    The one open reason is geometric. Vol(5₂) = 3·D(y₊) needs the fact that the 5₂ complement's ideal triangulation is three tetrahedra all of the same shape y₊. That is Thurston/SnapPea, nowhere near Mathlib, and it is the actual mathematical content — the division by 3 is bookkeeping. Note that Vol_figure_8 and Vol_Borromean in the filler enter the corpus the same way, as definitions; their accompanying "theorems" are rfl. This file does not repeat that pattern: it names the geometric input instead of hiding it in a definition.

    An earlier revision of this header listed the Clausen duplication formula as a second open input, isolated as a ClausenDuplication carrier. That is now proved (Cl_2_duplication), the carrier is gone, and the consistency check it was gating is discharged: BlochWigner_lob reproduces the corpus's figure-8 per-tetrahedron value at the regular shape. So the general definition is no longer merely numerically validated — it agrees with the corpus on a case the corpus already trusts.

    The duplication formula #

    Cl₂(2θ) = 2·Cl₂(θ) − 2·Cl₂(π−θ), proved from the Fourier series. The mechanism: sin(nπ − nθ) = −(−1)ⁿ sin(nθ), so the bracket sin(nθ) − sin(n(π−θ)) carries a factor 1 + (−1)ⁿ — it vanishes for odd n and doubles for even n. Splitting the sum on parity and reindexing n = 2m returns Cl₂(2θ).

    source
    theorem QOU.Archimedean.Cl_2_duplication (θ : ℝ) :
    Cl_2 (2 * θ) = 2 * Cl_2 θ - 2 * Cl_2 (Real.pi - θ)

    The Clausen duplication formula.

    Cl₂(2θ) = 2·Cl₂(θ) − 2·Cl₂(π − θ)

    Proved from the Fourier series by the parity split described above. This is what ClausenDuplication was isolating; with it in hand the general BlochWigner_lob can be checked against the corpus's own unit-circle knots rather than only against numerics.

    source
    theorem QOU.Archimedean.Cl_2_two_pi_div_three :

            Part 3 — the general Bloch–Wigner value #

            With the angles in hand, the general D is a sum of three Lobachevsky values, hence expressible in Cl₂ alone.

            source
            noncomputable def QOU.Archimedean.BlochWigner_lob (z : ℂ) :
            ℝ

            The general Bloch–Wigner value at shape z, defined through the dihedral angles rather than through a complex dilogarithm:

            D(z) = Λ(arg z) + Λ(arg 1/(1−z)) + Λ(arg(1 − 1/z)).

            This extends BlochWigner_unit_circle past |z| = 1.

            ⚠ THIS IS A DEFINITION, AND IT IS NOT THE STANDARD ONE (recorded 2026-08-08 after reading Neumann–Zagier 1985 §3). The literature's Bloch–Wigner function is

            D(z) = Im Li₂(z) + log|z| · arg(1 − z)          (Neumann–Zagier eq. (39))

            i.e. it is built from the dilogarithm, not from Λ. That the Λ-sum above equals it is Kummer's identity (Lewin, Polylogarithms, p. 121 eq. (5.5)), which Neumann–Zagier invoke explicitly to pass from their eq. (37) Vol(S(z)) = Λ(α)+Λ(β)+Λ(γ) to eq. (38) Vol(S(z)) = D(z). It is a theorem, not a definitional unfolding.

            So, precisely:

            • ⚠⚠ STATUS: KUMMER IS NOW PROVED (2026-08-09, bean qou-kmmr).

              QOU/Knot/KummerRadial.lean — kummer — proves, sorry-free and on the standard axioms, for every z with Im z > 0:

              BlochWigner_lob z = Im (cLiTwoExt z) + log‖z‖ · arg(1 − z)

              So the two objects named D in this corpus are the same function on the upper half plane. This bullet previously said the identity "cannot currently be proved in this corpus" (Mathlib has no dilogarithm); that was corrected first to "unblocked, not impossible" once QOU.MathlibExt.cLiTwoExt was recognised, and is now simply done.

              The proof chain, all sorry-free: KummerUnitCircle (the Λ-side on |z| = 1, which is Clausen duplication) → KummerDilogHalf (the cLiTwoExt side there, by same-derivative with basepoint θ = π) → IdealTetLawOfSines (‖z‖ = sin θ₂/sin θ₃) → KummerRadial (a radial reduction, using the unit circle as basepoint).

            • The prohibition below is therefore LIFTED. It used to read: "do not transport dilogarithm facts onto this symbol — the five-term relation, the functional equations, or any N–Z result stated for their D — without first proving Kummer's identity. The name is shared; the objects are so far only numerically observed to agree."

              That condition is now met. Dilogarithm facts about cLiTwoExt may be transported onto BlochWigner_lob on {Im z > 0}, via kummer. Outside the upper half plane nothing is claimed — BlochWigner_lob is built from args and this file separately proves it vanishes on real shapes in (0,1), which is a branch statement, not an instance of Kummer.

            • The numerical cross-check that used to be the only evidence is retained as a control, not as grounds: computations/qbeta/xi_classical_limit_probe.py matches the two forms at the substrate anchor to ~1e-6 series accuracy, and Routes 72–73 match them to 1e-41/1e-45 at five shapes including y₁.

            Consequence for qou-idvt T2 / qou-5gai H4: the target factors as (geometric) Vol = D ∘ (analytic) D = Λ-sum. The analytic factor is now closed (kummer). The geometric one — that a particular triangulation's Λ-sum is the hyperbolic volume of a particular knot complement — is untouched and is still the whole of H4. Nothing here computes Vol(5₂).

                  The open input — the 5₂ triangulation.
