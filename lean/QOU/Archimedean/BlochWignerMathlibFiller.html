    Bloch-Wigner dilogarithm D — repo-internal Mathlib filler #

    The Bloch-Wigner dilogarithm D : ℂ \ {0,1} → ℝ is the single-valued version of Im Li_2(z):

    D(z) := Im(Li_2(z)) + log|z| · arg(1 - z).

    On the unit circle z = e^{iθ} (where |z| = 1, log|z| = 0), D simplifies to the Clausen function:

    D(e^{iθ}) = Cl_2(θ).

    This is the case relevant to the QOU framework's hyperbolic-knot contributions:

    • Figure-8 shape parameter e^{iπ/3} → D(e^{iπ/3}) = Cl_2(π/3), yielding Vol(4_1) = 2 · Cl_2(π/3).
    • Borromean per-octahedron shape parameter i = e^{iπ/2} → D(i) = Cl_2(π/2) = G (Catalan), yielding Vol(B_3) = 8G = 8 · Cl_2(π/2) after the 4-tetrahedra-per- octahedron decomposition.

    This file provides:

    • BlochWigner_unit_circle : ℝ → ℝ — the BW dilogarithm restricted to unit-circle shape parameters, defined as Cl_2.
    • BlochWigner_unit_circle_zero — D(e^{i·0}) = D(1) = 0 (boundary; Li_2(1) = π²/6 real, imaginary part zero).
    • The figure-8 and Borromean BW values exposed as named carriers.

    Mathlib gaps still open after this filler:

    • General D : ℂ \ {0,1} → ℝ for non-unit-circle shape parameters — needs Complex.log and Complex.arg infrastructure with branch-cut handling.
    • The 5-term pentagon identity for D — proved via Bloch's functional equation; full proof needs the general D.
    • BlochSuslinUniqueness D instance — depends on the pentagon identity plus the K-theoretic injectivity of the Suslin map.
