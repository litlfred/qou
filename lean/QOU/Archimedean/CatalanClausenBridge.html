    QOU.Archimedean.CatalanClausenBridge — the two Catalan definitions agree #

    This repo defines Catalan's constant twice, in two files that do not import each other, and until now nothing connected them:

    • QOU.Archimedean.HyperbolicVolumeTranscendence.catalan_G := ∑' k, (-1)^k / (2k+1)^2 — the alternating series;
    • QOU.Archimedean.ClausenFunctionMathlibFiller.Catalan_constant := Cl_2 (π/2), where Cl_2 θ := ∑' k, sin((k+1)θ) / (k+1)^2 — the Clausen value.

    The filler's catalan_constant_eq_cl_2_pi_over_2 is rfl: it restates a definition and carries no content. The mathematical claim — that the alternating series and the Clausen value are the same real number — was unproved, and a corpus grep found no cross-reference between catalan_G and Cl_2 anywhere in the tree. Two unbridged definitions of one constant is a live hazard: a downstream result proved about one is not a result about the other.

    catalan_G_eq_Cl_2_pi_div_two closes that. The proof is elementary — no analysis, no integrals — because at θ = π/2 the Clausen series is the alternating series with its zero terms removed:

    • sin((2k+2)·π/2) = sin((k+1)π) = 0, so every odd-index term vanishes;
    • sin((2k+1)·π/2) = cos(kπ) = (-1)^k, so the even-index terms are the Catalan summand.

    tsum_even_add_odd then splits the sum. Real.cos_nat_mul_pi is not in Mathlib at this toolchain, so cos_nat_mul_pi' proves it by induction via Real.cos_add_pi.

    Scope. This says nothing about the lobachevsky (π/4) = catalan_G / 2 axiom in BorromeanVolumeCatalan. That one relates an integral to the series and needs the Clausen integral representation (Cl_2' θ = -log|2 sin(θ/2)|) — genuine analysis over an improper integrand, and still correctly classified External by docs/audits/2026-06-03-lean-axiom-tractability-triage.md. What this file does supply is the other half of that identity's bridge, so the residual gap is now exactly the integral representation and nothing else.
