    Transfer Matrix ↔ Hecke Algebra Correspondence (Layer 3) #

    The optimal NF coefficients equal the transfer matrix traced volumes V̂_i.

    Key idea: a Hecke algebra element a · σ + b · 𝟏 at generator σ_i corresponds to the state vector (a, b)ᵀ in ℤ[t, t⁻¹]². Multiplication by a crossing (c · σ + d) in the Hecke algebra (with Hecke reduction σ² = HA · σ + 1) corresponds to left-multiplication by the transfer matrix T(c, d) on the state vector.

    This file proves:

    1. The Hecke-to-matrix correspondence is well-defined
    2. Multiplication correspondence: Hecke product ↔ matrix product
    3. The traced volume V̂_i extracts the same data as the Markov trace
    4. Optimal NF coefficients = traced volumes

              noncomputable def QOU.TMCorrespondence.heckeMultiply (a b c d : Archimedean.R_t) :
              StateVec

              Multiply a Hecke element (a · σ + b) by a crossing (c · σ + d) using the Hecke relation σ² = HA · σ + 1.

              (a · σ + b)(c · σ + d) = a·c · σ² + a·d · σ + b·c · σ + b·d = a·c · (HA · σ + 1) + (a·d + b·c) · σ + b·d = (a·c·HA + a·d + b·c) · σ + (a·c + b·d) · 𝟏

              So the new state is: a' = a·c·HA + a·d + b·c b' = a·c + b·d

                theorem QOU.TMCorrespondence.hecke_eq_transfer (a b c d : Archimedean.R_t) :
                heckeMultiply a b c d = Matrix.mulVec (Archimedean.transferMatrix c d) (mkState a b)

                The transfer matrix T(c, d) acting on state vector (a, b)ᵀ produces the same result as Hecke multiplication of (a·σ + b) by (c·σ + d).

                Transfer matrix action:

                T(c,d) · (a, b)ᵀ = ⎡ c·HA+d,  c ⎤ · ⎡ a ⎤ = ⎡ (c·HA+d)·a + c·b ⎤
                    ⎣ c,       d ⎦   ⎣ b ⎦   ⎣ c·a + d·b         ⎦

                Hecke multiplication:

                (a·σ + b)(c·σ + d) = (a·c·HA + a·d + b·c)·σ + (a·c + b·d)·𝟏

                These are equal:

                • Row 0: (c·HA+d)·a + c·b = a·c·HA + a·d + b·c ✓ (ring identity)
                • Row 1: c·a + d·b = a·c + b·d ✓ (commutativity)

                This is the fundamental correspondence: the transfer matrix encodes exactly the Hecke algebra multiplication with reduction.

                      theorem QOU.TMCorrespondence.markov_trace_eq_traced_vol (a b : Archimedean.R_t) :
                      a + Archimedean.markov_denom * b = Archimedean.tracedVolCleared !![a, 0; b, 0]

                      The Markov trace of a Hecke element a·σ + b·𝟏 is: tr_M(a·σ + b) = a · z + b where z = 1/(t + t⁻¹) is the Markov parameter.

                      In cleared form (multiplied by t + t⁻¹): (t + t⁻¹) · tr_M(a·σ + b) = a + (t + t⁻¹) · b

                      This is exactly tracedVolCleared applied to the column vector (a, b)ᵀ viewed as the first column of a matrix.

                      theorem QOU.TMCorrespondence.traced_vol_from_state (M : Archimedean.TMatrix) :
                      Archimedean.tracedVolCleared M = sigmaCoeff (Matrix.mulVec M initialState) + Archimedean.markov_denom * identCoeff (Matrix.mulVec M initialState)

                      The traced volume of a chain matrix, applied to initial state (1, 0)ᵀ, extracts the Markov trace of the corresponding Hecke element.

                      If M = matrixChain seq, then: tracedVolCleared M = M[0,0] + (t + t⁻¹) · M[1,0]

                      The state vector is M · (1, 0)ᵀ = (M[0,0], M[1,0])ᵀ. So tracedVolCleared M computes a + (t+t⁻¹)·b where (a, b) = M · (1, 0)ᵀ is the Hecke state.

                      theorem QOU.TMCorrespondence.optimal_coeff_eq_transfer_state (seq : CrossingSeq) :
                      have state := Matrix.mulVec (matrixChain seq) initialState; sigmaCoeff (heckeChain initialState seq) = sigmaCoeff state ∧ identCoeff (heckeChain initialState seq) = identCoeff state

                      Layer 3 Main Theorem.

                      For each generator σ_i in a nuclear configuration, the coefficient of σ_i in the optimal normal form equals the σ-component of the transfer matrix chain state at generator i.

                      Specifically, let seq_i be the crossing sequence at generator i (the crossings that accumulate onto chain i). Then:

                      • The Hecke element at generator i is heckeChain (1, 0) seq_i
                      • The transfer matrix chain is M_i = matrixChain seq_i
                      • The state vector is M_i · (1, 0)ᵀ = (a_i, b_i)ᵀ
                      • The optimal NF coefficient of σ_i is a_i
                      • The traced volume is V̂_i = z · a_i + b_i (cleared: a_i + (t+t⁻¹)·b_i)

                      The proof combines:

                      1. chain_correspondence: Hecke chain = matrix chain on initial state
                      2. traced_vol_from_state: traced volume = Markov trace of Hecke element
                      3. The Markov trace is linear, so per-generator contributions factorise

                      Together: the NF coefficients (a_i, b_i) at each generator are exactly the entries of the transfer matrix chain state vector, and the traced volume V̂_i is the Markov trace of the per-generator Hecke element.

                      theorem QOU.TMCorrespondence.volume_eq_markov_trace (seq : CrossingSeq) :
                      Archimedean.tracedVolCleared (matrixChain seq) = sigmaCoeff (Matrix.mulVec (matrixChain seq) initialState) + Archimedean.markov_denom * identCoeff (Matrix.mulVec (matrixChain seq) initialState)

                      Corollary: the traced volume V̂_i equals the Markov trace of the per-generator Hecke element.

                      This bridges the transfer matrix world (TransferMatrix.lean) and the optimal NF world (OptimalNF.lean):

                      • Transfer matrix chain → state vector (a_i, b_i)
                      • Hecke chain → NF coefficients (a_i, b_i) [same by correspondence]
                      • V̂_i = z·a_i + b_i extracts Markov trace information
                      • The skein polynomial P(q) = ∏_i V̂_i is a product of Markov traces

                      noncomputable def QOU.TMCorrespondence.chainCrossings (config : Archimedean.NuclearConfig) (j : ℕ) :
                      CrossingSeq

                      Extract the crossing sequence for chain j from a nuclear configuration.

                      Chain j is formed by the crossings between nucleon j and all subsequent nucleons k > j. The crossing at position k contributes weights that match crossingMatrix from TransferMatrix.lean.

                      Scaling convention (v1.1): pp and nn crossings are DOUBLED to match crossingMatrix:

                      • pp: crossingMatrix pp = 2 • T_pp → coefficients (2, 0)
                      • nn: crossingMatrix nn = 2 • T_nn → coefficients (2, −2·HA)
                      • pn: crossingMatrix pn = two_T_pn → coefficients (2, −HA) (the "undoubled" pn base would be (1, −HA/2), but w_plus_t .pn and w_zero_t .pn are defined as the doubled form (2, −HA) which already matches two_T_pn directly)

                      This ensures transferMatrix c d = crossingMatrix(nj, nk) for each pair, which is needed for matrixChain_eq_buildChains.

                          theorem QOU.TMCorrespondence.buildChains_eq_foldl (config : Archimedean.NuclearConfig) :
                          Archimedean.buildChains config = (List.foldl (buildStep config) ([], 0) config).1

                              The skein polynomial equals the product of per-generator Markov traces.

                              P(q) = ∏_{j=0}^{A-2} V̂_j

                              where each V̂_j is the Markov trace of the j-th Hecke element. In cleared form:

                              (t+t⁻¹)^{A-1} · P(q) = ∏_j [a_j + (t+t⁻¹) · b_j]

                              This follows from volume_eq_markov_trace applied to each chain.
