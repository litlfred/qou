    QOU.Archimedean.noble_gas_characterization — noble gas iff full-of-curls #

    Proposition (prop:noble-gas-characterization).

    An atom 𝓐(p, n) is a noble gas if and only if its electron cloud p · T_{2,3} decomposes as a disjoint union of closed sub-Hopf links — i.e. every shell is topologically full of curls.

    The Lean encoding uses an abstract AtomLike structure with two predicates:

    • IsNobleGas a — physical noble-gas predicate (chemically inert).
    • IsFullOfCurls a — topological predicate ("p · T_{2,3} admits a closed-sub-Hopf-link decomposition with monotone nesting").

    The theorem is the iff between the two predicates; both sides are abstract Props at this stage. Concretising IsFullOfCurls to the explicit S₁ ⊔ … ⊔ S_k decomposition with S_i = 2·n_i² · T_{2,3} plus monotone nesting n_1 < … < n_k is downstream work once the underlying knot-theoretic structures (HopfLink, T_{2,3}, SubLink) have been Lean-translated.

    • stable : Prop

      Stability witness: only stable nuclei are admitted.

    • IsFullOfCurls : Prop

      Topological noble-gas predicate: the electron cloud decomposes as a disjoint union of closed sub-Hopf links with monotone nesting (p · T_{2,3} = S_1 ⊔ … ⊔ S_k, each S_i = 2 n_i² · T_{2,3}, with n_1 < … < n_k).

    • IsNobleGas : Prop

      Physical noble-gas predicate: chemically inert.

    • claim_noble_iff_curls : stable → (IsNobleGas ↔ IsFullOfCurls)

      Manuscript characterisation: for stable atoms, noble-gas status coincides with the full-of-curls topological decomposition.
