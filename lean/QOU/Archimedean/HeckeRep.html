    Iwahori–Hecke Algebra Representations #

    General framework for finite-dimensional representations of the Iwahori–Hecke algebra H_n(q) over ℤ[t, t⁻¹].

    Main definitions #

    • HeckeRep n d — a representation of H_n(q) of dimension d
    • HeckeRep.genInv — generator inverse from the Hecke relation
    • HeckeRep.eval — evaluate a signed braid word
    • HeckeRep.halfBorromean — the half-Borromean element h_{ij}
    • HeckeRep.character — trace (character) of a Hecke element

    The Hecke relation #

    The generators σ_i satisfy σ² = HA · σ + 1 where HA = t² − t⁻². The eigenvalues of each generator are t² = q and −t⁻² = −q⁻¹.

    References #

    • [iwahori1964] N. Iwahori, On the structure of a Hecke ring.
    • [jones1987] V. Jones, Hecke algebra representations of braid groups.
    • [murphy1992] G. Murphy, On the representation theory of the symmetric groups and associated Hecke algebras.

    §1 Representation structure #

    source
    structure QOU.Archimedean.HeckeRep (n d : ℕ) :
    Type

    A representation of the Iwahori–Hecke algebra H_n(q) of dimension d over the ground ring ℤ[t, t⁻¹].

    A representation assigns a d × d matrix to each generator σ_i (for i ∈ {0, …, n−2}) satisfying:

    1. The Hecke relation: σ_i² = HA · σ_i + I
    2. The braid relation: σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1}
    3. Far commutativity: σ_i σ_j = σ_j σ_i for |i − j| ≥ 2
    • gen : Fin (n - 1) → Matrix (Fin d) (Fin d) R_t

      Matrix for generator σ_i.

    • hecke_rel (i : Fin (n - 1)) : self.gen i * self.gen i = HA_t • self.gen i + 1

      Hecke relation: σ_i² = HA · σ_i + I for each generator.

    • braid_adj (i : ℕ) (hi₀ : i < n - 1) (hi₁ : i + 1 < n - 1) : self.gen ⟨i, hi₀⟩ * self.gen ⟨i + 1, hi₁⟩ * self.gen ⟨i, hi₀⟩ = self.gen ⟨i + 1, hi₁⟩ * self.gen ⟨i, hi₀⟩ * self.gen ⟨i + 1, hi₁⟩

      Adjacent braid relation: σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1}.

    • braid_far (i j : Fin (n - 1)) : ↑i + 2 ≤ ↑j → self.gen i * self.gen j = self.gen j * self.gen i

      Far commutativity: σ_i σ_j = σ_j σ_i for |i − j| ≥ 2.

      noncomputable def QOU.Archimedean.HeckeRep.genInv {n d : ℕ} (ρ : HeckeRep n d) (i : Fin (n - 1)) :
      Matrix (Fin d) (Fin d) R_t

      The inverse of generator σ_i, derived from the Hecke relation:

      σ_i⁻¹ = σ_i − HA · I

      Verification: σ_i · (σ_i − HA · I) = σ_i² − HA · σ_i = 1.

      Equations
      • ρ.genInv i = ρ.gen i - QOU.Archimedean.HA_t • 1

        theorem QOU.Archimedean.genInv_hecke {n d : ℕ} (ρ : HeckeRep n d) (i : Fin (n - 1)) :
        ρ.genInv i * ρ.genInv i = -HA_t • ρ.genInv i + 1

        Hecke relation for σ⁻¹: σ⁻¹² = −HA · σ⁻¹ + 1.

        Theorem (was previously HeckeRep.genInv_hecke_axiom). Discharged 2026-06-08 via the docstring's suggested linear_combination approach against hecke_rel.

        Proof sketch: σ⁻¹ = σ - HA·1, so σ⁻¹² = σ² - 2(HA·σ) + (HA·HA)·1 = (HA·σ + 1) - 2(HA·σ) + (HA·HA)·1 [hecke_rel] = 1 - HA·σ + (HA·HA)·1 RHS: -HA·σ⁻¹ + 1 = -HA·(σ - HA·1) + 1 = -HA·σ + (HA·HA)·1 + 1 = 1 - HA·σ + (HA·HA)·1 LHS = RHS.

              §4 Half-Borromean element #

              source
              def QOU.Archimedean.halfBorromeanWord {n : ℕ} (i j : Fin (n - 1)) :
              BraidWord n

              The half-Borromean braid word h_{ij} = σ_i⁻¹ σ_j σ_i σ_j⁻¹.

              This is the fundamental building block of the Borromean linking in H_n(q). It measures the mutual linking of strands i and j with all other strands as spectators.

              Equations
              • QOU.Archimedean.halfBorromeanWord i j = [(i, false), (j, true), (i, true), (j, false)]
