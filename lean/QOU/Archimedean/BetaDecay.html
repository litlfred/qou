    Beta Decay Operator and Knot Operators #

    The beta decay operator T_{β-decay}(q), the knot operator F(τ(r,s), N) for each embeddable torus knot, and the spectral decomposition theorem (as corollary of cohomological embedding).

    Note to reader: all proofs over ℤ[q, q⁻¹] (equivalently ℤ[t, t⁻¹] with t = q^{1/2}).

    §1 Beta decay operator #

    source
    structure QOU.Archimedean.BetaDecayOp :
    Type

    The beta decay operator T_{β-decay}(q) = σ₀ · σ₁⁻¹ in H₃(q).

    This is the universal ±1 transition operator: it changes one neutron crossing to a proton crossing (or vice versa) at the converting vertex.

    In the Gröbner–Shirshov framework, σ₁⁻¹ = σ₁ − (q − q⁻¹), so T_{β-decay} = σ₀σ₁ − (q − q⁻¹)σ₀.

    As a 2×2 matrix, the decay changes the crossing coefficients at the converting generator from (𝔴⁺_nn, 𝔴⁰_nn) to (𝔴⁺_pn, 𝔴⁰_pn) (or vice versa).

    • parent : NuclearConfig

      Parent nuclear configuration.

    • daughter : NuclearConfig

      Daughter nuclear configuration.

    • is_beta_minus : ∃ (k : ℕ), List.length self.parent = List.length self.daughter ∧ self.parent[k]! = NucleonType.neutron ∧ self.daughter[k]! = NucleonType.proton ∧ ∀ (j : ℕ), j ≠ k → self.parent[j]! = self.daughter[j]!

      The daughter differs by exactly one nucleon: n → p.

        §3 Markov trace on H_n(q) (cleared form) #

        The Markov trace on H_n(q) is defined recursively by:

        • tr_M(1) = 1
        • tr_M(b · σ_{n-1}) = z · tr_M(b) for b ∈ H_{n-1}(q) where z = 1/(t + t⁻¹).

        Since z ∉ ℤ[t, t⁻¹], we work with the cleared Markov trace: tr_M^cl(x) := (t + t⁻¹)^k · tr_M(x) where k is chosen to clear all denominators.

        For a 2×2 transfer matrix M representing an element of H_n(q), the cleared Markov trace is M[0][0] + (t + t⁻¹) · M[1][0], which is exactly tracedVolCleared from TransferMatrix.lean.

        The beta decay transfer matrix T_{β-decay} = σ₀ · σ₁⁻¹ in H₃(q).

        Using the Hecke relation σ⁻¹ = σ − (q − q⁻¹), we have T_{β-decay} = σ₀σ₁ − (q − q⁻¹)σ₀.

        As a 2×2 matrix: the decay changes one nn crossing to a pn crossing at the converting vertex. The net effect on the transfer matrix chain is to replace T_nn by T_pn at the converting site. In the doubled integral form, this is two_T_pn (the pn crossing matrix).

                    TMatrix

                    The transfer matrix for a torus knot τ(r,s).

                    The torus knot braid word is (σ₁σ₂…σ_{r-1})^s, which gives a product of r-1 crossing matrices repeated s times.

                    For the knot operator, we compute the product of crossing matrices along the knot's braid representative. We define this as the s-th power of the single-period transfer matrix.

                        noncomputable def QOU.Archimedean.pauliProjectedKnotOp (τ : TorusKnotLabel) :
                        R_t

                        The Pauli-projected knot operator for fully filled shells.

                        For a full shell, the antisymmetrizer e_{(1^r)} projects onto the sign representation of S_r. The Pauli-projected knot operator reduces to the determinant sign:

                        det(T_pp)^{(r-1)·s} where det(T_pp) = −(𝔴⁺)²·HA = −HA (since 𝔴⁺_pp = 1).

                        The determinant of a single crossing matrix T(c,d) is: det = (c·HA + d)·d − c² = c·HA·d + d² − c². For pp: c=1, d=0, so det = 0 − 1 = −1.

                        Thus the Pauli factor is (-1)^{(r-1)·s}.

                        Equations
                        • QOU.Archimedean.pauliProjectedKnotOp τ = if (τ.r - 1) * τ.s % 2 = 0 then 1 else -1

                          noncomputable def QOU.Archimedean.knotOperator (τ : TorusKnotLabel) (N g : ℕ) :
                          R_t

                          The knot operator F(τ, N) for torus knot τ at neutron number N on a genus-g surface.

                          This is defined over ℤ[t, t⁻¹] via the Markov trace of the torus knot element composed with the beta decay operator in H₃(q).

                          The operator is:

                          • 1 if τ is not embeddable (null: zero action)
                          • 1 if τ's shell is not active (cancels in parent/daughter)
                          • markovTrace_knot_beta τ if active shell, partially filled (the (t+t⁻¹) normalisation is absorbed into Q_bare)
                          • pauliProjectedKnotOp τ if active shell, fully filled (Pauli exclusion projects to sign representation)

                            §4 Spectral decomposition theorem #

                            source
                            class QOU.Archimedean.SpectralDecompositionQValue (g : ℕ) (_hg : g = 4) (op : BetaDecayOp) (qValue qBare knotProd : R_t) :
                            Prop

                            Spectral decomposition Q-value — typeclass.

                            For β⁻ decay on Σ_g, the Q_q-value decomposes as:

                            Q_q = Q_bare × ∏_{τ(r,s) ∈ E_g} F(τ(r,s), N)

                            where:

                            • Q_bare = |log_q(P_dau/P_par)| · ℏ_q · m_e/3
                            • F(τ, N) is the knot operator
                            • The product collapses to a single active term
                            • The decomposition is exact (completeness of torus knot basis)

                            Proof structure:

                            1. Completeness: Rosso–Jones + self-duality → complete basis
                            2. Inductive chain: zero Hecke steps, Gröbner normal form
                            3. Shell cancellation: parent/daughter share inner chains
                            4. Pauli projection: full shell → alternating irrep
                            5. Tower termination: degree ≥ 3 needs genus > 4

                            Per-op witness that the Q-value of a β-decay operator equals Q_bare · ∏ (knot-operator product). Full proof requires: (1) Rosso–Jones completeness (external), (2) inductive chain construction (TransferMatrix.lean), (3) shell cancellation, (4) Pauli projection (Young symmetrizer), (5) tower termination (embeddability bound). Until those land, the equality is per-instance.

                            • factorisation : qValue = qBare * knotProd

                              qValue = qBare · knotProd.

                              §5 Interaction completeness #

                              source
                              theorem QOU.Archimedean.interaction_completeness :
                              sigma4_knots.length = 6 ∧ ∀ (τ : TorusKnotLabel), τ.embeddableOn 4 → τ ∈ sigma4_knots

                              Theorem (interaction completeness). The 6 embeddable torus knots on Σ₄ exhaust the harmonic 1-forms on the fiber. Every transfer matrix (= force operator) is a composition of these 6. No 7th interaction exists.

                              Proof: a 7th embeddable torus knot τ(r,s) with (r-1)(s-1)/2 ≤ 4 and gcd(r,s) = 1 does not exist (exhaustive enumeration). The next candidate τ(2,11) requires genus 5 > 4.
