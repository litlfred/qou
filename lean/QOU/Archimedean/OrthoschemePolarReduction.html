    1. The radial integral #

    Elementary, and the step that turns a two-dimensional integral into Milnor's angular one. The r in the numerator is the polar Jacobian, and it is exactly what makes the radial primitive a logarithm.

    source
    theorem QOU.Archimedean.HyperbolicVolume.intervalIntegrable_radial {R r₀ : ℝ} (hR : 0 < R) (h0 : 0 ≤ r₀) (hlt : r₀ < R) :
    IntervalIntegrable (fun (r : ℝ) => r / (2 * (R ^ 2 - r ^ 2))) MeasureTheory.volume 0 r₀

    The radial integrand is continuous on [0, r₀] when r₀ < R, hence interval-integrable there. Unlike the angular integrand, there is no singularity inside the interval: the chord stays strictly inside the circle.

    source
    theorem QOU.Archimedean.HyperbolicVolume.integral_radial {R r₀ : ℝ} (hR : 0 < R) (h0 : 0 ≤ r₀) (hlt : r₀ < R) :
    ∫ (r : ℝ) in 0..r₀, r / (2 * (R ^ 2 - r ^ 2)) = -(1 / 4) * Real.log ((R ^ 2 - r₀ ^ 2) / R ^ 2)

    ∫₀^{r₀} r dr / (2(R² − r²)) = −¼ log((R² − r₀²)/R²) for 0 ≤ r₀ < R.

    The polar Jacobian r against the density 1/(2(R²−r²)) integrates to a log — which is why the angular integrand of the orthoscheme is a log, and hence why Λ (the primitive of −log(2 sin)) is the answer at all.

    2. The base triangle, and its polar description #

    The definition is Cartesian; the polar description is proved.

    source
    def QOU.Archimedean.HyperbolicVolume.orthoBase (R ψ : ℝ) :
    Set (ℝ × ℝ)

    The orthoscheme base triangle — the OPEN Euclidean triangle with vertices (0,0), (R cos ψ, 0), (R cos ψ, R sin ψ): the circumcentre, the foot of the perpendicular to a chord, and that chord's endpoint on the circle of radius R.

    One of the six pieces Milnor's circumcentre subdivision cuts an inscribed triangle into.

      3. The radial mass in ℝ≥0∞ #

      hypVolume integrates in ℝ≥0∞; the radial computation is Bochner. This is the same bridge H4-2 needed for the vertical fibre, now for the radial one — and, as there, it is the integrand's honest integrability that licenses it.

      source

      ∫⁻ (r : ℝ) in Set.Ioo 0 r₀, ENNReal.ofReal (r / (2 * (R ^ 2 - r ^ 2))) = ENNReal.ofReal (-(1 / 4) * Real.log ((R ^ 2 - r₀ ^ 2) / R ^ 2))

      The radial mass of one polar ray, in ℝ≥0∞.

      4. H4-3 — the polar reduction #

      The change of variables itself. Everything above is input; this is the theorem that joins H4-2's two-dimensional base integral to H4-4's one-dimensional one.

      source
      theorem QOU.Archimedean.HyperbolicVolume.lintegral_orthoBase {R ψ : ℝ} (hR : 0 < R) (hψ0 : 0 < ψ) (hψ : ψ < Real.pi / 2) :
      ∫⁻ (w : ℝ × ℝ) in orthoBase R ψ, ENNReal.ofReal (1 / (2 * (R ^ 2 - w.1 ^ 2 - w.2 ^ 2))) = ENNReal.ofReal (Lob ψ / 2)

      H4-3 — the base integral over one orthoscheme triangle collapses to Milnor's angular integral.

      ∫∫_{orthoBase R ψ} dA / (2(R² − x² − y²))
    =  ∫₀^ψ −¼ log((cos²φ − cos²ψ)/cos²φ) dφ   ( = ½Λ(ψ), by H4-4 )

      Three things happen here, and each is where the corresponding hypothesis is used:

      • the polar change of variables (lintegral_comp_polarCoord_symm), whose Jacobian r is what makes the radial primitive a logarithm;
      • Tonelli with the ANGLE outermost, so the inner integral is the radial one — the order Milnor computes in;
      • the radial evaluation, whose upper limit R cos ψ / cos φ is < R exactly because φ < ψ (the chord stays inside the circle).

      The right-hand side carries no R: the radial value depends on r₀/R, and r₀/R = cos ψ / cos φ. That is H2's dilation invariance visible in the base integral.

      5. The chimney over one orthoscheme base #

      Composing with H4-2 gives the first statement in this chain relating a THREE-dimensional hyperbolic volume to Λ.

      source
      theorem QOU.Archimedean.HyperbolicVolume.orthoBase_subset_disk {R ψ : ℝ} (hR : 0 < R) (hψ0 : 0 < ψ) (hψ : ψ < Real.pi / 2) (w : ℝ × ℝ) :
      w ∈ orthoBase R ψ → w.1 ^ 2 + w.2 ^ 2 < R ^ 2

      The open base triangle lies strictly inside the disk.

      Its third vertex (R cos ψ, R sin ψ) is ON the circle, but the triangle is open, so no point of it is: x² + y² < x²(1 + tan²ψ) = x²/cos²ψ < R². This is the pointwise disk hypothesis H4-2's corollary wants, so the a.e. form is not needed for a single orthoscheme — it will be, for the closed triangle H4-5 assembles.

      source
      theorem QOU.Archimedean.HyperbolicVolume.hypVolume_chimney_orthoBase {R ψ : ℝ} (hR : 0 < R) (hψ0 : 0 < ψ) (hψ : ψ < Real.pi / 2) :
      hypVolume (chimney (orthoBase R ψ) R) = ENNReal.ofReal (Lob ψ / 2)

      The hyperbolic volume of the chimney over one orthoscheme base triangle is ½Λ(ψ).

      The first statement in this chain with a THREE-dimensional hyperbolic volume on the left and Λ on the right. H4-2 collapses the solid to its base integral, H4-3 turns that into Milnor's angular integral, H4-4 evaluates it.

      This is not a statement about an ideal tetrahedron. It says that a particular region of H³ — the region above the radius-R hemisphere over an open Euclidean right triangle — has hyperbolic volume ½Λ(ψ). That such a chimney over a triangle INSCRIBED in the circle IS the ideal tetrahedron with dihedral angles (α,β,γ) is Milnor's geometric identification, and it is untouched: Mathlib has no ideal tetrahedra. Assembling six of these into Λ(α)+Λ(β)+Λ(γ) is H4-5, also open — and that step is where the obtuse case (circumcentre outside the triangle, one piece entering with a minus sign) finally has to be faced.
