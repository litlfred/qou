    P.transpose * lam • M * P = (lam * c) • G

    Markov leg of the three-scale gauge law. If the transported Markov Gram is proportional to the Hodge Gram, Pᵀ * M * P = c • G, then rescaling the Markov Gram M ↦ λ • M rescales the Schur scalar by λ: Pᵀ * (λ • M) * P = (λ * c) • G. Purely algebraic — stated over a generic commutative ring per the base-ring convention (§7c).

    theorem QOU.Archimedean.GaugeGroupThreeScale.three_scale_gauge_law {n : Type u_1} [Fintype n] {k : Type u_2} [Field k] {P M G : Matrix n n k} {c : k} (lam mu s : k) (hmu : mu ≠ 0) (h : P.transpose * M * P = c • G) :
    (s • P).transpose * lam • M * s • P = (lam * s ^ 2 / mu * c) • mu • G

    The composite three-scale gauge law (K1, transported-form orientation). Combining the Markov leg, the Hodge leg, and the proved intertwiner covariance invariantForm_pullback_smul: under the full gauge action (M, G, P) ↦ (λ • M, μ • G, s • P) with μ ≠ 0,

    (s • P)ᵀ * (λ • M) * (s • P) = (λ * s² / μ * c) • (μ • G),

    i.e. the Schur scalar transforms as c ↦ (λ·s²/μ)·c. This is the audit's K1 law: the gauge group has THREE scales, so two canonical Gram pins still leave the intertwiner gauge s² — a fully normalization-free magnitude is impossible with two pins. The gauge law constrains conventions only; it does not fix the τ-scale (that third scale is the open τ-scale gate).

    theorem QOU.Archimedean.GaugeGroupThreeScale.three_scale_gauge_law_probe_orientation {n : Type u_1} [Fintype n] {k : Type u_2} [Field k] {P GH GM : Matrix n n k} {c : k} (lam mu s : k) (hmu : mu ≠ 0) (hs : s ≠ 0) (h : GM = c • (P.transpose * GH * P)) :
    lam • GM = (lam / (mu * s ^ 2) * c) • ((s • P).transpose * mu • GH * s • P)

    The composite three-scale gauge law in the probe's orientation (K1, literal form). The probe defines c with the intertwiner on the Hodge side, G_M = c • (Pᵀ * G_H * P); there the gauge action (G_M, G_H, P) ↦ (λ • G_M, μ • G_H, s • P) transforms the scalar as c ↦ (λ/(μ·s²))·c — the exact factor asserted (and machine-verified to 5e-60) by K1_three_scale_gauge_group in alpha_em_b2_canonical_scale_ratio_probe.py. The two orientations are the same gauge law: the s-exponent flips sign with the side of the pullback.

    theorem QOU.Archimedean.GaugeGroupThreeScale.gauge_ratio_invariant {lam mu s c₁ c₂ : ℝ} (hlam : lam ≠ 0) (hmu : mu ≠ 0) (hs : s ≠ 0) :
    lam / (mu * s ^ 2) * c₁ / (lam / (mu * s ^ 2) * c₂) = c₁ / c₂

    Gauge invariance of Schur-scalar ratios (route C I1, over ℝ). Two Schur scalars c₁, c₂ transported under the same three-scale gauge action pick up the same factor λ/(μ·s²), so their ratio is unchanged: the ratio is a degree-0 (gauge-invariant) observable. This is the Lean footing for the probe's route-C I1 reading that only ratio-spectrum shapes are intrinsic — magnitudes of individual scalars are convention-carrying. (For an admissible gauge — λ, μ, s all nonzero — the common factor is nonzero and cancels; no c₂ ≠ 0 hypothesis is needed, since with Mathlib's division convention the identity also holds degenerately. The probe's route-C instance has c₂ ≠ 0.)
