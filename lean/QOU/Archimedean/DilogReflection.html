    Dilogarithm derivative + Euler reflection — the V1 bar-even keystone infra #

    Discharges the flagship honest sorry of QOU.Archimedean.DilogarithmArchimedeanLimit — LiTwo_reflection, the Euler reflection Li₂(x) + Li₂(1-x) = π²/6 − ln x·ln(1-x) — by building the missing analytic infra: the derivative of the dilogarithm d/dx Li₂(x) = −log(1-x)/x, which Mathlib does not provide (no Real.dilog).

    The build (bean milestone qou-a3ps):

    • dilogDerivSeries_tsum (Brick C) — the closed form ∑ₖ xᵏ/(k+1) = −log(1-x)/x for x ≠ 0, |x| < 1; pure algebra from neg_log_one_sub_hasSum.
    • hasDerivAt_LiTwo (Brick A) — HasDerivAt LiTwo (−log(1-x)/x) x for 0 < x < 1, via hasDerivAt_tsum_of_isPreconnected on a compact subinterval (−r, r), x < r < 1, with the summable geometric bound rⁿ.
    • LiTwo_reflection' (Brick B) — the reflection FE, from g' = 0 on (0,1) plus the boundary value at the x → 1⁻ limit.

    Everything is over ℝ (archimedean by construction — the reflection is a statement about the real dilogarithm's boundary regulator).

    -- Ref: [manuscript] conj:dilogarithm-archimedean-limit; Euler reflection (Lewin 1981)

    Brick C — the derivative series closed form #

    source
    theorem QOU.Archimedean.dilogDerivSeries_tsum {x : ℝ} (hx0 : x ≠ 0) (hx : |x| < 1) :
    ∑' (k : ℕ), x ^ k / (↑k + 1) = -Real.log (1 - x) / x

    Brick C. ∑ₖ xᵏ/(k+1) = −log(1-x)/x for x ≠ 0, |x| < 1. Pure algebra: neg_log_one_sub_hasSum gives ∑ xᵏ⁺¹/(k+1) = −log(1-x); divide by x.

    Brick A — the dilogarithm derivative #

    source
    theorem QOU.Archimedean.hasDerivAt_LiTwo {x : ℝ} (hx0 : 0 < x) (hx1 : x < 1) :
    HasDerivAt QPochhammer.LiTwo (-Real.log (1 - x) / x) x

    Brick A. d/dx Li₂(x) = −log(1-x)/x for 0 < x < 1. Differentiates the LiTwo power series term-by-term on a compact subinterval (−r, r) with x < r < 1, where the derivative series is dominated by the summable geometric series rⁿ.

    Brick B — the Euler reflection functional equation #

    The reflection Li₂(x) + Li₂(1-x) = π²/6 − ln x·ln(1-x) for 0 < x < 1. The proof: the function g(x) = Li₂ x + Li₂(1-x) + ln x·ln(1-x) has g' ≡ 0 on (0,1) (from hasDerivAt_LiTwo + chain/product rule), hence is constant; the constant is pinned to π²/6 by the x → 1⁻ boundary limit, which needs Abel's theorem (Li₂ x → π²/6), continuity of Li₂ at 0 (Li₂(1-x) → 0), and the standard ln x·ln(1-x) → 0.

    source
    theorem QOU.Archimedean.LiTwo_eq_powerSeries {x : ℝ} (hx : |x| < 1) :
    ∑' (n : ℕ), 1 / ↑n ^ 2 * x ^ n = QPochhammer.LiTwo x

    The LiTwo power series in Abel-normalized form: Li₂(x) = ∑ₙ (1/n²)·xⁿ (the n = 0 term vanishes since 1/0² = 0).

    theorem QOU.Archimedean.LiTwo_reflection' (x : ℝ) (hx0 : 0 < x) (hx1 : x < 1) :
    QPochhammer.LiTwo x + QPochhammer.LiTwo (1 - x) = Real.pi ^ 2 / 6 - Real.log x * Real.log (1 - x)

    Brick B — the Euler reflection functional equation. Li₂(x) + Li₂(1-x) = π²/6 − log x·log(1-x) for 0 < x < 1. The auxiliary g = Li₂ x + Li₂(1-x) + log x·log(1-x) is constant on (0,1) (g' ≡ 0), and its x → 1⁻ boundary value is π²/6.

    source
    theorem QOU.Archimedean.LiTwo_half :
    QPochhammer.LiTwo (1 / 2) = Real.pi ^ 2 / 12 - Real.log 2 ^ 2 / 2

    Special value Li₂(½) = π²/12 − (ln 2)²/2, the reflection FE at x = ½ (Lewin 1.16). A clean immediate corollary of LiTwo_reflection'.

    Integral representation — Part A of conj:dilogarithm-archimedean-limit #

    Li₂(x) = ∫₀ˣ −log(1-t)/t dt for 0 < x < 1, the FTC applied to hasDerivAt_LiTwo (Brick A) + LiTwo_zero. This is the integral-representation half of the conjecture's Part A (the elementary q → 1⁻ side, per docs/audits/2026-06-07-dilog-archimedean-limit-part-A-elementary.md). The integrand is bounded by 1/(1-x) on (0,x] — from Real.one_sub_inv_le_log_of_pos — so interval-integrability needs no removable-singularity limit.

    source
    theorem QOU.Archimedean.LiTwo_eq_integral {x : ℝ} (hx0 : 0 < x) (hx1 : x < 1) :
    QPochhammer.LiTwo x = ∫ (t : ℝ) in 0..x, -Real.log (1 - t) / t

    Integral representation Li₂(x) = ∫₀ˣ −log(1-t)/t dt for 0 < x < 1.

    Rescaled to the unit interval — the shape Route 5 of the 5₂ sum rule needs #

    LiTwo_eq_integral integrates over [0, x], with the argument as the endpoint. Route 5 (bean qou-0yqu) needs the argument inside the integrand over a fixed range, because that is what turns a product over roots into a single logarithm:

    Σⱼ Li₂(yⱼ) = −∫₀¹ log ∏ⱼ(1 − yⱼz) / z dz = −∫₀¹ log(1 − 2z + 3z² − z³)/z dz

    the factorisation being QOU.QBeta.FiveTwo.prod_one_sub_mul_eq, and the resulting integral convergent by QOU.QBeta.FiveTwo.intervalIntegrable_log_recipCubic_div.

    The substitution t = y·z is all that separates the two shapes. Note this lemma is real and needs 0 < y < 1, so on its own it covers only the real saddle root y₃ = 0.4301…; the conjugate pair y₁, y₂ has |y₁| = 1.52 and is not reached here.

    source
    theorem QOU.Archimedean.LiTwo_eq_integral_unit {y : ℝ} (hy0 : 0 < y) (hy1 : y < 1) :
    QPochhammer.LiTwo y = -∫ (z : ℝ) in 0..1, Real.log (1 - y * z) / z

    Unit-interval integral representation: Li₂(y) = −∫₀¹ log(1 − yz)/z dz for 0 < y < 1. The substitution t = y·z in LiTwo_eq_integral.
