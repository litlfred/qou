    QOU.Archimedean.QMomentum #

    Canonical declaration for content block at quantum-observable-universe/climax-volume-mass/q-momentum.ts.

    Formalises the manuscript definition of the q-momentum as the q-bracket-weighted sum of the crossing signs of a braid word,

    p_q(β) = Σ_j [ε_j]_q = Σ_j (q^{ε_j} − q^{−ε_j})/(q − q⁻¹),

    and proves the owner-ruled canonical fact (2026-07-05): whenever q − q⁻¹ ≠ 0 (i.e. q ≠ ±1; at q = 1 the identity holds in the limit) [+1]_q = +1 and [−1]_q = −1 exactly, so p_q(β) equals the classical writhe w(β) = Σ_j ε_j. (This corrects the block's boxed formula: the spurious ε_j prefactor and the inequivalent Σ(q^{2ε}−1)/(q²−1) form both disagree with the building-block table for negative crossings.) §7c: archimedean over ℝ (uses q⁻¹).

      structure QOU.Archimedean.QMomentum :
      Type

      Data for the q-momentum of a braid word.

      A definition carrier: the substrate q (with q − q⁻¹ ≠ 0) and the crossing-sign word crossings : List ℤ, each entry ±1.

      • q : ℝ

        Substrate parameter q.

      • q_reg : self.q - self.q⁻¹ ≠ 0

        q − q⁻¹ ≠ 0 (the q-bracket denominator is nonzero).

      • crossings : List ℤ

        The signed crossing word ε₁,…,ε_k of the braid representative.

      • signs (e : ℤ) : e ∈ self.crossings → e = 1 ∨ e = -1

        Each crossing is ±1.
