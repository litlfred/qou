    QOU.Archimedean.frobenius_gram_matrix — explicit Markov-Frobenius Gram matrix #

    Proposition (prop:frobenius-gram-matrix).

    The 6 × 6 Gram matrix G_{ij} = tr_M(b_i · b_j) over the NF basis {γ, σ₀, σ₁, L₊, L₋, e⁻} in H₃(q) is the symmetric matrix

    G =
  ⎛ 1    z    z    z²    z²    z³ ⎞
  ⎜ z   hz+1  z²  hz²+z  z³   g₁₅ ⎟
  ⎜ z   z²  hz+1  z³   hz²+z  g₁₅ ⎟
  ⎜ z² hz²+z  z³  g₁₅   g₃₄   g₃₅ ⎟
  ⎜ z²  z³  hz²+z g₃₄   g₁₅   g₃₅ ⎟
  ⎝ z³ g₁₅  g₁₅  g₃₅   g₃₅   g₅₅ ⎠

    where (using h = q − q⁻¹ for the Hecke parameter and z for the Markov parameter z = 1/(q^{1/2} + q^{−1/2}))

    g₁₅ = h·z³ + z²
g₃₄ = h·z³ + h·z + 1
g₃₅ = h²·z³ + 2h·z² + z
g₅₅ = (h³ + h)·z³ + 2h²·z² + 2h·z + 1

    The Lean side records the matrix as an explicit Matrix (Fin 6) (Fin 6) R over a generic ring R carrying two distinguished elements h, z (the Hecke and Markov parameters respectively). Three immediate facts are stated:

    1. The matrix is symmetric (Matrix.IsSymm).
    2. The (0, 0) entry is 1 (Markov-trace of the identity).
    3. The full matrix is recorded as a top-level def.

    Each of (1) and (2) is a concrete equality discharged by direct computation (decide/rfl/ring); the symmetry is by definition of the matrix entries.

    source
    noncomputable def QOU.Archimedean.frobeniusGramMatrix {R : Type u_1} [CommRing R] (h z : R) :
    Matrix (Fin 6) (Fin 6) R

    The Markov–Frobenius 6 × 6 Gram matrix on the NF basis {γ, σ₀, σ₁, L₊, L₋, e⁻} of H₃(q), parameterised by h = q − q⁻¹ (Hecke parameter) and z = 1 / (q^{1/2} + q^{−1/2}) (Markov parameter). Entries are polynomial in h and z.

    See [prop:frobenius-gram-matrix] for the categorical derivation; entries are read off the Skein decomposition of each product b_i · b_j plus the Markov-trace evaluation.

      (frobeniusGramMatrix h z).IsSymm

      Matrix symmetry: the Gram matrix is symmetric, reflecting the Frobenius-pairing property tr_M(a · b) = tr_M(b · a) (Markov- trace cyclicity).

      Each off-diagonal pair is identical by construction, so the proof is by index-case analysis.
