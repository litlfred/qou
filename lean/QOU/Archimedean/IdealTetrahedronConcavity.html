    structure QOU.Archimedean.IdealTetrahedronConcavity.AngleTriple :
    Type

    The dihedral-angle triple of an ideal tetrahedron: three positive angles summing to π. (Positivity plus the sum forces each to lie in (0, π).)

    • α : ℝ
    • β : ℝ
    • γ : ℝ
    • hα : 0 < self.α
    • hβ : 0 < self.β
    • hγ : 0 < self.γ
    • sum : self.α + self.β + self.γ = Real.pi

      Identity 1 — the determinant is exactly 1 #

      source
      theorem QOU.Archimedean.IdealTetrahedronConcavity.cot_cyclic_sum_eq_one (t : AngleTriple) :
      Real.cos t.α / Real.sin t.α * (Real.cos t.β / Real.sin t.β) + Real.cos t.β / Real.sin t.β * (Real.cos t.γ / Real.sin t.γ) + Real.cos t.γ / Real.sin t.γ * (Real.cos t.α / Real.sin t.α) = 1

      cot α cot β + cot β cot γ + cot γ cot α = 1 for α + β + γ = π.

      This is what makes det H = 1 exactly, at every interior point. Proved by clearing denominators onto the sine addition formula: with sin(α+β) = sin γ and cos(α+β) = -cos γ, the numerator collapses.

      Identity 2 — the diagonal entries are negative #

      source
      theorem QOU.Archimedean.IdealTetrahedronConcavity.cot_add_cot_eq (t : AngleTriple) :
      Real.cos t.α / Real.sin t.α + Real.cos t.γ / Real.sin t.γ = Real.sin t.β / (Real.sin t.α * Real.sin t.γ)

      cot α + cot γ = sin β / (sin α sin γ). Immediate from the sine addition formula, since α + γ = π - β.

      theorem QOU.Archimedean.IdealTetrahedronConcavity.cot_add_cot_pos (t : AngleTriple) :
      0 < Real.cos t.α / Real.sin t.α + Real.cos t.γ / Real.sin t.γ

      Hence cot α + cot γ > 0, so the Hessian's diagonal entries are negative.

      Negative definiteness #

      source
      theorem QOU.Archimedean.IdealTetrahedronConcavity.quadratic_neg_of_lead_neg_of_det_pos {A B C x y : ℝ} (hA : A < 0) (hdet : 0 < A * C - B ^ 2) (hxy : x ≠ 0 ∨ y ≠ 0) :
      A * x ^ 2 + 2 * B * x * y + C * y ^ 2 < 0

      A symmetric 2x2 form with negative leading entry and positive determinant is negative definite. Completing the square: A·Q = (A x + B y)² + (AC - B²) y², and A < 0 flips it.

      source
      theorem QOU.Archimedean.IdealTetrahedronConcavity.hessian_neg_definite (t : AngleTriple) {x y : ℝ} (hxy : x ≠ 0 ∨ y ≠ 0) :
      -(Real.cos t.α / Real.sin t.α + Real.cos t.γ / Real.sin t.γ) * x ^ 2 + 2 * -(Real.cos t.γ / Real.sin t.γ) * x * y + -(Real.cos t.β / Real.sin t.β + Real.cos t.γ / Real.sin t.γ) * y ^ 2 < 0

      The Hessian of the ideal-tetrahedron volume is negative definite.

      Entries A = -(cot α + cot γ), B = -cot γ, C = -(cot β + cot γ). The proof is the two identities: A < 0 by cot_add_cot_pos, and A·C - B² = 1 by cot_cyclic_sum_eq_one.

      Holds at every interior point of the simplex, the regular octahedral triple (π/4, π/4, π/2) included — there cot γ = 0 and the matrix looks degenerate, but the determinant is still exactly 1.

      source
      theorem QOU.Archimedean.IdealTetrahedronConcavity.hessian_det_eq_one (t : AngleTriple) :
      -(Real.cos t.α / Real.sin t.α + Real.cos t.γ / Real.sin t.γ) * -(Real.cos t.β / Real.sin t.β + Real.cos t.γ / Real.sin t.γ) - (-(Real.cos t.γ / Real.sin t.γ)) ^ 2 = 1

      The determinant, isolated: it is exactly 1 everywhere on the simplex — not merely positive. Recorded separately because the exactness is the surprising part and is what keeps the octahedral point non-degenerate.

      Non-vacuity: the simplex is inhabited, including the awkward point #

      Every theorem above is universally quantified over AngleTriple. If that structure were empty they would all hold vacuously, so the two triples the corpus actually cares about are exhibited.

        The regular ideal OCTAHEDRON triple — L6a4's unique symmetric point (L6a4AngleStructure.unique_symmetric_point), in radians.

        This is the case worth having: cot(π/2) = 0, so the Hessian's off-diagonal vanishes and the matrix looks degenerate. It is not — hessian_det_eq_one gives determinant exactly 1 here too.
