    Analytic seed for the dilog Part-B W-P1 boundary term #

    The W-P1 assembly (wp1_riemann_bound, DilogPartBBranchPointSum.lean) reduces the positive-factor convergence to the single scalar limit (q−1)·log(1−xqⁿ) → 0 — the non-uniform boundary term at the branch point.

    This file provides the analytic seed for controlling that term: t·log t → 0 as t → 0⁺. Once a lower bound 1−xqⁿ ≥ c·(q−1) is available (the Diophantine / Faddeev-scaling no-resonance condition on x), the boundary term is dominated by δ·log δ-type quantities with δ = 1−xqⁿ → 0, and this seed closes it. Proved from the continuity of Mathlib's entropy function Real.negMulLog = −t·log t at 0.

    Analytic seed — t·log t → 0 as t → 0⁺. Immediate from the continuity of the entropy function Real.negMulLog t = −t·log t at 0 (Real.negMulLog_zero : negMulLog 0 = 0). This is the ingredient that controls the W-P1 boundary term (q−1)·log(1−xqⁿ) once the endpoint 1−xqⁿ is bounded below by a multiple of q−1.

    theorem QOU.Archimedean.boundary_term_vanishes {ι : Type u_1} {l : Filter ι} {w δ : ι → ℝ} {c : ℝ} (hc : 0 < c) (hw0 : ∀ᶠ (i : ι) in l, 0 < w i) (hδ1 : ∀ᶠ (i : ι) in l, δ i < 1) (hbound : ∀ᶠ (i : ι) in l, c * w i ≤ δ i) (hδlim : Filter.Tendsto δ l (nhdsWithin 0 (Set.Ioi 0))) :
    Filter.Tendsto (fun (i : ι) => w i * -Real.log (δ i)) l (nhds 0)

    Conditional boundary-term limit (the "positive direction" of the W-P1 residual). Along any filter l, if the endpoint gap δ tends to 0⁺ and is bounded below by a fixed multiple of the width w (c·w ≤ δ, c > 0 — the Diophantine / no-resonance condition), then the boundary term w·(−log δ) → 0.

    Applied with δ = 1 − xqⁿ, w = q − 1, this closes the W-P1 boundary limit (q−1)·log(1−xqⁿ) → 0 whenever x satisfies the no-resonance bound 1 − xqⁿ ≥ c(q−1) — the precise hypothesis under which W-P1 converges. Proof: squeeze 0 ≤ w(−log δ) ≤ (δ/c)(−log δ) = −(1/c)·(δ log δ) → 0 by the seed tendsto_mul_log_nhdsWithin_zero.
