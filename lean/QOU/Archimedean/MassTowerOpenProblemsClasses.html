    §3b-cond classes for the four remaining mass-tower open problems #

    After the α_EM derivation chain (prop:archimedean-functor-uniqueness → prop:em-coupling-bring-zero-mode → conj:bring-hyperbolic-knot-bloch-decomposition), four structural gaps remain in the mass-tower derivation. This file consolidates them as Lean typeclasses in the §3b-cond pattern:

    • Term7ShellCorrectionClass — closes the α_5 phenomenological shell correction (Term 7) via a structural derivation in the GS spectral sequence at filtration ℓ=5.
    • ChiralityFactorClass — closes the deuterium chirality factor (1+h) via the Kauffman framing on H_n(R, q).
    • ZHabiroConvergenceClass — closes the |V|≈1 brane-tower divergence via a uniform z-Habiro bound.
    • AlphaOver4PiClass — closes the α/(4π) next-order term in the additive Bring zero-mode form via a higher Bloch group B_n(ℂ) (multivariate polylogarithm regulator).

    Each class encapsulates a single missing structural fact; a sorry-free conditional theorem follows the same pattern as prop:em-coupling-bring-zero-mode: take the class as [Instance], unpack the existential, conclude.

          Chirality factor class — strengthened. A concrete instance asserts the Kauffman-framing-formula derivation of a_K(β) = 1 + w(β) · ⟨c⟩_β · h + O(h²) on the Hecke ribbon category H_n(R, q), with the specific ⟨c⟩_β value determined by the Wedderburn-weighted character average. The "paper-empirical ansatz" of the trivial case ⟨c⟩ = 1 is one inhabited instance; the structural content is in the character-weighted average computation.

          • kauffman_derivation : ∃ (C : ℝ) (δ : ℝ), 0 < C ∧ 0 < δ ∧ ∀ (h : ℝ) (writhe : ℤ) (avg_content : ℝ), |h| < δ → |a_K h writhe avg_content - chirality_factor_first_order h writhe avg_content| ≤ C * h ^ 2

            Structural derivation of the chiral-case first-order factor from the Kauffman framing formula on the Hecke ribbon category, with explicit average-content factor: the ribbon-twist evaluation a_K agrees with 1 + w · ⟨c⟩ · h to O(h²) near h = 0.

            Two things changed on 2026-08-29, and both were load-bearing.

            a_K is now a parameter, not an existential. It was ∃ a_K error_term, …, which asserts only that some pair of functions differs by something times h² — satisfied by taking a_K to be the first-order polynomial itself and the error identically zero, which is how the instance below discharged it. An existential over the very object the claim is about says nothing about the Kauffman evaluation; a parameter does.

            The error is now bounded, which is what O(h²) means. The old field wrote + error_term · h² with error_term free, so the h² was decoration: an unbounded coefficient times h² can be any function at all.

            Same defect family as HasQPlancherelCLT (fixed in the same PR) and as the q-RH hasse-weil-bound axioms — an external theorem asserted over a structure that does not carry the theorem's hypotheses. Recorded in docs/audits/2026-08-29-q-ns-conditional-class-audit.md.

                    Unconditional class instances (where formal content is #

                    purely existential)

                    The four classes above are §3b-cond surrogates for substantive upstream conjectures. Three of them — Chirality, ZHabiro, and AlphaOver4Pi — have formal content that reduces to a purely existential statement (∃ z, z = <named real>) and can therefore be inhabited unconditionally inside Lean: the witness is the named real itself, with rfl. We provide those instances here so the corresponding conditional theorems unconditionalize.

                    The Term-7 case is not trivially inhabitable: the carrier alpha5_value is a placeholder requiring an explicit GS spectral-sequence derivation. We leave it as the residual conjectural input; an instance closure awaits the upstream structural derivation in conj:shell-correction-term-seven.

**Chirality is deliberately no longer in this list (2026-08-29).**
`ChiralityFactorClass` is now parametrised by the ribbon-twist
evaluation `a_K`, so no single instance can discharge it for an
arbitrary `a_K`, and its witness is an `example` rather than a
global `instance`. That is the point of the change: the previous
`chirality_factor_unconditional` asserted
`∃ a_K error_term, a_K = first_order + error_term · h²`
with nothing bounding `error_term` — a statement provable outright
by taking the error to be zero, which said nothing about the
Kauffman evaluation while reading as a discharged derivation.
What replaces it below is the honest residue: the class is
*consistent*, which is a different and much weaker claim.
