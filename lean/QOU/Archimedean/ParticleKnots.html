    QOU.Archimedean.ParticleKnots #

    Canonical declarations of the elementary-particle knot structures, shared by the predicted-spectra and knots-particles-confinement content blocks.

    Why these live here (bean qou-lsib, owner-authorised 2026-08-23) #

    They previously lived in the content-block .lean siblings that document them — electron-knot.lean, neutrino-knot.lean, and so on. Those files sit at content/{paper}/{chapter}/{block}.lean, outside the qou package's ["QOU", "QOU.+"] globs, so they are not modules and cannot import one another. A block needing another block's structure therefore had two options, and the corpus contained both:

    • re-declare it locally — down-quark.lean carried its own Neutrino and UpQuark, each a stripped-down copy with fewer fields than the original, so the two declarations were not even in agreement; or
    • reference it and fail to compile — positron-knot.lean referencing Electron, spectral-half-line.lean and hasse-weil-bound.lean referencing LocalQZetaFunction.

    Both are now unnecessary: a content-block sibling can import QOU.Archimedean.ParticleKnots and get one canonical declaration.

    Where a duplicate disagreed, the fuller declaration is canonical here. Every field carries a default, so a structure with more fields still admits ({} : T).field for each field the narrower version had; down-quark.lean was checked against this file's Neutrino and UpQuark and uses only fields present in both.

    Constructing a particle #

    Every field has a default, so the canonical instance is ({} : Electron) and a field is read as ({} : Electron).charge. Note that Electron.mk is the constructor — a function — so Electron.mk.charge does not elaborate; five blocks carried that form before it was corrected.

    R_q = ℤ[q, q⁻¹] is not redeclared here. It is QOU.Archimedean.GroundRing's, and this file imports it.

    Until 2026-08-30 both modules declared abbrev R_q := LaurentPolynomial ℤ — same name, same namespace, same body, and neither importing the other. Each compiled alone; they collided only where something imported both, which is the root aggregator QOU.lean: import QOU.Archimedean.ParticleKnots failed, environment already contains 'QOU.Archimedean.R_q' from QOU.Archimedean.GroundRing. Bean qou-lksc.
