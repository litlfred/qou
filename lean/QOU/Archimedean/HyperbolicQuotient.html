    §1 — The horizontal translation group #

    A translation of ℝ³ is an isometry of H³ exactly when it leaves the height coordinate alone. HyperbolicVolumeMeasure records why this is not a technicality: a vertical translation genuinely changes hyperbolic volume.

    The horizontal vectors — those with zero height. Translations by these are isometries of H³; translations by anything else are not.

        §3 — The action is free #

        Freeness is what makes the quotient a manifold rather than an orbifold: no nonzero element of Γ may fix a point. For translations this is immediate, and worth recording precisely because it is the hypothesis that silently fails for a general group.

        §5 — The hypotheses are inhabited #

        Everything above would be worth nothing over an empty class, so: horizontal groups with nonzero elements exist, and the rank-1 lattices are among them. Without this section a reader cannot tell §4 from a vacuous statement.

            §6 — A fundamental domain actually exists #

            §4 is a statement about fundamental domains, so it is worth exactly nothing until one is exhibited. This section proves the unit slab 0 ≤ x < 1 is a fundamental domain for the rank-1 lattice, which is what makes §4 an applicable theorem rather than a conditional over a possibly-empty hypothesis.

            That distinction is not hypothetical here: the sibling HyperbolicVolumeBridge was first written with a class admitting Realises := fun _ _ => False, under which every theorem about it held vacuously. Exhibiting the model is the only way to know.
