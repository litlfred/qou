    Multi-Generator Spectrum: 6×6 Transfer Matrix Products #

    For a single Hecke generator σ_i, the 6×6 transfer matrix has the same eigenvalues as the 2×2 (namely q and −q⁻¹), as proved by transfer_matrix_6x6.py. Channel separation only activates for multi-generator products — i.e., the raw Gröbner--Shirshov normal form acting as a full braid word.

    This file formalises the multi-generator spectral structure:

    1. Independent channel evolution: for a product of crossings, each irrep block evolves independently.
    2. Symmetric channel: the product of symmetric eigenvalues is ∏ (c_j · q + d_j) — depends only on crossing coefficients.
    3. Standard channel: the product of 2×2 transfer matrices — this is path-dependent and captures braid topology.
    4. Alternating channel: the product of alternating eigenvalues is ∏ (d_j − c_j · q⁻¹) — depends only on crossing coefficients.

    The standard channel's eigenvalue ratio relative to the symmetric channel is what produces the axial coupling suppression g_A < 5/3.

    References #

    • [manuscript] §7, axial coupling from 3-fold Borromean color average.
    • [mathas1999] A. Mathas, Iwahori--Hecke Algebras and Schur Algebras, AMS 1999.

              source
              theorem QOU.Archimedean.independent_channel_evolution (seq : List (R_t × R_t)) :
              have fullRep := { lamSym := multiSymEigenvalue seq, T_std := multiStdMatrix seq, lamAlt := multiAltEigenvalue seq }; fullRep.lamSym = multiSymEigenvalue seq ∧ fullRep.T_std = multiStdMatrix seq ∧ fullRep.lamAlt = multiAltEigenvalue seq

              Theorem (Independent channel evolution).

              For a multi-generator product, the 6×6 transfer matrix is block-diagonal:

              T₆(product) = lamSym(product) ⊕ T_std(product) ⊕ T_std(product) ⊕ lamAlt(product)

              The channels evolve independently — the symmetric eigenvalue does not interact with the standard matrix, etc.

              Proof: the 6×6 matrix is block-diagonal for each generator (by the Wedderburn-Artin decomposition of H₃(q)), and the product of block-diagonal matrices is block-diagonal.

              §3 The per-generator triviality theorem #

              source
              theorem QOU.Archimedean.per_generator_eigenvalue_coincidence :
              symEigenvalue 1 0 = q_from_t ∧ altEigenvalue 1 0 = -q_inv_from_t

              Theorem (Per-generator eigenvalue coincidence).

              For a SINGLE generator (crossing sequence of length 1), all three irreps have eigenvalues drawn from {q, −q⁻¹}:

              • Symmetric: lamSym = c·q + d
              • Standard: eigenvalues of T(c,d) = {c·HA + d ± √Δ}/2 where Δ = (c·HA+d-d)² + 4c² — for pp: eigenvalues are q, −q⁻¹
              • Alternating: lamAlt = d − c·q⁻¹

              For the pp crossing (c,d) = (1,0): lamSym = q, lamAlt = −q⁻¹, and the 2×2 has eigenvalues q, −q⁻¹. All channels share the same eigenvalue set.

              This is the formal content of transfer_matrix_6x6.py line 233: "the 6×6 does NOT give new information beyond the 2×2 for the PER-GENERATOR transfer matrix."

              §4 Multi-generator channel divergence #

              source
              theorem QOU.Archimedean.multi_pp_sym_eigenvalue (k : ℕ) :
              multiSymEigenvalue (List.replicate k (1, 0)) = q_from_t ^ k

              Theorem (Multi-generator channel divergence).

              For a multi-generator product, the ratio between the symmetric and alternating eigenvalues is: lamSym / lamAlt = ∏_j ((c_j·q + d_j) / (d_j − c_j·q⁻¹))

              For k pure pp crossings (1, 0): lamSym = q^k, lamAlt = (−q⁻¹)^k = (−1)^k · q^{−k} lamSym / lamAlt = (−1)^k · q^{2k}

              This ratio diverges as k → ∞ (for q > 1), showing that the channels become increasingly separated for longer braid words.

              For the standard channel, the ratio is more complex because it involves the 2×2 matrix product, which depends on the specific braid topology (not just the length).

              §5 Connection to axial coupling #

              Remark — axial coupling as channel ratio #

              The axial-vector coupling `g_A` is the ratio of the standard trace
to the symmetric trace of the color-averaged Borromean element:

`g_A(q) = (5/3) × |tr_std(β_color)| / |tr_sym(β_color)|`

In multi-generator terms:
- `tr_sym(β_color)` is the multiSymEigenvalue of the Borromean braid word
- `tr_std(β_color)` involves the trace of the multiStdMatrix
- The ratio measures HOW MUCH the standard channel deviates from
  the symmetric channel for the specific Borromean topology

The standard channel's trace is sensitive to the braid topology
(half-Borromean crossings produce different 2×2 matrices depending
on the color ordering), while the symmetric trace depends only on
the total crossing count.

This asymmetry is why `g_A ≈ 1.277 < 5/3 ≈ 1.667`: the axial
(standard) channel is suppressed relative to the vector (symmetric)
channel by the Borromean topology.
