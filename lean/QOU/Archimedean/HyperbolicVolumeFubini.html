    The Pi/Prod split #

    Tonelli is stated for a product measure; H1's carrier is Fin 3 → ℝ. This is the measure-preserving bridge, with the HEIGHT coordinate split off first so that lintegral_prod_symm leaves the base integral outermost — the order Milnor's computation uses.

    Fin 3 → ℝ ≃ᵐ ℝ × (ℝ × ℝ), height first. Splits coordinate 2 off the Pi type, then pairs the remaining two.

      The vertical fibre mass #

      The ℝ≥0∞ mass a single vertical fibre of a chimney carries. chimney_fibre (H3) is what says this ray IS the fibre; H4-1 is what evaluates it.

        H4-2a — Fubini #

        The reduction itself: three dimensions collapse to two. No hypothesis on where the base sits; both sides may be ⊤.

        source
        theorem QOU.Archimedean.HyperbolicVolume.hypVolume_chimney {T : Set (ℝ × ℝ)} (hT : MeasurableSet T) (R : ℝ) :
        hypVolume (chimney T R) = ∫⁻ (w : ℝ × ℝ) in T, fibreMass R w

        H4-2a (Fubini) — a chimney's hyperbolic volume is the base integral of its fibre masses.

        Unconditional: no assumption that the base lies inside the disk, so both sides are permitted to be ⊤ (and by fibreMass_eq_top they are, as soon as the base meets the exterior of the circle).

        H4-2b — the lintegral/Bochner bridge #

        hypVolume integrates in ℝ≥0∞; H4-1 is a Bochner integral. This is the reconciliation, and it is where H4-1's convergence does real work: the bridge lemma needs genuine integrability, which holds exactly because the exponent −3 is < −1.

        source

        fibreMass R w = ENNReal.ofReal (1 / (2 * (R ^ 2 - w.1 ^ 2 - w.2 ^ 2)))

        H4-2b — the fibre mass over a base point strictly inside the circle.

        ∫_{√(R²−d²)}^{∞} dz/z³ = 1/(2(R²−d²)), now as an ℝ≥0∞ mass. This is H4-1's value, transported across the ∫⁻/∫ boundary.

        The disk hypothesis is the exact finiteness boundary #

        source
        theorem QOU.Archimedean.HyperbolicVolume.fibreMass_eq_top {R : ℝ} {w : ℝ × ℝ} (hw : R ^ 2 ≤ w.1 ^ 2 + w.2 ^ 2) :
        fibreMass R w = ⊤

        Off the open disk the fibre carries infinite mass.

        Real.sqrt of a non-positive number is 0, so the chimney's floor degenerates to z > 0 and ∫_0^∞ dz/z³ diverges. Proved rather than asserted, because it is what makes hypVolume_chimney_of_subset_disk's hypothesis the exact boundary between a finite and an infinite volume, not a convenience.

        H4-2 assembled #

        The statement H4-3 consumes: over a base inside the disk, the three-dimensional hyperbolic volume IS Milnor's two-dimensional base integral.

        H4-2 — the Fubini reduction, in the form H4-3 will consume.

        Vol(chimney T R)  =  ∫∫_T  dA / (2(R² − x² − y²)).

        The hypothesis is almost-everywhere, and that is not a technical generalisation — it is what makes the statement applicable at all. Milnor's base triangle is inscribed in the circle, so its three VERTICES lie exactly ON it, where R² − x² − y² = 0 and the fibre mass is ⊤ (fibreMass_eq_top). A pointwise ∀ w ∈ T hypothesis would therefore exclude the closed triangle — precisely the case H4-3 needs. The vertices are a null set, so a.e. is both sufficient and honest.
