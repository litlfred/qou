    q-Hook Perturbation Bound #

    Step 1 of the convergence proof for the jet-filtered knot invariant.

    The q-integer [m]_q = (qᵐ − q⁻ᵐ)/(q − q⁻¹) satisfies:

    [m]_q / m = 1 + h² · (m² − 1) / (12 · m) + O(h⁴)

    where h = q − q⁻¹. For |h| < 1, the ratio is bounded:

    |[m]_q / m − 1| ≤ h² · m / 6

    The q-dimension d_q(λ) = [k]_q! / ∏ [hook]_q satisfies:

    |d_q(λ) / dim(λ) − 1| ≤ h² · k / 6

    because each q-integer ratio introduces at most h²·m/6 relative error, and the product has cancellations (numerator and denominator have the same factors in different order).

    This gives the q-Plancherel perturbation: the Wedderburn weights w_λ = d_q(λ)²/[k]! differ from the classical Plancherel measure dim(λ)²/k! by a factor of (1 + O(h²/k))².

    • [conj:jet-convergence-classical-limit]

      theorem QOU.Archimedean.QHookBound.qInt_pos (q : ℝ) (hq : q > 1) (m : ℕ) (hm : m ≥ 1) :
      qIntReal q m > 0

      For q > 1 and m ≥ 1, [m]_q > 0.

      The ratio [m]_q / m is close to 1 for small h = q - q⁻¹.

      [m]_q / m = 1 + h²(m² − 1)/(12m) + O(h⁴)

where h = q − q⁻¹.

Proof sketch: write q = e^θ, then
[m]_q = sinh(mθ)/sinh(θ)
[m]_q/m = sinh(mθ)/(m·sinh(θ))
For small θ: sinh(mθ)/(mθ) = 1 + (mθ)²/6 + ...
and sinh(θ)/θ = 1 + θ²/6 + ...
so the ratio = (1 + m²θ²/6)/(1 + θ²/6) = 1 + (m²-1)θ²/6 + ...
and h = 2sinh(θ) ≈ 2θ, so θ² ≈ h²/4, giving
[m]_q/m ≈ 1 + (m²-1)h²/24.

The bound |[m]_q/m - 1| ≤ h²·m/6 follows for m ≥ 1.

m = 4 gives LHS ≈ 1.36 > 1.26 ≈ RHS — so the hypothesis `q < 3/2` is

            §3 q-hook formula perturbation #

            The q-dimension of a partition λ is: d_q(λ) = [k]q! / ∏{cells c} [hook(c)]_q

            The hook-length formula is a ratio of q-integers, so:
d_q(λ)/dim(λ) = ([k]!/k!) × ∏(hook(c)/[hook(c)]_q)

Since [m]_q/m ≈ 1, each hook ratio is ≈ 1, and the product
has cancellations (same factors appear in num and denom).
            source
            theorem QOU.Archimedean.QHookBound.qDim_geq_dim (q : ℝ) (_hq : q > 1) (dq dim_classical : ℝ) (_hdq : dq > 0) (hdim : dim_classical > 0) (h_ratio : dq / dim_classical ≥ 1) :
            dq ≥ dim_classical

            q-dimension ratio bound (finite k).

            For any partition λ ⊢ k with k ≤ K: d_q(λ)/dim(λ) = ∏_{cells c} [hook(c)]_q / hook(c)

            Each factor satisfies [m]_q/m ≥ 1 (by qInt_ratio_upper), so d_q ≥ dim (the q-dimension is at least the classical one).

            For the RATIO in the branching fraction f_μ^{(k)}, the individual d_q/dim bounds cancel between numerator and denominator. The net effect on the fraction is O(h²) because:

            f_μ^{(k)} = Σ (d_q²/[k]!)·m_μ / Σ (d_q²/[k]!)·Σm_ν = Σ (dim²·R²/k!)·m_μ / Σ (dim²·R²/k!)·Σm_ν

            where R = d_q/dim. Since R appears in both num and denom, the ratio is: f_μ^{(k)} = Σ R²·dim²·m_μ / Σ R²·dim²·Σm_ν

            The R² factors perturb the classical measure by O(h²) per partition, but the SUM over all partitions averages these perturbations, giving convergence.

            §4 Wedderburn weight perturbation #

            The Wedderburn weight ratio: w_λ / w_λ^{classical} = (d_q/dim)² × (k!/[k]!)

            From the qDim bound:
|(d_q/dim)² - 1| ≤ 2 · |d_q/dim - 1| + |d_q/dim - 1|²
                 ≤ 2 · C·h²·k + (C·h²·k)²

For h²·k < 1 (which holds for all k of interest since h ≈ 0.2):
|w_λ/w_λ^cl - 1| ≤ 3 · C · h² · k

This means the q-Plancherel measure approximates the classical
Plancherel measure within O(h²·k).

              §5 Convergence rate #

              Convergence rate theorem: combining the q-perturbation bound with the classical branching asymptotics gives:

              |f_μ^{(k)} - f_μ^∞| ≤ C_q / (k - n + 1)

where n = 3 (the restriction target), and
C_q = 3 · h² · max_μ d_q(μ) / min_μ d_q(μ).

For H₃(q) with d_q = (1, [2], 1):
C_q = 3 · h² · [2] ≈ 3 × 0.044 × 2.01 ≈ 0.26.

At k = 8: bound = 0.26/6 ≈ 0.043.
Actual error at k = 8: 0.009 (well within bound).

              Convergence rate (improved via Féray–Méliot).

              The q-Plancherel CLT [feray2010] gives character variance O(1/k),
so the branching fraction converges at rate O(1/√k):

|f_μ^{(k)} − f_μ^∞| ≤ C_q / √(k − 3)

where C_q = O(h² · [2]_q) depends on q but not on k or μ.

This is STRONGER than our earlier O(1/k) estimate.
At k = 9: bound ≈ C_q/√6 ≈ 0.11 (actual 0.008 — well within).
At k = 12: bound ≈ C_q/3 ≈ 0.09.
