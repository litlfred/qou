    Young Symmetric Idempotent for H_n(q) #

    The Young symmetric idempotent e_{(n)} is the element of the Iwahori–Hecke algebra H_n(q) that projects onto the symmetric (trivial) representation.

    Main definitions #

    • CoxeterLength — the Coxeter length ℓ(w) of a permutation w ∈ S_n
    • S3Perms — explicit enumeration of S₃ (6 elements)
    • permToHeckeWord — embed a permutation into H_n(q) via a reduced word
    • poincarePolynomial — the Poincaré polynomial P_n(q²)
    • youngSymIdempotent — the Young symmetric idempotent e_{(n)}

    Key properties #

    The Young symmetric idempotent satisfies:

    1. e_{(n)}² = P_n(q²) · e_{(n)} (quasi-idempotent)
    2. σ_i · e_{(n)} = q · e_{(n)} (eigenvalue property for symmetric rep)
    3. e_{(n)} · σ_i = q · e_{(n)} (right eigenvalue property)

    References #

    • [murphy1992] G. Murphy, On the representation theory of the symmetric groups and associated Hecke algebras.
    • [mathas1999] A. Mathas, Iwahori-Hecke Algebras and Schur Algebras of the Symmetric Group.

        Archimedean.R_t

        The q²-integer [n]_{q²} = 1 + q² + q⁴ + … + q^{2(n−1)} as an element of ℤ[t, t⁻¹] where q = t².

        This is the sum form — no division required, so it lives in the Laurent polynomial ring directly.

        [n]_{q²} = Σ_{k=0}^{n-1} q^{2k} = Σ_{k=0}^{n-1} t^{4k}

          noncomputable def QOU.YoungIdempotent.poincarePolynomial :
          ℕ → Archimedean.R_t

          The Poincaré polynomial P_n(q²) = ∑_{w ∈ S_n} q^{2ℓ(w)}.

          This is the sum of q^{2ℓ(w)} over all permutations in S_n. It equals the q²-factorial: P_n(q²) = [n]_{q²}!.

          Recursion: P_n = P_{n-1} · [n]_{q²} where [n]_{q²} = 1 + q² + q⁴ + … + q^{2(n-1)}.

          For small n:

          • P₁ = 1
          • P₂ = 1 + q² = [2]_{q²}
          • P₃ = (1 + q²)(1 + q² + q⁴) = [2]{q²} · [3]{q²} = 1 + 2q² + 2q⁴ + q⁶
          Equations
          • QOU.YoungIdempotent.poincarePolynomial 0 = 1
          • QOU.YoungIdempotent.poincarePolynomial n.succ = QOU.YoungIdempotent.poincarePolynomial n * QOU.YoungIdempotent.qSqInt (n + 1)

            §4 Young symmetric idempotent (for representations) #

            noncomputable def QOU.YoungIdempotent.youngSymIdempotent3 {d : ℕ} (ρ : Archimedean.HeckeRep 3 d) :
            Matrix (Fin d) (Fin d) Archimedean.R_t

            The Young symmetric idempotent evaluated in a representation.

            For a representation ρ : H_n(q) → End(V), the image of the Young symmetric idempotent is:

            ρ(e_{(n)}) = ∑_{w ∈ S_n} q^{ℓ(w)} · ρ(T_w)

            where T_w is the Hecke algebra element for permutation w (using any reduced word).

            For H₃(q), this is explicitly: e_{(3)} = 1 + q·T₁ + q·T₂ + q²·T₁T₂ + q²·T₂T₁ + q³·T₁T₂T₁

                The Young symmetric idempotent satisfies the eigenvalue property: σ_i · e_{(n)} = q · e_{(n)} in the Hecke algebra.

                In a representation:
`ρ(σ₀) · ρ(e_{(3)}) = q · ρ(e_{(3)})`

This is the key property used for ordering independence:
the Skein polynomial symmetrized by e_{(n)} depends only on
the multiset of crossing weights, not their ordering.

Proof strategy: expand σ₀ · e_{(3)} using the Hecke and braid
relations to show each term contributes correctly.

For each w ∈ S₃, σ₀ · T_w is either:
- T_{s₀w} with ℓ(s₀w) = ℓ(w) + 1 (length increases), or
- q · T_w + (q−q⁻¹) · T_{s₀w} with ℓ(s₀w) = ℓ(w) − 1 (Hecke reduction)

Summing over S₃ with q^{ℓ(w)} weights produces q · e_{(3)}.
