        The edge-perpendicular in-face tangent vector #

        source
        noncomputable def QOU.Archimedean.edgePerp (n : ℝ × ℝ) (s : ℝ) :
        EuclideanSpace ℝ (Fin 2)

        The interior edge-perpendicular in-face tangent vector of a vertical face with base normal n, oriented by s = ±1. It is the 90°-rotation s·(−n.2, n.1) of the normal: horizontal (so ⊥ the vertical edge), in the face plane (⊥ n, see inner_edgePerp_self_normal), and unit when n is unit and s = ±1. The sign s is chosen (per wedge) so the vector points into the wedge, certified for a concrete wedge by inner_edgePerp_normal.

          The hyperbolic dihedral angle along a common edge, between two edge-perpendicular in-face tangent vectors e₁, e₂ at height z: the hyperbolic angle between them. (For a vertical edge these are horizontal vectors; File 1 makes the value height-independent and equal to the Euclidean angle.)

            theorem QOU.Archimedean.dihedralAngle_edgePerp {z : ℝ} (hz : 0 < z) {n₁ n₂ : ℝ × ℝ} {s₁ s₂ θ : ℝ} (hn1 : n₁.1 ^ 2 + n₁.2 ^ 2 = 1) (hn2 : n₂.1 ^ 2 + n₂.2 ^ 2 = 1) (hs1 : s₁ ^ 2 = 1) (hs2 : s₂ ^ 2 = 1) (hdot : s₁ * s₂ * (n₁.1 * n₂.1 + n₁.2 * n₂.2) = Real.cos θ) (hθ0 : 0 ≤ θ) (hθπ : θ ≤ Real.pi) :
            dihedralAngle z (edgePerp n₁ s₁) (edgePerp n₂ s₂) = θ

            The workhorse. If the two interior edge-perpendicular in-face vectors are unit (base normals unit, signs ±1) and their dot product is cos θ for some θ ∈ [0, π], then the dihedral angle along that edge is θ.

            This is genuinely non-vacuous: the dot product is the actual Euclidean dot of the two rotated normals, and θ is recovered as arccos of it — the standard measurement of a dihedral angle in the conformal model.
