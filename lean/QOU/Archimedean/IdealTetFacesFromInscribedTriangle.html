      theorem QOU.Archimedean.chimney_infedge_dihedral_eq_vertexAngle {t α β γ : ℝ} (hα0 : 0 < α) (hβ0 : 0 < β) (hγ0 : 0 < γ) (hα : α < Real.pi / 2) (hβ : β < Real.pi / 2) (hγ : γ < Real.pi / 2) (hsum : α + β + γ = Real.pi) :
      dihedralAngle 1 (edgePerp (chordNormal (t + γ)) 1) (edgePerp (chordNormal (t + 2 * γ + 2 * α + β)) (-1)) = α ∧ dihedralAngle 1 (edgePerp (chordNormal (t + γ)) (-1)) (edgePerp (chordNormal (t + 2 * γ + α)) 1) = β ∧ dihedralAngle 1 (edgePerp (chordNormal (t + 2 * γ + α)) (-1)) (edgePerp (chordNormal (t + 2 * γ + 2 * α + β)) 1) = γ

      The three ∞-edge dihedral angles of the chimney over the inscribed triangle are the triangle's vertex angles (α, β, γ).

      The interior edge-perpendicular in-face vectors are exhibited explicitly (with their orientation signs), and the dihedral angle along each ∞-edge is computed directly via dihedralAngle_edgePerp. No geometry is assumed beyond File 1's conformality — this is a real computation of the three angles.

      Interior-orientation certificates #

      The orientation signs above are not free choices tuned to the answer: each edgePerp vector points INTO the wedge, certified by a negative dot product with the neighbouring face's outward normal (i.e. it lies on the neighbour's interior < 0 side). This pins the vectors to the genuine interior edge-perpendicular in-face vectors, so the computed angle is the true interior dihedral angle.
