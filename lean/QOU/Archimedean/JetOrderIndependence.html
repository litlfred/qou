    QOU.Archimedean.JetOrderIndependence — the gap-closing reduction #

    §3b-cond conditional theorem for content block conj:three-knot-jet-order-independence: Jet-order algebraic independence (QOU-attackable reduction).

    This file formalises the reduction that closes the deep algebraic-independence conjecture (conj:hyperbolic-volume-transcendence) relative to two narrower, QOU-native inputs:

    1. JetOrderIndependence — finite jet-order independence: the order-N cyclotomic-coefficient Jacobian of the three coloured-Jones series J_{4₁}, J_{5₂}, J_{𝓑₃} has full rank 3 from the Reid-1991 base order onward. Decidable per order (a Gröbner–Shirshov normal form), so this is the QOU-attackable weakening.
    2. SurrealParallelTransportBound — the bridge: the surreal parallel-transport error of the categorical connection on the projective state fibre ℂP¹, as q deforms toward the root-of-unity (volume-conjecture) limit, has vanishing archimedean shadow, uniformly in the jet order.

    The reduction hyperbolicVolumeIndependence_of_reduction derives HyperbolicVolumeIndependence from these two plus the bridge step JetTransportImpliesIndependence (the Nesterenko-type transfer from finite jet data to the infinite-order polynomial statement), each conjectural per §3b-cond. It does NOT prove the deep conjecture; it converts a Grothendieck-period dead end into named internal QOU targets whose conditional structure is visible at every call site.

    The surreal parallel-transport bound — geometric content + open issues #

    The coloured-Jones invariant J_K(q) is the holonomy of the categorical (Yekutieli non-abelian Stokes / KZ) connection, parallel- transported along the substrate q-deformation path on the projective state fibre 𝒮 = P ×_G ℂP¹. The hyperbolic volume is the leading asymptotics of that holonomy at the singular limit: Vol(K) = lim_{n→∞} (2π/n)·log|J_K(e^{2πi/n})|. The surreal error bound measures the transport error as q approaches that singular (root-of-unity) point; it is surreal (non-Archimedean) precisely because the limit point is a singularity of the connection, so the error is an infinitesimal in the surreal field, not a real number.

    The class field transportShadow N is the archimedean realification (τ-shadow) of that fibre-level surreal infinitesimal at jet order N. The conjectural content shadow_vanishes packages the three open issues that must hold for the bridge:

    • (I1) Uniformity in jet order. The transport error must be bounded uniformly across all truncation orders N; otherwise order-N independence does not transfer to the limit. On ℂP¹ this is uniform control of the connection's curvature along the deformation path, independent of N. Non-uniform error growing with N breaks the bridge.
    • (I2) Archimedean projection (the fibre-vs-observable wall). The error lives at the fibre level (surreal, possibly carrying the Im(q) structure of AGENTS.md's fibre/archimedean box); the volume is archimedean (Im(q₀)=0, real). The bridge needs the surreal infinitesimal to project to exactly 0 under τ. A non-infinitesimal archimedean shadow injects a spurious polynomial relation among the volumes and independence fails — this is why the field is named a shadow.
    • (I3) Monodromy separation at the singular limit. Transport around the cusp is flat only at generic q; at the root-of-unity limit the holonomy picks up cusp/modular monodromy. The bound must separate the physical holonomy (→ Vol) from the monodromy artifact. Open: is the monodromy contribution surreal-controlled, or does it leak into the real volume?

    shadow_vanishes : ∀ N, transportShadow N = 0 is the assertion that (I1)+(I2)+(I3) all hold — the single conjectural input of the bridge.

                GB-elimination certificate (discharging JetOrderIndependence) #

                The weak conjecture asks that the order-N cyclotomic-coefficient Jacobian of the three coloured-Jones series has full rank 3. Per order this is a finite, decidable Gröbner–Shirshov elimination test: row-reduce the 3 × (N+1) coefficient matrix to echelon form and check the three pivots are non-zero — equivalently, that a 3 × 3 minor of the eliminated form has non-zero determinant.

                The order-3 minor below is the GB-eliminated (row-echelon) form of the order-≤2 jet-coefficient data at the Reid-1991 base order, recorded by its three pivots. These are witnessed from the framework's own canonical Markov traces (jet_order_pivots.py): the h-jet expansion about q = 1 of tr_M(K) for the canonical braid words of 4₁, 5₂, 𝓑₃ gives the jet-Jacobian rows (1/4, −1, 55/16), (1/2, 0, −1/16), (1, 0, 0), with elimination determinant 1/16 ≠ 0 and LU pivots (1/4, 2, 1/8). The certificate jetOrder3_certificate (elimination determinant = ∏ pivots ≠ 0) is the genuine, sorry-free content: (1/4)·2·(1/8) = 1/16 ≠ 0, so the order-3 Jacobian has full rank 3 and the three series are jet-order independent at the base order.

                        Rank-monotonicity: full rank at every order from the base order #

                        JetOrderIndependence.full_rank is not an independent claim at each order — mathematically it propagates from the single base-order certificate. The order-N coefficient Jacobian is 3 × (N+1); its first three columns are the witnessed base-order minor jetJacobianBase, whose determinant is 1/16 ≠ 0. An invertible 3×3 block forces rank ≥ 3 (Matrix.rank_submatrix_le), while the row count 3 forces rank ≤ 3 (Matrix.rank_le_height), so the order-N Jacobian has rank exactly 3 for every N, rank being monotone in the column count.

                        This file formalizes the two endpoints of that argument, not the order-N Jacobian itself: (1) the base minor is full-rank (jetJacobianBase_rank, via invertibility), and (2) the abstract monotonicity principle (jacobianRank_eq_three_of_base). Discharging the principle's hypotheses (Monotone, ≤ 3, base = 3) for the concrete order-N Jacobian — the column-extension/submatrix linkage stated above — is the remaining structural input, not a lemma proved in this file.

                          Why this file declares no global instances (2026-08-09) #

                          Both conjectures above were previously discharged by global instances that carried no mathematical content. Per AGENTS.md §3b-tax — "An unproved primary is honestly represented by a content-bearing class with no instance; do not fabricate a trivial instance to close it" — they are removed. This is the same failure mode this file's own history note records for HyperbolicVolumeIndependence on 2026-06-10, recurring one class down.

                          (1) SurrealParallelTransportBound — the instance was vacuous. It read

                            transportShadow := fun _ => 0 ; physicalShadow := fun _ => 0
  monodromyShadow := fun _ => 0 ; …_archimedean_zero := fun _ => rfl

                          Because transportShadow is a class field, the instance gets to choose the shadow, and the constant-zero choice satisfies (I2) and (I3) by rfl. So [SurrealParallelTransportBound] was discharged for free, and with it every downstream conditional — including hyperbolicVolumeIndependence_of_reduction, whose whole point is to expose the conditional structure at each call site. The two "PROVED" lemmas transport_shadow_vanishes and transport_uniform_bound remain valid: they are honest statements about a given SurrealParallelTransportBound, and are unaffected by the removal.

                          Redesigned the same day (bean qou-ijhk). Removing the instance stops the free discharge but does not by itself make the class content-bearing — any future instance could re-pick the zero functions. So the shadows were moved out of the class into TransportErrorData and the class now takes that data as a parameter: SurrealParallelTransportBound (E : TransportErrorData). A consumer must now name the error it assumes about, and that name propagates through JetTransportImpliesIndependence E and hyperbolicVolumeIndependence_of_reduction E to every call site.

                          The residual vacuity that parameterisation cannot remove — one may still instantiate at the zero error — is no longer left as a latent trap. It is recorded as the pair trivialError_bound (the bound holds at the zero error, so an instance for an unspecified E asserts nothing) and not_bound_of_physical_ne_zero (for an E with a non-zero physical shadow the bound is a real constraint that fails). Together they state exactly what an instance is worth. Supplying the E that actually comes from the categorical connection still requires a Lean definition of the transport error, which remains open.

                          (2) JetOrderIndependence — the instance fabricated its data. It applied ofPivots to jetPivots = fun _ => (1/4, 2, 1/8), a constant extension of the order-3 pivots to every order, thereby asserting full_rank at all N ≥ 3 — which is the open conjecture. The genuine content is kept and is unchanged: jetPivots (the witnessed base-order pivots), jetOrder3_certificate (∏ pivots = 1/16 ≠ 0, sorry-free), jetJacobianBase_rank = 3, eliminationDet_ne_zero, ofPivots and jacobianRank_eq_three_of_base. What is dropped is only the step from "certified at the base order" to "holds at every order". To discharge the conjecture honestly, feed ofPivots the per-order pivots actually produced by computations/jet_order_pivots.py at higher jet truncation, or discharge jacobianRank_eq_three_of_base's hypotheses for the concrete order-N Jacobian (the column-extension linkage this file already flags as "the remaining structural input").

                          Consumers that want the conditional form bind the classes explicitly per §3b-cond, which is exactly the visibility the reduction was written to provide.
