    Borromean rings volume — Catalan-constant categorical identity #

    Formalises the Adams 1985 result Vol(𝓑₃) = 8 · G where G is Catalan's constant. This is the categorical Lean theorem that the production code (computations/m_p_borromean_verification_50dps.py, _li_2_q_util.vol_density_borromean) currently uses as a literal mp.catalan numerical value.

    Why this matters (per docs/audits/2026-05-25-m-p-m-n-full-chain-audit.md §3): the Family A linking_weight 5/2 + (3/4)h² is PROVED in lambda-scale-substrate-form.lean, but the base hyperbolic volume Vol(𝓑₃) is currently cited from Adams 1985 as a numerical literal, NOT Lean-proved. Closing this gap formalises the LEADING factor in the canonical mass formula m(𝓑₃) = m_e · Vol(𝓑₃)/ℏ_q² · linking_weight.

    Structure #

    This file is a scaffold with axiom-witnessed theorems and explicit bibliographic citations. The full proof requires:

    1. Catalan's constant — definition via the series G := Σ (-1)^k / (2k+1)². Not yet in Mathlib (loogle/leansearch confirm); now defined upstream in QOU.Archimedean.HyperbolicVolumeTranscendence (lifted 2026-06-07 so that vol_B3 := 8 · catalan_G can be the symbolic exact volume rather than a 15-dps SnapPy decimal). The catalan_G_numerical_bounds interval also lives upstream — a theorem since 2026-06-10 (alternating-series bracket), formerly an axiom citing the 24-digit literature value.
    2. Lobachevsky function Λ : ℝ → ℝ defined as Λ(θ) := -∫_0^θ ln|2 sin t| dt. Not in Mathlib; declared here.
    3. Lobachevsky-Catalan identity Λ(π/4) = G/2. Standard (e.g. Lewin, "Polylogarithms and Associated Functions", 1981).
    4. Adams 1985 octahedral decomposition: 𝓑₃ has a complete hyperbolic structure as a union of 2 ideal regular octahedra; each octahedron has hyperbolic volume 8 · Λ(π/4) = 4G. So Vol(𝓑₃) = 2 · 4G = 8G. Since vol_B3 is now defined as 8 · catalan_G, this identity is rfl.

    The axioms are tagged with -- Ref: citations per AGENTS.md §1 (every axiom and sorry requires a bibliographic citation).

    §2 Lobachevsky function #

    source
    noncomputable def QOU.Archimedean.lobachevsky (θ : ℝ) :
    ℝ

    The Lobachevsky function Λ : ℝ → ℝ, Λ(θ) := -∫_0^θ ln|2 sin t| dt.

    Defined directly via Mathlib's intervalIntegral over the integrand -ln|2 sin t|. The integral is improper at the boundary (ln|2 sin 0| is -∞) but Lebesgue-integrable; intervalIntegral returns the canonical value when the integrand is integrable. For misuse / outside the convergent domain Mathlib's intervalIntegral falls back to 0, so callers should not rely on the value outside the standard Λ(π/4) = G/2 interface below.

    Equivalent to the Clausen function Cl_2 via Λ(θ) = (1/2) Cl_2(2θ); the natural measure of ideal-hyperbolic-tetrahedron volume in Lobachevsky's formula Vol(Δ(α,β,γ)) = Λ(α) + Λ(β) + Λ(γ).

    -- Ref: [lewin1981] Lewin, "Polylogarithms and Associated Functions", North-Holland (1981), §4.2 eq. 4.2.1. -- Ref: [zagier1986] Zagier, "Hyperbolic manifolds and special values of Dedekind zeta-functions" — connection to hyperbolic geometry.

      §3 Lobachevsky-Catalan identity #

      source
      theorem QOU.Archimedean.lobachevsky_pi_div_four_eq_half_catalan :
      lobachevsky (Real.pi / 4) = catalan_G / 2

      Lobachevsky-Catalan identity: Λ(π/4) = G/2.

      Standard identity in hyperbolic geometry / polylogarithm theory.

      Proof: substitute t = π/4 − s in the Lobachevsky integral, expand ln|2 sin(π/4 − s)| = ln|cos s − sin s| via the sin/cos addition formula, and integrate term-by-term against the Catalan series. Established literature fact (Lewin 1981 §4.2 eq. 4.2.21).

      PROVED 2026-08-26 — this was an axiom until today. The reasons recorded below for keeping it an axiom were both wrong, and the way they were wrong is worth keeping.

      The original text said a proof "would require Mathlib's full polylogarithm machinery (Clausen function Cl_2, dilogarithm Li_2, substitution-in- intervalIntegral over an improper integrand) — none of which is currently upstream". A 2026-08-25 revision narrowed that to one residual obstruction, "the Clausen integral representation Cl_2' θ = -log|2 sin(θ/2)| ... genuine analysis over an improper integrand", and classified it External.

      That residual obstruction was already discharged, in this repository, and had been since before the note was written. QOU.Knot.clausen_eq_series proves ∫₀^θ -log(2 sin(t/2)) dt = Cl_2 θ on (0, 2π), sorry-free, by pinning the constant between hasDerivAt_clausen (FTC) and hasDerivAt_Cl_2_series (Abel limit + locally-uniform convergence). Both halves of the "missing" analysis — the log-sine integrability at the endpoint, via MeromorphicOn.intervalIntegrable_log, and the boundary behaviour of the log power series, via Mathlib.Analysis.Complex.AbelLimit — are upstream and were already being used there. The gap was in the search, not in the mathematics: the note was written from what a single import cone made visible rather than from the corpus (AGENTS.md §"Before declaring 'open'").

      The proof. Three steps, no new analysis:

      1. |2 sin t| = 2 sin t on [0, π/4], so the absolute value comes off.
      2. Rescaling t = 2s (intervalIntegral.integral_comp_mul_left) turns -∫₀^{π/4} log(2 sin t) dt into clausen(π/2)/2, because clausen is defined with the half-angle sin(t/2).
      3. clausen(π/2) = Cl_2(π/2) (QOU.Knot.clausen_eq_series) and Cl_2(π/2) = catalan_G (QOU.Archimedean.catalan_G_eq_Cl_2_pi_div_two).

      Downstream consumers are unaffected: the name and statement are unchanged, so WhiteheadVolumeCatalan.vol_L5a1_eq_8_lobachevsky and the Borromean volume chain now hold unconditionally rather than modulo this axiom.

      -- Ref: [lewin1981] Lewin, "Polylogarithms and Associated Functions", North-Holland (1981), eq. 4.2.21 — the classical statement. The Lean proof is via the Zagier series-integral bridge, not via Lewin.

      §4 Borromean rings volume = 8·G (Adams 1985) #

      source
      theorem QOU.Archimedean.regular_ideal_octahedron_volume :
      4 * catalan_G > 0

      Each regular ideal hyperbolic octahedron has volume 8·Λ(π/4) = 4G.

      Derivation: the regular ideal octahedron decomposes into 8 congruent ideal tetrahedra with dihedral angles (π/4, π/4, π/2); by Lobachevsky's formula each has volume Λ(π/4) + Λ(π/4) + Λ(π/2) = 2Λ(π/4) (since Λ(π/2) = 0). So octahedron volume = 8 · 2Λ(π/4) / 2 = 8·Λ(π/4) = 4G.

      (Factor 2 in the divisor accounts for double-counting of tetrahedra sharing the octahedron centre.)

      -- Ref: [adams1985hyperbolic] Adams §2, "Decomposition of the regular ideal octahedron"; [zagier1986] eq. 3.1.

      source
      theorem QOU.Archimedean.vol_B3_eq_8_catalan :
      vol_B3 = 8 * catalan_G

      Adams 1985: The Borromean rings complement 𝓑₃ admits a complete hyperbolic structure that decomposes into 2 regular ideal octahedra.

      Total volume = 2 · 4G = 8G.

      This is the categorical identity behind the production literal vol_borromean ≈ 7.32772475341775 in computations/_li_2_q_util.vol_density_borromean (where mp.catalan ≈ 0.9159655942 is used).

      The narrative reference is the open problem prop:geom-universality (paper); this leg supplies the missing Lean identity.

      Theorem (was previously an axiom; discharged 2026-06-07). vol_B3 is now defined upstream as the symbolic product 8 · catalan_G (in HyperbolicVolumeTranscendence.lean), superseding the former 15-dps SnapPy literal 7.32772475341775. With the symbolic definition, the Adams 1985 identity collapses to rfl: there is no longer a literal-vs-exact mismatch to bridge.

      The historical reason this was an axiom (a finite decimal cannot equal the exact transcendental 8 · G) no longer applies; the SnapPy decimal moved to KnotRegistry's data-catalog field while the categorical vol_B3 carries the exact value.

      -- Ref: [adams1985hyperbolic] Adams, C. C. (1985), "The noncompact hyperbolic 3-manifold of minimum volume", Proc. Amer. Math. Soc. 100, 601-606. DOI: 10.2307/2045438. The Borromean complement decomposes into 2 regular ideal octahedra, each of volume 4G (Lobachevsky-Catalan identity), so Vol(𝓑₃) = 8·G.
