    Part A of conj:dilogarithm-archimedean-limit — the Riemann-sum reduction #

    The elementary q → 1⁻ side of the Archimedean-limit conjecture: (1-q)·log Φ_n(x; q) → Li₂(x). With Φ_n = (∏_{k<n}(1 - x qᵏ))⁻¹ this is a Riemann-sum limit — (1-q)·Σ_{k<n} −log(1 - x qᵏ) → ∫₀ˣ −log(1-t)/t = Li₂(x) (the integral identity is DilogReflection.LiTwo_eq_integral, landed 2026-07-19).

    This file builds the algebraic reduction bricks that turn the ArchimedeanLimit class field into an explicit Riemann sum:

    • denomPolyLocal_eq_prod — the recursive denominator is the finite product ∏_{k<n}(1 - x qᵏ).
    • log_partialProduct_eq_neg_sum — log Φ_n(x;q) = −Σ_{k<n} log(1 - x qᵏ) for 0 < x < 1, 0 < q ≤ 1 (every factor is positive).

    The remaining Riemann-sum convergence (the uniform-partition limit in the s = k·(−log q) variable, with the (1-q)/(−log q) → 1 correction) is the genuine analytic core of Part A — scoped here, not yet discharged. Part B (substrate continuation q → 1⁺, x → 1⁻ uniformity) is untouched.

    -- Ref: [manuscript] conj:dilogarithm-archimedean-limit -- Ref: [faddeev1994] https://doi.org/10.1142/S0217732394002793

    theorem QOU.QPochhammer.log_partialProduct_eq_neg_sum {q x : ℝ} (hx0 : 0 < x) (hx1 : x < 1) (hq0 : 0 < q) (hq1 : q ≤ 1) (n : ℕ) :
    Real.log (partialProductLocal q x n) = -∑ k ∈ Finset.range n, Real.log (1 - x * q ^ k)

    Brick 1 — the Riemann-sum reduction. For 0 < x < 1 and 0 < q ≤ 1 every factor 1 - x qᵏ is positive, so the rescaled logarithm of the partial product is a finite sum: log Φ_n(x;q) = −Σ_{k<n} log(1 - x qᵏ).

    source
    theorem QOU.QPochhammer.riemann_sum_form {q x : ℝ} (hq0 : 0 < q) (n : ℕ) :
    (1 - q) * ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k) = ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k) / q ^ k * (q ^ k - q ^ (k + 1))

    Brick 2 — the Riemann-sum structure. The rescaled sum (1-q)·Σ_{k<n} −log(1 - x qᵏ) is exactly the left-endpoint Riemann sum of the integrand h(u) = −log(1 - x u)/u over the geometric partition 1 = q⁰ > q¹ > ⋯ > qⁿ, whose k-th cell has width qᵏ − qᵏ⁺¹ = qᵏ(1-q):

    (1-q)·Σ_{k<n} −log(1 - x qᵏ) = Σ_{k<n} h(qᵏ)·(qᵏ − qᵏ⁺¹).

    As q → 1⁻ (mesh → 0) with qⁿ → 0 (the partition fills (0,1]), this Riemann sum converges to ∫₀¹ −log(1 - x u)/u du = Li₂(x) — the remaining analytic core of Part A.

    theorem QOU.QPochhammer.tendsto_one_sub_div_pow_sub_one (m : ℕ) :
    Filter.Tendsto (fun (q : ℝ) => (1 - q) / (q ^ (m + 1) - 1)) (nhdsWithin 1 {1}ᶜ) (nhds (-1 / (↑m + 1)))

    m-series termwise-limit ingredient (1) — the per-term coefficient limit. (Independent of the leading Riemann-sum route in DilogPartAConvergence.lean / PR #4106; this is the parallel m-series route.) In the m-series form of (1-q)·log Φ_n (partialProduct_log_eq_mseries), the q-dependent rescaling of the m-th term is (1-q)/(q^{m+1}-1), and it tends to the Riemann weight -1/(m+1) as q → 1. Proof: for q ≠ 1, q^{m+1}-1 = (q-1)·Σ_{j≤m} qʲ (geom_sum_eq), so the ratio equals -1/Σ_{j≤m} qʲ, which is continuous at q = 1 with value -1/(m+1). Combined with qⁿ⁽ᵐ⁺¹⁾ → 0 (when n(1-q) → ∞) this gives the termwise limit x^{m+1}/(m+1)²; the dominated-convergence exchange with the m-sum is the remaining core (still open).

    theorem QOU.QPochhammer.tendsto_pow_mul_nhds_zero {q : ℝ} (hq0 : 0 < q) (hq1 : q < 1) (m : ℕ) :
    Filter.Tendsto (fun (n : ℕ) => q ^ ((m + 1) * n)) Filter.atTop (nhds 0)

    m-series termwise-limit ingredient (2) — the tail factor vanishes. For 0 < q < 1 the numerator tail q^{(m+1)n} → 0 as n → ∞ (= (q^{m+1})ⁿ with 0 < q^{m+1} < 1). This is the n → ∞ half of the q^{(m+1)n} → 0 behaviour that, jointly with n(1-q) → ∞, sends the numerator (q^{(m+1)n} − 1) → −1; combined with Brick 3 the m-th term tends to the Riemann weight x^{m+1}/(m+1)².
