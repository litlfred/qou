    Dilog Part-B W-P1 — the Faddeev-scaling positive (unconditional cusp-reaching limit) #

    The joint W-P1 capstone (tendsto_wp1_sum_of_no_resonance, #4270) proves W-P1 convergence conditionally on a Diophantine no-resonance bound c(q−1) ≤ 1−x·qⁿ, and the unconditional branch-index (n = ⌊log_q(1/x)⌋) pointwise limit is proved-false along a resonant counter-sequence (ledger docs/coordination/dilog-part-b-cusp-attack.md, 2026-07-25). This file gives the honest positive counterpart: an explicit Faddeev-type restricted scaling that reaches the branch point (x·qⁿ → 1⁻) yet satisfies the no-resonance bound by construction (c = 1), so the joint W-P1 limit holds unconditionally along it — no Diophantine hypothesis.

    The scaling #

    Back the endpoint off the cusp by exactly the cell width: take the moving interior target ρ(q) := 2 − q → 1⁻ and the bulk floor index n(q) := nOfQ x q (2−q) = ⌊log((2−q)/x)/log q⌋ (the largest n with x·qⁿ ≤ 2−q). Because x·qⁿ ≤ 2 − q, the endpoint gap obeys

    1 − x·qⁿ ≥ 1 − (2−q) = q − 1,

    i.e. the no-resonance bound with c = 1 — automatically. Simultaneously 2−q → 1⁻ drags the endpoint x·qⁿ ∈ ((2−q)/q, 2−q] up to the cusp (→ 1⁻). So this single joint q → 1⁺ limit reaches the branch point and stays no-resonant — unlike the fixed-ρ bulk route (wp1_bulk_tendsto, which needs a second ρ→1⁻ iterated limit), and unlike the bare branch index (which resonates and fails). Feeding it to tendsto_wp1_sum_of_no_resonance:

    (q − 1)·Σ_{k<n(q)} log(1 − x·qᵏ) ⟶ Li₂(x) − π²/6 as q → 1⁺, unconditionally.

    Honest scope #

    This does not contradict the proved-false unconditional branch-index limit: that failure is pointwise over all q→1⁺ at the resonant index ⌊log_q(1/x)⌋; here the index n(q) is a specific restricted (Faddeev) approach chosen to avoid resonance. The existence of one convergent cusp-reaching scaling is exactly the positive content the equidistribution / Faddeev programme targets; the measure-theoretic "a.e. approach converges" statement (three-distance / equidistribution of frac(log_q 1/x)) remains the deeper open residual (bean qou-jplv). Combined with the W-P2 tail (DilogPartBEulerTail / the assembly of PR #4423), this scaling gives the Part-B total → Li₂(x) − π²/3 unconditionally along the Faddeev approach.
