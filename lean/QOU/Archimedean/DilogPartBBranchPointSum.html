    Part B of conj:dilogarithm-archimedean-limit — the positive-factor branch-point sum (V3) #

    The W-P1 half of the Part-B cusp cancellation: for the substrate side q > 1, the positive factors k ≤ k* (k* = log_q(1/x), x qᵏ < 1) give a geometric Riemann sum running up to the branch point x u = 1, converging to Li₂(x) − π²/6.

    This file builds the target-integral bricks. The genuine analytic core — the improper limit at the branch point and the variable-term (k* = ⌊log_q(1/x)⌋) Riemann sum — is scoped in bean qou-jplv and not yet discharged here.

    • integral_Icc_eq_LiTwo_sub — V3 brick 1, the interior target integral ∫_x^c −log(1−t)/t = Li₂(c) − Li₂(x) for 0 < x ≤ c < 1, straight from the dilog derivative hasDerivAt_LiTwo + FTC (both endpoints in (0,1), so the integrand is continuous — no branch-point/t=0 singularity).

    -- Ref: [manuscript] conj:dilogarithm-archimedean-limit -- Ref: [faddeev1994] https://doi.org/10.1142/S0217732394002793

    source
    theorem QOU.Archimedean.integral_Icc_eq_LiTwo_sub {x c : ℝ} (hx0 : 0 < x) (hxc : x ≤ c) (hc1 : c < 1) :
    ∫ (t : ℝ) in x..c, -Real.log (1 - t) / t = QPochhammer.LiTwo c - QPochhammer.LiTwo x

    V3 brick 1 — the interior target integral. For 0 < x ≤ c < 1, ∫_x^c −log(1−t)/t = Li₂(c) − Li₂(x). Since −log(1−t)/t is the derivative of Li₂ (hasDerivAt_LiTwo) and both endpoints lie in (0,1), this is a proper FTC — the integrand is continuous on [x,c] (no t=0 or branch-point singularity). Taking c → 1⁻ (with LiTwo_one) will give the branch-point value π²/6 − Li₂(x) (V3 brick 2, the improper step).

    source
    theorem QOU.Archimedean.tendsto_integral_x_to_c_nhdsWithin_one {x : ℝ} (hx0 : 0 < x) (hx1 : x < 1) :
    Filter.Tendsto (fun (c : ℝ) => ∫ (t : ℝ) in x..c, -Real.log (1 - t) / t) (nhdsWithin 1 (Set.Iio 1)) (nhds (Real.pi ^ 2 / 6 - QPochhammer.LiTwo x))

    V3 brick 2 — the improper target integral (branch-point limit). For 0 < x < 1, as the upper endpoint c → 1⁻ the interior integral converges to the branch-point value:

    ∫_x^c −log(1−t)/t ⟶ π²/6 − Li₂(x).

    Combines brick 1 (= Li₂(c) − Li₂(x) on [x,1)) with the corpus Abel limit tendsto_LiTwo_nhdsWithin_lt_one (Li₂(c) → π²/6). Since ∫_x^1 −log(1−t)/t = Li₂(1) − Li₂(x) = π²/6 − Li₂(x), this is the target the positive-factor Riemann sum (W-P1) converges to — the last, singular, cell of the q > 1 geometric partition contributing the cusp regulator ζ(2).

    V3 brick 3 — the going-up (q > 1) Riemann-sum ingredients #

    The q > 1 positive-factor sum is a geometric Riemann sum on cells [qᵏ, qᵏ⁺¹] ⊆ [1, 1/x) running up to the branch point. The per-cell squeeze needs the convexity/monotonicity of the integrand h(u) = −log(1−xu)/u on the wider interval [0, b] with x·b < 1 (Part A's versions are the special case b = 1). These generalise the Part-A bricks with 1 ≤ · ⇒ x·b < 1.

    source
    theorem QOU.Archimedean.convexOn_neg_log_one_sub_mul_Icc {x b : ℝ} (hx0 : 0 < x) (hb : x * b < 1) :
    ConvexOn ℝ (Set.Icc 0 b) fun (u : ℝ) => -Real.log (1 - x * u)

    Convexity of g(u) = −log(1 − x u) on [0, b] whenever x·b < 1 — the going-up generalisation of convexOn_neg_log_one_sub_mul (which is b = 1). log is concave on (0,∞), u ↦ 1 − x u is affine mapping [0,b] into (0,∞) (since x u ≤ x b < 1), negation flips concave to convex.

    source
    theorem QOU.Archimedean.h_monotoneOn_Ioc {x b : ℝ} (hx0 : 0 < x) (hb0 : 0 ≤ b) (hb : x * b < 1) :
    MonotoneOn (fun (u : ℝ) => -Real.log (1 - x * u) / u) (Set.Ioc 0 b)

    Monotonicity of h(u) = −log(1 − x u)/u on (0, b] whenever x·b < 1 — the going-up generalisation of h_monotoneOn (which is b = 1). Convex-slope: h(u) = (g u − g 0)/(u − 0) is a secant slope from 0 of the convex g, hence monotone (ConvexOn.secant_mono).

With h monotone increasing (h_monotoneOn_Ioc), the per-cell integral is squeezed between the left/right endpoint values.

    V3 brick 3c — the going-up telescoping Riemann-sum error bound #

    The genuine core: the left-Riemann sum Σ_{k<n} h(qᵏ)·(qᵏ⁺¹−qᵏ) over the going-up geometric cells [qᵏ, qᵏ⁺¹] ⊆ [1, 1/x) under-estimates ∫_1^{qⁿ} h by at most qⁿ·(q−1)·(h(qⁿ) − h(1)). Unlike Part A (q<1, shrinking widths, bounded integrand), here q>1 so the widths grow (qᵏ(q−1)); the telescoping still closes because the residual qᵐ(q−1)²(h(qᵐ⁺¹) − h(1)) ≥ 0. The hypothesis x·qⁿ < 1 keeps every cell strictly below the branch point (the last cell's blow-up as qⁿ → 1/x is handled separately in the assembly).

    source
    theorem QOU.Archimedean.riemann_error_bound_up {x q : ℝ} (hx0 : 0 < x) (hq1 : 1 < q) (n : ℕ) :
    x * q ^ n < 1 → 0 ≤ (∫ (u : ℝ) in 1..q ^ n, -Real.log (1 - x * u) / u) - ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k) / q ^ k * (q ^ (k + 1) - q ^ k) ∧ (∫ (u : ℝ) in 1..q ^ n, -Real.log (1 - x * u) / u) - ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k) / q ^ k * (q ^ (k + 1) - q ^ k) ≤ q ^ n * (q - 1) * (-Real.log (1 - x * q ^ n) / q ^ n - -Real.log (1 - x * 1) / 1)

    V3 brick 3c — going-up Riemann-sum error bound. For 1 < q and x·qⁿ < 1 (all cells below the branch point): 0 ≤ ∫_1^{qⁿ} h − Σ_{k<n} h(qᵏ)·(qᵏ⁺¹−qᵏ) ≤ qⁿ·(q−1)·(h(qⁿ)−h(1)), with h(u) = −log(1−xu)/u. Telescoping induction on the per-cell squeeze (brick 3b), the going-up analogue of Part A's riemann_error_bound.

    source
    theorem QOU.Archimedean.partialSum_up_eq {x q : ℝ} (hq0 : 0 < q) (n : ℕ) :
    ∑ k ∈ Finset.range n, -Real.log (1 - x * q ^ k) / q ^ k * (q ^ (k + 1) - q ^ k) = (1 - q) * ∑ k ∈ Finset.range n, Real.log (1 - x * q ^ k)

    V3 brick 3d — the Riemann sum IS the rescaled log-sum. Term-by-term, (−log(1−xqᵏ)/qᵏ)·(qᵏ⁺¹−qᵏ) = (1−q)·log(1−xqᵏ), since (qᵏ⁺¹−qᵏ)/qᵏ = q−1. So the going-up Riemann sum equals (1−q)·Σ_{k<n} log(1−xqᵏ), i.e. − the positive-factor W-P1 quantity −(1−q)·Σ log(1−xqᵏ). This connects riemann_error_bound_up to the log-product without needing the geometric riemann_sum_form.

    theorem QOU.Archimedean.integral_one_to_c_eq_LiTwo_sub {x c : ℝ} (hx0 : 0 < x) (hc1 : 1 ≤ c) (hxc : x * c < 1) :
    ∫ (u : ℝ) in 1..c, -Real.log (1 - x * u) / u = QPochhammer.LiTwo (x * c) - QPochhammer.LiTwo x

    V3 brick 3e — the going-up integral evaluates to a Li₂ difference. For 0 < x, 1 ≤ c, x·c < 1: ∫_1^c −log(1−xu)/u du = Li₂(xc) − Li₂(x), via the change of variables t = x u (smul_integral_comp_mul_left) plus brick 1 (integral_Icc_eq_LiTwo_sub). This turns the Riemann-sum target ∫_1^{qⁿ} h of riemann_error_bound_up into Li₂(xqⁿ) − Li₂(x), whose limit as xqⁿ → 1⁻ is π²/6 − Li₂(x) (brick 2's Abel limit).

    theorem QOU.Archimedean.error_up_eq {x q : ℝ} (n : ℕ) (hqn : q ^ n ≠ 0) :
    q ^ n * (q - 1) * (-Real.log (1 - x * q ^ n) / q ^ n - -Real.log (1 - x * 1) / 1) = (q - 1) * -Real.log (1 - x * q ^ n) - (q - 1) * q ^ n * -Real.log (1 - x * 1)

    V3 brick 3f — the error decomposition. The riemann_error_bound_up majorant factors exactly as a boundary log-term minus a manifestly-vanishing term: qⁿ(q−1)(h(qⁿ)−h(1)) = (q−1)·(−log(1−xqⁿ)) − (q−1)·qⁿ·(−log(1−x)), using qⁿ·h(qⁿ) = −log(1−xqⁿ). The second term → 0 (since qⁿ ≤ 1/x is bounded and q−1 → 0), so the whole W-P1 error reduces to the single boundary limit (q−1)·log(1−xqⁿ) → 0.

    theorem QOU.Archimedean.wp1_riemann_bound {x q : ℝ} (hx0 : 0 < x) (hq1 : 1 < q) (n : ℕ) (hqn : x * q ^ n < 1) :
    0 ≤ QPochhammer.LiTwo (x * q ^ n) - QPochhammer.LiTwo x - (1 - q) * ∑ k ∈ Finset.range n, Real.log (1 - x * q ^ k) ∧ QPochhammer.LiTwo (x * q ^ n) - QPochhammer.LiTwo x - (1 - q) * ∑ k ∈ Finset.range n, Real.log (1 - x * q ^ k) ≤ (q - 1) * -Real.log (1 - x * q ^ n) - (q - 1) * q ^ n * -Real.log (1 - x * 1)

    V3 assembly — the W-P1 Riemann bound. For 1 < q and x·qⁿ < 1, the positive-factor rescaled log-sum (1−q)·Σ_{k<n} log(1−xqᵏ) approximates the dilog difference Li₂(xqⁿ) − Li₂(x) from below, with error bounded by the explicit boundary decomposition:

    0 ≤ (Li₂(xqⁿ) − Li₂(x)) − (1−q)Σ log(1−xqᵏ) ≤ (q−1)·(−log(1−xqⁿ)) − (q−1)·qⁿ·(−log(1−x)).

    Assembles the telescoping bound (riemann_error_bound_up), the change of variables (integral_one_to_c_eq_LiTwo_sub), the log-sum identity (partialSum_up_eq) and the error decomposition (error_up_eq). As q → 1⁺ with xqⁿ → 1⁻, Li₂(xqⁿ) → π²/6 (brick 2's Abel limit), so W-P1 converges to Li₂(x) − π²/6 iff the boundary term (q−1)·log(1−xqⁿ) → 0 — the single remaining scalar limit (controlled by the Faddeev scaling).
