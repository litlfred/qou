    The Euclidean unit normal — coordinate facts #

    verticalPlaneNormal n = ![n.1, n.2, 0] (from GeodesicFaceH3), viewed as an element of E. Three elementary facts drive everything below.

    The general vertical-plane reflection vReflect n d #

    Reflection across the affine plane {p | ⟪ñ, p⟫ = d} where ñ = verticalPlaneNormal n: the Householder map p ↦ p − 2(⟪ñ,p⟫ − d)·ñ. A genuine Euclidean isometry that fixes the height coordinate (because ñ_z = 0), so it is the lam ≡ 1 case of the conformal-height-scaling engine.
