    Pinning a branch integer by the base point #

    Bean qou-trns. The 5₂ transport needs to know that a sum of logarithms equals a logarithm of a product on the nose, not up to 2πi ℤ. This file proves the principle that forces the integer to be 0, with no dilogarithm and no curve in it.

    The statement the transport wants #

    exp_eq_zero_of_continuousOn_of_exp_eq_one: if F : ℝ → ℂ is continuous on [a,b], satisfies exp (F y) = 1 throughout, and vanishes at a, then F ≡ 0.

    The transport instantiates it at F φ := Σⱼ log (1 − e^{iφ} · yⱼ) − iφ on [0, π]:

    • exp (F φ) = 1 is exactly the Vieta product ∏ⱼ (1 − x·yⱼ) = x, which is already sorry-free in QOU/QBeta/FiveTwoCyclotomicBloch.lean (prod_one_sub_x_mul; the companion prod_x_sub gives the other factor).
    • F 0 = 0 is the base point x = 1, where every factor is 1 − yⱼ and the product is 1.
    • Continuity is the one genuine analytic hypothesis. See the scoping note below — it is not the hypothesis the refuted argument used, and it is not the naive "no factor meets the cut" either. See "the arc ends on the cut".

    Why this had to be proved rather than waved at #

    The earlier argument for k = 0 ran: the branch integer is integer-valued and locally constant on a collision-free arc, hence constant; and it is 0 at the base point. Two separate steps, and the first one was false as stated — the arc is not collision-free. QOU/QBeta/FiveTwoDiscriminant.lean proves the discriminant of the GGM curve vanishes at a point of |x| = 1.

    The repair is that collisions are harmless here: at the collision the two colliding roots are equal, so the two log-terms being permuted are identical and their sum cannot notice the relabelling. What the sum really needs is that no factor 1 − x·yⱼ crosses the branch cut of log — a different hypothesis, and the honest one. This file takes that hypothesis in its weakest usable form, plain continuity of F, and gets k = 0 in a single step: connectedness plus the base point, with no appeal to local constancy.

    So the division of labour is now explicit:

    ingredient status
    exp (F φ) = 1 Lean-proved (Vieta, #4658)
    F 0 = 0 Lean-proved (same Vieta identity at x = 1)
    F continuous on the arc open — see below
    continuity + the two above ⟹ F ≡ 0 this file

    The arc ends on the cut — and that is why this lane keeps seeing 2π #

    Route 20 (computations/probes/qbeta_5two_route20_cut_avoidance_probe.py, 7 gates) measured the open hypothesis rather than the conclusion, and the first version of it failed. The obvious sufficient condition — no factor ever meets (−∞, 0] — is false: at the endpoint x = −1,

    1 − x·y₁ = 1 − w₁ = −1.2469796…

    sits exactly on the cut, where w₁ is the largest root of w³ − 2w² − w + 1 — the level-7 ladder's own cubic. And x = −1 is on the cut too. The transport arc ends on the branch cut in two independent ways; it is structural, not bad luck.

    Continuity survives because it forbids crossing, not touching. The contact is transversal — the margin is exactly w₁·(π − φ), measured over four orders of magnitude — and one-sided: rising to φ = π the factor arrives from above, so arg → +π, which is precisely where the principal branch is defined on the cut. Left-limit meets value; F is continuous on [0, π]; hcont holds.

    Traverse the same arc downward and the factor arrives from below, arg → −π, while principal Log on the cut still returns +π — a genuine 2πi jump. So the transport's orientation is load-bearing, and only because of where the principal branch is declared to sit. qou-trns records three separate spurious 2πs and calls them the most reliable false alarm in this work. This is their mechanism.

    Away from the endpoint the margin is comfortable: an interior minimum of 0.337 at φ/π = 0.542, and 0.775 at the collision — the branch point is invisible to it, which is exactly why the symmetric repair survives a collision that killed the per-root argument.

    hcont is measured, not proved. Proving it means showing from the curve that no factor meets (−∞, 0] for φ ∈ [0, π), plus the one-sided limit at the endpoint. That is not written, and until it is, this lemma's hypothesis is an assumption.

    Proof #

    Complex.exp_eq_one_iff puts every value of F in 2πi ℤ, so F has zero real part and its imaginary part lands in the discrete set 2π·ℤ. A continuous real function into c·ℤ is constant: if it took two distinct values c·m < c·n, the intermediate value theorem would realise c·m + c/2, which is not a multiple of c because 2(k − m) = 1 has no integer solution.

    That is the whole argument. Nothing here is deep; the point is that it is stated against the hypothesis the mathematics actually supplies.

    The 5₂ sum rule is PROVED: QOU.QBeta.FiveTwoComplexPentagon.fiveTwo_saddle_sum_rule and fiveTwoSaddleSumRule_holds, sorry-free, standard axioms.

    theorem QOU.Archimedean.eq_zero_of_continuousOn_of_exp_eq_one {F : ℝ → ℂ} {a b x : ℝ} (hx : x ∈ Set.Icc a b) (hcont : ContinuousOn F (Set.Icc a b)) (hexp : ∀ y ∈ Set.Icc a b, Complex.exp (F y) = 1) (h0 : F a = 0) :
    F x = 0

    The branch integer is pinned by the base point.

    If F is continuous on [a,b] with exp (F y) = 1 throughout and F a = 0, then F vanishes identically.

    This is the 5₂ transport's k = 0 step. exp (F y) = 1 is what Vieta supplies; F a = 0 is the base point x = 1; continuity is the open hypothesis, and it is the non-crossing condition, not the non-touching one — the arc's endpoint sits on the cut (see the header). No local-constancy argument appears, and no non-collision hypothesis is needed: the arc does carry a collision (FiveTwoDiscriminant.exists_unit_circle_disc_zero) and it is irrelevant to a symmetric sum.
