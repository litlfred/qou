    Transfer Matrices over ℤ[q, q⁻¹] #

    The 2×2 transfer matrices for the three nuclear vertex types (proton–proton, neutron–neutron, proton–neutron), the inductive chain construction, and the traced volume (Skein polynomial factor).

    Note to reader: all definitions and proofs over ℤ[q, q⁻¹]. Transfer matrices live in M₂(ℤ[q, q⁻¹]) (not over ℝ).

    References #

    • [beta-decay-transfer-matrix] Prop: beta decay as universal matrix polynomial.
    • [shell-closure-normal-form] Prop: palindromic Poincaré distribution.

    §1 Ground ring ℤ[t, t⁻¹] (where t² = q) #

    The skein weights for nn and pn vertices involve q^{1/2}. The transfer matrices therefore live in M₂(ℤ[q^{1/2}, q^{-1/2}]), which is a degree-2 extension of ℤ[q, q⁻¹].

    For formal proofs, we can either:

    1. Work in ℤ[t, t⁻¹] where t = q^{1/2} and q = t²
    2. Work with 2 · 𝔴⁺ and 2 · 𝔴⁰ to clear denominators

    We adopt option (1): set t = q^{1/2} and define everything in ℤ[t, t⁻¹].

                                    source
                                    def QOU.Archimedean.transferMatrixOf {R : Type u_1} [CommRing R] (h c d : R) :
                                    Matrix (Fin 2) (Fin 2) R

                                    The transfer matrix T(𝔴⁺, 𝔴⁰) at a single crossing, over any commutative ring, given the Hecke amplitude h as data.

                                    T(h; c, d) = ⎡ c·h + d, c ⎤ ⎣ c, d ⎦

                                    The amplitude is the parameter, not q (bean qou-u87j). The obvious generalisation — take q and form q - q⁻¹ inside — does not typecheck over a CommRing: the symbolic ground ring here is R_t = LaurentPolynomial ℤ, which has no Inv, which is precisely why this file carries t_inv as a separate element rather than writing t⁻¹. Passing h covers both users: HA_t over ℤ[t,t⁻¹] below, and q - q⁻¹ over ℝ in QOU.Archimedean.BetaDecayTransfer.

                                    Equations
                                    • QOU.Archimedean.transferMatrixOf h c d = !![c * h + d, c; c, d]
