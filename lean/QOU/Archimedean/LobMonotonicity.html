    theorem QOU.Archimedean.LobMonotonicity.Lob_sub_Lob_add_pos {a c : ℝ} (ha : Real.pi / 6 < a) (hc : 0 < c) (hac : a + c < 5 * Real.pi / 6) :

    The form the chord argument consumes: folding an obtuse angle with Lob_pi_sub turns the sum into a difference, and this makes it positive.

    Nonnegativity of the ideal-tetrahedron Λ-sum #

    Λ(α) + Λ(β) + Λ(γ) ≥ 0 whenever α, β, γ > 0 sum to π — i.e. an ideal tetrahedron's volume is never negative.

    The corpus did not have this. It has volChart_regular_pos (one point) and the maximum theorems; nothing bounded the functional below. qou-52ch's chord bound needs it at the far point of the segment.

    The proof is elementary rather than going through extreme points of the closed simplex: at most one angle can exceed π/2, and if one does, fold it with Lob_pi_sub and use that Λ is concave on [0, π/2] with Λ 0 = 0, hence subadditive there.
