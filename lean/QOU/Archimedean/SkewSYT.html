    Skew Standard Young Tableaux and the Young Lattice #

    Formalises the branching rule for H_k(q) → H_3(q) via skew standard Young tableaux (SYT).

    Main definitions #

    • Partition — a weakly decreasing list of positive naturals
    • YoungDiag — the set of cells (i, j) of a partition
    • contains — the containment partial order lam ⊇ μ
    • SkewDiag — the skew diagram lam/μ
    • IsSkewSYT — predicate: a filling is a valid skew SYT
    • skewSYTCount — the number of skew SYT of shape lam/μ
    • branchingMult — the branching multiplicity m_μ^lam = #SYT(lam/μ)

    Key theorems #

    • classical_dim_identity — Σ_μ m_μ^lam × dim(μ) = dim(lam) at q = 1
    • branching_nonneg — m_μ^lam ≥ 0 (it's a cardinality)

    References #

    • [sagan2001] B. Sagan, The Symmetric Group, 2nd ed.
    • [fulton1997] W. Fulton, Young Tableaux.

                                      def QOU.Archimedean.SkewSYT.Partition.removeCorner (lam : Partition) (row : ℕ) :
                                      Partition

                                      Remove a corner cell from a partition. Decrements the part at the given row by 1, then re-sorts the list to preserve the weakly-decreasing invariant.

                                      Sorting after decrement is benign: when row is a corner, the result is already sorted (the sort is the identity); when row is not a corner, sorting moves the decremented entry to the right place. The size (sum of parts) is invariant under permutation, so size-decrease lemmas continue to hold without a corner hypothesis.

                                      Equations
                                      • lam.removeCorner row = { parts := List.insertionSort (fun (x1 x2 : ℕ) => x1 ≥ x2) (List.mapIdx (fun (i p : ℕ) => if i = row then p - 1 else p) lam.parts), sorted := ⋯ }

                                        Partition → Partition → ℕ

                                        The number of skew SYT of shape lam/μ. Denoted f^{lam/μ} in the literature.
