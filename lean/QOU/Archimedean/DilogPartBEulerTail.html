    Part B of conj:dilogarithm-archimedean-limit — the Euler-tail coefficient limit (V1) #

    The regularized negative-factor piece of Part B (W-P2) reduces, after the substitution p = 1/q (q→1⁺ ⟺ p→1⁻) and m = k − k*, to the Euler-function / Dedekind-eta asymptotic

    (1−p)·log ∏_{m≥1}(1−pᵐ) → −π²/6 as p → 1⁻.

    Via the Lambert series log ∏(1−pᵐ) = −Σ_{j≥1}(1/j)·pʲ/(1−pʲ) this is a Tannery/dominated-convergence limit whose termwise input is the coefficient limit proved here:

    (1−p)·pʲ/(1−pʲ) → 1/j as p → 1⁻,

    after which Σ_{j≥1} 1/j² = ζ(2) = π²/6 (hasSum_zeta_two) supplies the constant. This is the cheap, load-bearing first brick (V1) of the Part-B cusp-cancellation attack (docs/coordination/dilog-part-b-cusp-attack.md); the Tannery exchange itself is V2.

    The proof is elementary: 1 − pʲ = (1−p)·Σ_{i<j} pⁱ (geom_sum_mul), so the (1−p) cancels and the ratio is pʲ / Σ_{i<j} pⁱ, continuous at p=1 with value 1/j.

    theorem QOU.QPochhammer.euler_tail_coeff_limit (j : ℕ) (hj : 1 ≤ j) :
    Filter.Tendsto (fun (p : ℝ) => (1 - p) * p ^ j / (1 - p ^ j)) (nhdsWithin 1 (Set.Iio 1)) (nhds (1 / ↑j))

    V1 — Euler-tail termwise coefficient limit. As p → 1⁻, the j-th Lambert coefficient (1−p)·pʲ/(1−pʲ) tends to 1/j. Since 1 − pʲ = (1−p)·Σ_{i<j} pⁱ, the (1−p) cancels, leaving pʲ/Σ_{i<j}pⁱ, whose limit at p=1 is 1/j (numerator → 1, denominator → j). This is the termwise input to the Tannery/DCT giving the negative-factor Euler tail (1−p)·log ∏(1−pᵐ) → −π²/6 (Part B, W-P2).

    theorem QOU.QPochhammer.euler_tail_coeff_le {j : ℕ} (hj : 1 ≤ j) {p : ℝ} (hp0 : 0 < p) (hp1 : p < 1) :
    (1 - p) * p ^ j / (1 - p ^ j) ≤ 1 / ↑j

    V1 — Euler-tail coefficient uniform bound. For 0 < p < 1 and j ≥ 1, (1−p)·pʲ/(1−pʲ) ≤ 1/j. Together with euler_tail_coeff_limit (the termwise limit → 1/j) this is the second Tannery/dominated-convergence input for W-P2: the coefficient times 1/j is dominated by the summable 1/j². Proof: (1−p)pʲ/(1−pʲ) = pʲ/Σ_{i<j}pⁱ, and each of the j summands pⁱ (i<j) is ≥ pʲ, so Σ_{i<j}pⁱ ≥ j·pʲ.

    theorem QOU.QPochhammer.euler_tail_jseries_tendsto :
    Filter.Tendsto (fun (p : ℝ) => ∑' (j : ℕ), 1 / ↑j * ((1 - p) * p ^ j / (1 - p ^ j))) (nhdsWithin 1 (Set.Iio 1)) (nhds (Real.pi ^ 2 / 6))

    V2 (heart) — the Lambert j-series limit. The negative-factor Euler tail in its Lambert form converges to ζ(2) = π²/6 as p → 1⁻:

    Σ_{j} (1/j)·(1−p)·pʲ/(1−pʲ) → Σ_{j} 1/j² = π²/6.

    This is Tannery's theorem (tendsto_tsum_of_dominated_convergence) applied to the two V1 inputs: termwise (1/j)·(1−p)pʲ/(1−pʲ) → 1/j² (euler_tail_coeff_limit), uniformly dominated by the summable 1/j² (euler_tail_coeff_le + euler_tail_coeff_nonneg), with Σ 1/j² = π²/6 (hasSum_zeta_two). The Lambert rearrangement −log ∏(1−pᵐ) = Σⱼ (1/j)·pʲ/(1−pʲ) (which turns this into the eta asymptotic (1−p)·log ∏(1−pᵐ) → −π²/6) is the remaining W-P2 step.

    theorem QOU.QPochhammer.euler_tail_lambert_rearrange {p : ℝ} (hp0 : 0 < p) (hp1 : p < 1) :
    ∑' (m : ℕ), -Real.log (1 - p ^ (m + 1)) = ∑' (j : ℕ), 1 / (↑j + 1) * (p ^ (j + 1) / (1 - p ^ (j + 1)))

    V2a — the Lambert rearrangement. For 0 < p < 1, the negative-factor Euler tail (in tsum-of-logs form) equals its Lambert j-series:

    Σ'_m −log(1−p^{m+1}) = Σ'_j (1/(j+1))·p^{j+1}/(1−p^{j+1}).

    A nonneg Fubini (Summable.tsum_comm) on a m j = p^{(m+1)(j+1)}/(j+1): the row sum is −log(1−p^{m+1}) (neg_log_one_sub_hasSum), the column sum is the geometric (1/(j+1))·p^{j+1}/(1−p^{j+1}). Combined with euler_tail_jseries_tendsto this yields the eta asymptotic (1−p)·Σ'_m −log(1−p^{m+1}) → π²/6.

    theorem QOU.QPochhammer.euler_tail_asymptotic :
    Filter.Tendsto (fun (p : ℝ) => (1 - p) * ∑' (m : ℕ), -Real.log (1 - p ^ (m + 1))) (nhdsWithin 1 (Set.Iio 1)) (nhds (Real.pi ^ 2 / 6))

    V2 (capstone) — the Euler-function / Dedekind-eta asymptotic (W-P2). The negative-factor Euler tail, rescaled by (1−p), converges to ζ(2) = π²/6:

    (1−p)·Σ'_m −log(1−p^{m+1}) → π²/6 as p → 1⁻,

    equivalently (1−p)·log ∏_{m≥1}(1−pᵐ) → −π²/6 (the classical Hardy–Ramanujan eta asymptotic). Assembles V2a (euler_tail_lambert_rearrange) with V2b (euler_tail_jseries_tendsto): the (1−p)-scaled Lambert j-series is the V2b summand reindexed by the vanishing j=0 term. With p = 1/q (q→1⁺ ⟺ p→1⁻) this is exactly the regularized negative-factor piece of Part B (W-P2 → −π²/6), one of the two halves of Li₂(x) − π²/3.
