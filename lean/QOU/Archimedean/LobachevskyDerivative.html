    theorem QOU.Archimedean.hasDerivAt_Lob {t : ℝ} (h0 : 0 < t) (hπ : t < Real.pi) :
    HasDerivAt Lob (-Real.log (2 * Real.sin t)) t

    Λ'(t) = −log(2 sin t) on (0, π).

    The chain rule through Λ(t) = Cl₂(2t)/2: the inner derivative 2 cancels the outer 1/2, and Cl₂'(2t) = −log(2 sin(2t/2)) = −log(2 sin t).

    This is the statement that Λ is the primitive Λ(x) = −∫₀ˣ log|2 sin t| dt in the standard normalisation — the form in which the Lobachevsky function is usually defined, recovered here from the Cl₂ series rather than assumed.

    theorem QOU.Archimedean.hasDerivAt_deriv_Lob {t : ℝ} (h0 : 0 < t) (hπ : t < Real.pi) :
    HasDerivAt (deriv Lob) (-(Real.cos t / Real.sin t)) t

    Λ''(t) = −cot t on (0, π).

    This is the identity IdealTetrahedronConcavity states in prose and uses to write the ideal-tetrahedron Hessian

    f_αα = −(cot α + cot γ),  f_αβ = −cot γ,  f_ββ = −(cot β + cot γ)

    for f(α,β) = Λ(α) + Λ(β) + Λ(π−α−β). Proving it here is what makes that Hessian the Hessian of the Lobachevsky volume sum, rather than of an unnamed function with the right second derivatives.

    Stated via EqOn on the open interval so that deriv (deriv Lob) may be rewritten along it: deriv Λ agrees with −log(2 sin ·) throughout (0, π), and differentiating that gives −cot.

    theorem QOU.Archimedean.deriv_deriv_Lob_neg {t : ℝ} (h0 : 0 < t) (hπ : t < Real.pi / 2) :
    deriv (deriv Lob) t < 0

    Λ is strictly concave-ish pointwise: Λ'' < 0 on (0, π/2).

    −cot t < 0 exactly when cos t > 0, i.e. on (0, π/2). Recorded because it is the sign that drives the diagonal entries f_αα = −(cot α + cot γ) < 0; note Λ'' is positive on (π/2, π), so Λ alone is NOT concave on (0, π) — concavity of the tetrahedron volume comes from the SUM, via cot_add_cot_pos, not from Λ termwise. Stating this guards against the plausible-but-false reading that Λ is concave.
