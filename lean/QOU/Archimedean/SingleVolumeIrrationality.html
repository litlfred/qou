    §3b-cond class axiomatisation for content block conj:single-volume-irrationality: Irrationality of a single hyperbolic knot volume.

    This is a conjecture, and the honest open state is a content-bearing class with no instance (AGENTS.md §3b-tax). SingleVolumeIrrationality carries three real volume fields (vol41, vol52, volBorromean) and one Irrational field for each — the conjecture's content, not a placeholder.

    No instance is provided anywhere in this file. An instance is the conjecture; fabricating one would be the audit-dodge §1a forbids. A downstream result takes [SingleVolumeIrrationality] as an explicit [Instance] hypothesis and is thereby conditional on it — rigorous modulo this single named input, per §3b-cond. It is not unconditional, and calling it so would be the "conditional-proved ≠ premise-established" confusion AGENTS.md warns about.
