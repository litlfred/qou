    Ground Ring: ℤ[q, q⁻¹] #

    All formal proofs in the Descartes universe are conducted over the Laurent polynomial ring ℤ[q, q⁻¹]. This is an integral domain with no zero divisors. Results do NOT require ℝ.

    Note to reader: all Lean proofs in this module work exclusively over ℤ[q, q⁻¹]. Numerical evaluations at the substrate parameter q₀ ≈ 1.1098 appear only in Chapter 7 (Physical Observations) and are NOT part of the formal chain.

    References #

    • [lusztig1993] G. Lusztig, Introduction to quantum groups, 1993.

          §2 Quantum integers #

          source
          noncomputable def QOU.Archimedean.qInt (n : ℤ) :
          R_q

          The quantum integer [n]_q = (qⁿ − q⁻ⁿ) / (q − q⁻¹) as an element of ℤ[q, q⁻¹]. For n ≥ 0, this is a polynomial in q and q⁻¹ (the denominator divides the numerator).

            theorem QOU.Archimedean.qInt_eq_geo_twist (n : ℤ) (hn : 0 < n) :
            qInt n = LaurentPolynomial.T (-(n - 1)) * QInteger.qIntGeo (LaurentPolynomial.T 2) n.toNat

            Bridge to the canonical bracket — the twist, made division-free.

            This is the one q-integer in the corpus that genuinely cannot be an instance of qIntBal: R_q = ℤ[q, q⁻¹] is not a field, so the balanced quotient (qⁿ − q⁻ⁿ)/(q − q⁻¹) is not even expressible here. That is why the definition above spells out the symmetric weight string qⁿ⁻¹ + qⁿ⁻³ + ⋯ + q⁻⁽ⁿ⁻¹⁾ as an explicit sum of monomials instead.

            What it is not is a different convention. qIntBal_eq_twist_canonical says [n]_q = q⁻⁽ⁿ⁻¹⁾ · qIntGeo(q²) n over a field; qIntGeo needs only a CommRing, so the right-hand side survives the drop to ℤ[q, q⁻¹] even though the left-hand side does not. This theorem is that surviving half — the same twist, stated where no division is available.

            Proved for 0 < n; the negative branch is - of this by construction (qInt is defined by odd extension), matching qIntBalZ_neg over a field.

                noncomputable def QOU.Archimedean.two_E_cross :

                The crossing energy E_cross = ½(q − q⁻¹).

                Note: the factor ½ takes us outside ℤ[q, q⁻¹] into ℤ[½][q, q⁻¹]. For formal proofs we work with 2 · E_cross = HA to stay in the ground ring. The ½ is a presentation convenience.

                  LaurentPolynomial ℤ

                  Build a Laurent polynomial from a list of (exponent, coefficient) pairs: Σᵢ cᵢ · T^{kᵢ}. Folding over a flat List (ℤ × ℤ) lets Lean elaborate the •/+ operations once (in the fold body) instead of building a deep HAdd/HSMul expression tree per definition — the latter does not finish elaborating within practical time/heartbeat budgets for these hecke-engine witness polynomials.

                  Shared helper for the QOU.Archimedean.PauliWitness modules; centralised here from the previously per-file private copies.
