    QOU.Archimedean.tau_leptonic_universality — tau leptonic universality #

    Proposition (prop:tau-leptonic-universality).

    Let T_{3,5} = (σ₀ σ₁)⁵ be the weak vertex in H₃(q), and let f(x) = 1 − 8x + 8x³ − x⁴ − 12 x² ln x be the phase-space factor for τ → ℓ ν̄_ℓ ν_τ with x = (m_ℓ / m_τ)². In the factorised model, the Markov trace of the weak vertex is the universal matrix element

    |M_e|² = |M_μ|² = |tr_Markov(T_{3,5})|²

    so the branching-ratio ratio reduces to the pure phase-space ratio:

    BR(τ → e) / BR(τ → μ) = f(m_e²/m_τ²) / f(m_μ²/m_τ²).

    The Lean encoding defines the phase-space factor phaseSpace as an explicit real-valued function of x ∈ (0, 1) and records the universality claim as an equality of branching-ratio quotients.

      Strictly speaking phaseSpace evaluates to 1 - 0 - 0 - 0 - 12·0·log 0 at x = 0; the 12 x² · log x term has limit 0 as x → 0⁺, and Real.log 0 = 0 by Mathlib convention, so the formula evaluates to 1 at x = 0.

      theorem QOU.Archimedean.phaseSpace_at_one :
      phaseSpace 1 = 0

      Boundary value: f(1) = 0 (degenerate daughter mass).

      f(1) = 1 − 8 + 8 − 1 − 12·1·log 1 = 0 − 12·0 = 0.

      class QOU.Archimedean.TauLeptonicContext :
      Type

      Abstract context for the tau-leptonic-universality claim.

      The factorisation hypotheses BR_ℓ_factored encode the physical content of the manuscript: each leptonic branching fraction factors as a universal squared matrix element times the daughter-dependent phase-space factor,

      BR(τ → ℓ) = |𝓜|² · f((m_ℓ / m_τ)²),

      with the same weakVertexTraceSq = |tr_Markov(T_{3,5})|² for both channels — this shared value is exactly the universality |𝓜_e|² = |𝓜_μ|² = |tr_Markov((σ₀σ₁)⁵)|². The Markov trace of the weak vertex is a property of the vertex alone (a class function on H_3(q); cf. QOU.MathlibExt.MarkovTrace.character_append_comm — the trace is invariant under the braid word's cyclic structure), so it does not depend on the daughter lepton. Its archimedean (real) evaluation at the substrate q₀ is the scalar weakVertexTraceSq.

      • weakVertexTraceSq_ne_zero : weakVertexTraceSq ≠ 0

        The universal matrix element is non-zero (the weak vertex is a non-trivial mediator), so it cancels in the branching ratio.

        Factorisation for τ → μ — same weakVertexTraceSq (universality).
