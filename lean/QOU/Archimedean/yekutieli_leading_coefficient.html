    QOU.Archimedean.yekutieli_leading_coefficient — κ(T_{2,p}) = c_{(p−1)/2} = 1 ≠ 0 #

    Lemma (lem:yekutieli-leading-coefficient).

    For T_{2,p} at level n = g + 1 = 5, the Yekutieli obstruction κ(T_{2,p}) ∈ H²(𝓢, 𝓑) equals the leading Chebyshev coefficient c_{(p−1)/2} = 1. In particular κ(T_{2,p}) ≠ 0 for q ≠ 1.

    What is proved here, and what is assumed #

    The bare opaque κ + sorry of the earlier revision is replaced by the accepted sibling patterns in this repo, so that the main lemma is sorry-free and progressively fewer inputs are axiomatised:

    1. def-not-field (cf. dq-squared.lean). The raw curvature value is a def of the geometric data — the d_q² formula κ_raw = q⁻¹(1 − q⁻¹) · w · ν (w the T-weight of the top Seifert cycle γ₅, i.e. 5; ν = ω_V ∧_q ω_T; prop:categorical-dq-squared). Its non-vanishing for q ≠ 1, yekutieliObstructionData_kappaRaw_ne_zero, is sorry-free.

    2. Leading Chebyshev coefficient = 1 — now PROVED, not assumed. The genus-filtration basis is the monic Chebyshev recurrence monicCheb (p₀ = 1, p₁ = X, p_{n+2} = X·p_{n+1} − p_n), which is monic of degree n by induction (monicCheb_monic); hence its leading coefficient is 1 (leadingChebyshev_eq_one). This discharges what was previously the axiomatised chebyshev_top_eq_one class field.

    3. §3b-cond conditional class (cf. q_bkm_criterion.lean). The remaining genuinely-deep, not-in-Mathlib input is stated as a concrete polynomial identity: Yekutieli's non-abelian Stokes theorem on surfaces ([yekutieli2015]) says the obstruction's genus generating polynomial is the raw d_q² curvature times the monic genus-filtration basis (YekutieliStokesNormalisation.stokes_expansion), with the geometric data unit-normalised (raw_normalised, κ_raw = 1). The scalar obstruction = κ_raw is then proved (obstructionCoord_eq_kappaRaw) from stokes_expansion via the leading-coefficient extraction leadingCoeff_C_mul_monicCheb — it is no longer an axiom. The main lemma derives κ = c ∧ κ = 1 from these plus the proved leadingChebyshev_eq_one; it does not assume the identity.

    This is a rigorous conditional result: verified by Lean modulo the named class instance standing in for the non-abelian Stokes machinery (which a full formalisation would build in QOU.MathlibExt.YekutieliIntegration, whose discrete holonomy / Stokes layer is already sorry-free). It is not a claim that the categorical H²-class identity is derived (AGENTS.md "Axiomatization is NOT a Proof"); the raw d_q² non-vanishing (1), the Chebyshev normalisation (2), and the obstruction↔curvature extraction (3) are all proved. The two remaining axioms are the polynomial stokes_expansion and the scalar raw_normalised.

    Base ring (§7c) #

    Generic {R : Type*} [CommRing R] with the substrate carried as a unit q : Rˣ — the formula needs q⁻¹, and unit-hood is exactly the algebraic content of the former q ≠ 0 (no ordering, no Real.*). No field and no division are required, so the manuscript's own ground ring R_q = ℤ[q, q⁻¹] (LaurentPolynomial ℤ, in which q = T 1 is a unit) is a direct instance. The monic-Chebyshev machinery needs only [CommRing S] [Nontrivial S].

    [IsDomain R] is required — and is genuinely load-bearing, not decorative — by exactly two things: the product non-vanishing yekutieliObstructionData_kappaRaw_ne_zero (mul_ne_zero) and the leading-coefficient extraction leadingCoeff_C_mul_monicCheb (Polynomial.leadingCoeff_mul, which needs NoZeroDivisors). Over a CommRing with zero divisors the non-vanishing is false: in R = ZMod 6 take q = 5 (a unit, q⁻¹ = 5, q ≠ 1), weight = 3 ≠ 0, wedge = 1 ≠ 0; then κ_raw = 5·2·3·1 = 30 = 0. ℤ[q, q⁻¹] and every field are domains, so nothing downstream is lost. Mirrors dq-squared.lean.

    Type u_1

    Geometric data of the level-n Yekutieli obstruction for T_{2,p}.

    The substrate q (with algebraic invertibility witness), the T-action weight w of the top Seifert cycle γ₅ (the integer 5, nonzero), and the q-wedge value wedge ν = ω_V ∧_q ω_T (nondegenerate, nonzero). The nonzero witnesses are geometric-nondegeneracy inputs, carried as data so the non-vanishing theorem below is non-vacuous.

    • q : Rˣ

      The substrate parameter q, carried as a unit of the ground ring: algebraic invertibility (the old q ≠ 0), not the archimedean 0 < q.

    • weight : R

      The T-action weight w of the top Seifert cycle γ₅ (the 5).

    • weight_ne_zero : self.weight ≠ 0

      The weight of a genuine top cycle is nonzero.

    • wedge : R

      The q-wedge value ν = ω_V ∧_q ω_T.

    • wedge_ne_zero : self.wedge ≠ 0

      The q-wedge of the two independent 1-forms is nondegenerate.

        Genus-filtration Chebyshev basis — leading coefficient = 1 #

        The leading Chebyshev coefficient c_{(p−1)/2} of the genus-filtration expansion is the leading coefficient of the monic Chebyshev basis polynomial of degree (p−1)/2. We exhibit that basis concretely (the monic three-term recurrence) and prove it monic, so its leading coefficient is 1 outright — discharging the former chebyshev_top_eq_one axiom. Only the normalisation (the basis is monic) is proved here; the identification of the obstruction's genus generating polynomial with this basis is the axiomatised YekutieliStokesNormalisation.stokes_expansion below.

            Yekutieli non-abelian Stokes normalisation (§3b-cond class).

            The genuinely deep, not-in-Mathlib input is now stated as a concrete polynomial identity rather than an opaque scalar equation:

            • genusPoly — the genus generating polynomial of the obstruction class (its expansion in the genus filtration);
            • stokes_expansion — Yekutieli's non-abelian Stokes theorem says this generating polynomial is the raw d_q² curvature times the monic genus-filtration Chebyshev basis, genusPoly = C κ_raw · monicCheb. A future formalisation of the d_q² curvature could discharge this by computing genusPoly (QOU.MathlibExt.YekutieliIntegration);
            • raw_normalised — the geometric data is unit-normalised so the top genus coordinate is 1 (κ_raw = 1), the irreducible normalisation.

            Progress vs. the earlier revision: the scalar stokes_identity (obstruction = κ_raw) is no longer an axiom — it is the derived obstructionCoord_eq_kappaRaw, obtained from stokes_expansion by the proved leading-coefficient extraction leadingCoeff_C_mul_monicCheb. The remaining axioms are the structural polynomial stokes_expansion (strictly stronger, but faithful to what non-abelian Stokes actually asserts) and the scalar raw_normalised. chebyshev_top_eq_one stays discharged (leadingChebyshev_eq_one).
