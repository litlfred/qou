    QOU.Archimedean.rj_canonical_inner_product — Rosso–Jones inner product, convention D #

    Proposition (prop:rj-canonical-inner-product).

    Hecke relation (σ − q)(σ + q⁻¹) = 0, [n] = (qⁿ − q⁻ⁿ)/(q − q⁻¹) (qIntBal), Markov parameter z = q³/(q² + 1) = q²/[2] (convention D).

    What this file proves (sorry-free, over a generic field R) #

    • markovZD_eq — the block's z = q²/[2] is z_D = q³/(q²+1).
    • hookContent_row — the hook-content product of the one-row shape (r): ∏_{i<r} [2+i] = [r+1] · ∏_{i<r} [r−i], i.e. d_(r) = [r+1] (denominators cleared, so no non-vanishing hypothesis is needed).
    • hookContent_hook — the same for the two-row hook (m,1): d_(m,1) = [m]. These are the two hook dimensions that survive in part (iii).
    • h2Trace_rossoJones — part (iii) at r = 2, for every s, computed in H₂(q) itself (basis {1, σ}, σ² = (q − q⁻¹)σ + 1) with the Markov trace tr(1) = 1, tr(σ) = z_D: [2]² · tr_M(σˢ) = [3] qˢ + (−q⁻¹)ˢ. For odd s (the torus knots τ(2,s)) this is the block's [r+1] q^{s(r−1)} − [r−1] q^{s(r−3)} at r = 2 (h2Trace_rossoJones_odd).
    • h3Trace_rossoJones — part (iii) at r = 3, for every s, computed in H₃(q) on the basis {1, σ₁, σ₂, σ₁σ₂, σ₂σ₁, σ₁σ₂σ₁}: [2]³ · tr_M((σ₁σ₂)ˢ) = [4] q^{2s} + [2]·χ(s), χ(s) = 2 if 3 ∣ s, else −1. For 3 ∤ s (torus knots τ(3,s)) this is the block's formula at r = 3 (h3Trace_rossoJones_coprime). The right-multiplication tables are derived from the Hecke and braid relations in an arbitrary R-algebra (H3.eval_rs1, H3.eval_rs2), and the trace values on the basis are forced by the Markov conditions (H3.markov3_unique); h3_markov_rossoJones states the result for every linear functional satisfying them.
    • H3.markov3_unique_adjoin — part (ii)'s uniqueness input at r = 3: two Markov traces with the same z agree on the whole subalgebra generated by σ₁, σ₂ (that subalgebra is spanned by the six basis words, H3.exists_eval_of_mem_adjoin).
    • old_form_ii_false_r2 — the formerly carried field claim_unique_up_to_scalar ("every diagonal form normalised at the trivial class is a scalar multiple of d_λ") is false already at r = 2.

    What it does NOT prove — stated here so the gap stays visible #

    • Part (iii) for general r (the hook/Adams-sign Rosso–Jones formula) is not formalised; only r = 2 and r = 3 are here (by explicit computation in H₂, H₃), and r = 4 is in QOU.Archimedean.RossoJonesH4 (h4_markov_rossoJones). It is cited ([rosso-jones1993]) and re-verified in exact arithmetic over ℚ(q) for every coprime (r,s) tested at r = 2, 3, 4 by computations/probes/rj_inner_product_conventionD_torus_probe.py. It is deliberately not encoded as a class field: a class whose torus-trace datum is unconstrained data is inhabited by defining that datum to be the right-hand side, which is the self-assuming pattern AGENTS.md §1a forbids. Formalising it honestly needs the Markov trace on H_r(q) for general r (QOU.IwahoriHecke.MarkovTrace), which is open infrastructure.
    • Part (ii)'s positive content — the form is [2]^r tr_M(p_λ p_μ) and is fixed because the Markov trace with tr_M(1) = 1 is unique for given z — rests on Markov uniqueness, formalised here only for r ≤ 3 (H3.markov3_unique_adjoin; r = 2 is immediate from {1, σ} spanning H₂). General r needs a normal-form / spanning theorem for H_r(q). That is now proved for every r in QOU.IwahoriHecke.JonesNormalForm (markov_unique), and QOU.IwahoriHecke.MarkovTransfer carries it across algebras. (The older modules QOU.Hecke.MarkovTrace, QOU.IwahoriHecke.MarkovTrace carry the trace as class data. QOU.Hecke.markov_trace_unique was proved from markov_trace_unique_axiom, which was false and has been removed; it is now a theorem that takes the cross-level Markov property MarkovTrace.IsMarkov as a hypothesis.)

    History #

    Until 2026-10-10 this file carried a self-assuming HeckeRepRingContext class whose fields claim_unique_up_to_scalar (false, see old_form_ii_false_r2) and jonesPoly_eq_eval (the convention-C sum Σ_{λ⊢r} d_λ q^{c_λ s}, which agrees with the trace only for r = 2, s even) were projected out as "theorems". Both are removed; bean qou-q425.

          Part (iii) at r = 3, computed in H₃(q) #

          H₃(q) has the standard basis {1, σ₁, σ₂, σ₁σ₂, σ₂σ₁, σ₁σ₂σ₁}. Right multiplication by σ₁, σ₂ on these coordinates is derived from the Hecke relation σᵢ² = (q − q⁻¹)σᵢ + 1 and the braid relation σ₁σ₂σ₁ = σ₂σ₁σ₂ (H3.eval_rs1, H3.eval_rs2 prove the derivation in any R-algebra carrying such generators). The Markov trace on the basis is then forced by tr(1) = 1, tr(σ₁) = z, cyclicity and the Markov property on H₂ = span{1, σ₁} (markov3_unique). The torus braid γ = σ₁σ₂ is iterated on the coordinates and its trace is evaluated in closed form (h3Trace_rossoJones). Nothing about the answer is assumed: the only inputs are the defining relations and the Markov conditions.
