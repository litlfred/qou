    def QOU.Archimedean.HyperbolicVolume.chimney (T : Set (ℝ × ℝ)) (R : ℝ) :
    Set (Fin 3 → ℝ)

    The solid over a base set, above the hemisphere of radius R.

    Milnor's normalized position uses R = 1; the radius is left free because it costs nothing and H4-1 (integral_Ioi_hemisphere) is already stated at general R.

    The far vertex sits at infinity, so this is unbounded upward -- a "chimney" over T, not a bounded solid. That product shape is what H4-2's Fubini consumes.

        theorem QOU.Archimedean.HyperbolicVolume.chimney_subset_upperHalfSpace (T : Set (ℝ × ℝ)) (R : ℝ) :
        chimney T R ⊆ upperHalfSpace

        Every chimney sits in the upper half-space -- with no hypothesis on the base at all.

        Real.sqrt is non-negative even where its argument is (so outside the disk the floor degenerates to z > 0), which is exactly what makes this unconditional. That is a genuine convenience of the Real.sqrt convention rather than an accident: it means the region never silently escapes H³.

        theorem QOU.Archimedean.HyperbolicVolume.chimney_fibre {T : Set (ℝ × ℝ)} {R : ℝ} {p : Fin 3 → ℝ} (hp : (p 0, p 1) ∈ T) :
        p ∈ chimney T R ↔ p 2 ∈ Set.Ioi √(R ^ 2 - p 0 ^ 2 - p 1 ^ 2)

        The vertical fibre of a chimney is exactly a ray -- the shape H4-1 integrates.

        This is the bridge between H3 and H4: integral_Ioi_hemisphere computes ∫ z in Ioi (√(R² − d²)), z⁻³ = 1/(2(R² − d²)), and this says that ray IS the fibre. H4-2 then only has to justify integrating fibrewise (Fubini).

        chimney over an empty base, or with the floor above every height, would be empty and every later statement about it vacuous.
