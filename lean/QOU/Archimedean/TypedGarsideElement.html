    QOU.Archimedean.TypedGarsideElement #

    Canonical declaration for content block at quantum-observable-universe/particle-interactions/typed-garside-element.ts.

    Formalises the manuscript definition of the typed Garside element 𝒢(t₀,…,t_{A-1}) ∈ H_A(q): the Garside staircase of typed crossings, one C(t_j, t_{ℓ+1}; σ_j) = σ_j + d(t_j, t_{ℓ+1}) per nucleon pair. The structure below pins the concrete crossing-coefficient table d and the binom(A, 2) factor count. (§7c: archimedean over ℝ — d uses q − q⁻¹.)

      structure QOU.Archimedean.TypedGarsideElement :
      Type

      Data for the typed Garside element 𝒢(t₀,…,t_{A-1}).

      A definition carrier: the substrate parameter q, the typed-crossing coefficient table d, its four defining values (manuscript d(p,p)=0, d(n,n)=-(q-q⁻¹), d(p,n)=d(n,p)=-½(q-q⁻¹)), the nucleon count A, and the crossing-factor count = binom(A,2) (one factor per nucleon pair).

      • q : ℝ

        Substrate parameter q.

      • d : Nucleon → Nucleon → ℝ

        Typed-crossing coefficient d(f_i, f_j) in C = σ + d.

      • d_pp : self.d Nucleon.p Nucleon.p = 0

        d(p,p) = 0.

      • d_nn : self.d Nucleon.n Nucleon.n = -(self.q - self.q⁻¹)

        d(n,n) = -(q − q⁻¹).

      • d_pn : self.d Nucleon.p Nucleon.n = -(1 / 2) * (self.q - self.q⁻¹)

        d(p,n) = -½(q − q⁻¹).

      • d_np : self.d Nucleon.n Nucleon.p = -(1 / 2) * (self.q - self.q⁻¹)

        d(n,p) = -½(q − q⁻¹).

      • A : ℕ

        Nucleon count A = Z + N.

      • numFactors : ℕ

        Number of crossing factors in the staircase.

      • numFactors_eq : self.numFactors = self.A.choose 2

        The staircase has one factor per nucleon pair: binom(A, 2).
