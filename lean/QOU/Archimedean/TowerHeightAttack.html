    QOU.Archimedean.TowerHeightAttack — the tower-height contrapositive, examined #

    rem:yekutieli-transcendence-shadow argues for algebraic independence of Vol(4₁), Vol(5₂), Vol(𝓑₃) by a contrapositive:

    1. a polynomial relation P(V₁, V₂, V₃) = 0 …
    2. … "would force holonomy contributions at different tower levels to close up after finitely many levels";
    3. closure at finite height gives Φ_n = 0 for n > h, hence κ_n = 0 there (CSEvaluationFaithful, contrapositive);
    4. which contradicts perpetual obstruction (κ_n ≠ 0 for all n).

    The prune in QOU.Archimedean.SurrealGradingPrune showed the squeeze cannot supply step 1→4. This file examines the contrapositive itself, which is the corpus's other route. Result: step 1 ⟹ 2 is invalid as stated, and becomes valid — with an immediately effective height — exactly when the tower decomposition is graded.

    §1 The gap (proved) #

    VolumeTowerDecomposition (in HyperbolicVolumeTranscendence) is an ungraded decomposition: its content is HasSum levelContribution totalVolume, a convergent sum of reals. A polynomial relation among the totals is therefore one real equation, and one equation cannot force term-wise vanishing.

    relation_does_not_force_closure exhibits two decompositions over any tower with every level non-zero whose totals satisfy the non-trivial ℚ-linear relation 3·A − 2·B = 0. Linear is a special case of polynomial, so the counterexample kills the general inference: a relation among the totals is compatible with a tower that never closes.

    §2 A second, independent problem (proved) #

    The only concrete decompositions the corpus builds — volumeTowerDecomp_4_1, volumeTowerDecomp_5_2, volumeTowerDecomp_B3 — are all baselineDecomposition, i.e. Φ₀ = Vol, Φ_n = 0 for n ≥ 1. That is a tower closed at height 0: the opposite of perpetual obstruction. perpetual_excludes_baseline proves no CSEvaluationFaithful over a perpetual tower can use one. So the argument's step 3 currently has no instance to run on. (The file's own docstring flags the baseline as trivial and promises a "REFINEMENT"; the refinement does not exist yet.)

    §3 The repair, and where the effective height comes from (proved) #

    Suppose instead the decomposition is graded: level n contributes at q-grade n, and a relation over ℚ[q,q⁻¹] must hold grade by grade. Then a relation is no longer one equation but one equation per level, and everything the contrapositive wants follows:

    • gradewise_determines_level — a gradewise relation pins each level of one tower to the corresponding level of the other.
    • gradewise_closure_propagates — so closure transfers level-by-level.
    • recurrence_step — the general shape. A relation of q-degree D convolves grade k of the relation with grade n−k of the tower, so the grade-n equation is Σ_{k≤D} c_k Φ_{n−k} = 0: an order-D linear recurrence. With c₀ ≠ 0, once D consecutive levels vanish every later level vanishes — the tower closes.
    • closed_above_window — the induction: a vanishing window of width D closes the tower from there on.

    This answers the effectivity question. The height is h(P) = deg_q P, read straight off the relation — no arithmetic input needed. The entire difficulty migrates from "bound the height" to "grade the tower".

    That is the same conclusion the surreal prune reaches from the other side: SurrealGradingPrune.grade_separation_needs_nonstandard says grade separation needs a non-standard object, and a graded tower is exactly such an object (level n at ω-grade n). The two routes converge on one target.

    What is NOT claimed #

    None of this proves or refutes HyperbolicVolumeIndependence. §1 and §2 are scope-(a) findings about the stated argument, not about the conjecture: the conjecture may well be true and provable by a graded version of exactly this route. §3 is a conditional: it supplies the height bound given a grading, and constructing the grading is open (bean qou-5b23).

    §0 A note on universes (AGENTS.md §7d) #

    RecursiveBraneTower carries twelve Type*-valued universe parameters and VolumeTowerDecomposition inherits them through its tower field, so both are universe-carrying in the §7d sense: each unpinned occurrence in a signature elaborates with fresh rigid universes. A theorem binding a tower and independently quantifying ∃ A B : VolumeTowerDecomposition therefore fails to unify (RecursiveBraneTower.{u_1,…} ≠ RecursiveBraneTower.{u_24,…}).

    Rather than positionally apply .{…} to two auto-bound declarations whose universe order is an elaboration artifact (§7d U5 forbids exactly that), this file uses the §7d U4 route — restate so unification happens inside one binder. The mathematical content of §1 involves no tower at all, so it is stated on the underlying summable sequences (relation_does_not_force_closure); the packaged form (geomDecomp_relation) then mentions a single tower binder and derives both decompositions from it.

      The recurrence step — where the effective height comes from.

      A relation of q-degree D convolves grade k of the relation with grade n − k of the tower, so the grade-n equation is Σ_{k ≤ D} c_k · Φ_{n−k} = 0 — an order-D linear recurrence. With c₀ ≠ 0, a vanishing window of the D preceding levels forces Φ_n = 0.

      Hence h(P) = deg_q P: the height bound is read off the relation, with no arithmetic input. Effectivity is free once the tower is graded.

      Closure above a vanishing window. Once D consecutive levels vanish, the order-D recurrence closes the tower from there on: Φ_n = 0 for every n ≥ N. This is the finite-height conclusion the contrapositive needs.

      §4 Jet-order independence does not transfer to algebraic independence #

      JetOrderIndependence asserts that the order-N jet-coefficient Jacobian of tr_M(4₁), tr_M(5₂), tr_M(𝓑₃) has full rank 3 — linear independence of the coefficient vectors. The gap-closing reduction then wants to transfer this, via JetTransportImpliesIndependence, to algebraic independence of the volumes.

      That transfer cannot be a transfer of independence, because the jet series are algebraically dependent — necessarily so:

      • each tr_M(K) is a rational function of u = √q (verified: numerator / denominator u-degrees 14/9, 16/9, 18/9 for 4₁ / 5₂ / 𝓑₃), so all three lie in ℚ(u);
      • ℚ(u) has transcendence degree 1 over ℚ, so any two of them already satisfy a polynomial relation, let alone all three.

      The minimal degree is not predicted by that argument; it is measured. The probe computations/jet_algebraic_independence_probe.py finds, by exact null space over ℚ:

      degree d equations null space stable under more equations?
      ≤ 6 93 → 385 0 yes — no relation
      7 129 → 421 3 yes — genuine, 3-dimensional

      So the minimal degree of an algebraic relation among the three canonical Markov-trace jets is exactly 7.

      linearIndependent_not_algebraicallyIndependent below is the general reason a rank certificate cannot deliver algebraic independence, in the cheapest possible form: t, t², t³ are linearly independent yet satisfy the degree-2 relation z = x·y. Rank counts linear relations; it says nothing about polynomial ones.

      source
      theorem QOU.Archimedean.TowerHeight.linearIndependent_not_algebraicallyIndependent :
      ∃ (f : ℝ → ℝ) (g : ℝ → ℝ) (h : ℝ → ℝ), (∀ (a b c : ℝ), (∀ (t : ℝ), a * f t + b * g t + c * h t = 0) → a = 0 ∧ b = 0 ∧ c = 0) ∧ ∀ (t : ℝ), h t - f t * g t = 0

      Linear independence does not imply algebraic independence.

      t, t², t³ are linearly independent as functions, yet annihilated by z − x·y. So a full-rank jet Jacobian — which is exactly a linear-independence certificate — cannot by itself support an algebraic-independence conclusion.
