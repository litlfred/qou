        def QOU.Archimedean.IsTotallyGeodesic (S : Set HyperbolicMetric.E) :
        Prop

        Totally geodesic (minimiser-convexity form): every minimiser between two points of S has its whole segment γ([0,1]) inside S. This is the only form statable without a Riemannian second fundamental form; it is exactly the property the classification proves.

          class QOU.Archimedean.HypMinimizerUnique :
          Prop

          THE WALL — geodesic uniqueness in H³, an open conjecture. Between two points of H³, a constant-speed minimiser is unique (pointwise on [0,1]).

          This is the one genuinely open, Mathlib-scale input of the whole T2 development. It is axiomatised as a class with a content-bearing field — a real ∀-quantified equality, the honest uniqueness proposition — and is deliberately given NO instance: the open state is a content-bearing carrier with no witness, per AGENTS.md §3b-tax. It is a primary conjecture (no other conjecture class appears in its signature). Existence of minimisers is part of the same wall and is likewise not asserted.

          • unique (x : HyperbolicMetric.E) : x ∈ HyperbolicMetric.upperH → ∀ y ∈ HyperbolicMetric.upperH, ∀ (γ δ : ℝ → HyperbolicMetric.E), IsHypMinimizer γ x y → IsHypMinimizer δ x y → ∀ t ∈ Set.Icc 0 1, γ t = δ t

            φ (γ t) = γ t

            The fixed set of an involutive dH-isometry is totally geodesic (conditional on HypMinimizerUnique).

            Given x, y ∈ Fix(φ) and a minimiser γ between them, the image φ ∘ γ is again a minimiser between the same endpoints — φ preserves admissibility, length (pathLenH_comp), and constant speed (speed_comp), and fixes x, y. By uniqueness γ t = (φ ∘ γ) t = φ (γ t), so γ t ∈ Fix(φ). A GENUINE conditional derivation: it uses the isometry structure and the named uniqueness hypothesis, and derives — never assumes — the conclusion.

            The two Thurston families, as fixed sets of the derived isometries #
