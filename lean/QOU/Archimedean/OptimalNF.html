                      theorem QOU.OptimalNF.pp_extension_not_prefix_closed (S : List HeckeWord) (k : ℕ) (w : HeckeWord) (hw : w ∈ S) (hlen : List.length w ≥ 1) (hend : List.getLast? w ≠ some k) :
                      ¬IsPrefixClosed (List.map (fun (w : HeckeWord) => w ++ [k]) S)

                      pp crossings have d = 0: pure extension (without identity preservation) cannot produce a prefix-closed support unless every non-empty element of S already ends with k. In particular, if S contains a non-empty word that does NOT end with k, then S.map (w ↦ w ++ [k]) fails prefix closure.

                      Proof: if w ∈ S with |w| ≥ 1 and w does not end with k, then w ++ [k] has length ≥ 2, so prefix closure requires w = (w ++ [k]).dropLast ∈ S.map (v ↦ v ++ [k]). But then w = v ++ [k] for some v ∈ S, meaning w ends with k — contradicting our hypothesis.
