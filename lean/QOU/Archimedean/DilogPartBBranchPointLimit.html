    Part B of conj:dilogarithm-archimedean-limit — the W-P1 branch-point limit #

    The wp1_riemann_bound of DilogPartBBranchPointSum sandwiches the positive-factor rescaled log-sum (1−q)·Σ_{k<n} log(1−xqᵏ) against the dilog difference Li₂(xqⁿ) − Li₂(x) with an explicit boundary-decomposition error:

    0 ≤ (Li₂(xqⁿ) − Li₂(x)) − (1−q)Σ log(1−xqᵏ) ≤ (q−1)·(−log(1−xqⁿ)) − (q−1)·qⁿ·(−log(1−x)).

    As q → 1⁺ along a branch-point scaling x qⁿ → 1⁻, the Abel limit tendsto_LiTwo_nhdsWithin_lt_one gives Li₂(xqⁿ) → π²/6, so the whole W-P1 sum converges to π²/6 − Li₂(x) iff the single scalar boundary term (q−1)·log(1−xqⁿ) → 0.

    This file does not fabricate that scalar limit. Per bean qou-jplv, the general limit is genuinely open: with the branch-point index n = ⌊log_q(1/x)⌋ one controls only the upper bound 1 − xqⁿ ≤ (q−1)/q, never the lower bound; 1 − xqⁿ is governed by frac(log_q(1/x)), which oscillates, so the limit holds only under a Faddeev-scaling / Diophantine no-resonance hypothesis on x — analytic number theory, not a brick.

    Joint vs. iterated (coordination). The limit studied here is the joint (diagonal) limit: a single sequence with q → 1⁺ and x qⁿ → 1⁻ simultaneously. That joint limit is false in general (the resonances above), and this file proves it holds exactly on the badly-approximable class — culminating in wp1_tendsto_expNeg_of_fractBound / …_quadratic / …Sqrt, unconditional for x = e^{−β} with β any quadratic irrational. The companion module QOU.Archimedean.DilogPartBIteratedLimit closes W-P1 in the weaker iterated sense — inner q → 1⁺ at fixed ρ, then outer ρ → 1⁻ — with no Diophantine input. The two are complementary: iterated is unconditional but weaker; the joint limit here is stronger but needs (and, on the quadratic-irrational class, gets) the Diophantine bound.

    Accordingly this file provides the two honest pieces:

    • wp1_tendsto_of_boundary — the full assembly (1−q)Σ log(1−xqᵏ) → π²/6 − Li₂(x) stated conditionally on the named boundary-vanishing hypothesis (q−1)·log(1−xqⁿ) → 0 (the §3b-cond pattern: the open analytic input is an explicit hypothesis, never assumed away). The error squeeze and the always-vanishing bulk term (q−1)qⁿ log(1−x) → 0 are discharged unconditionally.
    • boundary_tendsto_zero_of_bounded — the trivial bulk sub-case: whenever the scaling stays bounded away from the branch point (x qⁿ ≤ ρ < 1), the boundary hypothesis holds for free, so wp1_tendsto_of_boundary applies unconditionally in the tame regime. (Away from the branch point the limit is π²/6 − Li₂(x) only under the additional x qⁿ → 1⁻; the bulk lemma discharges the boundary hypothesis, which is what makes it a witness that the hypothesis is non-vacuous.)

    Everything is over ℝ (archimedean — LiTwo, Real.log, and the boundary limits live past the substrate→archimedean wall).

    theorem QOU.Archimedean.wp1_tendsto_of_boundary {x : ℝ} (hx0 : 0 < x) {q : ℕ → ℝ} {n : ℕ → ℕ} (hq1 : ∀ (j : ℕ), 1 < q j) (hqlim : Filter.Tendsto q Filter.atTop (nhds 1)) (hbelow : ∀ (j : ℕ), x * q j ^ n j < 1) (habel : Filter.Tendsto (fun (j : ℕ) => x * q j ^ n j) Filter.atTop (nhdsWithin 1 (Set.Iio 1))) (hbdry : Filter.Tendsto (fun (j : ℕ) => (q j - 1) * Real.log (1 - x * q j ^ n j)) Filter.atTop (nhds 0)) :
    Filter.Tendsto (fun (j : ℕ) => (1 - q j) * ∑ k ∈ Finset.range (n j), Real.log (1 - x * q j ^ k)) Filter.atTop (nhds (Real.pi ^ 2 / 6 - QPochhammer.LiTwo x))

    W-P1 branch-point limit — conditional on the boundary term vanishing. Along any scaling (q_j, n_j) with q_j → 1⁺, x q_j^{n_j} < 1, and x q_j^{n_j} → 1⁻ (branch point), the positive-factor rescaled log-sum converges to π²/6 − Li₂(x) provided the single scalar boundary term (q_j − 1)·log(1 − x q_j^{n_j}) → 0. The proof squeezes the wp1_riemann_bound error to 0; the boundary hypothesis is the only non-derived input (the open Faddeev/Diophantine limit), threaded explicitly.
