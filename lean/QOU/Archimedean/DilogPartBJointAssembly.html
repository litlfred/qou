    Joint-limit Part-B assembly (dilog Part B) — the second, Diophantine-gated closure #

    The coordination ledger (docs/coordination/dilog-part-b-cusp-attack.md) records two routes to the Part-B total reg_n → Li₂(x) − π²/3:

    • the iterated route (wp1_outer_tendsto, Diophantine-free but weaker — a ρ→1⁻ after q→1⁺ ordering), already assembled into the epic headline by naStokes_physical_partB_value (DilogNaStokesOrdering.lean), gated on the na-Stokes path-ordering conjecture;
    • the joint (q,n) route — the physically/mathematically genuine limit — proved conditionally on an explicit Diophantine no-resonance bound by tendsto_wp1_sum_of_no_resonance (DilogPartBWP1Capstone.lean, #4270).

    This file assembles the joint route: it fuses the joint W-P1 capstone with the W-P2 Euler / Dedekind-eta tail (euler_tail_asymptotic, composed along p = 1/q → 1⁻) into the Part-B total, giving a second, independent conditional closure of the epic — under the honest Diophantine no-resonance hypotheses carried explicitly in the signature (no conjectural ordering class). Two independent confirmations of an open result strengthen it (AGENTS.md §"Parallel exploration is valuable").

    Scope (honest, §"Conditional-proved ≠ premise-established") #

    The theorem proves the implication: under the joint filter l with q→1, the endpoint x·qⁿ→1⁻, and the no-resonance bound c(q−1) ≤ 1−x·qⁿ, the combination W-P1 − wp2Tail → Li₂(x) − π²/3. It does not discharge the no-resonance premise (the unconditional joint limit is proved-false along a resonant counter-sequence — ledger 2026-07-25), and it does not re-prove the per-factor k*-split algebraic identity reg_n = W-P1 − wp2Tail (that combinatorial reindexing is tracked separately; here the two proved halves are combined exactly as naStokes_physical_partB_value combines its two class hypotheses). −π²/3 = −2·Li₂(1) is an abelian dilog cusp value (two π²/6 boundary terms), not a curvature term (ledger 2026-07-26 correction).

    Base ring (§7c) #

    theorem QOU.Archimedean.tendsto_partB_total_joint_of_no_resonance {ι : Type u_1} {l : Filter ι} {x : ℝ} {q : ι → ℝ} {n : ι → ℕ} {c : ℝ} (hx0 : 0 < x) (hc : 0 < c) (hq1 : ∀ᶠ (i : ι) in l, 1 < q i) (hbound : ∀ᶠ (i : ι) in l, c * (q i - 1) ≤ 1 - x * q i ^ n i) (hxqn : Filter.Tendsto (fun (i : ι) => x * q i ^ n i) l (nhdsWithin 1 (Set.Iio 1))) (hq : Filter.Tendsto q l (nhds 1)) :
    Filter.Tendsto (fun (i : ι) => (q i - 1) * ∑ k ∈ Finset.range (n i), Real.log (1 - x * q i ^ k) - (1 - (q i)⁻¹) * ∑' (m : ℕ), -Real.log (1 - (q i)⁻¹ ^ (m + 1))) l (nhds (QPochhammer.LiTwo x - Real.pi ^ 2 / 3))

    Joint-limit Part-B total (conditional on Diophantine no-resonance). Along any filter l carrying substrate data q → 1 (1 < q eventually), a partition index n, and a fixed target 0 < x, with the going-up endpoint reaching the branch point (x·qⁿ → 1⁻) and the Diophantine no-resonance bound c·(q−1) ≤ 1 − x·qⁿ (c > 0), the Part-B combination

    (q−1)·Σ_{k<n} log(1−x·qᵏ) − (1−q⁻¹)·Σ'_{m} (−log(1−q⁻ᵐ⁻¹)) ⟶ Li₂(x) − π²/3.

    The first summand is the joint W-P1 (positive factors, → Li₂(x) − π²/6 by tendsto_wp1_sum_of_no_resonance, #4270); the second is the W-P2 regularized negative-factor Euler tail (→ π²/6 by tendsto_wp2_tail_of_q). Their difference is the Part-B total Li₂(x) − π²/3 (subtracted just as naStokes_physical_partB_value combines its two ordered pieces). This is the joint route — the honest genuine limit — gated only on the explicitly-stated no-resonance premise, complementing the iterated (na-Stokes) route which reaches the same value under the ordering conjecture instead.
