    QOU.Archimedean.TransferMatrixOperator #

    Canonical declaration for content block at quantum-observable-universe/mass-theory/transfer-matrix-operator-properties.ts.

    Formalises the manuscript action of the transfer matrix T = cσ + d on a Gröbner–Shirshov-reduced Hecke chain aσ + b: left-multiply and reduce with the Hecke relation σ² = (q − q⁻¹)σ + 1, giving a'σ + b' with

    a' = ca(q − q⁻¹) + cb + da, b' = ca + db.

    Generic over any field (§7c: q⁻¹ needs Field; no ordering/archimedean use).

    source
    structure QOU.Archimedean.TransferMatrixOperator (R : Type u_1) [Field R] :
    Type u_1

    Data for the transfer-matrix reduction (cσ+d)(aσ+b) → a'σ + b'.

    A definition carrier: the substrate q and the two reduced coordinates reduceA = a', reduceB = b' pinned to the Hecke-reduced coefficients of the product.

    • q : R

      Substrate parameter q.

    • reduceA : R → R → R → R → R

      Reduced σ-coefficient a' of (cσ+d)(aσ+b).

    • reduceB : R → R → R → R → R

      Reduced constant b' of (cσ+d)(aσ+b).

    • reduceA_def (a b c d : R) : self.reduceA a b c d = c * a * (self.q - self.q⁻¹) + c * b + d * a

      a' = ca(q − q⁻¹) + cb + da (the σ-part after σ² = (q−q⁻¹)σ + 1).

    • reduceB_def (a b c d : R) : self.reduceB a b c d = c * a + d * b

      b' = ca + db (the constant part).
