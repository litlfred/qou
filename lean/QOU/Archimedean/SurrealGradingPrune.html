    QOU.Archimedean.SurrealGradingPrune — the squeeze cannot see arithmetic #

    Formalize-first prune (AGENTS.md §"Formalize-first probe discipline") for the hypothesis class "transport the surreal-squeeze / ordω grade-separation mechanism — the one that powers the q-NS blowup bound, the q-Collatz drift bound and the P-vs-NP budget bound — to the algebraic independence of Vol(4₁), Vol(5₂), Vol(𝓑₃)" (conj:hyperbolic-volume-transcendence, rem:yekutieli-transcendence-shadow).

    The mechanism being pruned #

    Every surreal bound in appendix-surreals has the same engine (lem:surreal-squeeze): place a cost and a budget at different ordω grades, then read off the strict inequality. In ω-adic form the q-Collatz and P-vs-NP remarks both write it as

    ordω(δ² · Ω_q) = 1 > -3 = ordω(Δ_q) ⟹ δ² · Ω_q > Δ_q.

    The soundness of that step is dominance: a strictly larger grade means the element is infinitely larger — every standard multiple of the smaller stays below the larger. That is the Conway–Gonshor archimedean-class comparison, and it is the only property of ordω these arguments use.

    The obstruction (proved here, sorry-free) #

    ℝ is a single archimedean class. So the very property that makes dominance sound forces the grading to be constant on the positive reals (grade_eq_of_pos). Three consequences, each a theorem below:

    • no_separation_of_standard — the squeeze derives no strict inequality between two positive standard reals. Not "hard": the premise g a < g b is false for every such pair.
    • nonvanishing_premise_circular — under the ordω(0) = -∞ convention, the grade premise that would certify x ≠ 0 is logically equivalent to x ≠ 0. A grade-dominance proof of non-vanishing consumes its own conclusion.
    • grade_blind_to_rationality — the mechanism cannot separate a rational from an irrational, so it cannot deliver even SingleVolumeIrrational (Vol(4₁) ∉ ℚ), the weakest rung of the corpus's own transcendence ladder, let alone the algebraic-independence rung.

    Applied to the target: for P : MvPolynomial (Fin 3) ℚ and v = ![Vol(4₁), Vol(5₂), Vol(𝓑₃)], the value aeval v P is a standard real, so grade_aeval_const says every non-relation sits at one and the same grade. The grading partitions {P} into "vanishes" / "does not vanish" and adds nothing — it restates the conjecture in ω-adic notation rather than advancing it.

    Scope of the claim (AGENTS.md §"Before declaring refuted") #

    This is a scope-(b) structural exclusion — it cites a proved invariant (the archimedean property of ℝ, not_infinitelySmaller_of_pos) — but the excluded object is narrow and must be quoted precisely:

    Grade separation alone cannot decide a polynomial relation among standard reals.

    It does not exclude surreal or non-Archimedean methods from the problem. grade_separation_iff_infinitelySmaller is the positive half: the mechanism is exactly available when a comparison leaves the standard archimedean class. That is why it works for Ω_q ≍ ε⁻¹ vs Δ_q ≍ ε³ (grades +1 and -3) and is unavailable for Vol (grade 0). A route that first produces a non-standard object whose standard part is the relation — e.g. an effective tower height, per JetOrderIndependence — is untouched by this file.

    §1 The comparison the grading refines #

    def QOU.Archimedean.SurrealPrune.InfinitelySmaller (a b : ℝ) :
    Prop

    InfinitelySmaller a b — a is infinitely smaller than b: every standard multiple of a stays strictly below b.

    This is the Conway–Gonshor archimedean-class comparison. A strict ordω drop means exactly this, which is what makes the squeeze's grade-dominance step sound.

        §3 The prune #

        source
        theorem QOU.Archimedean.SurrealPrune.no_separation_of_standard {Γ : Type u_1} [LinearOrder Γ] {g : ℝ → Γ} (hg : SqueezeGrading g) {a b : ℝ} (ha : 0 < a) (hb : 0 < b) :
        ¬g b < g a

        The squeeze proves no inequality between standard reals.

        The mechanism concludes b < a from the premise g b < g a. For positive standard a, b that premise is false — so the mechanism yields no strict inequality between standard reals at all. This is the direct obstruction: the independence target |P(V)| > 0 is a separation among standard reals.

        theorem QOU.Archimedean.SurrealPrune.nonvanishing_premise_circular {Γ : Type u_1} [LinearOrder Γ] {g : ℝ → Γ} (hbot : ∀ (y : ℝ), y ≠ 0 → g 0 < g y) (x : ℝ) :
        g 0 < g x ↔ x ≠ 0

        The non-vanishing premise is circular.

        Adopt the usual bottom convention ordω(0) = -∞ (hbot). Then the grade premise that would certify x ≠ 0 by dominance is logically equivalent to x ≠ 0. Any grade-dominance proof of non-vanishing therefore consumes its own conclusion as its input — the ω-adic notation restates the question.

        Applied to x = P(Vol(4₁), Vol(5₂), Vol(𝓑₃)): writing the conjecture as a grade statement is a change of notation, not a step of the proof.

        theorem QOU.Archimedean.SurrealPrune.grade_aeval_const {Γ : Type u_1} [LinearOrder Γ] {g : ℝ → Γ} (hg : SqueezeGrading g) (v : Fin 3 → ℝ) (P Q : MvPolynomial (Fin 3) ℚ) (hP : 0 < (MvPolynomial.aeval v) P) (hQ : 0 < (MvPolynomial.aeval v) Q) :
        g ((MvPolynomial.aeval v) P) = g ((MvPolynomial.aeval v) Q)

        Every non-vanishing polynomial value at real arguments carries the same grade. So the grading assigns one value to every non-relation and one to every relation: it is exactly the characteristic function of the conjecture, and supplies no independent information about which polynomials vanish.

        This is no_separation_of_standard in the shape of the actual target: P ranges over ℚ[x,y,z] and v = ![Vol(4₁), Vol(5₂), Vol(𝓑₃)].

        §5 The positive half — where the mechanism is available #

        source
        theorem QOU.Archimedean.SurrealPrune.grade_separation_needs_nonstandard {Γ : Type u_1} [LinearOrder Γ] {g : ℝ → Γ} (hg : SqueezeGrading g) {a b : ℝ} (ha : 0 < a) (hb : 0 < b) (hsep : g a < g b) :
        False

        Exact domain of the squeeze. Grade separation between positive elements is available precisely when the comparison leaves the standard archimedean class.

        This is why the q-NS / q-Collatz / P-vs-NP bounds are legitimate uses (Ω_q ≍ ε⁻¹ and Δ_q ≍ ε³ sit at grades +1 and -3, genuinely different classes) and why the volume target is outside the domain (all of Vol(4₁), Vol(5₂), Vol(𝓑₃) and every P(V) sit at grade 0).

        A route that manufactures a genuinely non-standard object whose standard part is the relation is not pruned by this file.
