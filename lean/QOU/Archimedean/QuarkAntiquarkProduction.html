    QOU.Archimedean.QuarkAntiquarkProduction #

    Canonical declaration for content block at quantum-observable-universe/particle-interactions/quark-antiquark-production-reduction.ts.

    Formalises the manuscript normal form of the two-colored-photon product γ₁·γ₂ in H₃(q) (3-term specialisation γᵢ = 𝟏 + φ_i σ₀ + ψ_i σ₁), whose NF has coefficients

    • γ : 1 + φ₀ψ₀ + φ₁ψ₁
    • σ₀ : φ₀ + ψ₀ + φ₀ψ₀h, σ₁ : φ₁ + ψ₁ + φ₁ψ₁h
    • L₊ = σ₀σ₁ : φ₀ψ₁, L₋ = σ₁σ₀ : φ₁ψ₀ (cross-color only)

    with h = q − q⁻¹. Generic over any CommRing (§7c-clean; the σ non-commutativity is carried by the coefficient formulas).

    Type u_1

    Coefficient data for NF(γ₁·γ₂).

    A definition carrier: the two photons' color weights φ₀,φ₁ and ψ₀,ψ₁, the deformation h, and the five normal-form coefficients each pinned to its manuscript value.

    • φ₀ : R

      Color weights of γ₁.

    • φ₁ : R
    • ψ₀ : R

      Color weights of γ₂.

    • ψ₁ : R
    • h : R

      Deformation h = q − q⁻¹.

    • cγ : R

      Coefficient of γ (the identity knot).

    • cσ₀ : R

      Coefficient of σ₀.

    • cσ₁ : R

      Coefficient of σ₁.

    • cLp : R

      Coefficient of the positive Hopf link L₊ = σ₀σ₁.

    • cLm : R

      Coefficient of the negative Hopf link L₋ = σ₁σ₀.

    • cγ_def : self.cγ = 1 + self.φ₀ * self.ψ₀ + self.φ₁ * self.ψ₁
    • cσ₀_def : self.cσ₀ = self.φ₀ + self.ψ₀ + self.φ₀ * self.ψ₀ * self.h
    • cσ₁_def : self.cσ₁ = self.φ₁ + self.ψ₁ + self.φ₁ * self.ψ₁ * self.h
    • cLp_def : self.cLp = self.φ₀ * self.ψ₁
    • cLm_def : self.cLm = self.φ₁ * self.ψ₀
