    theorem QOU.Archimedean.at_most_one_obtuse {α β γ : ℝ} (hγ : 0 < γ) (hsum : α + β + γ = Real.pi) :
    ¬(Real.pi / 2 ≤ α ∧ Real.pi / 2 ≤ β)

    An admissible angle triple has at most one obtuse angle. If two of α, β, γ > 0 summing to π were both ≥ π/2, the third would be ≤ 0. So Milnor's obtuse case is a single configuration, not a family.

    theorem QOU.Archimedean.third_angle_acute_of_obtuse {α β γ : ℝ} (hγ : Real.pi / 2 ≤ γ) (hsum : α + β + γ = Real.pi) :
    α + β ≤ Real.pi / 2

    The reflected argument is acute. If γ ≥ π/2 then α + β = π − γ ≤ π/2. This is what makes the −Λ(α+β) term of lob_sum_eq_reflected an acute-argument Lobachevsky value in the obtuse case.

    theorem QOU.Archimedean.lob_sum_eq_reflected {α β γ : ℝ} (hsum : α + β + γ = Real.pi) :
    Lob α + Lob β + Lob γ = Lob α + Lob β - Lob (α + β)

    The Λ-sum in reflected form. From γ = π − (α+β) and Lob_pi_sub : Λ(π − t) = −Λ(t),

    Λ(α) + Λ(β) + Λ(γ)  =  Λ(α) + Λ(β) − Λ(α+β).

    No acuteness needed for the identity; combined with third_angle_acute_of_obtuse the right-hand side has all three arguments (α, β, α+β) acute exactly when γ is the obtuse one. This is Milnor's "one piece enters with a minus sign" at the analytic level.
