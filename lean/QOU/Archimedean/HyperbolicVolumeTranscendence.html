    Hyperbolic Volume Transcendence: Conjectures and Propositions #

    Formalizes the chain of results connecting the cosimplicial brane tower to algebraic independence of hyperbolic volumes:

    1. VolumeTowerDecomposition — Vol(K) = Σ_n Φ_n(K) (proposition)
    2. CSEvaluationFaithful — κ_n ≠ 0 ⟹ Φ_n(K) ≠ 0 (proposition)
    3. SingleVolumeIrrational — Vol(4₁) ∉ ℚ (conjecture)
    4. BorelZagierQOU — ℚ-linear independence (conjecture)
    5. HyperbolicVolumeIndependence — algebraic independence (conjecture)

    Proved facts (no sorry) #

    • vol_4_1_pos, vol_5_2_pos, vol_B3_pos: all volumes are positive
    • vol_4_1_ne_zero, vol_5_2_ne_zero, vol_B3_ne_zero: all nonzero
    • vol_4_1_ne_vol_B3, vol_4_1_ne_vol_5_2, vol_5_2_ne_vol_B3
    • pairwise_distinct: all three are pairwise distinct
    • decomposition_classical_limit: at q = 1, only level 0 contributes
    • faithfulness_from_tower: CS faithfulness + tower ⟹ independence

    §0 Catalan's constant (used in vol_B3 := 8 · G) #

    catalan_G and its numerical bounds were previously declared in QOU.Archimedean.BorromeanVolumeCatalan; they were lifted here on 2026-06-07 so that vol_B3 can be defined as the exact symbolic expression 8 · catalan_G rather than a 15-digit SnapPy decimal approximation. This discharges the former vol_B3_eq_8_catalan axiom (now a theorem … := rfl) and gives vol_B3 infinite mathematical precision. The two-sided interval 0.915 < G < 0.916 is now also a theorem (catalan_G_numerical_bounds, discharged 2026-06-10 via the alternating-series partial-sum bracket — no numerical axiom remains on the Catalan side).

                        §7 Algebraic independence conjecture #

                        The conjecture is stated as a class following the conjectural propagation convention: the sorry on any instance IS the conjecture itself. A polynomial relation P(Vol(4₁), Vol(5₂), Vol(𝓑₃)) = 0 with P ≠ 0 would contradict the conjecture.

                        We state this without importing MvPolynomial to keep the build light. The predicate is expressed directly: no non-trivial integer-coefficient polynomial relation holds among the three volumes.

                        (Declared before §8's implication chain because the conditional theorems there consume it; the class previously sat after its first use, which broke the file under top-to-bottom elaboration.)

                        source
                        class QOU.Archimedean.HyperbolicVolumeIndependence :
                        Prop

                        Conjecture (Algebraic independence of QOU hyperbolic volumes).

                        The three hyperbolic volumes Vol(4₁), Vol(5₂), Vol(𝓑₃) are algebraically independent over ℚ. Equivalently, for any finitely supported function f : ℕ × ℕ × ℕ → ℚ, if the sum Σ f(i,j,k) · Vol(4₁)^i · Vol(5₂)^j · Vol(𝓑₃)^k = 0 then f = 0.

                        Since the ground ring ℚ[q, q⁻¹] is a polynomial ring over ℚ, algebraic independence over ℚ implies algebraic independence over ℚ[q, q⁻¹] (the volumes are real constants, independent of q).

                        Note: we use non-negative exponents (ℕ) since the volumes are non-zero reals — any Laurent-style relation v^{-k} can be cleared by multiplying through by v^k.

                        LaTeX: \label{conj:hyperbolic-volume-transcendence}

                        • no_relation (S : Finset (ℕ × ℕ × ℕ)) (f : ℕ × ℕ × ℕ → ℚ) : (∀ ijk ∉ S, f ijk = 0) → ∑ ijk ∈ S, ↑(f ijk) * vol_4_1 ^ ijk.1 * vol_5_2 ^ ijk.2.1 * vol_B3 ^ ijk.2.2 = 0 → ∀ (ijk : ℕ × ℕ × ℕ), f ijk = 0

                          No non-trivial monomial relation holds. Given any finitely supported function assigning rational coefficients to triples of non-negative exponents, if the weighted sum of powers of the three volumes vanishes, the function is identically zero.

                              SingleVolumeIrrational

                              Algebraic independence implies irrationality of each volume.

                              The proof is a 2-monomial contradiction: if vol_v = (r : ℝ) for some r : ℚ, then the polynomial P(v) = v − r (support {(1,0,0),(0,0,0)} resp. the appropriate unit index) gives a nontrivial zero polynomial relation, contradicting HyperbolicVolumeIndependence.no_relation.
