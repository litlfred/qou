          shellOp φ 0 one = one ∧ (∀ (n : ℕ), (torusCD (q - q⁻¹) (n + 1)).1 = (q - q⁻¹) * (torusCD (q - q⁻¹) n).1 + (torusCD (q - q⁻¹) n).2 ∧ (torusCD (q - q⁻¹) (n + 1)).2 = (torusCD (q - q⁻¹) n).1) ∧ magicNumber 0 = 2 ∧ magicNumber 1 = 8 ∧ magicNumber 2 = 20 ∧ magicNumber 3 = 28 ∧ magicNumber 4 = 50 ∧ magicNumber 5 = 82 ∧ magicNumber 6 = 126

          Torus-knot shell binding (manuscript claims (i)–(iii)).

          When a nuclear shell closes (palindromic Poincaré histogram), the next nucleon starts a new shell and the inter-shell crossing is mediated by a torus knot T_{2,k} whose index k is the closed-shell size. This formalizes the inductive construction across shell boundaries and derives the magic numbers.

          All three sub-claims are derived:

          • (i) the inter-shell operator at level 0 is the identity (Φ⁰(1) = 1);
          • (ii) the torus-knot Chebyshev coefficients satisfy c_{n+1} = (q−q⁻¹)·cₙ + dₙ, d_{n+1} = cₙ;
          • (iii) the magic numbers (2, 8, 20, 28, 50, 82, 126) are the closed-shell occupancies.
