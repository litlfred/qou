              theorem QOU.Archimedean.HyperbolicMetric.dH_self {x : E} (hx : x ∈ upperH) :

              dH x x = 0 for x ∈ H³: the constant path at x is admissible and has hyperbolic length 0 (its derivative vanishes).

              Symmetry dH_comm — DERIVED via the reverse path #

              The reverse path t ↦ γ(1−t) of an admissible γ : x → y is admissible from y to x, and has the same hyperbolic length — the length equality is the antitone one-dimensional change of variables ∫⁻_{[0,1]} F = ∫⁻_{[0,1]} F(1−·). Hence dH is symmetric. No IsNegInvariant instance and no measurability of the integrand are needed: the JacobianOneDim reflection Jacobian supplies the change of variables for an arbitrary u : ℝ → ℝ≥0∞.

              The isometry engine #

              A map φ : E → E whose Fréchet derivative Dφ(p) scales every tangent vector by lam(p) and whose height scales by the SAME lam(p) preserves the line element ‖v‖/z pointwise. We bundle these four facts as IsDHIsometry φ and derive from them, once and reusably: image-admissibility, length preservation, pointwise speed preservation, and finally dH-invariance. Both boundary isometries below (reflection, inversion) and the totally-geodesic classification consume this one interface.

              Type

              Conformal height-scaling data for φ. A choice of derivative field Dφ and conformal factor lam witnessing that φ is, on H³, differentiable with a derivative that scales every tangent norm by lam(p) and scales the height coordinate by the SAME lam(p). Carries data (Dφ, lam), so it is a structure, not a Prop.
