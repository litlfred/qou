            theorem QOU.Archimedean.skein_finiteness_bound {A : ℕ} (V : Fin (A - 1) → ℝ) (Amax : ℕ) :
            skeinPoly V = Finset.univ.prod V ∧ ((∀ (i : Fin (A - 1)), 0 < V i) → 0 < skeinPoly V) ∧ (boundedConfigs Amax).Finite

            Skein finiteness bound (manuscript claims (i)–(iii)).

            The number of stable nuclear configurations at a given substrate parameter q is finite. The stability boundary is the zero locus of the Skein polynomial P_{N(p,n)}(q) = ∏ᵢ V̂ᵢ(q), and a configuration is stable only if every per-generator traced volume is positive (whence P > 0).

            All three sub-claims are derived:

            • (i) P = ∏ᵢ V̂ᵢ (Skein factorisation, definitional);
            • (ii) (∀ i, 0 < V̂ᵢ) → 0 < P (per-generator positivity ⇒ P > 0);
            • (iii) the configurations with mass number ≤ Amax form a finite set (finiteness of the stability window).
