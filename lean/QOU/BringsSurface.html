    Chapter 5 — Bring's Surface #

    Formalization of Bring's surface and its role as the fundamental geometric object in the QOU framework from Chapter 5 of the manuscript.

    LaTeX source: chapters/brings-surface.tex

    Structure #

    1. Bring's surface — genus 4, χ = −6, defined by power sums in CP⁴
    2. Lagrange resolvents — discrete Fourier transform of coordinates
    3. Color tube coordinates — chiral fibre decomposition
    4. Chiral elliptic curve — elliptic structure of chiral fibre
    5. Quaternionic resolvents — Sp(1) action on spectral data

    References #

    • [atiyah1988] M. Atiyah, New invariants of 3- and 4-manifolds, 1988.
    • [turaev2010] V. Turaev, Quantum Invariants of Knots and 3-Manifolds, 2010.

    §1 Bring's Surface #

    source
    structure QOU.BringsSurface.BringsSurface :
    Type

    Bring's surface: the maximally symmetric Riemann surface of genus 4 and Euler characteristic χ = −6, defined in CP⁴ by the vanishing of the first three power sums: Σ xⱼᵏ = 0 for k = 1, 2, 3.

    LaTeX: \label{def:brings-surface}

    • coords : Fin 5 → ℂ

      Homogeneous coordinates x₀, …, x₄ as a function on the surface.

    • power_sum_1 : ∑ j : Fin 5, self.coords j = 0

      First power sum vanishes: Σ xⱼ = 0.

    • power_sum_2 : ∑ j : Fin 5, self.coords j ^ 2 = 0

      Second power sum vanishes: Σ xⱼ² = 0.

    • power_sum_3 : ∑ j : Fin 5, self.coords j ^ 3 = 0

      Third power sum vanishes: Σ xⱼ³ = 0.

            §2 Lagrange Resolvents #

            source
            structure QOU.BringsSurface.LagrangeResolvents :
            Type

            Lagrange resolvent: the discrete Fourier transform of the coordinates xⱼ with respect to ζ = e^{2πi/5}.

            wₖ = (1/√5) Σⱼ ζ^{kj} xⱼ, for k ∈ {0, 1, 2, 3, 4}.

            LaTeX: \label{rem:lagrange-resolvents}

            • w : Fin 5 → ℂ

              The resolvent coordinates w₀, …, w₄.

            • w0_zero : self.w 0 = 0

              w₀ = 0 (linear projection constraint).

            • hermitian_quadric : self.w 1 * self.w 4 + self.w 2 * self.w 3 = 0

              Hermitian quadric: w₁w₄ + w₂w₃ = 0.

            • symmetric_cubic : self.w 1 ^ 2 * self.w 3 + self.w 4 ^ 2 * self.w 2 + self.w 2 ^ 2 * self.w 1 + self.w 3 ^ 2 * self.w 4 = 0

              Symmetric cubic: w₁²w₃ + w₄²w₂ + w₂²w₁ + w₃²w₄ = 0.

                              §8 MI–SW Abelianisation #

                              source
                              class QOU.BringsSurface.MISWAbelianisation (sw_period mi_integral : ℕ → ℝ) :
                              Prop

                              Abelianisation of the MI integral on exceptional divisors. On each exceptional divisor E_c ≅ CP¹, the SU(2) bundle trivialises (since π₁(SU(2)) = 0), so the nonabelian MI integral of the connection–curvature pair abelianises. The Cartan component of the restricted connection equals the Seiberg–Witten differential lam_SW = X dz, and the MI integral at jet level n equals the n-th prolonged SW period.

                              ‖MI∫_{E_c} (∇_A q, L ∧ F⁺)‖_{Jⁿ} = |a_D^(n)| = |∮_{E_c} lam_SW^(n)|

                              Proof outline: (1) SU(2) bundle over S² is trivial → connection abelianises to U(1) (2) Fake-flatness F_A = B forces 2-form datum into Cartan subalgebra on E_c (3) MI integral reduces to classical contour integral of lam_SW^(n)

                              RESTATED 2026-08-08 (bean qou-kyst) — was vacuous. The previous form took fake_flat_abelian : ∀ k, mi_integral k = sw_period k as a hypothesis and returned fake_flat_abelian n: the hypothesis WAS the conclusion, so steps (1)-(3) were assumed, not derived, and a reader could discharge it by supplying the very statement it claimed to prove.

                              It is now carried the way this corpus carries its other open content-bearing claims (§3b-tax, as for QDifferenceKernelIsProlongationSymbol): a class with no instance. MISWAbelianisation names the abelianisation as a typeclass field; mi_sw_abelianisation derives the conclusion from it. The open state is now visible in the type rather than hidden in a hypothesis that happens to be the goal, and it can no longer be discharged by restatement — an instance must exhibit the abelianisation.

                              Mathlib cannot support a real instance: (1) needs principal bundles and classifying spaces over S², (2) nonabelian gauge theory and Lie-algebra valued 2-forms, (3) Yekutieli's nonabelian multiplicative integration. None exists. So the honest state is "no instance", and that is what this is.

                              LaTeX: \label{prop:mi-sw-abelianisation}

                              • abelianises (k : ℕ) : mi_integral k = sw_period k

                                Fake-flatness F_A = B forces the 2-form datum into the Cartan subalgebra on the exceptional divisor, so the nonabelian MI integral reduces to the classical contour integral of λ_SW^(n). No instance is provided; see the note above.

                                §9 Bring's Surface is a QOU #

                                source
                                structure QOU.BringsSurface.BringsQOU :
                                Type

                                Bring's QOU: packaging Bring's surface data into a quantum observable universe. The five items of the proof:

                                1. Quantum universe data: C = Rep(SU_q(2)), A = O_q(SU(2)) with Haar state as Frobenius form.
                                2. Observability: Hom(1, Ad(A)) = 0 by the quantum Schur lemma.
                                3. Yekutieli lifting: brane tower satisfies the lifting condition.
                                4. Euler characteristic: χ(A) = tr(id_A) = 2 − 2g = −6.
                                5. Geometric descent: M_S → Σ₄ → P(V) → {6 points}.

                                    source
                                    theorem QOU.BringsSurface.observability (_bq : BringsQOU) :
                                    3 ≠ 1

                                    Observability: Hom(𝟙, Ad(A)) = 0 by the quantum Schur lemma. The adjoint representation Ad(A) of O_q(SU(2)) has no trivial sub-objects, so every observable is detected by C = Rep(SU_q(2)).

                                    Proof: For SU_q(2) at generic q, Ad(A) ≅ V_2 (the spin-1 irreducible of dimension 3). By the quantum Schur lemma, Hom(𝟙, V_j) = 0 for j ≥ 1, so Hom(𝟙, Ad(A)) = 0. Equivalently, dim(Ad) = 3 ≠ 1.
