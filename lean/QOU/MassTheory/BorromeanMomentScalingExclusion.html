    noncomputable def QOU.MassTheory.BorromeanMomentScaling.clusterOrd (r κ : ℝ) (k : ℕ) :
    ℝ

    The order-normalized Brunnian cluster magnitude as a function of the level index k = A - 1: c(k) = κ · r^k with r = h² ∈ (0,1) the per-order Hecke suppression. (Working in k avoids ℕ-subtraction; A ↦ A-1 is a bijection.)

      theorem QOU.MassTheory.BorromeanMomentScaling.brunnian_identification_at_most_one_A {r κ : ℝ} (hr0 : 0 < r) (hr1 : r < 1) (hκ : 0 < κ) {μ : ℕ → ℝ} (hμ : StrictMono μ) {a b : ℕ} (ha : clusterOrd r κ a = μ a) (hb : clusterOrd r κ b = μ b) :
      a = b

      Structural exclusion (main statement). If the Brunnian cluster order c_A = κ·r^{A-1} (r = h² ∈ (0,1), κ > 0) is identified with a strictly increasing residual-moment sequence μ, then the identification c = μ holds for at most one body-order — hence it cannot be a magnitude closure for the whole sequence. The clusters are strictly decreasing while the moments strictly increase; they cross at most once.
