    QOU.MassTheory.CanonicalOrderingSaddle #

    The canonical nucleon arrangement p…pn…n is a SADDLE of the production interface product — so no extremal principle selects it.

    Bean qou-48is (spun out of qou-prjo by PR #4850 §7). Companion to NucleonOrderingSymmetry, which proves the prior half: the corpus's orbit identity ranges over S_Z × S_N, under which the braid word is literally fixed, so it licenses nothing about the cross-species arrangement.

    The object #

    The production A ≥ 3 binding chain (mass_table_comprehensive → binding_canonical(use_closed_form=True) → closed_form_tau_M → closed_form_ratio) multiplies one factor per adjacent nucleon pair — f_pp at a p-p boundary, f_nn at an n-n boundary, f_pn at a mixed one — over a hardcoded ordering ["p"] * Z + ["n"] * N. ifaceProd below is exactly that product, with the ordering supplied as a parameter.

    What is proved #

    • ifaceProd_eq_of_ifaces_perm — the product is a function of the interface multiset alone. (This is the true premise of the "the multiset is the physical datum" resolution.)
    • ifaces_not_determined_by_species_counts — but the multiset is not an invariant of the isotope: two arrangements of the same (Z, N) realise different multisets. So that resolution re-coordinatises the freedom rather than removing it.
    • ifaceProd_deuteron_ordering_independent — the deuteron is the null control: its two arrangements share one interface, so A = 2 is exactly ordering-independent. The freedom switches on at A ≥ 3.
    • canonical_saddle / canonical_not_extremal — the main result. If f_pn < f_pp and f_nn < f_pn (both hold at the substrate anchor: measured f_pp = 0.4993…, f_pn = 0.3948…, f_nn = 0.2903…), then among the arrangements of two protons and two neutrons one lies strictly below the canonical ppnn and another strictly above it. The canonical arrangement is therefore neither a maximum nor a minimum — it is a saddle, and no extremising principle can pick it out.

    What is NOT proved — read before citing #

    • sorry-free ≠ derived. Nothing here derives a magnitude: no binding energy, no Δ_λ, no tr_M value, and no comparison to AME. The content is the shape of the ordering dependence, not any number.
    • This does not show the arrangement is undeterminable. It refutes the extremal-principle route and the multiset-invariance route. A selection rule of a different kind — a confinement/SDP argument, a Markov-move or normal-form argument, a coordination-graph constraint — is untouched. Scope-(a) for that broader claim; only canonical_saddle itself is a scope-(b) exclusion, and it excludes exactly one thing: extremality.
    • The two inequalities are HYPOTHESES, not corpus facts imported into Lean. canonical_saddle proves an implication. Its antecedent is verified numerically at the experimental proton anchor by computations/probes/canonical_ordering_dof_probe.py; cite the two together, and cite this theorem as the conditional it is.

    Base ring (§7c). ifaceProd and the multiset lemmas are over a generic [CommMonoid R] — no ring, no ℝ. Only canonical_saddle needs an order, and it takes the weakest generic form ([CommRing R] [LinearOrder R] [IsStrictOrderedRing R]) rather than specialising to ℝ.

      2. The multiset is not an invariant of the isotope #

      source
      theorem QOU.MassTheory.NucleonOrdering.ifaces_not_determined_by_species_counts :
      List.count Species.p [Species.p, Species.p, Species.n, Species.n] = List.count Species.p [Species.p, Species.n, Species.n, Species.p] ∧ List.count Species.n [Species.p, Species.p, Species.n, Species.n] = List.count Species.n [Species.p, Species.n, Species.n, Species.p] ∧ List.count Iface.pp (ifaces [Species.p, Species.p, Species.n, Species.n]) ≠ List.count Iface.pp (ifaces [Species.p, Species.n, Species.n, Species.p])

      Two arrangements of two protons and two neutrons — the same isotope — with different interface multisets: ppnn ↦ [pp, pn, nn] carries a pp interface, pnnp ↦ [pn, nn, pn] carries none.

      So "the observable depends only on the interface multiset" does not make the observable a function of (Z, N). The freedom is merely re-coordinatised: from which arrangement to which multiset.

      3. The canonical arrangement is a saddle #

      source
      theorem QOU.MassTheory.NucleonOrdering.canonical_saddle {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] (f : Iface → R) (hpp : 0 < f Iface.pp) (hnn : 0 < f Iface.nn) (hpn : 0 < f Iface.pn) (hlo : f Iface.pn < f Iface.pp) (hhi : f Iface.nn < f Iface.pn) :
      ifaceProd f [Species.p, Species.n, Species.n, Species.p] < ifaceProd f [Species.p, Species.p, Species.n, Species.n] ∧ ifaceProd f [Species.p, Species.p, Species.n, Species.n] < ifaceProd f [Species.n, Species.p, Species.p, Species.n]

      The canonical arrangement is strictly interior.

      Fix two protons and two neutrons. If the mixed factor is smaller than the p-p one and larger than the n-n one — f_nn < f_pn < f_pp, which is what the substrate anchor delivers — then

      • pnnp (which trades the canonical pp interface for a second pn) sits strictly below the canonical ppnn, and
      • nppn (which trades the canonical nn interface for a second pn) sits strictly above it.

      The two trades push in opposite directions precisely because f_pn lies between f_pp and f_nn. The canonical arrangement is therefore a saddle of the arrangement-indexed product, not an extremum of it.

      theorem QOU.MassTheory.NucleonOrdering.canonical_not_extremal {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] (f : Iface → R) (hpp : 0 < f Iface.pp) (hnn : 0 < f Iface.nn) (hpn : 0 < f Iface.pn) (hlo : f Iface.pn < f Iface.pp) (hhi : f Iface.nn < f Iface.pn) :
      (∃ (ss : List Species), ss.Perm [Species.p, Species.p, Species.n, Species.n] ∧ ifaceProd f ss < ifaceProd f [Species.p, Species.p, Species.n, Species.n]) ∧ ∃ (ss : List Species), ss.Perm [Species.p, Species.p, Species.n, Species.n] ∧ ifaceProd f [Species.p, Species.p, Species.n, Species.n] < ifaceProd f ss

      No extremal principle selects the canonical arrangement.

      Restated as the claim it is used for: within the same isotope — the same multiset of nucleon species, so the same (Z, N) — there is an arrangement strictly below the canonical one and an arrangement strictly above it. Hence the canonical arrangement is neither the minimiser nor the maximiser of the production interface product, and a variational selection rule of either sign cannot pick it out.

      Scope-(b) exclusion, and it excludes exactly one candidate: extremality. It says nothing about selection rules of other kinds.
