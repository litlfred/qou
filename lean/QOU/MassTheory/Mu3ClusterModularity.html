    The second mixed difference and the cluster identity #

    source
    def QOU.MassTheory.Mu3ClusterModularity.secondDiff (g₀ gₐ g_b gₐᵦ : ℝ) :
    ℝ

    The second mixed finite difference of a set-function g on the interface Boolean lattice {∅, a, b, ab}, represented by its four values (g_∅, g_a, g_b, g_ab): Δ²g = g_ab − g_a − g_b + g_∅. Δ²g > 0 is supermodularity (co-present bonds reinforce), Δ²g < 0 is submodularity (diminishing returns).

        Multiplicative (product-decrease) block-trace ⇒ supermodular ⇒ c₃ ≤ 0 #

        Re-derivation of the #4354 wall in the modularity language. A block-trace that factors as a product of independent per-interface decrease factors rᵢ ∈ [0,1] (g_a = g₀·r_a, g_b = g₀·r_b, g_ab = g₀·r_a·r_b) is supermodular, so its connected cluster is non-positive — the multiplicative route is on the wrong side of the door.
