    A signed split of a residual moment into binding minus saturation #

    source
    structure QOU.MassTheory.SignedResidualSplit :
    Type

    A two-operator residual split: a residual moment realized as residual = B − S, where B ≥ 0 is a binding contribution (a Brunnian trace deficit, provably non-negative) and S ≥ 0 is a saturation magnitude (the negative of a provably non-positive multiplicative cluster). The two operators have opposite sign by construction — that is the whole content.

    • B : ℝ

      Binding contribution (Brunnian/Borromean deficit); non-negative.

    • S : ℝ

      Saturation magnitude (= − multiplicative cluster); non-negative.

    • hB : 0 ≤ self.B
    • hS : 0 ≤ self.S

              Weak existence: some signed split always exists (the STRONG magnitude form is the open Δ_λ gate) #

              source
              theorem QOU.MassTheory.signed_split_exists (μ : ℝ) :
              ∃ (B : ℝ) (S : ℝ), 0 ≤ B ∧ 0 ≤ S ∧ μ = B - S

              Every real moment admits some signed split. This is the weak form — it says nothing about the physical operator magnitudes; it merely records that μ = B − S with B, S ≥ 0 is always solvable (B = max μ 0, S = max (−μ) 0). The STRONG form — that the concrete Borromean binding and multiplicative saturation magnitudes sum to the exact AME μₖ — is the OPEN Δ_λ magnitude closure and is deliberately NOT proved here.

              Capstone: the residual moment sequence is a two-operator object #

              source
              theorem QOU.MassTheory.residual_is_two_operator (r₃ r₄ : SignedResidualSplit) {μ₃ : ℝ} (hμ₃ : 0 < μ₃) (h3model : r₃.residual = μ₃) (h4model : r₄.residual = mu4Residual) :
              r₃.S < r₃.B ∧ r₄.B < r₄.S ∧ (∀ (rb : SignedResidualSplit), rb.S = 0 → rb.residual ≠ mu4Residual) ∧ ∀ (rs : SignedResidualSplit), rs.B = 0 → rs.residual ≠ μ₃

              (CAPSTONE) The Δ_λ residual is a TWO-operator (binding − saturation) object. Model the A=3 moment μ₃ > 0 and the A=4 moment μ₄ = mu4Residual each as a signed split (hmodel). Then, purely from the proved sign structure:

              1. A=3 is binding-dominated — μ₃ > 0 forces the binding value above the saturation magnitude (S₃ < B₃), so the positive odd moment is carried by the non-negative Brunnian/Borromean operator (borromean_cluster_nonneg, #4360).
              2. A=4 is saturation-dominated — μ₄ < 0 (mu4Residual_neg, #4376) forces the saturation magnitude above the binding value (B₄ < S₄), so the negative even moment is carried by the non-positive multiplicative operator (pairwise_3body_content_nonpos, #4354).
              3. Two operators of opposite sign are necessary — no single-sign model spans both: a binding-only (S = 0, hence ≥ 0) split can never equal μ₄ < 0, and a saturation-only (B = 0, hence ≤ 0) split can never equal μ₃ > 0.

              The sign pattern (μ₃ > 0 selects binding, μ₄ < 0 selects saturation) is exactly what the two proved cluster-sign lemmas force. This is the structural sign_swap_a3_a4 (#4376) read as a decomposition: the residual is neither the binding operator alone nor the saturation operator alone, but their signed difference.
