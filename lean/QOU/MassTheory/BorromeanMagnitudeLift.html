    Brunnian-order-suppressed level deficit: D_L(h) = h⁴ · κ_L(h) #

    noncomputable def QOU.MassTheory.BorromeanMagnitudeLift.brunnianDeficit (κ : ℝ → ℝ) (h : ℝ) :
    ℝ

    A Brunnian (order-h⁴-suppressed) level deficit with h⁴-coefficient function κ: D_L(h) = h⁴ · κ h. The leading order is exactly 4 whenever κ 0 ≠ 0 — every 2-sub-link of a Brunnian object is trivial, so the O(h), O(h²), O(h³) parts vanish.

        A level lift is a coefficient ratio — never an order change #

        source
        theorem QOU.MassTheory.BorromeanMagnitudeLift.lift_is_coefficient_ratio {κ₁ κ₂ : ℝ → ℝ} {h : ℝ} (hh : h ≠ 0) (hκ₂ : κ₂ h ≠ 0) :
        brunnianDeficit κ₁ h / brunnianDeficit κ₂ h = κ₁ h / κ₂ h

        Order-invariance of a level lift. For two Brunnian-order-suppressed levels with deficits h⁴·κ₁ h and h⁴·κ₂ h, the lift ratio is κ₁ h / κ₂ h: the shared h⁴ factor cancels. A level lift therefore rescales the coefficient and cannot change the leading h-order. (The measured H₃→H₉ exponent stays 4.098; the ~49× lift lives entirely in κ_{H₉}/κ_bare.)

          A=3 Δ_λ magnitude closure is a conditional coefficient identity #

          source
          def QOU.MassTheory.BorromeanMagnitudeLift.MagnitudeCloses (E0 h κ μ₃ : ℝ) :
          Prop

          Magnitude-closure predicate. The A=3 Δ_λ magnitude closes at a level with coefficient κ iff its magnitude equals the target moment μ₃: E₀ · h⁴ · κ = μ₃. This is a coefficient identity — the level (hence κ) is FIXED and derived, μ₃ is the target; a κ tuned to satisfy it would be a FIT.
