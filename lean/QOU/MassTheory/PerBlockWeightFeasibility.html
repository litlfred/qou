    Per-block weights over disjoint index sets impose no constraint on A-growth #

    Why no finite list of failed weight candidates excludes the class.

    In the Δ_λ binding programme a per-block weight is a function on partitions, and each isotope samples it on partitions of its own n: the deuteron uses λ ⊢ 6 (11 of them), tritium and ³He use λ ⊢ 9 (30), ⁴He uses λ ⊢ 12 (77). Those index sets are disjoint — they share no partition at all. The natural question is then whether the observed A-growth

    S(⁴He) / S(D) = (∑ᵢ u i * A i) / (∑ⱼ v j * B j)

    constrains the weight. This file proves it does not: with disjoint index sets the weight restricted to each isotope is an independent degree of freedom, so every positive growth value is attainable (growth_ratio_attains_any), and a fortiori no finite collection of failed candidates can exclude the class.

    The contrast with QOU.MathlibExt.GibbsRatioMonotonicity is the point: there a one-parameter family (damping time τ) is genuinely constrained and can be excluded wholesale; here the unrestricted class is not. An exclusion in this programme therefore has to name a formula family — it cannot be inferred from a pattern of misses, however uniform that pattern looks.

    Recorded because the session repeatedly read the uniform isotope-spread failures (6.61×, 34.1×, 0.04–3.07, 455×) as evidence against per-block weights as such. That inference does not hold, and this file is the reason.

    Base ring: generic [Field R] [LinearOrder R] [IsStrictOrderedRing R] (§7c). No Real.exp, no completeness, no archimedean construct beyond the ordering — so the statement holds over any ordered field, not merely ℝ. (Note that Mathlib has retired the bundled LinearOrderedField; this is its current spelling.)

      theorem QOU.MassTheory.PerBlockWeightFeasibility.growth_ratio_attains_any {R : Type u_1} [Field R] [LinearOrder R] [IsStrictOrderedRing R] {ι : Type u_2} {κ : Type u_3} [Fintype ι] [Fintype κ] [DecidableEq ι] [DecidableEq κ] (A : ι → R) (B : κ → R) (i₀ : ι) (j₀ : κ) (hA : 0 < A i₀) (hB : 0 < B j₀) {t : R} (ht : 0 < t) :
      ∃ (u : ι → R) (v : κ → R), (∀ (i : ι), 0 ≤ u i) ∧ (∀ (j : κ), 0 ≤ v j) ∧ (∑ i : ι, u i * A i) / ∑ j : κ, v j * B j = t

      Every positive A-growth is attainable. Given any target t > 0, there are non-negative per-block weights u (on the numerator's index set) and v (on the denominator's) realising it exactly.

      This is what disjointness of the index sets buys: u and v are unconstrained relative to one another, so the ratio carries no information about the weight. Hence the per-block-weight class is not excludable by any finite list of failed candidates.
