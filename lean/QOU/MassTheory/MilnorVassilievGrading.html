    1. The two expansion variables agree to first order (no convention factor) #

    theorem QOU.MassTheory.MilnorVassilievGrading.deficit_var_eq_two_sinh (q : ℝ) (hq : 0 < q) :
    q - q⁻¹ = 2 * Real.sinh (Real.log q)

    The deficit variable is 2·sinh of the Vassiliev variable. With h = q−q⁻¹ (the qou Markov-deficit variable) and ℏ = log q (q = e^{ℏ}, the finite-type variable), h = 2·sinh ℏ. Hence the two gradings differ by no rescaling constant other than the harmless factor 2: they assign the same leading order to a term.

    source
    theorem QOU.MassTheory.MilnorVassilievGrading.grading_change_fixes_origin :
    2 * Real.sinh 0 = 0

    sinh vanishes at 0, so the change of variable fixes the origin. With Real.sinh_zero, 2·sinh 0 = 0: the substitution q = e^{ℏ} sends ℏ = 0 (i.e. q = 1) to h = 0. Together with deficit_var_eq_two_sinh, h = 2 sinh ℏ = 2ℏ + O(ℏ³), so h and ℏ share the same leading order (the harmless factor 2 is a unit): an order-k-in-h term is an order-k-in-ℏ (Vassiliev-degree-k) term. The 2(A−1) deficit order is therefore a genuine Vassiliev degree statement, not a variable-convention artifact.

        3. DD-1 resolution — OPEN conjecture class (content-bearing, no instance) #

        The mechanism proposed by #4480: a cyclic Markov trace annihilates the linear (Milnor-degree A−1) part of the deficit — cyclic_trace_kills_iterCommTower proved this for the Lie tower — so the first surviving contribution is a bar-symmetric (q ↔ q⁻¹) quadratic in the tree-level data, landing at the doubled degree 2(A−1). This is the honest open resolution of DD-1; it is NOT proved here (it needs the finite-type scaffold + the Habegger–Masbaum tree-level identity).

        class QOU.MassTheory.MilnorVassilievGrading.BarSymmetricDegreeDoubling (vdeg : ℕ → ℕ) :
        Prop

        (CONJECTURE, primary — OPEN.) A Vassiliev-degree function vdeg on the Brunnian deficit family realises DD-1: the linear (degree-A−1) part vanishes and the first non-vanishing degree is the doubled 2(A−1). Content-bearing; NO instance (the honest open state). Do not fabricate an instance — that would launder the bridge (§"Axiomatization is NOT a Proof").

        • linear_milnor_part_absent (A : ℕ) : 2 ≤ A → vdeg A ≠ milnorVassilievDegree A

          The linear Milnor-degree part carries no deficit weight (cyclic-trace annihilation, #4480): the realised degree is never the bare A−1.

        • first_surviving_is_doubled (A : ℕ) : 2 ≤ A → vdeg A = qouDeficitLeadingOrder A

          The first non-vanishing degree is the bar-symmetric doubled order.
