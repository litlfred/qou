    The tensor-picture Hecke generator is a transposition plus a diagonal part #

    Bean qou-qqm4. Probes: computations/probes/tensor_picture_markov_trace_probe.py, computations/probes/c2_diagonal_insertion_expansion_probe.py.

    On ℂ² ⊗ ℂ² with basis (e₁₁, e₁₂, e₂₁, e₂₂) the U_q(sl₂) R-matrix in Hecke normalisation is

    Ř(q) = ⎡ q  0  0  0 ⎤
       ⎢ 0  0  1  0 ⎥        h = q − q⁻¹
       ⎢ 0  1  h  0 ⎥
       ⎣ 0  0  0  q ⎦

    Three facts about it carry the whole insertion-expansion derivation of the trace coefficients c₀, c₁, c₂, …:

    1. Ř = s + D(q) with s the swap and D(q) = diag(q−1, 0, h, q−1) diagonal and vanishing at q = 1 (rHecke_eq_swap_add_diag, diagPart_one). This is what makes the trace of a braid word, at every order in ε = q − 1, a fixed-point count over sub-words.
    2. The Hecke relation (Ř − q)(Ř + q⁻¹) = 0 (rHecke_hecke_relation), so Ř represents the generator σ_i of H_n(q) in the corpus's convention (§7a: eigenvalues q and −q⁻¹).
    3. The quantum trace of one generator is the convention-D loop value: Tr(K Ř) = q³(1 + q²) with K = diag(1, q², q², q⁴), so Tr(K Ř)/(1+q²)² = q³/(q²+1) = z_D (qtrace_rHecke, qtrace_rHecke_div). This pins the R-matrix normalisation to the Markov trace the corpus uses without any reference to the seminormal form.

    Also recorded: the swap squares to the identity, and the first- and second-order coefficients of D(1+ε) are the Y = diag(0, −1, 1, 0) and W = diag(0, 0, −1, 0) the probes read off — here as exact identities in ε rather than as series.

    Everything is over a generic field K (§7c); no ℝ, no numerics.

            q − 1 = ε and q − q⁻¹ = 2ε − ε² + ε³/(1+ε): the diagonal part at q = 1 + ε is ε·diag(1, 0, 2, 1) + ε²·diag(0, 0, −1, 0) + ε³·diag(0, 0, 1/(1+ε), 0). So X = 1 + Y with Y = diag(0, −1, 1, 0) and W = diag(0, 0, −1, 0), exactly.
