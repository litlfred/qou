    theorem QOU.MassTheory.convex_comb_le_bound {ι : Type u_1} (s : Finset ι) (w t : ι → ℝ) (M : ℝ) (hw : ∀ i ∈ s, 0 ≤ w i) (hsum : ∑ i ∈ s, w i = 1) (hM : ∀ i ∈ s, t i ≤ M) :
    ∑ i ∈ s, w i * t i ≤ M

    A convex combination is bounded by the largest term. With t b the branch traces and w the branch weights, this is tr_M(atom) = ∑_b w_b tr_M(β_b) ≤ max_b tr_M(β_b).

    The exclusion. A target strictly above every branch value is unreachable by any convex reweighting. Applied: M = 1.018275 is the measured max_b tr_M(β_b) over the 32 deuteron branches and target = 1.491498 is √B_AME, so no reweighting — the colour-tube refinement included — gets there.

    Non-vacuity, and what escapes #

    Three guards. The first two are AGENTS.md §3b-tax (satisfiable, load-bearing); the third is the one that matters physically — it exhibits the escape.

    ∑ j ∈ {i}, (fun (x : ι) => 1) j * t j = t i

    The hypotheses are satisfiable: a point mass is a convex combination.

    theorem QOU.MassTheory.bound_fails_without_nonneg :
    ∃ (w : Fin 2 → ℝ) (t : Fin 2 → ℝ), ∑ i : Fin 2, w i = 1 ∧ (∀ (i : Fin 2), t i ≤ 1) ∧ 1 < ∑ i : Fin 2, w i * t i

    Non-negativity is load-bearing. Drop hw and the bound fails: weights (2, -1) still sum to 1, but 2·1 + (-1)·0 = 2 exceeds max = 1. So convex_comb_le_bound is not a tautology about sums — it is convexity doing the work, which is exactly what atom-branch-convexity-bound had to measure (every w_b > 0) rather than assume.

    theorem QOU.MassTheory.larger_index_set_escapes_the_bound :
    ∃ (t : Fin 2 → ℝ) (w : Fin 2 → ℝ), (∀ i ∈ {0}, t i ≤ 1) ∧ (∀ (i : Fin 2), 0 ≤ w i) ∧ ∑ i : Fin 2, w i = 1 ∧ 1 < ∑ i : Fin 2, w i * t i

    What escapes: a larger index set. The bound is relative to the branch set it is taken over. Enlarging that set can raise the maximum and admit values the old bound excluded — here 2, which no convex combination over {0} could reach.

    This is the satellite/cabling move in miniature. A satellite replaces each strand by several, so its branches are words in a larger algebra: not a reweighting of the old branches but a different index set, outside the hypotheses of not_reaches_of_bound_lt. It is why front 2 closes the reweighting route without touching the satellite route.
