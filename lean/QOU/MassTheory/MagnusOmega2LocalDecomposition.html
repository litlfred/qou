    theorem QOU.MassTheory.commutator_eq_zero_of_commute {R : Type u_1} [CommRing R] {n : Type u_2} [Fintype n] (A B : Matrix n n R) (h : Commute A B) :
    A * B - B * A = 0

    Far-commutativity reduction core. A commutator of commuting operators vanishes: Commute A B → A*B − B*A = 0. For the Magnus germs A_a = q·(∂_q σ_a)·σ_a⁻¹, germs at Coxeter distance |a−b| ≥ 2 commute (their generators do), so ⁅A_a,A_b⁆ = 0 — the term drops from Ω₂. This is the operator content of the probe's if |a−b| ≠ 1: continue.

    theorem QOU.MassTheory.omega2_reduces_to_adjacent {R : Type u_1} [CommRing R] {n : Type u_2} [Fintype n] {ι : Type u_3} (s : Finset ι) (fst snd : ι → Matrix n n R) (adj : ι → Prop) [DecidablePred adj] (hfar : ∀ p ∈ s, ¬adj p → Commute (fst p) (snd p)) :
    ∑ p ∈ s, (fst p * snd p - snd p * fst p) = ∑ p ∈ s with adj p, (fst p * snd p - snd p * fst p)

    Ω₂ reduces to adjacent windows. Sum a family of commutators ⁅fst p, snd p⁆ over a finset s of ordered crossing-pairs; if every non-adjacent pair commutes, the sum equals the sum over the adjacent pairs alone. This is the operator identity Σ_{i<j} ⁅A_i,A_j⁆ = Σ_{adjacent} ⁅A_a,A_{a+1}⁆ — far pairs contribute nothing, so Ω₂ is a lattice sum of 3-strand-local windows.

    theorem QOU.MassTheory.trace_rho_localSum {R : Type u_1} [CommRing R] {n : Type u_2} [Fintype n] {ι : Type u_3} (s : Finset ι) (ρ : Matrix n n R) (O : ι → Matrix n n R) :
    (ρ * ∑ k ∈ s, O k).trace = ∑ k ∈ s, (ρ * O k).trace

    Per-window trace decomposition (linearity). The trace of ρ against a sum of local window operators is the sum of the per-window traces: tr(ρ · Σ_k O_k) = Σ_k tr(ρ · O_k). This is the algebraic identity the probe's numeric self-check confirms; it makes tr(ρ Ω₂)'s b-decay attributable window-by-window.

    theorem QOU.MassTheory.trace_rho_commutator_reframe {R : Type u_1} [CommRing R] {n : Type u_2} [Fintype n] (ρ A B : Matrix n n R) :
    (ρ * (A * B - B * A)).trace = ((ρ * A - A * ρ) * B).trace

    Trace-commutator reframing (the sublinear-bound tool). The single-window trace can be moved onto the density: tr(ρ·⁅A,B⁆) = tr(⁅ρ,A⁆·B). This localizes the open sublinear estimate |tr(ρ_λ ⁅A_a,A_{a+1}⁆)| = o(dim_λ) (bean qou-o6ov): the whole size of the single-window trace is controlled by ⁅ρ,A_a⁆, i.e. by how nearly the global word ρ commutes with the germ A_a. Combined with Cauchy–Schwarz |tr(X·B)| ≤ ‖X‖_F‖B‖_F (not in this file) it reduces the o(dim) claim to a Frobenius-norm bound on ⁅ρ,A_a⁆. General CommRing.

    theorem QOU.MassTheory.commutator_mul_left {R : Type u_1} [CommRing R] {n : Type u_2} [Fintype n] (X Y Z : Matrix n n R) :
    X * Y * Z - Z * (X * Y) = X * (Y * Z - Z * Y) + (X * Z - Z * X) * Y

    Leibniz rule for the ring commutator (the telescoping tool). ⁅X·Y, Z⁆ = X·⁅Y,Z⁆ + ⁅X,Z⁆·Y. Applied to the density ρ = ∏_i σ_{g_i} this telescopes: ⁅ρ, A_a⁆ = Σ_i (σ_{<i})·⁅σ_{g_i}, A_a⁆·(σ_{>i}), and ⁅σ_g, A_a⁆ = 0 whenever |g−a| ≥ 2 (the generators far from a commute with the germ A_a). So only the O(1) crossings near position a contribute to ⁅ρ,A_a⁆ — the structural handle that reduces the open Frobenius bound ‖⁅ρ_λ,A_a⁆‖_F = o(√dim) to a bounded number of local commutators ⁅σ_g, A_a⁆ (3-strand objects) dressed by word-pieces. General CommRing.

    theorem QOU.MassTheory.trace_rho_commutatorSum_eq_zero_of_commute {R : Type u_1} [CommRing R] {n : Type u_2} [Fintype n] {ι : Type u_3} (s : Finset ι) (ρ : Matrix n n R) (A B : ι → Matrix n n R) (h : ∀ k ∈ s, Commute (A k) (B k)) :
    (ρ * ∑ k ∈ s, (A k * B k - B k * A k)).trace = 0

    The decay endpoint is an EXACT zero (the commutative/1-dim rep). If the germs pairwise commute — Commute (A k) (B k) for every adjacent pair k, which holds in any 1-dimensional (hence commutative) seminormal rep — then the Magnus Ω₂ = Σ_k ⁅A_k,B_k⁆ is 0, so the single-window sum trace tr(ρ·Ω₂) = 0 identically, for every word ρ. In particular the maximal-b endpoint of the tr(ρ_λ Ω₂) decay, the sign rep λ=(1ⁿ) (dim 1), and the b=0 trivial rep λ=(n) (dim 1) both give an exact zero — the decay terminates at a provable zero, not an asymptote (measured in magnus_extreme_rep_endpoint_probe.py). General CommRing.
