      The genuine geometric normalizer D², and the S-correction of the ratio #

      noncomputable def QOU.MassTheory.geomCoeff (κ_raw S : ℝ) :

          theorem QOU.MassTheory.route_closes_with_rescale_iff {r_geom v_y μ₃ c : ℝ} (hr : r_geom ≠ 0) (hv : v_y ≠ 0) :
          r_geom * (c * v_y) = μ₃ ↔ c = μ₃ / (r_geom * v_y)

          Fit-trap (declined). Σ y_λ = 0.0318 ≠ 1, so one could rescale the production weights y_λ ↦ c·y_λ, changing the cluster to c·v_y and requiring the geometric ratio r_geom to satisfy r_geom·(c·v_y) = μ₃. Closure under such a rescale forces c to the specific value c = μ₃/(r_geom · v_y) — i.e. c is inverted from the target μ₃, a free parameter, hence a FIT. (Even the derivation-flavoured choice "put both weights on Σ=1", c = 1/Σy_λ ≈ 31.5, only reaches r_geom·Σy_λ = 1.506, a 5 % miss — and is itself an undetermined normalization convention, not a derivation.) This lemma states exactly that dependence (closure ⟺ c takes the μ₃-determined value).
