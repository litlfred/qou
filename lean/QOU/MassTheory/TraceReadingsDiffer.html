        theorem QOU.MassTheory.not_rel_of_invariant_ne {α : Type u_2} {β : Type u_3} {τ : α → β} {R : α → α → Prop} (hinv : ∀ (x y : α), R x y → τ x = τ y) {a b : α} (h : τ a ≠ τ b) :
        ¬R a b

        An invariant separates. If τ takes equal values on every R-related pair, then a difference in τ forbids the relation. Stated for an arbitrary relation so it applies to Markov equivalence without that notion being formalised here.

        theorem QOU.MassTheory.readings_not_related_of_invariance {K : Type u_1} [Field K] [CharZero K] {α : Type u_2} {τ : α → K} {R : α → α → Prop} (hinv : ∀ (x y : α), R x y → τ x = τ y) {atom borromean : α} (hatom : τ atom = trMProtonAtom 1) (hbor : τ borromean = trMBorromean 1) :
        ¬R atom borromean

        Reading (A) is refuted, conditional on the invariance hypothesis.

        Given any relation R on a type of algebra elements whose trace τ is R-invariant — Markov equivalence and the Markov trace being the instance intended — two elements whose traces differ are not R-related. Applied to the proton atom element and β_Bor, whose traces differ by the theorems above, this says they are not Markov equivalent, so they do not name a common K.

        The invariance is a hypothesis, not a claim proved here; see the module docstring.
