      resid S (G + d) - resid S G = -d

      The residual moves by exactly the baseline shift (unit absolute gain, opposite sign): shifting ρ_grad ↦ ρ_grad + d moves the residual by −d. There is no attenuation — every bit of baseline error passes straight into the target.

      theorem QOU.MassTheory.Mu3BaselineFragility.residual_amplifies {R : Type u_1} [Field R] [LinearOrder R] [IsStrictOrderedRing R] {r G : R} (hr : 0 < r) (hrG : r < G) :
      1 < G / r

      Relative amplification exceeds unity when the residual is smaller than its baseline. If the residual r = S − G satisfies 0 < r < G, then 1 < G / r: a relative baseline error is magnified by the factor G/r > 1 in the residual. (resid_shift gives the absolute unit gain; this converts it to the relative gain G/r.) For μ₃ this is ρ_grad(3)/μ₃ ≈ 7.
