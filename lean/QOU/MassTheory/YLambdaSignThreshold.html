    sign(y_λ) is a content-threshold parity #

    The Jones–Markov central coefficient is y_λ = s_λ / Z, with s_λ the Wenzl principal specialisation

    s_λ  =  Q^{n(λ)} · ∏_{x ∈ λ} (1 − Q^r·Q^{c(x)}) / (1 − Q^{h(x)}),      Q = q².

    Convention scope (added 2026-08-24). The premise below — that the corpus records y_λ only qualitatively as "sign-indefinite for n ≥ 4" (docs/audits/2026-05-19-weight-factor-audit.md §W3) — is a convention-C statement, and C was excised on 2026-08-09. Under the production convention D there is nothing indefinite to resolve: y_λ ≥ 0 on the two-row stratum and y_λ = 0 identically for ℓ(λ) ≥ 3 (QOU.QBeta.TemperleyLiebTower, sorry-free), measured zero-negative over n = 4 … 12 at q₀. The content block mass-theory/y-lambda-sign-pattern withdrew the indefiniteness claim on 2026-08-09; this file was not updated with it.

    The motivating clause below is affected the same way: Mu3SlotExclusion.door_mechanism_dichotomy does make the μ₃ door depend on sign(y_λ), but under D its "negative weight on supermodular geometry" branch is vacuous, so that mechanism has no budget for the reason opposite to the one stated — not because the sign rule is unknown, but because the sign is known and never negative.

    What survives, and why this file is kept. The combinatorial rule derived here is a statement about the Wenzl principal specialisation itself, not about which convention selects z, so the derivation stands as-is and remains the sharp form of the qualitative claim. Read it as characterising sign(s_λ) in general; do not read the motivation as a live μ₃-door opening.

    This file upgrades the qualitative record to a combinatorial rule, because Mu3SlotExclusion.door_mechanism_dichotomy makes the μ₃ door depend on exactly this sign: one of its two mechanisms is "negative weight on supermodular geometry", and without a rule for sign(y_λ) that mechanism has no budget.

    The derivation #

    For q > 1 (so Q > 1):

    • every hook length satisfies h(x) ≥ 1, hence Q^{h(x)} > 1 and every denominator factor 1 − Q^{h(x)} is negative — the denominator contributes the fixed sign (−1)^{|λ|} (wenzl_den_factor_neg, wenzl_den_sign);
    • a numerator factor 1 − Q^r·Q^{c(x)} is negative exactly when Q^r·Q^{c(x)} > 1, i.e. exactly when the cell's content lies above the threshold c* = −log_Q(Q^r).

    Writing P(λ) for the number of cells below the threshold, the two contributions combine — (−1)^{#above} · (−1)^{|λ|} = (−1)^{#below} since #above + #below = |λ| — to give

    sign(s_λ) = (−1)^{P(λ)}                                  (`wenzl_sign`)

    The Q^{n(λ)} prefactor is positive and drops out.

    What this buys #

    Convention C (as recorded). At q₀ under C the threshold is c* ≈ −2.5995, so P(λ) counts cells of content ≤ −3. A cell of content ≤ −3 requires ≥ 4 rows, so every λ with ℓ(λ) ≤ 3 carries a positive weight (shallow_of_no_deep_cells). That is why (8,1) is positive — the case that refutes the naive "ℓ-parity" reading of the measured data. Machine-verified on all 270 partitions for n = 2..12; smallest threshold margin 8.0e-2, far from the 1e-12 degeneracy guard.

    Convention D: hnd is UNSATISFIABLE on the ℓ(λ) ≥ 3 stratum, and this is prior to the y_λ = 0 point made above. D pins r = 2, so Q^r = Q² and c* = −log_Q(Q²) = −2 exactly — an attainable content, at row 3 column 1 of every diagram with ℓ(λ) ≥ 3. There Q^r·Q^{c} = Q²·Q^{−2} = 1 exactly, so the cell is neither above nor below the threshold and the smallest margin is 0.0, not merely small (measured at every n = 3..12). That is exactly the hnd hypothesis of wenzl_sign failing, which by that theorem's own docstring leaves the parity "genuinely undefined, not merely hard to prove".

    Nothing below is thereby refuted: every theorem here is generic in Q and QR and remains correct. What fails under D is the premise, on that stratum — conditional-proved is not premise-established. On the surviving ℓ(λ) ≤ 2 stratum the rule is well-posed but carries no information: the minimum content is −1 while a below-threshold cell needs ≤ −3, so P(λ) ≡ 0 and the predicted sign is the constant +1. The rule's whole discriminating power required ℓ(λ) ≥ 4, precisely the stratum D annihilates. Retired as a live rule and re-recorded in ylambda-sign-content-threshold.witness.json (bean qou-ulxr).

    Honest scope #

    This determines sign(s_λ). Since y_λ = s_λ / Z with a single global Z per n, it determines sign(y_λ) up to that one global sign; the probe verifies sign(Z) = +1 for n = 2..12 but this file does not derive it. The parity rule itself is q-independent for q > 1 — only the location of the cut c* moves with q.

    The sign of a finite product is the parity of its negative factors #

    source
    theorem QOU.MassTheory.YLambdaSignThreshold.neg_one_pow_card_neg_mul_prod_pos {α : Type u_1} [DecidableEq α] {f : α → ℝ} {s : Finset α} :
    (∀ x ∈ s, f x ≠ 0) → 0 < (-1) ^ {x ∈ s | f x < 0}.card * ∏ x ∈ s, f x

    Sign of a finite product. Multiplying a product of nonzero reals by (−1) raised to the number of negative factors makes it positive. This is the combinatorial engine behind the whole file: it turns "count the negative factors" into an actual sign statement.

    The Wenzl denominator: every hook factor is negative #

    source
    theorem QOU.MassTheory.YLambdaSignThreshold.wenzl_den_factor_neg {Q : ℝ} (hQ : 1 < Q) {h : ℕ} (hh : 1 ≤ h) :
    1 - Q ^ h < 0

    Every denominator factor is negative. A hook length is at least 1, and Q > 1, so Q^{h} > 1 and 1 − Q^{h} < 0. No cell escapes this — which is what makes the denominator's sign depend only on the number of cells.

    source
    theorem QOU.MassTheory.YLambdaSignThreshold.wenzl_den_sign {α : Type u_1} [DecidableEq α] {Q : ℝ} (hQ : 1 < Q) (cells : Finset α) (hgt : α → ℕ) (hh : ∀ x ∈ cells, 1 ≤ hgt x) :
    0 < (-1) ^ cells.card * ∏ x ∈ cells, (1 - Q ^ hgt x)

    The denominator contributes the fixed sign (−1)^{|λ|} — it depends on the cell count alone, not on the shape of the diagram.

    The numerator: the content threshold #

    source
    theorem QOU.MassTheory.YLambdaSignThreshold.wenzl_num_factor_neg_iff {v : ℝ} :
    1 - v < 0 ↔ 1 < v

    The threshold criterion. A numerator factor is negative exactly when the cell sits above the threshold, i.e. when Q^r·Q^{c(x)} > 1. This is the only place the content enters, and it enters through a single scalar comparison.

    source
    theorem QOU.MassTheory.YLambdaSignThreshold.card_above_add_card_below {α : Type u_1} (cells : Finset α) (v : α → ℝ) (hnd : ∀ x ∈ cells, v x ≠ 1) :
    {x ∈ cells | 1 < v x}.card + {x ∈ cells | v x < 1}.card = cells.card

    Above-threshold and below-threshold cells partition the diagram. Given no cell sits exactly on the threshold, the two counts sum to the number of cells — the bookkeeping that lets the denominator's (−1)^{|λ|} be absorbed into the numerator's parity.

    The main result #

    source
    theorem QOU.MassTheory.YLambdaSignThreshold.wenzl_sign {α : Type u_1} [DecidableEq α] {Q QR : ℝ} (hQ : 1 < Q) (nlam : ℕ) (cells : Finset α) (val : α → ℝ) (hgt : α → ℕ) (hh : ∀ x ∈ cells, 1 ≤ hgt x) (hnd : ∀ x ∈ cells, QR * val x ≠ 1) :
    0 < (-1) ^ {x ∈ cells | QR * val x < 1}.card * ((Q ^ nlam * ∏ x ∈ cells, (1 - QR * val x)) / ∏ x ∈ cells, (1 - Q ^ hgt x))

    sign(s_λ) = (−1)^{P(λ)}, P(λ) the number of BELOW-threshold cells.

    The Wenzl principal specialisation Q^{n(λ)}·∏(1 − Q^r·Q^{c})/∏(1 − Q^{h}) has sign exactly (−1) to the number of cells whose content lies below the threshold c* = −log_Q(Q^r).

    Both the Q^{n(λ)} prefactor and the denominator's shape drop out: the former is positive, the latter contributes (−1)^{|λ|} which merges with the numerator's (−1)^{#above} to leave (−1)^{#below}. So a global property of the diagram (its size) is invisible, and only the deep cells matter.

    Hypotheses are the honest minimum: Q > 1 (the substrate regime q > 1), hooks positive (automatic for a Young diagram), and no cell exactly on the threshold (hnd) — without which the parity is genuinely undefined, not merely hard to prove.

    source
    theorem QOU.MassTheory.YLambdaSignThreshold.shallow_of_no_deep_cells {α : Type u_1} [DecidableEq α] {Q QR : ℝ} (hQ : 1 < Q) (nlam : ℕ) (cells : Finset α) (val : α → ℝ) (hgt : α → ℕ) (hh : ∀ x ∈ cells, 1 ≤ hgt x) (hnd : ∀ x ∈ cells, QR * val x ≠ 1) (hshallow : ∀ x ∈ cells, 1 < QR * val x) :
    0 < (Q ^ nlam * ∏ x ∈ cells, (1 - QR * val x)) / ∏ x ∈ cells, (1 - Q ^ hgt x)

    No deep cells ⇒ positive. If every cell sits above the threshold, P(λ) = 0 and the weight is positive.

    At q₀ a below-threshold cell needs content ≤ −3, hence ≥ 4 rows. Under convention C that made this exactly the statement that every ℓ(λ) ≤ 3 block carries a positive weight, (8,1) included. Under D read ℓ(λ) ≤ 2: the ℓ(λ) = 3 blocks are not positive but identically zero, and in any case they fail this theorem's own hnd hypothesis, since under D a cell of content −2 sits exactly on the threshold. The theorem itself is unchanged and generic — only which diagrams can satisfy its hypotheses moves with the convention.
