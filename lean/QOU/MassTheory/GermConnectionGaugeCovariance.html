    QOU.MassTheory.GermConnectionGaugeCovariance #

    The germ q-curvature F_q = ⟦δq_i, δq_j⟧ is NOT gauge-covariant, and the transverse NA-Stokes pairing Ω₂ inherits that failure exactly. The covariant second-order object built from the germ is the cup square, and it is identically a coboundary — hence zero in H².

    Bean qou-prjo. Companion to GermRootVectorGaugeFixing (single-generator scope-(b)) and TransversePairingClusterDecomposition (the bilinear cluster decomposition).

    The question this file answers #

    PR #4849 §2.3 recorded that the germ δq = q (∂_q ρ) ρ⁻¹ transforms inhomogeneously — like a connection, not like a tensor — under a q-dependent change of representation basis, and left open whether the pairing Ω₂ is nevertheless covariant. It is not.

    What is proved (sorry-free, generic Ring R) #

    Everything is stated for a bare derivation D of a ring R and units of R. The substrate reading is D = q ∂_q, R = the matrix algebra of a Hecke representation, u = ρ(σ_i), b = B(q) the q-dependent basis change; but no such interpretation is needed for the algebra.

    § Result
    1 IsDeriv.map_one, IsDeriv.inv — derivation basics
    2 germ_mul — the germ is a 1-cocycle: α(uv) = α(u) + Ad(u) α(v)
    3 germ_conj — the connection law: α ↦ Ad(b)(α + (1 − Ad u)Θ), Θ = b⁻¹ D b
    4 germCurvature_conj, germCurvature_covariant_iff — covariance holds iff the defect vanishes
    5 listPairing_map_adAct, transversePairing_covariant_iff_curvature — the pairing is covariant given covariant inputs, so all of the failure sits in F_q
    6 gaugeDefect_witness, germCurvature_not_covariant — a concrete derivation, ring, and units where the defect is !![X², −2X; 0, −X²] ≠ 0
    7 cupSq_eq_neg_coboundary — the cup square ⟦α(u), Ad(u)α(v)⟧ is exactly −∂β with the explicit primitive β = D ∘ α
    8 trace_germ_conj — τ(α(u)) is gauge-invariant for any cyclic trace τ

    How to read the verdict #

    • §4 + §6: F_q is not a tensor. There is no basis-independent ‖Ω₂‖, so the 0 … 897 spread of #4798 and the 16.4× germ-observer spread of #4849 are not merely unchosen — there is nothing to choose between, because the object has no invariant value.
    • §7: the correct covariant second-order object exists and is the cup square in H²(G; R_{Ad ρ}). It vanishes identically — with an explicit primitive — so the covariant version of the order-2 transverse content is zero. The reason is structural: D is a derivation in a single direction (q), and a curvature needs two independent base directions; the generator indices i, j are group elements, not base directions.
    • §8: the surviving gauge-invariant linear functional of the germ is τ(α(u)) = D log det ρ(u), which sees only the abelianisation — i.e. exactly the writhe/framing datum already walled by no_writhe_only_framing.

    What is NOT proved — read before citing #

    • sorry-free ≠ derived. No binding energy, no Δ_λ, no magnitude, no q₀, no AME comparison appears in this file. Nothing is wired.
    • §6 exhibits one ring/derivation/unit triple with a nonzero defect. That refutes "the defect vanishes identically"; it does not compute the defect for the Hecke germ (the probe computations/probes/nastokes_germ_gauge_covariance_probe.py does that, exactly over ℚ(q)).
    • §7 shows the canonical covariant second-order object vanishes. It does not show that no nonzero gauge-invariant functional of the germ exists — §8 exhibits one (an abelian one). Classifying all of them is open.

    Base ring (§7c). Generic non-commutative Ring R throughout §§1–5, 7–8. §6's witness ring is Matrix (Fin 2) (Fin 2) (Polynomial ℚ) — a concrete counterexample carrier, not an archimedean specialisation: no ℝ, no ordering, no Real.* anywhere in the file.
