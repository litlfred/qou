        theorem QOU.MassTheory.colourWeights_nonneg_iff (d : ℝ) :
        0 ≤ wPos d ∧ 0 ≤ wNeg d ↔ |d| ≤ 2

        The threshold. Both weights are non-negative exactly when |δ| ≤ 2. Below it the letter lies in the convex hull of {σ, σ⁻¹} and convex_comb_le_bound applies; above it one weight is negative and the bound has no force.

        theorem QOU.MassTheory.affine_le_max_of_nonneg {w x y M : ℝ} (hw : 0 ≤ w) (hw' : w ≤ 1) (hx : x ≤ M) (hy : y ≤ M) :

        theorem QOU.MassTheory.target_above_max_forces_outside_hull {w x y T : ℝ} (hx : x < T) (hy : y < T) (heq : w * x + (1 - w) * y = T) :
        w < 0 ∨ 1 < w

        The converse that carries the physics. If an affine combination attains a value strictly greater than both endpoints, its weight lies outside [0,1]. So a target above the branch ceiling cannot be reached by any admissible colour weight — it is not a matter of choosing δ well.

        theorem QOU.MassTheory.hull_bound_fails_beyond_threshold :
        ¬0 ≤ wNeg 4 ∧ wPos 4 * 1 + wNeg 4 * 0 > 1

        Non-vacuity: the threshold is sharp. At δ = 4 the weight on σ⁻¹ is −1/2, and the combination (3/2)·1 + (−1/2)·0 = 3/2 exceeds both endpoints — so beyond |δ| = 2 the bound genuinely fails rather than merely losing its proof.
