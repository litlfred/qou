              5. Numerology dismissal — log₂ 3 is irrational #

              theorem QOU.MassTheory.VassilievMagnitudeA3.two_pow_ne_three_pow (a b : ℕ) (ha : 1 ≤ a) :
              2 ^ a ≠ 3 ^ b

              The arithmetic core of log₂ 3 ∉ ℚ: 2^a (a ≥ 1, even) never equals 3^b (odd). Hence log₂ 3 = a/b would force 2^a = 3^b, impossible — so r* ≈ log₂ 3 is a coincidence, not a rational finite-type weight the substrate could produce.
