    The mass channel's two-row cap, derived rather than posited #

    The mass channel restricts its Wedderburn sums to the two-row stratum Λ²(n) = {λ ⊢ n : ℓ(λ) ≤ 2}. Several places in the corpus state that restriction as an assumption, a ≥ 80 % empirical dominance bound, or a conditional class, and then infer convention D from it.

    That implication runs the other way, and both halves are now proved:

    • QOU.QBeta.WenzlWeight.wenzlLevel_conventionD — convention D (z = q³/(q²+1)) is Wenzl level r = 2.
    • QOU.QBeta.WenzlWeight.schurPrincipal_eq_zero_iff — the level-r principal specialisation vanishes iff ℓ(λ) > r, for every n, every λ and every r.

    So at convention D the ≥ 3-row weights are exactly zero, and this file derives the statements the mass channel actually consumes from that fact.

    What is derived here #

    1. massWeight_eq_zero_of_three_rows_of_wenzl — the cap itself.
    2. traceSum_eq_twoRow_of_wenzl — restricting a weighted Wedderburn sum ∑ y_λ · χ_λ to Λ² is an identity, not an approximation.
    3. bindingSum_eq_twoRow_of_wenzl — the same for the binding sum ∑ y_λ · χ_λ · Δ_λ, at every A. The Δ_λ factor multiplies a weight that is already zero, so it cannot reinstate a dropped block.
    4. twoRow_share_eq_one_of_wenzl — the two-row share of a nonzero Wedderburn sum is exactly 1.

    (4) is the statement prop:he4-two-row-dominance should carry. That block currently asserts ≥ 80 %, with an empirical 86.6 %, encoded as a §3b-cond class whose instance pins ratio := 866/1000. Under convention D the true share is 1, so the pinned instance is a convention-C measurement, not a weaker-but-valid bound: a nonzero ≥ 3-row contribution is precisely what convention D forbids. See the audit accompanying this file.

    Non-vacuity #

    An "identity" that held because the filter kept everything would say nothing. exists_three_row_diagram exhibits a diagram the filter drops, and twoRow_filter_ne_univ_of_wenzl shows the dropped weight really is zero while the surviving ones are not (conventionD_weight_ne_zero_of_two_rows upstream). The restriction discards genuine index set and loses no mass.

    What is cited, not proved — read before citing this file #

    Everything here is a theorem about schurPrincipal 2 Q μ / Z, a named explicit rational expression. Reading those theorems as statements about the mass channel's Ocneanu/Markov weight rests on Wenzl's theorem, that the trace weights at Markov parameter z_W = Q^r(1−Q)/(1−Q^r) are those principal specialisations. That is an external input — see the -- Ref: on schurPrincipal — and it is the reason every mass-channel-facing name below carries the _of_wenzl suffix.

    #print axioms will report these declarations clean, and that report does not certify the identification: the dependency is carried by the choice of schurPrincipal as the weight, not by an axiom the kernel can see. Do not quote an axiom-clean check as evidence that the mass channel's weight is this object.

    An independent route to the same vanishing avoids Wenzl entirely — the n = 3 moment pinning TemperleyLiebTower.conventionD_kills_antisymmetriser lifted by QOU.Mathlib.threeRow_vanishing_all_levels — at the cost of an ordered field and a propagation argument. Two routes, different weak points; cap_agrees_with_moment_route_of_wenzl records that they agree.

    Base ring #

    Generic [Field R] throughout (AGENTS.md §7c). Nothing here orders R, takes a root, or evaluates at a substrate value, so specialising to ℝ would be gratuitous. The genericity hypothesis on Q is discharged at the substrate by WenzlWeight.not_root_of_unity_of_pos_ne_one, which lives after the archimedean wall.

    Restriction to the two-row stratum is an identity #

    The mass channel evaluates Wedderburn sums ∑_λ y_λ · χ_λ and restricts the index set to Λ². The two lemmas below say that restriction changes nothing — so it is exact, not a truncation, and carries no error term to bound.

    source
    theorem QOU.MassTheory.TwoRowCap.traceSum_eq_twoRow_of_wenzl {R : Type u_1} [Field R] {Q Z : R} (hQ0 : Q ≠ 0) (hQ : ∀ (k : ℤ), k ≠ 0 → Q ^ k ≠ 1) (hZ : Z ≠ 0) (s : Finset YoungDiagram) (χ : YoungDiagram → R) :
    ∑ μ ∈ s, QBeta.WenzlWeight.schurPrincipal 2 Q μ / Z * χ μ = ∑ μ ∈ s with μ.colLen 0 ≤ 2, QBeta.WenzlWeight.schurPrincipal 2 Q μ / Z * χ μ

    The trace sum restricts exactly.

    For any finite set s of Young diagrams and any per-block observable χ,

    ∑_{μ ∈ s} y_μ · χ_μ = ∑_{μ ∈ s, ℓ(μ) ≤ 2} y_μ · χ_μ

    at convention D. χ is arbitrary — the Hoefsmit character is one instance, but nothing here depends on which observable is summed, because the dropped terms vanish through the weight, whatever multiplies it.

    ∑ μ ∈ s, QBeta.WenzlWeight.schurPrincipal 2 Q μ / Z * χ μ * Δ μ = ∑ μ ∈ s with μ.colLen 0 ≤ 2, QBeta.WenzlWeight.schurPrincipal 2 Q μ / Z * χ μ * Δ μ

    The binding sum restricts exactly too, at every A.

    ∑_{μ ∈ s} y_μ · χ_μ · Δ_μ = ∑_{μ ∈ s, ℓ(μ) ≤ 2} y_μ · χ_μ · Δ_μ

    Δ is arbitrary, so this covers the proved value Δ_λ = (−1)^{n(λ)}·dim V_λ without depending on it. The point is that Δ_λ cannot reinstate a dropped block however large it is on many-row diagrams: it multiplies a weight that is already zero.

    This is the formal content of the claim in def:two-row-stratum that the binding sum "does inherit the restriction, at every A, exactly", and of the 2026-08-09 withdrawal of the opposite reading.

    The two-row share of a nonzero Wedderburn sum is exactly 1.

    prop:he4-two-row-dominance asserts this ratio is ≥ 4/5, with an empirical 86.6 % pinned into a conditional-class instance. At convention D the ratio is 1 on the nose, for every braid word and every strand count — there is no dominance to measure, because there is no complement.

    A measured share strictly below 1 therefore does not refine this bound; it records a nonzero ≥ 3-row contribution, which is exactly what convention D forbids. Such a measurement is convention-C data.

    The two routes agree #

    There are two independent derivations of y₍₁³₎ = 0 at convention D, and they share no premise beyond convention D itself:

    • the moment route, BraidsAndKnots.threeRow_eq_zero_of_jones_ocneanu — from the three Markov moment equations against the H₃(q) character table plus the Ocneanu value z·[2]_q = q². It never mentions Schur functions and cites no external theorem.
    • the Schur route, proved above — from schurPrincipal_eq_zero_iff at the level wenzlLevel_conventionD pins. It never mentions the moment equations, and it costs one citation (Wenzl's weight formula).

    Neither is derivable from the other as stated, so their agreeing is a real check rather than a restatement. It is also the one place the Wenzl citation can be independently corroborated inside the corpus: the moment route reaches the same value without it.

    theorem QOU.MassTheory.TwoRowCap.moment_and_schur_routes_agree_of_wenzl {R : Type u_1} [Field R] {Q Z : R} (hQ0 : Q ≠ 0) (hQ : ∀ (k : ℤ), k ≠ 0 → Q ^ k ≠ 1) (hZ : Z ≠ 0) (q qi z y₃ y₂₁ y₁₃ : R) (hqi : q * qi = 1) (hnorm : y₃ + 2 * y₂₁ + y₁₃ = 1) (hsigma : q * y₃ + (q - qi) * y₂₁ + -qi * y₁₃ = z) (hsigmasigma : q ^ 2 * y₃ + -1 * y₂₁ + qi ^ 2 * y₁₃ = z ^ 2) (hzD : z * (q + qi) = q ^ 2) (hb2ne : q + qi ≠ 0) (h3ne : (q + qi) ^ 2 - 1 ≠ 0) :
    y₁₃ = QBeta.WenzlWeight.schurPrincipal 2 Q (YoungDiagram.ofRowLens [1, 1, 1] ⋯) / Z

    The moment route and the Schur route assign the same three-row weight.

    Given a weight vector satisfying the H₃(q) Markov moment equations at convention D's Ocneanu value, its three-row entry equals the convention-D Schur weight of (1,1,1) — both being zero, each derived without reference to the other.

    The hypotheses are the union of the two routes' own hypotheses and nothing more: no step assumes the conclusion of the other route. In particular this is not a discharge of markovWeights_eq_jones_of_threeRow_eq_zero's hTL; that lemma concludes z·[2]_q = q², so feeding it a convention-D weight would assume what it proves. The direction here is safe because both sides are consequences of convention D rather than premises for it.
