            2. The alternation, at the two orders that matter #

            The classical statement is (-1)^{n-1} φᵀ_n ≥ 0 for a non-negative pair potential, i.e. Mayer variable g ∈ (-1, 0). The probe verified it by sampling at n = 2, 3, 4, 5; the two orders the arc actually uses are proved here. These need an order, so they are stated over a LinearOrderedField.

            source
            theorem QOU.MassTheory.BondArcTheorems.ursell2_nonpos {K : Type u_2} [Field K] [LinearOrder K] {g : K} (hg : g ≤ 0) :
            ursell2 g ≤ 0

            φᵀ₂ ≤ 0. This is what settles the OCR'd exponent: the reading (-1)^n φᵀ_n ≥ 0 would demand φᵀ₂ ≥ 0 and fails immediately.

            source
            theorem QOU.MassTheory.BondArcTheorems.ursell3_pos {K : Type u_2} [Field K] [LinearOrder K] [IsStrictOrderedRing K] {a b c : K} (ha' : a < 0) (hb' : b < 0) (hc : -1 < c) (hc' : c < 0) :
            0 < ursell3 a b c

            φᵀ₃ > 0 for g ∈ (-1, 0) — the opposite sign, and the sign nature has. The proof is the regrouping g₁₂g₁₃ + g₁₂g₁₃g₂₃ = g₁₂g₁₃(1 + g₂₃), in which every factor is positive: two negatives multiply to a positive, and 1 + g > 0 is exactly g > -1.

            Note the hypotheses: all three variables must be negative, but only one of them needs > -1. The repulsive class gives -1 < g < 0 on all three, so the theorem applies; it is stated at the weaker hypothesis because that is what the proof uses, and a Lean file should not carry hypotheses it does not need.

                      5. The crossing counts #

                      level3_em_channel_parity measured n₊ + n₋ = 10A - 2 and n₊ - n₋ = 4Z on 12 nuclei and scoped the claim (a) for that reason. The word is built as a chain: for each nucleon its intra-nucleon letters, then one inter-nucleon letter per adjacent pair. Reading the per-nucleon and per-interface counts off that construction gives closed forms, and the probe verifies they reproduce the implementation exactly on 14 nuclei to A = 100. With the model fixed, the two statistics are theorems.

                            6. What is NOT proved here, and why #

                            • The observed exponents (0.874 for AME2020, 0.780 for the Coulomb reference) and the magic-shell comparison are measurements against data. They are not theorems and nothing here makes them so.
                            • b₃ = -φᵀ₃ does not extend to n = 4. Establishing that needs φᵀ₄, a sum over the 38 connected graphs on four vertices; the probe settles it by exhibiting 200 counterexamples and it is left there.
                            • isovector / isoscalar > 1000 depends on the numeric value of δ at the substrate q₀; §3 proves the two quantities are h/2 and hδ/4, so the ratio is 2/δ, but that it exceeds 1000 is a fact about δ.
                            • The per-nucleon counts (6,3,2) and (5,4,2) in §5 are read off the implementation, not derived from the quark content. §5's theorems are exact given them, and the probe verifies the model reproduces atom_braid_word_3A on 14 nuclei to A = 100. That is what upgrades qou-dhsn's statistics from sampled to proved for this construction — not a proof that the construction is the right one.
