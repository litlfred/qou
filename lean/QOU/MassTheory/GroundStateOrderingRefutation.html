    QOU.MassTheory.GroundStateOrderingRefutation #

    Refutation of the A ≥ 4 clause of prop:ground-state-ordering.

    The proposition claims that the arrangement minimising the quantum dilogarithm volume Φ_q = Σ_i log|V̂_i| is, for A ≥ 4, the interleaved + tail-packed one:

    ordering[k] = proton  ⟺  k odd and k < 2Z.

    This file refutes that clause at A = 5, Z = 1, N = 4, where the prescribed arrangement is n p n n n and the sorted arrangement p n n n n — the one the proposition reserves for A ≤ 3 — is strictly better.

    The readout, and where the Markov parameter enters #

    The corpus builds, at each chain position i, the product M_i = Π_{j>i} T(d_ij) of transfer factors

    T(d) = ![![h + d, 1], ![1, d]] = S + d • 1,   S = ![![h, 1], ![1, 0]],
h = q - q⁻¹,

    and reads off V̂_i = z · (M_i) 1 0 + (M_i) 1 1, where z is the Markov parameter. Every T(d) is a polynomial in the single matrix S, so they all commute (QOU.MassTheory.TransferFactorCommute) and M_i depends on the crossing coefficients only as a multiset. S has tr S = h, det S = -1, hence eigenvalues λ₊ = q and λ₋ = -q⁻¹ (transferEigen_vieta below), and S² = h • S + 1 collapses M_i to α • 1 + β • S. Since S 1 0 = 1 and S 1 1 = 0 we have (M_i) 1 0 = β and (M_i) 1 1 = α, so

    V̂_i = c₊ · μ₊ + c₋ · μ₋,      μ± = Π_{j>i} (λ± + d_ij),
c₊ = (z + q⁻¹)/(q + q⁻¹),     c₋ = (q - z)/(q + q⁻¹).

    z enters nowhere else. The three crossing coefficients used by the corpus contribute the z-free eigenfactor pairs

    d = 0     (pp)   :  μ₊ ·= q     μ₋ ·= -q⁻¹
d = -h/2  (pn)   :  μ₊ ·= c     μ₋ ·= -c      ,  c = (q + q⁻¹)/2
d = -h    (nn)   :  μ₊ ·= q⁻¹   μ₋ ·= -q

    which is what cMix, and the μ± arguments in sortedV0…sharedV3 below, encode.

    Convention independence (the point of this file) #

    This refutation was originally written in convention C, z = √q/(q+1), which the owner ruling of 2026-08-15 excises in favour of convention D, z = q³/(q²+1). The argument does not depend on either: it never reads z's formula. Two facts do all the work.

    • c₊ + c₋ = 1 identically in z (cPlus_add_cMinus) — the two weights are an affine partition of unity whatever z is.

    • The whole A = 5 comparison collapses to the single identity (readout_gap, weight_prod)

      V̂₀V̂₁(prescribed) - V̂₀V̂₁(sorted) = 2·c₊·c₋·c⁴·(q⁶ - 1)/q³,
4·c₊·c₋ = 4q(q - z)(qz + 1)/(q² + 1)².

    So for q > 1 the refutation holds exactly when both readout weights are positive, i.e. exactly when -q⁻¹ < z < q: the Markov parameter lies strictly between the two eigenvalues of the transfer matrix. Convention C and convention D both lie in that window for every q > 1 (zC_lt_self, zD_lt_self), with room to spare — at the proton anchor q₀ ≈ 1.10998 the weights are (0.6963, 0.3037) under C and (0.7527, 0.2473) under D.

    This is the same disposition as QOU.QBeta.BraidImageEigenphaseExclusion: generalise over z carrying the shared property as a hypothesis, rather than re-derive. Note that nothing here substitutes z_D into a C-frame conclusion — the generalisation happens at the point where z first enters the derivation, which is the readout itself.

    What is proved here #

    sorted_lt_prescribed_A5 : for every q > 1, every z with both readout weights positive, and every q at which the sign condition hU holds, the two chain positions at which the two arrangements differ satisfy

    |V̂₀ · V̂₁| (sorted)  <  |V̂₀ · V̂₁| (prescribed).

    The remaining two positions carry identical readouts (sharedV2, sharedV3), so this is exactly Φ_q(pnnnn) < Φ_q(npnnn), and the prescribed arrangement is therefore not the minimiser. Nothing here is assumed: hU is a plain sign condition on the sorted readout, discharged for convention D on 1 < q ≤ 6/5 (sortedV1_zD_nonneg, which contains the substrate anchor) and for convention C in the committed polynomial form (sortedV1_zC_eq).

    Scope note: this is a scope-(b) structural exclusion for the clause — a counterexample, valid for a whole interval of q containing the substrate anchor and for every admissible Markov parameter, not a "the numbers came out wrong" scope-(a) negative.

                        The A ≥ 4 clause of prop:ground-state-ordering is FALSE.

                        At A = 5, Z = 1, N = 4 the arrangement prescribed by rules (i)+(ii) is n p n n n. For every q > 1, every Markov parameter z whose two readout weights are positive, and under the sign hypothesis hU on the sorted readout, the sorted arrangement p n n n n — which the proposition reserves for A ≤ 3 — has a strictly smaller readout product at the two positions where the arrangements differ:

                        |V̂₀ V̂₁| (sorted)  <  |V̂₀ V̂₁| (prescribed).
