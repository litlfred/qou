    theorem QOU.MassTheory.A3PrecisionOrderSeparation.bounded_order_term_le {R : Type u_1} [Field R] [LinearOrder R] [IsStrictOrderedRing R] {a c h2 B : R} (hc : 0 ≤ c) (hh : 0 ≤ h2) (ha : |a| ≤ B) :
    |a * c * h2| ≤ B * c * h2

    Bounded coefficient ⇒ bounded higher-order contribution. A higher-order cluster term a · c · h² with a coefficient bounded by |a| ≤ B contributes at most B · c · h² in magnitude (for 0 ≤ c, 0 ≤ h²). This is the structural fact behind the tail bound: routine (bounded- coefficient) higher orders cannot exceed B·c·h² per order.

    theorem QOU.MassTheory.A3PrecisionOrderSeparation.bounded_tail_lt_miss :
    0.297 * 2 * 437062e-7 / (1 - 437062e-7) < 0.17376892

    The full bounded (|aₖ| ≤ 2) higher-order tail closes ≤ 0.7% of the ratio — ≪ the 4.56% miss. The geometric tail c₃·2·h²/(1−h²) at the corpus values (c₃ = 0.297, h² = 0.0437062) is < 0.0272, far below the miss Δ = 0.17376892. So even summing every bounded higher order cannot close the A=3 miss.

    theorem QOU.MassTheory.A3PrecisionOrderSeparation.required_coeff_gt_thirteen :
    0.17376892 / (0.297 * 437062e-7) > 13

    A higher-order closure would need an anomalous h⁶ coefficient a₁ > 13 — 13× the O(1) natural size (h² ≈ 0.0437), a fit red-flag (cf. the Q_β c₃ 1/u³ hypersensitivity). Here a₁ = Δ/(c₃·h²) = 0.17376892/(0.297·0.0437062).

    theorem QOU.MassTheory.A3PrecisionOrderSeparation.a3_precision_needs_leading_channel :
    0.297 * 2 * 437062e-7 / (1 - 437062e-7) < 0.17376892 ∧ 0.17376892 / (0.297 * 437062e-7) > 13 ∧ 3.3420311 / 3.8128 > 0.87

    Capstone — A=3 precision is Δ_λ-gated, not a higher-order refinement. The bounded higher-order tail is below the miss (bounded_tail_lt_miss) while the graded baseline dominates (graded_baseline_dominates); closing the miss by higher orders needs an anomalous coefficient (required_coeff_gt_thirteen). So the routine higher-cluster-order route is order-separated out — precision improvement requires a new leading-order (h⁴) channel (the Δ_λ closure). scope-(a); no fit.
