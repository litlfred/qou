    Type (max (max (max (max (max (max u_1 u_2) u_3) u_4) u_5) u_6) u_7)

    Branching data: two Frobenius pairings embedded in a third through a disjoint-union map, with branching multiplicities c and the weight identity.

    • D₁ : FrobeniusPairingData R A₁ Λ₁

      The pairing on the first factor.

    • D₂ : FrobeniusPairingData R A₂ Λ₂

      The pairing on the second factor.

    • D : FrobeniusPairingData R A Λ

      The pairing on the composite.

    • tensor : A₁ → A₂ → A

      The disjoint-union embedding a ⊗ b.

    • c : Λ₁ → Λ₂ → Λ → ℕ

      Branching multiplicities c^λ_{μν}.

    • branching (a : A₁) (b : A₂) (l : Λ) : self.D.χ l (self.tensor a b) = ∑ μ : Λ₁, ∑ ν : Λ₂, ↑(self.c μ ν l) * (self.D₁.χ μ a * self.D₂.χ ν b)

      The restriction rule for characters on a free product.

    • weight_branching (μ : Λ₁) (ν : Λ₂) : ∑ l : Λ, self.D.y l * ↑(self.c μ ν l) = self.D₁.y μ * self.D₂.y ν

      The weight identity Σ_λ y_λ c^λ_{μν} = y_μ y_ν.
