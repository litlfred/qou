    The structural invariant: a normalized reweighting is bounded by the max block #

    source
    theorem QOU.MassTheory.GeometricWLambdaA4Helium.normalized_reweight_abs_le_bound {ι : Type u_1} [Fintype ι] (W x : ι → ℝ) (B : ℝ) (hW : ∀ (i : ι), 0 ≤ W i) (hsum : ∑ i : ι, W i = 1) (hbound : ∀ (i : ι), |x i| ≤ B) :
    |∑ i : ι, W i * x i| ≤ B

    Weighted-average bound. Let W : ι → ℝ be a non-negative measure (0 ≤ W i) that sums to one (∑ W i = 1), and let x : ι → ℝ be per-block values with |x i| ≤ B for every i. Then the reweighted total is bounded by B:

    |∑ i, W i * x i| ≤ B.

    This is the structural reason the s5-so3 interface magnitude E₀·Σ_λ W_λ χ_λ (any normalized color-tube weight W, geometric or otherwise) is bounded by E₀·max_λ|χ_λ|: a normalized reweighting produces a weighted AVERAGE, never exceeding the largest block.

              theorem QOU.MassTheory.GeometricWLambdaA4Helium.targets_within_bound :
              B4He < maxCharBound ∧ absMu4 < maxCharBound

              The normalized-measure bound does NOT exclude the targets. E₀·max|χ| = 266 MeV is strictly greater than both B(⁴He) = 28.296 and |μ₄| = 4.591, so the weighted-average bound normalized_reweight_abs_le_bound does NOT forbid a normalized reweighting from reaching the target. Therefore the A=4 magnitude gap is NOT a scope-(b) structural exclusion — the target is reachable in principle by SOME normalized W.

              Capstone: WALL(scope-(a)) — bracketed but not closed, and not excluded #

              source
              theorem QOU.MassTheory.GeometricWLambdaA4Helium.a4_magnitude_bracketed_not_closed_not_excluded :
              (prodMagnitude < B4He ∧ B4He < geomMagnitude) ∧ geomMagnitude ≠ B4He ∧ B4He < maxCharBound ∧ (prodMagnitude < absMu4 ∧ absMu4 < geomMagnitude) ∧ geomMagnitude ≠ absMu4 ∧ absMu4 < maxCharBound

              (CAPSTONE) The s5-so3 interface reweighting BRACKETS but does not CLOSE the A=4 magnitude, and does not EXCLUDE it — WALL(scope-(a)).

              For each AME target t ∈ {B(⁴He), |μ₄|} the forward, 0-fit computation establishes, simultaneously:

              • bracket — prodMagnitude < t < geomMagnitude: the two canonical reweightings (production y_λ, geometric d_q²/D²) straddle the target;
              • no closure — geomMagnitude ≠ t: the canonical geometric endpoint overshoots, it does not land on the target;
              • not excluded — t < maxCharBound: the normalized-measure bound (normalized_reweight_abs_le_bound) lies above the target, so no invariant forbids reaching it.

              Hence the A=4 magnitude is open at scope-(a): the s5-so3 interface operator does not supply it as-is (this construction alone), but the target is reachable in principle — an EXACT hit needs an intermediate, TUNED weight (a FIT), which the anti-fit discipline declines. This mirrors the completely-bracketed A=3 magnitude. No μ₄/B(⁴He) inversion; nothing wired.
