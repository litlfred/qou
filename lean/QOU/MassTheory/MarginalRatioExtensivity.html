    Marginal-ratio criteria for extensivity — and why "ratios rising to 1" proves nothing #

    What this file is for. A chain binding total B(A) is a sum over A-1 bonds. Its marginal m(A) = B(A) - B(A-1) is what the A-th nucleon adds, and extensivity is exactly the statement that m has a nonzero limit: if m(A) → c > 0 then B(A) ~ cA, and if m(A) → 0 fast enough to be summable then B is bounded and not extensive at all. So the behaviour of the marginal sequence is not a side observation — it is the extensivity question, which docs/audits/2026-06-02-binding-intensive-vs-extensive-derivation.md and the qou-brng channel taxonomy both identify as the live blocker.

    Measured on the pure single-species chains (PRs #6336, #6365, and the A=5 continuation), the ratios r(A) = m(A+1)/m(A) are:

    pp   0.847753, 0.898991, 0.953066     rising toward 1
nn   0.386424, 0.367352, 0.314444     falling

    The claim this file was written to CHECK, and refutes #

    I wrote, in a merged PR body and in a probe, that a ratio sequence rising monotonically toward 1 from below is "the signature of a marginal bond converging to a NONZERO limit -- saturation rather than collapse."

    That is false, and ratio_rising_to_one_insufficient below exhibits the counterexample: r k = (k+1)/(k+2) is strictly increasing, lies strictly in (0,1), tends to 1, and its partial products are exactly 1/(n+1), which tends to 0. Rising-to-1 is necessary but not sufficient; the correct criterion is summability of 1 - r, which one_sub_sum_le_prod_one_sub supplies in the usable direction.

    What survives, and what it costs #

    • The nn reading survives and is now a scope-(b) structural exclusion with a named invariant: prod_le_pow_of_le shows a ratio sequence bounded above by c < 1 forces the partial products below c^n. The measured nn ratios are all ≤ 0.387, so that collapse is geometric and unconditional.
    • The pp reading does not survive as stated. Worse for it, the corpus already proved the total is bounded — |tr_M| is a bounded trace and its free-atom difference saturates — and B_tot = E₀·(S_off - S_on) is that difference. card_large_marginals_le turns a bounded total into the finite statement that only boundedly many marginals can exceed any ε > 0, so a nonzero limit is excluded outright.

    The corrected picture is therefore not "pp saturates, nn collapses" but both collapse, at wildly different rates — pp so slowly that four points cannot see it, which is exactly what a 1 - r ~ c/k tail looks like.

    Scope #

    Everything here is a statement about real sequences: no substrate, no q, no anchor. ℝ rather than a generic CommRing is correct under §7c because every statement uses the ordering. Nothing is wired; the file's role is to say which readings of a measured ratio sequence are licensed and which are not.

        3. The correct criterion, in the usable direction #

        Weierstrass: ∏ (1 - a i) ≥ 1 - ∑ a i. So a finite measurement plus a tail bound on ∑ (1 - r) gives a genuine positive lower bound on the product — which is what a claim of extensivity actually needs.

        source
        theorem QOU.MassTheory.MarginalRatio.one_sub_sum_le_prod_one_sub {a : ℕ → ℝ} (h0 : ∀ (i : ℕ), 0 ≤ a i) (h1 : ∀ (i : ℕ), a i ≤ 1) (n : ℕ) :
        1 - ∑ i ∈ Finset.range n, a i ≤ ∏ i ∈ Finset.range n, (1 - a i)

        1 - ∑_{i<n} a i ≤ ∏_{i<n} (1 - a i) for a i ∈ [0,1].

        Read with a i = 1 - r i: if the gaps to 1 sum to less than 1, the product is bounded below by a positive constant, so the marginal cannot collapse. This is the sufficient condition the counterexample above shows is missing — and note it is checkable from finitely many measured terms plus a bound on the tail, never from the measured terms alone.

        4. A bounded total excludes a nonzero marginal limit #

        This is the one that settles the pp case, given the corpus result that the trace binding is intensive (bounded). Stated finitely — no filters — so it can be applied to a measured, finite sequence directly.

        source
        theorem QOU.MassTheory.MarginalRatio.card_large_marginals_mul_le {m : ℕ → ℝ} {M ε : ℝ} (h0 : ∀ (i : ℕ), 0 ≤ m i) (hM : ∀ (n : ℕ), ∑ i ∈ Finset.range n, m i ≤ M) (n : ℕ) :
        ↑{i ∈ Finset.range n | ε ≤ m i}.card * ε ≤ M

        If the marginals are nonnegative and every partial sum is at most M, then for any ε > 0 the number of marginals reaching ε is bounded: their count times ε is at most M.

        Consequence for the binding: a bounded total (which is what "the binding is intensive" says) permits only boundedly many marginals above any threshold, so m(A) → c > 0 is impossible. Both chains' marginals therefore go to zero, and the measured question is only how fast.

        source
        theorem QOU.MassTheory.MarginalRatio.card_large_marginals_le {m : ℕ → ℝ} {M ε : ℝ} (hε : 0 < ε) (h0 : ∀ (i : ℕ), 0 ≤ m i) (hM : ∀ (n : ℕ), ∑ i ∈ Finset.range n, m i ≤ M) (n : ℕ) :
        ↑{i ∈ Finset.range n | ε ≤ m i}.card ≤ M / ε

        The usable form: at most M / ε of the first n marginals reach ε.

        This is the bound that actually excludes a nonzero limit — if m(A) → c > 0 then every sufficiently large A has m(A) ≥ c/2, i.e. unboundedly many, contradicting the fixed ceiling M / (c/2). Unlike the multiplicative form above it genuinely needs 0 < ε, which is why both are stated.

        5. Average understates the marginal #

        Formalises why reporting B(A)/(A-1) (as #6336 did) hides how fast the underlying quantity moves: the average of an antitone sequence is at least its last term.

        source
        theorem QOU.MassTheory.MarginalRatio.sum_ge_card_mul_last {m : ℕ → ℝ} (hanti : Antitone m) (n : ℕ) :
        ↑n * m n ≤ ∑ i ∈ Finset.range n, m i

        For an antitone marginal sequence, the running average dominates the last marginal. So an average that has fallen by x % sits on a marginal that has fallen by at least x % — the average is a lagging indicator, never a leading one.

        6. The chain channel has a closed form, and NO parameter makes it extensive #

        Measured on the pure chains (this PR), the bonded and free trace sums are each exactly geometric, and their ratio is exactly the corpus bond factor:

        S_on(A) / S_off(A) = f ^ (A - 1)          exact to 18 digits at every A
S_off(A + 1) / S_off(A) = g              constant to 20 digits

pp   g = 1.1457596924573008697   f = 0.6126880371464652516  (= z_D)
nn   g = 0.98774368811580957163  f = 0.403627738350825936

        so the whole channel is

        B(A) = E₀ · S_off(2) · g ^ (A - 2) · (1 - f ^ (A - 1))

        which reproduces all four measured points to 1e-30 relative — two constants against four points, i.e. an identity, not a fit. It is exactly the form the qou-brng taxonomy calls Channel 2, Δtr = tr_free · (1 - f^bonds).

        The exclusion. Extensivity needs B(A) ~ cA with c > 0. The two lemmas below split on g and neither branch can be linear:

        • chain_bounded_of_growth_le_one — for g ≤ 1 the channel is bounded above by S, so it cannot match an unbounded linear function. This is the branch the corpus's "the binding is intensive" claim describes, and the nn chain sits in it (g < 1).
        • chain_geometric_lower_of_growth_gt_one — for g > 1 each step multiplies by at least g, so B(n) ≥ B(0) · g ^ n: growth is at least geometric, and a linear function is eventually exceeded by any g ^ n with g > 1. The pp chain sits in this branch (g > 1).

        So g < 1 and g = 1 are too slow and g > 1 is too fast; linear is unreachable for every parameter value.

        That combination step was PROSE when first written, and §8 now proves it. The two lemmas above are the branches; the conclusion drawn from them was a docstring sentence, while being billed as a scope-(b) exclusion. §8's chain_never_exactly_linear supplies the missing proof — and by a shorter route that needs no case split on g at all. Read the exclusion there, not here.

        This also SCOPES a corpus claim. 2026-06-02-binding-intensive-vs-extensive- derivation.md states the binding is intensive (bounded). That is the g ≤ 1 branch and is correct for the neutron chain; the proton chain has g > 1 and is unbounded, so "intensive" is not universal over this construction. The exclusion above holds either way, which is why it is the right thing to lean on.

        S * g ^ n * (1 - f ^ k) ≤ S

        For g ≤ 1 and f ∈ [0,1], the chain channel is bounded by S. Bounded means not linear, so this branch cannot be extensive.

        theorem QOU.MassTheory.MarginalRatio.chain_step_ge_growth {S g f : ℝ} (hS : 0 ≤ S) (hg0 : 0 ≤ g) (hf0 : 0 ≤ f) (hf1 : f ≤ 1) (n k : ℕ) :

        For g > 1 and f ∈ [0,1), each step multiplies the channel by at least g. Iterating, B n ≥ B 0 * g ^ n — at least geometric growth, which a linear function cannot match.

        7. The OTHER channel is exactly extensive — and g is why #

        Section 6 excluded the difference channel B = S_off - S_on from extensivity for every g. The corpus's own answer to that has been the log-ratio, which log_ratio_binding_prototype.py asserts in one sentence: "the EXTENSIVE invariant is the log-ratio." That assertion now has a derivation, from the same identity, and it is exact rather than approximate.

        Write the measured structure with b = A - 1 bonds:

        S_off = g ^ (b + 1)          (free: A disjoint identical blocks)
S_on  = g ^ (b + 1) * f ^ b  (bonded: one factor of f per bond)

        Then logRatio_linear_in_bonds gives

        log (S_off / S_on) = -b * log f

        exactly linear in the bond count, verified numerically to 1e-30 on both species at A = 2,3,4,5, with slope

        -E₀ * log f  =  2.05070969238143369 MeV/bond   (pp)
-E₀ * log f  =  3.79778293514235333 MeV/bond   (nn)

        the pp value being exactly the Sec.10a chain bond -α·ln z.

        The mechanism is g, and it is one line. logRatio_independent_of_growth says the log-ratio does not depend on g at all: the free-trace growth g^(b+1) appears in numerator and denominator and cancels. The difference channel cannot cancel it — that is precisely what §6's two branches are about. So the two channels are not two guesses at one quantity; they differ by whether the single-nucleon growth survives, and that is why one is extensive and the other provably never is.

        Scope. This says the log-ratio channel has the right shape. It says nothing about its magnitude being right, and the corpus's measurement is that it is not: the t7qv arc measures B(4He) = 10.387 MeV against AME 28.296 (-63 %), with the three-body term negative at all eight A=3 orderings and the four-body term negative in 80/80 random bond orders — every many-body correction pushing further from the data. Extensive-and-short is a different problem from not-extensive, and this file only settles which of the two each channel has.

        source
        theorem QOU.MassTheory.MarginalRatio.logRatio_linear_in_bonds {g f : ℝ} (hg : 0 < g) (hf : 0 < f) (b : ℕ) :
        Real.log (g ^ (b + 1) / (g ^ (b + 1) * f ^ b)) = -↑b * Real.log f

        The log-ratio of free to bonded trace is exactly linear in the bond count, with slope -log f. This is the derivation behind the corpus's "the extensive invariant is the log-ratio".

        source
        theorem QOU.MassTheory.MarginalRatio.logRatio_independent_of_growth {g₁ g₂ f : ℝ} (hg₁ : 0 < g₁) (hg₂ : 0 < g₂) (hf : 0 < f) (b : ℕ) :
        Real.log (g₁ ^ (b + 1) / (g₁ ^ (b + 1) * f ^ b)) = Real.log (g₂ ^ (b + 1) / (g₂ ^ (b + 1) * f ^ b))

        The mechanism. The log-ratio is independent of the free-trace growth g: it cancels between numerator and denominator. The difference channel of §6 cannot cancel it, which is exactly why that one is never extensive and this one always is.

        8. The exclusion itself — previously prose, now proved #

        A gap in my own work, closed here. §6 proved the two branches — bounded for g ≤ 1, at-least-geometric for g > 1 — and then combined them in a docstring sentence ("bounded is too slow to be linear and geometric is too fast") to conclude that no g makes the channel extensive. That conclusion was billed as a scope-(b) exclusion while existing only as prose. The branches were proved; the exclusion was not.

        It turns out the exclusion has a much stronger and shorter proof than the asymptotic argument, and it needs only three bond counts.

        Write the channel bond-indexed to avoid ℕ subtraction:

        chainB S g f b = S * g ^ (b + 1) * (1 - f ^ b)

        Suppose it were exactly linear, chainB b = c * b for every b with c > 0. Evaluating at b = 1, 2, 3 and eliminating S:

        g * (1 + f) = 2          from b = 1, 2
g² * (1 + f + f²) = 3    from b = 1, 3

        Then 4 * (ii) - 3 * (i)² gives g² * (f - 1)² = 0, so f = 1 — which makes the channel identically zero, contradicting c > 0. One computation, every (g, f) at once, with no case split on g and no limit.

        chain_never_exactly_linear is that argument.

        What is proved here, and what is NOT #

        Proved. Exact linearity is refuted for every (g, f) (chain_never_exactly_linear); the §6 iteration claim (chain_ge_geom_iterated); and the g ≤ 1 half of the asymptotic exclusion (bounded_not_eventually_above_line) — a bounded channel is overtaken by every positive line, stated finitely so no filters are needed.

        NOT proved, and this is the honest residue. The g > 1 half of the asymptotic exclusion. chain_ge_geom_iterated gives the geometric lower bound, but the step from "grows at least like g^m" to "eventually exceeds every line" — the standard fact that a geometric sequence outgrows a linear one — is not formalised here. So:

        • exact linearity is excluded for all (g, f) — fully proved;
        • asymptotic linearity is excluded for g ≤ 1 — fully proved;
        • asymptotic linearity for g > 1 rests on that one standard growth fact.

        Since the measured g_pp = 1.1458 > 1, the proton chain is precisely the case sitting on the unformalised step. Anyone citing the exclusion asymptotically for pp should cite it as resting on that fact, not as fully mechanised.

        Also not formalised, and not a Lean question. That S_off(A) = g^A — the factorisation of the weighted Schur–Weyl sum over the disjoint per-nucleon blocks — is verified numerically at A = 1..5 to 20 digits and is an algebra fact about the Hecke construction, not about real sequences. Likewise f_pp = z_D (agreement 2.8e-31) is a computation, not a theorem. Everything in this file is conditional on those inputs being what the probes measured.

          9. The chain bond set cannot produce the alpha binding — parameter-free #

          The strongest statement in this file, and the one that needs no model constants at all.

          Three inputs, none of them a fitted parameter.

          1. The bond set is the chain, and that is forced, not chosen: QOU.Mass.StrandLayoutForcesChain (sibling arc, lean-direct exit 0) shows a single generator σ_m joins two different nucleons only when m % 3 = 2, and then only consecutive ones, under the 3-strands-per-nucleon layout.
          2. The channel is exactly pairwise-additive over that bond set. Measured at every composition of A = 3 and A = 4 to 1.8e-50 (logratio_exactly_pairwise_additive_probe): S_on/S_off is exactly the product of the bond factors, so L is a sum of per-bond terms with identically zero many-body correction.
          3. AME2020.

          Laying a chain out p…p n…n, the bond multiset of (Z, N) is (Z-1) pp, one pn, (N-1) nn. Writing p = Z-1, n = N-1, those multisets satisfy an exact identity:

          bonds(3H) + bonds(3He) - bonds(2H) = bonds(4He)      (1,1,1) both sides

          so any additive functional on them obeys

          B(4He) = B(3H) + B(3He) - B(2H)

          with the per-bond values cancelling out entirely. Against AME:

          predicted  13.975275 MeV
AME        28.295661 MeV        ratio 2.0247

          So the ADJACENT bond set is refuted for 4He, and not by being short. It is refuted whatever the per-bond values are — no rescaling of f_pp, f_pn, f_nn can help, because they do not appear in the relation.

          🛑 SCOPE CORRECTION — "all three repairs are closed" was WRONG #

          A first version of this section claimed the three obvious repairs were each closed: bond count forced, many-body zero, per-bond values cancel. The first of those is not closed, and the error was mine.

          StrandLayoutForcesChain forbids a single generator from joining non-consecutive nucleons. It does not forbid a bond routed through several generators. The sibling arc does exactly that — four_body_term_and_the_h12_collapse_probe.py:224: "bond between nucleons i<j: strand 3i+2 routed rightwards to strand 3j", with line 324 branching to a single generator only when j = i+1 and to band_between otherwise.

          Band-routed bonds are therefore a live escape, and they are precisely where the structure this file measures as absent reappears:

          • the adjacent bond set is exactly multiplicative, hence order-independent and many-body-free — measured to 1.8e-50;
          • band-routed bonds do not commute. The sibling measures an insertion-order spread of 11.12 % over one A=3 triangle's six orders and 38–40 % over 4He's, "with the outliers exactly those putting the band-routed bond between the two adjacent ones".

          That also explains the numerical disagreement between the two arcs: their B(4He) = 10.387277 against this file's adjacent-only 8.682248, a 19.6 % gap far too large to be the ~1e-4 colour arm. Two different bond sets, both computed correctly.

          What actually survives #

          The refutation stands on the adjacent bond set — which is what atom_canonical_crossings builds and what every measurement in this file uses. Restated honestly, the three repairs are:

          repair status

            10. NO bond topology works — the exclusion is not about the chain #

            §9 refuted the adjacent bond set, and §9's own scope correction named band-routed bonds as the escape. This closes that escape for every additive model, on every topology.

            The enumeration. A nucleus's available bonds are fixed by its nucleon multiset: 2H {p,n} has one pn slot; 3H {p,n,n} has two pn and one nn; 3He {p,p,n} one pp and two pn; 4He {p,p,n,n} one pp, four pn, one nn. Requiring at least a spanning tree's worth of edges and calibrating sPP, sPN, sNN from 2H, 3H, 3He, an exhaustive search over every remaining graph gives:

            exact solutions reproducing AME B(4He)   0

short by                                 1.3703x

            and the maximum is attained at the complete graph on 4He, (1,4,1), with sPP = 5.493477, sPN = 2.224566, sNN = 6.257232. There is nothing left to add: every edge the nucleon multiset permits is already in.

            🛑 What this does NOT exclude, and it is the whole remaining freedom #

            Additivity is the hypothesis, and band-routed bonds violate it. This file measures the adjacent bond product to be exactly multiplicative, hence order-independent; the sibling arc measures band-routed bonds as non-commuting, with an insertion-order spread of 11.12 % over one A=3 triangle and 38–40 % over 4He's. A non-additive B is not of the form Σ_edges s_type and is therefore outside this theorem.

            So the honest frontier, after §9's correction and this section, is narrow and well-posed:

            • additive, any topology, species-only bond values — excluded (here);
            • the only source of non-additivity in the construction is band routing;
            • the sibling measures its many-body contribution negative in 80/80 random bond orders — the wrong sign to close a shortfall.

            That last line is their measurement, cited not re-derived, and 80/80 is strong evidence rather than a proof. Whether a band-routed structure with a positive many-body contribution exists is the open question, and it is now the only one left standing between this channel and the binding table.
