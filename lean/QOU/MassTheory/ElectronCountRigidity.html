    1. The mass shape, and relational mass (generic R) #

    source
    def QOU.MassTheory.ElectronCountRigidity.nucleonMass {R : Type u_1} [CommRing R] (d : ℕ) (E : R) (c : ℕ) (mₑ : R) :
    R

    The canonical nucleon-mass shape: a block multiplicity d, a constituent energy E, and an integer count c of subtracted electron masses mₑ.

    `nucleonMass d E c mₑ = d * (E - c * mₑ)`

    Instantiated in the corpus at d = dim V_{(2,1)} = 2, c = |S₃| = 6, E = m_μ · F_Bor.

      theorem QOU.MassTheory.ElectronCountRigidity.nucleonMass_factors {R : Type u_1} [CommRing R] (d : ℕ) (G : R) (c : ℕ) (mₑ : R) :
      nucleonMass d (mₑ * G) c mₑ = mₑ * (↑d * (G - ↑c))

      Relational mass — the factorisation. When the constituent energy is itself mₑ times a dimensionless factor G (as it is: E = m_μ·F_Bor with m_μ = mₑ·Vol(4₁)/ℏ_q²), the whole mass is mₑ times a dimensionless number.

      There is no intrinsic mass in the formula: only the ratio m/mₑ is predicted.

      theorem QOU.MassTheory.ElectronCountRigidity.nucleonMass_homogeneous {R : Type u_1} [CommRing R] (d : ℕ) (G : R) (c : ℕ) (mₑ lam : R) :
      nucleonMass d (lam * mₑ * G) c (lam * mₑ) = lam * nucleonMass d (mₑ * G) c mₑ

      Relational mass — homogeneity of degree 1 in mₑ. Rescaling the electron mass rescales the nucleon mass by exactly the same factor.

      This is the falsifiable content of "mass is relational": a formula carrying an mₑ² term, or an additive constant with mass dimension not supplied by mₑ, would fail this.

      2. The additive term is not absorbable (generic R) #

      The count enters with an exact, E-independent gap. This is what makes it observable — and it is the algebraic engine of §3.

      source
      theorem QOU.MassTheory.ElectronCountRigidity.nucleonMass_sub_count {R : Type u_1} [CommRing R] (d : ℕ) (E : R) (c c' : ℕ) (mₑ : R) :
      nucleonMass d E c mₑ - nucleonMass d E c' mₑ = ↑d * mₑ * (↑c' - ↑c)

      Exact gap between counts. Changing the electron count from c to c' shifts the mass by exactly d · mₑ · (c' - c), independently of the constituent energy E.

      The E-independence matters: the shift cannot be reabsorbed by re-tuning the multiplicative dressing at fixed c, because the dressing enters through E and cancels here.

      theorem QOU.MassTheory.ElectronCountRigidity.nucleonMass_delete_term {R : Type u_1} [CommRing R] (d : ℕ) (E : R) (c : ℕ) (mₑ : R) :
      nucleonMass d E 0 mₑ - nucleonMass d E c mₑ = ↑d * ↑c * mₑ

      Deleting the additive term entirely (count 0) shifts the mass by exactly d · c · mₑ — for the corpus instance, 2 · 6 · mₑ = 12 mₑ ≈ 6.13 MeV.

      3. Rigidity: the count is forced by the data (archimedean, ℝ) #

      The theorem that distinguishes a count from a convention. A convention can be changed without observable consequence. This count cannot: any two integer counts that both reproduce an observed mass to better than half the gap must be the same integer.

      source
      theorem QOU.MassTheory.ElectronCountRigidity.count_unique_of_close (d : ℕ) (hd : 0 < d) (E mₑ m_obs : ℝ) (hme : 0 < mₑ) (c c' : ℕ) (h : |nucleonMass d E c mₑ - m_obs| < ↑d * mₑ / 2) (h' : |nucleonMass d E c' mₑ - m_obs| < ↑d * mₑ / 2) :
      c = c'

      Count rigidity. If integer counts c and c' both reproduce the observed mass m_obs to within d·mₑ/2, then c = c'.

      For the corpus instance d = 2 the tolerance is exactly one electron mass: any measurement of m_p good to better than mₑ ≈ 0.511 MeV pins the electron count uniquely. The actual residual at c = 6 is ≈ 1.3·10⁻⁶ MeV, roughly 4·10⁵ times inside the window — so the count is not merely determined, it is determined with enormous margin.

      This is the formal statement that the additive term is not a unit convention: a convention admits many equally good values, and this admits exactly one.

      c = c'

      The proton instance. At d = dim V_{(2,1)} = 2 the rigidity window is exactly one electron mass.

      Read against the numerics (me_additive_term_structure.py): the observed residual at c = |S₃| = 6 is ≈ 1.3·10⁻⁶ MeV, far inside the window, while the nearest competing integer c = 7 misses by ≈ 1.02 MeV — twice outside it. So |S₃| is the unique integer count compatible with the measured proton mass.
