            3. The exclusion #

            source
            theorem QOU.MassTheory.CrossingCountAffine.no_crossing_combination_is_protonPairs (a b c A : ℤ) :
            ¬∀ (Z : ℤ), a * nPlus A Z + b * nMinus A Z + c = protonPairs Z

            No linear functional of the crossing counts is the proton-pair count. Over ℤ, where 2 ≠ 0. The quantifier order is the point: the coefficients a, b, c are chosen first and the contradiction follows for every choice, so this excludes the whole family at once rather than one fit at a time.

            theorem QOU.MassTheory.CrossingCountAffine.coulomb_channel_mirror_invariant {R : Type u_1} [CommRing R] (A Z W : R) :
            nPlus A Z + nMinus A Z = nPlus A W + nMinus A W

            The mirror form. The Coulomb channel takes the same value on (Z, N) and on (N, Z), so whatever coefficient multiplies it contributes zero to every mirror splitting. Stated at fixed A, which is what a mirror pair shares.

            source
            theorem QOU.MassTheory.CrossingCountAffine.strong_channel_mirror_difference {R : Type u_1} [CommRing R] (A Z W : R) :
            nPlus A Z - nMinus A Z - (nPlus A W - nMinus A W) = 4 * (Z - W)

            And the strong channel is not mirror-invariant: its values differ by 4(Z - W). So the charge dependence the mirror splitting needs is present in the model — in the wrong channel.
