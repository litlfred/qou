    theorem QOU.MassTheory.QReebEigenphaseCompact.no_rotation_angle_of_boost (x : ℝ) (hx : 1 < |x|) :
    ¬∃ (θ : ℝ), Real.cos θ = x

    A boost block has no rotation angle. If the normalized character x = χ_λ/d_λ exceeds 1 in modulus, there is no real angle θ with cos θ = x: the eigenvalue is off the unit circle, so the block is a boost (real scaling), not a rotation. Since the q-Reeb eigenphase is defined by cos θ_λ = χ_λ/d_λ, it does not exist on such a block. (General; from |cos θ| ≤ 1.)

    theorem QOU.MassTheory.QReebEigenphaseCompact.compact_eigenphase_bounded (x : ℝ) :
    Real.arccos x ≤ Real.pi

    A compact eigenphase is a bounded, dimensionless invariant. When |χ_λ/d_λ| ≤ 1 the rotation angle θ_λ = Real.arccos (χ_λ/d_λ) lies in [0, π] — a bounded, scale-free quantity. (Real.arccos maps into [0, π] unconditionally; the point recorded here is the upper bound θ_λ ≤ π, so any predictor assembled from the eigenphases is bounded and carries no absolute scale.)

    Information-equivalence: the compact eigenphase is a lossless reparametrization of the #

    character already summed in the master binding formula (front 3, honest scope-(a) sharpening).

    The eigenphase does not merely fail to supply the scale — on the compact blocks it carries exactly the character χ_λ and nothing more. arccos is a bijection [-1,1] ↔ [0,π] (Real.cos_arccos / Real.arccos_cos), so θ_λ = arccos(χ_λ/d_λ) recovers χ_λ = d_λ cos θ_λ on every block where it is defined. Hence a predictor built from the compact eigenphases is a reparametrization of the χ_λ already inside S(K) = Σ_λ y_λ χ_λ f^λ; it introduces no new information, so it cannot be the source of the missing scale C_knot. This is why the route is "difference-only": it is the same data in angular coordinates. The scale must come from outside the character data (a radial Vol·ρ input).

    NOTE — this is scope-(a) (the eigenphase route adds nothing new), NOT a scope-(b) claim that no substrate function yields C_knot: C_knot is dimensionless and bounded (3.3–9.3), so no dimensional/boundedness argument excludes a substrate function in general. Only the eigenphase reparametrization is excluded, by the bijection below.

    theorem QOU.MassTheory.QReebEigenphaseCompact.char_from_eigenphase (d χ : ℝ) (hd : d ≠ 0) (h1 : -1 ≤ χ / d) (h2 : χ / d ≤ 1) :
    d * Real.cos (Real.arccos (χ / d)) = χ

    The character is reconstructed from its eigenphase: χ = d · cos θ_λ with θ_λ = arccos(χ/d), on any compact block (d ≠ 0, |χ/d| ≤ 1). So the eigenphase encoding of a compact block is invertible — it carries the full character, no more, no less.

    theorem QOU.MassTheory.QReebEigenphaseCompact.eigenphase_bijective_on_range (θ : ℝ) (h1 : 0 ≤ θ) (h2 : θ ≤ Real.pi) :
    Real.arccos (Real.cos θ) = θ

    The eigenphase inverts the character on [0,π]: arccos(cos θ) = θ for θ ∈ [0,π], the other half of the bijection. Together with char_from_eigenphase this makes χ_λ ↦ θ_λ a lossless reparametrization on the compact blocks — the angular data is information-equivalent to the character data already inside S(K).
