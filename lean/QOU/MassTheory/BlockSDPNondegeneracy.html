    QOU.MassTheory.BlockSDPNondegeneracy #

    Formalize-first groundwork for O3′, the amended replacement for the operator-selection objective (owner ruling, 2026-09-05).

    What is being separated #

    prop:operator-selection-lp is degenerate: the NF basis contains the identity, so its first Frobenius row is the objective vector, the program minimises t · x subject to t · x ≥ 0, its optimal value is identically 0, and by strong duality the net-constraint dual is y₀* = 0. The value therefore cannot respond to n_target — which is the whole content of a shadow price. (Commit 6b7d2ec4a8; y_0_eq_zero_of_radical.)

    O3 re-poses the program blockwise over the Wedderburn decomposition H_n(q) ≅ ⊕_λ M_{d_λ}, replacing n! scalar constraints by p(n) PSD constraints Φ_λ ⪰ 0. A falsifier run against that form fires: under the SU(2) specialisation the Markov weight of every ℓ(λ) ≥ 3 partition vanishes identically, so a Φ supported on such a block is feasible with objective 0 and nonzero net — the optimum is again 0 on a ray. Measured: that ray is the q-antisymmetriser radical, matched to 6.4e-51.

    O3′ poses the same program on the radical quotient, i.e. over the blocks of strictly positive weight. This file proves that this is exactly the condition that removes the degeneracy, and that dropping it brings the degeneracy back.

    What is proved here (all sorry-free) #

    • obj_pos_of_pos_weights — if every block weight is strictly positive and the blocks are PSD (so their traces are non-negative), then every feasible point has strictly positive objective. There is no zero-objective ray, hence no degenerate optimum.
    • exists_zero_obj_of_zero_weight — the converse failure, which is the O3 falsifier as a theorem: a single vanishing weight suffices to exhibit a feasible point of objective 0 at any target. So positivity is not a convenience assumption; it is the hypothesis that does the work.
    • feasible_smul — the value is homogeneous of degree one in n_target. This is the property the LP provably lacks (n_target · y₀* = 0 for every target), and it is what makes the program price its net constraint at all.
    • trace_nonneg_of_posSemidef — the bridge supplying the 0 ≤ t λ hypothesis from Φ_λ ⪰ 0, so the results above are about block traces and not about an abstract non-negative vector invented for the proof.

    The positivity hypothesis is MEASURED on the real program, not derived #

    obj_pos_of_pos_weights takes ∀ λ, 0 < y λ as a hypothesis, and the real program's objective coefficient is not the Markov weight alone — it is t_λ = w_λ · χ^λ(W_atom) (see computations/aK_via_lp_dual_full.py). A character can be negative, so positivity of t_λ does not follow from positivity of w_λ.

    Measured over every row of the committed a-K-via-lp-dual-full.witness.json (n = 3, 3, 6, 9, 9, 12): no surviving block carries a negative objective coefficient, in any row. The one negative character at n = 3, χ^{(1,1,1)} = −0.7392, sits on the block whose weight vanishes, so the product is exactly 0 rather than negative. Survivor counts are 2, 2, 4, 5, 5, 7 — matching the ≤ 2-row prediction of sdp_o3prime_weight_positivity_probe exactly, from an independent producer.

    So the hypothesis holds wherever it has been checked, and it is a statement about the ATOM, not a structural fact. A braid word whose character went negative on a surviving block would falsify it and the non-degeneracy result would not apply. Whoever implements the O3′ compute should assert t_λ > 0 on survivors per atom rather than assume it — the theorem below is conditional on exactly that.

    What is NOT proved here #

    That O3′ selects a distinguished operator. It does not follow, and the proposal says so: S4 (relative-interior exclusion) is untouched by re-posing. Non-degeneracy means the optimal value is well-defined and responds to the target; uniqueness of the minimiser is a separate question and stays open.

    That O3′ is a new idea. computations/aK_via_lp_dual_full.py:231-258 already states the two-row re-posing and deliberately declines to apply it. This file supplies the structural reason the quotient is the canonical cut rather than a convenient one.

        O3′ is non-degenerate. If every surviving block carries a strictly positive weight, then every feasible point of the program has strictly positive objective. In particular the optimal value is not 0, so — unlike the LP, whose value is identically 0 for every target — the program prices its net constraint.

        The falsifier as a theorem: one zero weight restores the degeneracy #

        source
        theorem QOU.MassTheory.BlockSDPNondegeneracy.exists_zero_obj_of_zero_weight {Λ : Type u_1} [Fintype Λ] [DecidableEq Λ] {y : Λ → ℝ} {lam0 : Λ} (hy0 : y lam0 = 0) {n_target : ℝ} (hn : 0 ≤ n_target) :
        ∃ (t : Λ → ℝ), (∀ (lam : Λ), 0 ≤ t lam) ∧ net t = n_target ∧ obj y t = 0

        The O3 falsifier, formalised. A single block of vanishing weight is enough to produce a feasible point with objective 0 at any positive target, so the optimum collapses to 0 exactly as it does for the LP. This is why O3 had to be amended to O3′: the hypothesis ∀ λ, 0 < y λ above is doing real work, and the SU(2) specialisation violates it for every ℓ(λ) ≥ 3.

        The value tracks the target #

        source
        theorem QOU.MassTheory.BlockSDPNondegeneracy.feasible_smul {Λ : Type u_1} [Fintype Λ] (y t : Λ → ℝ) {c : ℝ} (hc : 0 ≤ c) (ht : ∀ (lam : Λ), 0 ≤ t lam) :
        (∀ (lam : Λ), 0 ≤ (c • t) lam) ∧ net (c • t) = c * net t ∧ obj y (c • t) = c * obj y t

        Homogeneity of degree one. Scaling a feasible point scales the target and the objective by the same factor. This is precisely the property the LP lacks: there n_target · y₀* = 0 for every target, so the optimal value is constant in the target and prices nothing.
