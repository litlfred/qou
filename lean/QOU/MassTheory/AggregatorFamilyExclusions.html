    Which convex aggregators the three-point grid can already exclude #

    QOU.MassTheory.AggregatorConvexityDichotomy narrowed the many-body binding magnitude to convex-through-the-origin aggregators: writing B(A) = Φ(m_A · g) for the total bond weight, the measured b₃ = +1.4262225 excludes every concave-through-the-origin Φ, and AME's own Φ is convex and strictly superadditive on the grid the light nuclei supply.

    That is a class, not a candidate. This file supplies the two exclusion tests that the same three data points can run against a proposed Φ without fitting anything, so the next candidate is checked before it is believed.

    Both are ordinary consistency conditions — the point is that the grid has three points and the families have fewer than three parameters, so each leaves a residual identity that the data either satisfies or does not.

    Test 1 — two-parameter linear families (not_realizable_of_det3_ne_zero) #

    Φ(x) = c·x + a·ψ(x) for a fixed shape ψ and free (c, a) — the volume-plus-correction form, of which the semi-empirical volume-minus-surface c·x − a·x^{2/3} is the canonical member, and which is exactly the shape the convexity result points at (a linear term minus a concave deficit is convex, and its secant ratio Φ(x)/x → c is bounded, so it is compatible with saturation).

    Three points, two parameters, one residual: realizability forces the 3 × 3 determinant of (x, ψ, Φ) to vanish (det3_eq_zero_of_realizable). A nonzero determinant therefore excludes the whole family for that ψ — every (c, a) at once, with no fit performed and no optimisation involved.

    Test 2 — pure power laws (powerLaw_log_ratio) #

    Φ(x) = c·x^p. Its log-ratio across a scale factor k is p·log k, independent of where on the ray you measure it — so the local exponent extracted between any two grid points is the same number. Two grid intervals give two extractions, and if they disagree the family is excluded (not_powerLaw_of_log_ratios_differ).

    Scope #

    Both are scope-(b) exclusions for the families as stated, with the invariant proved here rather than cited. Neither excludes anything outside its family. In particular:

    • Test 1 excludes a two-parameter family. The full semi-empirical formula carries Coulomb, asymmetry and pairing terms as well; on Z = N light nuclei the asymmetry term vanishes, but three points cannot test a three-or-more parameter form at all — it is underdetermined, hence untestable here, not excluded here. Do not report a det3 ≠ 0 as excluding "the SEMF".
    • Test 2 excludes exact power laws, not functions that merely look like one over a range.

    Neither test identifies Φ. They are filters, and they exist because the surviving class after the convexity dichotomy is still large.

        Test 2 — pure power laws #

        source
        theorem QOU.MassTheory.AggregatorFamily.powerLaw_log_ratio {c p x k : ℝ} (hc : 0 < c) (hx : 0 < x) (hk : 0 < k) :
        Real.log (c * (k * x) ^ p) - Real.log (c * x ^ p) = p * Real.log k

        A pure power law has a scale-invariant log-ratio. For Φ x = c · x^p the quantity log Φ(k·x) − log Φ(x) is p · log k — it depends on the scale factor k alone and not on where along the ray it is measured. That is the identity the three-point grid tests twice.

        source
        theorem QOU.MassTheory.AggregatorFamily.not_powerLaw_of_log_ratios_differ {c p x₁ x₂ k₁ k₂ : ℝ} (hc : 0 < c) (hx₁ : 0 < x₁) (hx₂ : 0 < x₂) (hk₁ : 0 < k₁) (hk₂ : 0 < k₂) (hlk₁ : Real.log k₁ ≠ 0) (hlk₂ : Real.log k₂ ≠ 0) (hne : (Real.log (c * (k₁ * x₁) ^ p) - Real.log (c * x₁ ^ p)) / Real.log k₁ ≠ (Real.log (c * (k₂ * x₂) ^ p) - Real.log (c * x₂ ^ p)) / Real.log k₂) :
        False

        The exclusion. If the exponent extracted across one scale factor differs from the exponent extracted across another, no single p — and hence no pure power law c · x^p — reproduces both. Stated as the contrapositive of powerLaw_log_ratio applied at two base points.
