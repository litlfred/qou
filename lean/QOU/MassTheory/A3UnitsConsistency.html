    theorem QOU.MassTheory.A3UnitsConsistency.units_correction_is_scale {R : Type u_1} [Field R] (μ c B : R) (hμ : μ ≠ 0) (hc : c ≠ 0) (hB : B ≠ 0) :
    μ / (c / B) / (μ / c) = B

    The correction factor is exactly B. Comparing a MeV energy c to a dimensionless target μ gives the punned gap μ/c; the dimensionally-consistent gap divides the energy by the scale B (c ↦ c/B), giving μ/(c/B). Their ratio is exactly B: (μ/(c/B)) / (μ/c) = B. Here B = B(²H).

    theorem QOU.MassTheory.A3UnitsConsistency.a3_near_miss_is_scale_ambiguous :
    0.4708 / (0.297 / 2.224566) > 3 ∧ (1 < 0.297 / 0.380132 / 0.4708 ∧ 0.297 / 0.380132 / 0.4708 < 2) ∧ 2.224566 / 0.380132 > 5

    Capstone — the A=3 near-miss is scale-ambiguous, not a units-correctable near-miss. The gap is a 3.53× undershoot under one normalization (gap_A_undershoot_gt_three) and a 1.66× overshoot under the scale-consistent one (gap_B_overshoot_between_one_two); the two span the unpinned open gate C_knot > 5 (c_knot_gt_five). So repairing the dimensional pun does not yield a single honest gap — the real open object is C_knot itself (the Δ_λ magnitude). scope-(a) calibration + self-correction; no fit.
