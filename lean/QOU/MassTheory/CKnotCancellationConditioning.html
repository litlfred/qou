    theorem QOU.MassTheory.CKnotCancellationConditioning.perturbed_sum_dist_le {ι : Type u_1} (s : Finset ι) (t δ : ι → ℝ) (ε : ℝ) (hδ : ∀ i ∈ s, |δ i| ≤ ε) :
    |∑ i ∈ s, t i * (1 + δ i) - ∑ i ∈ s, t i| ≤ ε * ∑ i ∈ s, |t i|

    Conditioning bound for a relative per-block perturbation. If every block term t i is perturbed multiplicatively, t i ↦ t i · (1 + δ i), with sup-norm ‖δ‖_∞ ≤ ε, then the total moves by at most ε · Σ|t i|.

    Dividing by |Σ t i| and writing κ = |Σ t i| / Σ|t i|, the relative move of the total is bounded by ε / κ. That is the precise sense in which 1/κ is the condition number of the master binding magnitude: for ⁴He, κ ≈ 0.008, so a sub-percent per-block correction is amplified into an order-one change in |S| and hence in C_knot.

    theorem QOU.MassTheory.CKnotCancellationConditioning.exists_annihilating_perturbation {ι : Type u_1} (s : Finset ι) (t : ι → ℝ) (hT : 0 < ∑ i ∈ s, |t i|) :
    ∃ (δ : ι → ℝ), (∀ i ∈ s, |δ i| ≤ |∑ i ∈ s, t i| / ∑ i ∈ s, |t i|) ∧ ∑ i ∈ s, t i * (1 + δ i) = 0

    The conditioning bound is sharp: a perturbation of sup-norm exactly κ annihilates the sum.

    Take δ i = -(S / T) · sign(t i) with S = Σ t i, T = Σ|t i|. Then t i · δ i = -(S/T)·|t i|, so the perturbed total is S - (S/T)·T = 0, while ‖δ‖_∞ = |S|/T = κ.

    Consequence for the deficit ratio: when κ is small, C_knot = B/(m_e·|S|) is not merely imprecise — a per-block relative correction of size κ sends |S| to 0 and C_knot to +∞, and corrections slightly larger flip the sign of S. So C_knot(⁴He) = 290.007, sitting at κ < 1/100, carries essentially no information about the size of the missing per-block structure.

                absS_He4 / T_He4 < 1 / 100

                ⁴He sits on a sub-percent cancellation: κ(⁴He) = |S| / Σ|t_λ| < 1/100.
