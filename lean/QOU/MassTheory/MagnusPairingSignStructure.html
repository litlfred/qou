    theorem QOU.MassTheory.trace_commutator_eq_zero {R : Type u_1} [CommRing R] {n : Type u_2} [Fintype n] (A B : Matrix n n R) :
    (A * B - B * A).trace = 0

    The ρ = I control. The trace of a commutator vanishes: tr(A·B − B·A) = 0, by cyclicity of the trace. Consequently the linear Magnus pairing tr(ρ·Ω₂) with ρ = I and Ω₂ a sum of commutators is identically zero — it carries no built-in sign, and is therefore free (unlike a quadrature) to be negative for a suitable density.

    theorem QOU.MassTheory.trace_mul_transpose_nonneg {n : Type u_1} [Fintype n] (F : Matrix n n ℝ) :
    0 ≤ (F * F.transpose).trace

    The wall. The Frobenius quadrature tr(F·Fᵀ) = Σᵢⱼ (F i j)² is non-negative. A traceless curvature F_q enters the binding only through this square, so it can never supply a binding-reducing (negative) contribution — the reason the quadrature route qou-jqof is excluded from being the missing negative-at-A=2 term.

    theorem QOU.MassTheory.magnus_pairing_sign_indefinite :
    ∃ (A : Matrix (Fin 2) (Fin 2) ℤ) (B : Matrix (Fin 2) (Fin 2) ℤ) (ρp : Matrix (Fin 2) (Fin 2) ℤ) (ρn : Matrix (Fin 2) (Fin 2) ℤ), 0 < (ρp * (A * B - B * A)).trace ∧ (ρn * (A * B - B * A)).trace < 0

    The escape. The linear commutator-trace pairing is genuinely sign-indefinite: one fixed commutator ⁅A,B⁆, paired against two different densities ρ₊, ρ₋, gives a strictly positive and a strictly negative trace. So — unlike the non-negative quadrature of trace_mul_transpose_nonneg — the pairing is not sign-fixed, which is exactly why the second-order Magnus term can carry the sign the traceless F_q could not.

    Witnesses: A = e₀₁, B = e₁₀ give ⁅A,B⁆ = diag(1,−1); then ρ₊ = diag(1,0) yields trace +1 and ρ₋ = diag(0,1) yields trace −1.
