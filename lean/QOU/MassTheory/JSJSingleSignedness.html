    ∃ (k : ι), c k ≠ t k

    A family that is non-negative everywhere cannot agree pointwise with a family that takes a strictly negative value somewhere. This is the abstract content of the KL-positivity prune and of the Faddeev–Niemi verdict alike.

    theorem QOU.MassTheory.jsj_cannot_match_negative {ι : Type u_1} {κ : Type u_2} {R : Type u_3} [AddCommGroup R] [PartialOrder R] [IsOrderedAddMonoid R] {s : ι → Finset κ} {vol : ι → κ → R} {t : ι → R} (hvol : ∀ (a : ι), ∀ i ∈ s a, 0 ≤ vol a i) {a : ι} (ha : t a < 0) :
    ∃ (k : ι), ∑ i ∈ s k, vol k i ≠ t k

    The hinge, volume side. A term sourced from a per-isotope JSJ sum of non-negative piece volumes cannot reproduce a residual that is strictly negative at any isotope — hence cannot reproduce a sign-changing residual.

    theorem QOU.MassTheory.antitone_volume_gives_nonpos_binding {R : Type u_3} [AddCommGroup R] [PartialOrder R] [IsOrderedAddMonoid R] {B : R → R} (hB : Antitone B) {V dV : R} (hdV : 0 ≤ dV) :
    B (V + dV) ≤ B V

    The hinge, transport side. Binding is read off the carrier volume through an antitone map: more volume in the bound state means more mass and therefore less binding. So a non-negative volume addition contributes non-positively to the binding — single-signed, with the sign flipped.

    theorem QOU.MassTheory.monotone_volume_gives_nonneg_binding {R : Type u_3} [AddCommGroup R] [PartialOrder R] [IsOrderedAddMonoid R] {B : R → R} (hB : Monotone B) {V dV : R} (hdV : 0 ≤ dV) :
    B V ≤ B (V + dV)

    Monotone transport, for the opposite sign convention. Together with antitone_volume_gives_nonpos_binding this is the point: under either monotonicity direction the JSJ contribution is single-signed, so the exclusion does not depend on which convention the framework uses — only on the map being monotone at all.
