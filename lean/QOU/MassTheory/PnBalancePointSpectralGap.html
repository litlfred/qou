    QOU.MassTheory.PnBalancePointSpectralGap #

    The p-n interface letter sits at the spectral balance point, and AM-GM puts its growth rate strictly below both like-pair letters — at every crossing multiplicity.

    Bean qou-brng, escape class B.

    What this is for #

    QOU.MassTheory.PnBetweennessBlocksSignMixed.pn_betweenness_blocks_signMixed rules out the sign-mixed pattern using two hypotheses, and the 2026-09-12 entry on qou-brng named them as class B's whole remaining escape: the averaging of the p-n letter, and the affineness of the interface law μ = z + d.

    Affineness is an m = 1 fact. The interface letter σ_g + d·I has two-strand trace z + d (QOU.Mass.ChainTraceFactor.twoStrandTrace_eq), but at crossing multiplicity m the letter is (σ_g + d·I)^m, whose trace is degree m in d — already (d² + 1) + (2d + h)·z at m = 2. So the hypothesis is genuinely breakable, and measured, betweenness itself fails from m = 12 (computations/probes/multiplicity_breaks_affineness_but_not_the_pattern_probe.py).

    It breaks the wrong way. Diagonalising, σ_g has Hecke eigenvalues q and -q⁻¹, so the multiplicity-m trace is w₊(d+q)^m + w₋(d-q⁻¹)^m. The growth rate of each letter is therefore its spectral radius max |d+q| |d-q⁻¹|:

    letter d spectral radius
    pp 0 q
    nn -h q
    pn ≈ -h/2 ≈ (q + q⁻¹)/2

    This file proves the three facts that make the last column decide the question: balance_eigen_neg (at d = -h/2 the two eigenvalues are exact negatives, both of magnitude (q+q⁻¹)/2), one_lt_balance (AM-GM), and balance_lt_self ((q+q⁻¹)/2 < q for q > 1). Hence pn_spectralRadius_lt_pp: the p-n channel grows strictly slower than either like-pair channel, at every q > 1.

    The gap is growth_gap_eq: q / ((q+q⁻¹)/2) = 2q²/(q²+1), which is 1 + tanh(log q) — the crossing discriminant QOU.Braiding.em_strong_ratio_tanh already carries in that form, and the one qou-hjs8 proved θ-free.

    Scope #

    Scope (b) for the asymptotic statement; invariant = AM-GM on the two Hecke eigenvalues, and it mentions no numerical value. The small-m statement is measured, not proved.

    It does not exclude class B: a derived p-n letter that is not at the balance point is untouched, and that is now the whole of class B's remaining room. It says nothing about magnitude, which is qou-brng's real target.
