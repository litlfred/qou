    M₁ is the tilt derivative — for the ACTUAL Plancherel measure, not a generic family #

    Bean qou-k5r5, epic qou-x631. Sequel to QOU.MassTheory.TiltDerivativeCovariance.

    That file proved the tilt identity for an arbitrary finite family over an arbitrary field. On its own that is a lemma about polynomials: it says nothing about Plancherel measure, about ω₃, or about M₁. This file discharges its hypothesis at the corpus's own Plancherel datum, which is what turns it into a statement about the gap.

    The hypothesis that had to be discharged #

    tilt_deriv_eq_wCov assumes wMean w f = 0. Here w λ = dim(λ)² and f = ω₃ := Σ_c c² − binom(n,2), and the hypothesis is exactly the Plancherel content-square mean — the fact qou-ujil uses to eliminate limit-shape arguments.

    It is not assumed here. plancherel_weighted_omega3_sum_eq_zero derives it from the two PlancherelSnData fields already in the corpus:

    • sum_dim_sq : ∑ dim² = n!
    • two_sum_dim_sq_content : 2·∑ dim²·Σc² = n(n−1)·n!

    so ∑ dim²·ω₃ = n(n−1)n!/2 − binom(n,2)·n! = 0 exactly, by ring after casting.

    Epistemic status — read this before citing #

    [PlancherelSnData n] is a class hypothesis (AGENTS.md §3b-cond), so every theorem below is a conditional result. The class is not a hole: the corpus inhabits it at every n (PlancherelSnDataGeneral.plancherelSnDataGeneral, from RSK + Okounkov–Vershik), and its unlabelled Wedderburn form is proved unconditionally and sorry-free (IdentityBWedderburn.identityB_via_wedderburn_unconditional). But conditional-proved is not premise-established: state these as "modulo PlancherelSnData", never flatly.

    Scope — this is still not the gap #

    M₁ > 0 remains OPEN. Nothing here bounds the derivative below or determines its sign; the tilt statistic hgt is left arbitrary, so this fixes the shape of the reformulation and not one numerical fact about it. Generality is deliberate: the identity does not need hgt = Σ□h, and pinning it there would claim less while looking like more.
