              theorem QOU.MassTheory.PnInterfaceBarStructure.fPN_eq {K : Type u_1} [Field K] [CharZero K] (q ε : K) :
              fPN q ε = markovZ q - (1 / 2 - ε) * heckeH q

              The weighted-mean form agrees with the explicit shifted form used in the producers: f_pn = z - (1/2 - ε)·h.

              At ε = 0 this is z - h/2, the δ = 0 factor; at ε = δ/4 it is the colour-tube-weighted z - h(1/2 - δ/4).

              theorem QOU.MassTheory.PnInterfaceBarStructure.pnWeighted_bar_sub {K : Type u_1} [Field K] [CharZero K] (q ε ε' : K) :
              (1 / 2 + ε') * fNN q + (1 / 2 - ε') * fPP q - fPN q ε = -(ε' + ε) * heckeH q

              The bar defect of the weighted p-n factor.

              Applying bar swaps f_pp and f_nn (by fNN_eq_fPP_bar) and sends the offset ε to ε', so the image is (1/2 + ε')·f_nn + (1/2 - ε')·f_pp. Its difference from fPN q ε is -(ε' + ε)·h.

              ε' is taken as a parameter rather than computed: the conclusion depends only on the relation between the offset and its image.

              theorem QOU.MassTheory.PnInterfaceBarStructure.pnWeighted_barEven_iff {K : Type u_1} [Field K] [CharZero K] (q ε ε' : K) (hh : heckeH q ≠ 0) :
              (1 / 2 + ε') * fNN q + (1 / 2 - ε') * fPP q = fPN q ε ↔ ε' = -ε

              The load-bearing statement: bar-even iff the offset is bar-ODD.

              When h ≠ 0, the weighted p-n factor is fixed by the involution exactly when ε' = -ε.

              Note the direction. A bar-even offset (ε' = ε) gives defect -2ε·h, which vanishes only in the trivial case ε = 0; symmetrising the weight is therefore the wrong repair.
