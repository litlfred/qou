    def QOU.MassTheory.margDown {R : Type u} {ι : Type v} (restrict : Nat → (ι → R) → ι → R) (w : Nat → ι → R) :
    Nat → Nat → ι → R

    The marginal of the level-(n + d) weights, restricted down d steps to level n. Stated for a bare restrict/w pair rather than as a field of a structure, so that §"Non-vacuity" can instantiate it with a pair that does not satisfy the step condition.

      theorem QOU.MassTheory.margDown_eq_of_step {R : Type u} {ι : Type v} {restrict : Nat → (ι → R) → ι → R} {w : Nat → ι → R} (h : ∀ (n : Nat), restrict n (w (n + 1)) = w n) (n d : Nat) :
      margDown restrict w n d = w n

      The invariant. One-step compatibility forces depth-independence: the marginal taken from level n + d is w n, for every depth d.

      This is the Markov property doing the work. The hypothesis constrains a single step; the conclusion is about all of them.

      theorem QOU.MassTheory.margDown_ne_without_step :
      ∃ (restrict : Nat → (Unit → Nat) → Unit → Nat), ∃ (w : Nat → Unit → Nat), margDown restrict w 0 1 ≠ w 0

      The hypothesis is load-bearing. Drop it and the conclusion fails: with restrict the identity and w n = fun _ => n, the depth-1 marginal at level 0 is 1, not w 0 = 0. So margDown_eq_of_step is not a tautology about margDown, and the step condition is doing real work.
