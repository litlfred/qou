        theorem QOU.MassTheory.BraidPathNotCoordination.braid_count_eq_coordination_degree (A : ℕ) :
        (bonds A).card = coordinationDegree A

        The coincidence. The braid's edge count and the block's vertex degree are the same function of A, so no value of A can tell them apart. This is the statement a table of matching rows establishes, and it is weaker than it looks — it is an identity of two arithmetic expressions, not evidence that the two counts are the same object.

        theorem QOU.MassTheory.BraidPathNotCoordination.handshake_forces_le_two (A z edges : ℕ) (hz : z = coordinationDegree A) (he : edges = A - 1) (handshake : A * z = 2 * edges) :
        A ≤ 2

        A cluster cannot carry the braid's bond count and the block's degree at once above A = 2.

        The hypothesis handshake is the identity ∑_v deg v = 2·|E| specialised to a z-regular cluster (QOU.Mass.CoordinationBinding.coordination_handshake proves it for K_A). Feeding it the braid's measured |E| = A - 1 together with the block's z = A - 1 forces A ≤ 2.

        Stated with edges and z as arguments so the two inputs are visible and neither is baked in. A hypothesis 1 ≤ A was carried in a first draft and the linter showed it unused — the bound holds for every A, so it is dropped rather than kept for decoration.

        theorem QOU.MassTheory.BraidPathNotCoordination.sub_one_lt_choose_two {A : ℕ} :
        3 ≤ A → A - 1 < A.choose 2

        P_A = K_A only for A ≤ 2. The braid's bond count equals the complete graph's bond count C(A,2) exactly when A ≤ 2 — the deuteron is the only nucleus whose braid bond set is the fully coordinated cluster. At A = 3, where the block calibrates, the counts already differ (2 against 3).
