    QOU.MassTheory.EmGermMomentVanishing — where the EM germ moment vanishes, and where it blows up #

    Bean qou-rrgk (the germ-viability bean — see the ID note below).

    The 2026-08-29 germ-viability probe (computations/alpha_em_germ_viability_probe.py, audit docs/audits/2026-08-29-alpha-em-germ-viability-live.md) computed the EM-singlet moment of the germ curvature F_q = [δq₁, δq₂] in the fundamental representation and found the closed form

    m_F = qTr(E · F_q · E) / qTr(E) = −(q² − 1)/(q² + 1) = −h/[2]_q,

    with h = q − q⁻¹ bar-odd and [2]_q = q + q⁻¹ bar-even. That result is a probe computation and is taken here as given — this file does not re-derive it from the Hecke representation, and nothing below should be cited as doing so ("conditional-proved ≠ premise-established"). What this file adds is the structure of the closed form, which is where its meaning lives.

    The point: one formula, both distinguished loci #

    A bar-odd numerator over a bar-even denominator has two special loci, and the corpus already cares about both of them for separate reasons:

    • q² = 1 — the moment vanishes (emMoment_eq_zero_iff). This is the classical / self-dual point, and it is exactly the locus where the braiding becomes symmetric: QOU.MassTheory.TraceSignFlipRegime.trace_sign_flip_iff_symmetric gives tr σ⁻¹ = tr σ ↔ q² = 1 from the same factor h. So germ sterility in the EM singlet channel and symmetric braiding are the same condition (sterile_iff_bar_fixed), not two coincidences. The germ is non-sterile because the braiding is non-symmetric.

    • q² = −1 — the normalisation [2]_q degenerates (qInt2_eq_zero_iff), so the moment is not defined there. The measure wall's stated obstruction (docs/audits/2026-08-02-moc-gauss-manin-not-derivable.md, epic 08a2) is that "the discrete q = i F-construction shadow supplies no germ" — and q = i is a root of q² = −1.

      Stated as a coincidence of loci, not as a derivation. That [2]_q vanishes at q = i is the theorem; that this is why the discrete shadow supplies no germ is an interpretation this file does not prove and does not claim. It is recorded because the two loci agreeing is checkable and was not previously written down.

    Scope #

    Everything is algebraic over a Field R — no ordering, no Real.sqrt, no archimedean construct (§7c), so the statements hold at the categorical/fibre level and specialise to ℝ or ℂ on demand. Nothing here derives the measure 1/(8π), which stays phase-4; nothing is wired.

    A note on the bean ID #

    Two distinct beans carry the ID qou-rrgk on main: qou-rrgk--germ-viability-probe-... (this one) and qou-rrgk--drain-329-stale-q-0-anchors-.... beans show qou-rrgk resolves to the drain bean, so the germ bean is unreachable from the CLI by ID. Cite it by filename.
