    def QOU.MassTheory.ConjugationParity.barEvenTotal {I : Type u_1} {R : Type u_2} [Fintype I] [CommRing R] (sgn : R) (c : Equiv.Perm I) (T Δ : I → R) :
    R

    The (unnormalised) bar-even total of the Δ-dressed Wedderburn sum S = ∑ T_λ Δ_λ: S + sgn · (bar image of S), with sgn = (−1)^{n-1} the weight bar-sign.

      theorem QOU.MassTheory.ConjugationParity.barEvenTotal_symmetric_zero_deuteron {I : Type u_1} {R : Type u_2} [Fintype I] [CommRing R] (c : Equiv.Perm I) (hcc : ∀ (p : I), c (c p) = p) (T Δ : I → R) (hsym : ∀ (p : I), Δ (c p) = Δ p) :
      barEvenTotal (-1) c T Δ = 0

      The exclusion (deuteron, sgn = −1): a conjugation-symmetric dressing kills the bar-even total. If Δ (c p) = Δ p for all p, then barEvenTotal (−1) c T Δ = 0. Hence no conjugation-symmetric Δ_λ can supply the deuteron's nonzero bar-even coefficient g₂.
