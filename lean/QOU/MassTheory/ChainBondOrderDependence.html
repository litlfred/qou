    The linear-chain bond sum is ordering-dependent unless the substrate is classical #

    atom_braid_word_3A builds an atom's braid word from ordering = ['p']*Z + ['n']*N — a hard-coded arrangement of the nucleons on a line. The chain binding is then a sum over adjacent pairs,

    B(w) = α · ∑_{adjacent (a,b) in w} L_{ab},   L ∈ {L_pp, L_pn, L_nn},

    so it depends on the arrangement w and not only on (Z, N). A nucleus has no arrangement, so the dependence is a non-physical degree of freedom. Measured under convention C (2026-08-08, qou-h7mh) the spread reached 2.27 MeV at ⁴He and 2.88 MeV at ⁷Li, and the hard-coded choice was not even the best one (³He ppn gives −11.9 % against AME where pnp gives +0.79 %).

    This file asks the structural question that measurement cannot: can the arrangement dependence be removed by choosing the bond scalars better?

    Result #

    orderIndependent_iff — the chain bond sum is invariant under every rearrangement iff L_pp = L_pn = L_nn. The two A = 3 witnesses force it:

    B(ppn) = L_pp + L_pn      vs   B(pnp) = 2·L_pn      ⟹  L_pp = L_pn
B(nnp) = L_nn + L_pn      vs   B(npn) = 2·L_pn      ⟹  L_nn = L_pn

    and conversely a constant scalar makes B a function of the nucleon count alone (bondSum_const).

    not_orderIndependent_of_ne — so L_pp ≠ L_nn is already enough to make the chain arrangement-dependent, at every A ≥ 3.

    Why this is an exclusion and not a nuisance #

    QOU/QBeta/InterfaceScalar.charge_independence_iff proves (sorry-free) L_pp = L_nn ↔ h = 0 ↔ q = 1. Combining it with not_orderIndependent_of_ne: the linear-chain bond sum is arrangement-independent only in the classical limit, where the Hecke structure collapses. At the substrate q₀ ≠ 1 there is no assignment of bond scalars that repairs it.

    Scope (b), invariant named (the two A = 3 rearrangements above). What it excludes is the linear-chain ansatz as a well-defined binding functional at q ≠ 1 — not the bond picture itself. Symmetrising over arrangements, or choosing a different convention, cannot help: the defect is that the chain has an arrangement at all. The repair has to change the bond set — a coordination graph, an all-pairs sum, or a derived edge set (qou-h7mh proposes deriving it from the SU(4) partition shape) — which is a different object, not a better ordering.

    Consequence for the body-order programme (qou-i5yp, qou-d9sk): the Ursell cumulants b₃, b₄ are built from A ≥ 3 bindings, so each inherits this freedom. Extending the inversion to ⁶Li/⁷Li — the prerequisite for the body-order recurrence test to be falsifiable — inherits it too, and the arrangement must be settled first or the extension measures the convention.

    Stated over a generic ring per AGENTS.md §7c; letters are Bool with true for a proton, and nothing here is archimedean.
