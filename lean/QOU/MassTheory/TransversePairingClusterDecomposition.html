    QOU.MassTheory.TransversePairingClusterDecomposition #

    The transverse non-abelian-Stokes pairing is an exactly quadratic cluster functional: it has NO irreducible three-body content at fixed curvature data.

    Companion to TransverseSurfaceCurvature (the ordered pairing listPairing and the trace-annihilation theorem) and GermRootVectorGaugeFixing (the single-generator scope-(b) vanishing). Bean qou-prjo.

    Why this file exists #

    The bean's open gate is the super-pairwise extensive many-body binding term. Two readings of the transverse surface curvature are already excluded:

    • the diagonal / Betti-count reading is exactly linear in link count (seifertBettiOne_link_additive) hence pairwise-capped;
    • the scalar-trace readout vanishes identically (listPairing_trace_zero).

    That leaves the off-diagonal cross-handle pairing, whose super-pairwise status was untested. This file settles the algebraic half of the question, and it settles it negatively at fixed curvature data:

    listPairing is bilinear in the transported curvatures, so under any partition of the surface bands into ordered blocks it decomposes exactly into one-block and two-block terms — listPairing_append. Consequently the three-block Möbius (cluster) residual vanishes identically (moebius3_eq_zero), as does the four-block one (moebius4_eq_zero).

    So a nonzero measured three-body residual can have exactly one source: the per-block transported-curvature lists themselves differ between sub-configurations. Under the pinned Yekutieli ordering the transport to a band is the ordered product of everything earlier in the word, so deleting a nucleon changes the transport of every later one — the lists are context-dependent and the residual is generically nonzero. This file makes that the only available mechanism, which is what turns a numerical measurement of the residual into a statement about transport rather than about curvature.

    What is NOT proved — read before citing #

    • This does not show the transverse pairing is additive over links in practice. It shows the residual is zero when the block curvature lists are held fixed. The measured residual on real multi-generator words is nonzero (probe computations/probes/nastokes_multigen_cluster_additivity_probe.py), and by the theorems here that nonzero value is entirely attributable to context-dependence of the Yekutieli transport.
    • Nothing here derives a magnitude. sorry-free ≠ derived: no binding energy, no Δ_λ, no AME comparison appears in this file, and nothing is wired.
    • listPairing uses the surface-ordered (Yekutieli) convention. A homological reading weighted by a Seifert intersection form J is a different bilinear form; listPairing_append is the ordered case. The quadratic-hence-no-3-body argument applies verbatim to any bilinear form whose block restriction is the corresponding sub-block, but that generalisation is not formalised here.

    Base ring (§7c). Generic non-commutative Ring R throughout; the collinear corollary adds a generic CommRing K acting by Algebra K R. No ℝ, no ordering, no Real.*, no archimedean evaluation.

    2. The exact block decomposition #

    source
    theorem QOU.MassTheory.TransversePairingCluster.listPairing_append {R : Type u_1} [Ring R] (l₁ l₂ : List R) :
    TransverseSurfaceCurvature.listPairing (l₁ ++ l₂) = TransverseSurfaceCurvature.listPairing l₁ + TransverseSurfaceCurvature.listPairing l₂ + TransverseSurfaceCurvature.curvComm l₂.sum l₁.sum

    THE CLUSTER DECOMPOSITION.

    Splitting the surface bands into an earlier block l₁ and a later block l₂, the ordered transverse pairing is

    Ω(l₁ ++ l₂) = Ω(l₁) + Ω(l₂) + ⟦Σ l₂, Σ l₁⟧.

    The interaction between the two blocks is one commutator of the two block sums — the two-body cluster term. There is no residue beyond it: the pairing is bilinear, so a block decomposition terminates at second order.

    source
    theorem QOU.MassTheory.TransversePairingCluster.listPairing_append_eq_add_iff {R : Type u_1} [Ring R] (l₁ l₂ : List R) :
    TransverseSurfaceCurvature.listPairing (l₁ ++ l₂) = TransverseSurfaceCurvature.listPairing l₁ + TransverseSurfaceCurvature.listPairing l₂ ↔ TransverseSurfaceCurvature.curvComm l₂.sum l₁.sum = 0

    Additivity criterion. The pairing is additive across a block split exactly when the two block sums commute.

    The GermRootVectorGaugeFixing mechanism in cluster language. If both block sums are scalar multiples of one common element — the situation forced on a single-generator word, where every transported curvature is a scalar multiple of the root vector F_q — the cross term vanishes and the pairing is additive across the split. Multi-generator words break the hypothesis, which is exactly where the cross term can survive.

    3. No irreducible three- or four-body content at fixed curvature data #

    source
    theorem QOU.MassTheory.TransversePairingCluster.moebius3_eq_zero {R : Type u_1} [Ring R] (l₁ l₂ l₃ : List R) :
    TransverseSurfaceCurvature.listPairing (l₁ ++ l₂ ++ l₃) - TransverseSurfaceCurvature.listPairing (l₁ ++ l₂) - TransverseSurfaceCurvature.listPairing (l₁ ++ l₃) - TransverseSurfaceCurvature.listPairing (l₂ ++ l₃) + TransverseSurfaceCurvature.listPairing l₁ + TransverseSurfaceCurvature.listPairing l₂ + TransverseSurfaceCurvature.listPairing l₃ = 0

    THE MÖBIUS THEOREM (three blocks).

    For fixed block curvature lists l₁, l₂, l₃, the three-body cluster (Möbius) residual of the ordered transverse pairing

    Ω(123) − Ω(12) − Ω(13) − Ω(23) + Ω(1) + Ω(2) + Ω(3)

    is identically zero. The pairing is bilinear, so every block decomposition stops at two-block terms and the alternating sum cancels them exactly.

    Reading. The transverse surface-curvature pairing carries no irreducible three-body content of its own. Any nonzero three-body residual measured on actual braid words is therefore not a property of the curvature at all: it can only come from the block lists changing between sub-configurations, i.e. from context-dependence of the parallel transport (under the Yekutieli ordering, the transport to a band is the ordered product of everything earlier in the word).

    The four-block Möbius residual also vanishes identically, for the same reason: a bilinear functional has no irreducible k-body content for k ≥ 3. Stated explicitly (rather than by induction over Finsets) so the cancellation is directly checkable.

    source
    theorem QOU.MassTheory.TransversePairingCluster.moebius3_eq_sub_of_context {R : Type u_1} [Ring R] (l₁ l₂ l₃ l₁' l₂' l₃' : List R) :
    TransverseSurfaceCurvature.listPairing (l₁' ++ l₂' ++ l₃') - TransverseSurfaceCurvature.listPairing (l₁ ++ l₂) - TransverseSurfaceCurvature.listPairing (l₁ ++ l₃) - TransverseSurfaceCurvature.listPairing (l₂ ++ l₃) + TransverseSurfaceCurvature.listPairing l₁ + TransverseSurfaceCurvature.listPairing l₂ + TransverseSurfaceCurvature.listPairing l₃ = TransverseSurfaceCurvature.listPairing (l₁' ++ l₂' ++ l₃') - TransverseSurfaceCurvature.listPairing (l₁ ++ l₂ ++ l₃)

    The three-body residual is exactly a transport defect. If the block lists change from lᵢ to lᵢ' when the third block is present, the three-body residual equals the difference of the two Möbius sums — and the fixed-list one is zero by moebius3_eq_zero. This is the precise sense in which a measured nonzero residual measures context-dependence of the transport, not a three-body property of the curvature.
