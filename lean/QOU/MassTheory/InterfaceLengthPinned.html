    def QOU.MassTheory.colPole (step : Nat) :
    Nat → Nat

    Pole order at q = 0 of the all-column character of a positive braid word, accumulated one letter at a time. step is the pole order contributed by a single generator; the column channel has step = 1.

    Equations
    • QOU.MassTheory.colPole step 0 = 0
    • QOU.MassTheory.colPole step n.succ = step + QOU.MassTheory.colPole step n

      theorem QOU.MassTheory.colPole_faithful {m n : Nat} (h : colPole 1 m = colPole 1 n) :
      m = n

      The pinning. Pole order recovers word length exactly, so two interface words of different lengths carry different α_shift. The interface slot in the shift decomposition is therefore not free: a substitute word is admissible only if it has the same length as the one it replaces.

      theorem QOU.MassTheory.colPole_not_faithful_of_zero_step :
      ∃ (m : Nat), ∃ (n : Nat), m ≠ n ∧ colPole 0 m = colPole 0 n

      The unit step is load-bearing. If a generator contributed nothing to the pole order, every word length would collapse to the same α_shift and the interface would be entirely unconstrained.
