    The Borromean H₃ Markov trace and its unlink deficit #

    noncomputable def QOU.MassTheory.tauBorromean (h : ℝ) :
    ℝ

    The Borromean H₃ Markov-trace closed form (GAP-A-4, QOU.BraidsAndKnots.BorromeanMarkovTrace), as a function of h = q − q⁻¹: τ_Borr(h) = (4 + h² − 3h⁴ − h⁶)/(h² + 4). Amphichiral ⇒ even in h.

      theorem QOU.MassTheory.one_sub_tauBorromean (h : ℝ) :
      1 - tauBorromean h = h ^ 4 * (3 + h ^ 2) / (h ^ 2 + 4)

      Trace-deficit closed form. 1 − τ_Borr = h⁴(3 + h²)/(h² + 4). This is the irreducible 3-body content: the Borromean trace measured against the unlink τ(0) = 1. (Being Brunnian, no pairwise part is subtracted — it vanishes.)

      theorem QOU.MassTheory.borromean_cluster_nonneg {E0 h : ℝ} (hE : 0 ≤ E0) :
      0 ≤ E0 * (1 - tauBorromean h)

      (LEAD) The Borromean irreducible 3-body cluster is non-negative. For a non-negative energy scale E₀, the Brunnian binding cluster c₃ = E₀·(1 − τ_Borr) is ≥ 0 — the forward complement of Mu4RhoFCluster.pairwise_3body_content_nonpos (which is ≤ 0). This is the sign the multiplicative pairwise route provably cannot supply.

      theorem QOU.MassTheory.borromean_cluster_pos {E0 h : ℝ} (hE : 0 < E0) (hh : h ≠ 0) :
      0 < E0 * (1 - tauBorromean h)

      (LEAD, strict) c₃ > 0 in the physical regime (E₀ > 0, q ≠ 1). So the Borromean cluster is sign-compatible with μ₃ > 0 — unlike any pairwise interface product (Mu4RhoFCluster.mu3_ne_pairwise_3body_cluster).

      theorem QOU.MassTheory.mu3_sign_compatible_with_borromean_cluster {μ₃ E0 h : ℝ} (hμ : 0 < μ₃) (hE : 0 < E0) (hh : h ≠ 0) :
      0 < μ₃ ∧ 0 < E0 * (1 - tauBorromean h)

      Sign selection. The residual moment μ₃ > 0 and the Borromean cluster c₃ = E₀·(1 − τ_Borr) > 0 (physical regime) lie on the same strictly-positive side — so the Brunnian operator is sign-compatible with μ₃. Contrast Mu4RhoFCluster.mu3_ne_pairwise_3body_cluster, where the ≤ 0 pairwise content is sign-incompatible with the same μ₃. (This fixes the sign only; it makes no magnitude claim — μ₃'s value enters neither statement nor proof.)
