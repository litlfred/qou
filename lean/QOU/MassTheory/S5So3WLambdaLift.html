    ℝ

    A Brunnian-order-suppressed H₉ cluster deficit at a given block weight (y_λ or W_λ) has the shape D(h) = h⁴ · κ h, with the weight's h⁴-coefficient κ. (Cabling preserves the Brunnian order-suppression — probe-measured exponent 4.098 — so both weights give an O(h⁴) deficit; only κ differs.)

      The y_λ → W_λ re-weight is a coefficient ratio, never an order change. Two block weights give deficits h⁴·κ_y h and h⁴·κ_W h; their ratio is κ_W h / κ_y h — the shared h⁴ cancels. Re-weighting the trace therefore rescales the coefficient and cannot move the leading h-order.
