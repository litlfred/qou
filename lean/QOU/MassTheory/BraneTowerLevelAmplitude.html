          §3b-cond conditional class: the edge-scaling RULE is the open hypothesis #

          source
          class QOU.MassTheory.CoordinationEdgeAmplitude (R : Type u_1) [CommRing R] :
          Type u_1

          Conjecture class (conj:binding-manybody-eq-jet-filtration, edge-scaling reading). Axiomatises the open rule that the irreducible 3-body coefficient scales linearly with the coordination edge count (bond channels), together with the derived path coefficient κ_P (#4364's H₉ value) and the derived edge ratio ρ. The ruleLinear field is the conjecture's content — that κ of the full coordination graph is ρ · κ_P. Having an instance is the conjecture; the theorem below is proved from it (no sorry).

          This is honest §3b-cond structure: the RULE κ_full = ρ · κ_P is NOT proved (a coefficient tuned to close would be a FIT); it is carried as a hypothesis, and the fullCoordAmplitude_eq corollary derives the full-coordination magnitude from it.

          • E0 : R

            Electron-mass ρ_F scale factor E₀.

          • h : R

            Hecke h = q − q⁻¹.

          • kappaPath : R

            Derived path (P₃, 2-edge) h⁴-coefficient — #4364's H₉ value.

          • rho : R

            Derived edge ratio ρ = |E(K₃)|/|E(P₃)| (= 3/2, edge_ratio_A3).

          • kappaFull : R

            The full-coordination h⁴-coefficient.

          • ruleLinear : kappaFull = rho * kappaPath

            The open RULE (the conjecture's content): the full-coordination 3-body coefficient is the path coefficient scaled by the edge ratio.

Hence the third bond does not stay Brunnian, the shared-h⁴ premise fails, and the 3/2 edge rescale does not apply: the coordination-edge reading walls (scope-a).
