      theorem QOU.MassTheory.he4WritheDet_bar_even {R : Type u_1} [CommRing R] (m : R) :
      he4WritheDet (-m) = he4WritheDet m

      ⁴He cumulant is bar-even. he4WritheDet is a function of m² alone, so it is invariant under m ↦ -m. Hence the connected cumulant b₄ = -ln (he4WritheDet m) is even in the magnitude m. Under the bar involution q ↦ q⁻¹ acting on a bar-odd magnitude (m ↦ -m) this says b₄(q) = b₄(q⁻¹): bar-even symmetrisation is a no-op at A = 4, so it cannot tame the ⁴He magnitude overshoot (the scope-(b) obstruction to Vector 3).

      def QOU.MassTheory.he4DetViaEig {R : Type u_1} [CommRing R] (L m : R) :
      R

      The A=4 writhe determinant written through the ss-sector eigenvalue L (L² = 1 + b²; classical integer pn-degree b = 2 gives L = √5), with the zero mode (1 - m·L) factored out explicitly: det(I + m·S) = (1 - m·L)(1 + m·L)(1 - m²). The (1 ± m·L) pair is the species-symmetric (pp-sym, nn-sym) sector; the (1 - m²) is the Pauli intra-pair (λ = ±1) sector.
