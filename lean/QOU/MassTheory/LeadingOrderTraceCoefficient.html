    The leading ℏ_q coefficient of the trace difference, derived #

    Bean qou-pdg9 (successor to qou-zrx2). Probe: computations/probes/c1_leading_coefficient_derived_probe.py.

    What this certifies #

    PairwiseChainLeadingOrder carries the six leading coefficients c₁ = lim (Δtr − c₀(A))/ℏ_q of Δtr = tr_M(W_free) − tr_M(W_atom) as definitions — Richardson measurements matched to rationals. This file records the derivation that turns them into values that follow from the braid words, by the same route that derived the classical floor c₀ (ClassicalTraceFloor):

    d tr_M / dε |₀  =  2^{−n} · Σ_ℓ w_ℓ · 2^{c(σ^{(ℓ)})}          [★]

    with q = 1 + ε, w_ℓ = +1 for a σ letter, −1 for σ⁻¹, 0 for either averaged letter, and σ^{(ℓ)} the permutation of the word with letter ℓ deleted. Reading the per-letter data collapses it further to

    c₁(Z,N) = (21Z + 16N)·(2^{−A−1} − 2^{−2A}) − 4·(I_pp − I_nn)·2^{−2A}

    where 21 = 4·6 − 3 and 16 = 4·5 − 4 are the proton / neutron letter census 4·#σ − #σ⁻¹, and I_pp = Z−1, I_nn = N−1 (truncated at 0) count the same-species interfaces of the chain.

    The four steps of [★], and what is formal here #

    1. The generator's first-order term is 1 + Y with Y anticommuting with s. From σ² = hσ + 1, h = 2ε + O(ε²), s² = 1. — hecke_first_order_anticommutes proves the ring identity; hecke_relation_snd extracts the first-order relation from the Hecke relation in the dual numbers R[ε]/(ε²); h_dual shows h = 2ε there.
    2. Tr(Y·P) = 0 for every permutation P. A spin-flip symmetry argument on (ℂ²)^{⊗n}. Not formalised — it needs the tensor representation, which needs Schur–Weyl, which Mathlib lacks. Stated in the probe.
    3. The K′ term cancels the normaliser's derivative. Arithmetic; both are n·2^{c(σ)}. Folded into [★] as stated.
    4. Each letter's own first-order term is the scalar 1 + d′(0), giving w ∈ {+1, −1, 0, 0}; the colour weight δ = O(ε³) is invisible. letter_weight records the four values.

    What IS proved below, unconditionally: the ring identity of step 1 (in any ring, and via the dual numbers); that any [★]-shaped sum is a dyadic rational with denominator dividing 2^n; that the closed form evaluates to the six recorded rationals; and — from the actual letter data of the twelve words, entered as explicit lists — that [★] reproduces every one of them. So the six definitions in PairwiseChainLeadingOrder are now derived conditional on steps 2 and 4 (Schur–Weyl plus the trace-invisibility of Y), which is exactly the hypothesis split ClassicalTraceFloor uses for c₀.

    ⚠ What the closed form does NOT license #

    It is a statement about the signed first-order coefficient of the difference channel at the chain's own letter census. It says nothing about the log channel, nothing about the scale (qou-59j5), and nothing past first order — the exact c₂ values are in the witness and are NOT closed-form here.

    1. First-order structure of a Hecke generator #

    source
    theorem QOU.MassTheory.hecke_first_order_anticommutes {R : Type u_1} [Ring R] (s X : R) (h : s * X + X * s = s + s) :
    s * (X - 1) = -((X - 1) * s)

    Step 1, ring form. If sX + Xs = s + s, then Y := X − 1 anticommutes with s. Holds in any ring, commutative or not — and, as the linter pointed out, needs no s² = 1: that hypothesis is used only to derive the relation (hecke_relation_snd), not to read it.

    source
    theorem QOU.MassTheory.hecke_relation_snd {R : Type u_1} [Ring R] (s X : R) (hσ : (TrivSqZeroExt.inl s + TrivSqZeroExt.inr X) * (TrivSqZeroExt.inl s + TrivSqZeroExt.inr X) = TrivSqZeroExt.inr 2 * (TrivSqZeroExt.inl s + TrivSqZeroExt.inr X) + 1) :
    s * X + X * s = s + s

    Step 1, where the relation comes from. In the dual numbers R[ε]/(ε²) the Hecke relation σ² = hσ + 1 for σ = s + εX with h = 2ε and s² = 1 forces exactly sX + Xs = s + s on the ε-coefficient.

    source
    theorem QOU.MassTheory.h_dual {R : Type u_1} [CommRing R] :
    (1 + DualNumber.eps) * (1 - DualNumber.eps) = 1 ∧ 1 + DualNumber.eps - (1 - DualNumber.eps) = 2 * DualNumber.eps

    h = q − q⁻¹ at q = 1 + ε is 2ε to first order: (1+ε)(1−ε) = 1 in the dual numbers, so q⁻¹ = 1 − ε and h = 2ε.

        3. The closed form #

        The closed form itself lives in PairwiseChainLeadingOrder as c1Closed (a b : ℚ) (Z N : ℕ); at the Borromean letter weights it is c1Closed 3 (-2), and c1_defs_eq_closed_borromean there pins it to the six values. This file used to carry a second, specialised c1Closed (Z N : ℕ) — a duplicate declaration in the same namespace, and the weaker of the two — so it is dropped and everything below uses the parameterised one.

        ⚠ Note for anyone reading an older revision: the per-nucleon coefficients read (21Z + 16N) until 2026-09-06. Those are the pre-2026-09-05 (grouped) atom word's. Owner ruling qou-hu1f reordered each nucleon's confinement core and they became (3Z − 2N) — the neutron's changes sign. Both are (S_p, S_n)/2 for that word's per-nucleon deletion sums, (42, 32) grouped and (6, −4) canonical, and PairwiseChainLeadingOrder.c1_grouped_values_eq_closed keeps the superseded column as a check. The interface term −4(I_pp − I_nn) is unchanged, and is unchangeable by an intra-nucleon reordering: interfaces are single letters outside the nucleon blocks. See computations/probes/canonical_c1_closed_form_probe.py (44 isotopes, both halves verified separately) and docs/audits/2026-09-06-c1-is-stale-on-the-reordered-atom-word.md.

        source
        theorem QOU.MassTheory.c1Closed_bond_symmetry :
        c1Closed 3 (-2) 2 0 + c1Closed 3 (-2) 0 2 = 2 * c1Closed 3 (-2) 1 1

        The pp and nn bonds differ from the pn bond only through the interface term: c₁(pp) − c₁(pn) = (5·(1/8 − 1/16) − 4/16) and c₁(nn) − c₁(pn) = −5·(1/8 − 1/16) + 4/16. In particular c₁(pp) + c₁(nn) = 2·c₁(pn) — the interface contributions cancel in the symmetric combination and the census terms average.

        source
        theorem QOU.MassTheory.c1Closed_step (Z N : ℕ) (hZ : 1 ≤ Z) (hN : 2 ≤ N) :
        c1Closed 3 (-2) (Z + 1) (N - 1) - c1Closed 3 (-2) Z N = 5 * (2⁻¹ ^ (Z + N + 1) - 2⁻¹ ^ (2 * (Z + N))) - 8 * 2⁻¹ ^ (2 * (Z + N))

        At fixed A, c₁ is affine in Z with slope 5(2^{−A−1} − 2^{−2A}) − 8·2^{−2A} while both species stay present (1 ≤ Z, 2 ≤ N, so that after the move N − 1 ≥ 1): moving one neutron to a proton adds 5 to the census and shifts I_pp − I_nn by 2. (At N = 1 the truncated I_nn does not move and the shift is 1; that boundary case is excluded here.)

        4. The twelve words, letter by letter #

        Each list is the (w_ℓ, c(σ^{(ℓ)})) data of the non-averaged letters of one word, read off the canonical crossings by atom_canonical_crossings and a transposition product with that letter deleted (probe, Part B). Every deleted σ raises the cycle count by one and every deleted σ⁻¹ lowers it — visible in the lists as (1, c+1) and (−1, c−1) against c_free = 2A, c_atom = A+1, with the single nn-interface σ⁻¹ the one (−1, c+1).
