    structure QOU.MassTheory.BlockMeasure.FrobeniusPairingData (R : Type u_1) [CommRing R] (A : Type u_2) [Ring A] (Λ : Type u_3) [Fintype Λ] :
    Type (max (max u_1 u_2) u_3)

    Abstract Frobenius-pairing data for a Markov trace on a finite block set Λ: trM x = ∑ λ, y λ * χ λ x, with χ λ 1 = dim λ and the Markov axiom M1 trM 1 = 1. The characters are carried as functions A → R; nothing about their linearity or class-function property is needed below.

    • trM : A → R

      The Markov trace.

    • y : Λ → R

      The Markov (Frobenius-pairing) weight of each block.

    • χ : Λ → A → R

      The character of each block.

    • dim : Λ → ℕ

      The dimension of each block.

    • pairing (x : A) : self.trM x = ∑ l : Λ, self.y l * self.χ l x

      The Frobenius pairing tr_M = Σ_λ y_λ χ_λ.

    • χ_one (l : Λ) : self.χ l 1 = ↑(self.dim l)

      A character at the unit is the dimension.

    • trM_one : self.trM 1 = 1

      Markov axiom M1.
