    def QOU.MassTheory.isospinExchange {R : Type u_1} [CommRing R] {n : ℕ} (mag : Fin n → Fin n → R) (s : Fin n → R) :
    Matrix (Fin n) (Fin n) R

    Strong isospin-signed exchange matrix: diagonal 1, off-diagonal bond mag i j * s i * s j, where s : Fin n → R is the nucleon isospin labelling (+1 proton / -1 neutron, kept generic) and mag i j is the isospin-independent, geometry-only bond magnitude.

      The global isospin mirror s ↦ -s (proton ↔ neutron on every nucleon) fixes every entry of the strong exchange matrix, since (-s i)(-s j) = s i * s j.

      theorem QOU.MassTheory.isospinExchange_det_mirror_invariant {R : Type u_1} [CommRing R] {n : ℕ} (mag : Fin n → Fin n → R) (s : Fin n → R) :
      (isospinExchange mag fun (i : Fin n) => -s i).det = (isospinExchange mag s).det

      Strong-sector mirror invariance. The isospin-signed exchange determinant is invariant under the global proton↔neutron mirror. Hence any strong binding functional of this determinant assigns a mirror pair (³H and ³He) the same value: the strong ³H/³He split is exactly zero, so the observed ~1.10× split is non-strong (the Coulomb term).
