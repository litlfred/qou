    theorem QOU.MassTheory.abs_convex_combination_le {ι : Type u_1} (s : Finset ι) (w t : ι → ℝ) (M : ℝ) (hw : ∀ i ∈ s, 0 ≤ w i) (hsum : ∑ i ∈ s, w i = 1) (ht : ∀ i ∈ s, |t i| ≤ M) :
    |∑ i ∈ s, w i * t i| ≤ M

    A convex combination cannot exceed its largest term.

    If the weights w are non-negative and sum to 1, and every t i is bounded in absolute value by M, then so is ∑ w i * t i. Stated for an arbitrary finite index set, so it applies to the 2^(2A+1) branch expansion without that expansion being formalised.

    theorem QOU.MassTheory.atom_trace_le_max_branch {ι : Type u_1} (s : Finset ι) (w J : ι → ℝ) (M : ℝ) (hw : ∀ i ∈ s, 0 ≤ w i) (hsum : ∑ i ∈ s, w i = 1) (hJ : ∀ i ∈ s, |J i| ≤ M) :
    |∑ i ∈ s, w i * J i| ≤ M

    The pruning consequence. The atom element's Markov trace is bounded by the largest branch trace. Since the bound is a single max over branches, the question "can the atom carrier be large?" reduces from 2^(2A+1) independent questions to one: is any single branch large?
