        theorem QOU.MassTheory.damping_route_walled (q : ℝ) (hlo : 1109 / 1000 ≤ q) (hhi : q ≤ 111 / 100) (d : ℝ) (hd0 : 0 ≤ d) (hd1 : d ≤ 1) :
        d * dampGradRatio3 q < 3.8128 ∧ 13.0316 < dampGradRatio3 q * dampGradStep4 q

        The damping route is walled — the required correction is non-monotone in A. On the canonical substrate window [1.109, 1.11], the graded dimension undershoots A=3 (so a damping, which only subtracts, cannot close it — damping_cannot_close_A3) yet overshoots A=4 (substrate_A4_overshoots). The residual therefore changes sign between A=3 (+) and A=4 (−); a multiplicative damping D(A) ≤ 1 supplies a non-positive correction at every A and cannot realise a sign change.

        The statement packages the two directions as one certificate: at any substrate q in the window there is a damped-below A=3 value and an over-target A=4 value, so damped A=3 < target(3) while target(4) < undamped A=4.
