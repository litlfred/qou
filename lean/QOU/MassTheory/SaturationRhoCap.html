    theorem QOU.MassTheory.saturation_rho_cap_four (m : ℝ) (h0 : 0 ≤ m) (h1 : m ≤ 1) :
    (1 - m ^ 2) ^ 6 ≤ (1 + 3 * m) * (1 - m) ^ 3

    A=4 saturation cap (log-free): det₄ = (1+3m)(1−m)³ ≥ (1−m²)⁶, equivalently ρ₄ ≤ 6. The ⁴He strong target ρ_strong(4) ≈ 13 exceeds this cap of 6, so the isospin-even cumulant cannot supply the ⁴He binding magnitude for any m. The gap factorises as m³(1−m)³·h(m) with h(m) = 8 + 6m − 6m² − 8m³ + 3m⁵ + m⁶, and h(m) = 8(1−m) + 6(m−m²) + 8(m−m³) + 3m⁵ + m⁶ ≥ 0 on [0,1].
