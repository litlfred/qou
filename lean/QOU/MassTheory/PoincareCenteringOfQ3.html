    What /q³ in F_Bor actually is: a SECOND Poincaré centering #

    Bean qou-24w9. Attempt to derive the exponent in

    F_Bor(q) = |tr_M(β_Bor, q)| · [3]_q! / q³      (`m_p_substrate_identity_50dps.py:177`)

    which is asserted there as "the natural categorical observable", carries 37 % of m_p, and has no derivation trail.

    The candidate derivation, and what it gives #

    [n]_q! in the unbalanced convention is the Poincaré polynomial of Sₙ,

    [n]_q!^unbal = Σ_{w ∈ Sₙ} q^{ℓ(w)},     deg = ℓ(w₀) = n(n−1)/2,

    so q^{−ℓ(w₀)} is the canonical centering of it. Converting to the balanced convention carries exactly that factor:

    [n]_q!^balanced = q^{−n(n−1)/2} · [n]_{q²}!^unbal      (checked n = 1..6)

    For n = 3 this is q^{−3} — the exponent in question. So the factor has a canonical name after all: it is ℓ(w₀), the length of the longest element of S₃.

    But the code already uses the balanced convention, so it centers TWICE #

    m_p_substrate_identity_50dps.q_int is (qⁿ − q⁻ⁿ)/(q − q⁻¹) — balanced. So qfact_three is already the once-centered object, and F_Bor divides by q³ again:

    • balanced_is_already_centered — [3]_q!^bal = P(q) / q³
    • code_form_is_doubly_centered — [3]_q!^bal / q³ = P(q) / q⁶

    with P(q) = 1 + 2q² + 2q⁴ + q⁶ the Poincaré polynomial of S₃ in q². The code's object sits at q^{−2ℓ(w₀)}, twice the canonical centering.

    This is also why the bar-symmetry breaks (qou-24w9): the once-centered form [3]_q!^bal is bar-symmetric (balanced_is_bar_symmetric), and the second division destroys it.

    Verdict: NOT derived — but now precisely characterised #

    The exponent is not arbitrary — 3 = ℓ(w₀) is canonical — yet applying it to an already-balanced factorial is a second centering that no standard convention calls for, and it is the step that breaks bar-symmetry. So /q³ is identified, not justified.

    Two further facts keep this from being closed by inspection:

    1. n = 3 is degenerate. ℓ(w₀) = n(n−1)/2 equals n only at n = 3 (ell_w0_eq_n_iff_three). So the corpus's single 3-strand instance cannot distinguish "centering by ℓ(w₀)" from "one power per strand" — any 4-strand or 2-strand observable would, and none exists.
    2. The numerics need the doubling. Dropping the second centering moves m_p from 938.272089427 (−2.9·10⁻¹⁰ %) to 1285.39 (+37.0 %). So the doubled form is what reproduces CODATA, and the open question is what derives it — not whether it is numerically load-bearing.

    Scope-(a): this characterises the factor and rules out the "it is just the balanced/unbalanced conversion" reading (that conversion is already inside q_int). It does not refute F_Bor, and it does not touch the Lean-proved |tr_M(β_Bor)|.

            a ^ writhe borromeanWord ≠ (q ^ 3)⁻¹

            Attempt 2: no writhe prefactor can produce q⁻³ on this braid.

            markov-axioms-primitive.md states that link invariance is restored by the writhe prefactor outside the trace. Such a prefactor is a function of the writhe alone and multiplicative in it — w ↦ a^w. On β_Bor the writhe is 0, so every such prefactor equals 1, whatever a is. Hence none yields the q⁻³ that F_Bor applies, unless q³ = 1 — and at the substrate q₀ ≈ 1.11 it is not.

            This is the sharp form of the negative: /q³ does not merely lack a derivation trail, it is unreachable by the normalisation rule the corpus itself states, evaluated on the corpus's own braid word.

            Resolution: /q³ cannot be a state-dependent categorical factor #

            The mirror image of a link corresponds to q ↦ q⁻¹ in the Markov trace, and the corpus reads the bar involution as the conjugate (antiparticle) state (strand-twist-datum.md). So the bar-transform of the categorical factor is what distinguishes a state from its conjugate.

            Both of F_Bor's honest ingredients are blind to that:

            • trM_bar_invariant — the Lean-proved closed form (4+h²−3h⁴−h⁶)/(h²+4) is even in h = q − q⁻¹, and h ↦ −h under q ↦ q⁻¹, so tr_M is bar-invariant.
            • balanced_is_bar_symmetric (above) — [3]_q!^bal is bar-symmetric.

            So the only bar-asymmetric step is the /q³, and it is asymmetric by a definite amount:

            • fbor_mirror_ratio — F_Bor(q⁻¹) = q⁶ · F_Bor(q).

            At the substrate q₀ ≈ 1.11 that is q₀⁶ ≈ 1.87. Read as a state-dependent categorical factor, /q³ would therefore make a state and its conjugate differ by 87 % — which is not a small correction but a gross asymmetry.

            The resolution. /q³ cannot be a categorical factor attached to the state. It has to be a fixed normalisation applied identically to a state and its conjugate — in which case it is, by construction, a convention, not something the braid determines. That is consistent with every earlier finding here: it is unreachable by the writhe rule (no_writhe_prefactor_yields_inv_cube), it double-counts the Poincaré centering (code_form_is_doubly_centered), and it breaks the bar-symmetry both ingredients have.

            Interpretive caveat, stated: the identification "mirror ↦ q ↦ q⁻¹" is the standard Markov/HOMFLY behaviour and matches the corpus's reading of bar, but the physical step from there to a particle/antiparticle mass ratio is interpretation, not theorem. The theorems below are the algebra.
