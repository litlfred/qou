    The UIC block's displayed summand is even, so its total is sign-blind over ℝ #

    The archimedean half of the resolution of the prop:unified-iterative-correction block-vs-producer mismatch (owner ruling 2026-09-12: "resolve functionals ... what lean provable"). The generic half — where every theorem lives — is QOU.MassTheory.UICFunctionalSelection; this file only instantiates it at the summand the content block actually displays,

    f_d(τ) = ln|τ| − ln d ,

    and records that f_d is even. Real.log is the only archimedean construct here, which is why it is a separate file (AGENTS.md §7c).

    What this buys. Composed with uicAll_sign_blind it says: the total the content block writes down is unchanged when any subset of the block traces flips sign. Composed with gate_not_a_function_of_displayed_data it says the producer's Pass-2 gate — which keeps exactly the blocks with tr ≤ 0 — reads a datum this summand has destroyed. Hence the block's formula cannot denote the producer's functional, independently of which one the physics should keep.
