      Prop

      Removable corner on diagonal c, at row i.

      The cell (i, lam i - 1) is the last of its row and nothing sits below it in that column; its content is c, which in ℤ reads lam i = i + c + 1.

          theorem QOU.MassTheory.WeightedDirichletPoincare.no_removable_addable_same_diagonal {lam : ℕ → ℕ} (hmono : Antitone' lam) {i i' : ℕ} {c : ℤ} (hr : Removable lam i c) (ha : Addable lam i' c) :
          False

          THE COMBINATORIAL CORE. No partition has a removable corner and an addable corner on the same diagonal.

          This is what stops the edge weight (|u| + |v|) from vanishing: |u| + |v| = 0 would put both the removed and the added cell on the diagonal c = 0, which this forbids.

          theorem QOU.MassTheory.WeightedDirichletPoincare.one_le_weight {u v : ℤ} (h : u ≠ v) :

          The edge weight is at least 1. Two distinct integer contents cannot both be zero, so 1 ≤ |u| + |v|. Combined with no_removable_addable_same_diagonal, which is what rules out u = v = 0 on an actual up-down edge.

              theorem QOU.MassTheory.WeightedDirichletPoincare.poincare_transfer {ι : Type u_1} {R : Type u_2} [Field R] [LinearOrder R] [IsStrictOrderedRing R] (s : Finset ι) (w d : ι → R) (gap V : R) (hw : ∀ e ∈ s, 1 ≤ w e) (hpoincare : gap * V ≤ energy s d) :
              gap * V ≤ weightedEnergy s w d

              Poincaré transfer, at no loss of constant.

              If the unweighted form satisfies a Poincaré inequality gap · V ≤ energy, and every edge weight is at least 1, then the weighted form satisfies the same inequality with the same gap. This is the statement the (|u|+|v|)-weighted Fulman measure needed.

              theorem QOU.MassTheory.WeightedDirichletPoincare.weighted_lt_unweighted_of_small_weight :
              ∃ (s : Finset (Fin 1)) (w : Fin 1 → ℚ) (d : Fin 1 → ℚ), weightedEnergy s w d < energy s d

              1 ≤ w is load-bearing. A single edge with weight 1/2 and increment 1 has weighted energy strictly below the unweighted energy, so the domination is false without the bound.

              theorem QOU.MassTheory.WeightedDirichletPoincare.removable_and_addable_exist :
              ∃ (lam : ℕ → ℕ), Antitone' lam ∧ Removable lam 0 1 ∧ Addable lam 0 2

              The combinatorial core is not vacuous: removable and addable corners both exist, just never on one diagonal. The staircase-free partition lam = (2, 1, 0, 0, …) has a removable corner at row 0 on diagonal c = 1 and an addable corner at row 0 on diagonal c = 2.
