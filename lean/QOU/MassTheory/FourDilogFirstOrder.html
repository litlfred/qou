        fourDilog a b c d = 1 + (a + b + c + d) + (a * b + a * c + a * d + b * c + b * d + c * d + (a * b * c + a * b * d + a * c * d + b * c * d) + a * b * c * d)

        The missing part is second-order-and-up in the missing tetrahedra together with their first order. Symmetric companion: dropping the whole octahedral completion (a alone kept) and comparing to the identity isolates a as the sole surviving first-order term.

        Bar-parity of the octahedral orders (the #4158 discriminating-test structure) #

        The bar involution q ↦ q⁻¹ acts on the single-tetrahedron amplitudes as aᵢ ↦ −aᵢ (they are bar-odd, being linear in v − v⁻¹, v = √q). Under this the elementary-symmetric orders split by parity: the linear part e₁ is bar-odd and the quadratic part e₂ is bar-even. This is the exact structure the #4158 Magnus route found for the deuteron −9.21%: a bar-odd linear impurity t = (v−v⁻¹)/[2]_v ⊕ a bar-even quadratic gap h² = (v−v⁻¹)²[2]_v². The two routes converge on this parity split (octahedral_barsplit_convergence_probe.py); the bar-even e₂ coefficient (≈ 1.0·h²) is the shared remaining open.
