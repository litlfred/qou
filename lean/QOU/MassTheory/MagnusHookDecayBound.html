    The sharp bound on the hook column of the gauge-invariant curvature (qou-o6ov) #

    Context (#6464, #6480, and magnus_gauge_hook_decay_bound_probe.py). On a hook (k,1ⁿ⁻ᵏ) = Λʲ(V), j = n − k, the projector curvature Ω₂^P has the reduced-Burau closed form

    tr_hook(ρ·Ω₂^P) = c · Σ_a [ e_j(μ⁺_a) − e_j(μ⁻_a) ],    c = (4/[2]_q²)·q^{(L+2)(1−j)},

    with μ^±_a the Burau spectra of the commutator-member words ρσ_aσ_{a+1}, ρσ_{a+1}σ_a (MagnusGaugeCurvatureHookColumn.trace_mul_curvature_eq_of_word_traces). For hooks b(λ) = n − λ₁ = j, so a bound in j is the hook-column decay statement.

    The probe measured two bounds. The crude spectral-radius bound |e_j| ≤ C(n−1,j)·rʲ is a binomial hump (it decays only past j ≈ (n−1)·d/(1+d), d = q^{−(L+2)}·r ≈ q^{−2}·(r/q^L) — the twist exactly cancels the dominant Burau eigenvalue ≈ q^L, so the crude bound throws away the whole subdominant spectrum). The sharp bound keeps it:

    |tr_hook(ρ·Ω₂^P)| ≤ |c| · Σ_a [ e_j(|μ⁺_a|) + e_j(|μ⁻_a|) ]  =: B'_j,

    and B'_j / C(n−1,j) is strictly decreasing in j at A = 2 and A = 3 (exact mpf), while the crude bound is not. This file formalizes the only inequality the sharp bound uses.

    What is formalized. Three sorry-free lemmas over a generic linearly ordered commutative ring (the ordering is what |·| needs — this is the §7c archimedean-side specialisation, kept in its own file so MagnusHookExteriorPower stays a bare CommRing statement):

    • abs_esymm_le_esymm_abs — the triangle inequality for the elementary symmetric sum: |e_j(μ)| ≤ e_j(|μ|).
    • abs_sum_esymm_sub_le — applied across the commutator sum: |Σ_a (e_j(μ⁺_a) − e_j(μ⁻_a))| ≤ Σ_a (e_j(|μ⁺_a|) + e_j(|μ⁻_a|)).
    • abs_mul_sum_esymm_sub_le — with the twist scalar c: |c·Σ_a(…)| ≤ |c|·Σ_a(…), which is exactly B'_j.

    What is not. The monotonicity of B'_j / C(n−1,j) in j is a property of the measured Burau moduli (they fall off geometrically, ratio ≈ 0.71–0.77 per step at A = 2, 3), not a theorem for arbitrary spectra; the seminormal construction, the atom word and the twist are outside Mathlib, as in the sibling files. The lemmas here turn "the hook column decays" into a statement about one list of moduli per commutator member — which the probe then checks.

    theorem QOU.MassTheory.abs_esymm_le_esymm_abs {ι : Type u_1} [Fintype ι] {R : Type u_2} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] (j : ℕ) (μ : ι → R) :
    |esymm j μ| ≤ esymm j fun (i : ι) => |μ i|

    Triangle inequality for the elementary symmetric sum. |e_j(μ)| ≤ e_j(|μ|): the j-th elementary symmetric function of a spectrum is bounded by the same function of its moduli. This is the single inequality behind the sharp hook-column bound.

    theorem QOU.MassTheory.abs_sum_esymm_sub_le {ι : Type u_1} [Fintype ι] {R : Type u_2} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] (j m : ℕ) (μp μm : ℕ → ι → R) :
    |∑ a ∈ Finset.range m, (esymm j (μp a) - esymm j (μm a))| ≤ ∑ a ∈ Finset.range m, ((esymm j fun (i : ι) => |μp a i|) + esymm j fun (i : ι) => |μm a i|)

    Across the commutator sum. Each member of Σ_a (e_j(μ⁺_a) − e_j(μ⁻_a)) is bounded by the sum of the two moduli-symmetric values, so the whole signed sum is bounded by Σ_a (e_j(|μ⁺_a|) + e_j(|μ⁻_a|)).

    theorem QOU.MassTheory.abs_mul_sum_esymm_sub_le {ι : Type u_1} [Fintype ι] {R : Type u_2} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] (c : R) (j m : ℕ) (μp μm : ℕ → ι → R) :
    |c * ∑ a ∈ Finset.range m, (esymm j (μp a) - esymm j (μm a))| ≤ |c| * ∑ a ∈ Finset.range m, ((esymm j fun (i : ι) => |μp a i|) + esymm j fun (i : ι) => |μm a i|)

    The sharp bound B'_j. With the twist scalar c = (4/[2]_q²)·q^{(L+2)(1−j)} in front, |c · Σ_a (e_j(μ⁺_a) − e_j(μ⁻_a))| ≤ |c| · Σ_a (e_j(|μ⁺_a|) + e_j(|μ⁻_a|)). Composed with trace_mul_curvature_eq_of_word_traces, the left side is |tr_hook(ρ·Ω₂^P)| and the right side is the bound the probe finds strictly decreasing per dimension.
