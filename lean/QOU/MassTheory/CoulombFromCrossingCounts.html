          2. The counts DO reach the proton-pair multiplicity — quadratically #

          theorem QOU.MassTheory.CoulombFromCrossingCounts.protonPairs_from_counts {R : Type u_1} [CommRing R] (A Z : R) :
          16 * protonPairs Z = (nPlus A Z - nMinus A Z) * (nPlus A Z - nMinus A Z - 4)

          The point of this file. Z(Z-1) is an exact quadratic function of the crossing counts, with no hypotheses and no division:

          16·Z(Z-1) = (n₊ - n₋)·(n₊ - n₋ - 4)

          CrossingCountAffine.no_crossing_combination_is_protonPairs excludes the linear combinations only; this is what lies immediately outside that class.

          3. The two statements side by side #

          The linear exclusion and the quadratic construction are both true, of the same counts, at the same (A, Z).

          source
          theorem QOU.MassTheory.CoulombFromCrossingCounts.quadratic_escapes_linear_exclusion (A : ℤ) :
          (∀ (a b c : ℤ), ¬∀ (Z : ℤ), a * nPlus A Z + b * nMinus A Z + c = protonPairs Z) ∧ ∀ (Z : ℤ), 16 * protonPairs Z = (nPlus A Z - nMinus A Z) * (nPlus A Z - nMinus A Z - 4)

          Located, not contradicted. For every choice of linear coefficients there is a Z at which the linear form misses Z(Z-1) — that is CrossingCountAffine's content — while the quadratic form matches at every Z, with the coefficient fixed in advance. Over ℤ.

          4. The length scale — what its cube must satisfy #

          A Coulomb energy is ∝ Z(Z-1)/R with R ∝ A^{1/3}. The cube root is archimedean (§7c) and is deliberately NOT taken here; what is stated is the algebraic condition its cube satisfies, which is where the substrate content lives.

          source
          def QOU.MassTheory.CoulombFromCrossingCounts.IsChannelScale {R : Type u_1} [CommRing R] (A Z s : R) :
          Prop

          A scale s is the Coulomb-channel length scale exactly when its cube is that channel. Purely definitional — recorded so the downstream archimedean specialisation has a generic statement to instantiate, rather than introducing Real.rpow on this side of the wall.
