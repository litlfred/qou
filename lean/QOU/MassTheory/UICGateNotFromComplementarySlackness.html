    QOU.MassTheory.UICGateNotFromComplementarySlackness #

    The Pass-2 sign gate in hecke_core_legacy.unified_iterative_correction is not a consequence of complementary slackness on the operator-selection LP.

    What the producer does, and what it says it is doing #

    computations/hecke_core_legacy.py:2176-2199 keeps a Wedderburn block only when final_tr_sign <= 0 and returns that gated sum. Its comment derives the gate from LP duality, verbatim:

    LP duality theorem: on the OPTIMAL primal-dual pair (Φ*, y*), y_λ* × ⟨Φ*, π_λ⟩_F = 0 for every partition λ. So y_λ* > 0 only when the Frobenius constraint is TIGHT at the atom's FINAL state, i.e. tr(M_λ(W_atom)) ≤ 0. Partitions with positive final trace are SLACK → y_λ* = 0 → zero contribution.

    The LP being invoked exists: it is [prop:operator-selection-lp], formalised in QOU.ParticleInteractions.operator_selection_lp, whose OperatorSelectionLpContext carries the cost vector t, the Frobenius Gram G, a primal point x* and the Frobenius multipliers s (the narrative's y*), and whose complementary_slackness_x_star is exactly ∀ i, sᵢ (Gx*)ᵢ = 0.

    Where the inference fails #

    The comment identifies two different vectors. Complementary slackness constrains the constraint value (Gx*)ᵢ — a function of the operator the LP is selecting. The gate reads the cost entry t_λ = tr(M_λ(W_atom)) — a datum of the atom, fixed before any optimisation, appearing in the LP only as the objective. Three results below, and one witness:

    • frobeniusValue_nonpos_iff_eq_zero — on any primal-feasible point the constraint value is non-negative, so ≤ 0 and = 0 are the same predicate on it. A sign gate read on a Frobenius constraint value is therefore the tightness gate, and keeps only blocks sitting exactly at zero. The producer's gate keeps 4 of 10 blocks at A = 2 and returns -0.0896, so it is not reading a constraint value of any feasible point of this LP.
    • frobeniusValue_of_diagonal / complementarySlackness_diagonal_iff — in the Wedderburn basis the block projectors are orthogonal idempotents, so G_{λμ} = tr_M(P_λ P_μ) = δ_{λμ} tr_M(P_λ) is diagonal, complementary slackness decouples to s_λ · G_{λλ} · x_λ = 0, and the cost vector does not occur in it at all. (Measured independently in computations/probes/h6_block_selection_lp_probe.py, which found the LP selects 10-11 of 11 blocks at every reachable target for this reason.)
    • exists_lpData_activeSet_gateSet_disjoint — the refutation. There is a genuine OperatorSelectionLpContext (built through the corpus's own ofCertificate, so every LP hypothesis holds and the duality gap is derived) in which complementary slackness holds, the active set {i | 0 < sᵢ} is non-empty, the gate set {i | tᵢ ≤ 0} is non-empty, and the two are disjoint. So y_λ* > 0 does not imply t_λ ≤ 0: the implication the comment asserts has a counterexample inside the very program it cites.

    Scope #

    This is a scope-(b) structural exclusion in the sense of AGENTS.md §"Before declaring refuted": the invariant is primal feasibility of the Frobenius constraints (0 ≤ (Gx)ᵢ, a defining conjunct of IsFeasible), together with the orthogonality of Wedderburn projectors which makes the Gram diagonal. It excludes complementary slackness on this LP as a derivation of a sign gate on the cost vector — for every n, every q, and every trace convention, since neither invariant depends on them.

    It does not say the producer's gate is numerically wrong, and it does not exclude some other selection principle. It says this justification has no referent, which is what the owner's 2026-09-12 hunt asked.

    A Frobenius constraint value cannot be negative on a feasible point.

    IsFeasible demands 0 ≤ (Gx)ᵢ for every i, so the predicate (Gx)ᵢ ≤ 0 collapses to (Gx)ᵢ = 0. "Sign gate" and "tightness gate" are the same predicate when read on a constraint value; they differ only when read on something that is not a constraint value of a feasible point.

    Orthogonal Wedderburn projectors make the Gram diagonal, and a diagonal Gram collapses the Frobenius constraint value to a single product.

    G_{λμ} = tr_M(P_λ P_μ) = δ_{λμ} tr_M(P_λ) because block projectors are orthogonal idempotents.

    theorem QOU.MassTheory.UICGateLP.complementarySlackness_diagonal_iff {R : Type u_1} [CommRing R] {d : ℕ} {G : Fin d → Fin d → R} {x s : Fin d → R} (hdiag : ∀ (a b : Fin d), a ≠ b → G a b = 0) :
    (∀ (i : Fin d), s i * ∑ j : Fin d, G i j * x j = 0) ↔ ∀ (i : Fin d), s i * (G i i * x i) = 0

    Complementary slackness does not mention the cost vector.

    Under a diagonal Gram the condition ∀ i, sᵢ (Gx)ᵢ = 0 is equivalent to ∀ i, sᵢ · G_{ii} · xᵢ = 0, an equation in the multipliers, the block norms and the selected operator's coefficients. The Markov traces of the atom — the producer's t_λ — do not occur. No predicate on t follows from it.

    The witness #

    A two-index instance with G = I, x* = (1, 0), n_target = 1, multipliers s = (0, 2) and y₀* = -1, hence — by dual feasibility tⱼ = y₀ + Σᵢ sᵢGᵢⱼ — cost t = (-1, 1). Every LP hypothesis holds and complementary slackness holds, yet the active index is 1 while the only index the sign gate keeps is 0.

    theorem QOU.MassTheory.UICGateLP.exists_lpData_activeSet_gateSet_disjoint :
    ∃ (d : ℕ) (n_target : ℤ) (y_0 : ℤ) (t : Fin d → ℤ) (G : Fin d → Fin d → ℤ) (x : Fin d → ℤ) (s : Fin d → ℤ), (∀ (i : Fin d), 0 ≤ s i) ∧ (∀ (j : Fin d), t j = y_0 + ∑ i : Fin d, s i * G i j) ∧ ∑ j : Fin d, x j = n_target ∧ (∀ (i : Fin d), 0 ≤ ∑ j : Fin d, G i j * x j) ∧ (∀ (i : Fin d), s i * ∑ j : Fin d, G i j * x j = 0) ∧ (∃ (i : Fin d), 0 < s i) ∧ (∃ (i : Fin d), t i ≤ 0) ∧ ∀ (i : Fin d), ¬(0 < s i ∧ t i ≤ 0)

    The refutation.

    The witness data satisfy every hypothesis of the operator-selection LP — non-negative multipliers, dual feasibility tⱼ = y₀ + Σᵢ sᵢGᵢⱼ, the net constraint, Frobenius positivity, and complementary slackness — and yet

    • the active set {i | 0 < sᵢ} is non-empty (it is {1});
    • the gate set {i | tᵢ ≤ 0} is non-empty (it is {0});
    • the two are disjoint.

    So on the program the producer's comment cites, y_λ* > 0 does not imply t_λ ≤ 0. The Pass-2 sign gate is not a consequence of complementary slackness — the implication has a counterexample inside the LP itself.

    The same data are packaged as ctxW, whose mere type-correctness certifies that they form a genuine OperatorSelectionLpContext with a derived zero duality gap; ctxW_t, ctxW_s and ctxW_G identify its fields with the data used here.
