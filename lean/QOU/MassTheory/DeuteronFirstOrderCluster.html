          The deuteron collapse: the μ₃ door is identically zero at A = 2 #

          source
          theorem QOU.MassTheory.DeuteronFirstOrderCluster.secondDiff_single_bond_vanishes (g₀ gₐ : Int) :
          secondDiff g₀ gₐ g₀ gₐ = 0

          A single-bond (deuteron) configuration is one where the second interface bond b is absent, encoded by "adding b changes nothing": g_b = g_∅ and g_ab = g_a. Under this the second mixed difference vanishes identically. The μ₃ submodularity door therefore supplies nothing to a single-bond object — regardless of the (unknown, possibly submodular) sign of the joint trace, because there is no second bond for it to act on.

          theorem QOU.MassTheory.DeuteronFirstOrderCluster.cluster3_single_bond_vanishes (E₀ g₀ gₐ : Int) :
          cluster3 E₀ g₀ gₐ g₀ gₐ = 0

          The telescoping decomposition: where the deuteron content actually lives #

          source
          theorem QOU.MassTheory.DeuteronFirstOrderCluster.total_change_decomp (g₀ gₐ g_b gₐᵦ : Int) :
          gₐᵦ - g₀ = firstDiff g₀ gₐ + firstDiff g₀ g_b + secondDiff g₀ gₐ g_b gₐᵦ

          Möbius / inclusion decomposition of the total two-bond change. The full change of the joint block-trace from the empty configuration to both bonds present decomposes exactly into the two first-order (single-bond) terms plus the one second-order (3-body) term:

          g_ab − g_∅ = Δ¹g_a + Δ¹g_b + Δ²g.

          This is the finite Möbius inversion on the Boolean lattice {∅, a, b, ab}.

          source
          theorem QOU.MassTheory.DeuteronFirstOrderCluster.deuteron_content_is_first_order (g₀ gₐ : Int) :
          gₐ - g₀ = firstDiff g₀ gₐ + firstDiff g₀ g₀ + secondDiff g₀ gₐ g₀ gₐ ∧ firstDiff g₀ g₀ = 0 ∧ secondDiff g₀ gₐ g₀ gₐ = 0

          The deuteron's binding content is entirely FIRST-order. Specialising the decomposition to a single-bond configuration (g_b = g_∅, g_ab = g_a): the total change equals firstDiff g₀ gₐ alone — the second-order (μ₃) and the absent-bond first-order terms both vanish. Hence the deuteron magnitude is carried by the bare per-bond amplitude Δ¹g, and any deficit in it (the 5.853×) cannot be recovered from cluster structure, which is empty here.

          Contrapositive framing: a nonzero μ₃ contribution REQUIRES a real second bond #

          The only way the second mixed difference is nonzero is if the second bond is genuinely present — i.e. g_b ≠ g_∅ or g_ab ≠ g_a. For the deuteron neither holds (there is one bond), so the door is provably shut-because-absent.

          theorem QOU.MassTheory.DeuteronFirstOrderCluster.nonzero_cluster_needs_second_bond {g₀ gₐ g_b gₐᵦ : Int} (h : secondDiff g₀ gₐ g_b gₐᵦ ≠ 0) :
          g_b ≠ g₀ ∨ gₐᵦ ≠ gₐ

          A nonzero μ₃ door forces a genuinely present second bond. If secondDiff g₀ gₐ g_b gₐᵦ ≠ 0 then the configuration is not single-bond: g_b ≠ g₀ ∨ gₐᵦ ≠ gₐ. Contrapositive of secondDiff_single_bond_vanishes lifted to arbitrary second-bond values — the μ₃ mechanism is exclusive to A ≥ 3.
