        theorem QOU.MassTheory.FrameAmbiguity.frame_diff_second_order {R : Type u_1} [Field R] (t : R) (ht : t ≠ 1) :
        Cinv t - Clin t = t ^ 2 / (1 - t)

        The two resummations agree at first order and differ at exactly second order: 1/(1−t) − (1+t) = t²/(1−t). The frame ambiguity is O(t²), never O(t).

        theorem QOU.MassTheory.FrameAmbiguity.g_frame_difference {R : Type u_1} [Field R] (t hsq : R) (ht : t ≠ 1) (hh : hsq ≠ 0) :
        (Cinv t - 1) / hsq - (Clin t - 1) / hsq = t ^ 2 / ((1 - t) * hsq)

        The bar-even coefficient inherits the O(t²) frame difference. With the bar-even tier extracted as g = (C − 1)/h² after using bar-odd frame C, the two frames differ by (Cinv − Clin)/h² = t²/((1−t) h²). Since t = O(h), this is O(1) in h — the same size as g itself, so g (hence r = g − 1) is not frame-invariant.

        theorem QOU.MassTheory.FrameAmbiguity.common_first_order {R : Type u_1} [Field R] (t : R) (ht : t ≠ 1) :
        Cinv t - Clin t = t ^ 2 * (1 / (1 - t))

        First-order (frame-invariant) content. Both frames reduce to 1 + t modulo O(t²): their difference vanishes to first order, so the prediction through O(t) is frame-independent. Stated as: the linearisations coincide (Clin is the common first-order part, and Cinv − Clin has no constant or linear term — it is t²·(1/(1−t))).
