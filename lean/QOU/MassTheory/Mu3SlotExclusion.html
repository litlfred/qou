    The exclusion survives the GAP-7 slot correction: ∑Δ²g + Δ³g ≥ 0 on the whole class #

    Mu3BlockwiseExclusion (merged) shows that a per-block multiplicatively-damped Wedderburn trace has Δ²g ≥ 0, closing the μ₃ door for that class at the level of the pair term. But the merged GAP-7 work (UrsellSlotAlignment.triangle_moment_decomp) established that the moments and the differences are indexed differently — μₖ by particle count, Δᵐg by bond count — so the triangle's correct assembly is

    μ₃-slot  =  ∑_{pairs} Δ²g  +  Δ³g .

    That correction is not a formality here, because the third difference of a multiplicative block has the opposite sign:

    Δ³ = −c(1−r_a)(1−r_b)(1−r_c)  ≤ 0     (`thirdDiff_multiplicative`)

    so the triple term pushes toward the door and could in principle overturn the pair-term exclusion. This file proves it does not.

    The result #

    With damping factors in [0, 1], writing u = 1−r_a, v = 1−r_b, w = 1−r_c ∈ [0,1]:

    ∑Δ² + Δ³  =  c·(uv + uw + vw − uvw)  ≥  0

    because uvw ≤ uv (as w ≤ 1) while uw, vw ≥ 0. Hence slot_nonneg_multiplicative and, by block-linearity of both differences, mu3_slot_ne_blockwise_multiplicative — μ₃ > 0 is unreachable by a per-block multiplicatively-damped trace even under the corrected slot assembly.

    This is the structural counterpart of the numerical observation reported when GAP-7 landed (the correction "roughly doubles the magnitude but preserves the sign"): here the sign-preservation is proved for the entire class, not measured on two isotopes.

    Honest scope #

    Unchanged from Mu3BlockwiseExclusion: this excludes the per-block multiplicatively-damped class. It does not show the H₉ |χ| joint traces lie in that class. Note also that the triple result needs, beyond the pair result's r ≤ 1, only a single extra lower bound 0 ≤ r_c (used for uv(1−w) ≥ 0) — not 0 ≤ r on all three. The formalization found this: nlinarith closed the goal without the other two, so they were dropped rather than left in as decorative hypotheses.

    Verified lean-direct exit 0, sorry-free.

      Mixed-sign weights: the exhaustive door-mechanism dichotomy #

      source
      theorem QOU.MassTheory.Mu3SlotExclusion.secondDiff_eq_baseline_mul_slack (c rₐ r_b rₐᵦ : ℝ) :
      Mu3ClusterModularity.secondDiff c (c * rₐ) (c * r_b) (c * rₐᵦ) = c * (rₐᵦ - (rₐ + r_b - 1))

      The Fréchet slack IS the normalized second difference. In damping coordinates Δ² = c·(r_ab − (r_a + r_b − 1)), i.e. the baseline times the Fréchet–Hoeffding slack. This is what makes the slack the weight-independent invariant: the block weight y_λ cancels out of every ratio r, so the slack is a statement about the character alone, and the weight enters only as the outer factor.

      theorem QOU.MassTheory.Mu3SlotExclusion.door_mechanism_dichotomy {w d : ℝ} (h : w * d < 0) :
      0 < w ∧ d < 0 ∨ w < 0 ∧ 0 < d

      Exhaustive dichotomy of the two door mechanisms. A block can only push the total submodular in one of exactly two structurally distinct ways:

      • 0 < w ∧ d < 0 — submodular geometry carried by a positive weight: a genuine Fréchet–Hoeffding violation (the block's joint damping falls below r_a + r_b − 1);
      • w < 0 ∧ 0 < d — supermodular geometry carried by a negative weight: no Fréchet violation at all, just a sign-indefinite Wedderburn coefficient.

      Conflating these reports a bookkeeping sign as a geometric fact. They are measured separately by mu3_frechet_perblock_probe.py.

      Under convention D the second branch is VACUOUS. w < 0 never occurs on the physical spectrum (see reweight_cannot_open_door above: zero negative y_λ for n = 4 … 12), so a submodular total can only come from the first mechanism — submodular geometry carried by a positive weight. The dichotomy itself is a theorem about arbitrary reals and is unaffected; what changes is which branch the physics can occupy.
