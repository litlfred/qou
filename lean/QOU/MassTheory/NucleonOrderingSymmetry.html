    QOU.MassTheory.NucleonOrderingSymmetry #

    The same-species orbit symmetrization of an atomic braid word is the IDENTITY MAP; the cross-species reordering is not a symmetry of the construction at all.

    Bean qou-prjo. Companion to TransversePairingClusterDecomposition (the pairing is exactly bilinear) and GermRootVectorGaugeFixing.

    Why this file exists #

    PR #4849 measured the multi-generator transverse NA-Stokes pairing, found it super-pairwise, and then disqualified it on the ground that it depends on the nucleon ordering (pnn / npn / nnp), citing the corpus orbit identity tr_M(β) = tr_M(rep) as evidence that the corpus's own scalar observable is ordering-invariant.

    That citation conflates two different permutation groups. The corpus identity (computations/atom_orbit_reduction.py; docs/audits/2026-05-30-orbit-trace-identity-proof.md) is over S_Z × S_N — protons among protons, neutrons among neutrons — and its Lemma 1 establishes it by showing that such a permutation leaves the braid word unchanged. This file formalises exactly that distinction:

    • wordOf_of_speciesPreserving — a species-preserving relabelling leaves the word literally equal. Hence
    • sum_symmetrize_eq_nsmul — summing any readout f over a finite set of such relabellings gives card • f (word): orbit-symmetrization over the forced group is the identity map, for every readout, scalar or operator-valued. It cannot cancel anything, so a nonzero residual survives it trivially.
    • ifaces_pnn_ne_ifaces_npn and wordOf_pnn_ne_wordOf_npn — a cross-species reordering changes the interface list, hence changes the word. It is therefore not a symmetry of the construction, and no invariance under it can be assumed.

    What is NOT proved — read before citing #

    • Nothing here derives a magnitude: no binding energy, no Δ_λ, no transverse-pairing value, no AME comparison. sorry-free ≠ derived.
    • This does not revive the transverse route. It removes one of the two blockers #4849 named (the demand for a nucleon-symmetric readout, which is vacuous). The other — which two germ observers, plus the representation gauge — is untouched and still binding.
    • wordOf_pnn_ne_wordOf_npn is proved under the hypotheses that the pn interface letter is distinct from the nn one and does not occur inside either intra-nucleon chain. Both hold for the corpus letters (pp = σ, nn = σ⁻¹, pn = σ − h(½ − δ/4) on the interface generator, which no intra chain uses), but they are hypotheses here, not corpus facts imported into Lean.

    Base ring (§7c). No ring at all: the content is combinatorial. Letters live in a generic type L (DecidableEq only where the counting argument needs it); the symmetrization lemma takes a generic AddCommMonoid M target. No ℝ, no ordering, no Real.*.

                  2. Same-species relabelling fixes the word — Lemma 1, formalised #

                  source
                  theorem QOU.MassTheory.NucleonOrdering.wordOf_of_speciesPreserving {L : Type u_1} {A : ℕ} (intra : Species → List L) (lk : Iface → L) (s : Fin A → Species) (σ : Fin A → Fin A) (h : ∀ (k : Fin A), s (σ k) = s k) :
                  wordOf intra lk (List.ofFn fun (k : Fin A) => s (σ k)) = wordOf intra lk (List.ofFn s)

                  The word depends on the nucleon labelling only through the species string. A relabelling σ of nucleon indices that preserves species (s (σ k) = s k — exactly the condition defining S_Z × S_N) leaves the species string, hence the whole word, literally unchanged.

                  This is Lemma 1(a) of the orbit-trace identity proof. Note what it does not say: it is not an invariance of a readout under a nontrivial transformation of the word. The word never moves.

                  source
                  theorem QOU.MassTheory.NucleonOrdering.sum_symmetrize_eq_nsmul {L : Type u_1} {A : ℕ} {M : Type u_2} [AddCommMonoid M] (intra : Species → List L) (lk : Iface → L) (s : Fin A → Species) (G : Finset (Fin A → Fin A)) (hG : ∀ σ ∈ G, ∀ (k : Fin A), s (σ k) = s k) (f : List L → M) :
                  ∑ σ ∈ G, f (wordOf intra lk (List.ofFn fun (k : Fin A) => s (σ k))) = G.card • f (wordOf intra lk (List.ofFn s))

                  Orbit-symmetrization over the forced group is the identity map.

                  For any readout f — scalar trace, operator norm, the transverse pairing, anything — summing over a finite family G of species-preserving relabellings returns G.card • f (word). Averaging over the S_Z × S_N orbit therefore changes nothing: it cannot cancel a residual, and it cannot create one.

                  The hypothesis is the whole content: it is what fails for a cross-species reordering (§3).

                  3. Cross-species reordering is not a symmetry #

                  source
                  theorem QOU.MassTheory.NucleonOrdering.ifaces_pnn_ne_ifaces_npn :
                  ifaces [Species.p, Species.n, Species.n] ≠ ifaces [Species.n, Species.p, Species.n]

                  The tritium orderings of PR #4849 §5.1 have different interface lists: pnn ↦ [pn, nn] but npn ↦ [pn, pn]. They are not related by any species-preserving relabelling, and no corpus identity covers them.

                  source
                  theorem QOU.MassTheory.NucleonOrdering.count_link_pn {L : Type u_1} [DecidableEq L] (intra : Species → List L) (lk : Iface → L) (hp : lk Iface.pn ∉ intra Species.p) (hn : lk Iface.pn ∉ intra Species.n) (hnn : lk Iface.pn ≠ lk Iface.nn) (hpp : lk Iface.pn ≠ lk Iface.pp) (ss : List Species) :
                  List.count (lk Iface.pn) (wordOf intra lk ss) = List.count Iface.pn (ifaces ss)

                  Counting the pn interface letter in the word recovers the interface list's pn count, provided that letter is distinct from the other two interface letters and does not occur inside either intra-nucleon chain.

                  source
                  theorem QOU.MassTheory.NucleonOrdering.wordOf_pnn_ne_wordOf_npn {L : Type u_1} [DecidableEq L] (intra : Species → List L) (lk : Iface → L) (hp : lk Iface.pn ∉ intra Species.p) (hn : lk Iface.pn ∉ intra Species.n) (hnn : lk Iface.pn ≠ lk Iface.nn) (hpp : lk Iface.pn ≠ lk Iface.pp) :
                  wordOf intra lk [Species.p, Species.n, Species.n] ≠ wordOf intra lk [Species.n, Species.p, Species.n]

                  The cross-species reorderings produce different words. With the corpus's distinct interface letters, pnn carries one pn crossing and npn carries two, so the words are not equal.

                  Together with sum_symmetrize_eq_nsmul this is the whole finding: the group the corpus's orbit identity ranges over acts trivially, while the group PR #4849 varied over is not a symmetry of the construction — the word genuinely changes.
