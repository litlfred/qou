    theorem QOU.MassTheory.B3SignOneRoot.phi3_chain {R : Type u_1} [CommRing R] (g01 g12 : R) :
    UrsellPartitionFunctionB3.phi3 g01 0 g12 = g01 * g12

    A missing bond is f = 1. The production A = 3 word bonds only adjacent nucleons, so one of the three pairs carries no interface letter; its Mayer variable is g = f − 1 = 0. On that bond set the third Ursell function collapses from four connected graphs to one — the single path — and is a product.

    theorem QOU.MassTheory.B3SignOneRoot.b3corpus_chain_neg_of_same_sign {K : Type u_2} [Field K] [LinearOrder K] [IsStrictOrderedRing K] {f01 f12 : K} (h : 1 < f01 ∧ 1 < f12 ∨ f01 < 1 ∧ f12 < 1) :
    UrsellPartitionFunctionB3.b3corpus f01 1 f12 < 0

    🛑 THE CORRECTION — uniform attraction does not escape. On a chain φᵀ₃ is a product of two Mayer variables, so flipping both bonds from repulsive to attractive leaves the sign of b₃ unchanged. Both cases in one statement: whenever the two bonds sit on the same side of 1, b₃ < 0.

    So "a positive term needs a bond factor above 1" is necessary, not sufficient.

    The sharp condition. On a two-bond chain the cumulant is positive exactly when the two bonds lie on opposite sides of 1 — i.e. exactly one of them is attractive.

    The production interface family is confined to (0,1) — not proved here. That is QBeta.SingleCrossingAlwaysBinds.interface_mem_Ioo (μ ≤ z < 1 whenever q³ < q² + 1, which the substrate anchor satisfies with 24 % to spare). What this file adds is the consequence: fed into b3corpus_chain_neg, it makes the production chain negative whatever the typing. The hypothesis below is therefore stated as what it is — an input from that file.

    theorem QOU.MassTheory.B3SignOneRoot.confined_bonds_force_b3_neg {K : Type u_2} [Field K] [LinearOrder K] [IsStrictOrderedRing K] {f01 f12 : K} (h01 : 0 < f01 ∧ f01 < 1) (h12 : 0 < f12 ∧ f12 < 1) :
    UrsellPartitionFunctionB3.b3corpus f01 1 f12 < 0

    The one root, assembled. If both chain bonds come from any family confined to (0,1) — the production letters by SingleCrossingAlwaysBinds.interface_mem_Ioo, the isospin channels by projector_bonds_lt_one — then the connected three-body cumulant is negative. One hypothesis, one conclusion; the three constructions differ only in what they compute around it.

    Stated with the confinement as an explicit hypothesis rather than derived, so that a future family escaping (0,1) is visible as a failed hypothesis and not a hidden one.
