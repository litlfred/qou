    noncomputable def QOU.MassTheory.singleSupportCost (w a b : ℝ) :
    ℝ

    The cost of the single-support solution at a coordinate with constraint coefficient a and cost weight w: put all the mass there (x = b / a) and pay w · |x|.

    Equations
    • QOU.MassTheory.singleSupportCost w a b = w * |b| / |a|

      theorem QOU.MassTheory.both_orderings_achievable (a₁ a₂ b : ℝ) (ha₁ : a₁ ≠ 0) (ha₂ : a₂ ≠ 0) (hb : b ≠ 0) :
      (∃ (w₁ : ℝ) (w₂ : ℝ), 0 < w₁ ∧ 0 < w₂ ∧ singleSupportCost w₁ a₁ b < singleSupportCost w₂ a₂ b) ∧ ∃ (w₁ : ℝ) (w₂ : ℝ), 0 < w₁ ∧ 0 < w₂ ∧ singleSupportCost w₂ a₂ b < singleSupportCost w₁ a₁ b

      The refutation. For ANY single constraint, both orderings of any two coordinates are achievable by choosing the cost weights — so the extremum carries no information about which coordinate wins. The cost does, and the cost is a modelling choice rather than a consequence of the constraint.

      theorem QOU.MassTheory.two_costs_two_minimisers :
      singleSupportCost 1 2 1 < singleSupportCost 1 1 1 ∧ singleSupportCost 1 1 1 < singleSupportCost 4 2 1

      The corpus instance in miniature. One constraint x₁ + 2x₂ = 1. The uniform cost w = (1,1) prefers coordinate 2; the reweighted cost w = (1,4) prefers coordinate 1. Same feasible set, same optimum principle, different answer — which is Option D's Plancherel-vs-Frobenius split, stripped to two coordinates.

      theorem QOU.MassTheory.equal_costs_are_decided_by_the_constraint (w a₁ a₂ b : ℝ) (hw : 0 < w) (ha₁ : a₁ ≠ 0) (ha₂ : a₂ ≠ 0) (hb : b ≠ 0) (h : |a₂| < |a₁|) :
      singleSupportCost w a₁ b < singleSupportCost w a₂ b

      Non-vacuity. The freedom is in the cost, not in the arithmetic: hold the cost weights EQUAL and the constraint alone does decide, by |aᵢ|. So the theorem above is about the modelling choice, not about an ill-posed comparison.
