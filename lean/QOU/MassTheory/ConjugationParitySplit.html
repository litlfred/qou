          theorem QOU.MassTheory.ConjugationParity.pEven_conj {I : Type u_1} {R : Type u_2} [CommRing R] (sgn : R) (c : I → I) (g : I → R) (p : I) (hs : sgn * sgn = 1) (hc : c (c p) = p) :
          pEven sgn c g (c p) = sgn * pEven sgn c g p

          Covariance under conjugation (needs sgn·sgn = 1 and c an involution): the bar-even part picks up the sign under p ↦ c p. So a conjugate pair {p, c p} combines coherently in the bar-even channel with relative sign sgn.
