    theorem QOU.MassTheory.no_constant_scale_matches_of_mono (g₁ g₂ b₁ b₂ c : ℝ) (hg : g₁ ≤ g₂) (hc : 0 ≤ c) (hb : b₂ < b₁) (h₁ : c * g₁ = b₁) (h₂ : c * g₂ = b₂) :
    False

    The exclusion. A model that does not decrease across two points cannot, after any non-negative rescaling, reproduce data that does decrease across them.

    g₁, g₂ are the model's per-nucleon values at ⁴He and ⁶Li; b₁, b₂ the AME ones; c an arbitrary overall scale. The hypothesis hg : g₁ ≤ g₂ is what the probe verifies for every w, and hb : b₂ < b₁ is the ⁴He peak.

    theorem QOU.MassTheory.matching_possible_when_data_nondecreasing :
    ∃ (g₁ : ℝ) (g₂ : ℝ) (b₁ : ℝ) (b₂ : ℝ) (c : ℝ), g₁ ≤ g₂ ∧ 0 ≤ c ∧ b₁ ≤ b₂ ∧ c * g₁ = b₁ ∧ c * g₂ = b₂

    Non-vacuity I. The conclusion is not forced by the shape of the hypotheses: drop only hb (let the data be non-decreasing too) and matching becomes possible. So the theorem really is about the ⁴He peak.

    theorem QOU.MassTheory.mono_hypothesis_is_load_bearing :
    ∃ (g₁ : ℝ) (g₂ : ℝ) (b₁ : ℝ) (b₂ : ℝ) (c : ℝ), ¬g₁ ≤ g₂ ∧ 0 ≤ c ∧ b₂ < b₁ ∧ c * g₁ = b₁ ∧ c * g₂ = b₂

    Non-vacuity II. The monotonicity hypothesis is load-bearing, not decorative: a model that DOES decrease across the two points matches the same decreasing data exactly. This is why the probe must verify hg for every w rather than assume it.

    theorem QOU.MassTheory.best_constant_error_lower_bound {rmin rmax c : ℝ} (hmin : 0 < rmin) (hle : rmin ≤ rmax) (hc : 0 < c) :
    √(rmax / rmin) ≤ max (rmax / c) (c / rmin)

    The quantitative form. If the per-isotope rescalings that would be required span [rmin, rmax], then for EVERY positive constant c the worst multiplicative error is at least √(rmax / rmin).

    rmax / c is how far the constant undershoots the isotope needing the most; c / rmin how far it overshoots the one needing the least. No c escapes both.

    theorem QOU.MassTheory.measured_constant_error_at_least_two {c : ℝ} (hc : 0 < c) :
    2 ≤ max (23770636 / 10000000 / c) (c / (5130070 / 10000000))

    Instantiated at the measured spread. With rmin = 0.5130070 (²H) and rmax = 2.3770636 (⁴He) — the rescalings the balanced cut w = 3/2 would need — every constant is off by at least a factor of two somewhere. The probe's dense value is 2.1526×; two is the floor this bound certifies.

    The two literals are measured inputs, not Lean-derived.
