    theorem QOU.MassTheory.MilnorWeightParity.deficit_order_even (A : ℕ) :
    Even (2 * (A - 1))

    Deficit order is even. 2(A−1) is even, so the A-body deficit 1 − τ_A (leading order h^{2(A−1)}) is bar-even; its sign is a leading-coefficient effect, not a bar-parity flip.

    theorem QOU.MassTheory.MilnorWeightParity.weight_order_gt_deficit (A : ℕ) (hA : 1 ≤ A) :
    2 * (A - 1) < 3 * A - 1

    The weight prefactor is subleading. For A ≥ 1 the Ocneanu-weight order n−1 = 3A−1 strictly exceeds the deficit order 2(A−1). Since τ_A is a normalized (link/unlink) ratio the weight prefactor cancels; being higher-order it cannot set the deficit's leading sign.

    theorem QOU.MassTheory.MilnorWeightParity.weight_parity_eq_cluster_sign (k : ℕ) :
    (-1) ^ (3 * (k + 1) - 1) = (-1) ^ (k + 1 - 1)

    The parity coincidence. The weight bar-sign (−1)^{n-1} = (−1)^{3A−1} equals the cluster sign (−1)^{A−1} (phrased with A = k+1 so ℕ-subtraction is well-defined). Same VALUE — the source orders differ (facts above), so this is a convergence, not a derivation.

    theorem QOU.MassTheory.MilnorWeightParity.convergence_not_derivation (k : ℕ) :
    (-1) ^ (3 * (k + 1) - 1) = (-1) ^ (k + 1 - 1) ∧ 2 * (k + 1 - 1) < 3 * (k + 1) - 1 ∧ Even (2 * (k + 1 - 1))

    Convergence, not derivation (the packaged statement). For A = k+1 ≥ 1: the signs agree in value (weight_parity_eq_cluster_sign) while the weight order strictly exceeds the (even) deficit order — so the shared (−1)^{A−1} comes from distinct-order objects.
