    theorem QOU.Habiro.MirrorPair.coeffDiff_of_common_denom {R : Type u_1} [CommRing R] (d tX tY : R) :
    d * tX - d * tY = d * (tX - tY)

    The valid regime. With a shared denominator, differencing the denominator-cleared numerators is differencing the traces, scaled by that common denominator. Cyclotomic multiplicities of the result therefore differ from those of t_X − t_Y only by the multiplicities of d. This is why the convention-C computation gave the right answer despite taking the shortcut.

    The broken regime, exactly. At any point where the two traces agree, the coefficient-difference collapses to the denominator gap times the common trace value. It retains no information about the traces at all.

    theorem QOU.Habiro.MirrorPair.coeffDiff_eq_zero_iff {R : Type u_1} [CommRing R] [NoZeroDivisors R] (dX dY t : R) :
    dX * t - dY * t = 0 ↔ dX = dY ∨ t = 0

    Consequently, at a coincidence point the coefficient-difference vanishes iff the denominators agree there or the common trace value is zero.

    theorem QOU.Habiro.MirrorPair.mirror_trace_eq_of_tau_eq {R : Type u_1} [CommMonoid R] (τp τn c : R) (h : τp = τn) (Z N n : ℕ) :
    τp ^ Z * τn ^ N * c ^ n = τp ^ N * τn ^ Z * c ^ n

    The classical-point mirror coincidence. Write a closed-form trace as τ_p^Z · τ_n^N · c^n — the shape _build_closed_form produces, with c the common value of every interface factor. Measured at q = 1: all three interface kinds (z, z − h, z − h/2) equal 1/2, and τ_p = τ_n = 1/2.

    Given only τ_p = τ_n and an interface count invariant under (Z,N) ↦ (N,Z) (both verified), the mirror partners coincide. This is why (q − 1) divides a correctly formed mirror difference — and it is a statement about the classical point alone, requiring no ordering on R.
