    Habiro cyclotomic evaluation — truncation, well-definedness, non-vanishing #

    Infrastructure for the Habiro ring ℤ[q]^ = lim_← ℤ[q]/((q;q)_n) at the level actually needed by def:qou-motivic-galois-instance (bean qou-lwyo): the evaluation of a cyclotomic series Σ_m a_m (q;q)_m at a root of unity.

    QOU.Common.qPochDiag and cyclotomic_value_truncates already existed and are reused; this file supplies the three things they did not have.

    1. The bridge from roots of unity #

    cyclotomic_value_truncates assumes (ζ;ζ)_N = 0 as a hypothesis. qPochDiag_eq_zero_of_pow_eq_one derives it from ζ^N = 1: the k = N factor is 1 - ζ^N = 0. That is the actual Habiro mechanism, and without it the truncation lemma cannot be applied to a root of unity without assuming its own conclusion.

    2. Well-definedness of the evaluation #

    habiroEval_stable — past the order of ζ, truncating further changes nothing. This is what makes ev_ζ well defined on the inverse limit: a coherent sequence has one value regardless of the level it is read at. habiroEval_add gives additivity.

    Multiplicativity is NOT proved here. The Habiro product in cyclotomic coordinates is not termwise, so ev_ζ being a ring hom is a larger build. What this file establishes is a well-defined additive evaluation, which is what the frobenius_at construction consumes. Do not cite it as a ring hom.

    3. Non-vanishing, and why the obvious criterion is useless here #

    habiroEval_ne_zero_of_head_not_dvd: if the j-term head is not divisible by (ζ;ζ)_j, the whole evaluation is non-zero — for every N ≥ j, so this is a genuine "for all p" criterion rather than a per-prime check.

    The natural instance is j = 1, giving *"(1-ζ) ∤ a₀ ⇒ ev ≠ 0"* (habiroEval_ne_zero_of_head_not_dvd_one). **At the primes this framework needs, that is vacuous.** The norm of 1 - ζ_nisΦ_n(1), which is 1unlessnis a prime power. Forn = 2pwithpodd,2pis not a prime power, so1 - ζ_{2p}` is a unit and divides everything. Computed:

    p        2     3     5     7    11    13
n = 2p   4     6    10    14    22    26
Φ_n(1)   2     1     1     1     1     1
         ok  unit  unit  unit  unit  unit

    So j = 1 covers p = 2 and nothing else. head_criterion_vacuous_of_isUnit states that failure mode as a theorem rather than a comment.

    The escape is j = 2: (ζ;ζ)_2 = (1-ζ)(1-ζ²), and for a primitive 2p-th root ζ² is a primitive p-th root, so 1 - ζ² has norm Φ_p(1) = p — a non-unit. The j-general form above is stated precisely so this instance is available.

    What remains open for qou-lwyo. This file reduces "non-vanishing at every prime" to a concrete arithmetic condition on the head of the atomic Markov trace's Habiro expansion. Whether that head satisfies it is not settled here, and no instance is provided. That is a sharper open question than the one it replaces, not a closed one.

    Base ring (§7c). Generic [CommRing R] throughout — no ordering, no ℝ. The cyclotomic specialisation only needs IsPrimitiveRoot.

      j = 2 specialisation — the index that is actually usable at ζ_{2p}.

      habiroEval_ne_zero_of_head_not_dvd_one is vacuous at every odd prime, because Norm(1 - ζ_n) = Φ_n(1) = 1 unless n is a prime power, so 1 - ζ_{2p} is a unit there and head_criterion_vacuous_of_isUnit applies. At j = 2 the divisor picks up the second factor 1 - ζ² = 1 - ζ_p, whose norm is Φ_p(1) = p; that is a non-unit at every prime, so this form of the criterion has content everywhere.

      Concretely, in ℤ[ζ_{2p}] = ℤ[ζ_p] with 𝔭 = (1 - ζ_p) the unique prime above p and residue field 𝔽_p (in which ζ_{2p} ≡ -1), the hypothesis reduces to the single integer condition a₀(-1) + 2·a₁(-1) ≢ 0 (mod p) — one integer per series, deciding non-vanishing at every odd prime outside its finite set of divisors, with no dependence on how far the coefficients are known.

      j = 3 specialisation — what is needed when j = 2 is silent.

      The j = 2 criterion is silent exactly when p divides the integer A = a₀(-1) + 2·a₁(-1) (see habiroEval_ne_zero_of_head_not_dvd_two). Measured on this corpus, the only odd prime that ever divides A is 3, and it does so exactly for the mixed atoms; at j = 3 the divisor picks up the further factor 1 - ζ³, and the criterion fires there for every one of them. Silence at one index says nothing about the value — it says the test at that index cannot see it.

      The prime 2: four explicit terms, so no criterion is needed #

      At a primitive fourth root the Pochhammer collapses to constants and the whole evaluation is four terms. Non-vanishing at p = 2 is therefore decided by evaluating, not by a divisibility criterion — which matters because the criterion provably cannot decide it: qPochDiag ζ 4 = 0 caps the divisor, so habiroEval_ne_zero_of_head_not_dvd has only j = 1, 2, 3 to work with.
