    Mass-computation chain stubs — m_n + higher atoms/isotopes #

    This file aggregates the Lean theorem stubs identified as gaps in the m_n compute chain audit (commit dc3ce9e4 on PR #637, plus the follow-up symbolic recompute commit 3afe366f). Per AGENTS.md §1 ("every sorry requires a bibliographic citation"), every sorry below carries a citation to its manuscript source.

    The audit identified the following Lean gaps in the mass_endomorphism.py → m_K_pred pipeline:

    1. CAL-2 q_0 inversion (no Lean for the m_μ/m_e → q_0 map)
    2. Symbolic crossing recurrence (additive_wedderburn_volumes)
    3. Typed-crossings encoding for u/d quark pairs
    4. Φ_q tower convergence (Habiro / Yekutieli)
    5. Brane-tower level-selection n_⋆ (conjectural)
    6. Wedderburn weight closed-form (only count theorem currently proved)

    Plus for higher atoms/isotopes the gaps include:

    1. Atomic braid word atom_braid_word_3A(Z, N) at H_{3A}
    2. Per-nucleon shift additive linearity (18Z + 21N + 1 for A ≥ 2)
    3. Frobenius co-Casimir universality at H_{3A} (n=8, ..., n=12)
    4. |tr_M(β_K)| at H_{3A} via Wenzl bridge

    This file is a roadmap, not a closure. Each theorem statement records what would need to be proved, with the script-level fact already empirically verified at 50 dps. Filling in the proofs is multi-week Lean R&D work per gap.

    Gap 1: CAL-2 q_0 inversion from m_μ/m_e #

    The substrate parameter q_0 is defined by q-pinning-50-digit.witness.json as the unique real q > 1 such that an explicit function M_ratio(q) equals the CODATA m_μ/m_e ratio. The inversion is empirically pinned at q_0 ≈ 1.10998 (50 dps in the witness).

    Lean stub: prove that the inversion is well-posed (unique solution) and gives a Lipschitz amplification factor for error propagation.

    §3b-cond axiomatisation of the M_ratio inversion #

    The QOU substrate predicts m_μ/m_e as a function of q via M_ratio_QOU(q), with the inversion q_0 defined as the unique real q ∈ (1, 2) satisfying M_ratio_QOU(q_0) = M_ratio_codata (CODATA 206.7682830).

    Empirically verified at q_0 ≈ 1.10998 to 50 dps in q-pinning-50-digit.witness.json. The Lean theorem below is conditional on the strict-monotonicity class MRatioInversionMonotone axiomatising the underlying mass-ratio function's well-posedness in the substrate window.

    This is a §3b-cond-style class hypothesis: the conjectural input is the existence of a strictly monotone, continuous M_ratio_QOU function whose codomain covers M_ratio_codata. Given this, the uniqueness of q_0 follows from elementary real analysis (strict monotonicity ⇒ injective ⇒ at most one preimage; continuity + intermediate value ⇒ at least one preimage).

      Gap 2: Symbolic crossing recurrence (additive Wedderburn) #

      The mass_endomorphism.py:additive_wedderburn_volumes function applies a state-machine recurrence: starting at (a, b) = (0, 1), for each crossing (c, d) update

      a' = a · c · H_A + a · d + b · c
b' = a · c + b · d

      where H_A = q - q^{-1}. The final (a, b) determines V_std = z · a + b via the Markov parameter z = 1/(√q + 1/√q). The script's choice of this recurrence reflects the Burau / Hoefsmit seminormal representation of H_3 on the 2-dim std irrep; no Lean theorem currently certifies that the recurrence equals the std rep trace.

      Lean stub: prove that the recurrence equals tr ρ_std applied to the ordered crossing product.

        Gap 3: Typed-crossings encoding for u/d quark pairs #

        The framework's quark-typed crossings (four-term-pair-nucleon.md):

        • uu pair: σ_i (c=1, d=0)
        • dd pair: σ_i^{-1} = σ - H_A · 1 (c=1, d=-H_A)
        • ud pair: ½(σ + σ^{-1}) (c=1, d=-H_A/2)

        The encoding (c, d) = (1, -H_A) for dd is a CHOICE in the script mass_endomorphism.py:neutron_cross. Per AGENTS.md §7a (Hecke-Skein convention), σ^{-1} satisfies σ^{-1} = σ - H_A · 1, so dd → (1, -H_A) is forced. But the c=1, d=-H_A/2 ud-average is a convention.

        Absolute convergence core of Φ_q (derived).
