    QOU.BraidsKnots.tmli_constituent_composite_agreement #

    Canonical declaration for content block lem:tmli-constituent-composite-agreement: Constituent and composite Markov-trace evaluations agree exactly. The lean.ref URI qou:QOU.BraidsKnots.tmli_constituent_composite_agreement resolves here.

    Lemma statement (from manuscript): for a hadron $\mathfrak{H} \hookrightarrow V^{\otimes N}$ with $N = 2(j_1 + \cdots + j_n)$ and braid word $\beta_{\mathfrak{H}} \in B_N$, the constituent product $\prod_i \hat{V}_i^{\mathrm{const}}$ and the composite trace $\mathrm{tr}_M(\rho(\beta_{\mathfrak{H}}))$ evaluate the same element of $H_N(q)$, so

    $$ \prod_i \hat{V}_i^{\mathrm{const}} #

    \mathrm{tr}M(\rho(\beta{\mathfrak{H}})) #

    P_{K_{\mathfrak{H}}}(q). $$

    Disposition (integrity) #

    The class carries only genuine data (the constituent Hecke elements ρ(β_i) ∈ A, the composite braid image ρ(β_𝔥) ∈ A, the scalar quantities V̂ᵢ, ∏ᵢ V̂ᵢ, tr_M(ρ(β_𝔥)), P_K(q) — each pinned to the trace data by a definitional link field) plus the Markov-peel factorisation of β_𝔥 as per-step structural inputs (partialComposite, partial_zero, partial_full, peel). It does not carry the agreement identity as a projected field (the previous version carried claim_… : constituent_product = composite_trace and a def handing it back — the self-assuming projection forbidden by AGENTS.md §3b-cond item 5).

    • tmli_constituent_composite_agreement states the real claim — Markov-trace multiplicativity across constituents, ∏ᵢ tr_M(ρ(β_i)) = tr_M(ρ(β_𝔥)) — and is now proved sorry-free (§3b-cond conditional class). The class supplies the Markov peel of thm:markov-trace-product one step per constituent (peel); the theorem derives the aggregate identity by induction on the prefix length. The peel field is the per-step hypothesis, not the aggregate conclusion (§3b-cond item 5, non-degenerate). It mirrors the chain-list realisation QOU.Braiding.markov_trace_flatten.
    • tmli_constituent_product_is_link_polynomial is derived: chaining the agreement identity with the definitional link P_K(q) = tr_M(ρ(β_𝔥)) gives ∏ᵢ V̂ᵢ = P_K(q) — the outer equality of the manuscript display, obtained by using the main claim, not by restating a field.

    Base-ring convention (§7c / §7d) #

    The ring / algebra structure is carried as genuine instance binders ([CommRing R] [Ring A] [Algebra R A] [MarkovTrace n q A]), not as opaque data fields. This is required for the induction: with the ring stored as data the Finset.prod-side 1/* (monoid path) and the peel-side 1/* (ring path) are non-defeq (the projections cannot reduce past an opaque field), so exact/ring/simp cannot bridge them. With real instance binders the paths are defeq (Mathlib forgetful inheritance) and the proof goes through. Hence this block does not extend the shared data-field carrier QOU.Shared.MarkovTraceContext.

    class QOU.BraidsKnots.TmliConstituentCompositeAgreementContext {R : Type u} [CommRing R] [Inv R] {n : ℕ} {q : R} {A : Type u} [Ring A] [Algebra R A] [Hecke.HeckeAlgebra R n q A] [markovInst : Hecke.MarkovTrace n q A] :
    Type u

    Data of the constituent/composite Markov-trace agreement claim, over genuine ring/algebra instance binders (see the base-ring note in the module docstring). All fields are inputs: the hadron's braid data, its traced values (pinned by definitional links), and the per-step Markov-peel factorisation of β_𝔥; none is the agreement conclusion.

    • m : ℕ

      Number of constituents of the hadron 𝔥.

    • constituent : ℕ → A

      Constituent Hecke elements ρ(β_i) ∈ H_N(R, q).

    • beta_H : A

      Composite Hecke element ρ(β_𝔥) ∈ H_N(R, q).

    • V_hat : ℕ → R

      Traced constituent volumes V̂ᵢ^const : R.

    • V_hat_def (i : ℕ) : V_hat n q A i = (Hecke.MarkovTrace.trace n q) (constituent n q i)

      Definitional link: V̂ᵢ^const = tr_M(ρ(β_i)).

    • constituent_product : R

      The constituent product ∏ᵢ V̂ᵢ^const : R.

    • constituent_product_def : constituent_product n q A = ∏ i ∈ Finset.range (m n q A), V_hat n q A i

      Definitional link: the constituent product is the product of the traced constituent volumes over the m constituents.

    • composite_trace : R

      The composite Markov-trace value tr_M(ρ(β_𝔥)) : R.

    • composite_trace_def : composite_trace n q A = (Hecke.MarkovTrace.trace n q) (beta_H n q)

      Definitional link: composite_trace = tr_M(ρ(β_𝔥)).

    • P_K : R

      The link-polynomial value P_{K_𝔥}(q) : R.

    • P_K_def : P_K n q A = (Hecke.MarkovTrace.trace n q) (beta_H n q)

      Definitional link: the link polynomial of the hadron knot is the Markov trace of the composite braid image (Jones's construction).

    • partialComposite : ℕ → A

      The Markov-peel partial composites: partialComposite k is the composite Hecke element of the first k constituents along Jones's constituent factorisation of β_𝔥.

    • partial_zero : (Hecke.MarkovTrace.trace n q) (partialComposite n q 0) = 1

      Base of the Markov peel: the empty partial composite traces to 1 (tr_M(𝟙) = 1).

    • partial_full : partialComposite n q (m n q A) = beta_H n q

      Closure of the peel: the full partial composite over all m constituents is the composite hadron braid image ρ(β_𝔥).

    • peel (k : ℕ) : k < m n q A → (Hecke.MarkovTrace.trace n q) (partialComposite n q (k + 1)) = (Hecke.MarkovTrace.trace n q) (constituent n q k) * (Hecke.MarkovTrace.trace n q) (partialComposite n q k)

      One Markov peel per constituent (thm:markov-trace-product applied at each interface): appending constituent k multiplies the running Markov trace by tr_M(ρ(β_k)). Per-step structural input; the aggregate agreement is derived from it below (§3b-cond item 5, non-degenerate).
