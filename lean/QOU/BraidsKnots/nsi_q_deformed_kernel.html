    QOU.BraidsKnots.nsi_q_deformed_kernel #

    Content block lem:nsi-q-deformed-kernel: $q$-deformed commutator replaces $1/r^2$ with a hard kernel at $r = \hbar_q$.

    Manuscript statement. For $q \neq 1$, the categorical mass of a vortex filament $\varrho$ inherits a kernel

    $$ \frac{1}{\lvert \varrho(s) - \varrho(t) \rvert^2} \longmapsto \frac{[2]_q}{\lvert \varrho(s) - \varrho(t) \rvert^2 - \hbar_q^{2}}, $$

    where $[2]_q = q + q^{-1}$, $\hbar_q = 1 - q^{-1}$, and the kernel has a hard singularity at $\lvert \varrho(s) - \varrho(t) \rvert = \hbar_q$.

    Disposition (integrity) #

    The previous encoding was a self-assuming projection (AGENTS.md §3b-cond item 5): the class carried a claim_nsi_q_deformed_kernel field that was the kernel identity, and a def merely projected it back out. Here the kernel is defined concretely (qDeformedKernel q r = (q + q⁻¹) / (r² − (1 − q⁻¹)²)), which splits the lemma into its two honest parts:

    • nsi_q_kernel_hard_singularity is derived sorry-free: for q ≠ 0, q ≠ 1 the kernel genuinely blows up at r = ℏ_q — |qDeformedKernel q r| → ∞ as r → ℏ_q, r ≠ ℏ_q. The proof is real analysis, not a projection: ℏ_q ≠ 0 (else q = 1), [2]_q ≠ 0 (over ℝ, q + q⁻¹ = 0 forces q² + 1 = 0), the denominator r² − ℏ_q² tends to 0 and is eventually nonzero on the punctured neighbourhood (its only roots are ±ℏ_q), so the reciprocal diverges.
    • nsi_q_kernel_identification — that the trace-side kernel the categorical mass of the filament inherits is qDeformedKernel q ‖ϱ(s) − ϱ(t)‖ — is the genuinely open part (the q-deformed commutator / q-Hodge star are not yet formalised); it is an honest sorry carrying the manuscript citation per AGENTS.md §1.

    The resolving declaration nsi_q_deformed_kernel conjoins the two.
