    Full cyclicity of the site-weighted trace #

    QOU.IwahoriHecke.QuantumTrace proved cyclicity of tr_w only against a generator — tr_w(σ_a · y) = tr_w(y · σ_a) — and said plainly that the general statement needed the image of the action to lie in the centralizer of the site weight W, "an induction over the algebra rather than over its generators". This file supplies exactly that, and with it the general statement

    qTrace_mul_comm — tr_w(x y) = tr_w(y x) for arbitrary x, y ∈ H_{m+1}(q).

    so tr_w is a trace on the algebra, not merely a functional that happens to be cyclic on generators.

    The mechanism, and why it is not an induction #

    The naive route is a RingQuot induction over x. That is not needed. Ř commutes with W (braidAt_comm_siteWeight, for every weight), so the whole image lands in the R-subalgebra Subalgebra.centralizer R {W} — and a subalgebra is closed under the operations, so "the image is inside it" is a statement about a lift, not about a traversal of elements:

    • heckeActionCentral re-runs liftBalanced with the subalgebra as target. The three obligations are the same three, pulled back along the injective Subalgebra.val;
    • val_comp_heckeActionCentral says composing back with val returns heckeActionN, by hom_ext_sigma — two algebra maps agreeing on the σ_a;
    • so heckeActionN x is the image of a subalgebra element for every x (heckeActionN_mem_weightCentralizer), hence commutes with W.

    The braid-relation obligation is not re-proved: strandBraid_altProd reads it off heckeActionN itself, by pushing Balanced.sigma_braid through the map with map_altProd. Nothing about Fin arithmetic is repeated.

    🛑 Scope #

    This is cyclicity, and cyclicity alone. It is not the Markov property: a Markov trace must additionally satisfy the peel tr(x σ_n) = z · tr(x) relating the trace on H_{n+1}(q) to the one on H_n(q), which is a statement about the tower and is not here. See QOU.IwahoriHecke.MarkovPeel for that half. Normalisation (tr_M(1) = 1) is likewise absent — qTrace_one gives (∑ₖ w k)^{m+1}, which is not 1.

    -- Ref: [jones1987] Hecke algebra representations of braid groups and link polynomials -- Ref: [manuscript] bean qou-k4oq

        Cyclicity #

        source
        theorem QOU.IwahoriHecke.QuantumTrace.qTrace_mul_comm {R : Type u_1} [CommRing R] (q qi : R) {m : ℕ} (hqi : q * qi = 1) (w : Fin 2 → R) (x y : Balanced.BalancedHecke (TensorEmbed.coxA m) q) :
        qTrace q qi hqi w (x * y) = qTrace q qi hqi w (y * x)

        tr_w is cyclic. tr_w(x y) = tr_w(y x) for arbitrary elements of H_{m+1}(q), at every weight w.

        The proof is three associativity steps around one use of the commutation and one use of the ordinary cyclicity of the matrix trace: tr(W X Y) = tr(X W Y) = tr((W Y) X) = tr(W Y X). This supersedes qTrace_sigma_mul_comm, which is the special case x = σ_a.

        source
        theorem QOU.IwahoriHecke.QuantumTrace.qTrace_conj {R : Type u_1} [CommRing R] (q qi : R) {m : ℕ} (hqi : q * qi = 1) (w : Fin 2 → R) (u : (Balanced.BalancedHecke (TensorEmbed.coxA m) q)ˣ) (x : Balanced.BalancedHecke (TensorEmbed.coxA m) q) :
        qTrace q qi hqi w (↑u * x * ↑u⁻¹) = qTrace q qi hqi w x

        Conjugation-invariance. An immediate consequence of cyclicity: tr_w is a class function on the Hecke algebra, so it is constant on conjugacy classes of units — in particular on the braid-group images of conjugate braids, which is the Markov move I (conjugation) invariance the Jones polynomial needs.

        Markov move II is the peel, and is a separate statement — see QOU.IwahoriHecke.MarkovPeel.
