    QOU.IwahoriHecke.JonesNormalForm — the Jones normal form spans, and the Markov trace is unique #

    Setting: any R-algebra A (R a commutative ring) with a family s : ℕ → A whose first N members satisfy the type-A Hecke relations (HeckeFamily N a b s):

    • quadratic sᵢ² = a·sᵢ + b (any a b : R — convention D's σ² = (q − q⁻¹)σ + 1 is a = q − q⁻¹, b = 1; the unbalanced σ² = (q − 1)σ + q of QOU.Hecke.IwahoriHecke is a = q − 1, b = q),
    • braid sᵢ sᵢ₊₁ sᵢ = sᵢ₊₁ sᵢ sᵢ₊₁,
    • far commutation sᵢ sⱼ = sⱼ sᵢ for i + 2 ≤ j.

    No quotient is constructed: as in QOU.Archimedean.H3, every statement holds in any algebra carrying such elements, so it applies to the presented H_{n+1}(q) (QOU.IwahoriHecke.JonesNormalFormQuot), to representations, and to inductive limits.

    What is proved (sorry-free) #

    • adjoin_eq_level — the spanning theorem (Jones normal form). For n ≤ N, the subalgebra generated by s₀, …, s_{n-1} equals the R-span of the finite set words s n, where words 0 = {1} and words (n+1) = { x · s_n s_{n-1} ⋯ s_j : x ∈ words n, 0 ≤ j ≤ n+1 } (the empty run at j = n+1). That is H_{n+1} = Σ_j H_n · s_n ⋯ s_j.
    • card_words_le — |words s n| ≤ (n+1)! = |S_{n+1}|.
    • markov_unique, markov_unique_of_adjoin_eq_top — Markov-trace uniqueness for every n. Two R-linear functionals that are normalised (t 1 = 1), cyclic (t(xy) = t(yx)) and satisfy the Markov property with the same z (t(x·s_k) = z·t(x) for x generated by s₀, …, s_{k-1}) agree on every level ≤ N. The step: t(y · s_n · d) = t(d·y · s_n) = z · t(d·y) with d·y at level n (markov_peel).

    The closure argument behind spanning is the four-case analysis (commute / extend / fold / push) of QOU.Hecke.HeckeSpanning (bean qou-twwf), which proved the same decomposition for the concrete presented algebra; here it is redone for an abstract family and an arbitrary quadratic relation, which is what Markov uniqueness needs.

    What is NOT proved here #

    • Linear independence of the words (so dim = (n+1)!, i.e. the T_w basis) — only spanning, which is the half uniqueness uses.
    • Existence of the Markov trace (Ocneanu) — uniqueness says at most one.
    • The Rosso–Jones torus-knot formula for general r (bean qou-q425): uniqueness reduces tr((s₀⋯s_{r-2})^s) to a computation in the normal form, but evaluating it in closed form for general r needs the Wedderburn/Ocneanu-weight structure (or an equivalent recursion), which is not formalised. Only r = 2, 3, 4 are proved (QOU.Archimedean.rj_canonical_inner_product, QOU.Archimedean.RossoJonesH4); QOU.IwahoriHecke.MarkovTransfer shows the value does not depend on the algebra.
    • It did not discharge QOU.Hecke.markov_trace_unique_axiom, which quantified over the class QOU.Hecke.MarkovTrace without the cross-level Markov property — and was false (QOU.Hecke.MarkovTraceClassNotUnique.markov_trace_unique_axiom_false). The axiom is removed; QOU.Hecke.markov_trace_unique is now proved from markov_unique_of_adjoin_eq_top with (M3) as a hypothesis (MarkovTrace.IsMarkov).

    -- Ref: [jones1987] Jones, Hecke algebra representations of braid groups and link -- polynomials, Ann. Math. 126 (1987), §4–5 (normal form, Markov trace).

    structure QOU.IwahoriHecke.JonesNormalForm.HeckeFamily {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A] [Algebra R A] (N : ℕ) (a b : R) (s : ℕ → A) :
    Prop

    Type-A Hecke relations on the first N members of a family s : ℕ → A, with an arbitrary quadratic relation sᵢ² = a·sᵢ + b.

    • quad (i : ℕ) : i < N → s i * s i = a • s i + b • 1
    • braid (i : ℕ) : i + 1 < N → s i * s (i + 1) * s i = s (i + 1) * s i * s (i + 1)
    • comm (i j : ℕ) : i + 2 ≤ j → j < N → s i * s j = s j * s i

            Markov-trace uniqueness on H_{n+1}, for every n. Let t, t' be R-linear functionals on A that are normalised (t 1 = 1), cyclic, and satisfy the Markov property with the same parameter z at every level below N: t (x · s_k) = z · t x for x in the subalgebra generated by s₀, …, s_{k-1}, k < N.
