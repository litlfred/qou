    QOU.IwahoriHecke.Defn — Iwahori-Hecke algebra of a Coxeter group #

    Sprint 1 of the Iwahori-Hecke Mathlib infrastructure plan (see docs/workplans/2026-05-30-iwahori-hecke-mathlib-infra-plan.md).

    This file defines the Iwahori-Hecke algebra IwahoriHecke W q of a Coxeter system (W, S) over a commutative ring R with parameter q : R. It is the keystone infrastructure for closing 5 Tier-B source-node conjectures (conj:hecke-anyonic-substrate, conj:reverse-limit-q-to-infinity, conj:gs-graded-markov-trace-existence, conj:hoefsmit-ew-cell-content, conj:crystal-graph-realization) and for promoting prop:hecke-branching-trace-decomposition's §3b-cond branchCoefficient field from Unit placeholder to actual operator-valued content.

    Definition #

    Given a Coxeter system (W, S) and q : R, the Iwahori-Hecke algebra H(W, q) is the unital associative R-algebra generated by {T_s}_{s ∈ S} subject to:

    1. Hecke quadratic relation: (T_s - q) * (T_s + 1) = 0 for each s ∈ S. Equivalently, T_s^2 = (q - 1) * T_s + q.
    2. Braid relations: for adjacent s, t ∈ S with (st)^m = 1 (m = m_{st}), the alternating product of length m on each side coincides: T_s * T_t * T_s * ... = T_t * T_s * T_t * ... (m factors).

    At q = 1, the relations collapse to the group algebra R[W] (the Hecke quadratic becomes T_s^2 = 1 and braid relations match the Coxeter presentation).

    The algebra #

    Rebuilt 2026-08-30. This definition used to read

    def IwahoriHecke (W) [Group W] [DecidableEq W] (R) [CommRing R] (q : R) :=
  Quotient.IwahoriHeckeQuot R q (Set.univ : Set W)

    which had two defects, one on top of the other.

    • IwahoriHeckeQuot imposes the quadratic relation only — its braid relations were deferred — so the object was the free product of one copy of R[x]/((x−q)(x+1)) per generator.
    • Worse, passing Set.univ : Set W imposed that relation on every element of the group, not on the simple reflections. In the actual Hecke algebra T_w satisfies the quadratic relation exactly when ℓ(w) = 1; for w = st of order three it does not. So the object was not the "quadratic-only intermediate" its docstring claimed, and it admitted no natural map to or from a Hecke algebra.

    Both are fixed by building on QOU.MathlibExt.IwahoriHecke.HeckeAlgebra, which imposes both relation families, and by taking the simple-reflection set as a parameter rather than hard-coding all of W.

    The Coxeter matrix comes from the group itself: m(s,t) = orderOf (s * t). The long- standing blocker recorded here — that the order accessor was "in flux in Mathlib's CoxeterSystem API" — did not apply: orderOf is plain Mathlib group theory and needs no accessor at all.

    The Coxeter matrix carried by a subset of a group: m(s,t) = orderOf (s · t).

    For a genuine Coxeter system this is the Coxeter matrix on the nose. Nothing downstream requires that S be one — the construction is well-defined for any subset, and a caller that has a CoxeterSystem may pass its matrix instead.
