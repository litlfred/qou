    QOU.IwahoriHecke.MarkovTransfer — Markov traces agree across Hecke-family algebras #

    QOU.IwahoriHecke.JonesNormalForm.markov_unique compares two Markov traces on one algebra. This file compares Markov traces on different algebras. It does so through the presented algebra Pres N a b: the free R-algebra on N generators modulo the type-A relations sᵢ² = a·sᵢ + b, braid and far commutation. That algebra is generated by its generators (adjoin_pgen_eq_top). It maps to every algebra carrying a HeckeFamily N a b s (lift). So a Markov trace on any such algebra pulls back to a Markov trace on Pres N a b, and uniqueness there gives:

    • markov_transfer — for two algebras A, B with Hecke families sA, sB (same N, a, b) and Markov traces tA, tB with the same z, tA (lift x) = tB (lift x) for every element x of the presented algebra.
    • markov_transfer_cox — in particular the Markov trace of every power of the Coxeter element γ_r = s₀ s₁ ⋯ s_{r-2} (r ≤ N + 1), i.e. of the (r, s) torus braid, is the same number in every Hecke-family algebra.

    So the Rosso–Jones value tr_M(γ_r^s) is a function of (a, b, z, r, s) alone. To prove a closed form for it at a given r, it is enough to compute it in one algebra that carries a Markov trace, e.g. a sum of matrix representations. This is how QOU.Archimedean.RossoJonesH4 does r = 4. This file does not prove the closed form for general r. That still needs a Markov trace whose value on γ_r^s can be computed for every r, for example the Temperley–Lieb standard modules W_{r,j} with weights [j+1] and the eigenvalues of γ_r on each. None of that is formalised (bean qou-q425).

    Sorry-free; axioms propext, Classical.choice, Quot.sound.
