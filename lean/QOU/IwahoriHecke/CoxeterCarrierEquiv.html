    QOU.IwahoriHecke.CoxeterCarrierEquiv — the Fin n presentation is the Coxeter one #

    Bean qou-0fmb is titled "wire the IwahoriHecke algebra to the BraidedTower theorem", and the obstruction it names is real: the Ocneanu trace that is proved to exist and be unique lives on QOU.SchurWeyl.Hecke, while QOU/IwahoriHecke/ is built on a different construction. This file supplies the missing link of the isomorphism route.

    What already existed, and what did not #

    Two of the three legs were already in the corpus, and a corpus-grep found them:

    • QOU.SchurWeyl.carrierEquiv — Hecke K q qi n ≃ₐ[K] QOU.Hecke.IwahoriHecke K Q n, the skein↔Iwahori normalisation change at Q = q², σ_i ↦ c • T_i. It crosses the quadratic relation.
    • QOU.IwahoriHecke.Balanced — the same rescaling on the Coxeter-matrix family QOU.MathlibExt.IwahoriHecke.HeckeAlgebra R Q M, with σ_i := qi · T_i and a balanced universal property.

    What was missing is the leg between the two index presentations, at a fixed normalisation:

    QOU.Hecke.IwahoriHecke K Q n   ≃ₐ[K]   HeckeAlgebra K Q (Aₙ n)

    The left states its braid content as two explicit clauses on Fin n — adjacent braiding σ_i σ_{i+1} σ_i = σ_{i+1} σ_i σ_{i+1} and far commutation for j + 2 ≤ i. The right states it as one clause quantified over all pairs, altProd (T_i) (T_j) (M i j) = altProd (T_j) (T_i) (M j i), against a Coxeter matrix. Nothing connected them, so a result about one was not a result about the other — the defect bean qou-img9 records as "a result proved against one presentation is not automatically a result about the object the paper names".

    The content is the Coxeter matrix, and it is finite #

    For M = CoxeterMatrix.Aₙ n the entries are

    M i j = if i = j then 1 else if |i − j| = 1 then 3 else 2

    and altProd at those three values is a, a * (b * a), a * b respectively. So the single quantified clause is exactly the conjunction of the two explicit ones plus a triviality on the diagonal, and the translation is a five-way case split on (i : ℕ) against (j : ℕ). That is altProd_iff_explicit below; both lift directions consume it, and neither presentation is privileged.

    The quadratic relations are already the same modulo Q • 1 versus algebraMap _ _ Q, so nothing has to move there — quadratic_smul_iff_factored is the one-line bridge.

    What this buys #

    Composing with carrierEquiv gives skeinCoxeterEquiv:

    QOU.SchurWeyl.Hecke K q q⁻¹ n   ≃ₐ[K]   HeckeAlgebra K (q²) (Aₙ n)

    i.e. the algebra carrying the proved Ocneanu trace is the algebra the QOU/IwahoriHecke/ tree is built on — TypeA.IwahoriHeckeOfSn and Balanced.BalancedHecke are both HeckeAlgebra at a type-A matrix.

    What this does NOT do #

    • It does not transport the OcneanuTrace.MarkovTrace or BraidedTower instance. Those are structures over a tower indexed by ℕ; this is one equivalence at each fixed n, and the transport needs the equivalences to commute with the level inclusions. That is not proved here and is assumed nowhere.
    • It does not touch TypeA.IwahoriHeckeOfSn, whose index type is Fin (n - 1) with truncated subtraction. Relating that re-indexing to Fin n is a separate step.
    • It says nothing about the Set.univ-indexed QOU.IwahoriHecke.Defn.IwahoriHecke, which bean qou-img9 recommends retiring rather than repairing.

      The braid clause, in both shapes #

      This is the mathematical content of the file: the one altProd clause of the Coxeter presentation and the two explicit clauses of the Fin n presentation say the same thing about any family g : Fin n → A.

      The quadratic clause #

      QOU.Hecke writes it as σ² = (Q − 1) • σ + Q • 1; HeckeAlgebra writes it factored as (T − algebraMap Q)(T + 1) = 0. Over a commutative base these are the same statement.

      source
      theorem QOU.IwahoriHecke.CoxeterCarrier.quadratic_smul_iff_factored {K : Type u_1} [CommRing K] {A : Type u_2} [Ring A] [Algebra K A] (Q : K) (x : A) :
      x * x = (Q - 1) • x + Q • 1 ↔ (x - (algebraMap K A) Q) * (x + 1) = 0

      The two spellings of the Hecke quadratic relation agree.
