    Matsumoto's theorem, and the T_w basis it unlocks #

    Two reduced words for the same element of a Coxeter group are related by braid moves. Mathlib records this as an open TODO (GroupTheory/Coxeter/Basic.lean: "State and prove Matsumoto's theorem"); TwFromMatsumoto records it as the one hypothesis standing between this corpus and a T_w : W → H(M,q). This file proves it, for every Coxeter system, with no hypothesis.

    The proof, and where each ingredient came from #

    Tits' induction on length. Strip the last letter of each reduced word.

    • Same last letter — strip it, apply the induction hypothesis, put it back. Needs only that braid moves survive appending (braidEquiv_append).
    • Different last letters s ≠ t — then both are right descents, and CoxeterDihedralDescent.exists_reduced_alternating_tail produces a reduced word for w whose tail is the alternating block of length M s t, in both spellings, with a common prefix. One braid move connects them; each is then matched to the corresponding input word by the induction hypothesis, because they share a last letter.

    The chain of inputs beneath that one step is the whole arc: exchange (CoxeterReflectionCocycle, already in the corpus) → deletion (CoxeterDeletion) → rank-two structure (CoxeterRankTwo) → the descent lemma (CoxeterDihedralDescent).

    Nothing here is hypothetical #

    Earlier versions of this file carried two hypotheses — DihedralExact cs (that s_i s_j has order exactly M i j) and M i j ≠ 0 (no infinite bonds) — and were hypothesis-free only on type A. QOU.Machinery.CoxeterDihedralOrder proves both from the geometric representation, and CoxeterDihedralDescent spends them there, so matsumoto and exists_Tw below hold for every Coxeter system: Bₙ, Dₙ, E₆₇₈, F₄, H₃, H₄, every I₂(m), and the infinite-bond ones too.

    The alternating-word bridge #

    BraidMove is stated with the corpus's altWord (which starts with its first index) while the Coxeter machinery uses Mathlib's alternatingWord (which ends with its second). The two agree up to swapping the indices in the odd case, so the unordered pair of spellings is the same either way — which is all a braid move needs.

    source
    theorem QOU.IwahoriHecke.Matsumoto.altWord_eq_alternatingWord {B : Type u_1} (i j : B) (n : ℕ) :
    BraidWord.altWord i j n = if Even n then CoxeterSystem.alternatingWord i j n else CoxeterSystem.alternatingWord j i n

    The T_w basis map exists, for every Coxeter system, with no hypothesis.

    TwFromMatsumoto.exists_Tw_of_matsumoto was stated conditionally on Matsumoto; the condition is now discharged. Tw agrees with the word product on every reduced word, which is what a basis indexed by W through reduced expressions means.

    Type Aₙ: a concrete instantiation #
