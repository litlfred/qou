    QOU.IwahoriHecke.Quotient — concrete quotient construction (Sprint 2) #

    Sprint 2 of the Iwahori-Hecke Mathlib infrastructure plan (see docs/workplans/2026-05-30-iwahori-hecke-mathlib-infra-plan.md).

    Sprint 1 (Defn.lean) declared IwahoriHecke W R q as an opaque type with the expected AddCommGroup + Module R instances stubbed. This file replaces the opaque stubs with the concrete quotient construction:

    $$ \mathrm{IwahoriHecke}(W, q) \;:=\; \mathrm{FreeAlgebra}_R(S) \;/\; \mathcal{I}_{\mathrm{HBr}}(q) $$

    where $S \subset W$ is the simple-reflection set. That display is the target; read the scope note immediately below for what this file actually builds.

    The full Iwahori-Hecke presentation ([humphreys1990] §7.4, [geckpfeiffer2000] §4.4) quotients by two families:

    1. The Hecke quadratic relation: $(\mathfrak{T}_s - q)(\mathfrak{T}_s + 1)$ for each $s \in S$ (where $\mathfrak{T}_s$ is the free-algebra generator).
    2. The braid relations: for adjacent $s, t \in S$ with order $m_{st}$ in $W$, the alternating-product relation $\mathfrak{T}_s \mathfrak{T}_t \mathfrak{T}_s \cdots \, - \, \mathfrak{T}_t \mathfrak{T}_s \mathfrak{T}_t \cdots$ (each side has $m_{st}$ factors).

    Only (1) is imposed here. See heckeRel and the scope note below.

    Scope of Sprint 2 #

    This file establishes:

    • heckeRel R q S — the relation "each Hecke quadratic generator is 0". The braid relations are not included; see the scope paragraph below.
    • IwahoriHeckeQuot R q S := RingQuot (heckeRel R q S) — the concrete construction. It is a RingQuot, not an Ideal.Quotient: the free algebra is non-commutative, and the Ideal.Quotient form was a bug (see the Ring instance's docstring below).
    • T : S → IwahoriHeckeQuot R q S — image of the free generators under the quotient map; satisfies the Hecke quadratic relation definitionally.
    • heckeIdeal R W q : Ideal (FreeAlgebra R S) — vestigial. Spans only heckeQuadraticGenerators and is referenced by no construction in the tree; it survives from the superseded Ideal.Quotient design.

    Scope: this file does NOT build H_n(q). Imposing the quadratic relation alone yields a strictly larger algebra in which the braid relations simply do not hold, so nothing downstream may assume them. The braid step is tracked as bean qou-phir; the consequence for the Jucys–Murphy arc is bean qou-0o6j.

    The blocker recorded on heckeIdeal is the Coxeter order function m : S → S → ℕ "in flux in Mathlib's CoxeterSystem API". Note that m_{st} is just orderOf (s * t : W), which is plain Mathlib group theory and needs no CoxeterSystem accessor; altProduct (Defn.lean) already supplies the alternating product. Whoever takes qou-phir should check that route before waiting on the accessor.

    • Coherence with Defn.lean: a def proving the opaque IwahoriHecke W R q from Defn.lean is equivalent to the concrete IwahoriHeckeQuot R W q constructed here. (Sprint 2 stub: stated; Sprint 2 PR follow-up provides the bijection.)

    What's deferred to Sprint 3+ #

    • The reduced-expression basis Tw : W → IwahoriHeckeQuot R W q with IsBasis (Set.range Tw). This is Matsumoto's theorem on the independence of reduced expressions; it is the technical heart of the Iwahori-Hecke theory. Once landed:
      • Closes conj:hecke-anyonic-substrate (its content is "the T_w family spans the algebra freely modulo the relations").

    The Sprint 2 split lets us land the concrete quotient construction WITHOUT requiring Matsumoto's theorem, which is a substantial follow-up (estimated 400-600 LOC by itself).

    Authoring discipline #

    This file uses Mathlib's FreeAlgebra + Ideal.span + RingQuot primitives. All construction-level facts (heckeIdeal is an ideal, T_s satisfies the quadratic relation, etc.) are sorry-free under the Mathlib API.

    Sprint 2 status (post follow-up):

    1. ✅ Hecke quadratic relation + ideal + quotient + universal property factoring map (universal_property_hecke_quadratic) — now sorry-free via Ideal.Quotient.liftₐ + Submodule.span_induction.
    2. ⏸️ Braid relations addition — requires refactoring the S : Set W parameter to take a full CoxeterSystem M W so we can read the per-pair order M.M s t. Deferred to a follow-up sprint once the Mathlib CoxeterSystem order accessor API stabilises.

                φ = ψ

                Uniqueness half of the universal property. Two R-algebra maps out of IwahoriHeckeQuot R q S that agree on every generator T s are equal.

                Together with universal_property_hecke_quadratic (existence) this gives the full ∃! statement. It was previously recorded as an axiom in Defn.lean, on the stated ground that the container had no lake binary and elan could not reach the Lean release server; that obstacle is gone, and the proof is three steps:

                RingQuot.mkAlgHom is surjective, so it suffices that the two composites with it agree. Those are algebra maps out of a free algebra, so FreeAlgebra.hom_ext reduces the question to agreement on the generators ι s — which is the hypothesis, since T s is by definition mkAlgHom (ι s).
