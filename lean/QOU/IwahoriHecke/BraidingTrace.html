    The trace of the braiding, and its q = 1 identification with the classical character #

    Two halves of quantum Schur–Weyl were built separately in this corpus and never met.

    • The character half. QOU.MassTheory.TensorTraceCharacter computes the trace of a permutation of tensor factors — (card κ)^{orbitCount σ}, which at card κ = 2 is the 2^{c(σ)} that ClassicalTraceFloor assumes — and QOU.MassTheory.WeightedPermutationCharacter deforms it, one q-factor per orbit.
    • The braiding half. QOU.IwahoriHecke.RMatrixSl2 and QOU.IwahoriHecke.TensorEmbedding build Jimbo's Ř, prove its three Hecke relations at general n, and assemble the action H_{m+1}(q) → End(V^{⊗(m+1)}).

    RMatrixSl2.rCheck_one already showed Ř degenerates to the flip at q = 1. This file takes the step that actually connects the two halves:

    braidAt_one_eq_permMatrix — at q = qi = 1 the braiding at sites i ≠ j is not merely flip-like, it is permMatrixOf (indexPerm (swap i j) (Fin 2)), the very matrix TensorTraceCharacter computes the trace of.

    so the character follows with no new computation:

    trace_braidAt_one — tr(Ř_{ij}) = 2^{orbitCount (swap i j)} at q = 1.

    The classical 2^{c(σ)} is therefore the q → 1 limit of the braiding's trace, checked rather than asserted by analogy.

    The q ≠ 1 trace #

    trace_braidAt_eq_sum gives the trace at general q as an explicit sum over basis states — q on the diagonal a i = a j, q − qi on the ascent a i < a j, 0 on the descent. It is stated as a sum rather than in closed form on purpose: turning it into 2^{n−2}(3q − qi) needs the count #{a | (a i, a j) = (x, y)} = 2^{n−2}, which is a separate combinatorial lemma and carries ℕ-subtraction in the exponent.

    🛑 What this is NOT #

    It is not the Markov trace, and it does not connect the braiding to WeightedPermutationCharacter's deformed character. Those are different objects:

    • weighted_permutation_character traces K^{⊗n} ∘ σ for a diagonal weight K and a permutation σ; this file traces Ř itself. At q = 1 both specialise to the same classical character, which is exactly why the identification below is the right bridge — and exactly why it does not by itself relate them at q ≠ 1.
    • The Markov trace on H_n(q) — the thing the Jones polynomial needs — is still noncomputable opaque in QOU.IwahoriHecke.MarkovTrace, constructed nowhere.

    So: the q = 1 corner is joined; the q ≠ 1 bridge between braiding and character is open.

    -- Ref: [jimbo1986]; [manuscript] bean qou-k4oq

    The q = 1 identification #

    source
    theorem QOU.IwahoriHecke.BraidingTrace.swap_indexPerm_iff {n : ℕ} {i j : Fin n} (a b : Fin n → Fin 2) :
    (MassTheory.indexPerm (Equiv.swap i j) (Fin 2)) b = a ↔ (∀ (m : Fin n), m ≠ i → m ≠ j → a m = b m) ∧ (a i, a j) = (b j, b i)

    The braiding's matrix condition and the transposition's are the same condition.

    Ř at q = 1 sends a ↦ b with weight 1 exactly when a and b agree away from the two sites and are swapped on them — which is precisely b ∘ (i j) = a.

    source
    theorem QOU.IwahoriHecke.BraidingTrace.braidAt_one_eq_permMatrix {R : Type u_1} [CommRing R] {n : ℕ} {i j : Fin n} :
    TensorEmbed.braidAt 1 1 i j = MassTheory.permMatrixOf (MassTheory.indexPerm (Equiv.swap i j) (Fin 2)) R

    At q = 1 the braiding IS the transposition's permutation matrix.

    Not "degenerates to something flip-like" — literally the matrix permMatrixOf (indexPerm (swap i j) (Fin 2)) whose trace TensorTraceCharacter computes. This is the joint between the braiding half of quantum Schur–Weyl and the character half.

    No i ≠ j hypothesis is needed, and the degenerate case is not vacuous: at i = j both sides are the identity matrix — swap i i = 1, and the braiding's condition collapses to a = b — so the trace below reads 2^{orbitCount 1} = 2^n, the dimension of V^{⊗n}.

    source
    theorem QOU.IwahoriHecke.BraidingTrace.trace_braidAt_one {R : Type u_1} [CommRing R] {n : ℕ} {i j : Fin n} :
    (TensorEmbed.braidAt 1 1 i j).trace = ↑(2 ^ MassTheory.orbitCount (Equiv.swap i j))

    The classical character, from the braiding. At q = 1 the trace of the braiding at sites i ≠ j is 2^{orbitCount (i j)} — the 2^{c(σ)} of ClassicalTraceFloor, obtained from Ř rather than assumed alongside it.

    No new computation: this is TensorTraceCharacter.trace_permMatrixOf_indexPerm read through the identification above.

    The trace at general q #

    source
    theorem QOU.IwahoriHecke.BraidingTrace.trace_braidAt_eq_sum {R : Type u_1} [CommRing R] {n : ℕ} {i j : Fin n} (q qi : R) :
    (TensorEmbed.braidAt q qi i j).trace = ∑ a : Fin n → Fin 2, if a i = a j then q else if a i < a j then q - qi else 0

    The braiding's trace as an explicit sum over basis states.

    The diagonal entry at a depends only on the two site values: q when a i = a j (the symmetric channel), q − qi when a i < a j, and 0 when a i > a j — the asymmetry being the ordering built into Jimbo's Ř.

    Left as a sum rather than a closed form deliberately: collapsing it to 2^{n−2}(3q − qi) needs the state count #{a | (a i, a j) = (x, y)} = 2^{n−2}, a separate lemma that also drags ℕ-subtraction into the exponent.

    source
    theorem QOU.IwahoriHecke.BraidingTrace.trace_braidAt_one_eq_card {R : Type u_1} [CommRing R] {n : ℕ} {i j : Fin n} :
    (∑ a : Fin n → Fin 2, if a i = a j then 1 else if a i < a j then 1 - 1 else 0) = ↑(2 ^ MassTheory.orbitCount (Equiv.swap i j))

    Consistency: at q = qi = 1 the general-q sum counts the states fixed by the transposition, and agrees with trace_braidAt_one.
