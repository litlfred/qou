    QOU.StandardModel.ColourObstruction — why the tetraplectic SU(2) is not colour #

    Bean qou-ko4g, supporting the verdict of qou-8p1g ("tetraplectic reaches SU(2), not SU(3) — and that SU(2) is already spent").

    That bean argues the point in prose: the Bring cone's 3-Sasakian boundary carries three Reeb fields, three is dim su(2), that is the adjoint, and colour needs the fundamental of SU(3). Correct, and a judgement. This file turns each step into a checkable invariant.

    Nothing here needs machinery Mathlib lacks — see qou-pan0 for what it does lack (spectral sequences, the homotopy LES of a fibration, octonions, G₂), and qou-jbfx for what becomes provable if that is ever built.

    The four obstructions #

    1. real_rep_selfConjugate — a real matrix commutes with entrywise conjugation. Under the principal embedding SU(2) ↪ SU(3) the 3 restricts to the adjoint of su(2), which is a real representation, so 3 ≅ 3̄. Colour requires 3 ≇ 3̄ — that is what separates quark from antiquark. This is the mechanical form of qou-8p1g's "wrong 3".

    2. blockEmbed_not_normal — SU(2) is not normal in SU(3), by explicit witness. Hence there is no short exact sequence 1 → SU(2) → SU(3) → Q → 1, and "lift the tetraplectic SU(2) to SU(3)" cannot be posed as an extension problem at all.

    3. not_isomorphic_of_center — the order-120 trap. |Aut(Bring)| = |S₅| = 120 = |2I| (binary icosahedral), but Z(2I) = ℤ₂ while Z(S₅) = 1, so 2I ≇ S₅. Any argument sliding from "Bring has order-120 symmetry" to "so 2I ⊂ SU(2)" is invalid; the valid route runs through A₅ ⊂ S₅, which lifts to 2I.

    4. g2_dim_split — dim SU(3) + dim SO(4) = 8 + 6 = 14 = dim G₂. Trivial arithmetic, recorded because of what it says: G₂'s two homogeneous spaces G₂/SU(3) = S⁶ and G₂/SO(4) (the quaternionic Wolf space) are complementary. The corpus has S⁶ = G₂/SU(3); it has no mention of G₂/SO(4) anywhere. So the tetraplectic SU(2) (which enters G₂ through that SO(4), as the stabiliser of a quaternionic subalgebra ℍ ⊂ 𝕆) and colour SU(3) have never been put in the same frame — and G₂ is that frame.

    Plus one piece of downstream machinery:

    1. twist_surj_of_correction_trivial — the abstract exact-triangle vanishing lemma. This is the bookkeeping of Seidel's long exact sequence (library/arxiv-math-0105186v2/0105186v2.pdf) without the Floer theory: if the correction term of a three-term exact sequence vanishes, the twist map is onto. See the section docstring below for how it is meant to be used.

    What is Lean and what is narrative #

    Obstructions 1, 2, 4 and 5 are proved here outright, and so is most of 3: center_perm5_eq_bot (Z(S₅) = 1) is derived, since Mathlib does not ship it, and not_mulEquiv_perm5_of_center closes the trap. The single input still supplied in prose is Z(2I) ≠ 1 — the binary icosahedral group is not in Mathlib, so its centre cannot be computed here. That is the same split BringsSurface/OctonionInvariantObstruction.lean uses: abstract kernel in Lean, the one unavailable fact named in the narrative rather than papered over.

    1. The reality obstruction — 3 ≅ 3̄ for a real matrix #

    source
    theorem QOU.StandardModel.ColourObstruction.real_rep_selfConjugate {n : ℕ} (M : Matrix (Fin n) (Fin n) ℂ) (hM : ∀ (i j : Fin n), star (M i j) = M i j) (v : Fin n → ℂ) :
    (fun (i : Fin n) => star (M.mulVec v i)) = M.mulVec fun (i : Fin n) => star (v i)

    A real matrix intertwines a representation with its conjugate.

    If every entry of M is real then conjugating the output of M.mulVec is the same as applying M to the conjugated input. So the representation generated by M and its complex conjugate are the same matrix representation, hence isomorphic: 3 ≅ 3̄.

    This is why the three Reeb fields cannot be the colour triplet. Under the principal embedding SU(2) ↪ SU(3) the fundamental 3 restricts to the adjoint of su(2) — real matrices, the rotation action on ℝ³ ⊂ ℂ³ — so 3 ≅ 3̄, and there is no colour/anticolour distinction to be had. Colour needs 3 ≇ 3̄.

    2. SU(2) is not normal in SU(3) #

    Concretely, with `SU(2)` embedded as the top-left `2 × 2` block. The
witness is `h = diag(i, -i, 1)` — in the block, determinant
`i · (-i) · 1 = 1` — conjugated by the `3`-cycle permutation matrix `g`,
which is real orthogonal with determinant `+1`, hence in `SU(3)`.

Conjugation permutes the diagonal, so `(g h g⁻¹)` carries `-i` in the
`(2,2)` slot, and `-i ≠ 1` puts it outside the block.

          3. The order-120 trap #

          source
          theorem QOU.StandardModel.ColourObstruction.not_isomorphic_of_center {G : Type u_1} {H : Type u_2} [Group G] [Group H] (hG : ∀ g ∈ Subgroup.center G, g = 1) (hH : ∃ h ∈ Subgroup.center H, h ≠ 1) :
          ¬Nonempty (G ≃* H)

          Equal order does not give isomorphism — the centre separates them.

          |Aut(Bring)| = |S₅| = 120 = |2I|, the binary icosahedral group. But Z(2I) = ℤ₂ (it is a central extension of A₅) while Z(S₅) = 1. So 2I ≇ S₅, and an argument that reaches 2I ⊂ SU(2) from "Bring has order-120 symmetry" has proved nothing.

          The valid route is A₅ ⊂ S₅, which lifts to 2I ⊂ SU(2); and separately A₅ ⊂ SO(3) ⊂ SU(3) with no central extension needed — which is the asymmetry the whole SU(2)-vs-SU(3) question turns on.

          source
          theorem QOU.StandardModel.ColourObstruction.center_perm5_eq_bot :
          Subgroup.center (Equiv.Perm (Fin 5)) = ⊥

          Z(S₅) = 1 — the symmetric group on five letters has trivial centre.

          Derived here rather than cited: Mathlib does not ship it (checked). The argument is the standard one. If σ is central and σ a = b ≠ a, pick c ∉ {a, b} — Fin 5 has room — and commute σ past the transposition (b c). Evaluating both sides at a gives c = b, since the transposition fixes a and sends b to c. Contradiction.

          source
          theorem QOU.StandardModel.ColourObstruction.not_mulEquiv_perm5_of_center {H : Type u_1} [Group H] (hH : ∃ h ∈ Subgroup.center H, h ≠ 1) :
          ¬Nonempty (Equiv.Perm (Fin 5) ≃* H)

          The order-120 trap, closed. No group with a non-trivial central element is isomorphic to S₅.

          2I, the binary icosahedral group, is a central extension 1 → ℤ₂ → 2I → A₅ → 1, so it has a non-trivial central element and this applies: 2I ≇ S₅, despite |2I| = |S₅| = 120 = |Aut(Bring)|.

          The one input still supplied in prose is Z(2I) ≠ 1, because 2I is not in Mathlib. Everything else is proved.

          4. The G₂ dimension split #

          source
          theorem QOU.StandardModel.ColourObstruction.g2_dim_split :
          8 + 6 = 14

          dim SU(3) + dim SO(4) = dim G₂.

          8 + 6 = 14. Arithmetic, recorded for what it means: SU(3) (stabiliser of a unit imaginary octonion, quotient G₂/SU(3) = S⁶) and SO(4) = (SU(2)×SU(2))/ℤ₂ (stabiliser of a quaternionic subalgebra ℍ ⊂ 𝕆, quotient the 8-dimensional quaternionic Wolf space G₂/SO(4)) are complementary inside G₂.

          The tetraplectic SU(2) enters G₂ through that SO(4). So the two structures the framework juggles are the two subgroups giving G₂'s two homogeneous spaces — and G₂, not SU(3), is where they meet. The corpus records S⁶ = G₂/SU(3) and says nothing anywhere about G₂/SO(4).

          5. The exact-triangle vanishing lemma — Seidel's bookkeeping, no Floer #

          `library/arxiv-math-0105186v2/0105186v2.pdf` (Seidel, *A long exact sequence for symplectic
Floer cohomology*) gives, for `τ_L` the Dehn twist along a Lagrangian
sphere `L`,

    HF(L₀, L₁) → HF(L₀, τ_L L₁) → HF(L₀, L) ⊗ HF(L, L₁) → [1]

The content that makes it an obstruction-control tool is that the third
term — the correction — is **supported on `L`**. Twisting changes
cohomology by something computable at one place, and when that term
vanishes the twist acts invertibly.

Floer cohomology is far outside Mathlib (`qou-pan0`), so the theorem is
not formalisable. The *bookkeeping* is, and it is pure homological
algebra: in an exact sequence `A → B → C`, if `C` is trivial then `A → B`
is surjective; dually, a vanishing correction makes the twist an
isomorphism onto its target.

**How to use it downstream.** The framework already has the twist —
`[M_i, M_j] = 2 M_k` on the 3-Sasakian boundary, proved sorry-free in
`BringCone.lean`. Grade the objects by whatever filtration is in hand
(Gröbner degree, jet order, brane-tower height); the correction term then
lives in a **known bidegree**, and a vanishing result there is a
statement about one cell rather than about the whole complex. That is
what `qou-jbfx` means by localised obstruction control, and it is the
reason the spectral-sequence API had to stop being vacuous (`qou-fngs`)
before any of it is worth building on.

          Function.Surjective ⇑f

          Vanishing correction ⇒ the twist map is surjective.

          Stated for an exact sequence of additive groups: if g ∘ f = 0 describes the composite and every element of B killed by g is in the range of f, then a trivial C forces f to be onto.

          The abstract shell of "the twist is an isomorphism when the term supported on the sphere vanishes".
