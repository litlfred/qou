    The second crossing invariant for the hypercharge gap (formalize-first scaffold) #

    The HyperchargeInvariant conjecture (2026-06-02 audit, PR #1683; Lean sm-hypercharge-invariant.lean) reduced the electroweak U(1) gap to a single precise object: a second invariant on the state groupoid, independent of the writhe w, from which the weak hypercharge Y is read via the Gell-Mann–Nishijima relation Q = I₃ + Y/2. The writhe was DERIVED to carry I₃ (sign+ratio across the nucleon doublet, c = 1/2 fixed by def:coulomb-charge) but FALSIFIED as a Y-map (proton and neutron share Y = +1 while their writhes differ).

    This file (branch claude/hypercharge-second-invariant-2026-08-02) is the formalize-first artifact for the identity of that second invariant. The candidate identified by the corpus-grep survey is the Milnor triple linking number μ̄₁₂₃ of the three color-tube components:

    • The canonical baryon is the Borromean link 𝓑₃ of three color-tube unknots (borromean-quark.md): "no two components link, yet all three together remain inseparable" — i.e. all pairwise linkings vanish while the triple invariant is nonzero. The framework explicitly rejects the Hopf link (pairwise linking) because it would permit diquarks.
    • On this baryon the intra-braid writhe is 0 (β_Bor = (σ₁⁻¹σ₂)³, three + and three − crossings — s5-so3 audit 2026-06-01) and every pairwise linking is 0. So every degree-1 crossing invariant (writhe, self-linking, framing phase q^{w·c}, pairwise linking) vanishes on the baryon and cannot supply Y.
    • The first non-vanishing finite-type invariant of a 3-component Brunnian (Borromean) link is ±μ̄₁₂₃ = ±1 at degree 2(A−1) (the existing QOU.KnotTheory.Vassiliev.BrunnianVassilievBridge conjecture class; Habegger–Masbaum 2000). Because the pairwise linkings vanish, μ̄₁₂₃ has no indeterminacy (Milnor 1954: well-defined mod gcd of pairwise linkings; here the gcd is 0), so it is an unambiguous integer on the baryon. It equals the baryon number B (+1 for the confined triple, 0 for a 2-tube meson), and on the non-strange sector Y = B.

    This file states — as a content-bearing primary conjecture class with no instance (§3b-tax) — that such a Y = a·w + b·B (ℤ-linear in the writhe and the second invariant, b ≠ 0) realizes Gell-Mann–Nishijima and does not factor through the writhe; and it proves, sorry-free, the abstract reductions that make this the right shape: (i) any invariant not factoring through w supplies the writhe-degenerate separating pair the conjecture needs, (ii) the concrete baryon/vacuum pair (both w = 0, B = 1 vs 0) is such a pair, and (iii) on the writhe-0 baryon sector Y = 2Q — the writhe contributes nothing, so Y is carried entirely by the second invariant.

    Symbol disambiguation — two μ̄s in the corpus (do not conflate). QOU.MassTheory.MilnorExactCoefficient (landed upstream) carries mubarMeasured A = (3/4)·(−2)^{A−3}, whose A = 3 value is 3/4, not ±1. That object is the trace-normalised leading coefficient of the A-component Brunnian Markov-trace deficit 1 − τ_A, empirically extracted and explicitly not proved equal to the topological invariant (its own docstring: "that is the open Milnor μ̄(12…A) content, Route A"). The μ̄₁₂₃ in this file is the topological Milnor triple linking number, which is ±1 on the Borromean rings. Same glyph, different objects and different normalisations — per AGENTS.md §"Attributes do not transfer across overloaded symbols", no property of either transfers to the other.

    Relevant upstream negative: cyclic_trace_kills_iterCommTower proves a cyclic (Markov) trace annihilates the Lie iterated-commutator tower, so the leading coefficient is not recoverable from that tower via a trace. This does not bear on the conjecture below — nothing here extracts μ̄₁₂₃ from a trace — but it is why the exact-order law remains open upstream.

    Honesty scope (AGENTS.md anti-laundering). No instance is provided and no coefficient is fitted. The class is OPEN. The physics claim μ̄₁₂₃ = B = Y is a conjecture: Y = B closes only the non-strange sector, and the full Y = B + S (strangeness) and the relative U(1) coupling normalization that sin²θ_W needs both inherit the open SU(3)-flavor problem. What is proved here is only the abstract group-theoretic reduction, not the identification.

    theorem QOU.StandardModel.secondInvariant_gives_separating_pair {S : Type u_1} (B : S → ℚ) (w : S → ℤ) (hB : ¬∃ (f : ℤ → ℚ), ∀ (X : S), B X = f (w X)) :
    ∃ (X : S) (X' : S), w X = w X' ∧ B X ≠ B X'

    Reduction lemma (proved). If a candidate invariant B does not factor through the writhe w, then there is a writhe-degenerate pair of states — equal writhe, distinct B — exactly the object the hypercharge conjecture requires. This is the constructive converse of HyperchargeInvariant.exists_writhe_degenerate_pair: a genuine second invariant automatically discharges the non-factorization clause.

This realizes, with the framework's own objects, the pair whose existence the hypercharge conjecture asserts.

    theorem QOU.StandardModel.writheZero_Y_eq_twoQ {S : Type u_1} {R : Type u_2} [CommRing R] (w : S → ℤ) (I3 Q Y : S → R) (hI3 : ∀ (X : S), 2 * I3 X = ↑(w X)) (hgmn : ∀ (X : S), 2 * Q X = 2 * I3 X + Y X) (X : S) (hw : w X = 0) :
    Y X = 2 * Q X

    Writhe-0 sector lemma (proved). On any state whose writhe is 0 (the Borromean baryon, per the s5-so3 audit), the writhe reading I₃ = w/2 vanishes, so Gell-Mann–Nishijima forces Y = 2Q: the entire hypercharge is carried by the second invariant, not the writhe. This is the sharp reason the writhe alone cannot supply Y on the baryon.

    Stated in cleared (division-free) form -- 2·I₃ = w and 2Q = 2I₃ + Y rather than I₃ = w/2 and Q = I₃ + Y/2 -- so it holds over an arbitrary CommRing R with no characteristic hypothesis. Note the proof never needs I₃ X = 0, only 2·I₃ X = 0, which is why no invertible 2 is required. Matches the formulation in QOU/StandardModel/HyperchargeBatteryReduction.lean.

    class QOU.StandardModel.SecondCrossingInvariant (S : Type u) [CategoryTheory.Groupoid S] (Q I3 : S → ℚ) (w : S → ℤ) :
    Prop

    Conjecture class (primary): the second crossing invariant. Over a groupoid S of topological states with a derived charge Q, the writhe reading I₃ and the writhe w, there is an integer-valued gauge-invariant second invariant B (intended: the Milnor triple linking μ̄₁₂₃ of the three color-tube components) and integers a, b with b ≠ 0 such that the weak hypercharge

    Y = a·w + b·B

    is a genuine ℤ-linear combination (the b·B piece is present) realizing Gell-Mann–Nishijima Q = I₃ + Y/2, and — the sharp clause — Y does not factor through the writhe.

    Intended instantiation: S = knot-state groupoid; Q = w/2 the Coulomb charge, I₃ = w/2 the writhe reading (both 2026-06-02 audit), B = μ̄₁₂₃ the Borromean baryon-number invariant, a = 0, b = 1 (so Y = B) on the non-strange sector. Open: no instance — the identification B = μ̄₁₂₃, its GMN normalization, and the strangeness/sin²θ_W extension are not derived.

    • exists_second_invariant : ∃ (B : S → ℤ) (a : ℤ) (b : ℤ), b ≠ 0 ∧ (∀ ⦃X X' : S⦄ (a : X ⟶ X'), B X = B X') ∧ (∀ (X : S), I3 X = ↑(w X) / 2) ∧ (∀ (X : S), Q X = I3 X + ↑(a * w X + b * B X) / 2) ∧ ¬∃ (f : ℤ → ℚ), ∀ (X : S), ↑(a * w X + b * B X) = f (w X)

      There is an integer-valued gauge-invariant second invariant B (intended: Milnor μ̄₁₂₃, an integer because the Borromean pairwise linkings vanish) and integers a, b with b ≠ 0 such that Y = a·w + b·B realizes Gell-Mann–Nishijima Q = I₃ + Y/2, with I₃ the writhe reading w/2, and does not factor through the writhe.
