    def QOU.StandardModel.GellMannNishijima {R : Type u_1} [CommRing R] (Q I₃ Y : R) :
    Prop

    The Gell-Mann--Nishijima relation in cleared (division-free) form, 2Q = 2I₃ + Y.

    Equivalent to the familiar Q = I₃ + Y/2 whenever 2 is invertible, but stated so that it makes sense -- and the results below hold -- over an arbitrary commutative ring, with no characteristic hypothesis.

    Equations
    • QOU.StandardModel.GellMannNishijima Q I₃ Y = (2 * Q = 2 * I₃ + Y)

      theorem QOU.StandardModel.hypercharge_determined_of_isospin_zero {R : Type u_1} [CommRing R] (Q Y₁ Y₂ : R) (h₁ : GellMannNishijima Q 0 Y₁) (h₂ : GellMannNishijima Q 0 Y₂) :
      Y₁ = Y₂

      The right-handed battery is an identity, not a test.

      On a weak singlet (I₃ = 0) the Gell-Mann--Nishijima relation determines Y outright from Q. So two candidate hypercharge assignments that both satisfy GMN against the same derived charge agree on every right-handed row: the right-handed half of B2 has no discriminating power.

      No characteristic hypothesis is needed -- in the cleared form Y is subtracted out, never divided out.
