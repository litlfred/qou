    1. The spectrum battery is T = 3Q #

    source
    theorem QOU.StandardModel.TwistBattery.spectrum_iff_total_twist (T threeQ twoI₃ : ℤ) :
    2 * T - 3 * twoI₃ = 2 * threeQ - 3 * twoI₃ ↔ T = threeQ

    The spectrum battery is exactly T = 3Q.

    Both the candidate Y_t = 2(Q_twist - I₃) and the Standard-Model value Y_SM = 2(Q - I₃) carry the same -2I₃ term, so requiring them equal cancels the isospin entirely. Stated in the cleared 3× normalisation (threeQ = 3Q, T the total twist, twoI₃ = 2I₃), where the candidate reads Y_t = (2T - 3·twoI₃)/3 and the target Y = (2·threeQ - 3·twoI₃)/3; clearing the common denominator and the common I₃ term leaves 2T = 2·threeQ.

    No characteristic or field hypothesis: this is ℤ-linear.

    source
    theorem QOU.StandardModel.TwistBattery.spectrum_independent_of_isospin (T threeQ twoI₃ twoI₃' : ℤ) :
    2 * T - 3 * twoI₃ = 2 * threeQ - 3 * twoI₃ ↔ 2 * T - 3 * twoI₃' = 2 * threeQ - 3 * twoI₃'

    The isospin term is irrelevant to the battery: for any two isospin values the criterion is unchanged. This is why the battery tests nothing about I₃, only about the total twist.

    2. The nucleon-doublet check is entailed, and internally redundant #

    source
    theorem QOU.StandardModel.TwistBattery.nucleon_totals_entailed (Tu Td Qu Qd : ℤ) (hu : Tu = 3 * Qu) (hd : Td = 3 * Qd) :
    2 * Tu + Td = 3 * (2 * Qu + Qd) ∧ Tu + 2 * Td = 3 * (Qu + 2 * Qd)

    The nucleon check filters nothing.

    The proton is uud and the neutron udd, so their total twists are T_p = 2T_u + T_d and T_n = T_u + 2T_d, while their charges are Q_p = 2Q_u + Q_d and Q_n = Q_u + 2Q_d. If the spectrum battery holds for the quarks (T = 3Q each), then T = 3Q holds for the nucleons automatically -- by charge additivity alone. No assignment surviving the spectrum battery can fail the nucleon battery.

    theorem QOU.StandardModel.TwistBattery.nucleon_totals_are_three_and_zero (Tu Td : ℤ) (hu : Tu = 2) (hd : Td = -1) :
    2 * Tu + Td = 3 ∧ Tu + 2 * Td = 0

    Specialised to the physical first-generation charges 3Q_u = 2, 3Q_d = -1: the proton total is 3 and the neutron total is 0, which are precisely the two values the implemented nucleon check tests for.

    theorem QOU.StandardModel.TwistBattery.nucleon_second_clause_redundant (Tp : ℤ) :
    2 * Tp - 3 = 3 ↔ Tp = 3

    The nucleon check tests one condition twice.

    As implemented the proton clause is T_p/3 = 1 ∧ 2·(T_p/3 - 1/2) = 1. Cleared of denominators the second clause is 2T_p - 3 = 3, i.e. T_p = 3 — identical to the first. The apparent two-part Gell-Mann--Nishijima check is a single equation stated twice.

    theorem QOU.StandardModel.TwistBattery.neutron_second_clause_redundant (Tn : ℤ) :
    2 * Tn + 3 = 3 ↔ Tn = 0

    Same for the neutron clause: 2·(T_n/3 + 1/2) = 1 clears to T_n = 0, its own first clause.

        The survivor count is pure multiset counting.

        The spectrum battery fixes T = 3Q per flavour, so each flavour is filtered independently by one linear equation. For (u, d, νₑ, e⁻) the required totals are 3Q = (2, -1, 0, -3), giving 1, 2, 2, 1 admissible multisets — and 1 · 2 · 2 · 1 = 4, the reported survivor count. 10⁴ was never cut down by a joint condition.
