                  The writhe-degenerate pair, with derived writhes.

                  The Borromean baryon and the gluon unit both have writhe 0 — computed from their braid words — while carrying different baryon number (1 vs 0). Since L vanishes on both, Y = B - L differs on them at equal writhe, so Y is not a function of the writhe.

                  REFUTATION: sign(writhe) is not Markov-invariant #

                  source
                  theorem QOU.StandardModel.BraidWords.leptonNumber_not_markov_invariant :
                  leptonNumber borromean = 0 ∧ leptonNumber (borromean ++ [3]) = 1

                  The candidate fails the corpus's own conservation axiom.

                  Markov II (stabilization) sends β ∈ B_n to βσ_n ∈ B_{n+1} with the same link closure, and raises the writhe by 1. The Borromean baryon has writhe 0 (writhe_borromean), so its stabilisation has writhe 1 — and therefore L = sign(writhe) jumps from 0 to 1.

                  lepton-number-categorical-properties.md conservation clause 3 requires ΔL = 0 under Markov moves. This is ΔL = 1. So L = sign(writhe) is not a function of the link, only of the braid word, and it is refuted as a state function on Markov classes.

                  The one surviving reading is that states are Gröbner–Shirshov normal forms (mba-step02-gs-reduction.md: "every downstream algorithm consumes NF(w), not the raw braid"), where a canonical representative is fixed and Markov moves do not act within the state space. On that reading L = sign(writhe) is well-defined — but then conservation clause 3 is about a different object than this L, and the corpus should say which.
