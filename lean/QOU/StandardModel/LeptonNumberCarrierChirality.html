    theorem QOU.StandardModel.no_lepton_number_on_amphichiral_carrier {K : Type u_1} (mirror : K → K) (L : K → ℤ) (x : K) (hamphi : mirror x = x) (hparticle : L x = 1) (hanti : L (mirror x) = -1) :
    False

    The obstruction.

    If the mirror involution fixes a carrier x, no ℤ-valued function of the carrier can assign +1 to the particle and -1 to its mirror image.

    Applied to a carrier the mirror fixes — e.g. the unknot read as a bare knot type — this shows L cannot be a function of that carrier alone. It is not a statement about the corpus table, whose carriers are braid-level; see the module docstring.

    theorem QOU.StandardModel.mirror_must_move_the_carrier {K : Type u_1} (mirror : K → K) (L : K → ℤ) (x : K) (hparticle : L x = 1) (hanti : L (mirror x) = -1) :
    mirror x ≠ x

    The actionable form: the carrier must be chiral.

    Any L that separates a particle from its antiparticle by mirroring forces the carrier to be moved by the mirror. The unknot is not such a carrier.

    theorem QOU.StandardModel.chiral_carrier_admits_lepton_number {K : Type u_1} [DecidableEq K] (mirror : K → K) (x : K) (hchiral : mirror x ≠ x) :
    ∃ (L : K → ℤ), L x = 1 ∧ L (mirror x) = -1

    The obstruction is exactly amphichirality — nothing more.

    As soon as the mirror moves the carrier, a lepton-number function with the required values exists. So chirality of the carrier is sufficient as well as necessary, and the negative above is sharp: it rules out the unknot, not the idea.
