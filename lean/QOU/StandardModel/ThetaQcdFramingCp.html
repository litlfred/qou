    QOU.StandardModel.ThetaQCDFraming — framing-phase route to the strong-CP angle #

    Speculative direction, honestly scoped. The strong-CP angle θ_QCD is entirely open in the corpus (see appendix-standard-model/sm-params-theta-qcd.md). This file develops one named-but-unendorsed direction: the framework's framing phase Θ = q^{w·c} (c = 1/2 from def:coulomb-charge) is a topological angle attached to crossings — the same kind of object as a θ-term.

    The question this file formalizes: does a CP symmetry of the colour sector force the framing phase to be real, hence the effective strong-CP angle to lie in {0, π}?

    What is PROVED here (sorry-free, generic base ring) #

    The bar-involution bar (the corpus def:bar-involution: σᵢ ↦ σᵢ⁻¹, q ↦ q⁻¹) is the CP / charge-conjugation operation on the Hecke fibre. On the substrate circle q = e^{iφ}, q ↦ q⁻¹ is exactly complex conjugation, so bar-invariance = reality. We prove the clean algebraic core:

    framingPhase_eq_pm_one : if a framing phase Θ is (i) a pure phase bar Θ = Θ⁻¹ (unit modulus — the keystone "framing-is-phase" result, docs/audits/2026-07-12-…), and (ii) CP-even bar Θ = Θ (bar-symmetric), then Θ = 1 ∨ Θ = -1, i.e. θ ∈ {0, π}.

    This is the "bar-symmetry ⟹ reality ⟹ θ ∈ {0,π}" step, fully verified.

    What is NOT claimed (open — anti-laundering) #

    • Hypothesis (ii) is a HYPOTHESIS, not derived. Whether the QCD colour sector's total framing phase is CP-even is the open physical content — carried below as a content-bearing conjecture class with no instance (ColorSectorCPEven). A single T(2,9) gluon knot has writhe 9 ≠ 0, so it is maximally chiral, NOT CP-even; CP-evenness would have to come from a colour-singlet cancellation over the 9 = 3×3 tube structure, which needs the (open) SU(3) sector.
    • θ ∈ {0,π} is NOT the observed |θ_QCD| < 10⁻¹⁰ smallness. Even granting the conjecture, a discrete {0,π} prediction (or, at real q₀, θ = 0 exactly, since q₀^{2n}=1 ⟹ n=0) does not explain a small nonzero residual. That residual stays fully open.

            Concrete realization: the writhe framing phase Θ = qⁿ #

            The framing phase of a knot composite with writhe w is Θ = q^{w·c}, c = 1/2. For the CP structure only the bar-image matters; we record that any q-power is automatically a pure phase, and that CP-evenness of qⁿ is exactly q^{2n} = 1 — which at a real substrate q₀ > 1 forces n = 0 (zero net writhe), i.e. Θ = 1, θ = 0. At a root of unity (the fibre level) q^{2n}=1 has nontrivial solutions — the fibre-vs-observable distinction (AGENTS.md).
