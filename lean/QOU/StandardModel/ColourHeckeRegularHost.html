    QOU.StandardModel.ColourHeckeRegularHost — the colour action cannot live on the #

    regular three-strand Hecke carrier (a Hecke-compatibility obstruction)

    The colour conjecture conj:sm-colour-stabilizer-action records, as its surviving open content, an action of the colour algebra 𝔰𝔲(3) = ker(ev_e) (8-dimensional by the corpus gate) on the framework's own three-strand Hecke state space, compatible with its braid/Hecke structure — "not merely some faithful module somewhere."

    The abstract class QOU.StandardModel.ColourStabilizerAction asks only for an injective linear map g →ₗ End V. That is tautologically satisfiable for any V with finrank V ≥ 3 (since 8 ≤ 3² = 9); the octonion base module already witnesses it (OctonionColourActionBaseModule), and so would any 6-dimensional V. So instantiating the weak class on the Hecke carrier closes nothing — the genuine content is Hecke-compatibility.

    The framework's own three-strand state space is the 6-dimensional regular carrier H₃(q) implemented in QOU.Mathlib.HeckeAlgebra as H3Carrier = ℚ⁶, with the two braid generators acting by left multiplication H3.mulSigma1, H3.mulSigma2. Modelling it here as Fin 6 → ℚ (the same basis {1, σ₁, σ₂, σ₁σ₂, σ₂σ₁, σ₁σ₂σ₁}, positions 0..5), the generators are the matrices L₁ = mulSigma1, L₂ = mulSigma2 (formulas copied verbatim from HeckeAlgebra.lean, reproduced self-contained so this file verifies against Mathlib alone).

    Result (this file, sorry-free). "Hecke-compatible" in the Schur–Weyl sense means the colour action commutes with the Hecke action L₁, L₂. On the regular carrier this is structurally impossible for an 8-dimensional colour algebra:

    • evAtOne_injective — the centralizer of the regular Hecke action injects into V by evaluation at the cyclic vector 1 = e₀ (the six words 1, σ₁, σ₂, σ₁σ₂, σ₂σ₁, σ₁σ₂σ₁ applied to e₀ are the standard basis, so a centralizing T is determined by T e₀).
    • finrank_heckeCentralizer_le_six — hence finrank (centralizer) ≤ 6.
    • no_heckeCompatible_colour_action_on_regularH3 — no injective linear Φ : g →ₗ End V with every Φ x commuting with L₁, L₂ exists when finrank g = 8, since it would force 8 ≤ 6.

    This is a scope-(b) structural exclusion (per AGENTS.md "Before declaring refuted"), cited to a proved dimension invariant — finrank(End_{H₃}(H₃)) = finrank H₃ = 6 < 8. It is scoped to the regular carrier with the centralizer reading of compatibility; it does not exclude the colour action on the larger Schur–Weyl tensor host (ℂ³)^{⊗3} (dim 27), where the Hecke centralizer is the DV–Todorov diagonal 𝔰𝔲(3) itself. That positive construction is the genuine remaining open derivation (see the conjecture's authorNotes).

    Applies to 𝔰𝔲(3) = ker(ev_e) via the corpus gate finrank (su3 e) = 8 (QOU.MathlibExt.OctonionSU3Stabilizer): substitute g := ↥(su3 e).

    Base ring ℚ; exact rational linear algebra, nothing archimedean.

                  The cyclic vector and the five word steps #

                  e₀ = 1 is a cyclic vector for the regular action: the six basis words 1, σ₁, σ₂, σ₁σ₂, σ₂σ₁, σ₁σ₂σ₁ are L-words applied to e₀. We only need the five generator steps that reach e₁,…,e₅; each is a column read-off of M₁/M₂ that is d-free (the q-dependent diagonal entries multiply zero).

                      G3 colour-action obstruction (scope-(b) structural exclusion). No faithful colour action of an 8-dimensional colour algebra g on the framework's own 6-dimensional regular three-strand Hecke state space can be Hecke- compatible (commute with both braid generators L₁, L₂): such a Φ would land in the Hecke centralizer, whose dimension is ≤ 6 < 8.

                      The invariant cited is the proved finrank_heckeCentralizer_le_six. Applies to 𝔰𝔲(3) = ker(ev_e) via the corpus gate finrank (su3 e) = 8. It does not exclude the colour action on the Schur–Weyl tensor host (ℂ³)^{⊗3}.
