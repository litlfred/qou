              theorem QOU.StandardModel.QuarkBraid.charge_not_factoring_through_braid_element (Q : BraidWord → ℚ) (hu : Q upQuark = 2 / 3) (hd : Q downQuark = -1 / 3) (hconj : Q (mirror upQuark) = -Q upQuark) :
              False

              The Coulomb charge does not factor through the braid element.

              Charge conjugation negates Q and acts as the braid mirror. The mirror of the up quark is the down quark's braid element (antiUp_eq_down), so Q would have to give that one word both −2/3 (as the anti-up) and −1/3 (as the down).

              source
              theorem QOU.StandardModel.QuarkBraid.charge_not_factoring_through_writhe (f : ℤ → ℚ) (Q : BraidWord → ℚ) (hfac : ∀ (β : BraidWord), Q β = f (writhe β)) (hu : Q upQuark = 2 / 3) (hd : Q downQuark = -1 / 3) (hconj : Q (mirror upQuark) = -Q upQuark) :
              False

              A fortiori, not a function of the writhe.

              This route does not use antiUp_eq_down: it needs only that the anti-up and the down carry the same writhe −1, so any Q factoring through the writhe is forced to agree on them.

              theorem QOU.StandardModel.QuarkBraid.linear_charge_map_refuted (c : ℚ) (hu : c * ↑(writhe upQuark) = 2 / 3) (hd : c * ↑(writhe downQuark) = -1 / 3) :
              False

              No linear charge map.

              Q = c·w cannot fit the up and down together: their writhes are antisymmetric (+1, −1) while their charges are not (+2/3, −1/3). This is the sharpest form — it needs no charge-conjugation hypothesis at all.

                    theorem QOU.StandardModel.QuarkBraid.borromean_strand_writhes_all_zero :
                    strandWrithe 3 borromean 0 = 0 ∧ strandWrithe 3 borromean 1 = 0 ∧ strandWrithe 3 borromean 2 = 0

                    Every strand of the canonical Borromean word carries signed crossing sum 0.

                    So the ± orientation label that up-quark.md and down-quark.md use to separate 𝔲 from 𝔡 inside 𝓑₃ is invisible to any per-strand crossing sum: the three components are indistinguishable by that measure. (The pairwise linking numbers all vanish too — that is the defining property of the Borromean rings, and it is why the word is cyclically symmetric of order three.)
