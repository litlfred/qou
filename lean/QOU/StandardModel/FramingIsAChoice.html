    Can T = 0 be proved? No — and that is a theorem, not a gap #

    Bean qou-gzs0, follow-up. Companion to SignCoherentTwist.lean.

    The question #

    qou-gzs0 established that the ribbon layer's only free parameter is an integer framing T, contributing the weight θ^T = q^{T/2}, and that its quantum (5.36 %) is ~4·10⁴ times coarser than the L2 gaps. The natural follow-up is whether the framework pins T = 0, which would remove the parameter entirely.

    It does not, and the reason is structural rather than a missing lemma.

    Why T = 0 is not provable from the ribbon axioms #

    framing_unobservable_iff_trivial_twist: the framing weight is blind to T exactly when θ = 1.

    So at q ≠ 1 — the whole substrate regime, q₀ ≈ 1.11 — the framing is observable: distinct T give distinct weights. A quantity that changes the prediction cannot be fixed by the axioms that leave it free; it has to be pinned by a stated convention. "T = 0" is therefore a normalisation choice to be declared, not a proposition to be derived.

    The converse is the classical boundary: θ = 1 is q = 1, where framing genuinely carries no information. That is consistent with BalancedCategory.ofSymmetric making the symmetric case θ = 𝟙.

    What is provable, and is worth having #

    • bar_invariant_forces_zero — the bar involution negates the twist, so any self-conjugate state has T = 0. This is a genuine derivation of T = 0, on the sector where it applies (bar-invariant states; amphichirality).
    • zero_framing_is_weight_one — T = 0 is the multiplicative unit, i.e. the choice "no framing correction".

    The caveat that matters for the mass path #

    qou-gzs0 found that canonical_mass's F_Bor carries /q³, which is exactly q^{T/2} at T = −6 (−2 per Borromean component). If that factor is the framing, then the operative convention in the mass formula is T = −6, not T = 0 — and proving T = 0 would contradict the working formula rather than support it.

    So the target to settle is not "prove T = 0" but "declare which framing the mass path uses", and that is a corpus/owner ruling, not a Lean obligation. This file exists to make the choice visible as a choice.

      theorem QOU.StandardModel.FramingIsAChoice.framing_unobservable_iff_trivial_twist {M : Type u_1} [CommGroup M] (θ : M) :
      (∀ (T : ℤ), framingWeight θ T = 1) ↔ θ = 1

      The framing is unobservable exactly when the twist is trivial.

      If every framing gives the same weight then θ = 1; conversely θ = 1 makes every weight 1. So at θ ≠ 1 — i.e. q ≠ 1, the substrate regime — distinct framings give distinct predictions, and T must be fixed by a stated convention. This is why T = 0 cannot be a theorem of the ribbon axioms: they are precisely the axioms that leave T free.

      theorem QOU.StandardModel.FramingIsAChoice.bar_invariant_forces_zero {n : ℕ} {t : Fin n → ℤ} (h : ∀ (i : Fin n), t i = -t i) (i : Fin n) :
      t i = 0

      Where T = 0 IS derivable: self-conjugate states.

      The bar involution negates the per-strand twist (TwistDatum.bar), so a state equal to its own conjugate satisfies t = −t pointwise, forcing t = 0. This is a real derivation of zero framing — on the bar-invariant sector only.
