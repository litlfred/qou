    structure QOU.StandardModel.SmoothingGrading (M : Type u_1) [AddCommGroup M] :
    Type u_1

    The data the .md claims: a ℤ-indexed family of homogeneous components of the Skein module, indexed by smoothing count.

    independent is the defining property of a grading that we use: an element lying in two distinct components is zero. (This is strictly weaker than a full internal direct-sum decomposition, so the obstruction below is correspondingly strong — it does not need the full DirectSum structure to bite.)

    • piece : ℤ → AddSubgroup M

      The grade-g component: classes represented by diagrams with exactly g smoothings applied.

    • independent {g h : ℤ} : g ≠ h → ∀ x ∈ self.piece g, x ∈ self.piece h → x = 0

      Distinct graded components meet only in 0.

      S = 0 ∧ Lp = Lm

      The obstruction.

      If the two crossing classes Lp, Lm are homogeneous of grade g and the skein term S is homogeneous of grade g + 1, then the skein relation Lp - Lm = S forces both sides to vanish: S = 0 and Lp = Lm.

      The skein relation is inhomogeneous, so it cannot hold in a graded module unless it is trivial.

      theorem QOU.StandardModel.lepton_number_would_be_trivial {M : Type u_1} [AddCommGroup M] (G : SmoothingGrading M) (g : ℤ) (arises_as_skein : ∀ S ∈ G.piece (g + 1), ∃ (Lp : M) (Lm : M), Lp ∈ G.piece g ∧ Lm ∈ G.piece g ∧ Lp - Lm = S) (S : M) :
      S ∈ G.piece (g + 1) → S = 0

      Consequence: the grading would make lepton number identically zero.

      Lepton number is supposed to count smoothings, so a state with L = k > 0 is represented by a nonzero grade-k class. But if the skein relation holds at every crossing — which it does, it is the defining relation of the Skein module — then every smoothing term is 0 by skein_forces_vanishing.

      Formally: if every grade-(g+1) element arises as a skein term of grade-g crossings, the whole positive-degree part collapses, so the grading cannot distinguish a lepton-carrying state from a nuclear one.
