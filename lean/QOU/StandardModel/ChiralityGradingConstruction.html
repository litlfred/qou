    Constructing the Reeb chirality grading — it exists exactly when the involution is free #

    Bean qou-wqto (V10), under epic qou-qia8. Continues ChiralityIndependentOfCrossing.lean (V9).

    What V9 left open, stated precisely #

    V9 is scope-(a): it shows chirality cannot be the crossing sign, that the first-generation sector needs three bits, and that a Reeb-odd bit admits no Reeb-fixed state. It does not build the grading. Its one positive result, reeb_moved_state_admits_chirality, is weaker than it looks: the witness it produces is fun x => decide (x = s), which satisfies the odd condition at the single pair (s, ι s) and says nothing anywhere else. A grading has to be odd everywhere.

    Asking for that turns the open item into a question with an exact answer:

    For an involution ι, when does a globally ι-odd grading chir : State → Bool exist?

    Exactly when ι is free (has no fixed point). Necessity is V9's boson clause read globally; sufficiency is a construction, and it is the content here.

    The construction #

    An ι-odd grading is the same data as a choice of one element from each orbit. OrbitSection packages that choice: a map rep picking a representative that is one of the two orbit members (mem) and is constant on the orbit (inv). Given it, the grading is

    chir s := decide (s = rep s)

    — true on the chosen representative, false on its partner. Freeness is what makes the two cases exclusive; without it a fixed point would have to be both.

    The section is a hypothesis, not something conjured: for a general state space producing one needs choice over orbits, and the point of taking it as input is that the construction itself is then choice-free and computable. For the finite sector below the section is exhibited by hand, so nothing is assumed there at all.

    The payoff: instantiated, this is the corpus's chirality bit #

    gen1_chirality_is_the_constructed_grading closes the loop. Take Gen1Quark with flipChirality (the involution exchanging u_L ↔ u_R, d_L ↔ d_R, and their antiparticles), and the hand-written section repL choosing the left-handed member of each pair. Then the grading the theorem constructs is equal to V9's chirality function, pointwise.

    So the abstract mechanism is not a parallel invention: run it on the sector the corpus already labels, and it reproduces that labelling. That is a checkable claim — cases x <;> rfl over the eight states, i.e. the two functions are definitionally equal on each — and it is what makes this a construction of the corpus's datum rather than of some datum.

    (Not by decide: Gen1Quark derives DecidableEq but not Fintype, so a ∀ x : Gen1Quark, … goal has no Decidable instance to appeal to. Adding a Fintype instance here would work and would also cost this file its no-instance property, for no gain — the case split proves the same thing and reduces by rfl.)

    Honest scope #

    This does not derive chirality from the substrate, and it is not scope-(b). What is established:

    • an ι-odd grading exists iff ι is free (reeb_odd_grading_iff_free);
    • given a transversal, the grading is written down explicitly, and it is unique up to the global flip (reeb_odd_grading_unique_up_to_flip);
    • the SM first-generation chirality bit is an instance of that construction.

    What is not:

    • the Reeb involution on the physical state space is not identified here — that is CR geometry, and archimedean-chirality.md asserts rather than derives it. Everything below is conditional on ι being whatever involution the Reeb field induces; the theorems say what follows once it is one.
    • nothing is wired to compute, and no observable is predicted.
    • the SM labels enter as the target to be reproduced, exactly as in V9 — never as derived output. flipChirality and repL are written from the known labelling; the content is that the general construction, fed that section, returns the same function, plus the fact that no section could return anything else up to the flip.

    So qou-wqto moves from "the mechanism has the right shape" to "here is the grading, here is exactly when it exists, and it is the corpus's one" — and stays open on the geometric identification.

    Purely finite/decidable content: Bool, an eight-element inductive, two involution arguments. No ℝ, no ordering, no q (§7c). No class, axiom, or instance (the 2026-08-11 laundering ban is satisfied by construction).

    1. What an odd grading needs: a choice of one element per orbit #

    source
    structure QOU.StandardModel.Chirality.OrbitSection {State : Type u_1} (ι : State → State) :
    Type u_1

    A transversal for an involution — a choice of one representative from each orbit.

    mem says the representative is drawn from the orbit {s, ι s} itself, and inv says the choice does not depend on which member you start from. Together they are exactly "pick one element of each orbit".

    This is the input the construction needs, and it is where choice would enter for an infinite state space. Taking it as a hypothesis keeps chirOf/reeb_odd_grading_of_section choice-free.

    • rep : State → State

      The chosen representative of the orbit through a state.

    • mem (s : State) : self.rep s = s ∨ self.rep s = ι s

      The representative lies in the orbit it represents.

    • inv (s : State) : self.rep (ι s) = self.rep s

      The two members of an orbit choose the same representative.

        3. Sufficiency — the construction #

        source
        theorem QOU.StandardModel.Chirality.reeb_odd_grading_of_section {State : Type u_1} [DecidableEq State] (ι : State → State) (hfree : ∀ (s : State), ι s ≠ s) (T : OrbitSection ι) (s : State) :
        chirOf T (ι s) = !chirOf T s

        The grading built from a transversal is odd.

        The two cases of T.mem s are the two ways the orbit can be oriented, and freeness is what keeps them exclusive:

        • rep s = s — then s is the representative, so chir s = true, and ι s is not (that would need ι s = s, contradicting hfree), so chir (ι s) = false.
        • rep s = ι s — then ι s is the representative, so chir (ι s) = true, and s is not, again by freeness.

        Either way chir (ι s) = ! chir s.

        4. Rigidity — the grading is unique up to the global flip #

        c₁ (ι s) = c₂ (ι s)

        Two odd gradings agreeing at one point of an orbit agree on it.

        An odd grading has no freedom within an orbit: fixing its value on one member fixes the other. All the choice lives in the transversal, which is why the construction above is not one option among many but the shape of the answer.
