    Sign-isotype exclusion for a totally antisymmetric S₃-tensor #

    This file mechanizes the representation-theory half of the statement-B Brunnian isotype-exclusion result (docs/audits/2026-08-30-statement-b-brunnian-isotype-exclusion.md, PR #6106).

    The regular representation of S₃ decomposes into its three isotypes, R[S₃] = Sym ⊕ Alt ⊕ Std (trivial ⊕ sign ⊕ standard, dimensions 1 + 1 + 2), carried by the group-algebra projectors

    • π_Sym = (1/6) Σ_{σ} σ (symmetric / trivial isotype),
    • π_Alt = (1/6) Σ_{σ} sgn(σ)·σ (alternating / sign isotype),
    • π_Std = 1 − π_Sym − π_Alt (standard, 2-dimensional isotype).

    For an element t that transforms in the sign representation — a totally antisymmetric tensor, σ • t = sgn(σ)·t for every σ ∈ S₃ — the physics statement is that t lives entirely in the Alt isotype:

    • π_Sym(t) = 0, π_Alt(t) = t, π_Std(t) = 0.

    The crux is the scalar identity Σ_{σ ∈ S₃} sgn(σ) = 0 (three even permutations contribute +1, three odd contribute −1), proved here by decision procedure (sign_sum_eq_zero). Given it and sgn(σ)² = 1, the three projector identities follow.

    Two formulations are given, both sorry-free and both genuinely using the antisymmetry hypothesis (they are false without it):

    1. An unnormalized, base-ring-free version over any additive group M carrying a DistribMulAction (Equiv.Perm (Fin 3)) (§7c: no field, no characteristic assumption). The symmetric sum vanishes, the signed sum equals 6 • t, and the (scaled) standard combination vanishes.
    2. A normalized version with the genuine (1/6) projectors, over a characteristic-zero field R and an R-linear representation ρ. Here the scalar 6 must be invertible, which is exactly why [CharZero R] is required and honestly stated.

    theorem QOU.StandardModel.sign_sum_eq_zero :
    ∑ σ : Equiv.Perm (Fin 3), ↑(Equiv.Perm.sign σ) = 0

    Key scalar identity. The signs of the six permutations of Fin 3 sum to zero: three even permutations contribute +1, three odd contribute −1.

    This is the arithmetic crux behind the vanishing of the symmetric projection of a totally antisymmetric tensor.

    Unnormalized, base-ring-free version #

    Over an arbitrary additive group M with an S₃-action, using only the ambient ℤ-module structure (no division). These are the 6·π_· forms of the three projector identities.

    source
    theorem QOU.StandardModel.symSum_eq_zero {M : Type u_1} [AddCommGroup M] [DistribMulAction (Equiv.Perm (Fin 3)) M] (t : M) (hsgn : ∀ (σ : Equiv.Perm (Fin 3)), σ • t = ↑(Equiv.Perm.sign σ) • t) :
    ∑ σ : Equiv.Perm (Fin 3), σ • t = 0

    Symmetric projection vanishes. For a totally antisymmetric tensor σ • t = sgn(σ) • t, the unnormalized symmetric sum Σ_σ σ • t = 6·π_Sym(t) vanishes — the sign identity Σ sgn σ = 0 kills it.

    source
    theorem QOU.StandardModel.altSum_eq_card_smul {M : Type u_1} [AddCommGroup M] [DistribMulAction (Equiv.Perm (Fin 3)) M] (t : M) (hsgn : ∀ (σ : Equiv.Perm (Fin 3)), σ • t = ↑(Equiv.Perm.sign σ) • t) :
    ∑ σ : Equiv.Perm (Fin 3), ↑(Equiv.Perm.sign σ) • σ • t = 6 • t

    Alternating projection is the identity. For a totally antisymmetric tensor, the unnormalized signed sum Σ_σ sgn(σ) • (σ • t) = 6·π_Alt(t) equals 6 • t, because sgn(σ)² = 1 collapses every summand to t.

    source
    theorem QOU.StandardModel.stdCombination_eq_zero {M : Type u_1} [AddCommGroup M] [DistribMulAction (Equiv.Perm (Fin 3)) M] (t : M) (hsgn : ∀ (σ : Equiv.Perm (Fin 3)), σ • t = ↑(Equiv.Perm.sign σ) • t) :
    6 • t - ∑ σ : Equiv.Perm (Fin 3), σ • t - ∑ σ : Equiv.Perm (Fin 3), ↑(Equiv.Perm.sign σ) • σ • t = 0

    Standard projection vanishes. The (scaled) standard combination 6 • t − Σ_σ σ • t − Σ_σ sgn(σ) • (σ • t) = 6·π_Std(t) vanishes for a totally antisymmetric tensor: 6•t − 0 − 6•t = 0.
