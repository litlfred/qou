          theorem QOU.BringsSurface.ColourCurveBarVsBranch.zOf_barLift {K : Type u_1} [Field K] (s : K) :
          zOf (barLift s) = zOf s

          The bar FIXES z. This is the load-bearing fact.

          No s ≠ 0 hypothesis is needed: in a field 0⁻¹ = 0, so both sides are 0 at s = 0 and the identity is unconditional. Stated that way deliberately — carrying a hypothesis the proof does not use would invite a reader to think the bar-invariance is conditional on something.
