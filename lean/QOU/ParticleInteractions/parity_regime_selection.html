    class QOU.ParticleInteractions.ParityRegimeSelectionContext :
    Type

    Abstract context for the parity_regime_selection claim — manuscript-themed typed fields carrying the substrate parameter, the proton/neutron counts, the channel amplitudes, the sign value, the Q-value, and the mass-asymmetry / Frobenius-positive sums.

    The four regime identities are now carried as upstream class fields (added 2026-08-23 to repair the refutable encoding).

    • q : ℝ

      The substrate parameter q : ℝ.

    • q_gt_one : 1 < q
    • Z : ℕ

      Proton number Z.

    • N : ℕ

      Neutron number N.

    • A : ℕ

      Mass number A = Z + N.

    • A_eq : A = Z + N
    • a : ℝ

      The proton-channel amplitude a : ℝ.

    • b : ℝ

      The neutron-channel amplitude b : ℝ.

    • sign_val : ℝ

      The sign of a^Z · b^{N − 1} as ±1 (encoded as ℝ with value ±1).

    • m_e : ℝ

      Electron rest mass (MeV).

    • Q_value : ℝ

      The Q-value Q(Z, N) (MeV) of the decay.

    • S_Delta : ℝ

      Mass-asymmetry product S · Δ = a^Z · b^{N-1} · (a − b).

    • Sigma_FP : ℝ

      Sum of Frobenius-positive Markov-trace configurations (Σ_FP) used in the even-A regime.

    • sign_identity : sign_val = (-1) ^ (A - 1)

      (i) Sign identity: sign(a^Z·b^{N−1}) = (−1)^{A−1}.

    • odd_regime : Odd A → 3 ≤ A → Q_value = |S_Delta| * m_e

      (ii) Odd-A, A ≥ 3 regime: Q = |S·Δ|·m_e.

    • even_regime : Even A → Q_value = (Sigma_FP + 1) * m_e

      (iii) Even-A regime: Q = (Σ_FP + 1)·m_e.

    • neutron_regime : A = 1 → Q_value = (S_Delta + 1) * m_e

      (iv) A = 1 (neutron decay): Q = (S·Δ + 1)·m_e.
