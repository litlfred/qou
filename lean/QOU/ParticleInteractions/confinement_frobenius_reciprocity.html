    QOU.ParticleInteractions.confinement_frobenius_reciprocity #

    Proposition (prop:confinement-frobenius-reciprocity): confinement Frobenius reciprocity.

    Let T ∈ H_n(q) be a confined bound-state operator selected by the operator-selection LP with primal optimum T = ∑ᵢ x*ᵢ bᵢ and dual optimum (y₀*, y*), where {b₁, …, b_d} is the NF basis, G_{ij} = tr_M(bᵢ bⱼ) is the Frobenius Gram matrix, and the LP-active set is A*(T) = {i : y*ᵢ > 0}. Then for every observable O ∈ H_n(q) the physical expectation value is the Gram-inverse dual pairing weighted by LP-active shadow prices:

    ⟨O⟩_T = O(T) = ∑_{i,j ∈ A*(T)} u*ᵢ (G⁻¹)_{ij} ⟨O, bⱼ⟩ .

    Disposition (integrity) #

    The class carries only the LP + Frobenius data — the NF-basis size d, the Gram matrix G and its active-subspace dual Ginv = G⁻¹, the LP-active set A_star, the primal coefficients x_star, the dual shadow prices u_star = y*, the net-constraint dual y_0_star, the primal/dual objective values, and the observable pairing (pairing O j = ⟨O, bⱼ⟩) and physical expectation (physExp O = O(T)) maps. It does not carry the reciprocity formula or the LP sub-claims as fields (the previous versions did — first a theorem := ⟨ctx.claim_*⟩ self-assuming projection, then a def … : Prop that dropped the master formula entirely — both forbidden / weaker than the .md).

    confinement_frobenius_reciprocity now states the genuine .md claim — the master reciprocity formula together with the LP supporting facts (primal optimum nontrivial, positive net dual, active set nonempty, active ⇔ positive shadow price, strong duality) — over that data, and ends in sorry (disposition B). Establishing it requires the two-part argument of the manuscript: (1) non-degeneracy of the Markov trace as a Frobenius form on H_n(q) giving the dual basis T^∨ = ∑ x*ᵢ (G⁻¹)_{ij} bⱼ, and (2) the LP-active reduction via complementary slackness / KKT stationarity (x*ᵢ = (G⁻¹ u*)ᵢ on A*(T)) — neither present in the QOU library / Mathlib.

    class QOU.ParticleInteractions.ConfinementFrobeniusReciprocityContext :
    Type 1

    LP + Frobenius data of the confinement-reciprocity claim. All fields are inputs (LP primal/dual data, the Frobenius Gram matrix and its active-subspace inverse, and the observable pairing); none asserts the reciprocity conclusion.

    • d : ℕ

      NF basis size d.

    • G : Fin d → Fin d → ℝ

      The Frobenius Gram matrix G_{ij} = tr_M(bᵢ bⱼ).

    • Ginv : Fin d → Fin d → ℝ

      The Frobenius dual-basis matrix (G⁻¹)_{ij} on the active subspace.

    • A_star : Finset (Fin d)

      LP-active set A*(T) = {i : y*ᵢ > 0}.

    • x_star : Fin d → ℝ

      Primal-optimum coefficients x*ᵢ (T = ∑ x*ᵢ bᵢ).

    • u_star : Fin d → ℝ

      Dual shadow prices u*ᵢ = y*ᵢ on the active channels.

    • y_0_star : ℝ

      The net-constraint dual variable y₀*.

    • primal_obj : ℝ

      Primal objective value ∑ᵢ tᵢ x*ᵢ.

    • dual_obj : ℝ

      Dual objective value n_target · y₀*.

    • Observable : Type

      Observables O ∈ H_n(q).

    • pairing : Observable → Fin d → ℝ

      Frobenius pairing ⟨O, bⱼ⟩ = tr_M(O · bⱼ).

    • physExp : Observable → ℝ

      Physical expectation value ⟨O⟩_T = O(T).

    • reciprocity (O : Observable) : physExp O = ∑ i ∈ A_star, ∑ j ∈ A_star, u_star i * Ginv i j * pairing O j

      Master reciprocity formula.

    • primal_nontrivial : ∃ (i : Fin d), x_star i ≠ 0

      Nontrivial primal optimum.

    • y_0_star_pos : 0 < y_0_star

      Positive net dual.

    • A_star_nonempty : A_star.Nonempty

      Nonempty active set.

    • active_iff_pos_shadow (i : Fin d) : i ∈ A_star ↔ 0 < u_star i

      Active ⇔ positive shadow price.

    • strong_duality : primal_obj = dual_obj

      Strong duality. (Needs abstract LP duality infrastructure that does not exist in Mathlib; kept as an honest assumption for models without certificates)
