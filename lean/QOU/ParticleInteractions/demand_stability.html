    QOU.ParticleInteractions.demand_stability #

    Canonical declaration for content block prop:demand-stability: Demand profile determines nuclear and atomic stability.

    This module states the manuscript claim over a context class so the lean.ref URI resolves to a real, compiling declaration in the qou Lake package (§3b-conditional). See the declaration docstring below for what the term discharges versus what is carried as a context-class axiom.

    Base ring (§7c) #

    Z and N are ℕ. The scalars are the demand magnitude |dem|, the Markov trace tr_M and the substrate parameter q, and the claim only ever compares them with ≤ or tests = 0 -- no archimedean construct appears. So the scalars are a generic ordered commutative ring and the substrate evaluation is R := ℝ.
