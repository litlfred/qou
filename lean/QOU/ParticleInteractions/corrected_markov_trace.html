    QOU.ParticleInteractions.corrected_markov_trace — tr_M(σ₀σ₁σ₀) = z³ #

    Canonical Lean for content block prop:corrected-markov-trace.

    The Markov trace of the trefoil braid σ₀σ₁σ₀ is z³ — NOT h·z² + z as the (invalid for adjacent generators) vertex-volume product formula would give.

    The .md proof is a three-step recursion using the Markov reduction property (thm:jones-markov-trace): peeling the top-index generator multiplies the trace by z. This file derives z³ from those reduction steps as hypotheses — not from the conclusion. The previous encoding axiomatised an opaque intermediate_trace with h_trefoil : trM = intermediate and h_z3 : z³ = intermediate and rewrote with both; that was a vacuous self-assuming projection (the two fields just posit the answer) and is removed.

    theorem QOU.ParticleInteractions.corrected_markov_trace {R : Type u_1} [CommRing R] (z trM_σ0 trM_σ1σ0 trM_σ0σ1σ0 : R) (h_single : trM_σ0 = z) (h_reduce1 : trM_σ1σ0 = z * trM_σ0) (h_reduce2 : trM_σ0σ1σ0 = z * trM_σ1σ0) :
    trM_σ0σ1σ0 = z ^ 3

    Corrected Markov-trace of the trefoil tr_M(σ₀ σ₁ σ₀) = z³, derived from the Markov reduction steps.

    The hypotheses are exactly the three reduction steps of the .md proof, each an instance of the Markov property (peel the maximal-index generator, multiplying the trace by z):

    • h_single : trM_σ0 = z (single generator),
    • h_reduce1 : trM_σ1σ0 = z * trM_σ0 (peel σ₁),
    • h_reduce2 : trM_σ0σ1σ0 = z * trM_σ1σ0 (peel the top σ₀).

    From these, tr_M(σ₀σ₁σ₀) = z·(z·(z)) = z³ by substitution and ring. None of the hypotheses asserts the conclusion = z³.

    Base ring (§7c). The reduction recursion is a polynomial identity (z·z·z = z³) — only +, *, substitution, and a ≠ distinctness hypothesis; no inverse, no Real.*, no ordering. It is therefore stated over a generic commutative ring {R : Type*} [CommRing R].
