    Atomicity — the Lie-algebra-rank route to the upper bound (qou-atsd, T3-lie) #

    The atomicity upper bound needs rank G ≤ 1 for the Tannaka dual G — the piece the elementary matrix route (AtomicityFromSelfDuality.lean) could not close, because algebraic-group rank is not in Mathlib. But rank G = rank Lie(G), and Mathlib does have Lie-algebra rank (LieAlgebra.rank) together with the specific-element upper bound

    rank R L ≤ (ad R L x).charpoly.natTrailingDegree (rank_le_natTrailingDegree_charpoly_ad).

    So the residual reframes to a Mathlib-reachable statement: for Lie(SL₂) = 𝔰𝔩₂ with the regular diagonal h = diag(1,−1), ad h has characteristic polynomial X³ − 4X (eigenvalues 0, 2, −2 on the basis h, e, f), whose trailing degree is 1 — giving rank 𝔰𝔩₂ ≤ 1, the atomicity upper bound.

    This file lands the frame (rank_le_one_of_ad_charpoly_trailing): the general reduction from a trailing-degree-≤1 witness to rank ≤ 1. The concrete 𝔰𝔩₂ charpoly computation natTrailingDegree (charpoly (ad h)) = 1 — the genuine remaining core — is bean qou-atsd-t3-lie.

    Lie-rank route to the atomicity upper bound (frame). If a Lie algebra L over R carries an element x whose ad-characteristic polynomial has trailing degree ≤ 1, then rank R L ≤ 1. Immediate from Mathlib's specific-element rank bound rank_le_natTrailingDegree_charpoly_ad.

    This is the closeable reframing of the atomicity residual: with rank G = rank Lie(G) it replaces the (Mathlib-absent) algebraic-group root count by a Lie-algebra charpoly computation. Applied to 𝔰𝔩₂ and the regular diagonal h (whose ad h charpoly is X³ − 4X, trailing degree 1) it yields rank 𝔰𝔩₂ ≤ 1 — the atomicity upper bound. The concrete 𝔰𝔩₂ computation is the remaining core (bean qou-atsd-t3-lie); no instance is fabricated here.

    The 𝔰𝔩₂ triple and its ad h eigenstructure (T3-lie core, in progress) #

    The standard basis of 𝔰𝔩₂ = sl (Fin 2) R: e = E₀₁, f = E₁₀, h = diag(1,−1). The bracket is the matrix commutator (sl_bracket). The Cartan element h acts by [h,e]=2e, [h,f]=−2f, [h,h]=0 — so on the basis (h,e,f), ad h is diag(0,2,−2), charpoly X³−4X, trailing degree 1. This section lands the bracket relations; the basis + charpoly assembly is bean qou-atsd-t3-lie.

            theorem QOU.Atomicity.sl2_subalgebra_rank_le_one {K : Type u_2} [Field K] [Infinite K] (h2 : 2 ≠ 0) (𝔤 : LieSubalgebra K ↥(LieAlgebra.SpecialLinear.sl (Fin 2) K)) :
            LieAlgebra.rank K ↥𝔤 ≤ 1

            Tier-B assembly: every subalgebra 𝔤 ⊆ 𝔰𝔩₂ has rank 𝔤 ≤ 1. Over an infinite field a Cartan subalgebra H = engel_𝔤 x exists (nilpotent), and rank 𝔤 ≤ finrank H (rank_le_finrank_engel). If H is nontrivial its center is nonzero (non_trivial_center_of_isNilpotent); a nonzero central Z commutes with all of H, so under the inclusion ι : H ↪ 𝔰𝔩₂ the whole image lies in ker(ad (ι Z)), whose finrank is ≤ 1 (sl2_centralizer_finrank_le_one). Hence finrank H ≤ 1, so rank 𝔤 ≤ 1. This is the atomicity upper bound rank G ≤ 1 at the Lie level (rank G = rank Lie(G)), for a self-dual rank-2 V.
