    QOU.ParticleInteractions.branching_qvalue_factorization — Σ Δm_e = a^Z · b^{N−1} · (a − b) #

    Proposition (prop:branching-qvalue-factorization).

    For β⁻ decay of a nucleus (Z, N) with A = Z + N:

      Σ_{all 4^A configs} Δ m_e = a^Z · b^{N−1} · (a − b)

    where a = Σ_c G_P(c) and b = Σ_c G_N(c) are the per-nucleon channel sums over the four channels.

    Lean structure — genuinely derived, not axiomatised #

    Earlier this block recorded the factorisation against an abstract totalDeltaM field, which could only be asserted. It is now derived sorry-free from a concrete config-sum model:

    1. Concrete config sum. configSum g P is the sum over all 4^P channel assignments of P slots of the product of per-slot weights.
    2. Multiplicativity reduction (real content). configSum_eq proves configSum g P = (Σ_c g c)^P via Finset.prod_univ_sum — the nucleon-independence / distributivity that turns the 4^A sum into a product of per-nucleon channel sums. This is the genuine combinatorial step, not an assumption.
    3. Total Σ Δm_e as a config-sum difference. totalDeltaM is the daughter (Z+1, N−1) channel product minus the parent (Z, N) product — a concrete def, not a free field.
    4. Factorisation. The theorem substitutes the reduction and factors by elementary algebra, using 0 < N (so b^N = b^{N−1}·b).

    Base ring (§7c) #

    The whole derivation is Finset.prod_univ_sum, pow_succ and ring; the only order hypothesis, 0 < N, is on the neutron count in ℕ. So the channel weights live in a generic [CommRing R] and the substrate evaluation is R := ℝ.
