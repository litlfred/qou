    Atomicity — rank-one Lie algebra ⟹ a single fundamental object (rep-theory → order bridge) #

    This file is a CONDITIONAL SCAFFOLD. It targets the API for the standard reductive-representation-theory fact

    rank Lie(G) = 1 ⟹ Rep(G) is tensor-generated by a single fundamental object,

    isolates its genuine content as one honestly-open premise (an uninhabited Prop class, zero sorry, no fabricated instance — mirroring sibling PR #4380's RankGroupEqRankLie pattern), and then proves sorry-free the downstream bridge to the already-landed order-theoretic separation of PR #4285: a single fundamental object makes the tensor-generation order total (a chain).

      • singleGenerator_gives_chain — the decoupled tie: given the landed subsingleton⟹total lemma threaded as an explicit hypothesis (no import of the unmerged branch) and the class's single-generator conclusion, the tensor-generation order is total.
      • rankOne_gives_jetTowerChain — the full composition rank-1 ⟹ (class) single generator ⟹ (landed lemma) chain, proved modulo only the one open class.

    Mathlib survey — Lie.Weights toward "rank 1 ⟹ one fundamental weight" #

    Present (Lie / weight side).

    • LieAlgebra.rank R L : ℕ (Mathlib.Algebra.Lie.Rank) — the generic ad-nullity; the Lie-algebra rank. The rank-1 hypothesis LieAlgebra.rank R L ≤ 1 is stateable against this definition (and is the hypothesis carried by the class below).
    • Mathlib.Algebra.Lie.Weights.* — Basic (weight spaces, LieModule.weightSpace), Cartan, Chain (α-β weight chains, LieModule.exists_weightSpace_smul_add_eq_bot), RootSystem (the abstract root pairing LieAlgebra.IsKilling.rootSystem of a Killing / semisimple Lie algebra), Killing, Linear. So Mathlib does carry a root system and weight-chain calculus for a semisimple Lie algebra.

    Absent (the reductive dictionary this file needs).

    • No theorem that a rank-1 root system has exactly one simple root / one fundamental weight; no fundamentalWeights : ... indexed by the simple roots with card = rank; and critically no bridge from "one fundamental weight" to "Rep(G) is ⊗-generated by one object" (the Tannakian / highest-weight classification Rep(G) ≃ ⊕_λ V_λ, λ ∈ ℕ·ϖ in rank 1). The dominant-weight monoid = ℕ^{rank} and its generation of the tensor category are not in Mathlib.
    • Consequently the implication rank-1 ⟹ single generator cannot be discharged against Mathlib; it is the genuinely-open premise isolated below.

    Gap this file bridges. It carries rank-1 ⟹ single fundamental object as the open Prop class RankOneImpliesSingleGenerator, and proves the single fundamental object ⟹ tensor-generation chain half sorry-free, tying rep theory to the landed order separation. It does not construct the highest-weight classification.
