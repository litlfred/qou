    QOU.ParticleInteractions.MesonOperatorSelectionT3 #

    Wiring the derived weak-isospin T₃ into the meson operator-selection #

    Serves bean qou-2udt (child of the convergence epic qou-20sx). Resolves the selection half of the honest negative in docs/audits/2026-08-02-meson-fluxtube-junction-reduction.md (bean qou-qpj9, PR #4614): the meson operator-selection was degenerate because its input — the generation winding n ∈ {3,5,7} — is a symmetric function of the quark content (MesonFluxTubeReduction.lean, winding_content_not_injective): the D̄⁰ meson c̄u = {5,3} and the kaon K⁻ = ūs = {3,5} map to the same unsigned winding multiset, so the gg → c̄c operator-selection cannot pick a charm-specific channel.

    The missing datum that audit named — a weak-isospin T₃ grading orthogonal to n — was derived in WeakIsospinT3Grading.lean (PR #4618, bean qou-tdrd) as the sign of the signed writhe: κ = sign(κ)·|κ| = T₃ · genWinding, with charm = σ₁^{+5} (T₃ = +½) and strange = σ₁^{−5} (T₃ = −½) — same generation n = 5, opposite T₃.

    This file refines the meson operator-selection input from the unsigned winding multiset to the signed writhe multiset (an antiquark reverses the braid orientation, so it contributes −κ — a topological fact, not a fitted choice), and checks what the refinement fixes.

    What is proved (sorry-free, lean-direct) #

    1. The selection input is now injective on quarks. signedWrithe (equivalently the pair (genWinding, sign) = (n, 2T₃)) separates all six quarks; in particular the charm block (n=5, T₃=+½) is distinctly selectable from the strange block (n=5, T₃=−½) (selectionInput_injective, charmBlock_ne_strangeBlock).

    2. The specific blocker degeneracy is resolved. The unsigned content still collides D̄⁰ with the kaon (unsigned_D_kaon_collide, reproducing winding_content_not_injective), but the signed content separates them (graded_D_kaon_distinct), and is injective on the four-meson dictionary of lepton-meson-torus-knot-dictionary (gradedContent_injective_on_dictionary). The operator-selection is no longer degenerate on the pair the audit named.

    What is NOT fixed — the honest remainder (two distinct gaps) #

    1. A residual content collision survives once the neutral kaon K⁰ = d̄s is admitted: T₃ grades by (generation, weak-sign), and the charm-antiquark c̄ (κ = −5) shares that grade with the strange quark s (κ = −5), while u (κ = +3) shares it with d̄ (κ = +3). So the signed multiset collides D̄⁰ {−5,+3} with K⁰ {+3,−5} (graded_D_K0_collide, gradedContentExt_not_injective). It is broken only by keeping the quark/antiquark orientation (the "bar") as ordered data — itself topological (strand orientation), giving orderedContent_injective — a datum the audit's symmetric-multiset content model does not carry. The full separation therefore needs a third flavour grading (charm number C vs strangeness S), beyond (n, T₃).

    2. The tube GEOMETRY is untouched (Obstruction A / qou-qpj9). Even a fully-fixed graded content only pins the carrier quantum numbers — the Vol = 0 torus data (MesonFluxTubeReduction.twoStrand_winding_bijective). The hyperbolic braid word at H₃(q) whose closure volume gives the mass is a separate, still-open construction. This is packaged as the content-bearing conjecture class CanonicalHyperbolicMesonBraid with no instance (§3b-tax honest open state). Consequently no a-priori D-meson mass check is run here: T₃ resolves the selection, not the geometry (anti-fit discipline — no braid was hand-picked to hit 1864.84 MeV).

    This file re-states the minimal signedWrithe / T₃ scaffold of PR #4618 locally so it verifies standalone off main (neither #4618 nor #4614 is on main yet); at merge time the two consolidate into one import.

                          The tube GEOMETRY gap — conjecture class, NO instance (§3b-tax) #

                          source
                          class QOU.ParticleInteractions.MesonOperatorSelectionT3.CanonicalHyperbolicMesonBraid (vol mass : Meson → ℚ) :
                          Prop

                          Primary conjecture (open — deliberately NO instance).

                          Refining the operator-selection input to (n, T₃) fixes which meson content is selected (proved above), but not the hyperbolic braid word that carries the mass. The graded content is Vol = 0 torus-carrier data (MesonFluxTubeReduction.twoStrand_winding_bijective); the mass needs a genuinely hyperbolic braid at H₃(q) (Obstruction A, qou-qpj9).

                          A canonical realization would provide volume/mass maps such that:

                          • hyperbolic — every meson's canonical braid has positive volume (not the Vol = 0 carrier the (n,T₃) content alone gives);
                          • mass_positive — the mass law reads off that volume;
                          • breaks_graded_collision — the geometry supplies data beyond (n,T₃): though gradedContent .Dmeson = gradedContent .K0 (graded_D_K0_collide), the physical masses differ sharply (m_D ≈ 1865 ≫ m_K ≈ 498), so the braid word must carry the residual flavour datum the content lacks.

                          Content-bearing (each field is a genuine constraint), and no instance is provided — constructing the canonical hyperbolic meson braid from the graded content is the open step qou-qpj9. A fabricated instance over this finite toy would be forbidden laundering (§3b-tax).

                          • hyperbolic (m : Meson) : 0 < vol m

                            Every meson's canonical braid is genuinely hyperbolic (positive volume), not the Vol = 0 torus carrier the (n,T₃) content provides.

                          • mass_positive (m : Meson) : 0 < mass m

                            The mass law reads the hyperbolic volume (volume–density mass form).

                          • breaks_graded_collision : mass Meson.Dmeson ≠ mass Meson.K0

                            The geometry must separate the residual graded-content collision D̄⁰ ≡ K⁰: same (n,T₃) content, sharply different mass.
