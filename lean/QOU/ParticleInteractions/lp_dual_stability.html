    QOU.ParticleInteractions.lp_dual_stability #

    Proposition (prop:lp-dual-stability): LP dual stability of confined hadrons.

    Let x* be a confined hadron (proton or neutron, built via B₃ · Φ_quarks). Then

    1. x* is LP-stable: G x* ≥ 0 in all six channels;
    2. the dual shadow prices are bounded: |y*ᵢ| ≤ κ(G) · ‖t‖;
    3. the B₃ sub-braid σ₀σ₁⁻¹ is LP-unstable: the σ₀ channel of G · x_partial is strictly negative (partial confinement fails);
    4. strong duality: tr_M(x*) = y₀* · n_target.

    Disposition (integrity) #

    The class carries only the LP data — the Gram matrix G, the cost vector t with its norm ‖t‖, the condition number κ(G), the candidate primal/partial points x*, x_partial, and the dual variables y*, y₀*. It does not carry the four conclusions as fields (the previous version did, then projected them — the self-assuming projection forbidden by AGENTS.md §3b-cond item 5).

    lp_dual_stability states the genuine four-part conjunction over that data and ends in sorry (disposition B): the per-channel non-negativity, the condition-number shadow-price bound, the strict sub-braid instability, and strong duality all require the explicit 6 × 6 Gram-matrix entries at q₀, the LP strong-duality theorem, and a perturbation bound |y*| ≤ κ(G)·‖t‖ for the dual solution — none yet available in the QOU library / Mathlib.

    class QOU.ParticleInteractions.LpDualStabilityContext :
    Type

    Data of the confined-hadron LP-stability claim. All fields are inputs; none asserts a conclusion.

    • q : ℝ

      Substrate parameter q : ℝ.

    • channels : ℕ

      The number of LP channels (6 for the standard QOU H₃(q) NF basis).

    • G : Fin channels → Fin channels → ℝ

      The Frobenius Gram matrix G : Fin channels → Fin channels → ℝ.

    • κ_G : ℝ

      The condition number κ(G) of the Gram matrix (≈ 7.0).

    • y_star : Fin channels → ℝ

      The dual shadow prices y* : Fin channels → ℝ.

    • t : Fin channels → ℝ

      The mass-coefficient (cost) vector t : Fin channels → ℝ.

    • t_norm : ℝ

      The Euclidean norm ‖t‖.

    • tr_M_x_star : ℝ

      The total Markov trace tr_M(x*) : ℝ.

    • y_0_star : ℝ

      The net-constraint dual variable y₀* : ℝ.

    • n_target : ℕ

      The target nucleon count n_target : ℕ.

    • x_star : Fin channels → ℝ

      The confined primal solution x* : Fin channels → ℝ.

    • x_partial : Fin channels → ℝ

      The partial-confinement primal vector x_partial : Fin channels → ℝ.

    • σ_0_idx : Fin channels

      The σ₀ channel index.

    • primal_stable (i : Fin channels) : 0 ≤ ∑ j : Fin channels, G i j * x_star j

      Primal stability holds in all channels.

    • dual_price_bound (i : Fin channels) : |y_star i| ≤ κ_G * t_norm

      Dual shadow prices are bounded.

    • partial_unstable : ∑ j : Fin channels, G σ_0_idx j * x_partial j < 0

      Partial-confinement sub-braid is LP-unstable.

    • strong_duality : tr_M_x_star = y_0_star * ↑n_target

      Strong duality holds. (Needs abstract LP duality infrastructure that does not exist in Mathlib; kept as an honest assumption for models without certificates)
