    QOU.ParticleInteractions.FrobeniusPositivityPredicate #

    The Frobenius-positivity predicate, stated exactly as the corpus states it, and the theorem separating it from the predicate an agent reaches for instead.

    The corpus statement #

    stable-atom.md (def:stable-atom) fixes the predicate:

    Let G(q) be the Frobenius Gram matrix of the primitive Wedderburn-block operators {e_λ}. Decompose the normal form in the primitive basis, T_w = Σ_λ x_λ · e_λ with x_λ ∈ ℤ_{≥0}. The atom K is stable at q iff ∃ x ∈ ℤ_{≥0}^N such that G(q) x ≥ 0 coordinatewise. That is, the Frobenius positivity constraint (Gx)_γ ≥ 0 holds for every primitive constraint γ with x a nonnegative integer vector.

    Two things in that sentence are load-bearing and are easy to drop:

    • the inequality is on G x, not on x; and
    • x are the coordinates in the primitive Wedderburn basis {e_λ}, not the coordinates in the normal-form basis {T_w}.

    Why this file exists #

    Reading (Gx)_γ ≥ 0 as "every normal-form coefficient is ≥ 0" is wrong on both counts, and the mistake is invisible: it type-checks as a positivity condition, it agrees with the corpus's phrasing whenever a block names a channel ("the σ_0 channel violates Frobenius positivity"), and it returns a definite verdict on every input. It is nonetheless a different predicate, and coordPos_imp_frobPos_iff_entriesNonneg below says exactly when the two coincide: never, unless G is entrywise nonnegative. A Gram matrix with one negative entry already separates them.

    That is not a hypothetical. A probe on this branch adopted the naive reading, concluded that k = 1 (one Hopf link) is infeasible for the proton, and so contradicted categorical-proton-properties.md, which states that a single Hopf link L_- = σ_1σ_0 is the minimum structure restoring stability. The corpus was right and the reading was wrong. exists_coordPos_not_frobPos is that failure as a theorem.

    Scope #

    This is the predicate and its separation, over a generic ordered ring (AGENTS.md §7c: no ℝ unless an archimedean construct is genuinely needed -- an order is, a completion is not). It does not supply G(q) for H_3, which is what evaluating stability for a nucleon still requires. Nothing here selects a gluon count or adjudicates any net value.

              theorem QOU.ParticleInteractions.stableAt_trivial {R : Type u_1} [CommRing R] [LinearOrder R] {N : ℕ} (G : Fin N → Fin N → R) :
              StableAt G

              The relaxed stability predicate is trivially satisfied, for every G.

              This is a sharpness result, not a useful one: it shows the corpus's condition carries content only through the constraint this relaxation drops -- that x be the primitive-basis decomposition of the given normal form T_w, with nonnegative integer coordinates. Any formalisation aiming to decide stability for a nucleon must carry that constraint, or it proves nothing.

              Why the Gram entries come out nonnegative #

              The computation qbeta_frobenius_gram_h3_probe finds every entry of the Frobenius Gram matrix nonnegative — at k = 3, where the central primitive idempotents are orthogonal and G is diagonal, and also across the k ≤ 2 filtration, where G acquires four genuine off-diagonal entries and stays nonnegative anyway.

              That is not a coincidence of the numbers. tr_M = Σ_λ y_λ χ_λ, so with convention D's weights (y_λ ≥ 0, and = 0 for ℓ(λ) > 2) the entries are nonnegative as soon as each χ_λ(e_a e_b) is. The block characters are traces of the idempotents' images in the Wedderburn blocks, so the fact needed is the one below, about matrices.

              It is the reason a Gram matrix built from idempotents is better behaved than an arbitrary Gram matrix — and therefore the reason the separation theorem above, while sound in general, does not bite here.

              theorem QOU.ParticleInteractions.trace_mul_nonneg_of_symm_idem {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {n : Type u_2} [Fintype n] {P Q : Matrix n n R} (hPs : P.transpose = P) (hPi : P * P = P) (hQs : Q.transpose = Q) (hQi : Q * Q = Q) :
              0 ≤ (P * Q).trace

              The structural fact. For symmetric idempotent matrices P and Q, tr(P Q) ≥ 0.

              The proof is the identity tr(P Q) = tr((P Q)ᵀ (P Q)), which holds because (PQ)ᵀ (PQ) = Q P P Q = Q P Q and tr(Q P Q) = tr(P Q²) = tr(P Q) by cyclicity and idempotency. The right-hand side is a sum of squares.

              This is what makes the Frobenius Gram matrix of a family of idempotents entrywise nonnegative, block by block, and hence -- once weighted by nonnegative y_λ -- what makes EntriesNonneg hold for the G the corpus defines. The nonnegativity measured at k = 3 and across the k ≤ 2 filtration is this identity, not a numerical accident.

              theorem QOU.ParticleInteractions.entriesNonneg_gram_of_symm_idem {R : Type u_1} [CommRing R] [LinearOrder R] [IsStrictOrderedRing R] {n : Type u_2} [Fintype n] {N' : ℕ} (e : Fin N' → Matrix n n R) (hs : ∀ (a : Fin N'), (e a).transpose = e a) (hi : ∀ (a : Fin N'), e a * e a = e a) :
              EntriesNonneg fun (a b : Fin N') => (e a * e b).trace

              The Gram matrix of a family of symmetric idempotents is entrywise nonnegative -- exactly the hypothesis frobPos_of_entriesNonneg needs.

              So for such a family Frobenius positivity is implied by coordinatewise positivity, and therefore excludes nothing from the nonnegative orthant: the constraint is loose. This is the general statement behind the corpus's own report of N_ℓ = 84 feasible ILP solutions for the proton -- a count that is large precisely because the constraint is weak.
