    QOU.ParticleInteractions.tritium_qvalue_symbolic #

    Proposition for content block prop:tritium-qvalue-symbolic: The Q-value of tritium β⁻-decay ³H → ³He + e⁻ + ν̄ₑ has an exact closed form as a rational function of q.

    The derivation is the branching factorisation at (Z, N) = (1, 2) (so A = 3, odd regime):

    Σ_{4³ configs} Δmₑ = a¹ · b¹ · (a − b) = a·b·(a − b),

    with channel sums (categorical inputs from the branching factorisation)

    a = −h/2, h = q − q⁻¹, b = −3(q²−1)(q²+1)² / (4q³).

    These channel-sum definitions are carried as class hypotheses; the closed form Q = m_e · 3(q²−1)³(q²+1)²(3q⁴+4q²+3) / (32q⁷) is derived from a·b·(a − b) by field algebra (verified against the manuscript expression in computations/), not projected from a stored field.

    class QOU.ParticleInteractions.TritiumQvalueContext :
    Type

    Context for the tritium Q-value: the substrate parameter, electron mass, and the two branching-factorisation channel sums a, b carried as their categorical-input definitions (not the conclusion — the rational closed form is derived from them in tritium_qvalue_symbolic).

    • q : ℝ

      Substrate parameter q : ℝ.

    • q_gt_one : 1 < q
    • h : ℝ

      Hecke differential h = q − q⁻¹.

    • h_eq : h = q - q⁻¹
    • m_e : ℝ

      Electron mass m_e : ℝ.

    • Q : ℝ

      The Q-value Q(³H → ³He) : ℝ.

    • a : ℝ

      Standard-channel sum a (categorical input).

    • b : ℝ

      Standard-channel sum b (categorical input).

    • a_eq : a = -h / 2

      Channel-sum input: a = −h/2.

    • b_eq : b = -3 * (q ^ 2 - 1) * (q ^ 2 + 1) ^ 2 / (4 * q ^ 3)

      Channel-sum input: b = −3(q²−1)(q²+1)² / (4q³).

    • qvalue_branching : Q = a * b * (a - b) * m_e

      Branching-factorisation ansatz: the Q-value equals the product of the 4³ configuration sum a·b·(a − b) times m_e.
