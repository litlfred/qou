    QOU.ParticleInteractions.transfer_matrix_identities #

    Canonical Lean formalization for content block prop:transfer-matrix-identities: Transfer matrix identities: $T_{pp}T_{nn} = I$ and $T_{pn}^2 = [2]_q^2/4 \cdot I$.

    Per prop:beta-decay-transfer-matrix (mass-theory/beta-decay-transfer-matrix.md), each nucleon pair contributes a crossing transfer matrix

    T(c, d) = !![c·(q − q⁻¹) + d, c; c, d]

    with crossing coefficients (c, d) depending on the pair type:

    T_pp = T(1, 0), T_nn = T(1, −(q − q⁻¹)), T_pn = T(1, −(q − q⁻¹)/2) (the mixed crossing ½(σ + σ⁻¹)).

    This file proves the two identities of the proposition over a generic field K (AGENTS.md §7c base-ring rule — the identities are purely algebraic; no ordering or square root is used):

    • (i) T_pp * T_nn = 1 and T_nn * T_pp = 1 — these hold for every q : K (they are ring identities in h = q − q⁻¹).
    • (ii) T_pn * T_pn = ((q + q⁻¹)^2 / 4) • 1 — requires q ≠ 0 (so q·q⁻¹ = 1, giving 1 + (q − q⁻¹)²/4 = (q + q⁻¹)²/4) and (2 : K) ≠ 0 (the mixed crossing has half-integer coefficients).

    Supporting lemmas record the corollary facts stated in the .md: det T_pp = det T_nn = −1 (unimodularity, forced by the Hecke eigenvalues q·(−q⁻¹) = −1), trace T_pn = 0, and det T_pn = −(1 + (q − q⁻¹)²/4).

            theorem QOU.ParticleInteractions.transfer_matrix_identities {K : Type u_1} [Field K] (q : K) (hq : q ≠ 0) (h2 : 2 ≠ 0) :
            (T_pp q * T_nn q = 1 ∧ T_nn q * T_pp q = 1) ∧ T_pn q * T_pn q = ((q + q⁻¹) ^ 2 / 4) • 1

            Transfer matrix identities (prop:transfer-matrix-identities):

            (i) T_pp · T_nn = T_nn · T_pp = I;

            (ii) T_pn² = ([2]_q²/4) · I where [2]_q = q + q⁻¹.

            Stated over a generic field K with q ≠ 0 and (2 : K) ≠ 0 (AGENTS.md §7c). This is the declaration resolved by the block's lean.ref URI qou:QOU.ParticleInteractions.transfer_matrix_identities.
