    QOU.ParticleInteractions.confinement_operator_selection — topological Brunnian selection #

    Canonical for content block prop:confinement-operator-selection: Confinement operator selection via topological Brunnian minimality.

    The confinement operator is selected by a topological principle: a confined n-quark state is the closure of the crossing-minimal nontrivial Brunnian n-braid (confinement ⇔ no proper subset of quarks can be isolated ⇔ every proper sublink is trivial). This replaces the earlier minimum-action on the 6×6 Frobenius Gram matrix framing, which was refuted: NF(𝓑₃) is ≈ 99.8% the identity γ (the maximum-cost channel), so any cost-minimising operator-space program selects the smallest-cost mesonic L± instead — never 𝓑₃ (see docs/audits/2026-06-17-b3-dense-sdp-lever-closed.md and computations/probes/b3_dense_sdp_wedderburn_projector.py).

    The general statement yields the baryon/meson dichotomy as a theorem: nontrivial Brunnian links require ≥ 3 components, so confinement (a nontrivial Brunnian braid) exists iff n ≥ 3 — n = 2 (mesons) has none and falls back to pairwise L± binding, while n = 3 (baryons) selects the minimal Brunnian link, the Borromean braid 𝓑₃ = (σ₀σ₁⁻¹)³.

    This is a placeholder context-class: the Brunnian predicate, the existence dichotomy, and crossing-minimality are axiomatised as class fields carrying the computational witnesses (computations/probes/b3_brunnian_selection_scope.py, b3_brunnian_minimality_enumeration.py); the theorem composes them. Minimality is witnessed among 3-braid closures (the framework's setting), not proved as full link-theoretic uniqueness. Upgrading to a closed Lean proof requires formalising the Brunnian predicate over an actual braid-group model and the finite enumeration.

    Braid-group word model — the Borromean linking signature is machine-proved #

    A concrete 3-strand braid-word model. A letter is a generator index (0 = σ₀ swapping the strands at positions 0,1; 1 = σ₁ swapping positions 1,2) with a sign. Tracking strand positions through the word, signedCrossings accumulates the signed crossing count per unordered strand pair (= 2·lk), and crossingCounts the unsigned count. For the Borromean braid (σ₀σ₁⁻¹)³ both are proved by decide: every pairwise linking number vanishes (the Brunnian signature — a necessary condition for Brunnian) while every pair still crosses twice (geometrically interwoven). Moreover borromean_sublinks_trivial proves the full Brunnian property's decidable core: deleting any strand leaves a 2-braid trivial in B₂ ≅ ℤ (exponent sum 0), hence each 2-sublink closes to the unlink — no general unknot recognition needed, because B₂ is free abelian on one generator. Crossing-minimality at n = 3 is now also machine-proved, by native_decide, in QOU.Knots.TL.borromean_crossing_minimal (../Knots/KauffmanTL3.lean): enumerating every 3-braid word of length < 6, none is simultaneously Brunnian (the B₂ test above) and nontrivial (the writhe-normalised Kauffman/TL₃ bracket = Jones invariant), while the Borromean (σ₁σ₂⁻¹)³ at length 6 is — cross-checking the Python enumeration oracle. So the general-n is_minimal_brunnian field below remains an abstraction, but its n = 3 (baryon) instance is a closed Lean proof, not merely witnessed.

                      theorem QOU.ParticleInteractions.BraidModel.borromean_sublinks_trivial :
                      b2class 0 borromean = 0 ∧ b2class 1 borromean = 0 ∧ b2class 2 borromean = 0

                      Brunnian property — decidable core, machine-proved. Deleting any one of the three strands from the Borromean braid leaves a 2-braid that is trivial in B₂ ≅ ℤ (exponent sum 0; concretely each induced word is σ σ⁻¹). Because B₂ is free abelian on one generator, exponent-sum-0 is exactly triviality, so each 2-sublink closure is the 2-component unlink — i.e. removing any quark frees the other two. This proves the full Brunnian property modulo the textbook facts B₂ ≅ ℤ and "a trivial 2-braid closes to the unlink"; only crossing-minimality (the finite enumeration, b3_brunnian_minimality_enumeration.py) remains witnessed-not-proved.
