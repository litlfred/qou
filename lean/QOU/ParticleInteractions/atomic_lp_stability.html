    QOU.ParticleInteractions.atomic_lp_stability — bare H is LP-unstable, dressed H is stable #

    Proposition (prop:atomic-lp-stability).

    The bare hydrogen atom [e, 𝔭] = σ₀⁻¹ in H₂(q) is LP-unstable: there exists a Markov-normalised operator X* = α · 𝟙 + β · σ₀ that annihilates the traced volume (V = 0). The 𝓑₃ dressing (proton internal structure) stabilises the atom: the annihilation ratio λ_s / λ_a changes from 0.537 (bare) to q⁻¹⁰ (dressed), so the original annihilator X* cannot satisfy the dressed condition.

    2026-09-03 — the docstring described a repair that was never made #

    This module's header used to say:

    "Carries the genuine inputs … but not the conclusion."

    "Those two facts are therefore stated faithfully and end in sorry (disposition B)."

    Neither sentence described the code beneath it. AtomicLPStabilityContext carried both conclusions as fields — bare_unstable and dressed_stable, each the theorem's statement verbatim — and both theorems ended in the projection, not in sorry. This is the fourth file in this drain whose prose asserts the repair while the code does the opposite (cf. QOU.Archimedean.knot_operator_selection, QOU.BraidsKnots.skein_mass_from_linking, QOU.Interactions.nucleon_ordering_factorization).

    The class was inhabitable by junk, and that is now proved #

    Every other field was data too — Candidate is a bare Type, and normalised, bareVolume, dressedVolume are functions the instance supplies. So an instance could pick Candidate := Unit, normalised := fun _ => True, bareVolume := fun _ => 0, dressedVolume := fun _ => 1, and satisfy both "conclusions" with data that has nothing to do with hydrogen, H₂(q), or a Markov trace. atomic_lp_stability_of_junk_data below exhibits exactly that instance, so a [AtomicLPStabilityContext] binder is demonstrably not an assumption about anything.

    not_atomic_lp_stability_of_junk_data gives the other half: the same carrier type with bareVolume := fun _ => 1 refutes it. Satisfiable and refutable at freely-chosen data is the sharpest statement of what the claim constrains without the Hecke content — nothing.

    That is also why sorry (disposition B, as the old docstring proposed) would have been unsound: it reads as "true, not yet proved" over a statement that is false at free data.

    Disposition: name it, assert nothing (AGENTS.md §1a, disposition 3) #

    atomic_lp_stability is now a Prop-valued definition over caller-supplied data. A caller who has actual H₂(q) candidate operators and Markov pairings supplies them and takes this as a hypothesis, and it constrains them because the data are theirs. bare_is_lp_unstable and dressed_is_lp_stable remain, as the two halves of that hypothesis — the legitimate accessor idiom, since what they destructure is something the caller brought rather than something an instance chose.

    What is still open, and what is proved #

    Open, stated rather than implied: both annihilator-existence facts. They are claims about the kernel of a 2 × 2 Markov-trace pairing on H₂(q) and need the Iwahori–Hecke representation theory and Markov-trace machinery — the eigenvalue structure of σ₀, the (q, −q⁻¹) versus (q⁵, −q⁻⁵) channels — which the QOU library does not carry. Nothing here constructs σ₀, the pairing, or the Markov normalisation.

    Proved sorry-free: annihilation_ratios_distinct, the arithmetic mechanism linking the two — the bare and dressed ratios are numerically distinct, so no single Markov-normalised X* can annihilate both volumes.

    That result is now stated for every q > 1.1 rather than at one hard-coded substrate literal. The old version pinned 1.109978595554181 — the CODATA-2018 muon derivation — into the statement, which per AGENTS.md §q₀-anchor is not the default pin and, more to the point, was never needed: the proof only ever used q > 1.1, so the conclusion is pin-independent. annihilation_ratios_distinct instantiates it at the substrate value and the choice of anchor can no longer affect it.

    Bean qou-z9ws.

        Prop

        The claim of prop:atomic-lp-stability, as a proposition over caller-supplied data:

        • there is a Markov-normalised candidate annihilating the bare traced volume (the bare hydrogen atom is LP-unstable), and
        • there is none annihilating the dressed volume (the 𝓑₃ dressing stabilises it).

        Named, not asserted. See the module docstring for why neither a projection nor a sorry is the honest form here.
