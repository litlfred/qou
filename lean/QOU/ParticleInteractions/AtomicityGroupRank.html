    Atomicity — the GROUP-rank premise rank G = rank Lie(G) (conditional scaffold) #

    This file is a CONDITIONAL SCAFFOLD, not a closure of rank G = rank Lie(G). It sets up the target API for the standard structural theorem

    rank G = rank Lie(G) (algebraic-group rank = Lie-algebra rank),

    which is absent from Mathlib and which this file does not prove. The theorem is a genuine major result (its proof runs through maximal tori of an algebraic group, the Lie functor, and the identification of a maximal torus with a Cartan subalgebra of the Lie algebra — see the survey below). Here we (1) axiomatize it as a §3b-cond conditional class carrying the real equality as its field, provide no instance, and mark it an OPEN premise; and (2) derive the downstream group bound groupRank G ≤ 1 conditionally on that class, from the already-landed Lie-side bound LieAlgebra.rank K 𝔤 ≤ 1. Only the conditional implication is proved; the group-rank premise itself stays open.

    Why this is needed (atomicity context) #

    QOU atomicity needs rank G ≤ 1 for the Tannaka dual G of a self-dual rank-2 object. The Lie-side bound is already proved sorry-free on branch claude/atomicity-rankone-order-separation-2026-07-25 (PR #4285), QOU/ParticleInteractions/AtomicityLieRank.lean:

    QOU.Atomicity.sl2_subalgebra_rank_le_one : ∀ 𝔤 ⊆ 𝔰𝔩₂, LieAlgebra.rank K 𝔤 ≤ 1 QOU.Atomicity.sl2_rank_eq_one : LieAlgebra.rank K 𝔰𝔩₂ = 1.

    To lift rank 𝔤 ≤ 1 (Lie) to rank G ≤ 1 (group) one needs precisely rank G = rank Lie(G). That is the single open premise this file isolates.

    Mathlib survey — what is present, what is absent #

    Present (Lie side):

    • LieAlgebra.rank R L : ℕ — the Lie-algebra rank (Mathlib.Algebra.Lie.Rank), defined as the minimum over x of natTrailingDegree (charpoly (ad R L x)), i.e. the generic dimension of ad-generalized-0-eigenspaces.
    • LieAlgebra.rank_le_natTrailingDegree_charpoly_ad — the specific-element upper bound.
    • LieAlgebra.IsCartanSubalgebra, LieSubalgebra.engel, LieAlgebra.finrank_engel, LieAlgebra.exists_isCartanSubalgebra_engel, LieAlgebra.rank_le_finrank_engel, LieAlgebra.exists_isRegular, LieAlgebra.isRegular_iff_finrank_engel_eq_rank (Mathlib.Algebra.Lie.{Rank,CartanExists,EngelSubalgebra}) — a genuine Cartan-subalgebra-of-a-Lie-algebra API. The maximal-torus notion on the Lie side is thus available (a Cartan subalgebra of a semisimple Lie algebra is a maximal torus).

    Absent (group side):

    • No LinearAlgebraicGroup / AlgebraicGroup rank, no maximal-torus-of-an-algebraic-group theory. Mathlib has Mathlib.Algebra.Group.*, Mathlib.GroupTheory.*, Mathlib.AlgebraicGeometry.*, and Mathlib.Geometry.Manifold.Algebra.LieGroup (smooth Lie groups), but no algebraic-group rank, no maximal split torus, and no Lie : AlgebraicGroup ⥤ LieAlgebra functor with a rank-preservation theorem.
    • Consequently rank G for an algebraic group G cannot even be stated against a Mathlib definition, let alone equated to LieAlgebra.rank.

    Gap this file bridges: it introduces an abstract handle AlgebraicGroupRank G (the datum "G carries a rank") and the conditional equality class RankGroupEqRankLie (the open theorem rank G = rank Lie(G)), then proves the downstream implication. It does not construct algebraic-group rank theory.

    The abstract group-rank handle and the conditional equality class #

    source
    class QOU.Atomicity.AlgebraicGroupRank (G : Type u_1) :
    Type

    Abstract algebraic-group rank (data). Mathlib has no maximal-torus-of-an-algebraic- group theory, so the rank of an algebraic group G — the common dimension of its maximal tori — cannot be constructed here. We carry it as opaque data: [AlgebraicGroupRank G] means "G comes equipped with a well-defined rank groupRank G : ℕ". This is a data class (like Fintype carrying card), not a proposition — it makes no unproved logical claim; it only names a quantity the ambient algebraic-group theory would supply.

    This is the honest placeholder for the missing Mathlib API. It is deliberately weak: it asserts nothing about how groupRank G relates to anything, so it cannot be used to launder a claim. The load-bearing relation lives in RankGroupEqRankLie below.

    • groupRank : ℕ

      The rank of G (dimension of a maximal torus). Supplied by the ambient algebraic-group theory; abstract here.

        Prop

        Conditional class (§3b-cond): rank G = rank Lie(G). This is the standard structural theorem identifying the rank of an algebraic group G with the rank of its Lie algebra L = Lie(G), absent from Mathlib (see the survey above). We axiomatize it as a Prop-valued class whose single field is the genuine equality groupRank G = LieAlgebra.rank R L — not True, and not the block's own conclusion.

        The equality is non-trivial to discharge: groupRank G is fixed independently by the AlgebraicGroupRank G instance (it does not mention L), so an instance of this class must actually prove that the group's maximal-torus dimension equals the Lie-algebra generic-ad-nullity — the whole content of the theorem. Establishing that in general requires the maximal-torus / Lie-functor theory Mathlib lacks.

        OPEN PREMISE — no canonical instance is provided. Per the anti-laundering rule (AGENTS.md §"Axiomatization is NOT a Proof"), writing this class does not prove rank G = rank Lie(G); the theorem remains mathematically open in this corpus. Any downstream result depending on it is a rigorous conditional (proved modulo this class), never an unconditional claim.
