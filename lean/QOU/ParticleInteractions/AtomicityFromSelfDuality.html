    Atomicity from self-duality — deriving rank-one from the volume-form axiom (T0 + T2) #

    Milestone qou-atsd. The order-separation file (AtomicityRankOneOrderSeparation.lean) reduced atomicity to two premises — the categorical bridge TensorGenerationFree and the jet-tower chain axiom. This file begins deriving them from the QOU axioms rather than assuming them, via the chain

    [ε : V⊗V→𝟙 symplectic, non-deg] + [dim V = 2] ⟹ G ⊆ Sp(V) = Sp₂ = SL₂ ⟹ rank G ≤ dim V / 2 = 1 ⟹ |fundamental objects| ≤ 1.

    Key distinction kept explicit throughout: dim V = 2 is the cohomological input (H¹(Bring) = 2W is rank 2 = dim V); it is not rank G = 2. It is self-duality that collapses dim V = 2 ⇝ rank G = 1 — the Sp₂ = SL₂ dim-2 accident rank Sp(2m) = m.

    Tiers realised here (attack plan: docs/workplans/2026-07-25-atomicity-from-self-duality-attack-plan.md):

    • T0 — Λ²V ≅ 𝟙 non-degenerate forces dim V = 2: the arithmetic crux n.choose 2 = 1 → n = 2 (dim_two_of_choose_two_eq_one). Sorry-free.
    • T2 — the reduction skeleton at the level of the natural-number invariants (dim V, rank G, rank Sp): compose [rank G ≤ rank Sp(dim V)] (self-duality embedding) + [rank Sp(2m) = m] (the classical residual, T3, an explicit hypothesis — not proved here, not an instance) + [dim V = 2] to rank G ≤ 1, hence Subsingleton (Fin (rank G)) (rankG_le_one_of_self_dual, atomicity_subsingleton_of_self_dual). Sorry-free.

    The two hard classical facts — rank Sp(2m) = m (T3, symplectic root system) and G connected reductive (T4, Tannakian reconstruction) — are named residuals carried as hypotheses; they are the open content, honestly delimited, and tracked in beans qou-atsd-t3 / qou-atsd-t4. No axiom fabricates the conclusion (AGENTS.md §"Axiomatization is NOT a Proof").

    T1 — symplectic ⟹ (det A)² = 1 (matrix-group infra). A symplectic matrix satisfies A · J · Aᵀ = J; taking determinants (det J is a unit, isUnit_det_J) gives (det A)² = 1. This is the matrix-group shadow of "self-duality constrains the determinant": in every dimension a symplectic-form-preserving map has det = ±1. The refinement det A = +1 (excluding −1), and thereby the Sp₂ = SL₂ dim-2 accident, is the deeper connectedness / Pfaffian fact — the base case of the classical residual T3, tracked in beans qou-atsd-t1/t3. Holds over any CommRing.

          T3 (m = 1) — maximality ingredient: the diagonal torus is self-centralizing #

          source
          theorem QOU.Atomicity.commute_diagMat_imp_diagonal {R : Type u_1} [Field R] (M : Matrix (Fin 2) (Fin 2) R) (t : Rˣ) (ht : ↑t ^ 2 ≠ 1) (hcomm : M * diagMat t = diagMat t * M) :
          M 0 1 = 0 ∧ M 1 0 = 0

          Maximality ingredient — a regular torus element centralizes only diagonals. If a 2×2 matrix M commutes with diag(t, t⁻¹) for a regular unit t (t² ≠ 1 — which needs the base ring to carry a unit of order > 2, true for the archimedean substrate ℝ/ℂ, false over 𝔽₂/𝔽₃), then M is diagonal (M 0 1 = M 1 0 = 0). Proof: the (0,1)/(1,0) entries of M·diag = diag·M force M 0 1·(1 − t²) = 0 and likewise for M 1 0, and 1 − t² ≠ 0 in a field.

          Consequence: the centralizer of a regular element of the diagonal torus is contained in the diagonals, so (with sl2_diagonal_eq_diagEmbed) the diagonal 𝔾ₘ is self-centralizing — the standard criterion for a maximal torus in a connected reductive group. This is a genuine ingredient of the maximality step (rank ≤ 1); concluding rank ≤ 1 from it still needs the connected-reductive structure theory, so it does not by itself close the atomicity upper bound (bean qou-atsd-t3). The t² ≠ 1 hypothesis honestly records that maximality requires the substrate's ring-richness.
