    QOU.ParticleInteractions.neutron_qvalue_symbolic #

    Proposition (conditional on conj:borromean-quark) for content block prop:neutron-qvalue-symbolic: Symbolic $Q$-value of free neutron $\beta^-$-decay.

    The single-wrap normal-form (NF) net coefficients of the proton [u,u,d] and neutron [u,d,d] in H_3(q) are the conjectural categorical inputs (conj:borromean-quark), carried here as class hypotheses:

    net(p) = 1 − h/2, net(n) = 1 − 3h/2 + h²/2, h = q − q⁻¹.

    The closed-form Q-value additionally assumes the energy-scale ansatz Q_β = |Δ(net)| · E₀ with E₀ = m_e / (q(q−1)), stated "by construction" in the manuscript (pre-archimedean-derivation-chain.md), not derived from the canonical per-braid mass formula. This too is carried as a hypothesis.

    Given these inputs, the symbolic difference Δ(net) = (h² − 2h)/2 and the closed form Q_β = m_e·(2−h)·h / (2q(q−1)) are derived by algebra — this is a rigorous §3b-cond conditional, not a self-projection.

    §3b-cond conjecture class for conj:borromean-quark (non-degenerate per AGENTS.md §3b-cond item 5): carries the conjectural categorical inputs — the single-wrap NF net coefficients and the energy-scale ansatz — as hypotheses, NOT the conclusion (Δ(net) and the Q-value are derived from them below).

      Substrate parameter q : ℝ.

    • q_gt_one : 1 < q
    • h : ℝ

      Hecke differential h = q − q⁻¹.

    • h_eq : h = q - q⁻¹
    • m_e : ℝ

      Electron mass m_e : ℝ.

    • net_p : ℝ

      Proton single-wrap NF net coefficient.

    • net_n : ℝ

      Neutron single-wrap NF net coefficient.

    • Q_β : ℝ

      The Q-value Q_β : ℝ.

    • h_pos : 0 < h

      Substrate-regime bound on the Hecke differential: 0 < h. Holds at the substrate q₀ ≈ 1.11 (h ≈ 0.21); carried as an explicit input so the |Δ(net)| resolution is rigorous, not assumed silently.

    • h_lt_two : h < 2

      Substrate-regime bound: h < 2. Holds at q₀ ≈ 1.11; needed to resolve the absolute value |h² − 2h| = 2h − h².

    • proton_net : net_p = 1 - h / 2

      Conjectural input (i): proton NF net = 1 − h/2.

    • neutron_net : net_n = 1 - 3 * h / 2 + h ^ 2 / 2

      Conjectural input (ii): neutron NF net = 1 − 3h/2 + h²/2.

    • qvalue_ansatz : Q_β = |net_n - net_p| * (m_e / (q * (q - 1)))

      Ansatz input (iii): the Q-value is the absolute NF difference |Δ(net)| scaled by the energy scale E₀ = m_e / (q(q−1)). This Q_β = |Δ(net)| · E₀ relation is stated "by construction" in the manuscript, not derived from the per-braid mass formula.

      theorem QOU.ParticleInteractions.neutron_qvalue_symbolic [inst : BorromeanQuark] :
      BorromeanQuark.Q_β = BorromeanQuark.m_e * (2 - BorromeanQuark.h) * BorromeanQuark.h / (2 * BorromeanQuark.q * (BorromeanQuark.q - 1))

      Symbolic Q-value closed form (conditional on conj:borromean-quark).

      Given the conjectural NF nets and the energy-scale ansatz, the neutron β⁻-decay Q-value has the closed form

      Q_β = m_e · (2 − h) · h / (2 q (q − 1)), h = q − q⁻¹.

      The proof derives this from qvalue_ansatz by substituting the NF nets (via neutron_delta_net) and clearing the denominator — it is NOT a read-back of a stored conclusion.
