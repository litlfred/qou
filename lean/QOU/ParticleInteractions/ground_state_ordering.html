    class QOU.ParticleInteractions.GroundStateOrderingContext (R : Type u_1) [Ring R] :
    Type u_1

    Abstract context for the ground_state_ordering claim — manuscript-themed typed fields below; the ground-state ordering is selected by the transfer-matrix eigenvalues λ_± and the Z, N counts.

    §7c base ring: the claim's only arithmetic is the Vieta product λ₊ · λ₋ = -1, which needs a Ring and nothing more — no ordering on the eigenvalues, no square root, no archimedean construct. The Z ≤ N, 4 ≤ A, A ≤ 3 comparisons are over ℕ, not over the eigenvalue carrier. The carrier is therefore a type variable R; the archimedean realisation is R := ℝ.

    • Z : ℕ

      Proton number Z.

    • N : ℕ

      Neutron number N.

    • A : ℕ

      Mass number A = Z + N.

    • A_eq : A R = Z R + N R
    • q : R

      Substrate parameter q, in the generic base ring.

    • lam_plus : R

      Transfer-matrix dominant eigenvalue (T_pp).

    • lam_minus : R

      Transfer-matrix subdominant eigenvalue (T_pp).

    • ordering : ℕ → ℕ

      The ground-state ordering at position k: 1 = proton, 0 = neutron.
