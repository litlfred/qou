    QOU.Shared.ZPowFinsetProd — a fixed base with varying integer exponents #

    Mathlib carries two neighbouring facts and not this one:

    • Finset.prod_pow_eq_pow_sum — ∏ i ∈ s, a ^ f i = a ^ ∑ i ∈ s, f i for f : ι → ℕ, the right shape but natural exponents;
    • Finset.prod_zpow — ∏ a ∈ s, f a ^ n = (∏ a ∈ s, f a) ^ n, a fixed integer exponent distributed over a varying base, which is the other direction.

    Missing is the combination: one fixed base, exponents varying over ℤ. That is the shape of a gauge product ∏_c z c ^ A c for an integer exponent row A, and of a q-power product ∏ q ^ f i where f takes negative values — so it is needed wherever an exponent lattice acts multiplicatively. ℕ will not do in either case, because lattice rows and content functions both take negative values.

    This file exists because the repo had TWO copies already #

    Found by grep, after a third was written:

    • QOU.BraidKnot.Keystone.prod_zpow_eq_zpow_sum — stated over a Field R with q ≠ 0, used by KeystoneJucysMurphyTwist and HeckeSeminormalWeight;
    • a CommGroup copy inside QOU.Eightfold.GaugeAnsatzNesting, now removed in favour of this file.

    Neither subsumes the other — CommGroup has total zpow, while a ring element needs the q ≠ 0 side condition — so both forms live here. The ₀ version is stated over GroupWithZero, which is strictly more general than the Field it was written for.

    The two pre-existing consumers are deliberately NOT rewired. Consolidating them is a refactor of files this branch has no other business in, and the 2026-09-07 ask-first ruling names "tidying an inconsistency" as not exempt. The duplication is recorded here so the next agent finds it from either end rather than writing a fourth copy.
