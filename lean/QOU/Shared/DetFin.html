    Explicit determinant expansions det_fin_four / det_fin_five / det_fin_six #

    Mathlib ships Matrix.det_fin_two and Matrix.det_fin_three (the explicit Leibniz formulae for 2×2 and 3×3 determinants) but stops there. This module continues the pattern up to 6×6.

    The lemmas are proved incrementally — det_fin_four from det_fin_three, det_fin_five from det_fin_four, det_fin_six from det_fin_five — so each proof only expands the top row via Matrix.det_succ_row_zero and discharges the remaining minors with the previous lemma. This keeps every step at the single-succAbove-layer complexity that simp (decide := true) can fully reduce, avoiding the factorial blow-up of a one-shot 6-level cofactor expansion.

    The det_fin_six RHS has the full 720-term Leibniz sum; it is generated mechanically. These are generic CommRing identities (no archimedean hypotheses), reusable for any explicit small-matrix determinant.
