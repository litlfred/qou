    QOU.Shared.OperatorSelectionLP — shared context for LP-dual claims #

    An LP-selection claim is any proposition that bundles:

    • A target n_target ∈ ℝ_{>0}
    • A d-dimensional NF basis with Markov-trace coefficients t_i
    • A d × d Frobenius Gram matrix G_{ij}
    • The LP primal optimum x* : Fin d → ℝ
    • The LP dual optima (y_0*, y* : Fin d → ℝ)

    Per local/lean-substantive-pass, ~10 blocks share this shape (operator-selection / confinement / shadow-price / strong-duality content). This typeclass extracts the shared structure so per-block claims only need to specify which LP-property they encode (primal feasibility / strong duality / active-set characterisation / etc.).

    Usage:

    class MyLPClaim extends QOU.Shared.OperatorSelectionLPContext where
  -- block-specific assertion
  claim_active_set_size :
    (Finset.filter (fun i => 0 < y_star i) Finset.univ).card = 3

    class QOU.Shared.OperatorSelectionLPContext :
    Type

    Shared context for any block whose claim involves the operator-selection LP and its dual certificate.

    • n : ℕ

      Strand number n ≥ 2.

    • d : ℕ

      Basis dimension d (usually n!).

    • n_target : ℝ

      The target net value n_target ∈ ℝ_{>0}.

    • t : Fin d → ℝ

      The Markov-trace coefficient vector t : Fin d → ℝ.

    • G : Fin d → Fin d → ℝ

      The Frobenius Gram matrix G : Fin d → Fin d → ℝ.

    • x_star : Fin d → ℝ

      The primal optimum x* : Fin d → ℝ.

    • y_0_star : ℝ

      The Markov-trace dual variable y_0* : ℝ.

    • y_star : Fin d → ℝ

      The Frobenius-positivity dual variables y* : Fin d → ℝ.

    • A_star : Finset (Fin d)

      LP-active set: the indices i with strictly positive dual variable, A* = {i : y*_i > 0}.

    • strong_duality : ∑ i : Fin d, t i * x_star i = n_target * y_0_star

      Strong-duality identity: Σ t_i · x*_i = n_target · y_0*. (Needs abstract LP duality infrastructure that does not exist in Mathlib; kept as an honest assumption for models without certificates)
