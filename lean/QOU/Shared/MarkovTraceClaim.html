    QOU.Shared.MarkovTraceClaim — shared context for Markov-trace claims #

    A Markov-trace claim is any proposition that bundles a substrate parameter q, a strand count n, an Iwahori–Hecke algebra H_n(R, q), and a Markov-trace instance, and then asserts some identity about tr_M(x) for x : H_n(R, q).

    Per local/lean-substantive-pass, ~40 blocks in the QOU package share this shape (Hecke / Wenzl-bridge / mass-formula / spectral-sequence content). This typeclass extracts the shared structure so per-block claims only need to specify the substantive identity.

    Usage:

    class MyBlockClaim extends QOU.Shared.MarkovTraceContext where
  -- block-specific data (Hecke element, etc.)
  T_w : A
  -- block-specific assertion
  claim_identity : markovInst.trace T_w = ...

    Then the per-block theorem proves directly from claim_identity:

    theorem my_block [ctx : MyBlockClaim] :
    ctx.markovInst.trace ctx.T_w = ... :=
  ctx.claim_identity

    class QOU.Shared.MarkovTraceContext :
    Type (u + 1)

    Shared context for any block whose claim involves a Markov trace on the Iwahori–Hecke algebra H_n(R, q). Bundles the coefficient ring, substrate parameter, Hecke algebra, and Markov-trace instance.

    • R : Type u

      The coefficient ring R.

    • ringR : CommRing R

      Commutative-ring structure on R.

    • invR : Inv R

      Inverse function on R (needed for q^{1/2} + q^{-1/2} in the Markov parameter).

    • q : R

      The substrate parameter q : R.

    • n : ℕ

      The strand count n.

    • A : Type u

      The Hecke-algebra carrier A = H_n(R, q).

    • ringA : Ring A

      Ring structure on A.

    • algebraA : Algebra R A

      R-algebra structure on A.

    • heckeInst : Hecke.HeckeAlgebra R n q A

      The Hecke-algebra typeclass instance.

    • markovInst : Hecke.MarkovTrace n q A

      The Markov-trace instance on A.
