    class QOU.Braiding.TrMHopfSigma1SqClosedForm (q : ℝ) :
    Type

    Closed-form value of the canonical Markov trace of σ_1² in H_n(q), expressed as a real-valued function of q > 1.

    The propositional content is the algebraic identity (q^{5/2} − q^{1/2} + q² + q) / (q² + q) = 1 + (q − 1) · q^{−1/2} that the Markov-trace value satisfies for every n ≥ 2. Markov-invariance under stabilisation is captured by the MarkovTraceTower class.

    closed_form carries the value; closed_form_equals_simplified follows from the rpow algebra.

    • q_gt_one : 1 < q

      Hypothesis: q is in the Wenzl positivity regime (q > 1).

    • trM_sigma1_sq : ℝ

      Canonical-Markov-trace value of σ_1² in H_n(q) at any n ≥ 2.

    • closed_form : trM_sigma1_sq q = (q ^ (5 / 2) - q ^ (1 / 2) + q ^ 2 + q) / (q ^ 2 + q)

      The closed form: tr_M(σ_1²) = (q^{5/2} − q^{1/2} + q² + q) / (q² + q).

      TrMHopfSigma1SqClosedForm.trM_sigma1_sq q = 1 + (q - 1) * q ^ (-1 / 2)

      The closed form equals the simplified form 1 + (q − 1) · q^{−1/2}.

      Proof strategy: substitute u := sqrt(q) > 0 and reduce to the polynomial-in-u identity (u^5 - u + u^4 + u^2) / (u^4 + u^2) = 1 + (u^2 - 1) · u⁻¹ which closes via field_simp + ring under u > 0.
