    QOU.Braiding.HeckeGenPolyReduction — single-generator Hecke polynomial #

    reduction ∏ⱼ (σ + dⱼ·1) = α·σ + β·1 (Cayley–Hamilton).

    Proposition (prop:hecke-generator-poly-reduction).

    Any product of factors (σ_i + dⱼ·1) in a single Hecke generator σ_i collapses to an R-linear combination α·σ_i + β·1, with (α, β) given by a DIVISION-FREE recursion driven only by the Hecke quadratic relation σ_i² = (q − q⁻¹)·σ_i + 1:

      (α, β) for []      = (0, 1)
  (α, β) for d :: ds = (α'·(h+d) + β',  α' + β'·d)   where (α',β') = rec ds,  h = q−q⁻¹.

    This is the algebraic core of the monotone-word fine-Bratteli transfer matrix for the atom character (computations/chi_monotone_transfer.py). The atom braid word has a monotone generator sequence, so each per-generator operator O_g = ∏ⱼ(σ_g + dⱼ·1) is a single-generator polynomial; by this reduction its seminormal diagonal entry is α·D(δ′) + β — a function of the content gap δ′ of the two added boxes alone. That is what removes the d_λ-dimensional Hoefsmit matrix from the χ compute (⁶Li/⁷Li in sub-second time, no n! wall).

    The reduction holds over ANY CommRing R — no archimedean / q+q⁻¹ ≠ 0 hypothesis (per AGENTS.md §7c the structural fact is stated generically). The eigenvalue closed form α = (E₁−E₂)/(q+q⁻¹), E₁=∏(q+dⱼ), E₂=∏(−q⁻¹+dⱼ) used in the compute for speed is a corollary that DOES need 2-invertibility; only the division-free heckeAB recursion is formalised here, and it suffices for correctness.

      Single-generator Hecke polynomial reduction (Cayley–Hamilton).

      For σ : A satisfying the Hecke quadratic σ * σ = h • σ + 1, every product ∏ⱼ (σ + dⱼ • 1) equals α • σ + β • 1 with (α, β) = heckeAB h ds. Proof: induction on ds, using only the quadratic relation (no division).

      This makes the per-generator block of the transfer-matrix χ a single α·D(δ′) + β evaluation; see the module docstring.
