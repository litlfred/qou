    class QOU.Braiding.MarkovTraceTower (q : ℝ) :
    Type

    Canonical Markov-trace tower abstraction.

    MarkovTraceTower q parameterises a family of trace maps tr_n : H_n(q) → ℝ (one per n ≥ 1) satisfying the three Markov-trace axioms (Jones 1987 §2):

    (M1) Normalisation: tr_n(1) = 1 (M2) Trace property: tr_n(a · b) = tr_n(b · a) (M3) Markov property: tr_{n+1}(β · σ_n^{±1}) = z^{±1} · tr_n(β) for β ∈ H_n(q) and σ_n the new generator, with z := 1/(q^{1/2} + q^{-1/2}).

    For abstract reasoning about cross-n invariance, the relevant property is (M3)' a STRENGTHENING of (M3): when σ_n is disjoint from β (which is the case when β uses only generators σ_1..σ_{m-1} for m < n), the new strand contributes z · z⁻¹ = 1 in the stabilisation chain. Thus tr_n(β) = tr_m(β) for the canonical inclusion H_m ⊆ H_n.

    • z : ℝ

      The Markov parameter. The class does not fix a convention — an instance does, by what it assigns here. This docstring used to read z = 1/(q^{1/2} + q^{-1/2}), i.e. it named convention C at the class level, which is the wrong place for it: the class is the abstraction over towers, and a convention is a property of an instance. Corrected 2026-08-26 (bean qou-cxjq). The canonical instance below is convention D.

    • z_pos : 0 < z q

      z is positive.

    • trM_sigma1_sq : ℕ → ℝ

      The Markov trace at H_n: σ_1² → ℝ. This abstracts over the concrete Hecke-algebra elements; only the trace of the Hopf braid σ_1² in H_n is needed here.

    • trM_sigma1_sq_stabilises (m n : ℕ) : 2 ≤ m → 2 ≤ n → trM_sigma1_sq q m = trM_sigma1_sq q n

      Markov-invariance: for every n ≥ 2, the trace of σ_1² is the same as in H_2 (since σ_1² involves only the first generator, extra strands stabilise trivially: z · z⁻¹ = 1).

      This is property (M3)' applied to σ_1² ∈ H_2 ⊆ H_n.

      noncomputable instance QOU.Braiding.markovTraceTower_canonical (q : ℝ) (hq : 1 < q) :
      MarkovTraceTower q

      Canonical concrete instance of MarkovTraceTower q for q > 1 (Wenzl positivity regime).

      The instance uses:

      • z = 1/(q^{1/2} + q^{-1/2}) (canonical Wenzl Markov parameter)
      • trM_sigma1_sq n = (q^{5/2} − q^{1/2} + q² + q) / (q² + q) for all n (Markov-invariant closed form proved in prop:trm-hopf-sigma1-sq-closed-form)
      • stabilises proof: the function is constant in n, so trivially equal.

      The numerical implementation lives in computations/markov_peel.tr_M_atomic (Python; uses GS reduction + Markov-axiom recursive ascent). The Lean class instance here mirrors that semantic at the type level.

      Convention D (owner ruling R1, 2026-08-15), migrated from convention C 2026-08-26 (bean qou-cxjq). This instance previously set z := 1/(√q + 1/√q) — convention C — and was the single most load-bearing convention site in the tree: it is the tower downstream Jones-value code resolves against. It was invisible to scripts/lean-markov-convention-audit.py until that scanner learned to read instance field assignments, because a convention set by a field is not set by a def body (detector-blindness taxonomy #15).

      Both fields move together, and they have to. trM_sigma1_sq is the Markov trace of the Hopf braid σ₁², which the Markov axiom fixes as h·z + 1; the committed convention-C value (q^{5/2} − q^{1/2} + q² + q)/(q² + q) is exactly that at z = z_C (verified symbolically). Migrating z alone would have left the instance internally inconsistent — a tower whose z and whose Hopf trace came from different conventions.

      Under convention D the same identity gives h·z_D + 1 = (q − q⁻¹)·q³/(q²+1) + 1 = (q⁴ + 1)/(q² + 1), which is fully rational in q. So the note that used to sit here — that real-valued q^{1/2} requires Real.sqrt, used via Real.sqrt_pos for the positivity proof — no longer applies: convention D removes every square root from this instance, positivity included.
