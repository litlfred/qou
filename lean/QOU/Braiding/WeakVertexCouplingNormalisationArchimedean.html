    Archimedean half of the coupling-normalisation result #

    The generic-field identities live in WeakVertexCouplingNormalisation; this file is their K := ℝ specialisation, kept separate per AGENTS.md §7c because everything here needs the archimedean structure of ℝ — HasDerivAt for the vanishing orders, and decidable rational arithmetic for the exclusion.

    Two results:

    • Vanishing orders. s² vanishes to second order at q = 1 (hasDerivAt_sSq_one: s²′(1) = 0, with sSq_one giving s²(1) = 0), while W has W′(1) = 5 ≠ 0 (hasDerivAt_weakVertexTrace_one), so W − W(1) vanishes only to first order. A single bridge factor vanishing like q − 1 repairs that, so the order alone does not decide the question.

    • The exclusion. no_constant_rescaling: there is no constant c with c · (W(q) − 1/4) · ℏ_q = s²(q) for all q > 1. It is decided at two rational points — candidateRatio_two gives 695.91 at q = 2 and candidateRatio_three_halves gives ≈ 65.27 at q = 3/2 — so the ratio is a function of q, and no normalisation constant absorbs it.

    Scope: this excludes the family c · (W − W(1)) · X; it says nothing against W itself. Bean qou-pfh7.

    Verified lean-direct, sorry-free.

    source
    theorem QOU.Braiding.WeakVertexT35.hasDerivAt_sSq_one :
    HasDerivAt (fun (x : ℝ) => sSq x) 0 1

    s² vanishes to second order: its derivative at q = 1 is 0.

    source
    theorem QOU.Braiding.WeakVertexT35.hasDerivAt_weakVertexTrace_one :
    HasDerivAt (fun (x : ℝ) => weakVertexTrace x) 5 1

    W vanishes to first order about its classical value: W′(1) = 5 ≠ 0, so W − W(1) is 5(q − 1) + O((q−1)²).

    source
    theorem QOU.Braiding.WeakVertexT35.no_constant_rescaling :
    ¬∃ (c : ℝ), ∀ (q : ℝ), 1 < q → c * candidateCoupling q = sSq q

    The family is excluded. No constant rescales the order-matched candidate onto the coupling the decay rate uses: c would have to be 100/69591 at q = 2 and 86528/5647625 at q = 3/2.

    source
    theorem QOU.Braiding.WeakVertexT35.candidateRatio_two :
    candidateRatio 2 = 69591 / 100

    At q = 2 the ratio is 69591/100 = 695.91.

    source
    theorem QOU.Braiding.WeakVertexT35.candidateRatio_three_halves :
    candidateRatio (3 / 2) = 5647625 / 86528

    At q = 3/2 it is 5647625/86528 ≈ 65.27 — a different number, so the ratio is a function of q and not a normalisation constant.
