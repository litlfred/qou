    QOU.Braiding.HeckeMassElement — Hecke mass element #

    The Hecke mass element Φ_mass(β) ∈ H_n(q) is the fibre-functor image of the mass integrand (∫_A ⊗ id) ∘ Δ ∘ ϱ, viewed as an endomorphism of A via left multiplication in the Frobenius–Hopf algebra.

    By quantum Schur–Weyl duality, every SU_q(2)-equivariant endomorphism of V^{⊗n} is an element of H_n(q), so the mass element is well-defined.

    The descent involution decomposes it: Φ_mass = Φ^desc + Φ^trans

    and the Markov trace of Φ_mass recovers the categorical mass.

    Pre-Archimedean stub. The previous version coupled this stub to [NormedCommRing R] and returned ℝ via ‖·‖. The Hecke mass element lives in H_n(R, q) for any commutative ring R ⊇ ℤ[q^±1]; the Archimedean norm is post-τ. We split into two declarations:

    1. frobeniusMassSquared — the pre-Arch squared mass, m² := ⟨massElement, massElement⟩_F, valued in R (caller supplies the Frobenius pairing).
    2. mass — the post-τ Archimedean realisation, valued in ℝ, requires [NormedCommRing R].

    structure QOU.Braiding.HeckeMassElement (R : Type u) [CommRing R] :
    Type u

    The Hecke mass element: given a particle's Hecke element ρ(β) and the Frobenius–comultiplication dressing, the mass element is the dressed element whose Markov trace computes the mass.

    Abstractly: Φ_mass(β) = τ(L_{α_ϱ}) where α_ϱ = (∫_A ⊗ id) ∘ Δ ∘ ϱ and L denotes left multiplication in the Frobenius–Hopf algebra.

    We encode this as a structure carrying the decomposition data, polymorphic in the ground ring R (pre-Arch: R = ℤ[q^±1]).

    • particleElement : R

      The particle's Hecke element ρ(β) (before Frobenius dressing).

    • descendedComponent : R

      The descended component Φ^desc (base-level cycle).

    • transientComponent : R

      The transient component Φ^trans (blow-up contributions).

    • massElement : R

      The mass element is the sum of descended and transient components.

    • decomposition : self.massElement = self.descendedComponent + self.transientComponent

      Decomposition: Φ_mass = Φ^desc + Φ^trans.
