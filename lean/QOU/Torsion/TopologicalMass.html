        §11a Categorical Mass Decomposition #

        The categorical version of the topological mass decomposition: mass = descended trace + Σ transient traces, where the splitting comes from the idempotent decomposition of End_C(A_{n+1}) via the descent involution.

        LaTeX: \label{thm:topological-mass} (categorical proof)

        source
        structure QOU.Torsion.CategoricalMassDecomposition :
        Type

        Categorical Mass Decomposition (data).

        The mass of a vortex ϱ : 𝟙 → A decomposes into descended and transient contributions via the descent involution τ̂ₙ. This is the categorical formulation — it works in any QOU, not just the archimedean realisation.

        • di : DescentInvolution (ℕ → ℝ)

          The descent involution on the endomorphism algebra.

        • numBlowups : ℕ

          Number of blow-up centres (exceptional divisors).

        • totalMass : ℝ

          The total categorical mass 𝔪(ϱ).

        • totalMass_nonneg : 0 ≤ self.totalMass
        • descendedTrace : ℝ

          Descended trace ‖tr_desc(ϱ)‖: the mass of the base-level cycle ϱ₀, capturing baseline Frobenius–Hopf drag.

        • descended_nonneg : 0 ≤ self.descendedTrace
        • transientTrace : Fin self.numBlowups → ℝ

          Transient trace ‖tr_trans(ϱ, pᵢ)‖ at each blow-up centre.

        • transient_nonneg (i : Fin self.numBlowups) : 0 ≤ self.transientTrace i
        • decomposition : self.totalMass = self.descendedTrace + ∑ i : Fin self.numBlowups, self.transientTrace i

          The decomposition: mass = descended + Σ transient.
