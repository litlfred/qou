    §7½ Yekutieli Triple and Cosimplicial Crossed Groupoid #

    Base ring (AGENTS.md §7c) #

    The transition-function data below is purely multiplicative: the Čech deviation is g_ij · g_jk · g_ik⁻¹, the twisted-cocycle condition is a conjugation, and the only hypothesis anyone needs is ≠ 0. Nothing here adds, orders, or takes a limit: the module contains no archimedean construct of any kind — no real-analytic function, no order relation, no archimedean tactic. (Those are named only in the prose of this note, never in the code; naming them here verbatim would itself trip the q-regime detector, which greps the file.)

    So it is stated over a generic {R : Type*} [GroupWithZero R] — the minimal structure that supports the operations actually used (multiplication, and inverses of non-zero elements, with no zero divisors). It is deliberately not [Field R]: addition and distributivity are never used, and demanding them would over-constrain the transition groupoid. GroupWithZero is one of the generic-R markers §7c recognises alongside CommRing/Field.

    Note it cannot be stated over R_q = ℤ[q, q⁻¹] (the ground ring of the sibling QOU.LiftingDescent.CosimplicialCrossedGroupoid) as written: R_q is a CommRing whose non-monomial elements are not invertible, so g_ik⁻¹ has no meaning there. Unifying the two would first require restating the deviation as a division-free multiplicative relation, or moving to R_qˣ.

    Yekutieli triple at level n over Uᵢ ∩ Uⱼ. LaTeX: \label{def:yekutieli-triple}

    Requires only [Zero R]: the triple is data plus one non-degeneracy hypothesis (twoMorphisms p ≠ 0), and nothing in it multiplies or inverts. Kept deliberately at that minimum so rings without total inverses can instantiate it — in particular R_q = ℤ[q, q⁻¹], which QOU.LiftingDescent.CosimplicialCrossedGroupoid builds its cosimplicial tower over. The inverse-using constructions below ask for GroupWithZero separately, so the weaker structure is not weakened for them.
