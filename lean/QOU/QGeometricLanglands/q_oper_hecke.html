    QOU.QGeometricLanglands.q_oper_hecke — conjectural class (§3b) #

    §3b class axiomatisation for content block conj:q-oper-hecke: $q$-Opers are $q$-Hecke eigensheaves.

    This is a conjecture: the class carries the conjecture's actual content as the oper_irreducible field (every $q$-oper determines an irreducible $q$-Hecke eigensheaf); the noncomputable instance's sorry represents the open conjecture itself (per AGENTS.md §3b), NOT a missing proof.

    Mathlib carries no geometric-Langlands / $q$-$\mathcal{D}$-module machinery, so $q$-opers and eigensheaves are abstracted as class parameters and the irreducibility relation is the asserted content.

    class QOU.QGeometricLanglands.q_oper_hecke :
    Type 1

    $q$-Opers are $q$-Hecke eigensheaves.

    Conjectural class — see conj:q-oper-hecke.

    • QOper : Type

      $q$-Opers $(\mathcal{P}_{\check G_q}, \nabla_q)$ on $X$.

    • Eigensheaf : Type

      $q$-Hecke eigensheaves on $\mathrm{Bun}_{G_q}(X)$.

    • toEigensheaf : QOper → Eigensheaf

      The $q$-GL assignment $\nabla_q \mapsto \mathcal{M}_{\nabla_q} = \mathbb{L}_q^{-1}(\delta_{\nabla_q})$.

    • IsIrreducible : Eigensheaf → Prop

      Irreducibility as a $q$-$\mathcal{D}$-module.

    • oper_irreducible (op : QOper) : IsIrreducible (toEigensheaf op)

      The conjecture: every $q$-oper determines a $q$-Hecke eigensheaf, and the $q$-oper (Borel-transversality) condition makes that eigensheaf irreducible.
