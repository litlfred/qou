    QOU.QGeometricLanglands.q_gl_classical_limit — conjectural class (§3b) #

    §3b class axiomatisation for content block conj:q-gl-classical-limit: The $q \to 1$ limit recovers classical (Beilinson–Drinfeld) Geometric Langlands.

    This is a conjecture: the class carries the conjecture's actual content as the three-leg degeneration fields, and no instance is supplied — the absent instance is the open conjecture (AGENTS.md §3b-tax), NOT a missing proof. (An earlier revision discharged it with an axiom + global instance; see the history note at the foot of this file.)

    The degeneration of categories is abstracted; the one leg that is concretely statable — the Hecke-relation degeneration — is encoded faithfully ($q$-Hecke eigenvalues at $q = 1$ collapse to $\pm 1$, the symmetric-group eigenvalues), alongside the differential and dual-group legs as the remaining conjectural inputs.

    Base ring (AGENTS.md §7c). The eigenvalue-degeneration leg is purely algebraic: it uses only the literals 1 and -1, no ordering, no radical, no Real.*. The class is therefore stated over a generic {R : Type*} [Ring R] — Ring being the weakest idiomatic class carrying both One and Neg — and never mentions ℝ. Hecke eigenvalues live in $\mathbb{Z}[q, q^{-1}]$, not in the archimedean completion; an archimedean evaluation is the instantiation R := ℝ, which belongs on the observation side of the substrate→archimedean wall.

    class QOU.QGeometricLanglands.q_gl_classical_limit (R : Type u_1) [Ring R] :
    Type u_1

    Classical limit $q \to 1$ of the $q$-Langlands correspondence.

    Conjectural class — see conj:q-gl-classical-limit.

    • heckeEigenvalue : R → R → Prop

      heckeEigenvalue q T — T is a $q$-Hecke eigenvalue at parameter q, i.e. a root of $(T - q)(T + q^{-1}) = 0$. Carried abstractly: the defining relation needs q invertible, which a generic Ring does not supply, so the predicate is a class field rather than a definition.

    • hecke_limit (T : R) : heckeEigenvalue 1 T → T = 1 ∨ T = -1

      Conjecture, Hecke leg: at $q = 1$ the $q$-Hecke relation $(T - q)(T + q^{-1}) = 0$ degenerates to $(T - 1)(T + 1) = 0$, so every limiting eigenvalue is $\pm 1$ (the symmetric-group action).

    • differential_limit : Prop

      Conjecture, differential leg: $d_q^2 \to 0$ as $q \to 1$, so $q$-flat connections become flat connections.

    • dual_group_limit : Prop

      Conjecture, dual-group leg: $\check G_q \to \check G$ as the quantum deformation is removed.

    • recovers_classical : differential_limit R ∧ dual_group_limit R

      The remaining two legs hold jointly (with the Hecke leg above), recovering $\mathbb{L}_{\mathrm{BD}}$.
