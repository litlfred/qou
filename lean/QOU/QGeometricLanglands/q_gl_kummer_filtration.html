    QOU.QGeometricLanglands.q_gl_kummer_filtration — conjectural class (§3b) #

    §3b class axiomatisation for content block conj:q-gl-kummer-filtration: Kummer-tower filtration of the moduli of $q$-local systems.

    This is a conjecture: the class carries the conjecture's actual content as the level1_all and lifts_iff_divides fields; the noncomputable instance's sorry represents the open conjecture itself (per AGENTS.md §3b), NOT a missing proof.

    The moduli of $q$-local systems is abstracted as a class parameter; the two substantive claims encoded are (1) the level-1 sublocus is everything, and (3) the level-$n$ sublocus lifts through the brane tower iff $n \mid \chi(A)$.

    class QOU.QGeometricLanglands.q_gl_kummer_filtration :
    Type 1

    Kummer-tower filtration of $\mathrm{LocSys}_{\check G_q}(X)$.

    Conjectural class — see conj:q-gl-kummer-filtration.

    • LocSys : Type

      Moduli of $q$-local systems $\mathrm{LocSys}_{\check G_q}(X)$.

    • inLevel : ℕ → LocSys → Prop

      Membership in the level-$n$ sublocus $\mathrm{LocSys}^{(n)} \subseteq \mathrm{LocSys}$ ($n$-divisible $q$-monodromy).

    • liftsThroughTower : ℕ → Prop

      Whether the level-$n$ sublocus admits lifts through the brane tower.

    • chiA : ℤ

      The Euler characteristic $\chi(A)$ governing the lifting obstruction.

    • level1_all (L : LocSys) : inLevel 1 L

      Conjecture, part 1: the level-1 sublocus is all $q$-local systems.

    • lifts_iff_divides (n : ℕ) : 1 ≤ n → (liftsThroughTower n ↔ ↑n ∣ chiA)

      Conjecture, part 3: the level-$n$ sublocus lifts through the brane tower iff $n \mid \chi(A)$ (perpetual obstruction otherwise).
