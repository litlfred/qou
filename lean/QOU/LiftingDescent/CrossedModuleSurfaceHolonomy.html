    In a crossed module the 2-holonomy is its boundary 1-holonomy up to a central element #

    Check C1 of the 2026-09-05 binding-gap survey (route D's first prune, bean qou-20bk). The survey's §4.4 guessed that Yekutieli's 2-dimensional multiplicative integral is "structurally pair-local" because every kite is tethered to the basepoint. Read against the held text (library/arxiv-1007.1250v4, Def. 4.1.1, 4.3.3, 4.4.16; Thm 0.4.2 and 0.9.1), the tether is a gauge choice; the mechanism is the 2-dimensional Stokes theorem: for a connection–curvature pair (fake-flat), Φ(MI(α,β|σ,τ)) = MI(α|∂(σ,τ)) — the surface holonomy h ∈ H maps under the feedback Φ : H → G to the boundary path holonomy g ∈ G.

    This file records the group-theoretic core, which needs nothing from geometry: in a crossed module (G, H, Φ, Ψ) the kernel of the feedback is central in H (a consequence of the Peiffer identity), so any two elements of H with the same image under Φ differ by a central element. Read back into the geometry:

    • the non-abelian content of a 2-holonomy is entirely its boundary 1-holonomy — a path-ordered product, i.e. word/ordering data, the degree-0 class the survey's §7b–7d already characterised;
    • everything beyond it lives in ker Φ (Yekutieli's inertia subgroup H₀), which is abelian and central — and the 3-dimensional Stokes theorem (Thm 8.6.6) says that on the boundary of a balloon this remainder is the abelian integral of the inert 3-curvature γ.

    So no 2-dimensional Yekutieli object carries a non-abelian many-body term beyond word ordering, and the only 3-body-shaped object in the book is the abelian volume term ∫γ over a 3-cell — which is additive over 3-cells (extensive), exactly the "super-pairwise additive extensive object" the Δ_λ audit asks for, if γ ≠ 0 for the framework's connection. That last condition cannot be evaluated: the framework's Step-2 curvature is stipulated, not a form (cheat-sheet §2a). Recorded in the survey §7e; this file proves only the algebra.

    Base ring §7c: none — pure group theory over arbitrary Group G, Group H.

    structure QOU.LiftingDescent.CrossedModuleSurfaceHolonomy.CrossedModule (G : Type u_1) (H : Type u_2) [Group G] [Group H] :
    Type (max u_1 u_2)

    A crossed module (G, H, Φ, Ψ): a group homomorphism Φ : H → G (the feedback), an action Ψ of G on H by automorphisms (the twisting), such that Φ is G-equivariant and the Peiffer identity Ψ(Φ h) h' = h h' h⁻¹ holds.

    • Φ : H →* G

      The feedback Φ : H → G.

    • Ψ : G →* MulAut H

      The twisting Ψ : G → Aut(H).

    • equivariant (g : G) (h : H) : self.Φ ((self.Ψ g) h) = g * self.Φ h * g⁻¹

      Φ is G-equivariant for the conjugation action on G.

    • peiffer (h h' : H) : (self.Ψ (self.Φ h)) h' = h * h' * h⁻¹

      The Peiffer identity Ψ(Φ h) = Ad_H(h).

      theorem QOU.LiftingDescent.CrossedModuleSurfaceHolonomy.classFn_factors_through_feedback {G : Type u_1} {H : Type u_2} [Group G] [Group H] (C : CrossedModule G H) {R : Type u_3} (f : H → R) (hf : ∀ z ∈ Subgroup.center H, ∀ (h : H), f (z * h) = f h) {h h' : H} (hΦ : C.Φ h = C.Φ h') :
      f h = f h'

      Consequence for any conjugation-invariant reading. A class function f : H → R (one that cannot see conjugation) evaluated on a surface holonomy is determined by the boundary path holonomy only through the central factor: if f is also invariant under multiplication by central elements, then f is a function of Φ h alone. This is the precise sense in which a 2-dimensional multiplicative integral carries no non-abelian content beyond its boundary.
