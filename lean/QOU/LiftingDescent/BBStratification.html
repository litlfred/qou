    QOU.LiftingDescent.BBStratification — abstract BB-stratification + spectral sequence #

    Provides Mathlib-grounded abstract infrastructure for the Białynicki–Birula (BB) stratification of the Hecke category and the resulting spectral sequence used by conj:homological-shell-condensation.

    The actual BB-stratification of a Hecke variety is a substantial algebraic-geometry object beyond Mathlib's current scope. This module supplies:

    1. An abstract BBStratification typeclass capturing the filtration data (a poset of strata, refinement maps, residue maps).
    2. An abstract SpectralSequence typeclass with E_r^{p, q} pages, differentials d_r, and convergence to a target cohomology.
    3. A connecting BBSpectralSequence typeclass tying the two together.
    4. Concrete consequences: e.g., if the stratification has finite length, the spectral sequence collapses at finite page; if all higher differentials vanish, E_∞ equals the E_r we stopped at.

    These abstractions plug into the existing InfinityVanishesAtPositiveQ predicate of HomologicalCondensation.lean, giving a more substantive Mathlib grounding for the homological-shell-condensation conjecture.

    LaTeX label: conj:homological-shell-condensation (BB-stratification infrastructure).

    §1 Abstract BB-stratification #

    source
    structure QOU.LiftingDescent.BBStratification.BBStratification (n : ℕ) :
    Type 1

    A Białynicki–Birula stratification at strand count n: abstractly, a finite filtration of the Hecke category indexed by partitions λ ⊢ n (or some other poset), with each stratum X_λ a locally closed subvariety carrying its Hoefsmit cell.

    For our framework we expose only the structural data:

    • Index: the indexing poset (typically partitions of n).
    • length: the length of the filtration (≤ #partitions of n).
    • refines: the partial order on strata.
    • is_complete_intersection: predicate identifying strata that satisfy the complete-intersection property — these are the "magic" strata where obstruction classes vanish.
    • Index : Type

      Indexing poset of the filtration (partitions of n, or a poset abstraction thereof).

    • length : ℕ

      The length of the filtration.

    • refines : self.Index → self.Index → Prop

      Partial order on strata.

    • is_complete_intersection : self.Index → Prop

      Predicate: stratum λ has the complete-intersection property (= no obstruction to lifting the section across higher jets).

    • refines_refl (i : self.Index) : self.refines i i

      Refinement is reflexive.

    • refines_trans (i j k : self.Index) : self.refines i j → self.refines j k → self.refines i k

      Refinement is transitive.

        §2 Abstract spectral sequence #

        source
        structure QOU.LiftingDescent.BBStratification.SpectralSequence :
        Type

        An abstract bigraded spectral sequence with pages E_r^{p, q} for r ≥ 2. We track only the structural facts needed for the framework:

        • Pages indexed by (r, p, q) ∈ ℕ × ℕ × ℕ.
        • Each page has a real-valued "size" (= dimension or norm of the cohomology class at that bidegree).
        • Differentials d_r : E_r^{p, q} → E_r^{p + r, q - r + 1} — we expose them via the resulting page-(r+1) sizes.
        • A convergence target E_∞^{p, q}.
        • size : ℕ → ℕ → ℕ → ℝ

          Size at page r, position (p, q), of the cohomology.

        • converges (p q : ℕ) : ∃ (r₀ : ℕ), ∀ (r : ℕ), r₀ ≤ r → self.size r p q = self.size r₀ p q

          Convergence: there exists r₀ such that for all r ≥ r₀, size r p q = size r₀ p q.

        • size_nonneg (r p q : ℕ) : 0 ≤ self.size r p q

          Sizes are non-negative.

                §3 BB-spectral-sequence connection #

                source
                structure QOU.LiftingDescent.BBStratification.BBSpectralSequence (n : ℕ) :
                Type 1

                A BB spectral sequence ties a BB-stratification to a spectral sequence such that the stratum-collapse condition (all strata are complete intersections) implies the spectral sequence vanishes in positive q-degree.

                This abstracts the relationship in conj:homological-shell-condensation: if every BB-stratum of the Hecke category at strand count n satisfies the complete-intersection property, then no obstruction classes survive in higher cohomology.

                • stratification : BBStratification n
                • spectralSequence : SpectralSequence
                • collapse_when_all_complete : (∀ (i : self.stratification.Index), self.stratification.is_complete_intersection i) → self.spectralSequence.vanishesInPositiveQ

                  Collapse condition: if every stratum is a complete intersection, then E_∞^{p, q > 0} = 0.

                  §4 Bridge to the framework conjecture #

                  source
                  class QOU.LiftingDescent.BBStratification.BBSpectralSequenceProvider :
                  Type 1

                  The framework's InfinityVanishesAtPositiveQ predicate (from HomologicalCondensation.lean) is exactly SpectralSequence.vanishesInPositiveQ for the spectral sequence built from the BB-stratification.

                  This bridge is exposed as an abstract typeclass: concrete instances supply the BB-spectral-sequence at each strand count n, and the predicate aligns.

                  • bbSeq (n : ℕ) (q : ℝ) : BBSpectralSequence n

                    The BB-spectral sequence at strand count n and substrate parameter q.

                  • bridge (n : ℕ) (q : ℝ) : (bbSeq n q).spectralSequence.vanishesInPositiveQ ↔ HomologicalCondensation.InfinityVanishesAtPositiveQ n

                    Bridge: the framework's condensation predicate aligns with the spectral sequence's positive-q-vanishing predicate.

                    Formally: at each (n, q), the spectral sequence built from the BB-stratification vanishes in positive q-degree iff the framework predicate InfinityVanishesAtPositiveQ n holds. Concrete instances supply the equivalence.
