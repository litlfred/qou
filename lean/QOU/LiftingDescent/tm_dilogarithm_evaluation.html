    QOU.LiftingDescent.tm_dilogarithm_evaluation #

    Lemma (lem:topological-mass-dilogarithm).

    Each exceptional-divisor summand evaluates to the quantum dilogarithm:

    ‖ MI∫_{E_i} (∇_A q, L ∧ F⁺) ‖ = Φ_q(z_i) = ∫₀^{z_i} ln_q(1+t)/t dt,

    in the spectral coordinates of the Briggs–Klein chart at E_i.

    Structure (hypothesis vs. derivation) #

    The .md displays a chain of two equalities.

    • The second equality — Φ_q(z) = ∫₀^{z} ln_q(1+t)/t dt — is realised definitionally: Phi_q is defined below as a genuine Mathlib interval integral of the q-logarithm integrand, and the representation is recorded as the proved lemma phi_q_integral_representation. Φ_q is no longer an opaque constant; only the q-logarithm ln_q itself remains opaque (its q-series theory is not in Mathlib).
    • The first equality — the Briggs–Klein chart evaluation of the multiplicative-integral norm to that integral — is the genuine open analytic input (Yekutieli multiplicative integration + the Faddeev–Kashaev saddle evaluation), stated as the sub-lemma tm_divisor_chart_evaluation with an honest sorry + citations (AGENTS.md §1, §1a item 2).

    The main theorem derives the .md identity by chaining the sorried chart evaluation with the proved integral representation — it does not assume its conclusion (lean-proof-vacuity-audit fix recipe; AGENTS.md §3b-cond item 5).

    Base ring (§7c) #

    ℝ throughout: the statement is about an archimedean norm and a real interval integral (∫ … dt over the volume measure), which are archimedean constructs.

    MI is opaque, deliberately. An earlier revision defined it as the very integral that tm_divisor_chart_evaluation claims it equals, which made that "open analytic input" a rfl tautology — the Briggs-Klein chart evaluation was assumed by definition rather than stated. (It also created a forward reference, since the definition mentioned z/lnq before either was declared.) Bean qou-t4cv. Phi_q below is a genuine definition and its integral representation is honestly definitional, as its docstring says.
