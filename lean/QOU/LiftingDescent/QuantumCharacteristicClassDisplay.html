    structure QOU.QuantumCharacteristicClass :
    Type (u_1 + 1)

    A quantum characteristic class at level n: the obstruction to extending the gerbe from level n to level n+1.

    • level : ℕ

      Level in the brane tower.

    • ObstructionSpace : Type u_1

      The obstruction space (representing H²(𝒮, ℬ)).

    • addCommGroup : AddCommGroup self.ObstructionSpace

      The obstruction space is an additive abelian group.

    • kappa : self.ObstructionSpace

      The obstruction value κₙ ∈ H²(𝒮, ℬ).
