    QOU.LiftingDescent.HomologicalCondensation — magic-number condensation #

    The Białynicki–Birula filtration of the Hecke category builds a spectral sequence E_r^{p,q}(n) abutting to the twisted cohomology of the global mass endomorphism Φ_n. The conjecture below claims that the spectral sequence collapses with E_∞^{p, >0}(n) = 0 exactly on the magic ladder

    n ∈ {2, 8, 20, 28, 50, 82, 126}.

    Conjectural-propagation (AGENTS.md §3b): downstream of SaturatedShellConjecture, so the condensation claim itself is also axiomatised here.

    LaTeX label: conj:homological-shell-condensation

            §3 The condensation conjecture #

            class QOU.LiftingDescent.HomologicalCondensation.ShellCondensationConjecture :
            Prop

            Conjecture 2 — Homological shell condensation.

            The spectral sequence collapses with E_∞^{p, >0}(n) = 0 if and only if n is a magic number on the ladder {2, 8, 20, 28, 50, 82, 126}.

            The conjectural content is the iff: collapse occurs exactly on this ladder. Two routes for closing it are documented in the associated .md (combinatorial enumeration of complete-intersection BB-strata; Yekutieli MC-equation reduction).

            • collapse_iff_magic (n : ℕ) : InfinityVanishesAtPositiveQ n ↔ n ∈ magicLadder

              Both directions of the iff.

                  theorem QOU.LiftingDescent.HomologicalCondensation.shellCondensation_iff_perN_axioms_at (h_in : ∀ n ∈ magicLadder, IsKnownCondensed n) (h_out : ∀ (n : ℕ), 2 ≤ n → n ∉ magicLadder → IsKnownNotCondensed n) (n : ℕ) :
                  2 ≤ n → (InfinityVanishesAtPositiveQ n ↔ n ∈ magicLadder)

                  Assembly theorem. If for every n ≥ 2 we have either IsKnownCondensed n (when n ∈ magicLadder) or IsKnownNotCondensed n (when n ∉ magicLadder), then the ShellCondensationConjecture holds for n ≥ 2.

                  The n ≥ 2 restriction handles the edge cases:

                  • n = 0 (vacuum): no jet prolongations, so condensation holds trivially — but 0 ∉ magicLadder, so the iff form fails.
                  • n = 1 (single strand): similarly, no inter-strand jets, so condensation holds trivially.

                  Both edge cases are vacuously condensed without being magic; the conjecture is only meaningful for n ≥ 2.
