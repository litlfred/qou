    Jet prolongation chain — descent involution + transient/descended decomposition #

    The brane tower of a quantum observable universe ascends through the jet prolongation J¹(A) = A ⊗ Ω¹(A) (see prop:jet-prolongation in lifting-and-descent/jet-prolongation.lean). At each level n we have:

    • Ascent embedding ℓ_n : A_n ↪ A_{n+1} (the unit section composed with the prolongation; prop:jet-prolongation).
    • Descent retraction 𝔡_{n+1} : End_C(A_{n+1}) → End_C(A_n) (lem:descent); satisfies 𝔡_{n+1} ∘ ℓ_n = id on End_C(A_n).
    • Descent involution τ̂_n = ℓ_n ∘ 𝔡_{n+1} : End_C(A_{n+1}) → End_C(A_{n+1}), an idempotent: τ̂_n² = τ̂_n.

    Because τ̂_n is idempotent, the level-(n+1) endomorphism algebra splits as the direct sum

    `End_C(A_{n+1}) = 𝒜_{n+1}^{desc} ⊕ 𝒜_{n+1}^{trans}`

    where:

    • 𝒜_{n+1}^{desc} = im τ̂_n is the descended subalgebra (endomorphisms factoring through level n via ℓ_n).
    • 𝒜_{n+1}^{trans} = ker τ̂_n is the transient subalgebra (the new modes appearing at level n+1).

    This decomposition is the categorical scaffold for:

    • The per-level mass tower (prop:per-braid-mass-tower): the descended part contributes only at base level (prop:descended-level-zero); the transient part carries the new contribution at each ascension step.
    • R7 inter-level pentagon ascension (prop:pentagon-uv-commutation, post-PR-501 reformulation): the q-graded operator-lift identity uv = q·vu modulo R_q ∈ im τ̂_n lives on B_λ^{(n+1)}_trans and is the bridge from level n to level n+1.

    This file lays out the structural Lean infrastructure as a typeclass that downstream theorems can hypothesise against. Substantive construction of concrete instances (e.g. for the QOU substrate's H_n(q) chain) is left to follow-up branches; the typeclass framework lets the inter-level pentagon lift be stated and the per-level brane tower's transient/descended decomposition be referenced uniformly.

    class QOU.LiftingDescent.JetChain (R : Type u) [CommRing R] (EndAlg : ℕ → Type v) [(n : ℕ) → AddCommGroup (EndAlg n)] [(n : ℕ) → Module R (EndAlg n)] :
    Type v

    Jet prolongation chain at a given category C over a base ring R: an indexed family A_n : ℕ → C with ascent embeddings ℓ_n : A_n ⟶ A_{n+1} and descent retractions 𝔡_{n+1} : End(A_{n+1}) →ₗ[R] End(A_n) satisfying the retraction identity 𝔡_{n+1} ∘ post(ℓ_n) = id (descending an ascended endomorphism recovers it).

    The "endomorphism algebra at level n" is parameterised by an abstract R-module EndAlg n; the descent retraction is a linear map between these. Concretely (e.g. for the Hecke chain) EndAlg n would be the algebra End_C(A_n); here we keep it abstract so the typeclass is reusable for both the categorical brane tower and the algebraic Hecke-chain instantiation.

    Per AGENTS.md §3b, this is a structural typeclass; substantive proofs at instances are deferred until concrete chains are wired up. The fields encode the algebraic content of the chain (idempotent decomposition, retraction identity); category-level content (objects, morphisms) lives in lifting-and-descent/jet-prolongation.lean.

    • ascent (n : ℕ) : EndAlg n →ₗ[R] EndAlg (n + 1)

      Ascent at level n: post-composition by ℓ_n lifts an endomorphism at level n to one at level n+1.

    • descent (n : ℕ) : EndAlg (n + 1) →ₗ[R] EndAlg n

      Descent retraction at level n+1.

    • descent_ascent (n : ℕ) (x : EndAlg n) : (descent n) ((ascent n) x) = x

      Retraction identity: descending an ascended endomorphism recovers it. Equivalent to ℓ_n embedding A_n as a direct summand of A_{n+1} (Frobenius non-degeneracy).

                class QOU.LiftingDescent.JetChain.InterLevelLift (R : Type u) [CommRing R] (EndAlg : ℕ → Type v) [(n : ℕ) → AddCommGroup (EndAlg n)] [(n : ℕ) → Module R (EndAlg n)] [(n : ℕ) → Mul (EndAlg n)] (q : R) extends QOU.LiftingDescent.JetChain R EndAlg :
                Type v

                Inter-level pentagon ascension — operator-lift typeclass + substantive theorem.

                For a triple (i, j, k) of braid-generator indices and the operator-lift Ũ_ℓ : EndAlg n →ₗ[R] EndAlg (n+1) carrying the quantum-torus structure, the level-internal product u = Ũ_i Ũ_j and v = Ũ_k satisfy u · v = q · v · u + R_q where R_q ∈ im τ̂_n is the descended residual (i.e., is fixed by the descent involution).

                This is prop:pentagon-uv-commutation's inter-level lift content. The level-internal version (single jet level n) is plain commutativity in the scalar trace ring; see QOU.BraidKnot.VhatPairCommutationTrace.

                The typeclass InterLevelLift packages the operator lift Ũ_ℓ together with the q-graded commutation identity as fields. A concrete instance for the Hecke chain awaits the substantive brane-tower / H_n(q) → H_{n+1}(q) quantum-torus implementation, but downstream theorems can already be stated and proved conditionally on InterLevelLift — making this typeclass the clean assumption point.

                • ascent (n : ℕ) : EndAlg n →ₗ[R] EndAlg (n + 1)
                • descent (n : ℕ) : EndAlg (n + 1) →ₗ[R] EndAlg n
                • descent_ascent (n : ℕ) (x : EndAlg n) : (descent n) ((ascent n) x) = x
                • liftOperator (n : ℕ) : Hecke.Generator n → EndAlg n →ₗ[R] EndAlg (n + 1)

                  Per-jet-level operator lift Ũ_ℓ : EndAlg n → EndAlg (n+1), one for each braid-generator index ℓ : Generator n.

                • q_graded_commutation (n : ℕ) (i j k : Hecke.Generator n) (x : EndAlg n) : ∃ (R_q : EndAlg (n + 1)), descendedPart n R_q = R_q ∧ (liftOperator q n i) x * (liftOperator q n j) x * (liftOperator q n k) x = q • ((liftOperator q n k) x * ((liftOperator q n i) x * (liftOperator q n j) x)) + R_q

                  The q-graded inter-level commutation identity. For i, j, k : Generator n (necessarily i < j < k for non-trivial ordering), the operator-lift product u = Ũ_i ∘ Ũ_j (composition lifted to End_C(A_{n+1})) v = Ũ_k satisfies u · v = q · v · u + R_q, where R_q ∈ im τ̂_n (i.e. is fixed by the descent involution).

                  This is the Step-3-and-4 content of prop:pentagon-uv-commutation's narrative derivation: braid relation + Hecke quadratic + descent splitting on the q-eigenblock.

                  Stated as the existence of R_q with the divisibility-by-descent property so that any concrete instance only needs to exhibit the operator-lift action and verify the residual is descended.
