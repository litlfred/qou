    Trivial witness for MotivicGaloisCharacter #

    A minimal MotivicGaloisCharacter ℤ ℤ trivialTarget (motiveA := 1) instance with frobenius_at p := (p : ℤ). The instance witnesses inhabitability — for any prime p ≥ 2, (p : ℤ) is not a unit in ℤ (the only units are ±1).

    The perpetual obstruction (non-unitality at almost every prime) is now a standalone theorem in MotivicPerpetualObstructionFromTrace.lean, not a class field obligation.

    This is not the QOU motivic Galois character at q₀. The principal open item is GAP 6a in the 2026-05-02 forward-derivation audit; see 2026-05-04 GAP 6a + 18a scoping for the outstanding work.
