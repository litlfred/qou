    QOU.LiftingDescent.CosimplicialCrossedGroupoid #

    The recursive brane tower carries a cosimplicial object in the category of crossed groupoids: coface maps from jet prolongation, codegeneracy maps from descent, and the crossed structure from conjugation of 1-morphisms on 2-morphisms via the adjoint representation of SU_q(2).

    Pre-Archimedean (formal-chain) version. Lives under lean/QOU/ and is compiled by lake build. The co-located documentation stub at lifting-and-descent/cosimplicial-crossed-groupoid.lean mirrors this content.

    Ground ring: R_q = ℤ[q, q⁻¹] (Laurent polynomials over ℤ).

    LaTeX label: prop:cosimplicial-crossed-groupoid

          Type u_1

          A Yekutieli triple at level n over a manifold M: the datum (x, g, a) of local trivialisations, transition automorphisms, and deformation parameters.

          De-duplicated (bean qou-s82c). This module used to declare its own copy of this structure, byte-identical to QOU.Torsion.YekutieliTriple except for the coefficient ring. It is now that structure instantiated at this module's ground ring R_q = ℤ[q, q⁻¹] — one definition, two rings, instead of two definitions that could drift apart. The generic structure asks only for [Zero R] precisely so a CommRing without total inverses can instantiate it.

            structure QOU.LiftingDescent.CrossedModule :
            Type 1

            A crossed module in the sense of Yekutieli [yekutieli2010]: a pair of (possibly non-abelian) groups N, G, a boundary homomorphism ∂ : N → G, and a conjugation action of G on N satisfying the Peiffer identity ∂(g · n) = g · ∂n · g⁻¹.

            Note: the formal-chain layer keeps the carriers polymorphic rather than fixing them to R_q; the commutative ring R_q enters only through the image of ∂ when an instance is realised over the deformation parameter. Cf. gemini-code-assist review on PR #535.

            • N : Type
            • G : Type
            • grpN : Group self.N
            • grpG : Group self.G
            • boundary : self.N → self.G
            • action : self.G → self.N → self.N
            • peiffer (g : self.G) (n : self.N) : self.boundary (self.action g n) = g * self.boundary n * g⁻¹
