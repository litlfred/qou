    QOU.LiftingDescent.ccg_crossed_module_structure — (SU_{q_n}(2), 𝓞_M^×) crossed module #

    Lemma (lem:ccg-crossed-module-structure).

    At each level n, the pair (SU_{q_n}(2), 𝓞_M^×) is a crossed module in the sense of Yekutieli (2010), with boundary ∂(a) = a · 𝟙 and conjugation action g · a = g a g⁻¹.

    The Lean encoding records the crossed-module axioms (Peiffer identity + boundary compatibility) as fields of an abstract CrossedModuleContext.

    -- Ref: [manuscript] quantum-observable-universe/lifting-and-descent/ccg-crossed-module-structure.md -- Ref: [yekutieli2010] A. Yekutieli, Nonabelian Multiplicative Integration, 2010

    class QOU.LiftingDescent.CrossedModuleContext :
    Type 1

    Abstract crossed-module context for (SU_{q_n}(2), 𝓞_M^×).

    • G_n : Type

      The base group G_n = SU_{q_n}(2).

    • H : Type

      The fibre group H = 𝓞_M^×.

    • mul_G : G_n → G_n → G_n

      Group operation on G_n.

    • inv_G : G_n → G_n
    • one_G : G_n
    • mul_H : H → H → H

      Group operation on H.

    • inv_H : H → H
    • one_H : H
    • boundary : H → G_n

      The boundary map ∂ : H → G_n.

    • action : G_n → H → H

      The conjugation action G_n ⊗ H → H.

    • embed : H → G_n

      Embed map from H to G_n.

    • boundary_def (a : H) : boundary a = embed a

      Boundary is just the embed map.

    • embed_mul (a b : H) : embed (mul_H a b) = mul_G (embed a) (embed b)

      Embed is a homomorphism.

    • embed_inv (a : H) : embed (inv_H a) = inv_G (embed a)
    • action_def (g : G_n) (a : H) : embed (action g a) = mul_G (mul_G g (embed a)) (inv_G g)

      Action is conjugation in G_n.

    • embed_inj (a b : H) : embed a = embed b → a = b

      Embed is injective.
