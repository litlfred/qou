    The motivic character does not vanish at places not dividing χ(A) #

    This file formalises the final step of the sketch of thm:motivic-perpetual-obstruction, in the sketch's own words:

    the Euler class projects to a Frobenius character whose trace equals χ(A) mod p. Because p ∤ χ(A), this trace is non-zero modulo p. The character is non-trivial.

    Why this file exists: the block and its Lean were measuring different propositions. The block's conclusion is that the character is non-trivial at p — its local trace does not vanish. Every Lean declaration previously attached to the block concludes instead that the Frobenius is not a unit (motivic_perpetual_obstruction, motivic_perpetual_obstruction_frobenius, habiro_frobenius_not_unit). Non-vanishing and non-unitness are different properties, and over a field they point in opposite directions: a unit is precisely a nonzero element.

    That distinction is what makes the arithmetic here work where bean qou-lrnd's route did not. qou-lrnd established — scope-(b), with the invariant exhibited — that a congruence to a fixed constant C can yield non-unitness only at the finitely many primes dividing C, "the complement of what perpetual means"; HabiroCollapse.isUnit_four_zmod is that obstruction in Lean. That refutation is untouched, and this file does not reopen it. What it does is observe that the same fact settles the block's actual claim affirmatively: IsUnit in ZMod p implies ≠ 0, so exactly where the non-unit reading fails, the non-vanishing reading succeeds — and it succeeds in the "perpetual" shape, at every prime above |χ(A)|.

    What is proved and what is assumed (§3b-cond). The two substantive links of the sketch are carried as hypothesis fields of MotivicResidueRealization, not proved:

    • chi, the Euler characteristic χ(A), identified with tr(κ₀) via thm:qu-to-qou — consumed as a datum;
    • residue_eq_chi, that the local Frobenius trace reduces to χ(A) mod p under the realization ρ_p — the sketch's own "trace equals χ(A) mod p".

    Everything below is derived from those: the class carries no non-vanishing field, and residue_eq_zero_iff_dvd is genuine arithmetic (ZMod.intCast_zmod_eq_zero_iff_dvd), not a projection. Proving residue_eq_chi itself is open and is not attempted here.

    Ref: [yekutieli2010] — obstruction theory LaTeX label: thm:motivic-perpetual-obstruction (sketch, final step)

    class QOU.LiftingDescent.MotivicResidueRealization :
    Type

    §3b-cond context for the sketch's mod-p step.

    Fields are the inputs of the sketch, never its conclusion. There is deliberately no non-vanishing field: that is derived below.

    • chi : ℤ

      The Euler characteristic χ(A), i.e. tr(κ₀) via thm:qu-to-qou.

    • residue (p : Nat.Primes) : ZMod ↑p

      The trace of the local Frobenius character χ^mot_{A,p} after realization ρ_p, living in the residue ring at p.

    • residue_eq_chi (p : Nat.Primes) : residue p = ↑chi

      INPUT — the sketch's own step: "a Frobenius character whose trace equals χ(A) mod p". This is the substantive content and is a hypothesis, not a theorem.

      The obstruction is perpetual: every prime above |χ(A)| is a non-vanishing place.

      This is the "almost every finite place" shape the block claims, made quantitative. A prime at which the residue vanishes must divide the nonzero integer χ(A), hence is bounded by |χ(A)|; so the exceptional set is contained in the finitely many primes up to that bound.

      def QOU.LiftingDescent.protonResidueRealization :
      MotivicResidueRealization

      A concrete realization, so nothing above is vacuous.

      χ(A) = 8 is the QOU proton collapse constant a₀(-1) + 2·a₁(-1) as measured from habiro-coefficients-atomic.witness.json (a₀ = 8 identically, a₁(-1) = 0) — the value bean qou-lrnd corrected the corpus's 4 to on 2026-08-23. Under it the vanishing locus is p = 2 alone, so the character is non-trivial at every odd prime.

      Deliberately a def, not an instance. As an instance it would be found by typeclass resolution for every downstream [MotivicResidueRealization] hypothesis, silently discharging the very assumption this file exists to keep visible. It witnesses inhabitation and derives no physics.
