    QOU.LiftingDescent.ccg_cosimplicial_identities — cosimplicial identities #

    Definition (def:ccg-cosimplicial-identities).

    The coface maps δⁱ (composites of jet prolongation with Čech face maps) and codegeneracy maps σⁱ (composites of descent with Čech degeneracy maps) satisfy the cosimplicial identities

      δʲ ∘ δⁱ = δⁱ ∘ δ^{j−1}    (i < j)
  σʲ ∘ σⁱ = σⁱ ∘ σ^{j+1}    (i ≤ j)

    plus the mixed identities, each case reducing to disjoint-support commutation or to the retraction 𝔡_{n+1} ∘ ℓ_n = id.

    The Lean encoding records the four identities as a Prop-valued conjunction against an abstract CcgCosimplicialIdentitiesContext.

    class QOU.LiftingDescent.CcgCosimplicialIdentitiesContext :
    Type 1

    Abstract context for the cosimplicial identities.

    • Obj : ℕ → Type

      The cosimplicial object at level n (abstract).

    • delta (n i : ℕ) : Obj n → Obj (n + 1)

      Coface map δⁱ : Obj n → Obj (n+1).

    • sigma (n i : ℕ) : Obj (n + 1) → Obj n

      Codegeneracy map σⁱ : Obj (n+1) → Obj n.

    • cech_face (n i : ℕ) : Obj n → Obj (n + 1)

      Čech face map.

    • jet (n : ℕ) : Obj n → Obj n

      Jet prolongation map.

    • delta_def (n i : ℕ) (x : Obj n) : delta n i x = cech_face n i (jet n x)

      Coface map is composite of jet and Čech face.

    • cech_deg (n i : ℕ) : Obj (n + 1) → Obj n

      Čech degeneracy map.

    • descent (n : ℕ) : Obj n → Obj n

      Descent map.

    • sigma_def (n i : ℕ) (y : Obj (n + 1)) : sigma n i y = descent n (cech_deg n i y)

      Codegeneracy map is composite of descent and Čech degeneracy.

    • jet_face_comm (n i : ℕ) (x : Obj n) : jet (n + 1) (cech_face n i x) = cech_face n i (jet n x)

      Jet prolongation commutes with Čech face.

    • cech_face_comm (n i j : ℕ) (x : Obj n) : i < j → cech_face (n + 1) j (cech_face n i x) = cech_face (n + 1) i (cech_face n (j - 1) x)

      Čech face maps satisfy disjoint-support commutation.

    • descent_deg_comm (n i : ℕ) (y : Obj (n + 1)) : descent n (cech_deg n i y) = cech_deg n i (descent (n + 1) y)

      Descent commutes with Čech degeneracy.

    • cech_deg_comm (n i j : ℕ) (y : Obj (n + 1 + 1)) : i ≤ j → cech_deg n j (cech_deg (n + 1) i y) = cech_deg n i (cech_deg (n + 1) (j + 1) y)

      Čech degeneracy maps satisfy disjoint-support commutation.
