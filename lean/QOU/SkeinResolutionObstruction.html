    QOU.SkeinResolutionObstruction #

    Canonical declaration for content block at quantum-observable-universe/braids-and-knots/skein-resolution-obstruction.ts.

    Formalises the manuscript definition of the Skein resolution obstruction κ_c^comp(L,q) — the image of the universal obstruction class χ(A) ∈ HH² ≅ k under the resolution-tree restriction map (the fourth evaluation of χ(A); cf. thm:qou-obstruction-reduction).

    De-axiomatised (2026-07-06, bean 7kzn). The universal class is no longer a free field: it is cross-wired to the same QouObstructionReductionContext that qou_obstruction_reduction uses — octx.chi_A is the universal class. So this is literally the fourth evaluation of the one obstruction class, and the vanishing statements are derived through the shared context's kappa_vanishes_iff_chi.

    Repaired 2026-08-09. This file did not compile on main: it referenced three members that no version of QouObstructionReductionContext has — obstruction_class, obstruction_class_eq and kappa_vanishes_iff. A rename to chi_A / kappa_vanishes_def was never propagated here, and with the class field and the class-consumer in different files nothing caught it. Kept generic over the coefficient ring R (§7c: no archimedean construct is used).

    structure QOU.SkeinResolutionObstruction (R : Type u_1) [CommRing R] [octx : AlgebraicSubstrate.QouObstructionReductionContext] :
    Type u_1

    Data for the Skein resolution obstruction on a link L, over the shared QOU obstruction context.

    A definition carrier: the additive resolution-tree restriction map res (from HH² ≅ k = ℤ to the coefficient ring R) and the obstruction κ = res(χ(A)), where χ(A) = octx.chi_A is the canonical universal class carried by QouObstructionReductionContext.

    • res : ℤ →+ R

      The resolution-tree restriction map (additive), HH² ≅ ℤ → R.

    • κ : R

      The Skein resolution obstruction κ = res(χ(A)).

    • κ_def : self.κ = self.res AlgebraicSubstrate.QouObstructionReductionContext.chi_A

      κ is the restriction of the canonical universal obstruction class.
