    QOU.Conjectures.WeakSpectralCompleteness — EW cell-content trace #

    Conjectural axiomatisation of conj:weak-spectral-completeness (folio/quantum-observable-universe/mass-theory/weak-spectral-completeness.md).

    Over the categorical ring R with q generic, the EW/Higgs force-carrier sector {T(2,4), T(2,6), T(2,8)} ↔ {σ₁⁴, σ₃⁶, σ₅⁸} admits a categorically complete idempotent decomposition whose substrate-level structural quantity is the bar-self-dual cell-content trace

    tr_pure(σ₁⁴ σ₃⁶ σ₅⁸) = 4(q¹⁸+q⁻¹⁸) + 2(q¹⁰+q⁻¹⁰) + (q⁶+q⁻⁶) + 3(q²+q⁻²)

    derivable directly from the eight pure-pattern cell-content multiplicities (4, 2, 1, 3, 3, 1, 2, 4) (summing to 20), without invoking Plancherel weights.

    The substrate-level identity tr_pure is a concrete object: it is defined here over a generic field with q invertible, and its bar-self-duality (q ↦ q⁻¹ invariance) — the substrate-level bar T-duality at the trace level — is proved (cellTrace_bar_self_dual). The completeness multiplicity bookkeeping (4+2+1+3+3+1+2+4 = 20) is likewise discharged. The remaining open content (the categorical completeness of the idempotent decomposition itself) is carried by the content-bearing conjecture class with no instance.

        class QOU.Conjectures.WeakSpectralCompleteness (R : Type u_2) [Field R] :
        Type (u_3 + 1)

        Conjecture class (conj:weak-spectral-completeness).

        An instance supplies the six per-link block projectors e X ± of the EW carriers {T(2,4), T(2,6), T(2,8)} inside End_R(V^{⊗6}) and asserts that they form a categorically complete pairwise-orthogonal idempotent decomposition of the EW Wedderburn content. The completeness field carries the genuine completeness claim (the projectors are orthogonal idempotents exhausting the EW sector), not a bare True. This is a primary conjecture.

        • EWAlgebra : Type u_3

          The carrier algebra End_R(V^{⊗6}) of the n = 6 Hecke action.

        • ring_EWAlgebra : Ring (EWAlgebra R)

          EWAlgebra is a (possibly non-commutative) ring.

        • projector : Fin 6 → EWAlgebra R

          The six per-link block projectors e_W^±, e_Z^±, e_H^±.

        • completeness : (∀ (i : Fin 6), projector i * projector i = projector i) ∧ ∀ (i j : Fin 6), i ≠ j → projector i * projector j = 0

          Conjectural categorical completeness. Each projector is idempotent and distinct projectors are orthogonal — the pairwise-orthogonal idempotent decomposition exhausting the EW Wedderburn content.
