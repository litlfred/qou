    QOU.Conjectures.ShellTransitionKnot — magic numbers from shell transitions #

    Conjectural axiomatisation of conj:shell-transition-knot (folio/quantum-observable-universe/particle-interactions/shell-transition-knot.md).

    The seven stability pairs {2, 8, 20, 28, 50, 82, 126} arise from the 3-D harmonic-oscillator shell structure of nucleons in the nuclear mean field, corrected by the spin–orbit coupling of the Borromean baryon's three internal crossings.

    The harmonic-oscillator content is concrete and proved here: shell sizes s_N = (N+1)(N+2), cumulative closures C_N = (N+1)(N+2)(N+3)/3, and the uncorrected closure sequence {2, 8, 20, 40, 70, …} (which does not match observation — the gap the spin–orbit correction must close). The conjectural content (that the spin–orbit threshold set by the three Borromean crossings produces exactly the observed {2, 8, 20, 28, 50, 82, 126}) is carried by the content-bearing class with no instance.

    This is a dependent conjecture: it is conditional on conj:borromean-quark (the Borromean-baryon model that supplies the crossing count 3). The dependency is threaded through the type by the [BorromeanQuark] instance binder (AGENTS.md §3b-cond / §3b-tax).

        List.map hoClosure (List.range 7) = List.map (fun (N : ℕ) => (Finset.range (N + 1)).sum hoShellSize) (List.range 7)

            class QOU.Conjectures.ShellTransitionKnot [BorromeanQuark] :
            Type

            Conjecture class (conj:shell-transition-knot), conditional on [BorromeanQuark].

            An instance supplies the spin–orbit-corrected cumulative closure function correctedClosure and asserts that its first seven values reproduce the observed stability pairs {2, 8, 20, 28, 50, 82, 126} — with the shell-transition threshold set at N = 3 matching the three Borromean crossings (BorromeanQuark.crossingNumber).

            The field closures_match carries the conjecture's genuine content (the corrected closures equal the observed magic numbers), not a bare True. The [BorromeanQuark] binder makes this a dependent conjecture.

            • correctedClosure : ℕ → ℕ

              The spin–orbit-corrected cumulative shell closure at level N.

            • closures_match : List.map correctedClosure (List.range 7) = stabilityPairs

              Conjectural shell-transition identity. The corrected closures at levels 0..6 reproduce the seven observed stability pairs.
