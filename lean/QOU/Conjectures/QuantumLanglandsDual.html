    QOU.Conjectures.QuantumLanglandsDual — quantum Langlands duality (D19) #

    Conjectural axiomatisation of conj:quantum-langlands-dual (folio/quantum-observable-universe/q-geometric-langlands/quantum-langlands-dual.md).

    The Iwahori–Hecke algebra H_n(q) has a quantum Langlands dual H_n(q⁻¹) obtained by inverting the deformation parameter. For Type A_{n-1} (self-dual root datum) the dual algebra is isomorphic to the original at the algebra level, but the parameter inversion q ↦ q⁻¹ produces a non-trivial ℤ/2 duality, distinct from the bar involution (which acts on the generator action at fixed root data, not on the algebra structure).

    This is research-grade: the Langlands functor on H_n(q) is not in Mathlib, so the Hecke algebra and the dual functor are carried abstractly. The content that can be stated is the structural signature of the duality — a dual-parameter map dualParam together with its involutivity (dualParam ∘ dualParam = id, the ℤ/2 nature of q ↦ q⁻¹) — which is encoded as a genuine class field, not a bare True.

    The carrier is content-bearing and has no instance (honest open state).

    class QOU.Conjectures.QuantumLanglandsDual (R : Type u_2) [Field R] :
    Type (max u_2 (u_3 + 1))

    Conjecture class (conj:quantum-langlands-dual).

    An instance supplies the abstract Hecke-algebra family Hecke n q (carried abstractly — H_n(q) is not in Mathlib), the dual-parameter map dualParam (Langlands parameter inversion q ↦ q⁻¹), and a Langlands-dual algebra isomorphism langlandsDual identifying Hecke n q with Hecke n (dualParam q) for the self-dual Type-A root datum.

    Two content fields, not bare True:

    • dualParam_eq — the dual parameter is literally q⁻¹;
    • dualParam_involutive — the duality is a genuine ℤ/2 action (dualParam (dualParam q) = q for invertible q).

    This is a primary conjecture (no other conjecture class in its signature).

    • Hecke : ℕ → R → Type u_3

      The abstract Iwahori–Hecke algebra H_n(q) at strand count n and parameter q (carried abstractly; not in Mathlib).

    • dualParam : R → R

      The Langlands dual parameter map.

    • dualParam_eq (q : R) : dualParam q = q⁻¹

      The Langlands dual parameter is the inverse q ↦ q⁻¹.

    • dualParam_involutive (q : R) : q ≠ 0 → dualParam (dualParam q) = q

      ℤ/2 duality. The dual-parameter map is involutive on the invertible parameters: dualParam (dualParam q) = q.
