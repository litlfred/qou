    QOU Type Definitions — Proof Objects, Glossary, and Formalization Pipeline

    TypeScript type definitions replacing JSON schemas for the Quantum Observable Universe formalization pipeline. These types define the data structures for proof tracking, semantic glossary, narrative-to-Lean mapping, and proof state export.
