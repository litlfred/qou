descriptionBuilt wheels of qou's native Python extensions, today only pyhecke-native (not on PyPI; a maturin build takes about 2.5 min per container). One orphan branch per package, version, CPython tag, platform and source key, where the source key hashes the git trees of tools/pyhecke-native and tools/hecke-engine. Read and written by scripts/wheel-cache.sh, which keeps its git objects in a private bare repository rather than the checkout; scripts/build-pyhecke-native.sh restores before it builds by default, but seeds origin only when PYHECKE_NATIVE_PUSH=1 (and never when PYHECKE_NATIVE_NO_SEED=1), after a clean build passes its convention gate. wheel-cache/ is where a member is mounted; nothing is tracked there.
