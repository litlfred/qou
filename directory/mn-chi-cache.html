descriptionExact values of pyhecke_native.mn_chi_q(lambda, mu), the q-Murnaghan-Nakayama Hecke character table, stored so a sweep that needs a heavy table (n = 24, 27) computes each entry once. One orphan branch per engine source key; inside it, content-addressed JSONL shards of (lambda, mu) -> the producer's exact [q-degree, coefficient-string] pairs, never a float. Before 2026-11-22 this was the in-tree file computations/.derived-chi-mn-cache.json, keyed by (lambda, mu) alone, so an entry from one engine build was served to every later one. Read and written by computations/derived_chi_catalogue_mn_disk_cache.py through the shared layer (scripts/lib/branch-cache.sh, computations/_branch_cache.py); it restores by default but seeds origin only when QOU_MN_CHI_CACHE_PUSH=1. A dirty engine tree has no key and nothing is served from the store; loaded entries are re-checked against the live binary first. mn-chi-cache/ is where a member is mounted; nothing is tracked there. The kind is typologies/mn-chi-cache.json.
