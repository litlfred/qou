descriptionExact results of qou's native trace producers (pyhecke_native.tr_m_atomic_mpfr and tr_m_atomic_mpfr_suffixes), stored so a long probe run resumes and a re-run recomputes nothing. One orphan branch per producer function, engine source key, q0 string and dps; inside it, content-addressed JSONL shards of (n, signed word, suffix) -> the producer's exact decimal string, never a float. A dirty engine tree has no key, so a stale value is never served, and computations/trace_cache.py re-evaluates a sample of loaded entries against the live binary before using any. Read and written by scripts/trace-cache.sh, whose git objects live in a private bare repository; computations/trace_cache.py restores by default but seeds origin only when QOU_TRACE_CACHE_PUSH=1; a seed adds a shard on top of the tip and never forces. trace-cache/ is where a member is mounted; nothing is tracked there. The kind is typologies/trace-cache.json.
