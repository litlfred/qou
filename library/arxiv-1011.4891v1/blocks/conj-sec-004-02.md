For any suﬃciently large n0 > 0, there exists a positive s and a nontrivial knot with crossing number n greater than n0 which has more than one s-normal form. Examples justifying both of these two conjectures can be constructed by the same method: it can be shown that certain diﬀerent braids have the same closure, but the isotopy equivalence of these closures involves Markov moves that increase as well as decrease the length of the braid, whereas our device can only do the simplifying Markov moves.
