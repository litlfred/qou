Similarly, if we have an inclusion of type II1-factors N ⊂M, we can make L2(M, tr) into an M–M, M–N, N–M or N–N-bimodule via usual left and right multiplication. If N⊂M is a reducible inclusion, i.e., the relative commutant N′∩M is larger than C1, then we obtain further examples by reducing by projections in the relative commutant. For example, if p ∈N′ ∩M, we obtain the N–M bimodule L2(pM, tr). If φi : M →M are endomorphisms for i = 1, 2, we can also deﬁne an M–M- bimodule structure on L2(M, tr) by perturbing the right and left actions by these endomorphisms, that is, by deﬁning the action by m1.ξ.m2 = φ1(m1)ξφ2(m2).
