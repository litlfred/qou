Given $m_1 \otimes v_1$ and $m_2 \otimes v_2$ representing the same element $m \otimes v$ of $\mathbb{C}[Aut(t(x)] \otimes_{\mathbb{C}[Aut({x})]} F(x)$, we must have $h_1 \in Aut(x)$ with $$m_1 t(h_1) = m_2$$ and $$h_1 v_2 = v_1$$ But then applying $\gamma^{-1}$, we get: $$\gamma^{-1}(m_1 \otimes v_1) = (1 \otimes v_1)_{m_1^{-1}} = (1 \otimes h_1 v_2)_{m_1^{-1}}$$ and $$\gamma^{-1}(m_2 \otimes v_2) = (1 \otimes v_2)_{m_2^{-1}} = (1 \otimes v_2)_{t(h_1)^{-1} m_1^{-1}}$$ but these are in the same component, since $g \sim g'$ when $g' s'(k) = t(h) g$ for some $h \in Aut(x)$ and $k \in Aut({x'})$.
