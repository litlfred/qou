Note that if $(i)$ is a singleton of $\gamma_m\pi_1^{-1}$ and if we have $D_i=1$ for that $i$, then we have $$\gamma_m\pi_1^{-1}(i)=i,\qquad\text{thus}\qquad \pi_1^{-1}(i)=\gamma_m^{-1}(i)=\gamma^{-1}(i),$$ and hence $$\epsilon_{\pi_1^{-1}(i)}=\epsilon_{\gamma^{-1}(i)}=\epsilon_i,$$ which is not allowed because $\pi_1$ is from $NC^{(\epsilon_1)}(m)$, i.e., it must connect alternatingly $U$ with $U^*$.
