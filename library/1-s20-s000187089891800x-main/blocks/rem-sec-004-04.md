3.4. If A is a Hopf algebra there may exist more than one ele- ment w such that (A, w) is a spherical Hopf algebra. However, if w1 is one such element then w2= gw1 is another such element if and only if g satisfies the conditions: (1) g is central (2) g is group-like (3) g is an involution. In particular, if A is finite dimensional over a field, the set of g satisfying these conditions forms a group of the form Zk 2 for some integer k.
