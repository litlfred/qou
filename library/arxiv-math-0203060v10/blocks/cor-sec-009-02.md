A module category M over a multi-fusion category C does not admit nontrivial deformations. In particular, the number of such module categories (up to equivalence) with a given number of simple objects is ﬁnite. To prove Corollary 2.35, it suﬃces to choose a semisimple algebra R with number of blocks equal to the number of simple objects in M, and apply Theorem 2.31 to the functor F : C →R −bimod associated with M.
