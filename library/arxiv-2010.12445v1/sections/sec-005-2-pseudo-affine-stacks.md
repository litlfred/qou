One of the key points in the proof of Theorem A is a characterization of the following stacks.
Deﬁnition 2.1. A pseudo-aﬃne stack is a quasi-compact fpqc stack with quasi-aﬃne diagona l
such that all quasi-coherent sheaves on it are generated by g lobal sections. In other words a
pseudo-aﬃne stack is a quasi-compact fpqc stack X such that {OX } generates QCoh (X ).
A map f : Y ′ − → Y of ﬁbered categories is called pseudo-aﬃne if for all maps T − → Y from
an aﬃne scheme the ﬁber product T ×Y Y ′ is pseudo-aﬃne.
A quasi-aﬃne scheme is pseudo-aﬃne. We will prove a pseudo-a ﬃne stack which is algebraic is
quasi-aﬃne. This result appeared before in [ Gro13, Proposition 3.1]. We will show that pseudo-
aﬃne stacks are indeed just arbitrary intersection of quasi -compact open subsets of an aﬃne
scheme (see 4.2). In general a pseudo-aﬃne sheaf is not quasi-aﬃne. An examp le is the sheaf
intersection of all the complement of closed points in Spec k[x,y ], where k is a ﬁeld (see 4.3).

Remark 2.3. The assumption on the diagonal in 2.2 is necessary: the stack X = BkE, where E
is an elliptic curve over a ﬁeld k, is not a sheaf but QCoh X ≃ QCohk.
Remark 2.4. As a consequence of 2.2 a pseudo-aﬃne stack is separated. In particular a pseudo-
aﬃne map f : Y − → X of pseudo-algebraic ﬁber categories is quasi-compact and s eparated.
Taking an aﬃne atlas of X and applying 2.2 we can also conclude that f ∗f∗F − → F is surjective
for all F ∈ QCoh Y. In particular if D ⊆ QCoh X generates QCoh X thenf ∗D generates QCoh Y
(see [ Ton20, Rem 7.3]).
Remark 2.5. If Y − → SpecA is a map of ﬁbered categories then Y is pseudo-aﬃne if and only
if Y − →SpecA is pseudo-aﬃne, because if Y is pseudo-aﬃne and g : Y ′ − → Y is an aﬃne map,
then Y ′ is an fpqc sheaf with quasi-aﬃne diagonal and OY ′ =g∗OY generates QCoh Y ′.

Theorem 2.7. A quasi-compact ﬂat monomorphism of algebraic stacks is quas i-aﬃne.
Proof. We have to prove that if X → SpecR is a ﬂat monomorphism and X is quasi-compact
algebraic space then X is a quasi-aﬃne scheme. First we observe that X is separated because
X → X × R X is an isomorphism. Thus we can apply 2.2 and conclude that X is pseudo-aﬃne.
Moreover by [ Aut19, Tag 0B8A] the space X is actually a scheme. By [ Gro60, Prop 5.1.2] we
conclude that X is quasi-aﬃne. □
Corollary 2.8. A pseudo-aﬃne algebraic stack is a quasi-aﬃne scheme.
Proof. Use 2.2 and 2.7. □
