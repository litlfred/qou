Theorem 13.1. Let F be a number ﬁeld, and let ρ : π1(M ) → SL(n, F ) be a boundary-unipotent
representation. If ρ is irreducible, [ρ] lies in ˆB(Tr(ρ)).
Proof. Let σ be an automorphism of F over Tr(ρ) and let τ : F → C be an embedding. Then ρ and
σ ◦ ρ have the same traces, so τ ◦ρ and τ ◦σ ◦ρ are conjugate in SL(n, C), and thus have the same
extended Bloch group element in ˆB(C). By Corollary 3.6, it follows that [ρ] = [ σ◦ρ] ∈ ˆB(F ). Hence,
[ρ] is invariant under all automorphisms of F over Tr(ρ), so [ρ] ∈ ˆB(Tr(ρ)) by Galois descent. □
