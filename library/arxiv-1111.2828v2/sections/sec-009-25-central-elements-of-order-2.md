The element sG = φG(−I) is a central element of G of order dividing 2, and equals (−I)n+1 if
G = SL(n, C) (see e.g. Fock-Goncharov [ 14, Corollary 2.1]). Let
(2.17) pG = G/⟨sG⟩.
Note that φG descends to a homomorphism PSL(2, C) → pG. The following follows easily from the
Serre spectral sequence.
Proposition 2.13. Suppose sG has order 2. The canonical map p∗ : H 4(BpG; Z) → H 4(BG; Z) is
surjective with kernel of order dividing 4. □
