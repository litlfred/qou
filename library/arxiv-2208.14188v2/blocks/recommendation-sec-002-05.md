The saddle point equations, i.e. the critical point equations for $U_0$ are \begin{align} u_j + \sum_{i=1}^N A_{ji}Z_i + \sum_{i=1}^N B_{ji} \log(1-\re^{-Z_i}) = \pi\ri \nu_j,\quad j=1,\ldots,N, \label{eq:cr-eq-u} \end{align} or equivalently with \begin{equation} z_i = \re^{Z_i},\quad w_i = \re^{u_i} \end{equation} we find \begin{align} w_j \prod_{i=1}^N z_i^{A_{ji}}(1-z_i^{-1})^{B_{ji}} = (-1)^{\nu_j},\quad j=1,\ldots,N. \label{eq:cr-eq-w} \end{align} Note that at the end of the day, we must set $u_j=0$ or equivalently $w_j = 1$ for $j=2,\ldots,N$.
