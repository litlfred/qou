Deﬁnition 2.3. We say that a BPS structure ( Z, Γ , Ω) is
(a) uncoupled, if for any two active classes γ1, γ2∈ Γ one has ⟨γ1, γ2⟩ = 0;
(b) generic, if for any two active classes γ1, γ2∈ Γ one has
R>0· Z(γ1) = R>0· Z(γ2) =⇒ ⟨γ1, γ2⟩ = 0.
(c) integral, if the BPS invariants Ω( γ)∈ Z are all integers.
The uncoupled condition ensures that the Hamiltonian ﬂows for any p air of functions on T of
the form DT( γ)· xγ commute. This situation corresponds to the case of ‘mutually local c orrections’
in [ 16]. Genericity is the weaker condition that all such ﬂows for which Z(γ) lies on a given ﬁxed
ray ℓ⊂ C∗ should commute.
