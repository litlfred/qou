In this section we address the problem of when the Yoneda functor $\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arr\L_{R}(\shC,A)$ is fully faithful and describe its essential image. This will led us to the notion of generating category and left exactness for functors in $\L_{R}(\shC,A)$.

We fix an $R$-algebra $A$ and a fibered category $\stX$. We assume that our fibered category $\stX$ is pseudo-algebraic, that is we assume there exists a representable map $X\arr\stX$ from a scheme which is an fpqc covering. We also fix a small subcategory $\shC$ of $\mathop{\mathrm{\textup{QCoh}}}\stX$.

::: defn
Let $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}\stX$ be a subcategory. A sheaf $\shG\in\mathop{\mathrm{\textup{QCoh}}}\stX$ is generated by $\shD$ if there exists a surjective morphism $$\bigoplus_{i\in I}\E_{i}\arr\shG$$ where $I$ is a set and $\E_{i}\in\shD$ for all $i\in I$. A sheaf $\shG\in\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ is generated by $\shD$ if it is so as an object of $\mathop{\mathrm{\textup{QCoh}}}\stX$. Equivalently, a sheaf $\shG\in\mathop{\mathrm{\textup{QCoh}}}\stX_{A}$ is generated by $\shD$ if $h_{*}\shG\in\mathop{\mathrm{\textup{QCoh}}}\stX$ is so, where $h\colon\stX_{A}\arr\stX$ is the projection. We define $\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shD}\stX$ as the subcategory of $\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ of sheaves $\shG$ generated by $\shD$ and such that, for all maps $\E\arrdi{\psi}\shG$ with $\E\in\shD^{\oplus}$, also $\mathop{\mathrm{\textup{Ker}}}\psi$ is generated by $\shD$.

If $\shD'$ is another subcategory of $\mathop{\mathrm{\textup{QCoh}}}\stX$ we will say that $\shD$ generates $\shD'$ if all quasi-coherent sheaves in $\shD'$ are generated by $\shD$.
:::

::: rem
[]{#rem: local characterization of generation by D label="rem: local characterization of generation by D"} Consider a set of morphisms $\{U_{j}=\mathop{\mathrm{\textup{Spec}}}B_{j}\arr\stX\}_{j\in J}$ such that $\sqcup_{j}U_{j}\arr\stX$ is an atlas. By [\[prop:reducing to atlases for quasi-geometric categories\]](#prop:reducing to atlases for quasi-geometric categories){reference-type="ref" reference="prop:reducing to atlases for quasi-geometric categories"} we have the following characterizations. If $\shG\in\mathop{\mathrm{\textup{QCoh}}}\stX$ then $\shG$ is generated by $\shD$ if and only if $$\forall j\in J\comma x\in\shG(B_{j})\comma\exists\E\in\shD^{\oplus}\comma\phi\in\E(B_{j})\comma\E\arrdi u\shG\text{ such that }u(\phi)=x$$ If $\E\in\shD^{\oplus}$ and $\psi\colon\E\arr\shG$ is a map then $\mathop{\mathrm{\textup{Ker}}}\psi$ is generated by $\shD$ if and only $$\forall j\in J\comma y\in\E(B_{j})\text{ with }\psi(y)=0\comma\exists\overline{\E}\in\shD^{\oplus}\comma\phi\in\overline{\E}(B_{j})\comma\overline{\E}\arrdi v\E\text{ such that }\psi v=0\comma v(\phi)=y$$ In particular if $\shG\in\mathop{\mathrm{\textup{QCoh}}}^{\shD}\stX$, $\shH\in\mathop{\mathrm{\textup{QCoh}}}\stX$ is generated by $\shD$ and $\shH\arrdi{\alpha}\shG$ is a map then $\mathop{\mathrm{\textup{Ker}}}\alpha$ is generated by $\shD$.
:::

::: prop
If $\shD$ is a subcategory of $\mathop{\mathrm{\textup{QCoh}}}\stX$ then the category $\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shD}\stX$ is stable by direct sums. In particular $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shD}\stX\iff\shD^{\oplus}\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shD}\stX$.
:::

::: proof
*Proof.* Let $\shF,\shG\in\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shD}\stX$. Clearly $\shF\oplus\shG$ is generated by $\shD$. Now consider a map $\alpha\colon\E\arr\shF\oplus\shG$ with $\E\in\shD^{\oplus}$ and write $\alpha=\phi\oplus\psi$. By [\[rem: local characterization of generation by D\]](#rem: local characterization of generation by D){reference-type="ref" reference="rem: local characterization of generation by D"} it follows that $\mathop{\mathrm{\textup{Ker}}}\alpha=\mathop{\mathrm{\textup{Ker}}}(\phi_{|\mathop{\mathrm{\textup{Ker}}}(\psi)}\colon\mathop{\mathrm{\textup{Ker}}}\psi\arr\shF)$ is generated by $\shD$ because $\mathop{\mathrm{\textup{Ker}}}(\psi)$ is generated by $\shD$ and $\shF\in\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shD}\stX$. ◻
:::

If $g\colon U=\mathop{\mathrm{\textup{Spec}}}B\arr\stX$ is a map from a scheme then $(J_{B,\shC})^{\mathop{\mathrm{\textup{op}}}}$ (see [\[prop:FGammaCB as a direct limit\]](#prop:FGammaCB as a direct limit){reference-type="ref" reference="prop:FGammaCB as a direct limit"}) is not a filtered category in general. Thus if $\Gamma\in\L_{R}(\shC,A)$ and $x_{\E,\phi}\in\shF_{\Gamma,\shC}(B)$ it is very difficult to understand when $x_{\E,\phi}$ is zero in $\shF_{\Gamma,\shC}(B)$. Luckily, under some hypothesis this is possible.

::: lem
[]{#lem:when J is filtered label="lem:when J is filtered"} Assume $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$. Then for all flat and representable maps $g\colon\mathop{\mathrm{\textup{Spec}}}B\arr\stX$ the category $(J_{B,\shC^{\oplus}})^{\text{op}}$ is filtered. In this case, given $\Gamma\in\L_{R}(\shC,A)$, an element $x_{\E,\phi}\in\shF_{\Gamma,\shC}(B)$ for $(\E,\phi)\in J_{B,\shC}$ is zero if and only if there exists $(\overline{\E},\overline{\phi})\arrdi u(\E,\phi)$ in $J_{B,\shC}$ such that $\Gamma_{u}(x)=0$.
:::

::: proof
*Proof.* By [\[prop:find a directed category\]](#prop:find a directed category){reference-type="ref" reference="prop:find a directed category"} we can assume $\shC=\shC^{\oplus}$. By [\[prop:FGammaCB as a direct limit\]](#prop:FGammaCB as a direct limit){reference-type="ref" reference="prop:FGammaCB as a direct limit"} we have to prove that for all maps $\alpha,\beta\colon(\E,\phi)\arr(\overline{\E},\overline{\phi})$ in $J_{B,\shC}$ there exists $u\colon(\E',\phi')\arr(\E,\phi)$ in $J_{B,\shC}$ such that $\alpha u=\beta u$. Let $\shK=\mathop{\mathrm{\textup{Ker}}}((\alpha-\beta)\colon\E\arr\overline{\E})$, so that $\phi\in\shK(B)$ since $g$ is flat. By assumption $\shK$ is generated by $\shC$ and, since $\shC$ is additive, there exist $\E'\in\shC$, a map $u\colon\E'\arr\shK$ and $\phi'\in\E'(B)$ such that $u(\phi')=\phi$. So $(\E',\phi')\arrdi u(\E,\phi)$ is an arrow in $J_{B,\shC}$ such that $(\alpha-\beta)u=0$ as required. The last claim follows from [\[prop:FGammaCB as a direct limit\]](#prop:FGammaCB as a direct limit){reference-type="ref" reference="prop:FGammaCB as a direct limit"} and the fact that $J_{B,\shC}^{\mathop{\mathrm{\textup{op}}}}$ is filtered. ◻
:::

In what follows we work out sufficient (and sometimes necessary) conditions for the surjectivity or injectivity of $\delta_{\shG}\colon\shF_{\Omega^{\shG},\shC}\arr\shG$. Recall that $\delta_{\shG}(u_{\E,\phi})=u(\phi)$ for $\E\in\shC^{\oplus}$, $\mathop{\mathrm{\textup{Spec}}}B\arr\stX$, $\phi\in\E(B)$, $u\in\Omega_{\E}^{\shG}=\mathop{\mathrm{\textup{Hom}}}_{\stX}(\E,\shG)$ (see [\[prop:FGammaC on affine schemes\]](#prop:FGammaC on affine schemes){reference-type="ref" reference="prop:FGammaC on affine schemes"}).

::: lem
[]{#lem:surjectivity natural map F label="lem:surjectivity natural map F"} If $\shG\in\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ the map $\delta_{\shG}\colon\shF_{\Omega^{\shG},\shC}\arr\shG$ is surjective if and only if $\shG$ is generated by $\shC$.
:::

::: proof
*Proof.* By [\[prop:find a directed category\]](#prop:find a directed category){reference-type="ref" reference="prop:find a directed category"} we can assume $\shC=\shC^{\oplus}$. Let $\{g_{i}\colon U_{i}=\mathop{\mathrm{\textup{Spec}}}B_{i}\arr\stX\}$ be a set of maps such that $\sqcup_{i}U_{i}\arr\stX$ is an atlas. By [\[prop:reducing to atlases for quasi-geometric categories\]](#prop:reducing to atlases for quasi-geometric categories){reference-type="ref" reference="prop:reducing to atlases for quasi-geometric categories"} $\delta_{\shG}$ is surjective if and only if $\delta_{\shG,U_{i}}\colon\shF_{\Omega^{\shG},\shC}(U_{i})\arr\shG(U_{i})$ is surjective for all $i\in I$. By [\[prop:FGammaCB as a direct limit\]](#prop:FGammaCB as a direct limit){reference-type="ref" reference="prop:FGammaCB as a direct limit"} $\mathop{\mathrm{\textup{Im}}}\delta_{\shG,U_{i}}$ is the set of elements of $\shG(U_{i})$ of the form $\delta_{\shG}(u_{\E,\phi})=u(\phi)$ for $\E\in\shC^{\oplus}$, $\phi\in\E(U_{i})$, $u\in\Omega_{\E}^{\shG}=\mathop{\mathrm{\textup{Hom}}}_{\stX}(\E,\shG)$. So the claim follows from [\[rem: local characterization of generation by D\]](#rem: local characterization of generation by D){reference-type="ref" reference="rem: local characterization of generation by D"}. ◻
:::

::: lem
[]{#lem:injectivity natural map F label="lem:injectivity natural map F"} Let $\shG\in\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$. If for all maps $\E\arrdi{\phi}\shG$ with $\E\in\shC^{\oplus}$ the kernel $\mathop{\mathrm{\textup{Ker}}}\phi$ is generated by $\shC$ then the map $\delta_{\shG}\colon\shF_{\Omega^{\shG},\shC}\arr\shG$ is injective. The converse holds if $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$.
:::

::: proof
*Proof.* By [\[prop:find a directed category\]](#prop:find a directed category){reference-type="ref" reference="prop:find a directed category"} we can assume $\shC=\shC^{\oplus}$. Let $\{g_{i}\colon U_{i}=\mathop{\mathrm{\textup{Spec}}}B_{i}\arr\stX\}$ be a set of maps such that $\sqcup_{i}U_{i}\arr\stX$ is an atlas. By [\[prop:reducing to atlases for quasi-geometric categories\]](#prop:reducing to atlases for quasi-geometric categories){reference-type="ref" reference="prop:reducing to atlases for quasi-geometric categories"} $\delta_{\shG}$ is injective if and only if $\delta_{\shG,U_{i}}\colon\shF_{\Omega^{\shG},\shC}(U_{i})\arr\shG(U_{i})$ is injective for all $i\in I$. We start proving that $\delta_{\shG}$ is injective if the hypothesis in the statement is fulfilled. So let $z\in\mathop{\mathrm{\textup{Ker}}}\delta_{\shG,U_{i}}$. By [\[prop:FGammaCB as a direct limit\]](#prop:FGammaCB as a direct limit){reference-type="ref" reference="prop:FGammaCB as a direct limit"} there exists $\E\in\shC$, $\phi\in\E(U_{i})$ and $u\colon\E\arr\shG$ such that $z=u_{\E,\phi}$ and $\delta_{\shG}(u_{\E,\phi})=u(\phi)=0$. Set $\shK=\mathop{\mathrm{\textup{Ker}}}u$. Since $\phi\in\shK(U_{i})$ and, by hypothesis, $\shK$ is generated by $\shC$ there exist $\overline{\E}\in\shC$, $\overline{\phi}\in\overline{\E}(U_{i})$ and a map $v\colon\overline{\E}\arr\shK$ such that $v(\overline{\phi})=\phi$. If we denote by $v$ also the composition $\overline{\E}\arr\shK\arr\E$ we have $$u_{\E,\phi}=(\Omega_{v}^{\shG}(u))_{\overline{\E},\overline{\phi}}=(uv)_{\overline{\E},\overline{\phi}}=0_{\overline{\E},\overline{\phi}}=0\text{ in \ensuremath{\shF_{\Gamma,\shC}(U_{i})}}$$ Assume now that $\delta_{\shG}$ is injective and $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ and let $u\colon\E\arr\shG$ be a map with $\E\in\shC$. We have to prove that $\shK=\mathop{\mathrm{\textup{Ker}}}u$ is generated by $\shC$. If $\phi\in\shK(U_{i})\subseteq\E(U_{i})$, then $u(\phi)=\delta_{\shG}(u_{\E,\phi})=0$. So $u_{\E,\phi}=0$ and the conclusion follows from [\[rem: local characterization of generation by D\]](#rem: local characterization of generation by D){reference-type="ref" reference="rem: local characterization of generation by D"} and [\[lem:when J is filtered\]](#lem:when J is filtered){reference-type="ref" reference="lem:when J is filtered"}. ◻
:::

In general we can still conclude that:

::: prop
[]{#prop: delta E is an isomorphism label="prop: delta E is an isomorphism"} If $\E\in\shC^{\oplus}$ then the map $\delta_{\E}\colon\shF_{\Omega^{\E},\shC}\arr\E$ is an isomorphism.
:::

::: proof
*Proof.* By [\[prop:find a directed category\]](#prop:find a directed category){reference-type="ref" reference="prop:find a directed category"} we can assume $\shC=\shC^{\oplus}$. Let $\shH\in\mathop{\mathrm{\textup{QCoh}}}\stX$. The map $$\mathop{\mathrm{\textup{Hom}}}_{\stX}(\E,\shH)\arrdi{\Omega_{*}}\mathop{\mathrm{\textup{Hom}}}_{\L_{R}(\shC,R)}(\Omega^{\E},\Omega^{\shH})\simeq\mathop{\mathrm{\textup{Hom}}}_{\stX}(\shF_{\Omega^{\E},\shC},\shH)$$ maps $\id_{\E}$ to $\delta_{\E}$ and thus is induced by $\delta_{\E}$. By the enriched Yoneda's lemma or a direct check we see that the above map and therefore $\delta_{\E}$ are isomorphisms. ◻
:::

::: thm
[]{#thm:when Omegastar is fully faithful label="thm:when Omegastar is fully faithful"} Let $\shD_{A}$ be the subcategory of $\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ of sheaves $\shG$ such that $\delta_{\shG}\colon\shF_{\Omega^{\shG},\shC}\arr\shG$ is an isomorphism. Then $\shD_{A}$ is an additive category containing $\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shC}\stX$, $\shC^{\oplus}\subseteq\shD_{R}$ and the functor $$\Omega^{*}\colon\shD_{A}\arr\L_{R}(\shC,A)$$ is fully faithful. Moreover if $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ then $\shD_{A}=\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shC}\stX$.
:::

::: proof
*Proof.* The category $\shD_{A}$ is additive because $\Omega^{*}$ and $\shF_{*,\shC}$ are additive. All the other claims follows from [\[lem:surjectivity natural map F\]](#lem:surjectivity natural map F){reference-type="ref" reference="lem:surjectivity natural map F"}, [\[lem:injectivity natural map F\]](#lem:injectivity natural map F){reference-type="ref" reference="lem:injectivity natural map F"}, [\[prop: delta E is an isomorphism\]](#prop: delta E is an isomorphism){reference-type="ref" reference="prop: delta E is an isomorphism"} and the fact that $\delta_{\shG}$ is the counit of an adjiunction. ◻
:::

Now we want to address the problem of what is the essential image of the Yoneda functor $\Omega^{*}\colon\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arr\L_{R}(\shC,A)$. We will see that if $\shF\in\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ the associated Yoneda functor $\Omega^{\shF}$ is always "left exact" and we will give sufficient conditions assuring that "left exact" functors in $\L_{R}(\shC,A)$ are Yoneda functors associated with some quasi-coherent sheaf on $\stX$. Since $\shC$ is not abelian, we introduce an ad hoc notion of left exactness.

::: defn
[]{#def: left exact functors label="def: left exact functors"} Let $\shD$ be a subcategory of $\mathop{\mathrm{\textup{QCoh}}}\stX$. A *test sequence* for $\shD$ is an exact sequence $$\bigoplus_{k\in K}\E_{k}\arr\bigoplus_{j\in J}\E_{j}\arr\E\arr0\text{ with }\E,\E_{j},\E_{k}\in\shD\text{ for all }j\in J,k\in K\label{eq:exact sequence for functor exactness}$$ in $\mathop{\mathrm{\textup{QCoh}}}\stX$ given by maps $u_{j}\colon\E_{j}\arr\E$, $u_{kj}\colon\E_{k}\arr\E_{j}$ such that for all $k\in K$ the set $\{j\in J\st u_{kj}\neq0\}$ is finite. We will also say that it is a test sequence for $\E\in\shD$. A finite test sequence for $\E\in\shD$ is an exact sequence $$\E''\arr\E'\arr\E\arr0\text{ with }\E',\E''\in\shD^{\oplus}$$ Given $\Gamma\in\L_{R}(\shD,A)$ we say that $\Gamma$ is exact on the test sequence ([\[eq:exact sequence for functor exactness\]](#eq:exact sequence for functor exactness){reference-type="ref" reference="eq:exact sequence for functor exactness"}) if the sequence $$\begin{tikzpicture}[xscale=2.9,yscale=-0.8]     
\node (A0_2) at (2, 0) {$(x_j )_j$};     
\node (A0_3) at (3, 0) {$(\sum_j \Gamma_{u_{kj}}(x_j))_k$};     
\node (A1_0) at (0.4, 1) {$0$};     
\node (A1_1) at (1.1, 1) {$\Gamma_\E$};     
\node (A1_2) at (2, 1) {$\displaystyle{\prod_{j\in J}\Gamma_{\E_j}}$};     
\node (A1_3) at (3, 1) {$\displaystyle{\prod_{k\in K}\Gamma_{\E_k}}$};    
\node (A2_1) at (1.1, 2) {$x$};     
\node (A2_2) at (2, 2) {$(\Gamma_{u_j}(x))_j$};     
\path (A0_2) edge [|->,gray]node [auto] {$\scriptstyle{}$} (A0_3);     
\path (A1_0) edge [->]node [auto] {$\scriptstyle{}$} (A1_1);     
\path (A2_1) edge [|->,gray]node [auto] {$\scriptstyle{}$} (A2_2);     
\path (A1_2) edge [->]node [auto] {$\scriptstyle{}$} (A1_3);     
\path (A1_1) edge [->]node [auto] {$\scriptstyle{}$} (A1_2);   
\end{tikzpicture}
\label{Gamma on a test sequence}$$ is exact. We say that $\Gamma$ is left exact if it is left exact on all short exact sequences in $\shD$. We define $\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$ as the subcategory of $\L_{R}(\shD,A)$ of functors exact on all test sequences in $\shD$.
:::

::: rem
Notice that the sequence ([\[Gamma on a test sequence\]](#Gamma on a test sequence){reference-type="ref" reference="Gamma on a test sequence"}) is a complex because $\Gamma$ is $R$-linear. Moreover we should warn the reader that the sequence ([\[Gamma on a test sequence\]](#Gamma on a test sequence){reference-type="ref" reference="Gamma on a test sequence"}) is not obtained applying $\Gamma$ on the test sequence, unless $J$ and $K$ are finite, even if $\Gamma$ is defined (or extended) to the whole $\mathop{\mathrm{\textup{QCoh}}}\stX$. The problem is that $\Gamma$ does not necessarily transforms infinite direct sums in products.
:::

::: prop
[]{#prop:OmegaF is left exact label="prop:OmegaF is left exact"} Let $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}\stX$ be a subcategory. If $\shF\in\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ then $\Omega^{\shF}\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$.
:::

::: proof
*Proof.* It is enough to apply $\mathop{\mathrm{\textup{Hom}}}_{\stX}(-,\shF)$ to the test sequence ([\[eq:exact sequence for functor exactness\]](#eq:exact sequence for functor exactness){reference-type="ref" reference="eq:exact sequence for functor exactness"}) and observe that $$\mathop{\mathrm{\textup{Hom}}}_{\stX}(\bigoplus_{i}\E_{i},\shF)\simeq\prod_{i}\mathop{\mathrm{\textup{Hom}}}(\E_{i},\shF)\simeq\prod_{i}\Omega_{\E_{i}}^{\shF}$$ ◻
:::

::: prop
[]{#prop:excatness properties of Omega* and shF* label="prop:excatness properties of Omega* and shF*"} The functor $\Omega^{*}\colon\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arr\L_{R}(\shC,A)$ is left exact. If $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ then $\shF_{*,\shC}\colon\L_{R}(\shC,A)\arr\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ is exact.
:::

::: proof
*Proof.* For the first claim it is enough to use that $\mathop{\mathrm{\textup{Hom}}}_{\stX}(\E,-)$ is left exact. For the last part of the statement consider a set of maps $\{U_{i}=\mathop{\mathrm{\textup{Spec}}}B_{i}\arrdi{g_{i}}\stX\}_{i\in I}$ such that $\sqcup_{i}U_{i}\arr\stX$ is an atlas. Let also $\Gamma'\arr\Gamma\arr\Gamma''$ be an exact sequence in $\L_{R}(\shC,A)$. By [\[prop:FGammaCB as a direct limit\]](#prop:FGammaCB as a direct limit){reference-type="ref" reference="prop:FGammaCB as a direct limit"} the sequence $\shF_{\Gamma',\shC}(B_{i})\arr\shF_{\Gamma,\shC}(B_{i})\arr\shF_{\Gamma'',\shC}(B_{i})$ are exact for all $i\in I$ because limit of exact sequences $\Gamma_{\E,\phi}'\arr\Gamma_{\E,\phi}\arr\Gamma_{\E,\phi}''$ over the category $(J_{B_{i},\shC})^{\mathop{\mathrm{\textup{op}}}}$, which is filtered thanks to [\[lem:when J is filtered\]](#lem:when J is filtered){reference-type="ref" reference="lem:when J is filtered"}. Applying [\[prop:reducing to atlases for quasi-geometric categories\]](#prop:reducing to atlases for quasi-geometric categories){reference-type="ref" reference="prop:reducing to atlases for quasi-geometric categories"} we get the result. ◻
:::

Recall that if $\Gamma\in\L_{R}(\shC,A)$ then $\gamma_{\Gamma,\E}\colon\Gamma_{\E}\arr\Omega_{\E}^{\shF_{\Gamma,\shC}}=\mathop{\mathrm{\textup{Hom}}}_{\stX}(\E,\shF_{\Gamma,\shC})$ is given by $\gamma_{\Gamma,\E}(x)(\phi)=x_{\E,\phi}$ for $\E\in\shC$, $x\in\Gamma_{\E}$, $\mathop{\mathrm{\textup{Spec}}}B\arr\stX$ and $\phi\in\E(B)$ (see [\[prop:FGammaC on affine schemes\]](#prop:FGammaC on affine schemes){reference-type="ref" reference="prop:FGammaC on affine schemes"}).

::: lem
[]{#lem:injectivity natural transformation Omega label="lem:injectivity natural transformation Omega"} Assume $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$. If $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$ and the map $\Omega^{*}\circ\shF_{*,\shC}(\gamma_{\Gamma})\colon\Omega^{\shF_{\Gamma,\shC}}\arr\Omega^{\shF_{\Omega^{\shF_{\Gamma,\shC}},\shC}}$ is an isomorphism then the natural transformation $\gamma_{\Gamma}\colon\Gamma\arr\Omega^{\shF_{\Gamma,\shC}}$ is an isomorphism.
:::

::: proof
*Proof.* Let $\{U_{i}=\mathop{\mathrm{\textup{Spec}}}B_{i}\arrdi{g_{i}}\stX\}_{i\in I}$ be a set of maps such that $\sqcup_{i}U_{i}\arr\stX$ is an atlas and let $\Psi\in\L_{R}(\shC,A)$ and $x\in\mathop{\mathrm{\textup{Ker}}}\gamma_{\Psi,\E}$ for some $\E\in\shC$. We are going to prove that there exists a surjective map $\mu=\oplus_{j}\mu_{j}\colon\oplus_{j\in J}\E_{j}\arr\E$ with $\E_{j},\E\in\shC$ such that $\Psi_{u_{j}}(x)=0$ for all $j$.

If $\phi\in\E(U_{i})$, by [\[lem:when J is filtered\]](#lem:when J is filtered){reference-type="ref" reference="lem:when J is filtered"} and the fact that $\gamma_{\Psi,\E}(x)(\phi)=x_{\E,\phi}$ is zero in $\shF_{\Psi,\shC}(U_{i})$, there exists $(\E_{\phi},y_{\phi})\in J_{B_{i},\shC}$ and a map $(\E_{\phi},y_{\phi})\arrdi{u_{\phi}}(\E,\phi)$ such that $\Psi_{u_{\phi}}(x)=0$. Consider the induced map $$\bigoplus_{i\in I}\bigoplus_{\phi\in\E(U_{i})}\E_{\phi}\arr\E$$ which is surjective by [\[prop:reducing to atlases for quasi-geometric categories\]](#prop:reducing to atlases for quasi-geometric categories){reference-type="ref" reference="prop:reducing to atlases for quasi-geometric categories"}. Writing all the $\E_{\phi}\in\shC^{\oplus}$ as sums of sheaves in $\shC$ we get the desired surjective map.

We return now to the proof of the statement. Given $x\in\mathop{\mathrm{\textup{Ker}}}\gamma_{\Gamma,\E}$ and considering a surjection $\mu$ as above for $\Psi=\Gamma$, we can conclude that $x=0$ by [\[prop:test sequences and Extone\]](#prop:test sequences and Extone){reference-type="ref" reference="prop:test sequences and Extone"}. This means that the natural transformation $\gamma_{\Gamma}\colon\Gamma\arr\Omega^{\shF_{\Gamma,\shC}}$ is injective. Set now $\Pi=\mathop{\mathrm{\textup{Coker}}}\gamma_{\Gamma,\shC}$. By [\[prop:excatness properties of Omega\* and shF\*\]](#prop:excatness properties of Omega* and shF*){reference-type="ref" reference="prop:excatness properties of Omega* and shF*"} we have an exact sequence $$0\arr\shF_{\Gamma,\shC}\arrdi{\shF_{*,\shC}(\gamma_{\Gamma})}\shF_{\Omega^{\shF_{\Gamma,\shC}}}\arr\shF_{\Pi,\shC}\arr0$$ This is a split sequence because the composition of $\shF_{*,\shC}(\gamma_{\Gamma})\colon\shF_{\Gamma,\shC}\arr\shF_{\Omega^{\shF_{\Gamma,\shC}},\shC}$ and $\delta_{\shF_{\Gamma,\shC}}\colon\shF_{\Omega^{\shF_{\Gamma,\shC}},\shC}\arr\shF_{\Gamma,\shC}$ is the identity. So $\Omega^{*}$ maintains the exactness of the above sequence and therefore $$\Omega^{\shF_{\Pi,\shC}}=\mathop{\mathrm{\textup{Coker}}}(\Omega^{*}\circ\shF_{*,\shC}(\gamma_{\Gamma}))=0$$ We want to prove that $\Pi=0$. Let $x\in\Pi_{\E}$ for $\E\in\shC$. Since $\Omega^{\shF_{\Pi,\shC}}=0$ we have $x\in\mathop{\mathrm{\textup{Ker}}}\gamma_{\Pi,\E}$. Consider a surjection $\mu=\oplus_{j}\mu_{j}$ constructed as above starting from $x\in\Pi_{\E}$ and $\Psi=\Pi$. By [\[rem: local characterization of generation by D\]](#rem: local characterization of generation by D){reference-type="ref" reference="rem: local characterization of generation by D"} $\mu$ can be extended to a test sequence $\oplus_{k}\E_{k}\arr\oplus_{j}\E_{i}\arrdi{\mu}\E$ because $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$. ::: defn
We define $\mathop{\mathrm{\textup{Lex}}}_{R}^{\shC}(A)$ as the subcategory of $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$ of functors $\Gamma$ such that $\shF_{\Gamma,\shC}\in\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shC}\stX$.
:::

::: thm
[]{#thm:relative theorem for equivalence label="thm:relative theorem for equivalence"} Assume $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$. Then the functors $$\Omega^{*}\colon\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shC}\stX\arr\mathop{\mathrm{\textup{Lex}}}_{R}^{\shC}(A)\text{ and }\shF_{*,\shC}\colon\mathop{\mathrm{\textup{Lex}}}_{R}^{\shC}(A)\arr\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shC}\stX$$ are quasi-inverses of each other.
:::

::: proof
*Proof.* Let $\Gamma\in\L_{R}(\shC,A)$ be such that $\shF_{\Gamma,\shC}\in\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shC}\stX$. The composition $$\shF_{\Gamma,\shC}\arrdi{\shF_{*,\shC}(\gamma_{\Gamma})}\shF_{\Omega^{\shF_{\Gamma,\shC}},\shC}\arrdi{\delta_{\shF_{\Gamma,\shC}}}\shF_{\Gamma,\shC}$$ is the identity and $\delta_{\shF_{\Gamma,\shC}}$ is an isomorphism since $\shF_{\Gamma,\shC}\in\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shC}\stX$ by [\[thm:when Omegastar is fully faithful\]](#thm:when Omegastar is fully faithful){reference-type="ref" reference="thm:when Omegastar is fully faithful"}. Thus $\shF_{*,\shC}(\gamma_{\Gamma})$ and therefore $\Omega^{*}\circ\shF_{*,\shC}(\gamma_{\Gamma})$ are isomorphisms. By [\[lem:injectivity natural transformation Omega\]](#lem:injectivity natural transformation Omega){reference-type="ref" reference="lem:injectivity natural transformation Omega"} we can conclude that if $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}^{\shC}(A)$ then $\gamma_{\Gamma}\colon\Gamma\arr\Omega^{\shF_{\Gamma,\shC}}$ is an isomorphism. The result then follows from [\[thm:when Omegastar is fully faithful\]](#thm:when Omegastar is fully faithful){reference-type="ref" reference="thm:when Omegastar is fully faithful"} and [\[prop:OmegaF is left exact\]](#prop:OmegaF is left exact){reference-type="ref" reference="prop:OmegaF is left exact"}. ◻
:::

The following result allow us to extend results from small subcategories of $\mathop{\mathrm{\textup{QCoh}}}\stX$ to any subcategory.

::: prop
[]{#prop: QCoh X is Grothendieck label="prop: QCoh X is Grothendieck"} The category $\mathop{\mathrm{\textup{QCoh}}}\stX$ is generated by a small subcategory. Equivalently $\mathop{\mathrm{\textup{QCoh}}}\stX$ has a generator, that is there exists $\E\in\mathop{\mathrm{\textup{QCoh}}}\stX$ such that $\{\E\}$ generates $\mathop{\mathrm{\textup{QCoh}}}\stX$.
:::

::: proof
*Proof.* Follows from [\[prop:reducing to atlases for quasi-geometric categories\]](#prop:reducing to atlases for quasi-geometric categories){reference-type="ref" reference="prop:reducing to atlases for quasi-geometric categories"} and [@SP014 Tag 0780]. ◻
:::

::: rem
[]{#rem: finding small subcategory generating QCoh X label="rem: finding small subcategory generating QCoh X"} If $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}\stX$ generates $\mathop{\mathrm{\textup{QCoh}}}\stX$ there always exists a small subcategory $\overline{\shD}\subseteq\shD$ that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$. Indeed if $\E$ is a generator of $\mathop{\mathrm{\textup{QCoh}}}\stX$ it is enough to take a subset of sheaves in $\shD$ that generates $\E$.
:::

::: thm
[]{#thm:general theorem for equivalences label="thm:general theorem for equivalences"} Let $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}\stX$ be a subcategory that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$. Then the functor $$\Omega^{*}\colon\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$$ is an equivalence of categories and, if $\shD$ is small, $\shF_{*,\shD}\colon\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{QCoh}}}_{A}\stX$ is a quasi-inverse. In particular if $\overline{\shD}\subseteq\shD$ is a subcategory that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$ the restriction functor $\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\overline{\shD},A)$ is an equivalence.
:::

::: proof
*Proof.* If $\shD$ is small we have $\mathop{\mathrm{\textup{QCoh}}}_{A}\stX=\mathop{\mathrm{\textup{QCoh}}}_{A}^{\shD}\stX$, $\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)=\mathop{\mathrm{\textup{Lex}}}_{R}^{\shD}(A)$ and everything follows from [\[thm:relative theorem for equivalence\]](#thm:relative theorem for equivalence){reference-type="ref" reference="thm:relative theorem for equivalence"}. In particular the restriction $\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\overline{\shD},A)$ is an equivalence if $\overline{\shD}\subseteq\shD$, they are small and they generate $\mathop{\mathrm{\textup{QCoh}}}\stX$. Assume now that $\shD$ is not necessarily small and consider a small subcategory $\shC\subseteq\shD$ that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$, which exists thanks to [\[rem: finding small subcategory generating QCoh X\]](#rem: finding small subcategory generating QCoh X){reference-type="ref" reference="rem: finding small subcategory generating QCoh X"}. The proof of the statement is complete if we prove that the restriction functor $\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$ is an equivalence. Given a set $I\subseteq\shD$ we set $\shC_{I}=\shC\cup I\subseteq\shD$. For all sets $I$, quasi-coherent sheaves are generated by $\shC_{I}$. Note that we have the restriction functor $-_{|C_{I}}\colon\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\shC_{I},A)$ and the composition $\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arrdi{\Omega^{*}}\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)\arrdi{-_{|\shC_{I}}}\mathop{\mathrm{\textup{Lex}}}_{R}(C_{I},A)$ is an equivalence for all $I$. In particular $-_{|C}\colon\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$ is essentially surjective. We will conclude by proving that it is fully faithful. Let $\Gamma,\Gamma'\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$. If $\overline{I}\subseteq I$ the restriction functor $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC_{I},A)\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\shC_{\overline{I}},A)$ is an equivalence of categories. In particular the map $\mathop{\mathrm{\textup{Hom}}}(\Gamma_{|\shC_{I}},\Gamma'_{|\shC_{I}})\arr\mathop{\mathrm{\textup{Hom}}}(\Gamma_{|\shC_{\overline{I}}},\Gamma'_{|\shC_{\overline{I}}})$ is bijective. Using this, it is elementary to prove that also the map $\mathop{\mathrm{\textup{Hom}}}(\Gamma,\Gamma')\arr\mathop{\mathrm{\textup{Hom}}}(\Gamma_{|\shC},\Gamma'_{|\shC})$ is bijective. ◻
:::

As a corollary we recover Gabriel-Popescu's theorem for the category $\mathop{\mathrm{\textup{QCoh}}}\stX$.

::: thm
[]{#thm: Gabriel Popescu's theorem label="thm: Gabriel Popescu's theorem"}\[Gabriel-Popescu's theorem\] If $\E$ is a generator of $\mathop{\mathrm{\textup{QCoh}}}\stX$ then the functor $$\mathop{\mathrm{\textup{Hom}}}_{\stX}(\E,-)\colon\mathop{\mathrm{\textup{QCoh}}}\stX\arr\mathop{\mathrm{\textup{Mod}}}_{\text{right}}(\mathop{\mathrm{\textup{End}}}_{\stX}(\E))$$ is fully faithful and has an exact left adjoint.
:::

::: proof
*Proof.* It follows from [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"} and [\[prop:excatness properties of Omega\* and shF\*\]](#prop:excatness properties of Omega* and shF*){reference-type="ref" reference="prop:excatness properties of Omega* and shF*"} with $\shD=\shC=\{\E\}$. ◻
:::

Before showing other applications of [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"} we want to present a cohomological interpretation of the functors in $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$, which will allow us to show that it is often enough to consider just finite test sequences instead of arbitrary test sequences.

::: rem
In an abelian category $\alA$, given $X,Y\in\alA$ we can always define the abelian group $\mathop{\mathrm{\textup{Ext}}}^{1}(X,Y)$ as the group of extensions (regardless if $\alA$ has enough injectives) and it has the usual nice properties on short exact sequences. In order to avoid set-theoretic problems one should require that $\alA$ is locally small and that, given $X,Y\in\alA$, $\mathop{\mathrm{\textup{Ext}}}^{1}(X,Y)$ is a set. This is the case for $\alA=\L_{R}(\shC,R)$, for instance by looking at the cardinalities of the $\Gamma_{\E}$ for $\Gamma\in\L_{R}(\shC,R)$ and $\E\in\shC$.
:::

::: defn
[]{#def: cohomologically left exact label="def: cohomologically left exact"} Given a surjective map $\mu=\oplus_{j}\mu_{j}\colon\oplus_{j}\E_{j}\arr\E$ with $\E,\E_{j}\in\shC$ we set $\Omega^{\mu}=\oplus_{j}\Omega^{\mu_{j}}\colon\oplus_{j}\Omega^{\E_{j}}\arr\Omega^{\E}$. A functor $\Gamma\in\L_{R}(\shC,A)$ is *cohomologically left exact* on $\mu$ if $$\mathop{\mathrm{\textup{Hom}}}_{\L_{R}(\shC,R)}(\Omega^{\E}/\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu}),\Gamma)=\mathop{\mathrm{\textup{Ext}}}_{\L_{R}(\shC,R)}^{1}(\Omega^{\E}/\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu}),\Gamma)=0\label{eq:cohomological vanishing left exact functors}$$ It is cohomologically left exact if it is so on all surjections $\mu$ as above.
:::

We setup some notation. We denote by $\Phi_{\shC}(\E)$ for $\E\in\shC$ the set of subfunctor of $\Omega^{\E}$of the form $\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu})$ for some surjective map $\mu\colon\oplus_{j}\E_{i}\arr\E$ with $\E_{j}\in\shC$ and by $\Phi_{\shC}$ the disjoint union of all the $\Phi_{\shC}(\E)$. Given $\Delta=\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu})\in\Phi_{\shC}$ and $\Gamma\in\L_{R}(\shC,A)$ we will say that $\Gamma$ is cohomologically left exact on $\Delta$ if it is cohomologically left exact on $\mu$. Notice that, using Yoneda's lemma, we have an $A$-linear isomorphism $$\mathop{\mathrm{\textup{Hom}}}_{\L_{R}(\shC,R)}(\oplus_{j}\Omega^{\E_{j}},\Gamma)\simeq\prod_{j}\Gamma_{\E_{j}}\text{ for all }\E_{j}\in\shC\comma\Gamma\in\L_{R}(\shC,A)$$ In particular $\mathop{\mathrm{\textup{Hom}}}_{\L_{R}(\shC,R)}(\Omega^{\E},-)$, which is the evaluation in $\E$, is exact, which implies that $\mathop{\mathrm{\textup{Ext}}}_{\L_{R}(\shC,R)}^{1}(\Omega^{\E},-)=0$.

A map $\oplus_{j}\E_{j}\arr\oplus_{k}\E_{k}$ is called *locally finite* if, for all $j$, the restriction $\E_{j}\arr\oplus_{k}\E_{k}$ factors through a finite sub-sum. Composition of locally finite maps is locally finite and, using Yoneda's lemma, we obtain a functorial map $$\mathop{\mathrm{\textup{Hom}}}_{\L_{R}(\shC,R)}(\oplus_{j}\Omega^{\E_{j}},\oplus_{k}\Omega^{\E_{k}})\arr\mathop{\mathrm{\textup{Hom}}}(\oplus_{j}\E_{j},\oplus_{k}\E_{k})$$ which is an isomorphism onto the set of locally finite maps.

Let $\mu\colon\oplus_{j}\E_{j}\arr\E$ be a surjective map and set $\Delta=\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu})$. Notice that $\Delta_{\E'}$ is the set of maps $\E'\arr\E$ which factors through $\mu$ via a locally finite map $\E'\arr\oplus_{j}\E_{j}$. Given a map $u\colon\overline{\E}\arr\E$ in $\shC$ we set $u^{-1}(\Delta)=\Delta\times_{\Omega^{\E}}\Omega^{\overline{\E}}\subseteq\Omega^{\overline{\E}}$: $u^{-1}(\Delta)_{\E'}$ is the set of maps $\E'\arr\overline{\E}$ such that $\E'\arr\overline{\E}\arr\E$ factors through $\mu$ via a locally finite map $\E'\arr\oplus_{j}\E_{j}$. Notice that if $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ then $u^{-1}(\Delta)\in\Phi_{\shC}(\overline{\E})$. Indeed, if $\shH$ is the kernel of $\mu\oplus(-u)\colon(\oplus_{j}\E_{j})\oplus\overline{\E}\arr\E$ then all elements of $\shH$ on some object $\mathop{\mathrm{\textup{Spec}}}B\arr\stX$ lies in a finite subsum of $(\oplus_{j}\E_{j})\oplus\overline{\E}$. By [\[rem: local characterization of generation by D\]](#rem: local characterization of generation by D){reference-type="ref" reference="rem: local characterization of generation by D"} $\shH$ is the image of a locally finite map $\oplus_{q}\E_{q}\arr(\oplus_{j}\E_{j})\oplus\overline{\E}$ and, since $\shH\arr\overline{\E}$ is surjective, the induced map $\mu'\colon\oplus_{\E'}\oplus_{\phi\in u^{-1}(\Delta)_{\E'}}\E'\arr\overline{\E}$ is surjective and clearly $u^{-1}(\Delta)=\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu'})$.

::: thm
[]{#prop:test sequences and Extone label="prop:test sequences and Extone"} If $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ then $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$ coincides with the subcategory of $\L_{R}(\shC,A)$ of cohomologically left exact functors.

::: proof
*Proof.* Let $\mu=\oplus_{j}\mu_{j}\colon\oplus_{j\in J}\E_{j}\arr\E$ be a surjective map with $\E,\E_{j}\in\shC$ and set $\Delta=\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu})$, $K=\mathop{\mathrm{\textup{Ker}}}(\Omega^{\mu})$. By [\[rem: local characterization of generation by D\]](#rem: local characterization of generation by D){reference-type="ref" reference="rem: local characterization of generation by D"} there exists a test sequence $\oplus_{k}\E_{k}\arr\oplus_{j}\E_{j}\arrdi{\mu}\E\arr0$. Using [\[lem:almost left exact functors and hom\]](#lem:almost left exact functors and hom){reference-type="ref" reference="lem:almost left exact functors and hom"} we have to prove that if $\Gamma\in\L_{R}(\shC,R)$ is cohomologically left exact then $\lambda\colon\mathop{\mathrm{\textup{Hom}}}(K,\Gamma)\arr\prod_{k}\Gamma_{\E_{k}}$ is injective. Consider the kernel $\shH$ of the difference of the maps $\oplus_{k}\E_{k}\arr\oplus_{j}\E_{j}$ and $\overline{\E}\arr\oplus_{j}\E_{j}$. Since this difference map is locally finite, $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ and using [\[rem: local characterization of generation by D\]](#rem: local characterization of generation by D){reference-type="ref" reference="rem: local characterization of generation by D"} there is a surjective map $\oplus_{t}\E_{t}\arr\shH$ with $\E_{t}\in\shC$ such that $\oplus_{t}\E_{t}\arr\oplus_{k}\E_{k}$ is locally finite and $\oplus_{t}\E_{t}\arr\overline{\E}$ is surjective. We now show how to reduce the number of test sequences in order to check when a $\Gamma\in\L_{R}(\shC,A)$ belongs to $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$. The following is the key lemma:

::: lem
[]{#lem: reducing the set of test sequences label="lem: reducing the set of test sequences"}Let $\Phi'\subseteq\Phi_{\shC}$ such that, for all $\E\in\shC$ and $\Delta\in\Phi_{\shC}(\E)$ there exists $\Delta'\in\Phi'\cap\Phi_{\shC}(\E)$ such that $\Delta'\subseteq\Delta$ (inside $\Omega^{\E}$). If $\Gamma\in\L_{R}(\shC,A)$, $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ and $\Gamma$ is cohomologically left exact on all the elements of $\Phi'$ then $\Gamma$ is cohomologically left exact.
:::

::: proof
*Proof.* Consider $\Delta\in\Phi_{\shC}(\E)$, $\Delta'\subseteq\Delta$ with $\Delta'\in\Phi'$ and the exact sequence $0\arr\Delta/\Delta'\arr\Omega^{\E}/\Delta'\arr\Omega^{\E}/\Delta\arr0$. Applying $\mathop{\mathrm{\textup{Hom}}}(-,\Gamma)$ and using that $\mathop{\mathrm{\textup{Ext}}}^{1}(\Omega^{\E},\Gamma)=0$, the only non trivial vanishing to check is $\mathop{\mathrm{\textup{Hom}}}(\Delta/\Delta',\Gamma)=0$. Write $\Delta'=\mathop{\mathrm{\textup{Im}}}(\Omega^{u})$, where $u\colon\oplus_{q}\E_{q}\arr\E$. We can apply [\[lem:key lemma for reducing test sequences\]](#lem:key lemma for reducing test sequences){reference-type="ref" reference="lem:key lemma for reducing test sequences"} to $K=\Delta$ and the map $\Omega^{u}\colon\oplus_{q}\Omega^{\E_{q}}\arr\Delta$: if $\Omega^{\E'}\arr\Delta\subseteq\Omega^{\E}$ is a map corresponding to $\psi\colon\E'\arr\E$, then $\psi^{-1}(\Delta')\in\Phi_{\shC}$ and, by hypothesis, we can find $\Phi'\ni\mathop{\mathrm{\textup{Im}}}(\Omega^{v})\subseteq\psi^{-1}(\Delta')$; the last inclusion tells us that $v$ is the factorization required for [\[lem:key lemma for reducing test sequences\]](#lem:key lemma for reducing test sequences){reference-type="ref" reference="lem:key lemma for reducing test sequences"}. Thus the map $\mathop{\mathrm{\textup{Hom}}}(\Omega^{u},\Gamma)\colon\mathop{\mathrm{\textup{Hom}}}(\Delta,\Gamma)\arr\mathop{\mathrm{\textup{Hom}}}(\oplus_{q}\Omega^{\E_{q}},\Gamma)$ is injective and, since $\Delta'=\mathop{\mathrm{\textup{Im}}}(\Omega^{u})\subseteq\Delta$, this is also true for the restriction $\mathop{\mathrm{\textup{Hom}}}(\Delta,\Gamma)\arr\mathop{\mathrm{\textup{Hom}}}(\Delta',\Gamma)$, whose kernel is $\mathop{\mathrm{\textup{Hom}}}(\Delta/\Delta',\Gamma)$, as required. ◻
:::

::: prop
[]{# prop: Lex and left exact functors label=" prop: Lex and left exact functors"} Let $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}\stX$ be a subcategory and $\Gamma\in\L_{R}(\shD,A)$. If $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$ then $\Gamma$ is exact on finite test sequences in $\shD$ and transforms arbitrary direct sums in $\shD$ into products. The converse holds if one of the following conditions is satisfied:

-   the category $\shD$ is stable by arbitrary direct sums;

-   all the sheaves in $\shD$ are finitely presented, $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shD}\stX$ and $\stX$ is quasi-compact. In this case $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$ if and only if it is cohomologically left exact on all surjective maps $\E'\arr\E$ with $\E\in\shD$ and $\E'\in\shD^{\oplus}$.

In any of the above cases, if moreover $\shD$ is additive and all surjections in $\shD$ have kernel in $\shD$ then $\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$ is the subcategory of $\L_{R}(\shD,A)$ of left exact functors which transforms arbitrary direct sums in products.
:::

::: proof
*Proof.* If $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$ then it is clearly exact on finite test sequences. Given a set $\{\E_{j}\in\shD\}_{j\in J}$ set $\E=\bigoplus_{j}\E_{j}$. If $\E\in\shD$, then the sequence $$0\arr\bigoplus_{j\in J}\E_{j}\arrdi{\id_{\E}}\E\arr0$$ is a test sequence and therefore we get that the natural map $\Gamma_{\E}\arr\prod_{j}\Gamma_{\E_{j}}$ is an isomorphism. If $\shD$ is stable by arbitrary direct sums is easy to see that the converse holds. Moreover the last part of the statement follows easily from the first part.

So we focus on the second point and we assume that all the sheaves in $\shD$ are finitely presented, $\shD\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shD}\stX$ and that $\stX$ is quasi-compact. Since the class of finitely presented quasi-coherent sheaves on $\stX$ modulo isomorphism is a set, we can assume $\shD=\shC$ small. Let $\Phi'\subseteq\Phi_{\shC}$ be the subset of functors of the form $\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu})$ for some surjective map $\mu\colon\E'\arr\E$ with $\E\in\shC$ and $\E'\in\shC^{\oplus}$. The set $\Phi'$ satisfies the hypothesis of [\[lem: reducing the set of test sequences\]](#lem: reducing the set of test sequences){reference-type="ref" reference="lem: reducing the set of test sequences"}: if $v\colon\oplus_{j\in J}\E_{j}\arr\E$ is a surjective map then there exists a finite subset $J_{0}\subseteq J$ such that $v_{|\E'}\colon\E'=\oplus_{j\in J_{0}}\E_{j}\arr\E$ is surjective because $\E$ is of finite type and $\stX$ is quasi-compact. In particular, taking into account [\[prop:test sequences and Extone\]](#prop:test sequences and Extone){reference-type="ref" reference="prop:test sequences and Extone"}, the last claim of the second point follows. It remains to show that if $\Gamma\in\L_{R}(\shC,A)$ is exact on finite test sequences then $\Gamma$ is cohomologically left exact on all the elements of $\Phi'$. Let $\mu\colon\E'\arr\E$ be a surjective map with $\E\in\shC$ and $\E'\in\shC^{\oplus}$. Since $\E$ is finitely presented and $\E'$ is of finite type it follows that $\mathop{\mathrm{\textup{Ker}}}(\mu)$ is of finite type and, since $\stX$ is quasi-compact and $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$, there exists $\E''\in\shC^{\oplus}$ and a surjective map $\E''\arr\mathop{\mathrm{\textup{Ker}}}(\mu)$. Thus $\E''\arr\E'\arrdi{\mu}\E\arr0$ is a finite test sequence and by [\[lem:almost left exact functors and hom\]](#lem:almost left exact functors and hom){reference-type="ref" reference="lem:almost left exact functors and hom"} it follows that $\Gamma$ is cohomologically left exact on $\mu$ as required. ◻
:::

There is another characterization of $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$ in terms of sheaves on a site. Although we will not use it in this paper, I think it is worth to point out. We refer to [@SP014 Tag 00YW] for general definitions and properties. We start by comparing $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$ and $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC^{\oplus},A)$.

::: prop
[]{#prop:Lex for Coplus and C label="prop:Lex for Coplus and C"} If $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ then the equivalence $\L_{R}(\shC^{\oplus},A)\simeq\L_{R}(\shC,A)$ maps $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC^{\oplus},A)$ to $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,A)$.
:::

::: proof
*Proof.* We can assume $A=R$. Let $\Gamma\in\L_{R}(\shC^{\oplus},R)$ such that $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,R)$ and consider $\Phi'\subseteq\Phi_{\shC^{\oplus}}$ the set of subfunctors $\Delta\subseteq\Omega^{\E}$ that can be written as follows: $\E=\E_{1}\oplus\cdots\oplus\E_{r}$ and there are surjective maps $\mu_{k}\colon\oplus_{q}\E_{q,k}\arr\E_{k}$ for $\E_{k},\E_{q,k}\in\shC$ such that $\Delta=\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu_{1}})\oplus\cdots\oplus\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu_{r}})$. Since for such $\Delta$ we have $$\Omega^{\E}/\Delta\simeq\oplus_{i}(\Omega^{\E_{i}}/\Delta_{i})$$ it follows that $\Gamma$ is cohomologically left exact on all the elements of $\Phi'$. Taking into account [\[prop:test sequences and Extone\]](#prop:test sequences and Extone){reference-type="ref" reference="prop:test sequences and Extone"}, in order to conclude that $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,R)$ we can show that $\Phi'\subseteq\Phi_{\shC^{\oplus}}$ satisfies the hypothesis of [\[lem: reducing the set of test sequences\]](#lem: reducing the set of test sequences){reference-type="ref" reference="lem: reducing the set of test sequences"}. So let $\Delta=\mathop{\mathrm{\textup{Im}}}(\Omega^{\mu})\in\Phi_{\shC^{\oplus}}$ where $\mu\colon\oplus_{q}\E_{q}\arr\E$ where $\E,\E_{q}\in\shC^{\oplus}$. If $\E=\E'_{1}\oplus\cdots\oplus\E'_{r}$ with $\E'_{i}\in\shC$ and $\psi_{i}\colon\E'_{i}\arr\E$ are the inclusions then $\Delta_{i}=\psi_{i}^{-1}(\Delta)\in\Phi_{\shC^{\oplus}}(\E'_{i})=\Phi_{\shC}(\E'_{i})$ and it is easy to see that $\Phi'\ni\Delta_{1}\oplus\cdots\oplus\Delta_{r}\subseteq\Delta$ as required. ◻
:::

::: prop
[]{#prop:Lex and Grothendieck topology label="prop:Lex and Grothendieck topology"} If $\shC\subseteq\mathop{\mathrm{\textup{QCoh}}}^{\shC}\stX$ and $\shJ$ is the smallest Grothendieck topology on $\shC^{\oplus}$ containing $\Phi_{\shC^{\oplus}}$ then $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC^{\oplus},A)$ is the category of sheaves of $A$-modules on $(\shC^{\oplus},\shJ)$ which are $R$-linear.
:::

::: proof
*Proof.* We can assume $A=R$ and $\shC=\shC^{\oplus}$. If $\Delta\subseteq\Omega^{\E}$ is a sieve and $f\colon\E'\arr\E$ we set $f^{-1}(\Delta)=\Delta\times_{\Omega^{\E}}\Omega^{\E'}\subseteq\Omega^{\E'}$. Let $\widetilde{\shJ}$ be the set of sieves $\Delta\subseteq\Omega^{\E}$ of $\shC$ such that, for all $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,R)$ and maps $f\colon\E'\arr\E$ the map $$\mathop{\mathrm{\textup{Hom}}}_{\sets}(\Omega^{\E'},\Gamma)\arr\mathop{\mathrm{\textup{Hom}}}_{\sets}(f^{-1}(\Delta),\Gamma)$$ is bijective. Here $\mathop{\mathrm{\textup{Hom}}}_{\sets}$ denotes the set of natural transformation of functors with values in $\sets$. The set $\widetilde{\shJ}$ is a Grothendieck topology on $\shC$ such that all functors in $\mathop{\mathrm{\textup{Lex}}}_{R}(\shC,R)$ are sheaves. Notice that, by [\[rem: natural transf are linear for additive categories\]](#rem: natural transf are linear for additive categories){reference-type="ref" reference="rem: natural transf are linear for additive categories"}, if $A,B\in\L_{R}(\shC,R)$ then $\mathop{\mathrm{\textup{Hom}}}_{\sets}(A,B)=\mathop{\mathrm{\textup{Hom}}}_{\L_{R}(\shC,R)}(A,B)$. Moreover if $\Delta\in\Phi_{C}$ and $f\colon\E'\arr\E$ is a map in $\shC$ then $\Delta'=f^{-1}(\Delta)\in\Phi_{\shC}$ and if $\Gamma\in\L_{R}(\shC,R)$ then, applying $\mathop{\mathrm{\textup{Hom}}}_{\L_{R}(\shC,R)}(-,\Gamma)$ on the exact sequence $0\arr\Delta'\arr\Omega^{\E'}\arr\Omega^{\E'}/\Delta'\arr0$ and taking into account that $\mathop{\mathrm{\textup{Ext}}}^{1}(\Omega^{\E'},\Gamma)=0$ we obtain an exact sequence $$0\arr\mathop{\mathrm{\textup{Hom}}}(\Omega^{\E'}/\Delta',\Gamma)\arr\mathop{\mathrm{\textup{Hom}}}_{\sets}(\Omega^{\E'},\Gamma)\arr\mathop{\mathrm{\textup{Hom}}}_{\sets}(\Delta',\Gamma)\arr\mathop{\mathrm{\textup{Ext}}}^{1}(\Omega^{\E'}/\Delta',\Gamma)\arr0$$ Thus, if $\shJ$ is the smallest topology on $\shC$ containing $\Phi_{\shC}$ then $\Phi_{\shC}\subseteq\shJ\subseteq\widetilde{\shJ}$ and everything follows easily from [\[prop:test sequences and Extone\]](#prop:test sequences and Extone){reference-type="ref" reference="prop:test sequences and Extone"}. ◻
:::

We now apply [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"} and [\[ prop: Lex and left exact functors\]](# prop: Lex and left exact functors){reference-type="ref" reference=" prop: Lex and left exact functors"} in some (more) concrete situations.

::: thm
[]{#thm:equivalence for QCoh X label="thm:equivalence for QCoh X"} The category $\mathop{\mathrm{\textup{Lex}}}_{R}(\mathop{\mathrm{\textup{QCoh}}}\stX,A)$ is the category of contravariant, $R$-linear and left exact functors $\Gamma\colon\mathop{\mathrm{\textup{QCoh}}}\stX\arr\mathop{\mathrm{\textup{Mod}}}A$ which transform arbitrary direct sums in products. Moreover the functor $$\Omega^{*}\colon\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\mathop{\mathrm{\textup{QCoh}}}\stX,A)$$ is an equivalence of categories.
:::

::: proof
*Proof.* Follows from [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"} and [\[ prop: Lex and left exact functors\]](# prop: Lex and left exact functors){reference-type="ref" reference=" prop: Lex and left exact functors"} with $\shD=\mathop{\mathrm{\textup{QCoh}}}\stX$. ◻
:::

::: thm
[]{#thm:equivalence for noetherian algebraic stacks label="thm:equivalence for noetherian algebraic stacks"} Let $\stX$ be a noetherian algebraic stack. The category $\mathop{\mathrm{\textup{Lex}}}_{R}(\mathop{\mathrm{\textup{Coh}}}\stX,A)$ is the category of contravariant, $R$-linear and left exact functors $\mathop{\mathrm{\textup{Coh}}}\stX\arr\mathop{\mathrm{\textup{Mod}}}A$. Moreover the functor $$\Omega^{*}\colon\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\mathop{\mathrm{\textup{Coh}}}\stX,A)$$ is an equivalence of categories.
:::

::: proof
*Proof.* Follows from [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"} and [\[ prop: Lex and left exact functors\]](# prop: Lex and left exact functors){reference-type="ref" reference=" prop: Lex and left exact functors"}, taking into account that in our assumptions $\mathop{\mathrm{\textup{Coh}}}\stX$ is an abelian category that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$. ◻
:::

::: thm
[]{#thm:equivalence for Loc X label="thm:equivalence for Loc X"} Assume that $\stX$ is quasi-compact and that $\mathop{\mathrm{\textup{Loc}}}\stX$ generates $\mathop{\mathrm{\textup{QCoh}}}\stX$. Then $\mathop{\mathrm{\textup{Lex}}}_{R}(\mathop{\mathrm{\textup{Loc}}}\stX,A)$ is the category of contravariant, $R$-linear and left exact functors $\mathop{\mathrm{\textup{Loc}}}\stX\arr\mathop{\mathrm{\textup{Mod}}}A$. Moreover the functor $$\Omega^{*}\colon\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\mathop{\mathrm{\textup{Loc}}}\stX,A)$$ is an equivalence of categories.
:::

::: proof
*Proof.* Follows from [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"} and [\[ prop: Lex and left exact functors\]](# prop: Lex and left exact functors){reference-type="ref" reference=" prop: Lex and left exact functors"}, taking into account that all surjections in $\mathop{\mathrm{\textup{Loc}}}\stX$ have kernels in $\mathop{\mathrm{\textup{Loc}}}\stX$. ◻
:::

::: thm
[]{#thm:equivalence for affine schemes label="thm:equivalence for affine schemes"} Let $B$ be an $R$-algebra and $\shD\subseteq\mathop{\mathrm{\textup{Mod}}}B$ be a subcategory that generates $\mathop{\mathrm{\textup{Mod}}}B$, that is there exists $\E_{1},\dots,\E_{r}\in\shD$ with a surjective map $\bigoplus_{i}\E_{i}\arr B$. Then the functor $$\Omega^{*}\colon\mathop{\mathrm{\textup{Mod}}}(A\otimes_{R}B)\arr\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$$ is an equivalence of categories. Moreover if $\shD\subseteq\mathop{\mathrm{\textup{Loc}}}B$ then $\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)=\L_{R}(\shD,A)$.
:::

::: proof
*Proof.* If $\stX=\mathop{\mathrm{\textup{Spec}}}B$, then $\mathop{\mathrm{\textup{QCoh}}}_{A}\stX\simeq\mathop{\mathrm{\textup{Mod}}}(A\otimes_{R}B)$ and the first part follows from [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"}. For the last claim, observe that any $\Gamma\colon\mathop{\mathrm{\textup{Loc}}}B\arr\mathop{\mathrm{\textup{Mod}}}A$ is exact because any short exact sequence in $\mathop{\mathrm{\textup{Loc}}}B$ splits. By [\[thm:equivalence for Loc X\]](#thm:equivalence for Loc X){reference-type="ref" reference="thm:equivalence for Loc X"} we can conclude that $\L_{R}(\mathop{\mathrm{\textup{Loc}}}B,A)=\mathop{\mathrm{\textup{Lex}}}_{R}(\mathop{\mathrm{\textup{Loc}}}B,A)$. If now $\shD\subseteq\mathop{\mathrm{\textup{Loc}}}B$ and $\Gamma\in\L_{R}(\shD,A)$, we can extend it to $\overline{\Gamma}\in\L_{R}(\mathop{\mathrm{\textup{Loc}}}B,A)$ and therefore $\Gamma=\overline{\Gamma}_{|\shD}\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$. ◻
:::

We want to extend Theorem [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"} to functors with monoidal structures.

::: defn
If $\shD$ is a monoidal subcategory of $\mathop{\mathrm{\textup{QCoh}}}\stX$ we define $\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)$ (resp. $\mathop{\mathrm{\textup{MLex}}}_{R}(\shD,A)$) as the subcategory of $\mathop{\mathrm{\textup{PML}}}_{R}(\shD,A)$ (resp. $\mathop{\mathrm{\textup{ML}}}_{R}(\shD,A)$) of functors $\Gamma$ such that $\Gamma\in\mathop{\mathrm{\textup{Lex}}}_{R}(\shD,A)$.
:::

::: thm
[]{#thm:fundamental for sheaf of algebras and monoidal functors label="thm:fundamental for sheaf of algebras and monoidal functors"} Let $\shD$ be a monoidal subcategory of $\mathop{\mathrm{\textup{QCoh}}}\stX$ that generates it. Then the functors $$\Omega^{*}\colon\mathop{\mathrm{\textup{Rings}}}_{A}\stX\arr\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)\text{ and }\Omega^{*}\colon\mathop{\mathrm{\textup{QAlg}}}_{A}\stX\arr\mathop{\mathrm{\textup{MLex}}}_{R}(\shD,A)$$ (see [\[prop:Omegastar on algebras\]](#prop:Omegastar on algebras){reference-type="ref" reference="prop:Omegastar on algebras"}) are equivalence of categories. If $\shD$ is small a quasi inverse is given by $\alA_{*,\shD}\colon\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{Rings}}}_{A}\stX$ and $\alA_{*,\shD}\colon\mathop{\mathrm{\textup{MLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{QAlg}}}_{A}\stX$ respectively (see [\[prop: from sheaves to algebras\]](#prop: from sheaves to algebras){reference-type="ref" reference="prop: from sheaves to algebras"}). Moreover if $\overline{\shD}\subseteq\shD$ is a monoidal subcategory that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$ the restriction functors $\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{PMLex}}}_{R}(\overline{\shD},A)$ and $\mathop{\mathrm{\textup{MLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{MLex}}}_{R}(\overline{\shD},A)$ are equivalences.
:::

::: proof
*Proof.* Assume that $\shD$ is small. Then $\Omega^{*}\colon\mathop{\mathrm{\textup{Rings}}}_{A}\stX\arr\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)$ and $\alA_{*,\shD}\colon\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{Rings}}}_{A}\stX$ are quasi-inverses of each other because, by [\[prop: from sheaves to algebras\]](#prop: from sheaves to algebras){reference-type="ref" reference="prop: from sheaves to algebras"}, we have natural transformations $\id\arrdi{\gamma}\Omega^{*}\circ\alA_{*,\shD}$ and $\alA_{*,\shD}\circ\Omega^{*}\arrdi{\beta}\id$ which are isomorphisms thanks to [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"}. In particular if $\overline{\shD}\subseteq\shD$ is a monoidal subcategory that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$ then the restriction functor $\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{PMLex}}}_{R}(\overline{\shD},A)$ is an equivalence. Since $\gamma$ and $\beta$ preserve unities by [\[prop: from sheaves to algebras\]](#prop: from sheaves to algebras){reference-type="ref" reference="prop: from sheaves to algebras"}, the same holds if we replace $\mathop{\mathrm{\textup{Rings}}}_{A}\stX$ by $\mathop{\mathrm{\textup{QAlg}}}_{A}\stX$ and $\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)$ by $\mathop{\mathrm{\textup{MLex}}}_{R}(\shD,A)$. Notice that there exists a small subcategory $\shC'\subseteq\shD$ that generates $\mathop{\mathrm{\textup{QCoh}}}\stX$ thanks to [\[rem: finding small subcategory generating QCoh X\]](#rem: finding small subcategory generating QCoh X){reference-type="ref" reference="rem: finding small subcategory generating QCoh X"}. If $I\subseteq\shD$ is a set we set $\shC_{I}$ for the category containing all tensor products with factors in $C\cup I$ and $\odi{\stX}$. We have that $\shC_{I}$ is a collection of small monoidal subcategories of $\shD$, that generate $\mathop{\mathrm{\textup{QCoh}}}\stX$ and such that $\shC_{I}\subseteq\shC_{I'}$ if $I\subseteq I'$. If $\shC=\shC_{\emptyset}$ we can show that the restrictions $\mathop{\mathrm{\textup{PMLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{PMLex}}}_{R}(\shC,A)$ and $\mathop{\mathrm{\textup{MLex}}}_{R}(\shD,A)\arr\mathop{\mathrm{\textup{MLex}}}_{R}(\shC,A)$ are equivalences by proceeding as in the proof of [\[thm:general theorem for equivalences\]](#thm:general theorem for equivalences){reference-type="ref" reference="thm:general theorem for equivalences"}. All the other claims in the statement follow easily from this fact. ◻

"monoidal functors").

# []{#sec: group schemes representation label="sec: group schemes representation"} Group schemes and representations.

Let $G$ be a flat and affine group scheme over $R$. In this section we want to interpret the results obtained in the case $\stX=\mathop{\mathrm{\textup{B}}}_{R}G$, the stack of $G$-torsors for the *fpqc* topology, which is a quasi-compact fpqc stack with affine diagonal.

If $A$ is an $R$-algebra, by standard theory we have that $\mathop{\mathrm{\textup{QCoh}}}_{A}\mathop{\mathrm{\textup{B}}}_{R}G$ is the category $\mathop{\mathrm{\textup{Mod}}}^{G}A$ of $G$-comodules over $A$. Recall that the regular representation $R[G]$ of $G$ is by definition the $G$-comodule $p_{*}\odi G$. By definition it comes equipped with a morphism of $R$-algebras $\varepsilon\colon R[G]\arr R$ induced by the unit section of $G$.

::: rem
[]{#rem: crucial isomorphism invariants RG and modules label="rem: crucial isomorphism invariants RG and modules"} If $M\in\mathop{\mathrm{\textup{Mod}}}^{G}A$ then the composition $$(M\otimes_{R}R[G])^{G}\arr M\otimes_{R}R[G]\arrdi{\id_{M}\otimes\varepsilon}M$$ is an isomorphism. This follows from [@Jantzen2003 3.4] applied to $G=H$.
:::

We start with a criterion to find a set of generators for $\mathop{\mathrm{\textup{QCoh}}}\mathop{\mathrm{\textup{B}}}_{R}G$.

::: prop
[]{#thm:generating sheaves for BG label="thm:generating sheaves for BG"} If the regular representation $R[G]$ is a filtered direct limit of modules $B_{i}\in\mathop{\mathrm{\textup{Mod}}}^{G}R$ which are finitely presented as $R$-modules then $\{\duale B_{i}\}_{i\in I}$ generates $\mathop{\mathrm{\textup{Mod}}}^{G}R$.
:::

::: proof
*Proof.* Set $B=R[G]$ and $\varepsilon_{i}\colon B_{i}\arr R$ for the composition $B_{i}\arr B\arrdi{\varepsilon}R$ and let $M\in\mathop{\mathrm{\textup{Mod}}}^{G}R$. Since filtered direct limits commute with tensor products and taking invariants, by [\[rem: crucial isomorphism invariants RG and modules\]](#rem: crucial isomorphism invariants RG and modules){reference-type="ref" reference="rem: crucial isomorphism invariants RG and modules"} we have that the limit of the maps $(\varepsilon_{i}\otimes\id_{M})_{|(B_{i}\otimes M)^{G}}\colon(B_{j}\otimes M)^{G}\arr M$ is an isomorphism. This means that for any $m\in M$ there exists $i_{m}\in I$ and an element $\psi_{m}\in(B_{i_{m}}\otimes M)^{G}$ such that $(\varepsilon_{i}\otimes\id_{M})(\psi_{m})=m$. The map $B_{i}\otimes M\arr\mathop{\mathrm{\textup{Hom}}}(\duale{B_{i}},M)$ is $G$-equivariant and therefore we obtain a $\delta_{m}\in\mathop{\mathrm{\textup{Hom}}}^{G}(\duale{B_{i}},M)$ such that $\delta_{m}(\varepsilon_{i})=m$. This implies that the map $$\bigoplus_{m\in M}\delta_{m}\colon\bigoplus_{m\in M}\duale B_{i_{m}}\arr M$$ is surjective and therefore that $M$ is generated by $\{\duale{B_{i}}\}_{i\in I}$. ◻
:::

::: rem
[]{#rem: resolution property for BG cases label="rem: resolution property for BG cases"} The class $\shG_{R}$ of flat, affine group schemes $G$ over $R$ such that $R[G]$ is a direct limit of modules in $\mathop{\mathrm{\textup{Loc}}}(\mathop{\mathrm{\textup{B}}}_{R}G)$ is stable by arbitrary products and projective limits. Moreover by construction contains all groups which are flat, finite and finitely presented over $R$, i.e. $R[G]\in\mathop{\mathrm{\textup{Loc}}}(\mathop{\mathrm{\textup{B}}}_{R}G)$, and thus all profinite groups. Since any $G$-comodule is the union of the sub $G$-comodules which are finitely generated $R$-modules (see [@Jantzen2003 2.13]), we see that $\shG_{R}$ contains all flat groups defined over a Dedekind domain or a field, such as $\mathop{\mathrm{\textup{GL}}}_{r}$, $\text{SL}_{r}$ and all diagonalizable groups. Proposition [\[thm:generating sheaves for BG\]](#thm:generating sheaves for BG){reference-type="ref" reference="thm:generating sheaves for BG"} tells us that if $G\in\shG_{R}$ then $\mathop{\mathrm{\textup{B}}}_{R}G$ has the resolution property.
:::

Let $A$ be an $R$-algebra. We denote by $\mathop{\mathrm{\textup{Loc}}}^{G}A$ the subcategory of $\mathop{\mathrm{\textup{Mod}}}^{G}A$ of $G$-comodules that are locally free of finite rank (projective of finite type) as $A$-modules, so that $\mathop{\mathrm{\textup{Loc}}}(\mathop{\mathrm{\textup{B}}}_{R}G)\simeq\mathop{\mathrm{\textup{Loc}}}^{G}R$. We define $\mathop{\mathrm{\textup{QAdd}}}^{G}A$ ($\mathop{\mathrm{\textup{QPMon}}}^{G}A$, $\mathop{\mathrm{\textup{QMon}}}^{G}A$) as the category of *covariant* $R$-linear (pseudo-monoidal, monoidal) functors $\mathop{\mathrm{\textup{Loc}}}^{G}R\arr\mathop{\mathrm{\textup{Mod}}}A$. We set $\mathop{\mathrm{\textup{QRings}}}^{G}A$ for the category of $M\in\mathop{\mathrm{\textup{Mod}}}^{G}A$ with a $G$-equivariant map $M\otimes_{A}M\arr M$ and $\mathop{\mathrm{\textup{QAlg}}}^{G}A$ for the (not full) subcategory of $\mathop{\mathrm{\textup{QRings}}}^{G}A$ of commutative $R$-algebras.

::: defn
The group $G$ is called *linearly reductive* if the functor $(-)^{G}\colon\mathop{\mathrm{\textup{Mod}}}^{G}R\arr\mathop{\mathrm{\textup{Mod}}}R$ is exact.
:::

::: rem
[]{#rem: LocG R semisimple if G linearly reductive label="rem: LocG R semisimple if G linearly reductive"} If $G$ is linearly reductive then any short exact sequence in $\mathop{\mathrm{\textup{Loc}}}^{G}R$ splits. Indeed if $M\arr N$ is surjective then $\mathop{\mathrm{\textup{Hom}}}_{R}^{G}(N,M)\arr\mathop{\mathrm{\textup{Hom}}}_{R}^{G}(N,N)$ is surjective, yielding a $G$-equivariant section $N\arr M$.
:::

::: thm
[]{#thm:general theorem for BG label="thm:general theorem for BG"} If $\mathop{\mathrm{\textup{B}}}_{R}G$ has the resolution property then the functors $$\mathop{\mathrm{\textup{Mod}}}^{G}A\arr\mathop{\mathrm{\textup{QAdd}}}^{G}A\comma\mathop{\mathrm{\textup{QRings}}}^{G}A\arr\mathop{\mathrm{\textup{QPMon}}}^{G}A\comma\mathop{\mathrm{\textup{QAlg}}}^{G}A\arr\mathop{\mathrm{\textup{QMon}}}^{G}A$$ which maps $M$ to the functor $(-\otimes_{R}M)^{G}\colon\mathop{\mathrm{\textup{Loc}}}^{G}R\arr\mathop{\mathrm{\textup{Mod}}}A$ are well defined, fully faithful and have essential image the subcategory of functors which are left exact on short exact sequences in $\mathop{\mathrm{\textup{Loc}}}^{G}R$. In particular they are equivalences if $G$ is a linearly reductive group.
:::

::: proof
*Proof.* Set $\shC=\mathop{\mathrm{\textup{Loc}}}^{G}R$. The functor $\duale{(-)}\colon\mathop{\mathrm{\textup{Loc}}}^{G}R\arr\mathop{\mathrm{\textup{Loc}}}^{G}R$ is an equivalence and therefore we get equivalences $\mathop{\mathrm{\textup{QAdd}}}^{G}A\simeq\L_{R}(\shC,A)$, $\mathop{\mathrm{\textup{QPMon}}}^{G}A\simeq\mathop{\mathrm{\textup{PML}}}_{R}(\shC,A)$ and $\mathop{\mathrm{\textup{QMon}}}^{G}A\simeq\mathop{\mathrm{\textup{ML}}}_{R}(\shC,A)$. Left exact functors are sent to left exact functors. Under those equivalences $\Omega^{M}$ corresponds to $(-\otimes_{R}M)^{G}$ because $\mathop{\mathrm{\textup{Hom}}}_{\mathop{\mathrm{\textup{B}}}_{R}G}(\duale{\E},M)\simeq\mathop{\mathrm{\textup{H}}}^{0}(\E\otimes_{\odi{\mathop{\mathrm{\textup{B}}}_{R}G}}M)\simeq(\E\otimes_{R}M)^{G}$. Thus the result follows from [\[prop:excatness properties of Omega\* and shF\*\]](#prop:excatness properties of Omega* and shF*){reference-type="ref" reference="prop:excatness properties of Omega* and shF*"}, [\[thm:equivalence for Loc X\]](#thm:equivalence for Loc X){reference-type="ref" reference="thm:equivalence for Loc X"}, [\[thm:rewriting of general equivalences for monoidal functors\]](#thm:rewriting of general equivalences for monoidal functors){reference-type="ref" reference="thm:rewriting of general equivalences for monoidal functors"} and [\[rem: LocG R semisimple if G linearly reductive\]](#rem: LocG R semisimple if G linearly reductive){reference-type="ref" reference="rem: LocG R semisimple if G linearly reductive"}. ◻
:::
