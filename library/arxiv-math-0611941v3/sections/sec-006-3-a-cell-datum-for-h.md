[]{#secDatum label="secDatum"} We keep the notation of the previous sections. In order to show that ${\mathcal{H}}$ is "cellular" in the sense of Graham--Lehrer [@GrLe Definition 1.1], we must specify a quadruple $(\Lambda,M,C,*)$ satisfying the following conditions.

-   $\Lambda$ is a partially ordered set, $\{M(\lambda) \mid
    \lambda \in \Lambda\}$ is a collection of finite sets and $$C \colon \coprod_{\lambda \in \Lambda} M(\lambda)\times M(\lambda)
    \rightarrow {\mathcal{H}}$$ is an injective map whose image is an $A$-basis of ${\mathcal{H}}$;

-   If $\lambda \in \Lambda$ and ${\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)$, write $C({\mathfrak{s}},{\mathfrak{t}})=C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda \in {\mathcal{H}}$. Then $* \colon {\mathcal{H}}\rightarrow 
    {\mathcal{H}}$ is an $A$-linear anti-involution such that $(C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda)^*=
    C_{{\mathfrak{t}},{\mathfrak{s}}}^\lambda$.

-   If $\lambda \in \Lambda$ and ${\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)$, then for any element $h \in {\mathcal{H}}$ we have $$hC_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda\equiv \sum_{{\mathfrak{s}}'\in M(\lambda)} r_h({\mathfrak{s}}',{\mathfrak{s}})\,
    C_{{\mathfrak{s}}',{\mathfrak{t}}}^\lambda\quad \bmod {\mathcal{H}}(<\lambda),$$ where $r_h({\mathfrak{s}}',{\mathfrak{s}}) \in A$ is independent of ${\mathfrak{t}}$ and where ${\mathcal{H}}(<\lambda)$ is the $A$-submodule of ${\mathcal{H}}_n$ generated by $\{C_{{\mathfrak{s}}'',{\mathfrak{t}}''}^\mu
    \mid \mu <\lambda; {\mathfrak{s}}'',{\mathfrak{t}}''\in M(\mu)\}$.

We now define a required quadruple $(\Lambda,M,C,*)$ as follows.

Let $\Lambda$ be an indexing set for the irreducible representations of $W$, as in §[\[sub21\]](#sub21){reference-type="ref" reference="sub21"}. Using the ${\mathbf{a}}$-invariants in §[\[sub22\]](#sub22){reference-type="ref" reference="sub22"}, we define a partial order $\preceq$ on $\Lambda$ by $$\lambda \preceq \mu \qquad \stackrel{\text{def}}{\Leftrightarrow} \qquad
\lambda=\mu \quad \mbox{or}\quad {\mathbf{a}}_\lambda >{\mathbf{a}}_\mu.$$ Thus, $\Lambda$ is ordered according to *decreasing* ${\mathbf{a}}$-value. Next, we define an $A$-linear anti-involution $* \colon {\mathcal{H}}\rightarrow {\mathcal{H}}$ by $T_w^*=T_{w^{-1}}$ for all $w \in W$. Thus, $T_w^*=T_w^{\,\flat}$ in the notation of [@Lusztig03 3.4].

For $\lambda\in \Lambda$, we set $M(\lambda)=\{1,\ldots,d_\lambda\}$ as before. The trickiest part is, of course, the definition of the basis elements $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$ for ${\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)$. We can now state the main result of this paper.

::: theorem
[]{#mainthm label="mainthm"} Recall that Lusztig's conjectures **(P1)**--**(P15)** are assumed to hold for ${\mathcal{H}}$. Let $R \subseteq {\mathbb{C}}$ be a subring such that all $L$-bad primes are invertible in $R$. Let $\bigl(\rho_{{\mathfrak{s}}{\mathfrak{t}}}^\lambda(t_w)\bigr)$ and $\bigl(\beta_{{\mathfrak{s}}
{\mathfrak{t}}}^\lambda\bigr)$ be as in Proposition [\[lem1\]](#lem1){reference-type="ref" reference="lem1"}. For any $\lambda 
\in \Lambda$ and ${\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)$, define $$C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda=\sum_{w \in W} \sum_{{\mathfrak{u}}\in M(\lambda)} \hat{n}_w
\hat{n}_{w^{-1}}\,\beta^\lambda_{{\mathfrak{t}}{\mathfrak{u}}}\,\rho_{{\mathfrak{u}}{\mathfrak{s}}}^\lambda\, 
(t_{w^{-1}})\, c_w^\dagger.$$ Then $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$ is a ${\mathbb{Z}}$-linear combination of Kazhdan--Lusztig basis elements $c_w^\dagger$ where ${\mathbf{a}}(w)={\mathbf{a}}_\lambda$. The quadruple $(\Lambda,M,C,*)$ is a "cell datum" in the sense of Graham--Lehrer [@GrLe].
:::

::: proof
*Proof.* First note that, by [@Lusztig03 Prop. 20.6], we have $\rho^\lambda(t_{w^{-1}})=0$ unless ${\mathbf{a}}(w)={\mathbf{a}}_\lambda$. Thus, $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$ is an integral linear combination of elements $c_w^\dagger$ where ${\mathbf{a}}(w)={\mathbf{a}}_\lambda$. In what follows, it will be convenient to write the coefficients occurring in various sums as entries of matrices. Thus, for example, the defining formula for $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$ reads: $$\begin{aligned}
C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda&=\sum_{w \in W} \hat{n}_w\hat{n}_{w^{-1}}\,\bigl(
B^\lambda \cdot\rho^\lambda(t_{w^{-1}})\bigr)_{{\mathfrak{t}},{\mathfrak{s}}}\, c_w^\dagger\\
&= \sum_{w \in W} \hat{n}_w\hat{n}_{w^{-1}}\,\bigl(\rho^\lambda
(t_w)^{\text{tr}}\cdot B^\lambda\bigr)_{{\mathfrak{t}},{\mathfrak{s}}}\, c_w^\dagger,
\end{aligned}$$ where the second equality holds by Proposition [\[lem1\]](#lem1){reference-type="ref" reference="lem1"}. We now proceed in three steps.

*Step 1*. (C1) holds, that is, the elements $\{C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda 
\mid \lambda \in \Lambda \mbox{ and }  {\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)\}$ form a basis of ${\mathcal{H}}$. This is proved as follows. By Wedderburn's Theorem, $\dim {\mathcal{H}}_K= |W|=\sum_{\lambda \in \Lambda} |M(\lambda)|^2$. Hence the above set has the correct cardinality. It is now sufficient to show that the elements $\{C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda\}$ span ${\mathcal{H}}$ as an $A$-module.

Let us fix $y \in W$. We consider the following $R$-linear combination: $$\sum_{\lambda \in \Lambda} \sum_{{\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)} \frac{1}{f_\lambda} 
\,\bigl(\rho^\lambda(t_y)\cdot (B^\lambda)^{-1}\bigr)_{{\mathfrak{s}},{\mathfrak{t}}}\, 
C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda.$$ Note that the coefficients lie in $R$ since $f_\lambda$ and $\det(B^\lambda)$ are invertible in $R$. Inserting the first of the above-mentioned two expressions for $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$, we obtain: $$\sum_{w\in W} \hat{n}_w\hat{n}_{w^{-1}}
\sum_{\lambda \in \Lambda} \sum_{{\mathfrak{s}}\in M(\lambda)} \frac{1}{f_\lambda} \,
\bigl(\rho^\lambda(t_y)\cdot \rho^\lambda(t_{w^{-1}})\bigr)_{{\mathfrak{s}},{\mathfrak{s}}}\,
c_w^\dagger.$$ Now, writing out the product $\rho^\lambda(t_y)\cdot 
\rho^\lambda(t_{w^{-1}})$ and using the "second" Schur relations, we find that $$\sum_{\lambda \in \Lambda} \sum_{{\mathfrak{s}}\in M(\lambda)} \frac{1}{f_\lambda} \,
\bigl(\rho^\lambda(t_y)\cdot \rho^\lambda(t_{w^{-1}})\bigr)_{{\mathfrak{s}},{\mathfrak{s}}} =
\delta_{yw}.$$ Hence our linear combination reduces to $\hat{n}_y\hat{n}_{y^{-1}}\, 
c_y^\dagger=\pm c_y^\dagger$. Thus, $c_y^\dagger$ is an $R$-linear combination of the elements $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$, as required.

*Step 2*. (C2) holds, that is, we have $(C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda)^*=C_{{\mathfrak{t}},{\mathfrak{s}}}^\lambda$ for all $\lambda \in \Lambda$ and ${\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)$. This is seen as follows. By [@Lusztig03 4.9 and 5.6], we have $(c_w^\dagger)^*=(c_w^*)^\dagger= c_{w^{-1}}^\dagger$. Thus, using the above two expressions for $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$, we obtain: $$\begin{aligned}
(C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda)^* &= \sum_{w \in W} \hat{n}_w\hat{n}_{w^{-1}}\,\bigl(
B^\lambda \cdot \rho^\lambda(t_{w^{-1}})\bigr)_{{\mathfrak{t}},{\mathfrak{s}}}\, 
c_{w^{-1}}^\dagger\\ &= \sum_{w \in W} \hat{n}_w\hat{n}_{w^{-1}}\,\bigl(
\rho^\lambda(t_w)^{\operatorname{tr}}\cdot B^\lambda\bigr)_{{\mathfrak{t}},{\mathfrak{s}}}\, 
c_{w^{-1}}^\dagger\\ &= \sum_{w \in W} \hat{n}_w\hat{n}_{w^{-1}}\,
\bigl( B^\lambda \cdot \rho^\lambda(t_w)\bigr)_{{\mathfrak{s}},{\mathfrak{t}}}\, 
c_{w^{-1}}^\dagger = C_{{\mathfrak{t}},{\mathfrak{s}}}^\lambda,
\end{aligned}$$ as required.

*Step 3*. Finally, we consider the multiplication rule (C3). By Lusztig [@Lusztig03 18.10], there is a natural left $J_A$-module structure on ${\mathcal{H}}$ given by the formula $$t_x * c_w^\dagger=\sum_{z \in W} \gamma_{x,w,z^{-1}}\, \hat{n}_w\,
\hat{n}_z\, c_z^\dagger \qquad (x,w \in W).$$ We begin by studying the effect of the $J_A$-action on the element $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$. Let $x \in W$. We claim that $$t_x * C_{{\mathfrak{s}},{\mathfrak{t}}}=\sum_{{\mathfrak{s}}'\in M(\lambda)} \rho^\lambda_{{\mathfrak{s}}'{\mathfrak{s}}}(t_x)
\, C_{{\mathfrak{s}}', {\mathfrak{t}}}.$$ Indeed, recalling the defining formula for $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$, we have: $$\begin{aligned}
t_x * C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda &=
\sum_{w \in W} \sum_{{\mathfrak{u}}\in M(\lambda)} \hat{n}_w \hat{n}_{w^{-1}}\, 
\beta_{{\mathfrak{t}}{\mathfrak{u}}}^\lambda\, \rho_{{\mathfrak{u}}{\mathfrak{s}}}^\lambda(t_{w^{-1}})\, t_x * 
c_w^\dagger\\ &=\sum_{w,z \in W} \sum_{{\mathfrak{u}}\in M(\lambda)} \hat{n}_z
\hat{n}_{w^{-1}}\, \beta_{{\mathfrak{t}}{\mathfrak{u}}}^\lambda\, \rho_{{\mathfrak{u}}{\mathfrak{s}}}^\lambda(
t_{w^{-1}}) \, \gamma_{x,w,z^{-1}} \, c_z^\dagger.
\end{aligned}$$ Assume that the term in the sum corresponding to $w,z\in W$ is non-zero. Then $\gamma_{x,w,z^{-1}}\neq 0$ and so $w \sim_{{\mathcal{L}}} z$, by property **(P8)** in [@Lusztig03 14.2]. Hence $w^{-1}\sim_{{\mathcal{R}}}z^{-1}$ and so $\hat{n}_{w^{-1}}=\hat{n}_{z^{-1}}$. Furthermore, $\gamma_{x,w,z^{-1}}
=\gamma_{z^{-1},x,w}$ by property **(P7)** in [@Lusztig03 14.2]. Thus, we obtain $$\begin{aligned}
t_x * C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda &=
\sum_{z \in W} \sum_{{\mathfrak{u}}\in M(\lambda)} \hat{n}_z\hat{n}_{z^{-1}}\,
\beta_{{\mathfrak{t}}{\mathfrak{u}}}^\lambda\, \rho_{{\mathfrak{u}}{\mathfrak{s}}}^\lambda\Bigl(\sum_{w \in W}
\gamma_{z^{-1},x,w} t_{w^{-1}}\Bigr)\,c_z^\dagger\\
&=\sum_{z \in W} \sum_{{\mathfrak{u}}\in M(\lambda)}\hat{n}_z\hat{n}_{z^{-1}}\,
\beta_{{\mathfrak{t}}{\mathfrak{u}}}^\lambda\,\rho_{{\mathfrak{u}}{\mathfrak{s}}}^\lambda\bigl(t_{z^{-1}}\, t_x\bigr)
\,c_z^\dagger\\
&=\sum_{z \in W} \hat{n}_z\hat{n}_{z^{-1}}\,\bigl(B^\lambda\cdot
\rho^\lambda(t_{z^{-1}}t_x)\bigr)_{{\mathfrak{t}},{\mathfrak{s}}}\, c_z^\dagger\\ 
&=\sum_{z \in W} \sum_{{\mathfrak{s}}'\in M(\lambda)}\hat{n}_z\hat{n}_{z^{-1}}\,
\bigl(B^\lambda\cdot \rho^\lambda(t_{z^{-1}})\bigr)_{{\mathfrak{t}},{\mathfrak{s}}'}\,
\rho_{{\mathfrak{s}}'{\mathfrak{s}}}^\lambda(t_x)\, c_z^\dagger\\ &=\sum_{{\mathfrak{s}}'\in M(\lambda)} 
\rho^\lambda_{{\mathfrak{s}}'{\mathfrak{s}}}(t_x)\, C_{{\mathfrak{s}}',{\mathfrak{t}}},
\end{aligned}$$ as claimed. Now let $h \in {\mathcal{H}}$ and write $\phi(h)=\sum_{x \in W} a_h(x)\,t_x$ where $a_h(x) \in A$. Then define $$r_h({\mathfrak{s}}',{\mathfrak{s}})=\sum_{x \in W} a_h(x)\, \rho^\lambda_{{\mathfrak{s}}'{\mathfrak{s}}}(t_x)
 \quad \mbox{for any ${\mathfrak{s}}',{\mathfrak{s}}\in M(\lambda)$}.$$ Note that, indeed, this coefficient lies in $A$ and it only depends on ${\mathfrak{s}},{\mathfrak{s}}'$ and $h$. Then the above computation shows that $$\phi(h) * C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda=\sum_{{\mathfrak{s}}' \in M(\lambda)} r_h({\mathfrak{s}}',{\mathfrak{s}})\, 
C_{{\mathfrak{s}}',{\mathfrak{t}}}^\lambda.$$ For any $a \geqslant 0$, we define ${\mathcal{H}}^{\geqslant a}$ to be the $A$-span of all elements $c_y^\dagger$ where $y \in W$ is such that ${\mathbf{a}}(y)\geqslant a$. By [@Lusztig03 18.10(a)], we have $$hc_w^\dagger\equiv\phi(h)*c_w^\dagger\quad\bmod{\mathcal{H}}^{\geqslant{\mathbf{a}}(w)+1}
\quad \mbox{for any $h \in {\mathcal{H}}$ and $w \in W$}.$$ We have already noted in the beginning of the proof that $C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda$ is a linear combination of elements $c_z^\dagger$ where ${\mathbf{a}}(z)= {\mathbf{a}}_\lambda$. Hence the above relations imply that $$hC_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda \equiv \phi(h)*C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda \equiv 
\sum_{{\mathfrak{s}}'\in M(\lambda)} r_h({\mathfrak{s}}',{\mathfrak{s}})\, C_{{\mathfrak{s}}',{\mathfrak{t}}}^\lambda \quad \bmod 
{\mathcal{H}}^{\geqslant{\mathbf{a}}_{\lambda}+1}.$$ The definition of the partial order $\preceq$ on $\Lambda$ now shows that (C3) holds. ◻
:::

::: corollary
[]{#cor1 label="cor1"} Let $\theta \colon A \rightarrow k$ be a ring homomorphism into an integral domain $k$ (i.e., a "specialisation"). By extension of scalars, we obtain a $k$-algebra ${\mathcal{H}}_k=k \otimes_A {\mathcal{H}}$. Then the above ingredients define a "cell datum" for ${\mathcal{H}}_k$, where $$C_{{\mathfrak{s}},{\mathfrak{t}}}^\lambda=\sum_{w \in W} \sum_{{\mathfrak{u}}\in M(\lambda)} 
\hat{n}_w\hat{n}_{w^{-1}}\,\theta(\beta^\lambda_{{\mathfrak{t}}{\mathfrak{u}}})\,\theta
\bigl(\rho_{{\mathfrak{u}}{\mathfrak{s}}}^\lambda\, (t_{w^{-1}}) \bigr)\, (1 \otimes c_w^\dagger)
\in {\mathcal{H}}_k,$$ for $\lambda \in \Lambda$ and ${\mathfrak{s}},{\mathfrak{t}}\in M(\lambda)$.
:::

::: proof
*Proof.* This immediately follows from Theorem [\[mainthm\]](#mainthm){reference-type="ref" reference="mainthm"}; see the remarks in [@GrLe (1.8)]. ◻
:::

Thus, since Lusztig's conjectures **(P1)**--**(P15)** hold in the "equal parameter" case, we have proved Theorem [\[thmb\]](#thmb){reference-type="ref" reference="thmb"}, as stated in the introduction.

::: remark
[]{#noncryst label="noncryst"} Assume that $W$ is a finite Coxeter group which is not a Weyl group, i.e., $W$ is of type $H_3$, $H_4$ or $I_2(m)$ where $m=5$ or $m\geqslant 7$. In these cases, ${\mathbb{Q}}$ is no longer a splitting field for $W$, and this leads to some technical complications. However, choosing $R\subseteq {\mathbb{C}}$ appropriately, Theorem [\[mainthm\]](#mainthm){reference-type="ref" reference="mainthm"} remains valid in these cases as well.

First note that Lusztig's properties **(P15)**--**(P15)** (see §[\[sub24\]](#sub24){reference-type="ref" reference="sub24"}) are known to hold for types $H_3$, $H_4$ and $I_2(m)$ (where $L$ is a positive multiple of the length function), thanks to DuCloux [@Fokko]. (As far as we know, these properties do not seem to have been verified in type $I_2(m)$ with unequal parameters.)

Now, the irreducible representations in type $H_3$, $H_4$ and $I_2(m)$ (and much further information) are explicitly known; see [@GePf §8.1 and §11.2]. Using this explicit information, one can show that Theorem [\[mainthm\]](#mainthm){reference-type="ref" reference="mainthm"} holds if we require that the subring $R \subseteq {\mathbb{C}}$ satisfies the following two conditions: (1) $R$ contains $\zeta+\zeta^{-1}$ where $\zeta$ is a root of unity of order $5$ (in type $H_3$, $H_4$) or $m$ (in type $I_2(m)$); (2) the order of $W$ is invertible in $R$.

A more detailed discussion of these cases will appear elsewhere.

Jeong et al. [@kor] point out that Fakiolas [@Fak] also produces a cellular basis in type $I_2(m)$ where $L$ is a positive multiple of the length function.
:::
