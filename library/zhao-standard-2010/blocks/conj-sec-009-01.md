Let (R, ZR) = (R, Z) if N = 1, and (R, ZR) = (C, Z) if N = 2, 3 or N = pn with prime p ≥5. If N = 1 (resp. N = 2) then the map ϕR is injective, namely, the algebra of MPVs of level one or two is isomorphic to RRDS (resp. RSR). If N = 3 or N = pn (p ≥5) then the map ϕC is injective so the algebra of MPVs of level N is isomorphic to RSR. The above conjecture generalizes [24, Conjecture 1]. It means that all the linear relations among MPVs can be produced by RDS when N = 1 or 2, and by the standard ones when N = 3 or pn with prime p ≥5.
