If N is a standard level then the standard relations always provide the sharp bounds of d(w, N), namely, all linear relations can be derived from the standard ones, if further N > 3 then the bound D(w, N) in (36) by Deligne and Goncharov can be lowered. If N is a non-standard level then the bound D(w, N) is sharp and there exists a positive integer w0(N) so that at least one non-standard relation exists in MPV(w, N) for each w ≥w0(N).
