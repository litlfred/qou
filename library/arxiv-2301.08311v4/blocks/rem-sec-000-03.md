The algebraic relation between the local systems in Theorem 1.2 matches with the mutation formulae present in the literature. When n = 2, this formula matches with the expected change in the local system needed for invariance under Lagrangian surgery as done in [Aur07], [Sei13], [PW19]. For higher dimensions, it agrees with the mutation formula for monotone Lagrangian torus in [PT20], see the relation (1.2.3).
