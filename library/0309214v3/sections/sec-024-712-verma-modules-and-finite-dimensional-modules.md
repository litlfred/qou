If (λ|αi) < 0 for all i = 1, ..., ℓthen M(λ) is irreducible. On the other hand
if (λ|αi) ≥0 for all i = 1, ..., ℓ(ie, λ is dominant), then M(λ) has a unique
proper maximal submodule, and the quotient L(λ) of M(λ) by the proper
maximal submodule is a ﬁnite dimensional module (of type 1, see [17]). Every
ﬁnite dimensional module of type 1 of U is a direct sum of several L(λ).
