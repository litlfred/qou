Let C = c R× × R× be the self-dual Gaussian group used for the state variables. It acts (by pointwise multiplication) on the boundary edge chain group C1(∂X; Z). After we integrate out the internal face variables and impose the face–pairing constraints, the resulting tempered distribution is supported on assignments that satisfy the edge relations; hence it factors through edge homology: FF,M : A(∂X)2 −→H1(∂M; C) −→C. Each boundary component of M is a torus, so H1(∂M; Z) is free abelian. For a free abelian group F there is a canonical isomorphism F ⊗C ∼= Hom(F, C); hence H1(∂M; C) = H1(∂M) ⊗C ∼= Hom(H1(∂M), C).
