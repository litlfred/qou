Inversion relation: There exists a nonzero constant c ∈C \ {0} such that φ(x)φ(−x) = c · ⟨x⟩ (3.1) for almost all x ∈G. 2. Pentagon identity: For almost all pairs (x, y) ∈G × G, we have φ(x)φ(y) = γ Z G3 ⟨x −u; y −w⟩ ⟨u −v + w⟩φ(u)φ(v)φ(w)dudvdw, (3.2) where the constant γ := Z G ⟨x⟩dx is defined as an (improper) integral over G.
