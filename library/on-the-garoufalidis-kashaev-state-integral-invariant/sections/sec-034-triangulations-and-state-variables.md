Triangulations and State Variables
Let X be a finite ∆–complex obtained by gluing the faces of a finite collection
of oriented tetrahedra in pairs; see Hatcher [9] for background on ∆–complexes. We
denote
• X3 – the set of tetrahedra;
• X2 – the set of triangular faces;
• (∂X)2 ⊂X2 – those faces that are not glued to a partner face. (These are the
genuine boundary faces of the 3–complex; note the round bracket: (∂X)2̸ =
∂X2, the latter being the set of edges in the boundary of the 2–skeleton.)
Ideal–triangulated knot complements.
If X is an ideal triangulation of a knot
(or link) complement, all vertices are removed (i.e., placed at infinity, as in a classical
ideal triangulation), and every triangular face is paired—then (∂X)2 is empty. We
distinguish (∂X)2, the unglued triangular faces, from ∂X2, the boundary of the
2-skeleton, which consists of edges. The geometric boundary re-appears only after
truncating the ideal vertices, producing polygonal faces that are not part of the
original set X2. Consequently, when we specialise to such a manifold we integrate
31
only over internal state variables; no boundary-face variables are present in the
state-integral itself. Holonomy variables for the peripheral torus are introduced after
truncation, when we define the tempered distribution supported on the geometric
boundary.
