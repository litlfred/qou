Structure Theorem (Informal)
Every LCA group decomposes (non-canonically) into:
Theorem 1 (Structure Theorem (informal)). Any LCA group L admits an isomor-
phism
L ∼= Rn × D × K,
where D is discrete, K is compact, and n ∈Z≥0 (the set on non-negative integers).
