Gaussian Group
A Gaussian Group developed in previous works [2, 13] and denominated in [7].
Definition 4. Let G be a locally compact abelian (LCA) group. A Gaussian group
is a pair (G, ⟨·⟩) where
⟨·⟩: G →T
is a continuous function, called a quadratic exponential, satisfying:
1. Evenness: ⟨x⟩= ⟨−x⟩for all x ∈G.
2. Polarization: the function
⟨x; y⟩:= ⟨x + y⟩
⟨x⟩⟨y⟩
defines a continuous, symmetric bicharacter ⟨·; ·⟩: G × G →T, meaning:
⟨x + x′; y⟩= ⟨x; y⟩⟨x′; y⟩,
⟨x; y + y′⟩= ⟨x; y⟩⟨x; y′⟩,
⟨x; y⟩= ⟨y; x⟩.
Remark 1. For any quadratic exponential ⟨·⟩on a Gaussian group G, the polarization
identity satisfies:
⟨x; x⟩= ⟨x⟩2
for all x ∈G.
This follows directly from applying the definition to 0 = x + (−x), using evenness
and symmetry.

Remark 2. Similarly, one obtains ⟨2x⟩= ⟨x⟩4 and recovers the same identity from
the definition of the Polarization.
Remark 3.
• The function ⟨·⟩generalizes the Gauss character (quadratic expo-
nential), serving as a quadratic refinement of the Fourier kernel.
• The symmetric bicharacter ⟨x; y⟩captures the failure of ⟨·⟩to be additive,
encoding it in a bilinear form.
