The State-Integral Definition
The Archimedean state-integral is defined as:
FR,X,θ(y) :=
Z
AX3
KX(y, z) · DX,θ(z)dz.
(4.3)
• If (∂X)2 = ∅, this integral yields a scalar.
• If (∂X)2̸ = ∅, it yields a tempered distribution in the boundary variables y ∈
A∂X2.
Remark 7. In physical terms, FR,X,θ(y) may be viewed as a quantum wavefunction
encoding boundary holonomy data within the Chern–Simons framework [19, 4].
