Angle Structures and Parameter Dependence
• The state-integral requires a choice of balanced angle structure:
θ ∈Angle(X) ⊆CX3,1, with C := R × F ×,
satisfying compatibility constraints (tetrahedra and edge balancing).
• The angle structure θ determines the dilogarithmic deformation parameters
(a, c) ∈C used in each quantum weight Ψa,c.
• The target space S′(A(∂X)2) does not depend on θ itself; rather, θ determines
the integrand of the state-integral.

• Invariance under angle gauge transformations ensures that the output depends
only on the gauge equivalence class of θ.
