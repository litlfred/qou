We say that a formal power series φ(z) is Gevrey-1 if there exist A, B > 0 such that |an| ≤ABnΓ(n + 1), (n ≥0), where Γ is the gamma function. Here, we note that Γ(n + 1) equals n! since n ∈N. We choose to use the gamma function throughout the paper, even when the factorial suffices, since it will allow for a uniform treatment of all of our cases. In order to build the theory of resurgence, we will first need to define the Borel and Laplace transforms. Here, we introduce shifted versions of these transforms which will more readily suit our needs.
