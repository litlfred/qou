Let τ be an ideal triangulation of M, containing n tetrahe- dra. The set of all ways to assign a real number to each pair of opposite edges of each tetrahedron is naturally identiﬁed with R3n. Then A(τ) is a convex, ﬁnite–sided, bounded polytope in R3n. If A(τ)̸ = ∅, its dimension is dim A(τ) = |τ| + |∂M|, where |τ| = n is the number of tetrahedra and |∂M| is the number of boundary tori in M.
