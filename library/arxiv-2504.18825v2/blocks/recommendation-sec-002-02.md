A generalized $m$-multi-ribbon tableau $\bm{\T}$ can also be described by a tuple of tableaux, in which the cells of each partition are marked $i_j$ $(i\geq 1, j\geq 1)$, satisfying \begin{enumerate}[label=(\roman*)] \item the numbers $i_j$ inserted in the diagram of each partition of $\bm{\T}$ must increase weakly down each column and along each row from left to right; \item the cells marked same number consist of a generalized $m$-multi-ribbon. \end{enumerate} The {\it content} of $\bm{\T}$ is defined as a multicomposition $\bm{c}=(c^{(1)},c^{(2)},\cdots)$ such that $c^{(i)}_j$ equals the number of cells marked $i_j$ in $\bm{\T}$.
