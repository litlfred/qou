Before we start we must point out the following identity (valid for any 3-form $\gamma$ on $M\times M\times M$ and vector fields $X_1,X_2,X_3$ on $M$) $$(\iota_{X_1}\iota_{X_2}\iota_{X_3}\gamma)\wedge\mu\wedge\mu\wedge\mu= \gamma(X_1,X_2,X_3)\,\mu\wedge\mu\wedge\mu=\gamma\wedge\iota_{X_1}\mu\wedge\iota_{X_2}\mu\wedge\iota_{X_3}\mu\ .$$ The first equation follows from the definition, the second equation is a consequence of the fact that $\iota_X$ is an antiderivation i.e. $$\label{eq:iota-antiderivation} \iota_X(\alpha\wedge\beta)=(\iota_X\alpha)\wedge\beta+(-1)^{|\alpha|}\alpha\wedge(\iota_X\beta),$$ and $\iota_{X_i}\mu_j\equiv 0$ for $i\neq j$.
