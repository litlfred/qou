The function Lig(z), extended as above to C \ [1, 00), jumps by 27% log |z| as
z crosses the cut. Thus the function Lig(z) + iarg(1 — z) log|z|, where arg
denotes the branch of the argument lying between —7 and 7, is continuous.
Surprisingly, its imaginary part

D(z) = S(Lig(z)) + arg(1 — z) log |z|
is not only continuous, but satisfies
