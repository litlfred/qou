Examples of Hopf algebras which are spherical are: (1) Any involutory Hopf algebra is spherical. The element w can be taken to be 1. (2) Any ribbon Hopf algebra, as deﬁned in [Reshetikhin and Turaev 1990], is spherical. The element w can be taken to be uv−1 where the element u is determined by the quasi-triangular structure and the element v is the ribbon element.
