Tracing the map in the new type $A F$ from $A S$ to $\boldsymbol{\operatorname{{FinSet_0}}}$, we note that we can pass through $S$ so that $A F = P_2;\alpha$, in which case we see that since $\alpha$ must make the lower triangle commmute so that $\alpha;+\{\star\}=F$ we get that the preimage of a given finite set $S$ under $A F$ must correspond to the preimage of $S+\{\star\}$ under $F$.
