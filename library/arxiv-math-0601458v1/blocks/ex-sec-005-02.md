A categoriﬁed state is just a structure type. One such type is “being a ﬁnite set”, which we can denote EZ (E from the French “ensemble”, but also appropriate in light of the generating series for this type). Then putting an A(EZ)- structure on a ﬁnite set S is the same as putting an EZ structure on S ∪⋆, and there is exactly one way to put an EZ-structure on ANY ﬁnite set, hence exactly one way to put an A(EZ)-structure on S as well. That is, A(EZ) = EZ. This makes sense, since |EZ| = ez, and so this equation becomes ∂ ∂zez = ez when we take its cardinality.
