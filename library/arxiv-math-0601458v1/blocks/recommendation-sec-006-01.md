We have described a structure type as a functor $F \in \boldsymbol{\operatorname{{Set [ Z ]}}}$, where the image of each finite set $S$ is the set of structures "of type $F$" which can be put on $S$, but it should be obvious that the category $\boldsymbol{\operatorname{{Set}}}$ is rather larger than we need, since for most sorts of structures we can think of, almost all sets will not appear in the image at all - most are not sets of $F$ structures on an $n$-element set for any $F$ or $n$.
