Consider the structure type O, “being a totally ordered ﬁnite set” (or “of total orderings on a ﬁnite set”). There are n! such structures on a ﬁnite set n, so we can see this type as isomorphic to (18) 1 −Z = ∞ X n=0 Zn (since Zn is the type of totally ordered n-element sets). Here, the sum is to be understood as a coproduct. Then to put an A(O)-structure on a set S, one puts a total order on S ∪{⋆}: this amounts to splitting S into two (ordered) parts and putting a total order on each part.
