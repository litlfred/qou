Remark 8.47. The answer to Question 8.45 is “no” for triangular Hopf algebras,
as follows from [EG3]. However, if the answer is “yes” in general, then it is “yes” al-
ready for quasitriangular Hopf algebras. Indeed, if Rep( D(H)) is group-theoretical
then so is Rep( H) ⊗ Rep(H ∗cop) (as a dual category to Rep D(H)), from which it
follows by Proposition 8.44 that so is Rep( H).
