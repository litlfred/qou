Remark 2.34. One says that an indecomposable multi-fusion category C′ is a
quotient category of an indecomposable multi-fusion category C if there exists a
tensor functor F : C →C′ such that any object of C′ is a subobject of F(X), X ∈C
(See Section 5). It follows from the above that a given multi-fusion category C has
only ﬁnitely many quotient categories.
Corollary 2.35. A module category M over a multi-fusion category C does not
admit nontrivial deformations. In particular, the number of such module categories
(up to equivalence) with a given number of simple objects is ﬁnite.
To prove Corollary 2.35, it suﬃces to choose a semisimple algebra R with number
of blocks equal to the number of simple objects in M, and apply Theorem 2.31 to
the functor F : C →R −bimod associated with M.
Remark 2.36. We note that this result was conjectured in [O].
