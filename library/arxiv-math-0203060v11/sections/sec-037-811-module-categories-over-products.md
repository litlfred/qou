Proposition 8.55. Let C, D be nondegenerate fusion categories with coprime Frobenius-
Perron dimensions. Then any indecomposable module categor y over C⊗D is M⊗N ,
where M is an indecomposable module category over C, and N over D.
Proof. Let B be an indecomposable module category over C ⊗ D . Let us restrict it
to C. We get B|C = ⊕iMi, where Mi are indecomposable. Thus the action of D on
B can be regarded as a tensor functor F : D → ⊕i,jFunC(Mi, Mj). Let D′ be the
image of this functor, i.e. the category generated by subquotient s of F (X). Then
D′ is a multifusion category, which is indecomposable (as B is indecomposable over
C ⊗ D). Since the functor F : D → D ′ is surjective, the Frobenius-Perron dimension
d of any component category of D′ divides FPdim( D). On the other hand, each
component category of D′ is a tensor subcategory in Fun C(Mi, Mi) for some i.
The latter is a dual category to C, so it has the same Frobenius-Perron dimension
as C. Hence, d must divide FPdim( C). Thus, d = 1 by the coprimeness condition.
Hence D′ =A −bimod, where A is a semisimple algebra, and furthermore, all Mi
are equivalent to a single module category M. The functor F : D → D ′ deﬁnes a
module category N over D, and it is clear that B = M ⊗ N . We are done. □
