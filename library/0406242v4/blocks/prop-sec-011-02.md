If two consecutive tetrahedra ∆i−1, ∆i are ﬂat, then ∆i+1 is ﬂat, too. Proof We use only Figure 5 and the deductions recorded in (3). There are three cases: (1) If i is not a hinge index, ﬂatness of ∆i implies wi−1 + wi+1 ∈{0, π}. By the range condition 0 ≤w ≤π 2 , this implies wi+1 ∈{0, π 2 }, so ∆i+1 is ﬂat. (2) If i is a hinge index and wi = π 2 , we must have |wi−1 −wi+1| = π 2 , so by the range condition, wi+1 is 0 or π 2 , and ∆i+1 is ﬂat. (3) If i is a hinge index and wi = 0, we have |wi+1 −wi−1| ≤0 so wi+1 = wi−1. But ∆i−1 is assumed ﬂat, and therefore so is ∆i+1. Note that ﬂatness of ∆i−1 was needed only in this case.
