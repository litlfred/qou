Later \cite{Hemmecke+Onn+Weismantel:oracle} showed that if a ``best-improving'' augmentation $\vez$ in the ``Graver basis'' of the constraint matrix is chosen (the authors of \cite{Hemmecke+Onn+Weismantel:oracle} called this augmentation rule ``greedy improvement''; here we will call this ``deepest descent''), only polynomially-many augmentations (in the binary encoding length of the input data) must be performed in order to reach the optimal value.
