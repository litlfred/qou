The reason one should pay attention to both of these maps is that it is their composition which relates homological invariants of $K \subset M_3$ to concrete calculations in $T[M_3;G]$, $$\boxed{{\text{UV line} \atop \text{operators}~W_{\lambda}}} \quad \xleftrightarrow[~]{\text{UV/IR map}} \quad \boxed{{\frac12\text{-BPS impurity} \atop \Gamma_{K,{\mathcal R}} }} \quad \xleftrightarrow[\text{~}]{\text{3d/3d correspondence}} \quad \boxed{{\text{link}~K \subset M_3 \atop \text{colored by}~{\mathcal R}}}$$ Because each of these maps can be rather non-trivial, one should not confuse the representation $\lambda$ that labels half-BPS line operators in the UV description with the "color" of $K$.
