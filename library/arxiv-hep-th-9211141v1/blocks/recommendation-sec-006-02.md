The definitions of $u$ and $v$ must be modified to read \begin{equation} u=\left(A\chiJ,\left(I-K\right)^{-1}A\right),\ \ \ v=\left(A\chiJ,\left(I-K\right)^{-1}A^\prime\right)\, . \label{uv_defn2} \end{equation} Notice that since \[ \left(I-K\right)^{-1} A = \left(I-K\right)^{-1} A \chiJ \ \ \ {\rm in }\ J \] this agrees with the original definitions of $u$ and $v$ given by (\ref{uv_defn}). \par We can think of $K$ as an operator taking smooth functions to smooth functions and so the operators $KD$ and $DK$ make sense, the former having distributional kernel.
