We say that a partition π is smaller (or ﬁner) than a partition ρ of the
same set if every block of π is a subset of some block of ρ and we denote
it by π ≤ ρ. For partitions π 1, π 2 of the same set we denote by π 1 ∨ π 2
the minimal partition which is greater or equal than both π 1 and π 2. The
set of all partitions of some given set X has a maximal element, namely the
partition with only one block equal to X.
