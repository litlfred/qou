Note from Eqs. (10) and (11) that, owing to its imaginary part, the quaternion cubic kernel KQ P pro- vides enhanced data representation over the real-valued cubic kernel K RP. Therefore, KQ P has the ability to learn the relationship between input variables, while preserving the mathematical simplicity of polynomial kernels. Fig. 1 visualises KQ P for the scalar case x = 1, y = yr + iyi + jy j + kyk ∈H, which gives KQ P(1, y) = 2(1 + y) (1 + ∥y∥2). As KQ P(1, y) is symmetric, we only plot the region (yr, yi, y j, yk) ∈[−15, 15] × [−15, 15] × {0} × {0}.
