One speculative idea is that the lack of faithfulness of the representations of the braid groups
B2 and Bc
3 using C and H respectively naturally places a restriction on the number of distinct
braided physical states that can be represented. The Helon model has no mechanism in place to
restrict the number of allowable physical states. One could add more twisting to the ribbons and
increase the complexity of braiding without limit, to get an inﬁnite number of distinct states.
Indeed, the model has been extended to a inﬁnite number of generations [26]. However, because
the C and H representations ofB2 andBc
3 representations are not faithful, many distinct braids
are represented by the same (hyper)complex number. Each (hyper)complex number therefore
represents an equivalence class of braids, each to be identiﬁed with a physical state. The ﬁnite
set of equivalence classes then places a limit on the number of admissible physical states.
