Corollary 4.17. LetA and B be as in Theorem 4.16.
1. There is a functorial isomorphism
R Homgr
B (M,RB) ∼= R Homgr
A (M,RA)
for all M ∈ D(GrModB).
2. If A is graded Auslander then so is B.
3. Cdim AM = CdimBM for M ∈ GrModB.
4. If A is graded Auslander GKdim-Macaulay then so is B.
