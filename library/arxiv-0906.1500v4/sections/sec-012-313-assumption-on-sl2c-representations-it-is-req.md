The character variety of π1(M ) is the set of characters of SL 2(C)-representations. Here
the character of an SL 2(C)-representation ρ is a map π1(M ) → C given by the assignment
γ ↦→tr ρ(γ) for all γ ∈ π1(M ), where tr denotes the usual trace of square matrices. This

a complete hyperbolic manifold, the character variety X(M ) contains the distinguished
components related to the complete hyperbolic structure. These components are deﬁned
by containing a lift of the holonomy representation π1(M ) → PSL2(C) ( i.e., the discrete
and faithful representation) determined by the complete hyperb olic structure. We call
these components the geometric components.
