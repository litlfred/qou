We shall also use the exponent $+$ to indicate the following operations on these combinatorial objects:\vspace{1mm} \begin{itemize} \item transforming a non-crossing pairing $\nu$ of size $2r-2$ in a non-crossing pairing $\nu^+$ of size $2r$ by adding the bond $\{1,2r\}$ "over" the bonds of $\nu$.\vspace{1mm} \item transforming a Dyck path $\delta$ of length $2r-2$ in a Dyck path $\delta^+$ of length $2r$ by adding an ascending step before $\delta$ and a descending step after $\delta$.\vspace{1mm} \item transforming a rooted tree $T$ with $r-1$ edges in a rooted tree $T^+$ with $r$ edges by adding an edge "below" the root.\vspace{1mm} \end{itemize} All these operations are compatible with the aforementioned bijections, so for instance $\nu(T^+)=(\nu(T))^+$ and $\delta(\nu^+)=(\delta(\nu))^+$.
