Having reviewed all this formalism we now see what it has to tell us about Alice's computing task. There is a straightforward way to recast what Alice is trying to do as a quantum coding problem [@HaydenPreskill]. We can write the state [\[compPsi\]](#compPsi){reference-type="eqref" reference="compPsi"} of the black hole as $$|\Psi\rangle=\frac{1}{\sqrt{|B|}}\sum |b\rangle_B |\bar{b}\rangle,$$ where $$\label{bhcode}
|\bar{b}\rangle\equiv \frac{1}{\sqrt{|H|}} |h\rangle_H U_R |bh0\rangle_R$$ is a basis for a $k$ dimensional subspace of $\mathcal{H}_H\otimes\mathcal{H}_R$. We can obviously interpret this subspace as a quantum code, with encoding transformation $$\label{bhenc}
U_{enc}\equiv U_{R}U_{mix,H}.$$ Here $U_{mix,H}$ is a simple entangling transformation analogous to $U_{mix}$ from equation [\[Umix\]](#Umix){reference-type="eqref" reference="Umix"}, but here entangling only the $m$ qubits of $H$ and the $n+1$ to $n+m$th qubits of $R$. For later convenience we will take $U_{mix,H}$ to act on each pair of qubits as $$\label{entangler2}
|b_1b_2\rangle\mapsto \frac{1}{\sqrt{2}}\left((-1)^{b_1}|b_1b_2\rangle+|b_1+1,b_2+1\rangle\right),$$ which is not quite the transformation given by the circuit in figure [\[gates\]](#gates){reference-type="ref" reference="gates"}; to implement it we need to act with an extra CNOT gate prior to the Hadamard transformation and CNOT gates in figure [\[gates\]](#gates){reference-type="ref" reference="gates"}. In this language, we can think of Alice not having access to $H$ as putting this code through an erasure channel that erases all qubits in $H$.

This simple recasting unfortunately does not allow us to learn anything about the computational complexity of $U_R$, since the state $|\Psi\rangle$ has the special property that it can be decoded just by acting with $U_R^\dagger$. The error correction is no harder than the encoding, whose complexity we don't know a priori. We can do better by recalling the discussion of section [\[slowcomp\]](#slowcomp){reference-type="ref" reference="slowcomp"}, where we interpreted the state $|\Psi\rangle$ as arising from the action of a polynomial size circuit $U_{dyn}$ $$U_{dyn}|0\rangle_{BHR}=\frac{1}{\sqrt{|B||H|}}\sum_{bh}|b\rangle_B |h\rangle_HU_R|bh0\rangle_R.$$ We'd like to interpret $U_{dyn}$ as an encoding transformation and $U_R$ as a correction operation, but this is not quite manifest here since $U_{dyn}$ always acts on the same state so the code space appears one dimensional whereas we'd like it to be $2^k$ dimensional. We can fix this by introducing an additional system $B'$, with the same number of qubits as $B$, and then entangle it with $B$ by acting with a transformation $U_{mix,B'}$ which acts as [\[entangler2\]](#entangler2){reference-type="eqref" reference="entangler2"} on the $ith$ qubits of $B'$ and $B$ for all $i\in 1,\ldots,k$. We can then define a $k$-qubit code subspace of this $2k+m+n$ qubit Hilbert space via the encoding transformation $U_{enc}\equiv U_{mix,B'}U_{dyn}$ such that $$\label{Bpstate}
U_{enc}|b'\rangle_{B'}|0\rangle_{BHR}=\frac{1}{\sqrt{|B||H|}}\sum_{bh}U_{mix,B'}|b'b\rangle_{B'B} |h\rangle_HU_R|bh0\rangle_R.$$ The errors introduced by the environment we again take to be erasures, now acting on both $B$ and $H$. With $B$ and $H$ erased, the only way to extract $b'$ and restore the initial state is to unscramble the entanglement between $B'$ and $R$, which effectively requires being able to implement $U_R^\dagger$. More concretely, say that we have a polynomial size circuit for $U_R$. We may use it to act on the state [\[Bpstate\]](#Bpstate){reference-type="eqref" reference="Bpstate"} with $U_R^\dagger$. We may then act with $U_{mix,B'}$, now with the second element of each pair of qubits taken from the first $k$ qubits of $R$ instead of from $B$, which we no longer have access to. This produces a state $$|b'\rangle\frac{1}{\sqrt{|B||H|}}\sum_{bh}|b\rangle_B|h\rangle_H|bh0\rangle_R,$$ so we have recovered the information $b'$. From here we can explicitly restore the initial state in polynomial time by using ancilla to return $BHR$ to the state $|0\rangle_{BHR}$ and then using $U_{enc}$ to get back to the state [\[Bpstate\]](#Bpstate){reference-type="eqref" reference="Bpstate"} as desired. We may thus apply the lesson of the previous section, which is that in general doing error correction for codes with small encoding circuits requires exponential sized circuits. For stabilizer codes in the erasure channel we saw that this was not true, but there is no reason to expect that the encoding map [\[Bpstate\]](#Bpstate){reference-type="eqref" reference="Bpstate"} produces a stabilizer code. For more general $U_{enc}$ the only known correction procedure even in the erasure channel is the one described in the footnote at the end of section [\[ecrev\]](#ecrev){reference-type="ref" reference="ecrev"}, which takes a time $2^{2l}$ where $l$ is the number of erased qubits.[^1][^2]

So far we have only discussed errors arising from Alice not having access to $B$ and $H$. There are of course other errors that can occur, having to do with the practical difficulty of controlling the Hawking radiation. In particular an order one fraction of the radiation will be gravitons, which are very hard to detect at all, never mind coherently manipulate. It was shown long ago by Page [@pageevap] that the rate of Hawking radiation into a field of spin $s$ decreases as $s$ increases, so for Schwarzschild black holes in our universe the fraction will be small. The question of how many bits can be lost without losing the ability to error correct with high probability of success has been studied in the literature, and as discussed in the previous subsection for the erasure channel the number of bits which are lost must be less than $\frac{n-k}{2}$. For a typical stabilizer code any smaller number of erasures can be corrected with high probability of success [@preskillnotes]. This will typically be true for more general codes like the one discussed here as well since they should protect information at least as well as stabilizer codes. For the channel just constructed, what was called $n$ in our general discussion of error correction is $2k+m+n$ in terms of the parameters of our black hole model, so we can lose at most $\frac{k+m+n}{2}$ bits. $k+m$ have already been lost since Alice does not have access to $B$ and $H$, so she can lose $\frac{n-k-m}{2}$ more and still be able to error correct. Say that the fraction of the radiation which is gravitons is $\alpha$. Since $\alpha<\frac{1}{2}$, this means that if Alice waits long enough she can lose *all* of the gravitons and still be able extract the entanglement accurately with room to spare for correcting additional errors. Of course doing this error correction can be an additional source of computational hardness, which will only make it even harder to complete the decoding before the black hole evaporates. This discussion shows however that without taking into account computational complexity, the difficulty of measuring gravitons does not prevent the AMPS experiment from being done.

[^1]: By reshuffling factors between $U_{enc}$ and $U_{noise}$ we can turn erasures for a general code into a more general channel for a stabilizer code, which for simplicity we can just take to be the trivial code. The [NP]{.sans-serif}-completeness results of [@hsieh2011np] strongly suggest that no general polynomial time error correction algorithm exists for putting stabilizer codes through general channels, and essentially prove it when $k$ is large provided that $\textsf{P}\neq \textsf{NP}$.

[^2]: It is interesting to note that since we here have $l=k+m$, the correction time $2^{2(k+m)}$ is actually a bit faster than our estimate [\[dectime\]](#dectime){reference-type="eqref" reference="dectime"} which came from counting gates. This is because the correction procedure from the footnote just mentioned involves doing quantum operations on $B'$, which is fictitious and not available from the point of view of the original black hole problem. In other words, any circuit for $U_R$ can be used to correct the channel just constructed but the converse is not true; a generic correction procedure for this channel cannot be converted into a circuit for $U_R$ of comparable complexity.
