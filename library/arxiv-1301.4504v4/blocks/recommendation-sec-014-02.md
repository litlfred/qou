[QSZK]{.sans-serif} also trivially contains [BQP]{.sans-serif}, the class of problems that can be solved on a quantum computer: for such problems, the verification can be done directly using the computer itself without any need for a clever discussions with a prover. [QSZK]{.sans-serif} should therefore be understood as the set of problems whose yes instances can be reliably identified using a quantum computer with the help of an all-powerful prover, albeit one who is both secretive and dishonest.
