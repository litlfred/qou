Restating the setup of the previous section, we can think of the black hole as a polynomial-size circuit $U_{dyn}$ which acts on a set of microstates $|i\rangle$ as $$U_{dyn}|i\rangle=\frac{1}{\sqrt{|B||H|}}\sum_{bh}|b\rangle_B|h\rangle_H U_R(i)|bh0\rangle_R.$$ The point here is that we must be able to recover any initial state from the final state, so the unitaries $U_R(i)$ must all be distinct elements of the coset $U(2^n)/U(2^n-2^{m+k})$.
