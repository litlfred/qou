11 (Farkas’ Lemma). If A is a real m × n matrix and b ∈Rm, and · the standard Euclidean inner product on Rm, then the following holds: {x ∈Rn | Ax = b, x > 0} is non-empty if and only if for all z ∈Rm such that ATz̸ = 0 and ATz ≥0, z · b > 0. Here x ≥0 (respectively x > 0) indicates that all coordinates of x are non-negative (re- spectively positive).
