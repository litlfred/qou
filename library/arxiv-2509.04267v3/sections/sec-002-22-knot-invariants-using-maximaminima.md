A pairing ∪: V ⊗V →k and a copairing ∩: k →V ⊗V in a module V over a unital ring k are
said to have (or satisfy) the switchback property if they satisfy the equalities
(∪⊗1)(1 ⊗∩) = 1 = (1 ⊗∪)(∩⊗1).
Let R be a YBO. A pairing ∪is said to satisfy (or have) the passcup property with respect to R
if it satisfies
(1 ⊗∪)(R ⊗1) = (∪⊗1)(1 ⊗R−1),
(1 ⊗∪)(R−1 ⊗1) = (∪⊗1)(1 ⊗R).
