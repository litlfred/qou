Let us consider the unit disk ${\mathbb D}$, and a given subharmonic function $\psi:{\mathbb D}\to{\mathbb R}$. If $u:{\mathbb D}\to{\mathbb C}$ is holomorphic and nontrivial, then $\log|u|$ is subharmonic. Then $\log|u|+\psi$ is subharmonic, and by convexity, $|u|^2\mathrm{e}^{2\psi}$ is subharmonic as well. By the sub-mean value property of subharmonic functions, we have the estimate $$|u(0)|^2\mathrm{e}^{2\psi(0)}\le\frac{1}{\pi}\int_{{\mathbb D}} |u|^2 
\mathrm{e}^{2\psi} \mathrm{d}A,$$ which allows us to control the norm of the point evaluation at the origin in $\mathrm{A}^2({\mathbb D},\mathrm{e}^{2\psi})$. If we would try this with a bianalytic function $u$, we quickly run into trouble as $\log|u|$ need not be subharmonic then (just consider, e.g., $u(z)=1-|z|^2$). So we need a different approach.
