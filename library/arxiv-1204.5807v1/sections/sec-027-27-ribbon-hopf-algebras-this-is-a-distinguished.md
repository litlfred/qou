Deﬁnition 2.13. [RT1] A quasi-triangular Hopf algebra (H, R) is ribbon if

v2 = uS(u), S(v) = v, ∆( v) = Q−1(v⊗v).(2.14)
The ribbon element is not unique but it is determined up to mul tiplication
by an element in {g ∈G(H) ∩Z(H) : g2 = 1}.
