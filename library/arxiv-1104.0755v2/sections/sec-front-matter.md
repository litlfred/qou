A connection formula between the Ramanujan
function and the q-Airy function
Takeshi MORITA‡
Abstract
We show a connection formula between two diﬀerent q-Airy func-
tions. One is called the Ramanujan function which appears in Ra-
manujan’s ”Lost notebook”. Another one is called the q-Airy function
that obtained in the study of the second q-Painlev´e equation. We use
the q-Borel transformation and the q-Laplace transformation following
C. Zhang to obtain the connection formula.
