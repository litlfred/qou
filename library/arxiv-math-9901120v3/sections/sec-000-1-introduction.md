In [@HatcherOertel], Hatcher and Oertel gave an algorithm for computing the boundary slopes of a Montesinos knot. At the end of their paper they provided a table giving the boundary slopes for each Montesinos knot in the standard table in Rolfsen's book [@Rolfsen76]. Unfortunately, their table contains several (17) errors. These errors were due to problems with the computer program that generated the table, as well as transcription/printing errors. This note provides a corrected table which was generated by a completely new computer program. Section [\[table\]](#table){reference-type="ref" reference="table"} contains the corrected table. Section [\[method\]](#method){reference-type="ref" reference="method"} describes the precautions I took in writing the new program. Unfortunately, not all mistakes in [@HatcherOertel] were found in the original [1999 version of this note](http://arxiv.org/abs/math.GT/9901120v2), and this 2010 revision corrects several more (details are given in Section [\[method\]](#method){reference-type="ref" reference="method"}). Section [\[gettingprogram\]](#gettingprogram){reference-type="ref" reference="gettingprogram"} describes where the reader can download the new program.

I thank Allen Hatcher and especially Ulrich Oertel for their help with this project. I also thank Thomas Mattman and Marc Culler their help with finding and correcting the additional errors.
