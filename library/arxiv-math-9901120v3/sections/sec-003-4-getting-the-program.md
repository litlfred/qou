[]{#gettingprogram label="gettingprogram"}

The programs I used in preparing this note are available at <http://dunfield.info/montesinos>. They are written the programming language Python, and you will need a Python interpreter to run them. These interpreters are available, for free and for almost all platforms, from <http://python.org>.
