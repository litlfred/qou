A closed orientable 3-manifold has a geometric structure modelled on one of the following six geometries: S3, R3, S2 × R, H2 × R, Nil, g SL2 if and only if it is a Seifert manifold of the appropriate commensurability class, as prescribed by Table 12.1. It has a Sol geometric structure if and only if it is a torus (semi-)bundle of Anosov type. It is a surprising (and maybe disappointing) fact that, despite its elegance and generality, the only known proof of this theorem available today works by investigating each geometry separately and carefully, often employing quite diﬀerent techniques. We start with the elliptic case.
