The proof of Lemma \ref{fissi:lemma} extends as is when $\varphi_2$ is elliptic, and shows that if $\Gamma$ contains a hyperbolic element $\varphi_1$ then every other non-trivial element of $\Gamma$ is either hyperbolic or elliptic and fixes the same axis of $\varphi_1$, but this is excluded: so $\Gamma$ contains only parabolics and elliptics, and these must fix all the horospheres centred at $x$, as required.
