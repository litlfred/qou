COROLLARY 7.6. The stabilization index of a link of braid index 3
is one.
Proof. By the Classification Theorem, a link of braid index 3 is
either represented by a unique conjugacy class (in which case the sta-
bilization index is zero) or else it is represented by two conjugacy
classes which are related to one-another by flypes. Therefore it is only
necessary to show that two classes which are related by flypes become
conjugate after a single stabilization. For a proof, see page 100, equa-
