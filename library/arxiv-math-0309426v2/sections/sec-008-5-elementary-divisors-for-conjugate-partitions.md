Let R = Z[q,q −1]. Let λ be a partition of n. In this section we relate the Gram
matrices G(λ) and G(λ′). We start with some mild generalizations of some results
about Specht modules which were proved by Dipper and James [ 2] over a ﬁeld.
Recall that if Y is a submodule of an R–free module X then Y is pure if the
quotient module X/Y is R-free.
