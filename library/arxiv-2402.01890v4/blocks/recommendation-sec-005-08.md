We first define $ \Lambda_{sph}^{k} \subseteq \Lambda^k $ via \begin{equation}\label{concretelydefined2} \Lambda_{sph}^{k} = \{ \lambda = (\lambda_1, \lambda_2, \ldots, \lambda_l ) \in \Lambda^k \, | \, \overline{b}(\lambda) \le k \} \end{equation} where \begin{equation} \overline{b}(\lambda) = \sum_{i=1}^l i \lambda_i. \end{equation} This definition should be contrasted with the definition of $\ParSph $ in \eqref{defineLambaSph}.
