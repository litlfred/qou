If we relax the assumption that 9 be ordinary, and let h = vp(c(pOF, 9)) (where the valuation is normalised such that vp(p) = 1), then we can still make sense of cLAs p (9) as long as h < 1; however, it is no longer a measure, but a distribution of order h. This can be extended to h < 1 + k using the same techniques as in [Loefﬂer and Zerbes 2016]. However, if k = 0 and h ⩾1 (as in the case of an eigenform associated to an elliptic curve supersingular at the primes above p) then we are stuck.
