Let λ = (2, 1(5)) and let µ = (3, 3, 1) be two partitions of 7. Clearly, λ ⊴µ in the dominance order. We choose βλ := (7, 5, 4, 3, 2, 1) and βµ = (8, 7, 4, 2, 1, 0) for the sequences of β-numbers for λ and µ, respectively. Comparing the two sequences, we see that there are two mismatches, so d(λ, µ) = d6(βλ, βµ) = 2. So µ is in fact a branch of λ; we calculate that h1 λ(µ) = 5 and h2 λ(µ) = 3. It is easily seen that µ is odd; indeed, D(µ) = (3) and f(3) = 1, so the oddness follows by Lemma 2.4. In particular, µ is an odd branch of λ.
