(cf. [7, Theorem 2.3.21]) Let λ be a partition of n. Then fλ := χλ(1) = n! Q c∈[λ] hλ(c). We further set f(0) := 1. A partition is said to be odd (resp. even) if and only if fλ is odd (resp. even). We say that a partition λ is q-core for some positive integer q if there is no c ∈[λ] such that q | hλ(c). There is a unique partition coreq(λ), which is q-core, that can be constructed from [λ] by successively removing hooks of cells with hook lengths a multiple of q, see also [7, Section 2.7].
