We are interested in the discrete spectrum σdis, which is the set of isolated eigenvalues of ﬁnite multiplicity, that is σdis(A) = {λ ∈C | ∃ψ ∈D(A), ∥ψ∥= 1, Aψ = λψ}. If λ ∈σdis(A), then its multiplicity is given by dim(ker(A −λ)) < ∞.
