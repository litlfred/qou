(i) Which normal functions in eD arise from eﬀective curves?
(ii) Which of these arise from irreducible curves?
(iii) Which of these arise from rational curves?
We note that a given normal function ν might arise from many diﬀerent
curves. The simplest example is that of complete intersection curves: a given
family of such curves is parametrized by a (usually positive dimensional)
projective space on each CY in the family, and all such curves have the same
Abel-Jacobi image since they are rationally equivalent. In fact, the Corollary
to Theorem 5 says that all curves in any connected family on the generic
CY give rise to the same ν.
The above remark suggests that we need not only decide which normal
functions ν come from rational curves, but to determine a multiplicity or
weight of ν accounting for all its realizations in terms of rational curves. Now
this seems rather special; one can just as well hope for a weight function wν
counting all curves, of all genera, corresponding to ν, through an expansion
such as wν = P Nν,gλg−1, where λ is a dummy variable and the coeﬃcients
Nν,g account for the curves.
