(Inﬁnitesimal cubic condition) Consider a family π : X →U of polarized abelian varieties with classifying map q : U →Ag and vertical bundle V, together with an isomorphism (3). Then there exists a non-degenerate holomorphic 2-form σ on X for which π is Lagrangian and which induces the given isomorphism i, if and only if the composition of (2) and (3): dq ◦i ∈Hom(V∗, Sym2V) = Γ(V ⊗Sym2V) comes from a cubic c ∈Γ(Sym3V). In this case, there is a unique σ for which the 0-section of π is Lagrangian.
