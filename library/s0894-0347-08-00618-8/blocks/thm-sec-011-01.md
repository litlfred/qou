For any graph G the polynomial fG(1, w) is real stable. Let G = (V, E) be a graph and let q > 0 and 0 ≤p ≤1 be parameters. The random cluster (RC) model (see [33]) is the measure µ on 2E deﬁned by µ(F) = ZRC qk(F )p|F |(1 −p)|E\F |, F ⊆E, where k(F) is the number of connected components in the graph (V, F) and ZRC is the appropriate normalizing factor. The uniform spanning tree measure can be obtained from this model by letting p →0 and q/p →0; see [33, Section 1.5]. If q ≥1, the RC model satisﬁes PLC and is therefore positively associated. If q ≤1, NLC is satisﬁed, but other negative correlation properties are largely a matter of conjecture.
