Beardon and Maskit [6] showed that a Kleinian group is convex cocompact if and only every
point in the limit set is a conical limit point. We say that z∈ Λ(ρ) is a conical limit point if
whenever− →xz is a geodesic ray ending at z, there exists R and a sequence{γn}⊂ π1(M) so that
γn(x)→z and d(γn(x),− →xz)≤R for all n.
Marden [50] showed that a Kleinian group is convex cocompact if and only if it has a finite-
sided convex fundamental domain and contains no parabolic elements.
Exercises: (1) Prove that if Γ is a Kleinian group, which is not virtually abelian, then every
point in Λ(ρ) is conical if and only if Γ is convex cocompact.
(2) Prove that z ∈ Λ(Γ) is conical if and only if there exists a sequence {γn} ⊂Γ and
a̸=b∈ Λ(Γ) so that γn(x)→a for all x∈ H3−{z} and γn(z)→b.
