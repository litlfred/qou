If Γ is a Kleinian group, then b NΓ is homeomorphic to C1(NΓ). We say that Γ is convex cocompact if C1(NΓ) is compact. Notice that this is equivalent to requiring that either b NΓ or C(NΓ) is compact. If ρ is convex cocompact, then we identified Nρ −C1(Nρ) with C1(Nρ) × (1, ∞).
