Let N = H3/Γ be a hyperbolic 3-manifold with finitely generated fundamental group. The manifold N is strongly parabolic (i.e. admits no non-constant positive superhar- monic functions) if and only if Λ(Γ) = ∂H3. Sullivan [71] showed that the geodesic flow of N is ergodic if and only if it admits a (positive) Green’s function, so one can also completely characterize when the geodesic flow of N is ergodic.
