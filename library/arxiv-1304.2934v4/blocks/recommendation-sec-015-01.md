Define the auxiliary variables $$Y_{n}=\frac{X_{n}-t_{n}\eta'(0)}{\sqrt{t_{n}\eta''(0)}}$$ We shall apply Feller's Lemma to the functions \begin{align*} F_{n}(x)&=\text{cumulative distribution function of } Y_n;\\ G_{n}(x)&=\int_{-\infty}^{x}\left(1+\frac{\psi'(0)}{\sqrt{t_{n}\eta''(0)}}\,y+\frac{\eta'''(0)}{6\sqrt{t_{n}(\eta''(0))^{3}}}\,(y^{3}-3y)\right)g(y)\,dy. \end{align*} Note that each $G_n$ is clearly a Lipschitz function (with a uniform Lipschitz constant, \emph{i.e.} that does not depend on $n$).
