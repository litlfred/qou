Given correspondences L♭ 0 ⊂M −× N and L♭ 1 ⊂ N −× P with the geometric composition L♭ 1 ◦L♭ 0 ⊂M −× P smooth, embedded and transversely cut out, there is a quasi-isomorphism of functors FL♭ 1◦L♭ 0 ≃FL♭ 1 ◦FL♭ 0. The construction of a morphism in the functor-category between FL♭ 1◦L♭ 0 and FL♭ 1 ◦FL♭ 0 comes from counting “biquilted” disks with two interior seams (two parallel horocycles). The quasi- isomorphism statement is a diﬃcult result which relies on a delicate strip-shrinking argument for the associated cohomological functors, proved in detail in [105].
