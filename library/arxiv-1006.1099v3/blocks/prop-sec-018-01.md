If L ⊂M is a Lagrangian sphere, equipped with the non-trivial Spin structure if L ∼= S1, then the geometric twist and the algebraic twist are quasi-isomorphic in nu-fun(F(M), F(M)). This is [92, Corollary 17.17] for exact symplectic manifolds; the argument carries over mutatis mutandis to the monotone case (see [106] for a detailed account, but note most of their work is needed only for the strictly more diﬃcult case of ﬁbred Dehn twists). Seidel also proves that if G : A →B is an A∞-functor, then for Y ∈A, G ◦TY ≃TG(Y ) ◦G ∈nu−fun(A, B). (3.6)
