Given any finite set $A$ in some ring we define the sum set and product set of $A$ as $$A+A=\{a+b: a,b\in A\}\quad\textrm{and}\quad AA=\{ ab : a,b\in A\}.$$ The sum-product conjecture in a given ring is that at least one of these must grow near-maximally; more precisely $$\label{eq-sp}\max(\mathopen{}\left| A+A\mathclose{}\right|,\mathopen{}\left| AA\mathclose{}\right|)\geq \mathopen{}\left| A\mathclose{}\right|^{2-o(1)}$$ (where the $o(1)$ term tends $0$ as $\mathopen{}\left| A\mathclose{}\right|\to \infty$).
