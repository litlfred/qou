The functor Π has the following properties. (a) Let h : X →B be an isogeny with kernel F. Then we have an exact sequence / Hom(F,C∗) / Π(B) Π(h) / Π(X) / 0. For P ∈Perv(X,C) we have h∗(P) ∈Perv(B,C), and Π(h) induces a surjection S (h∗(P)) ↠S (P). (b) Let i : A ,→X be an embedding of abelian varieties with quotient morphism q : X →B = X/A. Then we have an exact sequence / Π(B) Π(q) / Π(X) Π(i) / Π(A) / 0. In this situation we denote by K(A) ⊆Π(X) the image of Π(q).
