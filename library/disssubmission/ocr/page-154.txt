The recursion formula in theorem 6.1 determines the generic rank rg for
any partition a. For future reference we include below a list of these generic
ranks for all partitions with 3 < deg(a) < 9. For each degree d = deg(a) the
values of rq are listed in a table whose rows are labeled by the partition
and whose columns are labeled by the genus g. For the sake of brevity we
denote multiplicities in a partition by exponents, so the notation [3*2, 1]
refers to the partition (3,3, 1). Of course it suffices to deal with genera g < d
since otherwise ra = 0 by example 6.2.

the last column in our tables by hand via the hook formula for the dimension
