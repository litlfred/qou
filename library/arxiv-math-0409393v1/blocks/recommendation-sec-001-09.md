If one moreover requires $F$ to be compatible with the graduation, that is, to have the form $F = \begin{pmatrix} 1 & f \\ 0 & 1 \end{pmatrix}$, then there is unicity of the formal series $f$, which must satisfy the functional equation: $$f(z) = - u(z) + z f(qz).$$ We call $\hat{f}_{u}$ this unique formal solution (it can be computed by iterating the above fixpoint equation) and $\hat{F}_{u}$ the corresponding formal gauge transformation.
