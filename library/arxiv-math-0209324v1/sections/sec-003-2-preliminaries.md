Throughout the paper, rings are unital and commutative, and homomor-
phisms of rings are unital. By “homomorphism” we will usuall y mean a ring
homomorphism. Two rings that are considered to be canonical ly isomorphic
to each other will often be identiﬁed. Also, if a ring R embeds into another
ring R′ in a natural way, we will often regard R as a subring of R′.

Let N ={1, 2, . . . } denote the set of positive integers. We regard N as a
directed set with respect to the divisibility relation |. We will not use the
letter N for the same set {1, 2, . . . } when it is considered as an ordered set
with the usual order ≤.
The letter q will always denote an indeterminate.
