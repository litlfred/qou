For each n∈ N set⟨n⟩ ={m∈ N| m|n}. Since ∏ Φ ⟨n⟩ = ∏
m|n Φ m(q) =
qn− 1, we have
R[q]⟨n⟩ = R[q](qn−1) = lim←−j
R[q]/ (qn− 1)j.
Note that the set ⟨n⟩ is⇔R-connected if and only if for each prime factor
p of n the ring R is p-adically separated. A subset S⊂ N will be called
R-admissible if S is a ⇔R-connected, directed subset of N such that n∈ S
implies⟨n⟩⊂ S. Note that a subset S⊂ N is ﬁnite and R-admissible if
and only if there is n∈ N such that S =⟨n⟩ and R is p-adically separated
for each prime factor p of n. Note also that an R-admissible subset S⊂ N
satisﬁes S = ⋃
n∈S⟨n⟩, and hence we have R[q]S ≃ lim
←−n∈S R[q]⟨n⟩. The
following easily follows from Theorem 4.2.
Corollary 4.3. Let R be a ring, and let S ⊂ N be R-admissible. Then
for each m, n ∈ S with m|n the homomorphism ρR
⟨n⟩, ⟨m⟩ : R[q]⟨n⟩→ R[q]⟨m⟩
is injective. Hence R[q]S can be regarded as the intersection ⋂
n∈S R[q]⟨n⟩,
where the R[q]⟨n⟩, n∈ S, are regarded as R-subalgebras of R[q]⟨1⟩ = R[[q−1]].
In particular, if m, n ∈ N and m|n, then ρZ
⟨n⟩, ⟨m⟩ : Z[q]⟨n⟩→ Z[q]⟨m⟩ is
injective. We have Z[q]N = ⋂
n∈N Z[q]⟨n⟩.
We will see in Proposition 7.7 that if m|n and m⁄= n, then ρZ
⟨n⟩, ⟨m⟩ is not
surjective.
