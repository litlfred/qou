2.5. If I is an ideal ofC in the sense of Deﬁnition 2.1, then one can deﬁne subspaces
J(X,Y ) ={f∈ HomC(X,Y )| there exists Z inI, g :X→Z, h :Z→Y so that f =hg}.
Then J forms a tensor ideal and we write J(I) for this tensor ideal.
Conversely, ifJ is a tensor ideal, then one can deﬁneI to be the full subcategory consisting
of all objects V inC such that IdV ∈ J(V,V ). This is an ideal of C and we write I(J) for
this ideal.
