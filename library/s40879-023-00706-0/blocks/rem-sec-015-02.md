Note that when we call (345) an automorphism of the elliptic curve, we have to think about it only in the category of projective varieties with morphisms given by rational maps. To consider the group structure on an elliptic curve E we need to also give a base point O ∈E which acts as the additive identity. A morphism from pair (E, O) →(E′, O′) must map O →O′.
