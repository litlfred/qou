However, for the present purposes we will employ a different normalization by demanding $P_n^{(\alpha)}(0) = 1$: \begin{equation} P_n^{(\alpha)}(\lambda) = 1+ \cdots + p^{(\alpha)}_n \lambda^n. \label{normal} \end{equation} This is because we shall seek a smooth limiting behavior near $\lambda = 0$ as $n$ gets as large as $N$ (which is taken to infinity), and $N^2 \lambda$ is kept fixed at the same time (the microscopic limit).
