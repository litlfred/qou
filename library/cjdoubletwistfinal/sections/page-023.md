We close with two further questions. First, for torus knots T(2,2t+1), the q-hypergeometric
series expressions for JN(T(2,2t+1); q) which led to the generalized Kontsevich-Zagier functions
Ft(q) were computed in [14, 15] using diﬀerence equations. Can one prove Theorems 1.1 and
1.2 using this technique?
Second, both U1,1(x; q) and F1,1(q) are interesting combinatorial
generating functions and the coeﬃcients of F1,1(1−q) and U1,1(1; q) satisfy intriguing congruences
[1, 2, 4, 8, 10, 27]. It would be worthwhile to determine if the same is true for Um,p(x; q) and
Fm,p(q).
