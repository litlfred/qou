A global diﬀerence module has, in general, no slope ﬁltration! We con-
sider the category of the global modules N that have an ascending slope
ﬁltration, i.e., a sequence of submodules 0 = N0 ⊂N1 ⊂· · · ⊂Nr = N,
such that each quotient Ni/Ni−1 is pure with slope λi and λ1 < · · · < λr.
Theorem 4.3. — The functor T from the category of the global diﬀer-
ence modules with ascending slope ﬁltration to the category of the diﬀerence
modules over K, given by N →K ⊗C[z,z−1] N, is an equivalence of Tan-
nakian categories.
Remarks 4.4. — For a given module M over K, the global module with
ascending slope ﬁltration N with T(N) = K ⊗N ∼= M has the property
that C({z−1}) ⊗N is a diﬀerence module over the ﬁeld C({z−1}) which is
a direct sum of pure modules. Indeed, C({z−1}) ⊗N has both an ascending
and a descending slope ﬁltration. In other words, N is an algebraic vector
bundle above P1 −{0, ∞} with a Φ-action and a ﬁltration according to the
slopes at z = 0.
One can see Theorem 4.3 as an analogue of a theorem of G. Birkhoﬀ
which states that every diﬀerential module over K comes from a connection
on P1 which has only singularities at 0 and ∞. Moreover the singularity at
∞is regular singular.
