1. Let f ∈C∞(R/Z, Rn) and s > 0. Then the function f is analytic on R/Z if there are positive constants r and C such that ∥f (k)∥H1+s ≤C k! rk holds for all integers k ≥0. This can be seen by using [KP02, Proposition 1.2.12] together with a standard covering argument, Morrey’s inequality (see e.g. [AF03, Paragraph 4.16]), the equivalence of the W 1,2- and the H1-norm on R/Z (cf. [Rei12, Lem. 1.2] or [AF03, 7.62]) as well as the embedding Hs ⊆Ht for any t < s (cf. [Tay96, Chapter 4, Proposition 3.4]). In addition, we need a special case of the Cauchy-Kovalevsky theorem, which can be derived for example from [Fol95, (1.25)].
