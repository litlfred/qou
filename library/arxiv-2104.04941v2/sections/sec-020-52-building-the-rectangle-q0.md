5.3. Construction of µrot. The most diﬃcult step is modifying Q0 to become triangular by adding a third
group of vertices, A•, also of half-Dynkin type. However, since the A•, B•, and C• vertices will be frozen,
the Q0 alone is enough to describe the mutation sequence µrot. It will be composed of three main pieces.
• The mutation µrotTw transforms coordinates of α to coordinates of rot(α), in some order. The
component mutation ~µCol(j) performs a mutation on column j that adjusts the minor coordinates
by concatenating the Coxeter element to each word.
• The mutation ~µO1 (“ordering-1”) performs a σAℓ action on each row (a Dynkin diagram of Aℓ) using
~µRS (“rowσAℓ”)
• The mutation ~µO2 (“ordering-2”) performs a σG action on each column (a Dynkin diagram of G)
using~µCS (“column σG”), as in Remark 2.7. When σG is trivial, this can be ignored.
