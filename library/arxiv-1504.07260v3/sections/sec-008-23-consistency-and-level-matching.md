2.4 Classiﬁcation
We are considering four dimensional CHL models obtained by orbifolding symmetryˆg =
(δ,g ) whereg∈O(Γ6,22) ﬁxes a sublatticeΓS1⊕Γ ˜S1∼= Γ2,2 andδ∈ ΓS1⊗ R has ﬁnite order

this labelling is highly redundant, in the sense that there are inﬁnitely many pairs(δ,g )
leading to the same CHL model, i.e. to the same connected component in the moduli space.

diﬀerent choices for the order lead to the same set of CHL models. As discussed in section

Whenever two pairsˆg = (δ,g ) and ˆg′ = (δ′,g′) are related by aO(Γ6,22) transformation,
the corresponding CHL models belong to same component of the moduli space. An obvious
necessary condition forˆg = (δ,g ) and ˆg′ = (δ′,g′) to be conjugated is thatδ andδ′ have the
same order ˆN = ˆN′ and normδ2 = (δ′)2. Furthermore, up to a replacement ofˆg by ˆga, for
somea coprime to ˆN, we can assume thatδ andδ′ are 1/ ˆN fractions of some primitive null
vectors u,u′∈ Γ6,22. It is well known that there is always aO(Γ6,22) transformation that

same order, we can assume thatδ =δ′. It remains to classify all possible choices ofg and

the stabilizer ofδ contains in particularO(Γ5,21), whereΓ5,21 is the orthogonal complement
of ΓS1 in Γ6,22.

3 Fricke S-duality and N -modularity
The equivalence between type IIA string theory compactiﬁed on(K3×S1)/Z ˆN× ˜S1 and
heterotic string theory on(T 4×S1)/Z ˆN× ˜S1 can be explained using the standard adiabatic
argument of [56]. We will use this argument to discuss the strong coupling limit of the
heterotic CHL model. This will lead us to discover new Fricke-type S- and T-dualities. In
this section we derive these new dualities and analyse their implications for heterotic-type
II duality and electric-magnetic duality.
