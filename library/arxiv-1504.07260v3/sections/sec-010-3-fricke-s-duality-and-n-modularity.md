[]{#s:Sdual label="s:Sdual"}

The equivalence between type IIA string theory compactified on $(K3\times S^1)/\mathbb{Z}_{\hat N}\times \tilde S^1$ and heterotic string theory on $(T^4\times S^1)/\mathbb{Z}_{\hat N}\times \tilde S^1$ can be explained using the standard adiabatic argument of [@VafaWitten95]. We will use this argument to discuss the strong coupling limit of the heterotic CHL model. This will lead us to discover new Fricke-type S- and T-dualities. In this section we derive these new dualities and analyse their implications for heterotic-type II duality and electric-magnetic duality.
