An interesting phenomenon is that N=1 supersymmetry can be p reserved if

one obtains only an abelian gauge group and no chiral fermion s [341, 342].
How to get a non-abelian gauge symmetry in compactiﬁcation o f such a the-

boundary [343]. Another possibility is to get gauge ﬁelds an d chiral fermions

the manifold of G2 holonomy. If X looks locally like Q × R4/Γ where Q is
