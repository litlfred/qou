class A. An example of class B model is that of Ref [479] where the ratio
Re(T1) : Re(T2) : Re(T3) is determined and the gauge coupling uniﬁcation

where Re(T2) : Re(T3) is determined, Re(T1) is left unconstrained and one
may achieve gauge coupling uniﬁcation by constraining Re(T1).
