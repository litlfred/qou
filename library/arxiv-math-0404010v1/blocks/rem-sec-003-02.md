If S = (R, µ, α, β) is a redundant Yang–Baxter operator, then we have that XS (L) = Trace(µ) · XS,1(L) for any oriented link L. In particular, if Trace(µ) vanishes, then XS does too: this is the case when it is worth working with modiﬁed Markov traces. Next proposition will be proved thanks to arguments from [8, Appendix A]. There, Murakami shows redundancy of a particular (colored) enhanced Yang–Baxter operator, from which he derives the (multivariable) Alexander polynomial.
