Let A be a k–algebra of dimension at least 2 and let x, y, z ∈k be scalars. Then Rx,y,z is a Yang–Baxter operator if and only if one of the following conditions holds: (i) x = z̸ = 0, y̸ = 0, (ii) y = z̸ = 0, x̸ = 0, (iii) x = y = 0, z̸ = 0. If so, its inverse is given by Rx,y,z−1 = Ry−1,x−1,z−1 in cases (i) and (ii), and by R0,0,z−1 = R0,0,z−1 in case (iii). We will be only interested in the non–trivial cases (i) and (ii) (which are equivalent through inversion) and we will denote by Rx,y the operator Rx,y,x.
