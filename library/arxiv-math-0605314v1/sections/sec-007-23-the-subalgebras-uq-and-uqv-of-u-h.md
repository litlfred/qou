[]{#sec:subalgebras-uq-uqv label="sec:subalgebras-uq-uqv"} Set $$\begin{gathered}
  e= (v-v^{-1})E,\\
  F^{(n)} = F^n/[n]!,\\
  \tF^{(n)} = F^nK^n/[n]_q! = v^{-\hf n(n-1)}F^{(n)}K^n
\end{gathered}$$ for $n\ge 0$. Let $\Uq$ denote the $\Zqq$-subalgebra of $U_h$ generated by $K$, $K^{-1}$, $e$, and $\tF^{(n)}$ for $n\ge 1$. The definition of $\Uq$ here is equivalent to that in [@H:uqsl2 Section 11].

Let $\Uqv$ denote the $\Zqq$-subalgebra of $\Uq$ generated by $K^2$, $K^{-2}$, $e$, and $\tF^{(n)}$ for $n\ge 1$. ($\Uqv$ is the same as ${\mathcal G}_0\Uq$ in [@H:uqsl2].) $\Uq$ is equipped with a $(\modZ /2\modZ )$-graded $\Zqq$-algebra structure $$\label{eq:56}
  \Uq= \Uqv \oplus K\Uqv.$$

Later we need the following formulas in $\Uq$. $$\begin{gathered}
  \label{eq:58}
  Ke=qeK,\quad
  K\tF^{(n)}=q^{-n}\tF^{(n)}K,\\
  \label{eq:59}
  \tF^{(m)}\tF^{(n)}=q^{-mn}\bbq{m+n}{m} \tF^{(m+n)},\\
  \label{eq:60}
  e^m\tF^{(n)}= \sum_{p=0}^{\min(m,n)}
    q^{-n(m-p)}{\bbq mp} \tF^{(n-p)}\{H-m-n+2p\}_{q,p} {e^{m-p}}.
\end{gathered}$$ Here, for $i\in \modZ$ and $p\ge 0$, we set $$\{H+i\}_{q,p} = \{H+i\}_q\{H+i-1\}_q\cdots\{H+i-p+1\}_q,$$ where $$\{H+j\}_q = q^{H+j}-1 = q^jK^2-1$$ for $j\in \modZ$. Note that $\{H+j\}_q,\{H+i\}_{q,p}\in \Zqq[K^2,K^{-2}]$.

The following is a "$q$-version" of [@H:uqsl2 Proposition 3.1], which can be easily proved using [\[eq:58\]](#eq:58){reference-type="eqref" reference="eq:58"}--[\[eq:60\]](#eq:60){reference-type="eqref" reference="eq:60"}.

::: lemma
[]{#r39 label="r39"} $\Uq$ (resp. $\Uqv$) is freely spanned over $\Zqq$ by the elements $\tF^{(i)}K^je^k$ (resp. $\tF^{(i)}K^{2j}e^k$) with $i,k\ge 0$ and $j\in \modZ$.
:::

Recall from [@H:uqsl2] that $\Uq$ inherits from $U_h$ a Hopf $\Zqq$-algebra structure, which can be easily verified using the following formulas, which we also need later. $$\begin{gathered}
  \label{eq:53}
  \Delta (K^i) = K^i\otimes K^i,\quad   S^{\pm 1}(K^i) = K^{-i},\\
  \label{eq:54}
  \Delta (e^n) = \sum_{j=0}^n {\bb nj}_q e^{n-j}K^j\otimes e^j,\quad
  \Delta (\tF^{(n)})=\sum_{j=0}^n \tF^{(n-j)}K^j\otimes \tF^{(j)},\\
  \label{eq:55}
  S^{\pm 1}(e^n)=(-1)^n q^{\hf n(n\mp1)} K^{-n} e^n,\quad
  S^{\pm 1}(\tF^{(n)}) =(-1)^n q^{-\hf n(n\mp1)} K^{-n}\tF^{(n)},\\
  \label{eq:4}
  \epsilon (K^i)=1,\quad \epsilon (e^n)=\epsilon (\tF^{(n)}) = \delta _{n,0}.
\end{gathered}$$

For $n\ge 0$, the $n$-output comultiplication $\Delta ^{[n]}\zzzcolon U_h\rightarrow \Uhhon$ is defined inductively by $\Delta ^{[0]}=\epsilon$, and $\Delta ^{[n+1]}=(\Delta ^{[n]}\otimes \id)\Delta$ for $n\ge 0$. For $x\in U_h$ and $n\ge 1$, we write $$\Delta ^{[n]}(x)=\sum x_{(1)}\otimes \cdots\otimes x_{(n)}.$$
