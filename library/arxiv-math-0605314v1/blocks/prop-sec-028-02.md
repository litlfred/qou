Two elements $m,n\in \modN$ are said to be *adjacent* to each other (written $m\Leftrightarrow n$) if $m/n=p^e$ with $p$ prime and $e\in \modZ$. For a subset $S\subset \modN$, a limit point of $S$ is defined to be an element $m\in \modN$ which is adjacent to infinitely many elements of $S$.
