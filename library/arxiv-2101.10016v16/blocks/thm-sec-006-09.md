Let C be a semisimple linear category. (a) The assignment F → D, D(ρ) := dim(F(ρ)), is a bijective correspondence between faithful functors F : C → Vec up to natural isomorphism and functions D : Irr(C) → N. (b) If C is tensorial then the functor F admits a weak quasi-tensor structure if and only if D is an integral weak dimension function. Furthermore, quasi-tensor structures correspond to genuine dimension functions. (c) The weak quasi bialgebra structures on A = Nat0(F) associated to the various weak quasi-tensor structures on F of dimension D as in Theorem 7.6 are pairwise twist isomorphic.
