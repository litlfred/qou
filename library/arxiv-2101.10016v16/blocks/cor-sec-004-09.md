Let C be a rigid tensor category and F : C → Vec be a weak tensor functor. Then dim(F(ρ)) = dim(F(ρ ∨ )) = dim(F( ∨ρ)) for every object ρ. If a tensor category is rigid, left and right duals need not be isomorphic. It is easy to see that this is the case if and only if ρ ≃ ρ ∨∨ and, following M¨uger, we call ρ∨ a two-sided dual of ρ. We shall say that C has two-sided duals if every object has a two-sided dual. For example, duals are two-sided if C is a semisimple tensor category, see e.g. Prop. 2.1 in [51], a tensor category with a coboundary, e.g. a braided symmetry, by Prop. 27.7, or a tensor ∗-category [118].
