Let E : C → D be a linear equivalence between semisimple tensor categories with D strict. The simplest solution, that is Eρ,σ = 1 for all objects ρ, σ, is possible only if E is multiplicative on objects, E(ρ) ⊗ E(σ) = E(ρ ⊗ σ). By (4.6), (4.7), (E, 1) is a tensor equivalence if and only if C is strict as well. In the applications to CFT in the setting of vertex operator algebras, tensor categories are not strict. If we try to use Mac Lane strictification theorem then we add many undesired objects to the categories, thus Example 8.24 may turn too restrictive.
