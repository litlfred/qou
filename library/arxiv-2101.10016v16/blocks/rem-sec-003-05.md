It is well known (Theorem 1 in IV.4 of [123]) that a linear functor F : C → C ′ is a linear equivalence if and only if it is full and faithful (i.e. bijective between the morphism spaces) and essentially surjective (every object of C ′ is isomorphic to one in the image of F.) We shall use these definitions interchangeably. When C and C ′ are semisimple, this is equivalent to the property that {F(ρ), ρ ∈ Irr(C)} is a complete set of pairwise non-isomorphic simple objects in C ′ .
