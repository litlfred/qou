Let F, F ′ : C → C ′ be two weak quasi-tensor functors between pretensor categories defined by (Fρ,σ, Gρ,σ), (F ′ ρ,σ, G′ρ,σ), respectively. A natural transformation η : F → F ′ is called monoidal if ηι = 1ι and if F ′ ρ,σ ◦ ηρ ⊗ ησ = ηρ⊗σ ◦ Fρ,σ, G′ ρ,σ ◦ ηρ⊗σ = ηρ ⊗ ησ ◦ Gρ,σ.
