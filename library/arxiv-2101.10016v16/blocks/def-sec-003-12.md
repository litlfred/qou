A tensor equivalence between tensor categories C and C ′ is a tensor functor E : C → C ′ which is an equivalence of linear categories. It is known that a quasi-inverse G : C ′ → C may be chosen tensorial and the natural transformations 1C′ → FG, 1C → GF monoidal see Remark 2.4.10 in [50]. In particular, G is a tensor equivalence as well.
