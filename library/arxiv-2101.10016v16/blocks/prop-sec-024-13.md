Let C be a fusion category and ω ∈ Z (Ch(C); T) normalized. If D is the right duality functor of C associated to the right duality (ρ ∨ , bρ, dρ) and η ∈ (1, D2) is a pivotal (spherical) structure then (ρ ∨ , bω, dω) is a right duality for C ω where bω ρ = bρ, d ω ρ = dρω −1 (g, g−1, g), with ρ simple and [ρ] = g. Furthermore η ω = η is a pivotal (spherical) structure for the associated right duality functor Dω. In particular, if η is spherical under the correspondence (η, D) → (η ω , Dω) we have dC(ρ) = dCω (ρ) for every object ρ. Furthermore, C is pseudo-unitary if and only if so is C ω .
