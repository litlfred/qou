Let C be a semisimple tensor category with generating object ρ. The category C s ρ is a strict tensor category. Moreover (H, H) : C s ρ → C is a tensor equivalence, where H : C s ρ → Cρ is the inclusion and Hρn,ρm := ρn ⊗ ρm → ρn+m the unique associativity morphism given by Mac Lane coherence. If c is a braided symmetry for C then c is a braided symmetry for C s ρ ; if C is rigid then C s ρ is rigid; if v is a ribbon structure for C then v is a ribbon structure for C s ρ . In these cases, (H, H) becomes a braided or ribbon tensor equivalence, accordingly.
