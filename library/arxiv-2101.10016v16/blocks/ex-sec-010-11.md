We have the following generalization of the construction in Remark c) in 11.2. Let A be a unitary discrete weak quasi bialgebra with an Ω-involution given by Ω ∈ M(A ⊗ A). We may consider T = Ω1/2 defined via continuous functional calculus in each full matrix subalgebra of M(A⊗A). This element satisfies the properties T ∆(I) = T, ∆(I) ∗T = T, and ω ⊗ 1(T) = 1 ⊗ ω(T) = 1, so we may regard T as an element of A with the same domain ∆(I) as Ω. Applying the same construction to Ω−1, we construct T ′ = (Ω−1 ) 1/2 ∈ M(A ⊗ A) with range ∆(I).
