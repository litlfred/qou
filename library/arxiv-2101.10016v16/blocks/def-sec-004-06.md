Let C be a rigid tensor category with braided symmetry c. A ribbon structure is a natural isomorphism v ∈ (1, 1) such that c(σ, ρ) ◦ c(ρ, σ) = vρ ⊗ vσ ◦ v −1 ρ⊗σ and compatible with some right duality. In a ribbon category one has a notion of C-valued categorical trace Trρ(T) for all morphisms T ∈ (ρ, ρ) see Sect. 27 for the definition. For any pair of objects ρ, σ, consider the matrix Sρ,σ = Trρ⊗σ(c(σ, ρ)c(ρ, σ)). The number Sρ,σ depends on X and Y only up to isomorphism. When C is a fusion ribbon category, let {ρi} be a complete set of irreducible objects.
