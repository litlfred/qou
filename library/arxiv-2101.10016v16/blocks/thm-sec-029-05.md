Let A be a discrete unitary coboundary wqh algebra with compatible ∗- involution satisfying all the assumptions in the statement and in part c) of theorem 30.4 (e.g. A has strongly trivial involution, see Def. 11.9). Let T be the twist defined in Theorem 30.4. Then T induces a canonical unitary equivalence of ribbon categories Rep+(A) → Rep+(AT ). Moreover, if A is semisimple then Rep(A) is modular if and only if Rep(AT ) is modular. If A has antipode defined by elements α and β such that β = α ∗ (e.g. of Kac type) then Rep+(A) is a unitary modular fusion category if and only if so is Rep+(AT ).
