Let G be a finite group and ω ∈ H3(G, C ×). The pointed fusion category Vecω G admits the natural dimension function taking value 1 on every irreducible and the associated quasi-Hopf algebra is Fun(G, C)ω, see Example 5.13.6 in [50]. In particular, we obtain a Hopf algebra if and only if ω is trivial in H3(G, C ×). We next see that for G = ZN and ω = 1 for N odd (ω = −1 for N even) this fusion category may also be described as the representation category of AW = AW (slN , q, N + 1).
