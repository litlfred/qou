Let C be a tensor C ∗ -category with finite dimensional morphism spaces and D a weak dimension function on C. Then there is a faithful weak quasi-tensor ∗- functor G : C → Hilb such that D(ρ) = dim(G(ρ)). If A is the discrete unitary weak quasi bialgebra corresponding to G via duality then all the others corresponding to different weak quasi-tensor ∗-functors with the same dimension function are isomorphic to AF,t for some twist F ∈ A ⊗ A and t ∈ A+ of the bialgebra and Ω-involutive structure of A respectively.
