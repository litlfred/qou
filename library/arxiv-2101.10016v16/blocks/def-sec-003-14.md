A C ∗ -category is a ∗-category where morphism spaces are Banach spaces such that the norm satisfies ∥S ◦ T∥ ≤ ∥S∥∥T∥ and ∥T ∗ ◦ T∥ = ∥T∥2 for every pair of morphisms S, T and S ∗S is positive (i.e. has positive spectrum) in the algebra (ρ, ρ) for every morphism S ∈ (ρ, σ). Finally, a tensor C ∗ -category is a tensor ∗-category which is also a C ∗ -category with respect to the given ∗-involution. The positivity condition is equivalent to the existence of S ′ ∈ (ρ, ρ) such that S∗S = S ′∗S′ . It follows in particular that (ρ, ρ) is a C ∗ -algebra for any object ρ.
