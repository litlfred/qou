Let C and C ′ be pseudo-unitary ribbon fusion categories with ribbon structures θ and θ ′ , assumed positive for N even, and with based Grothendieck rings isomorphic to RN,ℓ with N + 1 ≤ ℓ < ∞. Let f : Gr(C) → Gr(C ′ ) be a based ring isomorphism such that for each irreducible ρ ∈ C, θ ′ ρ ′ = θρ where ρ ′ is an irreducible in C ′ in the class of f[ρ]. Then there is an equivalence of ribbon braided tensor categories F : C → C ′ inducing f. If the categories are unitary, F may be chosen unitary.
