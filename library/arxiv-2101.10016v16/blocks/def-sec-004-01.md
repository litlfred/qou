Let C be a tensor category with associativity morphisms αρ,σ,τ ∈ ((ρ ⊗ σ) ⊗ τ, ρ ⊗ (σ ⊗ τ )). An object ρ ∨ is a right dual of ρ if there are morphisms d ∈ (ρ ∨ ⊗ ρ, ι) and b ∈ (ι, ρ ⊗ ρ ∨ ) satisfying the right duality equations 1ρ ⊗ d ◦ αρ,ρ∨,ρ ◦ b ⊗ 1ρ = 1ρ, (5.1) d ⊗ 1ρ∨ ◦ α −1 ρ∨,ρ,ρ∨ ◦ 1ρ∨ ⊗ b = 1ρ∨ . (5.2) A left dual object ∨ρ is defined by morphisms b ′ ∈ (ι, ∨ρ ⊗ ρ), d′ ∈ (ρ ⊗ ∨ρ, ι) satisfying the left duality equations d ′ ⊗ 1ρ ◦ α −1 ρ,∨ρ,ρ ◦ 1ρ ⊗ b ′ = 1ρ, (5.3) 1∨ρ ⊗ d ′ ◦ α∨ρ,ρ,∨ρ ◦ b ′ ⊗ 1∨ρ = 1∨ρ.
