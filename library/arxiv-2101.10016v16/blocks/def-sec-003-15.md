A ∗-functor F : C → C ′ between ∗ -categories is a linear functor satisfying F(T ∗ ) = F(T) ∗ for all morphisms T ∈ C. If C and C ′ are tensor ∗ -categories, a ∗-functor endowed with a weak quasi tensor structure will be called a weak quasi tensor ∗-functor. Let F be a weak quasi tensor ∗-functor defined by Fρ,σ, Gρ,σ. Then the adjoint pair F ′ ρ,σ = G∗ ρ,σ, G′ ρ,σ = F ∗ ρ,σ defines another weak quasi tensor structure on F.
