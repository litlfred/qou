Let C and C ′ be semisimple tensor categories and let f : Gr(C) → Gr(C ′ ) be an isomorphism between their Grothendieck rings. Let (A, ∆, Φ ′ ) be a weak quasi bialgebra corresponding to an integral weak dimension function D′ on C ′ . Then there is an associator Φ for A defining a new weak quasi bialgebra (A, ∆, Φ) which corresponds to C with respect to D = D′f. In particular, if C ′ is a finite semisimple tensor category then C is tensor equivalent to one with the same category and tensor product structure as C ′ but possibly different associativity morphisms.
