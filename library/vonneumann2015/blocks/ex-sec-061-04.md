Continuously varying index. Choose a projection of trace d in the hyperﬁnite type II1 factor R. Then pRp and (1 −p)R(1 −p) are isomorphic by hyperﬁniteness so choose a von Neumann algebra isomorphism θ : pRp →(1 −p)R(1 −p). Let M be R and N be the subalgebra {x + θ(x)|x ∈pRp}. It is clear that pMp = Np and (1 −p)M(1 −p) so by lemma 19.2.3, [M : N] = 1 d + 1 −d. As d varies between 0 and 1, this index takes all real values ≥4. Observe though that N ′∩M contains p so the subfactor is reducible. The set of index values for irreducible subfactors of R is not understood though for other type II1 factors it may be the interval [4, ∞]
