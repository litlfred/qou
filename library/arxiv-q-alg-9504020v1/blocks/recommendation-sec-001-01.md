For any non-negative integer $n<N$ define the symbol: $$(\omega)_n=\cases{1, &if $n=0$;\cr \prod_{j=1}^n(1-\omega^j), &$0<n<N$,\cr}$$ Under complex conjugation we have the following properties: $$(\omega)_n^*=(\omega^*)_n,\quad \omega^*\omega=1.$$ It will be convenient to use the "theta"-function, defined on integers: $$\theta(n)=\cases{1, &$0\le n< N$;\cr 0,&otherwise,\cr}\quad n\in Z.$$ For any $n\in Z$ denote by $[n]$ the coresponding integer residue modulo $N$, lying in the interval $\{0,\ldots,N-1\}$: $$=n\pmod N,\quad 0\le [n]<N,\quad n,[n]\in Z.\label{brac}$$ The evident property of this function is its' periodicity: $$=[n],\quad n\in Z. \label{periodicity}$$ It should be stressed however that the "bracketing" is a map from $Z$ to $Z$ rather than to $Z_N$, the ring of residues modulo $N$.
