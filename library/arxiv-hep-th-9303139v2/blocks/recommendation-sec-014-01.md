The main property of the Van-der-Monde determinant is that it is at the same time a $Pfaffian$ (and it is in this quality that it arises from matrix integrals) and a $determinant$ (and this is the feature that implies integrability): \be \prod_{i>j}(h_i-h_j) = \Delta(h) = {\rm det}_{ij}h_i^{j-1}. \label{vdmd} \ee We already used this property above, when going from eq.(\ref{KIev}) to eq.(\ref{KIev'}), which as we shall see later is the crucial step in the proof of integrability of Kontsevich model.
