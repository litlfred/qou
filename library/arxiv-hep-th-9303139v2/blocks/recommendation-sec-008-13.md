Namely, we shall prove the following identity \cite{tildeW}: \be \left(\frac{\partial}{\partial \Lambda_{tr}}\right)^{m+1} {\cal Z}\{ T_k\} = (\pm)^{m+1} \sum_{l\geq 0} \Lambda^{-l-1} \tilde W_{l-m}^{(m+1)}( T) {\cal Z}\{ T_k\}, \label{tiwko} \ee valid for $any$ function ${\cal Z}$ which depends on $ T_k = \mp\frac{1}{k}{\rm tr}\Lambda^{-k},\ \ k\geq 1\ $ and $ T_0 = \pm{\rm tr}\log \Lambda$ with $n\times n$ matrix $\Lambda$.
