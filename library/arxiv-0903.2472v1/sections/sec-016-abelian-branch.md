For completeness, we can also mention perturbation theory around an abelian flat connection ${\cal A}^{({\rm abel})}$ on $M$, although it has no obvious counterpart in the state integral model.

For an abelian flat connection ${\cal A}^{({\rm abel})}$, the classical Chern-Simons action [\[szero\]](#szero){reference-type="eqref" reference="szero"} vanishes. This is exactly what one finds from [\[S0_integral\]](#S0_integral){reference-type="eqref" reference="S0_integral"}: $$S_0^{({\rm abel})} (u) =\int_0^u du\, v_{{\rm abel}} (u)
+ i\pi u = 0 \qquad (\mbox{mod $2\pi i u$})\,,$$ fixing the constant of integration so that $S_0^{(\rm abel)}(0)=0$. From the hierarchy of differential equations, the first few subleading coefficients are

::: {#tab:figeightabel}
  ------------------------- --- ----------------------------------------------------------------------------------------------------------------------------
    $S_1^{({\rm abel})}(u)$  =  $\displaystyle\log\frac{m(m^2-1)}{1 - 3 m^2 + m^4},$
    $S_2^{({\rm abel})}(u)$  =  $0$
    $S_3^{({\rm abel})}(u)$  =  $\displaystyle \frac{4(m^2-1)^2}{(1 - 3 m^2 + m^4)^3}\big(1-7m^2+16m^4-7m^6+m^8\big) ,$
    $S_4^{({\rm abel})}(u)$  =  $0$
    $S_5^{({\rm abel})}(u)$  =  $\displaystyle \frac{4(m^2-1)^2}{3(1 - 3 m^2 + m^4)^6}\big(41 - 656 m^2 + 4427 m^4 - 16334 m^6 + 35417 m^8 - 46266 m^{10}$
                                $+ 
                                 35417 m^{12} - 16334 m^{14} + 4427 m^{16} - 656 m^{18} + 41 m^{20}\big)$
    $S_6^{({\rm abel})}(u)$  =  $0$ ....
                                
  ------------------------- --- ----------------------------------------------------------------------------------------------------------------------------

  : Perturbative invariants $S_n^{({\rm abel})}(u)$ up to six loops.
:::

In the language of Section [\[sec:symmetries\]](#sec:symmetries){reference-type="ref" reference="sec:symmetries"}, the abelian branch must be its own "signed pair," guaranteeing that all even $S_{2k}^{(\rm abel)}(u)$ vanish.

Having determined the perturbative coefficients for the three branches of classical solutions (in principle to any order desired), we can now compare them with the computation of the state integral model.
