2.2.2
Lemma
Suppose M is a graded R-bimodule generated by a homogenous element m ∈M. Then M is
indecomposable.
Proof: We have M = RmR. Let d = deg(m). Then M d = R0mR0,. Suppose that M = L ⊕N.
Then M d = Ld ⊕N d, so we can say WLOG m ∈L. Then M = R · m · R ⊂L, which implies that
N d = 0, so that M = RmR ⊂N, i.e. N = 0.
