LetMbe a closed, orientable 3–manifold. For each integern≥0,we define the invariant
voltn(M) = inf

volH(M\K)|K⊂Mis a hyperbolicn–component link
	
.(2.2)
For alln≥1 and all closed, orientable 3–manifoldsM, we have volt(M)≤volt n(M). In
particular, volt(M) = volt 0(M)<volt n(M) if and only ifMis hyperbolic. This also allows us
to define an integer valued invariant
h(M) = min{n|volt(M) = volt n(M)}.
HenceMis hyperbolic if and only ifh(M) = 0.The examples presented in Section 4Section 4 and based
on the census in [ GHM+21GHM+21] satisfyh(M) = 1.
Question 2.5Is there an explicit family of examples (M n) withh(M n) =n?
Myers [Mye93Mye93] showed that every homology class (indeed every free homotopy class) in a closed
3–manifold is represented by some hyperbolic knot. More generally, he showed that every given
finite set of free homotopy classes can be represented by a hyperbolic link. Hence for each class
c∈H 1(M),there is an invariant
volt(M,c) = inf

volH(M\L)|L⊂Mis an oriented hyperbolic link with [L] =c
	
.(2.3)
A natural question is to ask which homology classes satisfy volt(M,c) = volt(M).Some examples
and a further discussion of this refinement can be found in Section 4.3Section 4.3.
