The elements JA k are sometimes called multiplicative Jucys–Murphy elements in the Iwahori–Hecke algebra of type A. There seems to be no agreement in the literature on which elements to call the Jucys–Murphy elements in other types. We chose our convention because under it the deﬁnition of the Jucys–Murphy element is uniform in all types, but elements jX k for X = B, D deﬁned below arguably also deserve the name.
