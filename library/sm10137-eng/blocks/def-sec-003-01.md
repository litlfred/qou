The operator K on L2(E) is locally trace class if for each bounded measurable subset B of E the operator χBKχB is trace class. Let J loc (L2(E)) denote the space of locally trace-class operators. Recall that for K ∈J1 the Fredholm determinant det(I + K) is well defined, which is equal to a product, det(I + K) = Q λ∈σ(K)(1 + λ), by Lidskii’s theorem. It is continuous with respect to the trace norm. We also define the regularized determinant by det 2(I + K) = exp(−Tr(K)) det(I + K).
