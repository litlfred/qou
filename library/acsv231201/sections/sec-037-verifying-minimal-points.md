The diﬃcult part of this approach is working with the critical points implic-
itly through their deﬁning algebraic equations. Gr¨obner basis computations can
be slow, and theoretical complexity guarantees are weak in the worst case. Mel-
czer and Salvy [MS21] give a complexity analysis for smooth varieties using a
Kronecker representation, which parametrizes the generically ﬁnite set of crit-
ical points by the roots of a univariate polynomial in a new variable that is an
integer linear combination of z1,..., zd, t. Other alternatives include homotopy
methods for polynomial system solving [LMS22], or proving minimality by
