If A is the class of lattice paths in N2 using the steps North (0, 1), East (1, 0), and Northeast (1, 1) enumerated by endpoint then the counting sequence ar = |Ar| deﬁnes the Delannoy numbers [Com74, Exercise I.21]. The generating function x + y + xy for the set of steps leads to the Delannoy generating function F(x, y) = 1 −x −y −xy . ◁
