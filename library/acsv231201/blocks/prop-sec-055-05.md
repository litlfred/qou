For any positive integers n and d, determining whether a homogeneous polynomial f ∈Q[z] of degree n in d variables has a factoriza- tion into n (possibly repeated) linear terms is decidable via computer algebra. If f is a product of linear factors, then whether these factors are distinct is also decidable by computer algebra. Proof The set of coeﬃcients of products of n homogeneous linear polynomi- als in d dimensions forms an algebraic variety.
