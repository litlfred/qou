Appendix B Algebraic topology Having established the necessary background for integration on real and com- plex manifolds in Appendix A, we now move on to the topological results that allow us to manipulate these integrals in order to derive asymptotics. A diﬀer- ential form ω is said to be a closed form if dω = 0 and an exact form if ω = dτ for some form τ. Many of the forms we care about are closed, for instance if ω is any holomorphic n-form in Cn then ∂ω vanishes by holomorphicity and ∂ω vanishes because there are no holomorphic (n + 1)-forms, hence ω is closed.
