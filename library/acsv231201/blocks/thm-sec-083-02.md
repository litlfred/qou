27. If C is any (n + 1)-chain on a domain U ⊆Cn and ω is any holomorphic n-form on U then Z ∂C ω = 0 . Proof The d operator preserves holomorphicity, so dω is holomorphic. There are no holomorphic forms above rank n and ∂ω is a (n+1)-form, hence ∂ω = 0. Stokes’s Theorem then gives Z ∂C ω = Z C dω = 0 . □ Exercise A.15.
