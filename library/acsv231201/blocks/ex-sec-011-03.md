If an = 1/n! then {an} is P-recursive as (n + 1)an+1 −an = 0 for all n ≥0. Furthermore, if f(z) enumerates {an} then P n≥0(n + 1)an+1zn = f ′(z), so f ′(z) −f(z) = 0 and f is D-ﬁnite. We can compute f by solving this linear diﬀerential equation with the initial condition a0 = 1, obtaining the expected solution f(z) = ez = P n≥0 zn/n!. ◁ The correspondence between P-recursive sequences and D-ﬁnite series is a classical result, known at least as far back as Frobenius’s work on computing series solutions to ordinary diﬀerential equations.
