Let X = I × S 1, where I is the interval [−1, 1] and S 1 is the unit circle parametrized by θ ∈[−π, π] with the endpoints identiﬁed, so that X can be nicely embedded in C2. We apply Theorem 5.3 in the case p = k = 1 and d = 2, with A(x, y) = 1 and φ : X →C deﬁned by φ(t, θ) = Kθ2 + iLθt (5.8) for real numbers K > 0 and L. The phase φ is analytic on X, and the 2-chain C representing X can be any cell complex with a subcomplex I×N for a compact neighborhood N of θ = 0 in S 1. There is a single critical point p = (0, 0), at which Re φ vanishes, so G′ = G = {p}.
