Consider the class of lattice paths on Z2 that start at the origin and must remain in the nonneg- ative quadrant N2 while using the set {(1, 0), (1, −1), (−1, 0), (−1, 1)} of allow- able steps. The kernel method [Mel21, Chapter 4] allows one to prove that the generating function enumerating such walks by number of steps is the main diagonal of F(x, y, t) = (x + 1)(x−2 −y−1)(x −y)(x + y) 1 −xyt(x + xy−1 + yx−1 + x−1) . This is a rational function with smooth singular variety, and minimal critical points p1 = (1, 1, 1/4) and p2 = (−1, 1, 1/4).
