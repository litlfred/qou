4. The unit torus in Cd is the set {z ∈Cd : |z j| = 1 for all 1 ≤j ≤ d}. Identifying Cd with R2d, this set is deﬁned by x2 j + y2 j = 1 for all 1 ≤j ≤d, and is thus always a real d-manifold. On the other hand, the unit torus is never a complex manifold. When d is odd this follows immediately from the fact that it has the wrong dimension to be a complex manifold (when d is even then the concept of tangent spaces, described below, can be used to prove the unit torus is not a complex manifold).
