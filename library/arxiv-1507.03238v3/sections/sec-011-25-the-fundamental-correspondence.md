The following result is proved in [@GaroufalidisThurstonZickert] for $\mathop{\mathrm{SL}}(n,\mathbb C)$. For $n=2$ the correspondence is particularly simple, and is illustrated in Figure [1](#fig:FundamentalCorrespondence){reference-type="ref" reference="fig:FundamentalCorrespondence"}.

::: theorem
We have a one-to-one-correspondence $$\label{eq:FundamentalCorrespondence}
\left\{\text{Generic $P$-decorations}\right\}\overset{\text{1:1}}{\longleftrightarrow}P(\mathcal T)\overset{\text{1:1}}{\longleftrightarrow}\left\{\text{Natural cocycles on $\overline\mathcal T$}\right\}$$ respecting the diagonal action.0◻
:::

<figure id="fig:FundamentalCorrespondence">

<figcaption>The fundamental correspondence.</figcaption>
</figure>

::: remark
[]{#rm:NonGenericDecoration label="rm:NonGenericDecoration"} A decoration $(g_0P,\dots,g_3P)$ is generic if and only if $c_{ij}\neq0$, where $c_{ij}$ are defined as in Figure [1](#fig:FundamentalCorrespondence){reference-type="ref" reference="fig:FundamentalCorrespondence"}. Even if a decoration is not generic, the Ptolemy relation is still satisfied.
:::
