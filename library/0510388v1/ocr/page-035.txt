Consider the following features of parallel transport on S° :

e If we start with a tangent vector V ata single point x € S* and then parallel
transport it to each possible point y € S*, we get a vector field W(y) = Pyx V
which is defined for all y € S* except for the point y = —x antipodal to x.

The orbits of the vector field P,,V are all the oriented circles,
great and small, which are tangent at the point —x to the vector —V.

e The vector field Py, V is neither divergence-free nor a curl eigenfield.
We will obtain and use explicit formulas for its divergence and curl.
