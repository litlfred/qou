[]{#sec3 label="sec3"} In this section we set $[n]:=\{1, ... ,n\}$ and $E_n:=\{\{i,j\} :\; i,j \in [n], \ i <j \}$. We recall also that ${\mathcal G}_n$ is the set of all connected graphs with vertex set $[n]$ (i.e labeled connected graphs with $n$ vertices) and ${\mathcal T}_n$ is the set of all trees with vertex set $[n]$ (i.e labeled trees with $n$ vertices). Given $g\in {\mathcal G}_n$, we denote $E_g$ its edge set. Given $g\in {\mathcal G}_n$ and $g'\in {\mathcal G}_n$ such that $E_g\subset E_{g'}$, we say that $g$ is a subgraph of $g'$ and write $g\subset g'$. Note that the pair $({\mathcal G}_n, \subset)$ is a partially ordered set. Given $g,g'\in {\mathcal G}_n$ such that $g\subset g'$, we denote $[g,g'] =\{g''\in {\mathcal G}_n: g\subseteq g''\subseteq g'\}$. In other words $[g,g']$ is an interval in $({\mathcal G}_n,\subset)$. Given a set $S$, we denote by $|S|$ its cardinality.
