[]{#sec:pinched-limit label="sec:pinched-limit"}

In the computation of the $R$-matrix in [\[sec:R-matrix\]](#sec:R-matrix){reference-type="ref" reference="sec:R-matrix"} we excluded certain singular ("pinched") configurations of characters. We now explain how to derive the $R$-matrix there as a limit of the generic case.

::: definition
[]{#def:standard-flattening label="def:standard-flattening"} Consider a $\chi$-colored crossing as in [\[fig:crossing-regions\]](#fig:crossing-regions){reference-type="ref" reference="fig:crossing-regions"}. If any of the relations $$\label{eq:pinched-crossing-conditions}
    b_2 = m_1 b_1
    ,\quad
    m_2 b_2 = m_1 b_{1'}
    ,\quad
    b_{2'} = b_{1}
    ,\quad
    m_2 b_{2'} = b_{1'}$$ hold it is not hard to show that all of them do. In this case we say the crossing is . There is an obvious way to choose logarithms $\beta_i$ of the parameters $b_i$ at a pinched crossing; we say a log-coloring of such a crossing is if there is a $\beta$ so that $$\begin{aligned}
    \label{eq:standard-flattening}
    \beta_{1} &= \beta,
              &
    \beta_{2} &= \beta + \mu_1,
              &
    \beta_{1'} &= \beta + \mu_2\text{, and}
               &
    \beta_{2'} &= \beta.
  
\end{aligned}$$ This is equivalent to requiring $\zeta_{\lN}^0 = \zeta_{\lW}^0 = \zeta_{\lS}^0 = \zeta_{\lE}^0 = 0$ in terms of the parameters ([\[eq:flattening-N\]](#eq:flattening-N){reference-type="ref" reference="eq:flattening-N"}--[\[eq:flattening-E\]](#eq:flattening-E){reference-type="ref" reference="eq:flattening-E"}).
:::

::: remark
[]{#rem:pinched eigenlines label="rem:pinched eigenlines"} This definition has a geometric interpretation discussed in more detail in [@McPhailSnyder2024]. Consider a braid diagram $D$ and write $\pi$ for the fundamental group of the complement of the braid. Via the Wirtinger presentation $\pi$ is generated by meridians. A $\chi$-coloring of $D$ determines both a representation $\rho : \pi \to \slg$ and a of $\rho$, which is a distinguished eigenspace $L \in \mathbb{C}P^1$ for the image of each meridian under $\rho$ (generically $g \in \slg$ has two eigenspaces, and we pick one). A crossing is pinched exactly when the eigenspaces $L_{1}, L_{2}$ of the incoming overstrand and understrand are equal.
:::

::: remark
[]{#rem:standard-flattening label="rem:standard-flattening"} We can use [\[thm:R-matrix transformation\]](#thm:R-matrix transformation){reference-type="ref" reference="thm:R-matrix transformation"} to write the $R$-matrix of a nonstandard log-coloring in terms of a standard one with some index shifts and scalar factors that are nonsingular in the pinched limit. As such, we consider only standard pinched log-colorings.
:::

For $k \in \mathbb{Z}$ we write $\modb{k}$ for the unique integer with $$0 \le \modb{k} < N
  \text{ and }
  \modb{k} \equiv k \pmod N$$ We also write $$\cutoff{k}
  =
  \begin{cases}
    1 & 0 \le k \le N-1
    \\
    0 & \text{ otherwise,}
  \end{cases}
  =
  \begin{cases}
    1 & k = \modb{k}
    \\
    0 & \text{ otherwise.}
  \end{cases}$$ Recall the $q$-Pochhammer symbol $\qp{a}{n}$ of [\[eq:qp-def\]](#eq:qp-def){reference-type="eqref" reference="eq:qp-def"}, which satisfies $$\qp{\omega}{n} = (1 - \omega) \cdots (1 - \omega^{n -1}) \text{ for } n \ge 0.$$

::: theorem
[]{#thm:R-mat-pinched label="thm:R-mat-pinched"}

::: thmenum
[]{#thm:R-mat-pinched:regular label="thm:R-mat-pinched:regular"} The $R$-matrices [\[eq:R-mat-positive\]](#eq:R-mat-positive){reference-type="eqref" reference="eq:R-mat-positive"} are well-defined in the pinched limit where $e^{2\pi i \zeta_j^0} \to 1$.

[]{#thm:R-mat-pinched:formula label="thm:R-mat-pinched:formula"} At a positive, pinched crossing with a standard log-coloring the matrix coefficients are given by $$\label{eq:R-mat-pinched:formula}
        \begin{aligned}
          \rmat{n_1}{n_2}{n_1'}{n_2'} 
          &=
          \frac{1}{N}
          \theta_{n_1 n_2}^{n_1' n_2'}
          A_{n_1 n_2}^{n_1' n_2'}
          \\
          &\phantom{=}\times
          \omega^{
            n_1(\alpha_1-\mu_1 - 1)
            +
            n_2(\alpha_2 + \mu_2 + 1)
            -
            n_1' (\alpha_{1'} - \mu_{1})
            -
            n_2' (\alpha_{2'} + \mu_2)
          }
          \\
          &\phantom{=}\times
          \frac{
            \qp{\omega}{\modb{n_2' - n_1'}}
            \qp{\omega}{\modb{n_2 - n_1 - 1}}
            }{
            \qp{\omega}{\modb{n_2' - n_1}}
            \qp{\omega}{\modb{n_2 - n_1'}}
          }.
        \end{aligned}$$ Here $$\theta_{n_1 n_2}^{n_1' n_2'}
      =
      \cutoff{
        \modb{n_1 - n_2} + \modb{n_1' - n_2' -1}
      }
      \cutoff{
        \modb{n_2' - n_1} + \modb{n_2 - n_1'}
      }$$ and $$A_{n_1 n_2}^{n_1' n_2'}
      =
      \frac{a_{1'}}{a_1}
      \left( \frac{a_1}{ m_1} \right)^{2 - \cutoff{n_1 - n_2} - \cutoff{n_2 - n_1'}}
      (a_2 m_2)^{- \cutoff{n_2 - n_1'}}
      (a_{2'} m_2)^{1- \cutoff{n_1' - n_2' - 1}}
      .$$

[]{#thm:R-mat-pinched:Kashaev label="thm:R-mat-pinched:Kashaev"} In particular, when $\alpha_i = \mu_i = -1/2 \text{ or } (N- 1)/2$ for all $i$ we obtain $$\label{eq:Kashaev-R-matrix}
      \rmat{n_1}{n_2}{n_1'}{n_2'} 
      =
      \theta_{n_1 n_2}^{n_1' n_2'}
      \frac{
        N
        \omega^{
          n_2' - n_1
          +1/2
        }
        }{
        \qp{\omega}{\modb{n_2' - n_1}}
        \qp{\omega}{\modb{n_2 - n_1'}}
        \qp{\overline{\omega}}[\overline{\omega}]{\modb{n_1' - n_2' - 1}}
        \qp{\overline{\omega}}[\overline{\omega}]{\modb{n_1 - n_2}}
      }$$ Up to complex conjugation this is Kashaev's $R$-matrix [@Kashaev1995]. Specifically, [\[eq:Kashaev-R-matrix\]](#eq:Kashaev-R-matrix){reference-type="eqref" reference="eq:Kashaev-R-matrix"} is $(R_K)_{n_2' n_1'}^{n_1 n_2}$ at $q = \overline{\omega}$, where $R_K$ is the matrix given in [@Murakami2018 Section 4.1] .
:::
:::

As discussed in [\[sec:factorization\]](#sec:factorization){reference-type="ref" reference="sec:factorization"} the pinched $R$-matrices almost factor into four pieces: the obstruction is the term $\theta_{n_1 n_2}^{n_1' n_2'}$.

::: proof
*Proof.* We prove regularity for positive crossings; the negative case works similarly. By [\[rem:standard-flattening\]](#rem:standard-flattening){reference-type="ref" reference="rem:standard-flattening"} we may assume the log-coloring is standard. By [\[thm:R-mat-phi-form\]](#thm:R-mat-phi-form){reference-type="ref" reference="thm:R-mat-phi-form"} the matrix coefficients are $$\begin{aligned}
      \rmat{n_1}{n_2}{n_1'}{n_2'}
    &=
    \frac{
      \omega^{\Theta/2 + (1 - N)\zeta_{\lW}^{0}}
      }{
      N
    }
    \frac{
      \pf{\zeta_{\lN}^0}
      \pf{\zeta_{\lS}^0}
      }{
      \pf{\zeta_{\lE}^0}
      \pf{\zeta_{\lW}^0}
    }
    \\
    &\phantom{=}\times
    \omega^{
      n_1(\alpha_{1}  -\mu_1 - 1)
      +
      n_2(\alpha_{2} + \mu_2 + 1)
      -
      n_1'(\alpha_{1'} -\mu_1)
      -
      n_2'(\alpha_{2'} + \mu_2)
    }
    \\
    &\phantom{=}\times
    ( 1 - \omega^{N\zeta_{\lW}^{0}} )
    \frac{
      \qlog{\zeta_{\lN}^0}{n_2' - n_1}
      \qlog{\zeta_{\lS}^0}{n_2 - n_1'}
      }{
      \qlog{\zeta_{\lW}^0}{n_2 - n_1 - 1}
      \qlog{\zeta_{\lE}^0}{n_2' - n_1'}
    }
  \end{aligned}$$ Because our log-coloring is standard we are taking the limit where each $\zeta_j^0 \to 0$, holding the $\alpha_{i}$ and $\mu_{k}$ fixed. We immediately have $$\frac{
      \omega^{\Theta/2 + (1 - N) \zeta_{\lW}^{0}}
      }{
      N
    }
    \frac{
      \pf{\zeta_{\lN}^0}
      \pf{\zeta_{\lS}^0}
      }{
      \pf{\zeta_{\lE}^0}
      \pf{\zeta_{\lW}^0}
    }
      \to
      \frac{
        1
        }{
        N
      }$$ so it remains to understand $$\label{eq:pinched-hard-part}
      (1 - \omega^{N\zeta_{\lW}^{0}} )
      \frac{
        \qlog{\zeta_{\lN}^0}{n_2' - n_1}
        \qlog{\zeta_{\lS}^0}{n_2 - n_1'}
        }{
        \qlog{\zeta_{\lW}^0}{n_2 - n_1 - 1}
        \qlog{\zeta_{\lE}^0}{n_2' - n_1'}
      }
      .$$ Notice that for $k \in \left\{ \def\given{\ \middle| \ }  -N, -(N-1), \dots, N-1 \right\}$ and $\omega^{N\zeta^1} = (1 - \omega^{N\zeta^0})^{-1}$ we have $$\qlog{\zeta^0}{k}
      =
      (1 - \omega^{N\zeta^0})^{1 - \cutoff{k}} \qlog{\zeta^0}{\modb{k}}
      =
      \omega^{N\zeta^1(\cutoff{k} - 1)} \qlog{\zeta^0}{\modb{k}}$$ so by using $$-\zeta_{\lN}^1 - \zeta_{\lS}^1
      +\zeta_{\lW}^1 + \zeta_{\lE}^1
      =
      \alpha_{1'} - \alpha_{1}$$ we see that [\[eq:pinched-hard-part\]](#eq:pinched-hard-part){reference-type="eqref" reference="eq:pinched-hard-part"} is the product of $$\begin{gathered}
      \label{eq:pinched-cuttoff-term}
      \frac{a_{1'}}{a_{1}}
      \omega^{
        N\left[
          \cutoff{n_2' -  n_1} \zeta_{\lN}^1
          +
          \cutoff{n_2 -  n_1'} \zeta_{\lS}^1
          -
          (\cutoff{n_2 -  n_1-1} + 1) \zeta_{\lW}^1
          -
          \cutoff{n_2' -  n_1'} \zeta_{\lE}^1
        \right]
      }
      \intertext{and}
      \label{eq:pinched-qfac-term}
      \frac{
        \qlog{\zeta_{\lN}^0}{\modb{n_2' - n_1}}
        \qlog{\zeta_{\lS}^0}{\modb{n_2 - n_1'}}
        }{
        \qlog{\zeta_{\lW}^0}{\modb{n_2 - n_1-1}}
        \qlog{\zeta_{\lE}^0}{\modb{n_2' - n_1'}}
      }
    
\end{gathered}$$ Because $\modb{n} \in \left\{ \def\given{\ \middle| \ }  0, \dots, N-1 \right\}$ it is clear that the limiting value of [\[eq:pinched-qfac-term\]](#eq:pinched-qfac-term){reference-type="eqref" reference="eq:pinched-qfac-term"} is $$\frac{
        \qp{\omega}{\modb{n_2' - n_1'}}
        \qp{\omega}{\modb{n_2 - n_1 - 1}}
        }{
        \qp{\omega}{\modb{n_2' - n_1}}
        \qp{\omega}{\modb{n_2 - n_1'}}
      },$$ while [\[eq:pinched-cuttoff-term\]](#eq:pinched-cuttoff-term){reference-type="eqref" reference="eq:pinched-cuttoff-term"} requires more care.

Each $\omega^{N\zeta_j^1}$ has an order $1$ pole in the limit, so [\[eq:pinched-cuttoff-term\]](#eq:pinched-cuttoff-term){reference-type="eqref" reference="eq:pinched-cuttoff-term"} (hence the matrix coefficient) has a zero of order $$\label{eq:matrix-coeff-zero-order}
      \cutoff{n_2 - n_1 - 1}
      +
      1
      +
      \cutoff{n_2' - n_1'}
      -
      \cutoff{n_2' - n_1}
      -
      \cutoff{n_2 - n_1'}.$$ This expression is negative when $$n_2' < n_1, n_2 < n_1', n_1 < n_2 \text{, and } n_1' \le n_2',$$ which is impossible. Therefore the matrix coefficients never have poles, which proves [\[thm:R-mat-pinched:regular\]](#thm:R-mat-pinched:regular){reference-type="ref" reference="thm:R-mat-pinched:regular"}. Furthermore this argument shows that $\rmat{n_1}{n_2}{n_1'}{n_2'}$ is nonzero only when $$\label{eq:matrix-coeff-nonzero-cond}
      \cutoff{n_2 - n_1 - 1}
      +
      \cutoff{n_2' - n_1'}
      -
      \cutoff{n_2' - n_1}
      -
      \cutoff{n_2 - n_1'}
      =
      -1.$$ By using $$\cutoff{n} = 1 + \frac{n - \modb{n}}{N} \text{ for } n \in \left\{ \def\given{\ \middle| \ }  -N, \dots, N-1 \right\}$$ and $$\modb{n} = N- 1 - \modb{-n - 1}$$ we see that [\[eq:matrix-coeff-nonzero-cond\]](#eq:matrix-coeff-nonzero-cond){reference-type="eqref" reference="eq:matrix-coeff-nonzero-cond"} holds exactly when $$\label{eq:matrix-coeff-nonzero-modb}
      \modb{n_1 - n_2} + \modb{n_1' - n_2' -1} + \modb{n_2' - n_1} + \modb{n_2 - n_1'} = N-1.$$ Following [@Murakami2018 Section 4.1] we note that $$\modb{n_1 - n_2} + \modb{n_1' - n_2' -1} + \modb{n_2' - n_1} + \modb{n_2 - n_1'} \equiv -1 \pmod{N}$$ which shows that [\[eq:matrix-coeff-nonzero-modb\]](#eq:matrix-coeff-nonzero-modb){reference-type="ref" reference="eq:matrix-coeff-nonzero-modb"} is true if and only if both $\modb{n_1 - n_2} + \modb{n_1' - n_2' -1}$ and $\modb{n_2' - n_1} + \modb{n_2 - n_1'}$ are less than $N$. We conclude that the matrix coefficient $\rmat{n_1}{n_2}{n_1'}{n_2'}$ is nonzero if and only if $$\cutoff{
        \modb{n_1 - n_2} + \modb{n_1' - n_2' -1}
      }
      \cutoff{
        \modb{n_2' - n_1} + \modb{n_2 - n_1'}
      }
      =
      1$$ which gives the conditional expression $\theta_{n_1 n_2}^{n_1' n_2'}$ above.

To derive $A_{n_1 n_2}^{n_1' n_2'}$, use ([\[eq:flattening-N\]](#eq:flattening-N){reference-type="ref" reference="eq:flattening-N"}--[\[eq:flattening-E\]](#eq:flattening-E){reference-type="ref" reference="eq:flattening-E"}) to write $$\begin{aligned}
      &
      \cutoff{n_2' -  n_1} \zeta_{\lN}^1
      +
      \cutoff{n_2 -  n_1'} \zeta_{\lS}^1
      -
      (\cutoff{n_2 -  n_1-1} + 1) \zeta_{\lW}^1
      -
      \cutoff{n_2' -  n_1'} \zeta_{\lE}^1
      \\
      &=
      \left[
        \cutoff{n_2' -  n_1}
        +
        \cutoff{n_2 -  n_1'}
        -
        (\cutoff{n_2 -  n_1-1} + 1)
        -
        \cutoff{n_2' -  n_1'}
      \right]
      (\kappa - \gamma_{\lN})
      \\
      &\phantom{=}+
      \cutoff{n_2 -  n_1'}(- \alpha_1 - \alpha_2 + \mu_1 - \mu_2)
      \\
      &\phantom{=}-
      [\cutoff{n_2 - n_1 - 1} + 1](- \alpha_1 + \mu_1)
      -
      \cutoff{n_2' - n_1'}(-\alpha_{2'} - \mu_2)
    
\end{aligned}$$ We just showed that $\rmat{n_1}{n_2}{n_1'}{n_2'}$ is nonzero exactly when the coefficient of $(\kappa - \gamma_{\lN})$ above vanishes, and after using the identity $$\cutoff{n} = 1 - \cutoff{-n-1}$$ we see that [\[eq:pinched-cuttoff-term\]](#eq:pinched-cuttoff-term){reference-type="eqref" reference="eq:pinched-cuttoff-term"} is equal to $$\frac{a_{1'}}{a_1}
      \left( \frac{a_1}{ m_1} \right)^{2 - \cutoff{n_1 - n_2} - \cutoff{n_2 - n_1'}}
      (a_2 m_2)^{- \cutoff{n_2 - n_1'}}
      (a_{2'} m_2)^{1- \cutoff{n_1' - n_2' - 1}}$$ which is precisely $A_{n_1 n_2}^{n_1' n_2'}$. This establishes [\[thm:R-mat-pinched:formula\]](#thm:R-mat-pinched:formula){reference-type="ref" reference="thm:R-mat-pinched:formula"}.

Part [\[thm:R-mat-pinched:Kashaev\]](#thm:R-mat-pinched:Kashaev){reference-type="ref" reference="thm:R-mat-pinched:Kashaev"} follows immediately from applying the identities $$\modb{n} = N- 1 - \modb{-n - 1}$$ and $$\qp{\omega}{n}
      \qp{\overline{\omega}}[\overline{\omega}]{N- 1 - n}
      =
      N
      \text{ for }
      0 \le n < N.
      \qedhere$$ ◻
