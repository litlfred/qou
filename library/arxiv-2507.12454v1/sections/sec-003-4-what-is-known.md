4.1. Non-abelian Hodge correspondence. The non-abelian Hodge correspondence, pi-
oneered by Hitchin [Hit87] and developed by Simpson [Sim90, Sim91, Sim92], is a construc-
tion of a remarkable bijection between local systems and stable Higgs bundles, which in-
duces a diffeomorphism between the character variety and the moduli space that parametrizes
stable Higgs bundles.

compact algebraic curve C over C with marked points. Then a Higgs bundle is a pair

4.9. What is known? Conjecture (4.5) was motivated by a computation performed in
[HLRV11]. It was shown that its implication for the number of Fq points is correct (see
(2.2)), by counting representations π1(C)→ GLn(Fq) using the character theory of the
finite group GL n(Fq).
Theorem 4.6 ([HLRV11]). The number of points over Fq (t =q−1) deduced from (4.3) is
correct.

polynomials combinatorics established in [GM19], the author first proved

With the help of this theorem, there is a following line of attack on Conjecture (4.5).
Suppose we managed to construct a “candidate model” M for the cohomology ring of the
character variety so that it comes with a surjective mapM→H∗(X). Showing surjectivity
of the map is plausible because the generators of H∗(X) are known. If we furthermore
manage to show that the dimension of M is exactly as predicted by Conjecture (4.5), then
by Theorem 4.8 the map M→ H∗(X) will have to be an isomorphism. Partial progress
in this direction is discussed in the next sections.
