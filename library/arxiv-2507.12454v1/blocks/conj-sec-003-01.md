[\[conj:partition function conjecture\]](#conj:partition function conjecture){reference-type="eqref" reference="conj:partition function conjecture"} was motivated by a computation performed in [@hausel2011arithmetic]. It was shown that its implication for the number of $\mathbb{F}_q$ points is correct (see [\[eq:Fq points and mixed Hodge\]](#eq:Fq points and mixed Hodge){reference-type="eqref" reference="eq:Fq points and mixed Hodge"}), by counting representations $\pi_1(C)\to \mathrm{GL_n}(\mathbb{F}_q)$ using the character theory of the finite group $\mathrm{GL_n}(\mathbb{F}_q)$.
