The $Q=5$ minimal energy solution is $5(\ensuremath{\mathcal{L}}_{1,2}\between\ensuremath{\mathcal{L}}_{1,2})_{\ensuremath{\mathcal{L}}_{1,2}}$, it is a link, which is similar to the usual minimal energy charge five Hopfion in the massless Faddeev-Skyrme model. However, the structure of the energy density of this solution in the model with Heisenberg type potential is different, one can clearly identify four linked tubes, see Table [\[hopftable\]](#hopftable){reference-type="ref" reference="hopftable"}. Confirming the general pattern we also found the dihedrally symmetric configuration $5(\ensuremath{\mathcal{A}}_1\between\ensuremath{\mathcal{A}}_1)_{\widetilde\ensuremath{\mathcal{A}}_{5,1}}$ with energy about $5 \%$ above the global minimum.

As expected, variations of the parameter $\alpha$ in the potential ([\[potential\]](#potential){reference-type="ref" reference="potential"}) affects the solutions. In the model with the potential $V=m^2(\phi_1-1/3)^2$ the ground state configurations is of very unusual type, the location curves $\mathcal{C}_1 = \vec \phi^{-1}(1,0,0)$ and $\mathcal{C}_{-1} = \vec \phi^{-1}(-1,0,0)$ correspond to the knot $\ensuremath{\mathcal{K}}_{3,2}$ and to the link $\ensuremath{\mathcal{L}}_{1,2}$, respectively, see Table [\[hopftable2\]](#hopftable2){reference-type="ref" reference="hopftable2"}. At the same time, the curve $\mathcal{C} = \vec \phi^{-1}(0,0,-1)$ is a link of two bend tubes $\ensuremath{\mathcal{L}}_{1,2}$, thus this new Hopfion with mixed types of location curves can be labeled as $5(\ensuremath{\mathcal{L}}_{1,2}\between\ensuremath{\mathcal{K}}_{3,2})_{\ensuremath{\mathcal{L}}_{1,2}}$. The local minimum, which we found in this sector, represent the deformation of the $D_5$ symmetric configuration $5(\ensuremath{\mathcal{A}}_1\between\ensuremath{\mathcal{A}}_1)_{\widetilde\ensuremath{\mathcal{A}}_{5,1}}$.

Considering the Faddeev-Skyrme model with the Heisenberg type potential at $m=4$, we found that in the sector of degree six the minimal energy has the double trefoil knot configuration $6(\ensuremath{\mathcal{K}}_{3,2}\between\ensuremath{\mathcal{K}}_{3,2})_{A_{3,2}}$. This is the solution with dihedral symmetry, see the corresponding plots in Table [\[hopftable\]](#hopftable){reference-type="ref" reference="hopftable"}. Recall that in the massless Faddeev-Skyrme model the link $\ensuremath{\mathcal{L}}_{2,2}^{1,1}$ is the minimal energy charge six solution [@Sutcliffe:2007ui] whereas in the presence of the usual mass term the global minimum is the axially symmetric Hopfion $A_{3,2}$ [@Battye:2013xf; @Harland:2013uk].

Making use of variety of initial configurations in the model with the potential $V=m^2{\phi_1}^2$, we found two other solutions, which represent local minima. The solution $6(\ensuremath{\mathcal{L}}_{1,3}\between\ensuremath{\mathcal{K}}_{3,2})_{\ensuremath{\mathcal{L}}_{1,3}^{1,1}}$ yields another example of mixed type configuration, here the location curves $\mathcal{C}_1$ and $\mathcal{C}_{-1}$ form the trefoil knot and the link, respectively, see Table [\[hopftable\]](#hopftable){reference-type="ref" reference="hopftable"}. The curve $\mathcal{C}$ in this case is the usual link $\ensuremath{\mathcal{L}}_{1,3}^{1,1}$, which corresponds to a local minimum in the model with the usual pion-mass type potential. The bent configuration $6(\widetilde\ensuremath{\mathcal{A}}_1\between\widetilde\ensuremath{\mathcal{A}}_1)_{\widetilde\ensuremath{\mathcal{A}}_{6,1}}$ has even higher energy.

Last solution also exist as a local minimum in the model with potential $V=m^2(\phi_1-1/3)^2$, see Table [\[hopftable2\]](#hopftable2){reference-type="ref" reference="hopftable2"}. But global minimum now is represented by trefoil knot Hopfion $6(\ensuremath{\mathcal{K}}_{3,2}\between\ensuremath{\mathcal{K}}_{3,2})_{\ensuremath{\mathcal{K}}_{3,2}}$, the next by energy configuration is $6(\ensuremath{\mathcal{L}}_{1,3}\between\ensuremath{\mathcal{K}}_{3,2})_{\ensuremath{\mathcal{K}}_{3,2}}$, which differs from the corresponding $c=0$ solution by configuration of the position curve. We should mention that for these solutions, curves of the types $\ensuremath{\mathcal{K}}_{3,2}, \ensuremath{\mathcal{L}}_{1,3}, \ensuremath{\mathcal{L}}_{1,2}, \ensuremath{\mathcal{A}}_{3,2}$ are looking very similar to each other, they are almost indistinguishable in some cases, moreover they possess almost the same energy, so we cannot exclude a possibility that further more precise numerical minimization scheme may reduce the number of local minima.

Finally, in the sector of degree seven we identify $7(\ensuremath{\mathcal{L}}_{1,2}^{2,2}\between\ensuremath{\mathcal{K}}_{3,2})_{\ensuremath{\mathcal{K}}_{3,2}}$ as the lowest energy solution in the model with the potential $V=m^2{\phi_1}^2$ at $m=4$. The curve $\mathcal{C}$, which in the massless limit corresponds to the position curve, has the form of the trefoil knot, which becomes less symmetric as the mass parameter $m$ increases. Another double knot configuration $(\ensuremath{\mathcal{K}}_{2,3}\between\ensuremath{\mathcal{K}}_{2,3})_{\ensuremath{\mathcal{K}}_{2,3}}$ in that case represents a local minimum, the double bend axial configuration $(\widetilde{\ensuremath{\mathcal{A}}}_1\between\widetilde{\ensuremath{\mathcal{A}}}_1)_{\widetilde\ensuremath{\mathcal{A}}_{7,1}}$ is another metastable local minimum, see Table [\[hopftable\]](#hopftable){reference-type="ref" reference="hopftable"}. Configurations of the last two types also exist in the model with potential $V=m^2(\phi_1-1/3)^2$, however the global minimum now has the form of usual trefoil knot, see Table [\[hopftable2\]](#hopftable2){reference-type="ref" reference="hopftable2"}.
