The surgery formula for the Casson--Walker invariant \cite{walker} says that \[ \lambda(S^3_n(K)) = \lambda(S^3_n(U)) + \frac{1}{n}\frac{\Delta''_K(1)}{2} \] and likewise for $\lambda(S^3_n(T_{2,2g+1}))$, so since these two invariants are equal we must have \[ \frac{\Delta''_K(1)}{2} = \frac{\Delta''_{T_{2,2g+1}}(1)}{2}. \] But Proposition~\ref{prop:casson-t2n} says that this is only possible if $\Delta_K(t) = \Delta_{T_{2,2g+1}}(t)$, as promised, and so the knot Floer homologies of $K$ and $T_{2,2g+1}$ coincide as well.
