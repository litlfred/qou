As discussed in Section 3, the partition function of Chern-Simons theory with gauge group
GC will take a ﬁnite, well-deﬁned value on manifolds M that only admit ﬁnitely many ﬂat
GC connections. For GC = SL(2, C) and possibly GC = SL(N, C), hyperbolic manifolds
are expected to be of this type. (Indeed, there exist systematic computations of partition
functions for hyperbolic manifolds with boundary of genus≥ 1.) One may then try to relate
properties of the partition function with the topology of M. We proceed to outline some
of the more striking relations. In each case, M-theory and/or the 3d-3d correspondence
provides valuable insight.
