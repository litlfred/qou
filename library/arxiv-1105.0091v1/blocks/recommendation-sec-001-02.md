More precisely, under the morphism $\mathbb{C}\langle X \rangle \to \mathbb{C}[X]$, a free quasi-symmetric function $F_{\sigma}$ becomes $L_{c(\sigma)}$, where for any composition $c \in \mathfrak{C}_{n}$, $L_{c}$ is defined as $$L_{c}=\sum_{\substack{i_{1}\leq i_{2}\leq \cdots \leq i_{n}\\ i_{j}<i_{j+1}\text{ if }j \in D(c)}} x_{i_{1}}x_{i_{2}}\cdots x_{i_{n}}.$$ A formal power series $f$ in commutative variables $x_{1},x_{2},\ldots$ belongs to the vector space generated by the $L_{c}$'s, $c \in \mathfrak{C}=\bigsqcup_{n \in \mathbb{N}}\mathfrak{C}_{n}$ if and only if it is quasi-symmetric, meaning that for any $i_{1}< i_{2}< \cdots < i_{r}$ and $j_{1}< j_{2}< \cdots < j_{r}$, and any $(a_{1},\ldots,a_{r})\in \mathbb{N}^{r}$, $$[x_{i_{1}}^{a_{1}}x_{i_{2}}^{a_{2}}\cdots x_{i_{r}}^{a_{r}}](f)=[x_{j_{1}}^{a_{1}}x_{j_{2}}^{a_{2}}\cdots x_{j_{r}}^{a_{r}}](f).$$ The reader should compare this definition of quasi-symmetric functions with the definition of symmetric functions given on page .
