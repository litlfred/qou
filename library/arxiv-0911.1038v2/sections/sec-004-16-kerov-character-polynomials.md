An interesting feature of this deﬁnition is that we do not require that k, the
index of the symmetric group to which π belongs, must be equal to n, the
number of boxes of λ. In order for ρλ(π) to make sense, for k < n we just
declare that the permutation π ∈S(k) can be also regarded as an element
of S(n); we just add to π additional n −k ﬁxpoints. As it was pointed
out by Scarabotti [Sca11], it would be more appropriate to use the name of
spherical function instead of character for these objects, nevertheless we
will stick to this old nomenclature.
