In order to prove Theorem [\[theo:main\]](#theo:main){reference-type="ref" reference="theo:main"} we would like to apply Lemma [\[lem:sie-dzieli\]](#lem:sie-dzieli){reference-type="ref" reference="lem:sie-dzieli"} to Kerov polynomials. For this, we need some interesting arithmetic properties of coefficients of Kerov polynomials. The next lemma, which was formulated as a conjecture by Światosław Gal [@Gal], shows some properties of these kind.

::: lemma
[]{#lem:div label="lem:div"} If $p$ is an odd prime number then

1.  []{#lem:gal_a label="lem:gal_a"} $\frac{\Sigma_{p}-R_{p+1}+2 R_2}{p}$,

2.  []{#lem:gal_b label="lem:gal_b"} $\frac{\Sigma_{p-1}-R_p}{p}$,

3.  []{#lem:gal_c label="lem:gal_c"} $\frac{\Sigma_{p+1}-R_{p+2}+R_3}{p}$

are polynomials in free cumulants $R_2,R_3,\dots$ with nonnegative integer coefficients.
:::

We will prove this Lemma in Section [\[sec:technical\]](#sec:technical){reference-type="ref" reference="sec:technical"}, because the proof is very technical. Finally, we can prove the main result.
