400 T. Ohtsuki (Editor)

Conjecture 2.1 ({220, Problem 1.92 (N)]) Fu(ZK)/Fa41(ZK) is torsion free
for each d.

Remark (see (220, Remark on Problem 1.92 (N)]) Goussarov has checked
the conjecture for d < 6. It has been checked that Fy(ZK)/Fa41(ZK) has no
2-torsion for d < 9 by Bar-Natan, and for d < 12 in [224].

Remark If this conjecture was true, then Z-valued and Q-valued Vassiliev
invariants carry exactly the same information about knots. Moreover, any
(Z/nZ)-valued Vassiliev invariants would be derived from Z-valued Vassiliev
invariants.

Conjecture 2.2 A(S!;Z) is torsion free.

Remark (T. Stanford) This conjecture would imply Conjecture 2.1 because
of the Kontsevich integral. However, it is possible that there is torsion in
A(S!,Z) which is in the kernel of the map (8).

Conjecture 2.3. (X.-S. Lin [262]) Let R be a commutative ring with 1, say
Z/2Z. Every weight system A(S!; R)®/FI— R is induced by some Vassiliev
invariant RK > R.

Remark Ifthe map (8) is an isomorphism and Fa(RK)/Fa41(RK) is a direct
summand of RK/Fa,1(RK), then this conjecture is true (see the diagram at
the beginning of this section).

Remark When R = Q, this conjecture is true, since the composition of the
Kontsevich invariant and a weight system gives a Vassiliev invariant, which
induces the weight system. If the Kontsevich invariant with coefficients in R
would be constructed (see Problem 3.7), this conjecture would be true.

Remark (T. Stanford) The chord diagram module A(||,Z) corresponds to
finite-type invariants of two-strand string links. Jan Kneissler and Ilya Dogo-
lazky (see [109]) showed that there is a 2-torsion element in A(||,Z)/FI (see
Figure 7). I have done recent calculations (to be written up soon) which show
that there is no Z/2Z-valued invariant of string links corresponding to this tor-
sion element. Thus there is a Z/2Z weight system A(||,Z/2Z)/FI > Z/2Z
which is not induced by a Z/2Z-valued finite-type invariant. So for string links,
Conjecture 2.1 is false.
