relation N C M satisfying some property. A major class of subfactors is a class

< 4; they are classified to be of types An, Don, Eg, or Eg. A left X right Y

Thus, the following classification problems are almost equivalent. Each of them
is fundamental, but probably impossibly hard. (See also Problem 8.2.)

Problem 9.1
(1) Find (and classify) all semi-simple monoidal categories (with finitely many
isomorphism classes of simple objects).

(2) Find (and classify) (finite dimensional) fusion rule algebras and sets of
6j-symbols.

(3) Find (and classify) all subfactors (of finite depth).
