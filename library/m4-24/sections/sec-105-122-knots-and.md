12.2 Knots and 
nite groups
Knot groups are known to be residually 
nite, that is, any non-trivial element
can be detected by a homomorphism to some 
nite group.
Now by Dehn’s lemma and the loop theorem a knot is trivial if and only if
its longitude represents the trivial element of the knot group. Consequently
for each non-trivial knot there is a homomorphism to some 
nite group which
carries the longitude to a non-trivial element.
