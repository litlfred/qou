A conjecture would be that, if K is a prime knot, L(K) is homotopy equivalent to the circle if and only if K is non-trivial, with the fundamental group generated by the obvious loop in L(/’) shown in the above picture. This question is motivated by the paper [287]. If the conjecture holds, the homotopy type of the space of short ropes studied by Mostovoy would be clear. A paper of Hatcher [171] seems to be related with this problem.
