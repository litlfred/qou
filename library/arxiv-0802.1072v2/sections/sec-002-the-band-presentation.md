The *band presentation* of $B_3$ uses a cyclically ordered set of generators which includes the generators of ([\[E:classical presentation\]](#E:classical presentation){reference-type="ref" reference="E:classical presentation"}): $$\label{E:BKL presentation}
<a_1, a_2, a_3 \ | \  a_2a_1 = a_3a_2 = a_1a_3> , \  {\rm where}  \  a_1=\sigma_1, \ \ a_2 = \sigma_2, \ \ a_3 = \sigma_1^{-1}\sigma_2\sigma_1.$$ In terms of the new generators, a 3-braid $L$ admits a flype (see ([\[E:flype-admissible form\]](#E:flype-admissible form){reference-type="ref" reference="E:flype-admissible form"})) if its conjugacy class contains $a_1^ua_2^va_1^wa_2^{\pm 1}$ for some $u,v,w,\epsilon$. The constraints on $u,v,w,\epsilon$ are as before. In working with the presentation ([\[E:BKL presentation\]](#E:BKL presentation){reference-type="ref" reference="E:BKL presentation"}) subscripts are always defined mod 3. Let $\delta = a_2a_1 = a_3a_2 = a_1a_3$. The following formulas follow immediately from the defining relations in ([\[E:BKL presentation\]](#E:BKL presentation){reference-type="ref" reference="E:BKL presentation"}). $$\label{E:working with delta} 
(i) \ \  a_i^{-k} = \delta^{-k} a_{i-k+2}a_{i-k+1}\cdots a_ia_{i+1} \ \ {\rm for \ all} \ \ k\geq  1, \ \ (ii) \ \ a_j \delta^m = \delta^m a_{j+m} \  \ {\rm for \ all} \ \ m\in \mathbb N.$$ They will be used repeatedly in what follows. Note that $\delta^3$ generates the center of $B_3$, because subscripts are defined mod 3.
