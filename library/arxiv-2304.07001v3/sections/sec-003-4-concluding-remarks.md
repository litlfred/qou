In order to apply Theorems 1.2 and 1.4 and thus verify Conjecture 1.1 for all torus knots
T (s, t), one needs to prove the relevant strange identity in ( 1.13). The ﬁrst obstruction in this
task is ﬁnding an explicit “non-cyclotomic” expansion for JN (T (s, t); q) from which an element
inH such as the one in ( 3.16) can be extracted. The Rosso-Jones formula for JN (T (s, t); q) does
not appear to be suﬃcient [ 50, page 132]. Instead, one should consider the walks along bra ids
method in [ 5,7]. The second obstruction is in determining the underlying q-series identity which
implies the strange identity. Thus, it would be of substanti al interest to further develop the
techniques in [ 45]. Finally, what can one say about Conjecture 1.1 for satellite or hyperbolic
knots?
