::: prop
[]{#cyclic_case_3 label="cyclic_case_3"} For case 3, $\mu = q^{M+1}$, $\lambda=q^{-(N+1)}$, $M$, $N \geq 0$,

1.   $HC_0^\sigma(\mathcal{A}) \cong k^2$, with generators $[ d^{M+1} c^{N+1} ]$, $[ a^{M+1} b^{N+1} ]$.

2.   $HC_1^\sigma(\mathcal{A}) \cong k^2$, with generators $[ ( a^{M+1} b^N ,b)]$, $[ ( d^{M+1} c^N ,c)]$,\
    equivalently $[ ( d^M c^{N+1} ,d)]$, $[ ( a^M b^{N+1} ,a)]$.

3.   $HC_n^\sigma(\mathcal{A}) =0, \quad n \geq 2$
:::

::: pf
Recall that $HH_0^\sigma(\mathcal{A}) \cong k^2$, generated by $[ d^{M+1} c^{N+1} ]$, $[ a^{M+1} b^{N+1} ]$, $HH_1^\sigma(\mathcal{A}) \cong k^4$, generated by $[ ( a^{M+1} b^N ,b)]$, $[ ( d^{M+1} c^N ,c)]$, $[ ( d^M c^{N+1} ,d)]$ and $[ ( a^M b^{N+1} ,a)]$, and $HH_2^\sigma(\mathcal{A}) \cong k^2$ with generators $\omega_2$ and $\omega_2^{'}$ ([\[case6_w2\]](#case6_w2){reference-type="ref" reference="case6_w2"}).\

::: lemma
For $B_0 : HH_0^\sigma(\mathcal{A}) \rightarrow HH_1^\sigma(\mathcal{A})$ we have: $$\begin{aligned}
&&B_0 [ d^{M+1} c^{N+1} ] = (N+1) [ (d^{M+1} c^N ,c)] + (M+1) q^{- (N+1)} [ (d^M c^{N+1} ,d)]\nonumber\\
&&B_0 [ a^{M+1} b^{N+1} ] = (N+1) [ ( a^{M+1} b^N ,b)] + (M+1) q^{N+1} [ ( a^M b^{N+1} ,b)]\nonumber
\end{aligned}$$
:::

::: pf
We treat only $[ d^{M+1} c^{N+1} ]$, the calculations for $[ a^{M+1} b^{N+1} ]$ are completely analogous. By considering $b (1, d^{M+1} c^N ,c)$, we find that $$B_0 [d^{M+1} c^{N+1} ] = [(1, d^{M+1} c^{N+1})] = [ (d^{M+1} c^N ,c)] + q^{-(M+1)} [( c, d^{M+1} c^N )]$$ Now, for any $x$, $y \in \mathcal{A}$, and for all $r \geq 0$, a simple induction shows that: $$\label{handy_formula}
[ (x , y^{r+1} )] = \sum_{j=0}^r \; [( \sigma( y^j ) x y^{r-j} ,y )]$$ Also, $[( c, d^{M+1} c^N )] = q^{M+1} [ (d^{M+1} c, c^N)] + q^{-N(M+1)} [ (c^{N+1}, d^{M+1})]$. It follows from ([\[handy_formula\]](#handy_formula){reference-type="ref" reference="handy_formula"}) that $[ (d^{M+1} c, c^N)] = N [ (d^{M+1} c^N ,c)]$ and\
$[ (c^{N+1}, d^{M+1})] = (M+1) q^{M(N+1)} [ (d^M c^{N+1} ,d)]$. Hence the result.
:::

::: cor
It follows that:

1.   $\mathrm{ker}(B_0) = \{ 0 \}$.

2.   $HH_1^\sigma(\mathcal{A}) / \mathrm{im}(B_0 ) \cong k^2$, generated by $[( a^{M+1} b^N ,b)]$, $[(d^{M+1} c^N ,c)]$,\
    equivalently $[( d^M c^{N+1} ,d)]$, $[(a^M b^{N+1} , a)]$.
:::

::: lemma
[]{#lemma:b_1_surjective label="lemma:b_1_surjective"} $B_1 : HH_1^\sigma(\mathcal{A}) \rightarrow HH_2^\sigma(\mathcal{A})$ is surjective.
:::

::: pf
Using ([\[B_n\]](#B_n){reference-type="ref" reference="B_n"}) we have $$\begin{aligned}
&B_1 ( a^M b^{N+1} , a) =& (1, a^M b^{N+1} ,a) - 
                q^{-(N+1)} (1, a, a^M b^{N+1} ) \nonumber\\
&B_1 ( d^M c^{N+1} , d) =& (1, d^M c^{N+1} ,d) 
            - q^{N+1} ( 1,d, d^M c^{N+1} ) \nonumber
\end{aligned}$$ Consider the twisted Hochschild 2-cocycles given by $$\phi_2 (x,y,z) = h_{[ a^{M+1} b^{N+1}] } ( x \partial_a (y) \partial_b (z))$$ $$\phi_2^{'} (x,y,z) = h_{[ d^{M+1} c^{N+1}] } ( x \partial_a (y) \partial_b (z))$$ with $h_{[ a^{M+1} b^{N+1}] }$, $h_{[ d^{M+1} c^{N+1}] }$ defined in ([\[case_6_HH\^0\]](#case_6_HH^0){reference-type="ref" reference="case_6_HH^0"}). Then $$\begin{aligned}
&&\phi_2 ( B_1 ( a^M b^{N+1} , a) )= -(N+1) q^{-(N+1)}\nonumber\\
&&\phi_2^{'} ( B_1 ( a^M b^{N+1} , a) ) = 0 =  \phi_2 ( B_1 ( d^M c^{N+1} , d) )\nonumber\\
&&\phi_2^{'} ( B_1 ( d^M c^{N+1} , d) ) = -q^{N+1} (N+1)\nonumber
  
\end{aligned}$$ It follows that $B_1 ( a^M b^{N+1} , a)$ and $B_1 ( d^M c^{N+1} , d)$ are nontrivial and linearly independent, and hence span $HH_2^\sigma(\mathcal{A}) \cong k^2$.
:::

It follows that $\mathrm{ker}(B_1) / \mathrm{im}(B_0) = 0$, and $HH_2^\sigma(\mathcal{A}) / \mathrm{im}(B_1) =0$. So:

1.  $HC_0^\sigma(\mathcal{A}) = HH_0^\sigma(\mathcal{A})$

2.  $HC_1^\sigma(\mathcal{A}) = HH_1^\sigma(\mathcal{A}) / \mathrm{im}(B_0) \cong k^2$

3.  $HC_{2n+2}^\sigma(\mathcal{A}) = (HH_2^\sigma(\mathcal{A}) / \mathrm{im}(B_1)) \oplus \mathrm{ker}(B_0) = 0$

4.  $HC_{2n+3}^\sigma(\mathcal{A}) = \mathrm{ker}(B_1) / \mathrm{im}(B_0) = 0$

This completes the proof of Proposition [\[cyclic_case_3\]](#cyclic_case_3){reference-type="ref" reference="cyclic_case_3"}.
:::

Dually, we have $HC^0_\sigma(\mathcal{A}) \cong k^2$, generated by the two 0-cocycles $h_{[ a^{M+1} b^{N+1}] }$, $h_{[ d^{M+1} c^{N+1}] }$ defined in ([\[case_6_HH\^0\]](#case_6_HH^0){reference-type="ref" reference="case_6_HH^0"}). To give the generators of $HC^1_\sigma(\mathcal{A}) \cong k^2$, define a new derivation $\partial' = (N+1) \partial_a - (M+1) \partial_b$. We have $$\partial' ( a^{M+1} b^{N+1} ) = 0 = \partial' ( d^{M+1} c^{N+1} )$$ so by Lemma [\[cyclic_1_cocycle\]](#cyclic_1_cocycle){reference-type="ref" reference="cyclic_1_cocycle"} the twisted Hochschild 1-cocycles $\phi_1$, $\phi_1^{'}$ defined by $$\phi_1 (x,y) = h_{[ a^{M+1} b^{N+1}] } ( x \partial' (y)), \quad 
\phi_1^{'} (x,y) = h_{[ d^{M+1} c^{N+1}] } (x \partial' (y))$$ are also twisted cyclic 1-cocycles, and satisfy $$\phi_1 ( a^M b^{N+1},a) = N+1, \quad \phi_1 ( d^M c^{N+1} ,d) = 0$$ $$\phi_1^{'} ( a^M b^{N+1},a) = 0, \quad \phi_1^{'} ( d^M c^{N+1} ,d) = -(N+1)$$ In fact $\phi_1$, $\phi_1^{'}$ are a basis for $HC^1_\sigma(\mathcal{A}) \cong k^2$.\

::: prop
[]{#tch_case_4 label="tch_case_4"} In case 4, $\mu = q^{-(M+1)}$, $\lambda= q^{-(N+1)}$, $M$, $N \geq 0$ ,

1.   $HC_0^\sigma(\mathcal{A}) \cong k^2$, with generators $[ d^{M+1} b^{N+1} ]$, $[ a^{M+1} c^{N+1} ]$.

2.   $HC_1^\sigma(\mathcal{A}) \cong k^2$, generated by $[ ( d^{M+1} b^N ,b)]$, $[ ( a^{M+1} c^N , c) ]$,\
    equivalently $[ ( d^M b^{N+1} ,d)]$, $[ ( a^M c^{N+1} ,a )]$.

3.  $HC_n^\sigma(\mathcal{A}) =0, \quad n \geq 2$.
:::

The proof is completely analogous to that of Proposition [\[cyclic_case_3\]](#cyclic_case_3){reference-type="ref" reference="cyclic_case_3"}. We also have $HC^0_\sigma(\mathcal{A}) \cong k^2$, generated by the two 0-cocycles $h_{[ a^{M+1} c^{N+1}] }$, $h_{[ d^{M+1} b^{N+1}] }$, and $HC^1_\sigma(\mathcal{A}) \cong k^2$, generated by $\phi_1$, $\phi_1^{'}$ defined by $$\phi_1 (x,y) = h_{[ a^{M+1} c^{N+1}] } ( x \partial'' (y)), \quad 
\phi_1^{'} (x,y) = h_{[ d^{M+1} b^{N+1}] } (x \partial'' (y))$$ where $\partial'' = (N+1) \partial_a + (M+1) \partial_b$.\
The remaining case is the trivial one:

::: prop
In case 5 ($\mu = q^{\pm (M+1)}$, $M \geq 0$, $\lambda\notin q^{-\mathbb{N}}$, and $\mu \notin q^{\mathbb{Z}}$, $\lambda\neq 1$), we have $HC_n^\sigma(\mathcal{A}) = 0$ for all $n \geq 0$.
:::

::: pf
In each case $HH_n^\sigma(\mathcal{A}) = 0$ for all $n \geq 0$, so the spectral sequence stabilises at the first page, with all entries being zero.
:::
