To be absolutely precise, i.e. to make the above construction into an algorithm, one should fix once and for all the following data: \begin{enumerate} \item For each $w \in W$, a rex ${\un{w}}$. \item For each $w \in W$ and each index $s \in \SC$ in the \emph{right descent set} of $w$, a rex ${\un{w}}_s$ which ends in $s$. \item For any two rexes ${\un{w}}_1$ and ${\un{w}}_2$ in for $w$, a rex move from ${\un{w}}_1$ to ${\un{w}}_2$. \end{enumerate} This is not the only way to make the algorithm precise.
