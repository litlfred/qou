If one is familiar with the geometric underpinning of Soergel bimod- ules, then it should not be terribly off-putting that these maps are not cyclic. One expects cyclicity whenever one analyzes convolution between perverse sheaves, be- cause the procedure of taking the biadjoint of a sheaf is a functor. Soergel bimodules are the equivariant (derived) global sections of the semisimple perverse sheaves on the ﬂag variety, and taking global sections is a well-behaved functor on this semisim- ple category, so that cyclicity happens to be preserved.
