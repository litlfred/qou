The fact that the open sets of Definition [\[def:chart\]](#def:chart){reference-type="ref" reference="def:chart"} cover the whole of $\mathrm{FHilb}_n$ follows from the following principle: $$\label{eqn:principletorus} \textbf{any open torus invariant property which holds}$$ $$\textbf{near the fixed points of }\mathrm{FHilb}_n \textbf{ holds everywhere}$$ This is because the set of points which do not enjoy said property is closed, torus invariant and contains no fixed points: any such set must be empty.
