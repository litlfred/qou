0.1. Let R be a k-algebra, and χ : B[Γ] →R an R-character. Assume that χ is irreducible, that is χ(∆α,β) ∈R× for some α, β ∈Γ, and let A, B ∈SL2(R) such that Tr A = χ(Yα), Tr B = χ(Yβ), Tr AB = χ(Yαβ). Then there exists a unique representation ρ : Γ →SL2(R) whose character is χ and such that ρ(α) = A, ρ(β) = B. In the sequel we will denote by φ : Γ →R the map φ(γ) = χ(Yγ).We ﬁrst introduce the following deﬁnition : Deﬁnition A.0.2. An R-valued form is a map h : Γ →R such that ∀γ, δ ∈ Γ, h(γδ) + h(γδ−1) = φ(γ)h(δ). A form will be called homogeneous if h(e) = 0.
