In general, the use of the term variety is reserved to irreducible and reduced algebraic sets. An irreducible set is a set which is not a reunion of two proper closed subsets. An irreducible component is a maximal irreducible subset. Given a ring R, Spec(R) is said to be reduced if R does not contain any nilpotent element. In particular, by mean of an irreducible component we will assume it to be reduced. We will call many algebraic objects varieties despite they have no reason to be irreducible, nor reduced.
