Assuming that $\Le^*_W=1$, \eqref{eq:hat-sandwich} implies that $\hat\kappa_{ij}=\kappa_{ij}$ holds and the rescaling factors $d_i$ must satisfy \begin{equation}\label{eq:kappa-d} \hat\kappa_{ij}d_j=d_i\quad \forall i,j\in [n]\, . \end{equation} If this system is infeasible, then using the circuits that provided the estimates $\hat\kappa_{ij}$, we can obtain a cycle $H$ such that $\kappa_A(H)>1$, that is, outcome \ref{i:outcome_not_TU}.
