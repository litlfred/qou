As far as color goes, pions live in $${\mathbb C}^3 \otimes {\mathbb C}^{3*}.$$ Confinement says that pions need to be white, just like nucleons, and there is only a one-dimensional subspace of ${\mathbb C}^3 \otimes {\mathbb C}^{3*}$ on which ${\rm SU}(3)$ acts trivially, spanned by $$r \otimes {\overline{r}}+ g \otimes {\overline{g}}+ b \otimes {\overline{b}}\in {\mathbb C}^3 \otimes {\mathbb C}^{3*} .$$ So, this must be the color state of all pions.
