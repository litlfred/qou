If we use the simplest nontrivial Hilbert space for both the proton and neutron, namely ${\mathbb C}$, then the Hilbert space for the nucleon should be $${\mathbb C}^2 \cong{\mathbb C}\oplus {\mathbb C}.$$ The proton and neutron then correspond to basis vectors of this Hilbert space: $$p = \left( \begin{array}{c} 1 \\ 0 \end{array} \right) \in {\mathbb C}^2$$ and $$n = \left( \begin{array}{c} 0 \\ 1 \end{array} \right) \in {\mathbb C}^2.$$ But, we can also have a nucleon in a linear combination of these states.
