Let X be an oriented knot type and let (X+, X−) be a pair of closed braids such that X−∈Bmin(X) and X+ ∈B(X) with b(X+) = m and b(X−) = n. Then there exist X′ + ∈B(X), X′ −∈Bmin(X), and a ﬁnite set of templates T (m, n) (whose membership is only dependent on (m, n)) such that: (1) X+ is exchange reducible to X′ + and X−is exchange equivalent to X′ −, and (2) There is a template (D+, D−) in the ﬁnite set T (m, n) where, using the same braiding assignment, on D+ and D−, the diagram D+ carries X′ + and the diagram D−carries X′ −.
