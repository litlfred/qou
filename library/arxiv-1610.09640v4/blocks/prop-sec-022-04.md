Let φ : M →N be a morphism in an abelian category M. (1) The morphism φ is zero if and only if for every U ∈M the homomorphism Γ(U, φ) in Mod K is zero. (2) The morphism φ is a monomorphism if and only if for every U ∈M the homomorphism Γ(U, φ) in Mod K is injective. (3) The morphism φ is an epimorphism if and only if for every U ∈M and every section n ∈Γ(U, N), there exists a covering V ↠U and a section m ∈Γ(V, M), such that φ(m) = n in Γ(V, N). The heuristic interpretation of item (3) of the proposition is this: φ : M →N is an epimorphism in M if and only if it is “locally surjective”.
