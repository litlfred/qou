The Yoneda functor YC is fully faithful. See [102, Section III.2] or [76, Section 1.4] for a proof. The proof is not hard, but it is very confusing. A functor F : Cop →Set is called representable if there is an isomorphism of functors η : F ≃ −→YC(C) for some object C ∈C. Such an object C is said to represent the functor F.
