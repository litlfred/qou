In the situation of Deﬁnition 8.4.7, assume there is a full trian- gulated subcategory J ⊆K with these two properties: (a) Every object M ∈K admits a morphism ρ : M →I in S with target I ∈J. (b) If ψ is a morphism in J ∩S, then F(ψ) is an isomorphism in E. Then the triangulated right derived functor (RF, ηR) : KS →E of F with respect to S exists. Moreover, for every object I ∈J the morphism ηR I : F(I) →RF(I) in E is an isomorphism.
