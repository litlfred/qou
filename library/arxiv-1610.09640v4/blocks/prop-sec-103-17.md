Let A be a connected graded K-ring, let N ∈M(A, gr) be a bounded above graded module, and let W := Soc(N). (1) There is an injection σ : N ↣HomK(A, W) in M(A, gr), such that the diagram W id / α  W β  N σ / HomK(A, W) in which α and β are the canonical embeddings, is commutative. (2) If W = 0 then N = 0. (3) If N is a graded-injective A-module, then the homomorphism σ above is bijective. Hence N is a graded-cofree A-module.
