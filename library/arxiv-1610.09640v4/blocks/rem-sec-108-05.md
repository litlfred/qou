Idempotent copointed functors already appeared in the litera- ture under another name: idempotent comonads. Another name for (nearly) the same notion is a (Bousﬁeld) colocalization functor, see e.g. [90]. Dually, idempo- tent pointed functors are the same thing as idempotent monads. See [115] for a discussion of these concepts. In [76, Section 4.1], what we call an idempotent pointed functor is called a projector. It is proved there that for an idempotent pointed functor (G, τ), and an object M ∈M, the isomorphisms τG(M) and G(τM) are equal.
