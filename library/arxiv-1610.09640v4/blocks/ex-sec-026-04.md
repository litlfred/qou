By a graded set we mean a set X partitioned as X = ` i∈Z Xi. The elements of Xi are called variables of degree i. The noncommutative graded polynomial ring on the graded set X is the graded ring K⟨X⟩, which is the free graded K-module spanned by the monomials (i.e. words) x1 · · · xn in the elements of X, and its multiplication is by concatenation of monomials. The strongly commutative graded polynomial ring on the graded set X is the graded ring K[X] := K⟨X⟩/I, where I is the two-sided ideal of K⟨X⟩generated by the elements y·x −(−1)i·j ·x·y for all variables x ∈Xi and y ∈Xj, together with the elements z·z for all z ∈Xk and odd k.
