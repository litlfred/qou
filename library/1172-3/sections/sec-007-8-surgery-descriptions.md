Deﬁnition 8.1. Let $L$be an $m$-component algebraically split link in
$S^{3}$, i.e., a link in $S^{3}$with all the linking numbers of components are
zero. In particular, a knot is algebraically split. A surgery description
of an algebraically split link $L$is a pair $(L_{0}, J)$of $L_{0}$and a framed link
$J$such that
1. $J$is disjoint from $L_{0}$,
2. $J$is an unlink,
3. $L_{0}\cup J$is algebraically split,
4. each component of $J$has $\mathrm{f}\mathrm{r}\mathrm{a}\mathrm{m}\mathrm{i}\mathrm{n}\mathrm{g}\pm 1$,
5. the result from $L_{0}$of surgery on $J$is ambient isotopic to $L$.
