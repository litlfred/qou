This is true provided that $$\frac{8}{20}\left(2\left(\frac{q^{-n/20}}{q^{-n/20}+1}\right)-1\right)>\frac{2}{20}$$ Solving this inequality gives a condition on q, which is $$q>\left(\frac{3}{5}\right)^{\frac{20}{n}}$$ or $$q>e^{20/n\log(3/5)}$$ Taylor expanding the exponential gives $$q> 1+\frac{20}{n}\log(3/5)+\frac{400}{2n^2}(\log(3/5))^2+\dots$$ As $n\rightarrow\infty$, taking $q>1-\alpha/n$ with $\alpha=-20\log(3/5)$ should be sufficient.
