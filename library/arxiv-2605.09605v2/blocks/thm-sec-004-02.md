2 (Global HQMM State). Let T : AH ⊗AH ⊗AO →AH be a CPU map and ϕ0 a state on AH. For each n ∈N0, the functional φn defined above extends uniquely to a state on A[0,n]. The sequence {φn}n∈N0 satisfies the Kolmogorov compatibility condition, and thus there exists a unique state φ on AN0 such that φ|A[0,n] = φn for all n. This φ is called the global HQMM state generated by (ϕ0, T ).
