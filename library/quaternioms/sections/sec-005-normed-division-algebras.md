A (real) normed division algebra (A, ∥ · ∥) is a ﬁnite-dimensional real algebra with unit
1, equipped with a norm such that
∥xy∥ = ∥x∥ ∥y∥ ∀ x, y ∈ A,
and where every nonzero element is invertible. A classical result due to Hurwitz shows
that there are exactly four such algebras:
R, C, H, O,
with dimR = 1, 2, 4, 8, respectively [1,2]. They arise from the Cayley–Dickson construction:
R double− − − →C double− − − →H double− − − →O,
and carry an involutive conjugation x ↦→¯x, a quadratic norm N(x) = x ¯x = ¯xx = ∥x∥2 ∈
R≥0, and a bilinear inner product ⟨x, y⟩ := 1
2
(
N(x + y) − N(x) − N(y)
)
.
Algebraically ,R and C are commutative and associative; H is non-commutative but
associative; O is non-associative but alternative, i.e., the subalgebra generated by any two
elements is associative. The associator
[x, y, z] := ( xy)z − x(yz)
vanishes identically in R, C, H and controls the failure of associativity in O. Octonions
obey the Moufang identities (e.g., (xy)(zx) = x(yz)x), which are often used to tame
non-associativity in structured calculations [ 2].
Cayley–Dickson product.
Writing O = H ⊕ He6 as a real vector space means that every octonion x ∈ O can be
written uniquely as follows:
x = a + be6, a, b ∈ H,
so that we may freely identify x with the pair (a, b) ∈ H ⊕ He6. With this convention, the
Cayley–Dickson product for (a, b), (c, d) ∈ H ⊕ He6 reads
(a, b) · (c, d) = ( ac − ¯d b, dc + b ¯c),
which makes explicit both the embedding of quaternionic subalgebras inside O and how
non-associativity emerges beyond H. This notation will be used repeatedly when discussing
associative triples and conﬁnement strategies.
