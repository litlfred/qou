The following are equivalent: (1) O is semisimple. (2) ∆(E) = L(E) for all E ∈Irr(W). (3) D is the identity matrix. Now, there exist several orderings on the set of standard modules of O (and consequently on Irr(W)) for which O is a highest weight category in the sense of [CPS] (see also [Ro2, §5.1]). If <O is such an ordering on Irr(W), and if [∆(E) : L(E′)]̸ = 0 for some E, E′ ∈Irr(W), then either E = E′ or E′ <O E. Thus, we can arrange the rows of D so that the decomposition matrix is lower unitriangular. We will refer to these orderings on Irr(W) as orderings on the category O.
