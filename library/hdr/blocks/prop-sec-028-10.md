The values of the isotopy invariants Θd,D for classical links depend only on the cardinality |D| of D. Hence, for a ﬁxed d, we only obtain d invariants. Further, for d, d′ positive integers with d ⩽d′, we have Θd,D = Θd′,D′ as long as |D| = |D′|. We deduce that, if |D′| = d, then Θd′,D′ = Θd, Z/dZ. Therefore, the invariants Θd,D can be parametrised by the positive natural numbers, setting Θd := Θd, Z/dZ for all d ∈N∗.
