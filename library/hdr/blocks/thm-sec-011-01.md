Let E ∈Irr(W). The Schur element sE is an element of ZK[v, v−1] of the form sE = ξENE Y i∈IE ΨE,i(ME,i) (3.3) where (a) ξE is an element of ZK, (b) NE = Q C,j vbC,j C,j is a monomial in ZK[v, v−1] with PeC−1 j=0 bC,j = 0 for all C ∈A/W, (c) IE is an index set, (d) (ΨE,i)i∈IE is a family of K-cyclotomic polynomials in one variable, (e) (ME,i)i∈IE is a family of monomials in ZK[v, v−1] such that if ME,i = Q C,j vaC,j C,j , then gcd(aC,j) = 1 and PeC−1 j=0 aC,j = 0 for all C ∈A/W.
