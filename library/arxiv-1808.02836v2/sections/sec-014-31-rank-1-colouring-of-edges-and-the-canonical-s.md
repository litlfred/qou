If ϕ is non-trivial, one obtains a unique normal surface, Sϕ = Sϕ (T ), with respect to T by introducing
a single vertex on each ϕ –odd edge. This surface is disjoint from the tetrahedra of type ∆/ 0; it meets each
tetrahedron of type ∆t in a single triangle meeting all ϕ –odd edges; and each tetrahedron of type ∆q in a single
quadrilateral dual to the ϕ –even edges. Moreover, Sϕ is Lefschetz dual to ϕ and is termed the canonical
(normal) surface dual to ϕ. Given 0⁄= c∈ H2(M; Z2) we also write Sc = SDM(c) and call Sc the canonical
(normal) representative of c.
