[]{#sec:normsurfs label="sec:normsurfs"}

Normal surfaces in 1--vertex triangulations of closed 3--manifolds that are dual to non-trivial first cohomology classes were used in [@Jaco-minimal-2009; @Jaco-Z2-2013] in order to obtain lower bounds on the complexity of 3--manifolds. This section develops a similar theory for ideal triangulations. In this section, $\overline{M}$ is a compact, irreducible 3--manifold with non-empty boundary a finite union of tori, and $M$ is its interior.

We consider surfaces representing elements of $H_2(M; \mathbb{Z}_2).$ We wish to emphasise that we do not work with $H_2(\overline{M}, \partial \overline{M}; \mathbb{Z}_2).$ We recall the following definitions from the introduction. If $S$ is connected, let $\chi_{-}(S) = \max \{ 0,-\chi(S)\},$ and otherwise let $$\chi_{-}(S) = \sum_{S_i\subset S} \max \{ 0,-\chi(S_i)\},$$ where the sum is taken over all connected components of $S.$ Note that $S_i$ is not necessarily orientable. Define: $$|| \ c \ || = \min \{ \chi_{-}(S) \mid [S]= c\}.$$ Then the surface $S$ representing the class $c \in H_2(M;\mathbb{Z}_2)$ is *$\mathbb{Z}_2$--taut* if no component of $S$ is a sphere, real projective plane, Klein bottle or torus and $\chi(S) = -|| \ c \ ||.$ As in [@Thurston-norm-1986], one observes that every component of a $\mathbb{Z}_2$--taut surface is non-separating and geometrically incompressible.
