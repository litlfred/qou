The simplest knots with MWF = 4 which can be excluded from being a 4-braid using corollary 7.3 are 138385 (where one can use t = e2πi/9) and 1437492 (with t = e2πi/8). For 3-braids we can deal with the known examples 942 and 949. (This gives now an alternative proof that there are no 3-braid knots with such Alexander polynomial, as we explained in example 4.2.) If we know the exponent sum of β we can do better.
