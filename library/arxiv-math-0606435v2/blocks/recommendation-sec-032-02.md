We have now the cubic \[ x^3 +ax^2 +bx +c \,:=\,x^3-A x^2+B x-C \,=\,0\,. \] One solution is obtained by Cardano's formula \begin{eqn}\label{qw} \lm_1\,=\,-\frac{a}{3} -\frac{\sqrt[3]{2}(-a^2+3b)}{3\Gm} + \frac{\Gm}{3\sqrt[3]{2}}\,, \end{eqn} where \begin{eqn}\label{Gm} \Gm=\sqrt[3]{ -2a^3 + 9ab - 27c + \sqrt{ 27\,\left( -a^2b^2 + 4b^3 + 4a^3c -18abc + 27c^2 \right) } }\,. \end{eqn} We must have that $|\lm_1|=1$.
