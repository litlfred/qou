Let R be a commutative ring with unity, A an R-algebra which is free as an R-module, (B, <) an admissible system on A. Let I ≤A be an ideal generated by a unital set: G := {gγ | γ ∈Γ} for some index set Γ. Then G is a Gr¨obner basis for I if and only if all S- polynomials for G have zero remainder under the division algorithm.
