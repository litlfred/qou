[]{#sec:link label="sec:link"}

We define link invariants for objects in $\mathcal C_R$. These can be normalized according to the nullity of the objects and yield nontrivial link invariants for objects in $\mathcal C$ even if their categorial dimension is zero.

Let $\mathcal C$ be a ribbon category. Then one obtains for each labeling of components of a link by objects of $\mathcal C$ an invariant of that link, see e.g. Turaev's book [@Turaev]. For our purposes it will be enough to do this via braids as follows:

By Markov's theorem, any link $L$ with $m$ components can be obtained as the closure of a braid $\beta$ whose image in the canonical quotient map into $S_n$ would be a permutation with $m$ cycles. Choose objects $X_i$, $1\leq i\leq m$ in $\mathcal C$. We label the strands of $\beta$ which corresponds to the $i$-th cycle by the object $X_i$. After conjugating by a suitable braid, if necessary, we can assume that the first $c_1$ strands are labeled by $X_1$, the next $c_2$ strands by $X_2$ etc, where $c_i$ is the number of strands labeled by $X_i$. Using the braiding morphisms in $\mathcal C$ we obtain a linear map $$\Phi(\beta)\in {\rm End}(X_1^{\otimes c_1}\otimes X_2^{\otimes c_2}\otimes\ ...
\otimes X_m^{\otimes c_m}).$$ The link invariant $\mathcal L^{(X_1,\ ..., X_m)}(L)$ is then defined by $$\mathcal L^{(X_1,\ ..., X_m)}(L)=Tr(\Phi(\beta)).$$ We now assume that our ribbon category $\mathcal C$ is defined over a local ring $R$ whose maximal ideal $(p)$ is generated by an element $p$ in $R$, as in the previous subsection.

Then we can similarly also define the link invariant $\mathcal L^{(X_1,\ ..., X_m), (k)}$ over the category $\mathcal C$ as follows: Let $${\bf X}^{\otimes \bf m}=X_1^{\otimes c_1}\otimes X_2^{\otimes c_2}\otimes\ ...
\otimes X_m^{\otimes c_m}$$ Then we have

::: theorem
[]{#thm:mod-link label="thm:mod-link"} (a) If the object ${\bf X}^{\otimes \bf m}$ is $k$-negligible, then we obtain a new link invariant $\mathcal L^{(X_1,\ ..., X_m), (k)}$ defined by $$\mathcal L^{(X_1,\ ..., X_m), (k)} (L) 
 =\frac{1}{p^k} \mathcal L^{(X_1,\ ..., X_m)}(L)$$ which is well-defined. In particular, we obtain a well-defined invariant with values in $R/(p)$.

\(b\) Let $\mathcal C= Tilt(U_v(\mathfrak{g}), R)$ where $R$ is the completion of ${\mathbb C}[v]_{(v-q)}$ and $p=v-q$. Then $R/(p)\cong {\mathbb C}$ and the value of the $R/(p)$-valued invariant is equal to $\frac{1}{k!}\frac{d^k}{dv^k}\mathcal L^{(X_1,\ ..., X_m)}(L)_{|v=q}$, which is valid for its evaluation on any $m$-component link $L$.
:::

::: proof
*Proof.* The value of $\mathcal L^{(X_1,\ ..., X_m), (k)}(L)$ is just a renormalization of the value of $\mathcal L^{(X_1,\ ..., X_m)}(L)$ which does not depend on the particular presentations of $L$ via a braid $\beta$. Hence it is a link invariant. Note that all constructions of $\mathcal L$ can be performed over the subring ${\mathbb C}[v]_{(v-q)}$. To prove the last statememt from part (b), just observe that $\mathcal L^{(X_1,\ ..., X_m)}(L)=(v-q)^k\mathcal L^{(X_1,\ ..., X_m),(k))}(L)$. One shows easily by induction on $k$ that the $k$-th derivative of $\mathcal L^{(X_1,\ ..., X_m)}(L)$ at $v=q$ is equal to $k!\mathcal L^{(X_1,\ ..., X_m),(k))}(L)(q)$. ◻
:::

::: remark
[]{#modifiedremarks label="modifiedremarks"} 1. Our modified trace depends on the choice of the generator $p$. If we choose a different generator $p'$, it is of the form $p'=ap$ for an invertible element in $R$. Then the modified dimensions with respect to $p$ and $p'$ differ by the same element $a^k$ for all objects in $\mathcal I$.

2\. Observe that if $X$ is a simple object in $N_k$, then the dimension of $X^{\otimes 2}$ would be in $I^{2k}$. Nevertheless, $X^{\otimes 2}$ usually is not in $N_{2k}$. We would expect that the nullity of the object ${\bf X}^{\otimes \bf m}$ would just be the maximum of the nullities of the objects $X_i$.

3\. It would be interesting to define modified traces over local rings whose maximal ideals need more than one generator.

4\. We expect that these constructions can also be applied to the theory of logarithmic Hopf link invariants as in [@Creutzig-Gannon Section 3.1.3].
:::
