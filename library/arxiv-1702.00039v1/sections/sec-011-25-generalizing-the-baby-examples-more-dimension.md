If we raise the rank, we can generalize our baby examples in a different way. We give the $n$-analogue of the baby examples.

1.  The *Weyl group of type $A_{n-1}$*. It can be defined as the symmetries of an $n$-simplex, or equivalently, as $S_n$, the symmetric group in $n$ elements. The isomorphism between these two groups is obvious. It admits a Coxeter presentation given by generators $s_i, 1\leq i <n$ and relations

    -   $s_i^2=e$ for all $i$.

    -   $s_is_j =s_js_i$ if $\vert i-j\vert \geq 2$

    -   $s_is_{j}s_i=s_{j}s_is_{j}$ if $\vert i-j\vert =1$ (i.e. $i=j\pm 1$)

    The isomorphism from this group to the symmetric group is given by sending $s_i$ to the transposition $(i, i+1)\in S_n.$

2.  The *Weyl group of type $BC_{n-1}$*. It is the group of symmetries of an $n$-hypercube. It has order $2^nn!$

3.  More generally, all symmetry groups of regular polytopes are finite Coxeter groups. Dual polytopes have the same symmetry group.
