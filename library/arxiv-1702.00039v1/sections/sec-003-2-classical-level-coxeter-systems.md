2.1 Some deﬁnitions
A Coxeter matrix is a symmetric matrix with entries in{1, 2,... }∪{∞} , diago-
nal entries 1 and off-diagonal entries at least 2.
Deﬁnition 1 A pair (W,S ), where W is a group and S is a ﬁnite subset of
W, is called a Coxeter system if W admits a presentation by generators and
relations given by
⟨s∈S| (sr)msr =e if s,r∈S andmsr is ﬁnite⟩,
where (msr)s,r∈S is a Coxeter matrix ande is the identity element.

system deﬁned above, the order of the element sr is msr (it is obvious that it
