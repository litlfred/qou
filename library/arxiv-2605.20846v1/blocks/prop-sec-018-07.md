1.7. (Universal Property of Quotient Category) [Mac94] Let C be a category with R a binary relation on the homs. Let C/R be the quotient category. Then the quotient functor Q = QR : C →C/R, which is identity on objects and sends a morphism to its equivalence class,1 satisfy the following universal property: If H : C →D is any functor such that fRa,bf′ implies Hf = Hf′ for all f and f′, then there exists a unique functor H′ : C/R →D with H′ ◦QR = H.
