1.3. (Congruence) A congruence R on a category C is an assignment to each pair of objects a, b ∈obj(C) an equivalence relation Ra,b on HomC(a, b) that is compatible with compositions: if fRa,bf′, meaning if (f, f′) are equivalent, then for all g : a′ →a and all h : b →b′ one has (hfg)Ra′,b′(hf′g); if eRb,ce′, then (ef)Ra,c(e′f′). We sometimes write f ∼R f′ instead to denote the fact that R is a congruence rather than a binary relation.
