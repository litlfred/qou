1.2. (Binary Relation) Let C be a category and a, b ∈obj(C). A bi- nary relation Ra,b on HomC(a, b) is a subset Ra,b ⊂HomC(a, b) × HomC(a, b). We write fRa,bg if (f, g) ∈Ra,b. We say R is a binary relation on homs of C if R = {Ra,b | a, b ∈obj(C)} is a collection of binary relations on all pairs of objects of C. If a pair of morphisms (f, f′) is in Ra,b, we write fRa,bf′, or f = f′ if the context is clear.
