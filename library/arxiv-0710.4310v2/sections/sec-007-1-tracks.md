1.3.2 2-T racks
Deﬁnition 19 Two 2-paths Γ and Γ ′ are said to be rank-2 homotopic (and we
write Γ ∼=2 Γ ′) if there exists a smooth map J : [0, 1]2 × [0, 1] →M such that:
1. J(t,s, 0) = Γ(t,s ), J(t,s, 1) = Γ ′(t,s ) for s,t ∈ [0, 1].
2. J is constant over {0} × [0, 1]2 and {1} × [0, 1]2.
3. Over [0, 1]×{0}× [0, 1] the map J : [0, 1]2 ×[0, 1] →M restricts to a rank-1
homotopy ∂d(Γ) →∂d(Γ ′).
4. J restricts to a rank-1 homotopy ∂u(Γ) →∂u(Γ ′) over [0, 1] × {1} × [0, 1].
5. There exists an ǫ >0 such that J(t,s,x ) = J(t,s, 0) if x ≤ ǫ and s,t ∈
[0, 1], and analogously for all the other faces of [0, 1]3. We will denote this
condition as saying that J has a product structure close to the boundary
of [0, 1]3.
6. Rank(DvJ) ≤ 2 for any v ∈ [0, 1]3.
