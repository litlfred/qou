In this section, we prove that the Lawrence-Krammer represent ation is faithful.
The main ingredient in the proof is the following lemma.
Lemma 3.1 (The Key Lemma) . Let N be a noodle and let F be a fork. Then
⟨N, F ⟩ = 0 if and only if T (F ) is isotopic relative to ∂D ∪ P to an arc which is
disjoint from N .
