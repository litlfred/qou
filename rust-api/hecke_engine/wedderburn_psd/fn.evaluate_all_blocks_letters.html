Evaluate ρ_λ(β) for every partition λ ⊢ n, then emit per-block PSD reports — extended-braid version accepting σ_avg crossings.

R5.7 follow-up to PR #1271 (BraidLetter introduction). Without this, the canonical atom-braid for ⁴He (9/47 = 19% σ_avg crossings) couldn’t be evaluated for per-partition Wedderburn-block PSD, blocking R5-full mass-table closure.
