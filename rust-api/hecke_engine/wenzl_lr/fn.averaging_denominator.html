Function averaging_denominator 

Source 
pub fn averaging_denominator(factors: &[WenzlFactor]) -> u128
Expand description

Total averaging denominator for a list of factors: the product of 2^{k_i} where k_i is the number of Averaged crossings in factor i. The unnormalised tr_M returned by tr_m_via_lr should be divided by this denominator to obtain the genuine averaged Markov trace.
