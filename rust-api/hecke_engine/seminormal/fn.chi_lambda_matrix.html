Expand description

Cached-seminormal batched chi evaluator — χ_{λ_i}(w_j) for all (shape, word) pairs, building seminormal_block_generators(λ_i, q) once per shape (then reusing across all words).

For atlases (e.g. cycle-type LP for Jones-Markov y_λ) that evaluate p(n) shapes × p(n) words at the same q, the naive chi_lambdas_braid rebuilds seminormal blocks p(n)² times. This function rebuilds them p(n) times — order-p(n) speedup for the seminormal-build cost.

Returns Vec<Vec<f64>> where result[i][j] = χ_{shapes[i]}(words[j]). Outer Vec is parallel-iter over shapes (rayon); inner is sequential per shape (since they share cached blocks).

Cost: p(n) seminormal builds + p(n)·|words|·dim_max² trace ops.
