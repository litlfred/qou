GB-NF reducer for the Iwahori-Hecke algebra H_n(q).

Rust port of the Python proof-of-concept gb_filtration_jet_tracker.py.

Generators T_1, …, T_{n-1} satisfy: T_i^2 = (q - q^{-1}) T_i + 1 (Hecke quadratic) T_i T_{i+1} T_i = T_{i+1} T_i T_{i+1} (braid 1) T_i T_j = T_j T_i for |i - j| ≥ 2 (braid 2)

Inverse rule: T_i^{-1} = T_i - (q - q^{-1}).

Right-multiplication GB-NF rule: T_w · T_i = T_{ws_i} if ℓ(ws_i) > ℓ(w) = (q - q^{-1}) T_w + T_{ws_i} otherwise.

See RUST_INTEGRATION.md §“Phase R2”.
