§S3 — MPFR analogue of [crate::sdp_solver_clarabel]’s svec_pack: pack a d × d symmetric matrix into Clarabel’s PSDTriangleConeT(d) svec convention — upper-triangular column-major with off-diagonal entries scaled by √2.

Diagonal entry M_{k,k} sits at position k(k+3)/2. Total length is d(d+1)/2. Symmetrising side: this version computes ½ · (M[r][c] + M[c][r]) per off-diagonal element (matching svec_pack_symmetric in sdp_solve_canonical_t_w), so the input does not need to be exactly symmetric.
