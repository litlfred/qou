pub fn reduce_laurent_rules(
    elem: &LaurentHeckeElement,
    max_iterations: u32,
) -> (LaurentHeckeElement, u32)
Expand description

Reduce elem to fixpoint under R1 / R2 / R3.

Returns (reduced, iteration_count). iteration_count is the number of outer fixpoint passes; max_iterations is the safety cap (well above typical atomic-braid usage — empirically the fast path terminates in < 50 iterations even for ⁵Li).
