Incremental reduce — mirror of incremental_reduced_element_fast from folio-assistant/computations/hecke_laurent_fast.py:219.

Multiplies factors one at a time (via [LaurentHeckeElement::Mul]) and reduces after each step (via reduce_laurent_rules). Returns the final reduced LaurentHeckeElement.

signed_word: list of (sign, gen_0based) pairs. Each pair constructs a LaurentHeckeElement::crossing_factor which is then multiplied into the accumulating element.

max_iterations_per_step: passed straight through to reduce_laurent_rules for the per-step fixpoint loop. The Python default is 5000; production calls pass 10000.
