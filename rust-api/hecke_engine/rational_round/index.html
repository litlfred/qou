§S9.1 — Local Stern–Brocot continued-fraction rationalisation.

Given an f64 and a denominator bound q_max, produce the best rational approximation p/q with |q| ≤ q_max. Algorithm: the standard semi-convergent / Stern-Brocot continued-fraction recursion.

Exists as a hecke-engine-local replacement for the upstream clarabel::algebra::tighten_scalar because that helper sits behind the clarabel-bigrational feature flag, which is mutually exclusive with clarabel-sdp (see docs/audits/exact-sdp-feasibility.md). §S9 needs to round f64 SDP solutions to rationals, so the tightening must live on the SDP side of the mutex.

Per workplan CLARABEL_PRECISION_PLAN.md §S9.1.
