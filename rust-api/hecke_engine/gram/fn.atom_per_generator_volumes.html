Expand description

Per-generator Wedderburn volumes V̂_i^full for the atom braid.

Mirrors hecke_core.atom_per_generator_volumes. Returns one VolumeEntry per generator (length n_gens_total):

  • include_inter=true: n_gens_total = 3A - 1 (the physical atom braid with pp/nn/pn inter-nucleon crossings)
  • include_inter=false: n_gens_total = 2A (free disconnected baseline)

crossings_per_pair (or explicit m_pp, m_pn, m_nn) controls inter-nucleon crossing multiplicity. Pass None for the defaults.
