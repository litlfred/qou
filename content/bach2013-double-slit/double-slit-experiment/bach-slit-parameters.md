The double-slit geometry used throughout the experiment:

| Parameter | Value |
|-----------|-------|
| Slit width $a$ | 50 nm |
| Slit separation $d$ (center-to-center) | 280 nm |
| Slit height | 4 $\mu$m |
| Support structure | 150 nm, midway along height |
| Electron energy $E$ | 600 eV |
| de Broglie wavelength $\lambda$ | 50 pm |
| Mask width | 5 $\mu$m |
| Mask height | 10 $\mu$m |
| Mask--slit distance | 230 $\mu$m |
| Total system length | $\sim 1$ m |

The mask was held in a frame controlled by a piezoelectric actuator,
allowing continuous positioning to block one slit, both slits, or
neither slit in a non-destructive, reversible manner.
