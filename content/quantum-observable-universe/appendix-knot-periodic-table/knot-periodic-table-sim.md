Interactive visualization of the knot-centric periodic table.
Elements are organized by nuclear shell rows (stability pairs)
and proton sub-shell filling order (Mayer--Jensen).  Controls
allow switching between nuclear sub-shell, electron block, and
fill-order column modes, with color overlays for binding energy,
$\alpha$ sub-links, Skein polynomial degree, and shell
eigenvalue $\lambda_+^n$.

**Views:**

1. **Default**: knot-centric layout with electron block coloring
2. **Magic numbers**: standard layout highlighting stability pairs
3. **Binding energy**: $B/A$ gradient across elements
4. **Alpha clusters**: $k_\alpha$ sub-link count
5. **Transfer matrix**: Skein polynomial degree bound $A^2 - 1$
6. **Shell eigenvalues**: $\lambda_+^n$ at outermost electron shell
