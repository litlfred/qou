A transfer matrix records how a single configuration of
interacting braid strands acts; a physical *interaction* is a
change from one such configuration to another. The value of
encoding these interactions is that, once every crossing type
carries a transfer matrix, the change an interaction induces is
nothing more than the difference between the matrix after the
interaction and the matrix before it. This turns each process —
a beta decay, a photon absorption, a pair creation — into a
single operator on the same $2 \times 2$ matrix structure, so
that otherwise disparate processes can be compared, composed, and
iterated on equal footing.

The guiding case is beta decay. Converting one neutron into a
proton advances a nuclear crossing type by one step — from a
neutron--neutron crossing $T_{nn}$ to a mixed crossing
$T_{\mathrm{mix}}$ — and the change it records is the difference
$\Delta = T_{\mathrm{after}} - T_{\mathrm{before}}$ of the two
transfer matrices. Writing this difference as the $\Delta$
operator makes the interaction itself, rather than either
endpoint configuration, the object of study.

This section builds the catalogue of such operators. It opens
with the universal beta-decay difference, then treats its reverse
($\beta^+$), photon absorption, pair creation, double beta decay,
and an information-theoretic Toffoli transfer matrix, and closes
with a table collecting every $\Delta$ operator in one place.
