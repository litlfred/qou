*The Hecke normal form $T_w$ is a finite linear combination of
basis elements $\{T_v : v \in S_{n(K)}\}$, each indexed by a
permutation of size $n(K)$.  The set of partitions
$\{\lambda \vdash k : k \leq k_{\max}\}$ is finite (bounded by
the partition function $p(k_{\max})$).  Therefore the filtration
$J^\bullet(q)$ has finitely many distinct levels, and the
minimum $\ell$ such that $T_w \in J^\ell(q)$ is achieved by some
$\ell \in \{0, 1, \ldots, m\}$ where $m$ is the number of
distinct nonzero shadow-price values at $q$.*

*$\ell(K, q) = m$ in the worst case (when $T_w$ requires the
top-energy operator).  $\ell(K, q) = 0$ when $T_w$ lies entirely
in the trivial 1-dimensional blocks $\{(k), (1^k)\}$.
$\qquad\blacksquare$
