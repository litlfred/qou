The dihedral relations are checked above. The orbit of $\varphi$
under $\langle \sigma \rangle$ is the four-element set
$\{\sigma^k \varphi : k = 0, 1, 2, 3\} = \{\varphi, i\varphi, -\varphi, -i\varphi\}$.
Acting by $\tau$ on this set yields the four reciprocals
$\{1/\varphi, -i/\varphi, -1/\varphi, i/\varphi\}$ (using
$\tau(i\varphi) = (i\varphi)^{-1} = -i/\varphi$, etc.), giving the
full octet $G_8$ of size 8. Since $|D_4| = 8$ and $|G_8| = 8$,
the action is transitive on $G_8$, and the stabilizer of
each element is trivial.

For the polynomial: $P(z/i) = P(-iz) = (-iz)^4 - 3(-iz)^2 + 1
= z^4 + 3z^2 + 1$. The product is a difference of squares with
$a = z^4 + 1$ and $b = 3z^2$:

$$
  (z^4 - 3z^2 + 1)(z^4 + 3z^2 + 1)
   =  (z^4 + 1)^2 - (3z^2)^2
   =  z^8 + 2z^4 + 1 - 9z^4
   =  z^8 - 7z^4 + 1.  \quad
$\qquad\blacksquare$
