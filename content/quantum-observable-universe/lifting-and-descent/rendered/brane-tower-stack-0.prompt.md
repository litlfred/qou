# The recursive brane tower

F3.1 (P0). Vertical stack of disks of increasing radius, labelled bottom-to-top $A_0, A_1, A_2, A_3, \ldots, A_{n+1}$; each connected to the next by a $J^1$ jet-prolongation arrow on the right side. The disk at the base is the original Frobenius–Hopf object $A_0 = A$; each subsequent level $A_{n+1} = J^1(A_n)$ adds one extra $\Omega^1$ dimension via Kähler differentials; $A_n$ serves as the brane of $A_{n+1}$. On the left side, red dots mark the Yekutieli obstruction classes $\kappa_1, \kappa_2, \ldots$, one per level, controlling whether the lift exists. A footer notes the chain of canonical inclusions $A_0 \hookrightarrow A_1 \hookrightarrow A_2 \hookrightarrow \cdots$ via the unit section. Layout axis: vertical stack. Density axis: minimal — labels per level, one obstruction marker per level. Style axis: schematic disks. Colour axis: monochrome plus red for obstruction classes (filter-invert flips to cyan, still readable).
