| Symbol | Reading |
|--------|---------|
| $\mathbf{No}$ | The class of surreal numbers (Conway 1976). Contains $\mathbb{R}$ as a proper subclass plus infinite and infinitesimal elements. |
| $\omega$ | The surreal representation of the first infinite ordinal. We have $\omega > n$ for every $n \in \mathbb{N}$. There is no smallest infinite surreal; $\omega - 1$, $\omega/2$, and $\sqrt{\omega}$ are also infinite surreals. Concretely, $\omega = \{\,0, 1, 2, \dots \,\mid\,\,\}$ in Conway's $\{L \mid R\}$ form. |
| $\varepsilon$ | The positive infinitesimal defined as $1/\omega$. We have $0 < \varepsilon < 1/n$ for every $n \in \mathbb{N}$. There is no smallest positive infinitesimal; $\varepsilon/2$ and $\varepsilon^2$ are also infinitesimal. We construct the substrate parameter $q$ from $\varepsilon$ via [the $q$-from-$\varepsilon$ relation](#def:q-from-epsilon). |
| $1 + \varepsilon$ | An **infinitesimal lift** of $1$. The appendix procedure [(`sec:relaxing-strict-equalities`)](#sec:relaxing-strict-equalities) replaces every $x = 1$ with $x = 1 + \varepsilon$ for some surreal infinitesimal $\varepsilon$. |
| $\mathrm{st}\!:\,\mathbf{No}_{\text{fin}} \to \mathbb{R}$ | The **standard-part functor** on finite (non-infinite) surreals. It maps $1 + \varepsilon$ to $1$, $\omega^{-1}$ to $0$, and every finite real to itself. It replaces the classical limit; see [`sec:standard-part-classical-limits`](#sec:standard-part-classical-limits). |
| $\mathrm{ord}_\omega\,x$ | The **$\omega$-adic order**, the leading exponent of $x$ in Conway normal form. It provides the direct surreal analogue of $\mathrm{ord}_p$ in $p$-adic analysis. We use it to grade $\mathcal{H}_q$ and to formulate Goncharov-period-depth identifications. |
| $\{L \mid R\}$ | Conway's **simplest-form construction** represents a surreal with left set $L$ and right set $R$. It is birthday-graded. The surreal's complexity equals the minimum number of construction steps from $\{\,\mid\,\} = 0$. |
| $b(x)$ | The **birthday** of a surreal $x$ denotes the ordinal at which $x$ first appears in the Conway construction. We have $b(0) = 0$, $b(1) = b(-1) = 1$, $b(\omega) = \omega$, and $b(\varepsilon) = \omega$. |
| $a \sim b$ | The values $a$ and $b$ share the **same standard part**, meaning $a - b$ is infinitesimal or zero. We use this in Millennium-bound statements. The surreal bound holds **up to a $1 + \varepsilon$ multiplier**, which collapses to equality under $\mathrm{st}$. |
| $a \prec b$ | The value $a$ is **infinitesimal relative to** $b$. We require $|a/b|$ to be infinitesimal. This denotes Conway's asymptotic-domination order. |
