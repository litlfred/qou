Let $R$ be a commutative ring with unity, $A$ an $R$-algebra which
is free as an $R$-module, $(B, <)$ an
[admissible system](#def:admissible-system). Let $I \leq A$ be an
ideal generated by a unital set
$G := \{g_\gamma \mid \gamma \in \Gamma\}$.

Then $G$ is a [Gröbner--Shirshov basis](#def:groebner-basis) for $I$ if and
only if all $S$-polynomials for $G$ have zero remainder under the
[division algorithm](#def:division-algorithm).
