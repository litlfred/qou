# H5: a derived boundary datum that breaks u ↔ d (pre-registration, 2026-11-21)

The user chose this on the card. Written before any candidate is computed.

## Why a boundary

`commutant_trace_eq` (PR #8111) proves that anything commuting with the total lowering operator `F₃`
gives n = p up to the pivot `q²`. A VEV cannot be a module map `𝟏 → V` (Schur). So a breaker has to be
adjoined from outside `Rep(U_q)`. The standard way to do that for braids is a **boundary**: braids
with one end attached to a wall, i.e. the type-B braid group `B(B_n)`, generated by `σ₁…σ_{n−1}` and a
boundary generator `τ` acting on strand 1. For a representation, `τ ↦ 𝒦₁ = 𝒦 ⊗ 1 ⊗ 1` with `𝒦` a
2×2 matrix solving the constant reflection equation (Sklyanin; Kulish–Sklyanin):

  `Ř 𝒦₁ Ř 𝒦₁ = 𝒦₁ Ř 𝒦₁ Ř`  on `V ⊗ V`.

This is also the route `AGENTS.md` §7b names for chirality (type-B folding).

## Questions, in order

1. **Solutions.** Find all 2×2 `𝒦` solving the reflection equation for the Jimbo Ř, exactly.
2. **Does it break?** Does `𝒦₁` commute with `F₃`? A diagonal `𝒦 ∝ 1` does, so it is a null.
3. **Is it fixed?** Is there a condition already in the framework that cuts the solution set down to
   finitely many points, with no free number? Conditions allowed, listed now:
   - (C1) Hecke-type quadratic relation for `τ`, with eigenvalues fixed by the framework;
   - (C2) Markov / trace compatibility with the convention-D pivot `K = diag(q, q⁻¹)` (type-B Markov
     trace in the sense of Geck–Lambropoulou);
   - (C3) bar-invariance or the u ↔ d involution acting on the boundary;
   - (C4) `𝒦` equal to an object already in the corpus (the pivot `K`, a weak-vertex projector).
   A condition with a free parameter left over does not fix the size.
4. **Only if 1–3 give a fixed, breaking `𝒦`:** compute the n − p restricted traces of the γγ word with one
   boundary insertion, exactly in `q`, and evaluate at the proton pin `q₀ = 1.1099785827513808`.

## Classification and what counts as a hit

A **hit** is a `𝒦` that solves the reflection equation, does not commute with `F₃`, is fixed by
(C1)–(C4) with no free number, and gives an n − p difference other than the pivot factor.

- A family with a free parameter is "breaks, size input", scope (a). This is the expected outcome.
- If (C4) returns the pivot `K` itself, the result is "the pivot again", not a hit.

## Discipline

No fitting. No parameter is chosen to match the measured n − p difference, and accuracy does not
promote a candidate. The only physics is the final comparison with CODATA, if a hit reaches step 4.
