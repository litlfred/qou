nameRust crates workspace, tool-defs KG registration & proton-pinned witnessed values
summaryAuthor, verify, and register Rust crates in QOU's top-level Cargo workspace (Cargo.toml + crates/*), and evaluate 80-dps proton-pinned witnessed values via crates/qou-values and Clarabel.rs MPFR (rev = "37f06c3").
descriptionAuthor, verify, and register Rust crates in QOU's top-level Cargo workspace (Cargo.toml + crates/*), and evaluate 80-dps proton-pinned witnessed values via crates/qou-values and Clarabel.rs MPFR (rev = "37f06c3"). DOMAIN-NEUTRAL LIBRARY BOUNDARY (Ruling A1, 2026-11-28). General mathematical crates (crates/gs-basis: non-commutative Buchberger–Shirshov, Coxeter/Hecke/TL normal forms, Markov tower peeling, binomial/toric Gröbner reduction) stay 100% free of QOU domain specifics with strict semver metadata (package-release) so folio-assistant-sci and external scientific consumers reuse them directly. QOU-specific physics/model crates (crates/qou-gg-core, crates/qou-gg-eval, crates/qou-clarabel, crates/qou-values) sit on top. EVERY CRATE IS A TOOL NODE (Ruling A2, 2026-11-28). scripts/gen-crate-tools.ts projects every crates/*/Cargo.toml into tool-defs/crate-<id>/crate-<id>.json (tool-definition/v1) and tool-defs/crates.json, checked by bun run cat check:tools. PROTON PIN & 80-DPS CERTIFICATES (Ruling A3, 2026-11-28). All active Rust and Python evaluations use the proton pin (q0Anchor = "proton"; muon pin on hold until rederivation) at >= 80 decimal digits (prec_bits >= 280 in MPFR). Rewriting any committed *.witness.json waits on owner approval (processes/content/witness-refresh.bpmn).
