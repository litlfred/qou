## The question

The 2026-08-15 owner ruling makes convention D (`z_D = q³/(q²+1)`) canonical
and excises C (`z_C = √q/(q+1)`). The Q_β precision ladder

    Q_β / Q_A  =  cos(α − u/2) · Π_{k≥2} (1 + c_k u^k),
    α = (z − 1)h/2,   u = b·ℏ_q²,   h = q − q⁻¹

was derived entirely in the C frame. The ladder must be **re-derived** under
D, and a `z` substitution is not a valid re-derivation.
