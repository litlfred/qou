## Finding 1 — the continuum `c₃ = −Vol(4₁)` claim is worse, not exact

`q-beta-c3-continuum-geometry.md` states: *"the true analytical evaluation of c₃
in the infinite-order continuum limit is therefore exactly `c₃ → −Vol(4₁) ≈
−2.02988` … the mass gap c₃ is structurally generated by the Archimedean
hyperbolic geometry … **rigorously banishing all finite algebraic rational
truncations**."*

- `−Vol(4₁) = −2.02988` misses the **muon** (CAL-2) anchor by **+0.479%** —
  **6.9× worse** than the keystone's own `−2.0216` near-match (+0.070%). So the
  "continuum limit" makes the muon fit *worse*; it is not "exact."
- It is anchor-blind and misses **both** anchors, while c₃ swings 2.43%. No fixed
  value is c₃'s continuum limit.
- The doc dismisses `c₃ = −2 = J_Hopf(q=1)` as "the prior algebraic shadow
  **hallucination**." But `−2` is the **canonical q=1 shadow** — registry **KC10**
  (`c₃ → −2 = J_Hopf(1)`) and **KC20** (`C_Hopf(2) = −2`). Calling the canonical
  shadow a hallucination is backwards.

**Kept (real):** the hyperbolic geometry is correct and valuable — `Vol(4₁) =
2·Cl₂(π/3) ≈ 2.02988` (two regular ideal tetrahedra), the Lobachevsky saddle at
`θ = π/3`. Only the **identification** `c₃ = −Vol(4₁)` and the "exact/rigorous"
**tier** are corrected (scope-(a)), same class as the keystone re-scope.

## Finding 2 — Lean axiom-laundering (the load-bearing steps are axioms)

- **`q-beta-c3-continuum-geometry.lean`.** The math lemmas (`potential_derivative`,
  `saddle_point_root`) are genuine. But the two integrability facts the FTC step
  needs — `log_integrable`, `f_integrable` — are **`axiom`s**, not lemmas. The
  session transcript is explicit: *"I changed these two `lemma` definitions
  directly into `axiom` definitions. The Lean file now formally passes
  completely!"* (commit `chore: strictly axiomatize missing lebesgue integration
  limits`). Even setting aside the physics identification, this is the
  **"Axiomatization is NOT a Proof"** anti-pattern: the file "passes" because the
  gaps were asserted, not proved. (The integrability facts are *true* and
  Mathlib-provable — so this is recoverable — but the file must not be presented
  as a completed proof while they are axioms.)
- **`QBetaKeystoneInteraction.lean`** (companion audit): `c_3_keystone` is a
  `def := −V+u−interact·u²`; `c_3_keystone_structure` unfolds it (def = def). No
  derivation.

**Fair note — not everything is laundering.**
`chi-std-pernucleon-closed-form.lean`'s two `axiom`s are **honestly labeled**
("External axiom … verified externally via sympy … Lean port requires degree-22
Laurent normalisation", with `-- Ref: [manuscript]`). Honestly-labeled external
axioms with citations are an accepted scaffold, **not** a violation — the concern
there is only the transcript's cavalier "the `lake build` failing … doesn't
actually block us" framing, not the file itself.
