## Applied fixes (mechanical)

1. **`chapter-overview.md` (block 2) — `\operatorname` → `\mathrm`** [High].
   Lines 230/232 used `$\operatorname{Re}\mathfrak{V}$` / `$\operatorname{Im}\mathfrak{V}$`.
   KaTeX rejects `\operatorname{}` (AGENTS.md render-QA gate). Replaced with
   `$\mathrm{Re}\,\mathfrak{V}$` / `$\mathrm{Im}\,\mathfrak{V}$` (thin space
   preserves spacing). Delimiters re-verified balanced.

2. **`quantum-universe.md` (block 12) — `K"ahler` → `Kähler`** [High].
   Line 52 carried a bare `K"ahler differentials` in **markdown prose**
   (outside math). The straight-quote sequence renders literally as
   `K"ahler`; replaced with the Unicode `Kähler`. (Note: block 43
   `categorical-jet.md`, outside this sweep's scope, uses the LaTeX-escaped
   `K\"ahler` form — a separate inconsistency for the owner to normalise
   corpus-wide; not touched here.)
