## 1. What is left to prove

Notation, as in the Lean:

- `V = K^d`, with letters `0, …, d−1`. Words `c : Fin N → Fin d` index the basis `e_c` of `V^{⊗N}`.
- `T_a = strandBraid q q⁻¹ a` is Jimbo's braiding of strands `a, a+1`.
- `S = qSchur d m q` is the set of matrices commuting with every `T_a`. This is the q-Schur algebra, with `N = m+1`.
- `B` is the subalgebra generated by Stream 14's `uqGens`: `raiseOp` (letter `i → i+1`), `lowerOp = raiseOpᵀ`, the Cartan elements, and the weight projectors.
- `Idx` is the set of pairs `(u, c)` with `u` sorted (monotone) and `c` *block-decreasing* for `u`. That means `c a ≥ c (a+1)` whenever `u a = u (a+1)`.

On `main` or on the branch:

| fact | where |
|---|---|
| `B ⊆ S` | `jimbo_mem_commutant` (Stream 14, `QuantumGLCommutant.lean`) |
| `dim S ≤ #Idx` (any field, any `q`) | `finrank_qSchur_le` (`QSchurUpperBound.lean`) |
| `A'' = A` when `V` is a semisimple `A`-module | `centralizer_centralizer_eq` (`MathlibExt/Bicommutant.lean`) |

So **G3.4 over a field `K` follows from one inequality, `dim B ≥ #Idx`.** That inequality gives `B = S = A'`. Since `H` is semisimple at generic `q` (char 0: `isSemisimpleRing_hecke_generic`), `V` is a semisimple `A`-module, and DJ0 then gives `B' = A'' = A`.

### Reformulation as a cyclic-vector statement

The coefficient map of `QSchurUpperBound.lean`, restricted to one sorted `u`, sends `X ↦ (X c u)_{c ∈ Dec(u)}`. It is injective on the column `S e_u`. For `X ∈ B`, the column `X e_u` lies in

  `Inv(u) = {v : T_a v = q v whenever u a = u (a+1)}`

(the row relation `entry_swap_of_col_eq`). Therefore

> **(DJ3)** For every sorted `u`, the vectors `{(X e_u)|_{Dec(u)} : X ∈ B}` span `K^{Dec(u)}`.

This implies `dim B ≥ #Idx`, by summing over `u`. The reason is that the weight projector `1_λ`, `λ = content(u)`, isolates one `u` per content. Classically, (DJ3) says that `U(gl_d)` applied to `e_u` fills `S^{λ_0}V ⊗ … ⊗ S^{λ_{d−1}}V`.

The plan is to prove (DJ3) by **unitriangularity**. For each `c ∈ Dec(u)` we exhibit `X_c ∈ B` such that `(X_c e_u)_c` is a unit and `(X_c e_u)_{c'} = 0` for every `c' ∈ Dec(u)` with `c' ≻ c`, in a well-founded order.

## 2. The case `d = 2` (complete argument, to be formalised first)

Let `u = 0^a 1^b`. Block 1 is the first `a` positions and block 2 the last `b`. Then `Dec(u) = {c_{k,l} = (1^k 0^{a−k})(1^l 0^{b−l}) : 0 ≤ k ≤ a, 0 ≤ l ≤ b}`.

Take `X_{k,l} = L^{b−l} R^{k}`, where `R = raiseOp 0 1` and `L = lowerOp 0 1`.

- **Support.** `R^k e_u` only turns zeros into ones. The only zeros of `e_u` are in block 1, so every term has exactly `k` ones in block 1 and `b` ones in block 2. `L^{b−l}` then turns `b−l` ones back into zeros, in either block. So every term of `X_{k,l} e_u` lying in `Dec(u)` is `c_{k−t, l+t}` for some `t ≥ 0`.
- **Leading coefficient.** The coefficient at `c_{k,l}` (the case `t = 0`) comes only from paths in which `R` fills exactly the first `k` positions of block 1 and `L` empties exactly the last `b−l` positions of block 2. Each factor is a sum over the orders of the moves of a monomial in `q^{±1}`. Up to a power of `q`, it is a Gaussian factorial `[k]_{q²}! · [b−l]_{q²}!`. This is nonzero when `q` is not a root of unity. The exact monomial needs to be computed from `siteTerm`'s tail weight `∏_{k>s} kap(b k)`; this is item O1 below.
- **Order.** Order `Dec(u)` by `k`. Then `X_{k,l}` is unitriangular: its other terms have strictly smaller `k`. Induction on `k` gives (DJ3).

No division by anything except `[j]_{q²}` for `j ≤ N` is used. So the argument works over any field in which `q^{2j} ≠ 1` for `1 ≤ j ≤ N`.

## 3. General `d`: the plan

Target `c_A ∈ Dec(u)`. It is encoded by the matrix `A = (a_{ij})`, with `a_{ij} = #`(letter `i` in block `j`); the column sums are `λ`. Following the shape of BLM / Du (1995, §3.2, `E^{(A)}`), take

  `X_A = (∏ lowering moves for the entries above the diagonal) · (∏ raising moves for the entries below the diagonal)`,

applied to `e_u`. Here a move `j → i` with `|i−j| > 1` is a product of simple moves through the intermediate letters. Expected properties:

1. **Support.** Every `Dec(u)` term `c_{A'}` of `X_A e_u` satisfies `A' ⪯ A` in BLM's order, which compares the partial sums `σ_{ij}(A) = Σ_{k ≤ i, l ≥ j} a_{kl}` for `i < j`, and dually for `i > j`.
2. **Leading coefficient** at `c_A` is a power of `q` times a product of Gaussian factorials. It is therefore a unit at generic `q`.

Obligations, to be discharged in Lean in this order:

- **O1.** An explicit formula for `siteOp` applied to a basis vector: one move, with its `q`-weight. Then the support lemma for products of moves.
- **O2.** The `d = 2` case of (DJ3), §2, as `QSchurLowerBoundGL2.lean`.
- **O3.** The order `⪯` and the support lemma for `X_A` with general `d`.
- **O4.** The leading-coefficient computation for general `d`.
- **O5.** Assembly: `dim B ≥ #Idx`, then `B = S`, then G3.4 over any field of characteristic 0, with no ordering hypothesis.
- **O6 (char p).** Hecke semisimplicity in characteristic `p` with `q` transcendental over `𝔽_p`. Only this is missing for "any field".

O3–O4 are where BLM 1990 (Lemma 3.9 and §5) will be followed once it is uploaded. §2 does not need it.

## 4. What this does not claim

- Nothing here is proved beyond the three facts in the table in §1. The `d = 2` argument in §2 is complete on paper; its `q`-monomial is item O1.
- `lowerOp` is `raiseOpᵀ`, **not** the standard `Δ(F)` (bean `qou-gl34`). The route above only uses that `lowerOp ∈ B`. So the conclusion is about the algebra generated by Stream 14's `uqGens`, exactly as in `range_jimbo_eq_commutant`.
