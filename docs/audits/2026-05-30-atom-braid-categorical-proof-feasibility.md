## Failure modes to flag for future agents

1. **Confusing graded-vec-space iso with algebra iso.** The sub-algebra is **not** `Λ*` as an algebra — Hecke multiplication doesn't satisfy `v∧v = 0`. A naive `AlgEquiv` attempt fails at the quadratic relation. The claim is purely about `Finset.card` of a basis indexed by Coxeter-length grades.
2. **Pascal-sum proves nothing structural.** `Nat.sum_range_choose` (`2^n = Σ C(n, k)`) only checks dimension consistency. An attempt that "closes the conjecture" by chaining binomial identities is a false positive — it skips Step 4.
3. **Treating `BraidLetter` patterns (G0_p, G1_p, …) as Lean primitives.** The patterns live in `mass_at_3A_proper.py` + Rust `gb_nf_reducer.rs`. A Lean proof needs either re-encoding as Lean data + decidable reduction (mechanical but voluminous) or axiomatising as opaque class fields (just relocates the `sorry`).
4. **§3b-cond promotion temptation.** A reviewer might suggest making downstream theorems "conditional on `AtomBraidExteriorAlgebraStructure`". The file already does this (the class IS the §3b-cond hook); the conjecture's content has not moved.
