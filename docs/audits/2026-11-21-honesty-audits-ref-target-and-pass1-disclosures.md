## 2. What the `lean.ref` of a provable block names (pass-1 §7 item 1, bean `qou-5d0x`)

Population: **717** provable blocks (`theorem`/`proposition`/`lemma`/`corollary`) in `folio/quantum-observable-universe/` with a `qou:` ref. Command: `python3 scripts/roundtrip-blind-sample.py --ref-audit`.

| the ref names | blocks | reading |
|---|---|---|
| `theorem` / `lemma` | 569 | expected shape (not a statement that the theorem proves the block) |
| `def`, Prop-valued | 27 | the **claim** is defined, not proved |
| `def`, other | 41 | a construction, or a proof written as `def`; needs a per-block look |
| `structure` | 22 | a data carrier; nothing is proved |
| `class` | 19 | an **assumption**; a provable block whose Lean is a class asserts nothing proved |
| `instance` | 16 | all `*-exists` blocks; an instance does witness existence, so these are the mildest |
| `module` (file path, no such declaration) | 10 | the ref names a file, not a proof |
| `abbrev` | 1 | `prop:categorical-coordinate-ring` |
| `axiom` | 1 | `prop:tannaka-krein-reconstruction`: a provable block discharged by a Lean `axiom` |
| not found | 11 | dangling ref: no declaration with any dotted suffix of that name under the paper's Lean |

So **148 of 717 (20.6 %)** provable blocks have a ref that does not name a theorem or lemma. Of the 435 proof-bearing blocks pass 1 sampled from, the split is theorem 326, def 43, instance 16, structure 13, class 9, not-found 7, module 4, abbrev 1.

**Limits, so the figure is not over-read.** The classifier is a regex over source text. It does not elaborate Lean, so a `def` whose body is a proof term and a `def` that defines a number land in the same "def, other" row. "Not found" means no declaration header matched; a name generated by a macro or declared through `export` would be missed. And "names a theorem" says nothing about whether that theorem proves the block: that is what the round-trip legs measure. The full per-block list is in the JSON (`rows[].names`).

Pass 1 reported 4 such refs among its first 15 candidates; the full count is consistent with that rate (4/15 = 27 %, 148/717 = 21 %).
