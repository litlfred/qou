## 3. Detailed Profiling Evidence & Algorithmic Diagnosis (Ranks 1–15)

### Bottleneck 1 — Two-Row Seminormal Nuclear Tower Walk (`14,996.0 s`)
- **Evidence:** `computations/probes/markov-trace-two-row-tower-colwise.witness.json` (`rows[1].elapsed_seconds = 14996.0`); producer `crates/hecke-engine/src/bin/two_row_tower_trace.rs:82-164, 187-240` (port of `computations/probes/markov_trace_two_row_tower_probe.py`).
- **Diagnosis:** Under Convention D ($z_D = q^3/(q^2+1)$), all $\ge 3$-row irreps carry Markov weight $y_\lambda = 0$, restricting the trace to two-row shapes $(n-k, k)$. `two_row_tower_trace.rs` avoids $O(C_A^2)$ dense matrices by walking one standard tableau column $e_j$ at a time in $O(d)$ memory, but still pays $O(L \cdot \sum_k d_{(A-k,k)}) = O(A^2 C_A)$ operations ($C_{16} = 3.53\times 10^7$, $C_{19} = 1.77\times 10^9$) and allocates temporary `rug::Float` heap buffers inside `alpha`/`factor_coeffs` (`lines 179-205`).
- **`crates/*` Elimination Path:** `crates/gs-basis` (`bratteli_two_row` + Kang–Lee–Lee–Oh / Markov layer-peeling). On monotone or GS-peeled words, the fine-Bratteli transfer tracks only the $O(A)$ two-row Young diagram states rather than all $C_A$ paths, collapsing exponential $\Theta(4^A A^{-3/2})$ path enumeration to polynomial $O(A^3)$ MPFR operations (`> 5,000×` at $A \ge 16$). For genuinely non-monotone braided closures, hoisting preallocated `mpfr_t` limb scratchpads in `crates/hecke-engine::seminormal_mpfr` removes inner-loop allocator contention (`~25×`).

### Bottleneck 2 — Infinite-Edge Concave Supergradient Ascent (`~12,000 s`)
- **Evidence:** `qou.json:185-196` documents `computations/deltalambda/rev_e_infinity_xbot_relaxation_probe.py` as a `~200 min` (`12,000 s`) run exceeding the `120 min` CI container ceiling (requiring dedicated orphan-branch checkpointing `cat/qou/xbot-relaxation-ckpt/`); `computations/deltalambda/rev-e-infinity-xbot-relaxation.witness.json` records `constants.checkpoint[4].seconds = 1258.0`.
- **Diagnosis:** Every coordinate-ascent step bisects `dG_coord` (`lines 410-429`), which evaluates `Rg(b + x)` (`lines 290-298`, `RSER ≈ 270` `mpmath` loop iterations), `Wg(h - x, pe, Tlen)` (`lines 338-347`, another `270` `mpmath` iterations), and $T_{\text{len}} - 1$ barrier calls `gx(...)` (`lines 252-270`, each doing `T2 ** (-y)` in `mpmath` at `mp.dps = 25`), repeated across `PEMAX=8 × TMAX=12 × JPAD=26` and `lam` sweeps.
- **`crates/*` Elimination Path:** Expose a 100-bit `rug::Float` (or `f64x2` / `qd` + certified 100-bit MPFR endpoint check, since `mp.dps = 25` is `< 85` bits!) kernel `xbot_concave_ascent_mpfr` in `crates/hecke-engine` (`precision_scalar`) via `crates/pyhecke-native`. Precomputing $T_2^{-r}$ tables in contiguous Rust `mpfr_t` arrays and evaluating `z = exp(-y * ln(T2))` once per bisection probe gives a **`~650×` speedup (`~12,000 s -> ~18 s`)**, retiring the multi-container checkpoint split.

### Bottleneck 3 — Stochastic Hutchinson Quadratic Gram Trace at $H_{15}$ (`11,037.05 s`)
- **Evidence:** `computations/probes/gram-qtrace-hutchinson-probe.witness.json` (`durationMs = 11037050`).
- **Diagnosis:** `gram_qtrace_multi` (`computations/probes/gram_qtrace_hutchinson_probe.py:125-149`) iterates over all $p(15) = 176$ partitions (up to $d_{\max} = 292{,}864$) across 4 `(5He/5Li, q0/qi)` legs, calling pure-Python `build_seminormal_matrices(lam, q=q)` (`hecke_characters.py`, without `BlockCache` — `compute-audit` Pattern **P21**) and applying 71 `scipy.sparse` generator matrices to 200 Rademacher vectors in Python loops. Live benchmark at $n=12$, $\lambda = [5,4,2,1]$ ($d = 5{,}775$) confirmed Python `build_seminormal_matrices` takes `437 ms` for a single small block vs `117.7 ms` for full Rust `pyhecke_native.chi_lambda_braid`, with superlinear Python dict overhead at $d = 292{,}864$.
- **`crates/*` Elimination Path:** `crates/gs-basis` doubled-Bratteli quadratic transfer (after GS-reducing interleaved $B_3$ letters to canonical runs) computes $\sum_\lambda y_\lambda \|\rho_\lambda(W)\|_F^2$ **deterministically at 50 dps** without materializing $d_\lambda = 292{,}864$ vectors (`~1,380×` speedup and eliminates both `float64` lossiness and Monte Carlo variance). For arbitrary non-monotone words, a matrix-free `Slot::PairHead` Rademacher kernel in `crates/hecke-engine::seminormal` avoids `scipy.sparse` CSR indirection entirely.

### Bottleneck 4 — $\gamma\gamma$ Strand-Climbing Reading-3 Tower (`8,421.00 s`)
- **Evidence:** `computations/probes/gg_ntower/gg-ntower.witness.json` (`wall_seconds = 8421`), `gg-closures.witness.json` (`436 s`), and `computations/probes/ales_h9/ales_h9_reading3_tower_probe.py` (`1.68 MiB` witness using `np.ndarray(dtype=object)` of `mpf`).
- **Live `cProfile` Measurement:** Running a single `gg_ntower_probe.level_chars(letters, n=7)` (`len(letters) = 6`, max dim `14`) took **`31.913 s`**, of which **`30.504 s` (`95.6%`)** was spent inside `sympy.core.facts.deduce_all_facts` (`194,154` calls / `14,622,359` `<genexpr>` evaluations) and `sympy.core.mul.flatten` (`21.706 s` cumulative) triggered by `K.from_sympy(sp.cancel(a_r(r)))`, dense $O(d^3 L)$ `DomainMatrix` multiplication over `QQ(q)`, and `K.to_sympy(M[i, i].element)` at $n \le 9$ ($d \le 42$).
- **`crates/*` Elimination Path:** `crates/qou-gg-core` + `crates/qou-gg-eval`. Clearing the deterministic axial denominators $[r]_q$ puts every two-row seminormal generator entry in $\mathbb{Z}[q, q^{-1}]$, where sparse 2-nonzero column updates (`Slot::Diag` / `Slot::PairHead`) run in $O(d L \cdot \deg)$ over `BigInt` Laurent arrays (`qou-gg-core`), while Reading-3 positivity on $(1, \infty)$ and evaluation at $q_0$ run via Sturm/Descartes isolation + MPFR in `qou-gg-eval` (**`8,421 s -> ~2.5 s`, `~3,300×`**).

### Bottleneck 5 — Full-Chart 50-dps MPFR Nuclide LP Sweep (`~3,600 s`)
- **Evidence:** `computations/all_nuclides_sdp_admissibility_mp.py:105-193` + `computations/compound_shift_nf.py:189-247`.
- **Live `cProfile` Measurement:**
  - `build_atom_nf_mp(82, 126, 50)` ($^{208}\mathrm{Pb}$, `23,898` sequential `hm_mp` ops) = **`2,075.02 ms`**;
  - `build_atom_nf_mp(92, 146, 50)` ($^{238}\mathrm{U}$, `31,110` `hm_mp` ops) = **`2,716.84 ms`**;
  - Across all **`4,543`** chart rows (`229` distinct $A$ values, **`41,152,981` total `hm_mp` calls**), the Python `mpmath` NF loop alone costs **`~3,573.2 s` (`59.6 min`)**.
  - Separately, `_precompute_lp_by_a` (`lines 105-143`) must spawn **`29` short-lived Python child processes** (`batch_size = 8` out of `229` distinct $A$ values), each invoking a subprocess `clarabel-operator-selection-lp` CLI binary, because Clarabel's `MpfrFloat: Copy` arena retains `16–20 MB` per solve (`~46 GB` if solved naively per row).
- **`crates/*` Elimination Path:**
  1. **Algebraic + Rust $6\times 6$ reduction (`crates/hecke-engine::gram`):** Each proton's 11-step intra-block, each neutron's 11-step intra-block, the $k$ commuting `gen=0` inter-nucleon factors `(pp, nn, pn)` at nucleon $k$, and the final $Z$ electron `gen=1` steps are fixed $6\times 6$ linear operators on the $H_3$ NF basis! Precomputing the five $6\times 6$ MPFR matrices $(M_p, M_n, G_{pp}, G_{nn}, G_{pn})$ and using binary matrix exponentiation reduces $^{208}\mathrm{Pb}$ from `23,898` `hm_mp` calls to `O(A)` (`208` $6\times 6$ matvecs) — and in `crates/hecke-engine` (`pyhecke_native.build_atom_nf_mpfr_batch`) executes all `4,543` rows in **`< 0.25 s`**.
  2. **Arena-resetting in-process MPFR LP (`crates/qou-clarabel`):** Solving all `229` distinct $A$ values in one Rust call with per-solve MPFR arena reset eliminates all `29` Python + `229` CLI subprocess spawns (**`~3,600 s -> ~0.9 s`, `~4,000×`**).

### Bottleneck 6 — Exact Symbolic $q$-Degree Laurent Walk (`3,926.38 s`, Family `~5,080 s`)
- **Evidence:** `computations/probes/symbolic-nf-q-degree-magic.witness.json` (`3,926.38 s`), `atom-nf-q-degree.witness.json` (`356.87 s`), `atom-nf-degree-laws.witness.json` (`356.54 s`), `gs-filtration-jet-shape-magic.witness.json` (`342.88 s`).
- **Live `cProfile` Measurement:** `symbolic_nf_q_degree_magic_probe.build_atom_nf_lau(6, 6)` ($A=12$) took **`622.7 ms`** (`1,057` nonzero `Fraction` Laurent monomials across 6 NF components), growing as $O(A^4)$ through $A = 20$ because `lau_add` and `lau_scale` (`lines 113-131`) hash integer exponents in Python `dict`s and run `math.gcd` inside `fractions.Fraction` on every term addition.
- **`crates/*` Elimination Path:** Crucial algebraic observation: every multiplier in `build_atom_nf_lau` belongs to $\{1, 0, -h, -\frac{1}{2}h\}$ with $h = q - q^{-1}$, so **every coefficient lies in the dyadic Laurent ring $\mathbb{Z}[\frac{1}{2}][q, q^{-1}]$ — odd denominators never arise and rational GCD is 100% redundant!** Representing each NF component in `crates/gs-basis` / `crates/hecke-engine::laurent_poly_q` as a dense `Vec<BigInt>` shifted by `2^k` (rescaled only by trailing-zero bit-shifts) + $6\times 6$ polynomial matrix squaring cuts **`3,926 s -> ~1.8 s` (`~2,100×`)**.

### Bottleneck 7 — Exact $H_{3A}$ Full-Irrep Matrix Walk (`3,924.01 s`)
